Description

The 'Gang of Four' book: Gamma, Helm, Johnson and Vlissides catalogue 23 design patterns — creational, structural and behavioural — that recur in object-oriented software, each with intent, structure, participants and sample code. It gave working programmers a shared vocabulary (Factory Method, Observer, Singleton, Strategy...) that still structures software design discussion.
