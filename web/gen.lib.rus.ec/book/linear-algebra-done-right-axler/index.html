Description

Sheldon Axler's innovative undergraduate linear algebra text, famous for its motto that determinants should be banished to the end of the book. Working with vector spaces and linear maps directly, it develops eigenvalues and eigenvectors through the structure theory of operators on finite-dimensional spaces, reaching the spectral theorem and singular value decomposition with unusual conceptual clarity. The third edition added many new exercises and a chapter on operators on real vector spaces.
