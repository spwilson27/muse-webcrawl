Description

The definitive introduction to C by the language's designer Dennis Ritchie and Brian Kernighan — 'K&R'. The second edition (1988) describes ANSI C and includes the reference manual; its terse examples ('hello, world' begins here) taught generations of programmers and set the style for technical writing about programming languages.
