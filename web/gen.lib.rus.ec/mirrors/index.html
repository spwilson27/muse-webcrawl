Mirrors and access

Library Genesis is served from a changing set of mirror domains, so that the catalogue stays reachable when individual domains are blocked or seized. The addresses below are the commonly listed ones, as remembered; mirrors change frequently and unofficial copies exist, so the project pages advise checking that a mirror behaves like the real catalogue before logging in or downloading.

The collection is also distributed in bulk: the catalogue's files are shared as torrents in identifier ranges, and volunteers pin content to IPFS, so that the library can survive the loss of any single site. Scientific articles are indexed by the sister project Sci-Hub.
