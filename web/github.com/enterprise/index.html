Two ways to run it

☁️ Enterprise Cloud

Hosted on github.com with data residency options, dedicated support and a 99.9% uptime SLA. Most enterprises start here.

🖥️ Enterprise Server

Self-hosted on your infrastructure or cloud — AWS, Azure, GCP or on-prem — for teams that must keep code inside their own network.

🔐 Advanced Security

Secret scanning, code scanning (CodeQL), Dependabot and dependency review find vulnerabilities before they ship.

🪪 Identity & compliance

SAML and OIDC single sign-on, SCIM provisioning, EMU (Enterprise Managed Users), audit-log streaming and SOC 1/2, ISO 27001 reports.

🤖 Copilot Enterprise

AI assistance personalised to your organisation's code and documentation, with chat in github.com and the IDE.

⚙️ Actions at scale

CI/CD with larger and self-hosted runners, reusable workflows and required deployments across thousands of repositories.
