Wikidata Query Service

Run SPARQL queries against all of Wikidata

The Wikidata Query Service lets users run queries over the structured data in Wikidata using the SPARQL query language, and explore the results as tables, images, maps, bubble charts, timelines and graphs. Example queries are provided for beginners — from cats and hospitals to large bibliographic and geographical datasets.

[Image: Screenshot of the query editor with a SPARQL query on the left and a map / grid of results on the right]

Getting started

Pick an example query, press the blue run button, and see the results. A query helper (the pencil / 'Show query helper' tool) lets non-programmers build simple queries by selecting items and properties.

Example queries

Popular examples include 'Cats, with pictures', 'Largest cities with female mayors', 'Hospitals in the world', paintings by a given artist, and maps of airports or UNESCO sites.

The endpoint

Programmatic access is offered through a public SPARQL endpoint, used by tools, researchers and other Wikimedia services; results can be downloaded as JSON, CSV and other formats.
