Entropiecodierung

Als Entropiecodierung (engl. entropy encoding) bezeichnet man in der Nachrichtentechnik und Informatik eine Klasse verlustfreier Codierungsverfahren, die die statistischen Eigenschaften einer Datenquelle ausnutzen. Jedem Symbol wird ein Codewort zugeordnet, dessen Länge näherungsweise dem negativen Logarithmus seiner Auftrittswahrscheinlichkeit entspricht.

Prinzip

Die Information eines Symbols x mit Wahrscheinlichkeit p(x) beträgt I(x) = −log2 p(x) Bit. Ein optimaler Code erreicht eine mittlere Länge nahe der Entropie der Quelle. Man unterscheidet prinzipiell zwei Ansätze:

VerfahrenBeschreibungBeispiele
Codes variabler Längejedem Symbol wird ein eigenes, eindeutig decodierbares Codewort zugewiesenHuffman-Code, Shannon-Fano-Code
Intervall-/Stromcodesdie Nachricht wird schrittweise in einen Zahlenstrom überführtarithmetische Codierung, ANS

Decodierbarkeit

Damit ein Code variabler Länge eindeutig decodierbar ist, muss er die Kraft-Ungleichung erfüllen; in der Praxis verwendet man Präfixcodes, bei denen kein Codewort Anfang eines anderen ist. Solche Codes lassen sich als Binärbaum darstellen, an dessen Blättern die Symbole stehen.

Verwendung in Standards

Entropiecodierung bildet die abschließende Stufe in Verfahren wie JPEG (Huffman oder arithmetisch), H.264/AVC (CAVLC und CABAC), HEVC sowie in Archivformaten wie ZIP und 7z. Adaptive Varianten schätzen die Symbolwahrscheinlichkeiten während der Codierung fortlaufend und benötigen daher kein vorab übermitteltes Modell.
