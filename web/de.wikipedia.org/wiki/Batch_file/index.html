Batchdatei

Eine Batchdatei (englisch batch file, auch Stapelverarbeitungsdatei) ist eine Textdatei, die eine Folge von Befehlen enthält, die vom Kommandozeileninterpreter eines Betriebssystems nacheinander abgearbeitet werden (Stapelverarbeitung). Unter MS-DOS und Windows tragen Batchdateien die Endungen .bat oder .cmd.

Aufbau und Befehle

Batchdateien werden vom Interpreter COMMAND.COM (unter DOS) bzw. cmd.exe (unter Windows) ausgeführt. Sie unterstützen neben dem Aufruf von Programmen auch Steuerstrukturen wie Verzweigungen (IF), Sprungmarken (GOTO), Schleifen (FOR) sowie Variablen und Übergabeparameter (%1 bis %9). Ein klassisches Beispiel ist die Datei AUTOEXEC.BAT, die unter DOS bei jedem Systemstart automatisch abgearbeitet wurde.

Anwendung

Batchdateien dienen der Automatisierung wiederkehrender Aufgaben, etwa dem Kopieren von Dateien, dem Starten mehrerer Programme oder einfachen Installationsroutinen. Für komplexere Aufgaben werden heute meist leistungsfähigere Skriptsprachen wie PowerShell oder VBScript eingesetzt.
