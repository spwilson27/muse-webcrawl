Reaktivität (Kerntechnik)

Die Reaktivität ρ (englisch reactivity) ist in der Kerntechnik eine dimensionslose Kennzahl für die Abweichung eines Kernreaktors vom kritischen Zustand. Sie wird aus dem effektiven Multiplikationsfaktor keff berechnet:

ρ = (keff − 1) / keff

Beschreibt keff das Verhältnis der in aufeinanderfolgenden Generationen erzeugten Neutronen, so kennzeichnet die Reaktivität das zeitliche Verhalten der Reaktorleistung.

Zustände

  • ρ = 0 (k = 1): Der Reaktor ist kritisch; die Kettenreaktion läuft stationär, die Leistung bleibt konstant.
  • ρ < 0 (k < 1): Der Reaktor ist unterkritisch; die Kettenreaktion klingt ab.
  • ρ > 0 (k > 1): Der Reaktor ist überkritisch; die Leistung steigt an.

Einheiten und Effekte

Da die Reaktivitätswerte im Betrieb klein sind, werden sie häufig in pcm (per cent mille, 10−5) angegeben; historisch ist auch die Einheit „Dollar" verbreitet, bezogen auf den Anteil β der verzögerten Neutronen. Einfluss auf die Reaktivität haben Steuerstäbe, lösliche Absorber wie Borsäure, Abbrand und Spaltproduktvergiftung (etwa durch Xenon-135) sowie Temperatur-Rückkopplungen: Ein negativer Temperaturkoeffizient der Reaktivität — die Leistungssteigerung bremst sich durch Erwärmung selbst — trägt wesentlich zur Eigenstabilität und Sicherheit eines Reaktorentwurfs bei.
