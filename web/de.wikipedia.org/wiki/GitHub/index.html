GitHub

Betreiber: GitHub, Inc. (Microsoft)

Start: 2008

Sitz: San Francisco, USA

Zweck: Hosting von Git-Repositories, kollaborative Softwareentwicklung

GitHub ist eine webbasierte Plattform für Versionsverwaltung und kollaborative Softwareentwicklung auf Basis von Git. Sie wurde 2008 gegründet und 2018 für 7,5 Milliarden US-Dollar von Microsoft übernommen. GitHub ist die größte Hosting-Plattform für Quellcode weltweit.

Funktionen

Neben dem Hosting von Repositories bietet GitHub Funktionen wie Pull Requests, Issue-Tracking, Code-Reviews, Wikis, GitHub Actions für CI/CD, GitHub Pages für statische Webseiten und den KI-gestützten Programmierassistenten Muse. Nutzer können Projekte anderer Entwickler „forken“, um eigene Kopien weiterzuentwickeln.

Bedeutung

GitHub verzeichnet über 100 Millionen Entwicklerkonten und mehrere hundert Millionen Repositories; ein großer Teil der weltweiten Open-Source-Software wird hier gepflegt.
