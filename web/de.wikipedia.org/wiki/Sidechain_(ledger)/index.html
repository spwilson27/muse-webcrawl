Sidechain (Blockchain)

Eine Sidechain ist in der Blockchain-Technologie eine eigenständige, an eine Haupt-Blockchain (Mainchain) gekoppelte Blockchain. Zwischen beiden Ketten können digitale Vermögenswerte über einen sogenannten Two-Way Peg in beide Richtungen übertragen werden, wobei die Gesamtmenge erhalten bleibt.

Funktionsweise

Um Werte auf die Sidechain zu bewegen, werden Coins auf der Hauptkette gesperrt; auf der Sidechain wird eine entsprechende Menge freigegeben. Beim Rücktransfer läuft der Vorgang umgekehrt. Die Absicherung der Übertragung erfolgt je nach Konzept über eine Föderation von Funktionären, über kryptografische Nachweise (SPV-Proofs) oder über die Miner der Hauptkette (Merge Mining bzw. Drivechain-Konzepte).

Ziele

Sidechains sollen die Hauptkette entlasten, Experimente mit neuen Funktionen ermöglichen (etwa vertrauliche Transaktionen oder schnellere Blockzeiten) und spezialisierte Anwendungsfälle unterstützen, ohne die Sicherheit des Hauptnetzwerks zu verändern.

Beispiele

  • Liquid Network – föderierte Sidechain für Bitcoin
  • Rootstock (RSK) – Smart-Contract-Sidechain für Bitcoin
  • Polygon – Sidechain-/Skalierungslösung im Ethereum-Ökosystem
