Model in the Loop

Model in the Loop (MiL) bezeichnet in der modellbasierten Entwicklung eingebetteter Systeme eine Test- und Simulationsstufe, bei der ein Regler- oder Steuerungsmodell in einer reinen Simulationsumgebung gegen ein Modell der Regelstrecke (Umgebungsmodell) getestet wird. Es ist die erste Stufe der sogenannten X-in-the-Loop-Verfahren.

Einordnung

Beim Model in the Loop liegen sowohl das Steuerungsmodell als auch das Streckenmodell als Simulationsmodelle vor, etwa in Simulink. Darauf aufbauend folgen Software in the Loop (SiL), bei dem der generierte Code ausgeführt wird, Processor in the Loop (PiL) auf der Zielhardware ohne reale Ein- und Ausgänge sowie Hardware in the Loop (HiL), bei dem das reale Steuergerät an einen Simulator angeschlossen wird.

Zweck

MiL-Tests erlauben es, Anforderungen und Regelungsalgorithmen früh im Entwicklungsprozess zu prüfen, lange bevor Hardware existiert. Fehler lassen sich so kostengünstig beheben; die Tests sind zudem gefahrlos und beliebig wiederholbar.

Anwendungsgebiete

Das Verfahren wird vor allem in der Automobilindustrie, in der Luft- und Raumfahrt sowie in der Automatisierungstechnik im Rahmen des V-Modells der Entwicklung eingesetzt.
