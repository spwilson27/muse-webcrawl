Lineare Funktion

Eine lineare Funktion ist eine Funktion der Form f(x) = mx + t mit reellen Parametern m und t. Ihr Graph ist eine Gerade. Lineare Funktionen gehören zu den grundlegenden Funktionstypen der Schulmathematik und sind Spezialfälle der Polynomfunktionen vom Grad 1 (bzw. Grad 0 für m = 0). Der Name geht auf das lateinische linea („Linie") zurück.

Parameter

Der Parameter m ist die Steigung der Geraden: Sie gibt an, um wie viel der Funktionswert steigt, wenn das Argument um 1 zunimmt; aus zwei Punkten der Geraden ergibt sie sich als Quotient der Differenzen der y- und x-Koordinaten („Steigungsdreieck"). Für m > 0 ist die Funktion streng monoton wachsend, für m < 0 fallend, für m = 0 konstant. Der Parameter t ist der y-Achsenabschnitt, also der Funktionswert an der Stelle 0; der Graph schneidet die y-Achse im Punkt (0 | t).

Nullstelle und Umkehrung

Für m ≠ 0 besitzt eine lineare Funktion genau eine Nullstelle bei x = −t/m. Ebenfalls für m ≠ 0 ist sie umkehrbar; die Umkehrfunktion ist wiederum linear mit der Steigung 1/m. Zwei Geraden sind parallel, wenn sie dieselbe Steigung haben, und senkrecht zueinander, wenn das Produkt ihrer Steigungen −1 ergibt.

Abgrenzung

Im Sinne der linearen Algebra ist die Abbildung x ↦ mx + t nur für t = 0 eine lineare Abbildung; für t ≠ 0 handelt es sich um eine affine Abbildung (geradlinig verschobene Proportionalität). In der Analysis und Schulmathematik ist die Bezeichnung „lineare Funktion" für die allgemeine Geradengleichung dennoch üblich.
