ISO-Abbild

Ein ISO-Abbild (englisch ISO image) ist eine Datei, die ein vollständiges Abbild (Image) des Dateisystems einer CD oder DVD enthält. Der Name leitet sich von der Norm ISO 9660 ab, das vom Dateisystem der meisten Daten-CDs verwendet wird, auch wenn ISO-Abbilder ebenso UDF-Dateisysteme enthalten können.

Verwendung

ISO-Abbilder werden häufig zur Verteilung großer Softwarepakete und Betriebssysteme eingesetzt, insbesondere von Linux-Distributionen. Sie können mit Brennprogrammen auf optische Medien geschrieben, in virtuelle Laufwerke eingebunden (gemountet) oder zur Erstellung bootfähiger USB-Sticks verwendet werden.

Erstellung und Verarbeitung

Zur Erstellung eines ISO-Abbilds von einem optischen Datenträger dienen Programme wie dd unter Unix-Systemen. Zahlreiche Brenn- und Archivprogramme können ISO-Dateien öffnen, extrahieren oder bearbeiten. Moderne Betriebssysteme wie Windows und macOS können ISO-Abbilder ohne Zusatzsoftware als virtuelles Laufwerk einbinden.

Hybride Abbilder

Sogenannte Hybrid-ISOs lassen sich sowohl von optischen Medien als auch von USB-Sticks starten, da sie zusätzlich eine Partitionstabelle (MBR oder GPT) enthalten.
