Partielle Applikation

Die partielle Applikation (englisch partial application) ist ein Konzept der funktionalen Programmierung: Dabei wird eine Funktion, die mehrere Argumente erwartet, mit nur einem Teil ihrer Argumente aufgerufen. Das Ergebnis ist eine neue Funktion, die nur noch die verbleibenden Argumente benötigt.

Beispiel

Gegeben sei eine Funktion add, die zwei Zahlen addiert. Wendet man sie partiell nur auf das Argument 2 an, entsteht eine neue Funktion, die zu jeder Zahl 2 addiert:

add = λx. λy. x + y
add2 = add 2        -- Funktion, die noch ein Argument erwartet
add2 3              -- ergibt 5

Abgrenzung zum Currying

Partielle Applikation wird häufig mit dem Currying verwechselt. Beim Currying wird eine Funktion mehrerer Argumente in eine Kette einstelliger Funktionen umgewandelt; partielle Applikation bezeichnet dagegen den Vorgang, eine (ggf. bereits curryfizierte) Funktion auf einen Teil ihrer Argumente anzuwenden und eine Restfunktion zu erhalten. Beim Currying wird stets ein Argument pro Schritt übergeben, während die partielle Applikation eine beliebige Anzahl von Argumenten auf einmal binden kann.

Sprachunterstützung

In Sprachen wie Haskell sind alle Funktionen standardmäßig curryfiziert, sodass partielle Applikation unmittelbar möglich ist. In Sprachen wie Python steht dafür etwa functools.partial zur Verfügung; in JavaScript kann sie unter anderem über Function.prototype.bind oder Pfeilfunktionen nachgebildet werden.
