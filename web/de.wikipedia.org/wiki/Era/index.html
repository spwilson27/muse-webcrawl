Ära

Eine Ära (von lateinisch aera) ist ein längerer, durch prägende Merkmale einheitlich erscheinender Zeitabschnitt. Der Begriff wird in mehreren Fachgebieten mit unterschiedlicher Bedeutung verwendet.

Begriffsverwendungen

  • Chronologie: Eine Ära ist ein Zeitalter mit festem Anfangsjahr, von dem aus die Jahre fortlaufend gezählt werden, etwa die christliche Ära (Zeitrechnung ab Christi Geburt) oder die islamische Ära (Hidschra).
  • Geologie: In der geologischen Zeitskala ist eine Ära (Erdzeitalter) eine Einheit der Chronostratigraphie, die mehrere Perioden umfasst, zum Beispiel das Mesozoikum (Erdmittelalter).
  • Geschichtswissenschaft: Eine Epoche, die durch eine Person, eine Herrschaft oder ein kulturelles Phänomen geprägt ist, etwa die „Ära Adenauer" oder die viktorianische Ära.
  • Astronomie: Der Anfangszeitpunkt einer Ephemeridenrechnung.

Herkunft

Das Wort geht auf das lateinische aera zurück, ursprünglich der Plural von aes (Erz, Geld), später im Sinne von Rechnungszahlen und schließlich von Zeitrechnung verwendet.
