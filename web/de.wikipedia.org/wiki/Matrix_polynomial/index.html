Matrixpolynom

Ein Matrixpolynom ist in der linearen Algebra ein Polynom, dessen Variable eine quadratische Matrix ist. Gegeben ein skalares Polynom mit Koeffizienten aus einem Körper, entsteht das zugehörige Matrixpolynom, indem die Matrix in das Polynom eingesetzt wird; der konstante Term wird dabei mit der Einheitsmatrix multipliziert.

Definition

Ist p(x) = anxn + … + a1x + a0 ein Polynom und A eine quadratische Matrix, so ist das Matrixpolynom definiert als p(A) = anAn + … + a1A + a0I, wobei I die Einheitsmatrix bezeichnet.

Eigenschaften

Matrixpolynome derselben Matrix kommutieren miteinander. Von besonderer Bedeutung ist der Satz von Cayley-Hamilton, demzufolge jede Matrix eine Nullstelle ihres eigenen charakteristischen Polynoms ist. Das Minimalpolynom einer Matrix ist das normierte Polynom kleinsten Grades, das die Matrix annulliert; sein Grad ist höchstens gleich der Dimension der Matrix.

Anwendungen

Matrixpolynome treten bei der Berechnung von Matrixfunktionen wie der Matrixexponentialfunktion, bei der Lösung linearer Differentialgleichungssysteme und in der Regelungstheorie auf. Auch Krylow-Unterraummethoden der numerischen Mathematik beruhen auf der Betrachtung von Matrixpolynomen.
