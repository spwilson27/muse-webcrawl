Server Message Block

Server Message Block (SMB) ist ein Netzwerkprotokoll, das vor allem für den Zugriff auf Dateien, Drucker und andere Ressourcen in Netzwerken verwendet wird. Es wurde ursprünglich in den 1980er-Jahren von IBM entwickelt und später von Microsoft maßgeblich weiterentwickelt und in den Windows-Betriebssystemen eingesetzt. SMB arbeitet üblicherweise über TCP/IP, heute meist direkt über den Port 445.

Geschichte

Die erste Version des Protokolls entstand bei IBM für das Betriebssystem DOS. Microsoft kombinierte SMB mit den LAN-Manager- und Windows-Diensten und prägte auch die Weiterentwicklung. Eine von Microsoft veröffentlichte Spezifikationsvariante wurde als CIFS (Common Internet File System) bezeichnet; diese Bezeichnung wird gelegentlich noch für die ältere SMB-Version 1 verwendet.

Mit Windows Vista und Windows Server 2008 führte Microsoft SMB 2 ein, das das Protokoll deutlich vereinfachte, die Zahl der Befehle reduzierte und die Leistung verbesserte. SMB 3, eingeführt mit Windows 8 und Windows Server 2012, brachte unter anderem Verschlüsselung, transparentes Failover und SMB Direct über RDMA.

Funktionen

SMB erlaubt es Clients, über ein Netzwerk Dateien zu öffnen, zu lesen, zu schreiben und zu verwalten, als befänden sie sich auf einer lokalen Festplatte. Darüber hinaus unterstützt es die Freigabe von Druckern, benannte Pipes für Interprozesskommunikation sowie Authentifizierung und Zugriffskontrolle. Die freie Implementierung Samba stellt SMB-Dienste für Unix- und Linux-Systeme bereit und ermöglicht die Interoperabilität mit Windows-Netzwerken.

Sicherheit

Die veraltete Version SMB 1 gilt als unsicher und sollte deaktiviert werden; Schwachstellen des Protokolls wurden unter anderem von der Schadsoftware WannaCry ausgenutzt. Neuere Versionen bieten Signierung und Verschlüsselung der übertragenen Daten.
