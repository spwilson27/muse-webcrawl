Code civil

Der Code civil, ursprünglich Code civil des Français und zeitweise Code Napoléon genannt, ist das französische Zivilgesetzbuch, das am 21. März 1804 unter Napoleon Bonaparte in Kraft trat.

Inhalt

Das Gesetzbuch fasste das Privatrecht in über 2.200 Artikeln zusammen und verankerte Prinzipien der Revolutionszeit: Rechtsgleichheit der männlichen Bürger, Schutz des Privateigentums, Vertragsfreiheit und Trennung von Kirche und Staat im Zivilrecht, insbesondere die Zivilehe.

Wirkung

Der Code civil wurde in vielen Ländern Europas und darüber hinaus zum Vorbild für Zivilgesetzbücher, etwa in Belgien, den Niederlanden, Italien, Spanien und Teilen Lateinamerikas. In Frankreich gilt er, vielfach reformiert, bis heute.
