Michael-Addition

ReaktionstypNukleophile Additionsreaktion
NamensgeberArthur Michael (1887)
KlasseC-C-Bindungsknüpfung

Die Michael-Addition ist eine Namensreaktion der organischen Chemie. Sie bezeichnet die nukleophile Addition eines Carbanions oder eines anderen geeigneten Nukleophils (des „Michael-Donors“) an eine α,β-ungesättigte Carbonylverbindung (den „Michael-Akzeptor“). Das Nukleophil addiert dabei an das β-Kohlenstoffatom der Doppelbindung – man spricht von einer 1,4-Addition im Gegensatz zur 1,2-Addition an die Carbonylgruppe.

Mechanismus

Der erste Schritt ist die Deprotonierung des Michael-Donors, häufig einer Verbindung mit acider Methylengruppe zwischen zwei elektronenziehenden Gruppen (etwa Malonsäureester oder Acetessigsäureester), durch eine Base. Das entstehende resonanzstabilisierte Enolat greift das β-Kohlenstoffatom des Akzeptors an, beispielsweise eines Enons, Enals, α,β-ungesättigten Esters oder Nitrils. Das dabei gebildete neue Enolat wird anschließend protoniert, was das Endprodukt ergibt.

Anwendung

Die Michael-Addition ist ein zentrales Werkzeug zur Knüpfung von Kohlenstoff-Kohlenstoff-Bindungen. Eine bekannte Anwendungsform ist die Robinson-Annelierung, bei der auf eine Michael-Addition mit Methylvinylketon eine intramolekulare Aldolreaktion folgt und so sechsgliedrige Ringe aufgebaut werden. Asymmetrische Varianten mit chiralen Katalysatoren (Organokatalyse) ermöglichen die enantioselektive Michael-Addition und werden in der Wirkstoffsynthese genutzt. Die analoge Addition von Aminen wird als Aza-Michael-Addition, die von Thiolen als Thia-Michael-Addition bezeichnet.

Geschichte

Die Reaktion wurde 1887 von dem amerikanischen Chemiker Arthur Michael beschrieben, der die Addition von Malonester an Zimtsäureester untersuchte.
