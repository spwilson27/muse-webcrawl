Maschinencode

Maschinencode (auch Maschinensprache) ist die unterste Ebene der Computerprogrammierung: eine Folge von Befehlen in binärer oder hexadezimaler Form, die ein Prozessor unmittelbar ausführen kann. Jede Prozessorarchitektur besitzt ihren eigenen Befehlssatz (Instruction Set Architecture), sodass Maschinencode nicht ohne Weiteres zwischen verschiedenen Architekturen übertragbar ist.

Aufbau

Ein Maschinenbefehl besteht typischerweise aus einem Opcode, der die Operation festlegt (z. B. Addition, Laden, Springen), sowie Operanden, die Register oder Speicheradressen angeben. Assemblersprache ist eine menschenlesbare, mnemonische Darstellung des Maschinencodes; ein Assembler übersetzt sie eins zu eins in Maschinencode. Programme in höheren Programmiersprachen werden dagegen von einem Compiler in Maschinencode übersetzt oder von einem Interpreter zur Laufzeit ausgeführt.

Verwendung

Direkt in Maschinencode wird heute nur noch in Ausnahmefällen programmiert, etwa bei der Entwicklung von Bootladern, Firmware oder zeitkritischen Routinen. Für Analyse und Fehlersuche stellen Disassembler und Debugger Maschinencode in Assemblerform dar.
