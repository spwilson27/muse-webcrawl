Kubische Gleichung

Eine kubische Gleichung ist eine algebraische Gleichung dritten Grades der Form ax³ + bx² + cx + d = 0 mit a ≠ 0. Über den reellen Zahlen besitzt sie stets mindestens eine Lösung; insgesamt hat sie (mit Vielfachheit gezählt) drei komplexe Lösungen.

Geschichte

Die allgemeine Lösungsformel wurde im 16. Jahrhundert in Italien gefunden: Scipione del Ferro entdeckte eine Methode für einen Spezialfall, Niccolò Tartaglia erweiterte sie, und Gerolamo Cardano veröffentlichte sie 1545 in seiner Ars Magna (Cardanische Formeln). Um die Priorität der Entdeckung entbrannte ein berühmter Streit zwischen Cardano und Tartaglia.

Lösung

Durch die Substitution x = t − b/(3a) wird die Gleichung auf die reduzierte Form t³ + pt + q = 0 gebracht. Ihre Lösung ergibt sich aus Kubikwurzeln der Terme −q/2 ± √((q/2)² + (p/3)³). Im Fall dreier reeller Lösungen (casus irreducibilis) führt der Weg zwangsläufig über komplexe Zahlen.
