Handle System

Das Handle System ist ein System zur Vergabe und Auflösung dauerhafter Identifikatoren (Handles) für digitale Objekte im Internet. Es wurde von der Corporation for National Research Initiatives (CNRI) unter Leitung von Robert Kahn entwickelt und bildet unter anderem die technische Grundlage des Digital Object Identifier (DOI).

Funktionsweise

Ein Handle besteht aus einem Präfix, das die vergebende Organisation kennzeichnet, und einem Suffix, das das einzelne Objekt bezeichnet, getrennt durch einen Schrägstrich (Beispiel: 10.1000/182). Im Gegensatz zu URLs bleibt ein Handle stabil, auch wenn sich der Speicherort des Objekts ändert: Der Handle-Dienst löst den Identifikator zur jeweils aktuellen Adresse auf. Das System ist verteilt organisiert, mit einem globalen Handle-Register und lokalen Diensten der einzelnen Präfixinhaber.

Anwendungen

Neben DOI für wissenschaftliche Publikationen wird das Handle System unter anderem in digitalen Bibliotheken, Archiven und für die Kennzeichnung von Forschungsdaten eingesetzt. Die Verwaltung der Präfixe obliegt der International DOI Foundation beziehungsweise der DONA Foundation, die das Multi-Primary Registry des Systems betreibt.
