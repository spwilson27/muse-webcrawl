Google Cloud Platform

BetreiberGoogle
Start2008 (App Engine), Ausbau ab 2011
AngebotCloud Computing (IaaS, PaaS, SaaS)
Wichtige DiensteCompute Engine, Kubernetes Engine, BigQuery, Cloud Storage

Die Google Cloud Platform (GCP), heute meist als Google Cloud vermarktet, ist eine Sammlung von Cloud-Computing-Diensten von Google, die auf derselben Infrastruktur laufen, die Google intern für Produkte wie die Suche und YouTube nutzt. Sie ist nach Amazon Web Services und Microsoft Azure der drittgrößte Anbieter im Markt für Public Clouds.

Dienste

Zum Angebot zählen Rechenleistung (Compute Engine für virtuelle Maschinen, App Engine als Plattformdienst, Cloud Run und die Kubernetes Engine für Container), Speicher (Cloud Storage), Datenbanken (Cloud SQL, Spanner, Firestore) sowie Analyse- und KI-Dienste wie das Data-Warehouse BigQuery und die Machine-Learning-Plattform Vertex AI.

Infrastruktur

Google betreibt weltweit mehrere Dutzend Cloud-Regionen mit jeweils mehreren Verfügbarkeitszonen, verbunden über ein eigenes globales Glasfasernetz. Der Betrieb der Rechenzentren wird vom Unternehmen als CO₂-neutral dargestellt; Ziel ist ein vollständig CO₂-freier Betrieb rund um die Uhr.

Geschichte

Den Anfang machte 2008 die App Engine, mit der Entwickler Webanwendungen auf Googles Infrastruktur betreiben konnten. In den Folgejahren kamen Speicher-, Datenbank- und Big-Data-Dienste hinzu; 2015 wurde mit Kubernetes ein von Google entwickeltes Container-Orchestrierungssystem quelloffen, das sich zum Industriestandard entwickelte.
