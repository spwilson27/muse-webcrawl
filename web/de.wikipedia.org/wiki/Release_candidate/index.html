Release Candidate

Ein Release Candidate (abgekürzt RC, deutsch etwa „Veröffentlichungskandidat“) ist in der Softwareentwicklung eine nahezu fertige Version eines Computerprogramms, die potenziell als endgültige Version veröffentlicht werden kann, sofern keine schwerwiegenden Fehler mehr auftreten. Release Candidates werden in der Regel an einen größeren Tester- oder Nutzerkreis verteilt, um letzte Fehler vor der Veröffentlichung zu finden.

Entwicklungsstadien

Im typischen Entwicklungszyklus folgt der Release Candidate auf die Beta-Version. Während Alpha-Versionen noch intern getestet werden und Beta-Versionen bereits einen Großteil der Funktionen enthalten, gilt der Release Candidate als funktionsvollständig („feature complete“). Treten keine kritischen Fehler mehr auf, wird er ohne Änderung zur finalen Version (Release) erklärt.

Versionierung

Release Candidates werden häufig mit Suffixen wie „RC1“, „RC2“ usw. gekennzeichnet, etwa „Version 2.0 RC1“. Bei Betriebssystemen und großer Anwendungssoftware kann es mehrere Release Candidates geben, bevor die finale Version erscheint.

Zweck

Da der Release Candidate dem Endprodukt entsprechen soll, dient seine Verbreitung vor allem der Qualitätssicherung unter realen Bedingungen: Kompatibilitätsprobleme, Installationsfehler und seltene Programmfehler sollen aufgedeckt werden, bevor die Software allgemein freigegeben wird.
