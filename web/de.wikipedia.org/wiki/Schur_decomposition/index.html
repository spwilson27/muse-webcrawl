Schur-Zerlegung

Die Schur-Zerlegung (auch Schursche Normalform oder Schur-Triangularisierung) ist ein Begriff aus der linearen Algebra. Sie besagt, dass jede quadratische komplexe Matrix durch eine unitäre Ähnlichkeitstransformation auf obere Dreiecksgestalt gebracht werden kann. Benannt ist die Zerlegung nach dem Mathematiker Issai Schur.

Aussage

Zu jeder quadratischen Matrix A über den komplexen Zahlen existiert eine unitäre Matrix U, sodass U*AU = T gilt, wobei T eine obere Dreiecksmatrix ist. Auf der Diagonalen von T stehen die Eigenwerte von A. Die Spalten von U bilden eine Orthonormalbasis, die aus Schur-Vektoren besteht.

Bedeutung

Die Schur-Zerlegung spielt eine zentrale Rolle in der numerischen linearen Algebra. Der QR-Algorithmus zur Berechnung von Eigenwerten konvergiert im Allgemeinen gegen die Schur-Form einer Matrix. Für reelle Matrizen existiert eine reelle Variante, die sogenannte reelle Schur-Form, bei der auf der Diagonalen zusätzlich 2×2-Blöcke für Paare komplex konjugierter Eigenwerte auftreten dürfen.

Geschichte

Issai Schur stellte die Zerlegung zu Beginn des 20. Jahrhunderts im Zusammenhang mit der Darstellungstheorie von Gruppen und der Theorie der Matrizen vor. Sie verallgemeinert die Tatsache, dass jede normale Matrix unitär diagonalisierbar ist.
