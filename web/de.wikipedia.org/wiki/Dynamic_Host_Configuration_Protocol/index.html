Dynamic Host Configuration Protocol

Aus Wikipedia, der freien Enzyklopädie

Das Dynamic Host Configuration Protocol (DHCP) ist ein Netzwerkprotokoll, mit dem Rechnern in einem IP-Netzwerk automatisch Konfigurationsdaten – vor allem IP-Adressen – zugewiesen werden. Es erspart die manuelle Konfiguration jedes einzelnen Geräts und wird in praktisch allen Heim- und Unternehmensnetzwerken sowie für IPv4-Netze eingesetzt. DHCP für IPv4 ist im RFC 2131 spezifiziert, die Variante für IPv6 (DHCPv6) im RFC 8415.

Ablauf der Adressvergabe

Der Aushandlungsprozess wird mit der Abkürzung DORA beschrieben:

  1. Discover: Der Client sendet eine Broadcast-Anfrage, um verfügbare DHCP-Server zu finden.
  2. Offer: Ein oder mehrere Server bieten eine IP-Adresse samt Konfigurationsparametern an.
  3. Request: Der Client wählt ein Angebot aus und fordert die Adresse formell an.
  4. Acknowledge: Der Server bestätigt die Zuweisung; der Client konfiguriert seine Netzwerkschnittstelle.

Die Kommunikation erfolgt über UDP (Server-Port 67, Client-Port 68). Die Adresse wird nur für eine begrenzte Zeit („Lease“) vergeben und muss vor Ablauf erneuert werden. Neben der IP-Adresse übermittelt der Server typischerweise Subnetzmaske, Standardgateway, DNS-Server und Domainname; über zusätzliche Optionen lassen sich weitere Parameter wie NTP-Server verteilen.

Geschichte

DHCP baut auf dem älteren BOOTP-Protokoll von 1985 auf und wurde 1993 erstmals standardisiert. Es erweiterte BOOTP um die automatische, zeitlich begrenzte Adressvergabe aus einem Adresspool sowie um ein flexibles Optionsfeld.

Sicherheit

DHCP selbst enthält keine Authentifizierung, sodass sich sowohl Clients durch unbefugte „Rogue“-Server als auch Server durch Anfragenfluten angreifen lassen. In verwalteten Netzwerken kommen daher Verfahren wie DHCP-Snooping auf Switches zum Einsatz.
