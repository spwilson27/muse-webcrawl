Idris (Programmiersprache)

Idris ist eine rein funktionale Programmiersprache mit abhängigen Typen (dependent types). Sie wurde von Edwin Brady an der University of St Andrews entwickelt. Die Syntax ist stark von Haskell beeinflusst; das Typsystem erlaubt es, Eigenschaften von Programmen bereits zur Kompilierzeit zu beweisen.

Merkmale

Das zentrale Merkmal von Idris sind abhängige Typen: Typen können von Werten abhängen, sodass beispielsweise die Länge eines Vektors Teil seines Typs ist. Dadurch können viele Fehler, die in anderen Sprachen erst zur Laufzeit auftreten, bereits vom Typprüfer ausgeschlossen werden. Idris verfügt über einen interaktiven, beweisorientierten Entwicklungsmodus mit Editorunterstützung (z. B. für Emacs und Vim) sowie über Taktik-artige Beweisführung.

Idris 2

Die 2020 veröffentlichte Version Idris 2 wurde von Grund auf neu implementiert und basiert auf einem quantitativen Typsystem (Quantitative Type Theory), das unter anderem die Unterscheidung von Werten zur Kompilier- und Laufzeit präzise steuert. Idris 2 kompiliert standardmäßig über Scheme (Chez Scheme) bzw. Racket, weitere Backends existieren.
