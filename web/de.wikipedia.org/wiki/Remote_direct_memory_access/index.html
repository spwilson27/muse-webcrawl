Remote Direct Memory Access

Remote Direct Memory Access (RDMA) ist eine Netzwerktechnologie, die es einem Computer erlaubt, direkt auf den Arbeitsspeicher eines anderen Computers zuzugreifen, ohne dessen Prozessor und Betriebssystemkern in den Datentransfer einzubeziehen. Dadurch werden sehr hohe Übertragungsraten bei minimaler Latenz und geringer CPU-Last erreicht.

Prinzip

Bei herkömmlichen Netzwerkprotokollen müssen Daten mehrfach zwischen Anwendungs-, Kern- und Pufferspeicher kopiert werden. RDMA-fähige Netzwerkadapter übertragen Daten dagegen unmittelbar zwischen registrierten Speicherbereichen zweier Anwendungen („zero copy", „kernel bypass"). Die Operationen umfassen lesende und schreibende Zugriffe sowie in klassischen Implementierungen atomare Operationen.

Implementierungen

Die wichtigsten Varianten sind InfiniBand, das von Grund auf für RDMA entworfen wurde, RoCE (RDMA over Converged Ethernet) sowie iWARP, das RDMA über TCP/IP abbildet. RDMA wird vor allem in Hochleistungsrechnern (HPC), bei verteiltem Speicher, Datenbanksystemen und im Training großer KI-Modelle eingesetzt, wo es die Kommunikation zwischen tausenden Rechenknoten beschleunigt.
