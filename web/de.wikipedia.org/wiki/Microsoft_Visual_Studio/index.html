Microsoft Visual Studio

Microsoft Visual Studio ist eine integrierte Entwicklungsumgebung (IDE) von Microsoft. Die erste Version erschien 1997; aktuelle Hauptversionen sind Visual Studio 2019 und Visual Studio 2022. Die IDE unterstützt zahlreiche Programmiersprachen, insbesondere C#, C++, Visual Basic .NET und F#, und richtet sich vor allem an die Entwicklung für Windows, .NET, Webanwendungen und Cloud-Dienste.

Funktionen und Editionen

Visual Studio umfasst einen Code-Editor mit IntelliSense-Codevervollständigung, einen grafischen Debugger, Werkzeuge zur Oberflächengestaltung, Profiler, Datenbank- und Testwerkzeuge sowie eine tiefe Integration mit Git und dem Cloud-DevOps-Dienst Azure DevOps. Die Umgebung ist durch Erweiterungen modifizierbar. Angeboten werden die kostenlose Community-Edition für Einzelentwickler und Open-Source-Projekte sowie die kostenpflichtigen Editionen Professional und Enterprise. Von Visual Studio zu unterscheiden ist der schlankere, quelloffene Editor Visual Studio Code.
