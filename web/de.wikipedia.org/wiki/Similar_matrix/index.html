Ähnlichkeit (Matrix)

In der linearen Algebra heißen zwei quadratische Matrizen A und B derselben Größe ähnlich, wenn es eine invertierbare Matrix S gibt mit B = S−1AS. Die Umformung von A nach B wird Ähnlichkeitstransformation genannt. Ähnliche Matrizen beschreiben denselben linearen Endomorphismus, lediglich bezogen auf unterschiedliche Basen des Vektorraums.

Eigenschaften

Ähnlichkeit ist eine Äquivalenzrelation auf der Menge der quadratischen Matrizen. Ähnliche Matrizen besitzen zahlreiche gemeinsame Invarianten: Sie haben dieselbe Determinante, dieselbe Spur, denselben Rang, dasselbe charakteristische Polynom und damit dieselben Eigenwerte einschließlich ihrer algebraischen Vielfachheiten. Auch das Minimalpolynom und die Jordansche Normalform (bis auf die Reihenfolge der Jordanblöcke) stimmen überein. Umgekehrt sind zwei Matrizen über einem algebraisch abgeschlossenen Körper genau dann ähnlich, wenn ihre Jordanschen Normalformen übereinstimmen.

Bedeutung

Die Ähnlichkeit erlaubt es, eine Matrix durch Wahl einer geeigneten Basis in eine möglichst einfache Form zu überführen – im besten Fall in eine Diagonalmatrix (Diagonalisierbarkeit) oder wenigstens in Jordanform. Dies vereinfacht unter anderem das Berechnen von Matrixpotenzen und das Lösen linearer Differentialgleichungssysteme. Eng verwandt ist der Begriff der Äquivalenz von Matrizen, bei der links und rechts mit zwei verschiedenen invertierbaren Matrizen multipliziert werden darf.
