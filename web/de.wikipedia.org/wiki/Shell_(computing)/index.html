Shell (Informatik)

Eine Shell (englisch für „Schale", „Hülle") ist in der Informatik ein Programm, das die Benutzerschnittstelle zu einem Betriebssystem bildet. Sie nimmt Eingaben des Benutzers entgegen, startet Programme und stellt deren Ausgaben dar. Man unterscheidet vor allem textbasierte Kommandozeilen-Shells (CLI) und grafische Shells.

ArtSystemsoftware, Benutzerschnittstelle
BeispieleBash, zsh, PowerShell, Windows Explorer

Kommandozeilen-Shells

Unix-Shells wie die Bourne-Shell (sh), die C-Shell (csh), die KornShell (ksh), die Bourne-again Shell (Bash) und die Z shell (zsh) verfügen über eine eigene Skriptsprache mit Variablen, Kontrollstrukturen und Umleitungen (Pipes und Redirection). Unter Windows dienen cmd.exe und PowerShell als Shells; PowerShell arbeitet objektorientiert und ist auch plattformübergreifend verfügbar.

Grafische Shells

Grafische Shells stellen die Desktop-Umgebung eines Betriebssystems bereit, etwa der Windows Explorer unter Windows, der Finder unter macOS oder Umgebungen wie GNOME und KDE Plasma unter Linux. Der Name verweist darauf, dass die Shell den Betriebssystemkern (Kernel) wie eine Schale umgibt und dem Benutzer zugänglich macht.
