ReFS

ReFS (Resilient File System) ist ein Dateisystem von Microsoft, das 2012 mit Windows Server 2012 eingeführt wurde. Es wurde als Ergänzung und langfristiger Nachfolger von NTFS für große Datenmengen und hohe Datenintegrität konzipiert.

Eigenschaften

ReFS nutzt Prüfsummen für Metadaten und optional auch für Dateiinhalte, um Datenbeschädigungen („Bit Rot") zu erkennen und in Verbindung mit gespiegelten Speicherplätzen automatisch zu reparieren. Es unterstützt sehr große Volumes und Dateien und verzichtet auf einige ältere NTFS-Funktionen wie kurze 8.3-Dateinamen oder Objekt-IDs.

Einsatz

ReFS wird vor allem auf Servern, in Virtualisierungsumgebungen und mit Storage Spaces eingesetzt. Das Erstellen von ReFS-Volumes ist in den Client-Versionen von Windows auf bestimmte Editionen beschränkt.
