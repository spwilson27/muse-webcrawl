Java Virtual Machine

Java Virtual Machine
Typ: Virtuelle Maschine
Entwickler: Sun Microsystems / Oracle
Programmiersprache: C++, Java
Lizenz: Proprietär / GPL

Die Java Virtual Machine (JVM) ist eine virtuelle Maschine, die Java-Bytecode ausführt. Sie bildet die zentrale Komponente der Java-Laufzeitumgebung (Java Runtime Environment, JRE) und ermöglicht das Prinzip „Write once, run anywhere“ („Einmal schreiben, überall ausführen“): Ein in Java geschriebenes und zu Bytecode kompiliertes Programm kann auf jeder Plattform laufen, für die eine JVM-Implementierung existiert.

Funktionsweise

Der Java-Compiler übersetzt Quellcode nicht in Maschinencode, sondern in plattformunabhängigen Bytecode, der in Klassendateien (.class) gespeichert wird. Die JVM lädt diese Dateien zur Laufzeit, verifiziert den Bytecode aus Sicherheitsgründen und führt ihn aus – zunächst interpretiert, später durch einen Just-in-time-Compiler (JIT), etwa den HotSpot-Compiler, in schnellen Maschinencode übersetzt.

Bestandteile

Zur JVM gehören unter anderem der Klassenlader (Classloader), der Bytecode-Verifizierer, der Interpreter, der JIT-Compiler sowie die automatische Speicherbereinigung (Garbage Collection), die nicht mehr benötigte Objekte selbsttätig entfernt. Die Spezifikation der JVM ist herstellerunabhängig definiert; bekannte Implementierungen sind HotSpot (Oracle/OpenJDK), Eclipse OpenJ9 und GraalVM.

Geschichte

Die erste JVM wurde Mitte der 1990er Jahre von Sun Microsystems zusammen mit der Programmiersprache Java entwickelt und 1995 veröffentlicht. Nach der Übernahme von Sun durch Oracle im Jahr 2010 wird die Referenzimplementierung im Rahmen des OpenJDK-Projekts weiterentwickelt.
