Engineered Materials Arrestor System

Engineered Materials Arrestor System ist eine alternative Bezeichnung für das Engineered Materials Arresting System (EMAS), ein Fangbett aus bruchfreudigen Betonblöcken am Ende von Start- und Landebahnen.

Funktion

Das System dient dazu, ein Flugzeug, das über das Ende der Landebahn hinausrollt (Runway Excursion), durch das Zermalmen der Blöcke unter den Fahrwerksrädern sanft und ohne schwere Schäden abzubremsen. Es wird vor allem dort eingesetzt, wo die vorgeschriebene Sicherheitsfläche hinter dem Bahnende nicht zur Verfügung steht.
