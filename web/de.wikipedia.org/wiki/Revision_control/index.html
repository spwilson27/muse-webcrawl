Versionsverwaltung

Eine Versionsverwaltung (englisch version control oder revision control) ist ein System, das Änderungen an Dateien – vor allem Quelltext in der Softwareentwicklung – aufzeichnet, sodass frühere Zustände jederzeit wiederhergestellt, verglichen und zusammengeführt werden können.

Grundbegriffe

Die verwalteten Dateien liegen in einem Repository. Änderungen werden als Commit (Revision) mit Kommentar gespeichert. Entwicklungszweige (Branches) erlauben parallele Arbeit, die später per Merge zusammengeführt wird; Konflikte müssen dabei gegebenenfalls manuell aufgelöst werden. Als Tag markiert man benannte Stände, etwa Releases.

Systemtypen

Lokale Systeme wie das Revision Control System (RCS) verwalten einzelne Dateien auf einem Rechner. Zentrale Systeme wie CVS und Subversion nutzen einen Server, von dem Entwickler Arbeitskopien beziehen. Verteilte Systeme wie Git und Mercurial geben jedem Nutzer ein vollständiges Repository, was dezentrales Arbeiten und nachträgliche Änderungen der Historie ermöglicht. Git ist heute das dominierende System der Softwareentwicklung.
