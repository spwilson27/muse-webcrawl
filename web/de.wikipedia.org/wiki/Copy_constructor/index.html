Kopierkonstruktor

Ein Kopierkonstruktor (englisch copy constructor) ist in der objektorientierten Programmierung ein spezieller Konstruktor, der ein neues Objekt als Kopie eines bereits existierenden Objekts derselben Klasse erzeugt. Der Begriff ist vor allem in der Programmiersprache C++ gebräuchlich.

C++

In C++ hat der Kopierkonstruktor üblicherweise die Signatur Klassenname(const Klassenname&). Er wird unter anderem aufgerufen, wenn ein Objekt mit einem anderen Objekt initialisiert wird, wenn ein Objekt als Wert an eine Funktion übergeben oder von einer Funktion zurückgegeben wird.

Klasse a;
Klasse b = a;   // Aufruf des Kopierkonstruktors

Wird kein eigener Kopierkonstruktor definiert, erzeugt der Compiler einen automatisch, der eine elementweise (flache) Kopie vornimmt. Verwaltet eine Klasse dynamisch allozierte Ressourcen, ist häufig eine tiefe Kopie erforderlich; hier gilt die sogenannte Dreierregel (Rule of Three) beziehungsweise Fünferregel (Rule of Five) unter Einbeziehung des Verschiebekonstruktors und der Verschiebezuweisung.

Andere Sprachen

In Java und C# erfüllt die Methode clone() beziehungsweise Copy-Konstruktoren ähnliche Aufgaben. In Python wird das Kopieren von Objekten durch die Funktionen copy.copy und copy.deepcopy des Moduls copy unterstützt.
