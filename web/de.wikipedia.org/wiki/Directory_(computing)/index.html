Verzeichnis (Informatik)

Ein Verzeichnis (englisch directory) ist in der Informatik eine logische Gruppierung von Dateien und Unterverzeichnissen innerhalb eines Dateisystems. Verzeichnisse dienen der hierarchischen Organisation von Daten auf einem Datenträger und ermöglichen es, Dateien thematisch oder strukturell zu ordnen.

Geschichte

Das Konzept hierarchischer Verzeichnisse wurde bereits in frühen Mehrbenutzersystemen wie Multics eingeführt und später von Unix, MS-DOS (ab Version 2.0) und allen modernen Betriebssystemen übernommen. In MS-DOS und Windows wird ein Verzeichnis umgangssprachlich auch als Ordner bezeichnet.

Struktur

Verzeichnisse bilden eine Baumstruktur: An der Spitze steht das Wurzelverzeichnis (englisch root directory), von dem aus alle weiteren Verzeichnisse und Dateien über Pfadnamen erreichbar sind. Ein Verzeichnis, das ein anderes enthält, heißt dessen Elternverzeichnis (englisch parent directory); die enthaltenen Verzeichnisse heißen Unterverzeichnisse oder Subverzeichnisse.

In Unix-ähnlichen Systemen werden die Einträge . (aktuelles Verzeichnis) und .. (Elternverzeichnis) automatisch in jedem Verzeichnis geführt. Auf Dateisystemebene ist ein Verzeichnis selbst eine besondere Datei, die eine Liste von Namen und Verweisen (Inodes) auf die enthaltenen Objekte enthält.

Operationen

Typische Operationen auf Verzeichnissen sind das Erstellen, Löschen, Umbenennen und Durchsuchen. In Unix-Systemen stehen dafür Befehle wie mkdir, rmdir, cd und ls zur Verfügung; in der API stellt POSIX Funktionen wie opendir und readdir bereit.
