Ackermannfunktion

Die Ackermannfunktion ist eine nach Wilhelm Ackermann benannte, extrem schnell wachsende mathematische Funktion, die eine wichtige Rolle in der theoretischen Informatik spielt. Sie wurde 1926 von Ackermann veröffentlicht und dient als klassisches Beispiel einer total berechenbaren Funktion, die nicht primitiv-rekursiv ist.

Definition

Die Ackermannfunktion ist für nichtnegative ganze Zahlen m und n rekursiv definiert durch:

  • A(0, n) = n + 1
  • A(m + 1, 0) = A(m, 1)
  • A(m + 1, n + 1) = A(m, A(m + 1, n))

Wachstum

Die Funktion wächst schneller als jede primitiv-rekursive Funktion. Schon kleine Argumente führen zu enormen Werten: A(4, 2) ist eine Zahl mit 19.729 Dezimalstellen. A(1, n) entspricht n + 2, A(2, n) entspricht 2n + 3, A(3, n) entspricht 2n+3 − 3. Für A(4, n) ergibt sich eine Turm-Potenz von Zweien.

Bedeutung

Ackermann zeigte mit dieser Funktion, dass nicht jede berechenbare Funktion primitiv-rekursiv ist. In der Komplexitätstheorie dient sie außerdem zur Beschreibung der Laufzeit bestimmter Algorithmen; so tritt die inverse Ackermannfunktion in der Analyse der disjunkten Mengengevereinigung (Union-Find) auf. Eine vereinfachte, einstellige Variante stammt von Rózsa Péter.
