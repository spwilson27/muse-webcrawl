Verteilungsfunktion

Die Verteilungsfunktion (englisch cumulative distribution function, CDF) einer reellen Zufallsvariablen X ist eine Funktion, die für jeden Wert x die Wahrscheinlichkeit angibt, dass X einen Wert kleiner oder gleich x annimmt: F(x) = P(X ≤ x). Sie beschreibt die Verteilung der Zufallsvariablen vollständig.

Eigenschaften

Jede Verteilungsfunktion ist monoton wachsend, rechtsseitig stetig und besitzt die Grenzwerte 0 für x → −∞ und 1 für x → +∞. Umgekehrt ist jede Funktion mit diesen Eigenschaften die Verteilungsfunktion einer Zufallsvariablen. Die Wahrscheinlichkeit, dass X in einem Intervall (a, b] liegt, beträgt F(b) − F(a).

Zusammenhang mit der Dichte

Besitzt die Zufallsvariable eine Wahrscheinlichkeitsdichte f, so gilt F(x) = ∫−∞x f(t) dt, und an den Stetigkeitsstellen von f ist F′(x) = f(x). Bei diskreten Verteilungen ist die Verteilungsfunktion eine Treppenfunktion mit Sprüngen an den Stellen positiver Wahrscheinlichkeit. Die empirische Verteilungsfunktion einer Stichprobe schätzt die unbekannte Verteilungsfunktion; nach dem Satz von Glivenko-Cantelli konvergiert sie gleichmäßig gegen diese.
