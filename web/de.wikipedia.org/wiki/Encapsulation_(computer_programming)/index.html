Datenkapselung (Programmierung)

Datenkapselung (englisch encapsulation) ist ein Grundprinzip der objektorientierten Programmierung, bei dem Daten (Attribute) und die darauf operierenden Methoden in einer Einheit – einer Klasse beziehungsweise einem Objekt – zusammengefasst werden und der direkte Zugriff von außen auf die internen Daten eingeschränkt wird. Der Zugriff erfolgt stattdessen über eine definierte Schnittstelle, etwa über Getter- und Setter-Methoden.

Ziele

  • Information Hiding: Die interne Repräsentation bleibt verborgen; Änderungen an ihr wirken sich nicht auf den nutzenden Code aus, solange die Schnittstelle gleich bleibt.
  • Invarianten wahren: Das Objekt kann sicherstellen, dass seine Daten stets in einem gültigen Zustand bleiben, weil jede Änderung über kontrollierte Methoden läuft.
  • Modularität: Gekapselte Einheiten lassen sich unabhängig entwickeln, testen und austauschen.

Umsetzung

Viele Sprachen bieten Zugriffsmodifikatoren wie private, protected und public (z. B. Java, C#, C++). In Python wird Kapselung eher durch Konvention (Namenspräfixe wie ein einzelner oder doppelter Unterstrich) und über Properties erreicht.

Abgrenzung

Kapselung wird gelegentlich mit Datenabstraktion gleichgesetzt, bezeichnet aber genauer das Zusammenfassen und Zugangsbeschränken, während Abstraktion das Weglassen irrelevanter Details meint.
