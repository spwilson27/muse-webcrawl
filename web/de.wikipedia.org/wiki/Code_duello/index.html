Code Duello

Der Code Duello ist eine Sammlung von Regeln für das Duell, die 1777 auf der Clonmel Summer Assizes in der Grafschaft Tipperary (Irland) von einer Versammlung irischer Gentlemen verabschiedet wurde. Er gilt als bekanntester Duellkodex der englischsprachigen Welt.

Inhalt

Der Kodex umfasst 26 Regeln, die den Ablauf eines Ehrkonflikts detailliert festlegen: die Rangfolge von Beleidigungen, die Pflicht zur Entschuldigung bei geringfügigen Anlässen, die Aufgaben der Sekundanten, die Waffenwahl und die Bedingungen, unter denen ein Duell ehrenvoll beendet werden kann, etwa nach dem ersten Blut oder einem Fehlschuss. Sekundanten sollten zunächst alles versuchen, den Streit beizulegen.

Verbreitung

Der Code Duello verbreitete sich in Großbritannien und besonders in den Vereinigten Staaten; in den Südstaaten wurde er in zahlreichen Ausgaben gedruckt, etwa 1838 als Grundlage der „Code of Honor" des früheren Gouverneurs von South Carolina, John Lyde Wilson.
