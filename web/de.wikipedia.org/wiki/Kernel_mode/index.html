Kernelmodus

Der Kernelmodus (englisch kernel mode, auch Supervisor-Modus oder privilegierter Modus) ist ein Ausführungsmodus der CPU, in dem der Code des Betriebssystemkerns mit uneingeschränkten Rechten läuft. Er steht im Gegensatz zum eingeschränkten Benutzermodus (user mode), in dem Anwendungsprogramme ausgeführt werden.

Schutzringe

Auf x86-Prozessoren entspricht der Kernelmodus dem Ring 0 der Schutzring-Architektur, der Benutzermodus dem Ring 3. Im Kernelmodus darf der Code beliebige Speicherbereiche ansprechen, alle Prozessorbefehle ausführen und direkt auf die Hardware zugreifen. Im Benutzermodus sind Speicherzugriffe auf den eigenen Adressraum beschränkt und privilegierte Befehle verboten; ein Verstoß löst eine Ausnahme aus.

Moduswechsel

Anwendungen fordern Dienste des Kernels über Systemaufrufe an. Dabei wechselt die CPU kontrolliert in den Kernelmodus, der Kernel prüft die Anfrage, führt sie aus und kehrt anschließend in den Benutzermodus zurück. Auch Interrupts und Ausnahmen (etwa Seitenfehler) führen zu einem Wechsel in den Kernelmodus.

Bedeutung

Die strikte Trennung schützt das System: Ein fehlerhaftes oder bösartiges Programm kann im Benutzermodus weder andere Prozesse noch den Kernel selbst direkt beeinträchtigen. Umgekehrt kann ein Fehler im Kernelmodus – etwa in einem Gerätetreiber – das gesamte System zum Absturz bringen, weshalb möglichst wenig Code mit Kernelrechten laufen sollte.
