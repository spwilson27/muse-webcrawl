Quotientengruppe

In der Gruppentheorie, einem Teilgebiet der Mathematik, ist eine Quotientengruppe (auch Faktorgruppe) eine Gruppe, die aus den Nebenklassen eines Normalteilers einer Gruppe gebildet wird. Man schreibt sie als G/N, gesprochen „G modulo N“.

Definition

Sei G eine Gruppe und N ein Normalteiler von G. Die Menge der Nebenklassen G/N = {gN : g ∈ G} bildet mit der Verknüpfung (aN)·(bN) = (ab)N eine Gruppe, die Quotientengruppe. Die Voraussetzung, dass N Normalteiler ist, sichert die Wohldefiniertheit dieser Verknüpfung. Das neutrale Element ist die Klasse N selbst, das Inverse von gN ist g−1N.

Beispiele

  • Die ganzen Zahlen mit der Addition, modulo den Vielfachen von n, ergeben die zyklische Gruppe Z/nZ.
  • Die Gruppe der Drehungen einer Ebene modulo der vollen Umdrehungen beschreibt Winkelklassen.

Homomorphiesatz

Der Homomorphiesatz besagt, dass das Bild eines Gruppenhomomorphismus isomorph zur Quotientengruppe nach dem Kern des Homomorphismus ist. Quotientengruppen sind daher untrennbar mit der Klassifikation von Gruppen und ihren Homomorphismen verbunden.
