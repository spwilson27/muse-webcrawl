PHP

Entwickler: Rasmus Lerdorf (1995), heute PHP Group

Aktuelle Version: PHP 8.x

Paradigma: imperativ, objektorientiert, prozedural

Lizenz: PHP-Lizenz

Dateiendungen: .php

PHP (rekursives Akronym für PHP: Hypertext Preprocessor, ursprünglich Personal Home Page) ist eine weit verbreitete, freie Skriptsprache, die hauptsächlich zur Erstellung dynamischer Webseiten und Webanwendungen eingesetzt wird. PHP-Code wird üblicherweise auf dem Webserver ausgeführt und in HTML eingebettet.

Geschichte

PHP wurde 1995 von Rasmus Lerdorf als Sammlung von Perl-/C-Programmen („Personal Home Page Tools“) veröffentlicht. Mit der 1997/98 von Zeev Suraski und Andi Gutmans neu geschriebenen Version PHP 3 begann der Durchbruch; die Zend Engine bildet seit PHP 4 (2000) den Kern der Sprache. PHP 5 (2004) brachte ein stark verbessertes Objektmodell, PHP 7 (2015) eine deutliche Performancesteigerung und PHP 8 (2020) unter anderem einen Just-in-time-Compiler.

Einsatz und Verbreitung

PHP läuft auf der Mehrheit aller Websites mit bekannter serverseitiger Programmiersprache. Bekannte in PHP geschriebene Systeme sind WordPress, MediaWiki (die Software der Wikipedia), Drupal, Joomla und Magento; auch Facebook begann als PHP-Anwendung. Paketverwaltung erfolgt über Composer; große Frameworks sind Laravel und Symfony. PHP wird als Open Source von der PHP Group und einer weltweiten Entwicklergemeinschaft gepflegt.
