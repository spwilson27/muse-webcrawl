Anonyme Funktion

Eine anonyme Funktion (auch Lambda-Ausdruck oder function literal) ist in der Programmierung eine Funktion, die bei ihrer Definition keinen Namen erhält. Anonyme Funktionen werden häufig als Argumente an Funktionen höherer Ordnung übergeben oder zur Erzeugung von Closures verwendet.

Hintergrund

Der Begriff geht auf den Lambda-Kalkül von Alonzo Church zurück, in dem Funktionen mit dem griechischen Buchstaben Lambda (λ) notiert werden. Viele moderne Sprachen übernahmen die Schreibweise: In Python lautet das Schlüsselwort lambda, in JavaScript verwendet man Pfeilfunktionen (=>), in C# ebenfalls =>, in Java seit Version 8 ->; Lisp, Scheme, Haskell, Ruby und viele weitere Sprachen unterstützen Lambda-Ausdrücke nativ.

Verwendung

Typische Einsatzgebiete sind kurze Rückruffunktionen (Callbacks), Sortierkriterien, das Filtern und Transformieren von Daten (map/filter/reduce) und Ereignisbehandlung. Closures entstehen, wenn eine anonyme Funktion auf Variablen aus ihrer umgebenden Umgebung zugreift und diese „einschließt“.
