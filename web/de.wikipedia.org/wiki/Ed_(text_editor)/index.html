ed (Texteditor)


Eine ed-Sitzung an einem klassischen Unix-Terminal.

ed ist ein zeilenorientierter Texteditor, der Anfang der 1970er Jahre von Ken Thompson für Unix geschrieben wurde. Er geht auf den Editor QED zurück und war auf frühen Unix-Systemen der einzige verfügbare Editor. Der Name wird gewöhnlich als eine Silbe oder buchstabiert („e-d“) ausgesprochen.

Bedienung

ed lädt eine Datei in einen Puffer und nimmt Befehle von der Standardeingabe entgegen. Befehle wie a (append, Anhängen), d (delete, Löschen), p (print, Ausgeben) und s (substitute, Ersetzen) wirken auf adressierte Zeilen. Adressen können Zeilennummern, die aktuelle Zeile (.), die letzte Zeile ($) oder Suchmuster in regulären Ausdrücken sein. Zwei Modi werden unterschieden: der Befehlsmodus und der Eingabemodus.

Einfluss

ed begründete die Syntax regulärer Ausdrücke, wie sie heute in vielen Sprachen und Werkzeugen verwendet wird. Aus ihm hervorgegangene Befehle finden sich in grep (ursprünglich das ed-Kommando g/re/p), sed und dem ex-Modus von vi wieder. Trotz seiner Spartanität ist ed bis heute Bestandteil aller POSIX-konformen Systeme und wird gelegentlich zur Bearbeitung von Dateien auf Systemen ohne grafische Oberfläche oder in Rettungsumgebungen genutzt.
