Extensible Application Markup Language

Die Extensible Application Markup Language (XAML, ausgesprochen „Zammel“) ist eine von Microsoft entwickelte, auf XML basierende deklarative Auszeichnungssprache, mit der Benutzeroberflächen und Objektstrukturen beschrieben werden. Sie wurde mit der Windows Presentation Foundation (WPF) im Rahmen von .NET Framework 3.0 eingeführt.

Konzept

In XAML wird jedes Element auf eine Klasse und jedes Attribut auf eine Eigenschaft oder ein Ereignis dieser Klasse abgebildet. Dadurch lassen sich Fenster, Steuerelemente, Layouts, Styles und Datenbindungen deklarativ beschreiben, während die Programmlogik im sogenannten Code-Behind in Sprachen wie C# oder Visual Basic steht. Diese Trennung soll die Zusammenarbeit von Entwicklern und Oberflächendesignern erleichtern; Werkzeuge wie Microsoft Expression Blend und der Designer der Entwicklungsumgebung Visual Studio bearbeiten XAML visuell.

Einsatzgebiete

XAML wird neben WPF auch in Silverlight, der Universal Windows Platform (UWP), der Windows App SDK (WinUI), .NET MAUI und Xamarin.Forms zur Beschreibung von Oberflächen verwendet. Da XAML allgemein Objektdiagramme instanziieren kann, sind auch andere Anwendungen wie die Beschreibung von Workflows möglich. Von Adobe Flex (MXML) und anderen deklarativen UI-Sprachen unterscheidet sich XAML durch die enge Bindung an das .NET-Typsystem.
