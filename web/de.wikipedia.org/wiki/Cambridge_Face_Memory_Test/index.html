Cambridge Face Memory Test

Der Cambridge Face Memory Test (CFMT) ist ein psychologischer Test zur Messung der Fähigkeit, Gesichter zu erkennen und sich an sie zu erinnern. Er wurde 2006 von den Forschern Brad Duchaine und Ken Nakayama entwickelt, um Personen mit Prosopagnosie (Gesichtsblindheit) zu identifizieren und die Gesichtererkennung in der Allgemeinbevölkerung zu untersuchen.

Ablauf

Der Test besteht aus mehreren Phasen. Zunächst werden den Versuchspersonen sechs Zielgesichter aus verschiedenen Blickwinkeln gezeigt, die sie sich einprägen sollen. Anschließend folgen 72 Testdurchgänge, in denen jeweils drei Gesichter präsentiert werden, von denen eines ein zuvor gelerntes Zielgesicht ist. Die späteren Phasen sind schwieriger, weil die Bilder unter veränderten Lichtbedingungen und Blickwinkeln gezeigt und zusätzlich mit visuellem Rauschen überlagert werden.

Anwendung

Der CFMT gilt als zuverlässiges Instrument zur Diagnose der entwicklungsbedingten Prosopagnosie. Personen mit dieser Störung erzielen typischerweise deutlich unterdurchschnittliche Ergebnisse. Umgekehrt wurde der Test auch zur Identifizierung sogenannter „Super-Recognizer“ eingesetzt – Menschen mit außergewöhnlich guter Gesichtererkennung.

Eine erweiterte Version, der Cambridge Face Memory Test Long Form (CFMT+), enthält zusätzliche, schwierigere Durchgänge und eignet sich besser zur Messung im oberen Leistungsbereich.
