Dynamisches Array

Aus Wikipedia, der freien Enzyklopädie

Ein dynamisches Array (englisch dynamic array, auch array list oder growable array) ist eine Datenstruktur der Informatik, die wie ein Array wahlfreien Zugriff auf Elemente in konstanter Zeit bietet, deren Größe sich aber zur Laufzeit verändern kann. Dynamische Arrays gehören zu den am häufigsten verwendeten Datenstrukturen überhaupt.

Funktionsweise

Intern verwaltet ein dynamisches Array einen zusammenhängenden Speicherblock mit einer bestimmten Kapazität, die größer oder gleich der aktuellen Größe (Anzahl der Elemente) ist. Reicht die Kapazität beim Anhängen eines Elements nicht mehr aus, wird ein größerer Speicherblock angelegt – üblicherweise mit der doppelten Kapazität –, die vorhandenen Elemente werden kopiert und der alte Block freigegeben.

Durch dieses geometrische Wachstum besitzt das Einfügen am Ende trotz gelegentlicher teurer Kopiervorgänge eine amortisierte Laufzeit von O(1). Der Zugriff über einen Index kostet ebenfalls O(1), während Einfügen und Löschen in der Mitte wegen des Verschiebens der nachfolgenden Elemente O(n) kostet.

Implementierungen

Nahezu jede verbreitete Programmiersprache stellt dynamische Arrays bereit, etwa als std::vector in C++, ArrayList in Java, List<T> in C# oder als eingebaute Liste in Python. Der Wachstumsfaktor variiert je nach Implementierung zwischen 1,5 und 2.

Abgrenzung

Gegenüber verketteten Listen bieten dynamische Arrays bessere Cache-Lokalität und konstanten Indexzugriff, benötigen dafür aber zusammenhängenden Speicher und erzeugen Kopieraufwand beim Wachsen. Eine verwandte Struktur ist das Gap-Buffer, das bei Texteditoren eingesetzt wird.
