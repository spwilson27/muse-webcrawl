Windows Media Foundation

Media Foundation ist eine Multimedia-Architektur von Microsoft für das Betriebssystem Windows. Sie wurde mit Windows Vista eingeführt und löste schrittweise die ältere DirectShow-Technik als Grundlage für die Wiedergabe und Verarbeitung digitaler Medien ab.

Architektur

Die Architektur besteht aus einer Pipeline, in der Quellen (Sources), Transformationen (Media Foundation Transforms, etwa Codecs) und Senken (Sinks) Mediendaten verarbeiten. Sie unterstützt den Schutz digitaler Inhalte über die Protected Media Path-Umgebung und wird vor allem in Anwendungen für Video- und Audiowiedergabe, Streaming und Aufzeichnung genutzt.

Anwendung

Media Foundation bildet die Grundlage zahlreicher Windows-Anwendungen und moderner Browser unter Windows. Entwickler greifen über COM-Schnittstellen in C++ oder über verwaltete APIs darauf zu.
