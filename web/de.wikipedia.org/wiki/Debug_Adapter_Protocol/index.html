Debug Adapter Protocol

Das Debug Adapter Protocol (DAP) ist ein von Microsoft entwickeltes, offenes Kommunikationsprotokoll, das die Interaktion zwischen Entwicklungsumgebungen (IDEs) und Debuggern standardisiert. Es wurde im Umfeld von Visual Studio Code entwickelt und 2016 veröffentlicht.

Funktionsweise

Das Protokoll definiert ein abstraktes Nachrichtenformat auf JSON-Basis zwischen einem Client (der IDE) und einem Debug-Adapter, der als Vermittler zum eigentlichen Debugger der Zielplattform fungiert. Anfragen (requests), Antworten (responses) und Ereignisse (events) werden sequenznummeriert ausgetauscht. Typische Operationen sind das Setzen von Haltepunkten, das schrittweise Ausführen von Code, das Auswerten von Ausdrücken und das Inspizieren von Variablen und Aufrufstapeln.

Verbreitung

Das DAP folgt demselben Architekturprinzip wie das Language Server Protocol (LSP): Statt dass jede IDE jeden Debugger nativ unterstützen muss, genügt ein Adapter pro Debugger. Dadurch unterstützen zahlreiche Editoren und Sprachen – darunter Python, Java, Go, Rust und C/C++ – ein einheitliches Debugging-Modell. Die Spezifikation wird offen auf GitHub gepflegt.
