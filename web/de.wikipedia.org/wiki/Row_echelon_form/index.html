Zeilenstufenform

Zeilenstufenform

Englisch: Row Echelon Form

Gebiet: Lineare Algebra

Erreichbar durch: Gaußsches Eliminationsverfahren

Eine Matrix befindet sich in Zeilenstufenform (englisch row echelon form), wenn sie folgende Bedingungen erfüllt: Alle Nullzeilen stehen unterhalb aller Zeilen, die von null verschieden sind, und das erste von null verschiedene Element jeder Zeile (der sogenannte Pivot oder das führende Element) steht weiter rechts als das Pivotelement der darüberliegenden Zeile. Dadurch entsteht unterhalb der Pivots eine Treppen- beziehungsweise Stufenstruktur aus Nullen.

Reduzierte Zeilenstufenform

Die reduzierte Zeilenstufenform (englisch reduced row echelon form) geht darüber hinaus: Jedes Pivotelement hat den Wert 1, und in jeder Pivotspalte ist das Pivotelement der einzige von null verschiedene Eintrag. Während die Zeilenstufenform einer Matrix nicht eindeutig ist, ist die reduzierte Zeilenstufenform, die man mit dem Gauß-Jordan-Verfahren erhält, für jede Matrix eindeutig bestimmt.

Anwendung

Jede Matrix lässt sich durch elementare Zeilenumformungen – Vertauschen von Zeilen, Multiplikation einer Zeile mit einem Skalar ungleich null und Addition eines Vielfachen einer Zeile zu einer anderen – in Zeilenstufenform überführen, ohne dass sich die Lösungsmenge des zugehörigen linearen Gleichungssystems ändert. In dieser Form lassen sich die Lösungen durch Rückwärtseinsetzen bestimmen. Zudem entspricht die Anzahl der Pivots dem Rang der Matrix, und aus der Stufenform ist unmittelbar ablesbar, ob ein Gleichungssystem keine, genau eine oder unendlich viele Lösungen besitzt.
