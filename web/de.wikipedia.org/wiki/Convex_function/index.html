Konvexe Funktion

In der Mathematik heißt eine reellwertige Funktion konvex, wenn ihr Graph unterhalb jeder Verbindungsstrecke zweier seiner Punkte liegt – äquivalent, wenn ihr Epigraph eine konvexe Menge ist. Konvexe Funktionen sind der zentrale Untersuchungsgegenstand der konvexen Optimierung, weil bei ihnen jedes lokale Minimum zugleich ein globales Minimum ist.

Definition

Sei D eine konvexe Teilmenge eines reellen Vektorraums. Eine Funktion f : D → ℝ heißt konvex, wenn für alle x, y ∈ D und alle λ ∈ [0, 1] gilt:

f(λx + (1 − λ)y) ≤ λf(x) + (1 − λ)f(y).

Gilt hier die strikte Ungleichung für x ≠ y und λ ∈ (0, 1), so heißt f strikt konvex. Eine Funktion heißt konkav, wenn ihr Negatives konvex ist.

Kriterien

  • Eine differenzierbare Funktion ist genau dann konvex, wenn ihr Graph oberhalb jeder ihrer Tangenten liegt: f(y) ≥ f(x) + ⟨∇f(x), y − x⟩.
  • Eine zweimal differenzierbare Funktion einer Variablen ist genau dann konvex, wenn ihre zweite Ableitung überall nichtnegativ ist.
  • Im Mehrdimensionalen ist eine zweimal differenzierbare Funktion genau dann konvex, wenn ihre Hesse-Matrix überall positiv semidefinit ist.

Beispiele

Konvex sind unter anderem die Exponentialfunktion, die Betragsfunktion, quadratische Formen mit positiv semidefiniter Matrix, die Normen in normierten Räumen sowie die negative Entropiefunktion. Auch das Maximum beliebig vieler konvexer Funktionen ist konvex.
