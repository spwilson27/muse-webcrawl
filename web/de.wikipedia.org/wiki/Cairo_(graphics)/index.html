Cairo (Grafikbibliothek)

EntwicklerKeith Packard, Carl Worth u. a.
Erstveröffentlichung2003
ProgrammierspracheC
LizenzLGPL 2.1 / MPL 1.1
Kategorie2D-Grafikbibliothek

Cairo ist eine freie Programmbibliothek für zweidimensionale Vektorgrafiken. Sie stellt ein geräteunabhängiges API bereit, mit dem Zeichenbefehle auf verschiedene Ausgabemedien übertragen werden können – etwa Bildschirmfenster, PDF-, PostScript- und SVG-Dateien oder Bildpuffer im Speicher.

Geschichte

Das Projekt wurde um 2000 von Keith Packard und Carl Worth zunächst unter dem Namen Xr (für das X Window System) begonnen und später in Cairo umbenannt. Die erste stabile Version 1.0 erschien 2005.

Technik und Verwendung

Das Zeichenmodell von Cairo lehnt sich an PostScript und PDF an: Pfade werden aufgebaut und anschließend gestrichen (stroke) oder gefüllt (fill); hinzu kommen Transformationen, Farbverläufe und Alpha-Komposition. Cairo wird von zahlreichen Projekten eingesetzt, unter anderem von GTK, dem Browser Firefox, der Schriftbibliothek Pango (für Text) sowie von Poppler und Inkscape. Für viele Sprachen – darunter Python (pycairo), Rust und C++ – existieren Anbindungen.
