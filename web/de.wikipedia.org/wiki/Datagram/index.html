Datagramm

Ein Datagramm ist in der Nachrichtentechnik eine in sich geschlossene, unabhängige Dateneinheit, die alle Informationen enthält, um über ein paketvermitteltes Netz vom Sender zum Empfänger zu gelangen, ohne dass zuvor eine Verbindung aufgebaut werden muss. Der Begriff wurde von den Worten data und Telegramm abgeleitet.

Eigenschaften

Der Versand von Datagrammen ist verbindungslos: Jedes Datagramm enthält die vollständige Zieladresse und wird unabhängig von anderen weitergeleitet. Dadurch können Datagramme unterschiedliche Wege nehmen, in veränderter Reihenfolge eintreffen, verloren gehen oder dupliziert werden; Zuverlässigkeit muss gegebenenfalls die Anwendung oder ein darüberliegendes Protokoll herstellen.

Verwendung

Das Internet Protocol (IP) arbeitet mit Datagrammen: Ein IP-Paket wird auch als IP-Datagramm bezeichnet. Auf der Transportschicht stellt das User Datagram Protocol (UDP) einen verbindungslosen Dienst bereit, der für zeitkritische oder einfache Dienste wie DNS-Anfragen, Sprach- und Videoübertragung oder Onlinespiele genutzt wird. Die gesicherte Variante DTLS schützt Datagrammverkehr durch Verschlüsselung.
