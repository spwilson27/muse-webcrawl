Glomeruläre Filtrationsrate

Die glomeruläre Filtrationsrate (GFR) bezeichnet das Volumen an Primärharn, das pro Zeiteinheit von allen Glomeruli beider Nieren filtriert wird. Sie ist die wichtigste Größe zur Beurteilung der Nierenfunktion. Bei einem gesunden jungen Erwachsenen beträgt sie etwa 120 ml/min bezogen auf eine Körperoberfläche von 1,73 m², entsprechend rund 170 Litern Primärharn pro Tag.

Bestimmung

Die exakte Messung erfolgt über die Clearance von Substanzen, die frei filtriert und weder sezerniert noch rückresorbiert werden, klassisch Inulin; in der Praxis werden auch Iohexol oder radioaktive Marker verwendet. Im klinischen Alltag wird die GFR meist aus dem Serumkreatinin geschätzt (eGFR), etwa mit der CKD-EPI-Formel, die neben dem Kreatinin Alter und Geschlecht berücksichtigt. Auch Cystatin C kann zur Schätzung herangezogen werden.

Klinische Bedeutung

Die GFR dient der Stadieneinteilung der chronischen Nierenerkrankung: Stadium G1 entspricht einer GFR über 90, G5 (Nierenversagen) einer GFR unter 15 ml/min/1,73 m². Mit dem Alter sinkt die GFR physiologisch ab.
