Wurzelkriterium

Das Wurzelkriterium (englisch root test) ist ein Konvergenzkriterium der Analysis für unendliche Reihen. Es geht auf Augustin-Louis Cauchy zurück und wird daher auch als Cauchysches Wurzelkriterium bezeichnet.

Aussage

Für eine Reihe mit Gliedern an betrachtet man den Limes superior der n-ten Wurzeln der Beträge der Glieder. Ist dieser Wert kleiner als 1, so konvergiert die Reihe absolut; ist er größer als 1, so divergiert die Reihe. Im Grenzfall des Wertes 1 liefert das Kriterium keine Aussage, und es müssen feinere Kriterien herangezogen werden.

Vergleich mit dem Quotientenkriterium

Das Wurzelkriterium ist stärker als das Quotientenkriterium: Liefert das Quotientenkriterium eine Entscheidung, so auch das Wurzelkriterium, aber nicht umgekehrt. Besonders geeignet ist es für Reihen, deren Glieder n-te Potenzen enthalten, sowie zur Bestimmung des Konvergenzradius von Potenzreihen (Formel von Cauchy-Hadamard).

Beispiel

Bei der geometrischen Reihe ergibt die n-te Wurzel der Glieder unmittelbar den Quotienten; das Kriterium reproduziert so die bekannte Bedingung, dass die Reihe für Beträge kleiner als 1 konvergiert.
