Integrierte Entwicklungsumgebung

Eine integrierte Entwicklungsumgebung (englisch integrated development environment, kurz IDE) ist eine Software, die Programmierern die wesentlichen Werkzeuge zur Softwareentwicklung unter einer gemeinsamen Oberfläche bereitstellt. Dazu gehören typischerweise ein Quelltexteditor mit Syntaxhervorhebung und Autovervollständigung, Compiler oder Interpreter, ein Debugger sowie Werkzeuge zur Versionsverwaltung und zum Erstellen der fertigen Programme.

Merkmale

Moderne IDEs unterstützen das Refactoring von Code, die Navigation in großen Projekten, die Einbindung von Bibliotheken und Frameworks sowie Tests. Viele Umgebungen lassen sich über Plug-ins erweitern und decken mehrere Programmiersprachen ab.

Beispiele

Verbreitete integrierte Entwicklungsumgebungen sind Eclipse und IntelliJ IDEA für Java, Microsoft Visual Studio und Visual Studio Code für zahlreiche Sprachen, Xcode für die Apple-Plattformen, Android Studio für Android sowie PyCharm für Python. Frühe einflussreiche Systeme waren Turbo Pascal und die Smalltalk-Umgebungen der 1980er Jahre, die viele der heute üblichen Konzepte wie interaktives Debuggen prägten.
