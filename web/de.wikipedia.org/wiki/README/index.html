README

Eine README-Datei (englisch für „lies mich“) ist eine Textdatei, die einem Softwarepaket, einem Quelltextarchiv oder einem sonstigen Dateiverzeichnis beigefügt wird und wichtige Informationen über dessen Inhalt enthält. Sie soll der ersten Datei sein, die ein Nutzer öffnet, um sich einen Überblick zu verschaffen.

Inhalt

Eine README-Datei enthält typischerweise eine Beschreibung des Projekts oder der Software, Installationsanweisungen, Hinweise zur Verwendung, Angaben zu Lizenz und Urheberschaft sowie gegebenenfalls Verweise auf weiterführende Dokumentation. In der Softwareentwicklung ist sie häufig die erste Anlaufstelle für neue Mitwirkende.

Formen und Formate

Klassischerweise liegt die README als reine Textdatei ohne Dateiendung oder mit der Endung .txt vor. Auf Plattformen wie GitHub wird sie zumeist in Markdown verfasst (Dateiname README.md) und formatiert auf der Projektseite angezeigt. Üblich sind daneben Namen in Großbuchstaben wie README, die dafür sorgen, dass die Datei in alphabetischen Verzeichnislisten weit oben erscheint.

Geschichte

Die Konvention geht auf die Frühzeit der Softwareentwicklung zurück, in der Begleittexte auf Lochkartenbündeln oder in Softwarearchiven der 1970er-Jahre Hinweise für die Benutzer enthielten. Mit der Verbreitung von Open-Source-Software wurde die README-Datei zu einem festen Bestandteil nahezu jedes Softwareprojekts.

Verwandte Dateien

  • CHANGELOG – Auflistung der Änderungen zwischen Versionen
  • INSTALL – Installationsanleitung
  • LICENSE – Lizenzbedingungen
  • AUTHORS – Liste der Autoren
