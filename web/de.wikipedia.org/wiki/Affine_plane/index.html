Affine Ebene


Zweidimensionaler affiner Raum und axiomatische Verallgemeinerung

Eine affine Ebene ist in der Geometrie ein zweidimensionaler affiner Raum. Axiomatisch gefasst bezeichnet der Begriff eine Inzidenzstruktur aus Punkten und Geraden, in der je zwei Punkte eine eindeutige Verbindungsgerade besitzen und das Parallelenaxiom gilt.

Axiome

  • Zu je zwei verschiedenen Punkten gibt es genau eine Gerade, die beide enthält.
  • Zu einer Geraden und einem Punkt außerhalb der Geraden gibt es genau eine Parallele durch den Punkt.
  • Es existieren drei nicht kollineare Punkte.

Beispiele

Das Standardmodell ist die Ebene über einem Körper, etwa die reelle Ebene ℝ². Endliche affine Ebenen existieren zur Ordnung q, wenn q eine Primzahlpotenz ist; eine solche Ebene hat q² Punkte und auf jeder Geraden q Punkte. Darüber hinaus existieren nichtdesarguessche affine Ebenen, die nicht über einem Körper koordinatisiert werden können.

Zusammenhang mit projektiven Ebenen

Entfernt man aus einer projektiven Ebene eine Gerade samt ihrer Punkte, so erhält man eine affine Ebene. Umgekehrt lässt sich jede affine Ebene durch Hinzufügen einer Ferngeraden zu einer projektiven Ebene vervollständigen.
