Buffer Cache

Der Buffer Cache ist ein Bereich des Hauptspeichers, in dem ein Betriebssystem Kopien von Datenblöcken eines Massenspeichers (Festplatte, SSD) vorhält, um langsame Zugriffe auf das Speichermedium zu vermeiden. Er gehört zu den ältesten Caching-Mechanismen der Unix-Systeme und ist konzeptionell eng mit dem Page Cache moderner Betriebssysteme verwandt.

Arbeitsweise

Beim Lesen eines Datenblocks prüft der Kernel zunächst, ob sich der Block bereits im Buffer Cache befindet (cache hit); dann kann er direkt aus dem RAM geliefert werden. Andernfalls wird er vom Datenträger gelesen und im Cache abgelegt. Schreibzugriffe werden häufig zunächst nur im Cache vermerkt (write-back) und erst zeitverzögert auf den Datenträger übertragen, was die gefühlte Schreibgeschwindigkeit deutlich erhöht, aber bei einem Systemabsturz ein Risiko für die Datenintegrität darstellt. Werkzeuge wie sync und fsync erzwingen das Ausschreiben der gepufferten Daten.

Geschichte

In klassischen Unix-Systemen verwaltete der Buffer Cache Dateisystem-Metadaten und Dateiinhalte in Blöcken fester Größe. Moderne Systeme wie Linux vereinen Buffer Cache und Page Cache weitgehend: Der Page Cache verwaltet dateiinhaltliche Seiten, während Pufferköpfe (buffer heads) den Zustand einzelner Dateisystemblöcke beschreiben. Nicht belegter Hauptspeicher wird unter Linux dynamisch als Cache verwendet und bei Bedarf von Anwendungen verdrängt, weshalb ein „voller“ Cache dort keinen Mangel an freiem Speicher bedeutet.
