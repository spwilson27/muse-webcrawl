Genetischer Fehlschluss

Der genetische Fehlschluss (englisch genetic fallacy) ist ein logischer Fehlschluss, bei dem eine Aussage oder Überzeugung allein aufgrund ihrer Herkunft, Entstehung oder Geschichte bewertet wird, anstatt ihren Inhalt sachlich zu prüfen. Der Begriff geht auf das griechische Wort genesis (Entstehung, Ursprung) zurück.

Beschreibung

Wer einen genetischen Fehlschluss begeht, nimmt an, dass der Wahrheits- oder Wertgehalt einer Aussage von der Quelle abhängt, aus der sie stammt. Die Herkunft einer Behauptung kann zwar Anlass zu kritischer Prüfung geben, sie entscheidet jedoch nicht über deren Richtigkeit. Der Fehlschluss tritt in zwei Richtungen auf:

  • Abwertung: Eine Idee wird verworfen, weil sie von einer als unseriös geltenden Quelle stammt.
  • Aufwertung: Eine Idee wird akzeptiert, weil sie aus einer als angesehen geltenden Tradition oder Autorität stammt.

Beispiele

Ein Beispiel ist die Abweisung einer wissenschaftlichen Theorie allein mit der Begründung, sie sei in einem bestimmten politischen oder religiösen Umfeld entstanden. Umgekehrt wäre es ein Fehlschluss, eine Behauptung nur deshalb für wahr zu halten, weil sie aus einem alten, ehrwürdigen Text stammt.

Verwandte Fehlschlüsse

Der genetische Fehlschluss ist verwandt mit dem Ad-hominem-Argument, bei dem eine Aussage durch einen Angriff auf die Person zurückgewiesen wird, sowie mit dem Autoritätsargument (argumentum ad verecundiam). Abzugrenzen ist er von Fällen, in denen die Herkunft einer Information tatsächlich relevant ist, etwa bei der Prüfung der Zuverlässigkeit von Quellen in der Geschichtswissenschaft.
