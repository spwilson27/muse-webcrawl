Kombination (Mathematik)

In der Kombinatorik bezeichnet eine Kombination eine Auswahl von Elementen aus einer gegebenen Menge, bei der die Reihenfolge der Auswahl keine Rolle spielt. Eine Kombination unterscheidet sich damit von einer Permutation, bei der die Anordnung der Elemente wesentlich ist.

Definition

Gegeben sei eine Menge mit n Elementen. Eine Kombination von k Elementen ist eine k-elementige Teilmenge dieser Menge. Die Anzahl der möglichen Kombinationen ohne Wiederholung wird durch den Binomialkoeffizienten „n über k“ angegeben:

C(n, k) = n! / (k! · (n − k)!)

Dabei bezeichnet n! die Fakultät von n.

Kombinationen mit Wiederholung

Darf jedes Element mehrfach ausgewählt werden, spricht man von einer Kombination mit Wiederholung. Die Anzahl solcher Auswahlen beträgt (n + k − 1 über k). Diese Situation tritt etwa beim Ziehen von Kugeln aus einer Urne mit Zurücklegen auf, wenn die Reihenfolge der gezogenen Kugeln unerheblich ist.

Beispiele

Beim Lotto „6 aus 49“ ist die Anzahl der möglichen Tipps durch den Binomialkoeffizienten (49 über 6) = 13.983.816 gegeben. Auch die Auswahl einer Delegation, eines Ausschusses oder einer Handvoll Karten aus einem Kartenspiel sind typische Anwendungen.
