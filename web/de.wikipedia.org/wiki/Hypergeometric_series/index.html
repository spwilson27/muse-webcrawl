Hypergeometrische Reihe

Eine hypergeometrische Reihe ist in der Mathematik eine Potenzreihe, bei der das Verhältnis aufeinanderfolgender Koeffizienten eine rationale Funktion des Summationsindex ist. Der Name rührt daher, dass die Reihe eine Verallgemeinerung der geometrischen Reihe darstellt, bei der dieses Verhältnis konstant ist.

Definition

Die allgemeine hypergeometrische Reihe lautet

pFq(a₁,…,ap; b₁,…,bq; z) = Σn=0∞ [(a₁)n … (ap)n / (b₁)n … (bq)n] · zn / n!

mit dem Pochhammer-Symbol (a)n = a (a + 1) … (a + n − 1). Die klassische Gaußsche Reihe ist der Fall p = 2, q = 1; ihre Summationsformel für z = 1 ist der Satz von Gauß. Weitere berühmte Summationsformeln stammen von Vandermonde, Saalschütz, Dougall und Dixon.

Geschichte

Der Begriff wurde im 17. Jahrhundert von John Wallis für eine verwandte Reihe geprägt. Systematisch untersucht wurden hypergeometrische Reihen von Euler und vor allem von Gauß in seiner Arbeit von 1813, der ersten strengen Konvergenzuntersuchung einer Reihe überhaupt.
