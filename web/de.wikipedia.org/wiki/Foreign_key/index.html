Foreign key

Ein Foreign key (deutsch Fremdschlüssel) ist im relationalen Datenbankmodell ein Attribut oder eine Attributkombination einer Tabelle, die auf den Primärschlüssel (Primary key) einer anderen – oder derselben – Tabelle verweist. Fremdschlüssel stellen Beziehungen zwischen Datensätzen her und sind die Grundlage der referenziellen Integrität.

Referenzielle Integrität

Eine Fremdschlüssel-Bedingung (FOREIGN KEY constraint) legt fest, dass jeder Wert des Fremdschlüssels entweder als Primärschlüsselwert in der referenzierten Tabelle existiert oder NULL ist. Das Datenbanksystem verhindert so „verwaiste“ Datensätze, etwa eine Bestellung, die auf einen nicht existierenden Kunden verweist. Für Änderungen und Löschungen in der referenzierten Tabelle können Verhaltensregeln definiert werden, insbesondere:

  • ON DELETE CASCADE – abhängige Datensätze werden mitgelöscht,
  • ON DELETE SET NULL – der Fremdschlüssel wird auf NULL gesetzt,
  • ON DELETE RESTRICT / NO ACTION – die Löschung wird blockiert.

Beispiel in SQL

In SQL wird ein Fremdschlüssel bei der Tabellenerstellung oder nachträglich deklariert, etwa wenn die Spalte kunden_id der Tabelle bestellung auf kunde(id) verweist. Fremdschlüssel dienen auch der Umsetzung von Beziehungstypen (1:n, m:n über Zwischentabellen) aus dem Datenmodell.
