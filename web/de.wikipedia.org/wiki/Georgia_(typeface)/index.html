Georgia (Schriftart)

KategorieSerifenschrift
EntwerferMatthew Carter
AuftraggeberMicrosoft
Veröffentlichung1996

Georgia ist eine Serifenschrift, die 1996 von Matthew Carter für die Microsoft Corporation entworfen wurde. Sie wurde speziell für gute Lesbarkeit auf Bildschirmen bei kleinen Schriftgraden optimiert und gehört zu den Core fonts for the Web.

Gestaltung

Die Georgia zeichnet sich durch eine große x-Höhe, offene Formen und kräftige Serifen aus. Ihre Ziffern sind als Mediävalziffern (Textziffern) mit Ober- und Unterlängen gestaltet, was sie von vielen anderen Bildschirmschriften unterscheidet. Carter ließ sich von schottischen Serifen des 19. Jahrhunderts inspirieren; benannt ist die Schrift nach einer Boulevard-Schlagzeile über die angebliche Sichtung eines Außerirdischen im US-Bundesstaat Georgia.

Verwendung

Die Georgia wird mit Windows und macOS ausgeliefert und war lange eine der beliebtesten Serifenschriften im Web. Sie wurde unter anderem von der New York Times für ihren Onlineauftritt verwendet. Ergänzt wird sie durch die zur gleichen Zeit von Carter gestaltete sans-serif-Schrift Verdana.
