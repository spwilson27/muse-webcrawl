Opcode

Ein Opcode (kurz für englisch operation code) ist der Teil eines Maschinenbefehls, der festlegt, welche Operation ein Prozessor ausführen soll – etwa das Addieren zweier Werte, das Laden eines Speicherinhalts in ein Register oder einen Sprung im Programm.

Aufbau eines Maschinenbefehls

Ein vollständiger Maschinenbefehl besteht typischerweise aus dem Opcode und einem oder mehreren Operanden, die Adressen oder unmittelbare Werte angeben. Länge und Kodierung der Opcodes sind von der jeweiligen Befehlssatzarchitektur (ISA) abhängig: Einfache RISC-Architekturen verwenden überwiegend feste Befehlslängen, während komplexe Architekturen wie x86 variable Längen mit Präfixen und Escape-Sequenzen für erweiterte Opcodes nutzen.

Beispiele

Beim historischen Prozessor MOS Technology 6502 steht der Opcode 0xA9 für „LDA #“ (Lade den Akkumulator mit dem folgenden Wert), 0x00 für den Software-Interrupt BRK. In virtuellen Maschinen wie der Java Virtual Machine spricht man entsprechend von Bytecodes.
