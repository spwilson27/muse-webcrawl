Element (Mathematik)

In der Mathematik ist ein Element ein Objekt, das in einer Menge enthalten ist. Die Elementbeziehung wird mit dem Symbol ∈ (Elementzeichen) notiert: Ist x ein Element der Menge M, schreibt man x ∈ M; andernfalls x ∉ M. Der Begriff geht auf Georg Cantor, den Begründer der Mengenlehre, zurück und gehört zu den Grundbegriffen der gesamten modernen Mathematik.

Definition und Beispiele

Cantor beschrieb eine Menge als Zusammenfassung bestimmter, wohlunterschiedener Objekte der Anschauung oder des Denkens zu einem Ganzen; diese Objekte heißen die Elemente der Menge. Beispiele: Die Zahl 3 ist ein Element der Menge der natürlichen Zahlen (3 ∈ ℕ), die Zahl −1 dagegen nicht (−1 ∉ ℕ, aber −1 ∈ ℤ). Mengen können selbst Elemente anderer Mengen sein, etwa in der Potenzmenge. Die leere Menge besitzt keine Elemente.

Das Elementzeichen

Das Zeichen ∈ geht auf das griechische ε (Epsilon) zurück und wurde 1889 von Giuseppe Peano eingeführt, abgeleitet von ἐστι („est“, lateinisch „ist“). In der axiomatischen Mengenlehre, etwa der Zermelo-Fraenkel-Mengenlehre, ist die Elementbeziehung die einzige nicht definierte Grundrelation, aus der alle weiteren Begriffe aufgebaut werden.

Übertragene Bedeutung

Auch in anderen Strukturen spricht man von Elementen, etwa von den Elementen einer Gruppe, eines Vektorraums (Vektoren) oder einer Matrix (ihre Einträge). In der Gruppentheorie bezeichnet das neutrale Element dasjenige Element, das bei Verknüpfung mit einem beliebigen Element dieses unverändert lässt.
