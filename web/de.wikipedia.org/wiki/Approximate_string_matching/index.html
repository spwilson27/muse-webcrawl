Approximate String Matching

Approximate String Matching (deutsch etwa „ungefähre Zeichenkettenübereinstimmung“, auch Fuzzy String Searching) bezeichnet Verfahren der Informatik, die in einem Text Vorkommen eines Suchmusters finden, die mit dem Muster nur annähernd übereinstimmen. Es wird eingesetzt, um Tippfehler, Rechtschreibvarianten und OCR-Fehler zu tolerieren, etwa in Suchmaschinen („Meinten Sie …“), Rechtschreibprüfungen und der Bioinformatik beim Sequenzabgleich.

Abstandsmaße

Die Ähnlichkeit zweier Zeichenketten wird meist über Editierabstände gemessen. Die Levenshtein-Distanz zählt die minimale Zahl von Einfüge-, Lösch- und Ersetzungsoperationen, um eine Zeichenkette in eine andere zu überführen. Die Damerau-Levenshtein-Distanz berücksichtigt zusätzlich die Vertauschung benachbarter Zeichen. Für ein Muster der Länge m und einen Text der Länge n löst das klassische Verfahren auf Basis dynamischer Programmierung das Problem in Zeit O(nm).

Algorithmen

Effiziente Verfahren nutzen Bitparallelismus (etwa der Myers-Algorithmus), Automaten über Editiergraphen oder Indexstrukturen wie N-Gramm-Indizes und Suffixbäume. Bekannte Werkzeuge sind das Unix-Programm agrep und Bibliotheken für unscharfe Suche. In der Praxis wird oft eine maximale Fehlerzahl k vorgegeben (k-Fehler-Problem), statt den besten Treffer global zu suchen.
