Darwin Core

Darwin Core (DwC) ist ein internationaler Standard für den Austausch von Daten zur Biodiversität, insbesondere von Nachweisdaten zu Organismen (Vorkommen, Sammlungsbelege und Beobachtungen). Er wird von der Biodiversity Information Standards Organisation (TDWG) gepflegt und ratifiziert.

Inhalt

Der Standard definiert ein Glossar von Begriffen (terms) mit eindeutigen Bezeichnern, darunter scientificName, decimalLatitude, decimalLongitude, eventDate, basisOfRecord und occurrenceID. Die Begriffe sind in Klassen wie Taxon, Occurrence, Event und Location gegliedert.

Anwendung

Darwin Core ist das zentrale Austauschformat der Global Biodiversity Information Facility (GBIF), über die mehrere Milliarden Vorkommensdatensätze aus Museen, Herbarien und Beobachtungsprogrammen weltweit bereitgestellt werden. Für den Datenaustausch wird häufig das Darwin Core Archive (DwC-A) verwendet, ein Paket aus CSV-Dateien mit einer Metadatenbeschreibung.
