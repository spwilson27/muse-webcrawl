Länderspezifische Top-Level-Domain (ccTLD)

Eine länderspezifische Top-Level-Domain (englisch country code top-level domain, kurz ccTLD) ist eine zweibuchstabige Top-Level-Domain des Domain Name System (DNS), die einem Land oder Gebiet zugeordnet ist. Sie entspricht in der Regel dem Alpha-2-Code der Norm ISO 3166-1, etwa .de für Deutschland, .at für Österreich und .ch für die Schweiz.

Vergabe und Verwaltung

Die Zuteilung der ccTLDs erfolgt durch die Internet Assigned Numbers Authority (IANA). Verwaltet werden sie von nationalen Registrierungsstellen (NICs), etwa der DENIC für .de oder der Switch für .ch. Jede Registrierungsstelle setzt eigene Vergaberegeln fest; manche Domains stehen nur Einwohnern oder Unternehmen des jeweiligen Landes offen, andere werden weltweit vermarktet.

Besonderheiten

Einige kleine Staaten vermarkten ihre ccTLD international, etwa Tuvalu mit .tv, Montenegro mit .me oder Curaçao mit .cw. Die Domain .eu bezeichnet die Europäische Union. Das Vereinigte Königreich nutzt .uk, obwohl sein ISO-Code GB lautet. Historische ccTLDs wie .su (Sowjetunion) oder .yu (Jugoslawien, 2009 abgeschaltet) zeigen, dass das System politische Veränderungen nur verzögert abbildet.
