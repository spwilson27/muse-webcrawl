Binomialverteilung

Die Binomialverteilung mit den Parametern n und p ist eine diskrete Wahrscheinlichkeitsverteilung. Sie beschreibt die Wahrscheinlichkeit, in einer Folge von n unabhängigen Bernoulli-Versuchen mit Erfolgswahrscheinlichkeit p genau k Erfolge zu erzielen.

Definition

Für eine binomialverteilte Zufallsvariable X gilt:

P(X = k) = ( n über k ) · pk · (1 − p)n − k,   k = 0, 1, …, n

Dabei ist ( n über k ) der Binomialkoeffizient. Voraussetzung ist ein Zufallsexperiment, das n-mal unter denselben Bedingungen wiederholt wird, wobei jedes Teilexperiment nur die Ausgänge „Erfolg“ und „Misserfolg“ kennt (Bernoulli-Kette).

Kenngrößen

  • Erwartungswert: E(X) = n · p
  • Varianz: Var(X) = n · p · (1 − p)
  • Standardabweichung: σ = √( n · p · (1 − p) )

Beispiele

Typische Beispiele sind der mehrfache Münzwurf (n Würfe, p = 0,5 für „Kopf“), die Anzahl defekter Stücke in einer Stichprobe aus einer Produktion mit bekannter Ausschussquote oder die Anzahl der Sechser bei n Würfen mit einem Würfel (p = 1/6).

Approximationen

Für große n lässt sich die Binomialverteilung durch die Normalverteilung approximieren (Satz von Moivre-Laplace, ein Spezialfall des zentralen Grenzwertsatzes). Als Faustregel gilt die Näherung als brauchbar, wenn n·p·(1−p) > 9 ist. Für kleines p und großes n bei moderatem Produkt n·p bietet sich die Poisson-Approximation an.

Verwandte Verteilungen

Für n = 1 ergibt sich die Bernoulli-Verteilung. Die geometrische Verteilung beschreibt dagegen die Wartezeit bis zum ersten Erfolg, die negative Binomialverteilung die Wartezeit bis zum r-ten Erfolg. Die Verallgemeinerung auf mehr als zwei Ausgänge ist die Multinomialverteilung.
