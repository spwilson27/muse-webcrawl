Capo (Begriffsklärung)

Capo (italienisch für „Kopf“, „Chef“) steht für:

  • Kapodaster, eine Klemmvorrichtung für das Griffbrett von Saiteninstrumenten
  • Capo, Rangstufe bzw. Anführer einer Gruppe in Organisationen der Mafia, siehe auch Caporegime
  • „Da capo“, eine Spielanweisung in der Musik („von Anfang an“)
  • Capo, ein Kartenspiel
  • Capo d’Orlando, eine Stadt in Sizilien
  • Capò, ein historisches Längenmaß

Siehe auch:

  • Capocannoniere, Auszeichnung für den Torschützenkönig der italienischen Serie A
