Hausdorff-Dimension

Die Hausdorff-Dimension ist ein von dem Mathematiker Felix Hausdorff eingeführter Dimensionsbegriff, der die klassische, ganzzahlige Dimension auf gebrochene (fraktale) Werte verallgemeinert. Sie erlaubt es, die „Fülligkeit" beziehungsweise Rauigkeit von Mengen wie Fraktalen quantitativ zu beschreiben.

Definition

Ausgangspunkt ist das Hausdorff-Maß: Für eine Menge in einem metrischen Raum betrachtet man für jede Zahl s ≥ 0 das s-dimensionale Hausdorff-Maß. Es zeigt sich, dass es einen kritischen Wert gibt, an dem dieses Maß von unendlich auf null springt. Dieser Wert ist die Hausdorff-Dimension der Menge.

Beispiele

Für glatte geometrische Objekte stimmt die Hausdorff-Dimension mit der üblichen Dimension überein: Eine Strecke hat Dimension 1, eine Fläche Dimension 2. Die Cantor-Menge besitzt die Dimension log(2)/log(3) ≈ 0{,}631, das Sierpinski-Dreieck die Dimension log(3)/log(2) ≈ 1{,}585.

Eigenschaften

Die Hausdorff-Dimension ist monoton: Eine Teilmenge hat nie größere Dimension als die Gesamtmenge. Sie ist stabil unter abzählbaren Vereinigungen und unveränderlich unter bi-Lipschitz-Abbildungen. Für viele Fraktale stimmt sie mit der Box-Dimension überein, im Allgemeinen ist sie jedoch kleiner oder gleich dieser.
