Rainbow Table

Eine Rainbow Table (deutsch etwa „Regenbogentabelle“) ist eine in der Kryptanalyse eingesetzte Datenstruktur zum schnellen Auffinden von Klartexten zu gegebenen Hashwerten, etwa um Passwörter aus gestohlenen Passwort-Hashes wiederherzustellen. Sie geht auf eine Arbeit des Informatikers Philippe Oechslin aus dem Jahr 2003 zurück und stellt eine Weiterentwicklung der von Martin Hellman beschriebenen Zeit-Speicher-Abwägung (Time-Memory Tradeoff) dar.

Funktionsweise

Eine Rainbow Table speichert Ketten aus abwechselnden Hash- und Reduktionsfunktionen. Ausgehend von einer großen Zahl zufälliger Startwerte werden durch wiederholtes Anwenden einer Hashfunktion und verschiedener Reduktionsfunktionen Ketten gebildet. Dabei wandelt eine Reduktionsfunktion einen Hashwert in einen neuen plausiblen Klartext um. Gespeichert werden nur der Start- und der Endpunkt jeder Kette; der Speicherplatz bleibt dadurch überschaubar.

Zur Umkehrung eines gegebenen Hashwerts wird der Zielhash wiederholt reduziert und gehasht, um zu prüfen, ob ein so erzeugter Wert mit einem gespeicherten Kettenendpunkt übereinstimmt. Ist dies der Fall, wird die zugehörige Kette vom Startpunkt aus neu durchlaufen, bis der Klartext gefunden ist, dessen Hash dem Zielwert entspricht. Die verwendeten Reduktionsfunktionen wechseln von Position zu Position innerhalb der Kette, was — bildlich gesprochen — die „Farben“ des Regenbogens erklärt und Kollisionen zwischen verschiedenen Ketten reduziert.

Abwehr

Die wichtigste Gegenmaßnahme gegen Rainbow Tables ist das Salzen (engl. salt) von Passwörtern: Jedem Hash wird ein zufälliger, benutzerspezifischer Wert beigefügt, wodurch eine vorgefertigte Tabelle für jedes einzelne Passwort neu berechnet werden müsste. Zusätzlich erschweren langsame, speicherharte Hashverfahren wie bcrypt, scrypt oder Argon2 die Kettenbildung erheblich.

Anwendungsbereiche

Rainbow Tables wurden insbesondere gegen ältere, ungesalzene Hashverfahren wie LM-Hash oder MD5 eingesetzt. Heute spielen sie vor allem in der Passwortsicherheit, bei Sicherheitsüberprüfungen (Audits) und in der forensischen Analyse eine Rolle.
