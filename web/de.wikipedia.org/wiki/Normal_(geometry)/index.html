Normale (Geometrie)

In der Geometrie ist eine Normale ein geometrisches Objekt – etwa eine Gerade oder ein Vektor –, das senkrecht (orthogonal) auf einem anderen Objekt steht, etwa auf einer Kurve, einer Fläche oder einer Ebene. Die Normale in einem Punkt einer Fläche steht senkrecht auf der Tangentialebene in diesem Punkt.

Flächennormale

Für eine durch eine implizite Gleichung gegebene Fläche ist der Gradient der definierenden Funktion ein Normalenvektor. Bei parametrisch gegebenen Flächen ergibt sich die Normale aus dem Kreuzprodukt der partiellen Ableitungen der Parametrisierung. Normiert man den Normalenvektor auf die Länge eins, spricht man von einem Einheitsnormalenvektor.

Anwendungen

Flächennormalen sind von zentraler Bedeutung in der Computergrafik, etwa für Beleuchtungsberechnungen beim Shading, sowie in der Physik, zum Beispiel bei der Berechnung des Flusses eines Vektorfeldes durch eine Fläche oder bei Reflexionsgesetzen.
