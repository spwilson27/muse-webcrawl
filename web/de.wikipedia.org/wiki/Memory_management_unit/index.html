Memory Management Unit

Die Memory Management Unit (MMU, deutsch: Speicherverwaltungseinheit) ist eine Hardwarekomponente in Computern, die für die Umsetzung virtueller Speicheradressen in physische Adressen zuständig ist. Sie sitzt zwischen CPU und Arbeitsspeicher und arbeitet eng mit dem Betriebssystem zusammen.

Funktionsweise

Die MMU unterteilt den Speicher in Seiten (Pages) fester Größe, typischerweise 4 KiB. Für jeden Prozess verwaltet das Betriebssystem eine Seitentabelle, die angibt, welcher physischen Seite eine virtuelle Seite entspricht. Häufig benötigte Übersetzungen speichert die MMU in einem schnellen Zwischenspeicher, dem Translation Lookaside Buffer (TLB). Fehlt eine Seite im physischen Speicher, löst die MMU einen Seitenfehler (Page Fault) aus, woraufhin das Betriebssystem die Seite von der Festplatte nachlädt.

Speicherschutz

Neben der Adressübersetzung übernimmt die MMU den Speicherschutz: Jede Seite erhält Attribute, die festlegen, ob sie lesbar, beschreibbar oder ausführbar ist und ob der Zugriff aus dem Benutzer- oder Kernmodus erfolgen darf. Unzulässige Zugriffe führen zu einer Schutzverletzung (Segmentation Fault).
