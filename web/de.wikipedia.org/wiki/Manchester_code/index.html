Manchester-Code

Der Manchester-Code ist ein Leitungscode zur Übertragung digitaler Daten, bei dem jede Bitperiode in der Mitte einen Pegelwechsel enthält. Die Richtung dieses Wechsels bestimmt den Bitwert: Nach einer verbreiteten Konvention (IEEE 802.3) steht ein Übergang von hoch nach niedrig für eine 1 und ein Übergang von niedrig nach hoch für eine 0; die umgekehrte Festlegung geht auf G. E. Thomas zurück.

Eigenschaften

Da jedes Bit einen Übergang enthält, ist das Signal selbsttaktend: Der Empfänger kann den Bittakt aus dem Datenstrom zurückgewinnen. Zudem ist der Code gleichstromfrei, da jede Bitperiode zur Hälfte auf hohem und zur Hälfte auf niedrigem Pegel liegt. Nachteil ist der doppelte Bandbreitenbedarf gegenüber einer einfachen NRZ-Codierung, weil pro Bit zwei Signalzustände übertragen werden.

Anwendungen

Der Manchester-Code wurde im klassischen Ethernet (10 Mbit/s, IEEE 802.3) verwendet. Weitere Anwendungen sind RFID-Systeme, Infrarot-Fernbedienungen nach dem RC-5-Protokoll und die Aufzeichnung auf Magnetbänder (Phase Encoding).
