Gruppenwirkung

Eine Gruppenwirkung (englisch group action), auch Gruppenaktion oder Operation einer Gruppe, ist in der Mathematik eine Zuordnung, durch die eine Gruppe G auf einer Menge X „wirkt“, also die Elemente von X in strukturverträglicher Weise permutiert. Gruppenwirkungen sind das zentrale Werkzeug, um Symmetrien mathematischer Objekte zu beschreiben.

Definition

Eine (Links-)Wirkung einer Gruppe G auf einer Menge X ist eine Abbildung G × X → X, (g, x) ↦ g·x mit den Eigenschaften:

  • e·x = x für das neutrale Element e und alle x ∈ X.
  • (gh)·x = g·(h·x) für alle g, h ∈ G und x ∈ X.

Grundbegriffe

Die Bahn (Orbit) eines Punktes x ist die Menge aller Punkte g·x, die durch die Gruppenwirkung erreicht werden. Der Stabilisator von x besteht aus allen g mit g·x = x. Der Bahn-Stabilisator-Satz verknüpft die Größe von Bahn und Stabilisator mit der Gruppenordnung. Eine Wirkung heißt transitiv, wenn es nur eine Bahn gibt, und treu, wenn nur das neutrale Element alle Punkte festhält.

Beispiele und Anwendungen

Die symmetrische Gruppe wirkt auf den Elementen einer Menge; Drehgruppen wirken auf geometrischen Körpern; Matrizengruppen wirken auf Vektorräumen. Mit dem Lemma von Burnside und dem Abzählsatz von Pólya lassen sich kombinatorische Anzahlen symmetrischer Objekte bestimmen.
