Satz vom Maximum und Minimum

Satz vom Maximum und Minimum
EnglischExtreme value theorem
GebietAnalysis
AussageStetige Funktionen auf kompakten Intervallen nehmen Maximum und Minimum an
ZugehörigKarl Weierstraß (1860er Jahre)

Der Satz vom Maximum und Minimum, auch Satz von Weierstraß (nach Karl Weierstraß) und im Englischen extreme value theorem genannt, ist ein grundlegender Satz der Analysis. Er besagt: Eine reellwertige, stetige Funktion auf einem kompakten (abgeschlossenen und beschränkten) Intervall [a, b] ist beschränkt und nimmt ihr Maximum und ihr Minimum an.

Aussage und Bedeutung

Formal: Ist f : [a, b] → ℝ stetig, so existieren Stellen xmin, xmax ∈ [a, b] mit f(xmin) ≤ f(x) ≤ f(xmax) für alle x ∈ [a, b]. Die Aussage ist nicht selbstverständlich: Auf offenen Intervallen oder für unstetige Funktionen können Suprema existieren, ohne dass sie als Funktionswerte angenommen werden. Die Funktion f(x) = 1/x auf (0, 1] ist nicht einmal beschränkt; die Funktion f(x) = x auf [0, 1) besitzt ein Supremum, aber kein Maximum.

Beweisidee

Ein üblicher Beweis nutzt zunächst den Satz von Bolzano-Weierstraß, um die Beschränktheit zu zeigen: Wäre f unbeschränkt, existierte eine Folge mit gegen unendlich wachsenden Funktionswerten, die eine konvergente Teilfolge mit Grenzwert im Intervall besitzt – im Widerspruch zur Stetigkeit. Anschließend zeigt man mit einem ähnlichen Folgenargument, dass das Supremum der Bildmenge tatsächlich als Wert angenommen wird; für das Infimum argumentiert man analog.

Verallgemeinerungen

Der Satz verallgemeinert sich auf stetige Funktionen auf beliebigen nichtleeren kompakten Mengen in metrischen Räumen und auf halbstetige Funktionen. Er bildet die theoretische Grundlage vieler Existenzbeweise der Optimierung: Erst die Gewissheit, dass ein Optimum existiert, rechtfertigt die Suche nach ihm, etwa über die Nullstellen der Ableitung oder numerische Verfahren.
