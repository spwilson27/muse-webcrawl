Französisches Recht

Das französische Recht gehört zum romanischen Rechtskreis der kontinentaleuropäischen Civil-Law-Tradition. Geprägt wird es vor allem durch die großen Kodifikationen der Napoleonischen Zeit, insbesondere den Code civil von 1804, der das Recht zahlreicher Länder weltweit beeinflusste.

Geschichte

Vor der Revolution war Frankreich rechtlich zweigeteilt: Im Süden galt geschriebenes römisches Recht (pays de droit écrit), im Norden Gewohnheitsrecht (pays de droit coutumier). Die Revolution und Napoleon schufen einheitliche Gesetzbücher: den Code civil (1804), den Code de commerce (1807) und den Code pénal (1810). Der Code civil sicherte Rechtsgleichheit, Eigentum und Vertragsfreiheit und wurde in vielen Ländern Europas, Lateinamerikas und darüber hinaus zum Vorbild.

Struktur

Kennzeichnend ist die strenge Trennung von ordentlicher Gerichtsbarkeit und Verwaltungsgerichtsbarkeit, an deren Spitze der Conseil d'État steht. Oberstes Gericht der ordentlichen Gerichtsbarkeit ist die Cour de cassation; über die Verfassungsmäßigkeit von Gesetzen wacht der Conseil constitutionnel. Die geltende Verfassung ist die der Fünften Republik von 1958, die ein semipräsidentielles System begründet. Recht wird in Frankreich in zahlreichen Codes (codes) systematisch zusammengefasst.
