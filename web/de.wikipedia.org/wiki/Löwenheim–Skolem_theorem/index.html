Satz von Löwenheim-Skolem

Der Satz von Löwenheim-Skolem (englisch Löwenheim–Skolem theorem) ist ein grundlegendes Ergebnis der mathematischen Logik, benannt nach Leopold Löwenheim und Thoralf Skolem. Er beschreibt die Mächtigkeiten von Modellen von Theorien der Prädikatenlogik erster Stufe.

Aussage

In der „abwärts" gerichteten Version besagt der Satz: Besitzt eine Theorie in einer abzählbaren Sprache ein unendliches Modell, so besitzt sie auch ein abzählbar unendliches Modell. In der „aufwärts" gerichteten Version gilt: Besitzt eine Theorie ein unendliches Modell, so besitzt sie Modelle jeder größeren unendlichen Mächtigkeit.

Skolem-Paradox

Eine berühmte Konsequenz ist das Skolem-Paradox: Die Mengenlehre, die Sätze über überabzählbare Mengen enthält, besitzt demnach auch ein nur abzählbares Modell. In einem solchen Modell existieren Mengen, die innerhalb des Modells überabzählbar sind, obwohl von außen betrachtet nur abzählbar viele Elemente vorhanden sind. Das Paradox löst sich dadurch auf, dass Abzählbarkeit eine modellrelative Eigenschaft ist.

Bedeutung

Der Satz zeigt eine fundamentale Grenze der Ausdrucksstärke der Logik erster Stufe: Unendliche Strukturen können durch sie nicht bis auf Isomorphie charakterisiert werden. Gemeinsam mit dem Kompaktheitssatz bildet er eine Grundlage der Modelltheorie. Löwenheim bewies eine erste Version 1915, Skolem verallgemeinerte sie 1920.
