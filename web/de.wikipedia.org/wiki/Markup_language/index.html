Auszeichnungssprache

Eine Auszeichnungssprache (englisch markup language) ist eine maschinenlesbare Sprache zur Gliederung und Formatierung von Texten und anderen Daten. Der Begriff leitet sich davon ab, dass der eigentliche Inhalt mit zusätzlichen Markierungen (Markups) versehen wird, die Struktur, Bedeutung oder Darstellung beschreiben. Auszeichnungssprachen sind keine Programmiersprachen, da sie in der Regel keine Logik oder Abläufe beschreiben.

Arten der Auszeichnung

Man unterscheidet drei Grundtypen: Die prozedurale Auszeichnung gibt konkrete Verarbeitungsanweisungen (etwa in TeX). Die deskriptive Auszeichnung beschreibt die Struktur eines Dokuments unabhängig von der Darstellung, etwa Überschriften oder Absätze. Die semantische Auszeichnung kennzeichnet die Bedeutung von Inhalten, etwa Personen oder Orte.

Geschichte

Vorläufer entstanden in den 1960er Jahren mit Systemen wie RUNOFF. 1969 entwickelte Charles Goldfarb bei IBM die Generalized Markup Language (GML), aus der 1986 die standardisierte SGML (ISO 8879) hervorging. Aus SGML entstanden unter anderem HTML, die Sprache des World Wide Web, sowie XML, eine vereinfachte Teilmenge von SGML, die weite Verbreitung als universelles Format zum Datenaustausch fand.

Bekannte Auszeichnungssprachen

  • HTML – zur Darstellung von Webseiten
  • XML – zur strukturierten Speicherung und Übertragung von Daten
  • Markdown – eine leichtgewichtige Auszeichnungssprache mit einfacher Syntax
  • LaTeX – eine auf TeX basierende Sprache für wissenschaftliche Dokumente
  • SVG – ein XML-basiertes Format für Vektorgrafiken
  • YAML und JSON-ähnliche Formate zur Datenbeschreibung
