Home Run

Ein Home Run ist im Baseball und Softball ein Schlag, bei dem der Schlagmann (Batter) nach seinem Treffer alle vier Bases umrunden und einen Punkt (Run) erzielen kann, ohne dass die verteidigende Mannschaft einen Fehler begeht. Meist wird der Ball dabei über die Begrenzung des Outfields geschlagen („out of the park").

Arten

  • Solo Home Run: kein Läufer auf den Bases – ein Punkt.
  • Two-Run / Three-Run Home Run: ein bzw. zwei Läufer befinden sich auf den Bases.
  • Grand Slam: alle Bases sind besetzt – vier Punkte, die höchstmögliche Ausbeute eines einzelnen Schlags.
  • Inside-the-Park Home Run: der Ball bleibt im Spielfeld, der Schlagmann erreicht dennoch die Home Plate.
  • Walk-off Home Run: ein Home Run in der unteren Hälfte des letzten Innings, der das Spiel sofort beendet.

Rekorde

Den Karriererekord in der Major League Baseball hält Barry Bonds mit 762 Home Runs; den Rekord für eine Saison stellte er 2001 mit 73 Home Runs auf. Berühmt ist auch Babe Ruth, der den Home Run in den 1920er Jahren populär machte.
