MPEG Program Stream

Der MPEG Program Stream (PS) ist ein Containerformat der MPEG-Standards, das mehrere elementare Datenströme (Video, Audio, Daten) zu einem einzigen Strom zusammenfasst. Er ist für relativ fehlerfreie Umgebungen wie Speichermedien ausgelegt und wird unter anderem auf der DVD und der Video CD verwendet.

Struktur

Der Program Stream besteht aus Paketen veränderlicher Länge, die mit sogenannten Pack-Headern gebündelt werden. Er enthält Zeitstempel (System Clock Reference sowie Präsentation- und Dekodierzeitstempel), mit denen Audio und Video synchronisiert werden. Auf der DVD werden Program Streams in VOB-Dateien gespeichert; Video-CDs verwenden MPEG-1 Program Streams.

Abgrenzung

Demgegenüber ist der Transport Stream mit seinen kurzen, gleich langen Paketen für fehleranfällige Übertragungswege wie Rundfunk konzipiert, während der Program Stream für lokale Wiedergabe optimiert ist.
