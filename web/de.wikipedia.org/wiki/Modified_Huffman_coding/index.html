Modifizierte Huffman-Codierung

Die modifizierte Huffman-Codierung (engl. Modified Huffman Coding, MH) ist ein verlustfreies Datenkompressionsverfahren für zweifarbige (schwarz-weiße) Bilder. Sie wurde für die digitale Faxübertragung standardisiert (ITU-T-Empfehlung T.4, Gruppe 3) und bildet die Grundlage der eindimensionalen Codierung von Faxdokumenten.


Lauflängencodierung einer Bildzeile

Verfahren

Das Verfahren kombiniert eine Lauflängencodierung mit statistisch optimierten Codewörtern: Jede Bildzeile wird als Folge von Läufen gleichfarbiger Pixel beschrieben. Die Lauflängen erhalten Huffman-ähnliche Codeworte variabler Länge, die auf den typischen Statistiken von Textdokumenten abgestimmt sind. Für Läufe bis 63 Pixel existieren eigene Codeworte; längere Läufe werden aus einem Make-up-Code und einem Abschlusscode zusammengesetzt. Weiße und schwarze Läufe besitzen getrennte Codetabellen.

Weiterentwicklung

Die zweidimensionale Erweiterung Modified READ (MR, T.4) und das Verfahren Modified Modified READ (MMR, T.6) nutzen zusätzlich die Ähnlichkeit benachbarter Zeilen und erreichen höhere Kompressionsraten; sie lösten MH in späteren Faxstandards weitgehend ab.
