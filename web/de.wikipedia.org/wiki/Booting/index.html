Booten

Als Booten (von englisch booting, Kurzform von bootstrapping) bezeichnet man den Startvorgang eines Computers, bei dem die Firmware zunächst grundlegende Hardwaretests durchführt und anschließend einen Bootloader lädt, der das Betriebssystem in den Arbeitsspeicher überträgt und startet. Der Begriff geht auf die Redewendung zurück, sich „an den eigenen Stiefelschlaufen“ (bootstraps) hochzuziehen.

Ablauf auf dem PC

Nach dem Einschalten führt die CPU Code im BIOS beziehungsweise UEFI aus. Ein Selbsttest (POST, Power-On Self-Test) prüft Speicher und Geräte. Danach sucht die Firmware ein startfähiges Medium, lädt den Bootloader (früher über den Master Boot Record, heute meist eine EFI-Systempartition) und übergibt an den Kernel des Betriebssystems, der Treiber lädt und die Systemdienste startet.

Varianten

Beim Kaltstart wird der Rechner von einem stromlosen Zustand eingeschaltet, beim Warmstart neu gestartet. Netzwerkboot (PXE) lädt das System über das Netzwerk, und beim Secure Boot prüft die Firmware kryptografische Signaturen der Boot-Komponenten, um Schadsoftware abzuwehren.
