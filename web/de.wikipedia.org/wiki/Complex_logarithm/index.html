Komplexer Logarithmus

Der komplexe Logarithmus ist die Verallgemeinerung des natürlichen Logarithmus auf die komplexen Zahlen. Da die komplexe Exponentialfunktion periodisch ist, besitzt der Logarithmus im Komplexen keine eindeutige Umkehrung: Er ist eine mehrwertige Funktion.

Definition

Für eine komplexe Zahl z ≠ 0 mit Polardarstellung z = r·eiφ gilt log z = ln r + i(φ + 2πk) für alle ganzen Zahlen k. Der Imaginärteil ist also nur bis auf Vielfache von 2π bestimmt. Die mehrwertige Struktur rührt daher, dass das Argument einer komplexen Zahl nur modulo 2π festgelegt ist.

Hauptzweig

Um eine eindeutige Funktion zu erhalten, wählt man einen Zweig des Logarithmus. Der Hauptzweig (Hauptwert, Log) beschränkt das Argument auf das Intervall (−π, π]; er ist auf der geschlitzten Ebene ℂ \ (−∞, 0] holomorph, besitzt aber längs der negativen reellen Achse einen Sprung. Seine Ableitung ist Log′(z) = 1/z.

Eigenschaften

Bekannte Logarithmusgesetze gelten im Komplexen nur eingeschränkt oder modulo 2πi: So ist log(z·w) im Allgemeinen nicht gleich log z + log w, sondern beide Seiten unterscheiden sich um ein ganzzahliges Vielfaches von 2πi. Die verschiedenen Zweige des Logarithmus lassen sich auf der Riemannschen Fläche des Logarithmus zu einer einzigen holomorphen Funktion zusammenfassen; der Logarithmus ist das Standardbeispiel einer unendlich vielblättrigen Überlagerung.

Anwendungen

Der komplexe Logarithmus wird zur Definition komplexer Potenzen ab = eb log a, in der Funktionentheorie bei der Auswertung von Integralen und in der Physik, etwa bei Phasenbetrachtungen, verwendet.
