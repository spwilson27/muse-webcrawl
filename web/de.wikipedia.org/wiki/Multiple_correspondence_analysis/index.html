Multiple Korrespondenzanalyse

Die multiple Korrespondenzanalyse (englisch multiple correspondence analysis, MCA) ist ein multivariates statistisches Verfahren zur explorativen Analyse mehrerer kategorialer Variablen. Sie ist eine Verallgemeinerung der einfachen Korrespondenzanalyse von zwei auf beliebig viele kategoriale Merkmale und wurde maßgeblich von Jean-Paul Benzécri und seiner Schule der „analyse des données“ entwickelt.

Verfahren

Ausgangspunkt ist eine Indikatormatrix, in der für jede Beobachtung und jede Ausprägung aller Variablen vermerkt ist, ob die Ausprägung vorliegt. Alternativ wird die Burt-Matrix aller paarweisen Kontingenztafeln verwendet. Analog zur Hauptkomponentenanalyse für quantitative Daten werden daraus Achsen bestimmt, entlang derer sich Kategorien und Beobachtungen in einem niedrigdimensionalen Raum grafisch darstellen lassen; nahe beieinander liegende Punkte weisen ähnliche Profile auf.

Anwendung

Die MCA wird vor allem in den Sozialwissenschaften eingesetzt, etwa zur Analyse von Lebensstilen und sozialem Raum – prominent wurde sie von Pierre Bourdieu verwendet. Auch in der Marktforschung und der Bioinformatik findet das Verfahren Anwendung.
