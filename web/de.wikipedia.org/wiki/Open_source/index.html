Open Source

Open Source (englisch für „offene Quelle“, sinngemäß „quelloffen“) bezeichnet Software, deren Quelltext öffentlich zugänglich ist und deren Lizenz es erlaubt, die Software zu nutzen, zu studieren, zu verändern und weiterzuverbreiten. Der Begriff wird auch über die Software hinaus für offene Entwicklungs- und Produktionsmodelle verwendet.

Die Open Source Definition

Maßgeblich ist die von der Open Source Initiative (OSI) veröffentlichte Open Source Definition. Sie verlangt unter anderem freie Weiterverbreitung, Zugang zum Quelltext, die Erlaubnis abgeleiteter Werke und die Diskriminierungsfreiheit gegenüber Personen, Gruppen und Anwendungszwecken. Bekannte Open-Source-Lizenzen sind die GNU General Public License (GPL), die Apache-Lizenz, die MIT-Lizenz und die BSD-Lizenzen.

Geschichte

Der Begriff wurde 1998 im Umfeld der Veröffentlichung des Quellcodes des Browsers Netscape Navigator geprägt; Christine Peterson schlug den Ausdruck vor, und die OSI wurde von Bruce Perens und Eric S. Raymond gegründet. Inhaltlich knüpft Open Source an die ältere Bewegung für freie Software um Richard Stallman und die Free Software Foundation an, betont jedoch eher praktische und wirtschaftliche Vorteile offener Entwicklung als dessen ethische Begründung.

Bedeutung

Open-Source-Software bildet heute einen Grundpfeiler der digitalen Infrastruktur. Beispiele sind das Betriebssystem Linux, der Webserver Apache, die Datenbanken MySQL und PostgreSQL sowie zahlreiche Programmiersprachen und Entwicklungswerkzeuge. Entwicklungsarbeit findet häufig dezentral und kollaborativ über Plattformen wie GitHub statt.
