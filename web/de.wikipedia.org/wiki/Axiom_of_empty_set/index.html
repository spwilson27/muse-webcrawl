Leermengenaxiom

Das Leermengenaxiom (englisch axiom of empty set) ist ein Axiom der Zermelo-Fraenkel-Mengenlehre (ZF). Es fordert die Existenz einer Menge, die keine Elemente enthält:

∃x ∀y ¬(y ∈ x)

Die leere Menge

Die durch das Axiom geforderte Menge ist eindeutig bestimmt und wird als leere Menge bezeichnet, geschrieben ∅ oder { }. Sie ist Teilmenge jeder Menge und spielt in der Mathematik eine grundlegende Rolle, etwa beim Aufbau der natürlichen Zahlen im Von-Neumann-Modell, wo 0 = ∅ gesetzt wird.

Redundanz

In vielen Formulierungen von ZF ist das Leermengenaxiom streng genommen entbehrlich: Aus dem Unendlichkeitsaxiom und dem Aussonderungsaxiom lässt sich die Existenz einer leeren Menge herleiten. Es wird aus Gründen der Übersicht dennoch häufig ausdrücklich aufgenommen.
