Kopierelision

Kopierelision (englisch copy elision) ist eine Compileroptimierung, bei der das Erzeugen überflüssiger Objektkopien vermieden wird. Obwohl das Weglassen von Kopien in bestimmten Fällen die beobachtbaren Nebeneffekte des Kopierkonstruktors und des Destruktors verändert, erlauben Programmiersprachen wie C++ diese Optimierung ausdrücklich.

Formen

  • Return Value Optimization (RVO): Ein Funktionsergebnis wird direkt im Speicher des Aufrufers konstruiert, statt ein temporäres Objekt zu kopieren.
  • Named Return Value Optimization (NRVO): Entsprechend für eine benannte lokale Variable, die zurückgegeben wird.
  • Elision bei Übergabe als Wert: Wird eine Funktion mit einem temporären Objekt aufgerufen, kann das Objekt direkt im Parameter konstruiert werden.

C++17

Seit C++17 ist die Kopierelision in bestimmten Fällen garantiert vorgeschrieben („guaranteed copy elision“): Temporäre Objekte werden dann gar nicht erst materialisiert, sodass Kopier- und Verschiebekonstruktoren in diesen Situationen nicht einmal vorhanden sein müssen. Davon zu unterscheiden ist die nicht garantierte Elision, für die die Konstruktoren weiterhin zugänglich und nicht gelöscht sein müssen.
