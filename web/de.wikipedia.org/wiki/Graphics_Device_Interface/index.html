Graphics Device Interface

Das Graphics Device Interface (GDI) ist eine Programmierschnittstelle (API) von Microsoft Windows zur geräteunabhängigen Ausgabe von Grafiken und formatiertem Text auf Bildschirmen und Druckern. Es gehört seit den ersten Windows-Versionen zum System und wird unter anderem über die Bibliothek gdi32.dll bereitgestellt.

Funktionsweise

Anwendungen zeichnen über einen Gerätekontext (device context, DC), der die Eigenschaften des Ausgabegeräts kapselt. GDI stellt Funktionen für Linien, Flächen, Bitmaps, Schriften, Farbpaletten und Regionen bereit und übersetzt sie mithilfe von Gerätetreibern in gerätespezifische Befehle. Objekte wie Stifte, Pinsel und Bitmaps werden vom Programm erzeugt, ausgewählt und nach Gebrauch wieder freigegeben.

Nachfolger

Für anspruchsvollere 2D-Grafik wurde GDI um GDI+ (ab Windows XP) ergänzt, das unter anderem Anti-Aliasing und Farbverläufe bietet. Modernere Anwendungen nutzen zunehmend Direct2D und DirectWrite aus der DirectX-Familie; GDI bleibt jedoch für die klassische Fensterdarstellung von Windows von Bedeutung.
