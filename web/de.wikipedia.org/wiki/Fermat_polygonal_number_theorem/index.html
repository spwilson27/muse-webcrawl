Fermatscher Polygonalzahlensatz

Der fermatsche Polygonalzahlensatz besagt, dass sich jede nichtnegative ganze Zahl als Summe von höchstens n n-Eckszahlen (Polygonalzahlen) darstellen lässt.

Spezialfälle

Für n = 3 ergibt sich die Aussage, dass jede Zahl Summe von höchstens drei Dreieckszahlen ist (bewiesen von Gauß), für n = 4 der Vier-Quadrate-Satz von Lagrange, nach dem jede Zahl Summe von höchstens vier Quadratzahlen ist.

Geschichte

Fermat stellte den Satz im 17. Jahrhundert ohne überlieferten Beweis auf. Den vollständigen Beweis für alle n lieferte Augustin-Louis Cauchy 1813, weshalb der Satz auch als Polygonalzahlensatz von Cauchy bekannt ist.
