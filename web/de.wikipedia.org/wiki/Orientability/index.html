Orientierbarkeit

In der Mathematik bezeichnet Orientierbarkeit eine Eigenschaft von Flächen und allgemeiner von Mannigfaltigkeiten, die beschreibt, ob sich auf ihnen konsistent eine „Seite" beziehungsweise eine Drehrichtung auszeichnen lässt. Eine Mannigfaltigkeit heißt orientierbar, wenn sie eine Orientierung zulässt, andernfalls nichtorientierbar.

Anschauliche Beschreibung

Eine Fläche ist genau dann orientierbar, wenn man auf ihr nicht durch eine geschlossene Wanderung ein Objekt in sein Spiegelbild verwandeln kann. Auf einem Möbiusband dagegen kehrt eine Figur nach einem Umlauf seitenverkehrt zurück – das Möbiusband ist nichtorientierbar. Ebenso nichtorientierbar sind die Kleinsche Flasche und die projektive Ebene.

Definition

Für eine differenzierbare Mannigfaltigkeit der Dimension n bedeutet Orientierbarkeit, dass das Tangentialbündel ein nirgends verschwindendes Volumenform-Element zulässt, äquivalent: die Determinante der Übergangsfunktionen geeigneter Karten kann durchweg positiv gewählt werden. Homologietheoretisch ist eine geschlossene n-Mannigfaltigkeit genau dann orientierbar, wenn ihre oberste Homologiegruppe Hn isomorph zu ℤ ist.

Bedeutung

Orientierbarkeit ist Voraussetzung für die Integration von Differentialformen über eine Mannigfaltigkeit und damit für den Satz von Stokes. Jede orientierbare geschlossene Fläche ist homöomorph zu einer Sphäre mit angehängten Henkeln (Torus, Brezel­flächen), was die Klassifikation der Flächen liefert.
