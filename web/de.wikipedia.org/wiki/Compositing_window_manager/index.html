Compositing Window Manager

Ein Compositing Window Manager ist ein Fenstermanager, der jedem Programmfenster einen eigenen, vom Bildschirm unabhängigen Puffer zuweist und das Gesamtbild erst beim Anzeigen aus diesen Puffern zusammensetzt (englisch compositing). Dadurch sind Effekte wie echte Transparenz, Schattenwurf, sanfte Animationen, Miniaturvorschauen und dreidimensionale Fensterwechsel möglich.

Funktionsweise

Anders als bei klassischen Fenstermanagern zeichnen Anwendungen nicht direkt auf den Bildschirm, sondern in eigene Speicherflächen. Der Compositor kombiniert diese Flächen – häufig beschleunigt durch die Grafikkarte über OpenGL oder Vulkan – zum finalen Bild. Ändert sich nur ein Fenster, muss nicht das gesamte Bild neu gezeichnet werden.

Beispiele

Bekannte Compositing-Systeme sind der Desktop Window Manager von Windows (seit Windows Vista), Quartz Compositor von macOS sowie unter Linux Compiz, KWin und Mutter. Unter Wayland ist das Compositing fester Bestandteil des Protokolls: Jeder Wayland-Compositor übernimmt zugleich die Aufgaben des Fenstermanagers.
