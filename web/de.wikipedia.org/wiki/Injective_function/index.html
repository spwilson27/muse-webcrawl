Injektive Funktion

Injektive Funktion
Synonym:Injektion, linkseindeutige Funktion
Gebiet:Mathematik (Mengenlehre)
Gegenteilige Begriffe:Surjektivität, Bijektivität

Eine injektive Funktion (auch Injektion genannt) ist in der Mathematik eine Funktion, bei der jedes Element der Zielmenge höchstens einmal als Funktionswert angenommen wird. Umgangssprachlich: Verschiedene Argumente haben stets verschiedene Werte – es wird nichts „zusammengeführt“.

Definition

Eine Funktion f: X → Y heißt injektiv, wenn aus f(x1) = f(x2) stets x1 = x2 folgt, beziehungsweise äquivalent, wenn für x1 ≠ x2 immer f(x1) ≠ f(x2) gilt. Anschaulich bedeutet das: Jede horizontale Gerade schneidet den Graphen einer injektiven reellen Funktion in höchstens einem Punkt.

Beispiele

Die Funktion f(x) = 2x + 1 auf den reellen Zahlen ist injektiv, ebenso die Exponentialfunktion. Die Quadratfunktion g(x) = x² ist auf den reellen Zahlen nicht injektiv, da g(−1) = g(1) = 1 gilt; schränkt man sie auf die nichtnegativen Zahlen ein, wird sie injektiv. In der linearen Algebra ist eine lineare Abbildung genau dann injektiv, wenn ihr Kern nur den Nullvektor enthält.

Eigenschaften

Injektive Funktionen besitzen eine linksseitige Umkehrung: Ist f injektiv, so gibt es eine Funktion g mit g ∘ f = id. Die Verkettung zweier injektiver Funktionen ist wieder injektiv. Eine Funktion, die zugleich injektiv und surjektiv ist, heißt bijektiv. Für endliche Mengen folgt aus der Injektivität einer Abbildung X → Y, dass X höchstens so viele Elemente wie Y besitzt.
