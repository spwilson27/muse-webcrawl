Satz von der monotonen Klasse

Der Satz von der monotonen Klasse (englisch monotone class theorem) ist ein Resultat der Maßtheorie. Er besagt: Erzeugt eine Algebra A eine σ-Algebra, und enthält eine monotone Klasse diese Algebra, so enthält die monotone Klasse bereits die gesamte erzeugte σ-Algebra.

Aussage

Eine Familie von Mengen heißt monotone Klasse, wenn sie gegenüber monotonen Vereinigungen und Schnitten abgeschlossen ist. Der Satz erlaubt es, Aussagen, die für alle Mengen einer Algebra gelten und gegenüber monotonen Limiten stabil sind, auf die von der Algebra erzeugte σ-Algebra zu übertragen.

Anwendung

Ein wichtiges Anwendungsbeispiel ist der Beweis des Satzes von Fubini oder der Nachweis, dass zwei endliche Maße übereinstimmen, wenn sie auf einem durchschnittsstabilen Erzeuger übereinstimmen. Eng verwandt ist das Dynkin-System bzw. der π-λ-Satz von Dynkin.
