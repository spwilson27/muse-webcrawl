Non-Uniform Memory Access

Non-Uniform Memory Access (NUMA) ist eine Computerarchitektur für Multiprozessorsysteme, bei der der Hauptspeicher in mehrere Bereiche aufgeteilt ist und die Zugriffszeit eines Prozessors davon abhängt, ob er auf seinen „lokalen“ oder auf einen „fernen“ Speicherbereich zugreift.

Aufbau

Das System besteht aus mehreren NUMA-Knoten, die jeweils einen oder mehrere Prozessoren (mit eigenen Caches) und einen eigenen Speicherbereich umfassen. Die Knoten sind über eine schnelle Verbindung (Interconnect, etwa Intels QPI/UPI oder AMDs Infinity Fabric) verbunden. Lokale Zugriffe sind schnell; Zugriffe auf Speicher anderer Knoten sind möglich, aber langsamer, da sie über die Knotenverbindung laufen.

Vergleich und Anwendung

NUMA steht im Gegensatz zu UMA (Uniform Memory Access), bei dem alle Prozessoren über einen gemeinsamen Bus gleich schnell auf den Speicher zugreifen – ein Konzept, das nur für wenige Prozessoren skaliert. NUMA ist heute die Standardarchitektur großer Server und Mehrsockel-Systeme. Betriebssysteme und Laufzeitumgebungen können die Leistung durch NUMA-bewusstes Scheduling steigern, indem sie Threads und deren Daten möglichst auf demselben Knoten halten. In der virtuellen Speicherverwaltung wird häufig eine First-Touch-Strategie verwendet: Eine Speicherseite wird auf dem Knoten des Threads angelegt, der sie zuerst berührt.
