BMP (Dateiformat)

BMP (englisch Bitmap) ist ein Dateiformat zur Speicherung von Rastergrafiken, das vor allem von Microsoft für das Betriebssystem Windows entwickelt wurde. Dateien verwenden meist die Endung .bmp oder .dib (Device Independent Bitmap).

Aufbau

Eine BMP-Datei besteht aus einem Dateikopf, einem Informationsblock mit Bildabmessungen, Farbtiefe und gegebenenfalls einer Farbpalette sowie den eigentlichen Bilddaten. Die Pixel werden zeilenweise gespeichert, in der Regel von unten nach oben; die Zeilen sind auf Vielfache von vier Byte aufgefüllt. Typische Farbtiefen sind 1, 4, 8, 16, 24 und 32 Bit pro Pixel.

Eigenschaften

BMP speichert Bilddaten meist unkomprimiert (eine einfache Lauflängenkodierung ist möglich), weshalb die Dateien vergleichsweise groß sind. Dafür ist das Format einfach aufgebaut und wird von praktisch allen Bildbearbeitungsprogrammen unterstützt. Für Fotos und das Internet sind komprimierende Formate wie JPEG oder PNG besser geeignet; in der Windows-Systemprogrammierung und bei Screenshots wird BMP weiterhin genutzt.
