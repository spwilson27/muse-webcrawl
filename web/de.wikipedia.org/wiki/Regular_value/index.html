Regulärer Wert

Ein regulärer Wert ist ein Begriff aus der Differentialtopologie. Sei f : M → N eine differenzierbare Abbildung zwischen differenzierbaren Mannigfaltigkeiten. Ein Punkt y ∈ N heißt regulärer Wert von f, wenn an jedem Urbildpunkt x ∈ f−1(y) das Differential von f surjektiv ist. Gilt N nicht im Bild von f, so ist y definitionsgemäß ebenfalls ein regulärer Wert. Werte, die nicht regulär sind, heißen kritische Werte; die Urbilder kritischer Werte unter einem Punkt heißen kritische Punkte.

Satz vom regulären Wert

Nach dem Satz vom regulären Wert (auch Regular Value Theorem) ist das Urbild f−1(y) eines regulären Wertes y eine Untermannigfaltigkeit von M, deren Kodimension gleich der Dimension von N ist. Dieser Satz ist ein zentrales Werkzeug, um Mannigfaltigkeiten als Niveaumengen glatter Funktionen zu konstruieren – so ist beispielsweise die Sphäre die Niveaumenge der Funktion f(x) = |x|² zum regulären Wert 1.

Satz von Sard

Der Satz von Sard besagt, dass die Menge der kritischen Werte einer hinreichend oft differenzierbaren Abbildung eine Lebesgue-Nullmenge ist; fast alle Werte sind also regulär.
