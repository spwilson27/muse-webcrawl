Verdrängungsreaktion

Eine Verdrängungsreaktion (englisch single displacement reaction oder single replacement reaction) ist eine chemische Reaktion, bei der ein Element einen Bestandteil einer Verbindung ersetzt und diesen freisetzt. Das allgemeine Schema lautet:

A + BC → AC + B

Dabei reagiert ein elementarer Stoff A mit einer Verbindung BC; A tritt an die Stelle von B, das als Element frei wird. Verdrängungsreaktionen sind stets Redoxreaktionen, da sich die Oxidationszahlen der beteiligten Elemente ändern.

Ablauf und Triebkraft

Ob eine Verdrängung stattfindet, hängt von der Stellung der Elemente in der elektrochemischen Spannungsreihe ab: Ein unedleres (stärker reduzierend wirkendes) Metall verdrängt ein edleres Metall aus dessen Salz. So überzieht sich ein Eisennagel in Kupfersulfatlösung mit Kupfer, während Eisen in Lösung geht. Umgekehrt findet keine Reaktion statt, wenn man Kupfer in eine Eisensalzlösung taucht. Entsprechendes gilt für Halogene: Chlor verdrängt Brom und Iod aus ihren Salzen, weil es das stärkere Oxidationsmittel ist.

Beispiele

  • Zink + Kupfersulfat → Zinksulfat + Kupfer
  • Eisen + Salzsäure → Eisenchlorid + Wasserstoff
  • Chlor + Kaliumbromid → Kaliumchlorid + Brom
  • Thermitreaktion: Aluminium verdrängt Eisen aus Eisenoxid

Abgrenzung

Von der einfachen Verdrängung unterscheidet man die doppelte Umsetzung (Metathese), bei der zwei Verbindungen ihre Bestandteile austauschen, ohne dass ein Element frei wird.
