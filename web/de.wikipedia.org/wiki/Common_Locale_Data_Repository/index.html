Common Locale Data Repository

Das Common Locale Data Repository (CLDR) ist ein Projekt des Unicode-Konsortiums, das Gebietsschema-Daten (Locale-Daten) im XML-Format bereitstellt. Diese Daten werden von Computeranwendungen genutzt, um Software an die sprachlichen und kulturellen Konventionen verschiedener Länder und Regionen anzupassen.

Inhalte

Das CLDR enthält unter anderem folgende Informationen für zahlreiche Sprachen und Regionen:

  • Übersetzungen von Sprach-, Regions-, Währungs- und Zeitzonennamen
  • Datums- und Zeitformate sowie Zahlen- und Währungsformate
  • Sortierreihenfolgen (Kollation) und Regeln für Pluralformen
  • Tastaturbelegungen und Transliterationsregeln
  • Exemplarzeichen, also die in einer Sprache üblicherweise verwendeten Zeichen

Verwendung

Die Daten des CLDR werden von vielen großen Softwareprojekten und Betriebssystemen verwendet, darunter die International Components for Unicode (ICU), zahlreiche Betriebssysteme sowie Programmiersprachen und Bibliotheken. Die Daten liegen im Format LDML (Locale Data Markup Language) vor, einem speziellen XML-Dialekt.

Survey Tool

Die Pflege der Daten erfolgt über das sogenannte Survey Tool, in dem Beiträger aus aller Welt Übersetzungen und Formate für ihre Sprachen vorschlagen und überprüfen können. Die Veröffentlichungen des CLDR erscheinen in der Regel zweimal jährlich.
