Partitionierung

Die Partitionierung (englisch disk partitioning) bezeichnet die Unterteilung eines physischen Datenträgers wie einer Festplatte oder SSD in mehrere logisch getrennte Bereiche, die Partitionen. Jede Partition wird vom Betriebssystem wie ein eigenes Laufwerk behandelt und kann mit einem eigenen Dateisystem formatiert werden. Die Informationen über Lage und Größe der Partitionen stehen in einer Partitionstabelle am Anfang des Datenträgers.

Partitionstabellen

Der klassische Master Boot Record (MBR) erlaubt vier primäre Partitionen (oder drei primäre und eine erweiterte Partition mit beliebig vielen logischen Laufwerken) und Datenträger bis zu einer Größe von 2 TiB. Der moderne Nachfolger GUID Partition Table (GPT), Teil der UEFI-Spezifikation, unterstützt praktisch beliebig viele Partitionen (in Windows 128) und sehr viel größere Laufwerke; er speichert zusätzlich eine Sicherungskopie der Tabelle am Ende des Mediums und schützt Einträge durch Prüfsummen.

Zwecke

  • Trennung von Betriebssystem, Programmen und Benutzerdaten, etwa um das System neu installieren zu können, ohne Daten zu verlieren
  • paralleler Betrieb mehrerer Betriebssysteme auf einem Rechner (Multi-Boot)
  • spezielle Partitionen, etwa die Auslagerungspartition (Swap) unter Linux, die Startpartition EFI-Systempartition oder Wiederherstellungspartitionen der Hersteller
  • Organisation großer Datenbestände und vereinfachte Datensicherung einzelner Bereiche

Werkzeuge

Zur Partitionierung dienen unter Windows die Datenträgerverwaltung und diskpart, unter Linux Programme wie fdisk, parted und GParted sowie unter macOS das Festplattendienstprogramm. Das nachträgliche Ändern von Partitionsgrößen ist mit geeigneten Werkzeugen ohne Datenverlust möglich, bleibt aber ein risikobehafteter Eingriff.
