Kernregression

Die Kernregression ist ein nichtparametrisches Verfahren der Regressionsanalyse, mit dem der Zusammenhang zwischen einer Zielgröße und einer oder mehreren Einflussgrößen geschätzt wird, ohne eine feste funktionale Form (etwa eine Gerade) vorzugeben. Sie geht auf Arbeiten von Geoffrey Watson und Elizbar Nadaraya aus dem Jahr 1964 zurück.

Nadaraya-Watson-Schätzer

Der bekannteste Kernregressionsschätzer ist der Nadaraya-Watson-Schätzer: Der geschätzte Funktionswert an einem Punkt x ist ein gewichteter Mittelwert der beobachteten Zielwerte, wobei die Gewichte durch eine Kernfunktion K (siehe Kern (Statistik)) bestimmt werden, die Datenpunkten in der Nähe von x größeres Gewicht gibt. Die Bandbreite steuert die Glättung analog zur Kerndichteschätzung.

Erweiterungen

Der Nadaraya-Watson-Schätzer hat an den Rändern des Datenbereichs eine systematische Verzerrung. Die lokal lineare Regression behebt dies, indem sie in jeder Umgebung statt einer Konstanten eine Gerade anpasst. Kernregressionen gehören zur Familie der Kernglätter und finden Anwendung in der Ökonometrie, der Zeitreihenanalyse und explorativen Datenanalyse.
