Docker (Software)

Docker ist eine quelloffene Software zur Betriebssystem-Virtualisierung mithilfe von Containern. Sie wurde 2013 von Docker, Inc. veröffentlicht und ist überwiegend in der Programmiersprache Go geschrieben. Docker vereinfacht die Bereitstellung von Anwendungen, indem Prozesse isoliert in Containern laufen, die alle benötigten Abhängigkeiten enthalten.

Funktionsweise

Im Gegensatz zu virtuellen Maschinen, die ein vollständiges Gastbetriebssystem emulieren, teilen sich Container den Kernel des Hostsystems. Docker nutzt dafür Linux-Kernel-Funktionen wie cgroups zur Ressourcenbegrenzung und Namespaces zur Isolation. Ein Container wird aus einem Image gestartet, einer schreibgeschützten Vorlage, die in Schichten (Layern) aufgebaut ist. Images werden über eine Textdatei, das Dockerfile, definiert und können über die Registry Docker Hub verteilt werden.

Komponenten

  • Docker Engine: Laufzeitumgebung mit dem Daemon dockerd und der Kommandozeilenschnittstelle.
  • Docker Compose: Werkzeug zur Definition von Anwendungen aus mehreren Containern mittels YAML-Dateien.
  • Docker Hub: öffentliche Registry für Images.
  • Docker Desktop: Entwicklungsumgebung für macOS und Windows.

Geschichte

Docker wurde im März 2013 von Solomon Hykes vorgestellt. Die Software begründete maßgeblich den Container-Boom der 2010er Jahre und beeinflusste die Entstehung von Orchestrierungssystemen wie Kubernetes. 2015 wurde die Open Container Initiative gegründet, um herstellerneutrale Standards für Containerformate und Laufzeitumgebungen zu schaffen.
