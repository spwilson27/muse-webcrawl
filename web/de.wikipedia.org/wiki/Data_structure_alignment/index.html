Speicherausrichtung

Die Speicherausrichtung (englisch data structure alignment) beschreibt in der Informatik, wie Daten im Hauptspeicher eines Computers angeordnet werden und in welcher Form die CPU auf sie zugreift. Ein Datum gilt als natürlich ausgerichtet, wenn seine Adresse ein Vielfaches seiner Größe ist; eine 4-Byte-Ganzzahl ist also ausgerichtet, wenn sie an einer durch 4 teilbaren Adresse beginnt.

Bedeutung

Viele Prozessorarchitekturen greifen auf ausgerichtete Daten deutlich schneller zu, da ein Zugriff dann innerhalb eines Speicherzyklus oder einer Cache-Line erfolgen kann. Fehlausgerichtete Zugriffe müssen von der Hardware in mehrere Zugriffe zerlegt werden oder lösen auf manchen Architekturen (etwa älteren RISC-Systemen) eine Ausnahme aus, die vom Betriebssystem emuliert werden muss.

Padding

Compiler fügen in Strukturen zwischen den Elementen Füllbytes (padding) ein, damit jedes Element seiner Ausrichtungsanforderung genügt. Dadurch kann eine Struktur mehr Speicher belegen, als die Summe ihrer Elemente vermuten lässt. Durch Umordnen der Elemente von der größten zur kleinsten Ausrichtung lässt sich der Verschnitt häufig verringern. Mit Schlüsselwörtern wie packed kann das Auffüllen unterdrückt werden, etwa für Dateiformate oder Netzwerkprotokolle; dies geht jedoch meist auf Kosten der Zugriffsgeschwindigkeit.
