Komposition (Mathematik)

In der Mathematik bezeichnet die Komposition oder Verkettung von Funktionen die Hintereinanderausführung zweier Funktionen. Wendet man zuerst eine Funktion g und anschließend eine Funktion f auf deren Ergebnis an, so entsteht die zusammengesetzte Funktion f ∘ g (gelesen „f nach g“).

Definition

Sind g: X → Y und f: Y → Z Funktionen, so ist ihre Komposition die Funktion f ∘ g: X → Z mit (f ∘ g)(x) = f(g(x)). Voraussetzung ist, dass die Zielmenge von g mit der Definitionsmenge von f übereinstimmt beziehungsweise in ihr enthalten ist.

Beispiel: Für g(x) = x + 1 und f(x) = x² ergibt sich (f ∘ g)(x) = (x + 1)², während (g ∘ f)(x) = x² + 1 gilt. Die Komposition ist also im Allgemeinen nicht kommutativ.

Eigenschaften

Die Komposition von Funktionen ist assoziativ: (f ∘ g) ∘ h = f ∘ (g ∘ h). Die Identität (identische Abbildung) id mit id(x) = x wirkt als neutrales Element. Sind zwei Funktionen bijektiv, so ist auch ihre Komposition bijektiv, und für die Umkehrfunktion gilt (f ∘ g)−1 = g−1 ∘ f−1. Stetigkeit und Differenzierbarkeit bleiben unter Komposition erhalten; die Ableitung verketteter Funktionen berechnet sich nach der Kettenregel.

Anwendungen

Die Komposition ist ein grundlegendes Konstruktionsprinzip: In der Analysis ermöglicht sie die Kettenregel, in der Algebra führt sie zu Verknüpfungsstrukturen wie Gruppen von Abbildungen, und in der Informatik entspricht sie dem Hintereinanderausführen von Programmfunktionen.
