Farbfiltermatrix

Eine Farbfiltermatrix (englisch color filter array, CFA) ist ein Mosaik winziger Farbfilter, das über einem elektronischen Bildsensor liegt, damit dieser Farbinformationen aufnehmen kann. Da ein einzelnes Sensorelement nur Helligkeit misst, lässt das Filter über jedem Pixel nur einen Farbanteil (Rot, Grün oder Blau) durch; die vollständige Farbinformation wird anschließend durch Interpolation berechnet (Demosaicing).

Bayer-Filter

Das mit Abstand verbreitetste Muster ist das 1976 von Bryce Bayer (Kodak) patentierte Bayer-Filter: In einem 2×2-Feld liegen je zwei grüne, ein rotes und ein blaues Filterelement (RGGB). Der doppelte Grünanteil berücksichtigt die höhere Helligkeitsempfindlichkeit des menschlichen Auges für Grün, sodass die Luminanzinformation feiner aufgelöst wird.

Alternativen

  • X-Trans (Fujifilm): 6×6-Muster, das Moiré-Effekte durch weniger regelmäßige Anordnung vermindert.
  • RGBW/RGBC-Muster: enthalten zusätzliche unfilterte („weiße“/klare) Pixel für höhere Lichtempfindlichkeit, etwa in Smartphone-Sensoren.
  • Foveon-Sensoren: stapeln drei Fotodiodenschichten übereinander und kommen ohne Mosaik aus.
  • 3-Chip-Kameras: trennen das Licht mit Prismen auf drei Sensoren und benötigen ebenfalls kein CFA.

Verarbeitung

Aus den Mosaikdaten rekonstruiert der Demosaicing-Algorithmus ein Vollfarbbild. Fehler in diesem Schritt können zu Farbsäumen, Treppchen und Moiré führen; moderne Verfahren nutzen Kanteninformation und maschinelles Lernen.
