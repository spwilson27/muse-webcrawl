Satz vom senkrechten Achsenpaar

Der Satz vom senkrechten Achsenpaar (englisch perpendicular axis theorem) ist ein Satz der klassischen Mechanik über das Trägheitsmoment ebener Körper. Er besagt, dass das Trägheitsmoment einer dünnen Platte um eine Achse senkrecht zur Plattenebene gleich der Summe der Trägheitsmomente um zwei zueinander senkrechte Achsen in der Plattenebene ist, die sich auf der Drehachse schneiden.

Formulierung

Gilt für die Trägheitsmomente Ix und Iy um zwei in der Ebene liegende Achsen, so ist das Trägheitsmoment um die dazu senkrechte z-Achse: Iz = Ix + Iy.

Herleitung

Für ein Massenelement im Abstand r von der z-Achse gilt r² = x² + y². Einsetzen in die Definition des Trägheitsmoments und Aufspalten der Summe liefert unmittelbar die beiden ebenen Trägheitsmomente.

Anwendung

Der Satz vereinfacht die Berechnung von Trägheitsmomenten flacher Körper, etwa einer Kreisscheibe oder einer rechteckigen Platte, und wird häufig zusammen mit dem Satz von Steiner verwendet.
