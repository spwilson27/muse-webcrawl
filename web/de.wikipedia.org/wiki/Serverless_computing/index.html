Serverless Computing

Serverless Computing ist ein Modell des Cloud Computing, bei dem Entwickler Anwendungen erstellen und ausführen, ohne Server selbst verwalten zu müssen. Der Cloud-Anbieter übernimmt Bereitstellung, Skalierung und Betrieb der Infrastruktur; Ressourcen werden dynamisch und bedarfsgerecht zugewiesen. Trotz des Namens sind physisch weiterhin Server im Einsatz – sie sind lediglich für den Entwickler abstrahiert.

Function as a Service

Die bekannteste Ausprägung des Serverless Computing ist Function as a Service (FaaS). Dabei wird Anwendungslogik in einzelne Funktionen zerlegt, die ereignisgesteuert ausgeführt werden, etwa bei einem HTTP-Aufruf, einer Datenbankänderung oder einer hochgeladenen Datei. Beispiele für FaaS-Angebote sind AWS Lambda, Microsoft Azure Functions und Google Cloud Functions.

Die Abrechnung erfolgt nach tatsächlicher Nutzung, beispielsweise pro Aufruf und Rechenzeit, anstatt für durchgehend reservierte Kapazität. Funktionen sind typischerweise zustandslos; dauerhafte Daten werden in externen Diensten wie Datenbanken oder Objektspeichern abgelegt.

Vor- und Nachteile

Zu den Vorteilen zählen der Wegfall von Serveradministration, die automatische Skalierung auch auf null Instanzen bei Nichtnutzung und die nutzungsabhängige Abrechnung. Nachteile können Latenzzeiten beim Kaltstart von Funktionen, eingeschränkte Ausführungsdauer, schwierigeres Debugging sowie eine starke Bindung an die Dienste eines Anbieters (Vendor Lock-in) sein.
