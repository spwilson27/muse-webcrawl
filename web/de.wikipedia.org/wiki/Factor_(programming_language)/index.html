Factor ist eine dynamisch typisierte, stapelbasierte Programmiersprache, die ab 2003 von Slava Pestov entwickelt wurde. Sie gehört zur Familie der konkatenativen Sprachen, deren bekanntester Vertreter Forth ist, verbindet dieses Modell aber mit Elementen funktionaler und objektorientierter Sprachen sowie einer umfangreichen Standardbibliothek.

Die interaktive Entwicklungsumgebung von Factor

Merkmale

Programme bestehen aus der Verkettung von „Wörtern" (Funktionen), die Werte vom Datenstapel konsumieren und Ergebnisse zurücklegen. Factor besitzt ein System generischer Wörter und Klassen einfacher Vererbung, lexikalische Closures, Fortsetzungen (Continuations) und Makros. Die Umgebung ist imagebasiert und interaktiv: Code kann zur Laufzeit in einer grafischen Entwicklungsumgebung verändert werden, die unter anderem einen Listener, einen Inspector und Hilfsmittel zur Ablaufverfolgung enthält.

Geschichte

Factor begann als Skriptsprache für ein Computerspiel und wurde zunächst in Java, später in C++ und schließlich weitgehend in Factor selbst implementiert. Die Laufzeitumgebung (Virtual Machine) übernimmt Speicherbereinigung und die Kompilierung zu nativem Maschinencode. Die Sprache steht unter einer BSD-Lizenz und wird von einer Community weiterentwickelt.
