Adjungierte Matrix

Aus Wikipedia, der freien Enzyklopädie

Die adjungierte Matrix (englisch conjugate transpose) einer komplexen Matrix ist die Matrix, die durch Transponieren und komplexes Konjugieren aller Einträge entsteht. Sie wird mit A* oder AH bezeichnet und ist das komplexe Analogon der transponierten Matrix im Reellen.

Definition

Für eine komplexe Matrix A mit Einträgen aij ist die Adjungierte definiert durch (A*)ij = āji, wobei der Querstrich die komplexe Konjugation bezeichnet. Man erhält sie also, indem man zunächst die Matrix an der Hauptdiagonalen spiegelt und anschließend jeden Eintrag konjugiert.

Rechenregeln

  • (A + B)* = A* + B*
  • (cA)* = c̄ A* für eine komplexe Zahl c
  • (AB)* = B* A*
  • (A*)* = A
  • (A−1)* = (A*)−1, falls A invertierbar ist

Eigenschaften und Spezialfälle

Eine Matrix heißt hermitesch (oder selbstadjungiert), wenn A* = A gilt, und unitär, wenn A*A = I gilt. Im reellen Fall stimmen Adjungierte und Transponierte überein. Die Adjungierte spielt eine zentrale Rolle bei der Definition des Skalarprodukts über den komplexen Zahlen: Für Vektoren x und y gilt ⟨x, y⟩ = x* y.

Anwendungen

Adjungierte Matrizen treten in der Quantenmechanik (adjungierte Operatoren), in der Signalverarbeitung sowie bei der Methode der kleinsten Quadrate für komplexe Daten auf.
