File Transfer Protocol (FTP)

Schicht: Anwendungsschicht

Ports: 21 (Steuerung), 20 (Daten, aktiv)

Standard: RFC 959 (1985)

Das File Transfer Protocol (FTP) ist ein Netzwerkprotokoll zur Übertragung von Dateien zwischen einem Client und einem Server. Es gehört zu den ältesten Protokollen des Internets; seine Ursprünge reichen bis 1971 zurück, der bis heute maßgebliche Standard wurde 1985 in RFC 959 festgelegt.

Funktionsweise

FTP arbeitet mit zwei Verbindungen: Über den Steuerkanal (Port 21) sendet der Client Textbefehle wie USER, LIST oder RETR und empfängt numerische Antwortcodes. Die eigentlichen Dateien fließen über eine separate Datenverbindung, im aktiven Modus auf Port 20, im passiven Modus (PASV) auf einem vom Server geöffneten Port — letzteres funktioniert besser hinter Firewalls und NAT-Routern.

Sicherheit und Nachfolger

FTP überträgt Passwörter und Daten unverschlüsselt. Sichere Alternativen sind FTPS (FTP über TLS) und das nicht verwandte SFTP, das auf SSH aufsetzt. Für die Pflege von Websites wurde FTP lange genutzt, wird heute aber zunehmend durch neuere Verfahren verdrängt.
