Lineare Erweiterung

Eine lineare Erweiterung (englisch linear extension) einer partiellen Ordnung (Halbordnung) auf einer Menge ist eine totale Ordnung (lineare Ordnung) derselben Menge, die alle Relationen der ursprünglichen Halbordnung respektiert: Stehen zwei Elemente in der Halbordnung in Beziehung, so stehen sie in der linearen Erweiterung in derselben Reihenfolge. Anschaulich entspricht eine lineare Erweiterung einer Anordnung aller Elemente in einer Reihe, bei der kein Element vor einem von ihm abhängigen Element steht.

Existenz und Anzahl

Nach dem Ordnungserweiterungssatz (Edward Marczewski, 1930) besitzt jede Halbordnung auf einer endlichen Menge mindestens eine lineare Erweiterung; für unendliche Mengen folgt die Existenz aus einem schwachen Auswahlaxiom. Die Anzahl der linearen Erweiterungen einer Halbordnung zu bestimmen ist im Allgemeinen ein schwieriges kombinatorisches Problem; für endliche Mengen ist es #P-vollständig (Brightwell und Winkler, 1991). Für spezielle Klassen – etwa Ordnungen von Dimension zwei oder Bäume – existieren effiziente Zählverfahren.

Anwendungen

Lineare Erweiterungen treten als topologische Sortierungen gerichteter azyklischer Graphen in der Informatik auf, etwa bei der Ablaufplanung von Aufgaben mit Abhängigkeiten (Scheduling) und bei der Auflösung von Abhängigkeiten in Build-Systemen und Paketverwaltungen. In der Sozialwahltheorie und Statistik dienen sie zur Analyse von Rangfolgen und Präferenzordnungen.

Beispiel

Die Teilmengenordnung auf den Teilmengen von {1, 2} hat die Inklusionen ∅ ⊂ {1}, ∅ ⊂ {2}, {1} ⊂ {1,2}, {2} ⊂ {1,2}. Die beiden linearen Erweiterungen lauten ∅, {1}, {2}, {1,2} sowie ∅, {2}, {1}, {1,2}.
