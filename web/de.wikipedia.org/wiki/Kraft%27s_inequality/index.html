Kraft-Ungleichung

Die Kraft-Ungleichung (auch Kraft-McMillan-Ungleichung) ist ein Satz der Informationstheorie. Sie gibt eine notwendige und hinreichende Bedingung dafür an, dass zu vorgegebenen Codewortlängen ein eindeutig decodierbarer Präfixcode existiert. Sie wurde 1949 von Leon G. Kraft formuliert und später von Brockway McMillan auf allgemein eindeutig decodierbare Codes verallgemeinert.

Aussage

Für einen Präfixcode über einem Alphabet der Größe r mit Codewortlängen l1, …, ln gilt:

Σ r−li ≤ 1

Gilt umgekehrt diese Ungleichung für gegebene Längen, so existiert ein Präfixcode mit genau diesen Codewortlängen. Für binäre Codes (r = 2) lautet die Bedingung Σ 2−li ≤ 1.

Bedeutung

Die Ungleichung ist grundlegend für die Datenkompression: Sie begrenzt, wie viele kurze Codewörter ein Code besitzen kann, und spielt beim Beweis der Optimalität der Huffman-Codierung eine zentrale Rolle.
