ANSI-Escape-Sequenz

ANSI-Escape-Sequenzen sind Zeichenfolgen, die mit dem Escape-Zeichen (ESC, Code 0x1B) beginnen und zur Steuerung von Textterminals verwendet werden. Sie ermöglichen unter anderem die Positionierung des Cursors, das Löschen von Bildschirmbereichen sowie die Änderung von Textfarben und -attributen. Sie gehen auf den Standard ANSI X3.64 beziehungsweise ECMA-48 zurück und wurden durch die weit verbreiteten VT-Terminals von DEC populär.

Codierung

Die bekannteste Gruppe sind die CSI-Sequenzen (Control Sequence Introducer), die mit ESC [ eingeleitet werden, gefolgt von Parametern und einem Schlusszeichen. Beispiele:

ESC [ 2 J   Bildschirm löschen
ESC [ 1 ; 31 m   Text fett und rot darstellen
ESC [ 5 ; 10 H   Cursor in Zeile 5, Spalte 10 positionieren

Die sogenannten SGR-Sequenzen (Select Graphic Rendition) enden auf m und legen Farben und Attribute fest. Der ursprüngliche ANSI-Standard sah acht Vordergrundfarben vor; später kamen helle Varianten sowie 256-Farben- und 24-Bit-Truecolor-Modi hinzu.

Verwendung

ANSI-Escape-Sequenzen werden von nahezu allen Terminal-Emulatoren unter Unix/Linux unterstützt; unter Windows setzte Microsoft sie ab Windows 10 weitgehend in der Konsole um. Sie bilden die Grundlage für textbasierte Benutzeroberflächen (Curses), farbige Kommandozeilenausgaben und ANSI-Art.
