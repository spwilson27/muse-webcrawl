Polynomring

Ein Polynomring ist in der Algebra die Menge aller Polynome in einer oder mehreren Veränderlichen mit Koeffizienten aus einem gegebenen Ring, versehen mit der üblichen Addition und Multiplikation von Polynomen. Für einen Ring R bezeichnet man den Polynomring in der Variablen X mit R[X].

Konstruktion

Formal lässt sich R[X] als die Menge der Folgen von Elementen aus R definieren, die nur endlich viele von null verschiedene Glieder besitzen; Addition erfolgt komponentenweise, die Multiplikation entspricht der Faltung der Folgen. Die Variable X selbst entspricht dabei der Folge (0, 1, 0, 0, …). Polynomringe in mehreren Variablen entstehen durch Iteration, etwa R[X, Y] = (R[X])[Y].

Eigenschaften

  • Ist R ein Integritätsring, so auch R[X]; die Einheiten von R[X] sind genau die Einheiten von R.
  • Ist K ein Körper, so ist K[X] ein euklidischer Ring bezüglich des Grades als euklidischer Funktion (Division mit Rest), folglich ein Hauptidealring und faktorieller Ring.
  • Ist R faktoriell, so ist auch R[X] faktoriell (Satz von Gauß).
  • Der Hilbertsche Basissatz besagt: Ist R noethersch, so ist auch R[X] noethersch.

Universelle Eigenschaft

Der Polynomring R[X] ist durch eine universelle Eigenschaft charakterisiert: Jede Ringhomomorphismus von R in einen Ring S lässt sich zusammen mit der Wahl eines Elements von S eindeutig zu einem Homomorphismus R[X] → S fortsetzen, der X auf das gewählte Element abbildet. Dies drückt aus, dass ein Polynom in jeder R-Algebra „ausgewertet“ werden kann.

Bedeutung

Polynomringe sind das zentrale Werkzeug der algebraischen Geometrie: Die Nullstellenmengen von Polynomen in mehreren Variablen definieren algebraische Varietäten, und den Idealen im Polynomring entsprechen über den Hilbertschen Nullstellensatz geometrische Objekte.
