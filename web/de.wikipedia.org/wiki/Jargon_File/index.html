Jargon File

Das Jargon File ist eine Sammlung von Slangausdrücken und Humor der Hacker- und Programmiererkultur. Es entstand ab 1975 am Stanford Artificial Intelligence Laboratory und wurde an weiteren US-Universitäten, darunter dem MIT, weitergeführt.

Geschichte und Ausgaben

1983 erschien das Jargon File erstmals in Buchform als The Hacker's Dictionary. Die von Eric S. Raymond betreute Ausgabe erschien 1991 als The New Hacker's Dictionary und erlebte mehrere Auflagen. Das Werk dokumentiert Wortschatz, Bräuche und Folklore der frühen Hacker-Szene.

Bedeutung

Das Jargon File gilt als historisches Dokument der Computerkultur; zahlreiche Begriffe daraus, etwa „Foo" und „Bar", gingen in den allgemeinen IT-Sprachgebrauch ein.
