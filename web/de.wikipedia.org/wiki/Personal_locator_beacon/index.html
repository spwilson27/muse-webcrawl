Personal Locator Beacon

Ein Personal Locator Beacon (PLB) ist ein tragbarer Notfallsender, der im Notfall ein Signal auf der internationalen Notfrequenz 406 MHz an das Satellitensystem Cospas-Sarsat sendet. Damit können Rettungskräfte die Position einer in Not geratenen Person bestimmen, etwa bei Wanderungen, Bergtouren, Segelreisen oder in abgelegenen Gebieten ohne Mobilfunkempfang.

Funktionsweise

Nach der manuellen Aktivierung sendet das Gerät ein kodiertes Notsignal mit einer eindeutigen Gerätekennung. Moderne PLBs verfügen zusätzlich über einen GPS-Empfänger, der die aktuelle Position in das Signal einbettet. Das Signal wird von Satelliten empfangen und an Bodenstationen weitergeleitet, die die zuständige Rettungsleitstelle alarmieren. Viele Geräte besitzen außerdem einen Peilsender auf 121,5 MHz, der die Ortung im Nahbereich erleichtert.

Registrierung

PLBs müssen in der Regel beim Kauf auf den Eigentümer registriert werden, damit Rettungskräfte im Alarmfall Kontakt- und Notfalldaten abrufen können. Die Registrierung ist in vielen Ländern kostenlos.

Abgrenzung

Im Gegensatz zu einem PLB, das einer Person zugeordnet ist, ist eine EPIRB (Emergency Position Indicating Radio Beacon) einem Schiff zugeordnet und wird automatisch durch Wasserkontakt aktiviert.
