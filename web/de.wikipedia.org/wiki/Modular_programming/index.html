Modulare Programmierung

Modulare Programmierung ist ein Programmierparadigma und ein Entwurfsprinzip der Softwareentwicklung, bei dem ein Programm in weitgehend unabhängige, wiederverwendbare Bausteine (Module) zerlegt wird. Jedes Modul kapselt eine bestimmte Funktionalität und stellt sie über eine klar definierte Schnittstelle bereit, während die interne Implementierung verborgen bleibt (Geheimnisprinzip, Information Hiding).

Geschichte

Das Konzept geht wesentlich auf David Parnas zurück, der Anfang der 1970er Jahre Kriterien für die Zerlegung von Systemen in Module formulierte. Programmiersprachen wie Modula-2 (von Niklaus Wirth), Ada und später Oberon stellten Module als Sprachkonstrukt zur Verfügung. In modernen Sprachen existieren Module unter anderem als Pakete (Java, Python), Module (JavaScript, Rust) oder Bibliotheken.

Vorteile

  • Bessere Übersichtlichkeit und Wartbarkeit großer Systeme
  • Wiederverwendbarkeit und getrenntes Testen
  • Teamarbeit durch klare Schnittstellen
  • Austauschbarkeit einzelner Implementierungen
