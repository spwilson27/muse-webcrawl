Konformer Bootstrap

Der konforme Bootstrap ist eine nichtperturbative Methode der theoretischen Physik zur Untersuchung konformer Feldtheorien (CFT). Statt von einer Lagrange-Dichte auszugehen, nutzt sie allein die Konsistenzbedingungen der Symmetrie – insbesondere die Kreuzungssymmetrie (Crossing-Symmetrie) der Operatorproduktentwicklung – um die Daten einer Theorie (Skalendimensionen und OPE-Koeffizienten) einzuschränken oder zu bestimmen.

Grundidee

Eine Vierpunktfunktion von Operatoren lässt sich auf zwei verschiedene Weisen in konforme Blöcke zerlegen. Die Gleichheit beider Zerlegungen liefert ein unendliches System von Konsistenzgleichungen. Moderne numerische Verfahren, maßgeblich vorangetrieben durch Arbeiten von Rattazzi, Rychkov, Tonni und Vichi (2008), übersetzen diese Gleichungen in Semidefinite Programme und erhalten so strenge Schranken an die Daten jeder CFT mit vorgegebenen Symmetrien.

Ergebnisse

Berühmt ist die hochpräzise Bestimmung der kritischen Exponenten des dreidimensionalen Ising-Modells, die zu den genauesten bekannten Werten zählt und ohne Monte-Carlo-Simulation auskommt. Auch das O(N)-Modell und Theorien mit Supersymmetrie wurden so untersucht.
