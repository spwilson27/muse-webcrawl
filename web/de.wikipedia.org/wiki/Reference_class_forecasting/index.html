Reference Class Forecasting

Reference Class Forecasting (RCF), auf Deutsch etwa „Prognose auf Grundlage einer Referenzklasse", ist eine Methode zur realistischen Vorhersage von Kosten, Dauer und Nutzen von Projekten. Sie wurde vom dänisch-amerikanischen Planungswissenschaftler Bent Flyvbjerg auf der Grundlage der Arbeiten von Daniel Kahneman und Amos Tversky entwickelt.

Verfahren

Statt sich allein auf die Innenansicht eines Einzelvorhabens zu verlassen, nimmt die Methode die „Außenperspektive" ein:

  • Es wird eine Referenzklasse vergleichbarer, bereits abgeschlossener Projekte bestimmt.
  • Für diese Klasse wird die statistische Verteilung der tatsächlichen Abweichungen (etwa Kostenüberschreitungen) ermittelt.
  • Die Prognose für das eigene Projekt wird anhand dieser Verteilung angepasst, zum Beispiel auf ein gewünschtes Sicherheitsniveau (P50, P80).

Hintergrund

RCF korrigiert zwei systematische Verzerrungen der Projektplanung: den Planungsfehlschluss (planning fallacy) und den Optimismus-Bias, die dazu führen, dass Großprojekte regelmäßig teurer und langsamer werden als geplant, während der Nutzen überschätzt wird. Die Methode wird unter anderem von der britischen Regierung im Rahmen der „Optimism Bias Uplifts" und von Infrastrukturbehörden mehrerer Länder empfohlen.
