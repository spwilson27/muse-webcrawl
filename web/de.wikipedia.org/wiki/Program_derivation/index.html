Programmableitung
Englisch: Program Derivation

Gebiet:
Formale Methoden
Informatik

Verwandte Methoden:
Verfeinerung
Hoare-Logik

Die Programmableitung (englisch program derivation) ist eine Methode der formalen Softwareentwicklung, bei der ein Programm systematisch aus einer formalen Spezifikation abgeleitet wird. Statt ein Programm zu schreiben und anschließend zu verifizieren, wird das Programm Schritt für Schritt so konstruiert, dass es die Spezifikation per Konstruktion erfüllt.

Grundidee

Der Ausgangspunkt ist eine formale Spezifikation, die angibt, was ein Programm leisten soll, ohne festzulegen, wie dies geschehen soll. Durch Anwendung von Transformationsregeln — etwa der Verfeinerung (Refinement) — wird die Spezifikation schrittweise in ausführbaren Code überführt. Jeder Schritt muss die Korrektheit bewahren; die resultierende Korrektheit folgt dann aus der Korrektheit der einzelnen Schritte.

Verwandte Ansätze

  • Verfeinerung (Refinement): Die Ersetzung einer abstrakten Spezifikation durch eine konkretere, wobei die Semantik erhalten bleibt.
  • Hoare-Logik: Ein Kalkül zur Begründung der Korrektheit von Programmen anhand von Vor- und Nachbedingungen.
  • Transformationale Programmentwicklung: Die systematische Umformung von Spezifikationen in effiziente Implementierungen.

Die Programmableitung war insbesondere in den 1970er und 1980er Jahren Gegenstand intensiver Forschung, etwa in der Arbeit von Edsger W. Dijkstra, der in seinem Buch A Discipline of Programming (1976) die systematische Entwicklung korrekter Programme vorführte.
