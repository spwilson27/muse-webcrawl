Network Function Virtualization

Network Function Virtualization (NFV, deutsch etwa „Virtualisierung von Netzwerkfunktionen") ist ein Konzept der Telekommunikations- und Netzwerktechnik, bei dem Netzwerkfunktionen, die traditionell auf spezialisierter, proprietärer Hardware ausgeführt wurden, als Software auf handelsüblichen Servern (COTS) betrieben werden. Ziel ist es, die Flexibilität zu erhöhen, Kosten zu senken und neue Dienste schneller einführen zu können.

Geschichte

Das Konzept wurde im Oktober 2012 von einer Gruppe führender Telekommunikationsanbieter in einem White Paper vorgestellt, das auf der Konferenz „SDN and OpenFlow World Congress" in Darmstadt veröffentlicht wurde. Im November 2012 wurde beim European Telecommunications Standards Institute (ETSI) die Industry Specification Group (ISG) NFV gegründet, die ein Referenzarchitektur-Framework erarbeitete.

Architektur

Die ETSI-NFV-Referenzarchitektur besteht im Wesentlichen aus drei Komponenten:

  • Virtualisierte Netzwerkfunktionen (VNFs): Softwareimplementierungen von Netzwerkfunktionen wie Firewalls, Load-Balancer, Router oder Deep-Packet-Inspection-Systemen.
  • NFV-Infrastruktur (NFVI): Die Gesamtheit der Hard- und Softwareressourcen (Rechen-, Speicher- und Netzwerkressourcen), auf denen die VNFs laufen, einschließlich einer Virtualisierungsschicht (Hypervisor oder Container).
  • MANO (Management and Orchestration): Verwaltung und Orchestrierung der Lebenszyklen der VNFs und der zugehörigen Ressourcen, bestehend aus NFV Orchestrator, VNF Manager und Virtualized Infrastructure Manager.

Verhältnis zu SDN

NFV wird häufig gemeinsam mit Software-defined Networking (SDN) genannt. Während SDN die Trennung von Steuerungs- und Datenebene im Netzwerk beschreibt, zielt NFV auf die Entkopplung der Netzwerkfunktionen von dedizierter Hardware. Beide Konzepte ergänzen sich, sind aber unabhängig voneinander nutzbar.

Anwendungsbereiche

NFV spielt insbesondere bei Mobilfunknetzen (etwa virtuellen Evolved Packet Cores), bei der Bereitstellung kundennaher Dienste (virtual CPE), bei Content Delivery Networks und im Umfeld von 5G eine Rolle, wo Network Slicing auf virtualisierter Infrastruktur aufbaut.
