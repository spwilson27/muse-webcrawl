Objekt (Informatik)

Ein Objekt ist in der Informatik eine Einheit, die Daten (Zustand) und Funktionen (Verhalten) zusammenfasst. Objekte sind der zentrale Baustein der objektorientierten Programmierung. Ein Objekt wird zur Laufzeit nach dem Bauplan einer Klasse erzeugt und besitzt eine eigene Identität, die es von anderen Objekten unterscheidet — selbst dann, wenn deren Zustände gleich sind.

Eigenschaften

  • Identität: Jedes Objekt ist eindeutig unterscheidbar.
  • Zustand: Die Gesamtheit der Werte seiner Attribute zu einem Zeitpunkt.
  • Verhalten: Die Operationen (Methoden), die ein Objekt ausführen kann, oft als Reaktion auf Nachrichten anderer Objekte.
  • Lebenszyklus: Ein Objekt wird erzeugt, existiert eine gewisse Zeit und wird schließlich zerstört beziehungsweise vom Garbage Collector freigegeben.

Objekte in verschiedenen Sprachen

In klassenbasierten Sprachen wie Java oder C++ werden Objekte als Instanzen von Klassen erzeugt. In prototypenbasierten Sprachen wie JavaScript entstehen neue Objekte durch Klonen bestehender Objekte. Manche Sprachen wie Ruby behandeln auch elementare Werte vollständig als Objekte.
