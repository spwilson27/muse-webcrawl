Listenkantenfärbung

Die Listenkantenfärbung (englisch list edge coloring) ist ein Begriff aus der Graphentheorie. Sie ist die auf die Kanten eines Graphen übertragene Variante der Listenfärbung: Jeder Kante wird eine Liste erlaubter Farben zugeordnet, und gesucht ist eine zulässige Kantenfärbung, bei der jede Kante eine Farbe aus ihrer eigenen Liste erhält und an einem gemeinsamen Knoten zusammentreffende Kanten stets verschiedene Farben haben.

Definition

Die Listenkantenchromatikzahl (englisch list chromatic index) ch′(G) eines Graphen G ist die kleinste Zahl k, sodass der Graph für jede Listenzuweisung mit mindestens k Farben pro Kante eine zulässige Listenkantenfärbung besitzt. Sie ist stets mindestens so groß wie die gewöhnliche Kantenchromatikzahl χ′(G), die nach dem Satz von Vizing entweder dem Maximalgrad Δ oder Δ + 1 entspricht.

Listenfärbungsvermutung

Die bekannte Listenfärbungsvermutung (englisch list coloring conjecture oder list edge coloring conjecture) besagt, dass für jeden (Multi-)Graphen stets ch′(G) = χ′(G) gilt, die Einschränkung auf Listen also die benötigte Farbzahl nicht erhöht. Sie wurde in den 1970er-Jahren unter anderem von Vizing sowie von Erdős, Rubin und Taylor aufgestellt und ist trotz intensiver Forschung bis heute unbewiesen. Für wichtige Graphenklassen ist sie jedoch verifiziert, etwa für bipartite Graphen: Fred Galvin bewies 1995 mit einem eleganten kombinatorischen Argument über stabile Matchings, dass die Vermutung für alle bipartiten Graphen gilt.
