Layout

Das Layout (englisch für „Anlage, Anordnung“), im Deutschen auch Seitenlayout genannt, bezeichnet die gestalterische Anordnung von Texten, Bildern und grafischen Elementen auf einer Seite oder einem anderen Medium. Es ist ein zentraler Bestandteil des Grafikdesigns und des Desktop Publishing.

Elemente

Zum Layout gehören unter anderem:

  • das Seitenformat und der Satzspiegel (der bedruckte Bereich einer Seite)
  • die Anordnung in Spalten und die Verwendung eines Gestaltungsrasters (grid)
  • Typografie: Schriftarten, Schriftgrößen, Zeilenabstände und Auszeichnung
  • die Platzierung von Überschriften, Fließtext, Bildern, Bildunterschriften und Fußnoten
  • der Umgang mit Weißraum (Leere zwischen den Elementen)

Gestaltungsprinzipien

Ein gutes Layout führt das Auge des Lesers, schafft Hierarchien und macht Inhalte schnell erfassbar. Zu den klassischen Prinzipien zählen Ausrichtung, Nähe (Zusammengehöriges steht nah beieinander), Wiederholung einheitlicher Stilelemente und Kontrast, etwa zwischen Überschrift und Fließtext. In der Editorial-Gestaltung sorgen Musterseiten (master pages) für ein konsistentes Erscheinungsbild aller Seiten einer Publikation.

Layout im Webdesign

Im Webdesign wird das Layout mit HTML und CSS umgesetzt. Anders als im Druck muss es sich an unterschiedliche Bildschirmgrößen anpassen (Responsive Webdesign); moderne CSS-Techniken wie Flexbox und Grid ermöglichen flexible Anordnungen. Da der Inhalt auf dem Bildschirm nicht auf feste Seiten verteilt ist, spricht man hier eher von Bildschirm- als von Seitenlayout.
