Canvas-Element

Das Canvas-Element (englisch canvas = Leinwand) ist ein Element der Auszeichnungssprache HTML5, das eine frei programmierbare Zeichenfläche im Webbrowser bereitstellt. Über eine JavaScript-API lassen sich zweidimensionale Grafiken, Bilder, Animationen und Spiele in Echtzeit rendern.

Geschichte

Canvas wurde 2004 von Apple für das Dashboard von Mac OS X eingeführt und später vom WHATWG standardisiert. Heute wird das Element von allen gängigen Browsern unterstützt.

Verwendung

Im HTML-Code wird die Fläche mit dem Tag <canvas> mit Breiten- und Höhenattributen angelegt:

<canvas id="leinwand" width="300" height="150"></canvas>

Per JavaScript erhält man über getContext('2d') den 2D-Zeichenkontext mit Methoden zum Füllen von Flächen, Zeichnen von Pfaden, Text und Bildern. Alternativ erlaubt der Kontexttyp webgl hardwarebeschleunigte 3D-Grafik (WebGL).

Anwendungsgebiete

Canvas wird für Diagramme, Bildbearbeitung im Browser, Spiele, Datenvisualisierung und interaktive Kunst eingesetzt. Im Gegensatz zu SVG, das Vektorgrafiken als Dokumentobjekte verwaltet, arbeitet Canvas pixelbasiert und unmittel­bar („immediate mode"), was es für große Datenmengen und Animationen effizient macht. Für die Barrierefreiheit müssen Inhalte der Zeichenfläche zusätzlich textuell beschrieben werden.
