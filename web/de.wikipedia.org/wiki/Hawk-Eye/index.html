Hawk-Eye

Hawk-Eye ist ein computergestütztes System zur Verfolgung von Ballflugbahnen im Sport, das vor allem im Tennis, Cricket und Fußball eingesetzt wird. Es wurde Anfang der 2000er-Jahre von dem britischen Ingenieur Paul Hawkins entwickelt und gehört heute zur Sony-Gruppe.

Funktionsweise

Mehrere Hochgeschwindigkeitskameras erfassen den Ball aus verschiedenen Winkeln. Aus den Bildern berechnet das System die dreidimensionale Flugbahn und kann so anzeigen, ob ein Ball innerhalb oder außerhalb einer Spielfeldlinie aufkam.

Einsatz

Im Tennis wurde Hawk-Eye 2006 offiziell eingeführt; Spieler können Schiedsrichterentscheidungen per „Challenge" überprüfen lassen. Im Fußball bildet das System seit 2012 die Grundlage der Torlinientechnik, im Cricket dient es zur Überprüfung von LBW-Entscheidungen.
