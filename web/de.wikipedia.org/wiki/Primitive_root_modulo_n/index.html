Primitive Wurzel modulo n

Eine primitive Wurzel modulo n ist in der Zahlentheorie eine ganze Zahl g, deren Potenzen modulo n sämtliche zu n teilerfremden Restklassen durchlaufen. Äquivalent dazu hat g in der multiplikativen Gruppe der Einheiten modulo n die größtmögliche Ordnung, nämlich φ(n), wobei φ die Eulersche Phi-Funktion bezeichnet. Eine primitive Wurzel ist also ein Erzeuger der Einheitengruppe (Z/nZ)×.

Existenz

Primitive Wurzeln modulo n existieren genau dann, wenn die Einheitengruppe zyklisch ist. Dies ist der Fall für n = 1, 2, 4, für ungerade Primzahlpotenzen pk sowie für deren Doppelte 2pk. Insbesondere besitzt jede Primzahl p primitive Wurzeln; ihre Anzahl beträgt φ(p − 1).

Beispiel

Modulo 5 ist 2 eine primitive Wurzel: Die Potenzen 21 = 2, 22 = 4, 23 = 3 und 24 = 1 durchlaufen alle zu 5 teilerfremden Reste. Ebenso ist 3 eine primitive Wurzel modulo 5, während 4 die Ordnung 2 hat und daher keine ist.

Anwendungen

Primitive Wurzeln spielen eine Rolle bei der Kryptographie, etwa beim Diffie-Hellman-Schlüsselaustausch, der auf dem Problem des diskreten Logarithmus beruht, sowie bei der Erzeugung von Pseudozufallszahlen und in der Kodierungstheorie.

Geschichte

Der Begriff wurde von Carl Friedrich Gauß in seinen Disquisitiones Arithmeticae (1801) systematisch eingeführt. Gauß bewies unter anderem, dass es zu jeder Primzahl primitive Wurzeln gibt.
