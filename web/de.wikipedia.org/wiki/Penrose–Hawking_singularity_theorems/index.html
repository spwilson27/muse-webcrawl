Singularitäten-Theoreme von Penrose und Hawking

Die Singularitäten-Theoreme von Penrose und Hawking sind eine Reihe von Ergebnissen der Allgemeinen Relativitätstheorie, die besagen, dass unter sehr allgemeinen Bedingungen in der Raumzeit Singularitäten – genauer: geodätische Unvollständigkeit – auftreten müssen.

Übersicht

Roger Penrose bewies 1965 das erste moderne Singularitäten-Theorem: Kollabiert Materie so weit, dass eine geschlossene gefangene Fläche (trapped surface) entsteht, so ist die Raumzeit geodätisch unvollständig – ein Hinweis auf die Entstehung eines Schwarzen Lochs. Stephen Hawking übertrug die Methoden auf die Kosmologie und zeigte, dass ein expandierendes Universum unter allgemeinen Annahmen aus einem Anfangszustand (Urknall) hervorgegangen sein muss. Das gemeinsame Hawking-Penrose-Theorem von 1970 fasste die Ergebnisse zusammen.

Bedingungen

Die Theoreme benötigen im Wesentlichen eine Energiebedingung (Materie gravitiert anziehend), eine Kausalitätsbedingung und eine Anfangs- oder Randbedingung, etwa das Vorliegen einer gefangenen Fläche oder einer kompakten Cauchy-Fläche mit überall positiver Expansion.

Bedeutung

Die Theoreme gelten als Meilensteine der mathematischen Relativitätstheorie. Sie zeigen, dass Singularitäten kein Artefakt spezieller Symmetrien sind, sondern eine generische Eigenschaft der Einsteinschen Feldgleichungen. Für seine Arbeiten zu Schwarzen Löchern erhielt Penrose 2020 den Nobelpreis für Physik.
