IP-Adresse

Eine IP-Adresse ist eine Adresse in Computernetzwerken, die auf dem Internetprotokoll (IP) basieren. Sie wird Geräten zugewiesen, die an das Netz angebunden sind, und macht diese so adressierbar und damit erreichbar. Eine IP-Adresse besteht aus einem Netzwerkteil und einem Hostteil; Router leiten Datenpakete anhand des Netzwerkteils an das Zielnetz weiter.

IPv4

Adressen des Protokolls IPv4 sind 32 Bit lang und werden üblicherweise in dezimaler Punktnotation aus vier Zahlen von 0 bis 255 geschrieben, zum Beispiel 192.168.0.1. Damit stehen rund 4,3 Milliarden Adressen zur Verfügung. Bestimmte Bereiche sind für private Netze reserviert (z. B. 192.168.0.0/16) und werden im Internet nicht geroutet; Network Address Translation (NAT) ermöglicht es vielen Geräten, sich eine öffentliche Adresse zu teilen. Wegen der weltweit knappen IPv4-Adressen wurde der Nachfolger IPv6 entwickelt.

IPv6

IPv6-Adressen sind 128 Bit lang und werden hexadezimal in durch Doppelpunkte getrennten Gruppen notiert, zum Beispiel 2001:0db8:85a3:0000:0000:8a2e:0370:7334. Der Adressraum umfasst etwa 3,4 × 1038 Adressen, sodass jedem Gerät ohne Weiteres eine weltweit eindeutige Adresse zugewiesen werden kann. IPv6 vereinfacht außerdem die automatische Adresskonfiguration und macht NAT in vielen Fällen entbehrlich.

Vergabe und Verwaltung

Die weltweite Organisation der Adressräume obliegt der Internet Assigned Numbers Authority (IANA), die große Blöcke an regionale Registrierungsstellen (RIR) wie das RIPE NCC für Europa vergibt; von dort gelangen Adressen an Provider und Endkunden. Auf einem Gerät kann eine Adresse fest konfiguriert oder dynamisch per DHCP bezogen werden. Die Zuordnung von Domainnamen zu IP-Adressen erfolgt über das Domain Name System (DNS).

Datenschutz

IP-Adressen können Rückschlüsse auf den ungefähren Standort und den Anschlussinhaber zulassen. In der Rechtsprechung des Europäischen Gerichtshofs gelten auch dynamische IP-Adressen als personenbezogene Daten, wenn der Betreiber einer Website über rechtliche Mittel verfügt, den Anschlussinhaber identifizieren zu lassen.
