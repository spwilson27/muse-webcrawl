Backpropagation through Time

Backpropagation through Time (BPTT, deutsch „Fehlerrückführung durch die Zeit") ist eine Erweiterung des Backpropagation-Verfahrens zum Trainieren rekurrenter neuronaler Netze (RNN). Rekurrente Netze verarbeiten Sequenzen, indem ihr verborgener Zustand von Zeitschritt zu Zeitschritt weitergegeben wird.

Verfahren

Bei BPTT wird das rekurrente Netz zunächst über eine Anzahl von Zeitschritten „entfaltet" (unfolding), so dass ein tiefes vorwärtsgerichtetes Netz entsteht, dessen Schichten den Zeitschritten entsprechen und die sich die Gewichte teilen. Auf dieses entfaltete Netz wird gewöhnliche Backpropagation angewendet; die Gradienten der gemeinsam genutzten Gewichte werden über alle Zeitschritte summiert.

Probleme

Das Training langer Sequenzen ist durch das Problem verschwindender und explodierender Gradienten erschwert: Fehler, die über viele Zeitschritte zurückpropagiert werden, schrumpfen exponentiell oder wachsen unkontrolliert, so dass langfristige Abhängigkeiten kaum gelernt werden. In der Praxis wird BPTT daher häufig nach einer begrenzten Zahl von Zeitschritten abgebrochen (truncated BPTT). Architekturen wie das Long Short-Term Memory (LSTM) wurden entwickelt, um das Gradientenproblem zu mildern.
