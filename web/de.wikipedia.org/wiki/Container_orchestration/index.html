Container-Orchestrierung

Als Container-Orchestrierung bezeichnet man die automatisierte Bereitstellung, Skalierung, Vernetzung und Verwaltung containerisierter Anwendungen über einen Verbund (Cluster) von Rechnern hinweg. Orchestrierungswerkzeuge übernehmen Aufgaben wie die Verteilung von Containern auf Knoten, den Neustart fehlerhafter Instanzen, Lastverteilung, rollierende Updates sowie die Verwaltung von Konfigurationen und Geheimnissen.

Kubernetes

Das bekannteste Orchestrierungssystem ist Kubernetes, das 2014 von Google als Open-Source-Projekt veröffentlicht wurde und heute von der Cloud Native Computing Foundation gepflegt wird. In Kubernetes werden Container zu Pods zusammengefasst; deklarative Beschreibungen legen den gewünschten Sollzustand fest, den das System fortlaufend herstellt. Weitere Systeme sind Docker Swarm und Apache Mesos.

Bedeutung

Container-Orchestrierung ist eine Schlüsseltechnologie des Cloud Computing und ermöglicht es, aus Microservices aufgebaute Anwendungen elastisch zu betreiben: Die Zahl der Instanzen passt sich der Last an, Ausfälle einzelner Knoten werden automatisch kompensiert.
