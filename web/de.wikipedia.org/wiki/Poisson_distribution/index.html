Poisson-Verteilung

Die Poisson-Verteilung ist eine diskrete Wahrscheinlichkeitsverteilung, die die Anzahl von Ereignissen beschreibt, die in einem festen Zeit- oder Raumintervall auftreten, wenn diese Ereignisse mit einer bekannten konstanten Rate und unabhängig voneinander eintreten. Sie ist nach dem französischen Mathematiker Siméon Denis Poisson benannt, der sie 1837 in seiner Arbeit Recherches sur la probabilité des jugements veröffentlichte.

Definition

P(X = k) = (λk · e−λ) / k!

Dabei ist λ > 0 der Erwartungswert (zugleich die Varianz) der Verteilung und e die eulersche Zahl. Die Wahrscheinlichkeit, dass genau k Ereignisse eintreten, hängt nur vom Parameter λ ab.

Eigenschaften

Für eine poissonverteilte Zufallsvariable X gilt:

  • Erwartungswert: E(X) = λ
  • Varianz: Var(X) = λ
  • Die Summe zweier unabhängiger poissonverteilter Zufallsvariablen mit Parametern λ1 und λ2 ist poissonverteilt mit Parameter λ1 + λ2.
  • Die Poisson-Verteilung ist ein Grenzfall der Binomialverteilung für große n und kleine Erfolgswahrscheinlichkeit p bei konstantem Produkt np = λ.

Anwendungsgebiete

Die Poisson-Verteilung wird unter anderem zur Modellierung von Anrufen in einem Callcenter, radioaktiven Zerfallsereignissen, der Anzahl von Mutationen in einem DNA-Abschnitt, Verkehrsunfällen an einer Kreuzung oder Toren in einem Fußballspiel verwendet. Ein eng verwandtes Modell ist der Poisson-Prozess.
