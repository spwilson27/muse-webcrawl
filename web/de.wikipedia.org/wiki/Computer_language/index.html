Computersprache

Eine Computersprache ist eine formale Sprache, die zur Kommunikation mit Computern dient. Der Begriff umfasst neben Programmiersprachen auch Auszeichnungssprachen, Abfragesprachen, Spezifikationssprachen und weitere formale Notationen, die von Maschinen verarbeitet werden.

Arten

Programmiersprachen wie Python, Java oder C beschreiben Algorithmen und Abläufe. Auszeichnungssprachen wie HTML und XML strukturieren Daten und Dokumente. Abfragesprachen wie SQL dienen dem Zugriff auf Datenbanken; Datenbeschreibungsformate wie JSON dem Austausch strukturierter Informationen. Auch Protokolle und Bytecodes lassen sich als Computersprachen auffassen.

Merkmale

Im Unterschied zu natürlichen Sprachen besitzen Computersprachen eine exakt definierte Syntax und Semantik, die häufig durch formale Grammatiken beschrieben wird. Compiler und Interpreter übersetzen sie in ausführbare Form beziehungsweise führen sie aus. Die Theorie der formalen Sprachen ordnet sie unter anderem in die Chomsky-Hierarchie ein.

Abstraktionsebenen

Maschinensprache ist die vom Prozessor direkt ausführbare Sprache aus Zahlenwerten; Assemblersprachen stellen ihre Befehle in mnemonischer Form dar. Höhere Programmiersprachen abstrahieren von der Hardware und erleichtern dem Menschen das Lesen und Schreiben von Programmen.
