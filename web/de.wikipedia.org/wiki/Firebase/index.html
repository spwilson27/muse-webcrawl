Firebase

Aus Wikipedia, der freien Enzyklopädie

Firebase ist eine von Google betriebene Entwicklungsplattform für mobile und Webanwendungen (Backend as a Service). Sie stellt Entwicklern unter anderem Echtzeitdatenbanken, Hosting, Authentifizierung, Cloud-Funktionen und Analysedienste bereit, ohne dass diese eine eigene Serverinfrastruktur betreiben müssen. Der Name geht ursprünglich auf ein 2011 gegründetes Startup zurück; im militärischen Sprachgebrauch bezeichnet „Firebase" zudem eine Feuerunterstützungsbasis.

Geschichte

Firebase entstand aus dem Startup Envolve, das eine Chat-API anbot und 2011 von Andrew Lee und James Tamplin gegründet wurde. Aus der dabei entwickelten Echtzeit-Synchronisation entstand 2012 die Firebase Realtime Database. Im Oktober 2014 übernahm Google das Unternehmen und baute Firebase in den Folgejahren zu einer umfassenden Plattform aus, die auf der Entwicklerkonferenz Google I/O 2016 in erweiterter Form vorgestellt wurde. 2017 kam mit Cloud Firestore eine zweite, skalierbarere Datenbank hinzu.

Produkte

Zu den wichtigsten Diensten gehören die Realtime Database und Cloud Firestore zur Datenspeicherung mit Echtzeit-Synchronisation, Firebase Authentication für die Benutzeranmeldung (unter anderem per E-Mail, Google- oder Apple-Konto), Cloud Functions für serverseitige Logik, Firebase Hosting für statische Webinhalte, Cloud Messaging (FCM) für Push-Benachrichtigungen sowie Werkzeuge zur Qualitätssicherung wie Crashlytics (Absturzberichte), Performance Monitoring und Test Lab. Mit App Check und Remote Config lassen sich Apps absichern beziehungsweise ihr Verhalten aus der Ferne konfigurieren. Die Preisgestaltung folgt einem Pay-as-you-go-Modell mit einer kostenlosen Einstiegsstufe („Spark" und „Blaze"-Tarife).

Kritik

Kritisiert werden die Abhängigkeit von einem einzelnen Anbieter (Vendor Lock-in), die proprietären Datenmodelle, die eine Migration erschweren, sowie Datenschutzfragen, weil Anwendungsdaten auf Google-Servern verarbeitet werden. Auch unerwartet hohe Kosten bei stark wachsender Nutzung werden von Entwicklern berichtet.
