RELAX NG

RELAX NG (englisch Regular Language for XML Next Generation) ist eine Schemasprache zur Beschreibung der Struktur von XML-Dokumenten. Sie wurde vom technischen Ausschuss RELAX NG der Organisation OASIS entwickelt und ist als internationaler Standard ISO/IEC 19757-2 genormt. RELAX NG entstand aus der Zusammenführung der Schemasprachen TREX (von James Clark) und RELAX (von Murata Makoto) und wurde 2001 veröffentlicht.

Eigenschaften

RELAX NG beschreibt Grammatiken für XML-Dokumente anhand von Mustern (patterns). Gegenüber XML Schema gilt die Sprache als einfacher zu erlernen und die Schemata als besser lesbar. Ein Dokument kann gegen ein RELAX-NG-Schema validiert werden; dabei wird geprüft, ob es der vorgegebenen Struktur entspricht.

Syntaxformen

RELAX NG besitzt zwei gleichwertige Syntaxformen: eine XML-Syntax, die das Schema selbst als XML-Dokument ausdrückt, und eine kompakte, nicht-XML-basierte Syntax (compact syntax), die der Notation von BNF-Grammatiken ähnelt. Beide Formen beschreiben dieselbe abstrakte Sprache und lassen sich ineinander überführen.

Verwendung

RELAX NG wird unter anderem zur Definition der Dateiformate OpenDocument und DocBook eingesetzt. Datentypen können aus XML Schema übernommen werden, da RELAX NG selbst nur eine begrenzte eigene Datentypbibliothek mitbringt.
