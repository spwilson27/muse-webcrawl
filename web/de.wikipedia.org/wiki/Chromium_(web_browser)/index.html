Chromium (Webbrowser)

EntwicklerThe Chromium Project (Google u. a.)
ErstveröffentlichungSeptember 2008
EngineBlink, V8
SprachenC++, JavaScript u. a.
Lizenzüberwiegend BSD-Lizenz

Chromium ist ein freies Webbrowser-Projekt, das überwiegend von Google getragen wird und die Codebasis für den Browser Google Chrome sowie zahlreiche weitere Browser bildet. Google veröffentlichte den Quellcode zeitgleich mit der ersten Chrome-Version im September 2008 unter der BSD-Lizenz. Der Name leitet sich vom chemischen Element Chrom ab.

Technik

Chromium nutzt die Rendering-Engine Blink, eine 2013 entstandene Abspaltung von WebKit, sowie die JavaScript-Engine V8. Das Programm verfolgt eine Multiprozess-Architektur mit Sandboxing: Jeder Tab und jede Erweiterung läuft in einem eigenen Prozess, was Stabilität und Sicherheit erhöhen soll.

Unterschiede zu Google Chrome

Gegenüber Chromium enthält Chrome proprietäre Ergänzungen, unter anderem bestimmte Audio- und Video-Codecs (AAC, H.264), ein integriertes PDF- und früher Flash-Modul, automatische Update-Mechanismen von Google, Markenzeichen sowie Nutzungs- und Absturzberichte an Google. Chromium synchronisiert standardmäßig keine Daten über Google-Dienste; die entsprechende API-Anbindung wurde für Drittanbieter-Builds 2021 eingeschränkt.

Darauf aufbauende Browser

Auf Chromium basieren unter anderem Microsoft Edge, Opera, Vivaldi, Brave, Arc und Samsungs Internet Browser sowie das Betriebssystemprojekt ChromiumOS. Dadurch hat die Blink-Engine einen weltweiten Marktanteil von deutlich über 70 Prozent bei Webbrowsern erreicht.
