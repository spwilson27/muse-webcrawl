Bootloader

Ein Bootloader (auch Bootmanager oder Urlader) ist ein Programm, das beim Start eines Computers von der Firmware geladen wird und anschließend den Kernel des Betriebssystems in den Speicher lädt und startet. Viele Bootloader bieten ein Auswahlmenü, wenn mehrere Betriebssysteme installiert sind, und erlauben das Übergeben von Startparametern an den Kernel.

Arbeitsweise

Klassisch unterschied man zwei Stufen: Der sehr kleine erste Stage befindet sich im Master Boot Record (MBR) und lädt die zweite, umfangreichere Stufe aus dem Dateisystem. Im UEFI-Modell werden Bootloader als EFI-Anwendungen von der EFI-Systempartition gestartet. Moderne Bootloader können Dateisysteme lesen, grafische Menüs darstellen, verschlüsselte Datenträger entsperren und über das Netzwerk starten.

Bekannte Bootloader

  • GRUB (Grand Unified Bootloader) – Standard unter Linux
  • Windows Boot Manager (bootmgr/BCD) – Microsoft Windows
  • systemd-boot – schlanker UEFI-Bootmanager
  • U-Boot – verbreitet in eingebetteten Systemen und ARM-Geräten
  • LILO – historischer Linux-Bootloader
