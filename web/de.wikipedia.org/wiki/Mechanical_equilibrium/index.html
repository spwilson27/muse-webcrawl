Mechanisches Gleichgewicht

Ein mechanisches System befindet sich im mechanischen Gleichgewicht (englisch mechanical equilibrium), wenn die Summe aller auf es wirkenden Kräfte und die Summe aller Drehmomente jeweils null sind. In diesem Zustand erfährt das System keine Beschleunigung und keine Drehbeschleunigung; es bleibt in Ruhe oder bewegt sich mit konstanter Geschwindigkeit geradlinig weiter.

Bedingungen

Für einen starren Körper lauten die Gleichgewichtsbedingungen:

  • Die vektorielle Summe aller äußeren Kräfte ist null: ΣF = 0.
  • Die vektorielle Summe aller äußeren Drehmomente (bezüglich eines beliebigen Punktes) ist null: ΣM = 0.

Diese Bedingungen bilden die Grundlage der Statik, eines Teilgebiets der Technischen Mechanik.

Stabilität

Man unterscheidet stabiles, labiles (instabiles) und indifferentes Gleichgewicht. Bei stabilem Gleichgewicht kehrt das System nach einer kleinen Auslenkung in seine Ausgangslage zurück, etwa eine Kugel in einer Mulde. Beim labilen Gleichgewicht entfernt es sich weiter von der Ausgangslage, etwa eine Kugel auf einer Kuppe. Beim indifferenten Gleichgewicht bleibt es in der neuen Lage, etwa eine Kugel auf einer ebenen Fläche.
