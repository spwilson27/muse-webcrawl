Game Developers Conference

Die Game Developers Conference (Abk. GDC) ist eine jährlich stattfindende Fachkonferenz für Videospielentwickler. Sie gilt als weltweit größte Veranstaltung der Spielebranche für Entwickler und umfasst Vorträge, Podiumsdiskussionen, Workshops und eine Fachmesse. Die Hauptkonferenz findet jeweils im Moscone Center in San Francisco statt.

Geschichte

Die erste Konferenz organisierte Chris Crawford 1988 als „Computer Game Developers Conference“ im Wohnzimmer bzw. mit rund 27 Teilnehmern; in den Folgejahren wuchs die Veranstaltung auf mehrere zehntausend Teilnehmer (rund 28.000 im Jahr 2019). Seit 2001 werden im Rahmen der GDC die Game Developers Choice Awards verliehen; parallel findet das Independent Games Festival statt.

Inhalte

Die Vorträge decken Programmierung, Game Design, Produktion, Grafik, Audio, Wirtschaft und Marketing ab. Bekannt sind die „Postmortems“, in denen Entwickler die Entstehung bekannter Spiele rückblickend analysieren. Veranstalter ist Informa Tech.
