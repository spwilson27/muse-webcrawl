C++

C++ ist eine standardisierte, weit verbreitete Programmiersprache. Sie wurde ab 1979 vom dänischen Informatiker Bjarne Stroustrup bei den Bell Laboratories als Erweiterung der Sprache C entwickelt – zunächst unter dem Namen „C with Classes" (C mit Klassen) – und 1983 in C++ umbenannt. C++ unterstützt mehrere Programmierparadigmen, darunter prozedurale, objektorientierte und generische Programmierung.

Geschichte

1985 erschien mit The C++ Programming Language die erste Beschreibung und die erste kommerzielle Implementierung. 1998 wurde C++ erstmals von der ISO standardisiert (C++98), gefolgt von C++03. Mit C++11 begann eine Reihe dreijährlicher Standardrevisionen (C++14, C++17, C++20, C++23), die die Sprache um Konzepte wie Lambda-Ausdrücke, Smart Pointer, Concurrency-Unterstützung, Concepts und Module erweiterten.

Eigenschaften

C++ wird meist in Maschinencode kompiliert und erlaubt eine feine Kontrolle über Speicher und Hardware, was die Sprache für Betriebssysteme, Spiele-Engines, Eingebettete Systeme und Hochleistungsrechnen prädestiniert. Zentrale Konzepte sind Klassen und Vererbung, Templates für generische Programmierung, Operatorüberladung sowie die Ressourceverwaltung nach dem RAII-Prinzip. Die C++-Standardbibliothek umfasst unter anderem die Standard Template Library (STL) mit Containern und Algorithmen.

Beispiel

#include <iostream>
int main() { std::cout << "Hallo Welt!\n"; }

Kritik und Verbreitung

C++ gilt als mächtig, aber komplex und fehleranfällig; gleichwohl gehört die Sprache seit Jahrzehnten zu den am häufigsten verwendeten Programmiersprachen weltweit und ist Grundlage vieler großer Softwaresysteme, von Browsern über Datenbanken bis zu Spielen.
