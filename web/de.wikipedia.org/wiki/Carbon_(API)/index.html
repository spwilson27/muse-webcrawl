Carbon (Programmierschnittstelle)

Carbon war eine Sammlung von Programmierschnittstellen (APIs) des Betriebssystems Mac OS beziehungsweise macOS von Apple. Sie wurde 1999 mit Mac OS 8.5 eingeführt, um Programmen aus der classic-Mac-OS-Ära den Übergang zum neuen, auf Unix basierenden Mac OS X zu erleichtern, ohne sie vollständig neu schreiben zu müssen.

Geschichte

Im Gegensatz zur von NeXT übernommenen Objective-C-Schnittstelle Cocoa bot Carbon eine prozedurale C-Schnittstelle, die an die klassische Macintosh Toolbox angelehnt war. Viele große Anwendungen, darunter Microsoft Office und die Adobe Creative Suite, wurden zunächst als Carbon-Programme auf Mac OS X portiert.

Ablösung

Mit dem Übergang zu 64-Bit-Prozessoren verlor Carbon an Bedeutung: Apple stellte die API nie vollständig in einer 64-Bit-Version bereit und erklärte sie 2012 für veraltet (deprecated). Mit macOS 10.15 Catalina (2019), das 32-Bit-Programme nicht mehr unterstützt, endete die Nutzung von Carbon endgültig.
