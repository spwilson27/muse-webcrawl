Exchangeable Image File Format

Das Exchangeable Image File Format (offizielle Abkürzung Exif) ist ein Standardformat für Metadaten, die von Digitalkameras und Scannern in Bilddateien – vor allem JPEG und TIFF – eingebettet werden. Der Standard wurde von der Japan Electronic Industries Development Association (JEIDA) entwickelt und wird heute von der CIPA gepflegt.

Inhalt der Metadaten

Exif-Daten umfassen technische Aufnahmeinformationen wie Kameramodell, Brennweite, Blende, Belichtungszeit, ISO-Wert, Datum und Uhrzeit der Aufnahme sowie gegebenenfalls GPS-Koordinaten des Aufnahmeorts (Geotagging). Außerdem kann ein Vorschaubild (Thumbnail) in der Datei gespeichert sein.

Datenschutz und Verwendung

Während Exif-Daten für die Organisation von Fotoarchiven und die Bildnachbearbeitung nützlich sind, können sie beim Veröffentlichen von Bildern sensible Informationen preisgeben, insbesondere Aufenthaltsorte. Viele soziale Netzwerke entfernen daher Exif-Daten beim Hochladen automatisch. Werkzeuge wie ExifTool erlauben das Lesen und Bearbeiten der Metadaten.
