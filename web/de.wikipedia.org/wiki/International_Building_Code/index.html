International Building Code

Der International Building Code (IBC) ist eine Musterbauordnung, die vom International Code Council (ICC) in den Vereinigten Staaten herausgegeben wird. Sie enthält Mindestanforderungen an die Sicherheit von Gebäuden, darunter Tragwerk, Brandschutz, Fluchtwege, Sanitär- und Barrierefreiheit.

Anwendung

Der IBC wurde erstmals im Jahr 2000 veröffentlicht und wird alle drei Jahre aktualisiert. Er ist in allen US-Bundesstaaten sowie von zahlreichen Kommunen als Grundlage der jeweiligen Bauordnungen übernommen worden, häufig mit lokalen Anpassungen. Ergänzend existieren Schwester Regelwerke wie der International Residential Code für Wohngebäude und der International Fire Code.

Bedeutung

Vor der Einführung des IBC galten in den USA drei konkurrierende regionale Musterbauordnungen. Ihre Vereinheitlichung vereinfachte Planung und Genehmigung von Bauvorhaben erheblich.
