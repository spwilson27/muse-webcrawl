Lightning Network

Das Lightning Network ist ein Zahlungsprotokoll, das als zweite Ebene („Layer 2“) auf der Bitcoin-Blockchain aufsetzt. Es ermöglicht nahezu sofortige Zahlungen mit sehr geringen Gebühren, indem Transaktionen außerhalb der Blockchain über ein Netzwerk von Zahlungskanälen abgewickelt und nur deren Eröffnung und Schließung in der Blockchain verankert werden.

Funktionsweise

Zwei Nutzer eröffnen einen Zahlungskanal, indem sie Bitcoin in eine gemeinsame Multisignatur-Adresse einzahlen. Innerhalb des Kanals können sie beliebig viele Zahlungen austauschen, indem sie aktualisierte, gegenseitig signierte Bilanzen austauschen, ohne diese zu veröffentlichen. Zahlungen an Dritte werden über mehrere Kanäle weitergeleitet (Routing); dabei sorgen Hashed Timelock Contracts (HTLCs) dafür, dass die Weiterleitung atomar erfolgt – entweder alle Teilschritte gelingen oder keiner.

Geschichte

Das Konzept wurde 2015 von Joseph Poon und Thaddeus Dryja in einem Whitepaper vorgestellt. Nach der Aktivierung von SegWit im Bitcoin-Netzwerk 2017 starteten 2018 die ersten Implementierungen auf dem Hauptnutz (Mainnet), darunter LND von Lightning Labs, c-lightning (heute Core Lightning) von Blockstream und Eclair von ACINQ. Die gemeinsame Protokollspezifikation heißt BOLT (Basis of Lightning Technology).

Vor- und Nachteile

  • Sehr schnelle und kostengünstige Mikrozahlungen
  • Skalierung unabhängig vom Blockgrößenlimit der Blockchain
  • Liquidität muss in Kanälen gebunden werden
  • Knoten müssen für den Empfang von Zahlungen grundsätzlich online sein
