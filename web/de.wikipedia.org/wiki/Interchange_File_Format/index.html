Interchange File Format

Das Interchange File Format (IFF) ist ein 1985 von Electronic Arts zusammen mit Commodore für den Amiga eingeführtes Container-Dateiformat. Es organisiert Daten in Blöcken (Chunks) mit vierstelligen Kennungen und Längenangaben und wurde zum Vorbild vieler späterer Formate.

Aufbau

Eine IFF-Datei besteht aus Chunks, die jeweils eine FourCC-Kennung, eine 32-Bit-Länge und die Nutzdaten enthalten. FORM-, LIST- und CAT-Chunks können weitere Chunks verschachteln.

Verwendung

Bekannte IFF-basierte Formate sind ILBM für Bilder, AIFF für Audio und ANIM für Animationen. Auch RIFF (und damit WAV und AVI) sowie das PNG-Vorläuferkonzept übernahmen die Chunk-Struktur.
