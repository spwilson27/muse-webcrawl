Git

Entwickler: Linus Torvalds (Initiator), Junio Hamano u. a.

Erstveröffentlichung: 2005

Lizenz: GNU GPL v2

Art: Verteilte Versionsverwaltung

Git ist ein freies, verteiltes Versionsverwaltungssystem für Dateien, das ursprünglich für die Entwicklung des Linux-Kernels entworfen wurde. Es wurde 2005 von Linus Torvalds initiiert und ist heute das weltweit am weitesten verbreitete Werkzeug zur Versionskontrolle in der Softwareentwicklung.

Konzept

Im Unterschied zu zentralen Systemen besitzt jede Arbeitskopie eines Git-Repositories die vollständige Projektgeschichte. Änderungen werden als Commits (Snapshots) mit kryptografischen SHA-1- bzw. SHA-256-Prüfsummen gespeichert. Zentrale Konzepte sind Branches (Entwicklungszweige), Merges, der Staging-Bereich (Index) sowie entfernte Repositories (Remotes), die über Befehle wie clone, fetch, pull und push synchronisiert werden.

Verbreitung

Git bildet die Grundlage von Hosting-Plattformen wie GitHub, GitLab und Bitbucket und ist zum Standardwerkzeug moderner Softwareteams geworden.
