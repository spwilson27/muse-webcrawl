Residuum (Funktionentheorie)

In der Funktionentheorie ist das Residuum einer holomorphen Funktion an einer isolierten Singularität eine komplexe Zahl, die das Verhalten der Funktion in der Nähe dieser Singularität beschreibt. Es ist definiert als der Koeffizient a−1 der Laurent-Reihe der Funktion um die Singularität, das heißt der Koeffizient des Terms (z − z0)−1. Der Begriff geht auf Augustin-Louis Cauchy zurück.

Definition

Ist die Funktion f in einem punktierten Gebiet um z0 holomorph und besitzt dort die Laurent-Entwicklung f(z) = Σn an (z − z0)n, so heißt Resz=z₀ f := a−1 das Residuum von f in z0. Äquivalent dazu ist das Residuum durch ein Linienintegral über eine kleine, einmal gegen den Uhrzeigersinn durchlaufene Kreisscheibe um die Singularität gegeben: Res f = (1/2πi) ∮ f(z) dz.

Berechnung

  • Hat f in z0 eine hebbare Singularität, so ist das Residuum null.
  • Bei einem Pol erster Ordnung gilt Res f = limz→z₀ (z − z0) f(z); ist f = g/h mit g(z0) ≠ 0 und einer einfachen Nullstelle von h, so gilt Res f = g(z0) / h′(z0).
  • Bei einem Pol m-ter Ordnung bestimmt man das Residuum als den (m−1)-ten Ableitungswert einer geeigneten Hilfsfunktion: Res f = 1/(m−1)! · lim dm−1/dzm−1 [(z − z0)m f(z)].
  • Bei einer wesentlichen Singularität muss der Koeffizient unmittelbar aus der Laurent-Reihe abgelesen werden.

Anwendung

Das Residuum ist der zentrale Baustein des Residuensatzes: Das Integral einer Funktion über eine geschlossene Kurve ist 2πi mal der Summe der Residuen aller eingeschlossenen Singularitäten (gewichtet mit den Umlaufzahlen). Damit lassen sich zahlreiche bestimmte reelle Integrale, etwa trigonometrische Integrale und uneigentliche Integrale rationaler Funktionen, ebenso berechnen wie Summen unendlicher Reihen. Ein einfaches Beispiel: 1/(1+z²) besitzt in z = i das Residuum 1/(2i); daraus folgt der Wert des Integrals von 1/(1+x²) über die gesamte reelle Achse zu π.
