Socket (Computer)

Ein Socket (englisch für „Steckdose", „Fassung") ist in der Informatik ein Endpunkt einer bidirektionalen Kommunikationsverbindung zwischen Prozessen, in der Regel über ein Rechnernetz. Sockets bilden eine standardisierte Programmierschnittstelle (API), über die Anwendungen Daten austauschen können, ohne Details der darunterliegenden Netzwerkprotokolle kennen zu müssen. Ein Netzwerk-Socket wird typischerweise durch die Kombination aus IP-Adresse und Portnummer identifiziert.

Geschichte

Das Socket-Konzept geht auf die Berkeley Sockets zurück, die 1983 mit der Version 4.2BSD des Betriebssystems Unix eingeführt wurden. Die Berkeley-Socket-API wurde zum De-facto-Standard und findet sich heute in nahezu allen Betriebssystemen; unter Windows ist sie als Winsock umgesetzt.

Funktionsweise

Eine Anwendung erzeugt mit dem Systemaufruf socket() einen Socket eines bestimmten Typs:

  • Stream-Sockets (SOCK_STREAM) für verbindungsorientierte, zuverlässige Kommunikation, meist über TCP.
  • Datagramm-Sockets (SOCK_DGRAM) für verbindungslose Kommunikation, meist über UDP.
  • Raw-Sockets (SOCK_RAW) für den direkten Zugriff auf Protokolle der Vermittlungsschicht.

Server binden einen Socket an eine Adresse (bind), lauschen auf Verbindungen (listen) und nehmen diese an (accept); Clients stellen mit connect eine Verbindung her. Der Datenaustausch erfolgt über send/recv bzw. die Dateizugriffsfunktionen read/write. Daneben existieren Unix-Domain-Sockets für die lokale Interprozesskommunikation über das Dateisystem.
