Apache Ant

Apache Ant
Entwickler: Apache Software Foundation
Programmiersprache: Java
Betriebssystem: plattformunabhängig
Lizenz: Apache License 2.0

Apache Ant (engl. ant = Ameise, zugleich gedeutet als Another Neat Tool) ist ein in Java geschriebenes Werkzeug zur automatischen Erstellung von Software (Build-Automatisierung), das vor allem in der Java-Entwicklung eingesetzt wird. Es wurde ursprünglich von James Duncan Davidson für das Servlet-API-Referenzprojekt Tomcat entwickelt und 2000 der Apache Software Foundation übergeben, wo es zu einem der erfolgreichsten Apache-Projekte wurde.

Funktionsweise

Ant liest eine in XML geschriebene Build-Datei (üblicherweise build.xml), die aus einer Folge von Zielen (targets) besteht. Jedes Target fasst einzelne Arbeitsschritte (tasks) zusammen, etwa das Kompilieren von Quellcode (javac), das Ausführen von Tests (junit), das Erzeugen von JAR-Dateien (jar), das Kopieren und Löschen von Dateien oder das Starten externer Programme. Targets können Abhängigkeiten zu anderen Targets deklarieren, die vor der Ausführung sichergestellt werden. Eigenschaften (properties) machen die Build-Dateien konfigurierbar.

Im Unterschied zu Make, dessen Makefiles auf Shell-Befehlen des jeweiligen Betriebssystems beruhen, implementiert Ant seine Tasks in Java und ist damit plattformunabhängig. Ant enthält eine umfangreiche Bibliothek eingebauter Tasks und kann durch eigene, in Java geschriebene Task-Klassen erweitert werden.

Geschichte und Verbreitung

Ant setzte sich in den 2000er Jahren als Standard-Build-Werkzeug der Java-Welt durch und wurde von nahezu allen Java-IDEs unterstützt. Später traten Werkzeuge wie Apache Maven mit integrierter Abhängigkeitsverwaltung und Gradle hinzu, die viele Projekte übernahmen; das Ant-Erweiterungsmodul Ivy ergänzt Ant um eine Maven-ähnliche Abhängigkeitsverwaltung. Ant wird weiterhin gepflegt und in vielen bestehenden Projekten eingesetzt.
