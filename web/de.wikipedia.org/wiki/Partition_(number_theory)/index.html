Partition (Zahlentheorie)


Ferrers-Diagramme der Partitionen von 4

Eine Partition einer natürlichen Zahl n ist in der Zahlentheorie eine Zerlegung von n in eine Summe positiver ganzer Zahlen, bei der die Reihenfolge der Summanden keine Rolle spielt. Die Anzahl aller Partitionen von n wird mit p(n) bezeichnet und Partitionsfunktion genannt.

Beispiele

Die Zahl 4 besitzt fünf Partitionen: 4, 3+1, 2+2, 2+1+1 und 1+1+1+1; also p(4) = 5. Es gilt p(0) = 1 (die leere Zerlegung) und p(1) = 1, p(2) = 2, p(3) = 3, p(5) = 7, p(10) = 42. Die Werte wachsen rasch: p(100) = 190.226.358.

Darstellungen

Partitionen lassen sich durch Ferrers- beziehungsweise Young-Diagramme veranschaulichen: Jede Zeile von Punkten entspricht einem Summanden. Das Spiegelbild des Diagramms an der Hauptdiagonalen liefert die konjugierte Partition; daraus folgen Sätze wie der, dass die Anzahl der Partitionen von n in höchstens k Teile gleich der Anzahl der Partitionen von n in Teile der Größe höchstens k ist.

Erzeugende Funktion und Formeln

Leonhard Euler fand die erzeugende Funktion

Σ p(n) xn = Πk≥1 1/(1 − xk)

sowie eine Rekursion mithilfe der verallgemeinerten Pentagonalzahlen. Eine geschlossene Formel gelang 1918 Godfrey Harold Hardy und S. Ramanujan mit ihrer Kreismethode als asymptotische Reihe; Hans Rademacher machte daraus 1937 eine exakt konvergierende Reihe. Asymptotisch gilt p(n) ~ eπ√(2n/3) / (4n√3).

Kongruenzen

Ramanujan entdeckte die berühmten Kongruenzen p(5n+4) ≡ 0 (mod 5), p(7n+5) ≡ 0 (mod 7) und p(11n+6) ≡ 0 (mod 11), die später zu einer allgemeinen Theorie der Partitionskongruenzen ausgebaut wurden. Eine Formel für eine zugehörige kombinatorische Statistik – die „crank“ – fanden Freeman Dyson (Vermutung) sowie Andrews und Garvan.
