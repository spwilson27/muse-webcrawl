Das Bit (Kofferwort aus englisch binary digit, „Binärziffer") ist in der Informatik und Informationstheorie die kleinste Informationseinheit. Ein Bit kann genau zwei Zustände annehmen, die üblicherweise mit 0 und 1 bezeichnet werden. Der Begriff wurde 1947 von John W. Tukey geprägt und 1948 von Claude Shannon in seiner mathematischen Kommunikationstheorie popularisiert.

Bedeutung

Mehrere Bits zusammengenommen können größere Informationsmengen darstellen: Mit n Bits lassen sich 2n verschiedene Zustände codieren. Acht Bit bilden ein Byte, die übliche kleinste adressierbare Einheit in Computern. Datenmengen werden mit dezimalen oder binären Präfixen angegeben, etwa Kilobit (kbit) oder Kibibit.

Verwendung

Bits beschreiben Speicherkapazitäten, Übertragungsgeschwindigkeiten (Bit pro Sekunde, bit/s) und die Breite von Datenworten in Prozessoren. In der physikalischen Realisierung werden die zwei Zustände beispielsweise durch Spannungspegel, Magnetisierung oder Ladungszustände dargestellt.
