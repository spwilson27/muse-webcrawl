Ähnlichkeit (Matrix)

Zwei quadratische Matrizen heißen in der linearen Algebra ähnlich (englisch similar), wenn sie dieselbe lineare Abbildung bezüglich unterschiedlicher Basen beschreiben. Die Ähnlichkeit ist eine Äquivalenzrelation auf der Menge der quadratischen Matrizen.

Definition

Zwei Matrizen A und B heißen ähnlich, wenn es eine reguläre Matrix S gibt, sodass B = S−1AS gilt. Die Matrix S beschreibt dabei den Basiswechsel zwischen den beiden Darstellungen.

Eigenschaften

Ähnliche Matrizen besitzen dasselbe charakteristische Polynom und damit dieselben Eigenwerte einschließlich ihrer algebraischen Vielfachheiten. Ferner stimmen Determinante, Spur, Rang und Minimalpolynom überein. Die Umkehrung gilt im Allgemeinen nicht: Gleiche Eigenwerte allein garantieren keine Ähnlichkeit, wie die Jordansche Normalform zeigt.

Normalformen

Jede Matrix ist zu einer Matrix in Jordanscher Normalform ähnlich; über den reellen Zahlen existiert zudem die reelle Jordansche Normalform. Eine Matrix ist genau dann diagonalisierbar, wenn sie zu einer Diagonalmatrix ähnlich ist. Die Klassifikation der Ähnlichkeitsklassen ist ein zentrales Ergebnis der Theorie der linearen Abbildungen.
