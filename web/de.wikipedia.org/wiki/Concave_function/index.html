Konkave Funktion

Eine konkave Funktion ist in der Mathematik eine reellwertige Funktion, deren Graph oberhalb jeder Verbindungsstrecke zweier Punkte des Graphen liegt. Formal heißt eine auf einer konvexen Menge definierte Funktion f konkav, wenn für alle Punkte x und y und alle t zwischen 0 und 1 gilt: f(tx + (1−t)y) ≥ t·f(x) + (1−t)·f(y). Das Negative einer konkaven Funktion ist eine konvexe Funktion.

Eigenschaften

Ist eine konkave Funktion zweimal differenzierbar, so ist ihre zweite Ableitung überall kleiner oder gleich null. Jede konkave Funktion auf einem offenen Intervall ist stetig und fast überall differenzierbar. Lokale Maxima konkaver Funktionen sind zugleich globale Maxima, was sie für die Optimierung besonders wichtig macht.

Beispiele und Anwendungen

Beispiele konkaver Funktionen sind die Logarithmusfunktion, die Wurzelfunktion und die Potenzfunktion xa mit 0 < a < 1 auf den positiven reellen Zahlen. In der Wirtschaftstheorie modellieren konkave Nutzenfunktionen risikoaverses Verhalten; in der Informationstheorie ist die Entropie eine konkave Funktion der Wahrscheinlichkeitsverteilung.
