Punktmengenregistrierung

Punktmengenregistrierung (englisch point set registration oder point cloud registration) bezeichnet in der Informatik und Bildverarbeitung das Problem, zwei oder mehr Punktmengen – etwa Punktwolken aus verschiedenen Scans desselben Objekts – durch eine räumliche Transformation so zueinander auszurichten, dass sie möglichst gut übereinstimmen. Gesucht wird meist eine starre Transformation aus Rotation und Translation, teilweise auch eine Skalierung oder eine nicht-starre Deformation.

Verfahren

Das bekannteste Verfahren ist der Iterative-Closest-Point-Algorithmus (ICP), der abwechselnd jedem Punkt der einen Menge den nächstgelegenen Punkt der anderen Menge zuordnet und die dazu optimale Transformation bestimmt, bis die Zuordnung konvergiert. Für bekannte Punktkorrespondenzen lässt sich die optimale starre Transformation in geschlossener Form berechnen, etwa mit dem Kabsch-Algorithmus über eine Singulärwertzerlegung. Weitere Ansätze wie Coherent Point Drift behandeln die Registrierung probabilistisch und sind robuster gegenüber Rauschen, Ausreißern und unvollständiger Überlappung.

Anwendungen

Punktmengenregistrierung wird eingesetzt, um Teilscans von 3D-Scannern zu einem Gesamtmodell zu fusionieren, in der Robotik (Lokalisierung und Kartierung, SLAM), beim autonomen Fahren, in der medizinischen Bildgebung zur Überlagerung von Aufnahmen verschiedener Zeitpunkte oder Modalitäten sowie in der industriellen Messtechnik zum Soll-Ist-Vergleich.
