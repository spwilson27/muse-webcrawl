React (auch React.js oder ReactJS) ist eine freie JavaScript-Bibliothek zur Erstellung von Benutzeroberflächen. Sie wurde von Meta (ehemals Facebook) entwickelt und wird von Meta sowie einer Gemeinschaft einzelner Entwickler und Unternehmen gepflegt. React kann als Grundlage für die Entwicklung von Single-Page-Anwendungen, mobilen Anwendungen oder serverseitig gerenderten Anwendungen in Verbindung mit Frameworks wie Next.js verwendet werden.

React kümmert sich ausschließlich um die Darstellung von Daten im Document Object Model (DOM) und erfordert daher typischerweise den Einsatz zusätzlicher Bibliotheken für das Zustandsmanagement und das Routing. Redux und React Router sind jeweils beliebte Beispiele für solche Bibliotheken.

Geschichte

React wurde von Jordan Walke entwickelt, einem Softwareingenieur bei Facebook, der von XHP beeinflusst war, einem HTML-Komponenten-Framework für PHP. Es wurde erstmals 2011 in Facebooks Newsfeed und 2012 auf Instagram eingesetzt. Im Mai 2013 wurde es auf der JSConf US als Open Source veröffentlicht.

React Native, das die Anwendung nativer Android-, iOS- und UWP-Funktionen mit React ermöglicht, wurde im Februar 2015 auf der React Conf von Facebook angekündigt und im März 2015 als Open Source veröffentlicht.

Im September 2017 änderte Facebook die Lizenzierung von React von der BSD+Patents-Klausel zur MIT-Lizenz, nachdem es in der Apache Software Foundation und anderen Organisationen zu Kontroversen gekommen war.

Grundlegende Konzepte

Komponenten

React-Code besteht aus Entitäten, die als Komponenten bezeichnet werden. Diese Komponenten sind wiederverwendbar und müssen innerhalb desselben Dateibereichs gebildet werden. Komponenten können mithilfe des virtuellen DOM in das DOM der Seite gerendert werden. Es gibt zwei primäre Möglichkeiten, Komponenten zu deklarieren: als Funktionskomponenten und als Klassenkomponenten.

Virtuelles DOM

Eine weitere bemerkenswerte Funktion ist die Verwendung eines virtuellen Document Object Model (virtuelles DOM). React erstellt einen Cache der Datenstruktur im Speicher; sobald sich eine Komponente ändert, berechnet es die Unterschiede zwischen dem virtuellen DOM und dem realen DOM und aktualisiert das DOM des Browsers nur dort effizient, wo tatsächlich Änderungen aufgetreten sind.

JSX

Komponenten werden typischerweise in JSX geschrieben, einer JavaScript-Syntaxerweiterung, die das Zitieren von HTML und die Verwendung von HTML-Tag-Syntax zum Rendern von Unterkomponenten ermöglicht. Entwickler können React-Code auch in reinem JavaScript schreiben; JSX ist hierbei ein Vorteil, weil es bei der Arbeit mit einer HTML-ähnlichen Syntax in JavaScript für diejenigen natürlicher ist, die mit HTML in einem visuellen Interaktionsdesign-Umfeld gearbeitet haben.

Hooks

Hooks sind Funktionen, die es Entwicklern ermöglichen, Zustands- und andere React-Funktionen zu verwenden, ohne Klassen schreiben zu müssen. Sie wurden mit React 16.8 eingeführt. Zu den eingebauten Hooks gehören unter anderem useState, useEffect, useContext, useReducer und useRef.
