D-Brane

Eine D-Brane (kurz für „Dirichlet-Brane") ist ein Objekt der Stringtheorie: eine Hyperfläche, auf der die Endpunkte offener Strings angeheftet sind. Der Begriff geht auf Arbeiten von Joseph Polchinski zurück, der 1995 zeigte, dass D-Branes eigenständige, dynamische Objekte mit Ladung und Masse sind.

Definition

Eine Dp-Brane erstreckt sich über p Raumdimensionen (und die Zeit). Für die Richtungen senkrecht zur Brane erfüllen die Endpunkte offener Strings Dirichlet-Randbedingungen (feste Position), entlang der Brane dagegen Neumann-Randbedingungen (freie Endpunkte). Eine D0-Brane ist dementsprechend punktförmig, eine D2-Brane membranartig und eine raumfüllende D9-Brane ein Grenzfall.

Bedeutung

D-Branes tragen die Ladungen der Ramond-Ramond-Felder und spielen eine zentrale Rolle für die Dualitäten der Stringtheorie. Fluktuationen der auf einer Brane endenden offenen Strings werden durch Eichfelder beschrieben; das Weltvolumen einer D-Brane trägt daher eine Eichtheorie. Mehrere übereinanderliegende D-Branes führen zu nichtabelschen Eichgruppen. Bekannte Anwendungen sind die mikroskopische Erklärung der Bekenstein-Hawking-Entropie Schwarzer Löcher durch D-Branes (Strominger und Vafa, 1996) sowie Branenwelt-Szenarien der Kosmologie.
