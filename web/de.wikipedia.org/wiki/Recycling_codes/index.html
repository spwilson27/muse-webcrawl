Recyclingcodes

Recyclingcodes sind Kennzeichnungen auf Produkten und Verpackungen, die das Material identifizieren und die Sortierung für das Recycling erleichtern sollen. Das bekannteste System ist der 1988 von der US-amerikanischen Society of the Plastics Industry eingeführte Resin Identification Code für Kunststoffe: eine Zahl in einem Dreieck aus Verfolgungspfeilen, ergänzt um ein Materialkürzel.

Weitere Materialien

Erweiterte Systeme vergeben auch Nummern für Papier und Pappe (20–39), Metalle (40, 41), Holz (50, 51), Textilien (60, 61) und Glas (70–72). Wichtig ist, dass der Code allein keine Aussage darüber trifft, ob ein Gegenstand an einem bestimmten Ort tatsächlich recycelt wird; er dient der Materialidentifikation.
