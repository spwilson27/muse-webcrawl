Mandelbrot-Menge

Mandelbrot-Menge
DefinitionM = { c ∈ ℂ : Folge zₙ₊₁ = zₙ² + c bleibt beschränkt }
NamensgeberBenoît Mandelbrot
GebietKomplexe Dynamik, Fraktale

Die Mandelbrot-Menge, benannt nach dem Mathematiker Benoît Mandelbrot, ist eine Menge von Punkten der komplexen Ebene, die durch eine einfache Rekursionsvorschrift definiert ist und für ihre äußerst komplexe, fraktale Randstruktur berühmt wurde. Sie gilt als eines der bekanntesten Objekte der modernen Mathematik und wird umgangssprachlich auch „Apfelmännchen“ genannt.

Definition

Für einen komplexen Parameter c betrachtet man die Folge z0 = 0, zn+1 = zn² + c. Der Punkt c gehört genau dann zur Mandelbrot-Menge M, wenn diese Folge beschränkt bleibt, also nicht gegen unendlich strebt. Anschaulich entspricht M genau der Menge derjenigen c, für die die zugehörige Julia-Menge zusammenhängend ist.

Eigenschaften

Der Hauptkörper der Menge ist eine Kardioide; an ihr sitzen unzählige kreisförmige „Knollen“, und am Rand bilden sich filigrane Verästelungen, Seepferdchen-ähnliche Strukturen und verkleinerte Kopien der Gesamtmenge („Minibrots“). Mandelbrot visualisierte die Menge ab 1978 mithilfe von Computern; ihre Popularität in den 1980er Jahren trug wesentlich zur Entstehung der Chaos- und Fraktal-Forschung bei. Wichtige Resultate stammen von Adrien Douady und John Hubbard, die unter anderem den Zusammenhang der Menge bewiesen.

Darstellung

Bei der üblichen Visualisierung wird jeder Punkt außerhalb der Menge nach der Anzahl der Iterationen eingefärbt, die nötig sind, bis ein Schwellwert (meist |z| > 2) überschritten wird; Punkte der Menge selbst werden schwarz dargestellt. Zooms in den Randbereich zeigen eine unerschöpfliche Detailfülle (Selbstähnlichkeit ohne strenge Skaleninvarianz).
