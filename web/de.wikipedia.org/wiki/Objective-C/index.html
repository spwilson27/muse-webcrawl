Objective-C

Objective-C ist eine objektorientierte Programmiersprache, die die Sprache C um objektorientierte Konzepte nach dem Vorbild von Smalltalk erweitert. Sie war lange Zeit die Hauptsprache für die Entwicklung von Software für macOS und iOS und bildet die Grundlage der Frameworks Cocoa und Cocoa Touch.

Geschichte

Objective-C wurde Anfang der 1980er Jahre von Brad Cox und Tom Love bei der Firma Stepstone entwickelt. Die Firma NeXT lizenzierte die Sprache 1988 und nutzte sie für das Betriebssystem NeXTSTEP. Nachdem Apple NeXT 1996 übernommen hatte, wurde Objective-C zur zentralen Entwicklungssprache der Apple-Plattformen. 2014 stellte Apple die Sprache Swift vor, die Objective-C zunehmend ablöste; beide Sprachen können in einem Projekt gemischt werden.

Merkmale

Charakteristisch ist die Syntax für Nachrichtenversand in eckigen Klammern, die der Smalltalk-Schreibweise nachempfunden ist, etwa [empfaenger nachricht: argument]. Objective-C unterstützt dynamische Typisierung und dynamisches Binden, ein flexibles Laufzeitsystem, Kategorien zur nachträglichen Erweiterung von Klassen sowie Protokolle. Seit der Version 2.0 (2007) gibt es Eigenschaften (Properties), Blöcke und eine automatische Speicherverwaltung durch Automatic Reference Counting (ARC).
