Zeiger (Informatik)

Ein Zeiger (englisch pointer) ist in der Informatik eine Variable, die als Wert die Speicheradresse eines Objekts oder einer anderen Variablen enthält. Durch Dereferenzierung eines Zeigers kann auf den Wert an der gespeicherten Adresse zugegriffen oder dieser verändert werden.

Grundlagen

Zeiger spielen vor allem in systemnahen Programmiersprachen wie C und C++ eine zentrale Rolle. Dort kann ein Zeiger auf Variablen beliebigen Typs, auf Arrays, Strukturen oder Funktionen verweisen. Die Adressarithmetik erlaubt es, mit Zeigern durch Speicherbereiche zu „wandern“.

int zahl = 42;
int *zeiger = &zahl;   /* zeiger enthält die Adresse von zahl */
*zeiger = 43;           /* Dereferenzierung: zahl wird 43 */

Besondere Zeiger

Ein Nullzeiger zeigt auf kein gültiges Objekt und wird verwendet, um das Nichtvorhandensein eines Werts anzuzeigen. Ein wilder Zeiger (dangling pointer) verweist auf bereits freigegebenen Speicher; seine Verwendung führt zu undefiniertem Verhalten. Ein Void-Zeiger (void*) ist ein typfreier Zeiger, der auf Daten beliebigen Typs zeigen kann.

Sicherheit

Fehler im Umgang mit Zeigern gehören zu den häufigsten Ursachen für Programmabstürze und Sicherheitslücken, etwa bei Pufferüberläufen. Modernere Sprachen schränken Zeiger daher ein oder ersetzen sie durch Referenzen beziehungsweise Smart Pointer, die Speicher automatisch verwalten.
