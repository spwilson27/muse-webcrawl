Cantor-Funktion

Die Cantor-Funktion, auch Teufelstreppe genannt, ist eine in der Mathematik bekannte stetige, monoton wachsende Funktion von [0, 1] nach [0, 1], die fast überall die Ableitung null besitzt, obwohl sie von 0 auf 1 anwächst. Sie wurde von Georg Cantor im Zusammenhang mit der Cantor-Menge eingeführt.

Konstruktion

Die Funktion wird über die ternäre (dreistellige) Entwicklung definiert: Man schreibt x ∈ [0, 1] zur Basis 3. Erscheint die Ziffer 1, so bricht man die Entwicklung dort ab und ersetzt alle folgenden Ziffern durch 0; jede Ziffer 2 wird durch 1 ersetzt. Die so erhaltene Binärzahl ist der Funktionswert. Auf den entfernten offenen Intervallen der Cantor-Menge ist die Funktion konstant; auf der Cantor-Menge selbst wächst sie.

Eigenschaften

  • Die Cantor-Funktion ist stetig und monoton nicht fallend.
  • Ihre Ableitung ist fast überall (im Sinne des Lebesgue-Maßes) null.
  • Sie ist nicht absolut stetig und ein Beispiel einer singulären Funktion.
  • Sie bildet die Cantor-Menge (vom Maß null) auf ganz [0, 1] ab.

Bedeutung

Die Teufelstreppe ist ein Standard-Gegenbeispiel in der Analysis: Sie zeigt, dass eine Funktion trotz Ableitung null fast überall nicht konstant sein muss, wenn absolute Stetigkeit fehlt. Zugleich liefert sie die Verteilungsfunktion eines singulären Wahrscheinlichkeitsmaßes.
