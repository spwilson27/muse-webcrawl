1-Up

Ein 1-Up (aus dem Englischen, wörtlich „eins hoch“) ist in Videospielen ein Gegenstand oder eine Belohnung, die dem Spieler ein zusätzliches Leben gewährt. Der Begriff wurde vor allem durch die Super-Mario-Reihe populär, in der der grüne „1-Up-Pilz“ dem Spieler ein Extraleben verschafft.

Verwendung

1-Ups können als sammelbare Gegenstände in der Spielwelt platziert sein oder für das Erreichen bestimmter Punktzahlen, das Besiegen einer Anzahl von Gegnern oder das Sammeln von Münzen vergeben werden. In vielen modernen Spielen mit Speicherständen und unbegrenzten Versuchen hat das Konzept an Bedeutung verloren, wird aber weiterhin als nostalgisches Element eingesetzt.

Übertragene Bedeutung

Umgangssprachlich wird „jemanden ein 1-Up geben“ im Englischen auch im Sinne von „einen Vorteil verschaffen“ oder „übertreffen“ verwendet.
