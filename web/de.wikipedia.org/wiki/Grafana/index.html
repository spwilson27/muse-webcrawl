Grafana ist eine plattformübergreifende Open-Source-Anwendung zur grafischen Darstellung und Analyse von Daten, insbesondere von Metriken aus Zeitreihendatenbanken. Die Software wird vor allem im Bereich des Monitorings von IT-Infrastrukturen und Anwendungen eingesetzt.

Geschichte

Grafana wurde 2014 von Torkel Ödegaard ins Leben gerufen und entstand aus Arbeiten an einem übersichtlicheren Frontend für Zeitreihendatenbanken wie Graphite und InfluxDB. Das Projekt entwickelte sich rasch zu einem der populärsten Werkzeuge seiner Art; die dahinterstehende Firma Grafana Labs (früher raintank) bietet neben der Open-Source-Version kommerzielle Produkte wie Grafana Cloud und Grafana Enterprise an.

Funktionen

Grafana ermöglicht das Erstellen interaktiver Dashboards, in denen Daten aus zahlreichen Quellen kombiniert dargestellt werden können. Unterstützte Datenquellen sind unter anderem Prometheus, InfluxDB, Elasticsearch, MySQL, PostgreSQL und diverse Cloud-Dienste. Über ein Plugin-System lässt sich der Funktionsumfang erweitern. Eingebaute Alarmierungsfunktionen benachrichtigen Nutzer bei Überschreitung definierter Schwellenwerte.

Seit Version 8 ist ein einheitliches Alerting-System („Grafana Alerting“) Bestandteil der Software.
