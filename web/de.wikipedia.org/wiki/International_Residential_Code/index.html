International Residential Code

Der International Residential Code (IRC) ist eine umfassende Muster-Bauordnung für den Wohnungsbau, die vom International Code Council (ICC) in den Vereinigten Staaten herausgegeben wird. Er bündelt alle wesentlichen Anforderungen an Ein- und Zweifamilienhäuser sowie Reihenhäuser bis zu drei Geschossen in einem einzigen Regelwerk – von Statik und Brandschutz über Sanitär- und Elektroinstallationen bis zur Energieeffizienz.

Entstehung und Verbreitung

Der IRC erschien erstmals im Jahr 2000, nachdem sich die drei regionalen US-amerikanischen Bauordnungsorganisationen zum ICC zusammengeschlossen hatten. Er wird in einem konsensorientierten Verfahren mit Vertretern von Bauaufsicht, Industrie und Fachplanung alle drei Jahre fortgeschrieben. Fast alle US-Bundesstaaten sowie zahlreiche Kommunen haben den IRC – zum Teil mit örtlichen Änderungen – als verbindliche Bauordnung übernommen; auch außerhalb der USA dient er als Vorlage.

Inhalt

Das Regelwerk enthält zahlreiche präskriptive Vorgaben, etwa Tabellen zu Spannweiten von Holzbalken, Anforderungen an Flucht- und Rettungswege, Rauchwarnmelder, Treppengeometrie und die Verankerung gegen Wind- und Erdbebenlasten. Dadurch können Standard-Wohnhäuser ohne gesonderten statischen Nachweis durch einen Ingenieur errichtet werden, sofern alle Vorgaben eingehalten werden. Der IRC gehört zur „I-Code“-Familie des ICC, deren wichtigstes Mitglied der International Building Code (IBC) für größere Gebäude ist.
