Barabási-Albert-Modell

Das Barabási-Albert-Modell ist ein Modell zur Erzeugung zufälliger skalenfreier Netzwerke. Es wurde 1999 von Albert-László Barabási und Réka Albert vorgestellt und erklärt das Entstehen von Gradverteilungen mit Potenzgesetz-Verteilung in vielen realen Netzwerken, etwa dem World Wide Web oder Zitationsnetzwerken.

Algorithmus

Das Netzwerk wächst schrittweise: In jedem Schritt wird ein neuer Knoten mit m Kanten hinzugefügt. Die Wahrscheinlichkeit, dass eine Kante zu einem bereits vorhandenen Knoten i gezogen wird, ist proportional zu dessen bisherigem Grad ki (bevorzugte Anbindung, englisch preferential attachment): Π(ki) = ki / Σj kj.

Eigenschaften

Die entstehende Gradverteilung folgt einem Potenzgesetz P(k) ~ k−3. Wenige Knoten („Hubs“) besitzen sehr viele Verbindungen, während die meisten Knoten nur wenige Kanten haben. Das Modell reproduziert damit eine zentrale Eigenschaft vieler natürlicher und technischer Netzwerke, nicht jedoch deren oft hohe Clusterkoeffizienten.
