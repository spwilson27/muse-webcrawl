Probability Integral Transform

Die Probability Integral Transform (deutsch etwa: Wahrscheinlichkeitsintegral-Transformation) ist eine Aussage der Wahrscheinlichkeitstheorie, wonach eine stetige Zufallsvariable durch Anwenden ihrer eigenen Verteilungsfunktion in eine auf dem Intervall [0, 1] gleichverteilte Zufallsvariable überführt wird. Sie bildet die theoretische Grundlage vieler Simulationsverfahren, insbesondere der Inversionsmethode zur Erzeugung von Zufallszahlen.

Aussage

Ist X eine Zufallsvariable mit stetiger Verteilungsfunktion F, so ist die transformierte Zufallsvariable Y = F(X) gleichverteilt auf [0, 1]. Umgekehrt gilt: Ist U gleichverteilt auf [0, 1] und F eine Verteilungsfunktion mit verallgemeinerter Inversen F−1, so besitzt F−1(U) die Verteilungsfunktion F.

Anwendungen

  • Inversionsmethode: Erzeugung von Zufallszahlen beliebiger Verteilungen aus gleichverteilten Zufallszahlen, etwa in Monte-Carlo-Simulationen.
  • Anpassungstests: Bei korrekt spezifizierten Modellen sind die transformierten Beobachtungen approximativ gleichverteilt, was für diagnostische Zwecke (PIT-Histogramme) genutzt wird.
  • Copulas: Die Ränder einer mehrdimensionalen Verteilung werden durch die Transformation auf gleichverteilte Größen standardisiert, um die Abhängigkeitsstruktur isoliert zu untersuchen.
