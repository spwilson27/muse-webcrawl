Serialisierung

Serialisierung (englisch data serialization) bezeichnet die Umwandlung von Datenstrukturen oder Objekten eines Programms in ein sequenzielles Format, das gespeichert oder über ein Netz übertragen werden kann. Der umgekehrte Vorgang heißt Deserialisierung.

Formate

  • Textbasiert: XML, JSON, YAML, CSV – menschenlesbar, aber umfangreicher
  • Binär: Protocol Buffers, Apache Avro, MessagePack, BSON – kompakt und schnell
  • Sprachspezifisch: etwa die Serialisierung von Java oder Pythons pickle-Modul

Anwendung und Risiken

Serialisierung wird für Datenaustausch zwischen Diensten, Nachrichtenwarteschlangen, Caches und die dauerhafte Speicherung von Laufzeitobjekten genutzt. Die Deserialisierung nicht vertrauenswürdiger Daten ist ein bekanntes Sicherheitsrisiko, da speziell präparierte Datenströme in manchen Frameworks zur Ausführung von Schadcode führen können.
