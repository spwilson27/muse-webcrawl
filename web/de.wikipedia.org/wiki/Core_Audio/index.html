Core Audio

Core Audio ist die Schnittstelle für die Verarbeitung digitaler Audiosignale in Apples Betriebssystemen macOS und iOS. Sie bietet eine latenzarme, leistungsfähige Umgebung für Aufnahme, Wiedergabe, Mischung, Verarbeitung und Formatkonvertierung von Audio.

Bestandteile

Zu den wichtigsten Komponenten zählen die Hardware Abstraction Layer (Audio HAL) für die Ansteuerung von Audiogeräten, das Plug-in-Format Audio Units für Effekte und Softwareinstrumente, Core MIDI für MIDI-Daten sowie Dienste wie Audio File Services und Audio Converter Services für Dateizugriff und Formatumwandlung. Das Standarddatenformat ist lineares PCM mit 32-Bit-Gleitkommawerten.

Verwendung

Core Audio ist die Grundlage professioneller Musik- und Videosoftware auf Apple-Systemen, darunter Logic Pro und GarageBand. Programme anderer Hersteller greifen über Core Audio auf Audio-Hardware zu.
