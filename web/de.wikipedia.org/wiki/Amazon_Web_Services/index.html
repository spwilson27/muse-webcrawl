Amazon Web Services

Amazon Web Services (AWS) ist die Cloud-Computing-Sparte des US-amerikanischen Konzerns Amazon und gilt als weltweit größter Anbieter von Cloud-Infrastruktur. AWS stellt über das Internet mehr als 200 Dienste bereit, darunter Rechenleistung, Speicher, Datenbanken, Netzwerke, Analyse und maschinelles Lernen, die nach Verbrauch abgerechnet werden.

Geschichte

AWS startete im März 2006 mit dem Objektspeicher Amazon S3, gefolgt von der Elastic Compute Cloud (EC2) für virtuelle Server. Das Angebot ging aus der internen Infrastruktur von Amazon hervor und war für kleine Start-ups ebenso zugänglich wie für Großunternehmen. Der Nachrichtenwarteschlangendienst SQS war bereits 2004 als einer der Vorläufer gestartet.

Seit 2015 weist Amazon die Ergebnisse von AWS gesondert aus; die Sparte erwirtschaftet bei einem Umsatzanteil von deutlich unter einem Viertel regelmäßig den größten Teil des operativen Gewinns des Konzerns. Zu den Kunden zählen neben Start-ups auch Behörden, Rundfunkanstalten und große Industrieunternehmen. Wettbewerber sind vor allem Microsoft Azure und Google Cloud.

Infrastruktur

Die Dienste laufen in weltweit verteilten Regionen, die jeweils aus mehreren räumlich getrennten Availability Zones mit eigenen Rechenzentren bestehen. Kunden können dadurch Anwendungen hochverfügbar und ortsnah betreiben. Ergänzt wird das Netz durch Edge-Standorte für das Content-Delivery-Netzwerk CloudFront.

Bekannte Dienste (Auswahl)

  • Amazon EC2 – virtuelle Server
  • Amazon S3 – Objektspeicher
  • Amazon EBS – Blockspeicher
  • Amazon Redshift – Data Warehouse
  • Amazon EMR – Big-Data-Verarbeitung
  • Amazon SQS und Amazon SNS – Nachrichten- und Benachrichtigungsdienste
  • AWS Lambda – serverlose Funktionen
