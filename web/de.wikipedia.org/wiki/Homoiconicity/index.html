Homoikonizität

Eine Programmiersprache heißt homoikonisch (von griechisch homo „gleich“ und icon „Bild“), wenn Programme in ihr durch eine Datenstruktur dargestellt werden, die die Sprache selbst nativ verarbeiten kann – wenn also Code und Daten dieselbe Repräsentation besitzen.

Lisp als klassisches Beispiel

Das bekannteste Beispiel ist Lisp, dessen Programme aus S-Ausdrücken (geschachtelten Listen) bestehen, also genau der Datenstruktur, die Lisp-Programme manipulieren. Dadurch können Programme zur Laufzeit erzeugt, verändert und ausgewertet werden, was mächtige Makrosysteme und Metaprogrammierung ermöglicht. John McCarthy, der Entwickler von Lisp, führte für diese Eigenschaft den Gedanken ein, dass ein Programm in seiner eigenen Sprache als Daten vorliegen kann.

Weitere homoikonische Sprachen

  • Prolog (Klauseln als Daten)
  • Wolfram Language
  • Rebol und Red
  • Julia (Expressions als Datenobjekte)
  • Tcl

Bedeutung

Homoikonizität erleichtert das Schreiben von Code-Generatoren, domänenspezifischen Sprachen (DSLs) und Makros, da keine separate Syntaxanalyse nötig ist: Ein Programm kann Programme wie beliebige Daten verändern, bevor sie durch eval ausgeführt werden.
