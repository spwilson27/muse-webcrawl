Escape-Zeichen

Ein Escape-Zeichen (englisch escape character) ist in der Informatik ein Zeichen, das die Interpretation der folgenden Zeichen verändert beziehungsweise eine Escape-Sequenz einleitet. Dadurch können Zeichen, die sonst eine Sonderbedeutung hätten, wörtlich gemeint oder Steuerfunktionen ausgelöst werden.

Beispiele

In vielen Programmiersprachen wie C, Java oder Python ist der Backslash (\) das Escape-Zeichen: Die Folge \n steht für einen Zeilenumbruch, \t für einen Tabulator und \" für ein Anführungszeichen innerhalb einer Zeichenkette. In ASCII existiert mit ESC (Code 27) ein eigenes Steuerzeichen, das etwa in ANSI-Escape-Sequenzen zur Steuerung von Terminals (Farben, Cursorbewegungen) dient. Bei regulären Ausdrücken und in SQL kommen ebenfalls Maskierungen mit Backslash oder Verdopplung von Zeichen vor.

Bedeutung

Das korrekte Escapen von Eingaben ist für die Sicherheit von Software wichtig: Fehlende Maskierung kann zu Injection-Angriffen wie SQL-Injection oder Cross-Site-Scripting führen, wenn Benutzereingaben ungeprüft in Kommandos oder Abfragen übernommen werden.
