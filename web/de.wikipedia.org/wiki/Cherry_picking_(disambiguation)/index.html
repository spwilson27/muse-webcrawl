Cherry Picking (Begriffsklärung)

Cherry Picking steht für:

  • Cherry Picking, die selektive Auswahl der günstigsten Elemente aus einer Menge („Rosinenpicken“)
  • Cherry Picking (Fehlschluss), ein logischer Fehlschluss durch selektive Datenauswahl
  • Cherry Picking (Basketball), eine Spielweise im Basketball
  • git cherry-pick, ein Befehl in der Versionsverwaltung Git zur gezielten Übernahme einzelner Änderungen

Diese Seite ist eine Begriffsklärung zur Unterscheidung mehrerer mit demselben Wort bezeichneter Begriffe.
