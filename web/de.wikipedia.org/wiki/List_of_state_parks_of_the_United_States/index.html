Liste der State Parks der Vereinigten Staaten

State Parks sind von den US-Bundesstaaten verwaltete Schutz- und Erholungsgebiete. Insgesamt gibt es in den Vereinigten Staaten mehr als 6.000 State Parks, die zusammen über 5,7 Millionen Hektar umfassen. Die folgende Liste nennt bedeutende State Parks je Bundesstaat (Auswahl).

Das System der State Parks entstand Ende des 19. Jahrhunderts; als einer der ältesten State Parks gilt der Niagara Falls State Park in New York (1885). Der Custer State Park in South Dakota ist für seine freilebende Bisonherde von rund 1.500 Tieren bekannt.
