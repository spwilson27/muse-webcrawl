7-Zip

7-Zip
Entwickler: Igor Pavlov
Erstveröffentlichung: 1999
Betriebssysteme: Windows, Linux, macOS (Kommandozeile)
Lizenz: GNU LGPL u. a.

7-Zip ist ein freies Datenkompressionsprogramm, das von Igor Pavlov entwickelt wird. Es unterstützt das eigene Archivformat 7z sowie zahlreiche weitere Formate wie ZIP, RAR (nur Entpacken), TAR, GZIP und BZIP2.

Eigenschaften

Das Programm verwendet vor allem den von Pavlov entwickelten Kompressionsalgorithmus LZMA und dessen Nachfolger LZMA2, die eine besonders hohe Kompressionsrate ermöglichen. 7-Zip bietet eine AES-256-Verschlüsselung, selbstentpackende Archive und lässt sich über eine grafische Oberfläche (7-Zip File Manager) oder per Kommandozeile bedienen. Es integriert sich in das Kontextmenü des Windows-Explorers.

Verbreitung

7-Zip steht unter der GNU Lesser General Public License und gehört zu den weltweit am häufigsten verwendeten Packprogrammen. Der Name leitet sich vom ZIP-Format ab; das eigene Format besitzt die Dateiendung .7z.
