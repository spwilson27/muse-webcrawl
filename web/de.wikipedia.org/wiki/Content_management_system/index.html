Content-Management-System

Ein Content-Management-System (CMS) ist eine Software zur gemeinschaftlichen Erstellung, Bearbeitung und Organisation von Inhalten, meist für Webseiten. Ein CMS zeichnet sich insbesondere dadurch aus, dass Inhalte ohne Programmier- oder HTML-Kenntnisse verwaltet werden können. Bekannte Vertreter sind WordPress, TYPO3, Joomla, Drupal und Contao.

Funktionsweise

Die Inhalte werden in der Regel in einer Datenbank gespeichert und beim Aufruf einer Seite dynamisch mit Hilfe von Vorlagen (Templates) zu einer HTML-Seite zusammengesetzt. Dadurch sind Inhalte, Layout und Technik voneinander getrennt. Ein Berechtigungssystem regelt, welche Benutzer Inhalte erstellen, bearbeiten oder freigeben dürfen; Freigabe-Workflows unterstützen redaktionelle Prozesse.

Merkmale

  • Texteditor nach dem WYSIWYG-Prinzip
  • Medienverwaltung für Bilder und Dateien
  • Benutzer- und Rechteverwaltung
  • Versionierung von Inhalten
  • Erweiterbarkeit durch Plugins und Module
  • Mehrsprachigkeit und Mandantenfähigkeit (je nach System)

Headless CMS

Bei einem Headless CMS wird auf eine fest eingebaute Ausgabeschicht verzichtet. Die Inhalte werden über eine Schnittstelle (API), etwa REST oder GraphQL, bereitgestellt und können so in beliebigen Kanälen – Webseiten, Apps, Displays – ausgespielt werden.
