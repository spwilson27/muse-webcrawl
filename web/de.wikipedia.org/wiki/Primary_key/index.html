Primärschlüssel

Ein Primärschlüssel (englisch primary key) ist in relationalen Datenbanken ein Attribut oder eine Kombination von Attributen, deren Werte jeden Datensatz (Tupel) einer Tabelle eindeutig identifizieren. Ein Primärschlüssel darf keine Nullwerte enthalten und muss für jeden Datensatz einzigartig sein.

Eigenschaften

Das Datenbankmanagementsystem überwacht die Eindeutigkeit automatisch, meist durch einen eindeutigen Index. Der Primärschlüssel dient zugleich als bevorzugtes Ziel für Verweise: Ein Fremdschlüssel in einer anderen Tabelle verweist auf den Primärschlüssel eines Datensatzes und stellt so Beziehungen zwischen Tabellen her.

Arten

Primärschlüssel können aus vorhandenen fachlichen Merkmalen bestehen (natürliche Schlüssel, etwa eine ISBN) oder eigens erzeugt werden (künstliche bzw. Surrogatschlüssel, etwa eine fortlaufende Nummer oder eine UUID). Besteht der Schlüssel aus mehreren Attributen, spricht man von einem zusammengesetzten Schlüssel.
