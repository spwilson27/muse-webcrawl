Hypothese

Eine Hypothese (von altgriechisch hypóthesis „Unterstellung") ist eine begründete Annahme oder Vermutung, die als Ausgangspunkt für weitere Untersuchungen dient. In der Wissenschaft ist eine Hypothese eine überprüfbare Aussage über Zusammenhänge zwischen Variablen, die durch Beobachtung oder Experiment bestätigt (verifiziert) oder widerlegt (falsifiziert) werden kann.

Hypothesen in der Wissenschaft

Im wissenschaftlichen Arbeiten bildet die Hypothese zusammen mit ihrer empirischen Prüfung den Kern der hypothetisch-deduktiven Methode. Aus einer Hypothese werden Vorhersagen abgeleitet, die anhand von Daten überprüft werden. Karl Popper betonte, dass Hypothesen grundsätzlich falsifizierbar sein müssen, um als wissenschaftlich zu gelten; endgültig beweisen lassen sie sich nicht, sie können sich lediglich bewähren.

Arten von Hypothesen

  • Nullhypothese (H0): Annahme, dass kein Effekt oder kein Unterschied besteht
  • Alternativhypothese (H1): Annahme eines Effekts oder Unterschieds
  • Arbeitshypothese: vorläufige Annahme zu Beginn einer Untersuchung
  • Gerichtete Hypothese: gibt die Richtung eines Zusammenhangs an

Abgrenzung

Von einer Hypothese zu unterscheiden ist die Theorie: Eine vielfach bestätigte und in einen größeren Erklärungszusammenhang eingebettete Hypothese kann Teil einer wissenschaftlichen Theorie werden. Im allgemeinen Sprachgebrauch wird „Hypothese" oft gleichbedeutend mit „Vermutung" oder „Annahme" verwendet.
