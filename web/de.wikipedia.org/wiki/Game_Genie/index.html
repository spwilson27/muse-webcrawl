Game Genie

Der Game Genie ist ein Cheat-Modul für Spielkonsolen, das 1990 von Codemasters entwickelt und von Galoob vertrieben wurde. Es wurde für das Nintendo Entertainment System (NES) sowie später für Super Nintendo, Game Boy, Sega Mega Drive und Game Gear angeboten.

Funktionsweise

Der Game Genie wird zwischen Konsole und Spielmodul gesteckt und verändert beim Laden einzelne Speicherwerte des Spiels. Über ein Eingabemenü geben die Spieler Codes ein, die etwa unendlich Leben, Unverwundbarkeit oder das Überspringen von Leveln bewirken. Die Codes lagen den Geräten in Codebüchern bei.

Rechtsstreit

Nintendo versuchte vergeblich, den Vertrieb gerichtlich zu untersagen (Lewis Galoob Toys, Inc. v. Nintendo of America, Inc., 1992). Das US-Berufungsgericht entschied, dass die Nutzung des Game Genie keine Urheberrechtsverletzung darstelle.
