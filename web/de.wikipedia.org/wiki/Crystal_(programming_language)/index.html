Crystal (Programmiersprache)

Crystal ist eine objektorientierte, kompilierte Programmiersprache mit statischer Typisierung, deren Syntax stark an Ruby angelehnt ist. Ihr Motto lautet sinngemäß „So schnell wie C, so geschmeidig wie Ruby". Crystal wird seit 2011 entwickelt, maßgeblich von dem argentinischen Unternehmen Manas Technology Solutions; die Version 1.0 erschien im März 2021.

Eigenschaften

Crystal-Programme werden mithilfe von LLVM in nativen Maschinencode übersetzt und erreichen dadurch eine mit C vergleichbare Ausführungsgeschwindigkeit. Die Typen werden weitgehend per Typinferenz ermittelt, sodass kaum Typangaben nötig sind, der Code aber statisch geprüft wird. Die Sprache bietet unter anderem:

  • ein Makrosystem zur Codegenerierung
  • Nebenläufigkeit über leichtgewichtige Fibers und Kanäle nach dem Vorbild von Go
  • Null-Sicherheit durch Union-Typen (der Wert nil ist ein eigener Typ)
  • Anbindung an C-Bibliotheken ohne Zusatzcode
  • einen Paketmanager namens Shards

Verwendung

Crystal wird vor allem für Webanwendungen, Kommandozeilenwerkzeuge und systemnahe Programme eingesetzt; bekannte Webframeworks sind Kemal, Amber und Lucky. Die Sprache ist quelloffen und steht unter der Apache-Lizenz 2.0.
