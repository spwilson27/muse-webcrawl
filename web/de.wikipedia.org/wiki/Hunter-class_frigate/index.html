Hunter-Klasse
Land: Australien
Typ: Fregatte (U-Boot-Jagd)
Programm: SEA 5000
Bauwerft: Osborne, Adelaide

Die Hunter-Klasse ist eine Klasse von Fregatten, die für die Royal Australian Navy gebaut wird. Sie basiert auf dem britischen Entwurf der Type 26 (Global Combat Ship) und ist primär für die U-Boot-Jagd ausgelegt. Das Programm ist eines der größten Rüstungsvorhaben in der Geschichte Australiens.

Programm

Die Schiffe werden von ASC Shipbuilding, einer Tochter von BAE Systems Australia, in Osborne bei Adelaide gebaut. Die Fregatten sollen die Anzac-Klasse ersetzen und erhalten unter anderem das Aegis-Kampfsystem sowie australische Radartechnik (CEAFAR). Der Bau des ersten Schiffes begann 2024; ursprünglich waren neun Einheiten geplant, die Zahl wurde in einer Flottenüberprüfung auf sechs reduziert.
