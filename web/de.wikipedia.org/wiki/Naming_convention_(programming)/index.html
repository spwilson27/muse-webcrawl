Namenskonvention (Programmierung)

Eine Namenskonvention (englisch naming convention) ist in der Programmierung ein Regelwerk zur einheitlichen Benennung von Bezeichnern wie Variablen, Funktionen, Klassen und Dateien. Ziel ist es, Quellcode lesbarer, wartbarer und weniger fehleranfällig zu machen.

Verbreitete Schreibweisen

  • camelCase: Das erste Wort beginnt klein, jedes weitere Wort mit einem Großbuchstaben, z. B. anzahlKunden.
  • PascalCase: Jedes Wort beginnt mit einem Großbuchstaben, z. B. AnzahlKunden.
  • snake_case: Wörter werden klein geschrieben und durch Unterstriche getrennt, z. B. anzahl_kunden.
  • SCREAMING_SNAKE_CASE: Durchgehend Großbuchstaben mit Unterstrichen, meist für Konstanten, z. B. MAX_WERT.
  • kebab-case: Wörter werden durch Bindestriche getrennt, gebräuchlich etwa in CSS und URLs.

Weitere Konventionen

Die ungarische Notation kennzeichnet den Datentyp eines Bezeichners durch ein Präfix. Daneben legen viele Styleguides fest, dass boolesche Variablen mit ist, hat oder kann beginnen oder dass private Felder mit einem Unterstrich markiert werden. Sprachspezifische Normen finden sich beispielsweise in den PEP 8 für Python oder den Java Code Conventions.

Bedeutung

Einheitliche Namenskonventionen erleichtern die Zusammenarbeit in Teams, Code-Reviews und die automatische Prüfung durch Linter. Sie gehören zu den grundlegenden Maßnahmen der Softwarequalität.
