CSS Profile

Das CSS Profile ist ein von der US-amerikanischen Organisation College Board bereitgestelltes Online-Formular zur Beantragung finanzieller Studienbeihilfen (Financial Aid) an Hochschulen in den Vereinigten Staaten. Anders als der staatliche FAFSA-Antrag wird das CSS Profile vor allem von privaten und besonders selektiven Colleges und Universitäten verwendet.

Inhalt und Verfahren

Das Formular erfasst detaillierte Angaben zu Einkommen, Vermögen und Ausgaben der Familie des Studierenden, darunter auch Eigenheimwerte und Einkommen nicht sorgeberechtigter Elternteile. Auf dieser Grundlage berechnen die teilnehmenden Hochschulen den finanziellen Bedarf und die Höhe institutioneller Stipendien und Zuschüsse. Die Übermittlung ist kostenpflichtig, wobei für einkommensschwache Familien Gebührenbefreiungen möglich sind.

Unterschied zum FAFSA

Während der FAFSA (Free Application for Federal Student Aid) Voraussetzung für staatliche Studienförderung ist, dient das CSS Profile der Verteilung hochschuleigener Mittel. Rund 200 bis 400 Institutionen, überwiegend private Hochschulen, nutzen das Verfahren zusätzlich.
