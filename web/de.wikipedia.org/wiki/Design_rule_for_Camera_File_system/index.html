Design Rule for Camera File System

Die Design Rule for Camera File System (DCF) ist ein Standard der Japan Electronics and Information Technology Industries Association (JEITA) für das Dateisystem von Digitalkameras. Er legt Verzeichnis- und Dateinamen auf Speicherkarten fest, sodass Aufnahmen zwischen Kameras, Druckern und anderen Geräten verschiedener Hersteller ausgetauscht werden können. DCF baut auf dem Exif-Standard auf.

Verzeichnisstruktur

Nach DCF liegen die Aufnahmen auf der Speicherkarte im Verzeichnis DCIM (Digital Camera Images). Darunter befinden sich Unterordner, deren Namen aus einer dreistelligen Nummer (100 bis 999) und fünf frei wählbaren alphanumerischen Zeichen bestehen, etwa 100CANON oder 101MSDCF. Dateinamen setzen sich aus vier frei wählbaren Zeichen und einer vierstelligen laufenden Nummer zusammen, zum Beispiel DSC_0001.JPG.

Bestimmungen

Als Dateisystem wird FAT (FAT12/16/32, teils exFAT) verwendet. Der Standard regelt auch den Farbraum der Bilder (sRGB oder Adobe RGB, durch einen Unterstrich als erstem Zeichen des Dateinamens gekennzeichnet) sowie die Vorschaubilder (Thumbnails). Eingeführt wurde DCF 1998 in der Version 1.0; Version 2.0 folgte 2010.
