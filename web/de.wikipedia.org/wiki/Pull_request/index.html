Pull Request

Ein Pull Request (deutsch etwa „Zieh-Anfrage“, auch Merge Request genannt) ist ein Verfahren in der Versionsverwaltung von Software, mit dem ein Entwickler beantragt, seine Änderungen an einem Zweig (Branch) in ein zentrales Repository zu übernehmen. Pull Requests sind ein zentrales Arbeitsmittel verteilter Versionskontrollsysteme wie Git und werden insbesondere durch Plattformen wie GitHub, GitLab und Bitbucket unterstützt.

Ablauf

Typischerweise erstellt ein Entwickler eine Kopie (Fork) eines Projekts oder arbeitet in einem eigenen Branch, nimmt dort Änderungen vor und stellt anschließend einen Pull Request, der die Unterschiede (Diff) zum Ziel-Branch beschreibt. Andere Projektmitglieder können die Änderungen prüfen (Code Review), kommentieren und Verbesserungswünsche äußern; automatisierte Tests (Continuous Integration) laufen parallel. Erst nach Freigabe durch einen Berechtigten werden die Änderungen zusammengeführt (Merge).

Bedeutung

Pull Requests strukturieren die Zusammenarbeit in Open-Source-Projekten und in der professionellen Softwareentwicklung: Sie dokumentieren die Entstehungsgeschichte von Änderungen, ermöglichen Diskussionen direkt am Code und senken die Hürde für Beiträge externer Entwickler.
