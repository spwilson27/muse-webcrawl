Gerichteter azyklischer Graph

Ein gerichteter azyklischer Graph (englisch directed acyclic graph, DAG) ist ein gerichteter Graph, der keine gerichteten Zyklen enthält: Es gibt keinen Weg, der von einem Knoten ausgeht und über gerichtete Kanten zu demselben Knoten zurückführt.


Beispiel eines DAGs mit topologischer Ordnung

Eigenschaften

Jeder DAG besitzt mindestens eine topologische Sortierung: eine Anordnung seiner Knoten, bei der jede Kante von einem früheren zu einem späteren Knoten zeigt. Umgekehrt besitzt ein gerichteter Graph genau dann eine topologische Sortierung, wenn er azyklisch ist. Endliche DAGs können induktiv über ihre Quellen (Knoten ohne eingehende Kanten) verarbeitet werden.

Anwendungen

  • Informatik: Abhängigkeitsgraphen in Build-Systemen (z. B. Make), Ablaufplanung und Aufgaben in Daten pipelines; die Versionsgeschichte von Git bildet einen DAG.
  • Digitale Währungen: Einige verteilte Ledger-Technologien wie IOTA nutzen DAGs statt einer linearen Blockchain.
  • Bayessche Netze: Kausalmodelle in der Statistik werden als DAGs dargestellt.
  • Darstellung von Ausdrücken: Gemeinsame Teilausdrücke in Compilern werden effizient als DAG gespeichert.
