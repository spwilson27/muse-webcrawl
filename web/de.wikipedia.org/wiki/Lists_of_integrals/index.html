Listen von Integralen

Diese Übersichtsseite verweist auf Integraltabellen – Sammlungen von Stammfunktionen und bestimmten Integralen, geordnet nach Funktionstypen. Solche Tabellen sind klassische Hilfsmittel der Analysis; bekannte Werke sind die Integraltafeln von Gradshteyn und Ryzhik sowie Bronstein/Semendjajew.

Integrallisten nach Funktionstyp

  • Integrale rationaler Funktionen
  • Integrale irrationaler Funktionen
  • Integrale trigonometrischer Funktionen
  • Integrale hyperbolischer Funktionen
  • Integrale von Exponentialfunktionen
  • Integrale von Logarithmusfunktionen
  • Integrale der inversen trigonometrischen Funktionen
  • Integrale der Gaußschen Fehlerfunktion und Fresnel-Integrale

Grundintegrale (Beispiele)

  • ∫ xn dx = xn+1 / (n+1) + C (für n ≠ −1)
  • ∫ 1/x dx = ln |x| + C
  • ∫ ex dx = ex + C
  • ∫ sin x dx = −cos x + C
  • ∫ cos x dx = sin x + C
  • ∫ 1/(1+x²) dx = arctan x + C

Bestimmte Integrale

Neben unbestimmten Integralen sammeln die Listen auch bestimmte Integrale, etwa das Gaußsche Integral ∫−∞∞ e−x² dx = √π, sowie Integrale, die über spezielle Funktionen wie die Gammafunktion ausgewertet werden.
