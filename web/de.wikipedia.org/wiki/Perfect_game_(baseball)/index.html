Perfect Game (Baseball)

Ein Perfect Game ist im Baseball ein Spiel, in dem ein Pitcher (oder eine Kombination von Pitchern) einen Sieg erringt, ohne dass ein einziger gegnerischer Schlagmann eine Base erreicht — weder durch einen Hit, einen Walk, einen Hit by Pitch noch durch einen Error. Mindestens 27 Schlagleute müssen in Folge aus gemacht werden.

Geschichte

Perfect Games sind äußerst selten. In der Geschichte der Major League Baseball gelangen bis heute nur gut zwei Dutzend solcher Spiele. Das erste anerkannte Perfect Game warf Lee Richmond am 12. Juni 1880; wenige Tage später folgte John Montgomery Ward. Berühmt ist das Perfect Game von Don Larsen im fünften Spiel der World Series 1956 für die New York Yankees gegen die Brooklyn Dodgers — bis heute das einzige in einer World Series.

Abgrenzung

Ein Perfect Game setzt einen No-Hitter voraus, ist aber strenger: Beim No-Hitter dürfen Schlagleute durch Walks oder Fehler durchaus Basen erreichen. Ein Perfect Game endet außerdem, sobald ein Runner die erste Base erreicht, auch im Nachhinein durch eine geänderte Schiedsrichterentscheidung kann die Anerkennung umstritten sein — bekannt wurde der Fall von Armando Galarraga im Jahr 2010, dem ein Perfect Game durch eine Fehlentscheidung des Umpires am 27. Schlagmann verwehrt wurde.
