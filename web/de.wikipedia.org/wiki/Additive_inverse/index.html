Gegenzahl (additiv Inverses)

Die Gegenzahl oder das additiv Inverse (englisch additive inverse) einer Zahl a ist diejenige Zahl −a, die mit a addiert das neutrale Element der Addition ergibt: a + (−a) = 0. Bei reellen Zahlen entspricht die Gegenzahl der Zahl mit umgekehrtem Vorzeichen und gleichem Betrag.

Beispiele

Die Gegenzahl von 7 ist −7, die Gegenzahl von −3 ist 3. Die Gegenzahl von 0 ist 0 selbst. Für eine komplexe Zahl a + bi ist die Gegenzahl −a − bi. In einem Vektorraum ist die Gegenzahl eines Vektors der Vektor mit entgegengesetzter Richtung und gleicher Länge.

Eigenschaften

  • Das additiv Inverse ist eindeutig bestimmt.
  • Es gilt −(−a) = a (Involutivität).
  • Es gilt −(a + b) = (−a) + (−b).
  • Die Subtraktion lässt sich als Addition der Gegenzahl definieren: a − b = a + (−b).

Allgemeine Bedeutung

In jeder Gruppe existiert zu jedem Element ein inverses Element. Wird die Gruppe additiv geschrieben, spricht man vom additiven Inversen oder Gegenelement; bei multiplikativer Schreibweise vom Kehrwert beziehungsweise multiplikativen Inversen.
