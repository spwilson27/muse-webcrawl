Objektdatei

Eine Objektdatei (englisch object file) ist eine Datei, die von einem Compiler oder Assembler erzeugt wird und Maschinencode sowie weitere Informationen enthält. Sie ist noch nicht eigenständig ausführbar, sondern wird von einem Linker mit anderen Objektdateien und Bibliotheken zu einem ausführbaren Programm oder einer Bibliothek verbunden.

Inhalt

Eine Objektdatei enthält typischerweise mehrere Abschnitte (Sections): den ausführbaren Code (.text), initialisierte Daten (.data), nicht initialisierte Daten (.bss) und schreibgeschützte Konstanten. Hinzu kommen eine Symboltabelle, die definierte und referenzierte Symbole auflistet, sowie Relokationsinformationen, die dem Linker angeben, welche Adressen beim Zusammenfügen anzupassen sind.

Formate

  • ELF (Executable and Linkable Format) — Standard unter Linux und vielen Unix-Systemen; Dateiendung meist .o.
  • COFF und sein Nachfolger PE — unter Windows üblich; Dateiendung .obj beziehungsweise .o.
  • Mach-O — unter macOS und iOS verwendet.

Ablauf

Im Übersetzungsvorgang wird jede Quelldatei getrennt in eine Objektdatei übersetzt. Der Linker löst anschließend die Verweise zwischen den Modulen auf, weist den Abschnitten Speicheradressen zu und erzeugt das fertige Programm. Statische Bibliotheken sind im Kern Archive mehrerer Objektdateien.
