IMSI

Die International Mobile Subscriber Identity (IMSI) ist eine weltweit eindeutige Kennung, mit der ein Mobilfunkteilnehmer gegenüber dem Netz identifiziert wird. Sie ist auf der SIM-Karte gespeichert und wird – anders als die Rufnummer – nicht zur Adressierung von Anrufen verwendet, sondern für Anmeldung, Authentifizierung und Abrechnung.

Aufbau

Die IMSI ist höchstens 15 Stellen lang und besteht aus dem Mobile Country Code (MCC) für das Land, dem Mobile Network Code (MNC) für den Netzbetreiber und der Mobile Subscription Identification Number (MSIN) für den einzelnen Anschluss. Die ersten Stellen erlauben es einem besuchten Netz, das Heimatnetz des Teilnehmers zu bestimmen.

Funktion im Netz

Beim Einbuchen sendet das Endgerät die IMSI an das Netz; im Heimatnetz wird sie im Home Location Register (HLR) bzw. Home Subscriber Server (HSS) verwaltet. Zum Schutz der Privatsphäre wird die IMSI im laufenden Betrieb möglichst selten im Klartext übertragen; stattdessen vergibt das Netz temporäre Kennungen wie die TMSI. In 5G-Netzen wird die entsprechende Kennung (SUPI) grundsätzlich verschlüsselt übertragen.

Sicherheit

Geräte, die sich als Basisstation ausgeben (IMSI-Catcher), können Endgeräte zur Preisgabe ihrer IMSI veranlassen und so Identifizierung und Ortung ermöglichen. Ihr Einsatz durch Ermittlungsbehörden ist in Deutschland in der Strafprozessordnung geregelt und umstritten. Auch kommerzielle Datensammler haben IMSI in der Vergangenheit zur Nachverfolgung von Geräten missbraucht.
