Basenkonstante

Die Basenkonstante (Kb) ist eine Gleichgewichtskonstante, die die Stärke einer Base in wässriger Lösung beschreibt. Sie gibt an, in welchem Maße eine Base in Wasser in ihr konjugiertes Kation und Hydroxidionen übergeht.

Definition

Für die Reaktion einer Base B mit Wasser gilt:

B + H2O ⇌ BH+ + OH−

Die Basenkonstante ist definiert als Kb = [BH+] · [OH−] / [B], wobei die eckigen Klammern Gleichgewichtskonzentrationen bezeichnen. Häufig wird der negative dekadische Logarithmus, der pKb-Wert, angegeben: Je kleiner der pKb-Wert, desto stärker ist die Base.

Zusammenhang mit der Säurekonstante

Für ein konjugiertes Säure-Base-Paar gilt in Wasser bei 25 °C: pKa + pKb = 14. Eine starke Base hat daher eine schwache konjugierte Säure und umgekehrt.
