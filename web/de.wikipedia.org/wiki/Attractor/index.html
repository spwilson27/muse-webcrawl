Attraktor

Ein Attraktor ist in der Theorie dynamischer Systeme eine Menge im Zustandsraum, auf die sich die Entwicklung eines Systems langfristig zubewegt, wenn es aus einem bestimmten Bereich von Anfangsbedingungen (dem Einzugsgebiet oder Bassin des Attraktors) startet.

Arten

  • Fixpunkt: Das System strebt einem stationären Zustand zu, etwa ein gedämpftes Pendel der Ruhelage.
  • Grenzzyklus: Die Trajektorie nähert sich einer geschlossenen periodischen Bahn, etwa bei selbsterregten Schwingungen.
  • Torus: Quasiperiodische Bewegung auf einer torusförmigen Fläche.
  • Seltsamer Attraktor: Ein Attraktor mit fraktaler Struktur, auf dem das System chaotisches Verhalten zeigt; das bekannteste Beispiel ist der Lorenz-Attraktor.

Bedeutung

Attraktoren beschreiben das Langzeitverhalten dissipativer Systeme. In der Chaosforschung spielen seltsame Attraktoren eine zentrale Rolle: Obwohl die Bewegung auf ihnen niemals exakt periodisch ist, bleibt sie auf eine gebundene, strukturierte Menge beschränkt. Die Dimension eines seltsamen Attraktors ist typischerweise nicht ganzzahlig (fraktale Dimension).

Der Begriff wird auch metaphorisch in anderen Wissenschaften verwendet, etwa in der Psychologie, Ökologie oder Stadtforschung für Zustände, auf die ein System immer wieder zurückfällt.
