Modulare Diskriminante

Die modulare Diskriminante, üblicherweise mit Δ (Delta) bezeichnet, ist eine zentrale Funktion der Theorie der Modulformen. Sie ist eine Spitzenform (Cusp-Form) vom Gewicht 12 zur vollen Modulgruppe SL(2, ℤ) und das älteste und bekannteste Beispiel einer solchen Form.

Definition

Als Funktion auf der oberen Halbebene wird die Diskriminante über das unendliche Produkt definiert: Δ(τ) = q ∏ (1 − qn)24, mit q = e2πiτ. Alternativ lässt sie sich als 1728-faches der dritten Potenz der Weierstraßschen ℘-Invariante g2 abzüglich … über die Eisenstein-Reihen ausdrücken: Δ = (E43 − E62) / 1728.

Fourierentwicklung

Die Fourierkoeffizienten der Diskriminante definiert die Ramanujan-Tau-Funktion τ(n): Δ(τ) = Σ τ(n) qn. Ramanujan stellte berühmte Vermutungen über diese Koeffizienten auf, die unter anderem von Pierre Deligne im Rahmen seines Beweises der Weil-Vermutungen bestätigt wurden.
