Mail Transfer Agent

Ein Mail Transfer Agent (MTA) ist ein Computerprogramm, das E-Mails entgegennimmt und an andere Mailserver oder an einen lokalen Mail Delivery Agent weiterleitet. MTAs kommunizieren untereinander mit dem Simple Mail Transfer Protocol (SMTP) über Port 25 und bilden das Rückgrat des weltweiten E-Mail-Systems.

Arbeitsweise

Ein MTA nimmt Nachrichten vom Mail User Agent des Absenders oder von einem anderen MTA an, bestimmt anhand des MX-Eintrags im Domain Name System den Zielserver der Empfängerdomain und übergibt die Nachricht an diesen – oder in eine Warteschlange, falls der Zielserver vorübergehend nicht erreichbar ist. MTAs, die Nachrichten für fremde Domains weiterleiten (Open Relays), gelten als missbrauchsanfällig und werden heute in der Regel blockiert.

Bekannte MTAs

  • Sendmail – einer der ältesten MTAs (seit den 1980er Jahren),
  • Postfix – sicherheitsorientierter, weit verbreiteter MTA von Wietse Venema,
  • Exim – Standard-MTA vieler Linux-Distributionen, insbesondere Debian,
  • qmail – von Daniel J. Bernstein entwickelter MTA,
  • Microsoft Exchange Server – Groupware- und Mailsystem für Unternehmen.

Sicherheit

Moderne MTAs unterstützen Verschlüsselung (STARTTLS) und Authentifizierungsverfahren wie SPF, DKIM und DMARC, um Spam und Absenderfälschung (Spoofing) einzudämmen.
