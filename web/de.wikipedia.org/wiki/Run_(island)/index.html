Run (Insel)

Run (indonesisch Pulau Run) ist eine kleine Insel der Banda-Inseln in der Bandasee, Provinz Maluku, Indonesien. Sie ist etwa drei Kilometer lang und einen Kilometer breit und war im 17. Jahrhundert wegen ihrer Muskatnussplantagen von großer Bedeutung für den weltweiten Gewürzhandel.

Geschichte

Run war eine der wenigen Inseln, auf denen die Muskatnuss ursprünglich wuchs, und daher im Gewürzhandel von immensem Wert. 1616 besetzten die Engländer unter Nathaniel Courthope die Insel und hielten sie mehrere Jahre gegen die Niederländische Ostindien-Kompanie (VOC). 1620 mussten sie sich schließlich zurückziehen.

Im Zweiten Englisch-Niederländischen Krieg spielte Run erneut eine Rolle. Mit dem Frieden von Breda 1667 trat England die Insel förmlich an die Niederlande ab und erhielt im Gegenzug die niederländische Kolonie Nieuw Nederland in Nordamerika mit der Siedlung Nieuw Amsterdam, dem späteren New York. Run blieb danach eine niederländische Muskatnussplantage, bis der Gewürzhandel im 19. Jahrhundert durch die Verpflanzung der Muskatnuss in andere Kolonien seine Bedeutung verlor.

Gegenwart

Heute leben wenige hundert Menschen auf Run, die von Fischerei und dem Anbau von Muskatnüssen und anderen Gewürzen leben. Die Insel ist ein Ziel für Taucher und historisch interessierte Reisende, die die Banda-Inseln besuchen.
