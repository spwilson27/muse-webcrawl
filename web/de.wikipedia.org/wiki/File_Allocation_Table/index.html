File Allocation Table

Die File Allocation Table (FAT, deutsch „Dateizuordnungstabelle“) ist ein von Microsoft entwickeltes Dateisystem, das ursprünglich für MS-DOS entstand und über Jahrzehnte auf Disketten, Festplatten und später auf Speicherkarten und USB-Sticks weit verbreitet war.

Varianten

Je nach Breite der Tabelleneinträge unterscheidet man FAT12 (Disketten), FAT16 und FAT32. FAT32, eingeführt mit Windows 95 OSR2, erlaubt Partitionen bis zu 2 Terabyte, einzelne Dateien jedoch nur bis 4 Gigabyte. Für größere Dateien entwickelte Microsoft das Nachfolgesystem exFAT.

Funktionsweise

Das Dateisystem verwaltet den Datenträger in Clustern. Die FAT enthält für jeden Cluster einen Eintrag, der auf den nächsten Cluster derselben Datei verweist oder das Dateiende markiert — so entstehen verkettete Listen. Ein Verzeichnis speichert zu jeder Datei Namen, Größe und Startcluster.

Bedeutung

Wegen seiner Einfachheit und breiten Unterstützung ist FAT bis heute Austauschstandard für Wechseldatenträger, obwohl es weder Berechtigungen noch Journaling kennt.
