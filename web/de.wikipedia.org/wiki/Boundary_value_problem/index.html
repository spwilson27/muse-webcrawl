Randwertproblem

Ein Randwertproblem (englisch boundary value problem) ist in der Mathematik ein Problem, bei dem eine Differentialgleichung zusammen mit Bedingungen gelöst wird, die an den Rändern des betrachteten Gebietes vorgeschrieben sind. Im Gegensatz dazu sind bei Anfangswertproblemen alle Bedingungen an einem einzelnen Punkt gegeben.

Arten von Randbedingungen

Bei Dirichlet-Randbedingungen wird der Funktionswert auf dem Rand vorgegeben, bei Neumann-Randbedingungen die Normalenableitung, bei Robin- beziehungsweise gemischten Bedingungen eine Linearkombination beider. Ein gut gestelltes Problem besitzt eine eindeutige, stabil von den Daten abhängige Lösung.

Beispiele und Anwendungen

Klassische Randwertprobleme beschreiben die stationäre Temperaturverteilung in einem Körper, die Elektrostatik oder die Durchbiegung einer eingespannten Membran. Numerisch werden sie häufig mit der Finite-Elemente-Methode oder Finite-Differenzen-Verfahren gelöst. Das Sturm-Liouville-Problem ist ein wichtiges Eigenwert-Randwertproblem der mathematischen Physik.
