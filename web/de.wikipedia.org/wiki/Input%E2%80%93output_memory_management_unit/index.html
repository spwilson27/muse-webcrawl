Input–Output Memory Management Unit (IOMMU)

Eine Input–Output Memory Management Unit (IOMMU) ist eine Hardwarekomponente, die – analog zur Memory Management Unit (MMU) für die CPU – Speicherzugriffe von Ein-/Ausgabegeräten (DMA) verwaltet und übersetzt. Sie verbindet DMA-fähige Geräte (etwa über PCI Express) mit dem Hauptspeicher des Computers.

Funktionsweise

Geräte arbeiten mit gerätespezifischen bzw. vom Betriebssystem vergebenen DMA-Adressen, die die IOMMU mithilfe von Seitentabellen in physische Adressen übersetzt. Dadurch kann jedem Gerät ein eigener Adressraum zugewiesen werden; Zugriffe außerhalb des erlaubten Bereichs werden blockiert und als Fehler gemeldet.

Vorteile

  • Schutz: Fehlerhafte oder bösartige Geräte (z. B. über Thunderbolt oder FireWire angeschlossene Peripherie) können nicht auf beliebige Speicherbereiche zugreifen (DMA-Angriffe werden erschwert).
  • Virtualisierung: Durch „Device Passthrough“ (PCI-Passthrough) kann eine virtuelle Maschine ein physisches Gerät direkt nutzen, da die IOMMU die Zugriffe isoliert zum Speicher der VM umlenkt (Intel VT-d, AMD-Vi).
  • Vereinfachung: Geräte benötigen keine besonderen Treiber, um auf nicht zusammenhängenden physischen Speicher als scheinbar zusammenhängenden Bereich zuzugreifen (Scatter-Gather-Unterstützung).

Implementierungen

Bekannte Implementierungen sind Intels VT-d (Virtualization Technology for Directed I/O), AMDs AMD-Vi (früher allgemein IOMMU genannt) und ARM SMMU in Mobil- und Serverprozessoren. Betriebssysteme wie Linux (mit Parametern wie intel_iommu=on), Windows und Hypervisoren nutzen die IOMMU für Virtualisierung und Geräteschutz, etwa bei Kernel DMA Protection.
