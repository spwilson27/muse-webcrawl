Object Linking and Embedding

Object Linking and Embedding (OLE, englisch für „Verknüpfen und Einbetten von Objekten“) ist ein von Microsoft entwickeltes Objektsystem und Protokoll, das die Zusammenarbeit unterschiedlicher Anwendungsprogramme unter Windows ermöglicht. Mit OLE können beispielsweise eine Excel-Tabelle in einem Word-Dokument oder eine Grafik in einer Präsentation eingebettet oder verknüpft werden.

Verknüpfen und Einbetten

Beim Einbetten wird eine Kopie der Daten zusammen mit Informationen über die erzeugende Anwendung im Zieldokument gespeichert. Beim Verknüpfen dagegen bleibt das Objekt in einer eigenen Datei, und das Dokument enthält nur einen Verweis darauf; Änderungen an der Quelldatei wirken sich dann auf alle verknüpften Dokumente aus.

Geschichte

OLE 1.0 erschien 1990 als Nachfolger des Dynamic Data Exchange (DDE). OLE 2.0 führte 1993 die Grundlage des Component Object Model (COM) ein. Spätere Entwicklungen umfassten OLE Automation, die OLE DB-Schnittstellen für Datenbankzugriff und die ActiveX-Steuerelemente.

Technik

Technisch basiert OLE auf COM und strukturierter Speicherung (Compound Files), einem Dateiformat, das viele Objekte wie in einem Dateisystem innerhalb einer Datei verwaltet. OLE-Server sind Anwendungen, die OLE-Objekte bereitstellen; OLE-Container betten diese ein.
