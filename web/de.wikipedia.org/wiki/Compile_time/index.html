Compilezeit

Als Compilezeit (englisch compile time) bezeichnet man in der Informatik den Zeitraum beziehungsweise den Zeitpunkt, zu dem ein Programm von einem Compiler übersetzt wird. Sie steht im Gegensatz zur Laufzeit (runtime), in der das übersetzte Programm ausgeführt wird, sowie zur Linkzeit und zur Ladezeit.

Compilezeit-Prüfungen

Viele Fehler können bereits zur Compilezeit erkannt werden, darunter Syntaxfehler, Typfehler und undeklarierte Bezeichner. Statische Typprüfung zur Compilezeit gilt als Vorteil statisch typisierter Sprachen, weil eine ganze Klasse von Fehlern nicht erst zur Laufzeit auftreten kann.

Auswertung zur Compilezeit

Compiler können bestimmte Berechnungen bereits zur Compilezeit ausführen:

  • Konstantenfaltung (constant folding): Ausdrücke aus Konstanten werden vorab berechnet.
  • Compilezeit-Funktionsauswertung: etwa constexpr in C++ oder const fn in Rust.
  • Generische Programmierung und Makros: Code wird zur Compilezeit erzeugt oder spezialisiert.
  • Statische Zusicherungen (static_assert): Bedingungen werden zur Compilezeit geprüft.

Bedeutung der Dauer

Die Länge der Compilezeit ist ein praktischer Faktor in der Softwareentwicklung: Lange Übersetzungszeiten verlangsamen den Entwicklungszyklus. Techniken wie inkrementelle Compilation, verteilte Builds und Caching (etwa mit ccache) dienen dazu, sie zu verkürzen.
