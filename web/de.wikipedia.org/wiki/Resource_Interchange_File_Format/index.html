Resource Interchange File Format

Das Resource Interchange File Format (RIFF) ist ein Containerformat zur Speicherung strukturierter Multimediadaten, das 1991 von Microsoft und IBM eingeführt wurde. Es basiert auf dem Interchange File Format (IFF) von Electronic Arts, verwendet jedoch Little-Endian-Bytefolge.

RIFF-Dateien bestehen aus Blöcken (Chunks), die jeweils durch eine vierstellige Kennung (FourCC), eine Längenangabe und die eigentlichen Daten aufgebaut sind. Bekannte RIFF-basierte Formate sind WAV für Audiodaten, AVI für Videodaten und WebP für Bilder.

Aufbau

Ein RIFF-Chunk beginnt mit dem Kennzeichen „RIFF“, gefolgt von der Dateigröße und einem Formattyp wie „WAVE“. Innerhalb des Containers können weitere Unter-Chunks verschachtelt werden, was eine flexible Erweiterung ermöglicht.

Verwendung

RIFF wird vor allem in der Windows-Welt eingesetzt. Viele Multimediaframeworks und Audioprogramme lesen und schreiben RIFF-Dateien.
