Abbildung (Mathematik)

Eine Abbildung (englisch map, mapping) ist in der Mathematik die eindeutige Zuordnung von Elementen einer Menge zu Elementen einer anderen Menge. In den meisten Zusammenhängen ist der Begriff gleichbedeutend mit dem der Funktion; in Teilgebieten wie der Algebra oder der Topologie wird „Abbildung" bevorzugt verwendet, etwa bei linearen Abbildungen oder stetigen Abbildungen.

Definition

Eine Abbildung f von einer Menge X (Definitionsbereich) in eine Menge Y (Zielmenge) ordnet jedem Element x ∈ X genau ein Element y = f(x) ∈ Y zu. Man schreibt f : X → Y.

Eigenschaften

  • Injektiv: Verschiedene Elemente von X erhalten verschiedene Bilder.
  • Surjektiv: Jedes Element von Y wird getroffen.
  • Bijektiv: Injektiv und surjektiv; es existiert eine Umkehrabbildung.

Beispiele

Die Quadratfunktion f(x) = x² bildet die reellen Zahlen in die nichtnegativen reellen Zahlen ab. Eine Drehung der Ebene um einen festen Punkt ist eine bijektive Abbildung der Ebene auf sich selbst. Die Projektion eines Raumes auf eine Fläche ist eine Abbildung, die nicht injektiv ist.
