Kuroda-Normalform


Produktionen einer Grammatik in Kuroda-Normalform (Platzhalter)

Die Kuroda-Normalform ist eine Normalform für kontextsensitive Grammatiken in der theoretischen Informatik. Sie ist nach dem japanischen Linguisten und Mathematiker Sige-Yuki Kuroda benannt, der sie im Zusammenhang mit linear beschränkten Automaten einführte.

Definition

Eine kontextsensitive Grammatik befindet sich in Kuroda-Normalform, wenn jede ihrer Produktionen eine der folgenden Gestalten hat:

  • AB → CD
  • A → BC
  • A → B
  • A → a

Dabei stehen Großbuchstaben für Nichtterminalsymbole und a für ein Terminalsymbol.

Bedeutung

Jede kontextsensitive Grammatik kann in eine äquivalente Grammatik in Kuroda-Normalform überführt werden. Die Normalform ist besonders nützlich beim Nachweis, dass die von linear beschränkten Automaten (LBA) akzeptierten Sprachen genau die kontextsensitiven Sprachen sind: Die beschränkte Form der Produktionen erlaubt eine direkte Simulation der Grammatik auf dem linear beschränkten Band des Automaten.
