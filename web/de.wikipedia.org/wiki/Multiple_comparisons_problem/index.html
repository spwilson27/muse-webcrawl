Multiples Testen

Das Problem des multiplen Testens (englisch multiple comparisons problem oder multiple testing problem) tritt in der Statistik auf, wenn in einer Untersuchung gleichzeitig viele statistische Hypothesentests durchgeführt werden. Mit jedem zusätzlichen Test steigt die Wahrscheinlichkeit, dass mindestens eine Nullhypothese fälschlich verworfen wird (Fehler 1. Art).

Problemstellung

Wird jeder Test einzeln zum Niveau α = 5 % durchgeführt, so beträgt die Wahrscheinlichkeit für mindestens einen Fehlalarm bei m unabhängigen Tests bereits 1 − (1−α)m. Bei 20 Tests liegt sie somit bei etwa 64 %. Die familienweise Fehlerrate (FWER) beschreibt genau diese Wahrscheinlichkeit über die gesamte Testfamilie.

Korrekturverfahren

Das bekannteste Korrekturverfahren ist die Bonferroni-Korrektur, bei der das Signifikanzniveau durch die Zahl der Tests geteilt wird. Weniger konservative Alternativen sind die Holm-Bonferroni-Methode sowie Verfahren zur Kontrolle der False Discovery Rate (FDR), etwa nach Benjamini und Hochberg, die vor allem in der Genomik und Bildgebung große Bedeutung haben.
