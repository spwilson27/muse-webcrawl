Hot-Coffee-Mod

Die Hot-Coffee-Mod ist eine Modifikation des Videospiels Grand Theft Auto: San Andreas (2004), die 2005 einen weltweiten Skandal auslöste. Ein Modder entdeckte im Programmcode ein deaktiviertes Minispiel mit sexuellem Inhalt und machte es durch eine Änderung des Spielstandes zugänglich; der Name spielt auf die Einladung einer Spielfigur „auf einen Kaffee" an.

Kontroverse und Folgen

Nachdem bekannt wurde, dass die Szenen bereits im ausgelieferten Code des Spiels enthalten waren, stufte die US-amerikanische ESRB das Spiel nachträglich von „Mature" auf „Adults Only" hoch. Der Handel nahm das Spiel daraufhin aus den Regalen, und der Publisher Take-Two Interactive musste eine überarbeitete Fassung ohne den Code veröffentlichen sowie Rückrufe und hohe Kosten verkraften. Der Fall führte zu politischen Debatten über Alterskennzeichnung von Videospielen und zu einer Einigung mit der US-Handelsbehörde FTC; auch eine Sammelklage von Käufern wurde durch einen Vergleich beigelegt.
