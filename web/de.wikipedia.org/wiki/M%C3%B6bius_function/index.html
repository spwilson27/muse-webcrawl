Möbiusfunktion

Die Möbiusfunktion (auch Möbiussche μ-Funktion) ist eine zahlentheoretische Funktion in der Mathematik, die nach August Ferdinand Möbius benannt ist. Sie spielt eine zentrale Rolle in der multiplikativen Zahlentheorie, insbesondere bei der Möbiusschen Umkehrformel.

Definition

Für eine natürliche Zahl n mit Primfaktorzerlegung ist μ(n) definiert durch:

  • μ(1) = 1,
  • μ(n) = (−1)k, wenn n das Produkt von k verschiedenen Primzahlen ist,
  • μ(n) = 0, wenn n von einem Primzahlquadrat geteilt wird, also nicht quadratfrei ist.

Die ersten Werte sind μ(1) = 1, μ(2) = −1, μ(3) = −1, μ(4) = 0, μ(5) = −1, μ(6) = 1, μ(10) = 1, μ(30) = −1.

Eigenschaften

Die Möbiusfunktion ist multiplikativ, aber nicht vollständig multiplikativ. Eine grundlegende Eigenschaft ist, dass die Summe der Werte μ(d) über alle Teiler d von n genau dann 1 ist, wenn n = 1 gilt, und sonst 0. Daraus folgt die Möbiussche Umkehrformel, die den Zusammenhang zwischen einer zahlentheoretischen Funktion und ihrer summierenden Teilerfunktion umkehrt. Die Mertensfunktion ist die summierte Möbiusfunktion; ihr Wachstum hängt mit der Riemannschen Vermutung zusammen.
