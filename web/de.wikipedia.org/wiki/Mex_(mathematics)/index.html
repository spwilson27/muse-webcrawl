Mex (Mathematik)

In der Mathematik bezeichnet mex (von englisch minimum excluded value) einer Menge von Ordinalzahlen die kleinste Ordinalzahl, die nicht in der Menge enthalten ist. Der Begriff stammt aus der kombinatorischen Spieltheorie und wurde im Zusammenhang mit der Sprague-Grundy-Theorie geprägt.

Definition

Für eine Menge S von Ordinalzahlen ist mex(S) die kleinste Ordinalzahl, die kein Element von S ist. Beispiele: mex({0, 1, 2}) = 3, mex({0, 2, 3}) = 1, mex(∅) = 0.

Anwendung

Die mex-Funktion ist zentral für den Satz von Sprague und Grundy: Die Grundy-Zahl einer Position eines impartialen Spiels ist der mex-Wert der Grundy-Zahlen aller erreichbaren Folgepositionen. Damit lässt sich für viele Spiele entscheiden, ob eine Position eine Gewinn- oder Verluststellung ist.
