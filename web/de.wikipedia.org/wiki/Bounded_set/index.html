Beschränkte Menge

Eine beschränkte Menge ist ein Begriff aus der Analysis und der Topologie. Eine Menge heißt beschränkt, wenn sie „nicht unendlich groß“ wird, das heißt, wenn sich alle ihre Elemente in einem endlichen Bereich unterbringen lassen. Der Begriff wird unter anderem auf Teilmengen der reellen Zahlen, auf metrische Räume und auf normierte Räume angewandt.

Beschränkte Mengen reeller Zahlen

Eine Teilmenge M der reellen Zahlen heißt nach oben beschränkt, wenn es eine reelle Zahl S gibt, die größer oder gleich jedem Element von M ist. Eine solche Zahl heißt eine obere Schranke von M. Entsprechend heißt M nach unten beschränkt, wenn es eine untere Schranke gibt. Eine Menge ist beschränkt, wenn sie sowohl nach oben als auch nach unten beschränkt ist.

Äquivalent dazu ist die Forderung, dass es eine Zahl K gibt mit |x| ≤ K für alle x ∈ M. Die kleinste obere Schranke einer nach oben beschränkten, nichtleeren Menge reeller Zahlen heißt Supremum, die größte untere Schranke Infimum.

In metrischen Räumen

In einem metrischen Raum (X, d) heißt eine Menge M beschränkt, wenn ihr Durchmesser endlich ist, das heißt, wenn sup{d(x, y) : x, y ∈ M} < ∞ gilt. Äquivalent: Es gibt einen Punkt x0 und eine reelle Zahl r, sodass M ganz in der Kugel um x0 mit Radius r liegt.

Beschränkte Funktionen und Folgen

Eine Funktion heißt beschränkt, wenn ihr Bild eine beschränkte Menge ist. Eine Folge heißt beschränkt, wenn die Menge ihrer Folgenglieder beschränkt ist. Nach dem Satz von Bolzano-Weierstraß besitzt jede beschränkte Folge reeller Zahlen eine konvergente Teilfolge.

Beschränkte Mengen in topologischen Vektorräumen

In einem topologischen Vektorraum heißt eine Menge B beschränkt, wenn sie von jeder Nullumgebung absorbiert wird: Zu jeder Nullumgebung U gibt es ein λ > 0 mit B ⊆ λU. In normierten Räumen stimmt dieser Begriff mit der Beschränktheit bezüglich der Norm überein. Lineare Operatoren, die beschränkte Mengen auf beschränkte Mengen abbilden, heißen beschränkte Operatoren; in normierten Räumen sind dies genau die stetigen linearen Operatoren.
