Punktfreie Programmierung

Punktfreie Programmierung (englisch point-free style, auch tacit programming) ist ein Programmierstil, bei dem Funktionen definiert werden, ohne die Argumente („Punkte“), auf die sie angewendet werden, explizit zu benennen. Stattdessen werden Funktionen durch Komposition und andere Kombinatoren aus einfacheren Funktionen aufgebaut. Der Stil ist vor allem in funktionalen Programmiersprachen wie Haskell verbreitet, geht aber auf die Kombinatorische Logik und John Backus’ Programmiersprache FP zurück.

Beispiel

Die Summe einer Liste lässt sich in Haskell auf zwei Weisen definieren:

sum xs = foldr (+) 0 xs   -- mit benanntem Argument
sum    = foldr (+) 0      -- punktfrei

Die zweite Variante benennt das Argument xs nicht; die Funktion entsteht allein durch partielle Anwendung von foldr. Ein weiteres klassisches Beispiel ist die Definition des Mittelwerts als Komposition: mean = sum / length-artige Ausdrücke in Sprachen mit entsprechender Operatorunterstützung.

Vor- und Nachteile

Befürworter sehen im punktfreien Stil eine knappe, algebraisch gut analysierbare Schreibweise, die Gleichungsbeweise über Programme erleichtert. Kritiker wenden ein, dass übermäßig punktfreier Code schwer lesbar werden könne („write-only code“), weil die Datenflüsse nicht mehr an benannten Variablen ablesbar sind. In der Praxis wird der Stil daher meist dosiert eingesetzt.
