Teiler

Ein Teiler (auch Divisor) einer ganzen Zahl n ist eine ganze Zahl d, durch die sich n ohne Rest dividieren lässt; man schreibt d | n („d teilt n"). Die Teilermengen und -funktionen sind ein zentrales Untersuchungsobjekt der Zahlentheorie. Bei einer Division a : b = c heißt zudem die Zahl b selbst Divisor (der Dividend ist a).

Grundbegriffe

Jede Zahl besitzt die trivialen Teiler 1, −1, sich selbst und ihr Negatives. Eine Zahl mit genau zwei positiven Teilern heißt Primzahl; alle anderen Zahlen mit mehr als einem positiven Teiler heißen zusammengesetzt. Der größte gemeinsame Teiler zweier Zahlen wird mit dem euklidischen Algorithmus bestimmt, das kleinste gemeinsame Vielfache ergibt sich aus ihm über kgV(a,b) = |a·b| / ggT(a,b).

Teilbarkeit in Ringen

Der Teilerbegriff lässt sich auf beliebige Ringe verallgemeinern: In einem Integritätsring heißt a ein Teiler von b, wenn ein Element c mit b = a·c existiert. Darauf bauen die Begriffe Primelement und irreduzibles Element sowie die Theorie der faktoriellen Ringe auf.
