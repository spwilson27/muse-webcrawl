Bing

Bing ist eine Websuchmaschine des US-amerikanischen Softwareunternehmens Microsoft. Sie wurde am 3. Juni 2009 als Nachfolgerin von Live Search vorgestellt und ist nach Google die weltweit am zweithäufigsten genutzte Suchmaschine. Seit 2023 tritt sie als „Microsoft Bing“ auf und integriert mit dem „Copilot“ (früher Bing Chat) Funktionen auf Grundlage großer Sprachmodelle.

Geschichte

Microsofts Suchangebote begannen 1998 mit MSN Search; es folgten Windows Live Search und Live Search. Mit Bing führte Microsoft eine neue Ergebnisdarstellung mit Kategorien, Vorschauinformationen und einem täglich wechselnden Hintergrundbild ein. 2009 vereinbarten Microsoft und Yahoo eine Kooperation, bei der Bing die Suchergebnisse für Yahoo bereitstellte. Im Februar 2023 stellte Microsoft eine neue, KI-gestützte Version von Bing auf Basis der GPT-4-Technik von OpenAI vor.

Funktionen

  • Web-, Bilder-, Video-, Karten- und Nachrichtensuche
  • Bing Maps als Kartendienst
  • Integrierter Übersetzer und Taschenrechner, Flug- und Sportergebnisse
  • Copilot: Chat-basierte Suche mit Quellenangaben
  • Belohnungsprogramm Microsoft Rewards

Marktstellung

Der weltweite Marktanteil von Bing liegt je nach Messmethode bei etwa 3 Prozent, in den USA – auch dank der Yahoo-Kooperation und der Voreinstellung im Browser Edge und im Betriebssystem Windows – deutlich höher. Die Suchtechnologie von Bing versorgt auch andere Suchmaschinen wie DuckDuckGo und Ecosia mit Ergebnissen.
