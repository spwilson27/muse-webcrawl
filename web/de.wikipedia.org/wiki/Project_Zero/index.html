Project Zero (Google)

Project Zero ist ein Team von Sicherheitsforschern bei Google, das im Juli 2014 vorgestellt wurde. Seine Aufgabe ist es, bislang unbekannte Schwachstellen (Zero-Day-Lücken) in weit verbreiteter Software zu finden – sowohl in Googles eigenen Produkten als auch in denen anderer Hersteller.

Arbeitsweise

Die gefundenen Schwachstellen werden dem betroffenen Hersteller gemeldet. Üblich ist eine Offenlegungsfrist von 90 Tagen; wird die Lücke in dieser Zeit nicht geschlossen, veröffentlicht Project Zero die Details in seinem öffentlichen Issue-Tracker. Ziel ist es, den Druck zur Behebung zu erhöhen und Anwender zu schützen. Das Team publiziert zudem ausführliche technische Analysen in einem eigenen Blog.

Bekannte Funde

Project Zero war an der Entdeckung und Analyse zahlreicher bedeutender Schwachstellen beteiligt, darunter Funde in Betriebssystemen von Microsoft und Apple sowie Analysen zu staatlich genutzten Exploit-Ketten gegen Smartphones. 2021 gründete das Team ein weiteres Forschungsprogramm zur Untersuchung von Angriffen, die bereits aktiv ausgenutzt wurden.
