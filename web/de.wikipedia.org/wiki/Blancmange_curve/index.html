Blancmange-Kurve

Die Blancmange-Kurve ist eine fraktale Kurve der Mathematik. Sie ist ein klassisches Beispiel einer überall stetigen, aber nirgends differenzierbaren Funktion. Ihren Namen verdankt sie der Ähnlichkeit ihres Graphen mit der Oberfläche der gleichnamigen Süßspeise Blanc-manger.

Definition

Die Kurve ist definiert als Summe f(x) = Σ s(2nx) / 2n über alle n ≥ 0, wobei s(x) den Abstand von x zur nächsten ganzen Zahl bezeichnet (eine Dreiecks- bzw. Sägezahnfunktion). Eine der Funktion eng verwandte Variante geht auf den japanischen Mathematiker Teiji Takagi (1903) zurück; man spricht daher auch von der Takagi-Funktion.

Eigenschaften

Die Blancmange-Kurve ist auf dem Einheitsintervall stetig, an keinem Punkt differenzierbar und selbstähnlich: Jeder Ausschnitt entsteht aus dem Ganzen durch Skalierung. Sie dient in der Analysis als Standard-Gegenbeispiel gegen die Anschauung, stetige Funktionen seien „fast überall“ glatt.
