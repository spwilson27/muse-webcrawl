Canadian Electrical Code

Canadian Electrical Code (CE Code)
Norm: CSA C22.1
Herausgeber: CSA Group
Erstausgabe: 1927
Überarbeitung: alle drei Jahre

Der Canadian Electrical Code (kurz CE Code, offiziell CSA C22.1 – Canadian Electrical Code, Part I) ist die kanadische Norm für die sichere Installation und den Betrieb elektrischer Anlagen und Geräte. Er wird von der CSA Group herausgegeben und alle drei Jahre überarbeitet.

Inhalt und Geltung

Die Norm enthält Vorschriften für Elektroinstallationen in Wohngebäuden, Gewerbe und Industrie, darunter Anforderungen an Leitungen, Erdung (Bonding), Schutzmaßnahmen, Überstromschutz und Anlagen in besonderen Umgebungen. Rechtlich verbindlich wird der Code, indem die Provinzen und Territorien ihn – teils mit regionalen Änderungen – in ihr Baurecht übernehmen. Der Ontario Electrical Safety Code und der Code de construction du Québec sind Beispiele für provinziale Fassungen.

System der CSA-Normen

Teil I (C22.1) regelt die Installation, während Teil II aus einer Reihe von Produktnormen (C22.2) für die Zertifizierung elektrischer Geräte besteht. Das CSA-Prüfzeichen auf Geräten weist die Übereinstimmung mit diesen Normen nach. Der Canadian Electrical Code ist in Aufbau und Inhalt mit dem amerikanischen National Electrical Code (NEC) verwandt, unterscheidet sich aber in zahlreichen Anforderungen.

Geschichte

Die erste Ausgabe erschien 1927. Seitdem wurde der Code fortlaufend an den technischen Fortschritt angepasst, zuletzt etwa um Regeln für Photovoltaikanlagen, Energiespeicher und Ladeinfrastruktur für Elektrofahrzeuge.
