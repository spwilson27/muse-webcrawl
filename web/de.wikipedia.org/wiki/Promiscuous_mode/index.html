Promiscuous Mode

Der Promiscuous Mode (deutsch etwa „promiskuitiver Modus“, wörtlich „Modus für jeden Verkehr“) ist ein Betriebsmodus von Netzwerkschnittstellen, in dem die Schnittstelle sämtliche empfangenen Datenframes an die CPU weitergibt – auch solche, die nicht an ihre eigene MAC-Adresse gerichtet sind.

Funktionsweise

Im Normalbetrieb verwirft ein Netzwerkadapter alle Frames, deren Zieladresse weder die eigene Unicast-Adresse noch eine Broadcast- oder abonnierte Multicast-Adresse ist. Im Promiscuous Mode wird dieser Hardwarefilter abgeschaltet, sodass die Software den gesamten Datenverkehr des Netzsegments sehen kann. In geswitchten Netzwerken sieht eine Schnittstelle dennoch nur den Verkehr, der tatsächlich an ihrem Port ankommt; für vollständige Mitschnitte werden Port Mirroring oder Network TAPs eingesetzt.

Anwendungsbereiche

Der Modus wird von Paket-Sniffern und Netzwerk-Analysewerkzeugen wie Wireshark und tcpdump (über die Bibliothek libpcap) genutzt, ferner von virtuellen Maschinen und Bridges, die Verkehr für mehrere Gastsysteme entgegennehmen müssen, sowie von Intrusion-Detection-Systemen. Da der Modus auch zum unbemerkten Abhören von Netzwerkverkehr missbraucht werden kann, ist seine Aktivierung ein mögliches Indiz bei Sicherheitsaudits; unter vielen Betriebssystemen sind dafür Administratorrechte nötig.
