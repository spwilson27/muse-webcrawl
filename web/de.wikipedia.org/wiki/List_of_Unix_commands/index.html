Liste von Unix-Befehlen

Diese Liste enthält wichtige Befehle (Kommandos) von Unix- und Unix-ähnlichen Betriebssystemen wie Linux und macOS, die typischerweise in einer Shell auf der Kommandozeile verwendet werden. Viele der Befehle sind im POSIX-Standard bzw. in den GNU Core Utilities definiert.

Dateien und Verzeichnisse

BefehlBeschreibung
lsVerzeichnisinhalt auflisten
cdVerzeichnis wechseln
pwdAktuelles Arbeitsverzeichnis anzeigen
cpDateien und Verzeichnisse kopieren
mvDateien verschieben oder umbenennen
rmDateien oder Verzeichnisse löschen
mkdir / rmdirVerzeichnis erstellen / leeres Verzeichnis löschen
touchLeere Datei anlegen oder Zeitstempel ändern
findDateien in Verzeichnisbäumen suchen
lnVerknüpfungen (Links) erstellen
chmod / chownZugriffsrechte / Eigentümer ändern
du / dfSpeicherplatzbelegung anzeigen
fileDateityp bestimmen
tarArchive erstellen und entpacken

BefehlBeschreibung

grepText nach Mustern durchsuchen
sedStream-Editor zur Texttransformation
awkMustererkennung und Textverarbeitung
sort / uniqZeilen sortieren / Duplikate entfernen
wcZeilen, Wörter und Bytes zählen
diffUnterschiede zwischen Dateien anzeigen
echoText ausgeben
