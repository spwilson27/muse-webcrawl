Cartan-Matrix

Eine Cartan-Matrix ist in der Mathematik eine quadratische Matrix mit ganzzahligen Einträgen, die in der Theorie der Lie-Algebren und der Darstellungstheorie eine zentrale Rolle spielt. Sie ist nach dem französischen Mathematiker Élie Cartan benannt.

Definition

Eine verallgemeinerte Cartan-Matrix ist eine Matrix A = (aij) mit folgenden Eigenschaften:

  • aii = 2 für alle i,
  • aij ≤ 0 für i ≠ j,
  • aij = 0 genau dann, wenn aji = 0.

Eine Cartan-Matrix im engeren Sinne ist eine verallgemeinerte Cartan-Matrix, die zusätzlich positiv definit ist. Solche Matrizen klassifizieren die endlichdimensionalen halbeinfachen Lie-Algebren.

Beispiele

Zur Lie-Algebra sl2 gehört die 1×1-Matrix (2). Zur Algebra sl3 gehört die Matrix mit den Einträgen 2 auf der Diagonalen und −1 auf den Nebendiagonalpositionen (1,2) und (2,1).

Zusammenhang mit Dynkin-Diagrammen

Jeder symmetrisierbaren Cartan-Matrix lässt sich ein Dynkin-Diagramm zuordnen, dessen Knoten den einfachen Wurzeln entsprechen. Die Klassifikation der Cartan-Matrizen endlichen Typs entspricht genau der Klassifikation der zusammenhängenden Dynkin-Diagramme der Typen A, B, C, D, E, F und G.

Bedeutung

Cartan-Matrizen treten auch in der Theorie der Kac-Moody-Algebren auf, wo die positiv definite Bedingung zu positiv semidefinit (affiner Typ) beziehungsweise indefinit abgeschwächt wird.
