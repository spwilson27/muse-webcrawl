Plattformübergreifende Software

Plattformübergreifende Software (englisch cross-platform software) ist Software, die auf mehreren Betriebssystemen oder Rechnerarchitekturen läuft, ohne dass für jede Plattform eine grundlegend eigene Version entwickelt werden muss. Bekannte Beispiele sind die Browser Firefox und Chrome, der Editor Visual Studio Code, die Office-Suite LibreOffice und viele Computerspiele.

Verfahren

  • Interpretierte und virtuelle Sprachen: Programme in Sprachen wie Java („write once, run anywhere“) oder Python laufen auf einer Laufzeitumgebung, die systemspezifische Unterschiede abfängt.
  • Portierbarer Quellcode: In C oder C++ geschriebene Software wird für jede Zielplattform neu kompiliert; Abstraktionsschichten und Frameworks wie Qt vereinheitlichen etwa die grafische Oberfläche.
  • Webanwendungen: Sie laufen im Browser und sind damit weitgehend plattformunabhängig.
  • Cross-Plattform-Frameworks: Werkzeuge wie Electron, React Native oder Flutter erzeugen aus einer Codebasis Anwendungen für Desktop- beziehungsweise Mobilplattformen.
  • Emulation und Kompatibilitätsschichten: Fremde Programme werden in einer nachgebildeten Umgebung ausgeführt (z. B. Wine).

Vor- und Nachteile

Plattformübergreifende Entwicklung senkt Entwicklungs- und Wartungskosten und vergrößert den erreichbaren Nutzerkreis. Nachteilig können geringere Leistung, größerer Speicherverbrauch und eine Oberfläche sein, die sich auf keinem System völlig „nativ“ anfühlt. Zudem müssen Eigenheiten aller Zielsysteme getestet werden. Für Entwickler steht dem gegenüber die native Entwicklung, die pro Plattform eigenen Code erfordert, aber die jeweiligen Konventionen und Funktionen am besten ausnutzt.

Bedeutung

Mit der Verbreitung mehrerer Desktop- und Mobilsysteme ist plattformübergreifende Verfügbarkeit für viele Anwendungen zum Standard geworden. Auch in der Spieleentwicklung kommen Engines wie Unity oder die Unreal Engine zum Einsatz, die Exporte für zahlreiche Plattformen aus einem Projekt erlauben.
