Robinson-Anellierung

Die Robinson-Anellierung (englisch Robinson annulation) ist eine Namensreaktion der organischen Chemie zum Aufbau sechsgliedriger Ringe, typischerweise von Cyclohexenonen. Sie wurde 1935 von Robert Robinson beschrieben und ist eine Standardmethode zur Synthese polycyclischer Verbindungen, etwa von Steroiden.

Mechanismus

Die Reaktion besteht aus zwei Schritten: Zunächst erfolgt eine Michael-Addition eines Keton-Enolats an ein α,β-ungesättigtes Keton, meist Methylvinylketon, wodurch ein 1,5-Diketon entsteht. Im zweiten Schritt schließt eine intramolekulare Aldolreaktion den neuen Ring, und unter Wasserabspaltung entsteht ein α,β-ungesättigtes Cyclohexenon.

Anwendung

Die Robinson-Anellierung ist ein klassisches Instrument der Totalsynthese. Berühmte Anwendungen finden sich in der Synthese von Steroiden und Terpenen; das dabei häufig entstehende Zwischenprodukt, das Wieland-Miescher-Keton, ist ein wichtiger Baustein der Steroidchemie. Es existieren zahlreiche Varianten, darunter asymmetrische, organokatalytische Versionen.
