Quadratischer Zahlkörper

Ein quadratischer Zahlkörper (englisch quadratic field) ist in der algebraischen Zahlentheorie eine Körpererweiterung der rationalen Zahlen vom Grad 2. Jeder quadratische Zahlkörper hat die Form ℚ(√d), wobei d eine quadratfreie ganze Zahl ungleich 0 und 1 ist.

Einteilung

Für d > 0 spricht man von einem reell-quadratischen Zahlkörper, für d < 0 von einem imaginär-quadratischen Zahlkörper. Bekannte Beispiele sind ℚ(√5), der eng mit dem Goldenen Schnitt verbunden ist, und die Gaußschen Zahlen ℚ(i), die für d = −1 entstehen.

Ganzheitsring

Der Ring der ganzen Zahlen eines quadratischen Zahlkörpers hängt davon ab, ob d ≡ 1 (mod 4) ist. Er wird im ersten Fall von (1 + √d)/2, sonst von √d erzeugt. Ob in diesem Ring eine eindeutige Primfaktorzerlegung gilt, ist eine zentrale Frage der Zahlentheorie; für imaginär-quadratische Körper ist dies nur für neun sogenannte Heegner-Zahlen der Fall. Die Klassenzahl misst, wie weit der Ganzheitsring von eindeutiger Faktorisierung entfernt ist.
