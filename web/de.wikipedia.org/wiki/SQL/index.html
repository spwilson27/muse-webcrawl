SQL

SQL (Structured Query Language) ist eine Datenbanksprache zur Definition von Datenstrukturen in relationalen Datenbanken sowie zum Bearbeiten und Abfragen von Datenbeständen. Sie ist von ANSI und ISO standardisiert und wird von nahezu allen verbreiteten relationalen Datenbanksystemen unterstützt.

Geschichte

SQL geht auf die 1970er-Jahre zurück: Donald D. Chamberlin und Raymond F. Boyce entwickelten bei IBM die Sprache SEQUEL für das System R. 1986 wurde SQL zum ANSI-Standard, 1987 zum ISO-Standard. Der Standard wurde mehrfach erweitert, unter anderem durch SQL:1999, SQL:2003 und SQL:2016.

Sprachumfang

SQL umfasst Befehle zur Datenabfrage (SELECT), zum Einfügen, Ändern und Löschen von Daten (INSERT, UPDATE, DELETE) sowie zur Definition des Datenbankschemas (CREATE, ALTER, DROP). Beispiel:

SELECT Name, Alter FROM Personen WHERE Alter >= 18 ORDER BY Name;

Dialekte

Die Hersteller erweitern den Standard in eigenen Dialekten, etwa PL/SQL (Oracle), T-SQL (Microsoft) oder PL/pgSQL (PostgreSQL).
