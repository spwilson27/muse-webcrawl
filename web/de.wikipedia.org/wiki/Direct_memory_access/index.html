Direct Memory Access

Direct Memory Access (DMA, deutsch „direkter Speicherzugriff“) ist ein Verfahren der Computertechnik, bei dem ein Peripheriegerät oder ein spezieller DMA-Controller Daten direkt mit dem Arbeitsspeicher austauschen kann, ohne dass die CPU jeden einzelnen Transfer ausführen muss. Die CPU stößt den Transfer nur an und wird nach dessen Abschluss – etwa per Interrupt – benachrichtigt.

Funktionsweise

Zum Start eines DMA-Transfers programmiert die CPU den DMA-Controller mit Quell- und Zieladresse, Transferlänge und Richtung. Der Controller übernimmt daraufhin die Bussteuerung und überträgt die Daten, während die CPU andere Aufgaben ausführen kann. Nach Abschluss meldet der Controller die Beendigung. Für die Kohärenz mit CPU-Caches sorgen je nach Architektur Hardwaremechanismen oder Software.

Bedeutung

Ohne DMA müsste die CPU jedes Datenwort einzeln bewegen (Programmed Input/Output, PIO), was insbesondere bei schnellen Geräten wie Festplatten, SSDs, Netzwerkkarten und Grafikkarten unverhältnismäßig viel Rechenzeit binden würde. DMA ist daher ein Grundprinzip praktisch aller modernen Computersysteme. Historisch gab es im PC-Bereich fest verdrahtete ISA-DMA-Kanäle; moderne Busse wie PCI Express realisieren DMA über Bus-Mastering der Geräte selbst.

Varianten

  • Scatter-Gather-DMA: Ein einziger Transferauftrag verarbeitet mehrere verstreute Speicherbereiche.
  • Remote DMA (RDMA): Direkter Speicherzugriff über ein Netzwerk auf den Speicher eines anderen Rechners, wichtig im Hochleistungsrechnen.
