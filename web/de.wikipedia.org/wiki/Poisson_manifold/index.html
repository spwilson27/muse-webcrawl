Poisson-Mannigfaltigkeit

Eine Poisson-Mannigfaltigkeit ist in der Differentialgeometrie eine glatte Mannigfaltigkeit, die mit einer Poisson-Klammer auf dem Ring ihrer glatten Funktionen ausgestattet ist. Poisson-Mannigfaltigkeiten bilden den natürlichen Rahmen der hamiltonschen Mechanik und verallgemeinern den Begriff der symplektischen Mannigfaltigkeit.

Definition

Eine Poisson-Struktur auf einer glatten Mannigfaltigkeit M ist eine bilineare Abbildung {·, ·} auf der Algebra der glatten reellwertigen Funktionen, die eine Lie-Klammer definiert und die Leibniz-Regel erfüllt: {fg, h} = f{g, h} + g{f, h}. Äquivalent dazu kann die Struktur durch einen Bivektor angegeben werden, der die Schouten-Nijenhuis-Klammer-Bedingung erfüllt.

Beispiele

  • Jede symplektische Mannigfaltigkeit ist eine Poisson-Mannigfaltigkeit, wobei die Poisson-Klammer aus der Umkehrung der symplektischen Form entsteht.
  • Der duale Raum einer Lie-Algebra trägt eine kanonische lineare Poisson-Struktur (Lie-Poisson-Struktur).
  • Die triviale Poisson-Struktur mit Klammer null existiert auf jeder Mannigfaltigkeit.

Symplektische Blätter

Jede Poisson-Mannigfaltigkeit zerfällt in symplektische Blätter: Die zu den hamiltonschen Vektorfeldern gehörenden Blätter tragen eine natürliche symplektische Struktur, und die Poisson-Klammer wird durch diese Blattstruktur bestimmt.

Bedeutung

Poisson-Mannigfaltigkeiten spielen eine zentrale Rolle in der mathematischen Physik, insbesondere in der klassischen Mechanik, der Deformationsquantisierung und der Theorie integrabler Systeme.
