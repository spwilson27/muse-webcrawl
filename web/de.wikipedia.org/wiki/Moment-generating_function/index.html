Momenterzeugende Funktion

Die momenterzeugende Funktion einer reellen Zufallsvariable X ist definiert als MX(t) = E[etX], sofern dieser Erwartungswert in einem Intervall um t = 0 existiert.

Eigenschaften

Die Ableitungen der momenterzeugenden Funktion an der Stelle 0 liefern die Momente der Verteilung: M′(0) = E[X], M″(0) = E[X²]. Existiert die Funktion in einer Umgebung von 0, bestimmt sie die Verteilung eindeutig.
