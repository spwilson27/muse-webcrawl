Erweiterte Backus-Naur-Form

Die erweiterte Backus-Naur-Form (englisch Extended Backus–Naur Form, kurz EBNF) ist eine Notation zur Beschreibung der Syntax von Sprachen mit Hilfe kontextfreier Grammatiken. Sie entstand aus der Backus-Naur-Form und ergänzt diese um Wiederholungs- und Optionsoperatoren, so dass Grammatiken kürzer und besser lesbar werden.

Grundbegriffe

Eine EBNF-Grammatik besteht aus Produktionsregeln, deren linke Seite ein Nichtterminalsymbol und deren rechte Seite eine Folge von Terminalen und Nichtterminalen ist. Die wichtigsten Konstrukte sind:

  • Verkettung von Symbolen nacheinander,
  • Alternative, geschrieben mit |,
  • Option in eckigen Klammern [ ... ],
  • Wiederholung (null- bis mehrmals) in geschweiften Klammern { ... },
  • Gruppierung in runden Klammern ( ... ).
Ausdruck = Term , { ( "+" | "-" ) , Term } ;
Term = Faktor , { ( "*" | "/" ) , Faktor } ;

Bedeutung

Die EBNF ist in der Norm ISO/IEC 14977:1996 standardisiert. Sie wird zur Definition von Programmiersprachen, Protokollen und Dateiformaten eingesetzt und ist Grundlage vieler Parsergeneratoren. Jede EBNF-Grammatik lässt sich in eine äquivalente reine BNF-Grammatik überführen; die Erweiterung dient allein der Übersichtlichkeit.
