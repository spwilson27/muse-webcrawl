OpenTelemetry

Erstveröffentlichung2019
TrägerCloud Native Computing Foundation
LizenzApache-Lizenz 2.0
ArtObservability-Framework

OpenTelemetry ist ein offenes Framework zur Erzeugung, Erfassung und Übertragung von Telemetriedaten wie Traces, Metriken und Logs aus Softwareanwendungen. Es entstand 2019 durch die Zusammenführung der Projekte OpenTracing und OpenCensus und wird von der Cloud Native Computing Foundation (CNCF) betreut. Ziel ist ein herstellerneutraler Standard für die Beobachtbarkeit (Observability) verteilter Systeme, der die früher üblichen proprietären Instrumentierungen ersetzt.

Bestandteile

OpenTelemetry besteht aus einer sprachübergreifenden Spezifikation, Programmierschnittstellen und SDKs für zahlreiche Sprachen – darunter Java, Go, Python, .NET und JavaScript – sowie aus dem OpenTelemetry Collector, einer Komponente zum Empfangen, Verarbeiten und Weiterleiten von Telemetriedaten an Analyse-Systeme wie Jaeger, Prometheus oder kommerzielle APM-Plattformen. Für die Übertragung definiert das Projekt das eigene Protokoll OTLP.

Viele Bibliotheken und Frameworks werden automatisch instrumentiert, sodass Entwickler ohne eigenen Code Spans und Metriken erhalten. Semantische Konventionen legen einheitliche Namen für Attribute fest, beispielsweise für HTTP-Anfragen und Datenbankzugriffe.

Verbreitung

OpenTelemetry entwickelte sich rasch zu einem der aktivsten CNCF-Projekte und gilt als De-facto-Standard für die Instrumentierung Cloud-nativer Anwendungen. Große Cloud- und Monitoring-Anbieter unterstützen das Format nativ; auch in Kubernetes-Umgebungen ist es weit verbreitet.
