Partition (Mengenlehre)

Eine Partition einer Menge X ist in der Mengenlehre eine Zerlegung von X in paarweise disjunkte, nichtleere Teilmengen, deren Vereinigung ganz X ergibt. Die Teilmengen heißen die Blöcke oder Zellen der Partition.

Definition

Eine Menge P von Teilmengen einer Menge X ist eine Partition von X, wenn gilt:

  • Kein Block ist leer.
  • Je zwei verschiedene Blöcke sind disjunkt.
  • Die Vereinigung aller Blöcke ist X.

Zusammenhang mit Äquivalenzrelationen

Partitionen entsprechen genau den Äquivalenzrelationen auf X: Die Äquivalenzklassen einer Äquivalenzrelation bilden eine Partition, und umgekehrt definiert jede Partition eine Äquivalenzrelation („liegt im selben Block").

Anzahl der Partitionen

Die Anzahl der Partitionen einer endlichen Menge mit n Elementen ist die n-te Bell-Zahl Bn. Die ersten Bell-Zahlen sind 1, 1, 2, 5, 15, 52, 203, …. Die feinste Partition besteht aus allen einelementigen Teilmengen, die gröbste aus dem einzigen Block X selbst.

Verband der Partitionen

Die Partitionen einer Menge bilden mit der Verfeinerungsrelation einen vollständigen Verband, der in Kombinatorik und Statistik eine wichtige Rolle spielt.
