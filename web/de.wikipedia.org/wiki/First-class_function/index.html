First-Class Function

Eine First-Class Function (deutsch etwa „Funktion erster Klasse“) ist ein Konzept der Informatik: Eine Programmiersprache behandelt Funktionen als First-Class Citizen, wenn Funktionen wie gewöhnliche Werte verwendet werden können. Das heißt, sie können als Argumente an andere Funktionen übergeben, als Rückgabewerte zurückgegeben und Variablen zugewiesen werden.

Eigenschaften

Zu den typischen Eigenschaften gehören die Unterstützung von Funktionen höherer Ordnung (Higher-Order Functions), anonymen Funktionen (Lambda-Ausdrücken) und Closures, bei denen eine Funktion Zugriff auf Variablen ihres Entstehungs-Kontextes behält. Sprachen mit First-Class Functions sind unter anderem Lisp, JavaScript, Haskell, Python, Ruby und Scala; auch moderne Versionen von C++, Java und C# unterstützen das Konzept über Funktionszeiger, Lambda-Ausdrücke oder Delegates.

Beispiel

In JavaScript kann eine Funktion einer Variable zugewiesen und als Argument übergeben werden:

const verdoppeln = x => x * 2;
[1, 2, 3].map(verdoppeln); // [2, 4, 6]

Hier wird die Funktion verdoppeln als Wert an die Higher-Order Function map übergeben.

Bedeutung

First-Class Functions sind ein Grundpfeiler der funktionalen Programmierung. Sie ermöglichen deklarative Programmierstile, die Wiederverwendung von Kontrollstrukturen und Konzepte wie Currying und partielle Applikation. Der Begriff geht auf den britischen Informatiker Christopher Strachey zurück, der in den 1960er Jahren die Unterscheidung zwischen „first-class“ und „second-class“ Objekten in Programmiersprachen prägte.
