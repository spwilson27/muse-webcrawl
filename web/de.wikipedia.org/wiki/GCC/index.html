GCC

Die GNU Compiler Collection (GCC) ist eine Sammlung von Compilern für verschiedene Programmiersprachen, die als freie Software vom GNU-Projekt entwickelt wird. Sie gilt als Standardcompiler für viele Unix-ähnliche Betriebssysteme, insbesondere für Linux.

GNU Compiler Collection
Erstveröffentlichung: 1987
Entwickler: GNU-Projekt
Programmiersprache: C, C++
Lizenz: GPL

Geschichte

GCC wurde ursprünglich 1987 von Richard Stallman als Compiler für die Sprache C veröffentlicht und hieß damals GNU C Compiler. Bald kamen Frontends für weitere Sprachen hinzu, darunter C++, Fortran, Ada, Go und D. Der Name wurde daraufhin in GNU Compiler Collection geändert.

Aufbau

GCC arbeitet in mehreren Stufen: Ein sprachspezifisches Frontend übersetzt den Quelltext in eine Zwischendarstellung (GIMPLE), die von sprach- und maschinenunabhängigen Optimierern verarbeitet wird. Anschließend erzeugt ein Backend Maschinencode für zahlreiche Zielarchitekturen wie x86, ARM, RISC-V und PowerPC.

Bedeutung

Der GCC wird zur Übersetzung des Linux-Kernels, großer Teile der GNU-Software und vieler weiterer Projekte verwendet. Die jährlichen Hauptversionen bringen neue Optimierungen, Sprachstandards (etwa C++20 und C23) und Unterstützung neuer Prozessoren.
