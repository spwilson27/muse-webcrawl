Pacman (Paketverwaltung)

Pacman (kurz für package manager) ist die Paketverwaltung der Linux-Distribution Arch Linux und ihrer Derivate wie Manjaro. Pacman installiert, aktualisiert und entfernt Softwarepakete und löst dabei Abhängigkeiten automatisch auf.

Merkmale

Pacman arbeitet mit komprimierten Paketarchiven (Dateiendung .pkg.tar.zst, früher .pkg.tar.xz) und synchronisiert lokale Paketdatenbanken mit den Paketquellen (Repositories) der Distribution. Die Bedienung erfolgt über die Kommandozeile mit kurzen Optionskürzeln, etwa pacman -Syu für eine vollständige Systemaktualisierung. Die Konfiguration steht in der Datei /etc/pacman.conf.

Geschichte

Pacman wurde von Judd Vinet, dem Gründer von Arch Linux, in C geschrieben und 2002 mit der ersten Arch-Version veröffentlicht. Pakete werden mit Bauanleitungen (PKGBUILD-Skripten) durch das Werkzeug makepkg erstellt; inoffizielle Pakete aus dem Arch User Repository (AUR) werden mit sogenannten AUR-Helpern eingebunden.
