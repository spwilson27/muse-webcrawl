Wahrscheinlichkeitsdichtefunktion

Eine Wahrscheinlichkeitsdichtefunktion, kurz Dichtefunktion oder einfach Dichte (englisch probability density function, pdf), ist eine mathematische Funktion, die zur Beschreibung stetiger Wahrscheinlichkeitsverteilungen verwendet wird. Die Wahrscheinlichkeit, dass eine stetige Zufallsvariable einen Wert in einem Intervall annimmt, ergibt sich als Integral der Dichte über dieses Intervall, also als Fläche unter der Dichtekurve.

Definition

Eine integrierbare Funktion f : ℝ → ℝ heißt Wahrscheinlichkeitsdichte, wenn sie nichtnegativ ist und das Integral über die gesamte reelle Achse den Wert 1 hat. Eine Zufallsvariable X besitzt die Dichte f, wenn für alle a ≤ b gilt:

P(a ≤ X ≤ b) = ∫ab f(x) dx.

Eigenschaften

  • Die Verteilungsfunktion ist das Integral der Dichte: F(x) = ∫−∞x f(t) dt.
  • An jeder Stetigkeitsstelle ist die Dichte die Ableitung der Verteilungsfunktion.
  • Für einzelne Punkte gilt P(X = x) = 0; Dichtewerte selbst sind keine Wahrscheinlichkeiten und können größer als 1 sein.
  • Der Erwartungswert berechnet sich als E(X) = ∫ x f(x) dx.

Beispiele

  • Gleichverteilung auf [a, b]: konstante Dichte 1/(b − a)
  • Normalverteilung: f(x) = (1/(σ√(2π))) e−(x−μ)²/(2σ²)
  • Exponentialverteilung: f(x) = λ e−λx für x ≥ 0
