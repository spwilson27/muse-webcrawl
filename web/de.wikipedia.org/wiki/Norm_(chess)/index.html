Norm (Schach)

Eine Norm ist im Schach eine Leistung in einem Turnier, die für den Erhalt eines Titels der FIDE, etwa Internationaler Meister oder Großmeister, erforderlich ist. Ein Spieler muss in der Regel mehrere Normen erzielen und eine bestimmte Elo-Zahl erreichen, um einen Titel verliehen zu bekommen.

Bedingungen

Für eine Großmeister-Norm muss ein Spieler in einem Turnier eine festgelegte Turnierleistung (Performance) gegen ein Feld ausreichender Stärke erreichen. Zu den Anforderungen zählen unter anderem:

  • Eine Mindestanzahl von Partien (in der Regel neun)
  • Ein Mindestanteil an Gegnern mit Titeln und aus anderen Föderationen
  • Eine Performance von mindestens 2600 für die Großmeister-Norm bzw. 2450 für die Norm zum Internationalen Meister

Titelvergabe

Für den Großmeistertitel werden drei Normen (mit Ausnahmen) sowie eine einmal erreichte Elo-Zahl von 2500 benötigt, für den Titel Internationaler Meister drei Normen und eine Elo-Zahl von 2400. Analoge Normsysteme gibt es für die Frauentitel WGM und WIM.
