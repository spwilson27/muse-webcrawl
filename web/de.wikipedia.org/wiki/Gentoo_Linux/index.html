Gentoo Linux

Gentoo Linux ist eine quellbasierte Linux-Distribution, die sich an erfahrene Anwender richtet. Nahezu die gesamte Software wird mit dem Paketverwaltungssystem Portage aus dem Quellcode direkt auf dem Zielrechner kompiliert und kann so gezielt an die vorhandene Hardware und die eigenen Wünsche angepasst werden. Benannt ist die Distribution nach dem Eselspinguin (englisch gentoo penguin), der als besonders schneller Schwimmer gilt.

Geschichte

Gentoo geht auf die 1999 von Daniel Robbins begonnene Distribution Enoch Linux zurück. Die erste Version unter dem Namen Gentoo Linux erschien 2002. Robbins verließ das Projekt 2004; seither wird es von der Gentoo Foundation und einem gewählten Rat (Gentoo Council) geleitet. Das auf Portage basierende Google-Betriebssystem Chrome OS verwendete anfangs Gentoo-Werkzeuge.

Portage und USE-Flags

Herzstück ist das in Python geschriebene Portage-System mit dem Befehl emerge. Paketrezepte („ebuilds") beschreiben, wie eine Software heruntergeladen, kompiliert und installiert wird. Über sogenannte USE-Flags kann der Anwender festlegen, welche Funktionen eines Programms mitübersetzt werden – etwa Unterstützung für bestimmte Sound-Systeme, Dokumentationsformate oder grafische Oberflächen. Globale Kompilieroptionen (CFLAGS) erlauben Optimierungen für den jeweiligen Prozessor.

Eigenschaften

Gentoo folgt einem Rolling-Release-Modell ohne feste Versionsveröffentlichungen. Unterstützt werden zahlreiche Architekturen, darunter x86, AMD64, ARM, PowerPC, SPARC und RISC-V. Die Installation erfolgt traditionell von einer Minimalumgebung aus von Hand und ist im umfangreichen Gentoo Handbook dokumentiert. Der hohe Konfigurationsaufwand gilt zugleich als Lernweg, weshalb die Distribution den Ruf hat, ihre Nutzer tief in den Aufbau eines Linux-Systems einzuführen.
