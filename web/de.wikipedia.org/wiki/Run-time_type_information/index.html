Laufzeit-Typinformation

Laufzeit-Typinformation (englisch run-time type information, kurz RTTI) bezeichnet in der Programmierung die Möglichkeit, den Datentyp eines Objekts während der Ausführung eines Programms zu ermitteln und zu nutzen. Bekannt ist der Mechanismus vor allem aus der Programmiersprache C++.

RTTI in C++

C++ stellt zwei zentrale RTTI-Werkzeuge bereit:

  • den Operator dynamic_cast, der eine sichere Typumwandlung innerhalb einer Klassenhierarchie zur Laufzeit durchführt und bei Misserfolg einen Nullzeiger bzw. eine Ausnahme vom Typ std::bad_cast liefert,
  • den Operator typeid, der ein Objekt der Klasse std::type_info zurückgibt, mit dem sich der tatsächliche Typ eines Ausdrucks bestimmen lässt.

RTTI steht in C++ nur für polymorphe Klassen zur Verfügung, also Klassen mit mindestens einer virtuellen Funktion. Implementiert wird sie üblicherweise über die virtuelle Funktionstabelle (vtable), die auf die Typinformationen zeigt.

Verwendung und Kritik

RTTI wird unter anderem für das sichere Herunterkonvertieren (Downcasting) in Klassenhierarchien, für Diagnose- und Serialisierungszwecke sowie in Frameworks genutzt. Kritiker weisen darauf hin, dass exzessive Typabfragen zur Laufzeit ein Hinweis auf Schwächen im Entwurf sein können, da polymorphe Aufrufe oder das Visitor-Muster das Problem oft eleganter lösen. In vielen anderen Sprachen wie Java oder C# ist Laufzeit-Typinformation in Form von Reflection noch deutlich weiter ausgebaut.
