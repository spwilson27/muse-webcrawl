Numbers Game

Das Numbers Game (auch „Policy Game“) war eine illegale Lotterie, die im 19. und 20. Jahrhundert in ärmeren Stadtvierteln der Vereinigten Staaten weit verbreitet war. Spieler setzten kleine Beträge auf eine dreistellige Zahl.

Ablauf

Die Gewinnzahl wurde aus öffentlich nachprüfbaren Zahlen abgeleitet, etwa aus Börsenkursen oder Rennergebnissen, damit kein Verdacht der Manipulation entstand. Annahmestellen („number runners“) sammelten die Einsätze ein; Organisatoren behielten einen erheblichen Anteil als Gewinnspanne.

Geschichte

Besonders verbreitet war das Spiel in Harlem und anderen afroamerikanischen Gemeinden, wo es zugleich eine informelle Wirtschaftsstruktur bildete. Mit der Einführung staatlicher Lotterien im 20. Jahrhundert verlor es an Bedeutung.
