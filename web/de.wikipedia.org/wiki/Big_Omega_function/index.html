Anzahl der Primfaktoren (Ω-Funktion)

Die zahlentheoretische Funktion Ω(n) (großes Omega) gibt die Anzahl der Primfaktoren einer natürlichen Zahl n mit Vielfachheit an. Ist n = ∏ pαp die Primfaktorzerlegung von n, so gilt Ω(n) = Σ αp. Im Englischen wird die Funktion als prime omega function oder big Omega function bezeichnet.

Beispiele

  • Ω(1) = 0, da 1 keine Primfaktoren hat.
  • Ω(12) = 3, denn 12 = 2² · 3 hat die Primfaktoren 2, 2 und 3.
  • Ω(16) = 4, denn 16 = 2⁴.
  • Für eine Primzahl p gilt Ω(p) = 1.

Eigenschaften

Ω ist eine vollständig additive zahlentheoretische Funktion: Für alle m, n gilt Ω(m · n) = Ω(m) + Ω(n). Damit unterscheidet sie sich von der Funktion ω(n), die nur die Anzahl der verschiedenen Primfaktoren zählt und lediglich additiv ist.

Der Mittelwert von Ω(n) wächst wie log log n. Genauer besagt ein klassisches Resultat der probabilistischen Zahlentheorie, dass die summatorische Funktion von Ω asymptotisch n log log n + (M − 1 + γ) n beträgt, wobei γ die Euler-Mascheroni-Konstante und M die Meissel-Mertens-Konstante bezeichnet. Nach dem Satz von Erdős–Kac ist die Verteilung von Ω(n) für große n annähernd normalverteilt.

Zusammenhänge

Eng mit Ω verknüpft ist die Liouville-Funktion: λ(n) = (−1)Ω(n). Zahlen mit Ω(n) = k werden auch als „fast prim“ bezeichnet; für k = 2 spricht man von Semiprimzahlen, für k = 1 genau von den Primzahlen.
