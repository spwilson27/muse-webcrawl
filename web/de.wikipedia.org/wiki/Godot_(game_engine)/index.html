Godot (Spiel-Engine)

Godot ist eine freie und quelloffene, plattformübergreifende Spiel-Engine unter der MIT-Lizenz. Sie wurde von den argentinischen Entwicklern Juan Linietsky und Ariel Manzur entworfen und 2014 erstmals öffentlich veröffentlicht. Der Name verweist auf Samuel Becketts Stück „Warten auf Godot“.

Eigenschaften

Godot ermöglicht die Entwicklung von 2D- und 3D-Spielen für Windows, macOS, Linux, Android, iOS, Konsolen sowie das Web. Das zentrale Konzept ist der Szenenbaum: Spiele setzen sich aus Knoten (Nodes) zusammen, die zu Szenen gebündelt und vielfach wiederverwendet werden können.

Programmierung

Haus eigene Skriptsprache ist das an Python angelehnte GDScript. Offiziell unterstützt werden außerdem C#, C und C++; über GDExtension lassen sich weitere Sprachen anbinden. Für Anfänger steht zudem ein System visueller Programmierung bzw. Blockskripte bereit.

Entwicklung

Version 4.0 erschien im März 2023 mit einer vollständig erneuerten Rendering-Architektur (Vulkan), überarbeitetem Editor und zahlreichen Verbesserungen. Gepflegt wird das Projekt von der Godot Foundation; die Engine gewann insbesondere nach den Lizenzänderungen kommerzieller Konkurrenten viele neue Nutzer, darunter auch professionelle Studios.
