DLL Hell

Als DLL Hell (deutsch etwa „DLL-Hölle") bezeichnet man Probleme, die unter Microsoft Windows auftreten, wenn mehrere Anwendungen gemeinsam genutzte Programmbibliotheken (Dynamic Link Libraries, DLLs) in inkompatiblen Versionen installieren oder erwarten.

Ursachen

Installiert ein Programm eine neuere oder ältere Version einer System-DLL und überschreibt dabei die vorhandene Datei, können andere Programme, die auf die ursprüngliche Version angewiesen sind, fehlerhaft arbeiten oder abstürzen. Da Windows lange keine wirksame Versionsverwaltung für gemeinsam genutzte Bibliotheken besaß und Installationsprogramme Änderungen nicht zuverlässig rückgängig machten, war dieses Problem in den 1990er Jahren weit verbreitet.

Gegenmaßnahmen

Microsoft begegnete dem Problem unter anderem mit der Windows-Dateischutzfunktion (Windows File Protection), die wichtige Systemdateien überwacht, sowie mit der Möglichkeit, DLLs im Programmverzeichnis lokal zu installieren („private DLLs"). Mit dem .NET Framework und dessen Global Assembly Cache sowie starken Namen (Strong Names) können mehrere Versionen einer Bibliothek parallel existieren (Side-by-Side). Auch moderne Konzepte wie Container und die Bündelung aller Abhängigkeiten in einer Anwendung vermeiden die DLL Hell.
