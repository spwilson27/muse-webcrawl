Referenz (Programmierung)

Eine Referenz ist in der Programmierung ein Wert, der den Zugriff auf Daten an einem anderen Speicherort ermöglicht — ein Verweis auf ein Objekt oder eine Variable. Referenzen sind das Gegenstück zur direkten Arbeit mit Kopien von Werten (Wertsemantik) und Grundlage dafür, dass mehrere Programmteile auf dieselben Daten zugreifen und sie verändern können.

Erscheinungsformen

  • Zeiger (Pointer) in Sprachen wie C und C++: enthalten Speicheradressen und erlauben explizite Adressarithmetik.
  • Referenztypen in Sprachen wie C++ (echte Referenzen als Alias) oder Java und C#, in denen Objekte grundsätzlich über Referenzen angesprochen werden.
  • Null-Referenzen: verweisen auf kein Objekt; ihre Dereferenzierung ist ein klassischer Laufzeitfehler, von Tony Hoare rückblickend als „Milliarden-Dollar-Fehler" bezeichnet.

Referenzzählung und Speicherverwaltung

Referenzen stehen im Zentrum der Speicherverwaltung: Bei der Referenzzählung wird für jedes Objekt mitgezählt, wie viele Verweise existieren; sinkt der Zähler auf null, kann der Speicher freigegeben werden. Alternativ ermitteln Garbage Collectoren nicht mehr erreichbare Objekte, indem sie die Referenzgraphen durchlaufen.

Parameterübergabe

Bei der Übergabe als Referenz („call by reference") arbeitet eine Funktion direkt mit der Variablen des Aufrufers, während bei der Wertübergabe eine Kopie erstellt wird.
