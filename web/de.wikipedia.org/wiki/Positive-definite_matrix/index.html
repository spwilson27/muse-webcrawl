Positive-definite Matrix

Eine positive-definite Matrix ist eine symmetrische (im komplexen Fall hermitesche) Matrix, deren zugehörige quadratische Form für jeden von Null verschiedenen Vektor einen positiven Wert ergibt. Sie ist ein zentraler Begriff der linearen Algebra mit zahlreichen Anwendungen.

Definition

Eine reelle symmetrische Matrix A heißt positiv definit, wenn xᵀAx > 0 für alle x ≠ 0 gilt. Gilt stattdessen xᵀAx ≥ 0, so heißt die Matrix positiv semidefinit. Analog definiert man negativ definite und indefinite Matrizen.

Charakterisierungen

  • Alle Eigenwerte einer positiv definiten Matrix sind positiv.
  • Alle Hauptminoren sind positiv (Hurwitz-Kriterium).
  • Es existiert eine Cholesky-Zerlegung A = LLᵀ mit einer unteren Dreiecksmatrix L.
  • Die Matrix definiert über (x, y) ↦ xᵀAy ein Skalarprodukt.

Anwendungen

Positive-definite Matrizen treten als Kovarianzmatrizen in der Statistik, als Hessematrizen bei der Optimierung (hinreichende Bedingung für lokale Minima) sowie als Steifigkeits- und Massenmatrizen in der Mechanik auf. Beim Lösen linearer Gleichungssysteme mit solchen Matrizen ist das Verfahren der konjugierten Gradienten besonders geeignet.
