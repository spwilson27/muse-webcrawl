DirectWrite

DirectWrite ist eine Programmierschnittstelle (API) von Microsoft zur hochwertigen Darstellung von Text unter Windows. Sie wurde zusammen mit Windows 7 und Direct2D eingeführt und ersetzt für moderne Anwendungen die älteren Textfunktionen von GDI und GDI+.

Merkmale

DirectWrite bietet hardwarebeschleunigtes Text-Rendering, Subpixel-Antialiasing mittels ClearType, Unterstützung für OpenType-Typografie (Ligaturen, alternative Glyphen, erweiterte Schriftschnitte) sowie für mehrsprachigen Text einschließlich bidirektionaler Schriften und komplexer Schriftsysteme. Es unterstützt verschiedene Schriftformate wie TrueType, OpenType und PostScript-basierte Fonts und ermöglicht hochwertige typografische Layouts mit Zeilenumbruch, Ausrichtung und Textfluss.

Einsatz

Die API wird von Webbrowsern wie Internet Explorer, Firefox und Chrome (für die Textdarstellung unter Windows), von Office-Anwendungen und zahlreichen weiteren Programmen genutzt. Mit Windows 10 kamen Unterstützung für Farbfonts und verbesserte Fallback-Mechanismen hinzu.
