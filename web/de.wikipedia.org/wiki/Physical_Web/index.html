Physical Web

Das Physical Web war ein von Google initiiertes Open-Source-Konzept, das physische Objekte über Bluetooth-Low-Energy-Beacons mit Webinhalten verknüpfen sollte. Die Beacons senden eine URL aus, die von Smartphones in der Nähe empfangen und im Browser geöffnet werden kann, ohne dass eine spezielle App installiert sein muss.

Funktionsweise

Grundlage war das offene Beacon-Format Eddystone, insbesondere der Nachrichtentyp Eddystone-URL. Objekte wie Automaten, Bushaltestellen oder Ausstellungsstücke konnten so Kontextinformationen, Bezahlseiten oder Fahrpläne bereitstellen. Auf Android wurden die URLs zeitweise über die Funktion „In der Nähe“ (Nearby) beziehungsweise im Chrome-Browser angezeigt.

Einstellung

Google stellte die Benachrichtigungsfunktion wegen zunehmenden Missbrauchs und Spam Ende 2018 für Android ein. Das Konzept gilt als früher Ansatz, das Internet der Dinge mit dem Web zu verbinden, hat sich in der ursprünglichen Form jedoch nicht durchgesetzt.
