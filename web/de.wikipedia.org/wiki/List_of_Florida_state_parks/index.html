Liste der State Parks in Florida

Das Florida State Parks System umfasst mehr als 175 Parks, historische Stätten und Trails mit einer Gesamtfläche von nahezu 800.000 Acres. Es wurde mehrfach als bestes State-Park-System der USA ausgezeichnet. Diese Liste enthält eine Auswahl der bekanntesten State Parks in Florida.

Geschichte

Das Florida Park Service wurde 1935 gegründet; viele der ersten Parks wurden vom Civilian Conservation Corps während der Großen Depression angelegt. Heute verzeichnet das System jährlich über 25 Millionen Besucher.
