Funktion (Mathematik)

In der Mathematik ist eine Funktion (auch Abbildung genannt) eine Beziehung zwischen zwei Mengen, die jedem Element der einen Menge (Definitionsmenge) genau ein Element der anderen Menge (Zielmenge) zuordnet. Funktionen gehören zu den grundlegenden Begriffen der modernen Mathematik und kommen in nahezu allen Teilgebieten vor.

Definition

Eine Funktion f von einer Menge X in eine Menge Y ordnet jedem x ∈ X genau ein Element f(x) ∈ Y zu. Man schreibt f: X → Y. Die Menge der tatsächlich angenommenen Werte heißt Bild oder Wertebereich der Funktion. Die Variable x wird als Argument oder unabhängige Variable, der Wert f(x) als Funktionswert oder abhängige Variable bezeichnet.

Darstellung

Funktionen können auf verschiedene Weise dargestellt werden: durch eine Funktionsgleichung wie f(x) = x², durch eine Wertetabelle, durch ihren Graphen in einem Koordinatensystem oder durch eine verbale Beschreibung. Bei reellen Funktionen ist der Graph die Menge aller Punkte (x, f(x)) der Ebene.

Eigenschaften

Wichtige Eigenschaften von Funktionen sind Injektivität (verschiedene Argumente haben verschiedene Funktionswerte), Surjektivität (jeder Wert der Zielmenge wird angenommen) und Bijektivität (beides zugleich). Weitere Untersuchungsgegenstände sind Monotonie, Stetigkeit, Differenzierbarkeit, Symmetrie sowie Nullstellen und Extremstellen.

Funktionstypen

Zu den elementaren Funktionen zählen Polynomfunktionen, Exponential- und Logarithmusfunktionen, trigonometrische Funktionen sowie gebrochenrationale Funktionen. Aus einfachen Funktionen lassen sich durch Verknüpfung und Verkettung (Komposition) neue Funktionen bilden.
