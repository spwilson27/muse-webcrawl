MP4

MP4 ist ein Containerformat für Multimediainhalte, das als MPEG-4 Part 14 standardisiert ist und üblicherweise die Dateiendung .mp4 trägt. Es basiert auf dem ISO Base Media File Format und ist strukturell mit dem QuickTime-Format von Apple verwandt.

Inhalte

Eine MP4-Datei kann Video-, Audio- und Untertitelspuren sowie Kapitelmarken und Metadaten enthalten. Als Videocodecs kommen typischerweise H.264/MPEG-4 AVC oder H.265/HEVC zum Einsatz, für Audio meist AAC oder MP3. Reine Audiodateien im MP4-Container tragen häufig die Endungen .m4a (Audio) oder .m4p (geschützt), Videos für mobile Geräte auch .m4v.

Verbreitung

MP4 ist das am weitesten verbreitete Format für Webvideos, Streaming und mobile Endgeräte und wird von praktisch allen gängigen Betriebssystemen, Browsern und Abspielgeräten unterstützt.
