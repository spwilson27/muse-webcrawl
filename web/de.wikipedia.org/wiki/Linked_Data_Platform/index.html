Linked Data Platform

Die Linked Data Platform (LDP) ist eine Empfehlung des World Wide Web Consortium (W3C) aus dem Jahr 2015. Sie beschreibt eine Menge von Regeln für die Verwendung von HTTP zum Lesen und Schreiben von Linked Data, sodass Clients mit unterschiedlichen Servern einheitlich interagieren können. LDP definiert damit eine REST-artige Architektur für den schreibenden Zugriff auf RDF-Ressourcen, der bei den reinen Leseprinzipien der Linked Data noch nicht standardisiert war.

Grundlagen

Im Zentrum steht der Begriff des Containers: Eine LDP-Ressource kann ein einfacher RDF-Datensatz (LDPR) oder ein Container (LDPC) sein, der andere Ressourcen verwaltet, ähnlich einem Verzeichnis in einem Dateisystem. Über HTTP-Verben lassen sich Ressourcen abrufen (GET), anlegen (POST), ersetzen (PUT), teilweise ändern (PATCH) und löschen (DELETE). Container werden in Basis-, direkte und indirekte Container unterschieden, je nachdem, wie Mitgliedschaftsbeziehungen zwischen Container und Inhalt modelliert werden.

Anwendungen

Die Spezifikation geht auf Arbeiten bei IBM zurück und wurde unter anderem in Repository-Software für digitale Archive – etwa im Fedora-Commons-Projekt – sowie in der dezentralen Webplattform Solid von Tim Berners-Lee aufgegriffen, deren Protokoll eng mit LDP verwandt ist.
