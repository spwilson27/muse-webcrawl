Codeumwandlung

Als Codeumwandlung (englisch code conversion) bezeichnet man in der Informatik und Nachrichtentechnik die Umwandlung von Daten aus einer Codierung in eine andere, ohne dass sich die dargestellte Information ändert.

Anwendungsbereiche

Typische Beispiele sind die Umwandlung zwischen Zeichencodierungen (etwa von ISO 8859-1 nach UTF-8), zwischen Leitungscodes in der Übertragungstechnik (etwa von unipolaren zu bipolaren Signalen), zwischen Zahlensystemen und Codierungen für Speicher- und Übertragungsmedien. Auch die Umsetzung von einem einschrittigen Code (Gray-Code) in einen Dualzahlcode ist eine Codeumwandlung.

Verfahren

Die Umwandlung kann tabellenbasiert, algorithmisch oder durch logische Schaltungen (Umsetzer, Codierer) erfolgen. Bei der Zeichencodierung sind Informationen, die in der Zielcodierung nicht darstellbar sind, eine typische Fehlerquelle; verlustfreie Umwandlung ist nur möglich, wenn die Zielcodierung alle Zeichen der Quelle abbilden kann.
