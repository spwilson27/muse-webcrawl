Input

Input (englisch für „Eingabe“, „Zufuhr“, „Einsatz“) bezeichnet allgemein Daten, Stoffe oder Leistungen, die einem System, Prozess oder einer Organisation von außen zugeführt werden. Das Gegenteil ist der Output (Ausgabe, Ausstoß). Der Begriff wird in mehreren Fachgebieten unterschiedlich verwendet.

Informatik

In der Informatik ist Input die Eingabe von Daten in ein Computersystem, etwa über Eingabegeräte wie Tastatur, Maus oder Sensoren, oder aus Dateien und Netzwerken. Das EVA-Prinzip (Eingabe – Verarbeitung – Ausgabe) beschreibt diesen Ablauf als Grundmodell der Datenverarbeitung. Eingabedaten müssen häufig validiert werden (Input-Validierung), um Fehler und Angriffe wie SQL-Injection zu verhindern.

Wirtschaftswissenschaften

In der Volkswirtschaftslehre bezeichnet Input die in der Produktion eingesetzten Produktionsfaktoren (Arbeit, Kapital, Rohstoffe). Die Input-Output-Analyse nach Wassily Leontief stellt die Verflechtungen zwischen Wirtschaftssektoren in Tabellenform dar. In der Betriebswirtschaft ist Input der Einsatz von Ressourcen in einem Wertschöpfungsprozess.

Sprachwissenschaft und Didaktik

Im Fremdsprachenerwerb bezeichnet Input das sprachliche Angebot, dem Lernende ausgesetzt sind; Stephen Krashens Input-Hypothese besagt, dass verständlicher Input („comprehensible input“) knapp oberhalb des aktuellen Sprachniveaus für den Erwerb entscheidend ist.

Weitere Bedeutungen

Umgangssprachlich wird „Input“ auch für einen gedanklichen Beitrag, einen Impuls oder Anstoß in Diskussionen und Projekten verwendet.
