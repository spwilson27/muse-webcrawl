Linear Tape File System

Das Linear Tape File System (LTFS) ist ein Dateisystem für Magnetbänder des Standards Linear Tape-Open (LTO). Es wurde von IBM entwickelt, 2010 zusammen mit LTO-5 eingeführt und später als offener Standard (ISO/IEC 20919) veröffentlicht. LTFS macht ein Datenband wie einen Wechseldatenträger – vergleichbar einem USB-Stick – mit Verzeichnisstruktur und einzelnen Dateien über das Betriebssystem zugänglich.

Funktionsweise

Voraussetzung ist die mit LTO-5 eingeführte Bandpartitionierung: Ein LTFS-Band besitzt eine kleine Indexpartition und eine große Datenpartition. In der Indexpartition liegt ein XML-formatiger Index mit Verzeichnisbaum und Metadaten aller Dateien; die Dateiinhalte selbst werden sequenziell in der Datenpartition gespeichert. Beim Einlegen des Bandes liest das System den Index, sodass Verzeichnisse durchsucht und einzelne Dateien gezielt angesteuert werden können, ohne das gesamte Band durchzulesen. Geänderte Metadaten werden als neue Indexversionen an das Bandende bzw. in die Indexpartition geschrieben.

Eigenschaften und Nutzung

LTFS-Bänder sind selbstbeschreibend: Index und Daten befinden sich auf demselben Medium, eine separate Backup-Datenbank ist nicht erforderlich. Bänder können damit herstellerübergreifend zwischen Systemen ausgetauscht werden. Typische Einsatzbereiche sind Medien- und Filmarchive, Rundfunk, Wissenschaftsdaten und die Langzeitarchivierung. Nachteilig bleibt die prinzipbedingt sequenzielle Zugriffszeit eines Bandes: Der wahlfreie Zugriff auf viele kleine Dateien ist langsam, und gelöschter Speicherplatz wird erst beim Neuformatieren wieder nutzbar.
