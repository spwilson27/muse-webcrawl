QuickTime File Format

Das QuickTime File Format (QTFF) ist ein von Apple entwickeltes Containerformat für Multimediadaten, das vor allem unter der Dateiendung .mov bekannt ist. Es speichert eine oder mehrere Spuren (Tracks) für Video, Audio, Text und Effekte zusammen mit Metadaten und Zeitinformationen und bildet die Grundlage der QuickTime-Technologie.

Aufbau

Eine MOV-Datei ist hierarchisch aus „Atomen“ aufgebaut: typisierte Datenblöcke mit Länge und Typkennung. Das Atom mdat enthält die eigentlichen Mediendaten, während das Atom moov die Struktur beschreibt – Spuren, Zeitachsen, Codec-Parameter und Verweise auf die Datenabschnitte. Diese Trennung erlaubt es, Dateien zu strömen und nicht-linear zu bearbeiten, ohne die Mediendaten umzukopieren. Anders als viele andere Formate kann eine QuickTime-Datei auch Verweise auf externe Medien enthalten.

Codecs und Verbreitung

Das Format ist codec-unabhängig; üblich waren unter anderem Sorenson Video, Cinepak, H.264 und ProRes sowie AAC- und PCM-Audio. In der Film- und Fernsehproduktion wird .mov mit Apple ProRes bis heute als Austausch- und Masterformat genutzt.

Bedeutung für Standards

Das QTFF diente Ende der 1990er Jahre als Vorlage für das MPEG-4-Dateiformat (MP4, ISO Base Media File Format), das die Atomstruktur weitgehend übernahm und heute das dominierende Videocontainerformat ist.
