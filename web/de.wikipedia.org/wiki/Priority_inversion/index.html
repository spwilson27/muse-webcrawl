Prioritätsinversion

Die Prioritätsinversion (englisch priority inversion) ist ein Problem in Echtzeitsystemen, bei dem ein Task hoher Priorität indirekt durch einen Task niedrigerer Priorität blockiert wird.

Entstehung

Hält ein niederpriorer Task eine Ressource, etwa einen Mutex, die ein hochpriorer Task benötigt, muss dieser warten. Wird nun ein Task mittlerer Priorität lauffähig, verdrängt er den niederprioren Task und verlängert die Wartezeit des hochprioren Tasks erheblich – die Prioritäten erscheinen „umgekehrt".

Beispiel und Gegenmaßnahmen

Berühmt wurde ein solcher Fehler bei der NASA-Mission Mars Pathfinder (1997), der per Softwareaktualisierung behoben wurde. Gegenmaßnahmen sind die Prioritätsvererbung (priority inheritance), bei der der blockierende Task vorübergehend die höhere Priorität erbt, sowie das Priority-Ceiling-Protokoll.
