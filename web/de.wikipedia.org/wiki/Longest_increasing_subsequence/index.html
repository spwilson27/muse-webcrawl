Längste aufsteigende Teilfolge

Die längste aufsteigende Teilfolge (englisch longest increasing subsequence, LIS) einer Folge ist eine möglichst lange Teilfolge, deren Elemente streng (oder schwach) zunehmen und in der ursprünglichen Reihenfolge auftreten, ohne notwendigerweise benachbart zu sein.

Algorithmen

Ein einfacher Algorithmus auf Basis dynamischer Programmierung löst das Problem für eine Folge der Länge n in der Zeit O(n²). Effizienter ist ein Verfahren mit Laufzeit O(n log n), das auf Geduld-Sortieren (Patience Sorting) beruht: Die Elemente werden auf Stapel gelegt, wobei gleichzeitg die minimalen möglichen Endwerte von Teilfolgen jeder Länge verwaltet und per binärer Suche aktualisiert werden.

Zusammenhänge

Nach einem Satz von Erdős und Szekeres enthält jede Folge von (r−1)(s−1)+1 verschiedenen Zahlen eine aufsteigende Teilfolge der Länge r oder eine absteigende Teilfolge der Länge s. Das Problem spielt außerdem eine Rolle in der Wahrscheinlichkeitstheorie; die erwartete Länge der längsten aufsteigenden Teilfolge einer zufälligen Permutation wächst wie 2√n (Satz von Ulam).
