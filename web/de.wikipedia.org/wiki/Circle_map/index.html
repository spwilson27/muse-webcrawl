Kreisabbildung

Eine Kreisabbildung (englisch circle map) ist in der Theorie dynamischer Systeme eine Abbildung des Kreises auf sich selbst. Kreisabbildungen dienen als einfaches Modell für periodisch angeregte Oszillatoren und für das Phänomen der Modenkopplung (mode locking).

Definition

Eine Kreisabbildung hat die Form θ ↦ θ + Ω + (K/2π) sin(2πθ), wobei θ den Winkel auf dem Kreis, Ω eine treibende Frequenz und K die Stärke der nichtlinearen Kopplung bezeichnen. Für K = 0 liegt eine reine Drehung vor; für K > 0 entsteht die bekannte Arnold-Abbildung.

Verhalten

Entscheidend ist die Rotationszahl der Abbildung. Bei rationaler Rotationszahl tritt Modenkopplung auf: Der Oszillator synchronisiert sich mit der Anregung. In Parameterräumen bilden die Bereiche mit Modenkopplung die sogenannten Arnold-Zungen. Mit wachsendem K kann das System über eine Folge von Periodenverdopplungen oder quasiperiodische Übergänge ins Chaos übergehen.

Anwendungen

Kreisabbildungen werden unter anderem zur Beschreibung von Herzrhythmen, Josephson-Kontakten, phasengekoppelten Schleifen in der Nachrichtentechnik und biologischen Schrittfrequenzen verwendet.
