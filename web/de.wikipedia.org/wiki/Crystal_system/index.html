Kristallsystem

Kristallsysteme
Anzahl: 7
Systeme: triklin, monoklin, orthorhombisch, tetragonal, trigonal, hexagonal, kubisch
Unterteilung: 32 Kristallklassen (Punktgruppen)

Ein Kristallsystem ist eine Gruppe von Kristallen, die sich durch die Symmetrie ihrer Elementarzellen und die damit verbundenen Gitterparameter zusammenfassen lassen. In der Kristallographie unterscheidet man sieben Kristallsysteme.

Die sieben Systeme

  • Triklin: keine Symmetrievorgaben; a ≠ b ≠ c, α ≠ β ≠ γ ≠ 90°
  • Monoklin: eine zweizählige Achse; a ≠ b ≠ c, α = γ = 90°, β ≠ 90°
  • Orthorhombisch: drei senkrechte Achsen unterschiedlicher Länge; alle Winkel 90°
  • Tetragonal: zwei Achsen gleich lang, eine vierzählige Achse; a = b ≠ c, alle Winkel 90°
  • Trigonal: eine dreizählige Achse; Beschreibung oft in hexagonaler Aufstellung
  • Hexagonal: eine sechszählige Achse; a = b ≠ c, γ = 120°
  • Kubisch: höchste Symmetrie; a = b = c, alle Winkel 90°

Einordnung

Die sieben Kristallsysteme umfassen insgesamt 32 Kristallklassen (kristallographische Punktgruppen) und 230 Raumgruppen. Das Kristallsystem beeinflusst physikalische Eigenschaften: So sind kubische Kristalle optisch isotrop, während Kristalle niedrigerer Symmetrie Doppelbrechung zeigen können.
