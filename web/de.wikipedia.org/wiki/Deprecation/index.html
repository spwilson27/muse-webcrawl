Warnhinweis auf eine veraltete Funktion

Deprecation

Deprecation (englisch für „Missbilligung", „Abwertung") bezeichnet in der Softwareentwicklung die Kennzeichnung von Funktionen, Schnittstellen (APIs), Befehlen oder Dateiformaten als veraltet (englisch deprecated). Die Entwickler eines Systems signalisieren damit, dass ein Element zwar noch funktioniert, seine Verwendung aber nicht mehr empfohlen wird und es in einer künftigen Version entfernt oder durch eine bessere Alternative ersetzt werden soll.

Zweck

Die Deprecation gibt Anwendern und Programmierern Zeit, ihren Code auf die neue Lösung umzustellen, ohne dass gewachsene Software schlagartig bricht. Gründe für eine Deprecation sind unter anderem Sicherheitslücken, fehlerhaftes oder missverständliches Design, bessere Nachfolgemodelle oder der Wegfall zugrunde liegender Technik.

Mechanismen

In vielen Programmiersprachen existieren Annotationen oder Attribute wie @Deprecated in Java oder [[deprecated]] in C++, die beim Übersetzen Warnungen auslösen. In Dokumentationen und Standards (etwa bei HTML-Elementen wie <center> oder in RFCs) wird Veraltetes entsprechend markiert. Der Lebenszyklus führt typischerweise von der Deprecation über eine Übergangsphase zur endgültigen Entfernung (removal).

Abgrenzung

Nicht zu verwechseln ist die Deprecation mit „obsolet": Ein als obsolet gekennzeichnetes Element ist faktisch nicht mehr funktionsfähig oder darf nicht mehr verwendet werden, während ein deprecated-Element lediglich von der Verwendung abgeraten wird. Von Deprecation wird auch außerhalb der IT gesprochen, etwa wenn Normungsgremien Verfahren oder Maßeinheiten als überholt einstufen.
