AWS Lambda

AWS Lambda ist eine serverlose Computing-Plattform von Amazon Web Services (AWS). Sie wurde 2014 eingeführt und führt Code als Reaktion auf Ereignisse aus, ohne dass Entwickler Server verwalten müssen.

Funktionsweise

Entwickler laden Funktionen in unterstützten Sprachen (u. a. Python, Node.js, Java, Go, Ruby, C#, Rust) hoch oder stellen beliebige Laufzeitumgebungen als Container-Image bereit. Lambda startet Instanzen automatisch bei Bedarf, skaliert sie und schaltet sie danach wieder ab. Abrechnung erfolgt nach tatsächlicher Laufzeit und Arbeitsspeicher.

Anwendungsbereiche

  • APIs und Webanwendungen (z. B. zusammen mit Amazon API Gateway)
  • Datenverarbeitung und ETL-Pipelines
  • Datei- und Stream-Verarbeitung (z. B. Amazon S3, DynamoDB, Kinesis)
  • Backend von IoT- und Chatbot-Anwendungen
