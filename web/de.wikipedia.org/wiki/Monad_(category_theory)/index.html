Monade (Kategorientheorie)

Eine Monade ist in der Kategorientheorie ein Tripel aus einem Endofunktor und zwei natürlichen Transformationen, das bestimmte Kohärenzbedingungen erfüllt. Monaden verallgemeinern Konzepte aus der Algebra und der Logik und spielen eine wichtige Rolle in der theoretischen Informatik.

Definition

Eine Monade auf einer Kategorie C ist ein Tripel (T, η, μ), wobei T: C → C ein Funktor ist, η: Id → T (die „Einheit") und μ: T∘T → T (die „Multiplikation") natürliche Transformationen sind, sodass die Assoziativitäts- und Einheitsdiagramme kommutieren: μ ∘ Tμ = μ ∘ μT sowie μ ∘ Tη = id = μ ∘ ηT.

Beispiele

Zu jeder Adjunktion von Funktoren gehört eine Monade. Umgekehrt erzeugt jede Monade Adjunktionen, etwa über die Kleisli-Kategorie und die Eilenberg-Moore-Kategorie ihrer Algebren. Klassische Beispiele sind die Potenzmengen-Monade, die Listen-Monade und Monaden, die aus freien Algebren algebraischer Theorien entstehen.

Anwendungen

In der funktionalen Programmierung werden Monaden verwendet, um Seiteneffekte wie Ein- und Ausgabe, Zustand oder Ausnahmen strukturiert zu behandeln; bekannt wurde das Konzept vor allem durch die Sprache Haskell. Eugenio Moggi führte Monaden 1991 zur Semantik von Berechnungs­effekten ein, Philip Wadler popularisierte sie in der Programmierung.
