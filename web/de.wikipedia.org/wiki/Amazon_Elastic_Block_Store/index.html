Amazon Elastic Block Store

Amazon Elastic Block Store (Amazon EBS) ist ein blockbasierter Speicherdienst der Amazon Web Services (AWS). Er stellt persistenten Speicher auf Blockebene für die Verwendung mit Amazon-EC2-Instanzen bereit und verhält sich dabei wie ein rohes, unformatiertes Blockgerät, auf dem beliebige Dateisysteme angelegt werden können.

EntwicklerAmazon Web Services
Erstveröffentlichung2008
TypBlockspeicher (Cloud)

Eigenschaften

EBS-Volumes sind netzwerkgebundener Speicher, der unabhängig vom Lebenszyklus einer EC2-Instanz bestehen bleibt. Ein Volume kann jeweils an eine Instanz in derselben Availability Zone angehängt werden; bestimmte Volume-Typen (io1/io2 mit Multi-Attach) erlauben auch das gleichzeitige Anhängen an mehrere Instanzen. Die Daten werden innerhalb einer Availability Zone automatisch repliziert, um Ausfälle einzelner Komponenten abzufangen.

Von EBS-Volumes lassen sich Snapshots erstellen, die inkrementell in Amazon S3 gespeichert werden. Aus Snapshots können neue Volumes erzeugt werden, auch in anderen Availability Zones oder Regionen.

Volume-Typen

  • gp3 / gp2 – SSD-Volumes für allgemeine Zwecke
  • io2 / io1 – SSD-Volumes mit bereitgestellten IOPS für latenzkritische Anwendungen
  • st1 – durchsatzoptimierte HDD-Volumes für Big-Data-Workloads
  • sc1 – kostengünstige HDD-Volumes für selten genutzte Daten

Abgrenzung

Im Unterschied zum Instance Store, der physisch mit dem Hostrechner einer Instanz verbunden und flüchtig ist, überdauern EBS-Volumes das Stoppen und Beenden von Instanzen. Root-Volumes von EC2-Instanzen basieren in der Regel auf EBS.
