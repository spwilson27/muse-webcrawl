Kad-Netzwerk

Das Kad-Netzwerk ist ein Peer-to-Peer-Netzwerk, das auf dem Kademlia-Protokoll basiert und vor allem von Filesharing-Programmen wie eMule, aMule und MLDonkey zum serverlosen Auffinden von Dateien und Quellen genutzt wird.

Funktionsweise

Kad ist eine verteilte Hashtabelle (DHT), in der jeder Knoten eine zufällige 128-Bit-ID besitzt. Die „Entfernung“ zwischen Knoten wird über die XOR-Metrik berechnet. Jeder Teilnehmer speichert Informationen über einen Teil des Schlüsselsraums: Schlüsselwörter für die Suche und Verweise auf Dateien samt deren Quellen. Anfragen werden iterativ an immer „nähere“ Knoten gerichtet, bis der zuständige Knoten gefunden ist.

Verhältnis zum eD2k-Netzwerk

Während das klassische eDonkey2000-Netzwerk auf zentrale Indexserver angewiesen war, erlaubt Kad eine vollständig dezentrale Suche. Dadurch ist das Netzwerk weniger anfällig gegen das Abschalten einzelner Server. In eMule kann Kad parallel zum Serverbetrieb genutzt werden; der Beitritt erfolgt über bereits bekannte Knoten („Bootstrapping“) oder eine nodes.dat-Datei.

Verbreitung

Das Netzwerk erreichte in den 2000er Jahren eine Größe von mehreren Millionen gleichzeitig verbundenen Nutzern. Mit dem allgemeinen Rückgang der klassischen Filesharing-Netzwerke nahm auch die Nutzung von Kad ab.
