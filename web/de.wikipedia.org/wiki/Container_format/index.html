Containerformat

Ein Containerformat (auch Containerdatei) ist ein Dateiformat, das verschiedene Datenströme – etwa Video, Audio, Untertitel und Metadaten – in einer einzigen Datei zusammenfasst. Das Containerformat legt fest, wie die Daten organisiert und synchronisiert gespeichert werden, während die eigentliche Kompression der Inhalte durch separate Codecs erfolgt.

Beispiele

Bekannte Multimedia-Container sind MP4 (MPEG-4 Part 14), Matroska (MKV), AVI, QuickTime (MOV), WebM und das Transportstrom-Format MPEG-TS, das im Rundfunk verwendet wird. Auch Archivformate wie ZIP und TAR sowie Dokumentenformate wie PDF oder EPUB lassen sich im weiteren Sinn als Container auffassen, da sie mehrere Ressourcen bündeln.

Arbeitsweise

Beim Erstellen einer Containerdatei werden die codierten Datenströme ineinander verschränkt (Multiplexen), beim Abspielen wieder getrennt (Demultiplexen). Der Container kann mehrere Tonspuren (etwa verschiedene Sprachen), Untertitelspuren, Kapitelmarken und zusätzliche Metadaten enthalten. Ob eine Datei abgespielt werden kann, hängt sowohl vom Container als auch von den verwendeten Codecs ab.
