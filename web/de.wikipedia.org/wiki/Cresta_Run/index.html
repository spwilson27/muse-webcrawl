Cresta Run

Cresta Run
Ort: St. Moritz – Celerina, Schweiz
Länge: 1.214 m
Höhenunterschied: 157 m
Eröffnung: 1885

Der Cresta Run ist eine Natureisbahn für Skeleton im Engadin in der Schweiz. Sie führt von St. Moritz nach Celerina und wird jeden Winter von Hand aus Schnee und Eis neu aufgebaut. Betrieben wird sie vom 1887 gegründeten Saint Moritz Tobogganing Club, einem privaten britischen Club.

Geschichte

Die Bahn entstand im Winter 1884/85, als britische Kurgäste in St. Moritz und Davos Wettkämpfe auf vereisten Wegen austrugen. Sie gilt als Geburtsstätte des Skeletonsports: Die Fahrer gleiten kopfüber und bäuchlings auf einem niedrigen Schlitten die Bahn hinab. 1928 und 1948 war der Cresta Run Austragungsort der olympischen Skeletonwettbewerbe.

Strecke

Die Bahn ist 1.214 Meter lang und überwindet 157 Höhenmeter. Berüchtigt ist die Steilkurve „Shuttlecock“: Wer sie nicht trifft, fliegt aus der Bahn und wird durch Strohballen abgefangen. Erfahrene Fahrer erreichen Geschwindigkeiten von bis zu 130 km/h und Fahrzeiten von gut 50 Sekunden. Gestartet wird entweder von „Top“ (Gesamtstrecke) oder für Anfänger von der Junction weiter unten.

Bedeutung

Der Cresta Run ist eine der letzten Natureisbahnen der Welt und ein Symbol des frühen britischen Wintersports in den Alpen. Die Rennen des Saint Moritz Tobogganing Club, darunter der Grand National, werden bis heute ausgetragen.
