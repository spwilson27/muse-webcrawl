DirectShow

DirectShow (früher auch ActiveMovie genannt) ist ein Multimedia-Framework von Microsoft für Windows zur Wiedergabe, Aufnahme und Verarbeitung von Audio- und Videodaten. Es war lange Zeit Teil des DirectX-SDK und bildete die Grundlage vieler Mediaplayer, darunter älterer Versionen des Windows Media Players.

Architektur

DirectShow basiert auf dem Component Object Model (COM) und arbeitet mit sogenannten Filtergraphen: Einzelne Filter – etwa Quellfilter, Decoder (Codecs), Effektfilter und Renderer – werden über Pins zu einer Verarbeitungskette verbunden, durch die die Mediendaten strömen. Das System wählt anhand registrierter Filter und ihrer Prioritäten (Merit) automatisch eine passende Kette für ein Dateiformat aus. Das Werkzeug GraphEdit ermöglichte es Entwicklern, Filtergraphen visuell zusammenzustellen.

Bedeutung und Nachfolge

Durch die offene Filterarchitektur konnte DirectShow nahezu jedes Format abspielen, für das ein Codec installiert war, was zugleich zu Problemen durch fehlerhafte oder konkurrierende Filterpacks führte. Seit Windows Vista wurde DirectShow schrittweise durch die Media Foundation abgelöst, wird aber aus Kompatibilitätsgründen weiterhin unterstützt und von vielen Anwendungen genutzt.
