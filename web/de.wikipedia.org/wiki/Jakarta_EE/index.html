Jakarta EE

Jakarta EE (ehemals Java Platform, Enterprise Edition, Java EE beziehungsweise J2EE) ist eine serverseitige Softwareplattform beziehungsweise eine Sammlung von Spezifikationen für die Entwicklung verteilter Unternehmensanwendungen in der Programmiersprache Java. Sie erweitert die Java SE um Dienste wie Transaktionsmanagement, Persistenz, Webdienste und komponentenbasierte Geschäftslogik.

Geschichte

Die Plattform wurde 1999 von Sun Microsystems als J2EE eingeführt und später von Oracle als Java EE weitergeführt. 2017/2018 übergab Oracle die Entwicklung an die Eclipse Foundation, wo das Projekt den Namen Jakarta EE erhielt. Da die Namensrechte an „Java“ nicht übertragen werden konnten, erfolgte mit Jakarta EE 9 die Umbenennung des Paketraums von javax.* nach jakarta.*.

Technologien

Zu den zentralen Spezifikationen gehören Jakarta Servlet, Jakarta Server Pages (JSP), Jakarta Persistence (JPA, Nachfolger von Hibernate als Spezifikation), Jakarta Enterprise Beans (EJB), Jakarta RESTful Web Services (JAX-RS), Jakarta Contexts and Dependency Injection (CDI) sowie Jakarta Transactions (JTA). Anwendungen laufen auf kompatiblen Applikationsservern wie WildFly, GlassFish, Payara oder Apache TomEE.
