Filterbasis

Eine Filterbasis (auch Filterbase) ist in der Mathematik, insbesondere in der Topologie, eine Familie von Teilmengen, aus der sich ein Filter erzeugen lässt. Filterbasen erlauben es, Konvergenz zu beschreiben, ohne den vollständigen Filter angeben zu müssen.

Definition

Eine nichtleere Familie B von Teilmengen einer Menge X heißt Filterbasis, wenn die leere Menge nicht zu B gehört und es zu je zwei Mengen A, C ∈ B eine Menge D ∈ B gibt, die im Durchschnitt von A und C enthalten ist. Der von B erzeugte Filter besteht aus allen Obermengen der Elemente von B.

Beispiele

Die Familie der Umgebungen eines Punktes, die eine offene Kugel enthalten, bildet in metrischen Räumen eine abzählbare Filterbasis des Umgebungsfilters. Die Endstücke einer Folge – also die Mengen aller Folgenglieder ab einem gewissen Index – bilden eine Filterbasis, deren erzeugter Filter der elementare Filter der Folge ist. Auch die Familie der Mengen des Komplements endlicher Mengen bildet, je nach Betrachtung, natürliche Basen einfacher Filter.

Konvergenz

Eine Filterbasis konvergiert gegen einen Punkt, wenn der von ihr erzeugte Filter gegen diesen Punkt konvergiert, also wenn jede Umgebung des Punktes ein Element der Basis enthält. Zwei Filterbasen heißen äquivalent, wenn sie denselben Filter erzeugen; sie haben dann dieselben Grenzwerte.
