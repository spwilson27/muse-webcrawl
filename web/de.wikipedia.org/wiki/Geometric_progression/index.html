Geometrische Folge

Eine geometrische Folge ist eine Zahlenfolge, bei der der Quotient zweier aufeinanderfolgender Glieder konstant ist. Dieser konstante Quotient q heißt auch Quotient oder Wachstumsfaktor der Folge. Geometrische Folgen beschreiben exponentielle Wachstums- und Abnahmeprozesse.

Definition

Eine Folge (an) heißt geometrisch, wenn an+1 / an = q für alle n konstant ist. Mit dem Anfangsglied a0 ergibt sich die explizite Darstellung an = a0 · qn. Beispiele: 3, 6, 12, 24, 48, … (q = 2) oder 100, 50, 25, 12,5, … (q = 1/2).

Summenformel

Die Summe der ersten n+1 Glieder beträgt für q ≠ 1: sn = a0 · (qn+1 − 1) / (q − 1). Aus der endlichen geometrischen Folge entsteht durch Summenbildung die endliche geometrische Reihe.

Anwendungen

Geometrische Folgen treten bei Zinseszinsrechnung, radioaktivem Zerfall (Halbwertszeit), Bevölkerungswachstum und Schallpegelabnahme auf. Das bekannte Schachbrett-Weizenkorn-Problem (Verdopplung auf jedem Feld) veranschaulicht die enorme Wachstumsgeschwindigkeit für q = 2.
