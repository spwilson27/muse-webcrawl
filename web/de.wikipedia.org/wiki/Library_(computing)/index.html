Programmbibliothek

Eine Programmbibliothek (englisch library) ist in der Softwareentwicklung eine Sammlung von Programmfunktionen, Klassen und Ressourcen, die von anderen Programmen wiederverwendet werden kann. Bibliotheken stellen über definierte Schnittstellen (APIs) Funktionalität bereit, ohne dass deren Implementierung dem nutzenden Programm bekannt sein muss. Sie sind ein zentrales Mittel zur Modularisierung und Wiederverwendung von Code.

Arten

Bei statischen Bibliotheken wird der Bibliothekscode beim Linken fest in das auszuführende Programm eingebunden (unter Unix meist Dateien mit der Endung .a, unter Windows .lib). Dynamische Bibliotheken (englisch shared libraries, .so unter Linux, .dylib unter macOS, .dll unter Windows) werden dagegen erst zur Laufzeit geladen und können von mehreren Programmen gleichzeitig genutzt werden, was Speicherplatz spart und Aktualisierungen erleichtert.

Verwendung

Praktisch jedes Programm nutzt Bibliotheken, von der Standardbibliothek der jeweiligen Programmiersprache (etwa der C-Standardbibliothek) über Grafik- und Netzwerkbibliotheken bis zu spezialisierten Fachbibliotheken. Betriebssysteme stellen Systembibliotheken als Teil ihrer Programmierschnittstellen bereit. Die Verwaltung von Bibliotheksabhängigkeiten erfolgt in modernen Entwicklungsumgebungen häufig über Paketmanager wie npm, pip oder Maven.
