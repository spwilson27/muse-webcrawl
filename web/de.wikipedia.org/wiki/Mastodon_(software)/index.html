Mastodon (Software)

Mastodon ist eine freie Server-Software zum Betrieb selbstgehosteter sozialer Netzwerke (Instanzen). Sie implementiert das ActivityPub-Protokoll des W3C und ist damit Teil des Fediverse; Nutzer verschiedener Instanzen und kompatibler Dienste können einander folgen und Nachrichten austauschen.

Technik

Der Server ist in Ruby on Rails geschrieben, die Weboberfläche nutzt React und Redux; für Echtzeit-Updates kommt ein Streaming-Dienst in Node.js zum Einsatz. Daten werden in PostgreSQL gespeichert, Redis dient als Cache und Warteschlange; Hintergrundaufgaben verarbeitet Sidekiq. Das System lässt sich per Docker oder klassisch auf Linux-Servern betreiben. Beiträge werden über WebFinger-Adressen der Form @nutzer@instanz identifiziert.

Eigenschaften

Mastodon unterstützt Textbeiträge mit einstellbarer Zeichenbegrenzung, Medienanhänge mit Bildbeschreibungen, Umfragen, Spoiler-/Inhaltswarnungen, lokale und föderierte Zeitachsen sowie umfangreiche Moderations- und Blockierwerkzeuge für Instanzadministratoren. Offizielle Apps für iOS und Android erschienen 2021 beziehungsweise 2022; daneben existiert ein großes Ökosystem von Dritt-Apps.

Entwicklung

Erstellt wurde die Software 2016 von Eugen Rochko; sie wird unter der GNU Affero General Public License (AGPLv3) veröffentlicht und von der Mastodon gGmbH sowie einer weltweiten Beitragsgemeinschaft weiterentwickelt. Die Föderation erfolgte zunächst über OStatus und wurde mit Version 1.6 (2017) auf ActivityPub umgestellt.
