QEMU

QEMU (kurz für Quick Emulator) ist eine freie und quelloffene Software zur Emulation und Virtualisierung von Computersystemen. Das Projekt wurde von Fabrice Bellard ins Leben gerufen und steht unter der GNU General Public License.

Funktionsweise

QEMU kann ein vollständiges Gastsystem inklusive Prozessor und Peripheriegeräten emulieren (Vollvirtualisierung) oder im Benutzermodus einzelne Programme einer fremden CPU-Architektur ausführen. Durch dynamische Binärübersetzung werden die Befehle der Gastarchitektur zur Laufzeit in Code der Wirtsarchitektur umgewandelt. In Verbindung mit Hardware-Virtualisierung wie KVM unter Linux erreicht QEMU nahezu native Geschwindigkeit.

Unterstützte Architekturen

Emuliert werden unter anderem x86, ARM, RISC-V, PowerPC, SPARC und MIPS. QEMU ist Bestandteil vieler Virtualisierungslösungen, etwa von Proxmox VE und dem libvirt-Umfeld, und wird häufig gemeinsam mit dem Linux-Kernelmodul KVM eingesetzt.
