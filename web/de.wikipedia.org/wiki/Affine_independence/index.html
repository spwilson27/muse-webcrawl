Affine Unabhängigkeit


Verallgemeinerung der linearen Unabhängigkeit auf Punkte

Affine Unabhängigkeit ist ein Begriff der affinen Geometrie. Eine Menge von Punkten eines affinen Raumes heißt affin unabhängig, wenn keiner der Punkte in der affinen Hülle der übrigen liegt.

Definition

Die Punkte x0, …, xn heißen affin unabhängig, wenn aus einer Affinkombination λ0x0 + … + λnxn mit Koeffizientensumme 0 und Wert 0 folgt, dass alle λi gleich 0 sind. Äquivalent sind die Differenzvektoren x1 − x0, …, xn − x0 linear unabhängig.

Beispiele

  • Zwei verschiedene Punkte sind stets affin unabhängig.
  • Drei Punkte sind genau dann affin unabhängig, wenn sie nicht auf einer gemeinsamen Geraden liegen (nicht kollinear sind).
  • Vier Punkte der Ebene sind stets affin abhängig, da die affine Hülle der Ebene die Dimension 2 hat.

In einem n-dimensionalen affinen Raum gibt es höchstens n + 1 affin unabhängige Punkte. Ein maximales System affin unabhängiger Punkte bildet ein Simplex beziehungsweise ein affines Koordinatensystem; seine Punkte sind die Ecken eines Simplex, und jeder Punkt des Raumes besitzt eindeutige baryzentrische Koordinaten bezüglich dieses Systems.
