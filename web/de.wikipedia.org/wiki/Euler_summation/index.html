Euler-Summation

Die Euler-Summation (englisch Euler summation) ist ein Summationsverfahren der Analysis, das einer (möglicherweise divergenten) Reihe einen Wert zuordnet beziehungsweise die Konvergenz einer Reihe beschleunigt. Sie geht auf Leonhard Euler zurück und beruht auf einer Transformation der Partialsummen mit Hilfe von Differenzen der Folgenglieder.

Definition

Ist (an) eine Folge und bezeichnet Δ den Vorwärtsdifferenzenoperator (Δan = an+1 − an), so lautet die Eulersche Reihentransformation für eine alternierende Reihe:

∑n=0∞ (−1)n an = ∑n=0∞ (−1)n Δn a0 / 2n+1

Unter geeigneten Voraussetzungen stimmt der so erhaltene Wert mit dem gewöhnlichen Reihenwert überein, die transformierte Reihe konvergiert jedoch häufig wesentlich schneller.

Beispiel

Für die langsam konvergente Leibniz-Reihe 1 − 1/3 + 1/5 − 1/7 + … = π/4 liefert die Euler-Transformation eine rasch konvergierende Reihe, mit der sich π effizient numerisch berechnen lässt.

Einordnung

Die Euler-Summation gehört zu den klassischen Summationsverfahren (neben Cesàro-, Abel- und Borel-Summation) und steht in engem Zusammenhang mit der Euler-Maclaurin-Formel. Zur Summation stark divergenter Reihen wird heute häufiger die verwandte Euler-Boole-Summation beziehungsweise die Bohr-Mollerup-Theorie der asymptotischen Entwicklungen herangezogen.
