Linked Data

Linked Data (deutsch: verknüpfte Daten) bezeichnet ein Konzept zur Veröffentlichung und Verknüpfung strukturierter Daten im World Wide Web. Der Begriff wurde 2006 von Tim Berners-Lee geprägt, der vier Prinzipien formulierte, nach denen Daten so bereitgestellt werden sollen, dass sie maschinell verknüpfbar und wiederverwendbar sind. Linked Data gilt als eine praktische Ausprägung des Semantic Web.

Die vier Prinzipien

  1. Verwende URIs als Namen für Dinge.
  2. Verwende HTTP-URIs, damit diese Namen nachgeschlagen werden können.
  3. Wenn jemand eine URI nachschlägt, stelle nützliche Informationen bereit und verwende dabei die Standards (RDF, SPARQL).
  4. Verlinke auf andere URIs, damit mehr Dinge entdeckt werden können.

Technologien

Grundlage ist das Resource Description Framework (RDF), das Aussagen als Tripel aus Subjekt, Prädikat und Objekt darstellt. Daten werden in Formaten wie RDF/XML, Turtle oder JSON-LD ausgeliefert; die Abfragesprache SPARQL ermöglicht Anfragen an verteilte Datenbestände. Wohlbekannte Vokabulare wie FOAF, SKOS und schema.org beschreiben die Bedeutung der verwendeten Begriffe. Berners-Lee schlug zudem ein Fünf-Sterne-Schema vor, das von offen lizenzierten Daten in beliebigen Formaten (ein Stern) bis zu verlinkten RDF-Daten (fünf Sterne) reicht.

Linked Open Data

Werden verknüpfte Daten unter freien Lizenzen veröffentlicht, spricht man von Linked Open Data (LOD). Das 2007 gestartete Projekt Linking Open Data vernetzte offene Datensätze wie DBpedia, Wikidata, GeoNames und zahlreiche Bibliotheks- und Regierungsdaten zu einer wachsenden „Datenwolke“.
