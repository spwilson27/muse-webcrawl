Halbordnung

Eine Halbordnung (englisch partial order), auch partielle Ordnung oder Partialordnung genannt, ist in der Mathematik eine Relation auf einer Menge, die reflexiv, antisymmetrisch und transitiv ist. Eine mit einer Halbordnung versehene Menge heißt halbgeordnete Menge oder Poset (von englisch partially ordered set).

Definition

Eine Relation ≤ auf einer Menge M heißt Halbordnung, wenn für alle x, y, z ∈ M gilt:

  • Reflexivität: x ≤ x
  • Antisymmetrie: Aus x ≤ y und y ≤ x folgt x = y
  • Transitivität: Aus x ≤ y und y ≤ z folgt x ≤ z

Im Unterschied zu einer Totalordnung müssen nicht je zwei Elemente miteinander vergleichbar sein; Elemente, für die weder x ≤ y noch y ≤ x gilt, heißen unvergleichbar.

Beispiele

  • Die Teilmengenrelation ⊆ auf der Potenzmenge einer Menge.
  • Die Teilbarkeitsrelation auf den natürlichen Zahlen: a teilt b.
  • Die Kleiner-gleich-Relation ≤ auf den reellen Zahlen ist sogar eine Totalordnung.
  • Abspiel- und Abhängigkeitsordnungen in der Informatik, etwa bei der Planung von Prozessen.

Darstellung und Begriffe

Endliche Halbordnungen lassen sich durch Hasse-Diagramme veranschaulichen, in denen nur die unmittelbaren Nachfolgerbeziehungen (Überdeckungsrelation) eingezeichnet werden. Wichtige Begriffe sind maximale und minimale Elemente, obere und untere Schranken, Suprema und Infima sowie Ketten und Antiketten. Halbordnungen, in denen je zwei Elemente ein Supremum und ein Infimum besitzen, heißen Verbände.
