Beta-Verteilung

Die Beta-Verteilung ist eine stetige Wahrscheinlichkeitsverteilung auf dem Intervall [0, 1]. Sie wird durch zwei positive Formparameter α und β bestimmt und eignet sich zur Modellierung von Zufallsgrößen, die Anteile oder Wahrscheinlichkeiten darstellen.

Dichtefunktion

Die Dichtefunktion lautet

f(x; α, β) = xα−1 (1−x)β−1 / B(α, β), 0 ≤ x ≤ 1,

wobei B(α, β) die Eulersche Beta-Funktion bezeichnet, die als Normierungskonstante dient.

Eigenschaften

Der Erwartungswert beträgt E(X) = α / (α + β), die Varianz Var(X) = αβ / [(α + β)² (α + β + 1)]. Je nach Wahl der Parameter kann die Dichte sehr unterschiedliche Formen annehmen: Für α = β = 1 ergibt sich die Gleichverteilung; für α, β > 1 ist die Dichte unimodal, für α, β < 1 ist sie U-förmig.

Anwendungen

In der bayesschen Statistik dient die Beta-Verteilung als konjugierte A-priori-Verteilung zur Binomialverteilung, etwa bei der Schätzung von Erfolgswahrscheinlichkeiten. Weiter wird sie in der Projektplanung (PERT) zur Modellierung von Vorgangsdauern und zur Beschreibung von Anteilen verwendet.
