CORBA

CORBA (Common Object Request Broker Architecture) ist eine von der Object Management Group (OMG) entwickelte Spezifikation für eine Middleware, die die Kommunikation zwischen verteilten Objekten in heterogenen Netzwerken ermöglicht. Programme in unterschiedlichen Programmiersprachen und auf unterschiedlichen Plattformen können so miteinander interagieren, als befänden sie sich im selben Prozess.

Architektur

Zentrales Element ist der Object Request Broker (ORB), der Methodenaufrufe zwischen Client und Serverobjekt vermittelt. Die Schnittstellen der Objekte werden in der sprachunabhängigen Interface Definition Language (IDL) beschrieben; aus der IDL-Beschreibung erzeugen Werkzeuge sogenannte Stubs (clientseitig) und Skeletons (serverseitig). Die Kommunikation erfolgt über das Protokoll GIOP beziehungsweise dessen TCP/IP-Variante IIOP. Zur Architektur gehören außerdem Dienste (CORBA Services) wie Namens-, Ereignis- und Transaktionsdienst.

Geschichte

Die erste Version erschien 1991; breite Verbreitung fand CORBA in den 1990er Jahren in Unternehmens- und Telekommunikationssystemen. Ab Version 3 kamen Komponentenmodelle und Quality-of-Service-Erweiterungen hinzu. Wegen seiner Komplexität verlor CORBA gegenüber einfacheren Web-Technologien wie SOAP- und später REST-Webservices sowie gRPC an Bedeutung, wird aber in langlebigen Systemen, etwa in der Telekommunikation, im Finanzwesen und in der Luft- und Raumfahrt, weiterhin eingesetzt.
