Eigenschaft (Programmierung)

Eine Eigenschaft (englisch property) ist in der objektorientierten Programmierung ein besonderes Klassenmitglied, das wie ein Feld gelesen und geschrieben werden kann, hinter dem aber Methoden (Getter und Setter) stehen. Sprachen wie C#, Delphi, Python, Kotlin und Objective-C bieten dafür eigene Sprachmittel.

Zweck

Properties verbinden die bequeme Syntax des direkten Feldzugriffs mit der Kontrolle expliziter Zugriffsmethoden: Beim Lesen oder Schreiben kann validiert, umgerechnet, protokolliert oder ein Ereignis ausgelöst werden. Automatisch implementierte Properties erzeugen im Hintergrund ein verdecktes Sicherungsfeld.

Beispiele

In C# definiert public int Alter { get; set; } eine Property mit automatisch generierten Accessoren; in Python geschieht dies mit dem Decorator @property. In Objective-C steuern Attribute wie strong oder copy die Speicherverwaltung der Property.

Abgrenzung

Anders als ein öffentliches Feld wahrt eine Property die Kapselung: Die interne Darstellung kann sich ändern, ohne dass aufrufender Code angepasst werden muss.
