Hauptdiagonale

Die Hauptdiagonale (englisch main diagonal) einer quadratischen Matrix ist die Diagonale, die von der oberen linken zur unteren rechten Ecke verläuft. Sie besteht aus allen Elementen aii, bei denen Zeilen- und Spaltenindex übereinstimmen.

Definition

Für eine Matrix A = (aij) mit n Zeilen und Spalten bilden die Einträge a11, a22, …, ann die Hauptdiagonale. Die Summe der Hauptdiagonalelemente einer Matrix heißt Spur.

Besondere Matrizen

  • Bei einer Diagonalmatrix sind alle Einträge außerhalb der Hauptdiagonale null.
  • Bei der Einheitsmatrix stehen auf der Hauptdiagonale ausschließlich Einsen.
  • Bei einer symmetrischen Matrix ist die Matrix an der Hauptdiagonale gespiegelt, es gilt aij = aji.
  • Bei Dreiecksmatrizen sind alle Einträge unterhalb beziehungsweise oberhalb der Hauptdiagonale null.

Nebendiagonale

Die von oben rechts nach unten links verlaufende Diagonale wird als Nebendiagonale (englisch anti-diagonal) bezeichnet. Sie besteht aus den Elementen ai, n+1−i.
