Gerichtete Menge

Eine gerichtete Menge (englisch directed set) ist in der Mathematik eine nichtleere Menge mit einer reflexiven und transitiven Relation (einer sogenannten Präordnung), bei der je zwei Elemente eine gemeinsame obere Schranke besitzen. Gerichtete Mengen verallgemeinern den Begriff der Indexmenge von Folgen und sind grundlegend für die Theorie der Netze in der Topologie.


Hasse-Diagramm einer gerichteten Menge

Definition

Eine Menge I mit einer Relation ≤ heißt gerichtet, wenn gilt: (1) a ≤ a für alle a ∈ I (Reflexivität), (2) aus a ≤ b und b ≤ c folgt a ≤ c (Transitivität), und (3) zu je zwei Elementen a, b ∈ I existiert ein c ∈ I mit a ≤ c und b ≤ c.

Beispiele

  • Die natürlichen Zahlen mit der üblichen Ordnung bilden eine gerichtete Menge.
  • Die endlichen Teilmengen einer beliebigen Menge, geordnet durch Inklusion, sind gerichtet.
  • Die Umgebungssysteme eines Punktes in einem topologischen Raum, geordnet durch umgekehrte Inklusion, sind gerichtet.

Netze

Ein Netz ist eine Abbildung von einer gerichteten Menge in einen topologischen Raum. Netze verallgemeinern Folgen: Jeder Folge liegt die gerichtete Menge der natürlichen Zahlen zugrunde, doch Netze ermöglichen die Beschreibung von Konvergenz in Räumen, in denen Folgen nicht ausreichen.
