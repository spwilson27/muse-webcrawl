POST-Karte

Eine POST-Karte (englisch POST card, auch Diagnosekarte) ist eine Erweiterungskarte zur Fehlerdiagnose an Personal Computern. Der Name leitet sich vom Power-On Self-Test (POST) des BIOS beziehungsweise UEFI ab, nicht vom Postversand.

Funktionsweise

Beim Einschalten eines PCs führt die Firmware eine Reihe von Selbsttests aus und schreibt dabei an einen bestimmten I/O-Port (bei klassischen IBM-PC-kompatiblen Systemen meist Port 80h) sogenannte POST-Codes, die den jeweils aktuellen Testschritt kennzeichnen. Die POST-Karte wird in einen Erweiterungssteckplatz (früher ISA, später PCI, heute auch PCIe oder per Spezialanschluss) gesteckt, liest diese Codes mit und zeigt sie auf einer zweistelligen Siebensegmentanzeige an.

Anwendung

Bleibt der Startvorgang hängen – etwa ohne Bildschirmausgabe –, zeigt die Karte den zuletzt ausgegebenen Code an. Anhand von Tabellen des jeweiligen BIOS-Herstellers (Award, AMI, Phoenix u. a.) lässt sich daraus die fehlerhafte Komponente, etwa Arbeitsspeicher, Grafikkarte oder CPU, eingrenzen. Moderne Hauptplatinen besitzen häufig bereits fest eingebaute POST-Code-Anzeigen oder Diagnose-LEDs, sodass separate Karten vor allem in der Reparaturtechnik verwendet werden.
