International Celestial Reference System

Das International Celestial Reference System (ICRS) ist das von der Internationalen Astronomischen Union festgelegte himmlische Referenzsystem zur Angabe von Positionen am Himmel. Es wurde 1991 beschlossen und wird seit dem 1. Januar 1998 verwendet.

Definition

Der Ursprung des ICRS liegt im Baryzentrum des Sonnensystems; seine Achsen sind raumfest und an weit entfernten extragalaktischen Radioquellen ausgerichtet. Die praktische Realisierung ist der International Celestial Reference Frame (ICRF), ein Katalog präziser Positionen von Quasaren, die mittels Very Long Baseline Interferometry bestimmt werden. Die dritte Version, ICRF3, wurde 2018 verabschiedet.

Bedeutung

Weil die Bezugsobjekte praktisch unbeweglich sind, ist das ICRS unabhängig von der Erdrotation und der Präzession. Es bildet die Grundlage moderner Sternkataloge wie der Gaia-Mission und für die genaue Navigation von Raumsonden.
