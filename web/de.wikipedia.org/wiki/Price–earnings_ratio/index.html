Kurs-Gewinn-Verhältnis

Das Kurs-Gewinn-Verhältnis (KGV; englisch price–earnings ratio, P/E ratio) ist eine betriebswirtschaftliche Kennzahl zur Bewertung von Aktien. Es setzt den aktuellen Aktienkurs ins Verhältnis zum Gewinn je Aktie eines Unternehmens.

Berechnung

KGV = Aktienkurs ÷ Gewinn je Aktie. Je nach verwendetem Gewinn unterscheidet man das KGV auf Basis vergangener Gewinne (trailing P/E) vom KGV auf Basis erwarteter künftiger Gewinne (forward P/E).

Interpretation

Ein hohes KGV kann auf hohe Wachstumserwartungen der Anleger hindeuten, aber auch auf eine Überbewertung. Ein niedriges KGV kann ein Zeichen für eine günstige Bewertung oder für Probleme des Unternehmens sein. Branchenvergleiche sind aussagekräftiger als absolute Schwellenwerte.

Varianten

Das von Robert Shiller populär gemachte zyklisch bereinigte KGV (CAPE bzw. Shiller-KGV) verwendet den Durchschnitt der inflationsbereinigten Gewinne von zehn Jahren und dient der Bewertung ganzer Aktienmärkte.
