Common Application

Die Common Application (kurz Common App) ist eine US-amerikanische Online-Plattform, über die sich Studienbewerber mit einem einheitlichen Bewerbungsformular an über 1.000 teilnehmenden Colleges und Universitäten bewerben können. Betrieben wird sie von einer gleichnamigen gemeinnützigen Organisation, die 1975 gegründet wurde.

Ablauf

Bewerber legen ein zentrales Profil mit persönlichen Angaben, schulischen Leistungen und Aktivitäten an und verfassen einen allgemeinen Bewerbungsessay, aus dem jährlich mehrere Themen zur Auswahl stehen. Hinzu kommen hochschulspezifische Ergänzungen (Supplements), die von den einzelnen Mitgliedshochschulen festgelegt werden. Über die Plattform werden außerdem Zeugnisse und Empfehlungsschreiben von Lehrkräften übermittelt.

Verbreitung

Die Common App wurde 1975 von 15 Hochschulen eingeführt; seit der Umstellung auf ein reines Online-Verfahren nutzen jährlich über eine Million Bewerber das System. Sie gilt als Standard der Studienbewerbung in den USA und wurde für ihre Zugänglichkeit, aber auch für technische Probleme beim Relaunch 2013 kritisiert.
