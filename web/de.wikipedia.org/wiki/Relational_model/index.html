Relationales Modell

Das relationale Modell ist ein von Edgar F. Codd 1970 in dem Aufsatz A Relational Model of Data for Large Shared Data Banks vorgeschlagenes Datenmodell für Datenbanken. Es basiert auf der mathematischen Relation der Mengenlehre und der Prädikatenlogik.

Struktur

Die einzige Datenstruktur des Modells ist die Relation, dargestellt als Tabelle. Eine Relation besteht aus einem Schema (Menge von Attributen mit ihren Domänen) und einer Ausprägung (Menge von Tupeln). Da Relationen Mengen sind, hat eine Tabelle keine doppelte Zeilen und keine feste Reihenfolge der Zeilen und Spalten.

Integritätsbedingungen

  • Entitätsintegrität: Ein Primärschlüssel darf keine Nullwerte enthalten.
  • Referenzielle Integrität: Ein Fremdschlüssel muss auf einen existierenden Primärschlüssel verweisen oder null sein.

Operationen

Auf Relationen operieren die relationale Algebra mit Operationen wie Selektion, Projektion, Vereinigung, Differenz und Verbund (Join) sowie das äquivalente relationale Kalkül. Codds zwölf Regeln (eigentlich dreizehn, nummeriert von 0 bis 12) von 1985 beschreiben Anforderungen an ein voll relationales Datenbankmanagementsystem.
