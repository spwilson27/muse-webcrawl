Load Balancer

Ein Load Balancer (deutsch: Lastverteiler) ist eine Komponente der Informationstechnik, die eingehende Anfragen oder Datenverkehr auf mehrere Server oder Ressourcen verteilt, um Auslastung, Antwortzeiten und Verfügbarkeit eines Dienstes zu verbessern. Er steht als Vermittler zwischen den Clients und einer Gruppe von Backend-Servern.

Arbeitsweise

Der Load Balancer nimmt Anfragen unter einer gemeinsamen Adresse (z. B. einer virtuellen IP-Adresse) entgegen und leitet sie nach einer Verteilstrategie an einen der Backend-Server weiter. Die Antworten gelangen entweder über den Load Balancer oder direkt zurück zum Client. Gesundheitsprüfungen („Health Checks") erkennen ausgefallene Server und nehmen sie automatisch aus der Verteilung.

Ebenen

  • Layer-4-Load-Balancer arbeiten auf der Transportebene (TCP/UDP) und verteilen Verbindungen anhand von IP-Adressen und Ports.
  • Layer-7-Load-Balancer arbeiten auf der Anwendungsebene und können HTTP-Anfragen anhand von URL, Headern oder Cookies steuern; sie ermöglichen u. a. Sitzungsbindung („Sticky Sessions") und SSL-Terminierung.

Umsetzung

Load Balancer existieren als dedizierte Hardware, als Software (z. B. HAProxy, Nginx) und als Cloud-Dienst. Auch DNS-basierte Verfahren (Round-Robin-DNS) werden zur groben Lastverteilung eingesetzt.
