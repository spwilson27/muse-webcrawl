Automatic Warning System

Das Automatic Warning System (AWS) ist ein britisches Zugsicherungssystem, das den Triebfahrzeugführer im Führerstand akustisch und optisch auf den Signalbegriff des nächsten Streckensignals hinweist. Es wurde ab den 1950er-Jahren auf dem Netz der British Railways eingeführt und ist bis heute auf einem großen Teil des britischen Streckennetzes Standard.

Funktionsweise

Etwa 180 bis 270 Meter vor einem Signal ist zwischen den Schienen eine Rampe mit einem Permanentmagneten und – bei „Fahrt"-Stellung – einem nachgeschalteten Elektromagneten angebracht. Überfährt der Zug die Einrichtung, wird je nach Signalstellung entweder eine Glocke ausgelöst (Signal zeigt „Fahrt") oder ein Warnton (Hupe) ertönt und eine Anzeige („Blume", eine schwarz-gelbe Scheibe) erscheint. Bei Warnung muss der Fahrer innerhalb weniger Sekunden eine Quittierungstaste betätigen, sonst erfolgt automatisch eine Zwangsbremsung. Eine Sichtanzeige erinnert den Fahrer an die zuletzt empfangene Warnung.

Geschichte

Vorläufer des Systems gehen auf das frühe 20. Jahrhundert zurück; nach schweren Unfällen, darunter der Eisenbahnunfall von Harrow and Wealdstone 1952, wurde die flächendeckende Einführung des von British Railways standardisierten AWS beschlossen. Das System besitzt keine kontinuierliche Geschwindigkeitsüberwachung; es wurde daher später durch das Train Protection and Warning System (TPWS) ergänzt, das an Signalen und Geschwindigkeitsbegrenzungen zusätzlich eine Bremsauslösung bei Annäherung mit überhöhter Geschwindigkeit vorsieht.
