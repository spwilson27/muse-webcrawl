Cyber Kill Chain

Entwickler: Lockheed Martin

Veröffentlichung: 2011

Bereich: Informationssicherheit

Die Cyber Kill Chain (deutsch etwa „Cyber-Angriffskette“) ist ein Modell der Informationssicherheit, das die Phasen eines gezielten Cyberangriffs beschreibt. Es wurde 2011 von Mitarbeitern des Rüstungs- und Technologiekonzerns Lockheed Martin vorgestellt und basiert auf dem militärischen Konzept der „Kill Chain“ (F2T2EA: Find, Fix, Track, Target, Engage, Assess).

Die sieben Phasen

  1. Reconnaissance (Aufklärung): Der Angreifer sammelt Informationen über das Ziel, etwa E-Mail-Adressen, Organisationsstrukturen oder eingesetzte Technologien.
  2. Weaponization (Bewaffnung): Ein ausnutzbarer Schadcode wird mit einer Schwachstelle zu einer „Waffe“ kombiniert, etwa ein präpariertes Dokument.
  3. Delivery (Zustellung): Die Waffe wird an das Ziel übermittelt, beispielsweise per E-Mail-Anhang, USB-Stick oder über eine kompromittierte Website.
  4. Exploitation (Ausnutzung): Der Schadcode wird ausgeführt und nutzt eine Schwachstelle im System des Opfers aus.
  5. Installation: Der Angreifer installiert eine Hintertür oder Schadsoftware, um dauerhaften Zugriff zu erhalten.
  6. Command and Control (C2): Das kompromittierte System baut eine Verbindung zum Angreifer auf, über die es ferngesteuert werden kann.
  7. Actions on Objectives (Aktionen am Ziel): Der Angreifer führt sein eigentliches Ziel aus, etwa Datendiebstahl, Spionage oder Sabotage.

Verteidigungsansätze

Das Modell dient Verteidigern dazu, Gegenmaßnahmen den einzelnen Phasen zuzuordnen. Je früher eine Angriffskette unterbrochen wird, desto geringer ist in der Regel der Schaden. Kritiker merken an, dass das Modell stark auf klassische, perimeterbasierte Angriffe mit Schadsoftware zugeschnitten sei und neuere Angriffsformen wie Identitätsdiebstahl oder Angriffe auf Lieferketten nur unzureichend abbilde. Weiterentwicklungen wie die MITRE-ATT&CK-Matrix ergänzen das Konzept um eine feinere Beschreibung von Taktiken und Techniken.
