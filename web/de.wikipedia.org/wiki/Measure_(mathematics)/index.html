Maß (Mathematik)

Ein Maß (englisch measure) ist in der Maßtheorie, einem Teilgebiet der Mathematik, eine Funktion, die Teilmengen einer Menge nichtnegative reelle Zahlen (oder ∞) zuordnet und dabei das intuitive Konzept von Länge, Fläche, Volumen bzw. Wahrscheinlichkeit verallgemeinert.

Definition

Sei X eine Menge und Σ eine σ-Algebra über X. Eine Abbildung μ : Σ → [0, ∞] heißt Maß, wenn gilt:

  • μ(∅) = 0,
  • σ-Additivität: Für jede Folge paarweise disjunkter Mengen A1, A2, … aus Σ ist μ(⋃An) = Σ μ(An).

Das Tripel (X, Σ, μ) heißt Maßraum. Ein Maß mit μ(X) = 1 heißt Wahrscheinlichkeitsmaß, ein Maß mit μ(X) < ∞ endliches Maß.

Beispiele

Wichtige Beispiele sind das Lebesgue-Maß auf dem ℝn (Verallgemeinerung von Länge/Fläche/Volumen), das Zählmaß, das Dirac-Maß, Wahrscheinlichkeitsmaße in der Stochastik sowie das Hausdorff-Maß in der geometrischen Maßtheorie. Signierte Maße lassen auch negative Werte zu und stehen über den Satz von Radon-Nikodým in enger Beziehung zu Integralen.
