Screen Scraping

Screen Scraping (englisch für „Bildschirm abkratzen“) bezeichnet das automatisierte Auslesen von Daten, die eigentlich zur Darstellung für menschliche Nutzer bestimmt sind. Im Kontext des Internets spricht man überwiegend von Web Scraping: Programme rufen Webseiten ab und extrahieren aus dem HTML-Code gezielt Informationen wie Preise, Produktdaten oder Nachrichten.

Verfahren

Beim Web Scraping sendet ein Programm Anfragen an einen Webserver, lädt die ausgelieferten Dokumente und wertet sie mithilfe von Parsern aus. Für dynamische Webseiten werden häufig „Headless Browser“ eingesetzt, die die Seite vollständig ausführen. Die extrahierten Daten werden in strukturierter Form, etwa in Datenbanken oder Tabellen, weiterverarbeitet.

Ursprüngliche Bedeutung

Der Begriff stammt aus der Zeit der Großrechner: Programme lasen Daten aus den Bildschirmmasken von Terminal-Anwendungen aus, um sie in andere Systeme zu übernehmen – eine Notlösung, wenn keine Programmierschnittstelle (API) zur Verfügung stand. In dieser Form wird Screen Scraping auch heute noch zur Integration von Altsystemen verwendet.

Rechtliche und praktische Aspekte

Das automatisierte Auslesen fremder Webseiten kann gegen Nutzungsbedingungen, Urheberrecht oder Datenschutzrecht verstoßen; die Rechtslage ist je nach Land und Anwendungsfall unterschiedlich. Webseitenbetreiber setzen zum Schutz vor übermäßigem Scraping unter anderem die Datei robots.txt, Ratenbegrenzungen und Captchas ein. Legitime Anwendungen sind unter anderem Preisvergleiche, wissenschaftliche Datenerhebungen und Suchmaschinen.
