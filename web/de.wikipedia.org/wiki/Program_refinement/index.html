Die Programmverfeinerung (englisch program refinement) ist eine Technik der formalen Softwareentwicklung. Ein Programm oder eine Spezifikation wird schrittweise in eine konkretere Version überführt, die alle wesentlichen Eigenschaften der ursprünglichen Version bewahrt, aber näher an einer ausführbaren Implementierung liegt. Der Verfeinerungsprozess ist abgeschlossen, wenn die Spezifikation vollständig in ausführbaren Code überführt wurde.

Verfeinerungskalkül

Der Verfeinerungskalkül (engl. refinement calculus) ist ein formales System für die Ableitung und Verifikation von Programmen. Er wurde ab den 1980er Jahren von Ralph-Johan Back, Carroll Morgan, J. Morris und anderen entwickelt. Im Verfeinerungskalkül werden Spezifikationen und Programme in derselben Sprache ausgedrückt, sodass der Übergang von der Spezifikation zum Programm als eine Kette beweisbarer Verfeinerungsschritte erfolgt.

Verfeinerung und Daten

Neben der Verfeinerung von Algorithmen gibt es die Datenverfeinerung, bei der abstrakte Datentypen durch konkrete Datenstrukturen ersetzt werden. Beide Formen treten in der Praxis häufig gemeinsam auf.

Verwandte Verfahren

  • Stepwise Refinement: Die schrittweise Zerlegung eines Problems nach Niklaus Wirth, ein älteres, informelleres Verfahren strukturierter Programmierung.
  • B-Methode und Event-B: Formale Methoden, die Verfeinerung als zentralen Mechanismus nutzen, entwickelt von Jean-Raymond Abrial.
