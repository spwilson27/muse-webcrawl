Azure Kubernetes Service

Azure Kubernetes Service (AKS) ist ein verwalteter Dienst von Microsoft zur Bereitstellung und zum Betrieb von Kubernetes-Clustern in der Cloud-Plattform Microsoft Azure. Er wurde 2017 vorgestellt und ist seit 2018 allgemein verfügbar.

Funktionsweise

AKS übernimmt den Betrieb der Kubernetes-Steuerungsebene (Control Plane), sodass Anwender sich auf die Verwaltung der Arbeitsknoten (Nodes) und ihrer Container-Anwendungen konzentrieren können. Der Dienst vereinfacht Aufgaben wie Clusterbereitstellung, Skalierung, Aktualisierung und Überwachung.

Eigenschaften

  • automatische Upgrades und Patches der Kubernetes-Version,
  • horizontale und vertikale Skalierung von Knotenpools,
  • Integration in Azure Active Directory für rollenbasierte Zugriffskontrolle (RBAC),
  • Anbindung an Azure-Dienste wie Azure Monitor, Azure Container Registry und Azure Policy,
  • Unterstützung von Windows- und Linux-Containern in einem Cluster.

Einordnung

AKS gehört zu einer Reihe verwalteter Kubernetes-Angebote großer Cloud-Anbieter, zu denen auch Amazon Elastic Kubernetes Service (EKS) und Google Kubernetes Engine (GKE) zählen. Kubernetes selbst ist ein Open-Source-System zur Orchestrierung von Containern, das ursprünglich von Google entwickelt wurde und von der Cloud Native Computing Foundation gepflegt wird.
