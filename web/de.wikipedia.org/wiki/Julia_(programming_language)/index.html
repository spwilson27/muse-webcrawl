Julia (Programmiersprache)

Julia ist eine dynamische, höhere Programmiersprache, die vor allem für numerisches und wissenschaftliches Rechnen entwickelt wurde. Sie wurde 2012 veröffentlicht und als Version 1.0 im August 2018 freigegeben. Julia verbindet eine einfache, ausdrucksstarke Syntax mit einer Ausführungsgeschwindigkeit, die der von statisch kompilierten Sprachen wie C nahekommen kann.

Eigenschaften

Julia nutzt einen Just-in-time-Compiler auf Basis von LLVM. Zentrale Konzepte sind multiples Dispatch (Mehrfachverteilung), ein mächtiges Typsystem mit parametrischen Typen und die Möglichkeit, Code aus anderen Sprachen wie C und Fortran ohne Zwischenschicht aufzurufen. Die Sprache eignet sich für Datenanalyse, maschinelles Lernen, Simulationen und Hochleistungsrechnen.

Entwicklung

Die Entwicklung begann 2009 durch Jeff Bezanson, Stefan Karpinski, Viral B. Shah und Alan Edelman am MIT. Julia steht unter der MIT-Lizenz und verfügt über ein wachsendes Ökosystem von Paketen, die über den integrierten Paketmanager verwaltet werden.
