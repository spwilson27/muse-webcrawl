Document Type Definition

Eine Document Type Definition (DTD) ist ein Regelsatz, der Bau und Vokabular einer Klasse von SGML- oder XML-Dokumenten festlegt. Sie deklariert, welche Elemente und Attribute in einem Dokument vorkommen dürfen, wie sie verschachtelt werden können und welche Entitäten definiert sind. Ein Dokument, das den Regeln seiner DTD entspricht, heißt „gültig“ (valid).

Bestandteile

Eine DTD besteht aus Deklarationen für Elemente (<!ELEMENT>), Attributlisten (<!ATTLIST>), Entitäten (<!ENTITY>) und Notationen (<!NOTATION>). Beispiel:

<!ELEMENT brief (absender, empfaenger, text)>
<!ELEMENT text (#PCDATA)>
<!ATTLIST brief datum CDATA #REQUIRED>

Die DTD kann intern – innerhalb der Dokumenttyp-Deklaration – oder extern als eigene Datei angegeben werden.

Geschichte und Alternativen

DTDs stammen aus der SGML-Welt und wurden von XML 1.0 übernommen. Bekannte DTDs sind die der HTML-Versionen bis 4.01 sowie DocBook und TEI in älteren Fassungen. Da DTDs keine Datentypen und Namensräume unterstützen und eine eigene, nicht XML-basierte Syntax verwenden, werden sie in XML-Anwendungen häufig durch XML Schema (XSD) oder RELAX NG ersetzt.
