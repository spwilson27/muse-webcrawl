Moralisches Dilemma

Ein moralisches Dilemma (englisch moral dilemma, auch ethisches Dilemma) ist eine Situation, in der eine handelnde Person zwischen zwei oder mehreren Handlungsoptionen wählen muss, von denen jede eine moralische Pflicht oder einen moralischen Wert verletzt, sodass keine Option ohne moralischen Rest als richtig erscheint.

Begriff

In einem echten Dilemma stehen moralische Forderungen in einem unauflösbaren Konflikt: Was auch immer die Person tut, sie verletzt eine der Forderungen. Philosophisch wird diskutiert, ob echte moralische Dilemmata überhaupt existieren oder ob sich scheinbar widersprechende Pflichten letztlich in eine Rangordnung bringen lassen. Der Begriff der prima-facie-Pflicht von W. D. Ross beschreibt Pflichten, die grundsätzlich gelten, im Konfliktfall aber von stärkeren Pflichten überlagert werden können.

Bekannte Beispiele

Trolley-Problem

Das bekannteste moderne Beispiel ist das von Philippa Foot formulierte und von Judith Jarvis Thomson weiterentwickelte Trolley-Problem: Eine Straßenbahn rast auf fünf Personen zu. Durch Umlegen einer Weiche kann sie auf ein anderes Gleis gelenkt werden, auf dem sich eine Person befindet. Die Frage lautet, ob es erlaubt oder geboten ist, die Weiche umzulegen und so eine Person zu töten, um fünf zu retten. In der Variante des „Footbridge"-Falls müsste eine Person unmittelbar von einer Brücke gestoßen werden, um die Bahn zu stoppen — hier fällt die Intuition der meisten Befragten anders aus.

Sophies Entscheidung

In William Styrons Roman Sophies Entscheidung wird eine Mutter im Konzentrationslager gezwungen, eines ihrer beiden Kinder auszuwählen, das überleben darf; trifft sie keine Wahl, werden beide getötet.

Heinz-Dilemma

Lawrence Kohlberg benutzte das Heinz-Dilemma zur Untersuchung der moralischen Entwicklung: Ein Mann erwägt, ein lebensrettendes Medikament zu stehlen, das er sich nicht leisten kann.

Bedeutung

Moralische Dilemmata spielen eine zentrale Rolle in der angewandten Ethik, etwa in der Medizinethik, der Bioethik und der Ethik des autonomen Fahrens, sowie in der moralpsychologischen Forschung, wo Reaktionen auf Dilemmata experimentell untersucht werden.
