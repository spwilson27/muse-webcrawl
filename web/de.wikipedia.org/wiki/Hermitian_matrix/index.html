Hermitesche Matrix

Eine hermitesche Matrix ist in der Mathematik eine komplexe quadratische Matrix, die gleich ihrer konjugiert Transponierten ist. Benannt ist sie nach dem französischen Mathematiker Charles Hermite. Für eine Matrix A bedeutet dies A = AH, das heißt, die Einträge erfüllen aij = āji. Reelle symmetrische Matrizen sind der reelle Spezialfall hermitescher Matrizen.

Eigenschaften

Alle Eigenwerte einer hermiteschen Matrix sind reell. Zu verschiedenen Eigenwerten gehörende Eigenvektoren sind orthogonal, und jede hermitesche Matrix ist unitär diagonalisierbar (Spektralsatz). Die Diagonalelemente einer hermiteschen Matrix sind stets reell. Die Summe zweier hermitescher Matrizen ist wieder hermitesch.

Anwendungen

Hermitesche Matrizen spielen eine zentrale Rolle in der Quantenmechanik: Messbare Größen (Observable) werden dort durch hermitesche Operatoren beschrieben, deren Eigenwerte die möglichen Messwerte sind. Auch in der Signalverarbeitung und der numerischen linearen Algebra sind sie von großer Bedeutung.
