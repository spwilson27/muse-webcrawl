Diagonalisierbare Matrix

Eine quadratische Matrix heißt diagonalisierbar, wenn sie zu einer Diagonalmatrix ähnlich ist, wenn es also eine invertierbare Matrix S gibt, sodass S−1AS eine Diagonalmatrix ist. Äquivalent dazu besitzt die zugehörige lineare Abbildung eine Basis aus Eigenvektoren.

Charakterisierungen

Eine Matrix über einem Körper ist genau dann diagonalisierbar, wenn ihr Minimalpolynom in paarweise verschiedene Linearfaktoren zerfällt. Eine andere Charakterisierung nutzt die Eigenwerte: Die Matrix ist genau dann diagonalisierbar, wenn für jeden Eigenwert die algebraische Vielfachheit (als Nullstelle des charakteristischen Polynoms) mit der geometrischen Vielfachheit (Dimension des Eigenraums) übereinstimmt.

Beispiele

Jede symmetrische reelle Matrix ist diagonalisierbar, ebenso jede Matrix mit lauter verschiedenen Eigenwerten. Nicht diagonalisierbar ist dagegen eine Matrix mit einem Jordanblock der Größe größer als eins, etwa die Matrix mit den Einträgen 1 auf der Diagonalen und einer 1 rechts oberhalb der Diagonalen; sie besitzt nur einen Eigenvektor bis auf Vielfache.

Bedeutung

Diagonalisierbare Matrizen lassen sich rechnerisch besonders gut handhaben: Potenzen, Exponentialfunktionen und die Lösung zugehöriger Differentialgleichungen reduzieren sich auf Operationen mit den Eigenwerten. In der Quantenmechanik entspricht die Diagonalisierung eines Operators der Bestimmung seiner Messwerte.
