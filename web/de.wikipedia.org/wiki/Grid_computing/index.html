Grid-Computing

Grid-Computing (von englisch grid = „Gitter, Netz") bezeichnet ein Verfahren, bei dem Ressourcen vieler, oft räumlich verteilter und administrativ getrennter Computer – Prozessorleistung, Speicher und Daten – zu einem virtuellen Gesamtsystem zusammengeschlossen werden. Der Begriff lehnt sich an das Stromnetz (power grid) an: Rechenleistung soll so selbstverständlich verfügbar sein wie Strom aus der Steckdose.

Geschichte

Die Konzepte des Grid-Computing wurden in den 1990er-Jahren unter anderem von Ian Foster und Carl Kesselman formuliert, die auch das wegweisende Buch „The Grid: Blueprint for a New Computing Infrastructure" (1998) herausgaben. Einen frühen Vorläufer bildete das Metacomputing an verteilten Supercomputerzentren. Bedeutende Software war das Globus Toolkit.

Arten von Grids

  • Computational Grids bündeln Rechenleistung,
  • Data Grids verwalten verteilte Datenbestände,
  • Service Grids stellen Dienste über Institutionen hinweg bereit.

Anwendung

Bekannte Grid-Infrastrukturen sind das Worldwide LHC Computing Grid (WLCG) für die Auswertung der Daten des Large Hadron Collider am CERN sowie die European Grid Infrastructure (EGI). Von Grids abzugrenzen sind Freiwilligenprojekte wie SETI@home (Volunteer Computing) sowie das Cloud Computing, das viele Grid-Ideen kommerziell weiterführt, jedoch meist innerhalb eines Anbieters operiert.
