HMAC

HMAC
ArtMessage Authentication Code
Grundlagekryptographische Hashfunktion + geheimer Schlüssel
StandardRFC 2104, FIPS 198-1
EntwicklerBellare, Canetti, Krawczyk (1996)

HMAC (englisch für keyed-hash message authentication code) ist ein Verfahren zur Berechnung eines Message Authentication Codes mithilfe einer kryptographischen Hashfunktion und eines geheimen Schlüssels. Es dient der Sicherstellung von Integrität und Authentizität von Nachrichten: Nur wer den Schlüssel kennt, kann den korrekten Prüfwert erzeugen.

Konstruktion

HMAC verknüpft den Schlüssel durch zweimaliges Hashen mit zwei unterschiedlichen Füllwerten (inner pad und outer pad, hexadezimal 0x36 beziehungsweise 0x5c) mit der Nachricht: HMAC(K, m) = H((K′ ⊕ opad) ‖ H((K′ ⊕ ipad) ‖ m)). Diese Konstruktion schützt – anders als die naive Verkettung H(K ‖ m) – unter anderem gegen Längenerweiterungsangriffe auf Hashfunktionen der Merkle-Damgård-Bauart. HMAC lässt sich mit jeder iterierten Hashfunktion wie SHA-256 kombinieren; die Bezeichnung lautet dann etwa HMAC-SHA256.

Sicherheit

Die Sicherheit von HMAC ist formal bewiesen, solange die zugrunde liegende Kompressionsfunktion als Pseudozufallsfunktion modellierbar ist. Bemerkenswert ist, dass HMAC auch mit der als gebrochen geltenden Hashfunktion MD5 keine praktikablen Angriffe auf die MAC-Eigenschaft zulässt; dennoch wird für neue Anwendungen SHA-2 oder SHA-3 empfohlen.

Anwendungen

HMAC wird in zahlreichen Protokollen eingesetzt, etwa in IPsec, TLS, SSH, JSON Web Tokens (HS256) und als Baustein der Schlüsselableitungsfunktion HKDF sowie der Passwortableitung PBKDF2.
