Code Napoléon

Als Code Napoléon wird gemeinhin das französische Zivilgesetzbuch von 1804 bezeichnet, das unter der Ägide Napoleon Bonapartes entstand und dessen Namen zeitweise amtlich trug. Es ist eines der einflussreichsten Gesetzbücher der Neuzeit.

Geschichte

Vor 1804 war Frankreich rechtlich zweigeteilt: Im Norden galt überwiegend Gewohnheitsrecht (pays de droit coutumier), im Süden das geschriebene, römisch beeinflusste Recht (pays de droit écrit). Die Revolutionsregierungen hatten vergeblich versucht, diese Vielfalt zu vereinheitlichen. Erst Napoleon trieb die Kodifikation durch eine Kommission aus Tronchet, Portalis, Bigot de Préameneu und Maleville zum Erfolg; 1804 wurden die Teilgesetze zum Code civil des Français zusammengeführt.

Ausbreitung

Der Code wurde in den von Frankreich besetzten oder beeinflussten Gebieten eingeführt, darunter das Rheinland, die Niederlande, Belgien, Italien und Polen. Er wirkte auf das deutsche Badische Landrecht, auf Gesetzbücher in Lateinamerika, im Nahen Osten und in Louisiana. Mit dem Code pénal (1810) und weiteren „Cinq codes" bildete er den Kern der napoleonischen Gesetzgebung.
