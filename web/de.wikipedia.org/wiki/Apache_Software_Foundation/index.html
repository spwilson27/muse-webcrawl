Apache Software Foundation

Apache Software Foundation
Gründung: 1999
Sitz: Forest Hill, Maryland, USA
Rechtsform: Non-Profit-Organisation (501(c)(3))
Zweck: Förderung freier Software

Die Apache Software Foundation (ASF) ist eine gemeinnützige Organisation zur Förderung von Open-Source-Softwareprojekten. Sie wurde im Juni 1999 von der Apache Group gegründet, der Entwicklergruppe des Apache HTTP Servers, und ist als 501(c)(3)-Organisation in den Vereinigten Staaten registriert.

Organisation und Arbeitsweise

Die ASF versteht sich als Meritokratie: Wer sich durch Beiträge verdient macht, erhält Committer-Rechte und kann später Mitglied der Stiftung werden. Jedes Projekt wird von einem Project Management Committee (PMC) weitgehend eigenständig geleitet; ein von den Mitgliedern gewählter Vorstand (Board of Directors) überwacht die Stiftung. Neue Projekte durchlaufen zunächst den Apache Incubator, in dem sie die Arbeitsweisen der Stiftung – offene Entwicklung, Gemeinschaft um Code herum, Lizenzpraxis („the Apache Way") – übernehmen. Alle Projekte der Stiftung erscheinen unter der Apache-Lizenz 2.0. Getragen wird die Arbeit fast vollständig von ehrenamtlichen Freiwilligen auf der ganzen Welt; finanziert wird die Stiftung durch Sponsoren und Spenden.

Projekte

Die Stiftung beherbergt mehrere hundert Projekte und Unterprojekte. Zu den bekanntesten gehören neben dem HTTP Server: Tomcat, Hadoop, Spark, Kafka, Cassandra, Maven, Ant, Lucene/Solr, OpenOffice, Groovy, Subversion und Airflow.
