Operatorüberladung

Operatorüberladung (englisch operator overloading) bezeichnet in der Programmierung die Möglichkeit, einem Operator wie +, == oder [] für benutzerdefinierte Datentypen eine eigene Bedeutung zu geben. Das Konzept wurde unter anderem durch C++, C#, Python, Ruby und Haskell bekannt.

Grundlagen

Normalerweise sind Operatoren für eingebaute Typen definiert, etwa die Addition von Zahlen. Durch Überladung kann derselbe Operator auch auf komplexe Zahlen, Vektoren, Strings oder eigene Klassen angewendet werden. In C++ geschieht dies über eine spezielle Funktion operator+, in Python über magische Methoden wie __add__.

Vorteile und Kritik

Befürworter sehen darin eine natürlichere, lesbarere Syntax, besonders in Mathematik und Wissenschaft. Kritiker warnen vor Missverständlichkeit, wenn ein Operator eine unerwartete oder teure Operation auslöst. Sprachen wie Java verzichten bewusst auf freie Operatorüberladung, Go erlaubt sie gar nicht.
