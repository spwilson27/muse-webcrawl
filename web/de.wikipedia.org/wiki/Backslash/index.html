Rückstrich

Der Rückstrich oder Backslash (englisch backslash) ist ein Schriftzeichen, das als umgekehrter Schrägstrich „\" dargestellt wird. Er ist vom gewöhnlichen Schrägstrich „/" zu unterscheiden und im ASCII-Zeichensatz auf Position 92 (hexadezimal 5C) zu finden. Im Unicode belegt er den Codepunkt U+005C.

Verwendung in der Informatik

In DOS und Windows dient der Rückstrich als Trennzeichen in Dateipfaden (z. B. C:\Users\Name). In vielen Programmiersprachen wie C, Java oder Python wird er als Escape-Zeichen verwendet, um Sonderzeichen einzuleiten, etwa \n für einen Zeilenumbruch oder \t für einen Tabulator. In TeX und LaTeX beginnen Befehle mit einem Backslash. In regulären Ausdrücken dient er ebenfalls der Maskierung von Metazeichen.

Weitere Verwendungen

In der Mengenlehre steht der Rückstrich gelegentlich für die Differenzmenge. In einigen Währungskontexten und auf japanischen Tastaturen wird an der Position des Backslash das Yen-Zeichen dargestellt, was auf historische Zeichensatzunterschiede zurückgeht.
