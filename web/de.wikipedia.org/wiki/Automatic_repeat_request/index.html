Automatic Repeat Request

Automatic Repeat Request (ARQ, deutsch „automatische Wiederholungsanforderung") bezeichnet eine Klasse von Verfahren zur Fehlerkorrektur in der digitalen Datenübertragung. Erkennt der Empfänger anhand einer Prüfsumme einen fehlerhaft übertragenen Datenblock, fordert er automatisch dessen erneute Sendung an.

Verfahren

Man unterscheidet vor allem drei ARQ-Varianten:

  • Stop-and-Wait-ARQ: Der Sender wartet nach jedem Block auf eine Empfangsbestätigung (ACK) oder eine Wiederholungsanforderung (NAK), bevor er den nächsten Block sendet.
  • Go-Back-N-ARQ: Der Sender darf mehrere Blöcke ohne Bestätigung senden; bei einem Fehler werden der fehlerhafte und alle folgenden Blöcke wiederholt.
  • Selective Repeat ARQ: Nur der fehlerhafte Block wird erneut gesendet; korrekt empfangene Folgeblöcke werden zwischengespeichert.

Hybrid-ARQ

Beim Hybrid-ARQ (HARQ) wird die Wiederholungsanforderung mit einer Vorwärtsfehlerkorrektur (FEC) kombiniert. HARQ wird unter anderem in den Mobilfunkstandards UMTS und LTE eingesetzt.

Anwendung

ARQ-Prinzipien stecken unter anderem in der Sicherungsfunktion des TCP-Protokolls sowie in zahlreichen Funk- und Satellitenverbindungen.
