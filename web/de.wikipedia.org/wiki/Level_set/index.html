Niveaumenge

Eine Niveaumenge oder Höhenmenge (englisch level set) ist in der Mathematik die Menge aller Punkte im Definitionsbereich einer Funktion, an denen die Funktion einen vorgegebenen konstanten Wert annimmt. Für eine Funktion f: ℝn → ℝ und einen Wert c lautet sie:

Lc(f) = { (x1, …, xn) | f(x1, …, xn) = c }


Höhenlinien einer Funktion zweier Variablen (Platzhalter)

Spezialfälle

Bei Funktionen zweier Variablen sind die Niveaumengen Kurven, die man als Höhenlinien oder Konturlinien kennt – etwa auf topographischen Karten oder als Isobaren und Isothermen in der Meteorologie. Bei Funktionen dreier Variablen sind die Niveaumengen Flächen (Äquipotentialflächen in der Physik).

Eigenschaften

Nach dem Satz über implizite Funktionen sind Niveaumengen an Stellen mit nicht verschwindendem Gradienten glatte Mannigfaltigkeiten der Dimension n−1. Der Gradient von f steht senkrecht auf der Niveaumenge. Kritische Punkte, an denen der Gradient verschwindet, können zu singulären Niveaumengen führen, etwa sich selbst schneidenden Kurven.

Anwendungen

Niveaumengen sind grundlegend für die Optimierung mit Nebenbedingungen (Lagrange-Multiplikatoren), die Beschreibung von Potentialflächen in der Physik und die Level-Set-Methode, in der eine bewegte Grenzfläche als Nullniveaumenge einer Hilfsfunktion verfolgt wird.
