Unmögliches Objekt

Ein unmögliches Objekt ist eine optische Täuschung: eine zweidimensionale Figur, die vom visuellen System als dreidimensionales Objekt interpretiert wird, das in der Realität so nicht existieren kann.

Beispiele

Berühmte Beispiele sind das Penrose-Dreieck (Tribar), die Penrose-Treppe, der Blivet (Teufelsgabel) und die Necker-Würfel-Varianten. M. C. Escher nutzte unmögliche Objekte in Lithografien wie Wasserfall.

Entstehung

Der schwedische Künstler Oscar Reutersvärd zeichnete 1934 das erste unmögliche Dreieck; Roger Penrose und sein Vater Lionel Penrose machten die Figuren in den 1950er Jahren populär.

Wahrnehmung

Das visuelle System interpretiert lokale Tiefenhinweise widerspruchsfrei, erkennt aber global einen Widerspruch – daher wirken die Figuren zugleich plausibel und absurd.
