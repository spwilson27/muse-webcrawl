Fallback-Schriftart

Eine Fallback-Schriftart (Ersatzschriftart) ist eine Schriftart, die ein Textverarbeitungssystem oder ein Browser verwendet, wenn eine angegebene Primärschrift ein benötigtes Zeichen nicht enthält oder selbst nicht verfügbar ist. Das Verfahren wird als font fallback bezeichnet.

Funktionsweise

In CSS wird mit der Eigenschaft font-family eine priorisierte Liste von Schriftarten angegeben, etwa eine spezielle Hausschrift, gefolgt von allgemeineren Alternativen und schließlich einer generischen Familie wie serif, sans-serif oder monospace. Fehlt ein Zeichen — etwa ein Sonderzeichen, ein Symbol oder Schriftzeichen einer anderen Schrift wie Chinesisch oder Arabisch — in der ersten Schrift, greift die Rendering-Engine zeichenweise auf die nächste Schrift der Liste zurück, die das Zeichen enthält.

Bedeutung

Font Fallback ist eine Grundlage mehrsprachiger Textdarstellung: Betriebssysteme wie Windows, macOS und Linux pflegen interne Fallback-Ketten, die für Unicode-Zeichen automatisch geeignete Schriften auswählen (unter Linux übernimmt dies fontconfig). Ohne Fallback-Mechanismen würden fehlende Zeichen als Platzhalter (etwa leere Rechtecke, „Tofu") dargestellt. Auch beim Webfont-Laden dient eine lokale Fallback-Schrift der lesbaren Darstellung, bevor die eigentliche Schriftart nachgeladen wurde.
