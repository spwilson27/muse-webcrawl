R-U-Dead-Yet

R-U-Dead-Yet (RUDY)
TypDoS-Angriffswerkzeug
ProtokollHTTP (POST)
AngriffsartSlow-Application-Layer-Angriff

R-U-Dead-Yet (abgekürzt RUDY) ist ein Werkzeug für Denial-of-Service-Angriffe auf der Anwendungsschicht von Webservern. Der Name ist eine spielerische Verkürzung von „Are you dead yet?“ (englisch für „Bist du schon tot?“).

Funktionsweise

RUDY durchsucht eine Website nach Webformularen und sendet anschließend formal gültige HTTP-POST-Anfragen mit einer sehr großen angegebenen Inhaltslänge (Content-Length), überträgt die Daten aber extrem langsam – beispielsweise byteweise in großen Zeitabständen. Der Server hält die Verbindung offen und wartet auf die angekündigten Daten, sodass seine Verbindungsressourcen blockiert werden, ohne dass auffällig viel Datenverkehr entsteht. Der Angriff gehört daher zur Klasse der „Slow“- beziehungsweise Low-and-Slow-Angriffe, zu denen auch das bekanntere Werkzeug Slowloris zählt.

Gegenmaßnahmen

Abwehrmaßnahmen umfassen Zeitlimits für das vollständige Eintreffen von Anfragen, Begrenzung gleichzeitiger Verbindungen pro Client sowie spezialisierte Filter und Reverse-Proxys.
