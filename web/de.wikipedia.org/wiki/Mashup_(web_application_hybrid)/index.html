Mashup (Webanwendung)

Ein Mashup ist eine Webanwendung, die Inhalte und Funktionen aus mehreren unabhängigen Quellen über offene Schnittstellen (APIs) kombiniert und daraus einen neuen Mehrwert schafft. Mashups gelten als ein Kennzeichen des Web 2.0.

Prinzip

Ein klassisches Beispiel ist die Einbindung von Kartendiensten wie Google Maps, auf denen zusätzliche Daten – etwa Immobilienangebote, Wetterinformationen oder Standorte von Fotos – dargestellt werden. Die Daten stammen von verschiedenen Anbietern und werden im Browser des Nutzers oder auf einem Server zusammengeführt.

Technologien

Grundlage sind offene Web-APIs, Datenformate wie XML und JSON sowie Techniken wie Ajax, RSS und REST. Werkzeuge wie Yahoo Pipes oder Microsoft Popfly erlaubten zeitweise auch Nicht-Programmierern, Mashups per Baukasten zu erstellen.

Typen

Man unterscheidet unter anderem Karten-Mashups, Video- und Foto-Mashups, Shopping- und Such-Mashups sowie Unternehmens-Mashups, die interne und externe Daten für Geschäftsprozesse kombinieren.
