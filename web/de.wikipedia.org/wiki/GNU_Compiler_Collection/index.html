GNU Compiler Collection

Die GNU Compiler Collection (GCC) ist eine Sammlung freier Compiler für zahlreiche Programmiersprachen, darunter C, C++, Objective-C, Fortran, Ada, Go und D. Sie ist ein Schlüsselprojekt des GNU-Projekts und der Standardcompiler der meisten Linux-Distributionen. Die erste Version veröffentlichte Richard Stallman 1987; damals stand GCC noch für „GNU C Compiler“.

Architektur

GCC ist modular aufgebaut: Sprachspezifische Frontends übersetzen den Quelltext in eine gemeinsame Zwischendarstellung (GENERIC/GIMPLE), die optimiert und anschließend von einem Backend in Maschinencode für die Zielarchitektur überführt wird. Unterstützt werden unter anderem x86, ARM, RISC-V, PowerPC und viele eingebettete Plattformen; GCC kann auch als Cross-Compiler gebaut werden.

Bedeutung

Mit GCC wurden und werden große Teile der freien Softwarewelt übersetzt, darunter der Linux-Kernel (der allerdings inzwischen auch mit Clang gebaut werden kann). Die Sammlung steht unter der GNU General Public License und wird von einer weltweiten Entwicklergemeinschaft gepflegt; die Freigabekoordination obliegt einem Lenkungsausschuss.
