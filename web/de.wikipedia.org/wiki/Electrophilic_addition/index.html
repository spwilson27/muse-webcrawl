Elektrophile Addition


Addition von Brom an eine Doppelbindung.

Die elektrophile Addition (Abkürzung AE) ist ein Reaktionsmechanismus der organischen Chemie, bei dem ein Elektrophil an eine Mehrfachbindung – meist eine C=C-Doppelbindung eines Alkens – addiert wird. Dabei wird die π-Bindung aufgebrochen und zwei neue σ-Bindungen entstehen.

Mechanismus

Die Reaktion verläuft in zwei Schritten:

  1. Die elektronenreiche π-Bindung greift das Elektrophil (E+) an. Es entsteht ein Carbokation als Zwischenstufe.
  2. Ein Nukleophil (Nu−) greift das Carbokation an und bildet das Additionsprodukt.

Die Orientierung der Addition folgt häufig der Markownikow-Regel: Das Elektrophil lagert sich so an, dass das stabilere Carbokation entsteht. Bei der Bromierung wird statt eines offenen Carbokations ein zyklisches Bromonium-Ion durchlaufen, was zu einer anti-Addition führt.

Beispiele

  • Addition von Halogenen (Br2, Cl2) an Alkene
  • Hydrohalogenierung mit HBr oder HCl
  • Säurekatalysierte Hydratisierung zu Alkoholen
  • Addition von Halogenwasserstoffen und Schwefelsäure
