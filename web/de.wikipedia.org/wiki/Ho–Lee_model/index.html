Ho-Lee-Modell

Das Ho-Lee-Modell ist ein Zinsstrukturmodell der Finanzmathematik zur Bewertung von Zinsderivaten. Es wurde 1986 von Thomas Ho und Sang-bin Lee vorgestellt und war das erste arbitragefreie Modell, das an die anfängliche Zinsstrukturkurve angepasst werden kann.

Modellbeschreibung

Im Ho-Lee-Modell wird der kurzfristige Zinssatz (short rate) als normalverteilter Prozess modelliert: drt = θ(t)dt + σdWt. Dabei ist σ eine konstante Volatilität, Wt ein Wiener-Prozess und θ(t) eine zeitabhängige Funktion, die so kalibriert wird, dass das Modell die beobachtete anfängliche Zinsstruktur exakt reproduziert.

Eigenschaften

Da der Prozess keine Mean-Reversion enthält und normalverteilt ist, können die modellierten Zinssätze negativ werden, was lange als Nachteil galt. Anleihepreise lassen sich im Ho-Lee-Modell in geschlossener Form angeben. Das Modell bildete die Grundlage für zahlreiche Weiterentwicklungen, darunter das Hull-White-Modell, das eine Mean-Reversion ergänzt.
