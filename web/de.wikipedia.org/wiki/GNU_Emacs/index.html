GNU Emacs

GNU Emacs ist ein erweiterbarer, anpassbarer Texteditor und das älteste noch gepflegte Projekt des GNU-Projekts. Die erste Version veröffentlichte Richard Stallman 1985; die Ursprünge reichen auf den Editor Emacs zurück, den Stallman und Guy Steele bereits 1976 am MIT entwickelten. Der Name wird oft als „Editor Macros“ gedeutet.

Konzept

Der Kern von Emacs ist ein Interpreter für Emacs Lisp, einen Dialekt der Programmiersprache Lisp. Der Großteil der Editorfunktionalität ist selbst in dieser Sprache geschrieben, sodass Nutzer den Editor nahezu beliebig erweitern und umgestalten können. Dadurch wuchs Emacs weit über einen Texteditor hinaus: Es gibt Modi und Pakete zum Programmieren für fast alle Sprachen, E-Mail- und News-Clients (Gnus), einen Dateimanager (Dired), eine Shell, Kalender, Organisationswerkzeug (Org-mode) und sogar Spiele.

Verbreitung

Emacs läuft auf GNU/Linux, macOS, Windows und anderen Systemen, sowohl grafisch als auch im Terminal. Zusammen mit vi bzw. Vim gehört er zu den ältesten noch verbreiteten Editoren; die jahrzehntelange Rivalität der Anhängerschaften wird scherzhaft als „Editorkrieg“ bezeichnet.
