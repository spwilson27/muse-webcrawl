Copy elision

Copy elision (deutsch etwa „Kopierelision“) bezeichnet eine vom C++-Standard erlaubte Optimierung, bei der der Compiler den Aufruf von Kopier- oder Verschiebekonstruktoren auslassen darf, wenn er ein ansonsten notwendiges temporäres Objekt gleich an seinem Zielort erzeugt.

Hintergrund

Die Optimierung umfasst insbesondere die Rückgabewertoptimierung (return value optimization, RVO) sowie die Initialisierung eines Objekts aus einem Temporärwert. Bis C++14 war die Elision lediglich erlaubt, aber nicht garantiert; der weggelassene Konstruktor musste gleichwohl existieren und zugänglich sein. Mit C++17 wurde die Elision für sogenannte Prvalue-Ergebnisse verbindlich vorgeschrieben, was unter anderem die Rückgabe nicht kopierbarer und nicht verschiebbarer Typen aus Funktionen ermöglicht.

Beispiel

Gibt eine Funktion ein Objekt als Wert zurück und übergibt der Aufrufer dieses Ergebnis unmittelbar an eine Initialisierung, kann das Objekt direkt im Zielspeicher entstehen; die Zwischenkopie entfällt vollständig.
