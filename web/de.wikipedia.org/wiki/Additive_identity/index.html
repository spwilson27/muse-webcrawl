Neutrales Element der Addition

Das neutrale Element der Addition (englisch additive identity) ist in einer additiv geschriebenen algebraischen Struktur ein Element e mit der Eigenschaft, dass für alle Elemente a gilt: a + e = e + a = a. In den üblichen Zahlbereichen ist dieses Element die Zahl Null (0).

Beispiele

  • In den ganzen, rationalen, reellen und komplexen Zahlen ist 0 das neutrale Element der Addition.
  • In einem Vektorraum ist der Nullvektor das neutrale Element bezüglich der Vektoraddition.
  • Bei Matrizen ist die Nullmatrix das neutrale Element der Matrizenaddition.
  • In der Kategorie der Mengen ist die leere Menge das neutrale Element der disjunkten Vereinigung.

Eigenschaften

Das neutrale Element einer Verknüpfung ist, sofern es existiert, eindeutig bestimmt. In einer Gruppe existiert zu jedem Element genau ein inverses Element; das Inverse des neutralen Elements ist es selbst. Das neutrale Element der Addition ist nicht mit dem neutralen Element der Multiplikation (der Eins) zu verwechseln; in einem Ring gilt a · 0 = 0 für alle a.
