Fundierungsaxiom

Das Fundierungsaxiom (auch Regularitätsaxiom, englisch axiom of regularity oder axiom of foundation) ist ein Axiom der Zermelo-Fraenkel-Mengenlehre. Es besagt, dass jede nichtleere Menge x ein Element y besitzt, das mit x kein gemeinsames Element hat:

∀x (x ≠ ∅ → ∃y (y ∈ x ∧ x ∩ y = ∅))

Folgerungen

Aus dem Fundierungsaxiom folgt insbesondere, dass keine Menge sich selbst als Element enthalten kann und dass es keine unendlichen absteigenden Elementketten x0 ∋ x1 ∋ x2 ∋ … gibt. Alle Mengen lassen sich dadurch in der kumulativen Hierarchie (Von-Neumann-Hierarchie) anordnen, die durch transfinite Rekursion entlang der Ordinalzahlen aufgebaut ist.

Geschichte und Alternativen

Das Axiom geht auf Arbeiten von Dimitry Mirimanoff (1917) und John von Neumann (1925) zurück und wurde von Ernst Zermelo 1930 in die Mengenlehre aufgenommen. In nicht-fundierten Mengenlehren (etwa mit dem Anti-Fundierungsaxiom von Peter Aczel) werden dagegen Mengen mit Selbstzugehörigkeit zugelassen, was z. B. in der theoretischen Informatik Anwendung findet.
