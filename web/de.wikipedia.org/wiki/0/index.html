0

Die Null (0) ist die ganze Zahl, die zwischen der −1 und der 1 liegt. Sie ist das neutrale Element der Addition: Für jede Zahl a gilt a + 0 = a. Die Null ist weder positiv noch negativ und die einzige reelle Zahl mit dieser Eigenschaft.

Geschichte

Während die Babylonier und die Maya bereits Stellenwertsysteme mit einem Leerzeichen bzw. einem Zeichen für „nichts“ kannten, wurde die Null als eigenständige Zahl mit Rechenregeln erstmals in Indien systematisch verwendet; der Mathematiker Brahmagupta beschrieb 628 n. Chr. Regeln für das Rechnen mit der Null. Über die arabische Mathematik gelangte das Konzept nach Europa.

Eigenschaften

Die Multiplikation mit 0 ergibt immer 0; eine Division durch 0 ist nicht definiert. Die Null ist eine gerade Zahl, da sie durch 2 teilbar ist. In der Informatik dient 0 neben 1 als Grundsymbol des Binärsystems; in der Programmierung markiert sie häufig den Anfangswert oder einen Wahrheitswert „falsch“.
