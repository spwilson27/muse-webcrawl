Sérsic-Profil

Das Sérsic-Profil (auch Sérsic-Gesetz oder Sérsic-Modell) ist eine mathematische Funktion, die beschreibt, wie die Flächenhelligkeit einer Galaxie mit dem Abstand von ihrem Zentrum variiert. Es wurde 1963 von dem argentinischen Astronomen José Luis Sérsic eingeführt und ist heute das Standardmodell zur Beschreibung der Lichtverteilung von Galaxien.

Definition

Die Flächenhelligkeit I(R) im Abstand R vom Galaxienzentrum wird durch

I(R) = Ie · exp{ −bn [ (R/Re)1/n − 1 ] }

beschrieben. Dabei ist Ie die Flächenhelligkeit am Effektivradius Re, der die Hälfte des Gesamtlichts der Galaxie umschließt. Der Sérsic-Index n beschreibt die Form des Profils: Für n = 1 ergibt sich eine exponentielle Scheibe, wie sie für Spiralgalaxien typisch ist; n = 4 entspricht dem klassischen De-Vaucouleurs-Profil elliptischer Galaxien. Der Parameter bn ist eine von n abhängige Konstante, die näherungsweise bn ≈ 2n − 1/3 beträgt.

Anwendung

Sérsic-Profile werden bei der photometrischen Analyse von Galaxien in großen Himmelsdurchmusterungen routinemäßig angepasst. Der Sérsic-Index korreliert mit Masse, Konzentration und Morphologie der Galaxie und dient zur Unterscheidung von Scheiben- und sphäroidalen Komponenten (Bulge-Scheiben-Zerlegung). Erweiterungen des Modells beschreiben auch Balken, Ringe und Mehrkomponentensysteme.
