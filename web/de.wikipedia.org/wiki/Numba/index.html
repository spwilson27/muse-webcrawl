Numba

Numba ist ein Just-in-time-Compiler für Python, der numerischen Code – insbesondere Funktionen, die mit NumPy-Arrays arbeiten – in schnellen Maschinencode übersetzt. Er basiert auf der Compiler-Infrastruktur LLVM.

Arbeitsweise

Mithilfe des Dekorators @jit werden ausgewählte Python-Funktionen beim ersten Aufruf kompiliert. Numba unterstützt eine Teilmenge von Python und NumPy, parallele Schleifen sowie die Ausführung auf NVIDIA-GPUs über CUDA.

Anwendung

Numba wird in Wissenschaft und Datenanalyse eingesetzt, wenn schleifenlastiger Python-Code ohne Wechsel zu C oder Fortran beschleunigt werden soll.
