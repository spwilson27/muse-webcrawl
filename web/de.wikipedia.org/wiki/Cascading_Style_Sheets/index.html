Cascading Style Sheets

AbkürzungCSS
EntwicklerHåkon Wium Lie, Bert Bos, W3C
Erscheinungsjahr1996 (CSS1)
ArtStylesheet-Sprache

Cascading Style Sheets (englisch für „gestufte Gestaltungsbögen"), kurz CSS, ist eine Stylesheet-Sprache für elektronische Dokumente und zusammen mit HTML und JavaScript eine der Kerntechnologien des World Wide Web. Mit CSS werden Gestaltungsanweisungen erstellt, die vor allem im Zusammenspiel mit HTML und XML eingesetzt werden. CSS ermöglicht es, Inhalt und Darstellung eines Dokuments zu trennen.

Grundlagen

Eine CSS-Regel besteht aus einem Selektor und einem Deklarationsblock. Der Selektor bestimmt, welche Elemente eines Dokuments gestaltet werden, während die Deklarationen Eigenschaften wie Farbe, Schriftart, Abstände oder Position festlegen. Der Begriff „Cascading" (Kaskadierung) beschreibt, dass mehrere Regelquellen – Browser-Standardwerte, externe Stylesheets, interne Angaben und Inline-Stile – nach festen Prioritätsregeln miteinander verrechnet werden.

Geschichte

CSS wurde 1994 von Håkon Wium Lie vorgeschlagen und gemeinsam mit Bert Bos weiterentwickelt. Das World Wide Web Consortium (W3C) veröffentlichte 1996 die erste Empfehlung CSS1. CSS2 folgte 1998. Die dritte Generation, CSS3, ist in zahlreiche Module aufgeteilt, die unabhängig voneinander standardisiert werden und unter anderem Animationen, Übergänge, Flexbox und Grid-Layouts ermöglichen.

Beispiel

Die Regel p { color: blue; font-size: 14px; } stellt alle Absätze eines Dokuments in blauer Schrift mit einer Größe von 14 Pixeln dar.
