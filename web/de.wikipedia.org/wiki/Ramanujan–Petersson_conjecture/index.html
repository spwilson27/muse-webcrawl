Ramanujan-Petersson-Vermutung

Die Ramanujan-Petersson-Vermutung ist eine Aussage der Zahlentheorie über das Wachstum der Fourier-Koeffizienten von Modulformen. Sie geht auf eine Vermutung Srinivasa Ramanujans über die Tau-Funktion zurück und wurde von Hans Petersson auf allgemeine Spitzenformen verallgemeinert.

Aussage

Ramanujan vermutete 1916 für die Koeffizienten τ(n) der Diskriminantenfunktion die Schranke |τ(p)| ≤ 2·p^(11/2) für Primzahlen p. Petersson formulierte die entsprechende Aussage für Hecke-Eigenformen vom Gewicht k: Die n-ten Fourier-Koeffizienten wachsen höchstens wie n^((k−1)/2), bis auf einen beliebig kleinen Exponenten-Zuschlag.

Geschichte und Beweis

Erich Hecke und Louis Mordell bewiesen erste Fälle; André Weil übertrug das Problem auf die Vermutungen über Zetafunktionen von Kurven über endlichen Körpern. Den vollständigen Beweis für Modulformen lieferte schließlich Pierre Deligne 1974 als Anwendung seines Beweises der Weil-Vermutungen, wofür er 1978 die Fields-Medaille erhielt. Analoge Aussagen für automorphe Formen auf anderen Gruppen sind Gegenstand des Langlands-Programms; für allgemeine Fälle wie Maass-Formen ist die Vermutung bis heute offen.
