Zufällige Partition

Eine zufällige Partition (englisch random partition) ist in der Wahrscheinlichkeitstheorie eine zufällig gewählte Zerlegung einer Menge oder einer natürlichen Zahl. Der Begriff wird sowohl für zufällige Partitionen von Mengen (Aufteilungen in disjunkte nichtleere Teilmengen) als auch für zufällige ganzzahlige Partitionen (Zerlegungen einer Zahl n in eine Summe positiver ganzer Zahlen) verwendet.

Young-Diagramme zufälliger Partitionen der Zahl n für wachsendes n

Partitionen von Mengen

Für Mengenpartitionen ist der Chinesische Restaurant-Prozess ein bekanntes Erzeugungsmodell: Die Elemente werden nacheinander entweder einem bereits bestehenden Block zugeordnet oder beginnen einen neuen Block, wobei die Wahrscheinlichkeit für einen neuen Block von einem Parameter abhängt. Dieses Modell führt auf die Ewenssche Stichprobenformel und spielt eine wichtige Rolle in der bayesschen Statistik, etwa beim Dirichlet-Prozess, sowie in der Populationsgenetik.

Partitionen ganzer Zahlen

Bei den ganzzahligen Partitionen interessiert man sich unter anderem für die Gestalt einer gleichverteilt zufällig gewählten Partition von n, dargestellt als Young-Diagramm. Für große n nähert sich die reskalierte Form des Diagramms einer deterministischen Grenzkurve, die von Vershik und Kerov sowie unabhängig von Logan und Shepp bestimmt wurde; die Schwankungen um diese Kurve und die Verteilung des größten Summanden sind Gegenstand weiterer Forschung. Zufällige Partitionen treten außerdem im Zusammenhang mit Permutationen, Darstellungen der symmetrischen Gruppe und der statistischen Mechanik auf.
