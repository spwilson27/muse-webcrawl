Division durch null

Die Division durch null ist in der Mathematik nicht definiert. Während die Division zweier Zahlen a : b als diejenige Zahl c verstanden wird, für die c · b = a gilt, existiert für b = 0 keine solche Zahl: Ist a ≠ 0, so gibt es kein c mit c · 0 = a; ist a = 0, so erfüllt jede Zahl die Gleichung, das Ergebnis wäre also nicht eindeutig.

Begründung

In einem Körper wie den reellen Zahlen folgt aus den Körperaxiomen, dass 0 kein multiplikatives Inverses besitzt. Aus a · 0 = 0 für alle a ergibt sich unmittelbar, dass die Gleichung x · 0 = 1 unlösbar ist; ein Ausdruck wie 1/0 kann daher keinen Wert haben. Die Division wird deshalb nur für von null verschiedene Divisoren definiert.

Grenzwertbetrachtungen

In der Analysis betrachtet man Ausdrücke der Form f(x)/g(x) für g(x) → 0. Je nach Verhalten der Funktionen kann der Quotient gegen plus oder minus Unendlich streben, einen endlichen Grenzwert besitzen oder gar nicht konvergieren – ein Beleg dafür, dass der Division durch null kein eindeutiger Wert zugeordnet werden kann. In der projektiven Geometrie und auf der Riemannschen Zahlensphäre wird formal ein Punkt „unendlich" hinzugefügt; auch dort bleibt 0/0 undefiniert.

Informatik

In der Informatik führt eine ganzzahlige Division durch null nach dem Standard IEEE 754 bei Gleitkommazahlen zu den Werten +∞, −∞ oder NaN („not a number"), während eine ganzzahlige Division durch null in vielen Programmiersprachen eine Ausnahme (Exception) oder einen Programmabbruch auslöst.
