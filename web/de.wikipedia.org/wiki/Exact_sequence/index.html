Exakte Sequenz

Eine exakte Sequenz ist ein Begriff aus der abstrakten Algebra beziehungsweise homologischen Algebra. Sie bezeichnet eine Folge von Moduln (oder Gruppen beziehungsweise Objekten einer abelschen Kategorie) und Homomorphismen zwischen ihnen, bei der das Bild jeder Abbildung gleich dem Kern der nachfolgenden Abbildung ist.

Definition

Eine Sequenz A → B → C heißt exakt an der Stelle B, wenn im(f: A → B) = ker(g: B → C) gilt. Eine Sequenz, die an jeder Stelle exakt ist, heißt exakte Sequenz. Ist sie endlich und beginnt beziehungsweise endet mit dem Nullobjekt, spricht man von einer kurzen exakten Sequenz: 0 → A → B → C → 0. Darin ist die erste Abbildung injektiv, die letzte surjektiv, und B ist gewissermaßen aus A und C aufgebaut.

Eigenschaften und Beispiele

Kurze exakte Sequenzen beschreiben Erweiterungen: B ist eine Erweiterung von C um A. Ob eine solche Sequenz zerfällt (spaltet), hängt von der Kategorie ab; über Vektorräumen zerfällt jede kurze exakte Sequenz. Lange exakte Sequenzen entstehen in der Homologietheorie typischerweise aus kurzen exakten Sequenzen von Kettenkomplexen, etwa die lange exakte Homologiesequenz eines Raumpaars oder die Mayer-Vietoris-Sequenz in der algebraischen Topologie.

Bedeutung

Exakte Sequenzen sind ein zentrales Ausdrucksmittel der homologischen Algebra: Sie kodieren Beziehungen zwischen Objekten, ohne konkrete Elemente zu benennen, und erlauben es, Eigenschaften eines Objekts auf die anderen zu übertragen.
