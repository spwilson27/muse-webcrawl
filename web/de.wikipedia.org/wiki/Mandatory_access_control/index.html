Mandatory Access Control

Mandatory Access Control (MAC, deutsch „verbindliche Zugriffskontrolle“) ist ein Sicherheitsmodell der Informationstechnik, bei dem Zugriffe auf Ressourcen anhand zentral festgelegter Regeln und Sicherheitsetiketten (Labels) entschieden werden. Im Gegensatz zur Discretionary Access Control (DAC) kann der Eigentümer eines Objekts die Zugriffsrechte nicht selbst verändern.

Grundprinzip

Jedem Subjekt (Benutzer, Prozess) und jedem Objekt (Datei, Speicherbereich) wird eine Sicherheitsstufe zugeordnet, etwa aus einer hierarchischen Ordnung (nicht klassifiziert, vertraulich, geheim, streng geheim) kombiniert mit Kategorien (need-to-know). Das System erlaubt einen Zugriff nur, wenn die Sicherheitsrichtlinie dies für die Kombination der Etiketten zulässt.

Modelle

Das klassische formale Modell ist Bell-LaPadula, das Vertraulichkeit durch die Regeln „no read up“ (kein Lesen höher eingestufter Objekte) und „no write down“ (kein Schreiben in niedriger eingestufte Objekte) schützt. Das Biba-Modell adressiert umgekehrt die Integrität. Mehrstufige Sicherheit (Multi-Level Security, MLS) setzt MAC in militärischen und staatlichen Systemen ein.

Implementierungen

Bekannte Implementierungen sind SELinux und AppArmor unter Linux, Trusted Solaris sowie die MAC-Frameworks in FreeBSD. Auch moderne Systeme wie Android nutzen MAC-Mechanismen (SE for Android), um Anwendungen voneinander abzuschotten.
