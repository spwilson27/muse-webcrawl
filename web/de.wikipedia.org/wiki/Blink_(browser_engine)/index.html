Blink (Browser-Engine)

Blink ist eine freie Browser-Engine, die von Google und weiteren Beteiligten im Rahmen des Chromium-Projekts entwickelt wird. Sie entstand 2013 als Abspaltung (Fork) der Rendering-Komponente WebCore der Engine WebKit. Der Name ist eine Anspielung auf das früher verbreitete, nicht standardisierte HTML-Element <blink>.

Verwendung

Blink bildet zusammen mit der JavaScript-Engine V8 das Herzstück der Browser Google Chrome und Chromium. Auch viele andere Browser verwenden Blink, darunter Microsoft Edge (seit 2020), Opera, Brave und Vivaldi. Dadurch ist Blink die weltweit am weitesten verbreitete Browser-Engine.

Entwicklung

Google begründete die Abspaltung damit, die Mehrprozess-Architektur von Chromium einfacher umsetzen und WebKit von nicht benötigtem Code befreien zu können. Blink ist freie Software; Teile stehen unter der BSD-Lizenz, andere unter der GNU LGPL. Die Weiterentwicklung wird maßgeblich von Google gesteuert, was in Debatten über Standards und Marktmacht wiederholt kritisiert wird.
