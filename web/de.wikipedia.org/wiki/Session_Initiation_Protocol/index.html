Session Initiation Protocol

Das Session Initiation Protocol (SIP) ist ein Netzwerkprotokoll zum Aufbau, zur Steuerung und zum Abbau von Kommunikationssitzungen, das vor allem in der IP-Telefonie (Voice over IP) eingesetzt wird. Es wurde von der Internet Engineering Task Force (IETF) standardisiert, zunächst in RFC 2543 (1999) und später in der überarbeiteten Fassung RFC 3261 (2002).

Funktionsweise

SIP arbeitet auf der Anwendungsschicht des OSI-Modells und dient ausschließlich der Signalisierung, also dem Aushandeln der Sitzungsparameter. Die eigentlichen Mediadaten, etwa Sprache oder Video, werden dagegen typischerweise mit dem Real-Time Transport Protocol (RTP) übertragen. Die Beschreibung der Medienströme erfolgt meist mit dem Session Description Protocol (SDP), dessen Parameter im Nachrichtenkörper der SIP-Nachrichten transportiert werden.

SIP ist ein textbasiertes Protokoll, dessen Syntax an HTTP angelehnt ist. Die wichtigsten Anfragearten (Methoden) sind INVITE (Sitzungsaufbau), ACK (Bestätigung), BYE (Sitzungsabbau), CANCEL (Abbruch eines Aufbaus), REGISTER (Registrierung eines Endgeräts bei einem Server) und OPTIONS (Abfrage von Fähigkeiten).

Netzelemente

Zu den typischen Netzelementen einer SIP-Infrastruktur gehören User Agents (Endgeräte wie IP-Telefone oder Softphones), Proxy-Server, die Anfragen weiterleiten, Registrar-Server, die Registrierungen entgegennehmen, sowie Redirect-Server und Session Border Controller.

Verbreitung

SIP ist das am weitesten verbreitete Signalisierungsprotokoll für VoIP und bildet unter anderem die Grundlage des IP Multimedia Subsystem (IMS) in Mobilfunknetzen. Auch viele moderne Telefonanlagen und Anbieter von Internet-Telefonie setzen auf SIP.
