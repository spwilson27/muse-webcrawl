Java Card

Java Card ist eine Technologie, mit der kleine, in der Programmiersprache Java geschriebene Anwendungen (Applets) sicher auf Chipkarten und anderen eingebetteten Geräten mit stark begrenzten Ressourcen ausgeführt werden können. Sie wurde von Sun Microsystems entwickelt und wird heute von Oracle betreut.

Technik

Die Java Card Runtime Environment (JCRE) stellt eine stark abgespeckte virtuelle Maschine bereit, die einen Teil des Java-Bytecodes verarbeitet. Da Chipkarten nur über wenige Kilobyte Arbeitsspeicher verfügen, unterstützt die Sprache nur eine Teilmenge von Java; Applets werden am PC in sogenannte CAP-Dateien umgewandelt und auf die Karte geladen. Eine Firewall trennt die Applets voneinander, sodass mehrere Anwendungen sicher auf einer Karte koexistieren können.

Anwendungsgebiete

Java Card wird in Milliarden von Geräten eingesetzt, unter anderem in SIM-Karten von Mobiltelefonen, Bank- und Kreditkarten (EMV), elektronischen Ausweisdokumenten und Zugangssystemen.
