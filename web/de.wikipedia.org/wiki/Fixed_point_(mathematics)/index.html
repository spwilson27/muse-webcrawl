Fixpunkt (Mathematik)

In der Mathematik ist ein Fixpunkt einer Funktion ein Punkt, der von der Funktion auf sich selbst abgebildet wird. Für eine Funktion f gilt also: f(x) = x. Anschaulich entspricht ein Fixpunkt einer reellen Funktion einem Schnittpunkt ihres Graphen mit der Winkelhalbierenden des ersten und dritten Quadranten.

Beispiele

Die Kosinusfunktion besitzt genau einen Fixpunkt (etwa 0,739085), die sogenannte Dottie-Zahl. Die Quadratfunktion x → x² hat die Fixpunkte 0 und 1. Eine Drehung der Ebene um einen Punkt lässt genau diesen Punkt fest; eine Verschiebung besitzt dagegen keinen Fixpunkt.

Fixpunktsätze

Mehrere bedeutende Sätze der Mathematik garantieren unter bestimmten Voraussetzungen die Existenz von Fixpunkten. Der Fixpunktsatz von Banach besagt, dass eine Kontraktion auf einem vollständigen metrischen Raum genau einen Fixpunkt besitzt; er liefert zugleich ein Iterationsverfahren zu dessen Berechnung. Der Fixpunktsatz von Brouwer garantiert, dass jede stetige Abbildung einer abgeschlossenen Kugel auf sich selbst mindestens einen Fixpunkt hat. Weitere Sätze stammen von Schauder, Kakutani und Lefschetz.

Anwendungen

Fixpunktiterationen werden zur numerischen Lösung von Gleichungen eingesetzt. In der Informatik spielen Fixpunkte in der Semantik von Programmiersprachen und bei der Analyse rekursiver Definitionen eine Rolle. In der Wirtschaftswissenschaft beruht der Nachweis der Existenz von Gleichgewichten, etwa des Nash-Gleichgewichts, auf Fixpunktsätzen.

Attraktive und abstoßende Fixpunkte

Bei der Iteration einer Funktion kann ein Fixpunkt anziehend (attraktiv) sein, wenn benachbarte Startwerte gegen ihn konvergieren, oder abstoßend (repulsiv), wenn Iterationen sich von ihm entfernen. Dieses Verhalten ist Gegenstand der Theorie dynamischer Systeme.
