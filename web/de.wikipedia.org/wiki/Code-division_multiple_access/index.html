Codemultiplexverfahren

Das Codemultiplexverfahren (englisch Code Division Multiple Access, CDMA) ist ein Verfahren der Nachrichtentechnik, bei dem mehrere Teilnehmer gleichzeitig dasselbe Frequenzband nutzen, indem ihre Signale mit unterschiedlichen Spreizcodes codiert werden.

Prinzip

Jedes Nutzsignal wird mit einem teilnehmerspezifischen Code multipliziert, wodurch es über eine große Bandbreite gespreizt wird (Bandspreizverfahren, Direct Sequence Spread Spectrum). Der Empfänger kann das gewünschte Signal durch Korrelation mit demselben Code zurückgewinnen, während fremde Signale wie Rauschen wirken. Eine präzise Leistungsregelung ist nötig, um das Near-Far-Problem zu vermeiden.

Anwendungen

CDMA wurde unter anderem im Mobilfunkstandard cdma2000 (IS-95) sowie in Variante WCDMA im UMTS-Netz eingesetzt. Auch das Satellitennavigationssystem GPS nutzt CDMA, damit alle Satelliten auf derselben Frequenz senden können.
