Microsoft Exchange Server

Microsoft Exchange Server ist ein E-Mail- und Groupware-Server von Microsoft. Die erste Version erschien 1996. Exchange Server verwaltet E-Mails, Kalender, Kontakte und Aufgaben für Unternehmen und wird üblicherweise gemeinsam mit dem Clientprogramm Microsoft Outlook eingesetzt. Der Zugriff ist außerdem über den Webclient Outlook on the web sowie über Protokolle wie Exchange ActiveSync, MAPI und EWS möglich.

Editionen und Betrieb

Exchange Server wird traditionell auf eigener Hardware im Unternehmen betrieben (On-Premises). Daneben bietet Microsoft mit Exchange Online eine cloudbasierte Variante als Teil von Microsoft 365 an; die beiden Betriebsformen lassen sich in hybriden Bereitstellungen kombinieren. Zu den Funktionen gehören Datenbank-Verfügbarkeitsgruppen für Hochverfügbarkeit, Archivierung, Data Loss Prevention und Schutz vor Schadsoftware.

Geschichte

Wichtige Versionen waren unter anderem Exchange Server 2003, 2007, 2010, 2013, 2016 und 2019. Anfang 2021 wurde eine als „Hafnium“ bekannt gewordene Angriffswelle über mehrere Sicherheitslücken in lokalen Exchange-Servern öffentlich, die weltweit zahlreiche Organisationen betraf.
