Amazon EMR

Amazon EMR (früher Amazon Elastic MapReduce) ist eine verwaltete Big-Data-Plattform der Amazon Web Services (AWS). Sie ermöglicht die Verarbeitung großer Datenmengen mit Open-Source-Werkzeugen wie Apache Hadoop, Apache Spark, Apache HBase, Apache Flink und Presto auf Clustern aus EC2-Instanzen.

EntwicklerAmazon Web Services
Erstveröffentlichung2009
TypBig-Data-Plattform

Funktionsweise

EMR übernimmt die Bereitstellung, Konfiguration und Skalierung von Rechenclustern. Ein Cluster besteht aus einem Primärknoten, der die Arbeit koordiniert, Kernknoten, die Daten verarbeiten und im Hadoop Distributed File System (HDFS) speichern, sowie optionalen Taskknoten für reine Rechenleistung. Daten werden häufig aus Amazon S3 gelesen und dorthin zurückgeschrieben; mit EMR File System (EMRFS) kann S3 wie ein HDFS-Dateisystem angesprochen werden.

Cluster können dauerhaft betrieben oder nur für die Dauer eines Jobs gestartet und danach automatisch beendet werden. Mit Amazon EMR Serverless steht außerdem eine Variante ohne eigene Clusterverwaltung zur Verfügung, und EMR auf EKS erlaubt den Betrieb auf Amazon Elastic Kubernetes Service.

Anwendungsgebiete

Typische Einsatzgebiete sind die Analyse von Logdaten, wissenschaftliche Simulationen, Datenverarbeitung für maschinelles Lernen, Genomik sowie Extract-Transform-Load-Prozesse (ETL) in Data Lakes und Data Warehouses.

Geschichte

Der Dienst wurde im April 2009 unter dem Namen Amazon Elastic MapReduce vorgestellt und basierte zunächst auf dem MapReduce-Verfahren von Apache Hadoop. Mit der zunehmenden Verbreitung von Apache Spark und anderen Frameworks wurde das Angebot erweitert und schließlich in Amazon EMR umbenannt.
