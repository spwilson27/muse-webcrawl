Call by Reference

Call by Reference (deutsch „Übergabe per Referenz“, auch Referenzübergabe) ist ein Parameterübergabemechanismus in Programmiersprachen, bei dem einer Funktion nicht der Wert eines Arguments, sondern eine Referenz (Adresse) auf die Variable des Aufrufers übergeben wird. Änderungen am Parameter wirken sich daher unmittelbar auf die Variable des Aufrufers aus.

Beschreibung

Bei Call by Reference teilen sich Aufrufer und aufgerufene Funktion denselben Speicherplatz. Das ermöglicht es, mehrere Ergebnisse aus einer Funktion zurückzuliefern oder große Datenstrukturen zu übergeben, ohne sie zu kopieren. Zugleich können unbeabsichtigte Seiteneffekte entstehen, weil Schreibzugriffe der Funktion die Daten des Aufrufers verändern.

Sprachunterstützung

Explizite Referenzparameter kennen unter anderem Pascal (var-Parameter), C++ (Referenzen und Zeiger) und C# (ref/out). Sprachen wie Java und Python übergeben dagegen Werte – bei Objekten ist dieser Wert eine Referenz, was gelegentlich als „Call by Sharing“ bezeichnet wird und sich von echtem Call by Reference unterscheidet, da ein Neuzuweisen des Parameters die Variable des Aufrufers nicht verändert.

Vergleich

Demgegenüber steht Call by Value, bei dem eine Kopie des Wertes übergeben wird, sowie Call by Name, bei dem das Argument unausgewertet übergeben und bei Bedarf ausgewertet wird.
