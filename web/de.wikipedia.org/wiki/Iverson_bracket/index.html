Iverson-Klammer

Die Iverson-Klammer (englisch Iverson bracket) ist eine mathematische Notation, die eine Aussage in eine Zahl überführt. Für eine Aussage P ist definiert: [P] = 1, wenn P wahr ist, und [P] = 0, wenn P falsch ist. Die Notation wurde vom kanadischen Informatiker Kenneth E. Iverson, dem Entwickler der Programmiersprache APL, eingeführt und durch Donald E. Knuth popularisiert.

Verwendung

Iverson-Klammern vereinfachen Summen mit Bedingungen, da die Bedingung in den Summanden selbst aufgenommen werden kann. So lässt sich etwa die Anzahl der Teiler einer Zahl oder die Indikatorfunktion einer Menge kompakt schreiben: Die Indikatorfunktion 1A(x) entspricht der Klammer [x ∈ A]. Verwandte Notationen sind das Kronecker-Delta δij = [i = j] und das Signum über Vergleiche.

Beispiele

  • [3 < 5] = 1, [3 > 5] = 0
  • Summe der Primzahlen ≤ n als Σ [p prim] · p
  • Kronecker-Delta: δij = [i = j]
