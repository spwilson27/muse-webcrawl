Core Animation

Core Animation ist eine Grafik- und Animations-API von Apple für macOS und iOS. Sie wurde 2007 mit Mac OS X Leopard eingeführt und bildet die Grundlage der visuellen Darstellung und der Animationen in den Betriebssystemen des Unternehmens.

Konzept

Core Animation organisiert Inhalte in einer Baumstruktur aus Ebenen (Layer). Jede View besitzt eine zugeordnete Ebene, deren Eigenschaften wie Position, Größe, Transformation, Deckkraft und Inhalt animierbar sind. Änderungen an diesen Eigenschaften werden standardmäßig implizit animiert; für komplexere Abläufe stehen explizite Animationen über Klassen wie CABasicAnimation und CAKeyframeAnimation zur Verfügung.

Leistung

Das Rendern übernimmt ein separater Prozess, der die Ebenen auf der GPU zusammensetzt (Compositing). Dadurch bleiben Animationen auch bei Belastung der Hauptanwendung flüssig. Core Animation ist ein zentraler Baustein der Effekte in iOS, etwa beim Wechsel zwischen Apps und auf dem Home-Bildschirm.
