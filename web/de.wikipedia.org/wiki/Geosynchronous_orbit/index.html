Geosynchrone Umlaufbahn

Eine geosynchrone Umlaufbahn (englisch geosynchronous orbit, GSO) ist eine Erdumlaufbahn, deren Umlaufzeit genau einem Sterntag entspricht. Ein Satellit auf einer solchen Bahn kehrt nach jeweils einem Tag (relativ zu den Fixsternen) an dieselbe Position zurück. Im Gegensatz zur geostationären Umlaufbahn muss eine geosynchrone Bahn weder kreisförmig noch äquatorial sein.

Eigenschaften

Ist die Bahn geneigt oder exzentrisch, beschreibt der Satellit von der Erde aus gesehen eine periodische Bewegung um einen mittleren Punkt, etwa in Form einer Analemma-ähnlichen Acht (bei geneigter Kreisbahn). Satelliten auf geneigten geosynchronen Bahnen müssen von Bodenstationen nachgeführt werden.

Anwendungen

Geneigte geosynchrone Bahnen werden unter anderem für das japanische Navigationssystem QZSS genutzt, dessen Satelliten in Zenitbahnen („Quasi-Zenith“) lange über der Region Asien-Pazifik verweilen. Auch die Tundra-Bahn ist eine hoch exzentrische geosynchrone Bahn mit einer Inklination von etwa 63,4°.
