Network File System

Das Network File System (NFS) ist ein von Sun Microsystems entwickeltes Protokoll, das den transparenten Zugriff auf Dateien über ein Netzwerk ermöglicht. Ein NFS-Server stellt Verzeichnisse (Exports) bereit, die Clients in ihr lokales Dateisystem einhängen (mounten) können, sodass entfernte Dateien wie lokale erscheinen.

Geschichte und Versionen

NFS wurde 1984 vorgestellt. Die Version 2 arbeitete ursprünglich über UDP; NFSv3 (1995) brachte unter anderem Unterstützung für größere Dateien. Die aktuelle Version NFSv4 fasst zahlreiche Funktionen zusammen, darunter integrierte Sicherheit, Dateisperren und einen zustandsbehafteten Betrieb über eine einzige Verbindung.

Technik

NFS baut klassisch auf RPC (Remote Procedure Call) und der plattformunabhängigen Datendarstellung XDR auf. Es ist vor allem in der Unix- und Linux-Welt verbreitet und wird für Dateiserver, Virtualisierungsumgebungen und gemeinsame Benutzerverzeichnisse eingesetzt.
