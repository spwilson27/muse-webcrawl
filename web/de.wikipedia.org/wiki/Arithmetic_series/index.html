Arithmetische Reihe

Eine arithmetische Reihe ist die Summe der Glieder einer arithmetischen Folge. Man unterscheidet endliche arithmetische Reihen (Partialsummen) von der unendlichen Reihe, die für von null verschiedene Differenz stets divergiert.

Summenformel

Für die arithmetische Folge mit Anfangsglied a1 und Differenz d gilt für die Summe der ersten n Glieder:

Sn = a1 + a2 + … + an = (n/2) · (2a1 + (n − 1)d) = (n/2) · (a1 + an).

Die letzte Form besagt anschaulich: Die Summe ist das Produkt aus der Anzahl der Glieder und dem arithmetischen Mittel aus erstem und letztem Glied. Ein Spezialfall ist die Gaußsche Summenformel 1 + 2 + … + n = n(n + 1)/2, deren Werte die Dreieckszahlen liefern.

Herleitung

Schreibt man die Summe einmal vorwärts und einmal rückwärts untereinander, so ergibt jede Spalte denselben Wert a1 + an; das Doppelte der gesuchten Summe ist daher n(a1 + an).
