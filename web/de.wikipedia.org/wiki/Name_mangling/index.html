Name Mangling

Name Mangling (deutsch etwa „Namensverstümmelung“) bezeichnet in der Informatik ein Verfahren, bei dem Compiler den Namen einer Funktion, Methode oder Variablen systematisch verändern, um zusätzliche Informationen – etwa Parametertypen, Namensräume oder Klassen – in dem erzeugten Symbolnamen zu kodieren.

Motivation

Programmiersprachen wie C++ erlauben das Überladen von Funktionen: Mehrere Funktionen können denselben Namen tragen, sofern sie sich in ihren Parametern unterscheiden. Linker arbeiten jedoch traditionell mit eindeutigen Symbolnamen. Durch das Mangling erhält jede überladene Funktion einen eigenen, eindeutigen Maschinennamen, der die komplette Signatur enthält.

Verfahren

Das genaue Kodierungsschema ist compiler- und ABI-spezifisch. Die Itanium-C++-ABI, die unter Linux und anderen Systemen von GCC und Clang verwendet wird, kodiert beispielsweise die Funktion void f(int) im globalen Namensraum als _Z1fi. Microsoft Visual C++ verwendet ein abweichendes Schema, das mit einem Fragezeichen beginnt.

Demangling

Da veränderte Namen für Menschen schwer lesbar sind, stellen Werkzeuge wie c++filt oder Debugger Funktionen zum Rückumwandeln (Demangling) bereit. Um das Mangling für bestimmte Symbole zu unterbinden, wird in C++ die Deklaration extern "C" verwendet, etwa für Schnittstellen zur Sprache C.
