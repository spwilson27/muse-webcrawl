Dead Set

Dead Set ist eine britische Horror-Miniserie des Drehbuchautors und Satirikers Charlie Brooker aus dem Jahr 2008. Die fünfteilige Serie wurde auf dem Sender E4 ausgestrahlt und verbindet das Zombiegenre mit einer satirischen Auseinandersetzung mit Reality-TV.

Handlung

Während einer Live-Auszugsshow der Reality-Show Big Brother bricht in Großbritannien eine Zombieepidemie aus. Die Kandidaten im Big-Brother-Haus bemerken zunächst nichts von der Katastrophe draußen, während sich die Produktionscrew und die Zuschauer vor dem Studio in Zombies verwandeln. Die Produzentin Kelly und die verbliebenen Kandidaten versuchen im abgeschotteten Haus zu überleben.

Produktion und Rezeption

Die Serie wurde von Zeppotron produziert und zeigt unter anderem Davina McCall, die Moderatorin der realen britischen Big-Brother-Ausgaben, in einer Gastrolle als Zombie. Dead Set wurde von der Kritik gelobt und 2009 für einen BAFTA-Award nominiert. 2020 erschien mit Reality Z eine brasilianische Neuverfilmung.
