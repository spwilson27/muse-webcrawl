Nameserver

Ein Nameserver (englisch name server) ist ein Server, der Informationen zur Auflösung von Namen in Adressen bereithält. Am bekanntesten sind die Nameserver des Domain Name System (DNS) im Internet, die Domainnamen wie de.wikipedia.org in IP-Adressen übersetzen.

Arten von DNS-Nameservern

  • Autoritative Nameserver verwalten die Daten einer Zone verbindlich und beantworten Anfragen zu dieser Zone aus erster Hand.
  • Rekursive Resolver nehmen Anfragen von Clients entgegen, verfolgen die Auflösung über die DNS-Hierarchie und zwischenspeichern die Ergebnisse (Caching).
  • Root-Nameserver stehen an der Spitze der Hierarchie und verweisen auf die Server der Top-Level-Domains.

Funktionsweise

Ein Client sendet eine Anfrage an seinen Resolver. Ist die Antwort nicht im Cache vorhanden, fragt der Resolver zunächst einen Root-Server, dann den Server der Top-Level-Domain und schließlich den autoritativen Server der Zielzone. Die Gültigkeitsdauer von Datensätzen wird über die TTL (Time to Live) gesteuert.

Software

Verbreitete Nameserver-Programme sind BIND, NSD, Knot DNS, PowerDNS und Unbound.
