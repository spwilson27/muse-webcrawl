Boolescher Datentyp

Der boolesche Datentyp (kurz Boolean, nach George Boole) ist ein Datentyp der Informatik, dessen Werte nur „wahr“ (true) oder „falsch“ (false) sein können. Er dient der Darstellung von Aussagenwerten und ist die Grundlage für Verzweigungen und Schleifenbedingungen in Programmiersprachen.

Eigenschaften

Auf booleschen Werten sind die logischen Verknüpfungen UND, ODER und NICHT definiert, wie sie aus der booleschen Algebra bekannt sind. Vergleiche (etwa Gleichheit oder Größer-als-Relationen) liefern boolesche Werte als Ergebnis. Theoretisch genügt ein Bit zur Speicherung eines booleschen Werts; in der Praxis belegen boolesche Variablen aus Effizienzgründen häufig ein ganzes Byte oder mehr.

Verwendung in Programmiersprachen

Viele Programmiersprachen besitzen einen eigenen booleschen Typ, etwa Java (boolean), C++ (bool), Python (bool) oder Pascal (Boolean). In der Programmiersprache C gab es ursprünglich keinen booleschen Typ; Wahrheitswerte wurden durch Ganzzahlen dargestellt, wobei 0 als falsch und jeder andere Wert als wahr galt; erst mit C99 wurde der Typ _Bool eingeführt. In SQL kennt man dreiwertige Logik mit dem zusätzlichen Wert UNKNOWN.
