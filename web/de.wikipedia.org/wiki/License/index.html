License

License ist im amerikanischen Englisch die Schreibweise sowohl für das Substantiv als auch für das Verb, das eine Erlaubnis oder Genehmigung bezeichnet; im britischen Englisch wird das Substantiv licence geschrieben. Eine License ist ein von einer Behörde oder einem Rechteinhaber erteiltes Recht, eine ansonsten verbotene Handlung vorzunehmen beziehungsweise ein Schutzrecht zu nutzen.

Arten von Lizenzen

Zu den bekanntesten Lizenzarten zählen der Führerschein (driver's license), Berufszulassungen für Ärzte, Anwälte oder Piloten, Gewerbeerlaubnisse, Jagd- und Angelscheine sowie Ehelizenzen (marriage license). Im Bereich des geistigen Eigentums gestatten Lizenzen die Nutzung von Patenten, Marken, Urheberrechten und Software; bekannte Beispiele sind die GNU General Public License und andere Open-Source-Lizenzen sowie proprietäre Endbenutzer-Lizenzverträge (EULA).

Abgrenzung

Eine Lizenz unterscheidet sich von einem Zertifikat dadurch, dass sie eine rechtliche Erlaubnis darstellt, während ein Zertifikat lediglich die Erfüllung bestimmter Anforderungen bescheinigt. Der Entzug einer Lizenz kann bei Verstößen gegen die Lizenzbedingungen erfolgen.
