Regionalcode der DVD

Der Regionalcode (auch Ländercode oder RPC, Regional Playback Control) ist ein Verfahren der DVD, das die Abspielbarkeit einer DVD-Video auf bestimmte Weltregionen beschränkt. Er wurde auf Wunsch der Filmindustrie eingeführt, um Veröffentlichungszeitpunkte und Preise regional steuern zu können.

Umsetzung

Der Code ist sowohl auf der Disc als auch im Abspielgerät hinterlegt. Stimmen die Codes nicht überein, verweigert der Player die Wiedergabe. Bei DVD-Laufwerken in Computern (RPC-2) darf der Regionalcode höchstens fünfmal geändert werden; danach bleibt die letzte Einstellung fest gespeichert. Discs ohne Regionalbeschränkung und codefreie Player waren insbesondere im Importhandel verbreitet. Beim Nachfolgestandard Blu-ray wurde die Zahl der Regionen auf drei reduziert.
