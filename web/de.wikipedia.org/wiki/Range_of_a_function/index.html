Bild (Mathematik)

Das Bild einer Funktion (englisch range oder image) ist in der Mathematik die Menge aller Funktionswerte, die die Funktion annimmt. Für eine Funktion f: X → Y ist das Bild f(X) = { f(x) | x ∈ X } eine Teilmenge der Zielmenge Y. Stimmt das Bild mit der Zielmenge überein, heißt die Funktion surjektiv.

Begriffsabgrenzung

Der englische Begriff range wird uneinheitlich verwendet: In der englischsprachigen Literatur bezeichnet er teils die Zielmenge (codomain), teils das Bild (image). Im Deutschen unterscheidet man Zielmenge beziehungsweise Wertemenge im Sinne der Zielmenge vom Bild beziehungsweise der Bildmenge als der Menge der tatsächlich angenommenen Werte.

Bild einer Menge und Urbild

Allgemeiner definiert man für eine Teilmenge M ⊆ X das Bild f(M) = { f(x) | x ∈ M } sowie für eine Teilmenge N ⊆ Y das Urbild f−1(N) = { x ∈ X | f(x) ∈ N }. Bilder und Urbilder spielen in Mengenlehre, Topologie und Maßtheorie eine grundlegende Rolle.

Beispiel

Für die Funktion f(x) = x² mit Definitionsmenge ℝ und Zielmenge ℝ ist das Bild das Intervall [0, ∞), denn Quadrate reeller Zahlen sind niemals negativ; die Funktion ist daher nicht surjektiv.
