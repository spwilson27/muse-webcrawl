Säure-Base-Reaktion

Eine Säure-Base-Reaktion (englisch acid–base reaction) ist eine chemische Reaktion, bei der ein Protonenübergang von einer Säure auf eine Base stattfindet. Nach dem Brønsted-Lowry-Konzept gibt die Säure dabei ein Proton ab (Protonendonator), während die Base das Proton aufnimmt (Protonenakzeptor). Entstehen dabei aus Säure und Base Wasser und ein Salz, spricht man von einer Neutralisation.

Neutralisation

Die bekannteste Säure-Base-Reaktion ist die Neutralisation, bei der Oxonium- und Hydroxidionen zu Wasser reagieren:

H3O+ + OH− → 2 H2O

Ein klassisches Beispiel ist die Reaktion von Salzsäure mit Natronlauge zu Natriumchlorid und Wasser. Die Reaktion verläuft exotherm; die freiwerdende Neutralisationsenthalpie beträgt etwa 57 kJ/mol.

Titration

Säure-Base-Reaktionen sind Grundlage der Säure-Base-Titration, einem analytischen Verfahren zur Konzentrationsbestimmung. Der Umschlagspunkt wird mit geeigneten Indikatoren wie Phenolphthalein oder Methylorange sichtbar gemacht.

Konjugierte Paare

Jede Säure besitzt eine konjugierte Base, die nach Abgabe des Protons zurückbleibt; umgekehrt hat jede Base eine konjugierte Säure. Das Gleichgewicht einer Säure-Base-Reaktion liegt stets auf der Seite der schwächeren Säure beziehungsweise Base.
