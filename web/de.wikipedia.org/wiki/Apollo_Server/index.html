Apollo Server

Erstveröffentlichung2016
ProgrammierspracheTypeScript / JavaScript
BetriebssystemPlattformunabhängig (Node.js)
LizenzMIT-Lizenz

Apollo Server ist eine quelloffene, von der Community betriebene Implementierung eines GraphQL-Servers für Node.js. Er wird vom Unternehmen Apollo Graph entwickelt und gepflegt und ist Teil der Apollo-Plattform für GraphQL-Anwendungen.

Geschichte

Apollo Server entstand aus dem Umfeld der Meteor Development Group, die zuvor das Meteor-Framework entwickelt hatte. Mit dem Aufkommen von GraphQL als Abfragesprache für APIs im Jahr 2015 verlagerte das Unternehmen seinen Schwerpunkt auf GraphQL-Werkzeuge. Apollo Server wurde 2016 veröffentlicht und entwickelte sich rasch zu einer der am weitesten verbreiteten GraphQL-Serverbibliotheken.

Funktionen

Apollo Server erlaubt es Entwicklern, ein GraphQL-Schema zu definieren und Resolver-Funktionen bereitzustellen, die Daten aus beliebigen Quellen – etwa REST-APIs, Datenbanken oder Microservices – zusammenführen. Zu den Funktionen gehören Schema-Stitching, Federation (Apollo Federation) zur Zusammenführung mehrerer GraphQL-Dienste zu einem übergeordneten Graphen, Caching, Fehlerbehandlung sowie eine integrierte Entwicklungsumgebung (Apollo Sandbox bzw. früher GraphQL Playground).

Verwendung

Der Server kann eigenständig betrieben oder in Frameworks wie Express, Koa, Hapi oder Fastify eingebettet werden. Er unterstützt sowohl die klassische Anfrage-Antwort-Kommunikation als auch Abonnements (Subscriptions) über WebSockets für Echtzeitdaten.
