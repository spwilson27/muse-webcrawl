Konditionszahl

Veranschaulichung: Eine schlecht konditionierte Matrix bildet einen Kreis auf eine stark verzerrte Ellipse ab

Die Konditionszahl (englisch condition number) ist eine Größe der numerischen Mathematik, die angibt, wie empfindlich die Lösung eines Problems auf kleine Störungen der Eingabedaten reagiert. Ein Problem heißt gut konditioniert, wenn seine Konditionszahl klein ist, und schlecht konditioniert (engl. ill-conditioned), wenn sie groß ist. Die Kondition ist eine Eigenschaft des Problems selbst und nicht des verwendeten Algorithmus; die Empfindlichkeit eines Verfahrens bezeichnet man dagegen als Stabilität.

Kondition einer Matrix

Für eine reguläre Matrix A ist die Konditionszahl bezüglich einer Matrixnorm definiert als

κ(A) = ‖A‖ · ‖A−1‖

Bezüglich der Spektralnorm (2-Norm) ergibt sich die Konditionszahl als Verhältnis des größten zum kleinsten Singulärwert. Für die Lösung linearer Gleichungssysteme Ax = b begrenzt die Konditionszahl den relativen Fehler der Lösung in Abhängigkeit vom relativen Fehler der Daten: Ist κ groß, können schon kleine Rundungsfehler zu großen Abweichungen führen.

Anschauliche Deutung

Eine grobe Faustregel lautet: Beträgt die Konditionszahl 10k, so verliert man bei der Berechnung etwa k Dezimalstellen an Genauigkeit. Die Hilbert-Matrix ist ein klassisches Beispiel für eine extrem schlecht konditionierte Matrix.

Kondition von Funktionen

Auch für skalare Funktionen lässt sich eine Kondition definieren. Für eine differenzierbare Funktion f ist die relative Kondition gegeben durch |x f′(x) / f(x)|. Beispielsweise ist die Subtraktion nahezu gleicher Zahlen schlecht konditioniert (Auslöschung), während die Addition positiver Zahlen gut konditioniert ist.
