Metaklasse

Eine Metaklasse (englisch metaclass) ist in der objektorientierten Programmierung eine Klasse, deren Instanzen selbst Klassen sind. So wie eine gewöhnliche Klasse beschreibt, wie ihre Objekte erzeugt werden und sich verhalten, legt eine Metaklasse fest, wie eine Klasse erzeugt wird und welche Eigenschaften sie besitzt.

Verwendung

Metaklassen kommen unter anderem in Smalltalk, Ruby, Objective-C und Python vor. In Python wird die Metaklasse einer Klasse über das Schlüsselwort metaclass beziehungsweise durch Ableiten von type festgelegt; der Standardtyp aller Klassen ist type. Typische Anwendungen sind die automatische Registrierung von Unterklassen, die Erzeugung von Schnittstellen (z. B. in ORM-Frameworks) und das nachträgliche Ausstatten von Klassen mit Methoden oder Attributen zur Definitionszeit.

Abgrenzung

Nicht jede Sprache mit Klassen kennt Metaklassen als vom Programmierer nutzbares Konzept: In Java und C# existieren Metaklassen nur implizit über die Laufzeit-Typinformationen (z. B. Class-Objekte), ohne dass ihr Erzeugungsverhalten verändert werden könnte.
