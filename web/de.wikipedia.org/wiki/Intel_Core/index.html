Intel Core

HerstellerIntel
Markteinführung2006
Architekturx86-64
SegmentDesktop, Mobil, Server

Intel Core ist eine Markenbezeichnung von Intel für eine Familie von Mikroprozessoren auf Basis der x86-Architektur. Die Marke wurde 2006 eingeführt und löste schrittweise die bisherige Pentium-Linie als Hauptmarke für den Massenmarkt ab. Unter dem Namen Core erschienen zunächst die auf der Core-Mikroarchitektur basierenden Prozessoren, später folgten die Reihen Core 2 sowie die bis heute fortgeführten Linien Core i3, Core i5, Core i7 und Core i9.

Geschichte

Die ersten Core-Prozessoren (Codename Yonah) erschienen Anfang 2006 als Doppelkernprozessoren für Notebooks. Sie gingen auf die Pentium-M-Architektur zurück und zeichneten sich gegenüber den NetBurst-basierten Pentium-4-Modellen durch eine deutlich höhere Energieeffizienz aus. Im Sommer 2006 folgte die Core-Mikroarchitektur mit den ersten Modellen der Reihe Core 2 Duo, die Intel die Leistungsführerschaft im Desktop- und Notebooksegment zurückbrachte.

Produktlinien

Seit 2008 gliedert Intel die Core-Familie nach Leistungsstufen: Core i3 für Einsteigersysteme, Core i5 für den Massenmarkt, Core i7 für anspruchsvolle Anwender und seit 2017 Core i9 für das Enthusiasten- und Workstation-Segment. Die Generationen werden fortlaufend nummeriert und beruhen auf wechselnden Mikroarchitekturen, etwa Nehalem, Sandy Bridge, Haswell, Skylake und späteren Hybridarchitekturen mit Performance- und Effizienzkernen.

Namensgebung ab 2023

Mit der Einführung der Meteor-Lake-Prozessoren stellte Intel die Namensgebung um: Die neuen Modelle heißen schlicht Core 3, Core 5 und Core 7 beziehungsweise in der Premiumlinie Core Ultra 5, Core Ultra 7 und Core Ultra 9. Das „i“ in der Bezeichnung entfiel.
