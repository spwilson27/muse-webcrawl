Advanced Host Controller Interface

Das Advanced Host Controller Interface (AHCI) ist eine technische Spezifikation, die eine einheitliche Schnittstelle zwischen dem Betriebssystem und SATA-Controllern beschreibt. Sie wurde von Intel mit Beiträgen weiterer Hersteller entwickelt; Version 1.0 erschien 2004.

Funktion

AHCI definiert eine registerbasierte Programmierschnittstelle, über die ein einheitlicher Treiber alle AHCI-kompatiblen SATA-Controller ansprechen kann. Dadurch wurden herstellerspezifische Treiber weitgehend überflüssig. AHCI unterstützt wesentliche Funktionen des SATA-Standards, darunter Native Command Queuing (NCQ), Hot-Plug (Austausch von Laufwerken im laufenden Betrieb), gestaffeltes Anlaufen der Laufwerke (Staggered Spin-up) und Port-Multiplier.

Betriebssystemunterstützung

Linux unterstützt AHCI seit Kernel 2.6.19 weitgehend nativ; auch macOS und die BSD-Systeme bringen generische Treiber mit. Unter Windows war AHCI ab Vista integriert; beim Umstellen älterer Installationen vom IDE-Kompatibilitätsmodus auf AHCI war Vorsicht geboten, da sonst Startfehler auftraten.

Nachfolger

Mit SSDs stieß SATA/AHCI an Leistungsgrenzen, weil die Schnittstelle für Festplatten ausgelegt war. Für PCIe-SSDs wurde daher die schlankere Schnittstelle NVMe entwickelt, die AHCI im Hochleistungsbereich weitgehend abgelöst hat.
