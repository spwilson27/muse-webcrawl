Common Object Request Broker Architecture

Die Common Object Request Broker Architecture (CORBA) ist eine von der Object Management Group (OMG) entwickelte Spezifikation für eine Middleware, die die Kommunikation zwischen verteilten Objekten in heterogenen Netzwerken ermöglicht. CORBA erlaubt es Programmen, die in unterschiedlichen Programmiersprachen geschrieben sind und auf verschiedenen Rechnern laufen, miteinander zu interagieren, als befänden sich die Objekte lokal.

Architektur

Im Zentrum von CORBA steht der Object Request Broker (ORB), der Anfragen von Clients an Objekte weiterleitet und deren Ergebnisse zurückliefert. Die Schnittstellen der Objekte werden in der sprachneutralen Interface Definition Language (IDL) beschrieben. Aus der IDL-Beschreibung erzeugen Compiler sogenannte Stubs (auf der Clientseite) und Skeletons (auf der Serverseite).

Kommunikation

Die Kommunikation zwischen ORBs erfolgt über das Protokoll GIOP (General Inter-ORB Protocol), das üblicherweise auf TCP/IP aufsetzt und dann als IIOP (Internet Inter-ORB Protocol) bezeichnet wird. CORBA definiert darüber hinaus eine Reihe von Diensten (CORBA Services), etwa für Namensauflösung, Transaktionen, Sicherheit und Ereignisbenachrichtigung.

Geschichte

Die erste Version der Spezifikation erschien 1991. CORBA war in den 1990er Jahren eine der wichtigsten Technologien für verteilte Systeme in Unternehmen, wurde später jedoch zunehmend durch Webservices, REST und andere leichtgewichtigere Ansätze verdrängt. In bestimmten Bereichen wie Telekommunikation, Militär und Echtzeitsystemen ist CORBA weiterhin im Einsatz.
