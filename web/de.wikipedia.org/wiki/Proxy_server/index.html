Proxy (Rechnernetz)

Ein Proxy (englisch für „Stellvertreter") ist in einem Rechnernetz ein Vermittler, der auf der einen Seite Anfragen entgegennimmt und sie auf der anderen Seite stellvertretend an einen Server weiterleitet. Ein Proxy-Server tritt gegenüber dem anfragenden Client wie ein Server und gegenüber dem eigentlichen Server wie ein Client auf.

Funktionen

  • Caching: Häufig abgerufene Inhalte werden zwischengespeichert und beschleunigen spätere Zugriffe.
  • Filterung und Kontrolle: In Unternehmen und Schulen können Zugriffe protokolliert und unerwünschte Inhalte gesperrt werden.
  • Anonymisierung: Der Zielserver sieht nur die Adresse des Proxys, nicht die des Clients.
  • Lastverteilung und Sicherheit: Ein Reverse Proxy steht vor Webservern und schützt diese vor direktem Zugriff aus dem Internet.

Arten

Der klassische Forward Proxy bündelt die Anfragen vieler Clients, etwa eines Firmennetzes, ins Internet. Ein Reverse Proxy dagegen vertritt einen oder mehrere Server gegenüber dem Netz, etwa für Lastverteilung und TLS-Terminierung. Daneben gibt es transparente Proxys, die ohne Client-Konfiguration im Datenstrom arbeiten, und spezialisierte Protokoll-Proxys. Weit verbreitete Proxy-Software ist unter anderem Squid; verbreitete Protokolle sind HTTP-Proxying sowie SOCKS.
