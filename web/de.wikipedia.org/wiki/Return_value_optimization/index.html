Return Value Optimization

Return Value Optimization (kurz RVO) ist eine Compileroptimierung in der Programmiersprache C++, bei der der Rückgabewert einer Funktion direkt im Speicher des Aufrufers konstruiert wird. Dadurch entfallen eine Kopie und eine Zerstörung eines temporären Objekts. Die Variante für benannte lokale Variablen heißt Named Return Value Optimization (NRVO).

Prinzip

Ohne RVO müsste eine Funktion, die ein Objekt per Wert zurückgibt, ein temporäres Objekt erzeugen, aus dem der Aufrufer anschließend sein Objekt kopiert oder bewegt. Mit RVO übergibt der Aufrufer der Funktion einen versteckten Zeiger auf den Zielspeicher, in dem das Ergebnis unmittelbar per Konstruktor aufgebaut wird. Semantisch ist die Optimierung auch dann zulässig, wenn Kopier- oder Verschiebekonstruktoren Seiteneffekte hätten; der Standard erlaubt ihr Weglassen ausdrücklich (Copy Elision).

Standardisierung

Seit C++17 ist die Elision in bestimmten Fällen – bei der Rückgabe eines nicht benannten temporären Objekts – garantiert vorgeschrieben, sodass der Kopier- bzw. Verschiebekonstruktor nicht einmal zugänglich sein muss. NRVO bleibt hingegen eine optionale Optimierung, die alle gängigen Compiler (GCC, Clang, MSVC) in der Praxis durchführen.
