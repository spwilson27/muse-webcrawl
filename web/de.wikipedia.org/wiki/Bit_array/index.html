Bitfeld

Ein Bitfeld (englisch bit array, bitset oder bitmap) ist eine Datenstruktur, die eine Folge von Bits kompakt speichert und effizienten Zugriff auf einzelne Bits ermöglicht. Jedes Bit repräsentiert dabei typischerweise einen Wahrheitswert oder die Zugehörigkeit eines Elements zu einer Menge.

Eigenschaften

Im Gegensatz zu einem Array von booleschen Werten, das pro Element oft ein ganzes Byte belegt, benötigt ein Bitfeld nur ein Bit pro Element und ist damit achtmal speichereffizienter (bei Byte-basierter Speicherung). Operationen wie Setzen, Löschen und Testen einzelner Bits erfolgen über bitweise Operatoren (AND, OR, NOT, Schiebeoperationen) und sind sehr schnell.

Anwendungen

Bitfelder werden unter anderem eingesetzt als Bitmaps in der Computergrafik, zur Verwaltung freier Speicherblöcke in Dateisystemen, als Bloom-Filter-Varianten, in der Datenbanktechnik für Bitmap-Indizes sowie zur Darstellung von Flags und Berechtigungen. Viele Programmiersprachen bieten dafür eigene Typen an, etwa std::bitset in C++ oder BitSet in Java.
