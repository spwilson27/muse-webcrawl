Kreisteilungspolynom

Das n-te Kreisteilungspolynom Φn(x) (englisch cyclotomic polynomial) ist in der Algebra das Polynom, dessen Nullstellen genau die primitiven n-ten Einheitswurzeln sind:

Φn(x) = ∏ (x − ζ), wobei ζ alle primitiven n-ten Einheitswurzeln durchläuft.

Eigenschaften

Das Kreisteilungspolynom hat ganzzahlige Koeffizienten, ist normiert und über den rationalen Zahlen irreduzibel. Sein Grad beträgt φ(n), die Eulersche Phi-Funktion von n. Es ist das Minimalpolynom einer primitiven n-ten Einheitswurzel über ℚ. Aus der Produktdarstellung xn − 1 = ∏d|n Φd(x) lässt sich jedes Kreisteilungspolynom rekursiv berechnen.

Beispiele

  • Φ1(x) = x − 1
  • Φ2(x) = x + 1
  • Φ3(x) = x² + x + 1
  • Φ4(x) = x² + 1
  • Φ5(x) = x⁴ + x³ + x² + x + 1
  • Φ6(x) = x² − x + 1
  • Φ8(x) = x⁴ + 1
  • Φp(x) = xp−1 + … + x + 1 für eine Primzahl p

Für n als Produkt von höchstens zwei Primzahlen sind alle Koeffizienten −1, 0 oder 1; der erste Koeffizient mit Betrag größer als 1 tritt bei Φ105 auf (Koeffizient −2).

Bedeutung

Kreisteilungspolynome stehen im Zentrum der Theorie der Kreisteilungskörper. Sie entscheiden auch darüber, welche regelmäßigen Vielecke mit Zirkel und Lineal konstruierbar sind, und spielen eine Rolle bei Primzahltests und in der Kryptographie.
