BIOS

Das BIOS (englisch Basic Input/Output System) ist die Firmware eines Personal Computers, die unmittelbar nach dem Einschalten ausgeführt wird. Es initialisiert die Hardware, führt einen Selbsttest (POST, Power-On Self-Test) durch und startet anschließend den Bootloader eines Betriebssystems.

Geschichte

Der Begriff wurde 1975 von Gary Kildall für das Betriebssystem CP/M geprägt. Mit dem IBM PC von 1981 wurde das BIOS zum Standardbestandteil der PC-Architektur; Hersteller wie Phoenix Technologies, Award und AMI erstellten eigene, zueinander weitgehend kompatible Implementierungen.

Funktionen

Das BIOS stellt grundlegende Routinen für den Zugriff auf Tastatur, Bildschirm, Laufwerke und andere Geräte bereit, die insbesondere beim Start und von einfachen Betriebssystemen wie DOS genutzt wurden. Über ein Setup-Programm lassen sich Einstellungen wie Bootreihenfolge, Uhrzeit und Hardwareoptionen konfigurieren; gespeichert werden sie in einem batteriegestaffelten CMOS-Speicher beziehungsweise heute in nichtflüchtigem Flash-Speicher.

Nachfolger

Auf modernen Systemen wird das klassische BIOS zunehmend durch das Unified Extensible Firmware Interface (UEFI) ersetzt, das unter anderem größere Datenträger, einen grafischen Setup-Modus und Secure Boot unterstützt. Viele UEFI-Firmware enthält eine Kompatibilitätsschicht (CSM), um weiterhin per BIOS zu booten.
