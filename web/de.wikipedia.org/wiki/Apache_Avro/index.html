Apache Avro

Apache Avro
Entwickler: Apache Software Foundation
Kategorie: Datenformat, Serialisierung
Lizenz: Apache License 2.0

Apache Avro ist ein System zur Serialisierung von Daten, das im Rahmen des Hadoop-Projekts der Apache Software Foundation entwickelt wurde. Es wurde maßgeblich von Doug Cutting initiiert und wurde 2010 ein eigenständiges Top-Level-Projekt der Apache Software Foundation. Avro ist besonders im Umfeld von Big-Data-Anwendungen, Datenströmen (etwa mit Apache Kafka) und verteilten Systemen verbreitet.

Eigenschaften

Avro definiert ein kompaktes binäres Datenformat. Anders als bei Formaten, die auf generiertem Code beruhen, werden die Daten bei Avro stets zusammen mit ihrem Schema interpretiert. Schemata werden in JSON beschrieben und definieren Datentypen wie Datensätze (records) mit benannten Feldern, Aufzählungen, Arrays, Maps, Unions sowie primitive Typen (null, boolean, int, long, float, double, bytes, string). Da das Schema in JSON vorliegt, lässt es sich leicht einbetten – Avro-Dateien tragen ihr Schema im Kopfbereich, sodass sie auch ohne Vorwissen gelesen werden können.

Ein zentrales Merkmal ist die Unterstützung der Schema-Evolution: Beim Lesen können ältere und neuere Schemata eines Datensatzes aufeinander abgebildet werden, etwa wenn Felder hinzukommen, entfallen oder Standardwerte erhalten. Avro bietet außerdem ein RPC-Protokoll und erlaubt eine dynamische Nutzung ohne Codegenerierung, obwohl ein Compiler Schemata in Klassen gängiger Programmiersprachen übersetzen kann.

Verwendung

Avro wird zur dauerhaften Speicherung großer Datenmengen, zur Kommunikation zwischen Diensten und als Nachrichtenformat in Streaming-Plattformen eingesetzt. In Verbindung mit Schema-Registries (etwa in Kafka-Ökosystemen) werden die Schemata zentral versioniert verwaltet, während die Nachrichten selbst nur eine Schema-Kennung tragen.
