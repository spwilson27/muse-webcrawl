.NET Remoting

.NET Remoting ist eine Technologie von Microsoft für die Kommunikation zwischen verteilten Anwendungen auf Basis des .NET Framework. Sie wurde mit .NET Framework 1.0 im Jahr 2002 eingeführt und ermöglicht es, Objekte über Anwendungs- und Rechnergrenzen hinweg aufzurufen, als wären sie lokal.

Funktionsweise

Der Client arbeitet mit einem Stellvertreterobjekt (Proxy), das Methodenaufrufe über einen Kanal (Channel) an den Server überträgt. Als Transportkanäle stehen TCP und HTTP zur Verfügung; die Daten werden binär oder per SOAP serialisiert. serverseitige Objekte können als Single Call (zustandslos, pro Aufruf neu) oder als Singleton bereitgestellt werden, daneben existieren clientaktivierte Objekte mit eigener Lebensdauer.

Nachfolger

Mit dem .NET Framework 3.0 wurde Remoting weitgehend durch die Windows Communication Foundation (WCF) abgelöst. In der modernen, plattformübergreifenden .NET-Plattform wird .NET Remoting nicht mehr unterstützt; Microsoft empfiehlt stattdessen Technologien wie gRPC oder ASP.NET Core Web-APIs.
