Code Adam

Code Adam ist ein in den Vereinigten Staaten verbreitetes Alarmsignal in Kaufhäusern und öffentlichen Einrichtungen, das ausgelöst wird, wenn ein Kind vermisst wird. Benannt ist es nach Adam Walsh, einem 1981 entführten und ermordeten sechsjährigen Jungen, dessen Fall zur Einrichtung nationaler Vermisstenprogramme führte.

Ablauf

Wird ein Kind als vermisst gemeldet, gibt das Personal eine Beschreibung des Kindes durch. Mitarbeiter sichern alle Ausgänge und prüfen diese, während andere das Gelände absuchen. Wird das Kind nach zehn Minuten nicht gefunden oder befindet es sich mit einer Person, die sich der Kontrolle widersetzt, wird die Polizei verständigt.

Verbreitung

Das Verfahren wurde 1994 von der Warenhauskette Walmart eingeführt und verbreitete sich auf zahlreiche Einzelhändler, Freizeitparks und öffentliche Gebäude in den USA und Kanada.
