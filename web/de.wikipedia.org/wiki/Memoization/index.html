Memoisation

Memoisation tauscht Rechenzeit gegen Speicherplatz

Memoisation (englisch memoization, von lateinisch memorandum) ist eine Technik der Informatik zur Beschleunigung von Programmen, bei der die Ergebnisse aufwendiger Funktionsaufrufe gespeichert und bei erneutem Aufruf mit denselben Argumenten direkt aus dem Speicher abgerufen werden, statt sie neu zu berechnen. Der Begriff wurde 1968 von Donald Michie geprägt.

Funktionsweise

Die Technik setzt voraus, dass die betreffende Funktion referentiell transparent ist, also bei gleichen Eingaben stets dieselbe Ausgabe liefert und keine Seiteneffekte besitzt. Die Ergebnisse werden typischerweise in einer Hashtabelle abgelegt, deren Schlüssel aus den Aufrufargumenten gebildet wird. Memoisation ist ein Kernelement der dynamischen Programmierung: Rekursive Algorithmen mit überlappenden Teilproblemen, etwa die naive Berechnung der Fibonacci-Folge, lassen sich damit von exponentieller auf polynomielle Laufzeit verbessern.

Beispiel

cache = {}
def fib(n):
    if n in cache:
        return cache[n]
    if n < 2:
        result = n
    else:
        result = fib(n-1) + fib(n-2)
    cache[n] = result
    return result

Viele Programmiersprachen und Bibliotheken bieten eingebaute Unterstützung, beispielsweise Python mit dem Dekorator functools.lru_cache.

Vor- und Nachteile

  • Vorteil: erhebliche Laufzeitgewinne bei wiederholten Teilberechnungen
  • Nachteil: zusätzlicher Speicherverbrauch; bei unbegrenzt wachsenden Caches drohen Speicherlecks
  • Verwandt mit dem allgemeinen Konzept des Caching, jedoch auf Funktionsergebnisse bezogen
