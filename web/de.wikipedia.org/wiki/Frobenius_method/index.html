Methode von Frobenius

Die Methode von Frobenius (auch Frobenius-Ansatz) ist ein Verfahren zur Konstruktion von Reihenlösungen linearer gewöhnlicher Differentialgleichungen an einer regulären singulären Stelle. Sie geht auf Ferdinand Georg Frobenius (1873) zurück und verallgemeinert den Potenzreihenansatz um einen gebrochenen oder komplexen Anfangsexponenten.

Verfahren

Für eine Gleichung der Form x²y″ + x p(x) y′ + q(x) y = 0 mit analytischen Koeffizienten macht man den Ansatz einer verallgemeinerten Potenzreihe y = xr Σ an xn. Einsetzen liefert die Indexgleichung (indicial equation) für den Exponenten r, deren Wurzeln die beiden möglichen Anfangsverhalten bestimmen. Rekursiv erhält man daraus alle Koeffizienten an.

Sonderfälle

Unterscheiden sich die beiden Wurzeln der Indexgleichung nicht um eine ganze Zahl, liefert die Methode zwei linear unabhängige Reihenlösungen. Differieren sie um eine ganze Zahl oder fallen zusammen, enthält die zweite Lösung im Allgemeinen einen logarithmischen Term. Klassische Anwendungen sind die Bessel-Gleichung und die hypergeometrische Differentialgleichung.
