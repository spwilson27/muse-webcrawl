Approximationsalgorithmus

Ein Approximationsalgorithmus ist ein Algorithmus, der für ein Optimierungsproblem eine Näherungslösung berechnet, deren Güte im Vergleich zur optimalen Lösung garantiert beschränkt ist. Approximationsalgorithmen werden vor allem für NP-schwere Probleme eingesetzt, für die keine effizienten exakten Verfahren bekannt sind.

Definition

Ein Approximationsalgorithmus für ein Minimierungsproblem besitzt ein Approximationsverhältnis (auch Gütegarantie oder Approximationsfaktor) ρ(n) ≥ 1, wenn die von ihm berechnete Lösung C höchstens das ρ(n)-Fache der optimalen Lösung C* kostet, also C ≤ ρ(n) · C*. Für Maximierungsprobleme gilt entsprechend C ≥ C* / ρ(n).

Beispiele

Bekannte Approximationsalgorithmen existieren unter anderem für das Knotenüberdeckungsproblem (Faktor 2), das Problem des Handlungsreisenden in der metrischen Variante (Christofides-Algorithmus, Faktor 1,5) und das Rucksackproblem, für das sogar ein vollpolynomielles Approximationsschema (FPTAS) existiert.

Approximationsklassen

Je nach Güte der erreichbaren Approximation unterscheidet man unter anderem die Klassen PTAS (polynomielles Approximationsschema), FPTAS und APX. Für manche Probleme, etwa allgemeine Varianten des Handlungsreisendenproblems, ist bewiesen, dass keine polynomiellen Approximationsalgorithmen mit konstantem Faktor existieren, sofern P ≠ NP gilt.
