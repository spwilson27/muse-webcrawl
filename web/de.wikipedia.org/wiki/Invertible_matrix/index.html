Reguläre Matrix

Eine quadratische Matrix heißt regulär oder invertierbar (englisch invertible matrix), wenn eine inverse Matrix existiert, deren Produkt mit ihr die Einheitsmatrix ergibt. Nicht invertierbare Matrizen heißen singulär.

Kriterien

Eine Matrix ist genau dann invertierbar, wenn ihre Determinante von null verschieden ist, wenn ihre Zeilen und Spalten linear unabhängig sind, wenn sie vollen Rang besitzt oder wenn das zugehörige lineare Gleichungssystem für jede rechte Seite genau eine Lösung hat.

Berechnung

Die Inverse kann mit dem Gauß-Jordan-Verfahren oder über die Adjunkte bestimmt werden. Die invertierbaren n×n-Matrizen bilden die allgemeine lineare Gruppe GL(n).
