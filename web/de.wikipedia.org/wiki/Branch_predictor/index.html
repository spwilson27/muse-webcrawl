Sprungvorhersage

Die Sprungvorhersage (englisch branch prediction) ist eine Technik in Prozessoren, bei der vorhergesagt wird, ob ein bedingter Sprungbefehl ausgeführt wird und welches sein Sprungziel ist, bevor dies sicher bekannt ist. Dadurch kann die Pipeline weiter mit Befehlen gefüllt und die Auslastung des Prozessors erhöht werden.

Verfahren

Statische Vorhersage trifft eine feste Annahme, etwa dass Rückwärtssprünge (Schleifen) genommen werden. Dynamische Prädiktoren lernen aus dem bisherigen Verhalten: Einfache Zähler nach dem Prinzip der Zwei-Bit-Sättigungszähler merken sich pro Sprung die letzten Ausgänge. Moderne Prädiktoren nutzen zusätzlich die globale Sprunghistorie, zweistufige adaptive Verfahren oder neuronale Ansätze wie den Perzeptron-Prädiktor.

Sprungzielvorhersage

Neben der Richtung wird auch das Ziel von Sprüngen vorhergesagt, wozu der Branch Target Buffer dient. Für Rücksprünge aus Unterprogrammen gibt es einen speziellen Return Address Stack.

Bedeutung

Fehlvorhersagen (branch mispredictions) zwingen dazu, die Pipeline zu leeren, und sind eine der wichtigsten Leistungsbremsen. Die spekulative Ausführung aufgrund von Vorhersagen führte außerdem zu sicherheitskritischen Seitenkanälen (Spectre).
