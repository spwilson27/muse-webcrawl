Funktion höherer Ordnung

Eine Funktion höherer Ordnung (englisch higher-order function) ist in der Informatik und Mathematik eine Funktion, die mindestens eine der folgenden Eigenschaften besitzt:

  • Sie nimmt eine oder mehrere Funktionen als Argument entgegen.
  • Sie gibt eine Funktion als Ergebnis zurück.

Funktionen, die keine dieser Eigenschaften haben, heißen Funktionen erster Ordnung. Das Konzept stammt ursprünglich aus der Mathematik, etwa aus der Differentialrechnung, wo der Ableitungsoperator eine Funktion auf eine andere Funktion abbildet.

Beispiele

Bekannte Funktionen höherer Ordnung in der funktionalen Programmierung sind map, filter und fold (auch reduce genannt). Die Funktion map wendet eine übergebene Funktion auf jedes Element einer Liste an:

map f [x1, x2, ..., xn] = [f x1, f x2, ..., f xn]

In Programmiersprachen wie Haskell, Lisp, JavaScript oder Python sind Funktionen höherer Ordnung ein zentrales Sprachmittel. Funktionen, die als Werte behandelt werden können, nennt man auch Funktionen erster Klasse (first-class functions).

Mathematischer Hintergrund

Im Lambda-Kalkül sind alle Funktionen höherer Ordnung, da dort Funktionen grundsätzlich Werte sind, die als Argumente übergeben und zurückgegeben werden können. Auch in der Kategorientheorie spielen Funktoren und Funktionale – Abbildungen zwischen Funktionenräumen – eine wichtige Rolle.
