Referenzzählung

Die Referenzzählung (englisch reference counting) ist eine Technik der automatischen Speicherverwaltung, bei der für jedes verwaltete Objekt gezählt wird, wie viele Verweise (Referenzen) auf dieses Objekt existieren. Sinkt der Referenzzähler eines Objekts auf null, ist das Objekt nicht mehr erreichbar und kann freigegeben werden.

Funktionsweise

Jedes Objekt besitzt ein zusätzliches Feld, den Referenzzähler. Wird eine neue Referenz auf das Objekt erzeugt, wird der Zähler erhöht; wird eine Referenz gelöscht oder überschrieben, wird er verringert. Erreicht der Zähler den Wert null, gibt das Laufzeitsystem den Speicher des Objekts frei und löst gegebenenfalls einen Destruktor aus, der weitere Referenzen des Objekts freigibt, wodurch eine Kaskade von Freigaben entstehen kann.

Vorteile und Nachteile

Zu den Vorteilen zählen die einfache Implementierung, die deterministische Freigabe von Ressourcen und der geringe Verwaltungsaufwand ohne eigenen Garbage-Collector-Prozess. Ein wesentlicher Nachteil ist die Unfähigkeit, zyklische Referenzen zu erkennen: Verweisen zwei Objekte gegenseitig aufeinander, bleibt ihr Zähler größer als null, obwohl sie von außen nicht mehr erreichbar sind. Außerdem verursacht das ständige Anpassen der Zähler Laufzeitkosten, insbesondere in nebenläufigen Programmen, in denen die Zähler atomar verändert werden müssen.

Anwendungsgebiete

Referenzzählung wird unter anderem in der Programmiersprache Objective-C und in Swift (Automatic Reference Counting, ARC), in Python (CPython), in COM (Component Object Model) von Microsoft sowie in der Dateiverwaltung von Betriebssystemen (harte Links in Unix-Dateisystemen) eingesetzt. In Python wird die Referenzzählung durch einen zusätzlichen Zyklensammler ergänzt.
