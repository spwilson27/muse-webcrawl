SHOUTcast

SHOUTcast ist eine Software zum Streaming von Audiodaten über das Internet. Sie wurde ursprünglich von Nullsoft, dem Entwickler des Mediaplayers Winamp, entwickelt und trug maßgeblich zur Verbreitung des Webradios bei.

Funktionsweise

Das System besteht aus einem Streaming-Server (SHOUTcast DNAS, Distributed Network Audio Server) und einer Quelle, die den Audiostrom üblicherweise über ein Winamp-Plug-in an den Server sendet. Hörer können den Stream mit gängigen Mediaplayern oder Browsern empfangen. Über das SHOUTcast-Verzeichnis ließen sich tausende vor allem hobbybetriebene Internetradiosender finden.

Geschichte

SHOUTcast erschien 1998/1999 und wurde zusammen mit Nullsoft von AOL übernommen. Nach der Einstellung von Winamp und SHOUTcast durch AOL 2013 übernahm die belgische Radionomy-Gruppe (später AudioValley) die Dienste und führte sie weiter.
