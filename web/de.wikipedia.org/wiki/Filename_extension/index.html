Dateinamenserweiterung

Die Dateinamenserweiterung (englisch filename extension), oft auch Dateiendung genannt, ist der letzte Teil eines Dateinamens, der durch einen Punkt vom Grundnamen getrennt ist. Sie gibt in der Regel Hinweise auf das Dateiformat und darauf, mit welchem Programm die Datei geöffnet werden kann.

Beispiele

ErweiterungBedeutung
.txtTextdatei
.jpg, .png, .gifBilddateien
.mp3, .wavAudiodateien
.mp4, .mkvVideodateien
.pdfDokumente im Portable Document Format
.htmlWebseiten in HTML
.zipArchivdatei
.exeAusführbare Datei unter Windows

Geschichte

Im Dateisystem FAT von MS-DOS war die Erweiterung auf drei Zeichen beschränkt (8.3-Dateinamen). Moderne Dateisysteme erlauben längere Erweiterungen; auch mehrere Punkte im Namen sind üblich, etwa bei .tar.gz für ein mit gzip komprimiertes tar-Archiv.

Bedeutung und Sicherheit

Die Erweiterung ist nur eine Konvention: Eine Datei kann umbenannt werden, ohne dass sich ihr Inhalt ändert; der tatsächliche Typ wird oft zusätzlich durch Magic Numbers im Dateiinhalt bestimmt. Weil Windows Erweiterungen standardmäßig ausblendet, wird dies gelegentlich für Schadsoftware mit doppelten Endungen wie rechnung.pdf.exe ausgenutzt.
