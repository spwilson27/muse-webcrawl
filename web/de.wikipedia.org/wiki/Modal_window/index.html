Modales Fenster

Ein modales Fenster (englisch modal window, auch modaler Dialog) ist in der Informatik ein Bedienelement grafischer Benutzeroberflächen, das die Interaktion mit dem übrigen Programm blockiert, bis es geschlossen wird. Der Benutzer muss zunächst eine Eingabe im modalen Fenster vornehmen oder es ausdrücklich abbrechen, bevor er mit dem dahinterliegenden Hauptfenster weiterarbeiten kann.

Verhalten

Modale Fenster erscheinen typischerweise als Dialogfelder, die eine Entscheidung oder Eingabe erfordern – etwa eine Sicherheitsabfrage („Möchten Sie die Datei wirklich löschen?“), eine Fehlermeldung oder ein Formular. Während das modale Fenster geöffnet ist, sind Klicks auf das Hauptfenster wirkungslos; häufig wird der Hintergrund abgedunkelt (Overlay), um die Aufmerksamkeit auf den Dialog zu lenken. Man unterscheidet anwendungsmodale Fenster, die das gesamte Programm blockieren, von fenstermodalen bzw. dokumentenmodalen Fenstern, die nur ein einzelnes Fenster oder Dokument sperren.

Abgrenzung

Nicht-modale (modelllose) Fenster erlauben dagegen den freien Wechsel zwischen Dialog und Hauptfenster, wie etwa Suchen-und-Ersetzen-Dialoge oder Werkzeugpaletten in Bildbearbeitungsprogrammen. In der Webentwicklung werden modale Fenster häufig mit HTML, CSS und JavaScript umgesetzt; das dialog-Element von HTML5 kennt mit der Methode showModal() eine native modale Variante.

Usability

Modale Fenster sind umstritten: Einerseits erzwingen sie die Aufmerksamkeit für wichtige Entscheidungen und verhindern ungültige Programmzustände, andererseits unterbrechen sie den Arbeitsfluss und können bei übermäßigem Einsatz als störend empfunden werden. Moderne Designrichtlinien empfehlen daher, modale Dialoge sparsam und nur für klar abgegrenzte, notwendige Interaktionen einzusetzen und stets eine Abbruchmöglichkeit vorzusehen (etwa über die Escape-Taste).
