Instrumentierung (Software)

Als Instrumentierung (englisch instrumentation) bezeichnet man in der Softwareentwicklung das Einfügen von zusätzlichem Code in ein Programm, um dessen Laufzeitverhalten zu beobachten und zu messen. Sie dient der Leistungsanalyse (Profiling), der Fehlersuche (Debugging), der Erfassung von Metriken und Ablaufverfolgung (Tracing) sowie der Überwachung von Systemen im Betrieb (Monitoring, Observability).

Verfahren

Instrumentierung kann zur Übersetzungszeit erfolgen, etwa wenn ein Compiler automatisiert Messpunkte einfügt, oder zur Laufzeit durch dynamische Instrumentierung von Maschinencode — Werkzeuge wie Pin, DynamoRIO oder eBPF erlauben das, ohne den Quelltext zu ändern. In verwalteten Laufzeitumgebungen kommen Agenten und Bytecode-Manipulation zum Einsatz, etwa Java-Agenten oder die .NET-Profiling-API.

Abwägung

Instrumentierter Code verursacht zusätzliche Laufzeit (Overhead) und kann das beobachtete Verhalten verfälschen; man spricht in Anlehnung an die Physik auch von einem Beobachtereffekt. Daher muss zwischen der Detailtiefe der erfassten Daten und der Beeinträchtigung des Systems abgewogen werden.
