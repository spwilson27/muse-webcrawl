Zentrische Streckung (Homothetie)

Eine Homothetie oder zentrische Streckung ist eine Abbildung der euklidischen Ebene oder des Raumes, bei der alle Punkte von einem festen Zentrum aus um einen konstanten Streckungsfaktor gestreckt oder gestaucht werden. Mathematisch wird sie durch f(x) = c + k(x − c) beschrieben, wobei c das Zentrum und k der Streckungsfaktor ist.

Eigenschaften

Die zentrische Streckung ist eine Ähnlichkeitsabbildung: Sie erhält Winkel und Verhältnisse von Strecken. Geraden werden auf parallele Geraden abgebildet, Kreise auf Kreise. Für |k| > 1 liegt eine Vergrößerung, für 0 < |k| < 1 eine Verkleinerung vor. Bei negativem Faktor kommt eine Punktspiegelung am Zentrum hinzu. Die Verknüpfung von Homothetien und Translationen bildet die Gruppe der Homothetie-Translationen.

Anwendungen

Zentrische Streckungen werden in der Konstruktionsgeometrie, beim Pantographen sowie bei perspektivischen Darstellungen eingesetzt.
