Ruby ist eine dynamische, objektorientierte Programmiersprache, die Mitte der 1990er Jahre von dem japanischen Informatiker Yukihiro Matsumoto entwickelt wurde. Sie verbindet Elemente aus Perl, Smalltalk, Eiffel, Ada und Lisp und legt besonderen Wert auf eine natürliche, gut lesbare Syntax sowie auf die Produktivität und das Vergnügen der Programmierer.

Geschichte

Matsumoto begann die Arbeit an Ruby im Februar 1993; die erste öffentliche Version 0.95 erschien am 21. Dezember 1995. Der Name wurde in Anspielung auf Perl (englisch „Perle“) gewählt – der Rubin ist der Geburtsstein eines Kollegen von Matsumoto. Weltweite Bekanntheit erlangte Ruby vor allem durch das Webframework Ruby on Rails, das ab 2004 die Entwicklung von Webanwendungen stark vereinfachte.

Eigenschaften

In Ruby ist alles ein Objekt, auch Zahlen und Klassen selbst. Die Sprache verfügt über automatische Speicherbereinigung (Garbage Collection), Blöcke und Iteratoren, Mixins über Module, Ausnahmebehandlung sowie ein eingebautes System zur Metaprogrammierung. Die Syntax orientiert sich an natürlicher Sprache und kommt weitgehend ohne Klammern und Semikola aus.

Implementierungen

Die Referenzimplementierung ist MRI (Matz's Ruby Interpreter), geschrieben in C. Weitere Implementierungen sind JRuby (auf der Java Virtual Machine), TruffleRuby und der eingebettete Interpreter mruby. Pakete und Bibliotheken werden über die Plattform RubyGems verwaltet.
