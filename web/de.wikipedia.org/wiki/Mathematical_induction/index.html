Vollständige Induktion

Die vollständige Induktion (englisch mathematical induction) ist eine mathematische Beweismethode, mit der Aussagen für alle natürlichen Zahlen bewiesen werden. Sie ist eines der grundlegenden Werkzeuge der Mathematik und folgt aus dem Induktionsaxiom der Peano-Axiome bzw. aus der Wohlordnung der natürlichen Zahlen.

Prinzip

Ein Induktionsbeweis besteht aus zwei Schritten:

  1. Induktionsanfang: Die Aussage wird für die kleinste Zahl (meist 0 oder 1) direkt nachgewiesen.
  2. Induktionsschritt: Man zeigt: Gilt die Aussage für eine beliebige natürliche Zahl n (Induktionsvoraussetzung), so gilt sie auch für den Nachfolger n + 1.

Anschaulich entspricht dies einer Kette fallender Dominosteine: Fällt der erste Stein und kippt jeder Stein den nächsten um, so fallen alle.

Beispiel

Die Summenformel 1 + 2 + … + n = n(n+1)/2 wird für n = 1 direkt verifiziert. Gilt sie für n, so folgt sie für n + 1, indem man auf beiden Seiten n + 1 addiert und den entstehenden Ausdruck zu (n+1)(n+2)/2 umformt.

Varianten

Neben der einfachen Induktion gibt es die starke (vollständige) Induktion, bei der im Schritt die Aussage für alle Vorgänger vorausgesetzt werden darf, sowie die strukturelle Induktion über rekursiv definierte Datenstrukturen, die in der Informatik eine große Rolle spielt. Das Prinzip lässt sich auf beliebige wohlgeordnete Mengen verallgemeinern (transfinite Induktion).

Geschichte

Frühe Formen finden sich bei al-Karaji und Francesco Maurolico; Blaise Pascal verwendete das Verfahren 1654 systematisch, und Augustus De Morgan prägte 1838 den Begriff „mathematical induction“.
