Promissory Note

Eine Promissory Note ist im anglo-amerikanischen Recht eine schriftliche, unbedingte Zahlungsverpflichtung, in der sich der Aussteller (Maker) verpflichtet, dem Empfänger (Payee) oder dessen Order eine bestimmte Geldsumme zu einem bestimmten Zeitpunkt oder auf Verlangen zu zahlen. Sie entspricht in ihrer Funktion weitgehend dem deutschen Solawechsel beziehungsweise einem abstrakten Schuldanerkenntnis.

Abgrenzung zum Wechsel

Anders als der Wechsel (Bill of Exchange), der eine Anweisung an einen Dritten darstellt und drei Beteiligte kennt, ist die Promissory Note ein Zwei-Parteien-Geschäft: Der Aussteller verspricht die Zahlung selbst. Im US-Recht wird sie im Uniform Commercial Code (Article 3) als übertragbares Wertpapier (Negotiable Instrument) behandelt, sofern sie unter anderem unbedingt, auf eine bestimmte Summe und an Order oder Inhaber zahlbar ist.

Anwendungsformen

Promissory Notes werden unter anderem bei Immobiliendarlehen (häufig zusammen mit einer Hypothek), Studien-, Auto- und Privatkrediten sowie im Geschäftsverkehr als kurzfristiges Finanzierungsinstrument eingesetzt. Übertragbarkeit durch Indossament macht sie handelbar; der gutgläubige Erwerber (Holder in Due Course) kann sie weitgehend einwendungsfrei durchsetzen.
