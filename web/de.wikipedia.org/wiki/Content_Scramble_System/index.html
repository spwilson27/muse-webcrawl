Content Scramble System

Das Content Scramble System (CSS) ist ein Verfahren zum Kopierschutz von Video-DVDs. Es wurde 1996 von der DVD Copy Control Association eingeführt und verschlüsselt die Inhalte der Disc, sodass sie nur mit lizenzierten Abspielgeräten und Schlüsseln wiedergegeben werden können.

Technik

CSS beruht auf einer Stromchiffre mit 40 Bit Schlüssellänge und einem System mehrerer Schlüssel: Disc-, Titel- und Player-Schlüssel. Die geringe Schlüssellänge galt bereits zur Einführung als schwach. 1999 wurde der Algorithmus durch das Programm DeCSS umgangen, das unter anderem der damals 16-jährige Norweger Jon Lech Johansen mitentwickelt hatte; seither lässt sich CSS praktisch mit jedem Computer knacken.

Rechtliches

Der Fall DeCSS führte zu aufsehenerregenden Verfahren über die Umgehung technischer Schutzmaßnahmen; in den USA berief sich die Filmindustrie auf den Digital Millennium Copyright Act. Der Nachfolger für Blu-ray Discs, AACS, verwendet deutlich stärkere Verfahren.
