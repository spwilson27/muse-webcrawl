Ländercode

Ein Ländercode (englisch country code) ist eine kurze alphanumerische oder numerische Kennung, die ein Land oder Gebiet eindeutig bezeichnet. Ländercodes werden in vielen Bereichen eingesetzt, etwa im Datenverkehr, im Bankwesen, bei Telefonverbindungen und bei Internetadressen.

ISO 3166

Der bekannteste Standard ist ISO 3166, der für jedes Land mehrere Codes definiert: einen zweistelligen (Alpha-2, z. B. DE für Deutschland), einen dreistelligen (Alpha-3, z. B. DEU) und einen numerischen Code (z. B. 276). Die Alpha-2-Codes bilden zugleich die Grundlage der länderspezifischen Top-Level-Domains im Internet (ccTLD).

Weitere Systeme

Daneben existieren unter anderem die Ländercodes des Internationalen Olympischen Komitees (IOC), der FIFA, die Kennbuchstaben für Kraftfahrzeuge sowie die ITU-Vorwahlen für das Telefonnetz (siehe Ländervorwahl). Im Zahlungsverkehr wird der Ländercode als Bestandteil der IBAN verwendet.
