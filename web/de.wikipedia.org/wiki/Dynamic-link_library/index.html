Dynamic Link Library

Aus Wikipedia, der freien Enzyklopädie

Eine Dynamic Link Library (DLL) ist eine dynamische Programmbibliothek unter Microsoft Windows und OS/2. DLLs enthalten ausführbaren Code, Daten und Ressourcen in einem modularen Format, das von mehreren Programmen gleichzeitig genutzt werden kann. Die übliche Dateierweiterung ist .dll; das Dateiformat entspricht dem Portable-Executable-Format (PE).

Funktionsweise

Im Gegensatz zu statischen Bibliotheken wird der Code einer DLL nicht beim Übersetzen in jedes Programm kopiert, sondern erst zur Laufzeit in den Speicher des Prozesses geladen. Dadurch teilen sich alle Anwendungen dieselbe Bibliotheksdatei, was Speicherplatz und Arbeitsspeicher spart und Aktualisierungen erleichtert: Eine korrigierte DLL steht sofort allen nutzenden Programmen zur Verfügung.

Programme binden Funktionen einer DLL entweder implizit beim Programmstart über eine Importbibliothek oder explizit zur Laufzeit über Funktionen wie LoadLibrary und GetProcAddress. DLLs exportieren ihre Funktionen über eine Exporttabelle, wahlweise mit Namen oder Ordnungszahlen.

Geschichte

Das Konzept existiert seit den frühesten Windows-Versionen; zentrale Systembibliotheken wie KERNEL32.DLL, USER32.DLL und GDI32.DLL bilden bis heute die Grundlage der Windows-API. In der 16-Bit- und frühen 32-Bit-Ära führten inkompatible DLL-Versionen im gemeinsamen Systemverzeichnis häufig zu Konflikten, die als „DLL Hell“ bekannt wurden. Gegenmaßnahmen sind unter anderem Side-by-Side-Assemblies, Versionsverwaltung und die Ablage anwendungsspezifischer DLLs im Programmverzeichnis.
