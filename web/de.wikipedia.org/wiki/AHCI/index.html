Advanced Host Controller Interface

Das Advanced Host Controller Interface (AHCI) ist eine von Intel entwickelte technische Spezifikation, die eine einheitliche Programmierschnittstelle für SATA-Hostcontroller definiert. AHCI ermöglicht es Betriebssystemen, ohne herstellerspezifische Treiber mit SATA-Festplatten und -SSDs zu kommunizieren.

Funktionen

AHCI wurde 2004 veröffentlicht und löste den älteren IDE-Kompatibilitätsmodus ab. Die Schnittstelle unterstützt unter anderem Native Command Queuing (NCQ), das Befehle zur effizienteren Abarbeitung neu sortiert, Hot-Plugging zum Austausch von Laufwerken im laufenden Betrieb sowie gestaffeltes Anlaufen mehrerer Festplatten (Staggered Spin-up) zur Begrenzung der Stromspitzen.

Verbreitung

Virtually alle modernen Betriebssysteme – Windows ab Vista, Linux und macOS – bringen AHCI-Treiber mit. Im BIOS beziehungsweise UEFI vieler Mainboards lässt sich für SATA-Anschlüsse zwischen den Modi IDE, AHCI und RAID wählen; für SSDs wird in der Regel AHCI empfohlen, sofern kein NVMe-Protokoll genutzt wird. Mit der Verbreitung von NVMe verliert AHCI, das nur für SATA-Geräte ausgelegt ist, zunehmend an Bedeutung.
