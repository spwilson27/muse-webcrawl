Generische Programmierung

Generische Programmierung ist ein Programmierparadigma, bei dem Algorithmen und Datenstrukturen so allgemein formuliert werden, dass sie mit verschiedenen Datentypen arbeiten können, ohne dass der Quellcode für jeden Typ erneut geschrieben werden muss. Die konkrete Typbindung erfolgt erst bei der Verwendung, meist durch Typparameter.

Konzept

Statt beispielsweise eine Sortierfunktion getrennt für Ganzzahlen, Gleitkommazahlen und Zeichenketten zu schreiben, wird eine einzige generische Funktion definiert, die für jeden Typ funktioniert, der eine Vergleichsoperation bereitstellt. Dadurch werden Code-Duplizierung vermieden und Wiederverwendbarkeit sowie Typsicherheit erhöht.

Umsetzung in verschiedenen Sprachen

In C++ erfolgt generische Programmierung über Templates, die zur Übersetzungszeit instanziiert werden; die Standard Template Library (STL) ist ein bekanntes Beispiel. Java führte mit Version 5 Generics ein, deren Typinformationen zur Laufzeit weitgehend gelöscht werden (Type Erasure). C# besitzt echte generische Typen im Laufzeitsystem, und auch Sprachen wie Rust, Swift, Go (seit Version 1.18) und TypeScript unterstützen generische Programmierung.

// Generische Funktion in TypeScript
function erstesElement<T>(liste: T[]): T | undefined {
    return liste[0];
}

Vor- und Nachteile

Zu den Vorteilen zählen bessere Wiederverwendbarkeit, Typsicherheit ohne Laufzeitprüfungen und geringerer Wartungsaufwand. Nachteile können längere Übersetzungszeiten, komplexe Fehlermeldungen und ein aufgeblähtes Binärprogramm durch mehrfache Instanziierung sein.
