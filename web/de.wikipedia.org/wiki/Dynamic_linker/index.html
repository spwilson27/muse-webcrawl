Dynamischer Linker

Aus Wikipedia, der freien Enzyklopädie

Ein dynamischer Linker (englisch dynamic linker oder dynamic loader) ist ein Programm, das beim Start einer ausführbaren Datei deren dynamisch einzubindende Bibliotheken in den Speicher lädt und die symbolischen Verweise des Programms auf die tatsächlichen Adressen auflöst. Er ist Bestandteil nahezu aller modernen Betriebssysteme und bildet die Laufzeit-Hälfte des dynamischen Linkens.

Aufgaben

  • Laden der im Programm verzeichneten Shared Libraries aus den Suchpfaden des Systems
  • Anwenden von Relokationen, also das Eintragen der tatsächlichen Ladeadressen in den Code
  • Auflösen von Symbolen (Funktionen und Variablen) über die Symboltabellen der Bibliotheken
  • Ausführen der Initialisierungsroutinen der geladenen Bibliotheken

Zur Effizienz wird die Auflösung von Funktionsadressen häufig verzögert (lazy binding): Erst beim ersten Aufruf wird über die Procedure Linkage Table (PLT) und die Global Offset Table (GOT) die Zieladresse ermittelt und zwischengespeichert.

Implementierungen

Unter Linux mit dem ELF-Format heißt der dynamische Linker ld.so beziehungsweise – je nach Architektur – ld-linux-x86-64.so.2; er ist Teil der glibc, kann aber auch direkt aufgerufen werden, um ein Programm mit einer anderen Bibliothekskonfiguration zu starten. Suchpfade lassen sich über /etc/ld.so.conf, den Cache /etc/ld.so.cache und die Umgebungsvariable LD_LIBRARY_PATH beeinflussen. Das Pendant unter macOS heißt dyld; unter Windows übernimmt die Ladefunktion von ntdll/kernel32 das dynamische Binden der DLLs.
