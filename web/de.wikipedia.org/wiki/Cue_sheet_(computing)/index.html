Cue Sheet (Computing)

Ein Cue Sheet ist im Bereich der Computertechnik eine Textdatei (Dateiendung .cue), die beschreibt, wie die Titel (Tracks) auf einer CD angeordnet sind. Sie enthält Angaben zu Art, Position und Länge der einzelnen Tracks sowie Metadaten wie Interpret und Titel. Cue Sheets werden vor allem beim Erstellen und Brennen von CD-Abbildern (Images), beim Rippen von Audio-CDs in einer einzigen Datei und bei der Emulation optischer Laufwerke verwendet.

Format

Die Syntax ist zeilenorientiert. Wichtige Befehle sind FILE (die zugehörige Datendatei, z. B. eine WAV- oder BIN-Datei), TRACK (Beginn eines Tracks mit Nummern- und Typangabe), INDEX (Startposition innerhalb der Datei, im Format Minute:Sekunde:Frame) sowie REM für Kommentare und Metadaten wie Genre oder Datum.

FILE "album.wav" WAVE
  TRACK 01 AUDIO
    TITLE "Erster Song"
    INDEX 01 00:00:00
  TRACK 02 AUDIO
    TITLE "Zweiter Song"
    INDEX 01 03:25:12

Anwendung

Brennprogramme wie CDRWIN, das das Format ursprünglich einführte, nutzen Cue Sheets zusammen mit einer BIN-Datei zur Rekonstruktion einer CD. Mediaplayer wie foobar2000 lesen Cue Sheets, um eine lange Audiodatei in einzelne Titel zu gliedern und mit Metadaten zu versehen. Auch bei verlustfreier Archivierung von Audio-CDs (etwa als FLAC mit eingebettetem Cue Sheet) spielt das Format eine wichtige Rolle.
