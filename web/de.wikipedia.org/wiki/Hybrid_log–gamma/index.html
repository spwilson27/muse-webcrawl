Hybrid Log-Gamma

Hybrid Log-Gamma (HLG, englisch Hybrid Log–Gamma) bezeichnet eine von BBC und NHK entwickelte HDR-Übertragungsfunktion für Fernsehübertragungen. Diese Seite beschreibt das Verfahren unter der englischen Originalschreibweise des Namens mit En-Dash („Log–Gamma“).

Technischer Hintergrund

Die elektro-optische Übertragungsfunktion (EOTF) von HLG ist szene-relativ: Sie bildet die im Bild vorhandene Helligkeit so ab, dass sowohl auf HDR- als auch auf SDR-Anzeigegeräten ein natürliches Bild entsteht. Der untere Teil der Kennlinie entspricht der Wurzel- beziehungsweise Gammakurve klassischer Fernsehsysteme (Gamma 0,5 für die Kamera-Kennlinie), der obere Bereich folgt einer logarithmischen Funktion, wie sie aus der Logarithmus-basierten Aufzeichnung von Filmmaterial bekannt ist. Die Referenzspitzenhelligkeit beträgt 1.000 cd/m².

Verbreitung

HLG wird von zahlreichen Rundfunkanstalten für Live-Übertragungen genutzt, da in der Sendekette keine dynamischen Metadaten verwaltet werden müssen. Unterstützt wird das Format von den meisten modernen Fernsehern sowie von Streamingdiensten und UHD-Blu-ray-Anwendungen.
