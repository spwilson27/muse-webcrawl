InterPlanetary File System

Das InterPlanetary File System (IPFS) ist ein Peer-to-Peer-Protokoll und Netzwerk zur verteilten Speicherung und Bereitstellung von Dateien. Es wurde 2015 von Juan Benet und dem Unternehmen Protocol Labs veröffentlicht. IPFS adressiert Inhalte über kryptografische Hashwerte statt über Speicherorte (Content Addressing) und soll das Web schneller, sicherer und offener machen – insbesondere unabhängig von zentralen Servern.

Funktionsweise

Jede Datei erhält bei der Aufnahme in das Netzwerk eine eindeutige Content-ID (CID), die aus ihrem Hashwert abgeleitet wird. Dateien werden in Blöcke zerlegt und in einer Merkle-DAG-Struktur organisiert. Über eine verteilte Hashtabelle (Kademlia-DHT) finden Knoten heraus, welche Teilnehmer die gewünschten Blöcke vorhalten, und laden sie von diesen – ähnlich wie bei BitTorrent. Da die Adresse aus dem Inhalt entsteht, ist die Integrität der Daten automatisch überprüfbar und die Inhalte sind versionsfest.

Eigenschaften und Anwendungen

  • Zensurresistenz: Inhalte bleiben verfügbar, solange irgendein Knoten sie bereithält
  • Deduplizierung: identische Inhalte werden nur einmal adressiert
  • Anwendungsfälle: Archivierung von Webinhalten, verteilte Websites, NFT-Metadaten, Datensicherung

Eine Schwäche ist, dass Inhalte verschwinden können, wenn kein Knoten sie „pinnt“ (dauerhaft bereithält); Anreizschichten wie Filecoin sollen die langfristige Speicherung ökonomisch absichern.
