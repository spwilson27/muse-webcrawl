Liste von LDAP-Software

Diese Liste enthält Software, die das Lightweight Directory Access Protocol (LDAP) implementiert oder nutzt, darunter Verzeichnisserver, Clientwerkzeuge und Verwaltungslösungen.

Verzeichnisserver

  • OpenLDAP – weit verbreitete Open-Source-Implementierung eines LDAP-Servers, entstanden an der University of Michigan.
  • Apache Directory Server (ApacheDS) – in Java geschriebener, erweiterbarer Verzeichnisserver der Apache Software Foundation.
  • 389 Directory Server – Open-Source-Server, ursprünglich von Netscape entwickelt, heute von Red Hat betreut.
  • Microsoft Active Directory – Verzeichnisdienst von Microsoft für Windows-Netzwerke, der LDAP als Zugriffsprotokoll nutzt.
  • OpenDJ – in Java implementierter Verzeichnisserver, Fork von OpenDS.
  • ForgeRock Directory Services – kommerzieller Nachfolger von OpenDJ.
  • eDirectory – Verzeichnisdienst von NetIQ (früher Novell).
  • Oracle Internet Directory und Oracle Unified Directory – LDAP-Server von Oracle.
  • IBM Security Directory Server – Verzeichnisserver von IBM.
  • FreeIPA – Identitätsmanagementlösung auf Basis von 389 Directory Server.

Client- und Verwaltungswerkzeuge

  • Apache Directory Studio – grafischer LDAP-Browser und -Editor auf Eclipse-Basis.
  • JXplorer – Java-basierter LDAP-Browser.
  • phpLDAPadmin – webbasierte Verwaltung für LDAP-Server.
  • LDAP Account Manager (LAM) – Weboberfläche zur Verwaltung von Konten in LDAP-Verzeichnissen.
  • ldapsearch, ldapadd, ldapmodify – Kommandozeilenwerkzeuge des OpenLDAP-Projekts.
  • Softerra LDAP Browser/Administrator – Werkzeuge für Windows.
  • FusionDirectory – Weboberfläche zur Verwaltung von Infrastruktur und Konten.
