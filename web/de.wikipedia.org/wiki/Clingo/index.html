Clingo

Clingo ist ein System zur Antwortmengenprogrammierung (Answer Set Programming, ASP), das an der Universität Potsdam entwickelt wird. Es verbindet den Grounder Gringo mit dem Solver Clasp in einem einzigen Programm und ist Teil des Potassco-Projekts (Potsdam Answer Set Solving Collection).

Funktionsweise

ASP ist ein deklaratives Paradigma der logischen Programmierung: Ein Problem wird als Logikprogramm beschrieben, dessen „Antwortmengen" (stabile Modelle) den Lösungen entsprechen. Clingo übernimmt das Grounding – die Erzeugung propositionaler Regeln – und das anschließende Suchen nach Antwortmengen in einem integrierten, inkrementellen Verfahren.

Anwendung

Clingo wird in Forschung und Industrie für kombinatorische Such- und Optimierungsprobleme eingesetzt, etwa in der Konfiguration, Planung, Bioinformatik und Wissensrepräsentation. Die Software ist in C++ geschrieben, als Open Source unter MIT-Lizenz verfügbar und bietet Schnittstellen zu Python und Lua zur Steuerung des Lösungsprozesses (Multi-Shot Solving).
