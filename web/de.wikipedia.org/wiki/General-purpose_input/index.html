Universal-Eingabe

Universal-Eingabe (englisch general-purpose input, GPI) bezeichnet in der Computertechnik eine Eingabeschnittstelle, die nicht für einen festen Zweck verdrahtet ist, sondern von Software frei interpretiert werden kann. Am bekanntesten ist der Begriff aus der Mikrocontrollertechnik, wo ein Anschluss entweder als Eingang oder als Ausgang konfiguriert werden kann.

GPIO

Die gebräuchlichste Form der Universal-Eingabe ist der General Purpose Input/Output (GPIO). GPIO-Pins eines Mikrochips können per Programmierung als digitale Eingänge oder Ausgänge dienen. Als Eingang lesen sie den logischen Zustand eines angeschlossenen Signals, etwa eines Tasters oder Sensors; als Ausgang geben sie ein Signal aus, etwa an eine Leuchtdiode.

Eigenschaften

GPIO-Pins besitzen in der Regel keine Spezialfunktion wie analoge Messung oder serielle Datenübertragung, lassen sich aber flexibel einsetzen. Häufig stehen Pull-up- oder Pull-down-Widerstände zur Verfügung, damit ein offener Eingang einen definierten Pegel annimmt. Viele Controller können bei einer Pegeländerung einen Interrupt auslösen.

Anwendungsgebiete

Universal-Eingaben finden sich auf Einplatinencomputern wie dem Raspberry Pi, auf Arduino-Boards sowie in der Industrieelektronik. Sie dienen zum Auslesen von Schaltern, zur einfachen Sensoranbindung und zur Steuerung einfacher Aktoren.
