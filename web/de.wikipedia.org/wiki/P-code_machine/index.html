P-Code-Maschine

Die P-Code-Maschine (englisch p-code machine) ist eine hypothetische, stapelbasierte virtuelle Maschine, die Anfang der 1970er Jahre als Zielarchitektur für Pascal-Compiler entworfen wurde. Programme werden dabei nicht in den Maschinencode eines realen Prozessors, sondern in den Befehlssatz dieser abstrakten Maschine (P-Code) übersetzt und anschließend von einem Interpreter ausgeführt.

Entstehung

Das Konzept geht auf Arbeiten an der ETH Zürich um Niklaus Wirth und Urs Ammann zurück; beschrieben wurde der P-Code unter anderem von Steven Pemberton und Martin Daniels. Ziel war die Portabilität: Ein Pascal-Compiler musste nur P-Code erzeugen, und für jeden neuen Computer genügte ein relativ einfacher Interpreter, um die Sprache verfügbar zu machen. Diese Idee wurde ab 1977 mit dem UCSD-Pascal-System der University of California, San Diego, populär, das auf vielen Heimcomputern verbreitet war.

Architektur

Die P-Code-Maschine arbeitet als Stackmaschine: Operanden werden auf einen Stapel gelegt und von arithmetischen und logischen Befehlen wieder abgehoben. Es gibt Befehle zum Laden und Speichern von Konstanten, Variablen und Feldelementen, Sprünge, Prozeduraufrufe sowie elementare Ein-/Ausgabeanweisungen. Der Speicher ist in Code-, Stapel- und Heap-Bereiche gegliedert.

Bedeutung

Das Prinzip der P-Code-Maschine gilt als wichtiger Vorläufer späterer virtueller Laufzeitumgebungen: Das Konzept des plattformunabhängigen Zwischen codes findet sich etwa im Bytecode der Java Virtual Machine und in der Common Language Runtime von .NET wieder.
