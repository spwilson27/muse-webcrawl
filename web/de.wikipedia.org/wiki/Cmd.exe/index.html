Cmd.exe

cmd.exe, auch Eingabeaufforderung (englisch Command Prompt) genannt, ist der Kommandozeileninterpreter der Betriebssysteme Windows NT, Windows CE und OS/2 von Microsoft. Er ist der analoge Nachfolger von COMMAND.COM unter MS-DOS-basierten Systemen und stellt eine textbasierte Schnittstelle zur Bedienung des Systems bereit.

Funktionen

Cmd.exe führt Befehle aus, die der Benutzer eingibt, und verarbeitet Stapeldateien (Batch-Dateien mit den Endungen .bat und .cmd). Unterstützt werden unter anderem interne Befehle wie dir, cd, copy, del und set sowie Kontrollstrukturen (if, for, goto), Variablenexpansion und Umleitungen von Ein- und Ausgaben. Viele externe Dienstprogramme wie ipconfig, ping oder robocopy werden aus der Eingabeaufforderung aufgerufen.

Geschichte

Cmd.exe ersetzte mit Windows NT die DOS-Kommandozeile. Die Implementierung geht auf OS/2 zurück. Seit 2016 ergänzt die Windows PowerShell bzw. das Windows Terminal die klassische Konsole; cmd.exe bleibt jedoch in Windows 10 und Windows 11 aus Kompatibilitätsgründen enthalten.
