Liste der State Parks in Washington

Das System der State Parks des US-Bundesstaates Washington umfasst mehr als 140 Parks, die von der Washington State Parks and Recreation Commission verwaltet werden. Es wurde 1913 gegründet und ist eines der ältesten State-Park-Systeme der Vereinigten Staaten.

Finanzierung

Seit 2011 finanziert sich das System weitgehend über den „Discover Pass“, eine gebührenpflichtige Zufahrtsgenehmigung für Fahrzeuge.
