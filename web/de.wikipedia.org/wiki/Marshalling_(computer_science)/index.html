Marshalling (Informatik)

Marshalling bezeichnet in der Informatik den Vorgang, die im Speicher vorliegende Repräsentation eines Datenobjekts in ein Format zu überführen, das zur Übertragung an einen anderen Prozess, ein anderes System oder zur Speicherung geeignet ist. Der umgekehrte Vorgang heißt Unmarshalling. Marshalling ist damit eng mit der Serialisierung verwandt.

Anwendung

Marshalling wird überall dort benötigt, wo Daten Systemgrenzen überschreiten, etwa

  • bei entfernten Prozeduraufrufen (RPC), bei denen Parameter und Rückgabewerte zwischen Client und Server übertragen werden,
  • in Middleware-Technologien wie CORBA, Java RMI oder XML-RPC,
  • beim Austausch zwischen verwaltetem und nativem Code, z. B. beim Aufruf von Betriebssystemfunktionen aus Sprachen wie Java (JNI) oder C# (P/Invoke),
  • bei der Übergabe von Daten an ein externes „Marshalling Yard" genanntes Zwischenformat in der Datenintegration.

Abgrenzung zur Serialisierung

Während Serialisierung allgemein die Umwandlung eines Objekts in eine sequentielle Form beschreibt – meist zur Speicherung oder zur späteren Rekonstruktion desselben Objekts –, dient Marshalling primär der Übertragung von Daten über Prozess- oder Sprachgrenzen hinweg, oft verbunden mit der Bereitstellung von Platzhaltern (Stubs und Proxys) für Referenzen auf entfernte Objekte. In vielen Fachtexten werden die Begriffe jedoch nahezu synonym verwendet.
