343 Industries

Gründung: 2007

Sitz: Redmond, Washington, USA

Muttergesellschaft: Microsoft (Xbox Game Studios)

Branche: Computerspielentwicklung

Bekannt für: Halo-Reihe

343 Industries ist ein US-amerikanischer Computerspielentwickler mit Sitz in Redmond, Washington. Das Studio wurde 2007 von Microsoft gegründet, um die „Halo“-Reihe weiterzuführen, nachdem sich der ursprüngliche Entwickler Bungie von Microsoft getrennt hatte. Der Name verweist auf die Figur 343 Guilty Spark aus den Halo-Spielen.

Geschichte

Erste Projekte waren die Jubiläums-Neuauflage „Halo: Combat Evolved Anniversary“ (2011) sowie die von Certain Affinity mitentwickelten Kartenpakete. Mit „Halo 4“ (2012) legte das Studio den ersten eigenen Haupttitel der Serie vor und begann die sogenannte Reclaimer-Saga. Es folgten „Halo 5: Guardians“ (2015) und „Halo Infinite“ (2021), das auf der eigens entwickelten Slipspace Engine basiert.

Sonstiges

Neben den Spielen betreut 343 Industries das gesamte Halo-Franchise, darunter Romane, Comics und die Fernsehserie „Halo“. Nach Umstrukturierungen bei Microsoft übernahm das Studio 2024 den Namen Halo Studios und kündigte einen Wechsel zur Unreal Engine 5 an.
