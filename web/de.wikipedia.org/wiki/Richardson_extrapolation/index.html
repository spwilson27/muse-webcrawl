Richardson-Extrapolation

Die Richardson-Extrapolation ist ein Verfahren der numerischen Mathematik, mit dem die Konvergenz einer Folge von Näherungswerten beschleunigt werden kann. Sie geht auf den britischen Mathematiker und Physiker Lewis Fry Richardson zurück, der sie 1927 im Zusammenhang mit der numerischen Differentiation einführte.

Prinzip

Viele numerische Verfahren liefern für eine Schrittweite h einen Näherungswert A(h) für eine gesuchte Größe A, wobei der Fehler eine Entwicklung der Form A(h) = A + c1hp + c2hq + … besitzt. Berechnet man die Näherung zusätzlich für die halbierte Schrittweite h/2, lassen sich die führenden Fehlerterme durch eine geeignete Linearkombination der beiden Werte eliminieren. Das Ergebnis ist eine Näherung höherer Ordnung.

Die systematische Anwendung dieses Prinzips führt auf eine Tabelle von Werten (Neville-ähnliches Schema), bei der jede Spalte eine höhere Fehlerordnung liefert. Bekannte Anwendungen sind das Romberg-Verfahren zur numerischen Integration sowie die Extrapolation bei der numerischen Lösung von Differentialgleichungen, etwa im Bulirsch-Stoer-Verfahren.

Beispiel: numerische Differentiation

Der zentrale Differenzenquotient nähert die Ableitung einer Funktion mit einem Fehler der Ordnung h2 an. Durch Kombination der Werte für h und h/2 entsteht eine Näherung mit Fehlerordnung h4; weitere Stufen erhöhen die Ordnung schrittweise um jeweils zwei.
