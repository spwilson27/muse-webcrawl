ISO 15924

Die Norm ISO 15924 („Codes für die Namen von Schriften") definiert Codes zur Bezeichnung von Schriftsystemen. Jeder Schrift sind ein vierbuchstabiger alphabetischer Code und ein dreistelliger numerischer Code zugeordnet. Die Norm wurde erstmals 2004 veröffentlicht; Registerbehörde ist das Unicode Consortium.

Anwendung

Die Codes werden in Sprach-Tags nach BCP 47 verwendet, um die Schrift einer Sprache anzugeben, etwa de-Latn für Deutsch in lateinischer Schrift oder sr-Cyrl für Serbisch in kyrillischer Schrift. Sie spielen außerdem in Unicode, in der Typografie und in Bibliothekssystemen eine Rolle. Insgesamt sind über 180 Schriftsysteme erfasst, darunter auch historische Schriften wie Runen (Runr) oder Hieroglyphen (Egyp).
