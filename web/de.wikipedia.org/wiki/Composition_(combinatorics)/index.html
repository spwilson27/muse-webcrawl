Komposition (Kombinatorik)

In der Kombinatorik bezeichnet eine Komposition einer positiven ganzen Zahl n eine Darstellung von n als Summe positiver ganzer Zahlen, bei der – anders als bei einer Partition – die Reihenfolge der Summanden eine Rolle spielt. Beispielsweise besitzt die Zahl 4 die acht Kompositionen 4, 3+1, 1+3, 2+2, 2+1+1, 1+2+1, 1+1+2 und 1+1+1+1.

Anzahl

Die Anzahl der Kompositionen von n beträgt 2n−1. Dies lässt sich einsichtig machen, indem man zwischen n Einheiten n−1 mögliche Trennstellen betrachtet, von denen jede entweder eine Summengrenze markiert oder nicht. Die Anzahl der Kompositionen von n mit genau k Summanden ist der Binomialkoeffizient „n−1 über k−1“.

Abgrenzung

Erlaubt man auch die Null als Summanden, spricht man von schwachen Kompositionen; ihre Anzahl folgt dem Prinzip der „stars and bars“-Abzählung. Kompositionen spielen unter anderem bei der Untersuchung erzeugender Funktionen und in der Analyse von Algorithmen eine Rolle.
