PyPy

PyPy ist eine alternative Implementierung der Programmiersprache Python. Sein Kernstück ist ein Just-in-time-Compiler (JIT), der Python-Programme zur Laufzeit in Maschinencode übersetzt und sie dadurch in vielen Fällen deutlich schneller ausführt als die Referenzimplementierung CPython.

Technik

PyPy ist selbst weitgehend in einer eingeschränkten Teilmenge von Python (RPython) geschrieben. Die RPython-Toolchain übersetzt den Interpreter in C-Code und fügt dabei wahlweise einen Tracing-JIT und eine Speicherverwaltung hinzu. PyPy unterstützt Python 2.7 sowie Python 3 und ist weitgehend kompatibel zu CPython, mit Einschränkungen bei manchen C-Erweiterungsmodulen.

Geschichte

Das Projekt begann 2003 und wurde zeitweise von der Europäischen Union gefördert. Es steht unter der MIT-Lizenz und wird von einer offenen Entwicklergemeinschaft gepflegt.
