Gruppenhomomorphismus

Ein Gruppenhomomorphismus ist in der Gruppentheorie eine Abbildung zwischen zwei Gruppen, die mit den Gruppenverknüpfungen verträglich ist. Homomorphismen erhalten die algebraische Struktur und sind das zentrale Werkzeug, um Beziehungen zwischen verschiedenen Gruppen zu beschreiben.

Definition

Sind (G, ·) und (H, ∗) Gruppen, so heißt eine Abbildung f: G → H ein Gruppenhomomorphismus, wenn für alle a, b ∈ G gilt: f(a · b) = f(a) ∗ f(b). Aus dieser Bedingung folgt bereits, dass das neutrale Element von G auf das neutrale Element von H und Inverse auf Inverse abgebildet werden.

Kern und Bild

Der Kern eines Homomorphismus ist die Menge aller Elemente von G, die auf das neutrale Element von H abgebildet werden; er ist stets ein Normalteiler von G. Das Bild ist eine Untergruppe von H. Der Homomorphiesatz besagt, dass die Faktorgruppe G/ker(f) isomorph zum Bild von f ist.

Sonderfälle

Ein bijektiver Homomorphismus heißt Isomorphismus, ein Homomorphismus einer Gruppe in sich selbst Endomorphismus und ein bijektiver Endomorphismus Automorphismus. Ein injektiver Homomorphismus wird auch Monomorphismus, ein surjektiver Epimorphismus genannt.

Beispiele

  • Die Determinante als Homomorphismus von der allgemeinen linearen Gruppe in die multiplikative Gruppe der Skalare
  • Der Exponentialfunktions-Homomorphismus von (ℝ, +) nach (ℝ>0, ·)
  • Das Vorzeichen einer Permutation als Homomorphismus der symmetrischen Gruppe
