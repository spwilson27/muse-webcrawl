Dualität (Optimierung)

Die Dualität in der mathematischen Optimierung ordnet jedem Optimierungsproblem (dem primalen Problem) ein zweites, eng verwandtes Problem zu, das duale Problem. Die Theorie ist besonders für die lineare Programmierung ausgebaut worden und geht auf Arbeiten von John von Neumann und George B. Dantzig zurück.

Lineare Programme

Zu einem linearen Programm in Standardform max cTx unter Ax ≤ b, x ≥ 0 lautet das duale Problem min bTy unter ATy ≥ c, y ≥ 0. Jede Nebenbedingung des einen Problems entspricht einer Variablen des anderen.

Dualitätssätze

Der schwache Dualitätssatz besagt, dass der Zielfunktionswert jeder zulässigen dualen Lösung eine Schranke für die primale Zielfunktion liefert. Der starke Dualitätssatz garantiert, dass im Optimum beide Zielfunktionswerte übereinstimmen, sofern eines der Probleme eine Lösung besitzt. Die Differenz wird als Dualitätslücke bezeichnet.

Interpretation

Die dualen Variablen lassen sich ökonomisch als Schattenpreise interpretieren: Sie geben an, wie stark sich der optimale Zielfunktionswert ändert, wenn eine knappe Ressource um eine Einheit erhöht wird. Die Bedingungen des komplementären Schlupfs verknüpfen primale und duale Lösungen zusätzlich.
