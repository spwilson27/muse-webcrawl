Input-Output-Modell

Das Input-Output-Modell ist ein ökonomisches Modell der Volkswirtschaftslehre, das die Verflechtungen zwischen den Wirtschaftssektoren einer Volkswirtschaft beschreibt. Es geht auf den russisch-amerikanischen Ökonomen Wassily Leontief zurück, der dafür 1973 den Nobelpreis für Wirtschaftswissenschaften erhielt.

Grundlagen

Das Modell stellt in einer Input-Output-Tabelle dar, welche Vorleistungen (Inputs) jeder Sektor von anderen Sektoren bezieht und welche Produkte (Outputs) er an andere Sektoren, an den Staat, an private Haushalte und ans Ausland liefert. Zentrale Annahmen sind feste Produktionskoeffizienten: Zur Herstellung einer Einheit Output wird stets dieselbe Menge an Inputs benötigt (lineare Produktionsfunktion).

Mathematische Darstellung

Mit dem Outputvektor x, der Matrix der Inputkoeffizienten A und der Endnachfrage y gilt die Fundamentalgleichung x = Ax + y. Umgeformt liefert x = (I − A)−1 y mit der Leontief-Inversen (I − A)−1 den für eine gegebene Endnachfrage erforderlichen Gesamtoutput aller Sektoren – einschließlich aller indirekten Vorleistungsketten.

Anwendungen

Input-Output-Modelle werden von Statistikämtern (in Deutschland das Statistische Bundesamt) erstellt und für wirtschaftspolitische Analysen genutzt, etwa zur Abschätzung der Wirkungen von Nachfrageänderungen, Steueränderungen oder Infrastrukturprogrammen. Erweiterungen binden Umweltgrößen ein (z. B. Emissionskoeffizienten) und ermöglichen ökologische Input-Output-Analysen; multiregionale Modelle (MRIO) bilden internationale Lieferketten ab.

Kritik

Kritisiert werden die starren Annahmen – konstante Preise, keine Substitution von Inputs, keine Kapazitätsgrenzen –, die das Modell für langfristige Prognosen nur bedingt geeignet machen.
