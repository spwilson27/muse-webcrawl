GLib

GLib ist eine plattformübergreifende Programmbibliothek in der Sprache C, die grundlegende Hilfsfunktionen für die Softwareentwicklung bereitstellt. Sie entstand im Rahmen des GTK- und GNOME-Projekts und bildet heute das Fundament großer Teile des GNOME-Desktops sowie vieler weiterer freier Programme. GLib wird als freie Software unter der LGPL veröffentlicht.

Bestandteile

GLib besteht aus mehreren Teilbibliotheken:

  • GLib Core – Datenstrukturen wie verkettete Listen, Hash-Tabellen, Bäume und Strings, dazu Speicherverwaltung, Threads, eine Hauptschleife (Main Loop) für ereignisgesteuerte Programme und Hilfen zur Internationalisierung.
  • GObject – ein Objektsystem für C mit Vererbung, Interfaces, Eigenschaften und Signalen.
  • GIO – eine Abstraktion für Dateizugriffe, Netzwerkkommunikation und asynchrone Ein-/Ausgabe, unter anderem Grundlage des virtuellen Dateisystems GVfs.
  • GModule – Laden von Plugins und dynamischen Bibliotheken.

Bedeutung

Über Language Bindings wird GLib auch aus vielen anderen Sprachen wie Python (PyGObject), Rust, JavaScript und Vala – einer eigens für GObject entwickelten Sprache – genutzt. Zahlreiche bekannte Anwendungen, darunter der Dateimanager von GNOME, der Bildeditor GIMP und Systemdienste wie D-Bus-basierte Komponenten, bauen auf GLib auf.
