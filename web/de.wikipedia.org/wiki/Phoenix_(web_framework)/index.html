Phoenix ist ein freies Webframework für die Programmiersprache Elixir. Es läuft auf der virtuellen Maschine BEAM der Sprache Erlang und folgt dem Model-View-Controller-Muster. Phoenix wurde von Chris McCord entwickelt und ist für leistungsfähige, echtzeitfähige Webanwendungen mit vielen gleichzeitigen Verbindungen ausgelegt.

Eigenschaften

Kernbestandteile sind die Channels, die bidirektionale Echtzeitkommunikation über WebSockets ermöglichen, sowie das PubSub-System zur Verteilung von Nachrichten auf mehrere Server. Mit LiveView (seit 2019) lassen sich interaktive, serverseitig gerenderte Weboberflächen ohne eigenes JavaScript-Framework erstellen; Änderungen werden über eine WebSocket-Verbindung als kleine Diffs an den Browser übertragen. Für Datenbankzugriffe wird die Bibliothek Ecto eingesetzt.

Leistungsfähigkeit

Durch das Aktorenmodell und die leichtgewichtigen Prozesse der BEAM ist Phoenix für sehr viele gleichzeitige Verbindungen bekannt. In vielbeachteten Tests erreichte ein einzelner Server zwei Millionen gleichzeitige WebSocket-Verbindungen.

Verbreitung

Phoenix wird unter anderem in den Bereichen Finanzen, E-Commerce, Kommunikation und IoT eingesetzt. Das Framework ist unter der MIT-Lizenz auf GitHub frei verfügbar und wird von einer aktiven Community weiterentwickelt.
