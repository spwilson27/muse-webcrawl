M3U ist ein Dateiformat für Multimedia-Playlisten. Es wurde ursprünglich für den Mediaplayer Winamp entwickelt und wird heute von nahezu allen gängigen Audio- und Videoplayern unterstützt. Eine M3U-Datei ist eine reine Textdatei, die eine Liste von Verweisen auf Mediendateien oder Streams enthält.

Format

Jede Zeile der Datei enthält entweder einen Pfad beziehungsweise eine URL zu einer Mediendatei oder eine Direktive, die mit dem Zeichen # beginnt. Die wichtigste Direktive ist #EXTINF, die Dauer und Titel des folgenden Eintrags angibt; eingeleitet wird eine erweiterte Playliste durch #EXTM3U. Die Einträge können absolute oder relative Pfade sowie Streaming-URLs (HTTP, RTSP u. a.) sein.

M3U8 und HLS

Die Variante M3U8 verwendet UTF-8-Kodierung und bildet die Grundlage des Streaming-Protokolls HTTP Live Streaming (HLS) von Apple. Dabei verweisen Master-Playlisten auf Varianten unterschiedlicher Bitrate, während die eigentlichen Mediensegmente als kurze TS- oder MP4-Dateien ausgeliefert werden. M3U-Playlisten werden zudem vielfach für IPTV-Angebote genutzt, bei denen Senderlisten als URL-Sammlungen ausgetauscht werden.
