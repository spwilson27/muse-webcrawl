Destruktor (Programmierung)

Ein Destruktor ist in der objektorientierten Programmierung eine spezielle Methode einer Klasse, die automatisch aufgerufen wird, wenn ein Objekt dieser Klasse zerstört wird beziehungsweise seinen Gültigkeitsbereich verlässt. Der Destruktor dient dazu, vom Objekt belegte Ressourcen wieder freizugeben. Er ist das Gegenstück zum Konstruktor.

Verwendung

In Sprachen wie C++ wird der Destruktor durch eine Tilde vor dem Klassennamen gekennzeichnet, etwa ~Klasse(). Er besitzt keine Parameter und keinen Rückgabewert. Typische Aufgaben sind das Freigeben von dynamisch reserviertem Speicher, das Schließen von Dateien und Netzwerkverbindungen sowie das Lösen von Sperren. Das dahinterstehende Idiom wird als RAII (Resource Acquisition Is Initialization) bezeichnet.

Virtuelle Destruktoren

Wird ein Objekt über einen Zeiger auf eine Basisklasse gelöscht, muss der Destruktor der Basisklasse als virtual deklariert sein, damit auch der Destruktor der abgeleiteten Klasse korrekt ausgeführt wird; andernfalls ist das Verhalten undefiniert.

Abgrenzung

In Sprachen mit automatischer Speicherbereinigung (Garbage Collection), etwa Java oder C#, übernehmen Finalizer beziehungsweise die Garbage Collection die Freigabe des Speichers; ein deterministischer Aufrufzeitpunkt ist dort in der Regel nicht garantiert.
