Ladbares Kernelmodul

Ein ladbares Kernelmodul (englisch loadable kernel module, LKM) ist eine Objektdatei mit Code, der zur Laufzeit in den Betriebssystemkern (Kernel) geladen und wieder entfernt werden kann, ohne den Kernel neu zu kompilieren oder das System neu zu starten. Module erweitern den Kern typischerweise um Gerätetreiber, Dateisysteme, Netzwerkprotokolle oder Systemaufrufe.

Beispiele

Linux unterstützt Module von Anfang an; sie tragen meist die Endung .ko (früher .o) und werden mit Werkzeugen wie insmod, modprobe und rmmod verwaltet. Auch FreeBSD (kld), macOS (Kernel Extensions, „kexts") und Solaris kennen ladbare Module. Windows realisiert ein ähnliches Konzept über dynamisch ladbare Treiberdateien.

Vor- und Nachteile

Module halten den Kern klein, ermöglichen die Unterstützung nur tatsächlich vorhandener Hardware und vereinfachen die Entwicklung von Treibern. Da Modulkode im privilegierten Kernelmodus läuft, kann ein fehlerhaftes oder bösartiges Modul das gesamte System gefährden; LKMs sind daher auch ein bekanntes Einfallstor für Rootkits. Moderne Systeme verlangen daher zunehmend signierte Module (Secure Boot) und bieten feinere Berechtigungsmodelle wie eBPF als sicherere Alternative für bestimmte Erweiterungen.
