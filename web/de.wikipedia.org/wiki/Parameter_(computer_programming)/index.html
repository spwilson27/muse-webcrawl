Parameter (Programmierung)

Ein Parameter ist in der Programmierung eine Variable, die einer Funktion, Prozedur oder Methode bei ihrer Definition als Platzhalter für Eingabewerte dient. Beim Aufruf werden dem Parameter konkrete Werte – die Argumente – übergeben. Streng unterschieden wird daher zwischen dem formalen Parameter in der Deklaration und dem aktuellen Parameter (Argument) am Aufrufort; im allgemeinen Sprachgebrauch werden beide Begriffe oft synonym verwendet.

Übergabemechanismen

Programmiersprachen unterscheiden mehrere Arten der Parameterübergabe:

  • Call by value (Wertübergabe): Der Wert des Arguments wird kopiert; Änderungen am Parameter wirken nicht auf den Aufrufer zurück.
  • Call by reference (Referenzübergabe): Es wird eine Referenz auf die Variable des Aufrufers übergeben, sodass Änderungen sichtbar werden.
  • Call by name und verwandte Verfahren, bei denen der Ausdruck bei jeder Verwendung neu ausgewertet wird.

Varianten

Viele Sprachen unterstützen zudem Standardparameter mit voreingestellten Werten, benannte Argumente, über die Argumente unabhängig von der Reihenfolge übergeben werden können, sowie eine variable Anzahl von Argumenten (Variadic Functions, etwa ... in C oder *args in Python). Ausgabewerte können über Referenzparameter oder – moderner – über Rückgabewerte an den Aufrufer geliefert werden.

Bedeutung

Parameter machen Code wiederverwendbar und abstrakt: Dieselbe Funktion kann mit unterschiedlichen Eingaben arbeiten, ohne dass ihr Ablauf verändert werden muss. Sie sind damit ein zentrales Konzept der Strukturierung von Programmen und der Schnittstellengestaltung.
