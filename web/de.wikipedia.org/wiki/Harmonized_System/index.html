Harmonisiertes System

Das Harmonisierte System zur Bezeichnung und Codierung der Waren (HS) ist eine internationale Nomenklatur der Weltzollorganisation (WZO) zur Klassifizierung von Waren im Außenhandel. Es wurde 1988 eingeführt und wird von über 200 Staaten und Wirtschaftsräumen angewendet.

Aufbau

Das HS gliedert Waren in 21 Abschnitte und 99 Kapitel. Jede Ware erhält eine sechsstellige Codenummer: Die ersten zwei Ziffern bezeichnen das Kapitel, die nächsten zwei die Position und die letzten zwei die Unterposition. Nationale Tarife wie die Kombinierte Nomenklatur der Europäischen Union oder der Harmonized Tariff Schedule der USA erweitern den Code um weitere Stellen.

Bedeutung

Auf Grundlage der HS-Codierung werden Zollsätze festgelegt, Handelsstatistiken erstellt und handelspolitische Maßnahmen wie Kontingente oder Verbote angewendet. Die Weltzollorganisation überarbeitet das System in der Regel alle fünf Jahre; größere Revisionen gab es unter anderem 1992, 1996, 2002, 2007, 2012, 2017 und 2022.
