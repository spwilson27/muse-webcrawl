sbt (Software)

sbt (früher simple build tool) ist ein quelloffenes Build-Werkzeug für die Programmiersprachen Scala und Java. Es übernimmt Aufgaben wie das Kompilieren von Quellcode, das Ausführen von Tests, das Verpacken von Programmen und das Verwalten von Bibliotheksabhängigkeiten. sbt ist das Standard-Build-Werkzeug der Scala-Gemeinschaft.

Funktionsweise

Die Build-Definitionen werden in einer Datei namens build.sbt in einer Scala-basierten domänenspezifischen Sprache formuliert. sbt unterstützt inkrementelle Kompilierung, bei der nur veränderte Teile eines Projekts neu übersetzt werden, sowie eine interaktive Shell, in der Befehle wie compile, test und run schnell nacheinander ausgeführt werden können. Abhängigkeiten werden standardmäßig aus dem zentralen Maven-Repository bzw. über die Ivy-/Coursier-Infrastruktur aufgelöst.

Geschichte

sbt wurde ursprünglich von Mark Harrah entwickelt und 2008 veröffentlicht. Es steht unter der Apache-Lizenz 2.0 und wird heute von der Scala-Gemeinschaft und dem Unternehmen Lightbend (ehemals Typesafe) weiterentwickelt. Neben Scala-Projekten wird sbt auch für gemischte Scala-/Java-Projekte eingesetzt und ist in zahlreiche Entwicklungsumgebungen integriert.
