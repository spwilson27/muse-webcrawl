.NET Framework

Das .NET Framework ist ein von Microsoft entwickeltes Softwareframework, das 2002 erstmals veröffentlicht wurde. Es besteht aus der Laufzeitumgebung Common Language Runtime (CLR) und einer umfangreichen Klassenbibliothek (Framework Class Library) und dient der Entwicklung von Anwendungen für Windows.

Versionen

Wichtige Versionen sind 1.0 (2002), 2.0 (2005), 3.0 (2006, mit WPF und WCF), 3.5 (2007, mit LINQ), 4.0 (2010) und 4.8 (2019). Die Version 4.8 ist die letzte Hauptversion; das Framework wird weiterhin mit Sicherheitsupdates versorgt, aber nicht mehr funktional weiterentwickelt. Der Nachfolger ist das plattformübergreifende .NET (ehemals .NET Core).

Bestandteile

Zum Framework gehören unter anderem ASP.NET für Webanwendungen, Windows Forms und Windows Presentation Foundation (WPF) für grafische Benutzeroberflächen, ADO.NET für den Datenzugriff sowie die Windows Communication Foundation (WCF) für verteilte Dienste.

Programmiersprachen

Die wichtigsten Sprachen sind C# und Visual Basic .NET; daneben existieren F#, C++/CLI und zahlreiche weitere Sprachen, die auf die Common Language Infrastructure (CLI) aufsetzen.
