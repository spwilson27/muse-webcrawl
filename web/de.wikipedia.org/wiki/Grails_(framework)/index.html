Grails (Framework)

Erstveröffentlichung2005 (als „Groovy on Rails“)
ProgrammierspracheGroovy, Java
PlattformJava Virtual Machine
LizenzApache-Lizenz 2.0

Grails ist ein freies Webframework für die Programmiersprache Groovy. Es läuft auf der Java Virtual Machine und folgt dem Prinzip „Konvention vor Konfiguration“ (Convention over Configuration) sowie dem MVC-Muster.

Geschichte

Das Projekt entstand 2005 unter dem Namen „Groovy on Rails“ in Anlehnung an Ruby on Rails und wurde später in Grails umbenannt. Grails baut auf bewährten Java-Technologien wie Spring und Hibernate auf: Als ORM-Schicht dient GORM (Grails Object Relational Mapping), für Views werden Groovy Server Pages (GSP) verwendet.

Eigenschaften

Grails erzeugt große Teile einer Webanwendung automatisch („Scaffolding“), darunter CRUD-Oberflächen für Domänenklassen. Ein Plugin-System mit mehreren hundert Erweiterungen deckt Funktionen wie Sicherheit (Spring Security), Suche und REST-Schnittstellen ab. Seit Grails 4 basiert das Framework auf dem Micronaut-Framework; Grails 5 und 6 brachten Unterstützung für neuere Java- und Spring-Versionen.
