Leberwerte

Als Leberwerte (englisch liver function tests, LFT) bezeichnet man eine Gruppe von Laborparametern, die Hinweise auf Erkrankungen der Leber und der Gallenwege geben. Sie werden aus einer Blutprobe bestimmt und gehören zu den am häufigsten angeforderten Laboruntersuchungen.

Parameter

Zu den klassischen Leberwerten zählen die Enzyme Alanin-Aminotransferase (ALT/GPT), Aspartat-Aminotransferase (AST/GOT), Gamma-Glutamyltransferase (Gamma-GT) und alkalische Phosphatase (AP) sowie das Bilirubin. Zusätzlich werden häufig Albumin und die Blutgerinnung (INR/Quick-Wert) bestimmt, um die Syntheseleistung der Leber einzuschätzen.

Interpretation

Erhöhte Transaminasen (ALT, AST) deuten auf eine Schädigung der Leberzellen hin, etwa bei Hepatitis oder Fettleber. Eine Erhöhung der Cholestaseparameter (AP, Gamma-GT, Bilirubin) weist auf einen Gallestau hin. Einzelne Werte allein erlauben keine Diagnose; sie werden stets im Gesamtbild mit Anamnese und weiteren Untersuchungen bewertet.
