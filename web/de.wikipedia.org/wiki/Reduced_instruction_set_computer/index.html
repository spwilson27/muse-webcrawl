Reduced Instruction Set Computer

Reduced Instruction Set Computer (RISC, deutsch „Computer mit reduziertem Befehlssatz“) ist eine Designphilosophie für Prozessorarchitekturen, die auf einem kleinen Satz einfacher, schnell ausführbarer Befehle basiert. Das Gegenstück bildet CISC (Complex Instruction Set Computer), wie es klassisch durch die x86-Architektur vertreten wird.

Merkmale

Typische RISC-Merkmale sind: wenige, einheitlich lange Befehle; Ausführung der meisten Befehle in einem einzigen Taktzyklus durch Pipelining; eine Load/Store-Architektur, bei der nur Lade- und Speicherbefehle auf den Hauptspeicher zugreifen; eine große Zahl allgemeiner Register; sowie die Verlagerung von Komplexität aus der Hardware in den Compiler.

Geschichte

Als Wegbereiter gilt das IBM-801-Projekt unter John Cocke in den 1970er Jahren. In den 1980er Jahren entstanden an den Universitäten Berkeley (RISC-I, daraus SPARC) und Stanford (MIPS) einflussreiche Entwürfe. Kommerziell erfolgreich wurden unter anderem MIPS, SPARC, PowerPC, DEC Alpha und vor allem ARM, das heute in nahezu allen Smartphones und zunehmend auch in Notebooks und Servern eingesetzt wird. Die offene Befehlssatzarchitektur RISC-V gewinnt seit den 2010er Jahren an Bedeutung.

Bewertung

Die Grenze zwischen RISC und CISC ist heute fließend: Moderne x86-Prozessoren zerlegen komplexe Befehle intern in RISC-ähnliche Mikrooperationen, während RISC-Architekturen ihren Befehlssatz erweitert haben. Energieeffizienz und einfache Kerne haben RISC-Designs jedoch in mobilen und eingebetteten Systemen dominiert.
