Google Summer of Code

Der Google Summer of Code (GSoC) ist ein seit 2005 jährlich stattfindendes Förderprogramm von Google, das neue Beitragende an Open-Source-Projekte heranführt. Ausgewählte Teilnehmer arbeiten über einen Zeitraum von etwa zwölf Wochen unter Betreuung von Mentoren an einem Programmierprojekt für eine Open-Source-Organisation und erhalten dafür ein Stipendium.

Ablauf

Zunächst bewerben sich Open-Source-Organisationen – darunter bekannte Projekte wie die Wikimedia Foundation, Mozilla oder die Apache Software Foundation. Anschließend reichen Interessierte Projektvorschläge ein; nach der Auswahl folgt eine Kennenlernphase („Community Bonding“), dann die eigentliche Programmierphase mit Zwischen- und Abschlussbewertung.

Geschichte und Reichweite

Ursprünglich richtete sich das Programm an Studierende; seit 2022 steht es grundsätzlich allen Erwachsenen offen, die neu in der Open-Source-Entwicklung sind. Seit Bestehen nahmen nach Angaben von Google über 20.000 Beitragende aus mehr als 100 Ländern teil und steuerten Code zu über tausend Organisationen bei.
