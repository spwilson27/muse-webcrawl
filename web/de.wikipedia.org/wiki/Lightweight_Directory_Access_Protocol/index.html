Lightweight Directory Access Protocol

Das Lightweight Directory Access Protocol (LDAP) ist ein Anwendungsprotokoll für den Zugriff auf und die Pflege von Verzeichnisdiensten über IP-Netzwerke. Es ist der De-facto-Standard zur Abfrage und Änderung von Verzeichnissen, in denen Informationen über Benutzer, Gruppen, Geräte und andere Objekte hierarchisch organisiert sind. LDAP arbeitet standardmäßig auf TCP-Port 389, verschlüsselt (LDAPS) auf Port 636.

Geschichte

LDAP entstand Anfang der 1990er Jahre als schlanke Alternative zum aufwendigen Directory Access Protocol des X.500-Standards, das auf dem OSI-Protokollstapel aufsetzte. Die erste Version wurde 1993 an der University of Michigan entwickelt (RFC 1487); die heute gebräuchliche Version 3 ist in den RFCs 4510 bis 4519 beschrieben.

Datenmodell

Das Verzeichnis ist als Baum (Directory Information Tree) aufgebaut. Jeder Eintrag besitzt einen weltweit eindeutigen Distinguished Name (DN), etwa cn=Max Mustermann,ou=Benutzer,dc=beispiel,dc=de, und besteht aus Attributen mit einem oder mehreren Werten. Objektklassen legen fest, welche Attribute ein Eintrag haben darf. Grundlegende Operationen sind Suchen, Vergleichen, Hinzufügen, Löschen und Ändern von Einträgen sowie das Authentifizieren (Bind).

Verbreitung

Bekannte LDAP-Verzeichnisdienste sind Microsoft Active Directory, OpenLDAP, Apache Directory Server und 389 Directory Server. LDAP ist die Basis für zentrale Benutzerverwaltung, Single Sign-on und Adressbücher von E-Mail-Programmen in Unternehmen und Behörden.
