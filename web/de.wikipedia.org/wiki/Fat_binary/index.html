Fat Binary


Schema eines Fat Binary mit mehreren Architekturen

Ein Fat Binary (auch Multi-Architecture Binary) ist eine ausführbare Datei, die nativen Maschinencode für mehrere verschiedene Prozessorarchitekturen enthält. Das Betriebssystem wählt beim Start die zur jeweiligen Hardware passende Codevariante aus, sodass ein einziges Programm auf unterschiedlichen Plattformen lauffähig ist.

Geschichte und Verbreitung

Das Konzept wurde unter anderem von NeXTSTEP eingeführt. Apple nutzte Fat Binaries beim Übergang von der 68k- zur PowerPC-Architektur (ab 1994) und erneut beim Wechsel von PowerPC zu Intel (2006, „Universal Binary"). Mit dem Übergang zu Apple Silicon (ARM) ab 2020 führte Apple „Universal 2"-Binaries ein, die Code für Intel- und ARM-Prozessoren vereinen. Auch das Mach-O-Dateiformat von macOS sieht entsprechende Strukturen vor; bei Android werden vergleichbare „Fat APKs" eingesetzt.

Vor- und Nachteile

Vorteil ist die einfache Distribution: Nutzer müssen nicht wissen, welche Architektur ihr Gerät besitzt. Nachteil ist der größere Dateiumfang, da der Code für alle unterstützten Architekturen mitgeliefert wird. Mit Werkzeugen wie lipo lassen sich einzelne Architekturen aus einem Fat Binary extrahieren oder entfernen.
