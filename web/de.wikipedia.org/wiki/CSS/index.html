Cascading Style Sheets

Cascading Style Sheets (CSS) ist eine Stylesheet-Sprache zur Gestaltung von Webseiten und anderen Dokumenten, die mit Auszeichnungssprachen wie HTML beschrieben sind. CSS legt fest, wie Inhalte dargestellt werden – etwa Farben, Schriftarten, Abstände und Layout –, und trennt so die Gestaltung von der Struktur eines Dokuments.

Geschichte

CSS wurde von Håkon Wium Lie vorgeschlagen und 1996 vom World Wide Web Consortium (W3C) als Empfehlung CSS Level 1 veröffentlicht. Es folgten CSS 2 (1998) und ab 2011 das modular weiterentwickelte CSS3, das unter anderem Übergänge, Animationen und flexible Layoutmodelle wie Flexbox und Grid einführte.

Funktionsweise

CSS-Regeln bestehen aus einem Selektor und einem Deklarationsblock mit Eigenschaft-Wert-Paaren, zum Beispiel:

p { color: blue; font-size: 14px; }

Die „Kaskade“ (cascade) beschreibt die Regeln, nach denen bei widersprüchlichen Angaben entschieden wird, welche Deklaration gilt – abhängig von Herkunft, Spezifität und Reihenfolge der Regeln.
