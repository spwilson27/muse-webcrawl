Autonomes System

Ein autonomes System (englisch autonomous system, AS) ist im Internet ein Zusammenschluss von IP-Netzen unter einheitlicher Verwaltung, die nach außen eine gemeinsame Routing-Politik vertreten. Betreiber sind typischerweise Internetdienstanbieter, große Unternehmen, Universitäten und Behörden.

AS-Nummern

Jedes autonome System erhält eine weltweit eindeutige AS-Nummer (ASN), die von den regionalen Internet-Registries (etwa RIPE NCC für Europa) vergeben wird. Ursprünglich 16 Bit lang (0 bis 65535), wurde der Nummernraum auf 32 Bit erweitert. Innerhalb eines AS kommen Interior-Gateway-Protokolle wie OSPF oder IS-IS zum Einsatz; zwischen autonomen Systemen erfolgt das Routing über das Border Gateway Protocol (BGP).

Bedeutung

Autonome Systeme bilden die Bausteine der globalen Routingstruktur des Internets; weltweit existieren mehrere Zehntausend über BGP sichtbare Systeme. Fehler oder Manipulationen in der Routing-Politik eines AS können weltweite Auswirkungen haben, etwa bei sogenannten Prefix-Hijackings.
