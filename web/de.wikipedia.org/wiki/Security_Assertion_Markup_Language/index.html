Security Assertion Markup Language

Die Security Assertion Markup Language (kurz SAML) ist ein offener, XML-basierter Standard zum Austausch von Authentifizierungs- und Autorisierungsdaten zwischen Parteien, insbesondere zwischen einem Identitätsanbieter (Identity Provider, IdP) und einem Dienstanbieter (Service Provider, SP). SAML ist die technische Grundlage vieler Single-Sign-on-Verfahren (SSO) im Web, vor allem im Unternehmens- und Hochschulbereich.

Geschichte

SAML wird vom Security Services Technical Committee der OASIS entwickelt. Die Version 1.0 erschien 2002, Version 1.1 folgte 2003. Die heutige Version 2.0 wurde 2005 verabschiedet und führte unter anderem Konzepte des eingestellten Standards Liberty ID-FF zusammen.

Funktionsweise

Ein SAML-Ablauf für webbasiertes SSO verläuft typischerweise so:

  1. Der Nutzer ruft eine Anwendung (Service Provider) auf und wird zum Identitätsanbieter weitergeleitet.
  2. Der Nutzer meldet sich beim Identitätsanbieter an (falls noch nicht geschehen).
  3. Der Identitätsanbieter erstellt eine digital signierte Assertion – eine XML-Aussage über Identität und ggf. Attribute des Nutzers – und sendet sie über den Browser an den Service Provider.
  4. Der Service Provider prüft Signatur und Gültigkeit und gewährt Zugriff, ohne dass der Nutzer sich erneut anmeldet.

Assertions können Authentifizierungs-, Attribut- und Autorisierungsaussagen enthalten; typische Bindings sind HTTP Redirect und HTTP POST.

Verwendung

SAML wird unter anderem in Föderationen wie dem akademischen Netzwerk eduGAIN und in Unternehmens-SSO mit Produkten wie Microsoft Entra ID, Okta oder Shibboleth eingesetzt. Für konsumentenorientierte Web- und Mobilanwendungen hat sich daneben zunehmend OpenID Connect auf Basis von OAuth 2.0 verbreitet.
