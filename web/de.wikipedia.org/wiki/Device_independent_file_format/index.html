Device Independent File Format

Das Device Independent File Format (DIFF, auch Device-Independent Format) ist ein Dateiformat zum Austausch von Daten zwischen unterschiedlichen Systemen, das die Eigenschaften eines Geräts unabhängig von dessen Hersteller oder Modell beschreibt. Der Begriff wird unter anderem in der Druckvorstufe und in der Grafikausgabe verwendet, wo ein Dokument so beschrieben werden soll, dass es auf verschiedenen Ausgabegeräten (Drucker, Belichter, Bildschirm) möglichst gleich wiedergegeben wird.

Zweck

Geräteunabhängige Formate trennen den Inhalt eines Dokuments von den technischen Besonderheiten des Ausgabegeräts. So enthalten sie typischerweise Auflösungs-, Farbraum- und Metainformationen in geräteneutraler Form; die eigentliche Umsetzung in gerätespezifische Befehle erfolgt erst im Druck- oder Ausgabesystem.

Abgrenzung

Ein bekanntes Beispiel für ein geräteunabhängiges Format ist das DVI-Format von TeX, das seitenweise eine geräteneutrale Beschreibung von Text und Grafik speichert und erst durch einen speziellen Gerätetreiber in druckerspezifische Befehle umgesetzt wird. Ähnliche Konzepte finden sich bei PostScript und PDF, die ebenfalls geräteunabhängige Seitenbeschreibungen darstellen.
