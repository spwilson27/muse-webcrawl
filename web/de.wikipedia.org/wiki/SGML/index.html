SGML

Die Standard Generalized Markup Language (SGML; deutsch: Normierte verallgemeinerte Auszeichnungssprache) ist eine Metasprache zur Definition von Auszeichnungssprachen für Dokumente. Sie wurde 1986 als ISO-Norm 8879 veröffentlicht. SGML ist die Grundlage, auf der später unter anderem HTML und XML aufbauten.

Geschichte

SGML geht auf die Generalized Markup Language (GML) zurück, die in den 1960er und 1970er Jahren bei IBM von Charles Goldfarb, Edward Mosher und Raymond Lorie entwickelt wurde. Goldfarb leitete anschließend die Standardisierung bei der ISO. Grundidee war die Trennung von Inhalt und Darstellung: Dokumente werden mit beschreibenden Markierungen (Tags) versehen, die die logische Struktur kennzeichnen.

Eigenschaften

Mit einer Document Type Definition (DTD) lässt sich in SGML festlegen, welche Elemente ein Dokument eines bestimmten Typs enthalten darf und wie diese verschachtelt werden können. SGML ist sehr flexibel und erlaubt unter anderem das Weglassen bestimmter Tags, was die Verarbeitung jedoch komplex machte. Die Websprache HTML wurde ursprünglich als Anwendung von SGML definiert; das später entwickelte XML ist eine vereinfachte, strengere Teilmenge von SGML.
