DataMatrix

Typ2D-Code (Matrixcode)
StandardISO/IEC 16022
Kapazitätbis zu 2.335 alphanumerische Zeichen
FehlerkorrekturReed-Solomon (ECC 200)

DataMatrix ist ein zweidimensionaler Matrixcode zur maschinenlesbaren Kennzeichnung von Objekten. Der Code besteht aus einer Anordnung quadratischer schwarzer und weißer Zellen und ist im Standard ISO/IEC 16022 genormt. Die heute gebräuchliche Variante ECC 200 verwendet eine Fehlerkorrektur nach dem Reed-Solomon-Verfahren, durch die der Code selbst bei teilweiser Beschädigung (etwa bis zu 30 Prozent der Fläche) noch lesbar bleibt.

Aufbau

Charakteristisch ist das Suchmuster aus zwei durchgezogenen und zwei gestrichelten Begrenzungslinien in L-Form, an dem Lesegeräte den Code finden und ausrichten. Die Datencellen speichern den eigentlichen Inhalt in einem festgelegten Muster. Je nach Datenmenge variiert die Symbolgröße von 10×10 bis 144×144 Modulen; ein Code kann bis zu 2.335 alphanumerische Zeichen oder 3.116 Ziffern enthalten.

Anwendungen

DataMatrix-Codes werden wegen ihrer geringen Größe und hohen Lesesicherheit vor allem in Industrie und Logistik eingesetzt, etwa zur direkten Teilekennzeichnung (Direct Part Marking) in der Automobil- und Luftfahrtindustrie, zur Kennzeichnung von Arzneimitteln und Medizinprodukten sowie im GS1-System als „GS1 DataMatrix“. Auch in der Elektronikfertigung und auf Postsendungen finden sie Verwendung.
