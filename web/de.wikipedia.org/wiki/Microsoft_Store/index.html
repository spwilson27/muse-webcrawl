Microsoft Store

Der Microsoft Store (bis 2017 Windows Store) ist die digitale Vertriebsplattform von Microsoft für Software, Spiele und weitere Inhalte. Er wurde 2012 zusammen mit Windows 8 eingeführt und ist Bestandteil von Windows 10 und Windows 11 sowie der Xbox-Konsolen.

Angebot und Entwicklung

Über den Store werden Apps im Universal-Windows-Platform-Format, herkömmliche Desktop-Programme, Spiele (unter anderem über den Xbox Game Pass für PC) sowie zeitweise Filme und Serien vertrieben. Anders als in vielen anderen App-Stores erlaubt Microsoft unter Windows auch die Installation von Software aus anderen Quellen (Sideloading). Mit Windows 11 wurde der Store technisch erneuert und für weitere App-Typen und fremde Storefronts geöffnet. Bis 2019 betrieb Microsoft unter dem gleichen Namen auch eine Kette stationärer Einzelhandelsgeschäfte, von denen die meisten 2020 geschlossen wurden.
