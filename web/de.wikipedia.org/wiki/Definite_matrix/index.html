Definite Matrix

Eine symmetrische (bzw. hermitesche) reelle Matrix heißt positiv definit, wenn die zugehörige quadratische Form für alle Vektoren x ≠ 0 einen positiven Wert annimmt: xTAx > 0. Entsprechend heißt die Matrix negativ definit, wenn xTAx < 0 für alle x ≠ 0 gilt. Lässt man auch den Wert 0 zu, spricht man von positiv bzw. negativ semidefinit; eine Matrix, die weder das eine noch das andere ist, heißt indefinit.

Kriterien

Für positiv definite Matrizen existieren mehrere äquivalente Charakterisierungen:

  • Alle Eigenwerte der Matrix sind positiv.
  • Alle führenden Hauptminoren sind positiv (Hurwitz-Kriterium bzw. Sylvester-Kriterium).
  • Es existiert eine Cholesky-Zerlegung A = LLT mit einer regulären unteren Dreiecksmatrix L.

Bedeutung

Positiv definite Matrizen treten unter anderem als Hesse-Matrizen in der Optimierung auf: Ist die Hesse-Matrix einer zweimal differenzierbaren Funktion an einem kritischen Punkt positiv definit, liegt ein lokales Minimum vor. In der Statistik sind Kovarianzmatrizen stets positiv semidefinit. Jede positiv definite Matrix definiert außerdem ein Skalarprodukt und damit eine Norm.

Beispiele

Die Einheitsmatrix ist positiv definit. Die Matrix mit den Einträgen (2, −1; −1, 2) ist positiv definit, während (1, 2; 2, 1) wegen der Eigenwerte 3 und −1 indefinit ist.
