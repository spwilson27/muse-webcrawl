MorphOS

MorphOS ist ein Betriebssystem für Computer mit PowerPC-Prozessoren, das sich an der Architektur und den Schnittstellen des klassischen AmigaOS orientiert. Es wurde ursprünglich für die Pegasos-Rechner der Firma Genesi entwickelt und läuft heute unter anderem auf bestimmten Modellen des Power Mac, des Mac mini und des eMac von Apple sowie auf den Amiga-Modellen mit PowerPC-Erweiterungskarten.

Geschichte

Die Entwicklung von MorphOS begann in den späten 1990er Jahren, nachdem der klassische Amiga-Markt zunehmend an Bedeutung verloren hatte. Ziel war es, die AmigaOS-Umgebung auf moderner PowerPC-Hardware weiterzuführen. Die erste öffentlich verfügbare Version erschien im Jahr 2000 für Amiga-Computer mit PowerUP-Beschleunigerkarten. Später wurde das System vor allem für die Pegasos-Plattform weiterentwickelt.

Wichtige Meilensteine waren die Version 2.0 im Jahr 2008, die unter anderem Unterstützung für den Efika 5200B und weitere Hardware brachte, sowie Version 3.0 im Jahr 2012, die erstmals PowerBook-G4-Laptops unterstützte. MorphOS wird bis heute von einem kleinen Entwicklerteam gepflegt und in regelmäßigen Abständen aktualisiert.

Architektur

Der Kern des Systems ist der Quark-Mikrokernel. Auf ihm setzt die sogenannte A-Box auf, eine Umgebung, die eine weitgehend kompatible Implementierung der AmigaOS-API bereitstellt. Dadurch können viele klassische Amiga-Programme nativ ausgeführt werden. Die grafische Oberfläche heißt Ambient und ist an die Workbench des AmigaOS angelehnt, bietet jedoch moderne Erweiterungen.

Die native API von MorphOS heißt PowerOpen. Für ältere 68k-Programme steht eine JIT-Emulation zur Verfügung, die eine hohe Ausführungsgeschwindigkeit ermöglicht.

Merkmale

  • Kompatibilität zu AmigaOS 3.x auf API-Ebene
  • Native PowerPC-Unterstützung mit 68k-JIT-Emulation
  • Grafische Benutzeroberfläche Ambient
  • MUI (Magic User Interface) als GUI-Toolkit
  • Integrierter Webbrowser (Wayfarer, früher OWB)
