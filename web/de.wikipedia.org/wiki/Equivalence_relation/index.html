Äquivalenzrelation

Eine Äquivalenzrelation ist in der Mathematik eine zweistellige Relation, die reflexiv, symmetrisch und transitiv ist. Sie teilt eine Menge in disjunkte Teilmengen, die Äquivalenzklassen, in denen die Elemente als unter dem betrachteten Gesichtspunkt gleichwertig angesehen werden.

Definition

Eine Relation ~ auf einer Menge M heißt Äquivalenzrelation, wenn für alle x, y, z ∈ M gilt:

  • Reflexivität: x ~ x
  • Symmetrie: aus x ~ y folgt y ~ x
  • Transitivität: aus x ~ y und y ~ z folgt x ~ z

Äquivalenzklassen und Partitionen

Die Äquivalenzklasse eines Elements x ist die Menge aller Elemente, die zu x in Relation stehen: [x] = { y ∈ M | y ~ x }. Die Menge aller Äquivalenzklassen bildet eine Partition der Menge M: Jede Äquivalenzrelation definiert eine Partition und umgekehrt definiert jede Partition genau eine Äquivalenzrelation. Die Menge der Äquivalenzklassen heißt Faktormenge oder Quotientenmenge.

Beispiele

  • Die Gleichheit von Zahlen ist eine Äquivalenzrelation mit einelementigen Klassen.
  • Die Kongruenz modulo n auf den ganzen Zahlen: a ~ b genau dann, wenn n die Differenz a − b teilt. Die Klassen sind die Restklassen.
  • Zwei Brüche a/b und c/d sind äquivalent, wenn ad = bc gilt; so werden die rationalen Zahlen konstruiert.
  • Die Parallelität von Geraden in der euklidischen Ebene.
