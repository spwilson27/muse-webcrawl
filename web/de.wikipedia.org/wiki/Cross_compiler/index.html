Cross-Compiler

Ein Cross-Compiler ist ein Compiler, der ausführbaren Code für eine andere Plattform erzeugt als die, auf der er selbst läuft. Während ein nativer Compiler etwa auf einem x86-PC Programme für denselben x86-PC erzeugt, kann ein Cross-Compiler auf dem PC Programme für einen ARM-Mikrocontroller, eine Spielekonsole oder ein Smartphone erstellen. Dabei werden drei Systeme unterschieden: das Build-System, auf dem der Compiler gebaut wurde, das Host-System, auf dem er ausgeführt wird, und das Target-System, für das der Code bestimmt ist.

Anwendungsgebiete

Cross-Compiler sind unverzichtbar in der Entwicklung eingebetteter Systeme, deren Hardware zu leistungsschwach, zu spezialisiert oder noch gar nicht verfügbar ist, um darauf direkt zu entwickeln. Auch bei der Entwicklung neuer Prozessorarchitekturen und Betriebssysteme wird zunächst per Cross-Kompilierung gearbeitet, bis ein System sich selbst hosten kann (Bootstrapping). Größere Projekte wie der Linux-Kernel werden regelmäßig für zahlreiche Architekturen cross-kompiliert. Für die Entwicklung von Smartphone-Apps auf dem Desktop-PC kommen ebenfalls Cross-Toolchains zum Einsatz.

Aufbau einer Cross-Toolchain

Eine vollständige Cross-Toolchain umfasst neben dem Compiler (etwa GCC oder LLVM/Clang) einen Assembler und Linker (Binutils), eine Standardbibliothek für das Zielsystem (etwa glibc, musl oder newlib) sowie die Header-Dateien des Zielsystems. Werkzeuge wie crosstool-NG oder das Yocto Project automatisieren den Bau solcher Toolchains. Eine bekannte Fehlerquelle ist die Verwechslung von Pfaden und Bibliotheken zwischen Host- und Target-System.
