Rijndael S-box

Die Rijndael-S-Box ist die Substitutionsbox (S-Box) der Blockchiffre Rijndael beziehungsweise des Advanced Encryption Standard (AES). Sie realisiert im Schritt SubBytes die einzige nichtlineare Operation des Verfahrens und ersetzt jedes Byte des Zustands unabhängig durch ein anderes Byte. Dieselbe S-Box wird auch in der Schlüsselexpansion verwendet.

Konstruktion

Die S-Box ist nicht zufällig gewählt, sondern algebraisch definiert, damit keine Hintertüren vermutet werden können und die Eigenschaften analysierbar sind. Sie besteht aus zwei Schritten:

  1. Multiplikative Inversion: Jedes Byte wird als Element des endlichen Körpers GF(28) interpretiert und durch sein multiplikatives Inverses ersetzt. Das irreduzible Polynom lautet dabei x8 + x4 + x3 + x + 1 (0x11B). Die Null wird auf sich selbst abgebildet.
  2. Affine Transformation: Auf das Ergebnis wird eine über GF(2) affine Abbildung angewandt: Das Byte wird mit einer festen 8×8-Matrix multipliziert und der Konstantenvektor 0x63 addiert.

Beispiele

Die S-Box bildet etwa den Wert 0x00 auf 0x63, 0x01 auf 0x7C, 0x53 auf 0xED und 0xFF auf 0x16 ab. In Implementierungen liegt sie meist als 256 Byte große Tabelle vor; alternative Implementierungen berechnen sie zur Vermeidung von Cache-Timing-Angriffen zur Laufzeit oder über zusammengesetzte Körper (composite fields) in Hardware.

Inverse S-Box

Für die Entschlüsselung existiert die inverse S-Box, die zuerst die inverse affine Transformation und danach die multiplikative Inversion anwendet. Sie ist fest definiert und wird im Schritt InvSubBytes benutzt.

Eigenschaften

Die gewählte Konstruktion liefert eine hohe Nichtlinearität und gute differentielle Eigenschaften: Maximal vier Eingabedifferenzen führen auf dieselbe Ausgabedifferenz, was die Sicherheit gegen differentielle und lineare Kryptoanalyse wesentlich mitbestimmt.
