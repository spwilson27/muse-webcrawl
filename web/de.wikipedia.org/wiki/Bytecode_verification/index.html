Bytecode-Verifikation

Die Bytecode-Verifikation ist ein Prüfverfahren, bei dem der Bytecode eines Programms vor oder während des Ladens auf strukturelle Korrektheit und Typsicherheit untersucht wird. Sie ist vor allem aus der Java Virtual Machine (JVM) bekannt, in der ein Bytecode-Verifier Bestandteil des Klassenladers ist.

Ziele

Da Bytecode auch aus nicht vertrauenswürdigen Quellen stammen kann, stellt die Verifikation sicher, dass er wohlgeformt ist: Der Operandenkeller darf weder über- noch unterlaufen, Sprünge dürfen nur auf gültige Befehlsanfänge zeigen, Zugriffe auf lokale Variablen müssen typkorrekt sein, und Methoden müssen mit passenden Argumenttypen aufgerufen werden. So werden Speicherzugriffsfehler und Typverwechslungen ausgeschlossen, ohne dass der Code zur Laufzeit ständig dynamisch überprüft werden muss.

Verfahren

Klassische Verifier arbeiten mit Datenflussanalyse und inferieren die Typen aller Kellerzellen und Variablen an jeder Programmstelle. Modernere Varianten – etwa das StackMapTable-Verfahren bei Java – verlagern einen Teil der Beweisführung zum Compiler, der Typinformationen in der Klassendatei mitliefert, sodass der Verifier diese nur noch nachprüfen muss.
