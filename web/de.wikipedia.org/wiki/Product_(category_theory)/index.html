Produkt (Kategorientheorie)

In der Kategorientheorie ist das Produkt einer Familie von Objekten eine Verallgemeinerung mehrerer mathematischer Konstruktionen, etwa des kartesischen Produkts von Mengen, des direkten Produkts von Gruppen und des Produkts topologischer Räume.

Definition

Gegeben sei eine Familie von Objekten (Xi)i∈I einer Kategorie. Ein Produkt dieser Familie besteht aus einem Objekt X zusammen mit Morphismen pi : X → Xi (den Projektionen), sodass für jedes Objekt Y und jede Familie von Morphismen fi : Y → Xi genau ein Morphismus f : Y → X existiert mit pi ∘ f = fi für alle i. Diese universelle Eigenschaft bestimmt das Produkt bis auf eindeutigen Isomorphismus.

Beispiele

  • In der Kategorie der Mengen ist das Produkt das kartesische Produkt mit den üblichen Projektionen.
  • In der Kategorie der Gruppen ist es das direkte Produkt.
  • In der Kategorie der topologischen Räume ist es das Produkt mit der Produkttopologie.
  • In der Kategorie der Ringe ist das Produkt nur für endliche Familien mit dem direkten Produkt identisch.

Dualer Begriff

Der zum Produkt duale Begriff ist das Koprodukt, das unter anderem die disjunkte Vereinigung von Mengen und die direkte Summe abelscher Gruppen umfasst.
