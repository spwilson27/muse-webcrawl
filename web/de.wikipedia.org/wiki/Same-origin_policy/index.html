Same-Origin-Policy

Die Same-Origin-Policy (auch Same-Origin Policy, SOP) ist ein zentrales Sicherheitskonzept in Webbrowsern. Sie besagt, dass Skripte, die von einer Herkunft (Origin) geladen wurden, nur auf Inhalte und Daten derselben Herkunft zugreifen dürfen. Eine Herkunft ist dabei durch das Tripel aus Protokoll (Schema), Hostname und Port definiert.

Wirkungsweise

Die Richtlinie verhindert beispielsweise, dass ein Skript einer böswilligen Webseite Inhalte einer anderen, im selben Browser geöffneten Webseite (etwa eines Webmail- oder Banking-Dienstes) auslesen oder verändern kann. Sie gilt unter anderem für den Zugriff auf das Document Object Model (DOM) fremder Fenster und Frames sowie für XMLHttpRequest- und Fetch-Anfragen.

Ausnahmen und Erweiterungen

Bestimmte Elemente wie Bilder, Skripte und Stylesheets dürfen herkunftsübergreifend eingebettet werden, ohne dass ihr Inhalt ausgelesen werden kann. Für kontrollierte herkunftsübergreifende Kommunikation existieren Mechanismen wie Cross-Origin Resource Sharing (CORS) und das window.postMessage-Verfahren. Verwandte Sicherheitsmechanismen sind die Content Security Policy und das sitebasierte Isolieren von Webseiten in modernen Browsern (Site Isolation).
