Link Rot

Link Rot (deutsch etwa „Linkfäule“ oder „Verweisverfall“), auch als Link Decay bezeichnet, beschreibt das Phänomen, dass Hyperlinks im World Wide Web im Laufe der Zeit ins Leere führen, weil die Zielseiten verschoben, umbenannt oder gelöscht werden oder der betreffende Server abgeschaltet wird. Solche defekten Verweise nennt man tote Links (englisch dead links oder broken links).

Ursachen

Zu den häufigsten Ursachen zählen die Umstrukturierung von Websites ohne Weiterleitungen, der Wechsel von Domainnamen, die Einstellung von Diensten, Änderungen an Content-Management-Systemen, die neue URL-Schemata erzeugen, sowie das Löschen von Inhalten aus rechtlichen oder redaktionellen Gründen.

Ausmaß

Studien zeigen, dass ein erheblicher Anteil der im Web zitierten Quellen bereits nach wenigen Jahren nicht mehr erreichbar ist. Besonders betroffen sind wissenschaftliche Publikationen und juristische Entscheidungen, die auf Webquellen verweisen. Eine Untersuchung von Zitaten in Entscheidungen des Obersten Gerichtshofs der USA ergab, dass rund die Hälfte der zitierten Links nicht mehr zum ursprünglich referenzierten Inhalt führte. Man unterscheidet dabei zwischen dem vollständigen Verschwinden einer Ressource und der inhaltlichen Veränderung der Zielseite bei gleichbleibender URL (englisch content drift).

Gegenmaßnahmen

  • Webarchivierung: Dienste wie das Internet Archive mit seiner Wayback Machine sichern Kopien von Webseiten, auf die anstelle der Originale verwiesen werden kann.
  • Persistente Identifikatoren: Systeme wie DOI (Digital Object Identifier), PURL oder Permalinks sollen dauerhaft auflösbare Verweise ermöglichen.
  • Weiterleitungen: serverseitige Redirects (HTTP-Statuscodes 301/308) führen alte Adressen auf neue Ziele.
  • Referenzarchive: Projekte wie perma.cc legen zitierte Quellen zum Zeitpunkt der Zitierung dauerhaft ab.
