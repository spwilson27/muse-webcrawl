Applejack

Applejack bezeichnet:

  • eine amerikanische Spirituose aus Äpfeln, siehe Applejack (Getränk)
  • eine Figur aus der Zeichentrickserie My Little Pony – Freundschaft ist Magie, ein ehrliches und bodenständiges Erdenpony, das auf einer Apfelfarm lebt
  • eine Frühstücksflocken-Marke von Kellogg’s in den Vereinigten Staaten
  • einen Cocktail auf Basis von Apfelbrand
