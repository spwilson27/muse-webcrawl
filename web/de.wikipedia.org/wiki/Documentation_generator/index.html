Dokumentationsgenerator

Ein Dokumentationsgenerator ist ein Programm, das aus Quellcode und speziell formatierten Kommentaren automatisch Softwaredokumentation erzeugt, meist im HTML- oder PDF-Format. Ziel ist es, die Dokumentation nahe am Code zu pflegen und konsistent aktuell zu halten („docs as code“ beziehungsweise „documentation from source“).

Arbeitsweise

Entwickler versehen Klassen, Funktionen und Parameter unmittelbar im Quelltext mit Dokumentationskommentaren in einer festgelegten Syntax (zum Beispiel /** ... */ mit Tags wie @param und @return). Der Generator analysiert den Code (Parsing), extrahiert Signaturen und Kommentare und erstellt daraus verlinkte, durchsuchbare Dokumentationsseiten mit Vererbungshierarchien und Querverweisen.

Bekannte Generatoren

  • Javadoc – für Java, quasi der Ausgangspunkt vieler Systeme
  • Doxygen – für zahlreiche Sprachen, insbesondere C/C++
  • Sphinx mit autodoc – ursprünglich für die Python-Dokumentation entwickelt
  • JSDoc, TypeDoc – für JavaScript beziehungsweise TypeScript
  • rustdoc – fest in die Werkzeugkette von Rust integriert
  • phpDocumentor, pydoc, RDoc für weitere Sprachen

Vorteile und Grenzen

Automatisch erzeugte Dokumentation spiegelt den tatsächlichen Code wider und senkt den Pflegeaufwand für Schnittstellenreferenzen. Sie ersetzt jedoch keine übergreifenden Erläuterungen zu Architektur, Konzepten und Anwendung; deshalb kombinieren viele Projekte Generatoren mit handgeschriebenen Handbüchern.
