Minimalpolynom

Das Minimalpolynom einer quadratischen Matrix (oder eines linearen Endomorphismus) über einem Körper ist das normierte Polynom kleinsten Grades, das die Matrix als Nullstelle besitzt. Es ist ein zentrales Hilfsmittel der linearen Algebra und teilt stets das charakteristische Polynom.

Definition

Sei A eine n×n-Matrix über einem Körper K. Die Menge aller Polynome p mit p(A) = 0 bildet ein Ideal im Polynomring K[x]. Da nach dem Satz von Cayley-Hamilton das charakteristische Polynom zu diesem Ideal gehört, ist das Ideal nicht leer und besitzt einen eindeutigen normierten Erzeuger: das Minimalpolynom μA. Es ist das normierte Polynom kleinsten Grades mit μA(A) = 0.

Eigenschaften

  • Das Minimalpolynom teilt jedes Polynom, das A annulliert, insbesondere das charakteristische Polynom.
  • Minimalpolynom und charakteristisches Polynom haben dieselben Nullstellen (bis auf Vielfachheit): die Eigenwerte von A.
  • Die Potenzen A0, A1, …, Am−1 (m = Grad des Minimalpolynoms) sind linear unabhängig.
  • Ähnliche Matrizen haben dasselbe Minimalpolynom.
  • Eine Matrix ist genau dann diagonalisierbar, wenn ihr Minimalpolynom in paarweise verschiedene Linearfaktoren zerfällt.

Beispiel

Für die Nullmatrix ist das Minimalpolynom μ(x) = x, für die Einheitsmatrix μ(x) = x − 1. Eine Drehmatrix ohne reelle Eigenwerte über ℝ kann etwa das Minimalpolynom x² + 1 besitzen, falls es sich um eine Drehung um 90° handelt.
