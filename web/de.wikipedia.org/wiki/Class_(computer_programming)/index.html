Klasse (Programmierung)

Eine Klasse ist in der objektorientierten Programmierung ein Bauplan für Objekte. Sie definiert, welche Attribute (Daten) und Methoden (Verhalten) die aus ihr erzeugten Objekte – die Instanzen – besitzen. Klassen sind das zentrale Strukturierungsmittel von Sprachen wie Java, C++, C# und Python.

Eigenschaften

Eine Klasse bündelt Daten und die darauf operierenden Funktionen (Kapselung). Über Vererbung kann eine Unterklasse die Eigenschaften einer Oberklasse übernehmen und erweitern; über Polymorphie können Objekte verschiedener Klassen über eine gemeinsame Schnittstelle angesprochen werden. Konstruktoren erzeugen neue Instanzen und initialisieren deren Zustand.

Beispiel

Eine Klasse Auto könnte Attribute wie farbe und geschwindigkeit sowie Methoden wie beschleunigen() definieren. Jedes konkrete Auto-Objekt besitzt eigene Werte dieser Attribute. Abstrakte Klassen und Schnittstellen (Interfaces) dienen der Modellierung, ohne selbst vollständig instanziiert zu werden.
