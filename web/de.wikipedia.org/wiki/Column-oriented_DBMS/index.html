Spaltenorientierte Datenbank

Eine spaltenorientierte Datenbank (englisch column-oriented DBMS, auch Column Store) ist ein Datenbankmanagementsystem, das Daten physisch spaltenweise statt zeilenweise speichert. Alle Werte einer Spalte liegen dabei nacheinander auf dem Datenträger, während bei klassischen zeilenorientierten Systemen die Werte einer Zeile (eines Datensatzes) zusammenhängend abgelegt werden.

Vorteile

Analytische Abfragen (OLAP) greifen typischerweise auf wenige Spalten sehr vieler Zeilen zu, etwa für Aggregationen wie Summen und Durchschnittswerte. Spaltenorientierte Systeme müssen dafür nur die benötigten Spalten einlesen und erzielen dadurch große Geschwindigkeitsvorteile. Zudem lassen sich gleichartige Daten einer Spalte sehr effektiv komprimieren. Nachteilig ist das aufwendigere Einfügen und Aktualisieren einzelner Datensätze.

Produkte

Bekannte spaltenorientierte beziehungsweise hybrid arbeitende Systeme sind unter anderem Apache Cassandra (Wide-Column-Store), ClickHouse, Apache Parquet als Speicherformat, Amazon Redshift, Google BigQuery, SAP HANA (spaltenorientierte In-Memory-Verarbeitung) und MonetDB, eines der ersten Forschungs- und kommerziellen Column-Store-Systeme.
