Hypertext Transfer Protocol Secure

HTTPS
Typ: Netzwerkprotokoll
Standardport: 443
Grundlage: HTTP über TLS

Hypertext Transfer Protocol Secure (HTTPS) ist ein Internetprotokoll zur abhör- und manipulationssicheren Übertragung von Daten. Es entspricht dem Hypertext Transfer Protocol (HTTP), dessen Datenstrom durch Transport Layer Security (TLS) verschlüsselt und authentifiziert wird. In der Adresszeile von Browsern wird HTTPS meist durch ein Schloss-Symbol angezeigt.

Funktionsweise

Vor der eigentlichen Datenübertragung bauen Client und Server eine TLS-Verbindung auf. Dabei weist sich der Server mit einem digitalen Zertifikat aus, das von einer Zertifizierungsstelle signiert ist. Anschließend wird ein Sitzungsschlüssel vereinbart, mit dem der gesamte HTTP-Verkehr symmetrisch verschlüsselt wird.

Verbreitung

HTTPS wurde 1994 von Netscape eingeführt und zunächst vor allem für Onlinebanking und E-Commerce verwendet. Seit Mitte der 2010er Jahre, gefördert durch kostenlose Zertifikate von Let’s Encrypt und die Bevorzugung sicherer Verbindungen durch Browser und Suchmaschinen, hat sich HTTPS als Standard für nahezu alle Websites durchgesetzt.

Abgrenzung

HTTPS schützt die Vertraulichkeit und Integrität der übertragenen Daten, nicht jedoch die Anonymität der Kommunikationsteilnehmer; Verbindungsdaten wie der aufgerufene Hostname sind weiterhin sichtbar.
