Comics Code

Der Comics Code war ein Regelwerk zur Selbstregulierung der US-amerikanischen Comicindustrie, das 1954 von der Comics Code Authority eingeführt wurde. Er schrieb vor, welche Inhalte in Comicbüchern dargestellt werden durften, die das Prüfsiegel der Organisation tragen wollten.

Entstehung

Anfang der 1950er-Jahre gerieten insbesondere Horror- und Kriminalcomics des Verlags EC Comics in die Kritik. Der Psychiater Fredric Wertham behauptete in seinem Buch Seduction of the Innocent (1954), Comics förderten Jugendkriminalität. Anhörungen vor einem Unterausschuss des US-Senats erhöhten den Druck auf die Branche, die daraufhin einen strengen Selbstzensurkodex verabschiedete.

Inhalte

Der Kodex verbot unter anderem die Darstellung von Verbrechen ohne moralische Verurteilung, Horror- und Schreckensszenarien, das Wort „Horror“ oder „Terror“ in Titeln, sowie jede Anspielung auf Sexualität außerhalb traditioneller Normen. Autoritäten wie Polizei und Regierung durften nicht in schlechtem Licht erscheinen.

Folgen und Ende

Der Code führte zum Niedergang der Horror- und Kriminalcomics und begünstigte harmlose Superhelden- und Humorreihen. Er wurde 1971 und 1989 gelockert. Mit dem Ausstieg der großen Verlage – zuletzt Archie Comics 2011 – verlor er jede Bedeutung; die Comics Code Authority wurde aufgelöst.
