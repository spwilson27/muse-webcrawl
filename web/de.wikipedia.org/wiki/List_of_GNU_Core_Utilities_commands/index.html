Liste der GNU-Core-Utilities-Befehle

Die GNU Core Utilities (coreutils) sind ein Softwarepaket des GNU-Projekts mit grundlegenden Befehlszeilenwerkzeugen für Unix-ähnliche Betriebssysteme, etwa für Datei-, Shell- und Textoperationen. Diese Liste enthält die wichtigsten Befehle des Pakets.

Dateioperationen

BefehlBeschreibung
cpDateien und Verzeichnisse kopieren
mvDateien verschieben oder umbenennen
rmDateien oder Verzeichnisse löschen
mkdirVerzeichnisse erstellen
rmdirLeere Verzeichnisse löschen
lsVerzeichnisinhalte auflisten
lnVerknüpfungen zwischen Dateien erstellen
installDateien kopieren und Attribute setzen
ddDateien konvertieren und kopieren (blockweise)
touchZeitstempel ändern bzw. leere Dateien anlegen
chmodZugriffsrechte ändern
chownEigentümer ändern
chgrpGruppe ändern
statDatei- oder Dateisystemstatus anzeigen
duSpeicherverbrauch von Dateien schätzen
dfFreien Speicherplatz auf Dateisystemen anzeigen
syncZwischengespeicherte Schreibvorgänge ausführen
truncateDateigröße anpassen
shredDateien sicher überschreiben und löschen
mkfifo / mknodSpezialdateien anlegen
mktempTemporäre Datei oder Verzeichnis erstellen
realpath / readlinkKanonische Pfade auflösen

Textoperationen

BefehlBeschreibung
catDateien verketten und ausgeben
tacDateien in umgekehrter Zeilenreihenfolge ausgeben
head / tailAnfang bzw. Ende von Dateien ausgeben
wcZeilen, Wörter und Bytes zählen
sortZeilen sortieren
uniqDoppelte Zeilen melden oder ausfiltern
cutAbschnitte aus Zeilen herausschneiden
pasteZeilen von Dateien zusammenfügen
joinZeilen zweier Dateien über ein gemeinsames Feld verbinden
trZeichen ersetzen oder löschen
expand / unexpandTabulatoren in Leerzeichen umwandeln und umgekehrt
fmtText auf eine Zielbreite formatieren
foldZeilen auf eine Breite umbrechen
nlZeilen nummerieren
odDateien oktal oder in anderen Formaten ausgeben
printfDaten formatiert ausgeben
split / csplitDateien in Teile zerlegen
commZwei sortierte Dateien zeilenweise vergleichen
ptxPermutierten Index erzeugen
sum / md5sum / sha1sum / sha256sumPrüfsummen berechnen
base32 / base64Daten kodieren und dekodieren

Shell-Dienstprogramme

BefehlBeschreibung
echoEine Zeile Text ausgeben
printfFormatierte Ausgabe

basename / dirnameDateinamen bzw. Verzeichnisteil eines Pfades ausgeben
envProgramm mit veränderter Umgebung ausführen
exprAusdrücke auswerten

true / falseNichts tun, erfolgreich bzw. nicht erfolgreich
sleepEine angegebene Zeit warten
seqZahlenfolgen ausgeben
yesZeichenkette wiederholt ausgeben
teeStandardeingabe lesen und in Datei und Ausgabe schreiben
ttyDateinamen des mit der Standardeingabe verbundenen Terminals ausgeben
unameSysteminformationen ausgeben
whoami / id / groupsBenutzerinformationen ausgeben
dateDatum und Uhrzeit ausgeben oder setzen
cal-ähnlich: nproc, uptime, hostnameSysteminformationen
timeoutBefehl mit Zeitlimit ausführen
nohup / nice / stdbuf / chrootAusführungsumgebung anpassen
killProzesse beenden (Shell-Builtin bzw. util-linux)
factorZahlen in Primfaktoren zerlegen
getlimits, dircolors, vdir, dirWeitere Hilfsprogramme
