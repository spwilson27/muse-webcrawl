Extremalpunkt

Extremalpunkt
EnglischExtreme point
GebietKonvexe Geometrie, Funktionalanalysis
Verwandter SatzSatz von Krein-Milman

Ein Extremalpunkt (englisch extreme point) einer konvexen Menge in einem reellen oder komplexen Vektorraum ist ein Punkt dieser Menge, der nicht im Inneren einer Strecke zwischen zwei verschiedenen anderen Punkten der Menge liegt. Anschaulich entsprechen Extremalpunkte den „Ecken" einer konvexen Menge: In einem Polygon sind die Eckpunkte Extremalpunkte, während bei einer Kreisscheibe jeder Punkt des Randes ein Extremalpunkt ist.

Definition

Formal heißt ein Punkt x einer konvexen Menge K Extremalpunkt, wenn aus x = ty + (1−t)z mit y, z ∈ K und 0 < t < 1 stets y = z = x folgt. Äquivalent: K ohne den Punkt x ist weiterhin konvex.

Bedeutung

Der Satz von Krein-Milman besagt, dass jede kompakte konvexe Menge in einem lokalkonvexen Raum die abgeschlossene konvexe Hülle ihrer Extremalpunkte ist – die Menge wird also vollständig durch ihre Extremalpunkte bestimmt. In der linearen Optimierung folgt daraus, dass ein lineares Programm, das eine optimale Lösung besitzt, diese auch in einem Extremalpunkt (einer Ecke) des zulässigen Polyeders annimmt; hierauf baut das Simplex-Verfahren auf. In der Wahrscheinlichkeitstheorie und mathematischen Physik treten Extremalpunkte als reine Zustände beziehungsweise ergodische Maße auf.

Beispiele

  • Die Ecken eines Würfels oder Simplex sind dessen Extremalpunkte.
  • Eine offene konvexe Menge besitzt keine Extremalpunkte.
  • In unendlichdimensionalen Räumen kann eine kompakte konvexe Menge sehr viele, aber stets genügend viele Extremalpunkte besitzen (Krein-Milman).
