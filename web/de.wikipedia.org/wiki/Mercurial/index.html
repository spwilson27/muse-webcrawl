Mercurial

Mercurial ist ein verteiltes Versionsverwaltungssystem für Softwareprojekte. Es wurde 2005 von Olivia Mackall (damals Matt Mackall) in Python entwickelt und steht unter der GNU General Public License.

Eigenschaften

Mercurial arbeitet dezentral: Jeder Entwickler besitzt eine vollständige Kopie des Repositories samt Historie. Das System ist für Geschwindigkeit und Skalierbarkeit ausgelegt und wird über die Kommandozeile mit dem Befehl hg gesteuert – benannt nach dem chemischen Symbol für Quecksilber (englisch mercury).

Verbreitung

Mercurial wurde zeitweise von großen Projekten und Unternehmen genutzt, darunter Mozilla und Facebook, das eigene Erweiterungen für sehr große Repositories entwickelte. Inzwischen dominiert Git den Markt weitgehend.
