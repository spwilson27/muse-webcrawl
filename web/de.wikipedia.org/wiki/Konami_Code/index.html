Konami Code

Der Konami Code (auch Contra Code) ist eine bekannte Cheat-Tastenkombination in Videospielen des Herstellers Konami. Die Sequenz lautet auf dem Steuerkreuz: ↑ ↑ ↓ ↓ ← → ← → B A, häufig gefolgt von Start oder Select.

Entstehung

Der Code wurde von Kazuhisa Hashimoto entwickelt, der 1986 die NES-Umsetzung des Arcade-Spiels Gradius testete und das Spiel als zu schwierig empfand. Er programmierte die Kombination als Testhilfe ein, die dem Spieler volle Bewaffnung verlieh; sie wurde versehentlich nicht vor der Veröffentlichung entfernt.

Verbreitung

Weltberühmt wurde der Code durch das Spiel Contra (1988), in dem er 30 Leben gewährte. Danach tauchte er in zahlreichen weiteren Konami-Titeln auf, darunter Castlevania, Teenage Mutant Ninja Turtles und Dance Dance Revolution.

Rezeption

Der Konami Code ist heute ein fester Bestandteil der Popkultur. Er wird als Easter Egg auf vielen Websites eingesetzt und in Filmen, Serien und Musik zitiert.
