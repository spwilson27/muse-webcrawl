Konstruktor (objektorientierte Programmierung)

Ein Konstruktor ist in der objektorientierten Programmierung eine spezielle Methode einer Klasse, die beim Erzeugen eines Objekts (Instanz) automatisch aufgerufen wird. Er dient dazu, das Objekt in einen gültigen Anfangszustand zu versetzen, etwa indem Attribute mit Anfangswerten belegt und Ressourcen bereitgestellt werden.

Eigenschaften

In vielen Sprachen wie Java, C++ oder C# trägt der Konstruktor den Namen der Klasse und besitzt keinen Rückgabetyp. Klassen können mehrere Konstruktoren mit unterschiedlichen Parameterlisten besitzen (Überladung). Wird kein Konstruktor definiert, stellen viele Sprachen einen parameterlosen Standardkonstruktor bereit. Das Gegenstück ist der Destruktor, der beim Zerstören des Objekts aufräumt.

class Punkt {
    int x, y;
    Punkt(int x, int y) {   // Konstruktor
        this.x = x;
        this.y = y;
    }
}

Besondere Formen

Man unterscheidet unter anderem Kopierkonstruktoren (Erzeugung eines Objekts als Kopie eines anderen), Move-Konstruktoren in C++, statische Konstruktoren zur Initialisierung von Klassenvariablen sowie private Konstruktoren, die die Instanziierung von außen verhindern – etwa beim Singleton-Muster oder bei Fabrikmethoden. In Python übernimmt die Methode __init__ die Rolle des Konstruktors im weiteren Sinne, während __new__ das Objekt tatsächlich erzeugt.
