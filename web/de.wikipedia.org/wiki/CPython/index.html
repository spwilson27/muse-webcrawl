CPython

CPython ist die Referenzimplementierung der Programmiersprache Python. Sie ist in C geschrieben und wird von der Python Software Foundation entwickelt. Wenn von „Python" ohne Zusatz die Rede ist, ist in der Regel CPython gemeint.

Eigenschaften

CPython übersetzt Python-Quelltext zunächst in Bytecode, der von einer virtuellen Maschine ausgeführt wird. Das Speichermanagement erfolgt weitgehend automatisch über Referenzzählung, ergänzt durch einen zyklischen Garbage Collector. Charakteristisch ist der Global Interpreter Lock (GIL), der verhindert, dass mehrere Threads gleichzeitig Python-Bytecode ausführen; ab Version 3.13 wird experimentell ein Betrieb ohne GIL angeboten. Über die C-API lassen sich Erweiterungsmodule in C einbinden, was CPython zur Grundlage vieler wissenschaftlicher Bibliotheken wie NumPy macht.

Entwicklung

Die Versionen erscheinen in einem jährlichen Rhythmus. Mit dem „Faster CPython"-Projekt wurden ab Python 3.11 erhebliche Geschwindigkeitsgewinne erzielt, unter anderem durch einen spezialisierenden, adaptiven Interpreter. Alternative Implementierungen sind PyPy (mit JIT-Compiler), Jython (JVM) und IronPython (.NET).
