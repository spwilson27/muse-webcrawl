Programmiersprache
Formale Sprache zur Erstellung von Computerprogrammen

Erste höhere Sprache:
Plankalkül (1940er), Fortran (1957)

Einteilung:
Imperativ, deklarativ, funktional, objektorientiert

Merkmale:
Syntax, Semantik, Typsystem

Eine Programmiersprache ist eine formale Sprache zur Formulierung von Datenstrukturen und Algorithmen, also von Rechenvorschriften, die von einem Computer ausgeführt werden können. Programmiersprachen richten sich an den Menschen und sollen ihm eine verständliche Darstellung von Programmen ermöglichen; damit der Computer ein Programm ausführen kann, muss es in Maschinensprache übersetzt (compiliert) oder zur Laufzeit interpretiert werden.

Geschichte

Die erste höhere Programmiersprache war der Plankalkül, den Konrad Zuse in den 1940er Jahren entwarf, der jedoch zu seinen Lebzeiten kaum praktische Verbreitung fand. Als erste kommerziell erfolgreiche höhere Sprache gilt Fortran (1957), entwickelt unter John Backus bei IBM. Es folgten Lisp (1958), COBOL und ALGOL (um 1960), BASIC (1964), Pascal (1970), C (1972) und viele weitere. Spätere einflussreiche Sprachen sind C++ (1983), Python (1991), Java (1995), JavaScript (1995), C# (2000) sowie moderne Sprachen wie Rust, Go und Kotlin.

Einteilung

  • Nach Abstraktionsebene: Maschinensprachen und Assemblersprachen (niedrig) gegenüber höheren Programmiersprachen.
  • Nach Paradigma: Imperativ, prozedural, objektorientiert, funktional, logisch, deklarativ.
  • Nach Typisierung: Statisch oder dynamisch, stark oder schwach typisiert.
  • Nach Ausführung: Compilierte Sprachen gegenüber interpretierten Sprachen; viele moderne Implementierungen mischen beide Modelle.

Bestandteile

Eine Programmiersprache wird durch ihre Syntax (die Form erlaubter Programme), ihre Semantik (deren Bedeutung) und meist eine Standardbibliothek beschrieben. Ihre Implementierung erfolgt über einen Compiler, Assembler oder Interpreter.

Verbreitung

Heute existieren Tausende von Programmiersprachen; eine kleine Zahl dominiert die Praxis. Zu den am weitesten verbreiteten zählen Python, JavaScript, Java, C, C++, C# und SQL.
