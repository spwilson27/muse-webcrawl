Schnittstelle (Informatik)

Eine Schnittstelle (englisch interface) ist in der Informatik der Übergang zwischen zwei Komponenten eines Systems, über den Daten oder Steuerinformationen ausgetauscht werden. Schnittstellen legen fest, welche Funktionen und Datenformate zur Verfügung stehen, ohne die innere Umsetzung offenzulegen.

Arten

Hardware-Schnittstellen wie USB, HDMI oder PCIe verbinden Geräte physisch und elektrisch. Software-Schnittstellen umfassen Programmierschnittstellen (APIs), mit denen Programme aufeinander zugreifen, sowie Benutzerschnittstellen, über die Menschen mit dem System interagieren. In objektorientierten Programmiersprachen wie Java bezeichnet ein Interface zudem einen Typ, der Methodensignaturen ohne Implementierung definiert.

Bedeutung

Standardisierte Schnittstellen ermöglichen die Austauschbarkeit von Komponenten und die Arbeitsteilung in der Softwareentwicklung. Siehe auch: Schnittstellenbeschreibungssprache, Interface Design.
