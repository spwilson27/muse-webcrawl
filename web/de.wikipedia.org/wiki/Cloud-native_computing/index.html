Cloud Native Computing

Cloud Native Computing bezeichnet einen Ansatz zur Entwicklung und zum Betrieb von Anwendungen, die die Vorteile des Cloud Computing konsequent nutzen. Cloud-native Anwendungen sind darauf ausgelegt, in dynamischen, virtualisierten Umgebungen zu laufen, elastisch zu skalieren und Ausfälle einzelner Komponenten zu tolerieren.

Definition

Die Cloud Native Computing Foundation (CNCF) definiert Cloud Native als Technologien, die es Organisationen ermöglichen, skalierbare Anwendungen in modernen, dynamischen Umgebungen – öffentlichen, privaten und hybriden Clouds – zu erstellen und auszuführen. Zu den zentralen Bausteinen zählen Container, Microservices, unveränderliche Infrastruktur, deklarative Schnittstellen (APIs) und Service Meshes.

Prinzipien

  • Containerisierung: Anwendungen und ihre Abhängigkeiten werden in Containern verpackt und isoliert ausgeführt.
  • Orchestrierung: Systeme wie Kubernetes übernehmen Bereitstellung, Skalierung und Selbstheilung der Container.
  • Microservices: Anwendungen werden in kleine, lose gekoppelte Dienste zerlegt, die unabhängig entwickelt und bereitgestellt werden können.
  • Automatisierung: Continuous Integration und Continuous Delivery (CI/CD) sowie Infrastructure as Code automatisieren Bereitstellung und Betrieb.
  • Beobachtbarkeit: Metriken, Protokolle und Traces machen das Verhalten verteilter Systeme nachvollziehbar.

Abgrenzung

Cloud Native geht über die bloße Verlagerung bestehender Anwendungen in eine Cloud („Lift and Shift“) hinaus. Während migrierte Altanwendungen häufig monolithisch bleiben, werden cloud-native Anwendungen von Grund auf für verteilte, fehlertolerante Umgebungen entworfen.
