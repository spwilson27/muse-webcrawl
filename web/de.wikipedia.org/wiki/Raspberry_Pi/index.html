Raspberry Pi

Der Raspberry Pi ist ein Einplatinencomputer, der von der britischen Raspberry Pi Foundation entwickelt wurde, um den Informatikunterricht an Schulen zu fördern und den Zugang zu preiswerter Computertechnik zu erleichtern. Seit seiner Einführung im Jahr 2012 wurden weltweit mehrere zehn Millionen Geräte verkauft.

Raspberry Pi

Entwickler: Raspberry Pi Foundation
Erstveröffentlichung: 2012
Architektur: ARM
Betriebssystem: Raspberry Pi OS, Linux u. a.

Geschichte

Die Idee zu einem preiswerten Lerncomputer geht auf Eben Upton und Kollegen der Universität Cambridge zurück, die einen Rückgang der Programmierkenntnisse bei Studienbewerbern beobachteten. Das erste Modell, der Raspberry Pi Model B, erschien im Februar 2012 zu einem Preis von 35 US-Dollar. Es folgten zahlreiche weitere Modelle, darunter der besonders günstige Raspberry Pi Zero (2015), der leistungsstarke Raspberry Pi 4 Model B (2019), der in eine Tastatur integrierte Raspberry Pi 400 (2020) und der Raspberry Pi 5 (2023).

Hardware

Die Platinen basieren auf einem System-on-a-Chip (SoC) von Broadcom mit ARM-Prozessorkernen und einer Grafikeinheit (VideoCore). Je nach Modell stehen USB-Anschlüsse, ein Ethernet-Port, HDMI-Ausgänge, ein Steckplatz für microSD-Karten sowie eine 40-polige GPIO-Stiftleiste zur Ansteuerung externer Elektronik zur Verfügung. Die Stromversorgung erfolgt über USB.

Software

Als offizielles Betriebssystem wird Raspberry Pi OS (früher Raspbian) angeboten, eine auf Debian basierende Linux-Distribution. Daneben laufen zahlreiche weitere Systeme, darunter Ubuntu, LibreELEC und verschiedene Retro-Gaming- und IoT-Plattformen.

Verwendung

Neben dem Bildungseinsatz wird der Raspberry Pi für Heimautomatisierung, Mediacenter, Server, Industriesteuerungen, Robotik und Bastelprojekte der Maker-Szene genutzt. Speziell für eingebettete Anwendungen gibt es die Compute-Module-Reihe, für Mikrocontroller-Anwendungen den Raspberry Pi Pico mit dem hauseigenen Chip RP2040.
