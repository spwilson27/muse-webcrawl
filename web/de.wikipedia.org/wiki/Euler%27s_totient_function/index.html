Eulersche Phi-Funktion

Die Eulersche Phi-Funktion, meist mit φ(n) bezeichnet, ordnet jeder natürlichen Zahl n die Anzahl der zu n teilerfremden Zahlen im Bereich 1 bis n zu. Sie ist eine der wichtigsten zahlentheoretischen Funktionen und nach Leonhard Euler benannt.

Eigenschaften

Für eine Primzahl p gilt φ(p) = p − 1, da alle kleineren positiven Zahlen teilerfremd zu p sind. Für eine Primzahlpotenz gilt φ(pk) = pk − pk−1. Die Phi-Funktion ist schwach multiplikativ: Sind m und n teilerfremd, so ist φ(mn) = φ(m)·φ(n). Daraus folgt die Berechnungsformel über die Primfaktorzerlegung: φ(n) = n · ∏ (1 − 1/p), wobei das Produkt über alle Primteiler von n läuft. Beispiele: φ(1) = 1, φ(6) = 2, φ(9) = 6, φ(10) = 4.

Anwendung

Die Phi-Funktion tritt im Satz von Euler auf (aφ(n) ≡ 1 mod n für teilerfremdes a), der eine Grundlage des RSA-Verschlüsselungsverfahrens bildet. Sie gibt außerdem die Ordnung der multiplikativen Gruppe der Einheiten des Restklassenrings Z/nZ an und hängt mit der Anzahl der Stammbrüche und der Farey-Folgen zusammen.
