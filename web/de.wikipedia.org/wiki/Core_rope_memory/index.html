Core Rope Memory

Core Rope Memory (deutsch etwa „Kernseilspeicher“) ist eine Form des Festwertspeichers (ROM), die in den 1960er Jahren unter anderem im Apollo Guidance Computer (AGC) der NASA verwendet wurde. Die Technik wurde am MIT Instrumentation Laboratory entwickelt und von der Firma Raytheon gefertigt.

Funktionsweise

Beim Core Rope Memory werden Drähte durch oder um kleine Ferritkerne (Magnetkerne) gefädelt. Jeder Kern repräsentiert mehrere Bits: Ein Draht, der durch einen Kern geführt wird, codiert eine „1“, ein Draht, der am Kern vorbeigeführt wird, eine „0“. Da pro Kern bis zu 64 Drähte hindurchgeführt werden konnten, erreichte das Verfahren eine für die damalige Zeit sehr hohe Speicherdichte.

Einsatz im Apollo-Programm

Im Apollo Guidance Computer speicherte das Core Rope Memory die Flugsoftware. Das Einfädeln der Drähte war aufwändige Handarbeit, die überwiegend von Frauen ausgeführt wurde; das Verfahren erhielt daher scherzhaft den Namen „LOL memory“ (von „Little Old Ladies“). Einmal gefertigte Module waren nicht mehr veränderbar, was eine besonders sorgfältige Prüfung der Software vor der Produktion erforderte.

Vorteile und Nachteile

Zu den Vorteilen zählten die hohe Datendichte, die Unempfindlichkeit gegenüber Strahlung und der nichtflüchtige Charakter des Speichers. Nachteilig waren die aufwändige Fertigung und die fehlende Möglichkeit, Daten nachträglich zu ändern. Später wurde die Technik durch Halbleiterspeicher verdrängt.
