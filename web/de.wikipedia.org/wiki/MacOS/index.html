macOS

macOS ist das Betriebssystem von Apple für seine Mac-Computer. Es erschien 2001 unter dem Namen Mac OS X und ging aus dem von NeXT entwickelten NeXTSTEP hervor, nachdem Apple 1997 das Unternehmen von Steve Jobs übernommen hatte. Zwischen 2012 und 2016 hieß es OS X, seither macOS.

Technik

macOS basiert auf dem Unix-Kern Darwin, der den Mach-Kernel mit Komponenten aus FreeBSD verbindet. Auf ihm setzen die Grafikoberfläche Aqua und Frameworks wie Cocoa auf. Das System ist für die Gerätefamilien MacBook Air, MacBook Pro, iMac, Mac mini, Mac Studio und Mac Pro ausgelegt.

Versionen

Frühe Versionen trugen Raubkatzennamen (Cheetah, Panther, Tiger, Leopard, Snow Leopard, Lion). Seit 2013 werden kalifornische Orte verwendet, darunter Mavericks, Yosemite, El Capitan, Sierra, Mojave, Catalina, Big Sur, Monterey, Ventura, Sonoma und Sequoia. Neue Hauptversionen erscheinen jährlich und werden kostenlos bereitgestellt.

Geschichte

macOS löste das klassische Mac OS ab, dessen letzte Version Mac OS 9 (1999) war. Mit dem Übergang zu Apple Silicon ab 2020 wurde das System für ARM-Prozessoren optimiert.
