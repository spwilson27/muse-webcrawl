Memory Debugger

Ein Memory Debugger (deutsch: Speicher-Debugger) ist ein Software-Werkzeug, das Programmierer dabei unterstützt, Fehler im Zusammenhang mit der Speicherverwaltung eines Programms zu finden. Dazu gehören Speicherlecks (Memory Leaks), Pufferüberläufe, Zugriffe auf bereits freigegebenen Speicher sowie das Lesen uninitialisierter Speicherbereiche.

Funktionsweise

Memory Debugger überwachen zur Laufzeit alle Speicheranforderungen und -freigaben eines Programms. Viele Werkzeuge arbeiten mit Instrumentierung: Der Quellcode oder die Binärdatei wird so verändert, dass jede Speicheroperation protokolliert und geprüft wird. Andere Ansätze nutzen spezielle Speicherallokatoren, die um jeden angeforderten Block Schutzbereiche (sogenannte Red Zones) legen, um Überläufe zu erkennen.

Bekannte Werkzeuge

  • Valgrind mit dem Werkzeug Memcheck – weit verbreitet unter Linux
  • AddressSanitizer – Compiler-integrierte Laufzeitprüfung von GCC und Clang
  • Purify – eines der frühen kommerziellen Produkte
  • Dr. Memory – Open-Source-Werkzeug für Windows und Linux
  • Electric Fence – Bibliothek zur Erkennung von Pufferüberläufen
