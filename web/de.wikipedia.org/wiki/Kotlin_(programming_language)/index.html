Kotlin (Programmiersprache)

Kotlin

Paradigma: objektorientiert, funktional
Erscheinungsjahr: 2011
Entwickler: JetBrains
Aktuelle Version: 2.x
Lizenz: Apache 2.0

Kotlin ist eine statisch typisierte Programmiersprache, die von der Firma JetBrains entwickelt wird. Sie läuft auf der Java Virtual Machine (JVM), kann aber auch nach JavaScript oder in nativen Code kompiliert werden. Der Name geht auf die Insel Kotlin nahe Sankt Petersburg zurück.

Geschichte

JetBrains stellte Kotlin 2011 vor; 2012 wurde das Projekt als Open Source unter der Apache-2.0-Lizenz veröffentlicht. Die Version 1.0 erschien im Februar 2016. Im Mai 2017 erklärte Google Kotlin zur offiziell unterstützten Sprache für die Android-Entwicklung, 2019 zur bevorzugten Sprache („Kotlin-first“) für Android-Apps.

Eigenschaften

Kotlin ist vollständig mit Java interoperabel, sodass bestehender Java-Code und Java-Bibliotheken weiterverwendet werden können. Zu den Merkmalen der Sprache zählen Null-Sicherheit durch das Typsystem, Datenklassen, Erweiterungsfunktionen, Smart Casts, Coroutinen für asynchrone Programmierung sowie eine im Vergleich zu Java deutlich kompaktere Syntax.

Verwendung

Neben der Android-Entwicklung wird Kotlin für serverseitige Anwendungen (etwa mit den Frameworks Ktor oder Spring), plattformübergreifende Entwicklung mit Kotlin Multiplatform und zunehmend auch für Desktop- und Webanwendungen eingesetzt.
