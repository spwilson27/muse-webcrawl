Secure Boot

Secure Boot (englisch für „sicherer Start“) ist eine Funktion der UEFI-Firmware, die beim Start eines Computers sicherstellt, dass nur vertrauenswürdige, kryptografisch signierte Software ausgeführt wird. Dazu prüft die Firmware die digitalen Signaturen des Bootloaders und der nachfolgenden Startkomponenten anhand gespeicherter Schlüssel, bevor sie diese ausführt.

Funktionsweise

Secure Boot basiert auf einer Public-Key-Infrastruktur innerhalb der Firmware. Wichtige Komponenten sind:

  • der Platform Key (PK), der den Besitzer der Plattform identifiziert,
  • die Key Exchange Keys (KEK), mit denen Datenbanken aktualisiert werden dürfen,
  • die Datenbank erlaubter Signaturen (db) und die Datenbank gesperrter Signaturen (dbx).

Stimmt die Signatur einer Startkomponente nicht mit den hinterlegten Schlüsseln überein, wird der Startvorgang abgebrochen. So soll verhindert werden, dass Bootkits und andere Schadsoftware sich vor dem Betriebssystem einnisten.

Geschichte und Verbreitung

Secure Boot wurde mit der UEFI-Spezifikation 2.2 eingeführt und verbreitete sich ab 2012 mit Windows 8, für dessen Zertifizierung Microsoft Secure Boot auf x86-Systemen vorschrieb. Dies löste eine Kontroverse aus, weil befürchtet wurde, alternative Betriebssysteme wie Linux könnten ausgesperrt werden. In der Praxis lassen die meisten Hersteller das Deaktivieren von Secure Boot oder das Hinzufügen eigener Schlüssel zu; Linux-Distributionen nutzen häufig den von Microsoft signierten Bootloader „Shim“.
