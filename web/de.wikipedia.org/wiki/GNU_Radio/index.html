GNU Radio ist ein freies Software-Toolkit zur Implementierung softwaredefinierter Funkgeräte (Software Defined Radio, SDR). Es stellt Blöcke zur Signalverarbeitung bereit, mit denen sich Empfänger und Sender für verschiedenste Funkstandards in Software realisieren lassen.

Architektur

Anwendungen werden als Flussgraphen (Flowgraphs) aus Signalverarbeitungsblöcken zusammengesetzt. Die rechenintensiven Blöcke sind in C++ geschrieben und werden über Python angebunden. Mit dem grafischen Werkzeug GNU Radio Companion lassen sich Flussgraphen per Drag-and-drop erstellen.

Hardware

GNU Radio arbeitet mit einer Vielzahl von SDR-Hardware zusammen, darunter die USRP-Familie (Universal Software Radio Peripheral) von Ettus Research, der HackRF One, der RTL-SDR-Empfänger sowie Geräte von BladeRF und LimeSDR.

Anwendungen

Eingesetzt wird GNU Radio in Forschung, Lehre, Amateurfunk und Industrie, etwa zum Empfang von GSM-, LTE-, ADS-B-, AIS- und Wettersatellitensignalen oder zur Entwicklung neuer drahtloser Kommunikationsverfahren.
