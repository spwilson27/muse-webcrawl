C ist eine imperative, prozedurale Programmiersprache, die Anfang der 1970er Jahre von Dennis Ritchie an den Bell Laboratories entwickelt wurde. Sie entstand im Zusammenhang mit der Entwicklung des Betriebssystems Unix und zählt bis heute zu den am weitesten verbreiteten Programmiersprachen, insbesondere in der Systemprogrammierung und bei eingebetteten Systemen.

Geschichte

C entwickelte sich ab 1969 aus der Sprache B, die ihrerseits auf BCPL zurückgeht. 1973 war das Unix-System weitgehend in C umgeschrieben. 1978 veröffentlichten Brian Kernighan und Dennis Ritchie das Buch „The C Programming Language“, dessen Sprachbeschreibung als „K&R C“ bekannt wurde. 1989/1990 wurde C vom ANSI- bzw. ISO-Gremium standardisiert (C89/C90). Weitere Standardversionen folgten mit C99, C11, C17 und C23.

Eigenschaften

C ist eine vergleichsweise kleine Sprache mit direktem Zugang zu Speicheradressen über Zeiger (Pointer), manueller Speicherverwaltung und einer Standardbibliothek für Ein-/Ausgabe, Speicherverwaltung und Zeichenkettenverarbeitung. Sie erlaubt hardwarenahe Programmierung und ist auf nahezu allen Plattformen verfügbar. Ein klassisches Beispielprogramm ist:

#include <stdio.h>

int main(void) {
    printf("Hallo, Welt!\n");
    return 0;
}

Anwendungsgebiete

In C sind unter anderem die Kernel von Unix, Linux und Windows (große Teile) sowie unzählige eingebettete Systeme, Datenbanken und Compiler geschrieben. Zahlreiche spätere Sprachen, darunter C# und C++, übernahmen Syntax und Konzepte von C.
