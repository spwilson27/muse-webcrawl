Gradle

Gradle ist ein Build-Automatisierungswerkzeug, das vor allem für Projekte in Java, Kotlin, Groovy und anderen Sprachen der Java Virtual Machine eingesetzt wird. Es wurde erstmals 2008 veröffentlicht und steht unter der Apache-Lizenz 2.0.

Konzept

Anders als ältere XML-basierte Werkzeuge wie Apache Ant oder Maven verwendet Gradle eine domänenspezifische Sprache auf Grundlage von Groovy oder Kotlin (Kotlin DSL), in der Build-Skripte verfasst werden. Ein Build wird als gerichteter azyklischer Graph von Aufgaben (Tasks) modelliert; Gradle führt nur die Aufgaben aus, deren Eingaben sich geändert haben, und unterstützt inkrementelle Builds sowie einen Build-Cache.

Einsatz

Gradle ist das offizielle Build-System für Android-Anwendungen und wird vom Spring Framework und vielen weiteren Projekten verwendet. Ein Gradle-Wrapper erlaubt es, eine festgelegte Gradle-Version ohne vorherige Installation zu nutzen, was reproduzierbare Builds sicherstellt. Plugins für Tests, Codequalität, Veröffentlichung und viele Programmiersprachen wie C/C++ oder Scala erweitern die Funktionalität.

Entwicklung

Entwickelt wird Gradle maßgeblich von der Firma Gradle Inc., die auch kommerzielle Zusatzprodukte wie den Gradle Enterprise Server (heute Develocity) anbietet.
