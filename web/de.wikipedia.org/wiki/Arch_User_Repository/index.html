Arch User Repository

Das Arch User Repository (kurz AUR) ist ein von der Community gepflegtes Repository für die Linux-Distribution Arch Linux. Es enthält keine fertigen Binärpakete, sondern sogenannte PKGBUILD-Dateien: Bauskripte, mit denen Benutzer Software aus dem Quellcode oder aus bereitgestellten Archiven selbst in installierbare Pakete überführen können.

Funktionsweise

Jeder registrierte Benutzer kann PKGBUILD-Skripte einreichen und pflegen. Andere Nutzer können die Skripte herunterladen, prüfen und das Paket mit dem Werkzeug makepkg erstellen und anschließend mit Pacman installieren. Zur bequemeren Nutzung existieren sogenannte AUR-Helper wie yay oder paru, die das Suchen, Bauen und Aktualisieren automatisieren. Die Pakete werden von den Benutzern bewertet; Abstimmungen und Kommentare dienen als Qualitätsindikator. Beliebte und gut gepflegte Pakete können in das offizielle Repository „extra“ übernommen werden.

Sicherheit

Da Inhalte des AUR nicht vom Arch-Team geprüft werden, liegt die Verantwortung für die Kontrolle der PKGBUILD-Dateien beim Anwender. In der Vergangenheit kam es vereinzelt zu Vorfällen mit manipulierten Skripten, weshalb die Community empfiehlt, PKGBUILDs vor dem Bauen zu lesen.

Bedeutung

Mit zehntausenden Paketen gehört das AUR zu den größten communautären Softwaresammlungen im Linux-Bereich und ist ein wesentlicher Grund für die Popularität von Arch Linux und seiner Ableitungen.
