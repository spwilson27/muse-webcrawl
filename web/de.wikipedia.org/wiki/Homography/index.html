Homographie

Eine Homographie (auch projektive Transformation oder Kollineation) ist eine bijektive Abbildung der projektiven Ebene auf sich selbst, die Geraden auf Geraden abbildet. In der Bildverarbeitung und Computer Vision bezeichnet man damit insbesondere die Abbildung zwischen zwei Bildern derselben ebenen Fläche oder zwischen zwei Aufnahmen desselben Schauplatzes bei reiner Kamerarotation.

Mathematische Beschreibung

Eine Homographie wird in homogenen Koordinaten durch eine reguläre 3×3-Matrix H beschrieben: x′ ≃ H·x. Da die Matrix nur bis auf einen Skalierungsfaktor bestimmt ist, besitzt die Homographie acht Freiheitsgrade. Aus vier Punktkorrespondenzen (von denen keine drei kollinear sein dürfen) kann H eindeutig bestimmt werden, etwa mit dem DLT-Verfahren (Direct Linear Transform).

Anwendungen

  • Zusammenfügen von Einzelbildern zu Panoramen (Image Stitching)
  • Entzerrung perspektivisch verzerrter Aufnahmen, z. B. von Dokumenten oder Gebäudefassaden
  • Augmented Reality: Einblendung virtueller Objekte auf ebene Marker
  • Videoanalyse im Sport, etwa zur Kalibrierung von Spielfeldmaßen
