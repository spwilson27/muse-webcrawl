Message Authentication Code

Ein Message Authentication Code (MAC) ist in der Kryptographie ein Prüfwert, mit dem die Echtheit (Authentizität) und Unversehrtheit (Integrität) einer Nachricht nachgewiesen werden kann. Im Gegensatz zu einer digitalen Signatur basiert ein MAC auf symmetrischer Kryptographie: Sender und Empfänger teilen sich einen geheimen Schlüssel, aus dem zusammen mit der Nachricht der MAC berechnet wird.

Funktionsweise

Der Sender berechnet über Nachricht und geheimen Schlüssel einen kurzen Authentifizierungs-Tag und hängt ihn an die Nachricht an. Der Empfänger berechnet den MAC mit demselben Schlüssel erneut und vergleicht ihn mit dem übermittelten Wert. Stimmen beide überein, kann der Empfänger davon ausgehen, dass die Nachricht unverändert ist und vom Inhaber des Schlüssels stammt. Eine Vertraulichkeit der Nachricht wird durch einen MAC nicht erreicht.

Konstruktionen

Zu den gebräuchlichsten Verfahren zählen:

  • HMAC – eine Konstruktion auf Basis kryptographischer Hashfunktionen wie SHA-2.
  • CMAC – ein MAC auf Basis von Blockchiffren wie AES (auch als OMAC bekannt).
  • Poly1305 – ein schneller MAC, der unter anderem zusammen mit ChaCha20 eingesetzt wird.
  • Ältere Verfahren wie CBC-MAC, die nur bei Nachrichten fester Länge sicher sind.

Anwendung

MACs werden in zahlreichen Protokollen verwendet, etwa in TLS, IPsec und SSH, um die Integrität übertragener Daten zu sichern. In der modernen Praxis werden häufig Verfahren der authentifizierten Verschlüsselung (AEAD) eingesetzt, die Verschlüsselung und MAC in einem Schritt kombinieren.
