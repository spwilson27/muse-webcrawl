COFF

COFF (Common Object File Format) ist ein Dateiformat für ausführbare Dateien, Objektcode und Bibliotheken, das ursprünglich für Unix-Systeme entwickelt wurde. Es wurde mit UNIX System V Release 3 eingeführt und ersetzte dort das ältere a.out-Format.

Aufbau

Eine COFF-Datei besteht aus einem Dateikopf (File Header), einem optionalen Kopf für ausführbare Dateien sowie mehreren Sektionen (Sections), die Code, initialisierte und nicht initialisierte Daten enthalten. Hinzu kommen Relokationsinformationen, Zeilennummerneinträge und eine Symboltabelle mit zugehöriger Zeichenkettentabelle. Gegenüber a.out bot COFF durch das Sektionskonzept größere Flexibilität, etwa für eingebettete Systeme und eigene Speicherbereiche.

Varianten und Nachfolger

Unter Unix wurde COFF weitgehend durch das Format ELF (Executable and Linking Format) abgelöst. Eine erweiterte Variante von COFF bildet jedoch bis heute die Grundlage des PE-Formats (Portable Executable), das von Microsoft Windows für EXE- und DLL-Dateien verwendet wird. Auch Entwicklungswerkzeuge für Mikrocontroller und digitale Signalprozessoren nutzen häufig COFF-Abkömmlinge.
