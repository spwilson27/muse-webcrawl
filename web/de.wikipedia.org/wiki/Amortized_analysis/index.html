Amortisierte Analyse

Die amortisierte Analyse ist eine Methode der theoretischen Informatik zur Analyse der Laufzeit von Algorithmen. Sie betrachtet nicht die Kosten einer einzelnen Operation im schlechtesten Fall, sondern die durchschnittlichen Kosten über eine ganze Folge von Operationen, wobei teure Operationen durch viele billige Operationen „amortisiert" werden. Das Ergebnis ist eine garantierte Schranke für die Gesamtkosten der Folge, nicht nur eine statistische Erwartung.

Motivation

Bei dynamischen Datenstrukturen können einzelne Operationen gelegentlich sehr teuer sein, während die meisten Operationen billig sind. Ein klassisches Beispiel ist das dynamische Array: Das Anhängen eines Elements kostet normalerweise konstant viel Zeit, doch wenn die Kapazität erschöpft ist, muss ein doppelt so großes Array angelegt und alle Elemente kopiert werden, was lineare Zeit kostet. Die amortisierte Analyse zeigt, dass die Kosten pro Einfügeoperation dennoch konstant (O(1)) sind.

Methoden

  • Aggregatmethode: Man bestimmt die Gesamtkosten T(n) einer Folge von n Operationen und teilt sie durch n.
  • Buchungsmethode (Kontenmethode): Billige Operationen werden mit einem höheren Betrag belastet; das Guthaben bezahlt spätere teure Operationen.
  • Potenzialmethode: Eine Potenzialfunktion ordnet jedem Zustand der Datenstruktur einen Wert zu; die amortisierten Kosten ergeben sich aus den tatsächlichen Kosten plus der Potenzialänderung.

Beispiele

Weitere klassische Anwendungsfälle sind der Binärzähler, bei dem das Inkrementieren amortisiert konstante Kosten hat, die Multipop-Operation beim Stack, Splay-Bäume sowie die Fibonacci-Heaps, deren Effizienz wesentlich auf amortisierter Analyse beruht. Der Begriff wurde in den 1980er Jahren unter anderem von Robert Tarjan geprägt und systematisiert.
