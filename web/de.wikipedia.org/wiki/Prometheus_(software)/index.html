Prometheus (Software)

Prometheus
Entwickler: Community, ursprünglich SoundCloud
Erstveröffentlichung: 2012
Programmiersprache: Go
Lizenz: Apache License 2.0
Kategorie: Monitoring

Prometheus ist eine freie Software zur Überwachung (Monitoring) von Computersystemen und Anwendungen. Sie sammelt Metriken in einer Zeitreihendatenbank und ermöglicht deren Abfrage mit der eigens entwickelten Abfragesprache PromQL. Benannt ist sie nach dem Titanen Prometheus.

Architektur

Prometheus arbeitet nach dem Pull-Prinzip: Der Server ruft in regelmäßigen Abständen HTTP-Endpunkte (Targets) ab, auf denen Anwendungen oder Exporter Metriken im Textformat bereitstellen. Die Daten werden lokal in einer optimierten Zeitreihendatenbank gespeichert. Metriken werden durch einen Namen und eine Menge von Schlüssel-Wert-Paaren (Labels) identifiziert, was mehrdimensionale Abfragen erlaubt.

Komponenten

  • Prometheus Server – Datensammlung, Speicherung und Abfrage
  • Alertmanager – Verarbeitung und Weiterleitung von Alarmen
  • Exporter – Adapter für Drittsysteme, z. B. der Node Exporter für Systemmetriken
  • Pushgateway – für kurzlebige Jobs, die keine regelmäßige Abfrage erlauben
  • Client-Bibliotheken – zur Instrumentierung eigener Anwendungen

Geschichte

Prometheus wurde ab 2012 bei SoundCloud entwickelt und 2015 als Open Source veröffentlicht. 2016 wurde das Projekt als zweites nach Kubernetes in die Cloud Native Computing Foundation (CNCF) aufgenommen und erreichte 2018 den Status eines graduierten Projekts. Prometheus ist eng mit dem Dashboard-Werkzeug Grafana verbunden und gilt als Standard für das Monitoring von Kubernetes-Umgebungen.
