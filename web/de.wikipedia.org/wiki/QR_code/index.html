QR-Code

Der QR-Code (englisch Quick Response, „schnelle Antwort“) ist eine zweidimensionale Codierung, die 1994 von der japanischen Firma Denso Wave zur Markierung von Bauteilen in der Automobilproduktion entwickelt wurde. Heute ist er weltweit verbreitet, etwa für Weblinks, Fahrkarten, Zahlungsvorgänge und Produktinformationen.

Aufbau

Ein QR-Code besteht aus einer quadratischen Matrix schwarzer und weißer Module. Drei große Positionsmarkierungen in den Ecken ermöglichen das Einlesen aus beliebigen Richtungen. Die Daten werden mit Reed-Solomon-Fehlerkorrektur gesichert, sodass der Code auch bei teilweiser Beschädigung lesbar bleibt. Je nach Version (1 bis 40) fasst ein QR-Code bis zu 7.089 Ziffern oder 4.296 alphanumerische Zeichen.

Verwendung

Mit der Verbreitung von Smartphones, deren Kameras QR-Codes direkt auslesen, fand der Code Eingang in Werbung, Gastronomie, ÖPNV und bargeldlose Zahlungssysteme, insbesondere in Ostasien.
