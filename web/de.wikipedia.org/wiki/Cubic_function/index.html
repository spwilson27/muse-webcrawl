Kubische Funktion

Eine kubische Funktion ist eine ganzrationale Funktion dritten Grades der Form f(x) = ax³ + bx² + cx + d mit a ≠ 0. Ihr Graph ist eine kubische Parabel, die stets einen Wendepunkt besitzt und punktsymmetrisch zu diesem ist.

Eigenschaften

Da der Grad ungerade ist, strebt die Funktion für x → +∞ und x → −∞ gegen entgegengesetzte unendliche Werte; sie ist auf den reellen Zahlen surjektiv und besitzt mindestens eine Nullstelle. Je nach Koeffizienten kann sie ein oder zwei Extrempunkte (Hoch- und Tiefpunkt) haben oder streng monoton wachsen beziehungsweise fallen. Die Ableitung einer kubischen Funktion ist eine quadratische Funktion, ihre Stammfunktion eine Funktion vierten Grades.

Nullstellen

Die Nullstellen kubischer Funktionen werden mit den Cardanischen Formeln bestimmt, siehe kubische Gleichung. Der einfachste Fall ist die reine Kubikfunktion f(x) = x³, deren Umkehrfunktion die Kubikwurzel ist.
