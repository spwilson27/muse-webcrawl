Lexical set

Ein lexical set (englisch für „lexikalisches Set“) ist in der Phonologie eine Gruppe von Wörtern, die alle denselben betonten Vokal (oder Diphthong) in einer bestimmten Varietät des Englischen teilen. Das Konzept wurde 1982 von dem Phonetiker John C. Wells in seinem Werk Accents of English eingeführt, um die Aussprache verschiedener englischer Akzente systematisch vergleichen zu können.

Schlüsselwörter

Jedes Set wird durch ein Schlüsselwort in Großbuchstaben bezeichnet, das den betreffenden Vokal repräsentiert. Bekannte Sets sind:

SetBeispielwörter
KITship, bridge, milk
DRESSstep, head, ready
TRAPcat, back, hand
LOTstop, rob, box
FOOTput, bush, full
FLEECEcreep, leave, feel
FACEtape, cake, day
PALMfather, bra, calm
GOOSEgoose, two, blue

Verwendung

Weil sich Wörter in unterschiedlichen Akzenten unterschiedlich verhalten – etwa ob TRAP und BATH zusammenfallen –, erlaubt die Notation präzise Aussagen wie „Im südenglischen Standard haben BATH-Wörter denselben Vokal wie PALM“. Lexical sets sind heute Standard in der Akzentbeschreibung und im Englischunterricht.
