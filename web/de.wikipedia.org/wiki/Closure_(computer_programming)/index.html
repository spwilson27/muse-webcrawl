Closure (Funktion)

Eine Closure (deutsch: Funktionsabschluss) ist in der Programmierung eine anonyme oder benannte Funktion, die auf Variablen aus ihrer definierenden Umgebung zugreifen kann, selbst wenn diese Umgebung zur Ausführungszeit nicht mehr existiert. Man sagt, die Funktion „schließt über" die freien Variablen ihrer Umgebung („closes over").

Konzept

Closures verbinden Funktionscode mit einer Umgebung (Environment), in der die Werte der freien Variablen gespeichert sind. Sie ermöglichen Zustandsbehaftung ohne globale Variablen, Fabrikfunktionen, die spezialisierte Funktionen erzeugen, sowie Callback- und Ereignisbehandlung. Das Konzept stammt aus der Theorie der Programmiersprachen (Lambda-Kalkül) und wurde zuerst in Sprachen wie Lisp und Scheme verwirklicht.

Verwendung

Heute unterstützen die meisten modernen Sprachen Closures, darunter JavaScript, Python, Ruby, Swift, Kotlin und – seit Java 8 über Lambda-Ausdrücke – auch Java. In JavaScript sind Closures ein zentrales Idiom, etwa um private Daten in Modulen zu kapseln. Je nach Sprache werden Variablen per Referenz (Änderungen bleiben sichtbar) oder per Wert (Kopie zum Definitionszeitpunkt) eingefangen, was eine häufige Fehlerquelle darstellt.

Beispiel

Eine Funktion, die eine Zählerfunktion zurückgibt, bei der eine lokale Variable über mehrere Aufrufe hinweg erhalten bleibt, ist ein klassisches Beispiel: Die innere Funktion bildet eine Closure über die Zählvariable der äußeren Funktion.
