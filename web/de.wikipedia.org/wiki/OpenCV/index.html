OpenCV

OpenCV (englisch Open Source Computer Vision Library) ist eine freie Programmbibliothek für maschinelles Sehen und Bildverarbeitung. Sie enthält mehrere tausend optimierte Algorithmen und ist eine der am weitesten verbreiteten Bibliotheken auf diesem Gebiet.

Geschichte

OpenCV wurde 1999 von Intel ins Leben gerufen, um rechenintensive Bildverarbeitungsanwendungen zu fördern und eine gemeinsame Infrastruktur für Forschung und Industrie zu schaffen. Die erste Alpha-Version erschien 2000. Später wurde die Entwicklung unter anderem von Willow Garage und Itseez fortgeführt; heute wird die Bibliothek von der OpenCV Foundation betreut. Seit der Version 4.0 (2018) steht OpenCV unter der Apache-Lizenz 2.0.

Funktionen

Die Bibliothek ist in C++ geschrieben und bietet Schnittstellen für Python, Java und weitere Sprachen. Sie umfasst Funktionen zur Filterung, geometrischen Transformation, Merkmalserkennung (etwa SIFT, ORB), Objekterkennung, Kamerakalibrierung, 3D-Rekonstruktion und Videoverarbeitung sowie ein Modul für tiefe neuronale Netze (DNN), das Modelle gängiger Frameworks ausführen kann. Viele Algorithmen sind hardwarenah optimiert und laufen in Echtzeit.

Anwendung

OpenCV wird in Industrie, Forschung, Robotik, Überwachungstechnik, medizinischer Bildgebung und in zahllosen Hobbyprojekten eingesetzt.
