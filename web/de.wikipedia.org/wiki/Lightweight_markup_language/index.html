Lightweight Markup Language

Eine Lightweight Markup Language (deutsch etwa „leichtgewichtige Auszeichnungssprache“) ist eine vereinfachte Auszeichnungssprache, deren Quelltext auch ohne Umwandlung gut lesbar ist. Solche Sprachen werden üblicherweise in HTML oder andere Zielformate konvertiert und dienen dem Verfassen von Dokumentationen, Webseiten, Forenbeiträgen und Notizen.

Eigenschaften

Im Gegensatz zu HTML oder XML verzichten lightweight markup languages weitgehend auf spitze Klammern und lange Tags. Überschriften werden etwa durch vorangestellte Zeichen wie # oder durch Unterstreichungen markiert, Fettdruck durch Asterisken. Ziel ist, dass der Text bereits in Rohform seine Struktur erkennen lässt und schnell mit jedem Texteditor zu schreiben ist.

Bekannte Sprachen

  • Markdown (2004 von John Gruber und Aaron Swartz): weit verbreitet in Software-Dokumentation, Wikis und auf Plattformen wie GitHub
  • Textile: frühe Blog- und CMS-Sprache
  • reStructuredText: Standard in der Python-Dokumentation
  • AsciiDoc: für umfangreiche technische Dokumentation
  • Org-mode-Syntax und die Wikitext-Syntaxen der Wiki-Systeme, darunter MediaWiki
  • BBCode in Internetforen

Einsatz

Lightweight Markup Languages sind Grundlage vieler statischer Website-Generatoren, Wissensdatenbanken und Notizanwendungen. Umwandlungsprogramme wie Pandoc übersetzen zwischen zahlreichen dieser Formate und Zielformaten wie HTML, LaTeX und PDF.
