Bitfehlerhäufigkeit

Die Bitfehlerhäufigkeit (englisch bit error rate, BER, auch Bitfehlerrate) ist in der Nachrichtentechnik ein Maß für die Qualität einer digitalen Datenübertragung. Sie gibt das Verhältnis der fehlerhaft empfangenen Bits zur Gesamtzahl der übertragenen Bits an.

Definition

Die Bitfehlerhäufigkeit ist definiert als Quotient aus der Anzahl falsch übertragener Bits und der Gesamtzahl übertragener Bits. Sie hängt unter anderem vom Signal-Rausch-Verhältnis, der Modulation und der verwendeten Kanalcodierung ab. Eine BER von 10−9 bedeutet im Mittel einen Fehler pro Milliarde übertragener Bits.

Messung

Gemessen wird die BER mit speziellen Bitfehlerraten-Testern (BERT), die eine bekannte Prüffolge senden und empfangsseitig mit dem Sollmuster vergleichen. In der Praxis dient sie als Abnahmekriterium für Übertragungsstrecken: Für Glasfasernetze werden häufig Werte von 10−12 oder besser gefordert, während Funksysteme mit Fehlerkorrektur auch bei höheren Raten zuverlässig arbeiten können.
