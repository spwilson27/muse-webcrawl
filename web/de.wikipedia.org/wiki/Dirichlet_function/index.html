Dirichlet-Funktion

Die Dirichlet-Funktion (englisch Dirichlet function) ist eine mathematische Funktion, die von Peter Gustav Lejeune Dirichlet eingeführt wurde. Sie ist ein klassisches Beispiel einer Funktion, die in keinem Punkt stetig ist und die nicht Riemann-integrierbar ist.

Definition

Die Dirichlet-Funktion D: ℝ → ℝ ist definiert als charakteristische Funktion der rationalen Zahlen:

D(x) = 1, falls x rational ist, und D(x) = 0, falls x irrational ist.

Eigenschaften

  • Die Funktion ist überall unstetig: In jeder Umgebung eines beliebigen Punktes liegen sowohl rationale als auch irrationale Zahlen, sodass der Funktionswert ständig zwischen 0 und 1 springt.
  • Sie ist periodisch mit jeder rationalen Zahl als Periode.
  • Sie ist auf keinem Intervall Riemann-integrierbar, da ihre Obersummen stets 1 und ihre Untersummen stets 0 betragen.
  • Sie ist jedoch Lebesgue-integrierbar: Da die rationalen Zahlen eine Nullmenge bilden, ist sie fast überall gleich 0, und ihr Lebesgue-Integral über jedes beschränkte Intervall ist 0.
  • Sie ist kein punktweiser Grenzwert stetiger Funktionen (Baire-Klasse 1), wohl aber Grenzwert einer Doppelfolge stetiger Funktionen; sie gehört zur Baire-Klasse 2.

Varianten

Eine bekannte Abwandlung ist die Thomaesche Funktion (auch „Popcorn-Funktion“), die für rationale Zahlen p/q in gekürzter Form den Wert 1/q und für irrationale Zahlen den Wert 0 annimmt; sie ist auf den irrationalen Zahlen stetig.
