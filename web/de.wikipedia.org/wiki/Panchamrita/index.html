Panchamrita

Panchamrita (Sanskrit पञ्चामृत, pañcāmṛta, „fünf Nektare/Unsterblichkeitstränke“) ist eine Mischung aus fünf Zutaten, die im Hinduismus bei religiösen Riten verwendet wird, insbesondere beim rituellen Bad (Abhisheka) von Götterbildern und als gesegnete Speise (Prasada).

Zusammensetzung

Die traditionellen fünf Bestandteile sind:

  • Milch
  • Quark bzw. Joghurt (Dahi)
  • Ghee (geklärte Butter)
  • Honig
  • Zucker bzw. Jaggery

Regional kommen Varianten vor, etwa mit Banane, Kokoswasser, Tulsi-Blättern oder Rosenwasser; in Tamil Nadu ist eine fruchthaltige Version aus Banane, Rosinen, Datteln, Jaggery und Ghee verbreitet.

Verwendung

Panchamrita wird über das Murti (Götterbild) gegossen, aufgefangen und anschließend an die Gläubigen als Prasada verteilt. Der Name verweist auf die Amrita, den Unsterblichkeitstrank der Götter. Die Mischung spielt auch bei Festen wie Krishna Janmashtami eine Rolle.
