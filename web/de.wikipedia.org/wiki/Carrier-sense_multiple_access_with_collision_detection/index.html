Carrier Sense Multiple Access/Collision Detection

Kollisionserkennung auf einem gemeinsamen Bus

Carrier Sense Multiple Access/Collision Detection (CSMA/CD) ist ein Zugriffsverfahren für leitungsgebundene Netze, das Kollisionen erkennt und auflöst. Es war das klassische Medienzugriffsverfahren des Ethernet in Bus- und Hub-Topologien (Halbduplex-Betrieb).

Ablauf

Eine Station hört den Kanal ab und sendet nur bei freiem Medium. Während des Sendens überwacht sie die Leitung weiter; erkennt sie eine Kollision – etwa weil eine andere Station aufgrund der Signallaufzeit gleichzeitig zu senden begann –, bricht sie die Übertragung ab und sendet ein kurzes Störsignal (Jam-Signal), damit alle Stationen die Kollision registrieren. Anschließend wartet jede beteiligte Station eine nach dem Verfahren des truncated binary exponential backoff zufällig gewählte Zeit, bevor sie erneut sendet.

Mindestlänge der Rahmen

Damit eine Kollision noch während des Sendens bemerkt werden kann, muss ein Rahmen mindestens so lang sein, wie das Signal für Hin- und Rückweg durch das Netz benötigt (Slot Time). Beim klassischen Ethernet beträgt die Mindestlänge daher 64 Byte.

Bedeutung heute

Im modernen, geswitchten Ethernet mit Vollduplex-Verbindungen treten keine Kollisionen mehr auf, sodass CSMA/CD dort keine Rolle mehr spielt. Es bleibt jedoch ein grundlegendes Lehrbeispiel für verteilte Medienzugriffsverfahren.
