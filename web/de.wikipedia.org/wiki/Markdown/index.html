Markdown

Markdown ist eine 2004 von John Gruber in Zusammenarbeit mit Aaron Swartz entwickelte, vereinfachte Auszeichnungssprache. Ziel war es, Texte so zu schreiben, dass sie schon in der Quellform gut lesbar sind und sich leicht in HTML umwandeln lassen. Markdown wird weltweit für Dokumentationen, Readme-Dateien, Foren, Blogs und Notizen verwendet.

Syntax

Die Syntax nutzt einfache Zeichen aus der Tradition von Text-E-Mails: Überschriften werden mit # eingeleitet, Fettdruck mit doppelten Sternchen, Kursivschrift mit einfachen Sternchen oder Unterstrichen, Listen mit Bindestrichen oder Zahlen. Links und Bilder werden in eckigen und runden Klammern notiert.

# Überschrift
Dies ist ein **fetter** und ein *kursiver* Text.
- Listenpunkt
[Linktext](https://example.org)

Dialekte und Standardisierung

Da die ursprüngliche Spezifikation mehrdeutige Stellen enthielt, entstanden zahlreiche Dialekte, darunter GitHub Flavored Markdown (GFM), das Tabellen, Aufgabenlisten und Syntaxhervorhebung ergänzt und unter anderem auf der Plattform GitHub verwendet wird. Die Initiative CommonMark bemüht sich seit 2014 um eine präzise, einheitliche Spezifikation samt Referenzimplementierung.
