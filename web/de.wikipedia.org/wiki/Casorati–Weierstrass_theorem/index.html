Satz von Casorati-Weierstraß

Der Satz von Casorati-Weierstraß beschreibt in der Funktionentheorie das Bildverhalten holomorpher Funktionen nahe wesentlicher Singularitäten. Er geht auf Arbeiten von Felice Casorati (1868) und Karl Weierstraß (1876) zurück.

Formulierung

Sei f auf einer punktierten Umgebung eines Punktes z0 holomorph und besitze dort eine wesentliche Singularität. Dann liegt das Bild f(U \ {z0}) jeder punktierten Umgebung U dicht in ℂ. Anschaulich: Kommt man der Singularität beliebig nahe, so kommen die Funktionswerte jedem beliebigen Punkt der komplexen Ebene beliebig nahe.

Bedeutung und Verschärfung

Während eine Funktion an einem Pol betragsmäßig gegen unendlich strebt und an einer hebbaren Singularität einen endlichen Grenzwert besitzt, herrscht an einer wesentlichen Singularität „chaotisches" Verhalten. Der große Picardsche Satz verschärft die Aussage noch erheblich: Das Bild enthält sogar alle komplexen Zahlen mit höchstens einer Ausnahme, und jeder dieser Werte wird unendlich oft angenommen.

Beispiel

Die Funktion f(z) = exp(1/z) hat im Nullpunkt eine wesentliche Singularität. In jeder noch so kleinen Umgebung von 0 nimmt sie alle Werte außer der 0 an, was die Aussage des Satzes weit übertrifft und das Beispiel des Picardschen Satzes illustriert.
