Fixpunktfreie Permutation

Eine fixpunktfreie Permutation (englisch derangement, französisch dérangement) ist in der Kombinatorik eine Permutation einer Menge, bei der kein Element an seiner ursprünglichen Position verbleibt, also kein Element ein Fixpunkt ist.

Anzahl

Die Anzahl der fixpunktfreien Permutationen von n Elementen wird mit !n (Subfakultät) bezeichnet. Mit dem Prinzip von Inklusion und Exklusion ergibt sich

!n = n! · (1 − 1/1! + 1/2! − 1/3! + … + (−1)ⁿ/n!).

Äquivalent genügt die Folge der Rekursion !n = (n − 1) · (!(n−1) + !(n−2)). Die ersten Werte sind !1 = 0, !2 = 1, !3 = 2, !4 = 9, !5 = 44, !6 = 265. Der Anteil der fixpunktfreien unter allen Permutationen strebt für wachsendes n gegen 1/e ≈ 0,368.

Beispiel

Das klassische Anschauungsbeispiel ist das „Briefproblem", das auf Pierre Rémond de Montmort (1708) zurückgeht: Briefe werden zufällig in adressierte Umschläge gesteckt; gefragt ist die Wahrscheinlichkeit, dass kein Brief im richtigen Umschlag landet. Eine alltägliche Entsprechung ist das Wichteln, bei dem niemand seinen eigenen Namen ziehen soll.
