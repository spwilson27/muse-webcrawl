Message Queue

Eine Message Queue (Nachrichtenwarteschlange) ist eine Datenstruktur beziehungsweise ein Kommunikationsmuster der nachrichtenorientierten Middleware, bei dem Nachrichten von einem Sender (Producer) in einer Warteschlange abgelegt und von einem Empfänger (Consumer) zu einem späteren Zeitpunkt abgerufen und verarbeitet werden. Dadurch werden Sender und Empfänger zeitlich entkoppelt.

Funktionsweise

Der Producer stellt Nachrichten in die Warteschlange ein, ohne darauf zu warten, dass sie verarbeitet werden. Der Consumer entnimmt sie – meist in Reihenfolge der Ankunft (FIFO) – und bestätigt die Verarbeitung. Kann eine Nachricht nicht erfolgreich verarbeitet werden, wird sie je nach Konfiguration erneut zugestellt oder in eine spezielle Dead-Letter-Queue verschoben. Viele Systeme speichern Nachrichten persistent ab, sodass sie auch einen Ausfall des Warteschlangenservers überdauern.

Vorteile

  • Entkopplung der Komponenten und ihrer Verfügbarkeit
  • Lastspitzen können gepuffert werden (Backpressure-Pufferung)
  • Skalierung durch parallele Konsumenten
  • Erhöhte Ausfallsicherheit durch Zwischenspeicherung

Beispiele

Verbreitete Message-Queue-Systeme sind RabbitMQ, Apache Kafka (das zusätzlich ein verteiltes Log-Konzept verfolgt), Apache ActiveMQ, Amazon SQS und Redis-basierte Warteschlangen. Auch Betriebssysteme stellen Message Queues zur Interprozesskommunikation bereit, etwa die POSIX Message Queues unter Linux.
