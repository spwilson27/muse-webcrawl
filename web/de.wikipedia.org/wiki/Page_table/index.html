Seitentabelle

Eine Seitentabelle (englisch page table) ist eine Datenstruktur des Betriebssystems, mit der bei der seitenbasierten virtuellen Speicherverwaltung die Zuordnung von virtuellen Seiten zu physischen Seitenrahmen verwaltet wird. Die Memory Management Unit (MMU) der CPU nutzt sie bei jedem Speicherzugriff, um virtuelle in physische Adressen zu übersetzen.

Aufbau

Jeder Prozess besitzt eine eigene Seitentabelle. Jeder Eintrag (page table entry, PTE) enthält unter anderem:

  • die Nummer des zugeordneten Seitenrahmens (sofern die Seite eingelagert ist)
  • ein Present-Bit, das angibt, ob die Seite im Hauptspeicher liegt
  • Zugriffsrechte (Lesen, Schreiben, Ausführen) und Privilegstufen
  • ein Dirty-Bit für Veränderungen und ein Accessed-Bit für erfolgte Zugriffe
  • gegebenenfalls die Position der Seite im Auslagerungsspeicher

Mehrstufige Seitentabellen

Bei großen Adressräumen wären einstufige Tabellen zu speicherintensiv: Für einen 32-Bit-Adressraum mit 4-KiB-Seiten wären bereits eine Million Einträge nötig. Deshalb verwenden übliche Architekturen mehrstufige (hierarchische) Seitentabellen: Die virtuelle Adresse wird in mehrere Indexe zerlegt, die eine Baumstruktur von Tabellen durchlaufen. Nur tatsächlich genutzte Teile des Adressraums benötigen Tabellenseiten. Auf x86-64 sind vier bis fünf Stufen üblich.

Alternative Ansätze sind invertierte Seitentabellen, bei denen es nur einen Eintrag pro physikalischem Seitenrahmen gibt, sowie Hashtabellen-Verfahren.

Beschleunigung

Da eine Adressübersetzung mehrere Speicherzugriffe erfordern würde, hält die CPU häufig genutzte Übersetzungen in einem speziellen Cache, dem Translation Lookaside Buffer (TLB). Bei einem Kontextwechsel zwischen Prozessen wechselt auch die aktive Seitentabelle, indem ein Steuerregister (etwa CR3 auf x86) auf die neue Tabelle gesetzt wird.
