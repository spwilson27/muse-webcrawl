Bus error

Ein Bus error (deutsch: Busfehler) ist in der Informatik ein Hardware-Fehler, den der Prozessor beim Zugriff auf den Hauptspeicher feststellt und der unter Unix-ähnlichen Betriebssystemen als Signal SIGBUS an den betroffenen Prozess gemeldet wird. Er ist vom Segmentierungsfehler (SIGSEGV) zu unterscheiden.

Ursachen

  • Nicht ausgerichteter Speicherzugriff (unaligned access): Auf Architekturen wie SPARC oder älteren ARM-Systemen muss der Zugriff auf Mehrbyte-Datentypen an einer Adresse erfolgen, die ein Vielfaches der Datengröße ist. Auch auf x86-Prozessoren können bestimmte SIMD-Befehle bei falscher Ausrichtung einen Busfehler auslösen.
  • Zugriff auf nicht existierenden physikalischen Speicher, etwa über eine Speicherabbilddatei (mmap), die über ihr Ende hinaus adressiert wird, oder wenn eine eingeblendete Datei verkürzt wurde.
  • Hardwarefehler, beispielsweise defekte Speichermodule.

Verhalten

Erhält ein Prozess SIGBUS und behandelt das Signal nicht, beendet das Betriebssystem den Prozess – unter Unix üblicherweise mit einem Core Dump. Die Fehlermeldung der Shell lautet dann „Bus error (core dumped)“. Programmierer beheben Busfehler typischerweise mit einem Debugger, indem sie die fehlerhafte Speicheroperation lokalisieren.
