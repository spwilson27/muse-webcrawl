Request for Comments

Request for Comments (RFC) ist eine nummerierte Dokumentenreihe, in der die technischen Standards und Verfahren des Internets veröffentlicht werden. Herausgeber ist die Internet Engineering Task Force (IETF).

Geschichte

Die Reihe begann 1969 mit Notizen der Forscher des ARPANET; RFC 1 wurde von Steve Crocker verfasst. Heute durchlaufen neue Standards einen mehrstufigen Reifeprozess vom Internet-Draft über den Proposed Standard bis zum Internet Standard.

Bekannte RFCs

Zu den wichtigsten gehören RFC 791 (Internet Protocol), RFC 793 (TCP), RFC 2616 und RFC 9110 (HTTP) sowie RFC 5321 (SMTP). Eine humoristische Tradition sind die Aprilscherz-RFCs, etwa zum Transport von IP über Brieftauben. Veröffentlichte RFCs werden niemals geändert; Korrekturen erfolgen über Errata oder neue Dokumente.
