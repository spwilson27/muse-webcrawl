IOMMU

Eine IOMMU (Input/Output Memory Management Unit) ist eine Speicherverwaltungseinheit in Computersystemen, die – analog zur MMU für die CPU – die Speicherzugriffe von Ein-/Ausgabegeräten übersetzt und kontrolliert. Sie bildet die von einem Gerät verwendeten Adressen (IOVA, I/O Virtual Addresses) auf physische Speicheradressen ab und kann Zugriffe auf nicht freigegebene Speicherbereiche unterbinden.

Aufgaben

  • Adressübersetzung: Geräte, die per DMA auf den Hauptspeicher zugreifen, können damit in einem eigenen, geschützten Adressraum arbeiten.
  • Schutz: Ein fehlerhaftes oder bösartiges Gerät kann nur auf die ihm zugewiesenen Speicherbereiche zugreifen; DMA-Angriffe werden erschwert.
  • Virtualisierung: Bei der Gerätezuweisung (PCI Passthrough) an virtuelle Maschinen sorgt die IOMMU dafür, dass ein physisches Gerät sicher und performant direkt von einer Gastmaschine genutzt werden kann.
  • zusammenhängende Puffer: Verstreute physische Speicherseiten können dem Gerät als ein zusammenhängender Bereich präsentiert werden, was Treiber vereinfacht.

Implementierungen

Bekannte Implementierungen sind Intels VT-d (Virtualization Technology for Directed I/O), AMDs AMD-Vi (früher schlicht IOMMU genannt) sowie die System Memory Management Unit (SMMU) in der ARM-Architektur. In der Systemprogrammierung wird die IOMMU vom Betriebssystem über Gerätetreiber und Schnittstellen wie das DMA-API des Linux-Kernels verwaltet.
