Apache Cassandra

Apache Cassandra
Entwickler: Apache Software Foundation
Programmiersprache: Java
Kategorie: NoSQL-Datenbank
Lizenz: Apache License 2.0

Apache Cassandra ist ein verteiltes, spaltenorientiertes Datenbankmanagementsystem aus der Gruppe der NoSQL-Datenbanken. Es wurde ursprünglich bei Facebook entwickelt – maßgeblich von Avinash Lakshman, einem der Autoren von Amazons Dynamo, und Prashant Malik – um die Suche in der Nachrichten-Inbox zu ermöglichen, und 2008 als Open Source freigegeben. Seit 2010 ist Cassandra ein Top-Level-Projekt der Apache Software Foundation. Der Name verweist auf Kassandra, die Seherin der griechischen Mythologie.

Architektur

Cassandra ist als dezentrales Peer-to-Peer-System ohne zentralen Koordinator ausgelegt: Alle Knoten eines Clusters sind gleichberechtigt, es gibt keinen Single Point of Failure. Daten werden über konsistentes Hashing auf einem logischen Ring verteilt und mehrfach repliziert, wobei sich die Replikation über mehrere Rechenzentren erstrecken kann. Schreib- und Lesevorgänge lassen sich über einstellbare Konsistenzstufen (etwa ONE, QUORUM oder ALL) fein steuern, was Cassandra nach dem CAP-Theorem eher auf Verfügbarkeit und Partitionstoleranz ausrichtet.

Die Datenorganisation folgt einem spaltenfamilienbasierten Modell mit Partitionsschlüsseln; die Abfragesprache CQL (Cassandra Query Language) lehnt sich syntaktisch an SQL an. Intern baut Cassandra auf einem LSM-Baum-Speicherverfahren mit Memtables und SSTables auf und kombiniert Ideen aus Amazons Dynamo (Verteilung) und Googles Bigtable (Datenmodell).

Einsatz

Cassandra ist für sehr große Datenmengen und hohe Schreibdurchsätze auf Standardhardware ausgelegt und wird unter anderem von Netflix, Apple, eBay und Instagram-Nachfolgediensten eingesetzt. Apple betreibt einen der größten bekannten Cluster mit zehntausenden Knoten.
