International Components for Unicode

Abkürzung: ICU
Art: Softwarebibliothek (Open Source)
Sprachen: C/C++ (ICU4C), Java (ICU4J)
Lizenz: Unicode-Lizenz

Überblick

International Components for Unicode (ICU) ist eine weit verbreitete, quelloffene Softwarebibliothek, die Programmen Unterstützung für Unicode, Internationalisierung und Lokalisierung bietet.

Sie stellt Funktionen für Textumwandlung zwischen Zeichencodierungen, Sortierung nach länderspezifischen Regeln, Datums-, Zeit- und Zahlenformate, Textsegmentierung und reguläre Ausdrücke bereit.

Verbreitung

ICU liegt in den Varianten ICU4C für C und C++ sowie ICU4J für Java vor. Die Bibliothek wird unter anderem in Betriebssystemen, Browsern wie Chromium, der Java-Plattform, PHP und vielen Datenbank- und Büroprogrammen eingesetzt.

Die Locale-Daten stammen weitgehend aus dem Common Locale Data Repository (CLDR) des Unicode-Konsortiums.

Entwicklung

Das Projekt geht auf Arbeiten von Taligent und IBM in den 1990er Jahren zurück. Heute wird es vom Unicode-Konsortium betreut und erscheint in halbjährlichen Versionen, die mit neuen Unicode-Fassungen synchronisiert werden.
