Mono (Software)

Mono ist eine freie Implementierung des .NET-Frameworks von Microsoft auf Grundlage der ECMA-Standards für C# und die Common Language Infrastructure (CLI). Das Projekt ermöglicht es, .NET-Anwendungen plattformübergreifend unter anderem auf Linux, macOS und verschiedenen mobilen Betriebssystemen auszuführen.

Entwickler.NET Foundation / Community
Erstveröffentlichung2004
ProgrammierspracheC, C#
LizenzMIT u. a.

Geschichte

Mono wurde 2001 von Miguel de Icaza bei der Firma Ximian ins Leben gerufen und 2004 in der Version 1.0 veröffentlicht. Nach der Übernahme Ximians durch Novell und später Attachmate wurde das Projekt von der Neugründung Xamarin weitergeführt, die Miguel de Icaza mitbegründet hatte. Microsoft übernahm Xamarin 2016 und stellte Mono unter dem Dach der .NET Foundation als Open-Source-Projekt weiter bereit.

Anwendungsbereiche

Mono bildet die Grundlage für Xamarin und damit für die Entwicklung mobiler Anwendungen in C#. Die Spiele-Engine Unity nutzte lange eine Mono-basierte Laufzeitumgebung. Mit dem Aufkommen des plattformübergreifenden .NET (früher .NET Core) hat Mono einen Teil seiner ursprünglichen Rolle eingebüßt, wird aber weiterhin für eingebettete Systeme und bestehende Anwendungen gepflegt.
