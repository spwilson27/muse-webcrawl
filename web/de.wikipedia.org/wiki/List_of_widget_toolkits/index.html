Liste von GUI-Toolkits

Ein Widget-Toolkit (GUI-Toolkit) ist eine Bibliothek, die grundlegende Steuerelemente (Widgets) wie Schaltflächen, Textfelder und Fenster für grafische Benutzeroberflächen bereitstellt. Diese Liste gibt einen Überblick über bedeutende Toolkits.
