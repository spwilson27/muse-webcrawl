Permutation

Eine Permutation ist in der Mathematik eine Umordnung der Elemente einer endlichen Menge, formal eine bijektive Abbildung der Menge auf sich selbst.

Darstellung

Permutationen können als Zyklen, in Zweizeilenform oder als Produkt von Transpositionen geschrieben werden. Die symmetrische Gruppe Sₙ umfasst alle Permutationen von n Elementen; ihre Anzahl ist n! (Fakultät).

Anwendung

Permutationen spielen in Kombinatorik, Algebra, Kryptographie und Informatik eine zentrale Rolle.
