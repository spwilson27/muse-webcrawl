Liouville-Funktion

Die Liouville-Funktion, benannt nach Joseph Liouville, ist eine zahlentheoretische Funktion λ(n), die eng mit der Primfaktorzerlegung natürlicher Zahlen zusammenhängt.

Definition

Hat die natürliche Zahl n in ihrer Primfaktorzerlegung insgesamt Ω(n) Primfaktoren (mit Vielfachheit gezählt), so ist λ(n) = (−1)Ω(n). Es gilt λ(1) = 1. Die Funktion ist vollständig multiplikativ.

Eigenschaften

Die summatorische Liouville-Funktion L(n) = Σ λ(k) steht in Zusammenhang mit der Riemannschen Vermutung: Diese ist äquivalent dazu, dass L(n) = O(n1/2+ε) für jedes ε > 0 gilt. Die früher vermutete Pólya-Vermutung, L(n) sei stets ≤ 0, wurde widerlegt.
