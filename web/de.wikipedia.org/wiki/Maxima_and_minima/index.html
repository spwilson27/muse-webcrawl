Maxima und Minima

In der Mathematik, insbesondere in der Analysis, bezeichnen Maxima und Minima einer Funktion (zusammenfassend auch Extremwerte genannt) die größten beziehungsweise kleinsten Werte, die die Funktion in einer gegebenen Umgebung oder auf ihrem gesamten Definitionsbereich annimmt. Ein Punkt, an dem eine Funktion ein lokales oder globales Maximum oder Minimum besitzt, wird als Extrempunkt bezeichnet.

Definitionen

Sei f eine auf einer Menge D definierte reellwertige Funktion und x0 ein Punkt aus D. Man sagt, f habe an der Stelle x0 ein globales Maximum, wenn f(x) ≤ f(x0) für alle x ∈ D gilt. Entsprechend liegt ein globales Minimum vor, wenn f(x) ≥ f(x0) für alle x ∈ D gilt. Gilt die Ungleichung nur in einer Umgebung von x0, spricht man von einem lokalen Maximum beziehungsweise lokalen Minimum.

Notwendiges Kriterium

Ist f in einem inneren Punkt x0 differenzierbar und besitzt dort ein lokales Extremum, so gilt nach dem Satz von Fermat f′(x0) = 0. Die Umkehrung gilt im Allgemeinen nicht: Eine verschwindende Ableitung ist lediglich ein notwendiges, kein hinreichendes Kriterium. Punkte mit verschwindender Ableitung, die kein Extremum sind, heißen Sattelpunkte oder Terrassenpunkte.

Hinreichende Kriterien

Gilt zusätzlich f″(x0) > 0, so liegt ein lokales Minimum vor; bei f″(x0) < 0 ein lokales Maximum. Allgemeiner entscheidet das Vorzeichen der ersten nicht verschwindenden höheren Ableitung an einer kritischen Stelle über Art und Vorliegen eines Extremums.

Existenzsätze

Nach dem Satz vom Maximum und Minimum (Satz von Weierstraß) nimmt jede stetige Funktion auf einem kompakten Intervall sowohl ein Maximum als auch ein Minimum an. Auf nicht kompakten Mengen ist die Existenz dagegen nicht garantiert.

Mehrdimensionale Funktionen

Für Funktionen mehrerer Veränderlicher tritt an die Stelle der Ableitung der Gradient; an einer Extremstelle im Inneren muss der Gradient verschwinden. Die Art des Extremums wird über die Definitheit der Hesse-Matrix entschieden.
