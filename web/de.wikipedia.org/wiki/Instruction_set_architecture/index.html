Befehlssatzarchitektur

Die Befehlssatzarchitektur (englisch instruction set architecture, ISA) ist die Schnittstelle zwischen Hard- und Software eines Computers. Sie definiert den aus Programmierersicht sichtbaren Teil eines Prozessors: den Befehlssatz, die Register, das Speichermodell, die Adressierungsarten, die Datentypen sowie die Behandlung von Ausnahmen und Unterbrechungen.

Bedeutung

Die ISA abstrahiert von der konkreten Mikroarchitektur. Programme, die für eine bestimmte Befehlssatzarchitektur geschrieben wurden, können auf unterschiedlichen Implementierungen derselben Architektur laufen, etwa auf verschiedenen Prozessorgenerationen eines Herstellers. Bekannte Befehlssatzarchitekturen sind x86, ARM, MIPS, RISC-V und PowerPC.

Klassifikation

Befehlssatzarchitekturen werden häufig nach der Komplexität ihres Befehlssatzes unterschieden: CISC-Architekturen (Complex Instruction Set Computer) bieten viele, teils komplexe Befehle variabler Länge, während RISC-Architekturen (Reduced Instruction Set Computer) auf einen kleinen Satz einfach dekodierbarer Befehle fester Länge setzen. Eine weitere Einteilung erfolgt nach der Adressierung der Operanden, etwa in Stapel-, Akkumulator- und Registerarchitekturen.

Bestandteile

  • Befehlssatz mit Opcodes und Kodierung
  • Registersatz (Anzahl, Breite und Funktion der Register)
  • Adressierungsarten
  • Datentypen und Datenformate
  • Speichermodell und Speicherordnung
  • Ausnahme- und Interruptbehandlung
