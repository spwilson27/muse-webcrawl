Radiator (Begriffsklärung)

Radiator (englisch radiator, von lateinisch radiare „strahlen“) bezeichnet allgemein eine Vorrichtung, die Wärme an ihre Umgebung abgibt. Der Begriff wird für verschiedene technische Geräte verwendet:

  • Heizkörper – ein Bauteil von Heizungsanlagen, das Wärme an einen Raum abgibt
  • Kühler (Verbrennungsmotor) – ein Wärmetauscher zur Kühlung von Motoren und Maschinen

Darüber hinaus kann als Radiator in der Physik jeder strahlende Körper bezeichnet werden; in der Technik werden auch Wärmesenken an Raumfahrzeugen, die überschüssige Wärme ins All abstrahlen, Radiatoren genannt.
