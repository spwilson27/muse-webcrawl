Promise (Programmierung)

Ein Promise (englisch für „Versprechen“), in manchen Sprachen auch Future oder Deferred genannt, ist in der Informatik ein Platzhalterobjekt für das Ergebnis einer asynchronen Berechnung, das zum Zeitpunkt der Erstellung noch nicht vorliegt.

Funktionsweise

Ein Promise befindet sich in einem von drei Zuständen: pending (ausstehend), fulfilled (erfüllt, mit einem Wert) oder rejected (abgelehnt, mit einem Fehlergrund). Der Zustandswechsel erfolgt genau einmal. An ein Promise lassen sich Rückruffunktionen anhängen, die aufgerufen werden, sobald das Ergebnis vorliegt. Durch Verkettung (z. B. mit .then() in JavaScript) können asynchrone Verarbeitungsschritte nacheinander ausgeführt werden, ohne verschachtelte Callbacks („Callback Hell“) zu erzeugen.

Geschichte und Verbreitung

Das Konzept geht auf die späten 1970er-Jahre zurück (Future in Multilisp und Actor-Sprachen). In JavaScript wurden Promises durch Bibliotheken populär und mit ECMAScript 2015 (ES6) als Promise-Objekt standardisiert; die Syntax mit async/await (ES2017) baut darauf auf. Entsprechende Konstrukte existieren unter anderem in Java (Future, CompletableFuture), C# (Task), Python (asyncio.Future), Scala und Rust.
