MongoDB

MongoDB
Entwickler: MongoDB, Inc.
Ersterscheinung: 2009
Programmiersprache: C++, JavaScript, Go
Kategorie: Dokumentenorientierte Datenbank
Lizenz: Server Side Public License

MongoDB ist ein dokumentenorientiertes NoSQL-Datenbankmanagementsystem, das Daten als JSON-ähnliche Dokumente im BSON-Format speichert. Es wurde ab 2007 von der Firma 10gen (heute MongoDB, Inc.) entwickelt und 2009 erstmals veröffentlicht.

Eigenschaften

Im Gegensatz zu relationalen Datenbanken kennt MongoDB keine festen Tabellenschemata; Dokumente innerhalb einer Collection können unterschiedliche Felder besitzen. Unterstützt werden unter anderem Ad-hoc-Abfragen, Indexierung, Replikation über Replica Sets zur Hochverfügbarkeit sowie horizontale Skalierung durch Sharding, bei dem Daten auf viele Server verteilt werden. Seit Version 4.0 unterstützt MongoDB auch ACID-Transaktionen über mehrere Dokumente hinweg.

Verbreitung

MongoDB zählt zu den populärsten NoSQL-Datenbanken und wird in Webanwendungen, im Internet der Dinge und für Echtzeitanalysen eingesetzt. Neben der selbst gehosteten Version bietet der Hersteller mit MongoDB Atlas einen Cloud-Dienst an. Der Name leitet sich vom englischen Wort humongous („gewaltig") ab.
