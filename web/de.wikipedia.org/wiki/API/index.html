FachgebietSoftwareentwicklung

Eine Programmierschnittstelle, häufig API (englisch application programming interface, wörtlich „Anwendungsprogrammierschnittstelle“), ist ein Programmteil, den ein Softwaresystem anderen Programmen zur Anbindung an das System zur Verfügung stellt. Im Gegensatz zu einer Binärschnittstelle (ABI) wird eine API meist auf der Ebene des Quelltexts definiert.

Beschreibung

Eine API enthält die Definitionen von Funktionen, Prozeduren, Datenstrukturen und Protokollen, über die externe Programme auf die Funktionalität eines Systems zugreifen können, ohne dessen interne Implementierung kennen zu müssen. Dokumentiert wird eine API üblicherweise durch den Anbieter des Systems, etwa in Form einer API-Dokumentation oder von Interface-Dateien.

Arten von APIs

  • Funktionsorientierte APIs, etwa die Win32-API von Windows oder die POSIX-Schnittstellen von Unix-Systemen
  • Dateiorientierte APIs, bei denen Daten über Dateien oder Dateisystemfunktionen ausgetauscht werden
  • Objektorientierte APIs, etwa in Klassenbibliotheken von Java oder .NET
  • Protokollorientierte APIs wie die Socket-Schnittstellen zur Netzwerkkommunikation
  • Web-APIs, die über HTTP angesprochen werden, etwa REST- oder SOAP-basierte Dienste

Web-APIs

Mit der Verbreitung des Internets gewannen entfernte APIs (Remote APIs) große Bedeutung: Sie erlauben es, Daten und Funktionen über ein Netzwerk bereitzustellen, etwa Karten-, Wetter- oder Zahlungsdienste. Solche Schnittstellen werden häufig über das Architekturprinzip REST und Datenformate wie JSON oder XML realisiert.
