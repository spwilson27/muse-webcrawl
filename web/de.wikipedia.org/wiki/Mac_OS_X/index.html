Mac OS X

Mac OS X ist der Name, unter dem Apples heutiges Betriebssystem macOS von 2001 bis 2012 vertrieben wurde. Das „X“ steht für die römische Zehn und knüpfte an Mac OS 9 an; ausgesprochen wird es daher „Mac OS zehn“.

Grundlagen

Mac OS X verband die von NeXT übernommene Unix-Grundlage (NeXTSTEP/OPENSTEP) mit der neuen Benutzeroberfläche Aqua. Die erste Version 10.0 („Cheetah“) erschien am 24. März 2001; es folgten Puma, Jaguar, Panther, Tiger, Leopard, Snow Leopard und Lion. Dabei führte Tiger das Dashboard und die Spotlight-Suche ein, Leopard die Backup-Funktion Time Machine und Snow Leopard (2009) eine umfassende technische Überarbeitung für Intel-Macs.

Entwicklung

2012 wurde das System mit Version 10.8 (Mountain Lion) in „OS X“ umbenannt und 2016 schließlich in macOS. Die Unix-Basis von Mac OS X bildete später auch die Grundlage für iOS.
