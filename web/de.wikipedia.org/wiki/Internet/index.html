Internet

Das Internet (von englisch interconnected networks) ist ein weltweiter Verbund von Rechnernetzen, in dem Daten auf Grundlage der Internetprotokollfamilie (TCP/IP) ausgetauscht werden. Es ermöglicht Dienste wie das World Wide Web, E-Mail, Dateiübertragung, Telefonie und Streaming und wird von mehreren Milliarden Menschen genutzt.

Geschichte

Vorläufer war das 1969 in Betrieb genommene ARPANET des US-Verteidigungsministeriums. 1973/74 entwickelten Vint Cerf und Robert Kahn das TCP-Protokoll; am 1. Januar 1983 stellte das ARPANET auf TCP/IP um. Das von Tim Berners-Lee ab 1989 am CERN entwickelte World Wide Web und die grafischen Browser der 1990er Jahre machten das Internet massentauglich. Das kommerzielle Internet verbreitete sich ab Mitte der 1990er Jahre weltweit.

Technik

Das Internet ist dezentral organisiert: Autonome Systeme tauschen Datenpakete über Router aus; das Border Gateway Protocol steuert den Verkehr zwischen Netzen. Das Domain Name System (DNS) übersetzt Namen in IP-Adressen. Zuständig für Standards ist die Internet Engineering Task Force, für die Verwaltung von Namen und Nummern die ICANN.

Gesellschaft

Das Internet hat Kommunikation, Handel, Medien und Wissenschaft grundlegend verändert. Diskutiert werden unter anderem Netzneutralität, Datenschutz, digitale Spaltung und staatliche Regulierung.
