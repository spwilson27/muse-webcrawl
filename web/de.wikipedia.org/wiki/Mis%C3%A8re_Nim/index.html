Misère-Nim

Das Misère-Nim ist eine Variante des Nim-Spiels, eines mathematischen Wegnehmspiels für zwei Personen. Beim klassischen Nim liegen mehrere Haufen von Objekten (etwa Streichhölzern) vor; die Spieler nehmen abwechselnd von genau einem Haufen beliebig viele Objekte. Im Unterschied zur Normalform, bei der der Spieler gewinnt, der das letzte Objekt nimmt, verliert beim Misère-Nim, wer das letzte Objekt nehmen muss.

Strategie

Die Gewinnstrategie des Misère-Nim folgt über weite Strecken der des normalen Nim, die auf der Nim-Summe (bitweises XOR der Haufengrößen) beruht: Man hinterlässt nach jedem eigenen Zug eine Position mit Nim-Summe null. Erst das Endspiel unterscheidet sich: Sobald der Zug dazu führt, dass nur noch Haufen der Größe 1 übrig bleiben, muss die Strategie so angepasst werden, dass dem Gegner eine ungerade Anzahl von Einerhaufen verbleibt. Die vollständige Analyse beider Varianten stammt aus der Theorie kombinatorischer Spiele, insbesondere von Charles L. Bouton (1901).
