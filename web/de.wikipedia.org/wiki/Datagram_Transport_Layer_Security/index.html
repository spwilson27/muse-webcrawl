Datagram Transport Layer Security

Datagram Transport Layer Security (DTLS) ist ein Kommunikationsprotokoll, das die Sicherheit von verbindungslosem, auf Datagrammen beruhendem Datenverkehr gewährleistet. Es leitet sich vom Transport Layer Security (TLS) ab, das für verbindungsorientierte Übertragung (etwa über TCP) entwickelt wurde, und passt es an die Eigenschaften von UDP an.

Unterschiede zu TLS

Da Datagramme verloren gehen, dupliziert werden oder in falscher Reihenfolge eintreffen können, ergänzt DTLS das TLS-Protokoll unter anderem um:

  • explizite Sequenznummern in jedem Datensatz, die eine Entzerrung und Wiedereinspielschutz ermöglichen
  • einen Handshake mit Zeitüberschreitungen und Wiederholungen, damit verlorene Nachrichten erneut gesendet werden
  • einen zustandslosen Cookie-Austausch zur Abwehr von Denial-of-Service-Angriffen
  • die Behandlung jeder Nachricht als eigenständiges Datagramm, da Nachrichten nicht zerlegt oder zusammengelegt werden dürfen

Versionen und Einsatz

DTLS 1.0 (RFC 4347) beruht auf TLS 1.1, DTLS 1.2 (RFC 6347) auf TLS 1.2 und DTLS 1.3 (RFC 9147) auf TLS 1.3. Eingesetzt wird DTLS unter anderem in WebRTC zur verschlüsselten Übertragung von Audio- und Videodaten sowie des Datenkanals, in VPN-Lösungen und im Internet der Dinge, etwa in Verbindung mit CoAP.
