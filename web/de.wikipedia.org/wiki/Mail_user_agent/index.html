Mail User Agent

Ein Mail User Agent (MUA), üblicherweise E-Mail-Client genannt, ist ein Computerprogramm, mit dem ein Benutzer E-Mails lesen, verfassen und versenden kann. Der MUA übergibt ausgehende Nachrichten an einen Mail Submission Agent bzw. Mail Transfer Agent und ruft eingehende Nachrichten von einem Mailserver ab.

Zugriffsprotokolle

Zum Abruf der Nachrichten dienen vor allem zwei Protokolle: POP3 lädt die Nachrichten auf das lokale Gerät herunter, während IMAP die Nachrichten auf dem Server belässt und Ordnerstrukturen synchron hält – was den Zugriff von mehreren Geräten ermöglicht. Webmail-Dienste stellen den MUA als Webanwendung im Browser bereit.

Bekannte MUAs

  • Mozilla Thunderbird (freie Software, plattformübergreifend)
  • Microsoft Outlook
  • Apple Mail
  • Gmail (Webmail und App)
  • Mutt und Alpine (textbasiert, für die Kommandozeile)
  • eM Client, The Bat! und weitere kommerzielle Programme

Funktionen

Moderne E-Mail-Clients bieten neben dem Lesen und Schreiben von Nachrichten unter anderem Adressbücher, Volltextsuche, Filterregeln, Kalenderintegration, Verschlüsselung mit PGP oder S/MIME sowie Spam-Filterung. Das Nachrichtenformat selbst ist in RFC 5322 festgelegt, Anhänge werden über MIME kodiert.
