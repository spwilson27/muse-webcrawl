Microsoft Azure

Microsoft Azure (kurz Azure) ist die Cloud-Computing-Plattform von Microsoft. Sie wurde 2008 unter dem Namen Windows Azure angekündigt und ist seit 2010 allgemein verfügbar; 2014 erfolgte die Umbenennung in Microsoft Azure. Azure gehört neben Amazon Web Services und der Google Cloud Platform zu den größten Cloud-Plattformen weltweit.

Dienste

Azure bietet mehrere hundert Dienste in Kategorien wie Rechenleistung (virtuelle Maschinen, Container, serverloses Computing mit Azure Functions), Speicher (Blob Storage, Azure Files), Datenbanken (Azure SQL Database, Cosmos DB), Netzwerke, Analyse, künstliche Intelligenz und maschinelles Lernen sowie Internet der Dinge. Die Dienste werden in einem weltweiten Netz von Rechenzentren betrieben, das in Regionen und Verfügbarkeitszonen gegliedert ist. Unternehmen können Azure auch für hybride Szenarien mit lokaler Infrastruktur kombinieren, etwa über Azure Arc oder Azure Stack.
