Assoziatives Array

Ein assoziatives Array (englisch associative array, auch Map, Dictionary oder Hashtabelle genannt) ist eine abstrakte Datenstruktur, die eine Menge von Schlüssel-Wert-Paaren speichert. Anders als bei einem gewöhnlichen Array (Feld), dessen Elemente über ganzzahlige Indizes angesprochen werden, können die Schlüssel eines assoziativen Arrays beliebige Werte sein, etwa Zeichenketten.

Operationen

Die Grundoperationen eines assoziativen Arrays sind das Einfügen eines Schlüssel-Wert-Paars, das Nachschlagen des zu einem Schlüssel gehörenden Werts und das Löschen eines Paars. Häufig werden zusätzlich Operationen zum Prüfen, ob ein Schlüssel vorhanden ist, und zum Durchlaufen aller Einträge angeboten.

Implementierung

Die gebräuchlichste Implementierung ist die Hashtabelle, bei der eine Hashfunktion jeden Schlüssel auf eine Position in einem internen Feld abbildet. Kollisionen, bei denen zwei Schlüssel auf dieselbe Position fallen, werden etwa durch Verkettung oder offene Adressierung aufgelöst. Alternativ können assoziative Arrays über balancierte Suchbäume wie Rot-Schwarz-Bäume realisiert werden, was eine sortierte Reihenfolge der Schlüssel ermöglicht.

Verwendung in Programmiersprachen

Viele Programmiersprachen bieten assoziative Arrays als eingebauten Datentyp an: in Python als dict, in JavaScript als Objekte und Map, in PHP als Arrays, in Perl und Ruby als Hash sowie in Java und C# als Implementierungen der Schnittstelle Map beziehungsweise Dictionary.
