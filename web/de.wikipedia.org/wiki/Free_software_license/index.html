Freie-Software-Lizenz

Eine Freie-Software-Lizenz (englisch free software license) ist eine Lizenz, die den Lizenznehmern die Rechte einräumt, die Software zu nutzen, zu studieren, zu verändern und weiterzugeben. Sie erfüllt damit die von der Free Software Foundation formulierte Definition freier Software. Eng verwandt sind die Open-Source-Lizenzen, die den Kriterien der Open Source Initiative genügen; die meisten Lizenzen gehören beiden Kategorien an.

Arten

Permissive Lizenzen (freigiebige Lizenzen) wie die MIT-Lizenz, die BSD-Lizenzen und die Apache-Lizenz erlauben nahezu jede Verwendung, auch die Einbindung in proprietäre Software, solange Urhebervermerke erhalten bleiben. Lizenzen mit Copyleft wie die GNU General Public License (GPL) verlangen dagegen, dass abgeleitete Werke unter derselben freien Lizenz weitergegeben werden; die LGPL schwächt dies für Bibliotheken ab, und die AGPL erstreckt die Pflicht zur Quelltextfreigabe auch auf die Bereitstellung über Netzwerke.

Bekannte Lizenzen

  • GNU General Public License (GPL) in den Versionen 2 und 3
  • GNU Lesser General Public License (LGPL)
  • GNU Affero General Public License (AGPL)
  • Apache-Lizenz 2.0
  • MIT-Lizenz
  • BSD-Lizenzen (2-Clause und 3-Clause)
  • Mozilla Public License 2.0
  • Eclipse Public License

Bedeutung

Die Wahl der Lizenz bestimmt, wie ein Projekt weiterentwickelt und kommerziell genutzt werden kann. Copyleft soll sicherstellen, dass freie Software dauerhaft frei bleibt; permissive Lizenzen maximieren die Verbreitung und Akzeptanz in der Industrie. Lizenzkompatibilität – die Frage, ob Code unter verschiedenen Lizenzen kombiniert werden darf – ist ein wiederkehrendes praktisches und juristisches Thema.
