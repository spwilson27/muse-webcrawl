Schiefsymmetrische Matrix

Eine schiefsymmetrische Matrix (auch antisymmetrische Matrix) ist eine quadratische Matrix, die gleich dem Negativen ihrer Transponierten ist: AT = −A. Für ihre Einträge gilt daher aij = −aji, und alle Diagonaleinträge sind null.

Beispiel

    [ 0   2  −1 ]
A = [ −2  0   4 ]
    [ 1  −4   0 ]

Eigenschaften

  • Die Determinante einer schiefsymmetrischen Matrix ungerader Ordnung ist stets null.
  • Alle von null verschiedenen Eigenwerte reeller schiefsymmetrischer Matrizen sind rein imaginär.
  • Die Menge der schiefsymmetrischen n×n-Matrizen bildet die Lie-Algebra der orthogonalen Gruppe SO(n); sie hat die Dimension n(n−1)/2.
  • Jede quadratische Matrix lässt sich eindeutig als Summe einer symmetrischen und einer schiefsymmetrischen Matrix schreiben.

Anwendung

Schiefsymmetrische 3×3-Matrizen beschreiben Kreuzprodukte und Drehbewegungen: Zu jedem Vektor ω gehört eine Matrix Ω mit Ωx = ω × x. In der Mechanik treten sie bei der Beschreibung von Rotationen und Drehimpulsen auf.
