Callback (Programmierung)

In der Programmierung ist ein Callback (deutsch „Rückruf“) ein Stück ausführbaren Codes, das einer anderen Codeeinheit als Argument übergeben wird. Die aufgerufene Einheit kann den Callback zu einem späteren Zeitpunkt „zurückrufen“, etwa wenn ein bestimmtes Ereignis eingetreten ist oder eine asynchrone Operation abgeschlossen wurde. Callbacks sind ein zentrales Konzept der ereignisgesteuerten und asynchronen Programmierung.

Funktionsweise

Der aufrufende Code registriert eine Funktion bei einer Bibliothek oder einem Framework. Anstatt das Ergebnis direkt zurückzugeben, speichert die Bibliothek die Referenz und ruft die Funktion später mit dem Ergebnis oder einem Fehler auf. In Sprachen wie C werden Funktionszeiger verwendet; in JavaScript und anderen Sprachen übergibt man Funktionsobjekte oder anonyme Funktionen (Lambda-Ausdrücke).

// JavaScript-Beispiel
ladeDaten(url, function(ergebnis) {
    console.log("Daten geladen:", ergebnis);
});

Synchrone und asynchrone Callbacks

Synchrone Callbacks werden unmittelbar während der Ausführung der aufgerufenen Funktion ausgeführt, etwa Vergleichsfunktionen beim Sortieren. Asynchrone Callbacks dagegen werden später aufgerufen, beispielsweise nach Abschluss einer Netzwerk- oder Dateisystemoperation; sie verhindern, dass das Programm blockiert.

Probleme und Alternativen

Tief verschachtelte asynchrone Callbacks führen zu schwer lesbarem Code, der umgangssprachlich als „Callback Hell“ oder „Pyramid of Doom“ bezeichnet wird. Moderne Alternativen sind Promises, Futures sowie die Syntax von async/await, die eine sequenziell aussehende Schreibweise ermöglichen.
