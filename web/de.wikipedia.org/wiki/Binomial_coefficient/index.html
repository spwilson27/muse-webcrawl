Binomialkoeffizient

Der Binomialkoeffizient ist eine mathematische Funktion, mit der sich die Anzahl der Möglichkeiten bestimmen lässt, aus einer Menge von n Elementen eine Teilmenge mit k Elementen auszuwählen. Man schreibt ihn als „n über k“:

( n über k ) = n! / ( k! · (n − k)! )

Der Name rührt daher, dass die Binomialkoeffizienten als Koeffizienten in der Entwicklung von (a + b)n auftreten (siehe binomischer Lehrsatz).

Eigenschaften

  • Symmetrie: ( n über k ) = ( n über n − k )
  • Rekursion: ( n + 1 über k + 1 ) = ( n über k ) + ( n über k + 1 ) — Grundlage des Pascalschen Dreiecks
  • Summe: Die Summe aller Binomialkoeffizienten zu festem n ist 2n.
  • Für k > n ist der Binomialkoeffizient 0; es gilt ( n über 0 ) = ( n über n ) = 1.

Pascalsches Dreieck

Die Binomialkoeffizienten lassen sich im Pascalschen Dreieck anordnen, in dem jede Zahl die Summe der beiden darüberstehenden Zahlen ist. Das Dreieck war bereits im mittelalterlichen China (Yang-Hui-Dreieck) und in Persien bekannt, bevor Blaise Pascal es im 17. Jahrhundert systematisch untersuchte.

Anwendung

Binomialkoeffizienten sind zentral in der Kombinatorik und der Wahrscheinlichkeitsrechnung. Sie treten in der Binomialverteilung auf und geben beispielsweise die Anzahl der möglichen Ziehungen beim Zahlenlotto an: Beim Lotto „6 aus 49“ gibt es ( 49 über 6 ) = 13.983.816 mögliche Kombinationen.

Verallgemeinerung

Über die Gammafunktion lässt sich der Binomialkoeffizient auf reelle und komplexe obere Einträge verallgemeinern. Eine weitere Verallgemeinerung sind die Multinomialkoeffizienten für Auswahlen in mehr als zwei Gruppen.
