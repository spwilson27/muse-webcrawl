Quasikonkave Funktion

Eine quasikonkave Funktion ist in der Mathematik eine reellwertige Funktion, deren obere Niveaumengen konvex sind. Sie verallgemeinert den Begriff der konkaven Funktion und spielt insbesondere in der mathematischen Wirtschaftstheorie, etwa bei der Beschreibung von Präferenzen und Nutzenfunktionen, eine wichtige Rolle.

Definition

Eine Funktion f : D → ℝ auf einer konvexen Menge D heißt quasikonkav, wenn für alle x, y ∈ D und alle t ∈ [0, 1] gilt:

f(tx + (1 − t)y) ≥ min{f(x), f(y)}.

Äquivalent dazu ist die Forderung, dass jede obere Niveaumenge {x ∈ D : f(x) ≥ a} für alle a konvex ist. Eine Funktion heißt quasikonvex, wenn ihr Negatives quasikonkav ist, also wenn alle unteren Niveaumengen konvex sind.

Eigenschaften

Jede konkave Funktion ist quasikonkav, die Umkehrung gilt jedoch nicht. So ist beispielsweise die Funktion f(x) = x³ auf den reellen Zahlen quasikonkav (und zugleich quasikonvex), ohne konkav zu sein. Quasikonkavität bleibt unter monotonen Transformationen erhalten: Ist f quasikonkav und g eine monoton wachsende Funktion, so ist auch die Verkettung g ∘ f quasikonkav. Diese Eigenschaft macht den Begriff für die Nutzentheorie attraktiv, da Nutzenfunktionen ohnehin nur bis auf monotone Transformationen eindeutig sind.

Für differenzierbare Funktionen existieren Charakterisierungen über die Vorzeichen von Determinanten berandeter Hesse-Matrizen, die auf Arbeiten von Kenneth Arrow und Alain Enthoven zurückgehen. Eine quasikonkave Funktion auf einem Intervall ist zunächst monoton wachsend und danach monoton fallend (oder umgekehrt monoton), kann also höchstens einen „Gipfel“ besitzen, ohne dass dieser flach sein muss.

Anwendungen

In der Mikroökonomik sichern quasikonkave Nutzenfunktionen, dass die von den Präferenzen abgeleiteten Indifferenzmengen konvex sind. In der nichtlinearen Optimierung garantiert Quasikonkavität der Zielfunktion zusammen mit weiteren Voraussetzungen, dass lokale Maxima unter bestimmten Bedingungen globale Maxima sind; für streng quasikonkave Funktionen ist das Maximum auf einer konvexen Menge eindeutig.
