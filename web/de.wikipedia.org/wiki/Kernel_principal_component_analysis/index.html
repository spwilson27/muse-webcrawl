Kernel Principal Component Analysis

Die Kernel Principal Component Analysis (Kernel-PCA, deutsch Kern-Hauptkomponentenanalyse) ist eine nichtlineare Erweiterung der klassischen Hauptkomponentenanalyse (PCA) mittels des Kerntricks der Kernmethoden. Sie wurde 1998 von Bernhard Schölkopf, Alexander Smola und Klaus-Robert Müller eingeführt.

Verfahren

Bei der gewöhnlichen PCA werden die Richtungen größter Varianz der Daten durch eine Eigenwertzerlegung der Kovarianzmatrix bestimmt; sie kann nur lineare Strukturen erfassen. Die Kernel-PCA bildet die Daten zunächst implizit über eine Kernfunktion k(x, y) in einen hochdimensionalen Merkmalsraum ab und führt dort eine lineare PCA durch, wobei lediglich die Kernmatrix der Datenpunkte eigenzerlegt wird. Zusätzlich muss die Kernmatrix zentriert werden, da die Daten im Merkmalsraum nicht automatisch mittelwertfrei sind.

Anwendung

Die Kernel-PCA dient der nichtlinearen Dimensionsreduktion, der Merkmalsextraktion und der Datenvisualisierung. Mit geeigneten Kernen – häufig dem Gauß- oder RBF-Kern – kann sie gekrümmte Datenstrukturen wie Ringe oder Spiralen auf wenige Komponenten reduzieren, an denen eine lineare PCA scheitert. Verwandte Verfahren sind die Isomap-Methode und die lokal lineare Einbettung.
