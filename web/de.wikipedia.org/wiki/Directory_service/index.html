Verzeichnisdienst

Ein Verzeichnisdienst (englisch directory service) ist eine Anwendung oder ein Satz von Anwendungen, die Informationen über Netzwerkressourcen wie Benutzer, Computer, Drucker und Berechtigungen hierarchisch speichern und über ein Netzwerk verfügbar machen. Er bildet eine zentrale Komponente der Identitäts- und Zugriffsverwaltung in Unternehmensnetzwerken.

Grundlagen

Verzeichnisdienste organisieren ihre Daten in einer Baumstruktur aus Objekten mit Attributen. Jedes Objekt besitzt einen eindeutigen Namen, den Distinguished Name (DN). Anders als relationale Datenbanken sind Verzeichnisdienste für Lesezugriffe und Suchanfragen optimiert, während Schreibzugriffe vergleichsweise selten sind.

Protokolle und Standards

Der bedeutendste Standard ist das Lightweight Directory Access Protocol (LDAP), das aus dem älteren X.500-Standard der ITU hervorging. LDAP definiert sowohl das Zugriffsprotokoll als auch ein Informationsmodell. Daneben existieren herstellerspezifische und ergänzende Protokolle wie Kerberos für die Authentifizierung.

Bekannte Implementierungen

  • Active Directory (Microsoft) – Verzeichnisdienst der Windows-Server-Umgebungen, weit verbreitet in Unternehmen.
  • OpenLDAP – freie Open-Source-Implementierung des LDAP-Protokolls.
  • Apache Directory Server und 389 Directory Server – weitere LDAP-Serverimplementierungen.
  • Apple Open Directory und Novell eDirectory – historische bzw. plattformspezifische Dienste.

Anwendungsbereiche

Verzeichnisdienste werden vor allem zur zentralen Benutzerverwaltung, für Single Sign-on, zur Verwaltung von Gruppenrichtlinien sowie als Adressbuch für E-Mail-Programme eingesetzt. Sie bilden häufig die Grundlage für die Rechteverwaltung in Dateisystemen und Anwendungen.
