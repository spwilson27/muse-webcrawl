Function as a Service

Function as a Service (FaaS) ist ein Bereitstellungsmodell des Cloud Computing, bei dem Entwickler einzelne Funktionen in einer verwalteten Umgebung ausführen können, ohne Server selbst betreiben oder verwalten zu müssen. FaaS ist ein zentraler Bestandteil des Serverless Computing.

Funktionsweise

Bei FaaS lädt der Entwickler Programmcode in Form einzelner, kurzlebiger Funktionen auf die Plattform des Anbieters. Die Plattform startet diese Funktionen ereignisgesteuert, etwa bei einem HTTP-Aufruf, einer Änderung in einer Datenbank oder einer neuen Nachricht in einer Warteschlange. Die Ausführung erfolgt zustandslos; benötigte Daten müssen in externen Diensten gespeichert werden. Abgerechnet wird in der Regel nach Anzahl der Aufrufe und tatsächlicher Ausführungszeit.

Bekannte Plattformen

  • AWS Lambda (Amazon Web Services)
  • Microsoft Azure Functions
  • Google Cloud Functions (Cloud Run Functions)
  • IBM Cloud Functions
  • Cloudflare Workers
