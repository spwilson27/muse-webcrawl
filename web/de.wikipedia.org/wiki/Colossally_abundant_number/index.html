Kolossal abundante Zahl

Eine kolossal abundante Zahl (englisch colossally abundant number) ist eine natürliche Zahl, die in einem strengen Sinne besonders viele Teiler im Verhältnis zu ihrer Größe besitzt. Der Begriff wurde von dem indischen Mathematiker S. Ramanujan geprägt und später von Paul Erdős und Leonidas Alaoglu (1944) formalisiert.

Definition

Eine natürliche Zahl n heißt kolossal abundant, wenn es ein ε > 0 gibt, sodass für alle k ≠ n gilt: σ(n) / n1+ε ≥ σ(k) / k1+ε, wobei σ(n) die Summe aller Teiler von n (Teilersummenfunktion) bezeichnet. Jede kolossal abundante Zahl ist zugleich eine hochgradig abundante und eine superabundante Zahl.

Beispiele

Die ersten kolossal abundanten Zahlen sind: 2, 6, 12, 60, 120, 360, 2520, 5040, 55440, 720720, 1441440, 4324320, 21621600, …

Bedeutung

Kolossal abundante Zahlen spielen eine Rolle in der analytischen Zahlentheorie. Ramanujan nutzte sie in seinen Untersuchungen zur Riemannschen Zetafunktion; es besteht ein enger Zusammenhang zwischen dem Wachstum der Teilersummenfunktion und der Riemannschen Vermutung: Diese ist äquivalent zu einer bestimmten Ungleichung, die für alle genügend großen kolossal abundanten Zahlen gefordert wird.
