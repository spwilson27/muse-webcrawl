Erlang (Programmiersprache)

Erlang ist eine funktionale Programmiersprache, die ab Mitte der 1980er Jahre bei dem schwedischen Telekommunikationsunternehmen Ericsson entwickelt wurde. Sie ist auf die Entwicklung verteilter, fehlertoleranter und hochverfügbarer Systeme ausgelegt und wird vor allem in der Telekommunikation, in Messaging-Systemen und in der Finanzbranche eingesetzt. Der Name geht auf den dänischen Mathematiker Agner Krarup Erlang zurück und ist zugleich als Abkürzung von „Ericsson Language“ lesbar.

Entwicklungsgeschichte

Erlang entstand ab 1986 im Computer Science Laboratory von Ericsson, maßgeblich unter Joe Armstrong, Robert Virding und Mike Williams. 1998 wurde die Sprache als Open Source freigegeben. Bekannte Großanwendungen sind etwa Telekommunikationsvermittlungssysteme, der Chatdienst von WhatsApp sowie der Message Broker RabbitMQ.

Eigenschaften

Das zentrale Paradigma von Erlang ist das Aktorenmodell: Leichtgewichtige Prozesse kommunizieren ausschließlich durch Nachrichtenaustausch und teilen sich keinen Speicher. Das Konzept „let it crash“ beruht auf Überwachungsbäumen (Supervision Trees), in denen fehlerhafte Prozesse von Supervisor-Prozessen neu gestartet werden. Weitere Merkmale sind Pattern Matching, unveränderliche Daten, Hot Code Swapping (Austausch des Codes im laufenden Betrieb) und die Laufzeitumgebung BEAM. Auf der BEAM-VM laufen auch neuere Sprachen wie Elixir.

Beispiel

Ein einfaches Modul mit einer Fakultätsfunktion:

-module(fak).
-export([fak/1]).
fak(0) -> 1;
fak(N) when N > 0 -> N * fak(N - 1).
