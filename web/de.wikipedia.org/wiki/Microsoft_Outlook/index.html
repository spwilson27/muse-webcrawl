Microsoft Outlook

Microsoft Outlook ist ein Programm zur Verwaltung persönlicher Informationen (Personal Information Manager) und E-Mail-Client von Microsoft. Es erschien erstmals 1997 und ist Bestandteil von Microsoft Office beziehungsweise Microsoft 365. Outlook wird vor allem in Unternehmen gemeinsam mit Microsoft Exchange Server eingesetzt.

Funktionen

Neben E-Mail umfasst Outlook einen Kalender mit Besprechungsplanung, eine Kontaktverwaltung, Aufgabenlisten und Notizen. Die Software unterstützt neben Exchange auch die Protokolle IMAP, POP3 und EAS sowie die Postfächer des Webmaildienstes Outlook.com. Outlook ist für Windows und macOS sowie als mobile App und als Webanwendung („Outlook on the web“) verfügbar. Ab 2023 führte Microsoft schrittweise ein neues, stärker am Webclient orientiertes Outlook für Windows ein, das die bisherigen Programme Mail und Kalender ablöste.
