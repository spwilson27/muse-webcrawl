Google File System

Das Google File System (GFS) ist ein proprietäres, verteiltes Dateisystem, das Google für den Einsatz auf großen Rechnerclustern aus Standardhardware entwickelte. Es wurde 2003 in einer wissenschaftlichen Veröffentlichung vorgestellt und bildete lange die Speichergrundlage vieler Google-Dienste. Der Nachfolger wird intern als Colossus bezeichnet.

Entwurf

GFS ist auf sehr große Dateien (typischerweise mehrere Gigabyte), hohe Durchsatzraten und Fehlertoleranz ausgelegt. Hardwareausfälle werden nicht als Ausnahme, sondern als Regelfall behandelt: Daten werden in Blöcken (Chunks) von 64 Megabyte gespeichert und standardmäßig dreifach auf verschiedene Rechner repliziert.

Architektur

Ein GFS-Cluster besteht aus einem einzelnen Master-Server, der Metadaten und die Zuordnung von Dateien zu Chunks verwaltet, sowie zahlreichen Chunkservern, die die eigentlichen Datenblöcke speichern. Clients erfragen beim Master die Standorte der Chunks und übertragen die Daten anschließend direkt mit den Chunkservern, was den Master entlastet.

Bedeutung

Die Veröffentlichung des GFS-Konzepts – zusammen mit dem MapReduce-Papier – prägte die Entwicklung verteilter Systeme maßgeblich und inspirierte unter anderem das Hadoop Distributed File System (HDFS) des Apache-Hadoop-Projekts.
