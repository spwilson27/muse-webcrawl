PostmarketOS

postmarketOS (abgekürzt pmOS) ist ein freies Betriebssystem für Smartphones und andere mobile Geräte auf Basis von Alpine Linux. Das 2017 gestartete Projekt hat das Ziel, Smartphones eine Lebensdauer von etwa zehn Jahren zu ermöglichen – also weit über den Supportzeitraum hinaus, den die Hersteller mit ihren Android-Versionen üblicherweise bieten.

Konzept

Anders als bei herstellergebundenen Systemen soll für alle Geräte möglichst derselbe, geräteunabhängig gepflegte Linux-Kernel (Mainline-Kernel) verwendet werden, statt für jedes Modell einen eigenen, schnell veralteten Kernel zu pflegen. Auf diese Weise können Sicherheitsaktualisierungen zentral bereitgestellt werden. Als Oberflächen stehen verschiedene mobile Umgebungen zur Auswahl, darunter Phosh, Plasma Mobile und Sxmo. Das Installationswerkzeug pmbootstrap unterstützt bei der Erstellung und Installation der Abbilder.

Geräteunterstützung

postmarketOS läuft auf einer wachsenden Zahl von Geräten, wobei der Funktionsumfang je nach Modell variiert – etwa von der bloßen Startfähigkeit bis zur alltagstauglichen Nutzung inklusive Telefonie. Zu den gut unterstützten Geräten zählt unter anderem das PinePhone. Entwickelt wird das System von einer offenen Gemeinschaft von Freiwilligen.

Motivation

Hintergrund des Projekts ist die zunehmende Menge an Elektroschrott: Viele Smartphones werden ausgemustert, obwohl ihre Hardware noch funktionsfähig ist, nur weil der Hersteller keine Softwareaktualisierungen mehr bereitstellt. Ein langlebiges, herstellerunabhängiges System soll diesem Ressourcenverbrauch entgegenwirken.
