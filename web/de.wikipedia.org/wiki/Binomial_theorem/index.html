Binomischer Lehrsatz

Der binomische Lehrsatz ist ein Satz der Algebra, der angibt, wie eine Potenz einer Summe zweier Größen (eines Binoms) entwickelt werden kann. Für jede natürliche Zahl n gilt:

(a + b)n = Σk=0..n ( n über k ) · an−k · bk

Die auftretenden Vorfaktoren sind die Binomialkoeffizienten, die sich im Pascalschen Dreieck ablesen lassen.

Beispiele

(a + b)² = a² + 2ab + b²

(a + b)³ = a³ + 3a²b + 3ab² + b³

Die binomischen Formeln für n = 2 und n = 3 sind Spezialfälle des Lehrsatzes.

Beweis

Der Satz wird üblicherweise durch vollständige Induktion über n bewiesen, unter Verwendung der Identität ( n über k ) + ( n über k + 1 ) = ( n + 1 über k + 1 ). Ein anschaulicher kombinatorischer Beweis bemerkt, dass beim Ausmultiplizieren von n Faktoren (a + b) der Term an−kbk genau so oft entsteht, wie man aus den n Faktoren diejenigen k Faktoren auswählen kann, aus denen b genommen wird.

Geschichte

Spezialfälle des Satzes waren schon in der Antike sowie im mittelalterlichen islamischen und chinesischen Mathematikraum bekannt. Isaac Newton verallgemeinerte den Satz um 1665 auf beliebige reelle Exponenten; daraus entsteht eine unendliche Reihe, die binomische Reihe.

Verallgemeinerung

Die Verallgemeinerung auf Summen mit mehr als zwei Summanden ist der Multinomialsatz, bei dem Multinomialkoeffizienten auftreten. Die Binomialreihe ist zudem ein Spezialfall der Taylorreihe der Funktion (1 + x)α.
