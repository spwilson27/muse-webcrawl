Live-CD

Eine Live-CD (auch Live-System) ist ein bootfähiges Speichermedium – ursprünglich eine CD oder DVD, heute meist ein USB-Stick oder eine ISO-Datei –, von dem ein vollständiges Betriebssystem direkt gestartet werden kann, ohne dass eine Installation auf der Festplatte erforderlich ist.

Funktionsweise

Das System läuft im Arbeitsspeicher beziehungsweise auf einem schreibgeschützten Medium; Änderungen werden in der Regel nicht dauerhaft gespeichert. Viele Distributionen bieten optional eine Persistenzfunktion oder die spätere Installation auf die Festplatte an.

Anwendungsgebiete

Live-Systeme werden zum Ausprobieren von Betriebssystemen, zur Datenrettung, zur Systemwartung und -diagnose, für Forensik sowie für anonymes oder sicheres Surfen verwendet. Bekannte Beispiele sind Knoppix, die Live-Medien der großen Linux-Distributionen wie Ubuntu und Debian sowie Rettungssysteme.

Geschichte

Als erste populäre Live-CD gilt die Linux-Distribution Knoppix (ab 2000). Später traten USB-Sticks (Live-USB) an die Stelle optischer Medien.
