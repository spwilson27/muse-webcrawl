Rückgabeanweisung

Die Rückgabeanweisung (englisch return statement) ist eine Anweisung in imperativen Programmiersprachen, die die Ausführung einer Funktion oder Prozedur beendet und einen Rückgabewert an die aufrufende Stelle übergibt. In den meisten Sprachen lautet das Schlüsselwort return.

Semantik

Beim Erreichen einer Rückgabeanweisung wird der Kontrollfluss sofort an den Aufrufer zurückgegeben; nachfolgender Code in der Funktion wird nicht mehr ausgeführt. Funktionen ohne Wertrückgabe (Prozeduren, in C-artiger Syntax mit Rückgabetyp void deklariert) können ein return ohne Ausdruck verwenden oder die Anweisung ganz weglassen. Manche Sprachen erlauben mehrere Rückgabewerte, etwa Go, oder verwenden den Wert des letzten Ausdrucks als impliziten Rückgabewert wie Rust oder Ruby.

Beispiel

int quadriere(int x) { return x * x; } – die Funktion beendet sich mit dem Wert von x * x.

Gestaltungsfragen

Ob eine Funktion genau eine Rückgabestelle am Ende haben sollte (Single Exit Point) oder frühe Rückgaben („Guard Clauses") besser lesbar sind, wird in der Softwareentwicklung seit der strukturierten Programmierung diskutiert. Frühe Rückgaben reduzieren Schachtelungstiefe und werden in vielen Stilrichtlinien empfohlen; in ressourcenverwaltenden Sprachen sorgt die RAII-Technik oder finally-Blöcke dafür, dass Aufräumarbeiten trotz vorzeitiger Rückkehr ausgeführt werden.
