Krullscher Hauptidealsatz

Der Krullsche Hauptidealsatz (englisch Krull's principal ideal theorem) ist ein zentraler Satz der kommutativen Algebra, benannt nach Wolfgang Krull. Er macht Aussagen über die Höhe von Primidealen in noetherschen Ringen, die über einem Hauptideal liegen.

Aussage

Sei R ein noetherscher Ring, x ein Element von R, das weder Einheit noch Nullteiler ist, und P ein Primideal, das minimal über dem von x erzeugten Hauptideal (x) liegt. Dann hat P höchstens die Höhe eins.

Bedeutung

Der Hauptidealsatz ist ein Grundpfeiler der Dimensionstheorie kommutativer Ringe. Aus ihm folgt unter anderem, dass in einem noetherschen lokalen Ring die Dimension durch die minimale Anzahl von Erzeugern des maximalen Ideals abgeschätzt werden kann. Eine Verallgemeinerung besagt, dass ein minimal über einem von n Elementen erzeugten Ideal liegendes Primideal höchstens die Höhe n besitzt.
