CYK-Algorithmus

Der CYK-Algorithmus (nach seinen Erfindern John Cocke, Daniel Younger und Tadao Kasami) ist ein Parsing-Algorithmus der theoretischen Informatik, der für eine kontextfreie Grammatik in Chomsky-Normalform und ein Eingabewort entscheidet, ob das Wort von der Grammatik erzeugt werden kann (Wortproblem).

Verfahren

Der Algorithmus arbeitet mit dynamischer Programmierung: Für alle Teilwörter der Eingabe wird berechnet, aus welchen Nichtterminalsymbolen sie ableitbar sind. Die Ergebnisse werden in einer dreieckigen Tabelle eingetragen – zunächst für Teilwörter der Länge 1, dann für immer längere Teilwörter, indem jede Zerlegung in zwei Teile mit den binären Produktionen der Grammatik verglichen wird. Das Wort gehört genau dann zur Sprache, wenn das Startsymbol in der Zelle für das gesamte Wort steht.

Komplexität

Die Laufzeit liegt in O(n³ · |G|) für eine Eingabe der Länge n und eine Grammatik der Größe |G|. Eine probabilistische Erweiterung des Verfahrens wird in der Computerlinguistik zur Analyse natürlicher Sprache eingesetzt.
