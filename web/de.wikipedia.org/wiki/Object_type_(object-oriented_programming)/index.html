Objekttyp (objektorientierte Programmierung)

Der Objekttyp eines Objekts beschreibt in der objektorientierten Programmierung die Menge der Nachrichten beziehungsweise Methoden, auf die das Objekt reagieren kann, sowie die damit verbundene Schnittstelle. Der Typ eines Objekts legt fest, welche Operationen mit ihm zulässig sind, ohne Aussagen über die konkrete Implementierung zu machen.

Typ und Klasse

Typ und Klasse werden häufig verwechselt, sind aber verschiedene Konzepte: Die Klasse beschreibt, wie ein Objekt aufgebaut ist und wie es implementiert wird; sie dient als Bauanleitung und umfasst Code. Der Typ hingegen beschreibt nur die äußere Schnittstelle — ein Objekt kann mehrere Typen haben, aber nur einer Klasse angehören (in Sprachen mit Einfachvererbung). In vielen Sprachen fallen beide zusammen, weil eine Klasse zugleich einen Typ definiert; Schnittstellen (Interfaces) und abstrakte Klassen trennen Typ und Implementierung dagegen deutlicher.

Subtypisierung und Vererbung

Vererbung ist ein Mechanismus der Code-Wiederverwendung; Subtypisierung ist eine Beziehung zwischen Typen: Ein Subtyp kann überall dort verwendet werden, wo sein Basistyp erwartet wird (Liskovsches Substitutionsprinzip). Nicht jede Vererbung begründet deshalb eine sinnvolle Subtypbeziehung.
