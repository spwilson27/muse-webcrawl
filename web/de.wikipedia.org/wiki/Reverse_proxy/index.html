Reverse Proxy

Ein Reverse Proxy (deutsch „umgekehrter Stellvertreter“) ist ein Server, der stellvertretend für einen oder mehrere dahinterliegende Server Anfragen von Clients entgegennimmt und an diese weiterleitet. Während ein (Forward-)Proxy die Clients eines Netzes gegenüber den Servern vertritt, vertritt der Reverse Proxy die Server gegenüber den anfragenden Clients; für diese erscheint er als der eigentliche Zielserver.

Aufgaben

Reverse Proxys dienen der Lastverteilung auf mehrere Backend-Server, dem Zwischenspeichern statischer Inhalte (Caching) zur Entlastung der Anwendungsserver, der Terminierung von TLS-Verschlüsselung, der Kompression und Umformung von Inhalten sowie als Sicherheitsinstanz, die die eigentlichen Server abschirmt und Angriffe filtern kann. Auch Content-Delivery-Netzwerke arbeiten nach diesem Prinzip.

Software

Verbreitete Reverse-Proxy-Software ist unter anderem Nginx, der Apache HTTP Server mit mod_proxy, HAProxy, Varnish (als reiner Cache) sowie Cloud-Dienste großer Anbieter. Die ursprüngliche IP-Adresse des Clients wird dem Backend üblicherweise über spezielle Header wie X-Forwarded-For mitgeteilt.
