Game Boy Color

Der Game Boy Color (Abk. GBC) ist eine tragbare Spielkonsole von Nintendo, die am 21. Oktober 1998 in Japan erschien. Er ist eine Weiterentwicklung des originalen Game Boy mit Farbdisplay und wurde zusammen mit diesem insgesamt über 118 Millionen Mal verkauft.

Technik

Das Display zeigt 160 × 144 Pixel und kann aus einer Palette von 32.768 Farben bis zu 56 Farben gleichzeitig darstellen. Der Prozessor (Sharp LR35902) taktet mit bis zu 8,39 MHz – doppelt so schnell wie beim Vorgänger – und der Arbeitsspeicher wurde vervierfacht. Eine Infrarotschnittstelle ermöglichte drahtlosen Datenaustausch.

Kompatibilität

Der Game Boy Color ist vollständig abwärtskompatibel: Ältere Game-Boy-Spiele werden in einer vom Nutzer wählbaren Farbpalette dargestellt. Exklusive GBC-Titel erschienen auf durchsichtigen Modulen; Spiele, die beide Systeme unterstützten, auf schwarzen Modulen.

Spiele

Bekannte Titel sind Pokémon Gold/Silber/Kristall, The Legend of Zelda: Oracle of Ages/Seasons und Super Mario Bros. Deluxe.
