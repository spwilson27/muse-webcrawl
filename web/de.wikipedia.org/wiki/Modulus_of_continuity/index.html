Stetigkeitsmodul

Der Stetigkeitsmodul (englisch modulus of continuity) einer Funktion quantifiziert in der Analysis, wie stark die Funktionswerte bei kleinen Änderungen des Arguments schwanken können. Für eine Funktion f auf einem metrischen Raum ist er definiert als ωf(δ) = sup { |f(x) − f(y)| : |x − y| ≤ δ }.

Eigenschaften

Eine Funktion ist genau dann gleichmäßig stetig, wenn ihr Stetigkeitsmodul für δ → 0 gegen null geht. Der Stetigkeitsmodul ist monoton wachsend und subadditiv. Er erlaubt es, Stetigkeitsaussagen zu präzisieren und ratenartig zu formulieren.

Besondere Fälle

  • Gilt ωf(δ) ≤ L·δ, so ist f Lipschitz-stetig mit Konstante L
  • Gilt ωf(δ) ≤ C·δα mit 0 < α ≤ 1, so ist f Hölder-stetig zum Exponenten α

Anwendungen

Stetigkeitsmoduln werden in der Approximationstheorie verwendet, um die Konvergenzgeschwindigkeit von Näherungsverfahren (z. B. durch Polynome, Satz von Jackson) gegen die Glattheit der zu approximierenden Funktion abzuschätzen.
