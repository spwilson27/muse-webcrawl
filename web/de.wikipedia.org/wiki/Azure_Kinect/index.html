Azure Kinect

Die Azure Kinect DK (Developer Kit) ist eine von Microsoft entwickelte Entwicklerplattform für räumliche Erfassung (Spatial Computing), die im Februar 2019 auf dem Mobile World Congress in Barcelona vorgestellt wurde. Sie wird vor allem für Anwendungen der Computer Vision und der Künstlichen Intelligenz eingesetzt.

Technik

Das Gerät kombiniert mehrere Sensoren in einem kompakten Gehäuse:

  • eine 1-Megapixel-Tiefenkamera mit Time-of-Flight-Technik (ToF), die auf der Technologie des Kinect-Sensors der Xbox basiert,
  • eine 12-Megapixel-RGB-Kamera für Farbbilder,
  • ein kreisförmiges Mikrofonarray mit sieben Mikrofonen zur räumlichen Audiowiedergabe und Spracherkennung,
  • Beschleunigungs- und Drehratensensoren (IMU) zur Lagebestimmung.

Die Tiefenkamera arbeitet mit einer Auflösung von bis zu 1024 × 1024 Pixeln. Mehrere Azure-Kinect-Geräte lassen sich über Synchronisationsanschlüsse zu einem Erfassungssystem verbinden.

Einordnung

Die Azure Kinect gilt als Nachfolgerin der eingestellten Kinect-Produktlinie für Spielkonsolen, richtet sich jedoch an gewerbliche und wissenschaftliche Anwender, etwa in der Robotik, der Logistik, dem Gesundheitswesen und der Fertigung. Die Auswertung der Sensordaten erfolgte über Microsofts Cloud-Plattform Microsoft Azure sowie über On-Device-Verarbeitung. Im Jahr 2023 stellte Microsoft die Produktion der Azure Kinect DK ein und verwies auf Partnerprodukte, die die Technologie weiterführten.
