Raspberry Pi OS

Raspberry Pi OS (bis Mai 2020 Raspbian) ist eine auf Debian basierende Linux-Distribution, die von der Raspberry Pi Foundation als offizielles Betriebssystem für die Einplatinencomputer der Reihe Raspberry Pi entwickelt und gepflegt wird.

Raspberry Pi OS

Entwickler: Raspberry Pi Foundation / Raspberry Pi Ltd
Basis: Debian (ARM)
Erstveröffentlichung: 2012 (als Raspbian)
Desktop: PIXEL / labwc (Wayland)

Geschichte

Raspbian entstand 2012 als inoffizieller Port von Debian auf die ARMv6-Architektur des ersten Raspberry Pi, erstellt von Mike Thompson und Peter Green. Die Foundation übernahm das Projekt bald als offizielles System. Mit der Einführung von 64-Bit-Modellen wurde die Distribution im Mai 2020 in Raspberry Pi OS umbenannt. Seit der auf Debian 12 („Bookworm“) basierenden Version nutzt die Desktop-Variante standardmäßig Wayland mit dem Compositor labwc.

Varianten

Das System wird in drei Hauptausführungen angeboten: einer Desktop-Version mit grafischer Oberfläche, einer Desktop-Version mit zusätzlicher empfohlener Software sowie der schlanken „Lite“-Version ohne grafische Oberfläche für Server- und eingebettete Anwendungen. Zudem existiert eine Legacy-Variante für ältere Hardware.

Merkmale

Die Desktop-Umgebung PIXEL (Pi Improved Xwindows Environment, Lightweight) basiert auf LXDE. Das System enthält Werkzeuge zur Konfiguration (raspi-config), Programmierumgebungen wie Thonny und Scratch sowie den Imager als offizielles Werkzeug zum Beschreiben von Speicherkarten. Zur Installation auf anderen Systemen steht der Raspberry Pi Imager für Windows, macOS und Linux bereit.
