JSON Web Token

JSON Web Token (JWT, ausgesprochen wie das englische Wort „jot“) ist ein offener Standard (RFC 7519), der eine kompakte und eigenständige Methode definiert, um Informationen zwischen Parteien als JSON-Objekt sicher zu übertragen.

Aufbau

Ein JWT besteht aus drei Teilen, die durch Punkte getrennt sind: dem Header, der Nutzdaten (Payload) und der Signatur. Header und Payload sind Base64URL-kodierte JSON-Objekte; die Signatur wird mit einem Geheimnis (HMAC) oder einem Schlüsselpaar (RSA, ECDSA) berechnet.

Verwendung

JWTs werden vor allem zur Authentifizierung und Autorisierung in Webanwendungen und bei Single Sign-on eingesetzt. Nach der Anmeldung erhält der Client ein Token, das er bei weiteren Anfragen, meist im Authorization-Header, mitsendet.

Sicherheit

Da der Inhalt eines JWT nur kodiert, nicht verschlüsselt ist, dürfen keine vertraulichen Daten in der Payload stehen. Die Signatur schützt vor Manipulation.
