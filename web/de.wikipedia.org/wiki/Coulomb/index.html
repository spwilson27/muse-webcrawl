Coulomb

Einheitenzeichen: C
Größe: elektrische Ladung
Benannt nach: Charles Augustin de Coulomb

Das Coulomb (Einheitenzeichen C, früher auch Cb) ist die SI-Einheit der elektrischen Ladung. Sie ist nach dem französischen Physiker Charles Augustin de Coulomb (1736–1806) benannt.

Definition

Seit der Revision des Internationalen Einheitensystems von 2019 ist das Coulomb über die Elementarladung definiert: Ein Coulomb entspricht der Ladung, die von etwa 6,241509074 · 1018 Elementarladungen getragen wird. Praktisch anschaulich: Fließt eine Sekunde lang ein Strom von einem Ampere, so wird die Ladung von einem Coulomb transportiert (1 C = 1 A·s).

Vergleich

Die Ladung eines einzelnen Elektrons beträgt rund −1,602 · 10−19 C. Ein Blitz überträgt typischerweise Ladungen in der Größenordnung von 15 bis 350 Coulomb. Die Kapazität von Kondensatoren wird in Amperesekunden pro Volt (Farad) angegeben.
