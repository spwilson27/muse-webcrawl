Message Transfer Agent

Ein Message Transfer Agent (MTA), auch Mail Transfer Agent oder Mailserver genannt, ist ein Programm, das E-Mails entgegennimmt und weiterleitet. MTAs bilden das Rückgrat des E-Mail-Transports im Internet und kommunizieren untereinander überwiegend über das Simple Mail Transfer Protocol (SMTP).

Aufgaben

Ein MTA nimmt E-Mails von Mail User Agents (etwa einem E-Mail-Programm) oder von anderen MTAs entgegen, bestimmt über das Domain Name System (per MX-Eintrag) den zuständigen Zielserver und übermittelt die Nachricht dorthin. Ist der Zielserver vorübergehend nicht erreichbar, speichert der MTA die Nachricht in einer Warteschlange und wiederholt die Zustellung. Nicht zustellbare Nachrichten werden mit einer Fehlermeldung (Bounce Message) an den Absender zurückgeschickt. Die endgültige Ablage im Postfach des Empfängers übernimmt anschließend ein Mail Delivery Agent (MDA).

Bekannte Implementierungen

  • Sendmail – einer der ältesten und lange verbreitetsten MTAs der Unix-Welt
  • Postfix – sicherheitsorientierter, weit verbreiteter MTA von Wietse Venema
  • Exim – flexibler MTA, Standard in vielen Linux-Distributionen (Debian)
  • qmail – von Daniel J. Bernstein entwickelter MTA
  • Microsoft Exchange Server – kommerzielle Groupware-Lösung mit MTA-Funktionen

Abgrenzung

Vom MTA zu unterscheiden sind der Mail User Agent (MUA) als Programm des Endbenutzers und der Mail Delivery Agent (MDA), der die Postfächer verwaltet und Nachrichten über Protokolle wie IMAP oder POP3 bereitstellt.
