Classic-Umgebung

Die Classic-Umgebung (englisch Classic Environment) war eine Software-Kompatibilitätsschicht von Apple, mit der unter Mac OS X Programme des klassischen Mac OS (bis Version 9) ausgeführt werden konnten. Sie war Bestandteil von Mac OS X auf PowerPC-Macs von 2001 bis zur Einführung der Intel-Macs.

Funktionsweise

Die Classic-Umgebung startete ein im Wesentlichen vollständiges Mac OS 9 als Prozess innerhalb von Mac OS X. Klassische Programme liefen darin in ihrer gewohnten Oberfläche, hatten jedoch keinen direkten Hardwarezugriff; Systemaufrufe wurden an Mac OS X weitergereicht. Mit dem Wechsel zur Intel-Architektur (ab 2006) entfiel die Unterstützung, da die Umgebung auf PowerPC-Code angewiesen war.
