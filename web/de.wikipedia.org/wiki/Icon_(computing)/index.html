Icon (Computer)

Ein Icon (englisch für „Symbol, Piktogramm") ist in der Informatik ein kleines grafisches Symbol auf einer grafischen Benutzeroberfläche, das eine Datei, ein Programm, eine Funktion oder einen Befehl repräsentiert. Durch Anklicken oder Antippen eines Icons wird die zugehörige Aktion ausgelöst.

Geschichte

Icons wurden in den 1970er Jahren am Xerox PARC im Rahmen der Entwicklung der grafischen Benutzeroberfläche des Xerox Star (1981) eingeführt und durch den Apple Macintosh (1984) sowie Microsoft Windows einem breiten Publikum bekannt. Pioniere des Icon-Designs waren unter anderem Susan Kare, die die ursprünglichen Macintosh-Icons gestaltete.

Gestaltung

Icons sollen auf einen Blick verständlich sein und bedienen sich daher einfacher, stilisierter Bildmetaphern, etwa eines Papierkorbs für „Löschen" oder einer Diskette für „Speichern". Moderne Betriebssysteme stellen Icons in mehreren Auflösungen bereit, damit sie auf hochauflösenden Bildschirmen scharf dargestellt werden.

Dateiformate

  • ICO – Windows-Symbolformat
  • ICNS – macOS-Symbolformat
  • PNG und SVG – verbreitete Formate im Web und unter Linux
