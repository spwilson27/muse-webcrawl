ASP.NET Core

ASP.NET Core ist ein quelloffenes, plattformübergreifendes Webframework von Microsoft zum Erstellen moderner, cloudfähiger Internetanwendungen. Es ist die Nachfolgeversion von ASP.NET (klassisch) und wurde 2016 als eigenständiges Framework neu entwickelt. ASP.NET Core wird heute unter dem Namen ASP.NET in der .NET-Plattform weitergeführt.

Geschichte

Im Gegensatz zum klassischen ASP.NET, das eng an Windows und den IIS gebunden war, wurde ASP.NET Core modular und plattformunabhängig konzipiert. Es läuft auf Windows, Linux und macOS. Mit der Version 3.0 (2019) wurden klassisches ASP.NET und ASP.NET Core im einheitlichen .NET-Releasezyklus zusammengeführt; seit .NET 5 wird das Framework ohne das Suffix „Core“ als ASP.NET bezeichnet.

Programmiermodelle

  • Razor Pages: seitenorientiertes Modell für klassische Webseiten
  • Model-View-Controller (MVC): musterbasierte Trennung von Darstellung und Logik
  • Minimal APIs: schlanke, deklarative HTTP-Endpunkte ohne Controller-Klassen
  • Blazor: interaktive Komponenten, serverseitig oder per WebAssembly im Browser
  • gRPC: leistungsfähige Remote-Prozeduraufrufe auf Basis von HTTP/2
  • SignalR: Echtzeitkommunikation zwischen Server und Clients

Technik

ASP.NET Core nutzt eine Middleware-Pipeline zur Verarbeitung von HTTP-Anfragen und den eingebetteten Webserver Kestrel. Abhängigkeitsinjektion (Dependency Injection), Konfiguration, Logging und integrierte Authentifizierung sind fest im Framework verankert. Die Entwicklung erfolgt überwiegend in C#, der Quellcode ist auf GitHub öffentlich einsehbar.
