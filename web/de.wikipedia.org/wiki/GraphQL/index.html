GraphQL

GraphQL ist eine Abfragesprache für APIs sowie eine Laufzeitumgebung zur Ausführung dieser Abfragen mit vorhandenen Daten. GraphQL wurde ab 2012 bei Facebook entwickelt, ab 2015 intern und öffentlich eingesetzt und 2015 als Open Source veröffentlicht. 2018 wurde das Projekt an die eigens gegründete GraphQL Foundation unter dem Dach der Linux Foundation übergeben.

Konzept

Im Gegensatz zu REST, bei dem der Server über viele Endpunkte festgelegte Datenstrukturen liefert, deklariert bei GraphQL der Client in einer einzigen Anfrage exakt die Felder, die er benötigt. Dadurch werden Over-Fetching (zu viele Daten) und Under-Fetching (zu wenige Daten, weitere Anfragen nötig) vermieden. Die API wird über ein stark typisiertes Schema beschrieben, das alle verfügbaren Datentypen, Abfragen (Queries), Änderungen (Mutations) und Abonnements (Subscriptions) festlegt.

Bestandteile

  • Schema Definition Language (SDL) zur Beschreibung des Schemas
  • Resolver – Funktionen auf dem Server, die die Werte der einzelnen Felder bereitstellen
  • Introspection – das Schema kann zur Laufzeit abgefragt werden, was Werkzeuge wie GraphiQL ermöglicht

Verbreitung

GraphQL wird unter anderem von GitHub, Shopify, Twitter/X und zahlreichen weiteren Unternehmen eingesetzt. Es existieren Implementierungen und Client-Bibliotheken für nahezu alle gängigen Programmiersprachen.
