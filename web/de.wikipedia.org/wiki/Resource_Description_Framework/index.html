Resource Description Framework

Das Resource Description Framework (RDF) ist ein vom World Wide Web Consortium (W3C) standardisiertes Datenmodell zur Beschreibung von Ressourcen und Metadaten im Web. Es bildet eine der Grundlagen des Semantic Web und von Linked Data.

Grundmodell

Aussagen werden in RDF als Tripel aus Subjekt, Prädikat und Objekt dargestellt: Das Subjekt bezeichnet eine Ressource (identifiziert durch eine URI/IRI), das Prädikat eine Eigenschaft und das Objekt einen Wert oder eine weitere Ressource. Die Gesamtheit solcher Tripel lässt sich als gerichteter Graph darstellen und abfragbar machen. Literale können Sprachangaben oder Datentypen (u. a. nach XML Schema) tragen; anonyme Ressourcen werden als Blank Nodes modelliert.

Serialisierungen

Für den Austausch existieren mehrere Syntaxformen, darunter Turtle, N-Triples, JSON-LD und RDF/XML, die ursprüngliche, heute weniger gebräuchliche XML-Serialisierung. In HTML-Dokumente eingebettete Daten nutzen RDFa.

Erweiterungen und Werkzeuge

Auf RDF bauen unter anderem das Vokabularbeschreibungssprache RDF Schema (RDFS), die Ontologiesprache OWL, die Abfragesprache SPARQL und Regelwerke zur Validierung (SHACL) auf. RDF-Datenbanken werden als Triplestores bezeichnet. Große Anwendungen sind Wissensgraphen wie Wikidata und DBpedia, die ihre Inhalte als RDF zur Verfügung stellen.
