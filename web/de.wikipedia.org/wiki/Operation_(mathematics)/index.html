Operation (Mathematik)

Eine Operation oder Verknüpfung ist in der Mathematik eine Abbildung, die einem oder mehreren Elementen einer Menge ein weiteres Element zuordnet. Die Anzahl der Eingabeelemente heißt Stelligkeit der Operation.

Arten

Nullstellige Operationen wählen ein ausgezeichnetes Element aus, etwa ein neutrales Element. Einstellige (unäre) Operationen sind zum Beispiel Negation, Betrag oder Fakultät. Zweistellige (binäre) Operationen wie Addition und Multiplikation bilden aus zwei Elementen ein drittes; sie stehen im Zentrum der Algebra, wo man ihre Eigenschaften – Assoziativität, Kommutativität, Distributivität – untersucht.

Innere und äußere Operationen

Eine innere Verknüpfung auf einer Menge liefert stets wieder ein Element derselben Menge; algebraische Strukturen wie Gruppen, Ringe und Körper bestehen aus einer Grundmenge mit solchen Operationen. Bei äußeren Verknüpfungen wirkt eine zweite Menge, etwa wenn ein Vektor mit einem Skalar multipliziert wird.

Bedeutung

Der Operationsbegriff erlaubt es, das Rechnen mit Zahlen, Vektoren, Matrizen, Funktionen oder logischen Aussagen in einer gemeinsamen Sprache zu beschreiben. In der Informatik entsprechen Operationen den Anweisungen und Funktionen von Programmiersprachen, deren Operanden etwa auf einem Operandenstapel verwaltet werden.
