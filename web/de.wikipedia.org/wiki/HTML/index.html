Hypertext Markup Language

HTML
Typ: Auszeichnungssprache
Entwickler: Tim Berners-Lee / WHATWG
Ersterscheinung: 1993
Dateiendung: .html, .htm

Die Hypertext Markup Language (HTML, deutsch: Hypertext-Auszeichnungssprache) ist eine textbasierte Auszeichnungssprache zur Strukturierung elektronischer Dokumente wie Texte mit Hyperlinks, Bildern und anderen Inhalten. HTML ist die Grundlage des World Wide Web und wird von Webbrowsern dargestellt.

Geschichte

HTML wurde 1989/90 von Tim Berners-Lee am CERN in Genf entwickelt und 1993 erstmals veröffentlicht. Die Sprache lehnt sich an SGML an. Über die Versionen 2.0 (1995), 3.2 (1997) und 4.01 (1999) entwickelte sie sich weiter; parallel existierte mit XHTML eine XML-basierte Variante. Die aktuelle, fortlaufend weiterentwickelte Fassung ist der HTML Living Standard der WHATWG; Version HTML5 wurde 2014 vom W3C verabschiedet.

Aufbau

Ein HTML-Dokument besteht aus Elementen, die durch Tags in spitzen Klammern ausgezeichnet werden, etwa Überschriften, Absätze, Listen, Tabellen und Verweise. Tags können Attribute besitzen. Die logische Struktur des Dokuments bildet einen Baum (Document Object Model, DOM), auf den mit JavaScript zugegriffen werden kann. Das Erscheinungsbild wird üblicherweise mit CSS gestaltet.

Bedeutung

Zusammen mit CSS und JavaScript bildet HTML die Kerntechnik des Webs. Praktisch jede Webseite weltweit ist als HTML-Dokument aufgebaut.
