Code Napoléon

Der Code Napoléon ist die geläufige Bezeichnung für den Code civil des Français von 1804, das französische Gesetzbuch über das Zivilrecht. Er wurde unter Napoleon Bonaparte erarbeitet und 1807 offiziell „Code Napoléon" benannt; nach 1814 wechselte der Name mehrfach, 1870 wurde die Bezeichnung endgültig wieder aufgegeben.

Entstehung

Eine vierköpfige Kommission unter Beteiligung von Jean-Étienne-Marie Portalis legte binnen weniger Monate einen Entwurf vor. Napoleon nahm persönlich an zahlreichen Sitzungen des Staatsrates teil, der das Gesetzeswerk beriet. Der Code trat am 21. März 1804 in Kraft.

Inhalt und Wirkung

Das Gesetzbuch umfasst in seiner ursprünglichen Fassung 2281 Artikel in drei Büchern: Personenrecht, Sachenrecht und die Arten des Eigentumserwerbs (darunter Vertrags- und Erbrecht). Es verankerte Prinzipien der Französischen Revolution wie Rechtsgleichheit, Eigentumsgarantie und Vertragsfreiheit, stellte Frauen jedoch unter die Vormundschaft des Mannes. Über die Napoleonischen Kriege und französische Kolonien verbreitete sich das Modell weltweit; der Code civil gilt in Frankreich – vielfach reformiert – bis heute.
