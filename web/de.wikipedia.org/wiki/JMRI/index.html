JMRI

Name: Java Model Railroad Interface
Typ: Open-Source-Software
Programmiersprache: Java
Zweck: Steuerung von Modelleisenbahnen

JMRI ist eine freie Software-Suite zur Steuerung digitaler Modelleisenbahnen mit einem Computer. Der Name steht für Java Model Railroad Interface. Das Projekt wird von Freiwilligen entwickelt und läuft auf mehreren Betriebssystemen.

Programme

DecoderPro vereinfacht das Programmieren von DCC-Lokdecodern über Formulare, statt einzelne Konfigurationsvariablen von Hand eingeben zu müssen. PanelPro dient zum Erstellen von Gleisbildstellwerken, mit denen Weichen, Signale, Rückmelder und Fahrstraßen dargestellt und bedient werden können. Weitere Werkzeuge verwalten Loklisten, Fahrregler und Automatisierungen.

Technik

JMRI verbindet sich über Schnittstellen mit Digitalzentralen verschiedener Hersteller und unterstützt unter anderem DCC-Systeme, Rückmeldebusse und Netzwerkverbindungen. Über den integrierten Webserver und mobile Anwendungen lassen sich Züge auch mit Smartphone oder Tablet steuern.

Einsatz

Die Software wird sowohl auf Heimanlagen als auch in Clubs verwendet. Weil sie quelloffen ist, können Nutzer Funktionen erweitern, Decoderdefinitionen beitragen und Abläufe mit Skripten automatisieren.
