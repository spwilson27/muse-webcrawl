Amazon EC2

Amazon Elastic Compute Cloud (Amazon EC2) ist ein Webservice von Amazon Web Services, der 2006 startete und virtuelle Server („Instanzen“) in der Cloud bereitstellt. EC2 gilt als einer der Gründungdienste des modernen Cloud Computing: Nutzer können Rechenkapazität innerhalb von Minuten mieten und nach Nutzung abrechnen.

Instanztypen

EC2 bietet Hunderte von Instanztypen, die für unterschiedliche Zwecke optimiert sind – allgemein, rechen-, speicher- oder speicherplatzoptimiert sowie mit GPU-Beschleunigern für maschinelles Lernen. Die Instanzen basieren heute überwiegend auf der Nitro-Virtualisierung und auch auf ARM-Prozessoren der hauseigenen Graviton-Reihe.

Betriebsmodelle

Neben On-Demand-Instanzen gibt es reservierte Instanzen mit Rabatten für langfristige Bindung sowie Spot-Instanzen, die freie Kapazitäten zu stark reduzierten, schwankenden Preisen nutzen, aber kurzfristig entzogen werden können. Über Auto Scaling lässt sich die Zahl der Instanzen automatisch an die Last anpassen; Elastic Load Balancing verteilt Anfragen auf mehrere Instanzen.

Abbilder und Speicher

Betriebssysteme und Anwendungen werden über Amazon Machine Images (AMIs) bereitgestellt; persistente Daten liegen auf Elastic Block Store (EBS). Deutsche und europäische Kunden nutzen häufig die Region Frankfurt am Main.
