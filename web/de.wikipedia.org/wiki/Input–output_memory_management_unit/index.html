Input–Output Memory Management Unit (IOMMU)

Eine Input–Output Memory Management Unit (IOMMU) ist eine Speicherschutzeinheit in Computersystemen, die Speicherzugriffe von Ein-/Ausgabegeräten per Direct Memory Access (DMA) verwaltet und übersetzt. Während die Memory Management Unit (MMU) die Adressübersetzung für die CPU übernimmt, erfüllt die IOMMU dieselbe Aufgabe für Peripheriegeräte.

Arbeitsweise

Die IOMMU führt Seitentabellen, die die von einem Gerät verwendeten Adressen auf physische Speicheradressen abbilden. Greift ein Gerät per DMA auf den Speicher zu, prüft und übersetzt die IOMMU jede Transaktion. Zugriffe außerhalb des freigegebenen Bereichs werden verworfen und als Fehlerereignis signalisiert.

Anwendungen

  • Systemvirtualisierung: Sicherer direkter Gerätezugriff (Passthrough) für virtuelle Maschinen, z. B. mit Intels VT-d und AMDs AMD-Vi.
  • Sicherheit: Abwehr von DMA-Angriffen durch externe Schnittstellen wie Thunderbolt; Funktionen wie „Kernel DMA Protection“ in modernen Betriebssystemen beruhen auf der IOMMU.
  • Adressraumgröße: Auch Geräte mit begrenztem Adressbereich (32-Bit) können so auf großen Hauptspeicher zugreifen.

Geschichte und Implementierungen

Vorreiter waren die IOMMUs in Workstations von Sun und die GART (Graphics Address Remapping Table) für AGP-Grafikkarten. Standardisiert wurden moderne Varianten von AMD (AMD-Vi, Spezifikation unter dem Namen „IOMMU“) und Intel (VT-d); auf ARM-Plattformen übernimmt die SMMU (System Memory Management Unit) die gleiche Aufgabe.
