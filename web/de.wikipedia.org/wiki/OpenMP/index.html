OpenMP

Erstveröffentlichung1997
OrganisationOpenMP Architecture Review Board
TypAPI / Programmiermodell
SprachenC, C++, Fortran

OpenMP (Open Multi-Processing) ist eine Programmierschnittstelle (API) zur parallelen Programmierung auf Systemen mit gemeinsamem Speicher. Sie wird vom OpenMP Architecture Review Board (ARB) spezifiziert, einem Zusammenschluss von Hardware- und Softwareherstellern. Die erste Version erschien 1997 zunächst für Fortran; Versionen für C und C++ folgten 1998.

Programmiermodell

OpenMP folgt dem Fork-Join-Modell: Ein Master-Thread startet das Programm, erzeugt an parallelen Regionen ein Team weiterer Threads und setzt die Ausführung nach deren Ende wieder allein fort. Die Parallelisierung wird überwiegend über Compilerdirektiven gesteuert – in C und C++ über #pragma omp, in Fortran über spezielle Kommentare. Ergänzt werden sie durch Laufzeitfunktionen und Umgebungsvariablen wie OMP_NUM_THREADS.

Ein typisches Beispiel ist die parallele Schleife:

#pragma omp parallel for
for (int i = 0; i < n; i++) {
    a[i] = b[i] + c[i];
}

Neben Schleifenparallelismus unterstützt OpenMP auch Abschnitte (sections), Aufgaben (tasks) und seit Version 4.0 das Auslagern von Berechnungen auf Beschleuniger wie GPUs (target-Direktiven) sowie SIMD-Vektorisierung.

Versionsgeschichte

Wichtige Meilensteine sind Version 2.0 (2000/2002), Version 3.0 (2008) mit dem Task-Konzept, Version 4.0 (2013) mit Geräteunterstützung, Version 4.5 (2015), Version 5.0 (2018) und Version 5.2 (2021). Praktisch alle gängigen Compiler – darunter GCC, Clang, die Intel-Compiler und Microsoft Visual C++ – unterstützen OpenMP.

Anwendungsgebiete

OpenMP ist besonders im wissenschaftlichen Rechnen und im High Performance Computing verbreitet, weil sich bestehende sequenzielle Programme mit vergleichsweise geringem Aufwand schrittweise parallelisieren lassen. Es steht damit ergänzend zu MPI, das für Systeme mit verteiltem Speicher konzipiert ist; beide Modelle werden häufig kombiniert.
