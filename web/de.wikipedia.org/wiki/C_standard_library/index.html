C-Standardbibliothek

SpracheC
StandardISO/IEC 9899
Bekannte Implementierungenglibc, musl, Microsoft UCRT, Newlib

Die C-Standardbibliothek (englisch C standard library, oft libc genannt) ist die im Sprachstandard ISO C festgelegte Bibliothek von Funktionen, Makros und Datentypen, die jedem C-Programm zur Verfügung stehen. Sie umfasst unter anderem Ein- und Ausgabe, Speicherverwaltung, Zeichenkettenverarbeitung, Mathematik und Zeitfunktionen.

Header-Dateien

Die Funktionalität ist auf Header-Dateien aufgeteilt, darunter:

  • <stdio.h> – Ein- und Ausgabe (printf, fopen, …)
  • <stdlib.h> – Speicherverwaltung, Zufallszahlen, Programmsteuerung
  • <string.h> – Zeichenketten- und Speicherfunktionen
  • <math.h> – mathematische Funktionen
  • <time.h> – Datums- und Zeitfunktionen
  • <ctype.h> – Zeichenklassifikation
  • <stdint.h> und <inttypes.h> – Ganzzahltypen fester Breite (seit C99)
  • <stdbool.h> – boolescher Datentyp (seit C99)

Implementierungen

Unter Linux ist die GNU C Library (glibc) die verbreitetste Implementierung; daneben existieren musl, uClibc und Newlib für eingebettete Systeme. Unter Windows stellt die Universal C Runtime (UCRT) die Bibliothek bereit. Auch andere Sprachen greifen über Foreign Function Interfaces häufig auf die C-Standardbibliothek als kleinsten gemeinsamen Nenner der Systemaufrufe zurück.
