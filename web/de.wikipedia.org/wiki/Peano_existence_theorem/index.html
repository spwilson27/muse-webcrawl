Satz von Peano

Gebiet: Theorie der Differentialgleichungen

Aussage: Existenz lokaler Lösungen

Satz von Peano (Existenzsatz)

Der Satz von Peano ist ein Existenzsatz in der Theorie der gewöhnlichen Differentialgleichungen, benannt nach Giuseppe Peano. Er besagt, dass ein Anfangswertproblem y′ = f(x, y), y(x0) = y0 mit einer lediglich stetigen rechten Seite f stets mindestens eine lokale Lösung besitzt.

Aussage

Ist die Funktion f in einer Umgebung des Anfangspunktes (x0, y0) stetig, so existiert ein Intervall um x0, auf dem mindestens eine Lösung des Anfangswertproblems existiert. Der Satz macht keine Aussage über die Eindeutigkeit; diese folgt erst unter zusätzlichen Voraussetzungen wie einer Lipschitz-Bedingung (Satz von Picard-Lindelöf).

Bedeutung und Beweisidee

Die Beweise verwenden meist Näherungslösungen, etwa die Euler-Polygonzüge, und ein Kompaktheitsargument wie den Satz von Arzelà-Ascoli, um eine konvergente Teilfolge zu gewinnen. Ein bekanntes Beispiel zeigt die Nicht-Eindeutigkeit: Das Anfangswertproblem y′ = √|y|, y(0) = 0 besitzt neben y ≡ 0 unendlich viele weitere Lösungen.
