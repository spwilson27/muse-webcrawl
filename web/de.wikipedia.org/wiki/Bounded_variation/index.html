Beschränkte Variation

Eine Funktion von beschränkter Variation (auch beschränkter Schwankung) ist in der Analysis eine reellwertige Funktion, deren Gesamtänderung auf einem Intervall endlich ist. Der Begriff geht auf Camille Jordan (1881) zurück und spielt eine wichtige Rolle in der Integrationstheorie, insbesondere beim Riemann-Stieltjes-Integral.

Definition

Sei f eine Funktion auf dem Intervall [a, b]. Für eine Zerlegung a = x0 < x1 < … < xn = b betrachtet man die Summe der Beträge der Zuwächse Σ |f(xi) − f(xi−1)|. Das Supremum dieser Summen über alle Zerlegungen heißt die totale Variation (oder Gesamtvariation) von f auf [a, b]. Ist dieses Supremum endlich, so heißt f von beschränkter Variation.

Eigenschaften

  • Jede monotone Funktion ist von beschränkter Variation.
  • Jede Lipschitz-stetige Funktion und jede stetig differenzierbare Funktion auf einem kompakten Intervall ist von beschränkter Variation.
  • Satz von Jordan: Eine Funktion ist genau dann von beschränkter Variation, wenn sie sich als Differenz zweier monoton wachsender Funktionen darstellen lässt.
  • Funktionen von beschränkter Variation sind beschränkt, besitzen höchstens abzählbar viele Unstetigkeitsstellen und sind fast überall differenzierbar (Satz von Lebesgue).
  • Der Raum der Funktionen von beschränkter Variation bildet mit der Variationsnorm einen Banachraum.

Beispiele und Gegenbeispiele

Die Funktion f(x) = x · sin(1/x) für x ≠ 0 mit f(0) = 0 ist stetig, aber nicht von beschränkter Variation auf [0, 1]. Dagegen ist x2 · sin(1/x) von beschränkter Variation.

Anwendungen

Funktionen von beschränkter Variation dienen als Integratoren im Riemann-Stieltjes-Integral. In der Wahrscheinlichkeitstheorie stehen kumulative Verteilungsfunktionen in engem Zusammenhang mit monotonen Funktionen und damit mit beschränkter Variation. Verallgemeinerungen auf mehrere Veränderliche führen zum Begriff der BV-Funktionen, die in der Variationsrechnung und der Bildverarbeitung verwendet werden.
