Singuläres Maß

Ein singuläres Maß ist in der Maßtheorie ein Maß, das zu einem anderen Maß „singulär“ ist, das heißt, die beiden Maße konzentrieren sich auf disjunkte Mengen. Zwei Maße heißen zueinander singulär, wenn es eine Zerlegung des Grundraums in zwei Mengen gibt, auf denen jeweils eines der Maße verschwindet.

Lebesgue-Zerlegung

Nach dem Zerlegungssatz von Lebesgue lässt sich jedes σ-endliche Maß eindeutig in einen zu einem gegebenen Referenzmaß absolut stetigen und einen dazu singulären Anteil zerlegen. Bezogen auf das Lebesgue-Maß auf den reellen Zahlen bedeutet das: Ein Wahrscheinlichkeitsmaß zerfällt in einen absolut stetigen Teil (mit Dichte), einen diskreten Teil (Atome) und einen singulär stetigen Teil.

Beispiel

Das bekannteste Beispiel für ein singulär stetiges Maß ist die Verteilung der Cantor-Funktion: Sie ist stetig, besitzt also keine Atome, ist aber zum Lebesgue-Maß singulär, weil sie sich auf der Cantor-Menge konzentriert, die Lebesgue-Maß null hat.
