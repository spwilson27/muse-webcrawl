Quasiordnung

Eine Quasiordnung oder Präordnung (englisch preorder) ist in der Mathematik eine zweistellige Relation auf einer Menge, die reflexiv und transitiv ist. Im Unterschied zu einer Halbordnung wird keine Antisymmetrie gefordert; verschiedene Elemente können also gegenseitig in Relation stehen, ohne gleich zu sein.

Definition

Eine Relation ≲ auf einer Menge M heißt Quasiordnung, wenn für alle a, b, c ∈ M gilt:

  • Reflexivität: a ≲ a
  • Transitivität: aus a ≲ b und b ≲ c folgt a ≲ c

Definiert man a ∼ b durch a ≲ b und b ≲ a, so erhält man eine Äquivalenzrelation; auf den Äquivalenzklassen induziert die Quasiordnung eine (echte) Halbordnung.

Beispiele

Beispiele für Quasiordnungen sind die Teilbarkeitsrelation auf den ganzen Zahlen (wo a und −a gegenseitig teilbar, aber ungleich sind), die logische Implikation zwischen Aussagen in der Beweistheorie oder die Erreichbarkeitsrelation in gerichteten Graphen. In der Kategorientheorie bezeichnet eine Präordnung zugleich eine besonders einfache Kategorie, in der es zwischen je zwei Objekten höchstens einen Morphismus gibt.

Abgrenzung zum Handel

Das englische Wort pre-order bezeichnet außerdem die Vorbestellung von Waren vor ihrem Erscheinen, die mit dem mathematischen Begriff nicht zu verwechseln ist.
