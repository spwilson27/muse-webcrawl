Interledger protocol

Das Interledger protocol ist ein Protokollstapel für den Wertetransfer zwischen unabhängigen Zahlungsnetzwerken. Es definiert ein paketbasiertes Verfahren, bei dem Zahlungsanweisungen über zwischengeschaltete Knoten (Connectoren) geroutet werden – analog zur Paketvermittlung im Internet.

Technik

Kern des Protokolls sind die Nachrichtenformate PREPARE, FULFILL und REJECT sowie kryptografische Erfüllungsbedingungen: Ein Zahlungsauftrag wird nur dann endgültig gebucht, wenn der Empfänger den passenden Erfüllungscode liefert, bevor eine Zeitbedingung abläuft. Darüber liegt das Simple Payment Setup Protocol (SPSP) für die Adressierung von Zahlungsempfängern.

Organisation

Die Spezifikationen werden offen in der Interledger-Community entwickelt; die Interledger Foundation fördert Implementierungen, unter anderem für Web Monetization und internationale Überweisungen.
