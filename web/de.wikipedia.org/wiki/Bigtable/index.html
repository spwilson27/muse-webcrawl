Bigtable

Bigtable ist ein von Google entwickeltes, verteiltes Speichersystem für strukturierte Daten, das auf sehr große Datenmengen – bis in den Petabyte-Bereich – auf Tausenden von Servern skaliert. Die 2006 veröffentlichte Systembeschreibung beeinflusste maßgeblich die Entwicklung der NoSQL-Datenbanken; Apache HBase wurde direkt nach dem Vorbild von Bigtable entworfen.

Datenmodell

Bigtable speichert Daten als dünn besetzte, mehrdimensionale, sortierte Map: Jede Zelle wird über einen Zeilenschlüssel, einen Spaltennamen und einen Zeitstempel adressiert. Der Zeitstempel ermöglicht es, mehrere Versionen eines Wertes zu halten. Die Daten werden komprimiert und zeilenbereichsweise („Tablets") auf viele Server verteilt.

Nutzung

Google setzte Bigtable unter anderem für den Webindex, Google Earth, Google Maps und YouTube ein. Seit 2015 wird das System als Cloud Bigtable auch extern als verwalteter Datenbankdienst angeboten. Intern wurde Bigtable später durch das weltweit verteilte System Spanner ergänzt beziehungsweise in vielen Diensten abgelöst.
