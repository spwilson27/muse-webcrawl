Semantic Web

Das Semantic Web (Semantisches Web) ist eine Erweiterung des World Wide Web, deren Ziel es ist, Informationen im Web nicht nur für Menschen, sondern auch für Maschinen verstehbar zu machen. Dazu werden Daten mit eindeutigen Identifikatoren und formal beschriebener Bedeutung (Semantik) versehen, sodass Programme sie verknüpfen, kombinieren und automatisiert auswerten können. Das Konzept wurde 2001 von Tim Berners-Lee, James Hendler und Ora Lassila in einem vielzitierten Aufsatz vorgestellt.

Technologien

Das Semantic Web baut auf Standards des World Wide Web Consortium (W3C) auf:

  • URI/IRI zur eindeutigen Identifikation von Ressourcen,
  • RDF (Resource Description Framework) zur Formulierung von Aussagen in Form von Subjekt-Prädikat-Objekt-Tripeln,
  • RDFS und OWL (Web Ontology Language) zur Beschreibung von Klassen, Eigenschaften und Ontologien,
  • SPARQL als Abfragesprache für RDF-Datenbestände.

Anwendungen

Praktische Ausprägungen des Semantic Web sind Linked Open Data, bei dem offene Datensätze wie die DBpedia (aus Wikipedia extrahiert) oder Wikidata maschinenlesbar verknüpft werden, sowie die Auszeichnung von Webseiten mit strukturierten Daten (schema.org), die Suchmaschinen für sogenannte Rich Snippets und Wissensgraphen (Knowledge Graphs) nutzen.

Kritik und Entwicklung

Die ursprüngliche Vision eines weitgehend formal logisch erschlossenen Webs mit autonomen Agenten hat sich in voller Breite nicht durchgesetzt; kritisiert wurden die Komplexität der Standards und die Aufwände der Ontologieerstellung. Zugleich sind Kernideen – verknüpfte, strukturierte Daten – in Wissensgraphen großer Suchmaschinen und in offenen Datenportalen fest etabliert.
