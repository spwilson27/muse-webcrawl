Apache Thrift

Apache Thrift
Entwickler: Apache Software Foundation
Erstveröffentlichung: 2007 (Facebook)
Kategorie: RPC-Framework
Lizenz: Apache License 2.0

Apache Thrift ist ein Framework für die Entwicklung skalierbarer, sprachübergreifender Dienste auf Grundlage von Remote Procedure Calls (RPC). Es wurde bei Facebook entwickelt, um die Kommunikation zwischen den in unterschiedlichen Programmiersprachen geschriebenen Diensten der Plattform zu vereinheitlichen, 2007 als Open Source veröffentlicht und 2010 ein Top-Level-Projekt der Apache Software Foundation. Ein grundlegendes technisches Papier beschrieb Thrift als „skalierbares, sprachübergreifendes Framework zur Diensteimplementierung".

Funktionsweise

Dienstschnittstellen und Datentypen werden in einer eigenen Beschreibungssprache (Interface Definition Language, IDL) in .thrift-Dateien definiert. Ein Compiler erzeugt daraus Quellcode-Gerüste (Stubs und Skeletons) für über 20 Zielsprachen, darunter C++, Java, Python, PHP, Ruby, Erlang, Go, C# und JavaScript. Zur Laufzeit kombiniert Thrift einen austauschbaren Protokoll-Layer (etwa ein kompaktes Binärprotokoll oder JSON) mit einem Transport-Layer (Sockets, Dateien, HTTP) sowie Serverimplementierungen vom einfachen bis zum Thread-Pool-Modell. Thrift unterstützt grundlegende und zusammengesetzte Typen, Container (Listen, Mengen, Maps), Ausnahmen und einseitige (oneway) Methodenaufrufe.

Verwendung

Thrift wird in großen verteilten Systemen eingesetzt, in denen viele Dienste effizient und sprachübergreifend miteinander kommunizieren müssen, etwa bei Facebook, Twitter (in Teilen), Evernote und als Zugangsschicht zu HBase und Cassandra. Verwandte Systeme sind Googles Protocol Buffers mit gRPC und Apache Avro.
