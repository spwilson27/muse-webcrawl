Feldemission

Als Feldemission (englisch field emission) bezeichnet man in der Physik ganz allgemein die Emission von Teilchen aus einem Festkörper oder einer Flüssigkeit unter dem Einfluss eines starken elektrischen Feldes. Am bekanntesten ist die Feldemission von Elektronen, daneben existiert die Feldemission von Ionen.

Formen

  • Feldelektronenemission: Elektronen tunneln aus einer Metalloberfläche in ein starkes elektrisches Feld. Sie ist Grundlage von Kaltkathoden, Elektronenquellen in der Mikroskopie und von Feldemissionsdisplays. (Hauptartikel: Feldelektronenemission)
  • Feldionenemission: Ionen werden von einer Oberfläche abgelöst beziehungsweise an einer scharfen Spitze durch Feldionisation erzeugt. Sie wird im Feldionenmikroskop genutzt, mit dem Erwin Wilhelm Müller 1951 erstmals einzelne Atome abbildete.
  • Felddesorption: Adsorbierte Moleküle werden durch ein elektrisches Feld von einer Oberfläche gelöst; als Ionisationsmethode wird sie in der Massenspektrometrie eingesetzt.

Grundlagen

Allen Formen gemeinsam ist, dass ein starkes elektrisches Feld (etwa 10⁷ bis 10¹⁰ V/m) die Potenzialbarriere an der Oberfläche so weit erniedrigt und verschmälert, dass Teilchen diese klassisch oder durch den Tunneleffekt überwinden können. Die nötigen Feldstärken werden bevorzugt an feinen Spitzen und Kanten erreicht.
