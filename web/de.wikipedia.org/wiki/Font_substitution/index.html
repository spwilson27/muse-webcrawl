Schriftersetzung

Schriftersetzung (englisch font substitution) bezeichnet die Technik, bei der ein Computerprogramm für die Darstellung von Text eine ähnliche Schriftart einsetzt, wenn die ursprünglich angeforderte Schrift auf dem System nicht installiert ist oder die erforderlichen Zeichen nicht enthält.

Anwendungsbereiche

Schriftersetzung tritt auf, wenn Dokumente auf einem anderen Gerät geöffnet werden als dem von Autor vorgesehenen, wenn Betriebssysteme fallweise Standardschriften wie Arial oder Times New Roman ersetzen, oder wenn ein Font für eine bestimmte Sprache oder ein Schriftsystem fehlt. Im Webbrowser steuert die CSS-Eigenschaft font-family eine Ersetzungsreihenfolge („font stack“), bis eine verfügbare Schrift gefunden wird.

Folgen

Da Ersatzschriften meist andere Laufweiten und Metriken besitzen als das Original, kann sich das Layout verschieben und das typografische Erscheinungsbild verändern. Moderne Ersetzungstabellen, z. B. die fontconfig-Bibliothek unter Linux oder die Ersetzungslisten von Microsoft Office, versuchen, optisch und metrisch möglichst ähnliche Alternativen zu wählen, etwa Liberation Sans als metrische Kopie von Arial.
