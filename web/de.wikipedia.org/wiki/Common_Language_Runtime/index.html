Common Language Runtime

Die Common Language Runtime (CLR) ist die Laufzeitumgebung des .NET-Frameworks von Microsoft und die Implementierung des Virtual Execution System der Common Language Infrastructure. Sie führt Programme aus, die in der Zwischensprache Common Intermediate Language (CIL) vorliegen.

Aufgaben

Die CLR übernimmt unter anderem das Laden von Assemblys, die Prüfung der Typsicherheit, die Just-in-Time-Kompilierung des CIL-Codes in nativen Maschinencode, die automatische Speicherbereinigung (Garbage Collection), die Ausnahmebehandlung sowie Sicherheits- und Threading-Dienste. Dadurch können Programme verschiedener .NET-Sprachen wie C#, Visual Basic .NET und F# nahtlos zusammenarbeiten.

Entwicklung

Die erste Version erschien 2002 mit dem .NET Framework 1.0. Mit .NET Core wurde eine plattformübergreifende, quelloffene Weiterentwicklung unter dem Namen CoreCLR geschaffen, die heute die Laufzeit des einheitlichen .NET bildet.
