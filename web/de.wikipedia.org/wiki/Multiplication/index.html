Multiplikation

Die Multiplikation (von lateinisch multiplicatio „Vervielfachung“) ist eine der vier Grundrechenarten in der Arithmetik. Von diesen ist sie die dritte, die als Umkehrung der Division fungiert. Die Multiplikation natürlicher Zahlen entsteht durch das wiederholte Addieren (Zusammenzählen) des gleichen Summanden:

a · b = b + b + … + b (a-mal)

Beispielsweise ist 3 · 4 = 4 + 4 + 4 = 12. Die Operanden werden als Faktoren bezeichnet (erster Faktor auch Multiplikand, zweiter auch Multiplikator), das Ergebnis heißt Produkt. Als Rechenzeichen dient der Malpunkt (·) oder das Malkreuz (×).

Gesetze

Für die Multiplikation gelten das Kommutativgesetz (a · b = b · a), das Assoziativgesetz ((a · b) · c = a · (b · c)) und zusammen mit der Addition das Distributivgesetz (a · (b + c) = a · b + a · c). Das neutrale Element der Multiplikation ist die 1, das absorbierende Element die 0.

Schriftliches Multiplizieren

Das schriftliche Multiplizieren ist ein Verfahren, mit dem man größere Zahlen mit Papier und Bleistift multiplizieren kann, indem man die Stellenwerte einzeln multipliziert und die Teilergebnisse addiert. Grundlage ist das kleine Einmaleins. Algorithmen zur schnellen Multiplikation sehr großer Zahlen, etwa der Karazuba-Algorithmus oder die auf der schnellen Fourier-Transformation beruhende Schönhage-Strassen-Methode, sind Gegenstand der algorithmischen Zahlentheorie.

Verallgemeinerungen

Der Begriff der Multiplikation wird in der Mathematik auf viele weitere Objekte verallgemeinert, etwa auf Brüche, reelle und komplexe Zahlen, Matrizen, Vektoren (Skalarprodukt, Kreuzprodukt) und Funktionen.
