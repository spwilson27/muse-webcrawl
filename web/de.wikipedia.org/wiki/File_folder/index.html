Verzeichnis (Computer)

Ein Verzeichnis (englisch folder oder directory) ist in der Datenverarbeitung eine Organisationsstruktur eines Dateisystems, die Dateien und weitere Verzeichnisse (Unterverzeichnisse) enthält und so eine hierarchische Gliederung der gespeicherten Daten ermöglicht. In grafischen Benutzeroberflächen wird das Verzeichnis meist durch ein Ordnersymbol dargestellt, weshalb sich der Begriff Ordner eingebürgert hat.

Hierarchie

Verzeichnisse bilden eine Baumstruktur, die im Wurzelverzeichnis (englisch root directory) beginnt. Unter Unix-artigen Systemen wird das Wurzelverzeichnis mit einem Schrägstrich (/) bezeichnet, unter Windows erhält jedes Laufwerk einen eigenen Buchstaben, etwa C:\. Ein Pfad beschreibt die Lage einer Datei innerhalb dieser Hierarchie, absolut ausgehend von der Wurzel oder relativ zum aktuellen Arbeitsverzeichnis.

Metapher

Die Ordner-Metapher stammt aus der Büroorganisation: Wie Aktenordner Dokumente aufnehmen, fassen Verzeichnisse Dateien zusammen. Mit der Einführung grafischer Oberflächen wie dem Macintosh Finder (1984) und später dem Windows Explorer wurde das Ordnersymbol zum Standard.

Besondere Verzeichnisse

Unter Unix-Systemen sind unter anderem das Heimatverzeichnis des Benutzers (~), das Verzeichnis /etc für Konfigurationsdateien und /tmp für temporäre Dateien üblich. Die Einträge . und .. verweisen auf das Verzeichnis selbst beziehungsweise auf das übergeordnete Verzeichnis.
