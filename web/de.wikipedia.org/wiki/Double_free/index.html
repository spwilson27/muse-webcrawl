Double Free

Als Double Free (deutsch etwa „doppelte Freigabe“) bezeichnet man einen Programmierfehler in Sprachen mit manueller Speicherverwaltung wie C oder C++, bei dem ein bereits freigegebener Speicherbereich erneut mit free() beziehungsweise delete freigegeben wird.

Folgen

Ein Double Free führt zu undefiniertem Verhalten. Die Speicherverwaltung kann dadurch korrumpiert werden, sodass derselbe Speicherblock später zweimal vergeben wird; zwei scheinbar unabhängige Zeiger verweisen dann auf denselben Bereich. Das Programm kann abstürzen, Daten können unbemerkt überschrieben werden, und Angreifer können die Schwachstelle unter Umständen zur Ausführung beliebigen Codes ausnutzen. Im Common Weakness Enumeration System ist der Fehler als CWE-415 katalogisiert.

Vermeidung

  • Zeiger nach der Freigabe auf NULL setzen – ein erneutes free(NULL) ist wirkungslos definiert.
  • Eindeutige Besitzverhältnisse (Ownership) festlegen, sodass nur eine Stelle für die Freigabe zuständig ist.
  • In C++ Smart Pointer wie std::unique_ptr verwenden; in Rust verhindert das Ownership-System den Fehler bereits zur Kompilierzeit.
  • Analysewerkzeuge wie Valgrind oder AddressSanitizer einsetzen, die doppelte Freigaben zur Laufzeit erkennen.

Verwandte Fehler

Eng verwandt sind der Zugriff auf bereits freigegebenen Speicher (Use-After-Free), Speicherlecks und der doppelte Freigabeversuch über zwei Zeiger auf denselben Block (Dangling Pointer).
