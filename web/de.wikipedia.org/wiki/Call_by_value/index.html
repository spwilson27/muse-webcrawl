Call by Value

Call by Value (deutsch „Übergabe per Wert“, auch Wertübergabe) ist der in den meisten Programmiersprachen übliche Parameterübergabemechanismus: Beim Aufruf einer Funktion wird der Wert des Arguments ausgewertet und eine Kopie dieses Wertes an den Parameter übergeben. Änderungen am Parameter wirken sich nicht auf die Variable des Aufrufers aus.

Beschreibung

Call by Value ist einfach zu verstehen und schützt die Daten des Aufrufers vor unbeabsichtigten Seiteneffekten. Ein Nachteil besteht darin, dass die Auswertung des Arguments immer erfolgt – auch wenn die Funktion den Parameter gar nicht benutzt – und dass das Kopieren großer Datenstrukturen kostspielig sein kann.

Abgrenzung

In Sprachen wie Java oder Python wird Call by Value auch auf Objekte angewandt: Übergeben wird eine Kopie des Werts, der bei Objekten selbst eine Referenz ist. Daher können Methoden den Inhalt eines übergebenen Objekts verändern, nicht aber die Variable des Aufrufers auf ein anderes Objekt umbiegen. Streng zu unterscheiden ist Call by Value von Call by Reference und von Call by Name, der Auswertungsstrategie mit verzögerter, wiederholter Auswertung des Arguments.
