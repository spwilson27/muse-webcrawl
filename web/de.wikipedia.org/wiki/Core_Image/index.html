Core Image

Core Image ist eine Bildverarbeitungs- und Analyse-Technologie von Apple für macOS und iOS. Sie wurde 2005 mit Mac OS X Tiger vorgestellt und ermöglicht die nicht-destructive Anwendung von Bildfiltern und Effekten in Echtzeit, beschleunigt durch Grafikprozessor oder CPU.

Funktionsweise

Core Image arbeitet mit Filterketten: Ein Bild durchläuft nacheinander mehrere Filtereinheiten (etwa Weichzeichner, Farbkorrekturen oder Verzerrungen), ohne dass das Ausgangsmaterial verändert wird. Eigene Filter können als sogenannte Kernel in einer speziellen Shader-Sprache formuliert werden. Die Verarbeitung erfolgt möglichst auf der GPU; steht keine geeignete Grafikhardware zur Verfügung, übernimmt ein Software-Renderer.

Anwendung

Core Image wird in zahlreichen Apple-Programmen eingesetzt, unter anderem für die Effekte in Fotos, iMovie und Photo Booth. Es umfasst mehrere hundert eingebaute Filter sowie Funktionen zur Gesichts- und Merkmalserkennung.
