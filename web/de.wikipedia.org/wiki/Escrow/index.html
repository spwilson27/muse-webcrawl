Escrow

Escrow ist ein aus dem angloamerikanischen Recht stammender Begriff für ein Treuhandverfahren: Eine neutrale dritte Partei (der escrow agent) verwahrt Geld, Dokumente oder andere Vermögenswerte, bis die in einer Vereinbarung festgelegten Bedingungen erfüllt sind, und gibt sie dann an den Berechtigten heraus. Die hinterlegten Gegenstände werden als „in escrow" bezeichnet.

Anwendungsbereiche

Am verbreitetsten ist Escrow im US-amerikanischen Immobilienverkehr: Bis zum Abschluss des Kaufvertrags (Closing) verwahrt ein Treuhänder Anzahlung, Urkunden und weitere Unterlagen. Auch bei Hypotheken sind Escrow-Konten üblich, über die der Kreditgeber Steuern und Versicherungsprämien für den Eigentümer bezahlt. Im Internethandel bieten Treuhanddienste Schutz, indem der Kaufpreis erst nach ordnungsgemäßem Warenerhalt an den Verkäufer ausgezahlt wird.

Source Code Escrow

In der Softwarebranche bezeichnet source code escrow die Hinterlegung des Quellcodes einer Software bei einem Treuhänder. Geht der Hersteller etwa insolvent oder stellt er den Support ein, erhält der Lizenznehmer Zugriff auf den Quellcode und kann die Software weiter pflegen.
