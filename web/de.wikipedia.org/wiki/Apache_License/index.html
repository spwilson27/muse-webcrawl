Apache-Lizenz

Apache-Lizenz
Herausgeber: Apache Software Foundation
Aktuelle Version: 2.0 (2004)
Art: Freizügige (permissive) Freie-Software-Lizenz

Die Apache-Lizenz (englisch Apache License) ist eine freizügige Lizenz für freie Software, die von der Apache Software Foundation (ASF) herausgegeben wird. Sie erlaubt Nutzung, Veränderung und Weitergabe der Software – auch in proprietären und kommerziellen Produkten – und zählt zu den am weitesten verbreiteten Open-Source-Lizenzen.

Inhalt der Version 2.0

Die im Januar 2004 veröffentlichte Version 2.0 räumt jedem Nutzer ein weltweites, gebührenfreies und unwiderrufliches Urheberrechts- und – ausdrücklich – auch Patentlizenzrecht ein. Bedingungen sind im Wesentlichen:

  • Der Lizenztext und die Urheberrechtshinweise müssen bei Weitergabe erhalten bleiben.
  • Wesentliche Änderungen an Dateien sind zu kennzeichnen.
  • Eine mitgelieferte NOTICE-Datei mit Namensnennungen muss in abgeleiteten Werken weitergegeben werden.
  • Markenrechte (etwa an Projektnamen) werden nicht eingeräumt.

Die Lizenz enthält einen Gewährleistungsausschluss und eine Haftungsbeschränkung. Eine besondere Klausel regelt Patentstreitigkeiten: Wer wegen der Software eine Patentklage erhebt, verliert seine Patentlizenz an dem Werk. Die Apache-Lizenz 2.0 ist einseitig mit der GNU GPL in Version 3 kompatibel (Apache-Code darf in GPLv3-Projekte übernommen werden), nicht jedoch mit der GPLv2. Von Vorgängerversionen ist vor allem die Version 1.1 (2000) von Bedeutung.

Verbreitung

Neben allen Projekten der Apache Software Foundation wird die Lizenz unter anderem für das Android-Betriebssystem (Nutzerebene), die Programmiersprache Swift, Kubernetes und TensorFlow verwendet.
