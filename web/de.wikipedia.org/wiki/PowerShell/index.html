PowerShell

PowerShell ist ein plattformübergreifendes Framework zur Automatisierung und Konfiguration von Microsoft, das aus einer Kommandozeilen-Shell und einer Skriptsprache besteht. Es wurde ursprünglich 2006 als „Windows PowerShell“ veröffentlicht; seit 2016 ist die plattformübergreifende Weiterentwicklung als Open Source verfügbar und läuft unter Windows, macOS und Linux.

Eigenschaften

Im Gegensatz zu klassischen Shells, die Text verarbeiten, übergibt PowerShell .NET-Objekte zwischen den Befehlen einer Pipeline. Befehle heißen Cmdlets und folgen dem Benennungsschema Verb-Substantiv, etwa Get-Process oder Set-Location. PowerShell umfasst über 100 mitgelieferte Cmdlets, ein Modulsystem sowie Zugriff auf WMI, die Registry und das .NET-Framework.

Verwendung

PowerShell wird vor allem von Systemadministratoren zur Automatisierung von Server- und Arbeitsplatzverwaltung, im Active Directory, in Microsoft Azure und bei der Softwareverteilung eingesetzt. Skripte werden als .ps1-Dateien gespeichert; aus Sicherheitsgründen steuert eine Ausführungsrichtlinie (Execution Policy), welche Skripte ausgeführt werden dürfen.
