Reduktion (Komplexitätstheorie)

Eine Reduktion ist in der theoretischen Informatik und Komplexitätstheorie ein Verfahren, ein Problem auf ein anderes zurückzuführen. Kann ein Problem A mithilfe eines Lösungsverfahrens für ein Problem B gelöst werden, indem Eingaben von A in Eingaben von B umgewandelt werden, so sagt man, A sei auf B reduzierbar. Reduktionen dienen dazu, die relative Schwierigkeit von Problemen zu vergleichen und Vollständigkeit für Komplexitätsklassen nachzuweisen.

Arten von Reduktionen

Bei der Turing-Reduktion darf das Verfahren für B mehrfach als Orakel aufgerufen werden. Die restriktivere Karp-Reduktion (Polynomialzeit-Reduktion, Many-one-Reduktion) verlangt eine einzige in Polynomialzeit berechenbare Übersetzung der Eingabe, bei der die Antwort erhalten bleibt. Weitere Formen sind die Logspace-Reduktion und die Truth-Table-Reduktion.

NP-Vollständigkeit

Zentrales Anwendungsgebiet ist der Nachweis der NP-Vollständigkeit: Stephen Cook zeigte 1971, dass jedes Problem in NP auf das Erfüllbarkeitsproblem der Aussagenlogik (SAT) reduziert werden kann. Richard Karp stellte 1972 eine Liste von 21 NP-vollständigen Problemen zusammen, die über Reduktionsketten auseinander hervorgingen. Ist ein Problem NP-schwer und selbst in NP, so heißt es NP-vollständig; für alle diese Probleme gilt: Gäbe es für eines einen Polynomialzeit-Algorithmus, so wäre P = NP.
