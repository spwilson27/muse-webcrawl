Die Foot-candle (Einheitenzeichen fc, deutsch etwa „Fuß-Kerze“) ist eine in den Vereinigten Staaten gebräuchliche Einheit der Beleuchtungsstärke. Sie gibt an, wie viel Licht auf eine Fläche fällt: Eine Foot-candle entspricht der Beleuchtungsstärke, die eine Lichtquelle von einer Candela Stärke auf einer Fläche im Abstand von einem Fuß (30,48 cm) erzeugt.

Umrechnung

1 Foot-candle entspricht einem Lumen pro Quadratfuß beziehungsweise exakt 10,7639 Lux, der SI-Einheit der Beleuchtungsstärke. Umgekehrt gilt: 1 Lux ≈ 0,0929 fc.

Anwendungsbereiche

Die Einheit wird in der amerikanischen Beleuchtungsplanung, in Baunormen und in der Film- und Fototechnik verwendet, wo Kameraleute die Lichtstärke am Set traditionell in Foot-candles messen. Typische Richtwerte sind etwa 10–20 fc für Wohnräume, 30–50 fc für Büros und Klassenzimmer sowie rund 100 fc für feine Montage- und Inspektionsarbeiten. Ein sonniger Tag im Freien erreicht dagegen etwa 10.000 fc.

Geschichte

Der Name geht auf die Zeit zurück, in der Kerzen als Referenzlichtquellen dienten: Die Helligkeit einer genormten Kerze in einem Fuß Entfernung diente als praktische Bezugsgröße, bevor elektrische Beleuchtung und das metrische System die Photometrie vereinheitlichten.
