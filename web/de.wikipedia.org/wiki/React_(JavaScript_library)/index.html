React

React
Erstveröffentlichung: 2013
Entwickler: Meta (Facebook)
Programmiersprache: JavaScript
Lizenz: MIT

React ist eine freie JavaScript-Bibliothek zur Erstellung von Benutzeroberflächen, insbesondere für Single-Page-Webanwendungen. Sie wurde von Facebook (heute Meta) entwickelt und 2013 als Open Source veröffentlicht.

Konzept

React folgt einem komponentenbasierten Ansatz: Die Oberfläche wird aus wiederverwendbaren Komponenten zusammengesetzt, die ihren eigenen Zustand verwalten können. Änderungen werden zunächst auf ein virtuelles DOM angewendet; React gleicht dieses mit dem realen DOM ab und aktualisiert nur die tatsächlich geänderten Teile. Die Syntaxerweiterung JSX erlaubt es, HTML-ähnliche Strukturen direkt im JavaScript-Code zu schreiben. Mit Hooks, eingeführt in Version 16.8, lassen sich Zustand und Nebeneffekte auch in Funktionskomponenten nutzen.

Ökosystem

Auf React bauen zahlreiche Werkzeuge und Frameworks auf, darunter React Native für mobile Apps, Next.js und Remix für serverseitiges Rendering sowie umfangreiche Komponentenbibliotheken. React gehört zu den weltweit am häufigsten verwendeten Webtechnologien.
