Wurzel (Mathematik)

Die n-te Wurzel einer Zahl ist in der Mathematik die Umkehrung des Potenzierens mit dem Exponenten n. Für eine natürliche Zahl n ≥ 1 und eine nichtnegative reelle Zahl a ist die n-te Wurzel aus a, geschrieben n√a, diejenige nichtnegative reelle Zahl x, für die xn = a gilt.

Definition und Schreibweise

Die Zahl unter dem Wurzelzeichen heißt Radikand, die Zahl n Wurzelexponent. Für n = 2 spricht man von der Quadratwurzel (das Voranstellen des Exponenten wird dann meist weggelassen), für n = 3 von der Kubikwurzel. Es gilt n√a = a1/n, wodurch die Wurzel als Potenz mit gebrochenem Exponenten aufgefasst werden kann.

Eigenschaften

Für positive Radikanden gelten die Wurzelgesetze: n√(a·b) = n√a · n√b und n√(m√a) = nm√a. Wurzeln geraden Grades sind nur für nichtnegative Radikanden reell definiert; Wurzeln ungeraden Grades existieren auch für negative Zahlen. Im Komplexen besitzt jede Zahl ungleich null genau n verschiedene n-te Wurzeln, die sogenannten Einheitswurzeln spielen dabei eine besondere Rolle.

Berechnung

Zur numerischen Berechnung dienen unter anderem das Newton-Verfahren und das schriftliche Wurzelziehen. Schon in der Antike waren Näherungsverfahren für Quadratwurzeln bekannt (Heron-Verfahren).
