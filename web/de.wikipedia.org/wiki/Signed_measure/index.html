Signiertes Maß


Hahn-Zerlegung eines signierten Maßes

In der Maßtheorie ist ein signiertes Maß (englisch signed measure) eine Verallgemeinerung des Maßbegriffs, bei der den messbaren Mengen auch negative (und im Falle komplexer signierter Maße auch komplexe) Werte zugeordnet werden können. Signierte Maße treten beispielsweise in der Wahrscheinlichkeitstheorie, in der Integrationstheorie und in der mathematischen Finanzmathematik auf.

Definition

Es sei (X, 𝒜) ein messbarer Raum. Eine Funktion μ: 𝒜 → ℝ heißt signiertes Maß, wenn μ(∅) = 0 gilt und μ σ-additiv ist, das heißt, für jede Folge paarweise disjunkter messbarer Mengen An gilt μ(⋃ An) = Σ μ(An), wobei die Reihe absolut konvergiert. Ein signiertes Maß darf die Werte +∞ und −∞ nicht gleichzeitig annehmen.

Hahn-Zerlegung

Ein zentrales Ergebnis ist der Zerlegungssatz von Hahn: Jede messbare Menge X lässt sich in zwei disjunkte messbare Mengen P und N zerlegen, sodass μ auf allen messbaren Teilmengen von P nichtnegativ und auf allen messbaren Teilmengen von N nichtpositiv ist.

Jordan-Zerlegung

Aus der Hahn-Zerlegung folgt die Jordan-Zerlegung: Jedes signierte Maß μ lässt sich als Differenz μ = μ+ − μ− zweier (gewöhnlicher, nichtnegativer) Maße darstellen, wobei mindestens eines von beiden endlich ist. Das Maß |μ| = μ+ + μ− heißt Variationsmaß von μ. Ein signiertes Maß ist genau dann endlich, wenn sein Variationsmaß endlich ist.

Beispiele

Das klassische Beispiel ist das Integral einer integrierbaren Funktion f bezüglich eines Maßes ν: Die Abbildung A ↦ ∫A f dν ist ein signiertes Maß. Die Differenz zweier Wahrscheinlichkeitsmaße ist ebenfalls ein signiertes Maß.
