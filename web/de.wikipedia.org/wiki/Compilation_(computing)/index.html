Compilation (Informatik)

Compilation (deutsch etwa „Übersetzung“, „Zusammenstellung“) bezeichnet in der Informatik den Vorgang, bei dem ein in einer Quellsprache verfasstes Programm durch einen Compiler in eine Zielsprache übersetzt wird. Üblicherweise ist die Quellsprache eine höhere Programmiersprache wie C, C++ oder Rust, während die Zielsprache Maschinencode oder Zwischencode (Bytecode) ist.

Ablauf

Die Compilation erfolgt in mehreren Phasen. Zunächst zerlegt die lexikalische Analyse den Quelltext in Token. Die syntaktische Analyse (Parsing) baut daraus einen abstrakten Syntaxbaum. Anschließend prüft die semantische Analyse unter anderem Typkorrektheit und Namensauflösung. Danach wird Zwischencode erzeugt, optimiert und schließlich in die Zielsprache überführt.

Abgrenzung zur Interpretation

Im Gegensatz zur Interpretation, bei der ein Programm zur Laufzeit Anweisung für Anweisung ausgeführt wird, geschieht die Compilation vor der Ausführung. Das erzeugte Programm kann danach ohne den Compiler ausgeführt werden und ist in der Regel deutlich schneller. Moderne Laufzeitumgebungen kombinieren beide Verfahren, etwa durch Just-in-time-Kompilierung (JIT).

Arten der Compilation

  • Ahead-of-time-Compilation (AOT): Übersetzung vollständig vor der Ausführung.
  • Just-in-time-Compilation (JIT): Übersetzung einzelner Programmteile erst zur Laufzeit, etwa in der Java Virtual Machine oder in .NET.
  • Cross-Compilation: Der Zielrechner unterscheidet sich vom Rechner, auf dem der Compiler läuft, etwa bei der Entwicklung für eingebettete Systeme.
  • Transpilation: Übersetzung in eine andere Hochsprache, beispielsweise von TypeScript nach JavaScript.
