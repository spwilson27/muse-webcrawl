Apache Maven
Entwickler: Apache Software Foundation
Programmiersprache: Java
Kategorie: Build-Werkzeug
Lizenz: Apache License 2.0

Apache Maven ist ein Werkzeug zur Build-Automatisierung und zum Projektmanagement für Java-Projekte der Apache Software Foundation. Der Name Maven stammt aus dem Jiddischen und bedeutet etwa „Sammler von Wissen". Maven wurde ab 2002 von Jason van Zyl entwickelt, zunächst im Umfeld des Turbine-Projekts, und 2003 ein eigenständiges Apache-Projekt.

Konzept

Im Mittelpunkt steht die Projektbeschreibung in der Datei pom.xml (Project Object Model). Darin werden Projektkoordinaten (groupId, artifactId, version), die Abhängigkeiten zu Bibliotheken, Plugins und der Build-Ablauf deklariert. Maven folgt dem Prinzip „Konvention vor Konfiguration": Es gibt eine genormte Verzeichnisstruktur (src/main/java, src/test/java usw.) und einen festen Build-Lebenszyklus mit Phasen wie compile, test, package, install und deploy; einzelne Phasen werden über Plugin-Ziele bedient.

Abhängigkeiten löst Maven automatisch aus Repositorys auf – in erster Linie aus dem zentralen Maven Central –, lädt sie in ein lokales Repository und berücksichtigt dabei auch transitive Abhängigkeiten. Damit übernahm Maven eine Aufgabe, die Apache Ant ursprünglich nicht abdeckte. Maven unterstützt mehrmodulige Projekte, Berichte (etwa Testabdeckung und Projektdokumentation) und wird von allen gängigen Java-Entwicklungsumgebungen integriert.
