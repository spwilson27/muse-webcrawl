Programmzeiger
Englisch: Program Counter (PC)

Alternativnamen:
Befehlszeiger
Instruktionszeiger

Typ:
Prozessorregister

Der Programmzeiger (englisch program counter, abgekürzt PC, auch Befehlszeiger oder Instruktionszeiger, englisch instruction pointer) ist ein spezielles Register eines Prozessors, das die Speicheradresse des nächsten auszuführenden Befehls enthält. Er ist ein zentrales Element der Von-Neumann-Architektur.

Funktionsweise

Nach dem Abrufen (Fetch) eines Befehls wird der Programmzeiger in der Regel um die Länge des Befehls erhöht, sodass er auf den nächsten Befehl zeigt. Sprung- und Verzweigungsbefehle können den Programmzeiger dagegen direkt auf eine andere Adresse setzen und damit den Programmablauf ändern. Unterprogramme, Funktionsaufrufe und Interrupts speichern den aktuellen Programmzeiger, um später an die richtige Stelle zurückkehren zu können — meist auf einem Stack.

Historisches

Das Konzept eines Registers, das auf den nächsten Befehl zeigt, geht auf die frühen Computerarchitekturen der 1940er und 1950er Jahre zurück, insbesondere auf die von John von Neumann beschriebene Architektur. Moderne Prozessoren besitzen einen oder mehrere Programmzeiger, etwa in superskalaren und mehrkernigen Designs.

Sicherheitsaspekte

Die Kontrolle über den Programmzeiger ist ein zentrales Ziel von Sicherheitsangriffen wie Pufferüberläufen und Return-oriented Programming, bei denen ein Angreifer den Programmzeiger auf eigenen Code oder auf vorhandene Codefragmente umlenkt.
