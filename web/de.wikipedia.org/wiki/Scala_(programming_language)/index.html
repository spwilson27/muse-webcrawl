Scala (Programmiersprache)

Scala ist eine statisch typisierte Programmiersprache, die objektorientierte und funktionale Programmierung verbindet. Der Name steht für „scalable language" (skalierbare Sprache) und verweist auf den Anspruch, mit den Anforderungen der Anwender zu wachsen – von kleinen Skripten bis zu großen, verteilten Systemen. Scala läuft vor allem auf der Java Virtual Machine (JVM) und ist vollständig mit Java interoperabel.

Geschichte

Scala wurde ab 2001 an der École polytechnique fédérale de Lausanne (EPFL) unter der Leitung von Martin Odersky entwickelt und 2004 öffentlich veröffentlicht. Odersky hatte zuvor unter anderem am Java-Compiler und an den Java Generics mitgearbeitet. 2011 wurde die Firma Typesafe (später Lightbend) gegründet, um Scala kommerziell zu unterstützen. Mit Scala 3 („Dotty", veröffentlicht 2021) erhielt die Sprache eine überarbeitete Syntax und ein vereinfachtes Typsystem.

Merkmale

Scala vereint Klassen- und Trait-basierte Objektorientierung mit Funktionen höherer Ordnung, Pattern Matching, unveränderlichen Datenstrukturen und einem ausdrucksstarken Typsystem mit Typinferenz. Bekannte Frameworks und Bibliotheken sind das Web-Framework Play, das Stream- und Aktorensystem Akka sowie Apache Spark, das in der Datenverarbeitung verbreitet ist. Als Build-Werkzeug wird meist sbt verwendet.
