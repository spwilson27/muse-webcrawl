Internet Message Access Protocol

Das Internet Message Access Protocol (IMAP) ist ein Netzwerkprotokoll für den Zugriff auf E-Mails, die auf einem Mailserver gespeichert sind. Es wurde ursprünglich 1986 von Mark Crispin entwickelt; die heute verbreitete Grundlage ist IMAP4rev1 (RFC 3501, ergänzt durch IMAP4rev2).

Funktionsweise

Anders als beim älteren POP3 verbleiben die Nachrichten bei IMAP auf dem Server und werden nur zur Anzeige übertragen. Dadurch können mehrere Geräte denselben Posteingang mit Ordnern, Gelesen-Status und Markierungen synchron nutzen. IMAP arbeitet standardmäßig über Port 143, verschlüsselt (IMAPS) über Port 993.

Erweiterungen

Zahlreiche Erweiterungen ergänzen unter anderem serverseitige Suche und Sortierung, Push-Benachrichtigungen (IDLE), Kompression und spezielle Unterstützung für mobile Geräte. IMAP bildet zusammen mit SMTP zum Versand die Grundlage nahezu aller modernen E-Mail-Dienste.
