ASP.NET

ASP.NET ist ein serverseitiges Webframework von Microsoft zur Erstellung dynamischer Webseiten, Webanwendungen und Webdienste. Es ist der Nachfolger von Active Server Pages (ASP) und Teil des .NET-Frameworks beziehungsweise der modernen, plattformübergreifenden .NET-Plattform. Anwendungen werden typischerweise in C# oder Visual Basic geschrieben.

Geschichte

ASP.NET wurde im Januar 2002 zusammen mit der ersten Version des .NET Frameworks veröffentlicht. Die Entwicklung lief zuvor unter dem Codenamen „ASP+“. Im Gegensatz zum klassischen ASP werden ASP.NET-Seiten kompiliert statt interpretiert, was die Ausführung beschleunigt. 2016 erschien mit ASP.NET Core eine von Grund auf neu entwickelte, quelloffene und plattformübergreifende Variante.

Programmiermodelle

  • Web Forms: ereignisgesteuertes Modell mit serverseitigen Steuerelementen (nur klassisches ASP.NET)
  • ASP.NET MVC: Umsetzung des Model-View-Controller-Musters
  • Web API: Erstellung von HTTP-Diensten und REST-Schnittstellen
  • Razor Pages: seitenorientiertes Modell in ASP.NET Core
  • Blazor: interaktive Weboberflächen mit C# statt JavaScript, auch per WebAssembly im Browser

Technik

ASP.NET-Anwendungen laufen klassisch auf den Internet Information Services (IIS) unter Windows. ASP.NET Core nutzt den eingebetteten Webserver Kestrel und kann auf Windows, Linux und macOS betrieben werden. Seiten werden meist mit der Razor-Syntax beschrieben, die HTML mit C#-Code verbindet.
