Neovim

Neovim ist ein freier, quelloffener Texteditor, der 2014 als Fork des Editors Vim entstanden ist. Ziel des Projekts ist es, die Erweiterbarkeit und Wartbarkeit von Vim zu verbessern, ohne dessen modalen Bedienungsansatz und die Kompatibilität zur Skriptsprache Vimscript grundlegend aufzugeben. Neovim steht unter der Apache-Lizenz 2.0 sowie Teilen unter der Vim-Lizenz.

Geschichte

Das Projekt wurde 2014 von Thiago de Arruda initiiert und erfolgreich über eine Crowdfunding-Kampagne finanziert. Auslöser war die schwierige Erweiterbarkeit des Vim-Kerns, insbesondere das Fehlen asynchroner Jobsteuerung und eines eingebetteten Terminals. Neovim modernisierte die Codebasis, entfernte Unterstützung für veraltete Systeme und führte eine auf MessagePack-RPC basierende API ein, über die sich der Editor aus beliebigen Programmiersprachen fernsteuern lässt.

Eigenschaften

Neovim enthält eine eingebaute Unterstützung der Skriptsprache Lua, mit der sich Konfigurationen und Plugins deutlich schneller und übersichtlicher schreiben lassen als mit Vimscript. Weitere Merkmale sind ein eingebauter Terminal-Emulator, asynchrone I/O, ein integrierter Client für das Language Server Protocol (LSP) sowie Unterstützung moderner Terminalfunktionen wie 24-Bit-Farben. Zahlreiche grafische Oberflächen und Editor-Einbettungen bauen auf der RPC-Schnittstelle auf.

Verbreitung

Neovim ist für Linux, macOS, Windows und weitere Unix-artige Systeme verfügbar und erfreut sich insbesondere bei Softwareentwicklern großer Beliebtheit. Ein umfangreiches Ökosystem von Lua-Plugins hat sich um den Editor gebildet.
