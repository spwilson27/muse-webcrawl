Blazor

Blazor ist ein freies, quelloffenes Webframework von Microsoft, mit dem interaktive Webanwendungen in C# und .NET anstelle von JavaScript entwickelt werden können. Der Name ist ein Kofferwort aus „Browser“ und der .NET-Vorlagensprache „Razor“.

Ausführungsmodelle

Blazor kennt zwei Hauptausführungsmodelle: Bei Blazor Server läuft die Anwendung auf dem Server, und die Benutzeroberfläche wird über eine SignalR-Verbindung mit dem Browser synchronisiert. Bei Blazor WebAssembly wird eine .NET-Laufzeitumgebung zusammen mit dem kompilierten Code per WebAssembly direkt im Browser ausgeführt, sodass die Anwendung auch offline funktionieren kann. Seit .NET 8 lassen sich beide Modelle in einer Anwendung mischen („Blazor Web App“ mit interaktiven Server- und WebAssembly-Komponenten).

Aufbau

Die Oberfläche wird aus wiederverwendbaren Komponenten aufgebaut, die in Razor-Dateien Markup und C#-Logik verbinden. Blazor ist Teil von ASP.NET Core und erschien erstmals 2019 (Blazor Server mit .NET Core 3.0) beziehungsweise 2020 (Blazor WebAssembly). Mit .NET MAUI lassen sich Blazor-Komponenten auch in hybriden Desktop- und Mobilanwendungen einsetzen.
