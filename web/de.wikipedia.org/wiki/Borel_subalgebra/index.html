Borel-Unteralgebra

Eine Borel-Unteralgebra ist in der Mathematik eine maximal auflösbare Unteralgebra einer halbeinfachen Lie-Algebra. Sie ist nach dem schweizerischen Mathematiker Armand Borel benannt, der sie im Zusammenhang mit der Theorie der algebraischen Gruppen untersuchte.

Definition

Sei 𝔤 eine endlichdimensionale halbeinfache Lie-Algebra über einem algebraisch abgeschlossenen Körper der Charakteristik null. Eine Unteralgebra 𝔟 ⊂ 𝔤 heißt Borel-Unteralgebra, wenn sie maximal unter den auflösbaren Unteralgebren von 𝔤 ist.

Eigenschaften

Alle Borel-Unteralgebren einer halbeinfachen Lie-Algebra sind zueinander konjugiert, d. h. durch Automorphismen der Lie-Algebra ineinander überführbar. Beispiele sind die Algebren der oberen Dreiecksmatrizen in 𝔰𝔩(n). Jede Borel-Unteralgebra enthält eine Cartan-Unteralgebra, und aus der Wahl einer Borel-Unteralgebra ergibt sich eine Zerlegung der Lie-Algebra, die zur Klassifikation der Darstellungen verwendet wird.
