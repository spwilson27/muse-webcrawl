Active Directory

Active Directory (AD) ist der Verzeichnisdienst von Microsoft für Windows-Netzwerke. Er wurde mit Windows 2000 eingeführt und dient der zentralen Verwaltung von Benutzern, Computern, Gruppen und anderen Ressourcen einer Organisation. Die Erweiterung Active Directory Domain Services (AD DS) bildet die Kernkomponente; daneben existieren unter anderem die Active Directory Federation Services (AD FS) und der cloudbasierte Dienst Microsoft Entra ID (früher Azure Active Directory).

Struktur

Active Directory ist hierarchisch gegliedert: Die kleinste Verwaltungseinheit ist das Objekt (z. B. Benutzer oder Computer). Objekte werden in Organisationseinheiten (OUs) und Domänen zusammengefasst; mehrere Domänen bilden einen Tree, mehrere Trees eine Gesamtstruktur (Forest), die die Sicherheitsgrenze darstellt. Die Authentifizierung erfolgt vor allem über Kerberos, der Verzeichniszugriff über LDAP.

Komponenten

Server mit der AD-DS-Rolle heißen Domänencontroller. Sie replizieren die Verzeichnisdatenbank untereinander (Multi-Master-Replikation) und stellen darüber hinaus Dienste wie DNS-Integration, Gruppenrichtlinien (Group Policies) zur zentralen Konfiguration von Rechnern und Benutzern sowie die Vergabe von FSMO-Rollen für Aufgaben bereit, die nur ein einziger Server ausführen darf.

Gruppenrichtlinien

Über Gruppenrichtlinienobjekte (GPOs) können Administratoren Sicherheitseinstellungen, Softwareverteilung und Desktop-Konfigurationen zentral festlegen und auf OUs anwenden.
