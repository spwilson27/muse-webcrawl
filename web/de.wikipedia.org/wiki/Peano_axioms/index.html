Peano-Axiome

Die Peano-Axiome sind eine von dem italienischen Mathematiker Giuseppe Peano 1889 formulierte axiomatische Beschreibung der natürlichen Zahlen. Sie bauen auf der Nachfolgerfunktion auf und bilden bis heute eine Grundlage der Arithmetik. Unabhängig von Peano hatte bereits Richard Dedekind 1888 eine entsprechende Charakterisierung angegeben.

Die Axiome

In moderner Formulierung lauten die Axiome:

  1. 0 ist eine natürliche Zahl.
  2. Jede natürliche Zahl n besitzt einen Nachfolger S(n), der ebenfalls eine natürliche Zahl ist.
  3. 0 ist nicht Nachfolger einer natürlichen Zahl.
  4. Verschiedene Zahlen haben verschiedene Nachfolger: Aus S(m) = S(n) folgt m = n.
  5. Induktionsaxiom: Enthält eine Menge die 0 und mit jeder Zahl auch deren Nachfolger, so enthält sie alle natürlichen Zahlen.

Bedeutung

Aus den Axiomen lassen sich Addition und Multiplikation rekursiv definieren und die üblichen Rechenregeln beweisen. Das Induktionsaxiom begründet das Beweisverfahren der vollständigen Induktion. In der Logik zweiter Stufe charakterisieren die Axiome die natürlichen Zahlen bis auf Isomorphie; in der schwächeren Peano-Arithmetik erster Stufe existieren dagegen auch Nichtstandardmodelle.
