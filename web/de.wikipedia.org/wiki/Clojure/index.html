Clojure

Paradigma: funktional, Lisp

Erschienen: 2007

Entwickler: Rich Hickey

Plattform: JVM, CLR, JavaScript

Lizenz: Eclipse Public License

Clojure ist ein moderner Dialekt der Programmiersprache Lisp, der 2007 von Rich Hickey veröffentlicht wurde. Die Sprache läuft auf der Java Virtual Machine (JVM) und legt ihren Schwerpunkt auf funktionale Programmierung, Unveränderlichkeit (Immutability) und die Unterstützung nebenläufiger Programmierung.

Geschichte

Rich Hickey begann die Entwicklung von Clojure im Jahr 2005 und veröffentlichte die erste Version 2007. Sein Ziel war eine funktionale Lisp-Sprache für die JVM, die die Stärken der Java-Plattform mit der Ausdruckskraft von Lisp verbindet. 2011 erschien die Version 1.3, später folgten unter anderem ClojureScript, ein Compiler nach JavaScript, sowie die Spezifikationsbibliothek spec.

Eigenschaften

Clojure behandelt Code als Daten (Homoikonizität) und stellt leistungsfähige Makros zur Verfügung. Standardmäßig sind Datenstrukturen unveränderlich und persistent. Für die Zustandsverwaltung in nebenläufigen Programmen bietet Clojure ein Software Transactional Memory (STM), Agenten und Atome. Die Sprache interoperiert direkt mit Java-Bibliotheken.

(defn fakultaet [n]
  (if (zero? n) 1 (* n (fakultaet (dec n)))))

Verbreitung

Clojure wird in der Webentwicklung, Datenverarbeitung und in verteilten Systemen eingesetzt. Bekannte Werkzeuge der Community sind der Editor- und Build-Werkzeug Leiningen sowie die Laufzeitumgebung Babashka.
