Apache HTTP Server

Apache HTTP Server
Entwickler: Apache Software Foundation
Programmiersprache: C
Betriebssystem: plattformunabhängig
Lizenz: Apache License 2.0

Der Apache HTTP Server ist ein freier Webserver der Apache Software Foundation. Er entstand 1995 aus Weiterentwicklungen des NCSA HTTPd, der damals der verbreitetste Webserver war; der Name wird traditionell als Wortspiel erklärt („a patchy server" – ein aus Patches zusammengesetzter Server), und das Projekt beruft sich zugleich respektvoll auf den Stamm der Apachen. Lange Zeit war Apache der weltweit meistgenutzte Webserver; er trug maßgeblich zum Wachstum des frühen World Wide Web bei und wird bis heute auf einem erheblichen Teil aller Websites eingesetzt, inzwischen im Wettbewerb vor allem mit nginx.

Eigenschaften

Der Server ist modular aufgebaut: Kernfunktionen lassen sich durch eine Vielzahl von Modulen erweitern, etwa für TLS-Verschlüsselung (mod_ssl), URL-Umschreibung (mod_rewrite), Proxy-Betrieb (mod_proxy), Authentifizierung oder die Einbindung von Skriptsprachen. Unter Linux ist die Kombination aus Apache, MySQL und PHP/Perl/Python als LAMP-Stack bekannt geworden. Die Konfiguration erfolgt über die Datei httpd.conf sowie verzeichnisspezifische .htaccess-Dateien. Apache läuft auf Unix-Systemen, Linux, Windows und weiteren Plattformen und unterstützt HTTP/1.1 sowie HTTP/2.

Geschichte

Die erste Version erschien 1995 unter Federführung der „Apache Group", aus der 1999 die Apache Software Foundation hervorging. Version 2.0 (2002) brachte eine überarbeitete Architektur mit austauschbaren Multi-Processing-Modulen (MPM), Version 2.4 erschien 2012. Der Apache HTTP Server gilt als das Vorzeigeprojekt der Stiftung und gab der Apache-Lizenz ihren Namen.
