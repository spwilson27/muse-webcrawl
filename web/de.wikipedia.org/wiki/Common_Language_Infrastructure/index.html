Common Language Infrastructure

Die Common Language Infrastructure (CLI) ist eine offene Spezifikation, die ursprünglich von Microsoft entwickelt wurde und eine sprach- und plattformunabhängige Ausführungsumgebung für Programme beschreibt. Sie ist als ECMA-335 und ISO/IEC 23271 standardisiert.

Bestandteile

Kern der CLI sind das Common Type System (CTS), das alle unterstützten Sprachen ein gemeinsames Typsystem bereitstellt, die Common Language Specification (CLS) mit Regeln für die Sprachinteroperabilität, das Metadatensystem sowie das Virtual Execution System (VES), das Programme in der Zwischensprache Common Intermediate Language (CIL) lädt und ausführt.

Implementierungen

Die bekannteste Implementierung ist die Common Language Runtime (CLR) des .NET Frameworks beziehungsweise von .NET. Weitere Implementierungen sind das quelloffene Mono-Projekt und .NET Core beziehungsweise das moderne .NET, die CLI-Anwendungen auch unter Linux und macOS ausführen.
