Oracle Corporation

Die Oracle Corporation ist ein US-amerikanischer Software- und Hardwarekonzern mit Hauptsitz in Austin, Texas. Das Unternehmen wurde 1977 von Larry Ellison, Bob Miner und Ed Oates in Santa Clara, Kalifornien, unter dem Namen Software Development Laboratories gegründet und ist vor allem für sein relationales Datenbankmanagementsystem Oracle Database bekannt. Oracle zählt zu den weltweit größten Softwareunternehmen.

Geschichte

1979 brachte das Unternehmen mit Oracle Version 2 die erste kommerziell verfügbare relationale Datenbank mit SQL-Unterstützung auf den Markt. In den folgenden Jahrzehnten wuchs Oracle stark durch Zukäufe, darunter PeopleSoft (2005), Siebel Systems (2006), BEA Systems (2008) und Sun Microsystems (2010), womit Oracle unter anderem in den Besitz der Programmiersprache Java und des Datenbanksystems MySQL gelangte. 2022 übernahm Oracle für rund 28 Milliarden US-Dollar den Gesundheits-IT-Anbieter Cerner, dessen Geschäft in der Sparte Oracle Health aufging. Der Firmensitz wurde 2020 von Redwood City, Kalifornien, nach Austin verlegt.

Produkte

Zu den wichtigsten Produkten gehören die Oracle Database, die Cloud-Plattform Oracle Cloud Infrastructure (OCI), die Unternehmenssoftwarefamilien E-Business Suite, Fusion Applications und NetSuite sowie die Programmiersprache Java. Oracle beschäftigt weltweit weit über 100.000 Mitarbeiter.

Führung

Mitgründer Larry Ellison war bis 2014 CEO und ist seither Executive Chairman und Chief Technology Officer; die Geschäftsführung liegt bei Safra Catz.
