Portierung (Software)

Unter Portierung (englisch porting) versteht man in der Informatik die Anpassung einer Software, sodass sie auf einer anderen Plattform – etwa einem anderen Betriebssystem, einer anderen Prozessorarchitektur oder einer anderen Spielkonsole – lauffähig wird. Das Ergebnis wird als Port bezeichnet. Eine Software, die von vornherein für viele Plattformen konzipiert ist, heißt portabel.

Verfahren

Der Aufwand einer Portierung hängt stark von der Portabilität des ursprünglichen Programms ab. Wurde es in einer portablen Sprache wie C oder Java geschrieben und nutzt es standardisierte Schnittstellen, genügt häufig eine Neuübersetzung mit plattformspezifischen Anpassungen. Sind dagegen große Teile in Assemblersprache verfasst oder nutzt das Programm systemspezifische Funktionen, kann eine weitgehende Neuentwicklung einzelner Module erforderlich sein.

Portierungen bei Computerspielen

Im Bereich der Videospiele bezeichnet eine Portierung die Umsetzung eines Titels von einer Plattform auf eine andere, etwa von einer Konsole auf den PC. Solche Ports wurden wiederholt dafür kritisiert, die Möglichkeiten der Zielplattform nicht auszuschöpfen, während gelungene Umsetzungen neue Grafikoptionen, Steuerungsvarianten oder zusätzliche Inhalte bieten können.

Abgrenzung

Im Unterschied zur Portierung läuft bei der Emulation die ursprüngliche Software unverändert in einer nachgebildeten Umgebung. Eine Neuimplementierung (Remake) geht über die Portierung hinaus, da sie das Programm unter Verwendung moderner Technik weitgehend neu erstellt.
