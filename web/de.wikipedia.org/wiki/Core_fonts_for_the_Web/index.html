Core fonts for the Web

Core fonts for the Web war ein Projekt von Microsoft, das 1996 gestartet wurde, um einen einheitlichen Satz von Schriftarten für das World Wide Web kostenlos zu verbreiten. Ziel war es, Webdesignern eine plattformübergreifend verfügbare Schriftauswahl zu geben, damit Seiten überall weitgehend gleich dargestellt wurden.

Umfang

Zum Paket gehörten unter anderem Arial, Times New Roman, Courier New, Georgia, Verdana, Trebuchet MS, Comic Sans MS, Impact, Arial Black, Wingdings und Webdings sowie die Andale Mono. Die TrueType-Schriften wurden von Monotype und anderen Schrifthäusern gestaltet und waren für die Bildschirmanzeige optimiert.

Verbreitung und Ende

Die Schriften wurden mit Windows und dem Internet Explorer ausgeliefert und waren auch für Mac OS und Linux verfügbar. 2002 beendete Microsoft den freien Download von seiner Website; die EULA erlaubte jedoch weiterhin die unveränderte Weitergabe, sodass die Pakete bis heute verbreitet sind. Die Schriften prägen bis heute die Standard-Schriftauswahl von Websites.
