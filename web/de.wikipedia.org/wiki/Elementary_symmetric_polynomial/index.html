Elementarsymmetrisches Polynom

Die elementarsymmetrischen Polynome sind eine Familie symmetrischer Polynome, die in der Algebra eine grundlegende Rolle spielen. Das k-te elementarsymmetrische Polynom in n Variablen ist die Summe aller Produkte von jeweils k verschiedenen Variablen.

Definition und Beispiele

Für die Variablen x1, …, xn gilt:

  • e1 = x1 + x2 + … + xn (Summe aller Variablen),
  • e2 = Summe aller Produkte aus je zwei verschiedenen Variablen,
  • …,
  • en = x1 · x2 · … · xn (Produkt aller Variablen).

Für n = 3 ergeben sich beispielsweise e1 = x1+x2+x3, e2 = x1x2+x1x3+x2x3 und e3 = x1x2x3.

Hauptsatz über symmetrische Polynome

Nach dem Hauptsatz über symmetrische Polynome lässt sich jedes symmetrische Polynom eindeutig als Polynom in den elementarsymmetrischen Polynomen darstellen. Die elementarsymmetrischen Polynome bilden somit eine algebraische Basis des Rings der symmetrischen Polynome.

Zusammenhang mit Polynomwurzeln

Sind x1, …, xn die Nullstellen eines normierten Polynoms, so sind die Koeffizienten dieses Polynoms bis auf das Vorzeichen genau die elementarsymmetrischen Polynome in den Nullstellen (Satz von Vieta). Für ein quadratisches Polynom x² + px + q mit den Nullstellen x1, x2 gilt etwa e1 = x1 + x2 = −p und e2 = x1x2 = q.
