Brave ist ein freier Webbrowser, der von der Brave Software Inc. entwickelt wird. Er basiert auf dem Open-Source-Projekt Chromium und wurde 2016 erstmals veröffentlicht. Mitgründer des Unternehmens ist Brendan Eich, der zuvor an JavaScript und an Mozilla Firefox beteiligt war.

Eigenschaften

Brave blockiert standardmäßig Werbung und Website-Tracker („Brave Shields") und legt damit einen Schwerpunkt auf Datenschutz und Geschwindigkeit. Der Browser enthält eine integrierte Unterstützung für das Tor-Netzwerk in privaten Fenstern, eine Kryptowährungs-Wallet sowie den KI-Assistenten Leo.

Basic Attention Token

Mit dem optionalen Programm „Brave Rewards" können Nutzer Werbeeinblendungen des Browsers zulassen und erhalten dafür Einheiten der Kryptowährung Basic Attention Token (BAT), die sie an Webseitenbetreiber und Inhalteersteller weitergeben können. Dieses Modell soll eine Alternative zur herkömmlichen, datenbasierten Onlinewerbung bieten.

Verbreitung

Der Browser überschritt in den 2020er Jahren die Marke von 50 Millionen monatlich aktiven Nutzern und gehört damit zu den meistgenutzten datenschutzorientierten Browsern.
