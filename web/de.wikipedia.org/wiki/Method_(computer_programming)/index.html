Methode (Programmierung)

Eine Methode ist in der objektorientierten Programmierung eine Funktion oder Prozedur, die einer Klasse zugeordnet ist und das Verhalten der Objekte dieser Klasse beschreibt. Methoden operieren auf den Daten (Attributen) eines Objekts und bilden zusammen mit diesen die Schnittstelle, über die mit dem Objekt interagiert wird.

Begriff und Abgrenzung

Im Unterschied zu einer freien Funktion ist eine Methode an eine Klasse oder ein Objekt gebunden. Sie wird über einen Empfänger aufgerufen, der in vielen Sprachen über das Schlüsselwort this oder self innerhalb der Methode verfügbar ist. In manchen Sprachen, etwa Smalltalk, wird der Methodenaufruf als „Senden einer Nachricht“ an ein Objekt verstanden.

Arten von Methoden

  • Instanzmethoden arbeiten auf einer konkreten Instanz der Klasse.
  • Klassenmethoden bzw. statische Methoden gehören zur Klasse selbst und benötigen kein Objekt.
  • Konstruktoren dienen der Initialisierung neuer Objekte.
  • Abstrakte Methoden besitzen keinen Rumpf und müssen von abgeleiteten Klassen implementiert werden.
  • Getter und Setter (Zugriffsmethoden) kontrollieren den Zugriff auf Attribute.

Überladen und Überschreiben

Viele Sprachen erlauben das Überladen: Mehrere Methoden gleichen Namens unterscheiden sich in ihrer Parameterliste (Signatur). Beim Überschreiben ersetzt eine abgeleitete Klasse die Implementierung einer geerbten Methode; durch dynamische Bindung wird zur Laufzeit die zur tatsächlichen Objektklasse passende Implementierung ausgeführt (Polymorphie).

Beispiel

public class Konto {
    private double kontostand;

    public void einzahlen(double betrag) {
        this.kontostand += betrag;
    }

    public double getKontostand() {
        return this.kontostand;
    }
}
