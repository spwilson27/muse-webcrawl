Canonical XML

Canonical XML ist eine vom World Wide Web Consortium (W3C) standardisierte Methode, ein XML-Dokument in eine eindeutige, kanonische Byte-Darstellung zu überführen. Die Spezifikation wurde 2001 als W3C-Empfehlung veröffentlicht.

Zweck

Zwei XML-Dokumente können logisch identisch sein, sich aber in der Bytefolge unterscheiden – etwa durch Attributreihenfolge, überflüssige Leerzeichen oder verschiedene, gleichwertige Schreibweisen leerer Elemente. Für kryptographische Anwendungen wie XML-Signaturen (XMLDSig) ist das problematisch, weil ein Hashwert über die exakte Bytefolge gebildet wird. Die Kanonisierung beseitigt diese Mehrdeutigkeiten, sodass logisch gleiche Dokumente auch denselben Hashwert ergeben.

Regeln (Auswahl)

  • Zeichenkodierung UTF-8, Zeilenenden einheitlich LF
  • Attribute werden lexikographisch (nach Namensraum und Name) sortiert
  • Namensraumdeklarationen werden an den Elementen eingefügt, an denen sie benötigt werden
  • Leere Elemente werden als Start- und End-Tag-Paar geschrieben
  • Überflüssige Leerzeichen in Tags werden vereinheitlicht

Varianten

Neben der inklusiven Kanonisierung existiert die Exclusive XML Canonicalization, die nur die tatsächlich benutzten Namensräume übernimmt – wichtig, wenn ein signiertes Dokument in einen anderen XML-Kontext eingebettet wird. Canonical XML findet vor allem in XML-Signaturen, SAML und Web-Service-Sicherheitsstandards Anwendung.
