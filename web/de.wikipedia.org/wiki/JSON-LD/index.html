JSON-LD

JSON-LD (JavaScript Object Notation for Linked Data) ist eine Methode, um Linked Data mithilfe des Datenformats JSON zu kodieren. JSON-LD ist eine Empfehlung des World Wide Web Consortiums (W3C).

Grundlagen

JSON-LD erweitert JSON um spezielle Schlüssel wie @context, @id und @type. Der Kontext ordnet den im Dokument verwendeten Begriffen global eindeutige Bezeichner (IRIs) zu, sodass Daten maschinenlesbar verknüpft und interpretiert werden können.

Verwendung

JSON-LD wird häufig zur Auszeichnung strukturierter Daten auf Webseiten eingesetzt, etwa im Rahmen von schema.org, damit Suchmaschinen Inhalte besser verstehen können. Auch Google empfiehlt JSON-LD als bevorzugtes Format für strukturierte Daten.
