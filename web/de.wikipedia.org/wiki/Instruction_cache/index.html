Befehls-Cache

Ein Befehls-Cache (englisch instruction cache, kurz I-Cache) ist ein schneller Pufferspeicher in einem Mikroprozessor, der Maschinenbefehle zwischenspeichert, damit sie bei der Ausführung zügig bereitstehen. Er nutzt die zeitliche und räumliche Lokalität von Programmen aus, bei denen Befehle häufig wiederholt oder aufeinanderfolgend ausgeführt werden, etwa in Schleifen.

Aufbau

In modernen Prozessoren ist der Befehls-Cache vom Daten-Cache getrennt (Harvard-Architektur auf der ersten Cache-Ebene). Der L1-Befehls-Cache ist üblicherweise einige Dutzend Kilobyte groß; höhere Cache-Ebenen (L2, L3) sind dagegen meist für Befehle und Daten gemeinsam ausgelegt (Von-Neumann-Architektur). Wird ein benötigter Befehl nicht im Cache gefunden (Cache Miss), muss er aus einer langsameren Speicherebene nachgeladen werden.

Besonderheiten

Anders als Daten ändern sich Befehle während der Programmausführung in der Regel nicht, weshalb der Befehls-Cache nur gelesen werden muss. Probleme können bei selbstmodifizierendem Code oder beim Laden neuer Programme entstehen; dann muss der Cache gezielt ungültig gemacht werden.
