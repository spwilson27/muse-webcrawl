Normierter Raum

Ein normierter Raum oder normierter Vektorraum ist in der Mathematik ein Vektorraum, auf dem eine Norm definiert ist, mit der jedem Vektor eine Länge zugeordnet werden kann. Normierte Räume sind ein zentrales Konzept der Funktionalanalysis.

Definition

Eine Norm auf einem Vektorraum V über ℝ oder ℂ ist eine Abbildung ‖·‖: V → ℝ≥0 mit den Eigenschaften: Definitheit (‖x‖ = 0 genau dann, wenn x = 0), absolute Homogenität (‖λx‖ = |λ|‖x‖) und Dreiecksungleichung (‖x + y‖ ≤ ‖x‖ + ‖y‖).

Beispiele und Zusammenhänge

Beispiele sind der euklidische Raum ℝⁿ mit der euklidischen Norm sowie die Lp-Räume. Jede Norm induziert eine Metrik und damit eine Topologie. Vollständige normierte Räume heißen Banachräume; wird die Norm von einem Skalarprodukt induziert, spricht man von einem Prähilbertraum bzw. Hilbertraum.
