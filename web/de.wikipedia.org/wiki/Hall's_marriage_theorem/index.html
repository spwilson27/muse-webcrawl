Satz von Hall (Heiratssatz)

Der Satz von Hall (englisch Hall's marriage theorem) ist ein Resultat der Kombinatorik, das 1935 von Philip Hall veröffentlicht wurde. Er beantwortet die Frage, unter welchen Bedingungen aus einer Familie von Mengen ein System paarweise verschiedener Repräsentanten ausgewählt werden kann.

Die „Heirats"-Formulierung

Der volkstümliche Name rührt von folgender Veranschaulichung her: n Frauen möchten heiraten; jede von ihnen gibt an, welche Männer für sie infrage kommen. Eine vollständige Verheiratung, bei der jede Frau einen ihr genehmen (und jeweils anderen) Mann erhält, ist genau dann möglich, wenn je k Frauen zusammen mindestens k Männer als akzeptabel benennen – für jedes k von 1 bis n.

Graphentheoretische Fassung

In der Sprache der Graphentheorie besagt der Satz: Ein bipartiter Graph mit den Partitionsmengen X und Y besitzt ein X überdeckendes Matching genau dann, wenn für jede Teilmenge S von X die Nachbarschaft N(S) mindestens |S| Knoten enthält.

Verwandte Resultate

Aus dem Satz von Hall folgen unter anderem der Satz von König über bipartite Graphen, der Satz von Birkhoff-von Neumann über doppelt stochastische Matrizen sowie Aussagen über Lateinische Rechtecke. Es existieren auch Versionen für unendliche Mengenfamilien und defizitäre Varianten („defect form"), die angeben, wie viele Elemente höchstens unrepräsentiert bleiben.
