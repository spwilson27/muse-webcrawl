Python (Programmiersprache)

Python
Entwickler: Python Software Foundation
Erscheinungsjahr: 1991
Entwickler der Sprache: Guido van Rossum
Paradigmen: multiparadigmatisch
Typisierung: dynamisch, stark

Python ist eine universelle, interpretierte höhere Programmiersprache, die Anfang der 1990er Jahre von Guido van Rossum am Centrum Wiskunde & Informatica in Amsterdam entwickelt wurde. Sie legt Wert auf gut lesbaren, übersichtlichen Code und zählt heute zu den weltweit meistgenutzten Programmiersprachen. Der Name geht nicht auf die Schlange Python zurück, sondern auf die britische Komikergruppe Monty Python.

Eigenschaften

Python verwendet Einrückungen statt geschweifter Klammern zur Strukturierung von Codeblöcken. Die Sprache unterstützt mehrere Programmierparadigmen – objektorientiert, imperativ, funktional und aspektorientiert – und verfügt über eine dynamische Typisierung mit automatischer Speicherverwaltung (Garbage Collection). Eine umfangreiche Standardbibliothek („batteries included“) sowie ein riesiges Ökosystem an Zusatzpaketen, die über den Paketindex PyPI bereitgestellt werden, gehören zu den Stärken der Sprache.

Geschichte

Die erste Version erschien 1991. Python 2.0 folgte im Jahr 2000; die nicht abwärtskompatible Version 3.0 wurde 2008 veröffentlicht und beseitigte zahlreiche Inkonsistenzen der Sprache. Der Übergang von Python 2 zu Python 3 dauerte über ein Jahrzehnt und endete mit dem Supportende von Python 2 im Jahr 2020. Die Weiterentwicklung koordiniert die gemeinnützige Python Software Foundation.

Einsatzgebiete

Python wird unter anderem in der Webentwicklung (Frameworks wie Django und Flask), in Wissenschaft und Datenanalyse (NumPy, pandas), im maschinellen Lernen (TensorFlow, PyTorch), für Skripte und Systemadministration sowie in der Lehre eingesetzt. Bekannte Anwendungen sind unter anderem Teile von YouTube, Instagram und Dropbox.

Philosophie

Die Leitprinzipien der Sprache sind im „Zen of Python“ zusammengefasst, darunter „Lesbarkeit zählt“ und „Es sollte eine – und vorzugsweise nur eine – offensichtliche Möglichkeit geben, etwas zu tun“.
