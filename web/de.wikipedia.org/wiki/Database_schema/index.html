Datenbankschema

Ein Datenbankschema ist die formale Beschreibung der Struktur einer Datenbank: Es definiert die vorhandenen Tabellen, deren Spalten und Datentypen sowie die Beziehungen zwischen ihnen und die geltenden Integritätsbedingungen. Das Schema beschreibt die Struktur, nicht die konkreten Dateninhalte; letztere werden als Datenbankzustand oder -ausprägung bezeichnet.

Ebenen

Nach der ANSI/SPARC-Architektur werden konzeptionelle, externe und interne Schemata unterschieden. Das konzeptionelle Schema beschreibt die gesamte Datenbank logisch, externe Schemata definieren benutzerspezifische Sichten, und das interne Schema legt die physische Speicherung fest.

Definition

Schemata werden mit der Datendefinitionssprache (DDL) eines Datenbanksystems angelegt und verändert, in SQL etwa mit Anweisungen wie:

CREATE TABLE Kunde (
  KundenNr INTEGER PRIMARY KEY,
  Name     VARCHAR(100) NOT NULL
);

Schemaevolution

Da sich Anforderungen ändern, müssen Schemata weiterentwickelt werden (Schemaevolution, Schemamigration). In verteilten und NoSQL-Systemen kommen daneben Ansätze mit flexiblem oder zur Lesezeit interpretiertem Schema („schema on read") zum Einsatz, etwa in Data Lakes.
