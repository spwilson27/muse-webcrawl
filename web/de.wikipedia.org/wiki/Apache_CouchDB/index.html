Entwickler: Apache Software Foundation

Kategorie: Dokumentenorientierte Datenbank

Apache CouchDB ist eine dokumentenorientierte NoSQL-Datenbank der Apache Software Foundation. Sie wurde 2005 von Damien Katz, einem ehemaligen Lotus-Notes-Entwickler bei IBM, begonnen und 2008 ein Apache-Projekt. Der Name ist ein Akronym für Cluster Of Unreliable Commodity Hardware DataBase und zugleich ein Wortspiel mit dem englischen Wort couch (Sofa), das Entspannung signalisieren soll – das Projektmotto lautet sinngemäß „Relax".

Eigenschaften

CouchDB speichert Daten als JSON-Dokumente ohne festes Schema. Der Zugriff erfolgt vollständig über eine REST-artige HTTP-Schnittstelle; Dokumente werden per HTTP-Methoden gelesen, geschrieben und gelöscht. Abfragen und Indizes werden über sogenannte Views realisiert, die in JavaScript (oder anderen Sprachen) als MapReduce-Funktionen definiert werden und ihre Ergebnisse in B-Bäumen ablegen.

Die Datenbank folgt dem Prinzip der Eventual Consistency und ist auf Ausfallsicherheit und Replikation ausgelegt: Über das bidirektionale Replikationsprotokoll können Datenbanken auch ohne ständige Verbindung – etwa zwischen Server und mobilen Geräten oder Browsern (Offline-First-Ansatz, vgl. PouchDB) – synchronisiert werden. Konflikte werden über Multiversion Concurrency Control (MVCC) erkannt; jedes Dokument trägt eine Revisionskennung, und ältere Versionen bleiben bis zu einer Verdichtung (Compaction) erhalten. Anders als ACID-Systeme garantiert CouchDB ein Append-only-Speicherformat, das Abstürze gut toleriert.

Verwendung

CouchDB wird unter anderem für Anwendungen mit vielen, nur lose verbundenen Knoten, für die Datenspeicherung in Webanwendungen sowie in der Wissenschaft – etwa am CERN für Datenerfassungsexperimente – eingesetzt. Die Verwaltungsoberfläche trägt in neueren Versionen den Namen Fauxton.
