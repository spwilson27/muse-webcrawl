JavaScript

JavaScript (kurz JS) ist eine Skriptsprache, die 1995 von Brendan Eich bei Netscape entwickelt wurde. Sie wird vor allem im Webbrowser eingesetzt, um Webseiten interaktiv zu gestalten, kommt heute aber auch serverseitig (etwa mit Node.js) und in vielen anderen Bereichen zum Einsatz.

Geschichte

JavaScript wurde innerhalb weniger Tage entworfen und 1995 mit dem Netscape Navigator veröffentlicht. Der Name wurde aus Marketinggründen in Anlehnung an die damals populäre Sprache Java gewählt, obwohl beide Sprachen abgesehen von oberflächlichen Ähnlichkeiten wenig gemeinsam haben. Standardisiert wird JavaScript als ECMAScript durch die Organisation Ecma International; wichtige Meilensteine waren ES5 (2009) und ES6/ECMAScript 2015 mit Klassen, Modulen und Pfeilfunktionen.

Eigenschaften

JavaScript ist dynamisch typisiert, objektorientiert auf Grundlage von Prototypen und unterstützt funktionale Programmierung. Gemeinsam mit HTML und CSS bildet es die Kerntechnologien des World Wide Web; nahezu alle modernen Websites verwenden JavaScript. Bekannte Frameworks und Bibliotheken sind React, Angular und Vue.js.
