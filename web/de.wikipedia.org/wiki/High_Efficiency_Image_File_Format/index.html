High Efficiency Image File Format

Das High Efficiency Image File Format (HEIF) ist ein Containerformat für Bilder und Bildsequenzen, das von der Moving Picture Experts Group (MPEG) entwickelt und im Standard ISO/IEC 23008-12 festgelegt wurde. Dateien verwenden üblicherweise die Endungen .heic oder .heif.

Merkmale

HEIF basiert auf dem ISO Base Media File Format und kann Bilder speichern, die mit dem Videocodec HEVC (H.265) komprimiert sind. Gegenüber JPEG bietet das Format bei gleicher Bildqualität etwa die halbe Dateigröße. Unterstützt werden unter anderem Transparenz, Farbtiefen von 8 und 10 Bit, Miniaturansichten, Bearbeitungshistorien, Bilderserien und Animationen.

Verbreitung

Apple führte HEIF 2017 mit iOS 11 als Standardformat für Fotos auf iPhone und iPad ein, wodurch das Format weite Verbreitung fand. Microsoft Windows unterstützt HEIF über eine Erweiterung aus dem Microsoft Store. Auf Android wird das Format seit Android 10 nativ unterstützt.

Patente

HEIF nutzt patentierte Technologien von HEVC, sodass die Nutzung des Formats in einigen Ländern Lizenzfragen aufwirft. Dies gilt als ein Grund, warum das freie Konkurrenzformat AVIF auf Basis von AV1 zunehmend an Bedeutung gewinnt.
