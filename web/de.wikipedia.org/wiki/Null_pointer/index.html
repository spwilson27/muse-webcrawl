Nullzeiger

Ein Nullzeiger (englisch null pointer) ist in der Programmierung ein Zeiger, der auf kein gültiges Objekt verweist. Er dient als Markierung für „kein Wert vorhanden“ und wird in vielen Sprachen durch ein Schlüsselwort wie NULL, nullptr (C++), null (Java, C#) oder None (Python) dargestellt.

Geschichte

Die Nullreferenz wurde 1965 von Tony Hoare in die Sprache ALGOL W eingeführt. Hoare selbst bezeichnete das später als seinen „Milliarden-Dollar-Fehler“ (billion-dollar mistake), weil das Dereferenzieren eines Nullzeigers zu unzähligen Programmabstürzen und Sicherheitslücken geführt habe.

Fehler

Der Versuch, über einen Nullzeiger auf Speicher zuzugreifen, führt in Sprachen wie C und C++ zu undefiniertem Verhalten, meist zu einem Programmabsturz (z. B. Segmentation fault). In Java löst dies eine NullPointerException aus. Moderne Sprachentwürfe versuchen, das Problem durch nicht-nullbare Typen, Option-Typen (etwa in Rust oder Swift) und statische Analysen zu mildern.
