Absorbierendes Element

Ein absorbierendes Element ist in der Algebra ein Element einer Menge mit einer zweistelligen Verknüpfung, das bei Verknüpfung mit einem beliebigen anderen Element stets sich selbst ergibt.

Definition

Ein Element a einer Halbgruppe heißt absorbierend, wenn für alle Elemente x gilt: a · x = x · a = a. Ein absorbierendes Element ist, sofern es existiert, eindeutig bestimmt.

Beispiele

Das bekannteste Beispiel ist die Null bei der Multiplikation von Zahlen: 0 · x = 0 für alle x. In der Booleschen Algebra ist die 0 absorbierend bezüglich der Konjunktion bzw. die 1 bezüglich der Disjunktion. Auch die leere Menge ist absorbierend bezüglich des Durchschnitts von Mengen.
