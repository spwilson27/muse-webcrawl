Matrizenoptik

Die Matrizenoptik (englisch ray transfer matrix analysis, auch ABCD-Matrizen) ist ein Verfahren der geometrischen Optik, mit dem der Verlauf eines Lichtstrahls durch ein optisches System aus Linsen, Spiegeln und freien Strecken mithilfe von 2×2-Matrizen berechnet wird.

Grundlagen

Ein paraxialer Strahl wird an jeder Ebene durch einen Vektor aus seiner Höhe r (Abstand zur optischen Achse) und seinem Winkel θ zur Achse beschrieben. Jedes optische Element wirkt auf diesen Vektor als lineare Abbildung:

[r']   [A B] [r]
[θ'] = [C D] [θ]

Beispiele: Für die Translation über eine Strecke d in einem Medium mit Brechzahl n lautet die Matrix (1, d/n; 0, 1), für die Brechung an einer dünnen Linse mit Brennweite f (1, 0; −1/f, 1). Die Matrix eines Gesamtsystems ergibt sich durch Multiplikation der Einzelmatrizen in der Durchlaufreihenfolge des Lichts.

Anwendung

Aus der Systemmatrix lassen sich Brennweiten, Hauptebenen, Abbildungsmaßstäbe und die Stabilität optischer Resonatoren bestimmen. Das Verfahren wird breit in der Laseroptik (Stabilität von Resonatoren, Ausbreitung von Gauß-Strahlen mit dem komplexen Strahlparameter q) und im Linsendesign eingesetzt. Es ist auf die paraxiale Näherung beschränkt; Abbildungsfehler höherer Ordnung werden nicht erfasst.
