BitLocker

BitLocker (vollständig: BitLocker Drive Encryption) ist eine in Microsoft Windows integrierte Festplattenverschlüsselung. Sie wurde mit Windows Vista eingeführt und verschlüsselt ganze Laufwerke, um Daten bei Verlust oder Diebstahl eines Geräts vor unbefugtem Zugriff zu schützen.

Funktionsweise

BitLocker verschlüsselt die Daten eines Volumes mit dem AES-Algorithmus, standardmäßig im XTS-Modus mit 128- oder 256-Bit-Schlüsseln. Der Entschlüsselungsschlüssel wird idealerweise in einem Trusted Platform Module (TPM) versiegelt, sodass beim Systemstart die Integrität der Startkomponenten geprüft werden kann. Alternativ sind eine PIN, ein USB-Schlüssel oder ein Wiederherstellungsschlüssel möglich.

Varianten

Neben der Volumenverschlüsselung für interne Laufwerke existiert mit „BitLocker To Go" eine Variante für Wechseldatenträger wie USB-Sticks. BitLocker ist in den Pro-, Enterprise- und Education-Editionen von Windows verfügbar; neuere Windows-Versionen aktivieren eine Geräteverschlüsselung auf geeigneter Hardware teilweise automatisch.

Verwaltung

In Unternehmensumgebungen wird BitLocker zentral über Gruppenrichtlinien, Microsoft Intune oder den MBAM-Nachfolger verwaltet; Wiederherstellungsschlüssel können im Active Directory oder in Microsoft Entra ID hinterlegt werden.
