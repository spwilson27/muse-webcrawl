Registered Agent

Ein Registered Agent (in manchen Bundesstaaten auch resident agent oder statutory agent) ist im Gesellschaftsrecht der Vereinigten Staaten eine Person oder ein Unternehmen, die von einer Kapitalgesellschaft (Corporation) oder LLC benannt wird, um in deren Namen amtliche Zustellungen – insbesondere Klageschriften und behördliche Schreiben – entgegenzunehmen.

Anforderungen

Jeder Bundesstaat verlangt, dass eine dort gegründete oder registrierte Gesellschaft einen Registered Agent mit einer physischen Anschrift (registered office) in diesem Bundesstaat unterhält; Postfächer genügen nicht. Der Agent muss während der üblichen Geschäftszeiten erreichbar sein und die empfangenen Unterlagen an die Gesellschaft weiterleiten. Viele Unternehmen beauftragen kommerzielle Agenturdienste, die diese Funktion für zahlreiche Gesellschaften in mehreren Bundesstaaten übernehmen; besonders Delaware und Nevada sind als Gründungsstaaten verbreitet.

Zweck

Die Einrichtung gewährleistet, dass es für jede Gesellschaft eine zuverlässige Zustelladresse gibt, damit Rechtssuchende und Behörden Schriftstücke ordnungsgemäß zustellen können. Fehlt ein Registered Agent, kann dies zum Verlust des Good Standing und letztlich zur behördlichen Auflösung der Gesellschaft führen.
