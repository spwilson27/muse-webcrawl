Flugfläche

Eine Flugfläche (englisch Flight Level, FL) ist eine Fläche konstanten Luftdrucks in der Atmosphäre, die zur Höhenstaffelung von Flugzeugen im oberen Luftraum dient. Die Flugfläche wird in Einheiten von 100 Fuß angegeben; Flugfläche 350 (FL350) entspricht einer Druckhöhe von 35.000 Fuß (etwa 10.670 m) bezogen auf den Standardluftdruck von 1013,25 hPa.

Prinzip

Oberhalb der Übergangshöhe (Transition Altitude) stellen Piloten ihren Höhenmesser auf den Standardwert 1013,25 hPa ein. Dadurch zeigen alle Flugzeuge vergleichbare Höhen an, auch wenn die tatsächliche geometrische Höhe je nach Wetterlage abweicht. Dies gewährleistet eine sichere vertikale Staffelung. Unterhalb der Übergangshöhe wird stattdessen der lokale Luftdruck (QNH) eingestellt.

Halbkreisregel

Zur Vermeidung von Begegnungen werden Flugflächen nach dem Steuerkurs zugeteilt: Auf Kursen von 000° bis 179° werden ungerade Flugflächen (FL310, FL330, FL350 …), auf Kursen von 180° bis 359° gerade Flugflächen (FL320, FL340 …) geflogen. Durch die reduzierte Höhenstaffelung (RVSM) beträgt der Abstand zwischen Flugflächen im Höhenband von FL290 bis FL410 nur noch 1.000 Fuß statt früher 2.000 Fuß.

Übergangsebene

Die tiefste nutzbare Flugfläche wird als Übergangsebene (Transition Level) bezeichnet. Sie hängt vom aktuellen Luftdruck ab und wird von der Flugsicherung bekannt gegeben.
