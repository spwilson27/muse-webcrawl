Erzeugendensystem einer Gruppe

Ein Erzeugendensystem einer Gruppe ist eine Teilmenge, aus deren Elementen sich jedes Gruppenelement durch die Gruppenverknüpfung und Inversenbildung gewinnen lässt. Die Elemente eines Erzeugendensystems heißen Erzeuger der Gruppe.

Definition

Sei G eine Gruppe und S eine Teilmenge von G. Die von S erzeugte Untergruppe, geschrieben ⟨S⟩, ist der Durchschnitt aller Untergruppen von G, die S enthalten; sie ist die kleinste Untergruppe, die S umfasst. Gilt ⟨S⟩ = G, so heißt S ein Erzeugendensystem von G. Anschaulich besteht ⟨S⟩ aus allen Elementen, die sich als endliche Produkte von Elementen aus S und deren Inversen schreiben lassen.

Beispiele

  • Die additiv geschriebene Gruppe der ganzen Zahlen wird von {1} erzeugt; sie ist ein Beispiel einer zyklischen Gruppe.
  • Die symmetrische Gruppe Sn wird von den Transpositionen erzeugt, sogar bereits von einer einzigen Transposition zusammen mit einem n-Zykel.
  • Die freie Gruppe über einer Menge X wird von X erzeugt und besitzt die universelle Eigenschaft, dass sich jede Abbildung von X in eine Gruppe eindeutig zu einem Homomorphismus fortsetzen lässt.

Bedeutung

Erzeugendensysteme erlauben es, Gruppen durch Erzeuger und Relationen zu beschreiben (Präsentierung einer Gruppe). Eine Gruppe heißt endlich erzeugt, wenn sie ein endliches Erzeugendensystem besitzt. Der Begriff des Erzeugendensystems verallgemeinert sich auf andere algebraische Strukturen, etwa auf Ringe, Moduln und Lie-Algebren.
