Pfaffsche Determinante

Die Pfaffsche Determinante, benannt nach dem deutschen Mathematiker Johann Friedrich Pfaff, ist eine für schiefsymmetrische Matrizen gerader Dimension definierte Größe. Für eine schiefsymmetrische 2n×2n-Matrix A ist die Pfaffsche Determinante pf(A) ein Polynom in den Matrixeinträgen, dessen Quadrat gleich der Determinante von A ist: pf(A)² = det(A).

Definition

Sei A eine schiefsymmetrische Matrix der Größe 2n×2n. Die Pfaffsche Determinante kann rekursiv oder über eine Summe über alle perfekten Paarungen (perfekte Matchings) der Indexmenge {1, …, 2n} definiert werden. Jede Paarung trägt das Vorzeichen der zugehörigen Permutation und das Produkt der entsprechenden Matrixeinträge bei.

Für den einfachsten Fall n = 1 und die Matrix mit den Einträgen a₁₂ = a gilt pf(A) = a. Für 4×4-Matrizen ergibt sich pf(A) = a₁₂a₃₄ − a₁₃a₂₄ + a₁₄a₂₃.

Eigenschaften

  • pf(A)² = det(A) für jede schiefsymmetrische Matrix gerader Größe.
  • Für eine beliebige Matrix B gilt pf(BABT) = det(B) · pf(A).
  • Die Pfaffsche Determinante ändert unter orthogonalen Transformationen mit Determinante −1 ihr Vorzeichen.

Anwendungen

Pfaffsche Determinanten treten in der Kombinatorik auf, etwa bei der Zählung perfekter Matchings planarer Graphen (Kasteleyns Methode), sowie in der theoretischen Physik, beispielsweise bei der Auswertung von Gaußschen Grassmann-Integralen in der Quantenfeldtheorie und bei der Lösung des zweidimensionalen Ising-Modells.
