Sierpiński-Zahl

Eine Sierpiński-Zahl ist eine ungerade natürliche Zahl k, für die alle Zahlen der Form k · 2n + 1 zusammengesetzt sind, wobei n alle positiven ganzen Zahlen durchläuft. Benannt ist der Begriff nach dem polnischen Mathematiker Wacław Sierpiński, der 1960 bewies, dass es unendlich viele solche Zahlen gibt.

Geschichte

Sierpiński zeigte 1960 die Existenz unendlich vieler ungerader Zahlen k, für die k · 2n + 1 für kein n eine Primzahl ist. Die kleinste bekannte Sierpiński-Zahl ist 78557; sie wurde 1962 von John Selfridge angegeben. Der Nachweis, dass 78557 tatsächlich eine Sierpiński-Zahl ist, beruht auf einem Überdeckungssystem von Kongruenzen: Für jedes n teilt eine von wenigen festen Primzahlen die Zahl 78557 · 2n + 1.

Das Sierpiński-Problem

Das Sierpiński-Problem fragt nach der kleinsten Sierpiński-Zahl. Um zu zeigen, dass 78557 die kleinste ist, muss für jede kleinere ungerade Zahl k ein Exponent n gefunden werden, sodass k · 2n + 1 eine Primzahl ist. Verteilte Rechenprojekte wie „Seventeen or Bust“ und später PrimeGrid haben diese Frage für fast alle Kandidaten geklärt; nur wenige Werte von k blieben lange offen.
