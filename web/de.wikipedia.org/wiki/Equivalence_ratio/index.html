Verbrennungsluftverhältnis

Das Verbrennungsluftverhältnis λ (Lambda) ist eine Kennzahl aus der Verbrennungstechnik. Es gibt das Verhältnis der tatsächlich zugeführten Luftmasse zur stöchiometrisch für eine vollständige Verbrennung erforderlichen Luftmasse an. Im englischen Sprachraum wird häufig das Kehrwert-Verhältnis als equivalence ratio φ verwendet, das das Brennstoff-Luft-Verhältnis auf das stöchiometrische Verhältnis bezieht; es gilt φ = 1/λ.

Definition

Es gilt:

  • λ = 1: stöchiometrisches Gemisch, die zugeführte Luftmenge entspricht genau dem Bedarf.
  • λ < 1: Luftmangel, „fettes" Gemisch; es liegt mehr Brennstoff vor, als mit der vorhandenen Luft vollständig verbrennen kann (φ > 1).
  • λ > 1: Luftüberschuss, „mageres" Gemisch (φ < 1).

Anwendung

Bei Ottomotoren wird das Gemisch mittels Lambdasonde auf λ = 1 geregelt, damit der Drei-Wege-Katalysator optimal arbeitet. Dieselmotoren und Gasturbinen laufen dagegen stets mit Luftüberschuss. In der Feuerungstechnik beeinflusst das Luftverhältnis Wirkungsgrad und Schadstoffemissionen, insbesondere von Kohlenmonoxid und Stickoxiden.
