Content-addressable Memory

Content-addressable Memory (CAM), auch Assoziativspeicher genannt, ist ein spezieller Speichertyp in der Computertechnik, der nicht über eine Adresse, sondern über seinen Inhalt angesprochen wird. Beim Zugriff wird ein Suchwort parallel mit allen gespeicherten Einträgen verglichen und die Position des übereinstimmenden Eintrags zurückgegeben.

Funktionsweise

Jede Speicherzelle eines CAM enthält eigene Vergleichslogik, wodurch die Suche in einem einzigen Taktzyklus über den gesamten Speicher erfolgen kann. Varianten sind das binäre CAM (exakte Übereinstimmung) und das ternäre CAM (TCAM), das zusätzlich „Don't-care“-Zustände speichern kann und dadurch Präfixsuchen ermöglicht.

Anwendungsgebiete

Assoziativspeicher werden vor allem in Netzwerkroutern für die schnelle Weiterleitungsentscheidung (Routing-Tabellen), in Cache-Speichern von Prozessoren, in Translation Lookaside Buffern (TLB) und in der Mustererkennung eingesetzt. Nachteile sind der hohe Energieverbrauch und die Kosten der parallelen Vergleichslogik, weshalb CAMs meist nur relativ kleine Speichergrößen abdecken.
