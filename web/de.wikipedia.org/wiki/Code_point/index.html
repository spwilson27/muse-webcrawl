Codepoint

Ein Codepoint (englisch code point, deutsch auch „Codeposition“) ist ein numerischer Wert innerhalb eines Zeichenkodierungssystems, der einem bestimmten Zeichen zugeordnet ist oder zugeordnet werden kann. Der Begriff wird vor allem im Zusammenhang mit Unicode verwendet.

Unicode-Codepoints

Der Unicode-Zeichenraum umfasst 1.114.112 Codepoints von U+0000 bis U+10FFFF, unterteilt in 17 Ebenen (planes) zu je 65.536 Positionen. Die erste Ebene, die Basic Multilingual Plane (BMP), enthält die Zeichen fast aller modernen Schriften. Notiert werden Codepoints üblicherweise hexadezimal mit dem Präfix „U+“, etwa U+00E4 für den Kleinbuchstaben ä oder U+1F600 für ein Emoji.

Nicht jede Position ist einem sichtbaren Zeichen zugeordnet: Es gibt reservierte Bereiche, private Nutzungsbereiche (Private Use Areas), Surrogat-Codepoints für die UTF-16-Kodierung und sogenannte Nicht-Zeichen (noncharacters).

Abgrenzung

Der Codepoint ist vom kodierten Bytewert zu unterscheiden: Wie ein Codepoint als Bytefolge gespeichert wird, bestimmt erst die konkrete Kodierungsform wie UTF-8, UTF-16 oder UTF-32. Ebenso wenig entspricht ein Codepoint zwangsläufig einem auf dem Bildschirm sichtbaren Zeichen (Glyphe bzw. Graphem), da sich sichtbare Zeichen aus mehreren Codepoints zusammensetzen können, etwa Buchstabe plus kombinierendes Akzentzeichen.
