Recht Frankreichs

Das Recht Frankreichs gehört zur romanischen Rechtsfamilie und gilt als eines der einflussreichsten Rechtssysteme der Welt. Sein Fundament ist der Code civil von 1804 (auch Code Napoléon genannt), der das Privatrecht kodifizierte und zum Vorbild zahlreicher Länder in Europa, Lateinamerika, Afrika und Asien wurde. Grundlage des heutigen Staates ist die Verfassung der Fünften Republik von 1958.

Recht Frankreichs
Rechtsfamilie: Romanisch (Civil Law)
Verfassung: 1958 (Fünfte Republik)
Zivilgesetzbuch: Code civil (1804)
Revisionsgericht: Cour de cassation

Struktur

Charakteristisch ist die Zweiteilung der Gerichtsbarkeit: Ordentliche Gerichte (ordre judiciaire) entscheiden über Zivil- und Strafsachen, Verwaltungsgerichte (ordre administratif) über Streitigkeiten mit dem Staat; an ihrer Spitze stehen die Cour de cassation beziehungsweise der Conseil d’État. Der Conseil constitutionnel prüft Gesetze auf Verfassungsmäßigkeit. Frankreich unterscheidet strikt zwischen öffentlichem und privatem Recht.

Wichtige Kodifikationen

Neben dem Code civil bestehen der Code pénal (Strafgesetzbuch, 1994 erneuert), der Code de commerce (Handelsgesetzbuch), der Code du travail (Arbeitsgesetzbuch) und zahlreiche weitere Kodizes. Die Kodifikation geht auf die Revolution von 1789 und die Erklärung der Menschen- und Bürgerrechte zurück, die Prinzipien wie Legalität, Gleichheit und Eigentumsschutz verankerte.

Einfluss

Das französische Recht wirkte über Kolonialherrschaft und freiwillige Rezeption weltweit; der Code civil wurde unter anderem in Belgien, Italien, Spanien, den Niederlanden und vielen lateinamerikanischen Staaten übernommen oder nachgebildet. Als Mitglied der Europäischen Union ist das französische Recht heute eng mit dem Unionsrecht verflochten, das in seinem Anwendungsbereich Vorrang genießt.
