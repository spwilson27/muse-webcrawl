Metrik (Mathematik)

Metrik
Bereich: Mathematik (Topologie, Analysis)
Definition: Abstandsfunktion mit drei Axiomen
Eingeführt: Maurice Fréchet (1906)

Eine Metrik ist in der Mathematik eine Funktion, die je zwei Elementen einer Menge eine nichtnegative reelle Zahl als Abstand zuordnet. Eine Menge mit einer Metrik heißt metrischer Raum. Das Konzept wurde 1906 von Maurice Fréchet eingeführt und verallgemeinert den anschaulichen Abstand im euklidischen Raum.

Definition

Eine Abbildung d: X × X → ℝ heißt Metrik auf X, wenn für alle x, y, z ∈ X gilt:

  1. Definitheit: d(x, y) = 0 genau dann, wenn x = y;
  2. Symmetrie: d(x, y) = d(y, x);
  3. Dreiecksungleichung: d(x, z) ≤ d(x, y) + d(y, z).

Fällt die Definitheit zugunsten der schwächeren Bedingung d(x, x) = 0 weg, spricht man von einer Pseudometrik.

Beispiele

Die euklidische Metrik auf dem ℝn misst den geradlinigen Abstand. Die Manhatten-Metrik summiert die Beträge der Koordinatendifferenzen. Auf beliebigen Mengen definiert die diskrete Metrik d(x, y) = 1 für x ≠ y eine Metrik. Die französische Eisenbahnmetrik und p-adische Metriken sind weitere bekannte Beispiele; letztere verletzt sogar die verschärfte Dreiecksungleichung der Ultrametriken.

Bedeutung

In metrischen Räumen lassen sich Konvergenz, Stetigkeit, offene und abgeschlossene Mengen sowie Vollständigkeit mit Abstandsbegriffen beschreiben. Metrische Räume bilden eine wichtige Grundlage der Topologie und der Funktionalanalysis. Vom Begriff zu unterscheiden ist der metrische Tensor der Differentialgeometrie.

Dieser Artikel basiert auf dem allgemeinen Wissensstand zur Metrik in der Mathematik.
