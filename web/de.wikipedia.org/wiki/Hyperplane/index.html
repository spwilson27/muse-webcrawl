Hyperebene

Eine Hyperebene (englisch hyperplane) ist in der Mathematik eine Verallgemeinerung der Ebene auf höhere Dimensionen. In einem n-dimensionalen Raum ist eine Hyperebene ein Unterraum der Dimension n−1, der den Raum in zwei Halbräume teilt. Im zweidimensionalen Raum ist eine Hyperebene eine Gerade, im dreidimensionalen eine Ebene.

Darstellung

Eine Hyperebene im ℝn kann als Lösungsmenge einer linearen Gleichung a1x1 + … + anxn = b mit einem nicht verschwindenden Koeffizientenvektor a beschrieben werden. Der Vektor a steht senkrecht auf der Hyperebene und heißt Normalenvektor. Der Abstand eines Punktes von der Hyperebene ergibt sich aus der Hesseschen Normalform.

Bedeutung

Hyperebenen spielen in vielen Gebieten eine Rolle: In der linearen Optimierung begrenzen sie als Restriktionen den zulässigen Bereich. Im maschinellen Lernen dienen sie als Entscheidungsgrenzen, etwa bei der Support Vector Machine, die die Hyperebene mit dem größten Abstand zu den Trainingsdaten sucht, oder im Perzeptron. Der Stützhyperebenensatz der konvexen Analysis besagt, dass sich disjunkte konvexe Mengen durch eine Hyperebene trennen lassen.
