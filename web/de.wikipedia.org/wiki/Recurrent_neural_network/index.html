Rekurrentes neuronales Netz

Ein rekurrentes neuronales Netz (englisch recurrent neural network, RNN) ist eine Klasse künstlicher neuronaler Netze, bei denen Verbindungen zwischen Neuronen Rückkopplungen bilden. Dadurch besitzen sie einen internen Zustand, der als eine Art Gedächtnis dient, und eignen sich besonders zur Verarbeitung von Sequenzen.

Funktionsweise

Ein RNN verarbeitet Eingaben Schritt für Schritt und führt einen versteckten Zustand mit, der Informationen über frühere Eingaben speichert. Die Netzgewichte werden bei jedem Zeitschritt geteilt. Trainiert werden rekurrente Netze mit Backpropagation durch die Zeit.

Varianten

Einfache RNNs leiden beim Lernen langfristiger Abhängigkeiten unter verschwindenden oder explodierenden Gradienten. Bekannte Lösungen sind die Architekturen Long Short-Term Memory (LSTM) und Gated Recurrent Unit (GRU), die mit Gattermechanismen den Informationsfluss steuern.

Anwendungen

Rekurrente Netze wurden lange erfolgreich in Sprachverarbeitung, maschineller Übersetzung, Spracherkennung und Zeitreihenprognosen eingesetzt, bevor sie dort zunehmend von Transformer-Architekturen abgelöst wurden.
