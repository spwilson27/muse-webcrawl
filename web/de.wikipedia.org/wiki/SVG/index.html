Scalable Vector Graphics

Scalable Vector Graphics (kurz SVG) ist ein vom World Wide Web Consortium (W3C) standardisiertes, XML-basiertes Dateiformat zur Beschreibung zweidimensionaler Vektorgrafiken. SVG wurde 2001 als Recommendation veröffentlicht und ist heute ein offener Standard, der von allen gängigen Webbrowsern unterstützt wird.

Eigenschaften

Im Gegensatz zu Rastergrafiken wie JPEG oder PNG beschreiben SVG-Grafiken geometrische Objekte wie Linien, Kreise, Rechtecke, Pfade und Text. Dadurch lassen sie sich ohne Qualitätsverlust beliebig skalieren. SVG-Dateien sind Textdateien und können mit jedem Texteditor erstellt und bearbeitet werden; sie lassen sich außerdem mit CSS gestalten und mit JavaScript animieren oder interaktiv machen.

Verwendung

Typische Anwendungsgebiete sind Logos, Icons, Diagramme, Karten und Illustrationen im Web. Seit HTML5 können SVG-Elemente direkt in HTML-Dokumente eingebettet werden. Auch viele Zeichenprogramme wie Inkscape oder Adobe Illustrator unterstützen den Export und Import von SVG.

Geschichte

Die Entwicklung von SVG begann Ende der 1990er-Jahre; die Version SVG 1.0 wurde im September 2001, SVG 1.1 im Januar 2003 W3C-Recommendation. Für Mobilgeräte existierte zeitweise das Teilprofil SVG Tiny. An einer Version SVG 2 wird seit längerer Zeit gearbeitet.
