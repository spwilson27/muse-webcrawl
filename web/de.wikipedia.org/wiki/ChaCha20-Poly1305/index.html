ChaCha20-Poly1305

ChaCha20-Poly1305
Typ: AEAD-Verfahren
Bestandteile: ChaCha20 + Poly1305
Schlüssellänge: 256 Bit
Nonce: 96 Bit
Tag-Länge: 128 Bit
Standard: RFC 8439

ChaCha20-Poly1305 ist ein Verfahren für authentifizierte Verschlüsselung (AEAD, Authenticated Encryption with Associated Data). Es kombiniert die Stromchiffre ChaCha20 mit dem Message Authentication Code Poly1305, beide entwickelt von Daniel J. Bernstein. Die Konstruktion wurde 2014/2015 für den Einsatz in TLS vorgeschlagen und in RFC 8439 (zuvor RFC 7539) standardisiert.

Funktionsweise

Aus Schlüssel und Nonce erzeugt ChaCha20 zunächst einen Block, aus dem der einmalige Poly1305-Schlüssel abgeleitet wird. Der Klartext wird mit dem weiteren Schlüsselstrom verschlüsselt; über Chiffrat, Zusatzdaten (jeweils mit Padding und Längenangaben) berechnet Poly1305 ein 128-Bit-Authentifizierungstag. XChaCha20-Poly1305 ist eine Variante mit erweiterter 192-Bit-Nonce.

Verbreitung

ChaCha20-Poly1305 ist eine der drei in TLS 1.3 zugelassenen Cipher-Suiten und wird insbesondere auf Mobilgeräten ohne AES-Hardwarebeschleunigung bevorzugt, da es in reiner Software deutlich schneller ist als AES-GCM. Es wird außerdem von WireGuard, SSH (chacha20-poly1305@openssh.com) und zahlreichen Softwarebibliotheken verwendet.
