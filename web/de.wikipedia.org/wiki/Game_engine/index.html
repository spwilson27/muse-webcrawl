Spiel-Engine

Eine Spiel-Engine (englisch game engine) ist ein Softwaregerüst, das die grundlegenden technischen Funktionen für die Entwicklung von Computerspielen bereitstellt. Dazu zählen Grafik-Rendering, Physiksimulation, Sound, Animation, künstliche Intelligenz, Netzwerkfunktionen und Werkzeuge wie Leveleditoren.

Geschichte

Der Begriff etablierte sich in den 1990er Jahren mit den Engines von id Software (Doom, Quake), die lizenziert und von anderen Studios weiterverwendet wurden. Wichtige kommerzielle Engines sind die Unreal Engine von Epic Games und Unity, daneben existieren freie Engines wie Godot.

Komponenten

Moderne Engines bestehen aus der Rendering-Engine, einer Physik-Engine (z. B. Havok oder PhysX), Animationssystemen, Audio-Engine, Skriptanbindung und einem Editor als Entwicklungsumgebung. Durch die Wiederverwendung von Engine-Technologie können sich Entwickler auf Inhalte und Spielmechanik konzentrieren, statt Grundlagentechnik neu zu schreiben.
