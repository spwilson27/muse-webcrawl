SELinux

SELinux (Security-Enhanced Linux) ist eine Erweiterung des Linux-Kernels, die eine verbindliche Zugriffskontrolle (Mandatory Access Control, MAC) umsetzt. Sie wurde maßgeblich von der US-amerikanischen National Security Agency (NSA) entwickelt und im Jahr 2000 als freie Software veröffentlicht; seit Kernel 2.6 ist sie Bestandteil des offiziellen Linux-Kernels.

Funktionsweise

SELinux ordnet jedem Prozess und jedem Objekt (Dateien, Sockets etc.) einen Sicherheitskontext zu. Eine zentral definierte Sicherheitsrichtlinie (Policy) legt fest, welche Zugriffe erlaubt sind – unabhängig von den klassischen Unix-Dateirechten. Selbst ein Programm, das mit Root-Rechten läuft, kann dadurch auf die für seine Aufgabe vorgesehenen Ressourcen beschränkt werden.

Verbreitung

SELinux ist in den Distributionen der Red-Hat-Familie (Red Hat Enterprise Linux, Fedora, CentOS) standardmäßig aktiviert. Auch Android nutzt seit Version 4.3 eine auf SELinux beruhende Zugriffskontrolle (SEAndroid).
