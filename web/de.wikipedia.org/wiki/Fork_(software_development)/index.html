Fork (Softwareentwicklung)

Ein Fork (englisch für „Gabel“, „Verzweigung“) ist in der Softwareentwicklung eine Abspaltung eines Softwareprojekts: Der Quellcode eines bestehenden Projekts wird kopiert und anschließend unabhängig weiterentwickelt. Forks sind ein typisches Phänomen bei freier und quelloffener Software, deren Lizenzen die Veränderung und Weiterverbreitung des Codes ausdrücklich erlauben.

Entstehung

Forks entstehen häufig aus Meinungsverschiedenheiten über die Richtung eines Projekts, aus Unzufriedenheit mit der Projektführung oder weil ein eingestelltes Projekt von neuen Entwicklern fortgeführt werden soll. Manchmal entstehen auch freundschaftliche Abspaltungen zu Test- oder Spezialzwecken, deren Änderungen später in das Hauptprojekt zurückfließen können.

Bekannte Beispiele

  • LibreOffice entstand 2010 als Fork von OpenOffice.org.
  • MariaDB ist eine Abspaltung des Datenbanksystems MySQL.
  • X.Org Server spaltete sich 2004 vom XFree86-Projekt ab.
  • Blink, die Rendering-Engine von Chrome, ist ein Fork von WebKit.
  • Bitcoin Cash entstand als Hard Fork der Bitcoin-Blockchain.

Forks in Versionsverwaltungen

Auf Plattformen wie GitHub bezeichnet „Fork“ auch das Kopieren eines Repositorys in den eigenen Account, um dort Änderungen vorzubereiten und sie anschließend per Pull Request dem Originalprojekt vorzuschlagen. Diese Art des Forks ist ein vorübergehender Arbeitsmechanismus und keine dauerhafte Projektabspaltung. In verteilten Versionsverwaltungssystemen wie Git ist das Verzweigen (Branching) ohnehin grundlegender Bestandteil der Arbeitsweise.
