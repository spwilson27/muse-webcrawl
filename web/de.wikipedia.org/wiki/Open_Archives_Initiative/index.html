Die Open Archives Initiative (OAI) ist eine Initiative zur Förderung der Interoperabilität zwischen digitalen Archiven und Repositorien, insbesondere im Bereich wissenschaftlicher E-Print-Archive. Sie wurde 1999 in Santa Fe (New Mexico) ins Leben gerufen und entwickelte technische Standards, mit denen sich die Metadaten verteilter Dokumentenserver automatisch einsammeln und gemeinsam durchsuchen lassen. Damit schuf sie eine wichtige technische Grundlage der Open-Access-Bewegung.

OAI-PMH

Das bekannteste Ergebnis der Initiative ist das Protocol for Metadata Harvesting (OAI-PMH), dessen Version 2.0 im Jahr 2002 erschien. Es definiert eine HTTP-basierte Schnittstelle mit sechs Diensten („Verben“ wie ListRecords und GetRecord), über die sogenannte Service-Provider die Metadaten von Data-Providern ernten (Harvesting) können. Als Mindestformat ist Dublin Core (oai_dc) in XML vorgeschrieben; weitere Metadatenformate können parallel angeboten werden. Auf dieser Basis betreiben Aggregatoren wie BASE oder CORE übergreifende Suchdienste über tausende Repositorien.

Weitere Aktivitäten

Spätere Projekte der Initiative sind unter anderem OAI-ORE (Object Reuse and Exchange) zur Beschreibung zusammengesetzter digitaler Objekte und ResourceSync zur Synchronisation von Ressourcenbeständen. Unterstützt wurde die OAI unter anderem von der Digital Library Federation und der Coalition for Networked Information.
