Gedächtnislosigkeit

Als Gedächtnislosigkeit (englisch memorylessness) bezeichnet man in der Wahrscheinlichkeitstheorie eine Eigenschaft bestimmter Wahrscheinlichkeitsverteilungen: Die Verteilung der restlichen Wartezeit auf ein Ereignis hängt nicht davon ab, wie lange bereits gewartet wurde.

Definition

Eine stetige Zufallsvariable X ist gedächtnislos, wenn für alle s, t ≥ 0 gilt: P(X > s + t | X > s) = P(X > t). Die einzige stetige Verteilung mit dieser Eigenschaft ist die Exponentialverteilung. Das diskrete Gegenstück ist die geometrische Verteilung, die ebenfalls gedächtnislos ist.

Bedeutung

Die Gedächtnislosigkeit ist das kennzeichnende Merkmal von Poisson-Prozessen: Die Wartezeit auf das nächste Ereignis ist unabhängig von der Vergangenheit. Sie wird unter anderem in der Warteschlangentheorie, der Zuverlässigkeitstheorie und der Modellierung radioaktiver Zerfälle verwendet. Anschaulich bedeutet sie, dass ein „alterungsfreies" System nicht „verschleißt" – eine bereits lange laufende Komponente hat dieselbe Restlebensdauerverteilung wie eine neue.
