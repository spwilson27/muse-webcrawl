Asynchronous I/O

Asynchronous I/O (asynchrone Ein-/Ausgabe, kurz AIO) ist ein Konzept der Informatik, bei dem Ein- und Ausgabeoperationen nicht-blockierend ausgeführt werden: Ein Prozess stößt eine Operation an und läuft weiter, während die Operation im Hintergrund abläuft. Nach Abschluss wird das Programm über das Ergebnis benachrichtigt.

Geschichte und Implementierungen

Der POSIX-Standard definiert mit der aio-Schnittstelle (aio_read, aio_write) eine asynchrone Ein-/Ausgabe für Unix-ähnliche Systeme. Unter Linux existieren zusätzlich die native Schnittstelle libaio sowie seit Kernel 5.1 das leistungsfähige Framework io_uring. Windows stellt mit den Completion Ports ein vergleichbares Modell bereit.

Vorteile

Asynchrone I/O vermeidet blockierte Threads und ermöglicht es Anwendungen, sehr viele parallele Operationen – etwa Netzwerkverbindungen oder Dateizugriffe – mit wenigen Threads zu bedienen. Sie bildet die Grundlage reaktiver Systeme und moderner Ereignisschleifen.
