Speicherschutz

Als Speicherschutz (englisch memory protection) bezeichnet man Verfahren in Computersystemen, die verhindern, dass ein Prozess auf Speicherbereiche zugreift, die ihm nicht zugewiesen sind. Speicherschutz ist eine Grundvoraussetzung für Stabilität und Sicherheit moderner Mehrprogramm-Betriebssysteme: Ein fehlerhaftes oder bösartiges Programm kann so weder andere Programme noch das Betriebssystem selbst beschädigen.

Verfahren

Der Speicherschutz wird in der Regel von der Memory Management Unit (MMU) durchgesetzt. Jeder Speicherbereich erhält Schutzattribute, die erlauben oder verbieten, dass aus dem Benutzer- oder Kernmodus gelesen, geschrieben oder ausgeführt wird. Moderne Ergänzungen sind das NX-Bit (No Execute), das die Ausführung von Code aus Datenseiten verhindert, sowie ASLR (Address Space Layout Randomization), das die Speicherorte zufällig anordnet und Angriffe erschwert.

Verletzungen

Verstößt ein Programm gegen den Speicherschutz, beendet das Betriebssystem den Prozess – unter Unix mit einem Segmentation Fault (SIGSEGV), unter Windows mit einer Zugriffsverletzung (Access Violation).
