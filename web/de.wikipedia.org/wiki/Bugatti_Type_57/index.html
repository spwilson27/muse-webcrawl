Der Bugatti Type 57 ist ein Oberklasse-Automobil des französischen Herstellers Bugatti, das von 1934 bis 1940 gebaut wurde. Das von Jean Bugatti entworfene Modell gilt als Höhepunkt der Vorkriegs-Baureihen der Marke. Insgesamt entstanden rund 710 Exemplare.

Technik

Der Type 57 besaß einen 3,3 Liter großen Reihenachtzylinder mit zwei obenliegenden Nockenwellen, der in der Basisversion 135 PS leistete. Das Fahrgestell wurde mit verschiedenen Werks- und Karosseriebauer-Aufbauten versehen, darunter die Bezeichnungen Galibier, Ventoux, Stelvio und Atalante.

Varianten

Der Type 57S (französisch surbaissé für „abgesenkt") hatte ein niedrigeres Fahrgestell und leistete 175 PS. Auf ihm basierte der berühmte Type 57 SC Atlantic mit genieteter Rückenflosse, von dem nur vier Exemplare entstanden. Der Type 57G Tank gewann 1937 das 24-Stunden-Rennen von Le Mans, der Type 57C Tank 1939.

Bedeutung

Der Type 57 Atlantic zählt zu den wertvollsten Sammlerautomobilen der Welt. Der Type 57 war das letzte große Modell der Marke vor dem Zweiten Weltkrieg; nach dem Tod Jean Bugattis 1939 und Ettore Bugattis 1947 kam die Produktion nicht wieder in Gang.
