Satz von Brooks

Der Satz von Brooks ist ein Lehrsatz der Graphentheorie, der eine obere Schranke für die chromatische Zahl eines Graphen in Abhängigkeit von seinem Maximalgrad angibt. Er wurde 1941 von dem englischen Mathematiker Rowland Leonard Brooks veröffentlicht.

Aussage

Für jeden zusammenhängenden Graphen G, der weder ein vollständiger Graph noch ein Kreis ungerader Länge ist, gilt: Die chromatische Zahl χ(G) ist höchstens so groß wie der Maximalgrad Δ(G). Für die beiden Ausnahmefälle gilt dagegen χ(G) = Δ(G) + 1: Ein vollständiger Graph mit n Knoten benötigt n Farben, und ein ungerader Kreis benötigt drei Farben, obwohl sein Maximalgrad nur zwei beträgt.

Bedeutung

Die triviale Schranke für die Färbung eines Graphen lautet χ(G) ≤ Δ(G) + 1, da ein gieriger Färbungsalgorithmus in beliebiger Reihenfolge nie mehr als Δ(G) + 1 Farben benötigt. Der Satz von Brooks verbessert diese Schranke für fast alle Graphen um eins. Beweise des Satzes werden häufig induktiv oder über die Anordnung der Knoten geführt; eine bekannte einfache Beweisführung stammt von László Lovász.
