NX-Bit

Das NX-Bit (No-Execute-Bit), bei Intel als XD-Bit (Execute-Disable-Bit) bezeichnet, ist eine Prozessorfunktion zur Speichersicherheit. Es kennzeichnet Speicherseiten, deren Inhalt nicht als Programmcode ausgeführt werden darf.

Funktionsweise

In den Seitentabellen moderner Prozessoren ist pro Speicherseite ein zusätzliches Attributbit vorgesehen. Ist es gesetzt, löst der Versuch, Code von dieser Seite auszuführen (zum Beispiel aus dem Stack oder Heap), einen Schutzfehler aus. Das Betriebssystem markiert damit alle reinen Datenbereiche als nicht ausführbar.

Sicherheitsnutzen

Das NX-Bit erschwert klassische Pufferüberlauf-Angriffe, bei denen eingeschleuster Code ausgeführt werden soll. Es ist eine Voraussetzung für die Data Execution Prevention (DEP) unter Windows und vergleichbare Verfahren unter Linux. Vollständigen Schutz bietet es nicht: Angriffe wie Return-Oriented Programming (ROP), die vorhandenen Code umnutzen, werden nicht verhindert, weshalb weitere Maßnahmen wie ASLR kombiniert werden.

Verbreitung

AMD führte das Bit 2003 mit der AMD64-Architektur ein, Intel folgte mit XD in späteren Pentium-4- und Itanium-Modellen. Auch ARM-Prozessoren kennen ein entsprechendes Attribut (XN, Execute Never).
