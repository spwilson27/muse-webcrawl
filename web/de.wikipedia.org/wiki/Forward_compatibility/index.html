Vorwärtskompatibilität

Vorwärtskompatibilität (englisch forward compatibility) bezeichnet die Eigenschaft eines Systems, Eingaben oder Datenformate zu akzeptieren, die für eine spätere, erweiterte Version des Systems erstellt wurden. Ein vorwärtskompatibles Programm kann neuere Dateiformate zumindest teilweise verarbeiten, ohne abzustürzen.

Techniken

Vorwärtskompatibilität wird unter anderem erreicht, indem unbekannte Elemente in Datenformaten ignoriert statt als Fehler behandelt werden, Erweiterungen über versionierte Schemata eingeführt werden und optionale Felder vorgesehen sind. Beispiele sind HTML-Browser, die unbekannte Tags ignorieren, oder XML-Formate mit Erweiterungsmechanismen.

Abgrenzung

Das Gegenstück ist die Abwärtskompatibilität: Ein neues System verarbeitet Daten und Programme seiner Vorgänger. Während Abwärtskompatibilität durch Tests gegen die alte Version direkt überprüfbar ist, erfordert Vorwärtskompatibilität vorausschauende Designentscheidungen.
