PouchDB

PouchDB ist eine freie, in JavaScript geschriebene NoSQL-Datenbank, die im Webbrowser läuft und Daten lokal speichert. Sie ist vom dokumentenorientierten Datenbanksystem Apache CouchDB inspiriert und mit diesem über dessen Replikationsprotokoll kompatibel.

Eigenschaften

PouchDB nutzt im Browser die Speichertechnologien IndexedDB (und früher WebSQL) und speichert Dokumente als JSON. Das zentrale Konzept ist die bidirektionale Synchronisation („Replikation") mit einer CouchDB-Instanz auf einem Server, sodass Anwendungen auch offline arbeiten und ihre Daten bei Wiederherstellung der Verbindung abgleichen können. Konflikte werden dabei über Revisionsbäume der Dokumente aufgelöst.

Verwendung

PouchDB wird für Offline-first-Webanwendungen eingesetzt, etwa in Regionen mit unzuverlässiger Internetverbindung oder für Progressive Web Apps. Die Bibliothek steht unter der Apache-Lizenz 2.0 und kann auch unter Node.js betrieben werden.
