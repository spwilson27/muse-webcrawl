Tschebyscheff-Ungleichung

Die Tschebyscheff-Ungleichung (englisch Chebyshev's inequality) ist eine Ungleichung der Wahrscheinlichkeitstheorie, benannt nach dem russischen Mathematiker Pafnuti Lwowitsch Tschebyscheff. Sie gibt eine obere Schranke für die Wahrscheinlichkeit an, dass eine Zufallsvariable um mehr als einen vorgegebenen Betrag von ihrem Erwartungswert abweicht, und benötigt dafür nur die Kenntnis der Varianz.

Aussage

Sei X eine Zufallsvariable mit endlichem Erwartungswert μ und endlicher Varianz σ² > 0. Dann gilt für jedes ε > 0:

P(|X − μ| ≥ ε) ≤ σ² / ε²

Äquivalent dazu: Für jedes k > 0 ist die Wahrscheinlichkeit, dass X um mehr als das k-fache der Standardabweichung vom Erwartungswert abweicht, höchstens 1/k². So liegen beispielsweise mindestens 75 % der Werte innerhalb von zwei Standardabweichungen um den Mittelwert, und zwar für jede beliebige Verteilung mit endlicher Varianz.

Beweisidee

Die Ungleichung folgt unmittelbar aus der Markow-Ungleichung, angewandt auf die nichtnegative Zufallsvariable (X − μ)². Tschebyscheff selbst veröffentlichte die Ungleichung 1867; eine allgemeinere Version war bereits 1853 von Irénée-Jules Bienaymé angegeben worden, weshalb sie gelegentlich auch Bienaymé-Tschebyscheff-Ungleichung heißt.

Anwendungen

Die Tschebyscheff-Ungleichung ist ein grundlegendes Werkzeug der Stochastik. Mit ihrer Hilfe beweist man unter anderem das schwache Gesetz der großen Zahlen. Obwohl die Schranke in der Regel nicht scharf ist, ist sie universell gültig, ohne dass Annahmen über die Gestalt der Verteilung nötig wären.
