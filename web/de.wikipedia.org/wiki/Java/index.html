Java

Java (indonesisch Jawa) ist eine der Großen Sundainseln Indonesiens und die bevölkerungsreichste Insel der Erde. Auf einer Fläche von etwa 138.000 Quadratkilometern leben rund 150 Millionen Menschen. Auf Java liegt die indonesische Hauptstadt Jakarta.

Geografie

Die Insel erstreckt sich über etwa 1000 Kilometer in West-Ost-Richtung. Eine Kette von über 40 Vulkanen durchzieht die Insel; der höchste ist der Semeru mit 3676 Metern. Trotz der vulkanischen Gefahren sind die Böden äußerst fruchtbar, sodass Java zu den am dichtesten besiedelten Regionen der Welt zählt.

Geschichte

Java war Zentrum bedeutender hinduistisch-buddhistischer Reiche wie Mataram und Majapahit, deren Baudenkmäler, etwa Borobudur und Prambanan, zum UNESCO-Welterbe gehören. Ab dem 17. Jahrhundert wurde die Insel von der Niederländischen Ostindien-Kompanie und später vom niederländischen Kolonialstaat beherrscht. Die Bevölkerung spricht überwiegend Javanisch, Sundanesisch und Indonesisch.
