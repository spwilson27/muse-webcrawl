Wendepunkt

Ein Wendepunkt (englisch inflection point) ist ein Punkt auf dem Graphen einer Funktion, an dem der Graph sein Krümmungsverhalten ändert: Er geht von einer Linkskrümmung in eine Rechtskrümmung über oder umgekehrt. Anschaulich wechselt die Kurve dort von einer „Linkskurve“ in eine „Rechtskurve“ wie bei einer S-förmigen Straße.

Bedingungen

Für eine zweimal differenzierbare Funktion ist an einem Wendepunkt die zweite Ableitung gleich null (notwendige Bedingung: f″(x) = 0). Das allein genügt jedoch nicht; hinreichend ist ein Vorzeichenwechsel der zweiten Ableitung, was sich oft über die dritte Ableitung prüfen lässt: Gilt f″(x₀) = 0 und f‴(x₀) ≠ 0, so liegt an der Stelle x₀ ein Wendepunkt vor. Ein Wendepunkt mit waagerechter Tangente heißt Sattelpunkt (Terrassenpunkt).

Beispiel

Die Funktion f(x) = x³ hat an der Stelle x = 0 einen Wendepunkt (mit waagerechter Tangente), denn links davon ist der Graph rechtsgekrümmt, rechts davon linksgekrümmt. Wendepunkte spielen bei der Kurvendiskussion eine zentrale Rolle, etwa bei der Bestimmung von Bereichen, in denen eine Funktion konvex oder konkav ist.
