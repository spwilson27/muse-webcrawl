Kurvenintegral (Line integral)

Ein Kurvenintegral (auch Linien- oder Wegintegral, englisch line integral) ist in der Analysis ein Integral, dessen Integrationsbereich eine Kurve im Raum ist. Man unterscheidet das Kurvenintegral über ein Skalarfeld, das etwa zur Berechnung der Länge oder Masse eines Drahtes dient, und das Kurvenintegral über ein Vektorfeld, das unter anderem die von einer Kraft entlang eines Weges verrichtete Arbeit beschreibt.

Kurvenintegral über ein Skalarfeld

Ist die Kurve durch r(t) mit a ≤ t ≤ b parametrisiert und f ein Skalarfeld, so lautet das Integral: ∫ f(r(t)) |r′(t)| dt. Es ist unabhängig von der Parametrisierung und von der Durchlaufrichtung der Kurve.

Kurvenintegral über ein Vektorfeld

Für ein Vektorfeld F lautet das Integral ∫ F(r(t)) · r′(t) dt. Es hängt im Allgemeinen vom Weg ab. Unabhängig vom Weg ist es genau dann, wenn das Feld ein Gradientenfeld ist; dann über geschlossene Kurven ist der Wert null. Für ebene Felder verbindet der Satz von Green das Kurvenintegral über eine geschlossene Kurve mit einem Gebietsintegral über die eingeschlossene Fläche.
