Linux (Kernel)

Linux-Kernel
Entwickler: weltweite Gemeinschaft, leitend Linus Torvalds
Erstveröffentlichung: 17. September 1991 (Version 0.01)
Programmiersprachen: überwiegend C, daneben Assembler und Rust
Lizenz: GNU GPL v2
Kerneltyp: monolithisch, modular

Der Linux-Kernel ist der Betriebssystemkern des freien Betriebssystems Linux. Er wurde 1991 von Linus Torvalds ins Leben gerufen und wird seither von einer weltweiten Gemeinschaft aus Tausenden von Entwicklern – viele davon bei Technologieunternehmen angestellt – weiterentwickelt. Der Kernel steuert die Hardware, verwaltet Prozesse, Speicher und Dateisysteme und bildet damit das Herzstück jeder Linux-Distribution sowie des Betriebssystems Android.

Geschichte

Torvalds begann die Entwicklung als Student an der Universität Helsinki auf einem PC mit Intel-386-Prozessor, zunächst inspiriert vom Lehrbetriebssystem Minix. Die Version 0.01 vom September 1991 umfasste nur etwa 10.000 Zeilen Code. Mit der Freigabe unter der GNU General Public License (Version 0.12, 1992) setzte eine rasche, kollaborative Weiterentwicklung ein. Meilensteine waren Version 1.0 (1994), 2.0 mit Mehrprozessorunterstützung (1996), 2.6 (2003) sowie die Umstellung auf jahrbasierte Hauptnummern ab 3.0 (2011), 4.0 (2015) und 5.0 (2019); Version 6.0 erschien 2022. Der Kernel ist auf über 30 Millionen Zeilen Code angewachsen.

Technik

Linux ist ein monolithischer Kernel, der jedoch Gerätetreiber und weitere Funktionen als Module zur Laufzeit laden kann. Er unterstützt eine außergewöhnlich große Zahl von Hardwarearchitekturen, zahlreiche Dateisysteme, Netzwerkprotokolle und Sicherheitsmechanismen wie die Linux Security Modules. Seit Kernel 6.1 wird neben C auch die Programmiersprache Rust offiziell für Kernelcode zugelassen.

Entwicklungsmodell

Neue Hauptversionen erscheinen etwa alle neun bis zehn Wochen nach einem zweistufigen Verfahren aus Merge Window und Stabilisierungsphase. Einzelne Versionen erhalten als „longterm“-Kernel mehrere Jahre lang Pflege. Über die Annahme aller Änderungen entscheidet letztlich Linus Torvalds; die Subsysteme werden von Maintainern betreut. Koordiniert und finanziert wird ein Teil der Kernarbeit durch die Linux Foundation.
