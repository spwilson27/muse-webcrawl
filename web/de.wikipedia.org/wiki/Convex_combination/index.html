Konvexkombination

Eine Konvexkombination ist in der Mathematik eine spezielle Linearkombination, bei der alle Koeffizienten nichtnegativ sind und sich zu Eins summieren. Konvexkombinationen spielen eine zentrale Rolle in der konvexen Geometrie und der konvexen Optimierung.

Definition

Gegeben seien Punkte x1, …, xn in einem reellen Vektorraum. Eine Konvexkombination dieser Punkte ist ein Punkt der Form

λ1x1 + … + λnxn,

wobei die reellen Zahlen λi die Bedingungen λi ≥ 0 und λ1 + … + λn = 1 erfüllen.

Eigenschaften

Eine Menge ist genau dann konvex, wenn sie unter Bildung von Konvexkombinationen abgeschlossen ist, das heißt, wenn jede Konvexkombination von Punkten der Menge wieder in der Menge liegt. Der Durchschnitt aller konvexen Mengen, die eine gegebene Punktmenge enthalten, heißt deren konvexe Hülle; sie besteht genau aus allen Konvexkombinationen der Punkte.

Spezialfälle sind der Mittelpunkt zweier Punkte (λ1 = λ2 = ½) und der Schwerpunkt eines Dreiecks (alle Gewichte gleich ⅓). Konvexkombinationen aus zwei Punkten füllen genau die Verbindungsstrecke der beiden Punkte aus.
