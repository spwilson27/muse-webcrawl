C (Programmiersprache)

C ist eine imperative, prozedurale Programmiersprache, die Anfang der 1970er Jahre von Dennis Ritchie bei den Bell Laboratories entwickelt wurde. Sie diente ursprünglich der Implementierung des Betriebssystems Unix und ist bis heute eine der einflussreichsten und am weitesten verbreiteten Programmiersprachen.

Geschichte

C ging aus der Sprache B hervor und wurde zwischen 1969 und 1973 entwickelt. 1978 erschien das einflussreiche Buch The C Programming Language von Brian Kernighan und Dennis Ritchie („K&R C“). 1989/1990 wurde die Sprache als ANSI C bzw. ISO C standardisiert; weitere Standardversionen sind C99, C11, C17 und C23.

Eigenschaften

C erlaubt hardwarenahe Programmierung, direkte Speicherzugriffe über Zeiger und eine effiziente Übersetzung in Maschinencode. Die Sprache ist vergleichsweise klein, bietet aber kaum eingebaute Abstraktionen. Zahlreiche Sprachen wie C++, C#, Java und Objective-C übernahmen Syntax und Konzepte von C.

Anwendung

C wird vor allem für Betriebssysteme, eingebettete Systeme, Compiler und leistungskritische Software eingesetzt. Der Linux-Kernel und große Teile vieler Betriebssysteme sind in C geschrieben.
