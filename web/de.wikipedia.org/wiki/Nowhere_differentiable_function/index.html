Nirgendwo differenzierbare Funktion

Eine nirgendwo differenzierbare Funktion ist eine reellwertige Funktion, die überall stetig, aber an keiner Stelle differenzierbar ist. Die Existenz solcher Funktionen widersprach lange der mathematischen Anschauung, wonach stetige Funktionen „im Allgemeinen" glatt seien.

Geschichte

Bernard Bolzano gab um 1830 ein erstes Beispiel an, das jedoch unveröffentlicht blieb. Berühmt wurde die von Karl Weierstraß 1872 vorgestellte Weierstraß-Funktion, eine unendliche Reihe aus Kosinusfunktionen, deren Graph eine fraktale Struktur besitzt. Weitere Beispiele stammen von Stefan Banach, Stefan Mazurkiewicz und Hardy.

Weierstraß-Funktion

Die Weierstraß-Funktion ist definiert als f(x) = Σ an cos(bn πx) mit 0 < a < 1 und einer ungeraden natürlichen Zahl b, sodass ab > 1 + 3π/2 gilt. Sie ist überall stetig, aber nirgends differenzierbar.

Eigenschaften

Die Menge der nirgendwo differenzierbaren Funktionen ist im Raum der stetigen Funktionen im Sinne der Baireschen Kategorie „groß": Die typische stetige Funktion ist nirgendwo differenzierbar. Der Graph einer solchen Funktion hat typischerweise eine nichtganzzahlige Hausdorff-Dimension und weist auf jeder Skala Oszillationen auf.
