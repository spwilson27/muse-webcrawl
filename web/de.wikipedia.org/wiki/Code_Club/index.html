Code Club

Code Club ist eine internationale, ehrenamtlich getragene Initiative, die Kindern im Alter von etwa 9 bis 13 Jahren in kostenlosen Nachmittagskursen Grundkenntnisse des Programmierens vermittelt. Sie wurde 2012 im Vereinigten Königreich gegründet und ist heute Teil der Raspberry Pi Foundation.

Konzept

Die Clubs finden in Schulen, Bibliotheken und Gemeindezentren statt und werden von Freiwilligen geleitet. Anhand vorgefertigter Lernprojekte arbeiten die Kinder mit Programmiersprachen und Werkzeugen wie Scratch, HTML/CSS, Python und Mikrocontrollern wie dem micro:bit.

Verbreitung

Nach dem Start in Großbritannien breitete sich Code Club auf zahlreiche Länder aus; weltweit existieren viele Tausend Clubs. 2017 schloss sich Code Club mit der Raspberry Pi Foundation zusammen.
