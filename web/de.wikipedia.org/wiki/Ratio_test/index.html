Quotientenkriterium

Das Quotientenkriterium (englisch ratio test) ist ein Konvergenzkriterium der Analysis, mit dem sich die Konvergenz oder Divergenz einer Reihe mit positiven oder betragsmäßig betrachteten Gliedern untersuchen lässt. Es geht auf Jean-Baptiste le Rond d’Alembert zurück, der es 1768 veröffentlichte.

Aussage

Gegeben sei eine Reihe ∑ an mit an ≠ 0. Man betrachte den Quotienten aufeinanderfolgender Glieder und dessen Grenzwert:

L = lim |an+1 / an|

  • Ist L < 1, so konvergiert die Reihe absolut.
  • Ist L > 1 (oder divergiert der Quotient gegen unendlich), so divergiert die Reihe.
  • Ist L = 1, so lässt das Kriterium keine Aussage zu; die Reihe kann konvergent oder divergent sein.

Anwendungsbereich

Das Quotientenkriterium eignet sich besonders für Reihen, deren Glieder Fakultäten, Exponentialterme oder Produkte enthalten, etwa Potenzreihen. Bei einer Potenzreihe liefert es zugleich eine Formel für den Konvergenzradius. Es ist schwächer als das Wurzelkriterium: Liefert das Quotientenkriterium eine Entscheidung, so auch das Wurzelkriterium, aber nicht umgekehrt.

Versagt das Kriterium (L = 1), müssen andere Kriterien herangezogen werden, etwa das Verdichtungskriterium, das Integralkriterium oder feinere Kriterien wie das Kriterium von Raabe.

Beispiel

Für die geometrische Reihe mit Folgengliedern qn ist der Quotient konstant gleich |q|; die Reihe konvergiert daher für |q| < 1 und divergiert für |q| > 1 — genau das Ergebnis, das auch die explizite Summenformel liefert.
