Games Done Quick

Games Done Quick (GDQ) ist eine US-amerikanische Veranstaltungsreihe von Speedrun-Marathons, deren Einnahmen wohltätigen Zwecken zugutekommen. Speedrunner spielen Videospiele vor Publikum und im Livestream in möglichst kurzer Zeit durch, während Zuschauer Spenden abgeben können.

Veranstaltungen

Die beiden Hauptveranstaltungen sind Awesome Games Done Quick (AGDQ) im Januar, deren Erlöse an die Prevent Cancer Foundation gehen, und Summer Games Done Quick (SGDQ) im Sommer zugunsten von Ärzte ohne Grenzen (Médecins Sans Frontières). Daneben existieren kleinere Formate wie Games Done Quick Express und die Online-Reihe Frame Fatales.

Geschichte

Das erste Event fand 2010 unter dem Namen Classic Games Done Quick statt und sammelte rund 10.000 US-Dollar. Seitdem wuchsen Zuschauerzahlen und Spendensummen stetig; einzelne Veranstaltungen überschritten wiederholt die Marke von drei Millionen US-Dollar. Insgesamt wurden über die Jahre mehr als 50 Millionen US-Dollar für wohltätige Organisationen gesammelt.

Ablauf

Die Marathons dauern jeweils etwa eine Woche und laufen rund um die Uhr. Spenden können mit Kommentaren verbunden werden, die vorgelesen werden, und schalten zusätzliche Spielinhalte oder Show-Einlagen frei, wenn bestimmte Spendenziele erreicht werden.
