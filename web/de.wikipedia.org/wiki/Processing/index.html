Processing (Programmiersprache)

Processing ist eine freie Programmiersprache und Entwicklungsumgebung für visuelle Kunst, interaktive Medien und kreatives Programmieren. Sie wurde 2001 von Casey Reas und Ben Fry am MIT Media Lab entwickelt und baut auf Java auf.

Sprache und Umgebung

Processing verwendet eine vereinfachte, Java-ähnliche Syntax. Ein typisches Programm („Sketch") besteht aus einer setup-Funktion, die einmal läuft, und einer draw-Funktion, die wiederholt aufgerufen wird und so Animationen erzeugt. Die Sprache bietet eingebaute Funktionen zum Zeichnen von Formen, Farben, Bildern, 3D-Grafik, Klang und Netzwerk. Die Entwicklungsumgebung ist bewusst einfach gehalten, um Anfängern den Zugang zum Programmieren zu erleichtern.

Verwendung

Verwendung findet Processing in der Mediengestaltung, in der generativen Kunst, in der Datenvisualisierung, im Design und in der Ausbildung. Zahlreiche freie Bibliotheken erweitern die Sprache, etwa für 3D-Rendering, Video und Sound. Eine JavaScript-Umsetzung, p5.js, überträgt das Konzept ins Web; eine Python-Variante existiert ebenfalls.

Geschichte

Processing entstand als Weiterentwicklung des Design-by-Numbers-Projekts von John Maeda. Seit 2001 wird die Software als Open Source gepflegt und von der Processing Foundation betreut. Sie gilt als einflussreiches Werkzeug der Creative-Coding-Bewegung und wird weltweit an Schulen und Hochschulen eingesetzt.
