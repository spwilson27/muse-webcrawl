Kette (Ordnungstheorie)

Eine Kette (englisch chain) ist in der Ordnungstheorie eine Teilmenge einer halbgeordneten Menge, in der je zwei Elemente miteinander vergleichbar sind. Eine Kette ist also eine bezüglich der gegebenen Ordnung total geordnete Teilmenge. Das Gegenstück ist die Antikette, in der keine zwei verschiedenen Elemente vergleichbar sind.

Definition und Beispiele

Ist (P, ≤) eine Halbordnung, so heißt eine Teilmenge C ⊆ P eine Kette, wenn für alle x, y ∈ C gilt: x ≤ y oder y ≤ x. Beispielsweise bilden in der durch die Teilerrelation geordneten Menge der natürlichen Zahlen die Potenzen einer Zahl, etwa {1, 2, 4, 8, 16, …}, eine Kette. In der Potenzmenge einer Menge, geordnet durch Inklusion, ist jede Familie ineinander geschachtelter Mengen eine Kette.

Bedeutung

Ketten spielen eine zentrale Rolle im Lemma von Zorn, das besagt, dass jede nichtleere halbgeordnete Menge, in der jede Kette eine obere Schranke besitzt, ein maximales Element enthält. Die Länge der längsten Kette einer endlichen Halbordnung wird als ihre Höhe bezeichnet; der Satz von Mirsky und der Satz von Dilworth verknüpfen Ketten- und Antikettenzerlegungen mit der Struktur endlicher Ordnungen. Auch der Begriff der aufsteigenden beziehungsweise absteigenden Kettenbedingung in Algebra und Ringtheorie beruht auf diesem Konzept.
