Beleuchtungsproblem

Das Beleuchtungsproblem (englisch illumination problem) ist ein klassisches Problem der Geometrie, das auf Ernst Straus in den 1950er-Jahren zurückgeht. Es fragt, ob ein Raum, dessen Wände aus Spiegeln bestehen, von einer einzelnen punktförmigen Lichtquelle aus immer vollständig ausgeleuchtet wird.

Geschichte

1966 zeigte Victor Klee, dass die Antwort für bestimmte gekrümmte Räume negativ ausfällt. Für polygonale Räume gelang Roger Penrose 1958 mit einem Raum aus elliptischen Bögen ein Gegenbeispiel. Erst 1995 konstruierte George Tokarsky einen polygonalen Raum mit 26 Seiten, der einen Punkt enthält, von dem aus ein anderer Punkt nicht beleuchtet werden kann; 1997 fand David Castro eine einfachere Variante mit 24 Seiten. Der unbeleuchtete Bereich beruht darauf, dass Lichtstrahlen in den elliptischen bzw. polygonalen Nischen so reflektiert werden, dass bestimmte Ecken stets im Schatten bleiben.

Verwandte Probleme

Verwandt ist das vom Hugo Steinhaus zugeschriebene Wachmannproblem (Art-Gallery-Problem): Wie viele Wachen sind nötig, um eine polygonale Kunstgalerie vollständig zu überwachen? Václav Chvátal zeigte 1975, dass ⌊n/3⌋ Wachen für ein Polygon mit n Ecken stets ausreichen.
