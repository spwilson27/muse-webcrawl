Medientyp

Ein Medientyp (englisch media type, früher auch MIME-Typ genannt) ist eine standardisierte Kennzeichnung, die das Format und die Art von Daten beschreibt. Medientypen werden vor allem im Internet verwendet, etwa im HTTP-Protokoll, in E-Mails und in Dateisystemen, damit Programme Inhalte korrekt interpretieren und darstellen können.

Aufbau

Ein Medientyp besteht aus einem Haupttyp und einem Untertyp, getrennt durch einen Schrägstrich, zum Beispiel text/html, image/png oder application/json. Die wichtigsten Haupttypen sind text, image, audio, video, application, multipart und font. Zusätzlich können Parameter wie die Zeichenkodierung (charset=UTF-8) angegeben werden.

Registrierung

Die Registrierung offizieller Medientypen erfolgt bei der Internet Assigned Numbers Authority (IANA). Neben dem Standardbaum existieren ein Herstellerbaum (mit dem Präfix vnd.), ein persönlicher Baum (prs.) sowie der experimentelle Baum (x-).

Verwendung

Webserver senden den Medientyp einer Datei im HTTP-Header Content-Type an den Browser. Dieser entscheidet anhand der Angabe, ob er den Inhalt selbst anzeigt oder ein Hilfsprogramm startet. Auch in HTML und CSS spielen Medientypen eine Rolle, etwa bei der Auswahl von Stylesheets für unterschiedliche Ausgabemedien (Bildschirm, Druck, Sprache).
