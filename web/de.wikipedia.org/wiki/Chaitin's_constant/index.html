Chaitinsche Konstante

Die Chaitinsche Konstante Ω (Omega), benannt nach Gregory Chaitin, ist eine reelle Zahl aus der algorithmischen Informationstheorie. Sie gibt die Wahrscheinlichkeit an, dass ein zufällig erzeugtes Programm auf einer universellen, präfixfreien Turingmaschine anhält (Haltewahrscheinlichkeit).

Definition

Für eine universelle präfixfreie Maschine U ist

ΩU = Σp: U(p) hält 2−|p|,

wobei über alle Programme p summiert wird, die anhalten, und |p| deren Länge in Bits bezeichnet. Wegen der Präfixfreiheit konvergiert die Summe nach dem Satz von Kraft zu einem Wert zwischen 0 und 1; Ω hängt von der gewählten Maschine U ab, seine wesentlichen Eigenschaften jedoch nicht.

Eigenschaften

  • Unberechenbarkeit: Ω ist nicht berechenbar; aus den ersten n Bits von Ω ließe sich das Halteproblem für alle Programme bis zur Länge n lösen.
  • Algorithmische Zufälligkeit: Ω ist Martin-Löf-zufällig – seine Binärstellen sind inkompressibel; die ersten n Bits tragen n Bits an Information.
  • Normalität: Ω ist eine normale Zahl, jede Ziffernfolge kommt mit der statistisch erwarteten Häufigkeit vor.
  • Calude und Mitarbeiter berechneten für eine konkrete Programmiersprache die ersten 64 Bits einer Variante von Ω.

Bedeutung

Chaitin interpretierte Ω als „die“ mathematische Konstante der Unentscheidbarkeit: Ihr Stellenwert zeigt, dass große Teile der Mathematik auf algorithmisch zufälligen, nicht weiter begründbaren Fakten beruhen können, was an Gödels Unvollständigkeitssätze anschließt.
