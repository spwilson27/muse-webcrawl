Acht-Punkte-Algorithmus

Der Acht-Punkte-Algorithmus ist ein Verfahren der Bildverarbeitung (Computer Vision) zur Schätzung der Fundamentalmatrix aus Punktkorrespondenzen zweier Kamerabilder. Er wurde 1981 von H. Christopher Longuet-Higgins beschrieben.

Verfahren

Für jedes korrespondierende Punktepaar (x, x′) der beiden Bilder gilt die Epipolargleichung x′T F x = 0, die linear in den Einträgen der Fundamentalmatrix F ist. Aus acht (oder mehr) Punktkorrespondenzen entsteht ein homogenes lineares Gleichungssystem, dessen Lösung über eine Singulärwertzerlegung gewonnen wird. Anschließend wird die Rang-2-Eigenschaft von F erzwungen, indem der kleinste Singulärwert auf null gesetzt wird.

Normalisierte Variante

Richard Hartley zeigte 1997, dass eine vorgeschaltete Normalisierung der Bildkoordinaten (Translation und Skalierung) die numerische Kondition entscheidend verbessert; diese normalisierte Variante ist heute der Standard und Grundlage vieler Verfahren zur Kamerakalibrierung und 3D-Rekonstruktion.
