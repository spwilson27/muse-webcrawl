Geschichte von Microsoft Windows

Die Geschichte von Microsoft Windows beschreibt die Entwicklung des Betriebssystems Windows von einer grafischen Erweiterung für MS-DOS (1985) zum weltweit dominierenden Betriebssystem für Personal Computer.

Anfänge (1985–1992)

Windows 1.0 erschien 1985 als grafische Benutzeroberfläche für MS-DOS; Fenster konnten nur nebeneinander angeordnet werden. Windows 2.0 (1987) führte überlappende Fenster ein. Der Durchbruch gelang mit Windows 3.0 (1990) und 3.1 (1992), die Millionen Mal verkauft wurden und den PC auf dem Massenmarkt etablierten.

Windows 95 bis Windows XP

Windows 95 (1995) brachte Startmenü, Taskleiste und den Internet Explorer mit und wurde zu einem Medienereignis. Daneben entwickelte Microsoft mit der NT-Linie ein modernes 32-Bit-System für Unternehmen. Windows XP (2001) vereinigte beide Linien und wurde über Jahre das verbreitetste Betriebssystem der Welt.

Vom Vista zum Windows 10

Windows Vista (2007) wurde wegen hoher Hardwareanforderungen kritisiert, Windows 7 (2009) dagegen gut aufgenommen. Windows 8 (2012) setzte auf Touch-Bedienung und entfernte das klassische Startmenü, was vielen Anwendern missfiel. Windows 10 (2015) kehrte zum Startmenü zurück und wurde als laufend aktualisierter Dienst („Windows as a Service“) vermarktet. Windows 11 folgte 2021 mit überarbeiteter Oberfläche und höheren Sicherheitsanforderungen.
