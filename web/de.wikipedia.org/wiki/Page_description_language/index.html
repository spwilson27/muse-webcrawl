Seitenbeschreibungssprache

Eine Seitenbeschreibungssprache (englisch page description language, PDL) ist eine formale Sprache zur Beschreibung des Erscheinungsbildes einer Druckseite – also der Position und Darstellung von Text, Vektorgrafiken und Bildern – auf einer abstrakten, geräteunabhängigen Ebene. Ein Interpreter im Drucker oder in einer Raster-Image-Prozessor-Software setzt die Beschreibung in ein konkretes Rasterbild um.

Bekannte Sprachen

  • PostScript – 1982–1984 von Adobe entwickelt, eine vollwertige, Turing-vollständige Programmiersprache auf Stapelbasis. PostScript begründete zusammen mit dem Apple LaserWriter das Desktop Publishing.
  • PDF (Portable Document Format) – von Adobe 1993 eingeführt; baut auf dem Grafikmodell von PostScript auf, verzichtet aber auf Programmierbarkeit zugunsten eines festen Dokumentenformats.
  • PCL (Printer Command Language) – von Hewlett-Packard für die eigenen Drucker entwickelt, einfacher und stärker geräteorientiert als PostScript.
  • XPS/OpenXPS – von Microsoft als PDF-Alternative eingeführt, basiert auf XML.
  • SVG – beschreibt zweidimensionale Vektorgrafiken in XML und wird auch für den Druck verwendet.

Eigenschaften

Seitenbeschreibungssprachen arbeiten auflösungsunabhängig: Linien, Zeichen und Formen werden geometrisch beschrieben und erst bei der Ausgabe in der jeweiligen Geräteauflösung gerastert. Dadurch bleibt die Ausgabequalität auf verschiedenen Druckern gleich und hochwertige Typografie wird möglich. Viele PDLs unterstützen Farbmodelle wie RGB und CMYK, Transparenz, eingebettete Schriften und Kompression der Daten.
