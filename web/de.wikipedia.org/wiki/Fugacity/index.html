Fugazität

Die Fugazität (englisch fugacity) ist eine thermodynamische Größe, die 1901 von Gilbert Newton Lewis eingeführt wurde. Sie stellt einen „korrigierten Druck“ dar, mit dem das Verhalten realer Gase und Flüssigkeiten so beschrieben werden kann, als handle es sich um ideale Systeme.

Definition

Die Fugazität f eines Stoffes ist über das chemische Potential definiert: Es gilt dμ = RT · d ln f. Für ein ideales Gas entspricht die Fugazität dem Druck; für reale Stoffe weicht sie davon ab. Das Verhältnis von Fugazität zu Druck heißt Fugazitätskoeffizient φ = f/p; er ist gleich eins für ideale Gase.

Anwendung

Im Phasengleichgewicht ist die Fugazität eines Stoffes in allen koexistierenden Phasen gleich. In der chemischen Verfahrenstechnik wird die Fugazität zur Berechnung von Dampf-Flüssigkeits-Gleichgewichten, etwa bei der Destillation und Absorption, verwendet. Für Mischungen wird die partielle Fugazität mit Hilfe von Aktivitäts- bzw. Fugazitätskoeffizienten aus Zustandsgleichungen wie der Peng-Robinson-Gleichung berechnet.
