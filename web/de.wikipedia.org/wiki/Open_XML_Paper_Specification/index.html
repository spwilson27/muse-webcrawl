Open XML Paper Specification

Die Open XML Paper Specification (OpenXPS) ist ein offener Standard für ein seitenbeschreibendes Dokumentenformat, das auf der XML Paper Specification (XPS) von Microsoft aufbaut. OpenXPS wurde 2011 als Ecma-Standard 388 veröffentlicht und beschreibt Dokumente in fester, seitenweiser Darstellung vergleichbar zu PDF.

Format

Ein OpenXPS-Dokument ist ein OPC-Paket (Open Packaging Conventions) in Form einer ZIP-Datei, das die Seiteninhalte als XML (XAML-basiert) samt eingebetteten Schriften, Bildern und Farbprofilen enthält. Jede Seite wird mit festem Layout beschrieben, sodass das Dokument auf allen Ausgabegeräten – Bildschirm oder Drucker – identisch dargestellt wird. Die Dateiendung lautet .oxps, während das ältere Microsoft-Format XPS die Endung .xps verwendet.

Geschichte

Microsoft führte XPS 2006 mit Windows Vista ein und übergab die Spezifikation zur Standardisierung an Ecma International, um sie als offenen Standard zu etablieren. In der Praxis blieb die Verbreitung gegenüber dem PDF-Format der Firma Adobe gering; unter Windows wird das Format unter anderem vom XPS-Viewer gelesen und von der Druckpipeline von Windows genutzt.
