POSIX

POSIX (Portable Operating System Interface) ist eine von der IEEE entwickelte Familie von Standards, die eine einheitliche Schnittstelle für Betriebssysteme definiert. Ziel ist die Portabilität von Anwendungssoftware zwischen verschiedenen unixartigen Systemen.

Inhalt des Standards

POSIX beschreibt unter anderem Systemaufrufe und Bibliotheksfunktionen der Programmiersprache C (Datei- und Prozessverwaltung, Signale, Threads nach dem Pthreads-Modell), eine Kommandozeilen-Shell sowie eine große Zahl von Dienstprogrammen. Der Standard geht auf die 1980er-Jahre zurück; die erste Fassung IEEE Std 1003.1 erschien 1988. Heute wird POSIX gemeinsam mit der Single UNIX Specification der Open Group gepflegt (Austin Group).

Konformität

Vollständig POSIX-zertifizierte Systeme sind unter anderem macOS sowie verschiedene kommerzielle Unix-Systeme. Linux und die BSD-Systeme halten den Standard weitgehend ein, ohne in allen Fällen formell zertifiziert zu sein. Auch für Windows existierten beziehungsweise existieren POSIX-Umgebungen, etwa das frühere Windows Services for UNIX oder heute das Windows Subsystem for Linux (WSL).
