Bytecode

Bytecode ist ein Zwischencode, der von einem Compiler aus dem Quelltext einer Programmiersprache erzeugt und typischerweise von einer virtuellen Maschine ausgeführt wird. Er liegt zwischen dem menschenlesbaren Quellcode und dem direkt auf der Hardware laufenden Maschinencode.

Eigenschaften

Bytecode besteht aus kompakten, meist ein Byte langen Operationscodes (Opcodes) samt Operanden für eine abstrakte, meist stapelbasierte Maschine. Da er nicht an eine konkrete Prozessorarchitektur gebunden ist, ermöglicht er Plattformunabhängigkeit: Dasselbe Programm kann überall dort laufen, wo eine passende virtuelle Maschine existiert („Write once, run anywhere").

Beispiele

Das bekannteste Beispiel ist der Java-Bytecode, der von der Java Virtual Machine (JVM) interpretiert oder per Just-in-time-Kompilierung in Maschinencode übersetzt wird. Weitere Beispiele sind die Common Intermediate Language (CIL) der .NET-Plattform, der Bytecode von Python (Dateien mit der Endung .pyc), WebAssembly als binäres Zwischenformat für Webbrowser sowie historisch der P-Code der UCSD-Pascal-Umgebung.

Ausführung

Die Ausführung erfolgt durch Interpretation, Just-in-time-Kompilierung (JIT) oder Ahead-of-time-Kompilierung (AOT). Moderne Laufzeitumgebungen kombinieren diese Verfahren, um sowohl schnelle Startzeiten als auch hohe Ausführungsgeschwindigkeit zu erreichen.
