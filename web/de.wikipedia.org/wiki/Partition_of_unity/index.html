Zerlegung der Eins

Eine Zerlegung der Eins (englisch partition of unity) ist in der Analysis und Differentialgeometrie ein System nichtnegativer Funktionen, deren Summe überall gleich 1 ist und deren Träger eine gegebene offene Überdeckung verfeinern. Mit ihrer Hilfe lassen sich lokal definierte Objekte zu globalen zusammensetzen.

Definition

Sei X ein topologischer Raum mit einer offenen Überdeckung (Ui). Eine Zerlegung der Eins bezüglich dieser Überdeckung ist eine Familie von stetigen Funktionen φi : X → [0, 1] mit:

  • Der Träger von φi liegt in Ui.
  • Jeder Punkt hat eine Umgebung, in der nur endlich viele φi von null verschieden sind (lokale Endlichkeit).
  • Die Summe aller φi ist überall gleich 1.

Existenz

Auf parakompakten Hausdorffräumen existieren zu jeder offenen Überdeckung Zerlegungen der Eins. Auf glatten Mannigfaltigkeiten kann man die Funktionen zusätzlich als glatt (unendlich oft differenzierbar) wählen.

Anwendungen

Zerlegungen der Eins dienen unter anderem dazu, Integrale auf Mannigfaltigkeiten zu definieren, Riemannsche Metriken durch Verkleben lokaler Metriken zu konstruieren und Differentialformen global aus lokalen Daten zusammenzusetzen.
