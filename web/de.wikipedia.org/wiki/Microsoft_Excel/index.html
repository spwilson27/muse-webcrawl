Microsoft Excel

Microsoft Excel ist ein Tabellenkalkulationsprogramm von Microsoft und Bestandteil von Microsoft Office beziehungsweise Microsoft 365. Die erste Version erschien 1985 für den Macintosh; die Windows-Version folgte 1987. Excel setzte sich in den 1990er Jahren gegen Konkurrenten wie Lotus 1-2-3 durch und ist bis heute das weltweit am weitesten verbreitete Tabellenkalkulationsprogramm.

Funktionen

Excel organisiert Daten in Arbeitsblättern aus Zeilen und Spalten. Zellen können Werte, Texte und Formeln enthalten; mehrere hundert eingebaute Funktionen unterstützen Berechnungen aus Finanzmathematik, Statistik, Logik und Textverarbeitung. Weitere Merkmale sind Diagramme, Pivot-Tabellen zur Datenanalyse, bedingte Formatierung und die Automatisierung durch Makros in der Programmiersprache Visual Basic for Applications (VBA). Das Standarddateiformat ist seit Excel 2007 die XML-basierte Dateiendung .xlsx; zuvor wurde das proprietäre .xls-Format verwendet.
