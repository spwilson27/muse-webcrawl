SPARQL

SPARQL (Akronym für SPARQL Protocol and RDF Query Language) ist eine graphenbasierte Abfragesprache für RDF-Daten. Sie wurde vom World Wide Web Consortium (W3C) standardisiert und dient dazu, Informationen aus verteilten Datenquellen im Semantic Web abzurufen und zu verarbeiten.

Geschichte

SPARQL wurde am 15. Januar 2008 als W3C-Empfehlung veröffentlicht. Die Version SPARQL 1.1 folgte im März 2013 und erweiterte die Sprache unter anderem um Update-Operationen (SPARQL Update), Aggregation und Föderation über mehrere Endpunkte.

Syntax

Die Abfragesyntax ist an SQL angelehnt. Eine Abfrage besteht aus einem Muster aus Tripeln mit Variablen, das mit den RDF-Graphen abgeglichen wird. Das Grundgerüst einer SELECT-Abfrage lautet:

PREFIX foaf: <http://xmlns.com/foaf/0.1/>
SELECT ?name
WHERE { ?person foaf:name ?name . }

Neben SELECT stehen die Abfrageformen CONSTRUCT, ASK und DESCRIBE zur Verfügung.

Anwendung

SPARQL wird unter anderem von Wikidata, DBpedia und zahlreichen Linked-Data-Plattformen verwendet, die öffentliche SPARQL-Endpunkte anbieten.
