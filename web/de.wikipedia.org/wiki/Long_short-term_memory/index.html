Long Short-Term Memory

Long Short-Term Memory (LSTM) ist eine Architektur für rekurrente neuronale Netze (RNN), die 1997 von Sepp Hochreiter und Jürgen Schmidhuber an der Technischen Universität München eingeführt wurde. LSTM-Netze wurden entwickelt, um das Problem verschwindender Gradienten klassischer RNNs zu überwinden, und eignen sich besonders für das Lernen langfristiger Abhängigkeiten in sequentiellen Daten wie Sprache, Text und Zeitreihen.

Architektur

Die Grundeinheit einer LSTM-Schicht ist die Speicherzelle mit einem internen Zustand (cell state), dessen Informationsfluss durch drei Gatter gesteuert wird:

  • Das Forget Gate entscheidet, welche Informationen aus dem Zellzustand verworfen werden.
  • Das Input Gate entscheidet, welche neuen Informationen gespeichert werden.
  • Das Output Gate entscheidet, welche Informationen ausgegeben werden.

Der nahezu unveränderte „Durchfluss" der Gradienten über den Zellzustand (constant error carousel) ermöglicht das Training über viele Zeitschritte hinweg.

Varianten und Anwendungen

Wichtige Varianten sind die Peephole-Verbindungen (Gers, Schmidhuber) und die vereinfachte Gated Recurrent Unit (GRU, 2014). Anwendung fanden LSTMs unter anderem in der Spracherkennung, maschinellen Übersetzung, Handschrifterkennung und bei der Vorhersage von Zeitreihen. Die Google-Übersetzung Google Translate wechselte 2016 auf ein sequenzbasiertes System mit LSTM-Komponenten; später setzten sich zunehmend Transformer-Modelle durch.
