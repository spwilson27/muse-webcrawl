Interpretation (Logik)

Eine Interpretation ist in der mathematischen Logik und Modelltheorie eine Zuordnung, die den Symbolen einer formalen Sprache Bedeutung verleiht: Konstanten werden Elemente einer Grundmenge zugeordnet, Funktionszeichen werden als Funktionen und Relationszeichen als Relationen auf dieser Menge gedeutet.

Modelle

Eine Interpretation, in der eine Formel oder ein Satz wahr ist, heißt Modell dieses Satzes. Ob eine Aussage der Prädikatenlogik wahr ist, hängt damit stets von der gewählten Interpretation ab; logisch wahre Aussagen sind in jeder Interpretation wahr.

Bedeutung

Der Interpretationsbegriff ist Grundlage der Semantik formaler Sprachen und zentral für die Sätze von Gödel, Tarskis Wahrheitsbegriff und die Kategorientheorie der Logik.
