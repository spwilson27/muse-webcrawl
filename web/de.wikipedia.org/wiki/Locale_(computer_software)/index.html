Locale

Eine Locale (englisch für „Orts-/Gebietsschema“) ist in der Softwareentwicklung ein Parametersatz, der die Anpassung von Programmen an Sprache und regionale Konventionen beschreibt. Sie ist ein zentraler Baustein der Internationalisierung und Lokalisierung von Software.

Inhalte

Eine Locale legt unter anderem fest: die Sprache von Texten, das Datums- und Zeitformat, das Zahlenformat (Dezimal- und Tausendertrennzeichen), die Währung, die Sortierreihenfolge (Kollation) sowie Regeln für Groß- und Kleinschreibung. Beispiele sind de_DE für Deutsch in Deutschland oder en_US für Englisch in den USA; die Kennzeichnung folgt der Konvention aus Sprachcode nach ISO 639 und Ländercode nach ISO 3166, modern auch den BCP-47-Tags.

Implementierung

Unter Unix und Linux wird die Locale über Umgebungsvariablen wie LANG, LC_ALL und die kategoriespezifischen Variablen LC_TIME oder LC_NUMERIC gesteuert (POSIX-Locale). In Java steht die Klasse java.util.Locale, in .NET die CultureInfo-Klasse zur Verfügung. Umfassende Datensammlungen für Locales pflegt das Unicode-Konsortium im Common Locale Data Repository (CLDR).
