Kettenkomplex

Ein Kettenkomplex (englisch chain complex) ist ein grundlegendes Konzept der homologischen Algebra. Er besteht aus einer Folge abelscher Gruppen (oder allgemeiner Objekte einer abelschen Kategorie) zusammen mit Homomorphismen, deren Hintereinanderausführung stets null ergibt.

Definition

Ein Kettenkomplex ist eine Folge

… → Cn+1 → Cn → Cn−1 → …

von Objekten Cn mit Morphismen dn : Cn → Cn−1, den Randoperatoren oder Differentialen, sodass für alle n gilt: dn−1 ∘ dn = 0. Äquivalent dazu ist die Bedingung, dass das Bild von dn+1 im Kern von dn enthalten ist. Ein Kokettenkomplex ist analog mit Morphismen in aufsteigender Richtung definiert.

Homologie

Ist (C, d) ein Kettenkomplex, so heißt der Quotient

Hn(C) = ker dn / im dn+1

die n-te Homologiegruppe des Komplexes. Elemente des Kerns heißen Zykel, Elemente des Bildes Ränder. Misst die Homologie null, ist der Komplex an dieser Stelle exakt; ein überall exakter Kettenkomplex heißt azyklisch.

Beispiele

  • Der singuläre Kettenkomplex eines topologischen Raumes, aus dessen Homologie die singuläre Homologie entsteht
  • Der De-Rham-Komplex der Differentialformen auf einer Mannigfaltigkeit
  • Freie Auflösungen von Moduln, etwa zur Definition von Tor und Ext
  • Der simpliziale Kettenkomplex eines Simplizialkomplexes

Kettenabbildungen

Ein Morphismus zwischen Kettenkomplexen ist eine Familie von Morphismen, die mit den Differentialen vertauscht. Zwei Kettenabbildungen heißen homotop, wenn sie sich um eine sogenannte Kettenhomotopie unterscheiden; homotope Abbildungen induzieren dieselbe Abbildung auf der Homologie.
