Fehlstand

Ein Fehlstand (englisch inversion) einer Permutation ist ein Paar von Positionen, an denen das größere Element vor dem kleineren steht. Die Gesamtzahl der Fehlstände heißt Fehlstandszahl oder Inversionenzahl.

Bedeutung

Die Fehlstandszahl misst, wie weit eine Permutation von der sortierten Reihenfolge entfernt ist; sie entspricht der Mindestzahl benachbarter Vertauschungen, die zum Sortieren nötig sind. Verfahren wie Bubblesort führen pro Fehlstand genau einen Tausch aus, während Mergesort die Fehlstandszahl effizient zählen kann.

Eigenschaften

Eine Permutation ist genau dann gerade, wenn ihre Fehlstandszahl gerade ist. Die maximale Fehlstandszahl einer Permutation der Länge n beträgt n(n−1)/2 und wird von der vollständig umgekehrten Reihenfolge erreicht.
