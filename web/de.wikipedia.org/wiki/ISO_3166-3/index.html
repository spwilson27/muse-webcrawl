ISO 3166-3

ISO 3166-3 ist der dritte Teil der Norm ISO 3166 und definiert Codes für Ländernamen, die seit 1974 aus der ISO 3166-1 gestrichen wurden, etwa weil ein Staat aufgehört hat zu existieren, sich umbenannt hat oder sein Code geändert wurde. Die Norm erschien erstmals 1999.

Aufbau

Die Codes der ISO 3166-3 sind vierbuchstabig: Sie bestehen aus dem früheren Alpha-2-Code und einem zweibuchstabigen Suffix. Endet der Code auf HH, handelt es sich um einen gelöschten Code ohne Nachfolgestaat; andere Suffixe verweisen häufig auf den Alpha-2-Code eines Nachfolgestaates.

Zweck

Die ISO 3166-3 stellt sicher, dass historische Datenbestände, die alte Ländercodes verwenden, dauerhaft korrekt interpretiert werden können. Die gestrichenen Codes werden mindestens 50 Jahre lang nicht erneut vergeben, um Verwechslungen zu vermeiden.
