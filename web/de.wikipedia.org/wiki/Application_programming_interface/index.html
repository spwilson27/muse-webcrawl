Programmierschnittstelle

EnglischApplication Programming Interface (API)
ArtSoftwareschnittstelle
FormenFunktions-, objektorientierte, Protokoll- und Web-APIs

Eine Programmierschnittstelle (englisch Application Programming Interface, kurz API) ist ein Programmteil, den ein Softwaresystem anderen Programmen zur Anbindung zur Verfügung stellt. Anders als eine Benutzerschnittstelle dient eine API der Kommunikation zwischen Programmen; sie abstrahiert die interne Implementierung und legt fest, welche Funktionen und Daten bereitstehen.

Formen

Es gibt funktionsorientierte APIs (etwa die Win32-API von Windows), objektorientierte APIs (etwa die Klassenbibliotheken von Java oder .NET), dateiorientierte und protokollorientierte Schnittstellen. Bekannte Beispiele sind POSIX für Betriebssysteme, die Grafik-APIs OpenGL und Vulkan sowie die plattformspezifischen Frameworks von iOS und Android.

Web-APIs

Web-APIs kommunizieren über Netzwerke, meist per HTTP. Verbreitete Stile sind REST-APIs, die Ressourcen über Standardmethoden ansprechen und Daten in der Regel als JSON übertragen, sowie SOAP, GraphQL und gRPC. Sie ermöglichen es, Dienste wie Kartendarstellung, Zahlungsabwicklung oder Musikstreaming in fremde Anwendungen einzubinden, und bilden die Grundlage vieler Geschäftsmodelle der Plattformökonomie.

Abgrenzung

Die API ist auf Quelltextebene definiert; auf Binärebene übernimmt diese Rolle das Application Binary Interface (ABI).
