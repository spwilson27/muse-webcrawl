Fixpunktsatz von Kleene

Der Fixpunktsatz von Kleene (englisch Kleene fixed-point theorem) besagt in der Ordnungstheorie und der Domänentheorie der theoretischen Informatik: Hat ein vollständiger Verband mit kleinstem Element ⊥ eine stetige (monotone und mit Suprema aufsteigender Ketten verträgliche) Funktion f, so besitzt f einen kleinsten Fixpunkt, und zwar den Grenzwert der Kette ⊥ ≤ f(⊥) ≤ f(f(⊥)) ≤ …

Bedeutung

Der Satz liefert die mathematische Grundlage der denotationellen Semantik: Die Bedeutung rekursiver Programme und Schleifen wird als kleinster Fixpunkt einer stetigen Funktionalgleichung definiert. Es handelt sich dabei nicht um den gleichnamigen Rekursionssatz von Kleene aus der Berechenbarkeitstheorie, sondern um einen Fixpunktsatz der Ordnungs- und Verbandstheorie.
