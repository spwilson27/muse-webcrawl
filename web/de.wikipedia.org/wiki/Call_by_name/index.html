Call by Name

Call by Name ist eine Auswertungsstrategie (Parameterübergabemechanismus) in der Informatik, bei der ein Argument eines Funktions- oder Prozeduraufrufs nicht vor dem Aufruf ausgewertet, sondern als unausgewerteter Ausdruck übergeben wird. Der Ausdruck wird erst dann – und bei jedem Zugriff erneut – ausgewertet, wenn der entsprechende Parameter im Rumpf tatsächlich verwendet wird.

Beschreibung

Call by Name wurde durch die Programmiersprache ALGOL 60 bekannt. Technisch wird das Argument als parameterlose Prozedur (Thunk) übergeben. Wird der Parameter gar nicht benutzt, erfolgt auch keine Auswertung; wird er mehrfach benutzt, wird der Ausdruck mehrfach ausgewertet, was bei Seiteneffekten zu überraschenden Ergebnissen führen kann.

Vergleich mit anderen Strategien

Im Gegensatz dazu wertet Call by Value das Argument genau einmal vor dem Aufruf aus, während Call by Reference eine Referenz auf die Variable des Aufrufers übergibt. Die verwandte Strategie Call by Need (verzögerte Auswertung mit Memoisierung) wertet höchstens einmal aus und wird etwa in Haskell verwendet. Call by Name erlaubt es, nicht terminierende Argumente zu übergeben, solange sie nicht benötigt werden, ist aber wegen der wiederholten Auswertung ineffizienter.
