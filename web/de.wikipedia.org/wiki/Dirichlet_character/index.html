Dirichlet-Charakter

Ein Dirichlet-Charakter (englisch Dirichlet character) ist eine spezielle zahlentheoretische Funktion, die von Peter Gustav Lejeune Dirichlet eingeführt wurde, um den Satz über Primzahlen in arithmetischen Progressionen zu beweisen. Dirichlet-Charaktere sind ein grundlegendes Werkzeug der analytischen Zahlentheorie.

Definition

Ein Dirichlet-Charakter modulo q ist eine Funktion χ: ℤ → ℂ mit folgenden Eigenschaften:

  • χ ist periodisch mit Periode q: χ(n + q) = χ(n).
  • χ ist vollständig multiplikativ: χ(mn) = χ(m)χ(n) für alle m, n.
  • χ(n) = 0 genau dann, wenn gcd(n, q) > 1; andernfalls ist χ(n) eine Einheitswurzel.

Äquivalent kann ein Dirichlet-Charakter als Fortsetzung eines Gruppenhomomorphismus der primen Restklassengruppe (ℤ/qℤ)× nach ℂ× durch 0 auf die nicht zu q teilerfremden Zahlen beschrieben werden.

Hauptcharakter und primitive Charaktere

Der Hauptcharakter (oder prinzipale Charakter) modulo q nimmt den Wert 1 auf allen zu q teilerfremden Zahlen an. Ein Charakter heißt primitiv, wenn er nicht von einem Charakter zu einem echten Teiler von q induziert wird; der kleinste solche Modul heißt der Führer (englisch conductor) des Charakters. Charaktere mit reellen Werten (nur 1, −1 und 0) heißen quadratische Charaktere; sie entsprechen über das Kroneckersymbol den quadratischen Zahlkörpern.

Anwendung

Jedem Dirichlet-Charakter ist eine dirichletsche L-Funktion zugeordnet. Mithilfe der Orthogonalitätsrelationen der Charaktere lassen sich einzelne Restklassen modulo q aus Summen über alle Charaktere herausfiltern – dies ist der Kern von Dirichlets Beweis, dass jede teilerfremde Restklasse unendlich viele Primzahlen enthält.
