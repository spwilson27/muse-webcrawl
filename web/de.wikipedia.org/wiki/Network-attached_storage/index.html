Network Attached Storage

Network Attached Storage (NAS, englisch für netzgebundener Speicher) bezeichnet an ein Datennetz angeschlossene Speichergeräte, die anderen Geräten im Netz eigenständig Speicherplatz in Form von Dateisystemen bereitstellen. Ein NAS-System ist ein eigenständiger, für Speicheraufgaben optimierter Server mit eigenem Betriebssystem.

Funktionsweise

Im Gegensatz zu Direct Attached Storage (DAS) wird ein NAS nicht direkt an einen einzelnen Rechner angeschlossen, sondern über Ethernet ins Netzwerk eingebunden. Der Zugriff erfolgt dateibasiert über Netzwerkprotokolle wie NFS, SMB/CIFS oder AFP. NAS-Systeme enthalten meist eine oder mehrere Festplatten oder SSDs, häufig im RAID-Verbund für höhere Ausfallsicherheit.

Anwendungsbereiche

NAS-Systeme werden in Unternehmen und Privathaushalten genutzt, etwa für:

  • Dateiablage und gemeinsame Nutzung von Dokumenten
  • Datensicherung (Backups)
  • Medienbereitstellung (Fotos, Musik, Video-Streaming)
  • private Cloud-Dienste

Abgrenzung

Während ein NAS dateibasiert arbeitet, stellt ein Storage Area Network (SAN) Speicher blockbasiert bereit. Bekannte Hersteller von NAS-Systemen sind unter anderem Synology, QNAP und Netgear.
