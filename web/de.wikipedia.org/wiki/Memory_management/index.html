Speicherverwaltung

Die Speicherverwaltung (englisch memory management) ist ein Teil des Betriebssystems und der Laufzeitumgebung von Programmen. Sie koordiniert die Zuweisung und Freigabe von Arbeitsspeicher, schützt die Speicherbereiche verschiedener Prozesse voreinander und stellt jedem Programm einen eigenen, scheinbar zusammenhängenden Adressraum zur Verfügung.

Aufgaben

  • Zuweisung und Freigabe von Speicher für Prozesse und Daten
  • Adressübersetzung zwischen virtuellen und physischen Adressen
  • Speicherschutz gegen unberechtigte Zugriffe
  • Auslagerung (Swapping und Paging) auf Sekundärspeicher bei Speichermangel

Virtueller Speicher

Moderne Betriebssysteme nutzen virtuellen Speicher: Jeder Prozess sieht einen eigenen virtuellen Adressraum, der von der Memory Management Unit (MMU) mithilfe von Seitentabellen auf den physischen Speicher abgebildet wird. Seiten, die gerade nicht benötigt werden, können auf die Festplatte ausgelagert werden.

Speicherverwaltung in Programmiersprachen

In Sprachen wie C erfolgt die Speicherverwaltung manuell durch den Programmierer. Sprachen wie Java, Python oder Go verfügen dagegen über eine automatische Speicherbereinigung (Garbage Collection), die nicht mehr erreichbare Objekte selbstständig freigibt.
