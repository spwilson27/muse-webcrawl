Betrag (Mathematik)

Der Betrag einer reellen Zahl, auch Absolutbetrag genannt, ist der nichtnegative Wert dieser Zahl ohne Berücksichtigung ihres Vorzeichens. Er wird mit senkrechten Strichen bezeichnet: |x|. Geometrisch entspricht der Betrag dem Abstand der Zahl vom Nullpunkt auf der Zahlengeraden.

Definition

Für eine reelle Zahl x ist der Betrag definiert als |x| = x, falls x ≥ 0, und |x| = −x, falls x < 0. Für komplexe Zahlen ist der Betrag die Länge des zugehörigen Vektors in der Gaußschen Zahlenebene, also |a + bi| = √(a² + b²).

Eigenschaften

Der Betrag ist stets nichtnegativ, und |x| = 0 gilt genau dann, wenn x = 0. Es gelten die Multiplikativität |xy| = |x||y| sowie die Dreiecksungleichung |x + y| ≤ |x| + |y|. Zudem ist der Betrag eine Norm auf den reellen und komplexen Zahlen.

Betragsfunktion

Die Betragsfunktion f(x) = |x| ist stückweise linear, stetig, aber an der Stelle 0 nicht differenzierbar. Ihr Graph besteht aus zwei Halbgeraden, die im Ursprung einen Knick bilden.
