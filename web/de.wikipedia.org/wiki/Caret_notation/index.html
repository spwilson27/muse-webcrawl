Caret-Notation

Die Caret-Notation ist eine Schreibweise zur sichtbaren Darstellung von Steuerzeichen des ASCII-Zeichensatzes. Sie besteht aus einem Caret (^) gefolgt von einem Buchstaben oder einem anderen Zeichen. Beispielsweise steht ^C für das Steuerzeichen ETX, das durch die Tastenkombination Strg+C erzeugt wird.

Systematik

Der auf das Caret folgende Buchstabe ergibt sich aus dem Zeichencode: Das Steuerzeichen mit dem Code n wird durch den Buchstaben an der Position n + 64 dargestellt, sodass ^A dem Code 1 und ^Z dem Code 26 entspricht.

NotationZeichenBedeutung
^@NULNullzeichen
^CETXTextende / Abbruch
^DEOTÜbertragungsende (EOF in Unix-Terminals)
^ITABTabulator
^MCRWagenrücklauf
^ZSUBunter anderem Suspendierung in Unix-Shells
^?DELLöschzeichen

Verwendung

Die Notation findet sich in Terminals und Texteditoren (etwa bei der Anzeige mit cat -v oder in Emacs und Vim) sowie in der Dokumentation von Tastenkombinationen, beispielsweise in der Informatikliteratur zu Steuerungssequenzen.
