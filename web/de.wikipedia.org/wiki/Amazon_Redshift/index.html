Amazon Redshift

Amazon Redshift ist ein vollständig verwaltetes Data-Warehouse-Produkt der Amazon Web Services (AWS). Es basiert auf der Technologie des Unternehmens ParAccel und ermöglicht SQL-Abfragen auf strukturierten und halbstrukturierten Daten im Petabyte-Maßstab.

EntwicklerAmazon Web Services
ErstveröffentlichungNovember 2012 (Vorschau), 2013
TypData Warehouse

Technik

Redshift arbeitet mit spaltenorientierter Speicherung und massiv paralleler Verarbeitung (MPP): Ein Cluster aus einem Leader-Knoten und mehreren Compute-Knoten verteilt Daten und Abfragen auf alle Knoten. Durch Kompression der Spalten und das Vermeiden unnötiger Datenzugriffe werden analytische Abfragen (OLAP) beschleunigt. Die Ansprache erfolgt über SQL; kompatible Treiber (JDBC/ODBC) und eine an PostgreSQL 8.0 angelehnte Abfragesyntax werden unterstützt.

Mit Redshift Spectrum und der RA3-Architektur können Daten auch direkt in Amazon S3 abgefragt werden, wobei Speicher und Rechenleistung voneinander getrennt skalieren. Mit Redshift Serverless steht eine Variante ohne Clusterverwaltung zur Verfügung.

Geschichte

Amazon kündigte Redshift im November 2012 auf der Konferenz re:Invent an. Der Name spielt auf die Rotverschiebung (englisch redshift) an und wurde zugleich als Seitenhieb auf den Wettbewerber Oracle („Big Red“) verstanden. Die Technik geht auf das Unternehmen ParAccel zurück, dessen Software auch Grundlage von Microsofts Parallel Data Warehouse war; ParAccel wurde 2013 von Actian übernommen.
