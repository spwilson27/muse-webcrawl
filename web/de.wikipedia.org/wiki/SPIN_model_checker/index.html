SPIN model checker

SPIN ist ein Werkzeug zur formalen Verifikation nebenläufiger Softwaresysteme, ein sogenannter Model Checker. Es wurde von Gerard J. Holzmann an den Bell Labs entwickelt und wird seit 1991 als freie Software verbreitet.

Funktionsweise

Zu verifizierende Systeme werden in der Modellierungssprache PROMELA beschrieben. SPIN übersetzt ein PROMELA-Modell in einen Verifizierer, der den Zustandsraum systematisch durchsucht und prüft, ob bestimmte Eigenschaften eingehalten werden, etwa Abwesenheit von Deadlocks oder die Gültigkeit von in Linearer Temporallogik (LTL) formulierten Aussagen. Wird eine Eigenschaft verletzt, gibt SPIN einen Gegenbeispiel-Ablauf aus.

Techniken

Um große Zustandsräume zu bewältigen, nutzt SPIN unter anderem Partial-Order-Reduktion, Zustandsraum-Kompression und bitweise Zustandsabspeicherung (Bitstate Hashing).

Auszeichnungen

2001 erhielt SPIN den ACM Software System Award.
