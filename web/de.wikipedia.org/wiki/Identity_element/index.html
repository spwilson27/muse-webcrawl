Neutrales Element

Ein neutrales Element (englisch identity element) ist in der Algebra ein Element einer Menge mit einer zweistelligen Verknüpfung, das jedes Element bei der Verknüpfung unverändert lässt. Strukturen mit einem neutralen Element heißen Monoide bzw. Gruppen, wenn zusätzlich weitere Axiome erfüllt sind.

Definition

Sei S eine Menge mit einer Verknüpfung ∘. Ein Element e ∈ S heißt linksneutral, wenn e ∘ a = a für alle a ∈ S gilt, und rechtsneutral, wenn a ∘ e = a für alle a gilt. Ein beidseitig neutrales Element heißt einfach neutrales Element; existiert es, so ist es eindeutig bestimmt.

Beispiele

  • Die Zahl 0 ist neutrales Element der Addition: a + 0 = a.
  • Die Zahl 1 ist neutrales Element der Multiplikation: a · 1 = a.
  • Die leere Menge ist neutrales Element der Mengenvereinigung.
  • Die Identitätsabbildung ist neutrales Element der Verkettung von Funktionen.
  • Die Einheitsmatrix ist neutrales Element der Matrizenmultiplikation.

Bedeutung

Das neutrale Element ist Voraussetzung für die Definition inverser Elemente und damit für den Gruppenbegriff. In der Kategorie der Mengen entspricht das Konzept dem der Identität in allgemeineren kategorientheoretischen Strukturen.
