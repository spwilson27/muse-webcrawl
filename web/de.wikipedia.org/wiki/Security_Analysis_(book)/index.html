Security Analysis (Buch)

Security Analysis
Autoren: Benjamin Graham, David Dodd
Erstausgabe: 1934
Sprache: Englisch

Security Analysis ist ein 1934 erschienenes Fachbuch der US-amerikanischen Ökonomen Benjamin Graham und David L. Dodd. Es gilt als Grundlagenwerk der fundamentalen Wertpapieranalyse und als „Bibel“ des Value Investing. Die Autoren lehrten an der Columbia Business School; eine vollständig überarbeitete zweite Auflage erschien 1940, weitere Auflagen folgten 1951, 1962, 1988 und 2008.

Inhalt

Das Buch entwickelt eine systematische Methode, Wertpapiere – Aktien wie Anleihen – anhand von Geschäftsberichten, Ertragskraft und Substanzwerten zu bewerten. Zentrale Konzepte sind:

  • die Unterscheidung von Investition (gründliche Analyse, Kapitalsicherheit, angemessene Rendite) und Spekulation,
  • der innere Wert (intrinsic value) eines Unternehmens, unabhängig vom Börsenkurs,
  • die Sicherheitsmarge (margin of safety): Kauf nur deutlich unter dem inneren Wert,
  • die Analyse von Bilanzen, Gewinn-und-Verlust-Rechnungen und Deckungskennzahlen bei Anleihen.

Wirkung

Security Analysis prägte Generationen von Investoren. Zu den bekanntesten Schülern Grahams zählt Warren Buffett, der das Buch als entscheidend für seine Anlagestrategie bezeichnete. Das 1949 erschienene, allgemeinverständlichere Werk Grahams, The Intelligent Investor, baut auf seinen Grundsätzen auf.
