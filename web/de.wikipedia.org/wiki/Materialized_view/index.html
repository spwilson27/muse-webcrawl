Materialisierte Sicht

Eine materialisierte Sicht (englisch materialized view) ist in einem Datenbanksystem ein Datenbankobjekt, das das Ergebnis einer Abfrage physisch gespeichert enthält – im Unterschied zur gewöhnlichen Sicht (View), die nur die Abfragedefinition speichert und bei jedem Zugriff neu berechnet wird.

Eigenschaften

Materialisierte Sichten beschleunigen aufwendige Abfragen, insbesondere Aggregationen in Data Warehouses, weil die Ergebnisse bereits vorberechnet vorliegen. Dafür müssen sie bei Änderungen der Basisdaten aktualisiert werden: Die Aktualisierung kann vollständig (komplette Neuberechnung) oder inkrementell (nur die Änderungen werden nachgezogen) erfolgen, sofort oder zeitgesteuert. Das Datenbanksystem kann Abfragen intern auf eine passende materialisierte Sicht umschreiben (Query Rewrite), ohne dass der Anwender sie explizit referenziert. Unterstützt wird das Konzept unter anderem von Oracle, PostgreSQL und SQL Server (dort als indizierte Sicht).
