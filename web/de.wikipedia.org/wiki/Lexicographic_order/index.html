Lexikographische Ordnung

Die lexikographische Ordnung ist eine Ordnungsrelation auf Folgen (Wörtern oder Tupeln), die der Reihenfolge in einem Lexikon nachempfunden ist. Zwei Folgen werden verglichen, indem man die erste Position sucht, an der sie sich unterscheiden; die Ordnung dieser beiden Elemente entscheidet über die Reihenfolge der Folgen. Ist eine Folge ein Präfix der anderen, gilt die kürzere als die kleinere.

Beispiel

Auf Zeichenketten über dem Alphabet ergibt die lexikographische Ordnung genau die Wörterbuchreihenfolge: Apfel < Apfelsine < Birne. In der Informatik dient sie beispielsweise dem Alphabet von Zeichenketten, der Sortierung von Dateinamen oder dem Vergleich von Versionsnummern.

Mathematische Eigenschaften

Das lexikographische Produkt totaler Ordnungen ist selbst eine totale Ordnung; bei Wohlordnungen ist auch das lexikographische Produkt über endlich viele Komponenten wieder eine Wohlordnung. In der Algebra wird die lexikographische Ordnung als Monomordnung auf Polynomringen verwendet, etwa bei Gröbner-Basen, und in der Spieltheorie zur Beschreibung lexikographischer Präferenzen.
