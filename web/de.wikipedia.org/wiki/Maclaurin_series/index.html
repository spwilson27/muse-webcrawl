Maclaurin-Reihe

Die Maclaurin-Reihe ist ein Spezialfall der Taylorreihe, bei dem die Entwicklung um den Punkt x = 0 erfolgt. Sie ist nach dem schottischen Mathematiker Colin Maclaurin (1698–1746) benannt, der sie in seinem Werk Treatise of Fluxions (1742) systematisch darstellte.

Definition

Für eine beliebig oft differenzierbare Funktion f lautet die Maclaurin-Reihe:

f(x) = f(0) + f′(0)·x + f′′(0)/2! · x² + f′′′(0)/3! · x³ + … = Σn=0∞ f(n)(0)/n! · xn

Ob die Reihe gegen f(x) konvergiert, hängt von der Funktion und vom Konvergenzradius ab.

Beispiele

Bekannte Maclaurin-Reihen sind:

  • ex = 1 + x + x²/2! + x³/3! + …
  • sin(x) = x − x³/3! + x⁵/5! − …
  • cos(x) = 1 − x²/2! + x⁴/4! − …
  • 1/(1−x) = 1 + x + x² + x³ + … für |x| < 1
  • ln(1+x) = x − x²/2 + x³/3 − … für −1 < x ≤ 1

Anwendungen

Maclaurin-Reihen dienen zur näherungsweisen Berechnung von Funktionswerten, zur Herleitung von Grenzwerten und Integralen sowie in der Physik zur Approximation komplizierter Ausdrücke durch Polynome niedriger Ordnung.
