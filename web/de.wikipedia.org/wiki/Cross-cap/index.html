Kreuzhaube

Die Kreuzhaube (englisch cross-cap) ist ein Begriff aus der Topologie, einem Teilgebiet der Mathematik. Sie entsteht, wenn man auf einer Fläche eine Scheibe entfernt und die gegenüberliegenden Punkte des entstehenden kreisförmigen Randes miteinander verklebt. Die Kreuzhaube ist damit ein Baustein nichtorientierbarer Flächen.

Definition und Eigenschaften

Anschaulich lässt sich die Kreuzhaube vorstellen, indem man einen Schlauch an einem Ende so durch sich selbst hindurchstülpt, dass gegenüberliegende Randpunkte aufeinandertreffen. Ein dreidimensionales Modell ohne Selbstdurchdringung ist nicht möglich; Visualisierungen zeigen daher eine Fläche, die sich selbst schneidet.

Die projektive Ebene lässt sich als eine Kugel mit einer Kreuzhaube darstellen. Allgemein kann jede geschlossene nichtorientierbare Fläche als zusammenhängende Summe von Kreuzhauben beschrieben werden: Das Geschlecht einer nichtorientierbaren Fläche zählt, wie viele Kreuzhauben sie enthält. Eine Fläche mit einer Kreuzhaube ist die projektive Ebene, eine mit zwei Kreuzhauben die Kleinsche Flasche; ein Möbiusband entsteht, indem man aus einer Kugel eine Scheibe entfernt und durch eine Kreuzhaube ersetzt.

Zusammenhang mit dem Möbiusband

Entfernt man aus der projektiven Ebene eine offene Scheibe, so bleibt ein Möbiusband übrig. Umgekehrt ergibt sich die projektive Ebene, wenn man den Rand eines Möbiusbandes mit einer Scheibe zuklebt. Die Kreuzhaube ist daher eng mit der Nichtorientierbarkeit des Möbiusbandes verwandt.

Modelle

Bekannte Immersionen der projektiven Ebene in den dreidimensionalen Raum, die auf der Kreuzhaube beruhen, wurden unter anderem durch die „Cross-cap-Fläche“ von Werner Boy (Boysche Fläche) und andere Modelle der darstellenden Topologie populär.
