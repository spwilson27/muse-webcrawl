C++

C++ ist eine vom dänischen Informatiker Bjarne Stroustrup entwickelte, weit verbreitete Programmiersprache. Sie entstand ab 1979 bei den Bell Laboratories als Erweiterung der Sprache C um Konzepte der objektorientierten Programmierung („C with Classes“) und wurde 1985 erstmals kommerziell veröffentlicht.

Eigenschaften

C++ unterstützt mehrere Programmierparadigmen: prozedurale, objektorientierte und generische Programmierung (Templates). Sie erlaubt hardwarenahe, effiziente Programmierung bei gleichzeitig mächtigen Abstraktionsmitteln. Das Design folgt dem Prinzip, dass man nur für genutzte Funktionen „bezahlt“ (zero-overhead principle).

Standardisierung

Der erste ISO-Standard erschien 1998 (C++98). Mit C++11 erfolgte 2011 eine umfassende Modernisierung (u. a. Lambda-Ausdrücke, Smart Pointer, Move-Semantik); weitere Versionen sind C++14, C++17, C++20 (u. a. Konzepte, Koroutinen, Module) und C++23.

Anwendung

C++ wird unter anderem für Betriebssystemkomponenten, Spiele-Engines, Browser, Datenbanken, Finanzsoftware und eingebettete Systeme eingesetzt.
