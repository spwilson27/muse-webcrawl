Nullmenge

Eine Nullmenge ist in der Maßtheorie eine Menge, der das Maß null zugeordnet werden kann, genauer: eine Menge, die in einer Obermenge vom Maß null enthalten ist. Nullmengen spielen eine zentrale Rolle bei der Definition von Aussagen, die „fast überall“ gelten.

Definition und Beispiele

Im Lebesgue-Maß auf den reellen Zahlen hat jede abzählbare Menge das Maß null, also etwa die Menge der rationalen Zahlen – obwohl sie dicht in den reellen Zahlen liegt. Auch die Cantor-Menge ist eine Nullmenge, obwohl sie überabzählbar ist. Die leere Menge ist in jedem Maßraum eine (sogar messbare) Nullmenge.

Eigenschaften

Teilmengen von Nullmengen sind in einem vollständigen Maßraum ebenfalls Nullmengen, und abzählbare Vereinigungen von Nullmengen sind wieder Nullmengen. Eigenschaften von Funktionen und Ereignissen werden in Analysis und Wahrscheinlichkeitstheorie oft nur „fast überall“ bzw. „fast sicher“ gefordert, das heißt bis auf Ausnahmen, die eine Nullmenge bilden.
