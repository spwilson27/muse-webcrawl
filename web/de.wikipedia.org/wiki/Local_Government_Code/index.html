Local Government Code

Der Local Government Code (deutsch etwa: Kommunalverwaltungsgesetz) bezeichnet in mehreren Rechtsordnungen ein Gesetzbuch, das die Organisation, Zuständigkeiten und Befugnisse der kommunalen Selbstverwaltung regelt. Besonders bekannt ist der Local Government Code der Philippinen von 1991 sowie der Local Government Code des US-Bundesstaates Texas.

Philippinen

Der philippinische Local Government Code (Republic Act No. 7160) wurde 1991 unter Präsidentin Corazón Aquino verabschiedet und trat 1992 in Kraft. Er gilt als Meilenstein der Dezentralisierung: Er übertrug den lokalen Gebietskörperschaften – Provinzen, Städten, Gemeinden und Barangays – weitreichende Aufgaben in den Bereichen Gesundheit, Landwirtschaft, Soziales, Umwelt und öffentliche Arbeiten. Zugleich erhielten die Kommunen einen festen Anteil (Internal Revenue Allotment, heute National Tax Allotment) an den nationalen Steuereinnahmen, zuletzt 40 Prozent.

Texas

In Texas fasst der Local Government Code zahlreiche Einzelgesetze zur Kommunalverwaltung zusammen, darunter Regelungen zu Gemeindegründungen, Finanzen, Wahlen und öffentlichen Aufzeichnungen.
