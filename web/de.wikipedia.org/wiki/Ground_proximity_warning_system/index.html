Bodenannäherungs-Warnsystem

Ein Bodenannäherungs-Warnsystem (englisch Ground Proximity Warning System, GPWS) ist ein Sicherheitssystem in Flugzeugen, das die Besatzung warnt, wenn sich das Luftfahrzeug in einer gefährlichen Nähe zum Boden befindet oder eine Kollision mit dem Gelände droht. Es gehört zur Klasse der Terrain Awareness and Warning Systems (TAWS).

Funktionsweise

Das GPWS wertet Daten des Funkhöhenmessers, der Luftdatenrechner, des Fahrwerks und der Klappenstellung aus. Erkennt das System eine gefährliche Situation, gibt es akustische Warnungen wie „Pull up“ („Hochziehen“) oder „Terrain, Terrain“ aus. Typische Warnmodi umfassen übermäßige Sinkrate, Geländeannäherung bei nicht ausgefahrenem Fahrwerk, Höhenverlust nach dem Start und Abweichungen unter den Gleitpfad.

Geschichte

Das System wurde in den 1970er Jahren von dem kanadischen Ingenieur C. Donald Bateman entwickelt. Nach einer Reihe schwerer Unfälle durch Controlled Flight Into Terrain (CFIT) wurde der Einbau in Verkehrsflugzeuge in vielen Ländern vorgeschrieben.

Erweitertes System (EGPWS)

Das Enhanced Ground Proximity Warning System (EGPWS) nutzt zusätzlich GPS-Positionsdaten und eine weltweite Geländedatenbank. Dadurch kann es Hindernisse bereits vor einer unmittelbaren Gefährdung anzeigen und Warnungen auf einem Geländedisplay darstellen.
