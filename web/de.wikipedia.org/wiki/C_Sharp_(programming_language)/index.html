C# (ausgesprochen „C sharp“, deutsch „Cis“) ist eine von Microsoft entwickelte, objektorientierte Programmiersprache, die im Rahmen der .NET-Initiative entstand und im Jahr 2000 vorgestellt wurde. Chefentwickler war Anders Hejlsberg. Die Sprache ist durch ECMA-334 und ISO/IEC 23270 standardisiert.

Eigenschaften

C# vereint Konzepte aus C++, Java und Delphi. Programme werden in einen Zwischencode (Common Intermediate Language) übersetzt und von der Common Language Runtime ausgeführt; die Speicherverwaltung erfolgt automatisch durch Garbage Collection. Im Lauf der Entwicklung kamen unter anderem Generika, LINQ, Lambda-Ausdrücke, asynchrone Programmierung (async/await) und Pattern Matching hinzu.

using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hallo, Welt!");
    }
}

Anwendungsgebiete

C# wird für Desktop-Anwendungen (Windows Forms, WPF), Webanwendungen (ASP.NET Core), Spieleentwicklung mit der Unity-Engine, mobile Apps (Xamarin/.NET MAUI) sowie Cloud- und Serveranwendungen eingesetzt. Mit .NET ist die Sprache plattformübergreifend unter Windows, Linux und macOS verfügbar.
