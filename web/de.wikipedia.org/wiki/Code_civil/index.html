Code civil

Der Code civil (vollständig Code civil des Français, zeitweise Code Napoléon) ist das französische Zivilgesetzbuch. Es trat 1804 in Kraft und regelt bis heute – nach zahlreichen Reformen – das französische Privatrecht.

Gliederung

Der Code folgt der institutionellen Gliederung in drei Bücher: Das erste Buch behandelt das Personen- und Familienrecht, das zweite das Sachenrecht und das Eigentum, das dritte die verschiedenen Arten des Erwerbs von Eigentum, darunter Erbfolge, Schenkungen, Verträge, deliktische Haftung und Sicherungsrechte.

Grundsätze

Zu den berühmten Bestimmungen zählen die Generalklauseln des Deliktsrechts (Artikel 1240 und 1241, ursprünglich 1382 und 1383), die Schadensersatz für jedes schuldhaft verursachte Unrecht vorsehen, sowie die Vertragsfreiheit. Der Code verband revolutionäre Errungenschaften mit Elementen des römischen Rechts und des alten Gewohnheitsrechts.

Reformen

Insbesondere das Familienrecht wurde im 20. Jahrhundert grundlegend modernisiert; 2016 wurde das Schuldvertragsrecht umfassend reformiert. Trotz aller Änderungen ist ein erheblicher Teil der ursprünglichen Artikel noch in Kraft.
