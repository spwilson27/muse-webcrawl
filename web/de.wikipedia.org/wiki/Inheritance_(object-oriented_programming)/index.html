Vererbung (Programmierung)

Vererbung (englisch inheritance) ist eines der Grundprinzipien der objektorientierten Programmierung. Sie erlaubt es, eine neue Klasse (Unterklasse, abgeleitete Klasse) auf Grundlage einer bestehenden Klasse (Oberklasse, Basisklasse) zu definieren und deren Eigenschaften und Methoden zu übernehmen, zu erweitern oder zu überschreiben.

Zweck

Vererbung dient der Wiederverwendung von Code und der Modellierung von Ist-ein-Beziehungen: Eine Unterklasse ist eine Spezialisierung ihrer Oberklasse. So kann beispielsweise eine Klasse Hund von einer allgemeinen Klasse Tier erben. Objekte der Unterklasse können überall dort verwendet werden, wo Objekte der Oberklasse erwartet werden (Substitution), was eng mit dem Konzept der Polymorphie verbunden ist.

Arten

Bei der Einfachvererbung hat jede Klasse höchstens eine direkte Oberklasse (etwa in Java oder C#). Sprachen wie C++ erlauben auch Mehrfachvererbung, bei der eine Klasse von mehreren Basisklassen erbt; dies kann zu Mehrdeutigkeiten führen (Diamantproblem). In manchen Sprachen wird Mehrfachvererbung durch Schnittstellen (Interfaces) oder Traits ersetzt oder ergänzt.

Kritik

Zu tiefe oder unpassend verwendete Vererbungshierarchien gelten als wartungsfeindlich; in der modernen Praxis wird häufig das Prinzip „Komposition vor Vererbung“ empfohlen.
