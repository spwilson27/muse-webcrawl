Cluster Manager

Ein Cluster Manager (auch Clustermanager-Software) ist eine Software zur Verwaltung und Überwachung eines Rechnerverbunds (Computercluster). Er sorgt dafür, dass die Knoten eines Clusters koordiniert zusammenarbeiten, Dienste hochverfügbar bereitgestellt werden und Lasten sinnvoll verteilt werden.

Aufgaben

Zu den Kernaufgaben eines Cluster Managers gehören die Überwachung der Knoten (Health Checks), das Erkennen von Ausfällen und das automatische Umschalten von Diensten auf Ersatzknoten (Failover), die Verteilung von Arbeitslast (Scheduling und Load Balancing) sowie die Verwaltung der Clusterkonfiguration. Ein Quorum-Verfahren verhindert dabei, dass ein geteilter Cluster in zwei unabhängig agierende Teile zerfällt („Split Brain").

Beispiele

Bekannte Cluster-Management-Systeme sind Pacemaker mit Corosync für hochverfügbare Linux-Cluster, Kubernetes zur Orchestrierung von Containern, Apache Mesos sowie die Ressourcenmanager von Hochleistungsrechnern wie Slurm. Im Bereich der Datenbanken übernehmen vergleichbare Komponenten die Verwaltung replizierter Systeme.
