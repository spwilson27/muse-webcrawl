Eclipse

Eclipse bezeichnet:

Astronomie

In der Astronomie steht „Eclipse“ (englisch für Finsternis) allgemein für die Bedeckung eines Himmelskörpers durch einen anderen, insbesondere die Sonnenfinsternis (solar eclipse) und die Mondfinsternis (lunar eclipse). Siehe auch Bedeckungsveränderlicher.

Software

Eclipse ist eine quelloffene integrierte Entwicklungsumgebung (IDE), die ursprünglich von IBM entwickelt und 2001 freigegeben wurde. Sie wird vor allem für die Java-Entwicklung eingesetzt, lässt sich aber durch Plug-ins für zahlreiche weitere Programmiersprachen und Aufgaben erweitern. Gepflegt wird die Plattform von der Eclipse Foundation. Bekannt ist auch das Rich-Client-Framework auf Basis von Eclipse.
