Personal Package Archive

Ein Personal Package Archive (PPA) ist ein spezielles Software-Repository für die Linux-Distribution Ubuntu und ihre Derivate. PPAs werden über die Plattform Launchpad bereitgestellt und ermöglichen es Entwicklern, Softwarepakete außerhalb der offiziellen Paketquellen zu veröffentlichen, die Anwender direkt über die Paketverwaltung APT auf ihren Systemen installieren können.

Funktionsweise

Ein PPA wird auf Launchpad angelegt und mit einer eigenen URL registriert. Benutzer fügen ein PPA mit dem Befehl add-apt-repository zu ihren Paketquellen hinzu; dabei wird der OpenPGP-Schlüssel des Archivs importiert, mit dem die Pakete signiert sind. Anschließend stehen die Pakete wie gewohnt etwa über apt install zur Verfügung. Launchpad baut hochgeladene Quellpakete automatisch für unterstützte Architekturen und Ubuntu-Versionen.

Verwendung

PPAs dienen unter anderem dazu, neuere Programmversionen bereitzustellen als in den offiziellen Quellen, Test- und Vorabversionen zu verteilen oder Software anzubieten, die nicht Teil der offiziellen Distribution ist. Da PPAs von beliebigen Dritten betrieben werden können, weisen Ubuntu-Entwickler darauf hin, dass ihnen nur Software aus vertrauenswürdigen Quellen hinzugefügt werden sollte: Ein PPA kann Systempakete durch eigene Versionen ersetzen und damit die Stabilität und Sicherheit des Systems beeinträchtigen.

Geschichte

Canonical führte die PPAs 2007 ein, um Entwicklern eine unkomplizierte Verbreitung ihrer Software zu ermöglichen. Trotz der Kritik an der zunehmenden Fragmentierung der Paketlandschaft sind sie bis heute ein verbreitetes Mittel, Software für Ubuntu bereitzustellen.
