Hierarchisches Datenbankmodell

Das hierarchische Datenbankmodell ist das älteste Datenbankmodell. Es organisiert Datensätze in einer Baumstruktur, in der jeder Datensatz (bis auf die Wurzel) genau ein übergeordnetes Element (parent) besitzt, aber beliebig viele untergeordnete Elemente (children) haben kann. Beziehungen werden damit als 1:n-Beziehungen abgebildet.

Geschichte

Das bekannteste hierarchische Datenbanksystem ist das 1966 bis 1968 von IBM entwickelte Information Management System (IMS), das ursprünglich für das Apollo-Programm der NASA zur Verwaltung der riesigen Stücklisten der Mondraketen entstand. IMS wird bis heute auf Großrechnern eingesetzt.

Eigenschaften

Der Zugriff auf die Daten erfolgt navigierend entlang vorab definierter Pfade durch den Baum. Dadurch sind Zugriffe auf die vorgesehenen Strukturen sehr schnell, während Anfragen, die der Hierarchie nicht entsprechen, aufwendig oder gar nicht abbildbar sind. n:m-Beziehungen lassen sich nur über Redundanz oder virtuelle Zeiger realisieren. Spätere Modelle wie das Netzwerkmodell und das relationale Modell versuchten, diese Einschränkungen zu überwinden.

Moderne Beispiele für hierarchische Strukturen sind das Verzeichnis eines Dateisystems, XML-Dokumente und das Windows-Registrierungsdatenbank.
