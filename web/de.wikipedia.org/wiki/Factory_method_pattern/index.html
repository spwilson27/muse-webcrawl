Fabrikmethode

Die Fabrikmethode (engl. factory method pattern) ist ein Entwurfsmuster der Softwareentwicklung aus der Gruppe der Erzeugungsmuster. Es definiert eine Methode zur Erzeugung von Objekten, überlässt die Entscheidung, welche konkrete Klasse instanziiert wird, jedoch Unterklassen. Dadurch wird die Erzeugung von Objekten von ihrer Verwendung entkoppelt. Das Muster wurde 1994 im Buch der „Gang of Four“ (Gamma u. a.) beschrieben.

Struktur

Eine abstrakte Erzeugerklasse (Creator) deklariert die Fabrikmethode, die ein Objekt eines Produkttyps (einer Schnittstelle oder abstrakten Klasse Product) zurückliefert. Konkrete Erzeuger (ConcreteCreator) überschreiben die Methode und erzeugen jeweils ein passendes konkretes Produkt. Der übrige Code der Erzeugerklasse arbeitet nur mit der Produktabstraktion und bleibt so unabhängig von den konkreten Klassen.

abstract class Dialog {
    // Fabrikmethode
    abstract Button createButton();
    void render() {
        Button ok = createButton();
        ok.draw();
    }
}
class WindowsDialog extends Dialog {
    Button createButton() { return new WindowsButton(); }
}

Anwendung und Verwandte Muster

Die Fabrikmethode wird eingesetzt, wenn eine Klasse nicht vorhersehen kann, welche Objektart sie erzeugen muss, oder wenn die Erzeugungslogik an Unterklassen delegiert werden soll. Sie ist eng mit der abstrakten Fabrik verwandt, die ganze Produktfamilien erzeugt, und wird häufig mit Template-Methoden kombiniert. In vielen Programmiersprachen übernehmen auch Dependency Injection und einfache Factory-Klassen ähnliche Aufgaben.
