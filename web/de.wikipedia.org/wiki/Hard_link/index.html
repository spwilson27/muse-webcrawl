Hardlink

Ein Hardlink (deutsch „harter Verweis“, englisch hard link) ist in unixartigen Dateisystemen ein zusätzlicher Verzeichniseintrag, der auf dieselbe Datei (denselben Inode) verweist wie ein bereits vorhandener Dateiname. Alle Hardlinks auf eine Datei sind vollkommen gleichwertig – es gibt kein „Original“.

Eigenschaften

Die eigentlichen Dateidaten werden erst gelöscht, wenn der letzte Hardlink entfernt wird; das Dateisystem führt dazu einen Zähler der Verweise. Änderungen über einen Hardlink sind über alle anderen Namen der Datei sichtbar. Hardlinks können nur innerhalb desselben Dateisystems angelegt werden und sind – abgesehen von Sonderfällen unter macOS – für Verzeichnisse nicht zulässig, um Zyklen im Verzeichnisbaum zu vermeiden.

Erstellung

Unter Unix wird ein Hardlink mit dem Befehl ln ohne die Option -s erstellt; auf Systemebene steht dafür der Systemaufruf link(). Im Unterschied dazu verweist ein symbolischer Link (Symlink) nur auf einen Pfadnamen und kann auch dateisystemübergreifend oder auf Verzeichnisse zeigen.
