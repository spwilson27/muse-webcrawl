Federated database system

Ein Federated database system (deutsch föderiertes Datenbanksystem, auch föderierte Datenbank) ist ein Datenbanksystem, das mehrere autonome, heterogene Datenbanken zu einem einheitlichen Gesamtsystem integriert, ohne dass die einzelnen Datenbanken ihre Selbstständigkeit aufgeben müssen. Die Nutzer greifen über eine einheitliche Schnittstelle auf alle beteiligten Datenbanken zu, als handele es sich um ein einziges System.

Architektur

Die Integration erfolgt über Schemata auf mehreren Ebenen: Jede Komponentendatenbank stellt ein Exportschema bereit, das die Daten beschreibt, die sie der Föderation zur Verfügung stellt. Ein föderiertes Gesamtschema fasst die Exportschemata zu einer integrierten Sicht zusammen. Nach dem einflussreichen Fünf-Ebenen-Schema von Sheth und Larson (1990) unterscheidet man lokale Schemata, Komponentenschemata, Exportschemata, föderierte Schemata und externe Schemata für einzelne Anwendungen.

Eigenschaften

Charakteristisch für föderierte Datenbanksysteme sind die Autonomie der Komponenten (Entwurfs-, Ausführungs- und Kommunikationsautonomie), die Heterogenität der Datenmodelle und Abfragesprachen sowie die Verteilung der Daten auf mehrere Standorte. Man unterscheidet eng gekoppelte Systeme mit einem einheitlichen Gesamtschema und lose gekoppelte Systeme, bei denen die Nutzer eigene Sichten aus mehreren Datenbanken zusammenstellen.

Abgrenzung

Im Unterschied zu verteilten Datenbanksystemen werden die Daten bei einer Föderation nicht von Grund auf für ein Gesamtsystem entworfen; vielmehr bleiben bereits bestehende Datenbanken eigenständig bestehen und werden nachträglich integriert. Verwandte Konzepte sind die Datenintegration und sogenannte Polystore-Systeme.
