Response

Der englische Begriff Response (deutsch: Antwort, Reaktion, Rückmeldung) wird in mehreren Fachgebieten verwendet. In der Informatik bezeichnet er die Antwort eines Servers auf eine Anfrage (Request), etwa eine HTTP-Antwort im Web. In der Psychologie und Verhaltensforschung ist Response die Reaktion eines Organismus auf einen Reiz (Stimulus).

In der Medizin beschreibt Response das Ansprechen eines Patienten auf eine Therapie, etwa das Schrumpfen eines Tumors unter Behandlung.

Verwendung

Als Fachwort erscheint Response unter anderem in Begriffen wie Responsezeit (Reaktionszeit eines Systems), Fragebogen-Rücklauf (response rate) in der empirischen Sozialforschung und im Marketing bei der Messung von Kampagnenerfolgen.
