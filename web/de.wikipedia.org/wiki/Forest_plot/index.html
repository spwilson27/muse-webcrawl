Forest Plot

Ein Forest Plot ist eine grafische Darstellung der Ergebnisse mehrerer Studien in einer Metaanalyse. Er zeigt für jede einzelne Studie den geschätzten Effekt (etwa ein relatives Risiko oder eine Odds Ratio) zusammen mit seinem Konfidenzintervall sowie in der Regel einen zusammengefassten Gesamteffekt. Forest Plots sind das wichtigste grafische Instrument systematischer Übersichtsarbeiten, etwa der Cochrane Collaboration.

Aufbau

Die Studien werden zeilenweise untereinander aufgeführt. Jede Zeile enthält ein Quadrat, dessen Position den Punktschätzer und dessen Größe häufig das Gewicht der Studie in der Metaanalyse angibt; eine horizontale Linie markiert das Konfidenzintervall. Eine vertikale Linie bei dem Wert „kein Effekt“ (1 bei Verhältnismaßen, 0 bei Differenzen) erleichtert die Beurteilung der Signifikanz. Am unteren Rand fasst eine Raute (Diamant) den gepoolten Effekt zusammen: Ihre Mitte zeigt den Schätzwert, ihre Breite das Konfidenzintervall.

Interpretation

Überlappen sich die Konfidenzintervalle der Einzelstudien stark, spricht dies gegen ausgeprägte Heterogenität. Ausreißer und stark streuende Effekte lassen sich im Forest Plot unmittelbar erkennen.

Name

Die Herkunft des Namens ist umstritten: Er wird entweder auf die Vielzahl der Linien zurückgeführt, die an einen Wald erinnert, oder auf den Forscher Pat Forrest. Lewis und Clarke diskutierten 2001 mehrere mögliche Erklärungen.
