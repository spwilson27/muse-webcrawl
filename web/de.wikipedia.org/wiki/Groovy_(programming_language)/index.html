Groovy (Programmiersprache)

Apache Groovy ist eine dynamisch und optional statisch typisierte Programmiersprache für die Java Virtual Machine (JVM). Sie wurde von James Strachan ab 2003 entwickelt, ist weitgehend syntaxkompatibel zu Java und erweitert dieses um Konzepte aus Sprachen wie Python, Ruby und Smalltalk, etwa Closures, native Syntax für Listen und Maps sowie eingebettete domänenspezifische Sprachen.

Eigenschaften

Groovy-Code wird zu Java-Bytecode kompiliert und kann nahtlos mit Java-Bibliotheken zusammenarbeiten. Zu den Merkmalen gehören:

  • optionale Typdeklarationen und Semikolons
  • GStrings (String-Interpolation)
  • Closures und eingebaute Builder für XML, JSON und Swing
  • Operatorüberladung und Metaprogrammierung zur Laufzeit
  • direkte Unterstützung von regulären Ausdrücken und Collections
def namen = ['Anna', 'Bernd', 'Clara']
namen.each { println "Hallo, $it!" }

Verwendung

Groovy wird häufig für Skripte, Build-Automatisierung (das Build-Werkzeug Gradle nutzte ursprünglich Groovy für seine DSL), Tests (etwa mit dem Framework Spock) sowie für das Webframework Grails eingesetzt. Seit 2015 wird Groovy als Projekt der Apache Software Foundation weiterentwickelt.
