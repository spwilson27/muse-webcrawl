Apache Hadoop

Apache Hadoop
Entwickler: Apache Software Foundation
Programmiersprache: Java
Kategorie: Framework für verteilte Verarbeitung
Lizenz: Apache License 2.0

Apache Hadoop ist ein freies, in Java geschriebenes Framework zur verteilten Speicherung und Verarbeitung sehr großer Datenmengen (Big Data) auf Clustern aus Standardhardware. Es wurde von Doug Cutting und Mike Cafarella ab 2005 im Umfeld des Suchmaschinenprojekts Nutch entwickelt, inspiriert von Googles Veröffentlichungen zum Google File System (2003) und zu MapReduce (2004). Benannt ist es nach dem Stoffelefanten des Sohnes von Doug Cutting; das Logo zeigt einen gelben Elefanten. Cutting brachte das Projekt zu Yahoo!, wo es großflächig eingesetzt wurde.

Komponenten

  • HDFS (Hadoop Distributed File System): verteiltes Dateisystem, das Daten in Blöcken (typisch 128 MB) mit mehrfacher Replikation fehlertolerant auf den Knoten des Clusters speichert. Ein NameNode verwaltet den Namensraum, DataNodes speichern die Blöcke.
  • MapReduce: Programmiermodell und Ausführungsumgebung zur parallelen Verarbeitung: Eine Map-Funktion erzeugt Schlüssel-Wert-Paare, eine Reduce-Funktion fasst Werte gleicher Schlüssel zusammen.
  • YARN (Yet Another Resource Negotiator): seit Hadoop 2.0 die Komponente zur Ressourcenverwaltung und Auftragsplanung des Clusters, die neben MapReduce auch andere Verarbeitungsmodelle zulässt.

Ökosystem

Um Hadoop ist ein umfangreiches Ökosystem entstanden, darunter HBase, Hive (SQL-ähnliche Abfragen), Pig, Apache Spark und Apache Kafka. Hadoop prägte die Big-Data-Ära der 2010er Jahre; mit dem Aufkommen von Cloud-Objektspeichern und spezialisierten Engines verlagerte sich der Schwerpunkt vieler Installationen, HDFS und das Hadoop-Ökosystem bleiben jedoch weit verbreitet.
