Build Server Protocol

Das Build Server Protocol (BSP) ist ein offenes Protokoll, das die Kommunikation zwischen Entwicklungsumgebungen (IDEs) und Build-Werkzeugen standardisiert. Es wurde ab 2018 von JetBrains, dem Scala Center und weiteren Beteiligten entwickelt und ist konzeptionell am Language Server Protocol (LSP) orientiert.

Funktionsweise

Die Kommunikation erfolgt über JSON-RPC 2.0. Die IDE als Client startet das Build-Werkzeug als Server und fragt Fähigkeiten und Ziele (Targets) ab. Über Methoden wie buildTarget/compile, buildTarget/test und buildTarget/run lassen sich Kompilierung, Tests und Programmstarts auslösen. Der Server meldet Diagnosen, Fortschritt und Ergebnisse asynchron an den Client zurück.

Ziele

Vor BSP musste jede IDE jedes Build-System (etwa sbt, Maven, Gradle, Bazel oder Bloop) eigens integrieren. Mit BSP genügt eine Implementierung pro Seite, damit beliebige Kombinationen funktionieren. Es ergänzt das LSP: Während das LSP die Sprachebene abdeckt, beschreibt BSP Projektstruktur, Abhängigkeiten und Build-Abläufe.

Verbreitung

Unterstützt wird das Protokoll unter anderem von sbt, Bloop, Bazel (über Erweiterungen), Mill und Pants sowie auf IDE-Seite von IntelliJ IDEA und Metals. Die Spezifikation liegt in der Version 2.x vor.
