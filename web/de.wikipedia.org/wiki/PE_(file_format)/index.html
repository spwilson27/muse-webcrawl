Portable Executable

Dateiendungen: .exe, .dll, .sys, .ocx u. a.

Plattform: Microsoft Windows

Einführung: mit Windows NT 3.1 (1993)

Grundlage: COFF

Portable Executable (PE) ist das Dateiformat für ausführbare Programme und Bibliotheken unter Microsoft Windows. Es wird für Dateien mit Endungen wie .exe, .dll, .sys und .scr verwendet und basiert auf dem COFF-Format (Common Object File Format). Eingeführt wurde es mit Windows NT 3.1.

Aufbau

Eine PE-Datei beginnt mit einem MS-DOS-Stub, der bei Ausführung unter DOS eine Meldung ausgibt, gefolgt von der PE-Signatur „PE\0\0“. Der COFF-Header enthält Angaben zu Zielarchitektur, Anzahl der Abschnitte und Zeitstempel. Der optionale Header – trotz des Namens für Ausführungsdateien zwingend – definiert unter anderem den Einsprungspunkt (Entry Point), die Basisadresse des Abbilds sowie Tabellen für Importe, Exporte, Ressourcen, Relokationen und Debug-Informationen. Darauf folgen die Abschnitte (Sections) wie .text (Code), .data, .rdata und .rsrc.

Varianten und Verwendung

Die Variante PE32+ erweitert das Format auf 64-Bit-Adressen und wird auf x64- und ARM64-Systemen verwendet. Auch das .NET-Framework setzt auf PE-Dateien; diese enthalten neben nativem Startcode vor allem CIL-Zwischencode und Metadaten. Werkzeuge wie der PE-Header-Viewer, CFF Explorer oder die Sysinternals-Suite dienen der Analyse des Formats, das auch ein zentrales Untersuchungsobjekt der Schadsoftware-Analyse ist.
