Mobile Virtual Network Enabler

Ein Mobile Virtual Network Enabler (MVNE, deutsch etwa „Ermöglicher virtueller Mobilfunknetze") ist ein Unternehmen, das die technische Infrastruktur und die damit verbundenen Dienstleistungen bereitstellt, die ein Mobile Virtual Network Operator (MVNO) benötigt, um Mobilfunkdienste anzubieten, ohne selbst über ein eigenes Funknetz oder eigene Netzinfrastruktur zu verfügen.

Aufgaben

Ein MVNE übernimmt für seine Kunden typischerweise die Abrechnung und das Kundenmanagement (Billing und CRM), die Bereitstellung von SIM-Karten, die Anbindung an die Netze der Mobilfunknetzbetreiber (MNO), die Einrichtung von Tarifen und Produkten sowie den Betrieb der hierfür erforderlichen IT-Plattformen. Dadurch kann ein MVNO, der keine eigene technische Infrastruktur aufbauen möchte, sich auf Vertrieb, Marketing und Kundenbetreuung konzentrieren.

Abgrenzung

Anders als der MVNO steht der MVNE nicht in einer direkten Vertragsbeziehung zum Endkunden. Er agiert als Dienstleister im Hintergrund (Backend), während der MVNO die Marke und das Kundenerlebnis verantwortet. Manche Unternehmen treten zugleich als MVNE und als Aggregator (MVNA) auf.
