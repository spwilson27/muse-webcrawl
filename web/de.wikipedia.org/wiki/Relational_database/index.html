Relationale Datenbank

Eine relationale Datenbank ist eine Datenbank, die auf dem relationalen Datenmodell beruht. Dieses wurde 1970 von Edgar F. Codd am IBM-Forschungslabor in San José vorgestellt. Daten werden in Form von Tabellen (Relationen) gespeichert, deren Zeilen Tupel und deren Spalten Attribute darstellen.

Grundlagen

Zwischen den Tabellen können Beziehungen über Primärschlüssel und Fremdschlüssel hergestellt werden. Die Anfragesprache SQL (Structured Query Language) ist der Standard für Definition, Manipulation und Abfrage relationaler Datenbanken. Zur Vermeidung von Redundanzen und Anomalien werden Tabellen nach den Regeln der Normalisierung in Normalformen überführt.

Geschichte

Die ersten kommerziellen Systeme erschienen Ende der 1970er Jahre, darunter Oracle (1979) und das IBM-System DB2 (1983). In den 1980er und 1990er Jahren verdrängten relationale Systeme weitgehend hierarchische und netzwerkartige Datenbankmodelle.

Bekannte Systeme

  • Oracle Database
  • MySQL und MariaDB
  • PostgreSQL
  • Microsoft SQL Server
  • SQLite
  • IBM Db2

Eigenschaften

Relationale Datenbankmanagementsysteme garantieren in der Regel die ACID-Eigenschaften (Atomarität, Konsistenz, Isolation, Dauerhaftigkeit) von Transaktionen und die referenzielle Integrität der Daten.
