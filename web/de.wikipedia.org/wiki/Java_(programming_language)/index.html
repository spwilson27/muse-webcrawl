Java (Programmiersprache)

Java ist eine objektorientierte Programmiersprache, die 1995 von Sun Microsystems veröffentlicht wurde und heute von Oracle weiterentwickelt wird. Java-Programme werden in Bytecode übersetzt und auf einer virtuellen Maschine (JVM) ausgeführt, wodurch sie weitgehend plattformunabhängig sind („Write once, run anywhere").

Geschichte

Die Sprache entstand Anfang der 1990er Jahre unter der Leitung von James Gosling zunächst unter dem Namen Oak für eingebettete Systeme. Nach der Umbenennung in Java – nach der Kaffeesorte von der Insel Java – wurde sie 1995 der Öffentlichkeit vorgestellt und verbreitete sich rasch über Java-Applets im Web. Später verlagerte sich der Schwerpunkt auf Unternehmenssoftware und serverseitige Anwendungen; Java ist auch die Grundlage der App-Entwicklung für das Betriebssystem Android.

Eigenschaften

Java ist statisch typisiert, klassenbasiert und besitzt eine automatische Speicherbereinigung (Garbage Collection). Zum Ökosystem gehören die Java-Plattform mit der umfangreichen Klassenbibliothek, Werkzeuge wie Maven und Gradle sowie Frameworks wie Spring. Die Sprache erscheint seit 2017 in einem halbjährlichen Veröffentlichungsrhythmus.
