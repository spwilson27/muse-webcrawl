Amazon API Gateway

Amazon API Gateway ist ein vollständig verwalteter Dienst von Amazon Web Services (AWS), mit dem Entwickler Programmierschnittstellen (APIs) erstellen, veröffentlichen, überwachen und absichern können. Der Dienst wurde im Juli 2015 eingeführt und gilt als zentrale Komponente serverloser Architekturen.

Funktionen

API Gateway nimmt HTTP- und WebSocket-Anfragen entgegen und leitet sie an Backend-Dienste weiter, etwa an AWS-Lambda-Funktionen, EC2-Instanzen oder beliebige HTTP-Endpunkte. Der Dienst übernimmt dabei Aufgaben wie Authentifizierung und Autorisierung (z. B. über IAM, Cognito oder Lambda-Authorizer), Ratenbegrenzung und Kontingente, Anfrage- und Antworttransformation, Caching sowie Protokollierung und Metriken über Amazon CloudWatch.

API-Typen

Neben REST-APIs bietet der Dienst schlankere und günstigere HTTP-APIs mit geringerer Latenz sowie WebSocket-APIs für Echtzeitanwendungen wie Chats. APIs lassen sich in Phasen (Stages) bereitstellen und über OpenAPI-Definitionen importieren und exportieren.

Abrechnung

Abgerechnet wird nach der Zahl der API-Aufrufe und der übertragenen Datenmenge; eigene Server müssen nicht betrieben werden.
