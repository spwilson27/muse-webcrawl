Dynamische Typisierung

Symbolbild: Quelltext einer dynamisch typisierten Sprache

Dynamische Typisierung (englisch dynamic typing) ist eine Eigenschaft von Programmiersprachen, bei der die Typprüfung von Werten erst zur Laufzeit erfolgt. Variablen besitzen dabei keinen festen Datentyp; stattdessen trägt jeder Wert selbst eine Typinformation, und eine Variable kann im Programmverlauf Werte unterschiedlicher Typen annehmen.

Abgrenzung

Das Gegenstück ist die statische Typisierung, bei der Typen bereits zur Übersetzungszeit geprüft werden, wie in Java, C oder Haskell. Typische dynamisch typisierte Sprachen sind Python, JavaScript, Ruby, Lisp und PHP. Zu unterscheiden ist die dynamische Typisierung von der schwachen Typisierung: Ob eine Sprache Operationen zwischen inkompatiblen Typen automatisch umwandelt, ist eine davon unabhängige Entwurfsentscheidung.

Vor- und Nachteile

Dynamische Typisierung ermöglicht schlanken, flexiblen Code und schnelle Entwicklungszyklen, begünstigt Metaprogrammierung und Konzepte wie Duck Typing. Als Nachteile gelten, dass Typfehler erst zur Laufzeit auftreten und durch Tests abgesichert werden müssen, dass Werkzeuge schlechter bei Autovervollständigung und Refactoring unterstützen und dass Laufzeitumgebungen für Typprüfungen zusätzlichen Aufwand betreiben.

Graduelle Typisierung

Viele dynamisch typisierte Sprachen bieten heute optional nachrüstbare Typannotationen, etwa TypeScript als Übermenge von JavaScript, mypy und Typ-Hinweise in Python oder Sorbet für Ruby. Diese graduelle Typisierung soll die Flexibilität des dynamischen Ansatzes mit Teilen der Sicherheit statischer Prüfung verbinden.
