Rust (Programmiersprache)

Rust ist eine Multiparadigmen-Programmiersprache, die besonderen Wert auf Leistung, Speichersicherheit und Nebenläufigkeit legt. Sie wurde ursprünglich bei Mozilla entwickelt und 2015 in der Version 1.0 veröffentlicht. Seit 2021 wird die Weiterentwicklung von der unabhängigen Rust Foundation getragen.

Eigenschaften

Speichersicherheit wird bei Rust ohne Garbage Collection erreicht: Ein System aus Besitzverhältnissen (Ownership), Referenzen mit Lebensdauern und der „Borrow Checker" des Compilers verhindert ganze Fehlerklassen wie Nullzeiger-Dereferenzierungen und Datenrennen bereits zur Übersetzungszeit. Für seltene Fälle, in denen diese Regeln zu streng sind, steht der Schlüsselwortbereich unsafe zur Verfügung.

Verwendung

Rust wird in der Systemprogrammierung, für WebAssembly, eingebettete Systeme, Netzwerkdienste und Befehlszeilenwerkzeuge eingesetzt. Teile des Linux-Kernels und anderer großer Projekte nutzen Rust. Der Paketmanager und das Build-Werkzeug heißen Cargo; das zentrale Paketregister ist crates.io.

Verbreitung

In der jährlich durchgeführten Stack-Overflow-Entwicklerumfrage wurde Rust über viele Jahre als eine der beliebtesten („most loved") Programmiersprachen eingestuft.
