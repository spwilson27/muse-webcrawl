Java-Klassendatei

Eine Java-Klassendatei (englisch Java class file, Dateiendung .class) enthält den Java-Bytecode einer Klasse oder Schnittstelle. Sie entsteht beim Übersetzen von Java-Quellcode und wird zur Laufzeit vom Klassenlader der Java Virtual Machine geladen.

Aufbau

Jede Klassendatei beginnt mit der magischen Zahl 0xCAFEBABE. Darauf folgen die Versionsnummer des Dateiformats (Minor- und Major-Version), der Konstantenpool mit allen in der Klasse verwendeten Literalen und symbolischen Verweisen, Zugriffskennzeichen, Verweise auf die Klasse selbst und ihre Oberklasse sowie Tabellen der implementierten Schnittstellen, Felder, Methoden und Attribute. Der eigentliche Code steht im Attribut Code der jeweiligen Methode.

Mehrere Klassendateien werden üblicherweise in JAR-Archiven gebündelt. Werkzeuge wie javap können Klassendateien disassemblieren und lesbar darstellen.
