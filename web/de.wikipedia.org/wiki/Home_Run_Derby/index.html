Home Run Derby

Das Home Run Derby ist ein jährlicher Wettbewerb der Major League Baseball (MLB), bei dem ausgewählte Schlagmänner darin wetteifern, die meisten Home Runs zu schlagen. Die Veranstaltung findet traditionell am Tag vor dem MLB All-Star Game statt und gehört zu den Höhepunkten des All-Star-Wochenendes.

Format

Das Format wurde mehrfach verändert. Lange Zeit schlugen die Teilnehmer in Runden mit einer festen Zahl von „Outs" – jeder Schlag, der kein Home Run war, zählte als Out. Seit 2015 gilt ein Zeitformat mit Kopf-an-Kopf-Duellen im K.-o.-System: Jeder Spieler hat wenige Minuten Zeit, so viele Home Runs wie möglich zu schlagen; weite Schläge über eine Mindestdistanz bringen Bonuszeit.

Bekannte Sieger

Zu den mehrfachen Gewinnern zählen Ken Griffey Jr. mit drei Titeln sowie Prince Fielder und Yoenis Céspedes mit je zwei Siegen. Auch Aaron Judge und Pete Alonso gewannen den beliebten Wettbewerb, der regelmäßig hohe Fernsehquoten erzielt.
