FileVault

FileVault ist eine Funktion zur Festplattenverschlüsselung im Betriebssystem macOS von Apple. Sie schützt die Daten eines Macs, sodass sie ohne Anmeldepasswort oder Wiederherstellungsschlüssel nicht ausgelesen werden können — etwa bei Verlust oder Diebstahl des Geräts.

Versionen

Die erste Version wurde mit Mac OS X Panther (10.3) eingeführt und verschlüsselte nur das Benutzerverzeichnis in einem verschlüsselten Disk-Image. Mit Mac OS X Lion (10.7) folgte FileVault 2, eine vollständige Verschlüsselung des Startvolumes. Auf Macs mit Apple-Chips bzw. T2-Sicherheitschip sind die Daten ohnehin verschlüsselt gespeichert; FileVault knüpft die Entschlüsselung dann an die Benutzeranmeldung.

Technik

FileVault 2 verwendet den XTS-AES-128-Modus mit einem 256-Bit-Schlüssel. Beim Aktivieren wird ein Wiederherstellungsschlüssel angezeigt, der optional in iCloud hinterlegt werden kann, um den Zugriff nach vergessenem Passwort wiederzuerlangen.
