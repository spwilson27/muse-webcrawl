Multilineare Abbildung

Eine multilineare Abbildung ist in der linearen Algebra eine Abbildung von einem kartesischen Produkt von Vektorräumen in einen weiteren Vektorraum, die in jedem ihrer Argumente linear ist, wenn die übrigen Argumente festgehalten werden.

Definition

Seien V1, …, Vn und W Vektorräume über demselben Körper K. Eine Abbildung f : V1 × … × Vn → W heißt multilinear, wenn für jede Stelle i und alle festen übrigen Argumente die Abbildung v ↦ f(v1, …, v, …, vn) linear ist, also

f(…, a·v + b·v′, …) = a·f(…, v, …) + b·f(…, v′, …)

gilt. Für n = 1 ist das eine lineare Abbildung, für n = 2 eine bilineare Abbildung. Erreichen die Werte einen Körper, spricht man von einer Multilinearform.

Beispiele

  • Das Skalarprodukt reeller Vektorräume ist bilinear.
  • Die Determinante ist – als Funktion der Spalten (oder Zeilen) einer Matrix aufgefasst – eine multilineare, genauer alternierende Multilinearform.
  • Das Kreuzprodukt im ℝ³ ist bilinear, aber nicht assoziativ.
  • Matrixmultiplikation und die Multiplikation in Algebren sind bilinear.

Alternierende und symmetrische Abbildungen

Eine multilineare Abbildung heißt alternierend, wenn sie verschwindet, sobald zwei Argumente gleich sind; sie heißt symmetrisch, wenn ihr Wert unter Vertauschung zweier Argumente unverändert bleibt. Alternierende Formen sind die Bausteine der äußeren Algebra und der Differentialformen.

Bezug zum Tensorprodukt

Jede multilineare Abbildung f : V1 × … × Vn → W faktoriert eindeutig über das Tensorprodukt V1 ⊗ … ⊗ Vn: Es gibt genau eine lineare Abbildung des Tensorprodukts nach W, deren Einschränkung f ergibt. Diese universelle Eigenschaft definiert das Tensorprodukt bis auf Isomorphie.
