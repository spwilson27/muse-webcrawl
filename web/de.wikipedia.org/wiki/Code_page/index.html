Codepage

Eine Codepage (deutsch etwa „Codeseite“, auch code page) ist eine Tabelle, die jedem Zeichen eines Zeichensatzes eine Bytefolge zuordnet. Der Begriff wurde insbesondere durch IBM und Microsoft geprägt. Codepages dienten dazu, mit nur 256 möglichen Werten eines Bytes (8-Bit-Kodierung) neben den ASCII-Zeichen auch sprachspezifische Sonderzeichen, Umlaute und Grafikzeichen darstellen zu können.

Geschichte

Für den IBM PC legte IBM verschiedene Codepages fest, deren untere Hälfte stets dem ASCII-Standard entsprach, während die obere Hälfte je nach Sprache variierte. Die Codepage 437 war die ursprüngliche US-amerikanische Zeichentabelle des IBM PC und enthielt Rahmen- und Blockgrafikzeichen. Für Westeuropa wurde die Codepage 850 („mehrsprachig“) eingeführt, die mehr Buchstaben mit diakritischen Zeichen enthielt, dafür aber einige Grafikzeichen aufgab.

Microsoft Windows verwendete eigene, ähnliche Tabellen wie Windows-1252 für westeuropäische Sprachen. Unter MS-DOS konnte mit dem Befehl CHCP (change code page) zwischen Codepages umgeschaltet werden.

Ablösung durch Unicode

Da 8-Bit-Codepages nur eine Sprache oder Sprachgruppe abdecken konnten und der Austausch von Texten zwischen verschiedenen Systemen regelmäßig zu falsch dargestellten Zeichen (Mojibake) führte, werden sie zunehmend durch Unicode und die UTF-8-Kodierung verdrängt, die alle Schriften der Welt einheitlich abbildet. Codepages spielen heute vor allem in Altsystemen, eingebetteten Systemen und an der Kommandozeile noch eine Rolle.
