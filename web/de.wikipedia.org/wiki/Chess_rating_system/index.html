Wertungssysteme im Schach

Wertungssysteme im Schach dienen dazu, die Spielstärke von Schachspielern in einer Zahl abzubilden. Das weltweit maßgebliche System ist die von Arpad Elo entwickelte Elo-Zahl, die die FIDE seit 1970 verwendet.

Elo-System

Beim Elo-System wird aus der Differenz der Wertungszahlen zweier Spieler eine Gewinnerwartung berechnet. Ein Sieg gegen einen stärkeren Gegner erhöht die eigene Zahl, eine Niederlage gegen einen schwächeren senkt sie; die Anpassung hängt vom K-Faktor ab. Die FIDE veröffentlicht monatlich Weltranglisten für klassisches Schach, Schnellschach und Blitzschach. Eine Zahl von 2500 entspricht ungefähr Großmeisterniveau; die höchste je erreichte klassische Wertung erzielte Magnus Carlsen mit 2882 (2014/2019).

Andere Systeme

National werden mitunter eigene Systeme verwendet, etwa die Deutsche Wertungszahl (DWZ) oder das englische Grading. Onlineplattformen wie Chess.com und Lichess nutzen häufig das Glicko-System (Glicko-2), das neben der Wertung auch deren Zuverlässigkeit berücksichtigt. Historische Systeme sind das Ingo-System und das Harkness-System.
