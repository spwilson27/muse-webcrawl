Grenzwert (Mathematik)

Ein Grenzwert oder Limes (lateinisch limes = Grenze) ist in der Mathematik der Wert, dem sich eine Folge oder Funktion beliebig annähert. Der Grenzwertbegriff bildet das Fundament der Analysis: Mit ihm werden Stetigkeit, Differenzierbarkeit und Integrierbarkeit definiert.

Grenzwert einer Folge

Eine Folge (an) konvergiert gegen den Grenzwert a, wenn es zu jedem ε > 0 einen Index N gibt, sodass |an − a| < ε für alle n ≥ N gilt. Eine Folge mit Grenzwert 0 heißt Nullfolge. Konvergiert eine Folge nicht, so heißt sie divergent.

Grenzwert einer Funktion

Der Grenzwert einer Funktion f an einer Stelle x0 ist der Wert L, dem sich die Funktionswerte f(x) beliebig annähern, wenn x gegen x0 strebt. Man schreibt limx→x0 f(x) = L. Unterschieden werden einseitige (links- und rechtsseitige) Grenzwerte sowie Grenzwerte im Unendlichen.

Rechenregeln

Für konvergente Folgen und Funktionen gelten Grenzwertsätze: Der Grenzwert einer Summe ist die Summe der Grenzwerte, analog für Produkt, Quotient (bei Nenner ≠ 0) und Verkettung stetiger Funktionen. Wichtige Hilfsmittel sind der Einschließungssatz (Sandwichsatz), die Regel von de L’Hospital und das Monotoniekriterium.
