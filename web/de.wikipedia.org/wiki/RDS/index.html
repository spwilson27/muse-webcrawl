Radio Data System

Das Radio Data System (RDS) ist ein Verfahren zur Übertragung digitaler Zusatzinformationen im analogen UKW-Rundfunk. Es wurde in den 1980er-Jahren von der Europäischen Rundfunkunion entwickelt und ist heute in Europa nahezu flächendeckend im Einsatz.

Funktionen

  • PS (Programme Service): Anzeige des Sendernamens im Display
  • AF (Alternative Frequencies): automatischer Wechsel auf die stärkste Frequenz desselben Programms
  • TP/TA: Kennzeichnung und Durchschaltung von Verkehrsdurchsagen
  • RT (Radio Text): kurze Textinformationen, etwa zum laufenden Titel
  • PTY (Programme Type): Kennzeichnung des Programmtyps wie Nachrichten oder Popmusik
  • CT: Übertragung von Uhrzeit und Datum

Technik im Überblick

Die RDS-Daten werden mit einer niedrigen Datenrate von rund 1187,5 Bit pro Sekunde auf einem Unterträger von 57 kHz im UKW-Signal übertragen. In Nordamerika existiert die weitgehend kompatible Variante RBDS (Radio Broadcast Data System).

Verkehrsinformationen

Eine Erweiterung von RDS ist TMC (Traffic Message Channel), über das Navigationsgeräte codierte Verkehrsmeldungen empfangen und bei der Routenberechnung berücksichtigen können.
