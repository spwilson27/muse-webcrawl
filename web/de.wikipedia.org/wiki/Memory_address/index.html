Speicheradresse

Jede Speicherzelle eines Computers wird über eine eindeutige Adresse angesprochen

Eine Speicheradresse (englisch memory address) ist in der Informatik eine Zahl, mit der eine bestimmte Speicherzelle beziehungsweise ein bestimmter Speicherbereich im Arbeitsspeicher eines Computers eindeutig identifiziert wird. Die CPU nutzt Adressen, um Daten zu lesen und zu schreiben; übertragen werden sie über den Adressbus.

Adressraum und Wortbreite

Die Menge aller adressierbaren Speicherstellen bildet den Adressraum. Seine Größe wird durch die Breite des Adressbusses bestimmt: Mit 32 Bit lassen sich 232, also rund 4 Milliarden Adressen (entsprechend 4 GiB bei byteweiser Adressierung) ansprechen, mit 64 Bit theoretisch 16 Exbibyte. In modernen Systemen ist der Speicher in der Regel byteadressierbar, das heißt, jede Adresse bezeichnet genau ein Byte.

Physische und logische Adressen

Man unterscheidet physische Adressen, die tatsächliche Speicherbausteine ansprechen, von logischen (virtuellen) Adressen, mit denen Programme arbeiten. Die Memory Management Unit (MMU) übersetzt virtuelle Adressen mithilfe von Seitentabellen in physische Adressen. Dadurch erhält jeder Prozess einen eigenen, abgeschotteten Adressraum, und Speicher kann über den physikalisch vorhandenen hinaus ausgelagert werden (Paging/Swapping).

Adressierung in der Programmierung

In Programmiersprachen wie C greifen Zeiger (Pointer) direkt auf Speicheradressen zu. Fehlerhafte Adressierung – etwa Zugriffe auf nicht reservierte oder bereits freigegebene Bereiche – führt zu Schutzverletzungen (Segmentation Fault). Register sind ihrerseits über Registernummern adressierbar; Peripheriegeräte können über speicherabbildende Ein-/Ausgabe (Memory-Mapped I/O) in den Adressraum eingeblendet werden.
