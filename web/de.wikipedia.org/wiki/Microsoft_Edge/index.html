Microsoft Edge

Microsoft Edge ist ein Webbrowser von Microsoft. Er erschien 2015 zusammen mit Windows 10 als Nachfolger des Internet Explorers. Die ursprüngliche Version nutzte die von Microsoft entwickelten Engines EdgeHTML und Chakra. Im Jahr 2020 veröffentlichte Microsoft eine vollständig neue Version auf Basis des Open-Source-Projekts Chromium und dessen Blink-Engine.

Eigenschaften

Edge ist für Windows, macOS, Linux sowie die mobilen Betriebssysteme Android und iOS verfügbar. Der Browser bietet Funktionen wie vertikale Tabs, Sammlungen, einen integrierten PDF-Betrachter, einen Lesemodus sowie Schutz vor Tracking. Seit 2023 integriert Microsoft verstärkt KI-Funktionen, darunter den auf ChatGPT-Technik basierenden Copilot-Assistenten und die Bildersuche über Bing. In Windows ist Edge als Standardbrowser vorinstalliert.
