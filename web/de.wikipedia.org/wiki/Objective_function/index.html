Zielfunktion

Eine Zielfunktion (englisch objective function) ist in der mathematischen Optimierung eine reellwertige Funktion, deren Wert unter Einhaltung gegebener Nebenbedingungen minimiert oder maximiert werden soll. Zusammen mit den Entscheidungsvariablen und den Nebenbedingungen bildet sie ein Optimierungsproblem.

Formulierung

Ein Optimierungsproblem hat die allgemeine Gestalt: Minimiere (oder maximiere) f(x) über allen zulässigen x, wobei die Zulässigkeit durch Gleichungen und Ungleichungen (Nebenbedingungen) beschrieben wird. Je nach Gestalt der Zielfunktion spricht man von linearer, quadratischer oder nichtlinearer Optimierung.

Verlustfunktion

Im maschinellen Lernen wird die Zielfunktion häufig als Verlustfunktion (Loss-Funktion) bezeichnet: Sie misst die Abweichung der Vorhersagen eines Modells von den gewünschten Werten. Das Training eines Modells besteht darin, die Parameter so zu wählen, dass der durchschnittliche Verlust auf den Trainingsdaten minimal wird; verbreitet ist die Minimierung mittels Gradientenverfahren.

Mehrzieloptimierung

Sollen mehrere, möglicherweise widersprüchliche Ziele gleichzeitig verfolgt werden, spricht man von Mehrzieloptimierung. An die Stelle einer einzigen optimalen Lösung tritt dann die Menge der Pareto-optimalen Lösungen.
