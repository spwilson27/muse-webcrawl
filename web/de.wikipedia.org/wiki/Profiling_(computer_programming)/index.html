Profiling (Informatik)

Als Profiling bezeichnet man in der Softwareentwicklung die dynamische Analyse eines Programms während seiner Ausführung, um sein Leistungsverhalten (englisch performance) zu messen. Ein Werkzeug, das solche Messungen durchführt, wird Profiler genannt. Ziel ist es, Engpässe (Bottlenecks) zu finden, also Programmstellen, die besonders viel Zeit oder Speicher verbrauchen.

Ziele

Profiling dient der Optimierung von Programmen: Es zeigt, in welchen Funktionen die meiste Ausführungszeit verbracht wird, wie oft Funktionen aufgerufen werden und wie viel Speicher (etwa auf dem Heap) belegt wird. Damit verhindert es, dass Entwickler an Stellen optimieren, die für die Gesamtleistung kaum eine Rolle spielen.

Verfahren

Man unterscheidet zwei Hauptverfahren: Beim instrumentierenden Profiling wird der Programmcode (zur Übersetzungs- oder Ladezeit) um Messanweisungen erweitert, die Aufrufzahlen und Zeiten exakt erfassen. Beim Sampling (statistisches Profiling) unterbricht das Werkzeug das laufende Programm in regelmäßigen Abständen und zeichnet den aktuellen Aufrufstapel auf; daraus wird statistisch geschätzt, wo die Zeit verbraucht wird. Sampling verursacht weniger Laufzeitverluste, liefert aber nur Näherungswerte.

Ergebnisse

Die Ergebnisse werden häufig als Call Graph (Aufrufgraph), als Liste der zeitintensivsten Funktionen („Hot Spots“) oder als Flame Graph dargestellt, bei dem die Breite der Balken den Zeitanteil anzeigt. Auf dieser Grundlage entscheiden Entwickler über Optimierungen wie schnellere Algorithmen, Caching oder Parallelisierung.

Bekannte Profiler

Zu den bekannten Profilern zählen gprof und Valgrind (mit Callgrind) für C/C++, perf unter Linux, die Profiling-Werkzeuge der Java Virtual Machine (etwa VisualVM und Java Flight Recorder), cProfile für Python sowie die Werkzeuge in integrierten Entwicklungsumgebungen wie Visual Studio.
