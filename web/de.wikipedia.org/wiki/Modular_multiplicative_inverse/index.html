Modulares Inverses

Das modulare Inverse (modulare multiplikative Inverse) einer ganzen Zahl a modulo n ist eine ganze Zahl x mit a·x ≡ 1 (mod n). Es existiert genau dann, wenn a und n teilerfremd sind, das heißt, wenn ggT(a, n) = 1 gilt.

Berechnung

Das modulare Inverse lässt sich mit dem erweiterten euklidischen Algorithmus bestimmen, der die Bézout-Identität a·x + n·y = ggT(a, n) = 1 liefert; hierbei ist x das gesuchte Inverse. Alternativ kann für eine Primzahl p als Modul der kleine Satz von Fermat herangezogen werden: a−1 ≡ ap−2 (mod p).

Beispiel

Das Inverse von 3 modulo 11 ist 4, denn 3 · 4 = 12 ≡ 1 (mod 11).

Anwendungen

  • RSA-Kryptosystem: Berechnung des privaten Schlüssels d aus dem öffentlichen Exponenten e
  • Lösung linearer Kongruenzen
  • Affine Chiffren in der klassischen Kryptographie
