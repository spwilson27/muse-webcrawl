Internationaler Code der Nomenklatur für Algen, Pilze und Pflanzen

Abkürzung: ICN
Gültig für: Algen, Pilze und Pflanzen
Erste Fassung: 1867 (Lois de Candolle)

Überblick

Der Internationale Code der Nomenklatur für Algen, Pilze und Pflanzen (englisch International Code of Nomenclature for algae, fungi, and plants, ICN) regelt die wissenschaftliche Benennung von Pflanzen, Algen und Pilzen.

Er legt fest, wie Namen gebildet, veröffentlicht und priorisiert werden, damit jede Art weltweit einen eindeutigen, stabilen Namen trägt. Beschlüsse über Änderungen fassen die Nomenklatursektionen der Internationalen Botanischen Kongresse.

Grundprinzipien

Zentrale Regeln sind die Priorität des ältesten gültig veröffentlichten Namens, die Typisierung – jeder Name ist an ein Belegexemplar gebunden – und die binäre Nomenklatur nach Carl von Linné mit Gattungs- und Artnamen.

Seit 2012 sind auch elektronische Veröffentlichungen zulässig, und Neubeschreibungen dürfen auf Englisch statt wie zuvor auf Latein verfasst werden. Seit 2013 müssen neue Pilznamen in anerkannten Datenbanken registriert werden.

Geschichte

Die ersten international vereinbarten Regeln gehen auf Alphonse de Candolle 1867 zurück. Lange hieß das Regelwerk Internationaler Code der Botanischen Nomenklatur; die heutige Bezeichnung wurde 2011 auf dem Kongress in Melbourne eingeführt, weshalb diese Fassung Melbourne-Code genannt wird.
