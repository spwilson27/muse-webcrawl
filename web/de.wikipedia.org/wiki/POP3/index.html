Post Office Protocol

POP3
Port: 110 (POP3), 995 (POP3S)
Spezifikation: RFC 1939
Erschienen: 1988 (POP3)

Das Post Office Protocol (POP) ist ein Netzwerkprotokoll zum Abrufen von E-Mails von einem Mailserver. Die heute gebräuchliche Version 3 (POP3) ist in RFC 1939 spezifiziert. POP3 arbeitet standardmäßig über den TCP-Port 110; die verschlüsselte Variante POP3S nutzt Port 995.

Funktionsweise

Eine POP3-Sitzung läuft in drei Phasen ab: In der Autorisierungsphase meldet sich der Client mit Benutzername und Passwort an. In der Transaktionsphase kann er Nachrichten auflisten (LIST), abrufen (RETR) und zum Löschen markieren (DELE). Beim Beenden der Verbindung (QUIT) wechselt der Server in die Aktualisierungsphase und löscht die markierten Nachrichten endgültig.

Das klassische Nutzungsmodell sieht vor, dass E-Mails auf das Endgerät heruntergeladen und danach auf dem Server gelöscht werden. POP3 verwaltet keine Ordnerstrukturen auf dem Server und synchronisiert keine Zustände zwischen mehreren Geräten; dafür eignet sich das funktionsreichere IMAP-Protokoll besser. Viele Clients bieten allerdings die Option, Nachrichten zunächst auf dem Server zu belassen.

Geschichte

Die erste Version des Protokolls erschien 1984 (RFC 918), POP2 folgte 1985. POP3 wurde 1988 veröffentlicht und 1996 mit RFC 1939 zum Internet-Standard erhoben. Trotz der Verbreitung von IMAP und webbasierten Postfächern ist POP3 bei vielen Anbietern weiterhin verfügbar.
