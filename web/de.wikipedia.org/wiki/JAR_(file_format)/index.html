JAR (Dateiformat)

Eine JAR-Datei (von englisch Java Archive) ist ein Archivformat zur gebündelten Verteilung von Java-Klassen, Ressourcen und Metadaten. Es basiert auf dem ZIP-Format und verwendet üblicherweise die Dateiendung .jar.

Aufbau

Die Datei enthält kompilierte Klassendateien, Bilder, Konfigurationen und Bibliotheksinformationen in einer Verzeichnisstruktur, die den Java-Paketen entspricht. Der Ordner META-INF nimmt besondere Dateien auf, vor allem das Manifest MANIFEST.MF.

Manifest und Ausführbarkeit

Das Manifest kann unter anderem Version, Hersteller, Klassenpfad und die Hauptklasse eines Programms angeben. Enthält es einen Eintrag wie Main-Class, lässt sich das Archiv mit java -jar direkt starten, sofern alle erforderlichen Laufzeitbestandteile verfügbar sind.

Signaturen und Erweiterungen

JAR-Dateien können digital signiert werden. Signaturdateien und Prüfsummen im Archiv erlauben es, Veränderungen an einzelnen Einträgen zu erkennen. Spezialisierte Formen sind etwa WAR-Dateien für Webanwendungen und EAR-Dateien für Unternehmensanwendungen; beide verwenden dieselbe grundlegende Archivtechnik.

Verwendung

Entwickler nutzen JAR-Dateien als Programmbibliotheken, eigenständige Anwendungen und Bausteine in Build-Systemen. Werkzeuge des Java Development Kit wie jar können Archive erstellen, anzeigen und entpacken.
