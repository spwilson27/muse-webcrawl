Prüfergruppe

Die Prüfergruppe, auch quasizyklische Gruppe genannt, ist in der Gruppentheorie eine abzählbare abelsche p-Gruppe, die eine wichtige Rolle in der Theorie der abelschen Gruppen spielt. Sie ist nach Heinz Prüfer benannt und wird meist mit Z(p∞) bezeichnet.

Definition

Die Prüfergruppe zur Primzahl p kann als die Gruppe der pn-ten Einheitswurzeln in den komplexen Zahlen (für alle n) unter der Multiplikation definiert werden. Alternativ lässt sie sich als Quotientengruppe Q/Z in der p-primären Komponente beschreiben, also als Gruppe aller rationalen Zahlen, deren Nenner eine Potenz von p ist, modulo Z.

Eigenschaften

Die Prüfergruppe besitzt für jede natürliche Zahl n genau eine Untergruppe der Ordnung pn, und diese Untergruppen bilden eine aufsteigende Kette. Sie ist ein Beispiel für eine artinsche, aber nicht noethersche Gruppe im kategorialen Sinn und dient als Baustein in der Klassifikation teilbarer abelscher Gruppen: Jede teilbare abelsche Gruppe ist eine direkte Summe von Kopien der rationalen Zahlen und von Prüfergruppen.
