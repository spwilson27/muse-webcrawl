Fréchet-Filter

Der Fréchet-Filter, benannt nach Maurice Fréchet, ist ein spezieller Filter auf einer unendlichen Menge. Er besteht aus allen Teilmengen, deren Komplement endlich ist, und wird daher auch koendlicher Filter genannt.

Definition

Sei X eine unendliche Menge. Der Fréchet-Filter auf X ist die Menge aller A ⊆ X, für die X ∖ A endlich ist. Er erfüllt die Filteraxiome: Er enthält weder die leere Menge, ist abgeschlossen gegenüber endlichen Schnitten und gegenüber Obermengen.

Eigenschaften

Der Fréchet-Filter ist der kleinste nichttriviale Filter auf einer unendlichen Menge: Jeder freie Filter enthält den Fréchet-Filter. Erweitert man ihn mittels des Zornschen Lemmas, erhält man freie Ultrafilter. In der Analysis beschreibt Konvergenz bezüglich des Fréchet-Filters auf den natürlichen Zahlen die gewöhnliche Folgenkonvergenz im Sinne des Grenzwerts für n → ∞.
