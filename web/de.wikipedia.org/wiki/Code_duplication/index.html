Codeduplikat

Ein Codeduplikat (englisch code clone, duplicate code) ist ein Abschnitt von Quelltext, der an mehreren Stellen eines Programms gleich oder sehr ähnlich vorkommt. Codeduplikate entstehen meist durch Kopieren und Anpassen bestehender Abschnitte („Copy and Paste Programming") und gelten als Code Smell.

Probleme

Duplizierter Code vergrößert den Pflegeaufwand: Fehler müssen an jeder Kopie korrigiert werden, und es besteht die Gefahr, dass einzelne Stellen übersehen oder uneinheitlich geändert werden. Zudem bläht Duplikation den Quelltext auf und erschwert das Verständnis.

Erkennung und Beseitigung

Werkzeuge zur Klonerkennung finden exakte, umbenannte oder strukturell ähnliche Duplikate. Beseitigt werden Duplikate durch Refactoring, etwa indem man die gemeinsame Logik in eine eigene Methode oder Funktion auslagert (Extract Method) und alle Stellen darauf verweisen lässt. Bewusst in Kauf genommen wird Duplikation etwa, wenn Unabhängigkeit zwischen Modulen wichtiger ist als Konsistenz.
