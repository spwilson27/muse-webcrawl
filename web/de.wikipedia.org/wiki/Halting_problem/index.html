Halteproblem

Das Halteproblem (englisch halting problem) ist eine berühmte Fragestellung der theoretischen Informatik: Gibt es ein Computerprogramm, das für jedes beliebige andere Programm und jede Eingabe entscheiden kann, ob dieses Programm mit dieser Eingabe irgendwann anhält oder in eine Endlosschleife gerät? Alan Turing bewies 1936, dass ein solches Programm prinzipiell nicht existieren kann – das Halteproblem ist unentscheidbar.

Beweisidee

Turings Beweis ist ein Widerspruchsbeweis durch Diagonalisierung: Angenommen, es gäbe einen Halte-Test H, der für Programm P und Eingabe x korrekt ausgibt, ob P auf x hält. Dann ließe sich ein Programm D konstruieren, das H auf sich selbst anwendet und genau das Gegenteil tut: Hält D laut H an, geht D in eine Endlosschleife; sagt H eine Schleife voraus, hält D an. Wendet man D auf D an, ergibt sich in beiden Fällen ein Widerspruch – also kann H nicht existieren. Das Ergebnis steht in engem Zusammenhang mit Gödels Unvollständigkeitssätzen und dem von Alonzo Church gleichzeitig untersuchten Entscheidungsproblem.

Bedeutung

Das Halteproblem ist das Prototyp-Beispiel eines unentscheidbaren Problems und setzt der automatischen Programmverifikation prinzipielle Grenzen: Aus ihm folgt unter anderem der Satz von Rice, wonach jede nichttriviale semantische Eigenschaft von Programmen unentscheidbar ist. Praktische Werkzeuge wie statische Analysatoren oder Terminierungsbeweiser können daher immer nur Teilfälle abdecken. Über die Turingmaschine definiert, ist das Halteproblem zudem rekursiv aufzählbar: Ein Programm, das einfach simuliert wird, bestätigt das Anhalten irgendwann – nur das Nicht-Anhalten lässt sich nicht sicher feststellen.
