Pattern Matching

Pattern Matching (deutsch etwa „Musterabgleich“ oder „Mustervergleich“) bezeichnet in der Informatik das Überprüfen, ob Daten einer vorgegebenen Struktur (einem Muster) entsprechen, sowie die damit verbundene Zerlegung und Bindung von Werten. Der Begriff wird sowohl für den Abgleich von Zeichenketten als auch für ein Sprachkonstrukt funktionaler und moderner Programmiersprachen verwendet.

Musterabgleich auf Zeichenketten

Beim String-Matching wird geprüft, ob ein Muster in einem Text vorkommt. Wichtige Algorithmen sind der naive Algorithmus, der Knuth-Morris-Pratt-Algorithmus, der Boyer-Moore-Algorithmus und der Rabin-Karp-Algorithmus. Erweitert wird das Konzept durch reguläre Ausdrücke, die ganze Sprachen von Zeichenketten beschreiben; Programme wie grep oder Bibliotheken in nahezu jeder Programmiersprache nutzen sie für Suche und Validierung.

Pattern Matching in Programmiersprachen

In Sprachen wie Haskell, OCaml, Scala, Rust, F# oder Erlang ist Pattern Matching ein zentrales Konstrukt, um Datenstrukturen zu zerlegen. Ein Ausdruck wird nacheinander mit mehreren Mustern verglichen; das erste zutreffende Muster wird ausgeführt, wobei die im Muster benannten Variablen an die entsprechenden Teile des Wertes gebunden werden. Typisch sind Fallunterscheidungen über algebraische Datentypen, Listen und Tupel. Compiler prüfen häufig die Vollständigkeit (Exhaustiveness) der Fälle und warnen vor unerreichbaren Mustern.

Beispiel in Haskell:

fak 0 = 1
fak n = n * fak (n-1)

Anwendungsgebiete

Anwendung findet Pattern Matching unter anderem in Compilern, der Textverarbeitung, der Bioinformatik (Sequenzabgleich), in Regelsystemen und Expertensystemen sowie bei der Verarbeitung strukturierter Daten wie XML oder JSON.
