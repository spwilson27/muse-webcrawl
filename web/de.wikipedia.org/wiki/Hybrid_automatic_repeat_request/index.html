Hybrid Automatic Repeat Request

Hybrid Automatic Repeat Request (HARQ) ist ein Verfahren zur Fehlerkorrektur in der Datenübertragung, das die Vorwärtsfehlerkorrektur (Forward Error Correction, FEC) mit dem Wiederholungsverfahren ARQ (Automatic Repeat Request) verbindet. Es wird vor allem in Mobilfunkstandards wie UMTS (HSDPA), LTE und 5G NR eingesetzt.

Funktionsweise

Der Empfänger prüft empfangene Datenblöcke anhand von Prüfsummen. Ist ein Block fehlerhaft, wird er nicht verworfen, sondern zwischengespeichert, und der Empfänger fordert über eine kurze Rückmeldung (ACK/NACK) eine erneute Übertragung an. Dabei werden zwei Grundvarianten unterschieden: Beim Chase Combining wird derselbe Block erneut gesendet und mit dem ersten Empfang kombiniert; beim Incremental Redundancy sendet der Sender zusätzliche Redundanzinformation (Paritätsbits), die den bereits empfangenen Daten hinzugefügt wird und so die Dekodierung mit niedrigerer Coderate ermöglicht.

Bedeutung

HARQ arbeitet auf der physikalischen Schicht beziehungsweise der MAC-Schicht und reagiert daher wesentlich schneller auf Übertragungsfehler als Verfahren höherer Schichten wie ARQ im RLC- oder TCP-Protokoll. Das macht es zu einem Schlüsselverfahren für die hohe Effizienz und die geringen Latenzen moderner Mobilfunknetze.
