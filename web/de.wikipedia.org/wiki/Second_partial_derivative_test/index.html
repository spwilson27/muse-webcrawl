Kriterium der zweiten Ableitung (Second Partial Derivative Test)

Das Kriterium der zweiten Ableitung (englisch second partial derivative test) ist ein Verfahren der Analysis mehrerer Variablen, mit dem kritische Punkte einer Funktion zweier Veränderlicher als lokales Maximum, lokales Minimum oder Sattelpunkt klassifiziert werden können.

Ausgangspunkt

Ein Punkt (x0, y0) heißt kritischer Punkt einer zweimal stetig differenzierbaren Funktion f(x, y), wenn dort beide partiellen Ableitungen erster Ordnung verschwinden, also der Gradient gleich null ist. An solchen Punkten kann ein Extremum vorliegen, muss es aber nicht.

Das Kriterium

Man bildet die Determinante der Hesse-Matrix im kritischen Punkt:

D = fxx · fyy − (fxy)²

  • Ist D > 0 und fxx > 0, so liegt ein lokales Minimum vor.
  • Ist D > 0 und fxx < 0, so liegt ein lokales Maximum vor.
  • Ist D < 0, so liegt ein Sattelpunkt vor; der Punkt ist kein Extremum.
  • Ist D = 0, so ist das Kriterium nicht anwendbar; der Punkt muss mit anderen Methoden untersucht werden.

Anschauliche Deutung

Die Größen fxx und fyy beschreiben die Krümmung der Funktion in Richtung der Koordinatenachsen, während fxy die „Verwindung“ der Fläche angibt. Nur wenn die Krümmung in beiden Achsrichtungen dasselbe Vorzeichen hat und stärker ist als die Verwindung, entsteht ein Extremum; anderenfalls liegt ein Sattel vor.

Beispiel

Für f(x, y) = x² + y² ist der einzige kritische Punkt der Ursprung. Dort gilt fxx = 2, fyy = 2 und fxy = 0, also D = 4 > 0 mit fxx > 0: Der Ursprung ist ein lokales (und globales) Minimum.
