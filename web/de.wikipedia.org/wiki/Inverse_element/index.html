Inverses Element

In der Algebra heißt ein Element invers zu einem Element a bezüglich einer Verknüpfung, wenn ihre Verknüpfung das neutrale Element ergibt. In einer Gruppe besitzt jedes Element genau ein Inverses, das üblicherweise mit a⁻¹ (multiplikativ) oder −a (additiv) bezeichnet wird.

Beispiele

Bezüglich der Addition ganzer Zahlen ist −3 das Inverse zu 3, da 3 + (−3) = 0 gilt. Bezüglich der Multiplikation rationaler Zahlen ist der Kehrwert 1/a das Inverse zu a (für a ≠ 0); die Zahl 0 besitzt kein multiplikatives Inverses. Bei Matrizen ist das Inverse die Inverse Matrix, die nur für reguläre (invertierbare) Matrizen existiert. Für Funktionen entspricht das inverse Element der Umkehrfunktion, sofern diese existiert.

Eigenschaften

Das Inverse des Inversen ist das Element selbst: (a⁻¹)⁻¹ = a. Für das Inverse einer Verknüpfung zweier Elemente gilt (a · b)⁻¹ = b⁻¹ · a⁻¹, das heißt, die Reihenfolge kehrt sich um.
