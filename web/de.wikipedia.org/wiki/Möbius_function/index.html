Möbius-Funktion

Die Möbius-Funktion μ(n), benannt nach August Ferdinand Möbius, ist eine wichtige multiplikative Funktion der Zahlentheorie. Sie ist definiert durch:

  • μ(n) = 1, wenn n ein Produkt einer geraden Anzahl verschiedener Primzahlen ist,
  • μ(n) = −1, wenn n ein Produkt einer ungeraden Anzahl verschiedener Primzahlen ist,
  • μ(n) = 0, wenn n durch das Quadrat einer Primzahl teilbar ist.

Es gilt μ(1) = 1.

Eigenschaften

Die Möbius-Funktion ist multiplikativ, aber nicht vollständig multiplikativ. Ihre Summationsfunktion, die Mertens-Funktion M(x) = Σ μ(n), spielt eine Rolle im Zusammenhang mit der Riemannschen Vermutung. Die grundlegende Eigenschaft Σd|n μ(d) = 0 für n > 1 führt zur Möbiusschen Umkehrformel.

Anwendungen

Die Möbius-Funktion tritt in der Farey-Folge, bei der Berechnung der Anzahl aperiodischer Halsketten und in der physikalischen Beschreibung des Quanten-Hall-Effekts auf. Sie ist über die Dirichlet-Faltung die Inverse der konstanten Funktion 1.
