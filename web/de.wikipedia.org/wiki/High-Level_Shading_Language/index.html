Die High-Level Shading Language (HLSL) ist eine von Microsoft entwickelte Programmiersprache zur Erstellung von Shadern für die Grafik-API Direct3D. Sie wurde mit DirectX 9 eingeführt und ähnelt syntaktisch der Programmiersprache C. HLSL-Programme werden zur Laufzeit oder vorab in einen Zwischencode (DXBC bzw. DXIL) übersetzt und auf der GPU ausgeführt.

Geschichte

HLSL entstand aus einer Zusammenarbeit zwischen Microsoft und Nvidia; die verwandte Sprache Cg (C for Graphics) von Nvidia ist weitgehend kompatibel. Mit jedem neuen Shader Model wurden zusätzliche Fähigkeiten eingeführt, etwa Geometrie-Shader in Shader Model 4.0 (DirectX 10) und Compute-Shader in Shader Model 5.0 (DirectX 11). Mit DirectX 12 und Shader Model 6.0 wechselte der Compiler zur LLVM-basierten DXIL-Darstellung (DirectX Intermediate Language).

Shadertypen

  • Vertex-Shader – verarbeiten einzelne Vertices und transformieren deren Positionen.
  • Pixel-Shader (Fragment-Shader) – berechnen die Farbe einzelner Pixel.
  • Geometrie-Shader – erzeugen oder verwerfen Primitive.
  • Hull- und Domain-Shader – steuern die Tessellation.
  • Compute-Shader – für allgemeine Berechnungen auf der GPU (GPGPU).
  • Mesh- und Amplification-Shader – moderne Geometrie-Pipeline seit Shader Model 6.5.
  • Raytracing-Shader – für hardwarebeschleunigtes Raytracing (DXR).

Beispiel

float4 main(float4 pos : SV_POSITION, float2 uv : TEXCOORD) : SV_TARGET
{
    return tex.Sample(samp, uv);
}
