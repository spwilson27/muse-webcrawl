Zuordnungsproblem


Bipartiter Graph einer Zuordnung

Das Zuordnungsproblem (englisch assignment problem) ist ein klassisches Problem der kombinatorischen Optimierung: Eine Menge von Agenten soll so einer gleich großen Menge von Aufgaben zugeordnet werden, dass jeder Agent genau eine Aufgabe übernimmt, jede Aufgabe genau einmal vergeben wird und die Gesamtkosten minimal (oder der Gesamtnutzen maximal) sind. Die Kosten jeder möglichen Zuordnung sind durch eine Kostenmatrix gegeben.

Mathematische Formulierung

Mit binären Entscheidungsvariablen xij, die angeben, ob Agent i der Aufgabe j zugeordnet wird, lautet das Problem: Minimiere die Summe aller cij·xij unter den Bedingungen, dass jede Zeile und jede Spalte der Zuordnung genau eine Eins enthält. Das lineare Zuordnungsproblem ist ein Spezialfall des Transportproblems und kann als ganzzahliges lineares Programm formuliert werden; wegen der totalen Unimodularität der Koeffizientenmatrix liefert bereits die lineare Relaxierung eine ganzzahlige Lösung.

Lösungsverfahren

Das bekannteste Verfahren ist die Ungarische Methode (Kuhn-Munkres-Algorithmus), die Harold Kuhn 1955 auf Arbeiten der ungarischen Mathematiker Dénes Kőnig und Jenő Egerváry aufbauend veröffentlichte; James Munkres verbesserte ihre Laufzeit auf polynomiell O(n³). Weitere Verfahren sind der Jonker-Volgenant-Algorithmus und Auktionsalgorithmen. Spezialfälle wie das Bottleneck-Zuordnungsproblem minimieren statt der Summe die größte Einzelzuordnung.

Anwendungen

Anwendungen reichen von der Personaleinsatz- und Maschinenbelegungsplanung über die Zuordnung von Landebahnen und Gates an Flughäfen bis zur Objektverfolgung in der Bildverarbeitung und dem Matching in zweiseitigen Märkten.
