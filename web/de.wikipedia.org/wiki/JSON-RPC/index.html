JSON-RPC

JSON-RPC ist ein zustandsloses, schlankes Protokoll für entfernte Prozeduraufrufe (Remote Procedure Call), das das Datenformat JSON zur Kodierung verwendet. Es wurde ab 2005 entwickelt; die Spezifikation JSON-RPC 2.0 erschien 2010.

Funktionsweise

Der Client sendet eine Anfrage (Request) mit den Feldern jsonrpc, method, params und id. Der Server antwortet mit dem Ergebnis oder einem Fehlerobjekt. Benachrichtigungen (Notifications) kommen ohne ID aus und erhalten keine Antwort. Stapelverarbeitung (Batch) erlaubt das Senden mehrerer Anfragen in einem Array.

Eigenschaften

JSON-RPC ist transportunabhängig und kann über HTTP, WebSockets oder TCP verwendet werden. Es wird unter anderem von Ethereum-Nodes, Kodi und verschiedenen Entwicklungswerkzeugen eingesetzt.
