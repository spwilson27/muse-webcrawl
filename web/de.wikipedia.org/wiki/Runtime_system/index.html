Laufzeitsystem

Ein Laufzeitsystem (englisch runtime system oder runtime environment) ist in der Informatik die Softwareumgebung, die ein Programm während seiner Ausführung (Laufzeit) unterstützt. Es stellt Dienste bereit, die über die Möglichkeiten des reinen Maschinencodes hinausgehen, etwa automatische Speicherbereinigung (Garbage Collection), Typprüfung zur Laufzeit, Ausnahmebehandlung und Nebenläufigkeitssteuerung.

Beispiele

Bekannte Laufzeitsysteme sind die Java Virtual Machine (JVM) für Java-Bytecode, die Common Language Runtime (CLR) für .NET-Sprachen und die Laufzeitumgebung Node.js für JavaScript außerhalb des Browsers. Auch die Laufzeitbibliotheken nativ übersetzter Sprachen bilden ein minimales Laufzeitsystem, das etwa den Programmstart vorbereitet und Speicherfunktionen bereitstellt.

Abgrenzung zum Betriebssystem

Während das Betriebssystem die grundlegenden Ressourcen wie Prozesse, Dateien und Netzwerke verwaltet, arbeitet das Laufzeitsystem sprachspezifisch oberhalb dieser Schicht. Es kann zusätzliche Abstraktionen schaffen – beispielsweise virtuelle Threads oder einheitliche Fehlerbehandlung – und sorgt dafür, dass Programme unabhängig von der konkreten Hardware weitgehend gleich ausgeführt werden.
