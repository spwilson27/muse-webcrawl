Satz von Hall

Der Satz von Hall (englisch Hall's marriage theorem), benannt nach dem britischen Mathematiker Philip Hall (1935), ist ein Satz der Kombinatorik und Graphentheorie. Er gibt eine notwendige und hinreichende Bedingung dafür an, dass in einem bipartiten Graphen eine Paarung (Matching) existiert, die alle Knoten einer Partition überdeckt.

Aussage

Anschaulich formuliert: Gegeben seien eine Gruppe von Frauen und eine Gruppe von Männern, wobei jede Frau eine (nichtleere) Menge von Männern kennt, die sie heiraten würde. Dann kann jede Frau einen ihr bekannten Mann heiraten (und kein Mann wird zweimal verheiratet) genau dann, wenn für jede beliebige Auswahl von Frauen die Zahl der von ihnen insgesamt bekannten Männer mindestens so groß ist wie die Zahl der Frauen (Hallsche Bedingung).

Formale Fassung

Für eine Familie endlicher Mengen S1, …, Sn existiert ein System verschiedener Repräsentanten genau dann, wenn für jede Teilfamilie die Vereinigung der Mengen mindestens so viele Elemente enthält wie die Teilfamilie Mengen. Der Satz hat zahlreiche Anwendungen, etwa auf Lateinische Quadrate, den Satz von König und Zuordnungsprobleme.
