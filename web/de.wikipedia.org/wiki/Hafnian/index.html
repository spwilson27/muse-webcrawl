Hafnian

Das Hafnian ist eine Größe in der linearen Algebra, die einer symmetrischen Matrix zugeordnet wird und eng mit der Permanente verwandt ist. Der Begriff wurde nach der Stadt Kopenhagen (lateinisch Hafnia) benannt.

Definition

Für eine symmetrische 2n×2n-Matrix A ist das Hafnian definiert als die Summe über alle perfekten Paarungen (perfekte Matchings) der Indexmenge: haf(A) = Σ Π ai,j, wobei das Produkt über die n Paare (i, j) der jeweiligen Paarung läuft und die Summe über alle (2n−1)!! Paarungen gebildet wird. Für ungerade Dimensionen ist das Hafnian per Definition null.

Eigenschaften

Das Hafnian steht in Beziehung zur Permanente: Für eine Matrix der Blockform [[0, B], [BT, 0]] gilt haf = per(B). Außerdem ist das Hafnian der Kovarianzmatrix eines gaußschen Zustands proportional zur Wahrscheinlichkeit bestimmter Messergebnisse.

Anwendungen

Bedeutung erlangte das Hafnian in der Quantenoptik und im Quantencomputing: Beim Gaussian Boson Sampling hängt die Wahrscheinlichkeit, ein bestimmtes Photonenzählmuster zu messen, vom Hafnian einer Teilmatrix ab. Die Berechnung des Hafnians allgemeiner Matrizen ist #P-schwer, was als Argument für einen möglichen Quantenvorteil dieses Verfahrens dient.
