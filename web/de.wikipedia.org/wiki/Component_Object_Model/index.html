Component Object Model

Das Component Object Model (COM) ist eine von Microsoft entwickelte Technologie, die es Softwarekomponenten ermöglicht, prozess- und sprachübergreifend miteinander zu kommunizieren. COM wurde 1993 mit OLE 2.0 eingeführt und bildet die Grundlage zahlreicher Windows-Technologien, darunter OLE, ActiveX und DCOM.

Konzept

COM definiert ein binäres Standardschnittstellenformat: Objekte stellen ihre Funktionalität über Schnittstellen bereit, die aus einer Liste von Methoden bestehen und über eine vtable aufgerufen werden. Jede Schnittstelle besitzt eine eindeutige Kennung (Interface ID, IID), jede Komponente eine Klassenkennung (CLSID). Die Basisschnittstelle IUnknown stellt Methoden zur Referenzzählung und zum Abfragen weiterer Schnittstellen bereit.

Varianten

Mit DCOM (Distributed COM) wurde das Modell auf netzwerkweite Kommunikation erweitert. COM+ fasste später Dienste wie Transaktionen und Objektpooling unter dem Dach der Microsoft Transaction Server- und später der Enterprise Services zusammen. Unter Windows bildet WinRT ein modernes, konzeptionell verwandtes Komponentenmodell.

Bedeutung

COM ermöglichte erstmals eine breite Wiederverwendung binärer Komponenten unabhängig von der verwendeten Programmiersprache und prägte die Windows-Softwareentwicklung der 1990er- und 2000er-Jahre maßgeblich.
