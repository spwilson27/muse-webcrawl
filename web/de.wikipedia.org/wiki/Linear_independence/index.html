Lineare Unabhängigkeit

Lineare Unabhängigkeit ist ein Begriff aus dem mathematischen Teilgebiet der linearen Algebra. Eine Familie von Vektoren eines Vektorraums heißt linear unabhängig, wenn sich keiner der Vektoren als Linearkombination der übrigen darstellen lässt. Andernfalls heißen die Vektoren linear abhängig.

Definition

Eine Familie von Vektoren (vi)i∈I eines Vektorraums V über einem Körper K heißt linear unabhängig, wenn für jede endliche Teilfamilie und alle Skalare ai ∈ K aus der Gleichung

a1v1 + a2v2 + … + anvn = 0

stets folgt, dass alle Skalare gleich null sind: a1 = a2 = … = an = 0. Die einzige Linearkombination, die den Nullvektor ergibt, ist also die triviale.

Beispiele

Im dreidimensionalen Raum ℝ³ sind die drei Einheitsvektoren e1 = (1,0,0), e2 = (0,1,0) und e3 = (0,0,1) linear unabhängig. Dagegen sind die Vektoren (1,0), (0,1) und (1,1) im ℝ² linear abhängig, da (1,1) = (1,0) + (0,1) gilt.

Eigenschaften

  • Der Nullvektor ist zu jedem Vektor linear abhängig; eine Familie, die den Nullvektor enthält, ist stets linear abhängig.
  • Eine linear unabhängige Familie, die zusätzlich den Vektorraum aufspannt, bildet eine Basis des Vektorraums.
  • In einem n-dimensionalen Vektorraum können höchstens n Vektoren linear unabhängig sein.
  • Die Vektoren einer Basis sind definitionsgemäß linear unabhängig; ihre Anzahl ist die Dimension des Raums.

Bedeutung

Die lineare Unabhängigkeit ist grundlegend für die Theorie der Basen und der Dimension von Vektorräumen. Mit ihr lässt sich prüfen, ob eine Menge von Vektoren eine Basis eines Unterraums bildet, und sie spielt eine zentrale Rolle bei der Lösung linearer Gleichungssysteme.
