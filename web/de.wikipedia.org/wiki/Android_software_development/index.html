Android-Softwareentwicklung

Offizielle Sprachen: Kotlin, Java

IDE: Android Studio

SDK: Android SDK (API-Level)

Vertrieb: Google Play, APK/AAB-Dateien

Die Android-Softwareentwicklung (englisch Android software development) bezeichnet den Prozess der Erstellung von Anwendungen (Apps) für das Betriebssystem Android. Entwickelt wird mit dem Android SDK, typischerweise in der offiziellen Entwicklungsumgebung Android Studio.

Programmiersprachen

Ursprünglich wurden Android-Apps vor allem in Java geschrieben. Seit der Google I/O 2017 wird Kotlin offiziell unterstützt; 2019 erklärte Google die Android-Entwicklung für „Kotlin-first“, sodass neue APIs und Bibliotheken primär für Kotlin konzipiert werden. Für leistungskritische Komponenten kann mit dem Native Development Kit (NDK) in C oder C++ programmiert werden. Daneben existieren Frameworks für plattformübergreifende Entwicklung wie Flutter (Dart) und React Native (JavaScript/TypeScript).

Entwicklungswerkzeuge

Das Android SDK enthält die API-Bibliotheken für die jeweiligen Android-Versionen (API-Level), Emulatoren, Debugger und Build-Werkzeuge. Der Build erfolgt mit Gradle und dem Android-Gradle-Plug-in. Android Studio basiert auf IntelliJ IDEA und bietet unter anderem einen Layout-Editor, Profiler und Unterstützung für das UI-Framework Jetpack Compose, mit dem Oberflächen deklarativ in Kotlin beschrieben werden.

Anwendungskomponenten und Vertrieb

Zentrale Bausteine einer Android-App sind Aktivitäten (Bildschirme), Dienste (Hintergrundprozesse), Broadcast Receiver und Content Provider, die im Android-Manifest deklariert werden. Apps laufen jeweils in einer eigenen Sandbox und benötigen für sensible Funktionen Laufzeitberechtigungen. Vertrieben werden sie vor allem über den Google Play Store; das Installationsformat ist das Android App Bundle (AAB) beziehungsweise die APK-Datei.
