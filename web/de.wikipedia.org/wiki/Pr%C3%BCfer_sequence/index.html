Prüfer-Code

Der Prüfer-Code (englisch Prüfer sequence) ist in der Graphentheorie eine bijektive Codierung der beschrifteten Bäume. Er wurde 1918 von Heinz Prüfer eingeführt, um die Formel von Cayley zu beweisen, nach der es auf einer Menge von n beschrifteten Knoten genau nn−2 verschiedene Spannbäume gibt.

Konstruktion

Gegeben sei ein Baum mit den Knoten 1 bis n. Der Prüfer-Code entsteht, indem man wiederholt das Blatt mit der kleinsten Beschriftung entfernt und die Beschriftung seines einzigen Nachbarn in die Folge aufnimmt. Das Verfahren endet, wenn nur noch zwei Knoten übrig sind. Der entstehende Code hat die Länge n − 2, und jede Folge dieser Länge über der Menge {1, …, n} entspricht genau einem Baum.

Rückgewinnung des Baumes

Die Umkehrung ist ebenfalls algorithmisch einfach: Aus dem Code lässt sich ablesen, wie oft jeder Knoten im Baum als Nachbar auftritt; der Grad eines Knotens ist um eins größer als die Anzahl seiner Vorkommen im Code. Man verbindet schrittweise den kleinsten Knoten, der nicht mehr im restlichen Code vorkommt, mit dem ersten Codeelement.

Anwendungen

Neben dem klassischen Beweis der Cayley-Formel wird der Prüfer-Code in der algorithmischen Graphentheorie und in evolutionären Algorithmen verwendet, etwa zur Codierung von Spannbäumen in genetischen Algorithmen, sowie zur gleichverteilten Zufallserzeugung beschrifteter Bäume.
