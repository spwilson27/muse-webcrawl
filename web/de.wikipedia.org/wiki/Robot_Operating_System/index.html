Robot Operating System

Robot Operating System (ROS)
Erstveröffentlichung2010 (ROS 1.0)
EntwicklerOpen Robotics, Community
LizenzBSD bzw. Apache 2.0
ArtMiddleware / Framework für Robotik

Das Robot Operating System (ROS) ist eine freie Middleware beziehungsweise ein Software-Framework zur Entwicklung von Roboter-Software. Trotz des Namens handelt es sich nicht um ein klassisches Betriebssystem, sondern um eine Sammlung von Werkzeugen, Bibliotheken und Kommunikationsmechanismen, die auf Betriebssystemen wie Linux aufsetzt.

Konzept

ROS-Anwendungen bestehen aus einzelnen Prozessen („Nodes“), die über Nachrichten miteinander kommunizieren. Die Kommunikation erfolgt über sogenannte Topics nach dem Publish-Subscribe-Prinzip, über Dienste (Services) mit Anfrage-Antwort-Muster sowie über Aktionen für länger laufende Aufgaben. Hinzu kommen Werkzeuge für Visualisierung (RViz), Simulation (Gazebo), Aufzeichnung von Daten (rosbag) und ein umfangreiches Ökosystem wiederverwendbarer Pakete, etwa für Navigation, Wahrnehmung und Bewegungsplanung.

Geschichte

ROS entstand ab 2007 am Stanford Artificial Intelligence Laboratory und wurde anschließend bei dem Robotikunternehmen Willow Garage weiterentwickelt; die erste stabile Version erschien 2010. Seit 2013 wird das Projekt von der Open Source Robotics Foundation (heute Open Robotics) betreut. Die grundlegend überarbeitete zweite Generation, ROS 2, baut auf dem DDS-Standard auf und ist auch für industrielle und echtzeitnahe Anwendungen sowie für Systeme ohne zentrale Master-Instanz ausgelegt.
