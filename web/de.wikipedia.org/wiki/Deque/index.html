Deque

Eine Deque (von englisch double-ended queue, gesprochen meist „deck") ist eine abstrakte Datenstruktur der Informatik. Sie verallgemeinert die Warteschlange und den Stapel: Elemente können sowohl am vorderen als auch am hinteren Ende eingefügt und entfernt werden.

Operationen

  • push_front: Einfügen eines Elements am Anfang
  • push_back: Einfügen eines Elements am Ende
  • pop_front: Entfernen des ersten Elements
  • pop_back: Entfernen des letzten Elements
  • front / back: Lesen des ersten bzw. letzten Elements

Alle Einfüge- und Entnahmeoperationen laufen in (amortisiert) konstanter Zeit O(1).

Implementierung

Deques werden häufig als doppelt verkettete Listen oder als Arrays aus Speicherblöcken realisiert. Die Standardbibliothek von C++ stellt mit std::deque einen Container bereit, der zusätzlich wahlfreien Zugriff in konstanter Zeit erlaubt; in Java existiert die Schnittstelle java.util.Deque mit der Implementierung ArrayDeque, in Python das collections.deque.

Anwendungen

Deques eignen sich für die Implementierung von Warteschlangen und Stapeln in einer gemeinsamen Struktur, für gleitende Fenster in der Signalverarbeitung sowie für Algorithmen wie die Breitensuche mit 0-1-Gewichten (0-1-BFS).
