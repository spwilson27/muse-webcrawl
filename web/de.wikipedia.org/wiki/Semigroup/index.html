Halbgruppe

Eine Halbgruppe (englisch semigroup) ist in der abstrakten Algebra eine Menge mit einer assoziativen zweistelligen Verknüpfung. Sie ist damit eine allgemeinere Struktur als eine Gruppe: Weder die Existenz eines neutralen Elements noch die Existenz inverser Elemente wird gefordert. Besitzt eine Halbgruppe ein neutrales Element, nennt man sie ein Monoid.

Definition

Eine Halbgruppe ist ein Paar (S, ·) aus einer Menge S und einer Verknüpfung · : S × S → S, für die das Assoziativgesetz gilt: Für alle a, b, c aus S ist (a · b) · c = a · (b · c). Wegen der Assoziativität kann man auf Klammern verzichten und Produkte aus beliebig vielen Faktoren eindeutig schreiben.

Beispiele

Die natürlichen Zahlen bilden mit der Addition wie auch mit der Multiplikation eine Halbgruppe. Die Menge aller Abbildungen einer Menge in sich selbst bildet mit der Hintereinanderausführung eine Halbgruppe (die volle Transformationshalbgruppe); sie ist das Standardbeispiel, in das sich jede Halbgruppe einbetten lässt (Satz von Cayley für Halbgruppen). Auch die Menge der Wörter über einem Alphabet mit der Konkatenation ist eine Halbgruppe, die freie Halbgruppe.

Anwendungen

Halbgruppen spielen eine Rolle in der Theorie formaler Sprachen und Automaten, bei der Untersuchung partieller Differentialgleichungen (stark stetige Halbgruppen von Operatoren beschreiben die Zeitentwicklung physikalischer Systeme) sowie in der theoretischen Informatik.
