Kofaserung


Schema einer Kofaserung

Eine Kofaserung (englisch cofibration) ist ein Begriff aus der algebraischen Topologie, genauer aus der Homotopietheorie. Dual zur Faserung beschreibt eine Kofaserung eine Einbettung eines Raumes in einen anderen, entlang derer sich Homotopien fortsetzen lassen. Kofaserungen bilden zusammen mit Faserungen und schwachen Äquivalenzen die Grundstruktur einer Modellkategorie.

Definition

Eine stetige Abbildung i : A → X heißt Kofaserung, wenn sie die Homotopie-Erweiterungseigenschaft (HEP) besitzt: Zu jeder stetigen Abbildung f : X → Y und jeder Homotopie von f ∘ i auf A existiert eine Fortsetzung der Homotopie auf ganz X. Anschaulich bedeutet dies, dass Homotopien, die auf dem Teilraum A beginnen, auf den ganzen Raum ausgedehnt werden können, ohne die bereits erreichte Abbildung auf A zu stören.

Beispiele und Eigenschaften

  • Die Inklusion der Sphäre Sn−1 als Rand der Vollkugel Dn ist eine Kofaserung.
  • Die Inklusion eines Unterkomplexes in einen CW-Komplex ist eine Kofaserung.
  • Für eine Kofaserung ist die Abbildung stets eine abgeschlossene Einbettung (unter milden Voraussetzungen an die Räume).

Der Quotient X/A heißt Kofaser der Abbildung; aus einer Kofaserung entsteht eine lange exakte Sequenz von Homotopiegruppen, das duale Gegenstück zur langen exakten Sequenz einer Faserung. Jede stetige Abbildung lässt sich bis auf Homotopieäquivalenz durch eine Kofaserung ersetzen, indem man sie in ihren Abbildungszylinder einbettet.

Modellkategorien

In der Modellkategorie der topologischen Räume (nach Quillen) sind die Kofaserungen genau die Retrakte relativer CW-Inklusionen. Das Konzept wurde in den 1960er Jahren unter anderem von Dieter Puppe und im Rahmen der Theorie der Modellkategorien von Daniel Quillen systematisiert.
