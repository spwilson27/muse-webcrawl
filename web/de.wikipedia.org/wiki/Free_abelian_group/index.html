Freie abelsche Gruppe

Eine freie abelsche Gruppe ist in der Algebra eine abelsche Gruppe, die eine Basis besitzt, das heißt eine Teilmenge, deren Elemente die Gruppe erzeugen und zwischen denen keine nichttrivialen Relationen bestehen. Freie abelsche Gruppen sind genau die freien Objekte in der Kategorie der abelschen Gruppen beziehungsweise die freien Moduln über dem Ring der ganzen Zahlen.

Definition und Beispiele

Eine abelsche Gruppe F heißt frei, wenn es eine Teilmenge B ⊆ F gibt, sodass sich jedes Element von F eindeutig als endliche Linearkombination von Elementen aus B mit ganzzahligen Koeffizienten darstellen lässt. Die Menge B heißt dann Basis von F; ihre Mächtigkeit heißt Rang der Gruppe und ist wohldefiniert.

Das einfachste Beispiel ist die additive Gruppe der ganzen Zahlen (ℤ, +) mit Basis {1}. Endlich erzeugte freie abelsche Gruppen sind genau die Gruppen ℤn. Jede abelsche Gruppe ist ein Quotient einer freien abelschen Gruppe.

Universelle Eigenschaft

Ist B eine Menge und F die freie abelsche Gruppe über B, so lässt sich jede Abbildung von B in eine abelsche Gruppe A eindeutig zu einem Gruppenhomomorphismus F → A fortsetzen. Diese universelle Eigenschaft charakterisiert freie abelsche Gruppen bis auf Isomorphie.
