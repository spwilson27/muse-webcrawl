Ravioli-Code

Ravioli-Code ist eine scherzhafte Bezeichnung aus der Softwareentwicklung für einen Programmierstil, bei dem ein Programm aus einer sehr großen Zahl winziger, für sich genommen verständlicher Objekte oder Komponenten besteht, deren Zusammenspiel jedoch schwer zu durchschauen ist. Der Begriff spielt auf Ravioli an: viele kleine, einzeln gut verdauliche Einheiten, die zusammen ein unübersichtliches Ganzes bilden.

Hintergrund

Der Ausdruck wird als Gegenstück zum „Spaghetti-Code“ (stark verwobene, unstrukturierte Kontrollflüsse) und zum „Lasagne-Code“ (zu viele übereinanderliegende Abstraktionsschichten) verwendet. Er kritisiert eine übertriebene Anwendung der objektorientierten Programmierung, bei der das eigentliche Verhalten über unzählige kleine Klassen und indirekte Aufrufe verteilt ist, sodass das Verständnis des Gesamtablaufs erschwert wird („Was passiert eigentlich, wenn …?“).
