Norm (Mathematik)

Eine Norm ist in der Mathematik eine Abbildung, die einem Vektor oder einer Funktion eine nichtnegative reelle Zahl zuordnet, die als seine Länge oder Größe interpretiert wird. Ein Vektorraum, auf dem eine Norm definiert ist, heißt normierter Raum.

Definition

Eine Abbildung ‖·‖ von einem Vektorraum V über den reellen oder komplexen Zahlen in die reellen Zahlen heißt Norm, wenn für alle Vektoren x, y und alle Skalare λ gilt:

  • Definitheit: ‖x‖ = 0 genau dann, wenn x = 0
  • Absolute Homogenität: ‖λx‖ = |λ| · ‖x‖
  • Dreiecksungleichung: ‖x + y‖ ≤ ‖x‖ + ‖y‖

Beispiele

Wichtige Normen auf dem ℝⁿ sind die p-Normen, darunter die euklidische Norm (p = 2), die Summennorm (p = 1) und die Maximumsnorm (p = ∞). Auf Funktionenräumen sind etwa die Supremumsnorm und die Lp-Normen gebräuchlich.

Normierte Räume

Jede Norm induziert über d(x, y) = ‖x − y‖ eine Metrik und damit eine Topologie. Ist ein normierter Raum bezüglich dieser Metrik vollständig, heißt er Banachraum.
