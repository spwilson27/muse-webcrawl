Deep Web

Das Deep Web (deutsch „tiefes Netz“) bezeichnet den Teil des World Wide Web, der von herkömmlichen Suchmaschinen nicht indexiert wird und nicht über eine direkte URL-Eingabe frei zugänglich ist. Vom Deep Web zu unterscheiden ist das Darknet: ein kleiner Teilbereich, der nur mit spezieller Software und anonymisierenden Netzwerken wie Tor erreichbar ist.

Inhalte

Der weitaus größte Teil des Deep Web besteht aus alltäglichen, legalen Inhalten, darunter:

  • Inhalte hinter Anmeldeschranken (Webmail, Online-Banking, soziale Netzwerke, Streamingdienste)
  • Dynamisch aus Datenbanken erzeugte Seiten, etwa Kataloge, Buchungs- und Verwaltungssysteme
  • Wissenschaftliche Datenbanken und Bibliothekskataloge („Academic Invisible Web“)
  • Nicht verlinkte, unindexierte oder durch robots.txt ausgeschlossene Seiten sowie Intranets

Schätzungen zur Größe gehen auf eine viel zitierte Studie von Michael Bergman aus dem Jahr 2001 zurück, die das Deep Web auf ein Vielfaches – damals das 400- bis 550-fache – des sichtbaren („Surface“) Web bezifferte; diese Zahlen gelten heute als kaum mehr überprüfbar.

Abgrenzung zum Darknet

In der medialen Berichterstattung werden Deep Web und Darknet häufig gleichgesetzt. Tatsächlich ist das Darknet nur ein kleiner, absichtlich verborgener Ausschnitt (etwa Onion-Dienste im Tor-Netzwerk), während das Deep Web schlicht alle nicht indexierten Inhalte umfasst – vom passwortgeschützten Kundenkonto bis zur Bibliotheksdatenbank. Zur Suche in Teilen des Deep Web existieren spezialisierte Verzeichnis- und Suchdienste, sogenannte Tiefensuchmaschinen.
