Client-Server-Modell

Das Client-Server-Modell beschreibt eine Architektur verteilter Systeme, bei der ein Server Dienste bereitstellt und Clients diese über ein Netzwerk anfordern. Der Client initiiert die Kommunikation mit einer Anfrage (Request), der Server antwortet (Response).

Merkmale

Server sind in der Regel leistungsstarke, dauerhaft laufende Programme, die viele Clients gleichzeitig bedienen. Beispiele sind Webserver (HTTP), Mailserver, Datenbankserver und Dateiserver. Der Client stellt typischerweise die Benutzeroberfläche bereit, während Datenhaltung und Verarbeitung serverseitig erfolgen.

Varianten und Alternativen

Mehrschichtige Architekturen (Three-Tier) fügen eine mittlere Verarbeitungsschicht hinzu. Demgegenüber steht das Peer-to-Peer-Modell, bei dem alle Teilnehmer gleichberechtigt Dienste anbieten und nutzen. Auch serviceorientierte Architekturen und Microservices bauen auf dem Client-Server-Prinzip auf.
