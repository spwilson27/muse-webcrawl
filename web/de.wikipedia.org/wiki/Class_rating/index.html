Class rating (Klassenberechtigung)

Ein Class rating (deutsch: Klassenberechtigung) ist eine Berechtigung in einer Pilotenlizenz für Luftfahrzeuge, die es dem Inhaber erlaubt, Flugzeuge einer bestimmten Klasse zu führen, etwa einmotorige Flugzeuge mit Kolbenmotor (SEP, single engine piston) oder mehrmotorige Flugzeuge mit Kolbenmotor (MEP, multi engine piston). Im Unterschied dazu berechtigt ein Type Rating nur für einen bestimmten Flugzeugtyp.

Regelungen

In Europa werden Klassenberechtigungen nach den Regeln der EASA (Part-FCL) erteilt. Sie sind in der Regel zwei Jahre gültig und können durch eine Befähigungsüberprüfung oder durch den Nachweis ausreichender Flugerfahrung verlängert werden. Zu den Klassen zählen unter anderem SEP (Land/Sea), MEP, TMG (Reisemotorsegler) sowie bestimmte Gruppen von Flugzeugtypen.

Ausbildung

Die Ausbildung für eine Klassenberechtigung umfasst theoretischen Unterricht und eine praktische Ausbildung mit Fluglehrer, gefolgt von einer praktischen Prüfung (Skill Test) mit einem anerkannten Prüfer.
