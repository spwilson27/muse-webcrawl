Apache Subversion
Entwickler: Apache Software Foundation
Erstveröffentlichung: 2000 (Version 1.0: 2004)
Kategorie: Versionsverwaltung
Lizenz: Apache License 2.0

Apache Subversion (kurz SVN) ist ein freies, zentrales System zur Versionsverwaltung von Dateien und Verzeichnissen. Es wurde im Jahr 2000 von CollabNet mit dem Ziel begonnen, einen moderneren Nachfolger für das weit verbreitete CVS zu schaffen, und ist seit 2010 ein Top-Level-Projekt der Apache Software Foundation.

Eigenschaften

Subversion verwaltet ein zentrales Repository, in dem jede Änderung als eigene, fortlaufend nummerierte Revision abgelegt wird. Im Unterschied zu CVS erfolgen Commits atomar – eine Übernahme erscheint entweder vollständig oder gar nicht –, und auch Verzeichnisse, Umbenennungen und Dateieigenschaften (Properties) werden versioniert. Verzweigungen (Branches) und Markierungen (Tags) werden als kostengünstige Kopien im Repository angelegt. Änderungen werden platzsparend als Deltas übertragen und gespeichert; auch Binärdateien lassen sich verwalten. Der Zugriff auf das Repository erfolgt über ein lokales Protokoll, über SSH oder über HTTP/WebDAV mit dem Apache-Modul mod_dav_svn. Bekannte grafische Clients sind TortoiseSVN für Windows und AnkhSVN für Visual Studio.

Verbreitung

Subversion war in den 2000er Jahren eines der meistgenutzten Versionsverwaltungssysteme in Unternehmen und Open-Source-Projekten (u. a. zeitweise für Apache-Projekte, KDE, GNOME und SourceForge). Seit etwa 2010 wurde es in vielen Bereichen vom verteilten System Git verdrängt, ist aber in industriellen Umgebungen mit großen Binärdateien weiterhin verbreitet.
