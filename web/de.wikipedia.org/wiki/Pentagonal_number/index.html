Fünfeckzahl

Eine Fünfeckzahl oder Pentagonalzahl ist eine Zahl, die sich durch ein regelmäßiges Fünfeck aus Punkten darstellen lässt. Fünfeckzahlen gehören zu den figurierten Zahlen und verallgemeinern die Dreieckszahlen und Quadratzahlen auf das regelmäßige Fünfeck (Pentagon).

Berechnung

Die n-te Fünfeckzahl wird durch die Formel

P5,n = n(3n − 1) / 2

berechnet. Die ersten Fünfeckzahlen sind 1, 5, 12, 22, 35, 51, 70, 92, 117, 145, … Die jeweils hinzukommende Schicht (Gnomon) eines fünfeckigen Punktmusters wächst dabei in einem gleichmäßigen Muster.

Eigenschaften

Jede dritte Fünfeckzahl ist durch 3 teilbar; das erzeugende Vieleck wächst abwechselnd an drei Seiten. Fünfeckzahlen stehen in enger Beziehung zu den Dreieckszahlen: Jede Fünfeckzahl lässt sich als Summe einer Dreieckszahl und weiterer einfacher Terme ausdrücken. Ob eine gegebene Zahl x eine Fünfeckzahl ist, lässt sich prüfen, indem man untersucht, ob (√(24x + 1) + 1) / 6 eine natürliche Zahl ist.

Verallgemeinerte Fünfeckzahlen

Setzt man in der Formel auch negative Indizes ein, erhält man die verallgemeinerten Fünfeckzahlen 0, 1, 2, 5, 7, 12, 15, 22, 26, 35, … Diese spielen eine zentrale Rolle im Pentagonalzahlensatz von Leonhard Euler, der eine Produktdarstellung im Zusammenhang mit Partitionen angibt und zur Herleitung einer Rekursionsformel für die Partitionsfunktion dient.
