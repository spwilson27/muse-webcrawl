Microsoft

Microsoft Corporation
Gründung: 4. April 1975
Gründer: Bill Gates, Paul Allen
Hauptsitz: Redmond, Washington, USA
Branche: Software, Cloud Computing, Hardware

Die Microsoft Corporation ist ein US-amerikanischer multinationaler Technologiekonzern mit Hauptsitz in Redmond im US-Bundesstaat Washington. Das Unternehmen wurde am 4. April 1975 von Bill Gates und Paul Allen gegründet und zählt zu den größten Softwareherstellern der Welt. Bekannt ist Microsoft vor allem für das Betriebssystem Windows, die Bürosoftware Microsoft Office (heute Microsoft 365), die Cloud-Plattform Microsoft Azure sowie die Spielkonsolen der Xbox-Reihe.

Geschichte

Microsoft begann mit BASIC-Interpretern für frühe Heimcomputer. Der Durchbruch gelang 1981 mit dem Betriebssystem MS-DOS für den IBM PC. 1985 erschien die erste Version von Windows, das sich in den 1990er Jahren zum dominierenden PC-Betriebssystem entwickelte. Ab den 2010er Jahren verlagerte das Unternehmen unter Vorstandschef Satya Nadella (seit 2014) seinen Schwerpunkt zunehmend auf Cloud-Dienste und Abonnementmodelle. Zu den bedeutenden Übernahmen zählen Skype (2011), LinkedIn (2016), GitHub (2018) und Activision Blizzard (2023).

Produkte

Zum Produktportfolio gehören neben Windows und Office unter anderem der Browser Microsoft Edge, das Datenbank- und Servergeschäft, die Entwicklerwerkzeuge um Visual Studio, die Kommunikationsplattform Teams sowie KI-Dienste unter dem Namen Copilot. Microsoft gehört gemessen an der Marktkapitalisierung regelmäßig zu den wertvollsten Unternehmen der Welt.
