Inverses System

Ein inverses System (auch projektives System) in einer Kategorie besteht aus einer gerichteten Indexmenge, einer Familie von Objekten und Übergangsmorphismen, die von höheren zu niedrigeren Indizes zeigen und miteinander verträglich sind.

Definition

Zu je zwei Indizes i ≤ j gehört ein Morphismus vom Objekt zum Index j zum Objekt zum Index i; für i = j ist dies die Identität, und die Morphismen erfüllen die Verkettungsbedingung. Das duale Konzept, bei dem die Pfeile in die andere Richtung zeigen, heißt direktes System.

Anwendungen

Aus einem inversen System lässt sich sein inverser Limes bilden. Inverse Systeme treten in der algebraischen Geometrie, bei profiniten Gruppen, in der homologischen Algebra und bei der Konstruktion der p-adischen Zahlen auf.
