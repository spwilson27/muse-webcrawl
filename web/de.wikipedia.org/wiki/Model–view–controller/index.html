Model View Controller

Model View Controller (MVC) ist ein Entwurfsmuster der Softwarearchitektur, das eine Anwendung in drei miteinander verbundene Komponenten teilt: das Model (Daten und Geschäftslogik), die View (Darstellung) und den Controller (Steuerung der Eingaben). Ziel ist die Trennung von Datenhaltung, Präsentation und Interaktionslogik, um Wartbarkeit und Wiederverwendbarkeit zu erhöhen.

Geschichte

Das Muster wurde Ende der 1970er-Jahre von Trygve Reenskaug am Xerox PARC für die Programmiersprache Smalltalk entwickelt und im Smalltalk-80-System umgesetzt. Später verbreitete es sich über grafische Benutzeroberflächen und wurde zum Standardmuster zahlreicher Webframeworks.

Komponenten

Das Model verwaltet die Daten und benachrichtigt die View über Änderungen. Die View stellt die Daten dar und leitet Benutzereingaben an den Controller weiter, der die Eingaben interpretiert und das Model verändert.

Verwendung

MVC liegt Frameworks wie Ruby on Rails, Django, ASP.NET MVC und Spring MVC zugrunde. Verwandte Muster sind Model View Presenter und Model View ViewModel.
