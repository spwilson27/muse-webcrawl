Hybrid Memory Cube

Der Hybrid Memory Cube (HMC) ist eine Speichertechnologie, bei der mehrere DRAM-Chips übereinandergestapelt und über Silizium-Durchkontaktierungen (Through-Silicon Vias, TSV) mit einem Logikchip verbunden werden. Entwickelt wurde sie von Micron Technology; 2011 gründete sich ein Konsortium aus Unternehmen wie Micron, Samsung und IBM zur Förderung des Standards.

Technik

Der Stapel bildet einen würfelförmigen Baustein, dessen unterste Schicht ein Steuerchip ist. Dieser organisiert den Zugriff auf die darüberliegenden DRAM-Ebenen und kommuniziert mit dem Prozessor über schnelle serielle Verbindungen. Dadurch erreicht der Hybrid Memory Cube deutlich höhere Bandbreiten – in der Größenordnung von über 100 GB/s – bei zugleich geringerem Energieverbrauch pro übertragenem Bit als klassischer DDR-Speicher.

Geschichte und Konkurrenz

Micron stellte erste Muster um 2013 vor; der Standard wurde in den Versionen HMC 1.0 und 2.0 weiterentwickelt. Der kommerzielle Durchbruch blieb jedoch aus, unter anderem wegen hoher Fertigungskosten. Micron stellte die Entwicklung 2018 ein. Die Konkurrenztechnologie High Bandwidth Memory (HBM), die ähnliche Stapelkonzepte nutzt, setzte sich dagegen in Grafikkarten und Beschleunigern für künstliche Intelligenz durch.
