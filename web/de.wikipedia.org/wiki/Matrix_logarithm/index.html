Matrixlogarithmus

Der Matrixlogarithmus (englisch matrix logarithm) ist in der Mathematik die Umkehrfunktion des Matrixexponentials: Eine Matrix B heißt Logarithmus einer Matrix A, wenn e^B = A gilt.

Existenz und Eindeutigkeit

Im Komplexen besitzt jede invertierbare Matrix mindestens einen Logarithmus; er ist im Allgemeinen nicht eindeutig, weil die Eigenwerte um Vielfache von 2πi verschoben werden können. Besitzt eine Matrix keine negativen reellen Eigenwerte, existiert ein ausgezeichneter reeller beziehungsweise komplexer Hauptlogarithmus (principal logarithm), der über die Potenzreihe log(E + X) = Σ (−1)^(k+1) X^k/k für hinreichend kleine X definiert und fortgesetzt werden kann. Im Reellen hat eine invertierbare Matrix genau dann einen reellen Logarithmus, wenn jeder Jordanblock zu einem negativen Eigenwert geradzahlig oft auftritt.

Anwendungen

Der Matrixlogarithmus spielt eine Rolle in der Theorie der Lie-Gruppen (als Umkehrung der Exponentialabbildung), bei der Interpolation von Transformationen in Computergrafik und Robotik (etwa zwischen Rotationen), in der Statistik sowie bei der Analyse linearer dynamischer Systeme. Numerische Verfahren beruhen häufig auf der inversen Scaling-and-Squaring-Methode mit Padé-Approximationen.
