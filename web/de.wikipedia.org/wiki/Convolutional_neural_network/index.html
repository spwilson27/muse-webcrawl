Convolutional Neural Network

Ein Convolutional Neural Network (CNN, deutsch etwa „faltendes neuronales Netz“) ist ein künstliches neuronales Netz, das vor allem zur Verarbeitung von Bilddaten und anderen gitterartig strukturierten Daten eingesetzt wird. CNNs gehören zu den erfolgreichsten Verfahren des Deep Learning und bilden die Grundlage vieler moderner Systeme der Computer Vision, etwa zur Objekterkennung, Bildklassifikation und Gesichtserkennung.

Aufbau

Ein CNN besteht typischerweise aus mehreren hintereinander geschalteten Schichttypen. Die Convolutional Layer (Faltungsschicht) wendet lernbare Filter (Kernel) auf das Eingabebild an und erzeugt sogenannte Feature Maps, die lokale Muster wie Kanten, Ecken oder Texturen erkennen. Darauf folgt meist eine nichtlineare Aktivierungsfunktion, häufig die ReLU-Funktion. Eine Pooling Layer reduziert die räumliche Auflösung, beispielsweise durch Max-Pooling, und macht die Repräsentation robuster gegenüber kleinen Verschiebungen. Am Ende des Netzes stehen eine oder mehrere vollständig verbundene Schichten (Fully Connected Layer), die die extrahierten Merkmale zu einer Klassifikation zusammenführen.

Geschichte

Die Grundideen gehen auf das Neocognitron von Kunihiko Fukushima (1980) zurück. Yann LeCun entwickelte 1989 mit LeNet ein CNN zur Handschrifterkennung von Ziffern. Der Durchbruch gelang 2012 mit AlexNet, das den ImageNet-Wettbewerb deutlich gewann. Es folgten Architekturen wie VGGNet, GoogLeNet, ResNet und EfficientNet.
