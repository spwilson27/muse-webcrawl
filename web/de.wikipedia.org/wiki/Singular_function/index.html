Singuläre Funktion

Eine singuläre Funktion ist in der Mathematik eine stetige Funktion, deren Ableitung fast überall gleich null ist, die aber trotzdem nicht konstant ist. Das bekannteste Beispiel ist die Cantor-Funktion, die auch als „Teufelstreppe“ bezeichnet wird.

Cantor-Funktion

Die Cantor-Funktion ist auf dem Einheitsintervall [0, 1] definiert. Sie ist konstant auf allen Intervallen, die bei der Konstruktion der Cantor-Menge entfernt werden, und steigt nur auf der Cantor-Menge selbst, einer Menge vom Lebesgue-Maß null. Ihre Werte wachsen von 0 auf 1, obwohl ihre Ableitung fast überall verschwindet.

Bedeutung

Singuläre Funktionen spielen eine Rolle in der Maßtheorie und in der Wahrscheinlichkeitstheorie. Nach dem Zerlegungssatz von Lebesgue lässt sich jedes σ-endliche, signierte Maß in einen absolut stetigen, einen diskreten und einen singulär stetigen Anteil zerlegen. Eine Verteilungsfunktion heißt singulär, wenn sie stetig ist, aber ihre Ableitung fast überall null ist; die zugehörige Verteilung ist dann singulär stetig.
