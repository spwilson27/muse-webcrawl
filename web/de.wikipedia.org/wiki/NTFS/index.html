NTFS

NTFS (New Technology File System) ist ein proprietäres Dateisystem von Microsoft. Es wurde 1993 mit Windows NT 3.1 eingeführt und ist seit Windows XP das Standarddateisystem für Windows-Systempartitionen.

Eigenschaften

NTFS ist ein journalführendes Dateisystem: Änderungen werden in einem Protokoll (Journal) aufgezeichnet, was die Konsistenz nach Abstürzen erhöht. Zentrale Struktur ist die Master File Table (MFT), in der alle Dateien und Verzeichnisse als Datensätze mit Attributen verwaltet werden. NTFS unterstützt unter anderem Zugriffsberechtigungen (ACLs), Verschlüsselung (EFS), Kompression, Festplattengrenzwerte (Quotas), Hardlinks und Junctions, symbolische Verknüpfungen, alternative Datenströme sowie Dateien bis zu mehreren Terabyte Größe.

Verbreitung

Neben Windows unterstützen auch andere Systeme NTFS: Linux verfügt über den Kerneltreiber ntfs3 (zuvor NTFS-3G über FUSE), macOS kann NTFS-Datenträger standardmäßig nur lesen. Wegen seiner Eigenschaften wird NTFS vor allem auf internen Festplatten und SSDs von Windows-Rechnern eingesetzt; für Wechselmedien kommen oft exFAT oder FAT32 zum Einsatz.
