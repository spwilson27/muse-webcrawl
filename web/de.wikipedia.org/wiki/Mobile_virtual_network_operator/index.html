Mobile Virtual Network Operator

Ein Mobile Virtual Network Operator (MVNO, deutsch „virtueller Mobilfunknetzbetreiber") ist ein Anbieter von Mobilfunkdiensten, der kein eigenes Funkzugangsnetz besitzt, sondern die Netzinfrastruktur eines oder mehrerer Mobilfunknetzbetreiber (Mobile Network Operator, MNO) gegen Entgelt nutzt.

Geschäftsmodell

MVNOs kaufen Netzkapazitäten im Großhandel ein und verkaufen sie unter eigener Marke an Endkunden weiter. Sie verantworten dabei in der Regel Vertrieb, Marketing, Tarifgestaltung und Kundenservice. Die technische Abwicklung kann ganz oder teilweise von einem Mobile Virtual Network Enabler (MVNE) übernommen werden.

Typen

Man unterscheidet verschiedene Ausprägungen von MVNOs, vom reinen Wiederverkäufer (Reseller), der kaum eigene Infrastruktur besitzt, bis zum „Full MVNO", der eigene Kernnetzelemente wie HLR/HSS, Abrechnungssysteme und Paketdaten-Gateways betreibt und lediglich das Funknetz des Gastbetreibers nutzt. Daneben existieren markengebundene Anbieter (Branded Reseller), etwa von Handelsketten oder Medienunternehmen.

Marktbedeutung

Virtuelle Netzbetreiber erhöhen den Wettbewerb auf dem Mobilfunkmarkt, indem sie Nischenangebote, Discounttarife oder Dienste für bestimmte Zielgruppen anbieten. In vielen Ländern, darunter Deutschland, stellen sie einen erheblichen Anteil der Mobilfunkanschlüsse.
