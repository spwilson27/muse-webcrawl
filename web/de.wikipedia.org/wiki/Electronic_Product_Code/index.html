Electronic Product Code

Der Electronic Product Code (EPC) ist ein weltweit eindeutiges Nummernsystem zur Kennzeichnung von Objekten mithilfe von RFID-Transpondern. Im Unterschied zum Strichcode ( GTIN) identifiziert der EPC nicht nur die Produktklasse, sondern jedes einzelne Exemplar über eine Seriennummer.

Aufbau

Ein EPC besteht aus einem Header, der das Nummernschema angibt, einer Hersteller- bzw. Verwalternummer, einer Objektklasse und einer eindeutigen Seriennummer. Gängige Schemata wie SGTIN-96 kodieren die Informationen auf 96 Bit. Verwaltet wird das System vom EPCglobal-Netzwerk, einer Tochterorganisation von GS1.

Anwendung

EPC-Tags werden vor allem in Logistik und Handel eingesetzt, um Warenströme lückenlos zu verfolgen, Bestände automatisch zu erfassen und Fälschungen zu erkennen. Die zugehörigen Daten werden über das EPC-Informationssystem (EPCIS) zwischen Unternehmen ausgetauscht.

Datenschutz

Weil EPC-Tags ohne Sichtkontakt ausgelesen werden können, diskutieren Verbraucherschützer mögliche Risiken für die Privatsphäre und fordern Deaktivierungsmöglichkeiten an der Kasse.
