Redis

Redis (kurz für Remote Dictionary Server) ist eine quelloffene In-Memory-Datenbank, die Daten als Schlüssel-Wert-Paare im Arbeitsspeicher hält. Das Projekt wurde 2009 von Salvatore Sanfilippo begonnen und zählt zu den am weitesten verbreiteten NoSQL-Systemen. Redis wird vor allem als Cache, Message Broker und schnelle Sitzungs- und Echtzeitdatenbank eingesetzt.

Datenmodell

Anders als einfache Key-Value-Stores unterstützt Redis reichhaltige Datenstrukturen: Strings, Listen, Mengen (Sets), sortierte Mengen (Sorted Sets), Hashes, Bitmaps, HyperLogLogs und Streams. Operationen auf diesen Strukturen laufen serverseitig und weitgehend atomar; über Lua-Skripte und Transaktionen lassen sich mehrstufige Abläufe abbilden. Zur Persistenz kann Redis Schnappschüsse (RDB) schreiben oder alle Änderungen in einer Append-only-Datei (AOF) protokollieren.

Betrieb und Verbreitung

Redis arbeitet standardmäßig single-threaded pro Instanz und erreicht dadurch trotz einfacher Architektur sehr hohe Durchsatzraten. Für Hochverfügbarkeit und horizontale Skalierung stehen Replikation, Redis Sentinel und Redis Cluster zur Verfügung. Hinter der Weiterentwicklung steht das Unternehmen Redis Ltd.; 2024 stellte das Projekt seine Lizenz auf ein duales Modell um, was zur Abspaltung des freien Forks Valkey unter der Linux Foundation führte.
