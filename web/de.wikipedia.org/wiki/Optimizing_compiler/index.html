Optimierender Compiler

Ein optimierender Compiler ist ein Compiler, der den erzeugten Maschinencode durch eine Reihe von Transformationen verbessert, sodass das Programm schneller läuft, weniger Speicher benötigt oder weniger Energie verbraucht – ohne seine Semantik zu verändern. Bekannte Beispiele sind GCC und LLVM/Clang mit ihren Optimierungsstufen (etwa -O2 oder -O3) sowie die Just-in-time-Compiler moderner Laufzeitumgebungen.

Typische Optimierungen

  • Konstantenfaltung: Ausdrücke aus Konstanten werden schon zur Compilezeit ausgewertet.
  • Eliminierung toten Codes: Code ohne Effekt auf das Programmausgabe wird entfernt.
  • Inlining: Kleine Funktionsaufrufe werden durch den Funktionskörper ersetzt.
  • Schleifenoptimierungen: Schleifeninvarianter Code wird aus der Schleife herausgezogen, Schleifen werden aufgerollt oder vektorisiert.
  • Registerallokation: Variablen werden möglichst in schnellen Prozessorregistern gehalten.
  • Gemeinsame Teilausdrücke: Mehrfach berechnete Ausdrücke werden nur einmal berechnet.

Bedeutung der Zwischendarstellung

Die meisten Analysen und Transformationen arbeiten auf einer Zwischendarstellung (Intermediate Representation) des Programms, häufig in Static-Single-Assignment-Form (SSA), die Datenflussanalysen erleichtert.

Zielkonflikte

Stärkere Optimierung erhöht die Compilezeit und kann das Debuggen erschweren, weil sich Quellcode und Maschinencode nicht mehr zeilenweise entsprechen. Zudem müssen Optimierungen die Sprachsemantik strikt einhalten; fehlerhafte Transformationen gehören zu den kritischsten Compilerfehlern.
