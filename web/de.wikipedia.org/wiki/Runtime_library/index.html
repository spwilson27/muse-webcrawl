Laufzeitbibliothek

Eine Laufzeitbibliothek (englisch runtime library) ist eine Programmbibliothek, die grundlegende Funktionen bereitstellt, die ein Compiler oder Interpreter zur Ausführung eines Programms benötigt. Dazu gehören häufig Speicherverwaltung, mathematische Funktionen, Zeichenkettenverarbeitung, Ein- und Ausgabe sowie die Behandlung von Ausnahmen.

Funktion

Übersetzte Programme enthalten nicht sämtliche Basisoperationen als Maschinencode; stattdessen ruft der generierte Code Routinen der Laufzeitbibliothek auf. In der Sprache C ist dies die C-Standardbibliothek (libc), die Funktionen wie printf, malloc oder memcpy enthält und zugleich die Schnittstelle zum Betriebssystem bildet. Sprachen mit Garbage Collection, wie Java oder Go, benötigen umfangreichere Laufzeitkomponenten, die zusammen mit dem Programm ausgeliefert oder auf dem Zielsystem installiert sein müssen.

Bindung

Laufzeitbibliotheken können statisch in die Programmdatei eingebunden oder als dynamische Bibliothek zur Lade- oder Laufzeit hinzugeladen werden. Dynamische Bindung spart Speicherplatz und erlaubt Aktualisierungen ohne Neuübersetzung, kann aber zu Versionskonflikten führen, wenn ein Programm eine bestimmte Version der Bibliothek erwartet.
