Post Office Protocol


E-Mail-Abruf per POP3

Das Post Office Protocol (POP) ist ein Internetprotokoll auf der Anwendungsschicht, mit dem E-Mails von einem Mailserver abgerufen werden können. Die heute gebräuchliche Version 3 (POP3) ist im RFC 1939 spezifiziert und nutzt standardmäßig den TCP-Port 110, mit TLS-Verschlüsselung den Port 995 (POP3S).

Funktionsweise

Der Client baut eine Verbindung zum Server auf, authentifiziert sich (u. a. mit USER/PASS oder dem sichereren APOP-Verfahren) und kann dann die Nachrichten im Postfach auflisten (LIST), herunterladen (RETR) und zum Löschen markieren (DELE). Die klassischen Befehle sind kurze ASCII-Kommandos:

BefehlBedeutung
STATAnzahl und Gesamtgröße der Nachrichten
LISTNachrichten mit Größen auflisten
RETR nNachricht n abrufen
DELE nNachricht n zum Löschen markieren
QUITSitzung beenden, Löschungen ausführen

Traditionell werden Nachrichten nach dem Abruf vom Server gelöscht; POP3 verwaltet keine Ordnerstrukturen auf dem Server.

Vergleich mit IMAP

Im Gegensatz zu IMAP, das Nachrichten serverseitig verwaltet und den Zugriff von mehreren Geräten synchron hält, ist POP3 auf den Abruf auf ein lokales Gerät ausgelegt. Wegen der Verbreitung von Webmail und mehreren Endgeräten hat IMAP das ältere Protokoll weitgehend verdrängt, doch POP3 wird von vielen Anbietern weiterhin unterstützt.
