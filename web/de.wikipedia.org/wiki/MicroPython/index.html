MicroPython

MicroPython ist eine schlanke Implementierung der Programmiersprache Python 3, die für den Einsatz auf Mikrocontrollern und in ressourcenbeschränkten Umgebungen optimiert ist. Sie umfasst einen Compiler, eine Laufzeitumgebung und eine Teilmenge der Python-Standardbibliothek sowie Module für den direkten Zugriff auf die Hardware.

Geschichte

MicroPython wurde vom australischen Programmierer Damien George entwickelt und 2013 über eine erfolgreiche Kickstarter-Kampagne finanziert; 2014 erschien die erste Version zusammen mit dem Pyboard, einer speziell dafür entworfenen Mikrocontroller-Platine. Der Quellcode steht unter der MIT-Lizenz auf GitHub zur Verfügung.

Einsatz

Unterstützt werden zahlreiche Plattformen, darunter ESP32, ESP8266, STM32, Raspberry Pi Pico (RP2040) und der BBC micro:bit, der in britischen Schulen eingesetzt wird. MicroPython ermöglicht interaktives Programmieren über eine REPL und wird für Prototyping, Ausbildung und Internet-of-Things-Anwendungen genutzt. Eine verwandte Weiterentwicklung ist CircuitPython von Adafruit.
