Liste von Build-Automatisierungssoftware

Build-Automatisierungswerkzeuge übersetzen Quellcode in ausführbare Programme, verwalten Abhängigkeiten und führen Tests aus.

Bekannte Werkzeuge

  • Make – klassisches Unix-Werkzeug (1976), gesteuert über Makefiles
  • Apache Ant – XML-basiert, für Java-Projekte
  • Apache Maven – Projektverwaltung und Build für Java, mit zentralem Repository
  • Gradle – Groovy-/Kotlin-DSL, verbreitet bei Java und Android
  • CMake – plattformübergreifender Generator für Build-Dateien
  • MSBuild – Build-System von Microsoft für .NET
  • Bazel – von Google entwickelt, für große Monorepos
  • SCons – Python-basierte Make-Alternative
  • Meson / Ninja – schnelles Build-System für C/C++
  • Cargo – Paketmanager und Build-Werkzeug für Rust
  • npm / webpack / Vite – Werkzeuge im JavaScript-Ökosystem
  • Rake – Ruby-basierte Build-Automatisierung

Continuous Integration

CI-Server wie Jenkins, GitLab CI und GitHub Actions bauen Software automatisch bei jeder Änderung und sind heute eng mit den Build-Werkzeugen verzahnt.
