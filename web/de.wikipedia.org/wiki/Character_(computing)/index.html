Zeichen (Informatik)

Zeichen einer Zeichentabelle

Ein Zeichen (englisch character) ist in der Informatik die kleinste Einheit geschriebener Information, die eine Bedeutung trägt, etwa ein Buchstabe, eine Ziffer, ein Satzzeichen oder ein sonstiges Symbol. Eine Folge von Zeichen bildet eine Zeichenkette (String).

Zeichenkodierung

Damit Computer Zeichen verarbeiten können, werden sie durch Zeichenkodierungen in Zahlen (Codepoints) abgebildet. Historisch bedeutsam war der 7-Bit-Code ASCII mit 128 Zeichen. Der heutige Standard ist Unicode, der über eine Million Codepoints für die Schriften und Symbole der Welt bereitstellt; seine gebräuchlichste Kodierung ist UTF-8.

Datentypen

Viele Programmiersprachen besitzen einen eigenen Datentyp für einzelne Zeichen, beispielsweise char in C, C++ und Java. In C belegt ein char in der Regel ein Byte; in Java sind Zeichen durch UTF-16-Codeeinheiten repräsentiert.

Steuerzeichen

Neben den darstellbaren Zeichen existieren Steuerzeichen, die keine sichtbare Form besitzen, sondern Funktionen wie Zeilenumbruch, Tabulator oder Wagenrücklauf auslösen. In ASCII belegen sie die Codepunkte 0 bis 31 sowie 127.
