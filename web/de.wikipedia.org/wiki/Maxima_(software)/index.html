Maxima

Typ: Computeralgebrasystem

Programmiersprache: Common Lisp

Lizenz: GNU General Public License (freie Software)

Vorgänger: Macsyma

Maxima ist ein freies Computeralgebrasystem (CAS) zur symbolischen und numerischen Manipulation mathematischer Ausdrücke. Es geht auf das System Macsyma zurück, das ab Ende der 1960er Jahre am Massachusetts Institute of Technology entwickelt wurde.

Funktionen

Maxima beherrscht unter anderem Differenzieren und Integrieren, das Lösen von Gleichungen und Differentialgleichungen, Grenzwertberechnung, Reihenentwicklung, Matrizenrechnung, Laplace-Transformation sowie das Erstellen zwei- und dreidimensionaler Grafiken (meist über Gnuplot). Es läuft auf Linux, Windows und macOS; mit wxMaxima existiert eine verbreitete grafische Oberfläche.

Geschichte

Der Informatikprofessor William Schelter pflegte ab 1982 eine auf Common Lisp aufbauende Version von Macsyma und gab sie 1998 mit Zustimmung des US-Energieministeriums unter der GNU GPL als „Maxima" frei. Seitdem wird das System von einer offenen Entwicklergemeinschaft weiterentwickelt.
