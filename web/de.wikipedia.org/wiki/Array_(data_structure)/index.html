Feld (Datentyp)

Ein Feld (englisch array) ist in der Informatik eine Datenstruktur, die eine feste Anzahl von Elementen desselben Datentyps in einem zusammenhängenden Speicherbereich speichert. Auf die einzelnen Elemente wird über einen Index (meist eine ganze Zahl ab 0 oder 1) zugegriffen.

Eigenschaften

Da alle Elemente gleich groß sind und aufeinanderfolgen, kann die Adresse eines Elements in konstanter Zeit aus Basisadresse und Index berechnet werden; der wahlfreie Zugriff ist damit in O(1) möglich. Einfügen und Löschen in der Mitte sind dagegen aufwendig, weil nachfolgende Elemente verschoben werden müssen. Die Größe klassischer Felder steht zur Erstellungszeit fest; viele moderne Programmiersprachen bieten darüber hinaus dynamische Felder (etwa Listen oder Vektoren), die wachsen können.

Mehrdimensionale Felder

Felder können mehrdimensional sein, etwa als zweidimensionale Matrix für Tabellen oder Bilder. Im Speicher werden sie üblicherweise zeilen- oder spaltenweise linearisiert.

Verwendung

Felder gehören zu den grundlegendsten Datenstrukturen überhaupt und bilden die Basis zahlreicher weiterer Strukturen wie Zeichenketten, Stapel (Stacks), Warteschlangen und Hashtabellen. Nahezu alle imperativen Programmiersprachen – von C über Java bis Python (dort als Liste) – stellen Felder oder feldähnliche Typen bereit.
