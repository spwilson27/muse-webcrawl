Fluss (Mathematik)

Ein Fluss (englisch flow) ist in der Mathematik, insbesondere in der Theorie dynamischer Systeme, eine Familie von Abbildungen, die die zeitliche Entwicklung eines Systems beschreibt. Formal ist ein Fluss eine Gruppenwirkung der reellen Zahlen (der Zeit) auf einem Zustandsraum.

Definition

Sei X eine Menge (oder ein topologischer Raum beziehungsweise eine Mannigfaltigkeit). Ein Fluss ist eine Abbildung φ: ℝ × X → X mit φ(0, x) = x und φ(s + t, x) = φ(s, φ(t, x)) für alle s, t ∈ ℝ und x ∈ X. Für jedes feste x beschreibt die Kurve t ↦ φ(t, x) die Trajektorie (den Orbit) des Anfangszustands x.

Beispiele und Anwendungen

Der wichtigste Ursprung von Flüssen sind gewöhnliche Differentialgleichungen: Erfüllt der Lösungsraum einer autonomen Gleichung ẋ = f(x) globale Existenz und Eindeutigkeit, so definieren die Lösungen einen Fluss. Umgekehrt erzeugt jedes glatte Vektorfeld lokal einen Fluss. Beispiele sind der geodätische Fluss auf dem Einheitstangentialbündel einer Riemannschen Mannigfaltigkeit und der Horosphärenfluss in der Ergodentheorie. Flüsse bilden die Grundlage für Begriffe wie Stabilität, Attraktoren und chaotisches Verhalten dynamischer Systeme.
