Fedora Project
Gründung2003
SponsorRed Hat (IBM)
ProduktFedora Linux
LeitungFedora Council

Das Fedora Project ist ein Community-Projekt, das die Entwicklung der Linux-Distribution Fedora Linux sowie zahlreicher zugehöriger freier Softwareprojekte organisiert. Es wird hauptsächlich von Red Hat gesponsert, steht aber allen Beitragenden offen.

Organisation

Geleitet wird das Projekt vom Fedora Council, dem unter anderem der Fedora Project Leader angehört. Arbeitsgruppen kümmern sich um Paketierung, Dokumentation, Design, Qualitätssicherung, Infrastruktur und Lokalisierung. Freiwillige aus aller Welt wirken als Botschafter und Übersetzer mit.

Grundsätze

Das Projekt folgt den vier Grundwerten „Freedom, Friends, Features, First“ (Freiheit, Freunde, Funktionen, Erster). Fedora nimmt ausschließlich freie und quelloffene Software auf und pflegt eine enge Zusammenarbeit mit den Upstream-Projekten, deren Code es unverändert übernimmt, statt eigene Patches zu pflegen.

Geschichte

Das Projekt ging 2003 aus der Zusammenlegung von Red Hat Linux und dem ursprünglichen Fedora-Linux-Projekt von Warren Togami hervor. Seitdem veröffentlicht die Community etwa halbjährlich neue Versionen der Distribution.
