Extremale Kombinatorik

Extremale Kombinatorik
EnglischExtremal combinatorics
TeilgebietKombinatorik
Zentrale SätzeSatz von Sperner, Satz von Erdős–Ko–Rado, Satz von Turán

Die extremale Kombinatorik ist ein Teilgebiet der Kombinatorik, das untersucht, wie groß oder wie klein eine kombinatorische Struktur – etwa eine Familie von Mengen, ein Graph oder eine Zahlenmenge – sein kann, wenn sie bestimmte Eigenschaften besitzt beziehungsweise vermeiden muss.

Typische Fragestellungen

Charakteristisch ist die Frage nach maximalen oder minimalen Größen unter Nebenbedingungen. Beispiele sind: Wie viele Teilmengen einer n-elementigen Menge kann man wählen, ohne dass eine die andere enthält? Wie viele Kanten kann ein Graph mit n Ecken haben, ohne einen vollständigen Teilgraphen einer vorgegebenen Größe zu enthalten?

Bedeutende Resultate

  • Der Satz von Sperner (1928) besagt, dass die größte Antikette im Teilmengenverband einer n-Menge durch die mittlere Schicht gebildet wird.
  • Der Satz von Erdős–Ko–Rado (1961) bestimmt die größte Familie paarweise sich schneidender k-Teilmengen einer n-Menge.
  • Der Satz von Turán begrenzt die Kantenzahl von Graphen ohne (r+1)-Cliquen und begründet die extremale Graphentheorie.
  • Das Satz von Szemerédi über arithmetische Progressionen ist ein Meilenstein der extremalen Zahlentheorie.

Methoden

Zu den Methoden zählen Abzählargumente, das Schubfachprinzip, Induktion, Kompressionstechniken wie das „Shifting", die probabilistische Methode sowie neuere Ansätze wie die von Terence Tao und anderen entwickelte additive Kombinatorik. Wichtige Impulse gingen von Paul Erdős aus, der zahlreiche extremale Probleme stellte.
