International Code Council

Abkürzung: ICC
Gegründet: 1994
Sitz: Washington, D.C.
Produkte: International Codes (I-Codes)

Überblick

Der International Code Council (ICC) ist eine gemeinnützige US-amerikanische Organisation, die Modellbauvorschriften und Standards für die Sicherheit von Gebäuden entwickelt. Er wurde 1994 durch den Zusammenschluss dreier regionaler Bauordnungsorganisationen gegründet.

Die vom ICC herausgegebenen International Codes, kurz I-Codes, bilden in den meisten US-Bundesstaaten und vielen anderen Ländern die Grundlage des Baurechts.

Die I-Codes

Zur Reihe gehören der International Building Code (IBC) für Neu- und Umbauten, der International Residential Code für Wohngebäude, der International Fire Code sowie Vorschriften zu Sanitär, Mechanik, Energieeinsparung und Bestandserhaltung.

Die Regelwerke werden in einem konsensbasierten Verfahren alle drei Jahre überarbeitet, an dem Behörden, Bauwirtschaft und Wissenschaft beteiligt sind.

Weitere Aufgaben

Der ICC bietet Zertifizierungen für Bauinspektoren und Planprüfer, Schulungen sowie Bewertungsdienste für Bauprodukte an. Über die Global Alliance for Buildings and Construction engagiert er sich auch international für sicheres und nachhaltiges Bauen.
