Paketverwaltung

Eine Paketverwaltung (englisch package manager) ist ein System oder Programm, das die Installation, Aktualisierung, Konfiguration und Deinstallation von Softwarepaketen auf einem Computer automatisiert. Sie bezieht die Pakete üblicherweise aus Online-Repositorien und löst deren Abhängigkeiten automatisch auf.

Funktionen

Zu den Kernaufgaben gehören das Herunterladen kryptographisch signierter Pakete, das Prüfen und Auflösen von Abhängigkeiten, das Führen einer lokalen Datenbank installierter Pakete sowie Versionsverwaltung und Deinstallation. Moderne Paketverwaltungen sind ein wesentliches Merkmal der Linux-Distributionen.

Bekannte Systeme

  • dpkg/APT (Debian, Ubuntu) mit dem Format .deb
  • RPM mit dnf/Yum (Fedora, Red Hat Enterprise Linux, SUSE)
  • Pacman (Arch Linux)
  • Homebrew (macOS)
  • Sprachspezifische Verwalter wie npm (JavaScript), pip (Python), gem (Ruby) und Cargo (Rust)
  • Distributionsunabhängige Formate wie Flatpak, Snap und AppImage

Paketverwaltungen erhöhen die Sicherheit und Wartbarkeit von Systemen, weil Software zentral geprüft, signiert und aktualisiert werden kann. Herausforderungen sind Versionskonflikte („dependency hell“) und die Trennung von System- und Anwendungssoftware.
