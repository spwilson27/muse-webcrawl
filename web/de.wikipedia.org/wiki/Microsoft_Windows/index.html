Microsoft Windows

Microsoft Windows ist ein Betriebssystem von Microsoft. Die erste Version, Windows 1.0, erschien am 20. November 1985 zunächst als grafische Erweiterung des Betriebssystems MS-DOS. Mit Windows 95, Windows XP, Windows 7 und Windows 10 erreichte Windows eine dominierende Stellung auf Personal Computern; der Marktanteil unter den Desktop-Betriebssystemen liegt weltweit bei rund 70 Prozent. Aktuelle Version ist Windows 11, erschienen 2021.

Geschichte

Die frühen Windows-Versionen liefen auf MS-DOS. Ab 1993 existierte mit Windows NT eine separate, von Grund auf neu entwickelte Linie für professionelle Anwender, die ab Windows XP (2001) auch die Consumer-Linie aufnahm. Wichtige Meilensteine waren Windows 95 mit Startmenü und Taskleiste, Windows 98, Windows XP, das in der Gunst der Nutzer weniger erfolgreiche Windows Vista, Windows 7, das auf Touch-Bedienung ausgerichtete Windows 8 sowie Windows 10 (2015), das Microsoft zunächst als dauerhaft fortentwickeltes „Windows as a Service“ positionierte. Die Server-Varianten erscheinen unter dem Namen Windows Server.
