Apache Spark
Entwickler: Apache Software Foundation
Programmiersprache: Scala
Kategorie: Framework für verteilte Datenverarbeitung
Lizenz: Apache License 2.0

Apache Spark ist ein Framework zur schnellen, verteilten Verarbeitung großer Datenmengen auf Computerclustern. Es wurde ab 2009 am AMPLab der University of California, Berkeley, von Matei Zaharia entwickelt, 2010 als Open Source veröffentlicht und 2014 ein Top-Level-Projekt der Apache Software Foundation. Die Weiterentwicklung wird wesentlich vom Unternehmen Databricks getragen, das die ursprünglichen Entwickler gründeten.

Eigenschaften

Im Unterschied zum datenträgerbasierten MapReduce-Modell von Hadoop hält Spark Zwischenergebnisse bevorzugt im Arbeitsspeicher, was insbesondere iterative Algorithmen und interaktive Abfragen deutlich beschleunigt – nach Projektangaben um bis zu zwei Größenordnungen. Zentrales Konzept war ursprünglich die abstrakte, fehlertolerante Datenstruktur des Resilient Distributed Dataset (RDD); heute arbeiten Anwender überwiegend mit DataFrames und Datasets über der Optimierungs-Engine Catalyst. Ein Driver-Programm verteilt Aufgaben an Executor-Prozesse auf den Clusterknoten; als Ressourcenverwalter können YARN, Mesos oder Kubernetes dienen.

Komponenten

  • Spark SQL: Abfragen auf strukturierten Daten mit SQL und DataFrame-API
  • MLlib: Bibliothek für maschinelles Lernen
  • GraphX: Verarbeitung von Graphen
  • Structured Streaming: Verarbeitung von Datenströmen

Spark bietet Schnittstellen für Scala, Java, Python (PySpark) und R und gehört zu den aktivsten Open-Source-Projekten im Big-Data-Umfeld.
