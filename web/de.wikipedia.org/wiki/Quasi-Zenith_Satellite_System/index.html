Quasi-Zenith Satellite System

Das Quasi-Zenith Satellite System (QZSS, japanisch Michibiki) ist ein japanisches regionales Satellitennavigationssystem. Es ergänzt vor allem das amerikanische GPS über Japan und der Asien-Ozeanien-Region und verbessert dort Verfügbarkeit und Genauigkeit der Positionsbestimmung.

Aufbau

Das System besteht aus Satelliten in sogenannten Quasi-Zenit-Umlaufbahnen: geneigten, geosynchronen Orbits, deren Bodenspur eine asymmetrische Acht beschreibt, sodass sich stets mindestens ein Satellit nahezu im Zenit über Japan befindet – wichtig in Städten mit hohen Gebäuden und in Bergtälern, wo GPS-Signale häufig abgeschattet werden. Der erste Satellit, Michibiki, startete 2010; seit November 2018 arbeitet das System offiziell mit vier Satelliten. Eine Erweiterung auf sieben Satelliten soll eine eigenständige Positionsbestimmung ermöglichen.

Dienste

QZSS sendet GPS-kompatible Signale sowie Korrekturdaten, die eine Genauigkeit im Zentimeterbereich (CLAS-Dienst) erlauben. Zudem überträgt das System Warnmeldungen für den Katastrophenschutz.
