Konfidenzintervall


Konfidenzintervalle um Schätzwerte

Ein Konfidenzintervall (englisch confidence interval), auch Vertrauensbereich genannt, ist ein Intervall aus der Statistik, das auf Grundlage einer Stichprobe einen Bereich angibt, in dem der wahre Wert eines unbekannten Parameters der Grundgesamtheit mit einer vorgegebenen Wahrscheinlichkeit, dem Konfidenzniveau, liegt.

Definition

Konfidenzintervalle wurden in den 1930er Jahren von Jerzy Neyman eingeführt. Formal wird zu einem Schätzer ein Intervall [u, o] so konstruiert, dass das Verfahren bei unendlicher Wiederholung der Stichprobenziehung in (1−α)·100 % der Fälle ein Intervall liefert, das den wahren Parameter enthält. Übliche Konfidenzniveaus sind 90 %, 95 % und 99 %.

Für den Mittelwert bei bekannter Standardabweichung gilt: x̄ ± z1−α/2 · σ/√n.

Interpretation

Entgegen einer verbreiteten Fehldeutung besagt ein 95-%-Konfidenzintervall nicht, dass der wahre Wert mit 95 % Wahrscheinlichkeit in diesem konkreten Intervall liegt; der Parameter ist fest, nur das Verfahren hat die genannte Überdeckungswahrscheinlichkeit. Praktisch dienen Konfidenzintervalle dazu, die Präzision einer Schätzung anzuzeigen: Je größer die Stichprobe, desto schmaler das Intervall.

Anwendung

Konfidenzintervalle werden in der Medizin, den Sozialwissenschaften, der Meinungsforschung und der Qualitätskontrolle verwendet. Sie sind eng mit statistischen Tests verwandt: Ein Test lehnt einen Parameterwert genau dann ab, wenn er außerhalb des entsprechenden Konfidenzintervalls liegt.
