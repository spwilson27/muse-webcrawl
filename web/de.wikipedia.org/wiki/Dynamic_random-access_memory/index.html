Dynamic Random Access Memory

Symbolbild: DRAM-Speichermodule

Dynamic Random Access Memory (DRAM) ist eine Technologie für einen elektronischen Arbeitsspeicher, der überwiegend als Hauptspeicher in Computern eingesetzt wird. Jede Speicherzelle besteht aus einem Transistor und einem Kondensator; die gespeicherte Information entspricht der elektrischen Ladung des Kondensators.

Funktionsweise

Da der Kondensator seine Ladung durch Leckströme allmählich verliert, muss der Speicherinhalt periodisch aufgefrischt werden (Refresh), typischerweise alle 64 Millisekunden. Daher rührt die Bezeichnung „dynamisch" – im Gegensatz zum statischen RAM (SRAM), dessen Zellen aus Flipflops bestehen und kein Refresh benötigen, dafür aber mehr Fläche beanspruchen. Auch das Auslesen einer DRAM-Zelle ist destruktiv: Der Inhalt einer Zeile wird dabei in einen Zeilenpuffer übertragen und anschließend zurückgeschrieben.

Geschichte

Das Grundprinzip des DRAM geht auf Arbeiten von Robert Dennard bei IBM zurück, der 1966 die Ein-Transistor-Speicherzelle erfand und 1968 ein Patent erhielt. Der erste kommerziell erfolgreiche DRAM-Chip war 1970 der Intel 1103 mit einer Kapazität von 1024 Bit. In den folgenden Jahrzehnten stieg die Speicherdichte nach dem Mooreschen Gesetz um viele Größenordnungen.

Varianten

  • SDRAM und seine Nachfolger DDR-SDRAM (DDR bis DDR5) als Hauptspeicher von PCs und Servern
  • LPDDR für mobile Geräte mit geringem Energieverbrauch
  • GDDR als Grafikspeicher
  • HBM (High Bandwidth Memory) mit gestapelten Chips für besonders hohe Bandbreiten
