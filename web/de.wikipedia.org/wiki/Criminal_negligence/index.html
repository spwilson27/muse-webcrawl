Strafbare Fahrlässigkeit

Strafbare Fahrlässigkeit (englisch criminal negligence) bezeichnet im Strafrecht der Common-Law-Länder eine besonders schwere Form der Fahrlässigkeit, die über die bloße zivilrechtliche Fahrlässigkeit hinausgeht und eine strafrechtliche Verantwortung begründet. Sie liegt vor, wenn eine Person eine Sorgfaltspflicht in einem Maße verletzt, das eine deutliche Abweichung vom Verhalten einer vernünftigen Person darstellt und ein erhebliches, ungerechtfertigtes Risiko für Leben oder Gesundheit anderer schafft.

Abgrenzung

Während die einfache Fahrlässigkeit (negligence) im Zivilrecht Schadensersatzansprüche auslöst, verlangt das Strafrecht in der Regel einen höheren Grad an Vorwerfbarkeit. In England und Wales wird für die fahrlässige Tötung (gross negligence manslaughter) eine „grobe Fahrlässigkeit" (gross negligence) gefordert. Die maßgeblichen Kriterien wurden in der Entscheidung R v Adomako (1995) formuliert: Es muss eine Sorgfaltspflicht bestanden haben, diese muss verletzt worden sein, die Verletzung muss den Tod verursacht haben, und die Pflichtverletzung muss so schwerwiegend sein, dass sie als strafbar einzustufen ist.

Model Penal Code

Der US-amerikanische Model Penal Code definiert criminal negligence als Verhalten, bei dem eine Person ein erhebliches und ungerechtfertigtes Risiko nicht wahrnimmt, dessen Wahrnehmung unter den gegebenen Umständen eine grobe Abweichung vom Sorgfaltsmaßstab einer vernünftigen Person darstellt. Damit unterscheidet er die strafbare Fahrlässigkeit von der bewussten Fahrlässigkeit (recklessness), bei der das Risiko erkannt, aber missachtet wird.

Anwendungsbereiche

  • Fahrlässige Tötung (involuntary manslaughter / negligent homicide)
  • Gefährdung von Kindern (child endangerment)
  • Fahrlässiges Führen eines Fahrzeugs mit Todesfolge
  • Verstöße gegen Arbeitssicherheitsvorschriften mit schweren Folgen
