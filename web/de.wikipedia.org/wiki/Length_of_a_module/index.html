Länge eines Moduls

Die Länge eines Moduls ist in der kommutativen Algebra eine Maßzahl für die „Größe" eines Moduls über einem Ring. Ein Modul besitzt genau dann endliche Länge, wenn er sowohl artinsch als auch noethersch ist.

Definition

Die Länge eines Moduls M ist das Supremum der Längen n aller Ketten von Untermoduln M = M₀ ⊋ M₁ ⊋ … ⊋ Mₙ = 0. Existiert eine Kette, in der jeder Quotient Mᵢ/Mᵢ₊₁ ein einfacher Modul ist (eine Kompositionsreihe der Länge n), so hat M die Länge n; nach dem Satz von Jordan-Hölder ist diese Zahl unabhängig von der gewählten Kompositionsreihe.

Beispiele

Ein Vektorraum über einem Körper hat genau dann endliche Länge, wenn er endlichdimensional ist; seine Länge ist dann seine Dimension. Die abelsche Gruppe ℤ/nℤ hat als ℤ-Modul eine Länge, die der Anzahl der Primfaktoren von n (mit Vielfachheit) entspricht.

Eigenschaften

Die Länge ist additiv auf kurzen exakten Sequenzen: Für 0 → L → M → N → 0 gilt Länge(M) = Länge(L) + Länge(N). Sie verallgemeinert zugleich die Dimension von Vektorräumen und die Ordnung endlicher abelscher Gruppen.
