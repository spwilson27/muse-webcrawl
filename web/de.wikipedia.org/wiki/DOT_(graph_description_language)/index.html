DOT (Graphbeschreibungssprache)

DOT ist eine Sprache zur Beschreibung von Graphen in reinem Text. Eine DOT-Datei beschreibt Knoten und Kanten eines Graphen; Werkzeuge wie Graphviz berechnen daraus automatisch ein Layout und erzeugen eine Grafik, etwa als PNG, SVG oder PDF. DOT wird häufig eingesetzt, um Strukturen aus Programmen – Abhängigkeiten, Zustandsautomaten, Vererbungshierarchien – ohne manuelle Zeichenarbeit darzustellen.

Syntax

Ein gerichteter Graph wird mit dem Schlüsselwort digraph eingeführt, Kanten werden mit -> notiert; für ungerichtete Graphen (graph) steht -- zur Verfügung. Knoten und Kanten können Attribute in eckigen Klammern erhalten, etwa Beschriftungen, Farben und Formen.

digraph G {
  A -> B;
  A -> C;
  B -> D;
  C -> D;
}

Graphviz

Das freie Softwarepaket Graphviz, das aus den AT&T Labs hervorging, ist die Referenzimplementierung. Es bietet mehrere Layout-Programme: dot für hierarchische Zeichnungen gerichteter Graphen, neato und fdp für federbasierte Layouts ungerichteter Graphen sowie weitere Spezialprogramme. Die Ausgabeformate reichen von Rastergrafiken über SVG und PostScript bis zu interaktiven Formaten.

Verbreitung

DOT-Unterstützung findet sich in Dokumentationswerkzeugen, Wikis und Entwicklungsumgebungen; viele Programme können ihre internen Graphen als DOT exportieren. Wegen der einfachen, gut lesbaren Textform eignet sich das Format auch zur Versionierung in Quelltext-Repositories.
