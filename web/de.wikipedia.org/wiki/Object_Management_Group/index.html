Object Management Group

Die Object Management Group (OMG) ist ein internationales, offenes und gemeinnütziges Konsortium zur Entwicklung von Standards in der Informationstechnik. Sie wurde 1989 gegründet und hat ihren Sitz in Needham, Massachusetts, in den Vereinigten Staaten.

Standards

Zu den bekanntesten Standards der OMG gehören:

  • CORBA (Common Object Request Broker Architecture) — eine Middleware-Architektur für verteilte Objekte.
  • UML (Unified Modeling Language) — eine grafische Modellierungssprache für Softwaresysteme.
  • BPMN (Business Process Model and Notation) — eine Notation zur Modellierung von Geschäftsprozessen.
  • SysML — eine Modellierungssprache für Systems Engineering.
  • DDS (Data Distribution Service) — ein Standard für echtzeitfähigen Datenaustausch.

Organisation

Mitglieder der OMG sind Unternehmen, Behörden und Forschungseinrichtungen. Spezifikationen werden in einem offenen Verfahren von Arbeitsgruppen erarbeitet, in denen sich die Mitgliedsorganisationen beteiligen. Ziel ist die Förderung der Interoperabilität zwischen Systemen unterschiedlicher Hersteller.
