Polymorphie (Informatik)

Polymorphie (englisch polymorphism) ist ein Konzept in Programmiersprachen, das es erlaubt, dass ein Name, eine Funktion oder eine Operation auf Werte unterschiedlicher Datentypen angewendet werden kann. In der objektorientierten Programmierung bezeichnet Polymorphie insbesondere die Fähigkeit, dass Objekte verschiedener Klassen über eine gemeinsame Schnittstelle angesprochen werden können und ein Methodenaufruf je nach tatsächlichem Objekttyp unterschiedliches Verhalten auslöst.

Formen

Nach der einflussreichen Einteilung von Luca Cardelli und Peter Wegner (1985) unterscheidet man universelle und Ad-hoc-Polymorphie. Zur universellen Polymorphie zählen die parametrische Polymorphie, bei der Code generisch über Typparameter formuliert wird (Generics in Java, Templates in C++, generische Funktionen in Haskell), und die Inklusionspolymorphie durch Untertyp-Beziehungen (Vererbung). Ad-hoc-Polymorphie umfasst das Überladen von Funktionen und Operatoren sowie Typumwandlungen (Coercion).

Beispiel

Definiert eine Basisklasse Form eine Methode zeichnen(), können abgeleitete Klassen wie Kreis und Rechteck diese Methode jeweils eigenständig überschreiben. Ein Programm, das eine Liste von Formen durchläuft und für jede zeichnen() aufruft, muss die konkrete Klasse nicht kennen; ausgewählt wird zur Laufzeit die passende Implementierung (dynamische Bindung, meist über eine virtuelle Methodentabelle).
