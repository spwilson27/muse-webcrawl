Element (Software)

Element
Erstveröffentlichung: 2016 (als Vector)
Entwickler: Element (ehemals New Vector)
Protokoll: Matrix
Lizenz: Apache-Lizenz 2.0
Plattformen: Web, Windows, macOS, Linux, Android, iOS

Element ist ein freier Instant-Messaging-Client für das offene Kommunikationsprotokoll Matrix. Die Anwendung wurde 2016 unter dem Namen Vector veröffentlicht, hieß zeitweise Riot und trägt seit 2020 den Namen Element. Sie ermöglicht Text-, Sprach- und Videokommunikation mit Ende-zu-Ende-Verschlüsselung in einem dezentralen, föderierten Netzwerk.

Eigenschaften

Da Element auf dem Matrix-Protokoll basiert, können Nutzer über verschiedene Server (Homeserver) hinweg miteinander kommunizieren und bei Bedarf einen eigenen Server betreiben. Nachrichtenräume können standardmäßig Ende-zu-Ende-verschlüsselt werden (Olm/Megolm-Verfahren). Element unterstützt Direktnachrichten, Gruppenräume, Dateiaustausch, Sprachnachrichten, Videokonferenzen (über Jitsi beziehungsweise nativ über Element Call) sowie Brücken zu anderen Netzwerken wie IRC, Slack oder Telegram. Clients existieren als Webanwendung, Desktop-Programm und für Android und iOS.

Verbreitung

Element wird von mehreren europäischen Behörden und Institutionen eingesetzt, unter anderem im Rahmen des Projekts BundesMessenger der deutschen Bundesverwaltung sowie von den französischen Behörden (Tchap, auf Element-Basis). Entwicklungsseitig wird der Client von der Firma Element (früher New Vector Ltd.) betreut, während die Matrix-Protokollspezifikation von der gemeinnützigen Matrix.org Foundation gepflegt wird.
