Hypertext Transfer Protocol

Das Hypertext Transfer Protocol (HTTP) ist ein zustandsloses Protokoll zur Übertragung von Daten über ein Rechnernetz und bildet die Grundlage des Datenaustauschs im World Wide Web. Es wurde ab 1989 von Tim Berners-Lee und seinem Team am CERN entwickelt und wird heute von der Internet Engineering Task Force standardisiert.

Funktionsweise

HTTP folgt dem Client-Server-Modell: Ein Client, meist ein Webbrowser, sendet eine Anfrage (Request) an einen Server, der darauf mit einer Antwort (Response) reagiert. Wichtige Anfrage-Methoden sind GET, POST, PUT und DELETE. Jede Antwort enthält einen Statuscode, etwa 200 OK für eine erfolgreiche Anfrage, 404 Not Found für eine nicht gefundene Ressource oder 500 Internal Server Error.

Versionen

HTTP/1.1 wurde lange Zeit am häufigsten verwendet. HTTP/2 (2015) führte unter anderem Multiplexing mehrerer Anfragen über eine Verbindung ein. HTTP/3 (2022) basiert auf dem Transportprotokoll QUIC über UDP. Die verschlüsselte Variante von HTTP heißt HTTPS und nutzt TLS.
