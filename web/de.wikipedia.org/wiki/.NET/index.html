.NET

.NET ist eine von Microsoft entwickelte, freie und quelloffene Softwareplattform zur Entwicklung und Ausführung von Anwendungsprogrammen. Sie umfasst eine Laufzeitumgebung (Common Language Runtime, CLR), umfangreiche Klassenbibliotheken und unterstützt zahlreiche Programmiersprachen wie C#, F# und Visual Basic.

Geschichte

Microsoft kündigte .NET im Jahr 2000 an; die erste Version des .NET Framework erschien 2002. 2014 stellte Microsoft mit .NET Core eine plattformübergreifende Neuentwicklung vor, die auch Linux und macOS unterstützt. Mit .NET 5 (2020) wurden .NET Framework und .NET Core wieder zu einer einheitlichen Plattform zusammengeführt; seither erscheint jährlich eine neue Hauptversion.

Architektur

Programme werden in einen Zwischencode (Common Intermediate Language, CIL) übersetzt und zur Laufzeit von der CLR per Just-in-time-Kompilierung in Maschinencode überführt. Die Plattform bietet automatische Speicherbereinigung (Garbage Collection), ein einheitliches Typsystem und mit NuGet einen zentralen Paketmanager.

Anwendungsgebiete

.NET wird für Webanwendungen (ASP.NET Core), Desktopanwendungen (Windows Forms, WPF, MAUI), Cloud-Dienste, Spiele (Unity) und mobile Apps eingesetzt.
