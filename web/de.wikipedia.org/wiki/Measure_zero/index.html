Nullmenge

Eine Nullmenge (englisch measure zero set oder null set) ist in der Maßtheorie eine Menge, deren Maß null ist. Bezüglich des Lebesgue-Maßes ist eine Teilmenge N von ℝn eine Nullmenge, wenn sie sich für jedes ε > 0 durch (höchstens abzählbar viele) Quader mit Gesamtvolumen kleiner als ε überdecken lässt.

Beispiele und Eigenschaften

  • Jede endliche und jede abzählbare Menge ist eine Nullmenge; insbesondere sind die rationalen Zahlen ℚ eine Nullmenge in ℝ.
  • Die Vereinigung abzählbar vieler Nullmengen ist wieder eine Nullmenge.
  • Abzählbar-Unendlichkeit ist nicht nötig: Die Cantor-Menge ist überabzählbar, hat aber Lebesgue-Maß null.
  • Jede Teilmenge einer Nullmenge hat bezüglich des Lebesgue-Maßes ebenfalls Maß null (Vollständigkeit des Lebesgue-Maßes).

Fast überall

Eine Eigenschaft gilt „fast überall", wenn die Menge der Punkte, für die sie nicht gilt, eine Nullmenge ist. In der Wahrscheinlichkeitstheorie spricht man entsprechend von „fast sicher" für Ereignisse, deren Komplement Wahrscheinlichkeit null hat. Funktionen, die sich nur auf einer Nullmenge unterscheiden, haben dasselbe Lebesgue-Integral.
