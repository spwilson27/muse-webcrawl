Anwendungsserver

Ein Anwendungsserver (englisch Application Server) ist ein Server in einem Computernetzwerk, der Anwendungsprogramme ausführt und deren Dienste anderen Programmen oder Endgeräten zur Verfügung stellt. Anwendungsserver bilden das Rückgrat mehrschichtiger Softwarearchitekturen, insbesondere im Bereich von Webanwendungen und Unternehmenssoftware.

Funktionen

Zu den typischen Aufgaben eines Anwendungsservers gehören die Bereitstellung einer Laufzeitumgebung für Geschäftslogik, die Verwaltung von Transaktionen, die Sicherheit und Authentifizierung, die Anbindung an Datenbanken über Verbindungspools sowie die Lastverteilung und Ausfallsicherheit in Serverfarmen. Häufig stellen Anwendungsserver standardisierte Schnittstellen wie HTTP, REST oder SOAP bereit.

Java-EE-Anwendungsserver

Im Umfeld der Jakarta EE (früher Java EE) spezifizieren Anwendungsserver eine umfangreiche Sammlung von Diensten, etwa Enterprise JavaBeans, Java Persistence API und Java Message Service. Bekannte Produkte sind WildFly, Apache Tomcat (als Webcontainer), GlassFish, IBM WebSphere, Oracle WebLogic Server und JBoss EAP.

Andere Plattformen

Auch außerhalb der Java-Welt existieren Anwendungsserver, etwa der Internet Information Services (IIS) für Microsoft .NET, Node.js-Laufzeitumgebungen oder Anwendungsserver für PHP wie Apache HTTP Server mit mod_php. Mit dem Aufkommen von Cloud Computing und Microservices haben leichtgewichtige, eingebettete Server und Container-Technologien wie Docker an Bedeutung gewonnen.

Abgrenzung

Im Unterschied zu einem reinen Webserver, der vor allem statische Inhalte ausliefert, führt ein Anwendungsserver dynamische Geschäftslogik aus. In der Praxis überschneiden sich die Funktionen jedoch häufig.
