Apache Tomcat

Apache Tomcat
Entwickler: Apache Software Foundation
Programmiersprache: Java
Kategorie: Servlet-Container, Webserver
Lizenz: Apache License 2.0

Apache Tomcat ist ein freier Webserver und Servlet-Container der Apache Software Foundation. Er implementiert die Spezifikationen Jakarta Servlet, Jakarta Server Pages (JSP), WebSocket und weitere Technologien der Jakarta-EE-Plattform und dient als Laufzeitumgebung für in Java geschriebene Webanwendungen. Die Kernkomponente, der Servlet-Container, trägt den Namen Catalina; der HTTP-Konnektor heißt Coyote, die JSP-Engine Jasper.

Geschichte

Tomcat begann als Referenzimplementierung der Servlet- und JSP-Spezifikationen bei Sun Microsystems; sein ursprünglicher Entwickler James Duncan Davidson übergab den Quellcode 1999 der Apache Software Foundation. Aus Tomcat ging unter anderem das Build-Werkzeug Apache Ant hervor, das Davidson ursprünglich für Tomcat geschrieben hatte. Tomcat 4 führte 2001 die Catalina-Architektur ein. Ab Version 10 wechselte der Namensraum der Java-EE-APIs von javax.* zu jakarta.*, nachdem die Spezifikationen an die Eclipse Foundation übergegangen waren. Tomcat zählt zu den am weitesten verbreiteten Laufzeitumgebungen für Java-Webanwendungen und ist in vielen Anwendungsservern und Cloud-Diensten eingebettet.

Abgrenzung

Anders als vollständige Jakarta-EE-Anwendungsserver (etwa WildFly oder Payara) umfasst Tomcat nur die Web-Technologien der Plattform; für erweiterte Unternehmensfunktionen wird häufig das auf Tomcat aufbauende TomEE eingesetzt.
