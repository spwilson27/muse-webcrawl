NP (Komplexitätsklasse)

NP ist eine Klasse von Entscheidungsproblemen in der Komplexitätstheorie. Der Name steht für nichtdeterministische Polynomialzeit: Ein Problem liegt in NP, wenn es von einer nichtdeterministischen Turingmaschine in polynomieller Zeit entschieden werden kann.

Charakterisierung über Verifikation

Äquivalent dazu lassen sich Probleme in NP dadurch kennzeichnen, dass eine vorgeschlagene Lösung (ein Zertifikat) von einer deterministischen Maschine in polynomieller Zeit überprüft werden kann. Beispiele sind das Erfüllbarkeitsproblem der Aussagenlogik und das Graphenfärbungsproblem.

Beziehung zu P

Die Klasse P der in polynomieller Zeit entscheidbaren Probleme ist eine Teilmenge von NP. Ob P = NP gilt, ist eines der bekanntesten offenen Probleme der Informatik und eines der Millennium-Probleme des Clay Mathematics Institute, für dessen Lösung ein Preisgeld von einer Million US-Dollar ausgesetzt ist.

NP-Vollständigkeit

Die schwersten Probleme in NP heißen NP-vollständig. Karp und andere zeigten für zahlreiche praktische Probleme diese Eigenschaft. Ein Polynomialzeitalgorithmus für eines von ihnen würde P = NP beweisen.
