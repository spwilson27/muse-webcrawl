Merge (Versionsverwaltung)

Als Merge (englisch für „Zusammenführung“, auch „Verschmelzung“) bezeichnet man in der Versionsverwaltung von Software das Zusammenführen von Änderungen, die auf getrennten Entwicklungszweigen (Branches) oder von verschiedenen Entwicklern vorgenommen wurden, zu einer gemeinsamen Version.

Drei-Wege-Merge

Der gebräuchlichste Algorithmus ist der Drei-Wege-Merge: Zwei geänderte Versionen werden mit ihrem letzten gemeinsamen Vorfahren verglichen. Änderungen, die nur auf einer Seite vorgenommen wurden, können automatisch übernommen werden. Wurden dieselben Zeilen auf beiden Seiten unterschiedlich verändert, entsteht ein Merge-Konflikt, der manuell aufgelöst werden muss. Das Ergebnis wird in der Regel als eigener Merge-Commit gespeichert, der zwei (oder mehr) Vorgänger hat.

Strategien

Verteilte Versionsverwaltungssysteme wie Git bieten verschiedene Merge-Strategien, etwa recursive, ours, theirs oder octopus. Daneben existieren Alternativen zur klassischen Zusammenführung, insbesondere das Rebase, bei dem eigene Commits auf eine neue Basis umgesetzt werden, sowie das Cherry-Picking einzelner Commits.

Werkzeuge

Zur Konfliktauflösung stehen grafische Merge-Tools zur Verfügung, die die Versionen nebeneinander oder in einer Drei-Spalten-Ansicht darstellen. Bekannte Werkzeuge sind KDiff3, Meld und die in Entwicklungsumgebungen integrierten Editoren.
