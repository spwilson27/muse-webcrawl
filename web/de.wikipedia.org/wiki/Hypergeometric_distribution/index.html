Hypergeometrische Verteilung

Die hypergeometrische Verteilung ist eine Wahrscheinlichkeitsverteilung in der Stochastik. Sie beschreibt die Anzahl der Erfolge bei einer Stichprobe ohne Zurücklegen aus einer endlichen Grundgesamtheit, die aus zwei Sorten von Elementen besteht.

Definition

Eine Zufallsvariable X folgt einer hypergeometrischen Verteilung mit den Parametern N (Umfang der Grundgesamtheit), K (Anzahl der Elemente mit der betrachteten Eigenschaft) und n (Stichprobenumfang), wenn sie die Wahrscheinlichkeiten

P(X = k) = [ C(K, k) · C(N − K, n − k) ] / C(N, n)

besitzt, wobei C(a, b) den Binomialkoeffizienten bezeichnet.

Beispiel

Das klassische Modell ist das Lotto „6 aus 49“: Die Anzahl der „Richtigen“ in einem Tipp ist hypergeometrisch verteilt mit N = 49, K = 6 (die gezogenen Zahlen) und n = 6 (die getippten Zahlen). Auch die Qualitätskontrolle durch Stichproben ohne Zurücklegen und Fishers exakter Test in der Statistik beruhen auf dieser Verteilung.

Kennzahlen

Der Erwartungswert beträgt E(X) = n · K / N, die Varianz Var(X) = n · (K/N) · (1 − K/N) · (N − n)/(N − 1). Der Faktor (N − n)/(N − 1) ist die sogenannte Endlichkeitskorrektur. Für große Grundgesamtheiten geht die hypergeometrische Verteilung in die Binomialverteilung über.
