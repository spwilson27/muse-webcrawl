JSON Schema

JSON Schema ist eine Vokabularsprache, mit der die Struktur von JSON-Dokumenten beschrieben und validiert werden kann. Ein Schema ist selbst ein JSON-Dokument.

Grundlagen

Mit Schlüsselwörtern wie type, properties, required, items, enum oder pattern lassen sich Datentypen, Pflichtfelder, Wertebereiche und Formate festlegen. Validatoren prüfen, ob ein gegebenes JSON-Dokument dem Schema entspricht.

Verwendung

JSON Schema wird zur Validierung von API-Anfragen und -Antworten, zur Dokumentation von Schnittstellen (etwa in OpenAPI) sowie für Konfigurationsdateien eingesetzt. Die Spezifikation wird als Internet-Draft bei der IETF gepflegt.
