Pilatusbahn

Die Pilatusbahn ist eine Zahnradbahn in der Zentralschweiz, die von Alpnachstad im Kanton Obwalden auf den Pilatus bei Luzern führt. Mit einer maximalen Steigung von 48 Prozent gilt sie als steilste Zahnradbahn der Welt. Sie wurde 1889 eröffnet.

Technik

Die Strecke ist rund 4,6 Kilometer lang und überwindet etwa 1.635 Höhenmeter. Wegen der extremen Steigung wird das System Locher verwendet: Zwei horizontal liegende Zahnräder an jedem Fahrzeug greifen in eine doppelseitige Zahnstange ein, was ein Aufkippen oder Entgleisen verhindert. Die Bahn verkehrt saisonal etwa von Mai bis November; im Winter ruht der Betrieb wegen der Schneeverhältnisse.

Bedeutung

Die Pilatusbahn ist eine der bekanntesten Bergbahnen der Schweiz und bildet zusammen mit der Luftseilbahn von Kriens („Goldene Rundfahrt“) eine beliebte Tourismusroute.
