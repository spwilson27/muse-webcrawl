Metaobjekt

Ein Metaobjekt ist in der Informatik ein Objekt, das andere Objekte (Basisobjekte) beschreibt, erzeugt, steuert oder manipuliert – es operiert also auf der Metaebene eines Systems. Metaobjekte enthalten Informationen über Struktur und Verhalten anderer Objekte, etwa über deren Klasse, Methoden, Attribute und Vererbungsbeziehungen.

Begriff

Das Konzept stammt aus der objektorientierten Programmierung und der Reflexion (Reflection): Ein reflektives System kann seine eigene Struktur zur Laufzeit betrachten und verändern. In Sprachen wie Smalltalk und im Common Lisp Object System (CLOS) ist praktisch alles – einschließlich Klassen selbst – ein Objekt; Klassen werden durch Metaklassen beschrieben, deren Instanzen wiederum Metaobjekte darstellen.

Anwendung

Metaobjekte bilden die Grundlage für:

  • Metaobjekt-Protokolle, die das Verhalten des Objektsystems selbst als aufruf- und erweiterbare Schnittstelle offenlegen.
  • Objekt-relationale Mapper und Persistenzframeworks, die Metadaten über Klassen nutzen.
  • Entwicklungsumgebungen und Debugger, die Objektstrukturen inspizieren (Objektinspektoren).
  • Komponentenmodelle und Middleware, etwa CORBA mit seinem Meta Object Facility (MOF) der OMG.

Beispiele

In Qt liefert das Meta-Object System über den Meta Object Compiler (moc) Informationen über Klassen, Signale und Slots. In Java stellen die Class-Objekte der Reflection-API Metaobjekte dar, die Methoden und Felder einer Klasse beschreiben. Das Meta Object Facility (MOF) definiert auf Metaebene die Struktur von Metamodellen, beispielsweise für UML.
