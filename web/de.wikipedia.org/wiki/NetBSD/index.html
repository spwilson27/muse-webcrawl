NetBSD

Entwickler: The NetBSD Project
Erstveröffentlichung: 1993
Lizenz: BSD-Lizenz
Abstammung: 386BSD / 4.4BSD

NetBSD ist ein freies, unixoides Betriebssystem aus der Familie der BSD-Systeme. Es ist bekannt für seine ausgeprägte Portierbarkeit: Nach dem Motto „Of course it runs NetBSD" („Es läuft natürlich unter NetBSD") unterstützt es eine Vielzahl von Hardwareplattformen, von Servern und Workstations über historische Rechner bis zu eingebetteten Systemen. Die Entwicklung wird von der NetBSD Foundation betreut.

Geschichte

NetBSD entstand 1993 aus 386BSD 0.1 und Teilen der 4.3BSD-Net/2-Veröffentlichung; es ist damit neben FreeBSD eines der ältesten noch aktiv weiterentwickelten freien BSD-Systeme. Die erste Version, NetBSD 0.8, erschien im April 1993. NetBSD war das erste der großen BSD-Projekte, das mehrere Plattformen von Anfang an gleichberechtigt unterstützte.

Merkmale

Der Quellbaum ist weitgehend plattformunabhängig organisiert; maschinenabhängiger und maschinenunabhängiger Code sind strikt getrennt. Zu den technischen Kennzeichen zählen der Rump-Kernel (anykernel-Architektur), mit dem Kernelkomponenten im Userspace betrieben werden können, der Paketmanager und das plattformübergreifende Paketsystem pkgsrc sowie das portierbare Buildsystem, mit dem sich das gesamte System auf fremden Hostsystemen übersetzen lässt.

Code aus NetBSD fand unter anderem Eingang in andere Systeme; das aus NetBSD hervorgegangene Projekt DragonFly BSD spaltete sich 2003 ab, und der rump-basierte Ansatz beeinflusste weitere Forschung. OpenBSD war 1995 aus einer Abspaltung von NetBSD entstanden.
