Zentrum (Algebra)

Das Zentrum einer Gruppe G in der Algebra ist die Menge aller Elemente, die mit jedem Element der Gruppe kommutieren. Man schreibt dafür Z(G) und definiert:

Z(G) = { z ∈ G | zg = gz für alle g ∈ G }

Eigenschaften

Das Zentrum ist stets eine abelsche Untergruppe von G und sogar ein Normalteiler. Eine Gruppe ist genau dann abelsch, wenn sie mit ihrem Zentrum übereinstimmt. Ist der Quotient G / Z(G) zyklisch, so ist G bereits abelsch – daraus folgt, dass G / Z(G) niemals eine zyklische Gruppe von Primzahlordnung sein kann.

Beispiele

Das Zentrum der symmetrischen Gruppe Sn für n ≥ 3 besteht nur aus dem neutralen Element. Die allgemeine lineare Gruppe GL(n, K) dagegen hat als Zentrum die Vielfachen der Einheitsmatrix (skalare Matrizen mit von null verschiedenen Einträgen).

Bedeutung

In der Theorie der p-Gruppen spielt das Zentrum eine zentrale Rolle: Jede endliche p-Gruppe besitzt ein nichttriviales Zentrum. Dieser Satz ist ein wichtiger Schritt im Beweis der Klassengleichung-Anwendungen und der Sylow-Sätze.
