Docker, Inc.

Docker, Inc. ist ein US-amerikanisches Softwareunternehmen, das die gleichnamige Container-Plattform Docker entwickelt. Das Unternehmen wurde 2010 von Solomon Hykes unter dem Namen dotCloud in San Francisco gegründet und benannte sich 2013 nach der Veröffentlichung der Open-Source-Software Docker in Docker, Inc. um.

Geschichte

Ursprünglich betrieb das Unternehmen mit dotCloud eine Platform-as-a-Service (PaaS). Im März 2013 stellte Hykes auf der Konferenz PyCon die interne Container-Technologie als Open Source vor. Die Resonanz war so groß, dass sich das Unternehmen ganz auf Docker konzentrierte und das PaaS-Geschäft 2014 an den Berliner Anbieter cloudControl verkaufte. Docker trug maßgeblich zur Popularisierung von Betriebssystem-Virtualisierung mittels Containern bei und prägte Standards wie das Open Container Initiative (OCI) Format.

Produkte

Neben der quelloffenen Docker Engine bietet das Unternehmen kommerzielle Produkte wie Docker Desktop, Docker Hub (eine Registry für Container-Images) und Docker Business für Unternehmen an.
