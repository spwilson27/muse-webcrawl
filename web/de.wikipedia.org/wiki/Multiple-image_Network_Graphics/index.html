Multiple-image Network Graphics

Multiple-image Network Graphics (MNG, ausgesprochen „ming“) ist ein Grafikdateiformat für animierte Bilder. Es wurde als Erweiterung des Formats PNG entwickelt und von denselben Arbeitsgruppen spezifiziert, die auch PNG betreuten. Die erste Version der Spezifikation erschien 1999, Version 1.0 wurde 2001 veröffentlicht.

Eigenschaften

MNG unterstützt verlustfreie und verlustbehaftete Kompression, wobei für verlustbehaftete Einzelbilder das Format JNG (JPEG Network Graphics) eingebettet werden kann. Anders als animierte GIFs erlaubt MNG Vollfarben-Animationen mit Alphakanal, komplexe Objektkomposition, Schleifen und verschachtelte Animationen. Die Struktur basiert wie PNG auf Chunks und teilt viele Konzepte mit diesem Format.

Verbreitung

Trotz seiner technischen Fähigkeiten erreichte MNG nur geringe Verbreitung. Der Browser Mozilla unterstützte das Format zeitweise, entfernte die Unterstützung jedoch 2003 zugunsten einfacherer Alternativen; dies führte zum Fork des Formats APNG. MNG wird heute vor allem in Nischenanwendungen eingesetzt.
