patch (Unix)

patch ist ein Unix-Programm, das Textdateien anhand einer Änderungsdatei (ebenfalls Patch genannt) aktualisiert. Die Änderungsdatei enthält die Unterschiede zwischen Original und neuer Version, meist im von diff erzeugten Format. Das Programm war ursprünglich für die Verteilung von Quelltext-Änderungen konzipiert.

Geschichte

Die ursprüngliche Version wurde 1985 von Larry Wall geschrieben, der später die Programmiersprache Perl entwarf. Heute wird patch als Teil der GNU-Dienstprogramme (GNU patch) gepflegt und ist auf praktisch allen unixoiden Systemen verfügbar.

Arbeitsweise

Ein Aufruf wie patch < aenderung.patch liest die Patchdatei, lokalisiert die zu ändernden Stellen („Hunks") im Zieltext und ersetzt sie durch die neue Fassung. Ist eine Stelle durch zwischenzeitliche Bearbeitungen verschoben, versucht das Programm, sie anhand des Kontextes wiederzufinden; schlägt dies fehl, wird die Änderung in einer .rej-Datei (Rejects) abgelegt. Mit der Option -p lassen sich führende Pfadbestandteile der in der Patchdatei genannten Dateinamen entfernen, was beim Einspielen von Patches aus anderen Verzeichnissen üblich ist. Unterstützt werden unter anderem das Kontext-, das Unified- und das Normalformat von diff sowie das ed-Skript-Format.

Bedeutung

Zusammen mit diff bildet patch bis heute die Grundlage vieler Arbeitsabläufe in der Softwareentwicklung; auch Versionsverwaltungssysteme und das Linux-Kernel-Projekt nutzen Patchdateien im Unified-Diff-Format zum Austausch von Änderungen.
