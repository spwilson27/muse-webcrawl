Überladen (Programmierung)

Unter Überladen (englisch function overloading oder method overloading) versteht man in der Programmierung die Möglichkeit, mehrere Funktionen oder Methoden mit demselben Namen, aber unterschiedlichen Parameterlisten (Signaturen) zu definieren. Der Compiler oder Interpreter wählt beim Aufruf anhand der übergebenen Argumente die passende Variante aus.

Beispiel

In C++ können beispielsweise zwei Funktionen denselben Namen tragen:

int flaeche(int breite, int hoehe);
double flaeche(double radius);

Welche Funktion aufgerufen wird, entscheiden Anzahl und Typen der Argumente. Der Rückgabetyp allein genügt in den meisten Sprachen nicht zur Unterscheidung.

Sprachunterstützung

Überladung wird unter anderem von C++, Java, C#, Ada und Swift unterstützt. Nicht unterstützt wird sie dagegen von C; Sprachen wie Python erreichen ähnliche Effekte über optionale Parameter und variable Argumentlisten.

Abgrenzung

Vom Überladen zu unterscheiden ist das Überschreiben (Overriding) in der objektorientierten Programmierung, bei dem eine Methode einer Oberklasse in einer Unterklasse neu implementiert wird, sowie das Überladen von Operatoren, bei dem Operatoren wie + oder == für eigene Datentypen definiert werden.

Das Überladen gilt als Form des Ad-hoc-Polymorphismus.
