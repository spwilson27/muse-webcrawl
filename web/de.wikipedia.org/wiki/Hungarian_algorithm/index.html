Ungarische Methode

Die Ungarische Methode (englisch: Hungarian algorithm oder Hungarian method) ist ein Algorithmus der kombinatorischen Optimierung, der das Zuordnungsproblem (Assignment Problem) in polynomieller Zeit löst. Sie wurde 1955 von Harold W. Kuhn veröffentlicht und basiert auf Arbeiten der ungarischen Mathematiker Dénes Kőnig und Jenő Egerváry, worauf der Name zurückgeht.

Problemstellung

Beim Zuordnungsproblem sollen n Agenten n Aufgaben so zugeordnet werden, dass die Gesamtkosten minimiert (oder der Gesamtnutzen maximiert) werden. Gegeben ist eine Kostenmatrix; gesucht wird eine Permutation, die die Summe der ausgewählten Einträge optimiert.

Verfahren

Die Methode arbeitet mit Zeilen- und Spaltenreduktionen der Kostenmatrix: Von jeder Zeile und Spalte wird ihr Minimum subtrahiert, sodass Nullen entstehen. Anschließend wird versucht, eine vollständige Zuordnung über Nullpositionen zu finden. Ist das nicht möglich, wird die Matrix durch Abdecken der Nullen mit minimal vielen Linien und eine weitere Anpassung so lange verändert, bis eine optimale Zuordnung ablesbar ist. Die theoretische Grundlage bilden der Satz von König über bipartite Graphen und das Dualitätsprinzip der linearen Optimierung.

Anwendungen

Die Ungarische Methode wird unter anderem in der Produktionsplanung, der Personalzuteilung, der Bildverarbeitung (Objektverfolgung) und der Logistik eingesetzt. Eine verbesserte Implementierung stammt von Jonker und Volgenant (1987).
