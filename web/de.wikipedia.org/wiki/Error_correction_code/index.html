Fehlerkorrigierender Code

Ein fehlerkorrigierender Code (englisch error-correcting code, ECC) ist ein Code, der zu übertragenden oder zu speichernden Daten Redundanz hinzufügt, damit Übertragungs- oder Speicherfehler erkannt und korrigiert werden können. Fehlerkorrigierende Codes sind Gegenstand der Kodierungstheorie.

Prinzip

Bei einem (n, k)-Blockcode werden k Nutzdatenbits auf n Codebits abgebildet. Die Hamming-Distanz d zwischen beliebigen Codewörtern bestimmt die Leistungsfähigkeit: Erkennen lassen sich bis zu d−1 Fehler, korrigieren bis zu ⌊(d−1)/2⌋ Fehler. Bekannte Beispiele sind der Hamming(7,4)-Code, Reed-Muller-Codes, BCH-Codes und Reed-Solomon-Codes.

Anwendungen

ECC-Verfahren finden sich in nahezu allen modernen Kommunikations- und Speichersystemen: in Mobilfunkstandards (Turbo- und LDPC-Codes), auf optischen Datenträgern, in Solid-State-Drives, im ECC-Arbeitsspeicher von Servern und in der Raumfahrtkommunikation, wo eine erneute Übertragung oft nicht möglich ist.
