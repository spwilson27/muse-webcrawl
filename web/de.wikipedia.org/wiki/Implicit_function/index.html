Implizite Funktion

Eine implizite Funktion ist in der Mathematik eine Funktion, die nicht durch eine explizite Zuordnungsvorschrift der Form y = f(x) gegeben ist, sondern durch eine Gleichung F(x, y) = 0, aus der der Zusammenhang zwischen den Variablen nur indirekt abgelesen werden kann.

Beispiele

Der Einheitskreis wird durch x² + y² = 1 beschrieben; diese Gleichung definiert global keine einzelne Funktion, wohl aber lokal (etwa für die obere Halbebene) die Funktion y = √(1 − x²). Auch die Blätter des kartesischen Blatts x³ + y³ − 3axy = 0 lassen sich nicht global nach einer Variablen auflösen.

Ableitung impliziter Funktionen

Die Ableitung einer implizit gegebenen Funktion erhält man durch implizites Differenzieren: Man leitet die definierende Gleichung nach der unabhängigen Variablen ab und behandelt die abhängige Variable dabei als Funktion, wobei die Kettenregel anzuwenden ist. Für den Einheitskreis ergibt sich beispielsweise 2x + 2y·y′ = 0, also y′ = −x/y.

Satz über implizite Funktionen

Der Satz über implizite Funktionen gibt hinreichende Bedingungen dafür an, dass eine Gleichung F(x, y) = 0 in der Nähe eines Punktes eindeutig nach einer Variablen aufgelöst werden kann. Er ist ein zentrales Hilfsmittel der Analysis und der Differentialgeometrie.
