Schematron

Schematron ist eine regelbasierte Sprache zur Validierung von XML-Dokumenten. Anders als grammatikbasierte Schemasprachen wie DTD oder XML Schema formuliert Schematron Zusicherungen (Assertions), die ein Dokument erfüllen muss, und kann so insbesondere Abhängigkeiten zwischen verschiedenen Teilen eines Dokuments prüfen.

Prinzip

Ein Schematron-Schema besteht aus Regeln, die über XPath-Ausdrücke Kontexte in einem XML-Baum auswählen und darin Zusicherungen (assert) oder Verbote (report) prüfen. Schlägt eine Prüfung fehl, wird eine in natürlicher Sprache formulierte Meldung ausgegeben, was aussagekräftige Fehlermeldungen ermöglicht. Die Referenzimplementierung übersetzt Schematron-Schemata in XSLT-Stylesheets.

Standardisierung und Einsatz

Schematron wurde von Rick Jelliffe entwickelt und 2006 als ISO/IEC 19757-3 im Rahmen der Document Schema Definition Languages (DSDL) standardisiert. Eingesetzt wird es unter anderem zur Validierung von Geschäftsregeln in Branchenformaten, etwa im elektronischen Rechnungsaustausch und im Verlagswesen.
