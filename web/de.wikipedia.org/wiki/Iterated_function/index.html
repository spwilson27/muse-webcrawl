Iterierte Funktion

Eine iterierte Funktion ist in der Mathematik das Ergebnis der wiederholten Anwendung einer Funktion auf ihr eigenes Ergebnis. Wendet man eine Funktion f n-mal auf einen Startwert x an, schreibt man dafür f n(x). Die Folge der so entstehenden Werte heißt Orbit oder Trajektorie des Startwerts.

Definition

Rekursiv definiert man: f 0(x) = x und f n+1(x) = f(f n(x)). Das Studium iterierter Funktionen ist Gegenstand der Theorie dynamischer Systeme.

Bedeutung

Iterierte Funktionen spielen eine zentrale Rolle in der Chaostheorie und bei der Erzeugung von Fraktalen: Die berühmte Mandelbrot-Menge entsteht aus der Iteration der quadratischen Funktion z → z² + c. Auch numerische Verfahren wie das Newton-Verfahren zur Nullstellenbestimmung beruhen auf Iteration. In der Informatik beschreibt Iteration die wiederholte Ausführung von Anweisungen (Schleifen).
