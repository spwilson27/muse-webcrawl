Diagonalisierung

Die Diagonalisierung ist ein Verfahren der linearen Algebra, bei dem eine quadratische Matrix A durch eine Ähnlichkeitstransformation in eine Diagonalmatrix D überführt wird: Es gilt D = S−1AS mit einer invertierbaren Matrix S. Die Diagonaleinträge von D sind die Eigenwerte von A, die Spalten von S bilden eine Basis aus Eigenvektoren.

Kriterien

Eine Matrix ist genau dann diagonalisierbar, wenn die Summe der Dimensionen ihrer Eigenräume gleich der Dimension des Gesamtraums ist, das heißt, wenn es eine Basis aus Eigenvektoren gibt. Hinreichend ist, dass die Matrix n paarweise verschiedene Eigenwerte besitzt. Über den komplexen Zahlen scheitert die Diagonalisierbarkeit, wenn zu einem Eigenwert die geometrische Vielfachheit kleiner ist als die algebraische; in diesem Fall kann stattdessen die Jordansche Normalform gebildet werden.

Anwendungen

Die Diagonalisierung vereinfacht die Berechnung von Matrixpotenzen und -funktionen erheblich, da Ak = SDkS−1 gilt und Dk eintragsweise gebildet wird. Sie wird unter anderem zur Lösung linearer Differentialgleichungssysteme, in der Hauptachsentransformation von Quadriken und in der Quantenmechanik verwendet, wo selbstadjungierte Operatoren diagonalisiert werden.

Sonderfälle

Symmetrische beziehungsweise hermitesche Matrizen sind stets diagonalisierbar, und die Transformationsmatrix kann orthogonal beziehungsweise unitär gewählt werden (Spektralsatz). Normale Matrizen sind genau die unitär diagonalisierbaren Matrizen.
