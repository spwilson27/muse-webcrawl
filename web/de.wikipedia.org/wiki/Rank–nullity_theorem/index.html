Rangsatz

Der Rangsatz (englisch rank–nullity theorem, wörtlich „Rang-Defekt-Satz“) ist ein grundlegender Satz der linearen Algebra. Er verknüpft den Rang einer linearen Abbildung mit der Dimension ihres Kerns.

Aussage

Für eine lineare Abbildung f : V → W zwischen Vektorräumen gilt, sofern V endlichdimensional ist:

dim V = dim(ker f) + dim(im f) = Defekt(f) + Rang(f).

Die Dimension des Bildes wird als Rang, die Dimension des Kerns als Defekt (englisch nullity) der Abbildung bezeichnet.

Beispiel

Für eine Matrix A mit n Spalten besagt der Satz: n = Rang(A) + dim(Kern A). Eine quadratische Matrix ist genau dann invertierbar, wenn ihr Defekt null ist.

Bedeutung

Der Rangsatz ist ein Spezialfall des Homomorphiesatzes und Grundlage vieler Dimensionsformeln, etwa bei linearen Gleichungssystemen: Ein homogenes System mit n Unbekannten hat eine Lösungsmenge der Dimension n − Rang(A).
