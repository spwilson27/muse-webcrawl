Ausführbare Datei (Executable)

Eine ausführbare Datei (englisch executable, auch Executable file) ist eine Datei, deren Inhalt von einem Computer als Programm interpretiert und ausgeführt werden kann. Im Gegensatz zu reinen Datendateien enthält eine ausführbare Datei Anweisungen in Maschinencode oder in einer Form, die ein Interpreter verarbeiten kann.

Arten

Man unterscheidet grundsätzlich zwei Arten ausführbarer Dateien:

  • Native Programme: Sie enthalten Maschinencode, der direkt vom Prozessor ausgeführt wird. Das Format hängt vom Betriebssystem und der Prozessorarchitektur ab.
  • Skripte: Sie enthalten Quelltext oder Bytecode, der zur Laufzeit von einem Interpreter wie einer Shell, Python oder der Java-Laufzeitumgebung ausgeführt wird.

Dateiformate

Zu den bekanntesten Formaten für ausführbare Dateien gehören:

  • ELF (Executable and Linkable Format) unter Linux und anderen Unix-ähnlichen Systemen
  • PE (Portable Executable) unter Windows, erkennbar an den Dateiendungen .exe und .dll
  • Mach-O unter macOS
  • COM- und MZ-Formate unter DOS

Ausführungsberechtigung

Unix-ähnliche Systeme kennzeichnen ausführbare Dateien über ein besonderes Dateirecht (das „x-Bit"). Unter Windows entscheidet dagegen in erster Linie die Dateiendung (etwa .exe, .bat oder .com) darüber, ob eine Datei als Programm behandelt wird.

Sicherheit

Ausführbare Dateien sind ein klassischer Verbreitungsweg für Schadsoftware, da ihr Start beliebige Anweisungen ausführen kann. Moderne Betriebssysteme schützen den Nutzer daher durch Mechanismen wie Code-Signierung, Ausführungsrichtlinien und Warnungen beim Start von Dateien aus dem Internet.
