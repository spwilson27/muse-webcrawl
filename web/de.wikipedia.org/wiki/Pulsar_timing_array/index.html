Pulsar Timing Array

Ein Pulsar Timing Array (PTA) ist ein galaxisweites Messinstrument zum Nachweis niederfrequenter Gravitationswellen. Es besteht aus einem Ensemble von Millisekundenpulsaren, deren Radiopulse über Jahre hinweg mit hoher Präzision vermessen werden. Gravitationswellen, die sich zwischen den Pulsaren und der Erde ausbreiten, verändern die Ankunftszeiten der Pulse in einem charakteristischen, über den Himmel korrelierten Muster.

Prinzip

Millisekundenpulsare senden äußerst regelmäßige Pulse aus. Durchquert eine Gravitationswelle den Raum zwischen Pulsar und Erde, wird der Abstand minimal gestreckt und gestaucht, sodass die Pulse geringfügig früher oder später eintreffen. Da die Frequenz der gesuchten Wellen sehr klein ist (Nanohertz-Bereich), sind Beobachtungszeiträume von zehn Jahren und mehr nötig. Als Quellen kommen vor allem Paare supermassereicher Schwarzer Löcher in Galaxienzentren in Betracht, deren überlagerte Signale einen stochastischen Gravitationswellenhintergrund bilden.

Kollaborationen

  • NANOGrav (Nordamerika)
  • European Pulsar Timing Array (EPTA)
  • Parkes Pulsar Timing Array (PPTA, Australien)
  • Chinese Pulsar Timing Array (CPTA)
  • Indian Pulsar Timing Array (InPTA)

Die Kollaborationen sind im International Pulsar Timing Array (IPTA) zusammengeschlossen. Im Juni 2023 berichteten mehrere Kollaborationen übereinstimmend über starke Hinweise auf einen stochastischen Gravitationswellenhintergrund im Nanohertz-Bereich.
