Fedora Linux ist eine von der Community entwickelte Linux-Distribution, die vom Fedora Project gepflegt und von Red Hat gesponsert wird. Fedora gilt als innovationsfreudige Distribution, die neue Technologien wie Wayland, systemd und PipeWire frühzeitig einführt.

Geschichte

Fedora entstand 2003, als Red Hat seine kostenlose Distribution Red Hat Linux einstellte und in das Community-Projekt Fedora Core überführte, während das Unternehmen sich auf Red Hat Enterprise Linux konzentrierte. Seit Version 21 (2014) erscheint Fedora in den Editionen Workstation, Server und Cloud bzw. IoT.

Eigenschaften

Neue Hauptversionen erscheinen etwa alle sechs Monate und werden rund 13 Monate unterstützt. Fedora enthält ausschließlich freie Software und nutzt das RPM-Paketformat mit dem Paketmanager DNF. Die Distribution dient als Upstream-Grundlage für Red Hat Enterprise Linux und CentOS Stream.
