RDFa

RDFa (englisch Resource Description Framework in Attributes) ist eine vom W3C standardisierte Erweiterung von HTML bzw. XHTML, mit der sich Aussagen des Resource Description Framework (RDF) direkt in Webseiten einbetten lassen. Dadurch können Inhalte für Maschinen – etwa Suchmaschinen – semantisch ausgezeichnet werden.

Attribute

RDFa ergänzt die Markupsprache um Attribute wie about, property, typeof, resource und vocab, mit denen Subjekte, Eigenschaften und Objekttypen von RDF-Tripeln im Dokument angegeben werden. Vokabulare wie Schema.org werden häufig zusammen mit RDFa eingesetzt.

Versionen

Die erste Empfehlung erschien 2008 für XHTML 1.1. Mit RDFa 1.1 (2012) wurde die Technik für HTML5 und XML allgemein geöffnet; die vereinfachte Variante RDFa Lite richtet sich an typische Anwendungsfälle von Webautoren.

Verwendung

RDFa wird unter anderem von großen Websites wie Facebook (zusammen mit dem Open Graph Protocol) und in Projekten wie Drupal eingesetzt. Alternativen zur Einbettung strukturierter Daten sind Microdata und JSON-LD.
