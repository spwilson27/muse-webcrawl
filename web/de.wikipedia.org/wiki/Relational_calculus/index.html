Relationales Kalkül

Das relationale Kalkül ist eine formale Anfragesprache für relationale Datenbanken. Es geht auf Arbeiten von Edgar F. Codd zurück, der Anfang der 1970er Jahre das relationale Datenmodell begründete. Im Gegensatz zur prozeduralen relationalen Algebra beschreibt das relationale Kalkül eine Anfrage deklarativ: Der Benutzer gibt an, welche Daten gesucht werden, nicht, wie sie ermittelt werden sollen.

Formen

Man unterscheidet zwei Varianten:

  • Das Tupelkalkül (engl. tuple relational calculus), bei dem die Variablen ganze Tupel einer Relation durchlaufen.
  • Das Domänenkalkül (engl. domain relational calculus), bei dem die Variablen einzelne Attributwerte (Domänenwerte) annehmen.

Beispiel

Die Anfrage „Finde alle Angestellten der Abteilung 10“ lässt sich im Tupelkalkül etwa als {t | Angestellte(t) ∧ t.Abteilung = 10} schreiben. Die Sprache verwendet Quantoren (Existenzquantor ∃ und Allquantor ∀) sowie die üblichen logischen Verknüpfungen der Prädikatenlogik erster Stufe.

Bedeutung

Das relationale Kalkül ist gleich mächtig wie die relationale Algebra; diese Äquivalenz wird als Satz von Codd bezeichnet. Praktische Anfragesprachen wie SQL und QBE sind wesentlich vom relationalen Kalkül beeinflusst. Anfragen, die unabhängig von der physischen Speicherstruktur formuliert werden können, nennt man sicher (domänenunabhängig).
