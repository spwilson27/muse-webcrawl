Referenzmanager

Der Begriff Referenzmanager kann sich auf zwei verschiedene Bedeutungen beziehen: zum einen auf Software zur Literaturverwaltung, zum anderen auf Programme zur Verwaltung von Verweisstrukturen in der Informatik.

Literaturverwaltung

Im akademischen Umfeld bezeichnet ein Referenzmanager (englisch reference manager) ein Literaturverwaltungsprogramm, mit dem Forscher bibliografische Referenzen sammeln, ordnen und in wissenschaftlichen Texten zitieren. Historisch war „Reference Manager“ zugleich der Produktname eines 1984 erschienenen und später von Thomson Reuters vertriebenen Programms, dessen Weiterentwicklung 2016 eingestellt wurde; viele seiner Funktionen gingen in EndNote auf.

Verweisverwaltung in der Informatik

In der Softwareentwicklung überwachen Referenzmanager die Verweise zwischen Objekten, etwa bei der Referenzzählung zur automatischen Speicherfreigabe oder in Datenbanksystemen zur Wahrung der referentiellen Integrität. Sie stellen sicher, dass keine Verweise auf bereits gelöschte Objekte („dangling references“) bestehen bleiben.
