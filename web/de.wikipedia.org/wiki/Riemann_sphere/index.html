Riemannsche Zahlenkugel

Die Riemannsche Zahlenkugel ist ein Modell der erweiterten komplexen Zahlenebene, bei der die komplexen Zahlen durch einen zusätzlichen Punkt im Unendlichen zu einer kompakten Riemannschen Fläche ergänzt werden. Die Konstruktion geht auf Bernhard Riemann zurück.

Konstruktion

Mithilfe der stereographischen Projektion wird die komplexe Ebene bijektiv auf eine Kugeloberfläche ohne den Nordpol abgebildet; der fehlende Nordpol entspricht dem Punkt ∞. Die so entstehende erweiterte Ebene wird als Ĉ = ℂ ∪ {∞} bezeichnet. Auf ihr lassen sich Möbius-Transformationen als Drehungen der Kugel deuten.

Bedeutung

Die Zahlenkugel ist das einfachste Beispiel einer kompakten Riemannschen Fläche (vom Geschlecht 0) und wird auch als komplexe projektive Gerade ℙ¹(ℂ) aufgefasst. Meromorphe Funktionen auf der Zahlenkugel sind genau die rationalen Funktionen; Polstellen erscheinen dabei als reguläre Punkte mit Werten in Ĉ.
