Zwischencode

Eine Zwischendarstellung oder ein Zwischencode (englisch intermediate representation, IR) ist im Compilerbau eine interne Datenstruktur, in die der Quellcode eines Programms übersetzt wird, bevor daraus Zielcode für eine bestimmte Maschine erzeugt wird. Bekannte Beispiele sind LLVM IR, der Bytecode der Java Virtual Machine und die Common Intermediate Language der .NET-Plattform.

Zweck

Die Zwischendarstellung entkoppelt das sprachabhängige Frontend vom maschinenabhängigen Backend. Optimierungen wie Konstantenfaltung, Schleifenoptimierung oder die Beseitigung toten Codes werden meist auf dieser Ebene durchgeführt. Dadurch lassen sich mehrere Quellsprachen und mehrere Zielarchitekturen mit vertretbarem Aufwand unterstützen.

Formen

Verbreitete Formen sind Drei-Adress-Code, die Static-Single-Assignment-Form (SSA) sowie graphenbasierte Darstellungen wie Kontrollflussgraphen.
