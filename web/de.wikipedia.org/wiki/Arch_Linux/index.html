Arch Linux ist eine freie Linux-Distribution, die von Judd Vinet im Jahr 2002 gegründet wurde und sich an erfahrene Anwender richtet. Sie folgt dem Prinzip „Keep it simple“ und wird als Rolling-Release-System fortlaufend aktualisiert, sodass keine Versionswechsel durch Neuinstallation erforderlich sind.

Philosophie

Arch Linux orientiert sich an den Grundsätzen Einfachheit, Modernität, Pragmatismus, Benutzerzentrierung und Vielseitigkeit. Das System liefert weitgehend unveränderte Originalsoftware („vanilla“) und überlässt die Konfiguration weitgehend dem Benutzer. Die Installation erfolgt ohne grafischen Installer über die Kommandozeile; ein umfangreiches Wiki (ArchWiki) dient als zentrale Dokumentation und gilt als eines der besten Linux-Wikis überhaupt.

Paketverwaltung

Zur Paketverwaltung dient der eigens entwickelte Paketmanager Pacman, der Binärpakete aus den offiziellen Repositories (core, extra, multilib) installiert. Daneben existiert das Arch User Repository (AUR), in dem Benutzer PKGBUILD-Skripte bereitstellen, aus denen sich zusätzliche Software bauen lässt.

Ableitungen

Zahlreiche Distributionen bauen auf Arch Linux auf, darunter Manjaro, EndeavourOS, Garuda Linux und das auf SteamOS basierende System des Steam Deck (SteamOS 3.0).
