Schnittstellenbeschreibungssprache

Eine Schnittstellenbeschreibungssprache (englisch Interface Description Language, IDL) ist eine formale Sprache, mit der die Schnittstellen von Softwarekomponenten sprach- und plattformunabhängig beschrieben werden. Aus einer IDL-Beschreibung können automatisch Stubs und Skeletons für verschiedene Programmiersprachen erzeugt werden.

Verwendung

Bekannte Vertreter sind die OMG IDL des CORBA-Standards, die Web Services Description Language (WSDL) für SOAP-Dienste, Protocol Buffers von Google sowie Apache Thrift und gRPC-IDL. IDLs definieren Datentypen, Operationen und deren Parameter und ermöglichen so die Kommunikation zwischen verteilten Systemen, deren Teile in unterschiedlichen Sprachen geschrieben sind.
