Apache HBase

Apache HBase
Entwickler: Apache Software Foundation
Programmiersprache: Java
Kategorie: NoSQL-Datenbank
Lizenz: Apache License 2.0

Apache HBase ist eine verteilte, spaltenorientierte NoSQL-Datenbank, die auf dem Hadoop Distributed File System (HDFS) aufsetzt. Sie wurde nach dem Vorbild von Googles Bigtable entwickelt – der Name steht für Hadoop Database. HBase entstand 2006/2007 als Beitrag zum Hadoop-Projekt, wurde 2010 ein Top-Level-Projekt der Apache Software Foundation und ist in Java geschrieben.

Eigenschaften

HBase speichert Daten in Tabellen aus Zeilen und Spaltenfamilien; jede Zelle wird über Zeilenschlüssel, Spalte und Zeitstempel adressiert und kann mehrere Versionen eines Werts halten. Das System ist für sehr große, dünn besetzte Tabellen mit Milliarden Zeilen und Millionen Spalten ausgelegt. Tabellen werden horizontal in Regionen zerlegt, die auf verschiedene RegionServer verteilt und bei Bedarf automatisch verschoben oder geteilt werden (Sharding). HBase bietet starke Konsistenz für Zugriffe auf eine Zeile, lineare Skalierbarkeit und automatisches Failover.

Der Zugriff erfolgt über eine Java-API, REST- und Thrift-Schnittstellen sowie eine Shell; eine SQL-ähnliche Abfrageschicht stellt das Schwesterprojekt Apache Phoenix bereit. MapReduce-Aufträge können HBase-Tabellen direkt als Ein- und Ausgabe verwenden.

Einsatz

HBase wird eingesetzt, wenn wahlfreier Lese- und Schreibzugriff auf sehr große Datenmengen benötigt wird, etwa bei Facebook (zeitweise für Nachrichtenfunktionen), bei der Speicherung von Zeitreihen (zusammen mit OpenTSDB) oder in Such- und Empfehlungssystemen.
