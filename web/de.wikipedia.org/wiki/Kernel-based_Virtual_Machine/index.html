Kernel-based Virtual Machine

KVM
Typ: Hypervisor
Erstveröffentlichung: 2007
Betriebssystem: Linux
Lizenz: GNU GPL

Kernel-based Virtual Machine (KVM) ist eine Virtualisierungslösung für den Linux-Kernel, die den Kernel selbst in einen Hypervisor verwandelt. KVM wurde ursprünglich von der Firma Qumranet entwickelt und ist seit Kernelversion 2.6.20 (2007) Bestandteil des offiziellen Linux-Kernels.

Technik

KVM nutzt die Hardware-Virtualisierungsfunktionen moderner Prozessoren (Intel VT-x und AMD-V). Das Kernelmodul kvm.ko sowie architekturspezifische Module stellen jedem Gastsystem eine virtuelle Maschine mit eigener virtueller Hardware zur Verfügung. Für die Emulation der Geräte wird üblicherweise QEMU als Benutzermodus-Prozess eingesetzt. Jede virtuelle Maschine läuft als normaler Linux-Prozess und wird vom Kernel-Scheduler verwaltet.

Verwaltung

Zur Administration von KVM-Gästen werden Werkzeuge wie libvirt, virsh und virt-manager verwendet. KVM ist Grundlage vieler Cloud-Plattformen, darunter OpenStack, oVirt und Proxmox VE, und steht in Konkurrenz zu Hypervisoren wie Xen, VMware ESXi und Microsoft Hyper-V.
