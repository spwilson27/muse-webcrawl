Erzeugende Funktion

Eine erzeugende Funktion ist in der Mathematik eine formale Potenzreihe, deren Koeffizienten eine Folge von Zahlen kodieren. Erzeugende Funktionen sind ein zentrales Werkzeug der Kombinatorik, der Zahlentheorie und der Wahrscheinlichkeitsrechnung, weil sich Operationen auf Folgen in Operationen auf den zugehörigen Funktionen übersetzen lassen.

Definition

Die gewöhnliche erzeugende Funktion einer Folge (a0, a1, a2, …) ist definiert als

A(x) = a0 + a1x + a2x2 + a3x3 + …

Daneben gibt es die exponentielle erzeugende Funktion, bei der die Koeffizienten zusätzlich durch die Fakultät des Index geteilt werden:

E(x) = a0 + a1x + a2x2/2! + a3x3/3! + …

Beispiele

Die konstante Folge (1, 1, 1, …) hat die erzeugende Funktion 1/(1 − x). Die Fibonacci-Folge besitzt die rationale erzeugende Funktion x/(1 − x − x2), aus der sich die explizite Formel von Binet herleiten lässt. Die erzeugende Funktion der Catalan-Zahlen genügt einer quadratischen Gleichung.

Anwendungen

Erzeugende Funktionen werden genutzt, um Rekursionsgleichungen zu lösen, Identitäten zwischen Folgen zu beweisen und kombinatorische Abzählprobleme – etwa Partitionen ganzer Zahlen – zu behandeln. In der Wahrscheinlichkeitstheorie treten sie als wahrscheinlichkeitserzeugende Funktionen diskreter Zufallsvariablen auf; die momenterzeugende Funktion ist ein verwandtes Konzept.
