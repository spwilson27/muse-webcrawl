Lightweight Directory Access Protocol

ProtokollLDAP
Port389 (LDAP), 636 (LDAPS)
StandardRFC 4510 ff.
Erschienen1993 (LDAPv2), 1997 (LDAPv3)

Das Lightweight Directory Access Protocol (LDAP) ist ein Netzwerkprotokoll für den Zugriff auf Verzeichnisdienste. Es wurde Anfang der 1990er Jahre an der University of Michigan als schlanke Alternative zum X.500-Zugriffsprotokoll DAP entwickelt und ist heute der De-facto-Standard für die Abfrage und Verwaltung von Benutzer-, Gruppen- und Ressourcendaten in Netzwerken.

Funktionsweise

Ein LDAP-Verzeichnis ist hierarchisch als Baum (Directory Information Tree) organisiert. Jeder Eintrag besitzt einen eindeutigen Distinguished Name (DN), etwa „cn=Max Mustermann,ou=Benutzer,dc=example,dc=com“, und eine Menge von Attributen, deren Struktur durch Schemata und Objektklassen festgelegt wird. LDAP definiert Operationen zum Suchen, Hinzufügen, Ändern und Löschen von Einträgen sowie zur Authentifizierung (Bind). Die Datenübertragung erfolgt standardmäßig über Port 389, verschlüsselt über LDAPS (Port 636) oder per StartTLS.

Anwendungen

Bekannte Implementierungen und Verzeichnisdienste auf LDAP-Basis sind OpenLDAP, Microsoft Active Directory, Red Hat Directory Server und Apache Directory Server. LDAP wird unter anderem für zentrale Benutzerverwaltung, Single Sign-on, Adressbücher und die Authentifizierung in Unternehmensnetzwerken eingesetzt.
