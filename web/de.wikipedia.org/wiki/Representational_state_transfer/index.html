Representational State Transfer

Representational State Transfer (REST) ist ein Architekturstil für verteilte Systeme, insbesondere für Webservices. Er wurde im Jahr 2000 von Roy Fielding in seiner Dissertation beschrieben, in der er auch einer der Hauptautoren der HTTP-Spezifikation war.

Prinzipien

REST basiert auf mehreren Bedingungen: einer Client-Server-Architektur, Zustandslosigkeit der Kommunikation, Cachebarkeit, einer einheitlichen Schnittstelle, einem Schichtensystem und optional Code-on-Demand. Zentrale Begriffe sind Ressourcen, die über URIs adressiert werden, und ihre Repräsentationen (etwa in JSON oder XML), die über die Standardmethoden von HTTP wie GET, POST, PUT und DELETE manipuliert werden.

RESTful Webservices

Schnittstellen, die den REST-Prinzipien folgen, werden als „RESTful“ bezeichnet. REST-APIs sind heute der am weitesten verbreitete Stil für öffentliche Webschnittstellen. Das Richardson Maturity Model beschreibt Stufen der REST-Konformität bis hin zu HATEOAS (Hypermedia as the Engine of Application State).
