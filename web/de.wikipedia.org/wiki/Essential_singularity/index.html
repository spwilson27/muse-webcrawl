Wesentliche Singularität

Eine wesentliche Singularität (englisch essential singularity) ist ein Begriff der Funktionentheorie. Eine isolierte Singularität einer holomorphen Funktion heißt wesentlich, wenn sie weder hebbar ist noch ein Pol. In jeder noch so kleinen Umgebung einer wesentlichen Singularität zeigt die Funktion daher ein besonders unübersichtliches Verhalten.

Charakterisierung

In der Laurentreihenentwicklung um eine wesentliche Singularität enthält der Hauptteil unendlich viele von null verschiedene Koeffizienten. Der Satz von Casorati-Weierstraß besagt, dass das Bild jeder punktierten Umgebung einer wesentlichen Singularität dicht in der komplexen Ebene liegt. Der große Satz von Picard verschärft dies: In jeder solchen Umgebung nimmt die Funktion jeden komplexen Wert mit höchstens einer Ausnahme unendlich oft an.

Beispiel

Die Funktion f(z) = e1/z besitzt im Punkt z = 0 eine wesentliche Singularität. Während sie auf der positiven reellen Achse gegen unendlich strebt, geht sie auf der negativen reellen Achse gegen null und oszilliert auf der imaginären Achse.
