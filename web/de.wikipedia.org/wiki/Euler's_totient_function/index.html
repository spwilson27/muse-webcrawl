Eulersche Phi-Funktion

Die Eulersche Phi-Funktion (englisch Euler's totient function), üblicherweise mit φ(n) bezeichnet, gibt für eine natürliche Zahl n die Anzahl der zu n teilerfremden Zahlen unter den Zahlen 1, …, n an. Sie ist eine der grundlegenden Funktionen der elementaren Zahlentheorie und nach Leonhard Euler benannt.

Definition und erste Werte

φ(n) = |{ k ∈ {1, …, n} : ggT(k, n) = 1 }|. Per Konvention ist φ(1) = 1.

Berechnung

Aus der Primfaktorzerlegung n = ∏ pap folgt die Eulersche Produktformel:

φ(n) = n · ∏p | n (1 − 1/p)

Für eine Primzahl p gilt φ(p) = p − 1, für eine Primzahlpotenz φ(pa) = pa − pa−1. Die Phi-Funktion ist multiplikativ: Aus ggT(m, n) = 1 folgt φ(mn) = φ(m)φ(n).

Anwendungen

  • Im Satz von Euler: aφ(n) ≡ 1 (mod n) für ggT(a, n) = 1
  • Grundlage der Schlüsselerzeugung im RSA-Kryptosystem
  • Ordnung der multiplikativen Gruppe der Einheiten des Restklassenrings Z/nZ
  • Zählung der Erzeuger zyklischer Gruppen und der irreduziblen Brüche mit gegebenem Nenner
