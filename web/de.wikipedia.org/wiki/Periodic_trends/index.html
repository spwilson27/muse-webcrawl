Periodische Trends

Periodische Trends sind die regelmäßigen Veränderungen physikalischer und chemischer Eigenschaften der Elemente innerhalb des Periodensystems. Sie folgen aus der periodisch wiederkehrenden Elektronenkonfiguration und der mit der Ordnungszahl zunehmenden Kernladung.

Wichtige Trends

  • Atomradius: Nimmt innerhalb einer Periode von links nach rechts ab (wachsende Kernladung zieht die Hülle stärker an) und innerhalb einer Gruppe von oben nach unten zu (zusätzliche Elektronenschalen).
  • Ionisierungsenergie: Steigt innerhalb einer Periode an und fällt innerhalb einer Gruppe; Edelgase besitzen besonders hohe Werte.
  • Elektronegativität: Nimmt innerhalb einer Periode zu und innerhalb einer Gruppe ab; Fluor ist das elektronegativste Element.
  • Elektronenaffinität: Zeigt einen weniger regelmäßigen, im Grundzug ähnlichen Verlauf.
  • Metallcharakter: Nimmt innerhalb einer Periode ab und innerhalb einer Gruppe zu.

Erklärung

Die Trends lassen sich mit dem Konzept der effektiven Kernladung erklären: Innerhalb einer Periode schirmen die Elektronen derselben Schale die zusätzliche Kernladung nur unvollkommen ab, während neue Schalen in einer Gruppe den Abstand zum Kern und die Abschirmung deutlich vergrößern.
