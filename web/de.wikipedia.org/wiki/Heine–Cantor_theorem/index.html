Satz von Heine-Cantor

Der Satz von Heine-Cantor ist ein Satz der Analysis über gleichmäßige Stetigkeit. Er besagt, dass jede stetige Funktion auf einer kompakten Menge gleichmäßig stetig ist.

Aussage

Sei f : K → ℝ eine stetige Funktion auf einer kompakten Teilmenge K eines metrischen Raumes. Dann ist f gleichmäßig stetig auf K: Zu jedem ε > 0 existiert ein δ > 0, sodass für alle x, y ∈ K mit |x − y| < δ stets |f(x) − f(y)| < ε gilt. Das Entscheidende ist, dass δ nicht vom Punkt abhängt.

Geschichte

Eduard Heine veröffentlichte 1872 den ersten Beweis dafür, dass eine stetige Funktion auf einem abgeschlossenen beschränkten Intervall gleichmäßig stetig ist. Georg Cantor, dessen Name ebenfalls mit dem Satz verbunden wird, verallgemeinerte die zugrunde liegenden Begriffe der Stetigkeit und trug zur Klärung der Grundlagen bei. Heines Beweis benutzte ein Überdeckungsargument, das später im Satz von Heine-Borel präzisiert wurde.

Bedeutung und Beispiele

Ohne Kompaktheit gilt die Aussage nicht: Die Funktion f(x) = 1/x ist auf dem offenen Intervall (0, 1) stetig, aber nicht gleichmäßig stetig, und auch f(x) = x² ist auf ganz ℝ stetig, jedoch nicht gleichmäßig stetig. Der Satz ist ein Standardwerkzeug der Analysis, etwa beim Nachweis der Riemann-Integrierbarkeit stetiger Funktionen auf Intervallen.
