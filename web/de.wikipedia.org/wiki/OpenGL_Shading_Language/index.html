OpenGL Shading Language

ParadigmaImperative, shaderorientiert
Erscheinungsjahr2004 (mit OpenGL 2.0)
Entwickler3Dlabs, später Khronos Group
TypisierungStatisch, stark
Erweiterungen.vert, .frag, .geom, .tesc, .tese, .comp

Die OpenGL Shading Language (kurz GLSL) ist eine Shading-Sprache, die ursprünglich von 3Dlabs entwickelt wurde und heute von der Khronos Group gepflegt wird. Sie dient dazu, sogenannte Shader zu schreiben, die auf der GPU ausgeführt werden und die festverdrahtete Grafikpipeline von OpenGL durch frei programmierbare Stufen ersetzen. GLSL wurde 2004 zusammen mit OpenGL 2.0 eingeführt und ist eng an die Syntax von C angelehnt, ergänzt um Datentypen und eingebaute Funktionen für Vektor- und Matrixoperationen.

Allgemeines

GLSL-Programme werden zur Laufzeit von der Anwendung an den Grafiktreiber übergeben, dort kompiliert und auf der Grafikkarte zur Ausführung gebracht. Es gibt mehrere Shadertypen, darunter Vertex-Shader, Fragment-Shader, Geometrie-Shader, Tesselierungs-Shader und Compute-Shader. Jeder Shadertyp besitzt eine eigene Eintrittsfunktion main(). Über Qualifier wie in, out und uniform werden Daten zwischen den Pipelinestufen und der Anwendung ausgetauscht.

Die Sprache kennt skalare Typen wie float, int und bool, Vektortypen wie vec2, vec3 und vec4 sowie Matrixtypen wie mat4. Ein besonderes Merkmal ist das sogenannte Swizzling, mit dem Komponenten eines Vektors bequem ausgewählt und neu angeordnet werden können.

Beispiel

Ein einfacher Vertex-Shader, der Eingabepositionen mit einer Model-View-Projection-Matrix transformiert:

#version 330 core
layout(location = 0) in vec3 position;
uniform mat4 mvp;
void main()
{
    gl_Position = mvp * vec4(position, 1.0);
}

Ein passender Fragment-Shader, der eine konstante Farbe ausgibt:

#version 330 core
out vec4 fragColor;
void main()
{
    fragColor = vec4(1.0, 0.5, 0.2, 1.0);
}

Versionsgeschichte

Die Versionierung von GLSL folgt weitgehend der von OpenGL: GLSL 1.10 erschien mit OpenGL 2.0, GLSL 1.20 mit OpenGL 2.1 und GLSL 1.30 mit OpenGL 3.0. Ab GLSL 3.30 entspricht die Versionsnummer der OpenGL-Version (z. B. GLSL 4.60 für OpenGL 4.6). Eine eigenständige Variante ist OpenGL ES Shading Language (GLSL ES) für eingebettete Systeme und mobile Geräte; diese liegt ebenfalls WebGL zugrunde. Mit Vulkan wurde zudem die Verwendung von GLSL über die Zwischenrepräsentation SPIR-V üblich.
