Schriftrasterung

Schriftrasterung (englisch font rasterization) bezeichnet in der Computergrafik den Vorgang, die Vektor-Konturen einer Schrift in ein Raster aus Bildpunkten (Pixel) umzuwandeln, damit sie auf Monitoren oder Druckern dargestellt werden können. Dieser Vorgang wird von einer Rasterungs-Engine wie FreeType, DirectWrite oder Core Text ausgeführt.

Verfahren

Da auf niedrig auflösenden Bildschirmen die Pixelgröße die feinen Konturen der Zeichen nicht genau abbilden kann, greift die Rasterung zu Kompromissen:

  • Hinting: Anweisungen im Font, die Konturen vor dem Raster an das Pixelraster „anschnappen“ lassen, damit Stämme scharf und gleichmäßig dargestellt werden.
  • Graustufen-Antialiasing: Kanten werden durch Zwischentöne geglättet.
  • Subpixel-Rendering (z. B. ClearType von Microsoft): Die einzelnen Farbstreifen eines LCD-Pixels werden gezielt adressiert, um die horizontale Auflösung zu verdreifachen und die Lesbarkeit zu erhöhen.

Unterschiede der Betriebssysteme

Mac-Betriebssysteme bevorzugen tradi­tionell eine konturentreue Darstellung mit stärkerer Antialiasing-Glättung und weitgehenden Verzicht auf Hinting, während Windows mit DirectWrite und ClearType auf eine an das Pixelraster angepasste, kantenschärfere Darstellung setzt.
