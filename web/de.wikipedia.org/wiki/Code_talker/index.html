Code Talker

Als Code Talker (deutsch etwa „Code-Sprecher“) werden Angehörige indigener Völker Nordamerikas bezeichnet, die im Ersten und Zweiten Weltkrieg in der US-Armee und im Marine Corps Funksprüche in ihren Muttersprachen übermittelten, um eine für den Gegner praktisch unlesbare Kommunikation zu ermöglichen.

Zweiter Weltkrieg

Am bekanntesten wurden die Navajo Code Talkers des US Marine Corps im Pazifikkrieg. Ab 1942 wurden zunächst 29, später über 400 Navajo rekrutiert, die auf Grundlage ihrer Sprache einen Code entwickelten: Häufige englische Begriffe erhielten feste Navajo-Wörter, militärische Fachbegriffe wurden durch bildhafte Umschreibungen ersetzt – ein Kampfflugzeug hieß etwa „Kolibri“, ein U-Boot „eiserner Fisch“. Der Code wurde von den Japanern nie geknackt und trug nach Einschätzung der Marines wesentlich zu Erfolgen wie der Einnahme von Iwo Jima bei.

Neben den Navajo setzten die US-Streitkräfte auch Angehörige der Choctaw, Cherokee, Comanche, Hopi, Meskwaki und anderer Nationen als Code Talker ein; Choctaw-Soldaten hatten bereits 1918 im Ersten Weltkrieg Funksprüche in ihrer Sprache übermittelt.

Anerkennung

Das Programm blieb bis 1968 geheim, sodass die Ehrungen spät erfolgten: Die ursprünglichen 29 Navajo erhielten 2000 die Congressional Gold Medal, die übrigen 2001 Silbermedaillen. Der Spielfilm Windtalkers (2002) machte ihr Schicksal einem breiten Publikum bekannt.
