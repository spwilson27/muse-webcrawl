Get the latest stable release of MediaWiki

From this page you can download the current stable release of MediaWiki as a compressed archive (tar.gz), check its release notes and system requirements, and find links to legacy and alpha versions, packages for various operating systems, and the Git repository for developers.

[Image: The MediaWiki logo next to a large download button]

Requirements

MediaWiki needs a web server such as Apache or nginx, PHP, and a database server — MariaDB/MySQL is best supported, with PostgreSQL and SQLite also possible.

Installation

After downloading and unpacking, the browser-based installation script guides you through setting up the database, the wiki name, and the first administrator account; a LocalSettings.php file is generated for configuration.

Security and upgrades

Users are advised to join the mediawiki-announce mailing list for release and security announcements, and to keep their installations up to date.
