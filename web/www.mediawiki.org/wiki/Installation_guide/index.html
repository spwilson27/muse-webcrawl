MediaWiki Installation Guide

This guide walks through installing MediaWiki manually: checking that the server meets the requirements (web server, PHP version and extensions, and a supported database), downloading and unpacking the release, running the web-based installer to create LocalSettings.php, and finishing with configuration, uploads and short URLs.

[Image: Screenshot of the MediaWiki web installer welcome screen]

After installing

Next steps include choosing a skin, enabling extensions, setting user permissions, configuring caching and email, and planning backups and upgrades.
