Lexical analysis

Lexical analysis, also called scanning or tokenization, is the process of converting a sequence of characters into a sequence of tokens (strings with an assigned, meaningful value). It is typically the first phase of a compiler or interpreter.

Overview

A program that performs lexical analysis is called a lexer, tokenizer, or scanner. The lexer reads the input characters, groups them into lexemes, and outputs tokens consisting of a token name and an optional attribute value. Whitespace and comments are usually discarded at this stage.

Tokens and lexemes

A lexeme is the raw sequence of characters making up a token, such as the identifier count or the number 42. Tokens fall into categories including identifiers, keywords, literals, operators, and punctuation. Lexers are often specified using regular expressions and implemented as finite automata, or generated automatically by tools such as lex and flex.

Role in compilation

The token stream produced by the lexer is passed to the parser, which performs syntax analysis and builds a parse tree or abstract syntax tree. Splitting lexical analysis from parsing simplifies compiler design and allows each phase to be optimized independently. Lexical errors, such as illegal characters, are reported during this phase.
