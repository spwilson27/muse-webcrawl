Xbox Cloud Gaming is a cloud gaming service from Microsoft that streams Xbox games from Microsoft's Azure data centres to subscribers' devices. Announced as Project xCloud in October 2018 and tested publicly from 2019, it launched on 15 September 2020 as part of the Xbox Game Pass Ultimate subscription.

How it works

Games run on server hardware based on Xbox console architecture — initially Xbox One S blades, upgraded to Xbox Series X hardware in 2021 — and the rendered video is streamed to the client, which sends controller input back. The catalogue largely mirrors the Game Pass console library, enabling players to start a game instantly or continue a save across devices.

Availability

The service is accessible through the Xbox app on Windows and Android, through web browsers on iOS and other platforms, directly on Xbox consoles, and on selected smart televisions and streaming devices. It has rolled out to dozens of countries, though latency and picture quality depend on the user's connection and distance to a data centre.
