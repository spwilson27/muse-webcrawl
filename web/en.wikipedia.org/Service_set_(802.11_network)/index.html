Service set (802.11 network)

In IEEE 802.11 wireless local area networking, a service set is a set of wireless devices that share the same service set identifier (SSID) and related parameters, forming a logical network. A basic service set (BSS) is the building block: either an infrastructure BSS centred on one access point, identified by its BSSID (the AP's MAC address), or an independent BSS (IBSS) used in ad hoc networking.

Extended service set

An extended service set (ESS) joins multiple infrastructure BSSs through a distribution system, usually a wired Ethernet backbone, under a common SSID so clients can roam between access points. The SSID is a 0–32 byte network name broadcast in beacon frames (unless hidden) and used by stations when associating.
