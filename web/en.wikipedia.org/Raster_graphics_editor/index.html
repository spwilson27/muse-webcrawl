Raster graphics editor

A raster graphics editor (also called a bitmap editor or paint program) is a computer program that allows users to create and edit images interactively as raster graphics — grids of pixels. Such editors are used for retouching photographs, digital painting, compositing and preparing images for print and the web.

Features

Standard tools include freehand brushes and pencils, shape and line tools, fill and gradient tools, erasers, cloning/healing brushes, and text. Selections isolate regions for editing using rectangles, lassos, magic wands and masks. Layers let elements be stacked and edited independently, with blending modes and opacity. Filters and adjustment tools modify colour, contrast, sharpness and noise; many editors support non-destructive adjustment layers and histories of undoable steps. Advanced programs handle colour management, HDR images, raw photo formats and plug-ins.

Notable editors

The industry standard is Adobe Photoshop (released 1990), whose name became a verb for image manipulation. Free and open-source alternatives include GIMP and Krita (focused on digital painting). Others include Paint.NET, Affinity Photo, Corel PaintShop Pro, and the early MacPaint (1984), which popularised bitmap editing on personal computers. Online editors such as Photopea run entirely in a web browser.

Comparison with vector editors

Raster editors manipulate pixels and suit photographic material; vector graphics editors manipulate mathematical shapes and suit logos and illustration requiring arbitrary scaling. The two are often used together in design workflows.
