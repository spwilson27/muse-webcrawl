PostgreSQL, also known as Postgres, is a free and open-source relational database management system emphasising extensibility and SQL compliance. It originated in the POSTGRES project at the University of California, Berkeley, led by Michael Stonebraker in the 1980s.

Features

PostgreSQL supports transactions with ACID properties, multi-version concurrency control (MVCC), complex queries, foreign keys, triggers, updatable views, and a rich set of data types including arrays, JSON/JSONB, ranges and geometric types. Users can define custom types, functions and procedural languages — the built-in PL/pgSQL is similar to Oracle's PL/SQL. Extensions such as PostGIS add geographic database capabilities.

Adoption

Postgres is widely used as a primary data store for web, mobile, geospatial and analytics applications, and consistently ranks among the most popular and most loved database systems in developer surveys. It runs on all major operating systems and is the default database in macOS Server.
