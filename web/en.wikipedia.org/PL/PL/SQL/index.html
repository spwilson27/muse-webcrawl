PL/SQL

PL/SQL (an abbreviation of Procedural Language/SQL) is Oracle Corporation's procedural extension to the SQL database language. PL/SQL is available in Oracle Database (since version 6, with stored PL/SQL procedures added in version 7), TimesTen in-memory database and IBM Db2.

Structure

A PL/SQL program is organised into blocks, each with declaration, executable and exception-handling sections. Programs may be anonymous blocks sent from a client, or named objects stored in the database: procedures, functions, triggers and packages. PL/SQL integrates SQL statements directly, so variables can be declared with the same types as table columns using %TYPE and %ROWTYPE attributes.

Advantages

Stored PL/SQL code executes within the database server, improving performance for data-intensive logic, centralising business rules, and enhancing security because users can be granted execute rights on procedures without direct access to underlying tables.
