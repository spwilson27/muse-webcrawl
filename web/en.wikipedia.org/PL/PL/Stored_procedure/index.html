Stored procedure

A stored procedure is a subroutine available to applications that access a relational database management system. Stored procedures are stored in the database data dictionary and executed on the database server, rather than being sent repeatedly from client applications.

Overview

Procedures are written in SQL combined with a procedural language specific to the database system — for example PL/SQL in Oracle, Transact-SQL in Microsoft SQL Server, PL/pgSQL in PostgreSQL, or SQL/PSM in the SQL standard. They can accept input parameters, return output parameters and result sets, perform conditional logic and loops, and handle errors.

Advantages and disadvantages

Benefits include reduced network traffic, precompiled execution, code reuse, and the ability to enforce security and business rules centrally. Drawbacks include increased load on the database server, vendor-specific languages that hinder portability, and difficulties with version control and testing compared with application code.
