PL/SQL

DeveloperOracle Corporation
First appeared1992 (Oracle Database release 7)
ParadigmProcedural, imperative
Influenced byAda, Pascal, SQL

PL/SQL (Procedural Language for SQL) is Oracle Corporation's procedural extension language for SQL and the Oracle relational database. It combines the data-manipulating power of SQL with the processing power of a procedural language, allowing developers to write stored procedures, functions, packages and triggers that run inside the database server.

Features

PL/SQL supports variables and constants, conditional statements (IF, CASE), loops, cursors for processing query results row by row, user-defined records and collections, and structured exception handling. Code units can be grouped into packages. Because PL/SQL programs execute close to the data, they reduce network traffic between applications and the database.

Related languages

Similar procedural SQL extensions exist in other database systems: Transact-SQL in Microsoft SQL Server, PL/pgSQL in PostgreSQL (which was modelled partly on PL/SQL), and SQL PL in IBM Db2.
