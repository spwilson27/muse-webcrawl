Transact-SQL

DeveloperMicrosoft, Sybase
ParadigmProcedural, declarative
Used inMicrosoft SQL Server, Azure SQL, Sybase ASE

Transact-SQL (T-SQL) is Microsoft's and Sybase's proprietary extension to the SQL (Structured Query Language) used to interact with relational databases. It is the primary language of Microsoft SQL Server and Azure SQL Database.

Features

T-SQL extends standard SQL with procedural programming constructs: local variables, control-of-flow statements (IF...ELSE, WHILE, BEGIN...END), error handling (TRY...CATCH), transaction management, and a large library of built-in functions for string, date and mathematical operations. It is used to write stored procedures, triggers, user-defined functions and views.

History

Transact-SQL originated in the Sybase SQL Server product in the 1980s; Microsoft licensed the code for its own SQL Server, and the two implementations diverged after Microsoft rewrote its codebase in the 1990s. Successive versions added XML support, common table expressions, window functions and the MERGE statement.
