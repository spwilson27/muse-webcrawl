Transact-SQL

Transact-SQL (T-SQL) is Microsoft's and Sybase's proprietary procedural extension to the SQL (Structured Query Language) used by Microsoft SQL Server and SAP ASE (formerly Sybase Adaptive Server Enterprise). It expands standard SQL with procedural programming features including local variables, control-of-flow constructs (IF ... ELSE, WHILE), error handling (TRY ... CATCH), transaction management, and string and date processing functions.

History

T-SQL originated in the late 1980s when Sybase developed its SQL Server product and Microsoft licensed the technology for OS/2 and later Windows NT. After the partnership ended in the mid-1990s, Microsoft rewrote the database engine for SQL Server 7.0 while retaining and progressively extending the T-SQL language. Sybase's successor product, SAP ASE, kept its own dialect of the language, so the two implementations have diverged.

Features

  • Stored procedures, user-defined functions, triggers and views
  • Variables declared with DECLARE and assigned with SET or SELECT, prefixed with @
  • Flow control: BEGIN ... END blocks, IF, WHILE, RETURN, WAITFOR, and the CURSOR mechanism for row-by-row processing
  • Error handling with TRY ... CATCH and functions such as ERROR_MESSAGE()
  • Transaction statements: BEGIN TRANSACTION, COMMIT, ROLLBACK and savepoints
  • Extensions over the years including common table expressions, window functions, the MERGE statement, and integration with the .NET Common Language Runtime (SQL CLR)

Usage

T-SQL is the primary language for developing applications on Microsoft SQL Server and Azure SQL Database. It is written in tools such as SQL Server Management Studio and Azure Data Studio, and is used both for ad hoc queries and for server-side business logic stored in the database.
