PL/SQL

PL/SQL (Procedural Language for SQL) is Oracle Corporation's procedural extension for SQL and the Oracle relational database. It is available in Oracle Database (from version 6) and in the TimesTen in-memory database. PL/SQL allows developers to combine SQL statements with procedural constructs — variables, conditions, loops and exception handling — in units called blocks, which can be stored in the database as procedures, functions, packages and triggers.

Language structure

A PL/SQL block is divided into up to four sections: an optional DECLARE section for variables and cursors, a mandatory BEGIN section containing executable statements (including embedded SQL), an optional EXCEPTION section for error handlers, and END. Anonymous blocks are compiled and run on the fly, while named units are stored in the data dictionary. The language's syntax is modelled on Ada and Pascal, with strong typing based on database column types via the %TYPE and %ROWTYPE attributes.

Features

  • Stored procedures and functions callable from SQL and applications
  • Packages grouping related types, variables and subprograms, with public and private parts
  • Database triggers fired by data modification or system events
  • Collections (nested tables, VARRAYs, associative arrays) and bulk processing (BULK COLLECT, FORALL) for performance
  • Object types and, in later versions, features such as result caching and edition-based redefinition

History

PL/SQL first appeared in Oracle Database version 6 (1988) in a limited form for SQL*Forms, and became generally available for stored procedures with version 7 (1992). Each subsequent database release added capabilities, including object orientation (8i), native compilation, and integration with Java. The language inspired similar procedural extensions in other database systems.
