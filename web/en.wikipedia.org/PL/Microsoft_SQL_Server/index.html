Microsoft SQL Server is a proprietary relational database management system developed by Microsoft. Its primary query languages are T-SQL (Transact-SQL) and ANSI SQL. It stores and retrieves data as requested by other software applications, running either on the same computer or across a network.

History

SQL Server began in 1989 as a joint project of Microsoft, Sybase and Ashton-Tate for OS/2. After the partnership dissolved, Microsoft developed the product independently for Windows NT. Major milestones include SQL Server 2000, the substantially rewritten SQL Server 2005, and versions adding in-memory OLTP (2014), support for Linux and containers (2017), and big data clusters (2019).

Editions and features

SQL Server is offered in editions including Enterprise, Standard, Web, Developer and the free Express edition. Features include the Database Engine, Analysis Services (OLAP), Reporting Services, Integration Services, and high-availability options such as Always On availability groups. Its management tool is SQL Server Management Studio (SSMS); the cloud counterpart is Azure SQL Database.
