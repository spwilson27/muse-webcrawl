Model checking

Model checking is a method in computer science for automatically verifying that a finite-state model of a hardware or software system satisfies a formal specification, typically expressed in temporal logic. The technique exhaustively explores the model's state space to check whether properties such as safety ("nothing bad ever happens") and liveness ("something good eventually happens") hold.

Overview

Given a model M and a property φ, a model checker determines whether M ⊨ φ, and if not, produces a counterexample execution trace. Model checking emerged in the early 1980s from the independent work of Clarke and Emerson, and of Queille and Sifakis. Edmund M. Clarke, E. Allen Emerson, and Joseph Sifakis received the 2007 Turing Award for the invention of model checking.

Techniques

Early model checkers enumerated states explicitly, but the state explosion problem limited them to small systems. Symbolic model checking, using binary decision diagrams (BDDs), and later bounded model checking with SAT solvers, extended the reach to systems with enormous state spaces. Well-known tools include SPIN, NuSMV, and UPPAAL.

Applications

Model checking is used in the verification of digital circuits, communication protocols, device drivers, and safety-critical embedded software, complementing testing and theorem proving.
