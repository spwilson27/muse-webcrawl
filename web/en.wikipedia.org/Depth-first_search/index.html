Depth-first search

Depth-first search (DFS) is an algorithm for traversing or searching tree and graph data structures. Starting at a chosen root node, it explores as far as possible along each branch before backtracking.

Algorithm

DFS visits a start vertex, then recursively visits one unvisited neighbor at a time, marking vertices as visited to avoid cycles. It can be implemented recursively using the call stack or iteratively with an explicit stack. For a graph with V vertices and E edges, the running time is O(V + E) and the memory cost is proportional to the depth of the search.

Comparison with breadth-first search

Unlike breadth-first search, which explores vertices level by level using a queue and finds shortest paths in unweighted graphs, DFS may descend deeply into one part of the graph before visiting nearby vertices. DFS uses considerably less memory when the graph is wide, but it does not guarantee shortest paths.

Applications

DFS underlies many algorithms and tasks: topological sorting, detecting cycles, finding connected components and strongly connected components, solving mazes and puzzles, pathfinding, and generating spanning trees. Variants such as iterative deepening depth-first search combine DFS's low memory use with the completeness of breadth-first search.

History

Methods equivalent to depth-first search were used in the 19th century for maze solving, notably Trémaux's algorithm, and the technique was formalized in the early era of computer science.
