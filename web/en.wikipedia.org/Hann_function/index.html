Hann function

The Hann function is a window function named after the Austrian meteorologist Julius von Hann, widely used in signal processing and spectral analysis. It is a raised-cosine window defined, for a window of length L, by:

w(n) = 0.5 ( 1 − cos( 2πn / (L−1) ) )

for n = 0 … L−1. The function rises smoothly from 0 to 1 at the centre and falls back to 0, so that multiplying a signal segment by it tapers the segment's ends and reduces spectral leakage when the discrete Fourier transform is applied.

Properties

The Hann window has a main lobe width of 4/T (in DFT bins, 4 bins), a highest side-lobe level of about −31.5 dB, and a side-lobe roll-off of −18 dB per octave — respectable general-purpose characteristics that make it the most commonly used window in spectrum analysers. Its overlap properties are also convenient: Hann windows spaced at 50% overlap sum to a constant (for the periodic form, at any overlap that is a reciprocal of an integer), a property exploited in the short-time Fourier transform and overlap–add reconstruction.

Name

Because of its shape it was historically called the "Hanning" window (by analogy with the Hamming window), and the verb "to hann" is now preferred by its proponents; the function itself was named for von Hann, who used it in meteorological data smoothing. It is one of the family of cosine-sum windows alongside the Hamming and Blackman windows.
