The Real-time Transport Protocol (RTP) is a network protocol for delivering audio and video over IP networks. RTP is used in communication and entertainment systems that involve streaming media, such as telephony, video teleconference applications including WebRTC, television services and web-based push-to-talk features. It is specified in RFC 3550, which obsoleted RFC 1889.

Overview

RTP typically runs over the User Datagram Protocol (UDP). RTP does not guarantee delivery or prevent out-of-order delivery, nor does it reserve network resources; instead it provides sequence numbers, timestamps, payload-type identification and source identifiers that let a receiver detect packet loss, restore timing and synchronize multiple media streams, such as the audio and video of a call. Losses are usually concealed or tolerated rather than retransmitted, because for live media timely arrival matters more than perfect reliability.

Companion protocols

RTP is used in conjunction with the RTP Control Protocol (RTCP), which periodically sends statistics and feedback about transmission quality and helps synchronize separate streams. Session setup and media negotiation are typically handled by other protocols such as SIP or, in WebRTC, by SDP exchanged through an application-specific signalling channel. The Secure Real-time Transport Protocol (SRTP), defined in RFC 3711, adds encryption, authentication and integrity protection.

Packet header

The fixed 12-byte header includes a 2-bit version field, a marker bit whose meaning depends on the profile, a 7-bit payload type, a 16-bit sequence number incremented for each packet, a 32-bit timestamp reflecting the sampling instant of the first octet of the payload, and a 32-bit synchronization source (SSRC) identifier distinguishing sources within a session. Optional contributing source (CSRC) identifiers support mixers and translators.

Applications

RTP underlies VoIP systems, videoconferencing standards such as H.323 and SIP-based services, IPTV distribution, and the media transport of WebRTC, which mandates encrypted RTP through SRTP with DTLS key exchange.
