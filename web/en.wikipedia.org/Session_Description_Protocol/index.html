Session Description Protocol

SDP describes multimedia sessions in a simple text format

The Session Description Protocol (SDP) is a format for describing multimedia communication sessions for the purposes of announcement and invitation. Its predominant use is in support of streaming media applications, such as voice over IP (VoIP) and video conferencing. SDP does not deliver any media streams itself but is used between endpoints for negotiation of network metrics, media types and other associated properties. The set of properties and parameters is called a session profile.

Format

An SDP description is a plain-text document composed of lines of the form type=value. It begins with session-level information — protocol version (v=), originator (o=), session name (s=) and connection data (c=) — followed by time descriptions and one or more media descriptions (m= lines) giving the media type, port, transport protocol and list of supported formats, with optional attribute (a=) lines.

Use

SDP was published by the IETF as RFC 2327 in 1998, revised as RFC 4566 in 2006 and again as RFC 8866 in 2021. It is carried by session initiation protocols such as SIP, and is fundamental to WebRTC, where endpoints exchange SDP "offers" and "answers" to negotiate codecs, encryption keys and network candidates before media flows.
