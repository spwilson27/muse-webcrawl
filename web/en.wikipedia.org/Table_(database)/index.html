Table (database)

In a database, a table is a collection of related data held in a table format consisting of columns and rows. In relational databases, a table is a set of data elements (values) using a model of vertical columns and horizontal rows, the cell being the unit where a row and column intersect.

Overview

A table has a specified number of columns, but can have any number of rows. Each row is identified by the values appearing in a particular column subset, which has been designated as a unique key index. Tables are the fundamental storage structure of a relational database.

Columns and data types

Each column has a name and a data type, such as integer, character string, date, or binary data. Constraints may restrict the values a column can hold, including uniqueness, nullability, and referential integrity via foreign keys pointing to other tables.

Operations

Tables are manipulated with SQL statements: SELECT queries rows, INSERT adds rows, UPDATE modifies them, and DELETE removes them. Indexes can be created on columns to speed lookups. In formal relational algebra, a table corresponds to a relation, though practical SQL tables permit duplicate rows unless constrained.
