Graph traversal

Graph traversal (also known as graph search) refers to the process of visiting, checking or updating each vertex in a graph. Such traversals are classified by the order in which vertices are visited, and form the basis of many graph algorithms in computer science.

Principal strategies

The two most fundamental traversal strategies are breadth-first search (BFS), which explores vertices in order of increasing distance from the start vertex and is typically implemented with a queue, and depth-first search (DFS), which follows each branch as deeply as possible before backtracking and is typically implemented with a stack or by recursion. Tree traversal algorithms are the special case of graph traversal applied to trees.

Applications

Graph traversal is used to test connectivity, find connected components, detect cycles, perform topological sorting, and solve mazes and puzzles. BFS yields shortest paths (in number of edges) in unweighted graphs, while weighted extensions include Dijkstra's algorithm and the A* search algorithm. Traversal of web pages by search-engine crawlers is sometimes called web crawling.

Redundancy and marking

Unlike trees, graphs may contain cycles, so traversal algorithms must mark visited vertices to avoid processing a vertex more than once. A complete traversal produces a spanning tree (or spanning forest) of the graph, known as a breadth-first or depth-first tree according to the strategy used.
