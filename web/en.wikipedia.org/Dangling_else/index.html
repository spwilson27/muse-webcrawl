Dangling else

The dangling else is a problem in computer programming in which an else clause in a nested conditional statement is ambiguous: it is unclear to which if the else belongs. It arises in languages (such as C and its descendants) whose conditional grammar allows nested if-then and if-then-else forms without explicit delimiters.

Example

if (a == 1)
    if (b == 2)
        x = 1;
    else
        x = 2;

Readers may assume the else pairs with the outer if, but by the usual convention it pairs with the nearest unmatched if — the inner one. If a is not 1, nothing happens; if a is 1 and b is not 2, x becomes 2.

Resolutions

Languages resolve the ambiguity in various ways: by convention (else binds to the innermost if, as in C, Java, and ALGOL 60), by requiring blocks or terminators such as end if or fi (as in Ada, shell, and ALGOL 68), by requiring braces (Perl, Rust), or by making indentation syntactically significant (Python). Compiler grammars typically handle the construct via the "shift" preference in shift-reduce parsing. Programmers also avoid confusion by using braces and consistent indentation.
