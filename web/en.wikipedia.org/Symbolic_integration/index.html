Symbolic integration

A computer algebra system returning an antiderivative in closed form.

In calculus, symbolic integration is the problem of finding a formula for the antiderivative, or indefinite integral, of a given function f(x) — that is, to find a differentiable function F(x) whose derivative equals f(x). Unlike numerical integration, the answer is an exact expression rather than an approximation. It is one of the central capabilities of computer algebra systems.

Methods

Early programs used heuristic strategies mimicking textbook techniques: substitution patterns, integration by parts templates, trigonometric and hyperbolic manipulations, and large tables of integrals (the approach of Joel Moses's SIN program, 1967). A more algorithmic approach arrived with the Risch algorithm (1969, Robert Risch), which decides whether an elementary function has an elementary antiderivative and computes it when it exists. The Risch algorithm reduces the problem to integration in algebraic function fields, using Hermite reduction, the Lazard–Rioboo–Trager method for the logarithmic part, and related procedures. Full implementations are complicated by the constant problem — deciding whether an expression equals zero — which is undecidable in general.

Limitations

Many elementary integrands have no elementary antiderivative: e−x², sin(x)/x, and xx are classic examples whose integrals define new special functions (the error function, sine integral, and so on). Symbolic integrators therefore also return results in terms of special functions such as erf, Ei, li, and hypergeometric functions, or leave integrals unevaluated.
