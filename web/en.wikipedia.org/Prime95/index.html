Prime95

Prime95, also distributed as mprime for Linux and FreeBSD, is a freeware application written by George Woltman. It is the official client software of the Great Internet Mersenne Prime Search (GIMPS), a distributed computing project dedicated to finding new Mersenne prime numbers.

Prime95 tests whether a candidate Mersenne number is prime, traditionally using the Lucas–Lehmer primality test and, since 2020, primarily a Fermat probable-prime test with rigorous proof generation. Over the years, the project running Prime95 on volunteers' computers has discovered the largest known prime numbers, including 282,589,933 − 1, found in December 2018.

Stress testing

Beyond its mathematical purpose, Prime95 became popular among PC enthusiasts and overclockers for its "Torture Test" mode, which subjects a processor and memory subsystem to heavy, error-checking workloads. Because the program verifies its computations against known results, even a single incorrect calculation signals unstable hardware, making it a widely used stability test for overclocked systems.

Performance

The software is heavily optimized with hand-written assembly code using fast Fourier transforms to multiply very large numbers efficiently, and it takes advantage of modern CPU features such as AVX and AVX-512 instructions.
