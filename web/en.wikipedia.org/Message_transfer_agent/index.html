Message transfer agent

A message transfer agent (MTA) or mail transfer agent is software that transfers electronic mail messages from one computer to another using the Simple Mail Transfer Protocol (SMTP). MTAs are the core servers of the internet mail system.

Operation

An MTA accepts mail from a mail submission agent or another MTA, determines the recipient's domain, looks up MX records in DNS, and relays the message onward until it reaches the destination MTA, which hands it to a mail delivery agent for storage in the recipient's mailbox. If delivery fails temporarily, the MTA queues and retries; permanent failures generate bounce messages.

Examples

Widely used MTAs include Postfix, Exim, Sendmail, Microsoft Exchange, and Haraka. Internet standards such as SPF, DKIM, and DMARC help MTAs authenticate senders and fight spam and spoofing.
