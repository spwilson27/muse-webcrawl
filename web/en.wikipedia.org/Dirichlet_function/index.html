Dirichlet function

In mathematics, the Dirichlet function is the indicator function of the set of rational numbers, defined by f(x) = 1 if x is rational and f(x) = 0 if x is irrational. Named after Peter Gustav Lejeune Dirichlet, it is a classic example of a pathological function: it is continuous nowhere and not Riemann integrable on any interval, though it is Lebesgue integrable.

Properties

Because rationals and irrationals are both dense in the reals, every neighbourhood of any point contains values where f equals 0 and where f equals 1, so f has a discontinuity at every point. The function is periodic with any rational period. On any bounded interval its upper Riemann sums equal the interval length and its lower sums equal zero, so it fails Riemann integrability; in the Lebesgue theory its integral is zero since the rationals have measure zero.

Variants

A well-known modification is Thomae's function, which equals 1/q at rationals p/q in lowest terms and 0 at irrationals; unlike the Dirichlet function it is continuous at every irrational point. The Dirichlet function can also be written as a double limit of continuous functions, showing it belongs to Baire class 2 and not to Baire class 1.
