Web browser

A typical modern web browser interface

A web browser is an application for accessing websites. When a user requests a web page from a particular website, the browser retrieves its files from a web server and then displays the page's description on the user's device. Browsers are used on a range of devices, including desktops, laptops, tablets, and smartphones. By the mid-2020s, Google Chrome was by far the most used browser, followed by Safari, Microsoft Edge, and Firefox.

Function

The purpose of a web browser is to fetch content and display it on the user's device. This process begins when the user inputs a URL into the address bar. Using the Hypertext Transfer Protocol (or its encrypted form, HTTPS), the browser requests the resource from a server, receives HTML, CSS, JavaScript, images, and other files, and renders them with a browser engine. Modern browsers support tabs, bookmarks, history, extensions, private browsing modes, and synchronisation across devices.

History

The first web browser, WorldWideWeb, was created in 1990 by Sir Tim Berners-Lee. The graphical Mosaic browser (1993) popularised the Web, and its successor Netscape Navigator dominated the mid-1990s before Microsoft's Internet Explorer won the "first browser war". Mozilla Firefox (2004) revived competition, and Google Chrome (2008) introduced a fast engine and minimalist interface that eventually took the largest market share.

Components

A browser consists of a user interface, a browser engine, a rendering engine, networking components, a JavaScript interpreter, and data storage for cookies and cached resources. Major rendering engines include Blink (Chrome, Edge), WebKit (Safari), and Gecko (Firefox).
