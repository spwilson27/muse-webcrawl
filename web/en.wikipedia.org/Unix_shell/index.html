Unix shell

A Unix shell is a command-line interpreter or shell that provides a command-line user interface for Unix-like operating systems. The shell is both an interactive command language and a scripting language, and is used by the operating system to control the execution of the system using shell scripts.

Overview

Users typically interact with a Unix shell using a terminal emulator. Commands consist of the name of a program followed by arguments, separated by spaces. The shell performs expansions on the command line — such as variable expansion, wildcard (glob) matching, command substitution and arithmetic expansion — before executing the requested program or built-in command. Input and output can be redirected to files, and commands can be joined into pipelines.

History

The first Unix shell was the Thompson shell, written by Ken Thompson and introduced in the first edition of Unix in 1971. It was replaced in 1979 by the Bourne shell, written by Stephen Bourne at Bell Labs, which added a full programming language and became the standard scripting shell. The C shell (csh), developed by Bill Joy at Berkeley, added interactive features such as history and job control, and its syntax influenced the Korn shell and later designs.

Common shells

Widely used shells include the Bourne shell (sh), the Korn shell (ksh), the Bourne Again shell (Bash), which is the default on most Linux distributions, the Z shell (zsh), which became the default shell on macOS in 2019, and the Friendly Interactive Shell (fish). The Almquist shell (ash) and its descendant Debian Almquist shell (dash) are lightweight shells often used as /bin/sh on BSD systems and Debian-based Linux.

Shell scripts

A shell script is a text file containing a sequence of commands, beginning conventionally with a shebang line (#!) naming the shell to interpret it. Scripts automate administrative and repetitive tasks and are central to Unix system administration and software build processes. The POSIX standard specifies the features that a conforming shell must provide for portable scripting.
