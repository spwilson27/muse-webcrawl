Generalized least squares

In statistics, generalized least squares (GLS) is a method used to estimate the unknown parameters in a linear regression model when there is a certain degree of correlation between the residuals in the regression and/or the residuals have unequal variance (heteroscedasticity). In these cases ordinary least squares (OLS) estimates remain unbiased but are no longer efficient, and their usual standard errors are wrong; GLS restores efficiency by weighting the observations according to the error covariance structure.

Method

For the model y = Xβ + ε with error covariance matrix Var(ε) = Ω, the GLS estimator is

β̂ = (XᵀΩ⁻¹X)⁻¹XᵀΩ⁻¹y

Equivalently, the data are transformed by a matrix that "whitens" the errors — premultiplying the model by Ω−1/2 so that the transformed errors are uncorrelated with equal variance — and OLS is then applied to the transformed model. By the Gauss–Markov–Aitken theorem, GLS is the best linear unbiased estimator when Ω is known.

Feasible GLS

In practice Ω is unknown and must itself be estimated from the data, giving feasible generalized least squares (FGLS): a first-stage OLS regression supplies residuals from which the variance and correlation parameters (for example, the parameters of an autoregressive error process or group-wise variances) are estimated, and GLS is then performed with the estimated matrix. Standard applications include correcting for autocorrelation in time-series regression, heteroscedasticity across groups in panel data, and seemingly unrelated regressions. Weighted least squares is the special case in which the errors are uncorrelated but have differing variances.
