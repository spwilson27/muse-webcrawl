The Miller–Rabin primality test, also called the Rabin–Miller primality test, is a probabilistic primality test: an algorithm for determining whether a given number is likely prime. It is based on an equivalence, or a property of prime numbers, that can be turned into a test of primality: if a number does not obey the property, it is certainly composite, but numbers that obey it are only probably prime.

The test is one of the most commonly used primality tests in practice, appearing in cryptographic libraries such as OpenSSL and GMP. Variants of the test are due to Gary Miller (1976), who conditionalized it on the generalized Riemann hypothesis, and Michael Rabin (1980), who made it unconditionally probabilistic.

Description

To test an odd integer n > 2, write n − 1 as 2s·d with d odd. Choose a random base a between 2 and n − 2 and compute x = ad mod n. If x is 1 or n − 1, the test passes for this base. Otherwise square x repeatedly up to s − 1 times; if n − 1 is never reached, n is composite and a is called a witness. If n is composite, at least three quarters of bases are witnesses, so repeating the test with several random bases drives the error probability below 4−k after k rounds.

Deterministic variants

For fixed-size integers, testing a small set of predetermined bases is deterministic and exact. For numbers below 264, testing the first twelve prime bases (or a known seven-base set) is sufficient. Miller's original version is deterministic assuming the generalized Riemann hypothesis, needing only bases up to O((log n)2).

Applications

The test is used to generate large prime numbers for public-key cryptography, including RSA key generation, where candidates are sieved and then subjected to repeated Miller–Rabin rounds until the probability of error is negligible.
