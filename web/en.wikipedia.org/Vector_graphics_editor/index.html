Vector graphics editor

A vector graphics editor is a computer program that allows users to interactively compose and edit vector graphics images and save them in one of many popular vector graphics formats such as EPS, PDF, WMF, SVG, or VML. Unlike raster graphics editors, which manipulate pixels, vector editors manipulate points, lines, curves and polygons described mathematically.

Features

Typical tools include shape primitives (rectangles, ellipses, polygons), path drawing with Bézier curves, freehand paths, text, fills and gradients, layers, and transformations such as rotate, scale, skew and perspective. Because vector shapes are resolution-independent, artwork created in such editors can be enlarged without loss of quality.

Notable examples

Well-known editors include Adobe Illustrator, CorelDRAW, Affinity Designer, Sketch, and the free and open-source Inkscape. Web-based editors such as Figma have also become widely used.
