Hierarchical temporal memory

Hierarchical temporal memory (HTM) is a biologically constrained theory of intelligence and a machine learning framework originally described by Jeff Hawkins and Dileep George in 2005 and developed by the company Numenta. HTM models structural and algorithmic properties of the neocortex, aiming to learn patterns in sensory data, make predictions, and detect anomalies.

Overview

HTM networks are organised into regions arranged in a hierarchy. Each region learns sparse distributed representations of its input using competitive learning algorithms influenced by the operation of cortical columns and pyramidal neurons. A key component is the spatial pooler, which converts input patterns into sparse distributed representations, and temporal memory, which learns sequences and forms predictions.

Sparse distributed representations

Information in HTM is encoded as sparse distributed representations (SDRs): large binary vectors in which only a small fraction of bits are active. SDRs are argued to have useful properties such as robustness to noise and subsampling, and semantic similarity corresponding to overlap between representations.

Applications and criticism

HTM has been applied to anomaly detection in streaming data, such as server metrics and financial data. While proponents emphasise its biological plausibility and online learning, critics note limited adoption compared with deep learning approaches and the difficulty of benchmarking its performance on standard tasks.
