Solovay–Strassen primality test

From Wikipedia, the free encyclopedia


Primality testing flowchart

The Solovay–Strassen primality test, developed by Robert M. Solovay and Volker Strassen in 1977, is a probabilistic test to determine if a number is composite or probably prime. The concept behind the test was originally discovered by M. M. Artjuhov in 1967. The test was historically important as one of the first widely used probabilistic primality tests, foreshadowing the Miller–Rabin test.

Concept

For an odd prime p and integer a, Euler's criterion states that a(p−1)/2 ≡ (a/p) (mod p), where (a/p) is the Legendre (or Jacobi) symbol. The test picks random bases a; if the congruence fails for some base, n is certainly composite. If it holds for many independent bases, n is prime with high probability: a composite passes each round with probability at most one half.

Use

The test can be implemented efficiently with modular exponentiation and Jacobi symbol computation. It has largely been superseded by the faster Miller–Rabin test, and deterministic polynomial-time primality proving arrived with the AKS test in 2002.
