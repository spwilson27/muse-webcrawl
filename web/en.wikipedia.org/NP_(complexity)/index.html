DefinitionDecision problems verifiable in polynomial time by a deterministic Turing machine

In computational complexity theory, NP (nondeterministic polynomial time) is a complexity class used to classify decision problems. NP is the set of decision problems for which the problem instances where the answer is "yes" have proofs that can be verified in polynomial time by a deterministic Turing machine, or equivalently the set of problems that can be solved in polynomial time by a nondeterministic Turing machine.

P versus NP

The question of whether P equals NP — whether every problem whose solution can be verified quickly can also be solved quickly — is one of the most important open problems in computer science and mathematics, and is one of the Millennium Prize Problems. The class P of problems solvable in polynomial time is contained in NP, but whether the containment is strict is unknown.

NP-completeness

A problem is NP-complete if it is in NP and every problem in NP reduces to it in polynomial time. The Cook–Levin theorem established that the Boolean satisfiability problem (SAT) is NP-complete. Thousands of problems — including the travelling salesman decision problem and many scheduling, packing, and graph problems — have since been shown NP-complete, meaning that an efficient algorithm for any one of them would yield efficient algorithms for all of NP.

Examples

Problems in NP include integer factorization, the graph isomorphism problem, and all problems in P. Some problems in NP are not known to be in P or NP-complete, a category made concrete by Ladner's theorem if P ≠ NP.
