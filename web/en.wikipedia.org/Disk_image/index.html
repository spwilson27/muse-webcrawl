Disk image

A disk image is a computer file that contains the complete contents and structure of a storage volume, such as a hard disk, optical disc, floppy disk or USB flash drive. Creating a disk image is called disk imaging, and the process of writing an image back to a medium is sometimes called burning (for optical media) or restoring.

Formats

Common disk image formats include ISO images (.iso) for optical discs, Apple Disk Images (.dmg), raw images (.img), and virtual machine formats such as VHD, VHDX, VMDK and qcow2. Some formats support compression and encryption, and some record only the used portions of the disk ("smart" imaging) rather than a sector-by-sector copy.

Uses

Disk images are used for backup and system recovery, software distribution (especially operating system installers), creating bootable installation media, digital forensics — where a bit-for-bit image preserves evidence — and emulation and virtualization, where an image serves as a virtual machine's virtual hard drive. Many operating systems can mount an image so it appears as a real drive.
