MRDP theorem

Diophantine sets coincide with computably enumerable sets

Named for: Martin Davis, Hilary Putnam, Julia Robinson, Yuri Matiyasevich
Completed: 1970

The MRDP theorem (also called Matiyasevich's theorem) states that a set of integers is computably enumerable if and only if it is Diophantine — that is, it can be defined as the set of values for which some polynomial equation with integer coefficients has solutions in integers. The theorem gives a negative solution to Hilbert's tenth problem: there can be no algorithm that decides, for an arbitrary Diophantine equation, whether it has an integer solution.

Background and proof

David Hilbert's tenth problem (1900) asked for a general algorithm to determine whether a given polynomial Diophantine equation has integer solutions. In the 1950s and 1960s, Martin Davis predicted that Diophantine sets would prove to coincide with listable (recursively enumerable) sets; Davis, Hilary Putnam, and Julia Robinson proved the result for exponential Diophantine equations and narrowed the gap, with Robinson showing that it sufficed to find one particular kind of Diophantine relation growing roughly exponentially. In 1970 the 22-year-old Yuri Matiyasevich supplied the missing step, showing that the Fibonacci numbers can be defined Diophantine-ly, which completed the proof.

Consequences

Because there exist computably enumerable sets that are not computable, the MRDP theorem implies the unsolvability of Hilbert's tenth problem. It also implies that there is a polynomial whose positive values at integer inputs are exactly the prime numbers, and links number theory and logic in surprising ways: every statement about computation can, in principle, be encoded as a statement about integer solutions of polynomial equations.
