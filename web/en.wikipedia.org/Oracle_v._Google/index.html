Google LLC v. Oracle America, Inc., 593 U.S. 1 (2021), was a landmark United States Supreme Court case on copyright in software, concluding more than a decade of litigation over Google's use of the Java application programming interfaces (APIs) in its Android operating system. Oracle, which had acquired the Java platform with Sun Microsystems in 2010, sued Google for copyright and patent infringement, claiming that Google had copied the declaring code and structure of 37 Java API packages — about 11,500 lines — in building Android.

Procedural history

In 2012 a district court jury found the copied code de minimis in part, and Judge William Alsup ruled that APIs were not copyrightable; the Federal Circuit reversed in 2014, holding the declaring code copyrightable, and on remand a second jury in 2016 found Google's use to be fair use. The Federal Circuit reversed again in 2018, setting up the Supreme Court appeal, in which Oracle sought damages reported at up to $8.8 billion.

Supreme Court decision

Assuming without deciding that the code was copyrightable, the Court held 6–2, in an opinion by Justice Breyer, that Google's copying was fair use: the API declaring code was bound up with uncopyrightable ideas and functional organisation; Google took only what was needed to let programmers work in a new environment (the smartphone platform); and market effects, including Sun's earlier struggles in mobile phones, did not outweigh the public benefits of the reimplementation. The decision was widely welcomed by software developers as protecting interoperability through reimplementation of interfaces.
