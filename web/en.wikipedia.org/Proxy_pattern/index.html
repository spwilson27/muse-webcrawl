Proxy pattern

In software engineering, the proxy pattern is a design pattern in which a class functions as an interface to something else. The proxy is a wrapper or agent object that is being called by the client to access the real serving object behind the scenes. Use of the proxy can simply be forwarding to the real object, or it can provide additional logic.

Types

  • Remote proxy — represents an object located in a different address space, as in remote method invocation.
  • Virtual proxy — defers the creation or loading of an expensive object until it is actually needed (lazy loading).
  • Protection proxy — controls access to the real object based on permissions.
  • Smart reference — adds bookkeeping such as reference counting or caching.

Examples

Remote proxies underlie technologies such as CORBA and Java RMI. In graphics software, a low-resolution placeholder image acting for a large image is a virtual proxy. The pattern appears in the Gang of Four's 1994 catalogue of design patterns and is structurally similar to the adapter and decorator patterns, differing in intent.
