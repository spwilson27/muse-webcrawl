Opportunistic TLS

Opportunistic TLS is a method of upgrading a plaintext communication channel to an encrypted connection using the Transport Layer Security protocol, without requiring a separate dedicated port for secure communication.

Mechanism

Protocols such as SMTP, IMAP, POP3, FTP, and XMPP support a command (for example STARTTLS in mail protocols) with which the client asks the server to begin a TLS handshake on the same connection. If the handshake succeeds, subsequent traffic is encrypted; if not, the connection may continue in plaintext, depending on policy.

Security considerations

Because the initial request is unauthenticated, opportunistic TLS is vulnerable to downgrade ("stripping") attacks by active intermediaries, which led to the deployment of policies such as MTA-STS and DANE in the email ecosystem. It nevertheless raised the baseline of encryption on the internet by protecting against passive eavesdropping.
