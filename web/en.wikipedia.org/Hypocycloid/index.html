Hypocycloid

In geometry, a hypocycloid is a special plane curve generated by the trace of a fixed point on a small circle that rolls within a larger circle; it is comparable to a cycloid, which is generated by a circle rolling on a straight line. If the radius of the larger circle is R and that of the rolling circle is r, the curve can be described parametrically.

Special cases

If R/r is an integer n, the hypocycloid has n cusps. When R = 2r, the curve degenerates to a straight line segment (the Tusi couple). When R = 3r, it is a deltoid (tricuspoid); when R = 4r, it is an astroid. If the ratio is a rational but non-integer number, the curve has as many cusps as the numerator of the fraction in lowest terms; if irrational, the curve never closes and fills the annulus between the circles.

Properties and applications

The evolute of a hypocycloid is a similar hypocycloid, larger by a known factor. Hypocycloid gearing — in which a pinion rolls inside a ring gear — is used in some speed reducers and in the Wankel engine's geometry-related mechanisms, and the curves appear in the drawing toy Spirograph (which traces hypotrochoids, the generalized form where the point is not on the rolling circle).
