RFC 1918

RFC 1918, Address Allocation for Private Internets, is a Request for Comments published in February 1996 by Y. Rekhter, B. Moskowitz, D. Karrenberg, G. J. de Groot, and E. Lear. It defines ranges of IPv4 addresses reserved for use on private networks, which are not routable on the public Internet and may be reused concurrently by any number of separate organisations.

Address ranges

The document reserves three blocks of the IPv4 address space: 10.0.0.0 – 10.255.255.255 (10/8 prefix, a single class A network); 172.16.0.0 – 172.31.255.255 (172.16/12 prefix, 16 contiguous class B networks); and 192.168.0.0 – 192.168.255.255 (192.168/16 prefix, 256 contiguous class C networks).

Usage

Private addressing, combined with network address translation (NAT), allowed home and enterprise networks to connect many hosts to the Internet through a small number of public addresses, substantially slowing the exhaustion of IPv4 addresses. The ranges are used almost universally in home routers (commonly 192.168.0.0/24 or 192.168.1.0/24) and corporate intranets. RFC 1918 replaced RFC 1597 and is itself complemented by later documents; the shared address space 100.64.0.0/10 defined in RFC 6598 for carrier-grade NAT is a separate allocation. Internet routers should filter and not forward traffic to or from private addresses, and private addresses must not appear in public DNS.
