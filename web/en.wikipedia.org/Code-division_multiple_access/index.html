Code-division multiple access

Code-division multiple access (CDMA) is a channel access method used by various radio communication technologies. It is an example of multiple access, where several transmitters can send information simultaneously over a single communication channel. Unlike time-division or frequency-division schemes, CDMA allows all users to share the same frequency band at the same time, distinguishing their signals by assigning each user a unique spreading code.

Principle

In CDMA, each user's data is multiplied by a high-rate pseudo-random code sequence (chipping), spreading the signal over a wide bandwidth. The receiver, knowing the code, correlates the received signal to recover the desired data while other users' signals appear as noise. Accurate power control is essential to prevent a strong nearby transmitter from overwhelming weaker ones — the near–far problem.

Uses

CDMA underlies the cdmaOne (IS-95) and CDMA2000 families of second- and third-generation mobile telephony standards, particularly in North America and parts of Asia, and the W-CDMA air interface used by UMTS networks worldwide. It is also used in the Global Positioning System (GPS), where satellites transmit on shared frequencies distinguished by code, and in military communications, where spread spectrum provides resistance to jamming and low probability of intercept.
