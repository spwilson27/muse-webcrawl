Two-factor authentication

Two-factor authentication (2FA) is a type of multi-factor authentication in which a user confirms their identity using a combination of two different authentication factors. The factors are drawn from three categories: something the user knows (a password or PIN), something the user has (a phone, security key or smart card), and something the user is (a biometric trait such as a fingerprint).

Common methods

Widely used second factors include one-time codes generated by authenticator apps using the TOTP algorithm, codes sent by SMS or email, push notifications to a registered device, and hardware security keys supporting standards such as FIDO2/WebAuthn. SMS codes are convenient but vulnerable to SIM-swapping and interception, so security guidance generally prefers app-based or hardware factors.

Security considerations

By requiring two independent factors, 2FA greatly reduces the risk that a stolen or phished password alone will compromise an account. It is not invulnerable: real-time phishing proxies, push-notification fatigue attacks and account-recovery weaknesses can still be exploited, which motivates phishing-resistant authenticators and passkeys.
