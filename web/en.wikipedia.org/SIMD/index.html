SIMD

Single instruction, multiple data (SIMD) is a type of parallel processing in Flynn's taxonomy. SIMD describes computers with multiple processing elements that perform the same operation on multiple data points simultaneously. Such machines exploit data level parallelism, but not concurrency: there are simultaneous (parallel) computations, but each unit performs the exact same instruction at any given moment (just with different data). SIMD is particularly applicable to common tasks such as adjusting the contrast in a digital image or adjusting the volume of digital audio. Most modern CPU designs include SIMD instructions to improve the performance of multimedia use.

A SIMD operation applies a single instruction across multiple data elements simultaneously.

History

The first use of SIMD instructions was in the ILLIAC IV, completed in 1966. SIMD was the basis for vector supercomputers of the early 1970s such as the CDC Star-100 and the Texas Instruments ASC, which could operate on a "vector" of data with a single instruction. Vector processing was especially popularized by Cray in the 1970s and 1980s. SIMD remained relatively obscure on personal computers until the late 1990s, when Intel added the MMX instruction set to its Pentium processors, followed by SSE, AVX, and AVX-512 extensions.

Advantages

An application that may take advantage of SIMD is one where the same value is being added to (or subtracted from) a large number of data points, a common operation in many multimedia applications. One example is changing the brightness of an image. Each pixel of an image consists of three values for the brightness of the red (R), green (G) and blue (B) portions of the color. To change the brightness, the R, G and B values are read from memory, a value is added to (or subtracted from) them, and the resulting values are written back out to memory. With SIMD, a block of these values can be loaded, operated on, and written back in a single instruction stream, greatly reducing the number of instructions required.

SIMD instruction sets

Modern general-purpose processors commonly include SIMD units: x86 processors offer MMX, SSE, SSE2, AVX, AVX2 and AVX-512; ARM processors offer NEON and the Scalable Vector Extension (SVE); RISC-V defines a vector extension. Graphics processing units (GPUs) are built around a related model sometimes called SIMT (single instruction, multiple threads).
