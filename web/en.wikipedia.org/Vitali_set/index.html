Vitali set

A Vitali set selects one element from each equivalence class

Field: Set theory, measure theory

Named after: Giuseppe Vitali (1905)

In mathematics, a Vitali set is an elementary example of a set of real numbers that is not Lebesgue measurable. It is constructed using the axiom of choice and was first published by Giuseppe Vitali in 1905.

Construction

Consider the real numbers modulo the rationals: two real numbers are equivalent if their difference is rational. Restricting to the interval [0, 1], the axiom of choice guarantees a set V containing exactly one representative from each equivalence class. This V is a Vitali set.

Non-measurability

Suppose V were Lebesgue measurable. Translating V by each rational number in [−1, 1] produces a countable family of disjoint sets whose union covers [0, 1] and is contained in [−1, 2]. By translation invariance, all translates have the same measure; their total measure would then be either zero or infinite, contradicting the fact that the union lies in an interval of length 3 and contains an interval of length 1. Hence V cannot be measurable — the same style of argument shows that no set with the Vitali property can have any reasonable notion of length.

Significance

The Vitali set demonstrates that not all subsets of the real line can be assigned a Lebesgue measure, and that the existence of non-measurable sets depends essentially on the axiom of choice: in Solovay's model of set theory without full choice, every set of reals is measurable.
