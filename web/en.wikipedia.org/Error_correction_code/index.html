Error correction code

From Wikipedia, the free encyclopedia

In computing, telecommunication, and information theory, an error correction code (ECC), or forward error correction (FEC) code, is a scheme for controlling errors in data transmitted or stored over unreliable channels. The sender encodes the message with redundant information in the form of an ECC, allowing the receiver to detect and correct a limited number of errors without asking for retransmission.

History

The field began with Claude Shannon's 1948 noisy-channel coding theorem, which proved that arbitrarily reliable communication is possible at rates below channel capacity. Richard Hamming introduced the first practical family of codes — the Hamming codes — in 1950, motivated by error-prone relay computers at Bell Labs. Reed–Solomon codes (1960), convolutional codes and the Viterbi algorithm, turbo codes (1993), and low-density parity-check (LDPC) codes followed, the last two approaching the Shannon limit.

How it works

Block codes divide data into fixed-size blocks and append check symbols computed from the data. The set of valid codewords is separated by a minimum distance: a code with minimum distance d can detect up to d−1 errors and correct up to ⌊(d−1)/2⌋ errors in each block. Convolutional codes instead process data as a continuous stream, with each output symbol depending on a sliding window of input bits.

Applications

  • Storage: Reed–Solomon codes correct scratches on CDs, DVDs, and Blu-ray discs; ECC memory protects computer RAM against bit flips.
  • Communication: Deep-space probes, satellite links, mobile networks (4G/5G), and DSL all rely on powerful FEC, since retransmission may be impractical or impossible.
  • Everyday codes: QR codes use Reed–Solomon correction so they remain readable when partly damaged.
