Solovay–Strassen primality test

The Solovay–Strassen primality test, developed by Robert M. Solovay and Volker Strassen in 1977, is a probabilistic test to determine if a number is composite or probably prime. The concept behind the test was a landmark in computational number theory: it was the first widely known probabilistic primality test and paved the way for the more widely used Miller–Rabin test.

Method

Given an odd integer n, the test picks a random base a and compares the Jacobi symbol (a/n) with the value a(n−1)/2 mod n. For a prime n, Euler's criterion guarantees that these agree for every a coprime to n. If they disagree, n is certainly composite and a is called an Euler witness. If n is composite, at least half of all possible bases are witnesses, so after k independent rounds the probability that a composite passes all rounds is at most 2−k.

Euler pseudoprimes

Composite numbers that pass the test for a given base are called Euler pseudoprimes to that base. Unlike Fermat pseudoprimes, no analogue of Carmichael numbers exists for this test: every composite has many witnesses, which is what makes the probabilistic bound possible.

Significance

The test showed that primality could be decided efficiently with randomness, an insight that predated the deterministic polynomial-time AKS test by 25 years. Although superseded in practice by Miller–Rabin and Baillie–PSW, it remains of historical and pedagogical importance.
