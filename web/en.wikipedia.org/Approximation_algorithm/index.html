Approximation algorithm

An approximation algorithm is an algorithm used to find approximate solutions to optimisation problems, especially NP-hard problems where finding an exact optimum in polynomial time is believed impossible. Such an algorithm runs in polynomial time and comes with a guarantee on how far its solution can be from optimal.

Performance guarantees

An algorithm is an α-approximation for a minimisation problem if it always produces a solution costing at most α times the optimum. Classic examples include the 2-approximation for vertex cover obtained by taking both endpoints of edges in a maximal matching, greedy algorithms for set cover (with a logarithmic guarantee), and Christofides's algorithm, which guarantees a tour at most 1.5 times optimal for the metric travelling salesman problem.

Hardness of approximation

For many problems, limits are known: unless P = NP, no polynomial algorithm can approximate certain problems (such as general TSP or clique) within specified factors. The PCP theorem provides a powerful tool for proving such inapproximability results. Problems are classified into classes such as APX (constant-factor approximable) and by whether they admit a polynomial-time approximation scheme (PTAS) or a fully polynomial scheme (FPTAS), as the knapsack problem does.
