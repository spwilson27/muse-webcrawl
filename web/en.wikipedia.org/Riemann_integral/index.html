Riemann integral

The Riemann integral, created by Bernhard Riemann, was the first rigorous definition of the integral of a function on an interval. It is still the definition most commonly taught in introductory calculus and analysis courses, though it has been superseded in advanced work by the more general Lebesgue integral.

Definition

To integrate a bounded function f on [a, b], the interval is divided by a partition into subintervals. On each subinterval one forms rectangles whose heights are given by the supremum (upper sum) and infimum (lower sum) of f on that subinterval. If, as the partition is refined, the upper and lower sums approach a common value, that value is the Riemann integral of f. Equivalently, the integral is the limit of Riemann sums in which sample points are chosen in each subinterval.

Properties and limits

Every continuous function is Riemann integrable, as is every monotonic function and every bounded function with finitely many discontinuities. More precisely (Lebesgue's criterion), a bounded function is Riemann integrable if and only if its set of discontinuities has measure zero. Highly discontinuous functions, such as the Dirichlet function (1 on rationals, 0 on irrationals), are not Riemann integrable, which is one motivation for the Lebesgue integral.

Generalizations

Generalizations include the improper Riemann integral for unbounded intervals or functions, the Riemann–Stieltjes integral, and multidimensional integrals over rectangles and regions.
