Microsoft Outlook

Microsoft Outlook is a personal information manager software system from Microsoft, available as part of the Microsoft 365 office suite. Primarily an email client, it also includes a calendar, task manager, contact manager, note-taking and journal features. The name "Outlook" is also used for the Outlook.com webmail service (formerly Hotmail).

History

Outlook was first released in 1997 as part of Office 97, succeeding Microsoft's earlier Schedule+ and Exchange Client programs. It became the dominant corporate email client, tightly integrated with Microsoft Exchange Server, and successive versions added features such as improved search, social connectors, and cloud integration. A redesigned "new Outlook for Windows," based on the web app, began replacing the classic desktop client and the built-in Windows Mail and Calendar apps in the mid-2020s.

Features

Outlook supports multiple email accounts (Exchange, Outlook.com, Gmail, IMAP and — historically — POP3), rules and Quick Steps for organizing mail, Focused Inbox sorting, integrated calendaring with meeting scheduling and room booking, shared mailboxes, and task and contact management. It is available on Windows, macOS, iOS, Android and the web.

Outlook.com

Microsoft's webmail service began as Hotmail, founded in 1996 and acquired by Microsoft in 1997. It was rebranded as Outlook.com in 2012–2013, migrating hundreds of millions of users to a modern interface and Office web apps integration.
