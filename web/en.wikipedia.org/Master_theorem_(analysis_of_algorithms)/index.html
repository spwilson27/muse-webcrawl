Master theorem (analysis of algorithms)

In the analysis of algorithms, the master theorem provides a recipe for solving recurrence relations of the form that arise from divide-and-conquer algorithms:

T(n) = aT(n/b) + f(n)

where a ≥ 1 is the number of subproblems, n/b is the size of each subproblem (the input is divided into b parts), and f(n) is the cost of the work done outside the recursive calls. The theorem determines the asymptotic behaviour of T(n) by comparing f(n) with nlogb a, the rate at which the number of leaves in the recursion tree grows.

The three cases

Case 1: If f(n) = O(nlogb a − ε) for some ε > 0, then the leaves dominate and T(n) = Θ(nlogb a). Example: T(n) = 4T(n/2) + n gives T(n) = Θ(n²).

Case 2: If f(n) = Θ(nlogb a logk n) for some k ≥ 0, then every level of the tree costs about the same and T(n) = Θ(nlogb a logk+1 n). Example: merge sort, T(n) = 2T(n/2) + Θ(n), gives T(n) = Θ(n log n).

Case 3: If f(n) = Ω(nlogb a + ε) for some ε > 0, and f(n) satisfies the regularity condition a·f(n/b) ≤ c·f(n) for some c < 1, then the root dominates and T(n) = Θ(f(n)). Example: T(n) = 2T(n/2) + n² gives T(n) = Θ(n²).

Applications and limits

The theorem applies directly to binary search, merge sort, Strassen's matrix multiplication (a = 7, b = 2, yielding roughly Θ(n2.81)) and many other recursive algorithms. It does not cover recurrences with unequal subproblem sizes or non-polynomial gaps between f(n) and nlogb a; the more general Akra–Bazzi theorem handles many of those cases.
