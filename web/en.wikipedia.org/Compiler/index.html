Compiler

In computing, a compiler is a computer program that translates computer code written in one programming language (the source language) into another language (the target language). The name "compiler" is primarily used for programs that translate source code from a high-level programming language to a lower-level language (e.g. assembly language, object code, or machine code) to create an executable program.

Structure

A compiler typically performs lexical analysis (tokenizing), parsing (building a syntax tree according to a formal grammar), semantic analysis (type checking and error detection), intermediate code generation, optimization, and final code generation. The earlier phases are called the front end and the later phases the back end; retargetable compilers such as GCC and LLVM separate these so that one front end can serve many targets. The LLVM project provides reusable compiler infrastructure used by many modern language implementations.

History

The first compiler was written by Grace Hopper in 1952 (the A-0 system). The FORTRAN team at IBM, led by John Backus, produced the first complete compiler in 1957. Compiler theory drew heavily on formal language theory, including Noam Chomsky's hierarchy of grammars. Influential textbooks include Compilers: Principles, Techniques, and Tools (1986), known as the "Dragon Book."

Related tools

Interpreters execute source code directly without producing a standalone executable. Just-in-time (JIT) compilers, used by the Java HotSpot virtual machine and modern JavaScript engines, compile code during execution. A program that translates between high-level languages is called a transpiler or source-to-source compiler; a decompiler attempts the reverse translation from machine code to source.
