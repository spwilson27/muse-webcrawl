OpenID Connect

OpenID Connect (OIDC) is an authentication layer built on top of the OAuth 2.0 authorization framework. It allows clients to verify the identity of an end user based on authentication performed by an authorization server, and to obtain basic profile information in an interoperable, REST-like manner.

Overview

OpenID Connect was finalised in February 2014 by the OpenID Foundation. Unlike its predecessor OpenID 2.0, it uses JSON Web Tokens (JWT) rather than XML. The central artefact is the ID Token, a signed JWT that asserts the user's identity, the issuing provider, the intended audience, and the times of issuance and expiry.

Flows

The specification defines three flows: the authorization code flow, the implicit flow, and the hybrid flow. OIDC adds standard endpoints such as the UserInfo endpoint and a discovery mechanism (via .well-known/openid-configuration) and dynamic client registration, making federation between identity providers and relying parties practical at internet scale.
