Poisson kernel

In mathematics, and specifically in potential theory, the Poisson kernel is an integral kernel, used for solving the two-dimensional Laplace equation, given Dirichlet boundary conditions on a unit disc. The kernel provides an explicit formula for the solution of the Dirichlet problem in the disc: any harmonic function inside the disc is uniquely determined by its boundary values, and the Poisson kernel expresses the interior values as weighted averages of the boundary values. It is named for French mathematician Siméon Denis Poisson.

Definition

For the unit disc, the Poisson kernel is given by

Pr(θ) = Σn=−∞∞ r|n| einθ = (1 − r²) / (1 − 2r cos θ + r²),   0 ≤ r < 1.

Given a function u defined on the unit circle, its harmonic extension to the interior of the disc is given by the convolution of u with the Poisson kernel.

Properties

The Poisson kernel is an approximate identity: it is positive, integrates to 1 over the circle, and concentrates near the point θ = 0 as r approaches 1. These properties guarantee that the harmonic extension converges to the boundary values at points of continuity, thereby solving the Dirichlet problem for the disc.

Generalizations

Poisson kernels exist for other domains, most notably the upper half-plane and the unit ball in higher dimensions. For the unit ball in ℝn, the Poisson kernel gives the solution of the Dirichlet problem in terms of an integral over the bounding sphere. The Poisson kernel for the ball is closely related to the Green's function for the Laplacian.
