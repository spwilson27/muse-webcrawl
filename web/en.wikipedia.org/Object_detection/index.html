Object detection is a computer technology related to computer vision and image processing that deals with detecting instances of semantic objects of a certain class (such as humans, buildings, or cars) in digital images and videos. A detection system outputs both the category of each object found and its location, usually as a bounding box.

Methods

Early approaches relied on hand-crafted features and sliding-window classifiers, notably the Viola–Jones framework for face detection (2001) and histogram of oriented gradients (HOG) detectors for pedestrians. The field was transformed by deep learning: the R-CNN family (R-CNN, Fast R-CNN, Faster R-CNN) proposed candidate regions and classified them with convolutional neural networks, while single-shot detectors such as YOLO ("You Only Look Once") and SSD predict boxes and classes in one pass, enabling real-time performance. More recent transformer-based models such as DETR reformulate detection as a set-prediction problem.

Evaluation

Detectors are evaluated by the overlap between predicted and ground-truth boxes (intersection over union, IoU) and by mean average precision (mAP) across classes. Standard benchmarks include PASCAL VOC and Microsoft COCO, whose datasets provide large numbers of annotated images.

Applications

Well-researched domains of object detection include face detection and pedestrian detection. Object detection has applications in many areas of computer vision, including image retrieval, video surveillance, self-driving vehicles, medical image analysis, robotics and augmented reality.
