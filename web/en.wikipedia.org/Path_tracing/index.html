Path tracing

Path tracing is a computer graphics Monte Carlo method of rendering images of three-dimensional scenes such that the global illumination is faithful to reality. Fundamentally, the algorithm integrates over all the illuminance arriving at a single point on the surface of an object. This illuminance is then reduced by a surface reflectance function (BRDF) to determine how much of it will go towards the viewpoint camera. This integration procedure is repeated for every pixel in the output image.

Algorithm

The rendering equation, introduced by James Kajiya in 1986, describes total light emitted from a point. Path tracing estimates this integral by randomly sampling paths of light transport from the camera into the scene until they hit a light source or are terminated. Averaging many samples per pixel yields a progressively less noisy image; the method is unbiased and converges to the correct solution.

Bidirectional path tracing

Variants include bidirectional path tracing, which also traces paths from light sources, and Metropolis light transport, which mutates successful paths. These techniques handle difficult lighting such as caustics more efficiently.

Applications

Path tracing is the standard rendering method in film production, used by renderers such as Pixar's RenderMan, Arnold, and Blender's Cycles, and increasingly in real-time graphics with hardware ray tracing acceleration.
