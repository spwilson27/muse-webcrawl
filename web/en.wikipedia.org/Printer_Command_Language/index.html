Printer Command Language

Printer Command Language, commonly referred to as PCL, is a page description language developed by Hewlett-Packard as a printer protocol, introduced in 1984 with the original LaserJet. It became a de facto industry standard and is supported by many printer manufacturers.

Versions

PCL evolved through versions 1 to 6. PCL 5 added Intellifont scaling and vector (HP-GL/2) graphics; PCL 5e and 5c refined resolution enhancement and color support for the LaserJet 4 and Color LaserJet lines. PCL 6, marketed as PCL XL, is a stack-based, object-oriented protocol compiled into a compact binary format, designed for faster rendering from graphical operating systems.

Characteristics

Unlike PostScript, PCL traditionally delegates more rasterization work to the printer's own processor with comparatively simple commands, and HP has been more permissive about licensing. Companion technologies include PJL (Printer Job Language) for job-level control outside print jobs.
