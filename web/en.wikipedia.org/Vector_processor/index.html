Vector processor

In computing, a vector processor or array processor is a central processing unit (CPU) that implements an instruction set where instructions operate on large one-dimensional arrays of data called vectors. This contrasts with scalar processors, whose instructions operate on single data items. Vector processors can greatly increase performance on typical workloads, notably numerical simulation and similar tasks.

History

Vector processing was pioneered in supercomputers of the 1970s, notably the Cray-1 (1976), whose vector registers and pipelined functional units made it exceptionally fast for scientific computing. Japanese machines such as the Fujitsu VP and NEC SX series continued the approach; NEC's SX-Aurora TSUBASA later brought vector engines to accelerator cards. Modern CPUs incorporate shorter vector (SIMD) extensions such as AVX and ARM SVE, whose design — including scalable vector length — descends from the supercomputer tradition.

Architecture

Key features include vector registers holding many elements, deeply pipelined arithmetic units that produce one result per clock cycle after a start-up latency, vector length and stride control for handling multi-dimensional data, masked (predicated) operations for conditional execution, and gather-scatter memory access. Because a single instruction specifies a whole operation, instruction bandwidth and control overhead are greatly reduced.
