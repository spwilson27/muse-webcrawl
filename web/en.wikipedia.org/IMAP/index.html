Internet Message Access Protocol

The Internet Message Access Protocol (IMAP) is an Internet standard protocol used by email clients to retrieve email messages from a mail server over a TCP/IP connection. Unlike the older Post Office Protocol, IMAP keeps messages on the server, allowing a mailbox to be accessed consistently from multiple devices.

Features

IMAP supports server-side folders, searching, flags (such as read and flagged states), and partial message downloads, letting users fetch headers or individual MIME parts. The current version, IMAP4rev2, was standardized in RFC 9051 (2021), updating IMAP4rev1 from RFC 3501.

History

The protocol was designed by Mark Crispin at Stanford University in 1986 and evolved through several versions. Extensions add capabilities such as IDLE push notifications, quotas, and special-use mailbox flags.
