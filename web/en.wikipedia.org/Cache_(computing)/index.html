Cache (computing)

In computing, a cache is a hardware or software component that stores data so that future requests for that data can be served faster. The data stored in a cache might be the result of an earlier computation or a copy of data stored elsewhere.

Operation

A request served from the cache is a hit; otherwise it is a miss, requiring access to slower storage and possibly evicting existing entries according to a replacement policy such as least recently used (LRU). Caches exploit locality of reference — the tendency of programs to reuse recently or nearby accessed data.

Examples

CPUs contain multiple levels of cache (L1, L2, L3) between the processor and main memory. Other examples include disk caches, web browser caches, content delivery networks, DNS caches, and database buffer pools. Trade-offs involve cache size, coherence in multiprocessor systems, and write policies such as write-through and write-back.
