Logic gate
Electronic component implementing a Boolean function; basic gates: AND, OR, NOT, NAND, NOR, XOR, XNOR

A logic gate is a device that performs a Boolean function, a logical operation performed on one or more binary inputs that produces a single binary output. Logic gates are the fundamental building blocks of digital electronics and are implemented with transistors in integrated circuits, though they have historically been built from relays and vacuum tubes.

Basic gates

The AND gate outputs 1 only if all inputs are 1; the OR gate outputs 1 if any input is 1; the NOT gate (inverter) reverses its input. NAND and NOR are universal gates: any Boolean function can be built from NAND gates alone, or from NOR gates alone. XOR outputs 1 when its inputs differ.

Applications

Combinations of gates form adders, multiplexers, flip-flops, registers and, ultimately, entire processors containing billions of gates. Truth tables specify each gate's behaviour, and Boolean algebra and Karnaugh maps are used to design and minimise gate circuits. Standard logic families include TTL (7400 series) and CMOS (4000 series).
