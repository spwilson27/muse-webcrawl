Burrows–Wheeler transform

From Wikipedia, the free encyclopedia

The Burrows–Wheeler transform (BWT, also called block-sorting compression) is an algorithm used in data compression techniques such as bzip2. Invented by Michael Burrows and David Wheeler in 1994, it rearranges a string into runs of similar characters, which makes the result much more compressible by techniques such as move-to-front encoding and Huffman coding. The transform itself does not compress the data; it merely permutes it, in a fully reversible way.

How it works

To transform a string, all of its cyclic rotations are written out and sorted lexicographically; the last column of the resulting matrix forms the output, together with the index of the original string among the rotations. For example, transforming ^BANANA| yields BNN^AA|A. Because similar characters are grouped together, repeated patterns in the input produce long runs in the output.

Inversion

The transform is invertible: from the output column alone, the full sorted matrix can be reconstructed by repeated sorting and prepending, recovering the original string exactly. Efficient inversion can be done using the LF-mapping, which also makes the BWT useful for searching.

Applications

Beyond bzip2, the transform underlies the FM-index, a compressed full-text index used in bioinformatics tools such as Bowtie and BWA for aligning DNA sequencing reads to reference genomes.
