Wrapper library

A wrapper library is a library that translates the interface of an existing library (or other software component) into a compatible interface in another language or environment, acting as a thin layer of code between calling code and the wrapped library. Wrapper libraries are commonly used to make libraries written in one programming language usable from another, or to adapt a low-level interface to a more convenient form.

Type
Software library
Purpose
Language binding, interface adaptation
Design pattern
Adapter pattern

Purpose

Wrapper libraries serve several purposes. They provide language bindings, allowing code in one language (such as Python or Java) to call functions in a library written in another (such as C). They can simplify a complex or awkward interface, add type safety or memory management appropriate to the target language, and insulate applications from changes in the underlying library.

Examples

Well-known examples include JDBC database drivers wrapping vendor APIs, OpenGL bindings for languages other than C, and the Java Native Interface used to wrap native code for use from Java. Tools such as SWIG can generate wrapper libraries automatically from interface descriptions.

Drawbacks

Because a wrapper must be updated when the underlying library changes, wrappers can lag behind new releases; they may also introduce small performance overheads and additional points of failure.
