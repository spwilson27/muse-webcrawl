AutoML

Automated machine learning (AutoML) is the field concerned with automating the time-consuming, iterative tasks of building machine learning models, so that practitioners can produce predictive systems with limited manual effort and expertise.

Scope

AutoML methods address stages of the machine learning pipeline including automated data cleaning and feature engineering, algorithm selection, hyperparameter optimisation, and the combined algorithm-selection-and-hyperparameter problem known as CASH. A prominent subfield is neural architecture search (NAS), which automates the design of deep network structures. Techniques range from grid and random search through Bayesian optimisation, evolutionary algorithms and reinforcement learning.

Tools

Open-source systems include Auto-sklearn, Auto-WEKA, TPOT and H2O AutoML, while commercial offerings include Google Cloud Vertex AI, Microsoft Azure Automated ML, Amazon SageMaker Autopilot and DataRobot. Critics note that AutoML does not remove the need for problem framing, data quality work and evaluation, and that poorly specified objectives can produce models that optimise the wrong target.
