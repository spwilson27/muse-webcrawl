Oscilloscope

An oscilloscope is a type of electronic test instrument that graphically displays electrical signals as a two-dimensional plot of voltage against time. It allows engineers to observe waveforms, measure frequency, amplitude, distortion, and the time between events.

History

Early oscilloscopes used cathode-ray tubes (CRTs) and analog circuitry; Ferdinand Braun built the first CRT oscilloscope in 1897. General Radio produced an early commercial instrument in the 1930s, and companies such as Tektronix later made oscilloscopes a laboratory staple.

Digital oscilloscopes

Modern digital storage oscilloscopes sample the input signal with an analog-to-digital converter, allowing storage, automatic measurement, and analysis. Key specifications include bandwidth, sample rate, and the number of channels. Mixed-signal oscilloscopes add logic-analyser inputs for digital channels.
