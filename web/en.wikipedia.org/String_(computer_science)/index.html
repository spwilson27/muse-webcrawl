String (computer science)

In computer programming, a string is traditionally a sequence of characters, either as a literal constant or as some kind of variable. In formal languages, which are used in mathematical logic and theoretical computer science, a string is a finite sequence of symbols that are chosen from a set called an alphabet.

Depending on the programming language and precise data type used, a variable declared to be a string may either cause storage in memory to be statically allocated for a predetermined maximum length or employ dynamic allocation to allow it to hold a variable number of elements.

Representations

The most common representations store the characters contiguously in memory, either as a null-terminated array of characters (as in C) or paired with an explicit length. Character encodings such as ASCII, UTF-8, and UTF-16 determine how characters map to bytes or code units. Modern languages often provide immutable strings with operations like concatenation, substring extraction, searching, and comparison; the "rope" data structure offers an alternative representation efficient for large strings assembled from pieces.

String algorithms

Important algorithms on strings include pattern matching (Knuth–Morris–Pratt, Boyer–Moore), suffix trees and suffix arrays, regular expression matching, and edit distance computations such as the Levenshtein distance. String processing is central to text editors, compilers, search engines, and bioinformatics sequence analysis.

Security

Careless handling of strings has historically caused vulnerabilities such as buffer overflows, format string attacks, and injection attacks (e.g., SQL injection) when untrusted input is embedded into commands or queries.
