PREMIS

PREMIS (PREservation Metadata: Implementation Strategies) is an international standard for metadata used to support the long-term preservation of digital objects. The PREMIS Data Dictionary defines the core metadata that trustworthy digital repositories need to record in order to keep digital content usable over time.

History and structure

PREMIS was developed by an international working group convened by OCLC and the Research Libraries Group; the first version of the Data Dictionary appeared in 2005, with version 3.0 released in 2015. The Library of Congress hosts the standard's maintenance activity and an XML schema for exchanging PREMIS metadata.

Data model

The PREMIS data model consists of entities — Objects, Events, Agents and Rights — linked to one another. For each object, repositories record identifiers, fixity information (checksums), file format and significant properties, as well as the history of preservation events such as ingest, migration and fixity checks. PREMIS is a cornerstone of the OAIS reference model's concept of preservation description information.
