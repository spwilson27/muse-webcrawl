Half-duplex

A half-duplex system is a communication system in which data can be transmitted in both directions on a single channel, but not simultaneously. At any moment one party transmits while the other receives; the roles then swap. Walkie-talkies and two-way radios that require users to say "over" are classic examples, as are early Ethernet networks built with hubs and coaxial cable.

Comparison

By contrast, a full-duplex system allows simultaneous two-way communication, as in an ordinary telephone call, while a simplex system permits communication in only one direction, like a broadcast. Half-duplex operation wastes some channel capacity on turn-around time but simplifies equipment that shares a single medium or frequency band.
