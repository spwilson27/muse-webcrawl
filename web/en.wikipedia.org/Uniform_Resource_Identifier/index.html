Uniform Resource Identifier

Uniform Resource Identifier (URI)
Standard: RFC 3986
Subtypes: URL, URN
First defined: 1994 (RFC 1630)

A Uniform Resource Identifier (URI) is a string of characters that identifies a resource, usually on the Internet. The current specification, RFC 3986, defines a generic syntax of the form scheme ":" hier-part [ "?" query ] [ "#" fragment ]. URIs are the fundamental identification mechanism of the World Wide Web.

URLs and URNs

URIs are commonly divided into locators (URLs), which specify the means of accessing a resource such as an https address, and names (URNs), which identify a resource persistently without indicating its location, such as an ISBN-based URN. Every URL and URN is a URI, though the distinction has become less emphasised in modern standards work.

Resolution and references

Relative references, such as "../index.html", are resolved against a base URI to form complete identifiers — the mechanism that underlies hyperlinks between pages.
