PCRE provides a widely used implementation of Perl-style pattern matching.

Perl Compatible Regular Expressions (PCRE) is a library written in C that implements a regular expression engine inspired by the capabilities and syntax of the Perl programming language's regular expressions. It was written by Philip Hazel at the University of Cambridge, beginning in 1997, for use in the Exim mail server.

Features

PCRE supports features beyond classical regular expression syntax, including capturing groups, backreferences, lookahead and lookbehind assertions, lazy quantifiers, conditionals, recursion and callouts. Because backreferences make the language strictly more powerful than theoretical regular languages, PCRE-style expressions are sometimes called "regex" in distinction from formal regular expressions.

PCRE2 and adoption

In 2015, a revised API was released as PCRE2 (version 10.00), and the original library was deprecated. PCRE or compatible engines are used in many widely deployed systems and languages, including Apache HTTP Server, nginx, PHP, R, and tools such as grep -P. Many other languages, including Java, JavaScript and Python, implement closely related "Perl-like" syntax in their own engines.
