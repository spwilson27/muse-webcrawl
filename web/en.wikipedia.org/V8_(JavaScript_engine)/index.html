V8 is a free and open-source JavaScript and WebAssembly engine developed by Google. It was first released in 2008 alongside the Google Chrome browser and is written in C++. V8 compiles JavaScript directly to native machine code and executes it, and it is also the engine behind the Node.js and Deno runtimes and the Electron framework, making it the most widely used JavaScript engine on both client and server.

Design

V8 was designed by a team led by Lars Bak in Aarhus, Denmark. Rather than interpreting code or using a single compiler, modern V8 uses a pipeline: the Ignition interpreter generates bytecode, while the TurboFan optimizing compiler recompiles hot code with speculative optimizations based on observed types, using techniques such as hidden classes (maps) and inline caching. A generational garbage collector (Orinoco) reclaims memory with low pause times. The engine takes its name from the V8 automobile engine, reflecting its performance ambitions.

Impact

V8's speed at release — an order of magnitude faster than contemporary engines — triggered a JavaScript performance race among browser vendors and made large web applications practical. Its embeddability led directly to Node.js (2009), which moved JavaScript to the server, and V8 also executes WebAssembly. Notable features added over time include the Orinoco garbage collector, pointer compression, and support for successive ECMAScript standards.
