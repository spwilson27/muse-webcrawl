Justified true belief

Justified true belief is a traditional definition of knowledge, often traced to Plato's dialogues Theaetetus and Meno: a person knows a proposition if and only if the proposition is true, the person believes it, and the person is justified in believing it.

The tripartite analysis

The three conditions were long treated as individually necessary and jointly sufficient for knowledge. Truth ensures knowledge is factive — one cannot know what is false. Belief distinguishes knowledge from merely true statements one does not accept. Justification distinguishes knowledge from lucky guesses.

Gettier problem

In a short 1963 paper, Edmund Gettier presented counterexamples in which a belief is true and justified yet seems to be true only by luck, and therefore not knowledge. Famous variants include the stopped-clock case and cases involving disjunctions and false lemmas. The Gettier problem reshaped modern epistemology.

Responses

Proposed solutions include adding a "no false lemmas" condition, defeasibility theories, reliabilism (belief produced by a reliable process), causal theories, virtue epistemology, and knowledge-first epistemology, which denies that knowledge can be analysed into more basic components at all.
