Levenshtein distance

In information theory, linguistics and computer science, the Levenshtein distance is a string metric for measuring the difference between two sequences. It is the minimum number of single-character edits — insertions, deletions or substitutions — required to change one word into the other.

Named after: Vladimir Levenshtein
Proposed: 1965
Operations: Insert, delete, substitute
Also called: Edit distance

Examples

The distance between "kitten" and "sitting" is 3: substitute k→s, substitute e→i, insert g. The distance between "flaw" and "lawn" is 2 (delete f, insert n). Identical strings have distance 0, and the distance is symmetric and satisfies the triangle inequality, making it a true metric.

Computation

Levenshtein distance is usually computed by dynamic programming, filling a matrix whose entries give distances between prefixes of the two strings, in O(mn) time for strings of lengths m and n. The Wagner–Fischer algorithm is the standard formulation; optimisations reduce memory to two rows.

Applications

Uses include spell checking and suggestion, fuzzy string search, DNA sequence alignment in bioinformatics, plagiarism detection, and optical character recognition correction. Variants include the Damerau–Levenshtein distance, which also counts transpositions of adjacent characters.
