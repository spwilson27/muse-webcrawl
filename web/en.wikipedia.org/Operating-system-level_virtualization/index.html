Operating-system-level virtualization

Operating-system-level virtualization is an operating system (OS) virtualization paradigm in which the kernel allows the existence of multiple isolated user space instances, called containers (LXC, Solaris Containers, AIX WPARs, HP containers, Docker), zones (Solaris Containers), virtual private servers (OpenVZ), partitions, virtual environments (VEs), virtual kernels (DragonFly BSD), or jails (FreeBSD jail or chroot jail). Such instances may look like real computers from the point of view of programs running in them.

Contrast with hypervisors

In contrast to a hypervisor-based virtual machine, which emulates a complete hardware environment and runs a separate kernel for each guest, OS-level virtualization runs all instances on a single kernel. This makes containers lightweight, fast to start, and efficient in resource use, but restricts guests to the same operating system family as the host.

Implementations

Early examples include the Unix chroot mechanism (1979) and FreeBSD jails (2000). On Linux, namespaces and control groups (cgroups) provide the underlying isolation, used by LXC and Docker. Solaris Containers, AIX Workload Partitions, and OpenVZ offer comparable facilities on other platforms.
