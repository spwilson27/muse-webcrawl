SBCL

Steel Bank Common Lisp (SBCL) is a free and open-source Common Lisp implementation that features a high-performance native compiler, claimed by its developers to produce code "a few percent slower than optimized C". SBCL is largely in the public domain, with some parts under BSD-style licenses.

History

SBCL was forked from CMU Common Lisp (CMUCL) in 1999 by William Newman, who named it "Steel Bank" in homage to CMUCL's origins at Carnegie Mellon — Andrew Carnegie having made his fortune in steel, and Andrew Mellon in banking. The fork's initial goal was to clean up the code base and make the system easier to bootstrap and maintain.

The name is also an advertisement of its maintenance philosophy: SBCL emphasizes reliability, predictable behavior, and a compiler that signals errors and warnings aggressively rather than silently generating poor code.

Features

SBCL compiles Lisp code to native machine code on a wide range of platforms, including Linux, macOS, the BSDs, and Windows, on x86, x86-64, ARM, and other architectures. It provides an interactive REPL, a source-level debugger, statistical profiling, native threads, and extensive type checking. Version 2.0 was released in December 2019, and monthly releases have continued the project's steady development.
