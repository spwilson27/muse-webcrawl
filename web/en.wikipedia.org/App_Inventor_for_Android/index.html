App Inventor for Android

Original authorGoogle (Hal Abelson et al.)
Released2010
MaintainerMIT (since 2012)
TypeVisual programming / app development

App Inventor for Android is a web-based, open-source visual programming environment that allows beginners to create applications for the Android operating system. Users build apps by dragging and dropping components in a designer and snapping together code blocks, in a style similar to Scratch.

History

The project was launched by Google in 2010, led by MIT professor Hal Abelson while on sabbatical at Google. When Google discontinued it in 2011, the code was open-sourced and the project moved to the MIT Center for Mobile Learning, which relaunched it as MIT App Inventor in 2012. An iOS version was released in 2019.

Features

The environment provides two editors: a Designer for laying out user-interface components (buttons, sensors, media, and storage) and a Blocks editor for programming behaviour. A companion app allows live testing on a phone over Wi-Fi. App Inventor has been widely used in education to teach computational thinking, with millions of registered users worldwide.
