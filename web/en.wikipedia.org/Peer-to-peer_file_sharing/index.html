Peer-to-peer file sharing

Peer-to-peer file sharing is the distribution and sharing of digital media using peer-to-peer (P2P) networking technology. P2P file sharing allows users to access media files such as books, music, movies, and games using a P2P software program that searches for other connected computers on a P2P network to locate the desired content.

History

File sharing first became widely popular with the release of Napster in 1999, which used a centralized directory. After Napster was shut down following litigation, decentralized services such as Gnutella, eDonkey, Kazaa, and BitTorrent emerged. BitTorrent, created by Bram Cohen in 2001, became the dominant protocol, splitting files into pieces downloaded from many peers simultaneously and often accounting for a large share of Internet traffic.

Legal issues

P2P file sharing has been the subject of extensive legal controversy over copyright infringement, with lawsuits against both services and individual users. At the same time, the technology has many lawful uses, including distributing open-source software, public-domain media, and large datasets.
