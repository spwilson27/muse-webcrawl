Software configuration management

Software configuration management (SCM) is the discipline of tracking and controlling changes in software, part of the larger field of configuration management. It answers the questions of who changed what, when, and why, and ensures that a system's configuration can be reproduced at any point in its life.

Activities

Core SCM activities include revision control (version control of source code and other artefacts, using systems such as Git), configuration identification, change control through review and approval processes, build management, release management, and status accounting with audits.

History

SCM developed from hardware configuration management practices in defence contracting in the 1950s and 1960s, and was formalised for software in standards such as IEEE 828. Tools evolved from SCCS and RCS through CVS and Subversion to distributed systems like Git and Mercurial.
