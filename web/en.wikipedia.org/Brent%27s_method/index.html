Brent's method

In numerical analysis, Brent's method is a hybrid root-finding algorithm combining the bisection method, the secant method and inverse quadratic interpolation. It has the reliability of bisection but can be as quick as some of the less reliable methods. The algorithm tries inverse quadratic interpolation whenever possible, but falls back to the more robust secant or bisection methods when necessary.

Description

Brent's method, due to Richard Brent (1973), maintains a bracket [a, b] known to contain a root, using the fact that f(a) and f(b) have opposite signs. At each step it proposes a new point by interpolation; if the proposal is not acceptable (for instance it does not lie well inside the bracket or progress is too slow), a bisection step is taken instead. This guarantees worst-case performance comparable to bisection, while typically achieving superlinear convergence on smooth functions.

Usage

The method is widely implemented in numerical libraries — for example as brentq in SciPy and in the GNU Scientific Library — and is a common default choice for solving a one-dimensional equation f(x) = 0 when a bracket is available.
