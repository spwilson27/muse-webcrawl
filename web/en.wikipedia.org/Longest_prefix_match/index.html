Longest prefix match

Field: Computer networking
Used in: IP routing tables, CIDR

Longest prefix match is the algorithm used by routers in Internet Protocol networking to select an entry from a routing table. When several entries match the destination address, the entry with the longest subnet mask — that is, the most specific prefix — is chosen.

Example

If a table contains routes for 192.168.0.0/16 and 192.168.1.0/24, a packet addressed to 192.168.1.5 matches both, but the /24 entry wins because its 24-bit prefix is longer than the 16-bit prefix.

Implementation

Longest prefix match lookups must be performed at line speed, so routers use data structures such as tries and ternary content-addressable memory (TCAM). The rule is fundamental to Classless Inter-Domain Routing (CIDR).
