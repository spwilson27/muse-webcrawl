Kernel-based Virtual Machine

Kernel-based Virtual Machine (KVM) is a virtualization module in the Linux kernel that allows the kernel to function as a hypervisor. It was merged into the Linux kernel mainline in version 2.6.20, released in February 2007. KVM requires a processor with hardware virtualization extensions, such as Intel VT-x or AMD-V.

Operation

KVM itself provides no emulation: it exposes the /dev/kvm interface, through which a userspace program can create virtual machines, allocate their memory, and run virtual CPUs using hardware support. In practice KVM is almost always used with QEMU, which supplies device emulation, or with lighter-weight tools such as crosvm and Firecracker. Each virtual machine is implemented as a regular Linux process, so it benefits from the kernel's scheduler, memory management, cgroups and security modules.

Features

Supported features include live migration of running virtual machines, memory ballooning, CPU and memory hotplug, paravirtualised drivers (virtio), and nested virtualization. KVM supports guest operating systems including Linux, Windows, BSD variants, and others, on x86, ARM, s390, PowerPC and RISC-V architectures.

History

KVM was developed by Qumranet, a start-up acquired by Red Hat in 2008. It underpins much of the open-source cloud infrastructure built on Linux, including OpenStack deployments, Google Cloud's Compute Engine, and the microVM technology used by AWS Lambda (Firecracker).
