GTK

GTK (formerly GIMP Toolkit and GTK+) is a free and open-source cross-platform widget toolkit for creating graphical user interfaces (GUIs). It is one of the most popular toolkits for the Wayland and X11 windowing systems, and forms the foundation of the GNOME desktop environment. GTK is released under the GNU LGPL, permitting its use in both free and proprietary applications.

History

GTK was created in 1997–98 by Peter Mattis, Spencer Kimball, and Josh MacDonald for the GIMP image editor, after dissatisfaction with the Motif toolkit. Written in C using an object system (GObject) from the associated GLib library, GTK was adopted by the GNOME project, whose 1.0 release in 1999 cemented its role. GTK 2 (2002) added improved text rendering via Pango, theming, and accessibility; GTK 3 (2011) modernised rendering with Cairo and broadened device support; GTK 4 (2020) added a scene-graph-based renderer (GSK), GPU-accelerated rendering paths including Vulkan, and streamlined media and input handling.

Features and ecosystem

GTK provides a wide range of widgets, layout containers, CSS-like styling and theming, internationalised text layout, and an accessibility framework. Although written in C, it has official or community language bindings for C++, Python (PyGObject), Rust, JavaScript, Vala and many others. Well-known GTK applications include GIMP, Inkscape, GNOME's core applications, and much of the software of the Xfce and other Linux desktops; GTK also runs on Windows and macOS. The design language of modern GNOME applications is further shaped by the companion library libadwaita.
