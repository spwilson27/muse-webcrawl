EdDSA

From Wikipedia, the free encyclopedia

EdDSA operates on twisted Edwards curves, which admit fast, complete addition formulas.

The Edwards-curve Digital Signature Algorithm (EdDSA) is a digital signature scheme using a variant of Schnorr signatures based on twisted Edwards curves. It is designed to be faster than existing digital signature schemes without sacrificing security, and was developed by a team including Daniel J. Bernstein, Niels Duif, Tanja Lange, Peter Schwabe and Bo-Yin Yang. The reference implementation has formed part of widely used libraries such as libsodium.

Variants

The best-known instance is Ed25519, which uses the curve related to Curve25519 with SHA-512 and provides about 128-bit security. Ed448, defined alongside it in RFC 8032, uses a larger curve related to Curve448 with SHAKE256, targeting roughly 224-bit security. RFC 8032 describes both schemes informally as EdDSA.

Algorithm

Key generation hashes a seed with the chosen hash function to derive a scalar and a nonce prefix; the public key is the scalar multiple of the curve's base point. Signing derives a deterministic nonce from the prefix and the message, computes a challenge hash over the nonce point, public key and message, and outputs the nonce point with a scalar response. Verification checks the corresponding group equation.

Security and adoption

EdDSA's deterministic nonces protect against failures of random number generators, and its design resists common implementation pitfalls and side channels. The scheme is standardised in RFC 8032 (2017) and FIPS 186-5, and used in TLS 1.3, SSH, messaging protocols and cryptocurrencies.
