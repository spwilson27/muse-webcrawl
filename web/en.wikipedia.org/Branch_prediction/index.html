Branch prediction

In computer architecture, a branch predictor is a digital circuit that tries to guess which way a branch (e.g., an if–then–else structure) will go before this is known definitively. The purpose of the branch predictor is to improve the flow in the instruction pipeline. Branch predictors play a critical role in achieving high effective performance in many modern pipelined microprocessor architectures.

Two-way branching is usually implemented with a conditional jump instruction. A conditional jump can either be "taken" and jump to a different place in program memory, or it can be "not taken" and continue execution immediately after the conditional jump instruction. It is not known for certain whether a branch will be taken or not taken until the condition has been calculated and the conditional jump has passed the execution stage in the instruction pipeline.

Without branch prediction, the processor would have to wait until the conditional jump instruction has passed the execute stage before the next instruction can be fetched into the decode stage in the pipeline. The branch predictor attempts to avoid this waste of time by trying to guess whether the conditional jump is most likely to be taken or not taken. The branch that is guessed to be the most likely is then fetched and speculatively executed. If it is later detected that the guess was wrong, then the speculatively executed or partially executed instructions are discarded and the pipeline starts over with the correct branch, incurring a delay.

Implementation

Static branch prediction

Static prediction makes the same prediction for a given branch every time, based on heuristics — for example, predicting that backward branches (loops) are taken and forward branches are not, or using hints encoded by the compiler in the instruction stream.

Dynamic branch prediction

Dynamic predictors learn the behaviour of branches at run time. The simplest form is a one-bit saturating counter that records the last outcome of the branch; a two-bit counter is more tolerant of occasional exceptions. More sophisticated schemes include local history predictors, which track the recent outcomes of an individual branch, and global history predictors, which correlate the outcome of a branch with the outcomes of recently executed branches elsewhere in the program. Tournament predictors combine several predictors and choose between them.

Branch target prediction

A branch target buffer (BTB) caches the destination addresses of recently taken branches so that the processor can begin fetching from the target before the branch instruction itself has been fully decoded.

History

Branch prediction has been an important feature of high-performance processors since the early 1960s, when the IBM 7030 Stretch employed a form of it. The technique became widespread in the 1990s as pipelines deepened, and modern processors employ highly sophisticated multi-level predictors. In 2018, speculative execution — the mechanism branch prediction relies on — was shown to leak information across security boundaries in the Spectre vulnerabilities, prompting significant mitigations in hardware and software design.
