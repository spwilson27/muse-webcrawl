Las Vegas algorithm

In computing, a Las Vegas algorithm is a randomized algorithm that always gives correct results; that is, it always produces the correct result or informs about the failure. In other words, a Las Vegas algorithm does not gamble with the veracity of the result; it gambles only with the computational resources used for the computation (typically the running time).

Definition and examples

The archetypal example is randomized quicksort, in which pivots are chosen at random: the output is always correctly sorted, but the running time is a random variable, analyzed through its expected value. A Las Vegas algorithm is required to halt with positive probability and to have finite expected running time. Any Las Vegas algorithm can be converted into a Monte Carlo algorithm (which has fixed running time but may err) by stopping it after a suitable number of steps.

History and complexity

The terminology was introduced by László Babai in 1979, alongside the contrasting Monte Carlo algorithms, when defining complexity classes of randomized algorithms. Relevant complexity classes include ZPP (zero-error probabilistic polynomial time), the class of problems solvable by Las Vegas algorithms in expected polynomial time, which equals RP ∩ co-RP. Las Vegas algorithms are widely used in randomized incremental constructions in computational geometry, hashing (e.g., perfect hashing schemes), and identity checking.
