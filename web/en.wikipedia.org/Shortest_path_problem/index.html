In graph theory, the shortest path problem is the problem of finding a path between two vertices (or nodes) in a graph such that the sum of the weights of its constituent edges is minimized. The problem of finding the shortest path between two intersections on a road map may be modeled as a special case of the shortest path problem in graphs, where the vertices correspond to intersections and the edges correspond to road segments, each weighted by the length of the segment.

The shortest path problem can be defined for graphs whether undirected, directed, or mixed. It is defined here for undirected graphs; for directed graphs the definition of path requires that consecutive vertices be connected by an appropriate directed edge.

Definition

The shortest path problem can be defined either for graphs with weighted edges or for unweighted graphs. In the unweighted case, the goal is to minimize the number of edges traversed. More generally, each edge is assigned a real-valued weight, and the weight of a path is the sum of the weights of its edges. A shortest path between two vertices s and t is a path from s to t whose weight is minimum among all s–t paths. Problems in this family include the single-source shortest path problem, the single-destination problem, and the all-pairs shortest path problem.

Algorithms

The most important algorithms for solving the shortest path problem are:

  • Dijkstra's algorithm, which solves the single-source problem for graphs with nonnegative edge weights, producing a shortest-path tree.
  • The Bellman–Ford algorithm, which solves the single-source problem in the general case in which edge weights may be negative. It can also detect negative-weight cycles.
  • The Floyd–Warshall algorithm, which solves the all-pairs problem by dynamic programming.
  • Johnson's algorithm, which solves the all-pairs problem more efficiently on sparse graphs by combining Bellman–Ford and Dijkstra.
  • The A* search algorithm, which solves the single-pair problem using heuristics to speed up the search.
  • Breadth-first search, which solves the problem for unweighted graphs.

Applications

Shortest path algorithms are applied to automatically find directions between physical locations, such as driving directions on web mapping websites. In computer networking, they underpin routing protocols such as OSPF, which is based on Dijkstra's algorithm. Variants of the problem also model problems in operations research, robotics, transportation engineering, and VLSI design, where a "path" may be a sequence of decisions rather than a physical route.

Generalizations and related problems

Related problems include the traveling salesman problem, which asks for the shortest path that visits every vertex; the K shortest path problem, which asks for the K shortest paths between two vertices; and the widest path problem, which maximizes the capacity of the minimum-capacity edge along a path. In stochastic or time-dependent networks, edge weights may vary with time or with probability, giving rise to further generalizations used in transportation science.
