Computer memory

Computer memory is the hardware that stores information for immediate use in a computer. It is a fundamental component of all modern computers, working together with the central processing unit (CPU).

Types

  • Primary storage / main memory — volatile random-access memory (RAM), principally DRAM, which the CPU can access directly and which loses its contents when power is removed. SRAM is used for CPU caches.
  • Read-only memory (ROM) — non-volatile firmware storage.
  • Secondary storage — hard disks and solid-state drives, slower but persistent; sometimes grouped with storage rather than memory proper.

Hierarchy

Memory systems are organised in a hierarchy trading speed against cost per bit: registers and cache are fastest and smallest, followed by main memory, then mass storage. Virtual memory extends main memory onto disk, allowing programs to use more memory than is physically installed.
