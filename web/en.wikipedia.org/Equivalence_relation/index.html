Equivalence relation

In mathematics, an equivalence relation is a binary relation that is reflexive, symmetric and transitive. The equipollence relation between line segments in geometry is a common example; equality of numbers is the prototypical example of an equivalence relation.

Definition

A binary relation ~ on a set X is an equivalence relation if, for all a, b, c in X: (i) a ~ a (reflexivity); (ii) if a ~ b then b ~ a (symmetry); (iii) if a ~ b and b ~ c then a ~ c (transitivity).

Equivalence classes

The equivalence class of an element a is the set [a] = {x in X : x ~ a}. The equivalence classes of any equivalence relation partition the set into disjoint, non-empty subsets whose union is the whole set; conversely, every partition defines an equivalence relation. The set of all equivalence classes is called the quotient set.

Examples

Examples include congruence modulo n on the integers, similarity of triangles, having the same birthday, and the relation "is parallel to" on lines in the plane. Relations that are reflexive and symmetric but not transitive, such as "differs by at most one", are not equivalence relations.
