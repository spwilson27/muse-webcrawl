Linked data

In computing, linked data is structured data interlinked with other data so it becomes more useful through semantic queries. Tim Berners-Lee outlined its principles in 2006: use URIs as names, use HTTP URIs so they can be looked up, provide useful information in standards such as RDF and SPARQL, and include links to other URIs.

The Linked Open Data cloud includes datasets such as DBpedia, Wikidata, GeoNames and library and government data published under these principles, forming part of the Semantic Web.
