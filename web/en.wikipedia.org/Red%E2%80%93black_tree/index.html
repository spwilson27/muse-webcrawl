Red–black tree

A red–black tree is a self-balancing binary search tree data structure in which each node stores an extra bit representing its colour, either red or black. By constraining the colours along any root-to-leaf path, the structure guarantees that no such path is more than twice as long as any other, keeping the tree approximately balanced and operations efficient.

Properties

Every red–black tree satisfies: each node is red or black; the root is black; every leaf (null node) is black; a red node's children are both black; and every path from a node to its descendant leaves contains the same number of black nodes. These rules ensure the tree's height is O(log n).

Operations

Search runs in O(log n) time as in an ordinary binary search tree. Insertion and deletion use recolouring and rotations to restore the colour properties, also in O(log n) time.

History and uses

The structure was invented in 1972 by Rudolf Bayer as the "symmetric binary B-tree" and given its modern name and form by Leonidas Guibas and Robert Sedgewick in 1978. Red–black trees underlie associative containers in many libraries, such as C++'s std::map and Java's TreeMap.
