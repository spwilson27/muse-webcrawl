Windows Metafile

Filename extensions.wmf, .emf, .emz
Developed byMicrosoft
Type of formatVector graphics / image file format

Windows Metafile (WMF) is an image file format originally designed for Microsoft Windows in the 1990s. Files contain a sequence of Graphics Device Interface (GDI) function calls that Windows can play back to recreate a vector image, and may also embed bitmap data. The 32-bit enhanced version, Enhanced Metafile (EMF), added device independence and remains common in printing pipelines.

Structure

A WMF file consists of records, each describing a drawing operation such as lines, polygons, text, and filled regions, along with GDI objects like pens, brushes, and fonts. Because the format stores drawing commands rather than pixels, images scale without loss of quality. EMF files add a descriptive header, support for 32-bit coordinates, and features such as Bézier curves and embedded comments.

Security issues

The format became notorious in 2005–2006 after the discovery of the WMF vulnerability, in which specially crafted files could execute arbitrary code through a GDI feature for aborting print jobs (SETABORTPROC). The flaw affected many Windows versions before Microsoft issued an official patch in January 2006. Metafile support in browsers and mail clients has since been restricted.
