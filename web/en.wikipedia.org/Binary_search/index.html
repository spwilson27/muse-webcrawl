Binary search

In computer science, binary search, also known as half-interval search, logarithmic search, or binary chop, is a search algorithm that finds the position of a target value within a sorted array. Binary search compares the target value to the middle element of the array. If they are not equal, the half in which the target cannot lie is eliminated and the search continues on the remaining half, again taking the middle element to compare to the target value, and repeating this until the target value is found. If the search ends with the remaining half being empty, the target is not in the array.

Performance

Binary search runs in logarithmic time in the worst case, making O(log n) comparisons, where n is the number of elements in the array. It is much faster than linear search for large arrays, though the array must be sorted and must support random access. Binary search uses constant (O(1)) additional space in its iterative form.

Procedure

Given an array A of n elements with values sorted in ascending order and a target value T, the algorithm maintains low and high indices bounding the candidate interval. At each step it computes the midpoint m and compares A[m] with T: if equal, the search succeeds; if A[m] < T the search continues in the upper half; if A[m] > T it continues in the lower half. The interval halves at every step.

History and pitfalls

The idea of binary search is ancient — a form of it appears in Babylonian tablets — but it was first published in its modern form by Hermann Bottenbruch in 1962. Famously, correct implementations are subtle: a bug in the midpoint calculation (overflow of (low + high) / 2) survived for years in widely used library code, including Java's Arrays.binarySearch, as noted by Joshua Bloch in 2006.

Applications

Beyond searching sorted arrays, binary search underlies B-trees and binary search trees, numerical root-finding by bisection, debugging by bisection (as in "git bisect"), and searching on the answer in optimisation problems where a predicate is monotone.
