R (programming language)

R
Paradigm: Multi-paradigm (functional, object-oriented)
Designed by: Ross Ihaka and Robert Gentleman
First released: August 1993
License: GNU GPL

R is a programming language and free software environment for statistical computing and data visualization. It was created by statisticians Ross Ihaka and Robert Gentleman at the University of Auckland, New Zealand, and is developed by the R Development Core Team. R is an implementation of the S language combined with lexical scoping semantics inspired by Scheme.

Features

R provides a wide variety of statistical techniques — linear and nonlinear modelling, classical statistical tests, time-series analysis, classification, and clustering — together with strong graphical capabilities. It is highly extensible through packages: the Comprehensive R Archive Network (CRAN) hosts tens of thousands of contributed packages, and the tidyverse collection is widely used for data science workflows.

Usage

R is used by statisticians, data scientists, and researchers in academia and industry, and is supported by the integrated development environment RStudio (Posit). It interfaces with compiled languages such as C, C++, and Fortran for performance-critical code.
