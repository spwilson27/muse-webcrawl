Gauss–Jordan elimination

In linear algebra, Gauss–Jordan elimination is an algorithm for solving systems of linear equations. It extends Gaussian elimination by continuing the process until the coefficient matrix is in reduced row echelon form, at which point the solutions can be read off directly without back-substitution. The method is named after Carl Friedrich Gauss and Wilhelm Jordan.

Procedure

The system is first written as an augmented matrix. Using the three elementary row operations — swapping two rows, multiplying a row by a non-zero constant, and adding a multiple of one row to another — the algorithm proceeds column by column:

  1. Choose a non-zero pivot in the current column and swap it into the pivot row if necessary.
  2. Scale the pivot row so the pivot becomes 1.
  3. Eliminate the pivot variable from all other rows (above and below), not only those below as in Gaussian elimination.
  4. Move to the next column and repeat.

The result is the reduced row echelon form: each pivot is 1, each pivot is the only non-zero entry in its column, and pivots step down and to the right.

Applications

Besides solving linear systems, Gauss–Jordan elimination applied to a matrix augmented with the identity matrix yields the matrix inverse (when it exists). The row echelon forms it produces also reveal the rank of a matrix and the consistency of a system.

History and complexity

Elimination methods appear in the ancient Chinese text The Nine Chapters on the Mathematical Art. Gauss used elimination in least-squares work, and Wilhelm Jordan presented the fully reduced variant in an 1888 geodesy handbook. For an n × n system the algorithm performs on the order of n³ arithmetic operations; while slightly more work than Gaussian elimination followed by back-substitution, it is simple, systematic and widely taught.
