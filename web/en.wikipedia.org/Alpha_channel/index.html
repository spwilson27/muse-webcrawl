Alpha channel

The alpha channel is a colour component that represents the degree of transparency (or opacity) of a colour — its red, green and blue channels combined. It is used in image compositing to store selection masks and transparency information, as in RGBA colour models.

Alpha channel
Concept: Ed Catmull & Alvy Ray Smith, late 1970s
Term coined: 1982, Alvy Ray Smith
Models: Straight vs premultiplied alpha

Compositing

Using the "over" operator of Porter and Duff (1984), a foreground pixel with alpha α is blended over a background as C = Cfα + Cb(1−α). Alpha values range from 0 (fully transparent) to 1 (fully opaque). PNG, TIFF, TGA, WebP and many video codecs store an alpha channel.

Premultiplied alpha

In premultiplied (associated) alpha, RGB values are stored already multiplied by alpha, which simplifies and speeds compositing and avoids colour fringing when filtering, at the cost of losing original colour data in fully transparent pixels. Straight (unassociated) alpha keeps colour independent of opacity, as in PNG.

Applications

Alpha channels underpin image editing layers, game sprites, video overlays and lower-thirds, user-interface translucency, and anti-aliased text rendering.
