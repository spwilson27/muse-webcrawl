Fuzzy cognitive map

A fuzzy cognitive map (FCM) is a cognitive map in which the relations between the elements of a mental landscape can be modelled as a signed, weighted directed graph, allowing causal relationships to take fuzzy values between −1 and +1. FCMs were introduced by Bart Kosko in 1986, extending Robert Axelrod's cognitive maps with fuzzy logic.

Model

Concepts are nodes with activation values; edges encode how strongly one concept increases or decreases another. The map is simulated by repeatedly updating node values through the weight matrix with a squashing function, until the system settles into a fixed point, limit cycle, or chaotic attractor, representing the modelled system's predicted behaviour.

Applications

FCMs have been applied to decision support, policy and ecosystem modelling, medical diagnosis, engineering control, and scenario analysis, because they can combine expert knowledge qualitatively while still permitting quantitative simulation. Learning algorithms — Hebbian, genetic, and swarm methods — can tune the weights from data.
