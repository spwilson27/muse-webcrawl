Visual programming language

Programming by connecting blocks in Scratch

Examples: Scratch, LabVIEW, Max/MSP, Simulink, Blockly

A visual programming language (VPL) is any programming language that lets users create programs by manipulating program elements graphically rather than by specifying them textually. A VPL allows programming with visual expressions, spatial arrangements of text and graphic symbols, used either as elements of syntax or as secondary notation.

Types

Visual languages take several forms. Block-based languages such as Scratch and Blockly snap together puzzle-like blocks representing statements and expressions, making them popular in education. Dataflow languages such as LabVIEW, Max/MSP, and Simulink represent programs as graphs of nodes connected by wires carrying data. Form-based and diagrammatic languages derive programs from spreadsheets, flowcharts, or state diagrams.

Advantages and limitations

Visual languages lower the barrier to entry for beginners, make program structure explicit, and can eliminate syntax errors. Critics note that visual programs can become unwieldy at scale ("spaghetti" diagrams), are harder to search, diff, and version-control than text, and may lack the abstraction power of textual languages. Many professional tools combine both paradigms.
