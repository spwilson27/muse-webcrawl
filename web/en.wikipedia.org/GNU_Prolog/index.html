GNU Prolog (also called gprolog) is a Prolog compiler, with an interactive debugging environment, developed by Daniel Diaz. It is a free and open-source implementation published under the GNU General Public License and the GNU Lesser General Public License. Unlike many Prolog interpreters, GNU Prolog compiles Prolog to native machine code using a Warren Abstract Machine (WAM) based compiler, producing fast executables.

Features

GNU Prolog includes a constraint solver over finite domains (FD), with predefined constraints and heuristics, making it useful for constraint logic programming. It provides a low-level interface to C, a definite clause grammar system, and built-in predicates largely following the ISO Prolog standard. It runs on many platforms, including Unix-like systems, macOS, and Windows.

History

Development began with the wamcc compiler in the mid-1990s; version 1.0 was released in 1999. The system grew out of research at the University of Paris 1 Panthéon-Sorbonne. Version 1.5.0, released in 2021, remains a commonly used stable release.
