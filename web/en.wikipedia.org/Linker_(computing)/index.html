Linker (computing)

Linker
Other names: link editor
Function: combines object files into an executable, library or another object file

In computing, a linker or link editor is a computer program that takes one or more object files (generated by a compiler or assembler) and combines them into a single executable file, library file, or another object file. The linker resolves references between modules — symbols — and arranges code and data in the output, a process called linking.

Static and dynamic linking

In static linking, all library code used by a program is copied into the executable at link time. In dynamic linking, references to shared libraries are resolved at load time or run time by a dynamic linker/loader, reducing executable size and allowing library updates without recompiling. Most modern operating systems support both.

Tasks

A linker performs symbol resolution, relocation (assigning final addresses and adjusting references), and, in sophisticated implementations, optimisations such as dead-code elimination and link-time optimisation (LTO). Well-known linkers include GNU ld, gold, LLVM's LLD and the Microsoft link editor.
