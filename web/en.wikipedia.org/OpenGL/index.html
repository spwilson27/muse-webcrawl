OpenGL

OpenGL (Open Graphics Library) is a cross-language, cross-platform application programming interface (API) for rendering 2D and 3D vector graphics. It interacts with a graphics processing unit (GPU) to achieve hardware-accelerated rendering.

OpenGL was developed by Silicon Graphics Inc. (SGI) and released in 1992, evolving from SGI's IRIS GL. It is managed by the non-profit Khronos Group, which also oversees Vulkan, OpenGL's lower-overhead successor. Implementations exist on Windows, Linux, macOS (deprecated at version 4.1), and embedded systems via OpenGL ES for mobile and web-adjacent platforms; WebGL brings similar concepts to browsers.

Design

OpenGL is a state machine API: applications set state, define buffers of vertices, and issue draw calls processed through a programmable pipeline with vertex and fragment shaders written in GLSL. Extensions allow vendors to expose new hardware features.
