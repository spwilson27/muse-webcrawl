Widget toolkit

A widget toolkit, widget library or GUI toolkit is a library or collection of libraries containing a set of graphical control elements (widgets) — buttons, menus, scroll bars, dialog boxes and text fields — used to construct the graphical user interface (GUI) of programs.

Characteristics

Toolkits abstract over the underlying windowing system, handle event loops and drawing, and often provide layout management and theming so applications share a consistent look and feel. Some toolkits wrap the operating system's native widgets, while others draw their own controls for cross-platform consistency.

Examples

Major toolkits include GTK and Qt (cross-platform), the Windows API and Windows Presentation Foundation on Windows, Cocoa/AppKit and SwiftUI on Apple platforms, and the Java toolkits AWT, Swing and JavaFX. Web interface libraries such as React provide component models sometimes described in similar terms. Historical toolkits include Motif, Tk and wxWidgets (a cross-platform wrapper of native controls).
