Color model

A color model is an abstract mathematical model describing the way colors can be represented as tuples of numbers, typically as three or four values or color components. When this model is associated with a precise description of how the components are to be interpreted, taking account of visual perception, the resulting set of colors is called a color space.

Additive and subtractive models

The RGB model is additive: red, green, and blue light combine to make white, and underlies displays. The CMY/CMYK model is subtractive, used in printing, where cyan, magenta, yellow (and black key) inks absorb light. RYB is a historical model used in traditional art education.

Perceptual models

HSV and HSL represent colors by hue, saturation, and value/lightness, matching intuitive selection. CIE XYZ (1931) and CIELAB model human vision and allow device-independent specification.

Applications

Color models structure image file formats, video encoding (YCbCr), paint mixing, and printing workflows, with conversions managed by color management systems and ICC profiles.
