Non-linear least squares

From Wikipedia, the free encyclopedia

Non-linear least squares is a form of least squares analysis used to fit a set of observations with a model that is non-linear in its parameters. The objective is to find the parameter values that minimise the sum of the squares of the residuals — the differences between observed values and those predicted by the model. Unlike linear least squares, which has a closed-form solution, non-linear problems are solved iteratively.

Algorithms

The Gauss–Newton algorithm linearises the model about the current parameter estimates and solves the resulting linear least squares problem at each step. The Levenberg–Marquardt algorithm interpolates between Gauss–Newton and gradient descent, adding a damping term that improves behaviour far from the minimum. Both methods require, or numerically approximate, the Jacobian matrix of partial derivatives of the residuals with respect to the parameters.

Considerations

Convergence depends on good starting values; poor initial guesses can lead to divergence or to local rather than global minima. Approximate standard errors for the fitted parameters are obtained from the Jacobian at the solution, in analogy with the linear case. Weighted versions of the problem are used when observations have unequal variances.

Applications

Non-linear least squares is widely used in curve fitting for kinetics, pharmacology, spectroscopy, econometrics, and the calibration of physical models.
