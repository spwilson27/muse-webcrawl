Server (computing)

From Wikipedia, the free encyclopedia

RoleProvides services to client programs
Form factorsRack, tower, blade, mainframe
ExamplesWeb, mail, file, database servers

In computing, a server is a computer program or device that provides functionality for other programs or devices, called clients. This architecture is called the client–server model. Servers can provide various functionalities, often called services, such as sharing data or resources among multiple clients, or performing computation for a client.

At the high end of the server spectrum sit mainframes such as IBM Z, which function as servers of exceptional reliability and throughput for banking, insurance, and government workloads, running operating systems such as z/OS alongside Linux on Z. A single IBM Z system can host thousands of virtualized server instances within logical partitions (LPARs) while maintaining extremely high availability.

Hardware

Server hardware emphasizes reliability, availability, and serviceability: redundant power supplies, error-correcting memory, hot-swappable components, and remote management processors are standard. Servers range from small tower units for offices to rack-mounted and blade systems in data centers, up to mainframe-class systems. Historically, departmental servers evolved from minicomputers, whose multi-user role they inherited.

Operating systems

Server operating systems include Linux distributions, Windows Server, Unix variants, and mainframe systems such as z/OS and z/VM. They are optimized for long uptimes, network throughput, and running services unattended.
