Unix filesystem

The Unix filesystem is the hierarchical method Unix and Unix-like operating systems use to organise files and directories. It presents a single tree rooted at /, with devices, processes and network resources often represented as files.

Structure

Standard directories include /bin for essential binaries, /etc for configuration, /home for user directories, /var for variable data and /usr for user programs and libraries.

Inodes

Metadata is stored in inodes, which record permissions, ownership, size and data block locations but not the file name.

Philosophy

The design reflects the Unix principle that 'everything is a file', simplifying tools that operate uniformly on diverse resources.
