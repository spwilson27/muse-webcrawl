SpiderMonkey

SpiderMonkey is an open-source JavaScript and WebAssembly engine, written primarily in C++ with some Rust, used in Mozilla Firefox and other products. It is the first JavaScript engine ever written, created by Brendan Eich at Netscape Communications in 1995 for the Netscape Navigator web browser.

History

Eich "wrote JavaScript in ten days" in 1995; the code that would become SpiderMonkey was released as open source when Netscape freed the Navigator code base in 1998. The name refers to the spider monkey, a New World primate, and was chosen in keeping with other Mozilla animal-themed project names.

Features

SpiderMonkey implements ECMAScript and includes a just-in-time (JIT) compilation pipeline. Successive optimizing compilers have included TraceMonkey (2008), JaegerMonkey (2010), IonMonkey (2012), and Warp (2020), each improving performance. SpiderMonkey supports the JavaScript shell, embedding in C++ applications, and is used in projects such as GNOME Shell, CouchDB, and MongoDB (historically).
