Neuropsychological test

Neuropsychological assessment uses standardized tasks to measure cognitive domains.

Neuropsychological tests are specifically designed tasks that are used to measure a psychological function known to be linked to a particular brain structure or pathway. Tests are used for research into brain function and in a clinical setting for the diagnosis of deficits. They usually involve the systematic administration of clearly defined procedures in a formal environment, and scores are compared against normative data matched for age and education.

Domains and common tests

Assessment spans general intelligence (Wechsler scales such as the WAIS), memory (Wechsler Memory Scale, Rey Auditory Verbal Learning Test, Rey–Osterrieth complex figure), language (Boston Naming Test), visuospatial function, attention (Trail Making Test, Stroop test), and executive function (Wisconsin Card Sorting Test, verbal fluency). Brief screening instruments include the Mini-Mental State Examination and the Montreal Cognitive Assessment (MoCA).

Uses

Clinicians use neuropsychological profiles to diagnose and differentiate conditions such as neurodegenerative diseases, traumatic brain injury, stroke, epilepsy, and psychiatric disorders; to plan rehabilitation and surgery (e.g., pre-surgical mapping in epilepsy); and to track change over time. In forensic settings, performance validity tests assess whether examinees are exerting adequate effort.

Limitations

Scores are influenced by education, culture, language, mood, and effort, and no single test localizes a lesion by itself; interpretation integrates test patterns with history, imaging, and observation. Alexander Luria's qualitative approach and the process approach developed by Edith Kaplan emphasize how a task is performed, not only the final score.
