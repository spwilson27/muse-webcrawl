Ethernet VPN

Ethernet VPN (EVPN)
StandardRFC 7432 (BGP MPLS-Based EVPN)
LayerLayer 2 / Layer 3 overlay
Control planeMP-BGP

Ethernet VPN (EVPN) is a technology for carrying Layer 2 Ethernet traffic as a virtual private network using wide-area network protocols. Standardised by the IETF in RFC 7432 (2015), EVPN uses Multiprotocol BGP (MP-BGP) as its control plane to distribute MAC and IP address reachability information among provider edge devices.

How it works

Unlike older VPLS designs that learned MAC addresses in the data plane through flooding, EVPN routers advertise MAC/IP binding routes in BGP. This enables active-active multi-homing of customer sites, fast convergence through mass-withdraw messages, aliasing for load balancing, and suppression of ARP flooding. EVPN can run over MPLS or, in data-centre deployments, over VXLAN tunnels (EVPN-VXLAN, RFC 8365).

Applications

EVPN is widely used for data centre interconnect, scalable leaf–spine fabrics, and as a unified control plane providing both bridged (L2) and routed (L3, via Integrated Routing and Bridging) services over the same infrastructure.
