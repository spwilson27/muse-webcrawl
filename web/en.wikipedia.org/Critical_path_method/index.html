Critical path method

The critical path method (CPM), or critical path analysis, is an algorithm for scheduling a set of project activities. Developed in the late 1950s by Morgan R. Walker of DuPont and James E. Kelley Jr. of Remington Rand, it identifies the longest sequence of dependent activities — the critical path — which determines the shortest possible duration of the whole project. Any delay to an activity on the critical path directly delays the project's completion.

Technique

The method begins by listing all activities required to complete the project, the time each will take, and the dependencies between them. Activities are drawn as a network diagram of nodes and arrows. A forward pass computes the earliest start and finish times; a backward pass computes the latest start and finish times. The difference between them for each activity is its float (or slack). Activities with zero float lie on the critical path.

Uses

CPM is widely used in construction, engineering, software development, and manufacturing. Project managers use it to decide where to allocate resources, to evaluate the effect of schedule changes, and to apply "crashing" — adding resources to shorten critical activities. It is closely related to the Program Evaluation and Review Technique (PERT), developed for the U.S. Navy's Polaris programme, which adds probabilistic duration estimates.
