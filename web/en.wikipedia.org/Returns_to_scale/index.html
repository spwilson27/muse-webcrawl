Returns to scale

In economics, returns to scale describe what happens to long-run returns as the scale of production increases, when all input levels including physical capital usage are variable. The concept of returns to scale arises in the context of a firm's production function. It explains the long-run linkage of the output rate with the input rates.

Increasing, constant and decreasing returns to scale

There are three possible types of returns to scale:

  • Increasing returns to scale (IRS): output increases by more than the proportional change in inputs. For example, doubling all inputs more than doubles output.
  • Constant returns to scale (CRS): output increases by exactly the same proportion as inputs.
  • Decreasing returns to scale (DRS): output increases by less than the proportional change in inputs.

Formal definitions

Formally, for a production function F(K, L) with capital K and labour L, returns to scale are determined by comparing F(λK, λL) with λF(K, L) for a scaling factor λ > 1. If the scaled output exceeds λF, returns are increasing; if it equals λF, constant; if it is less, decreasing. A Cobb–Douglas production function Y = AKαLβ exhibits increasing returns when α + β > 1, constant returns when α + β = 1, and decreasing returns when α + β < 1.

Returns to scale and economies of scale

Returns to scale are related to, but distinct from, economies of scale. Returns to scale is a purely technical property of the production function, describing the relation between physical inputs and output. Economies of scale concern the cost per unit of output as scale rises, and include effects such as input price changes when a firm purchases in bulk. A firm can have increasing returns to scale without enjoying falling average costs if input prices rise, and vice versa.

Causes

Increasing returns may arise from specialisation and division of labour, indivisibilities in capital equipment, and geometric factors (such as the greater volume-to-surface ratio of larger containers). Decreasing returns may arise from managerial and coordination difficulties as organisations become very large. Returns to scale are a long-run concept, applying when all inputs can be varied, in contrast to the law of diminishing marginal returns, which is a short-run concept with at least one fixed input.
