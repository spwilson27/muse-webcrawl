Working directory

Image placeholder: Terminal showing a current working directory

In computing, the working directory of a process is a directory of a hierarchical file system, if any, dynamically associated with the process. It is sometimes called the current working directory (CWD) or simply current directory.

Behavior

When a process refers to a file using a simple file name or relative path, the reference is interpreted relative to the process's working directory. Each process maintains its own working directory, inherited from its parent process and changeable with system calls such as POSIX chdir(). In Unix shells, the cd command changes the shell's working directory and pwd prints it.

Real-life example

If a user logs in and works in a home directory, then navigates into a subdirectory, all relative file operations in that session resolve against the new directory.
