Boolean expression

A Boolean expression is an expression used in programming languages and logic that produces a Boolean value — either true or false — when evaluated. The concept is named after George Boole, whose algebraic system of logic underlies Boolean algebra.

Composition

Boolean expressions are built from Boolean operands (variables, constants, or comparisons) combined with logical operators: AND (conjunction), OR (disjunction), and NOT (negation). Relational operators such as ==, !=, <, and >= produce Boolean results from non-Boolean data; for example, x > 5 && y < 10 is true only when both comparisons hold.

Evaluation

Most languages evaluate Boolean expressions with operator precedence (NOT before AND before OR) and short-circuit evaluation: in A && B, if A is false, B is never evaluated, which programmers exploit for guard conditions. Truth tables enumerate the value of an expression for every combination of inputs, and expressions can be simplified using the laws of Boolean algebra, such as De Morgan's laws.

Uses

Boolean expressions control program flow in conditionals (if) and loops (while), filter database and search queries, and describe the logic of digital circuits, where they are implemented by combinations of logic gates.
