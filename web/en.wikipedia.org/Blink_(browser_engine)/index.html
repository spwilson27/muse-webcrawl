Blink (browser engine)

Blink is a browser engine developed as part of the Chromium project by Google and other contributors. It is a fork of the WebCore component of the WebKit engine, which was itself a fork of KHTML. Blink is used in Google Chrome, Microsoft Edge (since 2020), Opera, Brave, Vivaldi, and many other Chromium-based browsers, making it the most widely used browser rendering engine in the world.

History

Google announced Blink in April 2013, citing the architectural divergence between Chrome's multiprocess design and other WebKit ports. Early changes simplified the codebase by removing large amounts of unused code and ports. In 2017 Google announced plans to merge iOS Chrome's rendering with Blink as well. The name Blink is a reference to the deprecated non-standard HTML <blink> element.

Architecture

Blink implements the Document Object Model, CSS layout and painting, and works with the V8 JavaScript engine. It differs from WebKit in its multiprocess architecture, sandboxing, and its incremental adoption of new web standards, including early implementations of features later standardized across engines.

Market position

Because Chromium-based browsers dominate desktop and Android usage, Blink's behavior strongly influences how web standards evolve, a position that has prompted debate about engine diversity and the health of the open web.
