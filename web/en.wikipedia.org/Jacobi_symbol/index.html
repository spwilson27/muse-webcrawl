Jacobi symbol

The Jacobi symbol is a generalisation of the Legendre symbol in number theory, introduced by Carl Gustav Jacob Jacobi in 1846. While the Legendre symbol is defined for an odd prime modulus, the Jacobi symbol is defined for any positive odd integer modulus, as the product of the Legendre symbols corresponding to the prime factorisation of the modulus.

Definition

For an integer a and a positive odd integer n with prime factorisation n = p₁p₂…pₖ, the Jacobi symbol (a/n) equals the product of the Legendre symbols (a/pᵢ). It takes values in {−1, 0, 1}: it is 0 if gcd(a, n) > 1, and otherwise ±1.

Properties

The Jacobi symbol is completely multiplicative in both arguments and satisfies supplements for the numerators 2 and −1, together with a law of quadratic reciprocity closely analogous to that for the Legendre symbol. These properties allow it to be computed efficiently, using an algorithm similar to the Euclidean algorithm, without factoring the modulus. However, unlike the Legendre symbol, (a/n) = 1 does not imply that a is a quadratic residue modulo composite n.

Applications

Computing Jacobi symbols efficiently is essential in primality testing — the Solovay–Strassen test compares a Jacobi symbol with Euler's criterion — and in cryptographic algorithms such as the Goldwasser–Micali cryptosystem, whose security rests on the difficulty of quadratic residuosity for composite moduli.
