Interpretation (logic)

An interpretation is an assignment of meaning to the symbols of a formal language. Many formal languages used in mathematics, logic and computer science are defined purely syntactically, and an interpretation gives them semantics: it specifies a domain of discourse and assigns to each constant symbol an object in the domain, to each predicate symbol a relation, and to each function symbol a function.

Formal languages

For a first-order language, an interpretation (also called a structure or model, in a related sense) consists of a non-empty set D, the domain (or universe), together with an interpretation function that maps constant symbols to elements of D, n-ary function symbols to functions on D, and n-ary predicate symbols to relations on D. Under Tarski's definition of truth, a sentence is true in an interpretation when it is satisfied under that assignment of meaning.

Models

An interpretation in which a given sentence (or set of sentences) is true is called a model of that sentence or theory. The study of interpretations is central to model theory. For example, the axioms of arithmetic have the natural numbers as their intended interpretation, but also admit non-standard models; and Tarski's undefinability theorem and the Löwenheim–Skolem theorem are results about the interpretations of formal theories.

Intended interpretations

Formal theories are usually designed with a particular interpretation in mind — the intended or standard interpretation. A sentence that is true in the intended interpretation but unprovable in the theory illustrates the incompleteness phenomena established by Gödel.
