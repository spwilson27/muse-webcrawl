Edmonds–Karp algorithm

In computer science, the Edmonds–Karp algorithm is an implementation of the Ford–Fulkerson method for computing the maximum flow in a flow network. Published by Jack Edmonds and Richard Karp in 1972 (and independently by Yefim Dinitz in 1970), it differs from the general Ford–Fulkerson approach in that the augmenting path is always chosen as the shortest available path, found by breadth-first search, when path lengths are measured in the number of edges.

Algorithm

The algorithm repeatedly finds an augmenting path from source to sink in the residual graph using breadth-first search, computes the bottleneck capacity along that path, and augments the flow by that amount. The process terminates when no augmenting path remains, at which point the flow is maximum.

Complexity

Because each augmentation saturates at least one edge and shortest-path distances increase monotonically, the number of augmentations is bounded, giving a running time of O(VE²), which makes the algorithm strongly polynomial. This resolved the problem that naive Ford–Fulkerson implementations could run in time depending on the capacities, or even fail to terminate with irrational capacities.
