Document type declaration

A document type declaration, or DOCTYPE, is an instruction that associates a particular XML or SGML document with a document type definition (DTD). In HTML it appears at the very start of the document, before the root element, in the form <!DOCTYPE html>.

Purpose

Originally the declaration told parsers which DTD's rules the document followed, enabling validation. In web browsers, the DOCTYPE's practical role became switching between rendering modes: documents with a standards-compliant DOCTYPE are rendered in "standards mode", while those without, or with certain older declarations, trigger "quirks mode", emulating the buggy behaviour of 1990s browsers.

HTML5

HTML5 simplified the declaration to the minimal string <!DOCTYPE html>, which is not a reference to any DTD but simply ensures standards-mode rendering. It was deliberately chosen to be the shortest string that would trigger standards mode in all browsers of the era.
