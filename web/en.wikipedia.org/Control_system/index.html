Control system

A control system manages, commands, directs, or regulates the behavior of other devices or systems using control loops. It can range from a single home heating controller using a thermostat controlling a domestic boiler to large industrial control systems which are used for controlling processes or machines.

Open-loop and closed-loop control

In open-loop control, the controller acts without measuring the output — a simple timer switching a sprinkler is an example — so performance depends on accurate calibration and the absence of disturbances. Closed-loop or feedback control continuously measures the output with a sensor and adjusts the input to reduce the error between the measured value and the desired setpoint; the household thermostat and the cruise control of a car are everyday examples.

Control theory

Control engineering models systems with transfer functions, state-space equations and block diagrams, and analyses stability, transient response and robustness. Classical techniques include PID controllers (proportional–integral–derivative), root locus and frequency-response methods; modern control adds state feedback, observers and optimal control. Feedback can stabilize or, if poorly tuned, destabilize a system — the study of these trade-offs is a central theme of the field.

Applications

Control systems pervade industry and daily life: process control in chemical plants, autopilots and fly-by-wire aircraft, robotics, power-grid regulation, hard-disk and optical drives, and building climate systems. Programmable logic controllers (PLCs) and distributed control systems (DCS) implement them in factories, while biological control — homeostasis — offers natural analogues.
