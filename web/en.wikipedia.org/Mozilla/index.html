Mozilla is a free software community founded in 1998 by members of Netscape, which released the source code of its browser suite under an open-source license. The name — a portmanteau of "Mosaic killer" and "Godzilla" — was originally Netscape's internal codename for its browser. Today "Mozilla" refers to the project, the non-profit Mozilla Foundation (established 2003), and its taxable subsidiary the Mozilla Corporation (2005), which develops the Firefox web browser.

History

Losing the "browser wars" to Microsoft's Internet Explorer, Netscape opened its code in March 1998, creating mozilla.org. The rewritten browser engine, Gecko, powered the Mozilla Application Suite, from which the standalone Firefox browser (2004) and Thunderbird email client were spun out. Firefox rapidly gained market share, revived competition and web standards, and peaked at roughly 30% usage share around 2010 before Google Chrome took the lead. Mozilla's revenue has come chiefly from search-engine default placement deals, principally with Google.

Other work

Mozilla also develops the Rust programming language (transferred to the Rust Foundation in 2021), the MDN Web Docs documentation site, Firefox OS (discontinued), the Servo engine project, and advocacy for privacy, net neutrality and an open internet under the Mozilla Manifesto (2007). Its dinosaur mascot, designed by Dave Titus in 1994, remains a familiar emblem.
