Structure (mathematical logic)

In universal algebra and in model theory, a structure consists of a set along with a collection of finitary operations and relations that are defined on it. A structure for a signature σ consists of a set A (the domain, universe or carrier), together with, for each constant symbol in σ, a distinguished element of A; for each n-ary function symbol, an n-ary function on A; and for each n-ary relation symbol, an n-ary relation on A.

The archetypical example is the structure of fields: in the signature of rings (+, ·, −, 0, 1), a structure is a set equipped with interpretations making it a ring; the rational numbers, real numbers, and finite fields are all structures for this signature. In first-order logic, a structure interprets the non-logical symbols of a language, and a sentence is true in a structure — making the structure a model of the sentence — under the satisfaction relation defined by Tarski's inductive definition of truth.

Related notions

Structures are studied up to isomorphism and via maps such as homomorphisms and embeddings; substructures, reducts (forgetting some symbols), and expansions are standard constructions. The cardinality of the domain figures in the Löwenheim–Skolem theorem. In databases, a relational database instance can be viewed as a finite structure, and many query languages correspond to fragments of first-order logic over such structures.
