Hindley–Milner type system

A Hindley–Milner (HM) type system is a classical type system for the lambda calculus with parametric polymorphism, described by J. Roger Hindley (1969) and independently discovered by Robin Milner (1978). Its defining feature is complete type inference: a program written without any type annotations can be assigned the most general possible type (the principal type) automatically.

Type inference

The inference algorithm, known as Algorithm W (Milner), or Algorithm J (Damas), works by generating equations between type expressions containing unknowns (type variables) and solving them by unification. Because the principal type is always inferable, HM-typed languages can offer static type safety with almost no annotation burden.

Let-polymorphism

The system extends the simply typed lambda calculus with let-polymorphism: a value bound by a let expression may be given a polymorphic type scheme (universally quantified over type variables), so it can be used at several different types in the body. Polymorphism is restricted to let-bindings — lambda-bound variables remain monomorphic — which keeps inference decidable and complete.

Influence

The HM system underlies the type systems of the ML family of languages — Standard ML, OCaml, and Milner's original ML for the LCF theorem prover — as well as Haskell (with type classes extending the basic system), F#, and the inference engines of languages such as Scala, Rust, and Swift in adapted forms. Limitations, such as the difficulty of combining it with subtyping or mutable references (addressed in ML by the value restriction), have motivated many extensions studied in programming language theory.
