RSS
Web feed format
Really Simple Syndication
XML-based format for publishing frequently updated content

RSS (RDF Site Summary or Really Simple Syndication) is a web feed that allows users and applications to access updates to websites in a standardized, computer-readable format. Subscribing to RSS feeds allows a user to keep track of many different websites in a single news aggregator, which constantly monitors sites for new content, removing the need for the user to manually check them.

History

The first version of RSS, RDF Site Summary, was created by Guha and others at Netscape in March 1999 for use on the My.Netscape.Com portal. Dave Winer's competing "Really Simple Syndication" line evolved through RSS 0.91 and 0.92, culminating in RSS 2.0, released under a Creative Commons license from Harvard in 2003. A parallel effort produced the Atom syndication format, standardized by the IETF in 2005.

How it works

A website publishes an XML document — the RSS feed — listing recent items with titles, links, descriptions and publication dates. Feed readers and aggregators poll the file and present new items to subscribers. Podcasts are distributed by attaching audio files as enclosures in RSS items.

Usage

RSS underpinned the blogging ecosystem of the 2000s and remains widely used for podcasts, news distribution and software update channels, even as social media feeds displaced reader software for many consumers. Like RFID, it is a technology best known by its initials.
