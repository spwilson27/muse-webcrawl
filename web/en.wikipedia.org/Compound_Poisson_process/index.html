Compound Poisson process

A compound Poisson process is a stochastic process in which events occur according to a Poisson process and each event contributes a random amount. It is the sum of a Poisson-distributed number of independent, identically distributed random variables.

Properties

If events arrive at rate lambda and jump sizes have mean and variance, the process has independent increments, an expected value growing linearly in time, and a characteristic function expressible in terms of the jump distribution.

Applications

The process models aggregate insurance claims, rainfall totals, and queuing workloads — any setting where discrete events arrive randomly and each carries a random magnitude.
