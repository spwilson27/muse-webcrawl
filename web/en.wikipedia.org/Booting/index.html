Booting

From Wikipedia, the free encyclopedia

In computing, booting is the process of starting a computer as initiated via hardware such as a button or by a software command. After it is switched on, a computer's central processing unit (CPU) has no software in its main memory, so some process must load software into memory before it can be executed. This may be done by hardware or firmware in the CPU, or by a separate processor in the computer system.

The term is derived from "bootstrap," as in the idiom "pull oneself up by one's bootstraps": a small initial program loads progressively larger programs until the full operating system is running.

The boot sequence

When power is applied, the CPU begins executing firmware stored in read-only memory, traditionally the BIOS, and now usually UEFI firmware. The firmware performs a power-on self-test (POST), initializes hardware, and locates a boot device. It then loads a bootloader — historically from the master boot record (MBR) of a disk — which in turn loads the operating system kernel into memory and transfers control to it. Modern multi-stage bootloaders such as GRUB allow the user to choose among operating systems and kernel options.

History

Early computers required operators to toggle in a small loader program using front-panel switches, which then read a larger program from punched cards or paper tape. The introduction of read-only memory in the 1960s and 1970s automated the process. The IBM PC standardized the BIOS boot process in 1981, and UEFI gradually replaced legacy BIOS beginning in the 2000s, adding support for large disks, secure boot, and graphical setup.

Types of booting

  • Cold boot — starting the computer from a powered-off state.
  • Warm boot — restarting a running system, typically skipping parts of the POST.
  • Network boot — loading the operating system from a server via protocols such as PXE.
  • Secure boot — verifying cryptographic signatures of boot components before execution.
