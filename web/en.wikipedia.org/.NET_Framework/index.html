The .NET Framework (pronounced as "dot net") is a proprietary software framework developed by Microsoft that runs primarily on Microsoft Windows. It was the predominant implementation of the Common Language Infrastructure (CLI) until being superseded by the cross-platform .NET project. It includes a large class library called Framework Class Library (FCL) and provides language interoperability across several programming languages.

Programs written for .NET Framework execute in a software environment known as the Common Language Runtime (CLR), an application virtual machine that provides services such as security, memory management, and exception handling. The FCL provides user interface, data access, database connectivity, cryptography, network communications, and web application development.

History

Microsoft began developing .NET Framework in the late 1990s under the name of Next Generation Windows Services (NGWS). Version 1.0 was released on 13 February 2002 alongside Visual Studio .NET. Subsequent releases added generics (2.0, 2005), Windows Presentation Foundation and Windows Communication Foundation (3.0, 2006), LINQ (3.5, 2007), the Task Parallel Library (4.0, 2010), and async language features (4.5, 2012). The final version, 4.8.1, was released in August 2022; Microsoft has stated there will be no version 5 of .NET Framework, with development having moved to the unified .NET platform, though .NET Framework remains supported as a Windows component.

Architecture

The CLR manages the execution of .NET programs. Source code written in languages such as C#, Visual Basic .NET and F# is compiled to Common Intermediate Language (CIL), which is then compiled just-in-time to native machine code at run time. The CLR provides a garbage collector, a type system (the Common Type System), exception handling, and thread management. The Framework Class Library is a comprehensive collection of reusable types organised into namespaces such as System, System.IO, System.Net and System.Windows.Forms.

Design principles

The framework was designed around interoperability between languages, a common runtime engine, base class library reuse, simplified deployment (side-by-side versioning reducing "DLL Hell"), security through code-access permissions, and portability of compiled code. Its closed, Windows-only nature was widely criticised, leading first to the Mono project and later to Microsoft's own cross-platform .NET Core, which became .NET 5 and later.
