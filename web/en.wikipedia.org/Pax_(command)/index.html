pax (command)

pax is an archive utility available on various versions of the Unix operating system and many other operating system families, standardised by POSIX. Rather than having incompatible utilities such as tar and cpio, pax was created (as the name suggests, Latin for "peace") to read and write archives in multiple formats while copying files to different locations, functioning both as an archiver and, with its interactive rename capability, as a file copying tool.

History

The command was proposed in the late 1980s and included in POSIX.2 (IEEE Std 1003.2-1992) and the Single UNIX Specification. Its default archive format, an extended tar interchange format sometimes called "pax format" (IEEE 1003.1-2001), adds keyword attributes that allow long filenames, large files, and extended metadata, and was adopted by GNU tar and other archivers.

Usage

In write mode, pax -w creates an archive; in read mode, pax -r extracts one; in list mode it prints contents; and in copy mode it duplicates directory trees, combining the behaviours of tar and cpio. macOS historically used pax archives for installer packages.
