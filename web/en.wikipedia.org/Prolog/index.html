Prolog

ParadigmLogic programming, declarative
First appeared1972
Designed byAlain Colmerauer, Robert Kowalski, Philippe Roussel
TypingUntyped (single data type: term)

Prolog is a logic programming language associated with artificial intelligence and computational linguistics. It has its roots in first-order logic — a formal logic — and, unlike many other programming languages, Prolog is intended primarily as a declarative programming language: the program is composed of relations, represented as facts and rules. A computation is initiated by running a query over the relations. The name Prolog is short for Programmation en logique (French for "programming in logic").

History

Prolog was created around 1972 by Alain Colmerauer and Philippe Roussel, based on Robert Kowalski's procedural interpretation of Horn clauses. It was motivated partly by a desire to use logic as a knowledge representation language for natural language processing. The language was famously chosen as the core of the Japanese Fifth Generation Computer Systems project in the 1980s, and implementations such as SWI-Prolog and GNU Prolog remain in use for symbolic AI, expert systems, theorem proving, and term rewriting.

Example

mother_child(trude, sally).
father_child(tom, sally).
sibling(X, Y) :- parent_child(Z, X), parent_child(Z, Y), X \= Y.

Here, facts state parent–child relations and a rule defines when two people are siblings. Querying the program can infer relationships not stated explicitly — the hallmark of Prolog's execution model, which is based on unification and backtracking search.

Features

Prolog's single data type is the term, which includes atoms, numbers, variables, and compound terms. Pattern matching is by unification, and control flow relies on depth-first search with backtracking, moderated by the cut operator. Features such as definite clause grammars make Prolog well suited to parsing and computational linguistics. Its declarative style allows some programs to be run "backwards," using the same rules to answer different kinds of questions.
