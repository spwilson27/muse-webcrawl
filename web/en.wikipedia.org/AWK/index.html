AWK (/ɔːk/) is a domain-specific language designed for text processing and data extraction. A standard feature of Unix and Unix-like systems since Version 7 Unix (1979), it is used for scanning files line by line, splitting each line into fields, and performing actions when patterns match. The name derives from the surnames of its authors — Alfred Aho, Peter Weinberger, and Brian Kernighan.

Structure of AWK programs

An AWK program consists of pattern–action pairs: for each input record (by default a line), if the pattern matches, the associated action executes. Records are split automatically into fields $1, $2, … with $0 the whole record; special patterns BEGIN and END run before and after input. The language provides associative arrays, string and arithmetic operators, built-in variables such as NR (record number) and FS (field separator), and functions for string manipulation, making it effective for reports, data validation, and small text transformations, often as one-liners in shell pipelines.

History and implementations

AWK was created at Bell Labs in 1977 and described in the authors' 1988 book The AWK Programming Language. The 1985 revision ("new awk", nawk) added user-defined functions and dynamic regular expressions and was standardized in POSIX. Brian Kernighan's implementation, the "one true awk", is still maintained and was extended in 2023 with UTF-8 and CSV support. GNU Awk (gawk) adds extensions including multidimensional arrays and networking; mawk is a fast byte-code interpreter used historically as the default awk in Debian and Ubuntu.

Relation to other tools

AWK sits between simpler filters such as grep and sed and general-purpose scripting languages; Larry Wall cited it as an influence on Perl, which subsumed AWK's text-processing role for many users. AWK remains ubiquitous in shell scripting, system administration, and bioinformatics pipelines because of its availability and terseness.
