Forcing (mathematics)

In the mathematical discipline of set theory, forcing is a technique for proving consistency and independence results. It was introduced by Paul Cohen in 1963 to prove the independence of the axiom of choice and the continuum hypothesis from Zermelo–Fraenkel set theory. Forcing has been considerably reworked and simplified since, and has had immense import in set theory.

Forcing adjoins a generic object to a ground model, producing a larger model.

Overview

Intuitively, forcing starts with a transitive model M of ZFC (the "ground model") and adjoins an ideal object—a "generic" filter G on a partially ordered set of forcing conditions—forming an expanded model M[G] that satisfies desired properties. Conditions are finite pieces of information about the object to be added; a set of conditions is dense if it cannot be avoided, and a generic filter meets every dense set in the ground model, ensuring the new object is genuinely new and behaves as required. Statements in the forcing language are "forced" by conditions, giving a truth lemma linking the poset to the extension model.

Applications

Cohen used forcing with finite partial functions from natural numbers to cardinals to add many new subsets of the natural numbers, showing the continuum hypothesis can fail. Later techniques include iterated forcing (used by Solovay and Tennenbaum to prove the consistency of the Suslin hypothesis's negation and Martin's axiom variants) and proper forcing (developed by Shelah). Forcing is now the principal tool for independence results throughout set theory.
