Common Weakness Enumeration

Common Weakness Enumeration (CWE)
Maintainer: MITRE Corporation
Purpose: catalogue of software and hardware weakness types
Related: CVE, CAPEC

The Common Weakness Enumeration (CWE) is a community-developed list of software and hardware weakness types, maintained by the MITRE Corporation. Each weakness receives an identifier such as CWE-79 for cross-site scripting, providing a common language for describing, finding and fixing flaws before they become vulnerabilities.

Structure

CWE organises weaknesses hierarchically into pillars, classes, base weaknesses and variants, along with views tailored to researchers, developers and assessment tools. Well-known entries include CWE-89 (SQL injection), CWE-787 (out-of-bounds write) and CWE-20 (improper input validation).

CWE Top 25

MITRE publishes an annual CWE Top 25 Most Dangerous Software Weaknesses list, ranking weaknesses by prevalence and severity using CVE data scored with CVSS.

Relationship to CVE

Where CVE identifies specific vulnerability instances in products, CWE classifies the underlying weakness types that make those vulnerabilities possible.
