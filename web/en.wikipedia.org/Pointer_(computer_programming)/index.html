Pointer (computer programming)

A pointer stores the address of another value in memory

In computer science, a pointer is an object in many programming languages that stores a memory address. This can be that of another value located in computer memory, or in some cases, that of memory-mapped hardware. A pointer references a location in memory, and obtaining the value stored at that location is known as dereferencing the pointer. As an analogy, a page number in a book's index could be considered a pointer to the corresponding page; dereferencing such a pointer would be done by flipping to the page with the given page number and reading the text found on that page.

Pointers to data significantly improve performance for repetitive operations, like traversing iterable data structures (e.g. strings, lookup tables, control tables, and tree structures). Pointers are also used to implement dynamic memory allocation, linked data structures and pass-by-reference semantics.

History and use in C

Explicit pointers became central to programming with the C language (1972), in which the operators & (address-of) and * (dereference) expose machine addresses directly, and pointer arithmetic allows a pointer to be advanced through an array — in C, arrays and pointers are closely related, so that a[i] is equivalent to *(a + i). C++ retained pointers while adding references and, later, smart pointers such as std::unique_ptr and std::shared_ptr that manage object lifetimes automatically. Function pointers store the address of executable code, enabling callbacks and tables of operations. The null pointer designates an intentionally invalid reference; dereferencing it is undefined behaviour that typically crashes the program — Tony Hoare called his invention of the null reference his "billion-dollar mistake".

Hazards

Because pointers expose raw addresses, misuse is a major source of software defects and security vulnerabilities: dangling pointers that reference freed memory, memory leaks from unfreed allocations, buffer overflows from unchecked pointer arithmetic, and use-after-free errors have all been exploited in attacks. Memory-safe languages such as Java, C# and Go therefore replace general pointers with restricted references that cannot be forged or arithmetically manipulated, and rely on garbage collection for reclamation; Rust instead enforces pointer safety at compile time through its ownership and borrowing rules while retaining explicit pointer types for low-level code.

Special kinds of pointers

Variants include void pointers (a pointer without a specified data type, as in C's void *), double pointers (pointers to pointers), near and far pointers in segmented memory architectures, and opaque pointers that hide an object's representation from clients of a library. In databases and filesystems, analogous recorded addresses serve as persistent pointers to stored records.
