Distributed shared memory

Distributed shared memory (DSM) is a form of memory architecture in which physically separate memories attached to different computers in a network are made to appear as a single shared address space to programs. It allows processes on different machines to communicate by simply reading and writing shared data, rather than by explicit message passing.

Implementation

DSM systems are implemented in hardware, in the operating system (for example using page-based schemes such as IVY and Munin), or in software libraries and middleware. When a process accesses data held remotely, the system fetches it over the network, typically at page granularity, and consistency protocols — ranging from strict sequential consistency to relaxed release consistency — keep copies coherent.

Advantages and drawbacks

DSM offers a simple programming model and portability of shared-memory code, but network latency and false sharing can hurt performance compared with explicit message-passing systems such as MPI.
