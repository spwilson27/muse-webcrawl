Hexadecimal

Hexadecimal (often shortened to hex) is a positional numeral system with base 16. It uses sixteen symbols: the digits 0–9 and the letters A–F (or a–f) representing values ten through fifteen. Because sixteen is a power of two (24), each hexadecimal digit corresponds exactly to four binary digits (bits), making hex a compact human-readable shorthand for binary data.

Use in computing

Hexadecimal is ubiquitous in computing: memory addresses, machine code, and byte values are conventionally written in hex; color codes in web design (#RRGGBB) specify red, green, and blue components in hex; MAC addresses and IPv6 addresses use hex notation. Programming languages commonly mark hex literals with a 0x prefix, e.g. 0xFF = 255.

Conversion and fractions

Conversion between hex and binary is digit-by-digit, while conversion to and from decimal requires positional weighting by powers of 16. As in decimal, most simple fractions recur in hexadecimal; only fractions whose denominators are powers of two terminate. See also octal and decimal.
