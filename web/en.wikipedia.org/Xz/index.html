Xz

xz is a lossless data compression file format incorporating the LZMA/LZMA2 algorithms, used by the XZ Utils software. Files typically carry the .xz extension, and xz usually achieves better compression ratios than gzip or bzip2 at the cost of slower compression and higher memory use.

Use

The format supports checksums, random-access reading and multi-stream files. It is widely used for distributing software source tarballs, Linux kernel images and package archives.

2024 backdoor incident

In March 2024 a malicious backdoor inserted by a contributor under the name 'Jia Tan' was discovered in XZ Utils versions 5.6.0 and 5.6.1, targeting SSH authentication on some Linux distributions. Discovered by Andres Freund before it reached most stable releases, the incident became a major case study in open-source supply-chain security.
