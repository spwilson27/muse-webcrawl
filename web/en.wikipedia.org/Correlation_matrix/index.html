Correlation matrix

A correlation matrix is a matrix in which the (i, j) entry is the correlation coefficient between variables i and j of a set of random variables (or of observed data columns). Each entry lies between −1 and +1, the diagonal entries are all 1 (each variable is perfectly correlated with itself), and the matrix is symmetric.

Properties

The correlation matrix is the covariance matrix of the standardised variables, and it is positive semi-definite: all of its eigenvalues are non-negative. Sample correlation matrices computed from data are widely used in multivariate statistics. Because sampling noise affects the eigenvalues of large correlation matrices, random matrix theory (for example the Marčenko–Pastur distribution) is used, especially in finance, to distinguish genuine correlation structure from noise.

Uses

Correlation matrices are used in exploratory data analysis, in principal component analysis and factor analysis (which work directly on the correlation or covariance structure), in checking for multicollinearity in regression, and in portfolio theory, where the matrix of asset-return correlations drives diversification and risk estimates. Visual heat maps of correlation matrices are a common summary of large datasets.
