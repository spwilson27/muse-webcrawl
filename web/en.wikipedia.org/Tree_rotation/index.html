Tree rotation

In computer science, a tree rotation is an operation on a binary search tree that changes the structure of the tree without affecting the inorder sequence of its elements. Tree rotations are used in self-balancing binary search trees such as AVL trees and red–black trees to restore balance after insertions and deletions while preserving the binary search tree property.

Description

A rotation pivots around an edge between a node and one of its children. In a right rotation on a node, its left child takes its place, the node becomes the right child of that child, and the child's former right subtree becomes the node's left subtree. A left rotation is the mirror image. Because the inorder traversal is unchanged, the set of keys in each subtree and the overall search ordering are preserved, although the height of parts of the tree changes.

Rotations and balance

Single rotations correct a tree that leans uniformly to one side; when the imbalance is caused by a "zig-zag" (a left child with a heavy right subtree, or vice versa), a double rotation — a pair of single rotations in opposite directions — is required. In an AVL tree, the rotation type is chosen from the balance factors of the imbalanced node and its child. All rotations run in constant time, requiring only a fixed number of pointer changes.

Applications

Beyond balancing, rotations underpin the operations of splay trees, treaps, and the Day–Stout–Warren algorithm, which uses rotations to transform any binary search tree into a perfectly balanced one in linear time.
