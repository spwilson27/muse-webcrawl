VirtualBox

DeveloperOracle Corporation
Initial release15 January 2007
PlatformWindows, macOS, Linux, Solaris hosts
TypeHypervisor (hosted, type 2)
LicenseGPLv2 (base); proprietary extension pack

VirtualBox is a free and open-source hosted hypervisor for x86 virtualization, developed by Oracle Corporation. It runs on Windows, macOS, Linux and Solaris hosts and supports a wide range of guest operating systems, allowing users to run multiple virtual machines simultaneously on a single computer.

History

VirtualBox was originally created by the German company Innotek, which released it under a proprietary license in 2007 and then also under the GNU General Public License. Sun Microsystems acquired Innotek in 2008, and Oracle inherited the product when it acquired Sun in 2010, rebranding it Oracle VM VirtualBox.

Features

Features include snapshots, shared folders, clipboard sharing, drag-and-drop, seamless windows, 3D acceleration, multiple virtual network modes, remote display via RDP (with the Extension Pack), USB device passthrough, and support for disk image formats including its native VDI as well as VMDK and VHD. The optional Extension Pack adds USB 2.0/3.0 support, disk encryption and host webcam passthrough under a separate proprietary license. VirtualBox is widely used by developers, testers and students for running test environments and legacy software.
