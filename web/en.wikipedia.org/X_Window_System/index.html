The X Window System (X11, or simply X) is a windowing system for bitmap displays, common on Unix-like operating systems. Developed at MIT beginning in 1984 as part of Project Athena, X provides the basic framework for a graphical user interface — drawing and moving windows on a display and interacting with keyboard and mouse — in a network-transparent client–server architecture.

Architecture

In X, the server runs on the machine with the display and accepts connections from client applications, which may run on entirely different machines across a network. This reversal of the usual terminology reflects the server's role of serving display services. The X protocol deliberately avoids mandating a user-interface style ("mechanism, not policy"): window management is performed by a separate window manager client, and toolkits such as Motif, GTK, and Qt build widgets on top of the Xlib or XCB libraries.

History

Version 11 of the protocol, released in September 1987, proved durable enough to remain in use for decades. Development passed from the MIT X Consortium to The Open Group and then, in 2004, to the X.Org Foundation, whose X.Org Server became the reference implementation for Linux and the BSDs. Extensions such as Xinerama (multi-monitor), RandR, XRender, and Composite were added over the years to support modern desktops.

Security and succession

X's design predates modern security practice — any client can observe or inject input to others — and its codebase has grown difficult to maintain. The Wayland protocol was designed as a simpler, more secure successor, with X applications supported through the XWayland compatibility layer; most major Linux distributions now default to Wayland sessions while X11 remains widely used.
