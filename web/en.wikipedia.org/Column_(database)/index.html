Column (database)

In a relational database, a column is a set of data values of a particular type, one value for each row of a table. Columns define the structure of a table: each column has a name, a data type, and optional constraints, while rows supply the individual records.

Concepts

A column corresponds to an attribute in the relational model. Its declared type — such as integer, character string, date, or boolean — governs which values it may hold, and constraints such as NOT NULL or UNIQUE restrict them further. One or more columns may form a primary key uniquely identifying each row, and columns in one table may reference keys in another as foreign keys.

Operations

In SQL, columns are listed in SELECT statements to project chosen attributes, filtered in WHERE clauses, and added, altered, or dropped with ALTER TABLE. Indexing a column speeds lookups on it at the cost of storage and write performance.

Column-oriented storage

Analytical systems often use columnar databases that store each column's values together rather than row by row. This layout compresses well and lets queries read only the columns they need, making it popular for data warehousing and business intelligence.
