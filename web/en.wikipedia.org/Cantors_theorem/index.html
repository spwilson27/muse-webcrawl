Cantor's theorem is a fundamental result of set theory, proved by Georg Cantor in 1891. It states that for any set A, the set of all subsets of A — its power set — has a strictly greater cardinality than A itself. In symbols, |A| < |2A|.

Cantor's diagonal argument, the proof technique behind the theorem.

Proof

The standard proof supposes, for contradiction, that there is a surjection f from A onto its power set. One then forms the "diagonal" set B = { x in A : x is not in f(x) }. Since B is a subset of A, surjectivity would require some d with f(d) = B. But then d belongs to B if and only if d does not belong to f(d) = B — a contradiction. Therefore no such surjection exists.

Consequences

Applying the theorem repeatedly generates an endless hierarchy of infinite cardinalities: the natural numbers, their power set (with the cardinality of the continuum), the power set of that, and so on. Cantor's theorem thus shows there are infinitely many distinct sizes of infinity and no largest cardinal. A special case, applied to the set of real numbers, underlies his earlier diagonal proof that the reals are uncountable.

Generalizations

In category theory, Lawvere's fixed-point theorem generalizes Cantor's result, yielding related conclusions such as Russell's paradox and Gödel's incompleteness theorems as instances of a common diagonal structure.
