Game tree

In the context of combinatorial game theory, a game tree is a graph representing all possible game states within a game. A complete game tree for a game is the game tree starting at the initial position and containing all possible moves from each position; the complete tree is the same tree as that obtained from the extensive-form game representation.

Structure

The root node of the tree represents the initial state of the game. Each node represents a particular way the game might have been played up to that point, and the children of a node are the positions reachable by one legal move. Leaf nodes are terminal positions where the game ends in a win, loss or draw. The depth of a node (measured in moves, or plies) is an important parameter in game-playing programs.

Size and solving

Game trees grow exponentially with the number of moves: tic-tac-toe has about 255,168 possible games, while chess has a game-tree complexity estimated by the Shannon number at around 10120. Because complete trees are usually far too large to enumerate, game-playing programs such as chess engines search a partial tree using techniques like minimax with alpha–beta pruning and evaluation functions.

Solved games

Smaller games have been solved by complete game-tree analysis, including tic-tac-toe, Connect Four and checkers, whose game tree of roughly 5 × 1020 positions was proven a draw in 2007.
