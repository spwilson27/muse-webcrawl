Turtle (syntax)

Turtle (Terse RDF Triple Language) is a syntax and file format for expressing data in the Resource Description Framework (RDF) data model. It provides a compact, human-readable way of writing RDF triples using prefixed names, punctuation shortcuts, and literals.

History

Turtle was developed by Dave Beckett at the University of Bristol, drawing on Tim Berners-Lee's Notation3. It became a W3C Recommendation in February 2014 as part of the RDF 1.1 standards suite.

Features

Turtle supports @prefix declarations, semicolon and comma abbreviations for repeated subjects and predicates, typed and language-tagged literals, blank nodes, and RDF collections. Its subset N-Triples writes one triple per line, while TriG extends Turtle with named graphs.

Example

A triple stating that a resource has a title is written compactly as: @prefix dc: <http://purl.org/dc/elements/1.1/> . <http://example.org/book> dc:title "Example" .
