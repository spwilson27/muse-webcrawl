Smart pointer

A smart pointer wraps a raw pointer and manages the lifetime of the pointed-to object

In computer science, a smart pointer is an abstract data type that simulates a pointer while providing added features, such as automatic memory management or bounds checking. Such features are intended to reduce bugs caused by the misuse of pointers, such as memory leaks and dangling pointers, while retaining efficiency. Smart pointers typically keep track of the memory they point to, and may also be used to manage other resources, such as network connections and file handles.

In C++

The C++ standard library provides several smart pointers in the <memory> header. std::unique_ptr expresses unique ownership: it cannot be copied, only moved, and deletes its object when it goes out of scope. std::shared_ptr implements shared ownership through reference counting, deleting the object when the last owner is destroyed. std::weak_ptr observes a shared_ptr-managed object without extending its lifetime, which allows reference cycles to be broken. The older std::auto_ptr was deprecated in C++11 and removed in C++17.

Ownership and RAII

Smart pointers are a central application of the RAII idiom (resource acquisition is initialization): a resource is tied to the lifetime of a stack object, and the destructor releases it automatically, including during stack unwinding when exceptions are thrown. Guidelines in modern C++ recommend expressing ownership with smart pointers and using raw pointers only as non-owning observers.

Other languages

Other languages provide similar facilities: Rust's standard library offers Box, Rc and Arc smart pointer types, while languages with garbage collection, such as Java and C#, nonetheless offer weak references that resemble weak pointers.
