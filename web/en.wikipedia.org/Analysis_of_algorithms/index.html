Analysis of algorithms

Comparing growth rates — constant, logarithmic, linear, quadratic, exponential — is a core tool of algorithm analysis.

In computer science, the analysis of algorithms is the process of finding the computational complexity of algorithms — the amount of time, storage space, or other resources needed to execute them. Usually, this involves determining a function that relates the size of an algorithm's input to the number of steps it takes (its time complexity) or the number of storage locations it uses (its space complexity). An algorithm is said to be efficient when this function's values are small, or grow slowly compared to a growth in the size of the input.

Asymptotic analysis

Because exact running times depend on hardware and implementation, analysis focuses on how resource use grows as the input size n becomes large. The standard tool is Big O notation, which classifies algorithms by growth rate: for example, binary search is O(log n), linear search is O(n), and simple sorting algorithms such as bubble sort are O(n2). Analysis distinguishes worst-case, average-case, and best-case behaviour, and modern treatments may also count memory accesses or cache effects.

History

Donald Knuth's multi-volume The Art of Computer Programming, begun in 1968, established the rigorous mathematical analysis of algorithms as a discipline; the word "algorithm" itself derives from the name of the 9th-century Persian mathematician Muḥammad ibn Mūsā al-Khwārizmī. The field underpins algorithm design, compiler optimisation, and computational complexity theory, including the famous P versus NP problem.
