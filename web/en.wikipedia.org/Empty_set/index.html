Empty set

From Wikipedia, the free encyclopedia

In mathematics, the empty set is the unique set having no elements; its size or cardinality (count of elements in a set) is zero. Some axiomatic set theories ensure that the empty set exists by including an axiom of empty set, while in other theories, its existence can be deduced. Many possible properties of sets are vacuously true for the empty set.

Any set other than the empty set is called non-empty. In some textbooks and popularizations, the empty set is referred to as the "null set". However, the null set is a distinct notion within the context of measure theory, in which it describes a set of measure zero (which can be non-empty).

Notation

The empty set is denoted by the symbols {} or ∅. The latter symbol was introduced by the Bourbaki group (specifically André Weil) in 1939, inspired by the letter Ø in the Danish and Norwegian alphabets, and is not to be confused with the Greek letter Φ.

Properties

The empty set is unique: for any two empty sets, they are equal, since neither contains any element by which they could differ. For any set A, the empty set is a subset of A, and A is a subset of itself together with the empty set only in trivial ways. The union of the empty set with any set A is A, and their intersection is the empty set. The Cartesian product of any set with the empty set is empty.

The empty set is countable — indeed it is finite, with cardinality zero. In topology, the empty set is both open and closed. In the von Neumann construction of the natural numbers, the number 0 is defined as the empty set, and each successive number as the set of all preceding numbers.

Operations on the empty set

Operations performed on the empty set can be confusing. The sum of the elements of the empty set is zero (the empty sum), while the product of its elements is one (the empty product). These conventions keep algebraic identities consistent, for example in factorials and combinatorics.
