COFF

The Common Object File Format (COFF) is a format for executable, object code, and shared library computer files used on Unix systems. Introduced in AT&T's UNIX System V, it replaced the earlier a.out format. COFF and its variants continue to be used on some Unix-like systems, on Microsoft Windows (in the form of the Portable Executable format), in EFI environments, and in some embedded development systems.

History

COFF debuted in System V Release 1 (1983). It improved on a.out by supporting multiple named sections, richer symbolic debugging information, and a standardized header, which simplified linking and allowed section-level control over how code and data were loaded. Implementations varied by processor architecture, with related formats such as XCOFF (IBM AIX) and ECOFF (MIPS and DEC systems).

Structure

A COFF file begins with a file header identifying the target machine, the number of sections and a pointer to the symbol table, followed by an optional header (used for executables) and a series of section headers. Each section contains data such as machine code (.text), initialized data (.data) or uninitialized data (.bss), together with relocation entries that tell the linker how to adjust addresses when sections are combined or loaded.

Legacy

Most Unix systems eventually adopted the Executable and Linkable Format (ELF), but COFF lives on in Microsoft's PE/COFF specification, which underlies .exe and .dll files on Windows, and in TI and other embedded toolchains.
