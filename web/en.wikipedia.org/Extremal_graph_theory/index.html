Extremal graph theory

Extremal graph theory is a branch of combinatorics, in the overlap of mathematics and computer science, that studies how global properties of a graph constrain local substructures, and vice versa. It asks, for example, how many edges a graph on n vertices can have before it is forced to contain a given subgraph.

History

The field began in 1941 with Pál Turán's theorem, which determines the maximum number of edges in a graph on n vertices that contains no complete graph Kr+1; the extremal example is the Turán graph, a complete balanced r-partite graph. An earlier result, Mantel's theorem (1907), solved the triangle-free case. Turán-type problems are foundational to the subject.

Key results

The Erdős–Stone theorem gives the asymptotic maximum number of edges in an H-free graph in terms of the chromatic number of H. The Kővári–Sós–Turán theorem bounds the edges in a graph avoiding a complete bipartite subgraph Ks,t. The Zarankiewicz problem asks the analogous question for bipartite graphs. Extremal graph theory also includes the study of graph saturation, Ramsey–Turán problems, and forbidden subgraphs.

Methods

Proof techniques include induction, the probabilistic method, entropy arguments, and graph regularity methods deriving from Szemerédi's regularity lemma. More recent progress uses flag algebras, developed by Alexander Razborov, which have resolved several long-standing density problems.
