Edmonds–Karp algorithm

In computer science, the Edmonds–Karp algorithm is an implementation of the Ford–Fulkerson method for computing the maximum flow in a flow network. It was published in 1970 by Yefim Dinitz in the Soviet Union and independently in 1972 by Jack Edmonds and Richard Karp.

Description

The algorithm is identical to the Ford–Fulkerson algorithm, except that the search order used to find augmenting paths is defined so that the paths found are the shortest (in terms of number of edges). This is achieved by finding each augmenting path with a breadth-first search of the residual graph, treating all edges as having unit weight.

Complexity

Because each augmentation saturates at least one edge and the length of the shortest augmenting path increases monotonically, the number of augmentations is bounded by O(VE), giving an overall running time of O(VE2), where V is the number of vertices and E the number of edges. Importantly, this bound is independent of the value of the maximum flow, which makes Edmonds–Karp strongly polynomial, unlike naive implementations of Ford–Fulkerson with irrational capacities, which may never terminate.

Example

Given a network of seven nodes, source A and sink G, with capacities as commonly illustrated in textbooks, the algorithm successively augments flow along shortest paths such as A–D–F–G, then A–D–E–G, then A–C–D–E–G, and finally A–C–E–D–F–G, yielding a maximum flow whose value equals the minimum cut by the max-flow min-cut theorem.
