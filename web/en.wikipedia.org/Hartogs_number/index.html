Hartogs number

In mathematics, the Hartogs number of a set X is the least ordinal number that cannot be injected into X — that is, the smallest ordinal α such that there is no one-to-one function from α into X. It is named after the German mathematician Friedrich Hartogs, who proved in 1915 that such an ordinal always exists.

Hartogs number
Field: Set theory
Named after: Friedrich Hartogs
Notation: ℵ(X) or h(X)

Existence

Hartogs's theorem guarantees the existence of the Hartogs number for every set, without assuming the axiom of choice. The proof considers the set of all well-orderings of subsets of X, which is itself a set by the power set and separation axioms; the order types of these well-orderings form a set of ordinals, whose supremum cannot itself be injected into X.

Significance

The theorem shows there is an unending hierarchy of infinite cardinalities even in ZF set theory without choice, and it is a key step in proving that for any two sets, one injects into the other if the axiom of choice is assumed. For a set X that can be well-ordered, the Hartogs number is the successor cardinal of X's cardinality.
