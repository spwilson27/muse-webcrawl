Zeta function regularization

In mathematics and theoretical physics, zeta function regularization is a type of regularization and renormalization method that assigns finite values to divergent sums or products, using analytic continuation of a zeta function associated with the problem. It was proposed by Stephen Hawking in 1977 as a technique for computing functional determinants in quantum field theory, especially in curved spacetime.

Method

Given an operator with eigenvalues λ1, λ2, …, one defines a generalized zeta function ζA(s) = Σ λn−s, which converges for Re(s) sufficiently large, and extends it to other values of s by analytic continuation. Divergent quantities such as the sum of the eigenvalues or the product of all eigenvalues (the determinant) are then assigned values from the continuation: formally Σ λn = ζA(−1) and Π λn = exp(−ζA′(0)).

Famous example

The most celebrated instance applies the Riemann zeta function: the divergent series 1 + 2 + 3 + 4 + ⋯ is assigned the value ζ(−1) = −1/12. Results of this kind, obtained by Srinivasa Ramanujan and systematised in his summation method, are used in physics, notably in computing the Casimir effect and in bosonic string theory, where the value fixes the critical dimension of spacetime at 26.
