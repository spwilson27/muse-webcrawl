Ladder logic

From Wikipedia, the free encyclopedia

Ladder logic is a programming language that represents a program by a graphical diagram based on the circuit diagrams of relay logic hardware. It is used mainly in programmable logic controllers (PLCs) to develop software for industrial automation, and is one of the languages defined by the IEC 61131-3 standard.

Overview

A ladder diagram resembles the rungs of a ladder: two vertical "rails" representing power, and horizontal "rungs" containing instructions. Contacts represent inputs (such as switches or sensor conditions) and coils represent outputs (such as motors or lamps). The controller evaluates rungs from top to bottom in a continuous scan cycle, updating outputs based on inputs and internal state.

Elements

Basic elements include normally open and normally closed contacts, output coils, timers, counters, and comparison and arithmetic function blocks. Because it visually mimics the relay panels it replaced, ladder logic remains intuitive for electricians and control engineers, and it is still the most widely used PLC language worldwide.
