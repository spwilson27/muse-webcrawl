C string

In the C programming language, a string is a sequence of characters stored as an array of char values terminated by a null character ('\0'). This null-terminated representation, often called a C string, contrasts with string types in other languages that store an explicit length.

Representation

Because the length of a C string is not stored, functions operating on strings must scan for the terminating null byte; the standard library function strlen computes length in this way. A string literal such as "hello" is stored as an array of six characters, including the implicit terminator.

Standard library functions

The header <string.h> declares functions including strcpy (copy), strcat (concatenate), strcmp (compare), and strchr (search). Several of these functions do not check destination buffer sizes, and their misuse is a classic source of buffer overflow vulnerabilities; bounded alternatives such as strncpy and, in C11, the optional Annex K functions were introduced in response.

Limitations

C strings cannot contain embedded null characters, determining length is an O(n) operation, and the programmer is responsible for allocating sufficient memory. These limitations motivate the use of alternative string libraries in C and the distinct string types of C++ and other languages influenced by C.
