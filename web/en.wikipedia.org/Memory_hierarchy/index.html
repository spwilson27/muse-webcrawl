Memory hierarchy

From Wikipedia, the free encyclopedia

In computer architecture, the memory hierarchy is the organization of storage in a computer system into levels that trade off speed, size, and cost. Levels closer to the processor are smaller, faster, and more expensive per byte; levels further away are larger, slower, and cheaper.

Levels

A typical hierarchy comprises, from fastest to slowest: processor registers; one or more levels of cache memory (L1, L2, and often L3); main memory (RAM); and secondary storage such as solid-state drives and hard disk drives, sometimes followed by offline or archival storage. Each level acts as a cache for the one below it.

Locality of reference

The hierarchy works because programs exhibit locality of reference: data and instructions accessed recently (temporal locality) or near recently accessed items (spatial locality) are likely to be needed again soon. By keeping such working sets in fast memory, the average access time approaches that of the fastest levels.

Design considerations

Cache size, associativity, block size, and replacement policy all affect performance. As processor speeds have grown far faster than memory speeds, the "memory wall" has made hierarchy design central to computer performance.
