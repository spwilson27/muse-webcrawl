Exposure value

Each increase of one EV halves the amount of light reaching the film or sensor.

In photography, exposure value (EV) is a number that represents a combination of a camera's shutter speed and f-number such that all combinations that yield the same exposure have the same EV (for a given scene luminance). EV 0 corresponds to an exposure of 1 second at f/1.0; each step of 1 EV doubles or halves the light. The scale was developed by German shutter manufacturer Friedrich Deckel in the 1950s and simplified setting matched aperture and shutter controls on cameras.

Uses

Light meters report scene brightness in EV (usually at ISO 100), letting photographers pick any combination of aperture and shutter speed with the same EV for equivalent exposure. Landmark reference points include roughly EV 15 for bright sunlight, EV 10–12 for overcast daylight, and negative values for starlight. The related light value (LV) and the APEX system of exposure calculation are built on the same logarithmic idea.
