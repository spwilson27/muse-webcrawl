Software repository

A software repository, or "repo", is a storage location from which software packages are retrieved and installed. The term covers two related concepts: a repository in a version-control system holding the history of a codebase, and a package repository hosting installable software distributions.

Package repositories

Operating systems such as Linux distributions maintain official repositories (for example Debian's APT repositories or Fedora's DNF repositories) from which package managers install software and resolve dependencies. Language ecosystems have their own registries, such as PyPI for Python, npm for JavaScript, and Maven Central for Java.

Code hosting

Version-control repositories are hosted by services such as GitHub, GitLab, and Bitbucket, which add collaboration features — issues, pull requests, and continuous integration — around the underlying Git or other repository.
