SPIR-V

SPIR-V (Standard Portable Intermediate Representation, version V) is an intermediate language for graphics and compute developed by the Khronos Group. It is used as the shader and kernel language target for the Vulkan graphics API and for OpenCL 2.1 and later, allowing developers to compile high-level languages such as GLSL and HLSL once into a binary intermediate form that drivers then translate to native GPU instructions.

SPIR-V sits between high-level shading languages and GPU drivers.

Design

SPIR-V is a binary, word-oriented format based on static single assignment (SSA) form, designed to be a true cross-vendor, cross-API intermediate language — in contrast to the original SPIR, which was based on LLVM IR. It supports both graphics shaders and general-purpose compute kernels, carries rich type and decoration information, and is designed for validation, offline compilation and fast driver ingestion. SPIR-V is extensible, with extensions adding features such as ray tracing and machine-learning operations.

Ecosystem

The Khronos Group maintains open-source tools including glslang (a GLSL/HLSL to SPIR-V compiler), SPIRV-Tools for assembly, disassembly, validation and optimization, and SPIRV-Cross for translating SPIR-V back to high-level shading languages used in cross-platform game development.
