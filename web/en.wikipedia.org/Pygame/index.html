Pygame

Pygame is a cross-platform set of Python modules designed for writing video games. It includes computer graphics and sound libraries built on top of the Simple DirectMedia Layer (SDL), allowing games written in Python to run on many platforms with little modification.

History

Pygame was originally written by Pete Shinners and released in 2000, replacing the earlier pySDL project. It is free and open-source software released under the GNU LGPL. The library abstracts SDL surfaces, drawing, events, input devices, and the mixer for audio, and is widely used in education and in game jams. A major modern branch, pygame-ce ("community edition"), was forked in 2022–2023 by much of the active contributor community and continues development with regular releases.

Features

Pygame provides modules for display and surfaces, 2D drawing, sprites and collision detection, fonts, image loading, and sound playback. Because it is built on SDL, performance-critical code runs in C while game logic is written in Python.
