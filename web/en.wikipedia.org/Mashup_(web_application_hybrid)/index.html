Mashup (web application hybrid)

Web page combining data from multiple sources

A mashup, in web development, is a web page or application that uses content from more than one source to create a single new service displayed in a unified graphical interface. Mashups were a hallmark of the "Web 2.0" era of the mid-2000s, when publicly available application programming interfaces (APIs) let independent developers recombine data — for example, plotting rental listings or crime reports on interactive maps.

History

One of the earliest and most influential mashups was HousingMaps (2005), which combined Craigslist apartment listings with Google Maps — created before Google offered a formal maps API, by reverse-engineering the service. Google responded by releasing an official API, and thousands of mashups followed, catalogued by directories such as ProgrammableWeb. The pattern helped popularise open APIs, Ajax interfaces and lightweight data formats such as JSON.

Types and architecture

Consumer mashups combine data from public feeds; data mashups integrate information of similar type, such as mapping APIs from rival providers, into a single representation; and enterprise mashups pull together internal and external data behind a firewall. Aggregation may occur on the server, or in the browser using JavaScript and cross-service APIs. The decline of free public APIs and stricter platform terms after the early 2010s reduced the mashup ecosystem, though the underlying idea persists in modern data-integration dashboards and embedded widgets.
