Score (statistics)

In statistics, the score (or score function) is the gradient of the logarithm of the likelihood function with respect to the parameter vector. Evaluated at a particular point of the parameter space, the score indicates the steepness of the log-likelihood function and thereby the sensitivity of values of the likelihood function to infinitesimal changes in the parameter values.

Definition

If the probability density function (or probability mass function) is f(x; θ), the score is:

V(θ) = ∂/∂θ · log f(x; θ)

The score is a random variable because it depends on the observed data x. Under regularity conditions its expected value is zero when evaluated at the true parameter value.

Properties

The variance of the score is the Fisher information, which measures how much information an observable random variable carries about an unknown parameter. The score function is central to the method of maximum likelihood estimation: maximum likelihood estimates are found where the score equals zero.

Applications

The score is used in Rao's score test (also called the Lagrange multiplier test), one of the three classical approaches to hypothesis testing alongside the Wald test and the likelihood-ratio test. In generalized linear models, solving the score equations yields the parameter estimates.
