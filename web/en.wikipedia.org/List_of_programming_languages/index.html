List of programming languages

From Wikipedia, the free encyclopedia

This is a list of notable programming languages, organized alphabetically. Thousands of programming languages have been created since the 1940s; the entries below are those with significant use, historical importance, or distinctive design. Languages are also grouped in related articles by paradigm (functional, object-oriented, logic, and so on) and by generation.

A–C

  • Ada — structured, statically typed language developed for the U.S. Department of Defense
  • ALGOL — influential family of languages from the late 1950s
  • APL — array-oriented language known for its special symbols
  • Assembly language — low-level symbolic representation of machine code
  • AWK — text-processing language
  • BASIC — beginner-oriented language family, from 1964
  • C — general-purpose language developed at Bell Labs in the 1970s
  • C++ — extension of C with classes and generic programming
  • C# — Microsoft language for the .NET platform
  • COBOL — business-oriented language from 1959
  • Clojure — modern dialect of Lisp for the Java platform

D–L

  • D — systems language designed as a successor to C++
  • Dart — Google language used by the Flutter framework
  • Erlang — functional language for concurrent, fault-tolerant telecom systems
  • Fortran — first widely used high-level language (1957), still used in scientific computing
  • Go — Google language emphasizing simplicity and concurrency
  • Haskell — purely functional, lazily evaluated language
  • Java — class-based, object-oriented language running on the JVM (1995)
  • JavaScript — the scripting language of the web browser
  • Julia — high-performance technical computing language
  • Kotlin — modern JVM language, preferred for Android development
  • Lisp — pioneering language family (1958) based on symbolic expressions
  • Lua — lightweight embeddable scripting language

M–Z

  • MATLAB — numerical computing environment and language
  • Objective-C — Apple's former main language for macOS/iOS
  • Pascal — teaching and systems language designed by Niklaus Wirth
  • Perl — text-processing and scripting language (1987)
  • PHP — server-side language widely used for web development
  • Prolog — logic programming language
  • Python — high-level language emphasizing readability (1991)
  • R — statistical computing language
  • Ruby — object-oriented scripting language; known for Ruby on Rails
  • Rust — systems language focused on memory safety
  • Scala — functional/object-oriented JVM language
  • Scheme — minimalist Lisp dialect
  • SQL — standard language for relational database queries
  • Swift — Apple's language for its platforms (2014)
  • TypeScript — JavaScript superset adding static types
  • Visual Basic — event-driven language from Microsoft
