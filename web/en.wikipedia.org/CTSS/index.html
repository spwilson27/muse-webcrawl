Compatible Time-Sharing System

CTSS
DeveloperMIT Computation Center (Fernando J. Corbató et al.)
First demonstratedNovember 1961
PlatformsIBM 709, IBM 7090/7094
Written inFAP assembly language
InfluencedMultics, Unix culture, ITS

The Compatible Time-Sharing System (CTSS) was the first general-purpose time-sharing operating system, developed at the MIT Computation Center and first demonstrated in November 1961. It ran on modified IBM 709, 7090 and 7094 mainframes, allowing up to 30 users at teletype terminals to share one computer interactively — a revolutionary alternative to batch processing.

Features

CTSS combined a time-sharing supervisor in one memory bank with the older FMS batch system ("compatible" with it) in another. It introduced landmark innovations: the first computerised text formatting (RUNOFF), online editing, inter-user messaging and electronic mail (the MAIL command, 1965), instant messaging, a file system with personal files and passwords, and programs such as the ELIZA natural-language demonstration. One of the earliest password breaches occurred on CTSS when a software bug printed the password file — an incident that helped motivate password security research.

Influence

Project director Fernando J. Corbató received the Turing Award in 1990 for pioneering time-sharing. CTSS directly inspired Multics, and its user community — centred at MIT's Project MAC — shaped the interactive computing culture from which Unix and modern operating systems emerged. CTSS remained in use at MIT until 1973.
