Linear regression

A linear regression line fitted to a set of data points.

In statistics, linear regression is a model that estimates the linear relationship between a scalar response (dependent variable) and one or more explanatory variables (independent variables). The case of one explanatory variable is called simple linear regression; with more than one it is multiple linear regression.

Model and estimation

The model takes the form y = β₀ + β₁x₁ + … + βₚxₚ + ε, where ε is an error term. The coefficients are most commonly estimated by the method of least squares, which minimises the sum of squared residuals. Under the assumptions of the Gauss–Markov theorem, the ordinary least squares estimator is the best linear unbiased estimator.

Assumptions

Classical linear regression assumes linearity in the parameters, independence and homoscedasticity of the errors, and — for exact inference — normally distributed errors. Violations can be addressed with robust methods, transformations, or generalised linear models.

Applications

Linear regression is used throughout the sciences, economics, epidemiology, and machine learning for prediction and for quantifying relationships between variables. It is closely related to correlation analysis and forms the basis of more advanced techniques such as logistic regression and ridge regression.
