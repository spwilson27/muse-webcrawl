Object file

An object file is a file that contains machine code or bytecode, as well as other data and metadata, generated by a compiler or assembler from source code during the compilation or assembly process. The machine code that is generated is known as object code. Object files are typically relocatable: they contain references to symbols defined elsewhere that a linker resolves when combining object files into an executable or library.

Formats

Common object file formats include ELF (Executable and Linkable Format) on Unix-like systems, Mach-O on macOS, and COFF/PE on Microsoft Windows. Historical formats include a.out. A typical object file is organized into segments or sections, such as a text segment (code), data segment (initialized variables), BSS (uninitialized data), symbol table, and relocation information.

Use

Compiling source files separately into object files allows large programs to be built incrementally: only changed files need recompiling before linking. Object files collected into an archive form a static library.
