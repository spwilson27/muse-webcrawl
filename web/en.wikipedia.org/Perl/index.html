Perl

Paradigm: Multi-paradigm (imperative, functional, object-oriented, reflective)
Designed by: Larry Wall
First appeared: 1987
Typing: Dynamic, weak
Website: perl.org

Perl is a family of two high-level, general-purpose, interpreted, dynamic programming languages, "Perl 5" and "Raku" (formerly Perl 6), which diverged into separate languages. Perl was originally developed by Larry Wall in 1987 as a Unix scripting language for report processing, borrowing features from C, shell scripting, AWK and sed. The language is famous for its powerful built-in regular expression engine and its huge CPAN module repository.

Design

Perl's design philosophy is summed up in the mottos "There's more than one way to do it" (TMTOWTDI) and "Perl: the Swiss Army chainsaw". It emphasises practical text manipulation, context-sensitive scalar/list behaviour, sigils ($ for scalars, @ for arrays, % for hashes), and the use of punctuation variables and implicit variables such as $_. The language is highly expressive but is sometimes criticised for producing hard-to-read "write-only" code.

History

Perl 1.0 was released to the comp.sources.misc newsgroup in December 1987. Perl 4, described in the "Camel Book" (Programming Perl, 1991), made the language popular with system administrators; Perl 5 (1994) added references, modules, objects and the CPAN archive, and in the late 1990s Perl became the dominant language of CGI web programming and a mainstay of bioinformatics and system administration. The Perl 6 project, begun in 2000 as a redesign, grew into a distinct language and was renamed Raku in 2019, while Perl 5 continues active annual releases.
