RGBA color model

RGBA color model
Channels: Red, Green, Blue, Alpha
Typical depth: 32 bits per pixel
Use: Raster graphics, compositing, web design

RGBA is an extension of the RGB color model that adds a fourth channel, alpha, representing the opacity of each pixel. The acronym stands for red, green, blue and alpha. While RGB values specify a colour, the alpha value specifies how transparent the pixel is, from fully transparent (0) to fully opaque (maximum value).

Representation

In a common 32-bit representation, each channel occupies 8 bits, giving values from 0 to 255. In web design, CSS expresses RGBA colours with the rgba() function, where alpha is a number between 0.0 and 1.0, and with eight-digit hexadecimal notation. Image formats supporting alpha include PNG, WebP and TIFF.

Compositing

When an RGBA image is displayed over a background, the final colour is computed by alpha compositing — most often the "over" operator described by Porter and Duff in 1984. Implementations may store colour values as straight (unassociated) alpha or as premultiplied alpha, in which the RGB channels are already scaled by the alpha value; premultiplied storage avoids dark fringes during filtering and interpolation.

Variants

The byte order of the four channels varies by system: besides RGBA, formats such as ARGB (alpha first, used in many Microsoft and Android APIs), BGRA and ABGR are common.
