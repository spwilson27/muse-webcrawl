Reference

Reference is a relationship between objects in which one object designates, or acts as a means to connect to or link to, another object. In semantics, reference is the relation between a word or expression and what it stands for in the world; in computing, a reference is a value that enables a program to indirectly access data in memory.

The term also covers reference works — books or databases designed to be consulted for facts, such as dictionaries, encyclopaedias and atlases — a bibliographic reference or citation identifying a source, and a letter of reference vouching for a person's character or qualifications.

Philosophers from Frege to Kripke have debated how names refer: descriptivist theories tie reference to associated descriptions, while causal theories trace it to an initial naming and a historical chain of use. See also sense and reference and citation.
