Fallback font

A fallback font is a reserve typeface containing symbols for as many Unicode characters as possible. When a display system encounters a character it cannot render in the primary font, it substitutes glyphs from a fallback font rather than showing a placeholder box (sometimes called "tofu").

Implementation

Operating systems and browsers maintain font fallback chains: an ordered list of fonts searched until one is found that contains the required glyph. In CSS, authors specify fallback lists with the font-family property, ending in a generic family such as sans-serif or serif. Text layout engines such as HarfBuzz, DirectWrite, and Core Text perform automatic per-character fallback.

Examples

Microsoft's Segoe UI Symbol and the Noto font family developed by Google are widely used fallback fonts; Noto's stated goal is to cover every Unicode script and eliminate tofu across platforms.
