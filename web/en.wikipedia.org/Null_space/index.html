Null space

In mathematics, the null space (or kernel) of a linear map is the set of all vectors that the map sends to the zero vector. For a matrix A, the null space consists of all vectors x such that Ax = 0; it is a subspace of the domain.

Properties

The dimension of the null space is called the nullity. The rank–nullity theorem states that rank plus nullity equals the number of columns of the matrix. Finding the null space — by Gaussian elimination to reduced row echelon form — solves homogeneous systems of linear equations and underlies methods in least squares, computer graphics and data analysis, where it appears in the singular value decomposition.

Kernel of a linear map

More generally, the kernel of a linear transformation between vector spaces measures how far the map is from being injective: the map is injective if and only if its kernel is trivial.
