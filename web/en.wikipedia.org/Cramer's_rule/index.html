Cramer's rule

Cramer's rule is an explicit formula for the solution of a system of linear equations with as many equations as unknowns, valid whenever the system has a unique solution. It expresses the solution in terms of the determinants of the (square) coefficient matrix and of matrices obtained from it by replacing one column by the column vector of right-hand sides of the equations. It is named after Gabriel Cramer (1704–1752), who published the rule for an arbitrary number of unknowns in 1750, although Colin Maclaurin also published special cases of the rule in 1748 (and possibly knew of it as early as 1729).

Cramer's rule applied to a 2×2 system

General case

Consider a system of n linear equations for n unknowns, represented in matrix multiplication form as Ax = b, where the n × n matrix A has a nonzero determinant, and the vector x = (x1, …, xn)T is the column vector of the variables. Then the theorem states that in this case the system has a unique solution, whose individual values for the unknowns are given by:

xi = det(Ai) / det(A)

where Ai is the matrix formed by replacing the i-th column of A with the column vector b.

Proof

The proof of Cramer's rule uses properties of the determinant: linearity in each column of an argument and the fact that the determinant is zero when two columns are equal. A slick proof follows from abstract linear algebra: the rule is a consequence of the adjugate identity A adj(A) = det(A) I.

Finding inverse matrix

Cramer's rule can also be used to express the inverse of an invertible n × n matrix: solving Ax = ej for each standard basis vector gives the columns of A−1. This leads to the formula A−1 = adj(A) / det(A), where adj denotes the adjugate matrix of cofactors.

Applications

Cramer's rule is of theoretical importance mainly, because it gives an explicit expression for the solution of a system in terms of determinants. For large systems, Gaussian elimination is far more efficient computationally: Cramer's rule requires computing n + 1 determinants, each of which is generally as expensive as solving a system directly. The rule also applies in differential geometry and in proofs involving systems of equations over commutative rings.
