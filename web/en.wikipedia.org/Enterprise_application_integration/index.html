Enterprise application integration

Enterprise application integration (EAI) is the practice and technology of linking an organisation's software applications and data so they can share processes and information.

Approaches

Early EAI used point-to-point connections and central message brokers; later architectures adopted enterprise service buses, standardised messaging, adapters and APIs. Modern integration often uses cloud integration platforms and event streaming.

Challenges

Integration must reconcile differing data models, semantics and business rules across packaged, legacy and custom systems.
