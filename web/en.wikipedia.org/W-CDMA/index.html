W-CDMA

W-CDMA
Full name: Wideband Code-Division Multiple Access
Type: 3G mobile air interface
Standard body: 3GPP (UMTS)
Channel bandwidth: 5 MHz

W-CDMA (Wideband Code-Division Multiple Access) is a third-generation (3G) mobile telecommunications air interface, forming the basis of the UMTS networks deployed by most GSM operators worldwide. It uses direct-sequence spread spectrum with a 5 MHz channel bandwidth.

Technical features

W-CDMA spreads each user's signal over the full channel using unique spreading codes, allowing many users to share the same frequency band simultaneously. It supports variable data rates, with later HSPA evolutions (HSDPA and HSUPA) raising peak rates to several tens of megabits per second. The system uses fast power control and soft handover between cells.

Deployment

NTT DoCoMo's FOMA service, launched in Japan in 2001, was the first commercial W-CDMA network. W-CDMA/HSPA became the dominant 3G technology globally before operators migrated to LTE (4G).
