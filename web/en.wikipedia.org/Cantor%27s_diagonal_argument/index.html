Cantor's diagonal argument

Diagonal argument
Proof by Georg Cantor (1891) that the real numbers are uncountable

Cantor's diagonal argument is a mathematical proof, published by Georg Cantor in 1891, that there are infinite sets which cannot be put into one-to-one correspondence with the set of natural numbers — that is, the real numbers are uncountably infinite.

The argument

Suppose the real numbers between 0 and 1 could be listed in a sequence. Writing each as an infinite decimal expansion, construct a new number whose n-th digit differs from the n-th digit of the n-th listed number. The constructed number appears nowhere in the list, contradicting the assumption that the list was complete.

Consequences

The argument underlies Cantor's theorem on power sets and influenced the halting problem proof and Gödel's incompleteness theorems.
