Bootloader

Type: System software

Function: Loads an operating system at startup

Examples: GRUB, Windows Boot Manager, U-Boot

A bootloader (also spelled boot loader, and historically called a bootstrap loader) is a small program that loads an operating system into memory when a computer starts. Since a computer cannot load its operating system by itself, firmware — traditionally the BIOS, now usually UEFI — locates and runs the bootloader from a fixed location on a storage device, and the bootloader in turn locates the kernel, loads it, and transfers control to it.

Boot sequence

On classic PC systems the BIOS loads the first 512-byte sector of the boot disk (the Master Boot Record) into memory; this first-stage code then loads a larger second-stage bootloader with knowledge of file systems and configuration. Modern UEFI firmware can load a full bootloader application such as GRUB or the Windows Boot Manager directly from an EFI system partition. Multi-stage loading is necessary because early stages are severely size-constrained.

Common bootloaders

GNU GRUB is the standard bootloader of most Linux distributions, offering a menu of operating systems and kernels, an editable command line, and support for many file systems. Other examples include systemd-boot, the Windows Boot Manager (bootmgr), the embedded-system bootloader U-Boot, and mobile bootloaders such as Android's fastboot environment.

Security

Because bootloaders run before the operating system, they are a target for persistent malware ("bootkits"), and a point of control over what software may run. Secure Boot, part of UEFI, counters this by requiring bootloaders to carry valid cryptographic signatures. Many phones and consoles ship with locked bootloaders that refuse unsigned code, a source of controversy over owners' ability to modify their devices.
