Affine cipher


Example affine mapping of the alphabet

The affine cipher is a type of monoalphabetic substitution cipher in which each letter in an alphabet is mapped to its numeric equivalent, encrypted using a simple mathematical function, and converted back to a letter. It is a generalisation of both the Caesar cipher and the Atbash cipher.

Description

For an alphabet of size m, encryption is E(x) = (ax + b) mod m, where the key consists of the pair (a, b). The multiplier a must be coprime to m so that the mapping is one-to-one and decryption is possible: D(y) = a−1(y − b) mod m. When a = 1 the cipher reduces to a Caesar shift; when a = m − 1 and b = m − 1 it gives the Atbash cipher.

Security

Like all monoalphabetic substitution ciphers, the affine cipher is insecure: its key space is small (for a 26-letter alphabet there are only 12 × 26 = 312 possible keys), and it preserves letter frequencies, making it readily broken by frequency analysis or brute force.
