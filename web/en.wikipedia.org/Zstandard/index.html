Zstandard, commonly known by the name of its reference implementation zstd, is a lossless data compression algorithm developed by Yann Collet at Facebook and first released open source in 2015. It is designed to give compression ratios comparable to or better than DEFLATE (as used in gzip and ZIP) while offering much faster compression and especially decompression speeds.

Zstandard offers a wide range of speed-versus-ratio trade-offs through its compression levels.

Design

Zstandard combines a dictionary-matching stage (LZ77) with finite-state entropy coding, using both tANS (via the FSE library) and Huffman coding. It offers 22 compression levels, from very fast low-ratio modes to slow high-ratio modes, plus a training mode that builds custom dictionaries for compressing many small, similar files. A newer range-matching mode at high levels improves ratios substantially on large inputs.

Format and adoption

The Zstandard compressed data format is specified in RFC 8878 (2021), with media type application/zstd. The format was adopted by the Linux kernel (for kernel, initramfs and filesystem compression, e.g. Btrfs), software package formats such as Debian's .deb and RPM, container and archive tools, databases, and content-encoding in HTTP. Its media type and file format have made it one of the most widely deployed modern compression schemes.
