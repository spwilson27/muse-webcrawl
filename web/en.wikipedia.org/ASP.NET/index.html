ASP.NET

ASP.NET
Developer: Microsoft
Initial release: January 5, 2002
Type: Web application framework
Platform: .NET

ASP.NET is a server-side web-application framework designed for web development to produce dynamic web pages. Developed by Microsoft, it allows programmers to build dynamic websites, applications, and services using languages such as C# and Visual Basic running on the .NET runtime. The name continues that of Microsoft's earlier Active Server Pages (ASP) technology, with ".NET" marking its basis in the .NET Framework.

History

ASP.NET was first released in January 2002 with version 1.0 of the .NET Framework. Its original programming model, Web Forms, abstracted web development into a stateful, event-driven style resembling desktop programming. ASP.NET MVC, released in 2009, offered a lightweight model–view–controller alternative. In 2016 Microsoft introduced ASP.NET Core, a ground-up, open-source, cross-platform rewrite that unified MVC and Web API and runs on Windows, macOS, and Linux; from .NET 5 onward it is simply the .NET platform's web stack.

Components

The framework includes Razor, a markup syntax embedding C# in HTML; Blazor, which runs C# in the browser via WebAssembly or on the server; SignalR for real-time communication; and Entity Framework Core for data access. ASP.NET applications are typically hosted on IIS or run standalone with the cross-platform Kestrel web server.
