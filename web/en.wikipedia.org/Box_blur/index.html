Box blur

A box blur (also known as a box linear filter) is a spatial-domain image filter in which each pixel in the output image has a value equal to the average value of its neighbouring pixels in the input image. It is a form of low-pass ("blurring") filter and a simple example of a convolution.

Definition

For a box blur of radius r, each output pixel is the arithmetic mean of the (2r + 1)² input pixels in the square window centred on it. The corresponding convolution kernel is a square matrix filled with the constant value 1/(2r + 1)², so the filter is separable: it can be computed as a horizontal pass followed by a vertical pass.

Efficient computation and properties

Because the kernel is uniform, box blurs can be computed in constant time per pixel regardless of radius using sliding-window sums or summed-area tables (integral images). Applying a box blur repeatedly (three times is a common trick) approximates a Gaussian blur, an application of the central limit theorem. Unlike a true Gaussian blur, however, a single box blur can produce visible artefacts such as ringing and square-shaped bokeh. Box blurs are widely used in image editors, real-time graphics, and as a preprocessing step in computer vision.
