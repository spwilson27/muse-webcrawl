Executable and Linkable Format

From Wikipedia, the free encyclopedia

The Executable and Linkable Format (ELF, formerly named Extensible Linking Format) is a common standard file format for executable files, object code, shared libraries, and core dumps. It was developed by Unix System Laboratories as part of the Application Binary Interface for Unix System V, and was first published in the late 1980s. ELF has since become the standard binary format on most Unix and Unix-like operating systems, including Linux and the modern BSDs, displacing the older a.out and COFF formats.

Structure

An ELF file begins with an ELF header, identified by the magic number 0x7F followed by the ASCII letters E, L, F. The header records, among other things, whether the file uses 32-bit or 64-bit addressing, its byte order (endianness), the target instruction set architecture, and the file type: relocatable object, executable, shared object, or core dump. Following the header are a program header table, describing segments used by the loader at run time, and a section header table, describing sections used by the linker and debugger.

The two views of the file are complementary: the linker works with sections such as .text (code), .data (initialized data), .bss (uninitialized data), and symbol tables, while the operating system's program loader works with loadable segments. Tools such as readelf and objdump are used to inspect ELF files.

Adoption

ELF is used not only for user programs on Linux and BSD systems but also for their kernels, and it is the object format of the GNU toolchain. Many game consoles, embedded systems, and mobile devices also use ELF. Windows, by contrast, uses the Portable Executable (PE) format, and macOS uses Mach-O.
