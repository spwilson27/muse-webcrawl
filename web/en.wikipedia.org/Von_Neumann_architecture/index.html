Von Neumann architecture

The von Neumann architecture is a computer architecture model based on the stored-program concept, in which program instructions and data are held in the same read-write memory and processed by a central processing unit connected to that memory by a single bus. It is described in John von Neumann's 1945 First Draft of a Report on the EDVAC and underlies the design of nearly all modern digital computers.

Description

The architecture consists of a central processing unit containing an arithmetic logic unit and processor registers, a control unit containing an instruction register and program counter, a memory unit storing both data and instructions, external mass storage, and input and output mechanisms. Because instructions are stored in memory just like data, programs can be loaded, modified, and even modify themselves — the foundation of compilers, operating systems, and general-purpose computing.

The von Neumann bottleneck

The single connection between CPU and memory is known as the von Neumann bottleneck: throughput between the processor and memory is limited compared with the amount of memory, so the CPU often sits idle waiting for data. Modern designs mitigate this with cache hierarchies, pipelining, and separate instruction and data caches (a modified Harvard architecture at the cache level), but the fundamental model remains. The term was popularised by John Backus in his 1977 Turing Award lecture, which criticised the architecture's influence on programming language design.
