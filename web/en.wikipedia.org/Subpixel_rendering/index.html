Subpixel rendering

Subpixel rendering is a method used to increase the apparent resolution of a computer display. It takes advantage of the fact that each pixel on a colour liquid-crystal display (LCD) or similar display is composed of individual red, green, and blue subpixel components, arranged in a regular geometry. By lighting subpixels independently, text and graphics can be rendered with effectively three times the horizontal resolution of whole-pixel rendering.

How it works

Instead of treating each pixel as a single unit of light, subpixel rendering addresses each colour component separately. When rendering a diagonal edge of a letterform, the renderer can light, for example, only the red and green subpixels of a boundary pixel, producing a perceived luminance that the eye resolves more sharply than the pixel grid would otherwise allow. The trade-off is colour fringing: because neighbouring subpixels have different colours, poorly tuned rendering can leave coloured halos along edges.

Implementations

The best-known implementation is Microsoft's ClearType, introduced with Windows XP in 2001 and tuned for the common RGB or BGR stripe layout of LCD panels. Apple's macOS used subpixel antialiasing until macOS Mojave (2018), when it was removed as high-density Retina displays made it less necessary. PenTile matrix displays, common in OLED phones, use non-stripe subpixel layouts that require adapted rendering algorithms.
