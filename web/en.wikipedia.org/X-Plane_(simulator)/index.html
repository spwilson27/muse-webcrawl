X-Plane (simulator)

Image placeholder: X-Plane flight simulator screenshot

X-Plane is a flight simulation software initially launched by Laminar Research in 1995. Commercial desktop versions are marketed for macOS, Windows, and Linux, while mobile versions exist for iOS and Android; X-Plane is also used in professional FAA-certified simulators.

Simulation model

Unlike many simulators that use precomputed flight models, X-Plane uses blade element theory, computing the aerodynamic forces on many small sections of each aircraft surface simultaneously. This allows plausible flight characteristics for unusual designs.

Versions

Major releases include X-Plane 10 (2011), X-Plane 11 (2017), and X-Plane 12 (2022), which added a new weather engine and revised lighting. The simulator ships with global scenery and thousands of airports, and supports an extensive third-party add-on ecosystem.
