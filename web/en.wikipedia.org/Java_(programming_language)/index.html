Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible. Its "write once, run anywhere" philosophy means compiled Java code runs on any platform supporting a Java Virtual Machine (JVM) without recompilation.

History

Java was developed by James Gosling and colleagues at Sun Microsystems — the project, begun in 1991, was originally called Oak — and first released in 1995. It became hugely popular for enterprise software, web applications, and later as the principal language of Android app development. Sun released much of Java under open-source terms as OpenJDK in 2006–2007; after Oracle acquired Sun in 2010, Oracle became the steward of the platform, moving to a six-month release cadence in 2018.

Language and platform

Java syntax derives largely from C and C++ but with automatic memory management (garbage collection) and without low-level facilities such as explicit pointers. Programs compile to bytecode executed by the JVM, which uses just-in-time compilation for performance. The ecosystem includes a vast standard library, frameworks such as Spring, and sibling JVM languages including Kotlin, Scala, Groovy, and Clojure. Despite its similar name, Java bears little relation to JavaScript.
