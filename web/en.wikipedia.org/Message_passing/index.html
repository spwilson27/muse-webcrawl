Message passing

In computer science, message passing is a technique for invoking behavior — such as running a subroutine or method — on a remote or local computer program, as distinct from direct naming. The caller sends a message to a process or object, and the recipient decides how to respond.

Models

Message passing may be synchronous (the sender waits for a reply, as in a remote procedure call) or asynchronous (messages are queued and the sender continues). The actor model, developed by Carl Hewitt, formalizes computation entirely in terms of actors exchanging messages. Distributed systems use message passing over networks through libraries such as MPI (Message Passing Interface), widely used in high-performance computing.

Message passing versus shared memory

Message-passing systems avoid shared mutable state, which simplifies reasoning about concurrency and allows scaling across machines, at the cost of copying data. Languages such as Erlang and Go's channels are designed around message passing; its maxim in Go is "share memory by communicating."
