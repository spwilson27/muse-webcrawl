User interface

From Wikipedia, the free encyclopedia

A graphical user interface lets users interact with a computer through windows, icons, menus and a pointer.

In the industrial design field of human–computer interaction, a user interface (UI) is the space where interactions between humans and machines occur. The goal of this interaction is to allow effective operation and control of the machine from the human end. In order to achieve this, the user interface must be intuitive, efficient and enjoyable to use.

Generally, the goal of user interface design is to produce an interface which makes it easy (self-explanatory), efficient and user-friendly to operate a machine in the way which produces the desired result — which usually means the operator needs to provide minimal input to achieve the desired output, and also that the machine minimizes undesired outputs to the user.

Overview

User interfaces are composed of one or more layers, including a human–machine interface (HMI) which connects machines with physical input hardware (such as keyboards, mice or game pads) and output hardware (such as monitors, speakers and printers). A device which implements an HMI is called a human interface device (HID). In computing, the term user interface usually refers to the graphical user interface displayed on a screen, but voice, gesture, touch and command-line interfaces are also widely used.

History

Batch and command-line interfaces

Early computers were operated in batch mode, with jobs submitted on punched cards and results returned hours later; there was effectively no interactive interface. Time-sharing systems of the 1960s introduced teletypes and then video terminals with command-line interfaces (CLIs), in which the user types commands and the system responds with text.

The graphical user interface

The modern GUI grew out of research at SRI International and Xerox PARC in the 1960s–70s: Douglas Engelbart's 1968 "Mother of All Demos" showed the mouse, windows and hypertext, and the Xerox Alto (1973) and Star (1981) developed the desktop metaphor. Apple popularized it with the Lisa (1983) and Macintosh (1984), and Microsoft Windows brought it to mass-market PCs by the early 1990s. The WIMP paradigm — windows, icons, menus, pointer — dominated desktop computing for decades.

Touch and beyond

Capacitive multitouch screens, popularized by the iPhone in 2007, made direct manipulation the default for mobile devices. More recent interfaces include voice user interfaces (smart speakers and assistants), gesture and gaze control, augmented and virtual reality interfaces, and conversational agents.

Design

User interface design is a discipline drawing on cognitive psychology, graphic design and software engineering. Widely taught principles include visibility of system status, matching the system to the real world, user control and freedom, consistency, error prevention, recognition rather than recall, flexibility, aesthetic and minimalist design, and help and documentation (Nielsen's heuristics). Usability testing — observing representative users attempting representative tasks — is a central evaluation method, alongside expert review and analytics.
