Null set

FieldMeasure theory
Notationμ(S) = 0
RelatedEmpty set, almost everywhere

In mathematical analysis, a null set is a set that can be covered by a countable union of intervals of arbitrarily small total length — equivalently, a set of measure zero. In a general measure space, a set S is null if there exists a measurable set of measure zero containing it.

Definition

A subset S of the real line is a null set if, for every ε > 0, there is a countable collection of intervals whose union covers S and whose total length is less than ε. Every countable set is null: its points can be covered one by one by intervals of length ε/2, ε/4, ε/8, and so on. Remarkably, some uncountable sets are also null — the classic example is the Cantor set, which has the cardinality of the continuum but Lebesgue measure zero.

Properties

The collection of null sets is closed under subsets and countable unions. A property that holds for all points outside a null set is said to hold almost everywhere. Null sets are central to the Lebesgue theory of integration: two functions that differ only on a null set have the same integral, and changing a function's values on a null set does not affect its integrability.

Null set versus empty set

A null set need not be empty; indeed, there are null sets containing infinitely many — even uncountably many — points. The empty set is null trivially. In probability theory, events of probability zero are null sets, yet they may still occur in principle; a randomly chosen real number in [0, 1] lands on any specified value with probability zero.
