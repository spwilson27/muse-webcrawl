Cantor's diagonal argument

Cantor's diagonal argument is a mathematical proof devised by Georg Cantor and published in 1891, demonstrating that there are infinite sets which cannot be put into one-to-one correspondence with the set of natural numbers. In particular, the real numbers are uncountable: any attempted list of them necessarily omits some.

The argument

Suppose, for contradiction, that all real numbers between 0 and 1 could be enumerated as an infinite list r₁, r₂, r₃, …. Write each number's decimal expansion in rows, so the entries form an infinite array. Now construct a new number whose n-th decimal digit differs from the n-th digit of rₙ — for example, by adding 1 (avoiding 0 and 9 to sidestep dual expansions such as 0.3999… = 0.4000…). The constructed number lies between 0 and 1, yet differs from every row in at least one digit, so it cannot appear anywhere in the list. This contradiction shows that no such complete enumeration exists.

Consequences

The argument establishes that the cardinality of the real numbers (the cardinality of the continuum) is strictly greater than that of the natural numbers, and it underpins Cantor's theorem that the power set of any set has strictly greater cardinality than the set itself. Hence there is an unending hierarchy of infinite cardinalities.

Related results

Diagonalization became a foundational technique far beyond set theory. Variants appear in Cantor's earlier 1874 proof of uncountability, in Russell's paradox, in Gödel's incompleteness theorems, and in Turing's proof that the halting problem is undecidable — all arguments that proceed by constructing an object that differs from every member of an assumed enumeration.
