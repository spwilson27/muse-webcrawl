Servo is an experimental, open-source browser engine designed to take advantage of modern multi-core hardware through fine-grained parallelism and to improve memory safety by being written in the Rust programming language. The project was started by Mozilla Research in 2012, with engineering contributions from Samsung, and it served as a testbed whose technologies were later incorporated into Firefox's Gecko engine.

Features and influence

Servo renders pages using parallel layout, styling and painting, and uses WebGL and WebRender for GPU-accelerated compositing. Components developed within or alongside Servo — notably WebRender and the Stylo CSS engine — were integrated into Firefox starting with the Firefox Quantum release (57) in 2017, substantially improving its performance. Servo supports embedding in applications through an API, and has been ported to platforms including Linux, macOS, Windows, Android and embedded devices; it was also used in Mozilla's mixed-reality browsers.

Governance

In August 2020, amid layoffs at Mozilla, the Servo project was transferred to the Linux Foundation, and in 2023 stewardship moved to Linux Foundation Europe with a Technical Steering Committee; Igalia became a major contributor, refocusing Servo as an embeddable web engine for applications and embedded systems. The project joined the Rust ecosystem's broader effort to provide a safe, parallel alternative to legacy C++ browser engines.
