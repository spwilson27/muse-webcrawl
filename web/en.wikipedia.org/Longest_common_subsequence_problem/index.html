Longest common subsequence problem

The longest common subsequence (LCS) problem is the problem of finding the longest subsequence common to all sequences in a set of sequences, often two sequences. A subsequence is obtained by deleting some or no elements without changing the order of the remaining elements. Unlike substrings, subsequences need not occupy consecutive positions.

Applications

LCS is the basis of diff utilities that compare files, version control merge tools, and bioinformatics methods comparing DNA, RNA and protein sequences. It is closely related to edit distance.

Algorithms

For two sequences of lengths m and n, dynamic programming solves the problem in O(mn) time and space by filling a table of LCS lengths for prefixes. Hirschberg's algorithm reduces space to linear while also recovering a subsequence. For multiple sequences the problem is NP-hard. The Hunt–Szymanski algorithm is efficient when matches are sparse.
