TeamSpeak

TeamSpeak (TS) is a proprietary voice-over-Internet Protocol (VoIP) application for audio communication between users on a chat channel, much like a telephone conference call. Users typically use headphones with a microphone. The desktop client connects to a TeamSpeak server of the user's choice, from which the user may join chat channels.

The target audience for TeamSpeak is network video gamers, who can use the software to communicate with other players on the same team of a multiplayer video game. Communicating by voice gives a competitive advantage by enabling players to keep their hands on the controls.

History

TeamSpeak was first released in 2001, at a time when voice communication in online gaming was still a niche activity. It grew rapidly in popularity among gaming communities because it used very little bandwidth compared to alternatives of the era, such as Roger Wilco. The client is developed by TeamSpeak Systems GmbH, based in Germany.

Client

The TeamSpeak client is available for Windows, macOS, Linux, iOS, and Android. It connects to servers using a system of channels and sub-channels, within which users can talk, share files, and set permissions. Server administrators can assign user groups with different privilege levels, and channels can be password-protected.

Server

The TeamSpeak server software can be hosted by users on their own hardware or rented from authorized hosting providers. A free server license supports a limited number of slots, while commercial licenses allow larger communities and multiple virtual servers on a single instance.

TeamSpeak 5

A redesigned client, marketed as TeamSpeak 5, entered beta in 2019. It introduced a modernized interface, built-in text chat improvements, and additional social features while retaining compatibility with existing TeamSpeak 3 servers.
