Response surface methodology

Response surface methodology (RSM) is a collection of statistical and mathematical techniques, introduced by George E. P. Box and K. B. Wilson in 1951, used to model and optimise processes in which a response of interest is influenced by several variables.

Approach

An experimenter designs a set of experiments (often using central composite or Box–Behnken designs), fits a polynomial — typically quadratic — model to the observed response, and uses the fitted "surface" to find settings of the input variables that give a desired response: a maximum, minimum, or target value. The method of steepest ascent guides experiments toward the optimal region when starting far from the optimum.

Applications

RSM is widely used in chemical and process engineering, manufacturing, agriculture and product formulation, where running experiments is costly and a sequential, model-based search is efficient.
