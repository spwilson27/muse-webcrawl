A database is an organised collection of data stored and accessed electronically through a computer system. Databases are managed by a database management system (DBMS), software that provides for efficient storage, retrieval, updating, and administration while enforcing consistency and security. Together, the database and DBMS form the backbone of most information systems, from banking and reservations to websites and scientific archives.

History

Computerised databases emerged in the 1960s with navigational (hierarchical and network) systems. In 1970 Edgar F. Codd of IBM proposed the relational model, in which data are organised into tables of rows and columns and manipulated with declarative queries. Relational systems and the SQL language came to dominate by the late 1980s. From the 2000s, web-scale applications spurred "NoSQL" systems — document, key–value, wide-column, and graph stores — trading strict consistency for scalability and flexibility.

Key concepts

Relational databases guarantee the ACID properties (atomicity, consistency, isolation, durability) for transactions. A schema defines tables, keys, and constraints; indexes accelerate lookups; and normalization reduces redundancy. Query optimisers translate SQL into efficient execution plans.

Types and uses

Databases are classified as operational (OLTP) or analytical (OLAP, data warehouses and lakes), centralised or distributed, embedded or cloud-hosted. Major systems include Oracle, MySQL, PostgreSQL, Microsoft SQL Server, MongoDB, and Redis.
