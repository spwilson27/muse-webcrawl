Virtual machine

In computing, a virtual machine (VM) is the virtualization or emulation of a computer system. Virtual machines are based on computer architectures and provide the functionality of a physical computer. Their implementations may involve specialized hardware, software, or a combination of the two. System virtual machines substitute for a real computer and allow multiple operating systems to run simultaneously on a single physical machine, while process virtual machines — such as the Java virtual machine — provide a platform-independent environment for executing individual programs.

Managed byHypervisor (system VMs)
ExamplesVMware ESXi, KVM, Hyper-V, Xen, JVM
Key benefitsIsolation, consolidation, portability

System virtual machines

System VMs are created and managed by a hypervisor, also called a virtual machine monitor (VMM). A Type 1 ("bare metal") hypervisor runs directly on the host hardware; a Type 2 hypervisor runs as an application on a conventional operating system. Each guest operating system believes it controls real hardware, while the hypervisor multiplexes CPU, memory, storage and network resources among the guests. Hardware-assisted virtualization (such as Intel VT-x and AMD-V) makes this efficient enough for production use, enabling server consolidation, live migration of running VMs, snapshots, and the infrastructure underlying cloud computing.

Process virtual machines

A process VM, sometimes called an application virtual machine, runs as a normal application inside a host operating system and supports a single process. It lets programs written for an abstract instruction set — for example, Java bytecode or .NET's intermediate language — run unchanged on any platform that provides the VM. Such runtimes typically use just-in-time compilation to translate the abstract code into fast native machine code.

History

Virtual machines originated with IBM's CP-40 and CP-67 systems of the 1960s and the VM/370 mainframe operating system of 1972. Virtualization declined on minicomputers and PCs in the 1980s–90s, then revived dramatically from 1999 onward when VMware brought it to x86 servers. Today virtual machines are a foundational technology of data centers, desktop testing, legacy-system emulation and cloud infrastructure as a service.
