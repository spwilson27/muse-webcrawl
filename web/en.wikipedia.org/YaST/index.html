YaST

YaST (Yet another Setup Tool) is the installation and configuration tool for the openSUSE and SUSE Linux Enterprise families of Linux distributions. It provides a unified control centre from which administrators can install the operating system, manage software packages, configure hardware, set up network services and administer users and security settings. YaST can run with a graphical (Qt) interface or a text-mode (ncurses) interface.

History

YaST was developed by the German company SuSE beginning in the mid-1990s as the installer for its distribution. YaST2, a major rewrite, appeared around 1999–2000, unifying installation and system administration in a single modular framework. Originally proprietary, its source code was released under the GNU General Public License in 2004, after Novell's acquisition of SUSE. Modern YaST is written primarily in Ruby (converted from its former YCP language by the automated Y2R tool) and is structured as a collection of modules built on the libyui interface-abstraction library.

Features

  • Installer: guides partitioning, package selection, localisation and first-boot configuration.
  • Software management: a front end to the ZYpp/libzypp package stack for installing, updating and removing RPM packages.
  • Administration modules: users and groups, firewall, network, services, printers, bootloader, system log viewer and more.
  • AutoYaST: a system for fully automated, profile-driven installation and cloning of machines, widely used in enterprise deployments.
