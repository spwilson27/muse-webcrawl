SWI-Prolog is a free, open-source implementation of the Prolog programming language, developed principally by Jan Wielemaker at the University of Amsterdam. The name derives from Sociaal-Wetenschappelijke Informatica ("Social Science Informatics"), the group where development began.

Features

SWI-Prolog offers a rich development environment with a graphical debugger, extensive libraries for web programming (HTTP servers, HTML generation), semantic web support (RDF, OWL), constraint logic programming, and interfaces to other languages. It supports multithreading and tabling and runs on Windows, macOS and Unix-like systems.

Use

It is used in teaching, research and commercial applications including natural language processing, expert systems and semantic web tooling.
