In computer networking, the maximum transmission unit (MTU) is the size of the largest protocol data unit that can be communicated in a single network layer transaction. The MTU is a property of a communications link and is related to, but distinct from, the maximum frame size of the underlying data link layer.

Significance

Larger MTUs allow more data to be sent in each packet relative to protocol header overhead, improving efficiency and throughput. However, large packets occupy a link for longer and, if lost, cost more to retransmit. Packets larger than the MTU of a link must be split by fragmentation (in IPv4) or dropped with an error message so that the sender can perform path MTU discovery — a common source of problems when ICMP messages are blocked by firewalls, producing "black hole" connections.

Typical values

Standard Ethernet uses an MTU of 1,500 bytes; many data-centre and campus networks support jumbo frames of about 9,000 bytes. Point-to-point links over PPPoE commonly use 1,492 bytes, and tunnels and VPNs reduce the effective MTU further, which is why TCP implementations clamp the maximum segment size (MSS) on such connections. IPv6 requires every link to support an MTU of at least 1,280 bytes and forbids fragmentation by routers.

Path MTU discovery

Hosts determine the smallest MTU along a path either by probing with the IPv4 "Don't Fragment" flag and processing ICMP "Fragmentation Needed" replies, or by packetization-layer probing (RFC 4821), which is more robust against filtered ICMP.
