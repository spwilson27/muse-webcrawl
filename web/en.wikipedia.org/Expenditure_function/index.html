Expenditure function

In microeconomics, the expenditure function gives the minimum amount of money an agent needs to spend to achieve a given level of utility, given a vector of prices. Formally, for prices p and target utility u, it is defined as e(p, u) = min { p · x : u(x) ≥ u } — the value function of the expenditure minimization problem, which is dual to the utility maximization problem.

Properties

Where the utility function is continuous and locally non-satiated, the expenditure function is homogeneous of degree one in prices, non-decreasing in prices and utility, and concave in prices. By Shephard's lemma, its partial derivative with respect to the price of a good yields the Hicksian (compensated) demand for that good.

Duality

The expenditure function is the exact inverse of the indirect utility function: e(p, v(p, m)) = m and v(p, e(p, u)) = u. This duality lets economists translate between observed Marshallian demand behaviour and welfare concepts such as compensating variation and equivalent variation, which are computed directly from the expenditure function. For example, compensating variation for a price change is e(p¹, u⁰) − e(p⁰, u⁰).
