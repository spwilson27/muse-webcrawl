Barabási–Albert model

The Barabási–Albert (BA) model is an algorithm for generating random scale-free networks using a preferential attachment mechanism. Proposed by Albert-László Barabási and Réka Albert in 1999, it was one of the first models to explain the scale-free degree distributions observed in many real-world networks, such as the World Wide Web and citation networks.

The algorithm

The network begins with an initial connected network of m0 nodes. New nodes are added one at a time; each new node connects to m existing nodes with a probability proportional to the number of links those nodes already have. Formally, the probability that a new node connects to node i is proportional to the degree ki of that node. This "rich get richer" rule is known as preferential attachment.

Properties

Networks generated by the model have a power-law degree distribution with exponent 3, independent of the parameter m. The model produces hubs — a small number of very highly connected nodes — and has a small average path length, though it does not capture the high clustering found in many real networks, which motivated later variants such as the fitness model and models with triad formation.
