Axiom of power set

[Image placeholder: the power set of {x, y, z} shown as a lattice]

In axiomatic set theory, the axiom of power set is one of the Zermelo–Fraenkel axioms. It states that for any set x there exists a set y which is the power set of x: the set whose members are exactly all the subsets of x. In symbols, the power set of x is denoted 𝒫(x).

Formal statement

The axiom asserts: for every set x there is a set y such that for every set z, z is a member of y if and only if every element of z is an element of x (that is, z ⊆ x). The axiom of extensionality then guarantees that this power set is unique.

Consequences

If a set has n elements, its power set has 2n elements. Cantor's theorem shows that the power set of any set is strictly larger than the set itself, so iterating the power-set operation generates an endless hierarchy of ever-larger infinite cardinalities. Together with the axiom of infinity, the power-set axiom allows the construction of the real numbers (for example as Dedekind cuts, which are subsets of the rationals) within set theory.

Role in set theory

The axiom is used in forming the von Neumann cumulative hierarchy, where each stage Vα+1 is the power set of the previous stage. Some weaker systems of set theory, such as Kripke–Platek set theory, omit the power-set axiom and treat "power set" as a relation rather than an operation.
