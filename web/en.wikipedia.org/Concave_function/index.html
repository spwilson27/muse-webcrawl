Concave function

In mathematics, a concave function is one for which the value at any convex combination of points in its domain is greater than or equal to the corresponding convex combination of the function values. Equivalently, a function is concave if its hypograph (the set of points on or below the graph) is a convex set. A concave function is also called concave downwards, convex upwards, or simply "concave" in some older texts.

Definition

A continuous function f on an interval is concave if, for any two points x and y in the interval and any t in [0, 1], f((1 − t)x + ty) ≥ (1 − t)f(x) + tf(y). A function is strictly concave if the inequality is strict whenever x ≠ y and t is strictly between 0 and 1.

Properties

A differentiable function is concave if and only if its derivative is monotonically decreasing. A twice-differentiable function is concave if and only if its second derivative is non-positive everywhere. Concave functions play a central role in economics, where concave utility and production functions model diminishing returns and risk aversion. A function that is both concave and convex is affine.
