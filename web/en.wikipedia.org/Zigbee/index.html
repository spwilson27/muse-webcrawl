Zigbee

StandardIEEE 802.15.4-based
Frequency bands2.4 GHz (worldwide), 915 MHz (Americas), 868 MHz (Europe)
Data rate20–250 kbit/s
Range10–100 m (line of sight)
Network topologyStar, tree, mesh
Maintained byConnectivity Standards Alliance

Zigbee is an IEEE 802.15.4-based specification for a suite of high-level communication protocols used to create personal area networks with small, low-power digital radios. It is designed for low-data-rate, low-power applications such as home automation, wireless sensor networks, lighting control and smart metering.

Overview

Zigbee networks use mesh networking: mains-powered devices act as routers that relay traffic for battery-powered end devices, which can sleep most of the time and run for years on a small battery. A network is managed by a single coordinator. Data rates are modest — up to 250 kbit/s in the 2.4 GHz band — but are ample for sensors, switches and control messages.

Applications

The protocol underlies many smart-home products, including connected light bulbs, locks and thermostats, as well as industrial monitoring and medical data collection systems. Zigbee 3.0, released in 2016, unified the previously separate application profiles into a single standard. The Zigbee specification is maintained by the Connectivity Standards Alliance (formerly the Zigbee Alliance), which also develops the Matter standard.
