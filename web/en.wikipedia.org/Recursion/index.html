Recursion

Recursion occurs when the definition of a concept or process depends on a simpler or previous version of itself. Recursion is used in a variety of disciplines ranging from linguistics to logic. The most common application of recursion is in mathematics and computer science, where a function being defined is applied within its own definition. While this apparently defines an infinite number of instances, it is often done in such a way that no infinite loop or infinite regress can occur, because a base case terminates the chain.

Formal definitions

In mathematics and computer science, a class of objects or methods exhibits recursive behaviour when it can be defined by two properties: a base case (or cases), which terminates the recursion, and a set of rules that reduce all successive cases toward the base case. For example, the factorial function is defined recursively by:

n! = n × (n − 1)!   for n > 0
0! = 1

Recursion in computer science

A common method of simplification is to divide a problem into subproblems of the same type; this technique is known as divide and conquer and is the key to algorithms such as quicksort and mergesort, and to searching tree data structures. Recursive procedures push activation records onto the call stack; excessively deep recursion can cause a stack overflow. Some languages optimise tail recursion into iteration.

Recursive data types

Many data structures are defined recursively: a linked list is either empty or a node pointing to a list; a binary tree is either empty or a node with two subtrees. Grammars in formal language theory are also typically recursive, as in the Backus–Naur form used to describe programming languages.

Recursion in language

Linguist Noam Chomsky and others have argued that the recursive property of natural language — the ability to embed phrases within phrases, as in "the cat that chased the rat that stole the cheese" — is a defining feature of human grammar and possibly of human cognition itself. This claim has been debated, notably regarding the Pirahã language.

Recursion in art

Visual recursion appears in the Droste effect, where an image contains a smaller version of itself, famously used by M. C. Escher in works such as Print Gallery. Russian matryoshka nesting dolls are a physical analogue.
