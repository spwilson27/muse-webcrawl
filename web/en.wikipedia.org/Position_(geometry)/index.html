Position (geometry)

A position vector r locating a point P relative to an origin O.

In geometry, a position or position vector, also known as location vector or radius vector, is a Euclidean vector that represents a point P in space. Its length represents the distance in relation to an arbitrary reference origin O, and its direction represents the angular orientation with respect to given reference axes. Usually denoted x, r, or s, it corresponds to the straight line segment from O to P.

Definition

For a point P in a coordinate system with origin O, the position vector is defined as r = OP. In a three-dimensional Cartesian system, if P has coordinates (x, y, z), then r = xi + yj + zk, where i, j, k are unit vectors along the axes. The set of all position vectors forms a vector space.

Applications

Position vectors are fundamental in kinematics, where the position of a moving object is expressed as a function of time; its derivative with respect to time is the velocity vector, and the second derivative is the acceleration. In differential geometry, position vectors relative to a local frame are used to define curves and surfaces. Relative position, the difference of two position vectors, gives the displacement between two points.
