The Möbius function μ(n) is a multiplicative function in number theory introduced by August Ferdinand Möbius in 1832. It takes the values −1, 0 or 1 depending on the factorisation of n into prime factors.

Definition

μ(n) is defined for all positive integers n as follows: μ(n) = 0 if n is divisible by the square of a prime; μ(n) = 1 if n is a product of an even number of distinct primes; and μ(n) = −1 if n is a product of an odd number of distinct primes. By convention μ(1) = 1.

Properties

The Möbius function is the basis of the Möbius inversion formula, which recovers a function from its divisor sums. Its summatory function, the Mertens function, is connected with the distribution of the primes, and the statement that the Mertens function grows more slowly than any power of n is equivalent to the prime number theorem; a stronger bound of the form O(n1/2+ε) is equivalent to the Riemann hypothesis.
