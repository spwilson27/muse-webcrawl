UTF-8

ClassificationUnicode Transformation Format, variable-width encoding
DesignersKen Thompson, Rob Pike
First published1993
ExtendsASCII
StandardRFC 3629, Unicode Standard

UTF-8 is a variable-length character encoding standard used for electronic communication. Defined by the Unicode Standard, the name is derived from Unicode Transformation Format – 8-bit. UTF-8 is capable of encoding all 1,112,064 valid Unicode code points using one to four one-byte (8-bit) code units. Code points with lower numerical values — which tend to occur more frequently — are encoded using fewer bytes.

History

UTF-8 was designed by Ken Thompson and Rob Pike for the Plan 9 operating system, with the encoding scheme sketched on a placemat in September 1992. It was introduced publicly at the USENIX conference in January 1993 and was later adopted as an Internet standard in RFC 3629 (2003). UTF-8 has since become the dominant character encoding for the World Wide Web, used by the vast majority of web pages, and is the required or recommended encoding in most modern standards and programming environments.

Design

The first 128 characters of Unicode — corresponding exactly to ASCII — are encoded in a single byte identical to their ASCII representation, making valid ASCII text valid UTF-8 text. Subsequent code points use two, three, or four bytes, with the leading bits of the first byte indicating how many bytes follow. A key property is self-synchronisation: because the byte patterns for leading and continuation bytes are distinct, a reader can find the start of a character even when entering a stream mid-way. No valid character's encoding is a prefix of another's, and sorting UTF-8 text byte-by-byte preserves code-point order.
