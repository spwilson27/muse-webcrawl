Advanced Packaging Tool

The Advanced Packaging Tool (APT) is a free software user interface that works with core libraries to handle the installation and removal of software on Debian and Debian-based Linux distributions such as Ubuntu. APT simplifies managing software packages by automatically resolving dependencies and retrieving packages from configured repositories.

Usage

APT's principal command-line tools are apt, apt-get, and apt-cache. Commands such as apt update refresh repository indexes, apt install adds packages with their dependencies, and apt upgrade updates installed software. APT works on top of the lower-level dpkg tool, which installs individual .deb files. Repositories are listed in /etc/apt/sources.list and related files, and packages are authenticated with GPG signatures.

History

APT was introduced with Debian 2.1 in 1999 and became a model for package managers on other systems. Graphical front-ends such as Synaptic and distro software centres build on its libraries, and APT has also been ported to RPM-based systems and macOS (via Fink).
