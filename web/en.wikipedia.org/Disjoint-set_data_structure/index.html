Disjoint-set data structure

In computer science, a disjoint-set data structure, also called a union–find data structure or merge–find set, stores a collection of disjoint (non-overlapping) sets. It supports three operations: MakeSet, which creates a set containing a single element; Find, which determines which set an element belongs to, returning a canonical representative; and Union, which merges two sets.

Implementation and complexity

The standard implementation represents each set as a rooted tree, with the root as representative. Two heuristics make the structure extremely efficient: union by rank (or by size), which attaches the smaller tree under the larger, and path compression, which flattens trees during Find operations. Together they give an amortized running time of α(n) per operation, where α is the inverse Ackermann function — effectively constant for all practical input sizes.

Applications

Disjoint sets are used in Kruskal's algorithm for minimum spanning trees, in image segmentation and connected-component labelling, in percolation simulations, in maintaining equivalence classes in compilers, and in the unification algorithm of logic programming. The structure was analysed by Bernard Galler and Michael Fischer in 1964, with the classic complexity bound proved by Robert Tarjan in 1975.
