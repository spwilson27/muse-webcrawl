Pop out effect

The pop out effect (also known as pop-out) is a phenomenon of visual search in which a target item that differs from all surrounding distractor items in a single basic feature — such as colour, orientation, size or motion — is detected immediately, regardless of the number of distractors present. The contrasting case, in which the target is defined by a combination of features, requires slower, serial, attention-demanding search.

Pop out effect
FieldVisual perception, cognitive psychology
Key researcherAnne Treisman

Experimental findings

In visual search experiments, reaction time to find a single-feature target is essentially flat as the number of distractors increases (search slopes near 0 ms per item), whereas search for a conjunction target (for example, a red vertical bar among red horizontal and green vertical bars) increases by tens of milliseconds for each additional item. This dissociation motivated Anne Treisman and Garry Gelade's feature integration theory (1980), which proposed that individual features are registered pre-attentively in parallel across the visual field, while focused attention is needed to bind features into objects.

Features supporting pop-out

Features that support pop-out include colour, line orientation, curvature, size, brightness, motion, flicker, and certain shape properties; a lone tilted line among vertical lines, a moving item among stationary ones, or a single red item among green ones all pop out. The effect is explained by activity in feature maps and saliency maps in the visual system: a unique feature value generates a strong local signal that summons attention automatically.

Applications

Pop-out principles are applied in user-interface and information design: warnings, changed status indicators and rare symbols are rendered in a unique colour or shape so users can spot them without scanning, while critical designs avoid relying on conjunctions of features that require slow serial search.
