Process (computing)

In computing, a process is the instance of a computer program that is being executed by one or more threads. Depending on the operating system, a process may be made up of multiple threads of execution that execute instructions concurrently.

Components

A process typically includes the program code (text), a program counter and processor registers, a process stack, a data section containing global variables, and a heap for dynamically allocated memory. The operating system represents each process with a process control block and identifies it with a unique process identifier (PID).

States and scheduling

During its life a process moves through states such as new, ready, running, waiting (blocked) and terminated. The operating system's scheduler switches the CPU between processes, performing context switches that save and restore process state. Processes are often organized in a hierarchy of parents and children.

Inter-process communication

Processes are isolated in separate address spaces for protection; they exchange data through inter-process communication mechanisms such as pipes, message queues, shared memory and sockets. Lighter-weight alternatives for concurrency within a process are threads, which share the process's memory.
