Type3D rendering and augmented reality framework

RealityKit is a 3D rendering and augmented reality framework developed by Apple, introduced at WWDC 2019 alongside ARKit 3. Written natively in Swift, it provides a high-level, entity-component-system API for building AR experiences — rendering photorealistic 3D content, simulating physics, and anchoring virtual objects to the real world — without requiring developers to write low-level graphics code as with SceneKit or Metal.

Features

RealityKit handles physically based rendering, environment lighting, shadows, animation, spatial audio, and rigid-body physics. It integrates with ARKit for world tracking, plane detection, people occlusion, and face tracking. Content can be authored in the Reality Composer app and stored in the .reality and USDZ formats. RealityKit 2 (2021) added custom shaders and more flexible rendering pipelines, and the framework underpins AR and 3D apps on visionOS for the Apple Vision Pro.
