Spectral leakage

The Fourier transform of a function of time, s(t), is a complex-valued function of frequency, S(f), often referred to as a frequency spectrum. Any linear time-invariant operation on s(t) causes a new spectrum, so there is not really a distinction between the signal and its spectrum. But in practice we only have a finite segment of a signal, and we multiply the signal by a window function before computing the discrete Fourier transform (DFT). The result is that the spectrum of the windowed segment is the true spectrum convolved with the transform of the window — so energy from one frequency appears to "leak" into neighbouring frequencies. This effect is called spectral leakage.

Cause

Leakage occurs when the observed segment of a sinusoid does not contain an integer number of cycles; the implicit periodic repetition then contains a discontinuity, whose spectrum spreads across all frequencies. The amount and shape of leakage depends on the window: a rectangular window gives a narrow main lobe but high sidelobes (the sinc function), so strong components mask weak nearby ones. Windowing functions such as Hann, Hamming, and Blackman–Harris trade main-lobe width for much lower sidelobes, reducing leakage at the cost of frequency resolution.

Mitigation

Leakage is minimised by choosing a window function with low sidelobes, by zero-padding (which interpolates the spectrum but does not add information), by synchronous sampling so that an integer number of cycles is captured, and by windowing tapered at the segment edges. The related picket-fence effect describes the error when a signal frequency falls between DFT bins.
