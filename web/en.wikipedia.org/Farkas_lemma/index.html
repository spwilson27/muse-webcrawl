Farkas lemma

Farkas' lemma is a solvability theorem from linear algebra and convex geometry, named after Hungarian mathematician Gyula Farkas, who published it in 1902. It states that a system of linear inequalities either has a solution, or a certain alternative system has a solution, but not both.

In one common form: for a real matrix A and vector b, exactly one of the following holds — there exists x ≥ 0 with Ax = b, or there exists y with yTA ≥ 0 and yTb < 0.

The lemma is a key tool in proving the duality theorems of linear programming and results such as the separating hyperplane theorem and theorems of the alternative.
