Kolmogorov complexity

In algorithmic information theory, the Kolmogorov complexity of a string is the length of the shortest computer program (in a fixed universal programming language) that produces that string as output. It was independently introduced by Ray Solomonoff, Andrey Kolmogorov and Gregory Chaitin in the 1960s.

Properties

A string with a short description — such as a long run of repeated characters — has low complexity, whereas a random string is generally incompressible, its shortest program being nearly as long as itself. The invariance theorem shows the choice of universal language changes complexity only by an additive constant. Kolmogorov complexity itself is not computable, because determining the shortest program would solve the halting problem; the Berry paradox gives an intuitive proof.

Applications

The concept underlies theories of randomness, data compression, induction and the minimum description length principle, and is used in arguments about incompressibility in mathematics and computer science.
