Sobel operator

The Sobel operator, sometimes called the Sobel–Feldman operator or the Sobel filter, is used in image processing and computer vision, particularly within edge detection algorithms where it creates an image emphasising edges. It is named after Irwin Sobel and Gary M. Feldman, who presented the idea in 1968 at the Stanford Artificial Intelligence Laboratory.

Gradient magnitude image produced with the Sobel operator

Formulation

Technically, the operator uses two 3×3 kernels which are convolved with the original image to calculate approximations of the horizontal and vertical derivatives:

Gx = [ -1  0  +1 ]        Gy = [ +1  +2  +1 ]
     [ -2  0  +2 ]  * A        [  0   0   0 ]  * A
     [ -1  0  +1 ]             [ -1  -2  -1 ]

The gradient magnitude is computed as G = √(Gx² + Gy²), and its direction as θ = atan2(Gy, Gx). Because each kernel can be decomposed into a smoothing and a derivative component, the Sobel operator combines Gaussian smoothing with differentiation, making it relatively robust to noise for such a small kernel. It is computationally cheap and remains widely used, although Canny, Scharr, and Prewitt operators may be chosen for particular accuracy requirements.
