Cardinal number

FieldSet theory
Notation|A|, card(A), ℵ (aleph numbers)

In mathematics, a cardinal number, or cardinal for short, is a generalization of the natural numbers used to measure the cardinality (the size) of sets. The cardinality of a finite set is a natural number: the number of elements in the set. The transfinite cardinal numbers, often denoted with the Hebrew symbol ℵ (aleph), describe the sizes of infinite sets.

History

Cardinality was defined by Georg Cantor in the 1870s–1890s as part of his founding work on set theory. Cantor showed that the real numbers cannot be put into one-to-one correspondence with the natural numbers, proving that infinities come in different sizes.

Definition

Two sets have the same cardinal number if there exists a bijection between them. In modern set theory, a cardinal is usually defined as an ordinal number that cannot be put in bijection with any smaller ordinal, so that the cardinal of a set is the least ordinal equinumerous with it (assuming the axiom of choice).

Cardinal arithmetic

Exponentiation of cardinals leads to the continuum hypothesis, which asks whether the cardinality of the continuum, 2ℵ₀, equals ℵ₁; Kurt Gödel and Paul Cohen showed it is independent of the standard axioms of set theory.
