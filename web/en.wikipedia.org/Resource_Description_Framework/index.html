The Resource Description Framework (RDF) is a World Wide Web Consortium (W3C) standard originally designed as a data model for metadata. It has come to be used as a general method for description and exchange of graph data, and is a foundational technology of the Semantic Web.

Data model

RDF data is expressed as collections of triples, each consisting of a subject, a predicate, and an object. The subject is a resource identified by an IRI, the predicate expresses a relationship, and the object is either another resource or a literal value such as a string or number. A set of such triples forms a directed, labelled graph, in which resources are nodes and predicates are edges.

Serialisations

RDF graphs can be written in several syntaxes, including RDF/XML, Turtle, N-Triples, and JSON-LD. RDF data can be queried using the SPARQL query language and stored in specialised databases called triplestores.

Vocabularies and reasoning

RDF Schema (RDFS) and the Web Ontology Language (OWL) build on RDF to define vocabularies, classes, properties, and richer logical relationships that support inference over the data. Well-known vocabularies include Dublin Core, FOAF, and Schema.org.
