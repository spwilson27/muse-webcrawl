Imperative programming

In computer science, imperative programming is a programming paradigm that uses statements that change a program's state. In much the same way that the imperative mood in natural languages expresses commands, an imperative program consists of commands for the computer to perform. Imperative programming focuses on describing how a program operates, step by step.

The term is often used in contrast to declarative programming, which focuses on what the program should accomplish without specifying all the details of how the program should achieve the result.

History

The earliest imperative languages were machine languages, followed by assembly languages. High-level imperative programming developed with Fortran (1957), ALGOL, COBOL, and BASIC, and later Pascal and C. The von Neumann architecture — with memory, mutable variables, and sequential execution — strongly shaped the design of imperative languages.

Features

Imperative programs typically make use of variables and mutable state, assignment statements, control structures such as loops (for, while) and conditionals (if/else), and procedures or subroutines that group statements. Structured programming refined the paradigm by restricting arbitrary jumps (goto) in favor of these control structures.

Related paradigms

Procedural programming is a type of imperative programming organized around procedures or functions. Object-oriented programming extends imperative programming with objects that bundle state and behavior. Most widely used languages — including C, C++, Java, Python, and JavaScript — support imperative programming, often alongside other paradigms.
