wxWidgets (formerly wxWindows) is a free and open-source widget toolkit and library for creating graphical user interfaces (GUIs) for cross-platform applications. Written in C++, it allows a single codebase to be compiled for Microsoft Windows, macOS, Linux/Unix, and other platforms while using the native controls of each operating system.

History

Development began in 1992 by Julian Smart at the University of Edinburgh, initially to target both Windows 3.1 and Unix with Motif or XView. The project was renamed from wxWindows to wxWidgets in 2004 following a request from Microsoft. It has since been maintained by a team including Vadim Zeitlin and many contributors.

Features and bindings

Besides GUI components, wxWidgets provides classes for networking, multithreading, databases (ODBC), HTML rendering, and file handling. Language bindings exist for Python (wxPython), Perl, Ruby, Haskell, and others. Applications built with wxWidgets include Audacity, FileZilla, and KiCad.
