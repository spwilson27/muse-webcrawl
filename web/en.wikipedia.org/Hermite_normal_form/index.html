Hermite normal form

In linear algebra, the Hermite normal form is an analogue of reduced echelon form for matrices over the integers. Just as reduced echelon form can be used to solve problems about the solution set of a system of linear equations, the Hermite normal form can solve problems about the solution set of a system of linear Diophantine equations, in which the unknowns are required to be integers. The form is named after Charles Hermite, who introduced related ideas in 1851.

Definition

Several conventions are in use; one common version is the following. A nonsingular integer matrix is in (row-style) Hermite normal form if it is upper triangular, all its diagonal entries are positive, and each off-diagonal entry in a column lies between zero and one less than the diagonal entry of that column. Every nonsingular integer matrix can be transformed into a unique matrix in Hermite normal form by left-multiplication by a unimodular matrix (an integer matrix with determinant ±1), corresponding to a sequence of elementary integer row operations: swapping rows, negating a row, and adding an integer multiple of one row to another.

Lattices

A lattice in Zn can be described by many different bases, but the Hermite normal form of the matrix whose rows (or columns) form a basis gives a canonical representative of the lattice: two integer matrices generate the same lattice if and only if they have the same Hermite normal form. This makes the form a standard tool in lattice algorithms, integer programming, and computational number theory. The absolute value of the determinant of the Hermite normal form equals the index of the lattice in Zn.

Applications

Hermite normal form can be used to test whether a system of linear equations has an integer solution, to compute the structure of finitely generated abelian groups presented by integer matrices (in combination with the Smith normal form), and to compute kernels and images of integer matrices. Algorithms for computing it must control intermediate coefficient growth, a problem solved by modular and fraction-free methods developed in the twentieth century.
