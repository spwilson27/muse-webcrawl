The Apache Software Foundation (ASF) is an American non-profit corporation founded in 1999 to support a community of open-source software projects. It grew out of the Apache Group, the developers of the Apache HTTP Server, and now oversees several hundred projects.

History

The ASF was incorporated in Delaware in June 1999 by members of the Apache Group, which had formed in 1995 around patches to the NCSA HTTPd web server — the origin of the name "Apache" (a "patchy" server). The foundation provides legal, financial, and organisational infrastructure for its projects.

The Apache Way

Projects are governed by meritocratic, community-led principles known as "the Apache Way": decisions are made by consensus among contributors, and individuals earn committer and membership status through sustained contributions. New projects typically enter through the Apache Incubator.

Projects

Well-known Apache projects include the Apache HTTP Server, Hadoop, Spark, Kafka, Tomcat, Cassandra, Lucene/Solr, Maven, and OpenOffice. All ASF software is released under the Apache License, currently version 2.0 (2004).
