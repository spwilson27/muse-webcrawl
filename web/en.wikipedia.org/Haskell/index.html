Haskell, a purely functional programming language named for logician Haskell Curry.

Haskell is a general-purpose, statically-typed, purely functional programming language with type inference and lazy evaluation. Named after the logician Haskell Curry, it was designed by a committee formed in the late 1980s to create an open standard unifying the many functional languages of the time; the first version appeared in 1990, and the language was later standardized as Haskell 98 and Haskell 2010.

Features

Haskell programs are built from pure functions: expressions have no side effects, and effects such as input/output are represented in the type system, famously through the IO monad and other monads for state, exceptions, and nondeterminism. Its type system, derived from Hindley–Milner with type classes, supports powerful compile-time guarantees and equational reasoning. Lazy evaluation (call-by-need) allows infinite data structures and modular composition of programs.

Implementations and use

The main implementation is the Glasgow Haskell Compiler (GHC), an optimizing native-code compiler and interactive environment (GHCi). Haskell is used in academia, in finance, and in industry — including at Meta, where it powers the Sigma spam-fighting system, and in tools such as the Pandoc document converter and the xmonad window manager. Concepts pioneered or popularized in Haskell, including monads, type classes, and parser combinators, have influenced many other languages.

History

The committee that created Haskell included Paul Hudak, Simon Peyton Jones, Philip Wadler, and John Hughes. Successive language reports stabilized the core, while GHC extensions (such as generalized algebraic data types and type families) have driven much subsequent language evolution. The community maintains the Hackage package repository and the Cabal and Stack build tools.

Example

factorial :: Integer -> Integer
factorial 0 = 1
factorial n = n * factorial (n - 1)

quicksort :: Ord a => [a] -> [a]
quicksort [] = []
quicksort (p:xs) = quicksort [x | x <- xs, x < p]
                ++ [p]
                ++ quicksort [x | x <- xs, x >= p]
