BOOTP

The Bootstrap Protocol (BOOTP) is a computer networking protocol used in Internet Protocol networks to automatically assign an IP address to network devices from a configuration server. It was defined in RFC 951 in 1985.

Operation

A diskless client broadcasts a BOOTREQUEST containing its hardware (MAC) address. A BOOTP server replies with a BOOTREPLY giving the client its IP address, the server's IP address and the name of a boot file, which the client then downloads, typically with TFTP.

History

BOOTP succeeded the Reverse Address Resolution Protocol (RARP) and added the ability to convey a boot image name and vendor-specific information. It operates over UDP, using server port 67 and client port 68.

Successor

BOOTP was largely superseded by the Dynamic Host Configuration Protocol (DHCP), which was designed to be backward compatible with BOOTP relay agents while adding automatic, leased allocation of addresses. See also Preboot Execution Environment.
