Metaclass

For the concept in other languages, see class-object systems.

In object-oriented programming, a metaclass is a class whose instances are themselves classes. Just as an ordinary class defines the behaviour of its instances (objects), a metaclass defines the behaviour of classes and their instances. Not all object-oriented languages support metaclasses; among those that do, the extent to which metaclasses can override class behaviour varies widely. Metaclasses can be implemented by having classes be first-class objects, in which case the metaclass is simply the class of a class object.

Motivation

Metaclasses give a programmer a way to intercept class creation, customise how a class is built, enforce conventions, register subclasses automatically, add methods or attributes to every class created from the metaclass, and implement patterns such as singletons or class-level validation. In Python, the built-in type is the default metaclass; user code can define a subclass of type and assign it with the metaclass keyword in a class definition.

Python example

Defining class Meta(type): pass and then class Foo(metaclass=Meta): pass makes Meta the metaclass of Foo: calling Foo() first runs Meta.__call__, which in turn invokes the class's __new__ and __init__. Overriding __new__ or __init__ of the metaclass lets code modify the namespace dict before the class object exists.

Other languages

Smalltalk pioneered the idea: every class is an instance of its own unique metaclass, and Class and Metaclass are themselves part of the system. Ruby's singleton classes play a related role, Objective-C classes are objects whose classes are metaclasses created by the runtime, and languages such as CLOS (the Common Lisp Object System) provide a full metaobject protocol in which metaclasses are explicit and programmable.
