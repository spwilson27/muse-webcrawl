Linux is a family of open-source Unix-like operating systems based on the Linux kernel, first released by Finnish programmer Linus Torvalds in 1991. Strictly, "Linux" is the kernel — the core program that manages hardware, processes, memory and system calls — while a complete operating system combines it with system libraries and utilities, historically those of the GNU Project, in packaged collections called distributions. The kernel's mascot is Tux, a cartoon penguin.

History

Torvalds, a student at the University of Helsinki, began Linux as a personal project inspired by MINIX, announcing it on the comp.os.minix newsgroup in August 1991 ("just a hobby, won't be big and professional"). Released under the GNU General Public License, the kernel attracted contributions from programmers worldwide and became the centrepiece of the free and open-source software movement, alongside Richard Stallman's GNU Project. Through the 1990s, distributions such as Slackware, Debian and Red Hat brought Linux to servers; it came to dominate web hosting and, later, supercomputing — all of the TOP500 supercomputers run Linux — and, through Google's Android (which uses a modified Linux kernel), most of the world's smartphones.

Distributions and usage

Major distributions include Debian and its derivative Ubuntu, Fedora and Red Hat Enterprise Linux, Arch Linux, openSUSE and Gentoo, differing in package management, release cadence and philosophy. Linux powers web servers, cloud infrastructure (containers and Kubernetes are built on kernel features such as namespaces and cgroups), embedded devices, routers, smart televisions, and the majority of the world's web traffic; on the desktop it holds a small but persistent share, and Google's ChromeOS runs on it.

Design

The kernel is monolithic but modular: device drivers and filesystems can be loaded as modules at runtime. It supports preemptive multitasking, many CPU architectures, and is developed collaboratively through mailing lists and the git version-control system, which Torvalds created in 2005. New stable versions appear roughly every nine to ten weeks, coordinated by Torvalds and subsystem maintainers.
