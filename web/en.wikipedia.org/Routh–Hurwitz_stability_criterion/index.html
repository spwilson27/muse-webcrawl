Routh–Hurwitz stability criterion


A system is stable if all its poles lie in the open left half-plane

In control theory and stability theory, the Routh–Hurwitz stability criterion is a mathematical test that gives necessary and sufficient conditions for all roots of the characteristic polynomial of a linear time-invariant (LTI) system to have negative real parts — that is, for the system to be stable. The criterion was established independently by Edward John Routh in 1877 and Adolf Hurwitz in 1895.

Statement

Given a polynomial with real coefficients

p(s) = ansn + an−1sn−1 + ⋯ + a1s + a0,

the coefficients are arranged in the Routh array, a triangular table whose first two rows come directly from the polynomial and whose later entries are computed from determinants of the rows above. The Routh–Hurwitz criterion states that the number of roots in the right half-plane equals the number of sign changes in the first column of the array. The system is stable if and only if there are no sign changes, which (in the regular case) requires every entry in the first column to have the same sign.

Special cases

Two irregular situations arise. If an element of the first column is zero but its row is not, a small positive quantity ε is substituted and the test completed by examining signs as ε → 0. If an entire row vanishes, the derivative of an auxiliary polynomial formed from the row above is used instead; this case indicates roots lying symmetrically about the origin, such as poles on the imaginary axis or in mirror-image pairs.

Hurwitz determinants

Hurwitz's equivalent formulation uses a family of determinants built from the coefficients, the Hurwitz determinants. The polynomial is stable (a Hurwitz polynomial) if and only if all leading principal minors of the Hurwitz matrix are positive.

Applications

The criterion is a standard tool in control engineering for testing closed-loop stability without factoring the characteristic equation, and for finding ranges of controller gains (such as the proportional gain in a PID controller) over which a feedback system remains stable. It applies only to polynomial characteristic equations, so systems with time delays must first be approximated, for example with a Padé approximant.
