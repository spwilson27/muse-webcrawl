Post Office Protocol

The Post Office Protocol (POP) is an application-layer Internet standard protocol used by e-mail clients to retrieve e-mail from a mail server. The current version, POP3, is defined by RFC 1939 (1996) and operates by default over TCP port 110, or port 995 for the TLS-secured variant (POP3S).

Operation

In a typical POP3 session, the client connects, authenticates, retrieves messages to the local device, and typically deletes them from the server, after which the session ends. This "download-and-delete" model suited early dial-up use but handles access from multiple devices poorly, since mail is not synchronized between them. Optional commands can leave copies on the server.

Comparison with IMAP

The Internet Message Access Protocol (IMAP) keeps mail on the server and synchronizes state — read flags, folders, drafts — across clients. For this reason IMAP has largely displaced POP3 for general use, though POP3 remains supported by most providers.

History

Earlier versions include POP (RFC 918, 1984) and POP2 (RFC 937, 1985). POP3 first appeared in RFC 1081 (1988) and was refined through RFC 1225 and RFC 1460 before the current specification.
