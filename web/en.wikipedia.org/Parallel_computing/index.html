Parallel computing

Parallel computing is a type of computation in which many calculations or processes are carried out simultaneously. Large problems can often be divided into smaller ones, which can then be solved at the same time. There are several different forms of parallel computing: bit-level, instruction-level, data, and task parallelism. Parallelism has been employed for many years, mainly in high-performance computing, but it has gained broader interest since the mid-2000s, when physical constraints prevented further large gains from frequency scaling in single processors, and manufacturers turned to multi-core processors for consumer hardware.

Background

Traditionally, computer software has been written for serial computation: a problem is broken into a discrete series of instructions executed sequentially on a single processor. Parallel computing uses multiple processing elements simultaneously. The theoretical speedup from parallelizing a program is governed by Amdahl's law, which shows that gains are limited by the fraction of the program that must run serially; Gustafson's law argues that larger problems run in fixed time can nonetheless scale well. Parallelism is closely related to, but distinct from, concurrent computing, which concerns managing multiple interleaved tasks.

Types of parallelism

  • Bit-level parallelism — increasing processor word size (from 4-bit to 64-bit) reduces the number of instructions needed for large numbers.
  • Instruction-level parallelism — pipelines, superscalar execution, and out-of-order execution allow multiple instructions per clock cycle within one processor.
  • Data parallelism — the same operation is applied to many data elements at once, in SIMD units, vector processors, and GPUs; described by Flynn's taxonomy as SIMD and SPMD styles.
  • Task parallelism — different tasks or functions run concurrently on different processors, often communicating through messages or shared memory.

Computer architectures are commonly divided into shared-memory multiprocessors (including modern multicore chips), distributed-memory clusters of networked nodes, and accelerators such as graphics processing units (GPUs), which provide thousands of simple cores for data-parallel workloads — increasingly used for scientific simulation and machine learning.

Programming models

Parallel programs are written with shared-memory models (such as OpenMP and POSIX threads), message-passing models (such as the Message Passing Interface, MPI), data-parallel languages and frameworks (such as CUDA for GPUs and MapReduce and Spark for distributed data processing), and high-level constructs in languages with built-in concurrency support. Coordination introduces hazards absent in serial code — race conditions, deadlocks, and nondeterministic ordering — addressed with locks, atomic operations, barriers, and transactional memory. Correctness and performance must also account for communication costs, load balancing, and memory consistency models.

History

Early parallel machines included the ILLIAC IV (completed 1970s) and experimental systems of the 1960s; commercial development in the 1970s and 1980s produced vector supercomputers such as the Cray-1 (1976) and massively parallel machines such as the Connection Machine. By the 1990s, clusters of commodity computers ("Beowulf" clusters) and standard message passing made parallel computing affordable to laboratories and companies. The end of Dennard scaling around 2005–2006, when power limits stalled clock-speed increases, made multicore parallelism mainstream in desktops and phones. Modern supercomputers — measured by the TOP500 list, led in the 2020s by exascale systems such as Frontier and El Capitan — combine millions of CPU and GPU cores to reach over 1018 floating-point operations per second.

Applications

Parallel computing underlies weather forecasting and climate modelling, computational fluid dynamics, structural and molecular simulation, genome analysis, seismic processing, financial modelling, cryptanalysis, large-scale databases and search engines, and the training of large artificial neural networks.
