Emacs Lisp

Emacs Lisp is a Lisp dialect used to write the Emacs text editor and to extend and customise it. Most of GNU Emacs is implemented in Emacs Lisp on top of a smaller C core of primitives; the same is true of XEmacs and its variants. Users configure Emacs by writing Emacs Lisp in an initialisation file, and thousands of packages — from email clients to version-control interfaces — are distributed as Emacs Lisp libraries.

History

Earlier Emacs implementations were written in other extension languages, such as TECO for the original Emacs and Mocklisp for Gosling Emacs. Richard Stallman chose Lisp as the extension language for GNU Emacs in the mid-1980s, arguing that a full programming language made the editor freely extensible. Emacs Lisp has since evolved with lexical binding (introduced as an option in Emacs 24, 2012) and native compilation to machine code (Emacs 28, 2022).

Language features

Emacs Lisp is a dynamically typed language with special support for text processing: first-class buffers, windows, markers, overlays and text properties. Historically it used dynamic scoping; lexical scoping is now available and recommended. Its standard library includes the CL-Lib package derived from Common Lisp. Code can be byte-compiled for speed, and macros allow users to extend the language itself.

Use

Beyond editing, Emacs Lisp powers major applications such as the Org-mode organiser, the Magit Git interface, the Gnus newsreader and the ERC chat client, making Emacs a general computing environment for many users.
