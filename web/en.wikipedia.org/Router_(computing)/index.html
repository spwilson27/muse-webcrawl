Router (computing)

A router is a computer and networking device that forwards data packets between computer networks, most commonly between a local area network (LAN) and a wide area network (WAN) such as the Internet. Routers perform the traffic directing functions on the Internet: data sent through the internet, such as a web page or email, is in the form of data packets, and a router forwards each packet toward its destination based on information in its routing table.

Operation

When a router receives a packet, it reads the network address information in the packet header to determine the ultimate destination. Using information in its routing table or routing policy, it directs the packet to the next network on its journey — the next "hop" closer to the final destination. The most common packet switching technology is the Internet Protocol (IP), and routers operate at layer 3 (the network layer) of the OSI model.

Routers are typically dedicated hardware devices, but routing can also be performed by general-purpose computers running routing software. Core routers in the Internet backbone handle enormous volumes of traffic, while the small router in a home or office typically combines routing with a network switch, a wireless access point, and a firewall.

Types

Core routers forward packets at very high speed within the backbone of a network. Edge routers (or access routers) sit at the boundary between networks, such as between an enterprise network and its Internet service provider. Distribution routers aggregate traffic from multiple access routers. Residential broadband routers integrate routing with NAT (network address translation), DHCP services, and Wi-Fi.

Routing tables and protocols

A routing table stores the paths to particular network destinations. Tables can be configured statically or built dynamically using routing protocols. Interior gateway protocols such as OSPF and IS-IS are used within an autonomous system, while BGP (Border Gateway Protocol) is the exterior gateway protocol used to exchange routing and reachability information among autonomous systems on the Internet.
