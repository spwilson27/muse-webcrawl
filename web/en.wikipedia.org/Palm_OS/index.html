Palm OS

Palm OS (later renamed Garnet OS) is a discontinued mobile operating system initially developed by Palm, Inc. (then a subsidiary of U.S. Robotics) for personal digital assistants (PDAs) in 1996. Designed for ease of use with a touchscreen-based graphical user interface, it powered the highly successful PalmPilot line and was later extended with telephony features for smartphones such as the Treo.

Features

Palm OS was built around a simple application launcher, a suite of built-in personal information management applications (address book, date book, to-do list and memo pad), and HotSync technology for synchronising data with a desktop computer. Handwriting input was provided through the Graffiti gesture alphabet. The system was deliberately lightweight, running well on modest processors with very little memory and battery power.

History and versions

The first version shipped on the PalmPilot 1000 and 5000 in 1996. Subsequent versions added colour displays, expansion-card support, higher-resolution screens, and wireless connectivity. Palm OS 5 (2002) moved the platform to ARM processors. The planned successor based on Linux, Palm OS Cobalt (version 6), was completed in 2004 but never shipped on a device. Access Co., which acquired the source code in 2005, renamed the system Garnet OS and licensed it back to Palm.

Decline

Competition from Windows Mobile, Symbian, BlackBerry OS and later the iPhone and Android displaced Palm OS in the late 2000s. Palm replaced it with webOS in 2009, and the last Palm OS devices were discontinued shortly afterwards.
