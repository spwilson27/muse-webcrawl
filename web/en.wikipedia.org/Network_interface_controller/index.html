Network interface controller

A network interface controller (NIC, also known as a network interface card, network adapter or LAN adapter) is a computer hardware component that connects a computer to a computer network. Early network interface controllers were typically implemented on expansion cards that plugged into a computer's bus, but the low cost and ubiquity of the Ethernet standard means most modern computers have a network interface built into the motherboard, or provided via USB.

The network controller implements the electronic circuitry required to communicate using a specific physical layer and data link layer standard, such as Ethernet or Wi-Fi. It provides a low-level addressing system through the use of MAC addresses, allowing each connected device to be uniquely identified on the network. Modern NICs offer advanced features such as interrupt and DMA interfaces for parallel processing, support for multiple receive and transmit queues, on-controller network traffic processing, and offloading of TCP tasks (TCP offload engine).

Function

The NIC operates at the physical and data-link layers of the OSI model. It converts data between the parallel format used inside the computer and the serial format transmitted on the medium, frames outgoing data, checks incoming frames' destination addresses and frame-check sequences, and buffers data. Each NIC is assigned a globally unique 48-bit MAC address stored in its ROM. Network interface controllers may support speeds from 10 Mbit/s up to hundreds of gigabits per second in data-centre applications.

Types

Wired NICs communicate over twisted-pair copper (with RJ-45 connectors) or fibre-optic cable. Wireless NICs (WNICs) connect using Wi-Fi standards (IEEE 802.11) via antennas. Server adapters may provide multiple ports, remote management (such as Wake-on-LAN or IPMI), virtualisation support (SR-IOV), and remote direct memory access (RDMA) over Converged Ethernet for high-performance computing.
