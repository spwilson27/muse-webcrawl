Rapid application development

Rapid application development (RAD) is a software development methodology that emphasises iterative prototyping, user involvement, and fast delivery over rigid upfront planning. It arose in the late 1980s and early 1990s as a reaction against the sequential waterfall model.

History

Barry Boehm's spiral model and Tom Gilb's evolutionary delivery anticipated RAD's ideas. James Martin formalised RAD in his 1991 book Rapid Application Development, building on work at IBM and DuPont, stressing timeboxed development, joint application design sessions with users, and CASE tools that generate code from models.

Phases

Martin's model has four phases: requirements planning, user design (prototyping), construction, and cutover. Users evaluate working prototypes throughout, and feedback drives successive iterations. RAD trades exhaustive documentation and architectural rigor for speed, and works best for systems with well-understood, modular scope and available, committed users. Its ideas fed directly into agile software development and modern low-code platforms.
