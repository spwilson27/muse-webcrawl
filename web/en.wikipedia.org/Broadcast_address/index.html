Broadcast address

A broadcast address is a network address at which all devices connected to a multiple-access communications network are enabled to receive datagrams. In IPv4, a broadcast address for a subnet is formed by setting all the host bits of the address to 1; for example, in the subnet 192.168.1.0/24 the broadcast address is 192.168.1.255.

Types

A directed broadcast targets all hosts on a specific network, while the limited broadcast address 255.255.255.255 reaches all hosts on the local network segment only and is not forwarded by routers. Protocols such as ARP and DHCP make use of broadcast messages. IPv6 does not use broadcast addresses, relying instead on multicast.
