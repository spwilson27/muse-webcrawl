Kubernetes (commonly abbreviated K8s) is an open-source container orchestration system for automating the deployment, scaling, and management of containerized applications. It was originally designed by Google, drawing on the company's experience with its internal Borg cluster management system, and was announced in 2014. In 2015 Google donated it to the newly formed Cloud Native Computing Foundation (CNCF), where it became the foundation's first graduated project.

History

Kubernetes grew out of Google's Borg system, which had managed the company's production workloads for over a decade. Its first release, version 1.0, came in July 2015 alongside the launch of the CNCF. It rapidly became the de facto standard platform for running containers at scale, with managed offerings from all major cloud providers.

Architecture

A Kubernetes deployment is called a cluster, consisting of a control plane and a set of worker machines called nodes. The control plane includes the API server, a scheduler, a controller manager, and the etcd key-value store, which holds the cluster's configuration and state. Workloads run as pods — the smallest deployable unit, containing one or more containers that share storage and networking. Higher-level abstractions such as Deployments, Services, and Ingresses manage replicas, networking, and exposure of applications. Users state the desired state of the system declaratively, typically in YAML manifests, and controllers continually reconcile the actual state with it.

Name

The name Kubernetes comes from the Greek κυβερνήτης (kybernētēs), meaning "helmsman" or "pilot", reflected in its seven-spoked ship's wheel logo. The abbreviation K8s counts the eight letters between the initial K and final s.
