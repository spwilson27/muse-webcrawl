In optimization theory, maximum flow problems involve finding a feasible flow through a flow network that obtains the maximum possible flow rate. A flow network is a directed graph in which each edge has a non-negative capacity; a flow must respect capacity constraints on every edge and conservation of flow at intermediate vertices.

Definition

Given a directed graph G = (V, E) with a source s, a sink t, and a capacity c(u, v) ≥ 0 on each edge, a flow assigns a value f(u, v) ≤ c(u, v) to each edge such that for every vertex other than s and t, inflow equals outflow. The value of the flow is the net flow out of the source, and the maximum flow problem asks for a flow of greatest value.

Max-flow min-cut theorem

The max-flow min-cut theorem states that the maximum value of an s–t flow equals the minimum capacity of an s–t cut — a partition of the vertices separating s from t. It was first proved by Elias, Feinstein and Shannon and independently by Ford and Fulkerson in 1956, and it makes the problem a classic example of linear programming duality.

Algorithms and applications

The Ford–Fulkerson method (1956) iteratively augments flow along residual paths; the Edmonds–Karp implementation guarantees polynomial running time. Later algorithms by Dinic and the push–relabel family improved performance further. Applications include transportation and communication networks, bipartite matching, project scheduling, image segmentation and airline scheduling.
