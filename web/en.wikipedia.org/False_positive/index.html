False positive

A false positive is an error in binary classification in which a test result incorrectly indicates the presence of a condition or attribute when it is not present. The corresponding error, a false negative, incorrectly indicates absence. In statistical hypothesis testing, a false positive is a Type I error: rejecting a null hypothesis that is actually true.

Concepts

The false positive rate is the proportion of actual negatives that are incorrectly classified as positive; it equals one minus the specificity of the test. How much a positive result should be trusted also depends on the base rate of the condition — the base rate fallacy: even a highly accurate test applied to a rare condition can yield mostly false positives, as shown by the positive predictive value computed with Bayes' theorem.

Applications

False positives matter in medical screening (leading to anxiety and further invasive testing), spam filtering (legitimate mail flagged as junk), malware detection, airport security screening, polygraphy, and scientific publishing, where multiple comparisons inflate false positive rates and motivate corrections and pre-registration. The trade-off between false positives and false negatives is commonly visualized with the ROC curve.
