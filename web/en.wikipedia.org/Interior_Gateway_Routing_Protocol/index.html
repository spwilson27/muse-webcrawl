Interior Gateway Routing Protocol

The Interior Gateway Routing Protocol (IGRP) is a distance vector interior gateway protocol (IGP) developed by Cisco Systems in the mid-1980s. It was created to overcome the limitations of RIP, most notably RIP's 15-hop ceiling and its sole reliance on hop count as a routing metric, in large, heterogeneous networks.

Overview

IGRP uses a composite metric calculated from bandwidth, delay, reliability, load, and MTU; by default only bandwidth and delay contribute. Routers exchange their full routing tables every 90 seconds by default, using broadcasts, and mark routes invalid after 270 seconds without an update, holding them down for 280 seconds and flushing them after 630 seconds.

Features

IGRP supports an autonomous-system design with multiple processes, allows a maximum hop count of 255 (100 by default), and performs unequal-cost load balancing through the variance command. It was largely superseded by Enhanced IGRP (EIGRP), which added support for classless addressing and a loop-free DUAL algorithm.
