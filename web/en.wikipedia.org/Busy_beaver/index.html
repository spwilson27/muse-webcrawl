Busy beaver

In theoretical computer science, the busy beaver game, introduced by Tibor Radó in 1962, seeks the Turing machine of a given size that produces the most output or runs the longest before halting, among all machines of that size that do halt.

Definitions

For n-state, 2-symbol machines, the busy beaver function Σ(n) gives the maximum number of ones such a machine can write before halting, and S(n) gives the maximum number of steps. Because deciding which machines halt is equivalent to the halting problem, these functions are noncomputable and grow faster than any computable function.

Known values

Values are known exactly only for small n: S(1)=1, S(2)=6, S(3)=21 and S(4)=107. In 2024 the Busy Beaver Challenge collaboration proved S(5)=47,176,870, settling a problem open for decades; for n=6 only enormous lower bounds are known.
