Confusion matrix

A confusion matrix summarises the predictions of a classifier.

In the field of machine learning and specifically the problem of statistical classification, a confusion matrix, also known as an error matrix, is a specific table layout that allows visualization of the performance of an algorithm, typically a supervised learning one. Each row of the matrix represents the instances in an actual class while each column represents the instances in a predicted class, or vice versa. The name stems from the fact that it makes it easy to see whether the system is confusing two classes, that is, commonly mislabelling one as another.

Binary classification

For a binary classifier the matrix has four cells: true positives (TP), correctly predicted positive cases; true negatives (TN), correctly predicted negatives; false positives (FP, type I errors), negatives wrongly predicted positive; and false negatives (FN, type II errors), positives wrongly predicted negative.

Derived metrics

Many performance measures are computed from the matrix: accuracy, (TP+TN) divided by the total; precision, TP/(TP+FP), the fraction of positive predictions that are correct; recall or sensitivity, TP/(TP+FN), the fraction of positives found; specificity, TN/(TN+FP); and the F1 score, the harmonic mean of precision and recall. These metrics are particularly important for imbalanced datasets, where raw accuracy can be misleading.

Multi-class case

For problems with more than two classes the matrix generalises to an n-by-n table, with correct predictions on the diagonal and confusions off-diagonal, revealing which class pairs a model most often mistakes. Per-class metrics can be averaged across classes in macro or micro fashion.
