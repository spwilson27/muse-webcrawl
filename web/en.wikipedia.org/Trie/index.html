Trie

In computer science, a trie, also called a digital tree or prefix tree, is a kind of k-ary search tree — a tree data structure used to store a dynamic set or associative array whose keys are usually strings. Unlike a binary search tree, nodes in a trie do not store their associated key; instead, a node's position in the tree defines the key with which it is associated. All descendants of a node share a common prefix of the string stored at that node.

Operations

Lookup, insertion and deletion of a key of length m take O(m) time, independent of the number of keys stored, because each step descends one level by one character. Tries support efficient prefix queries — finding all keys beginning with a given prefix — which makes them suitable for autocomplete and predictive text, spell checking, IP routing (where keys are bit strings), and dictionary storage. A classic application is representing a set of words so that common prefixes are stored only once.

Variants and trade-offs

Because each node may carry a child pointer for every possible character, naive tries can consume large amounts of memory. Compressed variants — radix trees (Patricia tries) — merge chains of single-child nodes into edges labelled with strings. Other relatives include suffix trees and suffix tries used in string algorithms, and bitwise tries used in longest-prefix-match routing tables. The name "trie" comes from the middle syllable of "retrieval" and was coined by Edward Fredkin in 1960, building on earlier work by René de la Briandais (1959).
