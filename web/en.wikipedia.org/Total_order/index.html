Total order

In a total order, every two elements are comparable.

In mathematics, a total order or linear order is a partial order in which any two elements are comparable. That is, a total order is a binary relation ≤ on some set X which satisfies, for all a, b and c in X:

  1. a ≤ a (reflexivity);
  2. if a ≤ b and b ≤ c then a ≤ c (transitivity);
  3. if a ≤ b and b ≤ a then a = b (antisymmetry);
  4. a ≤ b or b ≤ a (strong connectedness, formerly called totality).

A set equipped with a total order is a totally ordered set; the terms simply ordered set, linearly ordered set and chain are also used. Although the term "chain" sometimes refers only to a totally ordered subset of a partially ordered set, it is commonly used synonymously with a totally ordered set.

Examples

The real numbers with the usual ≤ form a total order, as do the integers and the natural numbers. The alphabet with dictionary (lexicographic) order is a total order on words. By contrast, the subset relation on sets and the divisibility relation on integers are partial orders that are not total, since some pairs are incomparable. Every finite totally ordered set of n elements is order-isomorphic to {1, 2, ..., n}.

Related concepts

A strict total order drops reflexivity in favour of irreflexivity and trichotomy. A total order that is also a well-order requires every non-empty subset to have a least element. Total orders underpin sorting algorithms in computer science, order theory, and preference modelling in economics; the Szpilrajn extension theorem states that every partial order can be extended to a total order.
