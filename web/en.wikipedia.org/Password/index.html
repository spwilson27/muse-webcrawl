Password

A password, sometimes called a passcode, is secret data, typically a string of characters, used to confirm the identity of a user. Passwords have been used since ancient times as watchwords by sentries, and in computing since the early time-sharing systems of the 1960s.

Use in computing

A user presents an identifier, usually a username, together with a password; the system grants access if the password matches the one associated with the account. Well-designed systems store only a salted cryptographic hash of the password rather than the password itself.

Security

Password strength depends on length and unpredictability. Common weaknesses include reuse across sites, dictionary words, and susceptibility to guessing, phishing, and credential-stuffing attacks. Multi-factor authentication and password managers mitigate many of these risks, and modern guidance emphasizes length over complexity rules.

Alternatives

Alternatives and successors to passwords include biometrics, hardware security keys, one-time codes, and passkeys, which aim to replace passwords with phishing-resistant public-key credentials.
