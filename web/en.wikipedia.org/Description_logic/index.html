Description logic

Description logics (DL) are a family of formal knowledge representation languages designed to represent the knowledge of an application domain in a structured and formally well-understood way, while supporting automated reasoning such as classification of concepts and checking consistency of knowledge bases.

Overview

Knowledge in a description logic is expressed through concepts (classes), roles (properties), and individuals, organised into a TBox (terminological axioms) and an ABox (assertions about individuals). Different logics differ in their constructors and in the trade-off between expressiveness and the computational complexity of reasoning. The basic logic ALC includes conjunction, disjunction, negation, and existential and universal restrictions.

Applications

Description logics provide the formal underpinning of the Web Ontology Language OWL, used in the Semantic Web, and are applied in biomedical ontologies, configuration, and data integration. Notable DL reasoners include FaCT++, HermiT, Pellet and ELK.
