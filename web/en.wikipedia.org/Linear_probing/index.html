Linear probing

Linear probing is a scheme in computer programming for resolving collisions in hash tables, data structures for maintaining a collection of key–value pairs and looking up the value associated with a given key. In linear probing, when a collision occurs — the hash of a new key maps to a cell of the table already occupied — the algorithm searches the table for the next available slot by stepping through subsequent cells in sequence (usually wrapping around the end of the table) until an empty cell or the key itself is found.

Analysis

Together with quadratic probing and double hashing, linear probing is a form of open addressing. Its main advantage is excellent cache locality, since probes move through contiguous memory. Its main weakness is primary clustering: occupied cells form runs that grow rapidly, lengthening probe sequences. With load factor α, the expected number of probes for an unsuccessful search is roughly ½(1 + 1/(1−α)²), so performance degrades sharply as the table fills; linear probing works best at moderate load factors. Deletion is handled by marking cells as "deleted" tombstones or by rehashing the affected cluster.

History

Linear probing was invented in 1954 by Gene Amdahl, Elaine McGraw, and Arthur Samuel at IBM, and analysed in detail by Donald Knuth in 1963, an analysis considered a founding milestone of the analysis of algorithms.
