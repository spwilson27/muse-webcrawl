Wireless access point

PurposeConnect wireless devices to a wired network
StandardsIEEE 802.11 (Wi-Fi)
Typical bands2.4 GHz, 5 GHz, 6 GHz

In computer networking, a wireless access point (WAP or AP) is a device that creates a wireless local area network and allows Wi-Fi-compliant devices to connect to a wired network. Access points typically connect to a router or switch via Ethernet cable and project a Wi-Fi signal in a designated area, identified by a network name (SSID).

Operation

An access point bridges traffic between wireless clients and the wired LAN, translating between 802.11 radio frames and Ethernet. Enterprise deployments use many access points managed centrally, with features such as automatic channel and power adjustment, seamless roaming between cells, band steering, and support for power over Ethernet (PoE). Home routers usually combine a router, switch, and access point in one unit.

Security

Modern access points support WPA2 and WPA3 encryption and authentication. Enterprise networks often use 802.1X with a RADIUS server for per-user credentials, while captive portals are common in public hotspots. Rogue and misconfigured access points are a recurring security concern.
