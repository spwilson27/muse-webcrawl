EternalBlue

EternalBlue is a computer exploit developed by the United States National Security Agency (NSA) that exploits a vulnerability in Microsoft's implementation of the Server Message Block (SMB) protocol. It was leaked by the Shadow Brokers hacking group on 14 April 2017 and was used in the worldwide WannaCry ransomware attack of May 2017 and the NotPetya attack of June 2017.

Vulnerability

The vulnerability, catalogued as CVE-2017-0144, lies in SMB version 1 (SMBv1). A specially crafted packet can cause memory corruption allowing remote code execution with system privileges on an unpatched Windows system, typically over TCP port 445, without user interaction.

Disclosure and patch

Microsoft had issued security bulletin MS17-010 on 14 March 2017, a month before the public leak, patching supported Windows versions. After WannaCry, Microsoft also released emergency patches for out-of-support systems including Windows XP and Windows Server 2003. The NSA reportedly had known of the flaw for years and lost control of the tool, raising debate about the Vulnerabilities Equities Process.

Major attacks

WannaCry spread to hundreds of thousands of computers in more than 150 countries, disrupting Britain's National Health Service among others. NotPetya, initially disguised as ransomware, caused billions of dollars in damage to companies such as Maersk and Merck. Variants and derivatives of EternalBlue continued to be used by criminal and state actors for cryptomining and espionage for years afterwards on unpatched machines.

Mitigation

Disabling SMBv1, applying MS17-010, blocking port 445 at firewalls and keeping systems updated prevent exploitation. See also WannaCry ransomware attack, NotPetya and Server Message Block.
