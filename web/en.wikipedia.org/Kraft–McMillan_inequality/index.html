Kraft–McMillan inequality


The Kraft–McMillan inequality characterises the possible codeword lengths of uniquely decodable codes.

In coding theory, the Kraft–McMillan inequality gives a necessary and sufficient condition for the existence of a uniquely decodable code — in particular a prefix code — over an alphabet of size r with given codeword lengths.

Statement

If a uniquely decodable code has codeword lengths l1, l2, …, ln over an alphabet of size r, then

Σi=1..n r−li ≤ 1.

Conversely, if a multiset of natural numbers satisfies this inequality, there exists a prefix code (and hence a uniquely decodable code) with those codeword lengths. The inequality for prefix codes was proved by Leon G. Kraft in 1949; Brockway McMillan showed in 1956 that the same condition holds for all uniquely decodable codes, so no uniquely decodable code can have shorter lengths, on average, than a prefix code.

Applications

The inequality is a foundation of information theory: it underlies the analysis of Huffman coding and Shannon's source coding theorem, constraining how compactly a source can be encoded without ambiguity. It can be visualised through the completeness of the code tree — the sum measures the fraction of leaves at full depth occupied by codewords.
