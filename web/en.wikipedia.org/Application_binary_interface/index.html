Application binary interface

Application binary interface
FieldComputer science
AbbreviationABI
Related conceptsAPI, calling convention, machine code

An application binary interface (ABI) is an interface between two binary program modules, such as between an application program and the operating system, or between components of compiled code. It defines low-level details including the sizes and alignment of data types, the calling convention controlling how functions' arguments are passed and return values retrieved, the system call numbers and how an application makes system calls to the operating system, and the format of object files and shared libraries.

ABIs and APIs

An ABI differs from an application programming interface (API), which defines the interface at the source code level. Compatibility at the ABI level allows compiled binary code to run unchanged, whereas API compatibility allows source code to be recompiled without modification. Breaking ABI compatibility requires recompilation of dependent binaries.

Examples

Well-known ABIs include the System V ABI used on Unix-like systems such as Linux, the Microsoft x64 ABI used on Windows, the ARM architecture's Procedure Call Standard, and the Itanium C++ ABI, which was widely adopted by other compilers. The Embedded ABI (EABI) targets embedded systems.
