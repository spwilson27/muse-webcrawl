Comparison of ARM processors

This article compares processors based on the ARM architecture, a family of reduced instruction set computer (RISC) instruction set architectures designed by Arm Holdings and licensed to many manufacturers. ARM processors power most smartphones and tablets, and increasingly servers and laptops.

Families

  • ARM7 / ARM9 / ARM11 — early 32-bit cores used in feature phones and embedded devices.
  • Cortex-A — application processors (e.g. Cortex-A53, A72, A76, X-series) running rich operating systems.
  • Cortex-R — real-time cores for automotive and industrial control.
  • Cortex-M — microcontroller cores (M0, M3, M4, M7) for deeply embedded systems.
  • Neoverse — server and infrastructure cores.

Well-known licensees and implementations include Apple's A- and M-series, Qualcomm's Snapdragon and Kryo, Samsung's Exynos, MediaTek's Dimensity, and Amazon's Graviton. Comparisons generally consider instruction set version (ARMv7-A, ARMv8-A, ARMv9-A), number of cores, clock speed, cache sizes, process node, and power consumption.
