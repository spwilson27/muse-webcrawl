Markdown

Created: 2004
Creators: John Gruber, Aaron Swartz
Type: Lightweight markup language
File extension: .md, .markdown

Markdown is a lightweight markup language for creating formatted text using a plain-text editor. Created by John Gruber with Aaron Swartz in 2004, it is designed to be readable as-is and convertible to HTML and other formats.

Syntax

Headings use # characters, emphasis uses asterisks or underscores, lists use hyphens or numbers, links use [text](url), images add a leading !, and code spans use backticks. Blockquotes begin with >.

Variants and use

Flavours include CommonMark (a standardised specification), GitHub Flavored Markdown (tables, task lists, strikethrough) and extensions in static site generators, documentation tools, Jupyter notebooks, README files, forums and chat applications.
