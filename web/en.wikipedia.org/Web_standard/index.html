Web standard

Web standards are the formal, standardized technologies and protocols that define how the World Wide Web works. They are developed by standards organizations to ensure that web content and applications work consistently across browsers, devices, and platforms — the principle of interoperability.

Organizations and technologies

The World Wide Web Consortium (W3C) historically coordinated standards such as HTML, CSS, XML, and the Document Object Model; since 2019 the WHATWG has maintained the HTML Living Standard. Other bodies include the IETF (HTTP, URI standards), ECMA International (JavaScript/ECMAScript), and the Unicode Consortium.

Importance

Adhering to standards allows developers to write content once and have it render accessibly and durably everywhere, supports assistive technologies, and preserves the open character of the web against proprietary fragmentation. The web standards movement of the early 2000s campaigned for browsers to implement the standards correctly and for developers to stop using browser-specific hacks.
