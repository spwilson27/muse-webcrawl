Hilbert's tenth problem

Hilbert's tenth problem is the tenth on the list of mathematical problems posed by David Hilbert in 1900. It asks for a general algorithm that, given any Diophantine equation (a polynomial equation with integer coefficients), determines whether the equation has a solution with all unknowns taking integer values. The problem was settled in the negative in 1970: no such algorithm exists.

Resolution

The resolution built on work by Martin Davis, Hilary Putnam, and Julia Robinson, who reduced the problem to showing that a certain exponential relation is Diophantine. Yuri Matiyasevich, then a 22-year-old Soviet mathematician, completed the proof in 1970 using Fibonacci numbers. The combined result is known as the MRDP theorem (Matiyasevich–Robinson–Davis–Putnam): every computably enumerable set is Diophantine. Consequently, Diophantine equations are as general as computation itself — there are Diophantine equations that encode arbitrary Turing machines, and even a universal Diophantine equation.

Consequences and extensions

The theorem implies, among other things, that there is a polynomial equation whose set of positive values at integer inputs is exactly the set of prime numbers. Analogous decision problems remain open or have been answered for other rings: the corresponding question for rational numbers is a famous open problem, while related work connects the tenth problem to logic, computability theory, and number theory in general.
