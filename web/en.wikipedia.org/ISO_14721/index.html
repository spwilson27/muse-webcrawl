Open Archival Information System

The Open Archival Information System (OAIS), published as ISO 14721, is a reference model for an archive dedicated to preserving information and making it available to a designated community over the long term. It originated with the Consultative Committee for Space Data Systems.

Model

OAIS defines entities such as producers, consumers, and management, and functions including ingest, archival storage, data management, preservation planning, and access. Information moves through the archive as Submission, Archival, and Dissemination Information Packages (SIP, AIP, DIP).

Influence

Although a reference model rather than an implementation specification, OAIS concepts and terminology have become the standard vocabulary of digital preservation and underpin repository audit standards such as ISO 16363.
