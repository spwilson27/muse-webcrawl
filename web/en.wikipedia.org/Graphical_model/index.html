Graphical model

Field: Machine learning, statistics

Main types: Bayesian network (directed), Markov random field (undirected), factor graph

A graphical model, or probabilistic graphical model (PGM), is a probabilistic model for which a graph expresses the conditional dependence structure between random variables. Graphical models are widely used in probability theory, statistics — particularly Bayesian statistics — and machine learning.

Types

Generally, probabilistic graphical models use a graph-based representation as the foundation for encoding a distribution over a multi-dimensional space and a graph as a compact or factorised representation of a set of independences that hold in the specific distribution.

In a Bayesian network, the graph is a directed acyclic graph (DAG): each node represents a random variable, and each edge represents a conditional probability distribution of a variable given its parents. In a Markov random field, the graph is undirected and represents sets of variables having the Markov property with respect to the graph. Factor graphs are bipartite graphs connecting variables to factors, providing a unified representation used in message-passing algorithms.

Inference and learning

Key computational problems in graphical models include probabilistic inference (computing marginal or conditional distributions), parameter learning from data, and structure learning (discovering the graph). Exact inference is tractable in trees and some other structures; in general graphs, approximate methods such as variational inference, loopy belief propagation and Markov chain Monte Carlo sampling are used.

Applications

Graphical models are applied in speech recognition (hidden Markov models), computer vision, natural language processing, bioinformatics (gene regulatory networks), error-correcting codes, medical diagnosis and information extraction. Notable examples include hidden Markov models, Kalman filters, conditional random fields and the Ising model.
