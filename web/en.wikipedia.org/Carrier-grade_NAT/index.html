Carrier-grade NAT

Also known asLarge-scale NAT (LSN)
TypeNetwork address translation
Defined inRFC 6598 (shared address space); RFC 6888 (requirements)
PurposeIPv4 address conservation by ISPs

Carrier-grade NAT (CGN or CGNAT), also known as large-scale NAT (LSN), is a type of network address translation used by Internet service providers in IPv4 network design. With CGN, end sites — in particular residential networks — are configured with private network addresses that are translated to public IPv4 addresses by middlebox network address translator devices embedded in the network operator's network, permitting the sharing of small pools of public addresses among many end sites.

Motivation

CGN became widespread as the pool of unallocated IPv4 addresses approached exhaustion. By placing a second layer of translation inside the ISP network — producing a "NAT444" arrangement in which traffic passes through customer-premises NAT and then carrier NAT — a single public IPv4 address can serve many subscribers simultaneously through port multiplexing.

Shared address space

RFC 6598 reserved the 100.64.0.0/10 address block specifically for use between customer-premises equipment and the carrier-grade NAT, so that the range would not clash with private RFC 1918 addresses used inside homes. RFC 6888 sets out common requirements for CGN devices, and RFC 6264 describes incremental deployment strategies.

Drawbacks

CGN complicates applications that require inbound connections, such as hosting servers, some online games, and peer-to-peer software. It also makes it harder to identify individual subscribers from an IP address alone, which has legal and law-enforcement implications; ISPs must log port allocations to comply with data-retention requirements. These difficulties are among the arguments for migration to IPv6, under which CGN is unnecessary.
