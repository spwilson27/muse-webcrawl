Git

Git is a distributed version control system designed to handle everything from small to very large projects with speed and efficiency. It was created by Linus Torvalds in 2005 for development of the Linux kernel, after the free use of the proprietary BitKeeper system was withdrawn.

Design

Git tracks snapshots of a file tree rather than differences between files. Every clone contains the full history of the repository, allowing most operations to be performed locally. Data integrity is ensured by SHA-1 (and increasingly SHA-256) hashing of all objects: blobs, trees, commits, and tags.

In GitOps

In GitOps workflows, Git is the single source of truth: the desired state of a system is declared in a Git repository, and automated agents continuously reconcile the running system with the repository, using pull requests as the change mechanism.
