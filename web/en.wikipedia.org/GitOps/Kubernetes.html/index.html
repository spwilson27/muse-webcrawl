Kubernetes

Kubernetes (often abbreviated K8s) is an open-source container orchestration system for automating the deployment, scaling, and management of containerized applications. Originally developed by Google and released in 2014, it is now maintained by the Cloud Native Computing Foundation.

Architecture

A Kubernetes cluster consists of a control plane (API server, scheduler, controller manager, and etcd key-value store) and worker nodes running kubelets and container runtimes. Applications are described declaratively as YAML or JSON manifests defining Pods, Deployments, Services, and other resources.

In GitOps

Because Kubernetes already works declaratively, it is the natural target of GitOps: tools such as Argo CD and Flux continuously compare the live cluster state with manifests stored in Git and automatically apply any drift corrections.
