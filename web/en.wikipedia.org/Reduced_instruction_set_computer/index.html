Reduced instruction set computer

A reduced instruction set computer (RISC) is a computer architecture whose instruction set is designed with a small number of simple, regular instructions, each executable in roughly one clock cycle, so that performance is gained through fast execution and pipelining rather than complex instructions. The contrasting philosophy is CISC (complex instruction set computer).

Key RISC traits include a load–store architecture, fixed instruction length, many general-purpose registers and emphasis on compiler optimisation. Pioneering projects included IBM's 801, Berkeley RISC (which led to SPARC) and Stanford MIPS. Today RISC designs dominate: ARM powers most phones and Apple silicon, and the open RISC-V ISA is rapidly expanding.
