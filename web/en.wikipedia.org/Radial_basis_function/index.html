Radial basis function

A Gaussian radial basis function
FieldNumerical analysis, machine learning
Common formsGaussian, multiquadric, thin-plate spline

A radial basis function (RBF) is a real-valued function whose value depends only on the distance between the input and some fixed point, usually the origin or a centre c: φ(x) = f(‖x − c‖). Any function satisfying this property is radial, and RBFs are widely used as basis functions in approximation and learning methods.

Common types

  • Gaussian: φ(r) = exp(−(εr)²)
  • Multiquadric: φ(r) = √(1 + (εr)²)
  • Inverse multiquadric: φ(r) = 1/√(1 + (εr)²)
  • Thin-plate spline: φ(r) = r² ln(r)
  • Polyharmonic spline

Interpolation

In RBF interpolation, a function is approximated by a weighted sum of radial basis functions centred at known data points. Choosing weights so the approximation matches the data at those points yields a linear system that, for many RBFs, is guaranteed to be solvable. RBF methods are meshfree and are used for scattered-data interpolation, solving partial differential equations, and in neural networks (RBF networks) and kernel methods related to support vector machines.
