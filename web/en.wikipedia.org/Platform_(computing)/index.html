Computing platform

A computing platform, or digital platform, is the environment in which a piece of software is executed. It may consist of hardware, an operating system, or a runtime environment such as a web browser or a virtual machine, together with the libraries and interfaces the software depends on.

Examples

Platforms range from hardware architectures (such as x86-64 or ARM) and operating systems (such as Windows, Linux, macOS, Android and iOS) to software frameworks and cloud services. Cross-platform software is written to run on several platforms, sometimes through compatibility layers or portable languages.

Significance

The choice of platform determines which applications a user can run, and platforms are central to competition in the technology industry: control of a widely used platform confers advantages through network effects and ecosystems of complementary software and services.
