Jakarta EE

Jakarta EE, formerly Java Platform, Enterprise Edition (Java EE) and Java 2 Platform, Enterprise Edition (J2EE), is a set of specifications extending Java SE with features for distributed, enterprise computing, including web services, servlets, and enterprise beans.

History

Developed originally by Sun Microsystems and later Oracle, the platform was transferred to the Eclipse Foundation in 2017. Because Oracle retained the "Java" trademark, the platform was renamed Jakarta EE, and its APIs moved from the javax namespace to jakarta beginning with Jakarta EE 9. Major releases include Java EE 8 (2017), Jakarta EE 9 (2020), and Jakarta EE 10 (2022).

Specifications

Jakarta EE encompasses specifications such as Jakarta Servlet, Jakarta Persistence (JPA), Jakarta RESTful Web Services, Jakarta Enterprise Beans, Jakarta Contexts and Dependency Injection (CDI), and Jakarta Faces. Application servers implementing the platform include WildFly, GlassFish/Eclipse GlassFish, Apache TomEE, and Payara Server.
