Absolute value

In mathematics, the absolute value or modulus of a real number x, denoted |x|, is the non-negative value of x without regard to its sign. Namely, |x| = x if x is a positive number, and |x| = −x if x is negative (in which case negating x makes −x positive), and |0| = 0. For example, the absolute value of 3 is 3 and the absolute value of −3 is also 3. The absolute value of a number may be thought of as its distance from zero along the number line.

Properties

For real numbers, the absolute value satisfies: non-negativity (|x| ≥ 0); positive-definiteness (|x| = 0 if and only if x = 0); multiplicativity (|xy| = |x||y|); and subadditivity, expressed by the triangle inequality |x + y| ≤ |x| + |y|. It also satisfies the reverse triangle inequality | |x| − |y| | ≤ |x − y|, and |x − y| gives the distance between two points on the real line. The absolute value function is continuous everywhere but not differentiable at 0, and it is an even function.

Complex numbers and generalisations

For a complex number z = a + bi, the absolute value (or modulus) is |z| = √(a² + b²), its distance from the origin in the complex plane. The concept generalises to absolute values on fields and ordered rings in abstract algebra, to norms on vector spaces, and to the p-adic absolute value used in number theory, which satisfies the stronger ultrametric inequality.

History and notation

The notation |x| with vertical bars was introduced by Karl Weierstrass in 1841. The term "absolute value" had been used since at least 1806 in French (Jean-Robert Argand's module is also the source of "modulus"). In computing, absolute value is provided by functions such as abs() in most programming languages.
