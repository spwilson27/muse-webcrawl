Lucas–Lehmer primality test

The Lucas–Lehmer test is a primality test for Mersenne numbers — numbers of the form Mp = 2p − 1. It was developed by Édouard Lucas in 1878 and refined by Derrick Henry Lehmer in the 1930s. Because it is fast and deterministic for these special-form numbers, it is the test used by the Great Internet Mersenne Prime Search (GIMPS) to find record-breaking prime numbers.

The test

Let p be an odd prime and define the sequence s0 = 4, sn = sn−1² − 2 (mod Mp). Then Mp is prime if and only if

sp−2 ≡ 0 (mod Mp)

Each step requires only squaring a number of the size of Mp and reduction modulo Mp, which for powers of two has a particularly efficient form. The sequence relates to Lucas sequences, and Lucas's original proof used properties of these sequences in algebraic number fields.

Record primes

Nearly all of the largest known primes are Mersenne primes verified with this test. Volunteer computing through GIMPS has discovered the largest known primes of recent decades, each with tens of millions of digits. In recent years the GIMPS project has shifted toward a probable-prime (Fermat) test with rigorous error checking for first-time tests, reserving Lucas–Lehmer for double-checking, because the classic test lacks built-in error detection.
