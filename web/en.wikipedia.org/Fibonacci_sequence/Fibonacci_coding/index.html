Fibonacci coding

Fibonacci coding is a universal code that encodes positive integers into binary code words. It is based on the Zeckendorf representation of an integer as a sum of non-consecutive Fibonacci numbers, and provides an example of a representation of numbers with the Fibonacci numeral system.

Definition

By Zeckendorf's theorem, every positive integer has a unique representation as a sum of non-consecutive Fibonacci numbers F2=1, F3=2, F4=3, F5=5, and so on. The Fibonacci code word for an integer lists the coefficients of its Zeckendorf representation (least significant first) and appends an extra "1". Because the representation never contains consecutive 1s, the appended "11" occurs only at the end of a code word, making the code self-synchronizing: in a stream of code words, the positions of "11" mark the boundaries between words, and isolated bit errors affect only a limited number of decoded symbols.

Examples

For instance, 1 = F2 gives the code 11; 2 = F3 gives 011; 4 = F4 + F2 = 3 + 1 gives 1011; 10 = F6 + F3 = 8 + 2 gives 01011. Compared with other universal codes such as Elias gamma coding, Fibonacci coding has slower-growing code lengths for some ranges and is used in data compression contexts where robustness against bit errors is desirable, as well as in applications related to the Fibonacci search technique.
