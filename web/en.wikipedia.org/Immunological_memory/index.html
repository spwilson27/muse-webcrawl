Immunological memory

Immunological memory
SystemAdaptive immune system
Cells involvedMemory B cells, memory T cells
Basis ofVaccination; secondary immune response

Immunological memory is the ability of the immune system to respond more rapidly and effectively to a pathogen that has been encountered previously. It is a defining feature of the adaptive immune system and the principle on which vaccination is based.

Mechanism

During a first (primary) encounter with an antigen, antigen-specific B and T lymphocytes proliferate and differentiate; a subset persists as long-lived memory cells. On re-exposure, these cells mount a faster, stronger secondary response, often preventing disease.

Memory B and T cells

Memory B cells produce higher-affinity antibodies more quickly, while memory T cells—including central memory, effector memory, and tissue-resident subsets—provide rapid cellular responses at sites of infection.
