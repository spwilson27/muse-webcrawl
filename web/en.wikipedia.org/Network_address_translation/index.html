Network address translation

Network address translation (NAT) is a method of mapping an IP address space into another by modifying network address information in the IP header of packets while they are in transit across a traffic routing device. It allows multiple devices on a private network to share a single public IP address, and became essential in slowing the exhaustion of IPv4 addresses.

How it works

In the common form known as port address translation (PAT), a router rewrites the source address and port of outbound packets and keeps a table of mappings so that replies can be routed back to the correct internal host. NAT is a standard feature of home routers and firewalls.

Advantages and drawbacks

Besides conserving public addresses, NAT provides a measure of privacy and security by hiding internal addressing. However, it breaks the end-to-end principle of the Internet, complicating protocols that embed address information, peer-to-peer applications, and IPsec. Techniques such as STUN, TURN, and NAT traversal protocols mitigate these problems, and the transition to IPv6 reduces the need for NAT.
