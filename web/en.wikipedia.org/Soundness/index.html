Soundness

FieldLogic, mathematical logic, computer science
Related conceptCompleteness
Key figureKurt Gödel (completeness theorem, 1930)

In logic and deductive reasoning, an argument is sound if it is both valid in form and its premises are true. More generally, soundness is the property of a deductive system whereby everything provable in the system is true under its intended interpretation.

In logic

A sound argument is a valid argument with true premises, and therefore a true conclusion. For a formal system, the soundness theorem states that if a formula is derivable from a set of premises, then it is a semantic consequence of them: ⊢ implies ⊨. Soundness is the converse of completeness, which states that every semantic consequence is derivable. Gödel proved the completeness (and hence, with the easy direction, the soundness) of first-order logic in 1930.

In type systems and programming

In computer science, a type system or static analysis is called sound if it accepts only programs that cannot "go wrong" in a specified sense — informally, "well-typed programs cannot be blamed". Practical languages often trade strict soundness for expressiveness or convenience, leaving "soundness holes" such as null references or unchecked casts.

Other uses

In economics and finance, soundness describes the stability and resilience of institutions; in animal breeding, structural soundness refers to the physical fitness of livestock and horses.
