Pattern matching

Pattern matching is the act of checking a given sequence of tokens or a data structure against a pattern and, when it matches, decomposing it into its constituent parts. It is a fundamental feature of functional programming languages and appears also in string processing, term rewriting, and artificial intelligence.

In programming languages

In languages such as ML, Haskell, OCaml, Erlang, Elixir, Scala, Rust, and F#, functions can be defined by a series of patterns; at run time the argument is tested against each pattern in order, variables in the pattern are bound to the corresponding sub-values, and guards may add further conditions. Patterns can match literals, tuples, lists (head and tail), records, and algebraic data types, and compilers can check pattern sets for exhaustiveness and redundancy. Modern versions of Python (3.10+), Java, C#, and JavaScript have added their own pattern-matching constructs.

String pattern matching

In text processing, pattern matching ranges from literal substring search to shell globs and regular expressions, which describe sets of strings compactly. Tools such as grep, and languages descending from SNOBOL — the first language built around powerful string patterns — made pattern-based text processing a staple of computing.

Other uses

Pattern matching also refers to searching databases of structures in computer algebra (term rewriting), matching graph patterns in query languages, and classifying inputs in expert systems and machine perception. The underlying algorithms — from naïve search to the Knuth–Morris–Pratt algorithm and finite automata for regular expressions — are a classic topic in computer science.
