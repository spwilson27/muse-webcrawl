Data structure

From Wikipedia, the free encyclopedia

In computer science, a data structure is a data organization and storage format that is usually chosen for efficient access to data. More precisely, a data structure is a collection of data values, the relationships among them, and the functions or operations that can be applied to the data — that is, it is an algebraic structure about data.

Data structures serve as the basis for abstract data types (ADT). The ADT defines the logical form of the data type, while the data structure implements the physical form. Choosing an appropriate data structure is a central concern of algorithm design: the efficiency of operations such as search, insertion and deletion depends heavily on how data is organised in memory.

Usage

Data structures provide a means to manage large amounts of data efficiently for uses such as large databases and internet indexing services. Usually, efficient data structures are key to designing efficient algorithms. Some formal design methods and programming languages emphasise data structures, rather than algorithms, as the key organising factor in software design. Most programming languages provide built-in support for basic structures such as arrays and records, and standard libraries supply implementations of common structures such as lists, queues, stacks, hash tables and trees.

Basic principles

Data structures are generally based on the ability of a computer to fetch and store data at any place in its memory, specified by a pointer. The array and record (or struct) are therefore fundamental: an array stores elements in contiguous memory locations accessed by an index, while a record aggregates fields of possibly different types. Pointers allow the construction of linked structures, in which elements are scattered in memory and connected by explicit references.

Building blocks such as these are combined into more complex structures. Self-referential records (nodes) joined by pointers yield linked lists and trees; arrays arranged by index arithmetic yield heaps; and hashing functions map keys to array positions to give hash tables with fast average-case lookup.

Common data structures

  • Array — a fixed-size collection of elements of the same type stored contiguously, accessed by index.
  • Linked list — a linear collection of nodes, each containing data and a reference to the next node.
  • Stack — a last-in, first-out (LIFO) collection supporting push and pop at one end.
  • Queue — a first-in, first-out (FIFO) collection.
  • Tree — a hierarchical structure of nodes; variants include binary search trees, B-trees, heaps and tries.
  • Graph — a set of vertices connected by edges, used to model networks.
  • Hash table — maps keys to values using a hash function, giving average O(1) access.
  • Set — an unordered collection of unique elements.

Language support

Most assembly languages and some low-level languages, such as BCPL, lack built-in support for complex data structures, but high-level languages provide them directly or through libraries: Python offers lists, tuples, dictionaries and sets; Java and C# provide extensive collections frameworks; and C++ supplies the Standard Template Library (STL) containers. Functional languages favour persistent (immutable) data structures that preserve previous versions when modified.
