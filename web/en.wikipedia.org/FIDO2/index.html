FIDO2

FIDO2 is a set of specifications from the FIDO Alliance and the World Wide Web Consortium (W3C) that enables users to leverage common devices to easily authenticate to online services in both mobile and desktop environments. FIDO2 consists of the W3C Web Authentication (WebAuthn) standard and the FIDO Client to Authenticator Protocol (CTAP).

Components

WebAuthn defines a standard web API that can be incorporated into browsers and related web platform infrastructure, while CTAP defines how authenticators — such as security keys and platform authenticators — communicate with client devices over USB, NFC, or Bluetooth.

Passkeys

FIDO2 credentials synced across a user's devices are marketed as passkeys, adopted by Apple, Google and Microsoft as a passwordless sign-in method resistant to phishing.
