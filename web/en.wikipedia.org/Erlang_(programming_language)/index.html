Erlang (programming language)

Paradigm: Concurrent, functional
Designed by: Joe Armstrong, Robert Virding, Mike Williams
First appeared: 1986
Developer: Ericsson

Erlang is a general-purpose, concurrent, functional programming language and a garbage-collected runtime system. It was developed at Ericsson to support distributed, fault-tolerant, soft-real-time applications such as telephone exchanges, and was released as open source in 1998.

Design

Erlang processes are lightweight, isolated, and communicate by message passing, following the actor model. The language supports hot code swapping, allowing programs to be upgraded without stopping the system. The accompanying OTP middleware provides libraries and design principles for building robust servers and supervision trees.

Influence and use

Erlang underpins systems such as the CouchDB database, the RabbitMQ message broker, and WhatsApp's messaging infrastructure. It also inspired the Elixir language, which runs on the same BEAM virtual machine.
