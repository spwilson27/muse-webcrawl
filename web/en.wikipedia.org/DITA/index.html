Darwin Information Typing Architecture

The Darwin Information Typing Architecture (DITA) is an XML standard for authoring, producing and delivering technical information. Developed originally at IBM and standardised by OASIS, DITA is built around small, self-contained units of content called topics that can be reused across documents and output formats.

Core concepts

DITA content is written in three basic topic types: concept, task and reference. Topics are assembled for publication using DITA maps, which specify the order and hierarchy of topics much like a table of contents. Because topics are written to stand alone, the same topic can appear in a printed manual, a help system and a website without modification.

Specialisation

The "Darwin" in the name refers to the architecture's defining feature: specialisation, an inheritance mechanism by which new element and topic types are derived from existing ones, analogous to evolution by descent with modification. Specialised types remain processable by tools written for their ancestors, allowing organisations to define domain-specific markup — for example for pharmaceutical or semiconductor documentation — without abandoning interoperability.

Adoption

DITA is processed by the open-source DITA Open Toolkit and by many commercial authoring tools, and is widely used in software, manufacturing and other industries with large technical documentation sets. A simplified profile, LwDITA (Lightweight DITA), adapts the model for HTML and Markdown authoring.
