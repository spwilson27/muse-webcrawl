dpkg is the software at the base of the Debian package management system. It is used to install, remove, and provide information about .deb packages. dpkg itself is a low-level tool; front-ends such as APT are normally used to fetch packages from remote repositories and resolve dependencies, while dpkg performs the actual installation.

dpkg was originally written by Ian Murdock and others in the early 1990s as part of the Debian project. It maintains a database of installed packages in /var/lib/dpkg, including each package's status, file list, and maintainer scripts.

Usage

Common dpkg commands include:

  • dpkg -i package.deb — install a package file
  • dpkg -r package — remove a package (keeping configuration files)
  • dpkg -P package — purge a package, including configuration files
  • dpkg -l — list installed packages
  • dpkg -s package — show the status of a package
  • dpkg -L package — list the files installed by a package

dpkg runs maintainer scripts at various stages of installation and removal: preinst, postinst, prerm, and postrm. These scripts allow packages to perform setup tasks such as creating users, restarting services, or updating caches.

Package format

A .deb file is an ar archive containing a debian-binary file, a control archive with package metadata, and a data archive with the files to be installed. dpkg verifies package integrity and handles conffile prompts when a modified configuration file would be overwritten.
