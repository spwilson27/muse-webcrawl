API

Full nameApplication programming interface
TypeSoftware interface / contract between programs
ExamplesPOSIX, Windows API, REST web APIs, OpenGL

An application programming interface (API) is a connection between computers or between computer programs. It is a type of software interface, offering a service to other pieces of software. A document or standard that describes how to build or use such a connection or interface is called an API specification. A computer system that meets this standard is said to implement or expose an API. Unlike a user interface, which connects a computer to a person, an API connects computers or pieces of software to each other, and is not meant to be used directly by an end user (other than a computer programmer incorporating it into software).

Types of API

Library and framework APIs

Libraries expose APIs consisting of functions, classes, and data structures in a particular programming language — for example, the C standard library or the Java API. Frameworks invert control: the programmer fills in callbacks that the framework invokes.

Operating system APIs

Operating systems expose APIs such as POSIX and the Windows API, which let applications request services (files, memory, networking) through system calls without knowing hardware details.

Remote and web APIs

Remote APIs define interactions over a network. Web APIs, typically accessed over HTTP, are the most common kind today: REST-style APIs exchange representations (often JSON) of resources, while alternatives and complements include SOAP, GraphQL, and gRPC. Public web APIs — for maps, payments, weather, and social platforms — underpin much of the modern software economy, and their design (versioning, authentication by API keys or OAuth, rate limiting, documentation) is a discipline in itself.

Design and significance

A well-designed API hides implementation details behind a stable contract (information hiding), making software modular and reusable: applications can be built on an API without understanding the underlying code, and implementations can change as long as the contract holds. The specification of an API is therefore often treated as a contract between providers and consumers, and breaking changes are managed through version numbers. Courts have addressed the legal status of APIs, notably in Google LLC v. Oracle America, Inc. (2021), where the US Supreme Court held that Google's copying of Java API declarations to build Android was fair use.
