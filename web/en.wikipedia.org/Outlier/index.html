Outlier

In statistics, an outlier is a data point that differs significantly from other observations. An outlier may arise from measurement error, data entry mistakes, or genuine heavy-tailed variability in the population.

Identification

Common methods include standardising values (z-scores), the interquartile range rule (points more than 1.5 IQR beyond the quartiles), and graphical tools such as box plots and scatter plots. Formal tests include Grubbs' test and Dixon's Q test.

Treatment

Analysts may remove, winsorise, transform or model outliers, or use robust statistical methods less sensitive to them. Discarding outliers without justification can bias results, so causes should be investigated first.
