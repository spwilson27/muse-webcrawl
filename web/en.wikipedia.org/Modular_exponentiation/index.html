Modular exponentiation


Operation: c = be mod m
Efficient method: Exponentiation by squaring
Used in: RSA, Diffie–Hellman, ElGamal

Modular exponentiation is exponentiation performed over a modulus. It is a fundamental operation in computer science and number theory, central to public-key cryptography: given a base b, exponent e, and modulus m, it computes the remainder of be divided by m.

Computing it efficiently

Computing the power first and then reducing would require enormous intermediate numbers when the exponent is large — in cryptographic use, exponents may have thousands of bits. The standard method is exponentiation by squaring (the right-to-left binary method): the exponent is processed bit by bit, the base is repeatedly squared, and every intermediate result is reduced modulo m, keeping all numbers smaller than m2. This gives an algorithm running in time proportional to the number of bits of the exponent.

Applications

Modular exponentiation underlies the RSA cryptosystem, in which encryption and decryption are both modular exponentiations, the Diffie–Hellman key exchange, and the ElGamal and DSA signature schemes. Its inverse problem — the discrete logarithm — is believed to be computationally hard for suitable moduli, and that hardness is the basis of the security of these systems.
