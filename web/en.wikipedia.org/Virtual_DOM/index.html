Virtual DOM

A virtual DOM (VDOM) is a programming concept in which an ideal, "virtual" representation of a user interface is kept in memory and synced with the "real" Document Object Model (DOM) by a library such as ReactDOM. This process is called reconciliation.

How it works

When application state changes, the framework renders a new virtual tree and diffs it against the previous one. Only the minimal set of changes needed to update the real DOM is computed and applied (a process often called "patching"), avoiding the cost of directly manipulating the DOM on every state change, which can trigger expensive layout and paint operations in the browser.

History and implementations

The approach was popularized by Facebook's React library, released in 2013, and has since been adopted by Vue.js, Ember.js (Glimmer), and many other frameworks, as well as by implementations in other languages such as Elm's virtual DOM. Some newer frameworks, such as Svelte, question the technique, compiling components to direct DOM updates instead, and React itself has continued to refine its reconciliation algorithms (for example with the Fiber rewrite).
