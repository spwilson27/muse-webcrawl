Notation3

Notation3 (N3)
Filename extension.n3
Designed byTim Berners-Lee
PurposeSerialisation of RDF data; rules language

Notation3, or N3 as it is more commonly known, is a shorthand non-XML serialisation of the Resource Description Framework (RDF) model, designed for human read-writeability by Tim Berners-Lee and colleagues as part of the Semantic Web programme. N3 extends the simpler Turtle language by adding the ability to express rules — formulae and logical implication — within the same syntax.

Features

Like Turtle, N3 omits much of the verbosity of RDF/XML: namespaces are declared as prefixes, repeated subjects are grouped with semicolons, and lists use shortcut syntax. N3 goes further by supporting:

  • Variables and quantification within formulae, enclosed in braces;
  • The implication predicate log:implies, allowing N3 documents to state rules ("if these triples hold, then that triple holds");
  • Quoting of graphs and literals in several datatypes, and built-in functions from vocabularies such as the log and math namespaces.

Example

@prefix : <#> .
:Socrates a :Man .
{ ?x a :Man } => { ?x a :Mortal } .

This states that Socrates is a man, together with a rule from which a reasoner can infer that Socrates is mortal.

Use and standardisation

N3 has been used in Semantic Web tools and reasoners such as cwm and EYE. Although N3 itself was never elevated to a full W3C Recommendation, its subset Turtle became a W3C standard in 2014, and N3 continued to be developed by a W3C community group towards a formal specification.
