Local search (optimization)

In computer science, local search is a heuristic method for solving computationally hard optimization problems. Local search algorithms move from solution to solution in the search space by applying local changes, until a solution deemed optimal is found or a time bound elapses.

Method

A local search starts from a candidate solution and iteratively moves to a neighbouring solution — one reachable by a small modification defined by a neighbourhood relation. It is a hill-climbing approach and may stop at a local optimum that is not globally optimal.

Applications

Local search is widely used for the travelling salesman problem, scheduling, the Boolean satisfiability problem, nurse rostering, protein structure prediction and many other NP-hard problems, where exact methods are impractical.

Variants

Metaheuristics build on local search to escape local optima: simulated annealing accepts worse moves with decreasing probability, tabu search forbids recently visited solutions, and variable neighbourhood search changes the neighbourhood structure. WalkSAT and GSAT are classic local search procedures for satisfiability.
