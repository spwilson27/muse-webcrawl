In the context of complex dynamics, a branch of mathematics, the Julia set and the Fatou set are two complementary sets (Julia "laces" and Fatou "dusts") defined from a function. Informally, the Fatou set of the function consists of values with the property that all nearby values behave similarly under repeated iteration, whereas the Julia set consists of values on which arbitrarily small perturbations can cause drastic changes in the sequence of iterated function values.

History

The sets are named after the French mathematicians Pierre Fatou and Gaston Julia, who independently studied the iteration of rational functions in the early 20th century, with major memoirs appearing in 1917–1920. Their work was largely eclipsed until computer graphics in the late 1970s — and Benoit Mandelbrot's popularisation of fractals — revealed the sets' intricate beauty.

Quadratic polynomials

The best-known examples come from the family f(z) = z² + c. For each complex parameter c, the filled Julia set consists of points whose orbits under iteration remain bounded; the Julia set is its boundary. When c lies inside the Mandelbrot set, the Julia set is connected; otherwise it is a Cantor set of disconnected "dust". Famous examples include the dendrite (c = i), the Douady rabbit (c ≈ −0.123 + 0.745i), and Siegel disks, where the boundary behaviour involves rotation numbers.

Properties

Julia sets are invariant under the function, and dynamics on them is chaotic: the iteration restricted to the Julia set is sensitive to initial conditions and topologically transitive, with periodic points dense. Many Julia sets are fractals with non-integer Hausdorff dimension.
