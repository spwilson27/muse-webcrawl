Lempel–Ziv–Markov chain algorithm

The Lempel–Ziv–Markov chain algorithm (LZMA) is a lossless data compression algorithm developed by Igor Pavlov and released in 1998–99 as part of the 7-Zip file archiver. It combines a large-window dictionary coder based on LZ77 with a range encoder driven by context models organised as Markov chains, achieving compression ratios typically better than bzip2 and the DEFLATE algorithm used in gzip and ZIP, at the cost of slower compression speed.

How it works

LZMA analyses the input as a sequence of literals and matches (length–distance pairs referring back to earlier data in a sliding dictionary of up to 4 GB). Each symbol is encoded by an adaptive binary range coder whose probability estimates are selected by context: the state of the match finder, the position in the stream, and the values of recently encoded bytes. This context modelling, which treats the recent history as a Markov state, is the source of the algorithm's name and much of its efficiency. Decompression is comparatively fast and requires modest memory, an asymmetry suited to software distribution and firmware.

Formats and uses

LZMA is the default and strongest compression method of the .7z format. Its successor, LZMA2, adds support for parallel compression and better handling of incompressible data, and is the basis of the .xz format widely used for distributing Linux kernel sources and packages. LZMA is also used in the Windows Imaging Format, in installers, in ROM and BIOS images, and in the Python (lzma module) and Java standard ecosystems.
