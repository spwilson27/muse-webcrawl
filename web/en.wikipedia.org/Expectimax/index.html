Expectimax

The expectimax algorithm is a variation of the minimax algorithm for use in artificial intelligence systems that play two-player zero-sum games, such as backgammon, in which the expected outcome depends partly on chance. In addition to the "max" and "min" nodes of the traditional minimax tree, expectimax introduces "chance" nodes, whose value is the expected value (probability-weighted average) of the outcomes of all possible random events below them — for example, all possible dice rolls.

How it differs from minimax

In minimax, each node takes either the maximum (at the player's nodes) or minimum (at the opponent's nodes) of its children's values. In expectimax, chance nodes take the weighted average instead, reflecting that the dice do not conspire against the player the way an opponent does. Because averaging intervenes, the alpha-beta pruning used to speed up minimax does not directly apply, though bounds on leaf values allow related pruning techniques ("*"-minimax) to cut off some branches. The algorithm was introduced by Donald Michie in 1966.

Pseudocode outline

Expectimax(node, depth): if depth is zero or the node is terminal, return the heuristic value. If the node is a chance node, return the probability-weighted sum of Expectimax over its children. If it is a max node, return the maximum of the children's values; if a min node, the minimum. Expectimax search was notably used in computer backgammon programs and in the analysis of games with dice or card draws, and underlies agents for the game 2048.
