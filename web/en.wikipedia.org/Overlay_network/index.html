Overlay network

An overlay network is a computer network that is built on top of another network. Nodes in the overlay can be thought of as being connected by virtual or logical links, each of which corresponds to a path, perhaps through many physical links, in the underlying network.

Uses

Overlay networks are used to implement services that are not provided by the underlying network, such as resilient routing, content delivery, and peer-to-peer file sharing. Many peer-to-peer systems, including early file-sharing networks and distributed hash tables, are overlay networks because their nodes run on top of the Internet.

Examples

Examples include content delivery networks, virtual private networks (VPNs), the Tor anonymity network, multicast overlays, and cloud computing virtual networks built with protocols such as VXLAN. The Internet itself was originally conceived as an overlay on telephone networks.

Advantages and disadvantages

Overlays can be deployed without changes to underlying infrastructure and can add routing intelligence, but they may introduce inefficiency because the overlay cannot always account for the physical topology beneath it.
