EasyList

Type: Filter list

First released: 2005

License: Creative Commons / GPL

Website: easylist.to

EasyList is a primary filter list used by ad blockers to remove advertising and other unwanted content from web pages. Originally created in 2005 by Rick752, EasyList has become the most widely used filter list in the world and serves as the default subscription in many ad-blocking browser extensions, including Adblock Plus, uBlock Origin and AdGuard.

History

EasyList began in 2005 as a personal filter set maintained by the user known as Rick752 for the Adblock extension. After Rick752's death in 2009, stewardship of the list passed to a group of maintainers who continue to update it daily. In 2011, EasyList was merged with Fanboy's List, another popular filter set, and the combined project has since been maintained by the EasyList authors.

Content and syntax

EasyList uses the Adblock Plus filter syntax, a set of rules describing network requests and page elements to block or hide. Rules can match URLs by pattern, use wildcards and regular expressions, hide page elements through CSS selectors, and include exceptions that whitelist content. Regional supplementary lists, such as EasyList Germany or EasyList China, extend the main list for specific languages and regions.

Companion lists

The EasyList project also maintains EasyPrivacy, a list that blocks web tracking, and Fanboy's Annoyances, which removes social-media widgets, cookie notices and other page clutter. Along with EasyList itself, these lists form the core filter subscriptions shipped with most ad blockers.
