Baum–Welch algorithm

The Baum–Welch algorithm is a method for estimating the unknown parameters of a hidden Markov model (HMM) from observed data. It is a special case of the expectation–maximization (EM) algorithm, developed from work by Leonard Baum and colleagues in the 1960s and 1970s.

How it works

The algorithm alternates between two steps. In the expectation step, the forward–backward algorithm computes the probability of being in each hidden state at each time, given the current parameters. In the maximization step, those probabilities are used to re-estimate the transition and emission probabilities. Iteration continues until the likelihood of the observed sequence converges to a local maximum.

Applications

Baum–Welch training underlies classic HMM applications including speech recognition, bioinformatics sequence analysis, and cryptanalysis. Because it converges only to a local optimum, results depend on the initial parameter estimates.
