x86-64

The AMD Opteron, the first processor to implement the x86-64 architecture

x86-64 (also known as x64, x86_64, AMD64, and Intel 64) is a 64-bit extension of the x86 instruction set architecture. It was first announced in 1999 and first released by AMD in 2003 with the Opteron and Athlon 64 processor lines. The architecture extends the general-purpose registers to 64 bits, increases their number from 8 to 16, and raises the virtual address space from 4 GiB to a theoretical 16 exbibytes, while retaining full backward compatibility with 16-bit and 32-bit x86 code.

x86-64 was an alternative to Intel's IA-64 architecture, which was a clean-slate 64-bit design incompatible with x86. Intel eventually adopted x86-64 in its own processors beginning in 2004. The architecture has become the dominant instruction set for personal computers, workstations, and servers, supported by operating systems including Microsoft Windows, macOS, and Linux.

History

AMD publicly disclosed the x86-64 specification in August 2000. Because it built on the existing x86 architecture, software could be migrated gradually: 32-bit operating systems and applications continued to run unchanged, and developers could port code incrementally. The first x86-64 processors, the Opteron (for servers) and Athlon 64 (for desktops), shipped in 2003. Intel, which had initially pursued the Itanium (IA-64) line, introduced its own implementation, first called EM64T and later Intel 64, in the Prescott revision of the Pentium 4 in 2004.

Architectural features

In 64-bit mode, x86-64 provides sixteen 64-bit general-purpose registers, a 64-bit virtual address space (of which implementations initially used 48 bits), and a flat memory model. Additional features include RIP-relative addressing, which simplifies position-independent code, and the NX bit for marking memory pages as non-executable. The legacy and compatibility modes allow unmodified 16-bit and 32-bit x86 applications to run under a 64-bit operating system.

Operating modes

The architecture operates in several modes: long mode (comprising 64-bit mode and compatibility mode), legacy mode for running 16-bit and 32-bit operating systems, and system management mode. Long mode disables segmentation for most purposes while retaining paging as the primary memory protection mechanism.
