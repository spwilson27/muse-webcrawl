Address Resolution Protocol

The Address Resolution Protocol (ARP) is a communication protocol used for discovering the link layer address, such as a MAC address, associated with a given internet layer address, typically an IPv4 address. This mapping is a critical function in the Internet protocol suite. ARP was defined in 1982 by RFC 826.

Operation

When a host needs to send a packet to another host on the same local area network, it broadcasts an ARP request asking which device owns the target IP address. The device with that address replies with its hardware address, and the sender caches the mapping in its ARP table for future use.

Packet structure

ARP messages specify hardware and protocol address types and lengths, an operation code (request or reply), and the sender and target hardware and protocol addresses. For Ethernet and IPv4, hardware addresses are 48 bits and protocol addresses 32 bits.

Scope and related protocols

ARP operates only within a single network segment and is not routed. IPv6 replaces ARP with the Neighbor Discovery Protocol using ICMPv6. Because ARP has no authentication, it is vulnerable to ARP spoofing, in which an attacker associates their own MAC address with another host's IP address.
