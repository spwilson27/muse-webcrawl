Dirichlet character

Values of a Dirichlet character modulo 5 in the complex plane.

In number theory, a Dirichlet character is a certain type of arithmetic function arising from completely multiplicative functions on the units of the ring ℤ/qℤ of integers modulo q. Dirichlet characters are central to analytic number theory and were introduced by Dirichlet in his proof of the infinitude of primes in arithmetic progressions.

Definition

A Dirichlet character modulo q is a function χ from the integers to the complex numbers such that: χ is completely multiplicative, χ(ab) = χ(a)χ(b); χ is periodic with period q; and χ(n) = 0 whenever gcd(n, q) > 1, while χ(n) ≠ 0 otherwise. Equivalently, a Dirichlet character is the unique extension by zero and periodicity of a group homomorphism from the multiplicative group (ℤ/qℤ)× to the nonzero complex numbers. There are exactly φ(q) distinct characters modulo q.

Principal and primitive characters

The principal character modulo q, χ₀, equals 1 for all n coprime to q and 0 otherwise. A character is primitive if it is not induced from a character of smaller modulus; the smallest such modulus is its conductor. A character is called real (or quadratic) if its values are real — equivalently of order 1 or 2 — the nontrivial real primitive characters correspond, via Kronecker's theory, to quadratic fields and are expressed using the Legendre and Kronecker symbols.

Applications

Dirichlet characters are the building blocks of Dirichlet L-functions, L(s, χ), which generalize the Riemann zeta function. Using orthogonality of characters, Dirichlet proved that any coprime arithmetic progression a, a+q, a+2q, … contains infinitely many prime numbers. Characters also appear in estimates for primes in progressions, the theory of Gauss sums, and class number formulas.
