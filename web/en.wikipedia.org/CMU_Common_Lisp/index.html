CMU Common Lisp

CMU Common Lisp (CMUCL) is a free implementation of the Common Lisp programming language, originally developed at Carnegie Mellon University beginning in the early 1980s. It is distinguished by its native-code compiler, called Python (unrelated to the Python programming language), which generates efficient machine code.

Features

CMUCL compiles Lisp code to native instructions for platforms including x86 and SPARC, offers precise type inference and declarations-based optimisation, and includes a sophisticated debugger, an interface to the Hemlock editor and support for foreign-function calls. Its compiler's strong type checking made it popular for performance-sensitive Lisp applications.

Influence and derivatives

CMUCL was released into the public domain (apart from some contributed code) and runs on Linux, FreeBSD and other Unix-like systems. In 2000, its codebase was forked to create Steel Bank Common Lisp (SBCL), which has since become the more widely used of the two implementations.
