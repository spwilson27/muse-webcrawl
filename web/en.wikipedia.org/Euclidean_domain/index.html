Euclidean domain

Euclidean domain
FieldAbstract algebra (ring theory)
ImpliesPrincipal ideal domain ⇒ unique factorisation domain
ExamplesIntegers, polynomial rings over a field, Gaussian integers

In mathematics, a Euclidean domain is an integral domain that can be endowed with a Euclidean function allowing a suitable generalisation of the Euclidean algorithm for ordinary integers. The function measures the "size" of elements so that division with remainder always leaves a smaller remainder.

Definition

An integral domain R is Euclidean if there is a function f from the non-zero elements of R to the natural numbers such that for any a and non-zero b in R there exist q and r in R with a = bq + r and either r = 0 or f(r) < f(b). Under this condition, the Euclidean algorithm computes greatest common divisors, and every ideal is principal.

Examples

The integers with f(n) = |n|; any field (trivially); the polynomial ring F[x] over a field F with f = degree; and the Gaussian integers ℤ[i] with the norm f(a + bi) = a² + b² are Euclidean domains. Not every principal ideal domain is Euclidean: the ring of integers of ℚ(√−19) is a standard counterexample.

Properties

Every Euclidean domain is a principal ideal domain, and every principal ideal domain is a unique factorisation domain. The converses fail in general, making Euclidean domains the most computationally tractable class in this hierarchy.
