Redirection (computing)

In computing, redirection is a form of interprocess communication that changes the standard streams of a command or process, so that input is read from, or output written to, a file or another stream instead of the default terminal.

Shell redirection

In Unix-like shells, the operators > and >> redirect standard output to a file (overwriting or appending), < redirects standard input from a file, and 2> redirects the standard error stream. Pipelines, using the | operator, redirect the output of one command into the input of another, allowing small tools to be combined.

Other contexts

The term is also used for URL redirection on the web, where a page automatically forwards visitors to a different address, and for redirecting standard handles within programs using system calls such as dup2.
