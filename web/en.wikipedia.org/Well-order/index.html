Well-order

In mathematics, a well-order (or well-ordering) on a set S is a total order on S with the property that every non-empty subset of S has a least element in this order. Together, the set and the well-order form a well-ordered set.

Examples

The standard ordering of the natural numbers is a well-order: every non-empty set of natural numbers has a smallest element. By contrast, the integers, rational numbers and real numbers under their usual orderings are not well-ordered — for example, the set of negative integers has no least element.

Properties

In a well-ordered set every element has a unique successor (unless it is the maximum), and transfinite induction and transfinite recursion are valid. Every well-ordered set is order-isomorphic to a unique ordinal number.

Well-ordering theorem

The well-ordering theorem states that every set can be well-ordered. It is equivalent to the axiom of choice and to Zorn's lemma in Zermelo–Fraenkel set theory. Ernst Zermelo proved the theorem in 1904 using the axiom of choice, a result that was initially controversial.
