ed (text editor)

ed is a line editor for Unix and Unix-like operating systems. It was one of the first parts of the Unix operating system that was developed, in August 1969, initially in PDP-7 assembly by Ken Thompson. Many features of ed came from the qed text editor developed at Thompson's alma mater, the University of California, Berkeley. Ken Thompson was very familiar with qed, and had reimplemented it on the CTSS and Multics systems.

Description

ed is a line-oriented editor: it works on one or more lines of a file at a time, selected by addresses that may be line numbers, search patterns, or ranges. It has a command mode (its default) and an input mode entered with the append, insert, or change commands. Its terse interface reflects its teletypewriter origins — it prints only a character count on loading a file, and its sole error message is a question mark, though a help command in later versions provides slightly more information.

Influence

ed introduced or popularized several features that became central to Unix text processing. Its regular expression syntax — adapted from the formalism of Stephen Cole Kleene via qed — was adopted by many later tools. The stream editor sed and the interactive editor ex (from which vi developed) are direct descendants of ed, as is the g/re/p pattern that gave the grep utility its name: globally search for a regular expression and print matching lines. The text editor sam was described by its creator Rob Pike as a successor to ed.

Legacy

ed remains standardized by POSIX and is still shipped with Unix-like systems, though it is now used mainly in scripts and in constrained environments. It is the subject of a well-known humorous refrain in computing culture: "ed is the standard text editor."
