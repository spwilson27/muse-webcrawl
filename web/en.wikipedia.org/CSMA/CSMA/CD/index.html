CSMA/CD

Carrier-sense multiple access with collision detection (CSMA/CD) is a medium access control (MAC) protocol used most notably in early Ethernet technology for local area networking. It was used in combination with the physical layer of the original and fast Ethernet standards over shared media such as coaxial cable and repeater hubs.

Operation

A device wishing to transmit first listens to the medium ("carrier sense"). If the channel is idle, it begins transmitting while continuing to monitor for a collision — the simultaneous transmission by another station that also found the channel idle. If a collision is detected, the station sends a short jam signal so all senders know, then stops and waits a random backoff interval (chosen by truncated binary exponential backoff) before retrying. After 16 failed attempts, the frame is abandoned and an error reported.

For collisions to be detectable, a frame must still be transmitting when the signal of the colliding frame returns; classic Ethernet therefore specified a minimum frame size of 64 bytes and limited the network diameter, defining the 512-bit-time "slot time".

Decline

Switched, full-duplex Ethernet gives each station a private link to a switch, so collisions cannot occur and CSMA/CD is disabled. Gigabit Ethernet retained a half-duplex mode with carrier extension, but 10 Gigabit Ethernet and later standards are full-duplex only, making CSMA/CD effectively obsolete in modern networks — though its random-backoff ideas survive in Wi-Fi's related CSMA/CA protocol.
