Point-to-Point Protocol

PPP
OSI layer: Data link (Layer 2)
Standard: RFC 1661 (1994)
Predecessor: SLIP
Uses: Dial-up access, DSL (PPPoE), serial links

In computer networking, Point-to-Point Protocol (PPP) is a data link layer (layer 2) communication protocol between two routers that directly connects them without any host or any other networking in between. It can provide loop detection, authentication, transmission encryption, and data compression.

Features

PPP uses the Link Control Protocol (LCP) to establish and configure the connection, and a family of Network Control Protocols (NCPs) to configure different network-layer protocols such as IP and IPX. It supports authentication methods including PAP and the more secure CHAP, and error detection via a frame check sequence. PPP largely replaced the simpler SLIP for dial-up Internet access in the 1990s.

Encapsulation

PPP frames resemble HDLC frames, with flag, address, control, protocol, payload, and frame check sequence fields. Byte stuffing is used to escape special characters on asynchronous links.

Variants

PPPoE (PPP over Ethernet) is widely used for DSL and fiber broadband authentication; PPPoA was used over ATM networks. PPP also underlies many VPN and tunneling arrangements, often together with L2TP.
