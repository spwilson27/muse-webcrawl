Phrase structure grammar

A phrase structure grammar is a type of generative grammar in which the constituent structure of sentences is described by rewrite rules (phrase structure rules) that expand symbols into sequences of other symbols, producing parse trees. The framework originates in Noam Chomsky's work of the 1950s, especially Syntactic Structures (1957).

Constituency and dependency

Unlike dependency grammar, which relates words directly, phrase structure grammar groups words into nested constituents (noun phrases, verb phrases and so on). A typical rule set includes S → NP VP, NP → Det N, VP → V NP.

Descendants

Transformational grammar, generalized phrase structure grammar (GPSG), head-driven phrase structure grammar (HPSG) and lexical functional grammar (LFG) all descend from or react to classical phrase structure grammar. In computer science the same formalism underlies context-free grammars used in parsing programming languages.
