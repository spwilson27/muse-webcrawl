Test function

In mathematics, a test function is a particularly well-behaved function used to probe other objects, especially in the theory of distributions. Typically, a test function is infinitely differentiable and has compact support — it vanishes outside some bounded region — so that it can be paired with a distribution without boundary or convergence difficulties.

Bump functions

The standard example is the bump function, a smooth function that is positive on an interval and zero outside it. A canonical construction uses the function e−1/x for x > 0 and 0 for x ≤ 0, which is infinitely differentiable everywhere despite not being analytic. Scaling and translating bump functions produces mollifiers, used to approximate functions by smooth ones.

Role in distribution theory

Laurent Schwartz defined distributions as continuous linear functionals on a space of test functions. Every locally integrable function defines a distribution by integration against a test function, and operations such as differentiation extend to distributions through integration by parts. The Schwartz space of rapidly decreasing smooth functions serves a similar role for tempered distributions and the Fourier transform.
