Least-upper-bound property

The least-upper-bound property (also called the completeness property or supremum property) is a fundamental property of the real numbers: every nonempty set of real numbers that is bounded above has a least upper bound (supremum) that is itself a real number.

Significance

The property distinguishes the real numbers from the rational numbers: the set of rationals whose square is less than 2 is bounded above but has no rational supremum. In axiomatic treatments, the least-upper-bound property is taken as the completeness axiom characterising ℝ, and many cornerstones of analysis — the intermediate value theorem, the Bolzano–Weierstrass theorem, and the convergence of bounded monotone sequences — follow from it.

Generalisation

An ordered set with the property that every bounded nonempty subset has a supremum is called Dedekind-complete; the concept generalises in order theory and lattice theory.
