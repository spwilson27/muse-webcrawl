PowerShell

PowerShell is a task automation and configuration management program from Microsoft, consisting of a command-line shell and the associated scripting language. Initially a Windows component only, known as Windows PowerShell, it was made open-source and cross-platform on 18 August 2016 with the introduction of PowerShell Core. The former is built on the .NET Framework, the latter on .NET Core (now simply .NET).

Design

In PowerShell, administrative tasks are generally performed via cmdlets (pronounced "command-lets"), which are specialized .NET classes implementing a particular operation. These work by accessing data in different data stores, like the file system or Windows registry, which are made available to PowerShell via providers. Unlike traditional shells, which pass text between commands, PowerShell pipelines pass structured .NET objects, allowing cmdlets to operate on properties and methods directly. Cmdlets follow a Verb-Noun naming pattern, such as Get-ChildItem and Set-Location.

PowerShell includes its own scripting language with variables, flow control, functions, and access to the full .NET class library, making it comparable in capability to languages such as Perl and Python for system administration tasks. It also supports remoting over WS-Management and SSH, allowing administrators to run commands on remote systems.

History

PowerShell was developed under the codename "Monad" and first discussed publicly in 2003 by Jeffrey Snover, who sought to bring a modern, object-oriented shell to Windows, informed by Unix shells and by experience with Digital Equipment Corporation's DCL. Windows PowerShell 1.0 was released in November 2006 for Windows XP SP2, Windows Server 2003 SP1, and Windows Vista. Version 2.0 shipped with Windows 7. PowerShell Core 6.0, released in January 2018, brought the shell to macOS and Linux; version 7.0 followed in 2020, unifying the product line as simply PowerShell.

Usage

PowerShell is the principal automation tool for administering Windows environments, including Active Directory, Exchange, Azure, and Microsoft 365. Its integration with Windows Management Instrumentation (WMI) and its desired-state configuration (DSC) features make it central to infrastructure-as-code practices in Microsoft shops. It has also been adopted for security research and, conversely, by attackers, prompting extensive logging and monitoring capabilities such as script block logging and the Antimalware Scan Interface (AMSI).
