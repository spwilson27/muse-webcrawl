Loader (computing)

A loader copies a program from storage into main memory and prepares it for execution.

In computer systems, a loader is the part of an operating system that is responsible for loading programs and libraries. It is one of the essential stages in the process of starting a program, as it places programs into memory and prepares them for execution. Loading a program involves either copying the contents of the executable file from storage media into main memory, or mapping the contents of the executable file into a region of memory (memory-mapping), and performing other preparatory tasks to prepare the executable for running. Once loading is complete, the operating system starts the program by passing control to the loaded program code.

Relocating loaders

Some loaders, called relocating loaders, must adjust (relocate) addresses in the program to account for the actual address at which the program is loaded. Loaders may also resolve references to dynamically linked libraries, either at load time or lazily at runtime, in cooperation with the dynamic linker.

Types

  • Absolute loaders — load programs at a fixed, predetermined address.
  • Relocating loaders — adjust addresses based on the load address.
  • Dynamic loaders/linkers — load shared libraries and resolve symbols, e.g. ld.so on Unix-like systems.
  • Bootstrap loaders — small loaders, stored in firmware, that load the operating system itself.
