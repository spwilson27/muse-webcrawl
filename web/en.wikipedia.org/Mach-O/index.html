Mach-O

Mach-O
Type: Executable/object file format
Developed by: Carnegie Mellon; Apple
Magic number: 0xFEEDFACE / 0xFEEDFACF

Mach-O, short for Mach object file format, is a file format for executables, object code, shared libraries, dynamically loaded code, and memory dumps. It was developed to replace the a.out format.

History

Mach-O was introduced with the Mach kernel at Carnegie Mellon University and adopted by NeXTSTEP and later by Apple's macOS and iOS, where it remains the native object format.

Structure

A Mach-O file begins with a header specifying architecture and file type, followed by load commands describing segments and sections. "Universal" (fat) binaries bundle Mach-O files for multiple architectures.
