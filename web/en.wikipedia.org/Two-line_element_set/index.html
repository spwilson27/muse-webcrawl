Two-line element set

A two-line element set (TLE, or more recently three-line element set when a title line is included) is a data format encoding a list of orbital elements of an Earth-orbiting object for a given point in time, the epoch. Using a suitable prediction model — the SGP4/SDP4 algorithms — the position and velocity of the object can be calculated at any time in the past or future with useful accuracy. TLEs are produced by the United States Space Force's space surveillance system and are publicly distributed, most notably via CelesTrak, for satellites and space debris.

Format

Each set consists of two 69-character lines. Line 1 contains the satellite catalogue number, classification, international designator, epoch, the derivatives of mean motion, a drag term, and an element-set number with a checksum. Line 2 gives the orbital inclination, right ascension of the ascending node, eccentricity, argument of perigee, mean anomaly and mean motion, from which the semi-major axis and orbital period follow.

Limitations

TLE accuracy is typically on the order of a kilometre at epoch and degrades over days to weeks, especially for objects in low orbit affected by atmospheric drag or manoeuvres. TLEs are therefore a tracking and conjunction-screening tool rather than a precision navigation product, and their fixed-width format, designed for punched cards, is a legacy constraint on the data they can express.
