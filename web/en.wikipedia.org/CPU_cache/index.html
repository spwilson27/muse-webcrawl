CPU cache

A CPU cache is a hardware cache used by the central processing unit (CPU) of a computer to reduce the average cost (time or energy) to access data from the main memory. A cache is a smaller, faster memory, located closer to a processor core, which stores copies of the data from frequently used main memory locations.

Hierarchy

Most modern CPUs have multiple levels of cache: a small, fast Level 1 cache split into instruction and data caches; a larger Level 2 cache per core; and a shared Level 3 cache across cores. Memory locations are read or created in cache lines, typically 64 bytes.

Policies

Cache design involves choices of mapping (direct-mapped, set-associative or fully associative), replacement policy (commonly least-recently-used), and write policy (write-through or write-back), together with coherence protocols such as MESI in multicore systems. Cache performance critically affects overall system speed, and side-channel attacks such as Spectre exploited speculative cache behaviour.
