Binary heap

A binary heap is a tree-based data structure that satisfies the heap property: in a min heap, each parent node's key is less than or equal to the keys of its children, so the smallest element sits at the root; in a max heap, the ordering is reversed. Binary heaps are the standard implementation of the priority queue abstract data type and underpin the heapsort sorting algorithm.

Structure

A binary heap is stored as a complete binary tree: every level is fully filled except possibly the last, which is filled from the left. Because of this shape, the tree can be stored compactly in an array without pointers. For a node at index i (in a 1-based array), its children are at indices 2i and 2i+1 and its parent is at floor(i/2). The height of a heap with n elements is Θ(log n).

Operations

Inserting an element appends it at the end of the array and then "bubbles up" (sift-up), swapping it with its parent while the heap property is violated. Extracting the minimum removes the root, moves the last element to the root, and "bubbles down" (sift-down), swapping it with its smaller child until the property is restored. Both operations cost O(log n). A heap can be built from an unordered array in linear time by sifting down each internal node from the bottom up, a method analysed by Robert W. Floyd.

Applications

Binary heaps implement efficient priority queues used in Dijkstra's shortest-path algorithm, Prim's minimum spanning tree algorithm, event-driven simulation, and operating-system job scheduling. Heapsort sorts an array in O(n log n) time and O(1) extra space by repeatedly extracting the extremum. Variants such as Fibonacci heaps and binomial heaps improve the amortised cost of some operations, at the price of greater complexity.

History

The binary heap was introduced by J. W. J. Williams in 1964 as the basis of heapsort, and Floyd published the efficient linear-time construction algorithm in the same period.
