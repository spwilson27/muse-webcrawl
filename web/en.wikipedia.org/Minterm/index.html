Minterm

In Boolean algebra, a minterm is a product term in which every variable of the function appears exactly once, either in its true or complemented form. A Boolean function can be expressed as a sum (logical OR) of the minterms for which the function output is 1; this is its canonical sum-of-minterms form.

Indexing

Minterms are conventionally indexed by the binary value of the variable assignment that makes them true: for example, for variables x, y, z, the minterm x·ȳ·z is m5, since its assignment 101 is binary five. Minterms underpin methods of logic minimisation such as Karnaugh maps and the Quine–McCluskey algorithm, and the dual concept is the maxterm.
