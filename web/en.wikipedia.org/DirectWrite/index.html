DirectWrite

DirectWrite is a text layout and glyph rendering API from Microsoft, introduced with Windows 7 and Windows Vista (via the Platform Update) as part of the DirectX family of APIs. It was designed to succeed GDI and GDI+ for high-quality screen text rendering.

Features

DirectWrite supports ClearType subpixel rendering with hardware acceleration through Direct2D, advanced typographic features of OpenType (ligatures, stylistic alternates, contextual forms), multilingual text layout, and bidirectional and complex-script text. It handles font enumeration, fallback for missing glyphs, and text measurement for applications.

Adoption

The API is used by web browsers such as Google Chrome and Mozilla Firefox on Windows, by Microsoft Office, and by many desktop applications requiring crisp, device-independent text rendering.
