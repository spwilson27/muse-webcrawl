Anycast

Anycast is a network addressing and routing methodology in which a single IP address is assigned to multiple interfaces or nodes, and network routers deliver packets to the topologically nearest — typically the "best" — destination among the group, using standard routing protocols such as BGP.

How it works

Multiple servers at different geographic locations advertise the same IP prefix into the routing system. The Internet's routing fabric naturally directs each client's traffic to whichever announcement is closest in routing terms, providing automatic load distribution across locations and seamless failover: if one site fails and withdraws its route, traffic flows to the next-nearest site.

Applications

Anycast is central to the Domain Name System: most of the 13 logical root name server addresses are served by hundreds of anycast instances worldwide. Content delivery networks and large DNS resolvers use anycast to reduce latency and absorb distributed denial-of-service attacks, since attack traffic is dispersed across many sites. Anycast is used mainly with connectionless protocols such as UDP, because routing changes mid-flow can break stateful TCP connections.
