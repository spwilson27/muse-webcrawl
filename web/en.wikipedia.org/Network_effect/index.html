Network effect

The network effect (also called network externality or demand-side economies of scale) is the phenomenon by which the value of a product or service depends on the number of others using it. The telephone is the classic example: a single telephone is useless, but its value rises as more people own one.

Types

Direct network effects arise when users benefit from other users of the same product, as in communication networks and social media. Indirect network effects arise when growth of one group benefits a complementary group, as when more users of an operating system attract more software developers. Network effects underlie Metcalfe's law, which holds that a network's value grows proportionally to the square of its number of users.

Business impact

Strong network effects create winner-take-all or winner-take-most markets, high switching costs, and barriers to entry, and are central to the strategy of platform businesses. They can also be negative: congestion on a network degrades value as users are added.
