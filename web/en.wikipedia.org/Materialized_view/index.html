Materialized view

In database management, a materialized view is a database object that contains the results of a query, stored physically like a table. It contrasts with an ordinary view, which is a virtual table computed on demand. Materialized views trade storage and refresh cost for much faster query response, and are widely used in data warehousing, reporting and replication.

Refresh

Because the stored result can become stale when base tables change, materialized views must be refreshed. Refresh may be complete (recomputing the whole view) or incremental (applying only changes, using logs of modifications to the base tables), and may occur on demand, on a schedule, or automatically when the underlying data is committed. Query rewrite features in some systems can transparently redirect queries on base tables to a suitable materialized view.

Implementations

Oracle Database introduced materialized views (originally "snapshots") and remains known for incremental refresh and query rewrite. PostgreSQL added built-in materialized views in version 9.3 with manual refresh; other systems — including SQL Server (indexed views), MySQL (via workarounds), and stream and lakehouse platforms — offer related features under various names.
