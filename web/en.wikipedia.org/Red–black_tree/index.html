Red–black tree

A red–black tree is a self-balancing binary search tree in which each node stores an extra bit representing a color, red or black. By constraining how colors can appear along any path, the tree guarantees that no root-to-leaf path is more than twice as long as any other, so the tree remains approximately balanced and search, insertion and deletion all take O(log n) time.

Red–black trees were invented in 1972 by Rudolf Bayer, who called them symmetric binary B-trees, and were popularized by Leonidas Guibas and Robert Sedgewick. They must satisfy: every node is red or black; the root is black; every leaf (NIL) is black; a red node's children are black; and every path from a node to its descendant leaves contains the same number of black nodes.

They are used in the Linux kernel's Completely Fair Scheduler, Java's TreeMap, C++ std::map, and many other systems. See also AVL tree, B-tree and binary search tree.
