Meagre set

In the mathematical fields of general topology and descriptive set theory, a meagre set (also called a set of first category) is a set that can be expressed as a countable union of nowhere dense sets. Non-meagre sets are said to be of second category.

Definitions

A subset of a topological space is nowhere dense if the interior of its closure is empty. A set is meagre if it is a countable union of nowhere dense sets. For example, the rational numbers are a meagre subset of the real line, since each singleton is nowhere dense and the rationals are countable.

Baire category theorem

The Baire category theorem states that a complete metric space is non-meagre in itself (a Baire space), so meagre sets may be thought of as "small" in a topological sense, complementing the measure-theoretic notion of a null set. The two notions differ: there exist meagre sets of full measure and comeagre sets of measure zero.
