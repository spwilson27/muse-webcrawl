Touchstone file

An example of S-parameter data in Touchstone format

A Touchstone file is an ASCII text file format used to record the network parameter data of electrical circuits and components, most commonly S-parameters measured by a vector network analyser. The format was introduced with the Touchstone radio-frequency simulation software from EEsof, which later became part of Agilent (now Keysight) Advanced Design System.

Format

Touchstone files conventionally carry extensions such as .s1p, .s2p and, in general, .sNp for an N-port network. An option line beginning with # declares the frequency unit (Hz, kHz, MHz or GHz), the parameter type (S, Y, Z, H or G), the data format (magnitude-angle, dB-angle or real-imaginary) and the reference resistance, typically 50 ohms. Data lines then list frequency followed by pairs of values for each matrix element. Version 2.0 of the specification, standardised under the IBIS Open Forum, added keyword-based metadata and per-port reference impedances.

Use

Because it is a plain-text, vendor-neutral format, the Touchstone file is the standard interchange format for measured and simulated RF and microwave component data, supported by virtually all network analysers and circuit simulators.
