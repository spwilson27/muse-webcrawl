BLAST (biotechnology)

BLAST

Full name: Basic Local Alignment Search Tool

Introduced: 1990

Authors: Stephen Altschul, Warren Gish, Webb Miller, Eugene Myers, David Lipman

Purpose: Comparing biological sequences against databases

BLAST (Basic Local Alignment Search Tool) is an algorithm and program for comparing primary biological sequence information, such as the amino-acid sequences of proteins or the nucleotides of DNA and RNA sequences. A BLAST search enables a researcher to compare a subject protein or nucleotide sequence (called a query) with a library or database of sequences, and identify database sequences that resemble the query sequence above a certain threshold.

How it works

BLAST uses a heuristic method that breaks the query into short "words", finds database sequences containing matching words, and then extends these seed matches in both directions to build local alignments, scoring them with substitution matrices such as BLOSUM62. Results are reported with an E-value estimating how many alignments of that quality would be expected by chance.

Variants

Different programs in the BLAST family search different combinations of query and database type: BLASTP (protein against protein), BLASTN (nucleotide), BLASTX (translated nucleotide against protein), TBLASTN, and TBLASTX. PSI-BLAST iterates the search using a profile built from initial results to detect more distant evolutionary relationships.

Impact

Published in 1990, BLAST became one of the most widely used and cited tools in bioinformatics; the free web service hosted by the U.S. National Center for Biotechnology Information (NCBI) is a standard starting point for identifying unknown sequences and inferring function by homology.
