Chromium (web browser)

DeveloperThe Chromium Projects (Google and contributors)
Initial release2008
EnginesBlink, V8
LicenseBSD-3-Clause and others

Chromium is a free and open-source web browser project, primarily developed and maintained by Google. It forms the codebase from which Google Chrome is built, and most modern browsers — including Microsoft Edge, Opera, Brave and Vivaldi — are based on it. Chromium's source code is released under the BSD license and other open-source licenses.

History

Google launched the Chromium project alongside Chrome in September 2008, publishing the underlying code as open source. Initially Chromium used the WebKit rendering engine; in 2013 Google forked WebKit to create the Blink engine, which now powers Chromium and its derivatives. The project also developed the V8 JavaScript engine, notable for its speed.

Chromium and Chrome

Chromium lacks several proprietary components included in Chrome, such as licensed media codecs, automatic updates, usage tracking and the official Google branding. Builds of Chromium are distributed by many Linux distributions, and it can be installed on Windows, macOS, Linux, Android and other platforms.

Influence

Chromium's market dominance has made it the de facto platform for web development: the vast majority of desktop and mobile browsing now occurs in Chromium-based browsers. Its derivatives include the operating system environment ChromeOS, which runs on Chromebook laptops and uses the browser as its principal interface.
