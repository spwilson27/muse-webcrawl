Decentralized application


Architecture of a decentralized application

A decentralized application (dApp or DApp) is a computer application that runs on a decentralized computing system, most commonly a blockchain network. Unlike traditional applications, whose backend runs on centralized servers, a dApp's backend code typically runs on a peer-to-peer network, often through smart contracts, and its operation is not controlled by any single entity.

Characteristics

Definitions vary, but dApps are usually described as open-source, operating autonomously, storing data in a decentralized blockchain, and using cryptographic tokens to incentivize participants. Ethereum, launched in 2015, became the most popular platform for dApps through its support for smart contracts.

Uses

Common categories include decentralized finance (DeFi) protocols for lending, borrowing, and exchange; games; gambling; marketplaces for non-fungible tokens (NFTs); and decentralized social media. Criticisms of dApps include poor user experience, scalability limits, transaction costs, and security vulnerabilities in smart contracts, which have led to major losses in high-profile exploits.
