Open-source software

Open-source software (OSS) is computer software that is released under a license in which the copyright holder grants users the rights to use, study, change, and distribute the software and its source code to anyone and for any purpose. Open-source software may be developed in a collaborative, public manner.

The term was popularized in 1998, when the Open Source Initiative (OSI) was founded by Bruce Perens and Eric S. Raymond, partly in reaction to perceived ambiguities in the phrase "free software" associated with Richard Stallman and the Free Software Foundation. The OSI maintains the Open Source Definition, a set of ten criteria a license must satisfy for software to be considered open source.

History

In the early decades of computing, software was commonly shared among researchers and users, often in source-code form. As commercial software became dominant in the 1970s and 1980s, source code was increasingly treated as a trade secret. The free software movement, launched by Stallman in 1983 with the GNU Project, sought to preserve users' freedoms to run, study, modify, and share software. The release of the Linux kernel by Linus Torvalds in 1991, combined with GNU tools, produced a widely used free operating system that demonstrated the viability of large-scale collaborative development.

Development model

Open-source projects are often developed by distributed communities of volunteers and paid contributors coordinated over the Internet. Version control systems, especially Git, issue trackers, mailing lists, and code review tools support this process. Many projects follow a "release early, release often" philosophy. Governance models range from a single maintainer or "benevolent dictator for life" to foundations and meritocratic committees, as with the Apache Software Foundation.

Licensing

Open-source licenses fall broadly into two families. Permissive licenses, such as the MIT License, BSD licenses, and Apache License 2.0, impose minimal restrictions and allow reuse in proprietary products. Copyleft licenses, notably the GNU General Public License (GPL), require derivative works to be distributed under the same license terms, ensuring the software remains free. The choice of license is a central decision for any open-source project.

Business and adoption

Open-source software underpins much of the modern Internet: the majority of web servers run Linux and open-source server software, and open-source components are pervasive in commercial products. Companies monetize open source through support contracts, hosting, dual licensing, and open-core models. Studies have repeatedly found that open-source development can reduce costs and increase security through public scrutiny, though underfunded maintenance of critical projects remains a concern.
