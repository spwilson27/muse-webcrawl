Gaussian elimination

[ Image placeholder: An augmented matrix being reduced to row echelon form ]

In mathematics, Gaussian elimination, also known as row reduction, is an algorithm for solving systems of linear equations. It consists of a sequence of operations performed on the corresponding matrix of coefficients: swapping two rows, multiplying a row by a non-zero number, and adding a multiple of one row to another. These operations do not change the solution set of the system. The process reduces the matrix to an upper triangular (row echelon) form, after which the solution is found by back-substitution. Reducing further, with each pivot made the only non-zero entry in its column, yields the reduced row echelon form — the Gauss–Jordan elimination method.

Applications

Besides solving linear systems, Gaussian elimination is used to find the rank of a matrix, compute the determinant (the product of the pivots up to sign, when only row-addition and swap operations are used), and calculate the inverse of an invertible matrix by augmenting with the identity matrix. It is equivalent to factorizing the matrix as an LU decomposition in computational practice.

History

The method appears in the Chinese mathematical text The Nine Chapters on the Mathematical Art (c. 200 CE), nearly two millennia before it became associated with Carl Friedrich Gauss, who used it in his 1809 work on the orbit of the asteroid Pallas. The name "Gaussian elimination" dates from the mid-20th century.

Computational considerations

The algorithm requires about n³/3 operations for an n×n system. In floating-point arithmetic, partial pivoting — choosing the largest available pivot in each column — is used to control round-off error. Gaussian elimination remains the standard dense direct method, though iterative methods may be preferable for very large sparse systems.

Example

For the system 2x + y − z = 8, −3x − y + 2z = −11, −2x + y + 2z = −3, elimination produces the triangular system from which one reads z = −1, then y = 3, then x = 2 by back-substitution.
