ZIP Code Tabulation Area

ZIP Code Tabulation Areas (ZCTAs) are statistical geographic entities developed by the United States Census Bureau to summarize census data for ZIP Code delivery areas. They were first introduced for the 2000 Census.

Definition

ZIP Codes themselves are collections of delivery routes maintained by the United States Postal Service, not true areas. To provide a stable areal unit for statistical tabulation, the Census Bureau assigns each census block to the ZIP Code that occurs most frequently among the addresses in that block, then aggregates blocks into a generalized area bearing that five-digit code. The result is a ZCTA.

Types

There are two kinds of ZCTAs: five-digit ZCTAs, which generalize the familiar five-digit ZIP Codes, and three-digit ZCTAs, which aggregate by the first three digits and are used where five-digit data would be too sparse. Some ZIP Codes, such as those for unique organizations or points, have no corresponding ZCTA.

Use

ZCTAs are widely used in public health research, demography, and geographic information systems as a convenient approximation of ZIP Code geography, though users are cautioned that they do not exactly match postal boundaries.
