Character (computing)

In computing and telecommunications, a character is a unit of information that roughly corresponds to a grapheme, letter, numeral, punctuation mark or other symbol of a natural language. Examples include letters, digits, spaces and control characters such as newline and tab.

Encoding

Computers store characters as numbers according to a character encoding such as ASCII or Unicode. In ASCII, each character occupies seven bits (commonly stored in one byte); in Unicode, characters are identified by abstract code points that may be encoded in one or more bytes depending on the encoding form (for example, UTF-8 uses a variable-length scheme).

In programming languages

Many programming languages have a character data type, often called char, conventionally holding a single character; strings are sequences of characters. In C, a char is a one-byte integer type, so characters and small integers are interchangeable, a design that persists in later languages.
