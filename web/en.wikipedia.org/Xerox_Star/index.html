Xerox Star

The Xerox Star, officially the Xerox 8010 Information System, was a workstation computer introduced by Xerox in 1981. It was the first commercial system to incorporate the graphical user interface (GUI) concepts developed at Xerox's Palo Alto Research Center (PARC): a bitmapped display, windows, icons, a mouse, Ethernet networking, file servers, print servers, and electronic mail.

Development

The Star was the commercial descendant of the experimental Xerox Alto (1973). David Liddle led the development organization, while David Canfield Smith and colleagues designed the user interface, popularizing the term "icon" and the desktop metaphor — an on-screen office with documents, folders, in-baskets, and a wastebasket. The system ran the Star software environment on the Dandelion processor with up to 1.5 MB of memory, a large (for the time) 17-inch bitmapped display, a 10–40 MB hard disk, and an optical two-button mouse.

Features

The Star presented a consistent, modeless interface in which users manipulated objects directly: select an object, then choose a generic command (MOVE, COPY, DELETE, SHOW PROPERTIES) from the keyboard or menu. It supported WYSIWYG document editing with integrated text and graphics, multiple fonts, and drag-and-drop years before these became commonplace.

Commercial performance and legacy

Initially priced at $16,595 per workstation — with a practical installation requiring several workstations, servers, and laser printers — the Star sold modestly, roughly 25,000 systems. It was a commercial disappointment but enormously influential: its interface directly informed the Apple Lisa and Macintosh, and through them virtually all subsequent personal computing. Follow-on systems included the Star ViewPoint software and Xerox's GlobalView.
