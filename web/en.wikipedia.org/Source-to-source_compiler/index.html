Source-to-source compiler

A source-to-source translator, source-to-source compiler (S2S compiler), transcompiler, or transpiler is a type of translator that takes the source code of a program written in a programming language as its input and produces an equivalent source code in the same or a different programming language, usually at a similar level of abstraction. This contrasts with a traditional compiler, which translates from a high-level language to a lower-level language such as assembly or machine code.

Uses

Transpilers are used for language migration (for example, converting legacy code to a modern language), for targeting platforms that lack a native compiler for a preferred language, and for implementing new languages on top of existing runtimes — TypeScript and CoffeeScript compile to JavaScript, and Babel transpiles newer JavaScript to older versions for browser compatibility. Historically, the original C++ implementation, Cfront, compiled C++ to C, and early Fortran systems worked similarly.

Examples

Well-known source-to-source compilers include TypeScript, Babel, Emscripten (C/C++ to WebAssembly/JavaScript), Haxe, and numerous converters between dialects and generations of languages such as Python 2 to 3 tools.
