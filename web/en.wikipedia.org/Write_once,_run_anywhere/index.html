Write once, run anywhere

Image placeholder: Java write once, run anywhere concept diagram

Write once, run anywhere (WORA), or sometimes write once, run everywhere (WORE), was a 1995 slogan created by Sun Microsystems to illustrate the cross-platform benefits of the Java language.

Meaning

The slogan promised that a Java program compiled to bytecode could run on any device equipped with a Java virtual machine (JVM), without recompilation for each platform. This contrasted with languages such as C, where source code often had to be adapted and rebuilt per target.

Reception

Critics coined the parody "write once, debug everywhere", noting platform differences in JVM implementations and user-interface behavior. Variations on the slogan have since been used by other cross-platform technologies.
