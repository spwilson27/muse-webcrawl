XZ Utils is a set of free software command-line tools for lossless data compression using the LZMA2 algorithm, including the xz and lzma commands and the liblzma library. Developed by the Tukaani Project, it provides a successor to the older LZMA Utils and produces the widely used .xz file format, common for distributing Linux kernel source, software tarballs and package archives.

Features

xz typically achieves higher compression ratios than gzip or bzip2 at the cost of slower compression and higher memory use. The format supports integrity checks (CRC32, CRC64, SHA-256), multi-threaded compression in recent versions, and concatenated streams. Tools include xz, unxz, xzcat, xzgrep and related utilities, with interfaces modelled on gzip.

2024 backdoor incident

In March 2024 a malicious backdoor was discovered in XZ Utils versions 5.6.0 and 5.6.1 (CVE-2024-3094). The code, inserted by a contributor who had spent years building trust in the project, targeted systems linking liblzma through OpenSSH via systemd, and was caught before widespread stable release by engineer Andres Freund, who noticed anomalous SSH login delays and CPU usage. The incident became a major case study in open-source supply-chain security.
