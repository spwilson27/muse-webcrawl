Jordan block

In linear algebra, a Jordan block, also called a Jordan cell, is a square matrix composed of an eigenvalue λ along the main diagonal, ones on the superdiagonal (the diagonal immediately above the main diagonal), and zeros elsewhere. It is named after the French mathematician Camille Jordan.

Definition

A Jordan block of size n × n associated with eigenvalue λ has the form with λ repeated on the diagonal, 1 in each entry directly above the diagonal, and 0 everywhere else. A 1 × 1 Jordan block is simply the scalar [λ]. Every square matrix over an algebraically closed field is similar to a block diagonal matrix whose diagonal blocks are Jordan blocks — the Jordan matrix in the Jordan normal form.

Properties

A single Jordan block J = λI + N, where N is nilpotent with ones on the superdiagonal. Its powers and exponentials have closed forms involving binomial coefficients, which makes Jordan blocks central to solving linear systems of differential equations. The number and sizes of the blocks for an eigenvalue encode the geometric multiplicity and the structure of generalized eigenspaces: an eigenvalue's geometric multiplicity equals the number of Jordan blocks associated with it.
