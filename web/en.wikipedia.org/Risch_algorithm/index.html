Risch algorithm

The Risch algorithm is an algorithm in symbolic computation for indefinite integration — that is, for finding elementary antiderivatives of elementary functions. Developed by Robert Henry Risch in 1968–1970, it is essentially a decision procedure: given an elementary function, the algorithm either finds an elementary antiderivative or proves that none exists. This contrasts with the heuristic pattern-matching methods used in earlier computer algebra systems.

Overview

The algorithm reduces the problem of integrating a function in a tower of transcendental extensions of the rational function field to a problem in algebra — principally, solving certain differential equations (the Risch differential equation) and factoring polynomials. It depends on Liouville's theorem on integration in finite terms, which restricts the possible form of an elementary antiderivative. Difficult steps include deciding whether constants are zero and handling algebraic function fields, which were completed by later work (notably Manuel Bronstein's).

Implementation

Full or partial implementations appear in computer algebra systems such as Axiom, Mathematica, Maple and SymPy. Some cases remain hard in practice, particularly those involving algebraic functions of high degree or nested exponentials and logarithms. Well-known functions that provably have no elementary antiderivative — and which the algorithm can in principle certify — include e−x² and xx.
