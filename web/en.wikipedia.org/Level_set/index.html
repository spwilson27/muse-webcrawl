Level set

In mathematics, a level set of a real-valued function f of several variables is the set of all points where the function takes a given constant value c: {(x1, …, xn) | f(x1, …, xn) = c}. Level sets are fundamental in geometry, optimisation and physics.

Level set
FieldMathematics (analysis, geometry)
Special casesLevel curve (2 variables), level surface (3 variables)
Related conceptsContour line, fibre, implicit curve

Examples

For a function of two variables, level sets are level curves — familiar as contour lines on topographic maps, where each curve joins points of equal elevation. For three variables they are level surfaces, such as equipotential surfaces in physics.

Applications

The study of level sets as the value varies reveals the shape of a function; its maxima, minima and saddle points occur where level sets change topology. The level-set method in numerical analysis represents moving boundaries as the zero level set of a higher-dimensional function, and is widely used in computer graphics, fluid dynamics and image processing.
