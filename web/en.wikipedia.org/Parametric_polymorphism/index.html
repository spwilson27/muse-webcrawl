Parametric polymorphism

In programming languages and type theory, parametric polymorphism allows a function or a data type to be written generically so that it can handle values identically without depending on their type. It is a central feature of functional programming languages such as ML and Haskell, and appears in object-oriented languages as generics (for example, Java generics and C++ templates).

Description

A classic example is the identity function, which can be given the type scheme ∀α. α → α, meaning it works for a value of any type α. A list length function similarly works for lists of any element type. Because the implementation cannot inspect the unknown type, it must behave uniformly for all instantiations — a property John C. Reynolds and Philip Wadler formalised as "parametricity", which yields powerful reasoning principles sometimes summarised as "theorems for free".

History and variants

Parametric polymorphism was introduced by Christopher Strachey and formalised in the Hindley–Milner type system used by ML-family languages. Variants include bounded parametric polymorphism, where type variables may be restricted by constraints or type class bounds, and rank-n polymorphism, where polymorphic values can be passed as arguments.
