Polymorphism (computer science)

Polymorphism, in programming language theory and type theory, is the property of a single interface, function, or operator being usable with values of different types. It is one of the fundamental concepts of object-oriented and functional programming, allowing code to be written generically rather than for one specific type.

Types of polymorphism

Computer scientist Christopher Strachey distinguished two major categories in 1967. Ad hoc polymorphism covers cases such as function overloading and operator overloading, where the same symbol has different implementations chosen by the types of its arguments. Parametric polymorphism describes functions and data types written generically, so that they can handle values identically without depending on their type; it underlies generic programming in languages such as ML, Haskell, C++, Java, and Rust.

A third form, subtyping (also called inclusion polymorphism), allows a value of a subtype to be used in place of a value of a supertype, and is central to class-based object-oriented languages. Row polymorphism and polytypism are further specialized forms found in research languages.

History

The concept has roots in Strachey's lectures and in the development of the ML language in the 1970s, where Hindley–Milner type inference made parametrically polymorphic functions practical. Later, the System F calculus of Girard and Reynolds gave polymorphism a rigorous mathematical foundation.
