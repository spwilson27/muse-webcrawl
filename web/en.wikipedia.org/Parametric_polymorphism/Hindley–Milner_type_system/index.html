Hindley–Milner type system

The Hindley–Milner (HM) type system is a classical type system for the lambda calculus with parametric polymorphism. It was first described by J. Roger Hindley and later rediscovered by Robin Milner. The system supports complete type inference: a well-typed program always has a principal type, the most general type from which all others can be obtained by substitution, so programmers rarely need to write type annotations.

Algorithm W

Milner's Algorithm W (1978) is the standard inference procedure; the related Algorithm J is often implemented in practice. Inference works by generating fresh type variables and solving equality constraints between them by unification, generalizing types at let-bindings — the "let-polymorphism" that lets one definition be used at several types within a program.

Influence

HM underlies the type systems of ML, OCaml, Haskell (extended with type classes for ad hoc polymorphism), F#, and, in modified form, Rust and Swift. Its combination of safety, expressiveness, and automatic inference made it the reference point for static typing in functional languages and a foundation for practical generic programming.
