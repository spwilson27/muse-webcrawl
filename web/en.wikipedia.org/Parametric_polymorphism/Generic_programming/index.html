Generic programming

Generic programming is a style of computer programming in which algorithms are written in terms of data types to be specified later, and are instantiated when needed for specific types provided as parameters. This approach, pioneered by David Musser and Alexander Stepanov and embodied in the C++ Standard Template Library, permits writing common functions or data types that differ only in the set of types on which they operate, thus reducing duplication of code.

History and implementations

Generic programming facilities first appeared in languages such as ML and Ada, and were later adopted by Java (generics, 2004), C# , Rust (with trait bounds), Swift, and Go (with type parameters added in 2022). In functional languages with the Hindley–Milner type system, polymorphic functions are inferred automatically, so ordinary definitions are already generic.

Concepts

Stepanov's formulation centers on concepts: organized sets of requirements (operations, complexity guarantees, semantic properties) that a type must satisfy to be used with an algorithm. C++20 adopted concepts as a language feature for constraining templates. Unlike ad hoc polymorphism, generic code provides one uniform definition whose behavior is the same for every type meeting the requirements.
