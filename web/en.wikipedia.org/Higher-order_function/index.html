Higher-order function

In mathematics and computer science, a higher-order function (HOF) is a function that does at least one of the following: takes one or more functions as arguments, or returns a function as its result. All other functions are first-order functions. The concept originates in the lambda calculus of Alonzo Church, where all functions are inherently higher-order.

Examples

Common higher-order functions in functional programming include map, which applies a function to every element of a list; filter, which keeps elements satisfying a predicate; and fold (reduce), which combines elements using a binary function. The mathematical derivative operator and the composition operator are classical examples: the derivative takes a function and returns its derivative function.

Support in languages

Higher-order functions are central to functional languages such as Haskell, Lisp, ML, and Erlang, and are supported through first-class functions in many multi-paradigm languages, including Python, JavaScript, Scala, and (via lambdas and delegates) C# and Java. In languages without first-class functions, similar effects are achieved with function pointers, functors, or interfaces.

Uses

Higher-order functions enable powerful abstraction: they let programmers factor out the variable part of a computation (the function argument) from its fixed skeleton, supporting callbacks, event handling, function composition, currying, and partial application. Combined with closures, they form the basis for many design patterns in software engineering.
