Command guidance

Command guidance is a type of missile guidance in which the missile is controlled by commands sent from an external station, typically a ground station or launch aircraft, rather than by an onboard seeker making its own decisions. The guidance station tracks both the target and the missile, computes the necessary corrections, and transmits steering commands to the missile, usually by radio link or, in some systems, along wires.

Types

In command to line of sight (CLOS) guidance, the operator or a fire-control system keeps the missile on the line of sight to the target. Variants include manual command to line of sight (MCLOS), used by early anti-tank missiles such as the German X-7 and the British-Australian Malkara, in which the operator steered with a joystick; semi-automatic command to line of sight (SACLOS), in which the operator merely keeps the sight on the target while the system generates the commands, used by missiles such as TOW, Milan, and HOT; and semi-manual command to line of sight (SMCLOS). Command off line of sight (COLOS) relies on radar tracking of both missile and target with a computer generating commands, as in early surface-to-air systems such as the Soviet SA-2 Guideline.

Characteristics

Command guidance allows the missile itself to be relatively simple and cheap, but it requires an uninterrupted link to the missile, is vulnerable to jamming in radio-command forms, and accuracy tends to degrade at long range because angular errors grow with distance. The guidance station must remain exposed, tracking the engagement throughout the missile's flight. Many modern systems combine command guidance with terminal homing by an onboard seeker to overcome these limitations.
