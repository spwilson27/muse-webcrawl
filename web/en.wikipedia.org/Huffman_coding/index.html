Huffman coding

From Wikipedia, the free encyclopedia

Huffman coding is an algorithm for lossless data compression that assigns variable-length prefix codes to symbols according to their frequencies: frequent symbols receive short codewords and rare symbols receive longer ones. It was published by David A. Huffman in his 1952 paper “A Method for the Construction of Minimum-Redundancy Codes”, written while he was a graduate student at MIT.

Algorithm

The algorithm builds a binary tree from the bottom up. Each symbol starts as a leaf weighted by its frequency (or probability). The two nodes of lowest weight are repeatedly combined into a new internal node whose weight is their sum, until a single tree remains. Labelling each branch 0 or 1 gives each symbol a codeword read from root to leaf. Because no codeword is a prefix of another, the bit stream can be decoded unambiguously. Huffman’s method yields an optimal prefix code — no other prefix code gives a shorter average length for the same frequencies.

Uses

Huffman coding is a component of many compression formats, including DEFLATE (used in ZIP, gzip and PNG), JPEG and MP3. Variants include canonical Huffman codes, which simplify codebook storage, and adaptive Huffman coding, which updates the tree as data is processed. In modern systems it is often combined with dictionary methods such as LZ77 or with arithmetic coding for still better compression.
