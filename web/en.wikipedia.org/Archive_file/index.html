In computing, an archive file is a computer file that is composed of one or more files along with metadata. Many archive formats also provide compression. Archive files are used to collect multiple data files together into a single file for easier portability and storage, or simply to compress files to use less storage space. Archive files often store directory structures, error detection and correction information, arbitrary comments, and sometimes built-in encryption.

Purposes

Archiving combines files so that a directory tree can be transmitted as a unit (over email, file transfer, or software distribution), backed up to tape or disk, or preserved with its metadata — file names, timestamps, permissions, ownership — intact. Compression reduces size using algorithms such as DEFLATE (ZIP, gzip) or LZMA (7z, xz); "solid" compression across files improves ratios further. Archive files underpin software packaging (JAR, WAR, APK, and package formats such as .deb and .rpm), disk and system images, and dataset distribution.

Formats

The Unix tar format (tape archive, 1979) concatenates files with headers but does not itself compress; compression is applied externally, giving combinations such as .tar.gz and .tar.xz. The ZIP format, created by Phil Katz in 1989 for PKZIP, became the dominant general-purpose archive on personal computers, with a central directory enabling random access to entries and per-file compression. 7z (Igor Pavlov, 1999) and RAR (Eugene Roshal, 1993) achieve higher compression and support splitting archives into volumes. Other formats include the Unix ar (used for static libraries and .deb packages), cpio, Microsoft's CAB, and self-extracting archives that prepend executable code to unpack themselves.

Features and issues

Many formats include checksums or error-correction data, support for encryption (ZIP's legacy ZipCrypto is weak; AES is supported by ZIP extensions and natively by 7z and RAR), Unicode filenames, and multi-volume spanning. Security issues include "zip bombs" that expand to enormous size, path-traversal entries ("Zip Slip") that write outside the extraction directory, and archives used to smuggle malware past scanners. Unlike a general-purpose archive of records, an archive file is a container format rather than a curated collection.
