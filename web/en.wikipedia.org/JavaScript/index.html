JavaScript (JS) is a high-level programming language that is one of the core technologies of the World Wide Web, alongside HTML and CSS. As of recent years, the overwhelming majority of websites use JavaScript on the client side for webpage behavior, and all major web browsers include a dedicated JavaScript engine.

History

JavaScript was created by Brendan Eich in 1995 while he was an engineer at Netscape. Famously prototyped in about ten days, it was first released with Netscape Navigator 2.0 under the names Mocha and then LiveScript, before being renamed JavaScript in a marketing alliance with Sun Microsystems around its Java language — despite the two languages being largely unrelated. Microsoft introduced its implementation, JScript, in Internet Explorer. To prevent fragmentation, the language was standardized by ECMA International as ECMAScript in 1997.

Features and uses

JavaScript is a prototype-based, dynamically typed language with first-class functions, supporting object-oriented, imperative, and functional styles. Originally confined to browsers, it expanded to servers and applications with runtimes such as Node.js (2009), and frameworks and libraries like React, Angular, and Vue reshaped front-end development. Modern ECMAScript editions (notably ES6 in 2015) added classes, modules, arrow functions, promises, and async/await. TypeScript, a strict superset adding static types, has become widely used.
