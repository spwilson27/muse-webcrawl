Logical consequence

Logical consequence (also entailment) is a fundamental concept in logic: a sentence is a logical consequence of a set of sentences if it is impossible for all the premises to be true while the conclusion is false.

Accounts

The model-theoretic account, associated with Alfred Tarski, says a conclusion follows if every model of the premises is a model of the conclusion. The proof-theoretic account defines consequence in terms of formal derivations within a deductive system. Soundness and completeness theorems link the two for classical logic.

Properties

Logical consequence is typically taken to be necessary, formal and known a priori. Classical accounts are monotonic — adding premises never defeats a valid inference — whereas everyday reasoning is often non-monotonic.

Notation

Semantic consequence is written Γ ⊨ φ; syntactic derivability is written Γ ⊢ φ.
