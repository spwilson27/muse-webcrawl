Portable Network Graphics

Portable Network Graphics (PNG, officially pronounced "ping", sometimes "pee-en-gee") is a raster-graphics file format that supports lossless data compression. PNG was developed as an improved, non-patented replacement for the Graphics Interchange Format (GIF), and is one of the most widely used image formats on the World Wide Web, alongside JPEG. PNG supports palette-based images, grayscale images, and full-color images, with optional transparency (alpha channel).

History

Work on PNG began in early 1995 after Unisys announced it would enforce its patent on the LZW compression used by GIF, prompting developers on the Usenet newsgroup comp.graphics to design a patent-free successor. The name began as the recursive acronym "PNG's Not GIF" before settling on Portable Network Graphics. Version 1.0 was released in 1996, became a W3C Recommendation in 1996 (revised 2003), and an ISO standard, ISO/IEC 15948. Animation was deliberately omitted from the core format; the related MNG and the unofficial APNG extensions address it.

Technical details

A PNG file begins with an 8-byte signature and consists of a series of chunks, each with a type, length, data, and CRC checksum. Critical chunks include IHDR (image header), PLTE (palette), IDAT (compressed image data), and IEND (end marker); ancillary chunks store metadata such as text, gamma, colour profile (ICC), and physical pixel dimensions. Image data are filtered row by row (filters: None, Sub, Up, Average, Paeth) and compressed with the DEFLATE algorithm. Colour types support bit depths of 1–16 bits per channel, including truecolour with alpha (RGBA) and grayscale with alpha. A third edition of the PNG specification (2025) added support for HDR images and Exif data, and formally incorporated APNG animation.

Comparison and usage

PNG compresses losslessly and reproduces exact colours and sharp edges, making it preferred over JPEG for screenshots, diagrams, icons, logos, and images requiring transparency, though photographic images usually make larger files than JPEG. All major browsers and image tools support PNG.
