In formal language theory and computer science, a substring is a contiguous sequence of characters within a string. For example, "ana", "ban", and "nana" are substrings of "banana", while "bna" is not — it is a subsequence, since its characters are not contiguous. Substrings are also called factors in combinatorics on words, especially in European literature.

Definitions

Formally, a string t is a substring of a string s if there exist strings a and b such that s = a·t·b. A substring that is a prefix of the string (a = empty) or a suffix (b = empty) is called a prefix or suffix respectively; the empty string is a substring of every string, and a substring equal to its parent is sometimes distinguished as "proper" versus "improper." A string of length n has exactly n(n+1)/2 non-empty substrings when counted with multiplicity of position, though the number of distinct substrings can be smaller when characters repeat.

Algorithms and data structures

Finding whether a pattern occurs as a substring of a text — the substring search problem — is fundamental to text editors, search engines, and bioinformatics. Efficient algorithms include Knuth–Morris–Pratt and Boyer–Moore, both linear or sublinear in practice. Data structures such as suffix arrays, suffix trees, and suffix automata index all substrings of a string to answer queries like the longest repeated substring or the longest common substring of two strings in optimal time.
