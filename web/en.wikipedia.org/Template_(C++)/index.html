Template (C++)

Templates are a feature of the C++ programming language that allows functions and classes to operate with generic types. This allows a function or class declaration to reference, via a generic variable or placeholder, types that are evaluated at compile time rather than being fixed in the source code, a form of generic programming.

Function templates

A function template defines the behavior of a family of functions. For example:

template <typename T>
T max(T a, T b) { return a > b ? a : b; }

When the compiler encounters a call with concrete argument types, it instantiates the template, generating a specific function for those types.

Class templates

Class templates — such as the containers of the Standard Template Library (vector, list, map) — define families of classes parameterized by type. Class templates support partial specialization, allowing special behavior for particular argument patterns.

Advanced features

Template metaprogramming uses templates to perform computations at compile time; the template system is Turing-complete. Later standards added variadic templates (C++11), concepts (C++20) to constrain template arguments, and modules and constexpr facilities that partially supersede older idioms. Template instantiation can lengthen compile times and produce large error messages, trade-offs widely discussed in the C++ community.
