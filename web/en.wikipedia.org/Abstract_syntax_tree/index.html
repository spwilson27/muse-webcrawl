Abstract syntax tree

In computer science, an abstract syntax tree (AST), or just syntax tree, is a tree representation of the abstract syntactic structure of text (often source code) written in a formal language. Each node of the tree denotes a construct occurring in the text. The syntax is "abstract" in the sense that it does not represent every detail of real syntax: parentheses, commas, and other punctuation used only for grouping are normally omitted, while the essential structure — operators, operands, statements, and declarations — is preserved.

Structure and parsing

An AST is produced by the parser during compilation or interpretation, usually after lexical analysis has converted the source into tokens. It differs from a parse (concrete syntax) tree, which mirrors the grammar productions directly and includes purely syntactic nodes. For example, the expression (4 + 3) * 7 yields an AST whose root is a multiplication node with children for addition (with children 4 and 3) and the literal 7.

Uses

ASTs are the central data structure of compilers and language tools: semantic analysis annotates them with types and symbol information; optimisers transform them; code generators traverse them to emit machine code or bytecode. They also power interpreters (tree-walking interpreters execute the AST directly), static analysers, linters, code formatters, refactoring tools, and syntax highlighters. In programming-language theory, ASTs make it possible to define semantics and prove properties of programs by structural induction.

Representations

ASTs are represented in many forms depending on the implementation — from classes or algebraic data types in compiler source code to serialised S-expressions in Lisp-like languages, where code itself is written as tree-structured expressions (homoiconicity).
