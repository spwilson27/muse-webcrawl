Gauss–Newton algorithm

Iterative refinement of a fitted curve using the Gauss–Newton method.

The Gauss–Newton algorithm is a method used to solve non-linear least squares problems, which involves finding the parameters of a model function that minimize the sum of squares of the residuals between the model's predictions and observed data. It is a modification of Newton's method for finding a minimum of a function, adapted to the least-squares setting by using the Jacobian matrix of the residuals in place of the full Hessian.

Description

Given a set of m observations and a model function with n parameters (with m ≥ n), the algorithm iteratively improves an initial parameter estimate. At each iteration, the model is linearized using a first-order Taylor expansion around the current estimate, reducing the problem to a linear least squares problem whose solution gives the next parameter increment. The method converges quickly when the initial guess is close to the solution and when the residuals at the solution are small.

Variants and extensions

The Levenberg–Marquardt algorithm extends the Gauss–Newton method by adding a damping term, interpolating between Gauss–Newton steps and gradient descent steps, which improves behaviour far from the solution and when the Jacobian is ill-conditioned. The Gauss–Newton method is widely implemented in scientific software and is used in curve fitting, system identification, and bundle adjustment in computer vision and photogrammetry.
