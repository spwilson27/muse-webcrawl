Declarative memory

Diagram of human memory systems, including declarative memory

Declarative memory, also called explicit memory, is one of the two main divisions of long-term memory in the human brain (the other being procedural, or implicit, memory). It consists of facts and events that can be consciously recalled and "declared", and depends on the medial temporal lobe, including the hippocampus.

Subtypes

Endel Tulving distinguished semantic memory (general facts about the world) from episodic memory (personally experienced events situated in time and place).

Neural basis and impairment

Damage to the hippocampus, as in the famous patient H.M., severely impairs the formation of new declarative memories while leaving procedural learning largely intact, a dissociation central to modern memory science.
