Swift (programming language)

Swift is a high-level, general-purpose, multi-paradigm programming language developed by Apple Inc. and the open-source community. First released in 2014, it was designed as a modern replacement for Objective-C for building apps on iOS, macOS, watchOS and tvOS, emphasising safety, speed and expressive syntax.

History

Chris Lattner began work on Swift in 2010, drawing on Objective-C, Rust, Haskell, Ruby, Python and C#. Apple announced it at WWDC 2014 to surprised developers, and in December 2015 released it as open source under the Apache License, with ports to Linux and later Windows.

Features

Swift eliminates whole classes of errors: variables are always initialised, optionals make the absence of a value explicit and must be unwrapped safely, and arrays and integers are checked for overflow. It supports closures, generics, type inference, pattern matching and protocol extensions, uses automatic reference counting for memory management, and compiles via LLVM to native code with performance rivalling C++ in many benchmarks.

Adoption

Swift became the primary language for Apple-platform development, with frameworks such as SwiftUI (2019) built around it. It is also used for server-side development and, increasingly, systems programming through features like Swift concurrency (async/await, actors) added in Swift 5.5.
