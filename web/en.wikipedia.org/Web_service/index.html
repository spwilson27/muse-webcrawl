Web service

A web service is a software system that supports interoperable machine-to-machine interaction over a network. In the W3C's definition, a web service is designed for interaction between computer systems rather than directly with human users, typically using messages formatted in XML or JSON and transported over HTTP.

Types

Two broad styles dominate. SOAP-based services, standardized by the W3C, use XML messages described by WSDL contracts, often with the WS-* family of specifications for security and transactions. RESTful services follow the architectural style described by Roy Fielding in 2000, addressing resources with URLs and using standard HTTP methods (GET, POST, PUT, DELETE) with lightweight representations, most commonly JSON. More recent approaches include gRPC, which uses HTTP/2 and Protocol Buffers, and GraphQL, a query language for APIs developed at Facebook.

Uses

Web services let organizations expose functionality—payment processing, maps, weather data, login identity, cloud storage—for integration into other applications, forming the basis of service-oriented architecture and later microservices. Public APIs from companies and governments are overwhelmingly implemented as web services.
