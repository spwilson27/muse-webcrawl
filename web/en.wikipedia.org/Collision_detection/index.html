Collision detection

Collision detection is the computational problem of detecting the intersection of two or more objects. It is a central component of physics engines, video games, computer animation, robotics and engineering simulation, where the system must determine when objects touch so that a collision response can be computed.

Phases

Collision detection is usually divided into a broad phase, which quickly eliminates pairs of objects that cannot possibly collide using spatial partitioning (such as grids, octrees or bounding volume hierarchies) and bounding volumes (spheres, axis-aligned or oriented boxes), and a narrow phase, which performs exact intersection tests on the remaining candidate pairs using the objects' actual geometry, for example triangle meshes. Algorithms such as GJK compute the distance between convex shapes and detect their intersection.

Issues

Discrete collision detection samples positions at each time step and can suffer from "tunnelling", where a fast-moving object passes through a thin obstacle between samples; continuous collision detection addresses this by computing the time of impact along objects' trajectories. Performance and numerical robustness are major practical concerns, and implementations often exploit temporal coherence — the fact that object positions change little between frames.
