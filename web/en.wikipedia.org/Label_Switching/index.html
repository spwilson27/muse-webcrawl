Label Switching

Label switching is a technique of network relaying in which short, fixed-length labels attached to packets direct forwarding decisions, rather than the packet's full network-layer address. It is the principle behind Multiprotocol Label Switching (MPLS) and was also used in ATM and Frame Relay networks.

Operation

A label edge router assigns each packet a label identifying its forwarding equivalence class. Label switch routers along the path swap the label at each hop using a simple lookup table, and the label is removed at the egress router. Because forwarding uses an exact-match label lookup, it can be fast and can support traffic engineering by steering flows along explicit label-switched paths.

Uses

Label switching underpins carrier services such as Layer 3 VPNs, virtual private LAN services, quality-of-service classes and fast reroute for resilience.
