Percent-encoding

Percent-encoding, also known as URL encoding, is a mechanism for encoding information in a Uniform Resource Identifier (URI) using only a restricted set of characters. A byte that cannot appear directly is written as a percent sign (%) followed by two hexadecimal digits giving the byte's value — for example, a space may appear as %20, and the character é in UTF-8 as %C3%A9.

Rules

URI syntax (RFC 3986) divides characters into reserved characters, which have structural meaning (such as / ? # & =), unreserved characters (letters, digits, and - . _ ~), which never need encoding, and all other bytes, which must be percent-encoded. Non-ASCII text is first encoded to bytes, usually in UTF-8, and each byte is then percent-encoded. In the query strings of HTML forms, a related encoding uses + for spaces (application/x-www-form-urlencoded).

Use

Percent-encoding appears in web links containing spaces or punctuation, in data URIs, and in internationalised web addresses, where non-Latin scripts are encoded for transmission though browsers may display them decoded.
