IMEI

The International Mobile Equipment Identity (IMEI) is a numeric identifier, usually unique, for 3GPP and iDEN mobile phones, as well as some satellite phones. It is usually found printed inside the battery compartment of the phone, but can also be displayed on-screen on most phones by entering the code *#06# on the dial pad, or alongside other system information in the settings menu on smartphone operating systems.

Structure

The IMEI is a 15-digit number composed of an eight-digit Type Allocation Code (TAC), which identifies the manufacturer and model, a six-digit serial number, and a final check digit calculated using the Luhn algorithm. An extended form, the IMEISV, uses 16 digits and includes software version information.

Use by networks

GSM networks use the IMEI to identify valid devices and can bar a stolen phone from accessing the network. When a phone is reported stolen, its IMEI can be added to the Equipment Identity Register (EIR) blacklist, rendering the handset unusable on participating networks even if the SIM card is changed. Unlike the IMSI stored on the SIM, the IMEI identifies the hardware itself.

Legal status

Altering a phone's IMEI is a criminal offence in a number of jurisdictions. Because the IMEI is often transmitted by devices, privacy advocates have noted that it can also be used for tracking.
