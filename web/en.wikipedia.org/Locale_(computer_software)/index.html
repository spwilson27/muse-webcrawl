Locale (computer software)

In computing, a locale is a set of parameters that defines the user's language, region and any special variant preferences that the user wants to see in their user interface — affecting date and time formats, number and currency formats, collation order, and translated messages.

Locale identifiers

Locales are usually identified by codes combining a language and a country, such as en_US (English, United States) or fr_FR (French, France). Modern systems use IETF language tags (BCP 47), as in en-GB, and the Unicode Common Locale Data Repository (CLDR) supplies standard locale data.

Implementations

On Unix-like systems the C library locale is controlled by environment variables such as LANG, LC_ALL, LC_TIME and LC_MESSAGES, following the POSIX model. Windows historically used locale identifiers (LCIDs) and National Language Support settings. Programming environments including Java, ICU and .NET provide locale-sensitive formatting, sorting and message catalogues.

Internationalization

Using locales correctly is central to internationalization and localization, allowing one program to serve users in many languages and conventions without code changes.
