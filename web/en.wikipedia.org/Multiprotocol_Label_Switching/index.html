Multiprotocol Label Switching


Abbreviation: MPLS
Type: Packet-forwarding technique
Standardized: IETF, from 1997–2001

Multiprotocol Label Switching (MPLS) is a routing technique in telecommunications networks that directs data from one node to the next based on labels rather than long network addresses, avoiding complex lookups in a routing table. It operates between the link and network layers (sometimes called "layer 2.5") and can carry many kinds of traffic, including IP packets, Ethernet, and ATM.

Operation

At the edge of an MPLS network, a label edge router (LER) assigns each packet a forwarding equivalence class and attaches a short label. Interior label switch routers (LSRs) swap labels and forward packets along a label-switched path according to simple table lookups. Labels are distributed by protocols such as LDP or RSVP-TE, the latter enabling traffic engineering so operators can steer flows along chosen paths, and BGP for services such as VPNs.

Applications

Service providers use MPLS for layer-3 VPNs (connecting enterprise sites), layer-2 services and pseudowires, traffic engineering, and fast reroute for resilience. Segment routing has recently offered an alternative source-routing approach building on MPLS data planes.

History

MPLS grew out of mid-1990s proposals such as Cisco's Tag Switching and Ipsilon's IP Switching; the IETF MPLS working group consolidated them, publishing the core architecture in RFC 3031 in 2001.
