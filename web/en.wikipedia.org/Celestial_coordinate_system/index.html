Celestial coordinate system

PurposeSpecifying positions of objects on the celestial sphere
Principal systemsEquatorial, horizontal, ecliptic, galactic
Standard frameICRS; epoch J2000.0

In astronomy, a celestial coordinate system is a system for specifying the positions of satellites, planets, stars, galaxies, and other celestial objects relative to physical reference points available to a situated observer. Coordinate systems project positions onto the celestial sphere, using angular coordinates analogous to latitude and longitude on Earth.


The equatorial coordinate system on the celestial sphere

Main systems

The equatorial system, most widely used for star catalogues, measures right ascension and declination relative to the celestial equator and the vernal equinox. The horizontal system uses altitude and azimuth relative to the observer's horizon and changes continuously as Earth rotates. The ecliptic system uses the plane of Earth's orbit, and the galactic system uses the plane of the Milky Way, with the galactic centre in Sagittarius as its reference direction.

Frames, epochs, and conversion

Because of precession and nutation, equatorial coordinates drift slowly with time, so positions must be quoted for a standard epoch — B1950.0 historically, and now J2000.0. The International Celestial Reference System (ICRS), realised by the positions of distant quasars (the ICRF), provides a fixed, inertial frame. Converting between systems uses spherical trigonometry and accounts for the observer's location and local sidereal time.
