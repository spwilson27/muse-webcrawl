Cantor set

In mathematics, the Cantor set is a set of points lying on a single line segment that has a number of unintuitive properties. It is built by iteratively removing the open middle third of a set of line segments: starting from the interval [0, 1], remove the middle third (1/3, 2/3); then remove the middle thirds of the two remaining segments, and so on indefinitely. The set consists of the points never removed. It was introduced by the German mathematician Georg Cantor in 1883 (a related construction had appeared in work of Henry John Stephen Smith in 1874).

Properties

The Cantor set is uncountable — it contains exactly as many points as the whole interval, as can be seen by representing its members as numbers in [0, 1] whose base-3 expansions use only the digits 0 and 2. Yet its total length (Lebesgue measure) is zero, since the removed intervals sum to 1. The set is closed, perfect (every point is a limit point), nowhere dense, compact, and totally disconnected, containing no interval at all. It is self-similar: each of its parts is a scaled copy of the whole, and its Hausdorff dimension is log 2 / log 3 ≈ 0.631, making it a canonical example of a fractal.

Significance

The Cantor set is a standard source of counterexamples in real analysis and topology. Variants such as the "fat Cantor set" have positive measure while still containing no interval. The set is homeomorphic to the Cantor space of infinite sequences of binary digits, and it appears in the theory of dynamical systems, where the dynamics of maps such as the logistic map on their invariant sets can be modeled by the Cantor set.
