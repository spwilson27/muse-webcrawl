Cross-platform software

From Wikipedia, the free encyclopedia

In computing, cross-platform software (also called multi-platform or platform-independent software) is computer software that is implemented on multiple computing platforms. Cross-platform software may be divided into two types: software that requires an individual build for each platform but can be developed with the same source code, and software that can be directly run on any platform without special preparation, such as software written in an interpreted language or pre-compiled portable bytecode.

Approaches

Common strategies include writing applications in portable languages such as Java, whose programs run on a virtual machine; using interpreted scripting languages like Python; targeting web browsers through HTML, CSS, and JavaScript; and using cross-platform frameworks and toolkits such as Qt, Electron, React Native, or .NET. Source code may also be written in portable C or C++ with platform-specific code isolated behind abstraction layers.

Advantages and disadvantages

Cross-platform development reduces duplicated effort, widens the potential user base, and simplifies maintenance of a single codebase. Its drawbacks can include performance overhead, difficulty matching the native look and feel of each platform, and the need to work around differing operating system capabilities. Platform vendors sometimes use the availability of exclusive native applications as a competitive advantage.
