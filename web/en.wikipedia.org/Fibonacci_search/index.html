Fibonacci search

Fibonacci search technique
ClassSearch algorithm
Time complexityO(log n)
Data structureSorted array

The Fibonacci search technique is a method of searching a sorted array using a divide and conquer algorithm that narrows down possible locations with the aid of Fibonacci numbers. Like binary search it runs in logarithmic time, but it probes elements at positions derived from Fibonacci numbers rather than the midpoint.

Algorithm

Given an array of length n, the algorithm finds the smallest Fibonacci number greater than or equal to n and uses the preceding Fibonacci numbers to set probe indices. Each comparison discards a portion of the array whose size is again a Fibonacci number, so the sequence of splits descends the Fibonacci ladder. Because successive probes differ by subtraction rather than division, the method historically suited machines where division was expensive, and it tends to access memory in patterns favourable to some cache and tape-storage systems.

Comparison with binary search

On average Fibonacci search performs slightly more comparisons than binary search, and its advantage in locality — examining elements closer together — matters mainly on non-uniform access media. A related method, the golden-section search, uses the golden ratio to minimise the number of evaluations of a unimodal function and shares the same mathematical basis in the growth of Fibonacci numbers.
