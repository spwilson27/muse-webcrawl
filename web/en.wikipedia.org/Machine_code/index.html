Machine code

In computer programming, machine code is computer code consisting of machine language instructions, which are used to control a computer's central processing unit (CPU). For conventional computers, each instruction consists of an opcode specifying the operation to be performed, together with operands. Machine code is the lowest-level representation of a compiled or assembled program and is specific to a particular processor architecture, or instruction set architecture (ISA).

Instruction sets

Every processor family has its own instruction set, such as x86, ARM, MIPS, or RISC-V. An instruction set includes instructions for arithmetic and logic, data movement between registers and memory, control flow such as branches and calls, and input/output. The binary encoding of these instructions is what the processor fetches and executes, typically one after another from memory.

Relation to assembly language

Assembly language is a human-readable notation for machine code in which numeric opcodes are replaced by mnemonics (for example MOV, ADD) and memory addresses by symbolic labels. An assembler translates assembly language into machine code in a largely one-to-one process, while compilers translate higher-level languages through several stages into machine code.

Use

Programmers rarely write large programs directly in machine code today, but it remains important in reverse engineering, embedded systems, compiler back ends, and situations demanding complete control over hardware. Historically, early programmers entered machine code directly, using switches, punched cards, or hexadecimal keypads.
