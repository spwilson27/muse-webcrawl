Adobe Illustrator

Adobe Illustrator is a vector graphics editor and design program developed and marketed by Adobe Inc. Originally designed for the Apple Macintosh, development began in 1985 and the first version, Illustrator 1.0, shipped in January 1987 as a commercialization of Adobe's in-house font development software and PostScript file format.

Features

Illustrator works primarily with vector graphics based on Bézier curves, allowing artwork to be scaled without loss of quality. Core tools include the pen and curvature tools, shape builders, gradients and meshes, type tools, and artboards for multi-page layouts. It is widely used for logos, icons, typography, illustrations, and print and web design. Its native file format is AI, and it can export to PDF, EPS, SVG and many other formats.

Release history

Early versions established Illustrator alongside Aldus FreeHand and later Macromedia products as industry standards. Illustrator CS (2003) added 3D effects; later Creative Cloud versions (from 2013) moved the program to a subscription model and added features such as touch support, freeform gradients, and, in the 2020s, generative AI tools such as text-to-vector generation.
