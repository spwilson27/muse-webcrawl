Binary-to-text encoding

A binary-to-text encoding is a data encoding scheme for representing binary data in a text format, so that arbitrary binary content can be transmitted or stored through systems designed to handle only text. Such encodings are used when a communication channel does not support arbitrary bytes, or when binary data must be embedded in text documents.

Common schemes

The most widely used scheme is Base64, which encodes three bytes of binary data as four ASCII characters, increasing size by about 33%. Other schemes include Base32, Base16 (hexadecimal), Base58 (used in Bitcoin addresses), Base85 (Ascii85), quoted-printable, and uuencoding, historically used for sending files over Usenet and early email.

Applications

Binary-to-text encodings appear in email attachments (MIME), data URIs embedded in web pages, cryptographic keys and certificates (PEM format), and JSON Web Tokens. The trade-off is increased size in exchange for compatibility with text-only systems.
