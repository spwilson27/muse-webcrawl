Preboot Execution Environment

The Preboot eXecution Environment (PXE, pronounced "pixie") is an environment to boot computers using a network interface independently of data storage devices (such as hard disks) or installed operating systems. It was introduced as part of Intel's Wired for Management framework in 1999 and is described in detail by the PXE specification, version 2.1.

How it works

When a PXE-capable client boots, its network interface card firmware issues a DHCP request extended with PXE options. The DHCP (or a proxy DHCP) server responds with an IP address and the location of a boot server and a network bootstrap program (NBP). The client downloads the NBP via the Trivial File Transfer Protocol (TFTP), verifies and executes it. The bootstrap program may then load an operating system kernel, an installer, or a boot menu from the network. Modern UEFI firmware includes native PXE support; a faster variant, iPXE, allows booting over HTTP and other protocols.

Uses

PXE is widely used in data centres and enterprise IT for automated operating-system deployment, disk imaging, running diskless workstations and thin clients, booting diagnostic and recovery tools, and installing software on machines without optical drives. Technologies such as Windows Deployment Services, the Microsoft Deployment Toolkit, and Linux network installers rely on it.
