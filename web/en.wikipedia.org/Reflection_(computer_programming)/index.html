Reflection (computer programming)

Reflection is the ability of a computer program to examine, introspect, and modify its own structure and behavior while it is running. A reflective program can inspect metadata about its types, classes, methods, and fields, create new instances dynamically, and invoke methods whose names are known only at runtime.

Concepts

Reflection is typically divided into two capabilities: introspection, the ability to examine the structure of a program, and intercession, the ability to modify that structure or behavior. Languages such as Java, C#, Python, and Ruby provide extensive reflection facilities, while compiled languages like C++ offer only limited runtime type information.

Uses

Reflection underlies serialization libraries, dependency-injection frameworks, object-relational mappers, unit-testing tools, and plugin architectures. It enables generic code that operates on arbitrary objects without knowing their concrete types at compile time.

Drawbacks

Reflective operations are usually slower than direct code, bypass compile-time type checking, and can undermine encapsulation by exposing private members. Excessive use may also make code harder to read and maintain.
