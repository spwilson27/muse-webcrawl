Garlic routing

[ Image placeholder: Diagram of garlic routing, with multiple messages bundled as cloves inside an encrypted bulb ]

Garlic routing is a variant of onion routing that encrypts multiple messages together to make it more difficult for attackers to perform traffic analysis and to increase the speed of data transfer. It was first proposed in 2000 by Michael J. Freedman as part of his master's thesis and was later adopted as the core routing mechanism of the Invisible Internet Project (I2P).

Overview

The name derives from the structure of a garlic bulb: just as a bulb contains many cloves, a "garlic message" bundles several individually encrypted messages ("cloves"), each with its own delivery instructions, into a single message for transmission. Each clove may be addressed to a different destination. Along the route, participating routers can add their own messages to the bundle, and cloves can be peeled off at intermediate points, so an observer cannot easily tell which node originated or finally received any particular message.

Comparison with onion routing

In onion routing, as used by Tor, each message is wrapped in layers of encryption and sent through a circuit; garlic routing generalises this by bundling many messages, permitting variable-length tunnels, unidirectional tunnels, and the mixing of one's own traffic with relayed traffic. I2P uses separate inbound and outbound tunnels, each typically two or three hops, and periodically rebuilds them.

Use in I2P

In the I2P network, garlic messages carry routing data, distributed hash table updates and user traffic between encrypted destinations. Bundling improves efficiency by reducing the overhead per message and providing cover traffic that strengthens anonymity against timing and traffic-confirmation attacks.
