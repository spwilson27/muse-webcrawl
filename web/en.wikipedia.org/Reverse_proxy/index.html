Reverse proxy

In computer networks, a reverse proxy is an application that sits in front of back-end applications and forwards client (e.g. browser) requests to those applications. Reverse proxies help increase scalability, performance, resilience and security. The resources returned to the client appear as if they originated from the web server itself.

A reverse proxy forwarding requests to backend servers

Uses

  • Load balancing – distributing incoming requests among several backend servers to improve responsiveness and availability.
  • Caching – storing copies of responses so that repeated requests can be served quickly without contacting the backend.
  • TLS termination – decrypting incoming HTTPS connections (and encrypting responses) so backend servers need not perform this computationally expensive task.
  • Compression – compressing responses to reduce bandwidth.
  • Security – hiding the identity and characteristics of backend servers, and acting as a point at which malicious traffic can be filtered; web application firewalls are often deployed as reverse proxies.
  • Single point of access – presenting multiple services under one domain, and centralising authentication and logging.

Comparison with forward proxies

A forward proxy sits in front of clients and forwards their requests to servers on the wider internet; it represents the clients to the servers. A reverse proxy, by contrast, sits in front of servers and represents them to clients. The two play opposite roles, a fact reflected in their names. Organisations may use both at once.

Implementations

Popular software that can act as a reverse proxy includes nginx, Apache HTTP Server (with mod_proxy), HAProxy, Varnish (a caching reverse proxy), and Caddy. Content delivery networks such as Cloudflare and Akamai also operate, in effect, as globally distributed reverse proxies, caching content near users and absorbing hostile traffic.

Risks

A reverse proxy can track all IP addresses making requests through it and can also read and modify any traffic passing through it if not properly secured. A compromised or malicious reverse proxy places the privacy and security of data passing through it at risk. If a reverse proxy accepts connections on behalf of servers that do not encrypt, or fails to validate the backend connection, clients may be exposed to interception.
