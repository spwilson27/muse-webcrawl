The X.Org Server is the free and open-source implementation of the X Window System (X11) display server stewarded by the X.Org Foundation. For decades it has provided the graphical foundation for most Unix-like desktop systems, including Linux and the BSDs, handling input devices and drawing windows on the screen on behalf of client applications.

History

X.Org Server began in 2004 as a fork of XFree86, then the dominant X implementation, after a licensing change by the XFree86 project drove distributions and developers to the new fork. The X.Org Foundation took over stewardship of the X11 standard from the former X Consortium. Version numbering followed the X11 release series (X11R7.0 in 2005 introduced a modularized codebase split into many separate packages).

Architecture

The server implements the X11 protocol: clients connect and issue drawing requests; the server manages windows, input events, and extensions such as Xinerama, RandR (for display configuration), XRender, and, for hardware acceleration, the Direct Rendering Infrastructure (DRI), through which clients may render with OpenGL directly. Device drivers handle keyboards, mice, and graphics hardware, increasingly via generic kernel-mode-setting and evdev/libinput components.

Status

Since the 2010s, development has slowed as many Linux desktops migrate to Wayland compositors, for which X.Org is retained mainly as a compatibility layer via XWayland. The server remains widely deployed and receives maintenance and security releases.
