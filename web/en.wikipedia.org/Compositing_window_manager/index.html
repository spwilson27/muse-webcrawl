Compositing window manager

A compositing window manager, or compositor, is a window manager that provides applications with an off-screen buffer for each window. The window manager composites the window buffers together into an image representing the screen and writes the result into the display memory.

Compositing window managers may perform additional processing on buffered windows, applying 2D and 3D animated effects such as blending, fading, scaling, rotation, duplication, bending and contortion, shuffling, blurring, redirecting applications, and translating windows into one of a number of displays and virtual desktops.

Comparison with stacking window managers

In a traditional stacking window manager, windows draw directly to the screen, and overlapping regions must be repainted when windows move or are uncovered. With a compositor, each window renders to its own buffer, so the compositor can redraw the screen from the buffers without asking applications to repaint. This enables effects such as drop shadows, live window previews in task switchers, and smooth animations, at the cost of additional memory and processing.

History

One of the earliest compositing systems was Apple's Quartz Compositor, introduced with Mac OS X in 2001. Microsoft's Desktop Window Manager brought compositing to Windows with Windows Vista. On Linux and Unix-like systems, compositors such as Compiz, KWin, and Mutter, together with Wayland compositors, provide compositing for free desktop environments.
