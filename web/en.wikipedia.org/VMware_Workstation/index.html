VMware Workstation is a hosted (type-2) hypervisor for x86-64 computers developed by VMware. It allows users to create and run multiple virtual machines (VMs) — each with its own guest operating system — on a single physical Windows or Linux host. First released in 1999, it was the first product to bring practical x86 virtualisation to the desktop and became a standard tool for software development, testing, training and security research. The free, more limited Workstation Player and the macOS counterpart VMware Fusion share the same underlying technology.

The VMware Workstation interface with a library of virtual machines.

Features

Workstation supports a wide range of guest operating systems, from MS-DOS and legacy Windows versions to current Linux distributions and Windows 11 (including virtual TPM support). Key features include snapshots and cloning for restoring VM states; virtual networking with NAT, bridged and host-only modes plus a network editor for simulating complex topologies; Unity mode (on supported hosts), which integrates guest application windows into the host desktop; drag-and-drop and shared folders between host and guest; support for large VMs with many virtual CPUs and large memory allocations; DirectX and OpenGL 3D acceleration for guests; and integration with containers and Kubernetes clusters in later releases. Workstation Pro can also connect to vSphere/ESXi servers and the (now discontinued) VMware vCloud Air.

History

VMware was founded in 1998 by Diane Greene, Mendel Rosenblum and others, drawing on Rosenblum's research at Stanford. VMware Workstation 1.0 shipped in 1999 and was a commercial success among developers and IT professionals. EMC acquired VMware in 2004, and the desktop products continued through successive releases; Workstation 17 shipped in 2022 with Windows 11 guest support. Following Broadcom's acquisition of VMware in November 2023, licensing changed substantially: in 2024 Broadcom made Workstation Pro and Fusion Pro free for personal use, and in November 2024 extended free availability to all users, including commercial use, discontinuing the separate Player product line.

Comparison and ecosystem

Workstation competes with Oracle VirtualBox, Parallels Desktop (on macOS) and Microsoft's Hyper-V and Windows Sandbox. Its file formats, OVF/OVA export and the open vmx configuration files made it a reference platform in the 2000s, and its snapshot-based workflows shaped expectations for virtualisation products generally. In enterprise computing the same company's ESXi type-1 hypervisor dominates the data centre market, while Workstation remains a desktop and lab staple.
