DNF (software)

DNF
Initial release: 2013
Written in: C, C++, Python
Operating system: Linux
Predecessor: YUM

DNF (Dandified YUM) is a package manager for RPM-based Linux distributions, including Fedora, Red Hat Enterprise Linux, and CentOS. It is the successor to YUM.

History

DNF was forked from YUM in 2012 and became Fedora's default package manager in Fedora 22 (2015). It uses libsolv for dependency resolution and hawkey, later libdnf, as its core library.

Features

DNF supports automatic updates, repository management, modular streams, and a plugin architecture. Common commands include dnf install, dnf upgrade, and dnf history.

DNF5

A rewritten version, DNF5, based on libdnf5, became default in Fedora 41, offering faster performance and a smaller footprint.
