In graph theory, a Gomory–Hu tree of an undirected graph with weighted edges is a weighted tree on the same vertex set that represents the minimum s–t cuts for all pairs of vertices in the graph. It was introduced by Ralph E. Gomory and T. C. Hu in 1961.

Definition

For every pair of vertices s and t, the value of a maximum s–t flow in the original graph (equivalently, the weight of a minimum s–t cut) equals the minimum edge weight along the path between s and t in the Gomory–Hu tree, and removing that minimum edge partitions the tree in a way that gives a minimum s–t cut of the graph. Thus a single tree with n − 1 edges compactly encodes all O(n²) pairwise minimum cuts.

Construction

The classical algorithm constructs the tree using n − 1 maximum-flow computations, repeatedly computing a minimum s–t cut and contracting one side of the cut. Faster and simpler approximate variants and alternative constructions have been studied, and the structure is used in clustering, network reliability, and image segmentation, where minimum cuts model natural partitions.
