LXC

LXC (Linux Containers) is an operating-system-level virtualisation technology for running multiple isolated Linux systems (containers) on a single host using one Linux kernel. It builds on kernel features including namespaces and cgroups to provide process and resource isolation without a hypervisor.

History and ecosystem

LXC was first released in 2008, drawing on work by IBM engineers and the earlier OpenVZ and Linux-VServer projects. The related LXD project (now under the Incus fork) adds a REST API and management layer for containers and virtual machines. Early versions of Docker used LXC before switching to its own libcontainer runtime.

Features

LXC containers share the host kernel, so they start quickly and have near-native performance, but offer weaker isolation boundaries than full virtual machines and can only run Linux guests on a Linux host.
