IEEE 802.11

IEEE 802.11 is part of the IEEE 802 set of local area network (LAN) technical standards, and specifies the set of medium access control (MAC) and physical layer (PHY) protocols for implementing wireless local area network (WLAN) computer communication. The standard and amendments provide the basis for wireless network products using the Wi-Fi brand name, certified by the Wi-Fi Alliance. It is the world's most widely used wireless computer networking standard, employed in most home and office networks to allow laptops, printers, smartphones and other devices to communicate.

History

The first 802.11 protocol was released in 1997 and provided up to 2 Mbit/s link speeds in the 2.4 GHz band. It was updated in 1999 with 802.11b, allowing 11 Mbit/s, which proved enormously popular, and 802.11a, offering up to 54 Mbit/s in the 5 GHz band. Successive amendments have raised speeds by orders of magnitude while generally preserving backward compatibility.

Key technical advances include OFDM modulation (802.11a/g), MIMO multiple-antenna techniques (802.11n), wider channels and MU-MIMO (802.11ac), and OFDMA for efficient multi-user access (802.11ax). Devices connected under these standards obtain network access, typically in conjunction with an IP address assigned by a router. Numbering of the related 802.1 family, including IEEE 802.1Q for VLANs, is separate.

Architecture and medium access

Stations associate with an access point forming a Basic Service Set (BSS), identified by a BSSID and a human-readable SSID. Because the medium is shared and half-duplex, 802.11 uses CSMA/CA — carrier sense multiple access with collision avoidance — in which stations listen before transmitting and back off for random intervals after collisions, supplemented by RTS/CTS exchanges and link-layer acknowledgements. Later amendments added quality-of-service prioritization (802.11e), fast roaming (802.11r), and mesh networking (802.11s).

Security

Early security, Wired Equivalent Privacy (WEP), proved badly flawed and was deprecated in 2004. Wi-Fi Protected Access (WPA) and then WPA2 (802.11i, using AES-CCMP) replaced it; WPA3, announced in 2018, added stronger handshake protections and forward secrecy. Management-frame protection was added by 802.11w.
