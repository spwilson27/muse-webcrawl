JSON-LD

JSON-LD (JavaScript Object Notation for Linked Data) is a method of encoding linked data using JSON. It was designed to require as little effort as possible from developers to transform their existing JSON to JSON-LD, and it allows data to be serialized in a way that is similar to traditional JSON.

Filename extension.jsonld
Media typeapplication/ld+json
Developed byW3C JSON-LD Working Group
StandardW3C Recommendation

Design

JSON-LD uses a context, declared with the @context keyword, to map short terms in a document to IRIs that identify concepts in a vocabulary, most commonly Schema.org. Keywords such as @id and @type give nodes identity and types within a graph.

Use

JSON-LD is widely used for search engine optimization: Google recommends it as the preferred format for structured data embedded in web pages, typically inside a script element of type application/ld+json. It is also used in the ActivityPub protocol and in digital publishing.

History

The format was developed by Manu Sporny and collaborators and published as a W3C Recommendation in January 2014; version 1.1 followed in 2020, adding features such as scoped contexts and identifier maps.
