Server Message Block

SMB provides shared access to files, printers and ports on a network

Server Message Block (SMB) is a communication protocol used to share files, printers, serial ports, and miscellaneous communications between nodes on a network. On Microsoft Windows it underlies the "Microsoft Windows Network" file-sharing system. Originally developed at IBM in the 1980s by Barry A. Feigenbaum, SMB was extended by Microsoft and became a de facto standard for local-area network file sharing.

History and versions

The first widely used dialect, SMB 1.0 (also known as CIFS, the Common Internet File System), was designed for the networks of the 1980s and 1990s and carried significant overhead and security weaknesses. Microsoft introduced SMB 2.0 with Windows Vista and Windows Server 2008, greatly reducing the protocol's chattiness and adding symbolic link support and improved signing. SMB 3.0, introduced with Windows 8 and Windows Server 2012, added end-to-end encryption, multichannel connections and transparent failover for clustered file servers.

Implementations

Microsoft's implementation is built into Windows. The free Samba project provides an SMB server and client for Unix and Linux systems, enabling interoperability with Windows networks. SMB typically runs directly over TCP port 445 in modern networks.

Security

The legacy SMB 1.0 protocol has been the vector of major attacks: the EternalBlue exploit of SMBv1 was used by the WannaCry and NotPetya outbreaks of 2017. Microsoft and security agencies recommend disabling SMB 1.0 entirely.
