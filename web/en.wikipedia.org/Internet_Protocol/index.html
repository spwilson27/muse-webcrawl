Internet Protocol (IP)

The Internet Protocol (IP) is the network-layer protocol in the Internet protocol suite for relaying datagrams (packets) across network boundaries. Its routing function enables internetworking, and essentially establishes the Internet. Every device on an IP network is assigned an IP address that identifies both the device and, in routing terms, its location.

IP provides best-effort delivery of packets between any two hosts on interconnected networks.

Function

IP performs two basic functions: addressing and fragmentation. Each packet carries a header containing the source and destination IP addresses. Routers examine the destination address and forward the packet hop by hop toward its destination, consulting routing tables built by protocols such as BGP between networks. IP itself is connectionless and unreliable — it offers "best-effort" delivery with no guarantee of arrival, ordering, or duplicate suppression; reliability is left to higher-layer protocols such as TCP.

History

The protocol grew out of a 1974 paper by Vint Cerf and Robert Kahn describing a Transmission Control Program for interconnecting packet networks. The functions were later split into IP (routing and addressing) and TCP (reliable delivery). The ARPANET adopted IP as its standard on 1 January 1983 ("flag day"), and the design spread with the NSFNET and the commercial Internet.

Versions

IPv4, described in RFC 791 (1981), uses 32-bit addresses — about 4.3 billion — written in dotted-decimal notation such as 192.0.2.1. Exhaustion of the free pool (the IANA pool ran out in 2011) was mitigated by NAT and CIDR. IPv6, standardised in 1998 and updated by RFC 8200 (2017), uses 128-bit addresses written in hexadecimal groups, providing an effectively inexhaustible space along with simplified headers and autoconfiguration. The two versions coexist via dual-stack and tunnelling during a long transition.
