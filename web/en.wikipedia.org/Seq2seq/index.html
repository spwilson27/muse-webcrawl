Seq2seq

Seq2seq (sequence-to-sequence) is a family of machine learning approaches for transforming one sequence into another, introduced for neural machine translation in 2014 by Sutskever, Vinyals and Le, and in a related form by Cho and colleagues. A typical seq2seq model uses an encoder recurrent neural network (often LSTM or GRU) that reads the input sequence into a context vector, and a decoder network that generates the output sequence step by step.

Attention

The fixed-length context vector proved a bottleneck for long inputs; attention mechanisms (Bahdanau et al., 2015; Luong et al., 2015) let the decoder focus on different input positions at each output step, greatly improving translation quality. Seq2seq methods were later applied to summarisation, question answering, speech recognition and image captioning, and were largely superseded in many domains by the Transformer architecture (2017), which itself follows an encoder–decoder seq2seq pattern.
