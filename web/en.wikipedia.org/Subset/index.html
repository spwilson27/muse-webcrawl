Subset

In mathematics, a set A is a subset of a set B if all elements of A are also elements of B; B is then a superset of A. It is possible for A and B to be equal; if they are unequal, then A is a proper subset of B. The relationship of one set being a subset of another is called inclusion (or sometimes containment). The subset relation defines a partial order on sets.

If A is a subset of B, this is written A ⊆ B. If A is a proper subset of B, this may be written A ⊊ B or A ⊂ B (notation varies; some authors use ⊂ for any subset).

Euler diagram showing A as a subset of B

Definitions

Formally, A ⊆ B if and only if every element of A is an element of B: ∀x (x ∈ A → x ∈ B). From this definition it follows that every set is a subset of itself, and that the empty set ∅ is a subset of every set, vacuously. A proper subset is a subset that is not equal to the whole set: A ⊊ B if A ⊆ B and A ≠ B.

Examples

  • {1, 2} is a proper subset of {1, 2, 3}.
  • The set of all men is a proper subset of the set of all people.
  • {1, 2, 3} is a subset (but not a proper subset) of {1, 2, 3}.
  • The set of even integers is a proper subset of the set of integers.
  • The set of rational numbers is a proper subset of the set of real numbers.

Power set

The set of all subsets of a set S, including the empty set and S itself, is called the power set of S, denoted 𝒫(S). If S has n elements, its power set has 2n elements. Cantor's theorem shows that for any set, the power set is strictly larger in cardinality than the set itself, even for infinite sets. The subsets of a set, ordered by inclusion, form a complete lattice, and under union and intersection a Boolean algebra.
