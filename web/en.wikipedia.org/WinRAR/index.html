WinRAR

WinRAR is a trialware file archiver utility for Windows, developed by Eugene Roshal of win.rar GmbH. It can create and view archives in the proprietary RAR and ZIP formats and unpack many other archive formats. First released in 1995, it is one of the most widely used archiving tools on the Windows platform.

Features

WinRAR supports the RAR format developed by Roshal (the name derives from "Roshal Archive"), including multi-volume archives, strong AES-256 encryption, recovery records that can repair damaged archives, and solid compression. The software integrates with the Windows shell, adding context-menu options for compressing and extracting files, and also provides a command-line version. Companion tools exist for other systems: the command-line RAR for Linux, macOS and FreeBSD, and a RAR app for Android.

Licensing

WinRAR is distributed as shareware: it offers a 40-day trial, after which the program continues to function but displays a reminder asking users to purchase a licence. This lenient enforcement became a widely noted quirk of the software, and its nag-screen message is a familiar sight to long-time PC users. The related RARLAB tools are used by many other programs, and the RAR format's decoder source is available under a permissive licence, though the encoder remains proprietary.
