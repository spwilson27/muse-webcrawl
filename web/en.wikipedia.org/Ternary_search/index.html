Ternary search

A ternary search is a divide-and-conquer technique in computer science for finding the minimum or maximum of a unimodal function. The method repeatedly evaluates the function at two interior points, discarding the third of the interval that cannot contain the extremum, and is closely related to the golden-section search.

Algorithm

For a unimodal function f on [a, b], pick two points m1 and m2 dividing the interval into thirds. If f(m1) < f(m2) when seeking a maximum, the extremum cannot lie in the rightmost third, so the search continues on [a, m2]; otherwise it continues on [m1, b]. Each iteration reduces the interval by a factor of 2/3.

while b - a > epsilon:
    m1 = a + (b - a) / 3
    m2 = b - (b - a) / 3
    if f(m1) < f(m2): a = m1
    else: b = m2

Applications and analysis

Ternary search suits problems over real-valued domains where derivatives are unavailable, and a related discrete form finds peaks in unimodal arrays. It converges linearly; the golden-section search reuses one function evaluation per step and converges slightly faster, making it generally preferred in numerical optimization.
