Liouville number

In number theory, a Liouville number is a real number x with the property that, for every positive integer n, there exist integers p and q with q > 1 such that 0 < |x − p/q| < 1/qⁿ. Liouville numbers are "very close" to rational numbers: they can be approximated exceptionally well by rationals. Every Liouville number is a transcendental number, a fact first proved by Joseph Liouville in 1844; his result provided the first proof that transcendental numbers exist.

Liouville's constant

The best-known example is Liouville's constant, 0.110001000000000000000001000…, defined as the sum over n of 10^(-n!), so that the decimal expansion has 1s in the positions corresponding to factorials and 0s elsewhere. Its rational approximations — obtained by truncating the expansion — satisfy the Liouville approximation property beyond any fixed exponent, which by Liouville's theorem on algebraic numbers (no algebraic number of degree n can be approximated better than order 1/qⁿ) forces the constant to be transcendental.

Properties

Although all Liouville numbers are transcendental, the converse is false: there are transcendental numbers, such as e and π, that are not Liouville numbers. The set of Liouville numbers has Lebesgue measure zero but is dense in the reals and is a comeagre (residual) set of cardinality of the continuum.
