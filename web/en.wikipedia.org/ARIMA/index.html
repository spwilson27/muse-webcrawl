Autoregressive integrated moving average

In statistics and econometrics, an autoregressive integrated moving average (ARIMA) model is a generalization of an autoregressive moving average (ARMA) model used for analyzing and forecasting time series data. Both parts of the model are fitted to the data, often using the Box–Jenkins methodology described by George Box and Gwilym Jenkins in 1970.

Components

An ARIMA model is specified by three parameters (p, d, q):

  • AR(p) — autoregression: the variable is regressed on its own prior values.
  • I(d) — integration: the raw observations are differenced d times to make the series stationary.
  • MA(q) — moving average: the regression error is modeled as a linear combination of past error terms.

When d = 0 the model reduces to ARMA. Non-seasonal ARIMA is written ARIMA(p, d, q); seasonal extensions, SARIMA, add a set of seasonal parameters (P, D, Q) applied at the seasonal lag.

Use

The Box–Jenkins approach proceeds in three stages: identification (choosing p, d, q using autocorrelation and partial autocorrelation plots), estimation (typically by maximum likelihood), and diagnostic checking of residuals. ARIMA models remain a standard baseline for short-term forecasting in economics, demand planning, and epidemiology, though they assume linear relationships and can be outperformed by modern machine-learning methods on rich data.
