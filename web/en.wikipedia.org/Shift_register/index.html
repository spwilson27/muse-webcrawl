Shift register

A shift register is a type of digital circuit using a cascade of flip-flops where the output of one flip-flop is connected to the input of the next, and where all flip-flops share a single clock signal, so the data stored in the system shifts by one position on each clock cycle. Shift registers can have parallel and serial inputs and outputs.

Types

  • SISO – serial-in, serial-out: data enters and leaves one bit at a time; used as a digital delay line.
  • SIPO – serial-in, parallel-out: converts serial data (e.g., from a serial link) to parallel form; commonly used to expand output pins, e.g., the 74HC595 driving LEDs.
  • PISO – parallel-in, serial-out: loads parallel data and shifts it out serially, e.g., the 74HC165.
  • PIPO – parallel-in, parallel-out: a plain register with a shift capability.

Applications

Shift registers are used for serial-to-parallel and parallel-to-serial conversion in communication interfaces, as simple state machines and pseudo-random number generators (linear-feedback shift registers), in delay lines, and historically as computer memory: shift-register memory and delay-line memory stored data in recirculating form and were used in early computers and terminals.
