Database schema

The database schema is the structure of a database described in a formal language supported typically by a relational database management system (RDBMS). The term "schema" refers to the organisation of data as a blueprint of how the database is constructed — its tables, columns, data types, keys and relationships.

Levels

Database design distinguishes the conceptual schema (the entities and relationships of the domain), the logical schema (their mapping to tables and constraints) and the physical schema (storage details such as indexes and files). In SQL, CREATE SCHEMA also denotes a named namespace grouping tables and other objects. Schemas are normally specified in data definition language (DDL) statements.
