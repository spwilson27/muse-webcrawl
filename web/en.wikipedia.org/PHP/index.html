PHP is a general-purpose scripting language geared towards web development. It was originally created by Danish-Canadian programmer Rasmus Lerdorf in 1993 and released in 1995; the name originally stood for "Personal Home Page" and now stands for the recursive initialism "PHP: Hypertext Preprocessor".

History

Lerdorf's original Common Gateway Interface binaries evolved into PHP/FI and then, through a rewrite by Andi Gutmans and Zeev Suraski, into PHP 3 (1998) and PHP 4, powered by the Zend Engine. PHP 5 (2004) improved object-oriented support; PHP 7 (2015) brought major performance gains with the new Zend Engine 3.0; PHP 8 (2020) added just-in-time compilation, named arguments, attributes and union types.

Use

PHP code is usually processed on a web server by a PHP interpreter implemented as a module, a daemon or a CGI executable, generating HTML that is sent to the client. It powers a large share of the web, including major content management systems such as WordPress, Drupal and Joomla, and platforms like Wikipedia (MediaWiki) and much of Facebook's original codebase. Popular frameworks include Laravel, Symfony and CodeIgniter.

Syntax

PHP syntax borrows heavily from C, Perl and Java: variables are prefixed with a dollar sign, code is enclosed in <?php ... ?> tags when embedded in HTML, and the language supports both procedural and object-oriented programming.
