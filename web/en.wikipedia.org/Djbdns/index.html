djbdns is a software suite for the Domain Name System, written by Daniel J. Bernstein. It was designed as a more secure, reliable alternative to BIND, the dominant DNS server of the 1990s, and was published in 2000. Bernstein offered a $1,000 reward for anyone who could demonstrate a security hole in djbdns, which remained unclaimed for many years.

djbdns consists of several small, separate programmes, following the Unix philosophy of doing one thing well:

  • tinydns — an authoritative DNS server serving data from a single file.
  • dnscache — a recursive DNS resolver and cache.
  • axfrdns — a zone-transfer server.
  • dnsqr and dnsq — tools for querying DNS records.
  • dnsip, dnsmx, dnstxt, dnsname — small query tools for specific record types.
  • tinydns-data and tinydns-edit — tools for building and editing tinydns's data file.

The software emphasises separation of privileges and chroot environments for security, and uses a distinctive configuration scheme in which data is compiled from a human-readable text format into a compact binary database. djbdns was originally released under a restrictive licence, but Bernstein placed it in the public domain in 2007; it has since been maintained in community forks such as dbndns and djbdns's successor projects.
