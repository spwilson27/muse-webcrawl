Swagger (software)

Swagger is a suite of tools for designing, building, documenting and consuming RESTful web services using the OpenAPI Specification. Originally developed by Tony Tam at Wordnik and released in 2011, Swagger became the most widely used framework for API description before its specification was donated to the Linux Foundation and renamed OpenAPI in 2015.

History

Swagger began in 2010 as an internal project at Wordnik, the online dictionary company, where a machine-readable description of its API was needed to keep documentation, client libraries and server code in sync. It was open-sourced in 2011 and rapidly adopted. In 2015 SmartBear Software acquired the Swagger project from Reverb Technologies, Wordnik's parent company. Later that year the Swagger specification was transferred to the newly formed OpenAPI Initiative under the Linux Foundation and renamed the OpenAPI Specification, while the tooling retained the Swagger name.

Tools

The Swagger suite includes Swagger Editor, a browser-based editor for writing OpenAPI definitions; Swagger UI, which renders an API definition as interactive documentation that users can explore and test from the browser; and Swagger Codegen, which generates client libraries, server stubs and documentation from a specification in many programming languages.

Adoption

Swagger/OpenAPI became a de facto standard for describing HTTP APIs, supported by major cloud providers and frameworks, and is widely used for generating documentation and SDKs automatically.
