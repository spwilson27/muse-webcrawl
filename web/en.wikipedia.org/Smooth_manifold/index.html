Smooth manifold

In mathematics, a differentiable manifold (also called a smooth manifold when it has infinitely differentiable structure) is a type of manifold that is locally similar enough to a linear space to allow one to do calculus. Any manifold can be described by a collection of charts (an atlas); to do calculus on it, the coordinate changes between overlapping charts must be smooth.

Definition

A smooth manifold is a topological manifold equipped with an equivalence class of atlases whose transition maps are all smooth (infinitely differentiable). On such a space one can define smooth functions, tangent vectors and tangent spaces, vector fields, and differential forms.

Examples

Euclidean space, spheres, tori, and real and complex projective spaces are smooth manifolds. Lie groups are smooth manifolds with compatible group operations. Not every topological manifold admits a smooth structure, and some admit multiple inequivalent ones — famously, exotic spheres in higher dimensions.
