Resource Reservation Protocol

The Resource Reservation Protocol (RSVP) is a transport-layer protocol designed to reserve resources across a network for quality of service (QoS) in integrated services networks. Standardised in RFC 2205 (1997), RSVP lets hosts request specific levels of service for particular application data streams.

ProtocolRSVP
RFC2205
LayerTransport / control
PurposeQoS resource reservation

Operation

RSVP is receiver-oriented: the sender transmits PATH messages describing the traffic, and receivers reply with RESV messages that request a reservation hop by hop back toward the sender. Reservations are "soft state" and must be refreshed periodically. RSVP carries, but does not itself define, traffic-control parameters, and it is not a routing protocol.

Applications

RSVP was designed for multicast and unicast real-time traffic such as voice and video. An important extension, RSVP-TE (traffic engineering), is widely used to establish MPLS label-switched paths in service-provider networks.
