Runtime system

A runtime system or runtime environment is a sub-system that exists both in the computer where a program is created and in the computer where it is intended to be run. It provides the services and environment required for the execution of a computer program, including loading the program, providing access to system resources, and often implementing parts of the programming language's semantics that cannot be compiled directly into machine code.

Functions

Typical runtime services include memory management and garbage collection, exception handling, dynamic linking and loading, input/output, thread scheduling, and standard library routines. In compiled languages such as C, the runtime is a small library of startup code and support routines; in interpreted and virtual-machine languages — such as Java's JVM, .NET's CLR, or the Python interpreter — the runtime is a substantial program that executes or just-in-time compiles the code.

Runtime versus compile time

Errors and behaviour are often classified as occurring at compile time, when a program is translated, or at run time, when it executes. Runtime errors include division by zero, null-pointer dereferences and out-of-memory failures. A runtime environment may also provide portability: the same program can run on different hardware because the runtime adapts it to the host system.

Examples

Well-known runtimes include the Java Runtime Environment, the .NET runtime, Node.js and Deno for JavaScript and TypeScript, the Erlang BEAM virtual machine famed for fault tolerance, and the Android Runtime (ART) used on Android devices.
