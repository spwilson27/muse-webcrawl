Libreboot

Libreboot is a free and open-source software project aimed at replacing proprietary BIOS and UEFI firmware in computers with a free boot firmware. It is a distribution of coreboot configured with a focus on ease of use and minimal proprietary components ("blobs").

History

The project was started in December 2013 by Leah Rowe. Libreboot briefly became a GNU project in 2016 before a public dispute led to its removal in 2017, after which it continued independently. Later versions resumed shipping limited binary blobs for newer hardware, prompting debate within the free software community and the creation of the more strictly blob-free fork GNU Boot.

Features

Libreboot initializes the hardware and loads a payload such as the GRUB bootloader or SeaBIOS. It supports a limited set of mostly older laptops and desktops, notably certain Lenovo ThinkPad and Apple MacBook models, where the original firmware can be replaced without proprietary initialization code. Installation typically requires flashing the ROM chip, often with an external programmer.

Reception

The Free Software Foundation has promoted Libreboot through its Respects Your Freedom certification for compatible hardware retailers. Supporters value the security and freedom benefits of auditable boot firmware, while critics note the restricted hardware support and installation difficulty.
