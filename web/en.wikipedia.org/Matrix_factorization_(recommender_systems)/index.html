Matrix factorization (recommender systems)

Matrix factorization is a class of collaborative filtering techniques used in recommender systems. It characterises both users and items by vectors of latent factors inferred from patterns in a large, sparse matrix of user–item interactions such as ratings. A high correspondence between user and item factors predicts that the user will like the item.

Method

In the basic model, each user u has a vector pu and each item i a vector qi in a low-dimensional space; the predicted rating is their dot product. The factors are learned by minimising the regularised squared error on the observed ratings, using stochastic gradient descent or alternating least squares. Extensions add user and item bias terms, implicit feedback (clicks, views, purchases), temporal dynamics and side information.

History

The approach rose to prominence during the Netflix Prize (2006–2009), where Simon Funk's application of singular value decomposition to the sparse ratings matrix, and the refined models of the winning teams, dramatically improved prediction accuracy. Matrix factorization variants remain a standard baseline and component in commercial recommendation engines.
