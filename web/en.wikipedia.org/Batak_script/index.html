The Batak script (surat Batak) is a writing system used to write the Austronesian Batak languages spoken by several million people in North Sumatra, Indonesia. It is an abugida descended from the Brahmi script of India via the Pallava and Old Kawi scripts, and is closely related to other Indonesian scripts such as those of the Tagalog, Hanunó'o, and Rejang peoples.

Structure

Batak has a base set of consonant letters (the induk ni surat, "mother letters"), each with an inherent vowel /a/. Diacritics (anak ni surat, "child letters") change the vowel or close the syllable; a special mark called the pangolat cancels the vowel. There are also independent vowels and additional letters for sounds such as /i/ and the final /ng/ and /h/. The script is written without spaces between words, traditionally from bottom to top on bamboo, bark, and buffalo bone.

Variants

Each Batak subgroup — Karo, Pakpak, Simalungun, Toba, and Angkola-Mandailing — has its own variant of the script, differing in letter forms. Traditionally literacy in the script was concentrated among the datu (priest-magicians), who used it for magical and divinatory manuscripts called pustaha, written on folded bark books, as well as for calendars, charms, and letters carved on bamboo.

Modern usage

From the late 19th century, mission printing and Dutch colonial schooling shifted Batak publishing to the Latin alphabet, and everyday use of the script declined. It survives on ceremonial objects, signboards, and in cultural preservation efforts. Batak was added to the Unicode Standard in October 2010 with the release of version 6.0 (block U+1BC0–U+1BFF).
