Liouville function

The Liouville function, denoted λ(n) and named after Joseph Liouville, is an important arithmetic function in number theory. It is defined by λ(n) = (−1)Ω(n), where Ω(n) counts the total number of prime factors of n with multiplicity. Thus λ(n) = +1 if n is a product of an even number of primes and −1 if it is a product of an odd number of primes; for example λ(1) = 1, λ(2) = −1, λ(4) = 1, and λ(6) = 1.

Properties

The function is completely multiplicative, and its summatory function L(n) = Σk≤n λ(k) is connected to deep questions about the distribution of primes. Pólya's conjecture (1919) claimed that L(n) ≤ 0 for all n ≥ 2; it was disproved by C. Brian Haselgrove in 1958, with the smallest counterexample later found to be n = 906,150,257. The growth of L(n) is related to the Riemann hypothesis: the hypothesis implies L(n) = O(n1/2+ε).

Connections

The Dirichlet series of λ(n) equals ζ(2s)/ζ(s). The function is also related to the Möbius function through λ(n) = Σd²|n μ(n/d²), and its properties feature in equivalent formulations of the Riemann hypothesis.
