Zopfli is a data compression library and program developed by Google that performs data compression using the Deflate algorithm. Zopfli is named after zopf, a Swiss German word for a braided bread (literally "little braid"), following the pattern of naming compression tools after foods. It was released as free and open-source software under the Apache License, Version 2.0, in February 2013.

Properties

Zopfli produces output files that are fully compatible with the gzip, zlib and Deflate formats used by ordinary decompressors, but it expends far more computation time to find a denser encoding. It typically produces files about 3–8% smaller than the maximum-compression output of zlib, at the cost of being roughly two orders of magnitude slower. Decompression speed is unaffected. Because of this asymmetry, Zopfli is best suited to one-time compression of content that will be decompressed many times, such as static web assets, software packages and PNG images (via the companion zopflipng tool).

Technique

The encoder uses extensive iterative optimisation: it models the costs of literal/length and distance symbols, performs exhaustive searches for good LZ77 matches and repeatedly refines the block splitting and Huffman code choices until the output converges. Google later applied similar techniques in the Brotli format.
