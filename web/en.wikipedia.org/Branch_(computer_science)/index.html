Branch (computer science)

A branch is an instruction in a computer program that can cause a computer to begin executing a different instruction sequence and thus deviate from its default behaviour of executing instructions in order. Branch (or branching, branched) may also refer to the act of switching execution to a different instruction sequence as a result of executing a branch instruction. Branch instructions are used to implement control flow in program loops and conditionals (i.e., executing a particular sequence of instructions only if certain conditions are satisfied).

A branch instruction can be either an unconditional branch, which always results in branching, or a conditional branch, which may or may not cause branching depending on some condition. Also, depending on how it modifies the program counter, a branch instruction may be a direct branch (the effective address is specified in the instruction) or an indirect branch (the effective address is specified in a register or memory location, whose value can change at runtime).

Implementation

Mechanically, a branch instruction can change the instruction pointer (IP) register of the CPU. The new value of the IP then causes the CPU to fetch the next instruction from the indicated location in memory, thus altering the flow of control. Branch instructions come in a variety of forms:

  • Conditional branches — taken or not taken depending on the state of condition code flags, such as zero, carry, or sign.
  • Unconditional branches — always transfer control, often called jumps.
  • Call instructions — branch while saving the return address, used to invoke subroutines.
  • Return instructions — branch back to a saved address.

Performance

In modern pipelined processors, branches can be expensive. If the processor must wait to learn whether a conditional branch is taken before fetching the next instructions, the pipeline stalls and performance suffers. To mitigate this, processors use branch prediction hardware that guesses the outcome of a branch and speculatively fetches and executes instructions along the predicted path. When the prediction is correct, the branch costs almost nothing; when wrong, the speculatively executed work must be discarded, incurring a misprediction penalty.

Branch predication and conditional move instructions offer an alternative in some instruction set architectures, allowing short sequences to execute without an actual branch.

Examples

In x86 assembly language, the JMP instruction is an unconditional branch, while instructions such as JE (jump if equal) and JNE (jump if not equal) are conditional branches that test the flags set by a preceding comparison. In high-level languages, if statements, loops such as while and for, and function calls all ultimately compile down to branch instructions.
