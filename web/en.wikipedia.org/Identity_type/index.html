Identity type

In type theory, an identity type is a type whose elements are proofs (or witnesses) that two elements of another type are equal. Introduced by Per Martin-Löf in his intensional type theory, identity types internalise the notion of equality within the type system itself.

Introduction and elimination

For a type A and elements a, b : A, the identity type IdA(a, b) is formed. Its canonical element is reflexivity, refl : IdA(a, a). The elimination rule, traditionally called J, allows one to prove a property for all identifications by checking it for reflexivity alone.

Interpretations

Beyond the interpretation of identifications as proofs of equality, identity types admit a homotopical interpretation: elements of an identity type behave like paths between points in a space. This insight led to homotopy type theory, in which iterated identity types reflect higher-dimensional structure.
