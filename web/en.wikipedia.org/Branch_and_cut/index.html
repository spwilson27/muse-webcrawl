Branch and cut

FieldMathematical optimization
SolvesMixed-integer linear programs
CombinesBranch and bound; cutting planes

Branch and cut is a method of combinatorial optimization for solving integer linear programs (ILPs) and mixed-integer linear programs (MILPs). It combines the branch-and-bound search framework with cutting-plane methods, and is the basis of most commercial and open-source MILP solvers.

How it works

The algorithm relaxes the integer constraints and solves the resulting linear program. If the solution is fractional, it attempts to add cutting planes — valid inequalities (such as Gomory cuts or problem-specific cuts) that separate the fractional solution from the integer hull without removing any feasible integer point. If cuts fail to produce an integer solution, the algorithm branches: it splits the problem on a fractional variable, creating subproblems solved recursively, using bounds to prune the search tree.

Applications

Branch and cut underlies large-scale logistics, scheduling, network design, and production planning. Its efficiency depends heavily on strong formulations, good cut selection, branching rules, and primal heuristics; with these, problems with tens of thousands of integer variables can often be solved to proven optimality.
