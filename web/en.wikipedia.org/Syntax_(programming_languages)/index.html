Syntax (programming languages)

Syntax
Field: Computer science
Defined by: Grammars (e.g. BNF/EBNF)
Levels: Lexical, concrete, abstract

In computer science, the syntax of a programming language is the set of rules defining which combinations of symbols are correctly structured statements or expressions in that language. Syntax concerns the form of programs, as opposed to their semantics, which concerns meaning.

Levels of syntax

Syntax is usually analysed at three levels. Lexical syntax defines tokens — identifiers, literals, operators, keywords — typically with regular expressions. Concrete syntax defines how tokens combine into phrases, usually specified by a context-free grammar in Backus–Naur form (BNF) or extended BNF. Abstract syntax captures the essential structure of programs as trees, discarding punctuation and other surface details.

Parsing and errors

Compilers and interpreters analyse syntax using parsers that build a parse tree from source text; violations produce syntax errors, which must be fixed before a program can run. Languages differ greatly in surface style — compare the indentation-based blocks of Python with the brace-delimited blocks of C-like languages — even where their underlying structures are similar.
