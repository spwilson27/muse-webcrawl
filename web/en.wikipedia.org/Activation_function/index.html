Activation function

In artificial neural networks, the activation function of a node defines the output of that node given an input or set of inputs. A standard modern neural network uses a non-linear activation function, which allows the network to model complex relationships between inputs and outputs. Without non-linearity, a multi-layer network would collapse to an equivalent single linear transformation.

Properties

Desirable properties of activation functions include non-linearity, differentiability (to permit gradient-based training by backpropagation), a range suited to the task, and computational efficiency. Historically, the logistic sigmoid and hyperbolic tangent were dominant, but they suffer from the vanishing gradient problem in deep networks.

History

Early perceptrons used a binary step function. The adoption of smooth functions such as the sigmoid enabled training by gradient descent. The rectified linear unit, popularized around 2010–2011, greatly accelerated the training of deep networks and became the default for convolutional networks, while variants such as GELU and Swish are common in transformer architectures.
