OpenBSD is a free and open-source, security-focused, Unix-like operating system based on the Berkeley Software Distribution (BSD). Theo de Raadt created OpenBSD in 1995 by forking NetBSD 1.0. The project is known for its emphasis on correctness, proactive security, integrated cryptography and clean licensing, as well as its insistence on high-quality documentation.

Puffy, the OpenBSD mascot.

History

In December 1994, NetBSD co-founder Theo de Raadt was asked to resign from the NetBSD core team after disagreements. In 1995 he forked NetBSD to create OpenBSD, and the first release, OpenBSD 1.2, appeared in July 1996. The project, coordinated from Calgary, Alberta, Canada, has since produced a new release roughly every six months.

Security

OpenBSD pioneered or popularised many security technologies later adopted elsewhere, including W^X memory protection, privilege separation, address space layout randomisation, the bcrypt password hashing scheme, and the pledge and unveil system calls. The project famously long advertised "only two remote holes in the default install, in a heck of a long time". The team conducts continuous full-source code audits.

Associated projects

The OpenBSD project develops widely used software distributed with the system, including OpenSSH (the most popular SSH implementation), LibreSSL (a fork of OpenSSL created after the Heartbleed vulnerability), the pf packet filter, OpenBGPD, OpenNTPD, tmux and the mandoc documentation system.

Releases and funding

Each release is accompanied by an original song and artwork. The project is funded by donations and supported by the OpenBSD Foundation, a Canadian non-profit.
