Path (computing)

A path (or filepath, file path, pathname) is a string of characters used to uniquely identify a location in a directory structure. It is composed by following the directory tree hierarchy in which components, separated by a delimiting character, represent each directory. The delimiting character is most commonly the slash ("/") on Unix-like systems, the backslash ("\") on Windows, or the colon (":") in classic Mac OS.

Absolute and relative paths

An absolute path begins at the root directory and specifies a location completely, e.g. /home/user/documents/file.txt or C:\Users\user\file.txt. A relative path is interpreted from the current working directory, using . for the current directory and .. for its parent. Relative paths appear in command-line navigation (cd), hyperlinks, and configuration files.

System-specific conventions

POSIX systems use a single root and forward slashes, and paths are case-sensitive. Windows supports drive-letter paths, UNC paths for network shares (beginning \\), and both slash directions in many APIs; its traditional MAX_PATH limit of 260 characters historically constrained deep directories. Uniform Resource Locators (URLs) adapt path syntax for web resources, while Unix shells and scripting languages provide utilities for manipulating paths, such as basename, dirname, and Python's pathlib.

PATH environment variable

A separate but related concept is the PATH environment variable: an ordered list of directories that the operating system searches when a user types a command name without a path. The name of the concept — a "search path" — is the origin of much common usage of the word in computing.
