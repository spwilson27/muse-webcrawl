Numerical linear algebra

From Wikipedia, the free encyclopedia


A matrix, the central object of the field

Numerical linear algebra, sometimes called applied linear algebra, is the study within numerical analysis of how matrix operations can be used to create efficient and stable algorithms for computing solutions to problems in linear algebra on computers.

Core problems

The central problems are: solving systems of linear equations Ax = b; least-squares problems; eigenvalue problems; and computing matrix factorisations such as the LU, QR, Cholesky, and singular value decompositions. These decompositions reduce hard problems to sequences of triangular or orthogonal transformations that can be solved reliably.

Direct and iterative methods

Direct methods, such as Gaussian elimination with pivoting, obtain an answer in a fixed number of operations and are preferred for dense problems of moderate size. Iterative methods — including the Jacobi and Gauss–Seidel iterations, conjugate gradient methods, and GMRES — are used for very large sparse systems, where they exploit matrix structure and produce successively better approximations.

Stability and conditioning

Because floating-point arithmetic is inexact, algorithms are judged by backward stability: whether the computed result is the exact solution of a slightly perturbed problem. The condition number of a matrix measures how sensitively the solution depends on the data.

Software

Standard implementations are provided by the BLAS and LAPACK libraries, which underlie most scientific computing environments.
