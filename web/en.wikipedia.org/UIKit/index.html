UIKit

UIKit is a graphical user interface framework developed by Apple Inc. for building applications on iOS, iPadOS, and tvOS. Descended from the AppKit framework of NeXTSTEP and macOS, UIKit provides the core objects an app needs for its window-based interface: views, controls such as buttons and sliders, view controllers that manage screens of content, gesture recognizers, and animation support.

Design

UIKit applications traditionally follow the model–view–controller architecture. A UIView represents a rectangular area of the screen that draws content and handles touch events through a responder chain; a UIViewController manages a hierarchy of views and the app's response to user actions. UIKit supplies ready-made components including table views (UITableView), collection views, navigation controllers, tab bars, text fields, and switches, and it integrates with Auto Layout, a constraint-based system for adaptive layouts across device sizes. Since 2019, Apple has promoted the declarative SwiftUI framework as UIKit's successor for new development, though UIKit remains fully supported and underlies much of SwiftUI's implementation on Apple platforms.

History

UIKit debuted with the iPhone SDK in 2008, when the platform was called iPhone OS. It adapted desktop GUI concepts to a touch-first environment, introducing multi-touch gestures, accelerometers, and a single-window app model. Major additions over the years included iPad support with split views and popovers (2010), Auto Layout (2012), size classes for adaptive design (2014), and drag and drop (2017).
