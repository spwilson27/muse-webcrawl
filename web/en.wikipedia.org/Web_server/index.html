Web server

A web server is computer software and the underlying hardware that accepts requests via HTTP (or its secure variant HTTPS) from clients, typically web browsers, and serves them web content such as HTML documents, images, and other files.

Function

When a browser requests a resource by URL, the web server retrieves the file from storage or generates it dynamically — often by running application code and querying databases — and returns it in an HTTP response. Servers also log requests, enforce access controls and authentication, and support features such as caching, compression, and virtual hosting of many websites on one machine.

History and common software

The first web server was created by Tim Berners-Lee at CERN in 1990. Widely used server software includes the Apache HTTP Server (dominant from the mid-1990s), Nginx (known for high concurrency), Microsoft IIS, and LiteSpeed. As of the 2020s, Nginx and Apache together serve a large share of the world's websites, alongside cloud-provider infrastructure.
