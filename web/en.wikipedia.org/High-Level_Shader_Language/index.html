High-Level Shader Language

The High-Level Shader Language or High-Level Shading Language (HLSL) is a proprietary shading language developed by Microsoft for use with the Microsoft Direct3D API to create shaders. It is analogous to the GLSL shading language used with the OpenGL standard. HLSL was first introduced with Direct3D 9 in 2002, allowing developers to write programmable vertex and pixel shaders in a C-like syntax rather than assembly language.

Overview

HLSL programs come in several forms: vertex shaders, geometry shaders, pixel (fragment) shaders, compute shaders, and — with Direct3D 11 and later — tessellation stages (hull and domain shaders). The language includes scalar and vector types (such as float4), matrices, structures, semantics that bind shader inputs and outputs to pipeline stages, and intrinsic functions for common graphics operations.

float4 main(float4 color : COLOR) : SV_Target
{
    return color;
}

HLSL shaders were originally compiled offline or at runtime using Microsoft's D3DCompile API. In 2017 Microsoft released the DirectX Shader Compiler (DXC), based on LLVM/Clang, which compiles HLSL to DXIL (DirectX Intermediate Language) and supports Shader Model 6 and later, adding features such as wave intrinsics and support for ray tracing shaders. HLSL can also be cross-compiled to SPIR-V for use with Vulkan.

Comparison with GLSL

HLSL and GLSL are similar in purpose and syntax, both being C-like languages for GPU programming. Differences include how matrices are stored by default (row-major in HLSL, column-major in GLSL), the use of semantics instead of layout qualifiers for input/output binding, and differences in texture sampling functions and coordinate conventions.
