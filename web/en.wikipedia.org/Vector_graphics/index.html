Vector graphics

Vector graphics are a form of computer graphics in which visual images are created directly from geometric shapes defined on a Cartesian plane, such as points, lines, curves and polygons. These shapes are each assigned a mathematical formula. The associated image files are generally much smaller than raster graphics, in which the image is composed of a grid of pixels, and have the unique advantage that they can be scaled to any size or resolution without losing image quality.

How it works

A vector image is stored as a list of drawing commands or mathematical descriptions: for example, a circle might be stored by its centre, radius, line colour, and fill. Curves are typically represented by Bézier curves with control points. Editors such as Adobe Illustrator and Inkscape let users manipulate these primitives directly. The standard format for vector graphics on the web is SVG (Scalable Vector Graphics); other formats include EPS, PDF, and AI.

Comparison with raster graphics

Raster (bitmap) images are resolution-dependent and blur or pixelate when enlarged, but they capture photographic detail far more naturally. Vector graphics excel for logos, typography, diagrams, and illustrations that must scale from a business card to a billboard. Rendering a vector image to the screen — rasterisation — is done by the display software at whatever resolution is required.

Applications

Vector graphics are fundamental to computer-aided design (CAD), computer fonts (whose glyphs are stored as outlines), mapping (GIS), laser cutting, and much of print and web design. Early computer displays were themselves vector displays before raster screens became universal.
