Robot navigation

Robot navigation refers to the ability of a robot to establish its own position in its frame of reference and then to plan a path towards some goal location. This capability underlies applications from warehouse automation and domestic cleaning robots to planetary rovers and self-driving cars.

In order to navigate in its environment, the robot or any other mobility device requires representation, i.e. a map of the environment, and the ability to interpret that representation. Navigation can be defined as the combination of the three fundamental competences: self-localisation, path planning, and map-building and map interpretation.

Vision-based navigation

Vision-based navigation uses computer vision techniques and optical sensors, including laser-based range finders and photometric cameras using arrays of photodiodes, to extract information about the surroundings. Landmark recognition, optical flow, and stereo vision are common approaches.

Inertial navigation

Inertial navigation systems estimate position using dead reckoning from accelerometers and gyroscopes. Although they work without external references, their position estimates drift over time, so they are typically fused with other sensors.

Acoustic navigation

Underwater vehicles, which cannot use GPS, navigate using acoustic positioning systems and sonar. Acoustic beacons on the seafloor can provide long-baseline positioning for autonomous underwater vehicles.

Radio navigation

Robots may also locate themselves using radio signals, including GPS and other satellite navigation systems outdoors, and Wi-Fi positioning, Bluetooth beacons, or ultra-wideband anchors indoors.

Localization and mapping

A central problem in robot navigation is simultaneous localization and mapping (SLAM), in which a robot builds a map of an unknown environment while simultaneously tracking its own position within it. Popular algorithms include EKF SLAM, FastSLAM, and graph-based SLAM. Path planning algorithms such as A*, Dijkstra's algorithm, and rapidly-exploring random trees (RRT) compute routes through the map.
