Long short-term memory

Long short-term memory (LSTM) is a type of recurrent neural network (RNN) architecture designed to learn long-term dependencies in sequence data. It was proposed by Sepp Hochreiter and Jürgen Schmidhuber in 1997 to address the vanishing gradient problem that prevents ordinary RNNs from learning connections between distant time steps.

Architecture

An LSTM unit maintains a cell state that runs through the sequence like a conveyor belt, regulated by three gates: a forget gate deciding what to discard from the cell state, an input gate deciding what new information to store, and an output gate deciding what to emit as the hidden state. Each gate is a sigmoid layer producing values between 0 and 1. A later refinement added "peephole" connections letting the gates inspect the cell state.

Applications

LSTMs achieved state-of-the-art results in speech recognition, machine translation, handwriting recognition and language modelling in the 2010s, and powered early production systems such as Google Translate's neural engine and smartphone voice assistants. Although transformer architectures have since displaced them in many tasks, LSTMs remain used where sequential processing or small models are advantageous. The bidirectional variant reads sequences in both directions.
