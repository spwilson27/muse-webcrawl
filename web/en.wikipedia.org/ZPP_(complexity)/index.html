In computational complexity theory, ZPP (Zero-error Probabilistic Polynomial time) is the complexity class of problems for which a probabilistic Turing machine exists with three properties: it always gives the correct YES or NO answer; its expected running time is polynomial; and it may answer "don't know" with probability at most 1/2. Equivalently, ZPP problems admit Las Vegas algorithms — randomised algorithms that never err but have variable, polynomial expected, running time.

Definition and equivalent forms

ZPP can be defined as the intersection of the one-sided-error classes RP and co-RP. Another definition requires the algorithm to run in worst-case polynomial time while being allowed to output "don't know" with probability at most 1/2. The equality of these definitions is a standard result.

Relations to other classes

ZPP contains P and is contained in both RP and BPP. Whether any of these inclusions is strict is unknown, but it is widely believed that ZPP is strictly larger than P only if randomised computation adds real power in this zero-error setting. Problems known to lie in ZPP but not known to be in P have included, at various times, certain number-theoretic and algebraic problems; primality testing was in ZPP (via the Adleman–Huang algorithm) before the deterministic AKS test placed it in P.
