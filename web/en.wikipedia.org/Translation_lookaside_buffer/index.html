Translation lookaside buffer

Translation lookaside buffer
TypeCPU cache
PurposeCaching virtual-to-physical address translations
LocationMemory management unit (MMU)

A translation lookaside buffer (TLB) is a memory cache that stores recent translations of virtual memory addresses to physical addresses. It is part of the chip's memory management unit (MMU). A TLB may reside between the CPU and the CPU cache, between the CPU cache and primary storage memory, or between levels of the multi-level cache.

Overview

Most modern desktop, laptop, and server processors include at least one TLB in the MMU. When the processor needs to access a location in memory, it first uses the virtual address to check the TLB. If a matching entry is found (a TLB hit), the physical address is returned and memory access can continue. If there is no matching entry (a TLB miss), the MMU or operating system must locate the data in the page table, a process called a page walk, which is considerably slower.

Multilevel TLBs

Many processors have multiple TLBs, often organised in a hierarchy: a small, fast first-level TLB (sometimes split into separate instruction and data TLBs) backed by a larger, slower second-level TLB. Modern processors may also share TLBs between simultaneous multithreading contexts or isolate them per process using address space identifiers.

Context switching

When a context switch occurs, some or all TLB entries may become invalid because the virtual address mappings differ between processes. Hardware can avoid flushing the whole TLB by tagging entries with an address space identifier (ASID), so entries from different processes coexist.
