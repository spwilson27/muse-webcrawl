Nginx (pronounced "engine x") is a web server that can also be used as a reverse proxy, load balancer, mail proxy, and HTTP cache. The software was created by Russian developer Igor Sysoev and publicly released in 2004. It was designed to address the C10k problem — handling ten thousand concurrent client connections efficiently — using an asynchronous, event-driven architecture in which a small number of worker processes handle many connections, in contrast to the process-per-connection model of older servers such as Apache HTTP Server.

Use and features

Nginx is used by a large share of the world's busiest websites, particularly for serving static content, terminating TLS connections, and proxying requests to application servers. Its features include load balancing with health checks, caching, URL rewriting, HTTP/2 and HTTP/3 support, and a modular architecture. A commercial version, NGINX Plus, is sold with additional management and support features. The company behind the project, Nginx, Inc., was acquired by F5, Inc. in 2019 for a reported $670 million.

Forks and disputes

In 2024, following disagreements between F5 and long-time contributors in Russia over security policy handling, a prominent developer forked the project as freenginx. The episode followed earlier turbulence, including a 2019 police raid connected to a copyright dispute over the software's origins at the internet company Rambler, where Sysoev had first developed it.
