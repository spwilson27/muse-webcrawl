EPrints is a free and open-source software package for building open access repositories that are compliant with the Open Archives Initiative Protocol for Metadata Harvesting (OAI-PMH). It was developed at the School of Electronics and Computer Science of the University of Southampton and was first released in 2000, making it one of the earliest institutional repository systems.

Features

EPrints is typically used by universities to host research outputs — journal articles, theses, reports and datasets — in institutional repositories that support the open access self-archiving movement. The software runs on Unix-like systems using Perl, the Apache web server and a MySQL or PostgreSQL database. It offers configurable deposit workflows, metadata schemas, search and browse interfaces, and export in many bibliographic formats.

Adoption

Hundreds of repositories worldwide run EPrints. Its development was closely associated with open access advocates at Southampton, including Stevan Harnad, and the Registry of Open Access Repositories (ROAR) tracked repositories running the software. Major releases include EPrints 3 (2007), which added an extensible plug-in architecture.
