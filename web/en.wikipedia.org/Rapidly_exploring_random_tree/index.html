Rapidly exploring random tree

A rapidly exploring random tree (RRT) is an algorithm in motion planning designed to efficiently search nonconvex, high-dimensional spaces by randomly building a space-filling tree. It was developed by Steven M. LaValle and James J. Kuffner Jr. in the late 1990s.

Algorithm

Starting from an initial configuration, the tree grows by repeatedly sampling a random configuration, finding the nearest existing node, and extending a fixed step toward the sample if the connection is collision-free. The random sampling biases growth toward unexplored regions, making RRTs effective for problems with many degrees of freedom.

Variants and applications

Variants include RRT-Connect, bidirectional RRTs, and RRT*, which is asymptotically optimal. RRTs are widely used in robotics for manipulator and mobile-robot path planning, autonomous vehicles, and computer animation.
