Domain of a function

From Wikipedia, the free encyclopedia

In mathematics, the domain of a function is the set of inputs accepted by the function. It is sometimes denoted by dom(f) or dom f, where f is the function. In layman's terms, the domain of a function can generally be thought of as "what x can be".

Definitions

More precisely, given a function f : X → Y, the domain of f is X. In modern mathematical language, the domain is part of the definition of a function rather than a property of it. The set Y is called the codomain, and the set of values the function actually takes is its range (or image). A function is often described by a formula when no domain is stated explicitly; in that case the domain is understood to be the largest set on which the formula makes sense, sometimes called the natural domain.

Examples

The function f(x) = 1/x has natural domain the real numbers excluding 0, since division by zero is undefined. The square root function f(x) = √x, taken as a real function, has domain the non-negative reals. Trigonometric functions illustrate restricted domains: the tangent function is defined for all real numbers except odd multiples of π/2.

Domain restriction

If a function's domain is a subset of another set, one speaks of restricting the function; conversely a partial function is one whose domain of definition is a proper subset of its nominal domain. Domain considerations are essential in analysis, for example when inverting a function: the sine function restricted to [−π/2, π/2] has the inverse arcsine.
