RDF Schema

Initial release1999 (W3C)
TypeSemantic Web vocabulary / data model
Namespacehttp://www.w3.org/2000/01/rdf-schema#

RDF Schema (RDFS or RDF/S) is a set of classes and properties, standardized by the World Wide Web Consortium (W3C), that provides a data-modelling vocabulary for RDF (Resource Description Framework) data. It is the simplest ontology language of the Semantic Web stack, offering a way to describe groups of related resources and the relationships between them.

Main constructs

RDFS introduces classes such as rdfs:Class and rdfs:Resource, and properties including rdfs:subClassOf, rdfs:subPropertyOf, rdfs:domain, and rdfs:range, which allow basic inference — for example, if a class A is a subclass of B, then every instance of A is also an instance of B. Annotation properties such as rdfs:label and rdfs:comment attach human-readable documentation.

Relation to OWL

RDFS is deliberately limited in expressiveness: it cannot express cardinality restrictions, disjointness, or logical combinations of classes. The Web Ontology Language (OWL) builds on RDFS to provide these richer constructs for knowledge representation and reasoning.

History

An early draft was published in the late 1990s alongside RDF itself, and RDFS became a W3C Recommendation in 2004, with a revised version (RDF 1.1) in 2014. It remains widely used in linked data vocabularies and knowledge graphs.
