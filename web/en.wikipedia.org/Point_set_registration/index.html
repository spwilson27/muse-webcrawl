Point set registration

Point set registration is the process of finding a spatial transformation (such as rotation, translation, and possibly scaling or more general deformations) that aligns two point sets. Given two point clouds — for example from 3D scans, image features, or anatomical landmarks — the goal is to compute the transformation that best maps one onto the other, usually by minimizing a distance measure between corresponding points.

Problem formulation

Rigid registration seeks a rotation matrix and translation vector minimizing the sum of squared distances between matched points; when correspondences are known, the optimal solution is given by the Kabsch algorithm via singular value decomposition. When correspondences are unknown, the problem is much harder and algorithms alternate between estimating correspondences and estimating the transform.

Algorithms

The best-known method is iterative closest point (ICP), introduced in 1992, which repeatedly matches each point to the nearest point in the other set and recomputes the optimal transform. Variants include point-to-plane ICP, robust kernels for outliers, probabilistic methods such as Coherent Point Drift, and global methods based on branch-and-bound or feature matching (e.g., FPFH with RANSAC).

Applications

Registration is fundamental in computer vision, robotics (scan matching for SLAM), medical imaging (aligning scans of a patient), and computer graphics (merging partial scans into complete models).
