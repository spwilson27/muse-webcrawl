Divisibility rule

A divisibility rule is a shorthand and useful way of determining whether a given integer is divisible by a fixed divisor without performing the division, usually by examining its digits. The rules transform a given number into a smaller one while preserving divisibility by the divisor in question. A divisibility rule applicable to a base-ten number may not work in other bases, though analogous rules can be derived for any base.

Common rules in base ten

DivisorRule
2The last digit is even (0, 2, 4, 6, 8).
3The sum of the digits is divisible by 3; the test may be repeated.
4The number formed by the last two digits is divisible by 4.
5The last digit is 0 or 5.
6The number passes the tests for both 2 and 3.
7Double the last digit and subtract it from the rest of the number; repeat until small; the result is divisible by 7.
8The number formed by the last three digits is divisible by 8.
9The sum of the digits is divisible by 9.
10The last digit is 0.
11The alternating sum of the digits (adding and subtracting in turn) is divisible by 11.
12The number passes the tests for both 3 and 4.
13Add four times the last digit to the rest of the number; repeat; the result is divisible by 13.

Why the rules work

The digit-sum rules for 3 and 9 work because 10 is congruent to 1 modulo 3 and modulo 9, so a number is congruent to the sum of its digits. The alternating-sum rule for 11 works because 10 ≡ −1 (mod 11). Rules for 2, 4, 5, 8, 10 and 25 work because these divisors divide powers of ten (10, 100, 1000, …), so only the final digits matter. General algorithms, such as the method described by Blaise Pascal in the seventeenth century, exist for constructing a rule for any divisor in any base.

Examples

To test 1,234,567 for divisibility by 3, add the digits: 1+2+3+4+5+6+7 = 28, then 2+8 = 10, then 1+0 = 1; since 1 is not divisible by 3, neither is the original number. To test 918,082 for divisibility by 11, form the alternating sum 2 − 8 + 0 − 8 + 1 − 9 = −22, which is divisible by 11, so the number is divisible by 11.
