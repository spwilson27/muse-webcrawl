List of programming languages by type

This is a list of programming languages categorised by paradigm and type. A single language may belong to several categories, since modern languages often support multiple paradigms.

Logos of widely used programming languages (placeholder image).

Imperative and procedural languages

  • Ada, ALGOL, BASIC, C, COBOL, Fortran, Go, Modula-2, Oberon, Pascal, Perl, REXX, Rust, Zig

Object-oriented languages

  • C++, C#, Java, Kotlin, Objective-C, Python, Ruby, Scala, Smalltalk, Swift, Visual Basic .NET

Functional languages

  • Clojure, Common Lisp, Elixir, Erlang, F#, Haskell, ML, OCaml, Racket, Scheme

Scripting languages

  • JavaScript (and TypeScript), Lua, Perl, PHP, PowerShell, Python, Ruby, shell languages (Bash, zsh), Tcl

Logic languages

  • Prolog, Datalog, Mercury

Markup and data languages

  • HTML, XML, JSON, YAML, LaTeX, SQL (query language)

Concurrent and parallel languages

  • Erlang, Go, Rust, Ada, Chapel, Cilk

Array languages

  • APL, J, K, MATLAB, R, NumPy-based Python

Assembly languages

  • x86 assembly, ARM assembly, MIPS assembly, and other machine-specific assemblers

Esoteric languages

  • Brainfuck, INTERCAL, Whitespace, Shakespeare, Befunge

Educational languages

  • Logo, Scratch, BASIC, Pascal

Notes

Paradigm classification is a matter of design emphasis rather than strict boundaries: Python, for example, supports procedural, object-oriented, and functional styles, while Rust combines imperative systems programming with functional features and strong concurrency guarantees.
