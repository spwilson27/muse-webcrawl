Microsoft Excel is a spreadsheet editor developed by Microsoft for Windows, macOS, Android, iOS, and the web, and is a component of the Microsoft 365 suite. It features calculation and computation capabilities, graphing tools, pivot tables, and a macro programming language called Visual Basic for Applications (VBA). Excel is the dominant spreadsheet application in business and forms part of the standard Microsoft Office toolset.

History

Excel was first released for the Apple Macintosh in 1985 and for Windows in 1987, where it became the first spreadsheet to outsell Lotus 1-2-3. Bundled in Microsoft Office from 1993, it gained VBA in version 5.0 and rapidly displaced competitors. The 2007 release introduced the Ribbon interface and the XML-based .xlsx format, expanding worksheet capacity to 1,048,576 rows by 16,384 columns. Subsequent versions added Power Query and Power Pivot data tools, dynamic array functions (such as XLOOKUP), and AI-assisted analysis.

Features

Excel organizes data in workbooks of worksheets divided into cells referenced by column letters and row numbers (for example, B3). Hundreds of built-in functions support financial, statistical, logical, text, and engineering calculations, and formulas recalculate automatically when precedent cells change. Charts, conditional formatting, data validation, and PivotTables support analysis and reporting, while VBA and Office Scripts allow automation. Excel files — particularly the legacy .xls format — have been a noted vector for malware macros.

Impact and criticism

Excel is deeply embedded in finance, accounting, science, and government, but high-profile spreadsheet errors — including cases in economic research and public-health data handling (such as a 2020 incident in England in which case records were lost due to the row limit of the old .xls format) — have highlighted risks of relying on spreadsheets for critical processes.
