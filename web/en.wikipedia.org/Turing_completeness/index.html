Turing completeness

In computability theory, a system of data-manipulation rules is said to be Turing complete if it can be used to simulate any Turing machine. A system that is Turing complete is, in principle, able to compute anything that is computable, given enough time and memory.

Criteria

A system is Turing complete if it supports conditional branching and can manipulate an unbounded amount of storage — for example through arbitrary-precision integers, unbounded arrays, or self-modifying state. Nearly all general-purpose programming languages are Turing complete by design.

Examples

Unintentional Turing completeness appears in systems such as the Game of Life cellular automaton, Rule 110, Minecraft's redstone, spreadsheet formulas, and even some card games. The halting problem implies that no Turing-complete system can have all of its programs' behaviour decided in advance.
