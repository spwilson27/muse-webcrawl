Error detection and correction

Field: Information theory, coding theory

Key methods: Parity bits, checksums, CRC, Hamming codes, Reed–Solomon codes

In information theory and coding theory with applications in computer science and telecommunications, error detection and correction (EDAC, or error control) are techniques that enable reliable delivery of digital data over unreliable communication channels. Because channels are subject to noise, transmitted data may be corrupted, so redundancy is added to allow errors to be detected — and often corrected — at the receiver.

Detection schemes

Simple schemes include repetition codes, parity bits, checksums, and cyclic redundancy checks (CRCs), which append a short check value computed from the data. Error-detecting codes typically trigger retransmission, as in automatic repeat request (ARQ) protocols used in networking.

Forward error correction

Forward error correction (FEC) adds structured redundancy so the receiver can reconstruct the original data without retransmission. Foundations were laid by Richard Hamming's Hamming codes (1950) and Claude Shannon's channel coding theorem. Major families include convolutional codes, Reed–Solomon codes (used in CDs, DVDs, and QR codes), turbo codes, and low-density parity-check (LDPC) codes used in modern wireless standards.

Applications

Error control is essential in deep-space communications, mobile networks, data storage — where ECC memory and RAID rely on it — and optical media, anywhere the cost of errors or retransmission is high.
