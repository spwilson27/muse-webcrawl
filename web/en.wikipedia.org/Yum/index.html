Yum (Yellowdog Updater, Modified) is a free and open-source command-line package management utility for computers running the Linux operating system using the RPM Package Manager. It automatically computes dependencies and determines what actions should occur to install, update, or remove software packages.

History

Yum originated as a rewrite of the Yellowdog Updater (YUP) for Yellow Dog Linux and was developed principally by Seth Vidal and contributors at Duke University. It became the default package manager in Fedora, Red Hat Enterprise Linux (up to version 7), and CentOS.

Successor

Beginning with Fedora 22 and RHEL 8, Yum was superseded by DNF, a fork that resolved long-standing performance and memory issues while retaining a largely compatible command-line interface; the yum command in newer distributions is typically an alias to DNF.
