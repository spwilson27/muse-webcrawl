Bookmark (digital)

Type: Web browser feature

Also called: Favorite (Internet Explorer), shortcut

First browsers: Mosaic (1993), Netscape Navigator

In computing, a bookmark is a stored reference to a resource — most commonly a web page — that allows a user to return to it quickly without re-entering its address. The term is borrowed from the physical bookmark placed between the pages of a book. Web browsers maintain bookmarks in a dedicated menu or toolbar, usually organised into folders, and typically record the page's URL, title, and favicon.

History

The Mosaic browser introduced a "hotlist" in 1993; Netscape Navigator popularised the name "bookmarks," while Microsoft's Internet Explorer called them "Favorites." Bookmarks were stored locally, commonly in an HTML file (Netscape) or as individual shortcut files (Internet Explorer), making them portable but machine-bound. With browser synchronisation services, bookmarks now roam across a user's devices.

Social bookmarking and bookmarklets

In the 2000s, social bookmarking services such as Delicious let users save, tag, and publicly share collections of links, briefly becoming a major way of discovering web content; successors include Pinboard and read-it-later services. A related technology is the bookmarklet, a small piece of JavaScript stored as a bookmark's URL that runs in the context of the current page to perform an action, such as extracting data or submitting the page to a service.
