Object identifier

[Image placeholder: Object identifier]

An object identifier (OID) is an identifier used to name an object in a structured hierarchy, standardised by the ITU and ISO/IEC (X.660 / ISO/IEC 9834). OIDs form a tree in which each node is assigned by the registration authority that owns its parent node.

Structure

An OID is written as a sequence of numbers separated by dots, such as 2.5.4.3 (the X.500 common name attribute). The first arc is 0, 1 or 2; beneath it, registration authorities allocate arcs to organisations, which may subdivide them freely, giving a globally unique, decentralised naming scheme.

Uses

OIDs identify managed objects in SNMP MIBs, attribute types and certificate policies in X.509 public-key certificates, algorithms and object classes in LDAP directories, document types in DICOM medical imaging, and many other standardised entities.
