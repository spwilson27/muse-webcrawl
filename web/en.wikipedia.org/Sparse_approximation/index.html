Sparse approximation

FieldSignal processing, machine learning
ProblemFind the sparsest solution to a linear system
MethodsMatching pursuit, LASSO, basis pursuit

Sparse approximation (also known as sparse representation or sparse coding) is the problem of representing a signal as a linear combination of as few elementary components, called atoms, drawn from a dictionary, as possible. It underlies methods in signal processing, compressed sensing, and machine learning.

Formulation

Given a signal and an overcomplete dictionary matrix, one seeks a coefficient vector with few non-zero entries that approximately reproduces the signal. Because the exact problem is NP-hard in general, practical algorithms use greedy methods such as matching pursuit and orthogonal matching pursuit, or convex relaxations such as basis pursuit and the LASSO, which replace the count of nonzeros with the L1 norm.

Applications

Sparse models are used in denoising, compression, source separation, face recognition, and the learning of dictionaries from data.
