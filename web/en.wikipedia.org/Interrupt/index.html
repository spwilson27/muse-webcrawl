Interrupt

In digital computers, an interrupt is a request for the processor to interrupt currently executing code so that an event can be processed in a timely manner. When an interrupt fires, the processor suspends its current activities, saves its state, and transfers control to an interrupt handler (interrupt service routine), whose address is typically obtained from an interrupt vector table.

Types

Hardware interrupts are signalled by devices such as keyboards, timers, and network interfaces, and may be maskable or non-maskable. Software interrupts are generated by executing a special instruction, and exceptions are raised by the processor itself on conditions such as division by zero or page faults. Interrupts underpin multitasking, I/O handling, and real-time responsiveness in modern operating systems.
