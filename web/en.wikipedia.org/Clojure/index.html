Clojure

Clojure (pronounced like closure) is a dynamic and functional dialect of the Lisp programming language on the Java platform. Created by Rich Hickey and first released in 2007, it was designed as a general-purpose language combining the interactivity of a scripting language with an efficient approach to concurrent programming, largely through an emphasis on immutable data structures.

Design

Like other Lisps, Clojure treats code as data (homoiconicity) and has a powerful macro system. Unlike many Lisps, it discourages extensive mutable state: core data structures — lists, vectors, sets and maps — are persistent and immutable, and shared state is managed through explicit references with software transactional memory, atoms and agents. Functions are first-class, laziness is supported in sequences, and recursion is handled through the explicit loop/recur construct in the absence of tail-call optimisation in the JVM. Clojure compiles to JVM bytecode and interoperates directly with Java libraries.

(defn fib [n]
  (loop [a 0 b 1 i n]
    (if (zero? i) a (recur b (+ a b) (dec i)))))

Ecosystem

ClojureScript compiles Clojure to JavaScript for browser and Node.js applications. The language is maintained under the stewardship of Cognitect (later part of Nubank), with Hickey as benevolent dictator for life, and it is used commercially in domains such as finance, retail and data processing. Development is centred on REPL-driven, interactive programming.
