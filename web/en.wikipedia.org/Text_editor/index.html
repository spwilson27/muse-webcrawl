Text editor

A text editor is a type of computer program that edits plain text. Such editors are provided with operating systems and software development packages and can be used to change files such as configuration files, documentation files and programming language source code. Some text editors are small and simple, while others offer broad and complex functions; advanced editors aimed at programmers include syntax highlighting, macros, regular-expression search and replace, and integration with compilers and version control.

History

Before video displays, programmers edited text line by line on teleprinters using line editors such as ed. Screen editors emerged in the 1970s: vi, written by Bill Joy in 1976, and Emacs, developed by Richard Stallman and others, became the two dominant Unix editors, and their rivalry is jokingly called the "editor war". The personal computer era brought editors such as WordStar and later graphical editors like Notepad (Windows) and TextEdit (macOS).

Features

Modern programming editors — such as Visual Studio Code, Sublime Text, Vim and Neovim — support multiple cursors, code folding, autocompletion, plug-ins and themes, blurring into full integrated development environments. Text editors differ from word processors in that they do not embed formatting information in files, making them suitable for source code, markup and data files.

Plain text philosophy

Plain text files are portable across systems and decades, which makes text editors enduring tools in computing culture. Editing plain text is fundamental to system administration, programming and the Unix philosophy of composable tools.
