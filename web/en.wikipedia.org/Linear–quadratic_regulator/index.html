Linear–quadratic regulator

The linear–quadratic regulator (LQR) is an algorithm in optimal control theory concerned with operating a dynamic system at minimum cost. The case where the system dynamics are described by a set of linear differential equations and the cost is described by a quadratic function is the LQ problem. One of the main results is that the solution is provided by the linear–quadratic regulator, an optimal feedback controller whose gains are computed from a matrix Riccati equation.

Problem statement

Given a continuous-time linear system ẋ = Ax + Bu, the LQR seeks a state-feedback control law u = −Kx minimizing the quadratic cost functional J = ∫ (xᵀQx + uᵀRu) dt, where Q is positive semidefinite and R is positive definite. The optimal gain matrix K is obtained via the solution of the algebraic Riccati equation. In discrete time, the corresponding discrete algebraic Riccati equation is used.

Properties and applications

LQR controllers enjoy useful robustness margins and are widely used in aerospace guidance, robotics, process control, and economics. When process and measurement noise are present, combining LQR with a Kalman filter yields the linear–quadratic–Gaussian (LQG) controller. The theory dates to work by Rudolf Kálmán around 1960. Although the plant must be linear, LQR designs are often applied successfully to mildly nonlinear systems via linearization about an operating point.
