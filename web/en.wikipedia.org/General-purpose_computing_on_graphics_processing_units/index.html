General-purpose computing on graphics processing units

General-purpose computing on graphics processing units (GPGPU) is the use of a graphics processing unit (GPU), which typically handles computation only for computer graphics, to perform computation in applications traditionally handled by the central processing unit (CPU).

Principles

GPUs contain hundreds or thousands of small processing cores optimised for applying the same operation across large data sets — the single instruction, multiple data (SIMD) pattern. Workloads with high arithmetic intensity and abundant data parallelism, such as matrix multiplication, image processing, and simulations, can run an order of magnitude faster on a GPU than on a CPU.

Programming models

Early GPGPU work in the early 2000s shoehorned computation into graphics APIs. NVIDIA's CUDA platform (2007) and the open OpenCL standard (2009) made the technique mainstream, followed by APIs such as SYCL and DirectCompute. GPGPU underpins modern machine learning, where training deep neural networks relies overwhelmingly on GPU clusters, as well as scientific computing, finance, and cryptography.
