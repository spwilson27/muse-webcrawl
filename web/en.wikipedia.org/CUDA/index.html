CUDA

CUDA processing flow: data is copied to the GPU, processed by thousands of parallel threads, and copied back.

CUDA (Compute Unified Device Architecture) is a proprietary parallel computing platform and application programming interface (API) created by Nvidia that allows software to use certain types of graphics processing units (GPUs) for accelerated general-purpose processing, an approach known as GPGPU. First released in 2007 with the GeForce 8800 series, CUDA provides a software layer giving direct access to the GPU's virtual instruction set and parallel computational elements, letting developers write kernels in extensions of C, C++ and Fortran.

Programming model

In CUDA, computations are organised into kernels — functions executed on the GPU by large numbers of threads arranged in a hierarchy of thread blocks and grids. Threads within a block can cooperate through fast on-chip shared memory and synchronisation, while separate memory spaces (global, constant, texture, local) have different performance characteristics that programmers must manage. Nvidia provides the nvcc compiler, the CUDA Toolkit, and optimised libraries such as cuBLAS, cuFFT, cuDNN and Thrust.

Applications

CUDA underpins much of modern GPU computing: scientific simulation and computational fluid dynamics, weather modelling, molecular dynamics, and — most prominently — deep learning, where frameworks such as PyTorch and TensorFlow execute the bulk of their operations through CUDA, making Nvidia GPUs and the CUDA ecosystem the dominant platform for training large AI models. CUDA's proprietary nature and restriction to Nvidia hardware have motivated alternatives such as OpenCL, AMD's ROCm/HIP and SYCL, though CUDA's mature library ecosystem has kept it the de facto standard in high-performance and AI computing.

History

CUDA began with Nvidia's research into general-purpose GPU computing and was announced in November 2006 alongside the G80 architecture, the first GPU designed with compute in mind. Successive versions added C++ support, unified memory, cooperative groups and hardware features for tensor operations, and the platform extended to embedded (Jetson) and data-centre accelerators. Its chief architect in its early years was Ian Buck, whose BrookGPU research informed the design.
