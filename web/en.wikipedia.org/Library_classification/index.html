Library classification

A library classification is a system used to organise library materials — books, serials, media and digital resources — by subject, assigning each item a notation or call number that determines its place in a catalogue and on the shelf.

Major systems

The most widely used systems are the Dewey Decimal Classification (1876), used by most public and school libraries; the Library of Congress Classification, used by large academic libraries; and the Universal Decimal Classification, common in Europe. Other schemes include Bliss bibliographic classification and Ranganathan's faceted Colon Classification.

Principles

Classification schemes may be enumerative, listing all subjects, or faceted, combining elements from several aspects of a subject. Good classification balances literary warrant, logical order and practical shelf arrangement, and is continually revised as knowledge changes.
