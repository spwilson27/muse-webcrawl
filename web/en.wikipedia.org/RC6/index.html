RC6

In cryptography, RC6 is a symmetric key block cipher derived from RC5. It was designed by Ron Rivest, Matt Robshaw, Ray Sidney, and Yiqun Lisa Yin to meet the requirements of the Advanced Encryption Standard (AES) competition, for which it was one of five finalists. RC6 proper has a block size of 128 bits and supports key sizes of 128, 192 and 256 bits, with 20 rounds; the parametrised family RC6-w/r/b allows variable word size w, rounds r, and key length b.

Description

RC6 operates on four w-bit registers A, B, C, D rather than two, which suits the 128-bit AES block size. Its key innovation over RC5 is the use of integer multiplication in a quadratic function f(x) = x(2x + 1) mod 2w, whose upper bits provide data-dependent rotation amounts for the other registers. This strengthens resistance to differential and linear cryptanalysis compared with RC5. The key schedule expands the user key into 2r + 4 subkeys using constants derived from e and the golden ratio.

AES competition and status

Submitted in 1998, RC6 reached the AES finals alongside Rijndael, Serpent, Twofish and MARS. It was praised for its simplicity and speed, especially on 32-bit processors with fast multipliers, but scored below Rijndael, which was selected as AES in 2000. RC6 was patented by RSA Security and is now in the public domain following the patent's expiry and earlier royalty-free licensing statements. No practical attack on full 20-round RC6 is known, though reduced-round variants have been analysed extensively.
