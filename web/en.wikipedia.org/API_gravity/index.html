API gravity

The American Petroleum Institute gravity, or API gravity, is a measure of how heavy or light a petroleum liquid is compared to water: if its API gravity is greater than 10, it is lighter and floats on water; if less than 10, it is heavier and sinks.

API gravity is defined by the formula: °API = (141.5 / specific gravity at 60°F) − 131.5. Crude oils are classified as light, medium, or heavy according to their API gravity; light crude oils generally have an API gravity above 31°, while extra-heavy crudes and bitumen fall below 10°. The measure is widely used in the petroleum industry for grading and pricing crude oil.
