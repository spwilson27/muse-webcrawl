OpenCL

Original author: Apple Inc.
Developer: Khronos Group
Initial release: 2009
Written in: C, C++
Type: Heterogeneous computing framework

OpenCL (Open Computing Language) is a framework for writing programs that execute across heterogeneous platforms consisting of central processing units (CPUs), graphics processing units (GPUs), digital signal processors (DSPs), field-programmable gate arrays (FPGAs) and other processors or hardware accelerators. OpenCL specifies a programming language (based on C99) for programming these devices and application programming interfaces (APIs) to control the platform and execute programs on the compute devices.

History

OpenCL was initially developed by Apple Inc., which held trademark rights, and refined in collaboration with technical teams at AMD, IBM, Intel, and Nvidia. Apple submitted the initial proposal to the Khronos Group, and Khronos released the OpenCL 1.0 specification on 8 December 2008. Version 1.1 followed in 2010, 1.2 in 2011, and 2.0 in 2013. OpenCL 3.0, released in 2020, consolidated prior functionality and made all version 2.x features optional, aiming to simplify deployment. Apple deprecated OpenCL in macOS in favour of its Metal API, though the framework remains widely supported on Windows and Linux platforms, particularly through AMD, Intel, and Nvidia drivers and open-source implementations such as POCL.

Programming model

An OpenCL program consists of host code, written in C or C++, and kernels written in the OpenCL C language (later versions also support C++ kernels and the SPIR-V intermediate representation). The host enumerates platforms and devices, creates contexts and command queues, allocates memory buffers, and enqueues kernel executions and data transfers. Kernels execute in parallel across many work-items organised into work-groups, following a data-parallel model well suited to GPUs. OpenCL provides an abstract device model and a memory hierarchy that includes global, constant, local, and private memory.

Applications

OpenCL has been used for scientific computing, image and signal processing, cryptography, physics simulation, and machine-learning workloads, and in industries such as finance and medical imaging. It competes with vendor-specific frameworks such as Nvidia's CUDA while offering portability across hardware from different vendors.
