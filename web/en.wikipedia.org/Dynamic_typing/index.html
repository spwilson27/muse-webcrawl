Dynamic typing

Dynamic typing
ConceptType system behaviour at run time
Contrasts withStatic typing (compile-time checking)
Typical languagesPython, JavaScript, Ruby, Lisp, PHP, Perl

In computer programming, a type system is dynamically typed if most type checking is performed at run time rather than at compile time. In dynamic typing, types are associated with values (objects) rather than with variables, parameters or expressions: a variable can refer to a number at one moment and a string at the next, and an operation applied to a value of an inappropriate type is reported as a run-time error (or triggers an implicit conversion, depending on the language).

Characteristics

Dynamically typed languages typically require no type declarations, favour rapid prototyping and concise code, and support techniques such as duck typing — where an object's suitability is judged by the methods and properties it actually has ("if it walks like a duck and quacks like a duck, it is a duck") — metaprogramming, and runtime reflection and code generation. Because values carry type tags at run time, implementations must check types during execution, which costs performance unless mitigated by techniques such as just-in-time compilation, inline caching and hidden classes, used to great effect in modern JavaScript engines.

Trade-offs and debate

Advocates credit dynamic typing with flexibility and developer speed; critics point to the loss of early error detection, weaker tooling (refactoring and autocompletion historically), and self-documentation, since function signatures do not state their expected types. The boundary has blurred: many dynamic languages now offer optional static annotations — TypeScript and Flow for JavaScript, type hints and checkers such as mypy for Python, Sorbet for Ruby — a practice called gradual typing. Experiments and industry experience suggest the productivity differences are context-dependent rather than decisive.

History

Lisp, one of the earliest high-level languages (1958), was dynamically typed, as were Smalltalk, APL and the scripting languages that flourished in the 1990s. The mainstream popularity of dynamic typing rose with the web: JavaScript in the browser, PHP and Python on the server, and Ruby via Rails.
