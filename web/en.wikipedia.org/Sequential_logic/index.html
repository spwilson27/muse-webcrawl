Sequential logic

In digital circuit theory, sequential logic is a type of logic circuit whose output depends not only on its present input values but also on the sequence of past inputs, the input history. This is in contrast to combinational logic, whose output is a function of only the present input. Sequential logic circuits therefore have state (memory) and are used to build counters, registers and finite-state machines.

Synchronous and asynchronous

In synchronous sequential circuits, the state changes only at discrete instants in response to a clock signal; the storage elements are typically edge-triggered flip-flops. In asynchronous circuits, state can change whenever an input changes, and the design must avoid races and hazards.

Storage elements

The basic building blocks are latches (level-sensitive) and flip-flops (edge-triggered), such as the SR, D, JK and T types. Combinations of flip-flops form shift registers, counters and the registers in computer CPUs.

Applications

Nearly all practical digital systems mix combinational and sequential logic: processors, memory controllers, and communication protocols are modeled as finite-state machines built from sequential logic.
