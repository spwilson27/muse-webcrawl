Ford–Fulkerson algorithm

From Wikipedia, the free encyclopedia

The Ford–Fulkerson method or Ford–Fulkerson algorithm (FFA) is a greedy algorithm that computes the maximum flow in a flow network. It is sometimes called a "method" rather than an "algorithm" because the approach to finding augmenting paths in the residual graph is not fully specified. It is due to L. R. Ford Jr. and D. R. Fulkerson, who published it in 1956.

Description

The idea behind the algorithm is as follows: as long as there is a path from the source (start node) to the sink (end node), with available capacity on all edges in the path, send flow along one of the paths. Then find another path, and so on. A path with available capacity is called an augmenting path. The algorithm operates on the residual graph, which records for each edge how much additional flow can still be pushed, including "reverse" edges that allow previously sent flow to be cancelled.

Correctness and complexity

By the max-flow min-cut theorem, when no augmenting path remains in the residual graph, the flow is a maximum flow. If capacities are integers, the running time is O(E·f), where E is the number of edges and f is the value of the maximum flow; this can be slow if f is large, and with irrational capacities the algorithm may fail to terminate. Choosing augmenting paths by breadth-first search yields the Edmonds–Karp algorithm, which runs in polynomial time O(VE²); choosing them by depth-first search with capacity scaling improves the bound further.

Applications

Maximum-flow methods model transportation and communication networks, circulation problems, bipartite matching, image segmentation, and project selection, among many others.
