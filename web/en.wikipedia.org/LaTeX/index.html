LaTeX

LaTeX is a software system for typesetting documents, widely used for scientific and technical publishing because of its high-quality handling of mathematics and bibliographies. It is built on Donald Knuth's TeX typesetting engine.

History

Leslie Lamport began developing LaTeX in the early 1980s; the first version appeared in 1984 and LaTeX2e in 1994. A long-term LaTeX3 project develops its future core.

Markup approach

Authors write plain text with commands such as \section{} and \cite{}, describing logical structure while style files handle layout. Distributions include TeX Live and MiKTeX, and engines such as pdfLaTeX, XeLaTeX and LuaLaTeX.
