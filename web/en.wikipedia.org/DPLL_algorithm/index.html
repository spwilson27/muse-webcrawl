DPLL algorithm

The DPLL algorithm (Davis–Putnam–Logemann–Loveland) is a complete, backtracking-based search algorithm for deciding the satisfiability of propositional logic formulae in conjunctive normal form (CNF) — the SAT problem. Introduced in 1962, it refined the earlier Davis–Putnam procedure of 1960 and remains the conceptual basis of most modern SAT solvers.

Description

DPLL works by recursively choosing an unassigned variable and branching on its truth value. After each assignment it simplifies the formula and applies two key rules: unit propagation, which forces the value of any clause reduced to a single unassigned literal, and the pure literal rule, which assigns variables that appear with only one polarity. If a clause becomes empty (all its literals false), the current branch is a dead end and the algorithm backtracks; if all clauses are satisfied, the formula is satisfiable, and if every branch fails, it is unsatisfiable.

Modern developments

Practical solvers augment DPLL with conflict-driven clause learning (CDCL), which records the reasons for conflicts as new clauses so that the same failure is never repeated, together with watched literals, activity-based branching heuristics such as VSIDS, and periodic restarts. These enhancements let DPLL-style solvers routinely solve industrial problems with millions of variables, and the algorithm also underlies SMT solvers built on the DPLL(T) architecture.
