WIMP (computing)

In human–computer interaction, WIMP stands for "windows, icons, menus, pointer", denoting a style of graphical user interface (GUI) interaction. The model — in which users manipulate visual widgets on a desktop metaphor using a pointing device — became the dominant paradigm for personal computing from the 1980s onward.

History

The WIMP paradigm was developed at Xerox PARC in the 1970s for the Xerox Alto and commercialised in the Xerox Star (1981). It was popularised by the Apple Lisa (1983) and especially the Apple Macintosh (1984), then by Microsoft Windows, reaching near-universal adoption with Windows 95 and the corresponding Unix/Linux desktop environments. The term "WIMP" emerged in the 1980s; some attribute it to Merzouga Wilberts.

Elements

  • Windows — rectangular, often overlapping screen regions, each presenting a document, application, or view, which can be moved and resized.
  • Icons — small pictograms representing files, applications, and actions.
  • Menus — lists of commands, in menu bars, drop-down menus, and context menus.
  • Pointer — an on-screen cursor controlled by a mouse, trackpad, or similar device, used to select and drag objects (see WYSIWYG and direct manipulation).

Criticism and successors

Critics have long noted WIMP's inefficiency for expert users and poor fit for very small or very large displays. Touch-based smartphones rely instead on "post-WIMP" interfaces — direct multi-touch manipulation, gestures, and zooming user interfaces — though windows, icons, and menus persist on tablets and in multi-window modes. The acronym is sometimes playfully back-formed as an insult (" Wimps") by command-line enthusiasts, contrasting with CLI interfaces.
