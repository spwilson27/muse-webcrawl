String-searching algorithm

In computer science, string-searching algorithms, sometimes called string-matching algorithms, are an important class of algorithms that try to find a place where one or several strings (also called patterns) are found within a larger string or text. Given a pattern P of length m and a text T of length n, the task is to report all occurrences of P in T.

Basic approaches

The naive algorithm compares the pattern at every position of the text, taking O(nm) worst-case time. More efficient algorithms preprocess the pattern (or the text) to skip ahead on mismatches:

  • Knuth–Morris–Pratt (1977) uses a prefix function built from the pattern to achieve O(n + m) time.
  • Boyer–Moore (1977) compares the pattern from right to left and uses bad-character and good-suffix rules to make large jumps; it is often sublinear in practice and underlies the fast grep-like search in many tools.
  • Rabin–Karp uses rolling hash fingerprints, giving expected linear time.
  • Aho–Corasick finds many patterns simultaneously in a single pass, and is used in virus scanners and intrusion-detection systems.

Applications and variants

String searching is fundamental to text editors, search engines, compilers, bioinformatics sequence matching, and plagiarism detection. Variants of the problem include approximate string matching (allowing errors), regular expression matching, and compressed pattern matching on data stored in compressed form.
