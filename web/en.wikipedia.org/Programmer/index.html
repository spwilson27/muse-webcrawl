Programmer

From Wikipedia, the free encyclopedia


A programmer at work

A programmer, computer programmer or coder is an author of computer source code — someone with skill in computer programming. The professional titles software developer and software engineer are used for jobs that require a programmer, though they may encompass broader responsibilities including design, testing and project work.

History

Ada Lovelace is often credited as the first programmer for her 1843 notes on Charles Babbage's Analytical Engine, which included an algorithm for computing Bernoulli numbers. Programming became a distinct occupation with the electronic computers of the 1940s, when pioneers such as the ENIAC programmers — Kay McNulty, Betty Jennings, Betty Snyder, Marlyn Wescoff, Fran Bilas and Ruth Lichterman — developed methods of setting up problems for machine solution. Grace Hopper's work on compilers in the 1950s laid foundations for high-level programming languages.

Work

Programmers write, test, debug and maintain the source code of software in languages such as Python, Java, C, C++, JavaScript and many others. Their work involves translating requirements and designs into algorithms and code, reviewing colleagues' code, fixing defects, and collaborating with designers, analysts and users. Programming is central to industries from finance and medicine to entertainment and science, and employment in software roles has grown rapidly worldwide.
