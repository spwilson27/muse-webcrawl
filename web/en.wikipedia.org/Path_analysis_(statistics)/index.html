Path analysis (statistics)


A path diagram showing direct and indirect effects

Path analysis is a form of multiple regression statistical analysis used to evaluate causal models by examining the relationships between a dependent variable and two or more independent variables. Developed by geneticist Sewall Wright in the 1920s, it allows researchers to decompose correlations between variables into direct and indirect effects along specified paths.

Method

In a path model, variables are connected by arrows in a diagram: single-headed arrows represent hypothesized causal effects, while double-headed arrows represent unanalyzed correlations between exogenous variables. Each endogenous variable has an associated residual term representing unexplained variance. The standardized regression coefficients along each arrow are called path coefficients.

Using Wright's tracing rules, the correlation between any two variables can be expressed as the sum of products of path coefficients along all legitimate routes connecting them. This makes it possible to estimate how much of an effect is direct and how much is mediated through intervening variables.

Relation to other methods

Path analysis is a special case of structural equation modeling (SEM) in which all variables are directly observed rather than latent. It extends ordinary regression by permitting chains of dependent variables, so that a variable can be both a cause and an effect within the same model.

Limitations

Path analysis cannot by itself establish causation; the direction of arrows must be justified on theoretical grounds, and omitted variables or incorrect model specification can produce misleading estimates.
