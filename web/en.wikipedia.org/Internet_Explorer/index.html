Internet Explorer (formerly Microsoft Internet Explorer and Windows Internet Explorer, commonly abbreviated IE) is a discontinued series of graphical web browsers developed by Microsoft and included in the Microsoft Windows line of operating systems. First released in 1995 as part of the Plus! add-on for Windows 95, it grew out of source code licensed from Spyglass, Inc.'s Mosaic browser.

History

Internet Explorer became the dominant web browser after Microsoft bundled it free with Windows and, in the "browser wars" of the late 1990s, overtook Netscape Navigator. It reached a peak usage share of about 95% in 2002–2003, following the release of Internet Explorer 6 with Windows XP. Its dominance led to the United States v. Microsoft antitrust case, in which the bundling of IE with Windows was found to be an abuse of monopoly power.

Development stagnated after IE6, and renewed competition from Mozilla Firefox (2004) and Google Chrome (2008) drove a long decline. Later versions — IE7 with Windows Vista, IE9 with improved standards support, and IE11 in 2013 — improved performance and compliance but usage continued to fall.

Discontinuation

Microsoft announced Microsoft Edge as IE's successor in 2015, and Internet Explorer 11, the final version, was retired and went out of support on June 15, 2022. An "IE mode" in Edge preserves compatibility for legacy enterprise sites.
