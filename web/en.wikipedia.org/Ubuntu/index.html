Ubuntu

Ubuntu
OS family: Linux (Unix-like)
Developer: Canonical Ltd.
Initial release: October 20, 2004
Package manager: APT (dpkg), Snap

Ubuntu is a Linux distribution based on Debian and composed mostly of free and open-source software. It is developed by the British company Canonical and a community of other developers.

Releases

Ubuntu is released every six months, with long-term support (LTS) releases every two years supported for five years or more. Versions are named with an alliterative adjective and animal, such as "Jammy Jellyfish" (22.04 LTS).

Features

Ubuntu uses the GNOME desktop environment by default and targets desktop, server, cloud, and Internet of Things use. Official flavors include Kubuntu, Xubuntu, and Lubuntu.
