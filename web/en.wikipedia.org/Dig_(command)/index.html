Dig (command)

dig (Domain Information Groper) is a command-line tool for querying the Domain Name System (DNS). It is used for network troubleshooting and for verifying DNS configurations, returning detailed information about the query, the answer received, and the responding server.

Example output of a dig query for a domain's A records.

Usage

A basic lookup is performed with:

dig example.com

Options allow querying specific record types (dig example.com MX), directing the query to a particular server (dig @8.8.8.8 example.com), performing reverse lookups (dig -x 192.0.2.1), or requesting a short answer (dig +short example.com). The output is divided into header, question, answer, authority, and additional sections, along with query statistics.

History

dig was written by Steve Hotz and incorporated into the BIND name server distribution, distributed by the Internet Systems Consortium. It largely replaced the older nslookup tool as the preferred DNS diagnostic utility on Unix-like systems. On Windows, dig is not installed by default but is available with the BIND tools package.
