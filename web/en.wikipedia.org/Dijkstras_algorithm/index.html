Dijkstra's algorithm

Dijkstra's algorithm is an algorithm for finding the shortest paths between nodes in a weighted graph, which may represent, for example, a road network. It was conceived by Dutch computer scientist Edsger W. Dijkstra in 1956 and published three years later, in 1959.

The algorithm exists in many variants. Dijkstra's original finding was to find the shortest path between two given nodes, but a more common variant fixes a single node as the "source" node and finds shortest paths from the source to all other nodes in the graph, producing a shortest-path tree.

Algorithm

The algorithm maintains a set of unvisited nodes and tentative distances from the source, initialised to zero for the source and infinity for all others. At each step it selects the unvisited node with the smallest tentative distance, marks it visited, and relaxes all edges from it: if the path through the current node is shorter than the neighbour's tentative distance, the distance is updated. A priority queue is normally used to select the next node efficiently.

dist[source] = 0
for each vertex v: dist[v] = infinity, prev[v] = undefined
while unvisited nodes remain:
    u = unvisited node with smallest dist[u]
    mark u visited
    for each neighbour v of u:
        alt = dist[u] + length(u, v)
        if alt < dist[v]: dist[v] = alt, prev[v] = u

Complexity and uses

With a binary heap the algorithm runs in O((V + E) log V) time. It requires non-negative edge weights; graphs with negative edges require the Bellman–Ford algorithm instead. Dijkstra's algorithm underlies link-state routing protocols such as OSPF and IS-IS, and is widely used in mapping and navigation software to compute driving routes.
