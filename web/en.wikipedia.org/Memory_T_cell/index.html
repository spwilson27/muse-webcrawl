Memory T cell

Memory T cells are a subset of T lymphocytes that have previously encountered and responded to their cognate antigen; this experience is called immunological memory. After an infection resolves, antigen-specific T cells contract, but a population of long-lived memory cells persists, allowing a faster and stronger response upon re-encounter with the same pathogen.

Subsets

Memory T cells are classically divided into central memory (TCM) cells, which express CCR7 and CD62L and home to lymph nodes, and effector memory (TEM) cells, which circulate through peripheral tissues and provide immediate effector function. Further subsets include tissue-resident memory T cells (TRM), which remain permanently in tissues such as skin, gut, and lung, and stem-cell-like memory T cells (TSCM).

Formation and maintenance

Naive T cells activated by antigen-presenting cells expand clonally and differentiate into effectors; a minority survive as memory cells, maintained by homeostatic cytokines such as IL-7 and IL-15. Memory cells have a lower activation threshold and respond more rapidly than naive cells.

Importance

Together with memory B cells and long-lived plasma cells, memory T cells form the basis of protection conferred by vaccination and by prior infection.
