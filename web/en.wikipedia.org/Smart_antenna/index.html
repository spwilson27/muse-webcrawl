Smart antenna

Adaptive beamforming: a main lobe tracks the desired user while nulls suppress interference

Smart antennas (also known as adaptive array antennas, digital antenna arrays and multiple antennas) are antenna arrays with smart signal processing algorithms used to identify spatial signal signatures such as the direction of arrival (DOA) of a signal, and to use them to calculate beamforming vectors, which are used to track and locate the antenna beam on the mobile or target.

Techniques

Smart antenna techniques make use of the fact that multiple antenna elements sample the incoming wavefront at different points. By adjusting the phase and amplitude weights applied to each element, the array can steer a main beam toward a desired signal and place nulls in the directions of interfering signals. Two broad approaches exist: switched-beam systems, which select from a fixed set of pre-defined beam patterns, and adaptive array systems, which continuously optimise the weights using algorithms such as least mean squares (LMS) so the pattern follows the user and the interference environment.

Applications

Smart antennas are a key enabling technology for modern wireless systems. MIMO (multiple-input, multiple-output) communications, beamforming in Wi-Fi and cellular networks, and the massive MIMO arrays of 5G base stations all build on smart-antenna principles. Benefits include increased range and capacity, reduced multipath fading, lower transmit power, and improved quality of service through spatial division multiple access (SDMA), in which several users share the same frequency channel by being spatially separated.
