API unit

The API unit is the standard unit of measurement for natural gamma ray radioactivity in well logging, used throughout the petroleum industry. It is named after the American Petroleum Institute (API), which established the calibration standard on which the unit is based.

Definition

The unit is defined relative to a reference calibration facility originally built at the University of Houston in Texas: one API unit is 1/200 of the difference in measured radioactivity between two standard zones of the calibration pit, one of low radioactivity and one artificially enhanced with radioactive material. Gamma ray logs calibrated in this way can be compared quantitatively between different wells, tools, and service companies.

Typical values

Shales, which contain potassium-bearing clays and adsorbed uranium and thorium, typically read high on gamma ray logs, often between about 75 and 150 API units, whereas clean sandstones and carbonates commonly read in the range of roughly 10 to 30 API units. This contrast makes the gamma ray log a basic tool for distinguishing shale from reservoir rock and for estimating shale volume.
