Simple Mail Transfer Protocol

The Simple Mail Transfer Protocol (SMTP) is an Internet standard communication protocol for transmitting electronic mail. Defined by Jon Postel in 1982 and currently specified in RFC 5321, SMTP is used by mail servers to send and relay messages, while mail clients retrieve mail with protocols such as IMAP or POP3.

Operation

An SMTP session is a text-based dialogue: the client greets with EHLO, specifies sender and recipients with MAIL FROM and RCPT TO, and sends the message body after DATA. Servers relay messages between domains using DNS MX records. Extensions add authentication, encryption via STARTTLS, and size limits.

History and spam

SMTP was designed for a small, trusted network and originally had no authentication, which enabled widespread spam and spoofing. Countermeasures such as SPF, DKIM, and DMARC were layered on later, and port 587 with authentication became the standard path for message submission by end users.
