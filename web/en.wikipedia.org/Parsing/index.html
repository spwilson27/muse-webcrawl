Parsing

Parsing, or syntax analysis, is the process of analysing a string of symbols — in natural language or a formal language — and determining its grammatical structure according to a given grammar. A program or component that performs parsing is called a parser. The word derives from the Latin pars orationis, "part of speech".

In computer science

In computing, parsing is a core stage of compilers and interpreters. A lexical analyser (scanner) first converts source code into tokens; the parser then organises the tokens into a parse tree or abstract syntax tree (AST) reflecting the language's grammar, which later stages use for semantic analysis and code generation. Common strategies include top-down parsing (such as recursive descent and LL parsers) and bottom-up parsing (such as LR, LALR, and operator-precedence parsers). Parser generators like yacc, Bison, and ANTLR automate parser construction from grammar descriptions.

In linguistics

In psycholinguistics, parsing refers to how humans analyse sentences in real time. Classic experiments with "garden path" sentences — such as "The horse raced past the barn fell" — show that readers build structure incrementally and can be led into temporary misanalyses. In computational linguistics, parsing assigns syntactic structure to natural-language text and underpins tasks like machine translation and information extraction; modern systems often use statistical or neural models trained on treebanks.

Applications

Beyond compilers, parsers process markup (HTML, XML), data formats (JSON), query languages (SQL), configuration files, and network protocols.
