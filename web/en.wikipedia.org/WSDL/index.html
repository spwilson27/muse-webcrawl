Web Services Description Language

The Web Services Description Language (WSDL, pronounced "wiz-dull") is an XML-based interface description language used to describe the functionality offered by a web service. A WSDL description enumerates the operations a service supports, the messages it exchanges, and the data types involved, in a machine-readable form that tools can use to generate client code.

Structure

A WSDL 1.1 document is built from several elements: types (data type definitions, usually in XML Schema), messages (typed definitions of exchanged data), portTypes (sets of operations), bindings (protocol and format specifications, commonly SOAP over HTTP), and services (collections of endpoints, or ports). WSDL 2.0 renamed portType to interface and streamlined the model, though 1.1 remained more widely used in practice.

Use

Because the description is formal and machine-readable, development tools can generate client stubs and server skeletons automatically from a WSDL file, a workflow central to SOAP-based enterprise web services in the 2000s. WSDL documents are often paired with UDDI registries and WS-* specifications, though REST-style APIs described with OpenAPI later displaced much of WSDL's role in new systems.
