Rolling hash

A rolling hash (also called a recursive hash or rolling checksum) is a hash function designed so that the hash of a sliding window of input can be updated quickly when the window moves: values entering and leaving the window are added and removed in constant time, rather than recomputing the hash of the whole window.

Applications

The classic example is the Rabin–Karp string-search algorithm, which uses a rolling hash to compare a pattern against every substring of a text efficiently. Rolling checksums such as Adler-32 are used in the rsync algorithm to find matching blocks between two versions of a file. Rolling hashes also underlie content-defined chunking in deduplication and backup systems, including the Buzhash and Rabin fingerprint approaches.
