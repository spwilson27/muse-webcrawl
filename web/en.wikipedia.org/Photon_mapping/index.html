Photon mapping

In computer graphics, photon mapping is a two-pass global illumination rendering algorithm developed by Henrik Wann Jensen between 1995 and 2001 that approximately solves the rendering equation. It is able to simulate the effects of caustics, diffuse interreflection, and scattering in participating media such as smoke or water.

Algorithm

In the first pass, photons are traced from light sources into the scene and stored in a data structure called a photon map whenever they strike a surface. Separate photon maps are typically built for caustics (photons focused through specular surfaces) and for general global illumination. In the second pass, the scene is rendered using ray tracing, and the photon map is queried to estimate the radiance at each visible point by gathering nearby photons.

Photon mapping is a "biased" rendering algorithm: the result is not exact, but converges to the correct solution as the number of photons increases. Because photons are stored and reused, the method is particularly efficient for effects like caustics, which are difficult for pure path tracing, but the density estimation can produce blurring and light leaking artefacts if parameters are poorly chosen.

Variants and legacy

Extensions include progressive photon mapping, which progressively refines the estimate over many iterations, and vertex connection and merging, which combines photon mapping with bidirectional path tracing. Photon mapping has been implemented in renderers such as Mental Ray and was widely used in production rendering before unbiased methods became faster.
