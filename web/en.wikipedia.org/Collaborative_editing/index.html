Collaborative editing

Collaborative editing is the process of multiple people editing the same document, file, or work simultaneously or asynchronously. It ranges from traditional workflows in which editors pass drafts between one another, to real-time collaborative editing, in which several users type in a shared document at once and see each other's changes immediately.

History

Early systems such as Engelbart's NLS demonstrated shared editing in the 1960s, and groupware research produced editors like GROVE in the 1980s. Wikis, beginning with WikiWikiWeb in 1995, popularized asynchronous many-author editing on the web. Real-time tools became mainstream with products such as Google Docs (from Writely, 2006) and later collaborative features in office suites, design tools, and code editors.

Technology

Real-time systems must merge concurrent edits without conflicts. Two main families of algorithms are used: operational transformation, which transforms operations against one another, and CRDTs (conflict-free replicated data types), which guarantee convergence through commutative data structures. Presence indicators, comments, suggestion modes, and version history are standard supporting features.

Uses

Collaborative editing underpins Wikipedia, shared office documents, pair programming, and collaborative design. Research shows it can improve quality through rapid feedback but requires norms to manage edit conflicts and authorship questions.
