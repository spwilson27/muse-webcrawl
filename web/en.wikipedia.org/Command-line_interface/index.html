Command-line interface

A command-line interface (CLI) is a means of interacting with a computer program by typing lines of text commands, which the program reads, executes and answers with text output. CLIs are implemented by a command-line interpreter or shell, such as Bash and PowerShell, and are run in a terminal window or console. Before graphical user interfaces became standard in the 1980s, the command line was the primary interface to most operating systems.

How it works

The user types a command at a prompt, typically consisting of a program name followed by arguments and options (flags), for example ls -la /home. The interpreter locates and runs the program, connecting its standard input, output and error streams to the terminal. Features such as piping and redirection (|, >), wildcards, variables, command history and tab completion make CLIs powerful for composing programs and automating tasks through shell scripts.

History

Command lines descend from teleprinter interaction with early computers in the 1960s, through systems such as Multics and Unix, whose shells established much of today's CLI vocabulary, and MS-DOS's COMMAND.COM on personal computers. Although consumer computing is dominated by graphical interfaces, CLIs remain standard for system administration, software development, servers, networking equipment and embedded systems, where they offer precision, scriptability and low resource use.

Comparison with GUIs

CLIs require users to recall command names and syntax but reward expertise with speed, repeatability and remote operation over text-only connections such as SSH. Many modern tools provide both interfaces, and terminal emulators are built into all major desktop operating systems.
