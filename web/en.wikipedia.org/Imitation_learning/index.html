Imitation learning

Imitation learning is a paradigm in machine learning in which an agent learns to perform a task by observing and mimicking the behaviour of an expert, rather than by trial-and-error exploration guided by a reward signal, as in reinforcement learning. It is widely used in robotics and autonomous driving, where demonstrations by humans are easier to obtain than well-specified reward functions.

Approaches

The simplest approach, behaviour cloning, treats the problem as supervised learning: the policy is trained to reproduce the expert's action for each observed state. Behaviour cloning suffers from compounding errors, since small deviations carry the agent into states the expert never visited. Interactive methods such as DAgger (Dataset Aggregation) address this by repeatedly querying the expert on states visited by the learner. Inverse reinforcement learning instead infers a reward function under which the expert's behaviour is optimal, and then optimises that reward. Adversarial methods such as GAIL frame imitation as a game between a policy and a discriminator that distinguishes learner from expert trajectories.

Applications

Imitation learning has been applied to robot manipulation, helicopter aerobatics, game playing, natural language generation, and learning driving policies from human drivers. It is closely related to learning from demonstration and apprenticeship learning in the robotics literature.
