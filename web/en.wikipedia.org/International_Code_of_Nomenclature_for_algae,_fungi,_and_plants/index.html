International Code of Nomenclature for algae, fungi, and plants

The International Code of Nomenclature for algae, fungi, and plants (ICN or ICNafp) is the set of rules and recommendations governing the scientific names of organisms traditionally treated as algae, fungi, or plants. It was formerly called the International Code of Botanical Nomenclature (ICBN); the name was changed at the Eighteenth International Botanical Congress in Melbourne in July 2011 as part of the Melbourne Code, which replaced the Vienna Code of 2005. The most recent edition is the Shenzhen Code, adopted at the Nineteenth International Botanical Congress in Shenzhen, China, in 2017 and published in 2018.

The ICN applies not only to plants, as defined by the code, but also to other organisms traditionally studied by botanists, including cyanobacteria, fungi (including chytrids, oomycetes and slime moulds), and photosynthetic protists and their taxonomic relatives. It is independent of the zoological code, the International Code of Zoological Nomenclature, so the same generic name can exist in both botany and zoology.

Principles

The Code is founded on six principles: botanical nomenclature is independent of zoological nomenclature; the application of names is determined by nomenclatural types; nomenclature is based on priority of publication; each taxon can bear only one correct name, the earliest in accordance with the rules, except in specified cases; scientific names are treated as Latin regardless of their derivation; and the rules are retroactive unless expressly limited.

Changes in the Melbourne and Shenzhen Codes

The Melbourne Code introduced significant changes: descriptions or diagnoses of new taxa could be published in English as well as Latin from 1 January 2012; electronic publication in PDF format became acceptable; and for fungi, names published from 2013 onwards required an identifier from a recognized repository such as MycoBank. The "one fungus, one name" reform abolished the separate naming of different morphs of the same fungus. The Shenzhen Code made registration of fungal names mandatory for valid publication in some cases and introduced provisions on binding decisions regarding names and descriptions.

Governance

The Code can only be changed by an International Botanical Congress, held every six years. Between congresses, editorial committees prepare each new edition. Proposals to conserve or reject names are published in the journal Taxon and decided by standing committees.
