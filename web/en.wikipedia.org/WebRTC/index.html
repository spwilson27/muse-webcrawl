WebRTC

WebRTC (Web Real-Time Communication) is a free and open-source project providing web browsers and mobile applications with real-time communication via application programming interfaces. It allows audio and video communication and arbitrary data transfer to work inside web pages by enabling direct peer-to-peer communication, eliminating the need to install plugins or download native apps.

Technology

WebRTC's core components include getUserMedia for access to camera and microphone, RTCPeerConnection for encrypted audio/video calls, and RTCDataChannel for generic peer-to-peer data. Connections are established with the help of a signaling channel chosen by the developer, and NAT traversal uses the ICE framework with STUN and TURN servers. Media is secured with DTLS and SRTP. Standard codecs include Opus and G.711 for audio and VP8, VP9, AV1, and H.264 for video.

History

Google released the technology as open source in 2011, building on its acquisition of Global IP Solutions and On2 Technologies. The W3C and IETF standardized the APIs and protocols over the following decade; the W3C Recommendation for WebRTC 1.0 was published in January 2021. All major browsers now support WebRTC.

Applications

WebRTC underlies browser-based video conferencing such as Google Meet and Discord's web client, telehealth platforms, live streaming, cloud gaming, and peer-to-peer file sharing. During the COVID-19 pandemic it became a standard foundation for remote communication tools.
