Response element

A response element is a short sequence of DNA within a gene promoter to which specific transcription factors bind, regulating the expression of genes in response to a particular signal, such as a hormone.

Examples

Well-known response elements include hormone response elements (HREs) bound by nuclear receptors — such as the glucocorticoid response element (GRE), estrogen response element (ERE), and thyroid hormone response element (TRE) — as well as the cAMP response element (CRE), bound by CREB, the serum response element (SRE), and the hypoxia response element (HRE) bound by HIF-1.

Structure

Many response elements are palindromic or direct-repeat sequences, reflecting the fact that nuclear receptors often bind as dimers. The spacing and orientation of the half-sites determine which receptor binds and how the gene is regulated.
