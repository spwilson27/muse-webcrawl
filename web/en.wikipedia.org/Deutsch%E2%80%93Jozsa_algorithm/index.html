The Deutsch–Jozsa algorithm is a deterministic quantum algorithm proposed by David Deutsch and Richard Jozsa in 1992. It was one of the first examples of a quantum algorithm that is exponentially faster than any possible deterministic classical algorithm, and it extended Deutsch's earlier single-bit algorithm of 1985.

The problem

The algorithm solves a black-box problem: given an oracle that implements a Boolean function promised to be either constant (the same output for all inputs) or balanced (output 1 for exactly half the inputs and 0 for the other half), determine which it is. A deterministic classical computer may need as many as 2n−1 + 1 evaluations of the function in the worst case; the quantum algorithm needs exactly one.

How it works

The algorithm places the input register in a uniform superposition of all inputs, queries the oracle once so that the answer is encoded in the phases of the superposition (phase kickback), and then applies Hadamard transforms and a measurement. If the function is constant, the measurement yields all zeros with certainty; if balanced, it yields some nonzero string—giving an exact answer from a single oracle call.

Significance

Although the problem it solves is artificial, the algorithm was historically important: it demonstrated that a quantum computer could outperform classical machines on a well-defined task and introduced techniques that later fed into Simon's algorithm and Shor's algorithm.
