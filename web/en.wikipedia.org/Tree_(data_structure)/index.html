Tree (data structure)

[Image placeholder: tree diagram]

In computer science, a tree is a widely used abstract data type representing a hierarchical structure with a set of connected nodes. Each node in the tree can be connected to many children (depending on the type of tree), but must be connected to exactly one parent, except for the root node, which has no parent. Trees are a special case of graphs with no cycles, and they underpin many fundamental algorithms and data representations.

Terminology

  • Root: the topmost node, from which all others descend.
  • Parent, child, siblings: a node's immediate ancestor, its immediate descendants, and nodes sharing a parent.
  • Leaf (external node): a node with no children.
  • Internal node: a node with at least one child.
  • Depth of a node: the number of edges from the root to that node.
  • Height of the tree: the number of edges on the longest path from the root to a leaf.
  • Subtree: a node together with all its descendants.
  • Degree: the number of children of a node.

Common types

  • Binary tree: each node has at most two children, termed left and right.
  • Binary search tree (BST): a binary tree ordered so that keys in the left subtree are smaller and keys in the right subtree are larger than the node's key, permitting efficient search, insertion, and deletion.
  • Self-balancing trees, such as AVL trees and red–black trees, keep height logarithmic by restructuring on updates.
  • B-trees: generalized search trees used in databases and filesystems.
  • Heap: a tree satisfying the heap property, commonly used for priority queues and heapsort.
  • Trie: a tree for storing strings, keyed by characters along paths.
  • Syntax tree: represents the structure of expressions or programs in compilers.

Traversal

Tree traversal visits every node in a systematic order. Depth-first strategies include pre-order, in-order, and post-order traversals; breadth-first (level-order) traversal uses a queue. In-order traversal of a binary search tree visits keys in sorted order.

Applications

Trees model file systems, document object models (DOM), XML and HTML structure, organizational charts, decision trees in machine learning, game trees in artificial intelligence, and parsing in compilers. They are among the most fundamental structures in computing.
