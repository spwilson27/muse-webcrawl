Complexity class

In computational complexity theory, a complexity class is a set of computational problems of related resource-based complexity, typically time or space used by an algorithm on an abstract machine such as a Turing machine.

Major classes

Well-known classes include P, problems solvable in polynomial time; NP, problems whose solutions can be verified in polynomial time; PSPACE; and EXPTIME. The relationships among these classes are among the central questions of theoretical computer science.

The P versus NP problem

Whether P equals NP is a Millennium Prize Problem. Most researchers believe the classes differ, but no proof is known. Complexity classes are organized into hierarchies studied through reductions and completeness.
