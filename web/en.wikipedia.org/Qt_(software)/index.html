Qt (software)

Qt (pronounced "cute") is a free and open-source cross-platform software library for creating graphical user interfaces as well as cross-platform applications that run on various software and hardware platforms such as Linux, Windows, macOS, Android and embedded systems with little or no change in the underlying codebase while still being a native application with native capabilities and speed.

Qt is developed by the Qt Group in cooperation with the Qt Project community. It is available under both commercial licenses and the open-source GNU Lesser General Public License. Qt is written in C++ and provides bindings for other languages; its declarative UI language QML and the Qt Quick framework are widely used for touch interfaces and embedded devices.

History

Qt was begun in 1990 by Eirik Chambe-Eng and Haavard Nord, who founded Trolltech in 1994. The toolkit gained prominence as the foundation of the KDE desktop environment. Nokia acquired Trolltech in 2008, and after Nokia's mobile business declined, the Qt business was sold to Digia in 2012; the Qt Company was later spun out and listed publicly. Major releases include Qt 4 (2005), Qt 5 (2012) and Qt 6 (2020).

Components

The framework includes modules for GUI widgets (Qt Widgets), declarative UI (Qt Quick/QML), networking, SQL databases, XML, multimedia and WebEngine browser integration. Tools include the Qt Creator IDE, Qt Designer for visual form design, and the qmake and CMake build integrations. Code written with Qt uses a signals-and-slots mechanism for event communication and a meta-object compiler (moc) that extends C++.
