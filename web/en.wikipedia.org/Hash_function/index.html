Hash function

A hash function is any function that can be used to map data of arbitrary size to fixed-size values. The values returned by a hash function are called hash values, hash codes, digests, or simply hashes. Hash functions are used in data structures such as hash tables to rapidly locate data, and, in specialised cryptographic forms, for integrity checking, password storage, and digital signatures.

Properties

A good non-cryptographic hash function is deterministic, fast to compute, and distributes inputs roughly uniformly over the output range so as to minimise collisions — cases in which two different inputs produce the same hash. Because the output space is smaller than the input space, collisions are inevitable (by the pigeonhole principle), so systems using hashes must handle them, e.g. by chaining or open addressing in hash tables.

Applications

  • Hash tables and databases: indexing keys for average constant-time insertion and lookup.
  • Checksums and data integrity: detecting accidental corruption of files and messages.
  • Caching and deduplication: identifying identical data blocks, as in content-addressed storage and version control (Git).
  • Cryptography: cryptographic hash functions such as SHA-256 additionally provide preimage resistance, second-preimage resistance, and collision resistance, enabling digital signatures, message authentication, password hashing (with salted, slow constructions such as bcrypt), and proof-of-work in cryptocurrencies.

Algorithms

Simple hash functions include modular arithmetic on integer keys, multiplicative hashing, and polynomial rolling hashes used for string searching. Historical cryptographic hashes include MD5 (now considered broken for collision resistance) and SHA-1 (likewise deprecated after practical collision attacks), superseded by the SHA-2 and SHA-3 families.
