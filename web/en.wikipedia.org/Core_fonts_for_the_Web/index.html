Core fonts for the Web

Core fonts for the Web was a project started by Microsoft in 1996 to create a standard pack of fonts for the World Wide Web. It included the proprietary fonts Andalé Mono, Arial, Arial Black, Comic Sans MS, Courier New, Georgia, Impact, Times New Roman, Trebuchet MS, Verdana and Webdings, distributed in self-extracting executables for Microsoft Windows and in BinHexed Stuff-It files for Macintosh. The fonts were provided free of charge under an end-user license agreement that allowed redistribution so long as the packages were kept intact with their original names.

Purpose

The project aimed to give web designers a reliable palette of typefaces that would be present on most users' machines, so pages would render as intended across platforms. The fonts were designed or adapted for on-screen legibility: Verdana and Georgia, designed by Matthew Carter and hinted by Tom Rickner, were created specifically for screen reading, with large x-heights and generous spacing.

Distribution and termination

The fonts shipped with Internet Explorer, Windows, and Microsoft Office, and were also included with Mac OS. Microsoft terminated the downloadable distribution in 2002, though the fonts remain widely installed because of their bundling with operating systems, and the license terms continue to permit the original packages to be redistributed; they are commonly installed on Linux systems via the ttf-mscorefonts-installer package, which downloads the original archives.

Influence

Because of their ubiquity, the core fonts became de facto web standards, and their names still appear at the head of CSS font stacks. The initiative also influenced later efforts to standardize web typography, culminating in downloadable web fonts via @font-face.
