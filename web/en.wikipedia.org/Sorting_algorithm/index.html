Sorting algorithm

FieldComputer science, algorithmics
TaskArrange elements of a list in a defined order
Lower bound (comparisons)Ω(n log n)
Well-known examplesQuicksort, merge sort, heapsort, insertion sort

In computer science, a sorting algorithm is an algorithm that puts elements of a list into an order, most frequently numerical or lexicographical order. Sorting is fundamental to computing: it is a preprocessing step for searching, a component of database operations, and one of the most intensively studied problems in algorithm design. Efficient sorting was among the earliest problems addressed in the field, going back to the era of punched-card tabulating machines.

Properties

Algorithms are compared by time complexity (worst, average and best case), space complexity, and stability — whether equal elements retain their original relative order. "In-place" algorithms sort using only constant extra memory. No comparison-based sort can beat an average of Ω(n log n) comparisons, a bound attained by merge sort and heapsort; non-comparison sorts such as radix sort and counting sort can run in linear time under assumptions about the data.

Common algorithms

Quicksort partitions around a pivot and is fastest in practice on average (O(n log n)), though with an O(n²) worst case. Merge sort divides the list, sorts recursively and merges; it is stable and guarantees O(n log n). Heapsort uses a binary heap. Simple quadratic algorithms — insertion sort, selection sort and bubble sort — remain useful for small or nearly sorted inputs. Modern libraries often use hybrids such as Timsort (Python, Java) and introsort (C++).
