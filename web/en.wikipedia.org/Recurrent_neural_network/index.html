Recurrent neural network

A recurrent neural network (RNN) is a class of artificial neural networks designed for processing sequential data, in which connections between nodes can form cycles, allowing information to persist as a form of memory. RNNs are widely used in speech recognition, language modelling, translation and time-series prediction.

Architecture

Unlike feedforward networks, an RNN maintains a hidden state that is updated at each time step as a function of the current input and the previous state. Training uses backpropagation through time. Standard RNNs suffer from vanishing and exploding gradients, which motivated gated architectures such as long short-term memory (LSTM), introduced by Hochreiter and Schmidhuber in 1997, and the gated recurrent unit (GRU).

Applications and successors

RNNs powered major advances in handwriting and speech recognition in the 2010s. Since 2017, attention-based transformer models have largely superseded them for large-scale language tasks, though recurrent designs remain useful for streaming and low-latency applications.
