Apache HTTP Server

From Wikipedia, the free encyclopedia


The Apache HTTP Server logo

The Apache HTTP Server is a free and open-source cross-platform web server software, released under the terms of Apache License 2.0. It is developed and maintained by a community of developers under the auspices of the Apache Software Foundation.

The vast majority of Apache HTTP Server instances run on a Linux distribution, but current versions also run on Microsoft Windows, OpenVMS, and a wide variety of Unix-like systems. Past versions also ran on NetWare, OS/2 and other operating systems.

History

The Apache project began in 1995 when a group of webmasters began exchanging patches for the then-popular NCSA HTTPd server — a "patchy" server, as the project's name is commonly explained. Apache 1.0 was released in December 1995, and within a year it became the most popular web server on the internet. The Apache Software Foundation was formed in 1999 to provide organisational and legal support for the project and its growing family of software.

The heavily reworked Apache 2.0 was released in 2002, and version 2.4 followed in 2012. Apache long held the largest share of websites worldwide, though in recent years nginx has overtaken it in many surveys of the busiest sites, while Apache remains one of the most widely deployed servers overall.

Features

Apache features configurable, modular architecture: dynamically loadable modules add support for server-side languages such as PHP (mod_php), virtual hosting, URL rewriting (mod_rewrite), SSL/TLS (mod_ssl), proxying, caching, authentication, and per-directory configuration through .htaccess files. Its multi-processing module (MPM) design allows different process and threading models, including the event MPM.
