Fuzzy control system

From Wikipedia, the free encyclopedia

A fuzzy control system is a control system based on fuzzy logic — a mathematical framework for analysing analogue input values in terms of logical variables that take continuous values between 0 and 1, in contrast to classical Boolean logic's 0 or 1. Instead of a precise mathematical model of the plant, a fuzzy controller encodes the heuristic knowledge of human operators as linguistic rules such as "if the room is quite cold, then heat strongly".

Structure

A fuzzy controller works in three stages. Fuzzification maps crisp sensor inputs into degrees of membership in linguistic sets (e.g. "cold", "warm", "hot"). The inference engine applies a rule base of IF–THEN rules — commonly of the Mamdani or Takagi–Sugeno type — combining antecedents with fuzzy operators. Defuzzification converts the resulting fuzzy output into a single crisp control action, typically by the centroid method.

History and applications

Fuzzy logic was introduced by Lotfi Zadeh in 1965; Ebrahim Mamdani built the first fuzzy controller (for a steam engine) in 1974. The approach achieved commercial fame in Japan in the 1980s and 1990s — notably in the Sendai subway's automatic train operation, washing machines, camcorders and air conditioners — and is now used in anti-lock braking, elevator control, cement kilns and many consumer appliances. Its appeal lies in handling nonlinear systems and imprecise inputs without an exact model, though critics note that tuning rule bases can be unprincipled compared with classical control design.
