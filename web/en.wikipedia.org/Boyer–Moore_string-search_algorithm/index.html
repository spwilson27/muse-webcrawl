Boyer–Moore string-search algorithm

ClassString-search algorithm
InventorsRobert S. Boyer, J Strother Moore
Published1977
Worst caseO(nm) (with Galil rule: O(n))

The Boyer–Moore string-search algorithm is an efficient algorithm for finding occurrences of a pattern string within a larger text, developed by Robert S. Boyer and J Strother Moore in 1977. It is a standard benchmark for practical string-searching and underlies the search functions of many text editors.

How it works

Unlike naive algorithms, Boyer–Moore compares the pattern against the text from right to left. On a mismatch it uses two precomputed heuristics — the bad-character rule, which shifts the pattern so the mismatched text character aligns with its last occurrence in the pattern, and the good-suffix rule, which shifts based on the matched suffix — and takes the larger of the two shifts.

Performance

Because it can skip large portions of the text, the algorithm often inspects only a fraction of the characters, giving sublinear performance in typical cases: roughly n/m comparisons for a text of length n and pattern of length m. The longer the pattern, the faster it tends to run, the opposite behaviour of many other search algorithms.
