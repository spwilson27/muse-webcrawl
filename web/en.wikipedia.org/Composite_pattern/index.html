Composite pattern

In software engineering, the composite pattern is a structural design pattern that composes objects into tree structures to represent part-whole hierarchies, letting clients treat individual objects and compositions uniformly.

Structure

The pattern defines a common component interface, leaf objects with no children, and composite objects that store and delegate to child components. File systems and graphical user interface widget trees are classic examples.

Use

Composites simplify client code when a group of objects should be handled the same way as a single object, at the cost of making it harder to restrict the types of components allowed in the tree.
