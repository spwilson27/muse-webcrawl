constexpr

constexpr is a keyword in the C++ programming language, introduced in C++11, that declares that the value of a variable or the return value of a function is a constant expression capable of being evaluated at compile time. It is a central feature of modern C++ compile-time computation and metaprogramming.

Semantics

A constexpr variable must be initialized with a constant expression and is implicitly const. A constexpr function may be evaluated at compile time when called with constant-expression arguments — for example in array sizes or template arguments — but can also be called at run time with ordinary arguments, in which case it behaves like a normal function. In C++11 such functions were restricted to a single return statement; C++14 relaxed this to permit loops, local variables, and most ordinary statements. Later standards extended compile-time evaluation further: C++17 added if constexpr for compile-time conditional compilation; C++20 added consteval (functions guaranteed to be evaluated only at compile time), constinit, and virtual functions and dynamic allocation in constant expressions; C++23 continued the expansion.

Uses

Compile-time evaluation lets programs compute lookup tables, parse data, and validate constants before the program ever runs, improving performance and catching errors earlier. Libraries use constexpr throughout modern C++: much of the standard library (containers, algorithms, string views, chrono) has become usable in constant expressions in recent standards.
