Polynomial ring

From Wikipedia, the free encyclopedia

A polynomial in one indeterminate

In mathematics, especially in abstract algebra, a polynomial ring is a ring formed from the set of polynomials in one or more indeterminates (traditionally also called variables) with coefficients in another ring, often a field. Polynomial rings are central to ring theory, algebraic geometry and many other areas.

Definition

Given a ring R, the polynomial ring R[X] in the indeterminate X consists of all formal expressions

p = amXm + am−1Xm−1 + … + a1X + a0

where the coefficients ai lie in R and only finitely many are non-zero. Addition and multiplication are defined in the natural way, treating X as a formal symbol that commutes with coefficients. Multivariate polynomial rings R[X1, …, Xn] are obtained by adjoining several indeterminates, equivalently by iterating the one-variable construction.

Properties

If R is commutative, so is R[X]; if R is an integral domain, so is R[X]. When K is a field, K[X] is a Euclidean domain (via polynomial long division), hence a principal ideal domain and a unique factorisation domain. Hilbert's basis theorem states that if R is Noetherian, then R[X] is Noetherian — so polynomial rings in finitely many variables over a field have finitely generated ideals, a fact of fundamental importance in algebraic geometry, where ideals of polynomial rings correspond to algebraic varieties.

Evaluation

Substituting a value a ∈ R for X gives the evaluation homomorphism R[X] → R, associating to each polynomial the corresponding polynomial function. A value at which the polynomial vanishes is a root; over an algebraically closed field every non-constant polynomial factors completely into linear factors.
