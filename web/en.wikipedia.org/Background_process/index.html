Background process

A background process is a computer process that runs behind the scenes, without direct interaction from the user, as opposed to a foreground process that occupies the user's terminal or screen. Background processes are used for tasks that do not require supervision, such as rendering, indexing, printing, and long-running system services.

Background process
Field: Operating systems
Unix tools: &, nohup, disown, jobs, bg, fg
Long-running form: Daemon / Windows service

Unix and Linux

In Unix-like systems, a command can be started in the background by appending an ampersand (&) to the command line. Job control commands — jobs, bg, and fg — list background jobs and move them between background and foreground. The nohup command and the shell builtin disown allow a background process to keep running after the user logs out. A background process that runs continuously to provide a service is typically called a daemon.

Other systems

On Windows, comparable functionality is provided by services, which run independently of any logged-on user, and by background tasks in modern application frameworks. Mobile operating systems restrict background processing to save battery power, allowing apps only limited scheduled background work.
