Pseudorandom binary sequence

A pseudorandom binary sequence (PRBS) is a binary sequence that, although generated with a deterministic algorithm, is difficult to predict and exhibits statistical behaviour similar to a truly random sequence. PRBS generators are used in telecommunications, encryption, simulation, and measurement applications.

Generation

PRBS sequences are typically generated by linear-feedback shift registers (LFSRs), which produce maximal-length sequences (m-sequences) with a period of 2n − 1 bits for an n-bit register, provided the feedback polynomial is primitive. Common standard sequences include PRBS7, PRBS15, PRBS23, and PRBS31.

Properties and applications

A PRBS has a nearly flat spectrum resembling white noise and a sharp autocorrelation peak, which makes it useful for bit-error-rate testing of data links, channel sounding, system identification, and spread-spectrum communications. Because the sequence is deterministic and repeats, it is not suitable by itself for cryptographic security, though it underlies some stream-cipher designs.
