Virtual LAN

A virtual local area network (VLAN) is any broadcast domain that is partitioned and isolated in a computer network at the data link layer (OSI layer 2). In this context, virtual refers to a physical object recreated and altered by additional logic, within the local area network. Basically, a VLAN divides a network into separate groups that do not communicate directly, improving network performance and security.

Uses

Network architects set up VLANs to provide segmentation services traditionally provided only by routers in LAN configurations. VLANs address issues such as scalability, security, and network management: broadcast traffic is contained within a VLAN, devices in different VLANs cannot communicate without a layer-3 device, and administrators can group users logically — for example by department or security level — rather than by physical location.

Implementation

The dominant standard for VLAN tagging is IEEE 802.1Q, which inserts a 4-byte tag, including a 12-bit VLAN identifier, into the Ethernet frame header, allowing up to 4,094 VLANs. Ports on a managed switch are assigned to VLANs; a port carrying multiple VLANs is configured as a trunk. Inter-VLAN routing is performed by a router or a layer-3 switch. Alternatives and complements include VXLAN, which extends the identifier space for large data-centre networks.

History

VLANs were developed in the 1990s as switched Ethernet replaced shared hubs; W. David Sincoskie and others described early virtual LAN designs. IEEE 802.1Q was standardised in 1998.
