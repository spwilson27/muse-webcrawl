Tree traversal

In computer science, tree traversal (also known as tree search or tree walking) is a form of graph traversal and refers to the process of visiting, retrieving, updating or deleting each node in a tree data structure, exactly once. Such traversals are classified by the order in which the nodes are visited.

Depth-first search

Depth-first traversals explore as far down a branch as possible before backtracking. For a binary tree, three standard orders are defined by when the root is visited relative to its children:

  • Pre-order (root, left, right): the root is visited first; pre-order traversal of an expression tree yields prefix notation.
  • In-order (left, root, right): applied to a binary search tree, this visits keys in sorted order; it yields infix notation.
  • Post-order (left, right, root): children are visited before their parent; used for deleting a tree and for evaluating expressions in postfix notation.

These traversals are naturally implemented recursively, or iteratively with an explicit stack.

Breadth-first search

Breadth-first traversal, or level order, visits nodes level by level from the root downward, left to right within each level. It is typically implemented with a queue and is used, for example, to find shortest paths in unweighted trees.

Applications

Traversal underlies parsing and expression evaluation, file-system walks, document object model processing, and search algorithms. General graph traversal algorithms such as depth-first search and breadth-first search reduce to tree traversal when applied to trees.
