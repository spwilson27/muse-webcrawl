Simple Mail Transfer Protocol

The Simple Mail Transfer Protocol (SMTP) is an Internet standard communication protocol for electronic mail transmission. Mail servers and other message transfer agents use SMTP to send and receive mail messages. User-level email clients typically use SMTP only for sending messages to a mail server for relaying, and submit outgoing email to the mail server on port 587 or 465 per RFC 8314. Retrieval of messages is usually done with protocols such as IMAP or POP.

History

SMTP grew out of earlier mail delivery systems on the ARPANET in the 1970s. It was first defined by Jon Postel in RFC 788 in November 1981 and updated in RFC 821 (1982). SMTP was widely used by the mid-1980s, and the current specification is RFC 5321 (2008). Extensions, known collectively as Extended SMTP (ESMTP), add capabilities such as the EHLO greeting, message size declaration, and STARTTLS encryption.

Protocol overview

SMTP is a connection-oriented, text-based protocol in which a mail sender communicates with a mail receiver by issuing command strings and supplying necessary data over a reliable ordered data stream, typically a TCP connection on port 25. Commands include HELO/EHLO, MAIL FROM, RCPT TO, and DATA. An SMTP session may include zero or more transactions, and servers reply with numeric codes such as 250 (OK) and 354 (start mail input).

Security and anti-spam measures

The original SMTP design had no authentication, which spammers exploited through open relays. Modern deployments use SMTP Authentication, and validation frameworks such as SPF, DKIM, and DMARC to verify sender identity.
