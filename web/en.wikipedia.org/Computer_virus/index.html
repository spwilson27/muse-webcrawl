Computer virus

A computer virus is a type of malware that, when executed, replicates itself by modifying other computer programs and inserting its own code into them. When this replication succeeds, the affected areas are said to be "infected". Viruses require a host program and usually some form of user action, such as opening an infected file, in order to spread.

History

The theoretical foundations were laid by John von Neumann's work on self-reproducing automata. Early practical examples included Creeper (1971), an experimental self-replicating program on the ARPANET, and Elk Cloner (1982), which spread among Apple II systems via floppy disks. The Brain virus (1986) was the first widespread virus for IBM PC compatibles.

Behaviour and payloads

Viruses may attach to executable files, boot sectors, or documents containing macros. Beyond replication, many carry payloads that delete files, corrupt data, display messages, or steal information, though some are merely pranks. Viruses differ from computer worms, which spread by themselves across networks without a host file or user action.

Countermeasures

Antivirus software detects viruses using signature databases, heuristics, and behavioural monitoring. Other defences include keeping software patched, restricting macros, using least-privilege accounts, and maintaining backups.
