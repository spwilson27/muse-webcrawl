Partition of a set

In mathematics, a partition of a set is a grouping of its elements into non-empty subsets, in such a way that every element is included in exactly one subset. Every equivalence relation on a set defines a partition of the set, and every partition defines an equivalence relation, whose equivalence classes are exactly the blocks of the partition.

A set partitioned into five blocks.

Definition

A partition of a set X is a set of non-empty subsets of X such that every element x in X is in exactly one of these subsets. Equivalently, a family of sets P is a partition of X if and only if no block is empty, distinct blocks are pairwise disjoint, and the union of all blocks equals X. The sets in P are called the blocks, parts, or cells of the partition.

Counting partitions

The number of partitions of a finite set of n elements is given by the Bell numbers: 1, 1, 2, 5, 15, 52, 203, ... for n = 0, 1, 2, 3, .... The number of partitions of an n-element set into exactly k non-empty subsets is given by the Stirling numbers of the second kind. Partitions of a set form a lattice under refinement, a structure of importance in combinatorics and in the theory of equivalence relations.

Applications

Partitions appear throughout mathematics and computer science: in probability, where a partition of the sample space underlies the law of total probability; in group theory, where cosets partition a group; in graph theory, where vertex colourings are partitions; and in data analysis, where clustering algorithms partition data points into groups.
