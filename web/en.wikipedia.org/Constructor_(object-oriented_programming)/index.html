Constructor (object-oriented programming)

In class-based object-oriented programming, a constructor (abbreviation: ctor) is a special type of subroutine called to create an object. It prepares the new object for use, often accepting arguments that the constructor uses to set required member variables.

Types

A constructor resembles an instance method but usually has no explicit return type, is not inherited, and differs in its role from ordinary methods. Common kinds include the default constructor (taking no arguments), parameterized constructors, copy constructors (which initialize an object from another object of the same class), and conversion constructors. In C++, if a class has no user-declared constructor, the compiler generates a default one; in Java, a constructor has the same name as the class.

Related concepts

Constructors are paired in some languages with destructors, which free an object's resources at the end of its life. Languages also vary in whether constructors can be overloaded, whether they can be virtual (generally not), and how initialization lists and delegation between constructors are expressed.
