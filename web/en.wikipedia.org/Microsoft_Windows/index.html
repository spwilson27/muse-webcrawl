Microsoft Windows is a product line of proprietary graphical operating systems developed and marketed by Microsoft. It is grouped into families, each of which caters to a certain sector of the computing industry — principally personal computers, servers and embedded systems. Windows is the world's most widely used desktop operating system.

History

Windows began in 1985 as a graphical shell for MS-DOS. Windows 3.0 (1990) achieved broad commercial success, and Windows 95 unified the consumer line with the Start menu, taskbar and plug-and-play support. The professional NT line, launched with Windows NT 3.1 (1993), provided a separate 32-bit kernel; the two lines converged with Windows XP (2001). Major subsequent consumer releases were Vista (2007), Windows 7 (2009), the touch-oriented and controversial Windows 8 (2012), Windows 10 (2015) — initially described as "the last version of Windows", updated continuously — and Windows 11 (2021).

Market position

From the 1990s Windows held over 90 per cent of the personal computer operating system market; though its share has declined with the rise of mobile computing, it still runs on the large majority of desktop and laptop computers. Its dominance made Microsoft the target of major antitrust cases in the United States and Europe in the 1990s and 2000s, particularly over the bundling of Internet Explorer and Windows Media Player.

Architecture and features

Modern Windows is built on the NT kernel with a hybrid design, supports x86-64 and ARM64 hardware, and provides features including the NTFS file system, Active Directory in business editions, the Windows Subsystem for Linux, and extensive backward compatibility with older applications. Server editions are sold as Windows Server, and related products historically included Windows Phone and embedded variants.
