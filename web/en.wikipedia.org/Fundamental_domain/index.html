Fundamental domain

Given a topological space and a group acting on it, the images of a single point under the group action form an orbit of the point. A fundamental domain or fundamental region is a subset of the space which contains exactly one point from each of these orbits. It serves as a geometric realisation for the abstract set of representatives of the orbits.

There are many ways to choose a fundamental domain. Typically, a fundamental domain is required to be a connected subset with some restrictions on its boundary, for example, smooth or polyhedral. The images of a chosen fundamental domain under the group action then tile the space. One general construction which is mathematically rigorous is that of a Dirichlet domain.

Hints at a general definition

Given an action of a group G on a topological space X by homeomorphisms, the fundamental domain is a set D of representatives for the orbits of X under the action of G that lies in the quotient space X/G. It is usually required to be a topologically nice set in one of several precisely defined ways. One typical condition is that D is almost an open set, in the sense that the symmetric difference of D and its interior has measure zero, for certain (quasi)invariant measures on X.

Examples

Examples in the three-dimensional Euclidean space R3 are:

  • for G = Z3: fundamental domain: 0 ≤ x,y,z < 1
  • for G = SO(3): fundamental domain can be taken to be space with 0 ≤ φ < 2π, 0 ≤ θ < π, 0 ≤ r < ∞
  • for G = SO(2): fundamental domain can be taken to be space with 0 ≤ φ < 2π, 0 ≤ r < ∞

In general, the fundamental parallelepiped defined by a lattice in Euclidean space is a fundamental domain for the translations defined by the lattice.

Fundamental domain for modular subgroups

The existence of a fundamental domain is in general not obvious, but in many cases it can be constructed explicitly. The fundamental domain for the modular group acting on the upper half-plane, for example, is the well-known region bounded by two vertical lines and a circular arc.
