Wi-Fi Protected Access

Wi-Fi Protected Access (WPA) is a family of security standards for wireless local area networks developed by the Wi-Fi Alliance to replace the weak Wired Equivalent Privacy (WEP) system. WPA appeared in 2003, followed by WPA2 and WPA3.

Versions

The original WPA used TKIP as an interim encryption improvement. WPA2 adopted AES-based CCMP and became the long-standing standard for home and enterprise networks. WPA3 introduced Simultaneous Authentication of Equals for personal networks and stronger protections against password guessing and some passive attacks.

Use

In personal mode, devices authenticate with a shared passphrase; in enterprise mode, an authentication server and 802.1X are used. Weak passphrases and outdated protocols remain common risks even when WPA is enabled.
