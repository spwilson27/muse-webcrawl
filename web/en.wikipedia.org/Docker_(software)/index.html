Docker (software)

DeveloperDocker, Inc.
Initial releaseMarch 2013
Written inGo
PlatformLinux, Windows, macOS

Docker is a set of platform-as-a-service products that use operating-system-level virtualisation to deliver software in packages called containers. Containers are isolated from one another and bundle their own software, libraries, and configuration files, communicating through well-defined channels. Because they share the host operating system's kernel, containers are substantially lighter than virtual machines.

History

Docker was launched in 2013 by Solomon Hykes at the company dotCloud, a platform-as-a-service provider that later renamed itself Docker, Inc. The project built on Linux kernel features such as namespaces and cgroups, and on the LXC container technology, before developing its own runtime components including libcontainer and later containerd.

Components

The Docker platform includes the Docker Engine daemon, a client command-line interface, and image registries such as Docker Hub. A Dockerfile describes how to build an image; images are layered filesystems assembled from stacked, read-only layers. Tools such as Docker Compose define multi-container applications, while orchestration systems — notably Kubernetes — schedule containers across clusters.

Adoption and impact

Docker popularised the modern container model and reshaped software deployment, continuous integration, and microservices architecture. In 2019 Mirantis acquired Docker's enterprise business, while Docker, Inc. refocused on developer tooling such as Docker Desktop.
