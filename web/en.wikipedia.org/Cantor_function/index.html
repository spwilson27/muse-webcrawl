Cantor function

From Wikipedia, the free encyclopedia

In mathematics, the Cantor function is an example of a function that is continuous, but not absolutely continuous. It is a notorious counterexample in analysis, first described by Georg Cantor in 1884. It is also known as the Devil's staircase.

Definition

The Cantor function c(x) is defined on the interval [0, 1] using the Cantor set. A number x is written in base 3; if the expansion contains a 1, it is truncated at that point, all remaining digits are set to zero, and the resulting digits are reinterpreted in base 2 and divided appropriately, giving the value of the function. The function is constant on each interval removed in the construction of the Cantor set, and increases from 0 to 1 entirely on the Cantor set itself.

Properties

The Cantor function is continuous everywhere and has derivative zero almost everywhere, yet it rises from c(0) = 0 to c(1) = 1. It therefore shows that a continuous, non-decreasing function need not be the integral of its derivative, and that the fundamental theorem of calculus requires stronger hypotheses such as absolute continuity.
