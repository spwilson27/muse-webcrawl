CKM matrix

The Cabibbo–Kobayashi–Maskawa matrix (CKM matrix) is a unitary matrix in particle physics that contains information on the strength of the flavour-changing weak interaction. It describes how quarks of one type transform into quarks of another type under the weak force, and is a central element of the Standard Model.

Structure

The 3×3 matrix relates the down-type quark mass eigenstates (d, s, b) to the weak-interaction eigenstates (d′, s′, b′). Its diagonal elements (Vud, Vcs, Vtb) are close to 1, while off-diagonal elements are progressively smaller: the Cabibbo angle governs mixing between the first two generations, and mixing involving the third generation is strongly suppressed.

CP violation

Because a 3×3 unitary matrix contains an irreducible complex phase, the CKM matrix provides the Standard Model's source of CP violation, as proposed by Makoto Kobayashi and Toshihide Maskawa in 1973 — work for which they shared the 2008 Nobel Prize in Physics. The consistency of its parameters is visualised with the unitarity triangle, tested extensively by the B-factory experiments BaBar and Belle.
