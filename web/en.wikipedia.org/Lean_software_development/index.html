Lean software development

Lean software development is a translation of lean manufacturing principles — derived from the Toyota Production System — to software development, popularised by Mary and Tom Poppendieck's 2003 book Lean Software Development: An Agile Toolkit. It is closely related to agile software development.

Its seven principles are commonly stated as: eliminate waste; amplify learning; decide as late as possible; deliver as fast as possible; empower the team; build integrity in; and optimise the whole. Waste in software includes partially done work, extra features, task switching, waiting, and defects.

Lean methods emphasise short feedback loops, just-in-time decisions, continuous improvement (kaizen), and respect for the people doing the work, and they influenced later movements such as the lean startup and DevOps.
