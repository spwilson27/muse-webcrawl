International Code of Zoological Nomenclature

The International Code of Zoological Nomenclature (ICZN Code) is a widely accepted convention in zoology that rules the formal scientific naming of organisms treated as animals. It is a set of rules and recommendations intended to ensure that every animal is given a unique, unambiguous scientific name. The rules principally regulate the names of taxa in the family group, genus group and species group. The Code is produced by the International Commission on Zoological Nomenclature.

The fourth edition of the Code was published in 1999 and took effect on 1 January 2000. A fifth edition has been in preparation for many years. An official list of names and works in zoology is maintained in the Commission's ZooBank registry, which became the official register for electronically published names following a 2012 amendment permitting electronic publication under certain conditions.

Structure and rules

Under the Code, the scientific name of a species is a binomen — a combination of a generic name and a specific name — written in italics, with the generic name capitalised. Names must be published, must be formed from the Latin alphabet, and are anchored to name-bearing types, such as holotype specimens. The principle of priority holds that the valid name of a taxon is the oldest available name applied to it, subject to the Code's exceptions, such as the reversal of precedence for names in prevailing usage. The principle of homonymy prevents two different taxa from bearing the same name within the relevant group.

History

The origins of the Code lie in the nineteenth century, when the growing number of described species made uniform rules essential. The Strickland Code, drawn up by a committee of the British Association for the Advancement of Science in 1842, was an early attempt at standardisation. The first international Règles internationales de la nomenclature zoologique were adopted in 1905. Successive editions followed in 1961, 1985 and 1999. The International Commission on Zoological Nomenclature was founded in 1895 and issues rulings (Opinions) on disputed names, using its plenary power to set aside the rules where their strict application would disturb stability.

Relationship to other codes

The ICZN Code is independent of the codes governing plants and fungi (the International Code of Nomenclature for algae, fungi, and plants), bacteria, and viruses, so identical generic names — hemihomonyms — can exist for an animal and a plant, such as Prunella (a bird genus and a plant genus).
