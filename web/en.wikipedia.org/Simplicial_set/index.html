Simplicial set

In mathematics, a simplicial set is an object in category theory used to model spaces and homotopy types combinatorially. It consists of sets of "simplices" in each dimension, together with face and degeneracy maps satisfying the simplicial identities. Simplicial sets generalise simplicial complexes while allowing self-identifications, and they form a central setting for homotopy theory.

Definition

A simplicial set is a contravariant functor from the simplex category Δ — whose objects are finite ordered sets and whose morphisms are order-preserving maps — to the category of sets. Geometrically, the set in degree n gives the n-simplices; face maps extract boundaries and degeneracy maps insert repeated vertices.

Geometric realisation and examples

Every simplicial set has a geometric realisation, a topological space built by gluing standard simplices, and this sets up an equivalence between simplicial sets (with the Kan–Quillen model structure) and homotopy types of spaces. Important examples include the singular complex of a space and the nerve of a small category; Kan complexes, whose simplices can always fill horns, model ∞-groupoids and anchor higher category theory.
