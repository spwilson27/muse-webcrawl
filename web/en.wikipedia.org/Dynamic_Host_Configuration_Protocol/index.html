Dynamic Host Configuration Protocol

The Dynamic Host Configuration Protocol (DHCP) is a network management protocol used on Internet Protocol (IP) networks for automatically assigning IP addresses and other communication parameters to devices connected to the network. It enables computers and other devices to obtain the settings needed to operate on a network without manual configuration.

Operation

A client joining a network obtains an address through a four-step exchange often abbreviated DORA: the client broadcasts a DHCP Discover message; servers respond with a DHCP Offer; the client replies with a DHCP Request for the offered address; and the server confirms with a DHCP Acknowledgement. Addresses are leased for a limited period rather than assigned permanently. DHCP typically supplies the subnet mask, default gateway and DNS server addresses along with the client's IP address.

History

DHCP was first defined in RFC 1531 in October 1993, extending the earlier BOOTP protocol, and the current IPv4 specification is RFC 2131 (1997). DHCPv6, standardised in RFC 8415, performs an analogous role for IPv6 networks.

Security

Because DHCP lacks built-in authentication, rogue servers can hand out false configuration data; mitigations include DHCP snooping on switches and port-based authentication.
