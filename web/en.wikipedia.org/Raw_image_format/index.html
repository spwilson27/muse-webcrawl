Raw image format

A camera raw image file contains minimally processed data directly from the image sensor of a digital camera, scanner, or cinematography camera. Raw files are so called because they are not yet processed — like a photographic negative, they must be "developed" (converted) into a viewable format such as JPEG or TIFF before printing or display.

Characteristics

Raw files record linear sensor values, usually at 12–16 bits per channel, before demosaicing, white balance, tone curves, and compression are baked in. This preserves far greater dynamic range and editing latitude than an 8-bit JPEG: exposure, white balance, and highlight/shadow detail can be adjusted non-destructively afterwards. The trade-offs are large file sizes and the need for conversion software. Formats are mostly proprietary — Canon CR2/CR3, Nikon NEF, Sony ARW — though Adobe's DNG is an open standard, and most smartphones now offer raw capture (e.g. Apple ProRAW, Android RAW).
