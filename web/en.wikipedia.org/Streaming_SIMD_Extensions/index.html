Streaming SIMD Extensions

Streaming SIMD Extensions (SSE) is a SIMD instruction set extension to the x86 architecture, designed by Intel and introduced in 1999 with the Pentium III series of processors. It introduced eight new 128-bit registers (XMM0–XMM7) capable of holding four packed single-precision floating-point numbers, together with instructions for operating on them in parallel.

Features

SSE added 70 new instructions, including scalar and packed single-precision floating-point arithmetic, SIMD integer operations on MMX registers, and cache-control and prefetch instructions intended to help "streaming" workloads such as 3D graphics, video encoding, and signal processing. Unlike the earlier MMX extension, SSE's separate floating-point format let programmers mix SIMD floating-point with ordinary x87 floating-point code without costly mode switches.

Successors

SSE was followed by SSE2 (Pentium 4, 2000), which added double-precision and full integer operations on the XMM registers and effectively superseded MMX; SSE3 (2004), SSSE3 (2006), and SSE4 (2007–2008). Later extensions built on the same register file concept: Advanced Vector Extensions (AVX, 2011) widened the vectors to 256 bits, and AVX-512 widened them further to 512 bits.
