Quasiconvex function

In mathematics, a quasiconvex function is a real-valued function defined on an interval or convex subset of a real vector space such that the inverse image of any set of the form (−∞, a) is a convex set. Equivalently, for all x, y in the domain and λ in [0,1],

f(λx + (1−λ)y) ≤ max{ f(x), f(y) }.

Properties

Every convex function is quasiconvex, but not conversely: for example, the square root of |x| and many monotone functions are quasiconvex without being convex. The sublevel sets of a quasiconvex function are all convex. Unlike convex functions, a quasiconvex function need not attain its extrema in any locally detectable way and may have several distinct local minima in higher dimensions, although a strictly quasiconvex function on an interval is first non-increasing then non-decreasing.

Quasiconcavity

A function is quasiconcave if its negation is quasiconvex, i.e. the superlevel sets are convex. Quasiconcave utility functions are standard in economics: they express preference for diversified consumption bundles. The ratio of two functions gives common quasiconvex or quasiconcave examples — for instance, the ratio of a convex function to a positive concave function is quasiconvex, and specific instances arise in fractional programming.
