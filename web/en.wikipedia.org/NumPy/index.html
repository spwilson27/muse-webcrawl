NumPy (short for Numerical Python) is a library for the Python programming language that adds support for large, multi-dimensional arrays and matrices, together with a large collection of high-level mathematical functions to operate on these arrays. It is the fundamental package for scientific computing in Python and underpins much of the Python data-science ecosystem, including SciPy, pandas, scikit-learn, and the array interfaces used by deep-learning frameworks.

History

NumPy descends from two earlier packages: Numeric, written by Jim Hugunin in 1995, and Numarray, developed at the Space Telescope Science Institute. In 2005 Travis Oliphant unified the two codebases, incorporating Numarray's features into Numeric to create NumPy, whose 1.0 release followed in 2006. Development has since been supported by institutions and sponsors including Enthought, and later NumFOCUS, a nonprofit that fiscally sponsors the project.

Features

The core of NumPy is the ndarray, a homogeneous, n-dimensional array object backed by contiguous memory, which supports vectorised operations implemented in compiled C and Fortran (via BLAS and LAPACK) that are far faster than equivalent pure-Python loops. NumPy provides broadcasting rules for operating on arrays of different shapes, tools for reading and writing array data to disk, linear algebra, Fourier transforms, and random number generation (reworked in version 1.17 around the Generator API). Its C API allows other libraries to interoperate with NumPy arrays with minimal overhead.

Limitations

Arrays are homogeneous and fixed in size once created, so inserting or appending elements is generally inefficient compared with Python lists; computations are also confined to data that fits in memory, and most operations run on the CPU unless paired with GPU-backed libraries.
