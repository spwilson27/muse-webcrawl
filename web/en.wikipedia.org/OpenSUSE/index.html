openSUSE is a free and open-source Linux distribution developed by the openSUSE project and sponsored by SUSE and other companies. It is the community successor to SUSE Linux and serves as the upstream for SUSE Linux Enterprise. The distribution is known for its YaST configuration tool, the Open Build Service, and its rolling-release edition Tumbleweed.

The openSUSE mascot is a chameleon named Geeko.

Editions

Leap

openSUSE Leap is the regular, stable release edition, aligned with the source code of SUSE Linux Enterprise to provide an enterprise-grade, community-supported distribution. Leap releases are versioned (for example 15.x) and receive maintenance updates.

Tumbleweed

openSUSE Tumbleweed is a rolling-release edition: users receive the latest stable software continuously rather than periodic upgrades. New snapshots are tested automatically with the openQA automated testing system before publication.

Tools and infrastructure

YaST (Yet another Setup Tool) is openSUSE's installation and system administration program, unusual in offering both graphical and text interfaces. The Open Build Service (OBS) is a general system for building and distributing binary packages from sources, used by openSUSE and many other projects. Package management uses RPM packages with the ZYpp library and the zypper command-line tool.

History

SUSE Linux was originally a German distribution based on Slackware, later on Jurix. Novell acquired SUSE in 2003 and launched the openSUSE project in 2005, opening development to the community; the first community release was SUSE Linux 10.0. After several changes of corporate ownership, SUSE became an independent company again in 2019.
