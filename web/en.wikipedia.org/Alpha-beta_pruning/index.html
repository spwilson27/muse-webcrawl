Alpha–beta pruning

A minimax tree with the branches pruned by alpha–beta pruning shown in grey.

Alpha–beta pruning is a search algorithm that decreases the number of nodes evaluated by the minimax algorithm in a game tree. It is an adversarial search used in two-player games such as chess, checkers and Go, and it returns exactly the same move as minimax while skipping branches that cannot influence the final decision.

Principle

The algorithm maintains two values, alpha and beta, representing respectively the minimum score the maximising player is already assured of and the maximum score the minimising player is already assured of. When a node's value is found to lie outside the current alpha–beta window, the remaining children of that node need not be examined, because the opponent will never allow that line to be reached.

Efficiency

With optimal move ordering, alpha–beta pruning reduces the effective branching factor from b to roughly the square root of b, allowing a search about twice as deep in the same time. In practice, ordering heuristics such as trying captures and "killer moves" first approach this optimum.

History

The idea was developed in the 1950s by researchers including John McCarthy, Alexander Brudno, and Allen Newell and Herbert Simon, and was described in print in connection with early chess programs. It remains a core component of classical game-playing engines, often combined with transposition tables, iterative deepening and quiescence search.
