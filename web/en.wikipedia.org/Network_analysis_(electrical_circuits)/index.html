Network analysis (electrical circuits)

Network analysis is the process of finding the voltages across, and the currents through, all of the components in an electrical network. There are many techniques for calculating these values; however, for the most part, these techniques assume linear components. Except where stated, the methods described in this article are applicable only to linear networks.

Equivalent circuits

A useful procedure in network analysis is to simplify the network by reducing the number of components. This can be done by replacing physical components with equivalent combinations, such as resistors in series or parallel, or by transforming sources between voltage and current forms. Equivalent circuits include Thévenin and Norton equivalents, which allow a complex network to be represented from the perspective of a pair of terminals by a single source and impedance.

Resistive circuits

For networks containing only resistors and independent sources, fundamental tools include Ohm's law, series and parallel combinations, the current divider and voltage divider rules, and delta–wye (Δ–Y) transformations.

Methods

General systematic procedures include nodal analysis, which applies Kirchhoff's current law at the nodes of the circuit, and mesh analysis, which applies Kirchhoff's voltage law around the loops. Larger and more complex networks are usually analysed with computer programs such as SPICE using modified nodal analysis.

Frequency domain

For alternating-current and general time-varying signals, components are described by impedance and the analysis is carried out in the frequency domain using phasors or the Laplace transform, yielding transfer functions, poles and zeros of the network.
