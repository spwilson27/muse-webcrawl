Bang–bang control

In control theory, a bang–bang controller (also called an on–off controller) is a feedback controller that switches abruptly between two states. It is commonly used where the control input can only take extreme values, such as a heater that is either fully on or fully off.

Principle

A domestic thermostat is the classic example: below the set point the heating is switched fully on; above it, fully off. Hysteresis around the set point prevents rapid chattering of the switch.

Optimal control

Bang–bang solutions arise in optimal control problems where the Hamiltonian is linear in the control variable; by Pontryagin's maximum principle the optimal control lies at its bounds except on singular arcs. Time-optimal control of many systems is bang–bang: full thrust, then full reverse thrust.

Applications

Applications include thermostats, liquid-level control, missile and spacecraft attitude thrusters, and simple industrial process controllers.
