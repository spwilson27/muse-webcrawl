Active learning

Active learning is a term used in several fields. In machine learning it is a special case of semi-supervised learning in which a learning algorithm can interactively query a user (or another information source, called an oracle) to label new data points. In education, active learning is an instructional approach in which students engage with the material through discussion, problem solving, case studies and other activities rather than passively listening to a lecture.

Active learning in machine learning

The key hypothesis of active learning is that a learning algorithm allowed to choose the data from which it learns will perform better with less training data than one that receives randomly chosen examples. Active learning is therefore valuable in domains where unlabeled data is abundant but labels are expensive or time-consuming to obtain, such as speech recognition, information extraction and computational biology.

Scenarios

Three main scenarios are studied: pool-based sampling, in which queries are selected from a large pool of unlabeled data; stream-based selective sampling, in which examples arrive one at a time and the algorithm decides whether to request a label; and membership query synthesis, in which the algorithm generates artificial instances to be labeled.

Query strategies

Common query strategies include uncertainty sampling (label the instances about which the model is least certain), query-by-committee (choose instances on which a committee of models most disagrees), and expected model change or expected error reduction.

Active learning in education

In educational research, active learning denotes methods that involve students in doing things and thinking about what they are doing. Large meta-analyses, notably a 2014 study by Freeman and colleagues in PNAS, found that average examination scores improved by about 6% under active learning in STEM courses, and that students in traditional lectures were about 1.5 times more likely to fail.
