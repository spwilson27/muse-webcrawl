Domain name

Domain name
Example: en.wikipedia.org
System: Domain Name System (DNS)
Administered by: ICANN

A domain name is an identification string that defines a realm of administrative autonomy, authority, or control within the Internet. Domain names are used in various networking contexts and for application-specific naming and addressing purposes. In general, a domain name identifies a network domain or represents an Internet Protocol (IP) resource, such as a server hosting a website.

Structure

Domain names are organized from right to left: the rightmost label is the top-level domain (TLD), such as .com, .org, or a country code such as .uk. To its left are second-level and further subdomain labels, separated by dots. The hierarchy is resolved by the Domain Name System, which translates human-readable names into IP addresses.

Registration

Domain names are registered through accredited registrars under policies coordinated by ICANN. Registrants typically lease a name for a period of one to ten years, renewable. Disputes over names are handled under the Uniform Domain-Name Dispute-Resolution Policy (UDRP). The first registered domain name was symbolics.com, registered on 15 March 1985.
