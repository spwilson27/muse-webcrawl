Addition-chain exponentiation

In mathematics and computer science, optimal addition-chain exponentiation is a method of exponentiation by a positive integer power that requires the fewest number of multiplications. Using an addition chain — a sequence of positive integers beginning with 1, in which each element is the sum of two (not necessarily distinct) earlier elements — one computes each successive power by multiplying two previously computed powers. The shortest addition chain for the exponent gives the minimal number of multiplications.

Example

To compute x15, the binary method uses six multiplications, but the addition chain 1, 2, 3, 6, 12, 15 requires only five: x2 = x·x, x3 = x2·x, x6 = x3·x3, x12 = x6·x6, x15 = x12·x3. In general, the minimal chain length l(n) satisfies ⌊log2 n⌋ + (number of 1 bits in n) − 1 ≥ l(n) ≥ log2 n + log2(number of 1 bits) − small terms, but finding provably shortest chains is computationally hard for large exponents.

Methods and applications

Heuristic strategies include the binary method (square-and-multiply), the factor method, and window methods; Brauer's star-chain restriction (each new element must use the immediately preceding element) simplifies the search and is conjectured — the Scholz–Brauer conjecture, l(n) ≤ l*(2n − 1) ≤ l(n) + n − 1 — but not yet proven in general. Shortest chains are tabulated for exponents into the thousands. Addition chains matter practically in cryptography, where exponentiation in groups is a core operation, and in compiler optimisation of power computations. The related addition-subtraction chain, allowing subtraction, can be shorter still, as when computing x15 via x16/x.
