Quirks mode

In computing, quirks mode is a technique used by web browsers for the sake of maintaining backward compatibility with web pages designed for old browsers, instead of strictly complying with W3C and IETF standards in standards mode. Browsers choose the mode based on the presence and form of the document type declaration (doctype) at the start of an HTML page: a missing or obsolete doctype typically triggers quirks mode, while a complete modern doctype triggers standards mode (or "almost standards mode").

Behaviour

In quirks mode, layout emulates nonstandard behaviour in Navigator 4 and Internet Explorer 5. Examples include a different box model (in which padding and borders are included in an element's width), tables not inheriting font settings, different treatment of percentage heights, and parsing quirks in CSS such as accepting unit-less lengths. These emulations exist so that pages written in the 1990s still render acceptably in modern browsers.

History

Doctype switching was introduced by Internet Explorer 5 for the Macintosh around 2000 and was described by Eric Meyer. The HTML5 specification later standardised the three modes — quirks, limited quirks, and no quirks — and the rules for selecting among them, so that all browsers implement them identically.
