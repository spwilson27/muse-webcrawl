Unified Modeling Language

The Unified Modeling Language (UML) is a general-purpose visual modeling language in the field of software engineering, intended to provide a standard way to visualise the design of a system. It was developed by Grady Booch, Ivar Jacobson and James Rumbaugh at Rational Software in the mid-1990s, combining their earlier methods (the Booch method, OMT and OOSE), and it was adopted as a standard by the Object Management Group (OMG) in 1997. UML 2.x is also an ISO standard.

Diagram types

UML defines more than a dozen diagram types, grouped into structure diagrams and behaviour diagrams. Structure diagrams include the class diagram, which shows classes, attributes, operations and relationships such as inheritance and association; the component, package, object, deployment, composite structure and profile diagrams. Behaviour diagrams include the use case diagram, describing system functionality from the users' perspective; the sequence and communication diagrams, showing interactions over time; the activity diagram, for workflows; and the state machine diagram, for object lifecycles.

Use

UML is used in analysis and design of object-oriented systems, in documenting software architecture, and as a communication tool among stakeholders. It is supported by many CASE tools, some of which can generate code skeletons from models or reverse-engineer diagrams from code. Although agile practices reduced emphasis on comprehensive up-front modelling, UML diagrams — especially class, sequence and use case diagrams — remain in wide everyday use.

Criticism

Critics note that UML is large, complex and often ambiguous, and that diagrams can drift out of sync with code; proponents argue that selective, informal use of its notation is precisely how it delivers value.
