HTTPS

Hypertext Transfer Protocol Secure (HTTPS) is an extension of the Hypertext Transfer Protocol (HTTP). It uses encryption for secure communication over a computer network, and is widely used on the Internet. In HTTPS, the communication protocol is encrypted using Transport Layer Security (TLS) or, formerly, Secure Sockets Layer (SSL). The protocol is therefore also referred to as HTTP over TLS, or HTTP over SSL.

The principal motivations for HTTPS are authentication of the accessed website and protection of the privacy and integrity of the exchanged data while it is in transit. It protects against man-in-the-middle attacks, and the bidirectional block cipher encryption of communications between a client and server protects against eavesdropping and tampering.

Overview

HTTPS URLs begin with "https://" and use port 443 by default, while HTTP URLs begin with "http://" and use port 80. To authenticate the server, HTTPS relies on digital certificates issued by certificate authorities, which the client verifies during the TLS handshake. Web browsers display a padlock icon for valid HTTPS connections and warn users about invalid or expired certificates.

History

HTTPS was created by Netscape Communications in 1994 for its Netscape Navigator web browser. Adoption was initially confined largely to e-commerce and login pages because of the cost of certificates and the performance overhead of encryption. The launch of the free, automated certificate authority Let's Encrypt in 2016, together with browser pressure — Google Chrome began marking HTTP pages as "not secure" in 2018 — drove HTTPS to become the default for the large majority of web traffic.

Security

HTTPS provides confidentiality, integrity, and server authentication, but it does not conceal which site a user is visiting (the domain name may still be visible), and it offers no protection if the server itself or the client device is compromised. Related mechanisms include HTTP Strict Transport Security (HSTS), which instructs browsers to use HTTPS only, and certificate transparency logs, which make misissued certificates detectable.
