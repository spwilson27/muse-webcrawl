Glasgow Haskell Compiler

The Glasgow Haskell Compiler (GHC) is a free and open-source native-code compiler and interactive environment for the Haskell programming language. It is the most widely used Haskell compiler and implements the Haskell 2010 standard together with a large set of language extensions.

Overview

GHC originated at the University of Glasgow in the late 1980s and early 1990s, with Simon Peyton Jones among its principal developers. It compiles Haskell to native machine code on many platforms, and can also target intermediate representations such as LLVM. Its interactive environment, GHCi, provides a REPL and debugger.

Features

GHC is known for its powerful type system extensions, including generalized algebraic data types, type families, and type class extensions. Its runtime system supports lightweight concurrency, software transactional memory, and parallel execution. Optimisations such as inlining, strictness analysis and fusion are central to the performance of compiled Haskell programs. The package environment is commonly managed with Cabal or Stack.
