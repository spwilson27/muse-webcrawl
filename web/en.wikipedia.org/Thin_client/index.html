TypeLow-cost computing terminal
Relies onCentral server

In computer networking, a thin client (sometimes called a lean client or slim client) is a lightweight computer that relies on a more powerful server to fulfil most of its computational roles. Thin clients connect to a server-based computing environment, where most applications, data, and processing are hosted centrally rather than on the local device.

Architecture

A thin client typically contains only the hardware needed to display output, accept keyboard and mouse input, and maintain a network connection. The server runs the operating system sessions or virtual desktops and transmits screen updates to the client. Common remote display protocols include Microsoft's Remote Desktop Protocol (RDP), Citrix ICA, VMware's PCoIP/Blast, and VNC.

Advantages and disadvantages

Thin clients offer lower purchase and maintenance costs, centralized administration, improved security (since data does not reside on endpoints), and lower power consumption. Their drawbacks include total dependence on network and server availability and poorer performance for graphics-intensive or offline work.

History

The concept descends from the dumb terminals of mainframe and minicomputer eras. The term "thin client" was popularized in the 1990s, notably by Oracle Corporation's promotion of the Network Computer, and thin clients found wide use in call centres, schools, hospitals, and government offices.
