Allegro is a free, open-source software library for video game development, providing functions for graphics, sound, input, and timers. Its name is a recursive acronym for "Atari Low-Level Game Routines", reflecting its origins on the Atari ST.

History

Allegro was created by Shawn Hargreaves in the early 1990s and became popular on DOS with DJGPP for hobbyist game programming. Allegro 4 covered the DOS, Windows, and early Linux eras; the substantially redesigned Allegro 5, released in 2011, supports modern platforms including macOS, iOS, and Android, with hardware-accelerated graphics.

Features

The library offers 2D drawing primitives, image and font loading, audio playback and mixing, keyboard/mouse/joystick input, and an event system. Addons provide image codecs, text rendering with TrueType fonts, audio codecs, and primitives drawing. Community bindings exist for several other languages.
