Web typography

Web typography refers to the use of fonts on the World Wide Web. When HTML was first created, font faces and styles were controlled exclusively by the settings of each web browser. There was no mechanism for individual web pages to control font display until Netscape introduced the font element in 1995, which was then standardized in the HTML 3.2 specification.

CSS and downloadable fonts

The first Cascading Style Sheets (CSS) specification was published in 1996 and provided capabilities to specify font families, sizes, weights and styles. However, designers were limited to fonts installed on users' computers, leading to reliance on widely available "web-safe" font stacks such as Arial, Times New Roman, Georgia and Verdana.

The CSS @font-face rule, first supported in early browsers with embedded font formats, became practical with the widespread adoption of the Web Open Font Format (WOFF) and WOFF2 in the 2010s. Font delivery services and self-hosted web fonts made custom typefaces routine on the web. Variable fonts, standardized through the OpenType Font Variations specification, allow a single font file to vary continuously in weight, width and other axes.

Page layout

Web typography also concerns line length, line height (leading), alignment, hyphenation and responsive scaling of text across screen sizes, typically managed through CSS layout modules and relative units such as em, rem and viewport units.
