Monospaced font

A monospaced font, also called a fixed-pitch, fixed-width, or non-proportional font, is a font whose letters and characters each occupy the same amount of horizontal space. This contrasts with variable-width fonts, where the letters and spacings have different widths. Monospaced fonts are customary for typewriters and for displaying computer code.

History

Monospacing was a mechanical necessity of typewriters: the carriage advanced by the same amount for every keystroke, so all characters had to fit within the same width. Early computer printers and terminals inherited the constraint, and standard character grids (for instance, 80 columns) became conventions of computing. Classic examples include Courier, designed by Howard Kettler in 1955 for IBM typewriters, Prestige Elite, and Monaco and Consolas on modern systems.

Uses

Monospaced fonts remain standard for:

  • Computer programming — code editors use them so that indentation and alignment are consistent and similar characters (such as 0/O and 1/l/I) can be designed distinctly.
  • Tabular data — columns of figures line up vertically.
  • Terminal and console interfaces, ASCII art, and plain-text documents.
  • Typewritten documents such as screenplays, where page counts correspond predictably to running time.
  • Biological sequences — alignments of DNA and protein sequences.

Design considerations

Because every glyph must fit the same advance width, narrow letters such as i are given serifs or extra space to fill the cell, while wide letters such as m and w are compressed. Programming fonts add features such as a slashed or dotted zero, clearly distinguished brackets, and optional ligatures that combine common multi-character operators.

Examples

  • Courier / Courier New
  • Consolas, DejaVu Sans Mono, Liberation Mono
  • Monaco, Menlo
  • Source Code Pro, Fira Code, JetBrains Mono
  • IBM Plex Mono
