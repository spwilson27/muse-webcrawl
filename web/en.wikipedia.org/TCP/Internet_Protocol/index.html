Internet Protocol

The Internet Protocol (IP) is the network layer communications protocol in the Internet protocol suite for relaying datagrams across network boundaries. Its routing function enables internetworking, and essentially establishes the Internet. IP delivers packets from the source host to the destination host based solely on the IP addresses in the packet headers.

Function

IP provides an unreliable, connectionless delivery service: it defines the addressing and packet structure, fragments and reassembles packets when necessary, and routes each packet independently through the network, but it offers no guarantees of delivery, ordering, or duplicate protection. Reliability is provided by upper-layer protocols, principally the Transmission Control Protocol (TCP), giving rise to the common name TCP/IP.

Versions

The first major version, IPv4, described in RFC 791 (1981), uses 32-bit addresses and remains widely deployed. Its successor, IPv6, uses 128-bit addresses and was standardised to address the exhaustion of the IPv4 address pool. Version numbers 5 and 7–9 were assigned to experimental or alternative proposals and never saw general use.

Routing

Routers forward IP packets by matching the destination address against routing tables, decrementing the time-to-live field at each hop and discarding packets whose TTL reaches zero. Between autonomous systems, routes are exchanged using the Border Gateway Protocol.
