TCP/IP

The Internet protocol suite, commonly known as TCP/IP, is the set of communications protocols used in the Internet and similar computer networks. It is named after its two foundational protocols: the Transmission Control Protocol (TCP) and the Internet Protocol (IP). The suite provides end-to-end data communication specifying how data should be packetized, addressed, transmitted, routed and received.

Layers

The suite is organised into abstraction layers. In the common four-layer description these are the link layer (network interface hardware), the internet layer (IP addressing and routing), the transport layer (TCP and UDP) and the application layer (HTTP, DNS, SMTP and others). This layered model is often compared with the seven-layer OSI model.

History

The foundations were developed in the 1970s under the US Defense Advanced Research Projects Agency (DARPA), drawing on work by Vint Cerf, Bob Kahn and others for the ARPANET. TCP/IP became the standard protocol of the ARPANET on 1 January 1983, and its adoption spread with the growth of the Internet in the 1990s.

Key protocols

  • IP – delivers packets between hosts using IP addresses (IPv4 and IPv6).
  • TCP – provides reliable, ordered delivery of a byte stream.
  • UDP – a lightweight, connectionless transport protocol.
  • DNS – translates domain names into IP addresses.
