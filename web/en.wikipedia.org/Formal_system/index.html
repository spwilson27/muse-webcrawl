Formal system

A formal system is an abstract structure used for inferring theorems from axioms according to a set of rules. These rules, which may effectively be an algorithm, are used to carry out the inference of theorems from axioms. Formal systems underlie the fields of mathematical logic and theoretical computer science, and include axiomatic systems, formal grammars, and proof systems.

Components

A formal system typically consists of a formal language — an alphabet of symbols and formation rules specifying which strings of symbols are well-formed formulas — together with a deductive apparatus: a set of axioms and rules of inference that allow new formulas (theorems) to be derived from old ones. A derivation, or proof, is a finite sequence of formulas each of which is an axiom or follows from earlier formulas by an inference rule.

Properties

Formal systems are studied for properties such as consistency (no contradiction is derivable), completeness (every semantically valid statement is derivable), soundness (every derivable statement is valid), and decidability. Kurt Gödel's incompleteness theorems show that any consistent formal system strong enough to express basic arithmetic contains true statements that cannot be proved within the system, and cannot prove its own consistency.
