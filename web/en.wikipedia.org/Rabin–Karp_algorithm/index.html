Rabin–Karp algorithm

The Rabin–Karp algorithm slides a window across the text, comparing rolling hash values instead of the substrings themselves.

The Rabin–Karp algorithm or Karp–Rabin algorithm is a string-searching algorithm created by Richard Karp and Michael O. Rabin in 1987 that uses hashing to find an exact match of a pattern string in a text. It uses a rolling hash to quickly filter out positions of the text that cannot match the pattern, and then checks for a match at the remaining positions. Generalisations of the same idea can find more than one pattern, or patterns of multiple lengths, in a single pass.

Outline

The algorithm first computes the hash of the pattern, then slides a window of the same length along the text. Because the hash is a rolling hash (for example a polynomial hash computed modulo a large prime), the hash of each new window can be derived from the previous one in constant time by removing the contribution of the outgoing character and adding the incoming one. If the window's hash differs from the pattern's hash, the window cannot match. If the hashes agree, the algorithm compares the strings directly to confirm the match and rule out a hash collision.

Complexity

With a good hash function, hash mismatches reject almost all positions, so the average running time is linear, O(n + m) for a text of length n and a pattern of length m. In the worst case — for example with a deliberately weak hash or an adversarial input — many positions may require full comparison, giving O(nm) time. Choosing the modulus at random, or using two independent hashes, makes such worst cases improbable.

Applications

The algorithm is particularly useful for plagiarism detection and for searching for many patterns at once: by hashing a whole set of patterns of equal length, a single pass through the text can flag all of them. Rolling-hash fingerprints of documents are the basis of widely used document-similarity systems such as MOSS for detecting copied code.
