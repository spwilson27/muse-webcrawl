Harvard architecture

The Harvard architecture is a computer architecture with separate storage and signal pathways for instructions and data. The term originates with the Harvard Mark I relay-based computer (1944), which stored instructions on punched paper tape and data in electromechanical counters.

Harvard architecture
Named for: Harvard Mark I (1944)
Key feature: Separate instruction and data memories/buses
Contrasts with: Von Neumann architecture

Characteristics

Because instructions and data travel on separate buses, a Harvard-architecture machine can fetch an instruction and access data simultaneously, avoiding the bottleneck of a single shared pathway. Instruction and data memories may also differ in word width, size, and technology.

Uses

Pure Harvard designs are common in digital signal processors and microcontrollers, where predictable throughput matters. Most general-purpose computers use a modified Harvard architecture: a unified main memory with separate instruction and data caches at the CPU, combining the von Neumann programming model with Harvard-style bandwidth.
