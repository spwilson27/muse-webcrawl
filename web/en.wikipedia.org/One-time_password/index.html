One-time password

A one-time password (OTP) is a password that is valid for only one login session or transaction. Because it cannot be reused, an OTP avoids several weaknesses of static passwords, such as replay attacks and credential theft. OTPs are widely used as a second factor in multi-factor authentication for banking, email, and corporate networks.

Generation methods

OTPs may be time-synchronized, generated from the current time and a shared secret key (TOTP, standardized in RFC 6238), or event-based, generated from a counter (HOTP, RFC 4226). They can also be derived from a mathematical algorithm seeded by a previous password or a random challenge from the server. Delivery channels include hardware tokens, authenticator apps, SMS messages, email, and printed lists of codes.

Security

While OTPs greatly reduce the value of stolen passwords, they are not immune to attack: real-time phishing can relay a code to the genuine site, and SMS codes can be intercepted by SIM-swap fraud. For this reason, security guidelines increasingly favor authenticator apps or hardware keys over SMS, and transaction-signing schemes bind the code to the details of a specific transaction.

Applications

OTPs are used to authorize logins, confirm payments, reset passwords, and sign documents. Grid cards and scratch lists were early low-tech implementations used by banks.
