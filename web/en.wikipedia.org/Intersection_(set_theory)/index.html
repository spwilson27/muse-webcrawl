Intersection (set theory)

From Wikipedia, the free encyclopedia

In set theory, the intersection of two sets A and B, denoted by A ∩ B, is the set containing all elements of A that also belong to B — or equivalently, all elements of B that also belong to A. Intersection is one of the fundamental operations of set theory, alongside union and complement, and it corresponds to the logical connective "and" (conjunction).

A ∩ B = { x : x ∈ A and x ∈ B }

Notation and definition

The symbol ∩ was introduced by Giuseppe Peano in 1888. If the intersection of two sets is the empty set, the sets are said to be disjoint. For example, the intersection of {1, 2, 3} and {2, 3, 4} is {2, 3}, while the intersection of the sets of even and odd integers is empty.

Properties

Intersection is commutative (A ∩ B = B ∩ A), associative (A ∩ (B ∩ C) = (A ∩ B) ∩ C), and idempotent (A ∩ A = A). It distributes over union: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C). The universal set is an identity element for intersection, and the empty set is an annihilator. De Morgan's laws relate intersection to union through complementation.

Arbitrary intersections

The notion generalises to any collection of sets: the intersection of a family of sets is the set of elements belonging to every member of the family, written ⋂i∈I Ai. In the axiomatic Zermelo–Fraenkel set theory, the existence of intersections follows from the axiom of specification applied to any one of the sets in the family. The intersection of an empty family is conventionally taken to be the universal set, although the "universal set" itself is not a set in standard set theory.
