Causal graph

In statistics, econometrics, epidemiology, genetics and related disciplines, a causal graph (also known as a path diagram, causal Bayesian network or DAG) is a probabilistic graphical model used to encode assumptions about the data-generating process. Causal graphs can be used for communication and for inference: they communicate the causal assumptions a researcher makes, and they allow some aspects of the underlying causal structure to be identified from observational data.

Definition

A causal graph is a directed acyclic graph (DAG) whose vertices represent variables and whose directed edges represent direct causal effects: an edge X → Y asserts that X is a direct cause of Y relative to the variables in the graph. The graph implies a joint probability distribution that factorizes according to the causal Markov condition, with each variable independent of its non-descendants given its parents.

Inference

Graphical criteria such as d-separation allow one to read conditional independencies off the graph. Judea Pearl's do-calculus and the back-door criterion determine when a causal effect can be estimated from observational data, and when adjustment for confounding is needed. Causal graphs are the basis of structural causal models, in which each variable is assigned as a function of its parents and an exogenous disturbance.

Applications

Causal graphs are used in epidemiology to select confounders, in economics for structural modeling, in machine learning for causal discovery and transportability, and in artificial intelligence for reasoning about interventions and counterfactuals.
