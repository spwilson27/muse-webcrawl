Binary tree

In computer science, a binary tree is a tree data structure in which each node has at most two children, referred to as the left child and the right child. Binary trees underpin binary search trees, heaps, expression trees and Huffman coding trees.

Definitions

A full binary tree has every node with 0 or 2 children; a complete binary tree is filled on all levels except possibly the last, filled from the left; a perfect binary tree has all leaves at the same depth. The height of a tree is the length of the longest root-to-leaf path.

Traversals

Common traversals are inorder (left, root, right), preorder (root, left, right), postorder (left, right, root) and level-order (breadth-first). Inorder traversal of a binary search tree yields keys in sorted order.

Representation

Trees are usually stored as nodes with pointers to children and optionally a parent. Complete trees can be stored compactly in an array, as in a binary heap, with children of index i at 2i+1 and 2i+2.

Applications

Binary trees model hierarchical decisions, parse trees, file-system-like structures and priority queues, and appear in algorithms for searching and sorting.
