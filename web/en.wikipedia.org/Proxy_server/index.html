Proxy server

In computer networking, a proxy server is a server application that acts as an intermediary between a client requesting a resource and the server providing that resource. Instead of connecting directly, the client first connects to the proxy server and requests the resource; the proxy then evaluates the request, forwards it to the appropriate server using its own IP address, and returns the response to the client. Proxies therefore provide a level of abstraction, control and privacy between clients and the wider network.

Types

  • Forward proxy — sits in front of a group of client machines and forwards their requests to the internet; used by organisations and ISPs for caching, filtering and access control.
  • Reverse proxy — sits in front of one or more web servers, intercepting requests from the internet; used for load balancing, caching, TLS termination and shielding origin servers. Examples include Nginx and content delivery network edge servers.
  • Open proxy — accessible to any internet user; often abused for spam or to conceal the origin of attacks.
  • Transparent proxy — intercepts traffic without modifying requests and without requiring client configuration.

Uses

Proxies are deployed to improve performance through caching of frequently requested content, to enforce acceptable-use policies and block malicious or inappropriate sites, to bypass geographical restrictions or censorship, to monitor and log traffic, and to provide anonymity by masking the client's IP address. The SOCKS protocol and HTTP CONNECT method allow proxies to relay arbitrary TCP connections, and tools such as Tor build layered proxy chains for stronger anonymity.

Drawbacks and risks

A proxy can observe and potentially alter unencrypted traffic, so users must trust the operator; free proxy services have repeatedly been found logging data or injecting advertisements. Proxies also add latency and create a single point of failure if not made redundant.
