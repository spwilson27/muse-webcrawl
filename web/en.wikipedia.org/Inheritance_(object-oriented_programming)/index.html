Inheritance (object-oriented programming)


A class hierarchy: subclasses inherit attributes and behaviour from a superclass.

In object-oriented programming, inheritance is the mechanism by which one class (the subclass or derived class) acquires the properties and behaviours of another class (the superclass or base class). It supports code reuse and the modelling of "is-a" relationships: a Car subclass of Vehicle inherits wheels and a method for moving, and may override or extend them. Inheritance creates a class hierarchy and, together with polymorphism, allows programs to treat objects of subclasses as objects of their superclass.

Types of inheritance

In single inheritance a class derives from one base class, as in Java and C#. In multiple inheritance, supported by C++ and Python, a class may derive from several base classes, which introduces complications such as the "diamond problem", in which a feature is inherited along two paths. Languages resolve this in different ways; many modern languages instead allow a class to implement multiple interfaces while inheriting implementation from a single class.

Subclasses and overriding

A subclass inherits fields and methods, may add new ones, and may override inherited methods to specialise behaviour. Constructors are not inherited but are invoked in a chain. Access modifiers such as public, protected and private control what a subclass can see. Abstract classes and methods define behaviour that subclasses must supply.

class Vehicle {
    int wheels;
    void move() { ... }
}

class Car extends Vehicle {   // Car inherits from Vehicle
    void move() { ... }       // overridden method
}

Criticism and alternatives

Deep inheritance hierarchies can be fragile: changes to a base class may break subclasses (the fragile base class problem), and inheritance couples classes tightly. A common design maxim, popularised by the book Design Patterns (1994), is to "favour composition over inheritance" — assembling behaviour from component objects instead. Prototype-based languages such as JavaScript achieve reuse through prototype chains rather than classes, and trait/mixin systems offer inheritance-like reuse without a strict hierarchy.
