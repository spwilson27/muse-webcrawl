Rational function

In mathematics, a rational function is any function that can be defined by a rational fraction, which is an algebraic fraction such that both the numerator and the denominator are polynomials. The coefficients of the polynomials need not be rational numbers; they may be taken in any field K. In this case, one speaks of a rational function over the field K.

Definitions

A function f(x) is called a rational function if it can be written in the form f(x) = P(x) / Q(x), where P and Q are polynomial functions of x and Q is not the zero function. The domain of f is the set of all points x for which the denominator Q(x) is not zero.

A rational function is called proper if the degree of the numerator is less than the degree of the denominator, and improper otherwise. Any improper rational function can be expressed as the sum of a polynomial and a proper rational function through polynomial long division.

Examples

The rational function f(x) = (x² + 2) / (x² + 1) is defined for all real numbers, but not for all complex numbers, since the denominator vanishes at x = ±i. The function f(x) = 1 / (x − 1) has a vertical asymptote at x = 1 and a horizontal asymptote at y = 0.

Applications

Rational functions are used in numerical analysis for interpolation and approximation of functions, where they can model behaviour near singularities better than polynomials. Padé approximants are rational functions whose Taylor series matches a given function's series to some order. Rational functions also appear throughout algebra and algebraic geometry, where the field of rational functions on an algebraic variety is a central object of study.
