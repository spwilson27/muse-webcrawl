Serialization

Serialization converts data structures into a storable, transmittable format

In computing, serialization (or serialisation) is the process of translating a data structure or object state into a format that can be stored (in a file or data buffer) or transmitted (over a computer network) and reconstructed later, possibly in a different computer environment. When the resulting series of bits is reread according to the serialization format, it can be used to create a semantically identical clone of the original object. The opposite operation, extracting a data structure from a series of bytes, is deserialization.

Uses

Serialization is used for data persistence, remote procedure calls and distributed object communication, message passing between processes, and caching. It allows an object to be saved to disk and restored later, sent across a network to another machine, or passed between components written in different programming languages when a language-neutral format is used.

Formats

Common serialization formats include JSON, XML, YAML, Protocol Buffers, MessagePack and language-specific binary formats such as Java's built-in object serialization and Python's pickle module. Text-based formats are human-readable and language-independent but are generally larger and slower to parse than binary formats.

Security considerations

Deserializing untrusted data is a well-known source of security vulnerabilities. Many languages and libraries have suffered remote-code-execution flaws when attacker-controlled byte streams were deserialized into objects whose reconstruction logic could be manipulated. Defensive practice is to avoid deserializing untrusted input with native object formats and to prefer simple data-only formats with strict schemas.

In publishing

The term also refers to the publication of a work in sequential installments; see Serial (literature).
