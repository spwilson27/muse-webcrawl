Server (computing)

In computing, a server is a piece of computer hardware or software (a computer program) that provides functionality for other programs or devices, called "clients". This architecture is called the client–server model. Servers can provide various functionalities, often called "services", such as sharing data or resources among multiple clients, or performing computation for a client.

Types of servers

Common server roles include web servers (serving HTTP content), application servers, database servers, mail servers, file servers, print servers, proxy servers and game servers. A single physical machine can run several server programs at once, and a single program — such as a large web service — may run across thousands of machines.

Hardware

Server hardware emphasizes reliability and continuous operation: rack-mounted form factors, redundant power supplies, error-correcting (ECC) memory, hot-swappable drives and remote management controllers. Large deployments live in data centers with redundant power and cooling. At the high end, mainframes such as IBM Z serve transaction workloads; historically, minicomputers filled many departmental server roles before commodity x86 servers took over in the 1990s.

Operating systems

Popular server operating systems include Linux distributions (Debian, Ubuntu Server, Red Hat Enterprise Linux), Windows Server, and Unix systems such as FreeBSD. Servers typically run "headless," without a local display, and are administered remotely.
