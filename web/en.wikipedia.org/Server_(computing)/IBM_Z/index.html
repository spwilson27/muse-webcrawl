IBM Z is a family name used by IBM for all of its z/Architecture mainframe computers. As servers, IBM Z systems anchor the transaction-processing infrastructure of banks, insurers, airlines, and governments, prized for reliability, security, and the ability to sustain enormous input/output throughput.

An IBM Z machine can be divided into up to 85 logical partitions (LPARs), each running its own operating system, and can host thousands of Linux server instances consolidated onto a single footprint. The platform's Parallel Sysplex clustering, hardware cryptography, and pervasive encryption are intended to let a single system act as an enterprise's most trusted server while still running cloud-native and containerized workloads under z/VM or KVM.

History

The line descends from the System/360 announced in 1964. The "Z" branding began with the zSeries 900 in 2000, emphasizing zero downtime; subsequent generations include the z9, z10, zEnterprise (z196, zEC12), z13, z14, z15, and z16, each adding processor capacity, memory, and on-chip acceleration — the z16 and z17 adding AI inference acceleration on the processor chip itself.
