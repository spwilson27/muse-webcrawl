Column generation

Column generation is a technique in mathematical optimization for solving large linear programming problems whose structure makes it impractical to enumerate all variables (columns) in advance. It is closely related to the Dantzig–Wolfe decomposition principle proposed by George Dantzig and Philip Wolfe in 1960.

Method

The algorithm works with a restricted master problem containing only a small subset of the variables. After solving it, the dual values (shadow prices) are passed to a pricing subproblem, which constructs a new variable with negative reduced cost — that is, a column that can improve the objective. That column is added to the master problem and the process repeats until the pricing problem can find no improving column, proving the current solution optimal.

Applications

Column generation is central to solving the cutting stock problem, vehicle routing problems, airline crew scheduling, and ship routing. Combined with branching, it forms the branch-and-price framework for integer programming.
