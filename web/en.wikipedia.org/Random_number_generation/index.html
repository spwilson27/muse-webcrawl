Random number generation

Random number generation is the process of generating a sequence of numbers or symbols that cannot reasonably be predicted better than by random chance. Devices that perform it are called random number generators (RNGs).

Methods

Approaches divide into true random number generators, which harvest entropy from physical phenomena such as thermal noise, radioactive decay, or atmospheric noise, and pseudorandom number generators (PRNGs), which use deterministic algorithms — such as the Mersenne Twister or linear congruential generators — seeded with an initial value to produce sequences that pass statistical tests for randomness.

Applications

Random numbers are essential in cryptography, computer simulation (Monte Carlo methods), statistical sampling, gambling, lotteries, and games.
