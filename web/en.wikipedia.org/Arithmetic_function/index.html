Arithmetic function

In number theory, an arithmetic function, or number-theoretic function, is any function f(n) whose domain is the set of positive integers and whose range is a subset of the complex numbers. Arithmetic functions are studied for the irregular patterns of their values, and their summatory behaviour is a central topic of analytic number theory.

Examples

Important examples include the Möbius function μ(n), Euler's totient function φ(n), the divisor functions d(n) and σ(n) counting and summing the divisors of n, the prime omega functions, the Liouville function λ(n), and von Mangoldt's function Λ(n), which underlies the study of the distribution of prime numbers.

Multiplicative and additive functions

An arithmetic function is multiplicative if f(mn) = f(m)f(n) whenever m and n are coprime, and completely multiplicative if this holds for all m, n. Additive functions satisfy f(mn) = f(m) + f(n) for coprime arguments. Many key functions are multiplicative, so their values are determined by their values at prime powers.

Dirichlet convolution

Arithmetic functions form a ring under pointwise addition and Dirichlet convolution, (f * g)(n) = Σd|n f(d)g(n/d). Möbius inversion relates a function to its summatory convolution with the constant function 1. Dirichlet series generating functions encode arithmetic functions analytically and connect them to the Riemann zeta function and L-functions.

Average order

Because individual values of arithmetic functions fluctuate, one studies their average orders — for example, the average order of d(n) is log n — and results such as Dirichlet's divisor problem and the prime number theorem (stating that the average of Λ(n) is 1) are proved in this framework.
