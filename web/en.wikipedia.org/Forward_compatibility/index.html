Related conceptBackward compatibility

Forward compatibility (sometimes confused with extensibility) is a design characteristic that allows a system to accept input intended for a later version of itself. The concept is applied in a range of fields, including telecommunications, electronic devices, and information technology. A forward-compatible system is designed to gracefully accept data, files, or commands created for a newer version of the standard it implements.

Design approaches

Forward compatibility is usually achieved by designing older implementations to ignore unknown extensions, fields, or markup rather than failing on them. Robustness principles in protocol design, such as those embodied in version-tolerant formats like HTML and many XML vocabularies, encourage this behaviour. It can also be achieved artificially, by designing a system that mimics a future implementation — for example, video game consoles designed to play a limited selection of their successor's games.

Comparison with backward compatibility

Backward compatibility means a newer system can accept input intended for an older version. Forward compatibility is generally harder, because the older system must anticipate features not yet designed; designers often aim for both qualities so that systems of adjacent generations can interoperate during transitions.
