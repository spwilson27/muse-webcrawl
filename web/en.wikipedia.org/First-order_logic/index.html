First-order logic, also known as predicate logic or first-order predicate calculus, is a collection of formal systems used in mathematics, philosophy, linguistics, and computer science. Unlike propositional logic, first-order logic uses quantified variables over non-logical objects — its sentences contain quantifiers such as "for all" (∀) and "there exists" (∃) ranging over individuals in a domain of discourse.

First-order logic is distinguished from higher-order logics by the fact that quantification is permitted only over individual elements of the domain, not over predicates, sets, or functions. This restriction gives first-order logic attractive metalogical properties, including completeness and compactness, at the cost of expressive limitations.

Syntax and semantics

A first-order language consists of logical symbols (connectives, quantifiers, variables, equality) and non-logical symbols interpreted by a structure: constants, functions and relations over a chosen domain. A sentence is true in a structure when the Tarskian recursive definition of truth is satisfied. Formulas built without individual quantification over sets can express arithmetic, group theory, and virtually all of classical mathematics (via Zermelo–Fraenkel set theory).

Metalogical properties

In 1929, Kurt Gödel proved the completeness theorem: every logically valid first-order sentence is provable in a standard deductive system, so semantic consequence coincides with syntactic provability. The compactness theorem and the Löwenheim–Skolem theorems follow. However, validity in first-order logic is not decidable (Church and Turing, 1936), though it is semi-decidable — a consequence of the negative solution to the Entscheidungsproblem.

Applications

First-order logic underlies formalised mathematics, automated theorem proving, logic programming languages such as Prolog, database query theory, and formal verification of software and hardware.
