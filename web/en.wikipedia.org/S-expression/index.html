S-expression

In computer programming, an S-expression (short for symbolic expression, also abbreviated as sexp or sexpr) is an expression in a like-named notation for nested list (tree-structured) data. S-expressions were invented for and popularized by the programming language Lisp, which uses them for source code as well as data.

Characteristics

An S-expression is either an atom or a (possibly empty) list of S-expressions separated by whitespace and enclosed in parentheses. Atoms include numbers, strings, and symbols. For example, the following is an S-expression representing a function call in Lisp:

(* (+ 2 3) 4)

Here the outer list applies the multiplication operator * to the result of the inner S-expression (+ 2 3) and the atom 4.

History

S-expressions were designed by John McCarthy around 1960 for the Lisp language. McCarthy originally intended a different, more conventional syntax (M-expressions) for programs, with S-expressions as an internal representation; in practice programmers preferred to write S-expressions directly, and the notation became the defining feature of the Lisp family of languages, including Scheme, Common Lisp, and Clojure.

Uses

Beyond Lisp source code, S-expressions are used as a general data-interchange format. Variants appear in the Rivest S-expressions specification, in the SPKI certificate standard, in certain configuration formats, and in the syntax of languages and tools built on Lisp-like foundations. Their uniform, minimal syntax makes them easy to parse and generate programmatically.
