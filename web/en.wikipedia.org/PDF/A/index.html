PDF/A

PDF/A

Standard: ISO 19005

First release: 2005 (PDF/A-1)

Purpose: Long-term archiving of electronic documents

Based on: PDF 1.4 (A-1), PDF 1.7 (A-2, A-3), PDF 2.0 (A-4)

PDF/A is an ISO-standardised version of the Portable Document Format (PDF) specialised for use in the archiving and long-term preservation of electronic documents. Defined by the ISO 19005 series, PDF/A differs from ordinary PDF by prohibiting features unsuitable for long-term archiving and by requiring that everything needed to display the document — fonts, colour profiles and metadata — be embedded within the file itself, so that it will render identically far into the future.

Requirements

A conforming PDF/A file must be entirely self-contained. Key requirements include:

  • All fonts must be embedded, with legal embedding rights for unlimited universal rendering.
  • Colour must be specified in a device-independent manner using embedded ICC profiles or output intents.
  • Content may not depend on external sources — no external images, links to missing fonts, or streamed data.
  • Encryption and password protection are forbidden; audio, video, JavaScript and executable attachments are (in most parts) prohibited.
  • Metadata must be embedded in XMP format, identifying the file's claimed PDF/A part and conformance level.
  • Digital signatures are permitted under defined conditions, so archives can preserve authenticity.

Parts and conformance levels

PDF/A-1 (2005) is based on PDF 1.4. PDF/A-2 (2011) is based on PDF 1.7 (ISO 32000-1) and adds JPEG 2000 compression, transparency and the ability to nest PDF/A files. PDF/A-3 (2012) additionally allows arbitrary file formats (such as XML or spreadsheets) to be embedded as attachments, supporting hybrid archiving of, for example, invoices with machine-readable data. PDF/A-4 (2020) aligns the standard with PDF 2.0. Within each part, conformance levels include b (basic visual reproducibility), a (accessible — adds tagging and Unicode mapping), and u (Unicode mapping only, in later parts).

Validation and adoption

Compliance is checked with validators such as the open-source veraPDF, developed with the PDF Association's involvement. PDF/A is mandated or recommended for records archiving by many governments and regulated industries; related standards include PDF/X for print production and PDF/E for engineering documents.
