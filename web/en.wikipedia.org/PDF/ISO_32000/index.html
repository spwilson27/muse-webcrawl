ISO 32000

ISO 32000 is the international standard defining the Portable Document Format (PDF). Published by the International Organization for Standardization, it made PDF an open standard maintained independently of Adobe Systems, which created the format in 1993.

History

ISO 32000-1:2008, Document management — Portable document format — Part 1: PDF 1.7, was based on Adobe's PDF Reference, sixth edition, describing PDF version 1.7. ISO 32000-2:2017, defining PDF 2.0, was the first version developed entirely within the ISO working group process, and a second edition was published in 2020.

Related standards

Subsets of PDF standardized by ISO include PDF/A for archiving (ISO 19005), PDF/X for print exchange (ISO 15930), PDF/E for engineering (ISO 24517), and PDF/UA for universal accessibility (ISO 14289).
