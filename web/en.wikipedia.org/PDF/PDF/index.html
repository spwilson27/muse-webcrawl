PDF

Portable Document Format (PDF), standardized as ISO 32000, is a file format developed by Adobe in 1992 to present documents, including text formatting and images, in a manner independent of application software, hardware, and operating systems.

History

PDF was developed as part of Adobe co-founder John Warnock's "Camelot" project and released in 1993 with Acrobat and the initially paid Adobe Reader. The format became an open standard in 2008 with ISO 32000-1; PDF 2.0 followed in 2017.

Technical overview

Each PDF file encapsulates a complete description of a fixed-layout flat document, including text, fonts (with embedding and subsetting), vector graphics, and raster images. The format derives from PostScript and can carry interactive elements such as form fields, annotations, JavaScript, layers, and digital signatures. Related standardized subsets include PDF/A, PDF/X, PDF/E, and PDF/UA.
