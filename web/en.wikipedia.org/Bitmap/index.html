Bitmap

A bitmap is a mapping of data from some domain to bits — in computing, most commonly an image representation in which a rectangular grid of pixels, each assigned a colour value, forms a picture. Bitmap images (also called raster graphics) are resolution-dependent: enlarging them reveals the individual pixels. The term is also used for one-bit-per-element data structures in general, such as bit arrays used to track free blocks on a disk.

Image bitmaps

A bitmap stores one or more bits per pixel. Monochrome bitmaps use a single bit per pixel; grayscale and colour images typically use 8 bits per channel, giving 24-bit "true colour" (about 16.7 million colours), often with an additional 8-bit alpha channel for transparency. The colour of indexed images is instead given by a palette of colour values, each pixel storing a small index. File size grows with width × height × colour depth, which motivates compression: lossless formats such as PNG and GIF compress without discarding data, while JPEG uses lossy compression that discards detail the eye is less likely to notice.

Formats

Historical and current raster formats include BMP (the Windows bitmap format), GIF, PNG, JPEG, TIFF, and WebP. In Microsoft Windows programming, a bitmap resource (HBITMAP) and the device-independent bitmap (DIB) are foundational graphics objects. The X Window System uses the related term pixmap for multi-bit-depth off-screen images, reserving "bitmap" strictly for single-bit images.

Bitmap versus vector graphics

Unlike vector graphics, which describe images as mathematical shapes that scale cleanly, bitmaps capture fine tonal detail and are the natural format for photographs and scanned images — but they pixelate when scaled up and produce large files at high resolution. Digital workflows routinely combine both: photographs as bitmaps, logos and type as vectors.

Other uses

In data structures, a bitmap (bitset or bit array) is a compact array of bits used for set membership, indexing — database bitmap indexes are efficient for low-cardinality columns — and allocation maps in file systems. In typography, bitmap fonts define each glyph as a pixel grid, in contrast to outline fonts.
