User interface (UI) design or user interface engineering is the design of user interfaces for machines and software, such as computers, home appliances, mobile devices, and other electronic devices, with the focus on maximizing usability and the user experience. In computer or software design, user interface (UI) design primarily focuses on information architecture: the design of the interface aims to make the user's interaction as simple and efficient as possible, in terms of accomplishing user goals (user-centered design).

History

Early computers were operated through batch processing and command-line interfaces. The graphical user interface, pioneered at Xerox PARC in the 1970s with the Xerox Alto, popularized direct manipulation with windows, icons, menus, and a pointer (WIMP). The Apple Macintosh (1984) and Microsoft Windows brought GUIs to mass markets. Touch interfaces after the iPhone (2007) and, more recently, voice and gestural interfaces have broadened the discipline.

Principles

Widely cited guidelines include Jakob Nielsen's ten usability heuristics (visibility of system status, match with the real world, user control and freedom, consistency, error prevention, recognition over recall, flexibility, aesthetic and minimalist design, error recovery, and help/documentation) and Don Norman's concepts of affordances, signifiers, mapping, and feedback from The Design of Everyday Things (1988).

Process

UI design typically proceeds through research and user requirements analysis, information architecture, wireframing and prototyping, visual design (layout, typography, color, iconography), and usability testing with representative users, iterating on findings. Accessibility standards such as the Web Content Accessibility Guidelines (WCAG) inform design for users with disabilities.
