Forbidden subgraph problem

The forbidden subgraph problem is one of the central problems in extremal graph theory. Given a graph H, the problem asks for the maximum number of edges ex(n, H) in an n-vertex graph that does not contain H as a subgraph (such a graph is called H-free). This maximum number is called the Turán number of H.

The problem seeks the densest graph avoiding a given subgraph.

Classical results

Turán's theorem (1941) determines ex(n, Kr+1) exactly: the extremal graph is the complete r-partite Turán graph with parts as equal as possible. The Erdős–Stone theorem generalises this asymptotically, showing that the extremal number is governed by the chromatic number of H. For bipartite H the problem is much harder; the Kővári–Sós–Turán theorem gives upper bounds, and exact values are known only in special cases, such as for even cycles and complete bipartite graphs K2,t.

Related problems

Variants include the forbidden subgraphs problem for induced subgraphs, the saturation problem (finding sparse H-free graphs that gain H when any edge is added), and the generalised Turán problem, which counts copies of another graph F in an H-free graph. The problem connects to the Zarankiewicz problem for bipartite subgraphs and to extremal problems for hypergraphs.
