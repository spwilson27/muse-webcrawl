Security token

A security token is a physical or digital device that an authorised user of a computer service carries or controls to ease authentication. Security tokens are one factor in two-factor and multi-factor authentication, representing "something you have".

Types

Physical tokens include disconnected key-fob devices that display one-time passwords changing every 30–60 seconds, connected tokens such as smart cards and USB keys, and software tokens running as apps on a phone. Modern standards include FIDO2/WebAuthn security keys, which use public-key cryptography and resist phishing by binding credentials to the origin site.

Use

Tokens are widely used in banking, corporate VPNs and government systems. Their security depends on protecting the shared secret or private key stored in the device; lost or stolen tokens must be revoked and reissued.

In finance and blockchain contexts, the term security token is also used for a digital token that represents ownership of a regulated financial security.
