Home Run Derby

From Wikipedia, the free encyclopedia

The Home Run Derby is held on the Monday before the MLB All-Star Game.

The Home Run Derby is an annual home run hitting competition in Major League Baseball (MLB) customarily held the day before the MLB All-Star Game, which places the contest on a Monday in July. Since the inaugural derby in 1985, the event has been seen as one of great popularity, with television ratings sometimes rivalling the All-Star Game itself.

Format

Eight leading power hitters compete in a timed, bracket-style tournament. Since 2015, batters have had a set time (currently three minutes in early rounds, two minutes in the final) to hit as many home runs as possible, with bonus time or bonus outs awarded for especially long home runs; earlier formats limited batters by "outs" (any swing not producing a home run). Winners of each head-to-head pairing advance until a champion is crowned.

Records and notable winners

Ken Griffey Jr. won the event a record three times (1994, 1998, 1999). Other multiple champions include Prince Fielder, Yoenis Céspedes, Robinson Canó, Giancarlo Stanton, Aaron Judge, Pete Alonso (twice) and Albert Pujols's record appearances. Vladimir Guerrero Jr. set a single-event record with 91 home runs in 2019, losing the final to Alonso. Julio Rodríguez hit a single-round record 41 home runs in 2023. The 2019 derby also featured an epic swing-off between Guerrero and Joc Pederson.

The name and concept originate from the 1960 television series Home Run Derby, in which stars such as Mickey Mantle and Willie Mays competed head-to-head.
