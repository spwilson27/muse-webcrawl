SMILES

Full nameSimplified Molecular Input Line Entry System
Introduced1980s (Daylight Chemical Information Systems)
PurposeText encoding of molecular structure

SMILES (Simplified Molecular Input Line Entry System) is a specification for describing the structure of chemical molecules using short ASCII strings. A SMILES string encodes atoms, bonds, branching and ring closures in a linear notation, allowing structures to be stored in databases and exchanged between cheminformatics programs.

Notation

Atoms are written as their element symbols (organic subset elements such as C, N, O may be written without brackets). Single, double, triple and aromatic bonds are written as –, =, # and lowercase aromatic atom symbols respectively; omitted bond symbols imply single or aromatic bonds. Branches are enclosed in parentheses, and ring closures are marked by matching digits. For example, ethanol is "CCO", benzene is "c1ccccc1", and acetic acid is "CC(=O)O". Extensions describe stereochemistry (using / and \ for double-bond geometry and @ symbols for chirality) and isotopes (in brackets).

Variants and use

Canonical SMILES assign a unique string to each structure, enabling database indexing; "isomeric SMILES" include stereochemical information. SMILES is widely used in chemical databases such as PubChem and ChEMBL and as input to machine-learning models of molecules. Related notations include InChI and SMARTS, a pattern language built on SMILES for substructure searching.
