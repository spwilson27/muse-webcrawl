Rank (linear algebra)

From Wikipedia, the free encyclopedia

In linear algebra, the rank of a matrix A is the dimension of the vector space generated (spanned) by its columns. This corresponds to the maximal number of linearly independent columns of A. Equivalently, it equals the dimension of the row space of A, since the column rank always equals the row rank — one of the fundamental facts of linear algebra. The rank also equals the dimension of the image of the associated linear map, and it enters the rank–nullity theorem: for an m × n matrix, rank + nullity = n.

Equivalent definitions

The rank can be characterised in several ways: (1) the dimension of the column space; (2) the dimension of the row space; (3) the size of the largest nonzero minor (determinant of a square submatrix); (4) the number of pivots in row echelon form; and (5) the number of nonzero singular values in a singular value decomposition. A matrix is said to have full rank if its rank equals the smaller of its numbers of rows and columns; a square matrix is invertible if and only if it has full rank (rank n).

Properties

  • rank(A) ≤ min(m, n).
  • rank(AB) ≤ min(rank A, rank B); Sylvester's rank inequality gives a lower bound for products.
  • Rank is unchanged by multiplication by invertible matrices, and by elementary row or column operations.
  • rank(A) + dim(null A) = n (rank–nullity theorem).
  • A system Ax = b is consistent if and only if rank(A) = rank([A | b]) (Rouché–Capelli theorem).

Computing the rank

In practice, rank is computed by Gaussian elimination to row echelon form, counting pivots. For floating-point computation the singular value decomposition is preferred, since the rank is notoriously sensitive to small numerical perturbations: matrices that are exactly rank-deficient are dense in the space of all matrices, so a numerical "rank" is usually defined by thresholding singular values.

Applications

Rank measures the effective number of independent variables or equations in a system. It is used in control theory (controllability and observability), statistics (the rank of design and covariance matrices), computer vision (the rank-2 fundamental matrix), and data science, where low-rank approximation underlies recommender systems and principal component analysis.
