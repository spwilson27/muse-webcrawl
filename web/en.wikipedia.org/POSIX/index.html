The Portable Operating System Interface (POSIX; IPA: /ˈpɒz.ɪks/) is a family of standards specified by the IEEE Computer Society for maintaining compatibility between operating systems. POSIX defines both the system- and user-level application programming interfaces (APIs), along with command line shells and utility interfaces, for software compatibility (portability) with variants of Unix and other operating systems.

Contents of the standard

POSIX.1, the core specification, defines a C-language interface to services such as process creation and control (fork, exec), file and directory operations, pipes, signals, threads (pthreads), scheduling, clocks, sockets, and inter-process communication. Related standards cover the shell command language (derived from the Bourne shell tradition) and several hundred standard utilities such as grep, awk, sed, and make, along with their options and output formats. The specifications are developed jointly by the Austin Group, and the same text is published as an IEEE standard, an Open Group standard, and ISO/IEC 9945.

History

The project grew out of efforts in the 1980s to unify the diverging Unix variants of AT&T (System V) and Berkeley (BSD). The first standard, IEEE Std 1003.1-1988, followed the work of the /usr/group and other industry bodies. The name "POSIX" was suggested by Richard Stallman and adopted by the IEEE. Successive editions consolidated the real-time, threads, and utility standards; a major revision in 2001 merged POSIX with the Single UNIX Specification, and further editions appeared in 2004, 2008, 2017, and 2024.

Compliance

Fully certified POSIX-compliant systems have included commercial Unixes such as macOS (certified as a UNIX system since version 10.5 on Intel), AIX, HP-UX, and Solaris. Linux and the BSD systems are largely POSIX-compatible without pursuing formal certification in most distributions. Microsoft Windows has offered POSIX subsystems historically (such as Interix/SFU), and the Windows Subsystem for Linux provides a Linux environment within Windows.
