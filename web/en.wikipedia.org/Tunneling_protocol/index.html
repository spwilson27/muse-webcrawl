Tunneling protocol

In tunneling, a payload protocol is encapsulated inside a delivery protocol so it can traverse a network it could not otherwise cross.

In computer networks, a tunneling protocol is a communication protocol that allows the movement of data from one network to another by encapsulating the payload of one protocol (the "passenger" or payload protocol) within the packets of another (the "delivery" protocol). The tunneled data can cross intermediate networks that do not support the payload protocol directly, or can be carried securely across an untrusted network such as the public Internet.

How tunneling works

The transmitting endpoint of the tunnel encapsulates each packet of the payload protocol inside a new packet with a header of the delivery protocol, and sends it across the intermediate network. The receiving endpoint strips the outer header and forwards the original packet onto its destination network. To the payload packets, the tunnel appears to be a single link, regardless of how many hops the delivery packets traverse.

Uses

  • Virtual private networks (VPNs): Protocols such as IPsec, OpenVPN, WireGuard, PPTP and L2TP tunnel private traffic across the public Internet, usually with encryption.
  • Protocol transition: IPv6 traffic is tunneled over IPv4 networks (and vice versa) with mechanisms such as 6to4, Teredo and 6in4.
  • Carrying incompatible protocols: Tunnels carry multicast traffic, legacy protocols, or traffic between separated segments of a network (for example GRE, VXLAN and MPLS-based services in provider networks).
  • Bypassing restrictions: SSH port forwarding and HTTP tunnels can carry traffic through firewalls, sometimes legitimately for administration and sometimes to evade policy.

Examples

Widely used tunneling protocols include the Generic Routing Encapsulation (GRE), IP-in-IP, L2TP, SSTP, IPsec tunnel mode, and SSH tunnels. Tunneling adds overhead (extra headers reduce the effective MTU, sometimes causing fragmentation) and can complicate troubleshooting, but it remains one of the most versatile tools in network engineering.
