Univalence axiom

Univalence identifies equivalences between types with identities between them.

FieldMathematical logic, type theory
Proposed byVladimir Voevodsky
Related toHomotopy type theory, Martin-Löf type theory

In the foundations of mathematics, the univalence axiom is a principle introduced by Vladimir Voevodsky stating that equivalent mathematical objects can be identified — more precisely, that identity between types is equivalent to equivalence between those types. It is a central axiom of homotopy type theory and the univalent foundations program.

Statement

In Martin-Löf dependent type theory, given a universe U and types A, B : U, there is a canonical map from the identity type (A = B) to the type of equivalences (A ≃ B), sending the reflexivity proof to the identity equivalence. The univalence axiom asserts that this canonical map is itself an equivalence. Informally: "equivalent types are identical."

Consequences

Univalence implies function extensionality and propositional extensionality, and it makes it possible to transport structure along equivalences in a systematic way — a formal counterpart to the informal mathematical practice of treating isomorphic structures as the same. It also implies that the identity type of a universe behaves like a space of types, supporting the homotopical interpretation of type theory, in which types are spaces, terms are points, and identity proofs are paths.

History and status

Voevodsky proposed the axiom in the mid-2000s and developed a simplicial set model showing its consistency relative to ZFC with inaccessible cardinals. Univalence is taken as an axiom in the reference text Homotopy Type Theory: Univalent Foundations of Mathematics (2013) and is postulated or supported in proof assistants such as Coq, Agda, and Lean. In cubical type theories, univalence can be given computational content and proved as a theorem rather than assumed.
