Microsoft Edge is a cross-platform web browser developed by Microsoft. Released in 2015 as the successor to Internet Explorer, it is the default browser on Windows. The original version was built on Microsoft's own EdgeHTML engine, but in January 2020 Microsoft relaunched Edge based on the open-source Chromium project, the same foundation as Google Chrome.

History

Edge debuted with Windows 10, positioned as a faster, more standards-compliant replacement for Internet Explorer. Despite improvements, its market share remained low. In December 2018 Microsoft announced it would rebuild Edge on Chromium, contributing to the upstream project; the new Edge shipped in 2020 for Windows and macOS, followed by Linux, and replaced the legacy version. Internet Explorer was retired in June 2022, with Edge's "IE mode" preserving compatibility for legacy enterprise sites.

Features

Edge includes vertical tabs, collections for organising web content, a built-in PDF reader, tracking prevention, and shopping and password-management tools. Since 2023 it has integrated Microsoft Copilot, an AI assistant based on large language models, along with image generation and other AI features built around Bing.

Reception and market share

The Chromium-based Edge has been praised for performance and compatibility and has become the second most used desktop browser worldwide, though it trails Chrome by a wide margin.
