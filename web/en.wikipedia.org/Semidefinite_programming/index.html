Semidefinite programming

Semidefinite programming (SDP) is a subfield of convex optimization concerned with the optimization of a linear objective function over the intersection of the cone of positive semidefinite matrices with an affine subspace. It generalises linear programming, in which the variables are nonnegative vectors, to the case where the variables are symmetric matrices required to be positive semidefinite.

Formulation

A semidefinite program in standard form asks to maximise the inner product ⟨C, X⟩ subject to linear constraints ⟨Ai, X⟩ = bi and X ⪰ 0, meaning X is a symmetric positive semidefinite matrix. Every linear program can be written as an SDP by taking the matrices to be diagonal, so SDP is at least as general as LP; many problems in control theory expressed as linear matrix inequalities (LMIs) can also be cast as SDPs.

Duality and algorithms

SDPs enjoy a duality theory similar to that of linear programming, although strong duality requires a regularity condition such as Slater's condition (strict feasibility). Since the work of Nesterov and Nemirovski in the early 1990s, SDPs have been solvable in polynomial time by interior-point methods, which follow a central path defined by a self-concordant barrier function for the positive semidefinite cone. First-order methods and specialised solvers are used for very large instances.

Applications

SDPs arise as relaxations of hard combinatorial problems: Goemans and Williamson used an SDP relaxation to obtain a 0.878-approximation for MAX-CUT. Other applications include robust control synthesis, truss and structural design, polynomial optimisation via sum-of-squares decompositions, sensor network localisation, and entanglement detection in quantum information theory.
