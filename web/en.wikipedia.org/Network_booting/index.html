Network booting

Network booting, shortened as netboot, is the process of booting a computer from a network rather than a local drive. This method of booting can be used by routers, diskless workstations and centrally managed computers, such as public computers at libraries and schools.

Process

Network booting is typically initiated by firmware on the client machine, most commonly using the Preboot Execution Environment (PXE) built into the network interface controller or motherboard firmware. The client broadcasts a DHCP request, and the responding server supplies not only an IP address but also the location of a boot server and a network bootstrap program (NBP). The client downloads the bootstrap program, usually over TFTP, executes it, and then loads the operating system kernel and initial filesystem from the network.

Uses

Netbooting is widely used for automated operating-system installation and deployment in data centres and enterprises, for diskless workstations and thin clients, for running live recovery and diagnostic environments, and for booting clusters of identical machines from a single maintained image. Related protocols and systems include BOOTP, iPXE, gPXE, and Apple's NetBoot.

Advantages and disadvantages

Centralised images simplify administration, backup and security, and allow machines without local storage. The disadvantages include dependence on the network and boot servers, slower loading of large images, and additional security considerations, since classic PXE/TFTP provides little authentication.
