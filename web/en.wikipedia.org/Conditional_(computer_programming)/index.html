Conditional (computer programming)

Flowchart of an if–then–else conditional.

In computer science, conditionals (that is, conditional statements, conditional expressions, and conditional constructs) are programming language constructs that perform different computations depending on whether a programmer-specified Boolean condition evaluates to true or false. Conditionals are one of the fundamental control-flow mechanisms, allowing a program to branch rather than executing instructions strictly in sequence.

If statements

The most common conditional construct is the if statement, which executes a block of code only when its condition is true. Most languages provide an else clause executed when the condition is false, and an else if chain for multi-way decisions. A compact expression form, the ternary operator (condition ? value_if_true : value_if_false) in C-like languages, yields a value based on a condition and is common in assignments.

Case and switch statements

Many languages offer a switch or case statement that selects among alternatives by comparing an expression against a set of constant patterns. Modern languages extend this to pattern matching, where the structure of data can be tested and decomposed in each branch, as in ML, Haskell, Rust, and recent versions of Python and Java.

Semantics and implementation

At the machine level, conditionals are implemented with conditional branch instructions that alter the program counter. Processors use branch prediction to guess the outcome and keep the instruction pipeline full, so unpredictable branches can be costly. Compilers may convert short branches into conditional moves or predicated execution. Logically, conditionals correspond to the material conditional and to decision procedures in flowcharts; structured programming theory shows that sequence, selection (conditionals), and iteration suffice to express any computable function.
