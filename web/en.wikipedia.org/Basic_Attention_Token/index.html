Basic Attention Token

The Basic Attention Token (BAT) is an Ethereum-based cryptocurrency token used in the Brave web browser ecosystem to reward users, publishers and advertisers for attention in digital advertising.

History

BAT was launched in an initial coin offering in 2017 by Brave Software, co-founded by Brendan Eich. Users opt in to privacy-preserving ads and earn BAT.

Model

The token is intended to align incentives: users are compensated, publishers receive revenue shares, and advertisers get better measurement without invasive tracking.
