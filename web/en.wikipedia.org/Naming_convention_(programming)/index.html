Naming convention (programming)

A naming convention in computer programming is a set of rules for choosing the character sequence used for identifiers that denote variables, types, functions and other entities in source code. Conventions improve readability, make code self-documenting, and help programmers infer an identifier's type or scope at a glance.

Other systems

Hungarian notation encodes an identifier's type or intended use in a prefix, such as strName or bReady; it was widely used in Windows programming. Many style guides also prescribe prefixes or suffixes for member variables (e.g. trailing underscores in C++), boolean names phrased as questions (isValid), and consistent verb-noun patterns for methods. Consistent naming reduces cognitive load and is considered a core element of code style and maintainability.
