Turán graph

The Turán graph T(13, 4)

The Turán graph T(n, r), named for the Hungarian mathematician Pál Turán, is the complete multipartite graph formed by partitioning a set of n vertices into r subsets as equal in size as possible, and connecting two vertices by an edge if and only if they belong to different subsets. It is the unique extremal graph in Turán's theorem.

Turán's theorem

Turán's theorem (1941) states that any graph on n vertices that does not contain a complete graph Kr+1 as a subgraph has at most as many edges as the Turán graph T(n, r), and that T(n, r) is the unique such extremal graph. The maximum number of edges is often written ex(n, Kr+1). As a special case, Mantel's theorem (1907) gives the maximum number of edges in a triangle-free graph as ⌊n²/4⌋, attained by the complete bipartite graph T(n, 2).

Properties

In T(n, r), part sizes differ by at most one: if n = qr + s with 0 ≤ s < r, then s parts have q + 1 vertices and r − s parts have q vertices. The graph has chromatic number r, contains cliques of size r but none of size r + 1, and its complement is a disjoint union of cliques (a cluster graph).

Significance

Turán's theorem founded extremal graph theory, the study of how large or dense a graph can be while avoiding a given configuration. It is closely related to Turán's theorem in graph theory, Turán-type problems for other forbidden subgraphs, and to Turán's work on the extremal problem that also inspired the Erdős–Stone theorem.
