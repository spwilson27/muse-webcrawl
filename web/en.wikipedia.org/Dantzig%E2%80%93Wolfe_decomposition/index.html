Dantzig–Wolfe decomposition

Dantzig–Wolfe decomposition is a technique in mathematical programming, introduced by George Dantzig and Philip Wolfe in 1960, for solving large linear programs with a special block-angular structure. The feasible region is decomposed into a set of independent subproblems (blocks) linked by a small set of coupling constraints, together with convexity constraints expressing that each block's contribution is a convex combination of its extreme points.

Method

The reformulated "master problem" coordinates the subproblems: it works with columns (extreme points) generated on demand by the subproblems, rather than with all variables at once. Given dual prices from the master problem, each subproblem optimises its own block and returns a new column if one can improve the master solution. This delayed column generation is the conceptual ancestor of modern column-generation methods used in vehicle routing, crew scheduling, and cutting-stock problems.

Significance

Decomposition allowed problems far too large for the computers of the era to be solved by splitting them into tractable pieces, and it anticipated later distributed and Lagrangian approaches to large-scale optimisation.
