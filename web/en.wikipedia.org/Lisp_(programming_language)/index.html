Lisp (programming language)

Lisp (historically LISP) is a family of programming languages with a long history and a distinctive, fully parenthesized prefix notation. Originally specified in 1958 by John McCarthy, it is the second-oldest high-level language still in common use, after Fortran.

Features

Lisp code is written as S-expressions: nested lists in parentheses. Code and data share the same representation (homoiconicity), enabling powerful macros. The language pioneered conditionals, recursion, dynamic typing, garbage collection and the read–eval–print loop.

Dialects

Major dialects include Common Lisp, Scheme, Racket, Clojure and Emacs Lisp. Lisp was central to early artificial intelligence research and influenced many later languages.

Example

(defun factorial (n) (if (zerop n) 1 (* n (factorial (- n 1))))) defines a recursive factorial function.

Influence

Ideas from Lisp — garbage collection, first-class functions, REPLs — are now mainstream in modern programming languages.
