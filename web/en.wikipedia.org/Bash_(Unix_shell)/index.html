Bash (Unix shell)

Bash, short for Bourne Again Shell, is a command language and shell program for Unix-like operating systems, developed as part of the GNU Project by Brian Fox and released in 1989.

Features

Bash is compatible with the Bourne shell (sh) and incorporates features from the Korn shell and C shell, including command-line editing, history, job control, aliases, functions and scripting constructs.

Use

It has been the default login shell for most Linux distributions and was the default on macOS for many years.

Scripting

Bash scripts automate system administration and development tasks, though larger programs are often written in other languages.
