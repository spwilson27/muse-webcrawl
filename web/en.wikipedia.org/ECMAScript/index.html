ECMAScript

ECMAScript (ES) is a standard for scripting languages, including JavaScript, JScript, and ActionScript. It is best known as the standard underlying JavaScript, the programming language of the Web. The standard is maintained by Ecma International in specification ECMA-262, and developed by the TC39 committee.

History

In 1996 Netscape submitted JavaScript, created by Brendan Eich in 1995, to Ecma International for standardization in order to counter Microsoft's competing JScript. The first edition of ECMA-262 was adopted in June 1997. Subsequent major editions include ES3 (1999), ES5 (2009) and the landmark ES6 (2015), officially called ECMAScript 2015, which added classes, modules, arrow functions, promises, template literals and let/const declarations. Since 2015, new editions have been published annually, named ECMAScript 2016, 2017 and so on.

Conformance

A conforming implementation of ECMAScript must provide and support all the types, values, objects, properties, functions and program syntax described in the specification. JavaScript engines such as V8, SpiderMonkey and JavaScriptCore implement the standard, and features progress through TC39 stages from proposal (stage 0) to finished (stage 4) before inclusion in the yearly edition.
