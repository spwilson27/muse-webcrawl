Replacement character

The replacement character, U+FFFD � REPLACEMENT CHARACTER, is a symbol in Unicode used to indicate a problem when a system is unable to decode a stream of data into a known character. It is commonly rendered as a black diamond containing a white question mark.

Usage

Decoders for character encodings such as UTF-8 emit the replacement character when they encounter invalid byte sequences, missing data, or unassigned code points. The Unicode standard recommends substituting U+FFFD for each maximal subpart of an ill-formed subsequence.

Display

Its typical glyph — a black rhombus with a white question mark — is widely recognised as a sign of mojibake or corrupted text. Some systems instead display an empty box, a question mark, or nothing at all.
