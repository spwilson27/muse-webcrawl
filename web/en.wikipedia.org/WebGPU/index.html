WebGPU is a web standard and JavaScript API that provides access to the graphics processing unit (GPU) of a device from web applications, enabling high-performance 3D graphics rendering and general-purpose parallel computation (GPGPU). It is the successor to WebGL and is modelled on modern native graphics APIs such as Vulkan, Metal and Direct3D 12, exposing capabilities — including compute shaders — that WebGL lacked.

Design

WebGPU programs are written in JavaScript (or compiled from other languages via WebAssembly), with shaders written in the WebGPU Shading Language (WGSL). Unlike WebGL's stateful design, WebGPU uses explicit pipeline and command-buffer objects, reducing driver overhead and making rendering behaviour more predictable across platforms. The API is designed with security in mind, since web content is untrusted: resources are isolated and validated to prevent GPU-level exploits.

History and support

Development began in 2016–2017 within the W3C's "GPU for the Web" community group, with Apple, Google, Microsoft and Mozilla participating; Apple's WebMetal proposal was an early influence. Google shipped WebGPU by default in Chrome 113 in April 2023 on Windows, macOS and ChromeOS, with Firefox and Safari adding support in subsequent releases. Implementations map WebGPU onto Metal, Direct3D 12 or Vulkan underneath.

Applications

Beyond games and 3D visualisation, WebGPU's compute shaders enable machine-learning inference in the browser (for example via libraries such as TensorFlow.js), image and video processing, and scientific simulation — workloads previously impractical in web pages.
