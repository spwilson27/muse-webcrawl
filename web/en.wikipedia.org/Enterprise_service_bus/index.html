Enterprise service bus

An enterprise service bus (ESB) is a software architecture and middleware pattern in service-oriented architecture that routes, transforms and mediates messages between applications through a central bus.

Functions

An ESB typically provides message routing, protocol and format transformation, service orchestration, security and monitoring, decoupling producers from consumers.

Criticism and evolution

Critics argue heavyweight ESBs can become bottlenecks and single points of failure; many organisations have moved toward lightweight APIs, microservices and event streaming, while ESB products remain common in large enterprises.
