Ramanujan summation

Ramanujan summation is a technique invented by the mathematician Srinivasa Ramanujan for assigning a value to divergent infinite series. Although not a sum in the traditional sense, it produces finite values for certain divergent series that are useful in number theory and physics.

Definition

The method is closely related to the Euler–Maclaurin summation formula and analytic continuation. Famously, Ramanujan assigned the value −1/12 to the series 1 + 2 + 3 + 4 + ⋯, a result consistent with the Riemann zeta function evaluated at −1, ζ(−1) = −1/12.

Applications

Ramanujan summation and related regularisation methods appear in string theory, quantum field theory (for example in computing the Casimir effect), and analytic number theory.
