V-Model (software development)

The V-model is a software development process model that pairs each phase of specification and design (the descending left arm of the V) with a corresponding phase of testing and validation (the ascending right arm), with implementation at the bottom.

Structure

Requirements definition corresponds to acceptance testing; system design to system testing; detailed (module) design to integration testing; and coding to unit testing. Each test phase is planned in parallel with its design counterpart, so defects are considered from the start.

Use

The V-model is widely used in regulated and safety-critical industries, such as automotive and medical devices, where the German government adopted a standardized version (the V-Modell) for public IT projects. Critics note its rigidity compared with iterative and agile methods.
