Sensitivity (test)

In medical and diagnostic testing, sensitivity is the ability of a test to correctly identify those with a condition (the true positive rate). It is defined as the proportion of actual positives that are correctly identified: sensitivity = TP / (TP + FN), where TP are true positives and FN are false negatives.

Relationship to specificity

Sensitivity complements specificity, the true negative rate. A highly sensitive test rarely misses a case, so a negative result on such a test effectively rules a condition out (mnemonic "SnNout"); a highly specific test rarely yields false positives, so a positive result rules a condition in ("SpPin"). Adjusting a test's threshold typically trades sensitivity against specificity, summarised by the ROC curve.

Example

If 100 patients have a disease and a test detects 95 of them, its sensitivity is 95%. The five missed cases are false negatives.
