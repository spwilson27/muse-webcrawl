Range encoding

TypeEntropy encoding / lossless data compression
Described byG. Nigel N. Martin (1979)
RelatedArithmetic coding
UsesEntropy stage of compressors and codecs (e.g. PAQ-family, some video codecs)

Range encoding is a form of entropy encoding used in lossless data compression. It was defined by G. Nigel N. Martin in a 1979 paper and is effectively a rediscovery and generalisation of the earlier FIFO arithmetic coding concept. Range encoding encodes an entire message as a single interval of numbers, much like arithmetic coding, but performs the arithmetic using larger, byte-oriented chunks of the output stream, which makes it fast in software.

How it works

The encoder maintains a current range (interval), initially [0, 1). For each symbol, the interval is subdivided in proportion to the symbol's estimated probability, and the subinterval corresponding to the actual symbol is selected. As the interval shrinks, its leading digits become determined and can be emitted. Implementations keep the range as a fixed-width integer (commonly 32 bits), outputting the top byte whenever the range grows small and renormalising — a trick that avoids the arbitrary-precision arithmetic of classical arithmetic coding.

Relation to arithmetic coding

Range coding and arithmetic coding are mathematically almost identical; many authors treat them as different implementations of the same method. Range encoding attracted attention historically because key arithmetic-coding patents did not clearly cover it, and implementations such as those in the PAQ data compression family and various image and video codecs have used range coders as their entropy stage.
