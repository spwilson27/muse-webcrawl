Impersonal passive voice

In an impersonal passive, no object is promoted to subject; the agent is simply suppressed.
CategoryGrammatical voice construction
Related toPassive voice, impersonal verb
Examples inGerman, Dutch, Latin, Turkish, Celtic languages, Polish
Key featurePassive of intransitive verbs; no subject promotion

The impersonal passive voice is a verb construction in which the passive voice is applied to a verb — often an intransitive one — without promoting any object to the position of grammatical subject. The result is a clause that reports an action while leaving its performer wholly unspecified, as in German Es wird getanzt ("There is dancing", literally "It is danced").

Characteristics

In an ordinary ("personal") passive, the object of an active sentence becomes the subject: "The letter was written." Intransitive verbs have no object to promote, so many languages — English among them — cannot passivise them at all. Languages with the impersonal passive simply present the event itself as the focus. The verb typically takes default (third-person singular neuter) agreement, and some languages insert a dummy or expletive subject to fill the subject position.

Examples across languages

  • German: Hier wird gearbeitet — "Work is done here / People work here."
  • Dutch: Er wordt gedanst — "There is dancing."
  • Latin: Itur — "There is going; people are on the move"; Pugnatum est — "There was fighting."
  • Polish: a related function is served by the impersonal -no/-to forms, e.g. Mówiono o tym — "It was talked about."
  • Irish and Welsh: an "autonomous" verb form marks an unspecified subject, usable with intransitives.

Impersonal passives of transitive verbs

Some languages also allow a transitive verb to appear in an impersonal passive in which the object remains in the accusative case rather than being promoted, so the clause still has no true subject. Such constructions underline that the essential effect of the passive, cross-linguistically, is the demotion or suppression of the agent — promotion of the object is a separate, optional feature.
