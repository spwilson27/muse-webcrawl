GUID Partition Table

Layout of a GPT disk, with LBA 0 holding the protective MBR

The GUID Partition Table (GPT) is a standard for the layout of partition tables of a physical computer storage device, such as a hard disk drive or solid-state drive, using universally unique identifiers (UUIDs, also known as globally unique identifiers, GUIDs). It forms part of the Unified Extensible Firmware Interface (UEFI) standard and replaced the Master Boot Record (MBR) partitioning scheme that dated from the early 1980s.

Features

GPT uses 64-bit logical block addressing, allowing disks far larger than MBR's 2.2 terabyte limit (with 512-byte sectors); the theoretical maximum is 8 zebibytes. A GPT disk by default supports up to 128 partitions in Windows (the table has room for 128 entries), instead of MBR's four primary partitions. Every partition has its own unique GUID and a partition-type GUID, and names of up to 36 Unicode characters are supported.

Structure and integrity

Logical block 0 contains a "protective MBR" so that legacy tools see a valid, disk-spanning partition and do not overwrite the GPT structures. The primary partition table header and entries sit at the start of the disk, and a backup header and table are stored at the end, providing redundancy. CRC32 checksums protect the header and the partition table, allowing firmware and operating systems to detect corruption and recover from the backup copy.

Adoption

GPT is required for booting in UEFI mode on most modern systems and is the default partitioning scheme for new installations of Windows, macOS (which adopted it with the move to Intel processors), and Linux distributions.
