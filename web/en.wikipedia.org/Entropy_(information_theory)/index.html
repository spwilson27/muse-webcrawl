Entropy (information theory)

In information theory, the entropy of a random variable is the average level of "information", "surprise", or "uncertainty" inherent in the variable's possible outcomes. Introduced by Claude Shannon in his 1948 paper "A Mathematical Theory of Communication", it is defined for a discrete random variable X with possible values {x1, …, xn} as H(X) = −Σ p(xi) log2 p(xi), measured in bits when the logarithm is base 2.

Interpretation

Entropy quantifies the expected value of the information contained in a message. A fair coin has an entropy of one bit per toss; a biased coin has less, because its outcomes are more predictable. Shannon's source coding theorem shows that entropy is the fundamental limit on lossless data compression: no code can represent the source using, on average, fewer bits per symbol than its entropy.

Example

For a binary variable with probabilities p and 1 − p, the binary entropy function Hb(p) = −p log2 p − (1 − p) log2 (1 − p) rises from 0 at p = 0 or 1 to a maximum of 1 bit at p = 0.5, illustrating that uncertainty is greatest when outcomes are equiprobable.

Related concepts

Joint entropy, conditional entropy, mutual information and relative entropy (Kullback–Leibler divergence) extend the basic definition to pairs of variables and to comparisons between distributions. These quantities underpin modern data compression, error-correcting codes, cryptography and machine learning.
