WebP

Filename extension: .webp
Internet media type: image/webp
Developed by: Google
Initial release: 30 September 2010
Type of format: Image file format with lossy and lossless compression

WebP provides superior lossless and lossy compression for images on the web.

WebP is a raster graphics file format developed by Google intended as a replacement for JPEG, PNG, and GIF file formats. It supports both lossy and lossless compression, as well as animation and alpha transparency.

Google announced the WebP format in September 2010, and released the first stable version of its supporting library in April 2018. Support for the format has since increased, though it has been criticized for a lack of certain common features and missing support on some platforms.

Technology

WebP's lossy compression is based on the VP8 video codec's intra-frame coding: it uses predictive coding to encode an image, exploiting redundancy within blocks. Lossless WebP uses an LZ77-based algorithm with local cache of recently used colors and fragments of the image. According to Google, lossless WebP images are on average 26% smaller than comparable PNGs, and lossy WebP images are 25–34% smaller than comparable JPEGs at equivalent quality indices.

Adoption

WebP is natively supported in Google Chrome, Safari, Firefox, Edge, and the Opera browser, and by many other tools and software libraries. Google's own services, including YouTube and Google Photos, serve WebP extensively to reduce bandwidth. The format is based on the RIFF container and has the filename extension .webp.
