Cron

Cron is a time-based job scheduler in Unix-like operating systems. Users who set up and maintain software environments use cron to schedule jobs (commands or shell scripts), also known as cron jobs, to run periodically at fixed times, dates, or intervals. It typically automates system maintenance or administration — such as backups, log rotation, and updates — though its general purpose nature makes it useful for many other tasks.

Crontab format

Each user has a crontab (cron table) file whose lines each define a job. A line begins with five time-and-date fields — minute (0–59), hour (0–23), day of month (1–31), month (1–12), and day of week (0–7, where both 0 and 7 are Sunday) — followed by the command to run. Asterisks and ranges allow compact expressions; for example, 0 2 * * * runs a job daily at 2:00 a.m. The crontab command installs and edits these files, and the cron daemon checks them every minute for jobs to execute.

History and implementations

A simple cron appeared in Version 7 Unix in 1979; a multi-user version with the modern crontab format was written by Brian Kernighan's group at Bell Labs, and later implementations by Paul Vixie (Vixie cron, 1987) became widespread. Modern alternatives and extensions include cronie, anacron (for machines not running continuously), and systemd timers, but cron remains a standard component of Linux and BSD systems.
