Enhanced Interior Gateway Routing Protocol

Type: Interior gateway protocol

Developer: Cisco Systems

Introduced: 1993

Standard: RFC 7868 (2016)

Enhanced Interior Gateway Routing Protocol (EIGRP) is an advanced distance-vector routing protocol developed by Cisco Systems for automating routing decisions and configuration within an autonomous system. Released in 1993 as the successor to Cisco's Interior Gateway Routing Protocol (IGRP), EIGRP is considered a hybrid protocol, combining features of distance-vector and link-state protocols.

Operation

EIGRP routers discover neighbours using multicast Hello packets and exchange their full routing tables only at first adjacency; afterwards they send only partial updates when a route changes. Loop-free path selection is performed by the Diffusing Update Algorithm (DUAL), which maintains a successor — the best path to each destination — and, where possible, a feasible successor that can take over immediately if the main path fails, giving EIGRP fast convergence.

Metric

The protocol computes a composite metric from bandwidth and delay by default; load, reliability and MTU may also be factored in through weighting constants. EIGRP supports classless addressing, variable-length subnet masks, and both IPv4 and IPv6, and it uses protocol number 88 in the IP header.

Open standardisation

Although long treated as a Cisco proprietary protocol, the basic specification was published as an open standard in RFC 7868 in 2016, and other vendors have since implemented partial support. EIGRP nonetheless remains most common in Cisco-dominated enterprise networks, competing with OSPF and IS-IS.
