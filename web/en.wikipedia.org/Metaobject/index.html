Metaobject

In computer science, a metaobject is an object that manipulates, creates, describes or implements other objects, including itself. The architecture of a language or system that uses metaobjects is often specified by a metaobject protocol (MOP), which defines how the behaviour of the object system can be customised at runtime.

Metaobject protocols

The concept was developed most fully in the Common Lisp Object System (CLOS), whose metaobject protocol — described in the book The Art of the Metaobject Protocol (1991) by Gregor Kiczales, Jim des Rivières and Daniel G. Bobrow — exposes classes, generic functions and slot definitions as objects that programmers can subclass and modify. This allows the semantics of inheritance, method dispatch and instantiation to be extended without changing the language implementation.

Reflection

Metaobjects are closely related to reflection: a reflective system represents its own structures as objects open to inspection and modification. Languages such as Smalltalk, Ruby and Python provide varying degrees of metaobject access through metaclasses, while frameworks in Java and C++ use the term for generated classes describing entities, for example in Qt's meta-object compiler.
