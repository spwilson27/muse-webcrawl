Signalling System No. 7

Signalling System No. 7 (SS7) is a set of telephony signalling protocols developed in 1975 and standardised by the ITU-T in its Q.7xx series of recommendations. It is used to set up and tear down telephone calls, carry caller information, and support services such as roaming, text messaging, and number translation on the public switched telephone network.

Architecture

SS7 uses out-of-band signalling: control messages travel on a separate packet network of signal transfer points rather than in the voice channel. Its protocol stack includes the Message Transfer Part (MTP), the Signalling Connection Control Part (SCCP), and application parts such as ISUP for call control, TCAP for transactions, and MAP for mobile networks.

Security concerns

The SS7 network was designed for a closed circle of trusted operators. Researchers have demonstrated that attackers with SS7 access can intercept calls and messages, track subscribers, and bypass two-factor authentication, prompting the industry to deploy firewalls and monitoring as networks interconnect more widely.
