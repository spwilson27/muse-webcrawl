Timeline of operating systems

This timeline of operating systems records the major developments in operating system software from the batch-processing systems of the 1950s to the mobile and cloud platforms of the present day. An operating system (OS) manages computer hardware and software resources and provides common services for programs; its history runs from resident monitors on mainframes, through minicomputer and personal-computer systems, to the Unix-like and Windows families that dominate today.

1970s–1980s: minicomputers and microcomputers

DEC's VMS (1977) served the VAX minicomputers, while CP/M (1974) became the standard for early microcomputers. The IBM PC (1981) shipped with PC DOS/MS-DOS, and Apple's Macintosh (1984) popularised the graphical user interface, drawing on Xerox PARC research. Microsoft Windows followed in 1985 as a shell over DOS. AmigaOS, OS/2 and the first BSD Unix releases also date to this period.

1990s: networks and the internet

Linus Torvalds released the Linux kernel in 1991, and Linux distributions soon powered servers worldwide. Microsoft moved consumers to the NT architecture with Windows NT (1993), Windows 95 and Windows XP (2001). Apple acquired NeXT and rebuilt its system as Mac OS X (2001) on a Unix foundation. FreeBSD, NetBSD and OpenBSD continued the BSD line.

2000s–present: mobile and beyond

Apple's iOS (2007) and Google's Android (2008), the latter built on the Linux kernel, made Unix-like systems the most numerous computers on earth. Windows, macOS and Linux persist on desktops and servers, while real-time and embedded systems (from QNX to embedded Linux) run vehicles, machinery and the Internet of Things. Containerisation and virtualisation have blurred the role of the OS in cloud computing, but the core families traced above still underpin nearly all of it.
