B − L

QuantityBaryon number minus lepton number
Conserved inStandard Model (perturbatively and non-perturbatively)

In particle physics, B − L (pronounced "bee minus ell") is the difference between the baryon number (B) and the lepton number (L). It is an important quantum number in many extensions of the Standard Model.

Conservation

In the Standard Model, baryon number and lepton number are each conserved only as accidental symmetries: non-perturbative electroweak processes called sphalerons violate B and L individually while preserving B − L exactly. Baryon number is assigned +1/3 to each quark and −1/3 to each antiquark; lepton number is +1 for each lepton and −1 for each antilepton; ordinary matter made of protons and neutrons has B − L equal to the number of neutrons (protons having B − L = 0, since B = 1 and L = 0, while electrons contribute −1 to B − L per electron, cancelling the protons in neutral atoms).

Grand unified theories

Unlike B + L, the quantity B − L is conserved in most grand unified theories. In SO(10) grand unification, B − L is a genuine gauge symmetry, generated by a U(1)B−L subgroup, and all fermions of one generation (including a right-handed neutrino) fit into a single 16-dimensional representation. Breaking of gauged B − L is connected with the seesaw mechanism for generating small neutrino masses.

Baryogenesis

Because sphalerons convert a B + L asymmetry into a baryon asymmetry while preserving B − L, generating the observed matter–antimatter asymmetry of the universe through leptogenesis — creating first a lepton asymmetry (hence a nonzero B − L) at high energies — has become a leading scenario for baryogenesis.
