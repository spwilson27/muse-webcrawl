Network routing

Routing is the process of selecting paths in a computer network along which to send network traffic. In packet-switched networks, routing directs the forwarding of packets from their source toward their destination through intermediate nodes — routers — which consult routing tables to decide each packet's next hop. The routing process is usually performed by dedicated hardware but can also be done by software-based routers.

Routing tables and metrics

A routing table stores, for each destination network, the next hop and a metric used to choose among competing routes: hop count, bandwidth, delay, load, reliability, or monetary cost. Routes may be configured statically by an administrator, or learned dynamically through routing protocols in which routers exchange topology information. Within an autonomous system, interior gateway protocols such as OSPF and IS-IS compute shortest paths with Dijkstra's algorithm, while RIP uses distance-vector logic. Between autonomous systems on the Internet, the Border Gateway Protocol (BGP) exchanges reachability information governed by administrative policy as much as by path length.

Routing versus forwarding

Routing is the control-plane function that builds the routing table; forwarding is the data-plane act of looking up a packet's destination address in that table and sending the packet out the correct interface, typically in hardware at line rate. Routing algorithms aim for loop-free, efficient, and rapidly converging paths that adapt when links or routers fail.

Other schemes

Beyond conventional unicast routing, networks support broadcast, multicast (delivering one stream to a group of receivers), anycast (delivering to the nearest of several identical endpoints), and geocast. Modern developments include software-defined networking, which centralises routing decisions in a controller, and segment routing, which encodes the path in the packet itself.
