Systems integration

Systems integration is the process of bringing together component sub-systems into one system (an aggregation of subsystems cooperating so that the system is able to deliver the overarching functionality) and ensuring that the subsystems function together as a system. In information technology, systems integration is the process of linking together different computing systems and software applications physically or functionally, to act as a coordinated whole.

Methods

Integration approaches include vertical integration, in which subsystems are combined according to their functionality into "silos"; horizontal integration, in which a dedicated subsystem such as an enterprise service bus handles communication between all other subsystems; and integration through a common data format, which avoids the need for each system to translate data for every other system. Star ("spaghetti") integration, connecting every subsystem to every other, tends to become unmanageable as systems grow.

Challenges

Systems integration projects commonly struggle with legacy systems, incompatible data models, differing vendor standards, and organisational boundaries. Integration engineers must address data consistency, error handling, security and performance across the combined system.

Role of the systems integrator

A systems integrator is a person or company that specialises in bringing together component subsystems and building customised solutions, often combining hardware, software and consulting services. Large integrators emerged in the defence, aerospace and enterprise IT industries.
