Deutsch–Jozsa algorithm

The Deutsch–Jozsa algorithm is a quantum algorithm proposed by David Deutsch and Richard Jozsa in 1992. It was among the first examples of a quantum algorithm that is exponentially faster than any possible deterministic classical algorithm for its problem.

The problem

Given a black-box function (oracle) f that takes n-bit strings to a single bit, and that is promised to be either constant (the same output for all inputs) or balanced (output 1 for exactly half the inputs), the task is to determine which. A deterministic classical algorithm may need up to 2n−1 + 1 evaluations in the worst case.

The algorithm

The quantum algorithm solves the problem with a single oracle query. The input qubits are prepared in a superposition using Hadamard gates; the oracle imprints a phase depending on f; a second round of Hadamard gates and a measurement then reveal the answer: measuring all zeros indicates a constant function, and any other result indicates a balanced one.

Significance

Though the problem is artificial and of little practical use, the algorithm demonstrated the power of quantum parallelism and interference, and it directly inspired later breakthroughs such as Shor's algorithm. It built on Deutsch's earlier 1985 algorithm for the single-bit case.
