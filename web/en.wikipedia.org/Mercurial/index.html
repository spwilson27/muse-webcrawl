Mercurial

Original author: Olivia Mackall

Initial release: 19 April 2005

Written in: Python, C, Rust

Type: Distributed version control

License: GPL-2.0-or-later

Mercurial is a distributed revision control tool for software developers. It is supported on Microsoft Windows, Linux, and other Unix-like systems. Mercurial is primarily written in Python, with performance-critical parts implemented in C and increasingly in Rust.

History

Mercurial was created by Olivia Mackall (formerly Matt Mackall) in April 2005, during the period when the Linux kernel project was seeking a replacement for the proprietary BitKeeper system. Mackall announced Mercurial on 19 April 2005, and it was adopted by a number of projects, though Git ultimately became the more widely used system.

Design

Mercurial uses a distributed model in which every working directory contains a complete copy of the repository history. Changes are recorded as changesets identified by SHA-1 (later SHA-256) hashes. The command-line interface is invoked as hg, the chemical symbol for the element mercury.

Adoption

Notable users have included Mozilla, Facebook (Meta), and the Python project itself for a period. Facebook developed large-scale extensions to make Mercurial work with very large monorepositories.
