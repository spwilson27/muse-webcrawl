A website is a collection of related web pages published on a web server.

A website (also written as a web site) is a collection of web pages and related content that is identified by a common domain name and published on at least one web server. Websites are typically dedicated to a particular topic or purpose, such as news, education, commerce, entertainment, or social networking. Hyperlinking between web pages guides the navigation of the site, which often starts with a home page.

Websites can be accessed by users via a public Internet Protocol (IP) network, such as the Internet, or a private local area network (LAN), by referencing a uniform resource locator (URL) that identifies the site. Web pages, which are the building blocks of websites, are typically formatted in HyperText Markup Language (HTML) and styled with Cascading Style Sheets (CSS).

History

The World Wide Web (WWW) was invented by English computer scientist Tim Berners-Lee while at CERN in 1989 and opened to the public in 1991. The first website, info.cern.ch, was dedicated to information about the World Wide Web project itself. By 1994 nearly 3,000 websites existed; by the 2020s the number of websites on the Internet exceeded 1.8 billion, although a large share are inactive.

Static and dynamic websites

A static website stores a fixed version of each page and displays the same information to every visitor; its pages are coded in plain HTML and CSS. A dynamic website can display different content for different users and adjust the page interactively, typically by using a content management system (CMS) and server-side processing. Common content management systems include WordPress, Joomla, and Drupal.

Types of websites

Well-known types include personal websites, commercial websites, government websites, and non-profit organisation websites. Websites can be the work of an individual, a business, or other organisation, and are usually dedicated to a particular topic or purpose. Terms such as "electronic commerce" describe sites devoted to selling goods and services.
