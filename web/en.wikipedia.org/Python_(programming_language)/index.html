Python (programming language)

The Python logo

Python is a high-level, general-purpose programming language. Its design philosophy emphasises code readability with the use of significant indentation. Python is dynamically typed and garbage-collected, and supports multiple programming paradigms, including structured (particularly procedural), object-oriented and functional programming.

History

Python was created in the late 1980s by Guido van Rossum at the Centrum Wiskunde & Informatica in the Netherlands as a successor to the ABC programming language, and was first released in 1991 as Python 0.9.0. Python 2.0 was released in 2000, and Python 3.0, a major revision that is not backward compatible, in 2008. Van Rossum, the language's "benevolent dictator for life" until 2018, named it after the British comedy troupe Monty Python.

Design and features

Python's syntax is designed to be readable and uncluttered; blocks are delimited by indentation rather than braces. It has a large standard library — often described as "batteries included" — and an extensive ecosystem of third-party packages distributed through the Python Package Index (PyPI). The reference implementation, CPython, is written in C; other implementations include PyPy (a just-in-time compiler) and implementations for the JVM and .NET.

Uses and popularity

Python is widely used in web development (frameworks such as Django and Flask), data science and machine learning (NumPy, pandas, TensorFlow, PyTorch), automation and scripting, and scientific computing. It has consistently ranked among the most popular programming languages in indices such as TIOBE and the Stack Overflow developer survey.
