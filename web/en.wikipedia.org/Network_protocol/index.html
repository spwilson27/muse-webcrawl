Network protocol

Network protocol
DefinitionSet of rules governing communication between network devices
Reference modelsOSI model (7 layers); TCP/IP model (4–5 layers)
ExamplesIP, TCP, UDP, HTTP, DNS, Ethernet, Wi-Fi
StandardizationIETF, IEEE, ITU, ISO

A network protocol (or communication protocol) is a set of rules and formats that govern how devices exchange data over a computer network: the syntax of messages, the sequence in which they may be sent, error handling, and timing. Protocols make interoperability possible between equipment and software from different vendors, and are the foundation of the Internet and all modern data networks.

Layering

Protocols are organized into layers, each providing services to the layer above and using the services of the layer below, with each layer encapsulating the data of the one above. The OSI reference model defines seven layers — physical, data link, network, transport, session, presentation, application — while the practical Internet protocol suite uses four or five: link (Ethernet, Wi-Fi), internet (IP), transport (TCP, UDP), and application (HTTP, SMTP, DNS). Layering lets each protocol evolve independently; IP, for example, runs over almost any link technology ("IP over everything"), and almost any application can run over IP.

Essential functions

Protocols variously provide addressing and routing, fragmentation and reassembly, flow and congestion control, reliable delivery with acknowledgments and retransmission (TCP) or best-effort delivery (UDP), encryption and authentication (TLS), naming (DNS), and automatic configuration (DHCP). Protocol design trades off overhead, latency, robustness, and simplicity.

Standardization and history

Early networks used proprietary protocol suites (IBM's SNA, DECnet, Novell's IPX/SPX). The ARPANET moved to TCP/IP on January 1, 1983, and the open, free standards process of the Internet Engineering Task Force — documented in RFCs under the motto "rough consensus and running code" — helped TCP/IP prevail in the "protocol wars" of the 1980s–90s over the formally standardized OSI suite. Protocol analysis today uses tools such as packet analyzers (e.g., Wireshark) and formal verification for critical designs.
