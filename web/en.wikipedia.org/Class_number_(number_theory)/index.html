Class number (number theory)

In algebraic number theory, the class number of a number field is a measure of the failure of unique factorization in its ring of integers. It is defined as the order (size) of the field's ideal class group: the group of fractional ideals modulo principal ideals.

Definition and significance

Although numbers in a ring of integers may not factor uniquely into irreducibles, ideals always factor uniquely into prime ideals. The class number is 1 exactly when every ideal is principal, which in turn is equivalent to unique factorization of elements. Ernst Kummer's work on ideal numbers, and Richard Dedekind's theory of ideals, arose from attempts to prove Fermat's Last Theorem, which foundered on non-unique factorization in cyclotomic fields.

Examples and results

Quadratic fields have been studied intensively since Gauss, who computed class numbers in his theory of binary quadratic forms. The nine imaginary quadratic fields with class number 1 (the Heegner numbers) were determined completely only in the 1960s by Baker and Stark. For real quadratic fields, it remains unknown whether infinitely many have class number 1. Dirichlet's class number formula relates the class number of a quadratic field to values of L-functions, and Minkowski's bound guarantees that the class number is always finite.
