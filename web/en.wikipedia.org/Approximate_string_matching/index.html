Approximate string matching

Approximate string matching (often colloquially referred to as fuzzy string searching) is the technique of finding strings that match a pattern approximately rather than exactly. The problem of approximate string matching is typically divided into two sub-problems: finding approximate substring matches inside a given string, and finding dictionary strings that match the pattern approximately.

Overview

The closeness of a match is measured in terms of the number of primitive operations necessary to convert the match into the exact pattern. The usual primitive operations are insertions, deletions, and substitutions. The minimum number of such operations required to transform one string into another is known as the edit distance, most commonly the Levenshtein distance. Other measures include the Damerau–Levenshtein distance, which also counts transpositions of adjacent characters, and the Hamming distance, which counts substitutions only and applies to strings of equal length.

Applications

The most widely known application of approximate string matching is spell checking, where candidate corrections are dictionary words within a small edit distance of the mistyped word. Other applications include searching in DNA sequences, information retrieval, plagiarism detection, spam filtering, and record linkage in databases, where names or addresses may be recorded with variations.

Algorithms

Classical algorithms use dynamic programming over a matrix of distances between prefixes of the pattern and the text. Later methods use bit-parallelism (such as the Myers' algorithm and the agrep utility), automata, and metric indexing structures such as BK-trees to speed up dictionary searches.
