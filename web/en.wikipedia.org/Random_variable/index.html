Random variable

A random variable is a variable whose possible values are numerical outcomes of a random phenomenon. In the measure-theoretic formalism of probability, a random variable is a measurable function from a sample space Ω to a measurable space, most commonly the real numbers. The probability that the variable takes values in a given set is defined through this function.

Types

A discrete random variable takes values in a countable set, such as the integers; its distribution is described by a probability mass function. A continuous random variable takes values in an uncountable set, typically a real interval, and is described (when it exists) by a probability density function, with probabilities given by integrals. Some variables are mixtures of the two.

Distribution functions

The cumulative distribution function FX(x) = P(X ≤ x) characterises a random variable's distribution completely. Key summaries include the expected value (mean) E[X], the variance Var(X) = E[(X − E[X])2], and higher moments.

Functions and convergence

Functions of random variables produce new random variables; for a Borel function g, Y = g(X) has distribution obtained by pushing forward the original measure. Sequences of random variables may converge in several senses — almost surely, in probability, in distribution, or in mean square — concepts central to the law of large numbers and the central limit theorem.
