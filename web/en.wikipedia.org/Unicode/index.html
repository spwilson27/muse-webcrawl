Unicode

Unicode, formally the Unicode Standard, is a text encoding standard maintained by the Unicode Consortium designed to support the use of text in all of the world's writing systems that can be digitized. It assigns a unique number, called a code point, to every abstract character — letters, digits, punctuation, symbols and emoji — independent of platform, language or font. Version 16.0, released in 2024, encodes roughly 155,000 characters across 168 scripts.

History

Unicode originated in 1987 in discussions between Joe Becker of Xerox and Lee Collins and Mark Davis of Apple, who sought a universal character set to replace the chaos of incompatible 8-bit code pages. The Unicode Consortium was incorporated in 1991, and Unicode 1.0 appeared that October. The standard was aligned with ISO/IEC 10646, the Universal Coded Character Set. Early versions used a fixed 16-bit space; the codespace was later extended to 17 planes of 65,536 code points each (U+0000 to U+10FFFF).

Encoding forms

Abstract code points are stored by encoding forms: UTF-8, a variable-length byte encoding dominant on the web; UTF-16, used internally by Windows and Java, which encodes higher-plane characters as surrogate pairs; and UTF-32, a fixed four-byte form. Unicode also defines character properties, normalization forms, bidirectional text rules, collation, line breaking and case mappings, making it a full text-processing standard rather than a mere code list.

Repertoire and adoption

Beyond the world's scripts, Unicode includes punctuation, mathematical symbols, musical notation, historic scripts such as Egyptian hieroglyphs and cuneiform, and emoji, whose popularity since the 2010s made the Consortium's annual releases widely reported. Unicode underlies modern operating systems, programming languages, the web (HTML and XML), and internationalized domain names; it has effectively displaced legacy encodings such as ASCII and Latin-1.
