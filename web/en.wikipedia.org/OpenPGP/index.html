OpenPGP

OpenPGP is an open standard for encrypting and signing data, derived from the Pretty Good Privacy (PGP) software originally created by Phil Zimmermann in 1991. It was standardised by the Internet Engineering Task Force (IETF), first as RFC 2440 (1998) and then RFC 4880 (2007), and a major revision, RFC 9580 (2024), incorporated the "crypto-refresh" update with modern algorithms. OpenPGP defines the formats for encrypted messages, digital signatures, certificates (keys), and a trust model often called the "web of trust".

How it works

OpenPGP uses hybrid encryption: a message is encrypted once with a random symmetric session key, and that session key is then encrypted with each recipient's public key. Supported algorithms have evolved from RSA, DSA, and ElGamal to modern elliptic-curve cryptography including Curve25519. Signatures are created with the sender's private key and can be verified using the corresponding public key, providing authenticity and integrity as well as confidentiality. Data may be compressed before encryption, and an ASCII-armour encoding allows binary material to travel through text-based channels such as email.

Implementations

The best-known implementation is GnuPG (GPG), the GNU Project's free software suite, which ships with most Linux distributions and underlies much OpenPGP usage. Others include the commercial PGP lineage (now owned by Broadcom), the Java Bouncy Castle libraries, OpenKeychain for Android, GPGTools for macOS, Sequoia PGP, and the JavaScript library OpenPGP.js, which powers several encrypted email services. The EFAIL vulnerabilities disclosed in 2018 highlighted risks in how some email clients rendered decrypted content, though the core standard was not broken.

Uses

OpenPGP is used for encrypting email and files, signing software releases (Linux package repositories rely on it extensively), verifying downloads, and managing identities in developer workflows such as signed Git commits. Its decentralised trust model contrasts with the hierarchical certificate-authority model of S/MIME and TLS.
