Message Passing Interface

The Message Passing Interface (MPI) is a standardized and portable message-passing system designed for parallel computing on distributed-memory and hybrid systems. Conceived as a standard by a broadly based committee of vendors, implementers and users, MPI is the de facto standard for communication among the processing elements of parallel programs running on computer clusters and supercomputers.

Overview

MPI programs consist of multiple processes, each with its own address space, which cooperate by sending and receiving messages. The standard defines point-to-point communication (such as MPI_Send and MPI_Recv), collective operations across groups of processes (broadcast, scatter, gather, all-reduce), process groups and communicators, derived datatypes, one-sided communication, parallel I/O and dynamic process management. Language bindings are provided for C, C++ and Fortran.

History and implementations

The MPI Forum first convened in 1992; the MPI-1 standard was released in 1994, followed by MPI-2 in 1997, MPI-3 in 2012 and MPI-4.0 in 2021, which added features such as large-count support and partitioned communication. Major implementations include the open-source MPICH and Open MPI, and vendor-optimized versions such as Intel MPI. MPI remains the dominant programming model for high-performance computing, used by the large majority of applications on the world's fastest supercomputers.
