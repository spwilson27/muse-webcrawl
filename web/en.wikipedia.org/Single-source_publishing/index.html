Single-source publishing

Single-source publishing, also known as single-sourcing, is a content management method which allows the same source content to be used in different documents or output formats. Rather than maintaining parallel versions of a manual, website, and help system, authors write once and transform the source into each delivery channel.

Approach

Content is usually stored in a structured, presentation-neutral format such as XML (DocBook, DITA, or TEI) or lightweight markup, and stylesheets or build pipelines generate HTML, PDF, EPUB, and other outputs. Conditional text and variables allow product-specific or audience-specific variants to be produced from one source.

Benefits and challenges

Single-sourcing reduces duplication, keeps formats consistent, and simplifies translation and updates. Its costs include up-front investment in structured authoring and tooling, and the discipline required to write content that reads naturally in every output medium.
