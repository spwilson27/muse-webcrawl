Reference (computer science)

In computer science, a reference is a value that enables a program to indirectly access a particular datum, such as a variable or a record, stored elsewhere in memory or in another storage device. Accessing the datum through the reference is called dereferencing.

Forms

The most common form of reference is the pointer, which holds a memory address. Higher-level references, as in Java or C#, are opaque handles that cannot be manipulated arithmetically and may be null. In C++, a reference is an alias for an existing object that must be initialized and cannot be reseated. References are fundamental to linked data structures, call-by-reference parameter passing, and object-oriented programming.

Safety

Mismanaged references cause classic errors: dangling pointers to freed memory, null-pointer dereferences, and memory leaks. Garbage collection and ownership systems, such as Rust's borrow checker, are designed to manage reference lifetimes safely.
