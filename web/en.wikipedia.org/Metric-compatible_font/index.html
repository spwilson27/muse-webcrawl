Metric-compatible font

ExamplesLiberation fonts (for Arial, Times New Roman, Courier New); Croscore fonts (Arimo, Tinos, Cousine); Carlito (for Calibri); Caladea (for Cambria)
PurposeDrop-in substitution preserving document layout

A metric-compatible font (or metrically compatible typeface) is a typeface designed to have exactly the same character widths, and usually the same general appearance, as another typeface, so that one can be substituted for the other without changing the layout, line breaks, or pagination of a document. Metric compatibility is especially important for free and open-source fonts intended to replace proprietary fonts distributed with commercial software.

Rationale

Documents produced in applications such as Microsoft Word are commonly formatted in fonts like Arial, Times New Roman, and Calibri. If such a document is opened on a system lacking those fonts — common on Linux — an arbitrary substitute changes text flow and can break carefully arranged layouts, tables, and forms. A metric-compatible substitute preserves spacing exactly, even if its letterforms differ slightly in detail.

Notable families

The Liberation fonts, commissioned by Red Hat and designed by Ascender Corporation, are metric-compatible with Arial, Times New Roman, and Courier New. Google's Croscore fonts — Arimo, Tinos, and Cousine — provide the same compatibility, while Carlito and Caladea match Calibri and Cambria respectively. The Liberation and Croscore families share designs in many weights because both derive from the same Ascender prototypes.

Limitations

Metric compatibility guarantees identical advance widths only at the design level; rendering differences in hinting, kerning pairs, and line height (font ascent and descent metrics) can still alter appearance across platforms. Matching vertical metrics is sometimes included in the notion of compatibility to preserve total page length in office documents.
