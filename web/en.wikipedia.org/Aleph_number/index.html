In mathematics, particularly set theory, the aleph numbers are a sequence of cardinal numbers used to represent the sizes (cardinalities) of infinite sets that can be well-ordered. They are denoted by the Hebrew letter aleph (ℵ) with a subscript. The aleph numbers were introduced by Georg Cantor, the founder of set theory, in the late nineteenth century.

Definition

The smallest aleph number, ℵ0 (aleph-null or aleph-zero), is the cardinality of the set of natural numbers. A set has cardinality ℵ0 precisely when it is countably infinite. The next aleph, ℵ1, is the smallest uncountable cardinal: the cardinality of the set of all countable ordinal numbers. In general, for every ordinal α there is an aleph number ℵα, and every infinite cardinal is an aleph.

The continuum hypothesis

The cardinality of the set of real numbers — the cardinality of the continuum, written 2ℵ0 — is an aleph, but which one is not determined by the standard axioms of set theory (ZFC). The continuum hypothesis asserts that it is exactly ℵ1, i.e. that there is no set whose cardinality lies strictly between that of the integers and that of the real numbers. Kurt Gödel showed in 1940 that the hypothesis cannot be disproved in ZFC, and Paul Cohen showed in 1963 that it cannot be proved either.

Properties

Aleph numbers are initial ordinals: ℵα is the least ordinal of its cardinality. For every α, ℵα is a limit cardinal in the sense that there is no cardinal strictly between ℵα and any smaller aleph, and the alephs are unbounded: there is no largest infinite cardinal. Under the axiom of choice, every infinite set has an aleph number as its cardinality.
