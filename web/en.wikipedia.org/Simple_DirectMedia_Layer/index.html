Simple DirectMedia Layer (SDL) is a cross-platform development library providing low-level access to audio, keyboard, mouse, joystick and graphics hardware via OpenGL and Direct3D. It is written in the C programming language and is widely used by video game developers and multimedia software, including the Source engine's Linux ports, many emulators and the Steam client. SDL was created by Sam Lantinga, who developed it while working at Loki Software porting games to Linux.

Features

SDL abstracts platform-specific facilities — windows and rendering surfaces, an event loop for input, audio mixing and playback, threads, timers and file I/O — behind a single API, letting developers write code once and deploy on Windows, macOS, Linux, iOS, Android and other systems. Companion libraries add functionality: SDL_image loads image formats, SDL_mixer provides multi-channel audio mixing, SDL_ttf renders TrueType fonts and SDL_net supplies networking primitives.

Versions

The original SDL 1.2 was maintained for many years and became a de facto standard for Linux game development. SDL2, released in 2013 under the permissive zlib License (replacing the earlier LGPL), modernised the library with support for multiple windows, hardware-accelerated 2D rendering, touch input and mobile platforms. SDL3, released in January 2025, overhauled the API further with improved audio, camera and pen support and a new GPU API.

Adoption

Because of its portability and permissive licensing, SDL underpins a large share of commercial and open-source games on Linux and is a common foundation for game engines and media players. Valve's Steam runtime uses SDL, and many classic games have received cross-platform re-releases built on it.
