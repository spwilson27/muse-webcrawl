Latent semantic analysis

Singular value decomposition underlying LSA

Latent semantic analysis (LSA) is a technique in natural language processing, in particular distributional semantics, of analyzing relationships between a set of documents and the terms they contain by producing a set of concepts related to the documents and terms.

Method

LSA begins by constructing a term-document matrix recording how often each word occurs in each document. Singular value decomposition (SVD) is then applied to reduce the number of rows while preserving the similarity structure among columns. Documents and terms can then be compared in the reduced space using cosine similarity.

Advantages and limitations

Because documents are compared through shared latent concepts rather than exact word matches, LSA can retrieve documents about a topic even when they use synonyms rather than the query words. Its weaknesses include difficulty handling polysemy, sensitivity to parameters, and the cost of recomputing the decomposition when new documents arrive.

Applications

LSA has been applied to information retrieval, automated essay scoring, document classification, and models of human memory and language acquisition. The related method latent semantic indexing (LSI) is widely used in search engines and text mining.
