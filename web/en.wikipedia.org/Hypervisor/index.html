Hypervisor

Hypervisor
Also called: Virtual machine monitor (VMM)
Type 1: Bare-metal (e.g. Xen, VMware ESXi, Hyper-V)
Type 2: Hosted (e.g. VirtualBox, VMware Workstation)
Origin: IBM CP-40 and CP/CMS, 1960s

A hypervisor, also known as a virtual machine monitor, is computer software, firmware or hardware that creates and runs virtual machines. A computer on which a hypervisor runs one or more virtual machines is called a host machine, and each virtual machine is called a guest machine. The hypervisor presents guest operating systems with a virtual operating platform and manages their execution, allowing multiple operating systems to share one physical server.

Classification

Type-1, native or bare-metal hypervisors run directly on the host hardware to control it and manage guest operating systems; examples include Xen, VMware ESXi, Microsoft Hyper-V and the Linux KVM when acting in this role. Type-2 or hosted hypervisors run as applications on a conventional operating system, such as Oracle VirtualBox and VMware Workstation. Gerald Popek and Robert Goldberg's 1974 formal requirements defined the properties an architecture needs for efficient virtualisation.

Technology

Early x86 processors did not fully support classic virtualisation, prompting techniques such as binary translation and paravirtualisation; hardware extensions (Intel VT-x and AMD-V, from 2005–06) made near-native virtualisation routine. Hypervisors schedule virtual CPUs, manage memory through shadow or extended page tables, and emulate or pass through devices. Live migration lets running virtual machines move between hosts.

Uses

Hypervisors underpin cloud computing, server consolidation, software testing, desktop virtualisation and mainframe computing, where IBM systems have supported virtual machines since the late 1960s. Security uses include isolation of untrusted workloads, though hypervisor escapes are a recognised attack class.
