RSpec

Output of an RSpec run in documentation format.

RSpec is a computer domain-specific language (DSL) testing tool written in the Ruby programming language to test Ruby code. It is a behavior-driven development (BDD) framework which is extensively used in production applications. The basic idea behind this concept is that of test-driven development (TDD), where the tests are written first and the development is based on writing just enough code to pass the tests.

RSpec was created in 2005 by Steven Baker, growing out of ideas in Dave Astels' and David Chelimsky's work on behaviour-driven development. David Chelimsky led the project for many years, and the framework became the most widely used testing library in the Ruby community, shipped by default in the tooling of many Rails developers.

Syntax

RSpec examples are organised into groups introduced by describe blocks, with individual examples written with it. Expectations are expressed in a readable syntax:

describe Bowling do
  it "scores 0 for gutter games" do
    bowling = Bowling.new
    20.times { bowling.hit(0) }
    expect(bowling.score).to eq 0
  end
end

The framework provides matchers such as eq, include, raise_error and be_within, test doubles (mocks and stubs), shared examples, hooks, and a command-line runner that reports failures with diffs.

Ecosystem

RSpec is split into several gems: rspec-core (the runner), rspec-expectations (the matcher syntax) and rspec-mocks (test doubles). Companion libraries such as rspec-rails, FactoryBot and Capybara integrate it with web frameworks and browser-driven acceptance tests. Its chief alternative in the Ruby world is Minitest, which ships with Ruby itself.
