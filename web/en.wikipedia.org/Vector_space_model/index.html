Vector space model

The vector space model (VSM) is an algebraic model for representing text documents (or any objects) as vectors of identifiers, most commonly index terms. Developed for information retrieval — notably in the SMART system of Gerard Salton in the 1960s and 1970s — it underlies search engines, document classification, clustering and recommender systems.

Model

Each distinct term in a collection defines a dimension of a (typically high-dimensional, sparse) vector space. A document is a vector whose components are term weights, most famously tf–idf weights combining term frequency with inverse document frequency. A query is represented in the same space, and relevance is scored by similarity between vectors, usually the cosine of the angle between them. Documents are then ranked by similarity to the query.

Extensions

Limitations of the basic model — its bag-of-words assumption and ignorance of synonymy and word meaning — motivated latent semantic analysis, which applies singular value decomposition to the term–document matrix, and later dense word and document embeddings learned by neural networks, which retain the vector-space idea with learned coordinates.
