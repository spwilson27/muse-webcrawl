Linear programming

Linear programming (LP), also called linear optimization, is a method to achieve the best outcome (such as maximum profit or lowest cost) in a mathematical model whose requirements and objective are represented by linear relationships. Linear programming is a special case of mathematical programming (also known as mathematical optimization).

Standard form

A linear program in standard form maximises a linear objective cTx subject to linear inequality constraints Ax ≤ b and non-negativity x ≥ 0. The set of feasible solutions forms a convex polytope; if an optimum exists, it is attained at a vertex (corner point) of that polytope — the geometric fact exploited by the simplex algorithm.

Algorithms

George Dantzig developed the simplex algorithm in 1947, which moves along edges of the polytope between vertices and remains the practical workhorse for many problems. Although simplex has exponential worst cases, Leonid Khachiyan's ellipsoid method (1979) first proved LP solvable in polynomial time, and Narendra Karmarkar's interior-point method (1984) made polynomial-time algorithms practical for very large problems.

Duality

Every linear program has a dual program whose optimal value equals that of the primal (strong duality). Dual variables can be interpreted as shadow prices of the constraints. Duality underlies much of combinatorial optimization and game theory; the minimax theorem for zero-sum games is an equivalent statement.

Applications

Linear programming is used in logistics and scheduling, airline crew assignment, diet and blending problems (the subject of Dantzig's early work), portfolio selection, network flows, and as the relaxation engine inside integer-programming solvers. Problems with integer variables (ILP) extend LP to model discrete decisions.
