Sequential consistency

Sequential consistency is a consistency model for concurrent and distributed systems, defined by Leslie Lamport in 1979: "the result of any execution is the same as if the operations of all the processors were executed in some sequential order, and the operations of each individual processor appear in this sequence in the order specified by its program."

Properties

Sequential consistency requires a single global order of operations consistent with each processor's program order, but does not require that order to respect real time — distinguishing it from linearizability, which adds the real-time constraint. Many multiprocessors and languages offer weaker, more performant models; Java's memory model guarantees sequential consistency for correctly synchronised (data-race-free) programs.
