Map (higher-order function)

Paradigm: Functional programming
Type: Higher-order function
Signature: (a → b) → [a] → [b]
Related: Filter, fold/reduce

In many programming languages, map is the name of a higher-order function that applies a given function to each element of a collection (such as a list or iterable), returning a collection of the results in the same order. Together with filter and fold, it is one of the foundational operations of functional programming.

Examples

Mapping a squaring function over the list [1, 2, 3, 4] yields [1, 4, 9, 16]. In Lisp dialects the function appears as mapcar; in Haskell, map works over lists and generalises through the Functor typeclass as fmap. Python provides a built-in map, JavaScript arrays have a map method, and Java streams offer Stream.map.

Properties

Map preserves the structure and length of the input collection: each input element produces exactly one output element. It can often be implemented with a loop, but expressing the operation declaratively emphasises the transformation rather than the iteration mechanics, and map operations are readily parallelised — an idea exploited at large scale by the MapReduce programming model, in which a map phase transforms records into key–value pairs before a reduce phase aggregates them.

Generalisations

Related operations include flatMap, which maps each element to a collection and flattens the result, and mappings over dictionaries, sets, trees and asynchronous streams.
