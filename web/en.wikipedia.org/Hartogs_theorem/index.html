Hartogs's theorem

In mathematics, Hartogs's theorem is a fundamental result of Friedrich Hartogs in the theory of functions of several complex variables. Loosely stated, it asserts that a function of several complex variables that is holomorphic in each variable separately is automatically jointly holomorphic (that is, continuous and locally given by convergent power series). A consequence is that there is no isolated singularity phenomenon in several variables analogous to that in one variable: a holomorphic function on a domain with a compact subset removed extends holomorphically across the removed set whenever the ambient dimension is at least two.

Statement

Let f be a complex-valued function defined on an open subset of ℂn, with n ≥ 2. If f is holomorphic in each variable zj while the other variables are held fixed, then f is holomorphic on the whole domain. Hartogs proved this in 1906; modern proofs typically use the Cauchy integral formula in one variable to establish continuity, after which joint holomorphicity follows.

Hartogs's extension theorem

A related result, likewise due to Hartogs, is the extension theorem (or Hartogs's lemma): if f is holomorphic on the complement of a compact subset K of a domain Ω ⊂ ℂn, n ≥ 2, where Ω ∖ K is connected, then f extends to a holomorphic function on all of Ω. This is in striking contrast to one complex variable, where functions such as 1/z on ℂ ∖ {0} have non-removable isolated singularities. Early consequences concern the geometry of domains of holomorphy: no ball in ℂn (n ≥ 2) can have its boundary arcs removed while staying a domain of holomorphy in the same way as planar domains; Hartogs figures — regions shaped like a frame — are not domains of holomorphy because every holomorphic function on them extends to the full polydisc or ball they bound.
