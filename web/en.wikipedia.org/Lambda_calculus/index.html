Lambda calculus

Lambda calculus (also written as λ-calculus) is a formal system in mathematical logic for expressing computation based on function abstraction and application using variable binding and substitution. It is a universal model of computation that can be used to simulate any Turing machine. It was introduced by the mathematician Alonzo Church in the 1930s as part of his research into the foundations of mathematics.

Definition

Lambda expressions are built from variables (x, y), abstractions (λx.M, a function taking argument x and returning M), and applications (M N, applying function M to argument N). Computation proceeds by β-reduction: an expression of the form (λx.M) N reduces to M with N substituted for x. A related rule, α-conversion, renames bound variables to avoid capture. The Church–Rosser theorem guarantees that if an expression has a normal form, reduction order does not change the result.

History

Church introduced the calculus in the 1930s while investigating the Entscheidungsproblem. His student Alan Turing showed in 1936–37 that the lambda calculus and Turing machines are equivalent in computational power — the Church–Turing thesis. Encodings devised by Church showed that numbers, booleans, and recursive functions can all be represented as lambda terms; his fixed-point combinator (the Y combinator) demonstrated that recursion needs no special machinery.

Influence on computing

The lambda calculus directly inspired the programming language Lisp (1958), and through it the entire family of functional languages, including ML, Haskell, and Erlang. Concepts central to modern languages — anonymous functions ("lambdas"), closures, and higher-order functions — derive from it. Typed variants, beginning with the simply typed lambda calculus and the Curry–Howard correspondence between proofs and programs, underpin modern type theory and proof assistants such as Coq and Lean.
