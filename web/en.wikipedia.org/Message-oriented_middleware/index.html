Message-oriented middleware

Message-oriented middleware (MOM) is software or hardware infrastructure supporting the sending and receiving of messages between distributed systems. MOM allows application modules to be distributed over heterogeneous platforms and reduces the complexity of developing applications that span multiple operating systems and network protocols. It typically provides an asynchronous messaging pattern in which senders and receivers need not be active at the same time.

Architecture

The central components of a MOM system are message queues and, in publish–subscribe models, topics. In the point-to-point pattern, a producer places messages on a queue from which a single consumer retrieves them, often with transactional guarantees and persistence so that messages survive failures. In publish–subscribe, messages are published to topics and delivered to all subscribers. A message broker routes, stores and forwards messages, decoupling producers from consumers in time, location and implementation language.

Standards and products

Well-known MOM systems and standards include IBM MQ (originally MQSeries), Microsoft Message Queuing (MSMQ), the Java Message Service (JMS) API, the Advanced Message Queuing Protocol (AMQP), Apache Kafka — a distributed event-streaming platform — and Apache ActiveMQ and RabbitMQ. MOM is a core element of enterprise application integration and of modern event-driven and microservice architectures.
