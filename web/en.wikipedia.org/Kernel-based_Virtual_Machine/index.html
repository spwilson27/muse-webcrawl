Kernel-based Virtual Machine

KVM turns the Linux kernel itself into a hypervisor.

Kernel-based Virtual Machine (KVM) is a virtualization module in the Linux kernel that allows the kernel to function as a hypervisor. It was merged into the Linux kernel mainline in version 2.6.20, released in February 2007. KVM requires a processor with hardware virtualization extensions, such as Intel VT-x or AMD-V.

How it works

KVM exposes the device node /dev/kvm, through which a userspace program — most commonly QEMU — can create virtual machines, allocate their memory, and run guest code in a special CPU mode. Guest code runs directly on the host processor at near-native speed until it executes a sensitive instruction or accesses emulated hardware, at which point control returns to the userspace emulator. In this design the Linux scheduler, memory management and device drivers serve as the hypervisor's infrastructure, and each virtual CPU appears to the host as an ordinary process.

Features

KVM supports live migration of running guests between hosts, memory overcommit, paravirtualized drivers through the virtio framework, and a wide range of guest operating systems. It is the foundation of many commercial and open-source virtualization platforms, including Red Hat Virtualization, OpenStack deployments, Proxmox VE and Google Cloud's infrastructure. A related kernel module, vhost, accelerates network and block device I/O by handling data paths in the kernel rather than in userspace.

History

KVM was developed by the Israeli company Qumranet, led by Avi Kivity. Qumranet was acquired by Red Hat in 2008, and KVM became Red Hat's strategic virtualization technology in place of Xen. Support for ARM processors was added later, enabling KVM on servers, and increasingly on mobile and embedded hardware.
