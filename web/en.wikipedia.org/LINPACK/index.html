LINPACK is a software library for performing numerical linear algebra on digital computers, and also the name of the benchmark derived from it that for decades served as the standard measure of a computer's floating-point performance. The library was written in Fortran in the 1970s by Jack Dongarra, Jim Bunch, Cleve Moler and Gilbert W. Stewart and released in 1979.

The library

LINPACK provides routines for solving systems of linear equations and least-squares problems with various matrix structures (general, banded, symmetric, triangular and others), using Gaussian elimination with partial pivoting and the BLAS (Basic Linear Algebra Subprograms) for vector operations. It was superseded in the 1990s by LAPACK, which restructured the algorithms for block operations better suited to modern cache-based machines, though LINPACK routines remain widely available through netlib.

The benchmark

The LINPACK benchmark measures how fast a computer solves a dense system of linear equations, reporting the result in floating-point operations per second (FLOPS). Jack Dongarra maintained lists of results for 100×100, 1000×1000 and "toward peak performance" variants. Its highly parallel, tuned version, HPL (High Performance LINPACK), became the benchmark used to rank the TOP500 list of the world's fastest supercomputers from 1993 onward, measured in petaflops and later exaflops. Criticism that LINPACK over-represents one narrow workload led to alternative benchmarks such as HPCG being adopted alongside it.
