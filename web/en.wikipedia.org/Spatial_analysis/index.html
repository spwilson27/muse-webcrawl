Spatial analysis

FieldGeography, statistics
ToolsGIS, spatial statistics, remote sensing
RelatedGeostatistics, spatial econometrics

Spatial analysis is a type of geographical analysis that seeks to explain patterns of human and natural phenomena in geographic space, using the locations, shapes, and relationships of features as data. It includes spatial statistics, spatial interpolation, network analysis, and computer cartography.

Methods

Analysts study spatial autocorrelation — the tendency of nearby values to resemble each other — with measures such as Moran's I, model point patterns and clusters, and interpolate continuous surfaces from samples using methods such as kriging. Geographic information systems provide the computational environment for most applied work.

Applications

Spatial analysis is used in epidemiology, crime mapping, ecology, transport planning, archaeology, and real estate, wherever the question "where" is central to explanation.
