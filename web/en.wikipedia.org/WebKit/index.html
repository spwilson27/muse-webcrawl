WebKit

WebKit is a browser engine developed by Apple and used in the Safari web browser, as well as all web browsers on iOS and iPadOS. It consists principally of WebCore, which renders HTML and CSS, and JavaScriptCore, which executes JavaScript. WebKit is free and open-source software under the BSD and LGPL licenses.

History

Developer: Apple and contributors
Initial release: 2001 (as KHTML fork)
Written in: C++
License: BSD / LGPL

WebKit began in 2001 as Apple's fork of the KHTML and KJS libraries from the KDE project, created for the Safari browser, which was released in 2003. Apple open-sourced the project in 2005. Google adopted WebKit for Chrome in 2008, contributing the WebKit2 multiprocess architecture and the V8-related work before forking WebKit into Blink in 2013. Since then WebKit has been developed mainly by Apple, Igalia, and Sony, among others, and is used by the PlayStation browsers, GNOME Web (Epiphany), and numerous embedded web views.

Components

WebCore handles document parsing, layout, rendering, and networking bindings, while JavaScriptCore (branded Nitro in some contexts) provides a JIT-compiling JavaScript engine. The WebKit2 API, introduced in 2010, splits rendering into a UI process and sandboxed web processes, improving stability and security.
