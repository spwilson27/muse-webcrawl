In computing, bus snooping or bus sniffing is a technique used in distributed shared memory and multiprocessor systems for achieving cache coherency. Every cache that has a copy of the data from a block of the physical memory also has a copy of the cache state of that block and its hardware snoops the bus for transactions by other processors, reacting when another processor requests or modifies the same memory location.

How snooping works

Each cache controller monitors ("snoops") all bus activity. When a processor issues a read or write, the snooping caches check whether they hold the addressed line and take action according to a coherence protocol: a cache holding a line that another processor wants to write will invalidate its copy (or supply the up-to-date data), and a cache holding a modified line that another processor wants to read will flush or forward the current value. Snooping protocols are commonly described by the states a line can occupy, as in MESI: Modified, Exclusive, Shared, and Invalid.

Advantages and limits

Snooping is simple and fast because the shared bus provides a natural broadcast and ordering point, which is why classic symmetric multiprocessors and modern on-chip interconnects use snoopy coherence for small processor counts. However, every processor's traffic must be observed by every cache, so snooping consumes bus bandwidth and does not scale to large systems; big multiprocessors instead use directory-based coherence, and many modern designs combine snooping within a node with directories between nodes.
