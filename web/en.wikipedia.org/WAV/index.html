Waveform Audio File Format (WAVE, or WAV due to its filename extension) is an audio file format standard for storing an audio bitstream on personal computers. Developed by IBM and Microsoft and released in August 1991, it is the main format used on Microsoft Windows systems for uncompressed audio, and it remains widely used for professional recording, editing and archiving.

Format

WAV is an application of the Resource Interchange File Format (RIFF) bitstream format for storing data in chunks. A WAV file typically begins with a RIFF header containing the identifier "WAVE", followed by a format chunk describing the sample rate, number of channels and bits per sample, and a data chunk holding the audio samples. The usual encoding is linear pulse-code modulation (LPCM), in which the audio waveform is represented directly without compression.

Usage and limitations

Because uncompressed WAV audio is large — roughly 10 megabytes per minute for CD-quality stereo (44.1 kHz, 16-bit) — the format is less common for distribution over networks than compressed formats such as MP3 or AAC, but it is the default interchange format in studios and broadcast. The classic RIFF structure limits files to 4 GB; the RF64 extension was later introduced to overcome that ceiling. Variants include Broadcast Wave Format (BWF), standardized by the European Broadcasting Union, which adds metadata used in radio and television production.
