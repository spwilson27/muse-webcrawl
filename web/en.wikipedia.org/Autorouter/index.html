Autorouter

TypeElectronic design automation software
PurposePrinted circuit board routing, chip routing
Key algorithmsMaze routing, rip-up and retry, push-and-shove

An autorouter is a software tool in electronic design automation (EDA) that automatically routes the conductive traces (wires) of a printed circuit board (PCB) or an integrated circuit, connecting the pins of components according to a netlist while observing design rules such as minimum spacing and trace width.

Operation

After component placement, the designer defines constraints and the autorouter attempts to complete all connections. Classic algorithms include the Lee maze-routing algorithm, which works on a grid and guarantees a path if one exists; channel routers for restricted layouts; and rip-up and retry routers, which remove problem nets and reroute them in a different order.

Interactive routing

Modern PCB tools often combine automatic routing with interactive "push-and-shove" routing, in which manually placed traces push existing traces aside while maintaining clearances. Critical nets—such as high-speed differential pairs or power nets—are frequently routed by hand, with the autorouter completing the remaining, less sensitive connections.

Applications

Autorouters are a standard feature of PCB design packages such as Altium Designer, Cadence Allegro, KiCad, and EAGLE, and routing is an essential back-end step in digital integrated-circuit design flows.
