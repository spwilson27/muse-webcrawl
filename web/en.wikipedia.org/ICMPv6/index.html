Internet Control Message Protocol for IPv6

The Internet Control Message Protocol version 6 (ICMPv6) is the implementation of the Internet Control Message Protocol for Internet Protocol version 6 (IPv6), defined in RFC 4443. ICMPv6 messages report errors in processing IPv6 packets and perform diagnostics such as ping.

Functions

Unlike its IPv4 counterpart, ICMPv6 also carries the Neighbor Discovery Protocol, which provides address resolution (replacing ARP), stateless address autoconfiguration support, and router discovery. ICMPv6 is additionally used by Multicast Listener Discovery for managing multicast group memberships.

Message types

Error messages include Destination Unreachable, Packet Too Big, Time Exceeded, and Parameter Problem; informational messages include Echo Request and Echo Reply. Path MTU discovery depends on Packet Too Big messages, so indiscriminate filtering of ICMPv6 can break IPv6 connectivity.
