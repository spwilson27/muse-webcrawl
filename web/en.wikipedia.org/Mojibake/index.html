Mojibake

Mojibake (Japanese: 文字化け, "character transformation") is the garbled text that results when text is decoded using an unintended character encoding. The output is a stream of incorrect, often unreadable symbols, such as accented Latin letters appearing in place of Japanese or Cyrillic text.

Causes

Mojibake occurs when the encoding used to store text differs from the encoding assumed when displaying it. A common case is UTF-8 text interpreted as Windows-1252 or Latin-1, which turns multi-byte characters into sequences like "Ã©" for "é". The problem was especially frequent in early email and web pages, where encoding declarations were absent or wrong.

Prevention

The widespread adoption of Unicode and explicit character-encoding declarations in protocols such as HTTP and HTML has reduced mojibake, but it still appears when data passes through systems that strip metadata or assume legacy encodings. Similar corruption affecting East Asian text in Western-locale software is sometimes called by the related term mojibake in software-localisation literature generally.
