Shell script

A shell script is a computer program designed to be run by a Unix shell, a command-line interpreter. Various dialects of shell scripts are considered scripting languages. Typical operations performed by shell scripts include file manipulation, program execution, and printing text.

Features

Scripts are text files that begin with a "shebang" line such as #!/bin/sh or #!/bin/bash identifying the interpreter. Shell languages provide variables, control structures (if, for, while, case), functions, pipelines, redirection, and command substitution, combining the interactive command language with programming constructs.

#!/bin/sh
for f in *.txt; do
  echo "Processing $f"
done

Common shells

The Bourne shell (sh) and its descendants and relatives — bash, ksh, zsh, and dash — dominate Unix and Linux scripting, while the C shell family (csh, tcsh) uses different syntax. On Windows, batch files and PowerShell scripts play an analogous role. Shell scripts are widely used for system administration, build automation, and installation software, though larger programs are often written in general-purpose scripting languages such as Python or Perl.
