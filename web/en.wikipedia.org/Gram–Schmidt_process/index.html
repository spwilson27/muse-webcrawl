Gram–Schmidt process

Steps of Gram–Schmidt orthogonalization in two dimensions

In mathematics, particularly linear algebra and numerical analysis, the Gram–Schmidt process is a method for orthonormalizing a set of vectors in an inner product space, most commonly the Euclidean space Rn equipped with the standard inner product. It takes a finite, linearly independent set of vectors and generates an orthogonal (or orthonormal) set that spans the same subspace.

Definition

The process works by successive projection. Given linearly independent vectors v1, ..., vk, one defines:

u1 = v1,   uj = vj − Σi<j projui(vj)

where proju(v) = (⟨u, v⟩ / ⟨u, u⟩) u. Dividing each uj by its norm yields an orthonormal set ej = uj / ||uj||.

History

The method is named after Danish mathematician Jørgen Pedersen Gram and German mathematician Erhard Schmidt, though it appeared earlier in the work of Laplace and Cauchy. Gram published on least squares in 1883, and Schmidt described the orthogonalization procedure in 1907 in the context of integral equations.

Numerical stability

The classical Gram–Schmidt algorithm can suffer from loss of orthogonality due to rounding errors. The modified Gram–Schmidt process, which computes each projection sequentially and updates the working vector at each step, is numerically more stable and is mathematically equivalent. The process is closely related to QR decomposition of a matrix, in which the columns of Q are the orthonormal vectors produced.

Applications

Gram–Schmidt orthogonalization is used in solving least squares problems, constructing orthonormal bases, the Arnoldi and Lanczos iterations in numerical linear algebra, and in signal processing.
