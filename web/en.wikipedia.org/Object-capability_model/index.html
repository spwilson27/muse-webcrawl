Object-capability model

[Image placeholder: Object-capability model]

The object-capability model is a computer security model based on the principle of least authority. A computer program (an "object") receives the ability to interact with other objects only through designated references — unforgeable tokens called capabilities — and a subject that lacks a capability to an object simply cannot access it.

Principles

In object-capability systems, designation and authority are unified: naming a resource in the program is the same act as being authorised to use it, so confused-deputy attacks are avoided. Authority can only be obtained by initial conditions, by creation, by receiving it from another object (introduction), or as part of an authorised operation. The model was developed in systems and languages such as KeyKOS, EROS and the programming language E, and has influenced secure design in modern systems, web frameworks and smart contracts.

Comparison

The model contrasts with access-control-list and ambient-authority systems, where programs run with the full privileges of their user and must be trusted not to misuse them.
