Secure Shell

The Secure Shell Protocol (SSH) is a cryptographic network protocol for operating network services securely over an unsecured network. Its most notable applications are remote login and command-line execution.

Design

SSH was designed on Unix-like systems as a replacement for Telnet and the insecure Berkeley r-commands, which send information, notably passwords, in plaintext. SSH encrypts all traffic to eliminate eavesdropping and connection hijacking, using public-key cryptography to authenticate the remote computer and optionally the user. The standard TCP port for SSH is 22.

Uses

Beyond remote shells, SSH supports tunnelling (port forwarding), secure file transfer via SFTP and SCP, and X11 forwarding. It was originally developed by Tatu Ylönen in 1995; the widely used OpenSSH implementation is maintained by the OpenBSD project. SSH-2, standardised by the IETF in 2006, superseded the original protocol.
