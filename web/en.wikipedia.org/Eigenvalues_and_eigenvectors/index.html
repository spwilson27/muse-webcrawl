Eigenvalues and eigenvectors

[Image: images/Eigenvalues_and_eigenvectors.png — A linear transformation stretching vectors along its eigenvector directions]

In linear algebra, an eigenvector of a linear transformation is a nonzero vector that changes by only a scalar factor when that transformation is applied to it. The corresponding scalar factor is called an eigenvalue. Formally, if T is a linear map from a vector space V to itself and v is a nonzero vector in V, then v is an eigenvector of T if T(v) is a scalar multiple of v.

T(v) = λv

where λ is the eigenvalue associated with v. For a square matrix A, the eigenvalue equation is Av = λv, and the eigenvalues are the roots of the characteristic polynomial det(A − λI) = 0. An eigenvalue may be positive, negative, zero or complex; a negative eigenvalue reverses the vector's direction, and λ = 0 means the matrix is singular.

Eigenspaces and diagonalisation

The set of all eigenvectors for a given eigenvalue, together with the zero vector, forms a subspace called the eigenspace for that eigenvalue. If a matrix has a full set of linearly independent eigenvectors, it can be diagonalised as A = PDP−1, which greatly simplifies computing powers and functions of the matrix. Real symmetric matrices always have real eigenvalues and an orthonormal basis of eigenvectors (the spectral theorem).

Applications

Eigenvalues and eigenvectors are fundamental across science and engineering: principal component analysis in statistics, vibration modes and stability analysis in mechanics, quantum mechanical observables, Markov chain steady states, facial recognition ("eigenfaces"), and Google's PageRank algorithm, which is an eigenvector problem on a web graph.
