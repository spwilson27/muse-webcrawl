Antenna gain

Gain describes how an antenna concentrates radiated power in a particular direction.

In electromagnetics, an antenna's gain is a key figure of merit that combines the antenna's directivity and radiation efficiency. It is defined as the ratio of the radiation intensity produced by the antenna in a given direction to the radiation intensity that would be produced by a hypothetical lossless isotropic radiator fed with the same input power. Gain thus measures how effectively an antenna focuses energy in a desired direction compared with radiating it uniformly in all directions.

Definition

If U is the radiation intensity in a given direction and Pin the accepted input power, the gain in that direction is G = 4πU / Pin. Gain factorises as G = ηD, where D is directivity and η the radiation efficiency (the fraction of input power actually radiated, accounting for conductor and dielectric losses). A related quantity, realized gain, additionally includes losses from impedance mismatch at the antenna terminals.

Units

Gain is usually expressed in decibels. In dBi the reference is an isotropic radiator; in dBd the reference is a half-wave dipole, which itself has a gain of 2.15 dBi, so a value in dBd can be converted by adding 2.15 dB.

Typical values

A simple half-wave dipole has a maximum gain of about 2.15 dBi. Yagi–Uda television antennas reach roughly 10–15 dBi, while large parabolic dish antennas used in satellite communications and radio astronomy can exceed 40–50 dBi. Small omnidirectional antennas in mobile phones typically have gains near or below 0 dBi.
