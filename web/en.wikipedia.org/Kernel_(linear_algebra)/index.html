Kernel (linear algebra)

The kernel of a linear map is the set of vectors it sends to zero.

In linear algebra, the kernel (also known as the null space) of a linear map L : V → W between two vector spaces is the set of all elements v in V for which L(v) = 0, where 0 denotes the zero vector in W. The kernel is a linear subspace of V.

Definition and properties

For a matrix A, the kernel is the set of all vectors x satisfying the homogeneous system Ax = 0, and can be computed by Gaussian elimination. The kernel measures the failure of the map to be injective: L is injective if and only if its kernel is the trivial subspace {0}. The solution set of an inhomogeneous system Ax = b is either empty or an affine translate of the kernel.

Rank–nullity theorem

The dimension of the kernel, called the nullity, is linked to the dimension of the image (the rank) by the rank–nullity theorem: for a linear map on a finite-dimensional space, dim(ker L) + dim(im L) = dim(V). This is a special case of the first isomorphism theorem, which states that V/ker(L) is isomorphic to im(L).

Applications

Null spaces pervade applied mathematics: they describe the free modes of structures in engineering, the homogeneous solutions of linear differential equations (where the "kernel" terminology extends to linear operators generally), and consistency conditions in linear systems. Numerically, the kernel of a matrix is computed stably using the singular value decomposition, and nearly-singular directions in the kernel underlie methods such as total least squares and ridge regression.
