Struct (C programming language)

In the C programming language, a struct is a composite data type (or record) declaration that defines a physically grouped list of variables under one name in a block of memory, allowing the different variables to be accessed via a single pointer or by the struct declared name which returns the same address. The struct data type can contain other data types, so it is used for mixed-data-type records; however, some other types of records, such as unions, are also available in C.

Declaration

A struct declaration consists of the keyword struct, an optional tag name, and a list of member declarations enclosed in braces, followed by optional variable declarations and a semicolon:

struct point {
    int x;
    int y;
};

Members are accessed using the dot operator for struct values and the arrow operator (->) for pointers to structs. Structures can be nested, initialised with designated initialisers (since C99), assigned wholesale, passed to and returned from functions by value.

Memory layout

Members are stored in memory in the order in which they are declared, but the compiler may insert padding bytes between members to satisfy alignment requirements of the target architecture. Because of padding, the size of a struct (computed with the sizeof operator) can exceed the sum of the sizes of its members. The exact layout is implementation-defined apart from the guarantee that the first member lies at offset zero and members appear in declaration order.

Bit fields

C allows members of integer type to be declared with a specified width in bits, called bit fields, enabling compact storage of flags and small quantities. Bit fields are commonly used in low-level programming to model hardware registers and file or protocol formats.

Usage

Structs are the principal mechanism in C for building user-defined aggregate types. They serve as the basis for the library types such as struct tm (broken-down calendar time) and FILE, and in other languages the concept evolved into classes and records.
