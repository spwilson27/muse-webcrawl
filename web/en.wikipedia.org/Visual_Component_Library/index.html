Visual Component Library
DeveloperBorland / Embarcadero
Initial release1995 (with Delphi 1)
Written inObject Pascal
PlatformWindows

The Visual Component Library (VCL) is a visual component-based object-oriented framework for developing the user interface of Microsoft Windows applications. It was developed by Borland for use in, and is most strongly associated with, its Delphi and C++Builder rapid application development environments.

Design

The VCL is a thin object-oriented wrapper around the Windows API, organized as a hierarchy of classes rooted at TObject and TComponent. Components such as buttons, edit boxes, grids, and database controls can be placed on forms at design time in the IDE, with properties set in the Object Inspector and event handlers written in Object Pascal or C++. The framework handles Windows messages through a dispatch mechanism that maps them to methods.

Related frameworks

For cross-platform development, Borland later produced CLX (Component Library for Cross Platform), based on Qt, for use with Kylix; it was discontinued. Embarcadero's FireMonkey (FMX) framework is now the cross-platform successor, while the VCL remains the primary Windows framework in Delphi and C++Builder and continues to receive updates, including support for high-DPI displays and Windows 11 styling.
