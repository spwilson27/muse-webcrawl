Literate programming

Literate programming is a programming paradigm introduced by Donald Knuth in 1984. Instead of writing code in the order required by the compiler, the programmer writes an exposition of the program's logic in natural language, with code snippets embedded in the order best suited to human understanding.

Concept

A literate program is written as a document — a "web" of explanations and code chunks. Two tools process it: tangle extracts the machine-readable code in compiler order, while weave produces a typeset document for human readers. Knuth developed the WEB system to write TeX, which he described as a work of literature as much as a program.

Rationale

Knuth argued that programs should be written primarily for people to read, and only incidentally for machines to execute. Literate programming emphasises careful explanation, deliberate ordering of material, and treating the program as an essay.

Tools and influence

Systems descended from WEB include CWEB, noweb, and Leo. Modern notebook interfaces such as Jupyter and R Markdown borrow the interleaving of prose, code and output, though they are not literate programming systems in Knuth's strict sense. The approach remains influential in discussions of documentation and code quality.
