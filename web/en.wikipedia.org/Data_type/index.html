Data type

In computer science and computer programming, a data type (or simply type) is a collection or grouping of data values, usually specified by a set of possible values, a set of allowed operations on these values, and/or a representation of these values as machine types. A data type specification in a program constrains the possible values that an expression, such as a variable or a function call, might take.

Primitive types

Most languages provide built-in primitive types:

  • Boolean — true and false.
  • Integers — whole numbers, in fixed sizes (8-, 16-, 32-, 64-bit) with signed or unsigned ranges.
  • Floating-point numbers — approximations of real numbers, standardized by IEEE 754.
  • Characters and strings — single characters and sequences of them, typically encoded in Unicode.

Composite and abstract types

Composite types are built from other types: arrays, records/structs, tuples, unions, and classes. Abstract data types define behaviour purely by operations — such as stacks, queues, lists, maps, and sets — hiding their internal representation. Type systems range from static (types checked at compile time, as in Java, C, Rust) to dynamic (checked at run time, as in Python and JavaScript), and from strongly to weakly typed.

Type checking and safety

Type systems help prevent errors: if a function's argument types are checked, passing a string where an integer is required can be rejected before the program runs. Advanced systems — such as generics (parametric polymorphism), algebraic data types, and type inference in ML-family and Haskell languages — let programmers express richer constraints. Type safety guarantees that well-typed programs do not perform operations inappropriate to their data, though languages differ in how strictly this is enforced.

History

Formal concepts of type grew from logic (Russell's theory of types, Church's lambda calculus) and entered programming through ALGOL, Pascal, and C in the 1960s–70s, maturing into modern type theory and languages such as ML, Haskell, and Rust.
