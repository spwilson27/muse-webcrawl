Foreign function interface

A foreign function interface (FFI) is a mechanism by which a program written in one programming language can call routines or make use of services written or compiled in another language. FFIs are commonly used to access libraries written in C from higher-level languages, or to allow code in one language to be called from another.

Purpose

An FFI lets developers reuse existing native libraries—such as operating-system APIs, numerical libraries, or graphics engines—without rewriting them in the host language. It must bridge differences between the languages' calling conventions, data representations, memory management models, and type systems.

Examples

Well-known FFI mechanisms include the Java Native Interface (JNI), Python's ctypes module and C extension API, Ruby's FFI gem, Node.js native addons, Rust's extern "C" declarations, and the Haskell FFI standardized in the Haskell 2010 report. The library libffi provides a portable low-level implementation used by many runtimes to call functions whose signatures are known only at run time.

Challenges

Crossing a language boundary can complicate garbage collection, error handling, and thread safety, and marshalling data between incompatible representations can impose performance costs. For these reasons FFIs are powerful but must be used carefully.
