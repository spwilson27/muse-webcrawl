Browser engine

A browser engine (also known as a layout engine or rendering engine) is a core software component of every major web browser. Its primary job is to transform HTML documents and other resources of a web page into an interactive visual representation on a user's device.

Operation

When a browser loads a web page, the engine parses the HTML markup into a Document Object Model (DOM) tree and parses CSS style information into a CSS Object Model (CSSOM). The two are combined into a render tree, after which the engine performs layout — computing the exact position and size of every element — and finally painting, which fills in pixels on the screen. Modern engines also composite layers using the graphics processing unit to accelerate scrolling and animation.

Notable engines

  • Blink — developed by Google as a fork of WebKit's WebCore component; used by Chrome, Edge, Opera and Brave.
  • Gecko — developed by Mozilla and used in Firefox and related browsers.
  • WebKit — developed by Apple, originating in the KHTML engine; powers Safari.
  • Trident and its successor EdgeHTML — Microsoft's former engines for Internet Explorer and early Microsoft Edge.

History

The first widely used layout engines appeared in the mid-1990s with browsers such as Netscape Navigator and Internet Explorer. Competition between engines drove the development of web standards, and the standardization work of the W3C and WHATWG has since made engine behavior far more interoperable. In 2013 Google forked WebKit to create Blink, and in 2019 Microsoft adopted Chromium and Blink for its Edge browser, leaving Blink, Gecko and WebKit as the three principal engines.

JavaScript engines

A browser engine works alongside a separate JavaScript engine, which executes the scripting code of web pages. Examples include V8 in Chromium browsers, SpiderMonkey in Firefox and JavaScriptCore in Safari. Although distinct, the two engines cooperate closely through the DOM.
