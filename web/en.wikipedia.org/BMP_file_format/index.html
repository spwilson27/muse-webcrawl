BMP file format

The BMP file format, also known as bitmap image file, device independent bitmap (DIB) file format and bitmap, is a raster graphics image file format used to store bitmap digital images, independently of the display device. It was developed by Microsoft for the Windows operating system.

History

BMP files originated with OS/2 and early versions of Microsoft Windows. The format evolved through several versions of its header, including BITMAPCOREHEADER, BITMAPINFOHEADER, BITMAPV4HEADER and BITMAPV5HEADER, adding support for colour profiles, transparency and larger images.

File structure

A BMP file consists of a file header, a DIB header, an optional colour palette, optional bit masks, and the pixel array itself. Pixels are typically stored uncompressed in 24-bit true colour, though run-length encoding (RLE) compression is supported for 4-bit and 8-bit indexed images.

Pixel storage

Rows are padded to multiples of four bytes. By default the pixel array is stored bottom-to-top, so the first byte corresponds to the lower-left corner of the image, although a negative height in the header indicates top-down storage.

Usage

Because BMP files are usually uncompressed, they are much larger than JPEG or PNG files of the same image. The format remains common for screenshots, icons and intermediate images in Windows software. See also raster graphics and graphics file formats.
