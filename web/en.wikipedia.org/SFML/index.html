SFML

Full nameSimple and Fast Multimedia Library
Written inC++
Licensezlib License
PlatformWindows, macOS, Linux, Android, iOS

SFML (Simple and Fast Multimedia Library) is a cross-platform software development library designed to provide a simple application programming interface to various multimedia components in computers. It is written in C++ and offers modules for windowing and input, graphics, audio, networking and system utilities.

Modules

SFML is divided into five modules: System (vectors, strings, threads and clocks), Window (window creation, OpenGL contexts and input from keyboard, mouse and joysticks), Graphics (hardware-accelerated 2D rendering of sprites, text and shapes, built on OpenGL), Audio (playback and recording using OpenAL), and Network (TCP/UDP sockets and HTTP/FTP helpers).

Use and bindings

The library is popular for 2D games, prototypes and teaching, and official or community bindings exist for languages including C, .NET languages, Python, Rust, Go and others. SFML is distributed under the permissive zlib License. Major releases include SFML 2.x (from 2013) and SFML 3.0 (2024), which modernised the API and required C++17.
