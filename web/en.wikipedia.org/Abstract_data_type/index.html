Abstract data type

From Wikipedia, the free encyclopedia

In computer science, an abstract data type (ADT) is a mathematical model for data types, defined by its behaviour (semantics) from the point of view of a user — specifically, in terms of possible values and the operations allowed on data of this type — rather than by how it is implemented.

Concept

An ADT specifies what an operation does, not how. The same ADT may have many implementations: a stack, for example, can be implemented with an array or a linked list, but must support push, pop and peek with the same observable behaviour. Encapsulating the implementation behind an interface supports modularity, information hiding and reasoning about program correctness.

Examples

Common ADTs include lists, stacks, queues, priority queues, sets, maps (dictionaries), trees and graphs. Formal specification techniques range from informal interface contracts to algebraic specifications in the tradition of John Guttag, and to implementations in languages with module systems such as Barbara Liskov's CLU, which helped popularize data abstraction in the 1970s.
