Karger's algorithm

Karger's algorithm is a randomized algorithm for computing a minimum cut of an undirected graph. It was introduced by David Karger in 1993 and is based on the idea of randomly contracting edges.

Algorithm

The algorithm repeatedly picks an edge uniformly at random and merges (contracts) its two endpoints into a single supernode, combining parallel edges but discarding self-loops. When only two nodes remain, the edges between them form a cut of the original graph. A single run succeeds in finding a particular minimum cut with probability at least 2/(n(n−1)), so repeating the algorithm many times and keeping the smallest cut found makes the error probability small.

Extensions

The Karger–Stein algorithm improves the running time by using recursive contraction and is a standard example in the analysis of randomized algorithms. The algorithm is noted for its simplicity and for demonstrating the power of randomization in algorithm design.
