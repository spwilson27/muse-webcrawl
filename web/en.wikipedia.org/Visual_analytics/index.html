Visual analytics

Linked views in a visual analytics environment

Field: Information visualization, data analysis

Key text: Illuminating the Path (2005)

Visual analytics is an interdisciplinary field concerned with analytical reasoning facilitated by interactive visual interfaces. It combines automated analysis techniques, such as data mining and machine learning, with interactive visualizations so that human analysts can explore large, complex datasets, detect patterns, form hypotheses, and make decisions.

Definition and scope

The field was defined in the 2005 research agenda Illuminating the Path, edited by James J. Thomas and Kristin A. Cook, which grew out of post-9/11 efforts to help intelligence analysts cope with massive data volumes. Visual analytics emphasizes the human-in-the-loop: automated methods process and summarize data, while interactive visual representations let users steer the analysis, assess evidence, and communicate findings.

Process

The visual analytics process is iterative: data are transformed and modelled automatically, results are visualized, and user interaction generates knowledge that feeds back into the models. Sense-making frameworks such as the Pirolli–Card loop describe how analysts forage for information and build schemas. Applications include intelligence analysis, finance, public health, network security, and scientific data exploration.
