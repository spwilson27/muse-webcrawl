MESI protocol

MESI protocol
TypeCache coherence protocol
StatesModified, Exclusive, Shared, Invalid
Also known asIllinois protocol
ExtensionsMESI → MOESI, MESIF

The MESI protocol is a widely used cache coherence protocol for multiprocessor systems, also known as the Illinois protocol after its development at the University of Illinois at Urbana–Champaign. It maintains the consistency of data stored in local caches of shared resources by assigning each cache line one of four states.

States

Modified: the line is present only in this cache and has been changed; it must be written back before reuse elsewhere. Exclusive: the line is present only in this cache but is clean, matching memory. Shared: the line may be present in several caches and is clean. Invalid: the line must be treated as absent. Two additional bits per line encode the state.

Operation

Caches snoop bus transactions: a read miss that finds another cache holding a line causes it to be demoted to Shared; a write to a Shared line invalidates all other copies and upgrades the writer to Modified. The Exclusive state saves traffic by allowing silent upgrades to Modified without a bus transaction. Variants such as MOESI (adding an Owned state) and MESIF (adding a Forward state) refine the scheme in AMD and Intel processors respectively.
