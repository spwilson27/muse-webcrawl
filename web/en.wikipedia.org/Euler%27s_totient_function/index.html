Euler's totient function

Named afterLeonhard Euler
Notationφ(n)
DefinitionCount of integers 1 ≤ k ≤ n with gcd(k, n) = 1
First values1, 1, 2, 2, 4, 2, 6, 4, 6, 4, 10, …

In number theory, Euler's totient function φ(n) counts the positive integers up to a given integer n that are relatively prime to n — that is, the numbers k in 1 ≤ k ≤ n with gcd(k, n) = 1. Introduced by Leonhard Euler in 1763, it is a central function in elementary number theory and in modern cryptography.

Computing φ

By convention φ(1) = 1. For a prime p, φ(p) = p − 1, and more generally Euler's product formula states that if n has distinct prime factors p1, …, pr, then φ(n) = n ∏ (1 − 1/p). The function is multiplicative: φ(mn) = φ(m)φ(n) whenever m and n are coprime.

Euler's theorem

The totient function underlies Euler's theorem: if a is coprime to n, then aφ(n) ≡ 1 (mod n). Fermat's little theorem is the special case where n is prime. Equivalently, φ(n) is the order of the multiplicative group of integers modulo n.

Applications

The totient function is essential to the RSA cryptosystem, whose key generation relies on φ of the product of two large primes — a value that is computationally infeasible to obtain without knowing the factorization. It also appears in the classification of regular polygons constructible with compass and straightedge, in counting Farey sequences and primitive roots, and in the theory of cyclotomic polynomials: the degree of the n-th cyclotomic polynomial is φ(n). Gauss's identity Σd|n φ(d) = n connects the totient to divisor sums.
