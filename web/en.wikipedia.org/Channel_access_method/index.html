Channel access method

Channel access method
FieldTelecommunications, networking
FamiliesFDMA, TDMA, CDMA, CSMA, OFDMA
PurposeSharing a communication channel among multiple users

A channel access method (or multiple access method) is a technique that allows multiple terminals connected to the same transmission medium to share its capacity and transmit over it. It forms a central part of the medium access control sublayer in networking and of cellular radio design.

Fundamental methods

In frequency-division multiple access (FDMA), each user gets a separate slice of spectrum. In time-division multiple access (TDMA), users take turns in short time slots on the same frequency. Code-division multiple access (CDMA) separates users by distinct spreading codes, and orthogonal frequency-division multiple access (OFDMA) underlies LTE and Wi-Fi 6. Contention-based methods such as CSMA/CA, used by Wi-Fi, let stations sense the channel and back off randomly after collisions.

Applications

Every cellular generation adopted a characteristic scheme: analogue systems used FDMA, GSM combined FDMA with TDMA, 3G used CDMA, and 4G/5G use OFDMA-based schemes. Satellite links, Ethernet, and radio broadcasting all rely on channel access methods appropriate to their traffic.
