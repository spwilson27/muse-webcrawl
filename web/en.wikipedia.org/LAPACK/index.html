LAPACK

LAPACK (Linear Algebra Package) is a standard software library for numerical linear algebra. It provides routines for solving systems of linear equations, least-squares problems, eigenvalue problems, and singular value decomposition, as well as associated factorizations such as LU, QR, Cholesky and Schur decompositions.

Design

LAPACK was released in 1992 as the successor to the EISPACK and LINPACK libraries, redesigned to run efficiently on shared-memory vector and parallel processors. It achieves high performance by building most of its computation on the Basic Linear Algebra Subprograms (BLAS), especially the matrix–matrix operations of level 3 BLAS. It is written primarily in Fortran.

Implementations

Vendor-optimised implementations include Intel oneMKL and AMD Optimizing CPU Libraries, while open-source projects such as OpenBLAS and Reference BLAS/LAPACK (distributed via Netlib) underlie tools including MATLAB, NumPy/SciPy, Julia and R.
