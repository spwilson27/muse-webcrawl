Nemeth Braille

The Nemeth Braille Code for Mathematics and Science Notation is a Braille code for encoding mathematical and scientific notation linearly using standard six-dot Braille cells. It was developed by Dr. Abraham Nemeth, a blind American mathematician, and first published in 1952.

Design

The code was designed so that complex expressions — fractions, radicals, superscripts and subscripts, integrals — could be represented unambiguously in a linear stream readable on paper Braille and refreshable displays. It reuses literary Braille cells with context-dependent meanings and indicators for changes of level, allowing, for example, a fraction to be opened and closed with dedicated symbols. Nemeth code digits are written in the lower part of the cell, the opposite convention from literary Braille.

Use

Nemeth code has been the standard mathematics code in the United States and several other countries. With the adoption of Unified English Braille (UEB) in many jurisdictions, Nemeth has been retained in much of the US, with provisions ("UEB with Nemeth") for switching codes within a document.
