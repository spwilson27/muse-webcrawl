Blockly

Developer: Google
Initial release: 2012
Type: Library, visual programming editor
License: Apache License 2.0

Blockly is a free and open-source software library developed by Google for building visual block programming editors. Instead of typing code, users compose programs by dragging together interlocking graphical blocks, which resemble puzzle pieces; the library then generates syntactically correct code in languages such as JavaScript, Python, PHP, Lua, and Dart.

Design

Blockly runs entirely in a web browser and is implemented in JavaScript. Blocks are defined with connection shapes that constrain how they can fit together, so that many syntax errors are impossible by construction. Developers embedding Blockly can define custom blocks for their own domains and choose or design code generators for their target languages.

Applications

Blockly underlies a number of educational and end-user programming tools. It inspired and powers environments such as MIT's App Inventor, code.org activities, and numerous robotics and Internet-of-things programming kits aimed at children and beginners. The related Scratch environment uses a similar block metaphor developed independently.
