Separation of concerns

In computer science, separation of concerns (SoC) is a design principle for separating a computer program into distinct sections, each addressing a separate concern — a set of information that affects the code. A program embodying the principle is modular: concerns are encapsulated so that each section can be developed, understood and changed independently.

Origins

The term is associated with Edsger W. Dijkstra, who argued in the 1970s for the "separation of concerns" as the key to effective thinking about complex systems. It underlies practices such as modular programming, layered architectures, the model–view–controller pattern, and aspect-oriented programming.

Examples

In web development, HTML (content), CSS (presentation) and JavaScript (behaviour) are separated. In operating systems and frameworks, interfaces, plug-ins and microservices all implement forms of SoC.
