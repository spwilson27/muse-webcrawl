Fault tree analysis

Fault tree analysis (FTA) is a top-down, deductive failure analysis method in systems engineering and safety engineering. It uses Boolean logic gates (AND, OR) to model how component failures combine to cause an undesired top event, such as a system failure or accident.

Developed at Bell Laboratories in the 1960s for the Minuteman missile programme and widely adopted in aerospace, nuclear power, and chemical industries, FTA identifies minimal cut sets — the smallest combinations of basic events that cause the top event — and quantifies failure probabilities.
