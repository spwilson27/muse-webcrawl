Dimensionality reduction

Dimensionality reduction, or dimension reduction, is the transformation of data from a high-dimensional space into a low-dimensional space so that the low-dimensional representation retains some meaningful properties of the original data, ideally close to its intrinsic dimension.

A two-dimensional embedding of high-dimensional data.

Motivation

Working in high-dimensional spaces can be undesirable for many reasons. Raw data are often sparse, making statistical estimation difficult—a problem known as the curse of dimensionality—and distances between points become less meaningful. Reducing dimensionality can help with visualization, noise reduction, storage, and computation, and can improve the performance of machine learning algorithms.

Techniques

Linear methods include principal component analysis (PCA), linear discriminant analysis, and singular value decomposition. Nonlinear methods include t-SNE, UMAP, Isomap, kernel PCA, and autoencoders. Feature selection methods instead choose a subset of the original variables without transforming them.

Applications

Applications include data visualization, latent semantic analysis in text mining, bioinformatics (e.g., visualizing single-cell RNA sequencing data), image compression, and recommender systems.
