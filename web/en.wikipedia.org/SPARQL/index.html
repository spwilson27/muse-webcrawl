SPARQL

SPARQL (pronounced "sparkle", a recursive acronym for SPARQL Protocol and RDF Query Language) is an RDF query language — that is, a semantic query language for databases — able to retrieve and manipulate data stored in Resource Description Framework (RDF) format. It was made a W3C standard by the RDF Data Access Working Group on 15 January 2008, and version 1.1 was published in March 2013.

SPARQL queries match patterns of subject–predicate–object triples against an RDF graph.

Overview

SPARQL allows users to write queries against what can loosely be called "key-value" data or, more specifically, data that follows the RDF specification of the W3C. The entire database is thus a set of "subject–predicate–object" triples. Queries specify graph patterns containing variables, and the engine returns bindings for those variables. SPARQL supports four query forms: SELECT, CONSTRUCT, ASK and DESCRIBE, as well as update operations in SPARQL 1.1.

SELECT ?name ?birthplace
WHERE {
  ?person a <http://xmlns.com/foaf/0.1/Person> .
  ?person <http://xmlns.com/foaf/0.1/name> ?name .
  ?person <http://example.org/bornIn> ?birthplace .
}

Use

SPARQL endpoints power public knowledge bases such as Wikidata and DBpedia, enabling structured queries over the data behind Wikipedia infoboxes and the Linked Open Data cloud. Because queries can be federated, a single SPARQL query can combine results from multiple endpoints across the web.
