Linear-quadratic regulator

The linear-quadratic regulator (LQR) is an algorithm in optimal control that computes the state-feedback controller minimising a quadratic cost function for a linear time-invariant system. For the system ẋ = Ax + Bu, the cost J = ∫₀∞(xᵀQx + uᵀRu)dt balances performance (small state error) against economy of control effort through the weighting matrices Q and R.

Derivation

The optimal feedback is u = −Kx with K = R−1BᵀP, P being the stabilising solution of the continuous algebraic Riccati equation. Tuning is intuitive: increasing Q relative to R penalises state deviations more and produces a faster, more aggressive controller; increasing R produces a gentler one using less actuator effort.

Extensions

Important variants include the finite-horizon LQR, the discrete-time LQR for computer-controlled systems, output-feedback and tracking versions, and iterative LQR (iLQR), which applies the method successively to linearisations of a nonlinear problem and is popular in trajectory optimisation for robotics. Together with optimal state estimation by the Kalman filter, LQR forms the LQG control design used in many flight-control and industrial applications.
