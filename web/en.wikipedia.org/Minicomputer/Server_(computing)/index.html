Server (computing)

From Wikipedia, the free encyclopedia

RoleProvides services to client programs
OriginsTime-sharing systems and minicomputers
ExamplesWeb, file, print, database servers

In computing, a server is a piece of computer hardware or software that provides functionality for other programs or devices, called clients. The modern server descends directly from the departmental minicomputer: multi-user machines from vendors such as DEC, Data General, and Hewlett-Packard spent the 1970s and 1980s serving files, printers, and applications to terminals and, later, to networked personal computers.

As local area networks spread, former minicomputer product lines — DEC's VAX, HP's 9000 series, and IBM's AS/400 — were repositioned as servers, running server operating systems such as VMS, Unix variants, and OS/400. The arrival of inexpensive microprocessor-based machines running Windows NT and Linux completed the transition, and "server" replaced "minicomputer" as the everyday term for a shared departmental or enterprise machine.
