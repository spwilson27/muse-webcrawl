MAC spoofing

MAC spoofing is a technique for changing a factory-assigned Media Access Control (MAC) address of a network interface on a networked device. The MAC address is hard-coded on a network interface controller (NIC) and cannot ordinarily be changed; however, many drivers allow the operating system to report and use a different address, effectively masking the device's true hardware address.

Motivations

Legitimate reasons to change a MAC address include working around an internet service provider that registers service to a particular address, regaining connectivity after replacing hardware, and privacy — particularly on Wi-Fi networks, where randomising the MAC address prevents tracking of a device between locations. Modern operating systems such as iOS, Android, and Windows implement per-network MAC randomisation by default for this reason.

Misuse

MAC spoofing can also be used maliciously, for example to impersonate another device on a network, bypass access-control lists based on MAC filtering, evade device bans, or facilitate man-in-the-middle attacks when combined with other techniques. Because MAC filtering alone is easily defeated by spoofing, it is not considered a strong security control on its own.

Implementation

On Linux systems the address can be changed with tools such as ip link or utilities like GNU Macchanger; Windows exposes the setting through the network adapter's advanced properties (a "Network Address" value in the registry), and macOS through the ifconfig command. The change is normally temporary and resets when the device restarts, unless configured to persist.
