Cold start (recommender systems)

The cold start problem is a well-known challenge in recommender systems: the system cannot draw reliable inferences for users or items about which it has not yet gathered sufficient information. The problem arises in three main forms: new users, new items, and entirely new systems or communities.

Forms of the problem

New user problem: when a user first registers, the system has no record of their preferences, so personalised recommendations are impossible until some ratings or interactions accumulate. New item problem: newly added items have no ratings, so collaborative filtering methods cannot recommend them, and they may languish unnoticed. New system problem: a newly launched service has neither users nor ratings, making bootstrapping difficult.

Approaches

Common mitigations include asking new users to rate a small set of popular, diverse items during onboarding; using demographic or contextual information; defaulting to popularity-based or content-based recommendations until behavioural data exists; and hybrid models that combine collaborative filtering with content features so that new items can be recommended based on their attributes. Active learning strategies select which items to present to a new user in order to learn their tastes as quickly as possible, sometimes framed as an exploration–exploitation trade-off using multi-armed bandit methods.
