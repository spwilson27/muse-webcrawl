Turing machine

From Wikipedia, the free encyclopedia

A Turing machine is a mathematical model of computation describing an abstract machine that manipulates symbols on a strip of tape according to a table of rules. Despite the model's simplicity, it is capable of implementing any computer algorithm. The machine was invented by Alan Turing in 1936, who called it an "a-machine" (automatic machine).

Description

The machine operates on an infinite memory tape divided into discrete cells. A head reads the symbol in the current cell and, according to its internal state and a finite set of transition rules, writes a symbol, moves the tape left or right by one cell, and possibly changes state. The machine halts when it reaches a designated halting state, if it ever does.

Significance

Turing introduced the machine in his 1936 paper "On Computable Numbers" to formalise the concept of an algorithm and to give a negative answer to Hilbert's Entscheidungsproblem. He proved that there is no general method to decide whether an arbitrary Turing machine halts — the halting problem. A Turing machine capable of simulating any other Turing machine is called a universal Turing machine; the Church–Turing thesis holds that any effectively calculable function can be computed by such a machine.

Variants and analysis

Many variants — multi-tape, nondeterministic, probabilistic and quantum Turing machines — have been studied; the deterministic single-tape model remains the standard reference for classifying problems by computational complexity, including the classes P and NP.
