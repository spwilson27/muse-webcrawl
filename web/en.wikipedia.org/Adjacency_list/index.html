Adjacency list

A graph and its adjacency list representation.

In graph theory and computer science, an adjacency list is a collection of unordered lists used to represent a finite graph. Each list describes the set of neighbours of a particular vertex in the graph. This is one of several commonly used representations of graphs for use in computer programs, alongside the adjacency matrix and the incidence matrix.

Implementation details

An adjacency list representation for a graph associates each vertex in the graph with the collection of its neighbouring vertices or edges. There are many variations of this basic idea, differing in the details of how they implement the association between vertices and collections, how they implement the collections, whether they include both directions of an edge or only one, and what kind of information is stored in each adjacency entry.

A common implementation uses an array or hash table indexed by vertex, where each entry holds a linked list, dynamic array, or set of adjacent vertices. For undirected graphs, each edge appears twice: once in the list of each endpoint. For directed graphs, the edge appears only in the list of its source vertex, unless in-neighbour lists are also maintained.

Example

0: 1, 2
1: 0, 2, 3
2: 0, 1
3: 1

This represents an undirected graph with vertices 0–3, in which vertex 1 is connected to vertices 0, 2 and 3.

Operations and complexity

Adjacency lists use space proportional to the number of vertices plus the number of edges, O(|V| + |E|), which is efficient for sparse graphs. Iterating over all neighbours of a vertex takes time proportional to its degree. Testing whether an edge exists between two given vertices requires scanning one adjacency list, taking O(degree) time in the worst case, although using hash sets for adjacency collections can reduce this to expected constant time. Adding a vertex or edge is cheap, while removing a vertex requires updating all lists that mention it.

Comparison with adjacency matrices

An adjacency matrix uses O(|V|2) space regardless of the number of edges, so adjacency lists are strongly preferred when the graph is sparse. However, matrices allow O(1) edge-existence tests and simpler implementation, and they can be preferable for dense graphs or when matrix operations are used in algorithms.

Adjacency lists are the standard representation used by graph traversal algorithms such as breadth-first search and depth-first search, as well as shortest-path algorithms such as Dijkstra's algorithm.
