.NET (pronounced "dot net") is a free and open-source software framework developed by Microsoft for building applications that run on Windows, Linux, macOS and other platforms. Programs written for .NET typically use languages such as C#, F# and Visual Basic, and execute on a runtime — the Common Language Runtime (CLR) — that provides memory management, type safety and exception handling.

History

Microsoft released the original .NET Framework in 2002 as a Windows-only platform positioned against Java. In 2016 Microsoft introduced .NET Core, a modular, cross-platform reimplementation released as open source. With .NET 5 in 2020 the two lines were unified under the single ".NET" name, with annual releases thereafter, and stewardship shared with the independent .NET Foundation.

Architecture

.NET languages compile to Common Intermediate Language (CIL), which the CLR just-in-time compiles to native code. The platform includes a large base class library, the NuGet package ecosystem, and application frameworks such as ASP.NET Core for web services, Windows Forms and WPF for Windows desktop applications, and .NET MAUI for cross-platform mobile and desktop apps.

Standardisation

Parts of the platform — the Common Language Infrastructure and C# — are standardised by Ecma International and the ISO, enabling independent implementations such as Mono, which powers the Unity game engine's scripting environment.
