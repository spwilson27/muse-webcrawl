CPAN

The CPAN archive network holds hundreds of thousands of Perl modules.

The Comprehensive Perl Archive Network (CPAN) is a repository of software and documentation for the Perl programming language. Established in 1995, it is one of the earliest large-scale open-source code archives — predating similar repositories for other languages — and contains well over 200,000 modules in tens of thousands of distributions, contributed by thousands of authors and replicated on mirrors worldwide.

Organisation

Authors upload distributions through the PAUSE (Perl Authors Upload Server), which authenticates contributors and indexes modules by name, assigning primary maintainership of each module namespace. Every distribution is automatically unpacked, indexed and tested by a network of volunteer "CPAN Testers" on many operating systems and Perl versions, producing public test reports. Search and browsing interfaces, notably MetaCPAN (launched in 2011), provide dependency information, source viewing, ratings and release histories.

Software tools

Perl installations traditionally ship with a CPAN client (CPAN.pm) that fetches, builds, tests and installs modules and their dependencies; the lighter CPANPLUS and the popular third-party cpanminus (cpanm) are alternatives. Installing from CPAN integrates modules into Perl's library paths, and conventions such as Makefile.PL and Build.PL, later standardised with Module::Build and Dist::Zilla tooling, govern how distributions are packaged.

Influence

CPAN is frequently cited as a model — and the origin of the "-PAN" naming joke — for later language ecosystems' package archives, such as CTAN for TeX (which actually predates it and inspired its name), CRAN for R, and PyPI for Python. The archive's size and quality variance have both been praised and satirised within the Perl community; curated lists of recommended modules supplement the open archive. CPAN Day, 16 August, commemorates the first recorded upload.
