Developer: AT&T Bell Laboratories / GNU Project

cpio is a general file archiver utility and its associated file format. It is primarily installed on Unix-like computer operating systems. The software has its origins in the original AT&T Unix and was included in the Programmer's Workbench (PWB/UNIX). Like the tar utility, cpio reads and writes archive files, but it copies files into and out of archives rather than simply combining them, which is reflected in its name: copy in, copy out.

History

cpio was created by Dick Haight at AT&T and first appeared in PWB/UNIX in the late 1970s. It was later standardised as part of POSIX.1-1988, although POSIX later removed the format in favour of the pax format. A free implementation, GNU cpio, is maintained by the GNU Project.

Operation

Unlike tar, cpio does not take the list of files to archive from its command-line arguments; instead it reads the list of filenames from standard input. It operates in three main modes:

  • Copy-out mode (-o): reads a list of filenames from standard input and copies the files into an archive written to standard output.
  • Copy-in mode (-i): reads an archive from standard input and extracts the files into the current directory.
  • Pass-through mode (-p): copies a directory tree from one location to another without creating an archive.

Archive format

The cpio archive format stores each file preceded by a header containing metadata such as the filename, permissions, ownership and timestamps. Two header variants exist: the older binary format and the newer portable ASCII ("newc") format, the latter used by the Linux kernel's initramfs and by the RPM Package Manager.
