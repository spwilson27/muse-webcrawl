TIFF

Filename extension.tif, .tiff
Developed byAldus Corporation (later Adobe)
Initial release1986
TypeRaster image file format

TIFF (Tag Image File Format) is a flexible, adaptable file format for storing raster graphics, popular among graphic artists, photographers, and the publishing industry.

Features

TIFF supports lossless LZW compression as well as lossy JPEG compression, multiple colour spaces and bit depths, and multiple images per file. Its tag-based structure allows extensive metadata and private extensions.

History

Created by Aldus in 1986 to unify scanned image formats for desktop publishing, the specification passed to Adobe with its acquisition of Aldus in 1994. Revision 6.0 of 1992 remains the baseline standard.

Use

TIFF is widely used for archival storage, medical and scientific imaging (including GeoTIFF for georeferenced data), and professional print workflows.
