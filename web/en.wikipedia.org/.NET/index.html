.NET

.NET (pronounced "dot net") is a free, open-source, cross-platform developer platform created by Microsoft for building many types of applications. Programs written for .NET execute on the Common Language Runtime (CLR), a virtual machine that provides services such as memory management, type safety and exception handling, and they are typically written in C#, F# or Visual Basic.

History

Microsoft released the original .NET Framework in 2002 for Windows development. In 2016 the company released .NET Core, a modular, cross-platform reimplementation, as open-source software. With the release of version 5 in November 2020, the "Core" branding was dropped and the platform was simply named .NET, unifying the Framework and Core lineages. New major versions have since been released annually, with even-numbered versions (6, 8) designated long-term support (LTS) releases.

Architecture

Source code in supported languages is compiled to an intermediate language (CIL) stored in assemblies. At run time the CLR's just-in-time compiler translates the CIL to native machine code. The platform includes a large class library covering collections, file I/O, networking, cryptography, and data access. Application models built on .NET include ASP.NET Core for web services, Blazor for interactive web user interfaces, .NET MAUI for cross-platform desktop and mobile apps, and Windows Forms and WPF for Windows desktop software.

Languages

C# is the flagship language of the platform. F# is a functional-first language maintained with the F# Software Foundation, and Visual Basic remains supported for existing applications. Because all languages target the Common Language Infrastructure, libraries written in one language can generally be consumed from the others.
