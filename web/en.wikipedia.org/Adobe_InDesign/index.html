Adobe InDesign is a desktop publishing and page layout design software application first released by Adobe in 1999. It can be used to create works such as posters, flyers, brochures, magazines, newspapers, presentations, books and ebooks. InDesign can also publish content suitable for tablet devices in conjunction with Adobe Digital Publishing Suite. Graphic designers and production artists are the principal users.

History

InDesign was positioned as a successor to Adobe PageMaker, which Adobe had acquired with Aldus in 1994, and as a competitor to QuarkXPress, then dominant in professional publishing. InDesign introduced features such as support for Unicode, advanced typography with OpenType fonts, transparency effects, and cross-platform scripting. Version 2.0, released in 2002, was the first desktop publishing application to ship natively for Mac OS X.

With InDesign CS3, the application became part of Adobe Creative Suite, and from 2013 onward it was distributed through the Adobe Creative Cloud subscription service. InDesign files use the .indd extension; the InDesign Markup Language (IDML) provides an XML-based interchange format.

Features

InDesign offers precise control over typography, including kerning, tracking, paragraph composition, optical margin alignment and hyphenation, along with paragraph and character styles. Layout features include parent (master) pages, layers, tables, anchored objects, text wrapping and data merge. The application supports long-document workflows with books, tables of contents and indexes, and it can export print-ready PDF files as well as interactive PDF, EPUB and HTML documents.

InDesign integrates with other Adobe applications: images are commonly prepared in Photoshop and illustrations in Illustrator, then placed and linked in InDesign layouts. A server version, InDesign Server, enables automated publishing workflows.

International versions

Special editions support complex scripts and vertical or right-to-left text for languages including Arabic, Hebrew, Japanese, Chinese and Korean. InDesign's text engine provides shaping for these scripts in the appropriate editions.
