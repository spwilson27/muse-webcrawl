Lyapunov function

In the theory of ordinary differential equations, Lyapunov functions, named after Aleksandr Lyapunov, are scalar functions that may be used to prove the stability of an equilibrium of a dynamical system.

Definition

A Lyapunov function for an equilibrium is a positive-definite function V whose derivative along system trajectories is negative (semi-)definite. If such a function exists, Lyapunov's direct method shows the equilibrium is (asymptotically) stable, without solving the system explicitly.

Applications

Lyapunov functions are central to control theory, where candidate functions such as energy-like quadratics are used to design and certify stabilizing controllers, including in adaptive and nonlinear control.
