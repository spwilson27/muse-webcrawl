Convex hull

In geometry, the convex hull, convex envelope or convex closure of a shape is the smallest convex set that contains it. For a set of points in the plane, the convex hull can be visualized as the shape enclosed by a rubber band stretched around the set. Formally, the convex hull of a set X is the intersection of all convex sets containing X, equivalently the set of all convex combinations of points in X.

Computation

Computing the convex hull of a finite point set is a fundamental problem in computational geometry. In two dimensions, algorithms such as Graham scan, Jarvis march and Andrew's monotone chain run in O(n log n) time (output-sensitive methods can do better). The problem generalizes to three and higher dimensions, where hulls are polyhedra; software such as Qhull computes them efficiently in practice. In the plane, hulls can also be computed in linear time from a polygonal chain or from points sorted by coordinate.

Applications

Convex hulls are used in pattern recognition, image processing, statistics (e.g., hull-based estimators and depth measures), geographic information systems, collision detection in games and robotics, and in operations research, where the convex hull of feasible integer points is central to integer programming. Related structures include the Delaunay triangulation, which is dual to the Voronoi diagram and can be obtained from a convex hull in one higher dimension.
