Cantor's theorem

Illustration of Cantor's diagonal argument (placeholder)

Cantor's theorem is a fundamental result in mathematical set theory, proved by Georg Cantor in 1891. It states that for any set A, the set of all subsets of A — its power set, denoted ℙ(A) — has a strictly greater cardinality than A itself. In other words, there is no surjection (and hence no bijection) from a set onto its power set.

Statement

Formally, for every set A, the cardinality of A is strictly less than the cardinality of its power set: |A| < |ℙ(A)|. The theorem holds for finite sets as well: a set with n elements has a power set with 2n elements. Its most striking consequence, however, concerns infinite sets: it implies that there are infinitely many distinct infinite cardinalities, since starting from any infinite set one can repeatedly take power sets to obtain ever larger infinities.

Proof

Cantor's proof proceeds by contradiction using the famous diagonal argument. Suppose there were a surjective function f from A onto ℙ(A). Consider the set B = { x ∈ A : x ∉ f(x) }. Since f is assumed surjective, there must be some element b ∈ A with f(b) = B. But then b ∈ B if and only if b ∉ f(b) = B, a contradiction. Therefore no such surjection exists, and the power set is strictly larger.

Consequences

Applied to the natural numbers, the theorem shows that the set of real numbers (which can be put in correspondence with the power set of the naturals, or with infinite binary sequences) is uncountable. Cantor's theorem also underlies the concept of the beth numbers and is closely related to Russell's paradox, whose diagonal set construction mirrors Cantor's. The theorem implies that there is no "set of all sets" and no largest cardinal number.

History

Cantor published the result in his 1891 paper "Über eine elementare Frage der Mannigfaltigkeitslehre", which also introduced the diagonal argument to prove the uncountability of the real numbers. The theorem became a cornerstone of modern set theory and of the mathematical understanding of infinity.
