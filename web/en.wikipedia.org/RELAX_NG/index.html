RELAX NG

RELAX NG
Type: XML schema language
Standard: ISO/IEC 19757-2
Developed from: RELAX and TREX

RELAX NG is a schema language for XML documents. The name is an acronym for Regular Language for XML Next Generation. It was developed by merging two earlier schema languages, RELAX (by Murata Makoto) and TREX (by James Clark), and was standardized by OASIS and later as part of ISO/IEC 19757, the Document Schema Definition Languages (DSDL) family.

Syntaxes

RELAX NG schemas can be written in two syntaxes: an XML-based syntax and a compact non-XML syntax designed to be easier for humans to read and write. The two syntaxes express the same grammar model, and tools such as Trang can convert between them.

Features

RELAX NG is based on regular tree grammars: a schema describes patterns that match elements, attributes, and text content. It supports datatypes (commonly borrowed from W3C XML Schema), namespaces, interleaving, and mixed content, while deliberately omitting some features of XML Schema such as identity constraints. Popular tools supporting RELAX NG include the Jing validator.
