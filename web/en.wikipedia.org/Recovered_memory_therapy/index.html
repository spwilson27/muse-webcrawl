Recovered memory therapy

Recovered memory therapy is a catch-all term for a range of psychotherapeutic methods, used mainly in the 1980s and 1990s, that aimed to recover supposedly repressed memories of traumatic events, particularly childhood sexual abuse. Techniques included hypnosis, guided imagery, dream interpretation, and age regression.

Controversy

The practice became highly controversial when accusations based on recovered memories led to criminal prosecutions and family estrangements, and critics argued that suggestive techniques could create vivid but false memories. Research by memory scientists such as Elizabeth Loftus demonstrated that false memories can be implanted through suggestion.

Aftermath

Professional bodies issued cautions about the reliability of memories recovered through these methods, some patients later retracted their claims, and a number of therapists faced malpractice suits. The episode, sometimes linked to the "Satanic panic", remains a cautionary episode in the history of psychotherapy.
