Home directory

A home directory is a file system directory on a multi-user operating system containing files for a given user. It stores the user's personal files, configuration settings, and application data, and is the default working directory at login.

Conventions

On Unix-like systems, home directories are usually located under /home (or /Users on macOS) and are denoted by the tilde character ~ and the HOME environment variable. On Windows, the user profile folder is generally under C:\Users.

Organization

Systems define standard subdirectories for documents, downloads, pictures, and music; freedesktop.org's XDG user directories specification formalizes these on Linux. Hidden configuration files in the home directory are traditionally named with a leading dot.
