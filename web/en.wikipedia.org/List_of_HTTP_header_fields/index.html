List of HTTP header fields

HTTP header fields are components of the header section of request and response messages in the Hypertext Transfer Protocol (HTTP). They define the operating parameters of an HTTP transaction.

General and request fields

FieldPurpose
AcceptMedia types acceptable for the response
Accept-EncodingContent encodings the client supports, e.g. gzip
Accept-LanguagePreferred natural languages
AuthorizationCredentials for HTTP authentication
CookieStored cookies sent by the server
HostDomain name of the server (required in HTTP/1.1)
RefererAddress of the previous web page
User-AgentClient software identifier

Response fields

FieldPurpose
Content-TypeMedia type of the response body
Content-LengthSize of the body in bytes
Cache-ControlCaching directives
ETagValidator for conditional requests
LocationURL for redirection
Set-CookieSends a cookie to the client
ServerServer software identification
