Shader

Shaders compute the colour, lighting and position of rendered geometry.

In computer graphics, a shader is a program that runs on a graphics processing unit (GPU) and calculates rendering effects, most commonly the position, colour and lighting of vertices and pixels. Originally named for programs that computed shading, modern shaders have grown into general stages of the rendering pipeline and, with compute shaders, into general-purpose parallel computing.

Types

Vertex shaders process each vertex, transforming positions and passing data such as normals and texture coordinates down the pipeline. Fragment (or pixel) shaders compute the colour of each fragment, applying textures, lighting models and effects like reflections and shadows. Optional stages include geometry shaders, which can generate new primitives, and tessellation shaders, which subdivide surfaces. Compute shaders, exposed in modern APIs, run arbitrary parallel workloads outside the graphics pipeline and are used for physics, image processing and machine learning.

Languages and history

Shaders were written in assembly-like languages on early programmable GPUs around 2000, then in high-level languages: HLSL for DirectX, GLSL for OpenGL and Vulkan (via SPIR-V), and Metal Shading Language for Apple platforms. Pixar's RenderMan Shading Language had pioneered the concept for offline film rendering in the 1980s. Languages such as Shadertoy popularised fragment-shader programming in the browser. Programmable shading replaced the fixed-function pipeline and underlies virtually all real-time graphics today, from games to user interfaces.
