Prefix code

A prefix code is a type of code system (typically a variable-length code) distinguished by the possession of the "prefix property", which requires that there is no whole code word in the system that is a prefix (initial segment) of any other code word in the system. It is trivially true for fixed-length code systems, but not at all trivial for variable-length ones.

Properties

Because no code word is a prefix of another, a stream encoded with a prefix code can be decoded unambiguously from left to right without separators: as soon as a code word is recognised, the decoder knows it is complete. Prefix codes correspond exactly to leaf labellings of binary trees, and the code word lengths of a prefix code satisfy the Kraft–McMillan inequality.

Examples

Huffman coding produces optimal prefix codes for a given set of symbol frequencies and is used widely in data compression (DEFLATE, JPEG, MP3). Telephone country calling codes form a prefix code, so that no country's code is the beginning of another's. Morse code, by contrast, is not a prefix code over its symbols alone — it relies on timing gaps as separators.
