Continuous function

In mathematics, a continuous function is a function such that a continuous variation of the argument induces a continuous variation of the value — intuitively, a function whose graph can be drawn without lifting the pen. Formally, a real function f is continuous at a point c if the limit of f(x) as x approaches c equals f(c).

Definitions

The ε–δ definition states that f is continuous at c if for every ε > 0 there is a δ > 0 such that |x − c| < δ implies |f(x) − f(c)| < ε. In topology, a function between topological spaces is continuous if the preimage of every open set is open. A function continuous at every point of its domain is simply called continuous.

Properties

Sums, products and compositions of continuous functions are continuous. The intermediate value theorem says a continuous function on an interval attains every value between any two of its values, and the extreme value theorem guarantees that a continuous function on a closed bounded interval attains a maximum and minimum. Uniform continuity is a stronger property relevant on unbounded domains.

Discontinuities

Points of discontinuity are classified as removable, jump, or essential (infinite/oscillatory). The Weierstrass function is continuous everywhere but differentiable nowhere, showing continuity does not imply smoothness.
