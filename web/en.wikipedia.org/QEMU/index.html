QEMU

QEMU (short for "Quick Emulator") is a free and open-source emulator. It emulates a computer's processor through dynamic binary translation and provides a set of different hardware and device models for the machine, enabling it to run a variety of guest operating systems. It can interoperate with Kernel-based Virtual Machine (KVM) to run virtual machines at near-native speed. QEMU can also do emulation for user-level processes, allowing applications compiled for one processor architecture to run on another.

QEMU was written by Fabrice Bellard and is free software, mainly licensed under the GNU General Public License, version 2. It supports the emulation of a wide range of processors, including x86, ARM, RISC-V, PowerPC, SPARC, MIPS and many others, and can emulate complete computer systems including peripherals such as network cards, storage controllers and graphics adapters.

Operation

QEMU can run in several modes. In full system emulation mode, it emulates an entire computer system, including the processor and various peripherals, allowing an unmodified guest operating system to run. In user-mode emulation, available on Linux hosts, QEMU can launch processes compiled for one CPU on another CPU, translating system calls as needed. When combined with a hardware hypervisor such as KVM on Linux, Xen, or Hypervisor.Framework on macOS, QEMU provides the device model while the hypervisor executes guest code directly on the host CPU, giving near-native performance.

Features

QEMU supports snapshots of virtual machine state, live migration of running guests between hosts, virtual networking, USB passthrough, and a monitor console for management. Its companion tools include qemu-img for creating and converting disk images in formats such as qcow2 and raw. QEMU forms the foundation of many virtualization and cloud platforms and is widely used for software development, testing, and cross-platform emulation.
