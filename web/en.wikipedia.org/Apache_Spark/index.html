Apache Spark is an open-source, unified analytics engine for large-scale data processing, developed at the University of California, Berkeley's AMPLab and later donated to the Apache Software Foundation. It provides interfaces in Scala, Java, Python (PySpark), R, and SQL, and supports batch processing, streaming, machine learning, and graph computation.

History

Spark was created by Matei Zaharia in 2009 and open-sourced in 2010. It became an Apache top-level project in 2014. Databricks, founded by Spark's creators, provides a commercial cloud platform based on it.

Architecture

Spark's core abstraction was originally the resilient distributed dataset (RDD), a fault-tolerant collection of elements partitioned across a cluster. Later versions emphasise DataFrames and Datasets with the Catalyst query optimiser and Tungsten execution engine. By keeping data in memory where possible, Spark can be far faster than disk-based MapReduce for iterative workloads.

Components

The Spark ecosystem includes Spark SQL, Structured Streaming, MLlib for machine learning, and GraphX for graph processing.
