Wayland

Wayland is a display server protocol and a reference implementation of a windowing system for Linux and other Unix-like operating systems. It is intended to replace the X Window System as the standard display technology on the Linux desktop, offering a simpler architecture in which the compositor is the display server itself.

History

Wayland was started in 2008 by Kristian Høgsberg, then a developer at Red Hat, as a personal project to rethink how graphical desktops draw to the screen. Under X11, applications render into off-screen buffers managed by a separate server and compositor, adding latency and complexity. Wayland collapses these roles: every frame is rendered by the client into a buffer, and the compositor combines those buffers directly for display.

Architecture

Type: Display server protocol

The Wayland protocol defines communication between a compositor and its clients over Unix domain sockets. The core protocol is deliberately minimal; functionality such as window management, screenshots, and global shortcuts is provided by protocol extensions, including those developed under the wlroots and xdg-shell efforts. Clients typically use libraries such as GTK, Qt, or SDL, which hide the protocol details.

Applications written for X11 can still run through XWayland, a compatibility layer that runs a nested X server as a Wayland client.

Adoption

GNOME and KDE Plasma both support Wayland sessions, and major distributions such as Fedora have shipped Wayland as the default session since 2016. The Weston compositor serves as the reference implementation of a Wayland compositor.
