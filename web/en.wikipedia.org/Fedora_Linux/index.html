Fedora Linux

Fedora Linux
Developer: Fedora Project
Initial release: 6 November 2003
Package manager: RPM / DNF
Kernel: Linux (monolithic)
License: Free software (various)

Fedora Linux is a Linux distribution developed by the Fedora Project. It was originally developed in 2003 as a continuation of the Red Hat Linux project and is sponsored by Red Hat (now a subsidiary of IBM). Fedora contains software distributed under various free and open-source licenses and aims to be on the leading edge of free technologies — it is the upstream source for Red Hat Enterprise Linux.

Features

Fedora is known for its rapid release cycle (a new version roughly every six months), its adoption of new technologies such as Wayland, systemd, SELinux and PipeWire ahead of most distributions, and its commitment to free software. The default desktop environment is GNOME; official "Spins" offer KDE Plasma, Xfce, LXQt and others, while immutable "Atomic" variants include Silverblue.

Editions

The main editions are Fedora Workstation (desktop), Fedora Server, Fedora IoT, Fedora CoreOS and Fedora Cloud. Fedora uses the RPM package format with the DNF package manager and the Anaconda installer.

History

Fedora Core 1 was released on 6 November 2003, after Red Hat discontinued Red Hat Linux in favour of Red Hat Enterprise Linux and the community Fedora Project. The distribution dropped "Core" from its name with Fedora 7 (2007). The Fedora Project is governed by a community council and employs a project leader appointed by Red Hat.

Releases

Versions are released approximately every six months, each supported for about 13 months. Recent releases in the 30s and 40s series have continued the pattern of integrating current kernel, GNOME and compiler toolchain versions. Linus Torvalds, creator of the Linux kernel, has said he uses Fedora on his workstations.
