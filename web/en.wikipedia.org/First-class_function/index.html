First-class function

In computer science, a programming language is said to have first-class functions if it treats functions as first-class citizens. This means the language supports passing functions as arguments to other functions, returning them as the values from other functions, and assigning them to variables or storing them in data structures. Some languages commonly cited as supporting the concept include Lisp, Haskell, JavaScript, Python, Ruby and, with lambdas, modern C++ and Java.

History

The notion derives from the philosophy of Christopher Strachey, who in the 1960s distinguished "first-class" entities — which can be passed, returned and stored freely — from "second-class" ones subject to restrictions. Lisp, designed in the late 1950s, supported functions as data from early on, though lexical scoping for closures awaited Scheme in the 1970s.

Related concepts

First-class functions enable higher-order functions such as map and filter, and together with closures they are a foundation of functional programming style. Languages without first-class functions often emulate them with function pointers (as in C) or single-method objects.
