Formal methods

In computer science, formal methods are mathematically rigorous techniques for the specification, development, analysis, and verification of software and hardware systems. The use of formal methods is motivated by the expectation that, as in other engineering disciplines, performing appropriate mathematical analysis can contribute to the reliability and robustness of a design.

Techniques

Formal methods range from lightweight approaches—such as precise formal specification languages (e.g., Z, VDM, TLA+)—to full formal verification, in which properties of a system are proved mathematically. Model checking automatically explores a system's state space to verify temporal properties, while theorem proving uses logical deduction, often assisted by tools such as Coq or Isabelle. Static analysis tools apply abstract interpretation to find defects without executing the program.

Applications

Formal methods are applied where failure is costly: avionics and railway signalling, cryptographic protocols, compiler verification (such as the CompCert verified C compiler), and microprocessor design. The verified seL4 microkernel is a prominent example of a complete operating-system kernel proved correct against its specification.

Criticism

Formal methods can be expensive and require specialized expertise; proofs also verify a system only against its specification, which may itself be incomplete or wrong. Nonetheless, their use continues to grow in safety- and security-critical industries.
