Attention (machine learning)

Attention is a machine learning method that determines the relative importance of each component in a sequence relative to the other components in that sequence. In neural networks, attention is a process used to focus on the most relevant parts of the input sequence, in a way that resembles human attention. The mechanism assigns weights to different elements of an input sequence, enabling the model to highlight the most relevant information for the tasks, such as generating the next word in machine translation.

Scaled dot-product attention, the core operation of the Transformer.

History

Attention was introduced for neural machine translation in 2014 by Bahdanau, Cho and Bengio, allowing a decoder to consult all encoder states rather than a single fixed-length context vector. In 2017, the paper "Attention Is All You Need" by Vaswani and colleagues introduced the Transformer architecture, which relies entirely on self-attention mechanisms, dispensing with recurrence and convolutions entirely.

Mechanism

In the standard formulation, each input element is projected into three vectors: a query, a key and a value. Attention scores are computed as the scaled dot product of queries and keys, normalised with a softmax function, and used as weights to form a weighted sum of the values. Multi-head attention runs several such operations in parallel, allowing the model to attend to information from different representation subspaces simultaneously.

Variants

Variants include self-attention, in which a sequence attends to itself; cross-attention, in which one sequence attends to another; and masked attention, used in autoregressive decoders to prevent positions from attending to future tokens. Efficient variants seek to reduce the quadratic computational cost of attention over long sequences.

Applications

Attention underlies most modern large language models, as well as advances in computer vision (vision transformers), speech recognition, protein structure prediction and reinforcement learning.
