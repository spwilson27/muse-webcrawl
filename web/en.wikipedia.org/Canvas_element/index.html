Canvas element

Introduced2004, by Apple (Safari/WebKit)
StandardizedWHATWG HTML Living Standard; W3C HTML5
APIsCanvas 2D Context; WebGL; WebGPU

The canvas element is part of HTML5 and allows for dynamic, scriptable rendering of 2D shapes and bitmap images in web pages. It is a low-level, procedural model that updates a bitmap region; elements drawn on a canvas have no scene graph or DOM representation of their own. Scripts access the drawing surface through rendering contexts, principally the Canvas 2D API and the 3D-oriented WebGL API.

Shapes rendered in the browser with the canvas 2D API.

History

Canvas was introduced by Apple in 2004 for use in Mac OS X Dashboard widgets and the Safari browser, and was later standardized by the WHATWG and incorporated into the HTML5 specification. Apple's early patent claims on the technology caused controversy, but the company later disclosed its related patents under royalty-free terms through the W3C process.

Usage

A canvas is declared with width and height attributes; JavaScript obtains a context and issues drawing commands:

<canvas id="c" width="200" height="100"></canvas>
<script>
  const ctx = document.getElementById('c').getContext('2d');
  ctx.fillStyle = '#3366cc';
  ctx.fillRect(10, 10, 150, 75);
</script>

The 2D context supports paths, fills, strokes, gradients, patterns, text, image drawing, compositing, and pixel manipulation via ImageData. Canvas is widely used for charts, games, photo editors, data visualization, and browser-based creative tools. Unlike SVG, which is resolution-independent and retains a document model, canvas is resolution-dependent and raster-based, though it can be redrawn at device pixel ratios for sharpness.

Accessibility and fallback

Content placed between the canvas tags is displayed by browsers that do not support the element and can serve as fallback content. Because canvas graphics are opaque to assistive technologies, authors are advised to provide text alternatives or accessible equivalents.
