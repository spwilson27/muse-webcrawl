Power set

In mathematics, the power set (or powerset) of a set S is the set of all subsets of S, including the empty set and S itself. In axiomatic set theory (as in ZFC), the existence of the power set of any set is postulated by the axiom of power set. The power set of S is variously denoted as P(S), 𝑩(S), 2S, or {0,1}S.

Example

If S = {x, y, z}, then the subsets of S are: the empty set {}; {x}; {y}; {z}; {x, y}; {x, z}; {y, z}; and {x, y, z}. The power set therefore has eight elements.

Cardinality

If S is a finite set with |S| = n elements, then the number of subsets of S is 2n. Cantor's theorem states that the power set of any set (finite or infinite) always has strictly higher cardinality than the set itself — in particular, the power set of a countably infinite set is uncountable. The elements of a power set can be put in one-to-one correspondence with the indicator (characteristic) functions on the original set.

Properties

The power set of a set forms a Boolean algebra under the operations of set union, intersection and complement, and it is a standard example of a complete lattice. The binomial theorem is connected to the power set: the number of subsets with k elements is given by the binomial coefficient.
