Window manager

A window manager is system software that controls the placement and appearance of windows within a graphical user interface. It decides where windows appear on the screen, how they are decorated with borders and title bars, and how users move, resize, minimize, and switch between them.

TypeSystem software
ExamplesMutter, KWin, Explorer shell, Quartz Compositor, twm, i3
StylesStacking, tiling, compositing

Functions

Window managers handle window placement, focus policy (which window receives keyboard input), decorations, workspaces or virtual desktops, and interactions such as dragging and snapping. In the X Window System the window manager is a separate client program, which made Unix desktops famously customizable; on other systems the function is integrated into the shell or compositor.

Types

Stacking (or floating) window managers let windows overlap like papers on a desk. Tiling window managers arrange windows in non-overlapping frames that fill the screen, popular with keyboard-oriented users. Compositing window managers render each window to its own buffer and combine them, enabling transparency, shadows, and animation effects; modern systems such as Windows (via the Desktop Window Manager), macOS, and Wayland compositors work this way.

History

Overlapping windows were pioneered at Xerox PARC in the 1970s and popularized by the Apple Macintosh (1984) and Microsoft Windows. On Unix, window managers such as twm, fvwm, Enlightenment, Metacity, and KWin accompanied desktop environments like GNOME and KDE.
