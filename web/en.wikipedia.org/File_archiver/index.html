File archiver

A file archiver is a computer program that combines multiple files into a single archive file, often with compression, for easier storage and transfer.

Common formats include ZIP, TAR, RAR and 7z, produced by utilities such as tar, gzip, WinRAR, WinZip and 7-Zip. Archivers preserve metadata such as filenames, directory structure, timestamps and permissions, and may add error detection and encryption.
