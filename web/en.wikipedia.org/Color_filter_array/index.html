Color filter array

A color filter array (CFA), or color filter mosaic (CFM), is a mosaic of tiny color filters placed over the pixels of an image sensor in a digital camera so that each pixel records only one color channel. The full-color image is then reconstructed by interpolation in a process called demosaicing.

Bayer filter

The most common CFA is the Bayer filter, patented by Bryce Bayer of Eastman Kodak in 1976. Its 2×2 repeating cell contains two green filters on opposite corners and one red and one blue filter. Green is sampled at twice the rate of red and blue because human vision is most sensitive to green light and derives most luminance detail from it. Nearly all consumer digital cameras and smartphones use a Bayer-pattern sensor.

Other patterns

Alternatives include Fujifilm's X-Trans pattern, which uses a 6×6 arrangement designed to reduce moiré without an optical low-pass filter; RGBW arrays that add unfiltered "white" pixels for low-light sensitivity; and the Foveon X3 sensor, which stacks photodetectors to capture all three colors at every pixel and therefore needs no CFA. CYGM arrays (cyan, yellow, green, magenta) were used in a few early cameras.

Demosaicing

Because each pixel senses only one color, the missing two values at each location must be interpolated from neighbours. Simple bilinear interpolation is fast but can produce zippering and false-color artifacts; more advanced algorithms use edge direction and inter-channel correlation to reconstruct sharper, cleaner images.
