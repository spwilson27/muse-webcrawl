Strongly NP-complete

In computational complexity theory, a problem is said to be strongly NP-complete if it is NP-complete even when all of its numerical parameters are bounded by a polynomial in the length of the input. A problem is said to be weakly NP-complete if it is NP-complete only when the numerical parameters are allowed to be exponentially large relative to the input size.

Definitions

More formally, a decision problem is strongly NP-complete if it remains NP-complete even when restricted to instances in which all numbers in the input are bounded by a polynomial in the length of the input. This is usually stated by considering a unary encoding of numbers: a strongly NP-complete problem stays NP-complete even if numbers are written in unary rather than binary.

Strong NP-completeness is defined in terms of the notion of a pseudo-polynomial time algorithm: an algorithm whose running time is polynomial in the numeric value of the largest input number, but exponential in the length (bit-size) of the input. A problem that is NP-complete in the ordinary (weak) sense may admit a pseudo-polynomial algorithm, while a strongly NP-complete problem cannot have one unless P = NP.

Examples

Examples of strongly NP-complete problems include the bin packing problem (in its decision form with certain restrictions), the job-shop scheduling problem, the travelling salesman problem (decision version), the 3-partition problem, and many scheduling and routing problems.

By contrast, the knapsack problem and the subset sum problem are weakly NP-complete: both admit pseudo-polynomial algorithms based on dynamic programming.

Consequences

Strong NP-completeness rules out not only polynomial-time algorithms but also fully polynomial-time approximation schemes (FPTAS) for the corresponding optimization problems, unless P = NP, because an FPTAS for a problem with polynomially bounded objective values would yield an exact pseudo-polynomial algorithm. This makes strong NP-completeness a powerful tool for proving the inapproximability of optimization problems.
