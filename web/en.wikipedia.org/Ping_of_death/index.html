Ping of death

A ping of death is a type of attack on a computer system that involves sending a malformed or otherwise malicious ping to a computer. It exploits the way early implementations of the Internet Protocol handled oversized ICMP packets.

Mechanism

The maximum size of an IP packet is 65,535 bytes. By sending a ping packet larger than this, split into fragments, a victim machine would attempt to reassemble a packet exceeding the maximum size, causing buffer overflows that could crash the system or, in some cases, allow code execution. The attack became widely known in 1996–1997, when it could crash many popular operating systems of the day.

Mitigation

Operating system vendors patched their IP stacks to check fragment sizes during reassembly, and firewalls routinely block ICMP echo requests, making the classic ping of death ineffective on modern systems. A related IPv6 issue surfaced in some systems in 2013 and was likewise patched.
