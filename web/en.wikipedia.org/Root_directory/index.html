Root directory

In a hierarchical file system, the root directory is the first or top-most directory in the hierarchy — the directory from which all other directories and files descend. It has no parent directory.

Unix and Unix-like systems

On Unix-like systems the root directory is denoted by a single forward slash, /. All mounted file systems appear as subdirectories of this single tree, and standard subdirectories such as /bin, /etc, /home, and /usr branch from it. The superuser account is traditionally named "root" after its unrestricted access to this tree.

Windows and DOS

In DOS and Windows, each drive or volume has its own root directory, designated by a drive letter followed by a backslash, as in C:\. A path beginning with the separator is relative to the root of the current drive.
