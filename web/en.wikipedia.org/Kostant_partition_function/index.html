Kostant partition function

Root systems and their positive roots underpin the Kostant partition function.

In representation theory, the Kostant partition function, introduced by Bertram Kostant, counts the number of ways a given weight of a Lie algebra can be written as a non-negative integer linear combination of the positive roots. It plays a central role in Kostant's multiplicity formula for the weight multiplicities of finite-dimensional irreducible representations.

Definition

Let Φ+ be the set of positive roots of a root system Φ. For an element ν in the root lattice, the Kostant partition function P(ν) is the number of tuples (nα)α∈Φ+ of non-negative integers such that ν = Σ nα α. If ν cannot be so expressed, P(ν) = 0.

Kostant's multiplicity formula

The partition function appears in the formula expressing the multiplicity of a weight μ in the irreducible representation of highest weight λ as an alternating sum over the Weyl group: mλ(μ) = Σw∈W sgn(w) P(w(λ + ρ) − (μ + ρ)), where ρ is the Weyl vector. This formula generalises and refines the Weyl character formula and the Steinberg formula.
