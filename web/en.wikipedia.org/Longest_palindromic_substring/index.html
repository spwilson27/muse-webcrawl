Longest palindromic substring

In computer science, the longest palindromic substring or longest symmetric factor problem is to find the longest contiguous substring of a given string that is a palindrome — a sequence that reads the same forwards and backwards. For example, the longest palindromic substring of “bananas” is “anana”.

Algorithms

A naive approach checks every substring in cubic time. Dynamic programming gives an O(n²) solution. Expanding around each of the 2n−1 centres also runs in quadratic worst-case time but is simple and fast in practice. Manacher's algorithm (1975) solves the problem in linear time by reusing previously computed palindrome radii; suffix-tree and suffix-array methods also achieve linear or near-linear bounds.

Applications

Finding palindromic sequences matters in computational biology, where palindromic DNA sequences are associated with restriction sites and other structures.
