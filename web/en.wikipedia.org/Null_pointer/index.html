Null pointer

In computing, a null pointer (or null reference) is a pointer or reference value reserved to indicate that it does not point to a valid object. Dereferencing a null pointer is a common programming error that typically causes a program to crash, for example a segmentation fault or a NullPointerException in Java.

History

Tony Hoare introduced null references in the ALGOL W language in 1965 and later called the decision his "billion-dollar mistake", because of the countless errors, vulnerabilities and system crashes it has caused. In C, the null pointer constant is written NULL or, since C++11, nullptr.

Handling

Languages and tools mitigate null errors through nullable and non-nullable type distinctions (as in Kotlin and Swift optionals), static analysis, and checks before dereferencing. In many systems the null pointer is represented by the address zero, which is deliberately left unmapped so that accidental use faults immediately.
