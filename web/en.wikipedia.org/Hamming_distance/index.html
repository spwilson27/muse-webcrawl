Hamming distance

In information theory, the Hamming distance between two strings of equal length is the number of positions at which the corresponding symbols differ. It is named after Richard Hamming, who introduced it in his 1950 work on error-detecting and error-correcting codes.

Definition and examples

For binary strings it counts differing bits: the distance between 1011101 and 1001001 is 2. For decimal strings, 2173896 and 2233796 differ in three positions. The Hamming distance is a metric: it is non-negative, symmetric, and satisfies the triangle inequality.

Error control

A code with minimum Hamming distance d can detect up to d−1 errors and correct up to floor((d−1)/2) errors. Hamming codes achieve distance 3, correcting any single-bit error. The concept generalises to the Lee distance and to edit distances such as Levenshtein distance for strings of unequal length.

Applications

Beyond coding theory, Hamming distance is used in computer science, genetics for comparing sequences, and in signal processing and machine learning as a similarity measure for binary vectors.
