PostScript describes pages as device-independent programs.

PostScript (PS) is a page description language and dynamically typed, stack-based programming language. It is most commonly used in the electronic and desktop publishing areas. It was created at Adobe Systems by John Warnock, Charles Geschke, Doug Brotz, Ed Taft and Bill Paxton from 1982 to 1984, drawing on earlier work at Xerox PARC and Evans & Sutherland.

The language

PostScript code is written in reverse Polish notation: operands are pushed onto a stack and operators consume them. A program describes text, vector graphics, and images using a device-independent coordinate system; an interpreter in the printer or display renders the page at the resolution of the output device. PostScript fonts, defined as procedures drawing Bézier outlines, made scalable typography practical and underpinned desktop publishing.

History

The Apple LaserWriter of 1985, the first PostScript printer, together with Aldus PageMaker and the Macintosh, launched the desktop publishing revolution. PostScript became the standard interchange format for print production. Adobe's Portable Document Format (PDF), introduced in 1993, retained PostScript's imaging model in a simplified, non-programmable form and largely superseded it as an interchange format, though PostScript remains embedded in print workflows. Major versions are PostScript Level 1 (1984), Level 2 (1991), and PostScript 3 (1997). Encapsulated PostScript (EPS) files embed a single page or graphic for inclusion in other documents.
