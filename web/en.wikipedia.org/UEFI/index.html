UEFI

A typical UEFI firmware configuration interface.

The Unified Extensible Firmware Interface (UEFI, successor to the original Extensible Firmware Interface) is a specification for the software interface between an operating system and a computer's platform firmware. It replaced the legacy BIOS firmware interface originally present in IBM PC-compatible computers. UEFI implementations boot the machine, initialise hardware, and load the operating system through standardised boot services, typically storing boot code as .efi executable files on an EFI System Partition formatted with a FAT file system.

Features

Compared with BIOS, UEFI supports disks larger than 2.2 TB through the GUID Partition Table (GPT), a modular driver model, graphical setup screens with mouse input, network booting, and a built-in shell on many implementations. Secure Boot, introduced with UEFI 2.3.1, cryptographically verifies boot loaders against a database of trusted signatures, protecting against bootkits — though it has also drawn criticism over platform control and alternative-OS installation. A Compatibility Support Module (CSM) in many firmwares emulates legacy BIOS booting, though it has been phased out on newer platforms.

History

EFI originated at Intel in the late 1990s for the Itanium architecture; the first specification was published in 2000. In 2005 stewardship passed to the UEFI Forum, an industry consortium, which issued UEFI 2.0 in 2006. Adoption accelerated after Microsoft required UEFI for Windows 8-era certified hardware, and by the 2020s virtually all new PCs and servers used UEFI. Criticisms include its large, complex codebase and a history of vulnerabilities such as the LogoFAIL and BlackLotus exploits.
