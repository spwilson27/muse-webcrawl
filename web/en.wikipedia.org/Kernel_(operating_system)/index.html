Kernel (operating system)

The kernel is a computer program at the core of an operating system, with complete control over everything in the system. It manages memory, processes, device drivers, and system calls between applications and hardware.

Types

Monolithic kernels run all operating-system services in kernel space, as in Linux. Microkernels run most services in user space, communicating by message passing. Hybrid kernels combine elements of both, as in Windows NT and macOS XNU.

Functions

Core functions include process scheduling, memory management and paging, interrupt handling, and file-system and network access mediation, providing protection and abstraction.
