Interpolation

Interpolation
FieldNumerical analysis
TaskEstimate values between known data points
MethodsLinear, polynomial, spline, nearest-neighbor

In the mathematical field of numerical analysis, interpolation is a type of estimation — a method of constructing (finding) new data points based on the range of a discrete set of known data points. It contrasts with extrapolation, which estimates outside the known range.

Methods

The simplest method is linear interpolation, which joins neighboring data points by straight lines. Polynomial interpolation fits a single polynomial through all points but can oscillate badly for large data sets (Runge's phenomenon). Spline interpolation uses piecewise polynomials for smoothness and stability.

Applications

Interpolation is used in engineering and science for resampling signals and images, filling in missing measurements, computer graphics, and approximating functions whose values can only be computed at discrete points.
