TypeTimed text (captions/subtitles)

WebVTT (Web Video Text Tracks Format) is a World Wide Web Consortium (W3C) standard for displaying timed text in connection with the HTML <track> element. Its primary uses are marking up external text resources for HTML5 video and audio: subtitles and captions for viewers who cannot hear the audio, textual descriptions, chapter navigation, and other metadata timed to the media.

Format

A WebVTT file is a UTF-8 text file beginning with the signature WEBVTT, followed by a sequence of cues. Each cue gives a start and end time in the form hh:mm:ss.mmm separated by an arrow, followed by the cue text, which may include limited markup for voice spans, bold, italics and ruby annotations, plus settings for position and alignment:

WEBVTT

00:01.000 --> 00:04.000
Never drink alone.

History

The format originated in 2010 within the WHATWG as "WebSRT," modelled on the popular SubRip (.srt) subtitle format, and was renamed WebVTT when development moved toward the W3C. It was published as a W3C Candidate Recommendation in 2019, and is supported by all major browsers. WebVTT became the de facto caption format for web video, including on platforms such as YouTube, and is also used to carry subtitles in adaptive streaming formats.

Comparison

Compared with SubRip, WebVTT adds styling, cue settings, multiple kinds of tracks (subtitles, captions, descriptions, chapters, metadata) and a stricter syntax. The broadcast-oriented TTML is more expressive but considerably more complex.
