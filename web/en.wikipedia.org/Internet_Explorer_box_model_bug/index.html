Internet Explorer box model bug

The Internet Explorer box model bug refers to the way older versions of Microsoft's Internet Explorer web browser—versions 5 and earlier, and version 6 in quirks mode—incorrectly implemented the CSS box model compared to the W3C specification.

Description

Under the W3C standard box model, the width and height properties of an element specify the size of its content area only, with padding and borders added outside. In the buggy Internet Explorer model, width and height included the padding and border, so the same CSS produced differently sized elements in different browsers.

Workarounds

Web designers used CSS hacks, such as the box model hack by Tantek Çelik, to serve different widths to different browsers. The use of a DOCTYPE declaration triggering standards mode in Internet Explorer 6 largely resolved the problem, and later versions follow the standard model. CSS3 introduced the box-sizing property, which lets authors choose either model deliberately.
