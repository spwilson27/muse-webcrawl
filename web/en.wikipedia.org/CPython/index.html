CPython

CPython is the reference implementation of the Python programming language. Written in C and Python, CPython is the default and most widely used implementation of the language.

Design

CPython compiles Python source code into bytecode, which is then executed by a virtual machine (the Python eval loop). It uses reference counting for memory management, supplemented by a generational cyclic garbage collector, and historically was limited by the global interpreter lock (GIL); a free-threaded build became officially supported in Python 3.13. Python code can be extended with C modules, and C applications can embed the interpreter.

History

Guido van Rossum began Python at CWI in the Netherlands in 1989. CPython development is now coordinated by the Python Software Foundation and a steering council, with releases following an annual cadence since Python 3.9. Alternative implementations include PyPy, Jython and IronPython.
