Ingress filtering

In computer networking, ingress filtering is a technique used to ensure that incoming packets are actually from the networks from which they claim to originate. A router or firewall performing ingress filtering checks the source address of packets entering a network against the prefixes expected on that interface and drops packets whose source addresses do not belong — for example, packets arriving from the Internet that claim internal private source addresses, or packets arriving from a customer that claim addresses not assigned to that customer.

Purpose

Ingress filtering is a principal defence against IP address spoofing. Spoofed source addresses are used in many attacks, including reflection and amplification denial-of-service attacks, in which responses are directed at a victim whose address was forged. The related practice of egress filtering applies the same check to outbound traffic: an Internet service provider blocks packets leaving its network whose source addresses are not legitimately assigned to its customers, preventing its own subscribers from spoofing others.

Best current practice

The technique is codified in the IETF's Best Current Practice documents: RFC 2827 (BCP 38, "Network Ingress Filtering: Defeating Denial of Service Attacks which employ IP Source Address Spoofing", 2000) and RFC 3704 (BCP 84), which extends the guidance to multihomed networks. Implementation methods include explicit access control lists, strict unicast reverse path forwarding (uRPF), which verifies that a route back to the source exists via the receiving interface, and feasible-path uRPF variants that tolerate asymmetric routing.

Deployment

Despite long-standing recommendations, ingress filtering is far from universal, partly because it offers the deploying network little direct benefit while benefiting everyone else — a classic collective-action problem. Measurement projects such as CAIDA's Spoofer project track the fraction of networks that permit spoofed traffic to leave or enter. Wide deployment of source address validation is regarded as one of the most effective structural measures for reducing spoofed-source denial-of-service traffic on the Internet.
