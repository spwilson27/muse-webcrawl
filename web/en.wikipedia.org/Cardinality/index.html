Cardinality

FieldSet theory, mathematics
Key conceptsBijection, cardinal number, aleph numbers
RelatedCardinality of the continuum

In mathematics, the cardinality of a set is a measure of the number of elements of the set. For example, the set A = {2, 4, 6} contains 3 elements, and therefore A has a cardinality of 3. Beginning in the late 19th century, this concept was generalized to infinite sets, allowing one to distinguish between different types of infinity and to perform arithmetic on them.

Sets have the same cardinality when a bijection exists between them.

Comparing sets

Two sets A and B have the same cardinality if there exists a bijection (a one-to-one correspondence) from A to B. A set A has cardinality less than or equal to the cardinality of a set B if there exists an injective function from A into B. It has cardinality strictly less than B if there is an injection but no bijection.

For finite sets, cardinality is simply the count of elements. Two finite sets have the same cardinality exactly when they have the same number of elements.

Cardinal numbers

Assuming the axiom of choice, every set can be well-ordered, so to every set one can assign a smallest ordinal number having the same cardinality; this ordinal is called a cardinal number. The cardinal numbers of infinite well-ordered sets are denoted by the Hebrew letter aleph (ℵ) with subscripts: ℵ0 (aleph-null) is the smallest infinite cardinal, the cardinality of the natural numbers.

Finite, countable, and uncountable sets

A set is finite if its cardinality is a natural number. A set is countably infinite if its cardinality is ℵ0; it is countable if it is finite or countably infinite. The integers and rational numbers are countable, but the real numbers are not: Cantor's diagonal argument shows the reals form an uncountable set whose cardinality, denoted c, is strictly greater than ℵ0. See cardinality of the continuum.

Examples

  • The set of even integers has the same cardinality as the set of all integers, since n ↔ 2n is a bijection.
  • The set of rational numbers is countable, despite being dense in the reals.
  • The power set of any set has strictly greater cardinality than the set itself (Cantor's theorem).
