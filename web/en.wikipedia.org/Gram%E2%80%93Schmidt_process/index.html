Gram–Schmidt process

Orthogonalising a set of vectors by successive projection

In mathematics, particularly linear algebra and numerical analysis, the Gram–Schmidt process (or Gram–Schmidt procedure) is a method for orthonormalising a set of vectors in an inner product space, most commonly the Euclidean space Rn equipped with the standard inner product. The Gram–Schmidt process takes a finite, linearly independent set of vectors and generates an orthogonal (or orthonormal) set that spans the same subspace.

The method is named after Jørgen Pedersen Gram (1850–1916) and Erhard Schmidt (1876–1959), although it appeared earlier in the work of Laplace and Cauchy. Each new vector is projected onto the subspace spanned by the previous vectors, and the projection is subtracted, leaving a component orthogonal to all of them; normalising each result gives an orthonormal basis.

The process

Given vectors v1, …, vk, the first orthogonal vector u1 is simply v1. Each subsequent uj is formed by subtracting from vj its projections onto all earlier ui. Dividing each uj by its length yields the orthonormal set ej. If the input vectors are linearly dependent, some uj will be zero and is discarded.

Applications and numerical stability

The process underlies the QR decomposition of a matrix: applying Gram–Schmidt to the columns of a full-rank matrix factors it into an orthogonal matrix Q and an upper triangular matrix R. The classical algorithm is numerically unstable because of rounding error; the modified Gram–Schmidt process, which performs the projections one at a time in a different order, gives much better accuracy and is preferred in computation.
