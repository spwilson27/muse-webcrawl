Address space layout randomization

Address space layout randomization (ASLR) is a computer security technique involved in preventing exploitation of memory corruption vulnerabilities. In order to prevent an attacker from reliably jumping to, for example, a particular exploited function in memory, ASLR randomly arranges the address space positions of key data areas of a process, including the base of the executable and the positions of the stack, heap, and libraries.

History

The PaX project first coined the term and implemented ASLR in 2001. A Linux kernel mainline implementation followed, and major operating systems adopted the technique: Windows Vista (2007), macOS 10.5 Leopard (with partial implementation), iOS 4.3, and Android 4.0. Linux enables ASLR by default for position-independent executables.

Effectiveness and limitations

ASLR increases control-flow integrity by making it harder for an attacker to predict target addresses, particularly in combination with data execution prevention. Its effectiveness is weakened by information leaks that disclose addresses, by low entropy on 32-bit systems (making brute force feasible), and by exploits that do not rely on absolute addresses. Kernel ASLR (KASLR) applies the same idea to the kernel image itself.
