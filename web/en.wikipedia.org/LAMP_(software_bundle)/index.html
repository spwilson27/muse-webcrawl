LAMP (software bundle)

LAMP is an acronym for a popular open-source software stack used to build dynamic websites and web applications. It originally denoted Linux (operating system), Apache (web server), MySQL (database) and PHP (programming language).

Components and variants

Each component is free and open-source software, and the stack powered much of the early dynamic web, including content-management systems such as WordPress. Variants substitute components: MariaDB often replaces MySQL, Perl or Python may stand in for PHP, and analogous stacks include WAMP (Windows), MAMP (macOS) and LEMP (with Nginx, pronounced "engine-x", in place of Apache).

History

The term was coined in the late 1990s as Linux-based hosting spread. Although newer stacks and frameworks have become popular, LAMP remains widely deployed for web hosting.
