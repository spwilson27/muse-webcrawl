Buchberger's algorithm

Buchberger's algorithm iteratively adds S-polynomial remainders until a Gröbner basis is obtained. (Image placeholder)

Buchberger's algorithm is an algorithm in computational algebra for transforming a given basis of a polynomial ideal into a Gröbner basis with respect to some monomial order. It was invented by Austrian mathematician Bruno Buchberger in his 1965 PhD thesis, and is a generalisation of both the Euclidean algorithm for univariate polynomials and Gaussian elimination for linear systems.

Description

Starting from a finite generating set of the ideal, the algorithm repeatedly forms S-polynomials from pairs of basis elements — combinations designed to cancel their leading terms — and reduces them by the current basis. If a reduction yields a nonzero remainder, that remainder is added to the basis. The process terminates because the ideals generated by the leading terms form an ascending chain, which cannot grow indefinitely (by Dickson's lemma / Hilbert's basis theorem). The algorithm stops when every S-polynomial reduces to zero, which by Buchberger's criterion means the basis is a Gröbner basis.

Complexity and improvements

The worst-case complexity of Gröbner basis computation is doubly exponential in the number of variables, but the algorithm is highly effective in practice for many problems. Buchberger proposed criteria to discard useless pairs, and later algorithms such as F4 and F5 (Faugère) use linear algebra and signature-based methods to achieve major speedups. Gröbner bases computed by the algorithm are used to solve polynomial systems, in robotics kinematics, coding theory, automated theorem proving and algebraic cryptanalysis.
