Documentation

Documentation is any communicable material used to describe, explain or instruct about the attributes of an object, system or procedure, such as its parts, composition, operation and input requirements. Documentation can take the form of written text, diagrams, drawings, photographs, audio, video or software, and serves as a record or reference for users, operators, maintainers, auditors and regulators.

Types of documentation

  • Product documentation: user manuals, quick-start guides, installation instructions and safety warnings.
  • Technical documentation: specifications, architecture documents, engineering drawings and standards.
  • Software documentation: API references, tutorials, release notes, inline source code comments and documentation generated from code using tools such as Javadoc or Doxygen.
  • Process documentation: standard operating procedures, quality manuals and workflow descriptions used in manufacturing and regulated industries.
  • Regulatory and legal documentation: records required for compliance, such as clinical trial documentation, financial filings and safety data sheets.

Software documentation

In computing, documentation encompasses everything from end-user help systems to detailed API references. Good documentation is widely considered essential to software quality: it reduces support costs, eases onboarding, and preserves knowledge. Popular approaches include README files in open-source projects, wikis, docs-as-code workflows using Markdown and static site generators, and literate programming. Technical writers specialise in producing such material, working to standards for structure and style.

Documentation science

The scientific study of documentation—documentation science—emerged in the early twentieth century with figures such as Paul Otlet, who envisioned universal bibliographic systems for organising recorded knowledge. It overlaps with library and information science, archival science and knowledge management, and addresses how information is created, organised, stored, retrieved and preserved.
