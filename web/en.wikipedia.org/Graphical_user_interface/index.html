Graphical user interface

A graphical user interface (GUI) is a form of user interface that allows users to interact with electronic devices through graphical icons and visual indicators such as secondary notation, instead of text-based user interfaces, typed command labels, or text navigation. GUIs were introduced in reaction to the perceived steep learning curve of command-line interfaces (CLIs), which require commands to be typed on a computer keyboard.

Elements

A GUI displays objects that convey information and represent actions the user can take: windows, icons, menus, buttons, scroll bars, tabs, and a pointer moved by a pointing device such as a mouse — the so-called WIMP paradigm (windows, icons, menus, pointer). Actions are usually performed through direct manipulation of these elements: clicking, dragging, and dropping. Designing effective GUIs is the province of human–computer interaction and interaction design.

History

The conceptual foundations were laid by Vannevar Bush's Memex (1945), Ivan Sutherland's Sketchpad (1963), and Douglas Engelbart's oN-Line System, demonstrated in 1968's "Mother of All Demos" with the mouse, hypertext, and collaborative editing. At Xerox PARC in the 1970s, the Alto computer integrated these ideas into the first recognizable GUI. Xerox's Star (1981) commercialized it; Apple's Lisa (1983) and Macintosh (1984) brought it to a mass audience, and Microsoft Windows (especially 3.0, 1990, and Windows 95) made it dominant on personal computers. Touch-based GUIs on smartphones, beginning with the iPhone in 2007, extended the paradigm beyond the desktop metaphor.

Comparison with other interfaces

GUIs are generally more learnable than command lines because recognition replaces recall, but CLIs remain faster for experts, scripting and automation. Modern systems combine the two, and newer paradigms — touch, voice, gesture, and conversational interfaces — build on or alongside the GUI rather than replacing it entirely.
