The Real Time Streaming Protocol (RTSP) is an application-level network control protocol designed to control streaming media servers. Developed by RealNetworks, Netscape, and Columbia University and standardised in RFC 2326 (1998), RTSP acts as a "network remote control", establishing and controlling media sessions between an endpoint and a server, while the media data itself is usually carried by the Real-time Transport Protocol (RTP).

Operation

RTSP provides VCR-like controls: methods such as OPTIONS, DESCRIBE, SETUP, PLAY, PAUSE, RECORD, and TEARDOWN negotiate and manage a session. Session description is typically provided via the Session Description Protocol (SDP). RTSP runs over TCP or UDP on port 554 by default.

Uses

RTSP was widely used in early internet streaming (RealPlayer, QuickTime Streaming Server) and remains common in IP surveillance cameras, video encoders, and media servers, often paired with ONVIF in security systems. Version 2.0 was published as RFC 7826 in 2016. Much consumer streaming has moved to HTTP-based adaptive protocols such as HLS and MPEG-DASH, but RTSP persists where low-latency, session-controlled delivery is needed.
