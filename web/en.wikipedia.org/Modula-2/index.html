Modula-2

DesignerNiklaus Wirth
First appeared1978
ParadigmImperative, structured, modular
PredecessorPascal, Modula
SuccessorOberon

Modula-2 is a structured, procedural programming language designed by Niklaus Wirth at ETH Zurich between 1977 and 1985 as the successor to Pascal and Modula. It was intended both as a teaching language and as a systems programming language in which large programs could be built from separately compiled modules.

Features

Modula-2's central feature is the module: definition modules declare exported types and procedures, while implementation modules hide the details, enabling information hiding and separate compilation. The language also supports low-level facilities for systems work, coroutines for concurrency, and strong static typing. Wirth used it to write the operating system of the Lilith personal workstation.

Influence

An ISO standard for Modula-2 was published in 1996. Although it never matched the popularity of C, Modula-2 influenced later languages, notably Oberon (Wirth's own successor), Ada, and the module systems of many modern languages. It saw use in education, embedded systems, and — through the Modula-2-derived language of the XDS and TopSpeed compilers — some commercial software.
