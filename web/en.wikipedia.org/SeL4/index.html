seL4

Developer: Trustworthy Systems (originally NICTA)

Family: L4 microkernel

Licence: Open source (GPL/BSD)

seL4 is a high-assurance microkernel operating system, a member of the L4 family of microkernels, notable for being the first operating-system kernel to be formally verified for functional correctness — a mathematical proof that its implementation in C behaves exactly as its specification requires.

Verification

The verification, completed in 2009 by researchers at NICTA in Australia (now CSIRO's Data61 Trustworthy Systems group), was carried out in the Isabelle/HOL proof assistant and covered some 10,000 lines of C code. Later work extended the proofs to security properties such as integrity and confidentiality, and to binary-level correctness.

Design

seL4 provides a minimal set of mechanisms — threads, address spaces, inter-process communication and capability-based access control — on which complete systems can be built. Capabilities govern all access to kernel objects, giving fine-grained control suited to security-critical systems.

Use

The kernel was released as open source in 2014 and is governed by the seL4 Foundation, established in 2020. It is used in defence, aerospace, automotive and other safety- and security-critical projects, including research autonomous helicopters designed to be resilient to hacking.
