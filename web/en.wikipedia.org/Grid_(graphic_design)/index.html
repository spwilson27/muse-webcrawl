Grid (graphic design)

Grid
FieldGraphic design, typography
Key figuresJosef Müller-Brockmann, Emil Ruder, Jan Tschichold
Key workGrid Systems in Graphic Design (1981)

A grid in graphic design is a structure of intersecting vertical and horizontal lines used to organise content on a page or screen. Grids divide a layout into columns, rows, margins and modules, giving text and images consistent positions and proportions. They are a foundational tool of editorial design, corporate identity and interface design.

History

Scribes and early printers used ruling and proportional canons to construct manuscript and book pages. In the 20th century, designers of the Swiss Style (International Typographic Style) — including Josef Müller-Brockmann, Emil Ruder and Karl Gerstner — systematised grid-based layout, arguing that the grid brought order, clarity and objectivity to communication. Müller-Brockmann's Grid Systems in Graphic Design (1981) remains the standard reference.

Types of grid

Common forms include the manuscript grid (a single text block), the column grid, the modular grid (columns combined with horizontal flowlines), the baseline grid used to align type vertically, and hierarchical grids adapted to specific content. Breaking the grid deliberately is also an established expressive technique.

Digital design

Web and app design adopted grids through frameworks such as the 960 Grid System and Bootstrap's 12-column layout, and CSS Grid and Flexbox now provide native grid tools for responsive layouts that adapt across screen sizes.
