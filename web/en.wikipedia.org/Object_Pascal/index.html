Object Pascal

From Wikipedia, the free encyclopedia


Developing in Object Pascal with Delphi

Object Pascal is an extension of the Pascal programming language that adds object-oriented features such as classes, inheritance, and polymorphism. It was developed at Apple Computer in consultation with Pascal's creator, Niklaus Wirth, in the mid-1980s, drawing on the earlier Clascal language for the Lisa.

History

Apple used Object Pascal in the MacApp application framework and licensed it for the Macintosh Programmer's Workshop. Borland later adopted and greatly extended the dialect in Turbo Pascal 5.5 (1989), adding objects to its best-selling compiler. The language achieved its greatest prominence through Borland's Delphi (first released in 1995), a rapid application development environment whose compiler and Visual Component Library made Object Pascal a major tool for Windows desktop software; Anders Hejlsberg, Turbo Pascal's architect, led the Delphi project before moving to Microsoft.

Implementations

Besides Delphi, Object Pascal is implemented by the open-source Free Pascal compiler and the Lazarus IDE, which support many platforms and Delphi-compatible language modes. Modern versions of the language have added generics, anonymous methods, class helpers, and operator overloading.

Language features

Object Pascal supports single inheritance with interfaces, properties, exceptions, units for modular compilation, and a component-based model of events and published properties used by visual designers. It remains statically typed and compiles to native code.
