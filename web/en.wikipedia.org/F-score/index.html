F-score

In statistical analysis of binary classification and information retrieval, the F-score or F-measure is a measure of predictive performance. It is calculated from the precision and recall of a test, where the precision is the number of true positive results divided by the number of all positive results (including false positives), and the recall is the number of true positive results divided by the number of all samples that should have been identified as positive. The F1 score is the harmonic mean of precision and recall:

F1 = 2 · (precision · recall) / (precision + recall)

The general Fβ score

The general Fβ measure weights recall β times as much as precision. F2, for example, emphasizes recall, while F0.5 emphasizes precision. The measure derives from the effectiveness measure of Cornelis Joost van Rijsbergen (1979), defined so that Fβ measures effectiveness with a user who attaches β times as much importance to recall as precision.

Use and criticism

The F1 score is widely used in information retrieval, machine learning, and natural language processing (for example, in evaluating named-entity recognition, machine translation systems indirectly, and question-answering). Because F1 ignores true negatives, it can be a misleading summary for problems where negatives matter, and it is asymmetric — swapping which class is labelled positive changes the value. Multi-class generalizations include macro- and micro-averaged F1. Alternatives such as balanced accuracy, Matthews correlation coefficient, and precision–recall curves are often recommended to supplement it.
