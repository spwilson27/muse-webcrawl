XML Schema, published as a W3C recommendation, is a language for describing the structure and constraining the contents of XML documents. Unlike its predecessor the Document Type Definition (DTD), XML Schema is itself written in XML, supports namespaces, and provides a rich set of built-in data types. Schema documents usually have the file extension .xsd, and the language is often referred to as XSD (XML Schema Definition).

Overview

An XML Schema defines the elements and attributes that can appear in a document, their order and number, whether an element is empty or can contain text, data types for elements and attributes, and default and fixed values. A document that obeys a schema is said to be valid with respect to that schema, and the process of checking is called validation.

History

XML Schema 1.0 became a W3C Recommendation on 2 May 2001, drawing on earlier proposals such as XML-Data and the Document Definition Markup Language. A second edition followed in 2004. XML Schema 1.1, published in April 2012, added assertions (XPath-based co-constraints), conditional type assignment, and other refinements.

Data types

The language provides dozens of built-in types, including strings, booleans, decimals, floats, dates, times, and durations, from which users may derive their own simple and complex types by restriction, list, and union.

Comparison with other schema languages

XML Schema competes and coexists with DTDs, RELAX NG, and Schematron. It is more expressive than DTDs and is widely supported by parsers, data-binding tools, and web service frameworks, though critics have called it overly complex.
