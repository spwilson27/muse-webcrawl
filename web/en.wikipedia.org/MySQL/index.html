MySQL

MySQL is an open-source relational database management system (RDBMS). Its name is a combination of "My", the name of co-founder Michael Widenius's daughter, and "SQL", the acronym for Structured Query Language. MySQL is developed by the Swedish company MySQL AB, which was acquired by Sun Microsystems in 2008; Sun in turn was acquired by Oracle Corporation in 2010.

Original author: Michael Widenius

Developer: Oracle Corporation

Initial release: 23 May 1995

Written in: C, C++

License: GPLv2 and proprietary

Overview

MySQL is a central component of the LAMP open-source web application software stack (Linux, Apache, MySQL, Perl/PHP/Python). Applications that use MySQL databases include WordPress, Drupal, Joomla, phpBB, and large web properties such as Facebook, Flickr, and Twitter in their earlier years.

Editions and forks

MySQL is offered under the GNU General Public License as the Community Server, and in proprietary Enterprise editions by Oracle. Prominent forks include MariaDB, created by Widenius after the Oracle acquisition, and Percona Server. Storage engines include InnoDB (the default, supporting transactions and foreign keys) and MyISAM.

Features

MySQL supports replication, partitioning, stored procedures, triggers, views, and the SQL:2003 standard's core features. It runs on many platforms, including Linux, Windows, and macOS, and is administered through tools such as the mysql command-line client, MySQL Workbench, and phpMyAdmin.
