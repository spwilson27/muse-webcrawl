MS-DOS

MS-DOS (Microsoft Disk Operating System) is an operating system for x86-based personal computers, developed by Microsoft and first released in 1981. It was the dominant operating system for the IBM PC and its compatibles during the 1980s and early 1990s, before being gradually superseded by Microsoft Windows.

History

MS-DOS began as 86-DOS (originally QDOS, the "Quick and Dirty Operating System"), written by Tim Paterson at Seattle Computer Products. Microsoft purchased the rights in 1981 and supplied a modified version to IBM as PC DOS for the original IBM PC. Microsoft retained the right to license its own version, MS-DOS, to other manufacturers, a decision central to the rise of the PC clone industry and to Microsoft's growth.

Features

MS-DOS is a single-user, single-tasking system with a command-line interface built around the COMMAND.COM shell. It provides a hierarchical file system (with 8.3 filenames on the FAT file system), device drivers loaded through CONFIG.SYS, and batch files via AUTOEXEC.BAT. Successive versions added subdirectories (2.0), hard disk support, memory management utilities such as HIMEM.SYS and EMM386 (5.0), and disk compression. The last standalone retail version was MS-DOS 6.22 in 1994; versions 7.x underlay Windows 95, 98, and Me.

Legacy

In 2018 Microsoft released the source code for MS-DOS 1.25 and 2.0 under the MIT License. Its command language and file conventions influenced later systems, and the Windows command prompt still preserves much of its vocabulary.
