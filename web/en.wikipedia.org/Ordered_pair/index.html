Ordered pair

In mathematics, an ordered pair (a, b) is a pair of objects in which the order matters: the ordered pair (a, b) is different from the ordered pair (b, a) unless a = b. Its defining property is that (a, b) = (c, d) if and only if a = c and b = d.

Generalities

Ordered pairs are fundamental building blocks: Cartesian products, relations, functions, coordinates in the plane and complex numbers can all be defined in terms of them. A pair whose first element comes from a set A and second from a set B is an element of the Cartesian product A × B. Generalisations to n components are called tuples.

Set-theoretic definitions

Because set theory takes set membership as primitive, ordered pairs must be defined as sets satisfying the characteristic property. Norbert Wiener proposed the first such definition in 1914. The now-standard Kuratowski definition (1921) sets (a, b) = {{a}, {a, b}}, from which the characteristic property can be proved. Hausdorff's variant, (a, b) = {{a, 1}, {b, 2}}, uses tagged elements, and in type theory and category theory pairs are often taken as primitive instead.
