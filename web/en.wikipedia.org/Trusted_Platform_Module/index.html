Trusted Platform Module
TypeSecure cryptoprocessor
StandardISO/IEC 11889 (TPM 2.0, 2014)
Maintained byTrusted Computing Group

A Trusted Platform Module (TPM) is a secure cryptoprocessor — a dedicated microcontroller or firmware component — designed to secure hardware through integrated cryptographic keys. The international standard ISO/IEC 11889, maintained by the Trusted Computing Group, defines its functions.

Functions

A TPM can generate and store cryptographic keys, perform remote attestation of a system's software state using platform configuration registers (PCRs), seal data to a particular hardware and software configuration, and provide a hardware random number generator.

Adoption

TPM 2.0 became a system requirement for Windows 11 in 2021, greatly increasing its deployment. TPMs are implemented as discrete chips, firmware (fTPM), or virtual devices, and are used by full-disk encryption systems such as BitLocker.
