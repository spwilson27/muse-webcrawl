Ume Sámi
Native to: Sweden
Region: Västerbotten, along the Ume River
Speakers: ~20 native (c. 2000)
Family: Uralic > Sámi > Western Sámi

Ume Sámi is a Sámi language spoken in Sweden along the Ume River, historically from Arjeplog down toward the coast. It is one of the most critically endangered Sámi languages, with only a small number of elderly native speakers.

Features

Like other Sámi languages, Ume Sámi has consonant gradation and a rich morphology. It is notable as the first Sámi language to be written: a Swedish–Sámi primer and hymn translations appeared in the 17th century.

Revitalization

Revitalization efforts include language courses, documentation projects, and a standardized orthography adopted in 2016.
