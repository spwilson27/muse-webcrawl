Base rate fallacy

The base rate fallacy, also called base rate neglect or base rate bias, is a type of fallacy in which people tend to ignore the base rate (prior probability) in favour of individuating information when evaluating probabilities.

Example

If a test for a rare disease is 99% accurate, a positive result does not mean a 99% chance of disease, because the low base rate means false positives can outnumber true positives.

Psychology

Classic experiments by Kahneman and Tversky, such as the taxicab problem, demonstrated pervasive base rate neglect.

Applications

The fallacy matters in medicine, law, screening programmes and risk assessment.
