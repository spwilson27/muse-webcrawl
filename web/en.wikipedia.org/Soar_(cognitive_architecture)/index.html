Soar (cognitive architecture)

Soar is a cognitive architecture, originally created by John Laird, Allen Newell, and Paul Rosenbloom at Carnegie Mellon University. It is both a theory of human cognition and a computational framework for building intelligent agents, maintained since the 1980s. The name is an acronym — originally "State, Operator, And Result" — reflecting its problem-space model of behaviour.

Overview of Soar's memories and learning mechanisms

Theory

Soar is based on the problem space hypothesis: all goal-directed behaviour is the search through a space of states, applying operators to move between them. Knowledge is stored in production rules in a procedural memory; an agent's current situation is represented in a working memory as a graph structure, and long-term declarative knowledge is held in semantic and episodic memories. When an agent lacks the knowledge to choose or apply an operator, an impasse arises and Soar creates a substate in which it can reason deliberatively about the problem.

Learning

Soar's original learning mechanism is chunking, which compiles the results of problem solving in a substate into new production rules, so that similar situations in the future are resolved without impasse. Later versions added reinforcement learning over operator preferences, and semantic and episodic learning, making Soar a general architecture for agents that learn from experience.

Applications

Soar has been used to model human behaviour in psychological experiments and to build applied agents, including the TacAir-Soar and Quake-Soar systems that fly simulated military aircraft and play video game characters. It is one of the oldest continuously developed cognitive architectures, alongside ACT-R.
