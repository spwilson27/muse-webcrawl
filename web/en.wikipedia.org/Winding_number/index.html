Winding number

FieldTopology, complex analysis
ValuesIntegers (positive, negative, or zero)

In mathematics, the winding number or winding index of a closed curve in the plane around a given point is an integer representing the total number of times that the curve travels counterclockwise around the point. If the curve travels clockwise, the winding number is negative; a curve that does not enclose the point has winding number zero.

Formal definition

For a continuously differentiable closed curve γ and a point a not on the curve, the winding number can be defined by the contour integral (1/2πi) ∮ dz/(z − a). The result is always an integer, a fact that underlies Cauchy's integral formula and the argument principle in complex analysis.

Intuition

An intuitive picture is that of a person standing at the point and watching an object moving along the curve: the winding number counts the net number of complete turns the person's head makes. In topology, the winding number classifies closed curves in the punctured plane up to homotopy; two curves have the same winding number about a point if and only if one can be continuously deformed into the other without crossing the point.

Applications

Winding numbers appear in the fundamental group of the circle, in algorithms for point-in-polygon tests in computer graphics, and in physics, where related ideas describe topological defects and the quantisation of circulation in superfluids.
