IS-IS

Intermediate System to Intermediate System (IS-IS, also written ISIS) is a routing protocol designed to move information efficiently within a computer network, a group of physically connected computers or similar devices. It accomplishes this by determining the best route for data through a packet switching network.

The protocol was developed by Digital Equipment Corporation as part of DECnet Phase V and standardised by ISO in 1992 as ISO/IEC 10589 for the OSI Connectionless-mode Network Service (CLNS). Originally designed for OSI protocols, "Integrated IS-IS" (RFC 1195) extended it to route Internet Protocol (IP) traffic. It is a link-state protocol, algorithmically similar to Open Shortest Path First (OSPF): routers flood link-state advertisements, build an identical topology database, and compute shortest paths using Dijkstra's algorithm (the SPF algorithm).

Operation

IS-IS routers are organised into a two-level hierarchy. Level 1 routers route within an area; Level 2 routers form a contiguous backbone that routes between areas. A router may act at both levels (Level 1–2). Routers are addressed by Network Entity Titles (NETs), which encode an area address, a system identifier and an N-selector.

Information is carried in variable-length fields known as type–length–values (TLVs). This TLV structure made IS-IS readily extensible: it was adapted for IPv6, MPLS traffic engineering, and multi-topology routing, often with fewer changes than OSPF required. On each multi-access network segment, routers elect a Designated Intermediate System (DIS) which originates a pseudonode link-state PDU on behalf of the segment.

Deployment

IS-IS is widely used in the core networks of large Internet service providers, where its scalability, stability and ease of extension are valued. It is also the routing protocol underlying several data-centre and layer-2 technologies: TRILL, IEEE 802.1aq Shortest Path Bridging, and Cisco's FabricPath all use IS-IS-derived control planes.
