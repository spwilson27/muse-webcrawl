Variable font

A variable font is a font file that is able to store a continuous range of design variants. An entire typeface — including many different styles — can be stored in a single file, with the specific style selected by the user along continuous axes of variation such as weight, width or optical size.

Technology

Variable fonts were introduced in the OpenType Font Variations specification (OpenType 1.8), announced jointly by Microsoft, Adobe, Apple and Google in September 2016. Glyph outlines are defined by a default master plus deltas for variation points, and named instances (for example "Bold") can be defined within the continuous design space.

History

The concept descends from Apple's TrueType GX variations and Adobe's Multiple Master fonts of the 1990s, which were discontinued. The 2016 standardised format brought cross-platform support, and CSS gained controls through the font-variation-settings property and high-level properties such as font-weight ranges.

Advantages

Variable fonts reduce file size compared with loading many separate font files, enable finer typographic control (such as slightly adjusting weight for legibility), and allow smooth animation between styles on the web.
