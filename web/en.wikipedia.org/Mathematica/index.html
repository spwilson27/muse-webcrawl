Mathematica

Mathematica is a software system with built-in libraries for technical computing, developed by Wolfram Research. It was conceived by Stephen Wolfram and first released in 1988. Its programming language, now called the Wolfram Language, combines symbolic computation, numerics, graphics, and notebook documents.

Features

Mathematica provides tools for calculus, algebra, number theory, differential equations, statistics, image processing, machine learning and many other areas. Its notebook interface interleaves code, results, graphics and text, and is widely used in research, engineering and education.

History

Version 1.0 was released on 23 June 1988. Major additions over later releases included numerical solvers, plotting improvements, integrated curated data (such as chemical and geographic data), natural-language input, and interfaces to external languages and devices. The associated free online service WolframAlpha, launched in 2009, uses Mathematica as its computational back end.
