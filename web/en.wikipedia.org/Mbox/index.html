Mbox

Mbox is a generic term for a family of related file formats used for storing collections of electronic mail messages. All the messages in an mbox mailbox are stored in a single file. Messages are stored one after another, beginning each with a line starting with the four characters "From" followed by a space (the so-called "From_ line") and the sender's email address or the message's delivery time.

Format family

Because content lines beginning with "From " could be confused with message separators, writers typically "From-munge" such lines by prefixing them with a ">" character. Variants include mboxo, mboxrd, mboxcl and mboxcl2, differing in how they escape From_ lines and whether they use Content-Length headers. The lack of a single strict standard has caused interoperability problems, including message corruption when locking is mishandled.

Usage

The format originated on Unix systems and was used by mail user agents such as Eudora, Mozilla Thunderbird, and mail servers and filters such as procmail. File locking (for example with flock or dot-locking) is required to prevent corruption when multiple programs access the same mailbox. A related alternative, maildir, stores each message in its own file. Google Takeout exports Gmail data in mbox format.
