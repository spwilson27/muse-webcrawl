Elias gamma coding

Elias gamma code or Elias γ code is a universal code encoding positive integers developed by Peter Elias. It is used most commonly when coding integers whose upper-bound cannot be determined beforehand. It is one of a family of universal codes that also includes Elias delta coding and Elias omega coding.

Encoding

To code a number x ≥ 1: let N = ⌊log2 x⌋ be the highest power of 2 contained in x, so 2N ≤ x < 2N+1. Write out N in unary — that is, N zeroes followed by a one, or equivalently a one followed by N zeroes read in reverse convention. Then append the binary form of x − 2N, an (N)-digit binary number. The implicit probability distribution for the code lengths follows a power law, making the code well suited to data whose values cluster near small numbers.

Decoding

To decode, the decoder first counts the leading zeros to determine N, reads the single 1 bit, and then reads N additional bits, interpreting the result as 2N plus the value of those bits. Gamma coding is a prefix code, so a stream of concatenated codewords can be decoded unambiguously left to right.

Applications

Elias gamma coding is used in data compression contexts where values are predominantly small but occasionally large, and it forms the basis of more efficient variants such as Elias delta coding, which replaces the unary part with a gamma code of the length itself.
