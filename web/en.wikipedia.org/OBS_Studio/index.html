OBS Studio (formerly Open Broadcaster Software) is a free and open-source software suite for recording and live streaming, maintained by the OBS Project. It is available for Windows, macOS, and Linux.

Features

OBS Studio lets users compose scenes from multiple sources — window and display captures, webcams, images, text, and media files — and switch between them with transitions. It supports real-time encoding using hardware encoders such as NVENC as well as x264, direct streaming to platforms including Twitch, YouTube, and Facebook, and local recording in formats such as MP4 and MKV. A plugin system and scripting support extend its functionality, and features such as a virtual camera allow OBS output to be used in video-conferencing applications.

History

The project began in 2012 as a small tool written by Hugh Bailey and grew through community contributions into a cross-platform rewrite, OBS Multiplatform, later renamed OBS Studio. It is one of the most widely used tools among game streamers and online broadcasters.
