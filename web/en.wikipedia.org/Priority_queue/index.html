Priority queue

In computer science, a priority queue is an abstract data type similar to a regular queue or stack, but where each element additionally has a priority associated with it. In a priority queue, an element with high priority is served before an element with low priority. If elements with equal priority occur, they may be served according to their order in the queue or arbitrarily, depending on the implementation.

Operations

The basic operations are insert (add an element with a given priority), peek or find-max (return the highest-priority element without removing it), and extract-max (remove and return that element). Many implementations also support decrease-key, lowering the priority of an element — essential for graph algorithms such as Dijkstra's. Priority queues come in max-oriented and min-oriented forms.

Implementations

The classic implementation is the binary heap, which provides O(log n) insertion and extraction. Other heap structures — Fibonacci heaps, pairing heaps, binomial heaps, and van Emde Boas trees for bounded integer keys — trade constant factors and decrease-key performance. Naive implementations with sorted or unsorted arrays are simple but slower for large queues.

Applications

Priority queues are used in Dijkstra's shortest-path algorithm and Prim's minimum spanning tree algorithm, the A* search algorithm, Huffman coding, discrete-event simulation, operating-system scheduling, load balancing, and bandage-style triage systems in which the most urgent cases are handled first.
