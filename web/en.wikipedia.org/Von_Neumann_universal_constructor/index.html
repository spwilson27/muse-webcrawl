Von Neumann universal constructor

The von Neumann universal constructor is a self-replicating machine in a cellular automaton environment, designed by John von Neumann in the 1940s and published posthumously in Theory of Self-Reproducing Automata (1966), edited by Arthur Burks. Von Neumann sought a rigorous logical model of biological self-reproduction, and showed that a machine could contain a description of itself, use it both as instructions to build a copy and as data to be copied into the offspring — anticipating the dual role of DNA as template and message.

Von Neumann's design uses a 29-state cellular automaton and a long "tape" of cells encoding the machine's description.

Design

Von Neumann's design consists of three parts: a universal constructor, which can build any machine (including itself) given its description; a universal computer, which controls the construction process; and a duplicator, which copies the description tape. The description is used twice — once interpreted, as instructions, and once uninterpreted, as data to be copied — a separation von Neumann recognised as the essential logical trick of self-replication, years before the structure of DNA was known.

The full configuration is enormous, spanning hundreds of thousands of cells, and was not simulated completely until modern implementations in software such as Golly in the 21st century. Simpler self-replicating automata followed, including Codd's automaton (8 states) and Langton's loops, and the concept influenced fields from artificial life to proposals for self-replicating spacecraft and lunar factories ("von Neumann probes").
