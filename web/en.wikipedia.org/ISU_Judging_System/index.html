ISU Judging System

The ISU Judging System (IJS) is the scoring system used by the International Skating Union to judge figure skating and synchronized skating competitions. It replaced the old 6.0 system in 2004, following the judging scandal at the 2002 Winter Olympics.

How it works

Each performance receives a Total Element Score, in which a technical panel identifies each element and assigns it a base value, with judges adding or subtracting a Grade of Execution, plus a Program Component Score covering skating skills, transitions, performance, composition, and interpretation of the music. The sum gives the segment score.

Effects

The system rewards difficult, well-executed elements according to a published scale of values, but has been criticized for complexity, for encouraging element-maximizing programs, and for the anonymity originally applied to judges' marks.
