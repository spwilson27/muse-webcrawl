Cramer's rule

Field: Linear algebra
Named after: Gabriel Cramer (1704–1752)
Published: 1750

In linear algebra, Cramer's rule is an explicit formula for the solution of a system of linear equations with as many equations as unknowns, valid whenever the system has a unique solution. It expresses each unknown as the ratio of two determinants: the determinant of the coefficient matrix in which one column has been replaced by the constant terms, divided by the determinant of the coefficient matrix itself.

Statement

For a system Ax = b with invertible n × n matrix A, the i-th component of the solution is xi = det(Ai) / det(A), where Ai is formed by replacing the i-th column of A with the vector b. For two equations, this gives the familiar formulas involving 2 × 2 determinants taught in introductory algebra.

History

The rule is named for the Swiss mathematician Gabriel Cramer, who published it in his Introduction à l'analyse des lignes courbes algébriques (1750), though Colin Maclaurin had described special cases as early as 1729 and Leibniz had anticipated the determinant idea in the 17th century.

Computational considerations

Cramer's rule is theoretically elegant — it shows the solution is a rational function of the coefficients and is invaluable in proofs — but it is inefficient for large systems, since computing determinants naively requires factorial time. Practical computation uses Gaussian elimination or iterative methods instead; Cramer's rule is mainly used for small systems and in symbolic or geometric reasoning.
