Git

Git is a distributed version control system used to track changes in files, most commonly source code during software development. It was created by Linus Torvalds in 2005 for the development of the Linux kernel, after the free licence for the proprietary BitKeeper system previously used by kernel developers was revoked.

Git is free and open-source software, distributed under the GNU General Public License version 2. Every Git directory is a full-fledged repository with complete history and version-tracking capabilities, independent of network access or a central server. Development is coordinated by maintainer Junio Hamano, who took over from Torvalds in July 2005.

Design

Torvalds designed Git with an emphasis on speed, data integrity, and support for distributed, non-linear workflows with thousands of parallel branches. Instead of storing file differences, Git conceptually stores snapshots of the entire file system at each commit, with unchanged files stored by reference. Objects are identified by SHA-1 (and, in newer work, SHA-256) hashes, which protect the history against accidental or malicious corruption.

Usage

Common operations include clone, commit, branch, merge, rebase, push, and pull. Git is the dominant version control system in modern software development and underlies hosting platforms such as GitHub, GitLab, and Bitbucket. Surveys consistently show it used by the large majority of professional developers.

Name

Torvalds has joked that he named projects after himself, calling Git (British slang for an unpleasant person) "an egotistical bastard" that he named after himself like "Linux". The README of the original source notes the name can stand for different things depending on mood, from "global information tracker" to "goddamn idiotic truckload of sh*t".
