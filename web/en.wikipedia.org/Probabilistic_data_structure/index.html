Probabilistic data structure

A probabilistic data structure is a data structure that uses randomness and hashing to answer queries approximately, trading a small, controllable error rate for dramatically reduced memory or time compared with exact structures. They are widely used for processing large data streams and databases.

Examples

The Bloom filter tests set membership with possible false positives but no false negatives. Count–min sketch estimates item frequencies in a stream. HyperLogLog estimates the number of distinct elements using only a few kilobytes of memory. Other examples include the MinHash sketch for set similarity, t-digests for quantiles, and quotient filters. Skip lists and treaps use randomization for balancing, though their answers remain exact.

Applications

Probabilistic structures appear in databases (avoiding disk lookups for absent keys), network routers, distributed caches, and big-data systems where storing exact sets would be infeasible. Their error parameters are typically tunable: more memory buys lower error.
