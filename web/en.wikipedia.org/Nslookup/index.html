nslookup (name server lookup) is a network administration command-line tool for querying the Domain Name System (DNS) to obtain domain name or IP address mapping, or other DNS records.

Overview

The tool originated in the Berkeley Internet Name Domain (BIND) software of the Unix operating system and is available on most operating systems, including Windows. It operates in interactive mode, where a user can issue repeated queries, and non-interactive mode, where a single lookup is performed and the program exits. Nslookup can query for specific record types such as A, AAAA, MX, NS and TXT records.

Status

The Internet Systems Consortium long deprecated nslookup in favour of the host and dig utilities, though it remains widely used and is built into Microsoft Windows.
