ar (Unix)

ar
Operating systemUnix and Unix-like
TypeCommand-line utility
PurposeCreate, modify and extract archives
Typical fileStatic library (lib*.a), .deb packages

ar (short for archiver) is a Unix utility for creating, modifying and extracting archives of files. It is one of the oldest Unix tools, and its simple archive format remains in everyday use today in the creation of static libraries (files named libname.a) and as the container format of Debian .deb software packages.

Usage

Common operations are given by single-letter keys: r adds or replaces files in an archive, d deletes members, t lists the table of contents and x extracts members. For example, ar rcs libfoo.a foo.o bar.o creates a static library, where the modifier s writes an index (symbol table) that speeds up linking; the related program ranlib performs the indexing step on its own on some systems.

File format

An ar archive begins with the eight-byte global header !<arch>\n, followed by a sequence of members, each preceded by a 60-byte ASCII header recording the member name, modification time, owner and group IDs, permissions and size, padded so members start on even byte boundaries. Variants of the format include the GNU/System V form used on Linux and the BSD form with extended filename support.

Role in software development

Static linkers such as ld read ar archives of object files and pull in only the members needed to resolve symbols, which is why ar-format libraries underpin Unix software development. The .deb package is itself an ar archive containing control and data tarballs, and early versions of the .a format predate the more general tar archiver for pure file storage.
