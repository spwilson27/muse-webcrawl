Set (mathematics)

A set is the mathematical model for a collection of different things; a set contains elements or members, which can be mathematical objects of any kind: numbers, symbols, points in space, lines, other geometrical shapes, variables, or even other sets. A set may have a finite number of elements or be an infinite set. Two sets are equal if they have precisely the same elements.

Notation and description

Sets are conventionally denoted with capital letters and their elements listed within braces: A = {1, 2, 3}. In roster notation, large or infinite sets are indicated with ellipses, while set-builder notation specifies a defining property, as in {x | x is an even number}. Membership is written with the symbol ∈: 2 ∈ A means 2 is an element of A. The empty set, denoted ∅, contains no elements.

Operations

Basic operations include union (A ∪ B), intersection (A ∩ B), set difference, complement, and the Cartesian product. The power set of a set is the set of all its subsets. Venn diagrams visualize these operations. The number of elements of a set is its cardinality; Georg Cantor showed that infinite sets come in different cardinalities, with the real numbers strictly larger than the natural numbers.

History and foundations

Set theory was created by Georg Cantor in the 1870s and became a foundation for modern mathematics. Naive set theory led to paradoxes such as Russell's paradox, prompting axiomatic treatments, most influentially Zermelo–Fraenkel set theory (ZFC), in which nearly all of mathematics can be formalized.
