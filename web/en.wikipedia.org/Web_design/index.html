Web design

Web design encompasses many different skills and disciplines in the production and maintenance of websites. The different areas of web design include web graphic design, user interface design (UI design), authoring — including standardized code and proprietary software — user experience design (UX design), and search engine optimization.

History

The first websites of the early 1990s were text-only pages built with simple HTML. Tables and frames dominated layout in the mid-1990s, followed by Flash-based sites around 2000. The adoption of Cascading Style Sheets (CSS) separated presentation from content, and the Web 2.0 era brought rounded corners, gradients, and user-generated content. The spread of smartphones after 2010 made responsive web design — layouts that adapt to screen size, formalized by Ethan Marcotte in 2010 — the standard approach.

Elements

Key considerations include layout and visual hierarchy, typography, color theory, imagery, navigation, and accessibility. Modern practice emphasizes mobile-first design, performance budgets, semantic HTML, and compliance with the Web Content Accessibility Guidelines (WCAG). Designers commonly work with wireframes and prototypes in tools such as Figma before developers implement designs in HTML, CSS, and JavaScript, often within content management systems or front-end frameworks.
