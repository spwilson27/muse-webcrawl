Static routing

Static routing is a form of routing that occurs when a router uses a manually configured routing entry, rather than information from dynamic routing traffic. In many cases, static routes are manually configured by a network administrator by adding entries into a routing table, though this may not always be the case. Unlike dynamic routing, static routes are fixed and do not change if the network is changed or reconfigured.

Advantages and disadvantages

Static routing is simple, predictable, and places no processing overhead on the router of the kind incurred by routing protocols; it also sends no routing updates over the network, conserving bandwidth, and can be more secure because only the administrator can permit routing on particular networks. Its main disadvantage is a lack of scalability and fault tolerance: any change in topology requires manual reconfiguration, and a failed link will not be routed around automatically unless the administrator has provided an alternative.

Uses

Static routes are commonly used for stub networks with a single path in and out, for defining a default route (a gateway of last resort), and for small networks whose topology rarely changes. A floating static route is a static route configured with a higher administrative distance than a backup dynamic route, so that it only takes effect if the primary route fails.
