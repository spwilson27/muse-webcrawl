Syntax tree

Syntax tree
Types: Parse tree (concrete), abstract syntax tree
Used in: Compilers, linguistics
Nodes: Operators / constituents; leaves: operands / words

A syntax tree is a tree representation of the syntactic structure of a string according to a formal grammar. In computer science, the term usually means an abstract syntax tree (AST), in which each interior node represents an operator or construct and its children represent operands; it is a condensed version of the full parse tree, omitting punctuation and chain productions.

In compilers

Parsers produce syntax trees from source code, and subsequent compiler phases — semantic analysis, optimization, and code generation — operate on them. Because ASTs abstract away surface syntax, different spellings of the same construct share one representation, simplifying analysis and transformation tools such as linters, formatters, and transpilers.

In linguistics

Linguists use syntax trees (phrase structure trees) to depict the hierarchical constituent structure of sentences, with nodes labelled for categories such as noun phrase and verb phrase; movement and features may be annotated in generative grammar frameworks.
