xBase

xBase is the generic term for the family of database programming languages and file formats descended from dBase, the influential Ashton-Tate product first released for CP/M in 1980 and for the IBM PC soon after. Because dBase's creator never trademarked the name effectively and its file format became a de facto standard, numerous compatible "dBase clones" appeared, collectively referred to as xBase.

History

Wayne Ratliff developed the original program, Vulcan, and Ashton-Tate marketed it as dBase II (1981), then dBase III (1984) and dBase IV (1988). The language combined an interactive command environment with a procedural programming language and a simple flat-file database format (the .dbf table file with associated .dbt memo and .ndx/.mdx index files). Its popularity in the 1980s made it one of the best-selling software categories on the PC.

Clones and successors

Major xBase products included FoxBase and FoxPro (Fox Software, later Microsoft), Clipper (Nantucket), which compiled xBase code to native executables, as well as Arago, dBMAN and FlagShip. Microsoft's purchase of Fox Software in 1992 led to Visual FoxPro, the last version of which was released in 2004. Open-source efforts such as Harbour and xHarbour continue the Clipper lineage, and the .dbf format remains in use — notably in GIS shapefiles.

Language features

The xBase language is characterised by commands such as USE, APPEND, REPLACE, SEEK, BROWSE and REPORT FORM, record-pointer navigation through tables, and work areas allowing multiple tables open simultaneously. Dialects diverged over indexing, macros (& substitution), and object-oriented extensions, which the community attempted to standardise in the 1990s.
