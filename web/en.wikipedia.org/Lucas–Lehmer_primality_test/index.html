In mathematics, the Lucas–Lehmer test (LLT) is a primality test for Mersenne numbers. The test was originally developed by Édouard Lucas in 1878 and improved by Derrick Henry Lehmer in the 1930s. Because of its speed and simplicity for Mersenne numbers, nearly all of the largest known prime numbers have been found using this test, most recently by the Great Internet Mersenne Prime Search (GIMPS).

The test

Let Mp = 2p − 1 be the Mersenne number to test, with p an odd prime. Define a sequence {si} by:

s0 = 4;   si = si−12 − 2 (mod Mp) for i ≥ 1.

Then Mp is prime if and only if sp−2 ≡ 0 (mod Mp). The value sp−2 mod Mp is called the Lucas–Lehmer residue.

Example

Consider M5 = 31. Starting with s0 = 4: s1 = 4² − 2 = 14; s2 = 14² − 2 = 194 ≡ 8 (mod 31); s3 = 8² − 2 = 62 ≡ 0 (mod 31). Since sp−2 = s3 ≡ 0, 31 is prime. For M11 = 2047 = 23 × 89, the residue is nonzero (s9 = 1736), correctly showing it is composite.

Why it works

The test's correctness can be proved using properties of Lucas sequences and quadratic reciprocity, exploiting the fact that the multiplicative order of the element 2 + √3 in an appropriate ring divides Mp + 1. Lehmer's version of the test works in terms of the sequence above and is closely related to the Lucas primality test generalised by later authors.

Computational significance

The test is fast because arithmetic modulo a Mersenne number can be done with additions and shifts rather than general division, and because multiplication of very large integers is accelerated by FFT-based algorithms. Implemented in software such as Prime95, the test running on volunteer computers through GIMPS has discovered the largest known primes since 1996, including the 41-million-digit prime 2136279841 − 1 announced in 2024. A double-check and error-detection ecosystem (proof files and the Lucas–Lehmer variant test by Robert Gerbicz) guards against hardware errors.
