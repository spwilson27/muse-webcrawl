Microsoft Azure

Microsoft Azure, or just Azure, is the cloud computing platform developed by Microsoft. It offers management, access and development of applications and services to individuals, companies, and governments through its global infrastructure. It also provides capabilities that are usually not included within other cloud platforms, including software as a service (SaaS), platform as a service (PaaS), and infrastructure as a service (IaaS). Microsoft Azure supports many programming languages, tools, and frameworks, including Microsoft-specific and third-party software and systems.

Azure was first introduced at the Professional Developers Conference in October 2008 under the codename "Project Red Dog", launching as Windows Azure in February 2010; it was renamed Microsoft Azure in 2014. Azure is one of the largest commercial cloud platforms worldwide, competing principally with Amazon Web Services and Google Cloud Platform, and it underpins much of Microsoft's own online services as well as its partnership offerings for artificial intelligence, including hosting models developed with OpenAI.

Services

Azure offers hundreds of services grouped into categories such as compute (virtual machines, Azure Kubernetes Service, Azure Functions), storage (Blob, File, Disk and Queue storage), databases (Azure SQL Database, Cosmos DB), networking, analytics, machine learning and AI, identity (Microsoft Entra ID), security, and the Internet of Things. Regions and availability zones distributed worldwide let customers deploy applications close to their users and meet data-residency requirements.
