Standard Template Library

The STL's components: containers, iterators and algorithms.

The Standard Template Library (STL) is a software library for the C++ programming language that influenced much of the C++ Standard Library. It provides four components called algorithms, containers, functions, and iterators. The STL is built around generic programming: its algorithms operate on data through iterators rather than on specific container types, so a single algorithm can work with many different containers.

History

The chief architect of the STL was Alexander Stepanov, who developed the ideas of generic programming from the late 1970s onward. Working with Meng Lee at Hewlett-Packard, Stepanov produced a library that was presented to the ANSI/ISO C++ standardization committee in 1993 and adopted in 1994, an unusual step of incorporating a large third-party library into a language standard. Stepanov received the 2015 Computer Pioneer Award in part for this work.

Components

Containers include sequence containers such as vector, deque and list, and associative containers such as set and map. Iterators generalize pointers and come in categories from input and output iterators to random-access iterators. Algorithms include searching, sorting (such as sorting by computed keys), counting and numeric operations. Function objects, or functors, allow algorithms to be customized with user-defined operations.

Influence

The STL introduced template-based generic programming to mainstream practice and influenced library design in many other languages. Its concepts approach was formalized in C++20, which added concepts and ranges to the language.
