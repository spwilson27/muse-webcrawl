Proof assistant

A proof assistant or interactive theorem prover is a software tool that assists in the development of formal proofs by human–machine collaboration. The user constructs a proof step by step, typically in a formal language based on type theory or higher-order logic, while the software checks each step for correctness, automates routine deductions, and maintains the overall proof state. The result is a machine-verified proof whose validity can be confirmed by a small trusted kernel implementing the system's logic.

Major systems

Widely used proof assistants include Coq (based on the calculus of inductive constructions, and winner of the 2013 ACM Software System Award), Lean (whose mathematical library, Mathlib, has become a major repository of formalised mathematics), Isabelle (based on higher-order logic), Agda (a dependently typed programming language used as a prover), and HOL Light and HOL4, descendants of the pioneering LCF system of the 1970s. Mizar, developed in Poland since 1973, maintains one of the largest libraries of formalised mathematics.

Notable formalisations

Proof assistants have verified results beyond feasible human checking, including the Four Colour Theorem (Coq, 2005), the Feit–Thompson odd order theorem (Coq, 2012), the Kepler conjecture on sphere packing (the Flyspeck project, completed 2014), and Peter Scholze's condensed mathematics challenges (Lean, 2021–2022). In computer science they verify compilers (CompCert), operating-system kernels (seL4), and cryptographic code deployed in browsers.

How they work

Most systems follow the LCF architecture: proofs are built through an abstract type of theorems, so only the small kernel can create valid theorems — tactics and automation written in a metalanguage (such as Ltac in Coq or Lean's tactic framework) construct proof terms that the kernel then checks. By the Curry–Howard correspondence, proofs in type-theoretic systems are themselves programs, which the kernel type-checks.

Impact

Formal verification with proof assistants is increasingly central to high-assurance software and is reshaping research mathematics by making large, intricate arguments checkable. The field has also driven programming-language research on dependent types.
