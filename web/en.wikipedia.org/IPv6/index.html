Internet Protocol version 6 (IPv6) is the most recent version of the Internet Protocol (IP), the communications protocol that provides an identification and location system for computers on networks and routes traffic across the Internet. IPv6 was developed by the Internet Engineering Task Force (IETF) to deal with the long-anticipated problem of IPv4 address exhaustion. Its primary function is to allow more unique TCP/IP address identifiers to be created, now that the number of available IPv4 addresses has been exhausted.

Features

IPv6 addresses are 128 bits long, providing 2128 (about 3.4 × 1038) addresses. Addresses are written as eight groups of four hexadecimal digits separated by colons, e.g. 2001:0db8:85a3:0000:0000:8a2e:0370:7334, with leading zeros and runs of zero groups compressible (using "::"). Other features include:

  • A simplified, fixed-size 40-byte header for faster router processing; fragmentation is handled only by endpoints.
  • Stateless address autoconfiguration (SLAAC) and mandatory support for the Neighbor Discovery Protocol.
  • Built-in multicast; broadcast is not used.
  • End-to-end addressability, reducing the need for network address translation.

Deployment

World IPv6 Launch on 6 June 2012 marked permanent enablement by major ISPs and websites. Adoption has grown steadily: by the mid-2020s, roughly 40–45% of users accessing Google services did so over IPv6, with some countries (France, Germany, India, the United States among them) exceeding 50%. Mobile networks and large content providers are major drivers of deployment.
