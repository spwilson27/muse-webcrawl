Token physicalism

Token physicalism is a position in the philosophy of mind holding that every particular mental event, state, or process (each "token") is identical to some particular physical event, state, or process, without claiming that mental types correspond to physical types. It contrasts with type physicalism (the identity theory), which asserts that each kind of mental state is identical to a kind of brain state.

Multiple realizability

Token physicalism is motivated by the argument from multiple realizability, associated with Hilary Putnam: a mental state such as pain might be realised by quite different physical systems in humans, octopuses, or hypothetical machines, so no single physical type can be identical to pain as a type. Token physicalism preserves a physicalist ontology — every individual pain is some physical event — while allowing that cross-species and cross-system generalisations belong to the special sciences rather than physics.

Anomalous monism

The best-known version is Donald Davidson's anomalous monism (1970): mental events are identical with physical events, but there are no strict laws connecting mental and physical descriptions. Token physicalism is generally combined with supervenience claims and underlies much non-reductive physicalism, though critics ask whether, without type identities, it can explain the causal efficacy of mental properties.
