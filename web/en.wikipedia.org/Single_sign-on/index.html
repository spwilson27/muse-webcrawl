Single sign-on

Single sign-on (SSO) is an authentication scheme that allows a user to log in with a single ID to any of several related, yet independent, software systems. True single sign-on allows the user to log in once and access services without re-entering authentication factors.

Conversely, single sign-off or single log-out (SLO) is the property whereby a single action of signing out terminates access to multiple software systems.

Benefits and criticism

Benefits include reducing password fatigue, lowering IT help-desk costs associated with password resets, and centralising authentication management so that security policies can be enforced consistently. Critics note that SSO creates a single point of failure and that compromise of the single credential can grant an attacker access to many systems at once; for this reason SSO is commonly combined with multi-factor authentication.

Implementations

Common SSO standards and protocols include Kerberos, SAML (Security Assertion Markup Language), OpenID Connect and OAuth 2.0. Enterprise systems often integrate with directory services such as LDAP or Microsoft Active Directory. Consumer services such as "Sign in with Google" or "Sign in with Apple" provide SSO across websites via federated identity.
