Tutte polynomial

The Tutte polynomial is a two-variable graph polynomial, named after W. T. Tutte, that encodes many properties of a graph. It is defined for an undirected graph by a deletion–contraction recurrence and is equivalent to the earlier dichromatic polynomial.

Definition

For a graph G with edge set E, the Tutte polynomial TG(x, y) can be defined as a sum over spanning subgraphs weighted by connected components and the nullity and rank of each subgraph. Deleting or contracting a non-trivial edge splits the computation into two smaller graphs.

Specializations

Special values and curves of the Tutte polynomial recover the chromatic polynomial, the flow polynomial, the Jones polynomial of alternating links (via the Thistlethwaite theorem), and parameters connected to the Potts model of statistical physics and network reliability.

Computation

Evaluating the Tutte polynomial is #P-hard at almost all points, making it a central object in counting complexity.
