Vigenère cipher

The Vigenère cipher is a method of encrypting alphabetic text using a series of interwoven Caesar ciphers, employing a form of polyalphabetic substitution. It uses a keyword to select different Caesar alphabets for successive letters.

History

The method was first described by Giovan Battista Bellaso in 1553, but was later misattributed to Blaise de Vigenère, who described an autokey cipher in 1586. The cipher resisted all attempts at breaking until the 19th century, earning the French nickname le chiffrage indéchiffrable — the indecipherable cipher. Friedrich Kasiski published a general method of decryption in 1863, exploiting repetitions in the keyword; Charles Babbage had broken it earlier but unpublished.

Description

Encryption combines plaintext letters with keyword letters using the Vigenère square: each row is a shifted alphabet. Decryption reverses the shifts using the same keyword.
