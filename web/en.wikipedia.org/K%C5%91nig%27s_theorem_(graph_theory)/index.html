Kőnig's theorem (graph theory)

In the mathematical area of graph theory, Kőnig's theorem, proved by Dénes Kőnig in 1931, describes an equivalence between the maximum matching problem and the minimum vertex cover problem in bipartite graphs. That is, in every bipartite graph, the size of a maximum matching equals the size of a minimum vertex cover.

Statement

A matching is a set of edges no two of which share an endpoint; a vertex cover is a set of vertices touching every edge. In any graph the size of a maximum matching is at most the size of a minimum vertex cover. Kőnig's theorem states that for bipartite graphs equality always holds. It was discovered independently in a different form by Jenő Egerváry for weighted graphs (the Hungarian method for the assignment problem builds on this).

Proof idea

A standard proof uses the structure of alternating paths from the set of unmatched vertices on one side: the vertices reachable by alternating paths define a vertex cover whose size equals the matching's size. Alternatively, the theorem follows from the max-flow min-cut theorem by modelling the bipartite graph as a flow network.

Consequences

Kőnig's theorem implies Hall's marriage theorem and Dilworth-type results, and it is a basic example of a min–max relation in combinatorics. It fails for non-bipartite graphs: in a triangle, the maximum matching has size 1 while the minimum vertex cover has size 2.
