Multiprotocol Label Switching

Multiprotocol Label Switching (MPLS) is a routing technique in telecommunications networks that directs data from one node to the next based on short path labels rather than long network addresses, avoiding complex lookups in a routing table at each hop.

Operation

At the edge of an MPLS network, an ingress label edge router assigns each packet a label identifying its forwarding equivalence class. Inside the network, label switch routers forward packets purely by swapping labels according to pre-established label-switched paths, which are set up using signalling protocols such as LDP or RSVP-TE, or more recently segment routing. Because labels have only local significance and forwarding is simple, MPLS historically offered speed advantages and, more enduringly, traffic-engineering control.

Applications

MPLS underpins most large service-provider networks. Its most popular applications are MPLS VPNs — layer 3 (BGP/MPLS IP VPN, RFC 4364) and layer 2 services that interconnect corporate sites — and traffic engineering, quality of service, and fast reroute for resilience. Although direct IP routing has absorbed some of its roles, MPLS remains widespread in carrier backbones.

History

The IETF standardised MPLS in the late 1990s (RFC 3031, 2001), consolidating proprietary label-switching schemes such as Cisco's Tag Switching and IBM's ARIS that had been developed to marry IP routing with ATM-style forwarding.
