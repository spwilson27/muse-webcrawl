Actor model

The actor model in computer science is a mathematical model of concurrent computation that treats an actor as the basic building block. In response to a message it receives, an actor can make local decisions, create more actors, send more messages, and determine how to respond to the next message received. Actors may modify their own private state but can only affect each other's state indirectly through messaging, avoiding the need for locks.

History

The model was first published in 1973 by Carl Hewitt, Peter Bishop, and Richard Steiger, influenced by packet switching, Simula, and early work on artificial intelligence. It was developed further at MIT and influenced programming languages and systems design. Gul Agha's 1985 dissertation provided a formal operational semantics for the model.

Applications

The actor model underlies the concurrency design of Erlang, whose lightweight processes and message passing support highly reliable telecommunications systems, and of frameworks such as Akka for the JVM and Microsoft's Orleans. It is widely used for building distributed, fault-tolerant, and scalable systems, since supervision hierarchies allow failed actors to be restarted in isolation.
