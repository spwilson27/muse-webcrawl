Dependent type

In computer science and logic, a dependent type is a type whose definition depends on a value. It is an overlapping feature of type theory and type systems. In intuitionistic type theory, dependent types are used to encode logic's quantifiers like "for all" and "there exists".

Overview

A classic example is the type of vectors (lists of fixed length): a function that appends two vectors of lengths n and m can be given the type that guarantees the result has length n + m, so that length constraints are checked at compile time. By contrast, in simply typed languages the type of a list cannot mention its length.

Dependent types and formal proof

Through the Curry–Howard correspondence, a dependent type can serve as a logical proposition and a program of that type as its proof. This underlies proof assistants and dependently typed programming languages such as Agda, Coq (now Rocq), Lean, Idris and F*. Languages such as Haskell support limited forms of dependency through extensions and singleton types.

History

Dependent types were introduced into type theory by Per Martin-Löf in the 1970s, building on Howard's formulation of the propositions-as-types correspondence. Calculus of constructions, developed by Thierry Coquand and Gérard Huet, provided another influential foundation.
