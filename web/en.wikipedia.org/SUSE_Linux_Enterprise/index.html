SUSE Linux Enterprise

SUSE Linux Enterprise (SLE) is a Linux-based operating system developed by SUSE. It is available in two editions, suffixed Server (SLES) and Desktop (SLED), and is targeted at business customers. Its flagship product, SUSE Linux Enterprise Server, is marketed for servers, mainframes, and workstations but can also be installed on desktop computers for testing or development purposes.

Products

SUSE Linux Enterprise Server is designed for enterprise workloads including mission-critical databases, SAP applications, and high-performance computing. Versions are released at intervals with service packs and long-term service pack support. New versions of SUSE Linux Enterprise are developed in parallel with the community distribution openSUSE: since openSUSE Leap 15, the community release shares a common code base with SLE. Administration is commonly done with the YaST configuration tool and the Zypper package manager, using the RPM package format.

History

SUSE Linux Enterprise Server was first released in 2000 for IBM S/390 mainframe computers, reflecting SUSE's early focus on enterprise computing. Ownership of SUSE passed through Novell (2003) and The Attachmate Group before SUSE became an independent company again in 2019 under EQT.
