Cocoa is Apple's native object-oriented application programming interface (API) for applications on macOS. It consists of a suite of frameworks — principally Foundation, AppKit and Core Data — that provide the object model, user-interface elements, event handling and data persistence for Mac applications, written mainly in Objective-C and, increasingly, Swift. The related Cocoa Touch frameworks (UIKit) serve iOS, iPadOS and tvOS.

History

Cocoa descends from the OpenStep specification and the NeXTSTEP operating system developed at NeXT, the company Steve Jobs founded after leaving Apple. When Apple acquired NeXT in 1997, NeXTSTEP's application environment became the basis of Mac OS X (2001). Its frameworks were renamed: the generic Foundation and Application Kit layers became Cocoa's Foundation and AppKit. Cocoa replaced the older Carbon API (deprecated in 2007 and removed from 64-bit macOS in 2019) as the primary toolkit for Mac development.

Frameworks

  • Foundation — fundamental classes: strings, collections, dates, networking, file handling, notifications and run loops.
  • AppKit — the graphical user interface: windows, views, controls, menus, drawing and event handling specific to macOS.
  • Core Data — object-graph management and persistence, mapping objects to a SQLite or other store.

Cocoa applications follow the Model–View–Controller design pattern; Xcode and Interface Builder provide visual design tools, and bindings technology reduces glue code. Class names use the "NS" prefix, a legacy of NeXTSTEP (e.g. NSString, NSWindow).

Language support

Objective-C is Cocoa's original language, extended with a dynamic runtime and message-passing syntax. Since 2014 Swift has become Apple's preferred language for new development, interoperating fully with Cocoa frameworks. Bridges have historically existed for Java, Python (PyObjC), Ruby (RubyCocoa/MacRuby) and Perl.
