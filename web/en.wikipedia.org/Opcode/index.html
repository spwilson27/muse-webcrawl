Opcode

In computing, an opcode (abbreviated from operation code) is the portion of a machine language instruction that specifies the operation to be performed. A complete instruction also contains operands — the data on which the operation acts, or their addresses or registers. The set of opcodes available defines a processor's instruction set architecture (ISA).

Organization

Opcodes are binary patterns whose length and encoding vary by architecture. Simple architectures use fixed-length instructions in which the opcode occupies a fixed field; others, such as x86, use variable-length encodings with prefixes and multi-byte opcodes, including escape sequences that extend the opcode space. The processor's control unit decodes the opcode during the fetch–decode–execute cycle and activates the appropriate circuits, for example the arithmetic logic unit for an ADD operation.

Examples

In the MOS Technology 6502, for instance, the byte A9 is the opcode for "load accumulator with immediate value," followed by the byte to load; in x86, 90 is the opcode for NOP (no operation) and C3 is RET (return from procedure). Assemblers translate human-readable mnemonics such as MOV, JMP, and PUSH into these numeric opcodes.

Related concepts

Virtual machines and interpreters have their own opcode sets, called bytecodes — for example the Java Virtual Machine and CPython execute bytecode instructions. Some opcode values are reserved or illegal, and executing them may halt the processor or trigger an exception; on some historic machines undocumented illegal opcodes had useful side effects exploited by programmers.
