Directory (computing)

In computing, a directory is a file system cataloguing structure that contains references to other computer files and possibly other directories. On many computers, directories are known as folders, and on some systems historically as drawers, by analogy with office filing furniture.

A tree of directories shown in a graphical file manager.

Hierarchy

Most modern file systems organise directories in a hierarchy or tree. A directory contained within another is its subdirectory (child), and the enclosing one is the parent directory. The topmost directory, with no parent, is the root directory. A file's location is specified by a path, either absolute (from the root) or relative to the working directory (also called the current directory) of a process. The special entries "." and ".." refer to the directory itself and its parent on Unix-like systems.

History

Hierarchical directories were pioneered by Multics in the 1960s and adopted by Unix, which treats directories as a special kind of file. Early personal-computer systems such as CP/M used a flat structure per disk; MS-DOS 2.0 introduced subdirectories in 1983, influenced by Unix.

Terminology

Graphical user interfaces popularised the "folder" metaphor from the desktop metaphor. The terms are largely interchangeable, though "directory" predominates in technical and command-line contexts.
