Stirling's approximation

Stirling's approximation (or Stirling's formula) is an approximation for factorials, first given by Abraham de Moivre and refined by James Stirling, after whom it is named. It states that for large n,

n! ~ √(2πn) · (n/e)n

Equivalently, ln(n!) ≈ n ln n − n + ½ ln(2πn), with further terms forming the Stirling series.

Uses

The approximation is essential in probability and combinatorics for handling large factorials (for example in deriving the normal approximation to the binomial distribution), and in statistical mechanics, where it underlies the Boltzmann entropy formula S = k ln W. The gamma function satisfies the related asymptotic expansion.

Accuracy

The relative error decreases as roughly 1/(12n), so the formula is already within about 1% for n = 10. It can be converted into explicit bounds valid for all positive integers.
