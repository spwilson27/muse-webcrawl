Microsoft Windows is a product line of proprietary graphical operating systems developed and marketed by Microsoft. It was first released in 1985 as a graphical extension for MS-DOS and went on to dominate the personal computer market; for decades, versions of Windows have run on the large majority of the world's desktop and laptop computers.

History

Windows 1.0 (1985) and Windows 2.0 (1987) were modest environments running on top of DOS. Windows 3.0 (1990) achieved wide commercial success, and Windows 95 introduced the Start menu, taskbar, and Plug and Play. The consumer and business lines merged with Windows XP (2001), built on the Windows NT kernel. Later major releases include Windows Vista (2006), Windows 7 (2009), Windows 8 (2012), Windows 10 (2015), and Windows 11 (2021).

Versions and architecture

The NT family, begun in 1993, underlies all modern Windows releases. Windows ships in editions aimed at consumers, professionals, and enterprises, plus specialised variants for servers (Windows Server), embedded systems, and the now-discontinued Windows Phone for mobile devices. The system supports a vast ecosystem of third-party software, much of it written for the Win32 API.

Market position and criticism

Windows remains the most widely used desktop operating system, though its share has been challenged by macOS, Linux, and mobile platforms. Microsoft has faced criticism and antitrust action over bundling practices, security vulnerabilities, and telemetry and update policies, while Windows' ubiquity has made it a primary target for malware.
