Memory-mapped file

A memory-mapped file is a segment of virtual memory that has been assigned a direct byte-for-byte correlation with some portion of a file or file-like resource. This resource is typically a file that is physically present on disk, but it can also be a device, shared memory object, or other resource that the operating system can reference through a file descriptor.

Overview

When a file is memory-mapped, the program can access its contents using pointer dereferences rather than explicit read and write system calls. The operating system loads pages of the file into physical memory on demand through its page cache, so accessing a memory-mapped file is faster than sequential file I/O in many workloads. Changes to memory may be written back to the file automatically, depending on the mapping flags used.

Implementations

On POSIX systems, memory mapping is provided by the mmap system call. On Windows, the equivalent functionality is exposed through CreateFileMapping and MapViewOfFile. Memory-mapped files are widely used by database engines, text editors, and runtime environments to load large data sets efficiently.
