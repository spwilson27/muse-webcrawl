macOS, originally Mac OS X and later OS X, is a Unix-based operating system developed and marketed by Apple since 2001. It is the primary operating system for Apple's Mac computers and is the second most widely used desktop operating system after Microsoft Windows. It succeeded classic Mac OS, the primary Macintosh operating system from 1984 to 2001.

History

macOS is based on technology developed at NeXT, the company Steve Jobs founded after leaving Apple, which Apple acquired in 1997. The NeXTSTEP operating system provided the foundation — the Mach kernel, BSD Unix layers, and Objective-C development environment — that became Mac OS X, released in 2001 with the Aqua user interface. Successive versions were named after big cats (Cheetah through Mountain Lion) and then after California locations (Mavericks, Yosemite, Sierra, Monterey, Ventura, Sonoma, Sequoia, and others). In 2020 Apple began transitioning the Mac from Intel processors to its own Apple silicon chips, beginning with the M1.

Architecture

At its core is Darwin, an open-source Unix system built on the XNU hybrid kernel combining the Mach microkernel with components from FreeBSD. Above this sit frameworks such as Cocoa, Core Foundation, and Metal for graphics. macOS is certified as a UNIX 03 system on Intel and Apple silicon builds.
