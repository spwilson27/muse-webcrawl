Oberon is a general-purpose programming language first published in 1987 by Niklaus Wirth, the author of Pascal and Modula-2. It was developed as part of the Oberon operating system project at ETH Zurich. Named after the moon of Uranus, Oberon distils Modula-2 into a smaller, simpler core while adding type extension as the basis for object-oriented programming.

Design

Wirth's guiding principle was simplicity: Oberon's defining report is famously short, and the language omits many features of its predecessors, favouring a few powerful concepts — modules with strict separate compilation, strong typing, record type extension, and garbage collection. A 1992 revision, Oberon-2, added type-bound procedures (methods) and other refinements.

Influence

Oberon influenced later languages and systems including Go (whose designers cited its module and interface ideas indirectly through the Wirth tradition), Java's bytecode concepts via the Oberon system's dynamic loading, and the Acme and Plan 9 environments. Wirth revisited the language in Project Oberon 2013, a revised definition used for a complete FPGA-based workstation implementation.
