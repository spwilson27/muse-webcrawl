Pipeline (computing)

In computing, a pipeline is a set of data processing elements connected in series, in which the output of one element is the input of the next. The concept appears in software (command-line pipes and data pipelines) and in hardware, where instruction pipelining overlaps the stages of processor instruction execution.

Software pipelines

Unix popularised the software pipeline: the pipe operator (|) connects the standard output of one program to the standard input of another, letting small tools be composed into complex workflows. Similar constructs appear in shells, streaming frameworks and ETL (extract, transform, load) data pipelines.

Hardware pipelining

Instruction pipelines divide instruction execution into stages — fetch, decode, execute, memory access and writeback — so that multiple instructions are in flight simultaneously, increasing throughput. Hazards arising from data dependencies, control flow and structural conflicts are handled by forwarding, stalling and branch prediction.
