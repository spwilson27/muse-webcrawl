Formal grammar

A formal grammar is a set of rules for generating strings in a formal language. It consists of a finite set of production rules that describe how symbols of the language can be combined, together with a start symbol from which derivations begin. Formal grammars are a central concept in theoretical computer science, formal language theory, and linguistics.

Definition

A grammar is typically defined as a tuple (N, Σ, P, S), where N is a set of nonterminal symbols, Σ is a set of terminal symbols (disjoint from N), P is a set of productions of the form α → β that rewrite strings, and S ∈ N is the start symbol. A string of terminals is in the language of the grammar if it can be derived from S by successive application of the productions.

Chomsky hierarchy

Noam Chomsky's hierarchy classifies grammars by the restrictions on their productions: Type 0 (unrestricted, generating the recursively enumerable languages), Type 1 (context-sensitive), Type 2 (context-free), and Type 3 (regular). Context-free grammars, often written in Backus–Naur form, are widely used to specify the syntax of programming languages and are recognized by pushdown automata.

Applications

Formal grammars underpin compiler design, parsing, and natural language processing; phrase-structure grammars also form the basis of generative linguistics as developed by Chomsky from the 1950s.
