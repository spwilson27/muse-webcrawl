Microsoft DirectX is a collection of application programming interfaces (APIs) for handling tasks related to multimedia, especially game programming and video, on Microsoft platforms. Originally the names of these APIs all began with "Direct" — Direct3D, DirectDraw, DirectMusic, DirectPlay, DirectSound — and the "X" was added when Microsoft designed the APIs specifically, in the mid-1990s, to make Windows a viable gaming platform; the name later gave the Xbox console its name.

Components

The most important component is Direct3D, the graphics API used for rendering three-dimensional graphics, a rival to OpenGL and later to Vulkan and Metal. Other components, historical and current, include Direct2D and DirectWrite for 2D graphics and text, DirectSound and XAudio2 for audio, DirectInput and XInput for input devices, DirectCompute for GPU computing, and DXGI as the underlying infrastructure. Shaders are written in the High-Level Shader Language (HLSL).

History

DirectX 1.0 shipped in 1995 as the Windows Games SDK, championed by Alex St. John and colleagues; key early advocates included id Software's John Carmack, whose support helped win over developers. Successive versions added hardware transform and lighting (DirectX 7), programmable shaders (8/9), the unified shader model and geometry shaders (10, tied to Windows Vista), tessellation (11), and the low-overhead, explicit multi-threading model of DirectX 12 (2015). DirectX 12 Ultimate (2020) standardized features including DirectX Raytracing (DXR), variable-rate shading, mesh shaders, and sampler feedback across Windows and Xbox Series X/S.

Compatibility

DirectX versions are largely cumulative and backwards compatible on Windows, and many Direct3D titles run on other platforms through translation layers such as Wine's VKD3D and Valve's DXVK, used by the Steam Deck's Proton.
