Conditional random field

Conditional random fields (CRFs) are a class of statistical modeling methods often applied in pattern recognition and machine learning, where they are used for structured prediction. Unlike ordinary classifiers, which predict a label for a single sample without regard to neighboring samples, a CRF can take context into account. CRFs were introduced by John Lafferty, Andrew McCallum, and Fernando Pereira in 2001.

Overview

A CRF is a discriminative undirected graphical model. It is a type of Markov random field whose graph structure can be arbitrary, with the conditional distribution over labels modeled given observations. The most common form used in practice is the linear-chain CRF, which models sequences and is closely related to the hidden Markov model (HMM), but generalizes it by allowing arbitrary, overlapping features of the observations and by avoiding the HMM's assumption of conditional independence between observations.

Model

Given observation sequence X and label sequence Y, a linear-chain CRF defines the probability of Y given X proportional to the exponential of a weighted sum of feature functions over adjacent labels and observations, normalized by a partition function Z(X) that sums over all possible label sequences. Training typically maximizes the log-likelihood of labeled training data, often with L2 regularization, using gradient-based methods such as L-BFGS; inference over sequences uses the Viterbi algorithm.

Applications

CRFs have been widely used in natural language processing for part-of-speech tagging, named entity recognition, and shallow parsing; in bioinformatics for gene prediction and protein labeling; and in computer vision for image segmentation and object recognition. Extensions include skip-chain CRFs, which add long-range edges between labels, and higher-order CRFs.
