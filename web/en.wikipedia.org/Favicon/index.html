Favicon

Favicons appear in browser tabs, bookmarks, and history lists, helping users identify websites at a glance.

A favicon (short for favorite icon), also known as a shortcut icon, website icon, or tab icon, is a small image file associated with a particular website or web page. Web browsers display a page's favicon in the address bar, next to the page title in tabs, beside bookmarks, and in other places where a visual identifier for the site is useful. Favicons are most commonly 16×16 or 32×32 pixels.

History

The favicon was introduced by Microsoft with Internet Explorer 5 in 1999. When a user added a site to their "Favorites", the browser requested a file named favicon.ico from the site's root directory and displayed it beside the bookmark. The mechanism was later adopted by other browsers and standardised in HTML recommendations, which allow a page to declare its icon with a <link rel="icon"> element pointing to a file of the site's choosing.

Formats and implementation

The ICO format is the original favicon container and can hold several images at different sizes and colour depths in a single file. Modern browsers also accept PNG, GIF, JPEG, and SVG icons; SVG favicons can scale to any display size and can respond to light and dark colour schemes. Mobile platforms introduced further variants, such as Apple's touch icons for home-screen shortcuts. A typical modern site declares several icon sizes so that browsers, phones, tablets, and operating systems can each pick an appropriate version.

Uses and issues

Beyond decoration, favicons help users distinguish among many open tabs and find sites in bookmark lists. Because browsers request favicons automatically, server logs of favicon requests can be used to estimate readership, and researchers have shown that favicon requests can contribute to tracking techniques such as "supercookies", in which combinations of cached favicon responses identify returning visitors even after ordinary cookies are cleared.
