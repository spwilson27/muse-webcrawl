Iterative closest point

Iterative closest point (ICP) is an algorithm employed to minimise the difference between two clouds of points. It is widely used to register 3D data — for example aligning successive scans from a lidar or depth camera — in robotics, computer vision, 3D reconstruction and medical imaging.

Overview

ICP was introduced independently by Besl and McKay (1992) and by Chen and Medioni (1992). Given a "model" point cloud and a "data" point cloud to be aligned to it, the algorithm repeatedly revises the rigid-body transformation (rotation and translation) that best maps one onto the other:

  1. For each point in the data cloud, find its closest point in the model cloud (typically with a k-d tree).
  2. Compute the transformation that minimises the mean squared distance between the matched pairs — solvable in closed form using singular value decomposition (SVD) or a quaternion method.
  3. Apply the transformation to the data cloud.
  4. Repeat until the change in error falls below a threshold, or a maximum number of iterations is reached.

Properties and limitations

ICP is guaranteed to converge monotonically to a local minimum of the mean squared error, but only to a local one: it therefore requires a reasonable initial alignment, often supplied by feature matching, odometry or a global registration algorithm. Performance degrades with heavy occlusion, partial overlap, noise and non-rigid deformation.

Variants

Many variants have been proposed. Point-to-plane ICP (after Chen and Medioni) minimises distance along surface normals and converges faster on structured surfaces. Generalized-ICP incorporates local surface covariance into a probabilistic model. Other refinements include trimming outlier correspondences, robust error kernels, weighted sampling, and global methods such as Go-ICP. Implementations are available in libraries such as PCL and Open3D, and ICP remains a standard building block of SLAM systems, in which consecutive sensor scans are registered to build maps.
