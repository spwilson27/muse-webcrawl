MPEG transport stream

The MPEG transport stream (MPEG-TS, MTS, or simply TS) is a standard digital container format for the transmission and storage of audio, video, and Program and System Information Protocol (PSIP) data. It is used in broadcast systems such as DVB, ATSC, and IPTV, and is specified in MPEG-2 Part 1, Systems (ISO/IEC 13818-1 and ITU-T H.222.0).

Structure

A transport stream multiplexes several elementary streams into fixed-size packets of 188 bytes (with variants such as the 192-byte M2TS format used on Blu-ray discs adding a time code). Each packet begins with a sync byte and carries a Packet Identifier (PID) indicating which elementary stream it belongs to. Program-specific information tables — the Program Association Table and Program Map Tables — describe how the packets combine into television programmes. Program Clock References embedded in the stream allow the receiver to synchronise audio and video playback.

Uses

Because it tolerates errors gracefully and supports multiplexing many channels over a single transmission, the transport stream became the standard for digital terrestrial, satellite, and cable television. It is also used for streaming over IP networks, as the segment format for HTTP Live Streaming (HLS), and as a recording format in camcorders and set-top boxes (.ts, .m2ts, and .mts files).
