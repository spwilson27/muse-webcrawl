Longest common subsequence

The longest common subsequence (LCS) problem is the problem of finding the longest subsequence common to all sequences in a given set. A subsequence is obtained from a sequence by deleting some or no elements without changing the order of the remaining elements. Unlike substrings, subsequences need not be consecutive.

Algorithms

For two sequences of lengths m and n, the classic dynamic programming algorithm computes the LCS in O(mn) time and space, filling a table where each cell holds the LCS length for prefixes of the inputs. Space can be reduced to O(min(m,n)) when only the length is needed. The Hunt–Szymanski algorithm is faster when matches are sparse.

Applications

LCS underlies file-comparison tools such as the Unix diff utility, revision-control merge algorithms, and the comparison of DNA sequences in bioinformatics, where it is related to the edit distance. For an arbitrary number of sequences the problem is NP-hard.
