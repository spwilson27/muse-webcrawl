Penetration test

A penetration test (often shortened to pen test) is an authorised simulated attack performed on a computer system to evaluate its security. The test is carried out by security professionals — sometimes called "ethical hackers" — who attempt to exploit vulnerabilities in the same way an attacker would, in order to identify weaknesses before they can be exploited maliciously.

Methodology

Penetration tests typically proceed through stages: reconnaissance (gathering information about the target), scanning and enumeration, gaining access by exploiting vulnerabilities, maintaining access, and analysis and reporting. Tests may be conducted from outside the network, simulating an external attacker, or from inside, simulating a malicious insider or a compromised account.

Types

Tests are often classified by the knowledge given to the tester: in a black-box test the tester has no prior knowledge of the system; in a white-box test full information such as source code and architecture diagrams is provided; grey-box tests fall between. Targets may include network infrastructure, web applications, mobile applications, wireless networks, physical security, and the organisation's staff, via social engineering and phishing simulations.

Standards and reporting

Methodologies such as the Penetration Testing Execution Standard (PTES) and the OWASP Testing Guide structure the work. Results are documented in a report describing the vulnerabilities found, their severity (often rated using the CVSS scoring system), evidence of exploitation, and remediation recommendations. Penetration testing differs from a vulnerability assessment, which identifies and catalogues weaknesses but does not usually attempt to exploit them.

Because penetration testing involves techniques that would otherwise be unlawful, it is conducted only with the explicit written permission of the system owner, under agreed rules of engagement and scope.
