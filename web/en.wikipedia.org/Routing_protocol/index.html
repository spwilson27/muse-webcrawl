Routing protocol


Routing protocols let routers share reachability information

A routing protocol specifies how routers communicate with each other to distribute information that allows them to select routes between nodes on a computer network. Each router starts with knowledge only of its directly attached networks; routing protocols spread that knowledge so every router can build a routing table describing the topology and the best next hop toward each destination.

Classification

Interior and exterior protocols

An interior gateway protocol (IGP) operates within a single autonomous system, such as a corporate network or an ISP's backbone. An exterior gateway protocol (EGP) operates between autonomous systems; the only EGP in wide use on the Internet is the Border Gateway Protocol (BGP).

Distance-vector protocols

Distance-vector protocols compute routes from information supplied by neighbours: each router knows the distance (metric) and vector (direction) to destinations but nothing about the complete path. Examples include the Routing Information Protocol (RIP) and Cisco's EIGRP. They are simple but can converge slowly and are prone to routing loops, mitigated by techniques such as split horizon and poison reverse.

Link-state protocols

Link-state protocols flood descriptions of each router's local links throughout the network, so every router holds an identical map of the topology and independently runs Dijkstra's algorithm to build a shortest-path tree. The principal examples are OSPF and IS-IS. They converge faster and scale better than distance-vector protocols but demand more memory and processing.

Path-vector protocols

Path-vector protocols, of which BGP is the archetype, advertise the full sequence of autonomous systems along each route, enabling loop detection and extensive policy control over which routes are accepted and propagated.

Metrics and administrative distance

Protocols quantify path quality with metrics such as hop count, bandwidth, delay, reliability and cost. Where a router learns the same destination from several protocols, administrative distance decides which source is trusted most.
