Search algorithm

In computer science, a search algorithm is any algorithm designed to retrieve information stored in a data structure, or to find a solution within a search space, such as the state space of a problem. Search problems underpin databases, artificial intelligence, games and optimisation.

Searching data structures

For finding a value in a collection, the simplest method is linear search, examining each element in turn (O(n)). If the data are sorted, binary search repeatedly halves the interval, achieving O(log n). Hash tables offer average O(1) lookup, while tree structures such as binary search trees, B-trees and tries support ordered retrieval and range queries and are the basis of search in databases and file systems.

Searching state spaces

In artificial intelligence, search explores a graph of states to reach a goal. Uninformed strategies include breadth-first search, which expands level by level and is complete and optimal for uniform costs; depth-first search, which is memory-efficient but can miss solutions in infinite spaces; and Dijkstra's algorithm (uniform-cost search). Informed strategies use heuristics: greedy best-first search and the widely used A* search, which is optimal when its heuristic is admissible. Adversarial search, such as minimax with alpha–beta pruning, is used in games, while local search methods (hill climbing, simulated annealing, genetic algorithms) address optimisation.

String searching

Algorithms such as Knuth–Morris–Pratt and Boyer–Moore locate patterns within text efficiently and underlie text editors, search engines and bioinformatics tools. Web search engines build inverted indexes over crawled pages and rank results with algorithms such as PageRank.
