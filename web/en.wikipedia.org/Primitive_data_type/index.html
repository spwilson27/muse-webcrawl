Primitive data type

In computer science, primitive data types are a set of basic data types from which all other data types are constructed. A primitive type is a data type provided by a programming language as a basic building block, typically built into the language itself rather than defined by the programmer. Depending on the language and its implementation, primitive types may map directly onto machine-level operations and storage.

Common primitives

Most languages provide some version of the following:

  • Integer types — whole numbers in fixed sizes (such as byte, short, int, and long in Java and C), signed or unsigned.
  • Floating-point types — approximations of real numbers, typically following the IEEE 754 standard (e.g. float and double).
  • Boolean type — representing the truth values true and false.
  • Character type — a single character or code unit, such as ASCII or Unicode characters (e.g. char).

Primitive versus composite and reference types

Primitive types are contrasted with composite types (arrays, records, and structures built from primitives) and, in languages such as Java and C#, with reference types (objects accessed through references). In Java, variables of primitive type hold their values directly, while object variables hold references; boxing and unboxing convert between the two forms. Languages differ on where the line falls: in Python and Ruby nearly everything is an object, while C treats pointers and structs as fundamental machinery for building types.
