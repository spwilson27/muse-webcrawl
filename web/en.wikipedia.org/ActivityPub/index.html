ActivityPub

Protocol
Developed by:World Wide Web Consortium (W3C)
Introduced:23 January 2018 (Recommendation)
Based on:ActivityStreams, JSON-LD

ActivityPub is an open, decentralised social networking protocol based on the ActivityStreams 2.0 data format. It became a W3C Recommendation on 23 January 2018. It provides a client-to-server API for creating, updating, and deleting content, as well as a federated server-to-server API for delivering notifications and content, enabling independently operated servers to interoperate as a network commonly called the Fediverse.

Design

ActivityPub actors have an inbox and an outbox addressed by URLs. Followers receive posts when the author's server posts activities to their inboxes (server-to-server federation), and clients post to their own outbox for delivery. Content is represented as ActivityStreams objects in JSON-LD, with activities such as Create, Follow, Like, Announce (share) and Delete. Notable earlier technologies include OStatus, which ActivityPub largely superseded in federated microblogging.

Implementations

The best-known implementation is Mastodon, a federated microblogging platform; other implementations include PeerTube (video), Pixelfed (images), Lemmy (link aggregation), Misskey, Pleroma, and BookWyrm (book reviews). Larger services have also adopted or announced support: Meta's Threads began federating via ActivityPub, and platforms such as WordPress offer ActivityPub plugins, extending the protocol's reach beyond its open-source origins.
