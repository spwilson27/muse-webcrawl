Bin packing problem

The bin packing problem is an optimisation problem in computer science and operations research in which items of different sizes must be packed into a finite number of bins, each of a fixed capacity, in a way that minimises the number of bins used. It is a classic NP-hard problem with applications in logistics, resource allocation, and scheduling.

Formulation

Given a set of items with sizes between 0 and 1, and bins of capacity 1, the goal is to assign every item to a bin so that no bin's total exceeds capacity and the number of bins is as small as possible. The decision version — whether items fit into a given number of bins — is NP-complete, and the optimisation problem is NP-hard in the strong sense: unless P = NP, no polynomial-time algorithm can guarantee a solution using fewer than 3/2 times the optimal number of bins.

Heuristic algorithms

Because exact solutions are impractical for large inputs, many heuristics are used. In the First Fit heuristic, each item goes into the first bin that can hold it; Next Fit opens a new bin whenever an item does not fit in the current one; Best Fit places each item in the bin that leaves the least remaining space. Sorting items in decreasing size before applying these rules — First Fit Decreasing and Best Fit Decreasing — substantially improves performance, guaranteeing solutions within a constant factor of optimal. First Fit Decreasing, for example, never uses more than about 11/9 of the optimal number of bins plus a small additive term.

Online and offline versions

In the offline version all items are known in advance, permitting sorting strategies. In the online version items arrive one at a time and must be packed irrevocably, which models problems such as allocating arriving jobs to servers. Online algorithms are analysed by competitive ratio, and no online algorithm can do better than a factor of about 1.54 against an optimal offline packing.

Variants and applications

Variants include two- and three-dimensional packing (cutting stock and container loading), bins of varying sizes, and problems with item fragmentation. Applications range from loading shipping containers and cutting raw materials to scheduling television advertisements, allocating memory, and cloud computing, where virtual machines must be packed onto physical servers efficiently.
