Set theory

Set theory is the branch of mathematical logic that studies sets, which informally are collections of objects. Although any type of object can be collected into a set, set theory is applied most often to objects relevant to mathematics. Created by Georg Cantor in the 1870s, it became the standard foundational framework in which virtually all of mathematics can be formulated.

Basic concepts

A set is determined by its members. Key notions include membership (a ∈ A), subsets, the empty set, unions, intersections, complements, and the power set of all subsets. Cantor showed that infinite sets can have different sizes, or cardinalities: the integers are countably infinite, while the real numbers are uncountably infinite — there are strictly more reals than integers, a result proved by his celebrated diagonal argument.

Axiomatic set theory

Naive set theory led to paradoxes, most famously Russell's paradox (the set of all sets that do not contain themselves). In response, mathematicians developed axiomatic systems, principally Zermelo–Fraenkel set theory with the axiom of choice (ZFC), which restrict set formation to avoid contradiction. The continuum hypothesis — concerning the possible sizes of infinite sets — was shown by Gödel (1940) and Cohen (1963) to be independent of ZFC.

Applications

  • Foundations of analysis, algebra, and topology.
  • Cardinal and ordinal arithmetic.
  • Model theory, forcing, and descriptive set theory.
