Written in: C++

Operating system: Windows, Linux, macOS

Type: GUI application framework

License: BSD-style

The Visual Component Framework (VCF) is a free and open-source C++ application framework designed for building graphical user interface applications. Modelled in part on Borland's Visual Component Library and Microsoft's MFC, it provides a component-based object model with runtime type information, properties, and event handling.

Features

The VCF includes a foundation library with classes for strings, files, threads, streams, and XML, as well as a graphics library and an application framework wrapping native windowing controls. It supports the Model–View–Controller pattern, offers a form designer (VCF Builder) for laying out interfaces visually, and targets Windows primarily, with support for other platforms through its abstraction layers. The framework aims to reflect modern C++ practice, using features such as templates, exceptions, and the standard library while presenting an API reminiscent of Delphi and Java frameworks.
