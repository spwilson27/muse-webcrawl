ALGOL 60 (short for Algorithmic Language 1960) is a member of the ALGOL family of computer programming languages. It was defined by an international committee of American and European computer scientists and published in the Revised Report on the Algorithmic Language ALGOL 60 in 1960, edited by Peter Naur.

Influence

ALGOL 60 introduced many concepts that became standard: block structure with local variables, lexical scoping, code blocks delimited by begin and end, and recursion. Its syntax was described in Backus–Naur form, a notation introduced for the report that became a standard way of specifying programming language grammars. Tony Hoare later remarked that ALGOL was "a language so far ahead of its time that it was not only an improvement on its predecessors but also on nearly all its successors."

Features

The language had no standard input/output facilities, leaving those to each implementation. It supported call-by-name parameter passing as the default, which enabled devices such as Jensen's device but complicated implementation. Notable implementations included those by Edsger W. Dijkstra and Jaco Zonneveld for the Dutch Electrologica X1, the first complete ALGOL 60 compiler.
