Google Chrome

Google Chrome is a web browser developed by Google. It was first released in 2008 for Microsoft Windows, built with free software components from Apple WebKit and Mozilla Firefox. Versions were later released for Linux, macOS, iOS, and Android, where it is the default browser. The browser is also the main component of ChromeOS, where it serves as the platform for web applications.

History

Google CEO Eric Schmidt opposed the development of an independent web browser for six years, stating that the company was too small to weather browser wars. Co-founders Sergey Brin and Larry Page hired several Mozilla Firefox developers and built a demonstration of Chrome, after which Schmidt later said he was forced to change his mind. Chrome was unveiled with an explanatory comic book drawn by Scott McCloud, and initially marketed on speed, simplicity, and security, with each tab running in a separate sandboxed process.

Market share and features

Chrome passed Internet Explorer as the most-used web browser in 2012 and has since held the largest global market share among browsers, around 65–70 percent on all platforms combined. It introduced or popularised features such as the omnibox (combined address and search bar), automatic silent updates, syncing of user data through a Google account, and an extensive extension ecosystem through the Chrome Web Store. Its open-source counterpart is Chromium, from which browsers such as Microsoft Edge, Brave, and Opera are also derived.

Criticism

Chrome has been criticised for high memory usage, for privacy concerns surrounding Google tracking, and for moves perceived to entrench Google's dominance of the web platform, including the controversial deprecation of third-party cookies in favour of its Privacy Sandbox proposals and changes to extension APIs (Manifest V3) that limit ad-blocking capabilities.
