gRPC

gRPC is an open-source remote procedure call framework

gRPC is an open-source high-performance remote procedure call (RPC) framework developed by Google. It can run in any environment and supports load balancing, tracing, health checking, and authentication. It is commonly used to connect services in microservices architectures and to link mobile and browser clients to backend services.

Design

Services and messages in gRPC are defined in an interface description language using Protocol Buffers (protobuf) as the default serialisation format. From a .proto definition, the Protocol Buffer compiler generates client stubs and server skeletons in languages including C++, Java, Python, Go, C#, Ruby, PHP, and Dart:

service Greeter {
  rpc SayHello (HelloRequest) returns (HelloReply) {}
}
message HelloRequest { string name = 1; }
message HelloReply { string message = 1; }

Transport is based on HTTP/2, which gives multiplexed streams over a single connection, header compression, and flow control. gRPC supports four kinds of service method: simple unary calls, server streaming, client streaming, and bidirectional streaming.

History and adoption

gRPC grew out of Google's internal RPC system, Stubby, and was announced as open source in 2015; version 1.0 was released in August 2016. The project is now governed by the Cloud Native Computing Foundation (CNCF). It has been adopted by organisations such as Netflix, Cisco, and Square for internal and public APIs. Limitations include comparatively weak browser support (addressed by the separate gRPC-Web specification) and reduced human readability of its binary wire format compared with text-based REST/JSON APIs.
