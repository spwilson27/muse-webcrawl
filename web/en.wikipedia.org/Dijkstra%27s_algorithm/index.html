Dijkstra's algorithm
Conceived byEdsger W. Dijkstra (1956)
Published1959
ProblemSingle-source shortest path
ConstraintNon-negative edge weights

Dijkstra's algorithm is an algorithm for finding the shortest paths between nodes in a weighted graph, invented by Dutch computer scientist Edsger W. Dijkstra in 1956 and published three years later. Given a chosen source node, it computes the shortest path to every other reachable node.

Algorithm

The algorithm maintains tentative distances for all nodes, initially infinity except the source at zero. It repeatedly selects the unvisited node with the smallest tentative distance, marks it visited — its distance is now final — and relaxes its outgoing edges, updating neighbours when a shorter path through the current node is found. Implementations using a priority queue achieve efficient runtimes, typically O(E + V log V) with a Fibonacci heap.

Applications and limits

Dijkstra's algorithm underlies network routing protocols such as OSPF, geographic navigation and route planning, and countless graph-processing tasks. It requires non-negative edge weights; graphs with negative edges require the Bellman–Ford algorithm instead. The A* search algorithm extends it with a heuristic to find a single target faster.
