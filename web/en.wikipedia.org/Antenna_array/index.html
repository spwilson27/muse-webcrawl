Antenna array

An antenna array (or array antenna) is a set of multiple connected antennas which work together as a single antenna to transmit or receive radio waves. The individual antennas (called elements) are usually connected to a single receiver or transmitter by feedlines that supply the elements with power in a specific phase relationship.

Principles

The waves radiated by each element combine and superpose, adding together in some directions (constructive interference) and cancelling in others, to increase gain and directivity beyond what a single element can achieve. The overall radiation pattern is the product of the element pattern and the array factor, which depends on the spacing, geometry, and relative phase and amplitude of the elements.

Types

Arrays may be linear, planar, or conformal. A phased array varies the phase electronically to steer the beam without moving the antenna, as in modern radar and 5G base stations. A Yagi–Uda antenna is a parasitic array in which only one element is driven. Radio telescopes such as the Very Large Array use widely separated antennas as an interferometric array, synthesising a very large aperture.

Applications

Antenna arrays are used in radar, satellite communications, wireless networks, radio astronomy, and military systems, wherever high gain, beam steering, or interference nulling is required.
