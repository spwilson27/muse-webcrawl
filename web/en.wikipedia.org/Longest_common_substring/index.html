Longest common substring

Finding the longest string that appears contiguously in two or more strings

In computer science, the longest common substring problem is to find the longest string (or strings) that is a substring of two or more given strings. It should not be confused with the longest common subsequence problem: a substring must consist of consecutive characters, whereas a subsequence need not.

Example

The longest common substrings of "ABABC", "BABCA" and "ABCBA" are "ABC" and "BCA" (length 3); for the strings pictured in typical examples such as "ABAB" and "BABA", the answer is "ABA" or "BAB" (length 3).

Algorithms

For two strings of lengths m and n, the problem can be solved in O(mn) time and space by dynamic programming: build a table where each cell records the length of the longest common suffix ending at the corresponding positions, and track the maximum.

LCSuff(x[i..], y[j..]) = LCSuff(x[i+1..], y[j+1..]) + 1 if x[i] = y[j] = 0 otherwise answer = max over all i, j of LCSuff(x[i..], y[j..])

More efficient algorithms exist: using a generalised suffix tree or a suffix array with LCP (longest common prefix) data, the longest common substring of a set of strings with total length n can be found in O(n) time. A suffix automaton likewise gives a linear-time solution.

Applications

The problem arises in bioinformatics (comparing DNA or protein sequences), plagiarism detection, data deduplication and compression, file comparison tools, and pattern matching in large text collections.
