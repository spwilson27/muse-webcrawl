Non-measurable set

From Wikipedia, the free encyclopedia

In mathematics, a non-measurable set is a set that cannot be assigned a meaningful "size" (volume, length, or area) consistent with the axioms of measure theory. For Lebesgue measure on the real line, a set is non-measurable if it cannot be given a Lebesgue measure; such sets exist if the axiom of choice is assumed.

Vitali sets

The classic example is the Vitali set, constructed by Giuseppe Vitali in 1905. Consider the equivalence relation on the real numbers in which two numbers are equivalent when their difference is rational. Using the axiom of choice, select exactly one representative from each equivalence class within the interval [0, 1]. The resulting set cannot be Lebesgue measurable: its countably many rational translates are disjoint, all have the same measure, and together fill an interval of finite length, which is impossible whether that measure is zero or positive.

Related results

The Banach–Tarski paradox builds on similar choice-dependent constructions to decompose a ball into finitely many non-measurable pieces that can be reassembled into two copies of the original ball. Conversely, in Solovay's model of set theory without the full axiom of choice, every set of real numbers is Lebesgue measurable, showing that the existence of non-measurable sets cannot be proved from ZF set theory alone.
