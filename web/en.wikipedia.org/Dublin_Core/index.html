Dublin Core

Dublin Core is a set of vocabulary terms used to describe digital and physical resources — such as documents, images, web pages and books — for discovery and cataloguing. It is maintained by the Dublin Core Metadata Initiative (DCMI) and standardised as ISO 15836 and RFC 5013.

First published: 1995
Standards: ISO 15836, RFC 5013
Maintainer: DCMI

The fifteen elements

The original Dublin Core Metadata Element Set consists of fifteen broad, optional and repeatable elements: Title, Creator, Subject, Description, Publisher, Contributor, Date, Type, Format, Identifier, Source, Language, Relation, Coverage and Rights. Its simplicity — often described as a lowest common denominator for resource description — made it easy to adopt across libraries, repositories and the web.

Qualified Dublin Core and DCMI Terms

Qualified Dublin Core adds refinements and encoding schemes to make values more precise. The larger DCMI Metadata Terms vocabulary extends the original fifteen elements with additional properties and classes, expressed in RDF, and is widely used in digital libraries, institutional repositories (for example via the OAI-PMH harvesting protocol) and linked-data applications.

History

The scheme emerged from a 1995 workshop held in Dublin, Ohio — hence the name — organised to improve resource discovery on the rapidly growing World Wide Web.
