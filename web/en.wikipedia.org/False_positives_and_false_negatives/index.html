False positives and false negatives

A false positive is an error in binary classification in which a test result incorrectly indicates the presence of a condition when the condition is not present, while a false negative is an error in which a test result incorrectly indicates the absence of a condition when it is actually present.

Terminology and related concepts

In statistical hypothesis testing, a false positive corresponds to a Type I error (rejecting a true null hypothesis) and a false negative to a Type II error (failing to reject a false null hypothesis). In machine learning, these outcomes appear in the confusion matrix alongside true positives and true negatives, from which metrics such as precision and recall are derived.

Examples by field

In medicine, a false positive HIV screening result causes anxiety and follow-up testing, while a false negative may delay treatment. In quality inspection, false positives scrap good products; in biometric systems, false positives create security vulnerabilities, while false negatives inconvenience legitimate users. Base rates matter: when a condition is rare, even highly accurate tests can yield more false than true positives.
