Web page

A web page (or webpage) is a hypertext document on the World Wide Web, delivered by a web server to the user and displayed in a web browser. A website consists of many web pages linked together under a common domain name. Web pages are written in HTML and may incorporate CSS for styling, JavaScript for interactivity, and images or other media.

Elements

A web page typically contains hyperlinks to other pages, navigation menus, text, images, and embedded audio or video. The page is identified by a Uniform Resource Locator (URL) and fetched using HTTP or HTTPS. Pages may be static, stored as files on the server, or dynamic, generated on request by server software or adjusted in the browser by client-side scripts. Modern frameworks also build single-page applications, in which one initial page updates its content dynamically without full reloads.

History

The first web page was created by Tim Berners-Lee at CERN and published on August 6, 1991, describing the World Wide Web project itself. Early pages were plain text documents; the introduction of the Mosaic browser in 1993 brought inline images and a graphical interface, and the commercial web of the mid-1990s added design features such as tables, frames, and animated graphics. Standards work by the W3C and later WHATWG developed HTML into a rich application platform.

Viewing and creation

Pages are viewed with browsers such as Chrome, Firefox, and Safari, on devices from desktops to phones; responsive design adapts layout to screen size. Pages are created by hand in text editors, with visual authoring tools, or through content management systems such as WordPress.
