Multicast address


IPv4 range: 224.0.0.0 – 239.255.255.255 (Class D)
IPv6 prefix: ff00::/8
Purpose: One-to-many network delivery

A multicast address is a logical network address used to deliver packets to a defined group of interested receivers in a single transmission. Unlike unicast (one-to-one) and broadcast (one-to-all), multicast sends one copy of the data that network routers replicate only where group members exist.

IPv4 multicast

In IPv4, multicast addresses occupy the former Class D range 224.0.0.0/4. The block 224.0.0.0/24 is reserved for local network control (for example 224.0.0.1 for all hosts and 224.0.0.2 for all routers), while 239.0.0.0/8 is administratively scoped for private use. Hosts join groups using the Internet Group Management Protocol (IGMP), and routers distribute traffic using protocols such as PIM.

IPv6 multicast

IPv6 multicast addresses begin with the prefix ff00::/8; the following fields encode flags and a scope (interface-local, link-local, site-local, global, and others). IPv6 has no broadcast; multicast fulfils those roles, including the all-nodes address ff02::1. Receivers join groups with Multicast Listener Discovery (MLD).

Uses

Multicast is used for streaming media distribution, IPTV, routing protocols, service discovery, and financial data feeds. Its deployment across the public Internet is limited, so much application-level "multicast" traffic instead uses content delivery networks.
