Merge (version control)

In version control, merging (also called integration) is a fundamental operation that reconciles multiple changes made to a set of files under revision control. The result combines the development histories of two or more branches into a unified revision.

Types of merge

A three-way merge compares two revised versions of a file against their common ancestor, applying changes made on each side. When both sides modify the same region, a merge conflict arises and a user must resolve it manually. A fast-forward merge occurs when the target branch has not diverged and can simply be advanced to the source revision.

Merge tools

Version control systems such as Git, Mercurial, and Subversion include internal merge algorithms and can invoke external visual diff and merge tools. Automated merging is usually textual and line-based, although semantic merge tools that understand programming-language syntax also exist.
