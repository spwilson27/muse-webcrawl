Character encoding

A character encoding is a system that pairs each character of a character set with a sequence of numbers or bytes, allowing text to be stored and transmitted by computers. A complete encoding scheme also specifies how those numbers are represented as bits.

History

Early encodings included Morse code and telegraph codes such as Baudot. ASCII (1963) defined 128 characters in seven bits and dominated English-language computing. Competing national and vendor encodings — EBCDIC, ISO 8859 variants, Windows code pages, and East Asian multibyte encodings such as Shift JIS — caused persistent interoperability problems, visible as garbled text (mojibake) when a document was decoded with the wrong scheme.

Unicode

Unicode, first published in 1991, assigns a unique code point to each character of virtually all writing systems. Its encoding forms UTF-8, UTF-16 and UTF-32 translate code points into bytes; UTF-8, which is backward-compatible with ASCII and variable-length, has become the dominant encoding of the World Wide Web.
