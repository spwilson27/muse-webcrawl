Block cipher

In cryptography, a block cipher is a deterministic algorithm that operates on fixed-length groups of bits, called blocks, and transforms them using an invertible transformation determined by a symmetric key. Block ciphers are a fundamental component of many cryptographic protocols and are widely used to protect data in transit and storage.

Design

An iterated block cipher encrypts by repeatedly applying a round function, each round using a subkey derived from the main key by a key schedule. Claude Shannon's concepts of confusion and diffusion guide most designs. Common structures include Feistel networks (used by DES), in which half the block is modified using the other half, and substitution–permutation networks (used by AES), in which layers of S-boxes and permutations act on the whole block.

Examples

Important block ciphers include the Data Encryption Standard (DES, 64-bit block, 56-bit key, now insecure), Triple DES, the Advanced Encryption Standard (AES, 128-bit block with 128-, 192-, or 256-bit keys), Blowfish, Twofish, Serpent, and Camellia.

Modes of operation

To encrypt messages longer than the block size, block ciphers are used in a mode of operation such as CBC, CTR, or GCM. Modes define how blocks are chained and how nonces or initialization vectors are used; modern practice favors authenticated encryption modes such as AES-GCM.

Cryptanalysis

Block ciphers are analyzed with techniques including brute force, differential cryptanalysis, linear cryptanalysis, and related-key attacks. A secure block cipher should behave like a pseudorandom permutation and resist all attacks faster than exhaustive key search.
