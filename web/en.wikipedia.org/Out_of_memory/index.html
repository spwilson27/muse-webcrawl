Out of memory

FieldComputing
RelatedMemory leak, OOM killer (Linux)

Out of memory (OOM) is an undesired state of computer operation in which no additional memory can be allocated for use by applications or the operating system. When a system runs out of memory, programs may fail to load, return allocation errors, slow drastically due to swapping, or be terminated.

Causes

Common causes include memory leaks, in which a program fails to release memory it no longer needs; excessive numbers of processes; and working sets that exceed the available physical RAM and swap space.

Handling

Operating systems differ in response. On Linux, the kernel's OOM killer selects and terminates a process — chosen by a heuristic score — to free memory when the system is critically low. Other systems return errors (such as a NULL result from malloc, or an OutOfMemoryError exception in Java) and expect applications to cope. Application-level mitigations include caching limits, streaming data rather than loading it fully, and adding swap space.
