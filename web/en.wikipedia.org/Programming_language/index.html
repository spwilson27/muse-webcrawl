Programming language

A programming language is a system of notation for writing computer programs. Programming languages are described in terms of their syntax (form) and semantics (meaning), usually defined by a formal language. Languages usually provide features such as a type system, variables, and mechanisms for error handling. An implementation of a programming language is required in order to execute programs, namely an interpreter or a compiler.

Definition

Programming languages differ from natural languages in that they are designed for unambiguous communication of instructions to a machine. A language is Turing complete if it can simulate any Turing machine — a property shared by nearly all general-purpose languages. Thousands of programming languages have been created, from machine code and assembly languages to high-level languages such as Python, Java, and C.

History

The earliest programmable machines, such as the Jacquard loom and Charles Babbage's Analytical Engine, used physical or numerical instructions; Ada Lovelace wrote the first algorithm intended for machine execution in the 1840s. The first modern high-level languages — Fortran (1957), Lisp (1958), and COBOL (1959) — abstracted away machine details. Later decades brought structured programming, object-oriented languages such as C++ and Java, and scripting languages like Perl, Python, and JavaScript.

Elements

Common elements include variables and data types, operators and expressions, control structures such as loops and conditionals, procedures and functions, and input/output facilities. Languages also differ in their type systems — static versus dynamic, strong versus weak typing — and in their support for paradigms such as object-oriented, functional, and logic programming.

Classification

Languages are often classified by generation, level of abstraction, or execution model: compiled versus interpreted, imperative versus declarative. Domain-specific languages (DSLs) serve narrow areas such as query languages (SQL) and markup.
