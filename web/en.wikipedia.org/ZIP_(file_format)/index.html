ZIP (file format)

ZIP
Filename extension: .zip
Type: Lossless data compression / archive
Created by: Phil Katz, PKWARE (1989)
Standard: APPNOTE (ISO/IEC 21320-1)

ZIP is an archive file format that supports lossless data compression. A ZIP file may contain one or more files or directories, each compressed individually — most commonly with the DEFLATE algorithm — and identified by metadata in a central directory recorded at the end of the archive.

History

Phil Katz created ZIP in 1989 for PKZIP, after his company PKWARE was sued by SEA over the earlier ARC format; he dedicated the format's specification to the public domain, ensuring its rapid adoption across BBS culture and the early internet. Gary Conway contributed ideas including the "zip" name. Competing tools such as WinZip, Info-ZIP, and built-in support in Windows Explorer ("compressed folders," from 2001/XP era in mainstream use) and macOS made ZIP the default interchange archive.

Structure

Each entry has a local file header followed by (optionally encrypted or split) data; the End of Central Directory record (signature 0x06054b50, "PK\x05\x06") lets readers locate entries quickly and append updates. Later extensions added ZIP64 for archives over 4 GiB or 65,535 entries, AES encryption (via the WinZip extension), bzip2, LZMA, and Zstandard compression methods, plus UTF-8 filename flags.

Uses and derivatives

ZIP underlies many container formats identified by their own extensions: Java JAR/WAR/EAR, Android APK, Microsoft Office Open XML (.docx, .xlsx, .pptx), OpenDocument, EPUB e-books, and many software installers. Its ubiquity, streaming-friendly layout, and royalty-free spec keep it dominant despite higher-ratio rivals like 7z and RAR.
