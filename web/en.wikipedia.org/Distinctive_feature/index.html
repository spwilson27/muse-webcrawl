Distinctive feature

In linguistics, a distinctive feature is the most basic unit of phonological structure that distinguishes one sound from another within a language. Rather than treating each phoneme as an indivisible atom, feature theory analyzes phonemes as bundles of features such as [voice], [nasal], [coronal] or [high].

History

The concept was developed in the Prague School and in the work of Roman Jakobson, and was systematized in generative phonology, notably in Noam Chomsky and Morris Halle's The Sound Pattern of English (1968), which proposed a universal set of binary features defined in articulatory and acoustic terms.

Function

Features explain natural classes: sounds that behave together in phonological rules typically share feature values. For example, assimilation rules often spread a single feature (such as voicing or nasality) from one segment to a neighbor. Features are typically binary (+/−), though some theories use privative (single-valued) features or feature geometry, in which features are organized hierarchically under nodes such as place, manner and laryngeal features.
