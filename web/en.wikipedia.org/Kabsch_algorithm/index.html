Kabsch algorithm

The Kabsch algorithm, named after Wolfgang Kabsch, is a method for calculating the optimal rotation matrix that minimizes the root mean square deviation (RMSD) between two paired sets of points. It is widely used in computational biology and cheminformatics to compare the three-dimensional structures of molecules, and in computer vision and robotics for point set registration.

Problem statement

Given two sets of corresponding points P and Q, each consisting of N points in three-dimensional space, the problem is to find the rotation matrix R and translation vector t that best map P onto Q in the least-squares sense. The Kabsch algorithm solves this in closed form using the singular value decomposition (SVD) of the covariance matrix of the two centered point sets.

Algorithm

The procedure first translates both point sets so that their centroids coincide with the origin. The cross-covariance matrix H is then computed as the sum over all points of the outer products of corresponding centered coordinates. Taking the SVD of H gives H = U S V-transpose, from which the optimal rotation is R = V D U-transpose, where D corrects for the case in which the rotation would otherwise be an improper rotation (a reflection), by flipping the sign of the smallest singular value when the determinant would be negative.

Applications

The algorithm is a standard tool for structural alignment of proteins, measuring similarity between molecular conformations, and aligning scanned point clouds. Extensions handle weighted points, partial correspondences, and scaling, the latter being known as the Umeyama algorithm.
