Cons

Cons is a fundamental operation in Lisp programming languages and in functional programming generally. It constructs a memory object — a cons cell — that holds two values or pointers, conventionally called the car and the cdr.

In Lisp

In Lisp, (cons A B) creates a pair whose car is A and whose cdr is B. Singly linked lists are built by consing elements onto a list, with the empty list (nil) as the terminating cdr; thus (cons 1 (cons 2 nil)) gives the list (1 2). The accessor functions car and cdr — names inherited from the IBM 704, where they referred to the "contents of the address register" and "contents of the decrement register" — retrieve the two halves of the cell.

In other languages

Analogous constructors exist in many languages: :: in ML and Haskell, Cons as the list constructor in algebraic data types, and prepend operations in other functional languages. Cons cells also represent trees and arbitrary pair structures, not only lists.

Implementation

A cons cell is typically a two-word heap object managed by garbage collection. Because lists built with cons are immutable in purely functional settings, new lists can share structure with existing ones, making cons an O(1) operation.
