freedesktop.org (often abbreviated fd.o) is a project to work on interoperability and shared base technology for free software desktop environments on Linux and other Unix-like operating systems. It was founded by Havoc Pennington of Red Hat in March 2000.

Goals

The project's stated aim is to improve interoperability between desktop environments such as GNOME and KDE so that applications behave consistently regardless of which environment the user runs. freedesktop.org is not a formal standards body; rather, it hosts specifications, software implementations, and discussion mailing lists, and specifications hosted there often become de facto standards.

Hosted projects

Many central pieces of the modern Linux desktop stack are hosted at freedesktop.org, including the X.Org Server, the Wayland protocol and Weston compositor, Mesa 3D, D-Bus, systemd (originally), PulseAudio and PipeWire, NetworkManager, the xdg base directory and desktop entry specifications, and the GitLab-based hosting infrastructure used by these projects.

Specifications

Notable specifications include the Desktop Entry Specification, the Icon Theme Specification, the XDG Base Directory Specification, the D-Bus protocol, and the Desktop Menu Specification. The widely used XDG naming for user directories such as ~/.config and ~/.local/share derives from these specifications.
