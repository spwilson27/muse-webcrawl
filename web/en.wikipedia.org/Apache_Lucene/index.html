Apache Lucene is a free and open-source search engine software library, originally written in Java by Doug Cutting. It is supported by the Apache Software Foundation and is released under the Apache Software License. Lucene provides full-text indexing and search capabilities and has been ported to other programming languages, including implementations such as Lucene.NET for C#.

History

Cutting wrote Lucene in 1999 and released it on SourceForge in 2000; it became a project of the Apache Jakarta group in 2001 and a top-level Apache project in 2005. Lucene's creator went on to co-create Apache Hadoop, and the Lucene ecosystem produced the Apache Solr search server and helped inspire Elasticsearch, which was originally built on Lucene.

Architecture

Lucene stores documents as collections of fields and builds an inverted index that maps terms to the documents containing them. At query time it parses and analyses the query, retrieves matching documents, and scores them using ranking models such as the vector space model with TF-IDF and, in later versions, BM25. Analysis pipelines tokenize text and apply filters such as lowercasing, stemming, and stop-word removal.

Applications

Lucene underlies many well-known search systems, including those used by Wikipedia, Twitter (for a period), and numerous enterprise and e-commerce sites.
