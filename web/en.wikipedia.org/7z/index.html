7z

Filename extension.7z
Internet media typeapplication/x-7z-compressed
Developed byIgor Pavlov
Initial release1999
TypeData compression

7z is a compressed archive file format that supports several different data compression, encryption and pre-processing algorithms. It was introduced in 1999 by Igor Pavlov as part of the 7-Zip file archiver, which is free and open-source software released under the GNU LGPL.

Features

The format's default compression method is LZMA (and its successor LZMA2), a dictionary-based algorithm that typically achieves higher compression ratios than ZIP's DEFLATE. 7z supports very large files and archives, Unicode filenames, solid compression (treating multiple files as a single data block), optional AES-256 encryption of both file data and archive headers, and multi-volume archives split across several files. Through plug-in codecs the 7-Zip implementation can also use bzip2, PPMd and other methods.

Adoption

Although ZIP remains more ubiquitous, 7z is widely used for software distribution, backups and emulation archives where its superior compression is valued. Support is built into many third-party archivers across Windows, macOS and Linux.
