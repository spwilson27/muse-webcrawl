Glob (programming)

In computer programming, glob patterns specify sets of filenames using wildcard characters. The term originated with the Unix utility /etc/glob ("global command") in early editions of Unix, which expanded wildcard arguments for commands; the functionality later moved into the shell itself, notably the Bourne and C shells.

Syntax

The most common wildcards are *, which matches any sequence of characters (including none), and ?, which matches any single character. Bracket expressions such as [abc] or [a-z] match one character from a set or range. For example, *.txt matches all files ending in .txt, and file?.png matches file1.png but not file12.png. Unlike full regular expressions, glob patterns are anchored to the whole filename and lack operators for repetition of groups.

Usage

Globbing is built into shells on Unix-like systems and is available through library functions such as POSIX glob() and fnmatch(), and in languages including Python (glob module), Ruby, and PHP. Extended variants add features such as ** (recursive directory matching) in shells like bash and zsh. Windows command shells historically performed little globbing, leaving expansion to individual programs.
