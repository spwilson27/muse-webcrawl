Web mapping

An interactive web map allows users to pan, zoom, and query geographic information in a browser.

Web mapping or an online mapping is the process of using, creating, and distributing maps on the World Wide Web, usually through the use of Web geographic information systems (Web GIS). A web map or an online map is both served and consumed, thus, web mapping is more than just web cartography, it is a service by which consumers may choose what the map will show.

History

The origins of web mapping can be dated from 1993, with the Xerox PARC Map Viewer, one of the first interactive map services. MapQuest, launched in 1996, popularized online driving directions. The release of Google Maps in 2005, with its draggable tile-based interface using Ajax, transformed public expectations and opened web mapping to third-party developers through APIs. OpenStreetMap (founded 2004) brought crowdsourced, freely licensed map data to the web.

Types of web maps

Web maps may be static (simple images), dynamically generated from databases, or fully interactive, allowing panning, zooming, layer switching, and querying of features. Common technologies include tile layers, vector tiles, Web Map Service (WMS) and Web Feature Service (WFS) standards from the Open Geospatial Consortium, and JavaScript libraries such as Leaflet, OpenLayers, and MapLibre GL.

Applications

Applications range from navigation services such as Waze and Google Maps, through location-based services, real-estate and logistics dashboards, to public-sector geoportals, disaster-response mapping, and participatory citizen-science projects.
