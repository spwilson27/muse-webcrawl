Absolute value (algebra)

In algebra, an absolute value (also called a valuation, magnitude, or norm in some contexts) is a function that assigns to each element of a field a non-negative real number, generalising the familiar absolute value of real and complex numbers. Formally, an absolute value on a field K is a function |·| : K → ℝ satisfying, for all x, y in K:

  • |x| ≥ 0, and |x| = 0 if and only if x = 0 (positive definiteness);
  • |xy| = |x| · |y| (multiplicativity);
  • |x + y| ≤ |x| + |y| (the triangle inequality).

Types and examples

An absolute value is called non-Archimedean if it satisfies the stronger ultrametric inequality |x + y| ≤ max(|x|, |y|); otherwise it is Archimedean. The standard example of a non-Archimedean absolute value is the p-adic absolute value on the rational numbers, defined using the exponent of a prime p in the factorisation of a rational number. Every field also carries the trivial absolute value, which assigns 1 to every non-zero element. A theorem of Ostrowski states that every non-trivial absolute value on the rationals is equivalent either to the usual absolute value or to a p-adic one.

Places and completions

Equivalence classes of absolute values on a number field or function field are called places, and completing a field with respect to an absolute value produces objects such as the real numbers (from the usual absolute value) or the p-adic numbers. Absolute values play a central role in algebraic number theory, where the product formula relates all the absolute values of a field.
