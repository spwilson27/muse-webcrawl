Wavelet tree

A wavelet tree is a succinct data structure in computer science that stores a sequence of symbols over an alphabet and supports queries in logarithmic time. It was introduced by Roberto Grossi, Ankur Gupta, and Jeffrey Scott Vitter in 2003, by analogy with wavelet transforms in signal processing.

Structure

The wavelet tree recursively partitions the alphabet into two halves. Each node stores a bitvector marking, for each element of the subsequence reaching that node, whether the element belongs to the lower or upper half of the node's alphabet range; the elements are then passed stably to the corresponding child nodes. The tree has height O(log σ) for an alphabet of size σ, and its total space is close to n log σ bits, similar to storing the sequence directly.

Operations

Using rank and select operations on the bitvectors, the wavelet tree supports, in O(log σ) time: access (return the element at a position), rank (count occurrences of a symbol up to a position), and select (find the position of the k-th occurrence of a symbol). It can also answer range counting and quantile queries. Wavelet trees are a building block of compressed full-text indexes, range-query data structures, and dynamic sequence representations; variants such as the wavelet matrix improve practical performance.
