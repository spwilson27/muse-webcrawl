ed is a line editor for Unix and Unix-like operating systems. Written by Ken Thompson at Bell Labs, it was one of the first parts of the Unix operating system, developed in 1969 alongside the QED editor's influence. It remains part of the POSIX standard.

Features

ed operates on a file one line at a time using terse single-letter commands and regular expressions. Lines are addressed by number or by pattern searches. Its brevity suited the slow teletypes of early computing. The editor ex and later vi were built on concepts from ed, while its regular-expression syntax influenced tools including grep (whose name derives from ed's command g/re/p), sed, and awk.

Reputation

ed is famous for its unfriendliness: its only default error message is a single question mark, ?. This has made it the subject of long-running Unix humour — "Ed is the standard text editor" — and the 1991 book The Craft of Text Editing and Michael Lucas's parody works keep the joke alive. Despite this, ed is still included in nearly every Unix system and is useful for scripted edits and restricted environments.
