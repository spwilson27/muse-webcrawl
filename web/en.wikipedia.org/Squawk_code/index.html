Squawk code

A transponder control unit, on which the pilot dials in the assigned squawk code.

A squawk code (often simply squawk) is a four-digit octal number transmitted by an aircraft's transponder in response to interrogation by secondary surveillance radar. Air traffic control assigns a discrete code to each aircraft so that it can be identified on radar displays and its flight data correlated with a flight plan. The pilot enters the assigned code into the transponder — the act is called "squawking" the code, and a controller's instruction is phrased, for example, as "Squawk 4612".

Code assignment

Because the codes are four octal digits (each digit 0–7), there are 4,096 possible codes. Codes are allocated in blocks to states and air navigation service providers under regional agreements coordinated by ICAO. Some codes are reserved internationally for special purposes and must never be assigned as discrete codes:

CodeMeaning
7500Aircraft hijacking (unlawful interference)
7600Radio failure (loss of communications)
7700Emergency
2000Code to be squawked when entering airspace from an area where no code was assigned (procedural)
1200Visual flight rules (VFR) traffic in North America not in contact with ATC
7000VFR conspicuity code in much of Europe
0000Reserved (military / invalid)

History

The term "squawk" derives from the Second World War Identification Friend or Foe (IFF) system, code-named "Parrot"; controllers would instruct pilots to "squawk your parrot" to activate the device. Modern Mode A transponders reply with the code alone, while Mode C adds pressure altitude and Mode S adds a permanent 24-bit aircraft address and data-link capability. ADS-B extends this reporting to broadcast position derived from satellite navigation.

Use in emergencies

Selecting 7700 immediately alerts all monitoring radar units that the aircraft has an emergency, and controllers give it priority. Selecting 7500 is a covert signal of hijacking: controllers respond with a plain confirmation question and do not acknowledge the meaning openly on frequency. A loss of radio is signalled with 7600, after which the aircraft follows published lost-communications procedures.
