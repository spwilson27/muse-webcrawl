Division by zero

In mathematics, division by zero, division where the divisor (denominator) is zero, is a unique and problematic special case. Using fraction notation, the general example can be written as a/0, where a is the dividend (numerator). In standard arithmetic, division by zero is undefined: there is no number which, multiplied by 0, gives a non-zero a, and 0/0 would be consistent with every number, so neither case determines a unique result.

Why it is undefined

Division is defined as the inverse of multiplication: a/b is the unique number c such that c × b = a. For b = 0 and a ≠ 0, no such c exists since any number times 0 is 0. For a = 0, every c satisfies the equation, so no unique quotient exists. Allowing a value for division by zero in a field leads to contradictions (e.g. false proofs that 1 = 2) and breaks the distributive law.

Historical treatment

The Indian mathematician Brahmagupta (628 CE) attempted rules for zero, and Bhāskara II (12th century) suggested a quantity divided by zero is infinite. Modern mathematics treats the expression as undefined in real and complex arithmetic.

Extended systems

In the projectively extended real line and the Riemann sphere, 1/0 is defined as infinity (∞), at the cost of some algebraic rules. In IEEE 754 floating-point arithmetic, division of a non-zero finite number by zero yields positive or negative infinity, while 0/0 yields NaN ("not a number"). In certain algebraic structures called wheels, division by zero is totalised with additional elements.

In computing

Integer division by zero typically triggers a runtime error or program crash; many software failures have been traced to unhandled division by zero.
