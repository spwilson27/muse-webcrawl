Support function

In mathematics, the support function of a set A in a Euclidean space (or more generally a locally convex topological vector space) is a real-valued function that encodes the extent of the set in every direction. For a nonempty set A ⊆ ℝⁿ, the support function is defined by hA(x) = sup { ⟨x, a⟩ : a ∈ A }, where ⟨·,·⟩ denotes the inner product.

Properties

The support function is always convex and positively homogeneous of degree one, even if the original set is not convex; indeed hA = hconv(A), so it depends only on the closed convex hull of A. A closed convex set is completely determined by its support function, a fact closely related to the hyperplane separation theorem and the theory of convex duality. The support function of a Minkowski sum is the sum of the support functions: hA+B = hA + hB.

Applications

Support functions are used throughout convex geometry and functional analysis. They are related to the width of a convex body in a given direction, to Minkowski functionals (gauges), and to polar sets: the support function of a set is the gauge of its polar. In mathematical economics and optimization, support functions describe profit and cost functions and enter into duality theory.
