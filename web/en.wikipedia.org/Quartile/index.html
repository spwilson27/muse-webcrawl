Quartile

In statistics, quartiles are a type of quantile which divide a set of observations into four defined intervals, based on the values of the data. In descriptive statistics, the quartiles of a ranked data set are the three points that divide the data into four groups, each containing a quarter of the data points.


A box plot built from quartiles

Definitions

The three main quartiles are:

  • The first quartile (Q1), or lower quartile, is the value below which 25% of the data lie; it is the same as the 25th percentile.
  • The second quartile (Q2) is the median, splitting the data in half.
  • The third quartile (Q3), or upper quartile, is the value below which 75% of the data lie.

The difference between Q3 and Q1 is the interquartile range (IQR), a robust measure of statistical dispersion that contains the middle 50% of observations. In a box plot, the box spans the first to the third quartile, the line inside the box marks the median, and values more than 1.5 IQR beyond the quartiles are conventionally flagged as potential outliers.

Computation

There is no single universally agreed method for computing quartiles from a finite sample; several methods are in common use, differing in how they interpolate between adjacent observations. Different statistical packages may therefore report slightly different quartiles for the same data set. The methods include the exclusive and inclusive approaches associated with John Tukey's hinges and the percentile definitions implemented in common spreadsheet software.
