Type safety

From Wikipedia, the free encyclopedia

In computer science, type safety is the extent to which a programming language discourages or prevents type errors — errors that arise when an operation is applied to a value of a type for which it is not defined, or when memory is accessed in a way inconsistent with the types of the objects stored there. A language is often described as type-safe if well-typed programs cannot "go wrong" in specified ways, a formulation associated with Robin Milner's famous dictum: "Well-typed programs can't go wrong."

Static and dynamic enforcement

Type safety may be enforced at compile time (static typing), at run time (dynamic typing), or through a combination of both. Statically typed languages such as Java, Rust, Haskell, and C# reject type errors before execution, though they differ in how complete their guarantees are: the presence of null references, unchecked casts, or unsafe code blocks can create loopholes. Dynamically typed languages such as Python and JavaScript check types as operations execute and raise errors (or coerce values) at run time; they are still considered type-safe in the memory-safety sense if their implementations prevent arbitrary memory reinterpretation.

Memory safety and unsafe features

Type safety is closely related to but distinct from memory safety. Languages like C and C++ are described as type-unsafe because pointer arithmetic, manual memory management, and unrestricted casts allow programs to violate their own type structure, leading to undefined behaviour and security vulnerabilities such as buffer overflows. Many languages provide explicit escape hatches — Rust's unsafe blocks, Java's native interfaces, C#'s unsafe code — confining unsafety to auditable regions while keeping the rest of the language safe.

Theoretical foundations

In type theory, type safety of a language is typically proved through the properties of progress (a well-typed term is never stuck) and preservation (evaluation preserves typing). These results anchor the design of modern type systems, including generics, variance rules, and null-safety features in recent languages.
