Highest and best use

Highest and best use (HBU) is a concept in real estate appraisal and economics borrowed from zoning and property law. The Appraisal Institute defines it as the reasonably probable use of a property that is physically possible, appropriately supported, financially feasible, and that results in the highest value. Appraisers test candidate uses against four criteria — legally permissible, physically possible, financially feasible, and maximally productive — to determine the use on which a valuation should be based.

Application

The analysis is performed twice: for the land as though vacant, and for the property as improved. If the value of the land as vacant exceeds the value as improved (less demolition costs), redevelopment may be warranted. Highest and best use analysis is central to appraisals for lending, taxation, eminent domain (condemnation), and investment decisions, since the market value of a property depends on what buyers would do with it rather than only its current use.
