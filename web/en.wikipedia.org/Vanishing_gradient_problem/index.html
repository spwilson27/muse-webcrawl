Vanishing gradient problem

In machine learning, the vanishing gradient problem is encountered when training artificial neural networks with gradient-based learning methods and backpropagation. The gradients used to update the network's weights can shrink exponentially as they are propagated to earlier layers, so that neurons in those layers learn very slowly or stop learning altogether.

Cause

Backpropagation computes gradients by the chain rule, multiplying the derivatives of each layer's activation function. Activation functions such as the sigmoid and hyperbolic tangent have derivatives smaller than 1 (the sigmoid's maximum derivative is 0.25), so in a deep network the product of many small numbers tends toward zero. The problem was analysed by Sepp Hochreiter in 1991 and is related to the opposite exploding gradient problem.

Solutions

Common remedies include using rectified linear units (ReLU) and related activation functions, careful weight initialisation schemes (such as Xavier and He initialisation), batch normalisation, residual connections that give gradients a shortcut path, and gated architectures such as long short-term memory (LSTM) networks for recurrent models.
