Fuzzy logic

From Wikipedia, the free encyclopedia

[Image: Membership functions for the fuzzy sets "cool", "warm" and "hot" over a temperature range]

Fuzzy logic is a form of many-valued logic in which the truth value of variables may be any real number between 0 and 1, inclusive. It is employed to handle the concept of partial truth, where the truth value may range between completely true and completely false. By contrast, in Boolean logic, the truth values of variables may only be 0 or 1.

The term "fuzzy logic" was introduced with the 1965 proposal of fuzzy set theory by Iranian-Azerbaijani mathematician Lotfi Zadeh. A fuzzy set is characterised by a membership function assigning each element a degree of membership between 0 and 1, allowing concepts like "tall", "warm" or "fast" — which have no sharp boundaries — to be represented mathematically.

Basics

Where classical sets decide membership absolutely, a fuzzy set A over a universe X is defined by a function μA : X → [0, 1]. Logical operations are generalised — commonly AND as the minimum, OR as the maximum, and NOT as 1 − x (Zadeh operators) — though other t-norms are used. Fuzzy logic differs from probability: degrees of truth describe vagueness of description, not uncertainty about a crisp fact.

Fuzzy control systems

The most commercially successful application is the fuzzy control system. A controller converts crisp sensor inputs into fuzzy values ("fuzzification"), applies human-readable linguistic rules ("if temperature is hot and rising, then cooling is strong"), and converts the aggregated result back to a crisp output ("defuzzification", often by the centroid method). Ebrahim Mamdani demonstrated fuzzy control of a steam engine in 1974; Japanese companies then popularised the approach in the 1980s — in the Sendai subway's automatic train operation, camcorder autofocus, washing machines, rice cookers and air conditioners.

Other applications

Fuzzy methods appear in pattern recognition, decision support, medical diagnosis, finance and data mining, and fuzzy rules can be learned or tuned with neural networks (neuro-fuzzy systems such as ANFIS).

Criticisms

Critics note that fuzzy logic is not a substitute for probability in reasoning under uncertainty, and that membership functions are often chosen ad hoc. Defenders reply that vagueness, not randomness, is the target phenomenon, and point to the engineering track record of fuzzy controllers.
