Augmented matrix

In linear algebra, an augmented matrix is a matrix obtained by appending the columns of two given matrices, usually for the purpose of solving a system of linear equations. For a system with coefficient matrix A and constant vector b, the augmented matrix is written [A | b], the vertical bar separating the coefficients from the constants.

Solving systems

Elementary row operations on the augmented matrix correspond exactly to operations on the equations of the system. By applying Gaussian elimination, the augmented matrix can be brought to row echelon form, or to reduced row echelon form by Gauss–Jordan elimination, from which the solution set can be read directly by back-substitution.

Example

For the system x + 2y = 5 and 3x − y = 4, the augmented matrix is:

[ 1  2 | 5 ]
[ 3 −1 | 4 ]

Reducing it gives x = 13/7, y = 11/7.

Finding inverses

Augmenting a square matrix with the identity matrix and reducing to reduced row echelon form yields the matrix inverse on the right-hand side, if it exists.
