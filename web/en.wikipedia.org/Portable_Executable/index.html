Portable Executable

The Portable Executable (PE) format is a file format for executables, object code, and DLLs used in 32-bit and 64-bit versions of Microsoft Windows. It is a modified version of the Unix COFF format and was introduced with Windows NT 3.1 in 1993.

Structure

A PE file begins with an MS-DOS header and stub (containing the famous "This program cannot be run in DOS mode" message), followed by the PE signature "PE\0\0", a COFF file header, and an "optional header" that supplies the addresses and sizes the Windows loader needs, including the image base and entry point. Data such as code, resources, import and export tables, and relocation information is organized into named sections such as .text, .data, .rdata, and .rsrc.

Variants

PE32 serves 32-bit systems and PE32+ extends the format for 64-bit. The .NET Framework stores managed assemblies in PE files whose entry point invokes the Common Language Runtime. Despite the name "portable", the format is specific to Windows and compatible environments such as Wine and ReactOS.
