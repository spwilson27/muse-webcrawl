Blazor

Blazor lets developers build web UIs with C# and Razor components.

Blazor is a free and open-source web framework developed by Microsoft that enables developers to create interactive web user interfaces using C# and HTML instead of JavaScript. It is part of the ASP.NET Core framework and was first released in 2018. The name is a portmanteau of "browser" and "Razor," the ASP.NET view engine on which its component syntax is based.

Hosting models

Blazor supports several hosting models. In Blazor WebAssembly, the application — including a .NET runtime — is downloaded to the browser and runs client-side on WebAssembly, allowing offline operation and direct interaction with browser APIs. In Blazor Server, the application runs on the server and UI updates are sent to the browser over a SignalR connection. Later versions unified these into a single Blazor Web App model with selectable render modes, including static server-side rendering, and Blazor Hybrid allows components to run inside native mobile and desktop applications via .NET MAUI and similar hosts.

Features

Applications are built from reusable Razor components that combine markup and C# logic. Blazor supports dependency injection, routing, forms and validation, layout, and interoperability with existing JavaScript libraries through JS interop calls. Because code can be shared between client and server, Blazor is popular in organizations standardized on the .NET platform, although its WebAssembly download size and startup time have been noted as trade-offs compared with JavaScript frameworks.
