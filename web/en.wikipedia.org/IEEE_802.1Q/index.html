IEEE 802.1Q

IEEE 802.1Q, often referred to as Dot1q, is the networking standard that supports virtual local area networking (VLANs) on an IEEE 802.3 Ethernet network. The standard defines a system of VLAN tagging for Ethernet frames and the accompanying procedures to be used by bridges and switches in handling such frames. The standard also contains provisions for a quality-of-service prioritization scheme commonly known as IEEE 802.1p, which was originally a separate standard (802.1p) later incorporated into 802.1Q.

An 802.1Q-tagged Ethernet frame: the 4-byte tag sits between the source MAC address and the EtherType field.

Frame format

802.1Q adds a 32-bit field between the source MAC address and the EtherType field of the original frame. Two bytes are used for the tag protocol identifier (TPID), fixed at 0x8100, and two bytes for tag control information (TCI):

FieldBitsDescription
Priority Code Point (PCP)3Priority from 0 (best effort) to 7 (highest)
Drop Eligible Indicator (DEI)1Frame may be dropped under congestion (formerly CFI)
VLAN Identifier (VID)12Identifies the VLAN; 0 and 4095 reserved, giving 4094 usable VLANs

Because the tag changes the frame, the frame check sequence (FCS) is recalculated. Insertion of the tag raises the maximum frame size from 1518 to 1522 bytes, sometimes called a "baby giant" frame.

VLANs and trunking

By assigning switch ports to VLANs, a single physical network can be partitioned into multiple broadcast domains, separating departments, tenants or classes of traffic for security and manageability. Links carrying multiple VLANs between switches are called trunks; the native VLAN on a trunk is sent untagged. Switches learn which VLANs are needed on each trunk through protocols such as GVRP or MVRP, also defined within 802.1Q. Each VLAN typically corresponds to a separate IP subnet.

Double tagging and related standards

Provider bridging (802.1ad, "QinQ") stacks a second, service-provider tag around the customer tag, enabling providers to carry many customer VLANs independently. Amendments to 802.1Q have also incorporated Shortest Path Bridging (802.1aq), time-sensitive networking features (802.1Qbv and others), and the Multiple Spanning Tree Protocol. The standard sits alongside the IEEE 802.11 wireless standards in the broader IEEE 802 family.
