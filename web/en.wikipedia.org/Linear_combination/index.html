Linear combination

In mathematics, a linear combination is an expression constructed from a set of terms by multiplying each term by a constant scalar and adding the results: a1v1 + a2v2 + … + akvk.

The set of all linear combinations of vectors in a set S is their span. Vectors are linearly independent if none can be written as a linear combination of the others; a basis is a linearly independent spanning set.

Examples

In Euclidean space, any vector (x, y) is a linear combination x·e1 + y·e2 of the standard basis vectors. Linear combinations also apply to functions, polynomials and solutions of linear differential equations.
