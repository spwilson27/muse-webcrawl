Hamming code

In computing, telecommunication, and information theory, a Hamming code is a linear error-correcting code.

In computing, telecommunication, and information theory, a Hamming code is a linear error-correcting code that can detect and correct single-bit errors, and detect (but not correct) double-bit errors. It was invented by Richard Hamming in 1950. Because of its simplicity, Hamming codes are widely used in computer memory (ECC memory) and other systems where bit errors must be corrected.

History

Hamming worked at Bell Telephone Laboratories on the electromechanical relay-based Model V computer, whose error-prone operation — and the frustration of having programs fail over weekends — led him to devise codes that could not only detect but automatically correct errors. He published his fundamental paper in 1950. The codes he introduced founded, together with the near-contemporary work of Claude Shannon and Marcel Golay, the field of coding theory.

Construction

A Hamming code with r parity bits encodes blocks of 2r − 1 bits in total, of which 2r − r − 1 are data bits. The parity bits are placed at positions that are powers of two (1, 2, 4, 8, …); the remaining positions hold data. Each parity bit checks the parity of a subset of positions determined by the binary representation of the positions: parity bit 2k covers all positions whose index has a 1 in the 2k place. On decoding, the pattern of parity checks that fail (the syndrome) directly gives the binary index of the erroneous bit, which can then be flipped to correct it. The best-known example is the (7,4) code: three parity bits protect four data bits.

Hamming codes have a minimum distance of 3, which allows the correction of one error per block. Adding one overall parity bit produces the extended Hamming code with distance 4 — SECDED (single-error correcting, double-error detecting) — the scheme commonly used in error-correcting computer memory.
