Double Ratchet Algorithm


The algorithm advances cryptographic keys with every message.

The Double Ratchet Algorithm is a cryptographic key management protocol for end-to-end encrypted messaging. Developed by Trevor Perren and Moxie Marlinspike in 2013, it is the core of the Signal Protocol, used by Signal, WhatsApp, and other messengers to protect billions of conversations.

How it works

The algorithm combines two ratchets. A symmetric-key ratchet derives a fresh message key for every message from a chain key, providing forward secrecy: compromising a later key cannot decrypt earlier messages. A Diffie–Hellman ratchet periodically exchanges new public keys, so the session "heals" after a compromise — called post-compromise security or future secrecy. Out-of-order messages are handled by storing skipped message keys in a message-key cache.

Security properties

Because keys change with every message and are derived through one-way functions, an attacker who steals a device's state obtains only the keys not yet deleted. The design influenced later standards, including the MLS protocol for group messaging.
