Decidability (logic)

In logic, a problem is decidable if there exists an effective method — an algorithm — that always terminates and correctly answers yes or no for every instance of the problem. A formal theory is decidable if, for every sentence of its language, an algorithm can determine whether the sentence is provable in the theory. Decidability is a central theme linking mathematical logic and theoretical computer science.

Examples

Propositional logic is decidable, for instance by truth tables. Presburger arithmetic (addition without multiplication) is decidable, as is the first-order theory of real closed fields, proved by Alfred Tarski. By contrast, first-order predicate logic is undecidable — the Entscheidungsproblem posed by David Hilbert was answered negatively by Alonzo Church and Alan Turing in 1936 — and full arithmetic is undecidable as a consequence of Gödel's incompleteness theorems. Peano arithmetic is also incomplete: some true statements are unprovable within it.

Related concepts

A problem is semi-decidable (or recursively enumerable) if an algorithm can confirm every positive instance, though it may run forever on negative ones; theoremhood in first-order logic is semi-decidable, so automated theorem provers can eventually find any valid proof. Decidability must also be distinguished from computational complexity: a problem may be decidable in principle yet infeasible to solve in practice.
