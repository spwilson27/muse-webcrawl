WOFF

WOFF (Web Open Font Format) is a font format for use on web pages, developed in 2009 by Jonathan Kew, Tal Leming, and Erik van Blokland, with contributions from the Mozilla Foundation. It wraps TrueType, OpenType, or Open Font Format fonts in a compressed container and supports embedded licensing metadata.

Overview

WOFF was created to give web designers a standard, interoperable way to embed fonts with CSS @font-face rules while addressing font foundries' concerns about unlicensed distribution of raw font files. The format applies zlib compression to the font data — typically reducing file size by around 40 percent compared with an uncompressed TrueType font — and can carry optional XML metadata describing the font's origin and license.

WOFF 2.0

WOFF 2.0, developed with Google, replaces zlib with Brotli compression and adds transform-based preprocessing of font tables, yielding roughly 30 percent better compression on average than WOFF 1.0. It became a W3C Recommendation in 2018 and is supported by all major browsers.

Standardization and support

The W3C published WOFF 1.0 as a Recommendation in December 2012. Because a WOFF file is not directly installable as a system font, foundries were more willing to license fonts for web use in the format, and it became the de facto standard container for web fonts alongside raw TTF/OTF delivery.
