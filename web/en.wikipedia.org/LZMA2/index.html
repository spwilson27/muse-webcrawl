LZMA2

From Wikipedia, the free encyclopedia

LZMA2 is a lossless data compression format that provides a container format for LZMA (Lempel–Ziv–Markov chain algorithm) data. It was introduced with version 9 of the .xz file format and the XZ Utils software, and is intended as a successor container to the original ".lzma" format used by 7-Zip.

Design

Unlike LZMA, which is a raw stream, LZMA2 structures data into chunks of up to 2 MiB of uncompressed data. Each chunk is independently compressed with LZMA1 (with resettable dictionary and encoder state), or stored uncompressed when compression would not help; this makes it possible to decompress (and, with limits, compress) data in parallel threads and to seek within a stream. LZMA2 also avoids the possibility of expansion of incompressible data that exists with plain LZMA streams.

Use

LZMA2 is the default compression method of the .xz format and is widely used for distributing software source code, Linux kernel archives and package repositories, where its high compression ratio is prized and its relatively slow, memory-hungry compression is acceptable because decompression is faster and data is compressed once and read many times.
