Push technology

Push technology (also called server push) is a method of communication on the internet in which a central server transmits information to a client without the client specifically requesting it. This contrasts with the classic pull model, in which the client asks the server for data, as when a browser requests a web page.

Applications

Push techniques underlie instant-messaging notifications, stock tickers, news alerts, and mobile push notifications delivered by services such as Apple Push Notification service and Firebase Cloud Messaging. Email is effectively a push system at the delivery stage, as are RSS subscription feeds in spirit, though they are implemented by polling.

Web implementations

Because the HTTP protocol is fundamentally request–response, web push has historically been simulated by workarounds: long polling, in which the server holds a request open until data is available; streaming over a persistent connection; and technologies such as Comet. Modern standards-based approaches include the WebSocket protocol, which provides full-duplex channels, server-sent events, and HTTP/2 server push, together with the W3C Push API used to send notifications to web applications.
