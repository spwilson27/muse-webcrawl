Cascading Style Sheets

DeveloperWorld Wide Web Consortium (W3C)
Initial release17 December 1996 (CSS1)
Proposed byHåkon Wium Lie; Bert Bos
File extension.css

Cascading Style Sheets (CSS) is a style sheet language used for specifying the presentation and styling of a document written in a markup language such as HTML or XML. CSS is a cornerstone technology of the World Wide Web, alongside HTML and JavaScript, and is designed to separate content from presentation, including layout, colours, and fonts.

CSS rules style HTML elements, as used to style this page inline.

Syntax and the cascade

A CSS rule consists of a selector and a declaration block of property–value pairs:

p { color: #202122; line-height: 1.6; }

The "cascade" resolves conflicts between rules by origin and importance, specificity of the selector, and order of appearance. Styles may be supplied by external .css files, by a <style> element, or by the inline style attribute.

History

Style sheets for structured documents existed in publishing before the Web. Håkon Wium Lie proposed CSS in October 1994 while working at CERN with Tim Berners-Lee; with Bert Bos he developed it into a W3C Recommendation, CSS1, in December 1996. CSS2 followed in 1998, and CSS3 was developed as a set of modules (including selectors, media queries, flexbox, and grid) from the 2000s onward. The later work of the WHATWG and W3C CSS Working Group continues to evolve the language.

Capabilities

Modern CSS supports responsive design through media queries, complex layout via Flexbox and Grid, animations and transitions, custom properties (variables), and transforms — enabling most web presentation without images or scripting.
