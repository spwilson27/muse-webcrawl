In mathematics, a dynamical system is a system in which a function describes the time dependence of a point in a geometrical space. Examples include the mathematical models that describe the swinging of a clock pendulum, the flow of water in a pipe, and the number of fish in a lake. At any given time, a dynamical system has a state represented by a tuple of real numbers (a vector) chosen to describe the system's future behaviour given only that state.

The evolution rule is a function that describes what future states follow from the current state. If the rule is deterministic, the system is a deterministic dynamical system; if it involves randomness, it is a stochastic dynamical system. Systems are classed as continuous (flows, defined by differential equations) or discrete (maps, defined by iteration).

History

The field grew out of classical mechanics and was placed on a qualitative footing by Henri Poincaré, whose study of the three-body problem revealed what is now called chaos. In the 20th century, Birkhoff, Kolmogorov, Arnold, Moser and Smale developed the modern theory, and Edward Lorenz's 1963 model of atmospheric convection made sensitive dependence on initial conditions famous.

Basic concepts

Important concepts include stability (whether nearby orbits stay nearby), attractors (sets towards which orbits evolve), bifurcations (qualitative changes as parameters vary), ergodicity, and chaos — bounded, aperiodic long-term behaviour that is highly sensitive to initial conditions.
