Pandas (software)

pandas is a software library written for the Python programming language for data manipulation and analysis. It provides data structures and operations for manipulating numerical tables and time series.

Features

Its core structures are the DataFrame, a two-dimensional labelled table, and the Series, a one-dimensional labelled array. pandas supports reading and writing formats such as CSV, Excel, SQL databases and HDF5, along with grouping, merging, reshaping and handling of missing data.

History

Originally developed by Wes McKinney at AQR Capital Management beginning in 2008, pandas was open-sourced in 2009 and is now maintained by a large community under the NumFOCUS umbrella.
