Multi-factor authentication

TypeElectronic authentication method
FactorsKnowledge, possession, inherence
Common formTwo-factor authentication (2FA)

Multi-factor authentication (MFA) is an electronic authentication method in which a user is granted access only after successfully presenting two or more pieces of evidence (factors) to an authentication mechanism. The factors are drawn from distinct categories: something the user knows (password, PIN), something the user has (security token, phone), and something the user is (fingerprint, face).

Two-factor authentication

Two-factor authentication (2FA) is the most common form, typically combining a password with a one-time code sent by SMS or generated by an authenticator app, a push notification, or a hardware security key. Regulators in banking and payments increasingly mandate MFA, for example under the EU's PSD2 strong customer authentication rules.

Weaknesses

SMS-based codes are vulnerable to SIM-swap attacks and phishing proxies, leading standards bodies to recommend app-based or hardware-backed factors, and passkeys based on public-key cryptography.
