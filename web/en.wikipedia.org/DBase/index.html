dBase

dBase
Developer: Ashton-Tate
Initial release: 1979 (Vulcan); 1980 (dBASE II)
Written in: Assembly language, C
Operating system: CP/M, DOS, Windows
Type: Database management system

dBase was one of the first database management systems for microcomputers and the most widely used database system on personal computers in the 1980s. Originally released as Vulcan for CP/M by Wayne Ratliff, it was renamed dBASE II and marketed by Ashton-Tate beginning in 1980. Its file format, the .dbf file, became a widespread standard.

History

Wayne Ratliff developed the original software, called Vulcan, on an IMSAI 8080 home computer to manage a football pool. Ashton-Tate licensed the program and released it as dBASE II in 1981 — there was never a dBASE I, the version number implying maturity. dBASE III (1984) and dBASE IV (1988) followed; dBASE IV's bugs and slow performance damaged the product's reputation. Borland acquired Ashton-Tate in 1991 and later sold the dBase line; the product continues today under dBase LLC.

Language

dBase included a procedural programming language with commands such as USE, REPLACE, APPEND, and BROWSE, allowing developers to build complete applications. Its popularity spawned clones and compilers including FoxPro, Clipper, and Harbour.

Legacy

The xBase family of languages and the .dbf format descend directly from dBase, and .dbf files remain in use in geographic information systems as part of the shapefile format.
