Terraform (software)

Terraform
Developer: HashiCorp
Initial release: 28 July 2014
Written in: Go
Type: Infrastructure as code
Licence: Business Source License (formerly MPL-2.0)

Terraform is an infrastructure-as-code software tool created by HashiCorp. Users define data center infrastructure in a declarative configuration language known as HashiCorp Configuration Language (HCL), or optionally JSON. Terraform manages the lifecycle of resources — such as virtual machines, networking components, storage, and services — across cloud providers and on-premises platforms through provider plugins that translate the configuration into API calls.

Design

Terraform configurations describe resources and their dependencies; from these, Terraform builds an execution plan that shows what will be created, modified, or destroyed to reach the desired state. Running terraform plan previews the changes and terraform apply executes them. Terraform records the current state in a state file, which it uses to map the configuration onto real-world resources and to compute changes. Reusable groups of resources are packaged as modules, and a public registry distributes providers and modules maintained by HashiCorp, partners, and the community.

History

Terraform was first released by HashiCorp on 28 July 2014 and reached version 1.0 in June 2021. In August 2023, HashiCorp changed the licence of Terraform and its other products from the Mozilla Public License to the Business Source License 1.1. In response, a community fork, OpenTofu, was created under the Linux Foundation, initially from the last MPL-licensed version. In 2025 IBM completed its acquisition of HashiCorp, which had been announced in 2024.

Providers and ecosystem

Terraform's core is cloud-agnostic; provider plugins exist for AWS, Microsoft Azure, Google Cloud, Kubernetes, and hundreds of other platforms and services. HCP Terraform (formerly Terraform Cloud) and Terraform Enterprise provide hosted runs, remote state, and policy-as-code features. Terraform is widely used in DevOps practice alongside tools such as Ansible, Pulumi, and AWS CloudFormation.
