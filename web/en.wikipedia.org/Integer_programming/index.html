Integer programming

An integer programming problem is a mathematical optimization or feasibility program in which some or all of the variables are restricted to be integers. In many settings the term refers to integer linear programming (ILP), in which the objective function and the constraints (other than the integer constraints) are linear. If some variables are integer and others are not, the problem is a mixed integer programming (MIP) problem.

Complexity and methods

Integer programming is NP-hard in general, but many important problems — scheduling, routing, knapsack, facility location, and the travelling salesman problem — are routinely solved in practice. Standard solution techniques include branch and bound, branch and cut, cutting planes (beginning with Gomory's work in 1958), and heuristics. Dropping the integer constraints yields the linear programming relaxation, which provides bounds on the optimum.

Applications

ILP is used in production planning, crew scheduling, capital budgeting, network design, and computational biology, wherever decisions are discrete: choosing whether to build a facility, assigning workers to shifts, or selecting a set of items subject to a capacity constraint.
