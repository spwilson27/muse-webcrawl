Singular function

In mathematics, a real-valued function f on an interval [a, b] is said to be a singular function if it has the properties that it is continuous, it is non-constant, and its derivative is zero almost everywhere. Singular functions occur, for example, as sequences of spatially distributed point charges or in the Lebesgue decomposition of functions of bounded variation.

The Cantor function

The classic example is the Cantor function, also called the Devil's staircase. It is constant on each interval removed in the construction of the Cantor set, climbs from 0 to 1 on [0, 1], and yet has derivative zero wherever the derivative exists, because all its growth is concentrated on the Cantor set, which has Lebesgue measure zero.

Properties

Singular functions are non-decreasing continuous functions of bounded variation that are not absolutely continuous. By the Lebesgue decomposition theorem, every function of bounded variation can be written uniquely as the sum of an absolutely continuous part, a singular continuous part, and a jump (saltus) part. In probability theory, singular continuous distributions — neither discrete nor absolutely continuous — have singular functions as their cumulative distribution functions.
