SAT solver

A SAT solver is a computer program that solves the Boolean satisfiability problem (SAT): given a propositional logic formula — usually in conjunctive normal form (CNF) — it determines whether there is an assignment of truth values to the variables that makes the formula true ("satisfiable", returning an assignment) or proves that no such assignment exists ("unsatisfiable"). SAT was the first problem shown to be NP-complete (the Cook–Levin theorem), yet modern solvers routinely handle instances with millions of variables.

Algorithms

Most modern solvers are based on conflict-driven clause learning (CDCL), an enhancement of the classic DPLL backtracking search. CDCL solvers perform Boolean constraint propagation, analyse conflicts to learn new clauses that prune the search, backjump non-chronologically, and use heuristics such as VSIDS for choosing variables, plus periodic restarts. Examples include MiniSat, Glucose, CaDiCaL, and Kissat. Stochastic local search solvers, such as WalkSAT, take a different approach and are effective on random satisfiable instances but cannot prove unsatisfiability.

Applications

SAT solvers are used in hardware and software verification (including bounded model checking), electronic design automation, automated planning, cryptanalysis, bioinformatics, and configuration problems. Extensions include SMT solvers, which add theories such as arithmetic, and MaxSAT solvers, which optimize the number of satisfied clauses.

Competitions

Progress in the field is driven by SAT competitions and races held since the 1990s, which benchmark solvers on industrial, crafted, and random instance families.
