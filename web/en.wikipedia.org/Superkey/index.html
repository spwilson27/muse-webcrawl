Superkey

In relational database theory, a superkey is a set of attributes within a relation that uniquely identifies each tuple (row) in that relation. In other words, no two distinct rows can share the same values for all the attributes of a superkey.

Relation to other keys

Every primary key is a superkey, but a superkey may contain extra attributes that are not needed for uniqueness. A superkey that contains no proper subset that is itself a superkey is called a candidate key (or minimal superkey). Tables typically have many superkeys — any combination of a candidate key with additional attributes qualifies — but only one or a few candidate keys.

Example

In an employees table with attributes (employee_id, name, department), if employee_id alone is unique, then {employee_id}, {employee_id, name}, and {employee_id, name, department} are all superkeys, while {employee_id} alone is the candidate key.
