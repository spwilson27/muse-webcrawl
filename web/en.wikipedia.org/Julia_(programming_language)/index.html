Julia (programming language)

Paradigm: Multi-paradigm; multiple dispatch
Designed by: Jeff Bezanson, Stefan Karpinski, Viral B. Shah, Alan Edelman
First appeared: 2012; version 1.0 in 2018
Typing: Dynamic, with optional type annotations
License: MIT

Julia is a high-level, general-purpose dynamic programming language designed for high-performance numerical analysis and computational science. It aims to solve the "two-language problem" — the need to prototype in a slow, expressive language and then rewrite in a fast one — by being both easy to use and fast, with just-in-time compilation via LLVM producing speeds comparable to C.

History

Work began in 2009 at MIT, and the language was publicly unveiled in a 2012 blog post by Jeff Bezanson, Stefan Karpinski, Viral B. Shah, and Alan Edelman, who explained their ambition to combine the best features of Lisp, Python, Perl, Ruby, MATLAB, and C. Version 1.0 was released in August 2018 during the annual JuliaCon. The language's development is open source, and a commercial ecosystem has grown around it, including JuliaHub and its use in pharmaceutical and climate modelling — a Julia-based climate model won recognition in HPC, and the Celeste astronomy project achieved petaflop-scale performance cataloguing stars.

Design

Julia's central design feature is multiple dispatch: functions are defined by many methods selected at runtime based on the types of all their arguments, which makes generic, extensible code natural. A rich type system is optional — annotations mainly guide specialization and performance. Other features include macros and metaprogramming inherited from Lisp, garbage collection, coroutine-based tasks, built-in package management, and easy calling of C and Fortran libraries without wrappers, as well as interfaces to Python and R.

Adoption

Julia is widely used in scientific computing, data science, machine learning (for example the Flux framework), differential equations (DifferentialEquations.jl), optimization, and economics; the Federal Reserve Bank of New York has implemented a macroeconomic model in Julia. It regularly ranks among the most-loved languages in developer surveys, though its ecosystem remains smaller than Python's, and slow first-call compilation latency ("time to first plot") has been a recurring target of improvement.
