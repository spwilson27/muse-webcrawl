The Cathedral and the Bazaar: Musings on Linux and Open Source by an Accidental Revolutionary is an essay and book by Eric S. Raymond on software engineering methods, first presented in 1997.

Argument

Raymond contrasts two models of software development: the "cathedral", in which source code is developed by a small, closed group between releases, and the "bazaar", exemplified by Linus Torvalds's development of the Linux kernel, in which code is developed publicly and incrementally over the Internet. Drawing on his experience maintaining the fetchmail program, Raymond formulates "Linus's law": "Given enough eyeballs, all bugs are shallow."

Influence

The essay is credited with helping to persuade Netscape to release the source code of its browser suite in 1998, the project that became Mozilla Firefox, and with popularising the open-source model in business.
