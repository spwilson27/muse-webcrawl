iPXE

iPXE is an open-source implementation of the Preboot eXecution Environment (PXE) client firmware and bootloader, derived from the gPXE project. It provides a full PXE implementation with additional features and can replace the built-in PXE ROM of supported network cards or be chainloaded.

Features

Beyond the standard TFTP-based booting of PXE, iPXE can download boot images over HTTP, HTTPS, iSCSI, Fibre Channel over Ethernet, and other protocols, and includes a scripting language and interactive command line. It supports both BIOS and UEFI environments and Wi-Fi booting.

Uses

iPXE is widely used for provisioning servers and workstations, diskless workstations, and cloud and data-centre deployments, where machines are booted and installed entirely over the network.
