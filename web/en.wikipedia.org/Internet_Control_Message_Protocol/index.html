Internet Control Message Protocol

The Internet Control Message Protocol (ICMP) is a network-layer protocol in the Internet protocol suite used by routers and hosts to send error messages and operational information about network conditions. It is specified in RFC 792 (1981) and is integral to both IPv4 and, in a revised form called ICMPv6, to IPv6.

Functions

ICMP messages are carried inside IP datagrams. Common message types include Destination Unreachable, Time Exceeded (sent when a packet's time-to-live reaches zero), Redirect, and Echo Request and Echo Reply, which are used by the ping utility to test reachability. The traceroute tool exploits Time Exceeded messages to map the route packets take across a network.

Unlike TCP or UDP, ICMP is not normally used to exchange application data, and it has no concept of ports. It is a supporting protocol: IP implementations are required to generate and process ICMP messages.

ICMPv6

For IPv6, ICMPv6 (RFC 4443) performs the same error-reporting role and additionally carries the Neighbour Discovery Protocol functions that replace ARP, including router advertisements and neighbour solicitations, making it essential to basic IPv6 operation.

Security

Because ICMP can reveal network structure and redirect traffic, firewalls often filter or rate-limit it. Some ICMP-based attacks, such as ping floods and the historical "ping of death", have led administrators to block certain message types, though blanket blocking can break path MTU discovery.
