Metadata

Metadata is "data about data": structured information that describes, explains, locates or otherwise makes it easier to retrieve, use or manage an information resource. A library catalogue card is a classic example; digital examples include the author, creation date and file size stored with a document, or the camera settings embedded in a photograph.

Types

Metadata is commonly divided into descriptive metadata (title, author, subject — used for discovery), structural metadata (how components are organised, such as chapters in a book), administrative metadata (rights, provenance and preservation information), and statistical metadata describing data processes.

Standards

Widely used metadata schemas include Dublin Core for general resources, MARC for library catalogues, EXIF for image files, and domain-specific standards in geospatial, educational and scientific data. Metadata is often encoded in XML or JSON and exchanged using protocols such as OAI-PMH.

Privacy

Metadata about communications — who contacted whom, when, and from where — can be highly revealing even without message content, and its collection by governments and platforms is a major subject of privacy debate.
