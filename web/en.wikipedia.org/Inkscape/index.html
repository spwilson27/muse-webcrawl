Inkscape is a free and open-source vector graphics editor used to create vector images, primarily in the Scalable Vector Graphics (SVG) format. It runs on Linux, Windows, and macOS and is widely used for illustration, diagrams, logos, and technical drawing.

History

Inkscape began in 2003 as a fork of the Sodipodi editor. Its developers adopted the W3C SVG standard as the native file format and progressively rewrote the codebase in C++ using the GTK toolkit. Version 1.0, a major milestone with improved performance and features, was released in May 2020.

Features

Inkscape offers shape tools, paths and Bézier curves, text, gradients, layers, cloning, tracing of bitmaps, and a wide range of path operations. It can import formats such as PDF, AI, EPS, and raster images, and export to PNG, PDF, and many other formats. An XML editor allows direct manipulation of the document's SVG tree. Extensions and scripting extend its capabilities.

Use

Because SVG is the standard vector format for the web, Inkscape is popular for web graphics, icon design, and print preparation. It is often compared with proprietary tools such as Adobe Illustrator, though its interface and workflow differ.
