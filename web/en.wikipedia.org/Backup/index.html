Backup

An external hard drive is a common backup medium.

In information technology, a backup, or data backup, is a copy of computer data taken and stored elsewhere so that it may be used to restore the original after a data loss event. The verb form, referring to the process of doing so, is "back up", whereas the noun and adjective form is "backup". Backups can be used to recover data after its loss from data deletion or corruption, or to recover data from an earlier time.

Strategies

Common strategies include full backups, which copy all selected data; incremental backups, which copy only data changed since the last backup of any type; and differential backups, which copy data changed since the last full backup. The widely cited 3-2-1 rule recommends keeping three copies of data, on two different media, with one copy stored off-site. Backup media include magnetic tape, hard disk drives, optical discs, solid-state drives, and remote cloud storage services.

Importance

Backups protect against hardware failure, accidental deletion, software corruption, theft, natural disaster, and malicious attacks such as ransomware. A backup strategy is only reliable if restores are tested periodically, and untested backups are a common point of failure in disaster recovery plans.
