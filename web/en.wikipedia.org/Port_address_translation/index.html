Port address translation

Port address translation (PAT), also called NAT overload, is a type of network address translation that allows multiple devices on a local network to be mapped to a single public IP address by translating both IP addresses and port numbers in packet headers. It is the most common form of NAT used in home routers.

Operation

When an internal host sends traffic to the internet, the PAT device replaces the source IP address with its single public address and assigns a unique source port, recording the mapping in a translation table. Return traffic addressed to that public address and port is forwarded back to the correct internal host. Because a 16-bit port field offers tens of thousands of ports, a single public address can support many simultaneous internal sessions.

Advantages and limitations

PAT conserves scarce IPv4 addresses and conceals internal addressing. Its drawbacks include breaking end-to-end connectivity, complicating inbound services (which require port forwarding), and interfering with protocols that embed addresses in their payloads, such as FTP and SIP.
