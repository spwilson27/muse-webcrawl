Single UNIX Specification

Systems certified against the specification may carry the UNIX trademark.

The Single UNIX Specification (SUS) is a standard for computer operating systems, compliance with which is required to qualify for using the "UNIX" trademark. It is developed and maintained by the Austin Group, a joint working group of The Open Group, the IEEE and ISO/IEC JTC 1. The specification defines the operating system interface — system calls, command-line utilities, shell behaviour and C library functions — that applications can rely upon for portability between conforming systems.

History

The SUS grew out of efforts in the 1980s and 1990s to reconcile divergent Unix variants, merging earlier work including POSIX and the X/Open Portability Guide. The first version appeared in 1995 (UNIX 95), followed by UNIX 98, and then Version 3 (2001), jointly published as POSIX:2001, which unified the base specifications. Version 4 followed in 2008, with Issue 8 published in 2024.

Contents

The specification is published as the Base Specifications, comprising volumes on base definitions, system interfaces, shell and utilities, and rationale. Conformance profiles such as UNIX 98, UNIX 03 and UNIX V7 define which parts a product must implement to be certified and branded.

Certification

Vendors submit products to The Open Group's certification programme; certified systems have included macOS, AIX, HP-UX, Solaris, z/OS and others. Linux distributions generally follow the specification closely but are rarely certified, an exception being a few certified distributions; the related Linux Standard Base drew heavily on the SUS and POSIX.
