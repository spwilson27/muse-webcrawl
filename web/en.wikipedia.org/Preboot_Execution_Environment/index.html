Preboot Execution Environment

PXE
Full namePreboot Execution Environment
Introduced1999 (Intel, Wired for Management)
PurposeNetwork booting of computers

The Preboot Execution Environment (PXE, pronounced "pixie"), often called PXE boot, is an environment to boot computers using a network interface independently of available data storage devices (like hard disks) or installed operating systems.

Operation

When a computer with PXE-enabled firmware starts, its network card issues a DHCP request extended with PXE options. The DHCP server (or a proxy DHCP server) responds with the address of a boot server and the name of a network bootstrap program (NBP). The client downloads the NBP using TFTP, verifies it, and executes it; the bootstrap program may then load a full operating system image or installer over the network.

Uses

PXE is commonly used for deploying operating systems across large fleets of machines, diskless workstations, thin clients, and automated provisioning in data centres. Modern UEFI firmware implements PXE over both IPv4 and IPv6, and related standards such as iSCSI boot and HTTP boot extend the same idea.
