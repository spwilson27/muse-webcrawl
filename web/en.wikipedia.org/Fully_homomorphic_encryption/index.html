Fully homomorphic encryption

Fully homomorphic encryption (FHE) is a form of encryption that allows computations to be performed on encrypted data without first decrypting it. The result, when decrypted, matches the result of the same operations performed on the plaintext. This enables outsourcing computation to untrusted environments, such as cloud servers, while preserving data privacy.

History

The problem was posed in 1978 by Rivest, Adleman, and Dertouzos, shortly after the invention of RSA, whose multiplicative structure gives partial homomorphism. The first plausible fully homomorphic scheme was constructed by Craig Gentry in 2009 using lattice-based cryptography and a technique called bootstrapping, which "refreshes" ciphertexts to control noise growth.

Schemes and applications

Subsequent schemes (BGV, BFV, CKKS, TFHE) improved efficiency dramatically. Applications include private information retrieval, secure cloud analytics, encrypted machine learning, and privacy-preserving medical and financial computation. Performance remains a practical challenge, though hardware acceleration is narrowing the gap.
