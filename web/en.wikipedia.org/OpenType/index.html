OpenType

OpenType

Developed by: Microsoft and Adobe

Released: 1996

File extensions: .otf, .ttf, .ttc

Standard: ISO/IEC 14496-22 (Open Font Format)

Based on: TrueType; incorporates PostScript (CFF) outlines

OpenType is a format for scalable computer fonts, developed jointly by Microsoft and Adobe as the successor to TrueType and PostScript Type 1 fonts. Announced in 1996, it unifies the two outline technologies: an OpenType font may contain TrueType-style quadratic outlines (with the .ttf extension) or PostScript-style cubic Bézier outlines in a Compact Font Format (CFF) wrapper (typically .otf). The format was standardised as the Open Font Format, ISO/IEC 14496-22.

Features

OpenType's defining innovation is its layout system. Fonts can include extensive metadata and rules in tables such as GSUB (glyph substitution) and GPOS (glyph positioning), enabling:

  • Ligatures and contextual alternates
  • Small caps, old-style and tabular figures, fractions, and swashes
  • Kerning and mark positioning
  • Correct shaping of complex scripts such as Arabic and Indic scripts
  • Language-specific forms selected by language tags

Because the format uses Unicode encoding and permits tens of thousands of glyphs in one font, a single OpenType font can support many languages and a rich typographic palette.

Later developments

Extensions have added colour fonts (using embedded SVG, bitmaps, or layered glyphs) and, in 2016, OpenType Font Variations — variable fonts, in which a single file interpolates weight, width, and other design axes, a technology widely adopted on the web. OpenType is the dominant font format on all major operating systems and underlies the WOFF web font packages.
