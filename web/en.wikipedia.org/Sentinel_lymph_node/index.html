Sentinel lymph node

The sentinel lymph node is the hypothetical first lymph node or group of nodes draining a cancer. It is postulated that cancer cells spread from a primary tumour via the lymphatic system first to this node before reaching other nodes, so examination of the sentinel node can indicate whether a cancer has metastasised.

Sentinel node biopsy

In a sentinel lymph node biopsy, a tracer — a radioactive colloid, a blue dye such as isosulfan blue, or an indocyanine green fluorescent agent — is injected near the tumour. The first node to take up the tracer is identified, removed, and examined histologically. If it is free of cancer, more extensive lymph node dissection can usually be avoided, reducing complications such as lymphedema.

Clinical use

The technique was pioneered for melanoma by Donald Morton and colleagues and is now standard practice in the staging of melanoma and breast cancer, and increasingly used in other cancers including vulvar, cervical, and colorectal cancer.
