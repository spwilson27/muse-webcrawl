List of data structures

A data structure is a way of organizing and storing data in a computer so it can be accessed and modified efficiently. This list summarizes the principal data structures in computer science, grouped by family.

Linear structures

  • Array and dynamic array (vector)
  • Linked list (singly, doubly, circular)
  • Stack (LIFO)
  • Queue (FIFO) and deque, priority queue
  • String and rope

Hash-based structures

  • Hash table / hash map
  • Hash set
  • Bloom filter (probabilistic membership)
  • Count–min sketch

Trees

  • Binary tree, binary search tree
  • AVL tree, red–black tree, splay tree
  • B-tree and B+ tree (databases and filesystems)
  • Heap (binary, binomial, Fibonacci)
  • Trie (prefix tree), suffix tree, suffix array
  • Segment tree, Fenwick tree (binary indexed tree)
  • k-d tree, quadtree, octree (spatial)
  • Disjoint-set (union–find)

Graphs

  • Adjacency list and adjacency matrix representations
  • Directed acyclic graph (DAG)

Other

  • Bit array / bitset
  • Skip list
  • Ring buffer (circular buffer)
  • Sparse matrix formats
  • Persistent and functional data structures

Selection among structures is governed by the operations required and their time and space complexity, typically expressed in Big O notation.
