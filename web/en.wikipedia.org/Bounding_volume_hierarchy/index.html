Bounding volume hierarchy

A bounding volume hierarchy (BVH) is a tree structure on a set of geometric objects in which each node represents a bounding volume — commonly an axis-aligned bounding box (AABB) — that encloses all the geometry in its subtree. BVHs are a central data structure in computer graphics, used to accelerate ray tracing, collision detection and visibility queries.

Ray tracing acceleration

In a ray tracer, testing a ray against every triangle in a scene is prohibitively slow. With a BVH, the ray is first tested against the root bounding volume; subtrees whose volumes the ray misses can be discarded without further work, and only volumes the ray intersects are visited, recursively, down to the primitives at the leaves. Well-built BVHs reduce intersection cost from linear to roughly logarithmic in the number of primitives.

Construction

BVHs are usually built top-down by recursively splitting the object set, for example by choosing the longest axis of the centroid bounds and partitioning at the median, or by using the surface area heuristic (SAH), which chooses splits minimizing the expected cost of traversal. Bottom-up construction by agglomerative clustering is also used, and dynamic scenes may rebuild or refit the hierarchy each frame.

Applications

Beyond rendering, BVHs are used in physics engines for broad-phase collision detection, in robotics for motion planning, and in spatial databases. Modern GPUs implement dedicated BVH traversal hardware, as in real-time ray tracing APIs such as DirectX Raytracing and Vulkan RT.
