GNU

GNU is an extensive collection of free software, which can be used as an operating system or in parts with other operating systems. The name is a recursive acronym for "GNU's Not Unix". The project was announced in September 1983 by Richard Stallman, who founded the Free Software Foundation in 1985 to support it. GNU's goal was to create a complete Unix-compatible software system composed entirely of free software, respecting users' freedom to run, study, share, and modify the software.

History and components

Development began in 1984 at MIT. The project produced many of the essential components of a Unix-like system: the GNU Compiler Collection (GCC), the GNU C Library (glibc), the Bash shell, the GNU Core Utilities, GNU Emacs, the GNU Debugger (GDB), and the GNU Build System, among hundreds of other packages. To guarantee the software remained free, Stallman authored the GNU General Public License (GPL) in 1989, which uses the concept of copyleft.

The one major component that lagged was the kernel. The GNU Hurd kernel, based on the Mach microkernel, was repeatedly delayed. In 1991–92, Linus Torvalds released the Linux kernel, and the combination of GNU userland software with Linux produced the complete, widely used systems often called "GNU/Linux" or simply Linux. GNU software was also ported widely to proprietary systems, and the GNU toolchain became foundational to modern software development.

Philosophy

The GNU Project embodies the free software philosophy articulated in Stallman's GNU Manifesto (1985): software users should have four essential freedoms — to run the program, to study and change it, to redistribute copies, and to distribute modified versions. GNU remains a central reference point for the free and open-source software movements, and the GPL family of licences covers a large share of the world's free software.
