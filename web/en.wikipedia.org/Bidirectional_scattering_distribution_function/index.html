Bidirectional scattering distribution function

From Wikipedia, the free encyclopedia

The bidirectional scattering distribution function (BSDF) is a function that describes how light is scattered by a surface or medium, generalising both reflection and transmission. It gives the ratio of outgoing radiance in a given direction to the incident irradiance from another direction, as a function of both directions and wavelength.

Components

The BSDF combines the bidirectional reflectance distribution function (BRDF), which covers light reflected into the same hemisphere, and the bidirectional transmittance distribution function (BTDF), which covers light transmitted into the opposite hemisphere. It is used where a single model must handle reflection, refraction, subsurface scattering and diffusion in computer graphics and optical engineering.

Use

Measured BSDF data (for example from goniophotometers) drive physically based rendering of materials such as glass, car paint and fabrics, and lighting simulation for displays, luminaires and architectural glazing. The bidirectional scattering-surface reflectance distribution function (BSSRDF) extends the concept to surfaces where light enters and exits at different points.
