Percentile

In statistics, a percentile (or centile) is a value below which a given percentage of observations in a group falls. The 25th percentile is the first quartile, the 50th percentile is the median, and the 75th percentile is the third quartile.

Definitions

There is no single universal definition; methods differ in how they interpolate between data points. Common approaches include the nearest-rank method and linear interpolation between closest ranks, as used (with different interpolation rules) by spreadsheet and statistical software. Percentiles should not be confused with percentages: a score at the 90th percentile is better than 90 percent of scores, which is different from scoring 90 percent correct.

Applications

Percentiles are widely used for standardised test reporting, child growth charts (where a child's height or weight is compared with reference populations), income statistics, and service-level metrics such as the 95th-percentile response time of a server or the 95th-percentile billing method for internet bandwidth.
