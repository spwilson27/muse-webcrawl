CAN bus

A Controller Area Network (CAN bus) is a robust vehicle bus standard designed to allow microcontrollers and devices to communicate with each other without a host computer. Developed by Robert Bosch GmbH in the 1980s and released in 1986, it is now used throughout the automotive industry and in many other embedded systems.

Technical overview

CAN uses a multi-master, message-oriented protocol over a differential two-wire bus. Messages carry identifiers that determine priority: bitwise arbitration lets the highest-priority message continue without corruption while others retransmit. Classical CAN supports bit rates up to 1 Mbit/s; CAN FD (flexible data rate) increases both payload size and speed.

Applications

Originally created to reduce the weight and complexity of wiring in cars, CAN now links engine control units, transmissions, airbags and body electronics, and is also found in industrial automation, medical equipment, agricultural machinery and lifts. Higher-layer protocols built on CAN include CANopen, J1939 and DeviceNet.
