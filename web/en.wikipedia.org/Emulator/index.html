Emulator

In computing, an emulator is hardware or software that enables one computer system (the host) to behave like another (the guest), so that programs written for the guest system can run on the host. Emulators reproduce the functions of the original system closely enough that guest software cannot tell the difference. They are widely used to run legacy software, develop programs for devices not yet available, test software across platforms, and preserve obsolete systems and video games.

Emulation lets modern hardware run software written for long-obsolete systems

How emulation works

A software emulator models the guest system's processor and other hardware. In interpretation, each guest instruction is fetched and executed by equivalent host operations — simple but slow. Dynamic recompilation (binary translation) converts blocks of guest code into host machine code and caches them, greatly improving speed. Emulators must also imitate memory, graphics and sound hardware, input devices, and storage, often cycle-by-cycle for perfect timing with older machines.

Emulation versus simulation and virtualisation

An emulator duplicates the target system's behaviour at a low level so that real guest software runs unmodified. A simulator, by contrast, models a system abstractly for study and may not run real code. Virtualisation runs guest systems on the same processor architecture with the assistance of a hypervisor, which is much faster but cannot cross architecture boundaries the way emulation can.

Uses

Emulation has been used since the mainframe era — IBM's System/360 offered emulation of earlier machines in the 1960s. Today it underpins mobile app development (device emulators in software development kits), cross-platform testing, digital preservation of historic software, network equipment and terminal emulation, and the retro gaming scene, where emulators such as those for classic consoles allow old games to be played on modern computers. The legal status of emulators is generally accepted in many jurisdictions, though distributing copyrighted firmware or game images (ROMs) remains restricted.
