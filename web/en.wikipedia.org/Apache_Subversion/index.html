Apache Subversion (often abbreviated SVN) is a free, open-source, centralised version control system. It was created by CollabNet in 2000 as a successor to CVS and became a top-level project of the Apache Software Foundation in 2010.

Features

Subversion tracks changes to files and directories in a central repository. Commits are atomic and receive sequential revision numbers applying to the whole repository. It supports branching and tagging by cheap directory copies, file locking, and versioning of symbolic links and renames. Unlike distributed systems such as Git, clients check out a working copy of a single revision rather than the full history.

History

Version 1.0 was released in February 2004. Subsequent releases added merge tracking (1.5), a reworked working-copy format (1.7), and improved conflict resolution (1.10). Although Git has largely overtaken it in popularity for new projects, Subversion remains in use in many enterprise codebases.
