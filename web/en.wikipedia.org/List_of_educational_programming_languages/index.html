List of educational programming languages

An educational programming language is a programming language designed primarily for learning, rather than for practical software development. Such languages emphasise simple syntax, immediate feedback, and forgiving error behaviour.

Design principles

Educational languages typically lower the "floor" (easy to start), raise the "ceiling" (room to grow), and widen the "walls" (support many kinds of projects), a philosophy articulated by Mitchel Resnick's group at MIT.
