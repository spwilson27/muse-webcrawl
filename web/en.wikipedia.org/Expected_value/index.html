Expected value

NotationE[X], 𝔼X
DefinitionProbability-weighted average of possible values
IntroducedHuygens (1657), Pascal–Fermat correspondence (1654)

In probability theory, the expected value (also called expectation, mathematical expectation, or the mean) of a random variable is a generalization of the weighted average. Informally, the expected value is the arithmetic mean of a large number of independently selected outcomes of a random variable.

For a discrete random variable X taking values xi with probabilities pi, the expectation is E[X] = Σ pixi. For a fair six-sided die, E[X] = (1+2+3+4+5+6)/6 = 3.5 — a value that itself never occurs, illustrating that the expected value need not be a possible outcome.

History

The concept arose from the problem of points in the 1654 correspondence between Blaise Pascal and Pierre de Fermat, and was set out by Christiaan Huygens in De ratiociniis in ludo aleae (1657), the first book on probability. It quickly became central to gambling analysis, insurance, and economics.

Properties

Expectation is linear: E[aX + bY] = aE[X] + bE[Y] for constants a and b, even when X and Y are dependent. For independent variables, E[XY] = E[X]E[Y]. The law of large numbers guarantees that sample averages converge to the expected value as the number of trials grows. Expected values are used in decision theory through expected utility, and in finance through risk-neutral pricing.

When expectation fails

Some distributions have no finite expected value: the Cauchy distribution is the standard example, and the St. Petersburg paradox presents a game whose expected payoff is infinite despite no rational player paying much to play.
