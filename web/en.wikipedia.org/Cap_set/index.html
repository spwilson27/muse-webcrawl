Cap set
Subset of (Z/3Z)n containing no three-term arithmetic progression

In mathematics, a cap set is a subset of the vector space (Z/3Z)n that contains no three distinct elements in arithmetic progression — equivalently, no three collinear points. The cap set problem asks how large the biggest cap set can be.

The problem

The card game Set is played with the n = 4 case. For many years the best lower bounds grew roughly like 2.2n while upper bounds stayed close to 3n.

Breakthrough

In 2016, Jordan Ellenberg and Dion Gijswijt, building on a polynomial-method breakthrough by Croot, Lev, and Pach, proved that cap sets have size at most about 2.756n, resolving the problem's exponential gap — a landmark in additive combinatorics.
