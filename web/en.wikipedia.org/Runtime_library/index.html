Runtime library

TypeSoftware library
Used byCompiled programs at execution time
ExamplesC standard library implementations, compiler-specific support libraries

In computer programming, a runtime library is a set of low-level routines made available by a compiler or programming language implementation to support a program while it is running. Such routines provide services that the compiled code cannot easily express directly in the hardware instruction set, or that must be handled in a standardised way — including program startup and termination, memory allocation, input/output, mathematical functions, type checks, exception handling and, in some languages, garbage collection support.

Functions of a runtime library

Typical contents include:

  • Program initialisation — code that runs before a program's entry point, setting up the stack, initialising static data and invoking constructors.
  • Language support — routines implementing language features such as software floating-point arithmetic on processors lacking an FPU, integer division on simple hardware, bounds checking, or exception unwinding.
  • Standard library functions — implementations of string handling, mathematics and I/O exposed through the language's standard library.

Static and dynamic forms

A runtime library may be statically linked into the executable at link time or supplied as a shared (dynamic) library loaded when the program starts — for example, the Microsoft Visual C++ runtime redistributables (such as MSVCRT and the Universal CRT) on Windows, or glibc together with libgcc on Linux systems. The distinction between a "runtime library" in the narrow compiler-support sense and a language's broader standard library varies between toolchains.

Relation to runtime systems

A runtime library should be distinguished from a runtime system (or runtime environment), which typically denotes a more substantial execution framework, such as the Java virtual machine or the .NET Common Language Runtime, that actively manages the program's execution rather than merely providing routines it calls.
