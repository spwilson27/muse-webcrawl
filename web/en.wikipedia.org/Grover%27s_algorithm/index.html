Grover's algorithm

Grover's algorithm
FieldQuantum computing
DiscovererLov Grover (1996)
ComplexityO(√N) queries vs O(N) classical

Grover's algorithm is a quantum algorithm for searching an unstructured database of N entries for a marked item, using only O(√N) queries — a quadratic speedup over classical search. It was devised by Lov Grover in 1996.

How it works

The algorithm starts with the qubits in an equal superposition of all possible states. It repeatedly applies the Grover iteration: an oracle operation that flips the phase of the marked state, followed by a diffusion operation that reflects amplitudes about their mean, amplifying the marked state's probability.

Optimality and uses

Grover's algorithm is provably optimal for unstructured search: no quantum algorithm can do asymptotically better. It can be adapted to problems such as finding minima, estimating means, and speeding up brute-force attacks, which is why symmetric key sizes are often doubled in post-quantum planning.
