Nyquist stability criterion

The Nyquist stability criterion, named after Harry Nyquist, is a graphical technique in control theory for determining the stability of a dynamical system. Because it only looks at the Nyquist plot of the open-loop systems, it can be applied without explicitly computing the poles and zeros of either the closed-loop or open-loop system. As a result, it can be applied to systems defined by non-rational functions, such as systems with delays.

Background

The criterion is based on Cauchy's argument principle from complex analysis. Consider a closed-loop transfer function with characteristic polynomial 1 + G(s)H(s). If a contour that encircles the entire right half-plane is mapped through the open-loop transfer function, the number of times the resulting plot encircles the point (−1, 0) determines the number of unstable closed-loop poles.

The criterion

Let N be the number of encirclements of the −1 point, P the number of open-loop unstable poles, and Z the number of closed-loop unstable poles. Then Z = N + P. For the closed-loop system to be stable, Z must be zero, so the Nyquist plot of a system with no open-loop unstable poles must not encircle the −1 point.

Gain and phase margins

Nyquist plots also yield the gain margin and phase margin of a system, measures of how much gain or phase shift can be tolerated before instability, which are widely used in feedback amplifier and control system design.
