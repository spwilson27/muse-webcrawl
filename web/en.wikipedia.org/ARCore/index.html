ARCore

ARCore
Developer: Google
Initial release: March 2018
Platform: Android, iOS (via AR Foundation)
License: Proprietary / Apache 2.0 (SDK parts)

ARCore, also known as Google Play Services for AR, is a software development kit developed by Google that allows for augmented reality (AR) applications to be built. ARCore uses three key technologies to integrate virtual content with the real world as seen through a phone's camera: motion tracking, environmental understanding, and light estimation.

Technology

Motion tracking uses the phone's camera and inertial sensors to identify interesting points, called features, and track how they move over time, determining both the position and orientation of the phone as it moves through space. Environmental understanding detects horizontal and vertical surfaces, while light estimation allows virtual objects to be lit consistently with the surrounding environment.

Features

Later additions include the Depth API, which uses a depth-from-motion algorithm to create depth maps, Augmented Images, persistent anchors, and Cloud Anchors for shared AR experiences across devices. ARCore succeeded Google's earlier Project Tango platform.
