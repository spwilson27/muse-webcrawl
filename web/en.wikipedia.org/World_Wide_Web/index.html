World Wide Web

The World Wide Web (WWW or simply the Web) is an information system that enables content sharing over the Internet through user-friendly interfaces. It was invented by the English computer scientist Tim Berners-Lee at CERN in 1989 and opened to the public in 1991. Web content is identified by uniform resource locators (URLs), written primarily in the HyperText Markup Language (HTML), and transferred using the Hypertext Transfer Protocol (HTTP).

History

Berners-Lee proposed "a web of notes with links" in March 1989 and, with Robert Cailliau, had the first web server and browser/editor running by Christmas 1990 on a NeXT computer. CERN released the Web technology into the public domain on 30 April 1993, enabling royalty-free adoption. The graphical Mosaic browser (1993), developed at the University of Illinois, popularised the Web beyond academia, and Netscape Navigator followed in 1994.

Berners-Lee founded the World Wide Web Consortium (W3C) in 1994 to standardise web technologies. The commercialisation and privatisation of the Internet backbone in the mid-1990s triggered the dot-com boom (and bust of 2000), followed by the participatory "Web 2.0" era of social media, user-generated content and web applications, and later the mobile web driven by smartphones.

How it works

A web browser requests a resource from a web server by URL; the server responds, usually with an HTML document that the browser renders, following embedded hyperlinks and fetching linked assets such as images, stylesheets and scripts. The Web is built on the Internet but is not synonymous with it: email, file transfer and other services also run over the Internet without being part of the Web.

Standards and governance

Standards such as HTML, CSS and JavaScript/ECMAScript have been stewarded by the W3C and later the WHATWG. Issues of privacy, surveillance, misinformation, accessibility and the centralisation of platforms remain subjects of public debate; Berners-Lee himself has campaigned for a more decentralised web and proposed the Solid project.
