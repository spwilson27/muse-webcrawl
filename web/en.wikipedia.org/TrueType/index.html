TrueType is an outline font standard developed by Apple in the late 1980s as a competitor to Adobe's Type 1 fonts used in the PostScript language. It was released in 1991 with Macintosh System 7 and later adopted by Microsoft Windows, where it became the dominant font technology. TrueType fonts are identified by the file extensions .ttf (TrueType font) and .ttc (TrueType collection).

History

Apple developed TrueType—originally codenamed "Bass" and later "Royal"—partly to free itself from licensing Adobe's font technology. Apple licensed the technology to Microsoft, and TrueType shipped in Windows 3.1 in 1992. The two companies later collaborated with Adobe on the OpenType format, which unified TrueType and PostScript outlines in a single wrapper.

Technology

TrueType glyphs are described by outlines made of line segments and quadratic Bézier curves, in contrast to the cubic curves of PostScript (Type 1) fonts. A distinguishing feature of TrueType is its powerful hinting system: fonts can contain bytecode instructions that adjust the rasterisation of glyphs at small sizes so that text remains crisp and legible on low-resolution screens and printers.

Basic concepts

A TrueType file consists of a collection of tables containing the data a font rasteriser needs: glyph outlines, character-to-glyph mappings, metrics, kerning and hinting instructions. Because shapes are stored as scalable outlines, a single font file can render text at any size.
