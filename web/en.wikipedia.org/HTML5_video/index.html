HTML5 video

The HTML5 video element (<video>) is a specification element introduced in HTML5 for playing videos and movies natively in web pages, replacing earlier reliance on browser plug-ins such as Adobe Flash. It allows authors to embed video with native controls, scripting interfaces and integration with the rest of the page.

History

The video element was first proposed by Opera in 2007 and was adopted into the HTML5 specification. Support arrived in major browsers between 2009 and 2011, and the format dispute between the Ogg Theora, WebM and H.264 codecs was a major controversy of the standardisation process. The rise of HTML5 video accelerated after mobile platforms declined to support Flash.

Features

The element supports attributes for controls, autoplay, looping, preload and poster images, multiple <source> children for format fallback, timed text tracks for captions and subtitles, and a JavaScript API for playback control and statistics. Extensions such as Media Source Extensions and Encrypted Media Extensions underpin adaptive streaming and DRM-protected content delivered through HTML5 players.
