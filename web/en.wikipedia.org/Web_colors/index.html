Web colors

[Image: Web colors]

Web colors are colors used in displaying web pages on the World Wide Web, and the methods for describing and specifying those colors. Colors may be specified as an RGB triplet, in hexadecimal format (a hex triplet), or according to their common English names in some cases. A color tool or other graphics software is often used to generate color values. In some cases, hexadecimal colors are specified with notation using a leading number sign (#).

Hex triplet

A hex triplet is a six-digit, three-byte hexadecimal number used in HTML, CSS, SVG, and other computing applications to represent colors. The bytes represent the red, green, and blue components of the color. One byte represents a number in the range 00 to FF (in hexadecimal notation), or 0 to 255 in decimal notation. For example, the color red is represented as #FF0000, green as #008000, and blue as #0000FF.

CSS colors

The Cascading Style Sheets specification defines a set of named colors, originally 16 basic colors derived from the HTML specification and later extended to the 140 "extended color keywords" derived from the X11 color names. CSS also supports specifications using rgb(), rgba(), hsl(), and hsla() functional notations, and later color spaces such as Lab and OKLCH.

Web-safe colors

In the mid-1990s, many computers could display only 256 colors at a time, constrained by hardware or color palettes. The "web-safe" palette of 216 colors was proposed as a set that would display consistently across browsers and operating systems; it consists of combinations of six evenly spaced values (00, 33, 66, 99, CC, FF) for each RGB channel.
