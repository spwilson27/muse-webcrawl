Flash memory

TypeNon-volatile memory
InventedEarly 1980s (Fujio Masuoka, Toshiba)
Main typesNAND, NOR

Flash memory is an electronic non-volatile computer memory storage medium that can be electrically erased and reprogrammed. It is the dominant form of storage in USB flash drives, memory cards, and solid-state drives (SSDs).

Principles of operation

Flash memory stores information in an array of memory cells made from floating-gate transistors (or charge-trap cells). Each cell stores one or more bits depending on how many charge levels it can distinguish: single-level cells (SLC), multi-level cells (MLC), triple-level cells (TLC), and quad-level cells (QLC). Data must be erased in large blocks before rewriting, and each block tolerates only a limited number of program/erase cycles, so controllers use wear levelling to spread writes evenly.

History

Flash memory was developed by Fujio Masuoka and colleagues at Toshiba in the early 1980s; the name "flash" was suggested because the erasure process reminded a colleague of a camera flash. Intel introduced the first commercial NOR flash chip in 1988, and Toshiba announced NAND flash in 1989.

Applications

Because it has no moving parts, flash is rugged and fast, and it has displaced magnetic storage in portable devices and increasingly in laptops and data centres. NOR flash remains common for code storage in embedded systems because it supports execute-in-place.
