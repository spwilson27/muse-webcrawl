Structured analysis
Field: Systems analysis, software engineering
Tools: Data flow diagrams, data dictionary

Structured analysis is a software engineering and systems analysis method, developed in the late 1970s by Tom DeMarco, Ed Yourdon and others, for analysing and converting business requirements into specifications for information systems.

Techniques

Its central tool is the data flow diagram (DFD), which decomposes a system level by level into processes, data stores, external entities and data flows. Supporting tools include the data dictionary, structured English for process specifications, and entity–relationship modelling for data.

Context

Structured analysis forms the analysis half of structured systems analysis and design method (SSADM) approaches, and is contrasted with later object-oriented analysis methods such as UML-based techniques.
