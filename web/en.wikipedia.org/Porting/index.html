Porting

Porting is the process of adapting software for the purpose of achieving some form of execution in a computing environment that is different from the one that a given program (meant for such execution) was originally designed for, such as a different CPU, operating system, or third-party library. The term is also used in a general way to refer to the process of adapting software or hardware to make them usable in other environments.

Overview

Software is considered to be portable if the cost of adapting it to a new environment is significantly less than the cost of writing it from scratch. The lower the cost of porting software, relative to its implementation cost, the more portable it is said to be. Historically, portability was a major concern because programs were often written in assembly language tied closely to a specific machine.

History

The rise of high-level languages such as C and Unix in the 1970s greatly improved portability. The C programming language was designed so that a compiler could be retargeted to new hardware with modest effort, and Unix itself was famously ported across many architectures. Modern cross-platform frameworks, virtual machines such as the Java Virtual Machine, and container technologies continue this tradition.

Compilers and interpreters

When a compiler or interpreter is ported to a new platform, the work typically involves building a code generator for the new processor, adapting system interfaces, and bootstrapping the toolchain. Porting games between consoles is a common commercial example, where developers adapt a title originally released for one platform to another with different hardware capabilities.
