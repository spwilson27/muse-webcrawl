Conda (package manager)

Conda manages packages and environments across languages.

DeveloperAnaconda, Inc. (formerly Continuum Analytics)
Initial release2012
Written inPython
Operating systemWindows, macOS, Linux
LicenceBSD

Conda is an open-source, cross-platform, language-agnostic package manager and environment management system. It was originally developed to solve difficult package management challenges faced by Python data scientists, and is available for Linux, Windows, and macOS. Conda quickly installs, runs, and updates packages and their dependencies, and it can create, save, load, and switch between isolated environments on a local computer.

Features

Unlike Python-specific tools such as pip, Conda can manage packages written in any language, including compiled libraries and the Python interpreter itself, by installing precompiled binaries rather than building from source. It resolves dependencies using a SAT solver to produce a consistent environment. Packages are distributed through channels; the most important are the defaults maintained by Anaconda and the community-led conda-forge channel, which hosts a very large collection of packages.

Distributions

Conda is bundled with Anaconda Distribution, a large platform for data science, and with Miniconda, a minimal installer containing only Conda, Python, and their dependencies. A community distribution, Miniforge, is configured to use conda-forge by default. Faster alternative implementations of Conda's solver and environment handling, such as mamba and its micro-implementation micromamba, have also been developed and are compatible with Conda packages and environments.

Usage

Conda is widely used in scientific computing, data science, and machine learning, where projects frequently need specific versions of numerical libraries such as NumPy, CUDA toolkits, and R packages. Environments are described in YAML files that can be shared to reproduce a software stack on another machine.
