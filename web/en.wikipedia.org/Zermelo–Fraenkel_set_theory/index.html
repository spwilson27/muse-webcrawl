Zermelo–Fraenkel set theory

Zermelo–Fraenkel set theory, usually abbreviated ZF, or ZFC when the axiom of choice is included, is the standard axiomatic system for set theory and, by extension, the most widely used foundation of mathematics. It was developed in the early 20th century to provide a rigorous basis for set theory free of the paradoxes — such as Russell's paradox — that had undermined naive set theory.

In 1908 Ernst Zermelo published the first axiomatisation of set theory, designed to secure his proof of the well-ordering theorem while blocking paradoxical constructions. In the 1920s Abraham Fraenkel and Thoralf Skolem independently proposed strengthening Zermelo's axiom of separation into the axiom schema of replacement, yielding essentially the modern system. ZFC is formulated in first-order logic with a single binary relation, membership (∈); all mathematical objects are treated as sets.

The axioms

The standard axioms comprise: extensionality, the empty set, pairing, union, power set, infinity, the axiom schema of separation (specification), the axiom schema of replacement, regularity (foundation), and — for ZFC — choice. Regularity implies that every set belongs to the cumulative hierarchy, built by transfinite iteration of the power set operation from the empty set. Most of ordinary mathematics can be formalised within ZFC, and its consistency, while unprovable within the system itself by Gödel's second incompleteness theorem, is widely assumed.

History and variants

Important variants include ZF without choice, ZF with atoms (ZFU), and extensions such as von Neumann–Bernays–Gödel (NBG) and Morse–Kelley set theories, which admit proper classes. Famous statements independent of ZFC include the continuum hypothesis, shown independent by Gödel (1940) and Paul Cohen (1963).
