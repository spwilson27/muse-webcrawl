In machine learning, hyperparameter optimization or tuning is the problem of choosing a set of optimal hyperparameters for a learning algorithm. A hyperparameter is a parameter whose value is used to control the learning process — unlike model parameters, it is set before training begins. Examples include the learning rate of a neural network, the number and depth of trees in a random forest, and the regularisation coefficient of a support-vector machine.

Methods

Grid search exhaustively evaluates a manually specified set of combinations. Random search samples combinations from distributions over the hyperparameters and often performs better than grid search when only a few hyperparameters strongly affect performance. Bayesian optimization builds a probabilistic surrogate model of the objective (e.g. a Gaussian process or tree-structured Parzen estimator) and uses an acquisition function to choose promising points, making it sample-efficient but sequential. Multi-fidelity methods such as Hyperband allocate resources adaptively, terminating unpromising trials early; population-based and evolutionary methods evolve configurations over successive generations.

Considerations

Hyperparameter search is computationally expensive and risks overfitting to the validation set, so nested cross-validation or a held-out test set is recommended for honest evaluation. Automated machine learning (AutoML) frameworks incorporate hyperparameter optimization as a core component.
