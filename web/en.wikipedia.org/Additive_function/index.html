Additive function

In number theory, an additive function is an arithmetic function f(n) of the positive integer variable n such that whenever a and b are coprime, the value of the function applied to the product ab equals the sum of the values at a and b:

f(ab) = f(a) + f(b).

Completely additive functions

An additive function f is said to be completely additive if the relation f(ab) = f(a) + f(b) holds for all positive integers a and b, even when they are not coprime. Every completely additive function is additive, but not conversely.

Examples

  • The function Ω(n), counting the total number of prime factors of n with multiplicity, is completely additive.
  • The function ω(n), counting the distinct prime factors of n, is additive but not completely additive.
  • The logarithm function log n is completely additive when restricted to integer arguments viewed as an arithmetic function.

Properties

Any additive function can be extended using its values on prime powers. Additive functions play a central role in probabilistic number theory: the Turán–Kubilius inequality and the Erdős–Kac theorem describe the distribution of additive functions, showing that many of them behave asymptotically like sums of independent random variables and hence are approximately normally distributed.
