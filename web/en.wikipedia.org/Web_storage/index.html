Web storage

Web storage, sometimes known as DOM storage, is a set of web application software methods and protocols used for storing data in a web browser. Defined by the WHATWG HTML standard, it provides two mechanisms — localStorage and sessionStorage — that let websites store key–value pairs persistently on the client side, as an alternative to HTTP cookies.

Features

Web storage provides a much larger storage space than cookies, typically at least 5 megabytes per origin, and the stored information is not automatically transmitted to the server with every request. The API is synchronous and stores data as strings. sessionStorage persists only for the duration of a page session in a single tab, while localStorage persists across sessions until explicitly cleared. Storage is partitioned by origin under the same-origin policy, so one site cannot read another's data.

Use and concerns

Websites use localStorage for preferences, cached state, form drafts, and offline functionality. Because stored data can be used to track users persistently and survives cookie deletion, privacy regulators treat web storage similarly to cookies for consent purposes. For structured data, developers are encouraged to use IndexedDB instead. All major browsers support web storage.
