Multiple imputation

Multiple imputation
FieldStatistics
Key developerDonald Rubin (proposed 1977, published 1987)
PurposeHandling missing data

Multiple imputation is a statistical technique for analysing incomplete data sets, in which each missing value is replaced not by a single number but by several plausible values, creating multiple completed data sets. Proposed by Donald Rubin in 1977 and fully described in his 1987 book, it avoids the biased estimates and understated uncertainty of single imputation and complete-case analysis.

The procedure has three steps. First, the incomplete data are imputed m times (often 5–40) using a statistical model that draws replacements from the predictive distribution of the missing values given the observed data — commonly implemented through chained equations (MICE) or joint modelling. Second, each completed data set is analysed with the standard method intended for complete data. Third, the results are pooled using Rubin's rules, combining within-imputation and between-imputation variance so that confidence intervals reflect the uncertainty due to missingness.

Assumptions

Multiple imputation is valid under the assumption that data are missing at random (MAR) — that missingness depends only on observed data. It is widely implemented in software including R (mice, Amelia), Stata, SAS and SPSS, and is standard practice in biostatistics, clinical trials and social-science surveys.
