Polynomial-time reduction

In computational complexity theory, a polynomial-time reduction is a method for solving one problem using another. One shows that if a hypothetical subroutine solving the second problem exists, then the first problem can be solved by transforming or reducing it to inputs for the second problem and processing its outputs in polynomial time.

Definition

A reduction from problem A to problem B is an algorithm that transforms instances of A into instances of B such that the answer to the transformed instance determines the answer to the original. If the transformation runs in polynomial time, the reduction is a polynomial-time reduction.

Types

Common varieties include many-one reductions (mapping reductions), in which a single instance is transformed, and Turing reductions, in which the solving algorithm may call the subroutine for the second problem multiple times. Polynomial-time reductions are central to the theory of NP-completeness: a problem is NP-complete if every problem in NP reduces to it in polynomial time and it is itself in NP.

Applications

Reductions are used to prove hardness results throughout theoretical computer science, showing that problems in optimization, graph theory, and logic are at least as hard as known NP-complete problems such as the Boolean satisfiability problem.
