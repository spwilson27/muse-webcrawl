Factor analysis

Factor analysis is a statistical method used to describe variability among observed, correlated variables in terms of a potentially lower number of unobserved variables called factors. For example, it is possible that variations in six observed variables mainly reflect the variations in two unobserved (underlying) variables. Factor analysis searches for such joint variations in response to latent variables, and models each observed variable as a linear combination of the common factors plus a unique error term.

History

The technique originates in psychometrics: Charles Spearman proposed in 1904 that performance on varied mental tests reflected a single general intelligence factor, g. Louis Leon Thurstone later generalised the method to multiple factors, and it became a standard tool in psychology — for instance in developing the Big Five personality model and Cattell's 16 personality factors — and later in marketing, finance and other social sciences.

Methods

Common extraction methods include principal component analysis (often used as an approximation), principal axis factoring and maximum likelihood estimation. The number of factors is chosen using criteria such as eigenvalues greater than one, scree plots, or parallel analysis. Rotations — orthogonal, such as varimax, or oblique, such as promax — are applied to make the factor structure easier to interpret. Exploratory factor analysis lets the structure emerge from the data, while confirmatory factor analysis tests a hypothesised structure, usually within structural equation modelling.

Interpretation

The strength of association between a variable and a factor is expressed as a factor loading. Factor analysis is widely used but also criticised: results can be sensitive to analytic choices, factor names are assigned subjectively, and factors are statistical constructs that should not automatically be reified as real entities.
