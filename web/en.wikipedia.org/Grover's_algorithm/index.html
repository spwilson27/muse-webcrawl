Grover's algorithm

Grover's algorithm is a quantum algorithm for searching an unstructured database or, more generally, for finding the unique input to a black-box function that produces a particular output value. It was devised by Lov Grover in 1996 and provides a quadratic speed-up over classical search.

Description

Classically, searching an unsorted database of N entries requires on the order of N queries. Grover's algorithm finds the marked entry with high probability using only on the order of √N queries of the oracle that recognises the answer. The algorithm works by amplitude amplification: repeated application of the Grover operator — an oracle reflection followed by a diffusion reflection about the average amplitude — rotates the state towards the marked item.

Optimality and applications

The quadratic speed-up was proved optimal for black-box search by Bennett, Bernstein, Brassard and Vazirani in 1997. Grover's algorithm can be applied to speed up a broad range of problems, including collision finding, constraint satisfaction and the search for keys in symmetric cryptography, halving the effective security level of symmetric ciphers in a quantum setting.
