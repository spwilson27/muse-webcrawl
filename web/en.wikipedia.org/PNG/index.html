Portable Network Graphics (PNG, officially pronounced "ping", sometimes pronounced as the letters P-N-G) is a raster-graphics file format that supports lossless data compression. PNG was developed as an improved, non-patented replacement for Graphics Interchange Format (GIF) — unofficially, the initials PNG stood for the recursive acronym "PNG's not GIF".

History and development

The motivation for creating the PNG format came in 1994 and early 1995, after Unisys announced it would enforce the software patent on the LZW compression algorithm used by GIF. Developers working in the comp.graphics newsgroups designed PNG as a patent-free alternative, and the first version of the specification was released on 1 October 1996 as a W3C Recommendation. PNG became an ISO/IEC standard (ISO/IEC 15948) in 2004. In 2025 the specification was updated (third edition) to add support for high-dynamic-range images and the APNG animation extension.

Technical details

A PNG file is organised as an eight-byte signature followed by a series of chunks, each with a type such as IHDR (header), IDAT (image data) and IEND (end). Image data is compressed with the DEFLATE algorithm, preceded by per-scanline filtering to improve compression. PNG supports palette-based images, greyscale and truecolour images, with optional alpha channel transparency, at bit depths of up to 16 bits per channel. Unlike GIF, the base PNG specification does not support animation; the unofficial APNG extension and the separate MNG format addressed this.

Comparison with other formats

PNG generally compresses better than GIF for still images and supports full alpha transparency, which made it the standard choice for web graphics requiring transparency. For photographs, lossy formats such as JPEG usually produce much smaller files. Newer formats such as WebP and AVIF offer both lossy and lossless modes with better compression, but PNG remains universally supported.
