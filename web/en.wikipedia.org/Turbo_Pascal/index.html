Turbo Pascal

Original authorAnders Hejlsberg
DeveloperBorland
First release1983
LanguagePascal
PlatformCP/M, MS-DOS, Windows

Turbo Pascal is a software development system and integrated development environment (IDE) for the Pascal programming language, created by Anders Hejlsberg and marketed by Borland from 1983. Renowned for its extremely fast one-pass compiler and low price, it became one of the best-selling development tools of the personal computer era.

History

Hejlsberg originally developed the compiler in Denmark as "Compas Pascal" before licensing it to Borland, which launched Turbo Pascal in November 1983 at the strikingly low price of US$49.95. Unlike competing compilers that required separate editors and linkers, Turbo Pascal integrated editing, compiling and running in a single program that fit on one floppy disk and compiled code almost entirely in memory.

Development

Successive versions added a windowing IDE, an integrated debugger, object-oriented extensions (Turbo Pascal 5.5, 1989) and support for Windows (Turbo Pascal for Windows, 1991). The final DOS version, Turbo Pascal 7, appeared in 1992. Its object-oriented dialect formed the basis of Object Pascal and Borland's later Delphi environment.

Legacy

Turbo Pascal was enormously influential in education and hobbyist programming, introducing a generation of developers to structured programming and the concept of a fast, friendly IDE.
