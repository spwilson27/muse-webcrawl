Code point

A code point is a value in a coded character set — a numerical position assigned to a character or reserved for future assignment. The collection of all code points in a set is its code space.

Unicode

In Unicode, code points are written in hexadecimal with a "U+" prefix, such as U+0041 for the letter A. The Unicode code space runs from U+0000 to U+10FFFF, divided into 17 planes of 65,536 code points each. Not all code points are assigned to characters: some are reserved, some are noncharacters, and the surrogate range is used only by the UTF-16 encoding.

Code points versus characters

A code point is not identical to a user-perceived character: a single visible character (grapheme) may consist of several code points, such as a base letter plus combining accents, and some code points represent format controls or parts of characters rather than whole glyphs.
