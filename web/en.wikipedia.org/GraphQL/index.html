GraphQL

GraphQL is a data query and manipulation language for APIs, and a runtime for fulfilling those queries with existing data. It was developed internally by Facebook (now Meta) starting in 2012, publicly released as an open-source project in 2015, and moved to the GraphQL Foundation in 2018. GraphQL provides an alternative to REST-style APIs in which clients specify exactly the shape of the data they need.

Design

A GraphQL service defines a schema describing the types available and the fields on each type. Clients send queries naming the fields they want, and the server returns a JSON response mirroring the query structure. This avoids the over-fetching and under-fetching common with fixed REST endpoints. Operations include queries for reading, mutations for writing, and subscriptions for receiving real-time updates.

{
  user(id: "1") {
    name
    friends {
      name
    }
  }
}

Features

GraphQL schemas are strongly typed, enabling validation and tooling such as code generation and interactive explorers. The system is self-documenting through introspection, which lets clients query the schema itself. Because clients control the response shape, a single endpoint can serve web, mobile and other clients with different data needs.

Adoption

GraphQL is used by companies including Meta, GitHub, Shopify, Twitter and Airbnb. Implementations exist in many programming languages, and popular client libraries include Apollo Client and Relay.
