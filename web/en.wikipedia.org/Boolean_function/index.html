Boolean function

Field: Mathematics, computer science

Inputs/outputs: Values from {0, 1}

Number for n variables: 22n

Named after: George Boole

In mathematics and computer science, a Boolean function is a function whose arguments and result take values from a two-element set, usually written {0, 1} or {false, true}. Boolean functions model the behaviour of logic gates and digital circuits: an n-variable Boolean function assigns an output bit to each of the 2n possible input combinations, and can be specified completely by a truth table. There are 22n distinct Boolean functions of n variables.

Representation

Boolean functions are commonly written as formulas built from the basic operations AND, OR, and NOT, or in canonical forms such as disjunctive normal form (a sum of products) and conjunctive normal form. Another algebraic representation, the Zhegalkin or algebraic normal form, expresses the function as a polynomial over the field GF(2) using XOR and AND. Karnaugh maps and binary decision diagrams provide compact visual and computational representations used in circuit minimisation.

Applications

In cryptography, Boolean functions are the building blocks of block-cipher components such as S-boxes and of stream-cipher combining functions; desirable properties include high nonlinearity, balancedness, and resistance to correlation attacks. In complexity theory, Boolean functions and the circuits computing them define central questions such as circuit lower bounds. The analysis of Boolean functions — studying Fourier expansions, influences, and noise sensitivity — has become a field in its own right, with applications from social choice to learning theory. When statistical tests are run on many Boolean features at once, corrections like the Bonferroni correction are applied to the results.
