Strassen algorithm

In linear algebra, the Strassen algorithm, named after Volker Strassen, is an algorithm for matrix multiplication. It is faster than the standard matrix multiplication algorithm for large matrices and is the basis of practical implementations for fast matrix multiplication. Strassen published the algorithm in 1969, the first result showing that the naive O(n³) algorithm was not optimal.

Description

The algorithm divides each matrix into four blocks and computes the product using only seven multiplications of blocks (rather than the eight required by the naive block method), at the cost of extra additions and subtractions. Applied recursively, this gives a running time of O(nlog₂7) ≈ O(n2.807).

For two 2×2 block matrices, the seven products M₁ through M₇ are formed from sums and differences of the blocks; the four blocks of the result are then assembled from these products. Because additions are cheaper than multiplications for large matrices, trading one multiplication for several additions yields a net saving at each level of recursion.

Complexity and practice

Strassen's result opened the study of the matrix multiplication exponent ω; subsequent methods, down to the Coppersmith–Winograd family of algorithms, pushed the exponent below 2.38, though those "galactic" algorithms are impractical. Strassen's algorithm itself is used in practice for matrices above a crossover size (often a few hundred rows), but it has drawbacks: larger constant factors, extra memory for intermediate results, and reduced numerical stability compared with the naive method.
