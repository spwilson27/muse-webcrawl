Page table

Page table
TypeData structure
Used byOperating system / MMU
FunctionMaps virtual pages to physical frames

A page table is a data structure used by a virtual memory system in an operating system to store mappings between virtual addresses and physical addresses. The memory management unit (MMU) consults the page table to translate each virtual address generated by a program into the physical address where the data actually resides.

Structure

Each entry in the page table (PTE) records the frame number of the corresponding page along with control bits: a present/valid bit, a dirty bit recording whether the page has been written, a reference (accessed) bit, and permission bits controlling read, write, and execute access and user/supervisor privilege. If the present bit is clear, an access triggers a page fault, and the operating system loads the page from backing store.

Designs

A flat single-level table for a 32-bit address space with 4 KiB pages would contain a million entries per process, so architectures use hierarchical multi-level page tables — four or five levels on modern x86-64 — in which sparse regions of the address space need no lower-level tables. Alternatives include inverted page tables, keyed by physical frame rather than virtual page, used historically on some IBM and HP systems. Translation lookaside buffers (TLBs) cache recent translations so that the multi-step "page walk" is rarely needed, and large ("huge") pages reduce pressure on both the tables and the TLB.
