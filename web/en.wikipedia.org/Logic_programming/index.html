Logic programming

Logic programming is a programming paradigm based on formal logic. A logic program consists of a set of sentences in logical form, expressing facts and rules about some problem domain; computation is performed by applying an automated theorem-proving or resolution procedure to answer queries.

History

Logic programming grew out of work on automated deduction in the early 1970s. Robert Kowalski at the University of Edinburgh developed the procedural interpretation of Horn clauses, while Alain Colmerauer and colleagues at Marseille created the programming language Prolog, the best-known logic programming language. The paradigm was also adopted as the basis of Japan's Fifth Generation Computer Systems project in the 1980s.

Concepts

A logic program separates logic (what is true) from control (how the proof proceeds). Execution typically proceeds by unification and backtracking search, matching a query against rules and facts. Related paradigms include constraint logic programming and the database query language Datalog.
