Class number problem

The nine imaginary quadratic fields of class number one (Heegner numbers).

In mathematics, the class number problem is the problem of classifying quadratic number fields by their class number — the invariant from algebraic number theory that measures the failure of unique factorisation in the ring of integers of the field. Carl Friedrich Gauss treated special cases in his Disquisitiones Arithmeticae (1801), and complete classification for a given class number proved to be a deep challenge, especially for imaginary quadratic fields.

Imaginary quadratic fields

For imaginary quadratic fields ℑ(√d) with d < 0, Gauss conjectured that only finitely many fields have class number one and listed nine discriminants: d = −1, −2, −3, −7, −11, −19, −43, −67, −163. The completeness of this list was proved independently by Kurt Heegner (1952), Harold Stark (1967) and Alan Baker (1966) — the result is known as the Stark–Heegner theorem, and the nine values |d| are called Heegner numbers. The largest, 163, underlies Ramanujan's near-integer eπ√163.

For class number two, the list of 18 fields was completed through work culminating in Stark's 1975 determination. In general, the complete list for any fixed class number h can in principle be found: work of Goldfeld, Gross and Zagier in the 1980s gave effective lower bounds for class numbers, and Watkins (2004) completed the classification for class numbers up to 100. Nevertheless, an older ineffective proof by Siegel had shown finiteness without giving a computable bound, and effective determination remains computationally demanding as h grows.

Real quadratic fields

For real quadratic fields the situation is strikingly different. Gauss conjectured that infinitely many real quadratic fields have class number one; this remains unproven. Cohen and Lenstra proposed heuristics predicting that about 75% of real quadratic fields ℑ(√p) for primes p ≡ 1 (mod 4) should have class number one, but very little is known rigorously.
