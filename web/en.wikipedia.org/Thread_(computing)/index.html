Thread (computing)

Thread
In: Operating systems, concurrent programming
Unit of: CPU scheduling
Shares: Address space of its process
Standards: POSIX Threads (pthreads)

In computer science, a thread of execution is the smallest sequence of programmed instructions that can be managed independently by a scheduler. Multiple threads can exist within one process, executing concurrently and sharing the process's resources, such as memory, while each maintains its own stack and registers.

Benefits and challenges

Threads allow parallelism on multicore processors, keep user interfaces responsive while work proceeds in the background, and are cheaper to create and switch between than processes. However, shared memory introduces hazards such as race conditions, deadlocks and the need for synchronisation primitives like mutexes and semaphores.

Implementations

Threads may be implemented in user space (green threads) or by the kernel; modern systems such as Linux and Windows schedule kernel threads directly, typically on a one-to-one model. The POSIX Threads API (pthreads) and language-level facilities in Java, C++ and others provide standard programming interfaces.
