TWAIN

Developed byTWAIN Working Group
Initial release1992
TypeApplication programming interface

TWAIN is an application programming interface and communications protocol that regulates communication between software and digital imaging devices, such as image scanners and digital cameras.

Name

The name is officially not an acronym, though a backronym — "Technology Without an Interesting Name" — became famous. The word comes from Kipling's line "never the twain shall meet", reflecting the historical difficulty of connecting scanners and computers.

Architecture

TWAIN works through a data source manager that coordinates applications with device-specific data sources (drivers), transferring images either as files or through native or memory transfers.

Status

Maintained by the TWAIN Working Group since its release by a consortium including Aldus, Caere, Eastman Kodak, Hewlett-Packard, and Logitech, TWAIN remains common in document imaging even as alternatives such as WIA and SANE are used elsewhere.
