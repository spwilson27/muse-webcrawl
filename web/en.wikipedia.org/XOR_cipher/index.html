XOR cipher

OperationBitwise exclusive or (XOR)
KeyRepeating byte string (weak) or one-time pad
Encryptionciphertext = plaintext XOR key
Decryptionplaintext = ciphertext XOR key

In cryptography, the XOR cipher is a simple additive cipher in which each bit or byte of the plaintext is combined with a corresponding bit or byte of a key stream using the exclusive-or (XOR) operation. Because XOR is its own inverse — applying the same operation twice restores the original value — a single algorithm serves for both encryption and decryption.

Operation

If the key is a short string repeated to cover the message, the cipher is a form of polyalphabetic cipher that is trivially broken: an attacker can recover the key length by counting coincidences and then solve each position as a simple substitution. If, however, the key is as long as the message, truly random, and never reused, the result is the one-time pad, which is information-theoretically secure.

Uses

The XOR combination step appears throughout serious cryptography: stream ciphers generate a keystream that is XORed with the plaintext, and block ciphers in modes such as counter mode do the same. XOR ciphers with repeating keys survive mainly in obfuscation and copy-protection schemes, where they provide no real security. The operation is also used in RAID storage (for parity) and in checksums.

Example

Encrypting the letter "A" (0x41) with the key byte 0x2A yields 0x6B; XORing 0x6B with 0x2A again yields 0x41, "A".
