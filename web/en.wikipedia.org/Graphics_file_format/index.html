Graphics file format

A graphics file format is a file format for storing digital images, graphics and related data on a computer system. Graphics formats are generally divided into two families: raster (bitmap) formats, which store an image as a grid of pixels, and vector formats, which store an image as a set of geometric descriptions such as points, lines and curves.

Raster formats

Common raster formats include JPEG, widely used for photographs with lossy compression; PNG, a lossless format supporting transparency; GIF, limited to 256 colours but supporting simple animation; TIFF, common in printing and scanning; and BMP, a simple Windows format. Newer formats such as WebP and AVIF aim to provide better compression than their predecessors.

Vector formats

Vector formats describe images mathematically, so they can be scaled without loss of quality. The standard web format is SVG (Scalable Vector Graphics), an XML-based format. Other vector formats include EPS and PDF for print workflows, and the native formats of illustration programs.

Other categories

Some formats, such as PDF, can contain both raster and vector data. Compound and metafile formats, 3D graphics formats (such as OBJ and STL), and formats storing metadata such as colour profiles and EXIF camera data are also part of the broader family of graphics file formats. Choice of format depends on the balance between image quality, file size, colour depth, transparency and animation support.
