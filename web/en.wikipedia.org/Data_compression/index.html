Data compression

In information theory, data compression, source coding, or bit-rate reduction is the process of encoding information using fewer bits than the original representation. Any particular compression is either lossless or lossy: lossless compression reduces bits by identifying and eliminating statistical redundancy without losing information, while lossy compression additionally discards "unnecessary" or less-important information, achieving far greater reductions for media such as images, audio, and video. Compression is motivated by the cost of storage space and transmission bandwidth.

Theory

Claude Shannon's source coding theorem (1948) sets the limit: the average code length per symbol cannot be less than the entropy of the source for lossless coding. Huffman coding (1952) assigns short codes to frequent symbols; arithmetic coding approaches entropy more closely. Dictionary methods, notably the Lempel–Ziv algorithms (LZ77 and LZ78, 1977–78) and their combination with Huffman coding in DEFLATE, underpin ZIP, gzip, and PNG. The Burrows–Wheeler transform powers bzip2; newer codecs such as zstd and Brotli optimise speed and ratio for modern workloads.

Lossy compression

Lossy schemes use models of human perception: JPEG discards high-frequency detail in images via the discrete cosine transform; MP3 and AAC exploit psychoacoustic masking; video codecs (MPEG, H.264/AVC, HEVC, AV1) combine spatial and temporal prediction with transform coding. Rate–distortion theory formalises the trade-off between bit rate and fidelity.

Applications

Compression is ubiquitous: file archivers, compressed filesystems, streaming media, digital broadcasting, medical imaging, genomic data storage, and network protocols all depend on it. The balance between compression ratio and computational cost shapes algorithm choice — real-time applications favour fast codecs, archives favour maximum reduction.
