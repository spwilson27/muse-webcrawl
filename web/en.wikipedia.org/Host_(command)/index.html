host (command)

host is a simple utility for performing DNS lookups. It is normally used to convert names to IP addresses and vice versa. When no arguments or options are given, host prints a short summary of its command line arguments and options.

Usage

The command is part of the BIND DNS software suite and is available on most Unix-like operating systems. A basic lookup takes the form host hostname, returning A and AAAA records; options allow querying specific record types such as MX or TXT, choosing a particular DNS server, and enabling verbose or TCP-based queries. Related tools include nslookup and dig, the latter providing more detailed diagnostic output.
