vi (text editor)

vi (pronounced "vee-eye") is a screen-oriented text editor originally created for the Unix operating system. It was written by Bill Joy in 1976 at the University of California, Berkeley, as the visual mode of the ex line editor, and shipped with the early Berkeley Software Distribution (BSD) releases. Standardised by POSIX, some implementation of vi or a clone is available on virtually every Unix and Unix-like system.

Design

vi is a modal editor: in normal mode, keystrokes are commands that move the cursor or manipulate text, while in insert mode they enter text. This design suited the slow terminals of the 1970s and allows complex editing with few keystrokes: commands compose an operation (such as d for delete) with a motion (such as w for word), so dw deletes a word. Colon commands give access to the underlying ex editor for search, substitution, and file operations. The placement of the hjkl cursor keys reflects the ADM-3A terminal Joy used, on which those keys bore arrow markings.

Influence and clones

vi became one side of the famous "editor war" with GNU Emacs. Numerous clones and extensions were written, most importantly Vim ("Vi IMproved", 1991), which added syntax highlighting, scripting, and multi-level undo and became the de facto standard vi on Linux systems; Neovim is a modern fork of Vim. Because POSIX requires vi, it remains a dependable fallback editor on servers and minimal systems, and the popular saying that users are "stuck in vi" because they cannot find how to exit (:q!) is a longstanding in-joke.
