The Portable Document Format (PDF) is a file format developed by Adobe in 1992 to present documents, including text formatting and images, in a manner independent of application software, hardware, and operating systems. Each PDF file encapsulates a complete description of a fixed-layout flat document, including the text, fonts, vector graphics, raster images and other information needed to display it.

History

PDF grew out of Adobe's internal "Camelot" project led by John Warnock. It was released in 1993 alongside the Acrobat software; initially proprietary and costly, the reader was made free in 1994, aiding adoption. PDF became an open standard maintained by the International Organization for Standardization (ISO) as ISO 32000 in 2008; PDF 2.0 followed in 2017.

Technical overview

PDF is based on the imaging model of the PostScript language. A PDF file consists of a header, a body of indirect objects (dictionaries, arrays, streams), a cross-reference table or stream, and a trailer. Pages are described by content streams of graphics operators; text is drawn with fonts that may be embedded as subsets. The format supports compression, encryption, digital signatures, fillable forms, annotations, layers, tagged structure for accessibility, and embedded JavaScript. Specialized subsets include PDF/A for archiving, PDF/X for print production and PDF/UA for accessible documents.

Usage

PDF is one of the most widely used document formats worldwide, standard for forms, manuals, scholarly articles, e-books and pre-press exchange. Software for reading PDFs is built into all major operating systems and web browsers, and the print-to-PDF function makes the format a common way to share documents with fixed appearance.

Criticisms

PDF has been criticized for poor text reflow on small screens, historically complex specification, and security vulnerabilities in rich reader features such as JavaScript. Accessibility requires careful tagging of documents at creation time.
