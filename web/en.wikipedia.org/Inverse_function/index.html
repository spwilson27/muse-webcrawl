Inverse function

In mathematics, the inverse of a function f is a function that undoes the operation of f. The inverse of f exists if and only if f is bijective, and if it exists, is denoted by f−1. For a function f: X → Y, its inverse f−1: Y → X admits an explicit description: it sends each element y ∈ Y to the unique element x ∈ X such that f(x) = y.

For example, the multiplication by 3 function and the division by 3 function are mutual inverses. The graph of an inverse function is the reflection of the graph of the original function across the line y = x.

Properties

Composition of a function with its inverse yields the identity: f−1(f(x)) = x and f(f−1(y)) = y. A function has at most one inverse. If f is differentiable and its derivative is nonzero, the derivative of the inverse is the reciprocal of the derivative: (f−1)′(y) = 1 / f′(f−1(y)).

Partial inverses

Many functions that are not bijective have widely used partial inverses defined on restricted domains: the square root is the inverse of squaring restricted to non-negative numbers; the natural logarithm inverts the exponential function; inverse trigonometric functions such as arcsine invert the trigonometric functions on suitable intervals. The notation f−1 resembles but is unrelated to the multiplicative inverse 1/f.
