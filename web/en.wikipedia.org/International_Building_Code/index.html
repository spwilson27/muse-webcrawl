International Building Code

The International Building Code (IBC) is a model building code developed by the International Code Council (ICC) that provides minimum requirements for building systems using prescriptive and performance-related provisions. It has been adopted as a base code throughout the United States.

Scope

The IBC covers structural design, fire protection, means of egress, accessibility, and interior and exterior systems for most building types, while one- and two-family dwellings generally fall under the companion International Residential Code. It is updated on a three-year cycle.

Adoption

States and municipalities adopt the IBC with local amendments, and enforcement falls to local building officials through permitting and inspection. Other ICC codes — covering plumbing, mechanical systems and energy conservation — are designed to work alongside it.
