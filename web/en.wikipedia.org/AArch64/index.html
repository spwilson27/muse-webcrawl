AArch64

AArch64, also known as ARM64, is the 64-bit execution state of the ARM architecture family. It was introduced with the ARMv8-A architecture in 2011 and provides a clean 64-bit instruction set with 31 general-purpose registers, a large virtual address space, and dedicated instructions for cryptography and vector processing.

Features

AArch64 uses a fixed 32-bit instruction encoding like its 32-bit predecessor AArch32, but with a redesigned register file and instruction set. It supports extensions such as NEON SIMD, the Scalable Vector Extension (SVE), and hardware virtualisation. The architecture drops most of the conditional-execution features of 32-bit ARM in favour of simpler branch and conditional-select instructions.

Adoption

AArch64 powers nearly all modern smartphones, Apple's M-series and A-series chips, many servers (such as Amazon's Graviton processors), and embedded systems. Operating systems including Linux, Windows, macOS, Android, and iOS run natively on it.
