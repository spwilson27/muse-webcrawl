Library (computing)

In computer science, a library is a collection of read-only resources that is leveraged during software development to implement a computer program. Historically, a library consisted of subroutines and functions; today the term more broadly covers pre-written code, classes, procedures, configuration data and documentation that programs can reuse rather than reimplement.

Types

Static libraries are combined with a program at compile time by a linker: the needed object code is copied into the executable. Dynamic libraries (shared libraries, such as .dll files on Windows and .so files on Unix-like systems) are loaded at run time and can be shared in memory between many programs, reducing total memory use and allowing the library to be updated independently of the programs that use it.

Linking

When a program invokes a function in a library, the mechanism by which it does so depends on whether the library is static or dynamic. Dynamic linking resolves references when the program is loaded or first run, whereas static linking resolves them at build time. Dynamic linking introduces a dependency: if the library is absent or an incompatible version is present, the program may fail to run — a situation colloquially known as "dependency hell" or, on Windows, "DLL hell".

Examples

Most operating systems provide standard libraries such as the C standard library (libc) and, on Windows, the Windows API libraries. Language ecosystems maintain large public collections: Java's class libraries distributed with the JDK, Python's standard library, and package repositories such as npm for JavaScript and PyPI for Python, which distribute third-party libraries for reuse.
