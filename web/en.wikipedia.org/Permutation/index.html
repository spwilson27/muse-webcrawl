In mathematics, a permutation of a set is, loosely speaking, an arrangement of its members into a sequence or linear order, or, if the set is already ordered, a rearrangement of its elements. More formally, a permutation is a bijective function from a set onto itself. The number of permutations of n distinct objects is n! = n × (n−1) × ⋯ × 1.

Counting

Permutations are distinguished from combinations by the importance of order. The number of ways to choose and arrange k objects from n is the k-permutation count n!/(n−k)!. Permutations with repeated elements are counted by dividing by the factorials of the multiplicities of each repeated element.

Structure

Every permutation decomposes uniquely into disjoint cycles, giving cycle notation. Permutations are classified as even or odd according to the parity of the number of transpositions (pairwise swaps) needed to produce them, a property used to define the alternating group and the sign of a permutation. The set of all permutations of n elements forms the symmetric group Sn, a foundational object in abstract algebra. In computer science, generating permutations is a classic algorithmic problem, addressed by methods such as Heap's algorithm.
