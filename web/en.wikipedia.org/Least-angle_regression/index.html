Least-angle regression

Least-angle regression (LARS)
Field: Statistics / regression analysis
Proposed by: Efron, Hastie, Johnstone, Tibshirani (2004)
Related: LASSO, forward stagewise regression

Least-angle regression (LARS) is a regression algorithm for high-dimensional data developed by Bradley Efron, Trevor Hastie, Iain Johnstone and Robert Tibshirani and published in 2004. It is particularly useful when the number of predictors may exceed the number of observations.

Algorithm

LARS begins with all coefficients at zero and finds the predictor most correlated with the response. It then moves the coefficient in that direction until another predictor becomes equally correlated with the current residual, at which point it proceeds in the direction equiangular between the two predictors — hence "least angle". The process continues, adding one variable at a time and tracing out an entire path of solutions.

Relation to LASSO

With a simple modification, the LARS path coincides with the full solution path of the LASSO, providing an efficient way to compute LASSO fits for all values of the penalty parameter at roughly the cost of a single least-squares fit.
