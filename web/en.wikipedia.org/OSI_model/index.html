The Open Systems Interconnection model (OSI model) is a reference model from the International Organization for Standardization (ISO) that "provides a common basis for the coordination of standards development for the purpose of systems interconnection." It divides a communication system into seven abstraction layers.

The layers

From top to bottom: the Application layer interfaces with software applications; the Presentation layer handles data translation and encryption; the Session layer manages connections; the Transport layer provides end-to-end delivery (as in TCP); the Network layer routes packets (as in IP); the Data link layer handles local frame delivery (as in Ethernet); and the Physical layer transmits raw bits over a medium.

History and use

Work began in the late 1970s, and the model was published as ISO 7498 in 1984. Although the TCP/IP model, with fewer layers, became the practical basis of the Internet, the OSI model remains widely used in teaching and as a vocabulary for describing network protocols.
