STL (file format)

STL is a file format native to the stereolithography CAD software created by 3D Systems. It is widely used for rapid prototyping, 3D printing and computer-aided manufacturing. STL files describe only the surface geometry of a three-dimensional object without any representation of color, texture or other common CAD model attributes.

The name STL is commonly said to derive from "stereolithography", though backronyms such as "Standard Triangle Language" and "Standard Tessellation Language" are also used. The format was introduced in 1987 by Albert Consulting Group for 3D Systems.

Structure

An STL file describes a raw, unstructured triangulated surface by the unit normal and vertices of the triangles, using a three-dimensional Cartesian coordinate system. The surface is tessellated into small triangular facets; each facet is described by a perpendicular direction (the normal) and three points representing the corners of the triangle, ordered according to the right-hand rule.

ASCII and binary encodings

STL files exist in two encodings. ASCII STL files begin with the line solid name and list each facet with facet normal, outer loop and three vertex lines. Binary STL files use an 80-byte header followed by a 32-bit count of triangles and 50 bytes per triangle (normal, three vertices and an attribute byte count).

Use in 3D printing

Because of its simplicity, STL became the de facto standard input for 3D printers and slicing software. Its limitations — no units, no color or material information, and no guarantee of a watertight mesh — have motivated newer formats such as AMF and 3MF.
