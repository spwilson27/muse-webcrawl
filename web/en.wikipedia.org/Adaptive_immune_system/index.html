Adaptive immune system

The adaptive immune system, also known as the acquired immune system, is a subsystem of the immune system composed of specialised cells and processes that eliminate pathogens or prevent their growth. Unlike the innate immune system, it is highly specific to particular antigens, and it creates immunological memory after an initial response, leading to a faster and stronger response to subsequent encounters with the same pathogen. It is found in all jawed vertebrates.

Components

The main cells of the adaptive immune system are lymphocytes: B cells and T cells. B cells mediate humoral immunity by producing antibodies that circulate in blood and lymph, binding antigens and marking them for destruction. T cells mediate cell-mediated immunity: helper T cells coordinate the response by releasing cytokines, while cytotoxic T cells directly kill infected cells.

Antigen recognition

Lymphocytes bear unique antigen receptors generated by random rearrangement of gene segments (V(D)J recombination), creating an enormous repertoire of specificities. When a lymphocyte encounters its matching antigen, presented by antigen-presenting cells or displayed on MHC molecules, it proliferates in a process called clonal selection. Some progeny become long-lived memory cells.

Immunological memory and vaccination

Memory B and T cells persist after an infection clears, so a second exposure produces a faster, larger response. Vaccination exploits this by exposing the system to harmless antigen, establishing memory without disease.
