Mozilla Firefox

Mozilla Firefox, or simply Firefox, is a free and open source web browser developed by the Mozilla Foundation and its subsidiary, the Mozilla Corporation. It uses the Gecko rendering engine to display web pages, which implements current and anticipated web standards. Firefox is available for Windows, macOS, and Linux operating systems, and also for Android and iOS.

History

Firefox was created in 2002 under the code name "Phoenix" by members of the Mozilla community who desired a standalone browser rather than the Mozilla Application Suite bundle. It was renamed Firebird, then Firefox, and released as version 1.0 on November 9, 2004. It grew rapidly in popularity as an alternative to Internet Explorer, peaking at about 32% worldwide usage share in late 2009, before declining as Google Chrome rose to dominance. In November 2017, Firefox Quantum (version 57) introduced a major overhaul of the browser engine with multi-process architecture and a new user interface.

Features

Features include tabbed browsing, spell checking, incremental search, live bookmarking, a download manager, private browsing, and support for extensions. Since version 63, Enhanced Tracking Protection blocks third-party tracking cookies by default in some modes. Firefox is notable as the only major browser not based on Google's Chromium/Blink engine on desktop platforms.
