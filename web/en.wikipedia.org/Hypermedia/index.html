Hypermedia, an extension of the term hypertext, is a nonlinear medium of information that includes graphics, audio, video, plain text and hyperlinks. This designation contrasts with the broader term multimedia, which may include non-interactive linear presentations as well as hypermedia. The term was coined by author and philosopher Ted Nelson in the 1960s, alongside hypertext, as part of his work on the Xanadu project.

History

Early landmark systems include Douglas Engelbart's NLS, demonstrated in the 1968 "Mother of All Demos", and the Aspen Movie Map (1978), which linked video imagery of a town into navigable surrogate travel. Apple's HyperCard (1987) brought hypermedia authoring to personal-computer users, and the World Wide Web, built on HTML, made hypermedia the dominant mode of online information in the 1990s.

In software architecture

In web API design, "hypermedia as the engine of application state" (HATEOAS) is a constraint of the REST architectural style proposed by Roy Fielding: responses include links and forms that tell the client which actions are available next, so clients navigate the application much as a user browses the web. Hypermedia formats in this sense include HTML itself and machine-oriented types such as HAL and Siren.
