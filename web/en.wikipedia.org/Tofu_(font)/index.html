Tofu (font)

Tofu, in typography, is the nickname for the blank or boxed glyphs — typically empty rectangles, or boxes containing an X, a question mark, or a hexadecimal code point — that software displays when a character cannot be rendered because it is missing from the font in use. Technically the replacement is the font's .notdef glyph ("not defined"), which the Unicode standard recommends be shown as an open rectangle. The term derives from the glyphs' resemblance to blocks of tofu, the soybean curd.

Causes

Tofu appears when text contains characters outside a font's repertoire — for example when a document uses emoji, rare scripts or newly encoded Unicode characters on a system whose fonts do not cover them. It can also occur when a web page's intended web font fails to load, or when text is copied between systems with incompatible encodings.

Solutions

Operating systems mitigate tofu through font fallback, automatically substituting characters from other installed fonts. Google's Noto font family — whose name derives from "no tofu" — was created to cover all of Unicode's scripts and eliminate tofu across languages and platforms; Noto fonts are the default on Android and ChromeOS. Emoji tofu is commonly addressed by colour emoji fonts such as Noto Color Emoji.
