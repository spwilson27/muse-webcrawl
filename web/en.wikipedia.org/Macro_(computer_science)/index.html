Macro (computer science)

Macro
Field: Computer programming
Types: Text substitution, procedural, hygienic

In computer programming, a macro (short for macro instruction, from Greek for 'long') is a rule or pattern that specifies how a certain input should be mapped to a replacement output. Applying a macro to an input is known as macro expansion.

Textual macros

The C preprocessor's #define directives are a classic example: macros replace tokens before compilation. M4 and assembly-language macros work similarly at the text level.

Procedural and hygienic macros

Lisp-family languages provide powerful procedural macro systems that manipulate program structure as data; Scheme's hygienic macros prevent accidental variable capture. Keyboard and application macros in software such as spreadsheets likewise automate sequences of commands.
