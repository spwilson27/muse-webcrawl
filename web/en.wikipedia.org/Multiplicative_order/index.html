Multiplicative order


Field: Number theory, group theory
Notation: ordn(a)

In number theory, given an integer a and a positive integer n with gcd(a, n) = 1, the multiplicative order of a modulo n is the smallest positive integer k such that ak ≡ 1 (mod n). It is denoted ordn(a).

Properties

By Euler's theorem, aφ(n) ≡ 1 (mod n), so the multiplicative order of a always divides Euler's totient φ(n); in fact it divides the Carmichael function λ(n), the maximal order. If the order of a is exactly φ(n) (when n is prime, φ(p) = p − 1), then a is called a primitive root modulo n. The concept is the group-theoretic order of the element a in the multiplicative group of integers modulo n.

Example

The powers of 4 modulo 7 are 4, 2, 1, … so ord7(4) = 3, which divides φ(7) = 6. By contrast, 3 is a primitive root modulo 7 with order 6.

Applications

Multiplicative order underlies the analysis of repeating decimal periods, the Diffie–Hellman key exchange and discrete-logarithm cryptography, and the Shor quantum algorithm, which efficiently finds the order of an element.
