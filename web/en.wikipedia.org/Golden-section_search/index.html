Golden-section search

The golden-section search is a technique for finding the extremum (minimum or maximum) of a strictly unimodal function by successively narrowing the range of values inside which the extremum is known to exist. By exploiting the golden ratio, the method is able to reuse one function evaluation at each step, making it highly efficient among methods that do not use derivatives.

Basic idea

Suppose a function f is unimodal on an interval [a, b], meaning it decreases up to a single minimum and then increases. Two interior points c and d are chosen so that the ratios of the subinterval lengths equal the golden ratio φ ≈ 1.618. Comparing f(c) and f(d) tells us on which side of the larger point the minimum cannot lie, so that side is discarded. Because of the golden-ratio spacing, the retained interior point falls exactly at the correct position to serve as one of the two interior points of the new, smaller interval; only one new function evaluation is needed per iteration.

Convergence

Each step shrinks the bracketing interval by a factor of 1/φ ≈ 0.618, so after n iterations the interval length is (b − a)/φn. This gives linear convergence. The method is closely related to the Fibonacci search technique, which is optimal in the number of function evaluations for a fixed budget but requires knowing that budget in advance.

Algorithm

Input: function f, interval [a, b], tolerance τ
φ = (1 + √5) / 2
c = b − (b − a)/φ
d = a + (b − a)/φ
while b − a > τ:
    if f(c) < f(d):
        b = d
    else:
        a = c
    recompute c, d (one may be reused)
return (a + b)/2

Applications

Golden-section search is used in numerical optimization libraries, line searches within larger algorithms, and engineering design problems where function evaluations are expensive and derivatives are unavailable or unreliable.
