Software development

Software development is the process of designing, creating, testing, deploying, and maintaining software. It encompasses activities from requirements analysis and system design through programming, documentation, bug fixing, and ongoing maintenance.

Methodologies

Development has historically followed life-cycle models such as the waterfall model, in which phases proceed sequentially. Iterative and incremental approaches culminated in agile software development, formalised in the 2001 Agile Manifesto, emphasising working software, customer collaboration, and responding to change. Lean development, DevOps, and continuous delivery extend these ideas into operations.

Activities

Key activities include requirements engineering, architectural and detailed design, coding, code review, unit and integration testing, debugging, build automation, release management, and maintenance. Supporting disciplines include project management, quality assurance, and user-experience design.
