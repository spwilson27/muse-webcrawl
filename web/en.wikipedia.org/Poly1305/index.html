Poly1305

Poly1305 is a one-time authenticator designed by Daniel J. Bernstein. It computes a message authentication code using arithmetic modulo the prime 2130 − 5, using a nonce and a secret key, and provides strong authenticity guarantees when each key is used only once.

Poly1305 is widely used combined with the ChaCha20 stream cipher as ChaCha20-Poly1305, an AEAD construction standardized in RFC 8439 and used in TLS 1.3, WireGuard and other protocols. A variant was originally used with AES (Poly1305-AES).
