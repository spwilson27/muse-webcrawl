Backjumping

In constraint programming and satisfiability solving, backjumping is a technique for improving backtracking algorithms by jumping back more than one level when a dead end is reached, rather than simply undoing the most recent assignment.

Principle

When a variable cannot be assigned any value consistent with current assignments, backjumping identifies the deepest earlier variable that is actually in conflict with it — the "culprit" — and returns directly to that variable, skipping intermediate decisions that are irrelevant to the failure.

Variants

Graph-based backjumping, conflict-directed backjumping (CBJ), and backjumping in SAT solvers, where conflict analysis learns new clauses (as in conflict-driven clause learning, CDCL), are widely used refinements.
