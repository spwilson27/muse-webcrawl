Python Software Foundation

The Python Software Foundation (PSF) is an American non-profit corporation that holds the intellectual property rights behind the Python programming language, manages the open-source licensing for Python releases, and supports the Python community. It was launched on 6 March 2001 and is a 501(c)(3) non-profit organisation.

Python Software Foundation
Founded: 6 March 2001
Type: 501(c)(3) non-profit
Purpose: Promote and protect Python
Holds: Python trademarks and IP
Website: python.org

Activities

The PSF owns and helps maintain python.org, funds development through grants to contributors and projects, supports the core development team (including employing developers and a developer-in-residence programme), and runs the PyCon US conference together with a global community of affiliated PyCons. It also sponsors packaging infrastructure such as the Python Package Index (PyPI), which is operated under the PSF umbrella.

Governance

The Foundation is governed by an elected board of directors. Membership classes have evolved over time and include basic members, supporting members, contributing members, fellows (recognised for extraordinary contributions), and sponsor members. Python's creator, Guido van Rossum, served as the language's "Benevolent Dictator for Life" until 2018, after which language governance passed to an elected steering council under PEP 8016.
