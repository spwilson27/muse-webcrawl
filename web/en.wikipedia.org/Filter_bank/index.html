Filter bank

In signal processing, a filter bank is an array of band-pass filters that separates the input signal into multiple components, each one carrying a sub-band of the original signal. One application is the graphic equalizer, which splits audio into frequency bands that can be adjusted independently.

Analysis and synthesis

A filter bank that divides a signal into sub-bands is called an analysis filter bank; the complementary system that recombines the bands is a synthesis filter bank. In a perfect reconstruction filter bank the output of the synthesis stage equals the original signal, a key requirement in sub-band coding.

Applications

Filter banks underlie wavelet transforms, multirate signal processing, audio and image compression (such as the modulated filter banks used in MP3 and JPEG 2000), and digital communications systems such as filter-bank multicarrier modulation.
