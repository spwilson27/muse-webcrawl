DOCTYPE

A document type declaration, or DOCTYPE, is an instruction that associates a particular XML or SGML document (for example, a webpage) with a document type definition (DTD). It appears at the very beginning of the document, before the root element.

Purpose

The DOCTYPE identifies the version and flavor of the markup language used, allowing validators to check the document against the DTD and helping browsers decide how to render the page. In HTML documents, the presence of a standards-mode DOCTYPE historically switched browsers from "quirks mode" into standards-compliant rendering.

Syntax

An HTML 4.01 declaration might read <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN">, while HTML5 simplified the declaration to <!DOCTYPE html>, chosen to be the shortest string that triggers standards mode in browsers.
