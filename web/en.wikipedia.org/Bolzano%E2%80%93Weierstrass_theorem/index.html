Bolzano–Weierstrass theorem

In mathematics, specifically in real analysis, the Bolzano–Weierstrass theorem, named after Bernard Bolzano and Karl Weierstrass, states that each infinite bounded sequence in ℝⁿ has a convergent subsequence.

An equivalent formulation is that a subset of ℝⁿ is sequentially compact if and only if it is closed and bounded — in finite dimensions this matches the Heine–Borel theorem: a set is compact if and only if it is closed and bounded.

History and proof

The theorem was first proved by Bolzano in 1817 as part of his work on the intermediate value theorem, but remained little known until Weierstrass rediscovered it decades later. A standard proof proceeds by successive bisection: a bounded sequence can be enclosed in an interval, then in a half-interval containing infinitely many terms, and so on, producing nested intervals whose lengths shrink to zero and thus a convergent subsequence.

Applications

The theorem underlies fundamental results such as the extreme value theorem argument that a continuous function on a closed bounded interval attains its maximum and minimum, and convergence arguments throughout analysis and economics (for example, existence of equilibria).
