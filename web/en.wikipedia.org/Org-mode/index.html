Org mode (also written Org-mode) is a major mode for the GNU Emacs text editor, used for document authoring, note-taking, project planning, task management and literate programming. It was created in 2003 by Carsten Dominik, who was inspired by notes he kept for himself while working as an astronomer. The name derives from its use for organizing one's life and work.

Org documents are plain-text files with a lightweight markup language that uses asterisks for headline levels, markers such as TODO and DONE for task states, and bracketed links. Because the files are plain text, they can be version-controlled with tools such as Git and edited with any text editor.

Features

Org-mode combines outlining and folding, a to-do list system with priorities, deadlines and scheduling, tables with a built-in spreadsheet, time tracking ("clocking"), and an agenda view that collects tasks from many files. Its export back end converts documents to HTML, LaTeX, PDF, ODT and other formats. Through Org Babel, source code blocks in dozens of languages can be embedded and executed within a document, enabling literate programming and reproducible research.

History

Dominik released the first version in 2003 after finding existing outliners inadequate for his personal planning. Org-mode was incorporated into GNU Emacs starting with Emacs 22.1 (2007). In 2010, Bastien Guerry became the maintainer; he was later succeeded by Nicolas Goaziou, with a team of contributors. The ecosystem has grown to include mobile apps such as Orgzly and beorg, and related systems like denote.
