Free Pascal

Free Pascal (FPC)
Original author: Florian Klämpfl
First released: 1997 (as FPK Pascal, 1993)
Written in: Object Pascal, assembly
Platform: Many CPUs and operating systems
Licence: GPL (compiler), LGPL with exceptions (libraries)

Free Pascal Compiler (FPC) is a free and open-source compiler for the Pascal and Object Pascal programming languages. It supports a wide range of processor architectures — including x86, x86-64, ARM, PowerPC, and SPARC — and operating systems such as Linux, Windows, macOS, and FreeBSD, and can cross-compile between them.

History

The project began in 1993 when Florian Klämpfl, concerned that Borland might discontinue its Pascal products, started writing a 32-bit Pascal compiler, initially called FPK Pascal. Released publicly in 1997 and renamed Free Pascal in 1999, it reached version 1.0 in 2000. Major milestones included version 2.0 (2005) and 3.0 (2015), which added support for generics, anonymous functions, and many new target platforms.

Language and compatibility

FPC aims for compatibility with Borland Pascal, Delphi, and Mac Pascal dialects, selectable through compiler modes. It implements object-oriented extensions of Pascal, interfaces, operator overloading, and a large run-time library mirroring much of Delphi's RTL and the Free Component Library (FCL).

Lazarus

The companion project Lazarus provides a visual integrated development environment and a cross-platform component library (LCL) modelled on Delphi's VCL, enabling rapid application development with native look and feel on many platforms.
