Linux distribution

Hundreds of Linux distributions package the kernel with different software selections and tools.

A Linux distribution (often abbreviated to distro) is an operating system made from a software collection based on the Linux kernel and a package management system. A typical distribution consists of the Linux kernel, GNU tools and libraries, additional software, documentation, a window system, a desktop environment and an installer; most are released as free and open-source software.

History

Linux was created by Linus Torvalds in 1991. Early distributions such as SLS and Slackware (1993) made installation practical, and the mid-1990s saw the rise of Debian, Red Hat and SuSE. Hundreds of distributions now exist, ranging from general-purpose desktop systems to specialised variants for servers, routers, embedded devices, supercomputers and security testing.

Major families

  • Debian family — Debian and its derivatives, including Ubuntu, Linux Mint and Raspberry Pi OS, using .deb packages and APT.
  • Red Hat family — Red Hat Enterprise Linux, Fedora and derivatives such as Rocky Linux and AlmaLinux, using .rpm packages and DNF.
  • Arch family — Arch Linux and derivatives such as Manjaro and EndeavourOS, following a rolling-release model with Pacman.
  • SUSE family — SUSE Linux Enterprise and openSUSE.
  • Independent and source-based — Gentoo, Slackware, Alpine Linux (widely used in containers) and others.

Components and package management

Distributions differ in their package formats and managers, init systems (most now use systemd), default desktop environments (such as GNOME, KDE Plasma and Xfce), release models (fixed-point releases versus rolling releases), and philosophies about free software, documentation and support. Live media allow users to try a distribution from USB or DVD before installing.

Uses

Linux distributions dominate web servers, cloud infrastructure and supercomputers (all of the TOP500 run Linux), power the Android platform on mobile devices, and serve a minority but significant share of desktop computers. Their modularity makes them popular for appliances, single-board computers and containers.
