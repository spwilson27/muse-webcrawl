Branch and bound

[Image placeholder: branch and bound search tree]

Branch and bound (BB, B&B, or BnB) is an algorithm design paradigm for discrete and combinatorial optimization problems, introduced by Ailsa Land and Alison Doig in 1960 for integer programming. It is a general method for finding optimal solutions by systematically enumerating candidate solutions in a search tree while using bounds to discard ("prune") large portions of the tree that provably cannot contain a better solution than the best one found so far.

Method

  1. Branching: A problem is divided into smaller subproblems — for integer programming, typically by selecting a variable that takes a fractional value in the relaxed solution and creating subproblems with that variable fixed to its floor and ceiling values.
  2. Bounding: Each subproblem is solved in a relaxed form (for example, the linear programming relaxation), giving an optimistic bound on the best solution it could contain.
  3. Pruning: A subproblem is discarded if its bound is no better than the current incumbent solution, if its relaxation is infeasible, or if it yields an integer solution — in which case the incumbent may be updated.

The search continues until the tree is exhausted or a tolerance gap between the incumbent and the best bound is met. Worst-case running time remains exponential, but in practice, strong relaxations, cutting planes (leading to branch and cut), and good branching rules make many large problems tractable; modern mixed-integer programming solvers are built on this framework.

Applications

Branch and bound is used for the travelling salesman problem, knapsack problems, scheduling, facility location, protein structure prediction, and exact solutions in operations research generally. Related strategies include branch and price (combined with column generation) and best-first or depth-first node selection policies.
