Weierstrass function

The Weierstrass function is continuous everywhere but differentiable nowhere; magnification reveals structure at every scale.

In mathematics, the Weierstrass function is an example of a real-valued function that is continuous everywhere but differentiable nowhere. It is an example of a fractal curve. It is named after its discoverer Karl Weierstrass.

f(x) = ∑n=0∞ an cos(bn π x),

where 0 < a < 1, b is a positive odd integer, and ab > 1 + 3π/2.

History

The Weierstrass function was published by Weierstrass in 1872 (presented to the Berlin Academy on 18 July 1872), although Bernard Bolzano had constructed a similar example around 1830 that remained unpublished. The example shocked the mathematical community, which widely believed that continuous functions were differentiable except at isolated points. Charles Hermite called such functions a "lamentable plague" that he turned away from "with fright and horror", while Henri Poincaré denounced them as monsters; later generations embraced them as forerunners of fractal geometry.

Properties

The graph of the function has fractal character: it is self-affine, and its Hausdorff dimension is strictly greater than 1 (for typical parameters it equals 2 + log a / log b, as proven in general only in the 21st century). G. H. Hardy proved in 1916 that under weaker parameter conditions (ab ≥ 1) the function is still nowhere differentiable. Nowhere-differentiable functions are in fact typical: in the sense of Baire category, most continuous functions have this property.
