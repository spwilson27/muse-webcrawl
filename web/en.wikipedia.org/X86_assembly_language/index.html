x86 assembly language

x86 assembly language is the family of backward-compatible assembly languages for the Intel 8086 and the x86 family of processors used in most personal computers. It implements the x86 instruction set architecture, giving programmers direct control over registers, memory and hardware. Assembly code is translated into machine code by an assembler such as MASM, NASM or the GNU Assembler.

Syntax

Two syntaxes dominate. Intel syntax writes the destination operand first (mov eax, 1) and is used by MASM and NASM. AT&T syntax, used by the GNU toolchain, reverses operand order, prefixes registers with % and immediate values with $ (movl $1, %eax). Instructions are organised into sections such as .text for code and .data for initialised data.

Registers and modes

The original 8086 provided 16-bit general-purpose registers (AX, BX, CX, DX), segment registers and a flags register. The 80386 extended these to 32 bits (EAX, EBX, …) and introduced protected mode; x86-64 (from 2003) extended them again to 64 bits (RAX, RBX, …), adding registers R8–R15 and largely retiring segmentation. Memory is accessed using addressing modes combining base, index, scale and displacement.

Instructions

Common instruction groups include data movement (MOV, PUSH, POP), arithmetic (ADD, SUB, MUL, DIV, INC), logic (AND, OR, XOR, shifts), control flow (JMP, conditional jumps, CALL, RET, LOOP), string operations, and later extension sets such as MMX, SSE and AVX for SIMD floating-point and vector computation. System interaction occurs through interrupts in real mode, or system calls (SYSCALL/SYSENTER) in modern operating systems.

Usage

Although most software is now written in high-level languages, x86 assembly remains important in operating-system kernels, bootloaders, device drivers, reverse engineering, performance-critical routines and compiler back ends.
