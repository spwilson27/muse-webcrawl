Lossless compression

Lossless compression is a class of data compression that allows the original data to be perfectly reconstructed from the compressed data with no loss of information. Lossless compression is possible because most real-world data exhibits statistical redundancy. By contrast, lossy compression permits reconstruction only of an approximation of the original data, in exchange for improved compression rates.

Lossless data compression is used in many applications, including the ZIP file format and the GNU tool gzip. It is also used in components of other formats: PNG uses lossless compression of images, and audio formats such as FLAC and Apple Lossless compress sound without discarding any samples. It is essential wherever the original and decompressed data must be identical, for example in executable files, text, financial records and medical images.

Theory

Shannon's source coding theorem establishes that the expected code length of a lossless encoding cannot be less than the entropy of the source. A simple counting argument (the pigeonhole principle) shows that no lossless algorithm can compress every possible input: some files must grow. Practical compressors therefore exploit structure — repeated strings, skewed symbol frequencies and predictable patterns — present in real data.

Techniques

Statistical methods

Entropy encoding assigns shorter codewords to more probable symbols. Huffman coding (1952) generates an optimal prefix code for a known symbol distribution, while arithmetic coding represents an entire message as a single fraction, approaching the entropy bound more closely. Modern systems such as zstd and brotli refine these ideas using finite-state entropy coding.

Dictionary methods

The LZ77 and LZ78 algorithms, published by Abraham Lempel and Jacob Ziv in 1977 and 1978, replace repeated substrings with references to earlier occurrences. Phil Katz's DEFLATE combines LZ77 with Huffman coding and underlies ZIP, gzip and PNG. The Lempel–Ziv–Welch (LZW) variant powered early GIF images and the Unix compress utility.

Other methods

  • Run-length encoding stores runs of repeated symbols as a count plus a value; effective for simple graphics and fax images.
  • Burrows–Wheeler transform, used by bzip2, reversibly reorders data to group similar symbols for subsequent encoding.
  • Prediction techniques, such as context mixing in PAQ and the delta filters of PNG, predict each symbol from its context and encode only the error.

Formats and applications

Common lossless formats include ZIP, 7z, gzip, bzip2 and xz for general files; PNG, WebP lossless and TIFF for images; FLAC, ALAC and Monkey's Audio for sound; and losslessly compressed video in professional editing workflows. Cryptographic systems compress before encrypting, since ciphertext is essentially random and incompressible.
