Glossary of graph theory

This glossary of graph theory collects definitions of terms used in the mathematical study of graphs — structures made of vertices (nodes) connected by edges. Graph theory began with Euler's 1736 solution of the Seven Bridges of Königsberg problem and now underpins network science, computer science and combinatorics.

Selected terms

Adjacency
Two vertices are adjacent if connected by an edge; a vertex and an edge are incident if the vertex is an endpoint of the edge.
Bipartite graph
A graph whose vertices can be partitioned into two sets with no edge joining vertices within the same set.
Clique
A set of vertices that are pairwise adjacent; the clique number ω(G) is the size of the largest clique.
Connected
A graph is connected if every pair of vertices is joined by a path. A maximal connected subgraph is a component.
Cycle
A closed walk of length at least three with no repeated vertices (except start/end).
Degree
The number of edges incident to a vertex; a vertex of degree 0 is isolated, of degree 1 a leaf.
Directed graph (digraph)
A graph whose edges have orientations, from a tail to a head.
Eulerian path
A trail using every edge exactly once; exists in a connected graph iff zero or two vertices have odd degree.
Hamiltonian path / cycle
A path or cycle visiting every vertex exactly once.
Independent set
A set of vertices no two of which are adjacent.
Matching
A set of edges no two of which share a vertex.
Planar graph
A graph that can be drawn in the plane without edge crossings; by Kuratowski's theorem, exactly those with no K₅ or K₃,₃ subdivision.
Spanning tree
A subgraph that is a tree containing all vertices of the graph.
Tree
A connected acyclic graph.
Vertex colouring
An assignment of colours to vertices so adjacent vertices differ; the chromatic number χ(G) is the minimum number of colours needed.
