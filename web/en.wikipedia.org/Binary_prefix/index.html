Binary prefix

A binary prefix is a unit prefix for multiples of units in data processing, data transmission and digital information that represents multiplication by a power of 1024 (210). The International Electrotechnical Commission introduced prefixes kibi (Ki), mebi (Mi), gibi (Gi), tebi (Ti), pebi (Pi), exbi (Ei), zebi (Zi) and yobi (Yi) in 1998.

Background

Computer memory is naturally sized in powers of two, so early practitioners borrowed SI prefixes kilo, mega and giga for 1024, 1,048,576 and 1,073,741,824. This conflicted with SI decimal meanings (1000, 1,000,000...) used for disk capacity and data rates, causing confusion and lawsuits over advertised capacity.

Usage

Standards bodies including IEC, ISO and IEEE recommend binary prefixes for power-of-two quantities and SI prefixes strictly for powers of ten. Adoption is mixed: many operating systems report file sizes in binary units but label them with SI symbols, while some (notably macOS) switched to decimal reporting.

Table

1 kibibyte = 1024 bytes; 1 mebibyte = 1024 KiB; 1 gibibyte = 1024 MiB; 1 tebibyte = 1024 GiB, and so on by factors of 1024.
