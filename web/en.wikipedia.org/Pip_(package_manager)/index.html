pip (package manager)

pip is the standard package-management system used to install and manage software packages written in Python. It is included by default with Python installations from version 3.4 onward and installs packages from the Python Package Index (PyPI) and other indexes.

History

pip was created by Ian Bicking and first released in 2008 as pyinstall, a successor to easy_install. Its name is a recursive acronym, "Pip Installs Packages". Development is maintained by the Python Packaging Authority (PyPA).

Usage

Typical commands include pip install <package>, pip uninstall, and pip freeze, which lists installed packages. Requirements files (requirements.txt) record dependencies for reproducible environments, and pip is commonly combined with virtual environments to isolate project dependencies.
