Arithmetic coding

Arithmetic coding (AC) is a form of entropy encoding used in lossless data compression. Unlike Huffman coding, which assigns an integer-length code to each symbol, arithmetic coding encodes an entire message as a single number — a fraction in the interval [0, 1) — allowing it to approach the theoretical entropy limit more closely, especially for symbols with probabilities that are not powers of two.

Principle

The encoder begins with the interval [0, 1) and, for each symbol of the message, subdivides the current interval into subintervals proportional to the estimated probability of each possible symbol, selecting the subinterval corresponding to the actual symbol. As more symbols are processed, the interval shrinks; any number within the final interval uniquely represents the message, and the decoder can reconstruct it by tracking the same subdivisions. Practical implementations use finite-precision integer arithmetic with renormalisation.

Applications

Arithmetic coding and its variants are used in modern compression standards, including the context-based adaptive binary arithmetic coding (CABAC) of the H.264/AVC and HEVC video standards, and in image formats such as JPEG 2000 and JBIG2. Historically, patent issues surrounding arithmetic coding encouraged the development of alternatives such as range coding and asymmetric numeral systems.
