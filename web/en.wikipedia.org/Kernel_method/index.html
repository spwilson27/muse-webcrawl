Kernel method

A kernel maps data into a higher-dimensional feature space where a linear separator exists.

In machine learning, kernel methods are a class of algorithms for pattern analysis whose best-known member is the support vector machine (SVM). The general task is to find and study types of relations in data — classification, regression, clustering, and dimensionality reduction — by implicitly mapping the data into a high-dimensional feature space.

The kernel trick

The central idea is the kernel trick: many algorithms depend on the data only through inner products between pairs of points. By replacing that inner product with a kernel function k(x, y), which computes the inner product in some feature space without ever explicitly constructing the space, linear algorithms can operate as if in a very high- or even infinite-dimensional space at modest computational cost.

Common kernels

Popular kernels include the polynomial kernel, the Gaussian (radial basis function) kernel, and string kernels for text and sequence data. Mercer's theorem guarantees that a valid kernel corresponds to an inner product in some reproducing kernel Hilbert space.

Algorithms

Beyond SVMs, kernel methods include kernel principal component analysis, kernel ridge regression, Gaussian processes, and kernel Fisher discriminant analysis. They were a dominant approach in machine learning through the 1990s and 2000s before large-scale deep learning became common, and remain important for small- and medium-sized datasets.
