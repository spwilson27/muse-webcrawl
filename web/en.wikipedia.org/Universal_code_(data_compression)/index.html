Universal code (data compression)

Codeword lengths of common universal codes grow logarithmically with the encoded integer.

FieldData compression, information theory
Key examplesElias gamma, Elias delta, Elias omega, Fibonacci coding

In data compression, a universal code is a prefix code whose words are assigned to positive integers in such a way that the expected codeword length is within a constant factor of the entropy of any monotonic probability distribution on the integers. Universal codes allow arbitrarily large integers to be encoded without knowing a maximum in advance, and they are a basic tool in lossless compression algorithms.

Definition

A prefix code for the positive integers is universal if, for every non-increasing distribution p on the integers, the ratio of the expected codeword length to the entropy of p is bounded above, approaching 1 as the entropy grows. Equivalently, the length of the codeword for n should grow like log n plus lower-order terms, so that no integer is assigned an extravagantly long codeword.

Examples

  • Elias gamma coding writes n in binary preceded by a unary count of its length; the code is simple but not optimal asymptotically.
  • Elias delta coding encodes the length itself with a gamma code, improving efficiency for large n.
  • Elias omega coding applies the length-encoding idea recursively.
  • Fibonacci coding represents integers in the Zeckendorf system based on Fibonacci numbers; it is robust against certain errors.
  • Exponential-Golomb coding generalizes unary coding with a parameter k.

Applications

Universal codes appear in the Lempel–Ziv compression methods, in image and video standards (Exp-Golomb codes are used in H.264/AVC), and wherever data of unknown range must be encoded compactly and uniquely decodably.
