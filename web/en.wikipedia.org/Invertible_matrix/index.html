Invertible matrix

In linear algebra, an n-by-n square matrix A is called invertible (also nonsingular, nondegenerate, or — rarely used — regular) if there exists an n-by-n square matrix B such that AB = BA = In, where In denotes the n-by-n identity matrix and the multiplication used is ordinary matrix multiplication. If this is the case, then the matrix B is uniquely determined by A, and is called the (multiplicative) inverse of A, denoted by A−1.

Properties

The invertible matrix theorem gives many equivalent conditions: the determinant is nonzero; the matrix has full rank n; its columns are linearly independent and span the space; the linear map it represents is a bijection; zero is not an eigenvalue; and the equation Ax = b has exactly one solution for every b. The set of invertible matrices forms the general linear group GL(n).

For a 2×2 matrix with entries a, b, c, d, the inverse is 1/(ad − bc) times the matrix with entries d, −b, −c, a, provided ad − bc ≠ 0.

Methods of inversion

Gaussian elimination (Gauss–Jordan elimination) computes the inverse by row-reducing the augmented matrix [A | I]. Other methods use the adjugate matrix and determinant (impractical for large matrices), Newton's method, and blockwise decomposition. In numerical computation, explicit inversion is often avoided in favour of solving linear systems directly, which is faster and more stable.
