Principal ideal domain

FieldAbstract algebra; ring theory
AbbreviationPID
DefinitionAn integral domain in which every ideal is principal
HierarchyEuclidean domain ⇒ PID ⇒ UFD ⇒ GCD domain

A principal ideal domain (PID) is an integral domain in which every ideal is principal, that is, generated by a single element. Principal ideal domains are central objects in ring theory because their arithmetic closely parallels that of the integers: every PID is a unique factorisation domain, in which factorisation into irreducible elements is essentially unique.

Examples

The integers Z form the prototypical PID. Every field is trivially a PID, as is any polynomial ring in one variable over a field, such as k[x], and the ring of Gaussian integers Z[i]. Every Euclidean domain is a PID, though not conversely: the ring of integers of Q(√−19) is a classic example of a PID that is not Euclidean. The polynomial ring in two variables k[x, y] is a UFD but not a PID — the ideal generated by x and y is not principal.

Properties

In a PID, an element is prime if and only if it is irreducible, and every non-zero prime ideal is maximal. Finitely generated modules over a PID admit a complete classification (the structure theorem), which generalises both the fundamental theorem of finitely generated abelian groups and the rational canonical form for linear operators.
