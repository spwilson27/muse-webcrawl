DLL Hell

Illustration: DLL Hell

DLL Hell is a term for the complications that arise when working with dynamic-link libraries (DLLs) in Microsoft Windows, particularly the shared system libraries of 16-bit and early 32-bit versions. Problems occur when applications install incompatible versions of a shared library, breaking other programs.

Causes

Installers overwriting newer DLLs with older ones, applications depending on specific buggy versions, and the lack of version enforcement in the system directory led to fragile systems in the Windows 95–98 era.

Solutions

Microsoft addressed the problem with Windows File Protection, side-by-side assemblies (WinSxS) and manifests from Windows XP onward, private application-local DLLs, and the .NET Framework's strong-named Global Assembly Cache, each isolating or versioning shared components.
