Constraint satisfaction problem

Constraint satisfaction problems (CSPs) are mathematical problems defined as a set of objects whose state must simultaneously satisfy a number of constraints or limitations. A CSP is specified by a set of variables, each with a domain of possible values, and a set of constraints specifying allowable combinations of values. A solution is an assignment of a value to every variable that satisfies all constraints.

Examples

Classic examples include map coloring, Sudoku, the eight queens puzzle, Boolean satisfiability (SAT), scheduling, and timetabling. CSPs are a central topic in artificial intelligence and operations research.

Solving

Standard techniques include backtracking search enhanced by constraint propagation — such as arc consistency (AC-3) — variable and value ordering heuristics like minimum remaining values, and local search methods such as min-conflicts. In the general case CSPs are NP-complete, though many structured subclasses are tractable, a fact studied through the theory of constraint satisfaction complexity.
