Multiplicative function

In number theory, a multiplicative function is an arithmetic function f of a positive integer n such that f(1) = 1 and f(ab) = f(a)f(b) whenever a and b are coprime. A function that satisfies the relation for all pairs, coprime or not, is called completely multiplicative. Because of the fundamental theorem of arithmetic, a multiplicative function is completely determined by its values at prime powers.

Examples

Famous multiplicative functions include Euler's totient function φ(n), the Möbius function μ(n), the divisor functions d(n) and σ(n) counting and summing divisors, and Liouville's function λ(n). Completely multiplicative examples include the identity function and the constant function 1. The Dirichlet convolution of two multiplicative functions is again multiplicative, and Möbius inversion is built on this structure.

Applications

Multiplicative functions are central to analytic number theory: their associated Dirichlet series factor into Euler products over the primes, connecting arithmetic properties of integers with the analytic behaviour of functions such as the Riemann zeta function.
