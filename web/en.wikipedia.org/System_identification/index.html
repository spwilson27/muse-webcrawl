System identification

System identification is a methodology for building mathematical models of dynamical systems from measured input and output data, using statistical methods. It complements first-principles modelling when the underlying physics is too complex, partly unknown, or needed only as an input–output description, as in control engineering, signal processing, econometrics, and neuroscience.

Approach

An identification experiment is designed so that the inputs excite the system informatively (persistent excitation); the data are then fitted to a chosen model structure. Common structures range from transfer-function and ARX/ARMAX models, through state-space models fitted by subspace methods (such as N4SID), to nonlinear black-box models including neural networks. Parameters are typically estimated by prediction-error or maximum-likelihood criteria, and the model must be validated on fresh data, for example by residual analysis: a good model's residuals should be white and uncorrelated with the inputs.

History and applications

The field was shaped especially by Lennart Ljung, whose 1977 survey and textbook System Identification: Theory for the User (1987) established its modern form; the astronomer-style observational methods of Karl Åström were another influence. Applications include aircraft flight dynamics, process control in chemical plants, vibration analysis, battery modelling, and building climate models for thermostat control.
