File system

In computing, a file system (also written filesystem) is a method and data structure that an operating system uses to control how data is stored and retrieved on a storage device. A file system organizes data into named files and directories (folders), tracks which blocks of the device hold each file's contents, and maintains metadata such as size, timestamps, ownership, and permissions.

Architecture

File systems divide storage into fixed-size blocks or clusters. Structures such as the File Allocation Table (FAT), inodes (in Unix-style systems like ext4), or the Master File Table (NTFS) map file names to data extents. Journaling file systems (NTFS, ext4, APFS, XFS) log intended changes before applying them, allowing fast, consistent recovery after a crash. Copy-on-write designs (ZFS, Btrfs, APFS) never overwrite live data in place, enabling snapshots, checksumming of all data, and resistance to corruption.

Types

Common disk file systems include FAT32 and exFAT (widely used on removable media), NTFS (Windows), ext4 (Linux), APFS and HFS+ (Apple), and ZFS and Btrfs (advanced Unix/Linux). Network file systems such as NFS and SMB let clients access files stored on servers as if local. Distributed file systems (HDFS, Ceph) spread data across clusters for scale and fault tolerance. Special-purpose virtual file systems (procfs, tmpfs) present kernel information or RAM as files.

Features

Modern file systems may provide access control lists, extended attributes, hard and symbolic links, sparse files, transparent compression and encryption, quotas, snapshots, and deduplication. Limitations differ per design: maximum file size, volume size, file-name length and allowed characters, and case sensitivity.

History

The term derives from paper filing systems; punched-card and tape systems of the 1950s–60s first applied it to digital storage. Hierarchical directories, popularized by Multics and Unix, became the universal model, and file systems remain a foundational layer between block devices and applications.
