Free-software movement

The free-software movement is a social movement with the goal that computer users obtain and retain the freedoms that proprietary software denies them: the freedom to run, study, modify, and share software for any purpose. It holds that these freedoms are a matter of ethics and social solidarity, not merely practical convenience — "free" as in speech, not as in beer.

History

The movement crystallised in 1983, when Richard Stallman announced the GNU Project to build a complete free operating system, and in 1985 he founded the Free Software Foundation and published the GNU Manifesto. The GNU General Public License (GPL), first released in 1989, introduced copyleft: a licensing mechanism using copyright law to guarantee that derivative works remain free. In 1991 Linus Torvalds released the Linux kernel under the GPL, and the combination of GNU tools with the Linux kernel produced widely used free operating systems. In 1998 the term "open source" was promoted as a more business-friendly framing of similar practices, a rebranding the free-software movement regards as overlooking the ethical core of the cause.

The four freedoms

  • Freedom 0: to run the program for any purpose.
  • Freedom 1: to study how the program works and change it (requiring access to source code).
  • Freedom 2: to redistribute copies.
  • Freedom 3: to distribute copies of modified versions.

Free software in the movement's sense underpins much of the modern internet, from the GNU/Linux servers and Apache web server to programming languages and infrastructure tools.
