Interface (computing)


Hardware interfaces are the physical boundaries between devices.

In computing, an interface is a shared boundary across which two or more components of a system exchange information. The term spans hardware interfaces — the plugs, signals and protocols connecting devices, such as USB or a memory bus — and software interfaces, which specify how programs interact. A software interface, such as an application programming interface (API), defines the operations available and their signatures while hiding internal implementation, so that the components on either side can change independently as long as the contract is honoured.

In programming languages

Several object-oriented languages use "interface" in a precise sense: a type consisting only of abstract method signatures (and sometimes constants) that a class may implement. In Java and C#, a class may implement many interfaces but inherit implementation from only one class, a design that enables polymorphism without multiple inheritance. In Go, interfaces are satisfied implicitly by any type having the required methods. Interfaces in this sense define what an object can do, not how.

User interfaces

The boundary between a human and a computer is the user interface: command-line interfaces, graphical user interfaces with windows, icons and pointers, touch interfaces and voice interfaces. Interface design — studied as human–computer interaction — concerns making systems learnable, efficient and forgiving of error. The notion of interface should not be confused with interference, the superposition of waves, despite the similar names.
