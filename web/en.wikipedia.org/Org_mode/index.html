Org mode

Org mode
Original author: Carsten Dominik
First released: 2003
Platform: Emacs
Type: Note-taking, outlining, task management, plain-text markup
License: GNU GPL

Org Mode (also styled Org-mode) is a mode for document editing, formatting and organizing within the Emacs text editor, created by Carsten Dominik in 2003. It is designed for note-taking, maintaining to-do lists, planning projects and authoring documents using a fast and effective plain text system.

Features

Org files are plain text structured as outlines of headlines, which can be folded, moved and given properties, tags, priorities and TODO states. Org mode provides scheduling and deadlines, an agenda view that collects time-stamped items from many files, time tracking, tables with spreadsheet-like formulas, and capture templates for quickly recording notes. Source code blocks can be embedded and executed (org-babel), supporting literate programming and reproducible research.

Export and ecosystem

Documents can be exported to HTML, LaTeX/PDF, Markdown, plain text and many other formats. Because files are plain text, they integrate with version control and other tools; mobile and web implementations exist outside Emacs. Org mode has been a built-in part of GNU Emacs since version 22.1 (2007).
