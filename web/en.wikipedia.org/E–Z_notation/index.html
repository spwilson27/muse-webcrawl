E–Z notation

E–Z notation is a system in stereochemistry for unambiguously describing the configuration of double bonds in molecules, forming part of IUPAC organic nomenclature. The letters derive from the German entgegen ("opposite") and zusammen ("together").

Assignment

Each atom of a double bond carries two substituents, which are ranked by the Cahn–Ingold–Prelog priority rules. If the two higher-priority groups lie on opposite sides of the double bond, the configuration is E; if they lie on the same side, it is Z. For example, in (E)-but-2-ene the higher-priority methyl groups are opposed, while in (Z)-but-2-ene they are on the same side.

Relation to cis–trans

The older cis–trans notation works only when each carbon bears one comparable substituent (such as hydrogen). The E–Z system generalises stereodescription to tri- and tetrasubstituted alkenes, cumulenes and oximes, where cis/trans would be ambiguous.

Multiple double bonds

In molecules with several double bonds, a descriptor is assigned for each bond and included in the name with locants, e.g. (2E,4Z)-hexa-2,4-dienoic acid.
