Network virtualization

In computing, network virtualization is the process of combining hardware and software network resources and network functionality into a single, software-based administrative entity, a virtual network. Network virtualization involves platform virtualization, often combined with resource virtualization.

Overview

Network virtualization is categorized as either internal, providing network-like functionality to the software containers on a single system, or external, combining many networks or parts of networks into a single administrative unit. External network virtualization allows administrators to divide a physical network into multiple isolated virtual networks, or to combine separate networks into one.

Technologies

Related technologies include virtual LANs (VLANs), virtual private networks (VPNs), virtual routing and forwarding (VRF), overlay networks such as VXLAN, and network functions virtualization (NFV), which runs network functions such as firewalls and load balancers as software on commodity hardware. Software-defined networking (SDN) decouples the network control plane from the data plane and is frequently used together with network virtualization in data centers and cloud computing.

Applications

Virtual networks enable multi-tenancy in cloud data centers, network segmentation for security, and rapid provisioning of test and development environments without changes to physical infrastructure.
