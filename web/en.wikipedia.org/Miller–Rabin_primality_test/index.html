Miller–Rabin primality test

The Miller–Rabin primality test is a probabilistic algorithm for determining whether a given number is a probable prime. It was developed from Gary Miller's deterministic test of 1976, which depended on the generalised Riemann hypothesis, and Michael O. Rabin's randomised variant of 1980, which needs no unproved assumptions. The test is widely used in cryptography, where fast primality checking of large integers is essential for generating keys in systems such as RSA.

Concept

The test rests on properties of modular arithmetic related to Fermat's little theorem and the fact that the only square roots of 1 modulo a prime p are ±1. To test an odd integer n, write n − 1 as 2s·d with d odd. A base a is a witness to the compositeness of n if ad is not congruent to 1 mod n and a2rd is not congruent to −1 mod n for any r from 0 to s − 1. If such a witness is found, n is certainly composite. If no witness is found after k independent rounds, n is prime with probability at least 1 − 4−k.

Accuracy and deterministic variants

For random odd composite n, at most one quarter of bases are "liars" that fail to witness compositeness, so a handful of rounds makes the error probability negligible. For numbers below fixed bounds, testing a small predetermined set of bases is provably exact — for example, testing the first twelve prime bases decides primality deterministically for all n below about 3.3 × 1024. These deterministic variants are what most software libraries implement for machine-sized integers.

Applications

Miller–Rabin is the standard primality test in computer algebra systems and cryptographic libraries because, combined with fast modular exponentiation, it runs in polynomial time (roughly O(k log3 n)) while being simple to implement. It is typically paired with trial division by small primes to dispose of easy composites quickly.

Input: n > 2 (odd), k rounds
write n − 1 = 2^s · d with d odd
repeat k times:
    pick random a in [2, n − 2]
    x = a^d mod n
    if x == 1 or x == n − 1: continue
    repeat s − 1 times:
        x = x^2 mod n
        if x == n − 1: break
    otherwise: return "composite"
return "probably prime"
