Web search engine

A search engine returns a ranked list of web pages matching a user's query.

A web search engine is a software system that provides hyperlinks to web pages, and other relevant information on the Web in response to a user's specific query. The user inputs a query in a web browser or a mobile app, and the search results are typically presented as a list of hyperlinks accompanied by textual summaries and images. Users also commonly want to search for other types of information such as maps, images, videos, and news.

How search engines work

Search engines maintain an index of web content built by web crawlers that continuously fetch pages across the Web. The fetched text is analyzed and stored in an inverted index mapping terms to the documents containing them. When a query arrives, ranking algorithms score candidate documents using hundreds of signals — relevance of terms, link structure (famously Google's PageRank), freshness, location, and the user's history — and return results in milliseconds.

History

The first web search tools appeared in 1993–94: W3Catalog, Aliweb, and JumpStation, followed by WebCrawler and Lycos in 1994, AltaVista in 1995, and Yahoo!'s directory. Google, founded in 1998 by Larry Page and Sergey Brin, rose to dominance through the quality of its link-based ranking. Today the market is led by Google, with Microsoft Bing, Baidu (China), Yandex (Russia), and privacy-focused engines such as DuckDuckGo also significant.
