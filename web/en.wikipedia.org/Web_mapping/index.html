Web mapping

Web mapping is the process of using, creating and distributing maps on the World Wide Web. It encompasses everything from static map images published online to interactive, user-driven mapping applications. Web mapping overlaps with web GIS, in which maps serve as interfaces to geographic information systems and spatial databases.

History

Early milestones include the Xerox PARC Map Viewer (1993), one of the first interactive web maps, and MapQuest (1996), which brought route planning to the public. The launch of Google Maps and Google Earth in 2005, with their draggable "slippy map" interfaces and open APIs, transformed web mapping into a mass medium and spawned countless mashups combining maps with other data. OpenStreetMap, founded in 2004, provided a free, editable map of the world built by volunteers, rendered and served through the same tiled architecture.

Technology

Most web maps serve pre-rendered raster tiles at successive zoom levels (the XYZ tile scheme), increasingly supplemented by vector tiles styled in the browser. Standardised services from the Open Geospatial Consortium — such as WMS (map images), WFS (features) and WMTS (tiles) — allow interoperable delivery from map servers like GeoServer and MapServer. Client libraries such as Leaflet, OpenLayers and MapLibre GL handle display and interaction. Mobile mapping apps add positioning, offline tiles and real-time data such as traffic.

Types and uses

Web maps may be analytical (presenting spatial analysis results), animated or real-time (weather radar, vehicle tracking), collaborative (OpenStreetMap, crisis mapping), or embedded as locators and route planners. Applications range across journalism, public health, disaster response, urban planning, logistics and everyday navigation.
