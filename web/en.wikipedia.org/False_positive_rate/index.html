False positive rate

False positive rate (FPR) = FP / (FP + TN)

In statistics, when performing multiple comparisons, a false positive ratio is the probability of falsely rejecting the null hypothesis for a particular test. The false positive rate is calculated as the ratio between the number of negative events wrongly categorised as positive (false positives) and the total number of actual negative events.

Definition

The false positive rate (FPR) is:

FPR = FP / (FP + TN)

where FP is the number of false positives and TN is the number of true negatives. It is equal to 1 − specificity, where specificity (true negative rate) is TN / (FP + TN).

Relation to other measures

The FPR is one axis of a receiver operating characteristic (ROC) curve, plotted against the true positive rate (sensitivity). It should not be confused with the false discovery rate or the false positive risk, which condition on positive results rather than on actual negatives — the source of the so-called base rate fallacy in interpreting positive test results.

Applications

False positive rates are central to evaluating medical screening tests, spam filters, biometric systems and statistical hypothesis testing, where the significance level α of a test is precisely its (per-test) false positive rate.
