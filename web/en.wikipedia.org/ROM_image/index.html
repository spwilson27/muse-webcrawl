ROM image
Type: Computer file (binary copy of ROM data)
Uses: Emulation, preservation, firmware

A ROM image, or ROM file, is a computer file which contains a copy of the data from a read-only memory (ROM) chip. The term is used most often in connection with video game cartridges: a ROM image is a byte-for-byte copy of the software stored in a cartridge's ROM, used to run the game on an emulator or on reproduction hardware.

Creation

ROM images are produced by "dumping": reading the contents of a ROM chip with a hardware device and saving the data to a file. Related formats include disk images (from magnetic or optical media) and tape images. Console ROMs often carry file extensions such as .nes, .smc, or .n64, and some formats include headers added by dumping tools.

Uses and legality

ROM images are used for emulation, archival preservation, fan translation, and ROM hacking. Their distribution is frequently a copyright issue: rights holders generally consider downloading ROMs of commercial games to be infringement, while users sometimes argue that personal backup copies fall within fair use — a position most courts and publishers have not accepted for distribution.
