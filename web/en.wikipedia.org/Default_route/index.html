Default route

A default route forwards packets whose destinations match no more specific route in the routing table.

In computer networking, the default route is a configuration of the Internet Protocol (IP) that establishes the forwarding rule for packets when a more specific route to the destination is not available from the routing table. The default route is generally the address of another router, which treats the packet the same way: if a route matches, the packet is forwarded accordingly; otherwise it is forwarded to the default route of that router. The route evaluation process in each router uses the longest prefix match method to obtain the most specific route.

Notation

The default route in Internet Protocol Version 4 (IPv4) is designated as the zero address, 0.0.0.0/0 in CIDR notation. Similarly, in IPv6, the default route is specified by ::/0. The subnet mask or prefix length of the default route is always the shortest possible — zero bits — so it matches every destination address and is used only when no longer (more specific) prefix matches. The router to which packets are sent along the default route is often called the default gateway, a term especially common for end hosts on a local network.

Uses

Default routes simplify routing configuration on hosts and small networks: a host needs only one route, pointing to its local gateway, rather than an entry for every reachable network. Stub networks in enterprise and ISP routing likewise point a default route toward their provider, while backbone routers participating in the default-free zone must carry a complete routing table and have no default route at all.
