Extract, transform, load

In computing, extract, transform, load (ETL) is a three-phase process in data integration where data is extracted from source systems, transformed to fit operational needs or a target schema, and loaded into an end target such as a data warehouse.

Phases

Extraction reads data from source databases or files. Transformation applies rules such as cleansing, joining, deduplication, and aggregation. Loading writes the result to the destination, either as a full refresh or incrementally.

Alternatives

The ELT variant loads raw data first and transforms it within the target platform, a pattern enabled by scalable cloud warehouses.
