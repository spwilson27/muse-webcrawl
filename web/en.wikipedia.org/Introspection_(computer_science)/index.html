Introspection (computer science)

In computing, introspection (also called type introspection) is the ability of a program to examine the type and properties of an object at runtime. It is a core feature of many object-oriented and dynamic programming languages and is closely related to, but more limited than, reflection.

Definition

Introspection allows code to ask questions about objects: What class does this object belong to? What methods and attributes does it have? Does it support a particular interface? Languages with introspection typically expose operators or built-in functions for these queries. In Python, for example, the functions type(), isinstance(), dir(), and getattr() provide introspective access:

>>> x = [1, 2, 3]
>>> type(x)
<class 'list'>
>>> dir(x)[:3]
['__add__', '__class__', '__contains__']

Introspection vs. reflection

Introspection is the ability to examine program structure at runtime; reflection additionally allows a program to modify its own structure and behavior, such as invoking methods by name, creating objects from class names, or altering classes dynamically. Some languages, such as Ruby and Python, provide both; others, such as Go, provide a reflection library with introspective features. In Java and C#, reflection APIs (for example java.lang.reflect and System.Reflection) supply both examination and manipulation.

Uses

Introspection is used for debugging and development tools, object serialization and persistence, dynamic dispatch and duck typing, dependency injection frameworks, unit-test discovery, plugin architectures, and for generating documentation from code. In statically typed languages with compile-time generics, similar information may instead be available through type systems or metadata embedded in compiled artifacts.

Examples by language

C++ provides limited runtime type information (RTTI) through typeid and dynamic_cast. Objective-C exposes a rich runtime that supports messaging by name. PHP offers a Reflection API with classes such as ReflectionClass. JavaScript supports introspection through typeof, the in operator, and property enumeration. Smalltalk, one of the earliest object-oriented languages, made extensive use of runtime examination of objects.
