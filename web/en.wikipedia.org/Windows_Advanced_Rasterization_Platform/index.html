Windows Advanced Rasterization Platform

[Image: Windows Advanced Rasterization Platform]

Windows Advanced Rasterization Platform (WARP) is a software rasterizer for Direct3D introduced by Microsoft with Windows 7 and DirectX 11. WARP provides a fully conformant Direct3D 10/11 (and later Direct3D 12) implementation that runs entirely on the CPU, allowing applications to render 3D graphics on systems without compatible graphics hardware.

Purpose

WARP serves as a fallback and reference rasterizer: it is used for development, debugging, testing, server-side rendering, and virtual machines or remote-desktop environments where a GPU is unavailable. Because it implements the complete feature set of the Direct3D runtime, it guarantees that applications behave identically, if more slowly, than on hardware.

Performance

Although WARP cannot match dedicated GPUs, it is highly optimised, using SIMD instructions and multithreading to scale across CPU cores, and can outperform low-end integrated graphics of its era on some workloads. In Direct3D 12, WARP devices are created through the IDXGIFactory interface when no hardware adapter is suitable.
