Bounding volume

A bounding volume is a simple closed shape that completely encloses a more complex geometric object or set of objects in computer graphics and computational geometry. Testing an operation against the simple bounding volume first allows expensive operations on the complex geometry to be avoided when the test fails.

Common types

Common bounding volumes include the bounding sphere, the axis-aligned bounding box (AABB), the oriented bounding box (OBB), and capsules and convex hulls. Spheres are cheap to test but fit poorly around elongated objects; boxes fit more tightly but cost more to update when objects rotate. k-DOPs (discrete orientation polytopes) generalize boxes by using more bounding planes.

Uses

Bounding volumes are fundamental to collision detection in games and robotics, ray tracing acceleration, frustum culling in rendering, and spatial data structures. Organizing objects into a bounding volume hierarchy (BVH), in which bounding volumes are nested inside larger ones, allows intersection tests against large scenes to be performed in logarithmic expected time.
