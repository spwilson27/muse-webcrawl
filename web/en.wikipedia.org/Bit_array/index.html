Bit array

A bit array (also known as a bitmask, bit map, bit set, bit string, or bit vector) is an array data structure that compactly stores bits and can be used to implement a simple set data structure. A bit array is effective at exploiting bit-level parallelism in hardware to perform operations quickly. A typical bit array stores kw bits, where w is the number of bits in the unit of storage, such as a byte or word, and k is some nonnegative integer.

Basic operations

Bit arrays support fast operations through bitwise instructions: AND, OR, XOR, and NOT can be applied to entire words at once, making set union, intersection, and difference efficient. Individual bits are set, cleared, and tested by combining a word selection with a mask containing a single set bit. Population count (popcount) instructions allow the number of set bits to be counted quickly.

Applications

Bit arrays are used in priority queues, operating-system structures such as page allocation bitmaps, image processing masks, and Bloom filters. They are also used in the classic sieve of Eratosthenes for finding prime numbers, and as a compact representation of sets whose elements come from a small fixed universe.

Compression

For sparse or clustered bit arrays, run-length encoding and hybrid compressed formats can greatly reduce space while still supporting fast random access and rank/select queries, which are fundamental to succinct data structures.
