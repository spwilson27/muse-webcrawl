Objective-C

From Wikipedia, the free encyclopedia

Objective-C is a high-level general-purpose, object-oriented programming language that adds Smalltalk-style messaging to the C programming language. Originally developed in the early 1980s by Brad Cox and Tom Love at Stepstone, it was the main language used by NeXT for its NeXTSTEP operating system, and subsequently by Apple for macOS and iOS until the introduction of Swift in 2014.

History

NeXT licensed Objective-C in 1988 and built the NeXTSTEP system and its AppKit frameworks upon it. When Apple acquired NeXT in 1996, the technology became the basis of Mac OS X and the Cocoa API. With the launch of the iPhone in 2007 and the App Store in 2008, Objective-C became one of the most widely used languages in the world. Apple announced its successor, Swift, in 2014, though Objective-C remains in use for maintaining large existing codebases.

Syntax and features

Objective-C is a strict superset of C: any valid C code compiles as Objective-C. Object-oriented code uses a distinctive bracket syntax for message sends, e.g. [object messageWithArgument:value]. Classes are declared in interface (@interface) and implementation (@implementation) blocks. The language uses dynamic typing and late binding, with a runtime that supports introspection, categories (methods added to existing classes), and protocols. Memory was historically managed manually or by reference counting; Automatic Reference Counting (ARC) was introduced in 2011.

Influence

Objective-C influenced the design of Java in its early days and shaped the Cocoa frameworks used by millions of applications. See also Swift, Cocoa and NeXT.
