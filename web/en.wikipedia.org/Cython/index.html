Cython

Cython is a programming language and compiler that is a superset of Python, designed to give C-like performance for code written mostly in Python. Cython code is translated into C or C++ and compiled as extension modules that can be imported by Python programs, allowing optional static type declarations to speed up computation-heavy code.

Features

Programmers can annotate variables, function arguments and return values with C types, release the global interpreter lock for parallel threads, and call C libraries directly. Cython also serves as a bridge for wrapping external C and C++ libraries for use from Python. It descends from the earlier Pyrex language, developed by Greg Ewing, and was forked in 2007 by developers associated with the SageMath project.

Uses

Cython is widely used in the scientific Python ecosystem: parts of NumPy, SciPy, pandas and scikit-learn rely on it, as does SageMath itself. Typical speedups for numerical loops range from a few times to orders of magnitude compared with pure Python. Cython 3.0, a major release with improved Python compatibility, appeared in 2023.
