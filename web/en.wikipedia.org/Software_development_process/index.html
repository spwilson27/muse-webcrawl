Software development process

In software engineering, a software development process or software development life cycle (SDLC) is a process used by the software industry to design, develop and test high-quality software. The SDLC aims to produce software that meets or exceeds customer expectations, reaches completion within times and cost estimates. It typically divides work into phases such as requirements analysis, design, implementation, testing, deployment and maintenance.

Phases

  • Planning and requirements analysis — identifying the problem, gathering requirements from stakeholders, and assessing feasibility.
  • Design — specifying architecture, components, interfaces and data.
  • Implementation — writing code according to the design.
  • Testing — verifying that the software works as intended and fixing defects.
  • Deployment and maintenance — releasing the software and continuing to correct, adapt and enhance it.

Methodologies

Waterfall model

The waterfall model, described by Winston Royce in 1970, arranges the phases in a strict linear sequence, each completed before the next begins. It works best when requirements are stable and well understood, but adapts poorly to change.

Iterative and agile methods

Iterative models such as the spiral model repeat the phases in cycles, refining the product with each pass. The 2001 Manifesto for Agile Software Development popularised adaptive approaches — Scrum, Extreme Programming and Kanban among them — emphasising working software, customer collaboration and responding to change over comprehensive documentation and fixed plans.

DevOps

DevOps extends agile ideas into operations, integrating development with deployment through continuous integration, continuous delivery and infrastructure automation, shortening the cycle from commit to production.

Process improvement

Frameworks such as the Capability Maturity Model Integration (CMMI) and the ISO/IEC 12207 standard define reference processes and maturity levels against which organisations benchmark and improve their development practices.
