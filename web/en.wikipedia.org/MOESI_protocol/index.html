MOESI protocol

TypeCache coherency protocol
StatesModified, Owned, Exclusive, Shared, Invalid
ExtendsMESI protocol
Used inAMD Opteron / HyperTransport systems

The MOESI protocol is a full cache coherency protocol used in multiprocessor computer systems to maintain consistency between the caches of different processors and main memory. It is an extension of the simpler MESI protocol, adding a fifth state, Owned, which allows a cache line to be both modified with respect to main memory and shared among several caches, so that the owner cache can supply the data to other caches without writing it back to memory first.

States

Each cache line is in exactly one of five states:

StateMeaning
Modified (M)The line is present only in this cache and is dirty; it differs from main memory, and this cache must write it back before any other cache may read the memory location.
Owned (O)The line is present in this cache and possibly in other caches in the Shared state, and is dirty with respect to main memory. This cache is responsible for supplying the data to requesters and for eventually updating memory.
Exclusive (E)The line is present only in this cache and is clean; it matches main memory.
Shared (S)The line may be present in other caches as well; it may be clean or, when another cache holds it in the Owned state, stale with respect to memory.
Invalid (I)The line is not present or not usable in this cache.

Advantages

In the MESI protocol, when a modified line held by one cache is requested by another, the line generally has to be written back to main memory (or at least pass through a shared level of cache) before the requester can use it. MOESI avoids this traffic: the owning cache transitions from Modified to Owned and forwards the data directly to the requester, which takes the line in the Shared state. This cache-to-cache transfer reduces latency and memory bandwidth consumption, which is particularly valuable in NUMA systems such as AMD's Opteron processors, which used a MOESI variant over the HyperTransport interconnect.

Comparison with other protocols

MOESI is one of a family of snooping and directory-based protocols that includes MSI, MESI, MOSI and MESIF. The Intel-developed MESIF protocol instead adds a "Forward" state designating one shared copy as the designated responder. MOESI's Owned state is somewhat more powerful, because the owner retains responsibility for a dirty line across an arbitrary number of subsequent reads by other caches.
