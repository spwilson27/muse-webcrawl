Intelligent agent

In artificial intelligence, an intelligent agent (IA) is an entity that perceives its environment through sensors (producing percepts), acts upon that environment through actuators, and directs its activity toward achieving goals. This agent-centred framing, popularised by Stuart Russell and Peter Norvig's textbook Artificial Intelligence: A Modern Approach, treats many AI systems — robots, software programs, thermostats in the loosest sense — as agents whose behaviour can be described by an agent function mapping percept sequences to actions.

Rational agents

A rational agent is one that acts so as to maximise the expected value of a performance measure, given the percept sequence it has observed and its built-in knowledge. Rationality is distinct from omniscience: an agent acts on the information it has, not on information it cannot perceive. The task environment can be characterised along dimensions such as observable versus partially observable, deterministic versus stochastic, episodic versus sequential, static versus dynamic, and discrete versus continuous.

Agent architectures

Standard agent types of increasing sophistication include: simple reflex agents, which act only on the current percept using condition–action rules; model-based reflex agents, which maintain an internal state tracking aspects of the world not currently visible; goal-based agents, which choose actions by considering which lead to goal states; utility-based agents, which maximise a utility function over states; and learning agents, which improve their components from experience. Multi-agent systems study populations of interacting agents.

Applications and related notions

Intelligent agents are studied in robotics, game playing, automated planning, recommender and trading software, and autonomous vehicles. The concept connects AI to economics (rational agency and game theory) and cognitive science. In the 2020s the term "AI agent" gained prominence for systems built on large language models that can plan, use tools and execute multi-step tasks with limited supervision, reviving classic agent properties — autonomy, reactivity, pro-activeness and social ability — identified in early agent-oriented software engineering.
