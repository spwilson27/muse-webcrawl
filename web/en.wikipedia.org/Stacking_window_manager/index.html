Stacking window manager

A stacking window manager (also called floating window manager) is a window manager that draws all windows in a specific order, allowing them to overlap, using a technique called painter's algorithm. All window managers that allow the overlapping of windows and are not compositing window managers are considered stacking window managers, although it is possible that not all use exactly the same methods. Other window managers that are not considered stacking window managers are those that do not allow overlapping of windows, which are called tiling window managers.

Operation

A stacking window manager renders windows in a z-order, from bottom to top, so that the window at the top of the stack appears fully and windows beneath it are partly obscured where they overlap. The user can freely move and resize windows with the mouse, and raise a window to the top by clicking it or selecting it from a taskbar or window list. The metaphor is that of papers lying on a desk.

Examples

Classic examples include the window managers of Microsoft Windows (through its history), macOS's Aqua environment, and many X Window System window managers such as Openbox, Fluxbox, twm, Metacity and KWin (when not compositing). The Xerox Alto and early graphical environments established the overlapping-window paradigm that stacking managers embody. Modern compositing window managers generally retain the stacking model for window placement while rendering each window to its own off-screen buffer.
