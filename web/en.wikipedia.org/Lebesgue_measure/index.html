Lebesgue measure

In measure theory, a branch of mathematics, the Lebesgue measure, named after French mathematician Henri Lebesgue, is the standard way of assigning a measure to subsets of higher dimensional Euclidean n-spaces. For lower dimensions n = 1, 2, or 3, it coincides with the standard notions of length, area, and volume.


Approximating a set by countable covers of intervals

Definition

On the real line, the Lebesgue outer measure of a set is defined as the infimum of the total length of countable collections of open intervals covering the set. A set is Lebesgue measurable if it satisfies the Carathéodory criterion, splitting every test set additively. Intervals have measure equal to their length, and the measure is translation-invariant and countably additive.

Properties

Every interval, open set, closed set, and Borel set is Lebesgue measurable. Any set of outer measure zero (such as a single point or a countable set) is measurable. However, assuming the axiom of choice, there exist non-measurable sets, such as the Vitali set. The Lebesgue measure is complete: subsets of null sets are measurable.

Applications

Lebesgue measure underpins the Lebesgue integral, which generalizes the Riemann integral and is fundamental to real analysis, probability theory, and functional analysis.
