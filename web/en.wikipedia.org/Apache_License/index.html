The Apache License is a permissive free software license written by the Apache Software Foundation (ASF). It allows users to use, modify and distribute software for any purpose, including commercial use, without requiring derivative works to be distributed under the same license. Software under the Apache License may therefore be incorporated into proprietary products.

Terms

The license requires preservation of the copyright notice and disclaimer in redistributions, and it includes an express grant of patent rights from contributors: anyone who contributes to a work grants users a patent license covering their contributions, which terminates if the user brings patent litigation over the work. Unlike some permissive licenses, the Apache License does not grant trademark rights. Modified files must carry prominent notices stating that they were changed.

History and versions

Version 1.0 accompanied the Apache HTTP Server in 1995 and included an advertising clause similar to the original BSD license; version 1.1 (2000) removed that clause. Apache License 2.0, released in January 2004, clarified the patent grant and retaliation clause and was made usable by projects outside the ASF. The Free Software Foundation considers 2.0 a free software license compatible with version 3 of the GNU GPL (but not GPLv2, owing to the patent clauses).

Adoption

The Apache License is among the most widely used open-source licenses, applied to projects such as the Apache HTTP Server, Hadoop, Spark, Kubernetes, TensorFlow, Swift, and the Android Open Source Project's userspace components.
