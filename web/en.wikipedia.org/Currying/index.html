Currying

In mathematics and computer science, currying is the technique of translating a function that takes multiple arguments into a sequence of functions, each taking a single argument. It is named after logician Haskell Curry, though the idea was introduced earlier by Moses Schönfinkel and Gottlob Frege.

Currying
Field: Functional programming, logic
Named after: Haskell Curry
Related: Partial application, lambda calculus

Concept

A function f(x, y) can be curried into a function that takes x and returns a new function that takes y and produces the result. In lambda calculus all functions formally take one argument, so currying is the natural representation. For example, an addition function add(x, y) becomes add(x) returning a function that adds x to its argument.

Use in programming

Functional languages such as Haskell curry functions by default, enabling concise partial application and function composition. In languages like JavaScript, Scala, and ML, currying supports reusable, specialised functions — for instance, fixing a configuration argument to produce a family of related functions.

Currying vs partial application

Currying always decomposes a multi-argument function into unary functions, whereas partial application fixes some arguments of a function of any remaining arity. The two are related but not identical.
