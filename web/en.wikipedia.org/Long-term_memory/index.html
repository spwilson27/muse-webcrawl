Long-term memory

The modal model of memory

Long-term memory (LTM) is the stage of the Atkinson–Shiffrin memory model in which informative knowledge is held indefinitely. It contrasts with short-term and working memory, which hold limited amounts of information for seconds to minutes. Long-term memory is encoded in the hippocampus and gradually consolidated into the cerebral cortex, particularly during sleep.

Types

Psychologists divide long-term memory into two major systems. Explicit (declarative) memory covers facts and events that can be consciously recalled: episodic memory (personal experiences) and semantic memory (general knowledge). Implicit (procedural) memory covers skills and conditioned responses, such as riding a bicycle, that are expressed in performance without conscious recollection. The distinction was supported by studies of amnesic patients such as H.M., who could learn new skills while unable to form new declarative memories.

Encoding and consolidation

Information reaches long-term memory through elaborative encoding — connecting new material to existing knowledge — and is strengthened by rehearsal, emotional salience and retrieval practice (the testing effect). Systems consolidation transfers memories from hippocampal to neocortical storage over days to years, while synaptic consolidation stabilises traces within hours of learning. Forgetting results from decay, interference and retrieval failure, and memories are modified each time they are recalled (reconsolidation).
