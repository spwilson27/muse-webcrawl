Porter–Duff compositing

In computer graphics, Porter–Duff compositing (also called the Porter–Duff operators) is a family of binary operations for combining two images using their alpha channels. It was described by Thomas Porter and Tom Duff in their landmark 1984 SIGGRAPH paper "Compositing Digital Images," written while both were at Lucasfilm.

The algebra

Porter and Duff treated images as having an alpha value at each pixel describing coverage, and premultiplied colour by alpha. Given a source and a destination image, the compositing operators are defined by how the source and destination contributions are weighted by the two alpha values. The twelve operators include clear, src, dst, src-over, dst-over, src-in, dst-in, src-out, dst-out, src-atop, dst-atop, and xor.

The most familiar is over: the source is composited on top of the destination, each pixel's result being C = Cs + Cd(1 − αs) with premultiplied colours — the standard operation used whenever translucent layers are drawn over one another.

Influence

The Porter–Duff model underlies essentially all modern 2D rendering: window systems, web browsers (CSS compositing and Canvas), PDF transparency, and graphics APIs such as Cairo, Skia, and Java 2D all implement its operators.
