Axiomatic semantics

Axiomatic semantics is an approach based on mathematical logic for proving the correctness of computer programs. It is closely related to Hoare logic.

Overview

Axiomatic semantics define the meaning of a command in a program by describing its effect on assertions about the program state. Statements are typically expressed as Hoare triples of the form {P} C {Q}, where P is a precondition, C a command, and Q a postcondition: if P holds before C executes, then Q holds afterwards.

History

The approach grew out of Robert W. Floyd's 1967 work on assigning meanings to programs and C. A. R. Hoare's 1969 paper "An axiomatic basis for computer programming", which introduced rules for assignment, sequencing, conditionals, and loops (using loop invariants). Edsger W. Dijkstra's weakest-precondition calculus (guarded commands, 1976) developed the idea into a program derivation method. Axiomatic semantics contrast with denotational and operational semantics, and underlie modern program verification tools.
