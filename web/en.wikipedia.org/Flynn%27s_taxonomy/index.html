Flynn's taxonomy

Flynn's taxonomy is a classification of computer architectures proposed by Michael J. Flynn in 1966. It distinguishes computers according to whether they operate on single or multiple instruction streams and single or multiple data streams, yielding four categories: SISD, SIMD, MISD, and MIMD.

Categories

SISD (single instruction, single data) is the conventional sequential computer, executing one instruction stream on one data stream. SIMD (single instruction, multiple data) applies the same operation simultaneously to many data elements — the model of vector processors and modern graphics processing units. MISD (multiple instruction, single data) is rare, sometimes associated with fault-tolerant systems applying different operations to the same data for redundancy. MIMD (multiple instruction, multiple data) covers multiprocessors and multicore machines running independent instruction streams on independent data.

Refinements

Because the four classes are coarse, later authors subdivided MIMD into shared-memory and distributed-memory systems and into SPMD (single program, multiple data) programming styles. Flynn himself later proposed extensions to better describe pipelines and modern accelerators.

Legacy

Despite its age, the taxonomy remains the standard introductory framework for describing parallelism in computer architecture courses and literature.
