Direct3D

Direct3D powers real-time 3D graphics on Windows and Xbox.
DeveloperMicrosoft
Initial release1996 (DirectX 2.0)
PlatformWindows, Xbox
Type3D graphics API

Direct3D is a graphics application programming interface (API) for Microsoft Windows and Xbox, part of Microsoft's DirectX API collection. Direct3D is used to render three-dimensional graphics in applications where performance is important, most notably video games, and provides hardware acceleration of the 3D rendering pipeline when supported by a graphics processing unit (GPU).

History

Microsoft acquired RenderMorphics and its Reality Lab API in 1995, which became the basis of Direct3D, first shipped in 1996. Early versions competed with the cross-platform OpenGL and with proprietary APIs such as 3dfx's Glide. Direct3D 7 introduced hardware transform and lighting; Direct3D 8 unified vertex and pixel shaders in a programmable pipeline; Direct3D 9 (2002) became a long-lived standard for PC gaming. Direct3D 10 (2006, Windows Vista) redesigned the API around a uniform shader model, Direct3D 11 (2009) added tessellation and compute shaders, and Direct3D 12 (2015) moved to a low-overhead, explicit model giving developers closer control over GPU resources, later extended by DirectX 12 Ultimate with ray tracing and mesh shaders.

Architecture

Direct3D applications submit geometry, textures, and shader programs to the API; shaders are written in Microsoft's High-Level Shader Language (HLSL) and compiled to an intermediate bytecode executed by the driver on the GPU. The rendering pipeline proceeds through vertex processing, rasterization, and pixel (fragment) processing, with programmable stages at several points. Direct3D 12 exposes concepts such as command lists and queues, descriptor heaps, and explicit resource state management.

Competition

Direct3D's principal rivals have included OpenGL, and more recently the low-level cross-platform Vulkan API and Apple's Metal. On Windows and Xbox, Direct3D remains the dominant graphics API for commercial game development.
