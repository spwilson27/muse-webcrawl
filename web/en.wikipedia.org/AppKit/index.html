PurposeGraphical user interfaces for macOS applications

AppKit, formally the Application Kit, is the graphical user interface toolkit for macOS applications. Together with Foundation it forms the Cocoa application programming interface. AppKit originated in NeXTSTEP in the late 1980s and provides the windows, views, controls, menus, and event-handling classes from which Mac applications are built.

Contents and architecture

AppKit classes, most prefixed NS after NeXTStep, include NSApplication, NSWindow, NSView, and the standard controls such as NSButton, NSTextField, and NSTableView, together with drawing support built on Quartz. Interface layouts are often defined in Interface Builder and stored in nib or storyboard files, connected to code through outlets and actions. AppKit implements the responder chain for event routing and follows model–view–controller patterns.

History and successors

After Apple acquired NeXT in 1997, AppKit became the native toolkit of Mac OS X and later macOS. Newer frameworks such as SwiftUI (2019) and Mac Catalyst now offer alternative routes to Mac interfaces, but AppKit remains the underlying foundation and is still used directly by most traditional Mac applications.
