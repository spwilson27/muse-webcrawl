Internet Group Management Protocol

Internet Group Management Protocol
AbbreviationIGMP
PurposeManaging multicast group membership on IPv4 networks
LayerNetwork (part of the IP multicast architecture)
StandardsRFC 1112 (v1), RFC 2236 (v2), RFC 3376 (v3)

The Internet Group Management Protocol (IGMP) is a communications protocol used by hosts and adjacent routers on IPv4 networks to establish multicast group memberships. IGMP is an integral part of IP multicast and allows a host to inform its local router that it wishes to receive traffic addressed to a particular multicast group.

Operation

Multicast routers periodically send IGMP membership query messages to discover which groups have members on their attached networks. Hosts respond with membership report messages for the groups they have joined. When a host no longer wishes to receive a group, IGMPv2 allows it to send a leave group message, allowing the router to prune the group from the network more quickly.

On switches, IGMP snooping allows a layer-2 switch to listen to IGMP exchanges and forward multicast traffic only to ports with interested receivers, rather than flooding it to all ports.

Versions

  • IGMPv1 (RFC 1112, 1989) — original membership reporting; routers infer departure from the absence of reports.
  • IGMPv2 (RFC 2236, 1997) — added explicit leave messages and group-specific queries.
  • IGMPv3 (RFC 3376, 2002) — added source-specific multicast support, letting hosts request traffic from (or exclude) specific sources within a group.

The IPv6 equivalent of IGMP is Multicast Listener Discovery (MLD), which is integrated into ICMPv6.
