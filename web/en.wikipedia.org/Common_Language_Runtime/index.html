The Common Language Runtime (CLR) is the virtual machine component of Microsoft's .NET platform. It manages the execution of programs written in .NET languages such as C#, F#, and Visual Basic .NET, providing services including memory management, type safety, exception handling, garbage collection, security, and thread management.

Compilation to CIL and just-in-time execution by the CLR

How it works

Compilers for .NET languages translate source code into Common Intermediate Language (CIL) bytecode, packaged in assemblies with metadata. At runtime, the CLR's just-in-time (JIT) compiler converts CIL into native machine code method by method, caching the results. Because all languages compile to the same intermediate form and share a Common Type System, code written in different .NET languages can interoperate seamlessly.

Key features

  • Garbage collection — automatic, generational memory management that relieves developers of manual allocation bookkeeping.
  • Type safety and verification — code is verified for memory safety before execution, enabling sandboxed scenarios.
  • Exception handling — a unified model across languages.
  • Code Access Security and app domains — (in .NET Framework) isolation boundaries within a process.
  • Interoperability — access to native code via P/Invoke and COM interop.

Implementations

The original CLR ships with the Windows-only .NET Framework. Microsoft later developed the cross-platform CoreCLR for .NET Core (now simply .NET), which is open source and runs on Windows, Linux, and macOS. Other implementations include Mono (used by Xamarin and Unity) and the .NET Micro Framework for embedded devices.
