DCI-P3 is a color space or set of RGB primaries first defined in 2005 by Digital Cinema Initiatives (DCI) for digital cinema projection. It specifies a gamut substantially wider than the sRGB space used for ordinary displays, covering more saturated reds and greens, with a monochromatic green primary near 532 nm. Theatrical DCI-P3 uses a distinctive white point (approximately 6300 K, slightly greenish compared with D65) and a gamma of 2.6, with the X'Y'Z' encoding used in digital cinema packages.

Display P3

Display P3 is a variant created by Apple, standardised with the same red, green, and blue primaries as DCI-P3 but using the D65 white point, an sRGB-like gamma curve, and sRGB transfer characteristics for use in consumer displays. Introduced with the iMac with Retina 5K display in 2015 and subsequently adopted across Apple's phones, tablets, and laptops, Display P3 was promoted in Android devices as "wide colour" and is supported by modern web standards through CSS Color 4 media queries such as (color-gamut: p3).

Use in HDR

The UHD Alliance and ITU-R Recommendation BT.2020 define an even wider gamut for ultra-high-definition television; consumer HDR content (HDR10, Dolby Vision) is typically mastered in a container of BT.2020 primaries with actual colour content graded to the DCI-P3 gamut — commonly described as "P3-D65" in a BT.2020 container.
