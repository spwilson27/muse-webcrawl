Neighbor Discovery Protocol

The Neighbor Discovery Protocol (NDP), defined in RFC 4861, is a protocol in the Internet protocol suite used with IPv6. It performs functions that in IPv4 were handled by ARP, ICMP router discovery, and ICMP redirect, combining them into a single protocol operating over ICMPv6.

Functions

NDP allows hosts on the same link to discover one another's link-layer (MAC) addresses through Neighbor Solicitation and Neighbor Advertisement messages; to find routers; to learn network prefixes for Stateless Address Autoconfiguration (SLAAC); and to detect duplicate addresses and unreachable neighbors. Routers send Router Advertisement messages announcing prefixes and configuration flags.

Security

Because unauthenticated NDP messages can be spoofed to redirect traffic, extensions such as Secure Neighbor Discovery (SEND, RFC 3971) use cryptographically generated addresses. In practice, first-hop security features on switches, such as RA-Guard, are more commonly deployed.
