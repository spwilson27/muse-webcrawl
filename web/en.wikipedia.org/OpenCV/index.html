OpenCV (Open Source Computer Vision Library) is a library of programming functions mainly for real-time computer vision. Originally developed by Intel, it was later supported by Willow Garage and is now maintained by the OpenCV Foundation. The library is cross-platform and free for use under the Apache 2 licence.

OpenCV is used for tasks such as face detection and object tracking.

History

OpenCV was built to provide a common infrastructure for computer vision applications and to accelerate the use of machine perception in commercial products. Intel announced the first alpha release in January 1999 and released a beta at the IEEE Conference on Computer Vision and Pattern Recognition in 2000. Version 1.0 followed in 2006, OpenCV 2 in 2009, OpenCV 3 in 2015 and OpenCV 4 in 2018.

Features

The library contains more than 2,500 optimised algorithms, spanning classic and modern computer vision and machine learning: image filtering, feature detection and description (such as SIFT and ORB), object detection including face detection with Haar cascades, camera calibration, stereo vision, optical flow, video analysis, and a deep neural network (DNN) module that can run models from frameworks such as TensorFlow, PyTorch and Caffe. Many functions are hardware-accelerated using SIMD instructions, CUDA and OpenCL.

Applications and interfaces

OpenCV is written natively in C++ and provides interfaces for Python, Java and MATLAB, with community wrappers for many other languages. It is used in applications ranging from interactive art and robotics to surveillance, inspection on factory production lines, augmented reality and the stitching of street-view imagery.
