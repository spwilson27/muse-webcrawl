Page description language

In digital printing, a page description language (PDL) is a computer language that describes the appearance of a printed page in a higher level than an actual output bitmap (or generally raster graphics). An overlapping term is page description format (PDF), though PDF is a specific format. A page description language specifies the arrangement of text, images, and vector graphics on a page independently of the output device, so that the same description can be rendered on a low-resolution screen or a high-resolution imagesetter.

Notable languages

The most influential PDL is PostScript, developed by Adobe Systems and introduced with the Apple LaserWriter in 1985; it is a full programming language whose imaging model also underlies PDF. Hewlett-Packard's Printer Command Language (PCL) is widely used in office printers and ranges from simple escape sequences to the vector-capable PCL 6. Other examples include Xerox's Interpress, the ancestor of PostScript's imaging model, Microsoft's XML Paper Specification (XPS / OpenXPS), and SVG, an XML-based vector format used on the web that functions as a page description language for single images and documents.

How it works

A document or print job is translated by a driver into PDL commands, which are interpreted by a raster image processor (RIP) in the printer or in software. The interpreter executes drawing operations — placing glyphs from fonts, stroking and filling paths, and compositing images — at the device's native resolution, giving consistent output across devices at the cost of more processing in the printer.
