Directed acyclic graph

In mathematics, particularly graph theory, and computer science, a directed acyclic graph (DAG) is a directed graph with no directed cycles: it consists of vertices and directed edges, each edge connecting one vertex to another, such that there is no way to start at some vertex and follow a sequence of edges that eventually loops back to that same vertex.

Properties

Every DAG has a topological ordering, an arrangement of its vertices such that every edge points from earlier to later in the ordering. Reachability in a DAG defines a partial order on its vertices. The transitive closure and transitive reduction of a DAG are uniquely defined.

Applications

DAGs model processes with dependencies: project scheduling (such as PERT charts), build systems and spreadsheets, version histories in systems like Git, citation networks, Bayesian networks, and the structure of expressions in compilers. Dynamic programming over DAGs solves shortest and longest path problems in linear time relative to the graph size.
