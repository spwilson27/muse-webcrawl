Complex instruction set computer

CISC architectures feature rich, variable-length instruction sets

A complex instruction set computer (CISC) is a computer architecture in which single instructions can execute several low-level operations (such as a load from memory, an arithmetic operation, and a memory store) or are capable of multi-step operations or addressing modes within single instructions. The term was coined retroactively in contrast to reduced instruction set computer (RISC).

Characteristics

CISC designs typically feature a large number of instructions with many addressing modes, variable instruction lengths, and instructions that operate directly on memory operands. Examples include the IBM System/360, DEC VAX, PDP-11, the Motorola 68000 family, and Intel's x86 architecture, which remains dominant in desktop and server computing.

Rationale and history

In the 1970s, memory was expensive and compilers were primitive, so rich instruction sets reduced program size and bridged the "semantic gap" between machine code and high-level languages. Microcode made complex instructions feasible. The RISC movement of the 1980s argued that simpler, uniform instructions enabled faster pipelining and better compiler optimization. Modern x86 processors internally translate CISC instructions into RISC-like micro-operations, blurring the practical distinction, while RISC architectures such as ARM dominate mobile and embedded markets.
