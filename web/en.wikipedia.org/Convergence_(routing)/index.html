Convergence (routing)

Convergence, in computer networking, is the state of a set of routers that have the same topological information about the internetwork in which they operate. For a set of routers to have converged, they must have collected all available topology information from each other via the implemented routing protocol, the information they collected must not contradict each other, and it must reflect the real state of the network.

Convergence time

Convergence time is a measure of how fast a group of routers reach the state of convergence. It is one of the main design goals and an important performance indicator for routing protocols, which should implement a mechanism that allows all routers running the protocol to quickly and reliably converge.

Mechanisms

When a network event such as a link failure occurs, routers exchange updates and recompute their routing tables. Distance-vector protocols may converge slowly and suffer from problems such as counting to infinity, mitigated by techniques like split horizon and hold-down timers; link-state protocols such as OSPF flood link-state advertisements and typically converge faster. Until convergence completes, traffic may be misrouted, delayed, or caught in routing loops. See also routing protocol.
