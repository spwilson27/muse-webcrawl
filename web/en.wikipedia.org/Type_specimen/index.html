Type specimen

In biology, a type is a specimen (or a taxon, or a set of specimens) which serves as the anchor or reference point for the application of a scientific name. When a new species is described, the author designates a type specimen — the holotype — which is deposited in a museum or herbarium collection so that future researchers can compare material against it and verify the identity of the taxon.

Kinds of types

Under the international codes of nomenclature, several categories are recognized. A syntype is one of several specimens cited when no holotype was designated; a lectotype may later be selected from among syntypes to serve as the single name-bearing type. A paratype is any additional specimen cited in the original description besides the holotype. If the original type material is lost, a neotype may be designated. In botany, types are commonly preserved herbarium sheets; in zoology they may be whole organisms, parts, or fossils. In microbiology, living type strains are maintained in culture collections.

Purpose

Scientific names are not anchored to descriptions, which can be mistaken or based on mixed material, but to types, which are objective and permanent. If a species is later split into two, the name follows the population containing the type; the other receives a new name. This principle of typification gives biological nomenclature its stability. The concept extends beyond biology: in geology, type localities and type sections anchor stratigraphic names.
