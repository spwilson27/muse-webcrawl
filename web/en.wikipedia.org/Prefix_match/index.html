Prefix match

Prefix matching is an operation in computing in which a string, key, or network address is matched against a set of stored entries by comparing only the initial portion (the prefix) of each entry. Prefix matching is fundamental to text search, data structures such as tries, and to Internet routing.

Longest prefix match

In IP routing, the longest prefix match rule determines forwarding: when a router's forwarding table contains several routes whose network prefixes match a destination address, the route with the longest (most specific) prefix is chosen. For example, a route to 192.168.1.0/24 is preferred over 192.168.0.0/16 for the destination 192.168.1.5. This rule allows hierarchical aggregation of routes under CIDR while permitting more specific exceptions.

Data structures and algorithms

Prefix matching over strings is efficiently supported by trie (prefix tree) data structures, in which each node represents a common prefix of its descendants; tries underlie autocomplete and spell-checking systems. In databases, an index on a text column can accelerate queries that match a leading substring, and many query languages expose prefix predicates directly.
