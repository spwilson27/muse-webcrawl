Color management

In digital imaging systems, color management (or colour management) is the controlled conversion between the color representations of various devices, such as image scanners, digital cameras, monitors, TV screens, film printers, computer printers, offset presses, and corresponding media. The goal is consistent colour reproduction: an image should look the same on a camera display, a computer monitor and a printed page, even though each device has a different colour gamut and response.

ICC profiles

The standard framework is that of the International Color Consortium (ICC), founded in 1993. Each device is characterised by an ICC profile describing how its colour values map to a device-independent profile connection space (CIE XYZ or CIELAB). A color management module then converts colours between device profiles through that reference space, using rendering intents (perceptual, relative colorimetric, saturation, absolute colorimetric) to handle colours that fall outside a destination device's gamut.

Workflow

A colour-managed workflow typically involves calibrating and profiling input devices (scanners, cameras), soft-proofing on a calibrated and profiled monitor, embedding profiles in image files (such as sRGB or Adobe RGB for RGB images), and profiling output printers with test charts measured by a spectrophotometer. Operating systems provide built-in colour management, such as ColorSync on macOS and Windows Color System.

Applications

Color management is essential in professional photography, graphic design, prepress and printing, cinema production, and e-commerce, where accurate product colours matter. Without it, the same RGB values produce visibly different colours on different displays and in print.
