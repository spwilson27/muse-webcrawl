Representable functor

A representable functor is determined by its representing object via the Yoneda lemma.

In category theory, a representable functor is a functor from a category to the category of sets that is naturally isomorphic to a hom-functor. More precisely, a functor F : Cop → Set is representable if there is an object A of C and a natural isomorphism F(X) ≅ HomC(X, A) for all objects X; the object A is then called a representing object for F.

Universal elements and properties

By the Yoneda lemma, giving a representation of F is equivalent to giving a universal element: an element u ∈ F(A) through which every element of every F(X) factors uniquely. Many constructions in mathematics can be recast as representability statements: the tensor product, the Picard group, the classifying space for a cohomology theory, and the moduli spaces of algebraic geometry arise as representing objects for naturally defined functors. In algebraic geometry, the functor-of-points perspective treats a scheme as the functor it represents.

Examples

The forgetful functor from groups to sets is represented by the integers with the element 1. The functor assigning to a vector space its dual's underlying set is representable in the appropriate enriched sense. A celebrated application is Brown representability in homotopy theory, which guarantees that generalised cohomology theories are represented by spectra.
