Cocoa Touch

Cocoa Touch is the application development environment for iOS, iPadOS, and tvOS, Apple's operating systems for the iPhone, iPad, and Apple TV. It is built on the Cocoa API for macOS, adapted for touch-based interfaces. Cocoa Touch provides abstractions for presenting the user interface, handling touch events, and integrating with system features such as multitasking, push notifications, and sensors.

Features

The central framework of Cocoa Touch is UIKit, which supplies the application architecture, event handling, view hierarchy, and standard controls — buttons, tables, navigation controllers — designed for direct manipulation by touch. Gesture recognizers translate raw multitouch input into discrete actions such as taps, swipes, and pinches. Cocoa Touch also includes frameworks for animation (Core Animation), 2D drawing (Core Graphics), data storage (Core Data), maps, and media playback.

Relation to Cocoa

Where macOS's Cocoa centers on AppKit and mouse-and-keyboard interaction, Cocoa Touch replaces AppKit with UIKit and assumes a single-window, touch-first application model. Both share the Foundation framework, which provides strings, collections, networking, and concurrency primitives, and both are programmed with the model–view–controller pattern and delegation.

Development

Applications are built with Xcode using Objective-C or Swift. Since 2019, Apple has promoted SwiftUI as a declarative alternative above UIKit, but Cocoa Touch and UIKit remain the foundation on which iOS interfaces, including SwiftUI-rendered ones, are built.
