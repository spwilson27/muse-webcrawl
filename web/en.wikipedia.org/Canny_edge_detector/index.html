Canny edge detector

From Wikipedia, the free encyclopedia

The Canny edge detector is an edge detection operator that uses a multi-stage algorithm to detect a wide range of edges in images. It was developed by John F. Canny in 1986. Canny also produced a computational theory of edge detection explaining why the technique works.

The algorithm

The Canny algorithm contains five stages:

  1. Noise reduction — the image is smoothed with a Gaussian filter to remove noise.
  2. Finding the intensity gradient — the smoothed image is filtered with a Sobel kernel in both horizontal and vertical directions to obtain the first derivative, from which gradient magnitude and direction are computed.
  3. Non-maximum suppression — pixels that are not local maxima along the gradient direction are suppressed, thinning the edges.
  4. Double threshold — pixels are classified as strong, weak, or non-relevant based on two threshold values.
  5. Edge tracking by hysteresis — weak pixels are kept only if connected to strong pixels.

Applications

The Canny detector is widely used in computer vision, including medical imaging, object recognition, and autonomous vehicle systems. Implementations are included in libraries such as OpenCV.
