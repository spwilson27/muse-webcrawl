Memory consolidation

From Wikipedia, the free encyclopedia

Memory consolidation is the process by which a temporary, labile memory trace is transformed into a more stable, long-lasting form. Neuroscientists distinguish two broad kinds: synaptic consolidation, which occurs within the first hours after learning at the level of synapses, and systems consolidation, a slower process over weeks to years in which memories become less dependent on the hippocampus and more distributed in the neocortex.

Synaptic consolidation

Synaptic consolidation is associated with long-term potentiation and requires protein synthesis and gene expression; if these are blocked within a critical window after learning, the memory fails to stabilize. Following consolidation, a memory can become labile again when reactivated — a process known as reconsolidation.

Systems consolidation

According to the standard model, the hippocampus rapidly binds features of an experience and, through repeated reactivation — much of it during sleep, particularly during sharp-wave ripples in slow-wave sleep — gradually trains neocortical networks so the memory can be retrieved without the hippocampus. The multiple trace theory proposes instead that episodic memories remain hippocampus-dependent.

Role of sleep

Sleep is thought to support consolidation through the replay of waking neural activity patterns and the transfer of information between the hippocampus and cortex, coordinated by sleep spindles and slow oscillations.
