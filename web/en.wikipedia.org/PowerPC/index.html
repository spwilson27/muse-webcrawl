PowerPC (short for Performance Optimization With Enhanced RISC – Performance Computing) is a reduced instruction set computer (RISC) instruction set architecture created by the 1991 Apple–IBM–Motorola (AIM) alliance. Derived from IBM's POWER architecture, it became widely known as the processor family used in Apple's Macintosh computers from 1994 until the transition to Intel processors in 2006.

History

The first implementations, the PowerPC 601 (1993), powered Apple's Power Macintosh line (1994). Subsequent generations included the 603 and 604, the G3 (750), the G4 (74xx, with AltiVec vector instructions, from Motorola/Freescale), and the 64-bit G5 (970, from IBM). PowerPC chips also powered IBM's RS/6000 and later pSeries servers, and the architecture was adopted in all three major seventh-generation game consoles: Nintendo's GameCube and Wii (and Wii U) used IBM PowerPC-derived CPUs, Microsoft's Xbox 360 used the triple-core Xenon, and Sony's PlayStation 3 used the Cell processor with a PowerPC-based control core.

Applications

Beyond desktops, PowerPC found extensive use in embedded systems — networking equipment, automotive controllers, printers, and aerospace applications (including radiation-hardened RAD750 processors in NASA spacecraft such as the Perseverance rover). IBM continues the lineage in its POWER server processors; the architecture was opened through the OpenPOWER Foundation in 2013 and the instruction set was made royalty-free in 2019.

Design

PowerPC is a load–store architecture with 32 general-purpose registers, fixed-length 32-bit instructions, and support for both 32-bit and 64-bit implementations, with optional vector (AltiVec/VMX, VSX) and floating-point facilities.
