Semantic Web

The Semantic Web is an extension of the World Wide Web, standardised by the World Wide Web Consortium (W3C), in which information is given well-defined meaning so that computers and people can work in cooperation. Proposed by Tim Berners-Lee, who described the vision in a widely read 2001 Scientific American article with James Hendler and Ora Lassila, it aims to transform the web of documents into a web of data that software agents can process, combine and reason over.

Technologies

The core standards rest on Resource Description Framework (RDF), which expresses facts as subject–predicate–object triples identified by URIs. RDF Schema and the Web Ontology Language (OWL) add vocabularies and formal ontologies for describing classes, properties and logical constraints; SPARQL is the query language for RDF data. Data can be embedded in pages via RDFa, Microdata or JSON-LD — the latter boosted by search engines' adoption of schema.org vocabularies for rich search results.

Linked data and adoption

Berners-Lee's "Linked Data" principles encouraged publishing structured data with dereferenceable identifiers and links between datasets. Public knowledge bases such as DBpedia (extracted from Wikipedia) and Wikidata embody much of the vision, and Google's Knowledge Graph, launched in 2012, applied semantic techniques at commercial scale. However, the grander early vision of autonomous agents reasoning over open ontologies proved harder than expected: ontology engineering is laborious, trust and data quality are persistent problems, and much practical progress came through centralised knowledge graphs and, later, machine learning rather than formal logic. The term "Web 3.0" was long associated with the Semantic Web before being reused for blockchain-based proposals.
