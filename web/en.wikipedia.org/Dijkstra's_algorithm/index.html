Dijkstra's algorithm

Dijkstra's algorithm is an algorithm for finding the shortest paths between nodes in a weighted graph, which may represent, for example, a road network. It was conceived by computer scientist Edsger W. Dijkstra in 1956 and published three years later.

Dijkstra's algorithm progressively settles the closest unvisited node.

Algorithm

The algorithm maintains a set of unvisited nodes and tentative distances from the source. Initially the source has distance zero and all other nodes infinity. At each step it selects the unvisited node with the smallest tentative distance, marks it visited, and relaxes all edges leaving it, updating neighbors' distances if a shorter path is found. The algorithm requires that all edge weights be non-negative. With a binary heap priority queue, its running time is O((V + E) log V) for V vertices and E edges.

History

Dijkstra reportedly devised the algorithm in about twenty minutes while sitting at a café terrace in Amsterdam with his fiancée, thinking about the shortest route for a demonstration of the ARMAC computer. He published it in 1959 in the paper "A note on two problems in connexion with graphs".

Applications

Variants of Dijkstra's algorithm underpin link-state routing protocols such as OSPF and IS-IS used in computer networks, as well as route planning in mapping software. The A* search algorithm is a generalization that uses heuristics.
