Job control (Unix)

In Unix and Unix-like operating systems, job control refers to the control of jobs by a shell, especially interactively, where a "job" is a shell's representation for a process group. Job control allows the user to start, suspend, and resume multiple command pipelines from a single terminal session — capabilities made possible by the process group and session mechanisms of the kernel together with a controlling terminal.

Usage

A command followed by an ampersand (&) runs in the background. The built-in commands jobs, fg, bg, and disown list and manipulate jobs; typing Control-Z suspends the foreground job (sending SIGTSTP), and signals such as SIGCONT resume it. Job control was developed for BSD Unix, appearing with the C shell and the 4.2BSD kernel support, and it was later standardized in POSIX shells.

Implementation

The kernel associates each process with a process group and each session with a controlling terminal; only the foreground process group may read from the terminal or receive terminal-generated signals, while background processes attempting terminal input are stopped by SIGTTIN. The shell uses these primitives, plus wait and the termios interface, to present multiple jobs to the user.
