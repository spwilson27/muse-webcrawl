Push–relabel maximum flow algorithm

The push–relabel algorithm (also called the preflow–push algorithm) is an algorithm for computing a maximum flow in a flow network. Introduced by Andrew V. Goldberg and Robert Tarjan in the 1980s, it is among the most efficient maximum-flow methods known, with the generic version running in O(V2E) time and refined variants running faster.

Overview

Unlike augmenting-path algorithms such as Ford–Fulkerson, push–relabel works with a preflow — a flow assignment that may leave intermediate vertices with excess inflow — and manipulates the flow locally. Each vertex is assigned a height (label). The two basic operations are push, which sends excess flow from a vertex to a lower neighbour with residual capacity, and relabel, which raises a vertex's height when it cannot push its excess onward. The algorithm begins by saturating the edges out of the source and ends when no vertex other than the sink has excess, at which point the preflow is a maximum flow.

Variants and complexity

Vertex-selection rules strongly affect performance: the FIFO and highest-label variants achieve O(V3) and O(V2√E) bounds respectively. Heuristics such as gap relabelling and global relabelling make implementations highly competitive in practice, and push–relabel codes are widely used as reference solvers for flow problems.
