Blocking effect

The blocking effect is a phenomenon in classical (Pavlovian) conditioning: if a stimulus (A) has already been established as a reliable predictor of an unconditioned stimulus, then pairing a new stimulus (B) together with A and the same outcome produces little or no conditioning to B. Prior learning about A "blocks" learning about the redundant B.

Discovery

The effect was demonstrated by Leon Kamin in experiments with rats in the late 1960s. Animals first trained that a tone predicted shock later failed to learn that an added light also predicted shock, whereas control animals learned about the light readily.

Explanation

The effect motivated the Rescorla–Wagner model (1972), which explains learning as driven by prediction error: once A fully predicts the outcome there is no "surprise" left to drive new learning about B. Blocking is a cornerstone of modern associative learning theory and has analogues in human causal learning, marketing and machine learning.
