Support vector machine

Support vector machines (SVMs) are supervised machine learning algorithms used for classification and regression. Given labelled training examples, an SVM finds the hyperplane that separates the classes with the maximum margin — the greatest distance to the nearest training points, which are called the support vectors. Maximising the margin gives good generalisation, a fact grounded in statistical learning theory (VC theory) developed by Vladimir Vapnik and Alexey Chervonenkis.

Method

For linearly separable data, the algorithm solves a convex optimisation problem that depends only on the support vectors. Real data are handled with "soft margins", introduced by Corinna Cortes and Vapnik in 1995, which allow some misclassification at a cost controlled by a parameter C. Non-linear boundaries are obtained with the kernel trick: data are implicitly mapped into a high-dimensional feature space where a linear separator corresponds to a curved boundary in the original space. Common kernels include polynomial, radial basis function (Gaussian), and sigmoid kernels.

Variants and use

Related methods include support vector regression (SVR), one-class SVMs for anomaly detection, and structured SVMs. SVMs were among the most successful learning methods of the 1990s and 2000s, excelling at text categorisation, image recognition, bioinformatics (such as protein classification) and handwriting recognition, and they remain effective on small-to-medium datasets with many features — though deep learning now dominates large-scale image and speech tasks.
