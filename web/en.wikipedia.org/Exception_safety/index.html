Exception safety

Exception safety
FieldSoftware engineering
Associated withC++ exception handling

Exception safety is the state of code working correctly when exceptions are thrown during its execution. The concept was formalised in the context of the C++ programming language, notably by David Abrahams, in response to subtle bugs in early designs of the C++ standard library.

Levels of guarantee

Four levels of exception safety are commonly distinguished. The no-throw guarantee promises that an operation cannot fail with an exception. The strong guarantee promises that if an exception is thrown, the program state is rolled back to what it was before the operation began. The basic guarantee promises that invariants are preserved and no resources leak, though the state may have changed. Code offering no guarantee may corrupt state or leak resources when an exception occurs.

Achieving exception safety

Techniques include resource acquisition is initialization (RAII), smart pointers, and structuring operations so that potentially throwing work is completed before any visible state is modified, as in the copy-and-swap idiom.
