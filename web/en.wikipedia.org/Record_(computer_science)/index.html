Record (computer science)

A record groups named fields of possibly different types into a single composite value.

In computer science, a record (also called a structure, struct, or compound data) is a basic data structure. Records are a fundamental composite data type: a record is a value that contains other values, typically in fixed number and sequence and typically indexed by names. The elements of a record are usually called fields or members. A record contrasts with an array, whose elements are indexed by position and are usually of the same type, and with a tuple, whose components are ordered but unnamed.

Examples

COBOL was the first widespread language to support records explicitly, and the construct passed into Pascal (record), C (struct), and their descendants. For example, a person may be defined as a record with a name (a string), a birth date (a date), and a salary (a number):

type Person = record
  name   : string;
  birth  : Date;
  salary : Currency
end;

Database systems apply the same idea: a record is a row of a table, whose fields correspond to columns. Object-oriented languages provide classes, which generalize records with associated functions (methods) and access control. In type theory, records are modelled as record types, and operations on them — such as selecting a field by its label — are studied formally. JSON objects and many serialization formats are unordered record-like structures mapping names to values.

History and usage

The concept descends from unit-record equipment and punched-card practice, in which a card encoded one record of fixed fields — a heritage visible in fixed-length records in file systems and block storage. Most general-purpose languages today offer records natively (C structs, Go structs, Rust structs, C# and Java records) or through libraries, and they underpin data interchange, database management, and systems programming.
