In information technology, lossy compression is the class of data compression methods that uses inexact approximations and partial data discarding to represent the content. These techniques are used to reduce data size for storing, handling and transmitting content. Unlike lossless compression, the original data cannot be perfectly reconstructed from lossily compressed data.

How it works

Most lossy codecs exploit limitations of human perception: details the eye or ear scarcely registers are discarded first. JPEG, for example, transforms image blocks with the discrete cosine transform and quantizes high-frequency coefficients coarsely; MP3 discards sounds masked by louder sounds. The user typically chooses a quality setting that trades file size against fidelity.

Applications

Lossy compression underlies nearly all consumer media: digital photography (JPEG), streaming music (MP3, AAC, Opus), online video (MPEG-4, H.264, VP9, AV1) and voice telephony. Repeatedly re-encoding lossily — "generation loss" — progressively degrades quality.
