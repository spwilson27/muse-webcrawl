Vulkan (API)

Vulkan is a low-overhead, cross-platform application programming interface (API) for 3D graphics and compute, developed by the Khronos Group. First released in February 2016, Vulkan gives applications explicit control over GPU operations — memory, synchronisation, and command submission — reducing driver overhead and enabling better use of multi-core CPUs compared with its predecessor, OpenGL.

History

Vulkan grew out of AMD's Mantle API, which AMD donated to the Khronos Group in 2014 as the foundation of a new open standard. Announced at the Game Developers Conference in 2015 under the working name "glNext", Vulkan 1.0 shipped on 16 February 2016. Later releases added features including ray tracing extensions (later folded into Vulkan 1.2 and beyond), mesh shaders, and video encode/decode. Vulkan is supported on Windows, Linux, Android, and — via translation layers such as MoltenVK — on macOS and iOS.

Design

Vulkan is explicit: applications allocate GPU memory, record command buffers (which can be built in parallel across threads), and submit them to queues with explicit synchronisation via fences, semaphores, and events. Shaders are usually distributed as SPIR-V, an intermediate bytecode compiled ahead of time. Rendering uses fixed-function pipelines described by pipeline state objects, and render passes define how framebuffer attachments are used. This explicitness makes Vulkan more verbose than OpenGL or Direct3D 11, but dramatically reduces hidden driver work and frame-time spikes.

Adoption

Vulkan is the primary graphics API on Android and Linux gaming (including the Steam Deck via Proton/DXVK), and is supported by engines such as Unity, Unreal Engine, and id Tech. Valve's DXVK and VKD3D-Proton translate Direct3D calls to Vulkan, and Google selected Vulkan for Stadia and for its Android graphics stack.
