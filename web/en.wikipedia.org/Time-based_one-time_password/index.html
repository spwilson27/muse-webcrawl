Time-based one-time password

Time-based one-time password (TOTP) is a computer algorithm that generates a one-time password using the current time as a source of uniqueness. An extension of the HMAC-based one-time password algorithm (HOTP), it has been adopted as Internet Engineering Task Force standard RFC 6238 and is a cornerstone of two-factor authentication.

Algorithm

Client and server share a secret key. Both divide the current Unix time by a time step, usually 30 seconds, and compute an HMAC (typically SHA-1) of that counter with the shared secret; the result is truncated to a short numeric code, usually six digits. Because the code depends on time, each code is valid only for a brief window.

Security

Codes are only useful for a short period and cannot be reused, which protects against replay attacks. Security depends on the secrecy of the shared key, on clock synchronisation, and on the user protecting the authenticator device; the codes remain vulnerable to real-time phishing. Authenticator applications such as Google Authenticator and Microsoft Authenticator implement TOTP, and many online services offer it as a second factor.
