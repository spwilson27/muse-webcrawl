C is a general-purpose programming language created by Dennis Ritchie at Bell Labs between 1972 and 1973 for constructing utilities running on Unix. It has become one of the most widely used programming languages of all time, serving as the foundation for operating systems, embedded software and countless other languages.

History

C evolved from Ken Thompson's B language, itself derived from BCPL. Ritchie developed C alongside the Unix operating system, which was rewritten in C in 1973 — a landmark decision that made Unix portable across hardware. In 1978 Brian Kernighan and Ritchie published The C Programming Language, whose description, known as K&R C, served as the informal standard for years. The language was standardised by ANSI in 1989 (C89) and subsequently by ISO, with major revisions in 1999 (C99), 2011 (C11), 2017 (C17) and 2023 (C23).

Features

C provides constructs that map efficiently to typical machine instructions: a small set of keywords, structured control flow, recursion, pointers with pointer arithmetic, and a static but weakly enforced type system. The language gives the programmer direct control over memory through manual allocation and deallocation, which makes it suitable for systems programming but also error-prone.

#include <stdio.h>

int main(void) {
    printf("hello, world\n");
    return 0;
}

Influence

C's syntax has influenced many later languages, including C#, C++, Java, JavaScript and Objective-C. The kernels of Unix, Linux and Windows are written largely in C, and the language remains dominant in embedded systems and high-performance computing.
