False negatives and false positives

False negatives and false positives are errors that arise in binary classification and diagnostic testing. A false positive occurs when a test indicates a condition is present when it is not (a Type I error), while a false negative occurs when a test fails to detect a condition that is present (a Type II error).

Definitions

In medical testing, the proportion of actual positives correctly identified is sensitivity, and the proportion of actual negatives correctly identified is specificity. Raising a decision threshold generally decreases false positives while increasing false negatives, a trade-off captured by receiver operating characteristic (ROC) curves.

Examples

False positives arise in mammography screening, airport security screening, and spam filtering; false negatives can delay disease diagnosis or allow genuine threats to pass undetected. The consequences of each error type determine how tests are designed and thresholds chosen. The terminology parallels "false alarm" and "miss" in signal detection theory.
