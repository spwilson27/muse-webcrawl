Markup language

A markup language is a text-encoding system which specifies the structure and formatting of a document and potentially the relationships among its parts. Markup can control the display of the document or enrich its content to facilitate automated processing. It is often used to control the presentation of the document: how the content is displayed, printed, or structured.

Types

Markup is commonly classified as presentational (indicating appearance, as in word-processor files), procedural (instructions to processing software, as in troff or TeX), or descriptive (labelling what content is, as in SGML and XML), a distinction articulated by Coombs, Rubinstein and Hersh in 1987. Descriptive markup separates content from presentation, so the same source can be rendered in many forms.

History and examples

Early systems included RUNOFF and IBM's Generalized Markup Language (GML), developed from 1969 by Charles Goldfarb, Edward Mosher and Raymond Lorie. GML led to SGML (standardised 1986), from which Tim Berners-Lee derived HTML (1991), the markup language of the World Wide Web. XML (1998) is a simplified SGML profile used for data interchange and for formats such as SVG, MathML and Office documents. Lightweight markup languages — including Markdown, reStructuredText and wiki markup — use minimal, readable syntax converted to HTML. Other notable languages include LaTeX for typesetting and DocBook for technical documentation.

Characteristics

Most markup languages intermix markup with the document's content as plain text, using delimiters such as HTML's angle-bracket tags (e.g. <p>) to distinguish markup from text. Some, like XML, impose a strict tree structure and well-formedness rules; others, like Markdown, are informal. Markup languages are distinct from programming languages, though some, such as XSLT, are Turing-complete.
