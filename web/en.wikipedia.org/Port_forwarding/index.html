Port forwarding

Port forwarding (or port mapping) is an application of network address translation (NAT) that redirects a communication request from one IP address and port number combination to another while the packets traverse a network gateway such as a router or firewall.

Uses

Port forwarding allows services on a private network — such as web servers, game servers, SSH access, or security cameras — to be reachable from the public internet through the gateway's public IP address. For example, a router may forward requests arriving on port 80 to a specific internal computer running a web server.

Types

  • Local port forwarding — used in SSH tunneling to bypass firewalls and encrypt traffic to a local service.
  • Remote port forwarding — allows a server on the remote side of a tunnel to access services on the local side.
  • Dynamic port forwarding — creates a SOCKS proxy on demand through an SSH connection.

Security considerations

Each forwarded port exposes an internal service to the internet, so forwarded services must be patched and secured; unnecessary forwards increase attack surface.
