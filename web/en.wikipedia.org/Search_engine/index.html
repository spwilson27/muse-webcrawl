Search engine

A search engine returns ranked results in response to a user query.

A search engine is a software system that provides hyperlinks to web pages and other relevant information on the Web in response to a user's query. The search results are usually presented as a list of results, often called search engine results pages (SERPs). Search engines help to minimise the time required to find information and are the primary interface to the World Wide Web for most users.

How search engines work

General web search engines operate in three stages. In crawling, automated programs called web crawlers or spiders follow hyperlinks across the web and download pages. In indexing, the contents of pages are analysed and stored in a vast inverted index mapping terms to documents. In ranking, the engine matches a query against the index and orders the results by estimated relevance, using signals such as the text of the page, the anchor text of links, and the link structure of the web — famously exploited by PageRank.

History

The first search tools of the early 1990s, such as Archie and Veronica, indexed file archives and Gopher menus. Web search engines including Lycos, AltaVista and Yahoo! appeared from 1994. Google Search, founded in 1998, achieved dominance through the quality of its link-based ranking and has remained the global market leader, alongside Bing, Baidu in China and Yandex in Russia.

Types

Beyond general web search there are vertical search engines for images, video, news, shopping and academic literature, as well as enterprise and desktop search systems, and metasearch engines that aggregate results from several providers. Privacy-focused engines such as DuckDuckGo differentiate themselves by not tracking users.

Business and criticism

Search engines are generally funded by advertising, selling sponsored placements beside or above the organic results. The industry of search engine optimization (SEO) works to raise sites' rankings, while engines combat spam and manipulation. Critics have raised concerns about bias, filter bubbles, privacy and market concentration.
