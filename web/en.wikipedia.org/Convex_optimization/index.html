Convex optimization

FieldMathematical optimization
Problem classMinimise a convex function over a convex set
Key propertyEvery local minimum is a global minimum
Main methodsInterior-point methods; gradient methods; cutting-plane methods

Convex optimization is a subfield of mathematical optimization that studies the problem of minimizing convex functions over convex sets (or, equivalently, maximizing concave functions over convex sets). Many classes of convex optimization problems admit polynomial-time algorithms, whereas general mathematical optimization is in general NP-hard. Convex optimization has applications in a wide range of disciplines, such as automatic control systems, estimation and signal processing, communications and networks, electronic circuit design, data analysis and modeling, finance, statistics (optimal design), and structural optimization.


A convex function on a convex set has a single valley: any local optimum is global.

Standard form

A convex optimization problem in standard form minimises a convex objective function f₀(x) subject to convex inequality constraints fᵢ(x) ≤ 0 and affine equality constraints. The feasible set is convex, so the problem's geometry guarantees that a local minimum is a global minimum and that duality theory applies: under mild conditions (such as Slater's condition) the optimal value of the Lagrangian dual equals that of the primal problem, giving strong duality.

Problem classes

  • Linear programming — affine objective and constraints.
  • Quadratic programming — convex quadratic objective, affine constraints.
  • Second-order cone programming and semidefinite programming — successively more general cone constraints, with semidefinite programming subsuming the others.
  • Least squares and entropy maximisation problems as special cases.

Algorithms

The ellipsoid method (Khachiyan, 1979) first showed linear programming to be polynomial-time, and Karmarkar's interior-point method (1984) made large problems practical; primal–dual interior-point methods, developed further by Nesterov and Nemirovski, extend to all convex problems with self-concordant barriers. For very large-scale problems, first-order methods — gradient descent, proximal and splitting methods such as ADMM — are widely used in machine learning, where convex formulations underlie support vector machines, logistic regression, and the LASSO.

Software

Modelling tools such as CVX, CVXPY, and Convex.jl let users state problems in disciplined convex programming form and pass them to solvers such as MOSEK, Gurobi, ECOS, and SCS.
