Recursive least squares filter

Recursive least squares (RLS) is an adaptive filter algorithm that recursively finds the coefficients that minimise a weighted linear least squares cost function relating to the input signals. Unlike gradient-based algorithms such as least mean squares (LMS), which use only the current error and an approximation of the statistics of the signals, RLS uses information from all past input samples, weighted by an exponential forgetting factor.

Algorithm

At each step the algorithm forms an a priori estimate of the desired signal using the current weight vector, computes the error, and updates the weights using a gain vector derived from the inverse correlation matrix of the input, which is itself updated recursively — efficiently, using the matrix inversion lemma. A forgetting factor λ (0 < λ ≤ 1) weights recent data more heavily than old data, allowing the filter to track slowly time-varying systems; with λ = 1 the algorithm converges to the solution of the ordinary least squares problem over all data seen so far.

Properties and uses

RLS converges much faster than LMS and its steady-state error is largely independent of the eigenvalue spread of the input correlation matrix, but at the price of much greater computational complexity — quadratic in the number of filter coefficients — and potential numerical instability, addressed by square-root and QR-decomposition variants. Applications include system identification, channel equalisation in communications, echo cancellation, and adaptive noise cancellation. The Kalman filter can be viewed as a generalisation of the recursive least squares approach to state-space models.
