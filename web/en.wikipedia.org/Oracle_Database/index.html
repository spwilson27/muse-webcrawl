Oracle Database (commonly referred to as Oracle DBMS or simply Oracle) is a proprietary multi-model database management system produced by Oracle Corporation. First released in 1979, it was the first commercially available relational database to use SQL, and it remains one of the most widely used database systems for enterprise applications, online transaction processing (OLTP), data warehousing, and mixed workloads.

History

Oracle's founders based their product on Edgar F. Codd's relational model papers and on IBM's System R research, but beat IBM to market with a commercial SQL database. Early versions ran on minicomputers such as the PDP-11 and VAX. Oracle Version 6 (1988) introduced row-level locking and PL/SQL, the company's procedural extension to SQL. Later milestones included support for clustered servers with Real Application Clusters (RAC), partitioning, XML and JSON data types, multitenant "pluggable databases," and the self-managing Autonomous Database services offered on Oracle Cloud.

Architecture

An Oracle database server consists of a database (datafiles, control files, and redo logs on disk) and an instance (the System Global Area in memory plus background processes). Oracle uses multiversion read consistency: readers see a consistent snapshot as of a point in time without blocking writers. Transactions follow the ACID model, with redo logs and undo segments supporting recovery and rollback. Data is organised in tablespaces; the cost-based query optimiser chooses execution plans using stored statistics.

Editions and licensing

Oracle Database is sold in editions including Enterprise Edition, Standard Edition, and the free Express Edition (XE); licensing is typically by processor or named user and is a frequent subject of customer audits and disputes. A free "Oracle Database Free" release continues the XE line. The database also runs as a managed cloud service and, through converged-database features, supports relational, JSON, graph, and spatial data in one engine.
