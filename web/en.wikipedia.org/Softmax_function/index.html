Softmax function

The softmax function, also known as softargmax or the normalized exponential function, converts a vector of real numbers into a probability distribution. Each output value lies between 0 and 1 and the outputs sum to 1, so they can be interpreted as class probabilities. It is a generalization of the logistic function to multiple dimensions.

Definition

For an input vector z = (z1, …, zK), the softmax is

σ(z)i = ezi / Σj ezj

Exponentiating amplifies differences between inputs while normalization ensures a valid distribution. A "temperature" parameter can sharpen or soften the output.

Applications

Softmax is the standard output activation function for the final layer of a neural network classifier, where it is paired with the cross-entropy loss; the combination simplifies the gradient. It is also used in multinomial logistic regression, in reinforcement learning action selection, and in the attention mechanism of transformer models, where it weights the relevance of tokens. For numerical stability, implementations subtract the maximum input before exponentiating.

Relation to argmax

Whereas argmax returns a single index, softmax returns a smooth, differentiable distribution that "softly" approximates it; as inputs are scaled up, the distribution converges to the argmax one-hot vector.
