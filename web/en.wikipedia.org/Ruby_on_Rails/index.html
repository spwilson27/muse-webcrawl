Ruby on Rails (simplified as Rails) is a server-side web application framework written in Ruby under the MIT License. Rails is a model–view–controller (MVC) framework, providing default structures for a database, a web service, and web pages.

History

Rails was extracted by David Heinemeier Hansson from his work on the project management tool Basecamp at the web application company 37signals. It was first released as open source in July 2004. Rails popularised many paradigms that influenced later frameworks, including convention over configuration and don't repeat yourself (DRY).

Philosophy and design

Rails emphasises the use of well-known software engineering patterns: the model–view–controller architecture, Active Record for data access, and RESTful application design. Scaffolding and generators let developers produce working applications quickly, and the framework includes tools for database migrations, testing and asset management.

Usage

Well-known websites built with Rails include GitHub, Shopify, Airbnb (early versions), SoundCloud, Hulu and Basecamp. The framework remains widely used for start-ups and software-as-a-service products.
