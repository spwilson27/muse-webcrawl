FreeBSD

FreeBSD
Developer: The FreeBSD Project
Written in: C
OS family: Unix-like (BSD)
Initial release: November 1, 1993
License: BSD licenses (2-clause, 3-clause, 4-clause)
Preceded by: 386BSD

FreeBSD is a free and open-source Unix-like operating system descended from the Berkeley Software Distribution (BSD), which was based on Research Unix. The first version was released in 1993. In 2005, FreeBSD was the most popular open-source BSD operating system, accounting for more than three-quarters of all installed and permissively licensed BSD systems.

FreeBSD is developed as a complete operating system — kernel, device drivers, userland utilities, and documentation are maintained together in a single source repository — and it is released under the permissive BSD licenses, in contrast to the copyleft GNU General Public License used by Linux, with which it shares many similarities.

History

FreeBSD grew out of the unofficial patchkit for 386BSD, after that project's development stalled. Its first formal release, FreeBSD 1.0, appeared in December 1993. Because part of the early code derived from AT&T's Unix sources, a legal challenge by Unix System Laboratories led the project to re-base itself on the largely rewritten 4.4BSD-Lite release in FreeBSD 2.0 (1995), clearing the way for unrestricted distribution.

Features

FreeBSD is noted for its advanced networking, security, and storage features. It includes the ZFS file system, the jails OS-level virtualization mechanism (a precursor of modern containers), the pf and IPFW firewalls, and DTrace instrumentation. The FreeBSD Ports collection provides tens of thousands of third-party applications. The system powers major Internet infrastructure and appliances; its code has been incorporated into products including the PlayStation 4 and Nintendo Switch operating systems, macOS components, and storage systems from vendors such as NetApp. Derivatives include pfSense, TrueNAS, GhostBSD, and MidnightBSD.
