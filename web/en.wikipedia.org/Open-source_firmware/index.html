Open-source firmware

Open-source firmware is firmware whose source code is made available under an open-source licence, allowing users to study, modify and redistribute it. It stands in contrast to proprietary firmware ("blobs") that ship with most consumer hardware. Open firmware projects are most common for embedded devices such as routers, single-board computers, computer motherboards and peripherals, where they are valued for transparency, auditability, longevity and freedom from vendor abandonment.

Open firmware gives users control over the lowest level of their hardware.

Examples

coreboot and Libreboot

coreboot is an open-source project aimed at replacing the proprietary BIOS or UEFI firmware found in most computers, performing only minimal hardware initialisation before handing off to a payload such as SeaBIOS, TianoCore or a Linux kernel. Libreboot is a distribution of coreboot that removes proprietary binary blobs entirely.

OpenWrt and DD-WRT

OpenWrt is a Linux-based open-source operating system and firmware for embedded devices, especially wireless routers, providing a fully writable filesystem and package management. DD-WRT is a related third-party firmware for routers based on Linux.

Other projects

Other notable examples include U-Boot, a widely used open-source bootloader for embedded systems; EDK II, the open-source reference implementation of UEFI; OpenBMC for server baseboard management controllers; and open firmware for peripherals such as the QMK keyboard firmware.

Advantages and challenges

Advocates cite security auditing, faster fixes for vulnerabilities, extended hardware lifespan and user freedom. Challenges include hardware vendors withholding documentation, signed-firmware restrictions that prevent replacement, and the risk of "bricking" a device during flashing.
