Atom (web standard)


The Atom logo

Atom is a pair of related web standards for publishing and editing web resources: the Atom Syndication Format, an XML language used for web feeds, and the Atom Publishing Protocol (AtomPub), an HTTP-based protocol for creating and updating web resources. Atom was developed as a cleaner, fully specified alternative to the family of RSS formats.

History and standardisation

The project began in 2003 as a community effort led by developer Sam Ruby and others, frustrated by ambiguities in RSS 2.0. It was taken up by the Internet Engineering Task Force (IETF), which published the syndication format as RFC 4287 in December 2005 and AtomPub as RFC 5023 in 2007. Google adopted Atom for its GData APIs, and the format was widely supported by blogging platforms such as Blogger and WordPress.

Format

An Atom feed is an XML document containing a feed header (title, id, updated timestamp, author and links) and a list of entries, each with its own title, unique identifier, timestamps, summary and content, which may be text, HTML or embedded media. Compared with RSS, Atom requires unique identifiers and standardized date formats, distinguishes summaries from full content, and supports internationalisation and relative links more rigorously.

Usage

Although social media and algorithmic timelines reduced the visibility of feed readers in the 2010s, Atom (together with RSS) remains in wide use behind the scenes — for blogs, news sites, software release feeds, and notably for podcast distribution enclosures and YouTube channel feeds. Feed readers such as Feedly and NetNewsWire read both Atom and RSS.
