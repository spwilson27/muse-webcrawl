Berkeley Software Distribution

From Wikipedia, the free encyclopedia

The Berkeley Software Distribution (BSD), also known as Berkeley Unix, is a discontinued Unix operating system developed and distributed by the Computer Systems Research Group (CSRG) at the University of California, Berkeley, beginning in 1978. BSD began as a set of modifications to AT&T's Research Unix and evolved into a complete operating system.

History

Early versions of BSD were widely used in academic and workstation environments. BSD introduced many features that became standard in Unix systems, including the vi editor, the C shell, virtual memory support in 3BSD, and the implementation of TCP/IP networking in 4.2BSD (1983), which became the reference implementation of the Internet protocols. The BSD code base was gradually rewritten to remove AT&T-licensed code, culminating in the freely redistributable releases 4.3BSD Net/2 and 4.4BSD in the early 1990s, following a legal dispute with Unix System Laboratories.

Legacy

Modern descendants of BSD include the free operating systems FreeBSD, NetBSD, OpenBSD and DragonFly BSD, as well as Darwin, the core of Apple's macOS and iOS. BSD-licensed code found its way into many proprietary systems, including Microsoft Windows' TCP/IP stack. The permissive BSD licenses remain widely used in open-source software.
