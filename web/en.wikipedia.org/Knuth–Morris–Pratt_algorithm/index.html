Knuth–Morris–Pratt algorithm

The Knuth–Morris–Pratt algorithm (KMP) searches for occurrences of a pattern string within a main text string by exploiting the information in the pattern itself to avoid re-examining characters that are already known to match.

ClassString searching algorithm
InventorsDonald Knuth, Vaughan Pratt, James H. Morris
Published1977
Time complexityO(n + m)

Description

Before searching, the algorithm precomputes a "partial match" table (the failure function) recording, for each prefix of the pattern, the longest proper prefix that is also a suffix. When a mismatch occurs, the pattern is shifted according to this table so that no text character is compared more than a constant number of times.

Complexity

Preprocessing takes time proportional to the pattern length m, and the search itself takes time proportional to the text length n, giving overall linear time — an improvement over the worst case of naive search.
