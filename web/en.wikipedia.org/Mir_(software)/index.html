Mir (software)

Initial release2013

Mir is a computer display server and, since a later re-architecture, a set of libraries for building Wayland compositors, developed by Canonical for the Ubuntu Linux distribution. It was announced in March 2013 as a replacement for the X Window System in Ubuntu, intended to serve desktops, phones and tablets under Canonical's convergence strategy.

The announcement drew controversy in the Linux community because Ubuntu had previously signalled support for Wayland, and several Ubuntu derivatives declined to adopt Mir. Canonical nevertheless shipped Mir on its short-lived Ubuntu Touch devices. In 2017, with the abandonment of the Unity 8 interface and Ubuntu's return to the GNOME desktop, Canonical repositioned Mir as a Wayland compositor implementation — providing the plumbing (display, input, window management) so that desktop environments and embedded systems could be built on top of it more easily.

Uses

Mir continues in development and is used in Ubuntu Frame for kiosks and embedded displays, and underlies smaller Wayland desktops such as Miracle-WM. Its design emphasises a stable shell protocol and support for multiple client APIs.
