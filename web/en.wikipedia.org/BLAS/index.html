BLAS

The Basic Linear Algebra Subprograms (BLAS) are a specification that prescribes a set of low-level routines for performing common linear algebra operations such as vector addition, scalar multiplication, dot products, linear combinations, and matrix multiplication.

Levels

BLAS routines are grouped into three levels: Level 1 performs scalar, vector and vector–vector operations; Level 2 performs matrix–vector operations; and Level 3 performs matrix–matrix operations. Higher-level libraries such as LAPACK are built on top of BLAS.

Implementations

Because BLAS operations dominate the running time of much numerical software, hardware vendors provide highly optimised implementations. Widely used versions include OpenBLAS, Intel oneMKL, Apple Accelerate, and the GPU-oriented cuBLAS.
