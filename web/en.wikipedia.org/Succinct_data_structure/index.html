Succinct data structure

In computer science, a succinct data structure is a data structure which uses an amount of space close to the information-theoretic lower bound for representing the data, while still allowing efficient query operations. The concept was introduced by Guy Jacobson in 1989. A succinct structure occupies B + o(B) bits, where B is the information content of the data; a stronger notion, the compact data structure, allows space bounded by a constant multiple of the optimum.

Examples

Classic examples include succinct representations of bitvectors supporting rank and select queries in constant time with small auxiliary indexes; succinct trees, represented as balanced-parenthesis sequences or level-order unary degree sequences (LOUDS); and succinct graphs, tries, and text indexes. The FM-index, based on the Burrows–Wheeler transform, is a succinct full-text index widely used in bioinformatics sequence alignment.

Motivation

Succinct structures matter when data sets are so large that conventional structures, with their pointer overhead, exceed main memory or cache; a compact representation can keep more data in fast memory and speed overall processing despite more computation per access.
