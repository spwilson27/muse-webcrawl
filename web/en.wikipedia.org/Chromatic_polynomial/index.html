Chromatic polynomial

The chromatic polynomial is a graph polynomial studied in algebraic graph theory. It counts the number of ways a graph can be coloured using at most a given number of colours. More precisely, for a graph G and a positive integer λ, the chromatic polynomial P(G, λ) equals the number of proper colourings of G with λ colours — remarkably, it is a polynomial in λ.

Definition and examples

It satisfies a deletion–contraction recurrence: P(G, λ) = P(G − e, λ) − P(G / e, λ) for any edge e, with P(edgeless graph on n vertices, λ) = λⁿ. For example, a tree on n vertices has P(G, λ) = λ(λ − 1)ⁿ⁻¹, and the complete graph Kn has P(G, λ) = λ(λ − 1)⋯(λ − n + 1).

History and properties

The chromatic polynomial was introduced by George David Birkhoff in 1912 while attacking the four colour problem. It is the evaluation of the more general Tutte polynomial. Its coefficients are integers with alternating signs and encode information about the graph, such as numbers of vertices, edges, components and acyclic orientations. Evaluating P(G, λ) is #P-hard in general, except for a few special values.
