Probabilistic roadmap

The probabilistic roadmap planner (PRM) is a motion planning algorithm in robotics, which solves the problem of determining a path between a starting configuration of the robot and a goal configuration while avoiding collisions. It was introduced in the mid-1990s by Lydia Kavraki, Petr Švestka, Jean-Claude Latombe, Mark Overmars and colleagues.

Algorithm

The basic idea is to take random samples from the robot's configuration space, test them for being collision-free, and use a local planner to connect the sample configurations to nearby configurations. In a learning phase, the planner builds a graph (the roadmap) whose vertices are collision-free configurations and whose edges are feasible local paths. In the query phase, start and goal configurations are connected to the roadmap and a graph search (for example Dijkstra's algorithm or A*) finds a path between them.

Properties

PRM is probabilistically complete: if a solution exists and enough samples are taken, the probability of finding it approaches one. The roadmap is reusable for many queries in the same environment, which makes the method especially attractive for manipulators with many degrees of freedom moving among static obstacles. Variants include single-query versions, lazy collision checking (Lazy PRM), and optimal versions such as PRM*, which connect samples within a shrinking radius to guarantee asymptotic optimality.

Applications

Probabilistic roadmaps are used in robot path planning, animated characters and virtual prototyping, computational biology (for example, modelling molecular motions), and other high-dimensional search problems. Related sampling-based planners include rapidly-exploring random trees (RRTs).
