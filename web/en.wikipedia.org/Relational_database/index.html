Relational database

A relational database (RDB) is a database based on the relational model of data, first proposed by Edgar F. Codd in his 1970 paper "A Relational Model of Data for Large Shared Data Banks". In this model, data is organised into one or more relations (commonly represented as tables) of columns and rows, with a unique key identifying each row. Software used to maintain relational databases is called a relational database management system (RDBMS).

Structure

Each relation consists of tuples (rows) and attributes (columns), each attribute having a defined domain of values. A primary key uniquely identifies each tuple, and a foreign key in one table references the primary key of another, expressing relationships between data. Database normalisation organises tables to reduce redundancy and dependency. Virtually all relational systems use SQL (Structured Query Language) as their query and manipulation language.

History

Codd's model was developed at IBM, which built the prototype System R in the 1970s. The first commercial relational systems appeared around 1979–1980 (Oracle, followed by IBM's SQL/DS and DB2). Relational systems displaced earlier hierarchical and network models and came to dominate business data processing. Well-known modern RDBMSs include Oracle Database, Microsoft SQL Server, IBM Db2, MySQL, PostgreSQL, MariaDB and SQLite.

Properties

Relational systems are commonly expected to support transactions satisfying the ACID properties (atomicity, consistency, isolation, durability). Integrity constraints — including entity integrity, referential integrity and domain constraints — are declared in the schema and enforced by the system. Since the 2000s, non-relational "NoSQL" systems have gained use for some workloads, but relational databases remain the most widely used model.
