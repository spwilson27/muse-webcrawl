DocBook

DocBook is a semantic markup language for technical documentation. It was originally created as a standard for computer hardware and software documentation, and is now maintained by the DocBook Technical Committee of OASIS.

Description

DocBook is available in both SGML and XML formats and defines hundreds of elements for describing the structure and semantics of documents — books, articles, chapters, sections, code examples, commands, and glossaries — without specifying how they should be presented. Stylesheets, most commonly XSLT, transform DocBook sources into HTML, PDF, man pages, and other output formats.

Users

DocBook has been widely used in open-source projects, including the documentation of the Linux kernel utilities, GNOME, KDE, and many programming languages, as well as by commercial publishers such as O'Reilly Media in book production.
