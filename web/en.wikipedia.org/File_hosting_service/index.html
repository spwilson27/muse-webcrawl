File hosting service

A file hosting service (also called a cyberlocker, cloud file hosting, or online file storage) is an Internet hosting service designed specifically to store and distribute user files. Users upload files through a website or app; the service stores them on its servers and provides a URL by which they can be downloaded or shared, sometimes publicly and sometimes restricted by account, password, or link.

Types

Services vary in purpose: one-click hosts (such as the historical RapidShare and MegaUpload) centered on anonymous sharing links; cloud storage and synchronization services (Dropbox, Google Drive, Microsoft OneDrive, Box) centered on personal backup, sync across devices, and collaboration; and specialized hosts for images, video, code, or software distribution. Most operate a freemium model — free tiers with size, speed, or retention limits, and paid tiers offering larger storage, faster downloads, and no waiting periods.

History and controversies

File hosts flourished in the 2000s as broadband spread, partly displacing peer-to-peer file sharing for direct downloads. Because some users distributed copyrighted material, major hosts became targets of litigation and enforcement: MegaUpload was shut down by U.S. authorities in 2012 and its founder Kim Dotcom arrested in New Zealand; RapidShare, once among the world's most visited sites, shut down in 2015. Hosts generally rely on safe-harbor provisions (such as the U.S. DMCA) and operate notice-and-takedown systems for infringing content.

Related concepts

File hosting differs from file sharing (peer-to-peer transfer between users) and from dedicated cloud storage, though the categories overlap. Modern collaboration platforms have largely absorbed the role of the classic cyberlocker for legitimate file transfer.
