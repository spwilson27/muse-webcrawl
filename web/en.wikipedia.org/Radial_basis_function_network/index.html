Radial basis function network

In the field of mathematical modelling, a radial basis function network is an artificial neural network that uses radial basis functions as activation functions. The output of the network is a linear combination of radial basis functions of the inputs and neuron parameters. RBF networks were introduced in this form by Broomhead and Lowe in 1988, building on earlier work on radial basis functions for exact interpolation.

Architecture

A typical RBF network has three layers: an input layer, a single hidden layer in which each neuron computes a radial basis function — usually a Gaussian, φ(r) = exp(−βr²) — of the distance between the input vector and the neuron's centre, and a linear output layer. Because the hidden units respond locally to inputs near their centres, the network is sometimes described as a locally tuned function approximator.

Training

Centre positions are often selected by clustering the training data (for example with k-means), basis-function widths set by heuristics, and output weights solved by linear least squares, which makes training much faster than backpropagation through multilayer perceptrons. Applications include function approximation, time-series prediction, system identification, and classification. RBF networks are closely related to kernel methods and to the kernel trick used in support vector machines.
