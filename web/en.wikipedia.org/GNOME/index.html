GNOME

GNOME
Initial release: 3 March 1999
Written in: C, Python, Vala, and others
Operating system: Linux and other Unix-like systems
License: GPL and LGPL
Type: Desktop environment

GNOME is a free and open-source desktop environment for Linux and other Unix-like operating systems. It is the default desktop of many major distributions, including Fedora, Ubuntu, Debian, and Red Hat Enterprise Linux, and is developed by the GNOME Project.

History

The project was announced in 1997 by Miguel de Icaza and Federico Mena, in part to provide a desktop built entirely on free software at a time when KDE depended on the then-proprietary Qt toolkit. Early releases were written using the GTK toolkit developed for the project. GNOME 2 (2002) adopted a conventional desktop metaphor; GNOME 3 (2011) introduced the GNOME Shell interface centred on an activities overview, a change that prompted forks and alternative shells such as Cinnamon and MATE.

Design and components

GNOME emphasises simplicity and consistency through its Human Interface Guidelines. Core components include the Mutter window manager and compositor, the Files file manager, Settings, and a suite of core applications. The desktop has supported the Wayland display protocol since the mid-2010s.
