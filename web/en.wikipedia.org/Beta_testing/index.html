Beta testing

Beta testing is the phase of software development in which a nearly complete version of a product, called a beta version, is released to a selected group of external users for evaluation under real-world conditions. It follows alpha testing and precedes the general release.

Types

Closed beta testing limits participation to an invited group, while an open beta (or public beta) allows anyone to participate. Testers report bugs, usability problems and feature feedback, which developers use to stabilise the product before release.

Modern practice

With web services and continuous deployment, beta features are often released gradually behind feature flags, and products such as Google's Gmail famously remained in "beta" for years despite wide public use.
