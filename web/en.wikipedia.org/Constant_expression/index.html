Constant expression

A constant expression is an expression in a programming language that can be evaluated at compile time rather than at run time. Languages specify which operations and values may appear in constant expressions; their results can be used wherever a compile-time constant is required, such as array bounds, case labels and template arguments.

In C and C++

In C, an integer constant expression may contain integer constants, enumeration constants, character constants and sizeof expressions, but no assignments or function calls. C++ greatly extended the notion with constexpr (introduced in C++11), which allows functions and variables to be declared for evaluation during compilation, and later consteval and constinit. Compile-time evaluation enables zero-cost abstractions, static lookup tables and stronger static checking.

In other languages

Java defines constant expressions built from literals and constant variables, used in case labels and annotations. Rust provides const items and const generics evaluated at compile time. In all cases, restricting what may appear in a constant expression guarantees that evaluation is deterministic and free of run-time side effects.

Uses

Constant expressions support static assertions, fixed-size data structures, bit masks, configuration values and metaprogramming, and shifting work to compile time can improve run-time performance.
