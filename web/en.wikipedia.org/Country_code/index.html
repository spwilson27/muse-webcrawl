Country code

Main standardISO 3166
FormsAlpha-2, alpha-3, numeric
Other systemsITU calling codes, IOC codes, ccTLDs

A country code is a short alphabetic or numeric identifier assigned to a country or territory for use in data processing, communications, and international standardisation. Country codes allow unambiguous, language-independent reference to places in everything from internet domains to bank transfers and shipping.

ISO 3166

The best-known system is ISO 3166, maintained by the International Organization for Standardization. ISO 3166-1 defines three sets of codes for each country: alpha-2 (two letters, e.g. FR for France), alpha-3 (three letters, e.g. FRA), and numeric (three digits, based on UN Statistics Division codes, e.g. 250). ISO 3166-2 gives codes for subdivisions such as states and provinces, and ISO 3166-3 covers formerly used codes for countries that have changed name or status.

Other systems

Related but distinct systems include international telephone calling codes assigned by the ITU (e.g. +1 for the North American Numbering Plan, +44 for the United Kingdom), Internet country code top-level domains (ccTLDs), which are generally based on ISO alpha-2 codes, IOC country codes used at the Olympic Games (which differ in some cases, e.g. GER for Germany), FIFA codes, and vehicle registration codes.

Exceptions

A few ccTLDs do not match modern ISO codes — .uk is used although the ISO alpha-2 code for the United Kingdom is GB (reserved exceptionally in ISO). Codes also change as countries merge, split, or rename; for example, the Soviet Union's SU remains exceptionally reserved.
