Encapsulation (computer networking)

In computer networking, encapsulation is the method of hiding the internal structure of data by adding headers (and sometimes trailers) as information passes down a protocol stack. Each layer treats the data from the layer above as an opaque payload and wraps it with its own control information, producing the protocol data units exchanged with the corresponding layer on another host.

Process

Sending a message typically involves the application data being segmented by the transport layer (for example into TCP segments), which are then encapsulated as packets by the network layer (for example IP), which are in turn encapsulated as frames by the link layer, each step adding a header. The receiving host reverses the process, stripping headers layer by layer — decapsulation — and passing the payload upward.

Examples

Encapsulation underlies tunnelling protocols such as GRE, IPsec and VXLAN, in which whole packets are carried inside other packets. The related concept in object-oriented programming is information hiding through encapsulation of state and behaviour.
