C standard library

The C standard library, or libc, is the standard library for the C programming language, as specified in the ISO C standard. It provides macros, type definitions and functions for tasks such as string handling, mathematical computation, input/output processing and memory management.

Contents

The library is organised into header files. Key headers include <stdio.h> for input and output (printf, fopen), <stdlib.h> for memory allocation, conversion and process control, <string.h> for string and memory manipulation, <math.h> for mathematical functions, <time.h> for date and time, and <ctype.h> for character classification. Later standards added headers such as <stdint.h>, <stdbool.h> and <threads.h>.

Implementations

Major implementations include glibc on GNU/Linux systems, musl, the Microsoft C run-time library, and the BSD libc. The standard library forms the foundation on which most C programs, and the runtimes of many other languages, are built.
