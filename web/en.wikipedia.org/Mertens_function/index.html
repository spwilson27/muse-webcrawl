Mertens function

In number theory, the Mertens function M(x) is the sum of the Möbius function μ(k) for all integers k up to x: that is, M(x) = μ(1) + μ(2) + … + μ(x). It is named after the Polish mathematician Franz Mertens, who studied it in the 1890s. Because the Möbius function takes values −1, 0 and 1, M(x) changes slowly and behaves in an irregular, quasi-random way.

Mertens conjecture

Mertens conjectured that the absolute value of M(x) is always less than the square root of x. The conjecture, if true, would have implied the Riemann hypothesis. It was, however, disproved in 1985 by Andrew Odlyzko and Herman te Riele, who showed non-constructively — using computations with high-precision values of the Riemann zeta function — that M(x)/√x exceeds 1 somewhere, and later work showed it also falls below −1. The exact location of a counterexample remains unknown, as it lies far beyond the ranges that have been computed directly.

Relation to the Riemann hypothesis

The Riemann hypothesis is equivalent to the statement that M(x) grows more slowly than x^(1/2+ε) for every ε > 0. Values of the Mertens function have been computed for x up to and beyond 10^16, and its growth is a central example of how the distribution of prime numbers connects to analytic properties of the zeta function.
