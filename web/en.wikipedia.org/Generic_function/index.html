Generic function

In computer programming, a generic function is a function that consists of a collection of methods, each specialised for particular classes of arguments. When the generic function is called, the appropriate method is selected — or several methods are combined — based on the classes of the arguments. The idea was developed most fully in the Common Lisp Object System (CLOS), where generic functions are the primary vehicle of polymorphism.

Method dispatch

Unlike message-passing object systems, where a method belongs to a single class and is selected by the class of one receiver, a generic function can dispatch on the classes of all of its required arguments — a feature called multiple dispatch. For example, a generic function collide might have methods for (asteroid, spaceship), (asteroid, asteroid) and (spaceship, spaceship) argument pairs, each implementing different behaviour.

Method combination

CLOS provides standard method combination: primary methods do the main work, while :before, :after and :around auxiliary methods add behaviour around a call to the next most specific method via call-next-method. The applicable methods are ordered by the class precedence lists of the argument classes.

Other languages

The concept appears under various names elsewhere: Julia's functions are generic with multiple dispatch as the language's central paradigm; Dylan, Cecil and other languages adopt similar designs. In C++, templates provide compile-time genericity but are not generic functions in the CLOS sense.
