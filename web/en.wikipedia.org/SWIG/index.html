The Simplified Wrapper and Interface Generator (SWIG) is an open-source software tool used to connect computer programs written in C and C++ with scripting languages and other high-level languages such as Python, Perl, Ruby, Tcl, Java, C# and JavaScript.

How it works

SWIG reads an interface file declaring the functions and data structures to be exposed, then generates wrapper code ("glue code") that compiles into an extension module for the target language. This allows existing C/C++ libraries to be called from scripting languages without rewriting them, while handling type conversion and memory management conventions.

History

SWIG was created by David Beazley at Los Alamos National Laboratory in 1996 to make scientific simulation codes accessible from scripting languages, and it remains widely used for wrapping large native libraries.
