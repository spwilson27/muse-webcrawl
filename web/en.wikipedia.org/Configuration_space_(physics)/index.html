Configuration space (physics)

The configuration space of a double pendulum is a torus.

In classical mechanics, the parameters that define the configuration of a system are called generalised coordinates, and the space defined by these coordinates is called the configuration space of the physical system. It is a mathematical abstraction in which each possible arrangement of the system corresponds to exactly one point, and the evolution of the system traces a path through the space.

Examples

A single particle moving in three dimensions has configuration space R³. For N particles the space is R³ᵀ, of dimension 3N. Constraints reduce the dimension: a particle constrained to a sphere has configuration space S², a rigid body requires six coordinates (three positions and three angles), and the configuration space of a double pendulum is a torus, since it is specified by two angles. Where coordinates are angles or the system has nontrivial topology, the configuration space is a manifold rather than Euclidean space.

Use in mechanics

Configuration space is the arena of Lagrangian mechanics, in which the Lagrangian is a function on the tangent bundle of the configuration space, pairing generalised positions and velocities. Adding the conjugate momenta extends configuration space to phase space, the setting of Hamiltonian mechanics. In quantum mechanics, wavefunctions are defined on configuration space, and its structure—especially for identical particles—leads to exchange symmetry and the distinction between bosons and fermions.

Related fields

The same idea appears in robotics, where a robot's configuration space (C-space) of joint angles is used for motion planning, and in statistical mechanics, where points in configuration space are weighted by the Boltzmann factor in computing partition functions.
