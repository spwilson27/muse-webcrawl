Code duello

A duel fought under the code duello, with seconds acting as intermediaries

A code duello is a set of rules for a one-on-one combat, or duel. Codes duello regulate not only the actual combat but also the protocol for challenging, apology, and the roles of the seconds, in order that a duel be carried out in a way considered honourable. Duelling was a practice of the European aristocracy and officer class that spread to the Americas.

The Irish code of 1777

The most famous code is the Irish Code Duello, a set of 25 rules adopted at Clonmel in 1777 by representatives of Tipperary, Galway, Sligo, Mayo and Roscommon. It prescribed, among other things, that the first offence requires the first apology, that challenges must be delivered by seconds, that no apology can be received after the parties meet without an exchange of fires, and that seconds should attempt reconciliation before bloodshed. The code was widely reprinted and imitated in Britain and the United States.

Other codes and decline

The French comte d'Artois's and later the comte de Châteauvillard's treatise of 1836 formalized French practice; in the American South, former governor John Lyde Wilson published a Code of Honor in 1838. Famous duels under such codes include the Burr–Hamilton duel of 1804. Duelling was progressively outlawed and socially discredited during the nineteenth century, surviving longest in France and Germany, and the codes duello became historical documents of the etiquette of honour.
