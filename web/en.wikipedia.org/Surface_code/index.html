Surface code

From Wikipedia, the free encyclopedia

The surface code is a leading family of quantum error-correcting codes used in quantum computing. It encodes a logical qubit into many physical qubits arranged on a two-dimensional lattice, using local measurements of neighbouring qubits to detect errors without disturbing the encoded information. The surface code is notable for its high error threshold — around one percent per operation under standard noise models — and for requiring only nearest-neighbour interactions on a planar grid, which makes it well suited to superconducting and other solid-state qubit platforms.

History

The surface code grew out of Alexei Kitaev's toric code, introduced in the late 1990s, in which qubits sit on the edges of a torus and stabilizer measurements are performed on each vertex and face. Later work by many researchers developed planar versions with boundaries — the surface code proper — together with practical decoding methods, fault-tolerant logical operations by lattice surgery and braiding of defects, and resource estimates for large-scale algorithms.

Structure

In a standard implementation, data qubits occupy the sites (or edges) of a square lattice, and interleaved measurement qubits (ancillas) each couple to up to four neighbouring data qubits. Two kinds of stabilizer checks are measured repeatedly: plaquette-type (Z) checks and star-type (X) checks. Comparing successive rounds of measurement outcomes reveals a syndrome: a pattern of changed checks that indicates where errors have occurred, while the actual data remain unmeasured. Error correction cycles repeat on the timescale of the hardware — in superconducting implementations, roughly every microsecond.

Decoding

A classical decoder processes the syndrome history to infer the most likely set of physical errors and applies (or tracks) a corresponding correction. The most widely used algorithm is minimum-weight perfect matching, which pairs up syndrome defects on a graph with weights derived from error probabilities. Neural-network and other decoders have also been studied. Errors are corrected successfully as long as they do not combine into chains connecting opposite boundaries of the lattice, which would enact an undetectable logical error.

Logical qubits and scaling

The code distance d of a patch is the minimum number of physical errors needed to cause a logical error. The logical error rate falls exponentially with distance as long as the physical error rate is below threshold, at the cost of roughly 2d² physical qubits per logical qubit. Practical fault-tolerant computations may require distances of 25 or more, hence on the order of a thousand or more physical qubits per logical qubit, plus additional patches — "qubit factories" — devoted to distilling magic states for non-Clifford gates.

Experimental progress

In 2023, Google Quantum AI reported that scaling a surface code logical qubit from distance 3 to distance 5 reduced the logical error rate, a milestone toward demonstrating error suppression by scaling. In December 2024, Google reported with its Willow processor a distance-7 logical qubit whose error rate decreased by a factor of about two with each increase in code distance (3, 5, 7), operating below threshold with real-time decoding.
