Quantum phase estimation algorithm

In quantum computing, the quantum phase estimation algorithm (QPE) is a quantum algorithm used to estimate the phase (eigenvalue) of an eigenvector of a unitary operator. Given a unitary operator U and an eigenstate |u⟩ with U|u⟩ = e2πiθ|u⟩, the algorithm estimates θ to within additive error ε using O(1/ε) applications of U.

Algorithm

The algorithm uses two registers. The first holds n counting qubits, prepared in a uniform superposition by Hadamard gates; controlled applications of U2j then kick the unknown phase back onto the counting register, encoding θ in binary. Applying the inverse quantum Fourier transform to the first register converts that phase into a computational-basis state that, when measured, yields an n-bit approximation to θ with high probability.

Applications

Phase estimation is a core subroutine of many quantum algorithms, including:

  • Shor's algorithm for integer factorisation and discrete logarithms (order finding);
  • The Harrow–Hassidim–Lloyd algorithm for solving linear systems of equations;
  • Quantum chemistry, estimating molecular ground-state energies;
  • Quantum counting and amplitude estimation.

History

The algorithm was first described by Alexei Kitaev in 1995 and developed by others; it builds on the quantum Fourier transform introduced in the context of period finding.
