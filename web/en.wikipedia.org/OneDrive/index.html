OneDrive

DeveloperMicrosoft
LaunchedAugust 1, 2007 (as SkyDrive)
TypeFile hosting / cloud storage
PlatformsWindows, macOS, Android, iOS, web

Microsoft OneDrive is a cloud storage and file synchronization service operated by Microsoft. It allows users to store files online, synchronize them across devices, and share them with others. Launched in 2007 as Windows Live Folders and long known as SkyDrive, it was renamed OneDrive in 2014 after Microsoft lost a trademark dispute with the British broadcaster BSkyB.

Features

OneDrive is integrated with Windows and Microsoft 365: documents created in Office apps save to OneDrive by default for subscribers, enabling real-time co-authoring and version history. Other features include Files On-Demand (placeholders that download on use), automatic photo backup from phones, a ransomware-protected "Personal Vault," and sharing via links with permission controls.

Storage plans

A free tier offers a limited amount of storage (5 GB in recent years), while Microsoft 365 subscriptions include 1 TB per user. OneDrive for Business, built on SharePoint, provides storage for organizations with administrative controls and higher quotas.

History

The service evolved through names including Windows Live SkyDrive and SkyDrive Pro. Storage allowances have changed over time; a controversial 2015 plan to eliminate unlimited storage for subscribers was partly reversed after customer backlash.
