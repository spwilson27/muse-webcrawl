Screen tearing


Image placeholder: Screen tearing

Screen tearing is a visual artifact in display technology where a display device shows information from multiple frames in a single screen draw, so the image appears split or misaligned along a horizontal line (or lines). The effect occurs when the video feed to the device is not synchronized with the device's refresh cycle — typically when a new frame is delivered to the display partway through it scanning out the previous frame.

Causes and remedies

Tearing is common in video games and video playback when the frame rate produced by a graphics processing unit differs from the monitor's refresh rate, especially when it exceeds it. The traditional remedy is vertical synchronization (VSync), which forces the GPU to present frames only at the start of a refresh interval, at the cost of added input latency and stutter when frame rates fall below the refresh rate. Adaptive synchronization technologies — NVIDIA G-Sync and AMD FreeSync, standardized as VESA Adaptive-Sync — instead vary the display's refresh rate to match the GPU's output, eliminating tearing without a fixed cadence.
