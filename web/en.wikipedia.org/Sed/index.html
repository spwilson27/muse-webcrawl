sed

sed performing a substitution on a stream of text in a terminal.

sed ("stream editor") is a Unix utility that parses and transforms text, using a compact programming language developed by Lee E. McMahon of Bell Labs in 1973–74. It was one of the earliest tools to support regular expressions and remains ubiquitous in shell scripts for one-off, non-interactive text editing, such as find-and-replace operations over files or piped output.

Operation

sed reads input sequentially, line by line, into a buffer called the pattern space. For each line it applies the commands in the script whose address — a line number or a regular-expression match — selects that line, then prints the result. A second buffer, the hold space, allows limited state to be carried between lines. Although sed scripts can be written with branching and labels and the language is Turing-complete, in practice it is used for short substitutions and deletions.

Usage

The most common command is substitution, s/regexp/replacement/. For example:

sed 's/old/new/g' file.txt

replaces every occurrence of "old" with "new". The -i option (GNU sed) edits files in place, and -n suppresses automatic printing so that only lines selected by the p command are output, making sed act like a filter similar to grep.

History and influence

sed was inspired by the interactive editor ed and by the earlier qed editor. Its substitution syntax and regex flavour influenced later tools including Perl and AWK. GNU sed, maintained by the Free Software Foundation, is the most widely used implementation, with additional extensions beyond the POSIX standard.
