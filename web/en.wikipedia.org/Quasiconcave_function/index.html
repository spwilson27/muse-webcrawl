Quasiconcave function

In mathematics and economics, a quasiconcave function is a real-valued function defined on an interval or a convex subset of a real vector space such that the inverse image of any set of the form (a, ∞) is a convex set. Intuitively, a quasiconcave function first rises and then falls (it may have flat stretches), and every upper level set is convex.

Definition and properties

A function f is quasiconcave if f(θx + (1−θ)y) ≥ min{f(x), f(y)} for all x, y and θ in [0,1]. Every concave function is quasiconcave, but not conversely: for example, any monotonic function is both quasiconcave and quasiconvex, and √x is quasiconcave without being concave on all domains in higher dimensions.

Applications

In microeconomics, utility functions are commonly assumed quasiconcave, which guarantees that upper contour sets (sets of consumption bundles at least as good as a given one) are convex — the mathematical expression of a preference for balanced bundles.
