Simplex algorithm

In mathematical optimisation, the simplex algorithm (or simplex method) is a widely used procedure for solving linear programming problems. It was developed by George Dantzig in 1947 and is named for the fact that it can be interpreted geometrically in terms of simplices. In 2000 it was listed among the top ten algorithms of the twentieth century.

Overview

A linear programming problem asks for the point maximising (or minimising) a linear objective function over a convex polytope defined by linear equality and inequality constraints. Because the objective is linear, an optimum — if one exists — occurs at a vertex (corner point) of the polytope, called a basic feasible solution. The simplex algorithm moves from vertex to adjacent vertex along edges, at each step choosing an entering variable that improves the objective and a leaving variable that preserves feasibility (a "pivot"). It stops when no improving edge exists, certifying optimality; it also detects infeasible and unbounded problems.

Implementation and variants

In practice the algorithm is implemented with the revised simplex method and sparse LU factorisation of the basis matrix, with pivot rules such as Bland's rule to avoid cycling in degenerate problems, and pricing strategies such as steepest edge. The dual simplex method, used heavily in mixed-integer programming and after adding cuts or constraints, maintains dual feasibility instead.

Complexity

Although the simplex algorithm can require exponentially many steps in the worst case (as shown by the Klee–Minty cube in 1972), it is extremely fast in practice — a phenomenon explained partly by smoothed analysis (Spielman and Teng, 2001). Polynomial-time alternatives such as Khachiyan's ellipsoid method (1979) and Karmarkar's interior-point method (1984) compete with simplex on very large problems, but the simplex algorithm remains a cornerstone of commercial solvers.
