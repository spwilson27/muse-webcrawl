Shared memory

Shared memory is memory that may be simultaneously accessed by multiple programs.

In computer science, shared memory is memory that may be simultaneously accessed by multiple programs with an intent to provide communication among them or avoid redundant copies. Shared memory is an efficient means of passing data between programs. Depending on context, programs may run on a single processor or on multiple separate processors.

In hardware

In computer hardware, shared memory refers to a (typically large) block of random access memory that can be accessed by several different central processing units in a shared-memory multiprocessor system. Such systems use uniform memory access (UMA) or non-uniform memory access (NUMA) architectures, and must solve problems of cache coherence so that processors see consistent data. Shared memory is also used in many GPU and integrated graphics designs, where the graphics processor shares system RAM with the CPU.

In software

In software, shared memory is a method of inter-process communication (IPC): a region of memory is mapped into the address spaces of two or more processes, so that data written by one is immediately visible to the others without copying through the kernel. Unix-like systems expose it through POSIX shared memory objects and the older System V IPC calls (shmget, shmat), while Windows provides memory-mapped files. Because access is concurrent, programs typically coordinate with semaphores, mutexes or other synchronisation primitives to avoid race conditions. Shared memory is usually the fastest IPC mechanism, which makes it popular in databases, message-passing frameworks and high-performance computing.
