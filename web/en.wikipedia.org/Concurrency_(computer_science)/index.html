Concurrency (computer science)

In computer science, concurrency is the ability of different parts or units of a program, algorithm, or problem to be executed out-of-order or in partial order, without affecting the outcome. This allows for parallel execution of the concurrent units, which can significantly improve overall speed of the execution in multi-processor and multi-core systems.

Concepts

Concurrent systems rely on abstractions such as processes, threads, and coroutines. Because concurrent computations may share resources, mechanisms such as locks, semaphores, monitors, and message passing are used to coordinate access and avoid race conditions, deadlocks, and starvation.

Models of concurrency

Several formal models describe concurrent computation, including the actor model, process calculi such as CSP and the π-calculus, and Petri nets. Languages such as Erlang, Go, and Rust build concurrency primitives into the language or its standard idioms.

Concurrency versus parallelism

Concurrency is a property of a program's structure — the composition of independently executing computations — whereas parallelism is about actually running multiple computations simultaneously on separate hardware. A concurrent program may run on a single core through interleaving.

Problems

Concurrent programming is notoriously error-prone because the number of possible interleavings grows combinatorially. Formal verification, model checking, and ownership-based type systems are among the techniques used to manage this complexity.
