Extended Euclidean algorithm

In arithmetic and computer programming, the extended Euclidean algorithm is an extension to the Euclidean algorithm, and computes, in addition to the greatest common divisor (gcd) of two integers a and b, also the coefficients of Bézout's identity, which are integers x and y such that ax + by = gcd(a, b).

Extended Euclidean algorithm
Computes: gcd and Bézout coefficients
Complexity: O(h) divisions, h = number of digits

Description

The extended Euclidean algorithm is useful when a and b are coprime, since x is then the modular multiplicative inverse of a modulo b, and y is the multiplicative inverse of b modulo a.

Standard and recursive versions

The algorithm can be implemented iteratively with sequences s and t tracking the remainders, or recursively, returning the gcd together with the Bézout coefficients.

Applications

It is used in RSA key generation, in solving linear Diophantine equations, and in computing inverses in modular arithmetic.
