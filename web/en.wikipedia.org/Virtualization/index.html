Virtualization
Key technology: hypervisor (type 1 bare-metal, type 2 hosted)
Forms: hardware, operating-system (containers), desktop, network, storage virtualization
Products: VMware ESXi, Hyper-V, KVM, Xen

Virtualization is the creation of a virtual — simulated — version of something, such as a computer, operating system, storage device or network, rather than a physical one. Hardware virtualization lets several independent virtual machines (VMs), each running its own operating system, share a single physical host under the control of a hypervisor.

History

The concept began with IBM mainframes of the 1960s–70s (CP/CMS), which partitioned one machine among many users. On x86 hardware, VMware's products from 1999 onwards made virtualization mainstream, and hardware support (Intel VT-x, AMD-V) removed the main performance obstacles. Virtualization underpins modern cloud computing, enabling server consolidation, live migration, snapshots, and rapid provisioning.

Related forms

Operating-system-level virtualization (containers, e.g. Docker) shares one kernel among isolated user spaces, trading stronger isolation for density and speed. Desktop virtualization, application virtualization, and network functions virtualization apply the same abstraction principle at other layers.
