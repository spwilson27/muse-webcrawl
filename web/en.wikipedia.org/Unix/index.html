Unix (trademarked as UNIX) is a family of multitasking, multi-user computer operating systems that derive from the original AT&T Unix, whose development started in 1969 at the Bell Labs research center by Ken Thompson, Dennis Ritchie, and others.

Initially intended for use inside the Bell System, AT&T licensed Unix to outside parties in the late 1970s, leading to a variety of academic and commercial Unix variants from vendors including the University of California, Berkeley (BSD), Microsoft (Xenix), Sun Microsystems (SunOS/Solaris), HP (HP-UX) and IBM (AIX). The Open Group owns the UNIX trademark and certifies conformance to the Single UNIX Specification.

History

Unix grew out of the Multics project, from which Bell Labs withdrew in 1969. Thompson wrote a first version for a little-used PDP-7, and the system was jokingly named "Unics" (Uniplexed Information and Computing Service), a pun on Multics, before becoming "Unix". In 1972–73 the system was rewritten in the new C programming language, an unusual step at the time that made Unix far easier to port to other hardware. Versions V6 (1975) and V7 (1979) spread widely through universities, and Berkeley's BSD releases added virtual memory, TCP/IP networking and the vi editor.

In the 1980s and 1990s the "Unix wars" between AT&T's System V and the BSD-derived and Open Software Foundation camps fragmented the market. Standardisation efforts produced POSIX and the Single UNIX Specification. Meanwhile Unix-like systems not derived from AT&T code — notably Linux (1991) and the BSD descendants — carried Unix design ideas to near-universal adoption; Apple's macOS is a certified Unix built on the Darwin system.

Design

The Unix philosophy, summarised by Doug McIlroy, holds that programs should do one thing and do it well, work together, and handle text streams as a universal interface. Central design elements include a hierarchical file system in which devices and inter-process communication appear as files; pipelines connecting program output to input with the pipe operator; a shell as both command interpreter and scripting language; and a large set of small utilities. The system's portability, multi-user time-sharing and plain-text configuration made it foundational for servers, workstations, and the development of the Internet.
