OpenMP

OpenMP (Open Multi-Processing) is an application programming interface (API) for shared-memory multiprocessing programming in C, C++ and Fortran on many platforms. It consists of compiler directives, library routines and environment variables that let programmers incrementally parallelise existing serial code, and is maintained by the OpenMP Architecture Review Board, a consortium of hardware and software vendors.

Model

OpenMP uses a fork–join model: a program begins with a single master thread, which forks teams of threads at parallel regions and joins them again at the end of the region. In C and C++, parallelism is expressed with pragmas — for example #pragma omp parallel for divides the iterations of a loop among threads. Programmers control the sharing of variables (shared or private clauses) and synchronisation (barriers, critical sections, atomics, reductions).

Features and versions

The first specification appeared in 1997 for Fortran, with C/C++ support in 1998. Subsequent versions added task parallelism (3.0, 2008), support for accelerators and GPUs through target offloading directives (4.0, 2013), and further device, tasking and memory features in versions 4.5, 5.0 (2018), 5.1, 5.2 and 6.0. OpenMP is widely used in high-performance computing, engineering simulation and scientific codes, where it complements message-passing systems such as MPI: MPI distributes work between machines, OpenMP among cores within a node.
