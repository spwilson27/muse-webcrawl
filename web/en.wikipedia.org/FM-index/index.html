FM-index

TypeCompressed full-text index (data structure)
Introduced2000, by Paolo Ferragina and Giovanni Manzini
Based onBurrows–Wheeler transform, suffix array
SpaceNear the information-theoretic entropy of the text
ApplicationsSequence alignment (Bowtie, BWA), text search

In computer science, an FM-index is a compressed full-text substring index based on the Burrows–Wheeler transform, with similarities to a suffix array. It was created by Paolo Ferragina and Giovanni Manzini in 2000; its name stands for "Full-text index in Minute space". It can find the number of occurrences of a pattern within a compressed text, and locate the position of each occurrence, while occupying space roughly proportional to the size of the compressed text itself.

Structure

For a text T, the FM-index stores the Burrows–Wheeler transform BWT(T) in a wavelet tree (or similar rank-supporting structure), together with two auxiliary tables: C[c], the number of characters in T lexicographically smaller than c, and Occ(c, k), the number of occurrences of character c in the first k positions of the transform. A sampled suffix array allows positions to be recovered. Rank queries on the BWT support the central operation known as backward search.

Searching

Backward search processes the pattern from its last character to its first, maintaining an interval of suffix-array rows prefixed by the substring processed so far. Each step updates the interval using the LF-mapping: LF(i) = C[BWT[i]] + Occ(BWT[i], i). Counting the occurrences of a pattern of length m takes O(m) rank queries; locating each occurrence additionally requires following LF steps until a sampled suffix position is reached.

Applications

The FM-index underlies widely used bioinformatics tools. The short-read aligners Bowtie and BWA (in its BWA-backtrack and BWA-MEM modes) index reference genomes with FM-index variants, enabling fast alignment of billions of DNA reads on ordinary hardware. FM-indexes are also used in general-purpose full-text search libraries and in compressed data structures research, including run-length FM-indexes optimized for highly repetitive text collections such as many related genomes.
