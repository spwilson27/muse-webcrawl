Job scheduler

A job scheduler is a computer application for controlling unattended background program execution of jobs. This is commonly called job scheduling, to distinguish it from other kinds of scheduling. Job schedulers may run jobs in sequences determined by triggers — such as times, events, or completion of other jobs — and manage dependencies, retries, and resource allocation across many machines.

Overview

Early mainframe systems relied on operators to submit batch jobs; modern schedulers automate this entire workflow, providing calendars, dependency graphs, alerting, and audit trails for business-critical processing such as payroll, billing, and data pipelines. Basic operating-system facilities include Unix cron and at, systemd timers, and the Windows Task Scheduler; enterprise and cluster schedulers include products such as Control-M, AutoSys, Slurm (for high-performance computing), Kubernetes CronJobs, and workflow tools like Apache Airflow.

Key features

  • Time-based and event-based triggers
  • Job dependency and workflow (DAG) management
  • Monitoring, error handling, and automatic restarts
  • Load balancing and resource management
  • Priorities, backfilling, and fair-share policies
