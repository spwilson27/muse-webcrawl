Windows 11 is a major release of the Windows NT operating system, developed by Microsoft and released on October 5, 2021. It is the successor to Windows 10 and is available as a free upgrade for compatible Windows 10 devices.

Features

Windows 11 introduced a redesigned user interface with a centred Start menu and taskbar, rounded window corners, and new default themes. It added Snap Layouts for window management, Widgets, integration of Microsoft Teams chat (later removed), and an updated Microsoft Store. Subsystems include the Windows Subsystem for Linux and, for a time, the Windows Subsystem for Android, which was deprecated in 2024. Later updates added the Copilot AI assistant and generative features for supported hardware.

System requirements

The release raised official requirements considerably: a 64-bit processor of 1 GHz or faster with two or more cores from supported generations, 4 GB of RAM, 64 GB of storage, UEFI firmware with Secure Boot, and a Trusted Platform Module (TPM) 2.0. These requirements left many older but still-used PCs officially unsupported, drawing criticism; installation workarounds exist but are unsupported.

Reception

Reviews praised the visual refresh and window management while criticising the hardware requirements, taskbar regressions compared with Windows 10, and account sign-in requirements during setup. Adoption was slower than Windows 10's initial uptake but grew steadily as new PCs shipped with the system.
