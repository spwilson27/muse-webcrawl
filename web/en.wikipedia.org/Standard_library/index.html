Standard library

In computer programming, a standard library is the library made available across implementations of a programming language. It provides definitions for commonly used algorithms, data structures, and mechanisms for input and output.

Contents

Standard libraries typically include string and file handling, collections and containers, mathematics functions, date and time facilities, and concurrency primitives. The C standard library, the Python standard library, and Java's class library are prominent examples.

Role

Because the standard library is specified alongside the language, programs can rely on it being present in every conforming environment, increasing portability. Features not in the core language are often delegated to the standard library to keep the language itself small.
