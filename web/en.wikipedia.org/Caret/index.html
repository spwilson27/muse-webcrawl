Caret

The caret character (^) (placeholder)

^

The caret (^) is a grapheme with a variety of uses in typography, proofreading, mathematics, and computing. The name comes from the Latin caret, "it is lacking", because proofreaders used the mark to show where a missing word or punctuation should be inserted in a text. In ASCII the character is code 94 (hexadecimal 5E), where it is also known as the circumflex accent, "hat", or "up-arrow".

Uses

  • Proofreading — a caret below the line indicates the insertion point for material written above it.
  • Mathematics — placed over a symbol, the "hat" denotes a unit vector (x̂) or an estimator (θ̂); in inline text, a caret before a number denotes exponentiation, e.g. 2^3 = 8.
  • Computing — in regular expressions, ^ anchors a match to the start of a line or string; in many programming languages it is the bitwise XOR operator (and logical XOR in some); in C-derived languages it also appears in other roles. In caret notation, control characters are written as ^A, ^C, etc. In command-line interfaces it can represent the home or parent directory in some contexts, and in emoticons it forms "happy eyes" (^^).
  • Dictionaries and linguistics — the circumflex-like mark indicates vowel length or pitch in some transcription systems.

Confusion with similar marks

The caret is distinct from the circumflex diacritic used over letters (as in French hôtel), from the wedge symbol (∧) used in logic, and from the text cursor also called a "caret" in graphical user interfaces — the blinking line indicating where typed text will appear, named after the proofreading mark.
