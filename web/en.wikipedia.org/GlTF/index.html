Type3D scene and model format

glTF (Graphics Library Transmission Format) is a standard file format for three-dimensional scenes and models, developed by the Khronos Group. Designed as an efficient, interoperable delivery format for 3D content — often described as "the JPEG of 3D" — it stores scene structure in JSON with binary buffers for geometry, animation and texture data, minimising both file size and runtime processing.

Versions and structure

glTF 1.0 was released in 2015, growing out of work at Cesium. glTF 2.0, published in 2017, added physically based rendering (PBR) materials as a core feature and became an ISO standard (ISO/IEC 12113:2022). A glTF file describes a scene graph of nodes with meshes, materials, skins, cameras and animations; geometry is stored in binary buffers accessed via buffer views and accessors that mirror GPU data layouts, so content can be rendered with minimal conversion. The binary container variant, GLB, packs the JSON and all resources into a single file.

Adoption

glTF is widely supported in game engines, 3D tools and web frameworks including three.js, Babylon.js, Blender, Unity and Unreal Engine, and is used for product visualisation, augmented reality (including Apple's related usdz ecosystem comparisons), e-commerce and digital twins. Extensions add features such as Draco mesh compression, KTX2/Basis textures, and advanced materials including clearcoat, transmission and volume effects.
