Picard theorem

In complex analysis, the Picard theorems, named after the French mathematician Charles Émile Picard, are two related results about the range of values of analytic functions.

Little Picard theorem

The little Picard theorem states that if a function f is entire and non-constant, then the set of values that f assumes is either the whole complex plane or the plane minus a single point. For example, the exponential function ez never takes the value 0, but takes every other value infinitely often.

Great Picard theorem

The great Picard theorem states that a function with an essential singularity assumes every complex value infinitely often, with the possible exception of one value, in every neighbourhood of the singularity. It is a far stronger statement than the Casorati–Weierstrass theorem and was first proved by Picard in 1879.

Significance

The little theorem generalises Liouville's theorem (a bounded entire function is constant): if f omits two values, its range can be rescaled to a bounded function, forcing f to be constant. The results are foundational in the theory of entire and meromorphic functions.
