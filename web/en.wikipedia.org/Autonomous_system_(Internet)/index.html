Autonomous system (Internet)

An autonomous system (AS) is a collection of connected Internet Protocol (IP) routing prefixes under the control of one or more network operators presenting a common routing policy to the Internet. Each AS is assigned a globally unique autonomous system number (ASN) by a regional Internet registry.

Routing

Autonomous systems exchange reachability information using the Border Gateway Protocol (BGP), the inter-domain routing protocol of the Internet. Within an AS, operators may use interior gateway protocols such as OSPF or IS-IS. ASes are classified informally as stub, multihomed, or transit networks; a small number of large transit providers form the default-free zone at the core of the Internet.

Numbering

AS numbers were originally 16-bit values; a 32-bit format was introduced as the pool of available numbers diminished. Private and documentation ranges are reserved for non-public use. Well-known ASes include those of major ISPs, cloud providers, and content networks.
