User Datagram Protocol

The minimal UDP header: source port, destination port, length and checksum.

In computer networking, the User Datagram Protocol (UDP) is one of the core communication protocols of the Internet protocol suite. With UDP, computer applications can send messages, in this case referred to as datagrams, to other hosts on an Internet Protocol (IP) network. UDP uses a simple connectionless communication model with a minimum of protocol mechanisms; it provides checksums for data integrity and port numbers for addressing different functions at the source and destination.

Characteristics

UDP is a transport-layer protocol defined in RFC 768 (1980), attributed to David P. Reed. It has no handshaking dialogues and thus exposes the user's program to any unreliability of the underlying network; there is no guarantee of delivery, ordering, or duplicate protection. These trade-offs give UDP low overhead and latency, making it suitable for time-sensitive applications that can tolerate some loss, such as DNS lookups, DHCP, voice over IP, online games, and streaming media.

Comparison with TCP

Unlike the Transmission Control Protocol, UDP does not establish a connection or retransmit lost packets. Reliability, where needed, must be built by the application — as in the QUIC protocol, which runs over UDP and now carries a large share of web traffic.
