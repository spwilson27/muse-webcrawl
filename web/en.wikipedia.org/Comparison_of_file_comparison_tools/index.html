Comparison of file comparison tools

File comparison tools display the differences between two (or more) files, directories, or versions of text, and usually allow the changes to be merged. They are a core part of software development workflows, used for code review, merging in version control, and auditing changes. Tools are compared by platform, licence, interface, and features such as three-way merge, directory comparison, binary comparison, and editor integration.

Algorithms

Most tools build on the longest common subsequence problem, classically solved by the Myers diff algorithm, with refinements such as patience diff and histogram diff used in Git to produce more human-readable results.
