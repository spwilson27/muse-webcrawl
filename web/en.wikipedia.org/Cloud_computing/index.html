Cloud computing

Cloud computing is the on-demand availability of computing resources — especially data storage and computing power — over the Internet, without direct active management by the user. Large cloud providers operate data centres worldwide and rent resources with pay-as-you-go pricing. The term became popular in 2006 with the launch of Amazon Web Services' Elastic Compute Cloud, though its roots lie in earlier utility computing, time-sharing, and grid computing. The U.S. National Institute of Standards and Technology (NIST) defines cloud computing by five essential characteristics: on-demand self-service, broad network access, resource pooling, rapid elasticity, and measured service.

Service models

Infrastructure as a service (IaaS) provides virtualised computing resources — virtual machines, storage, and networking — over the Internet. Platform as a service (PaaS) adds managed runtimes, databases, and development tools so customers deploy applications without managing servers. Software as a service (SaaS) delivers complete applications accessed through a web browser, such as webmail and online office suites. Newer variants include function as a service ("serverless") computing, in which code runs in response to events with billing per invocation.

Architecture

Cloud systems rest on virtualisation and containerisation, automated orchestration, and software-defined networking. Providers group data centres into regions and availability zones to offer redundancy and low latency. Deployment models range from public clouds shared by many tenants to private clouds operated for a single organisation, with hybrid arrangements combining both.

History and impact

Salesforce and Amazon pioneered commercial cloud services in the early 2000s; Microsoft Azure and Google Cloud Platform followed. The cloud transformed software economics by converting capital expenditure into operating expenditure, enabling startups to scale globally without owning hardware. Concerns include vendor lock-in, data sovereignty and privacy, security of shared infrastructure, energy consumption of data centres, and service outages with wide knock-on effects.
