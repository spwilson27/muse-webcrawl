Prime omega function

In number theory, the prime omega functions count the number of prime factors of a natural number. The function ω(n) counts the number of distinct prime factors of n, while Ω(n) counts the total number of prime factors with multiplicity.

Definitions and examples

If n = ∏ pa, then ω(n) is the number of distinct primes p appearing, and Ω(n) is the sum of the exponents a. For example, 60 = 2²·3·5, so ω(60) = 3 and Ω(60) = 4. By convention ω(1) = Ω(1) = 0.

Properties

ω is an additive function and Ω is completely additive. Their average order is log log n, as shown by the Hardy–Ramanujan theorem, which also states that the normal order of both functions is log log n. The Erdős–Kac theorem describes their statistical distribution, which approaches a normal distribution.
