Integer matrix

In mathematics, an integer matrix is a matrix whose entries are all integers. Examples include binary matrices, the zero matrix, the matrix of ones, the identity matrix, and the adjacency matrices used in graph theory, amongst many others. Integer matrices find frequent application in combinatorics, number theory, coding theory and lattice theory.

Properties

The set of m × n integer matrices forms a ring under matrix addition and multiplication. Invertibility over the integers is more restrictive than over the reals: an integer matrix has an integer-matrix inverse if and only if its determinant equals 1 or −1. Such matrices are called unimodular, and the invertible n × n integer matrices form the general linear group GL(n, Z) under matrix multiplication.

The determinant of an integer matrix is itself an integer, and the characteristic polynomial of an integer matrix has integer coefficients. Eigenvalues of integer matrices are algebraic integers. Integer matrices also admit canonical forms over the integers, notably the Hermite normal form and the Smith normal form, which classify finitely generated abelian groups and modules over a principal ideal domain.

Examples

Counting matrices such as Pascal's triangle, adjacency matrices of graphs, Hadamard matrices, and (0,1)-matrices are all integer matrices. In combinatorics, integer matrices arise in the study of incidence structures and design theory; in integer programming they appear as constraint matrices, where total unimodularity guarantees integer-valued optima of linear programs.
