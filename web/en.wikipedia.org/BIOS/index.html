BIOS

In computing, BIOS (/ˈbaɪɒs, -oʊs/, BY-oss, -⁠ohss; Basic Input/Output System, also known as the System BIOS, ROM BIOS, BIOS ROM or PC BIOS) is firmware used to provide runtime services for operating systems and programs and to perform hardware initialization during the booting process (power-on startup).

History

The term BIOS was first coined by Gary Kildall for the CP/M operating system in 1975, describing the machine-specific part of CP/M loaded at boot time that interfaced with the hardware. When IBM introduced its Personal Computer in 1981, its BIOS — stored in ROM on the motherboard — performed the power-on self-test (POST), initialized devices, and loaded the operating system from disk. Rival manufacturers such as Phoenix Technologies and Compaq legally reverse-engineered the IBM BIOS using clean-room techniques, enabling the market in IBM PC compatibles.

Functions

On power-up, the BIOS initializes and tests hardware components, locates a bootable device, and loads the initial boot loader into memory. It historically also provided interrupt-based services for keyboards, displays, and disk access to DOS-era software. Users could adjust settings — boot order, clock speeds, enabled devices — through a BIOS setup utility, with configuration stored in battery-backed CMOS RAM.

UEFI and legacy

The Unified Extensible Firmware Interface (UEFI) has largely replaced legacy BIOS on modern PCs, offering faster boot, support for large drives, and a more capable pre-boot environment. Many UEFI implementations retain a Compatibility Support Module to emulate BIOS for older software.
