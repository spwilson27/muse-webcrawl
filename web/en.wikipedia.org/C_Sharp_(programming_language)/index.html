C# (pronounced "C sharp") is a general-purpose, high-level programming language developed by Microsoft as part of its .NET initiative and first released in 2000. Led by Anders Hejlsberg, the language was designed for the Common Language Infrastructure and combines the computing power of C and C++ with the productivity of rapid application development tools.

History

Development began in 1999 under the codename "Cool" (C-like Object Oriented Language). C# and the .NET Framework were announced at the Professional Developers Conference in July 2000, and the language was standardised by Ecma (ECMA-334) and ISO. The name derives from the musical notation sharp symbol, suggesting an increment of C++.

Features

C# is a managed, garbage-collected language with strong static typing, properties, events, delegates and indexers. Later versions added generics (C# 2.0), Language Integrated Query — LINQ (C# 3.0), dynamic binding (C# 4.0), async/await for asynchronous programming (C# 5.0), pattern matching, records and nullable reference types. Code compiles to Common Intermediate Language and runs on the Common Language Runtime.

using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }
}

Uses

C# is widely used for Windows desktop applications, enterprise web services with ASP.NET, and game development with the Unity engine, where it is the primary scripting language.
