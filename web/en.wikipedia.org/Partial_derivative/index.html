Partial derivative

In mathematics, a partial derivative of a function of several variables is its derivative with respect to one of those variables, with the others held constant. Partial derivatives are used in vector calculus and differential geometry.

Definition

For a function f(x, y, ...), the partial derivative with respect to x is written ∂f/∂x and is defined as the limit, as h approaches zero, of [f(x+h, y, ...) − f(x, y, ...)] / h. The symbol ∂ is a stylized lowercase d often read as "partial".

Examples

If f(x, y) = x²y + y³, then ∂f/∂x = 2xy and ∂f/∂y = x² + 3y². The gradient collects all first partial derivatives into a vector; higher-order partials appear in the Hessian matrix.

Applications

Partial derivatives underlie the partial differential equations of physics, including the heat equation, wave equation, and Maxwell's equations, as well as optimization and marginal analysis in economics.

Notation

Alternative notations include subscripts (fx), introduced by Legendre and Jacobi, and operator notation using the del (∇) symbol.
