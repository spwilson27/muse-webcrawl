Allegro (software library)

Allegro is a free and open-source software library for video game development. The library provides functions for graphics, sounds, user input, and timers, and is designed to be used with the C and C++ programming languages across multiple platforms.

Allegro
Original author: Shawn Hargreaves
Initial release: 1990
Written in: C, C++
License: zlib-style (giftware)
Type: API / game library

History

Allegro was created by Shawn Hargreaves in the early 1990s for the Atari ST, and its name originally stood for "Atari Low-Level Game Routines". It became widely used with DJGPP on DOS for homebrew game development. Allegro 4 supported DOS, Windows, Linux, and macOS; Allegro 5, released in 2011, is a redesigned API with hardware-accelerated graphics and support for platforms including iOS and Android.

Features

The library abstracts 2D drawing, audio playback and mixing, keyboard, mouse and joystick input, image loading, and threading, allowing cross-platform games to be written with a single codebase. It is not a game engine but a low-level library on which games and other multimedia programs are built.
