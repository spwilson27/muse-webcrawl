Controllability

Controllability is an important property of a control system and plays a crucial role in many control problems, such as stabilisation of unstable systems by feedback, or optimal control. Controllability and observability are dual aspects of the same problem.

Roughly, the concept of controllability denotes the ability to move a system around in its entire configuration space using only certain admissible manipulations. The exact definition varies slightly depending on the type of model considered and the framework used, but for a linear system described in state-space form, the system is controllable if and only if the controllability matrix has full rank.

Kalman's rank condition

For a continuous-time linear system with state matrix A and input matrix B, the system is controllable if and only if the matrix formed by stacking B, AB, A²B, and so on up to An−1B has rank n, where n is the dimension of the state. This test is known as Kalman's rank condition for controllability.

Related concepts

A weaker notion is stabilisability: a system is stabilisable if all uncontrollable modes are stable. In discrete-time systems the corresponding condition is reachability — the ability to reach any state from the origin in finite time. Together with its dual notion, observability, controllability underpins the design of state feedback controllers and state estimators in control theory.
