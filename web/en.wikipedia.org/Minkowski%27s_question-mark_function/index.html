Minkowski's question-mark function

In mathematics, Minkowski's question-mark function, denoted ?(x), is a function defined by Hermann Minkowski in 1904. It maps quadratic irrational numbers to rational numbers between zero and one, and has remarkable fractal properties.

Definition

If x has the continued fraction expansion [a₀; a₁, a₂, …], then ?(x) is given by an alternating series in powers of one half: ?(x) = a₀ + 2 Σ (−1)k+1 2−(a₁+…+ak). In particular ? maps rational numbers to dyadic rationals and quadratic irrationals to non-dyadic rationals.

Properties

The function is strictly increasing and continuous on [0,1], fixes 0, 1/2 and 1, and satisfies symmetries including ?(x) + ?(1−x) = 1. Remarkably, its derivative is zero almost everywhere, making it a singular function — a strictly increasing continuous function that is not absolutely continuous. It is closely related to the Stern–Brocot tree and Farey sequences, and to the modular group.
