Object type (object-oriented programming)

Image placeholder: Type hierarchy diagram for object types
A fragment of a type hierarchy: each object type can be a subtype of another

In object-oriented programming, an object type is a data type whose values are objects — entities combining state and behavior. Object types define the set of operations (methods) and attributes available on their instances, together with the rules for how objects of the type may be used.

Object types and classes

In class-based languages, a class serves both as the implementation of a type and as the factory for its instances; in such languages "class" and "object type" are often used almost interchangeably. Some languages, however, separate the two notions: an interface, for example, defines an object type without providing an implementation, and a single class may implement several interfaces (types).

Subtyping

Object types are typically organized in a hierarchy by inheritance or interface implementation, creating subtype relationships: if type S is a subtype of T, then objects of type S may be used wherever objects of type T are expected — the Liskov substitution principle. This underlies polymorphism in statically typed object-oriented languages such as Java and C#.

Reference types vs value types

Many languages distinguish object (reference) types from primitive or value types: variables of an object type hold references to objects rather than the objects themselves, so assignment copies the reference, and two variables can alias the same object. In languages like Java, all classes are reference types, contrasted with primitive types such as int; C# similarly distinguishes reference types (classes) from value types (structs).

Prototype-based languages

In prototype-based languages such as JavaScript, there are no classes in the classical sense; every object has a prototype from which it inherits properties, and "types" are informal, determined by structure and the prototype chain — though modern JavaScript also offers class syntax built on prototypes.
