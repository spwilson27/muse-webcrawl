ML (programming language)

ParadigmFunctional, modular
Designed byRobin Milner, others
First appeared1973
Typing disciplineStatic, strong, inferred
Major dialectsStandard ML, OCaml, F#

ML (Meta Language) is a general-purpose, high-level functional programming language. It is known for its use of the polymorphic Hindley–Milner type system, which automatically assigns the types of most expressions without requiring explicit type annotations.

History

ML was developed by Robin Milner and others at the University of Edinburgh in the 1970s as the scripting (meta) language of the LCF theorem prover. Its type-inference algorithm, formalized with Luis Damas, guarantees strong static typing while feeling like a dynamically typed language.

Features and descendants

ML features pattern matching, first-class functions, automatic memory management through garbage collection, parametric polymorphism, and an exception mechanism. Its descendants include Standard ML, OCaml, and the .NET language F#; ideas from ML have influenced Haskell, Rust, Scala, and many other languages.
