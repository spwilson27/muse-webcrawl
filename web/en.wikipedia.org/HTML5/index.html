HTML5

HTML5 is a markup language used for structuring and presenting hypertext documents on the World Wide Web. It was the fifth and last major version of HTML to be published as a numbered standard by the World Wide Web Consortium (W3C); the WHATWG now maintains HTML as a continuously updated "living standard". HTML5 was published by the W3C as a Recommendation on 28 October 2014, superseding HTML 4.01 (1999).

Features

HTML5 introduced native support for multimedia and graphics that previously required plug-ins such as Adobe Flash: the <video> and <audio> elements, the <canvas> element for 2D drawing, and scalable vector graphics (SVG) content. It added semantic elements describing page structure — <article>, <section>, <nav>, <header> and <footer> — together with new form controls, drag-and-drop, geolocation, web storage, and application programming interfaces intended to make web applications richer and more interoperable. It also, for the first time, defined detailed parsing rules so that all conforming browsers handle malformed documents the same way.

History

Work began in 2004 at the WHATWG, founded by Apple, Mozilla and Opera after dissatisfaction with the W3C's XHTML direction; the W3C adopted the WHATWG's work as the basis for HTML5 in 2007. A 2019 agreement between the two organisations made the WHATWG's HTML Living Standard the sole canonical version.

The term "HTML5" is also popularly used for the broader family of associated web technologies — CSS3, JavaScript APIs and media formats — that together defined the modern web platform.
