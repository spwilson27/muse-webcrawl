Filter (higher-order function)

In functional programming, filter is a higher-order function that processes a data structure (usually a list) in some order to produce a new data structure containing exactly those elements of the original for which a given predicate returns true.

Examples

In Haskell, filter even [1..10] returns [2,4,6,8,10]. Python's built-in filter(function, iterable) constructs an iterator of the elements for which the function returns true; JavaScript arrays provide Array.prototype.filter with the same semantics.

Relation to other functions

Filter is one of the canonical trio of higher-order functions alongside map and fold (reduce). Filter can be defined in terms of a fold, and list comprehensions in many languages subsume the combination of map and filter.
