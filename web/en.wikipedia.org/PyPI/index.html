PyPI

Full name: Python Package Index
Operator: Python Software Foundation
Launched: 2003
Companion tool: pip

The Python Package Index, abbreviated as PyPI and nicknamed the "Cheese Shop" (after a Monty Python sketch), is the official third-party software repository for the Python programming language. It hosts hundreds of thousands of packages — libraries and applications written in Python — which users can install with tools such as pip.

History

PyPI was established in 2003 around metadata standards developed by the Python community (PEP 241 and successors) and Richard Jones's early implementation. In 2018 the codebase was replaced by a new platform called Warehouse, developed with support from Mozilla's open-source support programme; the legacy interface was retired in favour of pypi.org. PyPI is operated by the Python Software Foundation and supported by donated infrastructure and content-delivery services.

Use and security

Developers publish source distributions and prebuilt wheels to PyPI using tools such as Twine, increasingly via "trusted publishing" through OpenID Connect rather than stored passwords. Because of its centrality, PyPI is a frequent target of supply-chain attacks, including typosquatting and account takeovers; countermeasures have included mandatory two-factor authentication for maintainers and malware scanning and reporting programmes.
