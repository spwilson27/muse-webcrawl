Barker code

A Barker code, or Barker sequence, is a finite sequence of N values of +1 and −1 with the property that its aperiodic autocorrelation has sidelobes no larger than 1 in magnitude. Barker codes were introduced by R. H. Barker in 1953 for use in radar and telemetry synchronisation, where their sharp autocorrelation peak makes it easy to detect alignment.

Known codes

Barker codes are known only for limited lengths. Apart from trivial cases, binary Barker codes exist for N = 2, 3, 4, 5, 7, 11, and 13; it has been proven that no odd-length Barker code exists beyond 13, and even-length codes beyond 4 are ruled out under known results except for very large lengths subject to strong number-theoretic constraints. The length-11 code (+ + + − − − + − − + −) and length-13 code are especially well known.

Applications

Barker codes are used in radar pulse compression, spread-spectrum communications, and frame synchronisation. The 11-bit Barker code was adopted in the original IEEE 802.11 wireless LAN standard for direct-sequence spread spectrum, and Barker sequences are also used in ultrasound imaging and radar altimetry.
