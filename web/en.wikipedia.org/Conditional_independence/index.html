Conditional independence

In probability theory, conditional independence describes a situation where two events or random variables are independent given the value of a third. Formally, events A and B are conditionally independent given an event C (with P(C) > 0) if P(A ∩ B | C) = P(A | C) · P(B | C). Knowing C renders A and B uninformative about each other.

Applications

Conditional independence is the organising principle of graphical models such as Bayesian networks and Markov random fields: missing edges in the graph encode conditional independence assumptions, allowing large joint distributions to be factorised into manageable pieces. It also underlies the naive Bayes classifier in machine learning, which assumes features are conditionally independent given the class label.

Properties

Conditional independence is symmetric in its first two arguments. Standard properties include decomposition, weak union, contraction, and — for strictly positive distributions — intersection. Two variables can be marginally independent but conditionally dependent, or vice versa, as in the "explaining away" pattern of a common-effect (collider) structure.
