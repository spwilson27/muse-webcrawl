Filesystem Hierarchy Standard

The Filesystem Hierarchy Standard (FHS) is a reference describing the conventions used for the layout of file systems on Unix-like operating systems, principally Linux. First released in 1994, it is maintained by the Linux Foundation. The FHS defines the names, locations and purposes of the main directories so that users and software can predict where files and directories are located on any compliant system.

Directory structure

Under the FHS, all files and directories appear under the root directory /. Key directories include /bin (essential command binaries), /boot (boot loader files), /dev (device files), /etc (host-specific system configuration), /home (user home directories), /lib (essential shared libraries), /mnt and /media (mount points), /opt (optional application packages), /proc (virtual filesystem for process and kernel information), /root (home of the root user), /sbin (system binaries), /srv (data for services), /sys (virtual filesystem for system information), /tmp (temporary files), /usr (secondary hierarchy with most user utilities and applications) and /var (variable data such as logs and spools).

History and adoption

The FHS grew out of earlier efforts to standardise the Linux directory layout (the FSSTND of 1994) and gradually took on a more general Unix scope. Most Linux distributions comply with the standard to a large degree, though some, such as NixOS and GoboLinux, deliberately depart from it. Modern revisions and distribution practice have also brought changes such as the merging of /bin, /lib and /sbin into their /usr counterparts.
