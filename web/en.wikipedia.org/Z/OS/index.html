z/OS is a 64-bit operating system for IBM mainframes, produced by IBM, and first released in 2001 as the successor to OS/390. It runs on IBM Z systems and supports many of the world's largest banks, insurers, airlines and government agencies, processing enormous transaction volumes with an emphasis on reliability, security and backward compatibility with applications written decades earlier.

History

z/OS descends from OS/360, introduced in the 1960s, through MVS and OS/390. Its name reflects its association with the z/Architecture line of mainframes. New releases appear on a regular cadence — version 2.x releases roughly every two years — and incorporate support for newer hardware, Java, and modern application runtimes alongside the traditional workload.

Features

The operating system supports batch processing, transaction processing through subsystems such as CICS and IMS, and interactive work through TSO and the ISPF interface. Its Workload Manager (WLM) assigns system resources according to business goals, and Parallel Sysplex clustering allows multiple systems to share data with near-continuous availability. z/OS also includes UNIX System Services, a certified UNIX environment that lets POSIX applications run beside traditional mainframe workloads. Security is centred on RACF (Resource Access Control Facility), and the platform is known for cryptographic hardware support and high evaluation assurance levels.
