Continuity (mathematics)

Continuous function
FieldMathematical analysis; topology

In mathematics, a continuous function is a function that does not make abrupt changes in value — intuitively, one whose graph can be drawn without lifting the pen from the paper. Formally, a function f is continuous at a point c if the limit of f(x) as x approaches c exists and equals f(c): nearby inputs are mapped to nearby outputs.

Definitions

The rigorous definition most used today is the ε–δ definition: f is continuous at c if for every ε > 0 there is a δ > 0 such that |x − c| < δ implies |f(x) − f(c)| < ε. Equivalent formulations use limits, sequences, or — in topology — the condition that the preimage of every open set is open, which generalises continuity to functions between arbitrary topological spaces. A function continuous at every point of its domain is simply called continuous.

Examples and failures

Polynomials, exponential, sine and cosine functions are continuous everywhere; the reciprocal function 1/x is continuous on its domain but not at 0, where it is undefined. Discontinuities are classified as removable (a "hole"), jump (left and right limits differ), or essential (wild behaviour, as with sin(1/x) near 0). The Dirichlet function, equal to 1 on rationals and 0 on irrationals, is discontinuous everywhere.

Important theorems

Continuity underpins much of analysis. The intermediate value theorem says a continuous function on an interval takes every value between any two of its values; the extreme value theorem says a continuous function on a closed bounded interval attains a maximum and a minimum. Stronger notions include uniform continuity and Lipschitz continuity, while weaker ones include semicontinuity.
