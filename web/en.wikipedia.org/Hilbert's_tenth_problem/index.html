Hilbert's tenth problem is the tenth on the list of mathematical problems David Hilbert presented in 1900. It asks for a general algorithm that, given any Diophantine equation — a polynomial equation with integer coefficients — determines whether the equation has a solution with all unknowns taking integer values. The problem was resolved in the negative in 1970: no such algorithm exists.

Statement

Hilbert asked: "Given a Diophantine equation with any number of unknown quantities and with rational integral numerical coefficients: to devise a process according to which it can be determined in a finite number of operations whether the equation is solvable in rational integers." (Integer and rational solvability are equivalent for this purpose.) The question presupposed the 20th-century notion of an algorithm, which was formalized in the 1930s by Church, Turing, Gödel and others, making a negative solution conceivable.

Solution: the MRDP theorem

The solution combined number theory with computability. In 1959–1961 Martin Davis, Hilary Putnam and Julia Robinson showed that solvability of exponential Diophantine equations is undecidable, and reduced the general problem to showing that exponentiation itself is Diophantine — that is, that there is a polynomial whose solution set encodes the graph of exponentiation. Robinson formulated the key hypothesis ("J.R."). In 1970 the 22-year-old Soviet mathematician Yuri Matiyasevich completed the proof, using Fibonacci numbers to construct a Diophantine definition of exponentiation. The resulting MRDP theorem (Matiyasevich–Robinson–Davis–Putnam) states that a set of integers is computably enumerable if and only if it is Diophantine; since there exist computably enumerable but undecidable sets, no algorithm for Hilbert's tenth problem can exist. A corollary is that there is a polynomial whose positive values at integer arguments are exactly the prime numbers.

Extensions

Analogous questions over the rational numbers remain famously open: whether there is an algorithm to decide solvability of polynomial equations in rational numbers is unknown, though it is known that the rationals admit a Diophantine definition of the integers in related formulations, and recent work has shown undecidability for many rings of algebraic integers. Over the real and complex numbers, by contrast, decision procedures do exist (Tarski's quantifier elimination for real closed fields).
