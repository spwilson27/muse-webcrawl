Refreshable Braille display

A refreshable Braille display is an electro-mechanical device that renders text from a computer or mobile device as tactile Braille characters. Rows of small pins are raised and lowered by piezoelectric actuators to form Braille cells that refresh as the user moves through a document, providing access for blind and deafblind readers.

Operation

Displays commonly present 20, 40, or 80 cells at a time and connect via USB or Bluetooth. A screen reader translates on-screen text into Braille output, while cursor-routing keys above each cell let the user interact with the text at that position.

Development

Refreshable displays emerged in the 1970s and 1980s but remained expensive because each cell requires precision actuators. Multi-line displays and lower-cost actuator technologies developed in the 2010s and 2020s have begun to make tactile graphics and full-page Braille more practical.
