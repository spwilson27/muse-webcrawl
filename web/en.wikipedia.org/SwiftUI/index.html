SwiftUI is a declarative user interface framework developed by Apple Inc. for building user interfaces across all Apple platforms. Announced at the Worldwide Developers Conference (WWDC) in June 2019, it lets developers describe what an interface should look like and how it should change with state, rather than imperatively constructing and updating views as with the older UIKit and AppKit frameworks.

Design

In SwiftUI, interfaces are composed of lightweight value types conforming to the View protocol. Views are arranged with container stacks such as VStack, HStack, and ZStack, and modified by chained modifier methods for layout, colour, and behaviour. State is managed with property wrappers including @State, @Binding, @ObservedObject, and later @Observable; when state changes, the framework automatically re-renders the affected views. SwiftUI integrates with Xcode's live previews and can interoperate with UIKit and AppKit code within the same app.

History

SwiftUI shipped in September 2019 with iOS 13, macOS Catalina, watchOS 6, and tvOS 13. Annual releases have added major features: app lifecycle and App protocol support and richer widgets (2020), improved lists, grids, and concurrency integration (2021), navigation stacks and charts (2022), and support for visionOS and interactive widgets (2023). SwiftUI is frequently compared to Google's Flutter and Meta's React Native, though it targets only Apple platforms natively.
