Noindex

The noindex value of several different HTML and HTTP conventions prevents search engine indexing of a web page or resource. It is most commonly implemented as a robots meta tag value, <meta name="robots" content="noindex">, in a page's HTML head, or via an X-Robots-Tag: noindex HTTP response header.

Usage

Site owners use noindex to keep pages out of search results — for example thank-you pages, login pages, thin or duplicate content, and staging sites. Unlike robots.txt exclusion, which only blocks crawling, noindex asks engines that have crawled the page to drop it from their index. For a crawler to see the meta tag, the page must not also be blocked by robots.txt. Google and other major search engines honour the directive.
