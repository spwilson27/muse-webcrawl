Server-sent events

Server-Sent Events (SSE) is a server push technology that allows a web server to send a stream of text updates to a browser over a single long-lived HTTP connection. Standardised by the WHATWG as part of HTML, SSE uses the EventSource JavaScript API and the text/event-stream media type, with messages formatted as fields such as data:, event: and id:.

Comparison

Unlike WebSockets, SSE is one-way (server to client only) and runs over ordinary HTTP, making it simple to implement and deploy through proxies, with automatic reconnection built in. Typical uses include live feeds, stock tickers, progress notifications and streaming tokens from web services.
