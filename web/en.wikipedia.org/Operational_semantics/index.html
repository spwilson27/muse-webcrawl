Operational semantics

In computer science, operational semantics is a category of formal programming language semantics in which the execution of a program is described directly, typically by defining transitions of an abstract machine or by structural rules relating program configurations.

Approaches

Structural operational semantics (SOS), introduced by Gordon Plotkin in a 1981 lecture report, defines behaviour through inference rules over program syntax and is widely used for specification. Abstract machine semantics, such as Landin's SECD machine or the CEK machine, describe evaluation step by step. Small-step semantics shows individual computation steps, while big-step (natural) semantics relates programs directly to their final results.

Relation to other semantics

Operational semantics contrasts with denotational semantics, which assigns mathematical objects as meanings, and axiomatic semantics, which describes programs by logical assertions. For well-designed languages the approaches can be proved to agree.
