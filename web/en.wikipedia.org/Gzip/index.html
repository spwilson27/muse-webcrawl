Gzip

gzip is a file format and software application used for file compression and decompression. The program was created by Jean-loup Gailly and Mark Adler as a free software replacement for the compress program used in early Unix systems, and is specified in RFC 1952. Compressed files usually carry the extension .gz.

Format

The gzip format is based on the DEFLATE algorithm, a combination of LZ77 and Huffman coding also used in ZIP archives and PNG images. A gzip file contains a 10-byte header (beginning with the magic numbers 1f 8b), optional extra fields such as the original filename, a compressed data stream, and a trailer with a CRC-32 checksum and the length of the original uncompressed data. Unlike ZIP, gzip normally compresses a single file; archives of many files are made by first combining them with tar, producing the familiar .tar.gz or .tgz format.

History and use

gzip was first publicly released on 31 October 1992 (version 0.1). It became a standard tool on Unix and Linux systems and was also built into web protocols: HTTP servers and browsers support gzip content-encoding to reduce transfer sizes of text responses. The related zlib format (RFC 1950) and the "raw" deflate format (RFC 1951) share the same compression algorithm.

Because a gzip stream is a sequence of independent members that can be concatenated, decompressing a concatenated file yields the concatenation of the originals. Variants such as bgzip and tools such as pigz exploit the format for parallel or block-wise compression, particularly in genomics.
