Extensible Markup Language (XML) is a markup language and file format for storing, transmitting, and reconstructing data. It defines a set of rules for encoding documents in a format that is both human-readable and machine-readable. The World Wide Web Consortium's XML 1.0 Specification of 1998 and several other related specifications define XML as a free open standard. XML is a simplified subset of SGML designed for use on the World Wide Web, and it has served as the basis for hundreds of document formats, including XHTML, SVG, RSS, Atom, Microsoft Office Open XML and OpenDocument.

Design goals

The XML specification emphasises simplicity, generality and usability across the Internet. Among its stated goals: XML should be straightforwardly usable over the Internet; it should support a wide variety of applications; it should be compatible with SGML; it should be easy to write programs that process XML documents; and XML documents should be human-legible and reasonably clear. The design deliberately omitted many of SGML's optional and rarely used features to make parsers simpler to write.

Structure

An XML document consists of nested elements delimited by start-tags and end-tags, which may carry attributes and contain text, other elements, comments, processing instructions and entity references. A document with a single root element and correctly nested tags is called well-formed; a document that also conforms to a schema such as a DTD or XML Schema is valid.

<?xml version="1.0" encoding="UTF-8"?>
<note>
  <to>Reader</to>
  <from>Author</from>
  <heading>Reminder</heading>
  <body>Example XML document.</body>
</note>

Related technologies

A large family of languages and tools surrounds XML: XPath and XQuery for querying, XSLT for transformation, XML Schema and RELAX NG for validation, DOM and SAX for parsing APIs, and namespaces for combining vocabularies. Web services of the 2000s were largely built on XML protocols such as SOAP and XML-RPC.

Criticism and decline in data interchange

XML documents are verbose, and their complexity has been criticised by some developers. From the late 2000s, the lighter JSON format displaced XML for much web data interchange, and YAML and other formats took over some configuration use cases. XML remains dominant in document formats, publishing, vector graphics (SVG), syndication and many enterprise and industry-specific standards.
