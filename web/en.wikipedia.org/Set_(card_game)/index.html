Set is a real-time card game designed by Marsha Falco in 1974 and published by Set Enterprises in 1991. The game uses a deck of 81 unique cards, each varying in four features: the number of shapes (one, two or three), the shape itself (diamond, squiggle or oval), the shading (solid, striped or open), and the colour (red, green or purple).

Gameplay

Twelve cards are dealt face up. Players race, without turns, to identify a set: three cards that are, for each of the four features separately, either all the same or all different. For example, three cards each with two red shapes (but differing shapes, all different shadings) form a set. When a player sees a set, they call "Set!" and collect the three cards, which are replaced from the deck. If no set is present, three more cards are added. The player with the most sets when the deck is exhausted wins.

Mathematics

The game is a popular vehicle for combinatorics and finite geometry: the deck corresponds to the points of the four-dimensional affine space over the field with three elements, and a set is exactly a line in that geometry. Mathematicians have studied questions such as the largest possible collection of cards containing no set (a "cap set"), which has size 20, and the probability that a random layout contains a set. The game's mathematical depth led to its use in research and teaching, and Set Enterprises later produced related games such as Quiddler.

History

Falco, a population geneticist, invented the game while studying epilepsy in German Shepherds, using symbols on cards to represent genetic information. The game won a Mensa Select award in 1991 and has since been published in numerous countries and digital versions.
