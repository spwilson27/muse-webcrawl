Hindley–Milner type system

FamilyType systems for typed lambda calculus
Devised byJ. Roger Hindley (1969); Robin Milner (1978)
Key featuresParametric polymorphism, principal types, type inference

The Hindley–Milner type system (HM) is a classical type system for the lambda calculus with parametric polymorphism. It is notable because a complete and decidable type inference algorithm exists for it: given a term without any type annotations, the algorithm can deduce the most general type of the term. The system was described independently by J. Roger Hindley in 1969 and Robin Milner in 1978, and it forms the theoretical basis of the type systems of languages such as ML, Haskell, and OCaml.

Description

HM extends the simply typed lambda calculus with let-polymorphism: a value bound by a let expression may be used at several different types, because its type may be generalised into a type scheme containing universally quantified type variables. Type schemes of the form ∀α₁…αₙ.τ allow a single definition, such as the identity function, to be used at every type.

Type inference

Milner's Algorithm W (1978) computes the principal type of an expression by generating and solving type equations using unification. Because the inferred type is principal — the most general type possible — any other valid typing of the term is an instance of it. Extensions such as type classes, row polymorphism, and higher-rank types build on the HM foundation.

Properties

Type inference for HM is decidable but can be EXPTIME-complete in the worst case, though it is nearly linear in practice. The system guarantees type safety: well-typed programs cannot produce certain classes of runtime errors.
