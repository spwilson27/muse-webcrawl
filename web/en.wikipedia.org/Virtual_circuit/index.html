Virtual circuit

A virtual circuit established across a packet network

Layer: Transport / network

Examples: X.25, Frame Relay, ATM, MPLS

A virtual circuit (VC) is a means of transporting data over a packet-switched network in such a way that it appears as though there is a dedicated physical link between the source and destination end systems. A virtual circuit is established before any packets are sent, and all packets belonging to the connection follow the same path through the network, preserving their order.

Characteristics

Virtual circuits give a connection-oriented service on top of a packet network. During a call setup phase, switches along the path allocate resources and record state; data packets then carry a short virtual circuit identifier rather than a full destination address. The call is torn down when communication ends. Unlike a true circuit-switched connection, however, capacity is not reserved end-to-end in older designs, and the path exists only as entries in switch tables — hence "virtual".

Examples

Historic and current virtual circuit technologies include X.25, Frame Relay, Asynchronous Transfer Mode (ATM), and the logical connections provided by the Transmission Control Protocol (TCP) at the transport layer. Multiprotocol Label Switching (MPLS) also forwards packets along predetermined label-switched paths that resemble virtual circuits.

Permanent and switched circuits

A permanent virtual circuit (PVC) is configured in advance by a network operator and is always available, while a switched virtual circuit (SVC) is set up on demand for each communication session.
