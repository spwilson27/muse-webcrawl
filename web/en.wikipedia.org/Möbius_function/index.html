The Möbius function μ(n) is a multiplicative function in number theory introduced by the German mathematician August Ferdinand Möbius (also transliterated Moebius) in 1832. It is ubiquitous in elementary and analytic number theory and arises in the Möbius inversion formula.

Definition

For a positive integer n, μ(n) is defined as follows: μ(n) = 0 if n is not square-free (that is, if it is divisible by the square of a prime); μ(n) = 1 if n is a square-free integer with an even number of prime factors; and μ(n) = −1 if n is a square-free integer with an odd number of prime factors. By convention μ(1) = 1.

Properties and applications

The Möbius function satisfies the identity that the sum of μ(d) over all positive divisors d of n equals 1 if n = 1 and 0 otherwise. This property underlies the Möbius inversion formula, which recovers a function from its divisor sums. The function appears in formulas counting aperiodic necklaces, in the Farey sequence, and in the Mertens function — the summatory function of μ(n) — whose conjectured growth is closely related to the Riemann hypothesis.

Generalizations

The Möbius function generalizes to incidence algebras of partially ordered sets, where it provides a combinatorial inversion principle, and to the inclusion–exclusion principle of combinatorics.
