Truth function

From Wikipedia, the free encyclopedia

In logic, a truth function is a function that accepts truth values as input and produces a unique truth value as output. In classical propositional logic, the inputs and outputs are drawn from the two values true and false, and the behaviour of a truth function is fully specified by a truth table. The logical connectives of conjunction (AND), disjunction (OR), negation (NOT), conditional (IF...THEN), and biconditional are all truth functions.

Counting and completeness

For n input variables there are 2^(2^n) possible truth functions: four of one variable, sixteen of two variables, and so on. Any truth function can be expressed using a functionally complete set of connectives — NAND alone, or the set {¬, ∧, ∨} suffices. This property underlies the design of digital logic gates, where AND, OR, and NOT gates implement the corresponding truth functions in hardware.

Truth-functional logic

A logic is truth-functional when the truth value of a compound sentence is determined entirely by the truth values of its components. Propositional logic is truth-functional, but many natural-language connectives are not: "because," modal operators such as "necessarily," and counterfactual conditionals depend on content beyond truth values, motivating the study of non-classical logics.
