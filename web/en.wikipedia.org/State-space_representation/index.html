State-space representation

In control engineering, a state-space representation is a mathematical model of a physical system as a set of input, output and state variables related by first-order differential equations or difference equations. State variables are variables whose values evolve over time in a way that depends on the values they have at any given time and on the externally imposed values of input variables. Output variables' values depend on the values of the state variables.

Formulation

The general state-space model can be written as two equations:

ẋ(t) = f(t, x(t), u(t))
y(t) = g(t, x(t), u(t))

where x is the state vector, u is the input (or control) vector, and y is the output vector.

Linear systems

The most commonly studied state-space models are linear systems, which can be written in matrix form:

ẋ(t) = A(t)x(t) + B(t)u(t)
y(t) = C(t)x(t) + D(t)u(t)

Here A is the state (or system) matrix, B the input matrix, C the output matrix, and D the feedthrough (or feedforward) matrix. In the time-invariant case the matrices are constant and the system is referred to as an LTI system.

Controllability and observability

A state-space model is controllable if it is possible, by means of an admissible control input, to transfer the system from any initial state to any other state in a finite time interval. It is observable if the current state can be determined in finite time using only the outputs. These concepts, developed by Rudolf E. Kálmán, are fundamental to modern control theory and underlie tools such as the Kalman filter and linear–quadratic regulator.

Relation to transfer functions

For a single-input, single-output linear system, the transfer function can be derived from the state-space model as G(s) = C(sI − A)−1B + D. Unlike transfer functions, state-space models naturally handle multiple-input multiple-output (MIMO) systems and can incorporate initial conditions.

Applications

State-space methods are used throughout aerospace guidance, robotics, chemical process control, economics (see state-space models in statistics), and signal processing. In statistics and machine learning, related latent-variable formulations include hidden Markov models.
