Naïve set theory

From Wikipedia, the free encyclopedia

Naïve set theory is any of several theories of sets used in the discussion of the foundations of mathematics. Unlike axiomatic set theories, which are formulated in a rigorous formal logic to avoid paradoxes, naïve set theory is defined informally in natural language. It describes the aspects of sets familiar from ordinary mathematical practice, and it suffices for most everyday uses.

Basic notions

In the naïve approach, a set is a collection of distinct objects, called its elements or members. Georg Cantor described a set as a gathering together into a whole of definite, distinct objects of perception or thought. Sets are commonly specified by listing their elements or by a defining property, and the basic operations are union, intersection, difference and complement; relations include membership (∈), subset (⊆), and equality.

Paradoxes

Unrestricted comprehension—assuming that for every property there is a set of exactly the objects with that property—leads to contradiction, most famously Russell's paradox (1901) concerning the set of all sets that do not contain themselves. Other paradoxes of size, such as Cantor's paradox and the Burali-Forti paradox, exposed the same problem.

Relation to axiomatic set theory

Axiomatic systems such as Zermelo–Fraenkel set theory (ZFC) replaced naïve comprehension principles with restricted axioms that recover the working content of naïve set theory without the known paradoxes. The expression "naïve set theory" is also the title of Paul Halmos's popular 1960 textbook, which presents an informal but careful introduction suitable for working mathematicians.
