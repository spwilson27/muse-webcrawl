coreboot, formerly LinuxBIOS, is a software project aimed at replacing proprietary firmware (BIOS or UEFI) found in most computers with a lightweight firmware designed to perform only the minimum number of tasks necessary to load and run a modern 32-bit or 64-bit operating system.

History

The project was begun in 1999 at the Advanced Computing Laboratory of Los Alamos National Laboratory by Ron Minnich, originally to boot clusters quickly. It was renamed coreboot in 2008 to reflect that it could load payloads other than Linux.

Design

coreboot performs minimal hardware initialization — CPU, memory controller (DRAM), and boot device — in stages (bootblock, romstage, ramstage), then hands off to a payload, which may be a bootloader or operating system kernel such as SeaBIOS (for legacy BIOS compatibility), TianoCore (UEFI), GRUB 2, or a Linux kernel directly. Because most initialization code is open source, coreboot boots quickly and can be audited, though some platforms still require vendor binary blobs for certain hardware.

Adoption

coreboot ships on all Chromebooks and is supported by vendors such as Purism, System76, and Star Labs, and by the Libreboot distribution, which removes proprietary blobs for supported boards. It supports architectures including x86, ARM, RISC-V, and POWER.
