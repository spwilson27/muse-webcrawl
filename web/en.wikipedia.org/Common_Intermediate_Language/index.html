Common Intermediate Language

Common Intermediate Language (CIL), formerly called Microsoft Intermediate Language (MSIL), is the intermediate language of the .NET platform. Compilers for languages such as C#, Visual Basic .NET, and F# translate source code into CIL together with metadata, packaged in assemblies. At runtime, the Common Language Runtime (CLR) just-in-time compiles CIL into native machine code for the host platform.

Design

CIL is a stack-based, object-oriented bytecode defined by the Common Language Infrastructure standard (ECMA-335). It is designed to be language-agnostic: types, methods, and exceptions follow the Common Type System, so components written in different .NET languages can interoperate seamlessly.

Execution

Because CIL is verified and managed, the runtime can provide garbage collection, type safety, and security checks. Tools such as ILDASM can disassemble assemblies back into readable CIL, and the language itself can be written and assembled directly with ILASM.

Comparison

CIL plays the same role for .NET that Java bytecode plays for the JVM, though it is designed from the start for multiple languages and value types rather than a single source language.
