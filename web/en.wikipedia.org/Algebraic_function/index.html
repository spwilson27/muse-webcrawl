Algebraic function

In mathematics, an algebraic function is a function that can be defined as the root of a polynomial equation. Quite often algebraic functions are algebraic expressions using a finite number of terms, involving only the algebraic operations addition, subtraction, multiplication, division, and raising to a fractional power. Examples of such functions are:

  • f(x) = 1/x
  • f(x) = √x
  • f(x) = (x3 + 1)/(x2 + 5)

However, some algebraic functions cannot be expressed using such finite expressions; this is the Abel–Ruffini theorem. For example, for the Bring radical, one has a function defined implicitly by an equation of degree five whose roots cannot in general be written down using radicals alone.

Definition

Formally, an algebraic function in one variable x over a field K is an element of the algebraic closure of the field of rational functions K(x) that satisfies a polynomial equation

an(x)yn + an−1(x)yn−1 + … + a0(x) = 0,

where the coefficients ai(x) are polynomial functions of x with coefficients in K. Algebraic functions in several variables are defined similarly.

History

The ideas surrounding algebraic functions go back at least to René Descartes. The first discussion of algebraic functions appears to be in Edward Waring's An Essay on the Principles of Human Knowledge in 1794, in which he wrote: “let a quantity denoting the ordinate, be an algebraic function of the abscissa x, by the common methods of division and extraction of roots, reduce it into an infinite series ascending or descending according to the dimensions of x, and then find the integral of each of the resulting terms.”

Algebraic and transcendental functions

Functions that are not algebraic are called transcendental functions. Most familiar transcendental functions are the exponential, logarithmic, and trigonometric functions. A transcendental function is one that cannot be expressed as a finite combination of addition, subtraction, multiplication, division, raising to a power, and taking roots. Algebraic functions play an important role in mathematical analysis and algebraic geometry, where they are studied using the theory of Riemann surfaces.
