Linear code

In coding theory, a linear code is an error-correcting code for which any linear combination of codewords is also a codeword. Linear codes are described by a generator matrix and a parity-check matrix over a finite field, most often GF(2).

An [n, k, d] code encodes k symbols into blocks of length n with minimum Hamming distance d, allowing detection and correction of errors. Examples include Hamming codes, Reed–Solomon codes (as cyclic codes), Reed–Muller codes and LDPC codes.

Decoding

Syndrome decoding uses the parity-check matrix to identify the error pattern, enabling efficient correction up to the code's error-correcting capability.
