Context switch

A context switch saves one process's state and restores another's.

In computing, a context switch is the process of storing the state of a process or thread so that it can be restored and resume execution at a later point, and restoring the state of a different process or thread for execution on the same central processing unit. Context switches are the mechanism that allows a single CPU core to appear to run many tasks concurrently, the basis of multitasking operating systems.

Mechanism

The saved state, or context, includes the contents of the CPU registers, the program counter, the stack pointer, and memory-management information such as page tables. The operating system kernel stores this data in a process control block. Switches are triggered by a timer interrupt in preemptive scheduling, by a process blocking on input/output, or by a system call. Switching between threads of the same process is cheaper than switching between processes because the address space, and with it much cached translation and memory state, can be retained.

Costs

A context switch consumes processor time without doing useful work, typically a few microseconds, and it disturbs CPU caches and translation lookaside buffers, so the newly scheduled process runs more slowly until the caches refill. Excessive switching, known as thrashing in extreme cases, degrades performance, and switch rates are a standard operating system performance metric. Hardware support, such as tagged translation lookaside buffers, can reduce the cost.

In human cognition

By analogy, psychologists use "task switching" for the measurable cost people incur when shifting attention between activities.
