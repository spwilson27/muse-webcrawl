Null-terminated string

TypeData representation
Used inC, C++, assembly languages, Unix APIs
SentinelNUL character (0x00)

In computer programming, a null-terminated string is a character string stored as an array of characters terminated by a null character (a character with the value zero, written '\0' in C). This representation is the native string format of the C programming language and is consequently often called a C string.

Characteristics

Because the length of the string is not stored, finding it requires scanning the array until the terminator is found, an O(n) operation performed by functions such as strlen. The format requires only one byte of overhead regardless of string length, but it cannot contain embedded null characters, which makes it unsuitable for arbitrary binary data. Operations such as concatenation can be inefficient because the lengths of the operands must be recomputed by scanning.

History

Null-terminated strings descend from the .ASCIZ directive in PDP-11 assembly languages, where the "Z" indicated the zero-terminated form of ASCII text. The representation was adopted by C in the early 1970s and, through C's influence, by Unix system calls and many file formats and network protocols.

Security issues

Failure to ensure null termination, or trusting terminators in untrusted input, has been the source of many buffer overflow vulnerabilities. Functions such as strcpy copy until they find a terminator and will overrun the destination buffer if the source is too long; bounded alternatives such as strncpy, strlcpy, and snprintf are preferred. The alternative length-prefixed (Pascal string) representation avoids scanning but historically limited strings to 255 characters.
