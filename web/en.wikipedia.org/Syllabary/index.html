Syllabary

The Japanese kana are classic examples of syllabic writing.

A syllabary is a set of written symbols that represent the syllables or (more frequently) moras which make up words. A symbol in a syllabary, called a syllabogram, typically represents a consonant followed by a vowel, or just a vowel alone.

Syllabaries are best suited to languages with relatively simple syllable structure, since one symbol must exist for each syllable. Languages that use syllabaries today include Japanese (with its two kana systems, hiragana and katakana), Cherokee (whose syllabary was created by Sequoyah in the 1820s), and the Yi script of China. Historically, syllabaries included Linear B (used for Mycenaean Greek) and the Vai script of Liberia.

Comparison with other scripts

Unlike an alphabet, which has separate symbols for consonants and vowels, or an abugida, in which consonant symbols are systematically modified for each vowel, a true syllabary uses distinct, unrelated symbols for syllables that happen to share sounds. Japanese kana, for example, has unrelated glyphs for ka, ki, ku, ke, and ko.
