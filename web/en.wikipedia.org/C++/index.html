C++ (pronounced "C plus plus") is a high-level, general-purpose programming language created by Danish computer scientist Bjarne Stroustrup. First released in 1985 as an extension of the C programming language, it has since expanded significantly, adding object-oriented, generic and functional features alongside facilities for low-level memory manipulation.

History

Stroustrup began work on "C with Classes" at Bell Labs in 1979, wanting Simula-like classes with C's efficiency. The language was renamed C++ in 1983 (the ++ is C's increment operator). C++98 was the first ISO standard; subsequent revisions — C++11, C++14, C++17, C++20 and C++23 — added lambdas, concurrency, concepts, ranges and modules, roughly tripling the language's size while maintaining near-total backward compatibility.

Design philosophy

C++ aims for zero-cost abstractions ("you don't pay for what you don't use"), direct mapping to hardware, deterministic resource management via RAII, and a rich standard library including the STL containers and algorithms. It is implemented as a compiled language on virtually every platform and dominates performance-critical domains: operating systems, game engines, browsers, high-frequency trading, embedded systems and scientific computing.

Criticism

The language is frequently criticised for its complexity, manual memory management pitfalls, and slow compile times, motivating alternatives such as Rust; nevertheless it remains among the most widely used languages in the world.
