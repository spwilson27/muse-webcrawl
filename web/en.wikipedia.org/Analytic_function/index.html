Analytic function

Analytic function
FieldMathematical analysis (real and complex analysis)
DefinitionA function locally given by a convergent power series
ExamplesPolynomials, exponential, sine and cosine, rational functions (where defined)

In mathematics, an analytic function is a function that is locally given by a convergent power series. A function is analytic at a point if, in some neighbourhood of that point, it equals the sum of its Taylor series. There are both real analytic functions and complex analytic functions; analyticity is a strong regularity condition, stronger than mere smoothness.

Definitions

A real-valued function f on an open subset of the real line is real analytic at x₀ if it can be written as a power series in (x − x₀) that converges to f(x) for x near x₀. The definition for complex-valued functions of a complex variable is analogous, with complex powers. Every polynomial, the exponential function, and the trigonometric functions are analytic on their whole domains; rational functions are analytic wherever the denominator does not vanish.

Properties

Analytic functions are infinitely differentiable, and sums, products, quotients (where defined) and compositions of analytic functions are analytic. A striking rigidity holds in the complex case: a complex function that is differentiable once on an open set is automatically analytic there — such functions are called holomorphic, and for complex functions the two notions coincide. The identity theorem states that two analytic functions agreeing on a set with a limit point agree everywhere on their connected domain. Unlike smooth real functions, an analytic function is fully determined by its values on any small interval.

Non-analytic smooth functions

Not every smooth real function is analytic: the classic example f(x) = e−1/x² for x ≠ 0, f(0) = 0, is infinitely differentiable at 0, but its Taylor series there is identically zero and does not reproduce the function. Such examples have no complex analogue.
