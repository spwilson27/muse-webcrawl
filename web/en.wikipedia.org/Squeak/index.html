Squeak

Squeak is an object-oriented, class-based, reflective programming language, developed by a group led by Alan Kay and Dan Ingalls at Apple Computer and later Walt Disney Imagineering. It is a modern implementation of Smalltalk, derived directly from Smalltalk-80, and is available under an open-source licence.

Features

Squeak runs in a virtual machine image containing the whole system, with a graphical environment (Morphic) inherited from the Self language work. It supports live programming, in which code can be changed while the system runs. The Etoys educational environment and the Scratch visual programming language's early versions were built on Squeak, and the Croquet collaborative environment was implemented in it.

History

Squeak was released publicly in 1996. Descendants and related projects include Pharo, a fork focused on professional software development.
