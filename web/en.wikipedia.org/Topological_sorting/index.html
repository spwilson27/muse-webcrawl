Topological sorting

In computer science, a topological sort of a directed acyclic graph (DAG) is a linear ordering of its vertices such that for every directed edge u → v, vertex u comes before v in the ordering. A topological ordering exists if and only if the graph contains no directed cycles.

Algorithms

Kahn's algorithm (1962) repeatedly removes vertices with no incoming edges; an alternative approach uses depth-first search, appending each vertex to the ordering after all its successors have been visited. Both run in linear time, O(V + E). If the graph has a cycle, the algorithms detect that no complete ordering exists.

Applications

Topological sorting is used to schedule tasks with dependencies, order courses by prerequisites, resolve symbol dependencies in linkers, drive build systems such as make, and determine cell evaluation order in spreadsheets. The set of orderings of a DAG relates to partial orders in mathematics.
