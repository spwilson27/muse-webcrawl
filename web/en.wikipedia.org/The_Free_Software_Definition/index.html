SubjectDefinition of free software

The Free Software Definition, written by Richard Stallman and published by the Free Software Foundation (FSF), sets out the criteria a computer program must satisfy to be considered free software. The definition centers on the freedoms granted to users rather than on price: "free" is a matter of liberty, not cost — often summarized as "free as in speech, not as in beer."

The four essential freedoms

A program is free software if its users have four essential freedoms:

  • Freedom 0: the freedom to run the program as they wish, for any purpose.
  • Freedom 1: the freedom to study how the program works and change it, which requires access to the source code.
  • Freedom 2: the freedom to redistribute copies so as to help others.
  • Freedom 3: the freedom to distribute copies of modified versions, giving the whole community a chance to benefit from the changes; this too requires source access.

Interpretation and related rules

The definition is accompanied by clarifications: commercial use and commercial distribution are permitted; the freedoms must apply to all users without discrimination; and rules such as copyleft are acceptable as a means of protecting the freedoms, provided they do not restrict them. Licenses that satisfy the definition include the GNU General Public License, the Apache License, and the MIT License, among many others assessed by the FSF.

Relation to other definitions

The Free Software Definition predates and inspired the Open Source Definition (1998) maintained by the Open Source Initiative, which is largely based on the Debian Free Software Guidelines. In practice the two frameworks classify nearly the same licenses as acceptable, though the free software movement emphasizes the ethical dimension of user freedom while open source advocates stress practical benefits.
