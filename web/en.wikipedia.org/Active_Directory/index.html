Active Directory

Software
Developer:Microsoft
Initial release:1999 (with Windows 2000)
Type:Directory service

Active Directory (AD) is a directory service developed by Microsoft for Windows domain networks. Windows Server operating systems include it as a set of processes and services. Originally, only centralised domain management used Active Directory; however, it ultimately became an umbrella title for various directory-based identity-related services.

Overview

A server running the Active Directory Domain Service (AD DS) role is called a domain controller. It authenticates and authorises all users and computers in a Windows domain-type network, assigning and enforcing security policies for all computers and installing or updating software. For example, when a user logs into a computer that is part of a Windows domain, Active Directory checks the submitted username and password and determines whether the user is a system administrator or a normal user. Active Directory uses Lightweight Directory Access Protocol (LDAP) versions 2 and 3, Microsoft's version of Kerberos, and DNS.

Structure

The directory is organised hierarchically: objects (users, groups, computers, printers) reside in domains; domains form trees sharing a contiguous DNS namespace; and trees form forests, the top-level security boundary. Organisational units (OUs) subdivide domains for administration and Group Policy application. Each domain controller holds a writable (or, for read-only domain controllers, read-only) copy of the directory database (NTDS.dit), and changes replicate between controllers by multi-master replication; certain sensitive operations are held by single Flexible Single Master Operations (FSMO) role holders.

Related services

The Active Directory family has included Active Directory Federation Services (AD FS), Certificate Services (AD CS), Rights Management Services (AD RMS), and Lightweight Directory Services (AD LDS). Microsoft's cloud identity service, Microsoft Entra ID (formerly Azure Active Directory), provides related identity services for Microsoft 365 and Azure, and can synchronise with on-premises AD.
