Volume rendering

In scientific visualisation and computer graphics, volume rendering is a set of techniques used to display a 2D projection of a 3D discretely sampled data set, typically a grid of voxels. A typical data set is a stack of images from a CT, MRI, or industrial scanner, or the result of a three-dimensional simulation. Rather than extracting surfaces, volume rendering models the data as a semi-transparent, light-emitting and absorbing medium, allowing internal structures to be seen in context.

Methods

The most common technique is ray casting: for each pixel, a ray is cast through the volume, samples are accumulated along the ray according to a transfer function that maps data values to colour and opacity, and the samples are composited front-to-back or back-to-front. Other approaches include splatting, in which each voxel is projected onto the image plane as a small footprint; texture-based slicing, which draws stacks of planar slices through the volume; and the shear-warp factorisation, which accelerates rendering by separating the viewing transformation.

Transfer functions and classification

The visual result depends heavily on the transfer function, which classifies data values into materials — for example, rendering bone opaque and white while keeping soft tissue translucent. Designing effective transfer functions, including multidimensional ones based on gradient magnitude, is a major topic in visualisation research. Modern GPUs make interactive volume rendering routine in radiology workstations, surgical planning, reservoir engineering, and weather visualisation.
