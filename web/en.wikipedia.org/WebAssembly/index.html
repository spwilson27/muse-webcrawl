WebAssembly

WebAssembly (abbreviated Wasm) is a binary instruction format for a stack-based virtual machine. Wasm is designed as a portable compilation target for programming languages, enabling deployment on the web for client and server applications. It is an open standard maintained by a W3C Community Group and the World Wide Web Consortium.

History

WebAssembly was first announced in 2015, building on earlier work such as asm.js and Google Native Client. A minimum viable product was released in the major web browsers in 2017, and in December 2019 WebAssembly became a W3C Recommendation, becoming the fourth language that can run natively in web browsers alongside HTML, CSS and JavaScript.

Design

WebAssembly code is intended to be faster to parse and execute than JavaScript, with a compact binary encoding and near-native execution speed. It provides a sandboxed execution environment, validates types before execution, and offers memory safety features such as bounds-checked linear memory. Languages such as C, C++, Rust and Go can be compiled to WebAssembly, allowing existing code to be reused on the web.

Use outside the browser

Through the WebAssembly System Interface (WASI), Wasm modules can run outside the browser with access to system resources, supporting server-side, embedded and plugin use cases.
