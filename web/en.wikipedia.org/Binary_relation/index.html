Binary relation

In mathematics, a binary relation associates elements of one set, called the domain, with elements of another set, called the codomain. Formally, a binary relation from a set A to a set B is a subset of the Cartesian product A × B. When A = B, the relation is said to be on A (a homogeneous relation).

Properties

Relations on a set may be reflexive, symmetric, antisymmetric, or transitive. A relation that is reflexive, symmetric, and transitive is an equivalence relation, which partitions the set into equivalence classes. A relation that is reflexive, antisymmetric, and transitive is a partial order; examples include the "less than or equal to" relation on numbers and the subset relation on sets.

Examples

Familiar binary relations include equality, divisibility ("is a divisor of"), kinship relations such as "is a parent of," and the "less than" relation on integers. Functions are special binary relations in which each element of the domain is associated with exactly one element of the codomain.

Representation

Binary relations can be represented by directed graphs and by Boolean matrices, in which composition of relations corresponds to matrix multiplication.
