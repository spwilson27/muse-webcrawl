MP4 file format

MP4
Filename extension: .mp4, .m4a, .m4v, .m4p
Developed by: ISO/IEC, MPEG
Standard: ISO/IEC 14496-14

MPEG-4 Part 14, or MP4, is a digital multimedia container format most commonly used to store video and audio, but it can also store other data such as subtitles and still images. It is based on the QuickTime file format and the ISO base media file format.

History

MP4 was first published in 2001 as part of the MPEG-4 standard and revised in 2003. It became the most widely used format for streaming and downloading video over the Internet.

Data streams

Nearly all kinds of data can be embedded in MP4 files through private streams; a separate hint track is used to include streaming information.
