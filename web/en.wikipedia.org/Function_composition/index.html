Function composition

From Wikipedia, the free encyclopedia

In mathematics, function composition is an operation that takes two functions f and g and produces a new function h = g ∘ f such that h(x) = g(f(x)): the output of f becomes the input of g. Intuitively, composing functions is a kind of chaining: first apply one function to the input, then apply the other to the result.

Properties

Composition is always associative: (f ∘ g) ∘ h = f ∘ (g ∘ h), but it is generally not commutative — f ∘ g and g ∘ f usually differ, and one of them may not even be defined unless the codomain of the inner function matches the domain of the outer. The identity function acts as a neutral element for composition. In calculus, the chain rule describes how to differentiate a composite function:

(f ∘ g)′(x) = f′(g(x)) · g′(x)

Notation and examples

The small circle ∘ is the composition operator; thus (g ∘ f)(x) is read "g of f of x", with f applied first despite appearing on the right. If f(x) = x + 1 and g(x) = x², then (g ∘ f)(x) = (x + 1)², whereas (f ∘ g)(x) = x² + 1. In computer science, function composition is a core idiom of functional programming, and repeated self-composition of a function defines its functional powers and iterates, central to the study of dynamical systems.
