Chirp spread spectrum

Chirp spread spectrum (CSS)
Type: Spread-spectrum modulation
Signal: Linear frequency-modulated chirps
Uses: LoRa, IEEE 802.15.4a, radar, sonar

In digital communications, chirp spread spectrum (CSS) is a spread-spectrum technique that uses wideband linear frequency-modulated chirp pulses to encode information. A chirp sweeps its frequency upward or downward over time.

Properties

CSS offers resilience to multipath fading, Doppler shift and narrowband interference, and it can operate below the noise floor because of processing gain. Its ranging capability also makes it useful for localisation.

Applications

CSS underlies LoRa modulation used in low-power wide-area IoT networks, was standardised in IEEE 802.15.4a for precision ranging, and has long been used in radar and sonar pulse compression.
