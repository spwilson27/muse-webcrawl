Memory

Memory involves encoding, storage, and retrieval of information in the brain.

Memory is the faculty of the mind by which data or information is encoded, stored, and retrieved when needed. It is the retention of information over time for the purpose of influencing future action. Without memory, learning and language would be impossible.

Types of memory

Psychologists distinguish sensory memory, short-term (working) memory, and long-term memory. Long-term memory is divided into explicit (declarative) memory — episodic memory of events and semantic memory of facts — and implicit memory, such as procedural skills. The influential Atkinson–Shiffrin model describes information flowing through these stores.

Processes

Memory formation involves encoding, consolidation (in which the hippocampus plays a central role, especially during sleep), storage, and retrieval. Forgetting can result from decay, interference, or retrieval failure, and memories are reconstructive — they can be distorted, as shown by research on false memories and the misinformation effect.

Disorders

Damage to the medial temporal lobe can cause amnesia, famously illustrated by patient H.M., while Alzheimer's disease progressively destroys memory and cognition. Techniques such as spaced repetition and the method of loci can improve retention.
