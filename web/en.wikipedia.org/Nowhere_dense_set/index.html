Nowhere dense set

Nowhere dense set
FieldTopology
DefinitionA set whose closure has empty interior
Related conceptMeagre set (first category)

In mathematics, specifically general topology, a subset A of a topological space is said to be nowhere dense or rare if its closure has empty interior. Equivalently, A is nowhere dense if for every non-empty open set U there is a non-empty open subset V of U that contains no points of A — loosely, A does not fill up any region of the space, however small.

Examples

In the real numbers, the integers are nowhere dense: their closure is themselves and they contain no interval. Any finite set of points, a line in the plane, and the Cantor set are also nowhere dense. By contrast, the rational numbers are not nowhere dense in the reals, because their closure is the whole real line, whose interior is non-empty; they are, however, a countable union of nowhere dense sets (singletons).

Meagre sets and the Baire category theorem

A countable union of nowhere dense sets is called a meagre set or a set of the first category; a set that is not meagre is of the second category. The Baire category theorem states that a complete metric space is not meagre in itself — it cannot be expressed as a countable union of nowhere dense sets. This result has far-reaching consequences in functional analysis, including the uniform boundedness principle and the open mapping theorem.

Properties

The union of finitely many nowhere dense sets is nowhere dense, and every subset of a nowhere dense set is nowhere dense. A closed nowhere dense set in the real line can nonetheless have positive Lebesgue measure — for example, a "fat Cantor set" — so nowhere density is a notion of topological smallness, distinct from smallness in measure.
