Bernstein–Vazirani algorithm

The Bernstein–Vazirani algorithm is a quantum algorithm invented by Ethan Bernstein and Umesh Vazirani in 1992. It is a restricted version of the Deutsch–Jozsa algorithm in which, instead of distinguishing between two classes of functions, it determines a hidden string encoded in a black-box function.

Problem statement

Given an oracle that implements a function f(x) = s · x (mod 2), where s is a secret n-bit string, the task is to determine s. A classical algorithm must query the oracle n times, once for each basis vector, whereas the quantum algorithm solves the problem with a single query.

Algorithm

The algorithm prepares n qubits in a uniform superposition using Hadamard gates, applies the oracle, applies Hadamard gates again, and measures. The measurement outcome is exactly the secret string s. It was one of the earliest demonstrations of a quantum speedup, showing an oracle separation between the complexity classes BQP and BPP.

Significance

Together with the Deutsch–Jozsa algorithm, the Bernstein–Vazirani algorithm helped motivate Shor's period-finding algorithm and remains a standard introductory example of quantum parallelism and phase kickback.
