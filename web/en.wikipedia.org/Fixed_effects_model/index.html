Fixed effects model

A fixed effects model is a statistical model in which the model parameters are fixed (non-random) quantities. In panel data analysis, the term usually refers to a regression model that includes a separate intercept for each individual or group, thereby controlling for all time-invariant characteristics of the units observed.

Panel data estimation

In the fixed effects (within) estimator, each unit's observations are demeaned — expressed as deviations from that unit's average over time — which removes the effect of any unobserved variable that does not change over time. This makes the estimator consistent even when the unobserved individual effects are correlated with the explanatory variables, a key advantage over the random effects model, which assumes such correlation is absent. The Hausman test is commonly used to choose between the two.

Limitations

Because time-invariant variables are absorbed by the fixed effects, their coefficients cannot be estimated; the method also cannot be applied directly when the number of parameters grows with the sample size in short panels (the incidental parameters problem in non-linear models).
