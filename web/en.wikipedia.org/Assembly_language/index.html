Assembly language

TypeLow-level programming language
First appeared1947
TranslationAssembler converts to machine code

In computer programming, assembly language (or assembler language) is a low-level programming language in which there is a very strong correspondence between the instructions in the language and the architecture's machine code instructions. Each assembly language is specific to a particular computer architecture, such as x86 or ARM.

Structure

Assembly programs use short mnemonics such as MOV, ADD, and JMP to represent machine operations, along with symbolic names for registers, memory addresses, and labels. An assembler translates the source code into executable machine code, resolving symbols into actual addresses.

section .text
  mov eax, 1   ; exit syscall number
  xor edi, edi ; status 0
  syscall

Use

Assembly was the dominant way to program early computers. Today it is used where direct hardware control or maximum performance is critical: device drivers, embedded firmware, boot loaders, operating-system kernels, and performance-sensitive or security-sensitive routines. Most general software is written in higher-level languages, though compilers often emit assembly as an intermediate step.
