Graph (abstract data type)

In computer science, a graph is an abstract data type that models a collection of vertices (or nodes) connected by edges, implementing the graph concept from graph theory in mathematics. A graph data structure consists of a finite set of vertices together with a set of pairs of vertices, which are unordered in an undirected graph and ordered in a directed graph. Edges may carry values, in which case the graph is called weighted.

Representations

Two representations dominate in practice. In an adjacency list representation, each vertex stores a list of its neighbours; this is memory-efficient for sparse graphs, using O(|V| + |E|) space. In an adjacency matrix representation, a |V| × |V| matrix records which pairs of vertices are adjacent; this uses O(|V|²) space but allows constant-time edge existence tests. Other representations include incidence matrices and edge lists.

Operations

Typical operations on the graph abstract data type include adjacent(G, x, y) (test whether an edge joins vertices x and y), neighbours(G, x) (list all vertices adjacent to x), add_vertex, remove_vertex, add_edge and remove_edge, together with accessors for values stored on vertices and edges.

Traversals and algorithms

Fundamental graph algorithms built on this data type include breadth-first search and depth-first search, shortest-path algorithms such as Dijkstra's algorithm and the Bellman–Ford algorithm, minimum spanning tree algorithms (Prim's and Kruskal's), and topological sorting for directed acyclic graphs. Graphs model networks of communication, transportation, social relationships and dependencies, making the graph ADT one of the most widely used structures in computing.
