Font

In metal typesetting, a font is a particular size, weight, and style of a typeface. Each font is a matched set of metal type pieces, one for each glyph. In modern usage, the words "font" and "typeface" are often used interchangeably, although strictly a typeface (such as Times New Roman) is the design, while a font is a specific implementation of that design in a particular size and style—or, in digital typography, a computer file containing the typeface's glyphs and the instructions for displaying them.

Metal type sorts from a font, and digital fonts of one typeface in several sizes and weights.

Etymology

The word font (also spelled fount in British English) derives from Middle French fonte, meaning something that has been melted, referring to the casting of metal type at a type foundry. A complete set of cast characters supplied by a foundry was a "font."

Characteristics

A font is defined by attributes including weight (light, regular, bold), style (roman or italic), width (condensed or extended), and size, traditionally measured in points. In metal type, each point size required a separately cast font; digital outline fonts, stored as vector shapes in formats such as TrueType and OpenType, can be scaled to any size. Digital fonts may also contain features such as kerning pairs, ligatures, alternate glyphs, and hinting instructions for legibility at small sizes.

Digital fonts

Early computer fonts were bitmap fonts, with a fixed pattern of pixels for each size. Outline formats developed in the 1980s—notably Adobe's PostScript Type 1, Apple's TrueType, and the jointly developed OpenType—became the standards. Variable fonts, introduced with OpenType Font Variations in 2016, allow a single file to interpolate continuously across weight, width, and other axes. Web fonts delivered in the WOFF and WOFF2 formats allow pages to display typefaces not installed on the reader's device.
