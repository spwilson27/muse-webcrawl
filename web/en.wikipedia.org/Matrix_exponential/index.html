Matrix exponential

In mathematics, the matrix exponential is a matrix function on square matrices analogous to the ordinary exponential function. For a real or complex matrix X, it is defined by the convergent power series:

eX = I + X + X2/2! + X3/3! + ⋯

The matrix exponential is central to the theory of Lie groups and to solving systems of linear differential equations.

Properties

e0 = I, and det(eX) = etr(X). If X and Y commute, then eX+Y = eXeY; in general this fails, and the Baker–Campbell–Hausdorff formula gives the correction. Unlike the scalar exponential, the matrix exponential is always invertible, with inverse e−X. If X is diagonalisable, X = PDP−1, then eX = P eD P−1, where eD exponentiates each eigenvalue on the diagonal.

Applications

The solution of the linear system dx/dt = Ax with initial condition x(0) = x0 is x(t) = eAtx0. The exponential of a skew-symmetric matrix is a rotation matrix, and in quantum mechanics the unitary time-evolution operator is the exponential of the Hamiltonian. Numerically, scaling-and-squaring with Padé approximants is the standard algorithm, though a well-known critique cautions that many published methods are unreliable for some inputs.
