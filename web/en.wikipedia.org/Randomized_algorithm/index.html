Randomized algorithm

A randomized algorithm is an algorithm that employs a degree of randomness as part of its logic or procedure. The algorithm typically uses uniformly random bits as an auxiliary input to guide its behaviour, in the hope of achieving good performance in the "average case" over all possible choices of random determined by the random bits; thus either the running time, or the output (or both) are random variables.

Types

Randomized algorithms are commonly classified as Las Vegas algorithms, which always produce a correct answer but whose running time is random, and Monte Carlo algorithms, which run in fixed (usually short) time but may produce an incorrect answer with a small probability. Quicksort with a random pivot is a classic Las Vegas example; the Miller–Rabin primality test is a classic Monte Carlo example.

Motivation

Randomization can break the worst cases that deterministic algorithms suffer on adversarial inputs: a deterministic pivot rule for quicksort can be forced into quadratic behaviour, while a random pivot gives expected logarithmic-depth recursion on every input. Randomization also yields simple, elegant algorithms for problems — such as primality testing, polynomial identity testing, and minimum cut — for which deterministic methods are slower or more complicated.

Derandomization

A major theme in theoretical computer science is derandomization: determining when randomness genuinely adds power. Complexity classes such as RP, BPP and ZPP formalise problems solvable by efficient randomized algorithms, and it is widely conjectured that P = BPP, meaning randomness can in principle be removed with only polynomial slowdown.
