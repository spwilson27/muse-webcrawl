In mathematics, the n-th cabtaxi number, typically denoted Cabtaxi(n), is defined as the smallest number that can be expressed as a sum of two positive or negative or zero cubes in n ways. Such numbers exist for all n, since the identity used for taxicab numbers (allowing repeated use of cube terms with different signs) generalises.

Name and definition

The name is a pun on the famous taxicab number Ta(2) = 1729 = 13 + 123 = 93 + 103, associated with the Hardy–Ramanujan anecdote. "Cabtaxi" reverses the syllables, just as the definition relaxes the restriction to positive cubes, permitting negative cubes so that cancellations produce smaller examples.

Known values

The first cabtaxi numbers are:

  • Cabtaxi(1) = 1 = 1³ + 0³
  • Cabtaxi(2) = 91 = 3³ + 4³ = 6³ − 5³
  • Cabtaxi(3) = 728 = 6³ + 8³ = 9³ − 1³ = 12³ − 10³
  • Cabtaxi(4) = 2741256

Larger values, up to Cabtaxi(10), were found by computer search; Cabtaxi(10) = 933528127886979200000 was announced by Uwe Hollerbach in 2008, using methods in the spirit of earlier searches for taxicab numbers.

Properties

Because negative cubes are allowed, every taxicab-type identity with signs yields additional representations, so cabtaxi numbers grow more slowly than the corresponding taxicab numbers. The sequence is recorded in the On-Line Encyclopedia of Integer Sequences.
