Similar matrix

In linear algebra, two n-by-n matrices A and B are called similar if there exists an invertible n-by-n matrix P such that

B = P−1AP

Similarity is an equivalence relation on the space of square matrices. Two matrices are similar precisely when they represent the same linear operator with respect to two different bases; the matrix P is a change-of-basis matrix.

Properties

Similar matrices share many invariants: the same determinant, trace, rank, characteristic polynomial and hence the same eigenvalues (with the same algebraic multiplicities), the same minimal polynomial, and the same Jordan normal form (over an algebraically closed field). Conversely, equality of elementary divisors or of the rational canonical form characterises similarity completely. However, similar matrices need not have the same eigenvectors: if v is an eigenvector of A, then P−1v is an eigenvector of B.

Applications

Similarity transformations are used throughout matrix analysis: to diagonalise a matrix when possible (diagonalisation makes powers and exponentials easy to compute), to reduce matrices to canonical forms such as Jordan, Frobenius (companion) or Hessenberg form, and in control theory, where state-space realisations of the same system are related by similarity. Similarity over the complex numbers must be distinguished from congruence and equivalence, which correspond to different transformation laws.
