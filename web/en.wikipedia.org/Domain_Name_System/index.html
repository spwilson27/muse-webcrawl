Domain Name System

The Domain Name System (DNS) is a hierarchical and distributed name service that translates human-readable domain names, such as www.example.com, into the numerical IP addresses needed to locate computer services and devices worldwide. It has been an essential component of the Internet since 1985 and is often described as the Internet's "phone book."

History

In the ARPANET era, host names were distributed in a single file, HOSTS.TXT, maintained by Elizabeth Feinler's group at Stanford Research Institute. As the network grew, this centralised system became untenable. In 1983 Paul Mockapetris designed the DNS, specified in RFCs 882 and 883 and updated by RFCs 1034 and 1035, introducing a distributed, delegated database.

Structure and resolution

The namespace is a tree: a root zone served by root name servers, top-level domains (.com, .org, country codes such as .uk), and domains delegated to authoritative name servers. A recursive resolver, typically run by an ISP or public service, answers a client's query by walking this hierarchy and caching the result for a time-to-live period. Common record types include A and AAAA (addresses), MX (mail), CNAME (alias), NS, and TXT.

Security and extensions

The original protocol sends queries in cleartext over UDP port 53 and is vulnerable to spoofing and cache poisoning. DNSSEC adds cryptographic signatures to authenticate responses, while DNS over TLS and DNS over HTTPS encrypt queries for privacy. Governance of the root zone is coordinated by ICANN and the IANA functions.
