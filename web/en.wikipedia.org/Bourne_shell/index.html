Bourne shell

The Bourne shell (sh) is a Unix shell created by Stephen Bourne at Bell Labs. Released with Version 7 Unix in 1979, it replaced the Thompson shell and became the standard command-line interpreter and scripting language for Unix systems for many years.

Features

The Bourne shell introduced fundamental concepts still central to shell scripting: control structures such as if, for, while, and case; variables and command substitution; input/output redirection; pipes; here documents; signal handling with trap; and the use of the $ notation for parameter expansion. Shell scripts beginning with the #!/bin/sh shebang line remain ubiquitous.

Legacy

Although it lacked interactive conveniences such as job control and history editing, the Bourne shell's scripting language was standardized in POSIX and influenced all later shells. The KornShell, Bash (the "Bourne Again SHell"), and the Debian Almquist shell (dash) are among its descendants and successors, and a POSIX-compatible sh remains the default script interpreter on Unix-like systems.
