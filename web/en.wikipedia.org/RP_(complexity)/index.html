RP (complexity)

RP
Full name: Randomized polynomial time
Introduced by: John Gill (1977)
Related classes: P, BPP, co-RP, NP, ZPP

In computational complexity theory, RP (randomized polynomial time) is the complexity class of problems for which a probabilistic Turing machine exists with the following properties: it runs in polynomial time; if the correct answer is NO, it always returns NO; if the correct answer is YES, it returns YES with probability at least 1/2. In other words, the algorithm may err, but only on YES instances, and repeating it reduces the error probability exponentially.

Definitions and relations

The complementary class, co-RP, allows errors only on NO instances. The intersection of RP and co-RP is ZPP, the class of problems solvable in expected polynomial time with zero error. RP is contained in NP, since a YES answer together with the random choices that produced it acts as a witness. Whether RP equals P is open, though many complexity theorists suspect that randomness can be removed (derandomization), which would imply P = RP = BPP.

Example

A classic RP-type algorithm is the Miller–Rabin primality test in its original form, which never declares a prime number composite but may wrongly accept composites with bounded probability.
