Control unit

The control unit (CU) is a component of a computer's central processing unit (CPU) that directs the operation of the processor. A CU typically uses a binary decoder to convert coded instructions into timing and control signals that direct the operation of the other units (memory, arithmetic logic unit and input and output devices, etc.).

Most computer resources are managed by the CU. It directs the flow of data between the CPU and the other devices. John von Neumann included the control unit as part of the von Neumann architecture. In modern computer designs, the control unit is typically an internal part of the CPU with its overall role and operation unchanged since its introduction.

Operation

The control unit receives instructions from memory via the program counter, decodes the opcode of each instruction, and generates the control signals needed to carry it out: opening and closing register gates, setting the arithmetic logic unit to the required function, and coordinating transfers to and from memory and peripherals. The sequence of operations is driven by the system clock and by microoperations within each instruction cycle — fetch, decode, execute, and writeback.

Types

Control units are implemented either as hardwired control, in which combinational logic circuits generate the signals directly and which is fast but difficult to modify, or as microprogrammed control, in which control signals are stored as microinstructions in a control store. Microprogramming, proposed by Maurice Wilkes in 1951, made complex instruction sets easier to design and debug, at some cost in speed, and became standard in mainframe and minicomputer design.
