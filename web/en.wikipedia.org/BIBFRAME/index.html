BIBFRAME

BIBFRAME (Bibliographic Framework) is a data model for bibliographic description maintained by the Library of Congress. It was designed to replace the MARC encoding and cataloguing standards used by libraries, and to express bibliographic data as linked data using RDF.

Model

BIBFRAME organizes bibliographic description around the core classes Work, Instance, Item and Agent. A Work is the conceptual essence of a resource, an Instance reflects an individual material embodiment, and an Item is an actual copy of an Instance.

Development

The Library of Congress announced the Bibliographic Framework Initiative in 2011. BIBFRAME 2.0, published in 2016, revised the vocabulary and model, and conversion tools translate legacy MARC records into BIBFRAME descriptions.
