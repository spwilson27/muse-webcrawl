Web 2.0

From Wikipedia, the free encyclopedia

Web 2.0 (also known as participative or participatory web and social web) refers to websites that emphasise user-generated content, ease of use, participatory culture and interoperability (i.e., compatibility with other products, systems and devices) for end users. The term was coined by Darcy DiNucci in 1999 and popularised by Tim O'Reilly and Dale Dougherty at the first Web 2.0 Conference in 2004.

Characteristics

A Web 2.0 site allows users to interact and collaborate through social media dialogue as creators of user-generated content in a virtual community. This contrasts to earlier websites — retroactively labelled "Web 1.0" — where people were limited to passively viewing content created by site owners. Typical features include blogs, wikis, folksonomies (tagging), Ajax-powered rich interfaces, syndication via RSS and Atom, mashups, and APIs that let third parties build on a platform.

History and criticism

The term emerged as the web industry regrouped after the dot-com bust of 2001. Tim Berners-Lee, inventor of the World Wide Web, dismissed Web 2.0 as jargon, noting that the web was always designed to be participatory; others criticised the label as marketing hype. Nevertheless it became the standard description of the mid-2000s generation of services — YouTube, Facebook, Twitter and Wikipedia among them — that turned audiences into contributors.

Successors

Later labels have included the Semantic Web (sometimes styled "Web 3.0") and Web3, a proposed decentralised web based on blockchain technology.
