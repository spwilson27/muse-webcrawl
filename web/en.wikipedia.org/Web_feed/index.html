Web feed

A web feed (or news feed) is a data format used for providing users with frequently updated content. Content distributors syndicate a web feed, allowing users to subscribe to updates from websites, blogs, and podcasts in a single place using an aggregator or feed reader.

Formats

The two main feed formats are RSS (Really Simple Syndication), which became widely used in the early 2000s, and the Atom Syndication Format, standardized by the IETF in 2005. Both are XML-based. The JSON Feed format, launched in 2017, offers a JSON alternative. Feeds typically contain headlines, summaries or full text, publication dates, and links to the source content.

Use

Feed readers such as the former Google Reader (discontinued 2013) and services like Feedly let users follow many sources at once. Podcasting is built on RSS feeds with audio enclosures. While social media displaced feeds for many users, RSS remains a core open technology for blogs, news sites, and podcasts.
