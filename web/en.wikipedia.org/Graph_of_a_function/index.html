Graph of a Function

In mathematics, the graph of a function f is the set of ordered pairs (x, y), where f(x) = y. In the common case where x and f(x) are real numbers, these pairs are Cartesian coordinates of points in two-dimensional space and thus form a subset of this plane.

Definition

For a function f : X → Y, the graph is the set { (x, f(x)) : x ∈ X }. In the case of functions of two variables — that is, functions whose input consists of an ordered pair (x, y) — the graph usually refers to the set of ordered triples (x, y, z) where f(x, y) = z, which is a surface in three-dimensional space.

Examples

The graph of the function f(x) = x³ − 9x is the set of points {(x, x³ − 9x) : x is a real number}, which when plotted gives a cubic curve crossing the axes at −3, 0 and 3. The graph of a linear function is a straight line; the graph of a quadratic function is a parabola.

Tests and properties

The vertical line test states that a curve in the plane represents the graph of a function if and only if no vertical line intersects it more than once. Features of a graph reveal properties of the function: where the graph crosses the axes gives roots and intercepts; its rises and falls show intervals of increase and decrease; and its local maxima and minima correspond to turning points studied in calculus.

Generalizations

For functions of several variables the graph lies in higher-dimensional space and is studied through level curves, contour plots and surfaces. In set theory, a function is sometimes identified with its graph as a subset of the Cartesian product of its domain and codomain.
