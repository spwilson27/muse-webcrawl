Linear prediction

Linear prediction is a mathematical operation where future values of a discrete-time signal are estimated as a linear function of previous samples. In digital signal processing, linear prediction is often called linear predictive coding (LPC) and can thus be viewed as a subset of filter theory. In system analysis (a subfield of mathematics), linear prediction can be viewed as a component of mathematical modelling or optimization.

The prediction model

The most common representation is the autoregressive (AR) model, in which the predicted value of a signal sample xn is computed from a weighted sum of p previous samples:

x̂n = a1xn−1 + a2xn−2 + ⋯ + apxn−p

where the coefficients a1, …, ap are called the predictor coefficients and p is the prediction order. The difference between the actual value and the predicted value is the prediction error en = xn − x̂n.

Estimating the parameters

The most common choice in optimizing the parameters aj is the root mean square criterion, also called the autocorrelation criterion. In this method the expected value of the squared prediction error E[en2] is minimized, giving rise to the system of linear equations known as the Yule–Walker equations, which can be solved efficiently with the Levinson–Durbin algorithm. The autocorrelation method produces a predictor that is guaranteed to be stable.

Applications

Linear prediction is used in speech coding (linear predictive coding in standards such as GSM and VoIP codecs), spectral estimation, data compression, echo cancellation, and in time-series analysis in econometrics. Because the predictor coefficients can be derived from the autocorrelation of the signal, the method is closely related to the modelling of a signal as the output of an all-pole filter driven by white noise.
