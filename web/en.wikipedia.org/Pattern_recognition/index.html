Pattern recognition

Pattern recognition is the automated recognition of patterns and regularities in data. It is a branch of machine learning concerned with assigning labels to input values, such as classifying emails as spam or not spam, recognising handwritten digits, or identifying faces in images. Pattern recognition systems typically work by extracting measurable features from raw observations and applying a learned model to them.

Overview

A pattern is anything that can be described by a set of features. A pattern recognition system acquires data through sensors, preprocesses it, extracts features, and classifies it by comparison with knowledge gained from a training set. Approaches divide broadly into supervised learning, where training examples carry known labels, and unsupervised learning, such as clustering, where the structure must be discovered without labels.

Methods

Classical methods include statistical decision theory, template matching, nearest-neighbour classifiers, decision trees, support vector machines and ensemble methods. Since the 2010s, deep learning with multi-layer neural networks has dominated applications such as image classification, speech recognition and natural language processing, learning features automatically from large datasets.

Applications

  • Optical character recognition and handwriting recognition
  • Speech recognition and speaker identification
  • Computer vision, including face recognition and medical image diagnosis
  • Bioinformatics, such as protein structure and DNA sequence analysis
  • Seismic analysis, radar signal classification and document image analysis
  • Financial applications, including credit scoring and fraud detection
