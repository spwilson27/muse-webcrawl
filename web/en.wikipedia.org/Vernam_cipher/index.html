Vernam cipher

The Vernam cipher is a symmetric-key cipher invented by Gilbert Vernam, an engineer at AT&T Bell Labs, in 1917 and described in his 1919 patent. It is the cipher that underlies the one-time pad: the plaintext is combined, character by character, with a key using modular addition — originally the XOR operation applied to the five-bit Baudot code of teletype messages.

Operation

In Vernam's system, each plaintext character (encoded in Baudot code) was combined with a key character read from a punched paper tape using the exclusive-or operation. Because XOR is its own inverse, applying the same key stream to the ciphertext restores the plaintext. Vernam built the system into teletype equipment so that encryption and transmission happened simultaneously, an early example of automated, on-line encryption.

The one-time pad

Joseph Mauborgne of the U.S. Army Signal Corps recognised that if the key tape were perfectly random and never reused, the ciphertext would give away nothing about the plaintext. This variant is the one-time pad. In 1949 Claude Shannon proved mathematically that such a system achieves perfect secrecy: the ciphertext provides no information about the plaintext beyond its length. The price of this security is key management — key material as long as all the traffic must be generated, distributed and destroyed securely.

Use and influence

Vernam-type systems protected high-level teletype links for decades, including the Washington–Moscow hotline established in 1963. The design is also the conceptual ancestor of modern stream ciphers, which generate a pseudorandom keystream to combine with plaintext in the same way, trading the one-time pad's perfect secrecy for practical key lengths.
