zlib is a free software library used for data compression. Written by Jean-loup Gailly (compression) and Mark Adler (decompression), it implements the DEFLATE algorithm and defines the zlib data format (RFC 1950), and is a core component of the gzip file format (RFC 1952) and the PNG image format, which rely on its code and format.

Capabilities

The library provides in-memory compression and decompression functions, including stream processing, and computes checksums (Adler-32 and CRC-32) of uncompressed data. Its format wraps DEFLATE data with a two-byte header and an Adler-32 trailing checksum. The related gzip format, used for single-file compression, is supported through auxiliary functions.

Use and licensing

zlib is one of the most widely deployed software libraries in the world, shipped with operating systems, programming language runtimes, game consoles, and countless applications. It is distributed under the permissive zlib License, which allows use in commercial products without charge or attribution in binary form. Its longevity has also made it a notable target for security maintenance; a heap-based buffer overflow in its inflate function (CVE-2022-37434) illustrated the risks of long-lived infrastructure code.
