Test automation

[Placeholder image: Test_automation.png]

In software testing, test automation is the use of software separate from the software being tested to control the execution of tests and the comparison of actual outcomes with predicted outcomes. Test automation can automate some repetitive but necessary tasks in a formalised testing process already in place, or perform additional testing that would be difficult to do manually.

Approaches

Common approaches include unit testing frameworks such as JUnit and pytest, graphical user interface testing tools such as Selenium, and record-and-playback systems. Automated tests are a cornerstone of continuous integration and continuous delivery pipelines.
