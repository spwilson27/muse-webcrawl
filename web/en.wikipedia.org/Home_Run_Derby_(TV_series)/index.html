Home Run Derby (TV series)

Home Run Derby is a 1960 American television series in which Major League Baseball sluggers competed in head-to-head home run contests. Hosted by broadcaster Mark Scott, it featured stars such as Mickey Mantle, Willie Mays, Hank Aaron, Harmon Killebrew, and Ernie Banks.

Format

Two players alternated turns at bat; any swing that did not produce a home run (other than a foul) counted as an out, and three outs ended an inning, with nine innings per match. The winner received a cash prize and returned the following week, while the loser also received a smaller prize.

Legacy

Filmed at Wrigley Field in Los Angeles, the syndicated series ran for one season of 26 episodes but was rerun for decades. It inspired Major League Baseball's modern Home Run Derby held during All-Star festivities.
