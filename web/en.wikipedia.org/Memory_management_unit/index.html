Memory management unit

A memory management unit (MMU), sometimes called a paged memory management unit (PMMU), is a computer hardware unit that translates virtual addresses generated by the CPU into physical addresses in memory. The MMU performs the translation using page tables maintained by the operating system, typically speeding lookups with a cache called the translation lookaside buffer (TLB).

Operation

Memory is divided into fixed-size pages (commonly 4 KiB). The high bits of a virtual address form a virtual page number, which the MMU maps through one or more levels of page tables to a physical frame; the low bits (the offset) pass through unchanged. Page table entries carry permission bits (read, write, execute, user/supervisor) and flags such as "present"; an access to a non-present page raises a page fault, allowing the operating system to load the page from disk or allocate it on demand.

Functions

Beyond translation, the MMU enforces memory protection between processes, so each process sees its own virtual address space. This enables virtual memory, memory-mapped files, shared libraries and copy-on-write. Modern MMUs also support large pages, address-space identifiers, and second-level translation for virtualisation.

History

Early minicomputers and mainframes had separate MMU hardware; in microcomputers the MMU was at first an optional coprocessor (such as the Motorola 68851 for the 68020) and was integrated on-chip from the late 1980s, as in the Intel 80486 and Motorola 68030.
