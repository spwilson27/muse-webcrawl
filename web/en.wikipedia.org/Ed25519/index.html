Ed25519

From Wikipedia, the free encyclopedia

The twisted Edwards curve −x² + y² = 1 − (121665/121666)x²y² over the field modulo 2²⁵⁵ − 19.

Ed25519 is an EdDSA signature scheme using SHA-512 (SHA-2) and the twisted Edwards curve −x² + y² = 1 − dx²y² with d = −121665/121666, computed in the prime field modulo p = 2²⁵⁵ − 19; the curve is related to Curve25519 and was introduced by Daniel J. Bernstein and co-authors in 2011. It offers roughly 128 bits of security, fast signing and verification, and small 32-byte public keys and 64-byte signatures.

Properties

Ed25519 is deterministic: the signature nonce is derived from the message and a secret value, avoiding the catastrophic failures that random-nonce schemes such as ECDSA can suffer when random number generation is flawed. Its design avoids secret-dependent branches and memory lookups, providing resistance to side-channel attacks, and its parameters were chosen transparently to minimise suspicion of backdoors.

Adoption

Ed25519 is implemented in OpenSSH (as the default key type since version 9.5), GnuPG, libsodium, Signal and many other systems, and is standardised for use in TLS 1.3 and in RFC 8032 and FIPS 186-5.
