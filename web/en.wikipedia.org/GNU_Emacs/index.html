GNU Emacs is a free software text editor developed by the GNU Project and first released by Richard Stallman in 1985. It is the most popular member of the Emacs family of editors, whose lineage traces to the TECO macros written by Stallman and Guy L. Steele Jr. in 1976. GNU Emacs is often described as "an extensible, customizable, self-documenting, real-time display editor", because most of its editing functionality is implemented in its own dialect of the Lisp programming language, Emacs Lisp.

History

Stallman began work on GNU Emacs in 1984 as the first program of the GNU operating system. Version 13, the first public release, appeared in March 1985. James Gosling's earlier Gosling Emacs (1981) contributed code to early versions, leading to a later rewrite. Through the 1990s and 2000s GNU Emacs gained Unicode support, a graphical toolkit interface, and native compilation of Lisp code in version 28 (2022).

Architecture and extensibility

The editor core is a Lisp interpreter written in C, with the majority of commands implemented in Emacs Lisp. Users can redefine keys, record keyboard macros, and load packages extending Emacs into an email client (Gnus, Mu4e, Notmuch), an organiser (Org mode), a file manager (Dired), a debugger interface, and a development environment for dozens of programming languages. Version 29 added built-in support for the Language Server Protocol via Eglot and the Tree-sitter parsing library.

Culture

GNU Emacs is central to hacker culture: the long-running "editor war" with vi/Vim, the tongue-in-cheek "Church of Emacs", and Stallman's alter ego "St IGNUcius" all originate in its community. Org mode, originally by Carsten Dominik, has become a widely used plain-text system for notes, literate programming, and task management.
