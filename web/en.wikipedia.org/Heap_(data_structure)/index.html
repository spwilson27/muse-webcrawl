Heap (data structure)

In computer science, a heap is a tree-based data structure that satisfies the heap property: in a max heap, for any given node, the key of the parent is greater than or equal to the keys of its children; in a min heap, the parent's key is less than or equal to the children's keys. The node with the greatest (or smallest) key is always at the root, which makes heaps the classic implementation of the priority queue abstract data type.

Operations

The principal operations are insert (add a key, then bubble it up to restore the heap property), extract-max (or extract-min: remove and return the root, then sift the replacement down), and peek (return the root without removing it). For a binary heap of n elements, insert and extract run in O(log n) time and peek in O(1).

Binary heap

The binary heap, introduced by J. W. J. Williams in 1964 for the heapsort sorting algorithm, is usually implemented as an array in which the children of the node at index i are stored at indices 2i + 1 and 2i + 2. Building a heap from an arbitrary array (heapify) takes linear time.

Variants and applications

Other heap variants include the Fibonacci heap, binomial heap, pairing heap, and d-ary heap, which offer better amortised bounds for operations such as decrease-key. Heaps are used in Dijkstra's algorithm and Prim's algorithm for shortest paths and minimum spanning trees, in operating-system scheduling, and in the heapsort algorithm, which sorts in O(n log n) time using O(1) extra space.
