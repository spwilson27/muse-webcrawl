GitHub

GitHub is an online platform for software development and version control using Git. Founded in 2008, it provides hosting for software projects together with tools for collaboration such as pull requests, code review, issue tracking, and continuous integration. It is the world's largest host of source code and is used by over 100 million developers. GitHub, Inc. is a subsidiary of Microsoft, which acquired it in 2018 for $7.5 billion.

History

GitHub was founded by Tom Preston-Werner, Chris Wanstrath, P. J. Hyett, and Scott Chacon, and launched in April 2008. Built around the Git version-control system created by Linus Torvalds, it made distributed development social through features such as forking, pull requests, and user profiles. The platform grew rapidly to become the default home of open-source software, hosting projects such as the Linux kernel mirrors, Ruby on Rails, and countless others.

Microsoft's acquisition, announced in June 2018, initially raised concerns in the developer community, but GitHub continued to operate as an independent subsidiary under Nat Friedman and later Thomas Dohmke. In 2021 it reported more than 73 million developers, a figure that passed 100 million in 2023.

Services and features

GitHub offers free hosting for public repositories and paid plans for private repositories and enterprises. Its services include GitHub Actions for continuous integration and delivery, GitHub Pages for website hosting, GitHub Packages for software distribution, and GitHub Copilot, an AI pair-programming assistant launched in 2021. GitHub Sponsors allows users to fund open-source developers. The company is headquartered in San Francisco, California, and has been known for its mascot, the Octocat.
