Cross-validation (statistics)

Cross-validation, sometimes called rotation estimation or out-of-sample testing, is any of various similar model validation techniques for assessing how the results of a statistical analysis will generalize to an independent data set. Cross-validation is a resampling method that uses different portions of the data to test and train a model on different iterations. It is mainly used in settings where the goal is prediction, and one wants to estimate how accurately a predictive model will perform in practice.

K-fold cross-validation.

Motivation

A model fitted to a data set tends to perform better on that same data than on new data — a phenomenon called overfitting. Cross-validation estimates out-of-sample performance by repeatedly holding out part of the data, fitting the model on the remainder, and evaluating it on the held-out portion.

Types

k-fold cross-validation

In k-fold cross-validation, the original sample is randomly partitioned into k equal-sized subsamples. Of the k subsamples, a single subsample is retained as the validation data for testing the model, and the remaining k − 1 subsamples are used as training data. The process is repeated k times, with each of the k subsamples used exactly once as validation data. The k results are then averaged. Common choices are k = 5 or k = 10; stratified k-fold preserves class proportions in each fold.

Leave-one-out cross-validation

Leave-one-out cross-validation (LOOCV) is the limiting case where k equals the number of observations: each observation is used once as the test set while the rest form the training set. It has low bias but can have high variance and is computationally expensive for large data sets, though closed-form shortcuts exist for linear models.

Holdout and repeated splits

The simplest scheme splits the data once into training and test sets (the holdout method). Repeated random subsampling performs many such random splits and averages the results.

Uses

Cross-validation is used for model selection (choosing hyperparameters or among algorithms), for estimating generalization error, and within nested cross-validation when both tuning and evaluation must be unbiased. It is a standard tool in machine learning and applied statistics.
