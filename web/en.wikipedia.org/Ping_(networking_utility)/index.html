Ping (networking utility)

Original authorMike Muuss
ReleaseDecember 1983 (4.3BSD)
TypeNetwork diagnostic command
ProtocolICMP Echo Request/Reply

Ping is a computer network administration utility used to test the reachability of a host on an Internet Protocol (IP) network and to measure the round-trip time for messages sent from the originating host to the destination and back. It is available on virtually every network operating system and most embedded network equipment.

How it works

Ping operates by sending Internet Control Message Protocol (ICMP) Echo Request packets to the target host and waiting for an Echo Reply. The utility reports the number of packets transmitted and received, the percentage lost, and statistics of the round-trip times—minimum, average, maximum and standard deviation. By default, Unix-like versions run until interrupted, while the Windows version sends four requests.

History and name

The program was written in December 1983 by Mike Muuss of the US Army Ballistic Research Laboratory, who named it after the sound of sonar, by analogy with a sonar pulse sent out to detect a distant object. The name has also been given a humorous backronym, "Packet InterNet Groper". Ping quickly became the first tool reached for in troubleshooting: if a host answers a ping, basic connectivity exists, though firewalls that filter ICMP can make a live host appear unreachable.

Security

Ping has figured in several attacks, including the "ping of death" malformed-packet crash of the 1990s and ICMP ping flooding in denial-of-service attacks; responses include rate limiting and blocking echo requests at network boundaries. Related tools include traceroute, which maps the path packets take, and monitoring systems that ping hosts continuously to detect outages.
