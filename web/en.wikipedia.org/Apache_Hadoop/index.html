Apache Hadoop

Apache Hadoop is a collection of open-source software utilities that facilitate using a network of many computers to solve problems involving massive amounts of data and computation. It provides a software framework for distributed storage and processing of big data using the MapReduce programming model.

Components

  • HDFS — the Hadoop Distributed File System, which stores data in large blocks replicated across cluster nodes.
  • MapReduce — a programming model and processing engine that splits work into map and reduce tasks.
  • YARN — a resource management layer that schedules cluster resources among applications.
  • Hadoop Common — shared utilities supporting the other modules.

History

Hadoop was created by Doug Cutting and Mike Cafarella in 2005–2006, inspired by Google's published papers on MapReduce and the Google File System. Cutting named it after his son's toy elephant. It became a top-level Apache Software Foundation project and underpinned the "big data" movement of the 2010s, with an ecosystem of related tools including Hive, Pig, HBase, and Spark.
