Patch (computing)

From Wikipedia, the free encyclopedia

Modern operating systems deliver patches as software updates

A patch is a set of changes to a computer program or its supporting data designed to update, fix or improve it. Patches correct security vulnerabilities and other bugs, and may also add new features or improve performance and usability. The term recalls the era of punched cards and paper tape, when programs were literally repaired by patching over holes or splicing in corrected sections.

Types

Patches range from small binary fixes distributed by software vendors to source-code diffs circulated among developers. In Unix-like development, a patch file produced by the diff utility lists the lines to be added or removed, and the patch program applies it to a source tree — a workflow still fundamental to open-source collaboration. Vendors group patches into service packs, cumulative updates and hotfixes; emergency "out-of-band" patches address actively exploited vulnerabilities. Microsoft's monthly release of updates became widely known as "Patch Tuesday".

Patch management

Organisations practise patch management: inventorying software, testing updates, deploying them promptly and verifying installation. Delayed patching is a leading cause of security breaches — the 2017 WannaCry ransomware attack spread through a Windows vulnerability for which a patch had been available for two months — yet patches can also break systems, so critical environments balance speed against testing. Some systems support live patching, applying fixes to a running kernel or process without rebooting.

Unofficial patches

Users and communities also produce unofficial patches, fixing abandoned software, translating games, or modifying behaviour in ways vendors did not intend. In video-game culture, post-release patches ("day-one patches") that fix or rebalance games are now a normal part of the product lifecycle.
