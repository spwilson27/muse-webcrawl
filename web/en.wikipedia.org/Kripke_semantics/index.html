Kripke semantics (also called relational semantics or frame semantics) is a formal semantics for non-classical logic systems created by Saul Kripke in the late 1950s and early 1960s, beginning with his work on modal logic published while he was still a teenager. It interprets modal statements — about necessity, possibility, knowledge, obligation and the like — in terms of possible worlds connected by an accessibility relation.

Semantics for modal logic

A Kripke frame consists of a set W of worlds and a binary relation R on W. A model adds a valuation assigning to each world the atomic propositions true at it. A proposition is necessarily true at a world w (written □p) if it is true at every world accessible from w, and possibly true (◇p) if it holds at some accessible world. Different conditions on R — reflexivity, transitivity, symmetry — characterize different modal systems: T, S4, S5, and others.

Correspondences and completeness

Kripke proved completeness theorems matching these semantic conditions to axiomatic systems: for example, □p → p corresponds to reflexivity, and □p → □□p to transitivity. The resulting "correspondence theory" became a central tool in modal logic.

Extensions

Kripke semantics was adapted to intuitionistic logic, where truth is persistent along the accessibility ordering, and underlies possible-worlds analyses in philosophy, linguistics (dynamic semantics), and computer science, including the verification of reactive systems and epistemic reasoning about knowledge in distributed systems.

See also: Kurt Gödel (whose incompleteness results frame the limits of such formal systems).
