Country code top-level domain

A country code top-level domain (ccTLD) is an Internet top-level domain generally used or reserved for a country, sovereign state, or dependent territory identified with a country code. All ISO 3166-1 country codes are two letters, and all two-letter top-level domains are ccTLDs.

Examples

.us United States, .uk United Kingdom, .de Germany, .jp Japan, .cn China, .au Australia. Some ccTLDs are marketed globally, such as .tv (Tuvalu) for television, .me (Montenegro), .io and .ai. Delegation and administration are managed under IANA, often by national registries, with local registration policies varying widely.

Internationalised

IDN ccTLDs allow country codes in non-Latin scripts.
