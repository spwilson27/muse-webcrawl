Turán's theorem

Turán's theorem
Field: Extremal graph theory
Proved: 1941, by Pál Turán
Extremal graph: Turán graph T(n, r)

Turán's theorem is a fundamental result in extremal graph theory, proved by Pál Turán in 1941. It determines the maximum number of edges a graph on n vertices can have without containing a complete graph Kr+1 as a subgraph.

Statement

If G is a graph on n vertices with no (r+1)-clique, then the number of edges of G is at most (1 − 1/r)·n²/2. Equality holds uniquely for the Turán graph T(n, r), the complete r-partite graph whose parts are as equal in size as possible.

Significance

The theorem originated in a question Turán worked on while in a wartime labour camp, and it launched the field of extremal graph theory. The special case r = 2 generalises Mantel's theorem on triangle-free graphs. Turán-type problems now ask for the extremal number of edges avoiding any fixed forbidden subgraph.
