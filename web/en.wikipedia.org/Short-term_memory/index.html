Short-term memory

Duration: Seconds to about a minute
Capacity: About 7 ± 2 items (Miller)
Contrasts with: Long-term memory

Short-term memory (STM) is the capacity for holding a small amount of information in mind in an active, readily available state for a short period of time, typically seconds. It contrasts with long-term memory, which can store vastly more information for extended periods.

Capacity and duration

George Miller's famous 1956 paper proposed a capacity of "seven, plus or minus two" items, though later research suggests a smaller core capacity of about four chunks. Without rehearsal, short-term memories fade within roughly 15–30 seconds, as shown by the Brown–Peterson task.

Working memory

The related concept of working memory, developed by Alan Baddeley and Graham Hitch, describes short-term storage as an active system for manipulating information, with components such as the phonological loop and visuospatial sketchpad coordinated by a central executive. Working memory capacity is closely linked to reasoning and learning.

Biological basis

Short-term memory is thought to depend on persistent activity in prefrontal and parietal networks, whereas consolidation into long-term memory involves the hippocampus and synaptic changes.
