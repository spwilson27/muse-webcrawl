Cuckoo hashing

From Wikipedia, the free encyclopedia

Cuckoo hashing is a scheme in computer programming for resolving hash collisions of values of hash functions inside a hash table, using worst-case constant-time lookups. The name derives from the behaviour of some species of cuckoo, in which the cuckoo chick pushes other eggs or young out of the nest when it hatches — an incoming key likewise evicts the occupant of its cell. Cuckoo hashing was first described by Rasmus Pagh and Flemming Friche Rodler in 2001.

Operation

The scheme uses two hash functions, giving each key two possible locations in the table. Lookup examines only those two cells, guaranteeing constant worst-case time. Insertion places the new key in one of its positions; if occupied, the displaced key is moved to its alternative position, possibly displacing another key in turn, and the process continues until a free cell is found. If a cycle is detected after too many displacements, the table is rehashed with new hash functions. Deletion simply removes the key from whichever cell holds it.

Properties

Because lookups and deletions are constant-time in the worst case, cuckoo hashing is attractive for applications that cannot tolerate the variable latency of chaining. With the table kept less than about half full, insertions succeed in expected constant time. Variants use more than two hash functions, buckets holding several keys, or a small auxiliary stash for keys that would otherwise cause failure.
