KDE Plasma is a free and open-source graphical desktop environment developed by the KDE community, primarily for Linux and other Unix-like operating systems. It provides a desktop shell — panels, menus, widgets, a window manager (KWin), and system settings — that is notable for its extensive customisability.

History

Plasma was introduced with KDE 4 in 2008, replacing the earlier KDesktop and Kicker components with a widget-based "plasmoid" architecture. Plasma 5, first released in 2014, modernised the visual design with the Breeze theme and moved to a more modular release structure, with new versions roughly every four months. Plasma 6, released in February 2024, is built on Qt 6 and the KDE Frameworks 6, defaults to the Wayland display protocol on most distributions, and adopts a floating panel and double-click-to-open defaults.

Features and editions

Plasma supports movable panels, desktop and panel widgets, virtual desktops and Activities, the KRunner launcher, and deep configuration of shortcuts, themes, and window behaviour. Related shells built on the same technology include Plasma Mobile for phones and Plasma Bigscreen for televisions. Plasma is the default desktop in distributions such as KDE neon and Fedora KDE, and it powers the desktop mode of the Steam Deck handheld console.
