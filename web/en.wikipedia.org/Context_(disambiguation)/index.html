Context (disambiguation)

Context generally refers to the circumstances that form the setting for an event, statement or idea, in terms of which it can be fully understood. This disambiguation page lists articles associated with the title Context.

• Context (language use) — the social and situational factors governing utterance interpretation in pragmatics.
• Context clue — information in a text that helps define an unfamiliar word.
