OpenAPI Specification

The OpenAPI Specification, previously known as the Swagger Specification, is a specification for a machine-readable interface description language for describing, producing, consuming and visualising web services, especially RESTful APIs. It allows both humans and computers to discover a service's capabilities without access to source code.

Originally developed by SmartBear Software from its Swagger tooling donated in 2015, it is now maintained by the OpenAPI Initiative under the Linux Foundation, with members including Google, Microsoft, IBM and others. Descriptions are written in YAML or JSON and list paths, operations, parameters, request and response schemas, and security schemes.

Versions and tooling

Version 2.0 was Swagger; OpenAPI 3.0 was released in 2017 and 3.1 in 2021, aligning fully with JSON Schema. Tooling generates documentation (e.g. Swagger UI), client and server code, and tests from a specification.
