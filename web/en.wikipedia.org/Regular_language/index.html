Regular language

In theoretical computer science and formal language theory, a regular language is a formal language that can be recognized by a finite automaton. Regular languages occupy the lowest level of the Chomsky hierarchy (type-3 languages).

Equivalent descriptions

By Kleene's theorem, the following define exactly the same class of languages: languages accepted by deterministic finite automata, languages accepted by nondeterministic finite automata, and languages described by regular expressions. Regular languages are closed under union, intersection, complement, concatenation, and the Kleene star operation.

Non-regularity

Not all languages are regular: the classic example is the set of strings of the form anbn. The pumping lemma for regular languages provides a standard tool for proving that a language is not regular. Regular languages are widely applied in lexical analysis, text search, and pattern matching.
