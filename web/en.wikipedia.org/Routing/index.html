Routing


Routers forward packets between networks along paths chosen by routing protocols

Routing is the process of selecting a path for traffic in a network, or across multiple networks. It is performed by dedicated devices called routers, which forward packets between computer networks based on the destination addresses in packet headers. Routing decisions are recorded in routing tables, which map destination networks to next hops.

Overview

Broadly, routing is the control-plane activity that determines where traffic should go, whereas forwarding (or switching) is the data-plane activity that moves a packet from an input interface to an output interface. Routing protocols exchange reachability information between routers so that each device can build a consistent view of the network topology and compute the best paths.

Routing may be static, with routes configured manually by an administrator, or dynamic, with routes learned automatically through protocols. Dynamic protocols are divided into interior gateway protocols, used within a single autonomous system — such as OSPF and RIP — and exterior gateway protocols used between autonomous systems, principally the Border Gateway Protocol (BGP), which ties together the global Internet.

Path selection

When several paths to a destination exist, routers choose among them using metrics such as hop count, bandwidth, delay, load and cost, combined in algorithms including Dijkstra's shortest-path algorithm for link-state protocols and the Bellman–Ford algorithm for distance-vector protocols. Administrative distance ranks the trustworthiness of competing routing sources. Modern networks also perform policy-based routing, in which decisions consider business relationships, traffic-engineering goals or security requirements as well as raw metrics.

Routing architectures

In the Internet Protocol suite, routing operates at the network layer (layer 3). Addresses are aggregated into prefixes so that a single routing-table entry can represent many hosts, an approach formalised by Classless Inter-Domain Routing (CIDR). Other models include source routing, in which the sender specifies the path; on-demand routing in mobile ad hoc networks; and content-based routing in publish–subscribe and content-centric networks. Multicast routing delivers traffic from one source to a group of receivers along shared distribution trees.
