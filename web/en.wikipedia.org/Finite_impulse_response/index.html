Finite impulse response

Direct-form structure of an FIR filter.

In signal processing, a finite impulse response (FIR) filter is a filter whose impulse response (or response to any finite length input) is of finite duration, because it settles to zero in finite time. This is in contrast to infinite impulse response (IIR) filters, which may have internal feedback and may continue to respond indefinitely (usually decaying).

Definition

The output of an FIR filter of order N is a weighted sum of the current and a finite number of previous input values:

y[n] = b0x[n] + b1x[n−1] + … + bNx[n−N]

The coefficients bi are the filter's tap coefficients, and they are also the values of its impulse response. FIR filters are inherently stable, because the output is a sum of a finite number of finite input values multiplied by finite coefficients.

Properties

An important property of FIR filters is that they can be designed to have exactly linear phase, meaning that all frequency components of a signal are delayed by the same amount; this is achieved when the coefficient sequence is symmetric or antisymmetric. FIR filters require no feedback, so rounding errors in implementation do not accumulate through recursion. Their main disadvantage compared with IIR filters is that they generally require a higher filter order to achieve a given level of performance, and hence more computation and memory.

Design methods

Common design techniques include the window method (in which the ideal, infinite impulse response is truncated and multiplied by a window function such as the Hamming or Blackman window), the frequency sampling method, and optimal equiripple design using the Parks–McClellan algorithm (also known as the Remez exchange algorithm).
