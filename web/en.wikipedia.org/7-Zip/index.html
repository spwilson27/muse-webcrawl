7-Zip is a free and open-source file archiver, a program used to compress groups of files into archive containers. Developed by Igor Pavlov and first released in 1999, it is best known for its native 7z format, which uses the LZMA and LZMA2 compression algorithms and typically achieves higher compression ratios than the older ZIP format. The program is distributed under the GNU Lesser General Public License.

Features and formats

7-Zip can pack and unpack 7z, ZIP, Gzip, Bzip2, XZ and TAR archives, and can unpack many additional formats including RAR, ISO disc images, and various installer and virtual-disk formats. The 7z format supports AES-256 encryption, file-name encryption, solid (single-stream) compression of many files together, multi-volume archives and self-extracting executables. The Windows version provides a graphical file manager, shell context-menu integration, and a command-line interface; the console version, p7zip, serves Unix-like systems, and in 2021 an official Linux build was added.

Compression performance

Using LZMA with large dictionaries, 7z frequently produces archives 30–70 percent smaller than those of contemporary proprietary tools on typical data, at the cost of slower compression. 7-Zip has won several comparative reviews and was for many years among the most downloaded utilities on SourceForge, where it was a long-running project of the month. Though the original ZIP format remains more universally supported, 7z is widely used for software distribution, backups and large dataset transfers where bandwidth and storage dominate.
