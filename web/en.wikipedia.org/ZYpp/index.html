ZYpp

ZYpp (often called libzypp) is a software management engine and library that powers the package management tools of openSUSE and SUSE Linux Enterprise. Its name derives from "Zen / YaST Package Pact".

Repositorygithub.com/openSUSE/libzypp
Written inC++
Operating systemLinux
TypePackage management library

Features

ZYpp provides dependency resolution using a SAT solver, which models package dependencies as a boolean satisfiability problem and thereby resolves complex upgrade scenarios quickly and reliably. It supports RPM packages, multiple repositories, delta RPMs, and repository metadata in several formats.

Front ends

The best-known front end is zypper, a command-line package manager. YaST's software management module also uses libzypp, as do graphical tools built on PackageKit.

History

ZYpp emerged from the merger of SUSE's YaST package management with Novell's ZENworks Linux Management technology after Novell's acquisition of Ximian and SUSE in 2003.
