A* search algorithm

A* (pronounced "A-star") is a graph traversal and pathfinding algorithm known for its completeness, optimality, and efficiency. It was described in 1968 by Peter Hart, Nils Nilsson, and Bertram Raphael at Stanford Research Institute, as part of the Shakey the Robot project. A* is an extension of Dijkstra's algorithm that uses a heuristic estimate to guide the search toward the goal.

How it works

For each node n, A* tracks g(n), the exact cost of the cheapest path found from the start, and estimates the remaining cost with a heuristic h(n). Nodes are expanded in order of f(n) = g(n) + h(n), using a priority queue (the "open set"). If the heuristic is admissible — it never overestimates the true remaining cost — A* is guaranteed to return an optimal path; if it is also consistent, no node ever needs to be re-expanded.

Applications and variants

A* and its descendants are standard tools for route planning in video games, robot navigation, road-network routing, and puzzle solving. Variants include weighted A*, IDA* (iterative deepening), SMA* (memory-bounded), and dynamic replanners such as D* used on planetary rovers. In the worst case its time and memory grow exponentially with problem size, so practical performance depends heavily on the quality of the heuristic.
