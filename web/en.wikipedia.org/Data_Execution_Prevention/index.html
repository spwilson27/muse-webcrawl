Data Execution Prevention

Data Execution Prevention (DEP) is a security feature included in modern operating systems, including Microsoft Windows. It prevents an application or service from executing code from a non-executable memory region, thwarting exploits that attempt to run injected code from data pages such as the heap or stack.

How it works

DEP relies on processor hardware — the NX (no-execute) bit on AMD processors or the XD (execute disable) bit on Intel processors — to mark memory pages as non-executable, supplemented by software-enforced checks. Introduced for Windows in Windows XP Service Pack 2 and Windows Server 2003 Service Pack 1, DEP can be configured per-application (OptIn), system-wide (OptOut), or always on (AlwaysOn). It is complemented by Address Space Layout Randomization (ASLR).
