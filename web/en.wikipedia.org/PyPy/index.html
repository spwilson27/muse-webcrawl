PyPy is an alternative implementation of the Python programming language, designed as a drop-in replacement for the standard CPython interpreter. Its most notable feature is a just-in-time (JIT) compiler, which can make many pure-Python programs run several times faster than under CPython.

Design

PyPy is written in RPython ("Restricted Python"), a subset of Python that can be translated to native code. This meta-tracing architecture allows the JIT compiler to be generated automatically from the interpreter definition. PyPy supports Python 2.7 and Python 3.x lines in separate releases, and it aims for broad compatibility with existing Python code.

Compatibility and performance

Most pure-Python libraries work unchanged on PyPy. Historically, compatibility with CPython C extension modules — a large part of the scientific Python ecosystem — has been the chief limitation, though a compatibility layer (cpyext) has steadily improved. In return, long-running pure-Python workloads often see substantial speedups, offset by higher memory use and JIT warm-up time.
