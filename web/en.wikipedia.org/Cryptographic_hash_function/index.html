Cryptographic hash function

A cryptographic hash function (CHF) is a hash algorithm that maps data of arbitrary size to a bit string of fixed size (a "digest") with special security properties that make it suitable for use in cryptography. It is a one-way function — practically infeasible to invert, i.e. to recreate the input data from its hash value alone.

Properties

An ideal cryptographic hash function has five main properties: it is deterministic; it is quick to compute; it is infeasible to generate a message from its hash except by brute force (preimage resistance); a small change to a message changes the hash extensively (the avalanche effect); and it is infeasible to find two different messages with the same hash (collision resistance).

Applications

Hash functions underpin digital signatures, message authentication codes, password storage, file and data integrity checks, and proof-of-work systems such as those used in cryptocurrencies. Widely used designs include the SHA-2 and SHA-3 families; older functions such as MD5 and SHA-1 are no longer considered secure against collisions.

Construction

Many hash functions are built with the Merkle–Damgård construction from a one-way compression function, while SHA-3 (Keccak) uses the sponge construction. Attacks exploiting length-extension or structural weaknesses have driven the move toward newer designs.
