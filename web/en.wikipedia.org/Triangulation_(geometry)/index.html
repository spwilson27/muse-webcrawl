Triangulation (geometry)
Subdivision of a geometric object into triangles or simplices

In geometry, a triangulation is a subdivision of a planar object into triangles, or more generally a subdivision of a higher-dimensional geometric object into simplices. A triangulation of a polygon divides its interior into triangles meeting edge-to-edge, using non-crossing diagonals.

Types

A point-set triangulation divides the convex hull of a set of points into triangles using the points as vertices; the Delaunay triangulation maximises the minimum angle and is widely used in mesh generation. A polygon with n vertices can always be triangulated into n − 2 triangles.

Applications

Triangulations underpin computer graphics rendering, finite element analysis, terrain modelling and geographic information systems.
