In set theory, an ordinal number, or ordinal, is a generalisation of the concept of a natural number that is used to describe a way to arrange a (possibly infinite) collection of objects in order, one after another. Ordinals were introduced by Georg Cantor in 1883 as a way to accommodate infinite sequences and to classify sets with certain well-ordered structures.

Ordinals as order types

Any finite collection can be put in order; the size of the collection is described by a cardinal number, while the manner of its ordering is described by an ordinal. Two well-ordered sets have the same ordinal if and only if there is an order-preserving bijection between them. The finite ordinals are just the natural numbers 0, 1, 2, …; the first infinite ordinal is denoted ω (omega).

Von Neumann definition

In the standard von Neumann construction, each ordinal is defined as the set of all smaller ordinals: 0 = ∅, 1 = {0}, 2 = {0, 1}, and so on. Every ordinal is then a transitive set well-ordered by set membership, and every well-ordered set is order-isomorphic to a unique ordinal.

Transfinite arithmetic and induction

Ordinal arithmetic (addition, multiplication, exponentiation) extends the finite operations but is not commutative: 1 + ω = ω, while ω + 1 is strictly greater. Ordinals support transfinite induction and transfinite recursion, foundational tools in set theory. The class of all ordinals is not a set — this is the Burali-Forti paradox.
