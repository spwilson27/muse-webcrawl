Mixture model

In statistics, a mixture model is a probabilistic model for representing the presence of subpopulations within an overall population, without requiring that an observed data set identify the subpopulation to which an individual observation belongs. A mixture distribution is formed as a weighted sum (convex combination) of component distributions:

p(x) = Σk wk · pk(x), with weights wk summing to 1.

Gaussian mixture models

The most common example is the Gaussian mixture model (GMM), in which each component is a normal distribution with its own mean and variance (or covariance matrix, in the multivariate case). GMMs are widely used for clustering, where each observation is softly assigned a probability of belonging to each component — in contrast to hard assignments as in k-means clustering, which can be viewed as a limiting special case.

Estimation

Because component membership is unobserved (a latent variable), the parameters of a mixture model are usually estimated by maximum likelihood using the expectation–maximisation (EM) algorithm, which alternates between computing posterior membership probabilities and re-estimating component parameters. Challenges include choosing the number of components, avoiding degenerate solutions, and the label-switching problem in Bayesian treatments.

Applications

Mixture models are used in density estimation, image segmentation, speaker identification, topic modelling (in the form of latent Dirichlet allocation, a related hierarchical model), anomaly detection, and modelling heterogeneous populations in biology and economics.
