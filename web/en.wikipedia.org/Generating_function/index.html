Generating function

From Wikipedia, the free encyclopedia

In mathematics, a generating function is a way of encoding an infinite sequence of numbers (an) by treating them as the coefficients of a formal power series. The ordinary generating function of a sequence is defined as G(x) = a0 + a1x + a2x² + a3x³ + ⋯. By manipulating the series algebraically or analytically, one can extract information about the sequence, such as closed forms, recurrences and asymptotic growth.

Types

Several kinds are in common use. The ordinary generating function uses terms anxn. The exponential generating function uses anxn/n!, and is natural for labelled combinatorial structures. Dirichlet generating functions use an/ns and appear in analytic number theory, where the Riemann zeta function is the generating function of the constant sequence 1.

Applications

Generating functions are central tools in combinatorics and probability. The Fibonacci numbers have the rational generating function x/(1 − x − x²), from which Binet's formula can be derived. In probability theory, the probability-generating function of a discrete random variable and the moment-generating function of a distribution summarise, respectively, probabilities and moments. Herbert Wilf's book generatingfunctionology popularised the subject, describing a generating function as "a clothesline on which we hang up a sequence of numbers for display".
