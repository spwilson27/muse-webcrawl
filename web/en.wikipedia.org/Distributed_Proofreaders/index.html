Distributed Proofreaders

Distributed Proofreaders (DP) is a web-based project founded in 2000 by Charles Franks to support the digitization of public domain books. Originally intended to assist Project Gutenberg, Distributed Proofreaders is now the main source of e-texts for Project Gutenberg and an official Project Gutenberg site since 2002.

Volunteers proofread and format scanned pages of books, one page at a time, comparing the OCR-generated text against the page image. As of recent counts, the community has contributed more than 45,000 books to Project Gutenberg.

Process

Each book project moves through multiple rounds:

  1. Proofreading rounds (P1, P2, P3) — successive volunteers compare the text to the scan, correcting OCR errors
  2. Formatting rounds (F1, F2) — volunteers add markup for italics, headings, footnotes and other structure
  3. Post-processing — a single volunteer assembles the final text, generating plain-text and HTML versions
  4. Smooth reading — volunteers read the finished book for flow and report any remaining errors

Splitting the work into short, page-sized tasks allows thousands of volunteers to contribute in small increments, an early example of crowdsourcing in digital preservation.

History

Distributed Proofreaders was set up in October 2000 and grew rapidly; in July 2006 it was incorporated as the Distributed Proofreaders Foundation. Sister sites were established for other languages and regions, including DP Canada and DP Europe (later folded into the main site). The project is closely associated with the textual scholarship tradition of preserving works accurately.
