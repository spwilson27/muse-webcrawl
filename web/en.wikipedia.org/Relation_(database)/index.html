Relation (database)

In relational database theory, a relation is a set of tuples sharing the same attributes — in practice, what is represented by a table in a relational database. The concept was introduced by E. F. Codd in 1970 as the foundation of the relational model.

Definition

Formally, a relation is defined over a heading of attribute-name and data-type pairs; its body is a set of tuples, each tuple assigning a value to every attribute. Because a relation is a set, it has no duplicate tuples and no inherent ordering of rows or columns.

Relations and tables

SQL tables differ from true relations in permitting duplicate rows, nulls, and column ordering, a divergence sometimes criticised by relational theorists. Operations on relations are described by relational algebra and relational calculus, including selection, projection, union, and join.
