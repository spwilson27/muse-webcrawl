Audio power amplifier

An audio power amplifier is an electronic amplifier that increases the power of an audio-frequency signal so that it can drive a loudspeaker. It is typically the final stage in an audio playback chain, following a preamplifier.

Amplifier classes

Designs are categorised by output-stage topology: class A conducts continuously and is inefficient but linear; class B and AB reduce dissipation; class D uses pulse-width modulation and high-efficiency switching, now common in compact and high-power designs.

Specifications

Key measures include output power into a given load, total harmonic distortion, signal-to-noise ratio, frequency response and damping factor.
