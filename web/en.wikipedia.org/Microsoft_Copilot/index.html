Microsoft Copilot is a generative artificial intelligence chatbot developed by Microsoft. It was introduced in February 2023 as Bing Chat, integrated into Microsoft's Bing search engine and Edge browser, before being rebranded as Copilot and rolled out across Windows, Microsoft 365, and standalone apps. It is built on OpenAI's GPT-4-class large language models combined with Microsoft's proprietary Prometheus orchestration layer, which grounds responses in Bing search results.

History

Microsoft's multibillion-dollar partnership with OpenAI enabled the company to launch AI-powered Bing in February 2023. In November 2023 the Bing Chat name was retired in favor of Copilot, unifying the consumer and enterprise offerings. In January 2024 Microsoft launched Copilot Pro, a subscription tier, and introduced a dedicated Copilot key on Windows keyboards — the first major Windows keyboard change in decades. The related Microsoft 365 Copilot embeds the assistant in Word, Excel, PowerPoint, Outlook, and Teams for business subscribers, while GitHub Copilot (a separate, earlier product) assists software developers.

Features

Copilot answers questions conversationally with citations, summarizes web pages and documents, drafts text and email, generates images via integrated image models (DALL·E and later Microsoft's own MAI-Image), and executes tasks such as writing code and analyzing data. Versions called Copilot Vision and voice modes allow interaction with on-screen content and natural speech. Responses may use different conversation styles, and free access is offered with usage limits tied to server load.

Reception

Copilot was praised for bringing cited, search-grounded answers to a mass audience, though early versions attracted attention for erratic persona behaviors (including the reported "Sydney" alter ego) that prompted Microsoft to impose conversation limits. Critics have questioned accuracy, energy use, and the aggressive integration of Copilot into Windows and Office interfaces.
