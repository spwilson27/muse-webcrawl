Bias of an estimator

In statistics, the bias of an estimator (or bias function) is the difference between this estimator's expected value and the true value of the parameter being estimated. An estimator or decision rule with zero bias is called unbiased. In statistics, "bias" is an objective property of an estimator. A biased estimator may still be useful; for example, in many cases a biased estimator has lower mean squared error than any unbiased estimator, a trade-off known as the bias–variance tradeoff.

Definition

Suppose we have a statistical model, parametrized by a real number θ, giving rise to a probability distribution for observed data, and a statistic, θ̂, which serves as an estimator of θ based on any observed data. That is, we assume that our data arise from some unknown distribution, and we estimate θ using the estimator θ̂. Then the bias of this estimator is defined to be the difference between its expected value and the true value: Bias(θ̂) = E[θ̂] − θ.

An estimator is said to be unbiased if its bias equals zero for all values of the parameter, or equivalently, if the expected value of the estimator matches that of the parameter.

Examples

Sample variance

The sample variance of a random variable demonstrates two aspects of estimator bias: firstly, the usual estimator 1/n Σ(xi − x̄)2 is biased, which can be corrected by using the sample variance with 1/(n−1) instead; secondly, the unbiased estimator sample standard deviation is biased, since the square root of an unbiased estimator is not necessarily unbiased.

Estimating a population maximum

For example, suppose the parameter θ is the upper bound of a uniform distribution on [0, θ] and the estimator is the maximum of the sample. The expected value of the sample maximum is (n/(n+1))θ, so the bias is −θ/(n+1), and the estimator is biased downward.

Median-unbiased estimators

The theory of median-unbiased estimators was revived by George W. Brown in 1947. An estimate of a one-dimensional parameter θ is said to be median-unbiased if, for a fixed θ, the median of the distribution of the estimate is at the value θ; i.e., the estimate underestimates just as often as it overestimates.

Bias with respect to other loss functions

Any minimum-variance mean-unbiased estimator minimizes the risk (expected loss) with respect to the squared-error loss function, as shown by the Gauss–Markov theorem. A minimum-average absolute deviation median-unbiased estimator minimizes the risk with respect to the absolute loss function, as observed by Laplace.
