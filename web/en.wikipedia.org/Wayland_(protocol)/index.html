Wayland (protocol)

Wayland is a communication protocol that specifies the communication between a display server and its clients, together with a C library implementation of that protocol. A display server using the Wayland protocol is called a Wayland compositor, because it additionally performs the task of a compositing window manager. Wayland was developed to replace the aging X Window System (X11) protocol with a simpler, more secure and more performant design.

Architecture

In Wayland, the compositor is the display server: clients render their own window contents into buffers (using OpenGL, Vulkan or CPU rendering) and pass buffer handles to the compositor, which combines them into the final screen image and handles input, output and window management. Unlike X11, there is no separate window manager or compositing manager, and clients are isolated: an application cannot read another application's window contents or snoop on its keystrokes, closing major X11 security holes. Functionality that X11 clients took for granted — screen capture, global hotkeys, remote display — is instead provided through restricted protocols and portals such as PipeWire and xdg-desktop-portal. Legacy X11 applications run through the XWayland compatibility server.

History and adoption

Kristian Høgsberg, then at Red Hat, began Wayland in 2008 as a side project; the reference compositor Weston followed. Fedora adopted Wayland by default with GNOME in 2016, and Ubuntu followed (after a detour) in 2021. Through the 2020s most major Linux distributions and desktop environments made Wayland their default session, while NVIDIA driver support and some accessibility and remote-desktop tools lagged for years. The protocol is specified in XML; extension protocols are standardised through the wayland-protocols project.
