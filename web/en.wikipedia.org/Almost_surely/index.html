Almost surely

In probability theory, an event is said to happen almost surely (often abbreviated a.s.) if it happens with probability 1. In other words, the set of possible exceptions may be non-empty, but it has probability 0. The concept is analogous to the concept of "almost everywhere" in measure theory.

Definition

Formally, if (Ω, F, P) is a probability space, an event E in F happens almost surely if P(E) = 1. Equivalently, a property holds almost surely if the set of outcomes for which it fails is contained in a set of measure zero. A property that holds almost surely is sometimes said to hold for almost all outcomes, even though the exceptional outcomes may genuinely be possible — they are simply so "small" that they occur with probability zero.

Examples

If a fair coin is tossed repeatedly, the outcome in which heads appears every single time is possible, but it has probability zero; hence a coin tossed infinitely many times will almost surely come up tails at least once. Similarly, a randomly chosen real number in [0, 1] is almost surely irrational, because the rationals form a set of Lebesgue measure zero.

Uses

The notion is central to the strong law of large numbers, which states that sample averages converge to the expected value almost surely, and to the theory of almost sure convergence of sequences of random variables, which is stronger than convergence in probability.
