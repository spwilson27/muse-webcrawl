The Invisible Web, also called the deep web or hidden web, is the portion of the World Wide Web whose contents are not indexed by standard web search engines. It is the opposite of the "surface web", the pages reachable and indexable by ordinary crawlers. The term was coined by Jill Ellsworth in 1994 and popularised by a 2001 BrightPlanet white paper, which estimated the deep web to be hundreds of times larger than the surface web.

Why content is invisible

Search engines cannot index content that is generated dynamically in response to a query (such as library catalogues, flight availability and database records), sits behind login forms or paywalls, is deliberately excluded via robots.txt, consists of unlinked pages, or is in formats crawlers handle poorly. The largest share of the Invisible Web is perfectly ordinary: webmail inboxes, online banking, corporate intranets, academic databases and dynamically generated shopping results.

Deep web versus dark web

The Invisible Web should not be confused with the dark web, a much smaller set of services deliberately concealed on overlay networks such as Tor and reachable only with special software. The dark web is a subset of the deep web, but the vast majority of deep-web content is neither hidden intentionally nor illicit — merely unindexed.

Access

Library and academic "federated search" tools, specialised vertical search engines and direct database interfaces provide gateways into invisible-web content. Search engines have gradually absorbed portions of it by indexing form-based and JavaScript-generated content, but database back-ends remain largely beyond general crawlers.
