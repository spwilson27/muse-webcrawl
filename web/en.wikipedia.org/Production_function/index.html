Production function

In economics, a production function gives the technological relation between quantities of physical inputs and quantities of output of goods. It specifies the maximum output that can be produced with a given set of inputs, usually written Q = f(K, L) for capital K and labour L.

Common forms

The Cobb–Douglas production function, Q = A·Kα·Lβ, introduced by Charles Cobb and Paul Douglas in 1928, is widely used because output elasticities are constant and factor shares correspond to the exponents. Other forms include the linear function (perfect substitutes), the Leontief fixed-proportions function (perfect complements), and the constant elasticity of substitution (CES) function, which generalises Cobb–Douglas.

Concepts

Analysis of production functions yields concepts such as the marginal product of an input, diminishing returns, the marginal rate of technical substitution, and returns to scale — whether output rises proportionally (constant), more than proportionally (increasing), or less (decreasing) when all inputs are scaled. Aggregate production functions underpin growth models such as the Solow model.
