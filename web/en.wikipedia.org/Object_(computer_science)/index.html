Object (computer science)

Image placeholder: Diagram of an object with fields and methods
An object bundles state (fields) and behavior (methods)

In computer science, an object is an entity with state, behavior, and identity: it stores data (in fields, attributes, or properties) and exposes operations (methods) that act on that data. Objects are the central construct of object-oriented programming (OOP), in which programs are organized as collections of interacting objects rather than as sequences of procedures operating on separate data.

Concepts

In class-based languages such as Java, C++, and C#, objects are instances of classes, which define their fields and methods; in prototype-based languages such as JavaScript, objects inherit directly from other objects. Objects support key OOP principles:

  • Encapsulation — bundling data with the methods that operate on it, and hiding internal representation.
  • Inheritance — deriving new object types from existing ones, reusing and extending behavior.
  • Polymorphism — letting objects of different types respond to the same interface.
  • Abstraction — exposing only essential features while concealing implementation detail.

Object lifetime

Objects are typically created (instantiated) at run time, often residing in heap memory. Their lifetime ends when they are explicitly destroyed or when a garbage collector reclaims them after they become unreachable. In languages like C++, object lifetime is bound to scope or explicit new/delete operations, governed by constructors and destructors.

Related meanings

"Object" also refers to entities in other computing contexts: objects in object databases, objects stored in object storage systems (such as Amazon S3), and object files produced by compilers. See also object type for the type-theoretic notion.
