Dataflow programming

Dataflow programming is a programming paradigm that models a program as a directed graph of operations ("actors" or nodes) connected by data flows. An operation executes as soon as all of its inputs become available, so execution is driven by data rather than by an explicit sequence of instructions.

Examples

Dataflow concepts appear in spreadsheet formulas, reactive programming, stream-processing systems such as Apache NiFi and Node-RED, visual environments like LabVIEW and Max/MSP, and hardware description in digital signal processing. Early dataflow computer architectures of the 1970s and 1980s, developed by researchers including Jack Dennis at MIT, explored machines that executed instructions purely on operand availability.
