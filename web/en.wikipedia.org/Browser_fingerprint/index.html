Browser fingerprint

A browser fingerprint (also called a device fingerprint when applied more broadly) is information collected about a web browser and the device it runs on — such as the operating system, installed fonts and plugins, screen resolution, timezone, language settings, and the user agent string — for the purpose of identifying individual browsers and tracking users across websites, even when cookies are blocked or deleted.

How it works

When a user visits a website, scripts can query many properties of the browser and device. Combinations of these attributes are often unique: research by the Electronic Frontier Foundation (the Panopticlick project) showed that most browsers carry a fingerprint that distinguishes them from the vast majority of others. Techniques include canvas fingerprinting, which exploits small rendering differences in drawn graphics, and AudioContext fingerprinting.

Uses and privacy concerns

Fingerprinting is used legitimately for fraud prevention and account security, but also for cross-site tracking and analytics without user consent. Because users cannot easily clear a fingerprint, privacy advocates regard it as more intrusive than cookie-based tracking. Defences include browser anti-fingerprinting features, standardised configurations (as in the Tor Browser), and noise-adding extensions.
