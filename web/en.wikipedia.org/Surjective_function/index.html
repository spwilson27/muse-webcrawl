Surjective function

In mathematics, a surjective function (also known as a surjection, or an onto function) is a function f such that, for every element y of the function's codomain, there exists at least one element x in the function's domain such that f(x) = y. In other words, the image (range) of a surjective function equals its codomain.

Definition and examples

Formally, a function f : X → Y is surjective if for every y ∈ Y there exists x ∈ X with f(x) = y. The identity function on any set is surjective, as is the projection of a Cartesian product onto one of its factors. The function f(x) = 2x from the integers to the even integers is surjective, while the squaring function from the real numbers to the real numbers is not, because negative numbers have no real preimage.

Properties

A function is bijective if and only if it is both surjective and injective. Every function factors as the composition of a surjection and an injection. A function has a right inverse if and only if it is surjective; conversely, if a function has a left inverse it must be injective. The composition of surjective functions is surjective. In set theory, the existence of surjections relates to comparisons of cardinality: there is a surjection from X onto Y only if the cardinality of X is at least that of Y.

History of the term

The terminology of surjection, injection and bijection was introduced by the Bourbaki group in the mid-20th century; "sur" is French for "on", reflecting that the function maps "onto" its entire codomain.
