Smith–Waterman algorithm

The Smith–Waterman algorithm performs local sequence alignment; that is, it determines similar regions between two strings of nucleic acid sequences or protein sequences. Instead of looking at the entire sequence, the Smith–Waterman algorithm compares segments of all possible lengths and optimizes the similarity measure. The algorithm was first proposed by Temple F. Smith and Michael S. Waterman in 1981.

The scoring matrix used in the Smith–Waterman dynamic program

Explanation

Like the Needleman–Wunsch algorithm, of which it is a variation, Smith–Waterman is a dynamic programming algorithm. A scoring matrix H is built in which negative scores are replaced by zero, so that only positive-scoring local alignments are retained. The optimal local alignment is found by locating the cell with the maximum score and tracing back until a cell with score zero is reached.

H(i,j) = max { 0,
               H(i-1,j-1) + s(a_i, b_j),
               H(i-1,j) - d,
               H(i,j-1) - d }

Here s is a substitution score from a scoring matrix such as BLOSUM or PAM, and d is a gap penalty. The algorithm runs in O(mn) time for sequences of lengths m and n, which motivated accelerated implementations and heuristics such as BLAST and FASTA for database searching.

Applications

Smith–Waterman alignment is a standard step in DNA read mapping, protein homology detection, and the alignment of sequencing reads to reference genomes. Hardware and GPU implementations, as well as striped vectorized variants, have reduced its practical cost substantially.
