Encapsulated PostScript

Encapsulated PostScript (EPS) is a Document Structuring Conventions–conforming PostScript document format, developed by Adobe, for including graphics in other documents. An EPS file is a PostScript program describing a single page illustration, with a bounding box comment that lets layout software position it.

Characteristics

EPS files carry the magic comment %!PS-Adobe-3.0 EPSF-3.0 and a %%BoundingBox line. They may embed an optional preview image (TIFF or WMF) for screens that cannot render PostScript. EPS was ubiquitous in desktop publishing and professional printing workflows.

Decline

PDF has largely superseded EPS for print exchange, though EPS remains supported in illustration and typesetting (notably LaTeX) workflows.
