Web 1.0

Web 1.0 is a retronym referring to the first stage of the World Wide Web's evolution, roughly from 1991 to the early 2000s. The term was coined after Web 2.0 entered use around 2004, to describe the earlier web of mostly static pages: content was created by a relatively small number of publishers and read by a large audience, with little user interaction beyond hyperlinks, guestbooks, and email forms.

Characteristics

Typical Web 1.0 sites consisted of static HTML pages served from filesystems rather than databases, often built with early tools or written by hand. Common features included framesets, table-based layout, GIF buttons, "under construction" signs, hit counters, and online advertisements in banner form. Content management, user accounts, comments, and social features were rare; commerce was limited, though early retailers such as Amazon and eBay emerged in this period.

Transition

Technologies such as server-side scripting (PHP, ASP), content management systems, and later Ajax blurred the boundary, but the conceptual shift to the "participatory web"—user-generated content, blogs, wikis, and social networking—was marketed as Web 2.0 after the dot-com crash. Some commentators, including Tim Berners-Lee, have noted that the original web was always intended to be read-write, making the 1.0/2.0 distinction partly a marketing construction.
