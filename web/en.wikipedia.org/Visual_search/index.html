Visual search

Visual search is a type of perceptual task that requires attention, involving an active scan of the visual environment for a particular object or feature (the target) among other objects or features (the distractors). It is a fundamental ability used in everyday life — finding a friend in a crowd, locating keys on a desk, or a radiologist scanning an image for a tumour.

Feature and conjunction search

In Anne Treisman's feature integration theory, a target distinguished by a single primitive feature (colour, orientation, size, motion) "pops out" and is found quickly regardless of the number of distractors — feature search. A target defined only by a combination of features requires serial, attention-demanding conjunction search, in which reaction time increases with set size. Later work showed conjunction searches can be guided by preattentive feature information, as formalised in Jeremy Wolfe's guided search model.

Factors affecting search

Search efficiency depends on target–distractor similarity, distractor heterogeneity, crowding, and the prevalence of the target: very rare targets are missed more often, a problem in medical screening and airport baggage inspection. Search terminates either when the target is found or when the observer judges it absent; quitting thresholds adapt to target prevalence and the cost of errors.

Applications

Visual search research informs human factors design, radiology training, security screening, and computer vision systems that model attention to predict where observers will look.
