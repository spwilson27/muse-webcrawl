Logistic regression

Logistic regression is a statistical model that estimates the probability of a binary outcome from one or more predictor variables, using the logistic (sigmoid) function.

Model

The log-odds (logit) of the outcome is modelled as a linear combination of predictors: log(p/(1−p)) = β₀ + β₁x₁ + … . Coefficients are usually estimated by maximum likelihood. Exponentiated coefficients give odds ratios.

Applications

It is used in medicine (predicting disease presence), social science, marketing and machine learning as a simple classifier. Extensions include multinomial logistic regression for multi-category outcomes and ordinal models for ranked outcomes.

History

The logistic function was developed by Pierre Verhulst in the 19th century for population growth; the regression method was developed largely by David Cox in 1958.

Evaluation

Model fit is assessed with tools such as ROC curves and AUC, calibration tests and likelihood-ratio tests.
