Dynamic loading

A program loading a library during execution (placeholder image)

Dynamic loading is a mechanism by which a computer program can, at run time, load a library or other binary into memory, retrieve the addresses of functions and variables contained in it, and execute those functions or access those variables. It differs from dynamic linking, in which libraries are loaded automatically when a program starts; with dynamic loading, the program itself decides if and when to load a module.

Mechanism

On Unix-like systems, programs use the functions dlopen(), dlsym(), dladdr() and dlclose(), declared in <dlfcn.h>, to open a shared object, resolve symbols within it, and unload it. On Windows, the equivalent functions are LoadLibrary, GetProcAddress and FreeLibrary. If the requested library does not exist, the loading call fails and the program can fall back gracefully.

Uses

Dynamic loading enables plug-in architectures, in which features are discovered and added at run time; optional functionality that loads only when needed; and software that adapts to the libraries available on a particular machine. Language runtimes for C, C++, Java (via class loaders and reflection), Python and others expose similar facilities.
