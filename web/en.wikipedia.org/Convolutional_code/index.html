Convolutional code

In telecommunication, a convolutional code is a type of error-correcting code that generates parity symbols via the sliding application of a boolean polynomial function to a data stream. The sliding application represents the "convolution" of the encoder over the data, which gives rise to the term "convolutional coding". Unlike block codes, the encoding of each output symbol depends not only on the current input symbols but also on previous ones, giving the encoder memory.

Description

A convolutional encoder is characterized by its code rate (for example 1/2, meaning one input bit produces two output bits) and its constraint length, the span of input bits influencing the output. The encoder is typically implemented with shift registers and modulo-2 adders defined by generator polynomials. Codes are often "punctured" — some parity bits are omitted — to achieve higher rates from a single parent code.

Decoding

The standard decoding method is the Viterbi algorithm (1967), a maximum-likelihood sequence estimation procedure that traces the most probable path through the encoder's trellis diagram. Sequential decoding and the BCJR algorithm are alternatives; BCJR also supplies soft outputs useful in iterative ("turbo") decoding schemes.

Applications

Convolutional codes have been widely used in deep-space communication (including the Voyager program with the famous rate-1/2, constraint-length-7 code), satellite links, GSM and other cellular systems, and Wi-Fi. They are often concatenated with Reed–Solomon block codes, and in modern systems are complemented or replaced by turbo codes and LDPC codes.

History

Convolutional codes were introduced by Peter Elias in 1955. Efficient decoding came with the Viterbi algorithm (1967) and the sequential decoding work of Wozencraft and Fano, making the codes practical for power-limited channels.
