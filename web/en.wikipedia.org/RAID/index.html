RAID

RAID combines multiple physical disks into one logical unit

RAID ("redundant array of independent disks", formerly "redundant array of inexpensive disks") is a data storage virtualisation technology that combines multiple physical disk drives into one or more logical units for data redundancy, performance improvement, or both. The concept was defined in a 1987 paper by David Patterson, Garth Gibson, and Randy Katz at the University of California, Berkeley.

Standard levels

RAID 0 stripes data across drives for performance with no redundancy. RAID 1 mirrors data, surviving the loss of a drive. RAID 5 stripes data with distributed parity, tolerating one drive failure, while RAID 6 uses double parity to tolerate two. RAID 10 combines mirroring and striping. Other schemes include RAID 2, 3, and 4 (largely obsolete) and nested and non-standard variants.

Implementation

RAID can be implemented in dedicated hardware controllers, in software by the operating system, or in firmware. Common failure modes include controller failure and the "write hole" in parity RAID, in which a crash during a write leaves parity inconsistent with data.

Reliability

RAID protects against drive failure but is not a substitute for backup: it does not guard against deletion, corruption, or loss of the whole array. Rebuild times on large modern drives increase the window in which a second failure is fatal, a factor motivating erasure coding in distributed storage systems.
