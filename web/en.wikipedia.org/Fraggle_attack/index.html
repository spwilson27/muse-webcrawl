Fraggle attack

A Fraggle attack is a type of distributed denial-of-service (DDoS) attack that uses UDP amplification to flood a target with traffic. It is a variant of the Smurf attack, substituting the User Datagram Protocol (UDP) for ICMP.

Mechanism

In a Fraggle attack, the attacker sends UDP packets with a spoofed source address — the victim's address — to the broadcast address of a network, typically aimed at UDP ports 7 (echo) and 19 (chargen). Hosts on the network that run these services respond to the victim rather than the attacker, amplifying the traffic volume and overwhelming the victim's bandwidth and processing capacity. Because the replies come from many reflectors, the attack is difficult to trace and filter.

Mitigation

Standard defenses include disabling directed broadcast forwarding on routers, turning off unused UDP echo and chargen services, ingress filtering to block spoofed source addresses (as recommended in BCP 38), and rate limiting at network edges. Modern operating systems and router defaults disable the vulnerable services, making classic Fraggle attacks far less common than in the late 1990s when they were first publicized.
