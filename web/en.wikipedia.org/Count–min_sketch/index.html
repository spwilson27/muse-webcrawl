Count–min sketch

Count–min sketch
TypeProbabilistic data structure
Invented2003, by Graham Cormode and S. Muthu Muthukrishnan
PurposeApproximate frequency counts in data streams
ErrorOverestimates only; bounded with high probability

The count–min sketch is a probabilistic data structure that serves as a frequency table of events in a stream of data. It uses hash functions to map events to frequencies, trading a controlled amount of accuracy for drastically reduced space compared with exact counting.

Structure

The sketch is a two-dimensional array of counters with width w and depth d. Each incoming item is hashed by d independent hash functions, one per row, and the corresponding counter in each row is incremented. To estimate an item's count, the structure takes the minimum of its d counters — hence the name.

Error properties

Because different items can collide, estimates may be too high but never too low. With width proportional to e/ε and depth proportional to ln(1/δ), the estimate exceeds the true count by more than ε times the total stream count with probability at most δ. This makes the sketch ideal for finding "heavy hitters" — items with high frequency — in massive streams.

Applications

Count–min sketches are used in network traffic monitoring, database query optimisation, natural-language statistics, and large-scale systems such as content-delivery and advertising platforms, where exact counts over huge vocabularies are infeasible. Related structures include the Count sketch and Bloom filters.
