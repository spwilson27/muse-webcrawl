Dynamic programming language

A dynamic programming language is a class of high-level programming languages that execute many common programming behaviors at run time that static languages perform at compile time, or omit entirely. These behaviors may include extending the program by adding new code, extending objects and definitions, or modifying the type system, all during program execution. Most dynamic languages are also dynamically typed, but not all are.

Examples

Well-known dynamic languages include JavaScript, Python, Ruby, PHP, Perl, Lua, Lisp and its dialects, and Smalltalk. Many combine dynamic features such as reflection, eval, garbage collection, and first-class functions. The term was popularized in contrast to statically typed, compiled languages such as C, Java, and Haskell, though the boundary is porous: static languages increasingly include dynamic features, and dynamic languages increasingly offer optional static typing (as in Python's type hints or TypeScript for JavaScript).

Features

  • Dynamic typing: types are associated with run-time values rather than variables or expressions.
  • Reflection: programs can inspect and modify their own structure — classes, methods, and objects — at run time.
  • Eval and macros: code can be constructed and executed dynamically.
  • Duck typing: an object's suitability is determined by the presence of methods and properties rather than its declared class.

Performance

Historically slower than compiled static languages, dynamic languages have closed much of the gap through just-in-time compilation, as in modern JavaScript engines (V8) and PyPy for Python, though peak performance and early error detection remain common arguments for static typing.
