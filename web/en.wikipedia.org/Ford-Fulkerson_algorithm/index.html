Ford–Fulkerson algorithm

The Ford–Fulkerson algorithm is a greedy algorithm that computes the maximum flow in a flow network. It was published in 1956 by L. R. Ford Jr. and D. R. Fulkerson. The idea is to repeatedly find an augmenting path from the source to the sink along which additional flow can be pushed, and to add that flow, until no such path exists in the residual network.

Algorithm

Starting from zero flow, the algorithm searches the residual graph — which includes reverse edges allowing flow to be "undone" — for a path with available capacity. The minimum residual capacity along the path (the bottleneck) is added to the flow on each edge. When no augmenting path remains, the flow is maximal; this is guaranteed by the max-flow min-cut theorem, also proved by Ford and Fulkerson, which states that the value of a maximum flow equals the capacity of a minimum cut.

Complexity

The running time depends on how augmenting paths are chosen. With integer capacities and poor path choices, the algorithm can be slow, and with irrational capacities it may fail to terminate. Choosing shortest augmenting paths by breadth-first search gives the Edmonds–Karp algorithm, which runs in polynomial time.

Applications

Maximum-flow methods underpin applications in transport, telecommunications, bipartite matching, and scheduling.
