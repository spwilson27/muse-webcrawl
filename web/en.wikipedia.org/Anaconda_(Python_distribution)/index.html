Anaconda is a distribution of the Python and R programming languages for scientific computing and data science that aims to simplify package management and deployment. The distribution includes data-science packages suitable for Windows, Linux, and macOS. It is developed and maintained by Anaconda, Inc., which was founded by Peter Wang and Travis Oliphant in 2012 as Continuum Analytics.

Features

Anaconda ships with the conda package and environment manager, which installs binary packages and their dependencies across languages and platforms, easing the installation of libraries that require compilation. The full distribution includes over 250 automatically installed packages — among them NumPy, pandas, SciPy, scikit-learn, Matplotlib, and Jupyter — with thousands more available from the Anaconda repository and community channels such as conda-forge. The graphical Anaconda Navigator provides a launcher for applications including JupyterLab, Spyder, and RStudio.

Editions

Besides the full Anaconda Distribution, the company offers Miniconda, a minimal installer containing only conda and Python, widely used in automated environments. Business and enterprise editions add security, repository management, and support. Terms of service changes in 2020 regarding commercial use by large organisations prompted debate within the open-source community about licensing, while the underlying conda ecosystem remains freely used by individuals and academia.
