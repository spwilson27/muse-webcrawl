Package manager

A package manager or package-management system is a collection of software tools that automates the process of installing, upgrading, configuring, and removing computer programs for a computer in a consistent manner. It typically maintains a database of software dependencies and version information to prevent software mismatches and prerequisites. Packages are distributions of software and data in archive files, together with metadata such as the software's name, purpose, version, vendor, and a list of dependencies necessary for proper functioning.

Functions

Package managers download packages from repositories, verify their integrity (often with cryptographic signatures), resolve and install dependencies, and track which files each package owns so that removal and upgrades are clean. They reduce the burden of manual installation and help administrators keep large numbers of machines consistent.

Examples

On Linux, distribution package managers include dpkg and APT (Debian and Ubuntu), RPM and DNF (Fedora and Red Hat), Pacman (Arch Linux), and Portage (Gentoo). Language-specific package managers, such as npm for JavaScript, pip for Python, Cargo for Rust, and Maven for Java, manage libraries rather than whole systems. On other platforms, examples include Homebrew for macOS, Chocolatey and winget for Windows, and the app stores on mobile operating systems, which serve a similar role for applications.

History

Package management emerged in the mid-1990s as free Unix-like systems grew: Debian's dpkg and Red Hat's RPM both date from 1993–1995, and APT's automatic dependency resolution (1998) set the pattern for modern tools. The concept built on earlier dependency problems jokingly called "dependency hell".
