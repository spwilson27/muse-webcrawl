Virtual function

Virtual function
Concept: object-oriented programming
Mechanism: dynamic dispatch, usually via a virtual method table (vtable)
Languages: C++, C#, Java (by default), and others

In object-oriented programming, a virtual function or virtual method is a function whose behaviour can be overridden in a derived class, so that a call made through a base-class pointer or reference invokes the most-derived override at run time. This is the principal mechanism of runtime polymorphism.

Implementation

Compilers typically implement virtual functions with a per-class virtual method table (vtable): each object of a polymorphic class carries a hidden pointer to its class's vtable, and calls are indirected through the appropriate slot. This adds a small memory and time cost compared with statically bound calls.

Pure virtual functions

A pure virtual function (declared in C++ with = 0) has no implementation in the base class, making the class abstract: it cannot be instantiated, and derived classes must supply the function to be concrete. Pure virtual functions define interfaces. Related concepts include virtual destructors — needed so that deleting a derived object through a base pointer destroys it correctly — and the contrast with templates and static polymorphism, which resolve calls at compile time.
