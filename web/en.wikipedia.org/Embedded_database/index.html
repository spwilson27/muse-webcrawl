Embedded database

An embedded database system is a database management system (DBMS) which is tightly integrated with an application software that requires access to stored data in such a way that the database system is "hidden" from the application's end user and requires little or no ongoing maintenance. The library providing the database is linked directly into the application process rather than running as a separate server.

Characteristics

Embedded databases typically offer a small footprint, fast startup, zero administration, and direct in-process access, at the cost of features needed for large multi-user deployments, such as network access and elaborate concurrency control — though many handle multiple connections within a single application.

Examples

Well-known embedded databases include SQLite, by far the most widely deployed database engine, found in web browsers, mobile operating systems, and countless applications; others include Berkeley DB, LevelDB, RocksDB, and Apache Derby.
