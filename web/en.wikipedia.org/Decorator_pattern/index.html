Decorator pattern


Decorator pattern class diagram

In object-oriented programming, the decorator pattern is a design pattern that allows behavior to be added to an individual object, dynamically, without affecting the behavior of other objects from the same class. It is one of the structural patterns described in the 1994 book Design Patterns by the "Gang of Four."

Motivation

The pattern provides a flexible alternative to subclassing for extending functionality. Instead of creating many subclasses to cover every combination of features, a component is wrapped in one or more decorator objects that implement the same interface and forward calls to the wrapped component, adding their own behavior before or after delegation.

Usage

A classic use is in input/output stream libraries, such as Java's java.io package, where streams can be wrapped — for example, buffering, compression, and encryption layers can be combined around a basic file stream. Decorators are also widely used for adding scroll bars and borders in graphical user interface toolkits.

Composition in this style adheres to the principle of favoring object composition over class inheritance, but can result in many small, similar classes and can complicate identity and debugging.
