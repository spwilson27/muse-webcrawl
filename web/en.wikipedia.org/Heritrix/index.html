Heritrix

Heritrix is an open-source, extensible web crawler developed by the Internet Archive for performing large-scale, archival-quality web harvesting. Written in Java, it has been used since 2003 to crawl and preserve web content for the Wayback Machine and for partner institutions such as national libraries conducting legal-deposit web archiving.

Design

Heritrix is designed for archiving rather than indexing: it aims to fetch a faithful snapshot of web content, respecting the robots exclusion standard, rate-limiting requests to avoid overloading host servers ("politeness"), and storing results in the WARC file format. Operators configure crawl scope, ordering, and processing chains through a web-based console and modular "processor" components.

Use

Heritrix powers or has powered the broad crawls underlying the Wayback Machine as well as curated crawls run by institutions including the Library of Congress and numerous national libraries. See also web crawler and web archiving.
