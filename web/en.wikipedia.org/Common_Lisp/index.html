Common Lisp

Common Lisp (CL) is a dialect of the Lisp programming language, standardised by ANSI in 1994. It consolidated the divergent Lisp dialects of the 1980s into a single, large, multi-paradigm language supporting procedural, functional, and object-oriented programming. Common Lisp is known for its powerful macro system, interactive development style, and the Common Lisp Object System (CLOS).

History

Work began in 1981 under ARPA sponsorship to unite dialects such as Maclisp, Interlisp, and Lisp Machine Lisp. The first edition of Guy L. Steele Jr.'s Common Lisp the Language (1984) defined the language; the ANSI standard X3.226-1994 followed a decade later, the first programming language standard to be object-oriented.

Features

Common Lisp offers dynamic typing, automatic memory management, first-class functions, multiple dispatch through CLOS, a condition system for restartable exception handling, and a read-eval-print loop that encourages image-based, incremental development. Its homoiconic syntax — code written as nested lists — makes macros exceptionally expressive.

Implementations and use

Major implementations include SBCL, Clozure CL, ECL, and commercial systems such as Allegro CL and LispWorks. Though a niche language today, Common Lisp remains in use in areas from airline scheduling and symbolic computation to research, and it has profoundly influenced later languages.
