Direct2D

Direct2D is a 2D vector graphics application programming interface (API) designed by Microsoft and implemented in Windows 7, Windows Server 2008 R2, and later versions of Windows. It provides hardware-accelerated rendering of two-dimensional geometry, bitmaps, and text, and was developed as the successor to the older GDI and GDI+ APIs.

Vector shapes and text rendered through the Direct2D pipeline.

Features

Direct2D is built on top of Direct3D 10/11 and can interoperate with Direct3D surfaces. It supports anti-aliased geometry rendering, alpha blending, transformations, and layers, and renders text through DirectWrite. The API uses an immediate-mode drawing model with a device context, and can fall back to software rendering when suitable GPU hardware is unavailable.

Releases

Direct2D 1.1 (with Windows 8) added features including an effects framework (blur, colour management, and other image effects), geometry realisations, and printing support. Later updates shipped with Windows 10 added gradient meshes, sprite batches, and ink rendering support.

Use

Applications using Direct2D have included Microsoft Office, Internet Explorer 9 and later (for page rendering), and many Windows desktop programs requiring fast, high-quality 2D graphics.
