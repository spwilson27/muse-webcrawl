Complement (set theory)

Venn diagram of the absolute complement of A (in red)

In set theory, the complement of a set A is the set of elements not in A. Two notions are distinguished: the absolute complement, taken relative to a universal set U, written Ac, A′, or U ∖ A; and the relative complement of A with respect to another set B, written B ∖ A, consisting of elements of B that are not in A.

Absolute complement

If U is a universal set containing all sets under consideration, the absolute complement of A is Ac = { x ∈ U : x ∉ A }. Key properties include:

  • A ∪ Ac = U and A ∩ Ac = ∅
  • (Ac)c = A (involution)
  • De Morgan's laws: (A ∪ B)c = Ac ∩ Bc, and (A ∩ B)c = Ac ∪ Bc

Relative complement

The relative complement of A in B, also called the set difference, is B ∖ A = { x ∈ B : x ∉ A }. It can be expressed as B ∩ Ac. Unlike the absolute complement, the relative complement is defined without reference to a universal set.

In logic and probability

Under the correspondence between set operations and logic, complement corresponds to negation. In probability theory, the complement of an event has probability 1 − P(A), a fact used in the complement rule.
