Dynamic random-access memory

DRAM
TypeVolatile random-access memory
CellOne transistor + one capacitor
Invented1966 (Robert Dennard, IBM)
VariantsSDRAM, DDR, DDR2–DDR5, LPDDR, HBM

Dynamic random-access memory (DRAM) is a type of random-access semiconductor memory that stores each bit of data in a memory cell, usually consisting of a tiny capacitor and a transistor. The charge on the capacitor represents a bit, but it leaks away, so the cell must be periodically refreshed — hence "dynamic", in contrast to static RAM (SRAM), which holds data in flip-flops without refresh.

History

Robert Dennard of IBM invented the one-transistor DRAM cell in 1966 and patented it in 1968. The first commercially successful DRAM, the Intel 1103 (1970), offered 1 kbit of storage and by 1972 was the best-selling semiconductor memory chip in the world, displacing magnetic core memory.

Operation

To read a cell, its access transistor is turned on and the capacitor shares its charge with a bit line, where a sense amplifier detects and restores the value, rewriting it back to the cell. Because charge leaks within tens of milliseconds, every row must be refreshed periodically — typically each cell within a 64 ms window. Memory is organized in banks, rows, and columns addressed through row and column strobes (RAS and CAS).

Generations

Modern DRAM includes synchronous DRAM (SDRAM) and the double data rate families DDR through DDR5 used as main memory in computers, low-power LPDDR in mobile devices, and stacked High Bandwidth Memory (HBM) used with GPUs and accelerators. DRAM is slower but far denser and cheaper per bit than SRAM, which is used for processor caches.
