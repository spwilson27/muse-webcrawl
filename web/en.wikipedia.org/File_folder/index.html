File folder

A file folder (or simply folder) is a kind of folder that holds papers and money together for organisation and protection. File folders usually consist of a sheet of heavy paper stock or other thin, but stiff, material which is folded in half, and is used to keep paper documents. They are often used in conjunction with a filing cabinet for storage.

Design

The most familiar form is the manila folder, made from buff-coloured manila paper, with a tab along the top edge for labels. Tabs are manufactured in different positions (cuts) across the top so that several folders in a row display their labels without overlap. Related products include hanging folders, which suspend from rails in a drawer, classification folders with internal dividers and fasteners, and expanding file pockets.

Uses

Folders are used in offices, schools, and medical and legal practices to group related documents — patient charts, client files, project records — so that they can be retrieved as a unit. Colour-coding systems help identify categories at a glance.

In computing

The file folder inspired the metaphor of the computer "folder" or directory used in graphical user interfaces to organise files, an idea popularised by the Xerox Star and the Apple Macintosh. The familiar yellow folder icon descends directly from the paper original.
