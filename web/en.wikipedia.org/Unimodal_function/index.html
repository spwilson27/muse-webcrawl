Unimodal function

In mathematics, a unimodal function is a function that has a single peak (for a maximum) or a single valley (for a minimum) — that is, it increases monotonically up to a point and then decreases monotonically, or the reverse. More precisely, a function f(x) is unimodal on an interval if there exists a value m (the mode) such that f is monotonically increasing for x ≤ m and monotonically decreasing for x ≥ m. In that case the maximum value of f(x) is f(m).

Examples

The probability density functions of many common distributions are unimodal, including the normal distribution, the exponential distribution (decreasing from its boundary), and the Cauchy distribution. A quadratic function with a negative leading coefficient is unimodal. Functions that are concave on an interval are unimodal, but the converse does not hold: a unimodal function need not be concave, or even continuous.

Optimization

Unimodality is valuable in optimization because it guarantees that a local maximum is the global maximum and enables efficient derivative-free search methods. Ternary search and golden-section search find the extremum of a strictly unimodal function on an interval by repeatedly discarding the third of the interval that cannot contain the mode, converging linearly. These methods are standard tools in numerical computing when derivatives are unavailable or expensive.

Generalizations

In statistics, unimodality describes distributions; a distribution can be characterized by its mode, and tests such as Hartigan's dip test assess whether a sample plausibly comes from a unimodal distribution. For functions of several variables there is no single agreed generalization; notions such as quasiconcavity and star-unimodality play related roles. A function with exactly two peaks is called bimodal, and one with several, multimodal.
