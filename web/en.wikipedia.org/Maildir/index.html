Maildir

Maildir is a widely used format for storing email messages on a server or local disk, in which each message is kept as a separate file with a unique name. It was designed by Daniel J. Bernstein for the qmail mail transfer agent and avoids the file-locking problems of the older mbox format, making it safe for use over network file systems.

Structure

A Maildir directory contains three subdirectories: tmp, new, and cur. New messages are written completely into tmp, then linked into new; when a mail reader marks a message as seen or flagged, the file moves to cur with informational flags appended to its name (such as :2,RS for replied and seen).

Adoption

Maildir is supported by MTAs and servers including Postfix, Exim, Dovecot and Courier, and by many mail user agents. Variants and extensions add nested folder layouts (Maildir++) and filename conventions for expiry.
