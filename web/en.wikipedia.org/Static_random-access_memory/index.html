Static random-access memory

From Wikipedia, the free encyclopedia

An SRAM integrated circuit of the type used for processor cache memory.

Static random-access memory (static RAM or SRAM) is a type of random-access memory that uses latching circuitry (flip-flops) to store each bit. SRAM is volatile in the conventional sense that data is lost when power is removed, but it differs from dynamic RAM (DRAM) in that it does not need to be periodically refreshed.

Design

A typical SRAM cell consists of six transistors: four forming two cross-coupled inverters that store the bit, and two access transistors controlled by the word line connecting the cell to the bit lines during reads and writes. Because the stored state is actively held by the inverters, no refresh is required, and access is fast and deterministic.

Characteristics

SRAM is faster and less power-hungry at idle than DRAM and offers simpler interfacing, but each cell is much larger and more expensive per bit. Consequently SRAM is used where speed or low power matters more than capacity: CPU registers are simpler still, but SRAM forms the L1, L2 and L3 caches of modern processors, as well as buffers in routers, disk drives and embedded systems.

Types

Variants include asynchronous and synchronous SRAM, dual-ported SRAM, and non-volatile SRAM (nvSRAM), which pairs an SRAM cell with a non-volatile storage element so contents survive power loss.
