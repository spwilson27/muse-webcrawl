CVE

CVE may refer to several things. In computing security, it most commonly denotes Common Vulnerabilities and Exposures, the system that provides standard identifiers (CVE IDs) for publicly known cybersecurity vulnerabilities. Each ID, in the format CVE-YYYY-NNNN, uniquely names a flaw so that vendors, researchers and scanners can refer to the same issue unambiguously. The program is operated by the MITRE Corporation under contract to the US Department of Homeland Security, and identifiers are assigned by CVE Numbering Authorities (CNAs) around the world.

Other uses

  • Cape Verdean escudo (ISO currency code CVE), the currency of Cape Verde.
  • Escort carrier (US Navy hull classification symbol CVE), a class of small aircraft carriers used extensively in the Second World War.
  • Countering violent extremism, government and civil-society programmes.
  • Common Vulnerabilities and Exposures feeds databases such as the US National Vulnerability Database (NVD), which adds severity scores (CVSS) and analysis to CVE records.

The CVE list was launched in 1999. Famous widely referenced CVEs include CVE-2014-0160 (Heartbleed), CVE-2017-0144 (EternalBlue) and CVE-2021-44228 (Log4Shell).
