Interface metaphor

In user interface design, an interface metaphor is a set of user interface visuals, actions and procedures that exploit specific knowledge that users already have of other domains. The purpose of the interface metaphor is to give the user instantaneous knowledge about how to interact with the user interface. They are designed to be similar to physical counterparts but can also reveal properties of the system that are not normally visible.

Examples

The most famous interface metaphor is the desktop metaphor popularized by the Xerox Star and the Apple Macintosh, in which files are documents, directories are folders, and deletion is done with a trash can. Other examples include the shopping cart in e-commerce, the magnifying glass for search, tape-recorder buttons for media playback, and tabbed dialogs modeled on index cards. Skeuomorphism — visually imitating real materials — is one way of expressing such metaphors.

Criticism

Critics argue that metaphors can constrain design, mislead users when the analogy breaks down, and become obsolete as the physical referents disappear (such as the floppy-disk save icon). Designers therefore often blend metaphorical and idiomatic interfaces, where learned conventions matter more than real-world resemblance.
