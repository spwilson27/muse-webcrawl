Smurf attack

A Smurf attack is a distributed denial-of-service (DDoS) attack in which large numbers of Internet Control Message Protocol (ICMP) packets with the intended victim's spoofed source IP are broadcast to a computer network using an IP broadcast address. Most devices on the network will, by default, respond to this by sending a reply to the source IP address, overwhelming the victim with traffic.

Mechanism

The attacker sends ICMP echo requests to a network's broadcast address with the source address forged to that of the target. Every host on the network replies, amplifying the attack. Networks that relay such broadcasts are sometimes called "Smurf amplifiers". The name comes from the original exploit program, smurf.c, released in the 1990s.

Mitigations

Modern routers are generally configured not to forward packets directed to broadcast addresses, and operating systems no longer respond to ICMP requests sent to broadcast addresses by default, making classic Smurf attacks largely historical. Related amplification attacks using other protocols, such as DNS and NTP, remain a concern.
