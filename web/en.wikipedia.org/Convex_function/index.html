Convex function

In mathematics, a real-valued function is called convex if the line segment between any two distinct points on the graph of the function lies above or on the graph between the two points. Equivalently, the function's epigraph (the set of points on or above the graph) is a convex set.

Definition

A function f defined on a convex subset of a real vector space is convex if, for all points x and y in its domain and all t in [0, 1],

f(tx + (1−t)y) ≤ t f(x) + (1−t) f(y).

If the inequality is strict whenever x ≠ y and 0 < t < 1, the function is strictly convex. A function is concave if its negative is convex. Familiar convex functions include x², the exponential function, and norms; the logarithm is concave.

Properties

A convex function on an interval is continuous on the interior of its domain and differentiable almost everywhere. A twice-differentiable function is convex exactly when its second derivative is everywhere non-negative. Jensen's inequality generalises the defining inequality to weighted averages and expectations. Crucially for applications, every local minimum of a convex function on a convex set is a global minimum, and a strictly convex function has at most one minimiser.

Applications

Convex functions are the foundation of convex optimization, a tractable class of mathematical programming used throughout economics, engineering, statistics and machine learning, where convexity guarantees that efficient algorithms find globally optimal solutions.
