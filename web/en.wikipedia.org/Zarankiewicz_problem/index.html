Zarankiewicz problem

The Zarankiewicz problem, named after the Polish mathematician Kazimierz Zarankiewicz, asks for the largest possible number of edges in a bipartite graph with a given number of vertices on each side that contains no complete bipartite subgraph Ks,t — that is, no set of s vertices on one side all connected to the same set of t vertices on the other side.

Definition

The Zarankiewicz number z(m, n; s, t) is the maximum number of edges in a bipartite graph with m vertices in one part and n vertices in the other that contains no copy of Ks,t. Zarankiewicz posed the problem in 1951, originally in connection with the number of ones in a 0–1 matrix containing no all-ones submatrix of a given size.

Bounds

The best-known general upper bound is the Kővári–Sós–Turán theorem, which gives z(n, n; t, t) = O(n2 − 1/t). Constructions based on finite geometry, such as norm graphs and polarity graphs of finite projective planes, give matching or near-matching lower bounds for small values of s and t. Exact values of the Zarankiewicz numbers are known only for small parameters, and computing them remains an active topic in extremal graph theory.

Related problems

The problem is equivalent to an extremal problem for 0–1 matrices. A related question is the bipartite Turán problem, and the special case of K2,2-free graphs connects to incidence geometry and the study of unit distances.
