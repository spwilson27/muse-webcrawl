HTTP Live Streaming

HTTP Live Streaming (HLS)
Developer: Apple Inc.
Released: 2009
Standard: RFC 8216 (2017; 2nd ed. 2024)

HTTP Live Streaming (also known as HLS) is an HTTP-based adaptive bitrate streaming communications protocol developed by Apple Inc. and released in 2009. It works by breaking a media stream into a sequence of small file downloads, delivered over ordinary HTTP from standard web servers and content delivery networks.

Operation

An encoder produces the same content at multiple bit rates, each split into short segments (historically MPEG-TS files, later also fragmented MP4). An index file in the M3U8 playlist format lists the segments; the client player measures available bandwidth and switches between bit-rate variants as conditions change. Because it traverses standard HTTP infrastructure, HLS passes easily through firewalls and caches.

Adoption

HLS shipped with the iPhone and iOS and became the default streaming format on Apple platforms; it is also widely supported on Android, smart TVs and the web via Media Source Extensions. It was documented as an Internet Standard in RFC 8216 and is a principal competitor to MPEG-DASH.
