Bopomofo (Unicode block)

Range: U+3100–U+312F
Script: Bopomofo
Characters: 48 code points
Introduced: Unicode 1.0

Bopomofo is a Unicode block containing phonetic characters for Chinese in the Bopomofo (Zhuyin Fuhao) script. Bopomofo is a transliteration system for Standard Chinese and other Sinitic languages, widely used in Taiwan for teaching pronunciation and as an input method.

Contents

The block spans U+3100 to U+312F and contains the letters of the Bopomofo alphabet, including the initials, medials and finals, along with tone-related and dialectal characters. An additional set of extended characters for Min Nan and Hakka appears in the separate Bopomofo Extended block.

History

The characters were encoded in Unicode version 1.0 in 1991. Bopomofo itself was created in the early 20th century, taking its name from the first four letters of the system: b, p, m and f.
