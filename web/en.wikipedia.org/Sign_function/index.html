Sign function

The sign function or signum function (from Latin signum, "sign") is a mathematical function that extracts the sign of a real number. It is defined as:

  • sgn(x) = −1 if x < 0
  • sgn(x) = 0 if x = 0
  • sgn(x) = +1 if x > 0

Properties

Any real number can be expressed as the product of its absolute value and its sign: x = |x| · sgn(x). The sign function is an odd function, is discontinuous at zero, and its derivative is zero everywhere except at the origin, where it is not differentiable in the ordinary sense; in distribution theory its derivative is twice the Dirac delta function. It is related to the Heaviside step function by sgn(x) = 2H(x) − 1 (for x ≠ 0).

Complex sign function

For complex numbers, the signum is often generalised as csgn(z) or as z/|z| for z ≠ 0, which returns the point on the unit circle with the same argument as z. The phase or argument of a complex number generalises the notion of sign.

Applications

The sign function appears in signal processing (as an ideal detector of polarity), in the definition of the absolute value, in sign-based algorithms such as the signum or sign gradient methods in optimisation, and in physics when expressing direction relative to a chosen axis. Smooth approximations of the sign function include the hyperbolic tangent and the sigmoid functions.
