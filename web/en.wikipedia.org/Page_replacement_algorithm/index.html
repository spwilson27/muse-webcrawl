Page replacement algorithm

Page replacement algorithm
DomainOperating systems, virtual memory
PurposeChoose which memory page to evict
Common policiesLRU, FIFO, Clock, OPT

In a computer operating system that uses paging for virtual memory management, page replacement algorithms decide which memory pages to page out, sometimes called swap out or write to disk, when a page of memory needs to be allocated. Replacement is triggered when a page fault occurs and no free frames are available.

Algorithms

Optimal (OPT or MIN), described by László Bélády, evicts the page that will not be used for the longest time in the future. It is unimplementable in practice because it requires future knowledge, but serves as a benchmark. Certain policies suffer from Bélády's anomaly, where increasing the number of frames increases the number of page faults.

FIFO (first in, first out) simply evicts the oldest loaded page using a queue; it is cheap but can discard heavily used pages. Least recently used (LRU) evicts the page not accessed for the longest time, exploiting locality of reference; exact LRU is costly to implement, so operating systems approximate it. The clock algorithm arranges frames in a circle with a reference bit per page, giving pages a "second chance" and approximating LRU with low overhead; variants such as Clock-Pro and the multi-queue schemes used in Linux extend this idea. Random replacement, which evicts a page chosen at random, performs surprisingly well in some workloads and requires no bookkeeping.

Considerations

Practical policies must also decide whether replacement is local (within the faulting process) or global (across all processes), handle dirty pages whose contents must be written back, and pin kernel or locked pages so they are never evicted.
