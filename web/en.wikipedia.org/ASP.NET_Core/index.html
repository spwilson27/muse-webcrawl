ASP.NET Core is a free and open-source web framework, and the successor to ASP.NET, developed by Microsoft. It is a modular, cross-platform redesign that runs on Windows, Linux, and macOS as part of the modern .NET platform, and it consistently ranks among the fastest mainstream web frameworks in independent benchmarks such as TechEmpower.

History

The framework began as "ASP.NET 5" during the re-platforming of .NET that produced .NET Core. To avoid implying it was merely an update of the Windows-only ASP.NET 4.x, Microsoft renamed it ASP.NET Core 1.0, released in June 2016 with the new Kestrel web server and a rebuilt middleware pipeline. Versions 2.0 (2017) and 3.0 (2019) followed the .NET Core cadence; from .NET 5 (2020) onward, ASP.NET Core versioning matches the unified .NET releases (6, 7, 8, and later), with long-term support for even-numbered releases.

Features

ASP.NET Core supports several programming models in one framework: MVC (Model–View–Controller) for conventional web applications, Razor Pages for page-focused development, Web APIs with automatic model binding and content negotiation, Blazor for interactive web UI written in C# (server-hosted or WebAssembly), SignalR for real-time communication, and gRPC services. It features a composable middleware pipeline, built-in dependency injection, configuration and options systems, structured logging, health checks, and hosting in Kestrel (optionally behind IIS, nginx, or Apache reverse proxies). "Minimal APIs", introduced in .NET 6, allow concise route-based endpoints without controllers.

Reception and use

ASP.NET Core is used for large services including parts of Bing and Microsoft's own web properties, and by major external sites and enterprises. It is a core component of the .NET ecosystem taught in Microsoft's documentation and is regularly among the top frameworks in the Stack Overflow Developer Survey's most-used and most-loved categories.
