Widget (GUI)

In computer programming, a widget (or graphical control element) is an element of a graphical user interface (GUI) that displays information and provides a way for a user to interact with the operating system or an application. Widgets include icons, pull-down menus, buttons, selection boxes, progress indicators, scrollbars, windows, window edges, toggle buttons, form fields, and many other interactive components.

History

The concept arose from the Xerox Alto and the Smalltalk programming environment at Xerox PARC in the 1970s, and widget toolkits were developed for the X Window System on Unix workstations; the Athena widget set (Xaw) was one of the earliest widely distributed toolkits. The term "widget" — a generic word for a small device or gadget — was adopted because programmers needed a neutral name for these reusable interface elements.

Widget toolkits

Widgets are usually packaged in widget toolkits or libraries that programmers use to build interfaces. Examples include GTK, Qt, the Windows API controls, Cocoa on macOS, and the view system of Android. Toolkit widgets share a consistent look and feel and handle low-level events such as mouse clicks, drawing, and resizing, freeing application developers from reimplementing standard behaviour.

Web widgets

On the web, "widget" can also denote a small third-party component embedded in a page, such as a weather display or social-media feed, and in mobile systems it refers to at-a-glance home-screen components such as clocks and calendars.
