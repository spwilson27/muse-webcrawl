Parity bit

A parity bit, or check bit, is a bit added to a string of binary code to ensure that the total number of 1-bits in the string has a chosen parity — either even ("even parity") or odd ("odd parity"). It is the simplest form of error-detecting code: it can detect any odd number of bit errors in the output, most simply a single flipped bit, but it cannot correct errors and cannot detect an even number of errors.

Even and odd parity

Under even parity, the parity bit is set to 1 if the number of 1-bits in the data is odd, so that the total count, including the parity bit, is even. Under odd parity the reverse applies: the bit is chosen so that the total count of 1-bits is odd. For example, the 7-bit data word 0110100 contains three 1-bits; its even-parity bit is 1 and its odd-parity bit is 0.

Use

Parity bits were widely used in asynchronous serial communication, where each transmitted character carried a parity bit, and in early computer memory: many systems stored 9 bits per byte, the ninth being parity, so that a single-bit memory fault would be caught. RAID storage arrays traditionally used parity information distributed across disks so a failed drive could be reconstructed (though RAID parity is computed with XOR across many bits rather than a single check bit). Parity checking survives in some modern systems, though it has largely been superseded by more powerful error-correcting codes such as ECC memory and checksums with retransmission protocols.

Limitations

Because parity records only whether the number of errors is odd or even, two simultaneous bit flips pass undetected, and the receiver cannot tell which bit is wrong. For this reason parity is classed as an error-detecting, not error-correcting, code, and robust systems layer additional checks — such as the cyclic redundancy checks used in networking and storage — on top of or in place of simple parity.
