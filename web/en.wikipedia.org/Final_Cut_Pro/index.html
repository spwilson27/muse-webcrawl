Final Cut Pro

DeveloperApple Inc.
Initial release1999
PlatformmacOS, iPadOS

Final Cut Pro is a professional non-linear video-editing application developed by Apple for macOS and iPadOS. First released in 1999, it became widely used by independent filmmakers and broadcast editors, and was the tool used to edit several feature films and television programmes.

History

Final Cut Pro originated at Macromedia before Apple acquired the project in 1998 and released it the following year. In 2011 Apple replaced it with Final Cut Pro X (later simply Final Cut Pro), a ground-up rewrite introducing the Magnetic Timeline; the redesign was initially controversial among professionals but gained features over successive updates.

Features

The application supports multicam editing, HDR and ProRes workflows, 360-degree video, machine-learning-based tools such as Smart Conform and object tracking, and deep integration with Apple's Motion and Compressor applications.
