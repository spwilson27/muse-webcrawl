Multirate signal processing


Field: Digital signal processing
Key operations: Decimation, interpolation, filter banks

Multirate signal processing is a subfield of digital signal processing in which systems operate at more than one sampling rate. Changing a signal's sampling rate — decreasing it (decimation or downsampling) or increasing it (interpolation or upsampling) — allows efficient processing, storage, and transmission when different parts of a system require different rates.

Basic operations

Downsampling by a factor M keeps every Mth sample and must be preceded by a low-pass anti-aliasing filter with cutoff below the new Nyquist frequency. Upsampling by a factor L inserts L − 1 zeros between samples, followed by a low-pass interpolation filter that removes spectral images. Combining both gives rational rate conversion. Polyphase decompositions rearrange these filters so computation happens at the lower rate, greatly reducing the number of operations.

Structures and theory

Filter banks split a signal into subbands that can be processed at reduced rates; the noble identities describe how filtering and sampling operations can be interchanged. Multirate theory underlies the discrete wavelet transform, subband coding, and oversampling converters (sigma-delta modulators).

Applications

Applications include sample-rate conversion in audio (for example between 44.1 kHz and 48 kHz), digital radio channelizers, image scaling and pyramids, speech and audio compression, and efficient narrowband filtering.
