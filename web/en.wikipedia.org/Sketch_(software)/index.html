Sketch (software)

Sketch is a vector graphics editor developed by the Dutch company Sketch B.V. for macOS. Released in 2010, it became a widely used tool for user-interface and user-experience design; its document format is used by many other design tools. Sketch won an Apple Design Award in 2012.

Sketch

Developer: Sketch B.V.
Initial release: 7 September 2010
Platform: macOS
Type: Vector graphics editor

Features

Sketch focuses on screen design: artboards for multiple screens, reusable symbols, shared styles, vector editing and prototyping. A plugin ecosystem long extended its functions, and companion web tools added collaboration, comments and developer handoff. Unlike browser-based rivals, the main editing app remained Mac-only, with viewing and collaboration available through the web.

History

Created by Pieter Omvlee and Emanuel Sá, Sketch grew rapidly among UI designers in the 2010s, displacing Adobe Photoshop for interface work and influencing competitors such as Figma and Adobe XD.
