DevOps

DevOps
OriginTerm coined 2009 (DevOpsDays, Ghent)
CombinesSoftware development (Dev) and IT operations (Ops)
Key practicesCI/CD, infrastructure as code, monitoring, automation
Key textsThe Phoenix Project (2013); The DevOps Handbook (2016)

DevOps is a set of practices, tools, and a cultural philosophy that automate and integrate the processes between software development and IT operations teams. It emphasizes team empowerment, cross-team communication and collaboration, and technology automation, aiming to shorten the systems development life cycle and provide continuous delivery with high software quality.

History

The term was popularized from 2009 through the "DevOpsDays" conferences, the first held in Ghent, Belgium, and Patrick Debois's advocacy. Influences included agile software development, lean manufacturing, John Allspaw and Paul Hammond's 2009 talk "10+ Deploys Per Day" at Flickr, and the site reliability engineering discipline pioneered at Google. Gene Kim's novel The Phoenix Project (2013) and The DevOps Handbook (2016) spread the ideas widely.

Practices

Core practices include continuous integration (frequently merging and testing code), continuous delivery and deployment (automated release pipelines), infrastructure as code (managing servers and environments with versioned configuration, e.g., containers and tools such as Terraform and Kubernetes), automated testing, and comprehensive monitoring and observability with feedback loops to developers. The CALMS framework summarizes the values as Culture, Automation, Lean, Measurement, and Sharing.

Impact

The annual DORA "State of DevOps" research classifies teams by deployment frequency, lead time for changes, change failure rate, and time to restore service, and correlates elite performance on these metrics with organizational success. DevOps also reshaped security practice ("DevSecOps"), embedding security checks into pipelines, and blurred the line between development and operations roles, spawning platform engineering as a related discipline.
