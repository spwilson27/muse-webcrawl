Entropy encoding

Entropy encoding (or entropy coding) is a lossless data compression scheme that is independent of the specific characteristics of the medium, in which symbols are assigned codewords whose lengths depend on the symbols' probabilities: frequent symbols get short codes and rare symbols get long codes. The name comes from information theory, where entropy sets the lower bound on the average number of bits needed to represent a symbol from a source.

Shannon's source coding theorem

Claude Shannon's source coding theorem (1948) states that the average code length of an optimal lossless code for a source is bounded below by the source's entropy. Entropy coders aim to approach this limit. Two classic families are prefix codes, exemplified by Huffman coding, and arithmetic coding, which can encode a whole message as a single fractional value and often achieves compression closer to the entropy limit, at higher computational cost.

Common schemes

  • Huffman coding builds an optimal prefix code from symbol frequencies; used in DEFLATE (gzip, PNG), JPEG (with a fixed or optimized table), and many other formats.
  • Arithmetic coding represents the message as an interval of real numbers; used in JPEG 2000, H.264/AVC (as CABAC), and other standards.
  • Asymmetric numeral systems (ANS), a more recent family, combine near-entropy compression with speed comparable to Huffman coding and are used in formats such as Zstandard and JPEG XL.
  • Range coding and context-adaptive variants adapt probabilities to local context for better compression.

Entropy encoding is usually the final stage of a compressor, applied after transforms and modelling steps (such as prediction or the Burrows–Wheeler transform) have converted the data into a symbol stream with skewed probabilities.
