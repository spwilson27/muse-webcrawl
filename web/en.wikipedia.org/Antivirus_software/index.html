Antivirus software

Antivirus software (abbreviated to AV software), also known as anti-malware, is a computer program used to prevent, detect, and remove malware. Antivirus software was originally developed to detect and remove computer viruses, hence the name. Modern products also protect against worms, trojan horses, ransomware, spyware, adware, and other malicious software.

Methods

Traditional detection uses signature-based scanning: files are compared against a database of known malware signatures, which vendors update frequently. Heuristic analysis examines code and behavior for suspicious characteristics, and behavioral monitoring watches running programs for malicious actions. Cloud-based lookups and machine-learning classifiers are increasingly used to identify previously unseen threats.

History

The first antivirus utilities appeared in the late 1980s, in response to viruses spreading on floppy disks for personal computers. The industry grew rapidly in the 1990s with companies such as McAfee, Symantec (Norton), and Trend Micro; security suites later bundled antivirus with firewalls and other tools.

Limitations

Signature-based detection cannot catch brand-new ("zero-day") malware, and false positives and performance overhead are recurring concerns. Operating systems now ship with built-in protection, such as Microsoft Defender.
