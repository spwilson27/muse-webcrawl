JPEG 2000 (JP2) is an image compression standard and coding system created by the Joint Photographic Experts Group committee in 2000 as a successor to the original JPEG standard. Unlike JPEG, which is based on the discrete cosine transform (DCT), JPEG 2000 uses wavelet transforms, offering superior compression performance and features such as scalability and region-of-interest coding.

Technical features

JPEG 2000 employs a two-dimensional discrete wavelet transform followed by quantization and arithmetic coding (EBCOT — Embedded Block Coding with Optimized Truncation). A single code stream can be decoded at multiple resolutions and quality levels, making the format attractive for progressive transmission and for applications that need both thumbnails and full-resolution images from one file.

Applications

The format found adoption in digital cinema (in the Digital Cinema Initiatives specification, where each frame is JPEG 2000 encoded), medical imaging (DICOM), geospatial imagery, and archival digitization by libraries and cultural heritage institutions. Despite its technical advantages, JPEG 2000 saw limited uptake in consumer web browsers, where the original JPEG remained dominant.

File format

The core coding system is defined in ISO/IEC 15444-1. The JP2 file format wraps the code stream in a box-based container that can hold metadata, color profiles, and multiple images. Extensions include JPX, the Motion JPEG 2000 (.mj2) format, and the compound image format JPM.
