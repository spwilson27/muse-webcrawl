GNU Binutils

The GNU Binary Utilities, or binutils, is a collection of programming tools maintained by the GNU Project for handling binary files, object code, and libraries. The package is a core part of the GNU toolchain alongside the GNU Compiler Collection and the GNU Debugger, and supports a very wide range of processor architectures through the Binary File Descriptor (BFD) library.

Components

The principal tools include as, the GNU Assembler; ld, the GNU Linker; ar, for creating and modifying static libraries (archives); objcopy and objdump, for copying, translating, and displaying information about object files; nm, which lists symbols from object files; readelf, which displays ELF file structure; size and strings, which report section sizes and printable character sequences; strip, which removes symbols to reduce file size; addr2line, which converts addresses to file names and line numbers; and gprof, a profiling tool. The package also historically included the fast gold linker.

Architecture

Most binutils programs are built on two shared libraries: BFD (the Binary File Descriptor library), which abstracts object-file formats such as ELF, PE/COFF, and a.out, and opcodes, which abstracts instruction encoding and decoding for disassembly. This design lets one set of tools work across dozens of targets and enables cross-development, for example assembling code on an x86 host for an ARM embedded target. Binutils is written mainly in C, is released under the GNU General Public License, and new releases appear roughly twice a year.
