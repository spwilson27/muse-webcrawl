RSA Security

RSA Security LLC
Industry: Computer and network security
Founded: 1982 (as Security Dynamics; RSA Data Security 1986)
Headquarters: Bedford, Massachusetts, U.S.

RSA Security LLC is an American computer and network security company, a subsidiary of Symphony Technology Group. It is named after its founders Ron Rivest, Adi Shamir, and Leonard Adleman, inventors of the RSA public-key cryptosystem. RSA is best known for the SecurID two-factor authentication tokens used by organizations worldwide.

History

RSA Data Security was founded in 1986 to commercialize the RSA algorithm; it merged with Security Dynamics in 1996. The company hosted the influential RSA Conference, first held in 1991. EMC Corporation acquired RSA in 2006 for about $2.1 billion, and RSA became part of Dell Technologies in 2016 before being sold to a consortium led by Symphony Technology Group in 2020.

Controversies

In 2011, attackers breached RSA and stole information related to SecurID, leading to attacks on defense contractors. In 2013, reports based on documents leaked by Edward Snowden alleged that RSA had accepted $10 million from the NSA to make the Dual EC DRBG random number generator — later shown to be backdoored — the default in its BSAFE library, which RSA denied as deliberate wrongdoing.
