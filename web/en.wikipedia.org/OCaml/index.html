OCaml

OCaml is a general-purpose, multi-paradigm programming language which extends the Caml dialect of ML with object-oriented features. OCaml was created in 1996 by Xavier Leroy, Jérôme Vouillon, Damien Doligez, Didier Rémy, Ascánder Suárez, and others at Inria in France.

ParadigmMulti-paradigm: functional, imperative, modular, object-oriented
Designed byXavier Leroy and others, Inria
First appeared1996
Typing disciplineInferred, static, strong

Features

OCaml features a static type system with type inference, parametric polymorphism, tail recursion, pattern matching, first-class lexical closures, functors (parametric modules), exception handling, and incremental generational garbage collection. It compiles both to bytecode and to efficient native code.

Applications

OCaml is used in static analysis tools (such as the Astrée analyzer and Facebook's Flow and Hack tooling), theorem provers (Coq), financial systems (notably at Jane Street), and compilers. Facebook's ReasonML and ReScript languages build on its ecosystem.
