Linear system

A linear system is a mathematical model of a system based on a linear operator. Such systems obey the superposition principle: the response to a sum of inputs equals the sum of the responses to each input, and scaling an input scales the response by the same factor. Linear systems are fundamental in signal processing, control theory, physics, and engineering because they admit powerful analytical tools — including convolution, Fourier and Laplace transforms, and transfer functions — that do not generally apply to nonlinear systems.

Linear time-invariant systems

A system is time-invariant if a time shift of the input produces the same shift in the output. A linear time-invariant (LTI) system is completely characterized by its impulse response h(t): the output for any input x(t) is the convolution y(t) = (x * h)(t). In the frequency domain the system is described by its transfer function H(s) or frequency response H(jω), the ratio of output to input transforms.

Properties

  • Superposition: additivity and homogeneity of the input–output mapping.
  • Stability: a system is BIBO stable if every bounded input gives a bounded output; for LTI systems this requires the impulse response to be absolutely integrable (continuous time) or summable (discrete time).
  • Causality: the output depends only on present and past inputs.
  • State-space form: ẋ = Ax + Bu, y = Cx + Du, used throughout modern control theory.

Applications

Electrical circuits of resistors, capacitors, and inductors; mechanical spring–mass–damper systems; audio filters and equalizers; and the linearized dynamics of aircraft and chemical processes are all modelled as linear systems. Even intrinsically nonlinear systems are commonly studied through linearization about an operating point.
