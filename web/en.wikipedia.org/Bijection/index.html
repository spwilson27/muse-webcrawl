Bijection

In mathematics, a bijection (or bijective function, one-to-one correspondence, or invertible function) is a function between two sets where each element of one set is paired with exactly one element of the other set, and vice versa. A function f: X → Y is bijective if and only if it is both injective (one-to-one) and surjective (onto).

Definition

Formally, f is bijective when for every y in Y there exists exactly one x in X such that f(x) = y. Injectivity requires that distinct inputs give distinct outputs; surjectivity requires that every element of the codomain is hit by at least one input. A bijective function has an inverse function f−1: Y → X that undoes it, and a function has an inverse if and only if it is bijective.

Examples

The identity function on any set is a bijection. The function f(x) = 2x + 3 from the real numbers to the real numbers is bijective, with inverse f−1(y) = (y − 3)/2. By contrast, f(x) = x² on the reals is neither injective nor surjective, though restricting its domain and codomain to the non-negative reals makes it bijective. The exponential function is a bijection from the reals onto the positive reals, inverted by the natural logarithm.

Cardinality

Bijections are fundamental to comparing the sizes of sets. Two sets are said to have the same cardinality when there exists a bijection between them. This definition, due to Georg Cantor, extends the notion of "same number of elements" to infinite sets: the natural numbers, integers, and rational numbers share the cardinality ℵ₀ (aleph-null), while the real numbers have a strictly larger cardinality, as shown by Cantor's diagonal argument.

Properties

The composition of two bijections is a bijection, and under composition the bijections from a set to itself form a group — the symmetric group — whose elements are the permutations of the set. In category theory, bijections are precisely the isomorphisms in the category of sets.
