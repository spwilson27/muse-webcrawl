Statistical classification
Field: Statistics, machine learning
Task: Assign observations to categories
Algorithms: Logistic regression, SVM, decision trees, naive Bayes, neural networks

Statistical classification is the problem of identifying which of a set of categories (sub-populations) a new observation belongs to, on the basis of a training set of data containing observations whose category membership is known. It is a central task of supervised learning in statistics and machine learning.

Problem formulation

Each observation is represented by a vector of measurable features. A classifier is a function that maps feature vectors to class labels; its performance is commonly measured by accuracy, precision, recall, or the area under the ROC curve, and estimated by cross-validation on held-out data.

Algorithms

Classical methods include linear discriminant analysis (introduced by Ronald Fisher), logistic regression, naive Bayes classifiers based on Bayes' theorem, k-nearest neighbours, decision trees and random forests, support vector machines, and artificial neural networks, including deep learning models.

Applications

Classification is used in spam filtering, medical diagnosis, image and speech recognition, document categorisation, credit scoring and biometrics.
