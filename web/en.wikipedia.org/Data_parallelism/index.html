Data parallelism

Data parallelism is a form of parallelization across multiple processors in parallel computing environments. It focuses on distributing data across different nodes, which operate on the data in parallel; the same operation is applied simultaneously to many data elements, in contrast to task parallelism, where different operations run concurrently.

Applications

Data parallelism underlies SIMD (single instruction, multiple data) architectures, vector processors and modern GPUs, and is natural for problems such as image processing, matrix operations, simulations and machine-learning training, where large datasets can be partitioned. Programming models such as CUDA, OpenCL, MPI and MapReduce expose data-parallel execution, while languages and libraries (e.g. NumPy, TensorFlow) hide it behind array operations.
