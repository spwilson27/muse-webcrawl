Flip-flop (electronics)

In electronics, a flip-flop or latch is a circuit that has two stable states and can be used to store state information — a bistable multivibrator. Flip-flops are the fundamental building blocks of sequential logic, used in computers and many types of control and memory circuits to store one bit of data.

Flip-flop
Type: Sequential logic circuit
Function: Stores one bit
Main types: SR, D, JK, T
Applications: Registers, counters, memory

History

The first electronic flip-flop was invented in 1918 by William Eccles and F. W. Jordan, using vacuum tubes, and was a key element of early electronic counters. Transistor versions became ubiquitous with integrated circuits such as the 7400 series.

Types

  • SR latch – built from two cross-coupled NOR or NAND gates, with Set and Reset inputs.
  • D flip-flop – captures the value of its data input at a specific clock edge and holds it at the output; the most common type in registers and pipelines.
  • JK flip-flop – refines the SR design so that both inputs active toggles the output.
  • T flip-flop – toggles its output on each clock edge when its T input is high, used for frequency division and counters.

Timing

Flip-flops are characterized by setup time and hold time around the clock edge, clock-to-output delay, and metastability behavior when inputs change too close to the clock edge. Cascading flip-flops forms shift registers, counters, and the state elements of finite-state machines.

Applications

Flip-flops store the bits in processor registers, static RAM cells are built from latch-like circuits, and flip-flops synchronize signals crossing clock domains and eliminate switch bounce.
