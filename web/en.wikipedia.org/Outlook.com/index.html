Outlook.com is a personal information manager and webmail service offered by Microsoft, part of the Microsoft 365 product family. It succeeds Hotmail, which Microsoft had operated since acquiring it in 1997, and combines email with calendar, contacts (People), and task management (To Do) in a single web interface.

History

Outlook.com was launched in preview on 31 July 2012, introducing a clean interface based on Microsoft's Metro design language, integration with Skype and social networks, and unlimited storage. By early 2013 Microsoft reported more than 60 million active users, and in spring 2013 all Hotmail accounts were migrated to the new service, ending the Hotmail brand after 16 years.

Features

The service offers focused inbox sorting, sweep rules for automatic message management, categories and flags, integration with OneDrive for large attachments, and Office web apps for viewing and editing documents. Paid Microsoft 365 subscriptions add increased mailbox storage, an ad-free interface, custom domain support, and advanced security features such as encrypted email.

Relationship to Outlook applications

Outlook.com shares its name with Microsoft Outlook, the desktop and mobile email client, and with Outlook on the web, the web interface of business Microsoft 365 accounts. Consumer Outlook.com accounts use the same modern interface design.
