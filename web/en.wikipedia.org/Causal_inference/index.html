Causal inference

Causal inference is the process of drawing conclusions about causal relationships from data. It is a central concern of statistics, epidemiology, economics and the social sciences, and is distinguished from mere association by the aim of predicting the effect of an intervention — what would happen if a variable were set to a particular value.

Frameworks

Two dominant frameworks formalise causal questions. The potential outcomes framework (Neyman–Rubin) defines a causal effect as the contrast between outcomes under treatment and control for the same unit, of which only one can be observed — the "fundamental problem of causal inference." Judea Pearl's structural causal model framework represents systems with directed acyclic graphs (causal diagrams) and a calculus (do-calculus) for deciding when causal effects can be estimated from observational data, e.g. by adjusting for confounders via the back-door criterion.

Methods

Randomised controlled trials remain the gold standard because randomisation breaks confounding by design. For observational data, methods include matching and propensity scores, instrumental variables, regression discontinuity, difference in differences, and sensitivity analyses. Identifying assumptions — exchangeability, positivity, consistency — must be justified in each application; violations such as unmeasured confounding, collider bias and reverse causation are common pitfalls.
