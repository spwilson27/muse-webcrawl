Merkle tree

A Merkle tree (also called a hash tree) is a tree data structure in which every leaf node is labelled with the hash of a data block and every internal node is labelled with the hash of its children's labels. The concept was patented by Ralph Merkle in 1979.

Properties

Merkle trees allow efficient and secure verification of the contents of large data structures. To prove that a given block belongs to a tree, only a logarithmic number of hashes (the sibling path to the root) is required. The topmost hash, the Merkle root, summarizes the entire data set: any change to any block changes the root.

Applications

Merkle trees are used in distributed systems and peer-to-peer networks (such as IPFS), version control systems like Git, certificate transparency logs, and blockchains. In Bitcoin, transactions in each block are committed in a Merkle tree whose root is stored in the block header, enabling simplified payment verification (SPV).
