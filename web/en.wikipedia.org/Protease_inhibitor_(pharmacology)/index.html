Protease inhibitor (pharmacology)

Protease inhibitors are a class of antiviral drugs that block viral proteases — enzymes viruses need to cleave precursor polyproteins into functional proteins, without which new virions are non-infectious.

Uses

HIV protease inhibitors, beginning with saquinavir (1995) followed by ritonavir and indinavir, transformed AIDS treatment as part of highly active antiretroviral therapy (HAART). Ritonavir and cobicistat are used as pharmacokinetic boosters. Hepatitis C NS3/4A inhibitors (e.g., grazoprevir, glecaprevir) form part of direct-acting antiviral regimens. Nirmatrelvir, the active component of Paxlovid, targets the SARS-CoV-2 main protease (3CLpro). Side effects of the HIV class include metabolic changes and lipodystrophy.
