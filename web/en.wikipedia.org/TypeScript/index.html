TypeScript is a free and open-source high-level programming language developed by Microsoft that adds static typing with optional type annotations to JavaScript. It is a strict syntactic superset of JavaScript: any valid JavaScript program is also a TypeScript program. TypeScript code is transpiled to ordinary JavaScript that runs in browsers, on servers via Node.js, and elsewhere.

Design

Led by Anders Hejlsberg, co-creator of C#, TypeScript aims to make large-scale JavaScript development manageable through compile-time type checking, interfaces, generics, enums and advanced tooling such as autocompletion and refactoring. Its structural type system matches JavaScript's duck-typing style while catching errors before runtime. Declaration files (.d.ts) let developers add types to existing libraries.

Adoption

TypeScript has been embraced by major projects and frameworks — Angular is built in it, and React, Vue and countless libraries ship first-class types. It has consistently ranked among the most used and most loved languages in developer surveys, and tools such as Visual Studio Code provide deep built-in support.

Versions

Notable milestones include generics (0.9), strict null checks (2.0), project references (3.0), template literal types (4.1) and the 5.x series, which modernised module handling and decorators.
