Internet Protocol version 4 (IPv4) is the fourth version of the Internet Protocol (IP). It is one of the core protocols of standards-based internetworking methods in the Internet and other packet-switched networks. IPv4 was the first version deployed for production on SATNET in 1982 and on the ARPANET in January 1983. It is still used to route most Internet traffic today, even with the ongoing deployment of its successor, Internet Protocol version 6 (IPv6).

Addressing

IPv4 uses a 32-bit address space which provides 4,294,967,296 (232) unique addresses, but large blocks are reserved for special uses or private networks. Addresses are conventionally written in dot-decimal notation as four decimal numbers separated by periods, such as 192.168.0.1. Originally addresses were divided into classes (A, B, C, D, E); classless inter-domain routing (CIDR), introduced in 1993, allows allocation in variable-length blocks using a suffix notation such as 192.168.1.0/24.

Address exhaustion

The rapid growth of the Internet led to IPv4 address exhaustion: IANA allocated its last free blocks to the regional Internet registries in February 2011, and the registries have since run out of unallocated addresses. Conservation techniques such as network address translation (NAT) have extended IPv4's life by allowing many hosts to share one public address, while the long-term solution is transition to IPv6.

Packet structure

An IPv4 packet consists of a header (20 bytes minimum) and a data section. Header fields include the version, Internet Header Length, Type of Service, total length, identification, fragmentation flags and offset, Time To Live (TTL), protocol, a header checksum, and the source and destination addresses.
