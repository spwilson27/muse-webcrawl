Call Stack

In computer science, a call stack is a stack data structure that stores information about the active subroutines of a computer program. This type of stack is also known as an execution stack, program stack, control stack, run-time stack, or machine stack, and is often shortened to 'the stack'.

Structure

Each entry is a stack frame (activation record) holding a return address, saved registers, parameters, and local variables for one invocation. A stack pointer tracks the top; on many architectures a frame pointer anchors the current frame.

Operation

Calling a function pushes a new frame; returning pops it and resumes the caller. Recursion pushes multiple frames for the same function. If pushes exceed the allocated stack, a stack overflow occurs — the classic cause of crashes in unbounded recursion.

Uses

Debuggers display the call stack (stack trace) to show the chain of calls leading to an error. Security exploits such as buffer overflows target return addresses stored on the stack, motivating protections like stack canaries and non-executable stacks.
