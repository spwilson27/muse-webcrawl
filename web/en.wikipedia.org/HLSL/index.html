High-Level Shader Language

The High-Level Shader Language or High-Level Shading Language (HLSL) is a proprietary shading language developed by Microsoft for use with the Microsoft Direct3D API, analogous to the GLSL language used with OpenGL. It is the official language of Direct3D and of the Xbox platforms, and is widely used in video game and real-time 3D graphics development on Windows.

Overview

HLSL programs — called shaders — are written in a C-like syntax and compiled for execution on graphics processing units. Shader types include vertex, pixel (fragment), geometry, hull, domain, and compute shaders, as well as newer amplification and mesh shaders. Shaders express how vertices are transformed and how surfaces are lit and coloured, using built-in vector and matrix types, intrinsic functions, and semantics that bind shader inputs and outputs to pipeline stages.

Compilation

HLSL source can be compiled ahead of time or at runtime into an intermediate bytecode (DXBC for the legacy compiler, DXIL for the newer DirectX Shader Compiler based on LLVM). Shader Model versions, from Shader Model 1.0 through 6.x, define successive feature levels; later models added compute support, dynamic linking, ray tracing shaders, and wave intrinsics.

Comparison with GLSL

HLSL differs from GLSL in details of syntax, in its treatment of uniforms through constant buffers, and in its compilation model. Cross-compilers such as SPIRV-Cross and Microsoft's own tooling can translate between HLSL, GLSL, and SPIR-V for multi-platform engines.
