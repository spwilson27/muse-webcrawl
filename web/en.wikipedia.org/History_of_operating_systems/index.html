Operating systems evolved from batch monitors to time-sharing, personal and mobile systems.

The history of operating systems traces the development of the software layer that manages computer hardware and provides services to applications. The earliest computers had no operating system at all: programs were loaded and run one at a time by operators and programmers working directly with the machine.

Mainframe era

In the mid-1950s, resident monitors and batch systems such as GM-NAA I/O (1956, for the IBM 704) automated job sequencing. The 1960s introduced the defining concepts of the field: multiprogramming, spooling, virtual memory (on the Atlas computer, 1962), and interactive time-sharing, pioneered by MIT's CTSS (1961) and the influential Multics project. IBM's OS/360 (1966), despite its troubled development chronicled in Fred Brooks's The Mythical Man-Month, established the idea of a compatible family of machines sharing one operating system.

Unix and minicomputers

Ken Thompson and Dennis Ritchie at Bell Labs created Unix (from 1969) as a lean reaction to Multics; rewritten in C in 1973, it spread widely through universities, spawning the BSD line and countless descendants, and standardising ideas such as hierarchical file systems, pipes and "everything is a file". DEC's VMS served minicomputers, while the microcomputer era began with CP/M (1974) and Apple DOS.

Personal computing

Microsoft's MS-DOS (1981) dominated IBM PC compatibles; Apple's Macintosh (1984) popularised the graphical user interface pioneered at Xerox PARC, and Microsoft's Windows (from 1985, dominant with Windows 95) followed. The 1990s brought fully 32-bit preemptive systems: Windows NT, and Linux — Linus Torvalds's free kernel (1991) combined with GNU software — which came to dominate servers, supercomputers and (via Android, 2008) mobile phones. Apple's macOS (2001) is Unix-based, as is iOS (2007).

Modern developments

Contemporary trends include virtualisation and hypervisors, containerisation (e.g. Docker), real-time and embedded systems, and cloud-native orchestration. The core functions identified in the 1960s — process, memory, file and device management, security and scheduling — remain the skeleton of every modern operating system.
