Type conversion

Conversion of a value from one data type to another.

In computer science, type conversion, type casting, type coercion, and type juggling are ways of changing an expression from one data type to another. An example is the conversion of an integer value into a floating-point value, or its textual representation as a string, and vice versa. Type conversions can take advantage of certain features of type hierarchies or data representations, but may also introduce precision loss or runtime errors if performed unsafely.

Implicit and explicit conversion

Implicit conversion, or coercion, is performed automatically by the compiler or interpreter, usually when it is "safe" — for instance, widening an integer to a larger floating-point type in a mixed expression. In C, adding an int and a double converts the integer to double before the addition.

Explicit conversion, or casting, is requested by the programmer, for example with C-style casts such as (int)3.99, which truncates to 3, or with constructor-like syntax in C++ and Rust (as). Explicit casts can also reinterpret bit patterns, as with pointer casts, which are a frequent source of undefined behaviour when misused.

Checking and safety

Languages differ in how aggressively they coerce: weakly typed languages such as JavaScript convert operands across types freely (the string "5" minus the number 3 yields 2), which can surprise; strongly typed languages restrict conversions to a defined set. Conversions between object types in class hierarchies are handled by upcasts (always safe) and downcasts (which require runtime type checking, e.g. Java's instanceof or C++'s dynamic_cast).
