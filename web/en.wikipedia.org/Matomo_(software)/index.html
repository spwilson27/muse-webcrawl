Matomo (software)

Matomo, formerly Piwik, is a free and open source web analytics application developed by a team of international developers, that runs on a PHP/MySQL web server. It tracks online visits to one or more websites and displays reports on these visits for analysis. As of June 2022, Matomo was used by about one million websites, including governments and companies that value data ownership and user privacy, because Matomo can be self-hosted so that analytics data is not shared with third parties.

History

Piwik was released in late 2007 as a replacement for phpMyVisites, with full API support and a cleaner web interface. In January 2018, Piwik was officially renamed to Matomo. The software is written in PHP, distributed under the GNU General Public License, and offers features comparable to Google Analytics such as real-time reporting, conversion tracking, e-commerce analytics, and privacy tools including IP anonymisation and opt-out mechanisms.

Features

Matomo provides dashboards, visitor logs, goal conversion tracking, event tracking, site search analytics, and a tag manager. It can be installed on-premises or used as a cloud service. Because data is stored on the user's own server, Matomo is often promoted as a GDPR-friendly alternative to cloud analytics platforms.
