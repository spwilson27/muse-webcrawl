Cluster analysis
Type: Unsupervised learning
Tasks: Grouping similar objects
Common methods: k-means, hierarchical clustering, DBSCAN

Cluster analysis or clustering is the task of grouping a set of objects in such a way that objects in the same group (called a cluster) are more similar in some sense to each other than to those in other groups. It is a main task of exploratory data analysis and a common technique for statistical data analysis, used in fields including machine learning, pattern recognition, bioinformatics, and market research.

Approaches

Clustering algorithms are commonly grouped into connectivity-based (hierarchical) methods, which build nested clusters by successively merging or splitting groups; centroid-based methods such as k-means, which represent each cluster by a mean vector; distribution-based methods, which model clusters as statistical distributions, as in Gaussian mixture models; and density-based methods such as DBSCAN, which define clusters as dense connected regions.

Evaluation

Because clustering is unsupervised, evaluating results is difficult. Internal measures such as silhouette scores assess cohesion and separation, while external measures compare clusters against known labels. The choice of distance measure and algorithm strongly affects the result, and there is no universally "correct" clustering.

Applications

Clustering is used for customer segmentation, grouping genes and proteins by expression patterns, image segmentation, document organization, anomaly detection, and community detection in social networks.
