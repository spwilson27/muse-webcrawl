LLVM

LLVM
Developer: LLVM Developer Group
Initial release: 2003
Written in: C++
License: Apache 2.0 with LLVM Exceptions

LLVM is a set of compiler and toolchain technologies that can be used to develop a frontend for any programming language and a backend for any instruction set architecture. LLVM is designed around a language-independent intermediate representation (IR) that serves as a portable, high-level assembly language that can be optimized with a variety of transformations over multiple passes.

History

The project began in 2000 at the University of Illinois at Urbana–Champaign under Vikram Adve and Chris Lattner as a research infrastructure for dynamic compilation techniques. The name was originally an acronym for "Low Level Virtual Machine", but the project has grown far beyond that scope and the acronym is no longer used. In 2005 Apple hired Lattner and made LLVM a focus of its developer tools; the Clang frontend became the default compiler for Xcode.

Architecture

A typical LLVM-based compiler uses a frontend (such as Clang for C and C++) to translate source code into LLVM IR, an optimizer that works on the IR, and a backend that emits machine code for targets including x86, ARM, RISC-V, and WebAssembly. The IR exists in three forms: an in-memory representation, a human-readable textual format (.ll files), and an on-disk bitcode format.

Components

Subprojects include Clang, the LLD linker, LLDB debugger, libc++, the MLIR compiler infrastructure, and OpenMP support. Languages with LLVM backends include Rust, Swift, Julia, Haskell, and many others.

Licensing

LLVM is released under the Apache License 2.0 with LLVM Exceptions, which permit linking compiled output without imposing license obligations on the resulting binary.
