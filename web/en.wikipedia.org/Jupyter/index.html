Jupyter

Project Jupyter is a non-profit, open-source project that develops open standards and software for interactive computing across dozens of programming languages. Its best-known product is the Jupyter Notebook, a web-based application for creating and sharing documents that contain live code, equations, visualizations and narrative text.

History

Jupyter evolved out of IPython, founded by Fernando Pérez in 2001. In 2014 IPython's language-agnostic components were spun off into Project Jupyter, whose name is a reference to the three core languages Julia, Python and R. JupyterLab, a more flexible interface, followed as the next-generation notebook environment.

Uses

Notebooks are stored as JSON documents with the .ipynb extension. Jupyter is widely used in data science, machine learning, scientific computing and education, and is supported by services such as Google Colab, Binder and major cloud platforms. The project is governed by NumFOCUS and received the ACM Software System Award in 2017.
