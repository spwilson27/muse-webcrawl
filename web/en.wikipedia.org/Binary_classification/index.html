Binary classification

Binary classification is the task of classifying the elements of a set into one of two groups on the basis of a classification rule. It is the simplest form of classification in statistics and machine learning, with typical examples including medical testing (diseased or healthy), spam detection (spam or not spam), and quality control (pass or fail).

Evaluation

Binary classifiers are evaluated using a confusion matrix of true positives, false positives, true negatives, and false negatives. Derived measures include accuracy, precision, recall (sensitivity), specificity, and the F1 score. Receiver operating characteristic (ROC) curves plot the true positive rate against the false positive rate across decision thresholds.

Methods

Common algorithms for binary classification include logistic regression, support vector machines, decision trees, naive Bayes classifiers, k-nearest neighbors, and neural networks. Many multiclass problems are reduced to binary classification through schemes such as one-vs-rest.
