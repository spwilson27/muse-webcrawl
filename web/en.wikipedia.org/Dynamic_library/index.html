Dynamic library

A dynamic library, also called a shared library or shared object, is a file containing machine code that is loaded and linked to a program at run time rather than being copied into the executable at build time. On Windows such files typically have the .dll extension (dynamic-link library), on macOS .dylib, and on Unix-like systems .so.

Advantages

Dynamic linking reduces the size of executables, allows multiple programs to share one copy of library code in memory, and lets libraries be updated independently of the programs that use them.

Disadvantages

Programs depend on the library being present and compatible at run time; mismatched versions can cause failures, a situation colloquially known as "DLL hell". Dynamic linking also adds a small run-time overhead and can complicate deployment.

See also static library and dynamic linker.
