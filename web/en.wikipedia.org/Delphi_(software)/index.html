Delphi (software)

DeveloperEmbarcadero Technologies (originally Borland)

Delphi is a software product that uses the Delphi dialect of the Object Pascal programming language and provides an integrated development environment (IDE) for rapid application development of desktop, mobile, web and console software. It was originally developed by Borland and first released in 1995.

Features

Delphi combines a visual form designer with a fast native-code compiler and component libraries: the Visual Component Library (VCL) for Windows and FireMonkey (FMX) for cross-platform development. Its component-based, event-driven model made it a leading rapid application development (RAD) tool of the late 1990s.

History

Delphi grew out of Borland's Turbo Pascal line; its chief architect was Anders Hejlsberg, who had designed Turbo Pascal and later created C#. The product's codename referenced the Oracle at Delphi ("if you want to talk to the Oracle, go to Delphi"). Ownership passed from Borland to CodeGear and then to Embarcadero Technologies in 2008.

Language

The Delphi language extends Object Pascal with features such as generics, anonymous methods, attributes and class helpers. Delphi code compiles to native executables with no runtime dependency, a trait that has kept it in use for long-lived business applications.
