Truth table

Truth table
FieldLogic, mathematics, computer science

Truth tables enumerate every possible combination of input truth values.

A truth table is a mathematical table used in logic — specifically in connection with Boolean algebra, Boolean functions, and propositional calculus — which sets out the functional values of logical expressions on each of their functional arguments, that is, for each combination of values taken by their logical variables. In particular, truth tables can be used to show whether a propositional expression is true for all legitimate input values, that is, logically valid.

Structure

A truth table has one column for each input variable and one final column showing all possible results of the logical operation that the table represents. Each row represents one of the possible combinations of input values; with n binary inputs there are 2n rows. For example, the table for conjunction (AND) and disjunction (OR) over inputs p and q is:

pqp ∧ qp ∨ qp → q¬p
TTTTTF
TFFTFF
FTFTTT
FFFFTT

Uses

Truth tables determine whether an argument in propositional logic is valid (the conclusion is true in every row where all premises are true), whether a formula is a tautology, contradiction, or contingency, and whether two expressions are logically equivalent. In digital electronics and computer science, truth tables specify the behavior of logic gates and combinational circuits and are inputs to logic minimization (e.g., Karnaugh maps and the Quine–McCluskey algorithm). Their exponential growth makes them impractical for large variable counts, where proof procedures such as resolution are preferred.

History

Truth-table-like matrices appear in the unpublished manuscripts of Charles Sanders Peirce (1880s–1900s). The device was publicly introduced in 1921, independently, in Ludwig Wittgenstein's Tractatus Logico-Philosophicus and in Emil Post's "Introduction to a General Theory of Elementary Propositions", and became a standard tool of the new mathematical logic.
