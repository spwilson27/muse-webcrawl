Breadth-first search

Breadth-first search (BFS) is an algorithm for traversing or searching tree and graph data structures. It starts at a chosen root node and explores all neighbours at the current depth before moving to nodes at the next depth level, using a queue to keep track of the frontier.

Algorithm

BFS marks the start node as visited and enqueues it. It then repeatedly dequeues a node, visits each unvisited neighbour, marks it visited, and enqueues it. Because nodes are processed in first-in, first-out order, BFS finds the shortest path (in edges) between the start and any reachable node in an unweighted graph.

Complexity

With V vertices and E edges, BFS runs in O(V + E) time. Its space complexity is O(V), since the queue may hold an entire level of the graph; this can be much larger than the memory used by depth-first search on deep graphs.

Applications

BFS is used in shortest-path routing, web crawling, social-network analysis ("degrees of separation"), garbage collection, and solving puzzles such as the shortest solution to a Rubik's Cube. It underlies the Edmonds–Karp algorithm for maximum flow.
