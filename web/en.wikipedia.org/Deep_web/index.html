Deep web
The deep web is often visualised as the submerged part of an iceberg, below the surface web.
Related conceptsSurface web, Dark web, Darknet, Search engine indexing
Term coined2001 (popularised by Michael K. Bergman)

The deep web, invisible web, or hidden web are parts of the World Wide Web whose contents are not indexed by standard web search-engine programs. This is in contrast to the "surface web", which is accessible to anyone using the internet. Computer scientist Michael K. Bergman is credited with inventing the term in 2001 as a search-indexing term.

The content of the deep web is hidden behind HTTP forms and includes many very common uses such as web mail, online banking, and services that users must pay for, and which are protected by a paywall. Content of the deep web can be located and accessed by a direct URL or IP address, but may require a password or other security access to get past public-facing pages.

Sizing

Estimates based on extrapolations from a study done at the University of California, Berkeley in 2001 speculated that the deep web consisted of about 7,500 terabytes of information, far larger than the surface web. More recent estimates suggest that genuinely unindexed content remains much larger than the indexed web, though precise measurement is difficult because the size of private databases changes constantly.

Deep web and dark web

The deep web is frequently confused with the dark web. The dark web is the portion of content that exists on darknets — overlay networks that require specific software, configurations, or authorisation to access, such as Tor — whereas the deep web is simply content not indexed by search engines, most of which is entirely mundane.

Classification

Content in the deep web can be categorised into forms such as dynamic content generated in response to queries, unlinked content, private web content behind logins, non-HTML/text content that search engines handle poorly, and content in databases accessible only through a search interface.
