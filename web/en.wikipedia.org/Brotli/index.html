Brotli is a lossless data compression algorithm developed by Google. It uses a combination of the general-purpose LZ77 lossless compression algorithm, Huffman coding and second-order context modelling to compress data, at a compression ratio comparable to the best currently available general-purpose compression methods.

Overview

Brotli was initially developed in 2013 to decrease the size of transmissions of WOFF2 web font data, and was released as a general-purpose compressor in September 2015. It uses a pre-defined 120-kilobyte dictionary of common strings from text, HTML and JavaScript, along with context modelling and sliding windows of up to 16 megabytes. The reference implementation is written in C and released as free software.

Use on the web

Brotli is widely used for HTTP compression: content served over HTTPS can use the br content encoding, which is supported by all major web browsers. It typically achieves smaller output than the older gzip format, at the cost of slower compression at the highest quality settings (levels 0–11). The format is standardised in RFC 7932.

The name derives from Brötli, a Swiss German word for a small bread roll.
