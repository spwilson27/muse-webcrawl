Z39.50

Z39.50 is an international standard client–server, application-layer communications protocol for searching and retrieving information from a database over a TCP/IP computer network, especially library catalogues. It is covered by ANSI/NISO standard Z39.50 and ISO standard 23950. The standard's maintenance agency is the Library of Congress.

History

Work on the protocol began in the 1970s under the National Information Standards Organization (NISO). Versions appeared in 1988 (version 1), 1992 (version 2), and 1995 (version 3), the latter adding features such as result-set sorting, extended services, and support for additional record formats. The corresponding ISO standard, ISO 23950, was published in 1998.

Functionality

Z39.50 supports a rich set of operations: a client can initialize a session, express complex queries (notably in the Type-1 RPN query language defined by the Bib-1 attribute set, using attributes for use, relation, position, structure, truncation, and completeness), browse indexes (Scan), retrieve records in formats such as MARC or SUTRS, and manage result sets on the server. The protocol is widely implemented in integrated library systems, union catalogues such as WorldCat, interlibrary-loan workflows, and copy-cataloguing, where librarians download bibliographic records from remote databases.

Modern developments

Because of its complexity and OSI heritage, Z39.50 has been complemented by web-oriented successors developed by the Z39.50 International Next Generation (ZING) initiative: SRU (Search/Retrieve via URL), which uses HTTP and CQL queries, and SRW, its SOAP-based sibling. Client software includes the open-source YAZ toolkit from Index Data and Z39.50 support built into most library systems; tools such as the Z39.50 extension for MetaProxy and the bibutils suite are also used.
