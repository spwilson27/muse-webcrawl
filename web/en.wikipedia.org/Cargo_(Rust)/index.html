Cargo (Rust)

TypePackage manager, build tool
ForRust programming language

Cargo is the build system and package manager for the Rust programming language. Cargo downloads a project's dependencies, compiles the project (libraries and binaries), runs tests, and produces distributable packages called crates. It is distributed together with Rust itself and is written in Rust.

Cargo manages Rust packages, known as crates.

Overview

A Cargo project is described by a manifest file, Cargo.toml, which lists the package name, version, edition of Rust, and its dependencies. Dependencies are resolved against the central registry, crates.io, using semantic versioning; the exact resolved versions are recorded in a lock file, Cargo.lock, so builds are reproducible.

$ cargo new hello_world
$ cargo build
$ cargo run
$ cargo test
$ cargo publish

Features

  • Workspaces: multiple related packages can share a lock file and build directory.
  • Features: optional, additive compile-time flags that enable optional dependencies or code paths.
  • Build scripts: a build.rs program run before compilation, used to link native libraries or generate code.
  • Profiles: debug and release profiles controlling optimization and debug information.

History

Cargo was developed alongside Rust by the Rust project, with Yehuda Katz among its early designers. The crates.io registry launched in 2014, and Cargo shipped with Rust 1.0 in May 2015. It has since become the standard way to build and share Rust software.
