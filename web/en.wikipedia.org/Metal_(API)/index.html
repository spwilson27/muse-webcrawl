Metal (API)

Metal

Developer: Apple Inc.

Initial release: June 2014 (iOS 8)

Platforms: iOS, macOS, tvOS, visionOS

Type: Graphics and compute API

Metal is a low-level, low-overhead hardware-accelerated 3D graphic and compute shader API created by Apple. It debuted in iOS 8 in 2014 and combines functions similar to OpenGL and OpenCL into a single API for Apple's platforms.

Features

Metal gives applications near-direct access to the GPU, reducing CPU overhead by pre-encoding commands and managing resources explicitly. Shaders are written in the Metal Shading Language, based on C++14, and compiled both at build time and at runtime. Metal 2 (2017) added machine-learning acceleration and VR support; Metal 3 (2022) added hardware ray tracing acceleration structures, mesh shaders, and upscaling via MetalFX.

Adoption

Metal replaced OpenGL and OpenCL as Apple's preferred graphics API, and those older APIs are deprecated on Apple platforms. Major game engines and professional applications use Metal on macOS and iOS, and it is the standard rendering backend for Apple's own frameworks.
