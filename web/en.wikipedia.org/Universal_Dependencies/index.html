Universal Dependencies

Universal Dependencies (UD) is an international cooperative project to create treebanks of the world's languages annotated in a uniform way, using a cross-linguistically consistent grammatical annotation framework based on dependency grammar. The project provides open data — treebanks in well over 100 languages — used widely in natural language processing research and for multilingual parser development.

Framework

UD annotation rests on three pillars: universal part-of-speech tags (17 categories such as NOUN, VERB, and ADJ), universal morphological features, and universal dependency relations (such as nsubj for nominal subject and obj for object) that connect words in a tree rooted in the main predicate. Content words are treated as heads wherever possible to maximize cross-linguistic parallelism. Data are distributed in the CoNLL-U format with columns for form, lemma, tags, features, head, and relation.

History and use

UD grew out of earlier efforts at harmonizing treebank annotation, including the Stanford Dependencies and Google's universal tagset work, and released its first version in October 2014. Regular releases have added languages and corrected annotation. The shared tasks at CoNLL 2017 and 2018 on multilingual parsing from raw text to UD made the treebanks the standard benchmark for cross-lingual dependency parsing, and tools such as UDPipe are trained on UD data.
