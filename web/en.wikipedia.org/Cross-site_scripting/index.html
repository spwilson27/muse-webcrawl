Cross-site scripting

From Wikipedia, the free encyclopedia

Cross-site scripting (XSS) is a type of security vulnerability that can be found in some web applications. XSS attacks enable attackers to inject client-side scripts into web pages viewed by other users. A cross-site scripting vulnerability may be used by attackers to bypass access controls such as the same-origin policy.

Types

XSS vulnerabilities are conventionally classified as stored (or persistent), in which the malicious script is permanently stored on the target server, for example in a comment field or database; reflected (or non-persistent), in which the script is reflected off a web server in an error message or search result delivered to the victim; and DOM-based, in which the vulnerability exists in client-side code that writes user input into the document object model unsafely.

Impact

Exploitation can allow an attacker to steal session cookies, impersonate the victim, deface pages, redirect users, or perform actions on the victim's behalf. XSS has historically been among the most commonly reported web vulnerabilities and has featured in major incidents against popular websites and webmail services.

Prevention

Defences include validating and sanitizing user input, context-sensitive output encoding, using templating systems that escape data by default, deploying Content Security Policy headers, and marking cookies HttpOnly so they cannot be read by scripts.
