Hurwitz zeta function

The Hurwitz zeta function in the complex plane

In mathematics, the Hurwitz zeta function is one of the many zeta functions. It is named after Adolf Hurwitz, who introduced it in 1882. It is formally defined for complex arguments s with Re(s) > 1 and q with Re(q) > 0 by

ζ(s, q) = Σn=0∞ 1 / (n + q)s.

For q = 1 the Hurwitz zeta function reduces to the Riemann zeta function ζ(s). The function admits an analytic continuation to a meromorphic function on the whole complex s-plane, with a single simple pole at s = 1.

Special values

At negative integers, the values of the Hurwitz zeta function are related to the Bernoulli polynomials: ζ(1 − n, q) = −Bn(q)/n for n ≥ 1. In particular, ζ(−n, q) generalises the Bernoulli numbers when q = 1.

Relations and derivatives

The derivative with respect to s at s = 0 is connected with the gamma function through Lerch's formula, which expresses ζ′(0, q) in terms of the logarithm of the gamma function. The Hurwitz zeta function also satisfies a functional relation generalising the functional equation of the Riemann zeta function, expressed through the Fourier transform of periodic zeta functions, and it appears in the study of Dirichlet L-functions: for a character χ modulo k, L(s, χ) can be written as a finite combination of Hurwitz zeta values ζ(s, a/k).

Applications

Hurwitz zeta functions occur in number theory, in the theory of modular forms, in statistics (where derivatives of zeta functions appear in certain probability distributions), and in physics, for example in computations of Casimir energies and in the spectral analysis of quantum systems.
