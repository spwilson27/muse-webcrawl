Recursion (computer science)

In computer science, recursion is a method of solving a computational problem where the solution depends on solutions to smaller instances of the same problem. A recursive function calls itself, directly or indirectly, until a base case is reached.

Examples

The factorial function is the classic example: n! = n × (n−1)!, with 0! = 1. The Fibonacci sequence, binary search, and tree traversals are also commonly defined recursively. Many sorting algorithms, such as quicksort and mergesort, use a recursive divide-and-conquer strategy.

Implementation

Recursive calls are typically implemented with a call stack; deep recursion risks stack overflow. Tail recursion can be optimised by some compilers into iteration. Recursion is fundamental to functional programming and to the theory of computation, where recursive (computable) functions characterise what algorithms can compute.
