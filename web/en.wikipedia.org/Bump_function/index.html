Bump function

Bump function
FieldMathematical analysis
PropertiesSmooth (C∞), compactly supported, non-analytic
UsesMollifiers, partitions of unity, distributions

In mathematics, a bump function (also called a test function) is a function on Euclidean space which is both smooth (in the sense of having continuous first partial derivatives of all orders) and compactly supported. The set of all bump functions with domain Rn forms a vector space, denoted C0∞(Rn) or Cc∞(Rn). The dual space of this space, when equipped with an appropriate topology, is the space of distributions.

Examples

The standard example is based on the function that equals e−1/x for x > 0 and 0 for x ≤ 0, which is smooth but not analytic at 0. From it one constructs a bump function on the real line equal to exp(−1/(1−x²)) for |x| < 1 and 0 otherwise. Rescaled and normalized versions of such functions serve as mollifiers: convolving a rough function with a mollifier produces a smooth approximation, a basic technique in analysis and partial differential equations.

Existence and properties

No nonzero analytic function can be a bump function, since an analytic function vanishing on an open set vanishes everywhere — this is why bump functions showcase the difference between smoothness and analyticity. Bump functions are essential in constructing partitions of unity on manifolds, in the theory of distributions, and in proving that smooth functions can be localized. The space of bump functions is dense in many function spaces, including Lp spaces for finite p.
