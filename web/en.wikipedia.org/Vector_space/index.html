Vector space

From Wikipedia, the free encyclopedia

In mathematics, a vector space (also called a linear space) is a set whose elements, called vectors, can be added together and multiplied ("scaled") by numbers called scalars. Scalars are often real or complex numbers, but vector spaces can be defined over any field.

Vector addition by the parallelogram rule.

Definition

A vector space over a field F is a set V with two operations — vector addition and scalar multiplication — satisfying eight axioms, including associativity and commutativity of addition, the existence of a zero vector and additive inverses, and distributivity of scalar multiplication:

a(u + v) = au + av; (a + b)v = av + bv; (ab)v = a(bv); 1·v = v

Examples

  • ℝn — n-tuples of real numbers, the archetype from Euclidean geometry and physics.
  • The set of all polynomials with coefficients in F.
  • Spaces of functions, such as continuous functions on an interval — typically infinite-dimensional.
  • The set {0} alone (the trivial vector space).

Bases and dimension

Every vector space has a basis: a linearly independent spanning set. All bases of a given space have the same cardinality, the space's dimension. Linear maps between vector spaces can be represented by matrices once bases are chosen — the core of linear algebra.
