A hidden Markov model (HMM) is a statistical model in which the system being modelled is a Markov process with hidden (unobserved) states. An HMM can be thought of as the simplest dynamic Bayesian network: at each time step the system occupies one of a set of discrete states, transitions between states according to fixed probabilities, and emits an observable symbol whose probability depends on the current state.

Architecture and parameters

An HMM is specified by the number of states N, the state-transition probability matrix A, the emission (observation) probability distribution B for each state, and the initial state distribution π; collectively λ = (A, B, π). The model generates an observation sequence by walking through hidden states and emitting symbols along the way. Because emissions are probabilistic, the same state can produce different observations, and the same observation can arise from different states — hence the state sequence is "hidden" and must be inferred.

Three basic problems

Three canonical problems define work with HMMs. Evaluation — computing the probability of an observation sequence given a model — is solved efficiently by the forward algorithm (and its backward counterpart). Decoding — finding the most likely hidden state sequence — is solved by the Viterbi algorithm. Learning — estimating the parameters λ from observed sequences — is typically done with the Baum–Welch algorithm, a special case of expectation–maximization. These algorithms make HMMs practical for sequences of substantial length.

Applications

HMMs were developed mathematically by Leonard Baum and co-workers in the 1960s and became famous through speech recognition, where from the 1970s (work at IBM and CMU) until the rise of deep learning they were the dominant technology, modelling phonemes as states. In bioinformatics, profile HMMs underpin sequence alignment and gene finding (tools such as HMMER); other uses include part-of-speech tagging, handwriting and gesture recognition, musical score following, financial time-series analysis, and decoding neural signals. Extensions include continuous-density (Gaussian mixture) emissions, factorial HMMs, hierarchical HMMs and input–output HMMs.
