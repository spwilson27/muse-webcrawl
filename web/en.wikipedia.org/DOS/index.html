DOS

DOS
Full name: Disk Operating System
Platform: Primarily x86 PCs
Interface: Command line

DOS is a family of disk-based operating systems for x86-based personal computers, dominated in the 1980s and early 1990s by Microsoft's MS-DOS and IBM PC DOS.

History

DOS originated with 86-DOS (QDOS), purchased by Microsoft and licensed to IBM in 1981 as PC DOS 1.0 for the IBM PC. MS-DOS versions followed through 6.22 in 1994, after which Windows graphical systems took over.

Characteristics

DOS is a single-user, single-tasking system with a command-line interface (COMMAND.COM), 640 KB conventional memory limit, 8.3 filenames, and drive-letter filesystem access.

Variants and legacy

Other variants included DR-DOS and the open-source FreeDOS, still maintained today. DOS concepts persist in the Windows command prompt.
