Unit testing

Unit testing
Field: Software testing
Granularity: Individual functions or methods
Frameworks: JUnit, pytest, NUnit

Unit testing is a software testing method by which individual units of source code — sets of one or more program modules, procedures, or methods — are tested to determine whether they are fit for use. Unit tests are typically automated, written by developers, and executed frequently, especially in continuous integration pipelines.

Benefits and techniques

Isolating each part of a program and verifying its correctness facilitates design, provides living documentation, and makes defects easier to locate. Test doubles — stubs, fakes, and mocks — replace dependencies a unit cannot control. Unit testing is a cornerstone of test-driven development, in which tests are written before the code they exercise. Critics note that poorly designed unit tests can be brittle and that unit-level correctness does not guarantee integration correctness.
