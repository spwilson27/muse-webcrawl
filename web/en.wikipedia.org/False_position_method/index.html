False position method

From Wikipedia, the free encyclopedia

In mathematics, the false position method or regula falsi method is a root-finding algorithm that combines features of the bisection method and the secant method. Like the bisection method, it maintains a bracket of two points whose function values have opposite signs, guaranteeing convergence to a root; but instead of taking the midpoint, it takes the point where the straight line through the two bracket endpoints crosses the x-axis — the "false position".

The method

Given points a and b with f(a) and f(b) of opposite sign, the next approximation is:

c = b − f(b)·(b − a) / (f(b) − f(a))

The point c then replaces whichever endpoint has a function value of the same sign, keeping the root bracketed. The method dates to ancient Egyptian and Babylonian mathematics; a form of it appears in the Rhind Papyrus (c. 1550 BC), and it was transmitted through medieval texts such as Fibonacci's Liber Abaci (1202), making it one of the oldest numerical methods still in use.

Convergence and variants

Regula falsi always converges, but it can be much slower than the bisection method in one respect: if the function is strongly curved, one endpoint may remain fixed for many iterations, so the interval shrinks only from one side and convergence becomes merely linear. Modifications such as the Illinois algorithm, the Pegasus method and the Anderson–Björck method correct this by scaling the retained endpoint's function value, restoring fast superlinear convergence. The hybrid Brent's method, widely used in numerical libraries, combines false-position-like interpolation with bisection safeguards.
