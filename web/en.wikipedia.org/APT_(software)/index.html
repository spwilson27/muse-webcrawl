APT (software)

APT
Developer: Debian Project
Initial release: 1998
Written in: C++
License: GNU GPL

APT (Advanced Package Tool) is a free software user interface that works with core libraries to handle the installation and removal of software on Debian and Debian-based Linux distributions. APT simplifies the process of managing software on Unix-like computer systems by automating the retrieval, configuration and installation of software packages, either from precompiled files or by compiling source code.

History

APT was introduced in 1998 with Debian 2.1 (hamm). It replaced the earlier dselect tool as the recommended front end to the dpkg package management system, adding automatic dependency resolution against package repositories.

Usage

Common commands include apt update to refresh the package index, apt upgrade to install available upgrades, and apt install <package> to install a package and its dependencies. Sources are listed in /etc/apt/sources.list and files under /etc/apt/sources.list.d/.

Front-ends

Graphical and alternative front-ends built on APT include Synaptic, GNOME Software, and the aptitude console interface.
