ChromeOS

Developer: Google

Initial release: 2011

Kernel: Linux

ChromeOS is a Linux-based operating system developed by Google for Chromebooks and other devices. Announced in 2009 and first shipped in 2011, it is designed around the Chrome browser, cloud services, automatic updates, and a comparatively simple security model.

Features

Users work primarily with web applications and progressive web apps. Later versions added support for Android applications through Google Play and Linux applications in a virtual machine, expanding ChromeOS into a more general computing platform while retaining centralized management valued by schools and businesses.

Design and security

The system uses verified boot, sandboxing, read-only system partitions, and seamless background updates. User data is strongly associated with a Google account and can be synchronized across devices.

Reception

ChromeOS became especially successful in education because of low-cost hardware and easy administration, though critics have noted dependence on internet services and limitations for specialized desktop software.
