diff

diff is a file comparison utility that outputs the differences between the contents of two files, line by line for text files. Originally developed for the Unix operating system at Bell Labs in the early 1970s — the first version shipped with the 5th Edition of Unix in 1974 — diff underlies patch files, version-control systems and code review throughout software development.

diff reports the lines that must change to turn one file into another.

Algorithm

The classic algorithm, by Douglas McIlroy and James Hunt, finds a longest common subsequence of the two files' lines — equivalently a shortest edit script — using analysis refined from the Hunt–Szymanski algorithm. Modern implementations such as GNU diffutils add heuristics (the Myers O(ND) algorithm) to handle large files gracefully, though the minimal output is not always the most human-readable.

Output formats

Besides the original "normal" format (commands like 3a4 and 7d6), diff supports the context format (-c) and the now-standard unified format (-u), in which hunks of changed lines are shown together with a few lines of surrounding context — the format used by patch, Git and most development tools.
