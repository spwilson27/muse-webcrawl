Technical documentation

Technical documentation is any document that describes the handling, functionality, architecture or use of a technical product or system. It includes user manuals, installation and maintenance guides, API references, specifications, online help, and knowledge bases, and it is produced by technical writers, often working with engineers and subject-matter experts.

Forms

Traditional technical documentation was delivered as printed manuals. Modern practice favours electronic delivery — HTML help systems, PDFs, embedded assistance, and searchable web portals — frequently produced from single-source content using structured authoring standards such as DITA (Darwin Information Typing Architecture) or DocBook, in which topics are written once and assembled into multiple outputs.

Process

Creating technical documentation typically involves analysing the audience, planning the information architecture, drafting and reviewing content with engineers, testing instructions with users, and maintaining the documents as the product changes. In software, the "docs as code" approach manages documentation with the same version control and review tools used for source code.

Standards

Various standards govern technical documentation, including ISO/IEC 26514 for user documentation and industry-specific requirements in fields such as aviation, medicine and machinery safety, where documentation is a legal requirement.
