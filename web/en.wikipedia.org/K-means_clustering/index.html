K-means clustering

From Wikipedia, the free encyclopedia

K-means clustering is a method of vector quantization, originally from signal processing, that is popular for cluster analysis in data mining. It aims to partition n observations into k clusters in which each observation belongs to the cluster with the nearest mean (cluster centre or centroid), serving as a prototype of the cluster.

Algorithm

The standard algorithm, often called Lloyd's algorithm, alternates between two steps. In the assignment step, each observation is assigned to the cluster whose mean yields the least within-cluster sum of squares. In the update step, the new means are computed as the centroids of the observations in each cluster. The algorithm iterates until the assignments no longer change. It is guaranteed to converge to a local optimum, though not necessarily the global optimum, so results depend on the initial choice of centroids.

History

The term "k-means" was first used by James MacQueen in 1967, though the underlying method was described by Hugo Steinhaus in 1957 and the standard algorithm by Stuart Lloyd in 1957 (published in 1982). Edward W. Forgy's essentially identical algorithm appeared in 1965, so the method is sometimes called the Lloyd–Forgy algorithm.

Variants and limitations

Common variants include k-means++, which seeds initial centroids so as to spread them apart and improves both speed and quality; fuzzy c-means, which allows partial cluster membership; and mini-batch k-means for large data sets. The method assumes roughly spherical, similarly sized clusters and requires the number of clusters k to be chosen in advance, which motivates diagnostics such as the elbow method and silhouette scores. Finding the optimal solution is NP-hard in general, but the iterative heuristic is fast in practice and remains one of the most widely used clustering algorithms, with applications in image segmentation, document clustering, market segmentation, and compression.
