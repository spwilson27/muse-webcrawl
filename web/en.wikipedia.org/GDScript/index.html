GDScript

GDScript source code in the Godot Engine editor

GDScript is a high-level, object-oriented, imperative, and gradually typed programming language built for the Godot game engine. Its syntax is deliberately similar to Python, using indentation to delimit blocks, and it is designed to integrate tightly with Godot's scene and node architecture.

Features

GDScript scripts are attached to nodes in a Godot scene tree. The language provides first-class support for engine concepts such as signals (an implementation of the observer pattern), groups, and scene instancing. It supports both dynamic typing and optional static typing with type hints, which can improve performance and editor error-checking. Since Godot 4.0, GDScript has included features such as lambdas, typed arrays, await for coroutines, and improved pattern matching.

History

Godot's lead developer Juan Linietsky created GDScript because integrating existing scripting languages such as Lua or Python with the engine's object model proved awkward, and a custom language promised a smaller footprint and better optimisation for the engine's needs. GDScript first appeared with Godot's open-source release in 2014 and was substantially rewritten for Godot 4.0 (2023), which added a new bytecode interpreter with significant performance improvements.

Use

GDScript is the most widely used language for Godot development, popular for 2D and 3D indie games, prototypes, and game jams. Alternatives within Godot include C#, C++, and visual scripting (removed in Godot 4).
