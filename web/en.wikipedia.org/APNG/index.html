APNG (Animated Portable Network Graphics) is an extension to the PNG image format that adds support for animated images similar to animated GIFs, while retaining compatibility with non-animated PNG decoders. It was created by Stuart Parmenter and Vladimir Vukićević of the Mozilla Corporation in 2004 as an alternative to the MNG format, which the PNG group had designed for animation but which saw little adoption because of its complexity and large decoder footprint.

Design

An APNG file stores its animation data in additional chunks after the standard PNG image data. The first frame of the animation is an ordinary PNG image, so any PNG viewer can display it as a static picture; animation-aware viewers read the extra chunks (acTL, fcTL and fdAT) to reconstruct the full sequence. Unlike GIF, APNG supports 24-bit colour and 8-bit alpha transparency, allowing smooth semi-transparent animations.

Adoption

The PNG Working Group rejected APNG as an official extension in 2007, favouring MNG, but the format spread through browser support: Firefox and Opera (Presto) supported it early, Safari added support in 2014, and Google Chrome in 2017, making APNG effectively universally supported in modern browsers. Apple adopted APNG for animated stickers in iMessage with iOS 10. In 2024–2025 the PNG specification's third edition formally incorporated APNG into the core PNG standard, ending its long status as an unofficial extension.
