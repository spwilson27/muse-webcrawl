Countable set

In mathematics, a countable set is a set with the same cardinality (number of elements) as some subset of the natural numbers. A set that is not countable is called uncountable.

Definition

A set is countably infinite if it can be put in one-to-one correspondence with the natural numbers. Finite sets are also countable under common usage. Examples: integers and rational numbers are countable; real numbers are uncountable, as shown by Cantor's diagonal argument. Countable unions of countable sets are countable.

The cardinality of a countably infinite set is aleph-null, ℵ0.
