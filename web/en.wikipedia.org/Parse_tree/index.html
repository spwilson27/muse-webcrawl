Parse tree

A parse tree or parsing tree, also called a derivation tree or concrete syntax tree, is an ordered, rooted tree that represents the syntactic structure of a string according to some grammar. The interior nodes of the tree are labelled by non-terminal symbols of the grammar, the leaves by terminal symbols (or the empty string), and each interior node's children correspond to one application of a production rule. Reading the leaves left to right reproduces the original string.

Parse trees and abstract syntax trees

A parse tree is "concrete": it records every detail of the derivation, including punctuation and keywords that carry no meaning. Compilers usually condense the parse tree into an abstract syntax tree (AST), which omits such syntactic sugar and keeps only the structure needed for semantic analysis and code generation. The process of constructing a parse tree from an input string is called parsing and is performed by a parser, generated by hand or by a parser generator from a grammar specification.

Ambiguity

If a grammar permits a string to have more than one parse tree, the grammar is said to be ambiguous for that string. Ambiguity is a practical problem in programming-language design — the classic example is the dangling else — and language designers either rewrite the grammar to remove the ambiguity or add precedence and associativity rules to select among trees.

Linguistics

In linguistics, parse trees (often called phrase structure trees) diagram the constituent structure of sentences. In the tradition of generative grammar descending from Noam Chomsky, such trees show how a sentence is built from noun phrases, verb phrases, and other constituents, and tree diagrams remain a standard tool for representing syntactic structure and its ambiguities — as in the classic example "I saw the man with the telescope".
