Security Assertion Markup Language

Security Assertion Markup Language (SAML, pronounced "sam-el") is an open standard for exchanging authentication and authorization information between parties, in particular between an identity provider (IdP) and a service provider (SP). SAML is an XML-based markup language developed by the OASIS Security Services Technical Committee; the current version, SAML 2.0, was ratified in 2005.

How it works

SAML enables web-based single sign-on (SSO): a user authenticates once with an identity provider, which issues a digitally signed XML assertion attesting to the user's identity and attributes. The assertion is conveyed to the service provider — typically through the user's browser using HTTP redirects or form posts defined by SAML bindings — and the service provider grants access without the user presenting separate credentials. Trust between parties is established in advance by exchanging metadata and certificates.

Components

  • Assertions — statements about a subject: authentication, attribute, and authorization decision statements.
  • Protocols — request/response message formats for obtaining assertions.
  • Bindings — mappings of SAML messages onto transports such as HTTP POST and HTTP Redirect.
  • Profiles — combinations of the above for specific use cases, such as the Web Browser SSO Profile.

Use

SAML 2.0 is widely used for enterprise and government single sign-on, federating access to cloud applications and across organizational domains, alongside newer protocols such as OpenID Connect.
