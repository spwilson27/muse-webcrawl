Microsoft Word is a word processor developed by Microsoft. It was first released on October 25, 1983, under the name Multi-Tool Word for Xenix systems. Subsequent versions were written for IBM PCs running DOS, the Apple Macintosh (1985), SCO Unix, and Microsoft Windows (1989); the Windows version became dominant, and Word grew into the world's most widely used word processing program as part of Microsoft Office and Microsoft 365.

History

Word was developed by Charles Simonyi and Richard Brodie, former Xerox PARC programmers hired by Bill Gates in 1981; it drew on concepts from Bravo, the first WYSIWYG word processor, developed at PARC. The DOS versions struggled against WordPerfect, but the graphical Windows versions overtook it in the early 1990s. Word 97 introduced the Office Assistant ("Clippy"), later retired; Word 2007 brought the Ribbon interface and the XML-based .docx format; later versions added real-time co-authoring, cloud storage via OneDrive, and integrated AI features through Microsoft 365 Copilot.

File formats

Word's native formats are the legacy binary .doc (Word 97–2003) and the Office Open XML .docx format (Word 2007 and later), standardized as ISO/IEC 29500. The ubiquity of the formats made them de facto standards for document exchange, though the binary format's complexity long hampered interoperability. Word also reads and writes Rich Text Format, plain text, HTML, and PDF.

Features

Beyond text editing and formatting, Word includes spell and grammar checking, templates, mail merge, tables, image placement, tracked changes and comments for collaborative review, footnote and bibliography tools, and automation via macros and VBA. Its dominance in offices, schools, and publishing has made "Word document" nearly synonymous with formatted text files in everyday usage.
