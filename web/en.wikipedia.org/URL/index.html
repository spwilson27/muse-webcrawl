URL

A uniform resource locator (URL), colloquially known as a web address, is a reference to a web resource that specifies its location on a computer network and a mechanism for retrieving it. A URL is a specific type of uniform resource identifier (URI), although many people use the two terms interchangeably. URLs occur most commonly to reference web pages (HTTP/HTTPS) but are also used for file transfer (FTP), email (mailto), database access (JDBC), and many other applications.

History

The URL was defined by Tim Berners-Lee in 1994, in RFC 1738, building on the concepts developed at CERN for locating documents on the World Wide Web. The syntax generalised earlier addressing schemes into a common format combining a scheme, an authority, and a path.

Syntax

A generic URL has the form scheme://authority/path?query#fragment. The scheme indicates the protocol or addressing system (for example https); the authority typically includes a host name and optionally a port and user information; the path identifies a resource on the host; the query string supplies parameters; and the fragment identifies a secondary resource such as a section of a page.

Use and issues

URLs are entered into browsers, embedded in hyperlinks, and printed as short links or QR codes. Because long URLs can be unwieldy, URL shortening services arose. URLs may break when resources move — a phenomenon called link rot — and persistent identifier schemes such as DOI and PURL were created to mitigate it. Internationalised resource identifiers (IRIs) extend URLs to allow characters from many writing systems.
