Conflict-free replicated data type

In distributed computing, a conflict-free replicated data type (CRDT) is a data structure that is replicated across multiple computers in a network, where the replicas can be updated independently and concurrently without coordination, and where it is always mathematically possible to resolve inconsistencies that might result. The replicas converge to a consistent state — a property called strong eventual consistency — without needing a consensus protocol.

Types

There are two main families. State-based CRDTs (convergent replicated data types, CvRDTs) send their full state to other replicas and merge states using a join operation that is commutative, associative, and idempotent, forming a join-semilattice. Operation-based CRDTs (commutative replicated data types, CmRDTs) propagate only update operations, which must commute with one another when applied concurrently.

Examples and use

Well-known examples include grow-only counters (G-Counters), positive–negative counters, grow-only sets, observed-remove sets (OR-Sets), and sequence CRDTs such as RGA and LSEQ used for collaborative text editing. CRDTs underpin many real-time collaborative editors, distributed databases such as Redis and Riak data types, and offline-first applications.
