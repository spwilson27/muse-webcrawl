Medium access control

In IEEE 802 LAN/MAN standards, the medium access control (MAC), also called media access control, is the layer that controls the hardware responsible for interaction with the wired (electrical or optical) or wireless transmission medium. The MAC sublayer and the logical link control (LLC) sublayer together make up the data link layer. The LLC provides flow control and multiplexing, while MAC provides addressing (MAC addresses) and channel access control mechanisms that make it possible for several terminals or network nodes to communicate within a multiple access network, typically a local area network (LAN) or metropolitan area network (MAN).

Channel access methods

MAC protocols determine how stations share a common medium. Families include channel partitioning (TDMA, FDMA, CDMA), random access (ALOHA, CSMA, CSMA/CD used by classic Ethernet, CSMA/CA used by Wi-Fi), and controlled access (token passing, polling). Modern switched Ethernet largely avoids collisions by giving each station a dedicated link, but MAC addressing remains fundamental.

MAC addresses

Each network interface is assigned a unique 48-bit MAC address, typically written as six groups of two hexadecimal digits. The first half identifies the manufacturer (OUI); addresses may be locally administered or universally administered. The LLC and MAC together sit at layer 2 of the OSI model.
