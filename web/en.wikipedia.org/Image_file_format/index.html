Image file format

An image file format is a standardised way of organising and storing digital images. Formats divide broadly into raster (bitmap) formats, which store pixel data, and vector formats, which store geometric descriptions that can be scaled without loss.

Raster formats

Common raster formats include JPEG (lossy, for photographs), PNG (lossless, with transparency), GIF (limited palette, animation), TIFF (archival and print), BMP, and WebP and AVIF (modern web formats with better compression). RAW formats preserve unprocessed sensor data from digital cameras.

Vector formats

SVG is the standard vector format for the web; EPS and PDF are common in print workflows. Vector images are resolution-independent and suited to logos and diagrams.

Compression

Lossless compression (PNG, lossless WebP) preserves every pixel; lossy compression (JPEG) discards information to reduce file size, with quality traded against size. Animated formats include GIF, APNG, and animated WebP/AVIF.
