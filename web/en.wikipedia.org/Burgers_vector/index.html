Burgers vector

Burgers vector
Concept in materials science
Named after: Johannes Martinus Burgers
Quantity: Vector describing lattice distortion of a dislocation

In materials science, the Burgers vector, named after Dutch physicist Johannes Martinus Burgers, is a vector, often denoted b, that represents the magnitude and direction of the lattice distortion resulting from a dislocation in a crystal lattice.

Definition

The Burgers vector is determined by drawing a Burgers circuit: a closed atom-to-atom path around the dislocation line in a real crystal. The same sequence of steps is then traced in a perfect reference crystal; the closure failure of that path is the Burgers vector.

Types of dislocation

If the Burgers vector is perpendicular to the dislocation line, the dislocation is an edge dislocation; if parallel, it is a screw dislocation; intermediate orientations are mixed dislocations. The magnitude of the Burgers vector for a face-centred cubic crystal is commonly a/2<110>, where a is the lattice parameter.

Significance

The Burgers vector is conserved as a dislocation moves and reacts, and it governs the elastic energy of the dislocation, which scales with the square of its magnitude. This is the basis of Frank's rule for dislocation reactions.
