OpenVPN

Original author: James Yonan

Initial release: 2001

Written in: C

Licence: GNU GPL (community edition)

Type: VPN software and protocol

OpenVPN is a free and open-source software application and protocol that implements virtual private network (VPN) techniques to create secure point-to-point or site-to-site connections in routed or bridged configurations and remote access facilities. It was written by James Yonan and first released in 2001. OpenVPN uses a custom security protocol based on SSL/TLS — rather than IPsec — for key exchange, and is capable of traversing network address translators (NATs) and firewalls because it can run over a single UDP or TCP port.

Architecture and security

OpenVPN creates a virtual network interface (TUN or TAP) on each endpoint and encrypts traffic using the OpenSSL library, supporting ciphers such as AES-256-GCM and ChaCha20-Poly1305, with Diffie–Hellman or elliptic-curve key exchange for perfect forward secrecy. Authentication may use pre-shared keys, username/password, or X.509 certificates — the most common deployment model for large installations, where a certificate authority issues client certificates. Data-channel offload (DCO) kernel modules improve throughput on newer releases.

Editions and use

The open-source OpenVPN Community Edition is included in most operating systems and routers and is also offered through commercial products: OpenVPN Access Server (a self-hosted business solution) and OpenVPN Cloud (a managed service). Many consumer VPN providers built their services on OpenVPN, prized for its auditability, cross-platform support (Windows, macOS, Linux, Android, iOS), and ability to run on port 443/TCP to resemble HTTPS traffic. Its security has been reviewed in multiple independent audits commissioned in 2016–2017, which found no critical flaws in the core protocol implementation.
