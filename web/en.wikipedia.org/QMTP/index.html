QMTP

QMTP (Quick Mail Transfer Protocol) is an e-mail transmission protocol designed by Daniel J. Bernstein, the author of the qmail mail transfer agent. QMTP was created as a faster, simpler alternative to SMTP for mail submission and relay between servers that both support it, particularly over reliable high-speed links.

QMTP
Type: E-mail transfer protocol
Designer: Daniel J. Bernstein
Default port: 209 (TCP)
Associated software: qmail (qmail-qmtpd)
Status: Experimental / niche use

Design

QMTP replaces SMTP's verbose, chat-driven exchanges with compact netstring-encoded transactions: the client sends the message and envelope in a small number of length-prefixed strings, and the server replies with a single response per recipient. This drastically reduces round trips compared with SMTP's greeting, HELO, MAIL FROM, RCPT TO, and DATA phases. QMTP runs on TCP port 209, assigned for the purpose, and is implemented by the qmail-qmtpd component of qmail and by some other servers.

Deployment

Because QMTP requires support on both ends, it never achieved the ubiquity of SMTP and is used mainly between cooperating servers, sometimes discovered through MX records pointing to hosts known to run qmail. It is documented in an Internet Draft authored by Bernstein rather than a formal RFC standard.
