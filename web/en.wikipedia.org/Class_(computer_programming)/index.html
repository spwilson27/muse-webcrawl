Class (computer programming)

From Wikipedia, the free encyclopedia

In object-oriented programming, a class is an extensible program-code template for creating objects, providing initial values for state (member variables) and implementations of behaviour (member functions or methods). A class defines a new data type; objects created from a class are called instances of that class. Classes are a central mechanism of languages such as Java, C++, C#, Python, Ruby and Smalltalk.

Structure

A class typically declares:

  • Fields (attributes, member variables) holding the object's state.
  • Methods (member functions) implementing behaviour.
  • Constructors, special methods invoked when an object is created, used to initialise state.
  • Optionally a destructor or finalizer, invoked when an object is destroyed.

Members may be declared with access modifiers such as public, private and protected, controlling which code may use them — an application of encapsulation. A simple example in Java:

public class Point {
    private double x;
    private double y;
    public Point(double x, double y) { this.x = x; this.y = y; }
    public double distance() { return Math.sqrt(x*x + y*y); }
}

Inheritance

A class may be derived from another class, its superclass or base class, inheriting its fields and methods and possibly overriding them; the derived class is a subclass. Inheritance models "is-a" relationships and supports polymorphism, in which a method call on a superclass reference dispatches to the subclass implementation at run time. Some languages (notably C++) allow multiple inheritance; others (Java, C#) allow a class to inherit from only one class but implement multiple interfaces.

Related concepts

An abstract class cannot be instantiated directly and exists to be subclassed, often declaring abstract methods without implementations. An interface specifies a set of method signatures a class must provide, defining a contract without state. Classes differ from prototypes, used in languages such as JavaScript, where objects inherit directly from other objects. In metaclass-based systems, a class is itself an object of a metaclass.

History

The class concept emerged in Simula 67, the first object-oriented language, designed by Ole-Johan Dahl and Kristen Nygaard in Norway. Smalltalk, developed at Xerox PARC in the 1970s, refined the idea and popularised the terminology of classes, objects and messages that later languages adopted.
