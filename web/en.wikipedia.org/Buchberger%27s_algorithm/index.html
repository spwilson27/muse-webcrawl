Buchberger's algorithm

In mathematics, Buchberger's algorithm is a method of transforming a given set of generators for a polynomial ideal into a Gröbner basis with respect to some monomial order. It was invented by Austrian mathematician Bruno Buchberger in 1965, who named the resulting bases after his advisor Wolfgang Gröbner. The algorithm is a generalisation of Gaussian elimination (for linear polynomials) and the Euclidean algorithm (for univariate polynomials).

Description

The algorithm repeatedly forms S-polynomials (syzygy polynomials) from pairs of polynomials, reduces them with respect to the current basis, and adds any nonzero remainder to the basis. Buchberger's criterion guarantees that when every S-polynomial reduces to zero, the set is a Gröbner basis and the process terminates.

Complexity and improvements

The algorithm's worst-case complexity is doubly exponential in the number of variables, yet it is efficient in many practical cases. Improvements include Buchberger's criteria for skipping useless pairs and later algorithms such as Faugère's F4 and F5. Gröbner bases computed with the algorithm are used for solving systems of polynomial equations, implicitisation, robotics, coding theory and automated theorem proving in geometry.
