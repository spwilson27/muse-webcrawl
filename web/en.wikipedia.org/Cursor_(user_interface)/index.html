Cursor (user interface)

Illustration: Cursor (user interface)

In human–computer interaction, a cursor is an indicator used to show the current position for user interaction on a computer monitor or other display device. The text cursor (caret) marks where typed characters will appear, while the mouse cursor—usually an arrow—is controlled by a pointing device.

History

The blinking text cursor was introduced with early computer terminals; Douglas Engelbart's mouse demonstration in 1968 popularised the pointer. Graphical user interfaces standardised shapes: the arrow for pointing, the I-beam for text, the hand for links, and the hourglass or spinning wheel for busy states.

Behaviour

Cursor appearance changes to give feedback about available actions, such as resizing windows or dragging objects. Accessibility settings allow users to enlarge the cursor, enable trails, or locate it with a key press.
