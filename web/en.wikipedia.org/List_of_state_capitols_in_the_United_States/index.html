List of state capitols in the United States

A state capitol is the building housing a U.S. state legislature. Most are domed, modelled on the United States Capitol, though some are distinctive modern designs.

  • Texas State Capitol — Austin, among the largest
  • California State Capitol — Sacramento
  • New York State Capitol — Albany
  • Pennsylvania State Capitol — Harrisburg
  • Wisconsin State Capitol — Madison
  • Louisiana State Capitol — Baton Rouge, a skyscraper and the tallest capitol
  • Nebraska State Capitol — Lincoln, tower design
  • Hawaii State Capitol — Honolulu, modern open design
  • New Mexico State Capitol — Santa Fe, round 'Roundhouse'
  • Virginia State Capitol — Richmond, designed with Thomas Jefferson's involvement

The full list gives, for each state, the capitol city, building, completion date and height.
