Noisy-channel coding theorem

In information theory, the noisy-channel coding theorem (also Shannon's theorem or Shannon's second theorem), established by Claude Shannon in 1948, shows that it is possible to communicate over a noisy channel with arbitrarily low error probability, as long as the communication rate is below a certain threshold called the channel capacity.

Statement

Given a noisy channel with capacity C and information transmitted at rate R, if R < C there exists a coding technique allowing the probability of error at the receiver to be made arbitrarily small; conversely, if R > C the probability of error necessarily grows toward one. The theorem does not itself give the code — finding practical codes approaching capacity (such as turbo codes, LDPC codes, and polar codes) occupied researchers for decades.

Impact

The result founded modern error-correction theory and underlies reliable digital communication, from deep-space probes to mobile networks and data storage.
