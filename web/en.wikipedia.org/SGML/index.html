SGML

The Standard Generalized Markup Language (SGML; ISO 8879:1986) is a standard for defining generalized markup languages for documents. It is a descendant of IBM's Generalized Markup Language (GML), developed in the 1960s by Charles Goldfarb, Edward Mosher and Raymond Lorie (whose surname initials happen to form "GML"). SGML provides an abstract syntax for describing a document's format in terms of descriptive markup — tags and attributes — separate from any particular processing.

An SGML document instance marked up with descriptive tags.

Features

An SGML application is defined by a document type definition (DTD), which specifies the elements, attributes and structural rules permitted in a document class. SGML supports features such as tag omission (inferred end tags), short references, and marked sections. A document is valid if it conforms to its DTD. Because of its generality and complexity, full SGML was rarely implemented in its entirety; notable software included James Clark's SP parser.

Descendants

SGML's most famous application is HTML, the markup language of the World Wide Web, first specified as an SGML application. In 1998 the W3C published XML, a deliberately simplified subset of SGML intended to bring descriptive markup to the web; XML in turn spawned XHTML and numerous data formats. Many modern descendants dropped formal SGML compatibility: HTML5, for example, is no longer defined as an SGML application.

History

SGML grew out of work begun at IBM in 1969 and was standardised by ISO in 1986 (ISO 8879). It was widely adopted for large-scale technical documentation in the aerospace, defence, publishing and semiconductor industries, where documents needed to outlive any single software system.
