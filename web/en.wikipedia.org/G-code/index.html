G-code

G-code (also RS-274) is the most widely used computer numerical control (CNC) and 3D printing programming language. It is used mainly in computer-aided manufacturing to control automated machine tools, as well as for 3D-printer firmware applications. The G stands for geometry. G-code has many variants.

G-code instructions are provided to a machine controller (industrial computer) that tells the motors where to move, how fast to move, and what path to follow. The two most common situations are within a machine tool such as a lathe or mill, in which a cutting tool is moved according to these instructions through a toolpath cutting away material to leave only the finished workpiece; and a 3D printer, in which material is instead extruded layer by layer.

History

The language was developed at MIT in the 1950s for early numerically controlled machines and was standardized in the United States by the Electronic Industries Alliance as RS-274 in the early 1960s. The final revision, RS-274-D, was approved in February 1980. Dialects proliferated among machine builders such as Fanuc, Siemens, and Heidenhain, and G-code was later adopted by desktop 3D printing, notably in the RepRap project and firmware such as Marlin.

Syntax

A program consists of blocks (lines), each containing letter-addressed words. G-words specify preparatory (geometric) functions such as rapid move (G0), linear interpolation (G1), and circular interpolation (G2/G3); M-words specify miscellaneous functions such as spindle start (M3) and program end (M30). Coordinates use X, Y, Z (and additional axes), F sets the feed rate, and S the spindle speed.

G21          ; units in millimetres
G90          ; absolute positioning
G1 X50 Y25 F800   ; linear move
M30          ; end of program

Applications

G-code drives CNC mills, lathes, routers, laser and plasma cutters, and virtually all fused-filament 3D printers, where slicing software converts 3D models into layered toolpaths. Despite its age and dialects, it remains the lingua franca of digital fabrication.
