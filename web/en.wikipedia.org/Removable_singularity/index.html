Removable singularity

In complex analysis, a removable singularity of a holomorphic function is a point at which the function is undefined (or has a singularity), but where it is possible to redefine the function at that point in such a way that the resulting function is regular in a neighbourhood of that point.

The graph of a function with a removable singularity can be "filled in" at the singular point.

Definition

Formally, if U is an open subset of the complex plane, a is a point of U, and f is a holomorphic function on U \ {a}, then a is called a removable singularity for f if there exists a holomorphic function g on all of U which coincides with f on U \ {a}. Equivalently, the singularity is removable if the limit of f(z) as z approaches a exists and is finite.

Example: f(z) = sin z / z has a removable singularity at z = 0, with limit 1.

Riemann's theorem

Riemann's theorem on removable singularities states that if f is holomorphic on a punctured neighbourhood of a and is bounded near a (or, more generally, if (z − a)f(z) tends to 0 as z tends to a), then the singularity at a is removable. Removable singularities contrast with poles, at which the function blows up, and essential singularities, near which the function exhibits wild behaviour described by the Casorati–Weierstrass theorem and Picard's great theorem.
