Signature (logic)

In logic, especially mathematical logic, a signature lists and describes the non-logical symbols of a formal language. In universal algebra, a signature lists the operations that characterize an algebraic structure. For a first-order signature, the list of symbols is divided into constant symbols, function symbols of specified arities, and predicate (relation) symbols of specified arities.

Definition

Formally, a signature σ can be represented as a tuple of three disjoint sets of symbols: constants, function symbols, and relation symbols, each function and relation symbol carrying a natural number called its arity. A structure over a signature interprets each constant as an element of its domain, each n-ary function symbol as an n-ary function, and each n-ary relation symbol as an n-ary relation on the domain.

Examples

The signature of ordered fields, (0, 1, +, −, ·, <), underlies the first-order theory of real closed fields. In model theory, fixing a signature allows one to define terms, atomic formulas, formulas, and sentences of the associated first-order language, and to compare structures of the same signature via elementary embeddings.

Many-sorted signatures

The notion generalizes to many-sorted logic, where symbols are indexed by sorts, and signatures may also include subsort relations. Signatures are foundational in algebraic specification languages, where they define the syntactic framework upon which equations can be stated.
