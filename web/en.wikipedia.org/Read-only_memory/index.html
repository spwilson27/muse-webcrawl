Read-only memory


Placeholder image: Read-only memory

Read-only memory (ROM) is a type of non-volatile memory used in computers and other electronic devices. Data stored in ROM cannot be electronically modified, or can only be modified slowly or with special equipment, after manufacture.

Types

Mask ROM is programmed during fabrication. PROM can be programmed once by the user; EPROM can be erased with ultraviolet light and reprogrammed; EEPROM and flash memory can be erased and rewritten electrically, blurring the line with read/write storage. Historically, ROM was implemented with diode matrices, core rope memory (used in the Apollo Guidance Computer), and punched cards.

Uses

ROM stores firmware — boot code, BIOS/UEFI, embedded controller programs — and fixed data such as character fonts and game cartridges. Filesystem images distributed for emulators are commonly called "ROMs".
