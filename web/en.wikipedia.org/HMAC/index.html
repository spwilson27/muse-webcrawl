HMAC

In cryptography, an HMAC (sometimes expanded as either keyed-hash message authentication code or hash-based message authentication code) is a specific type of message authentication code (MAC) involving a cryptographic hash function and a secret cryptographic key.

Definition

HMAC is defined as HMAC(K, m) = H((K′ ⊕ opad) ∥ H((K′ ⊕ ipad) ∥ m)), where H is a hash function such as SHA-256, K the secret key, and ipad/opad are inner and outer padding constants. The nested construction protects against length-extension attacks that affect naive prefix-keyed hashes.

Uses

HMAC is used to verify both the data integrity and authenticity of a message, and appears in protocols such as IPsec, TLS, and in HMAC-based key derivation (HKDF) and one-time password algorithms (HOTP/TOTP). It is specified in RFC 2104 and FIPS 198-1.
