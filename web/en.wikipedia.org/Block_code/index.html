Block code

In coding theory, a block code is a type of channel code consisting of codewords of a fixed length, as opposed to variable-length codes such as Huffman coding or convolutional codes. Block codes map a block of k information symbols onto a block of n encoded symbols, where n ≥ k. The added redundancy allows the receiver to detect and often correct errors introduced by a noisy channel.

Formal definition

A block code of length n with M messages over an alphabet of size q is a subset of M distinct sequences (codewords) of length n taken from the alphabet. When the alphabet is the binary field, the code is called a binary block code. Linear block codes, in which the set of codewords forms a vector space, are among the most important and most studied families.

Parameters and bounds

The key parameters of a block code are its length n, the number of codewords M, and its minimum distance d, the smallest Hamming distance between any two distinct codewords. A code with minimum distance d can detect up to d − 1 errors and correct up to floor((d − 1)/2) errors. Celebrated results such as the Hamming bound, the Singleton bound and the Gilbert–Varshamov bound describe the trade-offs among these parameters.

Examples

Well-known block codes include the Hamming codes, the Reed–Solomon codes used in compact discs and QR codes, Reed–Muller codes, cyclic codes such as the BCH codes, and the Golay codes. The simplest non-trivial example is the single parity-check code, which appends one bit so that every codeword has even weight.

Decoding

Decoding algorithms for block codes include syndrome decoding for linear codes, the Berlekamp–Massey algorithm for BCH and Reed–Solomon codes, and maximum-likelihood decoding, which is optimal but often computationally expensive for long codes. Modern soft-decision techniques and iterative methods have broadened the practical range of block codes considerably.
