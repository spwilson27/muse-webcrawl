Combination

Combination
FieldCombinatorics
NotationC(n,k), nCk, binomial coefficient
Related conceptsPermutation, Binomial coefficient, Factorial

In mathematics, a combination is a selection of items from a set that has distinct members, such that the order of selection does not matter (unlike permutations). For example, given three fruits, say an apple, an orange and a pear, there are three combinations of two that can be drawn from this set: an apple and a pear; an apple and an orange; or a pear and an orange. More formally, a k-combination of a set S is a subset of k distinct elements of S. If the set has n elements, the number of k-combinations, denoted by C(n,k) or Cnk, is equal to the binomial coefficient.

Number of combinations

The number of k-combinations from a given set of n elements is denoted C(n,k). It is the same as the number of k-element subsets (that is, combinations) of an n-element set. It can be calculated from the formula for permutations, noting that each combination of k elements can be arranged in k! ways, giving

C(n,k) = n! / (k! (n − k)!)

This formula can be derived using the principle of counting: there are n choices for the first element, n − 1 for the second, and so on down to n − k + 1 choices for the k-th element; but each unordered selection is counted k! times, once for each ordering of its elements.

Example of counting combinations

As a concrete example, one can compute the number of five-card hands possible from a standard fifty-two-card deck: C(52,5) = 52! / (5! · 47!) = 2,598,960. Unlike a permutation, in a hand of cards the order in which the cards are dealt does not matter.

Combinations with repetition

A combination with repetition, or multisubset, is a selection in which elements may be chosen more than once. The number of ways to choose k elements with repetition from an n-element set is given by the multichoose coefficient C(n + k − 1, k), which can be proved by the stars and bars argument.
