Birthday attack

A birthday attack is a type of cryptographic attack that exploits the mathematics behind the birthday problem in probability theory. It allows an attacker to find two different inputs that produce the same hash value (a collision) much faster than brute force would suggest.

Mathematics

For a hash function with n-bit outputs, a collision can be expected after roughly 2n/2 evaluations, rather than 2n. This is why a 128-bit hash offers only about 64 bits of collision resistance.

Implications

Birthday attacks motivate the use of long hash outputs; modern standards such as SHA-256 provide about 128 bits of collision resistance, which is considered beyond feasible attack.
