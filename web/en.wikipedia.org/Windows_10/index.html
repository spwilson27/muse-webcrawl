Windows 10 is a major release of the Windows NT operating system developed by Microsoft, released on July 29, 2015. It succeeded Windows 8.1 and was marketed as an operating system as a service, receiving ongoing feature updates rather than discrete successor releases for several years; Microsoft initially described it as the "last version of Windows" before announcing Windows 11 in 2021.

Features

Windows 10 restored the Start menu, combining the Windows 7 list with Windows 8 live tiles. It introduced the Microsoft Edge web browser, the Cortana virtual assistant, virtual desktops (Task View), the Universal Windows Platform for apps across devices, Windows Hello biometric sign-in, and the Xbox app for game streaming. DirectX 12 shipped with the system for improved graphics performance.

Reception and adoption

The system was offered as a free upgrade to users of Windows 7 and 8.1 during its first year, which drove rapid adoption; it surpassed 400 million active devices within a year. Reviewers praised the return of a desktop-oriented interface but criticised forced updates, privacy settings, and the aggressive upgrade campaign. Windows 10 became the most-used Windows version worldwide by 2018.

End of support

Mainstream support for most editions ended on October 14, 2025, with an Extended Security Updates programme offered to consumers and businesses for an additional period.
