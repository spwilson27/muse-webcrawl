Ajax (programming)

Ajax (short for "Asynchronous JavaScript and XML") is a set of web development techniques that allows web applications to send and retrieve data from a server asynchronously, in the background, without reloading the whole page. By exchanging small amounts of data as needed, Ajax enables interactive features such as live search suggestions, map tiles that load as you pan, and mail clients that update without refresh.

History

The underlying technology, the XMLHttpRequest object, was created by Microsoft for Outlook Web Access around 1999 and adopted by other browsers. Jesse James Garrett coined the term "Ajax" in a 2005 essay, and applications such as Google Maps and Gmail demonstrated its power, ushering in the "Web 2.0" era. JSON largely replaced XML as the data format, and the modern Fetch API has superseded XMLHttpRequest in most new code.

Technologies

Ajax combines HTML and CSS for presentation, the Document Object Model and JavaScript for dynamic display, and an asynchronous transport (XMLHttpRequest or fetch) exchanging data — commonly JSON — with a web server. Libraries such as jQuery historically smoothed over browser differences.

Drawbacks

Ajax applications complicate browser history and bookmarking, can hinder search-engine indexing and accessibility if implemented carelessly, and introduce latency and error handling absent from simple page loads. Modern single-page application frameworks build on the same principles.
