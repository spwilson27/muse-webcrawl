State-space models

A state-space model links unobserved states to measured observations.

State-space models are mathematical models that describe a system by a set of input, output, and state variables related by differential or difference equations. In statistics and control theory, the state-space representation separates a system's hidden internal state, which evolves over time, from the observations generated by that state.

Formulation

A linear state-space model is written as a state equation, xt+1 = A xt + B ut + wt, and an observation equation, yt = C xt + vt, where x is the state vector, u an input, y the observation, and w and v noise terms. In continuous time the state equation becomes a differential equation, ẋ = A x + B u.

Applications

State-space models underpin the Kalman filter, used for estimation and control in engineering, navigation, and robotics. In econometrics and time-series analysis they model unobserved components such as trends and cycles, and in machine learning related formulations include hidden Markov models and dynamic Bayesian networks.
