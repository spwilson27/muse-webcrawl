In computer networking, an Ethernet frame is a data link layer protocol data unit on an Ethernet network. A frame begins with header and trailer features — including source and destination MAC addresses — used to deliver data between nodes on the same local network segment. Frames are carried inside the physical layer's signal as packets of bits, with a preamble and start frame delimiter marking where each frame begins.

Structure

A typical IEEE 802.3 frame consists of: a 7-byte preamble and 1-byte start frame delimiter (on the wire, not counted in the frame size); a 6-byte destination MAC address; a 6-byte source MAC address; an optional 4-byte 802.1Q VLAN tag; a 2-byte field that in Ethernet II gives the EtherType of the encapsulated protocol (e.g. 0x0800 for IPv4, 0x0806 for ARP, 0x86DD for IPv6) or in 802.3 gives the payload length; a payload of 46 to 1500 bytes (padded if necessary); and a 4-byte frame check sequence (FCS), a CRC-32 used to detect corruption. Frames are separated on the medium by an interframe gap of 96 bit times.

Total frame size on the wire for standard Ethernet ranges from 64 to 1518 bytes (1522 with a VLAN tag). Oversized "jumbo frames" of up to about 9000 bytes are widely supported on modern equipment to improve efficiency but are not part of the original standard. Frames shorter than 64 bytes ("runts") and frames failing the FCS check are discarded.

Frame types

Historically, several framing conventions coexisted: Ethernet II (DIX) framing, Novell's raw 802.3 framing, IEEE 802.3 with LLC (802.2) headers, and 802.3 with SNAP. Receivers distinguish them by the value of the length/EtherType field: values of 1536 (0x0600) and above indicate an EtherType, smaller values indicate length. Ethernet II framing dominates modern networks.
