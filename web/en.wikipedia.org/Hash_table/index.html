Hash table

In computing, a hash table (also known as a hash map) is a data structure that implements an associative array, mapping keys to values. A hash table uses a hash function to compute an index, also called a hash code, into an array of buckets or slots, from which the desired value can be found. During a lookup, the key is hashed and the resulting hash indicates where the corresponding value is stored.

Ideally, the hash function will assign each key to a unique bucket, but most hash table designs employ an imperfect hash function, which might cause hash collisions where the hash function generates the same index for more than one key. Such collisions are typically accommodated in some way.

Operations

Hash tables support insertion, deletion, and lookup of key–value pairs. In a well-dimensioned hash table, the average time complexity for each of these operations is O(1) (constant), independent of the number of elements stored. The ratio of stored entries to buckets is called the load factor; when it grows too large, the table is typically resized (rehashing all entries into a larger array).

Collision resolution

Two main strategies handle collisions. In separate chaining, each bucket holds a list (often a linked list) of the entries that hash to it. In open addressing, colliding entries are placed in other buckets according to a probing sequence, such as linear probing, quadratic probing, or double hashing.

Hash functions

A good hash function distributes keys uniformly across the buckets to minimise collisions. Common techniques include the division method, multiplication method, and universal hashing, in which the function is chosen randomly from a family to guarantee good average performance.

Applications

Hash tables underlie associative arrays in most programming languages (such as Python dictionaries and Java's HashMap), database indexing, caches, symbol tables in compilers, and deduplication tasks.
