Return loss

Return loss is a measure, usually expressed in decibels, of how much power is reflected back toward the source when a signal encounters a discontinuity in a transmission line or optical fibre. It quantifies the quality of impedance matching between a source and a load.

Definition

Return loss is defined as the ratio of the incident power to the reflected power, expressed in decibels: RL = 10 log10(Pi/Pr). Equivalently, it is related to the voltage reflection coefficient Γ by RL = −20 log10 |Γ|. A perfectly matched load reflects no power, giving infinite return loss; a total mismatch (open or short circuit) gives 0 dB.

Relationship to VSWR

Return loss is closely related to the voltage standing wave ratio (VSWR). A VSWR of 1.5:1 corresponds to a return loss of about 14 dB, while a VSWR of 2:1 corresponds to roughly 9.5 dB.

Applications

Return loss measurements are standard in radio-frequency engineering, antenna testing, and fibre-optic communications, where connector and splice quality are assessed using optical time-domain reflectometers. High return loss values are desirable in most systems because reflected power represents lost signal and can cause interference or damage to transmitters.
