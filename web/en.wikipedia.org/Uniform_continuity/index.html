Uniform continuity

For a uniformly continuous function, a single δ works for every point of the domain.

In mathematics, a real function f of real numbers is said to be uniformly continuous if there is a positive real number δ such that function values over any function interval of length δ are as close to each other as we please. That is, given any positive real number ε > 0, there exists δ > 0 such that for all x, y in the domain with |x − y| < δ, we have |f(x) − f(y)| < ε.

The difference between uniform continuity and ordinary continuity is that in uniform continuity the chosen δ depends only on ε, whereas in ordinary continuity δ may also depend on the point x.

Examples

The identity function and all Lipschitz continuous functions are uniformly continuous on any set. The function f(x) = x² is continuous on the whole real line but not uniformly continuous there, because its slope grows without bound; it is, however, uniformly continuous on every bounded interval. The function f(x) = 1/x is not uniformly continuous on (0, 1).

Heine–Cantor theorem

The Heine–Cantor theorem states that a continuous function on a compact set (such as a closed bounded interval) is uniformly continuous. Uniform continuity also implies that a uniformly continuous function maps Cauchy sequences to Cauchy sequences, which fails for merely continuous functions in general.
