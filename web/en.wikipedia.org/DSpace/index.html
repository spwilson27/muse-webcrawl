DSpace

DSpace
Original authors: MIT Libraries and Hewlett-Packard Labs
Initial release: November 2002
Type: Institutional repository software
License: BSD 3-Clause

DSpace is an open-source software package typically used for creating open access repositories for scholarly and/or published digital content. While DSpace shares some feature overlap with content management and document management systems, it is specifically designed to serve as a platform for institutional repositories, preserving and providing access to research outputs such as journal articles, theses, reports, and datasets.

History

DSpace was jointly developed by MIT Libraries and Hewlett-Packard Labs and was first released in November 2002. It grew out of a broader movement toward institutional repositories and open access publishing. Governance of the project later passed to the DSpace community under the stewardship of DuraSpace, and subsequently LYRASIS following a merger. DSpace has become one of the most widely used repository platforms in the world, installed by thousands of institutions.

Features

The software organizes content into communities and collections, supports the Dublin Core metadata standard, assigns persistent identifiers (handles), and exposes content to search engines and harvesters through the OAI-PMH protocol. It is written in Java, uses a relational database such as PostgreSQL, and supports full-text search. Major releases such as DSpace 7 introduced a single, configurable user interface based on Angular with a REST API backend.
