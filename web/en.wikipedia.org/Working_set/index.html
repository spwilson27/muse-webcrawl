Working set

In computer science, the working set is a concept describing the amount of memory a process requires in a given time interval. Introduced by Peter Denning in 1968, the working set model explained thrashing in virtual memory systems and guided the design of page replacement policies.

Definition

The working set W(t, θ) of a process is the set of pages it has referenced within the most recent θ units of virtual time (page references). If the sum of working sets of all runnable processes exceeds physical memory, the system thrashes, spending most of its time paging.

Applications

Operating systems approximate working sets for memory balancing; the concept also applies to CPU caches, where a program's cache working set predicts performance, and to network and database buffer management.

Working set size

Working set size (WSS) is the number of pages in the working set. It is commonly measured empirically and used in capacity planning and cloud autoscaling.
