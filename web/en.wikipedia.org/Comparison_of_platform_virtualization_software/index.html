This article compares platform virtualization software—hypervisors that allow multiple operating systems to run concurrently on one physical machine—by architecture, supported hosts and guests, and management features.

Types of hypervisor

Type-1 (bare-metal) hypervisors such as VMware ESXi, Microsoft Hyper-V, Xen and KVM run directly on hardware and dominate data centres. Type-2 (hosted) products such as Oracle VirtualBox and VMware Workstation run atop a conventional operating system and are common on desktops.

Features compared

Tables typically record live migration, snapshots, paravirtualisation support, maximum virtual CPUs and memory per guest, USB and graphics passthrough, and clustering or high-availability options, alongside licence terms.

Open source platforms

KVM, integrated into the Linux kernel, underpins OpenStack clouds and the Proxmox VE management platform. Xen powered early public clouds and remains used in specialised and security-focused systems such as Qubes OS.
