Data dictionary

A data dictionary is a centralised repository of information about data, such as its meaning, relationships to other data, origin, usage, and format. It documents the elements of a database or information system: tables, fields, data types, constraints, allowable values and definitions, so that developers, analysts and users share a consistent understanding of the data.

Types

An active data dictionary is maintained automatically by a database management system and updated whenever the database structure changes; the system catalog of tables and columns in a relational database is an example. A passive data dictionary is maintained separately, often as a document or spreadsheet, and must be updated manually to stay synchronised with the system. Data dictionaries originated in structured analysis, where they defined every data flow, store and element in a system's data-flow diagrams.

Contents

Typical entries record an element's name, aliases, description, data type and length, whether it is required, default and permitted values, and its source and owner. In research contexts, data dictionaries (or codebooks) accompany shared datasets so that others can interpret variables correctly.
