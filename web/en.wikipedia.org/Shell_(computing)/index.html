Shell (computing)

From Wikipedia, the free encyclopedia

[Image: a terminal window with a shell prompt]

In computing, a shell is a computer program that exposes an operating system's services to a human user or other programs. In general, operating system shells use either a command-line interface (CLI) or graphical user interface (GUI), depending on a computer's role and particular operation. It is named after the idea that it is the outer layer of interface between the user and the operating system's kernel.

Shells specialized for searching the web are called search engines, and those used for file management are often called file managers. The earliest shells were simple command interpreters; the Multics shell of 1965 introduced many concepts later adopted by the Thompson shell for Unix in 1971.

Command-line shells

A command-line shell is a text-based interface in which the user types commands, presses Enter, and reads textual output. Examples on Unix-like systems include the Bourne shell (sh), the C shell (csh), the Korn shell (ksh), Bash, and the Z shell (zsh). On Microsoft Windows, PowerShell and the traditional Command Prompt serve this role.

Interactive shells typically provide features such as job control, command history, filename completion, aliasing, and scripting. A shell script is a program written in the shell's language, often used to automate administration tasks.

Graphical shells

Graphical shells provide a GUI, usually built on top of a windowing system and widget toolkit. On desktop computers, environments such as GNOME, KDE Plasma, and the Windows shell itself handle file management, launching applications, and presenting windows. On mobile devices, launchers and home-screen applications act as shells.
