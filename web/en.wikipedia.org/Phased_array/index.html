Phased array

A phased array antenna steers its beam by adjusting element phases.

In antenna theory, a phased array usually means an electronically scanned array, a computer-controlled array of antennas which creates a beam of radio waves that can be electronically steered to point in different directions without moving the antennas. The relative phases of the signals feeding the elements are varied so that constructive and destructive interference steer the beam.

Principle

When the elements of an array are fed with signals of equal phase, the combined wavefront is broadcast perpendicular to the array face. By introducing a progressive phase shift between adjacent elements, the wavefront tilts, steering the beam. Because steering is electronic, the beam can be repositioned in microseconds, allowing a single radar to interleave search, tracking and communication functions.

Types

  • Passive electronically scanned array (PESA) — elements are fed from a single transmitter/receiver through phase shifters; used in systems such as the SPY-1 radar of the Aegis Combat System.
  • Active electronically scanned array (AESA) — each element has its own transmit/receive module, giving greater power, reliability and beam flexibility; standard on modern fighter aircraft radars.

Applications

Phased arrays were developed for military radar during the Second World War and the Cold War — large examples include the PAVE PAWS early-warning radars and the Soviet Duga system. Today they are used in weather radar, air traffic control, satellite communications, radio astronomy (e.g., phased array feeds), 5G base stations and handsets, and medical ultrasound imaging, where the same beamforming principle applies to acoustic waves.
