Exif

A digital camera photograph whose embedded Exif tags record exposure settings and capture time.

The Exchangeable image file format (Exif) is a standard that specifies formats for images, sound, and ancillary tags used by digital cameras (including smartphones), scanners and other systems handling image and sound files recorded by digital cameras. The specification uses the existing JPEG, TIFF Revision 6.0, and RIFF WAV file formats, with the addition of specific metadata tags.

Technical background

Exif metadata tags can include the date and time the photo was taken, camera make and model, shutter speed, aperture value, ISO speed rating, focal length, flash status, and, if the device supports it, GPS location information recording where the photograph was taken. Applications such as photo organisers, mapping software and social networks read these tags to sort, place and annotate images.

History

Exif was created by the Japan Electronic Industries Development Association (JEIDA) and is maintained in cooperation with the Camera & Imaging Products Association (CIPA). Version 2.2, sometimes called Exif Print, was published in 2002 and added print-related features; version 2.21 unified the colour spaces; version 2.3 followed in 2010, with 2.31 in 2013 and 3.0 in May 2023.

Privacy considerations

Because Exif tags can reveal location and timestamps, publishing unedited photographs can inadvertently disclose sensitive personal information. Most major social-media platforms strip location metadata on upload, and many photo tools offer an option to remove Exif data before sharing.
