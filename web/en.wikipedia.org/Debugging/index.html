Debugging

Debugging is the process of finding, analysing, and removing bugs (defects or problems that prevent correct operation) in computer programs, software, or systems. It is a multistep process in software development that involves identifying a problem, isolating its source, and then either correcting the problem or determining a way to work around it; the final step is testing the correction and confirming it introduces no regressions.

Etymology

The terms "bug" and "debugging" are popularly attributed to Admiral Grace Hopper, whose team in 1947 found an actual moth taped into the logbook of the Harvard Mark II computer. In fact, "bug" was used for defects in engineering at least since the 1870s — Thomas Edison used it — and "debugging" in aviation and electronics preceded its adoption in computing.

Process and techniques

Common debugging strategies include:

  • Interactive debugging — stepping through code with a debugger, setting breakpoints, and inspecting variables and memory.
  • Print (tracing) debugging — inserting logging or output statements to follow program state.
  • Remote and post-mortem debugging — inspecting a running remote system or analysing a crash dump after failure.
  • Delta debugging and bisection — automatically narrowing down the input or the change-set that triggers the failure.
  • Static analysis and testing — using analysers, unit tests, and regression tests to find or localise faults without execution.

Tools

A debugger is a program used to test and debug other programs; examples include GDB, LLDB, WinDbg, and the debuggers integrated into development environments such as Visual Studio and IntelliJ IDEA. Memory debuggers (for example Valgrind), profilers, assertion checks, and sanitizers support the wider debugging process.

Anti-patterns

Debugging is made harder by tightly coupled code, undocumented assumptions, and intermittent ("Heisenbug") failures that change behaviour when observed. The related field of defensive programming aims to reduce the number of bugs that reach the debugging stage.
