Virtual union catalogue

A virtual union catalogue is a library catalogue that provides simultaneous, real-time searching across the catalogues of multiple libraries, without first merging their records into a single physical database. It contrasts with a conventional (physical) union catalogue, in which records from many libraries are copied and combined into one central index.

How it works

Virtual union catalogues typically use the Z39.50 protocol (or its web successor SRU/SRW) to broadcast a user's query to many target catalogues at once, then merge and de-duplicate the returned results for display. Because the search is live, holdings information is always current, but performance is limited by the slowest target, and differing local cataloguing practices can produce inconsistent results.

Examples

Examples include Germany's Karlsruhe Virtual Catalogue (KVK), which searches dozens of German and international catalogues, and various regional and subject-based metasearch services. OCLC's WorldCat, by contrast, is a physical union catalogue built from contributed records. Virtual catalogues are a precursor of modern library discovery systems and metasearch engines.
