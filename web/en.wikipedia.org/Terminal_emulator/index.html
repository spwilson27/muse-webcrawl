Terminal emulator

A terminal emulator window running a shell

A terminal emulator, or terminal application, is a computer program that emulates a video terminal within some other display architecture. It provides a text-based interface—typically to a command-line shell—by interpreting the byte stream exchanged with a pseudo-terminal and rendering it in a graphical window.

Function

Terminal emulators replicate the behaviour of hardware terminals such as the DEC VT100 and VT220, processing ANSI escape sequences that control cursor position, colour, and text attributes. Common examples include xterm, GNOME Terminal, Konsole, iTerm2, Windows Terminal, and PuTTY (which also acts as an SSH client). On Unix-like systems the emulator connects to a pseudoterminal device, so programs believe they are talking to a real serial terminal.

History

Early computers were operated through printing teletypes and later through cathode-ray "glass terminals." As graphical workstations replaced standalone terminals in the 1980s, emulation software preserved the enormous body of terminal-oriented applications and workflows. Terminal emulators remain central to system administration, software development, and remote access decades later.
