The UltraSPARC is a microprocessor developed by Sun Microsystems and fabricated by Texas Instruments. Introduced in 1995, it was Sun's first processor implementing the 64-bit SPARC V9 instruction set architecture, and the first in the UltraSPARC line that powered Sun's workstations and servers, including the Ultra series and the Enterprise servers.

Design

The original UltraSPARC was a four-issue superscalar design with an in-order pipeline, running at 143–200 MHz. Unusually for its time it included the Visual Instruction Set (VIS), SIMD extensions for media processing that anticipated later multimedia instruction sets. It contained 3.8 million transistors and was fabricated in a 0.5 μm process.

Successors

The UltraSPARC II (1997) raised clock speeds towards 650 MHz; the UltraSPARC III (2001) reached 1.2 GHz; and the UltraSPARC IV (2004) combined two cores on one die. The line's emphasis later shifted to multi-threading with the UltraSPARC T1 ("Niagara", 2005), which traded single-thread performance for throughput with eight cores and 32 threads, an approach continued in later SPARC T-series processors.
