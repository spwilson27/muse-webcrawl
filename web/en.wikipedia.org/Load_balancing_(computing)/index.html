Load balancing (computing)

In computing, load balancing is the process of distributing a set of tasks or network traffic over a set of resources (computing units) to make the overall processing more efficient. A load balancer sits between clients and a pool of servers, forwarding each request to one of the servers and returning its response.

Benefits

Load balancing improves responsiveness and availability: it prevents any single server from becoming a bottleneck, allows capacity to be scaled horizontally by adding servers, and enables failing servers to be removed from rotation so the service stays up.

Algorithms

  • Round robin — requests are sent to servers in rotation.
  • Weighted round robin — more powerful servers receive a proportionally larger share.
  • Least connections — the server with the fewest active connections receives the next request.
  • IP hash — the client's IP address determines the server, giving session persistence.
  • Random and least response time strategies are also used.

Types

Load balancers may be dedicated hardware appliances, software (such as HAProxy or NGINX), or cloud services. They are commonly classified by the network layer at which they work: layer 4 (transport-level, based on IP and port) or layer 7 (application-level, able to route on URLs, cookies and headers). Global server load balancing distributes traffic between data centres in different geographic regions.
