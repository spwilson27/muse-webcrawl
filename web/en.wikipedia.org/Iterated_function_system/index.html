In mathematics, an iterated function system (IFS) is a method of constructing fractals. Formalised by John E. Hutchinson in 1981 and popularised by Michael Barnsley, an IFS consists of a finite set of contraction mappings on a complete metric space. The system defines a unique compact set — its attractor — which is typically self-similar and fractal, having non-integer Hausdorff dimension.

Definition

An iterated function system is a finite set of contraction mappings f1, ..., fN on a complete metric space X. Treating the union of the images of a set under all the maps as a single operator (the Hutchinson operator) on the space of compact subsets of X, equipped with the Hausdorff metric, yields a contraction on a complete metric space. By the Banach fixed-point theorem, this operator has a unique fixed point: a compact set A satisfying A = ∪ fi(A), and iterating the operator on any starting compact set converges to A.

Examples

Many classical fractals are IFS attractors. The Sierpinski triangle arises from three contractions mapping an equilateral triangle onto its three corner halves. The Koch curve, the Cantor set, and the Menger sponge admit similar constructions. The most famous example is Barnsley's fern: four affine maps with assigned probabilities reproduce the image of a black spleenwort fern leaf with remarkable fidelity.

The chaos game

A practical way to render an IFS attractor is the "chaos game": assign each map a probability, start from an arbitrary point, repeatedly apply a randomly chosen map, and plot the orbit. For affine IFSs the probabilities are usually chosen in proportion to the absolute values of the determinants of the maps' linear parts. The plotted points converge in distribution onto the attractor.

Applications

Fractal compression

Barnsley proposed using IFSs for image compression: find, for a given image, a set of contractive maps whose attractor approximates the image (the "collage theorem" bounds the approximation error). Fractal compression was commercialised by Iterated Systems in the late 1980s and 1990s, but it was computationally expensive to encode and was ultimately eclipsed by wavelet-based standards.

Flame fractals

IFS variants with non-linear variations and log-density colouring — "fractal flames", developed by Scott Draves — are widely used to generate fractal artwork.
