Salsa20

Salsa20 is a stream cipher designed for speed in software.

Salsa20 is a stream cipher developed in 2005 by Daniel J. Bernstein. It is built on a pseudorandom function based on add-rotate-XOR operations, applied to a 512-bit state consisting of a 256-bit key, a 64-bit nonce and a 64-bit counter. Salsa20 was submitted to the eSTREAM portfolio process and selected as a finalist for high-speed software ciphers.

Design

The core of Salsa20 applies twenty rounds of mixing to its input and adds the result to the original state to produce a 64-byte keystream block. The quarter-round function operates on four 32-bit words using modular addition, fixed rotations (by 7, 9, 13 and 18 bits) and XOR. Because it uses only simple operations available on all processors, Salsa20 is fast in software without special hardware support.

Variants

Reduced-round versions such as Salsa20/12 and Salsa20/8 offer greater speed with a smaller security margin. A later refinement, ChaCha, modified the permutation to improve diffusion and is now more widely deployed; variants of ChaCha are used in TLS, WireGuard and other protocols.

Security

No practical attack is known against the full 20-round Salsa20. The best public cryptanalysis reaches only the reduced-round versions with complexities far beyond practical reach, and the cipher remains regarded as secure when used with unique nonces.
