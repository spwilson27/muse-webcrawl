ICC profile

Type: Colour management data format
Introduced: 1993
Standard: ISO 15076-1
Extensions: .icc, .icm

An ICC profile is a set of data that characterises a colour input or output device, or a colour space, according to standards promulgated by the International Color Consortium (ICC). Profiles describe the colour attributes of a device by defining a mapping between the device source or target colour space and a profile connection space, typically CIE XYZ or CIELAB.

History and versions

The ICC was founded in 1993 by eight vendors, including Adobe, Apple, Kodak, and Microsoft, to create an open, cross-platform colour management standard. The specification became ISO 15076-1. Version 2 profiles use lookup tables or matrices with a fixed structure; version 4, published in 2001 and revised later, clarified rendering intents and is widely recommended. A newer framework, iccMAX (ISO 20677), extends profiles to spectral and multi-angle colour.

Use

Colour management systems use profiles in pairs: an image's embedded source profile (such as sRGB or Adobe RGB) is converted through the connection space to the output profile of a monitor or printer, applying a rendering intent — perceptual, relative colorimetric, absolute colorimetric, or saturation. Devices are profiled with colorimeters, spectrophotometers, and standard test targets.
