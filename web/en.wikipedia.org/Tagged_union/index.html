Tagged union

In computer science, a tagged union, also called a variant, choice type, discriminated union, or sum type, is a data structure used to hold a value that could take on several different, but fixed, types. Only one of the types can be in use at any one time, and a tag field explicitly indicates which one is in use. Tagged unions are a central feature of functional programming languages such as ML and Haskell, where they are called algebraic data types, and appear in modern systems languages such as Rust as enums.

A tagged union: the tag records which of the possible payload types is active

Concept

A tagged union can be thought of as a type that has several "cases", each carrying data of possibly different types. The tag makes the structure type-safe: programs must inspect the tag—typically through pattern matching—before accessing the payload, so the error of interpreting the data as the wrong type (possible with C's untagged unions) is prevented. Conceptually, tagged unions are the type-theoretic "sum", dual to the "product" of records or tuples.

Language support

Haskell and ML define algebraic data types with named constructors; Rust's enum types (such as Option and Result) are tagged unions; Swift, Kotlin (sealed classes), and Scala offer similar constructs. C++17 added std::variant to its standard library, and TypeScript supports discriminated unions through literal discriminant properties. Pattern matching over tagged unions lets compilers check exhaustiveness, warning when a case is unhandled.

Uses

Tagged unions are used to model optional values, success-or-error results, abstract syntax trees in compilers, messages in actor systems, and states in protocols and parsers—anywhere a value is one of a known set of alternatives.
