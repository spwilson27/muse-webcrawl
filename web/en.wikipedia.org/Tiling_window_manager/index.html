Tiling window manager

A tiling window manager is a window manager with an organization of the screen into mutually non-overlapping frames, as opposed to the more common approach of drawing windows on top of each other (stacking). Tiling window managers aim to use all available screen space efficiently, are usually driven heavily from the keyboard, and are popular with programmers and power users, especially on Linux and other Unix-like systems.

History

Early examples include the tiling systems of the Xerox Alto research environment and Microsoft Windows 1.0 (1985), which could only tile. On Unix, larswm (c. 2000) and Ion (2000) pioneered dynamic tiling, in which the layout is computed automatically as windows open and close. The approach was popularised by wmii, dwm (2006), xmonad (2007, written in Haskell), awesome, and i3 (2009), and later by Wayland compositors such as Sway.

Concepts

Windows occupy regions formed by recursively splitting the screen horizontally or vertically (as in a binary tree), or according to preset layouts: a large "master" area with a stack of secondary windows is common. Users navigate and resize with keybindings, organise windows into workspaces or tags, and configure behaviour through text files or scripts. Some tiling managers are "manual" (the user chooses where each split goes, as in i3) while others are "dynamic" (layouts are automatic, as in dwm).

Notable examples

dwm, i3, xmonad, awesome, bspwm, herbstluftwm, Qtile, Hyprland and Sway are among the most widely used. Mainstream desktop environments have also adopted limited tiling features, such as window snapping in Microsoft Windows and GNOME.
