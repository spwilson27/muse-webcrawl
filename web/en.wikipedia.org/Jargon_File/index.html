Jargon File

The Jargon File
Created1975, Stanford AI Lab
EditorsRaphael Finkel; later Eric S. Raymond
Published formThe New Hacker's Dictionary (1991)

The Jargon File is a glossary of hacker slang and computer-programmer subculture that originated at the Stanford Artificial Intelligence Laboratory in 1975, compiled by Raphael Finkel from slang used at Stanford and MIT. It circulated on the ARPANET, was printed as The Hacker's Dictionary in 1983, and was extensively revised by Eric S. Raymond as The New Hacker's Dictionary (1991).

Contents

The file documents terms such as "foo", "bar", "kludge", "mung", "cruft" and elaborate entries on hacker folklore, humour, and attitudes toward bureaucracy and bad software. Entries include pronunciation, etymology and usage notes, and the file doubles as an ethnography of the early programming community centred on MIT's Tech Model Railroad Club and AI Lab.

Influence

Many Jargon File terms entered mainstream computing vocabulary, and the file became a canonical record of hacker culture in the 1970s and 1980s. Raymond's editorial changes were sometimes controversial among earlier contributors.
