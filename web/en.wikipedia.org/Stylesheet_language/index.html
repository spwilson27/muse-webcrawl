Stylesheet language

A stylesheet language is a computer language used to describe the presentation of a document written in a markup language. The most widely used stylesheet language for the web is Cascading Style Sheets (CSS), which is used to style documents written in HTML and XML. By separating the presentation from the content, stylesheets allow the same underlying document to be rendered in different ways for different devices and media.

History

The concept of style sheets originated in publishing, where a style sheet recorded a publication's typographic and layout conventions. In computing, the idea was applied to structured documents in systems such as SGML; the DSSSL standard was developed for SGML documents, and its concepts influenced XSL for XML. For the early web, several proposals competed before CSS, published by Håkon Wium Lie in 1994 and standardised by the W3C from 1996, became dominant.

Other stylesheet languages

  • XSL (Extensible Stylesheet Language), including XSLT for transforming XML documents and XSL-FO for formatting them
  • Sass and Less — CSS preprocessor languages adding variables, nesting, and mixins, compiled to CSS
  • Cascading Style Sheets variants and extensions used in e-book formats such as EPUB

Principles

Stylesheet languages embody the separation of concerns between content and presentation: authors describe how elements should appear — fonts, colours, spacing, layout — while the document itself describes what the content is. Cascading and inheritance rules determine how multiple style rules combine.
