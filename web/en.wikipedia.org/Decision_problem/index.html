Decision problem


A Turing machine deciding a language

In computability theory and computational complexity theory, a decision problem is a problem that can be posed as a yes–no question of the input values. An example is the question "given two numbers x and y, does x evenly divide y?" Decision problems are central to theoretical computer science because many computational problems can be reformulated as decision problems.

Definition

A decision problem is a set of inputs for which the answer is "yes"; equivalently, it corresponds to a formal language of encoded inputs. A decision problem is decidable if there is an algorithm (a Turing machine) that halts with the correct yes-or-no answer on every input. The set of decidable problems is the class R (recursive languages).

Undecidability

Some decision problems are undecidable: no algorithm can answer them in general. The most famous example is the halting problem, proved undecidable by Alan Turing in 1936. Rice's theorem generalizes this: any nontrivial property of the language recognized by a Turing machine is undecidable.

Complexity

Among decidable problems, complexity theory classifies them by the resources required, giving classes such as P (solvable in polynomial time) and NP (whose "yes" answers can be verified in polynomial time). Whether P equals NP is a major open problem.
