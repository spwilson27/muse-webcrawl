Finite-state machine

A finite-state machine (FSM) is a mathematical model of computation consisting of a finite set of states, transitions between those states, and actions. At any time the machine is in exactly one state; input events trigger transitions according to defined rules. FSMs recognise regular languages and sit at the base of the Chomsky hierarchy.

Types

Machines may be deterministic (DFA) or nondeterministic (NFA) acceptors, or transducers that produce output, such as Mealy and Moore machines. Every NFA can be converted to an equivalent DFA, though possibly with exponentially more states.

Applications

FSMs are used in lexical analysis, protocol design, digital circuit design, game AI, vending-machine and elevator controllers, and regular-expression engines.
