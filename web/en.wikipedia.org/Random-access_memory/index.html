Random-access memory

Random-access memory (RAM) is a form of computer memory that can be read and changed in any order, typically used to store working data and machine code. "Random access" means any storage location can be reached in a constant time regardless of its position, in contrast to sequential media such as tape. Nearly all RAM is volatile: it loses its contents when power is removed. A RAM device lets data items be read or written in almost the same amount of time irrespective of the physical location of data inside the memory.

History

Early computers used delay lines, Williams tubes and magnetic-core memory; core memory, invented in the late 1940s, dominated until the 1970s. Semiconductor RAM followed the development of integrated circuits: Intel's 1103 (1970) was the first commercially successful DRAM chip, and by the mid-1970s dynamic RAM had displaced core in most new machines.

Types

The two main forms are dynamic RAM (DRAM), which stores each bit as charge in a capacitor and must be refreshed periodically, and static RAM (SRAM), which uses a flip-flop circuit, is faster and more expensive, and is used for caches. Modern computers use synchronous DRAM (SDRAM) in generations such as DDR4 and DDR5, supplied on DIMM modules. Other variants include video RAM, pseudo-static RAM and non-volatile RAM technologies such as FeRAM and MRAM.

Use

In a typical computer, the operating system and running programs reside in RAM while in use, because its speed — with access times measured in nanoseconds — is far greater than that of disks or flash storage, though RAM capacity is correspondingly smaller and costlier per bit. Virtual memory systems page data between RAM and secondary storage when physical memory is exhausted.
