List of NP-complete problems

This is a list of problems known to be NP-complete in computational complexity theory — problems to which every problem in NP can be reduced in polynomial time, and for which no polynomial-time algorithm is known.

Karp's 21 problems

Richard Karp's 1972 paper showed 21 problems NP-complete, including satisfiability (SAT), 0-1 integer programming, clique, set packing, vertex cover, Hamiltonian cycle, and travelling salesman (decision version).

Other well-known NP-complete problems

  • 3-SAT and Boolean satisfiability variants
  • Graph colouring, independent set, subgraph isomorphism
  • Knapsack, bin packing, subset sum
  • Tetris, Minesweeper consistency, Sudoku (generalised), Super Mario Bros. reachability and other game problems
  • Steiner tree, set cover, exact cover, feedback arc set
  • Longest path, rural postman, quadratic programming
