ICO (file format)

The ICO file format is an image file format for computer icons in Microsoft Windows. ICO files contain one or more small images at multiple sizes and colour depths, so that they may be scaled appropriately. In Windows, all executables that display an icon to the user, on the desktop, in the Start menu, or in Windows Explorer, must carry an icon in ICO format.

The format was introduced with Windows 1.0 in 1985. The related CUR file format serves the same purpose for mouse cursors and differs only in the interpretation of two fields in the header.

Structure

An ICO file begins with a header (the ICONDIR structure) giving the number of images contained in the file, followed by a directory entry for each image recording its width, height, colour count, bit depth and the offset of the image data. The image data itself may be stored as a BMP-format bitmap (in the variant used inside icons, with its height doubled to include the AND mask providing transparency) or, since Windows Vista, as a complete PNG image.

Historically, icons were limited to 32×32 pixels and a handful of colours. Successive Windows releases raised the limits: Windows XP added 32-bit colour with alpha-channel transparency, and Windows Vista supports icons up to 256×256 pixels, usually PNG-compressed.

Favicons

In 1999 Microsoft introduced the "favicon" for Internet Explorer 5: a small icon file named favicon.ico placed in a website's root directory and displayed next to the site's address and in bookmarks. The concept was later adopted by all major browsers, and favicons are now commonly supplied in ICO, PNG, GIF or SVG form.
