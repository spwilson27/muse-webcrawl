Multicast

In computer networking, multicast is group communication in which data transmission is addressed to a group of destination computers simultaneously. A single stream from the sender is replicated by the network only where paths to group members diverge, making multicast a one-to-many (or many-to-many) delivery model that sits between unicast (one-to-one) and broadcast (one-to-all).

IP multicast

IP multicast uses reserved group addresses — in IPv4, the Class D range 224.0.0.0 to 239.255.255.255 — and the Internet Group Management Protocol (IGMP) for IPv4 (MLD for IPv6) so hosts can join and leave groups. Routers build distribution trees using protocols such as Protocol Independent Multicast (PIM). Multicast is efficient for IPTV, streaming media, financial data feeds, videoconferencing and service discovery, although deployment across the public Internet remains limited, so it is most common inside managed and enterprise networks.

Comparison with other models

Compared with sending separate unicast copies, multicast greatly reduces sender and network load for popular content; compared with broadcast, it delivers only to interested hosts. The trade-offs are complexity in routing, congestion control and reliability, since IP multicast is normally built on unreliable UDP transport, with reliability added by higher-layer protocols where needed.
