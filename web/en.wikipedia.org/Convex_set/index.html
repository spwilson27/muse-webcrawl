Convex set

In geometry, a subset of a Euclidean space, or more generally an affine space over the reals, is convex if, given any two points in the subset, the subset contains the whole line segment joining them. Equivalently, a set S is convex if for all x and y in S and all t in [0, 1], the point (1 − t)x + ty also belongs to S. Examples of convex sets include line segments, discs, balls, half-spaces and the interior of any ellipse; the boundary of a disc, by contrast, is not convex, nor is a crescent shape.

Properties

The intersection of any collection of convex sets is convex; the empty set and the whole space are convex. The convex hull of an arbitrary set is the smallest convex set containing it. Under mild assumptions, convex sets admit separating hyperplanes: two disjoint nonempty convex sets can be separated by a hyperplane (the hyperplane separation theorem), a result fundamental to convex analysis and optimization duality. A convex set is star-shaped, hence contractible, and for closed convex sets the metric projection onto the set is well defined and unique in Hilbert spaces.

Generalizations

Convexity is defined in any real or complex vector space, and is preserved under affine maps. Important classes include convex cones, convex polytopes and absolutely convex sets. Convex sets underpin the theory of convex functions and convex optimization, where local minima are automatically global minima, as well as game theory and mathematical economics, where the convexity of preference and production sets facilitates equilibrium results.
