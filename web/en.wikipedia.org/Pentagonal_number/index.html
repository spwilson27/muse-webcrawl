Pentagonal number

A pentagonal number is a figurate number that extends the concept of triangular and square numbers to the pentagon. The n-th pentagonal number counts the number of dots in a pattern of nested pentagons sharing a common vertex, and is given by the formula

pn = n(3n − 1) / 2

The first few pentagonal numbers are 1, 5, 12, 22, 35, 51, 70, 92, 117, 145, …

Generalised pentagonal numbers

Allowing n to take the values 0, ±1, ±2, … gives the generalised pentagonal numbers: 0, 1, 2, 5, 7, 12, 15, 22, 26, … These play a famous role in Euler's pentagonal number theorem, which gives a recurrence for the partition function p(n) using the generalised pentagonal numbers, and appears in the expansion of the infinite product ∏(1 − xk).

Tests and properties

A positive integer x is a pentagonal number if and only if (24x + 1) is a perfect square and its square root is congruent to 5 modulo 6. Every pentagonal number is one third of a triangular number. The generating function and connections with theta functions make pentagonal numbers significant in number theory and combinatorics.
