Quotient set

In mathematics, a quotient set is the set of equivalence classes of a set under a given equivalence relation. If X is a set and ~ is an equivalence relation on X, the quotient set, written X/~, is the set of all equivalence classes [x] = { y in X : y ~ x }.

Definition and properties

The equivalence classes of an equivalence relation partition the underlying set: they are nonempty, pairwise disjoint, and their union is the whole set. The natural projection map sends each element to its class. Functions defined on a quotient set must be well-defined, i.e., independent of the representative chosen from each class.

Examples

The rational numbers can be constructed as a quotient of pairs of integers under the relation (a, b) ~ (c, d) when ad = bc. In modular arithmetic, the integers modulo n form the quotient set Z/nZ of the integers under congruence modulo n. Quotient structures generalizing this idea appear throughout algebra as quotient groups, quotient rings, and quotient spaces in topology and linear algebra.
