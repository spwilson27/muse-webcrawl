Proxy (statistics)

In statistics, a proxy or proxy variable is a variable that is not in itself directly relevant, but that serves in place of an unobservable or immeasurable variable or a variable that cannot be measured directly. In order for a variable to be a good proxy, it must have a close correlation, not necessarily linear, with the variable of interest.

Examples

Common examples include using per capita GDP as a proxy for standard of living or quality of life, using body mass index as a proxy for body fat percentage, and using the number of emergency room visits as a proxy for community health. In climate science, proxies such as tree rings, ice cores, and sediments stand in for direct temperature measurements before the instrumental record.

Limitations

Proxy variables introduce measurement error into statistical models, which can bias estimates: using an imperfect proxy for a confounder leaves residual confounding, and using a proxy for an explanatory variable typically attenuates its estimated effect. Analysts therefore prefer direct measurement where possible and test the sensitivity of results to proxy choice.
