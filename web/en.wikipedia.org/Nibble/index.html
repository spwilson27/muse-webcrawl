Nibble

In computing, a nibble (occasionally spelled nybble) is a unit of digital information equal to four bits, or half of a standard eight-bit byte. Because 2^4 = 16, a nibble can represent any of 16 values and corresponds exactly to one hexadecimal digit.

Usage

Nibbles appear wherever data is naturally handled in hexadecimal: each hex digit in an address, colour code or machine instruction is one nibble. Binary-coded decimal (BCD) stores one decimal digit per nibble, and some early microprocessors, such as calculator chips, used 4-bit architectures whose word size was the nibble. The high and low nibbles of a byte are sometimes manipulated separately in low-level programming and in file-format specifications such as image headers.

Name

"Nibble" is a playful respelling based on "bite" for "byte": a nibble is a small bite. The term has been in use since the 1970s, and the alternative spelling "nybble" mirrors the y in byte.
