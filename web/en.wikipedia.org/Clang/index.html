Clang is a compiler front end for the C, C++, Objective-C, and related programming languages, as well as the OpenMP, OpenCL, RenderScript, CUDA, and HIP frameworks. It acts as a drop-in replacement for the GNU Compiler Collection (GCC), and it is part of the LLVM project.

History

Development of Clang began at Apple Inc. in 2005, motivated by the desire for a compiler with clearer diagnostics, better integration with integrated development environments, and a more permissive license than GCC. It was released as open source as part of LLVM and first distributed publicly with Xcode.

Design

Clang is built as a set of reusable libraries with a library-based architecture, making it suitable for building tools such as code analyzers, refactoring tools, and syntax-aware editors. Its parser produces an abstract syntax tree, and its static analyzer can detect bugs in C, C++, and Objective-C programs. Clang is noted for expressive error messages and fast compilation speeds with low memory use.

Adoption

Clang is the default compiler for macOS, iOS, and several BSD operating systems, including FreeBSD. It is also widely used on Linux and Windows, and underpins many language tooling projects and the Rust compiler's bundled components in some configurations.
