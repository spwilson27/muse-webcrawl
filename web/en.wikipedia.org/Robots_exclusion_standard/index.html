Robots exclusion standard

The robots exclusion standard, also known as the robots exclusion protocol or simply robots.txt, is a convention used by websites to communicate with web crawlers and other automated agents about which parts of the site should not be accessed. It was proposed in 1994 by Martijn Koster and was standardised by the Internet Engineering Task Force as RFC 9309 in 2022.

How it works

A website places a plain text file named robots.txt at the root of the site. Before crawling, a well-behaved robot fetches this file and obeys its rules, which are written as groups of User-agent lines followed by Disallow and Allow path directives. A directive such as Disallow: /private/ tells all crawlers to avoid that directory. An entirely permissive file allows full crawling; a file disallowing / asks robots to stay away altogether.

Limitations

The standard is purely advisory: it is not a security mechanism, and malicious crawlers may ignore it. A robots.txt file is publicly readable and can itself reveal the location of sensitive directories. Extensions include the Sitemap directive and the Crawl-delay directive supported by some search engines. Related mechanisms include the noindex and nofollow meta tags and HTTP headers.

History

The protocol emerged in 1994 after early crawlers began overloading servers. It remained an informal convention for nearly three decades before formal standardisation, and it continues to be debated in the era of large-scale data collection for artificial intelligence training.
