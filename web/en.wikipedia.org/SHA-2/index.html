SHA-2

SHA-2 (Secure Hash Algorithm 2) is a set of cryptographic hash functions designed by the United States National Security Agency (NSA) and first published in 2001. They are built using the Merkle–Damgård construction, from a one-way compression function itself built using the Davies–Meyer structure from a specialized block cipher.

SHA-2 includes significant changes from its predecessor, SHA-1. The SHA-2 family consists of six hash functions with digests (hash values) that are 224, 256, 384 or 512 bits: SHA-224, SHA-256, SHA-384, SHA-512, SHA-512/224, SHA-512/256.

Hash function structure

The SHA-256 and SHA-512 algorithms differ mainly in word size: SHA-256 uses 32-bit words where SHA-512 uses 64-bit words. Truncated versions of each standard were also defined, with initial values generated using the phrase "SHA-512/224" and similar strings hashed with the corresponding function. The message is padded, split into blocks, and processed through rounds of bitwise operations, additions modulo 232 or 264, and message schedule expansion.

Applications

SHA-2 functions are widely used in security applications and protocols, including TLS, PGP, SSH, and cryptocurrencies such as Bitcoin, which uses SHA-256 in its mining process. As of 2024, no practical attacks have been publicly reported against the full SHA-2 algorithms comparable to the collision attacks that broke SHA-1.
