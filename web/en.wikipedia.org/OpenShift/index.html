OpenShift is a family of containerisation software products developed by Red Hat. Its flagship product is the OpenShift Container Platform, a hybrid cloud platform as a service built around Linux containers orchestrated and managed by Kubernetes, on a foundation of Red Hat Enterprise Linux CoreOS. The upstream open-source project is called OKD.

OpenShift builds on Kubernetes to provide a full application platform.

History

OpenShift was announced in May 2011, based on technology from Red Hat's 2010 acquisition of Makara. Early versions used their own container technology called "cartridges" and "gears". OpenShift 3, released in 2015, was rebuilt on Docker containers and Kubernetes. OpenShift 4 (2019) introduced operator-based management and an immutable CoreOS host.

Architecture and features

Beyond upstream Kubernetes, OpenShift adds a web console and command-line tooling, an integrated container image registry, source-to-image builds, CI/CD pipelines based on Tekton (OpenShift Pipelines), monitoring, and a catalogue of operators for installing and managing services. It enforces stricter default security policies than vanilla Kubernetes, such as running containers without root privileges.

Offerings

Red Hat offers OpenShift as a self-managed platform for on-premises and public cloud infrastructure, as dedicated managed services on AWS (Red Hat OpenShift Service on AWS, ROSA) and Microsoft Azure (Azure Red Hat OpenShift, ARO), and as a fully managed service on Red Hat's own cloud.
