"Hello, World!" program

Output of a typical "Hello, World!" program

A "Hello, World!" program is generally a simple computer program that outputs or displays the message "Hello, World!". Such a program is often the first written by people learning to code, and it is commonly used as a sanity test to make sure that a computer language is correctly installed and that the operator understands how to use it.

History

While small test programs have existed since the development of programmable computers, the tradition of using the phrase "Hello, World!" as a test message was influenced by an example program in the 1978 book The C Programming Language. The example program in that book prints hello, world, and was inherited from a 1974 Bell Laboratories internal memorandum by Brian Kernighan, Programming in C: A Tutorial. An earlier form appeared in Kernighan's 1972 tutorial for the B programming language.

Example

The canonical example in C:

#include <stdio.h>

int main(void)
{
    printf("hello, world\n");
    return 0;
}

Later languages require more or less scaffolding; in Python the entire program is simply print("Hello, World!").

Purpose and variations

"Hello, World!" programs are used to illustrate a language's basic syntax, verify that a compiler or interpreter and runtime environment are working, and give beginners a first success. Variations include programs that produce the text graphically, programs in esoteric languages such as Brainfuck, and the "JAPH" (Just another Perl hacker) tradition. The phrase has also spawned conventions such as "Hello, World!" collections that gather examples in hundreds of languages.
