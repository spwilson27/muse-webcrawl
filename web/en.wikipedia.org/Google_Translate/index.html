Google Translate

Owner: Google

Launched: April 28, 2006

Type: Machine translation

Google Translate is a multilingual neural machine translation service developed by Google to translate text, documents and websites from one language into another. It offers a website interface, a mobile app for Android and iOS, as well as an API that helps developers build browser extensions and software applications.

History

Google Translate was launched in April 2006 as a statistical machine translation service, initially using United Nations and European Parliament documents to gather linguistic data. In November 2016, Google transitioned its translating method to a neural machine translation engine, the Google Neural Machine Translation system (GNMT), which translates whole sentences at a time rather than piece by piece.

Features

The service supports more than 240 languages at various levels. Features include text, document, and website translation; handwriting and voice input; camera-based translation of text in images; offline translation packs; and conversation mode for spoken dialogue. Google reported in 2022 that Translate processed over 100 billion words daily.

Accuracy

Translation quality varies widely by language pair, being strongest for widely spoken languages with large training corpora and weaker for low-resource languages. Human evaluations have found neural translations substantially more fluent than the earlier statistical approach.
