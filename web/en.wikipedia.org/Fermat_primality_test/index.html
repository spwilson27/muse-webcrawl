Fermat primality test

The Fermat primality test is a probabilistic method for determining whether a number is prime. It is based on Fermat's little theorem, which states that if p is prime and a is not divisible by p, then ap−1 ≡ 1 (mod p). If a number n fails this congruence for some base a, then n is certainly composite; if it passes, n is probably prime.

Algorithm

Given an integer n > 1 to be tested, choose a random integer a with 1 < a < n and compute an−1 mod n using fast modular exponentiation. If the result is not 1, then n is composite (and a is called a Fermat witness). If the result is 1, repeat with other random bases to increase confidence; n is then a probable prime to base a.

Limitations: Fermat pseudoprimes and Carmichael numbers

Some composite numbers pass the test for particular bases: a composite n with an−1 ≡ 1 (mod n) is a Fermat pseudoprime to base a, the smallest example being 341 = 11 × 31 for base 2. Worse, Carmichael numbers — composite numbers such as 561 — pass the test for every base coprime to them, so no amount of testing with random bases can expose them except by luck of choosing a factor-sharing base. For this reason, the Fermat test is mainly of historical and pedagogical interest, and practical systems prefer the Miller–Rabin or Baillie–PSW tests, which have no such counterexamples of this kind.

Applications

Despite its flaw, the Fermat test illustrates the core idea behind modern probabilistic primality testing used in cryptography, where candidate primes for RSA key generation must be generated quickly. Faster deterministic variants and refinements of the same underlying idea remain in daily use.
