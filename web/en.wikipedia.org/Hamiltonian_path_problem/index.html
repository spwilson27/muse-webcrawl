Hamiltonian path problem

The Hamiltonian path problem is the computational problem of deciding, given a graph, whether a Hamiltonian path exists in it — a path visiting each vertex exactly once. The related Hamiltonian cycle problem asks for a cycle visiting each vertex exactly once. Both belong to computational complexity theory's canonical list of NP-complete problems; the cycle problem appeared in Karp's 21 NP-complete problems of 1972.

Complexity

The problems remain NP-complete for directed and undirected graphs, bipartite graphs, planar graphs, and grid graphs, among many restrictions. Because a proposed path can be checked in polynomial time, the decision problems lie in NP. The counting versions are #P-complete.

Algorithms

The fastest known exact algorithms run in exponential time: the Bellman–Held–Karp dynamic programming algorithm solves the problem in O(n²2ⁿ) time, and inclusion–exclusion methods give O(1.62ⁿ)-style bounds for some variants. Heuristic and approximation approaches are used in practice, since the optimisation version relates to the travelling salesman problem.

Reductions and applications

Hamiltonian path is frequently used as a starting point for NP-completeness reductions to covering, routing, and sequencing problems, and practical variants appear in network design, genome assembly, and puzzle solving.
