Expectation–maximization algorithm

In statistics, an expectation–maximization (EM) algorithm is an iterative method to find maximum likelihood or maximum a posteriori estimates of parameters in statistical models that depend on unobserved latent variables.

ClassOptimization algorithm
InventedFormalized by Dempster, Laird, and Rubin (1977)

Description

Each iteration consists of an expectation (E) step, which computes the expected value of the log-likelihood with respect to the conditional distribution of the latent variables given the observations and current parameter estimates, and a maximization (M) step, which finds the parameters maximizing that expected log-likelihood. The algorithm is guaranteed to increase the likelihood at each step and converges to a local optimum.

Applications

The EM algorithm is widely used for clustering with Gaussian mixture models, training hidden Markov models (where it coincides with the Baum–Welch algorithm), handling missing data, and in medical imaging and bioinformatics.

History

Special cases of the algorithm were described earlier in the 20th century, but the general theory was presented by Arthur Dempster, Nan Laird, and Donald Rubin in their classic 1977 paper.
