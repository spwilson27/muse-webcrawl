Suffix array

In computer science, a suffix array is a sorted array of all suffixes of a string. It is a data structure used in full-text indices, data-compression algorithms, and, when combined with additional data structures, can solve many string-processing problems efficiently.

Definition and example

For the string "banana$", the suffixes sorted lexicographically are "$", "a$", "ana$", "anana$", "banana$", "na$", and "nana$", giving the suffix array [6, 5, 3, 1, 0, 4, 2] of starting positions. The suffix array was introduced by Udi Manber and Gene Myers in 1990 as a space-efficient alternative to the suffix tree.

Applications

With binary search, a suffix array supports finding all occurrences of a pattern in time proportional to the pattern length times a logarithmic factor; augmenting it with the longest-common-prefix (LCP) array and range-minimum structures recovers most suffix-tree functionality. Suffix arrays underlie the Burrows–Wheeler transform used in bzip2 compression and in bioinformatics aligners such as Bowtie and BWA for read mapping against reference genomes, and they appear in the FM-index.

Construction

Naïve sorting of suffixes takes quadratic time; linear-time construction algorithms (such as SA-IS) and practical near-linear algorithms (such as the induced-sorting family) exist, and the array can be built from a suffix tree in linear time.
