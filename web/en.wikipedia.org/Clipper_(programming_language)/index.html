Clipper is a computer programming language for building business applications, originally created as a compiler for the dBase database language. It was first released in 1985 by Nantucket Corporation as Nantucket Clipper, marketed as a compiler for Ashton-Tate's dBase III applications that would make them run faster and protect their source code. Clipper grew beyond dBase into a complete general-purpose language and development system, and became one of the most widely used tools for DOS business software in the late 1980s and early 1990s.

Features

Clipper retained the dBase command syntax and DBF file format while adding structured programming constructs, user-defined functions, arrays, code blocks, and a preprocessor. The compiler produced native executable files with a linker, and an extensive ecosystem of third-party libraries added networking, indexing formats, and windowing support. Applications were character-based, typically running on DOS, often in multi-user configurations over local area networks using record and file locking.

History and decline

Nantucket was acquired by Computer Associates in 1992, which released CA-Clipper 5.3 and then Visual Objects, a Windows object-oriented successor. As Windows graphical applications displaced DOS software in the mid-1990s, Clipper use declined, but large numbers of legacy Clipper systems remained in service for decades, particularly in Latin America and Eastern Europe.

Successors

The open-source Harbour project and its predecessor xHarbour reimplemented Clipper as a cross-platform compiler, allowing legacy applications to be ported to Windows, Linux, and other systems. Other compatible implementations include XBase++ and FlagShip.
