Bernoulli distribution

In probability theory and statistics, the Bernoulli distribution, named after Swiss mathematician Jacob Bernoulli, is the discrete probability distribution of a random variable which takes the value 1 with probability p and the value 0 with probability q = 1 − p. Less formally, it can be thought of as a model for the set of possible outcomes of any single experiment that asks a yes–no question, such as a single coin flip.

Bernoulli distribution
Parameters0 ≤ p ≤ 1; q = 1 − p
Supportk ∈ {0, 1}
Meanp
Variancep(1 − p) = pq

Definition

It is the simplest possible non-degenerate distribution on two points. The probability mass function is:

f(k; p) = p if k = 1;   1 − p if k = 0

equivalently written f(k; p) = pk(1 − p)1−k for k ∈ {0, 1}.

Properties

The expected value of a Bernoulli random variable X is E[X] = p, and its variance is Var[X] = p(1 − p), which reaches its maximum value of 1/4 at p = 1/2. The Bernoulli distribution is a special case of the binomial distribution with n = 1, and also a member of the exponential family. The sum of independent Bernoulli random variables with the same parameter p follows a binomial distribution; sums with differing parameters follow the Poisson binomial distribution.

Applications

Bernoulli trials model a wide range of phenomena: coin flips, whether a voter supports a candidate, defect rates in manufacturing, and click-through in online experiments. In logistic regression, the response variable is assumed to follow a Bernoulli distribution whose probability depends on predictor variables.
