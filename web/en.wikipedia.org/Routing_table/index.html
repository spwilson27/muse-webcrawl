Routing table

In computer networking, a routing table (or routing information base, RIB) is a data table stored in a router or network host that lists the routes to particular network destinations and, in some cases, metrics associated with those routes. The information in the table guides the forwarding of packets: for each packet, the destination address is matched against the table and the packet is sent toward the listed next hop.

Contents of an entry

A typical routing-table entry contains:

  • Destination network — the IP network or prefix the entry applies to, with its subnet mask.
  • Next hop — the address of the next router on the path, or an indication that the destination is directly connected.
  • Output interface — the local network interface through which the packet should leave.
  • Metric — the cost of the route as computed by the routing protocol.
  • Source — how the route was learned (directly connected, static configuration, or a named dynamic protocol), together with its administrative distance.

Longest prefix match

Because several entries may match one destination, forwarding uses longest prefix match: the entry whose network mask is longest (most specific) wins. The least specific entry, the default route (0.0.0.0/0 for IPv4), matches everything and acts as the route of last resort.

RIB and FIB

The routing table proper (RIB) holds all candidate routes from every source. From it the router builds a forwarding information base (FIB) containing only the single best route per destination, optimised for fast lookup in the forwarding plane — implemented in software tries or in hardware content-addressable memory on high-end routers.

Managing the table

Entries arrive from directly connected interfaces, static configuration by an administrator, or dynamic routing protocols such as OSPF and BGP. On Unix-like systems the table can be inspected with commands such as ip route or netstat -r; the global Internet routing table carried by BGP contains approaching one million IPv4 prefixes.
