The Lempel–Ziv–Markov chain algorithm (LZMA) is an algorithm used to perform lossless data compression. It has been under development since 1996 or 1998 by Igor Pavlov and was first used in the 7z format of the 7-Zip archiver.

Overview

LZMA combines a large-window dictionary coder based on LZ77 with a sophisticated range encoder driven by a Markov-chain context model with many context bits. It generally achieves higher compression ratios than bzip2 or DEFLATE, at the cost of slower compression; decompression is comparatively fast.

Uses

Beyond 7-Zip, LZMA and its successor LZMA2 are used in the .xz file format (via XZ Utils), in software distribution on Linux, in some installer systems, and in embedded firmware images where its high ratio offsets slow encoding. The algorithm and reference implementations are in the public domain.

LZMA2

LZMA2 wraps LZMA chunks in a container that allows multithreaded compression and decompression and stores uncompressed chunks for incompressible data, avoiding expansion.
