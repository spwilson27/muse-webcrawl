Orbital elements

Keplerian elements
Defines: Size, shape and orientation of an orbit, and position along it
Number of elements: Six
Named for: Johannes Kepler

Orbital elements are the parameters required to uniquely identify a specific orbit. In celestial mechanics these elements are considered in two-body systems, where the orbit is a Keplerian conic section. The classical set of six Keplerian elements describes the size and shape of the orbit, the orientation of its plane in space, the orientation of the orbit within that plane, and the position of the body along the orbit at a given time (epoch).

The six elements

  • Semi-major axis (a): half the longest diameter of the orbital ellipse; sets the size and energy of the orbit.
  • Eccentricity (e): the shape of the ellipse, from 0 (circular) to less than 1 (elliptical).
  • Inclination (i): the tilt of the orbital plane relative to a reference plane.
  • Longitude of the ascending node (Ω): the angle from a reference direction to the ascending node, where the orbit crosses the reference plane northward.
  • Argument of periapsis (ω): the angle from the ascending node to the periapsis, measured in the orbital plane.
  • True anomaly (ν) at epoch, or equivalently mean anomaly: the position of the orbiting body along its path at the reference time.

Two-line elements

For artificial satellites, orbital elements are distributed as two-line element sets (TLEs), which encode mean elements derived from observations, together with drag terms, in a fixed two-line text format used for tracking and prediction.
