Fire class

A fire class is a categorisation of fires by the type of fuel involved, used to select appropriate extinguishing agents and equipment. Classification systems differ between regions: the European system uses classes A (solids), B (liquids), C (gases), D (metals) and F (cooking oils); the American system uses A, B, C (electrical), D and K (kitchen oils).

Extinguisher matching

Water suits class A but is dangerous on electrical or oil fires; foam and dry powder cover A and B; carbon dioxide is used for electrical fires; class D requires special dry powders; and wet-chemical extinguishers are designed for class F/K cooking-oil fires.

Marking

Fire extinguishers are labelled with the classes they are rated for, and fire ratings (e.g. 13A) indicate tested capacity. Using the wrong agent can spread a fire or cause electrocution.
