Ridge regression

From Wikipedia, the free encyclopedia

Ridge regression is a method of estimating the coefficients of multiple-regression models in scenarios where the independent variables are highly correlated (multicollinearity). It is a form of regularization: it adds a penalty proportional to the square of the magnitude of the coefficients (an L2 penalty) to the least-squares objective, producing estimates that are biased but have lower variance than ordinary least squares. The method was introduced by Arthur E. Hoerl and Robert W. Kennard in 1970.

Formulation

For a linear model y = Xβ + ε, the ridge estimator minimizes the residual sum of squares plus λ‖β‖², where λ ≥ 0 is a tuning parameter. Its closed-form solution is β̂ = (XTX + λI)−1XTy. Adding λI to the matrix before inversion guarantees the inverse exists even when XTX is singular, which is exactly the multicollinearity problem ridge regression addresses. As λ increases, the coefficients shrink toward zero but never reach it exactly.

Choosing the penalty

The parameter λ is commonly selected by cross-validation or generalized cross-validation. The ridge trace — a plot of the coefficients against λ — was Hoerl and Kennard's original diagnostic for picking a value at which the estimates stabilize. In Bayesian terms, ridge regression corresponds to maximum a posteriori estimation with a Gaussian prior on the coefficients.

Related methods

Ridge regression is the L2 counterpart of the lasso, which uses an L1 penalty and can set coefficients exactly to zero. The elastic net combines both penalties. In functional analysis and inverse problems the same idea is known as Tikhonov regularization.
