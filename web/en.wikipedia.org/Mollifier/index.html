Mollifier

Mollifier
FieldMathematical analysis, PDEs
Introduced byKurt Otto Friedrichs (1944)
PurposeSmoothing non-smooth functions

In mathematics, a mollifier is a smooth function with special properties used to create sequences of smooth functions approximating nonsmooth (generalized) functions, via convolution. Intuitively, given a function that is rather irregular, by convolving it with a mollifier the function is "mollified": its sharp features are smoothed while it remains close to the original nonsmooth function.

Mollifiers are also called Friedrichs mollifiers after Kurt Otto Friedrichs, who introduced them in 1944. A standard example is built from the bump function exp(−1/(1−|x|2)) for |x| < 1, rescaled to form an approximate identity.

Definition

A mollifier on ℝn is a function φ that is smooth (infinitely differentiable), supported in the unit ball, positive, and has integral 1. The scaled functions φε(x) = ε−nφ(x/ε) form an approximate identity: for any locally integrable f, the convolutions f * φε are smooth and converge to f in Lp (and uniformly on compact sets where f is continuous) as ε → 0.

Applications

Mollifiers are a basic tool in the theory of partial differential equations and distributions. They are used to prove that weak and strong derivatives agree when both exist, to prove density of smooth functions in Sobolev spaces, and to define convolutions of distributions. Sergei Sobolev had earlier used similar smoothing kernels in his work on partial differential equations.
