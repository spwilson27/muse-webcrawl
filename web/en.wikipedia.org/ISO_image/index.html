ISO image

An ISO image is a disk image of an optical disc, consisting of the complete contents of the disc stored in a single file, typically with the file extension .iso. ISO images are named after the ISO 9660 file system standard used on CD-ROM media, though modern images may contain UDF or other file systems.

Uses

ISO images are widely used to distribute operating system installers — most Linux distributions and Microsoft Windows installation media are published as ISO files — as well as for archiving and emulation. An ISO image can be "mounted" by an operating system so that its contents appear as a virtual drive, or written to a physical disc or USB flash drive ("burning") to create bootable media.

Contents and creation

An ISO image contains a sector-by-sector copy of the disc's data, including the file system structure, but generally lacks the subchannel data, error-correction overhead, and copy-protection information of the original disc. Utilities for creating and manipulating ISO images include dd, mkisofs/genisoimage, and various commercial tools.
