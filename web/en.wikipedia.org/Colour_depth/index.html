Colour depth

Colour depth or bit depth is the number of bits used to indicate the colour of a single pixel in a bitmapped image or video frame buffer, or the number of bits used for each colour component of a single pixel.

Common depths

1-bit gives monochrome; 8-bit indexed colour (256 colours via a palette) was common in early systems and GIF images. 24-bit true colour uses 8 bits per RGB channel, giving about 16.7 million colours. 30/36/48-bit deep colour reduces banding and is used in professional imaging and HDR workflows.

Alpha and channels

An additional alpha channel stores transparency; 32-bit colour usually means 24-bit colour plus 8-bit alpha. Higher bit depths increase memory and bandwidth but improve gradient smoothness and editing headroom.

History

Early home computers offered few colours; VGA, then high colour (16-bit), then true colour became standard in the 1990s. Modern displays and formats such as HEIF and AVIF support 10-bit per channel.
