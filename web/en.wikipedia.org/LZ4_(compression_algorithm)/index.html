LZ4 (compression algorithm)

LZ4 is a lossless data compression algorithm and format that emphasises extremely fast compression and decompression speeds. It was created by Yann Collet and is implemented in a reference C library under a BSD licence.

Design

LZ4 belongs to the LZ77 family: it represents repeated sequences as length–offset matches. Its simplicity allows decompression at multiple gigabytes per second per core, making it popular in filesystems, databases and real-time systems where speed matters more than maximum ratio.

Variants and use

LZ4_HC offers higher compression at slower speed. LZ4 is used in systems including ZFS, the Linux kernel, Hadoop and many games and embedded systems.
