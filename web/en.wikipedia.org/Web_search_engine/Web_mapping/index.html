Web mapping

Web mapping delivers interactive maps through the browser, often integrated with search results.

Web mapping is the process of designing, implementing, generating, and delivering maps on the World Wide Web. It combines cartography with web technology and geographic information systems (GIS), allowing maps to be distributed widely and updated continuously.

Web mapping gained prominence because maps are a natural complement to search: a large share of web searches have local intent, and search engines embed interactive map results for businesses, directions, and places. Providers such as Google Maps, Bing Maps, and OpenStreetMap-based services render map tiles on demand and geocode search queries into map positions.

Technology

Most web maps use a tiled pyramid of pre-rendered or vector tiles in the Web Mercator projection, fetched as the user pans and zooms. Standards from the Open Geospatial Consortium (WMS, WMTS, WFS) define how map images and features are requested. Client libraries such as Leaflet and MapLibre GL assemble tiles, markers, and overlays in the browser.

Development

From the Xerox PARC Map Viewer (1993) and MapQuest (1996) to Google Maps (2005), web mapping evolved from static images to fully interactive applications with routing, street-level imagery, live traffic, and user-contributed edits. Mashups combining map platforms with external data popularized the field after 2005.
