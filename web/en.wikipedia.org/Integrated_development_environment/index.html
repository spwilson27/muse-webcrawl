Integrated development environment

An integrated development environment (IDE) is a software application that provides comprehensive facilities for software development. An IDE normally consists of at least a source-code editor, build automation tools, and a debugger. Some IDEs, such as IntelliJ IDEA and Eclipse, contain the necessary compiler, interpreter, or both; others, such as SharpDevelop and Lazarus, do not.

Features

  • Source code editor with syntax highlighting, code completion, and refactoring support.
  • Build automation — compiling and linking, often integrated with build tools and test runners.
  • Debugger with breakpoints, watches, and step execution.
  • Version control integration, class browsers, and object inspectors.
  • Language support, sometimes for a single language, sometimes extensible through plug-ins.

History

One of the first environments with a plug-in concept was Softlab's Maestro I (1975). Early IDEs became popular with Borland's Turbo Pascal (1983), which combined editor, compiler and runtime in a single fast program. Microsoft's Visual Basic (1991) and Visual Studio (1997) popularized visual RAD-style development; Eclipse and the JetBrains family became dominant in the 2000s. Modern lightweight editors such as Visual Studio Code blur the line between text editor and IDE, and cloud IDEs run entirely in a web browser.

Examples

Widely used IDEs include Microsoft Visual Studio, IntelliJ IDEA, Eclipse, Xcode, Android Studio, PyCharm, NetBeans and CLion, alongside configurable editors such as Visual Studio Code, Emacs and Vim.
