PostScript fonts

PostScript fonts are font files encoded in outline font specifications developed by Adobe Systems for professional digital typesetting. They use PostScript — a page description language and programming language — to describe glyph outlines with cubic Bézier curves, and were central to the desktop publishing revolution of the 1980s.

Type 1 and Type 3

Type 1 fonts are hinted, compressed and (originally) encrypted outline fonts; a font consists of an outline file plus a metrics file (AFM, and on classic Mac OS a bitmap screen font). Type 3 fonts are unhinted PostScript programs that can include fills and images but render more slowly. Adobe's introduction of Type 1 with the Apple LaserWriter and its core font set (Times, Helvetica, Courier and others) set the professional standard.

Multiple Master and successors

Multiple Master fonts allowed interpolation across design axes such as weight and width. Adobe later co-developed OpenType with Microsoft, and Adobe converted its type library to OpenType, phasing out Type 1 support; Adobe applications ended Type 1 support in the early 2020s, and the format is now considered legacy.
