Snake case

Snake case (or pothole case) is the naming convention in which the words in a compound word or phrase are separated by a single underscore character (_) and written in lowercase, with no spaces: for example, the_quick_brown_fox. It is commonly used in computing, particularly in variable, function, and file names in languages such as Python, Ruby, and C.

Snake case identifiers in a code editor

Usage

Snake case is the recommended convention for variable and function names in Python under the PEP 8 style guide, is idiomatic in Ruby and Rust, and is standard for file names in many Unix environments where spaces are inconvenient. Uppercase variants such as MAX_BUFFER_SIZE ("screaming snake case" or macro case) are widely used for constants and C preprocessor macros.

Comparison with other conventions

Related naming conventions include camelCase, in which word boundaries are marked by capital letters; PascalCase, in which the first letter is also capitalized; and kebab-case, which uses hyphens instead of underscores. Studies of identifier readability have compared the styles, finding that underscore-separated names can be recognized somewhat more accurately by readers, particularly non-native speakers, at the cost of longer names.

History

The convention dates to the earliest high-level programming languages; it was common in C code of the 1970s. The term "snake case" itself gained currency in the 2000s through contrast with camel case, as style guides for dynamically typed languages formalized their naming rules.
