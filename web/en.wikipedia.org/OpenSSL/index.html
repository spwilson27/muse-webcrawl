OpenSSL

OpenSSL is a software library for applications that provide secure communications over computer networks against eavesdropping, and to identify the party at the other end. It is widely used by Internet servers, including the majority of HTTPS websites.

OpenSSL contains an open-source implementation of the SSL and TLS cryptographic protocols, written primarily in C, together with a general-purpose cryptography library (libcrypto) and a command-line tool for creating and managing certificates. It began as a fork of SSLeay in 1998 and is released under the Apache License 2.0 since version 3.0 (2021).

Security incidents

In April 2014 the Heartbleed vulnerability (CVE-2014-0160), a buffer over-read in the TLS heartbeat extension, exposed private keys and memory of a large fraction of web servers and led to major funding and audit reforms, the Core Infrastructure Initiative, and forks such as LibreSSL and BoringSSL.
