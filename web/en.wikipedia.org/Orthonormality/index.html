Orthonormality

In linear algebra, two vectors in an inner product space are orthonormal if they are orthogonal (their inner product is zero) and each has unit length (norm one). A set of vectors is orthonormal if every pair is orthonormal.

Properties

An orthonormal set is always linearly independent. A basis that is orthonormal greatly simplifies computation: coordinates of a vector are given by inner products with the basis vectors, and the matrix with orthonormal columns satisfies QTQ = I, so its inverse equals its transpose.

Construction

The Gram–Schmidt process converts any linearly independent set into an orthonormal set spanning the same subspace; its numerical refinement underlies the QR decomposition. Examples include the standard basis of Rn and the Fourier basis of square-integrable functions.
