Symmetric matrix

In linear algebra, a symmetric matrix is a square matrix that is equal to its transpose: A = AT. Equivalently, a matrix is symmetric when its entries satisfy aij = aji for all indices i and j, so the matrix is symmetric across its main diagonal. Only square matrices can be symmetric.

The entries of a symmetric matrix are symmetric with respect to the main diagonal. If the entries are written as A = (aij), then aij = aji for all i and j. For example, the following 3×3 matrix is symmetric:

[ 1  7  3 ; 7  4  −5 ; 3  −5  6 ]

Properties

Every square diagonal matrix is symmetric, since all off-diagonal entries are zero. Similarly in characteristic different from 2, each diagonal element of a skew-symmetric matrix must be zero, since each is its own negative. The sum and difference of two symmetric matrices is symmetric, and the product of two symmetric matrices is symmetric only if the two matrices commute. Every square matrix can be written as the sum of a symmetric and a skew-symmetric matrix.

For any symmetric matrix A with real entries, the following properties hold:

  • All eigenvalues of A are real.
  • Eigenvectors corresponding to distinct eigenvalues are orthogonal.
  • A is diagonalizable by an orthogonal matrix: there exists a real orthogonal matrix Q such that QTAQ is diagonal. This is the spectral theorem for symmetric matrices.
  • A is diagonalizable in the usual sense, and its geometric multiplicities equal its algebraic multiplicities.

Decomposition

Using the Jordan normal form, one can show that every square real matrix can be written as a product of two real symmetric matrices, and every square complex matrix can be written as a product of two complex symmetric matrices. By the spectral theorem, every symmetric matrix with real entries is orthogonally diagonalizable, and the diagonal entries are its eigenvalues. A symmetric matrix is positive-definite if and only if all of its eigenvalues are positive.

Hessian

Symmetric matrices arise naturally wherever a bilinear or quadratic form is involved. The Hessian matrix of second partial derivatives of a smooth function is symmetric by the equality of mixed partials, and quadratic forms in n variables correspond one-to-one with symmetric n×n matrices.
