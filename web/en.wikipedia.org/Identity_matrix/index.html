Identity matrix

In linear algebra, the identity matrix of size n is the n × n square matrix with ones on the main diagonal and zeros elsewhere. It is denoted In, or simply I. It is the multiplicative identity for matrix multiplication: for any n × n matrix A, IA = AI = A.

Properties

The identity matrix is diagonal, symmetric, orthogonal, and its own inverse. Its determinant is 1, its trace is n, and all its eigenvalues are 1. It represents the identity linear transformation on an n-dimensional vector space.

Notation

Using the Kronecker delta, its entries are Iij = δij. In some fields the unit matrix is written E or U.

Uses

Identity matrices appear in defining inverse matrices, orthogonal matrices, and matrix groups, and as the starting point of algorithms such as Gauss–Jordan elimination.
