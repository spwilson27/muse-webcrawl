Classless Inter-Domain Routing

Classless Inter-Domain Routing (CIDR) is a method for allocating IP addresses and for IP routing. The Internet Engineering Task Force introduced CIDR in 1993 to replace the previous classful network addressing architecture on the Internet. Its goal was to slow the growth of routing tables on routers across the Internet, and to decrease the rapid exhaustion of IPv4 addresses.

Background

Every IP address consists of two parts: the network identifier and the host identifier. Under the classful system, addresses were divided into classes A, B and C, with fixed network-prefix lengths of 8, 16 or 24 bits. This coarse granularity wasted many addresses: an organisation needing slightly more than 254 hosts had to request a class B network with over 65,000 addresses. CIDR replaced fixed classes with prefixes of arbitrary length, a scheme known as variable-length subnet masking (VLSM) applied at the level of the whole Internet.

CIDR notation

CIDR notation is a compact representation of an IP address and its associated network mask. It is written as the address followed by a slash and a decimal number giving the count of leading 1-bits in the subnet mask. For example, 192.168.100.14/24 represents the address 192.168.100.14 with the mask 255.255.255.0, so the first 24 bits identify the network and the remaining 8 bits identify hosts. The network address 198.51.100.0/22 describes a block of 1,024 addresses.

Aggregation

Because prefixes can be any length, adjacent networks sharing a common prefix can be summarised into a single routing entry, a technique called supernetting or route aggregation. This substantially reduced the size of the global BGP routing table and remains one of CIDR's most important benefits.

IPv6

CIDR concepts carry over directly to IPv6, where the notation is identical in form; a typical end-user allocation is a /48 or /56 prefix, and a single LAN segment is almost always a /64.
