Firmware

Firmware is software that provides low-level control of a device's hardware. It is typically stored in non-volatile memory such as ROM, EPROM, EEPROM, or flash memory, and supplies the basic instructions that let hardware communicate with other software.

TypeSoftware embedded in hardware
StorageROM, EEPROM, flash memory

Overview

Examples of devices containing firmware include personal computers (where the BIOS or UEFI is firmware), routers, printers, digital cameras, smartphones, automotive systems, and household appliances. Historically firmware was fixed at manufacture, but modern devices commonly support firmware updates to fix bugs, patch security vulnerabilities, or add features.

History

The term was coined in 1967 by Ascher Opler for a microprogram stored in a computer's control store. As storage became cheaper, firmware increasingly took the form of ordinary programs stored like data, blurring the line between firmware and software.

Security

Because firmware runs below the operating system, compromised firmware is difficult to detect and remove, making it a target for persistent attacks and a focus of supply-chain security practices.
