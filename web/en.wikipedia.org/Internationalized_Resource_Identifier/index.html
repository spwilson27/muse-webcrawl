Internationalized Resource Identifier

An Internationalized Resource Identifier (IRI) is a generalisation of the Uniform Resource Identifier (URI) that allows characters from the Universal Character Set (Unicode/ISO 10646), including Chinese, Japanese, Korean and Cyrillic scripts, to appear in resource identifiers. IRIs are defined by RFC 3987, published by the Internet Engineering Task Force in 2005.

Relation to URIs and URLs

Every URI is also an IRI, but IRIs may contain characters outside the limited ASCII subset permitted in URIs. Any IRI can be converted to an equivalent URI by encoding the non-ASCII characters using UTF-8 and then percent-encoding the resulting bytes. The reverse mapping is possible when percent-encoded sequences correspond to valid UTF-8.

IRIs are used in technologies including XML, RDF, and internationalized domain names, allowing addresses and identifiers to be written in the user's own script rather than transliterated into Latin characters. Web browsers typically display IRIs in their native characters while transmitting the encoded URI form.

History

The concept was first proposed in the 1990s as the Web's use spread beyond English-speaking countries. Martin Dürst drafted the initial specification, and RFC 3987 was published in January 2005. The WHATWG URL standard and later language specifications such as XML Schema and SPARQL incorporate IRI handling.
