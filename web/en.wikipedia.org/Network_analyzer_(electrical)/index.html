Network analyzer (electrical)

A network analyzer is an instrument that measures the network parameters of electrical networks. Today, network analyzers commonly measure scattering parameters (s-parameters), because reflection and transmission of electrical networks are easy to measure at high frequencies, but there are other network parameter sets such as y-parameters, z-parameters, and h-parameters.

Types

There are two main types of network analyzer. A scalar network analyzer (SNA) measures amplitude properties only, while a vector network analyzer (VNA) measures both amplitude and phase properties. VNAs are by far the more common type and are widely used in the design and manufacture of radio frequency (RF) and microwave components.

Operation

A network analyzer applies a swept signal to a device under test and measures the signals reflected from and transmitted through it. From these measurements it derives quantities such as return loss, insertion loss, gain, and voltage standing wave ratio (VSWR), typically displayed on a Smith chart or as logarithmic magnitude plots.

Calibration

Accurate measurements require calibration using known standards, commonly an open, a short, a matched load and a through connection (SOLT calibration), to remove the systematic errors of the instrument and cables.
