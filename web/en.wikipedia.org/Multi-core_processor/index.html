Multi-core processor


Type: Microprocessor architecture
Components: Two or more CPU cores on one die
First commercial examples: Early 2000s (IBM POWER4, 2001)

A multi-core processor is a microprocessor on a single integrated circuit (or chip package) with two or more separate processing units, called cores, each of which reads and executes program instructions. The cores share interfaces to memory and I/O and typically run at the same clock frequency.

History

The industry shifted to multi-core designs in the early 2000s when rising clock speeds in single-core processors hit power and heat limits — the so-called power wall. IBM's POWER4 (2001) was an early dual-core server chip; mainstream desktop dual-core processors followed in 2005 with AMD's Athlon 64 X2 and Intel's Pentium D, and core counts grew steadily thereafter, reaching dozens of cores in server chips and heterogeneous designs in mobile devices.

Performance considerations

Multiple cores improve throughput on parallel workloads but do not automatically speed up single-threaded tasks. Amdahl's law limits the gains from parallelizing only part of a program, and software must be written with threads or multiple processes to benefit. Hardware features such as shared caches, interconnects, and simultaneous multithreading (hyper-threading) influence real-world performance.

Variants

Homogeneous processors have identical cores; heterogeneous designs (such as ARM big.LITTLE and its successors) mix high-performance and high-efficiency cores. Many-core processors, with dozens to hundreds of simpler cores, blur into GPU-style architectures.
