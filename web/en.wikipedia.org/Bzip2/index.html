bzip2 is a free and open-source file compression program developed by Julian Seward that uses the Burrows–Wheeler algorithm. It typically compresses files to within 10–15% of the best available techniques such as PPM, though at slower speeds than algorithms like DEFLATE (gzip). It compresses only single files, not archives; multi-file archives are usually created by combining it with tar (.tar.bz2).

Compression pipeline

bzip2 processes data in blocks of 100–900 kB. Each block passes through run-length encoding, the Burrows–Wheeler transform (which groups similar characters together), a move-to-front transform, a second run-length encoding stage, and finally Huffman coding. The resulting format includes CRC checksums for each block, allowing damaged archives to be partially recovered with bzip2recover.

History

Seward released the first version in 1996; version 1.0 followed in 2000. bzip2 became a staple of Unix and Linux systems and was widely used for distributing source code and software packages. Long-standing maintenance passed from Seward to the Sourceware project in 2019. Newer formats such as xz and zstd generally offer better speed–ratio trade-offs, but bzip2 remains ubiquitous.
