Caret notation

Caret notation is a notation for control characters in ASCII encoding. The notation consists of a caret (^) followed by a capital letter; this digraph stands for the ASCII code point with the same value as the letter's position minus 64. For example, the carriage return character (value 13) is written ^M, and null (value 0) as ^@.

Use

The notation is used by many Unix terminal programs to display control characters: ^C for interrupt (ETX), ^D for end-of-file (EOT), ^I for tab and ^[ for escape. The delete character (127) is conventionally written ^?. It derives from the extra row of symbols available on early Teletype keyboards.
