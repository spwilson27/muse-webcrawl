Monte Carlo tree search

Monte Carlo tree search (MCTS) is a heuristic search algorithm for decision processes, most notably employed in software that plays board games. It combines the generality of random simulation with the precision of tree search, building a game tree incrementally and asymmetrically in favour of promising moves.

ClassSearch algorithm
PhasesSelection, expansion, simulation, backpropagation
Notable useAlphaGo, game-playing programs

Method

Each iteration of MCTS performs four steps. In selection, the algorithm descends the existing tree choosing child nodes by a policy such as UCT (upper confidence bounds applied to trees). In expansion, one or more new nodes are added. In simulation, a playout is run from the new node, often with random or lightly guided moves. In backpropagation, the result is propagated back up the tree, updating visit counts and value estimates.

History

The method gained prominence after 2006, when it revolutionised computer Go; programs such as Crazy Stone and MoGo used MCTS with UCT to reach strong amateur dan levels. In 2016, DeepMind's AlphaGo combined Monte Carlo tree search with deep neural networks to defeat world-class human Go players.

Advantages and disadvantages

MCTS requires no handcrafted evaluation function beyond the rules of the game, and it can be stopped at any time to return the currently best move. Its weakness is that it may overlook deep tactical traps if simulations rarely reach them.
