Class field theory

Class field theory is a major branch of algebraic number theory that describes abelian extensions of local and global fields using arithmetic data of the base field. Its central result asserts a correspondence — the reciprocity map — between abelian extensions of a number field and open subgroups of its idèle class group.

Overview

Class field theory grew out of 19th-century reciprocity laws (quadratic, cubic and biquadratic reciprocity) and the work of Kronecker, Weber, Hilbert, Takagi, Artin, Chevalley and others in the first half of the 20th century. Teiji Takagi proved the existence theorem in 1920, and Emil Artin established the reciprocity law in 1927.

Main statements

Local class field theory describes abelian extensions of a local field (such as the p-adic numbers) via its multiplicative group. Global class field theory gives a bijection between finite abelian extensions of a global field and open subgroups of finite index in the idèle class group, with the norm group of an extension corresponding to the extension itself. The Hilbert class field — the maximal unramified abelian extension — is a special case.

Generalisations

Class field theory is the abelian prototype of the Langlands programme, which seeks non-abelian generalisations relating Galois representations and automorphic forms.
