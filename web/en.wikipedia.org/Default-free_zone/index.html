Default-free zone

In the context of Internet routing with the Border Gateway Protocol (BGP), the default-free zone (DFZ) is the set of autonomous systems that do not require a default route in order to reach any destination on the Internet. Routers in the DFZ carry a complete routing table — a full view of all prefixes announced globally — rather than pointing unknown traffic at an upstream provider.

Size and growth

The global routing table has grown steadily with the expansion of the Internet and the fragmentation of address space. The IPv4 table passed 512,000 entries in 2014 — an event that caused failures in older routers with limited ternary content-addressable memory (TCAM), sometimes called "512k day" — and reached roughly 900,000 to 1,000,000 IPv4 prefixes in the mid-2020s, in addition to a growing IPv6 table of well over 100,000 prefixes. Moore's-law growth in router hardware has largely kept pace, but the size of the DFZ table is a standing concern for network operators and a subject of measurement projects such as CIDR Report.

Characteristics

Autonomous systems in the DFZ are typically large transit providers and other networks that peer extensively. Membership is conceptually defined by behaviour — carrying the full table without a default route — rather than by any formal registration. Aggregation of routes (summarisation) reduces table growth, while multi-homing, traffic engineering, and address fragmentation increase it.
