Vulkan

Vulkan is a low-level, cross-platform graphics and compute application programming interface (API) first released by the Khronos Group in February 2016. It is intended to give developers more direct control over the GPU than older APIs such as OpenGL and Direct3D 11, enabling higher performance and more predictable behaviour, at the cost of substantially greater complexity and programmer effort.

Design

Vulkan removes much of the driver state management found in OpenGL: the application is responsible for memory allocation, synchronisation, command buffer recording and resource state transitions. Rendering work is recorded into command buffers that can be built in parallel on multiple CPU threads and submitted to queues, reducing driver overhead and enabling efficient multithreading. Shaders are normally pre-compiled to the SPIR-V intermediate representation. Because the API is explicit, features in the core specification are complemented by a large ecosystem of extensions exposing hardware capabilities.

History

Khronos began the project in 2014, building partly on technology AMD donated from its Mantle API. Vulkan 1.0 shipped in February 2016 with support from major GPU vendors. Vulkan 1.1 (2018) added subgroup operations and protected content; 1.2 (2020) consolidated many extensions; 1.3 (2022) made widely used extensions core and introduced dynamic rendering; Vulkan 1.4 was released in December 2024. Apple platforms do not support Vulkan natively, but the MoltenVK layer translates Vulkan calls to Apple's Metal API.

Adoption

Vulkan is the primary 3D API on Android and is used by game engines such as Unity, Unreal Engine and id Tech 7, by emulators, and by the Proton compatibility layer that runs Windows games on Linux. Its explicit design also suits scientific and machine-learning compute workloads through its compute queues.
