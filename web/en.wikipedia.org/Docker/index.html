Docker

Docker is a set of platform as a service (PaaS) products that use OS-level virtualization to deliver software in packages called containers. The service has both free and premium tiers; the software that hosts the containers is called Docker Engine.

Functionality

Containers are isolated from one another and bundle their own software, libraries, and configuration files; they can communicate with each other through well-defined channels. Because all containers share the services of a single operating system kernel, they use fewer resources than virtual machines, which each run a guest operating system.

History

Docker was released as open source in March 2013 by dotCloud, a platform-as-a-service company founded by Solomon Hykes. It builds on Linux kernel features including cgroups and namespaces, and the union filesystem concepts used to layer container images. Docker popularized the modern container format and ecosystem, and its image format became a de facto standard later adopted by the Open Container Initiative.

Components

The Docker software suite includes the Docker daemon (dockerd), the command-line client, Docker Compose for multi-container applications, Docker Hub as a public image registry, and Docker Desktop for macOS and Windows.
