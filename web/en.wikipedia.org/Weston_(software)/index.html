Weston is the reference implementation of a Wayland compositor, a display server protocol for Linux and other Unix-like systems. Developed as part of the Wayland project hosted on freedesktop.org, Weston demonstrates the Wayland protocol and provides a minimal, functional desktop shell, serving as a testbed and a model for developers writing their own compositors.

Weston is built on libweston, a library that implements the core compositing logic — input handling, output management, rendering with OpenGL ES or the Pixman software renderer, and the DRM/KMS, X11 and nested Wayland backends. Since version 3 (2017), libweston has been a public library used by embedded and automotive systems to build custom compositors.

Features

Weston supports features including animated window transitions, the XWayland compatibility layer for running legacy X11 applications, remote desktop streaming via RDP and PipeWire, high-DPI scaling, and colour management work in later releases. Although fully functional, Weston is intentionally lightweight and is used mostly in embedded devices, kiosks, automotive infotainment and developer testing rather than general desktop use, where environments such as GNOME's Mutter and KDE's KWin act as their own compositors.
