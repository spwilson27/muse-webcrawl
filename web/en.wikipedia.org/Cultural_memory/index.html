Cultural memory

Cultural memory is a concept in cultural studies and memory studies referring to the shared pool of knowledge, narratives, symbols, and practices through which a society remembers its past and constructs its collective identity. It is transmitted through texts, images, monuments, rituals, and institutions across generations.

Cultural memory
Key scholars: Jan Assmann, Aleida Assmann, Maurice Halbwachs
Field: Memory studies
Related: Collective memory, oral tradition

Origins

The concept builds on Maurice Halbwachs's work on collective memory in the 1920s. German Egyptologist Jan Assmann developed cultural memory in the 1980s and 1990s, distinguishing it from communicative memory — the everyday, informal memory that spans roughly three to four generations — by its formal, institutionalised, and often ceremonial character reaching back to foundational events.

Forms and media

Cultural memory is stored in canonical texts, archives, museums, memorials, festivals, and commemorative rituals. Such media stabilise a group's self-image and convey normative values. Aleida Assmann distinguished between the actively circulated "canon" and the passively stored "archive" of cultural memory.

Significance

The concept is used to analyse national identity, trauma, heritage, and how societies negotiate contested pasts, including colonialism, war, and genocide.
