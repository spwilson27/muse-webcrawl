Type II string theory

Type II string theory
Variants: Type IIA, Type IIB
Spacetime dimensions: 10
Supersymmetry: N = 2

Type II string theory is a class of superstring theories with two variants, type IIA and type IIB, both formulated in ten spacetime dimensions with N = 2 supersymmetry and containing only closed strings. The two differ in the chirality of their fermions and spectra.

Type IIA and IIB

Type IIA is non-chiral, with fermions of both chiralities; its massless spectrum includes a 1-form and 3-form Ramond–Ramond potential, and it is related by strong-coupling limits to eleven-dimensional M-theory. Type IIB is chiral, contains a self-dual 5-form, and is invariant under an S-duality exchanging weak and strong coupling. Both are related by T-duality upon compactification.

Applications

Type II theories host the D-branes on which much of modern string phenomenology rests, and type IIB backgrounds underlie the best-developed examples of the AdS/CFT correspondence.
