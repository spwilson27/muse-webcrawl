Edge coloring

From Wikipedia, the free encyclopedia

In graph theory, a field of mathematics, an edge coloring of a graph is an assignment of "colors" to the edges of the graph so that no two incident edges have the same color. Specifically, a proper edge coloring is an assignment of colors to the edges so that no two incident edges share the same color. Equivalently, an edge coloring partitions the edges of the graph into matchings, one per color. The minimum number of colors needed to properly color the edges of a graph G is its chromatic index, written χ′(G).

Vizing's theorem

By Vizing's theorem, every simple graph can be edge-colored using at most Δ+1 colors, where Δ is the maximum degree of the graph. Since at least Δ colors are always necessary, graphs fall into two classes: "class 1" graphs, which can be colored with Δ colors, and "class 2" graphs, which require Δ+1. Deciding which class a given graph belongs to is NP-complete, though many families of graphs (including all bipartite graphs, by Kőnig's line coloring theorem, and all planar graphs with maximum degree at least 7) are known to be class 1.

Examples and applications

A complete graph on an even number of vertices has chromatic index n−1, and on an odd number of vertices has chromatic index n; the Petersen graph is a famous class 2 cubic graph. Edge colorings model scheduling problems: for example, in scheduling sports fixtures or examinations, or assigning time slots to meetings so that no person has two commitments at once, edges represent pairings and colors represent time slots. Edge coloring is also used in register allocation in compilers and in the design of communication networks.

Other colorings

Related notions include total coloring (coloring vertices and edges so that no adjacent or incident elements share a color), list edge coloring, and acyclic edge coloring. The list coloring conjecture asserted that the list chromatic index equals the chromatic index for every graph; it has been verified for several important classes of graphs but remains open in general.
