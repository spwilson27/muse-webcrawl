Impedance parameters

Impedance parameters or Z-parameters are properties used in electrical engineering to describe the electrical behavior of linear electrical networks. These Z-parameters are used in Z-matrixes to calculate the incoming and outgoing voltages and currents of a two-port network.

Definition

For a two-port network, the Z-parameters relate the port voltages V1 and V2 to the port currents I1 and I2 by:

V1 = Z11I1 + Z12I2
V2 = Z21I1 + Z22I2

Here Z11 is the input impedance with the output port open-circuited, Z22 is the output impedance with the input port open-circuited, and Z12 and Z21 are the reverse and forward transfer impedances, respectively. Because the parameters are measured with ports open-circuited, Z-parameters are also called open-circuit parameters.

Properties

For a reciprocal network, Z12 = Z21. For a symmetrical network, Z11 = Z22. Z-parameters can be converted to and from other two-port parameter sets, including admittance (Y) parameters (the inverse of the Z-matrix), hybrid (h) parameters, and scattering (S) parameters, although not every network possesses a Z-matrix — for example, an ideal transformer has no impedance matrix.
