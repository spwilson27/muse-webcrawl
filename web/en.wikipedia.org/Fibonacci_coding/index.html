Fibonacci coding

Fibonacci coding is a universal code for positive integers based on the Fibonacci sequence. It encodes an integer as the binary string of its Zeckendorf representation — the unique representation as a sum of non-consecutive Fibonacci numbers — followed by an additional "1" bit, which marks the end of the codeword.

Encoding

By Zeckendorf's theorem, every positive integer has a unique representation as a sum of non-consecutive Fibonacci numbers (using F(2)=1, F(3)=2 as the smallest summands). Writing the coefficients as bits produces a string with no two consecutive 1s; appending a terminating 1 therefore creates a unique double "11" that occurs only at the end of the codeword. This makes the code self-delimiting, like the Elias codes, and robust: loss of synchronization caused by a bit error tends to be confined to nearby codewords.

Applications

Fibonacci coding is used in data compression contexts where a universal code with local self-synchronization is desirable, and in "Fibonacci search" and related representations in number systems and digital watermarks. It is related to the Fibonacci numeration system studied in combinatorics on words.
