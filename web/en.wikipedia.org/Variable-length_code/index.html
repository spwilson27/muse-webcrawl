Variable-length code

In coding theory, a variable-length code is a code which maps source symbols to a variable number of bits. Unlike fixed-length codes, which assign the same number of bits to every symbol, variable-length codes assign shorter codewords to more frequent symbols and longer codewords to less frequent ones, thereby reducing the average number of bits needed to represent the source. This principle is central to lossless data compression.

Prefix codes

The most common class of variable-length codes are prefix codes (also called prefix-free codes), in which no codeword is a prefix of another. This property allows the encoded sequence to be decoded unambiguously from left to right without lookahead. Prefix codes can be represented as binary trees whose leaves are the source symbols. The lengths of codewords in a prefix code must satisfy Kraft's inequality.

Examples

Morse code is an early example of a variable-length code: common letters such as E and T receive very short codes, while rare letters such as Q and J receive longer ones. Huffman coding, introduced by David A. Huffman in 1952, constructs an optimal prefix code for a given symbol probability distribution. Other schemes include Shannon–Fano coding, arithmetic coding (which is not strictly a per-symbol code), and the universal codes used for integers, such as Elias gamma and Fibonacci coding. UTF-8 is a variable-length encoding of Unicode characters.

Properties

By Shannon's source coding theorem, the average codeword length of an optimal code approaches the entropy of the source. Variable-length codes are vulnerable to error propagation: a single bit error can desynchronise the decoder and corrupt subsequent symbols, which has motivated the study of self-synchronising and reversible variable-length codes.
