Context-free grammar

Context-free grammars generate sentences with hierarchical parse trees.

A context-free grammar (CFG) is a formal grammar in which every production rule has the form A → w, where A is a single nonterminal symbol and w is a string of terminals and nonterminals. The name reflects that a nonterminal can be replaced wherever it occurs, regardless of context. Context-free grammars were introduced by Noam Chomsky in the 1950s in his study of natural language syntax, and independently in computer science as the basis of the Backus-Naur notation used to describe programming languages.

The Chomsky hierarchy

Context-free languages, the languages generated by such grammars, sit between regular and context-sensitive languages in the Chomsky hierarchy. They are exactly the languages recognised by pushdown automata, machines equipped with a stack. Every regular language is context-free, but context-free languages also capture nested structures such as matched parentheses, which finite automata cannot count.

Properties and parsing

Context-free languages are closed under union, concatenation, and Kleene star, but not under intersection or complementation; the pumping lemma for context-free languages provides a tool for proving that a language is not context-free. Parsing, determining whether a string belongs to the language and recovering its structure, can be done in cubic time by the CYK algorithm for grammars in Chomsky normal form, and faster for the restricted grammar classes (LL, LR) used in compilers. Ambiguity, where one string has several parse trees, is undecidable to test in general but practically important in both programming language design and computational linguistics.
