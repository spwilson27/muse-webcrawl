Dynamic web page

A dynamic web page is a web page whose content is generated at request time or updated interactively in the browser, as opposed to a static web page, which is delivered exactly as stored.

Server-side generation

In server-side generation, software on the web server assembles the page for each request, drawing on databases and user-specific information. Historically this was done with CGI scripts and later with technologies such as PHP, ASP.NET, JSP and frameworks in Python, Ruby and JavaScript.

Client-side generation

Client-side scripting with JavaScript allows pages to change in response to user actions without full reloads. Techniques such as Ajax, single-page applications and client-side rendering frameworks make pages behave more like applications, while server-side rendering and hybrid approaches balance performance and interactivity.

Trade-offs

Dynamic pages enable personalization, interactivity and up-to-date content, at the cost of greater server load, caching complexity and potential security exposure compared with static pages.
