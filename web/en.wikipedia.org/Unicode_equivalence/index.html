Unicode equivalence

Unicode equivalence is the specification by the Unicode standard that certain sequences of code points represent essentially the same character. This matters when comparing, searching, or sorting text, because the same visible character can be encoded in more than one way — for example, the character "é" can be a single code point (U+00E9) or the letter "e" followed by a combining acute accent (U+0065 U+0301).

Types of equivalence

Canonical equivalence holds between code point sequences with identical appearance and meaning, such as a precomposed accented letter and its base-plus-combining-mark decomposition. Compatibility equivalence is a weaker relation covering sequences that may differ in appearance but share meaning in some contexts, such as ligatures, superscripts, or full-width forms.

Normalization

Unicode defines normalization forms — NFC, NFD, NFKC, and NFKD — that convert strings into standard representations so that equivalent strings compare equal. Normalization is important for file systems, identifiers, and security, since visually identical but differently encoded strings can otherwise cause mismatches or spoofing.
