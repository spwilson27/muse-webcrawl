File comparison

File comparison is the calculation and display of the differences and similarities between data objects, typically text files. Comparison software, often called diff tools, is a core part of version control, software development, and data synchronisation.

Methods

Text comparison usually proceeds line by line, finding a longest common subsequence of lines. The Unix diff utility, written in the early 1970s, set the standard format still used in patches. Binary comparison tools instead report byte-level differences, while directory comparison tools recurse over folder trees.

Applications

Diff tools underpin code review, merge conflict resolution, backup verification, and plagiarism and document-change detection. Graphical tools highlight additions and deletions side by side and support three-way merges between two revisions and their common ancestor.
