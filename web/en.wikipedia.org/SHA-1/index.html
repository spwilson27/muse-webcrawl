SHA-1

SHA-1 (Secure Hash Algorithm 1) is a hash function which takes an input and produces a 160-bit (20-byte) hash value known as a message digest, typically rendered as 40 hexadecimal digits. It was designed by the United States National Security Agency and first published by the National Institute of Standards and Technology (NIST) in 1995 as a U.S. Federal Information Processing Standard.

Algorithm

SHA-1 processes messages in 512-bit blocks, padded to a multiple of 512 bits with the message length appended. Its compression function uses an 80-word expanded message schedule, five 32-bit state variables, and 80 rounds organised in four stages with different Boolean functions and constants. The design resembles the earlier MD4 and MD5 hash functions.

Security

Theoretical collision attacks were announced in 2005, and in February 2017 researchers from Google and CWI Amsterdam produced the first practical collision — two different PDF files with the same SHA-1 hash — known as the SHAttered attack. A practical chosen-prefix collision followed in 2020. Because of these weaknesses, SHA-1 has been deprecated for digital signatures and certificates: browsers removed trust in SHA-1 certificates, and NIST has directed migration to the SHA-2 and SHA-3 families. It remains in use in some non-security-critical contexts, such as checksums and the Git version control system (which is transitioning to SHA-256).
