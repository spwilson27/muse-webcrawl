Hedonic set point

The hedonic set point is a concept in positive psychology describing an individual's relatively stable level of happiness, to which they tend to return after major positive or negative life events. The theory is closely related to the idea of the hedonic treadmill.

Research

The concept was developed in the 1970s, notably in a 1978 study by Philip Brickman and colleagues comparing lottery winners and accident victims, which found that both groups tended to return toward their previous levels of happiness over time. Later research, including twin studies, suggested that a substantial portion of the variance in subjective well-being is heritable, supporting the idea of a genetically influenced set point.

Subsequent work has refined the model: set points may differ for different components of well-being, can shift somewhat with major life changes, and vary between individuals, so the theory is now usually framed in terms of a set range rather than a single fixed point.
