Start codon

The start codon is the first codon of a messenger RNA (mRNA) transcript translated by a ribosome. It commonly codes for methionine in eukaryotes and archaea and for a modified methionine (fMet) in bacteria, mitochondria and plastids.

The AUG codon

The most common start codon is AUG. In eukaryotes, the ribosome scans from the 5' cap and usually initiates at the first AUG in a suitable (Kozak) sequence context. Alternative start codons such as GUG and UUG are used, particularly in bacteria, but are still read as formylmethionine at initiation.

Function

The start codon defines the reading frame of the protein and marks where the amino acid sequence begins; translation proceeds until a stop codon is reached.
