Linear independence

In the theory of vector spaces, a set of vectors is said to be linearly independent if none of the vectors in the set can be written as a linear combination of the others. A set of vectors that is not linearly independent is called linearly dependent. The concept is central to linear algebra, since maximal linearly independent sets — bases — determine the dimension of a vector space.

Definition

Vectors v1, …, vn in a vector space V over a field F are linearly independent if the only scalars a1, …, an in F satisfying a1v1 + … + anvn = 0 are a1 = … = an = 0. If some non-trivial combination equals zero, the vectors are linearly dependent.

Examples

In R², the vectors (1, 0) and (0, 1) are linearly independent, while (1, 1) and (2, 2) are dependent because the second is a scalar multiple of the first. Any set containing the zero vector is dependent. In Rⁿ, no set of more than n vectors can be independent. The functions 1, x, x² in the space of polynomials are independent, a fact related to the non-vanishing of the Wronskian in more general settings.

Properties

  • A subset of an independent set is independent; a superset of a dependent set is dependent.
  • Square matrices are invertible exactly when their columns (or rows) are linearly independent, equivalently when the determinant is non-zero.
  • All bases of a vector space have the same cardinality, the dimension.
  • The vectors are independent if and only if the Gram matrix of inner products is non-singular (in inner product spaces).

Generalizations

The abstract theory of independence in sets with a closure operator is developed in matroid theory, which unifies linear independence with independence in graphs and algebraic independence in field extensions. In infinite-dimensional spaces, independence is defined for arbitrary sets by requiring every finite subset to be independent.
