Instruction-level parallelism

Instruction-level parallelism (ILP) is a measure of how many of the instructions in a computer program can be executed simultaneously. It is a form of parallel computing exploited by modern processors through techniques such as pipelining, superscalar execution, and out-of-order execution.

Approaches

ILP can be exploited by the compiler, which reorders instructions to expose parallelism, or by hardware, which dynamically detects independent instructions at runtime. Very long instruction word (VLIW) architectures rely primarily on the compiler, while superscalar processors such as those implementing Tomasulo's algorithm use hardware scheduling with reservation stations and register renaming.

Limits

The amount of available ILP is limited by data dependencies, control dependencies such as branches, and resource constraints. Studies in the 1990s suggested practical limits of only a few instructions per cycle for typical programs. Memory latency and branch misprediction penalties further constrain realized performance, motivating complementary techniques such as multithreading and vector processing.
