grep is a command-line utility for searching plain-text data sets for lines that match a regular expression. It was originally developed for the Unix operating system, but later became available for all Unix-like systems and some others such as Microsoft Windows. Its name comes from the ed editor command g/re/p (globally search for a regular expression and print matching lines), which had the same effect.

History

grep was written overnight by Ken Thompson at Bell Labs in 1973, extracting the regular-expression engine from the ed editor into a standalone tool at the request of Doug McIlroy, who wanted to search the text of the Federalist Papers for characteristic usage. It first appeared publicly in Version 4 Unix. McIlroy later remarked that "grep was created because no one would write a special program just to do that." The tool became a canonical example of the Unix philosophy of small, composable programs.

Usage

In its basic form, grep pattern file prints each line of the file containing a match. Common options include -i (case-insensitive), -v (invert the match), -r (recursive search through directories), -n (show line numbers) and -c (count matches). Variants standardised by POSIX include egrep (extended regular expressions, now grep -E) and fgrep (fixed strings, now grep -F).

Implementations and influence

The GNU version of grep, part of the GNU grep package, is the default on Linux systems and is known for fast matching algorithms derived from the Boyer–Moore string-search approach. The name has entered general computing vocabulary as a verb meaning to search text, and grep-inspired tools — such as ack, ag (the Silver Searcher) and ripgrep — extend the concept with defaults suited to searching source code.
