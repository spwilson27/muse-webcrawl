Media typeimage/svg+xml
Developed byW3C

Type of formatVector graphics

Scalable Vector Graphics (SVG) is an XML-based vector image format for defining two-dimensional graphics, developed by the World Wide Web Consortium (W3C) since 1999. Because an SVG image describes shapes geometrically — paths, circles, rectangles, text and gradients — rather than as a grid of pixels, it can be scaled to any size without loss of quality, making it ideal for logos, icons, diagrams, maps and responsive web design.

Features

SVG supports shapes, paths, text, fills, strokes, gradients, patterns, clipping, masking, filters and transformations, together with interactivity and animation. As XML text, SVG files are human-readable, can be created and edited in code, and can be styled with CSS and manipulated with JavaScript like any other part of a web page: SVG can be embedded directly in HTML, not only linked as an image. Compressed SVG files use gzip and take the extension .svgz.

History and adoption

SVG 1.0 became a W3C Recommendation in 2001, and SVG 1.1 (2003) is the widely implemented baseline; the modular SVG Tiny profile served early mobile phones. Browser support, initially the format's weak point, became universal in the 2010s, and SVG is now the standard format for icons and schematic illustrations on the web. SVG 2, developed as an evolving specification aligned with HTML5-era features, adds improved text, painting and geometry properties. Tools for authoring SVG include Adobe Illustrator and the free editor Inkscape.
