Roy Fielding

From Wikipedia, the free encyclopedia

Roy Thomas Fielding (born 1965) is an American computer scientist and one of the principal authors of the HTTP specification. He is best known for defining REST (Representational State Transfer), the architectural style of the World Wide Web, in his 2000 doctoral dissertation at the University of California, Irvine. Fielding co-founded the Apache HTTP Server project and was a founding member and former chairman of the Apache Software Foundation.

Contributions

Fielding was a co-author of the HTTP/1.0 and HTTP/1.1 specifications (RFC 1945, 2068, 2616 and successors) and of the URI generic syntax standard. As one of the original developers of the Apache web server, he helped create what became the most widely deployed web server software of the early web. He also contributed to libwww-perl and developed the Waka protocol proposal as a successor to HTTP.

REST

His dissertation distilled the architecture of the Web into a set of constraints — client–server separation, statelessness, cacheability, a uniform interface, layered systems, and optionally code-on-demand — combined into the style he named Representational State Transfer. REST became the dominant design approach for web APIs, although Fielding has frequently written that many systems marketed as "RESTful" omit key constraints, particularly hypermedia as the engine of application state.
