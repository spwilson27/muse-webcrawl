Basic block


A control-flow graph divided into basic blocks.

In compiler construction, a basic block is a straight-line code sequence with no branches in except to the entry and no branches out except at the exit. It is a sequence of instructions in which the flow of control enters at the beginning and leaves at the end without halting or branching, except possibly for function calls.

Construction

Compilers partition a program's code into basic blocks by identifying "leaders": the first instruction, every target of a branch, and every instruction immediately following a branch. A basic block extends from each leader up to, but not including, the next leader. Connecting basic blocks by their possible branches produces a control-flow graph, the foundation for many analyses and optimizations.

Uses

Basic blocks are the unit on which local optimizations are performed, including common subexpression elimination, copy propagation, and dead-code elimination within the block. They also structure global data-flow analysis, register allocation, and instruction scheduling. Extended basic blocks relax the definition somewhat, allowing multiple entries along a dominant path, and are used by some just-in-time compilers and trace-oriented analyses.
