Pageview

A pageview (or page view) is a standard unit of web traffic measurement: a request to load a single file of an HTML page, or, by extension, one instance of a user viewing a web page. Pageviews are a core metric in web analytics, though their meaning has evolved with the growth of dynamic web applications, single-page applications, bots, and content delivered through apps and feeds.

Definition and measurement

Traditionally, a pageview was counted each time a server received a request for an HTML document, as recorded in server log files. Modern analytics tools such as Google Analytics instead count pageviews through JavaScript tags embedded in pages, which fire when the page is rendered in a browser and can exclude many automated requests. A related metric, the unique pageview, counts sessions in which a page was viewed at least once.

Uses

Pageviews are used to measure popularity, to set advertising rates (often as cost per thousand impressions), to evaluate content performance, and to compare sites. Wikipedia pageview statistics are publicly available and are used by researchers to study attention to topics, seasonality of interest, and the impact of news events on public curiosity.

Criticisms

Critics note that pageviews measure raw loading events rather than attention or comprehension: a page may be opened in a background tab, refreshed repeatedly, or generated by a crawler. Publishers chasing pageviews have been accused of clickbait headlines and multi-page slideshows that split articles to inflate counts. Metrics such as time on page, engaged sessions, and conversions are often used to supplement or replace pageviews.
