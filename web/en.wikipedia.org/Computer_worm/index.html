Computer worm

A computer worm is a standalone malware program that replicates itself in order to spread to other computers. It often uses a computer network to spread itself, relying on security failures on the target computer to access it. Unlike a computer virus, a worm does not need to attach itself to an existing program or require user interaction to propagate.

Notable worms

The Morris worm of 1988, released by Robert Tappan Morris, was the first worm distributed via the Internet and drew widespread public attention to computer security. Later examples include ILOVEYOU (2000), which spread by email; Code Red (2001) and SQL Slammer (2003), which exploited server vulnerabilities; Conficker (2008); and Stuxnet (2010), which targeted industrial control systems.

Effects

Even worms without destructive payloads can cause harm by consuming network bandwidth and system resources as they spread. Worms are also used to install backdoors and assemble botnets for spam, distributed denial-of-service attacks, and further malware distribution.

Protection

Defences include promptly patching software vulnerabilities, network firewalls, intrusion detection systems, and segmentation of networks to limit spread.
