Ruby is an interpreted, high-level, general-purpose programming language. It was designed with an emphasis on programming productivity and simplicity. In Ruby, everything is an object, including primitive data types. It was developed in the mid-1990s by Yukihiro "Matz" Matsumoto in Japan.

History

Matsumoto began work on Ruby in 1993, seeking a language more powerful than Perl and more object-oriented than Python. Ruby 0.95 was released in December 1995. The language gained a worldwide following in the mid-2000s largely through the success of the Ruby on Rails web framework.

Philosophy

Ruby follows the principle of least astonishment and is designed for programmer happiness. Its syntax is deliberately readable and flexible, allowing programmers to alter parts of the language itself through metaprogramming. A typical first program reads: puts "Hello, World!".

Features

Ruby supports multiple programming paradigms, including procedural, object-oriented and functional programming. It features dynamic typing and automatic memory management (garbage collection), blocks and iterators, exception handling, and operator overloading. Libraries are distributed as "gems" through the RubyGems package manager.
