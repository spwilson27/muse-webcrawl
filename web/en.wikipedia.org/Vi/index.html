Vi

Original authorBill Joy
First released1976
PlatformUnix, Unix-like systems
TypeText editor
Successor conceptsVim, Neovim, other clones

vi (pronounced "vee-eye") is a screen-oriented text editor originally created for the Unix operating system. It was written by Bill Joy in 1976 at the University of California, Berkeley, as the visual mode of the ex line editor. The name derives from the ex command visual, abbreviated vi. vi became the de facto standard Unix editor, is specified by POSIX, and is present on virtually every Unix and Unix-like system to this day.

Interface

vi is a modal editor: the keyboard performs different functions in different modes. In normal (command) mode, keystrokes move the cursor and issue editing commands — h, j, k, l move left, down, up, and right — while insert mode, entered with commands such as i or a, inserts typed text. Commands combine operators and motions (dw deletes a word, y$ yanks to end of line), giving the editor a composable "language" of editing. Because it was designed for slow terminals and minimal keystrokes, vi keeps the user's hands on the home row and requires no mouse.

Legacy

The original vi spawned many enhanced clones, most notably Vim ("Vi IMproved", 1991), which added an extension language, syntax highlighting, and extensive configurability, and more recently Neovim. The rivalry between vi/Vim and the Emacs editor is a famous fixture of hacker culture, jokingly called the "editor war". Generations of programmers have learned its keystrokes, which recur as a movement scheme in shells, pagers, browsers, and development tools.
