Almost everywhere

A property holds almost everywhere if the set where it fails has measure zero.

In measure theory, a property holds almost everywhere if, in a technical sense, it holds for all but a negligible set of points. More precisely, if (X, Σ, μ) is a measure space, a property P holds almost everywhere in X if there exists a subset N of measure zero such that all points in X \ N satisfy P. The phrase is abbreviated a.e.; in probability theory, where the measure is a probability measure, the equivalent terms are almost surely and almost certainly.

Definition

μ({x ∈ X : ¬P(x)}) = 0

That is, the set of points where the property fails is contained in a set of measure zero. The exceptional set need not be empty: for example, the set of rational numbers has Lebesgue measure zero in the real line, so a property can hold almost everywhere on ℝ while failing at infinitely many points.

Examples

Every continuous function on ℝ that equals zero almost everywhere is identically zero, but an integrable function need only vanish almost everywhere to have integral zero. The Cantor function is constant almost everywhere in the sense that its derivative is zero almost everywhere. In the Lebesgue theory of integration, functions equal almost everywhere are identified, which is why the Lp spaces consist of equivalence classes of functions.

Almost surely

In probability, an event that occurs with probability 1 is said to happen almost surely. The strong law of large numbers, for instance, states that the sample average converges to the expected value almost surely.
