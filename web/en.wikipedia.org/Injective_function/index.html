Injective function

In mathematics, an injective function (also known as an injection, or one-to-one function) is a function f that maps distinct elements of its domain to distinct elements of its codomain; that is, if f(x1) = f(x2), then x1 = x2. Every element of the codomain is the image of at most one element of the domain.

An injection: no two inputs share the same output.

Properties

An injective function has a left inverse: there exists a function g such that g ∘ f is the identity on the domain. A function that is both injective and surjective is bijective and has a full inverse. The composition of injective functions is injective. A function is injective if and only if it has the cancellation property: f ∘ g = f ∘ h implies g = h.

Examples

The function f(x) = 2x + 1 on the real numbers is injective, as is the exponential function. The function f(x) = x² is not injective on the reals (since f(2) = f(−2) = 4) but becomes injective when restricted to the nonnegative reals. In set theory, the existence of an injection from set A to set B is the basis for comparing cardinalities: |A| ≤ |B|.
