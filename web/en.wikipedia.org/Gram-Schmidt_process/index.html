Gram-Schmidt process

Building an orthonormal basis step by step

The Gram-Schmidt process is an algorithm in linear algebra for converting a set of linearly independent vectors into an orthogonal set spanning the same subspace, typically then normalised to an orthonormal basis. It is named for the Danish mathematician Jørgen Pedersen Gram and the German mathematician Erhard Schmidt.

Description

Starting with the first vector unchanged, the algorithm repeatedly removes from each vector its components along all previously constructed orthogonal vectors. What remains is perpendicular to every earlier vector. Normalising each result to unit length completes the orthonormalisation. The procedure works in any inner product space, including spaces of functions, where it can be used to generate orthogonal polynomials such as the Legendre polynomials from the monomials 1, x, x², …

Example

In two dimensions, given two non-parallel vectors, the process keeps the first and subtracts from the second its projection onto the first; the two results are perpendicular and can be rescaled to unit length, forming a rotated coordinate frame aligned with the original data.

Numerical considerations

In floating-point arithmetic the classical formulation can lose orthogonality when vectors are nearly parallel. The modified Gram-Schmidt variant, mathematically equivalent but reordering the projections, is substantially more stable and is the basis of practical implementations, including the QR factorisation used in least-squares solvers.
