Probabilistically checkable proof

In computational complexity theory, a probabilistically checkable proof (PCP) is a type of proof that can be checked by a randomized algorithm using a bounded number of random bits and reading a bounded number of bits of the proof. The algorithm is required to accept correct proofs and reject incorrect ones with high probability.

The PCP theorem

The PCP theorem, proved in the early 1990s by Sanjeev Arora, Uriel Feige, Shafi Goldwasser, Carsten Lund, László Lovász, Rajeev Motwani, Shmuel Safra, Madhu Sudan, and Mario Szegedy, states that every decision problem in NP has probabilistically checkable proofs of polynomial size that can be verified by reading only a constant number of bits and using logarithmically many random bits. Formally, NP = PCP[O(log n), O(1)].

Applications

The PCP theorem underlies hardness of approximation results: because a verifier reads only constantly many proof bits, one can show that for many optimization problems (such as Max-3SAT or maximum clique) it is NP-hard to approximate within certain factors. Irit Dinur's 2006 proof of the theorem via gap amplification gave a simpler, more combinatorial argument.
