Root-finding algorithm

Root-finding algorithm

ProblemFind x such that f(x) = 0
Main methodsBisection, Newton's method, secant method, Brent's method
FieldNumerical analysis

In numerical analysis, a root-finding algorithm is an algorithm for finding the zeros, also called "roots", of continuous functions. A zero of a function f, from the real numbers to real numbers or from the complex numbers to the complex numbers, is a number x such that f(x) = 0. In general, the roots of a function cannot be computed exactly or expressed in closed form, so root-finding algorithms provide approximations.

Bracketing methods

Bracketing methods determine successively smaller intervals (brackets) in which a root must lie, relying on the intermediate value theorem. The bisection method is the simplest: it repeatedly halves an interval in which the function changes sign, guaranteeing convergence at a linear rate. The false position (regula falsi) method improves on bisection by using linear interpolation, and Brent's method combines bisection, the secant method, and inverse quadratic interpolation to achieve both reliability and speed.

Iterative methods

Newton's method uses the derivative of the function to refine an initial guess by following the tangent line to the x-axis; near a simple root it converges quadratically, though it can fail if the starting guess is poor or the derivative vanishes. The secant method replaces the derivative with a finite difference between two previous points, achieving superlinear convergence without requiring derivatives. Fixed-point iteration rewrites the equation as x = g(x) and iterates.

Polynomial roots

For polynomials, specialized algorithms exploit algebraic structure. The Abel–Ruffini theorem shows no general formula in radicals exists for degree five or higher, making numerical methods essential; algorithms such as the Jenkins–Traub algorithm and Aberth method find all roots simultaneously. Eigenvalue methods compute roots as eigenvalues of the companion matrix.

Convergence and stopping criteria

Algorithms are judged by their order of convergence, robustness, and cost per iteration. Practical implementations stop when the interval is sufficiently small, the function value is near zero, or successive iterates differ by less than a chosen tolerance.
