Level editor

A level editor (also known as a map editor, campaign editor or scenario editor) is a software tool used to design levels, maps, scenarios or campaigns for a video game. It may be the same tool the developers used internally, released to players to encourage user-generated content.

History

One of the earliest games with a built-in editor was Lode Runner (1983), which let players save home-made levels. In the 1990s, editors and scripting for Doom and Warcraft II created thriving modding communities; Valve's Hammer Editor and Epic's UnrealEd exposed professional pipelines to hobbyists, and some mods — such as Counter-Strike — grew into major commercial games. Dedicated creation games such as Super Mario Maker and LittleBigPlanet made level editing itself the gameplay.

Features

Editors typically provide terrain sculpting, object and enemy placement, trigger and script editing, and play-testing from within the tool. Community sharing is now usually integrated through platform workshops.
