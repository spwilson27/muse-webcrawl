Tuple

Tuple
FieldMathematics; computer science
DefinitionFinite ordered list (sequence) of elements
ExamplesPair (2-tuple), triple (3-tuple), ordered pair

In mathematics, a tuple is a finite sequence or ordered list of elements. An n-tuple is a tuple of n elements, where n is a non-negative integer. Specific cases have their own names: a 1-tuple is a single, a 2-tuple is an ordered pair (or couple), a 3-tuple is a triple, and so on with quadruple, quintuple, sextuple and further terms formed from Latin numerical prefixes and the suffix -tuple.

Properties

Unlike a set, a tuple can contain the same element more than once and the order of its elements matters: the tuple (1, 2) is different from (2, 1). Tuples may be written as comma-separated lists within parentheses, as in (2, 7, 4, 1, 7). Mathematically, an n-tuple can be defined as a function from a finite index set {1, ..., n} to the elements, or built inductively from ordered pairs.

Uses

Tuples are fundamental throughout mathematics: points in n-dimensional Euclidean space are n-tuples of real numbers, and relations in set theory and database theory are sets of tuples. In computer science, many programming languages provide tuples as a built-in data type for grouping a fixed number of possibly heterogeneous values, and in the relational model a row of a database table is formally called a tuple.
