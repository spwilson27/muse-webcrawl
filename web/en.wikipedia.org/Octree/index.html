Octree

An octree is a tree data structure in which each internal node has exactly eight children. Octrees are most often used to partition a three-dimensional space by recursively subdividing it into eight octants. Octrees are the three-dimensional analog of quadtrees.

Recursive subdivision of a cube into eight octants.

Uses

Octrees are used in 3D computer graphics to reduce the amount of geometry that must be rendered, in collision detection, in finite element analysis, and in spatial indexing. In robotics, octrees underpin probabilistic three-dimensional mapping frameworks such as OctoMap, which extends two-dimensional occupancy grid mapping to volumetric maps.

Structure

Each node represents a cubic volume of space. A node is subdivided when it contains more detail than a chosen threshold; leaves store values such as colour, density, or occupancy probability. Sparse voxel octrees store only the occupied branches, giving efficient memory use for mostly empty volumes.
