Linux Standard Base

The Linux Standard Base (LSB) was a joint project by several Linux distributions under the organizational structure of the Linux Foundation to standardize the software system structure, including the Filesystem Hierarchy Standard, used in the GNU/Linux operating system family. The LSB was based on the POSIX specification, the Single UNIX Specification, and other open standards, but extended them in certain areas.

The goal of the LSB was to develop and promote a set of open standards that would increase compatibility among Linux distributions and enable software applications to run on any compliant system even in binary form. It specified standard libraries, a standard set of commands and utilities, directory layout, printing and GUI components, and the LSB-compliant RPM package format or system-provided equivalents.

History and decline

The first LSB release appeared in 2001; version 5.0 was released in 2015. Compliance certification was offered through the Linux Foundation, and major distributions including Red Hat, SUSE, and Ubuntu were certified at various times. However, interest waned: Debian's support ended in 2015, and the LSB working group was disbanded as distributors moved toward other compatibility mechanisms such as container formats and distribution-specific standards. The specifications were archived, remaining as a reference work.
