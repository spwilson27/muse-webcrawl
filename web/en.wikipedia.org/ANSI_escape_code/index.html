ANSI escape code

ANSI escape sequences are a standard for in-band signaling to control cursor location, color, font styling, and other options on video text terminals and terminal emulators. Certain sequences of bytes, most starting with an ASCII escape character and a bracket character, are embedded into text. The terminal interprets these sequences as commands, rather than as text to display verbatim.

History

The standard, ANSI X3.64, was adopted in 1979 and drew on earlier sequences introduced by DEC's VT100 terminal in 1978. The popular ANSI.SYS driver for MS-DOS implemented a subset of the sequences, which made them widespread on personal computers and bulletin board systems.

CSI sequences

Most sequences begin with the Control Sequence Introducer, ESC followed by [. Parameters, given as decimal numbers separated by semicolons, are followed by a letter indicating the function: for example, ESC[31m sets the foreground color to red, and ESC[2J clears the screen.

SGR parameters

The Select Graphic Rendition (SGR) command controls attributes such as bold, italic, underline, and foreground and background colors, including 256-color and 24-bit "true color" extensions used by modern terminal emulators.
