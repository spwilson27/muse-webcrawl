Free software

The GNU head, emblem of free software

Free software (or libre software) is computer software distributed under terms that allow users to run the software for any purpose, and to study, change, and distribute it and any adapted versions. "Free" here refers to freedom, not price — a distinction often summarized as "free as in speech, not free as in beer."

The four freedoms

The Free Software Foundation defines free software by four essential freedoms:

  • Freedom 0: to run the program as you wish, for any purpose.
  • Freedom 1: to study how the program works and change it — requiring access to source code.
  • Freedom 2: to redistribute copies so you can help others.
  • Freedom 3: to distribute copies of your modified versions.

History

The movement began in 1983 when Richard Stallman announced the GNU Project to create a complete free operating system, and in 1985 he founded the Free Software Foundation and published the GNU Manifesto. The GNU General Public License (GPL), first released in 1989, used copyright law to enforce "copyleft" — requiring derivative works to remain free. The Linux kernel (1991), released under the GPL, completed a widely used free system, commonly called GNU/Linux.

Relation to open source

In 1998 part of the community adopted the term "open source" to emphasize practical development advantages rather than moral arguments. Nearly all open-source licenses also qualify as free software licenses, but the movements' values differ; Stallman described open source as a development methodology and free software as a social movement.
