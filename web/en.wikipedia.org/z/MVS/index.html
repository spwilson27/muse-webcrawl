MVS

Multiple Virtual Storage, more commonly called MVS, is the most commonly used operating system in the history of IBM mainframe computers, first released in 1974 as part of OS/VS2. MVS evolved from earlier IBM operating systems (OS/360 and OS/VS) and added the ability for each job to run in its own virtual address space, greatly improving the ability of a single machine to run many large batch and interactive workloads at once.

History

MVS grew through the 1970s and 1980s with enhancements such as MVS/XA (31-bit addressing), MVS/ESA, and extensive subsystem support: JES2 and JES3 for job entry, TSO for interactive use, IMS and CICS for transaction processing, and DB2 for relational databases. In 1995 IBM replaced MVS with OS/390, which integrated MVS with additional components; OS/390 in turn was succeeded by z/OS in 2000. Descendants of MVS code still run much of the world's core banking and insurance workload.

Characteristics

MVS was oriented around batch processing and high-throughput transaction work, managed through Job Control Language (JCL). Its resource management, security (via RACF) and reliability features set patterns followed by later enterprise operating systems.
