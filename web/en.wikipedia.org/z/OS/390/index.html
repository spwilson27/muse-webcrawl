OS/390

OS/390 is an IBM operating system for the System/390 (later IBM Z) mainframe computers, introduced in late 1995. It was the successor to MVS and bundled the MVS base together with a large set of previously separate products — including a UNIX environment (OpenEdition), LAN services, and distributed computing components — into a single integrated, pre-tested package with a simpler ordering and installation process.

Development

OS/390 was released on a roughly twice-yearly cadence of releases (Release 1 through Release 10). It added workload management goals, improved TCP/IP support, the UNIX System Services environment, and support for 64-bit real addressing in later releases. In October 2000 IBM announced z/OS as the successor to OS/390, aligned with the new 64-bit z/Architecture machines; the final OS/390 release was supported until 2004.
