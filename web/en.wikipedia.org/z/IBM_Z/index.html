IBM Z

IBM Z is a family name used by IBM for all of its z/Architecture mainframe computers, beginning with the zSeries in 2000. The Z designation signals the design goal of "zero downtime". IBM Z systems run operating systems including z/OS, z/VM, z/VSE and Linux on IBM Z, and are known for very high reliability, transaction throughput and backward compatibility with code written for the System/360 line of the 1960s.

Generations

Major generations include the zSeries (z800, z900, z990, z890), System z (z9, z10), zEnterprise (z196, zEC12), and the later IBM Z models: z13 (2015), z14 (2017), z15 (2019), z16 (2022) and z17 (2025). Each generation increased processor capacity, memory and I/O bandwidth, and added features such as pervasive encryption, on-chip AI acceleration (the Telum processor in z16 and later) and quantum-safe cryptography.

Use

IBM Z mainframes remain widely used by banks, insurers, airlines and governments for high-volume transaction processing, batch processing and large databases, valued for security, resilience and the ability to consolidate thousands of Linux workloads on a single machine.
