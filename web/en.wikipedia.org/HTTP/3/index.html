HTTP/3

HTTP/3 is the third major version of the Hypertext Transfer Protocol used to exchange information on the World Wide Web, standardized in RFC 9114 in June 2022. Unlike its predecessors, which run over TCP, HTTP/3 uses QUIC, a transport protocol built on UDP, as its underlying transport.

Motivation

HTTP/2 introduced multiplexing over a single TCP connection, but packet loss still stalled all streams on that connection — a problem known as head-of-line blocking. QUIC implements independent streams with their own flow control and loss recovery, so a lost packet blocks only the stream it belongs to. QUIC also integrates TLS 1.3 encryption into the transport handshake, reducing connection setup latency, and supports connection migration across changing IP addresses through connection identifiers.

Deployment

HTTP/3 was first deployed at scale by Google, derived from its experimental gQUIC protocol, and by other large content providers and content delivery networks. It is advertised to clients through the Alt-Svc response header or DNS HTTPS records, since browsers initially connect over earlier HTTP versions. By the early 2020s a substantial share of web traffic to major platforms was served over HTTP/3.
