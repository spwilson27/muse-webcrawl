HTTP (Hypertext Transfer Protocol) is an application-layer protocol for transmitting hypermedia documents, such as HTML, and the foundation of data communication for the World Wide Web. Designed by Tim Berners-Lee at CERN in 1989–91, it follows a client–server model in which a client (usually a web browser) sends a request and a server returns a response.

How it works

HTTP is stateless: each request–response pair is independent, though cookies add session state. Requests use methods such as GET, POST, PUT and DELETE, a URL, headers and an optional body; responses carry a three-digit status code (200 OK, 404 Not Found, 500 Internal Server Error), headers and content. Media types, caching, authentication and content negotiation are built into the protocol.

Versions

HTTP/1.1 (1997) standardised persistent connections and virtual hosting and served the web for two decades. HTTP/2 (2015) added binary framing, multiplexing and header compression. HTTP/3 (2022) runs over QUIC on UDP, cutting connection latency. The encrypted variant, HTTPS, uses TLS and is now used by the overwhelming majority of websites.
