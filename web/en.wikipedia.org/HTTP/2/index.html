HTTP/2

HTTP/2
Full name: Hypertext Transfer Protocol version 2
Published: May 2015 (RFC 7540; revised by RFC 9113, 2022)
Based on: SPDY
Developer: IETF HTTP Working Group

HTTP/2 (originally named HTTP/2.0) is a major revision of the HTTP network protocol used by the World Wide Web. It was developed by the HTTP Working Group of the Internet Engineering Task Force and published as RFC 7540 in May 2015; a revised edition appeared as RFC 9113 in 2022. It was derived from Google's experimental SPDY protocol.

Features

Unlike the textual, one-request-at-a-time model of HTTP/1.1 over a single connection, HTTP/2 uses a binary framing layer that multiplexes many concurrent streams over one TCP connection. Other features include header compression with HPACK, stream prioritisation and dependencies, flow control, and server push, which allows a server to send resources before they are requested. Most browsers support HTTP/2 only over TLS, via ALPN negotiation, even though the standard also defines a cleartext variant.

Adoption

HTTP/2 spread rapidly after 2015 and came to carry a large share of web traffic, before work shifted to its successor, HTTP/3, which replaces TCP with QUIC.
