Validity (logic)

In logic, an argument is valid if and only if it takes a form that makes it impossible for the premises to be true and the conclusion nevertheless to be false. Validity is a property of the argument's form, not of the actual truth of its premises or conclusion: a valid argument may have false premises, and an invalid argument may happen to have a true conclusion.

Validity and soundness

Validity is distinct from soundness. A deductive argument is sound if it is valid and all of its premises are actually true; a sound argument therefore necessarily has a true conclusion. For example, "All cats are mammals; Felix is a cat; therefore Felix is a mammal" is valid and sound. By contrast, "All birds can fly; penguins are birds; therefore penguins can fly" is valid in form but unsound, because its first premise is false.

Formal definition

In formal logic, an argument is valid if and only if the conclusion is a logical consequence of the premises — that is, in every model (interpretation) in which the premises are true, the conclusion is true. In propositional logic and first-order logic, validity of formulas can be investigated with truth tables, natural deduction, and semantic methods. Gödel's completeness theorem for first-order logic states that a formula is valid exactly when it is provable in the formal system.

Other senses

A formula of logic is sometimes said to be valid if it is true under every interpretation (a tautology or logical truth). In non-classical and inductive contexts, related notions — such as strong or cogent inductive arguments — are used instead, since inductive conclusions are not guaranteed by their premises.
