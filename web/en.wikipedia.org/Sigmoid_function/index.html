Sigmoid function

A sigmoid function is a mathematical function having a characteristic S-shaped curve. The most common example is the logistic function:

σ(x) = 1 / (1 + e−x) = ex / (ex + 1)

which maps any real number to a value between 0 and 1. Sigmoid functions are monotonic, differentiable, and have a positive derivative at each point. The logistic function was introduced by Pierre François Verhulst in the 1830s–1840s to model population growth.

Properties

The logistic function satisfies σ(−x) = 1 − σ(x) and σ(0) = 1/2. Its derivative has the convenient form σ′(x) = σ(x)(1 − σ(x)). Other functions described as sigmoidal include the hyperbolic tangent tanh(x), the arctangent, the Gudermannian function, the error function and smooth algebraic functions such as x / √(1 + x²).

Applications

Sigmoid functions appear throughout science and engineering:

  • Neural networks: the logistic function was a classic activation function, squashing a neuron's output into (0, 1); it is closely related to the sign function as a smooth analogue and to the step function.
  • Statistics: logistic regression models the probability of a binary outcome with a logistic curve.
  • Biology and ecology: population growth in a limited environment follows a logistic curve with an S-shape approaching a carrying capacity.
  • Biochemistry: binding and enzymatic responses are often modelled sigmoidally (Hill equations).
  • Signal processing and control: smooth saturation behaviour.

A drawback of the logistic activation in deep networks is the vanishing gradient problem: for large |x| the derivative approaches zero, slowing learning — one reason rectified linear units became popular.
