Hamiltonian path

In graph theory, a Hamiltonian path is a path in an undirected or directed graph that visits each vertex exactly once. A Hamiltonian cycle (or Hamiltonian circuit) is a Hamiltonian path whose endpoints are adjacent, forming a cycle. A graph possessing such a cycle is called a Hamiltonian graph.

History

The concepts are named after William Rowan Hamilton, who in 1857 marketed the Icosian game, a puzzle requiring a Hamiltonian cycle on the graph of a dodecahedron. Knight's tours on a chessboard and the travelling salesman problem are closely related classic problems.

Sufficient conditions

Unlike Eulerian paths, no simple necessary-and-sufficient characterisation is known. Dirac's theorem (1952) states that a graph with n ≥ 3 vertices in which every vertex has degree at least n/2 is Hamiltonian; Ore's theorem generalises this using degree sums of non-adjacent pairs. Bondy–Chvátal theory extends these results via graph closure.

Complexity

Determining whether a Hamiltonian path or cycle exists is NP-complete, even for many restricted graph classes, though polynomial algorithms exist for some special cases, and counting Hamiltonian cycles can be done in exponential time with inclusion–exclusion or dynamic programming methods.
