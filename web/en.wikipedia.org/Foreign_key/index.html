Foreign key

A foreign key is a set of attributes in a relational database table that references the primary key of another table (or, in a self-referencing relationship, the same table). The foreign key links the two tables together, enforcing referential integrity: the values in the referencing attributes must match values in the referenced primary key, or be null.

Referential integrity

Foreign keys are the principal mechanism for representing relationships between entities in the relational model. For example, an orders table may contain a customer_id column declared as a foreign key referencing the primary key of a customers table, guaranteeing that every order belongs to an existing customer.

Referential actions

When a referenced row is updated or deleted, the database can respond according to rules declared with the constraint: CASCADE (propagate the change), SET NULL, SET DEFAULT, RESTRICT, or NO ACTION. These rules are specified in SQL with the ON UPDATE and ON DELETE clauses of the FOREIGN KEY constraint.

Definition in SQL

Foreign keys are defined either when a table is created (CREATE TABLE) or added later (ALTER TABLE). Most relational database management systems enforce foreign key constraints automatically during INSERT, UPDATE, and DELETE operations.
