Matrix decomposition

In the mathematical discipline of linear algebra, a matrix decomposition or matrix factorization is a factorization of a matrix into a product of matrices. There are many different matrix decompositions; each finds use among a particular class of problems. Factorizations simplify computations such as solving systems of linear equations, computing determinants, and finding eigenvalues.

Common decompositions

The LU decomposition expresses a matrix as a product of a lower and an upper triangular matrix and underlies Gaussian elimination. The QR decomposition factors a matrix into an orthogonal matrix times an upper triangular matrix and is used in least-squares problems. The singular value decomposition (SVD) writes any matrix as UΣV*, with U and V orthogonal (or unitary) and Σ diagonal with the singular values; it is fundamental in statistics, signal processing, and recommender systems. Symmetric positive definite matrices admit the Cholesky decomposition, and diagonalizable matrices admit eigendecompositions.

Applications

Beyond numerical linear algebra, matrix factorization methods are used in machine learning: latent-factor models factor a user–item interaction matrix into low-rank factors for collaborative filtering, an approach popularized during the Netflix Prize competition.
