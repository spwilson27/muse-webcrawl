Library (computing)

In computer science, a library is a collection of resources — code, subroutines, classes, configuration data and documentation — used by programs during development and execution. Libraries allow code implementing common tasks, such as input/output, mathematics or networking, to be shared and reused rather than rewritten.

Types

Static libraries are linked into a program at compile time, becoming part of the executable. Dynamic (shared) libraries are loaded at run time, so several programs can share one copy in memory and updates can be applied without recompiling. On Windows these are DLLs; on Unix-like systems they are shared objects (.so files).

Linking and standard libraries

A linker or loader resolves references from a program to library routines. Most programming languages provide a standard library — for example the C standard library and the C++ Standard Library — and ecosystems add vast collections of third-party libraries distributed through package managers.
