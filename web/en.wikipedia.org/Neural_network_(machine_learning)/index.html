Neural network (machine learning)

In machine learning, a neural network (also artificial neural network, ANN, or simply neural net) is a model inspired by the structure and function of biological neural networks in animal brains. It consists of connected units called artificial neurons, which model the neurons in a brain. These are connected by edges, which model the synapses in a brain. An artificial neuron receives a signal from connected neurons, processes it, and sends a signal to other connected neurons.

Structure

Neurons are typically organised in layers: an input layer, one or more hidden layers, and an output layer. Each connection carries a numerical weight, and each neuron applies an activation function to the weighted sum of its inputs. In a feedforward network, signals pass in one direction; recurrent networks include feedback connections.

Learning

Training adjusts the weights to reduce the difference between the network's outputs and desired outputs, usually by gradient descent using the backpropagation algorithm with a defined loss function. Large networks with many layers underpin deep learning. Techniques such as stochastic gradient descent, dropout and batch normalisation, together with large datasets and GPU computing, drove the rapid progress of the 2010s.

Architectures and applications

Important architectures include convolutional neural networks for image recognition, recurrent networks and transformers for sequences and language, and generative models such as autoencoders, GANs and diffusion models. Neural networks are applied in computer vision, speech recognition, natural language processing, machine translation, game playing, drug discovery and many other domains.

History

Key milestones include the perceptron of Frank Rosenblatt (1958), the popularisation of backpropagation in the 1980s, and the deep-learning breakthroughs symbolised by AlexNet's victory in the ImageNet competition in 2012 and the transformer architecture introduced in 2017.
