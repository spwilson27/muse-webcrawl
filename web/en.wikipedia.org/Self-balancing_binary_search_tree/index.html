Self-balancing binary search tree

Tree rotations keep a self-balancing binary search tree's height logarithmic in the number of nodes.

In computer science, a self-balancing binary search tree is any node-based binary search tree that automatically keeps its height small in the face of arbitrary insertions and deletions. A plain binary search tree degrades to a linked list with linear-time operations if keys are inserted in sorted order; a self-balancing tree performs local restructuring operations — typically tree rotations — after updates so that the height remains O(log n), guaranteeing logarithmic worst-case or amortised time for search, insertion and deletion.

Implementations

Popular height-balanced schemes include the AVL tree (1962), the first self-balancing tree invented, which enforces a strict balance factor at every node; the red–black tree, which uses node colours to enforce looser balance with fewer rotations, and underlies ordered maps in the C++ Standard Template Library, Java's TreeMap and the Linux kernel's rbtree; the splay tree, which moves recently accessed nodes to the root; and randomized treaps. Weight-balanced trees, scapegoat trees and B-trees (used in databases and file systems) follow the same general principle of maintaining bounded height.

Comparison

Different schemes trade off strictness of balance against update cost: AVL trees give marginally faster lookups but more rotations on insertion, while red–black trees perform at most a constant number of rotations per update. All provide the same asymptotic guarantees and support ordered operations (minimum, maximum, successor, predecessor, and range iteration) that hash tables cannot.

Applications

Self-balancing trees are used in standard library associative containers, database indexes, file systems, memory allocators, interval and geometry data structures, and anywhere an ordered set with guaranteed performance is needed.
