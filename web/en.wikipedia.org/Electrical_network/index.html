Electrical network

An electrical network is an interconnection of electrical components — such as resistors, inductors, capacitors, voltage sources and switches — linked by conductive wires. A network that contains at least one closed path is called an electrical circuit. Networks range from a handful of components on a laboratory bench to nationwide power grids.

Analysis

Network analysis determines the voltages across and currents through every element. The fundamental tools are Kirchhoff's circuit laws: the current law states that currents entering a node sum to zero, and the voltage law states that voltages around any closed loop sum to zero. Systematic techniques built on these laws include nodal analysis, mesh analysis and superposition.

Equivalent circuits simplify analysis: resistors in series and parallel can be combined, and any linear network can be reduced to a Thévenin or Norton equivalent — a single source and resistance — as seen from a pair of terminals. For alternating-current networks, impedances generalise resistance to inductors and capacitors and phasor analysis applies.

Classification

Networks are described as linear or nonlinear depending on whether their components obey superposition; active if they contain energy sources and passive otherwise; and lumped if their physical dimensions are small compared with the wavelengths involved, so that Kirchhoff's laws apply exactly.

Applications

Electrical networks underlie power distribution grids, telecommunications, analogue and digital electronics, signal processing filters and control systems. Graph theory provides the mathematical language of network topology, in which components are edges and connection points are nodes.
