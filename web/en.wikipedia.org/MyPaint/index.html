MyPaint

TypeRaster graphics editor
LicenseGNU GPL (free software)
PlatformsLinux, Windows, macOS
Written inC, C++, Python (GTK)

MyPaint is a free and open-source raster graphics editor designed for digital painting, with an emphasis on natural-media brush simulation and a distraction-free interface for use with graphics tablets. It was created by Martin Renold, who began the project in 2004 after buying a Wacom tablet and finding existing software unsatisfying for sketching.

Features

MyPaint centers on a powerful brush engine that simulates dry media, ink, and paint with extensive tweakable dynamics responding to pen pressure, tilt, and speed. It supports an effectively infinite canvas — the drawing surface expands as you paint — layers, symmetry modes, and a scratchpad for mixing colours and testing brushes. Its native format is OpenRaster (.ora), shared with other open-source graphics applications such as Krita and GIMP.

Design philosophy

Rather than replicating photo-editing software, MyPaint keeps its interface minimal, hiding panels in full-canvas mode and relying on keyboard shortcuts and tablet input, so artists can concentrate on drawing. The brush engine, libmypaint, is shared as a separate library and is also used by other projects.
