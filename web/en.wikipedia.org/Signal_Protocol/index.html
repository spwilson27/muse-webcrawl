Signal Protocol


The Double Ratchet at the protocol's core

The Signal Protocol (formerly known as the TextSecure Protocol) is a non-federated cryptographic protocol that provides end-to-end encryption for voice calls and instant messaging conversations. Developed by Open Whisper Systems, it was introduced in 2013 and powers the Signal messaging app; variants have since been adopted by WhatsApp, Facebook Messenger, Google's Messages RCS encryption, and Skype's Private Conversations.

Components

The protocol combines the X3DH (Extended Triple Diffie–Hellman) key agreement protocol for establishing a shared secret between parties who may be offline, with the Double Ratchet algorithm, which derives a fresh encryption key for every message. Message keys use AES-256 and HMAC-SHA256. The Double Ratchet blends a Diffie–Hellman ratchet — which provides future secrecy — with a symmetric-key ratchet that provides post-compromise ("self-healing") security and protection against replay and reordering.

Properties

The protocol provides confidentiality, integrity, authentication, participant consistency, destination validation, forward secrecy, future secrecy, causality preservation, message unlinkability, message repudiation, and asynchronicity. It does not provide anonymity: servers can see who communicates with whom, though Signal's sealed-sender feature reduces this metadata.

History and analysis

The protocol was designed by Moxie Marlinspike and Trevor Perrin. In 2016 a team of researchers published a formal security analysis of the protocol, finding no major flaws, and the design has influenced the IETF Messaging Layer Security (MLS) standard for group encryption.
