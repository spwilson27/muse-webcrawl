Scalable Vector Graphics

Scalable Vector Graphics (SVG) is an XML-based vector image format for defining two-dimensional graphics, having support for interactivity and animation. The SVG specification is an open standard developed by the World Wide Web Consortium (W3C) since 1999.

SVG images are defined in a vector graphics format and stored in XML text files. They can be searched, indexed, scripted, and compressed, and can be created and edited with any text editor or drawing software. All major modern web browsers support SVG rendering.

History

SVG was developed by the W3C SVG Working Group starting in 1998, drawing on proposals such as PGML and VML. SVG 1.0 became a W3C Recommendation on 4 September 2001, and SVG 1.1 followed in January 2003, with a second edition in 2011. The SVG 2 specification adds features aligned with HTML5 and CSS.

Functionality

SVG supports basic shapes (rectangles, circles, ellipses, lines, polylines and polygons), paths described with Bézier curves, text, gradients, patterns, clipping, masking and filters. Because it is XML, SVG elements can be styled with CSS and manipulated with JavaScript through the Document Object Model, enabling interactive and animated graphics.

Applications

SVG is used for icons, logos, diagrams, maps, charts and user interface elements on the web, where its resolution independence and small file sizes are advantageous compared with raster formats such as PNG and JPEG.
