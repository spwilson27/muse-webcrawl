Breusch–Godfrey test

The Breusch–Godfrey test is a statistical test for autocorrelation in the errors of a regression model. It makes use of the residuals from the model being considered in a regression analysis, and a test statistic is derived from these. The null hypothesis is that there is no serial correlation of any order up to a specified order p. The test was developed independently by Trevor Breusch and Leslie Godfrey in 1978. Because it is based on the Lagrange multiplier principle, it is also known as the LM test for serial correlation.

Proposed byTrevor S. Breusch and Leslie G. Godfrey (1978)

Procedure

Consider a linear regression yt = β′xt + ut, estimated by ordinary least squares, with residuals ût. The test proceeds by an auxiliary regression of the residuals on the original regressors and on p lagged residuals, ût−1, …, ût−p. If the sample size is T, the statistic (T − p)R² from this auxiliary regression follows, under the null of no autocorrelation, an asymptotic chi-squared distribution with p degrees of freedom. An F-test version of the auxiliary regression is often preferred in finite samples.

Advantages and limitations

Unlike the older Durbin–Watson test, the Breusch–Godfrey test detects autocorrelation of arbitrary order (not just first-order) and remains valid when the regression includes lagged dependent variables, a setting in which Durbin–Watson is biased toward finding no autocorrelation. It also applies to moving-average errors, not only autoregressive ones. However, it is an asymptotic test and may have poor size or power in small samples; and it cannot identify which lag order is present without additional testing. Similar LM-based diagnostics include the Breusch–Pagan test for heteroskedasticity, developed by Breusch with Adrian Pagan in 1979.

Implementation

The test is implemented in most econometric software: as bgodfrey in R's lmtest package, acorr_breusch_godfrey in Python's statsmodels, bgodfrey in Stata, and in EViews and MATLAB's Econometrics Toolbox. It is a standard post-estimation diagnostic for time-series and dynamic panel regressions.
