Stored-program computer

ConceptInstructions and data held in the same memory
Key documentFirst Draft of a Report on the EDVAC (1945)
First working exampleManchester Baby (1948)

A stored-program computer is a computer that stores its program instructions in electronic memory, in the same format and address space as its data, rather than having its behaviour fixed by physical wiring or plugboards. This design, the basis of virtually all modern computers, allows a machine to change tasks by loading a new program and to treat programs themselves as data.

History

The concept was articulated in John von Neumann's 1945 First Draft of a Report on the EDVAC, building on discussions with the ENIAC team, and is often called the von Neumann architecture. The Manchester Baby, which ran its first program on 21 June 1948, was the first working stored-program computer; the Manchester Mark 1 and Cambridge EDSAC followed in 1949.
