Deb (file format)

Deb is the file format and the extension of the software package format used by the Debian Linux distribution and its many derivatives, including Ubuntu. Deb packages are installed and managed by the dpkg tool and front ends such as apt. The format has been in use since Debian 0.91 in 1994.

Structure

A .deb file is an ar archive containing three members: a debian-binary text file giving the format version; a control archive with the package's metadata (name, version, dependencies, description, and maintainer scripts); and a data archive containing the actual files to be installed, compressed with formats such as gzip, xz, or zstd. Package names follow the convention name_version_architecture.deb.

Use

Users typically install deb packages through package managers that resolve dependencies automatically from software repositories, though individual files can be installed directly with dpkg -i. Related tools include GDebi, the GNOME Software and KDE Discover front ends, and Alien, which converts packages between the deb and RPM formats used by other Linux families.
