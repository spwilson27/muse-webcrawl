Tangible user interface

A tangible user interface (TUI) is a user interface in which a person interacts with digital information through the physical environment. The term was coined by Hiroshi Ishii of the MIT Media Lab, whose Tangible Media group developed foundational systems in the 1990s. TUIs give physical form to digital information, allowing users to grasp and manipulate data directly, in contrast to the graphical user interface (GUI), where interaction is mediated through a screen and pointer.

Examples

Examples include the marble answering machine by Durrell Bishop, the metaDESK and Urp urban-planning systems, reacTable (a musical instrument with a tabletop interface), and commercial products such as Sifteo Cubes. The underlying technology may involve computer vision, RFID, sensors, and projection.

Characteristics

Key properties include physical representations coupled to underlying digital information, physical mechanisms for interactive control, and perceptual coupling between physical and digital representations.
