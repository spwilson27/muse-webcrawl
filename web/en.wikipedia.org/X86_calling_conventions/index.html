x86 calling conventions

Image placeholder: Diagram of a stack frame in the cdecl convention

The x86 calling conventions are a set of conventions governing how subroutines in x86 architecture receive parameters from their caller and how they return results. They include details of where data is placed (on the stack, in registers, or both) and who cleans up the stack.

Common conventions

cdecl, the C declaration convention, passes arguments on the stack, right to left, and the caller cleans up. stdcall, used by the Win32 API, has the callee clean the stack. fastcall passes the first arguments in registers (ECX and EDX in the Microsoft variant). On 64-bit systems, the Microsoft x64 convention and the System V AMD64 ABI each define register-based argument passing.

Importance

A calling convention mismatch between caller and callee corrupts the stack, so conventions form part of the application binary interface (ABI) of a platform.
