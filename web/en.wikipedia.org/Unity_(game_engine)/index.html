Unity (game engine)

Unity is a cross-platform game engine developed by Unity Technologies, first announced and released in June 2005 at Apple Worldwide Developers Conference as a Mac OS X game engine. The engine has since been gradually extended to support a variety of desktop, mobile, console, augmented reality, and virtual reality platforms. It is particularly popular for iOS and Android mobile game development and is considered easy to use for beginner developers.

Features

Unity provides a primary scripting API in C#, both for the editor in the form of plugins and for games themselves, as well as drag-and-drop functionality. The engine supports 2D and 3D graphics, physics engines (NVIDIA PhysX for 3D and Box2D for 2D), real-time rendering pipelines, animation, audio, and networking. The Unity Asset Store, launched in 2010, lets developers buy and sell models, tools, and code. As of the late 2010s, games made with Unity accounted for a substantial share — by some measures more than half — of all mobile games.

History

Unity Technologies was founded in Copenhagen, Denmark, in 2004 by David Helgason, Nicholas Francis, and Joachim Ante. After early success with the web player and iPhone support in 2008, the engine expanded rapidly. Well-known games built with Unity include Pokémon Go, Hearthstone, Cuphead, Hollow Knight, Cities: Skylines, and Among Us. A 2023 proposal to charge a per-install "Runtime Fee" provoked a major backlash from developers and was substantially revised and later cancelled.
