HTTP 404

The HTTP 404 Not Found response status code indicates that a web server could not find the resource requested by the client. It is one of the most widely recognised error messages on the World Wide Web, commonly displayed when a user follows a broken or dead link, mistypes a URL, or requests a page that has been moved or deleted.

Meaning and usage

In the HTTP standard, the 404 status belongs to the 4xx class of client error responses. The specification states that the origin server did not find any current representation for the target resource. A 404 does not indicate whether the absence is temporary or permanent; the 410 Gone status is used when the resource is known to be permanently removed. Servers customise 404 pages with site branding, search boxes, and links, partly to help users and partly because search engines treat "soft 404" pages — error pages returned with a success status — as a quality problem.

Error message conventions

The familiar "404 Not Found" phrase originates in the early HTTP specifications edited by Tim Berners-Lee's team at CERN. Popular folk etymologies — such as a "room 404" where web servers were supposedly housed — are unfounded. Web servers may also log and report sub-status codes, and Internet Explorer and other clients have historically substituted their own error pages when a server's 404 response was too small.
