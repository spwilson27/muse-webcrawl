Subnet

A subnet (short for subnetwork) is a logical subdivision of an Internet Protocol (IP) network. Dividing a network into subnets, called subnetting, improves routing efficiency, administration, and security by grouping hosts that communicate most frequently and by limiting broadcast traffic.

Subnet
Field: Computer networking
Notation: CIDR, e.g. 192.168.1.0/24
Defined by: Subnet mask

Subnet masks

An IPv4 address consists of a network portion and a host portion. The subnet mask—a 32-bit number such as 255.255.255.0—indicates which bits identify the network. In CIDR notation the same information is written as a prefix length: /24 means the first 24 bits are the network prefix, leaving 256 addresses, of which 254 are usable for hosts.

Benefits

Subnetting lets organizations allocate address space hierarchically, isolate departments or security zones, and reduce the size of routing tables through route aggregation.

IPv6

IPv6 networks are usually subnetted with /64 prefixes, allowing stateless address autoconfiguration, and the vast address space makes conservation concerns largely moot.
