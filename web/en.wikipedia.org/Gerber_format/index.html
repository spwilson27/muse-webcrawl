The Gerber format is an open ASCII vector format used by printed circuit board (PCB) manufacturers to describe the images of a board design: copper layers, solder mask, legend printing and paste layers, as well as drill and milling data. It is the de facto standard for PCB fabrication data exchange worldwide.

History

The format originated in the 1960s and 1970s as the command language for Gerber Systems Corporation's photoplotters, machines that drew PCB artwork on film. The original RS-274-D version relied on a separate "aperture wheel" file; the Extended Gerber format (RS-274X, introduced in the 1990s) embedded apertures and other parameters in the file itself. The format is now maintained by Ucamco, a Belgian company that acquired Gerber Systems.

Structure

A Gerber file describes a 2D binary image using commands to set apertures (shapes such as circles, rectangles and custom macros), draw lines and arcs, flash pads, and fill regions. Files use format specification commands to declare units, coordinate precision and image polarity. A complete PCB job typically consists of one Gerber file per layer plus drill files, often in the related Excellon format.

Gerber Layer Format (2020 revision)

Recent revisions of the specification added file attributes that identify each file's function (such as top copper or bottom solder mask), part identity, and netlist and component information in the "Gerber job file". These additions aim to automate the transfer of a full fabrication data package from designer to manufacturer.
