Rust is a general-purpose programming language emphasizing performance, type safety and concurrency. It enforces memory safety without a garbage collector — through a system of ownership with rules checked at compile time by the borrow checker — preventing null pointer dereferencing, data races and use-after-free errors that plague systems programming in C and C++.

History

Rust began as a personal project of Mozilla employee Graydon Hoare in 2006; Mozilla formally sponsored it from 2009, using it to build the experimental Servo browser engine, and parts of Rust code shipped in Firefox from 2016. The first stable release, Rust 1.0, appeared in May 2015. After Mozilla's 2020 restructuring, stewardship passed to the Rust Foundation, formed in 2021 by Amazon Web Services, Google, Huawei, Microsoft and Mozilla.

Adoption

Rust is used for operating-system components (including support in the Linux kernel from version 6.1 and in Windows), command-line tools, WebAssembly, embedded systems and backend services. It was voted the "most loved" language in Stack Overflow's developer survey every year from 2016 for nearly a decade. A canonical first program prints println!("Hello, world!");.
