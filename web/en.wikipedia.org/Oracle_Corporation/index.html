Oracle Corporation is an American multinational computer technology company headquartered in Austin, Texas. It is one of the world's largest software companies, best known for the Oracle Database, enterprise software, and the Oracle Cloud Infrastructure platform. Oracle markets database management systems, enterprise resource planning (ERP), human capital management, and customer experience software, and it owns the Java programming language platform.

History

The company was founded in 1977 as Software Development Laboratories by Larry Ellison, Bob Miner, and Ed Oates. Inspired by Edgar F. Codd's papers on the relational model and by a CIA project code-named "Oracle," it released Oracle Version 2 in 1979—among the first commercial relational database management systems using SQL. Renamed Oracle Corporation, it went public in 1986. Aggressive sales practices and an accounting restatement in 1990 brought a crisis, but the company recovered and grew through the 1990s.

Acquisitions

Oracle expanded by buying rivals and adjacent firms: PeopleSoft (2005, after a hostile takeover battle), Siebel Systems (2006), BEA Systems (2008), and Sun Microsystems (2010), which brought Java and MySQL. Later deals included NetSuite (2016, co-founded by Ellison) and the health-records company Cerner (2022, for about $28 billion). The Sun acquisition led to the long-running Oracle v. Google copyright litigation over Java APIs in Android, which the U.S. Supreme Court decided in Google's favour in 2021 on fair-use grounds.

Cloud business

Long identified with on-premises software licences, Oracle pivoted to cloud computing with Oracle Cloud World offerings and its second-generation Oracle Cloud Infrastructure, competing with Amazon Web Services, Microsoft Azure, and Google Cloud. In 2020 Oracle moved its headquarters from Redwood Shores, California, to Austin, Texas. Ellison, long the CEO, became executive chairman and chief technology officer in 2014, with Safra Catz serving as chief executive.
