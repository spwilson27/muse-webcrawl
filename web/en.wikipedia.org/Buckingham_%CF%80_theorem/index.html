Buckingham π theorem

FieldDimensional analysis
Named afterEdgar Buckingham
Key resultEquations can be rewritten with p = n − k dimensionless groups

The Buckingham π theorem is a key theorem in dimensional analysis. It states that if there is a physically meaningful equation involving a certain number n of physical variables, then the original equation can be rewritten in terms of a set of p = n − k dimensionless parameters π1, π2, …, πp constructed from the original variables, where k is the number of fundamental physical dimensions involved (equivalently, the rank of the dimensional matrix). The theorem was published by American physicist Edgar Buckingham in 1914.

Statement

More formally, if a phenomenon depends on n dimensional variables q1, …, qn through a relation f(q1, …, qn) = 0, and the variables span k independent fundamental dimensions, then the relation can be expressed equivalently as F(π1, …, πp) = 0 with p = n − k dimensionless groups. The choice of dimensionless groups is not unique, but any complete set captures the same physics.

Applications

The theorem underlies the method of dimensional analysis used throughout physics and engineering. Famous dimensionless numbers—such as the Reynolds number in fluid mechanics and the Froude number in ship hydrodynamics—arise as π groups, allowing experiments on scale models to predict the behaviour of full-size systems, a principle known as similitude.

Example

For the period of a simple pendulum, the relevant variables are the period T, length L, mass m, and gravitational acceleration g—four variables spanning three dimensions (mass, length, time). The theorem therefore yields a single π group, which shows that the period is proportional to √(L/g) and independent of mass.
