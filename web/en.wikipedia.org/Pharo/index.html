Pharo

The Pharo integrated development environment.

Pharo is a free and open-source, dynamically typed, reflective programming language and integrated development environment (IDE) based on Smalltalk. Its name (pronounced "FAR-oh") comes from the French word phare, meaning lighthouse. Pharo emerged in 2008 as a fork of Squeak, an open-source Smalltalk implementation, with the goal of providing a clean, modern, and professionally usable Smalltalk system.

Features

Like other Smalltalks, Pharo is a pure object-oriented language in which everything is an object, programs are developed inside a live image-based environment, and code can be inspected and modified while it runs. Distinctive features include:

  • A fully integrated IDE with browser, inspector, debugger, and refactoring tools
  • Live coding: objects can be examined and changed at runtime, with the system continuing to operate
  • Metacello and package management for loading community libraries ("catalog" packages)
  • Web frameworks such as Seaside, and data-science and modeling platforms built on top, such as the Moose software-analysis platform and the Glamorous Toolkit

History and governance

Pharo was created by Stéphane Ducasse, Marcus Denker, and other former Squeak contributors, with an initial release in 2009. Development is coordinated by the Pharo Consortium (for industrial members) and the Pharo Association (for individuals), with research support from the Inria institute in France. The system is released annually in major versions and is distributed under the MIT license. A virtual machine shared with other Smalltalk dialects (the OpenSmalltalk VM) provides just-in-time compilation.
