GNU Compiler Collection

The GNU Compiler Collection (GCC) is a key component of the GNU toolchain: a free software compiler system produced by the GNU Project that supports various programming languages, hardware architectures, and operating systems. Originally released in 1987 by Richard Stallman as the "GNU C Compiler", GCC made possible the development of much of the free software ecosystem, including the Linux kernel.

History

Stallman began work on GCC in 1985 and released version 1.0 in March 1987; it was soon extended to compile C++, Objective-C, Fortran, Ada, Go, and other languages via separate front ends. In the late 1990s a fork called EGCS, driven by dissatisfaction with slow development, eventually became the official line (GCC 2.95, 1999). GCC is now governed by a steering committee and released under the GNU General Public License with a runtime library exception permitting proprietary programs compiled with it to be distributed.

Architecture

GCC follows a three-stage design. A language front end parses source code into an abstract syntax tree; the middle end converts this into the GIMPLE and then RTL intermediate representations and performs target-independent optimisations (such as inlining, constant propagation, loop optimisation, and vectorisation); and a back end generates assembly for the target machine. GCC supports an unusually broad range of targets, from large servers to embedded microcontrollers, and is extensively configurable through hundreds of command-line options. Its compilation is coordinated by driver programs such as gcc and g++.

Significance

GCC became the standard compiler for GNU/Linux and many BSD systems, and its existence as a portable, high-quality free compiler was pivotal in enabling independent operating-system development in the 1990s. It now competes and coexists with the LLVM/Clang toolchain, and remains central to systems programming, embedded development, and high-performance computing.
