Functional (mathematics)

From Wikipedia, the free encyclopedia

In mathematics, a functional is a mapping from a set of functions (or, more generally, from a vector space) to a field of scalars, usually the real or complex numbers. In other words, a functional takes a function as its input and returns a number. The concept is central to functional analysis and to the calculus of variations.

Examples

The definite integral J[f] = ∫ab f(x) dx is a functional: it assigns to each integrable function a single number. So is the evaluation functional f ↦ f(x0) and, in physics, the action S[q] = ∫ L dt, whose stationary points give the equations of motion of a system.

Linear functionals

A functional F is linear if F(af + bg) = aF(f) + bF(g). The set of all continuous linear functionals on a normed space forms its dual space, a fundamental object of study. On a Hilbert space, the Riesz representation theorem says every continuous linear functional is given by an inner product with a fixed vector. In distribution theory, functionals on spaces of test functions define generalised functions such as the Dirac delta.

Calculus of variations

The calculus of variations, developed by Euler and Lagrange, seeks functions that maximise or minimise a given functional. Finding the curve of shortest length between two points, the brachistochrone problem, and Fermat's principle in optics are classical examples; necessary conditions for an extremum are given by the Euler–Lagrange equation.
