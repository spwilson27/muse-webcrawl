Extreme value theorem

In calculus, the extreme value theorem states that if a real-valued function f is continuous on the closed and bounded interval [a, b], then f must attain a maximum and a minimum, each at least once: there exist points c and d in [a, b] with f(c) ≥ f(x) ≥ f(d) for every x in the interval.

Role of the hypotheses

Both hypotheses are essential. On the open interval (0, 1), the function f(x) = x is bounded but attains neither a maximum nor a minimum; the unbounded function 1/x on (0, 1] has no maximum; and a discontinuous function on [a, b] can jump over its supremum without ever taking that value. The theorem fails on infinite intervals for the same reason.

Proof and generalizations

Standard proofs rely on the completeness of the real numbers, via the Bolzano–Weierstrass theorem: a maximizing sequence has a convergent subsequence whose limit point lies in the interval, and continuity then forces the limit value to be attained. The theorem generalizes to continuous real-valued functions on any compact set in a topological space — the continuous image of a compact set is compact, hence closed and bounded, so it contains its supremum and infimum. In optimization, the theorem (often called the Weierstrass extreme value theorem) guarantees that candidate optima can be sought among interior critical points and boundary points, the standard method of first-semester calculus.
