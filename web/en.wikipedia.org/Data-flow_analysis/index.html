Data-flow analysis

Data-flow analysis is a technique for gathering information about the possible set of values calculated at various points in a computer program. A program's control-flow graph (CFG) is used to determine those parts of a program to which a particular value assigned to a variable might propagate.

Framework

Classical analyses are formulated as systems of equations over a lattice of data-flow facts, with transfer functions for each basic block and a meet (or join) operation combining facts from predecessor (or successor) blocks. Forward analyses, such as reaching definitions and available expressions, propagate information in the direction of execution; backward analyses, such as live-variable analysis and very busy expressions, propagate it in reverse. Iterative worklist algorithms compute the least fixed point of the equations.

Applications

Data-flow analysis underlies many compiler optimisations, including constant propagation, common subexpression elimination, dead-code elimination and register allocation via liveness analysis. It is also used in program verification and static analysis tools for detecting bugs and security vulnerabilities, such as taint tracking.
