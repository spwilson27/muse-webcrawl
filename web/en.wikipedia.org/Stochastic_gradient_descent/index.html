Stochastic gradient descent

Stochastic gradient descent (SGD) is an iterative method for optimizing an objective function with suitable smoothness properties, such as differentiability or subdifferentiability. It can be regarded as a stochastic approximation of gradient descent optimization, since it replaces the actual gradient of the function — calculated from the entire data set — by an estimate calculated from a randomly selected subset of the data. It is the dominant method for training machine learning models, particularly neural networks.

Method

In each iteration, a mini-batch of training examples is sampled, the gradient of the loss with respect to the parameters is estimated from that batch, and the parameters are updated in the opposite direction: θ := θ − η·∇̂L(θ), where η is the learning rate. Passing through the full data set once is called an epoch.

Background

The idea traces to the Robbins–Monro algorithm of stochastic approximation (1951). In the 1980s and 1990s SGD, combined with backpropagation, became the standard way to train neural networks, and from the 2010s it underpinned the deep learning revolution.

Variants

Popular extensions include momentum, Nesterov accelerated gradient, AdaGrad, RMSProp, and Adam, which adapt the learning rate or smooth the update direction. Learning-rate schedules, batch-size tuning, and gradient clipping are commonly used to stabilize training. Challenges include noisy updates, saddle points, and choosing hyperparameters.
