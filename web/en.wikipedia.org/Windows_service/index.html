Windows service

In Microsoft Windows, a Windows service is a computer program that operates in the background of a computer system. It is similar in concept to a Unix daemon. A Windows service must conform to the interface rules and protocols of the Service Control Manager, the component responsible for managing Windows services.

Operation

Services can be configured to start when the operating system is booted, run in the background as long as Windows is running, and be paused, stopped, or restarted without displaying any user interface. Services typically run under one of the system accounts — Local System, Network Service, or Local Service — rather than a specific user's account.

Management

Services are managed through the Services snap-in of the Microsoft Management Console, the sc.exe command-line utility, or PowerShell cmdlets such as Start-Service and Stop-Service. Each service registers a name, a display name, a description, and startup options (automatic, manual, or disabled).
