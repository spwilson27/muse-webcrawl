SQLite is a database engine written in the C programming language. It is not a standalone application; rather, it is a library that software developers embed in their apps. As such, it belongs to the family of embedded databases. It is the most widely deployed database engine, as it is built into all mobile phones and most computers and comes bundled inside countless other applications that people use every day. The file format is cross-platform, stable and backwards compatible, and the source code is dedicated to the public domain.

SQLite is linked directly into applications rather than running as a separate server.

Design

Unlike most other SQL databases, SQLite does not have a separate server process. It reads and writes directly to ordinary disk files; a complete SQL database with multiple tables, indices, triggers and views is contained in a single file. The library implements a full-featured, transactional SQL database engine that is self-contained, serverless and zero-configuration. Its dynamic type system and small footprint — under a megabyte of code — suit it to embedded systems, browsers, operating systems and mobile applications, including Android and iOS.

History

D. Richard Hipp designed SQLite in the spring of 2000 while working for General Dynamics on contract with the United States Navy, seeking a database that could operate without a database administrator for software aboard guided-missile destroyers. First released in August 2000, SQLite has since become ubiquitous; its developers recommend the file format as a long-term archival format, and it is recognised by the Library of Congress.
