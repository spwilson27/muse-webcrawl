Function (mathematics)

From Wikipedia, the free encyclopedia

[Image: Diagram of a function mapping each input x in set X to a single output f(x) in set Y]

In mathematics, a function from a set X to a set Y assigns to each element of X exactly one element of Y. The set X is called the domain of the function and the set Y is called the codomain of the function. A function f from X to Y is written f : X → Y, and the value of f at an element x is written f(x), read "f of x". The set of all values actually attained is the range (or image) of the function.

Functions were originally the idealisation of how a varying quantity depends on another quantity — for example, the position of a planet as a function of time. The modern, set-theoretic definition emerged in the 19th and 20th centuries through the work of Dirichlet, Dedekind and others, and functions are now fundamental objects throughout mathematics, logic and computer science.

Definition

Formally, a function is a relation between the domain and codomain such that every domain element is associated with exactly one codomain element. Equivalently, as a set of ordered pairs (x, y) with x ∈ X and y ∈ Y, no two pairs share the same first component with different second components. The graph of a function of a real variable is the set of points (x, f(x)) in the plane.

f(x) = x²   e.g. f(3) = 9, f(−2) = 4

Types and properties

  • Injective (one-to-one): distinct inputs give distinct outputs.
  • Surjective (onto): every element of the codomain is attained.
  • Bijective: both injective and surjective; such functions have inverses.
  • Composition: applying one function after another, (g ∘ f)(x) = g(f(x)).

Elementary examples include polynomials, trigonometric functions, exponentials and logarithms; more advanced classes include distributions and functors.

History

The term "function" was introduced by Leibniz in the 17th century for quantities related to a curve. Euler popularised the notation f(x). The 19th century broadened the concept to arbitrary correspondences, and 20th-century set theory settled the definition used today. In computer science, functions appear as subroutines and as the mappings studied in lambda calculus and computability theory.
