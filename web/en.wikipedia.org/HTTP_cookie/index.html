HTTP cookie

An HTTP cookie (also called a web cookie, Internet cookie, browser cookie, or simply cookie) is a small piece of data that a server sends to a user's web browser. The browser may store the cookie and send it back to the same server with later requests. Cookies are used to maintain stateful information over the stateless HTTP protocol — most commonly for session management, personalisation, and tracking user behaviour.

History

Cookies were invented in 1994 by Lou Montulli of Netscape Communications to implement a virtual shopping cart for an online store. Netscape Navigator supported them that year, and the mechanism was described in the first formal specification, RFC 2109 (1997). The current standard is RFC 6265 (2011) and its successor drafts. The name derives from the computing term "magic cookie".

How cookies work

A server sets a cookie with the Set-Cookie response header; the browser stores it (subject to attributes such as Domain, Path, Expires/Max-Age) and returns matching cookies in the Cookie header of subsequent requests. Security attributes include Secure (HTTPS only), HttpOnly (inaccessible to JavaScript, mitigating cross-site scripting theft), and SameSite (restricting cross-site sending, mitigating CSRF).

Types and uses

  • Session cookies are deleted when the browser closes and commonly hold a session ID for logged-in users.
  • Persistent cookies survive browser restarts until an expiry date and remember preferences and logins.
  • First-party cookies belong to the site being visited; third-party cookies, set by embedded content from other domains, underpin much online advertising and cross-site tracking.

Privacy and regulation

Tracking cookies have raised significant privacy concerns. Laws such as the EU's ePrivacy Directive and GDPR require consent for many cookies, producing the familiar cookie-consent banners, and modern browsers increasingly block or phase out third-party cookies. Alternatives and related technologies include local storage, fingerprinting, and "supercookies" that abuse other storage mechanisms.
