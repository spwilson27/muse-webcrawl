Principal component analysis

Principal component analysis (PCA) is a statistical technique for dimensionality reduction that transforms a set of possibly correlated variables into a set of linearly uncorrelated variables called principal components, ordered so that the first component captures the largest possible variance in the data, the second the next largest, and so on. It was invented by Karl Pearson in 1901 and developed by Harold Hotelling in the 1930s.

Principal components are orthogonal axes ordered by explained variance.

Method

PCA is computed by eigendecomposition of the data covariance (or correlation) matrix, or equivalently by the singular value decomposition of the centred data matrix. The principal components are the eigenvectors of the covariance matrix, and the proportion of variance explained by each is given by its eigenvalue divided by the sum of all eigenvalues. Retaining only the first few components yields a low-dimensional approximation of the data that minimises reconstruction error in the least-squares sense.

Applications and limitations

PCA is widely used for data visualisation, noise reduction, feature extraction, and compression, in fields from genomics and finance to image processing — in face recognition, the components are known as "eigenfaces." Its limitations include sensitivity to the scaling of variables, the restriction to linear transformations, and the fact that components maximizing variance are not necessarily those most useful for a particular prediction task. Nonlinear generalisations include kernel PCA and autoencoders.
