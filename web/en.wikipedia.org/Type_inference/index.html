Type inference

FieldProgramming language theory
Key algorithmHindley–Milner (Algorithm W)
Used inML, Haskell, OCaml, Rust, TypeScript (partial)

Type inference is the automatic detection of the type of an expression in a formal language, most commonly by a compiler in a statically typed programming language. Rather than requiring programmers to annotate every variable, the compiler deduces types from how values are used, combining concision with static safety.

Hindley–Milner inference

The classic algorithm, developed independently by J. Roger Hindley and Robin Milner, underlies the ML family of languages. It generates type equations from expressions and solves them by unification, yielding the principal type — the most general type consistent with the program. Milner's Algorithm W (1978) gave a practical formulation, extended with let-polymorphism so that generic functions can be used at several types.

Local and partial inference

Many mainstream languages infer only local types: Java and C# infer the types of variables declared with var, C++ uses auto, and TypeScript infers types from initialisers while still accepting annotations. Full global inference can become undecidable for richer type systems, so practical languages mix inference with explicit declarations, especially at function boundaries.

Benefits and trade-offs

Inference reduces boilerplate and keeps types consistent during refactoring, but inferred types can obscure an interface and sometimes produce cryptic error messages when unification fails far from the actual mistake.
