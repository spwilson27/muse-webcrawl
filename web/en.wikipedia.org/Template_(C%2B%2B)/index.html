Template (C++)

Templates are a feature of the C++ programming language that allows functions and classes to operate with generic types. This allows a function or class declaration to reference a value of an unspecified type until it is instantiated by the client code.

Overview

Templates are implemented by generating a separate copy of the templated function or class for each distinct type argument at compile time. Function templates, such as a generic max function, and class templates, such as std::vector<T>, are the foundation of the C++ Standard Library's containers and algorithms. C++ templates are Turing-complete, enabling template metaprogramming.

History and developments

Templates were introduced in C++ in the late 1980s under Bjarne Stroustrup's design. Later standards added variadic templates (C++11), variable templates (C++14), class template argument deduction (C++17), and concepts (C++20), which allow constraints to be placed on template parameters.
