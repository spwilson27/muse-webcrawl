Lazarus (software)

Lazarus is a free, open-source, cross-platform integrated development environment (IDE) for rapid application development using the Free Pascal compiler and the Lazarus Component Library (LCL). Modelled on Delphi, it lets developers write Object Pascal code once and compile for Windows, macOS, Linux and other platforms — its motto is "write once, compile anywhere".

Features

Lazarus offers a visual form designer closely resembling Delphi's, with drag-and-drop components whose look is mapped to native widgetsets (Win32, Cocoa, GTK, Qt) on each target. The LCL mirrors much of Delphi's VCL, easing porting of Delphi code.

History and use

Started in 1999 after the collapse of the earlier Megido project — hence the name, "raised from the dead" — Lazarus reached version 1.0 in 2012. It is used for commercial and hobbyist software worldwide, including in schools in some countries. See also Lazarus (David Bowie song).
