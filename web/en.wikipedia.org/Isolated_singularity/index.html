Isolated singularity

From Wikipedia, the free encyclopedia

Isolated singularity
FieldComplex analysis
DefinitionA point at which a function is not analytic, but is analytic at every nearby point
ClassificationRemovable singularity; pole; essential singularity
Key toolsLaurent series; Riemann's removable singularity theorem; Casorati–Weierstrass theorem; Picard's great theorem

In complex analysis, an isolated singularity of a function is a point at which the function is not defined (or not analytic), but which has a neighbourhood in which the function is analytic everywhere except at the point itself. Formally, a point a is an isolated singularity of f if there is a punctured disc 0 < |z − a| < r on which f is holomorphic. Singularities that are not isolated — such as the point 0 for f(z) = 1/sin(π/z), near which poles accumulate — behave very differently and are much harder to analyze.

Classification

Isolated singularities are classified into three types, most conveniently described by the function's Laurent series expansion around the point, whose "principal part" is the sum of terms with negative powers.

Removable singularity

If the principal part vanishes identically, the singularity is removable: the function stays bounded near the point, and by Riemann's removable singularity theorem it can be redefined at the point to become holomorphic there. Example: sin(z)/z at 0, which extends by the value 1.

Pole

If the principal part has finitely many non-zero terms, the point is a pole. The number of terms (the index of the highest negative power) is the order of the pole; near a pole, |f(z)| → ∞. Example: 1/z² has a pole of order 2 at 0. Functions whose only singularities are poles are called meromorphic.

Essential singularity

If the principal part has infinitely many non-zero terms, the singularity is essential. Near an essential singularity the function behaves wildly: by the Casorati–Weierstrass theorem its values are dense in the complex plane in every neighbourhood of the point, and by Picard's great theorem it takes every complex value infinitely often, with at most one exception. Example: e^(1/z) at 0.

Examples

  • (z² − 1)/(z − 1) has a removable singularity at z = 1.
  • 1/(z − 2)³ has a pole of order 3 at z = 2.
  • sin(1/z) has an essential singularity at z = 0.
  • The point at infinity can likewise be classified by examining f(1/z) at 0; polynomials, for instance, have a pole at infinity.
