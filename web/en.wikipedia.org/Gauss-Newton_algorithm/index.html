Gauss–Newton algorithm

The Gauss–Newton algorithm is an iterative method for solving non-linear least squares problems, named after Carl Friedrich Gauss and Isaac Newton. It is widely used for fitting a model function to data, for example in curve fitting, calibration, and parameter estimation in science and engineering.

Method

Given a set of residual functions — the differences between observed values and the predictions of a model depending on unknown parameters — the algorithm linearises the residuals around the current parameter estimate using a first-order Taylor expansion. The resulting linear least-squares subproblem is solved via the normal equations using the Jacobian matrix of the residuals, and the solution gives the step by which the parameters are updated. The process repeats until the parameter changes and the sum of squared residuals become sufficiently small.

Properties and variants

The Gauss–Newton method can be viewed as a modification of Newton's method that drops the second-derivative terms from the Hessian, making each iteration cheaper but providing only approximate curvature information. It converges rapidly when the residuals at the solution are small, but can fail or diverge when the starting point is far from the solution or the residuals are large. The Levenberg–Marquardt algorithm improves robustness by interpolating between Gauss–Newton steps and gradient descent. For large problems, quasi-Newton and iterative variants are used, and the method forms the basis of many standard nonlinear regression software routines.
