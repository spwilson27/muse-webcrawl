Network socket

A network socket is a software structure within a network node of a computer network that serves as an endpoint for sending and receiving data across the network. The structure and properties of a socket are defined by an application programming interface (API) for the networking architecture. Sockets are created only during the lifetime of a process of an application running in the node.

Properties

A socket is identified by the combination of a transport protocol (such as TCP or UDP), the local IP address and port number, and, for an established connection, the remote address and port. The operating system forwards data arriving at a socket to the correct process using these identifiers.

History

The socket API originated with the Berkeley Software Distribution (BSD) Unix system in 1983, in the form of Berkeley sockets, and was later adopted, with variations, by essentially all major operating systems. The Winsock API brought the model to Microsoft Windows.

Types

Common socket types include stream sockets (connection-oriented, usually TCP), datagram sockets (connectionless, usually UDP), and raw sockets, which give applications more direct access to lower-level protocol data. Unix domain sockets provide a related abstraction for inter-process communication on a single machine.
