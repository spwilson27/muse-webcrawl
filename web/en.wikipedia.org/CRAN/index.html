CRAN

The Comprehensive R Archive Network (CRAN) is a network of servers around the world that store identical, up-to-date versions of code and documentation for the R programming language. It is the primary repository for contributed R packages, modelled in part on similar archive networks such as CTAN for TeX and CPAN for Perl.

Overview

CRAN's main site is hosted at the Vienna University of Economics and Business in Austria, and a worldwide network of mirror sites distributes its contents. The archive hosts the source code of R itself for multiple operating systems, pre-compiled binaries, documentation, and a large collection of contributed add-on packages.

Packages

Contributed packages on CRAN cover areas including statistics, machine learning, data visualization, econometrics, bioinformatics, and spatial analysis. Packages submitted to CRAN must pass a series of automated and manual checks for quality, portability, and licensing, and maintainers are expected to keep their packages working with current versions of R. By the 2020s, the number of available packages exceeded 20,000.

Use

Users typically install packages from CRAN from within R using the install.packages() function, which downloads and installs the package and its dependencies from a chosen mirror. CRAN also publishes task views that group packages by subject area to help users find relevant tools.
