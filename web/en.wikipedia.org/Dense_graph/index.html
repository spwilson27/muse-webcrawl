Dense graph

In mathematics, a dense graph is a graph in which the number of edges is close to the maximal number of edges (where every pair of vertices is connected by an edge). The opposite, a graph with only a few edges, is a sparse graph. The distinction between sparse and dense graphs is rather vague, and depends on the context.

Definitions

For an undirected simple graph with n vertices, the maximum possible number of edges is n(n−1)/2, the number in a complete graph. A graph is often called dense if its number of edges is Θ(n²) — that is, proportional to the maximum — and sparse if its number of edges is O(n) or otherwise much smaller than the maximum. Some authors define density precisely as the ratio of the actual number of edges to the number of possible edges, a value between 0 and 1.

Algorithmic consequences

Density influences the choice of data structure and algorithm in graph processing. Dense graphs are usually represented by an adjacency matrix, which uses Θ(n²) space but allows constant-time edge lookups, whereas sparse graphs favor adjacency lists, which use space proportional to the number of edges. Algorithms such as Floyd–Warshall are suited to dense graphs, while algorithms like Dijkstra's with a good priority queue are more efficient on sparse graphs. Densest subgraph problems and dense subgraph discovery are also active topics in the analysis of large networks.
