Scientific computing

High-performance computers are central tools of scientific computing.

Scientific computing (also called computational science) is the use of advanced computing capabilities to understand and solve complex scientific problems. It combines applied mathematics, numerical analysis, and computer science to construct mathematical models and quantitative analysis techniques, using simulation and computation alongside theory and experiment.

Areas

Core areas include numerical linear algebra, numerical solution of ordinary and partial differential equations, optimisation, Monte Carlo methods, and computational statistics. Application domains include computational physics, chemistry, biology, fluid dynamics, weather forecasting, and materials science.

Tools

Early scientific computing relied heavily on Fortran; today widely used environments include MATLAB, Julia, and the Python ecosystem built around NumPy and SciPy. Computations of the largest scale run on supercomputers and clusters, often exploiting parallel processing and GPU acceleration. Established software libraries such as BLAS, LAPACK, and PETSc underpin many applications.

Reproducibility

Because results depend on code, data, and computing environments, the field has increasingly emphasised reproducible research: sharing source code, version control, and containerised environments so that published computations can be independently verified.
