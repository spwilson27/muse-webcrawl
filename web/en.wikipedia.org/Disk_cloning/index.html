Disk cloning

Disk cloning is the process of copying the entire contents of a computer storage device, such as a hard disk drive or solid-state drive, to another storage medium or to an image file. Unlike ordinary file copying, cloning transfers the complete structure of the disk, including the operating system, applications, settings, hidden files and empty space layout.

Uses

Cloning is used to provision many computers with an identical system image, to migrate a system to a larger or faster drive, to create full backups for disaster recovery, and in digital forensics, where bit-for-bit images preserve evidence.

Methods

Software such as Clonezilla, Acronis True Image and the Unix utility dd can clone sector by sector or copy only used data blocks ("smart" cloning), and can compress the resulting image. Disk imaging differs subtly from cloning in that the copy is stored as a file for later restoration rather than written immediately to a bootable drive.
