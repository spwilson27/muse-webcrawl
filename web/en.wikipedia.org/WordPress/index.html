WordPress

WordPress is a free and open-source content management system (CMS) written in PHP and paired with a MySQL or MariaDB database. Originally created as a blog-publishing system by Matt Mullenweg and Mike Little in 2003 as a fork of b2/cafelog, it has grown into the world's most popular website platform, powering more than 40% of all websites.

Features

WordPress is built around themes, which control appearance, and plugins, which extend functionality; tens of thousands of both are available, enabling blogs, business sites, portfolios and full e-commerce stores (via the WooCommerce plugin). Since version 5.0 (2018) the default editor has been the block-based Gutenberg editor. WordPress can be self-hosted from wordpress.org, or used through the hosted WordPress.com service run by Automattic.

Community and governance

The WordPress Foundation holds the trademarks, and development is carried out by a large volunteer community coordinated through wordpress.org, with regular worldwide WordCamp conferences. Its open-source licence and extensibility made WordPress dominant, though it also attracts criticism for security vulnerabilities in third-party plugins and for performance overhead.
