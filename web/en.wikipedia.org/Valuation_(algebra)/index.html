Valuation (algebra)

From Wikipedia, the free encyclopedia

In algebra (particularly in algebraic number theory and algebraic geometry), a valuation is a function on a field that provides a measure of size or multiplicity. The most common type is an absolute value (also called a valuation), denoted |·|, satisfying:

|x| ≥ 0, with |x| = 0 iff x = 0
|xy| = |x| · |y|
|x + y| ≤ |x| + |y|  (triangle inequality)

The p-adic absolute value: numbers divisible by high powers of p are "small".

Types

  • Archimedean valuations: equivalent to the usual absolute value on the real or complex numbers (Ostrowski's theorem classifies all such on &8474;).
  • Non-archimedean (ultrametric) valuations: satisfy the strong triangle inequality |x + y| ≤ max(|x|, |y|). The p-adic absolute values |·|p are the canonical examples.
  • Discrete valuations: a surjective map v: K* → &8484; (additive notation) with v(xy) = v(x) + v(y) and v(x + y) ≥ min(v(x), v(y)). These correspond to discrete valuation rings.

Applications

Valuations are central to the theory of local fields, ramification in number fields, and the study of curves in algebraic geometry, where the order of vanishing of a function at a point is a discrete valuation.
