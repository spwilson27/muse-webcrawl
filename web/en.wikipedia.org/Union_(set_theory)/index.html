Union (set theory)

The union of two sets A and B is the shaded region covering both circles.

In set theory, the union (denoted by ∪) of a collection of sets is the set of all elements in the collection. It is one of the fundamental operations through which sets can be combined and related to each other.

Union of two sets

The union of two sets A and B, denoted A ∪ B, is the set of all elements that are members of A, or members of B, or both. For example, {1, 2} ∪ {2, 3} = {1, 2, 3}. A set has no duplicate elements, so the element 2 appears only once.

Algebraic properties

Union is commutative (A ∪ B = B ∪ A) and associative ((A ∪ B) ∪ C = A ∪ (B ∪ C)). The empty set is an identity element: A ∪ ∅ = A. Union distributes over intersection, and together the two operations make the power set of a set into a Boolean algebra. Union is also idempotent: A ∪ A = A.

Arbitrary unions

The union may be taken over an arbitrary, possibly infinite, collection of sets, finite or infinite in number. In axiomatic set theory, the existence of such unions is guaranteed by the axiom of union.
