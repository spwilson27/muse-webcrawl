Functional programming

Programming paradigm based on mathematical functions

Functional programming is a programming paradigm in which programs are constructed by applying and composing functions, treating computation as the evaluation of mathematical functions and avoiding changing state and mutable data. It is rooted in Alonzo Church's lambda calculus of the 1930s and emphasises pure functions — whose outputs depend only on their inputs, without side effects — together with first-class and higher-order functions, recursion and immutable data structures.

Concepts

Core concepts include referential transparency (an expression can be replaced by its value without changing behaviour), lazy versus strict evaluation, pattern matching, algebraic data types, and abstractions such as map, filter and fold (reduce), and in languages like Haskell, monads for structuring effects. Immutability makes programs easier to reason about and naturally suited to parallel and concurrent execution, since independent computations cannot interfere through shared state.

Languages and influence

Lisp (1958) was the first functional language; later languages include ML, Haskell, Erlang, Clojure, Scala, F#, OCaml and Elixir. Ideas from functional programming — lambdas, closures, list comprehensions, immutability and higher-order library functions — have been adopted by mainstream languages such as JavaScript, Python, Java and C++, and functional styles underpin large-scale data systems such as MapReduce and Apache Spark.
