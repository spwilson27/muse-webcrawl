System of linear equations

In mathematics, a system of linear equations (or linear system) is a collection of one or more linear equations involving the same variables. For example,

3x + 2y − z = 1
2x − 2y + 4z = −2
−x + ½y − z = 0

is a system of three equations in the three variables x, y and z. A solution to a linear system is an assignment of values to the variables such that all the equations are simultaneously satisfied.

Matrix form

Every linear system can be written as a matrix equation Ax = b, where A is a matrix of coefficients, x is a vector of variables, and b is a vector of constants. The system has a unique solution exactly when A has full rank and the system is consistent; it may also have no solution or infinitely many.

Solution methods

Classical methods of solution include substitution, elimination, and Gaussian elimination, which reduces the augmented matrix to row echelon form. Cramer's rule gives explicit solutions for square systems using determinants. In numerical practice, large systems are solved with iterative methods such as the conjugate gradient method.

Applications

Linear systems arise throughout science and engineering: in structural analysis, electrical circuit theory, economics (input–output models), computer graphics and the discretisation of differential equations.
