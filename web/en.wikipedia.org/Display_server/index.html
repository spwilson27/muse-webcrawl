Display server

A display server or window server is a program whose primary task is to coordinate the input and output of its clients to and from the rest of the operating system, the hardware, and each other. The display server communicates with its clients over the display server protocol, which can be network-transparent, allowing graphical applications to run on a machine different from the one displaying them.

Protocols and implementations

The best-known display server protocol is the X Window System's X11, implemented by the X.Org Server; in the X architecture a separate window manager, and optionally a compositing manager, work alongside the server. Wayland is a newer protocol in which the display server and compositor are combined, with implementations such as Weston, Mutter, and KWin serving both roles and supporting X applications through the XWayland compatibility layer. Apple's macOS uses the proprietary Quartz Compositor as its window server, and Microsoft's Desktop Window Manager fills an analogous role on Windows.

Functions

Display servers manage the framebuffer, route keyboard and pointer events to the focused client, and provide the drawing and windowing primitives by which graphical user interfaces are rendered on screen. In compositing architectures they assemble the final image from each application's buffer, enabling effects such as transparency and smooth window movement.
