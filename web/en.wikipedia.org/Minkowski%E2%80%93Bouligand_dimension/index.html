Minkowski–Bouligand dimension

In fractal geometry, the Minkowski–Bouligand dimension, also known as the Minkowski dimension or box-counting dimension, is a way of determining the fractal dimension of a set in a Euclidean space, named after Hermann Minkowski and Georges Bouligand.

Definition

To compute the dimension of a fractal set S, one counts N(ε), the number of boxes of side length ε needed to cover S, and examines how N(ε) grows as ε shrinks. The box-counting dimension is defined as the limit, when it exists, of log N(ε) / log(1/ε) as ε → 0. When the limit does not exist, upper and lower box dimensions are defined using limit superior and limit inferior.

Properties and computation

For smooth objects the box dimension agrees with the ordinary topological dimension; for fractals such as the coastline of Britain it yields non-integer values (about 1.25 measured by Lewis Fry Richardson). Box counting is popular in applications because it is straightforward to estimate from images by covering them with grids of decreasing size, though it can be sensitive to discretization and counts empty structure differently from the Hausdorff dimension, to which it is generally an upper bound.
