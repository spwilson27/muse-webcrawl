PostgreSQL (also known as Postgres) is a free and open-source relational database management system (RDBMS) emphasising extensibility and SQL compliance. It was originally named POSTGRES, referring to its origins as a successor to the Ingres database developed at the University of California, Berkeley. In 1996, the project was renamed to PostgreSQL to reflect its support for SQL. After more than 20 years of development, PostgreSQL has earned a strong reputation for its reliability, feature set, and performance.

Features

PostgreSQL features transactions with atomicity, consistency, isolation, and durability (ACID) properties, automatically updatable views, materialised views, triggers, foreign keys, and stored procedures. It supports a wide range of native data types, including JSON/JSONB, arrays, geometric types, and user-defined types, and it can be extended with custom functions written in many languages. Concurrency is handled by multiversion concurrency control (MVCC). The PostGIS extension makes it a leading geospatial database.

History

The POSTGRES project, led by Michael Stonebraker, began in 1986 as a "post-Ingres" research system. After Berkeley released the code, two graduates added an SQL interpreter and released Postgres95 in 1995; the renamed PostgreSQL 6.0 followed in 1997. Development continues under the PostgreSQL Global Development Group, with a major release each year. PostgreSQL is the default database for macOS Server and is widely used by web applications and cloud services.
