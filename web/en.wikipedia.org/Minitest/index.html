Minitest is a testing framework for the Ruby programming language. It provides a complete suite of testing facilities supporting test-driven development (TDD), behavior-driven development (BDD), mocking, and benchmarking, and for many years shipped as a default gem with Ruby itself.

Features

Minitest supports two main syntax styles: an assertion-based test style (Minitest::Test) and a specification style using describe/it blocks. It has a small, fast core, a plugin architecture for reporters and extensions, and built-in support for mocks and stubs and performance benchmarking. Its design philosophy emphasizes simplicity and minimalism compared with larger frameworks.

Comparison

Minitest is one of the two most widely used Ruby test frameworks, the other being RSpec. Where RSpec provides a rich domain-specific language, Minitest stays close to plain Ruby, which appeals to developers preferring less magic in their test suites.
