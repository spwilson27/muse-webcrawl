0 (zero) is a number representing an empty quantity and the digit used to denote it in positional numeral systems. Adding 0 to any number leaves that number unchanged, so 0 is the additive identity of the integers, real numbers, and many other algebraic structures. As a digit, 0 makes positional notation possible, allowing a finite set of symbols to express arbitrarily large numbers.

History

Placeholder zeros appeared in Babylonian sexagesimal notation and in the Maya calendar's shell glyph. The decisive step — zero as a number in its own right, with rules for arithmetic — was taken in India: the Bakhshali manuscript contains an early dot symbol, and in 628 CE Brahmagupta's Brāhmasphuṭasiddhānta gave rules for computing with zero and negative numbers. The concept passed through the Islamic world — where al-Khwarizmi described the Indian system — to Europe via Fibonacci's Liber Abaci (1202). The word "zero" derives from Arabic ṣifr, itself a translation of Sanskrit śūnya, "empty".

Mathematical properties

Zero is even, neither positive nor negative, and neither prime nor composite. Multiplication by zero always gives zero, and division by zero is undefined in ordinary arithmetic, since no number multiplied by 0 yields a nonzero result. Zero is the identity for addition, the number of elements of the empty set, and the origin of coordinate systems. In modern set theory, 0 is identified with the empty set in the von Neumann construction of the natural numbers.
