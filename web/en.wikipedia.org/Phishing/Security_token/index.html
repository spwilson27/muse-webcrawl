Security token

A security token is a physical device used to prove identity in authentication: the user presents something they know (a password) together with something they have (the token). Early tokens displayed changing one-time passwords on a small screen; modern USB and NFC keys implement the FIDO2/WebAuthn standards and function as the hardware form of a passkey.

Tokens and phishing

Display tokens raise the cost of phishing but share the OTP weakness: a code typed into a fake page can be relayed to the real service in real time. Origin-bound security keys remove that weakness — the key signs a challenge only for the legitimate domain and refuses to produce a usable response for a look-alike site — which is why hardware keys are mandated for administrators and recommended for high-risk users such as executives targeted by whaling, journalists and cryptocurrency holders.

Trade-offs

Tokens can be lost, and enrolment and recovery procedures must be guarded, since a help-desk reset is itself a social-engineering target of the kind Kevin Mitnick exploited. Even so, incident analyses repeatedly find that accounts protected by hardware keys experience near-zero successful phishing takeovers compared with those relying on passwords alone.
