One-time password

A one-time password (OTP) is an automatically generated code, valid for a single login session or transaction, used as an additional factor of authentication. Common forms are time-based codes (TOTP) from authenticator apps, which change every thirty seconds, event-based codes (HOTP), and codes delivered by SMS or email.

Why one-time passwords do not stop phishing

OTPs defeat replay of stolen static passwords, because an old code is worthless. Against phishing, however, they have a structural weakness: the code is a shared secret typed by the user wherever the page asks. Modern phishing kits operate as real-time relays — the victim enters the password and code on the fake site, the kit immediately submits them to the genuine service, and the resulting authenticated session cookie is captured. The code was used exactly once, but by the attacker. SMS codes are additionally vulnerable to SIM-swapping and interception, which is why standards bodies discourage them.

Phishing-resistant successors

The recognised fix is to bind the second factor to the legitimate site's origin, as FIDO2 passkeys and hardware security tokens do: the authenticator signs a challenge for the real domain only, so a relay site receives nothing it can reuse. Until such methods are universal, OTPs remain a useful but partial defence, especially valued against bulk credential theft from a data breach.
