Multi-factor authentication (MFA; two-factor authentication, or 2FA, along similar terms) is an electronic authentication method in which a user is granted access to a website or application only after successfully presenting two or more pieces of evidence (or factors) to an authentication mechanism. MFA protects user data — which may include personal identification or financial assets — from being accessed by an unauthorized third party.

Authentication factors

Authentication takes place when someone tries to log into a computer resource. Factors are traditionally grouped into three categories: knowledge factors (something the user knows, such as a password), possession factors (something the user has, such as a smartphone or hardware security key), and inherence factors (something the user is, such as a fingerprint or facial scan). A genuine MFA scheme requires factors from at least two different categories.

Methods

Common second factors include one-time passwords generated by authenticator apps (TOTP), codes sent by SMS or email, push notifications to a registered device, and hardware tokens implementing the FIDO2/WebAuthn standards. SMS codes are now considered weaker because of SIM-swapping attacks, and standards bodies recommend against them where alternatives exist.

Security considerations

MFA substantially reduces the risk of account takeover from stolen passwords, but it is not invulnerable: real-time phishing proxies can relay codes, and "MFA fatigue" attacks bombard users with push requests until one is approved. Phishing-resistant methods such as passkeys and hardware security keys address these weaknesses.
