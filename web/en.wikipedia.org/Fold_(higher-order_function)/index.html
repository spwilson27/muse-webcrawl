Fold (higher-order function)

In functional programming, a fold (also termed reduce, accumulate, aggregate, compress, or inject) is a family of higher-order functions that analyze a recursive data structure — typically a list — and, by applying a combining operation to the elements and a starting value, build up a single return value. Folding is one of the most general patterns of computation over lists, corresponding to the catamorphism in category theory.

Left and right folds

A left fold (foldl) processes elements from the head of the list, threading an accumulator through the list in order: foldl f z [a,b,c] = f (f (f z a) b) c. A right fold (foldr) associates from the end: foldr f z [a,b,c] = f a (f b (f c z)). In lazy languages such as Haskell, right folds can operate on infinite lists when the combining function is lazy in its second argument, whereas left folds run in constant stack space but cannot return results before consuming the whole input.

Examples

sum     = foldl (+) 0
product = foldr (*) 1
length  = foldl (\acc _ -> acc + 1) 0

Many familiar list functions — map, filter, reverse, maximum — can be expressed as folds, a fact formalized in the "universality of fold" and exploited in program-transformation systems. Parallel variants such as MapReduce generalize the same idea to distributed data.

Other structures

The concept extends beyond lists: fold-like operations exist for trees, options (Maybe), and other algebraic data types, where the fold replaces each constructor of the structure with a corresponding function.
