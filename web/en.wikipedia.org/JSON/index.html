JSON

JSON (JavaScript Object Notation) is a lightweight, text-based data interchange format derived from JavaScript object syntax and popularised by Douglas Crockford in the early 2000s. It is language-independent and standardised as RFC 8259 and ECMA-404.

Syntax

JSON values are objects (key–value pairs in braces), arrays, strings in double quotes, numbers, booleans and null. Example: {"name":"example","count":3,"tags":["a","b"]}.

Uses

JSON is the dominant format for web APIs, configuration files and data storage, largely displacing XML for many uses because it is simpler and maps naturally to data structures.

Limitations

JSON has no comments, dates or binary type natively, prompting extensions and related formats such as JSON5, BSON and JSON Lines.
