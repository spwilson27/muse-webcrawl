Stabilizer code

In quantum information and quantum computing, a stabilizer code is a class of quantum codes for performing quantum error correction. The traditional theory of stabilizer formalism was mainly developed by Daniel Gottesman and by A. R. Calderbank, Peter Shor and Andrew Steane. Standard codes such as the [[7,1,3]] Steane code and the five-qubit code can be represented in the stabilizer formalism.

The stabilizer formalism is a method to describe states, measurements, and operations on states by tracking the Pauli operators that stabilize the state. A stabilizer code is defined as the vector space stabilized by an abelian subgroup of the Pauli group.

Formalism

The Pauli group on n qubits is the group generated by tensor products of the Pauli matrices X, Y, Z together with the identity and phases. A stabilizer group is an abelian subgroup of this group that does not contain −I. The codespace of the stabilizer code is the set of states that are fixed by every element of the stabilizer group; each stabilizer generator contributes one independent constraint, halving the dimension of the codespace.

An [[n, k, d]] stabilizer code encodes k logical qubits into n physical qubits with code distance d. Errors are detected by measuring the stabilizer generators: an error that anticommutes with a generator flips the sign of the corresponding measurement outcome, producing a syndrome that identifies the error without disturbing the encoded information.

Examples

The five-qubit code is the smallest code that protects an arbitrary single-qubit state against an arbitrary single-qubit error. The Steane code, based on the classical [7,4,3] Hamming code, is a Calderbank–Shor–Steane (CSS) code whose transversal structure makes it especially attractive for fault-tolerant quantum computation. Surface codes, the leading candidates for practical fault-tolerant quantum computers, can also be understood within the stabilizer framework.
