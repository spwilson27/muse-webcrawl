WebGL

WebGL (short for Web Graphics Library) is a JavaScript API for rendering interactive 2D and 3D graphics within any compatible web browser without the use of plug-ins. WebGL is fully integrated with other web standards, allowing GPU-accelerated physics, image processing, and effects as part of a web page canvas.

Design

Developer: Khronos Group
Initial release: March 2011
Platform: Cross-platform
Type: API

WebGL 1.0 is based on OpenGL ES 2.0 and provides a shader-based pipeline programmed in GLSL ES. It exposes the HTMLCanvasElement through a rendering context (webgl). WebGL 2.0, based on OpenGL ES 3.0, added features such as multiple render targets, 3D textures, and transform feedback, and became widely available in browsers by 2022. Programming WebGL directly is verbose, so most developers use libraries and engines such as Three.js, Babylon.js, or game engines like Unity and Godot that export to WebGL.

History

WebGL originated in experiments by Vladimir Vukićević at Mozilla in 2006 and was adopted by the Khronos Group, which published the 1.0 specification in March 2011. Support followed in Chrome, Firefox, Safari, and later Edge. Khronos has since developed WebGPU as a modern successor API.

Applications

WebGL powers browser games, data visualization, virtual product configurators, mapping applications such as Google Maps' 3D mode, and online CAD and medical imaging tools.
