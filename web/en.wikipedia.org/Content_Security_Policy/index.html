Content Security Policy

Content Security Policy (CSP) is an added layer of security that helps to detect and mitigate certain types of attacks, including cross-site scripting (XSS) and data injection attacks. It is a World Wide Web Consortium (W3C) recommendation.

A policy is delivered by a web server to a web browser via the Content-Security-Policy HTTP response header, instructing the browser which sources of content — scripts, stylesheets, images, fonts, and more — are permitted to load for a page. Directives such as default-src, script-src, and object-src whitelist trusted origins; values like 'self', 'none', and cryptographic nonces or hashes further restrict what may execute.

History

The concept was introduced by Mozilla; an early header, X-Content-Security-Policy, shipped in Firefox 4 in 2011. The W3C published the first CSP specification in 2012, and CSP Level 2 followed with broader browser support. A report-only mode, using the Content-Security-Policy-Report-Only header, lets sites audit violations without enforcement.
