Linux namespaces

Namespaces are a feature of the Linux kernel that partition kernel resources so that one set of processes sees one set of resources while another set sees a different set. Resources — such as process IDs, hostnames, user IDs, network interfaces, and mount points — are wrapped in separate namespaces, providing a lightweight form of isolation that is the foundation of Linux containers.

Types of namespace

The kernel provides several namespace types: mount (filesystem mount points), PID (process IDs), network (interfaces, routing tables, firewall rules), IPC (System V IPC and POSIX message queues), UTS (hostname and domain name), user (UID/GID mapping), cgroup (cgroup root visibility), and time (system clocks). Processes are placed in namespaces via the clone(), unshare(), and setns() system calls, and namespaces are visible under /proc/[pid]/ns/.

Use in containers

Container runtimes such as Docker, LXC, and containerd combine namespaces (for isolation of views) with cgroups (for resource limits) to run processes in environments that appear to be separate machines. User namespaces additionally allow unprivileged users to create namespaces in which they have virtual root privileges, enabling rootless containers.
