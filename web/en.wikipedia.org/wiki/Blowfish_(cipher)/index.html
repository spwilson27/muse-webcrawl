Blowfish (cipher)

DesignerBruce Schneier (1993)
Block size64 bits
Key size32–448 bits
Rounds16

Blowfish is a symmetric-key block cipher designed in 1993 by Bruce Schneier as a fast, free alternative to existing encryption algorithms. It operates on 64-bit blocks with a variable key length from 32 to 448 bits and uses a 16-round Feistel network. Blowfish was placed in the public domain, unpatented and royalty-free, and became widely used in software such as password managers, file encryption tools and the bcrypt password hashing function.

Design

Blowfish's subkeys are generated by an expensive key schedule that expands the key using the hexadecimal digits of π. The P-array consists of 18 32-bit subkeys and four S-boxes each contain 256 entries. Encryption splits the block into two 32-bit halves; each round XORs the left half with a P-array entry, passes it through the F-function built from the S-boxes, and XORs the result into the right half before swapping. The slow key setup — requiring 521 iterations of the cipher — is deliberate and was exploited in bcrypt to make password hashing costly for attackers.

Security and successors

No practical attack against full-round Blowfish is known, but its 64-bit block size makes it vulnerable to birthday-bound attacks (such as the Sweet32 attack demonstrated in 2016) when large volumes of data are encrypted under one key. Schneier himself recommended the successor Twofish, a finalist in the AES competition, and later Threefish, for new designs.
