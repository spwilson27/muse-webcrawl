Intel 80386

Intel 80386
Launched: October 1985
Designer: Intel
Architecture: x86-32 (IA-32)
Transistors: 275,000 (DX)

The Intel 80386, also known as the i386 or 386, is a 32-bit microprocessor introduced by Intel in 1985. It defined the 32-bit IA-32 architecture, adding 32-bit registers and addressing, paging-based virtual memory, and improved protected mode, while retaining compatibility with earlier x86 software.

Features

The 386 could address up to 4 GB of physical memory, supported hardware multitasking and memory protection, and introduced the flat memory model used by 32-bit operating systems such as Windows NT, OS/2 2.x and early Linux. Variants included the original DX, the cost-reduced 386SX with a 16-bit external data bus, the low-power SL, and the embedded 386EX.

Impact

Compaq's Deskpro 386 (1986) was the first PC built around the chip — notably not by IBM — marking a shift in the PC industry. The 386 remained in production for embedded uses until 2007, and "386" long served as shorthand for the minimum PC class able to run early 1990s software.
