QEMU (short for "Quick Emulator") is a free and open-source emulator and hypervisor. It emulates the hardware of one computer system on another, allowing operating systems and programs compiled for one machine architecture (for example ARM) to run on a different one (such as x86). It was originally written by Fabrice Bellard and is now maintained by a large open-source community.

Modes of operation

QEMU operates in several modes. In full system emulation it models an entire machine — processor, memory and peripheral devices — and can boot unmodified guest operating systems. In user-mode emulation (on Linux and BSD hosts) it runs individual executables compiled for a different CPU, translating system calls to the host. When the guest and host architectures match, QEMU can use hardware virtualisation through accelerators such as KVM on Linux or Hypervisor.framework on macOS, achieving near-native speed; in this role it provides the machine model for much of the Linux virtualisation stack, managed by tools such as libvirt.

Emulation technology

For cross-architecture emulation QEMU uses dynamic binary translation: its Tiny Code Generator (TCG) converts guest instructions into host instructions at run time, caching translated blocks. QEMU emulates a very wide range of CPUs and boards and supports features including live migration of running virtual machines, disk image formats such as qcow2, snapshotting, and device passthrough.
