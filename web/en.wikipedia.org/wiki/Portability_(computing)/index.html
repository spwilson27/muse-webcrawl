Portability (computing)

In computing, portability is the property of software that allows it to be used on different platforms — different processors, operating systems or environments — with little or no modification. Adapting a program to a new platform is called porting.

Approaches

Programs written in standardised high-level languages such as C can usually be ported by recompiling the source code for the target machine, provided they avoid platform-specific features. Application binary interfaces, standard libraries and specifications such as POSIX reduce differences between systems. Virtual machines and interpreters, as with the Java virtual machine and modern web browsers, raise portability further by executing the same bytecode or script everywhere the runtime exists.

Costs and trade-offs

Portability is rarely absolute: differences in word size, endianness, file paths, graphics and performance characteristics all demand testing and adaptation. Highly portable software may sacrifice the ability to exploit the special features of any one platform, so developers balance reach against performance and native look-and-feel.

Data portability

The term also applies to data: open, documented file formats and the legal "right to data portability" (for example under the GDPR) allow users to move their information between services.
