Admittance parameters

Image placeholder: two-port network used to define the Y-parameters

Admittance parameters (or Y-parameters) describe the electrical behaviour of a linear two-port network in terms of the voltages at its two ports and the currents flowing into them. They are widely used in electronics and network theory, particularly for transistor modelling at a fixed bias point.

Definition

For a two-port with port voltages V1, V2 and currents I1, I2 (both defined as flowing into the network), the Y-parameter equations are:

I1 = Y11V1 + Y12V2
I2 = Y21V1 + Y22V2

Each parameter is measured with one port short-circuited: Y11 is the input admittance with the output shorted, Y22 the output admittance with the input shorted, Y21 the forward transfer admittance, and Y12 the reverse transfer admittance.

Properties

Because the defining measurements use short circuits, Y-parameters are often convenient for devices whose behaviour is naturally measured that way, though short-circuit measurements can be impractical at high frequencies, where scattering (S-) parameters are usually preferred. For a reciprocal network Y12 = Y21; for a symmetric network also Y11 = Y22.

Conversions

The Y-parameter matrix is the matrix inverse of the impedance (Z-parameter) matrix. Standard conversion tables also relate Y-parameters to hybrid (h-) parameters, ABCD (transmission) parameters, and S-parameters, allowing the analyst to work with whichever set best suits a circuit topology — parallel connections of two-ports, for instance, are handled by simply adding their Y matrices.
