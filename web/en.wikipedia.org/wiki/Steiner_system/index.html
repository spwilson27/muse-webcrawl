Steiner system

In combinatorial mathematics, a Steiner system with parameters t, k, v, written S(t, k, v), is a finite incidence structure: a set of v points together with blocks, each block containing k points, such that every set of t points is contained in exactly one block. Steiner systems are named after Jakob Steiner, who studied the case t = 2, k = 3.

Examples

Steiner triple systems S(2, 3, v) exist if and only if v is odd and not divisible by 3 in a specific sense (v ≡ 1 or 3 mod 6); the smallest nontrivial example is the Fano plane, S(2, 3, 7), and the affine plane of order 3 gives S(2, 3, 9). More exotic examples include the Witt design S(5, 8, 24), closely tied to the extended binary Golay code and the Mathieu groups, and S(5, 6, 12).

Existence

For fixed t and k, necessary divisibility conditions on v were long known; a major result by Peter Keevash (2014) established that these conditions are asymptotically sufficient for large v. Steiner systems are a special case of block designs (2-designs and t-designs) and have applications in coding theory and experimental design.
