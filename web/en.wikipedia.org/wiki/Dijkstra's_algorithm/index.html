Dijkstra's algorithm

From Wikipedia, the free encyclopedia

[Image: A network graph with the shortest path between two nodes highlighted in bold]

Dijkstra's algorithm is an algorithm for finding the shortest paths between nodes in a weighted graph — for example, the quickest route through a road network. It was conceived by the Dutch computer scientist Edsger W. Dijkstra in 1956 and published in 1959; he later recalled designing it in about twenty minutes, without pencil and paper, over coffee in Amsterdam.

The algorithm grows a frontier of settled nodes, always extending the currently cheapest tentative path, and guarantees the optimal route when all edge weights are non-negative. It is a classic greedy algorithm and a staple of computer-science education.

Uses and variants

Route planners, network routing protocols (OSPF) and logistics systems use Dijkstra's algorithm or its goal-directed descendant A*, which adds a heuristic estimate to focus the search.

Negative edge weights break the guarantee; the Bellman–Ford algorithm handles those at the cost of more time.
