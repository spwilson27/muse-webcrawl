SCXML
Full nameState Chart XML: State Machine Notation for Control Abstraction
DeveloperWorld Wide Web Consortium (W3C)
StatusW3C Recommendation, 1 September 2015
Based onHarel statecharts, CCXML

SCXML (State Chart XML: State Machine Notation for Control Abstraction) is an XML-based markup language that provides a generic state-machine environment based on Harel statecharts. It became a W3C Recommendation in September 2015. SCXML defines how state machines — with nested states, parallel regions, history pseudostates, and event-driven transitions — can be described in an executable, platform-independent way.

Features

An SCXML document declares states and the transitions between them, triggered by events and guarded by conditions. Executable content can be attached to transitions and to state entry and exit, including raising events, assigning data-model variables, logging, and invoking external services or other state machines. The default data model uses ECMAScript expressions, though other expression languages may be bound. A standard algorithm for interpretation — microsteps and macrosteps over an event queue — gives documents a precise, portable semantics.

<scxml version="1.0" datamodel="ecmascript">
  <state id="operational">
    <transition event="error" target="failed"/>
  </state>
  <state id="failed"/>
</scxml>

Applications

SCXML grew out of voice applications: it was designed to underpin CCXML call control and multimodal interaction frameworks, generalising the state logic used in VoiceXML dialogs. It has since been used in workflow and business-process modelling, user-interface logic, robotics control, and embedded systems. Implementations include Apache Commons SCXML in Java, the Qt SCXML module in C++/QML, and SCION in JavaScript.
