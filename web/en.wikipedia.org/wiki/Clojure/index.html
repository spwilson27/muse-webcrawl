Clojure

Clojure
Paradigm: functional, concurrent
Designed by: Rich Hickey
First appeared: 2007
Typing: dynamic, strong
Platform: JVM, CLR, JavaScript

Clojure (pronounced like closure) is a dynamic, general-purpose programming language, combining the approachability and interactive development of a scripting language with an efficient and robust infrastructure for multithreaded programming. It is a dialect of Lisp created by Rich Hickey and first released in 2007.

Features

Clojure is a compiled language that runs primarily on the Java Virtual Machine (JVM), with ports to the Common Language Runtime (ClojureCLR) and JavaScript (ClojureScript). It emphasizes functional programming with immutable, persistent data structures, software transactional memory for safe concurrent state management, and seamless interoperability with its host platform. Like other Lisps, it treats code as data (homoiconicity) and provides a powerful macro system.

Philosophy

Hickey designed Clojure in response to the complexity of managing state in concurrent programs in object-oriented languages. The language separates identity from state and encourages programming with pure functions over immutable values.
