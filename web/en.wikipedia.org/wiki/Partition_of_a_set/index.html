Partition of a set

A partition of a set is a grouping of its elements into non-empty subsets, in such a way that every element is included in exactly one subset.

A partition of a set into blocks.

Equivalently, a family of sets P is a partition of X if and only if all of the following conditions hold:

  • The union of the sets in P is equal to X (the sets in P are said to cover X).
  • The intersection of any two distinct sets in P is empty (the elements of P are pairwise disjoint).
  • None of the elements of P is the empty set (the sets are non-empty).

The sets in P are called the blocks, parts, or cells of the partition. Every partition is an antichain in the partition lattice.

Examples

  • The empty set has exactly one partition, namely the empty family of sets.
  • For any nonempty set X, the family {{X}} is a partition of X, called the trivial partition.
  • For any singleton set {x}, the only partition is {{x}}.
  • For a particular example, given set X = {1, 2, 3}, then {{1}, {2, 3}} is a partition, as are {{1, 2, 3}} and {{1}, {2}, {3}}.
  • The set of positive integers can be partitioned into the even integers and the odd integers.

Partitions and equivalence relations

For any equivalence relation on a set X, the set of its equivalence classes is a partition of X. Conversely, from any partition P of X, we can construct an equivalence relation on X by setting x ~ y precisely when x and y belong to the same part in P. Hence the notions of equivalence relation and partition are essentially equivalent.

Counting partitions

The total number of partitions of an n-element set is the Bell number Bn, named after Eric Temple Bell. The first few Bell numbers are B0 = 1, B1 = 1, B2 = 2, B3 = 5, B4 = 15, B5 = 52. The number of partitions of an n-element set into exactly k nonempty parts is the Stirling number of the second kind S(n, k).

Refinement of partitions

A partition α of a set X is a refinement of a partition ρ of X, and we say that α is finer than ρ, if every element of α is a subset of some element of ρ. The set of all partitions of a fixed set forms a lattice under this refinement order, known as the partition lattice.
