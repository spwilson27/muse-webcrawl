In cryptography, Curve25519 is an elliptic curve used in elliptic-curve cryptography (ECC) offering 128 bits of security (256-bit key size) and designed for efficient use with the elliptic curve Diffie–Hellman (ECDH) key agreement scheme. It is one of the fastest curves in ECC, and is not covered by any known patents. The reference implementation is public domain software.

The curve was introduced by Daniel J. Bernstein in 2005. The associated key exchange function, known as X25519, uses only the x-coordinate of points on the curve, which simplifies implementation and helps avoid common pitfalls.

Mathematical properties

Curve25519 is a Montgomery curve defined over the prime field GF(2255 − 19) by the equation y2 = x3 + 486662x2 + x. The prime 2255 − 19 is the largest prime below 2255, chosen so that arithmetic can be implemented efficiently. The curve's parameters were selected by rigid, verifiable criteria ("nothing up my sleeve numbers") to minimize the risk of hidden weaknesses.

Adoption

Curve25519 and X25519 are widely deployed: they are supported in TLS 1.3, SSH, the Signal Protocol (as part of the X3DH handshake), WireGuard, and many libraries including OpenSSH, libsodium, and modern web browsers. The related signature scheme Ed25519 uses a birationally equivalent Edwards curve, Ed25519.
