Backslash

The backslash is a typographical mark, \, used mainly in computing and mathematics. It is the mirror image of the ordinary slash (forward slash, /). The character was introduced into computing character sets in the early 1960s — appearing in ASCII in 1963 — largely to serve the needs of programming languages such as ALGOL.

Uses in computing

  • File paths: Microsoft Windows and MS-DOS use the backslash as the directory separator in paths such as C:\Users\Name, whereas Unix-like systems use the forward slash.
  • Escape character: In many programming languages and formats (C, JavaScript, JSON, regular expressions), the backslash introduces escape sequences such as \n (newline), \t (tab), and \\ (a literal backslash).
  • Line continuation: In shells, makefiles, and several languages, a trailing backslash continues a command onto the next line.
  • TeX/LaTeX: Commands begin with a backslash, e.g. \section.

Uses in mathematics

In set theory, the backslash denotes set difference: A \ B is the set of elements in A but not in B. It also appears in integer division notation in some programming languages and in lattice and logical notations.

Naming

The name "backslash" is first recorded in the 20th century; in some contexts it has been called a reverse solidus, slosh, or hack. Because of its Windows association, users sometimes confuse it with the forward slash used in URLs, leading to the common mnemonic "forward slash leans forward, backslash leans back".
