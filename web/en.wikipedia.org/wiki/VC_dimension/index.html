VC dimension

In statistical learning theory, the VC dimension (for Vapnik–Chervonenkis dimension) is a measure of the capacity of a set of functions — typically a class of binary classifiers — to fit data. It was introduced by Vladimir Vapnik and Alexey Chervonenkis in work beginning in 1968, and it is central to the theory of empirical processes and to the analysis of generalisation error in machine learning.

Three points in the plane can be shattered by halfplanes: every one of the 23 = 8 labellings is realised by some line. No set of four points can be.

Definition

A hypothesis class H shatters a set of points C if, for every subset of C, there is a hypothesis in H that labels exactly the points of that subset positive and the rest negative — that is, H realises all 2|C| possible dichotomies on C. The VC dimension of H is the cardinality of the largest set that H can shatter. If arbitrarily large sets can be shattered, the VC dimension is infinite.

For example, intervals on the real line have VC dimension 2: any two points can be shattered, but no three points can, since no interval contains the two outer points while excluding the middle one. Halfplanes in the plane have VC dimension 3, and the class of axis-aligned rectangles in the plane has VC dimension 4.

The growth function and Sauer's lemma

The growth function counts the maximum number of dichotomies that a class can realise on any set of m points. A fundamental result, proved independently by Vapnik and Chervonenkis, by Norbert Sauer, and by Saharon Shelah, states that if the VC dimension is finite and equal to d, then the growth function is bounded polynomially:

ΠH(m) ≤ Σi=0d C(m, i) ≤ (em/d)d

This dichotomy — the growth function is either polynomial or exactly 2m — is what makes uniform convergence of empirical errors possible for classes of finite VC dimension.

Importance in learning theory

The VC dimension controls generalisation bounds. With high probability, the true error of every hypothesis in a class of VC dimension d is close to its empirical error, with the gap shrinking roughly as the square root of d divided by the sample size m. Consequently, minimising empirical error over a class of finite VC dimension is a consistent learning rule in the PAC learning model, and sample complexity bounds scale linearly in the VC dimension (for fixed accuracy and confidence parameters).

In practice, the VC dimension of common models can be estimated: linear classifiers in n dimensions have VC dimension n + 1, and the VC dimension of a neural network grows with the number of its weights and units, which helps explain both its expressive power and its tendency to overfit when data are scarce.

Uses

Beyond PAC learning, VC theory underlies structural risk minimisation, the design of support vector machines, and results in computational geometry, where the VC dimension of range spaces governs the size of ε-nets and ε-approximations used in sampling and rendering algorithms.
