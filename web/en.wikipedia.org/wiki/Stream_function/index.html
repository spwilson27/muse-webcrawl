Stream function

In fluid dynamics, the stream function is a scalar function used to describe incompressible flow, particularly in two dimensions. It is defined so that lines of constant stream function are the streamlines of the flow, and the difference in the stream function between two streamlines equals the volumetric flow rate between them.

Two-dimensional flow

For a two-dimensional incompressible flow with velocity components u and v, the stream function ψ is defined by u = ∂ψ/∂y and v = −∂ψ/∂x. These definitions satisfy the continuity equation identically. In polar coordinates the corresponding relations involve the radial and angular velocity components. The stream function is due originally to Joseph-Louis Lagrange (1781); for irrotational flow, ψ satisfies Laplace's equation and forms, with the velocity potential, a pair of harmonic conjugates.

Three dimensions

For axisymmetric incompressible flow the analogous quantity is the Stokes stream function, defined in cylindrical or spherical coordinates, whose constant-value surfaces are stream surfaces containing the flow.
