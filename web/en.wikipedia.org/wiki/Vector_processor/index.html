Vector processor

A vector processor or array processor is a central processing unit (CPU) that implements an instruction set where its instructions are designed to operate efficiently and effectively on large one-dimensional arrays of data called vectors. This is in contrast to scalar processors, whose instructions operate on only single data items at a time, and in contrast to some of those same scalar processors having additional single instruction, multiple data (SIMD) or SWAR operations which can only do short vectors.

Vector processors can greatly improve performance on certain workloads, notably numerical simulation and similar tasks. The technique first appeared in the Cray-1 supercomputer of 1976 and dominated high-performance computing through the 1980s and early 1990s.

How it works

A vector processor has large vector registers, each holding dozens of elements, and deep pipelines that stream elements through functional units one per cycle. A single instruction such as "add vector A to vector B" initiates the addition of all element pairs, amortising instruction fetch and decode over the whole array. Memory systems provide high bandwidth loads and stores, sometimes with strided and gather/scatter addressing.

History

Early designs included the STAR-100 and the TI ASC, but the Cray-1 made the architecture commercially successful. Subsequent machines included the Cray X-MP and Cray-2, the Japanese NEC SX series, and Fujitsu VP machines. As commodity microprocessors added SIMD extensions (MMX, SSE, AVX on x86; Neon and SVE on ARM), and GPUs took over massively parallel workloads, dedicated vector mainframes declined, though vector ideas survive in the RISC-V vector extension and ARM's scalable SVE2.

Programming

Compilers for vector machines automatically vectorise loops when dependencies allow. Programmers can assist with directives and by structuring code to use long, regular loops over arrays.
