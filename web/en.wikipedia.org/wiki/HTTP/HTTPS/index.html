HTTPS

Hypertext Transfer Protocol Secure (HTTPS) is an extension of the Hypertext Transfer Protocol (HTTP). It uses encryption for secure communication over a computer network and is widely used on the Internet. In HTTPS, the communication protocol is encrypted using Transport Layer Security (TLS) or, formerly, Secure Sockets Layer (SSL).

Overview

The principal motivations for HTTPS are authentication of the accessed website and protection of the privacy and integrity of the exchanged data while it is in transit. It protects against man-in-the-middle attacks, and the bidirectional block cipher encryption of communications between a client and server protects the exchanges against eavesdropping and tampering. URLs using HTTPS begin with https:// and use port 443 by default, as opposed to port 80 for HTTP.

Certificates

Authentication is provided by digital certificates issued by certificate authorities, binding a public key to a domain name. Free automated issuance through initiatives such as Let's Encrypt, together with browser policies marking plain HTTP pages as "not secure", drove HTTPS to become the default for the web during the late 2010s.
