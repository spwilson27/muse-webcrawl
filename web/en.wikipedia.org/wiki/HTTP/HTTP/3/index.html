HTTP/3

HTTP/3 is the third major version of the Hypertext Transfer Protocol, standardised as RFC 9114 in 2022. Unlike earlier versions, it runs over QUIC, a UDP-based transport protocol with built-in TLS 1.3 encryption, rather than over TCP.

Advantages

QUIC eliminates head-of-line blocking between independent streams, reduces connection-establishment latency (including 0-RTT resumption), and supports connection migration when a client's network changes. HTTP/3 is supported by all major browsers and is used by a large share of web traffic.
