HTTP

The Hypertext Transfer Protocol (HTTP) is an application-layer protocol for transmitting hypermedia documents such as HTML. Developed by Tim Berners-Lee at CERN beginning in 1989, it is the foundation of data communication for the World Wide Web.

Operation

HTTP follows a client–server model: a client sends a request with a method (GET, POST, PUT, DELETE and others), a URL and headers; the server responds with a status code (such as 200 OK or 404 Not Found) and a body. HTTP is stateless, though cookies allow sessions. Versions include HTTP/1.1, the multiplexed HTTP/2 (2015) and HTTP/3, which runs over QUIC.
