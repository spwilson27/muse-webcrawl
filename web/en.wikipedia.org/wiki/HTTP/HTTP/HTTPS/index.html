Hypertext Transfer Protocol Secure (HTTPS) is an extension of the Hypertext Transfer Protocol (HTTP) that uses encryption for secure communication over a computer network. In HTTPS, the communication protocol is encrypted using Transport Layer Security (TLS) or, formerly, Secure Sockets Layer (SSL). The protocol is therefore also referred to as HTTP over TLS.

Overview

HTTPS protects against man-in-the-middle attacks by providing bidirectional encryption of communications between a client and server, and authenticates the visited website using digital certificates issued by certificate authorities and validated through the public key infrastructure. Web browsers display a padlock icon for HTTPS connections and warn users about invalid certificates.

Adoption

Originally used mainly for payment transactions and login pages, HTTPS became the default for the web during the 2010s, driven by free certificate services such as Let's Encrypt (launched 2015), browser warnings on plain-HTTP pages, and the adoption of HTTP/2, which major browsers implemented only over TLS. Google reported that the large majority of web pages loaded in Chrome now use HTTPS, and HSTS allows sites to insist on secure connections.
