QUIC

QUIC is a general-purpose transport layer network protocol initially designed by Jim Roskind at Google. It was first implemented and deployed in 2012 and standardised by the IETF in May 2021 in RFC 9000, together with companion specifications for loss detection and congestion control, TLS integration, and the HTTP/3 mapping.

Design

QUIC runs over UDP and provides multiplexed streams within a single connection, so that packet loss affecting one stream does not block others — eliminating the transport-level head-of-line blocking of TCP. Connections are identified by connection IDs rather than IP addresses and ports, allowing a connection to survive changes of the client's network address, such as moving from Wi-Fi to a mobile network.

Encryption and handshake

Encryption is integral: QUIC integrates the TLS 1.3 handshake, so a connection is established in a single round trip, and resumed connections can send data immediately (0-RTT). Almost all QUIC packet content beyond a small header is encrypted.

Use

QUIC underlies HTTP/3 and is used by major browsers, content delivery networks, and large web services; versions of the protocol also carry DNS and other application traffic.
