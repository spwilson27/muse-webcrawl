Transmission Control Protocol

The Transmission Control Protocol (TCP) is one of the main protocols of the Internet protocol suite. It originated in the initial network implementation in which it complemented the Internet Protocol (IP). Therefore, the entire suite is commonly referred to as TCP/IP. TCP provides reliable, ordered, and error-checked delivery of a stream of octets (bytes) between applications running on hosts communicating via an IP network.

Operation

A TCP connection is established with a three-way handshake (SYN, SYN-ACK, ACK) and terminated with a FIN exchange. Data is divided into segments carrying sequence numbers; the receiver acknowledges received bytes, lost segments are retransmitted, and flow control and congestion control algorithms adjust the sending rate to the capacity of the receiver and the network.

Applications

Major Internet applications such as the World Wide Web (HTTP/1.1 and HTTP/2), email (SMTP, IMAP, POP3), remote administration (SSH), and file transfer (FTP) rely on TCP. Applications that can tolerate some loss or delay sensitivity, such as media streaming and online games, often use UDP instead; QUIC builds TCP-like reliability over UDP.

History

TCP was designed in the 1970s by Vint Cerf and Bob Kahn and specified in RFC 793 in 1981; the modern consolidated specification is RFC 9293 (2022).
