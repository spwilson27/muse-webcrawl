HTTP

From Wikipedia, the free encyclopedia
[Image: A diagram of a browser sending an HTTP request and a server returning a response]

The Hypertext Transfer Protocol (HTTP) is an application layer protocol in the Internet protocol suite for distributed, collaborative, hypermedia information systems. It is the foundation of data communication for the World Wide Web: browsers (clients) request resources from servers, which respond with content or status information.

HTTP was designed by Tim Berners-Lee and his team at CERN between 1989 and 1991. HTTP/1.0 (1996) and HTTP/1.1 (1997, long dominant) are textual, stateless request–response protocols; HTTP/2 (2015) multiplexed streams over one connection; HTTP/3 (2022) runs over QUIC/UDP to cut latency.

Mechanics

Requests use methods (GET, POST, PUT, DELETE, HEAD...) on a URL; responses carry status codes (200 OK, 404 Not Found, 301 Moved Permanently, 500 Internal Server Error) and headers controlling caching, content type, and authentication. Statelessness is worked around with cookies, introduced in 1994.

HTTPS is HTTP over TLS encryption, now used by the large majority of web traffic after a decade-long push by browsers and free certificate authorities (Let's Encrypt, 2015). APIs (REST and others) use HTTP as the universal transport for web services.
