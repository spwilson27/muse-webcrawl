QUIC

QUIC is a general-purpose transport-layer network protocol originally designed at Google by Jim Roskind and standardised by the IETF as RFC 9000 in 2021. It runs over UDP and provides multiplexed streams, integrated TLS 1.3 security, and fast connection establishment.

Features

QUIC avoids TCP's head-of-line blocking, supports connection migration via connection IDs, and encrypts most transport metadata. It is the transport for HTTP/3 and is also used for DNS over QUIC and other applications.
