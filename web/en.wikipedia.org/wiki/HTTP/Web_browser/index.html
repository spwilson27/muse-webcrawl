Web browser

A web browser is an application for accessing websites. When a user requests a web page from a particular website, the browser retrieves its files from a web server and then displays the page's contents as text, images, and video on the user's screen. This process begins when the user inputs a Uniform Resource Locator (URL), such as https://en.wikipedia.org/, into the browser.

Function

Browsers fetch resources using HTTP or HTTPS, render HTML documents styled with CSS, and execute JavaScript. A browser engine layout process converts markup into the visual representation on screen, while networking, storage (including cookies), and security sandboxes are handled by other components.

History

The first browser, WorldWideWeb, was created by Tim Berners-Lee in 1990. Mosaic (1993) popularised the web with inline images, followed by Netscape Navigator, Internet Explorer, Firefox, Safari, and Google Chrome. As of the mid-2020s, Chrome holds the largest share of usage, with Safari second, largely through mobile devices.

Features

Modern browsers support tabbed browsing, bookmarks, history, extensions, synchronisation across devices, private browsing modes, and built-in tools for web developers.
