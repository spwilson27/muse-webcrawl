SPDY

SPDY (pronounced "speedy") is a deprecated open-specification networking protocol developed primarily at Google for transporting web content. Announced in 2009, it aimed to reduce web page load latency through compression, multiplexing and prioritisation of HTTP requests.

Legacy

SPDY's designs strongly influenced HTTP/2, which was based on it. Google deprecated SPDY in favour of HTTP/2 in 2015, and support was removed from Chrome in 2016.
