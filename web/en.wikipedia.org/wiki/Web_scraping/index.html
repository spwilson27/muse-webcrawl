Web scraping

Web scraping, web harvesting, or web data extraction is data scraping used for extracting data from websites. The web scraping software may directly access the World Wide Web using the HTTP protocol or a web browser. While web scraping can be done manually by a software user, the term typically refers to automated processes implemented using a bot or web crawler.

It is a form of copying in which specific data is gathered from the web — generally into a central local database or spreadsheet — for later retrieval or analysis. Scraping a web page involves fetching it and extracting information from it; fetching is the downloading of a page, which a browser does when you view it, and extraction parses and transforms the content into a structured form.

Techniques

Common approaches include HTTP programming with libraries that send requests and parse the returned HTML; DOM parsing with browser automation tools such as Selenium or headless browsers; optical character recognition for text embedded in images; and the use of site-provided APIs, which are more stable but not always available. Modern scrapers must handle JavaScript-heavy pages, rate limits, and structures that change frequently.

Uses and legality

Web scraping is used for price comparison, market research, lead generation, academic research, archiving, and monitoring changes on websites. Its legality varies by jurisdiction and circumstance: website terms of service, copyright and database rights, computer-misuse laws and data-protection rules may all apply, and cases such as hiQ Labs v. LinkedIn have tested the boundaries of accessing publicly available data.

Countermeasures

Site operators may block scrapers using robots.txt conventions, IP blocking, CAPTCHAs, rate limiting, or by requiring accounts and JavaScript execution. The ongoing contest between scraping and detection tools is sometimes called an arms race.
