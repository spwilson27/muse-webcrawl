Apollo Guidance Computer

The Apollo Guidance Computer (AGC) was a digital computer produced for the Apollo program, installed aboard each Apollo command module (CM) and Apollo Lunar Module (LM). It provided computation and electronic interfaces for guidance, navigation, and control of the spacecraft. The AGC was one of the first computers based on silicon integrated circuits, and the first modern embedded system to fly a crewed spacecraft. Its development, led by the MIT Instrumentation Laboratory (later the Draper Laboratory), drove early advances in software engineering.

Design

Two versions were built. Block I, flown only on uncrewed tests and Apollo 1's intended mission, used about 4,100 integrated circuits. Block II, the crewed version, was built from some 5,600 three-input NOR gates — a single IC type for reliability — and was among the earliest large-scale applications of integrated circuits, consuming a significant share of total world IC production in the mid-1960s. Its fixed program memory consisted of core rope memory, in which software was literally woven by hand as wires threaded through or around ferrite cores, largely by women at Raytheon nicknamed the "Little Old Ladies". Erasable memory was magnetic-core RAM.

Software and interface

Astronauts interacted with the AGC through the DSKY (display and keyboard), entering "verbs" and "nouns" as two-digit codes to request programs and data. The software, written in AGC assembly language plus an interpreted language for guidance calculations, ran under a real-time executive (designed by J. Halcombe Laning and colleagues) supporting priority-based multitasking — a pioneering feature. Margaret Hamilton led the software engineering team at MIT and popularised the term "software engineering" during this work.

In flight

Separate computers were carried in the CM (running the Colossus software) and the LM (Luminary). During the Apollo 11 lunar descent on 20 July 1969, the LM computer raised repeated 1201 and 1202 program alarms, caused by an overloaded task schedule from a rendezvous radar interface. Because the executive shed low-priority tasks while preserving guidance, and because flight controller Steve Bales recognised the alarms and called "Go", the landing continued successfully — an early famous demonstration of fault-tolerant software behaviour.

Legacy

The AGC project helped establish real-time embedded computing, core rope memory techniques, and disciplined software development practices. Surviving units are museum pieces; the original source code has been publicly released, transcribed, and run by enthusiasts and restorers, including the Virtual AGC project.
