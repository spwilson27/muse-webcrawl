Return loss

In telecommunications, return loss is a measure in relative terms of the power of the signal reflected by a discontinuity in a transmission line or optical fiber. This discontinuity can be created by a mismatch between the termination or load connected to the line and the characteristic impedance of the line. It is usually expressed as a ratio in decibels (dB).

Definition

Return loss is related to both standing wave ratio (SWR) and reflection coefficient (Γ). It is defined as the ratio of the incident power to the reflected power, expressed in decibels: RL (dB) = 10 log10(Pincident / Preflected), equivalently RL = −20 log10|Γ|. Increasing return loss corresponds with decreasing SWR: a perfectly matched load has infinite return loss and an SWR of 1:1, while an open or short circuit has a return loss of 0 dB.

Significance

High return loss is desirable because it indicates that little power is reflected, meaning good impedance matching and efficient power transfer. In radio-frequency and microwave engineering, specifications for antennas, cables, and connectors are commonly expressed as minimum return loss over a frequency band. In optical fiber systems, reflections at connectors and splices degrade performance, particularly for analog and high-speed digital systems, and return loss measurements (for example with an optical time-domain reflectometer) are used to characterize installed links.
