Amazon Simple Storage Service, commonly known as Amazon S3, is a service offered by Amazon Web Services (AWS) that provides object storage through a web service interface. Amazon S3 was one of the first services launched by AWS, on March 14, 2006, and can be used to store any amount of data for a wide range of use cases, including websites, mobile applications, backup and restore, archive, enterprise applications, IoT devices, and big data analytics.

Design

S3 stores data as objects within resources called "buckets". An object consists of a file and optionally any metadata that describes that file. Each object is identified by a unique, user-assigned key. Amazon designed S3 for durability of 99.999999999% (11 nines), achieved by automatically replicating data across multiple facilities. Individual objects can be up to 5 terabytes in size.

Storage classes

Amazon offers multiple storage classes with different durability, availability, and cost trade-offs, including S3 Standard, S3 Intelligent-Tiering, S3 Standard-Infrequent Access, S3 One Zone-Infrequent Access, and the S3 Glacier family for archival storage. Lifecycle policies can automatically transition objects between classes.

Notable outages and incidents

A major S3 outage in the US-EAST-1 region on February 28, 2017, caused widespread disruption across many websites and services that depended on it, and was traced to an incorrect command entered during debugging of the S3 billing system.
