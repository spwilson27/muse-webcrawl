Drum memory

Drum memory was a magnetic data storage device invented by Gustav Tauschek in 1932 in Austria. It consisted of a large metal cylinder coated with a ferromagnetic recording material, rotating beneath fixed read/write heads. Drums were widely used as the main working memory of early computers in the 1950s and early 1960s.

Design

Data were stored in parallel tracks around the drum's circumference, one head per track, so no head movement was needed; access time depended only on rotational latency — waiting for the desired data to pass under its head, typically a few milliseconds. Capacities were modest, from a few thousand words upward, and programmers often arranged code and data ("optimising" placement) to minimise rotational waiting.

Use in early computers

Atanasoff used a form of rotating drum storage in the Atanasoff–Berry Computer, and drums served as main memory in machines such as the IBM 650, one of the most popular early commercial computers, and the Bendix G-15. Drums were also used as fast backing store ("paging drums") on later machines.

Legacy

Drum memory was displaced by magnetic core memory for main storage and by disk drives for secondary storage, but its principle — data passing under fixed heads on a rotating magnetic surface — directly anticipates the hard disk drive.
