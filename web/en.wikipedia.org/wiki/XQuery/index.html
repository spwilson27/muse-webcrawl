XQuery

XQuery (XML Query) is a query and functional programming language that queries and transforms collections of structured and unstructured data, usually in the form of XML, text and, with vendor-specific extensions, other data formats such as relational data. It is developed by the W3C XML Query working group and became a W3C Recommendation in January 2007.

Features

XQuery is built on XPath expressions and shares its data model, in which everything is a sequence of items (nodes or atomic values). Its characteristic construct is the FLWOR expression — named for its clauses for, let, where, order by and return — which binds variables by iterating over sequences, filters them, and constructs new XML for each item:

for $b in doc("books.xml")//book
where $b/price > 30
order by $b/title
return $b/title

Queries can also construct elements dynamically, define recursive functions, and import modules. XQuery 3.0 added higher-order functions, try/catch and dynamic function calls; version 3.1 added maps and arrays, with support for JSON documents.

Implementations

XQuery is implemented by native XML databases such as eXist-db and BaseX, by commercial systems including MarkLogic, and as libraries such as Saxon and Zorba. It is used for data integration, report generation, content management and transforming XML documents into HTML for web applications.
