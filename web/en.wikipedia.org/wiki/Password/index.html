Password

From Wikipedia, the free encyclopedia
[Image: Screenshot-style image of a login form's password field showing masked dots and a strength meter]

A password is a secret word, phrase, or string of characters used to confirm a user's identity in an authentication process. Passwords have guarded everything since Roman sentries' watchwords; in computing they date to the first time-sharing systems of the early 1960s (MIT's CTSS), where — legend records — the first password theft followed within years, a user printing the master password file to use others' time.

Good password practice is a fight between human memory and machine guessing. Systems should store passwords only as salted cryptographic hashes, never in plaintext; users are told to choose long, unique passwords per site — advice impossible to follow unaided across hundreds of accounts, hence password managers, which generate and store random passwords behind one master password. Breach databases of billions of real passwords feed 'credential stuffing' attacks, which is why reuse is the cardinal sin and why phishing and multi-factor authentication dominate modern account security.

The industry has long predicted the password's death; the passkey standard (FIDO2/WebAuthn, adopted by Apple, Google and Microsoft in the 2020s) — cryptographic keys unlocked by biometrics, synced across devices, and un-phishable — is the first successor with real momentum, though the humble password field remains the web's most common doorway.
