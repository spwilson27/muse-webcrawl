Burrows–Wheeler transform

The Burrows–Wheeler transform (BWT, also called block-sorting compression) rearranges a character string into runs of similar characters. This is useful for compression, since it tends to be easy to compress a string that has runs of repeated characters by techniques such as move-to-front transform and run-length encoding. More importantly, the transformation is reversible, without needing to store any additional data except the position of the first original character. The BWT is thus a "free" method of improving the efficiency of text compression algorithms, on par with increasing the alphabet size.

The transform was invented by Michael Burrows and David Wheeler in 1994 while Burrows was working at DEC Systems Research Center in Palo Alto, California. It is based on a previously unpublished transformation discovered by Wheeler in 1983.

Description

The BWT is accomplished by creating a matrix whose rows are all the cyclic rotations of the input string, sorting the rows lexicographically, and taking the last column of the matrix as the output, together with the index of the row that equals the original string. Because strings with repeated patterns produce many similar rotations, sorting groups identical characters together in the last column, producing runs that compress well.

For example, the text ".BANANA" transforms to "ANNB.A" after sorting its rotations. The inverse transform reconstructs the original string from the sorted first column and the last column using repeated sorting and prepending.

Applications

The BWT is the key step in the bzip2 compression utility, where it is followed by a move-to-front transform and Huffman coding. It is also used in bioinformatics: the aligners Bowtie and BWA use the FM-index, a compressed full-text index based on the BWT, to map short sequencing reads to a reference genome efficiently.
