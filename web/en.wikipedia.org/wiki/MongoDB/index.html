MongoDB is a source-available, cross-platform, document-oriented database program. Classified as a NoSQL database product, MongoDB utilizes JSON-like documents with optional schemas. MongoDB is developed by MongoDB Inc. and is available under the Server Side Public License (SSPL). The name derives from the word "humongous," reflecting its aim of handling large amounts of data.

History

MongoDB was developed starting in 2007 by the New York company 10gen (now MongoDB Inc.), whose founders Dwight Merriman, Eliot Horowitz and Kevin Ryan had previously built the advertising company DoubleClick. The first public release was in 2009. In 2018 the project changed its license from the GNU Affero General Public License to the SSPL.

Features

MongoDB stores records as documents in BSON format, grouped into collections. It supports ad hoc queries, indexing (including geospatial and text indexes), aggregation pipelines, replication through replica sets, and horizontal scaling through sharding. Since version 4.0 it has supported multi-document ACID transactions. The managed cloud service MongoDB Atlas, launched in 2016, provides hosted deployments.

Reception

MongoDB became one of the most popular NoSQL databases, widely used in web applications, content management and real-time analytics. Critics at various times raised concerns about default security settings, memory usage, and data-consistency guarantees, many of which were addressed in later releases.
