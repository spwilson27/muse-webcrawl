Agda (programming language)

Agda is a dependently typed functional programming language and proof assistant originally developed by Ulf Norell at Chalmers University of Technology in Sweden. It has inductive families, pattern matching, dependent types, and an interactive development environment, usually used through an Emacs mode.

Features

Agda is based on Per Martin-Löf's intuitionistic type theory. Because types can depend on values, programs and mathematical proofs can be written in the same language: a function's type can state a property that its implementation must satisfy, and the type checker verifies the proof. Agda is a total language — programs that pass the termination checker are guaranteed to terminate, which keeps its logic consistent. It supports Unicode input extensively, mixfix operators, copattern matching, and compilation to executable code via back ends including one through Haskell.

Relation to other systems

Agda is comparable to Coq and Lean as a proof assistant, but its style is closer to Haskell programming: proofs are written as programs with holes that are refined interactively, rather than through a separate tactic language.
