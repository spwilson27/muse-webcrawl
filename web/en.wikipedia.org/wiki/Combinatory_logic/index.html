Combinatory logic is a notation for mathematical logic that eliminates the need for quantified variables. Introduced by Moses Schönfinkel in 1920 and developed extensively by Haskell Curry, it expresses computation in terms of a small set of primitive functions called combinators, which combine only by application to arguments. Combinatory logic is equivalent in expressive power to the lambda calculus and is Turing complete.

Combinators

The best-known basis uses three combinators: I (identity): I x = x; K (constant): K x y = x; and S (substitution): S f g x = f x (g x). Remarkably, S and K alone suffice to express any computable function — a result exploited in the SKI combinator calculus. Other familiar combinators include B (composition), C (flip) and W (duplication). Evaluating an expression proceeds by repeatedly applying these reduction rules.

Applications and paradoxes

Combinatory logic underlies some implementations of functional programming languages, because combinator expressions can be compiled without variables. Curry's paradox and the fixed-point (Y) combinator illustrate its logical subtleties: unrestricted combinatory systems can express self-referential statements, paralleling results in lambda calculus and computability theory.
