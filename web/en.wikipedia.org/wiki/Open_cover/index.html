Open cover

In mathematics, and more particularly in set theory and topology, a cover of a set X is a family (collection) of subsets of X whose union is all of X. More formally, a cover of X is an indexed family of sets. A cover is called an open cover if each of its elements is an open set.

Cover in topology

Covers are commonly used in the context of topology. If the set X is a topological space, then a cover C of X is a collection of subsets {Uα} of X whose union is the whole space X. In this case we say that C covers X, or that the sets of C cover X. If C is a cover of a subspace Y of X, then the union of the elements of C must contain Y.

A subcover of a cover of X is a subset of the cover that also covers X.

Refinement

A refinement of a cover C of a topological space X is a new cover D of X such that every set in D is contained within a set in C. Formally, the refinement relation is fundamental in notions such as paracompactness.

Compactness

The language of covers is often used to define several topological properties related to compactness. A topological space X is said to be compact if every open cover of X has a finite subcover; Lindelöf if every open cover has a countable subcover; and paracompact if every open cover admits an open refinement that is locally finite.
