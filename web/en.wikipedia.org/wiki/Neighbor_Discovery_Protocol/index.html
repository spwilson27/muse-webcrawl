Neighbor Discovery Protocol

The Neighbor Discovery Protocol (NDP, or simply ND) is a protocol in the Internet protocol suite used with Internet Protocol Version 6 (IPv6). It operates at the link layer and is responsible for gathering information required by IPv6 nodes on the same link, including address autoconfiguration, discovery of other nodes, determining link-layer addresses, detecting duplicate addresses, finding routers, and maintaining reachability information.

Functions

NDP combines and improves upon several IPv4 mechanisms: it replaces the Address Resolution Protocol (ARP), ICMP Router Discovery, and ICMP Redirect. Its functions include:

  • Router discovery — hosts locate routers on the link via Router Advertisement messages.
  • Address autoconfiguration (SLAAC) — hosts generate their own addresses from advertised prefixes.
  • Neighbor solicitation and advertisement — resolving IPv6 addresses to link-layer (e.g. MAC) addresses.
  • Duplicate Address Detection — verifying that a tentative address is unique.
  • Neighbor unreachability detection and redirect of traffic to better first-hop routers.

Messages

NDP is defined in RFC 4861 and uses five ICMPv6 message types: Router Solicitation, Router Advertisement, Neighbor Solicitation, Neighbor Advertisement, and Redirect. Security extensions such as Secure Neighbor Discovery (SEND, RFC 3971) address vulnerabilities including spoofed advertisements and rogue routers.
