Windows Metafile (WMF) is an image file format originally designed for Microsoft Windows in the 1980s. The original WMF format stores a list of function calls which, when played back by the Windows Graphics Device Interface (GDI), regenerate the image—making it a vector format, though it can also contain embedded bitmap components. WMF files appeared with Windows 2.0 in 1988 and became widespread through their use in clip art and in the Windows clipboard.

Enhanced Metafile

With 32-bit Windows NT 3.1 and Windows 95, Microsoft introduced the Enhanced Metafile (EMF), a more capable successor with device independence, larger coordinates, and support for features such as Bézier curves and embedded comments. Compressed variants exist: WMZ (gzip-compressed WMF) and EMZ (gzip-compressed EMF). Metafiles remain common in Windows printing, where EMF is used as the spool format, and in Microsoft Office documents, where pasted vector artwork is often stored as WMF or EMF.

Structure

A WMF file consists of a series of variable-length records, each encoding a GDI function call with its parameters. A special header, and optionally a placeable header with a bounding box and checksum, precede the records. Because a metafile is effectively a script for the graphics system, its rendering depends on the fonts and devices available when it is played.

Security issues

The script-like nature of WMF led to serious vulnerabilities. In late 2005 and early 2006, the WMF exploit (linked to the SetAbortProc GDI function, which allowed arbitrary code to be embedded in a metafile and executed when an image was merely viewed) was widely used to install malware before an official patch was released in January 2006. The incident led to third-party unofficial patches and increased scrutiny of image-format parsers.

The open-source library libwmf and projects such as LibreOffice provide WMF/EMF support on non-Windows platforms.
