Unix

Unix (trademarked as UNIX) is a family of multitasking, multi-user computer operating systems that derive from the original AT&T Unix, developed starting in 1969 at Bell Labs by Ken Thompson, Dennis Ritchie, and others. Unix systems are characterized by a modular design — the Unix philosophy — in which the operating system provides a set of simple tools, each performing a limited, well-defined function, combined through a command-line shell and a unified filesystem.

History

Unix grew out of the Multics project; Thompson wrote the first version in assembly language for a spare PDP-7, and the name was a pun on Multics. The system was rewritten in the new C programming language in 1973, an unprecedented step that made it portable across hardware. Bell Labs licensed Unix widely to universities, seeding the Berkeley Software Distribution (BSD), while commercial variants proliferated in the "Unix wars" of the 1980s. The Open Group now owns the UNIX trademark and certifies conformance to the Single UNIX Specification.

Design

Core concepts originating with Unix include the hierarchical file system, the treatment of devices and inter-process communication channels as files, pipes for composing programs, regular expressions, and the shell as an ordinary user-level program. Its descendants and relatives include Linux, macOS (a certified Unix), the BSD systems (FreeBSD, NetBSD, OpenBSD), Solaris, AIX, and HP-UX.

Impact

Unix reshaped computing culture: it powered early Internet infrastructure, standardized networking with TCP/IP via BSD, and its API was codified in the POSIX standard. Unix-like systems today run most servers, all of the world's fastest supercomputers (via Linux), and, through macOS, iOS, and Android, much of consumer computing as well.
