Mobile virtual network enabler

An MVNE supplies the operational platform behind one or more MVNOs

A mobile virtual network enabler (MVNE) is a company that provides network infrastructure and related business support services — such as billing, provisioning, administration and operations support systems — to mobile virtual network operators (MVNOs). An MVNE does not own spectrum and does not itself have a consumer-facing brand relationship with subscribers; instead it enables MVNOs to offer services over a host mobile network operator's radio network without building their own core infrastructure.

Role

Launching an MVNO requires integration with the host network, subscriber management, rating and billing, customer care systems and regulatory compliance. An MVNE aggregates these functions on a shared platform, reducing the cost and time needed for a new virtual operator to enter the market. The related term mobile virtual network aggregator (MVNA) is sometimes used for a model in which the intermediary also buys wholesale network capacity and resells it to several MVNOs.

Relationship with MVNOs and MNOs

The MVNE sits between the mobile network operator (MNO), which owns the licensed spectrum and radio access network, and the MVNO, which owns the customer relationship and brand. Depending on how much infrastructure the MVNO wishes to control, the enabler may supply anything from simple billing services to a complete "MVNO in a box" package.
