GNU Diffutils is a package of several utilities for computing the differences between files and comparing their contents, developed by the GNU Project. Its best-known program is diff, which reports line-by-line differences between two files; the package also includes cmp, diff3, and sdiff.

Programs

diff analyzes two files and prints the lines that differ, optionally with context. cmp performs a byte-by-byte comparison and reports the first position at which two files differ. diff3 compares three files and merges independently edited versions of a common ancestor. sdiff merges two files interactively, displaying them side by side.

Output formats

GNU diff supports several output styles, including the traditional "normal" format, the context format (-c), and the unified format (-u), which uses @@ headers and became the standard presentation for patches in software development.
