Bell–LaPadula model

The Bell–LaPadula model (BLP) is a state-machine model used for enforcing access control in government and military applications, focused on preserving the confidentiality of classified information. It was developed by David Elliott Bell and Leonard J. LaPadula, working for the MITRE Corporation, in a series of reports published between 1973 and 1976. The model formalises the multilevel security policies used for documents classified at levels such as Unclassified, Confidential, Secret and Top Secret.

Rules

The model assigns every subject (process) and object (file) a security level and enforces two mandatory properties:

  • Simple security property ("no read up"): a subject cannot read an object at a higher security level than its own.
  • Star (*) property ("no write down"): a subject cannot write information into an object at a lower security level than its own, preventing secrets from leaking downward.

A third, discretionary security property governs access through an access-control matrix. The Basic Security Theorem states that if a system starts in a secure state and all state transitions obey these rules, the system remains secure.

Discussion

Bell–LaPadula became the theoretical foundation of the U.S. Department of Defense's "Orange Book" Trusted Computer System Evaluation Criteria. Its limitations are well known: it addresses only confidentiality, not integrity (the complementary concern addressed by the Biba model); it does not handle the problem of authorised administrators changing security levels ("tranquility"); and covert channels lie outside the model. Nevertheless it remains a standard teaching model in computer security.
