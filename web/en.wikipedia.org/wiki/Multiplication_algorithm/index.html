Multiplication algorithm

A multiplication algorithm is an algorithm (or method) to multiply two numbers. Depending on the size of the numbers, different algorithms are more efficient than others. The complexity of multiplying two n-digit numbers is a fundamental question in computer science and computational number theory, with applications in cryptography and computer algebra.

Long multiplication

The schoolbook method, long multiplication, multiplies every digit of one number by every digit of the other and adds the shifted partial products. It requires O(n²) single-digit operations. Variants include lattice (gelosia) multiplication, grid multiplication, and the ancient Egyptian method of doubling and addition, which underlies the binary ("peasant") multiplication algorithm and binary exponentiation.

Fast algorithms

  • Karatsuba algorithm (1960): splits each number in two and computes the product with three half-size multiplications instead of four, giving complexity O(nlog23) ≈ O(n1.585). It was the first algorithm to break the quadratic barrier.
  • Toom–Cook multiplication: generalizes Karatsuba by splitting into more parts and evaluating at points, approaching O(n1+ε) as the split grows.
  • Schönhage–Strassen algorithm (1971): uses fast Fourier transforms over suitable rings to multiply in O(n log n log log n) bit operations; long the fastest practical method for huge integers.
  • Fürer's algorithm (2007) and the Harvey–van der Hoeven algorithm (2019): achieved O(n log n) bit complexity, proving a decades-old conjecture that such an algorithm exists, though these are "galactic" algorithms practical only at enormous sizes.

Hardware multiplication

Digital circuits multiply binary numbers using arrays of adders or tree structures such as Wallace and Dadda trees, often with Booth encoding to reduce the number of partial products. Floating-point units apply analogous algorithms to mantissas while adding exponents. The choice of algorithm in software libraries (e.g., GMP) switches between schoolbook, Karatsuba, Toom–Cook, and FFT methods as operand size increases.
