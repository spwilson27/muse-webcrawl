Multiprocessing

Multiprocessing is the use of two or more central processing units (CPUs) within a single computer system, or the ability of a system to support more than one processor and assign separate tasks to them. Multiprocessing can improve performance by executing instructions in parallel, and can also provide redundancy.

Architectures

In symmetric multiprocessing (SMP), all processors share a common memory and run a single operating system, with tasks distributed among them. Asymmetric multiprocessing (AMP) assigns specific roles to each processor. Modern multicore processors place several processing cores on one chip, bringing multiprocessing into mainstream personal computers and servers.

Challenges

Effective multiprocessing requires software that can divide work among processors and coordinate access to shared data, using mechanisms such as locks and inter-processor communication. The achievable speedup is limited by the serial fraction of a program, as described by Amdahl's law.
