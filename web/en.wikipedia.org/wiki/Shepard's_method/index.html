Shepard's method

Shepard's method is a form of inverse distance weighted interpolation, a method of multivariate interpolation on a set of scattered points, introduced by Donald Shepard in 1968. It is one of the simplest interpolation schemes and is widely used in geostatistics, meteorology, and computer graphics for approximating a function from irregularly spaced data.

Definition

Given a set of sample points xi with values fi, the interpolated value at a point x is a weighted average of the samples, where the weights decrease with distance:

f(x) = Σ wi(x) fi / Σ wi(x),   with   wi(x) = 1 / d(x, xi)p

The power parameter p controls how quickly influence decays with distance; p = 2 is the most common choice and gives the classic inverse distance squared weighting. If x coincides with a sample point, the interpolated value is defined to be that sample's value.

Properties and extensions

The method is exact at the sample points and produces a continuous surface, but it has flat spots (zero gradient) at every data point and tends to create "bull's-eye" patterns around isolated samples. It never predicts values outside the range of the sampled values. Extensions include using a search radius or a fixed number of nearest neighbours, adding directional or barrier weights, and Franke and Nielson's modified Shepard's method, which replaces each sample value with a local quadratic approximation to improve smoothness.
