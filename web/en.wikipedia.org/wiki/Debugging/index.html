Debugging

A debugger paused at a breakpoint, allowing inspection of variables and program state.

Debugging is the process of finding, analysing and removing defects — bugs — in computer programs, hardware or systems. It is a core activity in software development, often consuming a large share of a programmer's working time. Debugging begins when a failure or unexpected behaviour is observed, and ends when the underlying defect has been identified, fixed and verified.

Process

Debugging typically proceeds through several stages: reproducing the problem reliably; isolating the faulty component by narrowing the search space, often by bisection; forming a hypothesis about the cause; and testing the fix to confirm that the failure disappears and no regressions are introduced. Because intermittent defects may vanish under observation — the so-called "Heisenbugs" — techniques such as logging, deterministic record-and-replay and extensive test automation are used to capture failures that are hard to reproduce.

Tools and techniques

  • Debuggers such as GDB, LLDB and integrated development environment debuggers let the programmer set breakpoints, step through code, inspect memory and evaluate expressions.
  • Print debugging (tracing) inserts output statements to follow a program's path and variable values.
  • Rubber duck debugging involves explaining the code aloud, line by line, which often exposes the faulty assumption.
  • Delta debugging automatically minimises a failing input or change set to the smallest case that still triggers the defect.
  • Static analysis, fuzzing and sanitizers detect whole classes of defects, such as memory errors, before or during execution.

Etymology

The term "bug" for an engineering defect predates computing; Thomas Edison used it in the 1870s. The popular story of a moth found taped in the logbook of the Harvard Mark II computer in 1947 by Grace Hopper's team cemented the term, though the log entry itself joked that the operators were "debugging" — the first actual case of a bug being found.
