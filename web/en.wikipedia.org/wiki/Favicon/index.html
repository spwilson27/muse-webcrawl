Favicon

A favicon (short for favorite icon), also known as a shortcut icon, website icon, tab icon, URL icon, or bookmark icon, is a file containing one or more small icons associated with a particular website or web page.

Favicon

Filename extensions: .ico, .png, .gif, .svg
Internet media type: image/x-icon, image/vnd.microsoft.icon
Developed by: Microsoft (ICO), W3C (HTML standard)

History

In March 1999, Microsoft released Internet Explorer 5, which supported favicons for the first time. Originally, the favicon was a file called favicon.ico placed in the root directory of a website. It was used in Internet Explorer's favorites (bookmarks) and next to the URL in the address bar if the page was bookmarked.

Standardization

The .ico format was registered by Simon Butcher for IANA in 2003 under the MIME type image/x-icon. In 2003 the format was standardized by the W3C in the HTML recommendation which described adding a link element with rel="icon". Modern browsers support PNG, GIF, JPEG and SVG favicons in addition to ICO.

Usage

Browsers display favicons in the address bar, in tabs, in bookmark lists, and in history. Mobile operating systems use larger variants such as Apple touch icons for home screen shortcuts. A typical declaration is <link rel="icon" type="image/png" href="/favicon.png">.
