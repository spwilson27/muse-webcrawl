Ingress filtering

In computer networking, ingress filtering is a technique used to ensure that incoming packets are actually from the networks from which they claim to originate. This can be used as a countermeasure against various spoofing attacks in which the attacker's packets contain fake IP addresses, making them harder to trace and block.

Network ingress filtering

Best current practice, described in BCP 38 (RFC 2827) and BCP 84 (RFC 3704), recommends that Internet service providers filter packets entering their networks from downstream customers, discarding any packet whose source address is not within the address range allocated to that customer. Widespread deployment would greatly reduce the effectiveness of IP address spoofing used in distributed denial-of-service attacks.

Implementation

Filtering can be implemented with access control lists on border routers or with unicast reverse path forwarding (uRPF), which checks that a route back to the source address exists via the receiving interface. Strict uRPF can break legitimate traffic in multihomed or asymmetric-routing setups, so looser modes are often used.

Related concepts

Egress filtering applies similar checks to outbound traffic. Ingress filtering at the application level also describes sanitizing user input to prevent injection attacks.
