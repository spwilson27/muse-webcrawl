Systolic array

In parallel computer architectures, a systolic array is a network of processing elements (PEs) that rhythmically compute and pass data through the system, like the flow of blood through the heart — the source of the name — as described by H. T. Kung and Charles Leiserson in 1978. Each PE typically contains a small amount of memory and a simple multiply-accumulate unit, and computes as a stream of data flows through it from neighbouring elements.

Applications

Systolic arrays are ideally suited to computations with regular data flow, such as matrix multiplication, convolution, polynomial evaluation, signal processing and dynamic programming recurrences. Because each input datum is used many times as it propagates through the array, systolic designs achieve high arithmetic throughput with modest memory bandwidth — a property that made the architecture attractive again for machine learning: Google's Tensor Processing Unit (TPU) uses a large systolic array (256×256 multiply-accumulate units in its first version) to accelerate neural-network inference and training.

Advantages and drawbacks

Advantages include scalability of regular layouts, short local interconnects, and high compute-to-I/O ratios. The chief drawback is specialization: problems whose data flow does not map onto the array's rhythm run inefficiently, and programming such arrays can be more demanding than programming general-purpose processors.
