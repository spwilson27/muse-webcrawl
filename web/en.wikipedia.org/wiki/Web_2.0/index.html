Web 2.0

From Wikipedia, the free encyclopedia
[Image: Word-cloud graphic of Web 2.0 buzzwords: blog, wiki, social, sharing, RSS, AJAX, tagging]

Web 2.0 refers to websites that emphasise user-generated content, ease of use, participatory culture and interoperability, in contrast to the earlier generation of static web pages. The term was popularised by Tim O'Reilly and the 2004 Web 2.0 Conference, held as the industry recovered from the dot-com crash.

The archetypal Web 2.0 sites were blogs, wikis such as Wikipedia itself, social networks, video- and photo-sharing services (YouTube, Flickr), and web applications like Gmail whose in-browser interactivity — powered by AJAX techniques (asynchronous JavaScript and XML) — rivalled desktop software. Under the hood, the shift combined technical ingredients (broadband, RSS feeds, APIs and mashups) with an economic one: platforms hosting other people's content and profiting from network effects.

Critics called Web 2.0 a marketing term for things the web had always allowed, or a glossy label on the centralisation of the web into a few giant platforms — a critique that later fuelled talk of a decentralised 'Web3'. Either way, the label marks the era, roughly 2004 to the early 2010s, when the web turned from a library into a conversation.
