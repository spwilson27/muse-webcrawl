Cyber kill chain
Developed byLockheed Martin (2011)
BasisMilitary "kill chain" concept, Intelligence-Driven Defense

The cyber kill chain is a model of the stages of a cyberattack, developed by Lockheed Martin in 2011, adapting the military concept of a "kill chain" to information security. It describes seven phases of an intrusion:

  • Reconnaissance — researching and selecting targets
  • Weaponization — coupling an exploit with a deliverable payload
  • Delivery — transmitting the weapon (e.g., phishing email, malicious website)
  • Exploitation — triggering the malicious code on the target
  • Installation — installing malware or a backdoor for persistence
  • Command and control (C2) — opening a remote channel to the compromised system
  • Actions on objectives — achieving the attacker's goal, such as data theft or destruction

Use and criticism

Defenders use the model to map controls to each phase, reasoning that breaking any link stops the attack. Critics note that the model is perimeter- and malware-focused, fits insider threats and attacks exploiting legitimate credentials poorly, and has been partly superseded or complemented by frameworks such as MITRE ATT&CK, which catalogues adversary tactics in finer detail.
