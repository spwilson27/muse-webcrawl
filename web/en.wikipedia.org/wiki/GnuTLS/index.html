GnuTLS

GnuTLS (the GNU Transport Layer Security Library) is a free software implementation of the TLS, DTLS and (historically) SSL protocols. It provides a C application programming interface for adding secure communications to applications, together with command-line tools for certificate management and testing. GnuTLS is part of the GNU Project and is widely used in free software, including GNOME components, mail servers and messaging clients.

Features

The library supports TLS versions up to 1.3 and DTLS 1.2, X.509 and OpenPGP certificate handling, certificate status checking, smart cards and TPMs via PKCS #11, and hardware acceleration. Low-level cryptographic operations are delegated to the Nettle library. Associated tools include certtool for creating and examining certificates, gnutls-cli and gnutls-serv for debugging TLS connections, and p11tool.

History

GnuTLS was originally developed by Nikos Mavrogiannopoulos, initially outside the GNU Project, and was adopted as a GNU package in the early 2000s. It was long licensed under the LGPL; a period in which it was released under the GPLv3/LGPLv3 caused compatibility problems for some users and helped prompt work to bring TLS support into other stacks, before the project returned to the LGPL v2.1+ for the core library. In 2014 a serious certificate-verification flaw (CVE-2014-0092), in which invalid certificates could be accepted, was disclosed and patched; the bug drew attention because it affected software that had chosen GnuTLS partly in reaction to other libraries' problems.

Usage

GnuTLS is used by software such as the Emacs editor, the Exim mail server, the OpenConnect VPN client, GnuPG-related tooling in some distributions, and numerous GNOME libraries. It is one of the main TLS implementations available on Linux alongside OpenSSL, NSS and mbed TLS.
