File system

In computing, a file system or filesystem (often abbreviated to FS or fs) controls how data is stored and retrieved. Without a file system, data placed in a storage medium would be one large body of data with no way to tell where one piece of data stopped and the next began, or where any piece of data was located when it was time to retrieve it. By separating the data into pieces and giving each piece a name, the data are easily isolated and identified.

Architecture

A file system typically consists of metadata structures such as directories, allocation tables or trees, and journaling mechanisms for crash recovery. Examples include FAT, NTFS, ext4, APFS, Btrfs, and ZFS.

Features

File systems provide varying support for permissions, extended attributes, symbolic links, hard links, snapshots, compression, and encryption, and define limits on file and volume sizes and name lengths.
