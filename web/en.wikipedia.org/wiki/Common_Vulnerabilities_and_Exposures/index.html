Common Vulnerabilities and Exposures (CVE) is a publicly available list of information security vulnerabilities and exposures, each assigned a unique identifier (a CVE ID) so that practitioners can share data across separate vulnerability databases and tools using a common name. The system was launched in 1999 and is operated by the MITRE Corporation with funding from the U.S. Department of Homeland Security's cybersecurity agencies.

Identifiers

A CVE ID has the form CVE-YYYY-NNNN, where YYYY is the year the ID was assigned (not necessarily the year of disclosure) and NNNN is a sequence number of at least four digits. Well-known examples include CVE-2014-0160 (Heartbleed), CVE-2017-0144 (EternalBlue), and CVE-2021-44228 (Log4Shell).

Assignment

Identifiers are assigned by CVE Numbering Authorities (CNAs) — vendors, researchers, open-source projects, and coordination centres authorised to issue IDs for products within their scope — with MITRE acting as the root CNA. Not every security flaw receives, or merits, a CVE ID; assignment generally requires an independently fixable issue in a product that crosses a security boundary or violates the product's security policy.

Related systems

CVE entries are enriched by the U.S. National Vulnerability Database (NVD), which adds severity scores under the Common Vulnerability Scoring System (CVSS), fix information, and categorisation by the Common Weakness Enumeration (CWE).
