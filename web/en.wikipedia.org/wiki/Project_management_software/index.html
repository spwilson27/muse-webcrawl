Project management software

Project management software (PMS) has the capacity to help plan, organize, and manage resource tools and develop resource estimates. Depending on the sophistication of the software, it can manage estimation and planning, scheduling, cost control and budget management, resource allocation, collaboration, communication, decision-making, quality management, and documentation or administration systems.

Features

Common capabilities include task lists and boards, timelines and Gantt charts, critical-path scheduling, calendars, file sharing, time tracking, and reporting dashboards. Scheduling tools compute earliest and latest start and finish dates for tasks based on dependencies, a technique rooted in the critical path method developed in the 1950s.

Types

Project management software may be delivered as desktop applications, client-server systems, or web-based software as a service. Collaborative tools such as wikis, issue trackers, and kanban boards overlap with the category; examples of widely used products include Microsoft Project, Jira, Asana, Trello, and various open-source systems. Approaches range from traditional waterfall planning to software supporting agile methodologies. See also project management.
