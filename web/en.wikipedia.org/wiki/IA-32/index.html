IA-32

IA-32 (short for "Intel Architecture, 32-bit", commonly called i386) is the 32-bit version of the x86 instruction set architecture, designed by Intel and first implemented in the Intel 80386 microprocessor in 1985. IA-32 is the first incarnation of x86 that supported 32-bit computing; as a result, the "IA-32" term may be used as a metonym to refer to all x86 versions that support 32-bit computing.

Features

IA-32 extended the x86 architecture with 32-bit general-purpose registers (EAX, EBX and so on), 32-bit addressing, a flat memory model, memory paging with protection rings, and new addressing modes. Later processors added features including the FPU on-chip (486), MMX, SSE and virtualisation extensions. The architecture supports several operating modes: real mode, protected mode, virtual 8086 mode and system management mode.

History and legacy

IA-32 dominated personal computing for decades, powering PCs running DOS, Windows and Linux. Its 64-bit successor, x86-64, developed by AMD and adopted by Intel as Intel 64, retains full backward compatibility. Intel's own Itanium architecture was marketed as IA-64, but failed to displace IA-32 in the desktop market.
