HDR10+

Developed bySamsung, 20th Century Fox, Panasonic
Announced2017
TypeHigh dynamic range video format

HDR10+ is a high dynamic range (HDR) video technology developed by Samsung and announced in 2017 as an open, royalty-free competitor to Dolby Vision. It extends the base HDR10 format by adding dynamic metadata that allows brightness levels to be adjusted on a scene-by-scene or frame-by-frame basis.

Technical features

HDR10+ uses the same PQ (Perceptual Quantizer) transfer function and 10-bit colour depth as HDR10, with support for peak brightness up to 10,000 nits in the specification. Dynamic tone-mapping metadata is carried as an auxiliary data stream, and HDR10+ content remains playable as plain HDR10 on non-supporting displays.

Adoption

The format is administered by HDR10+ Technologies, LLC, founded by Samsung, Panasonic, and 20th Century Fox, and is supported on many Samsung and Panasonic televisions and several streaming services.
