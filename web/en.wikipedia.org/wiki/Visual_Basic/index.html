Visual Basic (VB) is a family of technologies from Microsoft that includes an event-driven programming language and integrated development environment. Derived from BASIC, the original Visual Basic — often called "classic" Visual Basic — was released in 1991 and made building graphical user interface (GUI) applications for Windows dramatically easier through a drag-and-drop form designer and rapid application development model. Its final classic version, VB6, appeared in 1998.

The Visual Basic 6 IDE with its form designer and toolbox.

History

Visual Basic grew out of Alan Cooper's "Tripod" drag-and-drop interface prototype, which Microsoft acquired and combined with the BASIC language under the code name "Thunder". Visual Basic 1.0 shipped in 1991 for Windows, and successive versions added database access, OLE/COM support, and ActiveX controls. VB6, part of Visual Studio 6.0, became enormously popular for business software. Mainstream support ended in 2008, though the VB6 runtime remains supported on modern Windows versions.

Visual Basic .NET

In 2002 Microsoft replaced the classic language with Visual Basic .NET, a reimplementation on the .NET Framework with full object orientation, structured exception handling, and access to the Common Language Runtime. Though it retained much of VB's syntax, it was not backward compatible with VB6, a change that sparked significant controversy. VB.NET evolved alongside C# for many years; Microsoft later announced it would no longer evolve the language, while continuing to support it on .NET.

Characteristics

Classic Visual Basic features an event-driven model in which developers draw controls on forms and write code in event handlers. The language uses Variant typing, automatic string and memory management, and COM-based components. Related dialects include VBA (Visual Basic for Applications), embedded in Microsoft Office, and VBScript.
