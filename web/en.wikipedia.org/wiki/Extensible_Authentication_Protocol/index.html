Extensible Authentication Protocol

EAP exchanges pass through an authenticator to a backend authentication server
AbbreviationEAP
PurposeAuthentication framework for network access
StandardRFC 3748; updated by RFC 5247
Common methodsEAP-TLS, EAP-TTLS, PEAP

The Extensible Authentication Protocol (EAP) is an authentication framework frequently used in network and internet connections. It is defined in RFC 3748, which was updated by RFC 5247. Rather than being a single authentication mechanism, EAP provides a framework and common functions for many authentication methods, called EAP methods, of which more than forty have been defined.

Operation

EAP runs between a peer (supplicant) seeking network access and an authenticator such as a wireless access point or network switch, which typically relays the exchange to a backend authentication server, often using RADIUS or Diameter. The framework defines request/response message formats with codes for Request, Response, Success and Failure, while each EAP method defines its own conversation — for example exchanging certificates, passwords or tokens. EAP was originally an extension of the Point-to-Point Protocol (PPP) and is now central to IEEE 802.1X port-based network access control.

Methods

Widely deployed methods include EAP-TLS, which uses mutual certificate authentication within TLS; EAP-TTLS and PEAP, which establish a TLS tunnel inside which legacy password-based credentials are exchanged; EAP-SIM and EAP-AKA, which authenticate using mobile-network subscriber credentials; and EAP-FAST, developed by Cisco. The choice of method determines security properties such as mutual authentication, identity protection and resistance to dictionary attacks.

Applications

EAP underpins enterprise Wi-Fi security (WPA2/WPA3-Enterprise), wired 802.1X authentication, VPNs and mobile network access. In eduroam, the worldwide academic roaming service, EAP methods carry user authentication back to the visitor's home institution.
