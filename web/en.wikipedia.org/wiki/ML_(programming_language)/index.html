ML ("Meta Language") is a general-purpose, high-level, functional programming language. It is known for its use of the polymorphic Hindley–Milner type system, which automatically assigns the data types of most expressions without requiring explicit type annotations, and ensures type safety. ML is used for research and teaching in programming language theory and has influenced a long lineage of languages.

ML was originally developed in the 1970s by Robin Milner and others at the University of Edinburgh, as the metalanguage of the LCF theorem prover — a system for constructing machine-checked proofs in logic. Its type inference algorithm formed the basis of the Hindley–Milner system, and Milner received the Turing Award in 1991 partly for this work.

Features

ML features first-class functions, garbage collection, parametric polymorphism, static typing, type inference, algebraic data types, pattern matching, and exception handling. Calls to ML functions can be typed-checked without annotations, as in:

fun fac 0 = 1
  | fac n = n * fac (n - 1);

The language has a formally defined semantics — it was the first language of its size to receive a complete formal definition, published in The Definition of Standard ML (1990, revised 1997).

Dialects and descendants

The main dialects are Standard ML (SML), OCaml, and F#. Standard ML implementations include MLton, Moscow ML, Poly/ML, and Standard ML of New Jersey (SML/NJ). OCaml, developed in France from Caml Light, added object-oriented features and became widely used in industry (Jane Street Capital, Facebook/Meta). F#, developed at Microsoft Research, targets the .NET platform. SML and OCaml together influenced Haskell's type classes, Rust's type system and pattern matching, Scala, and Elm. Microsoft's and Jane Street's use, the proof assistants Isabelle and HOL (written in ML) — descendants of LCF — keep the family central to formal verification.
