Runtime (program lifecycle phase)

Runtime, in the life cycle of a computer program, is the phase during which the program is executed on a machine, as opposed to the compile time, link time, and load time phases that precede it. Errors that occur during this phase are called runtime errors.

Phases of a program's life

A program typically passes through several distinct phases: source code is translated at compile time, object files are combined by a linker at link time, the executable is placed in memory at load time, and finally it runs at runtime, interacting with the runtime system — the libraries, environment, and services (such as memory management and input/output) that support its execution.

Runtime errors

Runtime errors include division by zero, dereferencing a null pointer, array-index violations, and running out of memory. Some languages provide exception handling so that runtime errors can be intercepted and handled gracefully rather than terminating the program. In contrast, compile-time errors are detected before execution and prevent the program from running at all.
