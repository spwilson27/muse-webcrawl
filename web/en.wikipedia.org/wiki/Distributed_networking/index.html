Distributed networking

Distributed networking is a distributed computing network system in which the program data and applications are spread across more than one computer, but communicate over a network for specific final outputs or purposes. It contrasts with centralized networking, in which a central server provides most processing and storage services to clients.

Distributed networking
TypeComputer network architecture
ExamplesPeer-to-peer networks, content delivery networks, distributed file systems

Characteristics

In a distributed network, functions such as routing, storage, and computation are shared among many nodes. This offers resilience — the failure of one node does not halt the network — and scalability, since capacity grows as nodes are added. The trade-offs include complexity in coordination, consistency, and security.

Examples

Peer-to-peer file sharing networks, distributed hash tables, content delivery networks, and blockchain networks are widely deployed examples. Enterprise designs may distribute services across multiple data centers for redundancy and locality.
