Network interface controller

A network interface controller (NIC, also known as a network interface card, network adapter, LAN adapter, or physical network interface) is a computer hardware component that connects a computer to a computer network. Early network interface controllers were commonly implemented on expansion cards that plugged into a computer bus. The low cost and ubiquity of the Ethernet standard means that most new computers have a network interface built into the motherboard, or contained in a USB-connected dongle.

A 1000BASE-T Ethernet network interface card for PCI Express.

Purpose and function

The NIC implements the electronic circuitry required to communicate using a specific physical layer and data link layer standard such as Ethernet or Wi-Fi. This provides a base for a full network protocol stack, allowing communication among computers on the same local area network (LAN) and large-scale network communications through routable protocols, such as Internet Protocol (IP). Each Ethernet NIC has a unique 48-bit MAC address assigned by its manufacturer.

Implementation

Modern NICs offload work from the host CPU, offering features such as interrupt moderation, multiple transmit and receive queues, TCP segmentation offload, checksum offload, and receive-side scaling. Server adapters may support remote direct memory access (RDMA) and virtualization features such as SR-IOV. Controllers are made by vendors including Intel, Broadcom, Mellanox (NVIDIA), and Realtek. Wireless NICs connect via an antenna rather than a cable and implement the IEEE 802.11 standards.
