Lucas–Lehmer primality test

In mathematics, the Lucas–Lehmer test (LLT) is a primality test for Mersenne numbers. The test was originally developed by Édouard Lucas in 1878 and improved by Derrick Henry Lehmer in the 1930s. It remains the most efficient known method for testing Mersenne numbers and is the test used by the Great Internet Mersenne Prime Search (GIMPS) to find the largest known prime numbers.

Statement

Let Mp = 2p − 1 be a Mersenne number with p an odd prime. Define a sequence by s0 = 4 and si = si−12 − 2 for i ≥ 1. Then Mp is prime if and only if sp−2 ≡ 0 (mod Mp).

How it works

The test requires only repeated squaring modulo Mp, which is fast because reduction modulo a Mersenne number can be done by simple bit shifts and additions. Deterministic and easy to verify, it converts the hunt for enormous primes into a feasible computation: nearly all of the largest known primes are Mersenne primes found with this test (modern GIMPS work first screens candidates with probable-prime tests such as PRP before confirming with Lucas–Lehmer verification).
