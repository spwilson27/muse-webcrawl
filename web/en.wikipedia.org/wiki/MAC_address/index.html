MAC address

MAC address
Length: 48 bits (EUI-48)
Notation: Six groups of two hex digits
Administered by: IEEE Registration Authority
Layer: Data link layer (OSI layer 2)

A MAC address (medium access control address, also called a physical or hardware address) is a unique identifier assigned to a network interface controller (NIC) for use as a network address in communications within a network segment. MAC addresses are used in most IEEE 802 networking technologies, including Ethernet, Wi-Fi, and Bluetooth.

Structure

The standard (IEEE 802) format is EUI-48: six octets, usually written as hexadecimal pairs separated by colons (e.g., 00:1A:2B:3C:4D:5E). The first three octets form the Organizationally Unique Identifier (OUI), assigned by the IEEE to a manufacturer; the remaining three are assigned by the manufacturer. Two bits of the first octet indicate whether the address is unicast or multicast (I/G bit) and whether it is globally unique or locally administered (U/L bit). The broadcast address is FF:FF:FF:FF:FF:FF.

Usage

Switches use MAC addresses to forward frames within a local network; protocols such as ARP map IPv4 addresses to MAC addresses. Although intended to be permanent, MAC addresses can often be changed in software ("spoofing"), and modern mobile operating systems randomize MAC addresses when probing for Wi-Fi networks to reduce tracking.

EUI-64

The extended 64-bit format EUI-64 is used in some technologies and in IPv6 stateless address autoconfiguration (modified EUI-64 interface identifiers).
