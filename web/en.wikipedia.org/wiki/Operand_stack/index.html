Operand stack

An operand stack is the stack used by stack-based virtual machines and processors to hold the operands and results of instructions. Instructions typically take their inputs from the top of the stack and push their results back onto it, so instructions need no explicit operand addresses — an encoding scheme used by the Java Virtual Machine, the .NET Common Language Runtime, WebAssembly and stack machines such as the Burroughs large systems.

Operation

For example, to add two numbers, a program pushes both values onto the stack and executes an add instruction, which pops the two operands and pushes their sum. In the JVM each method frame has an operand stack of a fixed maximum depth declared in the class file, and bytecode verification checks that the stack is used consistently — never underflowing and holding matching types at each point.

Advantages and trade-offs

Stack code is compact and simple to generate and verify, but the serial dependence on the stack top can limit instruction-level parallelism compared with register machines, so production runtimes typically map stack slots to registers when compiling to native code.
