LibreSSL

LibreSSL
Developer: OpenBSD Project
Initial release: 2014
Written in: C
Operating system: multi-platform
Type: cryptography library
License: ISC, Apache 1.0, BSD

LibreSSL is a free and open-source implementation of the TLS protocol developed by the OpenBSD Project. It is a fork of OpenSSL 1.0.1g created in April 2014, shortly after the disclosure of the Heartbleed vulnerability, with the goal of modernising the codebase, improving security, and applying best practice.

History

After Heartbleed exposed serious flaws in OpenSSL, OpenBSD developers led by Theo de Raadt began a wholesale cleanup of the OpenSSL codebase. Within weeks they had removed tens of thousands of lines of code, including support for obsolete platforms, unused protocols such as SSLv2, and little-used features. The first release, LibreSSL 2.0.0, shipped with OpenBSD 5.6 in November 2014.

Changes and features

  • Removal of obsolete platforms and features, simplifying auditing
  • New, safer APIs and extensive code refactoring with modern C idioms
  • Privilege separation and improved memory handling in the libtls library, a simplified API for TLS clients and servers
  • Removal of the FIPS mode and of the dual-licence complexities of the original
  • Support for newer algorithms including ChaCha20-Poly1305, added originally for use in OpenSSH

Adoption

LibreSSL is the default TLS stack in OpenBSD and is used by other systems and software, although OpenSSL remains far more widespread. A portable version is maintained for Linux, macOS, the other BSDs, and other Unix-like systems.
