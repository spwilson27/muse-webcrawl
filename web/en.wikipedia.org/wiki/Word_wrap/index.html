Word wrap

Word wrap is the feature of text editors and word processors that automatically moves a word that would extend beyond the right margin down to the next line, so that text fits within a display or page width without the user inserting manual line breaks. The stored text remains a continuous stream; wrapping is a property of how it is displayed, and the wrapping changes automatically when the window is resized or the font changes. Text that wraps in this dynamic way is said to be soft-wrapped, in contrast to hard return characters stored in the file.

History

Manual typewriters required the operator to watch for the end of the line and press the carriage return. Early full-screen text editors and dedicated word processors of the 1970s and 1980s introduced automatic wrapping, though standards differed over whether the text file itself recorded line breaks. Programs such as WordStar and later Microsoft Word made soft wrap the norm for prose, while programmers' editors retained configurable wrapping because source code and data formats are often sensitive to line length.

Algorithms

The simplest approach is a greedy algorithm: words are placed on a line until the next word does not fit, at which point a break is inserted. This is fast but can leave uneven line lengths. Typesetting systems such as TeX use a global algorithm (the Knuth–Plass algorithm) that evaluates all possible break points in a paragraph to minimise raggedness and bad spacing. Implementations must handle long words that exceed the line width (which may be split, hyphenated, or allowed to overflow), trailing spaces, and different scripts, including languages like Chinese and Japanese where breaks can occur between most characters, and languages where words are joined by spaces only loosely.

In HTML and CSS

Web browsers wrap text by default according to the Unicode line-breaking algorithm. CSS provides controls such as white-space (for example nowrap to disable wrapping and pre to preserve hard breaks), overflow-wrap/word-wrap (to force breaks inside long words), word-break, and hyphens for dictionary-based hyphenation.

Soft and hard wrapping

Hard wrapping physically inserts newline characters at a fixed column (traditional in email, limited historically to about 78 characters per line by RFC conventions and terminal widths). Hard-wrapped plain text reflows badly when quoted or displayed at different widths, one reason modern mail clients write soft-wrapped messages and wrap only for display. Many editors offer both: visual soft wrap to a window width and an option to insert hard breaks at a specified margin.
