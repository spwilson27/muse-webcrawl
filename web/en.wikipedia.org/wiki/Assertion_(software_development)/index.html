Assertion (software development)

In computer programming, specifically when using the imperative paradigm, an assertion is a predicate (a Boolean-valued expression) embedded in the program that should always evaluate to true at that point in the code. If an assertion fails at run time, the program typically halts or raises an exception, signalling a programming error.

Use

Assertions document assumptions made by the programmer and catch impossible conditions early during development and testing — for example, checking that a pointer is non-null before dereferencing it, or that an index is within bounds. They appear as assert constructs in languages such as C (via assert.h), C++, Java, Python and C#. In C, assertions can be disabled in production builds by defining NDEBUG; debate continues over whether assertions should remain enabled in released software, and whether they should be used to validate external input (generally discouraged, since they may be compiled out).

Relation to contracts and testing

Assertions are closely related to design by contract, where preconditions, postconditions and invariants state obligations on software components, and to unit testing, where assertion methods in test frameworks (such as assertEquals) verify expected behaviour of code under test.
