Property (programming)

In some object-oriented programming languages, a property is a special sort of class member, intermediate in functionality between a field (or data member) and a method. Properties are read and written like fields, but property reads and writes are (usually) translated to 'getter' and 'setter' method calls.

Purpose

Properties allow encapsulation: the underlying storage can change, validation and change notification can be added, and computed values can be exposed, all without changing the client code that uses the property. Languages with dedicated property support include C#, Delphi, Python (via the property decorator), Kotlin, and Swift, while other languages achieve the same effect by naming conventions for accessor methods.

Example

In C#, a property public int Width { get; set; } implicitly creates a backing field with generated accessors; explicit bodies can add logic to either accessor. In Python, @property turns a method into a read-only attribute, with @name.setter defining the write accessor.
