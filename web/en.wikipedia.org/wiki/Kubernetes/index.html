Kubernetes (also K8s) is an open-source container orchestration system for automating software deployment, scaling, and management. Originally designed by Google, the project is now maintained by a worldwide community of contributors, and the trademark is held by the Cloud Native Computing Foundation. The name derives from Ancient Greek κυβερνήτης (kubernḗtēs), meaning "helmsman" or "pilot"; the abbreviation K8s counts the eight letters between "K" and "s".

History

Kubernetes grew out of Google's internal cluster manager Borg, which had run Google's production services for over a decade. Google released Kubernetes as open source in 2014, influenced also by its Omega scheduler research; version 1.0 followed in July 2015, when Google donated the project to the newly formed Cloud Native Computing Foundation. It graduated from the CNCF in 2018 and became the de facto standard for container orchestration, offered as a managed service by every major cloud provider (GKE, EKS, AKS).

Architecture

Kubernetes groups machines into a cluster divided into a control plane and worker nodes. The control plane comprises the API server (the system's front door), etcd (a distributed key-value store holding cluster state), the scheduler (which assigns workloads to nodes), and controller managers that run reconciliation loops driving the actual state toward the desired state. On each node, the kubelet agent manages Pods — the smallest deployable units, each holding one or more containers sharing storage and network resources.

Workload resources

Users declare desired state in YAML or JSON manifests. Core objects include Deployments (declarative management of replicated Pods with rolling updates), Services (stable network endpoints with load balancing), ConfigMaps and Secrets (configuration), Namespaces (virtual partitions), and StatefulSets and DaemonSets for stateful and per-node workloads. The command-line tool is kubectl; packages of manifests are commonly distributed as Helm charts.

Adoption and criticism

Kubernetes underpins much of modern cloud-native computing and anchors a large ecosystem of networking, storage, and observability plugins. Its power comes with acknowledged complexity, prompting a market of managed services, distributions, and simpler alternatives, as well as debate about over-engineering for small deployments.
