Mathematical structure

A lattice — a set equipped with operations and relations — exemplifies a mathematical structure.

In mathematics, a structure is a set provided with some additional features on the set (e.g., an operation, relation, metric, or topology). Examples of features include an algebraic operation (as in a group or ring), an order relation (as in a partially ordered set), a distance function (as in a metric space), or a collection of open sets (as in a topological space). The additional features must satisfy certain properties (axioms) that define the type of structure.

Definition and examples

Formally, a structure consists of a base set (or several "sorts" of sets) together with distinguished elements, functions, and relations on it. A group is a set with one binary operation satisfying associativity, identity, and inverse axioms; a vector space is a set with operations of addition and scalar multiplication over a field; a graph is a set of vertices with a symmetric relation of adjacency; a measure space is a set with a σ-algebra and a measure.

Structure-preserving maps

Mathematics studies structures largely through the maps that preserve them: homomorphisms between algebraic structures, continuous maps between topological spaces, isometries between metric spaces. An isomorphism is a bijective structure-preserving map with structure-preserving inverse; isomorphic structures are, for most mathematical purposes, considered the same. Category theory generalizes this picture by treating structures as objects and their structure-preserving maps as morphisms.

Structures in logic

In model theory, a structure for a formal language interprets its symbols as sets, elements, functions, and relations, allowing one to say whether a sentence is true in the structure. This precise notion underlies much of modern mathematical logic.

Bourbaki and structuralism

The French collective Nicolas Bourbaki organized mathematics around "mother structures" — algebraic, order, and topological — and their combinations, an approach that dominated mid-20th-century mathematical exposition. In the philosophy of mathematics, structuralism holds that mathematical objects are merely positions in structures, with no intrinsic nature beyond the relations they bear to other positions.
