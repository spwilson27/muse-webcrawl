Deb (file format)

Deb is the file format and extension (.deb) of the software package format used by Debian and its derivatives, such as Ubuntu.

A .deb file is an ar archive containing three members: a version file, a control archive with package metadata and maintainer scripts, and a data archive containing the files to be installed. Packages are managed with tools such as dpkg and APT.

History

The format was introduced with Debian 0.91 in 1994–95 and remains the standard packaging format for the Debian family of distributions.
