Home Run Derby

The Home Run Derby is an annual home run hitting competition in Major League Baseball (MLB), usually held the day before the MLB All-Star Game. Eight sluggers compete to hit as many home runs as possible in timed rounds, with the event's format having evolved several times since its modern inauguration in 1985.

Format

Under the timed format introduced in 2015, batters receive a set time (originally four minutes) per round to hit as many home runs as possible, with bonus time awarded for especially long home runs. The contest proceeds as a single-elimination bracket seeded by regular-season home run totals. Earlier formats used "outs" — ten non-home-run swings per round.

Notable winners

Ken Griffey Jr. won the event a record three times (1994, 1998, 1999). Other multiple winners include Prince Fielder, Yoenis Céspedes, and Pete Alonso. Memorable performances include Josh Hamilton's 28 home runs in a single round at Yankee Stadium in 2008 and the 2019 duel between Vladimir Guerrero Jr. and Joc Pederson. The event traces its name to a 1960 television series, Home Run Derby, filmed at Wrigley Field in Los Angeles, in which stars such as Mickey Mantle and Willie Mays competed.
