Validity (logic)

In logic, specifically in deductive reasoning, an argument is valid if and only if it takes a form that makes it impossible for the premises to be true and the conclusion nevertheless to be false. Validity is a property of the argument's form, not of the actual truth of its premises or conclusion.

FieldLogic, philosophy
Related conceptsSoundness, entailment, syllogism

Definition

A valid argument need not have true premises. For example: "All cats are mammals; Socrates is a cat; therefore Socrates is a mammal" is valid in form, although a premise is false. An argument that is both valid and has all true premises is called sound.

Valid argument forms

Classic valid forms include modus ponens ("If P then Q; P; therefore Q"), modus tollens, hypothetical syllogism and disjunctive syllogism. In Aristotelian logic, syllogisms such as Barbara are valid categorical forms.

Validity and soundness

Soundness guarantees a true conclusion because the form preserves truth and the premises are true. Validity alone does not. Inductive arguments are not assessed as valid or invalid but as strong or weak, cogent or uncogent.

Formal validity

In formal and mathematical logic, validity is defined relative to a semantics: a formula is valid if it is true under every interpretation or model. A deductive system is sound if it proves only valid formulas, and complete if it can prove every valid formula.
