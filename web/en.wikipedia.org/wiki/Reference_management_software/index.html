Reference management software

Image placeholder: a typical reference manager interface.

Reference management software, also called citation management software or bibliographic software, is software used by scholars and authors to record, store and organise bibliographic references and to generate citations and bibliographies in documents. Most packages integrate with word processors and can format references in thousands of journal styles.

Features

Typical features include importing metadata from scholarly databases by DOI or ISBN, organising references in folders or tags, storing and annotating PDF full texts, synchronising libraries across devices, and collaborating through shared group libraries. Data are exchanged using formats such as BibTeX, RIS and CSL (Citation Style Language).

Notable packages

Widely used reference managers include Zotero, Mendeley, EndNote, and JabRef, alongside tools built into research platforms. Zotero is open source and developed by a non-profit; Mendeley is owned by Elsevier; EndNote is a long-established commercial product from Clarivate.
