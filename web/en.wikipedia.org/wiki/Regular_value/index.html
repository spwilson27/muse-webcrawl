Regular value

From Wikipedia, the free encyclopedia

In differential topology, a regular value of a smooth map between manifolds is a value in the codomain at which every preimage point is a regular point — that is, a point where the differential of the map is surjective. Values that are not regular values are called critical values, and points mapping to them in a non-surjective way are critical points.

Definition

Let f : M → N be a smooth map between smooth manifolds. A point p ∈ M is a regular point of f if the differential dfp : TpM → Tf(p)N is surjective. A point q ∈ N is a regular value if every point of the preimage f−1(q) is a regular point; by convention, a value with empty preimage is also a regular value.

Theorems

The regular value theorem (or preimage theorem) states that the preimage of a regular value is a smooth submanifold of the domain, of dimension dim M − dim N. Sard's theorem states that the set of critical values of a sufficiently smooth map has measure zero, so regular values are dense in the codomain. These results underlie transversality theory, intersection theory and much of Morse theory.
