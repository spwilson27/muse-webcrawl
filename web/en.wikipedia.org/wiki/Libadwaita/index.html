libadwaita is a library that implements the Adwaita design language for GTK 4 applications. It is developed as part of the GNOME project and provides a collection of widgets, styles, and utilities that help developers build applications consistent with the GNOME Human Interface Guidelines (HIG).

The library is the successor to libhandy, a library originally created for GTK 3 that added adaptive widgets suitable for both desktop and mobile form factors. With the release of GTK 4, libhandy's functionality was reworked and expanded into libadwaita, which was first released in early 2022 alongside GNOME 42.

Features

libadwaita provides widgets such as AdwApplicationWindow, AdwHeaderBar, AdwViewStack and AdwViewSwitcher for navigation, AdwFlap and AdwLeaflet for adaptive layouts, and various "boxed list" and preference widgets for settings interfaces. It also ships the Adwaita stylesheet, which defines the standard light and dark color schemes used by GNOME applications, along with support for high-contrast variants and system-wide dark style preferences.

The library supports adaptive design: applications built with libadwaita can adjust their layout when resized, collapsing sidebars and switching navigation patterns so that the same application works on large desktop monitors and on small touchscreens, such as those of Linux smartphones.

Reception

libadwaita has been a subject of discussion in the wider Linux desktop community. Some downstream distributors and theme developers criticized the difficulty of re-theming libadwaita applications compared with GTK 3 applications, since the library discourages user themes in favor of a consistent platform appearance. GNOME developers have argued that the approach improves consistency and reduces breakage caused by third-party themes.
