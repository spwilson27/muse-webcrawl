Post's lattice

In logic and universal algebra, Post's lattice is the lattice of all clones on a two-element set {0, 1} ordered by inclusion. A clone in this setting is a set of Boolean functions closed under composition and containing all projection functions; Post's lattice therefore classifies all sets of Boolean functions closed under superposition (composition and variable manipulation). It is named after Emil Post, who published the complete classification in his 1941 monograph The Two-Valued Iterative Systems of Mathematical Logic.

Description

Unlike the situation for three-element or larger sets — where the lattice of clones is of cardinality of the continuum — the lattice of Boolean clones is countable and can be described completely and explicitly. Post's diagram shows every Boolean clone, with the clones ordered by set inclusion, culminating in the clone of all Boolean functions and descending to the minimal clones generated by single operations such as conjunction, disjunction, negation, the majority function and the dual discriminator.

The maximal proper clones (the coatoms of the lattice, just below the clone of all functions) correspond exactly to the five classes appearing in Post's functional completeness criterion:

  • T0 — the 0-preserving functions
  • T1 — the 1-preserving functions
  • M — the monotone functions
  • S — the self-dual functions
  • L — the affine (linear) functions

Post's completeness criterion

A set of Boolean functions is functionally complete — that is, generates the clone of all Boolean functions — if and only if it is not contained in any of these five maximal clones; equivalently, for each of the five properties, the set contains some function not having that property. This classical result answers the question of which sets of logical connectives suffice to express every truth function, and is a standard part of courses in mathematical logic and switching theory.
