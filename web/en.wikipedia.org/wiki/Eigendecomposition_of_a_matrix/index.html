Eigendecomposition of a matrix

Eigenvectors point in directions a transformation only stretches

In linear algebra, eigendecomposition is the factorization of a matrix into a canonical form expressed through its eigenvalues and eigenvectors. A square matrix that admits such a factorization is called diagonalizable.

Definition

Let A be an n × n matrix with n linearly independent eigenvectors qi and corresponding eigenvalues λi, so that A qi = λi qi. Collecting the eigenvectors as columns of a matrix Q and the eigenvalues into a diagonal matrix Λ gives:

A = Q Λ Q−1

A matrix is diagonalizable if and only if it has a full set of linearly independent eigenvectors; matrices that do not are called defective and can at best be put in Jordan normal form.

Special cases

Every real symmetric matrix can be eigendecomposed with an orthogonal matrix of eigenvectors, A = Q Λ QT — the spectral theorem. More generally, normal matrices are unitarily diagonalizable. The decomposition is closely related to the singular value decomposition, which exists for every matrix.

Applications

Eigendecomposition makes powers and functions of matrices easy to compute (since Ak = Q ΛkQ−1), and underlies principal component analysis, the solution of systems of linear differential equations, vibration analysis, Google's PageRank, and the spectral methods of quantum mechanics, where observable operators are decomposed into states with definite values.
