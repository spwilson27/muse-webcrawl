In telecommunications and computing, bit rate (bitrate or as a variable R) is the number of bits that are conveyed or processed per unit of time. The bit rate is expressed in the unit bit per second (symbol: bit/s), often in conjunction with an SI prefix such as kilo (1 kbit/s = 1,000 bit/s), mega (1 Mbit/s = 1,000 kbit/s), giga (1 Gbit/s), or tera (1 Tbit/s).

Gross and net bit rates

The gross bit rate counts all transmitted bits, including protocol overhead, error-correction codes, and synchronization symbols. The net bit rate—also called data rate or throughput—counts only useful information. For example, a classic 56 kbit/s modem had a lower net rate after overhead, while a Gigabit Ethernet link nominally carries 1 Gbit/s at the physical layer. Bit rate should be distinguished from baud, the number of signal changes per second; with multilevel modulation a channel can convey several bits per symbol.

Media encoding

In digital audio and video, bit rate determines file size and streaming requirements: an uncompressed CD audio stream is 1,411.2 kbit/s, MP3 files are commonly encoded at 128–320 kbit/s, and high-definition streaming video typically uses several Mbit/s. Compression may use constant bit rate (CBR) or variable bit rate (VBR) encoding.
