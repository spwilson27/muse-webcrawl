Point set registration

Two point clouds being aligned by a rigid transformation

Point set registration, also known as point cloud registration, is the process of finding a spatial transformation — typically a rotation and translation, possibly with scaling or a more general deformation — that aligns one set of points with another. The two point sets may come from different sensor scans of the same scene, from a model and a measurement, or from images taken at different times.

Problem formulation

Given a model point set and a scene point set, registration seeks the transformation minimising an error measure between corresponding points. When correspondences are unknown, the problem is harder and usually solved iteratively. Rigid registration preserves all distances and is described by a rotation matrix and a translation vector; non-rigid registration additionally allows local warping.

Algorithms

The best-known algorithm is iterative closest point (ICP), which alternates between assigning each point its nearest neighbour in the other set and computing the least-squares optimal transformation, for example via the Kabsch algorithm using singular value decomposition. Other approaches include coherent point drift, which treats alignment as probability density estimation, and robust methods that use random sample consensus or feature matching to reject outliers. Applications include 3D reconstruction, robotics and SLAM, medical image fusion, and object recognition.
