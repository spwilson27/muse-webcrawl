Volatile memory

DRAM modules store data only while powered

Volatile memory, in contrast to non-volatile memory, is computer memory that requires power to maintain the stored information; it retains its contents while powered on but loses them when the power is interrupted. Most general-purpose random-access memory (RAM) is volatile.

Types

The two main subtypes are dynamic RAM (DRAM) and static RAM (SRAM). DRAM stores each bit as charge in a capacitor that leaks away, so it must be refreshed periodically — thousands of times per second — but is dense and inexpensive, and is used as main memory in most computers. SRAM stores bits in bistable flip-flop circuits of four to six transistors; it is faster and requires no refresh while powered, but is larger and costlier per bit, and is used for processor caches and registers. Both lose their state essentially immediately when power is removed, though forensic research has shown that DRAM contents may decay over seconds to minutes, a fact exploited in cold boot attacks — especially when memory chips are cooled to slow decay.

Uses and implications

Volatile memory is used wherever speed matters more than persistence: main memory, CPU caches, graphics memory and buffers. Because its contents vanish at power-off, systems store programs and data persistently on non-volatile media (hard disks, flash memory, ROM) and load them into volatile memory for execution. Historically magnetic core memory was non-volatile, and emerging technologies such as MRAM and FeRAM aim to combine RAM-like speed with non-volatility.
