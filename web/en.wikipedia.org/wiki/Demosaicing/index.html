Demosaicing

From Wikipedia, the free encyclopedia

Demosaicing (also de-mosaicing, demosaicking, or debayering) is a digital image processing algorithm used to reconstruct a full-colour image from the incomplete colour samples output by an image sensor overlaid with a colour filter array (CFA). Most modern digital cameras use a single sensor with the Bayer filter mosaic, in which each pixel records only one of the three primary colours — half the pixels green, and a quarter each red and blue — so demosaicing must interpolate the two missing colour values at every pixel.

Goal

The aim of demosaicing is to reconstruct a full-resolution colour image while avoiding visible artefacts such as colour fringing, zippering along edges, and false-colour moiré patterns. Because human vision is more sensitive to luminance detail than to colour detail, good algorithms interpolate along edges rather than across them, exploiting correlations between the colour channels.

Methods

The simplest method, bilinear interpolation, averages the neighbouring samples of each missing colour; it is fast but produces soft images with pronounced edge artefacts. More advanced methods include edge-directed interpolation, which chooses the interpolation direction based on local gradients; constant-hue and median-based methods; frequency-domain approaches; and modern learning-based methods using convolutional neural networks. Demosaicing is performed either in-camera when producing JPEG files, or by raw conversion software on a computer, where more sophisticated algorithms can be applied.

Artefacts

Poor demosaicing produces characteristic defects: zipper effects along high-contrast edges, maze patterns in fine textures, and rainbow moiré in repeating details such as fabrics. These artefacts are one reason some cameras use alternative sensor designs — stacked sensors such as Foveon X3, three-sensor beam-splitter systems, or pixel-shift multi-shot modes — that capture full colour at every location and avoid demosaicing altogether.
