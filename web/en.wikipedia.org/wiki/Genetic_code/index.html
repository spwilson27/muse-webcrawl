Genetic code

From Wikipedia, the free encyclopedia

The genetic code is the set of rules by which information encoded in DNA and RNA sequences is translated into proteins. It is written in codons — triplets of nucleotides — each specifying one amino acid (or a stop signal): 64 codons for 20 standard amino acids, so the code is redundant (several codons per amino acid) but unambiguous (each codon means one thing).

Cracking the code

The code was deciphered in the 1960s: Nirenberg and Matthaei showed in 1961 that UUU specifies phenylalanine; Khorana's synthetic RNAs and Nirenberg's binding assays filled the table by 1966, earning the 1968 Nobel Prize. Crick's group proved the triplet, comma-free reading frame by genetic experiments in phage. The code's near-universality across all life — the same table in bacteria and in us — is among the strongest evidences for common descent (see life), and its few variants (in mitochondria and some microbes) are themselves evolutionary clues.

The code's structure appears non-random — similar codons name similar amino acids, buffering mutation — and it is the dictionary at the heart of molecular biology, read aloud by the ribosome, itself a ribozyme, at the centre of every cell.
