GNU Debugger

The GNU Debugger (GDB) is the standard debugger for the GNU software system. It is a portable debugger that runs on many Unix-like systems and works for many programming languages, including Ada, C, C++, D, Fortran, Go, and Rust.

A GDB session examining a crashed program.

History

GDB was written by Richard Stallman in 1986 as part of the GNU system, after his work on GNU Emacs. It was modelled on the DBX debugger found on Berkeley Unix systems. From 1990 to 1993 it was maintained by John Gilmore while he was with Cygnus Support. GDB is free software released under the GNU General Public License.

Features

GDB offers typical debugging facilities, such as:

  • Starting a program and controlling its execution
  • Setting breakpoints that halt execution at specified locations or on conditions
  • Examining the call stack, variables, and memory when the program stops
  • Altering variables and calling functions in the debugged program
  • Remote debugging of programs running on another machine or an embedded target
  • Reverse debugging (record and replay) on supported platforms

GDB has a command-line interface, a curses-based text user interface (TUI), and a machine interface (GDB/MI) used by integrated development environments. It can be scripted in Python.

Example

$ gdb ./a.out
(gdb) break main
(gdb) run
(gdb) print x
(gdb) continue
