NVM Express

NVM Express (NVMe), or Non-Volatile Memory Host Controller Interface Specification (NVMHCI), is an open logical-device interface specification for accessing a computer's non-volatile storage media, usually solid-state drives (SSDs), attached via the PCI Express bus. It was designed from the ground up to exploit the low latency and internal parallelism of flash memory, in contrast to older protocols such as AHCI that were built for spinning hard disks.

History

The first specification was released in March 2011 by a working group of more than 90 companies; the standard is now maintained by NVM Express, Inc. Subsequent revisions added features such as namespaces, commands for management, NVMe over Fabrics (2016) — which extends NVMe across networks using RDMA or Fibre Channel — and later computational storage and zoned namespaces.

Advantages

NVMe supports up to 65,535 command queues with up to 65,536 commands each, drastically reducing CPU overhead and enabling the massive queue depths that parallel flash devices can service. The result is much lower latency and higher input/output operations per second (IOPS) than SATA/AHCI SSDs, along with reduced power consumption. NVMe drives are common in the M.2, U.2 and add-in-card form factors and are standard in modern laptops, desktops, servers and game consoles.
