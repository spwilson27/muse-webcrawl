Heterogeneous computing

Heterogeneous computing refers to systems that use more than one kind of processor or core, combining general-purpose CPUs with accelerators such as GPUs, DSPs, FPGAs or AI accelerators, each optimised for different kinds of work.

Overview

Amdahl's law and the end of Dennard scaling pushed designers toward specialised units: graphics processors for parallel floating-point work, tensor cores for machine learning, and fixed-function blocks for video encode/decode. Programming models such as CUDA, OpenCL, SYCL and heterogeneous system architecture (HSA) aim to present a unified memory and scheduling model.

Examples

Modern smartphones pair performance and efficiency CPU cores with GPUs and neural engines (big.LITTLE and successors). Supercomputers such as Frontier combine CPUs with GPU accelerators to reach exascale performance.

Challenges

Data movement between memories, load balancing, and programming complexity are the principal costs of heterogeneity.
