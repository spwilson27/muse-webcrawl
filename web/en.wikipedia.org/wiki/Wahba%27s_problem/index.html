Wahba's problem

Wahba's problem, first posed by Grace Wahba in 1965, concerns the determination of a rotation matrix (attitude) from a set of vector observations. Given two sets of vectors — measurements made in a body-fixed frame and corresponding reference vectors known in an inertial frame — the problem is to find the rotation matrix R that best maps one set onto the other in a least-squares sense, minimizing a loss function weighted by the confidence in each measurement.

Formulation

Given reference vectors vi and observed vectors wi, with weights ai summing to one, Wahba's loss function is:

L(R) = ½ Σ ai |wi − R vi|²

The optimal rotation minimizes this loss subject to R being an orthogonal matrix with determinant +1.

Solutions

Several algorithms solve Wahba's problem, including:

  • Davenport's q-method – formulates the problem using quaternions and finds the optimal attitude as the eigenvector of a 4×4 matrix.
  • QUEST (Quaternion Estimator) – a computationally faster algorithm by Malcolm Shuster, widely used in spacecraft.
  • SVD method – based on the singular value decomposition of the attitude profile matrix.
  • FOAM, ESOQ and related methods – later refinements for speed and robustness.

Applications

Wahba's problem is central to spacecraft attitude determination using star trackers, sun sensors, and magnetometers, and also appears in robotics, computer vision, and point set registration.
