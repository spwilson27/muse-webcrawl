Martin-Löf type theory

Martin-Löf type theory (MLTT), also known as intuitionistic or constructive type theory, is a formal system developed by Swedish logician Per Martin-Löf beginning in the early 1970s. It serves both as a foundation for constructive mathematics and as the theoretical basis for several proof assistants and dependently typed programming languages, including Agda and, indirectly, Coq and Lean.

Overview

Type theory is built on judgments, principally of the form "a is a term of type A". Unlike set theory, where membership is a proposition, typing is a judgment made by the system itself. Under the Curry–Howard correspondence, types correspond to propositions and terms to proofs, so a well-typed program is simultaneously a verified proof.

Key constructions

The theory provides product (Π) and sum (Σ) types, identity types whose elimination rule (the J rule) encodes equality reasoning, inductive types such as the natural numbers and the empty and unit types, W-types, and a hierarchy of universes to avoid paradoxes. Martin-Löf published successive versions in 1972, 1979, and a widely cited exposition in his 1984 Intuitionistic Type Theory notes.

Influence

MLTT underlies homotopy type theory, where identity types are interpreted as paths in spaces, and remains a central reference point in research on the foundations of mathematics and verified software.
