Lambda calculus

Lambda calculus (also written as λ-calculus) is a formal system in mathematical logic for expressing computation based on function abstraction and application using variable binding and substitution. It is a universal model of computation that can be used to simulate any Turing machine.

History

It was introduced by the mathematician Alonzo Church in the 1930s as part of his research into the foundations of mathematics. The lambda calculus was an influential framework in the development of functional programming languages.

Syntax

Lambda expressions are built from variables, abstractions (λx.M) and applications (M N). Computation proceeds by beta reduction: substituting the argument for the bound variable in the body of an abstraction.
