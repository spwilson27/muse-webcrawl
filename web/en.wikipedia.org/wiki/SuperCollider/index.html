SuperCollider

The SuperCollider IDE, showing code and audio server output

SuperCollider is a free and open-source programming language and environment for real-time audio synthesis and algorithmic composition. Originally developed by James McCartney and released in 1996, it has become one of the most widely used platforms for computer music research, live coding and sound art. SuperCollider is available for macOS, Windows and Linux under the GNU General Public License.

Architecture

The system has two main components. The language, sclang, is a dynamic, object-oriented language in the Smalltalk tradition, with garbage collection, closures and a large class library for musical structures, patterns and GUI building. The audio server, scsynth, is a separate application that performs all sound generation in real time; the language (and other clients) control it via Open Sound Control (OSC) messages. Unit generators (UGens) — oscillators, filters, envelopes and delays — are connected into SynthDefs on the server, allowing efficient graphs of thousands of sound sources.

// a simple synth definition and pattern
SynthDef(\ping, { |freq=440|
  Out.ar(0, SinOsc.ar(freq) * EnvGen.kr(Env.perc, doneAction: 2) * 0.2)
}).add;
Pbind(\instrument, \ping, \degree, Pseq([0,2,4,7], inf)).play;

Use

SuperCollider is used in academia for research in synthesis and human–computer interaction, by live coders who perform by writing and modifying code on stage, and in installations and games. Its pattern library, which streams musical events with precise timing, and its support for multichannel and spatial audio make it a standard tool in electroacoustic composition. A large community maintains extensions ("Quarks") and the scsynth server has been embedded in other environments.
