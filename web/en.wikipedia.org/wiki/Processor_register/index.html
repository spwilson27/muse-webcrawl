Processor register

From Wikipedia, the free encyclopedia

A processor register is a small amount of very fast memory located inside a central processing unit (CPU). Registers hold the data, addresses and control information the processor is actively working on, and are the fastest storage in the memory hierarchy — typically accessible in a single clock cycle, far faster than cache or main memory.

Categories

General-purpose registers hold operands and results of arithmetic and logic. Special-purpose registers include the program counter (instruction pointer), which holds the address of the next instruction; the stack pointer; the instruction register; and the status/flags register recording conditions such as zero, carry, sign and overflow. Floating-point and vector (SIMD) registers hold numeric data in wider formats. Control registers hold processor configuration, such as page-table addresses and privilege settings.

Register files

Registers are organised in a register file, whose size is a defining feature of an instruction set architecture: the classic x86 had only a handful of general registers, x86-64 has 16 general-purpose 64-bit registers plus 16 or more vector registers, while RISC architectures such as ARM64 provide 31 general-purpose registers. Compilers perform register allocation to keep frequently used values in registers, spilling the rest to memory.

Microarchitecture

Modern out-of-order processors use register renaming, mapping a modest number of architectural registers onto a much larger pool of physical registers to remove false dependencies and enable parallel execution.
