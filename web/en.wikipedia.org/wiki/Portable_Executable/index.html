Portable Executable

The Portable Executable (PE) format is a file format for executables, object code and DLLs used in 32-bit and 64-bit versions of the Microsoft Windows operating system. The 64-bit extension, PE32+, is used by Windows on x86-64 and ARM64. The format derives from the Unix COFF format and is used for .exe, .dll, .sys and other binary files.

Structure

A PE file begins with an MS-DOS stub (starting with the letters "MZ") that prints a message under DOS, followed by the PE signature "PE\0\0". After this come the COFF file header, an "optional" header — which is in fact required for executables and contains fields such as the entry point address, image base and subsystem — and a table of section headers. Sections hold the actual content: typically .text for code, .rdata for read-only data and import tables, .data for initialised data, and .rsrc for resources such as icons and dialogs.

Imports and relocations

PE files record the DLLs and functions they import so the Windows loader can resolve addresses at load time, and may include relocation information allowing the image to be loaded at an address other than its preferred base — a feature relied on by address space layout randomisation (ASLR).

Uses

Beyond ordinary applications, the PE format is used for UEFI firmware executables and by the .NET framework, whose assemblies are PE files containing Common Intermediate Language code and a CLR header.
