An ordered pair (x, y) locates a point in the plane; order matters, so (2, 3) ≠ (3, 2).

In mathematics, an ordered pair (a, b) is a pair of objects in which the order of the elements matters: the ordered pair (a, b) is different from the ordered pair (b, a) unless a = b. The element a is called the first entry (or first coordinate) and b the second entry. Ordered pairs are also called 2-tuples, and generalizations to more entries give tuples.

Defining property

The characteristic property of ordered pairs is that (a, b) = (c, d) if and only if a = c and b = d. Any definition of the ordered pair in set theory must realize this property.

Set-theoretic definitions

Kazimierz Kuratowski's widely used definition (1921) sets (a, b) = {{a}, {a, b}}, from which the defining property can be proved. Earlier definitions were given by Norbert Wiener (1914) and Felix Hausdorff. Ordered pairs underlie the definitions of Cartesian products, relations, and functions: a function is often defined as a set of ordered pairs.

Uses

Coordinate geometry uses ordered pairs of real numbers for points in the plane; ordered pairs also appear as complex numbers (a, b) for a + bi, as inputs and outputs of functions, and throughout algebra, logic, and computer science.
