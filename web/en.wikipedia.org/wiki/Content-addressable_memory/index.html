Content-addressable memory

Content-addressable memory (CAM) is a special type of computer memory used in certain very-high-speed searching applications. Unlike standard memory (RAM), in which the user supplies an address and the RAM returns the data stored at that address, CAM is designed so that the user supplies a search word and the CAM searches its entire memory in parallel to see whether that word is stored anywhere in it, returning the address(es) of any matches — typically in a single clock cycle. Because of this parallel search capability, CAM is much faster than RAM for search applications, but it is also significantly more expensive and power-hungry, since every cell must contain comparison circuitry.

Types

Binary CAM stores words made only of "1"s and "0"s and returns a match only on an exact equality. Ternary CAM (TCAM) adds a third state, "don't care" (X), for one or more bits, allowing wildcard and longest-prefix matching; TCAMs are the standard technology in high-performance network routers for storing forwarding tables and access-control lists, where the longest matching prefix must be found at line rate. Software alternatives such as hash tables and tries trade some speed for much lower cost per bit.

Applications

Beyond routing, CAMs and TCAMs are used in CPU cache tags and translation lookaside buffers (in associative form), database accelerators, pattern matching and intrusion-detection engines, and data compression hardware. The high cost per bit confines CAM to relatively small, performance-critical tables; commodity systems use SRAM-based algorithmic lookups instead. In neuroscience and cognitive science, "content-addressable memory" also describes a property of biological and artificial associative memories — such as Hopfield networks — in which stored patterns can be retrieved from partial or noisy cues.
