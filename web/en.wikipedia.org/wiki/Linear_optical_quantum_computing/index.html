Linear optical quantum computing

Linear optical quantum computing (LOQC) is a model of quantum computation in which information is encoded in photons and processed using linear optical elements such as beam splitters, phase shifters, and mirrors, together with single-photon sources and photon-counting detectors.

Because photons interact only very weakly with one another, direct two-photon gates are difficult. LOQC overcomes this by using measurement to induce effective nonlinearities between photons.

KLM scheme

In 2001, Emanuel Knill, Raymond Laflamme, and Gerard Milburn showed that universal quantum computation is possible using only linear optics, single-photon sources, and photodetectors — the KLM scheme. It uses teleportation-based gates and error encoding to achieve near-deterministic two-qubit operations probabilistically.

Implementations and challenges

Key experimental challenges include producing indistinguishable single photons on demand, building low-loss integrated photonic circuits, and achieving high-efficiency photon-number-resolving detection. Integrated silicon and silicon-nitride photonic chips have become a leading platform.
