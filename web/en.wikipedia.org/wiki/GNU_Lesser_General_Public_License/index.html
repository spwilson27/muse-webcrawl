The GNU Lesser General Public License (LGPL) is a free-software license published by the Free Software Foundation (FSF). The license allows developers and companies to use and integrate a software component released under the LGPL into their own (even proprietary) software without being required by the terms of a strong copyleft license to release the source code of their own components. However, any developer who modifies an LGPL-covered component is required to make their modified version available under the same LGPL license. For proprietary software, LGPL-licensed software components are typically used in the form of a shared library, so that there is a clear separation between the proprietary and LGPL components.

The LGPL was first published in 1991 as the GNU Library General Public License, a companion to the GNU General Public License (GPL). It was renamed with the release of version 2.1 in 1999 to reflect the FSF's position that the license should not necessarily be used for all libraries. Version 3 of the LGPL was published in 2007 as a list of additional permissions applied to GPL version 3.

History

The license was originally called the GNU Library General Public License and was first released in 1991. It was adopted as a strategy for promoting free software libraries: the FSF reasoned that requiring all programs using a library to be free software could discourage adoption of the library when functionally equivalent proprietary libraries existed, and that placing the library under the LGPL would allow the free library to compete while still keeping the library itself free.

Differences from the GPL

The main difference between the GPL and the LGPL is that the latter allows the work to be linked with (in the case of a library, "used by") a non-(L)GPLed program, regardless of whether it is free software or proprietary software. The non-(L)GPLed program can then be distributed under any terms if it is not a derivative work. If it is a derivative work, then the program's terms must allow for "modification for the customer's own use and reverse engineering for debugging such modifications" of the work.

Compatibility

One feature of the LGPL is the permission to sublicense under the GPL any piece of software which is received under the LGPL (see section 3 of the LGPL version 2.1, and section 2 option b of the LGPL version 3). This feature allows the developer of GPL-covered software to integrate LGPL-covered parts while keeping the whole work under the GPL.
