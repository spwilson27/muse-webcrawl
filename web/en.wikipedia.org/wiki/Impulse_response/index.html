Impulse response

In signal processing and control theory, the impulse response of a dynamic system is its output when presented with a brief input signal called an impulse (in continuous time, the Dirac delta function). More generally, an impulse response is the reaction of any dynamic system in response to some external change.

Linear time-invariant systems

For a linear time-invariant (LTI) system, the impulse response completely characterises the system: the response to any input can be computed by convolving the input with the impulse response. The Laplace transform of the impulse response is the system's transfer function, and its Fourier transform is the frequency response. A system is stable, in the bounded-input bounded-output sense, if its impulse response is absolutely integrable.

Applications

Impulse responses are measured in acoustics to characterise rooms and concert halls, and convolution with a measured impulse response is used in audio engineering to simulate spaces and equipment. In economics and econometrics, impulse response functions trace the effect of a shock to a variable through a model over time.
