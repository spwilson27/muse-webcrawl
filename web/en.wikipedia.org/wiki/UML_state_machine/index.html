UML state machine

The UML state machine, also known as a UML statechart, is an extension of the concept of the finite-state machine in the Unified Modeling Language (UML) for software and systems engineering. UML state diagrams represent the states of an object and the transitions between them triggered by events, and are used to model the dynamic behaviour of systems.

Concepts

UML state machines build on David Harel's statecharts, adding hierarchy and concurrency to classical Mealy and Moore machines. States may be nested (composite states), so that a transition at a high level applies to all substates; orthogonal regions allow an object to be in several states simultaneously. Transitions are annotated with the triggering event, an optional guard condition, and an action (event [guard] / action). States may define entry, exit, and do activities, and special pseudostates include the initial state, choice points, and history states that remember the last active substate.

Use

State diagrams are widely used for event-driven and reactive systems, user-interface behaviour, communication protocols, and embedded controllers. Because UML state machines have precisely defined execution semantics (including run-to-completion event processing), they can be used not just for documentation but directly for code generation in model-driven development tools.
