A return statement in source code

In computer programming, a return statement causes execution to leave the current subroutine and resume at the point in the code immediately after where the subroutine was called (its return address). It may also supply a value — the return value — to the caller.

Syntax and semantics

Most languages use the keyword return, as in C, Java, Python, and JavaScript: return expression;. A function may contain several return statements, and reaching the end of a function body may imply a return. In languages such as Ruby and Rust, the value of the last expression may be returned implicitly.

Considerations

Structured programming style often favours a single exit point for readability and easier reasoning about cleanup; other styles use early returns ("guard clauses") to avoid deep nesting. Returning also triggers stack-frame teardown and, in languages with destructors or finally blocks, associated cleanup code.
