Character encoding

In computing, a character encoding is a system that pairs each character in a character set with a sequence of bytes or numbers, allowing text to be stored and transmitted digitally. A character set (or repertoire) defines which characters exist; a coded character set assigns each a code point; and an encoding scheme specifies how code points are represented in bytes.

Text passes from abstract characters to code points to bytes through an encoding such as UTF-8.

History

Early systems such as Baudot code and Morse code encoded small alphabets for telegraphy. The ASCII standard (1963) defined 128 characters in seven bits and dominated early computing, but national variants and 8-bit extensions (the ISO 8859 family, Windows-1252 and others) multiplied incompatibly. East Asian scripts required multi-byte encodings such as Shift JIS and Big5.

Unicode

The Unicode Standard, first published in 1991, aims to assign a unique code point to every character of every writing system. Its principal encoding forms are UTF-8 (variable-width, ASCII-compatible, and dominant on the web), UTF-16 (used in many internal APIs), and UTF-32 (fixed-width). Incorrectly declaring or interpreting an encoding produces garbled text known as mojibake.

Concepts

Key concepts include the abstract character, the grapheme, byte order (endianness) and the byte-order mark, and transcoding between encodings. Modern standards recommend UTF-8 for interchange; the WHATWG Encoding Standard fixes how browsers interpret encoding labels.
