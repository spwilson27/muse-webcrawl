The Ford–Fulkerson algorithm is a greedy algorithm that computes the maximum flow in a flow network. It was published in 1956 by L. R. Ford Jr. and D. R. Fulkerson. The algorithm works by repeatedly finding an augmenting path from source to sink in the residual graph and pushing as much additional flow along it as possible, until no such path remains.

Algorithm

Given a network with capacities, maintain a residual graph in which each edge records the remaining capacity, together with reverse edges representing flow that can be cancelled. While there exists a path from the source s to the sink t in the residual graph, find the bottleneck (minimum residual capacity) along the path and augment the flow by that amount. When no augmenting path exists, the flow is maximal; this follows from the max-flow min-cut theorem, which Ford and Fulkerson's work established.

flow = 0
while there is an s–t path P in the residual graph:
    b = minimum residual capacity on P
    send b units of flow along P
    flow = flow + b
return flow

Complexity

If capacities are integers, each augmentation increases the flow by at least one unit, so the running time is O(E · f), where E is the number of edges and f the value of the maximum flow — a pseudo-polynomial bound. With irrational capacities the naive method may fail to terminate. Choosing augmenting paths by breadth-first search (fewest edges) gives the Edmonds–Karp algorithm, which runs in O(VE²); choosing the shortest path in terms of residual capacity gives Dinic's algorithm, which is faster still.

Applications

Beyond transport and network-flow problems, the method underlies solutions to bipartite matching, circulation and assignment problems, image segmentation in computer vision, and the analysis of connectivity in networks.
