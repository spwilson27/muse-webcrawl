Complete lattice

In mathematics, a complete lattice is a partially ordered set in which every subset has both a supremum (join) and an infimum (meet). Complete lattices are a central structure in order theory and have applications in formal concept analysis, domain theory, and the semantics of programming languages.

Definition

A partially ordered set (L, ≤) is a complete lattice if for every subset S ⊆ L, the supremum sup S (the least upper bound of S) and the infimum inf S (the greatest lower bound of S) both exist in L. Taking S to be empty shows that a complete lattice always has a greatest element ⊤ = sup L = inf ∅ and a least element ⊥ = inf L = sup ∅.

Examples

  • The power set of any set, ordered by inclusion, with union as join and intersection as meet.
  • The closed interval [0, 1] of real numbers with the usual order.
  • The set of all subgroups of a group, ordered by inclusion.
  • Any finite lattice.

Properties

By the Knaster–Tarski theorem, every monotone function on a complete lattice has a complete lattice of fixed points; in particular it has a least and a greatest fixed point. This result is fundamental in denotational semantics and abstract interpretation. Complete lattices are also characterised as the partially ordered sets that are both complete join-semilattices and complete meet-semilattices.
