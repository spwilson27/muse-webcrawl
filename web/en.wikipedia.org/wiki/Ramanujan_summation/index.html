Ramanujan summation

FieldMathematical analysis
Named afterSrinivasa Ramanujan
PurposeAssigning values to divergent series

Ramanujan summation is a technique invented by the mathematician Srinivasa Ramanujan for assigning values to divergent infinite series. It is related to, but distinct from, the modern concept of summability. Ramanujan summation is based on the Euler–Maclaurin summation formula and produces values that agree with ordinary sums for convergent series.

The −1/12 result

The most famous example is the assignment of the value −1/12 to the divergent series 1 + 2 + 3 + 4 + ⋯. In a 1913 letter to G. H. Hardy, Ramanujan wrote that he had obtained this value by his theory; the result is connected with the value of the Riemann zeta function at −1, ζ(−1) = −1/12. The value is used in physics, for example in bosonic string theory and the calculation of the Casimir effect.

Definition

Using the Euler–Maclaurin formula with Bernoulli numbers, the Ramanujan sum of a series can be written in terms of an integral plus correction terms involving Bernoulli numbers, giving a canonical finite value for many divergent series while agreeing with the usual sum whenever the series converges.
