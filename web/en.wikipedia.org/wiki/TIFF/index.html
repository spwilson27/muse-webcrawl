TIFF

From Wikipedia, the free encyclopedia

Tag Image File Format, or TIFF, is a computer file format for storing raster graphics images, popular among graphic artists, the publishing industry and photographers. The format was created by the Aldus Corporation for use in desktop publishing. It is a flexible, adaptable format for handling multiple images and data in a single file, through the inclusion of "tags" that define the geometry and characteristics of the image.

History

TIFF was developed in the mid-1980s by Aldus, working with scanner manufacturers and Microsoft, to standardise the output of scanned images. Aldus merged into Adobe Inc. in 1994, and Adobe has since controlled the specification; TIFF 6.0 was published in 1992, with the format later standardised in part as ISO 12639 for prepress use and forming the basis of related formats such as GeoTIFF and the TIFF/EP raw image standard.

Format features

A TIFF file begins with a header indicating byte order (the "II" little-endian and "MM" big-endian signatures) and an offset to the first Image File Directory, a table of tag entries describing width, length, colour depth, photometric interpretation, strip or tile offsets and compression. TIFF supports grayscale, palette, RGB and CMYK colour, multiple images per file, and both lossy (JPEG) and lossless compression, including none, PackBits, LZW and Deflate. Its flexibility is also its weakness: the enormous number of tag combinations means some readers cannot handle every valid TIFF file.

Applications

TIFF remains standard in professional photography workflows, scanning and archiving, print production, fax (in a subset profile), medical and scientific imaging, and geographic information systems via GeoTIFF metadata. Because files are typically large, TIFF is rarely used for images on the web.
