Canonicalization

Image placeholder — many representations, one canonical form

In computer science, canonicalization (sometimes standardization or normalization) is a process for converting data that has more than one possible representation into a "standard", "normal", or canonical form. This can be done to compare different representations for equivalence, to count the number of distinct data structures, to improve the efficiency of various algorithms by eliminating repeated calculations, or to make it possible to impose a meaningful sorting order.

Examples

URLs and files

A canonical URL is the single authoritative address of a page among duplicates differing in scheme, case, trailing slashes or parameters; search engines use the rel="canonical" link element to consolidate ranking signals. In filesystems, canonical paths resolve symbolic links, "." and ".." components and case variations.

XML and security

XML canonicalization (C14N) produces a deterministic byte representation of an XML document so that digital signatures (XML Signature) remain valid despite harmless serialisation differences. Canonicalization is security-critical because inconsistent normalisation between components has enabled directory-traversal and signature-verification attacks.

Text and linguistics

In natural language processing and lexicography, canonical forms reduce words to base forms (lemmatisation) and normalise case, diacritics and whitespace. In mathematics, canonical forms include matrix normal forms such as Jordan and Smith normal forms.
