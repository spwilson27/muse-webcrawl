DOT (graph description language)

DOT
Type: Graph description language
Used by: Graphviz
File extension: .dot, .gv

DOT is a graph description language for describing graphs — nodes, edges and their attributes — in plain text. It is the input language of the Graphviz layout and visualisation software.

Syntax

A DOT file defines a graph (undirected) or digraph (directed) containing statements such as a -> b for edges and bracketed attribute lists controlling colour, shape, labels and layout. Subgraphs and clusters group related nodes.

Use

Because it is simple text, DOT is widely generated by other programs to visualise call graphs, dependency trees, state machines and network diagrams, and rendered by Graphviz tools such as dot, neato and circo to images or vector formats.
