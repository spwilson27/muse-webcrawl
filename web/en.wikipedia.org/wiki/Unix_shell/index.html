Unix shell

A shell session in a terminal emulator.

A Unix shell is a command-line interpreter that provides a text-based user interface for Unix and Unix-like operating systems. The shell is both an interactive command language and a scripting language, used to control the execution of programs, manipulate files, and automate tasks. Users type commands at a prompt, and the shell reads, parses, and executes them.

History

The first Unix shell was the Thompson shell (sh), written by Ken Thompson for the original Unix in 1971, itself influenced by the command interpreter of Multics. Stephen Bourne's Bourne shell (1977) became the standard scripting shell of Unix System V. The C shell (csh), written by Bill Joy at Berkeley, added interactive features such as history and job control with C-like syntax. Later shells include the Korn shell (ksh), the Bourne Again Shell (Bash, 1989), and the Z shell (zsh), now the default shell on macOS.

Features

Shells provide filename globbing (wildcard expansion), pipes that connect the output of one command to the input of another, input/output redirection, variables and control structures, command substitution, job control for background processes, and command-line editing and history. POSIX specifies a standard shell command language derived from the Bourne shell, implemented by sh on modern systems.

Shell scripting

Sequences of commands stored in a file, marked executable and beginning with a shebang line such as #!/bin/sh, form shell scripts — a foundational tool of system administration and build automation.
