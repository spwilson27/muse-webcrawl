Macro virus

TypeComputer virus
PlatformMicrosoft Office and other macro-enabled applications
LanguageVisual Basic for Applications (VBA), WordBasic
First major exampleConcept (1995)

A macro virus is a computer virus written in the macro language of an application, such as Microsoft Word or Excel, and embedded in a document or spreadsheet. When the infected file is opened, the application's macro interpreter executes the embedded code, which can replicate itself into other documents, alter or delete files, display messages, or download further malware. Because macros were designed to automate repetitive tasks, macro viruses abuse a legitimate feature rather than exploiting a software bug.

History

The first widely recognised macro virus, Concept, appeared in 1995 and spread in Microsoft Word documents. It was written in WordBasic and demonstrated that data files — previously considered safe — could carry executable infections. Later that decade the Melissa virus (1999) combined a Word macro virus with mass-mailing behaviour, propagating itself through Microsoft Outlook address books and overwhelming corporate mail servers; it caused an estimated tens of millions of dollars in disruption and prompted the FBI to issue warnings. The ILOVEYOU worm of 2000, though technically a script worm rather than a pure macro virus, showed the same lesson about trusting attachments.

Mechanism

Macro viruses typically hook into automatic macros such as AutoOpen, AutoClose or AutoExec, which run when a document is opened or closed. On execution, the virus copies its macro module into the application's global template (for Word, Normal.dot), so that every subsequently created or opened document becomes infected. Payloads range from harmless pranks — inserting random text or displaying jokes — to destructive actions such as corrupting documents, stealing data, or installing backdoors.

Defences

Modern versions of Microsoft Office disable macros by default in files originating from the internet, display prominent security warnings, and mark downloaded files with the "Mark of the Web" so macros are blocked. Antivirus software scans documents for known malicious macro patterns, and organisations commonly disable macros entirely or restrict them to digitally signed code. In 2022 Microsoft moved to block VBA macros by default in Office files downloaded from the internet, sharply reducing the prevalence of this infection vector.
