Comparison of executable file formats

This is a comparison of executable file formats — the binary formats used to store programs that an operating system can load and run. Formats differ in their support for features such as dynamic linking, position-independent code, debugging metadata, digital signatures, architecture-independent ("fat") binaries, and metadata resources.

Feature discussion

ELF dominates the Unix-like world and is also used for kernel images, firmware and game consoles. It organises files into sections for linking and segments for loading, and supports shared libraries, position-independent executables and rich debugging information. PE, derived from COFF, underlies Windows executables and DLLs; it embeds Win32 resources such as icons and dialogs, and supports Authenticode digital signatures. Mach-O serves Apple's platforms and, via Universal binaries, can bundle several architecture slices in one file. WebAssembly represents a portable bytecode target rather than a native object format, prioritising sandboxing and portability over direct machine code.
