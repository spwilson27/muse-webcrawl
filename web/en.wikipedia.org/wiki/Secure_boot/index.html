Secure boot

Secure boot builds a chain of trust from firmware to the operating system.

Secure boot is a security standard to ensure that a device boots using only software that is trusted by the original equipment manufacturer (OEM). When a computer starts, the firmware checks the signature of the UEFI boot loader and other early boot software; if the signatures are valid, the PC boots, and the firmware gives control to the operating system. Secure boot is part of the Unified Extensible Firmware Interface (UEFI) specification, introduced in the UEFI 2.3.1 specification, and is intended to prevent malware such as rootkits and bootkits from loading before the operating system's own defences are running.

How it works

Secure boot relies on a hierarchy of cryptographic keys stored in firmware variables. A platform key (PK), controlled by the OEM or the machine's owner, authorises changes to key exchange keys (KEKs); KEKs authorise updates to the signature database (db), which contains certificates and hashes of trusted boot loaders, and the forbidden-signature database (dbx), which revokes compromised or malicious loaders. Before executing a boot image, the firmware verifies its digital signature against these databases; unsigned or revoked images are refused. Each stage in the boot chain in turn verifies the next, extending a "chain of trust" into the operating system kernel.

Adoption and controversy

Microsoft required secure boot capability on PCs certified for Windows 8 (2012) and later made it mandatory for new Windows 11 installations as part of its platform security requirements. The requirement attracted criticism from free-software advocates concerned that locked-down machines would prevent users from installing alternative operating systems. In practice, most x86 PCs allow secure boot to be disabled or custom keys enrolled, and major Linux distributions boot under secure boot using a small signed shim loader endorsed by Microsoft's signing service. Vulnerabilities such as BlackLotus (2023), the first UEFI bootkit found in the wild to bypass secure boot, have led to large-scale revocation updates through dbx.

Related technologies

Secure boot verifies software before it runs; related "measured boot" technology records hashes of boot components into a Trusted Platform Module (TPM) so that the system's integrity can later be attested. Similar verified-boot schemes exist on Android devices and Apple platforms.
