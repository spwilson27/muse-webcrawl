Concave hull

A concave hull is a polygon that more closely follows the outline of a set of points than a convex hull does. Whereas the convex hull of a point set is the smallest convex region containing all the points, a concave hull allows indentations, so it can approximate the actual shape of a cluster of points, a geographic region, or the range of an animal species.

Definition

Unlike the convex hull, which is unique, there is no single canonical concave hull. Several constructions exist, each trading off tightness against simplicity. Common approaches include the alpha shape method, in which a parameter α controls how much the boundary may curve inward, and the k-nearest neighbours approach, in which the boundary is threaded through points using local neighbourhood information.

Algorithms

The alpha-shape algorithm, introduced by Edelsbrunner and co-workers in the 1980s, derives the hull from the Delaunay triangulation of the points: triangles whose circumradius exceeds a threshold based on α are discarded, and the boundary of the remaining region is the concave hull. The k-nearest-neighbour method of Moreira and Santos (2007) instead builds the boundary point by point, at each step choosing the next point among the k nearest candidates that does not cause the polygon to self-intersect.

Applications

Concave hulls are used in geographic information systems to delineate the extent of point observations, in ecology to estimate home ranges, and in computer graphics and pattern recognition to recover the shape of an object from sampled points. Software libraries such as PostGIS and the R package concaveman implement concave-hull computation.
