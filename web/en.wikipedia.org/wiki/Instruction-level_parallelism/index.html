Instruction-level parallelism

Instruction-level parallelism (ILP) is the parallel or simultaneous execution of a sequence of instructions in a computer program. More specifically, ILP refers to the average number of instructions run per step of this parallel execution.

Approaches

ILP can be exploited in hardware, as in superscalar and out-of-order execution processors that dynamically discover independent instructions, or in software, as in very long instruction word (VLIW) architectures where the compiler schedules parallel operations. Pipelining overlaps successive instructions, while techniques such as register renaming, branch prediction and speculative execution increase the available parallelism.

Limits

The amount of ILP in real programs is limited by data dependencies, control flow and memory latency — a phenomenon sometimes called the ILP wall. From the mid-2000s, designers increasingly turned to thread-level parallelism and multicore processors, and later to data-level parallelism in GPUs, to continue improving performance.
