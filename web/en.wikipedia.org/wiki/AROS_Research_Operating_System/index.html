AROS Research Operating System (AROS, formerly the Amiga Research Operating System) is a free and open-source multi-media centric implementation of the AmigaOS 3.1 application programming interface (API), developed since 1995–96 to make the Amiga operating system portable to modern hardware.

Overview

AROS aims for source compatibility with AmigaOS: correctly written Amiga programs can be recompiled for AROS with few changes, and a 68k version can run original Amiga software natively on classic hardware or under emulation. Its components have familiar Amiga names — the desktop is called Wanderer (a work-alike of Workbench), the GUI toolkit is Zune (an open clone of MUI), and the windowing system runs on the Graphics and Intuition equivalents it reimplements.

Distributions and development

AROS is developed by a distributed volunteer team with a bounty system funding specific tasks. User-facing distributions package the system with applications; notable ones include Icaros Desktop (x86) and AROS Vision (68k). AROS can also run hosted within Linux or Windows. Release milestones were named as cat pictures denote its codename history; the system remains a niche platform sustained by the retro-Amiga community.
