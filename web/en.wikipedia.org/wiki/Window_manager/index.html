Window manager

A window manager is system software that controls the placement and appearance of windows within a graphical user interface. It determines the border, title bar and controls drawn around application windows — the window decoration — and handles operations such as moving, resizing, minimising, maximising and closing windows, as well as deciding which window receives input focus. The concept emerged from early research at Xerox PARC in the 1970s and became a standard component of desktop computing with systems such as the X Window System, Microsoft Windows and the Macintosh.

X Window System window managers

Under the X Window System, the window manager is an ordinary client program, separate from the display server, so users can choose among many implementations with different behaviour and appearance. Classic X window managers include twm, one of the earliest, and the lightweight Openbox and Fluxbox. The desktop environments GNOME and KDE ship their own window managers — Mutter and KWin respectively — while Xfce uses Xfwm. Many X window managers use a reparenting technique, inserting a frame window between the top-level window and its parent so that the manager can draw decorations and intercept move and resize requests.

Types of window manager

Stacking

Stacking (or floating) window managers allow windows to overlap freely like sheets of paper on a desk, with the user arranging them manually. This is the model used by Microsoft Windows and macOS and by most traditional X window managers.

Tiling

Tiling window managers arrange windows in a non-overlapping grid that fills the screen automatically, favouring keyboard control. Examples include i3, dwm, Awesome and XMonad, as well as terminal multiplexers in spirit. Dynamic tiling managers adjust the layout as windows open and close; manual ones let the user split regions explicitly.

Compositing

A compositing window manager gives each window an off-screen buffer and composites them into the final image, enabling effects such as drop shadows, translucency, live thumbnails and smooth animations. Quartz Compositor on macOS, the Desktop Window Manager on Windows, and KWin, Mutter and Compiz on Linux are compositing managers. Under the Wayland protocol, compositing is built in: the compositor itself (such as Weston, Sway or KWin) performs the window manager's role.

Window managers on other platforms

On Microsoft Windows and macOS the window manager is integrated into the operating system and cannot be replaced, though utilities can alter its behaviour. On Unix-like systems the choice is left to the user, and the window manager is commonly one component of a broader desktop environment that also supplies panels, file managers and settings tools. Conventions for interoperability between window managers, applications and desktops are described by the ICCCM and the Extended Window Manager Hints specifications maintained by freedesktop.org.
