SIMD

SIMD
Full name: Single instruction, multiple data
Class: Flynn's taxonomy
Examples: MMX, SSE, AVX, NEON, AltiVec

Single instruction, multiple data (SIMD) is a type of parallel processing in Flynn's taxonomy, in which a single instruction operates on multiple data elements simultaneously. SIMD instructions exploit data-level parallelism common in multimedia, scientific and machine-learning workloads, where the same operation — an addition, multiplication, comparison — must be applied across large arrays of numbers.

Implementations

Modern CPUs implement SIMD through wide vector registers: x86 processors progressed from MMX (64-bit) through SSE, AVX and AVX-512 (512-bit), while ARM processors use NEON and the scalable SVE extensions. Graphics processing units (GPUs) are built around massively parallel SIMD-style execution (often described as SIMT). Compilers can auto-vectorise suitable loops, and programmers can use intrinsics or libraries for explicit control.

Advantages and limits

Processing several elements per instruction improves throughput and energy efficiency for suitable workloads, but benefits are limited by data alignment, memory bandwidth and code that cannot be vectorised — a practical expression of Amdahl's law.
