Patch (Unix)

patch is a Unix program that updates text files according to instructions contained in a separate file called a patch file. The patch file (also called a patch for short) is a text file that consists of a list of differences, typically produced by the diff program, and is applied using the original file and the differences to produce a new version.

History

The program was written by Larry Wall, who later created the Perl programming language, and released in 1985 on the mod.sources newsgroup. It quickly became a standard tool for distributing changes to source code: rather than sending an entire modified file, developers could send a small patch that recipients applied to their own copies. GNU patch is now part of the GNU diffutils ecosystem and is available on virtually all Unix-like systems.

Usage

patch reads a diff file (in context, unified, or normal format) and attempts to apply each "hunk" of changes to the target file. It can tolerate offsets when the file has changed slightly, and applies "fuzz" to match context approximately; changes that cannot be applied are saved to a .rej file, and original files are preserved with a .orig suffix by default. Although version control systems such as Git have their own patch-handling commands, patch remains a ubiquitous tool in software distribution and system administration.
