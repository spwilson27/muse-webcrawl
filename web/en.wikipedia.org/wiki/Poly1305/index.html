Poly1305

Poly1305 is a one-time message authentication code (MAC) designed by Daniel J. Bernstein, first presented in 2004–2005. It takes a 32-byte one-time key and a message and produces a 16-byte authentication tag. The name reflects its arithmetic: polynomial evaluation modulo the prime 2130 − 5.

Construction

The key is split into two 16-byte halves, r and s. After "clamping" (clearing certain bits of r), the message is divided into 16-byte blocks; each block, with an appended 1 bit, is added to an accumulator that is multiplied by r modulo 2130 − 5. Finally s is added modulo 2128 to produce the tag. Because the key may be used only once, Poly1305 is normally paired with a stream cipher that generates a fresh key per message.

Use

Poly1305 is best known in the ChaCha20-Poly1305 authenticated encryption construction, standardised in RFC 8439 and widely deployed in TLS 1.3, the WireGuard VPN protocol, SSH and numerous libraries. Its design offers provable security bounds (forgery probability on the order of 2−128 when used correctly) and fast software implementation without lookup tables, avoiding cache-timing side channels.
