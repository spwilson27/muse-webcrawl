Nearest neighbor search

A query point and its nearest neighbors among a set of data points.

Nearest neighbor search (NNS), also known as proximity search, similarity search or closest point search, is an optimization problem for finding the point in a given set that is closest (or most similar) to a given point. Closeness is typically expressed in terms of a dissimilarity function: the less similar the objects, the larger the function values.

Formally, the nearest-neighbor search problem is defined as follows: given a set S of points in a space M and a query point q in M, find the point in S that is closest to q. Donald Knuth called it the post-office problem in his 1973 book The Art of Computer Programming, referring to an application of assigning a residence to the post office closest to it.

Variations

Several variations of the problem are commonly studied. In k-nearest neighbor search, the goal is to find the k closest points to the query. In approximate nearest neighbor search, the algorithm is allowed to return points whose distance from the query is within a factor (1 + ε) of the true nearest neighbor, which can dramatically reduce running time in high dimensions. Radius search returns all points within a specified distance of the query, and the closest pair of points problem seeks the two closest points in a set.

Methods

The naive approach, linear search, computes the distance from the query point to every other point in the dataset, keeping track of the "best so far"; this costs O(dN) for N points in d dimensions and is sometimes called the brute-force method.

Space-partitioning data structures such as the k-d tree, ball tree, cover tree, and R-tree recursively divide the search space and prune branches that cannot contain a closer point. Hashing-based schemes such as locality-sensitive hashing (LSH) achieve approximate answers in high dimensions. Graph-based methods, including navigable small-world graphs and hierarchical navigable small world (HNSW) graphs, are widely used in modern vector databases.

Applications

Nearest neighbor search underlies the k-nearest neighbors algorithm in classification and regression, content-based image and audio retrieval, recommender systems, pattern recognition, document clustering, spell checking, and plagiarism detection. It is also used in geographic information systems and in matching records in record linkage.

Curse of dimensionality

As the number of dimensions increases, most exact data structures degrade toward linear search, a phenomenon associated with the curse of dimensionality: distances concentrate, so the ratio between the nearest and farthest points tends toward 1, making discrimination between near and far neighbors nearly meaningless.
