High Bandwidth Memory

TypeDRAM (3D-stacked, TSV)
DevelopersAMD, SK Hynix, Samsung
StandardJEDEC JESD235
First productAMD Fiji (Radeon R9 Fury X), 2015

High Bandwidth Memory (HBM) is a type of computer memory interface for 3D-stacked synchronous dynamic random-access memory (SDRAM) developed by Samsung, AMD and SK Hynix. It uses stacks of memory dies connected by through-silicon vias (TSVs), mounted on a silicon interposer next to the processor, to deliver far higher bandwidth at lower power than conventional GDDR memory.

Technology

An HBM stack consists of four, eight or twelve DRAM dies pierced by thousands of TSVs, presenting a very wide interface — 1024 bits per stack — clocked at modest speeds. Because the buses are short and wide, HBM achieves much greater bandwidth per watt and per unit of board area than off-package memory such as GDDR6.

Generations

The original HBM (standardised by JEDEC in 2013) offered about 128 GB/s per stack and debuted in AMD's Fiji GPUs in 2015. HBM2 roughly doubled bandwidth to about 256 GB/s per stack and was used in data-centre GPUs and the AMD Vega series. HBM2E increased this further, and HBM3 (2022) reaches roughly 819 GB/s per stack, powering AI accelerators such as Nvidia's H100. HBM3E extended speeds beyond 1 TB/s per stack, and HBM4 widens the interface to 2048 bits per stack.

Applications

HBM is used primarily in high-performance graphics cards, AI training and inference accelerators, supercomputers, FPGAs and high-end networking equipment, where memory bandwidth is the limiting factor.
