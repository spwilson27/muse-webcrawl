Physical security

Physical security describes security measures designed to deny unauthorised access to facilities, equipment, and resources, and to protect people and property from damage or harm such as espionage, theft, or attack. It involves the use of multiple layers of interdependent systems, often summarised as deter, detect, delay, and respond.

Elements

Common elements include access control (locks, badges, biometric readers), surveillance (closed-circuit television, security guards, alarm systems), perimeter barriers (fences, walls, bollards, vehicle barriers), environmental design (lighting and crime prevention through environmental design, CPTED), and procedural measures such as visitor management and security patrols.

Layered approach

Modern practice favours defence in depth: a site perimeter, building perimeter, and interior layers each add independent controls, so that breaching one layer does not compromise the whole asset. Physical security complements information security and personnel security in organisational security programmes.
