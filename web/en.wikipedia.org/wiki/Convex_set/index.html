Convex set

In geometry, a subset of a Euclidean space (or more generally a vector space over the real numbers) is called convex if, given any two points in the subset, the subset contains the whole line segment joining them. Equivalently, a set S is convex if for all x, y in S and all t in [0, 1], the point tx + (1−t)y also belongs to S.

Examples

Intervals on the real line, triangles, disks, balls, half-spaces, and affine subspaces are convex. A five-pointed star and an annulus (ring) are not convex, because a segment joining certain pairs of their points passes outside the set. The empty set and any single point are conventionally convex.

Properties

The intersection of any collection of convex sets is convex. The image of a convex set under an affine map is convex. The convex hull of an arbitrary set is the smallest convex set containing it. By the Krein–Milman theorem, a compact convex set in a finite-dimensional space is the convex hull of its extreme points. The Hahn–Banach separation theorems state that disjoint convex sets can be separated by a hyperplane under suitable conditions.

Generalizations

Convexity generalizes to star-convex sets, geodesic convexity on manifolds, and abstract convexity in ordered structures. Convex sets and convex functions underpin the field of convex optimization.
