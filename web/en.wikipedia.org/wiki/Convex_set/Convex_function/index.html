Convex function

In mathematics, a real-valued function f on an interval (or, more generally, on a convex set in a vector space) is called convex if the line segment between any two points on its graph lies above the graph between those points. Formally, for all x, y in the domain and all t in [0, 1]:

f(tx + (1−t)y) ≤ t f(x) + (1−t) f(y).

Characterizations

A convex function has an epigraph that is a convex set. A differentiable function is convex if and only if its derivative is monotone non-decreasing; a twice-differentiable function is convex if and only if its second derivative is everywhere nonnegative. At any point, the graph of a convex function lies above each of its tangent lines (where tangents exist).

Examples

Examples include x2, |x|, the exponential function, norms, and the maximum of any family of affine functions. Sums and pointwise maxima of convex functions are convex, and convexity is preserved under affine composition.

Applications

Convex functions are the foundation of convex optimization: any local minimum of a convex function on a convex set is a global minimum. They also underlie Jensen's inequality, convex conjugate duality, and models of risk in economics.
