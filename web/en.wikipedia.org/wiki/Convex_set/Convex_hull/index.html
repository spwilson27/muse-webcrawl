Convex hull

The convex hull of a set of points is the smallest convex set that contains the set. For a finite set of points in the plane it can be visualized as the shape enclosed by a rubber band stretched around the outermost points. It equals the set of all convex combinations of points of the set, and the intersection of all convex sets containing it.

Computation

Algorithms for planar convex hulls include the gift wrapping (Jarvis) march, Graham's scan, Andrew's monotone chain, and Chan's output-sensitive algorithm, which runs in O(n log h) time for n points with h hull vertices. In three dimensions, algorithms such as QuickHull run in expected O(n log n). The problem has an Ω(n log n) lower bound in algebraic decision-tree models.

Properties

Carathéodory's theorem says every point in the convex hull of a set in d-dimensional space is a convex combination of at most d+1 points of the set. The hull of a compact set is compact in finite dimensions; the hull of a finite set is a convex polytope, whose vertices are the points of the set in convex position.

Applications

Convex hulls are used in pattern recognition, image processing, statistics (data depth), collision detection, and as preprocessing for problems such as the closest pair and farthest pair of points.
