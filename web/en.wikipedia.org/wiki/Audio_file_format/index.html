Audio file format

From Wikipedia, the free encyclopedia

An audio file format is a file format for storing digital audio data on a computer system. The bit layout of the audio data (excluding metadata) is called the audio coding format and can be uncompressed, or compressed to reduce the file size, often using lossy compression. The data can be a raw bitstream in an audio coding format, but it is usually embedded in a container format or an audio data format with defined storage layer.

Format types

It is important to distinguish between the audio coding format, the container containing the raw audio data, and an audio codec. A codec performs the encoding and decoding of the raw audio data, while this encoded data is (usually) stored in a container file.

Uncompressed formats

WAV — the standard format for uncompressed audio on Microsoft Windows, using the RIFF container; AIFF is the equivalent Apple format; BWF (Broadcast Wave Format) extends WAV for professional broadcasting.

Lossless formats

FLAC is the most widely supported free lossless format; others include ALAC (Apple Lossless), WavPack and Monkey's Audio (.ape).

Lossy formats

MP3 (MPEG-1 Audio Layer III), dominant since the late 1990s; AAC, used by iTunes, YouTube and digital broadcasting; Vorbis and Opus, free formats used in streaming and gaming; and formats such as WMA and ATRAC promoted by individual vendors.

Metadata

Most formats support embedded metadata tags — ID3 tags in MP3 files, Vorbis comments in FLAC and Ogg files — storing title, artist, album and artwork information.
