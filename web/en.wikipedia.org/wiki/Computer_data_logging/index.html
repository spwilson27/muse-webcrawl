Computer data logging

From Wikipedia, the free encyclopedia

Computer data logging is the process of recording events, measurements, or messages generated by computer systems, applications, and networks into log files (or other persistent records) for later analysis. Logs are a primary source of information for system administrators, developers, and security analysts, used for debugging, performance monitoring, auditing, compliance, and forensic investigation after incidents.

Log types and formats

Common categories include event logs (such as the Windows Event Log), transaction logs used by databases to guarantee durability, server logs recording requests to web servers (for example the Apache and Nginx access and error logs), and application logs written by software through logging frameworks. The syslog protocol, standardised in RFC 5424, defines a format and severity levels for messages on Unix-like systems. Log entries typically contain a timestamp, a severity level (such as DEBUG, INFO, WARN, ERROR, FATAL), the source component, and a message, increasingly emitted in structured formats such as JSON to permit machine parsing.

Management and analysis

Because production systems can generate enormous volumes of log data, log management practices include rotation and retention policies, centralised aggregation, indexing and search, and alerting on anomalous patterns. Security information and event management (SIEM) systems correlate log data across sources to detect intrusions and policy violations. Keystroke logging (“keylogging”) is a special, often malicious form of data logging that records keyboard input. Well-known log management and analysis tools and frameworks include the ELK/Elastic stack, Splunk, Graylog, log4j and its successors in the Java ecosystem, and the systemd journal on Linux.
