In computing, BIOS (pronounced "BY-oss"), standing for Basic Input/Output System, is firmware used to provide runtime services for operating systems and programs and to perform hardware initialization during the booting process (power-on startup). The BIOS firmware comes pre-installed on an IBM PC or IBM PC compatible's system board; it is the first software run when the system is powered on.

The term was coined by Gary Kildall for the CP/M operating system in 1975, where the BIOS was the machine-specific part of the system that loaded the hardware-independent BDOS. On the IBM PC of 1981, the BIOS resided in ROM on the motherboard, and clones of the PC had to reproduce it — companies such as Phoenix Technologies famously did so by clean-room design, creating a market in independent BIOS firmware.

Functions

When the computer starts, the BIOS performs the power-on self-test (POST), initializing and testing the CPU, memory, and peripherals. It then locates a boot device and loads its first-stage boot loader — historically the master boot record (MBR) — into memory and transfers control to it. During the pre-OS phase, the BIOS offers a setup utility, stored settings being kept in battery-backed CMOS RAM, in which users can configure hardware options and boot order.

The BIOS also exposes software interrupts — such as INT 10h for video and INT 13h for disk services — that early operating systems, especially DOS, used for input and output. Modern operating systems generally switch to their own native drivers once loaded, making the BIOS services mostly a bootstrapping mechanism. Historically, expansion cards carried their own "option ROMs" to extend BIOS services.

UEFI succession

From the mid-2000s onward, the Unified Extensible Firmware Interface (UEFI) began replacing the legacy BIOS, offering larger boot disks (via GPT instead of MBR), a graphical setup environment, Secure Boot, and faster startup. Many UEFI implementations include a Compatibility Support Module (CSM) that emulates BIOS behavior for older systems; Intel and others have progressively removed legacy BIOS support, making "BIOS" today often a generic term for system firmware, even when the implementation is UEFI.
