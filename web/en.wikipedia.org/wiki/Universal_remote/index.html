Universal remote

TypeRemote control
FunctionControls multiple devices
TechnologiesInfrared, RF, Bluetooth, Wi-Fi

A universal remote is a remote control that can be programmed to operate various brands and types of consumer electronic devices, such as televisions, set-top boxes, disc players, and audio equipment, replacing the separate remotes supplied with each device.

Types

Basic universal remotes come pre-loaded with code libraries for popular brands, selected by entering a code for each device. Learning remotes can copy infrared signals directly from an original remote. High-end models add LCD touchscreens, activity-based macros (such as a single "Watch TV" command), and programming via computer or smartphone app.

History

Universal remotes became widespread in the late 1980s and 1990s as home entertainment systems accumulated devices. Notable product lines included the Logitech Harmony series, discontinued in 2021, while smartphone apps and HDMI-CEC have since reduced the need for dedicated universal remotes.
