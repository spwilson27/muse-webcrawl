ISO 9660

ISO 9660 is the standard file system for CD-ROM media

ISO 9660 (also known as ECMA-119) is a file system standard, published by the International Organization for Standardization, for optical disc media, principally CD-ROMs. It defines how files and directories are laid out on a disc so that they can be read across different operating systems. The standard originated with the "High Sierra" format proposed by an industry group in 1985 and was adopted as ISO 9660 in 1988. Disc images in this format commonly carry the .iso file extension, a name that has become generic for disc images in general.

Structure

A disc begins with a system area of sixteen 2,048-byte sectors, followed by a volume descriptor sequence. The primary volume descriptor records metadata such as the volume label, publisher, dates and the location of the root directory and path tables. Files are stored as contiguous extents of sectors, and directories are special files containing directory records that point to the extents of their entries. In its strictest form the standard restricts file names to the familiar "8.3" pattern of uppercase letters, digits and underscores with a version number, and limits directory depth to eight levels.

Extensions

Several extensions relax the base restrictions. Rock Ridge (standardised as IEEE P1282) uses System Use fields to support long POSIX-style file names, deep directories, symbolic links and permissions, and is widely used on Unix-like systems. Joliet, designed by Microsoft, stores names in UCS-2 and allows up to 64 characters per name, and is readable by Windows. The El Torito specification adds bootable disc support. ISO 9660:1999 loosened some limits, and the successor format UDF (ISO 13346) was designed for rewritable and larger media such as DVDs.
