Software bloat

From Wikipedia, the free encyclopedia

Software bloat is the process by which successive versions of a computer program become perceptibly slower, use more memory and disk space, or require more processing power, while offering functionality of marginal benefit. Bloated software is sometimes said to suffer from 'featuritis' or creeping featurism.

Causes

Common causes include the continual addition of features demanded by marketing, backward compatibility with legacy formats, developer reliance on ever-faster hardware, and the use of heavyweight frameworks. The phenomenon is summed up by Wirth's law, attributed to Niklaus Wirth, which states that software gets slower faster than hardware gets faster.

Responses

Users and developers may counter bloat with minimal or 'suckless' software design, modular programs that load features on demand, and preference for lightweight alternatives. The term 'bloatware' is also applied to unwanted software pre-installed on new computers and phones.
