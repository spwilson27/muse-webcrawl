Web colors

Web colors are colours used in displaying web pages. They are specified in HTML and CSS using a hexadecimal triplet (such as #FF0000 for red), RGB or HSL functional notation, or predefined colour keywords.

Hex triplet

A hex triplet is a six-digit hexadecimal number in which the three byte pairs give the red, green, and blue components, each from 00 to FF. A shorthand three-digit form doubles each digit. The system yields 16,777,216 possible colours.

Named colors

CSS defines an extended set of colour keywords, from the original 16 VGA colours (black, silver, gray, white, maroon, red, purple, fuchsia, green, lime, olive, yellow, navy, blue, teal, aqua) to more than 140 names such as rebeccapurple, added in CSS Color Level 4.

Web-safe colors

In the era of 8-bit displays, a palette of 216 "web-safe" colours — those guaranteed to display without dithering — was commonly recommended; with modern 24-bit displays the palette is of mainly historical interest.
