IEEE 802.11 is a set of standards created and maintained by the Institute of Electrical and Electronics Engineers (IEEE) LAN/MAN Standards Committee (IEEE 802). It specifies the media access control (MAC) and physical layer (PHY) protocols for implementing wireless local area network (WLAN) computer communication. Products implementing the standards are marketed under the Wi-Fi trademark by the Wi-Fi Alliance, which certifies interoperability.

History

The first version of the standard was released in 1997 and provided data rates of 1–2 Mbit/s in the 2.4 GHz band using frequency-hopping or direct-sequence spread spectrum. Successive amendments added higher rates and new bands. The standard is maintained as a single consolidated document (e.g. IEEE 802.11-2020) into which ratified amendments are rolled.

Architecture

The basic building block is the basic service set (BSS): a group of stations communicating through an access point (infrastructure mode) or directly (ad hoc/IBSS mode). Stations share the medium using CSMA/CA — carrier sense multiple access with collision avoidance — backing off for random intervals to reduce collisions, with optional RTS/CTS handshaking. Multiple access points connected by a distribution system (usually Ethernet) form an extended service set identified by an SSID.

Security

Early security, Wired Equivalent Privacy (WEP), proved cryptographically weak and was deprecated. It was succeeded by WPA (based on TKIP), WPA2 (AES-CCMP, ratified as 802.11i), and WPA3 (SAE handshake), alongside enterprise authentication using 802.1X and EAP.
