Relational model

From Wikipedia, the free encyclopedia

The relational model (RM) is an approach to managing data using a structure and language consistent with first-order predicate logic, first described in 1969 by English computer scientist Edgar F. Codd. All data are represented in terms of tuples, grouped into relations, and a database organised in accordance with the model is a relational database.

Basics

In the relational model, a relation corresponds to what in SQL is loosely called a table: a set of tuples (rows), each sharing a common set of attributes (columns), each attribute having a name and a domain of permitted values. A subset of attributes forms a key, uniquely identifying tuples. Relationships between data are represented by values stored in attributes, such as foreign keys referencing the primary key of another relation.

Operations

Codd proposed an algebra of operations on relations — selection, projection, union, set difference, Cartesian product and renaming — later joined by the relational calculus, and showed the two were equivalent in expressive power. These operations underlie SQL, the dominant query language of relational database management systems such as Oracle, MySQL, PostgreSQL and Microsoft SQL Server. Database design for the relational model is guided by normalisation, a process of decomposing relations to eliminate redundancy and update anomalies, formalised through normal forms.
