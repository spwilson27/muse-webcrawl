Memory B cell

Memory B cells persist after an immune response

In immunology, a memory B cell is a type of B lymphocyte that forms part of the adaptive immune system. These cells develop within germinal centers of the secondary lymphoid organs. Memory B cells circulate in the bloodstream in a quiescent state, sometimes for decades, and when they encounter their cognate antigen again they can rapidly proliferate and differentiate into antibody-secreting plasma cells, producing a faster and stronger secondary immune response.

Development

During a primary immune response, naive B cells activated by antigen and T cell help enter germinal centers, where they undergo somatic hypermutation and class-switch recombination. Some of the resulting high-affinity B cells exit as long-lived plasma cells, while others become memory B cells. Memory B cells typically express class-switched immunoglobulin (IgG, IgA, or IgE) on their surface, though IgM-positive memory cells also exist.

Function

On re-exposure to antigen, memory B cells respond more quickly and vigorously than naive B cells: they require less co-stimulation, expand rapidly, and generate plasma cells secreting large quantities of high-affinity antibody. This immunological memory is the basis of vaccination — vaccines are designed to generate memory B (and T) cells without causing disease.

Markers

In humans, memory B cells are commonly identified by expression of the surface marker CD27. They persist in secondary lymphoid organs, bone marrow, and mucosal tissues, and tissue-resident populations have been described in sites such as the lung and gut.
