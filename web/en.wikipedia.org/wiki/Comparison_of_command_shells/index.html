Comparison of command shells

This article compares computer command shells — command-line interpreters that provide a user interface for operating systems. Shells differ in syntax, scripting features, interactivity, and platform support.

Shells compared

Common shells include the Bourne shell (sh), Bash, Z shell (zsh), Fish, the C shell family, KornShell, PowerShell, and Windows Command Prompt (cmd.exe), along with historical shells such as the Thompson shell.

Features

Comparison criteria typically include interactive features (command history, tab completion, job control), scripting capabilities (functions, arrays, control structures), POSIX compliance, license, and default availability on operating systems.

History

Command shells originated with early time-sharing systems; the Unix shell tradition beginning with the Thompson and Bourne shells strongly influenced modern designs, while PowerShell introduced an object-oriented pipeline model.
