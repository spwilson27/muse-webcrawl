Digital preservation

Digital preservation is the set of formal activities undertaken to ensure that digital information of continuing value remains accessible and usable over the long term. It involves planning, resource allocation, and the application of preservation methods and technologies to counter media degradation, technological obsolescence and the fragility of digital formats. Digital preservation is practised by libraries, archives, museums and other memory institutions, as well as by governments and businesses that must retain records.

Challenges

Unlike paper, digital objects depend on a chain of hardware, operating systems, applications and file formats to be rendered intelligible. Storage media fail or become unreadable as interfaces disappear; file formats are superseded; and bits can be silently corrupted. Preservation therefore cannot simply store objects passively: institutions must actively monitor the technological environment and intervene before content becomes inaccessible.

Strategies

  • Refreshing — copying data onto new media of the same type before the old media deteriorate.
  • Replication — maintaining multiple copies in geographically separate locations, as in the LOCKSS principle ("lots of copies keep stuff safe").
  • Migration — periodically converting content from older formats to current ones, accepting possible small changes in rendering.
  • Emulation — recreating the original hardware and software environment so that the original object can be run unchanged.
  • Encapsulation — storing the object together with the metadata and documentation needed to interpret it in the future.

Reference model

The Open Archival Information System (OAIS) reference model, published as ISO 14721, provides the standard conceptual framework for digital archives. It defines the functions of ingest, archival storage, data management, administration, preservation planning and access, and describes information packages submitted to, stored in and disseminated from an archive. Audit frameworks such as ISO 16363 allow repositories to be certified as trustworthy digital repositories.

Metadata

Preservation metadata records the provenance, fixity, context and rights of a digital object. The PREMIS data dictionary is the widely adopted standard for such metadata, and checksums are routinely used to detect corruption and verify that an object has not changed.
