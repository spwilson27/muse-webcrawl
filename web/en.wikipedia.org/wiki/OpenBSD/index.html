OpenBSD is a free and open-source, security-focused, Unix-like operating system based on the Berkeley Software Distribution (BSD). It was founded in 1995 by Theo de Raadt, who forked it from NetBSD after a dispute with the NetBSD core team. The project is known for its emphasis on code correctness, proactive security, extensive code auditing, and the development of widely used technologies such as OpenSSH.

History

De Raadt, a founding member of NetBSD, was asked to resign in late 1994; in October 1995 he announced OpenBSD, with the first release (1.2) following in July 1996 and version 2.0 in October 1996. Releases have since appeared roughly every six months. The project is based in Calgary, Alberta, Canada, and is supported by the OpenBSD Foundation.

Security features

OpenBSD pioneered or popularized many security mechanisms, including W^X (write xor execute) memory protection, privilege separation and privilege revocation, address space layout randomization, the bcrypt password hashing scheme, and system-call restriction mechanisms such as pledge and unveil. Its slogan — "Only two remote holes in the default install, in a heck of a long time!" — reflects the project's auditing culture. It was the first operating system to integrate cryptographic hardware support and an encrypted swap.

Associated projects

Sub-projects developed alongside OpenBSD have spread widely: OpenSSH (used almost universally for secure remote administration), the PF packet filter, LibreSSL (a fork of OpenSSL created after the Heartbleed disclosure), OpenSMTPD, OpenBGPD, tmux and the mandoc documentation tools. OpenBSD's permissive licensing policy discourages code under copyleft licences in the base system.
