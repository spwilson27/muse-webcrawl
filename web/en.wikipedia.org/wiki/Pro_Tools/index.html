Pro Tools is a digital audio workstation (DAW) developed and released by Avid Technology (formerly Digidesign) for Microsoft Windows and macOS. It is used for music creation and production, sound for picture (sound design, audio post-production, and mixing), and, more generally, sound recording, editing, and mastering processes.

The Pro Tools interface, showing the edit window (top) and mix window with channel strips

History

Pro Tools grew out of Sound Tools, a Mac-based two-track editor released by Digidesign in 1989, itself descended from the Sound Designer software written for sampling keyboards by Evan Brooks and Peter Gotcher. The first Pro Tools system, launched in 1991, offered four tracks of recording with dedicated digital signal processing hardware. Successive versions added track counts, plug-in formats (TDM, then RTAS, then AAX), video support, and surround mixing. Pro Tools|HD systems, with DSP accelerator cards, became a standard in professional recording studios and film sound facilities.

Features

Pro Tools provides software for recording, editing, and mixing audio and MIDI, with timeline-based editing, playlist comping, clip gain, elastic audio time-stretching, and automation. Historically the software was tied to Digidesign/Avid hardware, but modern versions run with any Core Audio or ASIO interface. Pro Tools is offered in tiers, from the free/introductory edition to Pro Tools Ultimate, which supports the HDX hardware ecosystem and immersive audio workflows.

Industry adoption

Because sessions can be exchanged reliably between studios, Pro Tools became the de facto standard DAW in much of the commercial music and film-sound world; proficiency with it is widely expected of professional recording and mix engineers.
