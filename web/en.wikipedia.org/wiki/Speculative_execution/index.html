Speculative execution


Field: Computer architecture
Techniques: Branch prediction, speculative loading, value prediction
Known risks: Spectre and related side-channel attacks

Speculative execution is an optimisation technique in which a computer system performs work that may not be needed, in advance of knowing whether the result will be used. Modern processors speculatively execute instructions past predicted branches so that the pipeline need not stall while waiting for conditions to resolve.

How it works

When a branch is encountered, the branch predictor guesses the outcome and the processor continues executing along the predicted path, holding results in a reorder buffer. If the prediction proves correct, results are committed; otherwise the speculative state is discarded and execution restarts along the correct path.

Security implications

Although discarded speculative work leaves no architectural trace, it can affect caches and other microarchitectural state. In 2018 the Spectre vulnerabilities showed that attackers could exploit this to leak memory contents across security boundaries via timing side channels, prompting extensive software and hardware mitigations.
