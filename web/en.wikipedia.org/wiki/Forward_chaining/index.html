Forward chaining

Forward chaining (or forward reasoning) is one of the two main methods of reasoning when using an inference engine in expert systems and production rule systems. It is a data-driven process: the system starts with available facts and repeatedly applies rules whose conditions are satisfied, adding new facts until a goal is reached or no rule can fire.

How it works

The inference engine maintains a working memory of facts and a rule base of if–then rules. In each cycle it matches rule conditions against the facts (pattern matching, as in the Rete algorithm), selects a set of applicable rules using a conflict-resolution strategy, and fires them, asserting their conclusions as new facts. The cycle repeats. Forward chaining is the opposite of backward chaining, which starts from a goal and searches for evidence supporting it.

Applications

Forward chaining suits problems where data arrives incrementally and all consequences must be derived, such as monitoring and control systems, business rule engines, and configuration. Classic systems built on it include OPS5 and CLIPS. Its weakness is that it may derive many irrelevant facts; backward chaining is preferred when the goal is narrow and facts are expensive to obtain.
