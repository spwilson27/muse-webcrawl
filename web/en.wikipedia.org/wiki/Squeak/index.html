Squeak

Squeak is a free and open-source implementation of the Smalltalk programming language and environment. It is derived from Smalltalk-80 and was developed initially at Apple Computer by a team that included Alan Kay, Dan Ingalls, Adele Goldberg, Ted Kaehler, and Scott Wallace. Squeak is notable for being largely written in Smalltalk itself, including its virtual machine, which is translated to C for performance.

History

Squeak was released in 1996 by Apple, which made it available under what became known as the Squeak License; the code was later relicensed under the MIT License and the Apache License. The project grew out of the work of the group that had created Smalltalk at Xerox PARC and later worked at Apple on educational computing. Alan Kay's later research at Viewpoints Research Institute continued to build on Squeak.

Features

Squeak provides a complete, self-contained development environment in which the entire system — compiler, debugger, text editor, and graphical user interface — is live and modifiable while it runs. It implements the Morphic user interface framework, which grew out of the Self programming language and offers direct manipulation of graphical objects. Squeak runs bit-identically on many platforms because its virtual machine abstracts the host system.

A distinctive feature is that the Squeak virtual machine is itself written in a subset of Smalltalk called Slang, which can be translated to C. This makes the system unusually portable and easy to experiment with.

Applications and derivatives

Squeak has been used as the basis for several projects. Scratch, the block-based programming language originally developed at the MIT Media Lab for children, was first implemented in Squeak. Etoys, an educational programming environment for children, runs on Squeak. The Seaside web framework helped popularize continuation-based web development. Commercial and community forks include Pharo, which focuses on clean, modern Smalltalk development, and Cuis Smalltalk. The Croquet Project built collaborative 3D environments on Squeak. The Newspeak language and the Open Smalltalk Virtual Machine (OpenSmalltalk-VM), shared by Squeak and Pharo, trace their roots to this work.

Community

Development is coordinated by the Squeak Oversight Board and the community around squeak.org. Version 6.0 was released in 2022, bringing improved support for high-DPI displays and other refinements.
