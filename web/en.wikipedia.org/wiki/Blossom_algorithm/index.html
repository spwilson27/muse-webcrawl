The blossom algorithm is an algorithm in graph theory for constructing maximum matchings on general graphs. It was developed by Jack Edmonds in 1965 and published in the paper "Paths, Trees, and Flowers". Unlike the matching problem on bipartite graphs, general graphs may contain odd cycles — "blossoms" — which defeat naive augmenting-path search; Edmonds' insight was to shrink each blossom into a single vertex, solve the smaller problem recursively, and then expand the blossom to recover the matching.

Description

The algorithm searches for an augmenting path with respect to the current matching. During the search it maintains a forest of alternating trees rooted at free vertices. When an edge closes an odd cycle within a tree, that cycle is a blossom and is contracted. When an augmenting path is found in the contracted graph, the matching is augmented, and blossoms along the path are expanded by choosing the appropriate alternating path through each one. Extensions by Edmonds and others solved the maximum-weight matching problem in polynomial time as well.

Significance

The blossom algorithm is regarded as a landmark in combinatorial optimisation: it was one of the first polynomial-time algorithms for a major combinatorial problem and helped motivate Edmonds' influential association of polynomial time with computational tractability, foreshadowing the formal theory of P and NP. Efficient implementations, notably the Blossom V code by Vladimir Kolmogorov, are widely used in computer vision and operations research.
