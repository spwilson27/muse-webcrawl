Intel MCS-51

Launched1980
ManufacturerIntel (and many licensees)
Architecture8-bit Harvard architecture microcontroller
Common variants8051, 8052, 8031, 8751, AT89 series

The Intel MCS-51 (commonly termed the 8051) is a single-chip microcontroller (µC) series developed by Intel in 1980 for use in embedded systems. The architect of the instruction set was John H. Wharton. Intel's original versions were popular in the 1980s and early 1990s, and enhanced binary-compatible derivatives remain popular today, produced by numerous manufacturers under licence or as independent implementations.

Features

The original 8051 integrates an 8-bit CPU with on-chip program ROM (4 KB) and data RAM (128 bytes), four 8-bit I/O ports, two 16-bit timer/counters, a full-duplex serial port (UART), and interrupt logic with two priority levels. It uses a Harvard architecture with separate program and data memory spaces. Distinctive features include bit-addressable memory — individual bits of certain RAM locations and registers can be set, cleared and tested directly — multiply and divide instructions, and a Boolean processor aimed at control applications.

Variants and legacy

The 8052 added more RAM and a third timer; the 8031 was a ROM-less version for use with external program memory; the 8751 carried EPROM. Later derivatives from Atmel (now Microchip), NXP, Silicon Labs, STC and others added flash memory, ADCs, watchdogs and faster one-cycle cores. Decades after its introduction, the 8051 architecture remains one of the most widely used microcontroller cores in the world, embedded in everything from keyboards and USB devices to industrial controllers.
