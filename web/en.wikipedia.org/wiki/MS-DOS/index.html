MS-DOS (Microsoft Disk Operating System) is an operating system for x86-based personal computers developed by Microsoft. First released in 1981, it was the dominant operating system for IBM PC compatibles during the 1980s and early 1990s.

History

Microsoft purchased 86-DOS, written by Tim Paterson of Seattle Computer Products, and adapted it as PC DOS for IBM's new personal computer in 1981; Microsoft retained the right to license its own version, MS-DOS, to other manufacturers. As clone PCs spread, MS-DOS became the standard platform for business software and games.

Successive versions added subdirectories, hard-disk support, networking, and memory management. MS-DOS 6.22 (1994) was the last standalone retail version; later releases shipped as the underlying base of Windows 95, 98, and Me. Its command-line interpreter is COMMAND.COM, and the system is configured through CONFIG.SYS and AUTOEXEC.BAT.

Legacy

MS-DOS shaped the conventions of personal computing: drive letters, 8.3 filenames, and commands such as DIR, COPY, and DEL persist in the Windows command prompt today. Microsoft released the source code of early versions (1.25 and 2.0) in 2014, and of MS-DOS 4.0 in 2024, for historical interest. Compatible systems such as FreeDOS remain in use for retro computing and embedded purposes.
