Signed measure

In mathematics, a signed measure is a generalisation of the concept of measure by allowing the set function to take negative values. A signed measure is defined on a measurable space (X, Σ) as a function μ: Σ → [−∞, +∞] (or [−∞, +∞)) that assigns the value 0 to the empty set and is countably additive, with the restriction that μ may take at most one of the two infinite values.

Hahn decomposition theorem

The Hahn decomposition theorem states that for any signed measure μ there is a partition of X into a positive set P and a negative set N such that every measurable subset of P has nonnegative measure and every measurable subset of N has nonpositive measure. The associated Jordan decomposition writes μ as the difference of two mutually singular finite measures: μ = μ+ − μ−.

Total variation

|μ|(E) = μ+(E) + μ−(E)

The total variation |μ| is itself a finite measure when μ+ and μ− are finite, and |μ|(X) defines a norm that makes the space of signed measures on (X, Σ) a Banach space. Signed measures arise naturally as indefinite integrals of integrable functions with respect to a positive measure.
