Integer programming

An integer programming problem is a mathematical optimization program in which some or all of the variables are restricted to be integers. If all variables must be integers it is a pure integer program; if some may be continuous it is a mixed-integer program (MIP). Programs with variables restricted to 0 or 1 are called binary integer programs.

Applications

Integer programming models many practical problems in which decisions are discrete, including production scheduling, vehicle routing, airline crew assignment, facility location, and capital budgeting. Famous problems such as the travelling salesman problem and the knapsack problem can be formulated as integer programs.

Complexity and methods

Integer programming is NP-hard in general. Standard solution methods include branch and bound, branch and cut, cutting-plane methods, and the Gomory cutting planes introduced in the 1950s. Relaxing the integrality constraints gives a linear programming relaxation whose optimum bounds the integer optimum.

Solvers

Commercial and open-source solvers such as CPLEX, Gurobi, and CBC solve large mixed-integer programs arising in industry, combining presolving, heuristics, and parallel branch-and-bound search.
