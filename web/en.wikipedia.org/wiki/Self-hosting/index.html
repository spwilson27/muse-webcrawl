Self-hosting

The term self-hosting is used in several computing contexts:

A self-hosting compiler produces a new version of itself when run on its own source code.

Compilers

A compiler is self-hosting if it is written in the language it compiles, so that it can compile itself. Examples include GCC (for C and C++), rustc (Rust), the Go compiler, and Free Pascal. Achieving self-hosting is a milestone in a language's maturity and simplifies development, since improvements to the compiler can be written in the language itself. Because the first version cannot compile itself, a new language must be bootstrapped: an initial compiler is written in another language or produced by cross-compilation, after which the self-hosted compiler takes over. Ken Thompson's "Reflections on Trusting Trust" lecture famously explored the security implications of self-hosting compilers.

Software and services

In a second sense, self-hosting means running software services on one's own hardware or server rather than relying on a third-party hosted provider — for example, self-hosting an email server, a Nextcloud instance, a Git server (such as Gitea), a media server, or a website from a home server or virtual private server. Advocates cite privacy, control over data, and independence from subscription services and platform shutdowns; critics note the burden of maintenance, security patching, backups, and uptime that the operator assumes.

Operating systems and other uses

Operating system projects may likewise be described as self-hosting when the system can be developed and built on itself. In web development, "self-hosting" fonts or assets (serving them from one's own domain instead of a content delivery network) is also commonly discussed.
