Finite-state machine

A finite-state machine (FSM) or finite-state automaton is a mathematical model of computation. It is an abstract machine that can be in exactly one of a finite number of states at any given time. The FSM can change from one state to another in response to some inputs; the change from one state to another is called a transition. An FSM is defined by a list of its states, its initial state, and the inputs that trigger each transition.

Concepts and terminology

A finite-state machine has a finite amount of internal memory, summarised entirely by its current state. Machines that only accept or reject input strings are called acceptors; those that produce output are transducers, classified as Mealy machines (output depends on state and input) or Moore machines (output depends only on state).

Mathematical model

A deterministic finite automaton is a 5-tuple (Q, Σ, δ, q0, F): a finite set of states Q, an input alphabet Σ, a transition function δ, a start state q0 and a set of accepting states F. The class of languages recognised by finite automata is exactly the regular languages, expressible by regular expressions.

Applications

Finite-state machines are used in lexical analysis in compilers, network protocol design, text processing, control systems, digital electronics and video-game character behaviour. More powerful computational models, such as the Turing machine, extend the FSM with unbounded memory.
