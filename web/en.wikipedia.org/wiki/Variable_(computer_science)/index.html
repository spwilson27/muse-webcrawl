Variable (computer science)

In computer programming, a variable is an abstract storage location paired with an associated symbolic name, which contains some known or unknown quantity of data or information referred to as a value. The variable name is the usual way to reference the stored value, in addition to referring to the variable itself, depending on context. Variables give programmers a way to manipulate data symbolically rather than by fixed memory addresses.

A variable: a name bound to a stored value.

Properties

A variable is characterised by its name (identifier), its type, its scope (the region of the program where the binding is visible), its lifetime (when its storage exists — for instance, automatic, static or dynamic allocation) and its mutability. In statically typed languages the type is fixed at declaration; in dynamically typed languages it may vary with the value assigned. Constants are names bound to values that cannot change after initialisation.

Semantics

Languages differ in whether a variable denotes a memory cell whose contents change (as in imperative languages and the notion of an l-value versus an r-value) or is simply a name bound to a value, as in functional programming, where "variables" follow the mathematical sense and are typically immutable once bound. Assignment, aliasing and side effects all turn on this distinction, as does the formal treatment of variables in the lambda calculus, where bound and free variables, substitution and alpha-conversion define how names work.
