Common Information Model (computing)

From Wikipedia, the free encyclopedia

The Common Information Model (CIM) is an open standard maintained by the Distributed Management Task Force (DMTF) that defines how managed elements in an information technology environment are represented as a common set of objects and relationships between them. It provides a vendor-neutral, object-oriented model for describing systems, networks, applications, storage and other managed resources.

Structure

CIM consists of a specification of the modelling language and meta-model, and a set of standard schemas. The schemas are organised into layers: the Core Model, containing concepts common to all areas of management; Common Models, covering areas such as systems, devices, networks and storage; and Extension Schemas, which vendors and organisations add for specific technologies. Classes, properties, associations and methods are defined in Managed Object Format (MOF) files.

Use in management technologies

CIM underlies several widely deployed management technologies, including Web-Based Enterprise Management (WBEM), the Windows Management Instrumentation (WMI) framework in Microsoft Windows, and the Storage Management Initiative Specification (SMI-S) used in storage area networks. It is also related to newer DMTF standards such as Redfish, the RESTful management interface for servers, which draws on CIM concepts.
