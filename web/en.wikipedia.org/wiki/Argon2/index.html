Argon2 is a key derivation function that won the Password Hashing Competition in July 2015. It was designed by Alex Biryukov, Daniel Dinu, and Dmitry Khovratovich of the University of Luxembourg and is standardised in RFC 9106.

Design

Argon2 is deliberately memory-hard: in addition to adjustable computational cost, it fills a large, configurable amount of memory, raising the cost of massively parallel password-cracking hardware such as GPUs and ASICs. Parameters include memory size, number of iterations, and degree of parallelism.

Variants

Argon2d uses data-dependent memory access, maximising resistance to GPU cracking but risking side-channel attacks; Argon2i uses data-independent access; Argon2id, the variant recommended by RFC 9106 and by OWASP for password storage, combines both approaches.
