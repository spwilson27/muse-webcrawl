Racket (programming language)

Racket is a general-purpose, multi-paradigm programming language based on the Scheme dialect of Lisp. It is designed as a platform for programming language design and implementation, and is also used in computer science education and research. One of Racket's goals is to serve as a platform for language creation, design, and implementation, letting programmers build domain-specific and general-purpose languages on top of its macro system.

History

Racket grew out of the PLT Scheme project founded in the mid-1990s by Matthias Felleisen and colleagues, originally aimed at teaching programming to beginners. The project produced the DrScheme programming environment (now DrRacket) and the How to Design Programs curriculum. In 2010 the language was renamed from PLT Scheme to Racket, reflecting its evolution into a broader language platform.

Features

Racket features a powerful macro system that supports creating entirely new languages ("language-oriented programming"); a rich standard library; a JIT-compiling virtual machine (with a newer Chez Scheme–based implementation, Racket CS); support for contracts and gradual typing via Typed Racket; and extensive tooling, including the DrRacket IDE, the Scribble documentation language, and the raco build and package tools. Derived languages built in Racket include Typed Racket, FrTime, and the teaching languages used by How to Design Programs.

Use

Racket is used in many university programming-languages courses, in research, and by companies for applications ranging from web services to commercial products; the Naughty Dog game studio famously used a Racket-derived scripting system in its games.
