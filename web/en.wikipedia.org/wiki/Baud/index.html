Baud

The baud (symbol: Bd) is a unit of measurement for symbol rate — the number of distinct symbol changes per second in a digitally modulated signal or communications channel. It is named after the French telegraph engineer Émile Baudot, inventor of the Baudot code.

Definition

A rate of one baud is one symbol per second. Where each symbol carries exactly one bit — as in simple binary signalling — the baud rate equals the bit rate in bits per second. Modern modulation schemes transmit several bits per symbol (for example, 16-QAM carries four bits per symbol), so a channel's bit rate is generally higher than its baud rate: a 2,400-baud modem using such schemes can achieve 9,600 bit/s or more.

Common misuse

"Baud" is frequently used colloquially to mean bits per second, especially in connection with older dial-up modems described as "300 baud" or "9600 baud". This is technically correct only where one bit is sent per symbol; a "56k modem" did not operate at 56,000 baud. Telecommunications engineers therefore distinguish the gross bit rate from the symbol rate measured in baud.

History

The unit was adopted in honour of Baudot, whose five-unit telegraph code of the 1870s was a forerunner of modern digital character codes. The measure became standard with the spread of telegraphy and, later, data modems in the twentieth century.
