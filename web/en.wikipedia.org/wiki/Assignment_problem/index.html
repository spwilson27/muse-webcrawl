Assignment problem

The assignment problem as a weighted bipartite matching.

The assignment problem is a fundamental problem of combinatorial optimization. Given a set of agents and a set of tasks, where assigning each agent to a task incurs a known cost, the problem is to find a one-to-one assignment of agents to tasks that minimises (or maximises) the total cost. It can be modelled as finding a minimum-weight perfect matching in a complete bipartite graph, or as a special case of the transportation problem and of linear programming.

Formal definition

Let there be n agents and n tasks, and let C(i, j) be the cost of agent performing task j. The goal is to find a permutation σ of the tasks minimising the sum Σ C(i, σ(i)). The problem is expressible as an integer linear program, but because the constraint matrix is totally unimodular, the linear programming relaxation yields integral optima automatically.

Algorithms

The classic solution is the Hungarian algorithm, developed by Harold Kuhn in 1955 based on earlier work by the Hungarian mathematicians Dénes Kőnig and Jenő Egerváry; James Munkres later showed it runs in polynomial time. The algorithm runs in O(n³) time in its refined form. Related methods include the Jonker–Volgenant algorithm, widely used in practice, and auction algorithms developed by Dimitri Bertsekas.

Variants and applications

Generalizations include the quadratic assignment problem (NP-hard), the bottleneck assignment problem, and rectangular problems with unequal numbers of agents and tasks. Applications include assigning workers to jobs, aircraft to gates, taxis to passengers, targets to weapons, and kidney donors to recipients, as well as data association in tracking and computer vision.
