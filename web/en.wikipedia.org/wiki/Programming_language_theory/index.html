Programming language theory

Programming language theory (PLT) is a branch of computer science that deals with the design, implementation, analysis, characterization, and classification of programming languages and of their individual features. It draws on mathematical logic, algebra, and category theory.

Topics

  • Semantics: formal descriptions of meaning, including operational, denotational, and axiomatic semantics
  • Type theory: classification of values and expressions, type inference, and type safety
  • Lambda calculus: the foundational model of computation underlying functional languages
  • Concurrency models, such as the actor model and process calculi
  • Language design: studying how features affect expressiveness, safety, and reasoning

History

The field emerged in the 1960s and 1970s with work on formal grammars, Algol, and denotational semantics by researchers such as Christopher Strachey and Dana Scott. Concepts developed in PLT, including type systems and garbage collection theory, now underpin mainstream languages.
