Rust is a general-purpose programming language emphasising performance, type safety and concurrency. It enforces memory safety — ensuring that all references point to valid memory — without requiring a garbage collector, by means of an ownership system with rules that the compiler checks through a "borrow checker". Rust was designed by Graydon Hoare as a personal project at Mozilla, which began sponsoring it in 2009; it was announced in 2010 and reached version 1.0 in May 2015.

Design

Rust's central innovation is its ownership model: each value has a single owner, values may be borrowed by reference under rules that prevent data races and dangling pointers, and memory is freed deterministically when an owner goes out of scope. Combined with a rich type system — algebraic data types, pattern matching, generics, traits (similar to type classes), and lifetimes — this lets Rust programs achieve the speed and low-level control of C and C++ while eliminating entire classes of bugs, including buffer overflows, use-after-free and null-pointer dereferences. Code that must bypass these checks can be written in explicitly marked unsafe blocks, used to build safe abstractions over low-level operations.

Tooling and ecosystem

Rust ships with Cargo, its package manager and build tool, which fetches dependencies from the crates.io registry, and with rustfmt for code formatting and Clippy for linting. The compiler, rustc, is built on LLVM and produces native code for a wide range of platforms. The language and its standard library are developed openly, with a six-week release cycle and an "edition" system (2015, 2018, 2021, 2024) allowing language evolution without breaking existing code.

Adoption

Rust has been used at Mozilla (components of the Firefox browser and the Servo engine), Microsoft, Google, Amazon, Meta, Discord and Cloudflare, and was adopted for parts of the Linux kernel — the first language other than C and assembly admitted there — and the Android operating system. In the Stack Overflow Developer Survey it was voted the "most loved" (later "most admired") programming language every year from 2016 onward. In 2021 stewardship passed to the independent Rust Foundation, formed by major industry sponsors.
