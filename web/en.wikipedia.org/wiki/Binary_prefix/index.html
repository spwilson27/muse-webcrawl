Binary prefix

A binary prefix is a unit prefix for multiples of units. It is most often used in data processing, data transmission, and digital information, principally in association with the bit and the byte, to indicate multiplication by a power of 2. The computer industry has historically used the units kilobyte, megabyte, and gigabyte, and the corresponding symbols KB, MB, and GB, in at least two slightly different measurement systems.

In citations of main memory (RAM) capacity, gigabyte customarily means 230 bytes. In citations of storage capacity, gigabyte has more typically meant 109 bytes. This discrepancy has caused confusion, litigation, and calls for clarification. In 1998, the International Electrotechnical Commission (IEC) proposed new prefixes, formed from the first two letters of the corresponding SI prefix plus "bi" (for binary): kibi-, mebi-, gibi-, and so on.

Thus, for example, one kibibyte equals 1,024 bytes, and one mebibyte equals 1,048,576 bytes. The IEC prefixes were incorporated into the international standard ISO/IEC 80000 and are recommended by standards bodies such as NIST. Adoption in general usage has been gradual, although many operating systems and free-software projects now display file sizes using IEC units.

History

The use of SI prefixes with binary values dates to the earliest days of computing, when engineers noticed that 210 = 1,024 is close to 1,000 and borrowed the term "kilobyte" for that quantity. As storage sizes grew, the percentage difference between the decimal and binary interpretations increased — about 10% at the gigabyte scale — making the ambiguity commercially significant. This led to consumer lawsuits against storage manufacturers in the 2000s, after which manufacturers increasingly labelled products in decimal units.

Usage

Memory manufacturers continue to use binary capacities for RAM, while storage manufacturers generally use decimal capacities. Operating systems differ: Microsoft Windows reports sizes in binary units with decimal labels, while macOS uses decimal units, and many Linux utilities can display either.
