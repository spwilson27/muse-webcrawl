Interface (computing)

In computing, an interface is a shared boundary across which two or more separate components exchange information. The term is used for hardware connections between devices, for the points of interaction between software components, and for the means by which users interact with a system. Interfaces are commonly standardised so that components built independently can work together, and they hide internal implementation details behind a defined set of interactions — a principle known as abstraction and information hiding.

Hardware interfaces

Hardware interfaces specify physical connectors, electrical signals and protocols: examples include USB, HDMI, PCI Express, SATA and Ethernet. A hardware interface lets a device such as a printer, disk drive or network adapter be attached to many different computers, and allows manufacturers to change a device's internals without breaking compatibility, provided the interface is honoured.

Software interfaces

In software, an interface defines the operations one component offers to others. An application programming interface (API) specifies functions, data structures and protocols by which programs request services from libraries, operating systems or remote services. In object-oriented programming, an interface (as in Java or C#) is an abstract type declaring method signatures that classes promise to implement, enabling polymorphism without inheritance of implementation. Programming against interfaces rather than concrete implementations is a standard design principle that reduces coupling and eases testing and substitution.

User interfaces

The user interface (UI) is the means by which people control and perceive a system, encompassing command-line interfaces, graphical user interfaces (windows, icons, menus, pointers), touch interfaces, voice interfaces and, increasingly, conversational and immersive interfaces. Human–computer interaction research studies how interface design affects usability, accessibility and error rates. A related concept is the network interface, the point at which a device connects to a network, identified for example by a MAC address.
