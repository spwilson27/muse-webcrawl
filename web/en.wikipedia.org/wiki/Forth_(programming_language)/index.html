Forth (programming language)

Forth is a procedural, concatenative, stack-based programming language and interactive development environment designed by Charles H. "Chuck" Moore from the late 1960s. Forth code is written in reverse Polish (postfix) notation: operands are pushed onto a data stack and "words" (subroutines) operate on them. A defining feature is extensibility — programmers build applications by defining new words composed of existing ones, so the language grows toward the problem domain. Forth became popular for astronomy, embedded control, and bootstrapping new hardware because a complete interactive system fits in a few kilobytes.

History

Moore developed the system informally at the National Radio Astronomy Observatory beginning around 1968; the name was chosen because he considered it a "fourth-generation" language but the operating system's file names were limited to five characters. With Elizabeth Rather he co-founded FORTH, Inc. in 1973. Forth controlled telescopes at observatories including Kitt Peak, flew in space instruments, powered arcade and industrial systems, and was used in the Open Firmware boot standard. ANS Forth was standardised in 1994 (ANS X3.215-1994).

Language structure

A Forth system is built around a dictionary of words, a data stack, and a return stack. Definitions are made with colon and semicolon:

: SQUARED ( n -- n^2 ) DUP * ;
5 SQUARED .   \ prints 25

The parenthesised comment documents the stack effect of the word — what it consumes and produces. Control structures (IF...THEN, DO...LOOP, BEGIN...UNTIL) are themselves words executed at compile time, and there is no conventional type system or parameter passing: everything passes through the stacks. Forth systems are typically threaded-code interpreters that can compile new definitions on the fly, giving an interactive read-eval loop decades before such environments were fashionable.

Applications and influence

Forth's small footprint made it a favourite for embedded systems, spacecraft (including instruments on NASA missions), boot firmware, and hardware bring-up. It influenced later concatenative languages such as Joy and Factor, and its minimalist philosophy influenced Moore's own later hardware designs of stack machines.
