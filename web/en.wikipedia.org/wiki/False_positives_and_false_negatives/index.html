False positives and false negatives

False positives and false negatives are the two kinds of error made by a binary test or classifier. A false positive occurs when a test reports a positive result for a case that is truly negative (a "false alarm"); a false negative occurs when a test reports a negative result for a case that is truly positive (a "miss"). Correct outcomes are true positives and true negatives.

The confusion matrix

Test positiveTest negative
Actually positiveTrue positive (TP)False negative (FN)
Actually negativeFalse positive (FP)True negative (TN)

From these four counts, many performance metrics are derived: sensitivity (recall) = TP/(TP+FN); specificity = TN/(TN+FP); precision = TP/(TP+FP); and accuracy = (TP+TN)/(TP+TN+FP+FN).

Hypothesis testing

In statistical hypothesis testing, a false positive is a Type I error (rejecting a true null hypothesis) and a false negative is a Type II error (failing to reject a false null hypothesis). The significance level α of a test is its false positive rate under the null hypothesis, while statistical power is one minus the false negative rate.

Examples

In medical screening, a false positive mammogram can lead to unnecessary biopsies, while a false negative can delay cancer treatment. In airport security, false positives cause secondary screening of harmless passengers, while false negatives allow threats through. In software testing and spam filtering, the same trade-off applies: tightening a test reduces false negatives but generally increases false positives.

Base rates

Because of the base rate effect, the practical meaning of a positive result depends strongly on how common the condition is. Screening a low-prevalence population yields a higher proportion of false positives even with an accurate test, which is why confirmatory testing is standard practice in medicine and forensic science.
