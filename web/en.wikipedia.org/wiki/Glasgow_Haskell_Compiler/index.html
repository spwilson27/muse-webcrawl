The Glasgow Haskell Compiler (GHC) is a native or machine code compiler for the Haskell functional programming language. It provides the platform for the research and development of modern language features, and is well known for being a production-grade open source software set. GHC was originally developed at the University of Glasgow, and is now maintained by a worldwide community of contributors.

Overview

GHC compiles to native code on many platforms and can also generate code via LLVM or C. It includes an interactive environment, GHCi, a profiler, and extensive libraries. GHC's type system supports many extensions beyond the Haskell 2010 standard, including generalised algebraic data types, type families, and type-level programming.

Architecture

The compiler desugars Haskell into a small intermediate language called Core, performs program transformations and optimisation, and passes the result through the Spineless Tagless G-machine (STG) model to native code generation. Its runtime system provides lightweight threads, software transactional memory, and a parallel garbage collector.

History

Development began in 1989 at Glasgow, with Simon Peyton Jones a central figure; the first public release, version 0.10, appeared in 1992. GHC has since become the de facto standard Haskell implementation, used by major projects and in industry.
