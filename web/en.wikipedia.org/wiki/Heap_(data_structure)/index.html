Heap (data structure)

In computer science, a heap is a tree-based data structure that satisfies the heap property: in a max heap, for any given node C, if P is a parent node of C, then the key of P is greater than or equal to the key of C; in a min heap, the parent key is less than or equal to that of its children. The node at the "top" of the heap (with no parents) is called the root.

Implementation

The most common implementation is the binary heap, in which the tree is a complete binary tree that can be stored compactly in an array: for a node at index , its children are at indices 2i + 1 and 2i + 2, and its parent at index ⌊(i − 1)/2⌋. Insertion and extraction of the extreme element are performed by "bubbling" the element up or down the tree to restore the heap property, each in O(log n) time.

Operations and complexity

  • Find max (or min) — constant time, O(1), by reading the root.
  • Insert — O(log n).
  • Extract max (or min) — O(log n).
  • Heapify / build heap — O(n) from an unsorted array.

Applications

Heaps are the classic implementation of the priority queue abstract data type, and underpin the heapsort sorting algorithm. They are used in graph algorithms such as Dijkstra's algorithm and Prim's algorithm, in Huffman coding, and in operating system scheduling. Other heap variants include the Fibonacci heap, binomial heap, d-ary heap, pairing heap and treap.

The heap data structure is unrelated to "heap memory" in memory management; the shared name is a historical coincidence.
