Dovecot (software)

Dovecot is an open-source IMAP and POP3 email server for Linux and Unix-like systems, written primarily with security and performance in mind. It was created by Finnish developer Timo Sirainen and first released in July 2002. Dovecot is among the most widely used IMAP servers in the world, serving as the back end for many large email providers and countless self-hosted mail systems.

Features

Dovecot supports the standard mail storage formats mbox and Maildir, as well as its own optimised dbox formats. It provides full IMAP extensions support, server-side searching and Sieve filtering (via the Pigeonhole project), flexible authentication against many back ends, and a local delivery agent with LMTP support. It is designed to be self-healing and uses extensive indexing to deliver high performance.

History

Version 1.0 was released in 2007, and the substantially reworked 2.0 series followed in 2010. In 2015 the company behind Dovecot merged with Open-Xchange, which continued to develop the open-source core alongside commercial offerings such as Dovecot Pro. Major deployments have included Apple, the Mozilla Thunderbird ecosystem, and large ISPs.
