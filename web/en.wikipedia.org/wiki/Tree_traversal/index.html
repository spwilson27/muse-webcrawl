Tree traversal

In computer science, tree traversal (also known as tree search or walking the tree) is a form of graph traversal that refers to the process of visiting each node in a tree data structure exactly once. Such traversals are classified by the order in which the nodes are visited, and are used to search, print, copy or evaluate the contents of a tree.

Depth-first search

Depth-first traversals explore as far down a branch as possible before backtracking. For a binary tree, the three standard orders are defined by when the node itself is visited relative to its left and right subtrees:

  • Pre-order: visit the node, then the left subtree, then the right subtree.
  • In-order: visit the left subtree, then the node, then the right subtree. In a binary search tree, in-order traversal yields the keys in sorted order.
  • Post-order: visit the left subtree, then the right subtree, then the node — the natural order for deleting a tree or evaluating a postfix expression.

Depth-first search is usually implemented recursively or with an explicit stack, and uses O(h) auxiliary space, where h is the height of the tree.

Breadth-first search

Breadth-first (level-order) traversal visits nodes level by level, from the root downwards, left to right within each level. It is implemented with a queue and is useful for finding the shallowest node satisfying a condition.

Applications

Tree traversal underlies expression evaluation, syntax-tree processing in compilers, file-system walking, decision-tree inference and the printing or serialisation of hierarchical data.
