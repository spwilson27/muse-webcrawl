Revision control

Revision control, also known as version control or source control, is the management of changes to documents, computer programs, large web sites, and other collections of information. Changes are usually identified by a number or letter code, termed the "revision number", and each revision is associated with a timestamp and the person making the change.

Overview

Revision control systems (VCS) allow teams to track changes over time, revert files to previous states, compare changes, and work in parallel on branches that can later be merged. Systems are classified as centralized, such as CVS and Subversion, where a single server repository holds the authoritative history, or distributed, such as Git and Mercurial, where every checkout contains a full copy of the history.

Concepts

Key concepts include the repository, the working copy, commits (check-ins), branches, merging, conflict resolution, tags, and the trunk or mainline. Revision control is a standard part of modern software development and is also used for configuration management, documents, and data.
