Sigmoid function

A sigmoid function is any mathematical function whose graph has a characteristic S-shaped or sigmoid curve. The most common example is the logistic function, which maps any real number to a value between 0 and 1.

S(x) = 1 / (1 + e−x) = ex / (ex + 1)

Properties

A sigmoid function is monotonic, differentiable, and bounded, with a positive derivative whose graph is bell-shaped. The logistic function has the convenient derivative S′(x) = S(x)(1 − S(x)). Other sigmoid functions include the hyperbolic tangent, the arctangent, the error function, and the Gompertz curve.

Applications

Sigmoid functions arise as the cumulative distribution functions of many probability distributions and as the activation function of artificial neurons in neural networks, where they were the standard choice before being largely displaced by the rectified linear unit (ReLU). In logistic regression, the logistic function models the probability of a binary outcome. Their saturating behaviour can cause the vanishing gradient problem in deep networks.
