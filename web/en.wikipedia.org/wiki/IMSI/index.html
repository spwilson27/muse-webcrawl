The international mobile subscriber identity (IMSI) is a unique number, usually fifteen digits, that identifies a subscriber in a mobile telephone network. It is stored on the subscriber's SIM card and in the operator's home location register (HLR) or home subscriber server (HSS), and is used to authenticate the subscriber and acquire services, particularly when roaming.

Structure

An IMSI, as defined in ITU-T Recommendation E.212, consists of:

  • Mobile Country Code (MCC) — three digits identifying the country.
  • Mobile Network Code (MNC) — two or three digits identifying the operator within the country.
  • Mobile Subscription Identification Number (MSIN) — the remaining digits identifying the individual subscription within that network.

Use and privacy

The IMSI is sent by the mobile device to the network when attaching, and is thereafter usually replaced by a temporary identity (TMSI) to protect the subscriber's privacy. Because it can be transmitted in the clear in older network generations, devices known as "IMSI catchers" (such as the StingRay) can exploit it to identify and track phones, which has raised legal and privacy concerns. In 5G networks, the permanent identifier (the SUPI, the successor to the IMSI) is transmitted in concealed form (SUCI) using public-key encryption to mitigate this vulnerability.
