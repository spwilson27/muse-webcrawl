Generalized linear model

From Wikipedia, the free encyclopedia

In statistics, a generalized linear model (GLM) is a flexible generalization of ordinary linear regression. The GLM generalizes linear regression by allowing the linear model to be related to the response variable via a link function and by allowing the magnitude of the variance of each measurement to be a function of its predicted value. Generalized linear models were formulated by John Nelder and Robert Wedderburn as a way of unifying various other statistical models, including linear regression, logistic regression and Poisson regression, in their landmark 1972 paper.

Components

A GLM consists of three elements:

  1. Random component — a probability distribution for the response variable from the exponential family (e.g. normal, binomial, Poisson, gamma).
  2. Systematic component — a linear predictor η = Xβ, a linear combination of unknown parameters and known covariates.
  3. Link function — a monotonic differentiable function g such that g(μ) = η, connecting the expected value μ of the response to the linear predictor.

g(E[Y]) = Xβ

Fitting

Parameters are usually estimated by maximum likelihood. Because the estimating equations are generally nonlinear, they are solved iteratively by iteratively reweighted least squares (IRLS), the algorithm proposed by Nelder and Wedderburn and implemented in software such as R's glm() function. Model assessment uses quantities such as the deviance and information criteria like the AIC.

Extensions

GLMs have been extended in many directions: generalized additive models (GAMs) replace the linear predictor with smooth functions of the covariates; generalized linear mixed models (GLMMs) add random effects; quasi-likelihood methods relax the distributional assumption; and generalized estimating equations (GEE) handle correlated responses. A Bayesian formulation places priors on the coefficients and is fitted by Markov chain Monte Carlo.
