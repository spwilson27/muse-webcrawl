Dynamic logic (modal logic)

Dynamic logic
BranchModal logic; formal verification
Introduced byVaughan Pratt (1976); developed by Fischer & Ladner, Harel, Kozen & Tiuryn
Key notation[α]φ, ⟨α⟩φ

Dynamic logic is a family of modal logics developed for reasoning about computer programs and actions. First proposed by Vaughan Pratt in 1976 and developed extensively in the following years — summarised in the 2000 monograph by Harel, Kozen and Tiuryn — dynamic logic treats programs as modal operators acting on propositions about states.

Syntax and semantics

In propositional dynamic logic (PDL), if α is a program and φ is a proposition, then [α]φ expresses that every execution of α terminates in a state satisfying φ, while the dual ⟨α⟩φ expresses that some execution of α can lead to a state satisfying φ. Programs can be combined with operators for sequence, nondeterministic choice, iteration (Kleene star) and tests. Semantically, programs denote relations between states, making dynamic logic a multi-modal logic with one modality per program.

Results and variants

PDL is decidable and has the finite model property; its satisfiability problem is EXPTIME-complete. Fischer and Ladner gave an early axiomatisation and proof procedures. First-order dynamic logic extends the framework to programs over data structures and underlies verification systems related to Hoare logic, whose triples {φ}α{ψ} correspond to the implication φ → [α]ψ.

Applications

Dynamic logic has been applied to program verification, reasoning about actions in artificial intelligence, and linguistics, and it has inspired related formalisms such as dynamic epistemic logic, used to model information change in multi-agent systems.
