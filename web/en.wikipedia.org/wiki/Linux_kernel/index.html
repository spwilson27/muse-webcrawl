Linux kernel

DeveloperLinus Torvalds and contributors
Initial release17 September 1991
Written inC (and Rust for some components)
TypeMonolithic kernel
LicenceGPLv2

The Linux kernel is a free and open-source, monolithic, modular, multitasking, Unix-like operating system kernel. It was originally written in 1991 by Linus Torvalds for his i386-based PC, and was soon adopted as the kernel for the GNU operating system. Since then it has been ported to more hardware platforms than any other operating system.

History

Torvalds announced the project on the comp.os.minix newsgroup on 25 August 1991. Version 1.0 was released in March 1994. Development is organised around Torvalds's tree, with six- or seven-figure numbers of lines of code contributed per release by thousands of developers, many employed by technology companies. The kernel's mascot is Tux, a penguin.

Architecture

Linux is a monolithic kernel: device drivers, filesystems, networking and memory management run in kernel space, though loadable kernel modules can be added and removed at runtime. It supports preemptive multitasking, virtual memory, shared libraries, demand paging, and multiprocessing. System calls provide the principal interface between user-space programs and the kernel.

Uses

The kernel underlies Linux distributions on desktops and servers, the Android mobile operating system, embedded devices, routers, Chromebooks, and nearly all of the world's top supercomputers. As of the mid-2020s it comprises tens of millions of lines of code and is one of the largest open-source projects in existence.
