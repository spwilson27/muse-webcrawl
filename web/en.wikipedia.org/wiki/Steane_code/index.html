Steane code

The Steane code is a quantum error-correcting code that encodes one logical qubit into seven physical qubits and can correct an arbitrary error on any single qubit. It was introduced by Andrew Steane in 1996 and is the best-known example of a CSS code, being constructed from the classical [7,4,3] Hamming code and its dual. In the [[n, k, d]] notation it is a [[7,1,3]] code: seven physical qubits, one logical qubit, and distance three.

Construction

The Steane code is a Calderbank–Shor–Steane (CSS) code. Its stabilizer group has six generators, three of X type and three of Z type, arranged according to the parity-check matrix of the classical Hamming (7,4) code: each generator acts on the four qubits corresponding to a row of that matrix. The logical |0⟩ state is the uniform superposition of the eight even-weight codewords of the Hamming code, and logical |1⟩ the superposition of its coset of odd-weight codewords. Bit-flip (X) errors are detected by the Z-type stabilizers and phase-flip (Z) errors by the X-type stabilizers, exactly mirroring classical syndrome decoding in the two bases.

Properties and fault tolerance

The code is notable because all Clifford group operations — including CNOT, Hadamard, and the phase gate — can be implemented transversally, applying the operation qubit-by-qubit across blocks, which prevents single errors from spreading within a block and made the Steane code the historical testbed for fault-tolerant quantum computation. Steane's own "ancilla-based" syndrome extraction method, in which prepared ancilla states are coupled to the data and measured, was developed for this code. Its main drawbacks are its encoding rate and modest distance compared with topological codes; nevertheless it has been demonstrated experimentally on ion-trap and superconducting platforms, including logical-qubit experiments showing error correction below the break-even point in combination with fault-tolerant gadgets.
