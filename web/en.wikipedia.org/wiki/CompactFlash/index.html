Introduced1994
DeveloperSanDisk
TypeMass storage device format

CompactFlash (CF) is a flash memory mass storage device format used mainly in portable electronic devices. The format was specified and devices were first manufactured by SanDisk in 1994.

History

CompactFlash was originally based around Intel's NOR-based flash memory, and its physical format was later adapted from PCMCIA cards. Two subtypes exist: Type I cards (3.3 mm thick) and the thicker Type II cards (5 mm), the latter also accommodating microdrives.

Use

CF cards became the dominant memory card format in professional digital photography through the 2000s, prized for their robustness and high capacity. Successor formats include CFast and XQD/CFexpress.

Interface

The interface is electrically compatible with the parallel ATA (IDE) interface, allowing CF cards to be used in passive adapters as hard disk replacements.
