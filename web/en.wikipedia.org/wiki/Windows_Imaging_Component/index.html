The Windows Imaging Component (WIC) is a Component Object Model based imaging codec framework introduced in Windows Vista and Windows XP Service Pack 3 that makes it possible to work with and process images and image metadata. WIC enables application developers to perform image processing operations on any image format through a single set of common interfaces, without needing to be aware of the individual image formats. The component provides a standard framework for image codecs (encoders and decoders), pixel formats, and metadata formats, including Exif and IPTC metadata.

Because the framework is extensible, software vendors, camera manufacturers, and independent developers can write their own image codecs for novel image formats and have them integrate with the rest of the platform in the same way as the native image formats. The most prominent example is support for camera raw image formats: camera manufacturers supply WIC codecs for their proprietary raw formats, after which any WIC-enabled application, including Windows Explorer and Windows Photo Gallery, can read those images.

Features

Windows Imaging Component provides an extensible architecture for image codecs, pixel formats, and metadata, with automatic discovery of run-time installed codecs. It supports reading and writing of metadata embedded in image files, and preserves that metadata during encoding, decoding, and transcoding operations. The component works with standard image formats in Windows Vista, including JPEG, BMP, PNG, GIF, TIFF, and the HD Photo format (later standardized as JPEG XR). Arbitrary image formats can be supported by supplying codec plug-ins.

WIC codecs consist of two components: a decoder, which converts a stored image into a bitmap in memory, and an encoder, which converts an in-memory bitmap into a stored image. The framework exposes interfaces such as IWICImagingFactory, which applications use to create components, IWICBitmapDecoder and IWICBitmapEncoder, which perform the conversions, and IWICMetadataQueryReader and IWICMetadataQueryWriter for accessing metadata blocks.

Formats

Windows Vista shipped with built-in codecs for the standard web and document formats, as well as for HD Photo. Microsoft distributed an updated set of codecs over time, and third-party vendors released codecs for formats including camera raw files from Canon and Nikon, as well as formats such as DjVu and JPEG 2000 variants. Windows 10 added native support for the WebP format and later releases continued to extend the codec set available through the Microsoft Store.

Usage

WIC is used by several Microsoft technologies. WPF imaging classes are built on top of it, Direct2D uses WIC for loading bitmap images, and Windows Explorer uses it to generate thumbnails for any image format with an installed codec. The Windows Photo Viewer and the earlier Windows Photo Gallery likewise depend on WIC codecs.
