Storage area network

A storage area network (SAN) is a dedicated high-speed network that interconnects servers with shared pools of storage devices, presenting storage as block-level logical units (LUNs) that appear to hosts as locally attached disks.

Protocols

Classic SANs run Fibre Channel; IP-based alternatives include iSCSI and Fibre Channel over Ethernet (FCoE), and NVMe over Fabrics. SANs contrast with network-attached storage (NAS), which serves files over protocols such as NFS and SMB.

Features

SANs enable storage consolidation, server clustering, replication between data centres, snapshots, and non-disruptive migration. Zoning and LUN masking control which hosts can see which storage.
