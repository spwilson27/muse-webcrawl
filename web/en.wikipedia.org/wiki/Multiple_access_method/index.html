Multiple access method

In telecommunications and computer networks, a channel access method or multiple access method allows more than two terminals connected to the same transmission medium to transmit over it and to share its capacity. Such methods define how the medium is divided among users or how contention for it is resolved.

Types

The fundamental schemes include frequency-division multiple access (FDMA), time-division multiple access (TDMA), code-division multiple access (CDMA), and space-division multiple access (SDMA). Random access methods, in which terminals transmit without prior coordination, include ALOHA and carrier-sense multiple access (CSMA), used in Ethernet and Wi-Fi networks.

See also time-division multiple access and carrier-sense multiple access.
