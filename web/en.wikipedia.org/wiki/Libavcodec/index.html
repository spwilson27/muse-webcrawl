libavcodec is a free and open-source library of codecs for encoding and decoding video and audio data. It is part of the FFmpeg project and is used by a large number of multimedia applications, including media players, transcoders, web browsers, and game engines.

The library contains implementations of a very large number of media formats. Its video decoders include H.264/AVC, H.265/HEVC, AV1 (through external libraries), VP8 and VP9, MPEG-1, MPEG-2, MPEG-4 Part 2, and many legacy and niche formats; its audio codecs include AAC, MP3, Opus, Vorbis, FLAC, and AC-3. For widely used formats, libavcodec includes both decoders and encoders, and it can also act as a wrapper around external encoding libraries such as x264 and x265.

Design

libavcodec uses a codec registration and context-based API. An application opens a codec context for a stream, feeds it compressed packets, and receives decoded frames. Since version 3.1 of FFmpeg, the preferred interface is the send/receive API, in which the application sends packets to the decoder and receives frames from it, decoupling the input and output sides. Hardware acceleration can be provided through platform APIs such as VA-API, NVDEC, and VideoToolbox.

Legal issues

Some codecs implemented in libavcodec have historically been covered by software patents in certain jurisdictions, which has led some Linux distributions to ship reduced versions of the library or to exclude particular encoders. The FFmpeg project's own native encoders are distributed under the LGPL, although enabling certain components makes the combined library effectively GPL-licensed.

Applications

Programs and frameworks that use libavcodec include VLC media player, mpv, Chromium, HandBrake, and the GStreamer framework (through gst-libav). Many commercial products also embed the library.
