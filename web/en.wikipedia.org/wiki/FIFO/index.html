FIFO

FIFO is an acronym for first in, first out. It describes methods of processing data, inventory, and other items in which the first element added is the first one removed.

Computing

In computing, FIFO is used for data structures such as queues, buffers, and scheduling algorithms. A queue processes elements in arrival order, in contrast to a stack, which follows last-in, first-out (LIFO). In operating systems, named pipes are also called FIFOs. FIFO replacement is also a page-replacement algorithm in virtual memory and a cache-replacement policy.

Accounting and inventory

In accounting, FIFO is an inventory valuation method that assumes the earliest goods purchased are the first ones sold, so ending inventory consists of the most recently purchased items. It is permitted under both US GAAP and IFRS, unlike LIFO, which IFRS prohibits.

Other uses

FIFO also refers to fly-in fly-out work arrangements in mining regions of Australia and Canada, and to the principle of serving customers in arrival order.
