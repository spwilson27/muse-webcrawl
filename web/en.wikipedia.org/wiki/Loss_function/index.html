Loss function

Loss function

Field: Mathematical optimization, machine learning, decision theory

Also called: Cost function, error function

In mathematical optimization and decision theory, a loss function or cost function (sometimes also called an error function) is a function that maps an event or values of one or more variables onto a real number intuitively representing some "cost" associated with the event. An optimization problem seeks to minimize a loss function.

In statistics

In statistical estimation, the loss function quantifies the penalty for inaccuracy of a decision or estimate. Classical examples include squared loss, L(θ, a) = (θ − a)², which leads to the mean as the optimal point estimate, and absolute loss, L(θ, a) = |θ − a|, which leads to the median. Expected loss is called risk; the decision rule that minimises posterior expected loss is the Bayes estimator.

In machine learning

In machine learning, a loss function measures the discrepancy between a model's predictions and the true values on training data; training proceeds by minimising it, usually with gradient-based methods. Common examples include mean squared error for regression, cross-entropy loss for classification, hinge loss for support vector machines, and the Huber loss, which is less sensitive to outliers.
