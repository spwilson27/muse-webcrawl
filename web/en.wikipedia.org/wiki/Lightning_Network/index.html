Lightning Network

The Lightning Network (LN) is a "layer 2" payment protocol built on top of a blockchain-based cryptocurrency such as Bitcoin. It is intended to enable fast, low-cost transactions between participating nodes and has been proposed as a solution to the Bitcoin scalability problem.

History

The Lightning Network was proposed in a 2015 white paper by Joseph Poon and Thaddeus Dryja. Implementations by several teams, including Lightning Labs (lnd), Blockstream (Core Lightning), and ACINQ (Eclair), reached the Bitcoin main network in 2018.

How it works

Two participants open a payment channel by committing funds in a multi-signature transaction on the underlying blockchain. They can then exchange an unlimited number of off-chain balance updates, secured by hashed timelock contracts (HTLCs), and payments can be routed across multiple channels through intermediaries. Only the opening and closing transactions need to be settled on-chain, which reduces fees and confirmation delays and supports near-instant micropayments.

Criticism and limitations

Critics note routing difficulties for large payments, the need to keep funds locked in channels, online requirements for receiving payments, and watchtower services needed to guard against fraud while a user is offline.
