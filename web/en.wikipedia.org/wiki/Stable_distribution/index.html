Stable distribution

In probability theory, a stable distribution is a class of probability distributions suitable for modelling heavy tails and skewness. A distribution is said to be stable if a linear combination of two independent random variables with this distribution has the same distribution, up to location and scale parameters.

Definition

A non-degenerate distribution is stable if, for independent copies X1 and X2 of a random variable X and any positive constants a and b, the sum aX1 + bX2 has the same distribution as cX + d for some positive c and some d. Stable distributions are most commonly specified by their characteristic function, since closed-form densities are available only in special cases.

The model has four parameters: the stability parameter α (0 < α ≤ 2), the skewness parameter β (−1 ≤ β ≤ 1), the scale parameter γ > 0, and the location parameter δ.

Properties

  • Stable distributions arise as the limiting distributions in the generalised central limit theorem, just as the normal distribution does under finite-variance conditions.
  • Except for the cases α = 2 (normal), α = 1 with β = 0 (Cauchy), and α = 1/2 with β = ±1 (Lévy), stable densities have no closed form.
  • For α < 2 the tails are heavy (power-law), decaying like |x|−1−α, so the variance is infinite; for α ≤ 1 the mean is also undefined.
  • Stable distributions are infinitely divisible.

Special cases

  • Normal distribution (α = 2)
  • Cauchy distribution (α = 1, β = 0)
  • Lévy distribution (α = 1/2, β = 1)
  • Holtsmark distribution (α = 3/2, β = 0)

Applications

Stable distributions, developed by Paul Lévy in the 1920s, have been used to model asset returns in finance (notably promoted by Benoit Mandelbrot), signal processing with impulsive noise, and a range of natural phenomena exhibiting scaling and heavy tails.
