No free lunch theorem

In computational complexity and optimisation, the no free lunch theorems state that, when averaged over all possible problems, every optimisation algorithm performs equally well. They were established by David Wolpert and William Macready in 1995–1997. The informal gloss, borrowed from the saying "there ain't no such thing as a free lunch", is that superior performance on one class of problems is necessarily paid for by worse performance on others.

Statement

For search and optimisation, the theorem says that for any two algorithms A and B, the average performance of A over the set of all possible objective functions equals that of B, provided the set is closed under permutation. Consequently, if an algorithm excels on some functions, there must exist other functions on which it performs worse than random search.

No free lunch in machine learning

A related result applies to supervised learning: averaged over all possible target functions, every learning algorithm has the same expected off-training-set error. This is used to argue that good generalisation depends on matching an algorithm's inductive bias to the structure of the actual problem, and that no learner is universally best.

Interpretation

The theorems are sometimes misread as implying that algorithm choice does not matter. In practice, real-world problems are not drawn uniformly from all possible problems, so assumptions about problem structure — which the theorem shows are unavoidable — are exactly what make some algorithms better than others in practice.
