Cogency

In logic, an argument is cogent if it is an inductively strong argument with all true premises. Cogency is the inductive analogue of soundness in deductive logic: a sound deductive argument is valid and has true premises (guaranteeing a true conclusion), whereas a cogent inductive argument is strong and has true premises, making its conclusion probable rather than certain. An argument that is inductively strong but has one or more false premises is called uncogent.

Cogency weighs true premises against a probable conclusion.

Strength and truth

Inductive strength is a matter of degree: premises make a conclusion more or less probable. For example, "Almost all birds can fly; Tweety is a bird; therefore Tweety can probably fly" is strong, and if its premises are true it is cogent — even though the conclusion could be false if Tweety happens to be a penguin. Unlike validity, strength can be gained or lost as premises are added, a property known as defeasibility. Evaluating cogency therefore requires both assessing the inferential link and verifying the factual truth of the premises.

Related concepts

Cogency applies only to inductive arguments; inductive arguments that are weak are neither cogent nor uncogent in the strict scheme but simply weak. The terminology is used prominently in introductory logic textbooks, notably Patrick Hurley's A Concise Introduction to Logic. Related notions include enumerative induction, statistical syllogism, and arguments from analogy and authority, each of which can be cogent when strong and factually grounded.
