Web crawler

A web crawler, sometimes called a spider or spiderbot, is an internet bot that systematically browses the World Wide Web. Web crawlers are usually operated by search engines for the purpose of web indexing (web spidering) — downloading and storing web content so that it can be searched quickly. Crawlers can also be used for data mining, web archiving, price monitoring, and other automated tasks.

Overview

A web crawler starts with a list of URLs to visit, called the seeds. As it visits each URL, it identifies all the hyperlinks in the page and adds them to the list of URLs to visit, called the crawl frontier. URLs from the frontier are recursively visited according to a set of policies that govern which pages are fetched, in what order, and how often, as well as how the crawler identifies itself and avoids overloading web servers.

Policies

  • Selection policy – which pages to download, given that the web is far too large to crawl completely.
  • Re-visit policy – when to check for changes to pages already visited.
  • Politeness policy – how to avoid overloading websites; crawlers typically respect the robots exclusion protocol in robots.txt files and insert delays between requests to the same host.
  • Parallelization policy – how to coordinate distributed crawlers to avoid downloading the same page multiple times.

Architectures

Search-engine crawlers such as Google's Googlebot are large distributed systems managing a URL frontier with prioritization based on importance, freshness, and politeness constraints. Open-source crawlers include Apache Nutch and Heritrix, the latter used by the Internet Archive for web archiving.
