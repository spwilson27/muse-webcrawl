A SAT solver is a computer program that solves the Boolean satisfiability problem: given a propositional formula, usually in conjunctive normal form (CNF), it determines whether there is an assignment of truth values to the variables making the formula true, and if so produces one. SAT was the first problem shown to be NP-complete (the Cook–Levin theorem), yet modern solvers routinely decide industrial instances with millions of variables and clauses.

Algorithms

Most modern solvers implement conflict-driven clause learning (CDCL), an evolution of the DPLL backtracking algorithm. CDCL solvers repeatedly pick an unassigned variable (using heuristics such as VSIDS), propagate forced assignments by unit propagation with watched literals, and, upon reaching a conflict, analyse the implication graph to learn a new clause that prevents similar conflicts, then backjump non-chronologically. Restarts, clause deletion policies, and randomisation further improve performance.

Alternative approaches include stochastic local search methods such as WalkSAT, which flip variables to minimise unsatisfied clauses and excel on random instances but cannot prove unsatisfiability, and parallel portfolio solvers that run many strategies concurrently.

Applications

SAT solvers are workhorses of hardware and software verification (bounded model checking, equivalence checking of circuits), electronic design automation, planning and scheduling in artificial intelligence, cryptanalysis, bioinformatics, and software package dependency resolution. Extensions of the same technology address satisfiability modulo theories (SMT), MaxSAT, and quantified Boolean formulas. Annual SAT competitions and the standard DIMACS CNF input format have driven steady improvements since the 1990s; notable solvers include MiniSat, Glucose, CaDiCaL, and Kissat.
