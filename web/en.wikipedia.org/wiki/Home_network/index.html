Home network

A home network or home area network (HAN) is a type of computer network that facilitates communication among devices within the close vicinity of a home. Devices capable of participating in this network, for example, smart devices such as network printers and handheld mobile computers, often gain enhanced emergent capabilities through their ability to interact.

Structure

A typical home network centres on a router supplied by an internet service provider or purchased separately, which connects the household's local area network to the internet through a modem (or a combined gateway device). Within the home, devices connect over wired Ethernet or wirelessly via Wi-Fi standards (802.11), with power-line networking (HomePlug) and coax-based MoCA as alternatives. The router typically provides network address translation (NAT) and a DHCP server that automatically assigns private IP addresses.

Devices and uses

Home networks link personal computers, smartphones, tablets, game consoles, smart TVs, streaming devices, network-attached storage (NAS), printers, and a growing population of Internet of Things devices such as thermostats, cameras, and voice assistants. Common applications include sharing an internet connection, streaming media, file and printer sharing, online gaming, and home automation coordinated by ecosystems such as Matter/Thread, Zigbee, and Z-Wave.
