Callback (computer programming)

In computer programming, a callback is a function that is stored as data (a reference) and passed as an argument to other code, which is expected to call back (execute) that function at a specific time. This execution may be immediate in a synchronous callback, or it might happen at a later point in time in an asynchronous callback.

Uses

Callbacks are central to event-driven programming: graphical user interfaces register callbacks (event handlers) for clicks and keystrokes; libraries use them to customize sorting comparisons or filtering predicates; and asynchronous I/O frameworks invoke callbacks when operations complete. In languages with first-class functions, callbacks are ordinary function values; in others they may be function pointers, delegates or anonymous classes.

Alternatives and issues

Deeply nested asynchronous callbacks can lead to hard-to-read "callback hell", motivating alternatives such as promises/futures, async/await syntax and reactive streams. Related patterns include the observer pattern and continuation-passing style.
