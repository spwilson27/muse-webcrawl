Polymorphism (computer science)

From Wikipedia, the free encyclopedia

In programming language theory and type theory, polymorphism is the provision of a single interface to entities of different types, or the use of a single symbol to represent multiple different types. A programming language is said to exhibit polymorphism if it allows programs to be written generically, so that code can work with values of different types without depending on their exact structure. The concept derives from the work of Christopher Strachey, who in 1967 distinguished parametric and ad hoc polymorphism, and was elaborated in the type theory of the following decades.

Forms of polymorphism

Ad hoc polymorphism

Ad hoc polymorphism allows a function to behave differently depending on the type of its arguments. It is realized through function overloading (multiple definitions of the same name with different parameter types, resolved at compile time) and operator overloading. Coercion — the implicit conversion of a value to another type, such as an integer to a floating-point number — is often grouped here as "coercive polymorphism" and is generally resolved statically.

Parametric polymorphism

Parametric polymorphism (generics) allows functions and data types to be written in terms of a type parameter, behaving uniformly for all types. Examples include generic functions in ML and Haskell, templates in C++, and generics in Java and C#. In statically typed languages it enables type-safe reusable container types such as lists and maps of arbitrary element type. Hindley–Milner type inference in ML-family languages can infer the most general polymorphic type of an expression automatically.

Subtype polymorphism

Subtype (inclusion) polymorphism, the best-known form in object-oriented programming, allows a value of a subtype to be used wherever a supertype is expected. Through inheritance and dynamic dispatch (virtual methods), a call to a method on a base-class reference invokes the override defined by the object's actual class at run time. This underlies classic object-oriented design, in which an interface such as Shape can be implemented by Circle, Square, and other classes, each drawing itself.

Static and dynamic polymorphism

Polymorphism may be resolved at compile time (static/early binding — overloading, templates, generics) or at run time (dynamic/late binding — virtual dispatch, duck typing in dynamic languages). Strachey's original classification is related to the influential taxonomy by Luca Cardelli and Peter Wegner (1985), which divides polymorphism into universal (parametric and inclusion) and ad hoc (overloading and coercion) forms.
