Loader (computing)

In computing, a loader is the part of an operating system that is responsible for loading programs and libraries. It takes an executable file from disk, prepares it in main memory, and starts its execution. Loading is the final stage of bringing a program to life, following compiling, assembling, and linking.

Tasks

A loader typically performs activities such as reading the executable image, allocating memory for it, copying its code and initialised data into that memory, performing relocation (adjusting addresses that depend on where the program is placed), resolving references to shared libraries, and finally transferring control to the program's entry point. In systems with virtual memory, much of the actual fetching of pages may be deferred until the pages are first used (demand paging).

Dynamic loading

Many systems distinguish the initial program loader from the dynamic loader (or dynamic linker), the component that loads shared libraries at run time, whether at program start-up or on request through calls such as dlopen. Relocating loaders, common in early computing and in embedded systems, load a program at an address determined at load time rather than a fixed address chosen by the linker.

Related components

The linker combines object files and libraries ahead of time and may perform much of the relocation statically, leaving a smaller job for the loader. A bootstrap loader (or bootloader) is a special loader that loads the operating system itself when a machine starts.
