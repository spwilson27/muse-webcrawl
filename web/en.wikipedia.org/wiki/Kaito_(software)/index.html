Kaito (software)

Kaito
Developer: Microsoft / open-source community
Type: Kubernetes AI toolchain operator
Platform: Kubernetes (AKS)
License: MIT

Kaito (Kubernetes AI Toolchain Operator) is an open-source operator that automates the deployment of AI inference models on Kubernetes clusters, particularly Azure Kubernetes Service (AKS). It simplifies provisioning GPU nodes and deploying open-source large language models as managed workspaces.

Features

Kaito introduces a Workspace custom resource describing a model deployment; the operator automatically provisions suitable GPU machines, applies model presets, and runs the inference service, typically using container images with popular open models and standard endpoints. Its GPU provisioner builds on Karpenter-based autoscaling, and later releases added features such as rag-engine support and fine-tuning (LoRA) workspaces.

Development

The project was released by Microsoft in 2023 and is developed publicly on GitHub under the MIT licence, with contributions from the cloud-native community.
