Page description language

In digital printing, a page description language (PDL) is a computer language that describes the appearance of a printed page at a higher level than an actual output bitmap. A printer or raster image processor interprets the description and renders it at the device's resolution, making the description largely device-independent.

Examples

The best-known page description language is Adobe's PostScript, introduced in 1984, a full programming language for describing text, vector graphics, and images. Its successor format, PDF, is based on the PostScript imaging model but is a structured data format rather than a programming language. Hewlett-Packard's Printer Command Language (PCL) is another widely used example, generally lower-level and more closely tied to printer features.

Characteristics

Page description languages specify fonts, glyph placement, vector shapes, colours, and sampled images, and handle scaling and transformation so that the same description prints correctly on devices of very different resolutions.
