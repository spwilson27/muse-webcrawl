Currying

Currying
Currying transforms f(x, y) into a chain of single-argument functions

Originated byMoses Schönfinkel (1920s); also Gottlob Frege
FieldFunctional programming, mathematical logic
InverseUncurrying

In mathematics and computer science, currying is the technique of translating a function that takes multiple arguments into a sequence of functions each taking a single argument. A function f(x, y) is curried into a function that takes x and returns another function that takes y and produces f's result:

curry(f)(x)(y) = f(x, y)

The term honours the logician Haskell Curry, in whose work the transformation was prominent, although it was introduced earlier by Moses Schönfinkel (building on ideas of Gottlob Frege); some authors accordingly call it Schönfinkelisation. The inverse transformation, combining a chain of unary functions into one multi-argument function, is called uncurrying.

In programming

In functional programming languages such as Haskell (named after Curry, and in which every function formally takes exactly one argument), ML and OCaml, functions are curried by default: writing add x y = x + y defines add as a function returning a function. Currying enables partial application — supplying fewer arguments than a function expects to obtain a specialised function, as in add1 = add 1. Languages such as JavaScript, Scala and Python support currying through libraries or manual transformation, and it is used in point-free style, combinators and function composition pipelines.

Mathematical significance

Currying underlies the correspondence between multi-argument functions and higher-order functions in the lambda calculus, where all functions are unary by construction. In category theory it appears as the exponential-object adjunction (the "curry–Howard" circle of ideas also connects it to implication in logic: a proof of A ∧ B → C corresponds to a proof of A → (B → C)). In type-theoretic notation the correspondence is visible directly: (A × B → C) ≅ (A → B → C).
