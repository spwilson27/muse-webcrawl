Data dredging

Data dredging (also known as data snooping or p-hacking) is the misuse of data analysis to find patterns in data that can be presented as statistically significant, when in fact there is no underlying effect. It typically involves testing many hypotheses on a single dataset and reporting only those comparisons that reach significance.

Mechanism

Statistical tests conventionally accept a 5% significance level, meaning a true null hypothesis will be wrongly rejected about one time in twenty. A researcher who runs many tests — across variables, subgroups, time windows or model specifications — is therefore almost guaranteed some "significant" but spurious results. If only those are published, the literature becomes distorted, contributing to the replication crisis in fields such as psychology and medicine.

Related practices

Data dredging is closely related to HARKing (hypothesising after the results are known), selective reporting and the multiple comparisons problem. Popular illustrations include spurious correlations, such as the near-perfect correlation once noted between per-capita cheese consumption and deaths by bedsheet entanglement.

Countermeasures

Recommended remedies include preregistration of hypotheses and analysis plans, corrections for multiple comparisons such as the Bonferroni correction, replication on independent data, and reporting all tests performed rather than only significant ones.
