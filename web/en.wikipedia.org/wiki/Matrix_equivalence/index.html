Matrix equivalence

From Wikipedia, the free encyclopedia

In linear algebra, two rectangular matrices are equivalent if one can be transformed into the other by a sequence of elementary row and column operations. Equivalently, an m × n matrix A and an m × n matrix B are equivalent if there exist invertible matrices P (of size m × m) and Q (of size n × n) such that B = PAQ.

Meaning

Matrix equivalence is exactly the relation of representing the same linear map under (independent) changes of basis in the domain and codomain: P corresponds to a change of basis in the codomain and Q to a change of basis in the domain. It is an equivalence relation on the set of m × n matrices.

Canonical form and rank

Two matrices are equivalent if and only if they have the same rank. Consequently, every m × n matrix of rank r is equivalent to the block matrix with an r × r identity block in the upper-left corner and zeros elsewhere; this is the canonical (normal) form under equivalence, reached by reducing the matrix with row and column operations. It follows that there are exactly min(m, n) + 1 equivalence classes of m × n matrices, one for each possible rank.

Comparison with other relations

Equivalence is a coarser relation than matrix similarity (which applies to square matrices and requires B = P−1AP, the same change of basis on both sides, and preserves eigenvalues) and also coarser than congruence (B = PTAP). Over rings other than fields, the analogous classification is given by the Smith normal form, in which the diagonal invariant factors refine the role played by rank alone.
