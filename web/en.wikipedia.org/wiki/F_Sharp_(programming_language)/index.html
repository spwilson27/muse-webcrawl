F# (programming language)

F# (pronounced "F sharp") is a functional-first, multi-paradigm programming language for the .NET platform, developed by Microsoft Research under Don Syme, drawing on OCaml. It supports functional, imperative and object-oriented programming, strong static typing and type inference.

F#
Designer: Don Syme, Microsoft Research
First appeared: 2005
Paradigm: Functional, multi-paradigm
Platform: .NET, cross-platform

Features

Distinctive features include type providers for data access, units of measure, pattern matching, asynchronous workflows and computation expressions. F# compiles to .NET assemblies, interoperates with C#, and is open source under the F# Software Foundation community.

Uses

Used in finance, data science, web services (e.g. SAFE stack, Fable to JavaScript) and analytics where correctness and concise modelling matter.
