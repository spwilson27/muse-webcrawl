Function composition

In mathematics, function composition is an operation that takes two functions f and g, and produces a function h = g ∘ f such that h(x) = g(f(x)). In this operation, the function g is applied to the result of applying the function f to x.


Composition of functions

Properties

Composition is associative: f ∘ (g ∘ h) = (f ∘ g) ∘ h whenever all compositions are defined. It is not, in general, commutative: g ∘ f need not equal f ∘ g. The identity function acts as an identity element for composition. Composition of bijective functions is bijective, and the inverse of a composition reverses the order: (g ∘ f)−1 = f−1 ∘ g−1.

Notation

The composition of f and g, with f applied first, is written g ∘ f, read "g of f" or "g after f". Repeated composition of a function with itself is denoted by superscripts, fn, and underlies the iteration studied in dynamical systems.

In computer science

In functional programming, composition is a fundamental combinator for building programs from smaller functions, and point-free style exploits it heavily. In category theory, composition of morphisms generalises the operation, with functions and sets forming the category Set.
