Container format

A container format (or wrapper format) is a file format whose specification describes how different streams of data — typically encoded by codecs — are stored together in a single computer file, along with metadata. Containers are common for multimedia (video and audio) but also exist for documents and other composite data.

Multimedia containers

  • MP4 (MPEG-4 Part 14) — ubiquitous for web and mobile video.
  • Matroska (.mkv) — open format supporting multiple audio/subtitle tracks and chapters.
  • AVI — Microsoft format from 1992.
  • WebM — royalty-free format optimized for HTML5.
  • MOV — Apple QuickTime format.

Containers versus codecs

A container does not itself compress data: an MP4 file, for instance, may hold video encoded as H.264, H.265 or AV1 and audio as AAC. Playback requires support for both the container and the codecs inside it.

Other containers

Archive formats (ZIP, tar), disc images (ISO), and office documents (OOXML, ODF) are also container formats bundling multiple elements.
