Big Omega function

In number theory, the Big Omega function, written Ω(n), counts the number of prime factors of a natural number n, counted with multiplicity. It is distinguished from the little omega function ω(n), which counts only distinct prime factors. For example, 12 = 2 × 2 × 3, so Ω(12) = 3 whereas ω(12) = 2.

Properties

Ω is a completely additive arithmetic function: Ω(mn) = Ω(m) + Ω(n) for all positive integers m, n, and Ω(pk) = k for a prime p. By convention Ω(1) = 0. Its average order is log log n: in particular, the Hardy–Ramanujan theorem states that Ω(n) has normal order log log n, i.e. for almost all integers Ω(n) is close to log log n.

Related concepts

An integer is called k-almost prime if Ω(n) = k; thus primes are 1-almost primes and semiprimes are 2-almost primes. The function is connected to the Liouville function by λ(n) = (−1)Ω(n). The Dirichlet series for Ω involves the Riemann zeta function and the prime zeta function.
