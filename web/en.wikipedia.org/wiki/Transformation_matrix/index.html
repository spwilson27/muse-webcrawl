Transformation matrix

A linear map represented by a 2×2 matrix acting on a square.

In linear algebra, a transformation matrix is a matrix that represents a linear transformation. If T is a linear transformation mapping Rn to Rm and x is a column vector with n entries, then there is an m × n matrix A such that

T(x) = Ax

Such matrices make it possible to compute the effect of a transformation on any vector by simple matrix multiplication, and to compose transformations by multiplying their matrices. For this reason, transformation matrices are the mathematical backbone of computer graphics, robotics and computer vision.

Examples in two dimensions

A rotation by angle θ counterclockwise about the origin is represented by

R(θ) = [cos θ, −sin θ; sin θ, cos θ]

Other standard examples include reflections, scalings, shears and projections. In homogeneous coordinates, translations can also be written as matrices, allowing rotation, scaling and translation to be combined into a single 3×3 (in 2D) or 4×4 (in 3D) affine transformation matrix — the workhorse of 3D graphics pipelines such as OpenGL.

Finding a matrix for a transformation

The columns of the transformation matrix are the images of the standard basis vectors under the transformation. Changing the basis in which a transformation is expressed amounts to conjugating its matrix by a change-of-basis matrix, which leads to the theory of similar matrices.

References: Strang, G., Introduction to Linear Algebra; Anton, H., Elementary Linear Algebra.
