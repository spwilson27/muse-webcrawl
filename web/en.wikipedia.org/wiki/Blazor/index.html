Blazor

Developer: Microsoft
Initial release: 2018
Written in: C#
Platform: .NET / WebAssembly
License: Apache License 2.0

Blazor is a free and open-source web framework developed by Microsoft that enables developers to build interactive web user interfaces using C# instead of JavaScript. Its name combines "Browser" and "Razor", the ASP.NET markup syntax.

Hosting models

Blazor WebAssembly runs C# code directly in the browser on a WebAssembly-based .NET runtime, while Blazor Server executes the application on the server and updates the UI over a SignalR connection. Later versions of .NET unify these models and add static server-side rendering.

Features

Blazor uses a component-based architecture with reusable .razor files combining HTML and C#. Components can call JavaScript through an interoperability layer when needed.
