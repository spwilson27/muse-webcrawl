Vector database

A vector database, vector store, or vector search engine is a database that can store vectors (fixed-length lists of numbers) along with other data items. Vector databases typically implement one or more approximate nearest neighbor (ANN) algorithms, so that one can search the database with a query vector to retrieve the closest matching database records.

Vectors are mathematical representations of data in a high-dimensional space. In this space, each dimension corresponds to a feature of the data, with the number of dimensions ranging from a few hundred to tens of thousands, depending on the complexity of the data being represented. A data point's position in this space represents its characteristics. Words, phrases, or entire documents, as well as images, audio, and other data, can be vectorised by machine learning models into embeddings.

Applications

Vector databases are used to build semantic search, recommendation systems, and retrieval-augmented generation (RAG) pipelines for large language models, in which documents are stored as embeddings and the most semantically similar passages are supplied to the model as context. Other applications include image and video similarity search, fraud detection, and molecular similarity in drug discovery.

Indexing algorithms

Because exact nearest-neighbour search in high dimensions is expensive, vector databases rely on approximate methods, including:

  • HNSW (Hierarchical Navigable Small World) — graph-based indexes offering high recall at low latency.
  • IVF (Inverted File Index) — clusters vectors and searches only the nearest clusters.
  • Product quantization — compresses vectors into short codes to save memory.
  • Locality-sensitive hashing (LSH) — hashes similar vectors into the same buckets.

Similarity measures

Common distance and similarity functions include cosine similarity, Euclidean (L2) distance, and inner product. The choice of metric should usually match the one used when training the embedding model.

Examples

Dedicated vector databases include Milvus, Pinecone, Weaviate, Qdrant, and Chroma. General-purpose systems have also added vector search, for example PostgreSQL with the pgvector extension, and libraries such as Faiss and Annoy provide in-process indexing.
