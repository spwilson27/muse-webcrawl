Dalvik (software)

Developer: Dan Bornstein, Google
Written in: C, C++
Platform: Android
Replaced by: Android Runtime (ART)

Dalvik was a discontinued process virtual machine in Google's Android operating system that executed applications written for Android. It ran programs compiled into Dalvik Executable (.dex) bytecode, a register-based format optimised for devices with limited memory and processor power.

Design

Unlike stack-based Java virtual machines, Dalvik used a register-based architecture, and Java class files were converted into .dex files by the dx tool. Each Android app ran in its own process with its own Dalvik instance, isolating applications from one another. Later versions added a just-in-time (JIT) compiler.

Replacement

Dalvik was succeeded by Android Runtime (ART), previewed in Android 4.4 KitKat (2013) and made the sole runtime in Android 5.0 Lollipop (2014), which moved compilation to install time (ahead-of-time) for better performance. Dalvik was named after the Icelandic fishing village of Dalvík, the ancestral home town of its author Dan Bornstein's family.
