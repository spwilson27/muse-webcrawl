Canvas element

Canvas element
HTML element<canvas>
Introduced byApple (2004)
Standardised inHTML5 / WHATWG HTML
APIsCanvas 2D, WebGL, WebGPU

The canvas element is part of HTML5 and allows for dynamic, scriptable rendering of 2D shapes and bitmap images. It is a low-level, procedural model that updates a bitmap. It is an HTML element — written <canvas> — that creates a fixed-size drawing surface exposing one or more rendering contexts.

History

Canvas was initially introduced by Apple in 2004 for use inside its own Mac OS X WebKit component, powering applications such as Dashboard widgets and the Safari browser. It drew criticism at the time for departing from vendor-neutral standards work, but was subsequently adopted by Mozilla and Opera and standardised by the WHATWG and W3C as part of HTML5.

Usage

JavaScript accesses the canvas through its rendering contexts: the widely supported Canvas 2D API provides paths, shapes, text, gradients, and image drawing; WebGL provides hardware-accelerated 3D graphics based on OpenGL ES; and the newer WebGPU API offers a modern graphics and compute interface. Canvas is used for browser games, charts, photo editors, animations, and data visualisation.

Unlike SVG, which retains a scene graph of vector objects, canvas is immediate-mode: once pixels are drawn they cannot be individually addressed as objects, which makes canvas efficient for many moving elements but less convenient for resolution-independent graphics.
