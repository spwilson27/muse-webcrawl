High-Level Shader Language

The High-Level Shader Language or High-Level Shading Language (HLSL) is a proprietary shading language developed by Microsoft for use with the Direct3D API, analogous to the GLSL language used with OpenGL. It first appeared with DirectX 9 and Shader Model 2 in 2002.

Overview

HLSL uses a C-like syntax with built-in vector and matrix types (such as float4 and float4x4), swizzling operations, and semantics that bind shader inputs and outputs to pipeline stages. Programs are written for vertex, pixel, geometry, hull, domain and compute stages. The traditional fxc compiler was succeeded by the open-source DXC compiler based on LLVM/Clang, which supports Shader Model 6 and can also emit SPIR-V for use with Vulkan.

Comparison with GLSL

Unlike GLSL, HLSL treats matrices as row-major by default and shares a unified model across shader stages. Microsoft's language became the dominant shading language for Windows and Xbox development, and cross-platform engines routinely translate HLSL to other targets.
