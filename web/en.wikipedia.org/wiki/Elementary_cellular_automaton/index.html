Elementary cellular automaton

From Wikipedia, the free encyclopedia

An elementary cellular automaton is a one-dimensional cellular automaton in which each cell has two possible states (0 or 1) and the next state of a cell depends on its current state and the states of its two immediate neighbours. There are 28 = 256 such automata, conventionally numbered from 0 to 255 by the Wolfram code, in which the rule number's binary digits give the output for each of the eight possible neighbourhoods.

Elementary cellular automata were studied extensively by Stephen Wolfram in the 1980s and popularised in his book A New Kind of Science (2002). Despite their simplicity, some rules produce surprisingly complex behaviour.

Notable rules

  • Rule 30 produces chaotic, aperiodic patterns and has been used as a random number generator.
  • Rule 90 generates the Sierpiński triangle fractal from a single seed cell.
  • Rule 110 was proved by Matthew Cook to be capable of universal computation.
  • Rule 184 models traffic flow and particle deposition.

Classification

Wolfram grouped the rules into four classes, from Class 1 (rapidly settling to uniformity) through Class 2 (repetitive structures) and Class 3 (chaotic patterns) to Class 4 (complex, localised structures capable of supporting computation), with Rule 110 the canonical Class 4 example.
