Round-robin DNS

Round-robin DNS is a simple method of load distribution in which a domain name is associated with multiple IP addresses, and the DNS server rotates the order of the addresses in its responses so that successive clients are directed to different servers.

How it works

A zone file lists several A or AAAA records for the same name. Each query receives the full list but in a rotated order; most resolvers and clients use the first address. Short TTL values reduce caching effects so rotation takes hold sooner.

Limitations

Round-robin DNS does not check server health, does not guarantee even distribution (because of resolver caching), and provides no session persistence. It has largely been supplemented by dedicated load balancers, anycast and content delivery networks, but remains cheap and widely supported for basic load sharing and geographic distribution when combined with other techniques.
