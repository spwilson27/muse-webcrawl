Scratch is a high-level, block-based visual programming language and website aimed primarily at children and beginning programmers. Users create projects by dragging together colourful code blocks — an approach designed to eliminate syntax errors and make programming concepts tangible — in a development environment populated by sprites on a stage. Scratch was developed by the Lifelong Kindergarten group at the MIT Media Lab, led by Mitchel Resnick, drawing on earlier work on Logo. It is one of the world's most widely used introductory programming languages, with over one hundred million registered users on its community website.

History

Development began in 2003; Scratch 1.0 was released in 2007. Scratch 2.0 (2013) moved the editor into the web browser and added features such as custom blocks and cloning. Scratch 3.0, released in January 2019 and rewritten in HTML5/JavaScript, runs on desktops, tablets, and phones, and added extension blocks for hardware such as micro:bit and LEGO robotics kits. In 2019 stewardship of Scratch passed from MIT to the non-profit Scratch Foundation.

Design and use

Programs are built from blocks organised by category — motion, looks, sound, events, control, sensing, operators, and variables — which snap together only in syntactically valid ways. Projects centre on sprites with costumes and sounds, coordinated by event scripts such as "when green flag clicked". The accompanying online community lets users publish projects, remix others' work (every shared project can be seen and modified), and comment — a design intended to teach through creative making and peer learning. Scratch is used worldwide in schools, coding clubs such as Code Club and CoderDojo, and museums, and influenced later block languages and environments, including Google's Blockly library and Microsoft's MakeCode. A simplified version, ScratchJr, targets children ages 5–7.
