Count–min sketch

[Image placeholder: count-min sketch structure]

The count–min sketch is a probabilistic data structure, introduced by Graham Cormode and S. Muthukrishnan in 2003–2005, that serves as a frequency table of events in a stream of data. It uses sub-linear space to estimate the frequency of individual items, trading a small, one-sided overestimation error for very large savings in memory compared with an exact counter array.

The structure is a two-dimensional array of counters of width w and depth d, together with d independent hash functions. To record an occurrence of an item, the item is hashed once by each function and the corresponding counter in each row is incremented. To estimate an item's frequency, the minimum of its d counters is returned — hence the name. Hash collisions can only inflate counters, so the estimate never underestimates the true count, and with w ≈ e/ε and d ≈ ln(1/δ) the estimate exceeds the true frequency by more than ε times the total stream length with probability at most δ.

Applications

Count–min sketches are used for finding heavy hitters in data streams, approximate query processing in databases, network traffic measurement, natural language processing (for approximate word-frequency counts), and in systems such as Redis and Apache Spark, which provide sketch implementations for high-volume counting tasks.
