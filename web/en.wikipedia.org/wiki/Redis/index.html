Redis (Remote Dictionary Server) is an open-source in-memory data structure store used as a distributed, in-memory key–value database, cache and message broker, with optional durability. Redis supports different kinds of abstract data structures, such as strings, lists, maps, sets, sorted sets, hyperloglogs, bitmaps, and streams.

History

Redis was created by Salvatore Sanfilippo starting in 2009, originally to scale his web analytics startup. It was later sponsored by VMware and Pivotal Software, and the company Redis Labs (now Redis Ltd.) was founded around it. In 2024 the project adopted a dual-licence model, prompting the Linux Foundation-backed fork Valkey.

Features

Redis keeps its entire dataset in memory, achieving very high throughput and sub-millisecond latency, and can persist data to disk through snapshotting (RDB) or an append-only file (AOF). It supports replication, clustering, transactions, pub/sub messaging, and scripting.
