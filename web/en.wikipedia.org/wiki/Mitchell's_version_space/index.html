Mitchell's version space

In machine learning, the version space, introduced by Tom Mitchell in the late 1970s, is the set of all hypotheses in a hypothesis space that are consistent with a given set of training examples. It is a central concept in Mitchell's work on concept learning.

Definition

A hypothesis is consistent with a set of training examples if it correctly classifies every example. The version space is the subset of the hypothesis space containing every consistent hypothesis — no more and no fewer.

Boundary representation

Because the version space can be very large, it is usually represented implicitly by its boundary sets: the specific boundary (S), containing the most specific consistent hypotheses, and the general boundary (G), containing the most general consistent hypotheses. Every hypothesis between these boundaries (in the generality partial ordering) is in the version space.

Candidate elimination algorithm

Mitchell's candidate elimination algorithm incrementally maintains the S and G boundary sets as training examples arrive. Positive examples cause the specific boundary to be generalized, while negative examples cause the general boundary to be specialized. Learning succeeds when the version space converges to a single hypothesis, and fails (collapses) when no hypothesis is consistent with the data.
