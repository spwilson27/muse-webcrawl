Propositional calculus

From Wikipedia, the free encyclopedia
[Image: A truth table for common logical connectives]

Propositional calculus (also called propositional logic, statement logic, or sentential calculus) is the branch of logic concerned with propositions — statements that are true or false — and the logical connectives that combine them, such as AND, OR, NOT, and implication.

Unlike predicate (first-order) logic, propositional calculus does not analyse the internal structure of propositions: each statement is treated as an indivisible atom. Its central decision problem — satisfiability — is mechanical: a truth table with 2^n rows settles any formula with n variables, though for large n this is computationally expensive (the SAT problem is NP-complete).

Syntax and semantics

Formulas are built from propositional variables using connectives: negation (¬), conjunction (∧), disjunction (∨), implication (→) and biconditional (↔). A valuation assigns each variable a truth value, and the truth of a compound formula is computed from the truth tables of its connectives.

A formula is a tautology if it is true under every valuation, satisfiable if true under some valuation, and a contradiction if true under none. Two formulas are logically equivalent when they agree on every valuation.

Proof systems

Propositional arguments can be formalised in several equivalent systems: Hilbert-style axiom systems, natural deduction (Gentzen), and truth tables. The calculus is sound and complete: every tautology is provable, and everything provable is a tautology.
