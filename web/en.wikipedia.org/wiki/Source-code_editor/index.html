Source-code editor

A source-code editor is a text editor program designed specifically for editing the source code of computer programs. It may be a standalone application or built into an integrated development environment (IDE) or web browser. Source-code editors are the most fundamental programming tool, as the fundamental job of programmers is to write and edit code.

Features

Source-code editors typically include features designed to simplify and speed up the typing of source code, such as:

  • Syntax highlighting – displaying keywords, comments, and strings in distinct colours and fonts.
  • Autocomplete – suggesting identifiers and language constructs as the user types.
  • Indentation support – automatic indentation and bracket matching.
  • Search and replace across files, often with regular expressions.
  • Line numbering and error/warning markers tied to compiler output.

Some editors add structural views such as code folding and minimaps, and many are extensible through plug-ins.

Notable examples

Widely used editors include Visual Studio Code, Sublime Text, Vim, Emacs, Notepad++, Atom, and the editor components of IDEs such as IntelliJ IDEA, Eclipse, and Xcode. Historic editors influential on the genre include vi (1976) and GNU Emacs (1985), both still in active use, celebrated for their keyboard-driven efficiency and extensibility.
