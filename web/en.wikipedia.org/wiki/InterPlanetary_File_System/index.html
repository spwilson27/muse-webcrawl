The InterPlanetary File System (IPFS) is a protocol, hypermedia and file sharing peer-to-peer network for storing and sharing data in a distributed file system. By using content addressing, IPFS uniquely identifies each file in a global namespace. IPFS is an open-source project developed since 2015 by Protocol Labs with help from the open-source community.

Design

IPFS allows users to host and receive content in a manner similar to BitTorrent. Files are split into blocks organised as a Merkle directed acyclic graph (DAG), and each object is identified by a content identifier (CID) derived from a cryptographic hash of its content. A distributed hash table (based on Kademlia) locates peers holding requested blocks. Because addresses describe what content is rather than where it is, links remain valid regardless of which host serves the data.

History

IPFS was created by Juan Benet, who published the design in 2014; the alpha release followed in February 2015. The related incentive layer Filecoin launched its mainnet in 2020. IPFS is used to distribute Wikipedia mirrors, host NFT metadata, and serve content in regions where websites are blocked.

Use cases and criticism

Supporters cite censorship resistance and deduplication; critics note that unpopular content can disappear when no node pins it, and that gateways reintroduce points of centralisation.
