scrypt

scrypt
Type: Password-based key derivation function
Designer: Colin Percival
First published: 2009

scrypt (pronounced "ess crypt") is a password-based key derivation function created by Colin Percival in 2009. It was designed to be deliberately expensive in both time and memory — a so-called memory-hard function — so that large-scale custom hardware attacks using ASICs become costly, because an attacker must equip each brute-force circuit with substantial fast memory.

Design

scrypt builds on the PBKDF2 construction using HMAC-SHA256 and adds the ROMix mixing function, which fills a large array with pseudorandom blocks and reads them in a data-dependent order. Its cost parameters (N, r, p) allow the CPU time and memory requirements to be tuned. scrypt is used in the Tarsnap backup service and as the proof-of-work function of some cryptocurrencies, notably Litecoin, and it was standardised in RFC 7914.
