Windows Shell

Not to be confused with Windows PowerShell or Command Prompt.

Windows Shell
Other names: Explorer
Developer: Microsoft
Type: Graphical shell
First released: 24 August 1995 (Windows 95)
Main executable: explorer.exe

The Windows shell is the graphical user interface of Microsoft Windows, centred on the Windows Explorer process (explorer.exe). It provides the desktop, the taskbar, the Start menu, the system tray (notification area), window switching such as Alt+Tab, and the file-management interface through which users browse folders, launch applications and manipulate files and shortcuts.

History

Early versions of Windows relied on the MS-DOS Executive and later the Program Manager and File Manager of Windows 3.x. The modern shell debuted in the Cairo-influenced interface of Windows 95, combining the desktop metaphor with the Start button and taskbar, a design that proved influential across desktop computing. The Windows Desktop Update shipped with Internet Explorer 4 brought features of the shell to Windows 95 and NT 4.0, including the Quick Launch toolbar and Active Desktop.

Subsequent releases refined the shell: Windows XP added a two-column Start menu and grouped taskbar buttons; Windows Vista introduced instant search and the Aero interface; Windows 7 added taskbar pinning and jump lists; Windows 8 controversially replaced the Start menu with the Start screen before Windows 10 restored a combined Start menu.

Components

Key components include the desktop and its icons, the taskbar with its Start button and notification area, the file explorer windows with navigation panes and ribbons or command bars, context menus, and the shell namespace, which unifies ordinary folders with virtual locations such as Control Panel, Libraries and network places. The shell is extensible through shell extensions written against COM, allowing third-party software to add context-menu handlers, thumbnail providers and namespace extensions — a flexibility that also made it a target for malware and poorly behaved add-ons.

Alternatives

Although explorer.exe is the default, Windows allows the shell to be replaced, and alternate shells have been developed for kiosk systems, accessibility or customization.
