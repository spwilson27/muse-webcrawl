Grid computing is the use of widely distributed computer resources to reach a common goal. A computing grid can be thought of as a distributed system with non-interactive workloads involving many files; it is distinguished from conventional high-performance computing systems such as computer clusters by its looser coupling, heterogeneity and geographic dispersion. The term was coined in the mid-1990s by analogy with the electric power grid, which delivers a utility service from distributed generation sources.

Overview

Grids are built from middleware — software that coordinates resources owned by different administrative domains and presents them to users as a single virtual system. The Globus Toolkit, developed by Ian Foster, Carl Kesselman and others, became a de facto standard, and Foster's "Three-Point Checklist" defined a grid as a system that coordinates resources not subject to centralised control, uses standard, open, general-purpose protocols, and delivers nontrivial quality of service.

Applications

The largest grid built for a single application is the Worldwide LHC Computing Grid (WLCG), which distributes the data of CERN's Large Hadron Collider to hundreds of computing centres worldwide. Other grids support drug discovery, climate modelling and earth observation. Volunteer computing projects such as SETI@home and the BOINC platform apply similar ideas using idle home computers.

Relationship to cloud computing

Grid computing's emphasis on sharing resources across organisations contrasted with the commercial, centrally provisioned model of cloud computing that rose in the late 2000s; many grid technologies and communities migrated into cloud and later utility computing frameworks, while large scientific grids continue to operate.
