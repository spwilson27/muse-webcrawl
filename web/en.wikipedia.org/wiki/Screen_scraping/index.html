Screen scraping

Screen scraping is a technique in which a computer program extracts data from the display output of another program. The key element that distinguishes screen scraping from regular parsing is that the output being scraped is intended for display to a human user, rather than as input to another program.

History and uses

The term originated with programs that read data from the character-based screens of mainframe terminals, allowing legacy systems to be integrated with newer applications in the absence of an application programming interface (API). Screen scraping has been used for data migration, system integration, terminal emulation and automated testing.

Web scraping

A related modern practice is web scraping, in which programs parse the HTML or other markup served to web browsers. Unlike terminal screen scraping, web scraping generally analyses the underlying document structure rather than rendered pixels, though some techniques render pages fully, including JavaScript execution, before extraction. The legality and terms-of-service status of web scraping have been litigated in several jurisdictions.

Techniques

Methods include reading terminal data streams, optical character recognition of bitmap displays, parsing document object models, and using accessibility or GUI automation interfaces.
