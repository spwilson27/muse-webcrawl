LZ4 (compression algorithm)

LZ4 is a lossless data compression algorithm that is focused on compression and decompression speed. It belongs to the LZ77 family of byte-oriented compression schemes. The algorithm was developed by Yann Collet and is distributed under a BSD license.

Design

LZ4 emphasizes speed over compression ratio, achieving compression speeds of several hundred megabytes per second per core and even faster decompression. It represents data as sequences of literal runs and matches, using a hash table to find repeated sequences of bytes.

LZ4 Frame Format

The LZ4 frame format (LZ4F) adds features needed for general-purpose use, including content checksums, optional block independence, and frame metadata. Other variants include the higher-compression LZ4HC mode.

Usage

LZ4 is widely used in databases, file systems such as ZFS, and big-data platforms where low-overhead compression of high-throughput data streams is required.
