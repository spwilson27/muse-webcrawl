Coppersmith–Winograd algorithm

The Coppersmith–Winograd algorithm, created by Don Coppersmith and Shmuel Winograd in 1987, is the square matrix multiplication algorithm with the second-best known asymptotic complexity (after the laser method extension by Alman, Duan, Vassilevska Williams, Xu, Xu, and Zhou). It can multiply two n × n matrices in O(n2.375477) time. This is an improvement over the naive O(n3) time algorithm and the Strassen algorithm's O(n2.807).

Asymptotic exponent

The exponent ω of matrix multiplication is the infimum of all constants such that two n × n matrices can be multiplied in O(nω) time. Subsequent work building on the Coppersmith–Winograd design, notably by Stothers, Vassilevska Williams, Le Gall, and later researchers, progressively lowered the bound on ω; algorithms of this family are called "galactic algorithms" because their enormous constant factors make them impractical for realistic input sizes.

Method

Like Strassen's algorithm, Coppersmith–Winograd is a divide and conquer algorithm: it recursively partitions matrices into blocks and reduces one multiplication of blocks through clever linear combinations found via the analysis of tensor rank. Its improvements come from a more intricate recursive tensor construction analysed using the laser method.
