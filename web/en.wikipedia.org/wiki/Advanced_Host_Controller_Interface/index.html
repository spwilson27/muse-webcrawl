Advanced Host Controller Interface

AbbreviationAHCI
TypeHost controller interface specification
Defined byIntel
ForSerial ATA (SATA) devices

The Advanced Host Controller Interface (AHCI) is a technical standard defined by Intel that specifies the operation of Serial ATA (SATA) host controllers in a non-implementation-specific manner. It gives operating systems a standard interface for detecting, configuring, and programming SATA devices, replacing the legacy IDE compatibility modes.

Features

AHCI exposes capabilities of modern SATA controllers that IDE emulation could not use, notably Native Command Queuing (NCQ), which lets drives reorder commands to improve performance, and hot swapping of drives. AHCI supports all SATA speeds and up to 32 devices through port multipliers. Operating systems with AHCI support include modern versions of Windows, macOS, Linux, and the BSD family.

Modes and successors

Many motherboards offer a choice between AHCI and IDE (legacy) mode, and switching modes after an operating system is installed can render it unbootable unless the AHCI driver is enabled first. AHCI was designed for spinning disks and the SATA bus; for solid-state drives on PCIe, it has been largely superseded by NVMe, which offers much lower latency and far deeper command queues.
