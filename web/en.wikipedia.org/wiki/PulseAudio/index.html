PulseAudio

PulseAudio is a network-capable sound server system for POSIX operating systems, created by Lennart Poettering and released under free and open-source licences. It acts as an intermediary between applications and audio hardware, typically ALSA on Linux.

Features

PulseAudio provides per-application volume control, mixing of multiple streams, sample-rate conversion, audio routing between devices including Bluetooth and network sinks, low-latency monitoring and compatibility layers for applications written for other sound systems. It became the default audio server in most major Linux distributions during the late 2000s and 2010s.

Since the early 2020s many distributions have replaced PulseAudio with PipeWire, which implements a compatible PulseAudio interface.
