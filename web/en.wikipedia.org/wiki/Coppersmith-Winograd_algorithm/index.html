Coppersmith–Winograd algorithm

In linear algebra, the Coppersmith–Winograd algorithm, named after Don Coppersmith and Shmuel Winograd, is a matrix multiplication algorithm published in 1990. For many years it was the asymptotically fastest known algorithm for multiplying two n × n matrices, improving on Strassen's algorithm (1969), which runs in O(n2.807) time.

Complexity

The algorithm runs in O(n2.3755) time in its original 1990 form. It was long the record holder for the exponent of matrix multiplication, usually denoted ω. Improvements by Andrew Stothers (2010), Virginia Vassilevska Williams (2012), François Le Gall (2014), and later researchers using refinements of the "laser method" built directly on the Coppersmith–Winograd framework, gradually lowering the bound on ω; as of the early 2020s the best known bound stood around ω < 2.372, with further small improvements announced in 2024.

The laser method

The Coppersmith–Winograd algorithm is based on the laser method, a technique for analyzing tensor powers of a bilinear operation. The starting point is a particular tensor — essentially, an identity-like tensor describing a matrix multiplication problem of a special structure — whose high tensor powers can be "degenerated" to extract many disjoint copies of a smaller matrix multiplication problem. Schönhage's asymptotic sum inequality then converts this combinatorial extraction into a bound on ω. The method produces bounds via a subtle probabilistic/concentration argument (Salem–Spencer type sets) that selects index triples avoiding collisions.

Practical significance

Like most algorithms in this family, the Coppersmith–Winograd algorithm is a "galactic algorithm": it outperforms Strassen's algorithm only for matrices of astronomically large size, far beyond anything encountered in practice, because of enormous constant factors. Its importance is theoretical, bearing on the central open question of determining the exact value of ω, which lies between 2 and 2.372.
