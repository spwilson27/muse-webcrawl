Windows-1252

Windows-1252 or CP-1252 (code page 1252) is a single-byte character encoding of the Latin alphabet, used by default in legacy components of Microsoft Windows for English and many other Western European languages. It is a superset of ISO 8859-1, differing mainly in the range 0x80–0x9F, where Windows-1252 provides printable characters (such as the euro sign, smart quotes and the trademark symbol) in place of C1 control codes.

Details

The first part of the code page (0x00–0x7F) matches ASCII, and characters 0xA0–0xFF match ISO 8859-1 exactly, so most accented Western European letters occupy the same code points in both encodings. The extra printable punctuation in the 0x80–0x9F range — including the Euro sign (€) at 0x80, curly apostrophes and quotes, the en dash and em dash, the dagger and the Œ/Ÿ letters — made the encoding practical for publishing and office documents.

Use on the web

Historically, a large share of web pages declared ISO 8859-1 but actually used Windows-1252 bytes, so browsers treated the two labels as equivalent. The modern WHATWG Encoding Standard formalises this: documents labelled ISO-8859-1 (or even US-ASCII) are decoded as Windows-1252. Although UTF-8 has become the dominant encoding of the web, Windows-1252 remains one of the most common single-byte encodings encountered, and confusing it with ISO 8859-1 or mislabelled UTF-8 is a classic source of mojibake — garbled text.
