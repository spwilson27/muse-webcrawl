Automatic differentiation (AD), also called algorithmic differentiation or autodiff, is a set of techniques for evaluating the derivative of a function specified by a computer program. AD exploits the fact that any program, however complex, executes a sequence of elementary arithmetic operations and functions (additions, multiplications, sines, exponentials, and so on) whose derivatives are known. By applying the chain rule repeatedly to these operations, AD computes derivatives exactly (to machine precision), avoiding both the truncation errors of numerical finite differences and the expression swell of symbolic differentiation.

Forward and reverse mode

In forward mode, the derivative of each intermediate value with respect to a chosen input is propagated alongside the computation itself, using dual numbers or a "tangent" computation; the cost scales with the number of inputs. In reverse mode, the program first records a graph of operations (the "tape" or Wengert list) during a forward pass, then propagates derivatives of the output backwards through the graph — this is the algorithm known in machine learning as backpropagation. Reverse mode computes the full gradient of a scalar output with respect to millions of inputs at a cost comparable to a few function evaluations, but requires storing the computational graph.

Implementation and use

AD is implemented by source-code transformation (as in ADOL-C or Tapenade) or by operator overloading and dynamic graph tracing (as in modern deep-learning frameworks). It underpins the training of neural networks, where gradients of a loss function with respect to model parameters drive optimisation, and is also used in scientific computing, inverse problems, optimal control, computational fluid dynamics and sensitivity analysis.

History

The foundations were laid in the 1960s and 1970s: Seppo Linnainmaa described reverse-mode differentiation in his 1970 master's thesis, and the technique was popularised in neural networks in the 1980s. The term "automatic differentiation" emphasises that the method is automatic rather than manual, and the community distinguishes it from both numerical and symbolic differentiation.
