Noisy-channel coding theorem

In information theory, the noisy-channel coding theorem (also called Shannon's theorem or Shannon's second theorem) establishes that, for any given degree of noise contamination of a communication channel, it is possible to communicate discrete data nearly error-free up to a computable maximum rate. Claude Shannon published the result in his landmark 1948 paper "A Mathematical Theory of Communication."

Statement

Every channel has a capacity C, the supremum of achievable information rates. For any rate R < C and any ε > 0, for sufficiently large block length there exists a code with decoding error probability less than ε. Conversely, if R > C, the error probability is bounded away from zero regardless of the code. For a band-limited channel with additive white Gaussian noise, the Shannon–Hartley theorem gives:

C = B log2(1 + S/N)

where B is the bandwidth in hertz and S/N is the signal-to-noise ratio.

Significance

The theorem surprised engineers of the time: it showed that noise did not prevent reliable communication, only limited its rate, provided coding added redundancy intelligently. Shannon's proof was existential, using random codes, and the search for practical capacity-approaching codes drove decades of research, producing turbo codes, LDPC codes, and polar codes, which are now used in deep-space links, mobile networks, and data storage.
