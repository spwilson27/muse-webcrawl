Production theory

From Wikipedia, the free encyclopedia

Production theory is the branch of microeconomics that studies how firms transform inputs (factors of production) into outputs. Its central object is the production function, which specifies the maximum output obtainable from each combination of inputs, given the state of technology.

Production function

A production function is written Q = F(K, L, ...), relating output to capital, labour and other inputs. Standard examples include the Cobb–Douglas function Q = A Kα Lβ and the Leontief (fixed-proportions) function. The marginal product of an input is the extra output from one more unit of it, holding others constant; the law of diminishing marginal returns states that, beyond some point, marginal product falls as one input is increased alone.

Short run and long run

In the short run at least one input is fixed, so the firm adjusts along a single-input margin. In the long run all inputs are variable, and the analysis uses isoquants (combinations yielding equal output) and isocost lines (combinations of equal cost). Cost minimisation occurs where an isoquant is tangent to an isocost line, so the marginal rate of technical substitution equals the ratio of input prices.

Returns to scale and efficiency

Returns to scale describe how output responds when all inputs grow proportionally: increasing, constant or decreasing. Production theory underpins cost theory — total, average and marginal cost curves are derived from it — and modern extensions study technical efficiency, total factor productivity and frontier estimation.
