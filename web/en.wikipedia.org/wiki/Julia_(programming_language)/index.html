Julia is a high-level, dynamic programming language designed for high-performance numerical analysis and computational science. It was developed at MIT and first released publicly in 2012 by Jeff Bezanson, Stefan Karpinski, Viral B. Shah and Alan Edelman.

Design goals

Julia was created to solve the "two-language problem": scientists traditionally prototype in a slow, expressive language such as Python, R or MATLAB, then rewrite performance-critical code in C or Fortran. Julia aims to be as easy to use as those languages while running at speeds comparable to statically compiled ones.

Key features

  • Multiple dispatch: functions are defined by the types of all their arguments, forming the core of Julia's design.
  • Just-in-time compilation: code is compiled at run time using the LLVM infrastructure, enabling near-C performance.
  • Dynamic typing with optional annotations: type declarations are used for dispatch and optimisation rather than safety checking.
  • Metaprogramming: Julia code can be represented and manipulated as data, enabling powerful macros.
  • Foreign function interfaces: C and Fortran libraries can be called directly without wrappers.
  • Built-in package manager and extensive standard library for linear algebra, statistics and distributed computing.

History

Work began in 2009; the language was announced in a 2012 blog post titled "Why We Created Julia". Version 1.0 was released at the JuliaCon conference in August 2018, marking API stability. Julia Computing (later JuliaHub) was founded by the creators to support commercial users. The language has been used by institutions including NASA, the Federal Reserve Bank of New York and pharmaceutical companies, and in 2017 a Julia application (Celeste) ran on a supercomputer at a peak of 1.54 petaflops.

Reception

Julia has consistently ranked among the most loved languages in developer surveys and was awarded the 2019 James H. Wilkinson Prize for Numerical Software to its creators for the core language design.
