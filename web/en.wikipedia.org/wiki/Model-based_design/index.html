Model-based design
FieldSystems engineering, control engineering, embedded software
Key activitiesModelling, simulation, rapid prototyping, automatic code generation, verification
Common toolsMATLAB/Simulink, Modelica, LabVIEW, SCADE

Model-based design (MBD) is a mathematical and visual method of addressing problems associated with designing complex control, signal processing and communication systems. It is used in many motion control, industrial equipment, aerospace, and automotive applications. Rather than relying on documents and hand-written code alone, engineers build executable graphical models of the system and its controller, simulate them throughout development, and in many workflows generate production code automatically from the validated model.

Workflow

A typical model-based design workflow proceeds through system modelling and analysis, controller design and simulation against a model of the plant, rapid prototyping on real-time hardware, and finally embedded deployment through automatic code generation. Verification and validation run throughout: model-in-the-loop, software-in-the-loop, processor-in-the-loop and hardware-in-the-loop testing compare implementations against the original model at each stage.

Advantages

Because the model is an executable specification, design errors are detected early, when they are cheapest to fix. Models can be reused across product variants, requirements can be traced to model elements for certification standards such as DO-178C in aviation and ISO 26262 in automotive functional safety, and multidisciplinary teams can share a common, unambiguous description of system behaviour.

History

The approach grew out of control engineering practice and the spread of block-diagram simulation tools in the 1990s, notably Simulink, together with code generators that made it practical to move directly from desktop simulation to embedded targets. It is closely related to the broader discipline of model-based systems engineering (MBSE), which applies modelling throughout the system life cycle.
