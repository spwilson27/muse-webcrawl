Vantage-point tree

A vantage-point tree (or VP tree) is a metric tree that segregates data in a metric space by choosing a position in the space (the "vantage point") and partitioning the data points into two sets: those that are nearer to the vantage point than a threshold, and those that are farther away.

VP trees, described by Peter Yianilos in 1993, support efficient nearest neighbor search in spaces where only a distance function satisfying the triangle inequality is available, without requiring coordinates. By recursively applying the partitioning, the search can prune entire subtrees whose distance bounds cannot contain a closer point than the best found so far.

Construction

To build a VP tree, a vantage point is selected, the median distance to the remaining points is computed, and points are split into inside and outside subsets around that median. The process repeats recursively for each subset. Variants such as the multi-vantage-point tree use several vantage points per node to improve pruning.
