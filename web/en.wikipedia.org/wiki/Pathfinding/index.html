Pathfinding

Pathfinding or pathing is the plotting, by a computer application, of the shortest route between two points. It is a practical application of graph search algorithms, which find paths between nodes in a graph, and it underlies technologies such as GPS navigation, network routing, robotics, and the movement of characters in video games.

An A* search finding the shortest path through a grid with obstacles.

Algorithms

The classic pathfinding algorithms operate on a graph in which locations are nodes and traversable connections are edges with associated costs. Dijkstra's algorithm, published in 1959, guarantees the shortest path by expanding outward from the start in order of increasing cost. The A* search algorithm (1968) improves on Dijkstra's by using a heuristic estimate of the remaining distance to guide the search toward the goal, dramatically reducing the number of nodes examined while remaining optimal when the heuristic is admissible. Other approaches include breadth-first search for unweighted graphs, greedy best-first search, and bidirectional search.

Video games

Pathfinding is a core problem in game artificial intelligence, where non-player characters must navigate complex, changing environments in real time. Early games used simple waypoint graphs or tile grids; modern games often use navigation meshes (navmeshes) that cover walkable surfaces, hierarchical pathfinding to break large maps into regions, and steering behaviours to smooth movement and avoid collisions between units. Poor pathfinding is a frequent source of visible AI failures, so designers combine algorithmic search with local movement rules.

Other applications

In transportation and logistics, pathfinding powers route-planning software that must account for road networks, traffic, and turn restrictions. In robotics, path planning determines how a robot arm or mobile robot moves through physical space without collision. Computer networks route packets using shortest-path protocols descended from Dijkstra's algorithm, such as OSPF.
