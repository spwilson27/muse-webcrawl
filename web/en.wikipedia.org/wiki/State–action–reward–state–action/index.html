State–action–reward–state–action (SARSA)

State–action–reward–state–action (SARSA) is an algorithm for learning a Markov decision process policy, used in reinforcement learning. It was proposed by G. A. Rummery and M. Niranjan in 1994 (as "modified connectionist Q-learning") and named for the quintuple of quantities (s, a, r, s′, a′) that defines each update: the current state, the action taken, the reward received, the next state, and the next action.

The update rule

SARSA is an on-policy temporal-difference algorithm. After taking action a in state s, observing reward r and the successor state s′, and choosing the next action a′ according to the current policy (for example ε-greedy), the action-value estimate is updated:

Q(s, a) ← Q(s, a) + α [ r + γ Q(s′, a′) − Q(s, a) ],

where α is the learning rate and γ the discount factor. Because the update uses the action actually taken next, SARSA learns the value of the policy it follows, including its exploratory steps — in contrast to off-policy Q-learning, which updates toward the greedy maximum action.

Properties and variants

This on-policy character makes SARSA more conservative in environments with risky states: in the classic "cliff walking" example, SARSA learns a safer path away from the cliff because it accounts for its own occasional exploratory missteps. With a suitable decay of exploration (GLIE conditions), SARSA converges to the optimal action-value function. Variants include Expected SARSA, which replaces the sampled next-action value with its expectation under the policy, and multi-step forms such as SARSA(λ) using eligibility traces.
