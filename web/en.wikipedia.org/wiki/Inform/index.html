Inform

Inform is a programming language and design system for interactive fiction originally created in 1993 by Graham Nelson. The current version, Inform 7 (released in 2006), is distinctive in using a natural-language-like syntax: authors write rules in sentences resembling ordinary English, which the system compiles into code for a virtual machine such as the Z-machine or Glulx.

History

Inform 1 through 6, written by Nelson from 1993 onwards, used a more conventional syntax influenced by C and was designed to target Infocom's Z-machine, enabling new games to run on the same interpreters as classic titles like Zork. Inform 6 became the standard authoring tool for the post-commercial text adventure community and remains in use.

Inform 7

Inform 7's source reads like prose: "The Kitchen is a room. The brass lantern is a thing in the Kitchen." It is built on a rule-based engine with a sophisticated world model of objects, kinds, properties and relations, with built-in libraries for actions such as taking, examining and going. Emily Short's game Galatea-era works and her example games helped popularise the system; works such as Counterfeit Monkey demonstrate its power. Thousands of works in the Interactive Fiction Database were written in Inform.

Development environment

The Inform IDE presents source in a "notebook" with an index, testing skein, transcripts and one-click play. In 2022 Inform was released as free and open-source software.
