GLSL

OpenGL Shading Language (GLSL) is a high-level shading language with a syntax based on the C programming language. It was created by the OpenGL Architecture Review Board (ARB) of the Khronos Group to give developers more direct control of the graphics pipeline without having to use ARB assembly language or hardware-specific languages.

Overview

GLSL programs, called shaders, are compiled at runtime by the graphics driver and executed on the GPU. The principal shader types are vertex shaders, which process vertex attributes, and fragment (pixel) shaders, which compute the colour of each fragment; later versions of the language added geometry, tessellation control, tessellation evaluation, and compute shaders. GLSL was officially incorporated into the OpenGL standard with OpenGL 2.0 in 2004.

Variants

GLSL ES is a version of the language for embedded systems, used with OpenGL ES and WebGL. The related Vulkan API uses SPIR-V intermediate bytecode, commonly produced by compiling GLSL with tools such as glslangValidator.
