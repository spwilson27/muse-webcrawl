Amazon DynamoDB is a fully managed proprietary NoSQL database offered by Amazon.com as part of the Amazon Web Services (AWS) portfolio. DynamoDB offers built-in security, backup and restore, and in-memory caching for internet-scale applications. It provides a fast, predictable performance with seamless scalability, and supports both document and key-value data structures.

History

DynamoDB was announced by Amazon CTO Werner Vogels on January 18, 2012. It was influenced by the design of Dynamo, an internal Amazon storage system described in a 2007 paper presented at the Symposium on Operating Systems Principles (SOSP). Amazon's shopping cart service and other internal systems had demonstrated the need for a highly available, scalable key-value store, and DynamoDB brought those lessons to AWS customers as a managed service.

Features

DynamoDB stores data in tables made up of items, each identified by a primary key consisting of a partition key and an optional sort key. It supports secondary indexes, streams for capturing table changes, global tables for multi-region replication, and two capacity modes: provisioned throughput and on-demand. Data is stored on solid-state drives and replicated synchronously across multiple Availability Zones within an AWS Region.

DynamoDB integrates with other AWS services including AWS Lambda, Amazon S3 for import and export, and Amazon EMR. DAX (DynamoDB Accelerator) provides an in-memory cache for microsecond read latency.
