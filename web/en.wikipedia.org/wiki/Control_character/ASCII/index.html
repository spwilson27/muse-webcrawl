ASCII

ASCII (American Standard Code for Information Interchange) is a character encoding standard for electronic communication. ASCII codes represent text in computers, telecommunications equipment, and other devices. The first commercial standard was published in 1963 by the American Standards Association (ASA), and the standard was revised several times, most substantially in 1967 and 1986.

Overview

ASCII was developed from telegraph codes and first used commercially as a seven-bit teleprinter code promoted by Bell data services. The standard encodes 128 characters: the digits 0–9, the lowercase and uppercase Latin letters, basic punctuation symbols, and 33 control characters. Printable characters occupy codes 32 (space) through 126 (tilde); codes 0–31 and 127 are the C0 control codes, including carriage return, line feed, tab and the null character.

History and influence

The ASCII standard was designed so that common operations, such as sorting and case conversion, could be performed with simple bit manipulations. It became the dominant character encoding of the early Internet and personal computing era. Because seven bits could not represent the scripts of most of the world's languages, numerous 8-bit extensions (such as the ISO/IEC 8859 family and Windows code pages) appeared; these were eventually largely superseded by Unicode, whose first 128 code points are identical to ASCII and whose UTF-8 encoding preserves ASCII bytes unchanged.
