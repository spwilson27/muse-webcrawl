Newline

A newline is a control character or sequence of control characters in a character encoding specification (e.g., ASCII or EBCDIC) that is used to signify the end of a line of text and the start of a new one. Some text editors set special character sequences, which may be typed into the editor by the user, that represent a newline character in the file, such as "\n" in Unix-like systems and Python, "\r\n" in DOS and Windows, and "\r" in older Macintosh systems.

History

On typewriters and teleprinters, starting a new line required two physical operations: moving the carriage back to the left margin (carriage return, CR) and advancing the paper by one line (line feed, LF). ASCII encoded both operations as separate control characters, and early operating systems adopted different combinations: Unix used a single LF, the classic Mac OS used a single CR, and CP/M and its descendants DOS and Windows used CR+LF.

Conventions and conversion

The differing conventions cause visible problems when files are transferred between systems — text may appear as a single line, or with extra blank lines or stray characters. Text editors, programming languages and transfer tools therefore offer newline conversion; the C programming language standard library translates between the host convention and a single \n in text mode. Unicode defines additional characters, including U+2028 LINE SEPARATOR and U+2029 PARAGRAPH SEPARATOR, but the ASCII controls remain the most common line delimiters in practice.
