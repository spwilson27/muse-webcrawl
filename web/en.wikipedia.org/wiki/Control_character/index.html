Control character

In computing and telecommunications, a control character or non-printing character (NPC) is a code point in a character set that does not represent a written symbol. Instead, control characters are used to signal the receiving device to perform a particular action, such as moving a print head, ending a line, or acknowledging receipt of data.

ASCII control characters

The ASCII character set reserves the 32 codes from 0x00 to 0x1F, plus 0x7F (DEL), as control characters. Widely used examples include NUL (0x00), BEL (bell, 0x07), BS (backspace, 0x08), HT (horizontal tab, 0x09), LF (line feed, 0x0A), CR (carriage return, 0x0D), and ESC (escape, 0x1B). Transmission controls such as ACK, NAK, SYN, and ETX managed early data links. On keyboards, many control characters can be entered with the Ctrl key held together with a letter key, giving rise to notation such as ^C for the ETX character generated by Ctrl+C, which many systems interpret as an interrupt.

Other character sets

Unicode includes the ASCII controls as the C0 block and adds the C1 control block (0x80–0x9F) inherited from ISO 8859 standards, though these are rarely used. EBCDIC has its own larger set of control codes. In modern markup and data formats, raw control characters in text streams can cause parsing problems and are generally escaped or prohibited, except for tab, line feed, and carriage return.
