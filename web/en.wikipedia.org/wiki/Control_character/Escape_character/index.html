Escape character

In computing and telecommunications, an escape character is a character that invokes an alternative interpretation on the following characters in a character sequence. An escape character is a particular case of metacharacters. Generally, the judgement of whether something is an escape character or not depends on the context.

The ASCII escape character

In the ASCII character set, the escape character (ESC, code 0x1B, written as ^[ in control notation) is used to introduce escape sequences that control devices rather than print characters. ANSI escape sequences, standardised in ECMA-48 and popularised by the VT100 terminal, use ESC followed by characters such as [ to move the cursor, erase parts of the screen, and set colours and text attributes. Modern terminal emulators still interpret these sequences.

Escaping in programming languages

Many programming languages and data formats designate the backslash (\) as an escape character: in C and languages derived from it, sequences such as \n (newline), \t (tab) and \" (a literal quotation mark) embed special or otherwise awkward characters in string literals. Shells, regular expressions and markup languages use similar conventions, quoting or escaping characters that would otherwise have syntactic meaning. Failure to escape user input correctly can produce syntax errors or security vulnerabilities such as injection attacks.
