C0 and C1 control codes

The C0 and C1 control codes are the control character sets of the ISO/IEC 646 and ISO/IEC 6429 (ECMA-48) standards. The C0 set defines the first 32 control characters (code points 0x00–0x1F) together with the Delete character (0x7F), inherited largely from ASCII. The C1 set defines additional controls at code points 0x80–0x9F used mainly in 8-bit environments.

C0 controls

Well-known C0 controls include NUL (0x00), BEL (0x07, the bell), BS (backspace, 0x08), HT (horizontal tab, 0x09), LF (line feed, 0x0A), CR (carriage return, 0x0D) and ESC (escape, 0x1B), which introduces escape sequences. Others, such as the transmission controls and information separators, reflect the telegraph and data-communications origins of the standard. In modern computing, many C0 controls are rarely used, but LF, CR, tab and ESC remain ubiquitous.

C1 controls

The C1 set includes characters such as NEL (next line), CSI (Control Sequence Introducer, 0x9B) and OSC (Operating System Command). In practice, C1 controls are more often represented by an ESC byte followed by an ASCII character — for example, ESC [ is equivalent to CSI — because single-byte C1 codes can be corrupted by systems that treat bytes 0x80–0x9F as printable characters, as Windows code pages do. In Unicode, the C0 and C1 controls occupy the ranges U+0000–U+001F and U+0080–U+009F.
