Unicode

Unicode, formally The Unicode Standard, is a text encoding standard maintained by the Unicode Consortium designed to support the use of text in all of the world's writing systems that can be digitized. Version 16.0 of the standard defines 154,998 characters and 168 scripts used in various ordinary, literary, and scientific symbols.

Design

Unicode assigns each character a unique number called a code point, written U+ followed by hexadecimal digits, and a unique name, without specifying how the character should be rendered. The code space runs from U+0000 to U+10FFFF, divided into 17 planes; the first, the Basic Multilingual Plane, contains nearly all commonly used characters, including the C0 and C1 control codes inherited from ASCII and Latin-1. Encodings such as UTF-8, UTF-16 and UTF-32 map code points to bytes; UTF-8, which is variable-length and backward compatible with ASCII, dominates the Web and Unix-like systems.

History

Unicode began in 1987 as an effort by engineers at Xerox and Apple to create a universal 16-bit character set. The Unicode Consortium was incorporated in 1991, and the first volume of the standard was published that year. Merging with the parallel ISO/IEC 10646 project kept the two standards synchronised. Successive versions added scripts, symbols and emoji; a major ongoing task is encoding historic and minority scripts. Unicode also specifies algorithms for bidirectional text, line breaking, normalisation, collation and segmentation, making it far more than a simple character list.

Adoption

Unicode is the foundation of text handling in modern operating systems, programming languages and the Web; the great majority of web pages are encoded in UTF-8. Its emoji repertoire has had a large cultural impact, and new emoji and scripts continue to be added in annual releases.
