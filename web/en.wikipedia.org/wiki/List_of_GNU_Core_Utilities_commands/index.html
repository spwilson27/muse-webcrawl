List of GNU Core Utilities commands

From Wikipedia, the free encyclopedia

The GNU Core Utilities (coreutils) is a package of GNU software containing implementations of many of the basic tools, such as cat, ls, and rm, which are used on Unix-like operating systems. The package was formed in 2003 by merging the earlier fileutils, textutils, and shellutils packages. This article lists the commands provided.

File utilities

CommandDescription
lsList directory contents
cpCopy files and directories
mvMove or rename files
rmRemove files or directories
mkdir / rmdirCreate / remove directories
touchChange file timestamps or create empty files
chmod / chownChange file permissions / ownership
lnMake links between files
ddConvert and copy a file
df / duReport filesystem free space / estimate file space usage

Text utilities

CommandDescription
catConcatenate files and print to standard output
head / tailOutput the first / last part of files
sortSort lines of text files
uniqReport or omit repeated lines
wcPrint newline, word, and byte counts
cut / pasteRemove / merge sections of lines
trTranslate or delete characters
expand / fmtConvert tabs to spaces / reformat paragraph text

Other utilities

Coreutils also provides shell-oriented commands such as echo, printf, pwd, test ([), true/false, sleep, seq, date, who, id, uname, hostname, basename, dirname, env, nice, nohup, timeout, and yes, among roughly one hundred commands in total.
