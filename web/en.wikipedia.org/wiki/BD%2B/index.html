BD+

BD+ is a component of the Blu-ray Disc digital rights management (DRM) system, developed by Cryptography Research Inc. Unlike the static AACS encryption layer, BD+ is a small virtual machine embedded in authorised players that runs code supplied on each disc, allowing content providers to verify that the player has not been tampered with and to patch compromised security mechanisms.

Mechanism

When a BD+ disc is loaded, the player runs a program stored on the disc inside a virtual machine. The program can inspect player memory and keys, transform (descramble) segments of the video stream, and detect known ripping tools. Because the code ships with the disc, studios can update countermeasures for new titles.

Circumvention

BD+ was first fully circumvented by commercial ripping software in 2008, after which updated BD+ generations appeared on later discs, producing an ongoing cycle of updates and cracks. The system remains part of the Blu-ray specification's layered copy protection alongside AACS and region coding.
