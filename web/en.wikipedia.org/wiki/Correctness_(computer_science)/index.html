Correctness (computer science)

In theoretical computer science, an algorithm is correct with respect to a specification if it behaves as specified. Two aspects are distinguished: partial correctness, which requires that if an answer is returned it is correct, and total correctness, which additionally requires that the algorithm terminates. Formal verification of correctness is a central topic of program semantics and software engineering.

Overview

Field: Theoretical computer science

Key concepts: Partial and total correctness, Hoare logic, formal verification

Hoare logic

Hoare logic, introduced by C. A. R. Hoare in 1969, is a formal system for reasoning about program correctness using triples {P} C {Q}, where P and Q are pre- and postconditions. Loop invariants are used to prove properties of iterative programs, and Dijkstra's weakest-precondition calculus extended the approach.

Practice

Although full formal proof is expensive, correctness arguments inform testing, type systems, model checking and the design of mission-critical software. Termination proofs rely on finding a quantity that decreases with each iteration and is bounded below.
