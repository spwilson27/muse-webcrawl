Invariant (computer science)


A loop invariant holds before and after every iteration.

In computer science, an invariant is a condition that can be relied upon to be true during the execution of a program, or during some portion of it. Such conditions are used in reasoning about program correctness, in assertions checked at run time, and in design by contract.

Loop invariants

A loop invariant is a property that holds before the loop starts, is preserved by each iteration, and — combined with the loop's exit condition — establishes the desired result when the loop ends. Finding suitable invariants is the central technique for proving algorithms correct, as in classic proofs for binary search and sorting algorithms.

Class invariants

In object-oriented programming, a class invariant is a condition that must hold for every instance of a class whenever control is outside the object's methods — essentially a consistency requirement on an object's state. Languages and tools such as Eiffel support stating invariants explicitly so they can be checked automatically, and violating an invariant generally signals a bug.

Data structure invariants

Many data structures are defined by invariants their operations must maintain: a binary search tree keeps keys ordered, a red–black tree maintains colouring rules that guarantee balance, and a heap keeps each parent ordered relative to its children.
