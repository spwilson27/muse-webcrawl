GNU

From Wikipedia, the free encyclopedia
[Image: The GNU head logo, a gnu's head in profile drawn in bold lines]

GNU is an extensive collection of free software, which can be used as an operating system or in parts with other operating systems. The GNU Project, launched by Richard Stallman in September 1983 at MIT, set out to build a complete Unix-like system composed entirely of free software; its name is a recursive acronym for 'GNU's Not Unix!'.

By the early 1990s GNU had produced the essential userland — the GCC compiler, Emacs editor, Bash shell, core utilities, and the GNU C Library — but its kernel, the Hurd, lagged. The independently written Linux kernel (1991) filled the gap, and the combined GNU/Linux system became the foundation of the free and open-source software world.

Components and licences

GNU software is licensed under the GPL and related licences Stallman drafted (GPLv1 1989, GPLv2 1991, GPLv3 2007), whose 'copyleft' requires derivatives distributed to others to remain free. The Free Software Foundation (1985) stewards the project and the licences.

The naming question — GNU/Linux versus Linux — is a long-running debate: the Linux kernel alone is not a usable system, and most distributions pair it with GNU tools (musl/BusyBox-based systems such as Alpine are exceptions).

Legacy

GNU tools set the quality bar for free software and modelled the licence-driven commons that followed. Development continues (the Hurd included), though GNU's centre of gravity shifted from a single system to infrastructure everywhere.
