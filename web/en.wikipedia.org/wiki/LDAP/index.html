LDAP

The Lightweight Directory Access Protocol (LDAP) is an open, vendor-neutral application protocol for accessing and maintaining distributed directory information services over an Internet Protocol (IP) network. Directory services play an important role in developing intranet and Internet applications by allowing the sharing of information about users, systems, networks, services, and applications throughout the network.

Overview

LDAP was developed as a lighter-weight alternative to the X.500 Directory Access Protocol, using the simpler TCP/IP protocol stack rather than the OSI stack. A common use of LDAP is single sign-on, where a user can use one password for many services. LDAP is specified in a series of RFCs published by the Internet Engineering Task Force, beginning with RFC 4510.

Directory structure

An LDAP directory is organized as a tree, with entries arranged hierarchically beneath a root. Each entry has a distinguished name (DN) that uniquely identifies it, and a set of attributes. A common structure organizes entries by organization (o), organizational unit (ou), and common name (cn).

Operations

LDAP defines operations for adding, deleting, and modifying entries, searching the directory, binding (authenticating), and abandoning requests. Searches support filters and a base object, search scope, and size and time limits.
