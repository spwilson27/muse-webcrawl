The GNU Hurd is the multiserver microkernel written as part of the GNU Project, intended as the kernel of the GNU operating system and a replacement for the Unix kernel. "Hurd" is a recursive acronym for "Hird of Unix-replacing daemons", where "Hird" itself stands for "Hurd of interfaces representing depth".

Architecture

The Hurd is a set of server processes running on top of the Mach microkernel (and later ports and experiments with other microkernels). Servers called translators implement filesystem, network, authentication, and other operating-system services in user space, communicating via Mach IPC through distributed objects.

History

Development began in 1990. Although the Hurd was officially the GNU kernel, the project progressed slowly as a research operating system, and the Linux kernel — released in 1991 — filled the role of a practical free kernel for GNU userland. Debian GNU/Hurd remains the principal distribution built on it.
