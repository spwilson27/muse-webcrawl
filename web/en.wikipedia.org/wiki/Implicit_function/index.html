Implicit function

Implicit function
FieldMathematical analysis, calculus
Defined byAn equation R(x, y) = 0
Related theoremImplicit function theorem
TechniqueImplicit differentiation

In mathematics, an implicit equation is a relation of the form R(x1, …, xn) = 0, where R is a function of several variables. An implicit function is a function defined implicitly by such an equation, by associating one of the variables (the value) with the others (the arguments). Not every implicit equation can be solved explicitly for one variable in terms of the others.

Examples

The unit circle is defined by the implicit equation x2 + y2 − 1 = 0. It is not the graph of a single function y(x), but it can be described locally by two explicit functions, y = √(1 − x2) and y = −√(1 − x2). The folium of Descartes, x3 + y3 − 3xy = 0, cannot conveniently be solved for y at all.

Implicit differentiation

Even when y cannot be isolated, its derivative can be found by differentiating both sides of the equation with respect to x and applying the chain rule, then solving for dy/dx. For the circle, this gives dy/dx = −x/y.

Implicit function theorem

The implicit function theorem guarantees that, under suitable smoothness conditions and a non-vanishing partial derivative, an implicitly defined relation locally defines a genuine differentiable function. It is a foundational result in multivariable calculus and differential geometry, with applications ranging from economics (comparative statics) to the theory of manifolds. (This mathematical concept is unrelated to the Implicit Association Test in psychology or the sociological notion of implicit bias.)
