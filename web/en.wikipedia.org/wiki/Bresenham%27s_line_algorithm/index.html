Bresenham's line algorithm

Bresenham's line algorithm
Type: rasterization algorithm
Developed by: Jack Elton Bresenham (1962, IBM)
Published: IBM Systems Journal, 1965
Properties: integer arithmetic only; incremental error
Extensions: midpoint circle algorithm, ellipse and curve variants

Bresenham's line algorithm is an algorithm that determines the points of an n-dimensional raster that should be selected in order to form a close approximation to a straight line between two points. It is one of the earliest algorithms developed in the field of computer graphics and remains widely used in graphics hardware and software libraries.

Method

Developed by Jack Bresenham in 1962 for a digital plotter, the algorithm avoids floating-point multiplication and division. For a line with slope between 0 and 1, it steps along the x-axis and maintains an integer error accumulator: at each step it adds the slope numerator, and whenever the accumulated error crosses a threshold it steps up one pixel in y and subtracts the run length. The procedure generalizes to all octants by swapping and negating axes, and analogous algorithms exist for circles and ellipses.

Importance

Because it uses only integer addition, subtraction, and comparison, the algorithm is extremely fast and easy to implement in hardware, making it a staple of graphics processing units, printer controllers, and CNC machines. Its simplicity and efficiency made it a landmark result in early computer graphics.
