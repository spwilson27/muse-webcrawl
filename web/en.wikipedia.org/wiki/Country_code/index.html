Country code

From Wikipedia, the free encyclopedia

A country code is a short alphabetic or numeric geographical code representing a country or dependent territory. Country codes are used in many technical and administrative contexts to identify nations unambiguously regardless of language or naming disputes.

Systems

The most widely used system is ISO 3166-1, which assigns each country a two-letter code (alpha-2, e.g. US, GB, JP), a three-letter code (alpha-3), and a three-digit numeric code. These underpin Internet country-code top-level domains, two-letter codes in passports and vehicle plates, and statistical coding by the United Nations. Related standards include international telephone dialling codes (ITU E.164, such as +1 and +44), IOC and FIFA trigrammes used in sport, and NATO country codes.
