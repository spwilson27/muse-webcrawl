Union type

A union type variable may hold a value of any one of its member types.

In computer science, a union type is a type that can hold values of several different (but fixed) types; only one of the alternatives can be present at any time. Union types are closely related to sum types and tagged (discriminated) unions in type theory, and appear in languages such as TypeScript, Rust (through enums), Haskell and ML (as algebraic data types), C and C++ (as the union construct), and PHP and Python (through type annotations such as int | str).

Tagged and untagged unions

In a tagged union (discriminated union), each value carries an explicit tag recording which alternative it currently holds, so a program can safely determine the active member at runtime. Languages such as Rust, Swift, Haskell and OCaml build their enumerations on this principle. In an untagged union, such as C's union, the storage simply overlays the members: the programmer is responsible for knowing which member was last written, and reading another member reinterprets the bits — a flexible but error-prone feature inherited from systems programming.

Union types in type systems

TypeScript popularised union types in mainstream programming with syntax such as string | number, combined with type narrowing through control-flow analysis. Flow, Hack and PHP 8 support similar constructs. In set-theoretic terms the union type corresponds to the set union of its member types, and is dual to the intersection type. A value of a union type may be used anywhere a value of one specific member is expected only after the program has checked which alternative is present.

Applications

Union types model values that may legitimately take different forms: a function result that is either a value or an error (result types), optional values (T | null), polymorphic function arguments, and nodes of abstract syntax trees in compilers.
