Introsort

Introsort or introspective sort is a hybrid sorting algorithm that provides both fast average performance and optimal asymptotic worst-case performance. It begins with quicksort, switches to heapsort when the recursion depth exceeds a level based on the logarithm of the number of elements being sorted, and switches to insertion sort for small partitions.

Overview

Introsort was invented by David Musser in 1997. Its design addresses quicksort's vulnerability to worst-case O(n²) behaviour on adversarial or degenerate inputs: once recursion depth passes 2⌊log₂ n⌋, the algorithm finishes the partition with heapsort, guaranteeing O(n log n) worst-case running time while retaining quicksort's speed and cache behaviour in the common case. Subarrays below a small threshold (often 16 elements) are left unsorted and finished with a single insertion sort over the whole array at the end.

Use

Introsort is best known as the implementation of std::sort in many C++ standard libraries, including GNU libstdc++, and variants are used in other language runtimes. Related hybrids include pdqsort, which is not an introsort but shares the goal of robust practical performance.
