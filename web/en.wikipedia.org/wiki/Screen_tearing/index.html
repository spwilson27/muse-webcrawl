Screen tearing

Screen tearing is a visual artifact in display technology where a screen shows information from multiple frames in a single screen draw. The effect occurs when the video feed to the device is not synchronised with the display's refresh rate: the graphic card begins sending a new frame while the previous one is still being drawn, so the top part of the image shows one frame and the bottom part shows the next, with a visible horizontal "tear" line between them.

Causes

Tearing is most noticeable during fast motion, such as in video games with rapid camera pans. It happens because displays refresh at a fixed rate (e.g. 60 Hz) while rendering pipelines produce frames at variable rates, and the frame buffer is swapped mid-scanout.

Prevention

The standard remedy is vertical synchronisation (VSync), which delays buffer swaps until the vertical blanking interval, though this can introduce input latency and stutter if the frame rate drops below the refresh rate. Double and triple buffering mitigate these problems. Adaptive sync technologies such as AMD FreeSync and Nvidia G-Sync vary the display's refresh rate to match the frame rate, eliminating tearing without the latency penalty of fixed VSync.
