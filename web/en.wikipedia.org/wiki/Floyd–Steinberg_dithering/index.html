Floyd–Steinberg dithering

From Wikipedia, the free encyclopedia

Floyd–Steinberg dithering is an image dithering algorithm first published by Robert W. Floyd and Louis Steinberg in 1976. It is commonly used by image manipulation software to convert an image from one color depth or palette to another — for example, reducing a grayscale image to black and white, or converting a picture to the limited palette of a GIF — while preserving the perceived distribution of tones.

Algorithm

The algorithm processes the image pixel by pixel, typically left to right and top to bottom. Each pixel's value is rounded ("quantized") to the nearest available palette value. The quantization error — the difference between the original and rounded values — is then distributed ("diffused") to neighboring pixels that have not yet been processed, in the following proportions: 7/16 to the pixel to the right, 3/16 to the pixel below-left, 5/16 to the pixel directly below, and 1/16 to the pixel below-right. This error diffusion pushes neighboring pixels in the opposite direction, so that over a small area the average value closely matches the original, and the eye perceives intermediate tones.

Characteristics and variants

Floyd–Steinberg dithering produces fine, somewhat noisy textures and avoids the visible banding of simple thresholding, though it can create characteristic "worm" artifacts in smooth gradients. A common optimization scans alternate rows in opposite directions (serpentine scanning) to reduce directional artifacts. Related error-diffusion kernels include Atkinson dithering (popular on early Macintosh systems, diffusing only 6/8 of the error), Jarvis–Judice–Ninke, Stucki, Burkes, and Sierra filtering, which spread the error over more pixels for smoother results. Error diffusion is conceptually the image-processing analogue of sigma-delta modulation in signal processing.
