Value network

A value network is a business analysis perspective that describes social and technical resources within and between businesses. The nodes in a value network represent people or organizations, while links represent interactions, transactions, or flows of tangible and intangible value between those nodes.

The concept extends the value chain framework introduced by Michael Porter, allowing multiple organizations to be modelled together rather than a single firm. Value networks are used to analyse how value is created, exchanged, and captured in ecosystems such as platform businesses, supply networks, and open innovation communities.

Overview

In a value network, value exchanges may include goods, services, revenue, knowledge, information, and intangible benefits such as reputation or customer loyalty. The approach draws on network theory and systems thinking. Researchers such as Verna Allee developed value network analysis as a method for mapping these exchanges and assessing the health of a business ecosystem.
