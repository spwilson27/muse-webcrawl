Extreme value theorem

Extreme value theorem
FieldReal analysis, calculus
StatementA continuous function on a closed bounded interval attains a maximum and a minimum
RelatedBolzano–Weierstrass theorem, Heine–Borel theorem

In calculus and real analysis, the extreme value theorem, or Weierstrass extreme value theorem, states that if a real-valued function f is continuous on a closed interval [a, b], then f must attain a maximum and a minimum, each at least once: there exist numbers c and d in [a, b] such that f(c) ≥ f(x) ≥ f(d) for all x in [a, b].

Conditions

Both hypotheses are essential. On an open interval a continuous function may fail to attain its bounds (for example f(x) = 1/x on (0, 1]), and a discontinuous function on a closed interval may likewise have no maximum. Related generalisations hold for continuous functions on compact sets in general topological spaces, where the image of a compact set under a continuous map is compact.

Proof sketch

The theorem is usually proved in two steps. First, the boundedness theorem shows that a continuous function on a closed interval is bounded, which follows from the Bolzano–Weierstrass theorem: if f were unbounded, a sequence of points with values tending to infinity would have a convergent subsequence whose limit point contradicts continuity. Second, taking a sequence of points whose values approach the supremum and extracting a convergent subsequence shows the supremum is actually attained; the same argument with the infimum gives the minimum.

Applications

The theorem guarantees that optimisation problems over closed bounded domains have solutions, and underpins techniques such as finding absolute extrema of functions in elementary calculus by checking critical points and endpoints.
