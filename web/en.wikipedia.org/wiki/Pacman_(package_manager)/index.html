Pacman (package manager)

Pacman is a package manager utility that tracks installed packages on a Linux system. It was originally developed by Judd Vinet and is the default package manager for Arch Linux and its derivatives. Pacman features dependency support, package groups, install scripts, and a scripting frontend called makepkg.

Design

Pacman is designed to be simple and fast. It uses a binary package format with the .pkg.tar.zst extension (earlier versions used .pkg.tar.xz and .pkg.tar.gz), containing all the files belonging to the package along with a .PKGINFO metadata file generated by makepkg. Packages are installed with the command pacman -S and the whole system can be upgraded with pacman -Syu.

Library

Underlying pacman is libalpm (Arch Linux Package Management library), which handles package transactions, dependency resolution, and database queries. The local package database is stored in /var/lib/pacman/local/, and sync databases are downloaded from repository mirrors.

Frontends

Several graphical frontends exist for pacman, including Pamac (used by default in Manjaro), which wraps libalpm. Command-line helpers such as yay and paru additionally provide access to the Arch User Repository (AUR).
