Parallel port

A parallel port is a type of interface on computers for connecting peripherals, in which data are sent multiple bits at a time over parallel wires. The best-known version was the printer port popularised by the IBM PC, using a 25-pin D-sub connector on the computer and a 36-pin Centronics connector on the printer. The interface was standardised as IEEE 1284 in 1994.

History

Centronics introduced its parallel printer interface in the 1970s; IBM adopted a variant for the original PC in 1981, initially as a largely one-way output to printers. Later modes added bidirectional capability: PS/2 bidirectional mode, Enhanced Parallel Port (EPP) and Extended Capability Port (ECP), raising speeds to around 2 MB/s. Before USB became universal, the port was also used for Zip drives, scanners, external CD drives, dongles and home-built hardware.

Decline

USB (and later network printing) displaced the parallel port during the 2000s, because it is faster, smaller, hot-pluggable and supports many devices on one bus. Parallel ports disappeared from mainstream laptops and desktops, though they linger in industrial equipment and dedicated adapters.
