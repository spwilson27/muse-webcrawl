Element (mathematics)

Element
Notation: x ∈ A
Field: set theory
Related: set, subset, membership relation

In mathematics, an element (or member) of a set is any one of the distinct objects that make up that set. The statement that x is an element of the set A is written x ∈ A; if x is not an element of A, one writes x ∉ A.

Sets and membership

Writing A = {1, 2, 3, 4} defines a set whose elements are the numbers 1 through 4. Membership is the fundamental relation of set theory: in the Zermelo–Fraenkel axiomatisation, every mathematical object is a set, and statements about elements are statements about the ∈ relation.

Examples

With A = {1, 2, 3, 4}, 2 ∈ A but 5 ∉ A. The set B = {1, 2, {3, 4}} has three elements: 1, 2, and the set {3, 4} itself — an element of a set may itself be a set. Every set is an element of its own power set's subsets, and the empty set has no elements at all.

Cardinality

The number of elements in a set is its cardinality. Finite sets have a natural number as cardinality, while infinite sets are compared using bijections, leading to the theory of cardinal numbers.
