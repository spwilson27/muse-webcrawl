LIFO (computing)

LIFO, an acronym for last in, first out, is a method of processing data in which the most recently added item is the first to be removed. It is the defining behaviour of the stack abstract data type: elements are added ("pushed") and removed ("popped") at the same end, called the top.

The stack

A stack supports the operations push (add an element to the top), pop (remove and return the top element), and peek (examine the top element without removing it). Because both insertion and deletion occur at one end, the last element pushed is necessarily the first element popped — the LIFO property. An everyday analogy is a stack of plates, where plates are added and taken from the top.

Applications

LIFO structures underpin many computing mechanisms. Function calls are tracked on a call stack, so that when a function returns, control passes to the most recent caller. Undo operations in editors, expression evaluation (including converting infix to postfix notation), depth-first search, and backtracking algorithms all rely on stack behaviour. Programming languages such as Forth are explicitly stack-oriented.

Contrast with FIFO

LIFO is the opposite of FIFO (first in, first out), the behaviour of a queue, in which the oldest item is processed first, as in a line of people waiting.
