XNU

XNU ("X is Not Unix") is the computer operating system kernel developed by Apple Inc. since December 1996 for use in the macOS operating system, and released as free and open-source software as part of the Darwin operating system, which forms the foundation for Apple's other systems including iOS, watchOS and tvOS.

Design

XNU is a hybrid kernel combining the Mach microkernel (developed at Carnegie Mellon University and refined by NeXT and Apple) with components from FreeBSD, including its process model, networking stack and virtual file system layer. It also incorporates I/O Kit, an object-oriented device-driver framework written in a restricted subset of C++. Earlier versions combined Mach 2.5-derived code from the Open Software Foundation's OSF/1.

History

The kernel descends from the Mach-based kernel of NeXTSTEP, acquired with Apple's purchase of NeXT in 1996. XNU first shipped in Mac OS X Server 1.0 and Mac OS X 10.0. Apple releases the source code for XNU for each macOS release under the Apple Public Source License, excluding some proprietary driver components.
