Galois/Counter Mode


Galois/Counter Mode (GCM) is an authenticated encryption mode for block ciphers.

In cryptography, Galois/Counter Mode (GCM) is a mode of operation for symmetric-key block ciphers that is widely adopted for its speed and authenticated-encryption properties. GCM combines counter mode (CTR) encryption with authentication based on a universal hash function evaluated over a Galois field, providing both confidentiality and integrity (AEAD — authenticated encryption with associated data).

Operation

The plaintext is encrypted using the block cipher in counter mode: successive values of a counter are encrypted and XORed with the plaintext blocks. Authentication uses GHASH, a polynomial hash defined over the finite field GF(2128): the ciphertext blocks (and any additional authenticated data, plus a length block) are multiplied by a hash key H — derived by encrypting the zero block — and powers of H in the field. The final GHASH output is masked with the encrypted initial counter block to produce the authentication tag.

Properties and use

GCM is parallelizable, can be implemented efficiently in hardware (Intel processors provide the PCLMULQDQ instruction for carry-less multiplication), and requires no padding beyond a final partial block. It was standardized by NIST in SP 800-38D (2007). GCM is used in TLS 1.2 and 1.3 cipher suites (AES-GCM), in IPsec, SSH, and in IEEE 802.11ad. Care is required with nonce uniqueness: reusing a nonce with the same key destroys authenticity and exposes the hash key, which motivated misuse-resistant variants such as AES-GCM-SIV.
