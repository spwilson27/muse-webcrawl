Galois/Counter Mode as a Block Cipher Mode of Operation

This article discusses Galois/Counter Mode (GCM) in relation to the general theory of block cipher modes of operation. A mode of operation is an algorithm that uses a block cipher to provide confidentiality and, in some constructions, authenticity for messages of arbitrary length.

Galois/Counter Mode

GCM, proposed by David McGrew and John Viega and standardised by NIST in SP 800-38D (2007), combines counter (CTR) mode encryption with authentication based on multiplication in the finite field GF(2¹²⁸). Encryption generates a keystream by encrypting successive counter values derived from an initialisation vector; authentication computes GHASH, a polynomial hash over the field defined by the polynomial x¹²⁸ + x⁷ + x² + x + 1, whose key is the encryption of the zero block. The combination yields an authenticated encryption with associated data (AEAD) construction.

Properties

Like other counter-based modes, GCM is parallelisable and requires only the forward direction of the block cipher; its authentication is also parallelisable and can be accelerated with carry-less multiplication instructions. GCM is extremely widely deployed, including in TLS 1.2 and TLS 1.3 cipher suites, IPsec and storage encryption. Its security depends critically on never reusing an IV with the same key, since nonce reuse leaks the authentication key and the XOR of plaintexts.

Related modes

Other authenticated modes include CCM (counter with CBC-MAC), EAX, OCB and the ChaCha20-Poly1305 construction. Earlier unauthenticated modes — ECB, CBC, CFB, OFB and CTR — provide confidentiality only and are now generally combined with a separate message authentication code or replaced by AEAD modes.
