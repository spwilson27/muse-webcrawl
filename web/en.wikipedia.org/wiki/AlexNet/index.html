AlexNet

From Wikipedia, the free encyclopedia

Original author(s)Alex Krizhevsky, Ilya Sutskever, Geoffrey Hinton
Initial release2012
TypeConvolutional neural network

AlexNet is a convolutional neural network (CNN) architecture designed by Alex Krizhevsky, Ilya Sutskever and Geoffrey Hinton at the University of Toronto. It won the ImageNet Large Scale Visual Recognition Challenge (ILSVRC) in 2012 by a large margin, achieving a top-5 error rate of 15.3%, compared to 26.1% for the second-place entry. Its success is widely regarded as the event that ignited the modern deep learning revolution in computer vision.

Architecture

AlexNet contains eight learned layers: five convolutional layers, some of which are followed by max-pooling layers, and three fully connected layers. It was the first large CNN to use several techniques that later became standard, including rectified linear units (ReLUs) for faster training, dropout and data augmentation to reduce overfitting, and training across multiple GPUs. The network takes a 227×227 RGB image as input and outputs class probabilities over 1,000 categories. Local response normalization was also used, though later work largely abandoned it.

Historical significance

The 2012 paper "ImageNet Classification with Deep Convolutional Neural Networks" demonstrated that deep networks trained on large datasets with GPUs could dramatically outperform hand-engineered features. Within a few years, convolutional networks based on AlexNet's design became the dominant approach for image classification, detection and segmentation, and the architecture remains a standard reference point in the field.
