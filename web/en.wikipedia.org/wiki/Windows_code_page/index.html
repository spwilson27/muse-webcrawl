Windows code page

Windows code pages are a family of single-byte character encodings used in Microsoft Windows systems prior to the widespread adoption of Unicode. Each code page maps byte values 0–255 to characters, with the lower half corresponding to ASCII and the upper half covering letters and symbols needed for particular languages.

ANSI code pages

The best-known group, often called the "ANSI" code pages, includes Windows-1252 for Western European languages, Windows-1251 for Cyrillic, Windows-1250 for Central European languages, Windows-1253 for Greek, and Windows-1254 for Turkish. Windows-1252 differs from ISO 8859-1 mainly in the range 0x80–0x9F, where it places printable characters such as the Euro sign, curly quotes, and the trademark symbol instead of control codes. These encodings are registered with IANA under names like windows-1252.

OEM and other code pages

Windows also supports "OEM" code pages (such as CP437 and CP850) inherited from MS-DOS for console applications, and double-byte code pages for East Asian languages, including Shift JIS (932), GBK (936), and Big5 (950). Modern Windows versions increasingly default to UTF-8, but code pages remain important for legacy applications and file formats.
