Microsoft Exchange Server

Microsoft Exchange Server
Developer: Microsoft
Initial release: 1996
Platform: Windows Server
Type: Mail server, groupware

Microsoft Exchange Server is a mail server and calendaring server developed by Microsoft, running exclusively on Windows Server operating systems. First released in 1996, it became the dominant corporate email platform, providing email, calendars, contacts, scheduling and voicemail services.

Clients and protocols

The native client is Microsoft Outlook, which connects using MAPI over HTTP; web access is provided through Outlook on the web. Exchange also supports POP3, IMAP and SMTP, and the Exchange ActiveSync protocol synchronises mail and calendars to mobile devices. Exchange Online, the hosted version, is a core part of Microsoft 365.

History

Major versions include Exchange 2000, 2003, 2007, 2010, 2013, 2016 and 2019. In March 2021, a set of zero-day vulnerabilities (dubbed ProxyLogon) was exploited in the wild against tens of thousands of on-premises servers worldwide, prompting emergency patches.
