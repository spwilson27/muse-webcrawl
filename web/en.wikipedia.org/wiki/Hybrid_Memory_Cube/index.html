Hybrid Memory Cube

The Hybrid Memory Cube (HMC) is a high-performance computer memory interface for three-dimensional stacked DRAM, developed by Micron Technology and Intel and promoted by the Hybrid Memory Cube Consortium. It stacks several DRAM dies on top of a base logic die, connected by through-silicon vias (TSVs), and communicates with the host processor over high-speed serial links rather than a wide parallel bus.

Design

In an HMC device the memory array is divided into vertical "vaults", each controlled by a memory controller in the base logic layer. Requests are sent as packets over serial links, which allows much higher bandwidth — on the order of hundreds of gigabytes per second per device — together with lower energy per bit transferred than conventional DDR memory. Placing logic under the memory also lets the cube perform some operations close to the data.

History and competition

The technology was announced in 2011 and sample devices followed in the middle of the decade. HMC competed with High Bandwidth Memory (HBM), the JEDEC-standardised stacked memory used on interposers beside processors; HBM ultimately achieved much wider adoption in graphics processors and accelerators, while HMC saw limited use, for example in some Intel Xeon Phi Knights Landing configurations and FPGA boards.
