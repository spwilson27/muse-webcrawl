Field (computer science)

In computer science, data that has several parts, known as a record, can be divided into fields. A field is a single named piece of data within a record, such as the "name" or "date of birth" within a person's record in a database.

Fields in databases

Relational databases arrange data in tables with pairs of rows and columns; each column corresponds to a field, and each row supplies one value for every field. In fixed-length records, fields occupy a predetermined number of bytes, whereas variable-length records often separate fields with delimiters. The term is also used for the individual data items entered on a form, whether on paper or on screen.

Fields in programming

In object-oriented programming, a field (also called a data member or instance variable) is data encapsulated within a class or object. Instance fields belong to a particular object and may hold different values for each instance, while static or class fields are shared across all instances. Access to fields is commonly controlled by access modifiers such as public, private, and protected.
