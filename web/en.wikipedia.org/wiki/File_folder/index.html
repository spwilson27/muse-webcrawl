File folder

A file folder is a kind of folder that holds documents together for organization and protection in an office or home. Typically made of heavy paper stock folded in half, with a tab for labelling, file folders are stored in filing cabinets, desk drawers, or boxes so that papers can be grouped, retrieved, and archived.

Types

The classic manila folder is made from manila paper, originally derived from abacá hemp. Common variants include hanging folders, which hook onto rails in a drawer; classification folders with internal dividers and fasteners; pocket folders; and expanding accordion files. Tabs may be in different positions (cuts) along the top edge so that labels remain visible in a drawer; coloured folders are often used to code categories of files.

Digital metaphor

The file folder, together with the filing cabinet and the desktop, became a central metaphor of early graphical user interfaces: directories in computer filesystems are called "folders" and are shown as folder icons, a convention popularized by the Xerox Star and the Apple Macintosh in the 1980s and retained in modern operating systems.
