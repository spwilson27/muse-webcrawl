Monotonic function

In mathematics, a monotonic function (or monotone function) is a function between ordered sets that preserves or reverses the given order. A function f is monotonically increasing (or non-decreasing) if, whenever x ≤ y, then f(x) ≤ f(y); it is strictly increasing if x < y implies f(x) < f(y). Decreasing functions are defined analogously. Monotonicity is a central concept in real analysis, order theory, economics and computer science.

In calculus and analysis

A differentiable function is increasing on an interval if its derivative is non-negative there, and strictly increasing if the derivative is positive (except possibly at isolated points). Monotone functions have useful regularity properties: a monotone function on an interval has left- and right-hand limits everywhere, can have only countably many discontinuities (all of them jump discontinuities), and is differentiable almost everywhere (Lebesgue's theorem). Every monotone function on a closed interval is Riemann integrable.

Inverses

A strictly monotonic continuous function is injective and possesses an inverse defined on its range, which is likewise strictly monotonic in the same direction. Cumulative distribution functions in probability are non-decreasing by definition.

Order theory and other uses

In order theory, a monotone map between partially ordered sets satisfies x ≤ y ⇒ f(x) ≤ f(y); such maps are fundamental to the fixed-point theorems of domain theory. In Boolean algebra, monotonic Boolean functions (built from AND and OR without negation) matter in circuit complexity. In economics, monotonic preferences and monotone comparative statics rely on the same idea.
