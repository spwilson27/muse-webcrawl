Visual Studio Code

Visual Studio Code, commonly called VS Code, is a source-code editor developed by Microsoft for Windows, Linux, and macOS, first released in 2015.

Features

It supports debugging, embedded Git, syntax highlighting, IntelliSense completion, snippets, and refactoring, and is extensible via a large marketplace of extensions. It is built on Electron.

Popularity

It became the most popular development environment in Stack Overflow surveys, used by a majority of developers worldwide.
