Gauss–Jordan elimination

In linear algebra, Gauss–Jordan elimination is an algorithm for solving systems of linear equations. It is an extension of Gaussian elimination in which the augmented matrix of the system is reduced not merely to row echelon form but to reduced row echelon form, so that the solution can be read off directly. The method is named after Carl Friedrich Gauss and Wilhelm Jordan.

Algorithm

Using elementary row operations — swapping rows, multiplying a row by a nonzero scalar, and adding a multiple of one row to another — the algorithm selects a pivot in each column, scales the pivot row so the pivot becomes 1, and eliminates that variable from all other rows, above as well as below the pivot. The resulting matrix has the identity on the left and the solution vector on the right.

Applications

Besides solving linear systems, Gauss–Jordan elimination is used to compute the inverse of a matrix (by augmenting with the identity matrix), to find the rank of a matrix, and to determine a basis for the null space of a system.

Complexity

For an n×n system the method requires on the order of n³ arithmetic operations, somewhat more than Gaussian elimination with back-substitution, but it is simple to implement and lends itself well to parallel computation.
