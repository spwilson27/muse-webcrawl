Apache Thrift

Apache Thrift is an interface definition language and binary communication protocol used to define and create services for numerous programming languages. It was developed at Facebook, released as open source in 2007, and later became an Apache Software Foundation project.

How it works

Developers describe data types and service interfaces in a Thrift file. The Thrift compiler then generates code for target languages such as C++, Java, Python, PHP, Ruby, Go and others. The generated code handles serialisation and remote procedure calls, allowing services written in different languages to interoperate efficiently.

Design

Thrift combines a software stack with a code generation engine. It supports several transports and protocols, including compact binary formats intended to be more efficient than text-based alternatives. Its type system includes base types, structs, containers and exceptions, with support for versioning fields as schemas evolve.

Comparison

Thrift is often compared with Protocol Buffers and gRPC. All three address cross-language service definition and serialisation, differing in language coverage, RPC support, streaming features and ecosystem conventions.
