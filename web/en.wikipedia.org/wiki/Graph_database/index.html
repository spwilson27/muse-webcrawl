Graph database

A graph database (GDB) is a database that uses graph structures — nodes, edges, and properties — to represent and store data, and that treats relationships as first-class citizens rather than reconstructing them with joins at query time. Graph databases are a central technology of the NoSQL movement and are used where the connections between data matter as much as the data itself.

Models

The dominant model is the labelled property graph, in which nodes and relationships carry labels and key–value properties; it underlies products such as Neo4j, Amazon Neptune, and Microsoft's Azure Cosmos DB. The alternative RDF model stores data as subject–predicate–object triples and is queried with SPARQL; it is standard in semantic-web and knowledge-graph applications, exemplified by Google's Knowledge Graph.

Query languages

Graph query languages focus on pattern matching and traversal. Cypher, originating with Neo4j, became the basis of the openCypher project and influenced the ISO standard GQL, published in 2024 as the first new ISO database query language since SQL. Other languages include Gremlin, from the Apache TinkerPop framework, and SPARQL for RDF stores.

Applications

Graph databases excel at queries involving many hops across relationships, where relational joins become prohibitively expensive: social network analysis, recommendation engines, fraud detection in financial transactions, network and IT operations, supply-chain tracing, and knowledge graphs for search and artificial intelligence.
