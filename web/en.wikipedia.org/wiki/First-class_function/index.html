First-class function

From Wikipedia, the free encyclopedia

First-class functions can be passed as arguments, returned, and assigned to variables.

In computer science, a programming language is said to have first-class functions if it treats functions as first-class citizens. This means the language supports passing functions as arguments to other functions, returning them as the values from other functions, and assigning them to variables or storing them in data structures.

History

The concept was articulated by Christopher Strachey in the 1960s. Languages such as Lisp and Scheme treated functions as first-class from early on; the feature has since spread to JavaScript, Python, Haskell, and most modern languages, including later versions of C++, Java, and C#.

Higher-order functions

Functions that take other functions as arguments or return them are called higher-order functions. Examples include map, filter, and reduce, which apply a supplied function across a collection. First-class functions enable closures, anonymous (lambda) functions, and functional programming patterns such as currying and partial application.
