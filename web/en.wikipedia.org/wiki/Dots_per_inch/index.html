Dots per inch

Dots per inch (DPI, or dpi) is a measure of spatial printing, video, or image scanner dot density, in particular the number of individual dots that can be placed in a line within the span of 1 inch (2.54 cm). Similarly, the more newly introduced dots per centimetre (d/cm or dpcm) refers to the number of individual dots that can be placed within a line of 1 centimetre (≈ 0.393 in).

Printing

In printing, DPI describes the output resolution of a printer: the number of individual dots of ink a press or printer can place within an inch. Historically, desktop laser printers offered 300 dpi, later 600–1200 dpi. High DPI values allow finer halftone reproduction, though effective image quality also depends on the source image resolution, measured in pixels per inch (PPI).

Displays and misuse of the term

"DPI" is widely but loosely applied to display resolution, where pixels per inch (PPI) is the technically correct term. Software such as Windows and Android uses DPI classifications (e.g. logical density buckets) to scale interface elements, so a displayed element's "dots" are logical rather than physical.

Scanners and mice

For scanners, DPI measures sampling resolution (optical vs interpolated). For computer mice, DPI (often marketed as CPI, counts per inch) measures sensitivity — the number of counts reported per inch of mouse movement.
