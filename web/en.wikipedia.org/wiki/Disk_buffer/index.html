Disk buffer

TypeEmbedded memory in storage devices
LocationHard disk drives, optical drives, SSDs
Typical size8 MB – 256 MB (HDDs)
Also calledDisk cache, cache buffer

A disk buffer (also known as a disk cache or cache buffer) is the embedded memory in a hard disk drive or other storage device that acts as a buffer between the computer system and the physical storage medium. It is implemented with fast semiconductor memory on the drive's controller board and is distinct from the operating system's page cache.

Function

The buffer smooths over the mismatch between the speed of the host interface and the mechanical delays of seeking and rotation in a hard drive. On writes, data is accepted quickly into the buffer and written to the platters afterwards ("write-back" caching); on reads, recently or speculatively read data can be served from the buffer without another disk access. Modern controllers reorder queued commands (native command queuing) to use the buffer efficiently.

Size and performance

Hard drive buffer sizes have grown from a few kilobytes in early drives to 64–256 MB in modern ones, usually using DRAM. The buffer is volatile, so some enterprise drives and hybrid drives (SSHDs), which pair a small NAND flash cache with spinning disks, add protection or non-volatile cache to guard against data loss on power failure. In solid-state drives, DRAM buffers similarly hold mapping tables and buffer writes.
