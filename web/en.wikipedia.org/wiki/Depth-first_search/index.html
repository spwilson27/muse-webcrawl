Depth-first search

Depth-first search (DFS) is an algorithm for traversing or searching tree and graph data structures. Starting at a chosen root (or an arbitrary node in a graph), it explores as far as possible along each branch before backtracking. The algorithm is a systematic development of the maze-solving method published by Charles Pierre Trémaux in the 19th century.

Algorithm

DFS can be implemented recursively or iteratively with an explicit stack. Each vertex is marked when first visited so that, in graphs with cycles, no vertex is processed more than once.

DFS(G, v):
    mark v as visited
    for each neighbour w of v:
        if w is not visited:
            DFS(G, w)

For a graph with V vertices and E edges, the running time is O(V + E), and the space requirement is O(V) in the worst case for the recursion stack or explicit stack.

Vertex orderings

Traversals of trees are classified as pre-order, in-order, or post-order according to when a node is recorded relative to the traversal of its subtrees. In directed graphs, DFS yields discovery and finishing times for each vertex, which classify edges as tree, back, forward, or cross edges.

Applications

Depth-first search underpins topological sorting, detection of cycles and strongly connected components (in Kosaraju's and Tarjan's algorithms), maze generation and solving, finding connected components, parsing, and the backtracking search used in constraint satisfaction and game-tree exploration. Its counterpart, breadth-first search, explores vertices level by level instead.
