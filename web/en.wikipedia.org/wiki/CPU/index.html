A central processing unit (CPU), also called a central processor or simply processor, is the electronic circuitry that executes the instructions of a computer program, performing the basic arithmetic, logic, controlling, and input/output operations specified by the instructions. It is the primary processor in a computer, as distinct from auxiliary components such as graphics processing units.

A modern multi-core microprocessor.

Operation

The CPU's operation follows the fetch–decode–execute cycle: the control unit fetches an instruction from memory, decodes it to determine the required action, and executes it using the arithmetic logic unit (ALU) and registers, which hold operands and intermediate results. A clock signal synchronizes operations; clock rate, measured in gigahertz, together with instructions per cycle determines performance.

Design and architecture

A CPU's instruction set architecture (ISA) — such as x86-64, ARM, or RISC-V — defines the instructions it can execute. Modern designs use pipelining, superscalar execution, out-of-order execution, branch prediction, and multiple levels of cache memory to increase throughput. Since about 2005, performance scaling has come mainly from integrating multiple processing cores on a single chip rather than from ever-higher clock rates.

History

Early CPUs were built from vacuum tubes and then discrete transistors; the term dates to the mainframe era. The invention of the integrated circuit led to the microprocessor — famously the Intel 4004 of 1971 — which placed a complete CPU on one chip and enabled personal computers.
