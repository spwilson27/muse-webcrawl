Forward compatibility

Forward compatibility or upward compatibility is a design characteristic that allows a system to accept input intended for a later version of itself. The concept can be applied to entire systems, electrical interfaces, signaling protocols, file formats and programming languages.

Definition

A standard supports forward compatibility if a version of a product can process data generated by a later product, according to the earlier product's specification, and produce a sensible outcome. Technologies designed for forward compatibility are much harder to design than those intended for backward compatibility, because the designer cannot know in advance how the specification will change.

Examples

The HTML specification states that web browsers should ignore unrecognized tags, allowing older browsers to render newer pages approximately. Old versions of the PostScript page description language were also designed to tolerate later extensions. In file formats, tolerant readers ignore unknown chunks or fields, a behaviour popularized by the PNG image format and by XML processors that skip elements they do not understand.

Forward compatibility in standards

Forward compatibility rules form part of the "must ignore unknown" family of conformance strategies, alongside "must forward unknown" and "ignore and override". Such rules trade strictness for evolvability, letting protocols such as XMPP and formats such as Protocol Buffers grow without breaking existing deployments.
