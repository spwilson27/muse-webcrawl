In computer science, the clique problem is the computational problem of finding cliques — subsets of vertices in a graph such that every two distinct vertices are adjacent — in a given undirected graph. The best-known version asks whether a graph contains a clique of a specified size k; this decision problem is NP-complete, one of Richard Karp's original 21 NP-complete problems (1972).

Related problems

  • Maximum clique problem: find the largest clique (NP-hard).
  • Maximal clique enumeration: list all cliques that cannot be extended (Bron–Kerbosch algorithm).
  • Clique cover: partition vertices into the fewest cliques.

Algorithms

Brute-force search over all subsets runs in exponential time. Practical algorithms such as branch-and-bound methods (e.g., those of Tomita and co-workers) and the Bron–Kerbosch algorithm with pivoting solve moderate instances, while approximation is hard: no polynomial-time algorithm can approximate the clique number within a constant factor unless P = NP.

Applications

Cliques model mutually related groups in social networks, protein-interaction networks in bioinformatics, and pattern matching in chemistry; "clique" is also a colloquial term for a close-knit social group.
