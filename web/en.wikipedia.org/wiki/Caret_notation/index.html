Caret notation

Caret notation is a notation for representing control characters in ASCII encoding, using a caret (^) followed by a capital letter or symbol. For example, ^C represents the control character with code 3, generated by holding Ctrl and pressing C.

Caret notation
Purpose: Display of control characters
Form: ^ followed by a character
Examples: ^C (ETX), ^M (CR), ^? (DEL)

Usage

For letters A–Z the notation corresponds to ASCII codes 1–26: ^A is SOH (1), ^I is tab, ^J is line feed, and ^M is carriage return. ^@ is the null character, and ^? is delete (127). Terminals and Unix tools such as cat -v display otherwise invisible control codes in caret notation.

History

The convention dates to early teleprinter and terminal practice, where control codes could not be printed directly. It remains common in documentation of keyboard shortcuts, terminal output, and text editors such as Emacs and Vim.
