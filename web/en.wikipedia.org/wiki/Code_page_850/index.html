Code page 850

Code page 850 (CCSID 850, also known as CP 850, IBM 00850, or OEM 850) is a code page used under DOS and Psion's EPOC16 operating system in Western Europe. It is part of IBM's family of DOS code pages and was designed to support the accented characters needed by most Western European languages more completely than the earlier code page 437, which had been designed primarily for English.

Character set

Like all single-byte DOS code pages, CP 850 retains ASCII in the range 0x00–0x7F and assigns the range 0x80–0xFF to additional characters. Compared with code page 437, it rearranges the accented letters into an order closer to ISO 8859-1 and adds characters required for languages such as French, German, Spanish, Italian, Dutch, Danish, and Norwegian — including À, Â, Ä, È, É, Ê, Ë, Î, Ï, Ô, Ù, Û, Ü, ÿ, Ÿ, and the soft hyphen — at the cost of some of CP 437's Greek letters and line-drawing combinations. A full set of single-weight box-drawing characters is retained, so text-mode interfaces still display correctly.

Usage and legacy

Code page 850 became the default OEM code page for most Western European DOS installations and was commonly selected with the DOS commands MODE CON CP PREPARE and CHCP 850. Under Microsoft Windows, its role was taken over by Windows-1252 for graphical applications, while console windows continued to use OEM code pages; on Western European Windows systems the default console code page remained 850 for many years. With the spread of Unicode and UTF-8, CP 850 survives mainly in legacy data, embedded systems, and terminal configurations. A modified variant, code page 858, replaces the dotless i at 0xD5 with the euro sign (€).
