cut (Unix)

cut is a command line utility on Unix and Unix-like operating systems used to extract sections from each line of input — usually from a file. It is part of the GNU coreutils package and the BSD Base System, and it originated in AT&T Bell Laboratories' System III, one of the early versions of Unix.

Usage

The cut command can extract text by bytes, by characters, or by delimiter-separated fields:

  • cut -b LIST — select only the bytes at the positions given in LIST.
  • cut -c LIST — select only the characters at the positions given in LIST.
  • cut -f LIST [-d DELIM] — select fields; DELIM is the field delimiter (the tab character by default).

Lists may be single positions, ranges such as 1-4, or open-ended ranges such as 5- or -8. The -s option suppresses lines that contain no delimiter character, and --complement inverts the selection.

Examples

$ echo "foo:bar:baz" | cut -d: -f2
bar
$ cut -c1-3 /etc/passwd
roo
dai
...

A common use is extracting columns from structured text files such as /etc/passwd, often in combination with other text utilities in a pipeline. For more complex field processing, administrators generally turn to awk or sed.

History

cut first appeared in System III UNIX and was later standardized by POSIX. The GNU implementation, provided by coreutils, adds conveniences such as the --output-delimiter option.
