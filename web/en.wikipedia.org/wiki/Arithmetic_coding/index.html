Arithmetic coding

From Wikipedia, the free encyclopedia

Arithmetic coding narrows an interval on the number line with each symbol encoded.

Arithmetic coding (AC) is a form of entropy encoding used in lossless data compression. Normally, a string of characters is represented using a fixed number of bits per character, as in the ASCII code. When a string is converted to arithmetic encoding, frequently used characters will be stored with fewer bits and not-so-frequently occurring characters will be stored with more bits, resulting in fewer total bits used. Arithmetic coding differs from other forms of entropy encoding, such as Huffman coding, in that rather than separating the input into component symbols and replacing each with a code, arithmetic coding encodes the entire message into a single number, an arbitrary-precision fraction q where 0.0 ≤ q < 1.0.

How it works

The encoder starts with an interval [0, 1). For each symbol in the message, the interval is subdivided into sub-intervals proportional to the symbol probabilities, and the sub-interval corresponding to the actual symbol becomes the new interval. When all symbols have been processed, any number within the final interval uniquely identifies the message. Because frequent symbols shrink the interval less, the final fraction needs fewer bits for common symbols, and the overall code length approaches the entropy of the source.

Precision and implementation

Practical implementations avoid infinite-precision fractions by using fixed-width integers with renormalization: as the interval narrows, its leading digits become fixed and are output, and the interval is rescaled. Adaptive models update symbol probabilities as data is processed, which makes arithmetic coding the core of many high-performance compressors.

Applications and history

Arithmetic coding underlies compression standards such as JPEG 2000, H.264/AVC and H.265/HEVC (in the form of CABAC, context-adaptive binary arithmetic coding), and DjVu. The basic ideas were developed from Shannon's and Elias's work on coding, with practical algorithms published in the 1970s and 1980s by Rissanen, Langdon, Pasco, and others. Historically, widespread adoption was slowed by patents, most of which have now expired.
