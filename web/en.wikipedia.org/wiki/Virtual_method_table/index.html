Virtual method table

In computer programming, a virtual method table (VMT), virtual function table, vtable, or dispatch table is a mechanism used in a programming language to support dynamic dispatch (run-time method binding). It is the most common implementation of polymorphism in object-oriented languages such as C++, Java, and C#.

Mechanism

For each class that declares or inherits virtual functions, the compiler builds a table of pointers to the most-derived implementations of those functions. Each object of such a class contains a hidden pointer (the vptr) to its class's vtable. A virtual call then consists of loading the vptr, indexing into the table at a fixed offset, and calling through the resulting pointer — a small constant overhead regardless of where the overriding method sits in the inheritance hierarchy.

Details and complications

With multiple inheritance an object may contain several vptrs, and calling code may need to adjust the implicit this pointer. Compilers may devirtualize calls whose target is provably known, and language runtimes may cache lookups. Because vtables are writable data in many implementations, corrupting a vptr is a classic exploitation technique in memory-safety attacks.
