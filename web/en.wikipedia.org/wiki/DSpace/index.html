DSpace

DSpace is an open-source software package typically used for creating open access repositories for published digital content. While DSpace shares some feature overlap with content management and document management systems, it is designed to serve the specific needs of an institutional repository, preserving and providing access to the intellectual output of an institution. Since its first release in 2002, DSpace has been adopted by thousands of universities, libraries, museums, and government agencies worldwide, primarily to host theses, dissertations, journal articles, datasets, and digitised special collections.

History

DSpace was developed jointly by the MIT Libraries and Hewlett-Packard (HP) Labs as the product of a two-year alliance begun in 2000, with HP providing US$1.8 million in research funding. The first public version, DSpace 1.0, was released in November 2002. In 2007 the DSpace Foundation was set up as a not-for-profit organisation to coordinate development and provide support to the user community; in 2009 it merged with Fedora Commons to form DuraSpace, whose services and communities were in turn acquired by LYRASIS in 2019.

Features

DSpace organises content into communities and collections, with items described using qualified Dublin Core metadata. It supports the Open Archives Initiative Protocol for Metadata Harvesting (OAI-PMH), making repository contents discoverable by search engines and aggregators, and assigns persistent identifiers (handles) to items. Deposit workflows support submission review and moderation, and the system provides configurable access controls, usage statistics, full-text indexing, and embargo management. Major releases have modernised the platform: DSpace 7, released in 2021, introduced a new Angular-based user interface and a fully featured REST API; DSpace 8 followed in 2024.

Technology

DSpace is written primarily in Java and runs on a servlet container such as Apache Tomcat, with PostgreSQL (or Oracle) as its database and Apache Solr providing search and discovery. It is distributed under the BSD 3-Clause licence, and development is coordinated on GitHub by a committers group drawn from the user community.
