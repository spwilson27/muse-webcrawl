Quicksort

Quicksort is an efficient, general-purpose sorting algorithm. Quicksort was developed by British computer scientist Tony Hoare in 1959 and published in 1961. It is a divide-and-conquer algorithm that works by selecting a "pivot" element from the array and partitioning the other elements into two sub-arrays, according to whether they are less than or greater than the pivot. The sub-arrays are then sorted recursively.

Algorithm

Quicksort operates in place on an array, using little additional memory. The main steps for a subarray are:

  1. Choose a pivot element.
  2. Partition: reorder the array so that all elements less than the pivot come before it and all elements greater come after it. The pivot is then in its final position.
  3. Recursively sort the two sub-arrays on either side of the pivot.
algorithm quicksort(A, low, high) is
    if low < high then
        p := partition(A, low, high)
        quicksort(A, low, p - 1)
        quicksort(A, p + 1, high)

Complexity

On average, quicksort makes O(n log n) comparisons, and this average-case efficiency has made it one of the most widely used sorting algorithms in practice; it is the basis of the default sort in many standard libraries, including variants such as Introsort and the pattern-defeating pdqsort. In the worst case—for example, sorted input with a naive pivot choice—quicksort makes O(n2) comparisons. Randomised pivot selection, median-of-three strategies, and switching to insertion sort for small subarrays make the worst case unlikely in practice.

Pivot selection and partitioning schemes

Named partition schemes include the Lomuto scheme, simple to implement but prone to more swaps, and Hoare's original scheme, which uses two pointers moving toward each other. Three-way partitioning (the "Dutch national flag" approach, due to Dijkstra) handles many duplicate keys efficiently.

History

Hoare developed quicksort in 1959 while working on machine translation in Moscow, needing to sort words so that sentences could be looked up in a dictionary. He published the algorithm in the Computer Journal in 1961. Robert Sedgewick's 1975 PhD thesis analysed and refined many implementation details, and Jon Bentley and M. Douglas McIlroy's 1993 "Engineering a Sort Function" influenced library implementations. Hoare received the Turing Award in 1980, in part for this work.
