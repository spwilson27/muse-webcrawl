SAE J1939

PublisherSAE International
Physical layerCAN (ISO 11898), typically 250 kbit/s
ApplicationHeavy-duty vehicles, diesel engines, agriculture, construction
Derived standardsISO 11783 (ISOBUS), NMEA 2000

SAE J1939 is a set of standards maintained by SAE International that defines a communications network for heavy-duty vehicles based on the Controller Area Network (CAN). It is widely used in diesel-powered vehicles, trucks, buses, agricultural machinery, and off-highway equipment for communication between electronic control units (ECUs) such as engine, transmission, and braking controllers.

Overview

J1939 uses the extended 29-bit CAN identifier. Each message carries a Parameter Group Number (PGN) that identifies its content, while individual data items within a parameter group are described by Suspect Parameter Numbers (SPNs). The standard defines physical layer options, data link and network layer functions including address claiming, application-layer parameter groups, diagnostics (notably diagnostic messages reporting Diagnostic Trouble Codes), and network management.

The protocol normally operates at 250 kbit/s on a shielded twisted pair, with later revisions supporting 500 kbit/s. Multi-packet messages larger than eight bytes are sent using transport protocol functions defined in the standard.

Parameter groups

Commonly used parameter groups include electronic engine controller messages broadcasting engine speed, torque, coolant temperature, and oil pressure, as well as vehicle speed, cruise control, and transmission data. Manufacturers may also define proprietary parameter groups within reserved ranges.

Applications and related standards

Beyond road vehicles, J1939 forms the basis for ISO 11783 (ISOBUS) in agricultural equipment and for NMEA 2000 in marine electronics. It is also used in generator sets, military vehicles, and rail applications. Diagnostic tools commonly connect through the J1939 9-pin Deutsch connector found on heavy-duty trucks.
