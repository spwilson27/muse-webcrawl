Line code

In telecommunication, a line code is a code chosen for use within a communications system for transmitting a digital signal down a transmission line. This process of coding is performed to avoid signal distortion, to ensure synchronization, and to control the spectrum of the transmitted signal. Line coding is often used for digital data transport.

Properties

A good line code provides transitions that let the receiver recover the clock (self-clocking), removes or controls any residual DC component (which cannot pass through transformers and repeaters), offers some redundancy for error detection, and shapes the signal spectrum to suit the channel bandwidth. The simplest code, unipolar non-return-to-zero (NRZ), is spectrally efficient but has no transitions during long runs of identical bits and can carry a large DC component.

Common line codes

Well-known line codes include return-to-zero (RZ), Manchester coding (used in 10BASE-T Ethernet, guaranteeing a transition in every bit period), biphase codes, alternate mark inversion (AMI) and its derivatives HDB3 and B8ZS used on T-carrier systems, and block codes such as 4B/5B and 8b/10b, which map data bits into code words with guaranteed transition density and DC balance; 64b/66b is used in high-speed Ethernet and serial links. Multilevel schemes such as PAM-4 carry more than one bit per symbol.
