Systematic sampling

Systematic sampling is a statistical method of selecting a sample from an ordered population. The most common form selects a random starting point and then picks every kth element thereafter, where k, the sampling interval, is calculated as the population size divided by the desired sample size.

Procedure

Given a population of N units listed in some order and a desired sample size n, the sampling interval is k = N/n. A random start between 1 and k is chosen, and then every kth unit is selected until the list is exhausted.

Advantages and disadvantages

Systematic sampling is simpler to carry out than simple random sampling and spreads the sample evenly over the population, which can make it more precise when the list order is unrelated to the variable of interest. Its main weakness is vulnerability to periodicity: if the list has a hidden pattern with the same period as the sampling interval, the sample can be badly biased. Because only the starting point is random, variance estimation from a single systematic sample requires special methods.

Applications

The method is widely used in quality control (inspecting every kth item on a production line), forestry, exit polling, and acceptance sampling in manufacturing.
