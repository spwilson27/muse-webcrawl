Information extraction

Information extraction (IE) is the task of automatically extracting structured information from unstructured and semi-structured machine-readable documents, most commonly natural-language text. In most cases the output is a set of entities, relations and events that can be stored in a database and queried, in contrast to information retrieval, which returns whole documents for a human to read.

Subtasks

Core subtasks include named entity recognition (locating and classifying names of people, organisations, places, dates and quantities), coreference resolution (determining which expressions refer to the same entity), relation extraction (finding semantic relations such as "X works for Y"), event extraction, and template filling, in which the results are merged into structured records. The field was driven in the 1990s by the Message Understanding Conferences (MUC) and later the ACE programme.

Methods and applications

Early systems used hand-written rules and gazetteers; modern systems rely on supervised machine learning — sequence labelling with conditional random fields and, more recently, transformer-based neural networks and large language models. Applications include intelligence analysis, biomedical literature mining, financial news processing, customer-support automation and the construction of knowledge bases such as those feeding question-answering systems.
