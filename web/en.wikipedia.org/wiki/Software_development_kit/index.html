A software development kit (SDK), also called a devkit, is a collection of software development tools in one installable package provided by a hardware or software platform vendor so that developers can create applications for that platform. SDKs are provided for building software for specific platforms, programming languages, operating systems, game consoles, or hardware devices.

Contents

An SDK may include any combination of the following:

  • Application programming interfaces (APIs) in the form of libraries of reusable functions, with header files or language bindings.
  • An integrated development environment (IDE), compilers, linkers and other build tools.
  • Debuggers and profiling tools.
  • Emulators or simulators of the target hardware, such as a phone emulator.
  • Documentation, tutorials and sample code.
  • Drivers and utilities for deploying and testing on real devices.

Uses

SDKs are central to modern app ecosystems: the Android SDK and Apple's iOS SDK are required to build mobile apps for those platforms, cloud providers publish SDKs that wrap their web APIs for popular languages, and game console manufacturers license devkits to approved studios. Use of an SDK is typically governed by a licence agreement, which may restrict redistribution or require the resulting software to be distributed through the vendor's store.
