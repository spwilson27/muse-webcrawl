Graphics pipeline

The graphics pipeline (or rendering pipeline) is the sequence of steps used in computer graphics — particularly in real-time 3D rendering — to transform a three-dimensional scene description into a two-dimensional image for display.

Graphics pipeline
Main stagesVertex processing, primitive assembly, rasterisation, fragment processing, output
Programmable stagesVertex, geometry, tessellation, fragment shaders
APIsOpenGL, Direct3D, Vulkan, Metal

Stages

Vertices of 3D models are transformed by model, view, and projection matrices and processed by a vertex shader. Primitives (usually triangles) are assembled, clipped, and rasterised into fragments, which correspond to pixels. A fragment (pixel) shader computes each fragment's colour from lighting, textures, and material properties, after which depth testing and blending merge the result into the framebuffer.

Programmability

Early pipelines were "fixed-function": developers could only configure preset operations. Since the early 2000s, programmable shader stages have progressively replaced fixed functions, enabling custom lighting, post-processing, and general-purpose GPU computing. Modern low-level APIs such as Vulkan expose pipeline state explicitly as precompiled objects.
