International Residential Code

The IRC provides a single model code for one- and two-family dwellings and townhouses.

The International Residential Code (IRC) is a model building code published by the International Code Council (ICC) that provides comprehensive minimum requirements for one- and two-family dwellings and townhouses up to three stories in height. First published in 2000, it is updated on a three-year cycle and has been adopted, in some edition and often with amendments, by most US states and many local jurisdictions.

Contents

Unlike the International Building Code, which covers all other buildings, the IRC is a stand-alone code that combines in one volume the subjects that would otherwise require several codes: building planning and structural requirements (including prescriptive "conventional construction" provisions for wood framing), energy conservation (aligned with the International Energy Conservation Code), plumbing, mechanical systems and fuel gas, and electrical provisions (drawn from NFPA 70, the National Electrical Code). Its prescriptive span tables and standard details allow typical houses to be designed and built without an engineer.

Adoption and use

Because the IRC is a model code, it has legal force only where adopted by a state or local government, which may amend it; adoption cycles vary, so different jurisdictions enforce different editions. The code is written in mandatory, enforceable language and is structured for use by builders, designers, and code officials alike. A companion commentary and study guides are published by the ICC.
