NTFS (New Technology File System) is a proprietary journaling file system developed by Microsoft. It is the default file system of the Windows NT family, starting with Windows NT 3.1 in 1993, and it supplanted the File Allocation Table (FAT) as the preferred file system on Windows.

NTFS reading and writing support is provided by most modern operating systems: Linux and BSD include free and open-source NTFS drivers, and macOS supports read-only access natively, with write support available through third-party software.

History

In the mid-1980s, Microsoft and IBM formed a joint project to create the next generation of graphical operating system, OS/2. IBM's resulting High Performance File System (HPFS) included many features that later appeared in NTFS. When the Microsoft–IBM collaboration broke down, Microsoft's engineers, including Tom Miller, Gary Kimura, Brian Andrew, and David Goebel, developed NTFS for the new Windows NT platform, borrowing heavily from HPFS concepts, including the idea of treating file attributes as extensible metadata.

Windows NT 3.1 shipped with NTFS 1.0 in 1993. Later versions added quotas (NTFS 3.0, with Windows 2000), the Encrypting File System, sparse files, reparse points, and distributed link tracking.

Design

Everything on an NTFS volume — file names, creation dates, access permissions, and even the file data itself — is stored as metadata in the Master File Table (MFT), a specialized relational database of file records. The first 16 records of the MFT are reserved for special metadata files, such as $MFT itself, $MFTMirr (a partial mirror), $LogFile (the journal), and $Bitmap (allocation status).

NTFS uses B-trees to index file system data, supports disk quotas, hard links, symbolic links (from NTFS 3.1), file compression, and file-level encryption through EFS. Access control lists (ACLs) provide fine-grained security permissions.

Interoperability

Though some details of NTFS remain a trade secret, Linux supports NTFS through the in-kernel driver (read and limited write) and the userspace NTFS-3G driver (full read/write). Microsoft's exFAT has largely replaced FAT32 for removable media, but NTFS remains the standard for fixed Windows system volumes.
