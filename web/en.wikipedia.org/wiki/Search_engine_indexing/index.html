Search engine indexing

Search engine indexing is the process by which a search engine collects, parses and stores web content so that it can be retrieved rapidly in response to user queries. Web crawlers (also called spiders or bots) fetch pages by following hyperlinks, respect exclusion directives such as robots.txt and the noindex meta tag, and pass the content to an indexer.

How indexing works

The indexer tokenises text, removes stop words in some designs, and builds an inverted index mapping each term to a list of documents (postings lists) with positions and other signals such as anchor text, term frequency and metadata. Supplementary indexes may store links between pages for ranking algorithms such as PageRank. At query time, the engine looks up the query terms, scores candidate documents and returns ranked results. Keeping the index fresh requires recrawling changed pages, detecting duplicates and spam, and handling content in forms other than HTML.
