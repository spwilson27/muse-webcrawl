Hypervisor

A hypervisor presents virtual hardware platforms to multiple guest operating systems.

A hypervisor, also known as a virtual machine monitor (VMM), is a type of computer software, firmware or hardware that creates and runs virtual machines. A computer on which a hypervisor runs one or more virtual machines is called a host machine, and each virtual machine is called a guest machine. The hypervisor presents the guest operating systems with a virtual operating platform and manages the execution of the guest operating systems.

Unlike an emulator, which emulates a different instruction set, most hypervisors run guest code directly on the host CPU, using hardware-assisted virtualisation features to maintain isolation and performance.

Classification

Gerald J. Popek and Robert P. Goldberg classified hypervisors into two types in 1974:

  • Type-1, native or bare-metal hypervisors run directly on the host's hardware and act as the host operating system. Examples include VMware ESXi, Microsoft Hyper-V, Xen, and the Linux-based KVM when configured as the host kernel.
  • Type-2 or hosted hypervisors run as applications on top of a conventional operating system. Examples include VMware Workstation, Oracle VirtualBox, and QEMU.

History

Hypervisors originated on mainframe computers in the 1960s. IBM's CP/CMS system, developed at the Cambridge Scientific Center, demonstrated that a control program could provide each user with a complete virtual machine. The concept was commercialised in IBM's VM/370 in 1972. Virtualisation later spread to x86 servers in the late 1990s and 2000s, driven by server consolidation, and became a foundation of cloud computing.

Hardware assistance

Modern processors provide extensions — Intel VT-x and AMD-V — that allow hypervisors to run guest code in a separate execution mode and trap privileged operations efficiently. Second-level address translation (Intel EPT, AMD NPT) reduces the memory virtualisation overhead that earlier shadow page table techniques imposed.

Uses

Hypervisors are used for server consolidation, cloud infrastructure, software testing and development, running legacy operating systems, desktop virtualisation, and security research such as malware analysis in isolated sandboxes.
