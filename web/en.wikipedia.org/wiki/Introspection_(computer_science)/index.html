Introspection (computer science)

In computing, introspection (also called type introspection) is the ability of a program to examine the type or properties of an object at runtime. It depends on the language and programming environment; some languages possess it intrinsically, while others require the programmer to implement it.

Examples

Dynamic languages such as Python, Ruby, Smalltalk and JavaScript offer rich introspection: Python's type(), dir() and hasattr() functions reveal an object's class, attributes and methods, and Ruby's methods and respond_to? serve the same purpose. In Java, the reflection API permits loading classes and examining and invoking their members dynamically.

Reflection

Introspection is closely related to reflection, which goes further by allowing a program to modify its own structure and behaviour at runtime — for example, invoking methods by name or constructing objects of classes unknown at compile time. Reflection underlies frameworks for dependency injection, serialization, testing mocks and object-relational mapping.

Uses

Introspection supports generic serialization and deserialization, interactive programming environments and REPLs, debugging and profiling tools, plugin architectures, and duck typing, in which an object's suitability for an operation is determined by its observed methods rather than its declared class.
