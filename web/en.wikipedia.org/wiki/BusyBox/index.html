BusyBox

DeveloperBruce Perens (original); community
Initial release1999
Written inC

Nickname"The Swiss Army Knife of Embedded Linux"

BusyBox combines tiny versions of many Unix utilities into one executable.

BusyBox is a software suite that provides several Unix utilities in a single executable file. It runs in a variety of POSIX environments such as Linux and Android, and is designed for embedded systems with limited storage and memory.

Design

BusyBox implements stripped-down versions of hundreds of commands — a shell, ls, cp, grep, tar, an init system, and networking tools among them — sharing code in one binary of typically a megabyte or less. The program behaves according to the name under which it is invoked, through symbolic links created at installation. Its modular build lets developers include only the applets they need.

History and use

Originally written by Bruce Perens in 1996 for the Debian installer, BusyBox became the standard userland for embedded Linux and is found in routers, set-top boxes, rescue disks, and container base images. It is also notable in free-software licensing: enforcement actions by the Software Freedom Law Center against companies shipping BusyBox in products without providing source code were among the most prominent GPL enforcement cases of the 2000s.
