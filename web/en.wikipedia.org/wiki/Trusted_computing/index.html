Trusted computing

Trusted computing (TC) is a technology developed and promoted by the Trusted Computing Group (TCG). It aims to enforce consistent behaviour in computers by loading hardware with a unique, manufacturer-endorsed encryption key inaccessible to the rest of the system, so that the platform can provide verifiable reports — known as remote attestation — about the software it is running.

Core technologies

The centrepiece is the Trusted Platform Module (TPM), a chip (or firmware equivalent) that provides secure key storage, platform configuration registers recording measurements of the boot process, sealed storage bound to platform state, and attestation keys. Related mechanisms include measured and secure boot, memory curtaining and protected input/output. TPM 2.0 chips are mandated by Microsoft for Windows 11.

Applications

Trusted computing underpins full-disk encryption systems such as BitLocker, digital rights management, anti-cheat systems in games, protection against bootkits, and enterprise device-health attestation used in zero-trust network architectures.

Criticism

Critics, including the Free Software Foundation and cryptographer Bruce Schneier, have argued that trusted computing can shift control of a computer from its owner to software vendors and content providers — sometimes called "treacherous computing" — potentially locking users in, enforcing censorship or preventing interoperability. The TCG responds that owners retain override controls and that attestation discloses, rather than dictates, platform state.
