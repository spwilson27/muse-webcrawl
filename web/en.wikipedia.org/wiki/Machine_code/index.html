Machine code

In computer programming, machine code is computer code consisting of machine language instructions, which are used to control a computer's central processing unit (CPU). For conventional binary computers, machine code is the binary representation of a computer program which is actually read and interpreted by the computer. A program in machine code consists of a sequence of machine instructions (possibly interspersed with data).

Each instruction causes the CPU to perform a very specific task, such as a load, a store, a jump, or an arithmetic logic unit (ALU) operation on one or more units of data in the CPU's registers or memory. Machine code is a strictly numerical language, and is the lowest-level representation of a compiled or assembled computer program.

Instruction sets

Every processor or family of processors has its own instruction set architecture (ISA), defining the set of machine instructions it can execute, their encodings (opcodes), registers, and addressing modes. Well-known ISAs include x86-64, ARM, RISC-V, and MIPS. An instruction typically consists of an opcode specifying the operation, together with fields identifying operands such as registers or memory addresses.

Relationship to assembly language

Machine code is usually represented for human reading as assembly language, in which instructions are written with mnemonic names (such as MOV, ADD, or JMP) corresponding one-to-one with the underlying machine instructions. An assembler translates assembly language into machine code, while a disassembler performs the reverse operation. Programs written in high-level languages are compiled into machine code, either ahead of time or just-in-time at runtime.

Example

On the MIPS architecture, the instruction add $t0, $t1, $t2 (add the contents of registers $t1 and $t2, storing the result in $t0) is encoded as the 32-bit machine instruction 0x012A4020. On x86, the single byte 0x90 encodes the NOP (no operation) instruction.
