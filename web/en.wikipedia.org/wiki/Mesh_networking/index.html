Mesh networking

Mesh networking is a local network topology in which infrastructure nodes (such as bridges, switches and wireless access points) connect directly, dynamically and non-hierarchically to as many other nodes as possible, cooperating to efficiently route data to and from clients. This organisation allows for continuous connections and reconfiguration around broken or blocked paths by "hopping" from node to node until the destination is reached.

Characteristics

A mesh network is self-healing: when one node fails, the rest can still communicate, and traffic is automatically rerouted. Mesh networks may be full mesh, where every node connects to every other, or partial mesh, where nodes connect to only some others. Wireless mesh networks use radio links and are applied in home Wi-Fi systems, community networks, disaster recovery and military communications.

Protocols

Routing in mesh networks uses protocols such as BATMAN, OLSR (Optimised Link State Routing) and HWMP, the default path selection protocol of IEEE 802.11s. Commercial home systems from vendors such as Eero, Google Nest Wifi and Netgear Orbi popularised Wi-Fi mesh for residential coverage.
