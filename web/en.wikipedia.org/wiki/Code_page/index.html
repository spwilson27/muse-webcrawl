Code page

Characters of code page 437, the original IBM PC character set.

In computing, a code page is a character encoding that associates a specific set of printable characters and control codes with a specific set of numeric code values. The term became widespread through IBM and Microsoft documentation, which numbered code pages for the character sets used by their systems; each code page is identified by an integer, such as code page 437 for the original IBM PC character set or code page 1252 for the Western European Windows character set.

History

Early personal computers used 8-bit encodings: the lower 128 values matched ASCII, while the upper 128 provided letters with diacritics for particular languages, or, in the case of code page 437, mathematical symbols and box-drawing characters. Because one byte could encode only 256 characters, different languages and regions needed different code pages: 850 for Western European DOS, 852 for Central Europe, 866 for Cyrillic, and the Windows "ANSI" code pages 1250–1258 for different scripts. Text exchanged between systems using different code pages produced garbled output, a phenomenon known as mojibake.

Transition to Unicode

The rise of Unicode and its UTF-8 encoding, which can represent virtually all of the world's scripts in a single encoding, has largely superseded code pages for new systems. However, code pages remain in use in legacy applications, file formats, console windows, and embedded devices, and operating systems still support them for backward compatibility.
