Microsoft FreeCell

Microsoft FreeCell is a computer game included with Microsoft Windows, based on the solitaire card game FreeCell. It was first included in Windows NT 3.1 as part of the Microsoft Entertainment Pack and has shipped with most versions of Windows since Windows 95, making it one of the most widely played computer games.

Gameplay

FreeCell is played with a standard 52-card deck dealt face up into eight tableau cascades. Four "free cells" hold cards temporarily and four foundation piles are built up by suit from ace to king. Unlike most solitaire games, nearly all FreeCell deals are solvable; in the original Windows implementation, deal number 11982 is famously the only unsolvable one among the first 32,000 numbered games.

History

The Windows version was written by Jim Horne. Later Windows versions expanded the number of deals to one million, added statistics and undo features, and eventually moved the game into the Microsoft Solitaire Collection with daily challenges and additional game modes.
