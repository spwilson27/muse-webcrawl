The Portable Document Format (PDF) is a file format developed by Adobe in 1992 to present documents, including text formatting and images, in a manner independent of application software, hardware, and operating systems. Based on the PostScript language, each PDF file encapsulates a complete description of a fixed-layout flat document, including the text, fonts, vector graphics, raster images and other information needed to display it.

PDF was standardized as ISO 32000 in 2008. It remains one of the most widely used formats for distributing documents over the Internet, for printing, and for long-term archiving in its PDF/A profile.

History

PDF originated in the "Camelot" project begun by Adobe co-founder John Warnock in 1990. The goal was a universal way to communicate documents across large companies and across computing platforms. Adobe released the format with Acrobat 1.0 in June 1993 as a proprietary format, initially charging for the tools needed to create files, and published the PDF Reference so that other vendors could implement it.

Early versions were aimed at print workflows and office documents. PDF 1.3 (1999) added support for forms and transparency arrived in PDF 1.4 (2001) with Acrobat 5. PDF 1.5 introduced optional content groups ("layers") and JPEG 2000 compression; PDF 1.6 and 1.7 added 3D content, embedded files, and richer encryption. In 2007 Adobe released PDF 1.7 to ISO, which published it as ISO 32000-1:2008. ISO 32000-2:2017 defines "PDF 2.0", the first version developed entirely within the ISO process.

Technical overview

File structure

A PDF file consists of a header identifying the version, a body of indirect objects (dictionaries, arrays, streams and other primitives), a cross-reference table (or cross-reference stream) giving the byte offset of each object, and a trailer pointing to the root catalog object. Since PDF 1.5, objects can be collected into compressed object streams, considerably reducing file size.

Content and graphics model

Page content is a sequence of operators drawn from a PostScript-like stack-based language. Text is drawn using embedded or standard fonts; PDF supports Type 1, TrueType, OpenType and CID-keyed fonts, with font subsets commonly embedded so documents display correctly anywhere. The imaging model supports vector paths, clipping, transparency groups, blend modes, and color spaces including DeviceGray, DeviceRGB, DeviceCMYK, ICC-based profiles and spot colors.

Interactive features

PDF supports hyperlinks, document outlines (bookmarks), annotations, form fields (AcroForms), digital signatures, file attachments, multimedia and JavaScript actions. The XFA forms technology, used in some government workflows, is deprecated in PDF 2.0.

Standardized subsets

  • PDF/A (ISO 19005) — for long-term archiving; requires embedded fonts and device-independent color, and forbids encryption and external dependencies.
  • PDF/X (ISO 15930) — for prepress and print production exchange.
  • PDF/E (ISO 24517) — for engineering documents.
  • PDF/UA (ISO 14289) — for universally accessible, tagged documents.
  • PDF/VT (ISO 16612-2) — for variable and transactional printing.

Security

PDF files can be encrypted with passwords controlling opening, printing, copying and editing, historically using RC4 and later AES up to 256-bit in modern revisions. Digital signatures based on public-key cryptography can authenticate the signer and detect modification. Because the format is rich, malformed PDFs and embedded scripts have historically been exploited, and most modern readers sandbox rendering and disable JavaScript by default.
