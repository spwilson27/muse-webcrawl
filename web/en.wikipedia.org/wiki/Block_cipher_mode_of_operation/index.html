Block cipher mode of operation

In cryptography, a block cipher mode of operation is an algorithm that uses a block cipher — which by itself encrypts only a single fixed-size block of data under a key — to securely encrypt messages of arbitrary length. Modes also determine how errors propagate, whether encryption can be parallelised, and whether identical plaintext blocks produce identical ciphertext.

Common modes

Electronic codebook (ECB) encrypts each block independently. It is insecure for most purposes because patterns in the plaintext remain visible in the ciphertext — famously illustrated by an image whose outline remains recognisable when ECB-encrypted.

Cipher block chaining (CBC) XORs each plaintext block with the previous ciphertext block before encryption, starting from a random initialisation vector (IV). CBC was widely used in TLS and disk encryption but decryption of chosen ciphertexts can be vulnerable to padding oracle attacks.

Cipher feedback (CFB) and output feedback (OFB) turn a block cipher into a self-synchronising or synchronous stream cipher respectively. Counter mode (CTR) encrypts successive values of a counter and XORs the result with the plaintext, allowing random access and full parallelisation; it requires that a nonce–counter combination never be reused with the same key.

Authenticated modes

Modern practice favours authenticated encryption modes that provide confidentiality and integrity together, such as Galois/Counter Mode (GCM), which combines CTR encryption with a polynomial hash, and the XTS mode specialised for storage devices. NIST standardises modes in its SP 800-38 series of publications.
