SoundFont

SoundFont
File extension: .sf2, .sf3, .sfArk, .sfpack
Developed by: E-mu Systems / Creative Technology
Introduced: Early 1990s (SoundFont 1.0/2.0)
Type: Sample-based instrument bank format

SoundFont is a brand name and file format for sample-based instrument banks used to render MIDI music. Developed by E-mu Systems and Creative Technology in the early 1990s, a SoundFont file bundles sampled sounds ("instruments" and "presets") with articulation data — key ranges, velocity layers, loops and envelopes — that a synthesiser maps to MIDI notes.

History

SoundFonts shipped with Creative's Sound Blaster AWE32 and later sound cards, whose onboard RAM let users replace the default instrument set with their own. The SoundFont 2.0 specification became a de facto standard, supported by software synthesisers such as FluidSynth and by many DAWs and media players. Community-created banks range from compact General MIDI sets to orchestral collections of many gigabytes.

Technical outline

An SF2 file is a RIFF container holding sample data (typically 16-bit PCM) plus a hierarchy of presets, instruments, zones and modulators. Variants include SF3 (using Ogg Vorbis-compressed samples) and compressed distribution formats such as sfArk and sfpack. Though largely superseded by large sampled libraries and formats like SFZ, SoundFonts remain popular for retro game music and lightweight playback.
