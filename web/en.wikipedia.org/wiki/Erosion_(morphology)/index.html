Erosion (morphology)

Erosion of a binary image by a structuring element (image placeholder)

Erosion (usually represented by ⊖) is one of two fundamental operations — the other being dilation — in morphological image processing. It is based on Minkowski subtraction and applies a structuring element to an input image, changing the shape of the objects within it.

Binary erosion

The erosion of a binary image A by a structuring element B is defined as the set of points z such that B translated by z is contained in A: A ⊖ B = { z | Bz ⊆ A }. Intuitively, the structuring element is "fitted" inside the object: erosion shrinks foreground regions, enlarges holes, and removes small protrusions and isolated specks.

Grayscale erosion

For grayscale images, erosion with a flat structuring element takes the minimum value of the image within the window covered by the structuring element at each position, darkening the image and shrinking bright features. Erosion is the dual of dilation under complementation: eroding the foreground is equivalent to dilating the background.

Applications

Erosion is used to remove noise, separate touching objects, and, in combination with dilation, to build higher-level operations such as opening, closing, morphological gradients and the hit-or-miss transform.
