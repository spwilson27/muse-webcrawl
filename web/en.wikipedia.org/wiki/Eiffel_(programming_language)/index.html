Eiffel is an object-oriented programming language designed by Bertrand Meyer and the company Eiffel Software, first released in 1986. It is named after Gustave Eiffel, builder of the Eiffel Tower, in reference to the tower's construction being completed on time and under budget. Eiffel is built around the methodology of Design by Contract and aims at reliability in large software systems.

Eiffel emphasises correctness through contracts.

Design by Contract

Eiffel's signature feature is built-in contract support: routines declare preconditions (require), postconditions (ensure) and classes declare invariants, which are checked at runtime and serve as documentation and specifications. Contracts interact carefully with inheritance, strengthening and weakening rules in subtypes.

Language features

Eiffel is a purely class-based language with multiple inheritance (with renaming and redefinition to resolve conflicts), generic classes, void safety (null-pointer safety enforced by the type system since the standardisation), agents (closures), and a uniform syntax in which everything — including basic types — is an object or expanded value. Code is organised into classes grouped in clusters; a typical "Hello, world" derives from a root class whose creation procedure prints the message.

class HELLO_WORLD
create make
feature make do print ("Hello, world!%N") end
end

Standardisation and implementations

Eiffel was standardised as ECMA-367 in 2005 and adopted as ISO/IEC 25436:2006. The main implementation is EiffelStudio, an open-source development environment; the language has seen use in finance, aerospace and telecommunications, and its ideas — especially contracts — have influenced other languages and tools.
