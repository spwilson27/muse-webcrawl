Subset sum problem

The subset sum problem (SSP) is a well-known problem in computer science and combinatorics: given a set (or multiset) of integers and a target sum, determine whether any non-empty subset of the integers sums exactly to the target. For example, given the set {−7, −3, −2, 5, 8} and target 0, the answer is yes because the subset {−3, −2, 5} sums to zero.

Complexity and algorithms

Subset sum is one of Richard Karp's 21 NP-complete problems (1972). In the worst case it can be solved in exponential time — the Horowitz–Sahni algorithm runs in O(2n/2) using a meet-in-the-middle technique — but there is also a pseudo-polynomial dynamic programming algorithm whose running time is polynomial in the magnitude of the target sum. The problem underlies the knapsack problem and was the basis of early public-key cryptosystems such as the Merkle–Hellman knapsack cryptosystem.

Variants

Variants include the decision, counting, and optimisation versions, the bounded subset sum with repeated elements, and the equal-subset-sum (partition) problem, in which the target is half the total sum.
