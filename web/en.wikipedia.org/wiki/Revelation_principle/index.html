Revelation principle

The revelation principle is a fundamental principle in mechanism design and game theory. It states that if a social choice function can be implemented by some (arbitrary) mechanism, then the same function can be implemented by an incentive-compatible direct mechanism (i.e., one in which players truthfully report their types), with the same outcome.

Intuition

Suppose a designer wants to implement some outcome rule but the agents hold private information. In any mechanism that implements the rule, agents' strategic behavior leads to an equilibrium in which their messages effectively encode their types. The designer can therefore bypass the complicated game: simply ask agents to report their types directly, then simulate what they would have done in the original mechanism and select the corresponding outcome. Because reporting truthfully replicates equilibrium behavior, no agent gains by lying, so the direct mechanism is incentive compatible.

Significance

The revelation principle, developed in work by Allan Gibbard, Roger Myerson, and others in the 1970s, greatly simplifies the analysis of mechanism design problems. Instead of searching over all possible mechanisms — with arbitrary message spaces and game forms — theorists can restrict attention to direct, truthful mechanisms and characterize which social choice functions are incentive compatible. The principle underlies classic results such as Myerson's optimal auction theory and the analysis of efficient trade with private information.
