TypeProgramming language interpreter

CPython is the reference implementation of the Python programming language. Written in C and Python, it is the most widely used Python interpreter and the one most people mean when they refer to 'Python'.

CPython compiles Python source code into bytecode, which is then executed by a virtual machine. It exposes a C API that allows extension modules to be written in C, giving access to a large ecosystem of libraries such as NumPy.

History

CPython originated with Guido van Rossum's original implementation of Python in 1989 at Centrum Wiskunde & Informatica in the Netherlands. It has been developed continuously since, with major milestones including Python 2.0 in 2000 and Python 3.0 in 2008.

Implementation

The interpreter uses a global interpreter lock (GIL) that allows only one thread to execute Python bytecode at a time, simplifying memory management through reference counting. Recent versions have added a specializing adaptive interpreter and experimental support for removing the GIL.

Distribution

CPython is distributed for Windows, macOS, and Linux, and is included by default in most Linux distributions and macOS developer tools. Source releases and installers are published by the Python Software Foundation.
