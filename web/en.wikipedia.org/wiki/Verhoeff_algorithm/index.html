Verhoeff algorithm

The Verhoeff algorithm is a checksum formula for error detection, published in 1969 by the Dutch mathematician Jacobus Verhoeff. It was the first decimal check-digit system that detects all single-digit errors and all transpositions of adjacent digits — the two most common transcription errors — which simpler schemes such as the Luhn algorithm cannot fully achieve.

How it works

The algorithm works in the dihedral group D5 (the symmetries of a pentagon) instead of ordinary modular arithmetic. It uses three precomputed tables: a multiplication table for the group, a permutation table applied according to each digit's position, and an inverse table used to generate the check digit. Digits are processed right to left, permuted by position, and combined with the group operation; a valid number yields zero, and the check digit is chosen so that appending it makes the whole string validate.

Uses

Verhoeff's scheme is used notably in India's Aadhaar national identity numbers. Its cost is slightly more computation than Luhn, but its complete detection of transpositions — about the most frequent human copying error — made it influential in the design of later check-digit systems.
