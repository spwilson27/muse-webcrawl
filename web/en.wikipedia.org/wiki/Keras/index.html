Keras

Keras
Original author: François Chollet
Initial release: 2015
Written in: Python
License: Apache-2.0

Keras is an open-source library providing a Python interface for artificial neural networks. It acts as a high-level interface for building and training deep learning models and supports multiple backends including TensorFlow, JAX and PyTorch.

History

François Chollet released Keras in 2015, emphasising user-friendliness, modularity and extensibility. In 2017 Google's TensorFlow team adopted Keras as TensorFlow's official high-level API (tf.keras). Keras 3, launched in 2023, restored full multi-backend support.

Features

Keras provides the Sequential API for simple stacks of layers and the Functional API for complex architectures, along with pre-built layers, optimisers, callbacks and pre-trained models via Keras Applications.
