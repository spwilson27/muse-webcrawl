Robot Operating System

The Robot Operating System (ROS) is an open-source robotics middleware framework. Despite its name, ROS is not a true operating system but a structured communications layer above the host operating system of a computer, providing services designed for a heterogeneous computer cluster such as hardware abstraction, low-level device control, implementation of commonly used functionality, message-passing between processes, and package management.

History

ROS began in 2007 at Stanford University's Artificial Intelligence Laboratory, in the context of the STAIR project, and was developed from 2008 at the robotics company Willow Garage, which released ROS 1.0 in 2010. Stewardship passed to the Open Source Robotics Foundation (now Open Robotics). ROS 2, a major re-architecture built on the Data Distribution Service (DDS) for real-time and commercial use, began rolling out in 2017 with the Ardent Apalone release.

Design

A ROS system consists of processes called nodes that communicate by publishing and subscribing to named topics, or through services and actions. Tools include rosbag for recording and playback, RViz for visualisation, and the Gazebo simulator. ROS software is organised in packages and stacks, and a large ecosystem of community-contributed drivers and algorithms makes ROS the de facto standard in research robotics.
