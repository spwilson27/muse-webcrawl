Grid (graphic design)

In graphic design, a grid is a structure made up of a series of intersecting straight (vertical, horizontal, and angular) or curved lines used to structure content. It serves as an armature or framework on which a designer can organize graphic elements (images, glyphs, paragraphs, etc.) in a rational, easy-to-absorb manner.

History

Although grid systems have precedents in manuscript layout and early printing, their systematic use in modern design developed in Switzerland after the Second World War. Designers of the International Typographic Style — among them Josef Müller-Brockmann, whose book Grid Systems in Graphic Design (1981) became the classic reference — treated the grid as an ordering system that embodied objectivity and clarity.

Types of grids

Common grid types include the manuscript grid (a simple rectangle defining the text block), the column grid (multiple vertical columns separated by gutters), the modular grid (columns combined with horizontal rows into modules), and the hierarchical grid (an irregular structure fitted to the content). The baseline grid aligns text across columns to a common rhythm of line spacing.

Use in digital design

Grids underpin modern page layout software and web design. Responsive web frameworks divide the screen into fluid columns that reflow across breakpoints, and CSS Grid and Flexbox give designers direct control of two-dimensional layout. Designers also deliberately break the grid for emphasis, though such departures are usually most effective against an established order.
