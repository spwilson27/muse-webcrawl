Apache CouchDB

Apache CouchDB is an open-source document-oriented NoSQL database system, written primarily in Erlang and developed by the Apache Software Foundation. It stores data as JSON documents, is queried using JavaScript-based map-reduce views, and is accessed through an HTTP RESTful API.

Features

CouchDB's name is an acronym for "cluster of unreliable commodity hardware", reflecting its design for scalability and fault tolerance. It uses multi-version concurrency control (MVCC), so reads never block writes, and features incremental, bi-directional replication with conflict detection — making it well suited to offline-first applications that synchronise between devices and servers when connectivity is available. Its companion replication protocol inspired compatible projects such as PouchDB, which runs in web browsers.

History

CouchDB was created by Damien Katz, a former Lotus Notes developer at IBM, and was released as an Apache top-level project in 2008. The database influenced the development of the wider NoSQL movement and of JSON document stores.
