Global Forecast System

The Global Forecast System (GFS) is a global numerical weather prediction system containing a global computer model and variational analysis run by the United States' National Weather Service (NWS). The model is run four times a day (00, 06, 12 and 18 UTC) and produces forecasts for up to 16 days in advance. Its output, unlike that of the European ECMWF model, is freely available worldwide and forms the basis for many commercial and academic weather products.

Model

The GFS uses a finite-volume cubed-sphere dynamical core (FV3), adopted operationally in June 2019, which replaced the long-used spectral core. In its current configuration the deterministic model runs at a horizontal resolution of roughly 13 km with 127 vertical levels. Data assimilation uses a hybrid four-dimensional ensemble-variational system drawing on the Global Data Assimilation System (GDAS).

Ensemble

The Global Ensemble Forecast System (GEFS) is the ensemble counterpart of the GFS, run with multiple perturbed members at coarser resolution to estimate forecast uncertainty. It was extended to 35-day forecasts with the version 12 upgrade in 2020.

Use and performance

GFS data are distributed through NOAA's NOMADS servers in GRIB2 format. The model is widely used by forecasters, researchers and hobbyists, though in medium-range verification it has historically scored somewhat below the ECMWF Integrated Forecasting System, prompting ongoing upgrades to physics and data assimilation.
