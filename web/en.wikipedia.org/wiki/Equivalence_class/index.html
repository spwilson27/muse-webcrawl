Equivalence class

In mathematics, an equivalence class is a subset of a set formed by grouping together all elements that are equivalent to one another under a given equivalence relation. Given a set X and an equivalence relation ~ on it, the equivalence class of an element a is the set [a] = { x ∈ X : x ~ a }.

Properties

Equivalence classes of a set form a partition: every element belongs to exactly one class, distinct classes are disjoint, and the union of all classes is the whole set. Any element of a class can serve as a representative of that class. The set of all equivalence classes is called the quotient set, written X / ~.

Examples

A standard example is congruence modulo n on the integers: the equivalence classes are the residue classes, such as the class of even numbers and the class of odd numbers for n = 2. Rational numbers can be constructed as equivalence classes of pairs of integers under the relation (a, b) ~ (c, d) when ad = bc.
