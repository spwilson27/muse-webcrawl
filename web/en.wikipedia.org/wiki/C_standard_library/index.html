C standard library

C standard library (libc)

StandardizedANSI C (1989), ISO C90 and successors

The C standard library, or libc, is the standard library for the C programming language, as specified in the ISO C standard. It provides macros, type definitions, and functions for tasks such as input/output, string handling, mathematics, memory management, and date and time manipulation, declared in a set of header files.

The C standard library is organized into header files such as stdio.h and stdlib.h.

Contents

The original ANSI C standard (1989) defined 15 headers; amendments and later standards (C95, C99, C11) raised the count to 29. Frequently used headers include <stdio.h> (printf, fopen), <stdlib.h> (malloc, exit, atoi), <string.h> (memcpy, strlen), <math.h> (sin, sqrt), and <time.h>. The standard specifies the library for both hosted environments (with an operating system) and freestanding environments (such as embedded kernels), for which only a small subset is required.

Implementations

On Linux the dominant implementation is the GNU C Library (glibc), alongside the lightweight musl; BSD systems ship their own libc, and Microsoft Windows provides the Microsoft C run-time library. Because nearly every other language runtime ultimately calls into libc on Unix-like systems, it is a foundational component of the software stack.
