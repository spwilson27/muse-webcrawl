Visual Basic (VB), originally called Visual Basic .NET (VB.NET), is a multi-paradigm, object-oriented programming language developed by Microsoft and implemented on .NET, Mono, and the .NET Framework. It is the successor to the classic Visual Basic language (last released as Visual Basic 6.0 in 1998) and was first released in 2002 alongside C# as one of the flagship languages of the .NET platform.

Overview

Visual Basic shares the .NET Common Language Runtime and class libraries with C#, so programs in the two languages compile to the same intermediate language and are usually functionally equivalent, differing mainly in syntax. Visual Basic retains the approachable, English-like syntax of its predecessor:

Module Program
    Sub Main()
        Console.WriteLine("Hello, World!")
    End Sub
End Module

Features added over successive versions include generics (2005), LINQ and lambda expressions (2008), asynchronous programming with Async/Await (2012), and tuples and pattern-like constructs in later releases. The language is used for Windows desktop applications (Windows Forms, WPF), web applications (ASP.NET), and Office automation.

History and status

The transition from Visual Basic 6 to VB.NET was controversial: the new language dropped or changed several familiar constructs and was not backward-compatible, prompting a vocal community campaign. Although VB.NET long remained among the most widely used programming languages, Microsoft has since centred its investment on C#. In 2020 Microsoft announced that Visual Basic would continue to be supported on .NET 5 and beyond but that the language would no longer receive new features, and new project templates were gradually removed from some workloads.
