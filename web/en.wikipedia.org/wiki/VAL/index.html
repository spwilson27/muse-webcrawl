VAL

VAL is a robot programming language developed in the late 1970s for the Unimation PUMA series of industrial robot arms. Created under the supervision of Bruce Shimano at Unimation, with roots in work at MIT, VAL (an abbreviation of Variable Assembly Language) was one of the first commercially successful languages for controlling industrial robots and strongly influenced later robot programming systems.

Features

VAL combined a real-time operating system and interactive interpreter with motion commands. Programs could be typed and executed interactively, taught positions could be stored as location variables, and the system continuously generated trajectories so that several motions could be blended together. Key instructions included:

  • MOVE — move the arm to a stored location along a computed joint-interpolated path.
  • MOVES — move in a straight line (Cartesian interpolation).
  • HERE — define the current arm position as a named location.
  • SPEED — set the speed of subsequent motions.
  • OPEN and CLOSE — operate the gripper.

Legacy

VAL's successor, VAL II, added features such as program flow control, sensor interaction, and rudimentary vision support, and was used throughout the 1980s. VAL established the pattern of text-based teach-and-program interfaces that subsequent languages, including Adept's V+, followed.
