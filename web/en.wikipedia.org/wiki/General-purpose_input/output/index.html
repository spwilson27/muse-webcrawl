General-purpose input/output

[Image placeholder: GPIO header pins]

General-purpose input/output (GPIO) is a generic pin on an integrated circuit or computer board whose behaviour — whether it functions as an input or an output, and its logic state — is controlled by the user at run time rather than being dedicated to a fixed function. GPIO pins have no predefined purpose and are typically left unconnected by default on specialised chips.

Usage

GPIO is ubiquitous in embedded systems, microcontrollers, and single-board computers such as the Raspberry Pi, whose 40-pin header exposes GPIO lines that hobbyists and engineers use to drive LEDs, read switches and sensors, and bit-bang communication protocols. In software, pins are configured as inputs (often with configurable pull-up or pull-down resistors) or push-pull/open-drain outputs; many support interrupts on state changes and alternate functions such as PWM output.

Characteristics

GPIO pins operate at the logic voltage of the device (commonly 3.3 V or 5 V) and can source or sink only small currents — typically a few milliamps to a few tens of milliamps — so external drivers or transistors are needed for motors, relays, and other heavy loads. On Linux systems, GPIO has historically been accessed through the sysfs interface and more recently through the character-device libgpiod API.
