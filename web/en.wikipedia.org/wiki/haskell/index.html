Haskell

Haskell is a general-purpose, statically-typed, purely functional programming language with type inference and lazy evaluation. Designed for teaching, research, and industrial application, Haskell has pioneered features such as type classes and monads that have influenced many other languages.

ParadigmFunctional, lazy, modular

Major implementationGHC

History

Haskell was formed by a committee following the release of the Miranda programming language; the first version was defined in 1990. The Haskell 2010 standard is the most recent widely implemented revision of the language report. It is named after logician Haskell Curry.

Features

Haskell is purely functional: functions have no side effects, with effects such as I/O encapsulated in monads. Its strong static type system with Hindley–Milner type inference catches many errors at compile time, and lazy evaluation evaluates expressions only when their values are needed.

Use

Haskell is used in academia and industry, including in finance, compilers, and web services; Facebook has used it for anti-spam systems, and it underpins the Pandoc document converter.
