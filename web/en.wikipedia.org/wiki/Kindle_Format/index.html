Kindle Format

The Kindle Format is a proprietary e-book file format created by Amazon for its Kindle e-readers and apps. Successive versions include the original AZW format (based on Mobipocket), AZW3 / KF8 (Kindle Format 8), which added HTML5 and CSS3 support, and KFX (Kindle Format 10), which added enhanced typesetting and improved hyphenation and justification.

Features

Kindle formats support reflowable text, bookmarks, annotations sync via Whispernet/Whispersync, and optional digital rights management (DRM) applied at the publisher's request. Amazon's Kindle Direct Publishing accepts manuscripts and converts them to Kindle Format for sale in the Kindle Store.
