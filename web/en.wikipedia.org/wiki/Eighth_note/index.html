Eighth note

Eighth note

British name: Quaver

Duration: Half of a quarter note; one eighth of a whole note

Symbol: Filled notehead with stem and one flag (𝅘𝅥𝅮)

An eighth note (American) or quaver (British) is a note played for one eighth the duration of a whole note (semibreve), hence the name. Eighth notes are notated with an oval, filled-in note head and a straight note stem with one flag note flag.

Notation

A single eighth note is drawn with a stem and one flag. Pairs and groups of eighth notes with the same beat unit are commonly joined by a thick beam replacing the individual flags, which makes rhythms easier to read. The stem normally points up if the note is below the middle line of the staff and down if above it. In Unicode, the symbol is U+266A (♪) for a single note and U+266B (♫) for a beamed pair.

Duration and rhythm

An eighth note lasts half as long as a quarter note (crotchet) and twice as long as a sixteenth note (semiquaver). In 4/4 time there are eight eighth notes per bar. A dotted eighth note extends the duration to three sixteenth notes. The corresponding silence is the eighth rest, written with a single flag-like mark.
