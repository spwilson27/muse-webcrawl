Ethernet hub

Ethernet hub
Type: Network hardware
OSI layer: Layer 1 (physical)
Also called: Multiport repeater
Speeds: 10 Mbit/s, 100 Mbit/s
Largely replaced by: Network switch

An Ethernet hub, also called a network hub or multiport repeater, is a network hardware device for connecting multiple Ethernet devices together, making them act as a single network segment. It operates at the physical layer (layer 1) of the OSI model: a signal arriving on any port is repeated, bit by bit, out of all other ports.

Operation

Unlike a network switch, a hub has no ability to inspect frames or learn addresses; every device attached to a hub shares the same collision domain and the same bandwidth, and the network operates in half-duplex mode. If two devices transmit simultaneously, a collision occurs and both must back off and retry, which severely limits usable throughput as the number of devices grows.

History and obsolescence

Hubs were common in 10BASE-T and early Fast Ethernet networks of the 1990s because they were inexpensive. As switch prices fell to hub levels by the early 2000s, hubs became obsolete in new installations; gigabit Ethernet effectively ended the hub era except for specialized monitoring uses, since switches forward traffic intelligently to the destination port only and support full-duplex links.
