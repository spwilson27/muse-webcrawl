FreeRTOS

FreeRTOS is a real-time operating system kernel for embedded devices, distributed freely under the MIT open-source licence. It has been ported to dozens of microcontroller architectures and is one of the most widely used real-time operating systems in embedded products, from consumer devices to industrial controllers.

Features

FreeRTOS provides a small, preemptive multitasking kernel with tasks, queues, semaphores, mutexes, software timers, and event groups. Its footprint can be as small as a few kilobytes of ROM, and the kernel is written mostly in C with small assembly portions for each supported processor. Optional libraries extend it with TCP/IP networking, file systems, and over-the-air update support.

History

FreeRTOS was developed by Richard Barry beginning in 2003. In 2017, stewardship passed to Amazon Web Services, which offers Amazon FreeRTOS (later renamed AWS IoT FreeRTOS) integrating cloud connectivity for microcontrollers, while the core kernel remains open source under the FreeRTOS name.
