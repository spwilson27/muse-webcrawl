Function overloading

In some programming languages, function overloading or method overloading is the ability to create multiple functions of the same name with different implementations. Calls to an overloaded function will run a specific implementation of that function appropriate to the context, based on the number and types of the arguments.


Overloaded functions in C++

Examples

Languages supporting overloading include C++, Java, C#, Swift and Ada. For instance, an add function might be declared for integers and for floating-point numbers; the compiler selects which version to call — a process called overload resolution — using the argument types at the call site. Constructors are commonly overloaded to provide several ways to initialise an object.

Rules

Overloading is usually resolved at compile time and is an example of static (ad hoc) polymorphism. Functions that differ only in return type generally cannot be overloaded. Operator overloading, found in languages such as C++, is a related feature allowing operators like + to be given custom meanings for user-defined types. Languages without overloading, such as C, use distinct names (e.g. abs, labs, fabs) for similar operations on different types.
