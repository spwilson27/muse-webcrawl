Half-precision floating-point format

In computing, half precision (sometimes called FP16) is a binary floating-point number format that occupies 16 bits in memory. The IEEE 754 standard defines it as binary16: 1 sign bit, 5 exponent bits (with a bias of 15), and 10 trailing significand bits. It can represent values up to about 65,504 and normal values down to about 6.1 × 10−5, with roughly three decimal digits of precision.

Uses

Half precision was long used mainly for storing graphics data, such as high-dynamic-range image textures, because its limited range and precision are inadequate for most general numerical work. It has become much more prominent with machine learning, where neural networks tolerate low-precision arithmetic: training and inference in FP16 (and derivatives such as bfloat16, which trades significand bits for exponent range) greatly reduce memory bandwidth and increase throughput on modern GPUs and dedicated accelerators. NVIDIA's graphics hardware has supported full-speed FP16 since the mid-2010s, and ARM and x86 processors have added native support.
