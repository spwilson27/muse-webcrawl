Hopfield network

A Hopfield network (or Ising model of a neural network) is a form of recurrent artificial neural network and a type of spin glass system popularised by John Hopfield in 1982, though described earlier by William Little in 1974. Hopfield networks serve as content-addressable ("associative") memory systems with binary threshold nodes, or with continuous variables.

Structure

The units in a Hopfield network are binary threshold units, taking values of 1 or −1 (or 1 and 0). Every pair of units is connected by a symmetric weight, and there are no self-connections. The network updates its units either asynchronously, one at a time, or synchronously, and is guaranteed to converge to a stable state because an energy function decreases (or stays the same) with each update.

Energy and memory

The energy of a state is defined as a quadratic function of the activities weighted by the connection strengths, in direct analogy with the energy of an Ising spin glass. Patterns are stored by adjusting the weights, commonly with a Hebbian rule: connections between units that are active together are strengthened. Stored patterns become local minima of the energy function, so presenting the network with a partial or noisy version of a pattern and letting it relax recalls the complete stored pattern.

Capacity

A network of N units can reliably store roughly 0.138N random patterns before retrieval errors become common. Beyond this capacity, spurious attractors appear and stored memories are catastrophically forgotten.

Modern developments

In 2016, Krotov and Hopfield introduced dense associative memories with higher-order interactions, which have much larger storage capacity. Later work showed that the update rule of these modern Hopfield networks is mathematically equivalent to the attention mechanism used in transformer architectures, a connection formalised by Ramsauer and co-authors in 2020.
