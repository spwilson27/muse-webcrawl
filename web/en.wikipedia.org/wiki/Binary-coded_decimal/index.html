Binary-coded decimal

The decimal number 739 in BCD is 0111 0011 1001.

In computing and electronic systems, binary-coded decimal (BCD) is a class of binary encodings of decimal numbers where each digit is represented by a fixed number of bits, usually four. Thus the decimal digit 9 is encoded as 1001, and the number 739 becomes 0111 0011 1001, in contrast to pure binary, in which 739 is 1011100011.

In the common "8421" encoding each decimal digit maps to its four-bit binary value; the six combinations 1010–1111 are unused. Packed BCD stores two digits per byte, while unpacked BCD stores one digit per byte. Variants include excess-3 code and the densely packed decimal encoding used in the IEEE 754-2008 decimal floating-point formats.

Advantages and disadvantages

BCD makes conversion to and from decimal displays trivial, and decimal fractions such as 0.1 can be represented exactly — important in financial calculations, where rounding errors of binary floating point are unacceptable. Early computers such as the IBM 1401 and the System/360 family offered native BCD arithmetic, and the x86 architecture historically included BCD adjustment instructions. The cost is efficiency: four bits can represent sixteen values but BCD uses only ten, wasting storage and complicating arithmetic circuitry.

Applications

BCD persists in digital clocks and real-time clock chips, calculators, digital multimeters, and in packed-decimal data formats in mainframe COBOL applications.
