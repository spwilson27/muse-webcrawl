Object (computer science)

In computer science, an object is an entity that bundles together data (state) and the procedures (behavior) that operate on that data. Objects are the central building blocks of object-oriented programming: a program is structured as a collection of objects that interact by sending messages or invoking methods.

Characteristics

An object typically has three defining features:

  • State — the values of its attributes or fields at a given moment.
  • Behavior — the actions it can perform, implemented as methods or procedures.
  • Identity — a uniqueness that distinguishes the object from others even when their states coincide; in many languages this is tied to the object's memory address or reference.

In class-based languages such as Java, C++, and Python, an object is an instance of a class, which serves as its template and type. In prototype-based languages such as JavaScript, objects instead inherit directly from other objects. Some formalisms, notably the actor model, emphasize objects as independent computational agents communicating only by messages.

Related concepts

Objects are characterized by encapsulation (hiding internal state behind a public interface), inheritance (deriving new classes from existing ones), and polymorphism (treating objects of different classes uniformly through a shared interface). In lower-level programming the term is used more loosely: C, for example, calls any region of storage an "object", and in distributed systems objects may be serialized and exchanged between processes or machines.

The concept descends from Simula 67, whose "objects" modeled real-world entities in simulations, and from Smalltalk, which made everything — including numbers and classes themselves — objects.
