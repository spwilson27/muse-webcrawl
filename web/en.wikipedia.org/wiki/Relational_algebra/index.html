Relational algebra

The fundamental operations of relational algebra

Relational algebra is a theory that uses algebraic structures for modelling data, and defining queries on it with well founded semantics. The theory was introduced by Edgar F. Codd in 1970 as a mathematical foundation for the relational model of data, and it provides the theoretical basis for relational databases and query languages such as SQL.

Introduction

In relational algebra, data is organized into relations (tables) consisting of tuples (rows) and attributes (columns). Queries are expressed as compositions of operators that take one or two relations as input and produce a new relation as output, a property known as closure, which permits arbitrarily nested expressions.

Fundamental operations

The primitive operations are usually taken to be: selection (σ), which filters tuples satisfying a predicate; projection (π), which selects a subset of attributes; union (∪), set difference (−), and Cartesian product (×), borrowed from set theory; and rename (ρ), which changes attribute or relation names. From these primitives, further operations such as intersection, division, and the various joins — most importantly the natural join and the theta join — can be derived.

Expressive power

Relational algebra is equivalent in expressive power to first-order relational calculus, as established by Codd's theorem. Both correspond to a safe, domain-independent fragment of first-order logic. Practical query languages extend the algebra with aggregation, grouping, sorting, and limits. Because expressions in the algebra can be rewritten using equivalence laws, database query optimizers use it as an internal representation for generating efficient execution plans.
