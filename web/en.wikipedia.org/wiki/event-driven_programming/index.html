Event-driven programming

In computer programming, event-driven programming is a programming paradigm in which the flow of the program is determined by events such as user actions (mouse clicks, key presses), sensor outputs, or message passing from other programs or threads.

Event handlers

Event-driven applications typically feature a main loop that listens for events and triggers a callback function, or event handler, when one of those events is detected. Handlers are registered for specific event types on specific objects, as in graphical user interface toolkits and web browsers' Document Object Model.

Applications

The paradigm is dominant in graphical user interfaces, web development (for example JavaScript in browsers), embedded systems, and server frameworks such as Node.js that rely on non-blocking event loops.

Criticism

Deeply nested callbacks can produce hard-to-follow code sometimes called "callback hell"; asynchronous language features such as promises and async/await were developed partly in response.
