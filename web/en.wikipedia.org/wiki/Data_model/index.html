Data model

A data model is an abstract model that organises elements of data and standardises how they relate to one another and to the properties of real-world entities. In software and database design, data modelling is the process of creating such a model for an information system by applying formal techniques, producing a specification of the structure of a database.

Levels of modelling

Data models are commonly developed at three levels of abstraction. A conceptual model identifies the entities, attributes and relationships of a domain in business terms. A logical model refines this into a structure for a particular kind of database (such as the relational model) without regard to physical implementation. A physical model describes storage details — tables, columns, indexes and partitions — for a specific database management system.

Model types

Historically important data models include the hierarchical model, the network model, the relational model proposed by E. F. Codd in 1970, the entity–relationship model introduced by Peter Chen in 1976, object-oriented models, document models used by NoSQL systems, and graph data models based on nodes and edges.

Uses

Beyond database design, data models appear in enterprise architecture, data exchange standards, and data governance, where shared models keep the meaning of data consistent across systems and organisations.
