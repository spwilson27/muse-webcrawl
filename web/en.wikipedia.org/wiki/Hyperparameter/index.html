Hyperparameter

In machine learning, a hyperparameter is a parameter whose value is used to control the learning process, in contrast to other parameters (such as node weights) whose values are learned during training. Hyperparameters must be set before training begins, and they may be constant during training or follow a schedule.

Hyperparameters are tuned on validation data, while parameters are learned on training data.

Examples

Common hyperparameters include the learning rate, the number of hidden layers and units in a neural network, the depth of a decision tree, the number of neighbours in k-nearest neighbours, the regularization strength, batch size, dropout rate and the number of training epochs. Different algorithms expose very different hyperparameter spaces, and the sensitivity of performance to each hyperparameter varies widely.

Hyperparameter optimization

Hyperparameter optimization (or tuning) seeks the set of hyperparameters that maximises a validation metric. Strategies include grid search, random search — often more efficient than grid search because only a few hyperparameters typically matter — Bayesian optimization, gradient-based methods, and population-based training. Because each evaluation can require a full training run, tuning is computationally expensive and risks overfitting to the validation set if performed too aggressively.

Reproducibility

Hyperparameter choices can have effects comparable to algorithmic differences, so reporting them is important for reproducibility in machine-learning research.
