Clone (algebra)

In universal algebra, a clone is a set of functions on a set A (interpreted as the operations of an algebra) which is closed under composition and contains all the projection functions. More precisely, a clone on a set A is a set of finitary operations on A containing every projection map and closed under generalized composition.

Definition

Formally, a clone on A is a subset of the set of all operations on A such that: (1) it contains all projections πin(x1,…,xn) = xi; and (2) whenever f is an n-ary operation in the clone and g1,…,gn are m-ary operations in the clone, the composition f(g1,…,gn) is also in the clone.

Properties

Every algebra determines a clone (its term operations), and clones on a set form a lattice under inclusion. The study of clones is closely connected with the classification of algebras, the theory of varieties, and problems such as the constraint satisfaction problem, where clones of polymorphisms govern complexity. Post's lattice gives a complete description of all clones on a two-element set, obtained by Emil Post in 1941.
