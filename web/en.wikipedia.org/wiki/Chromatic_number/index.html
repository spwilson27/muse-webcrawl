Chromatic number

In graph theory, the chromatic number of an undirected graph is the smallest number of colours needed to colour its vertices so that no two adjacent vertices share the same colour. It is conventionally denoted χ(G) (the Greek letter chi) for a graph G. A graph that can be coloured with k colours is called k-colourable, and one whose chromatic number equals k is k-chromatic.

Examples

A graph with no edges has chromatic number 1; a bipartite graph with at least one edge has chromatic number 2. An odd cycle needs 3 colours, while a complete graph on n vertices needs n. The Petersen graph has chromatic number 3.

Bounds

  • Clique bound: χ(G) ≥ ω(G), the size of the largest clique.
  • Greedy bound: χ(G) ≤ Δ(G) + 1, where Δ is the maximum degree.
  • Brooks' theorem: for connected graphs that are neither complete nor odd cycles, χ(G) ≤ Δ(G).
  • Hoffman's bound relates χ to the eigenvalues of the adjacency matrix.

Computation

Determining the chromatic number is NP-hard in general, and deciding whether a graph is 3-colourable is NP-complete — it was one of Karp's original 21 NP-complete problems. Polynomial cases include bipartite graphs (2-colourability, testable by breadth-first search) and perfect graphs. Exact exponential algorithms and greedy heuristics are used in applications such as register allocation in compilers, scheduling and frequency assignment.

Related concepts

The chromatic index concerns edge colourings; the chromatic polynomial P(G, k) counts the number of proper colourings with k colours, and the chromatic number is the smallest positive integer at which it is non-zero. The celebrated four colour theorem states that every planar graph has chromatic number at most 4.
