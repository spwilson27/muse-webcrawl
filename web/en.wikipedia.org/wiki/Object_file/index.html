Object file

An object file is a computer file containing object code — machine code in relocatable format — together with relocation information, a symbol table, and other metadata. Object files are produced by a compiler or assembler from source code and are combined by a linker to form an executable program or library.

Structure and formats

An object file typically contains sections for executable code (text), initialised data, uninitialised data (BSS), debugging information, and tables of defined and undefined symbols with the relocation entries needed to patch addresses when the file is linked with others. Common object file formats include ELF (Executable and Linkable Format) on Unix-like systems, COFF and its PE variant on Microsoft Windows, and Mach-O on macOS.

Use

Object files enable separate compilation: each source file can be compiled independently, and only changed files need to be recompiled before linking. Collections of object files can be packaged into static libraries (archives) for distribution and reuse.
