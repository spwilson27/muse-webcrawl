Data buffer

In computer science, a data buffer (or just buffer) is a region of memory used to store data temporarily while it is being moved from one place to another. Buffers are used to compensate for differences in the speed at which data is produced and consumed, to smooth out irregularities in data flow, and to allow data to be transferred in efficient block sizes.

Uses

Buffers appear throughout computing: in disk and network I/O, in audio and video streaming (where a playout buffer absorbs network jitter), in printers (spooling), and in graphics rendering (frame buffers). A common implementation is the circular buffer (ring buffer), in which a fixed-size region of memory is treated as if its ends were connected, allowing continuous streaming with bounded memory.

Buffering in telecommunications

In networking, buffers in routers and switches hold packets waiting to be forwarded. Excessive buffering can cause high latency, a phenomenon known as bufferbloat, while insufficient buffering can cause packet loss under bursts of traffic.

Buffer overflow

A buffer overflow occurs when a program writes more data into a fixed-size buffer than it can hold, overwriting adjacent memory. Buffer overflows have historically been a major source of security vulnerabilities, exploited to execute arbitrary code; modern languages and runtime protections aim to prevent them.

Double buffering

Double buffering uses two buffers so that one can be filled while the other is being read or displayed, avoiding flicker and stalls, particularly in computer graphics and audio processing.
