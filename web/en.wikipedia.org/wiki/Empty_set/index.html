Empty set

In mathematics, the empty set is the unique set having no elements; its size or cardinality is zero. It is denoted by the symbols { } or ∅. In standard axiomatic set theory, the existence of the empty set follows from the axiom of empty set (or from other axioms), and uniqueness follows from the axiom of extensionality: there is exactly one empty set.

Properties

The empty set is a subset of every set, and every set is a subset of itself unioned with the empty set. The union of any set with the empty set is the set itself; the intersection of any set with the empty set is the empty set; the Cartesian product of any set with the empty set is empty. The empty set's only subset is itself, its power set has exactly one element, and the sum and product of its elements are 0 and 1 respectively by convention (empty sum and empty product).

Notation and history

The symbol ∅ was introduced by André Weil and the Bourbaki group in 1939, borrowed from the Norwegian and Danish letter Ø. It should not be confused with the Greek letter phi (φ). In computing, the empty set concept appears as empty collections, and in logic, statements of the form "for all x in ∅" are vacuously true.
