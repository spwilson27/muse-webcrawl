Rendezvous hashing

From Wikipedia, the free encyclopedia


Clients pick the highest-scoring site

Rendezvous or highest random weight (HRW) hashing is an algorithm that allows clients to achieve distributed agreement on a set of k options out of a possible set of n options. A typical application is when clients need to agree on which sites (or proxies) objects are assigned to.

Rendezvous hashing is more general than consistent hashing, which becomes a special case (for k=1) of rendezvous hashing. The algorithm was invented by David Thaler and Chinya Ravishankar at the University of Michigan in 1996 and independently described as "highest random weight" hashing by the Web proxy community.

Algorithm

Given a set of n sites and a key identifying an object, for each site the client computes a weight by hashing the site identifier together with the object identifier (for example, hash(site ‖ object)). The object is assigned to the site with the highest resulting weight. Because the hash functions produce effectively random values, loads are distributed uniformly, and only the objects assigned to a removed or added site need to be remapped — the expected fraction of keys remapped when a site changes is 1/n.

Properties and uses

The scheme requires no coordination among clients beyond sharing the same hash function and site list, and it provides minimal disruption when sites fail. Its main cost is computation: selecting a site takes O(n) hash evaluations, which is acceptable for moderate numbers of sites and can be improved with hierarchical variants. Rendezvous hashing is used in content delivery, distributed caching, load balancing and systems such as Microsoft's Cache Array Routing Protocol successors and various distributed hash tables.
