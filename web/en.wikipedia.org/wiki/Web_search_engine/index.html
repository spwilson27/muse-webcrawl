Web search engine

A web search engine is a software system designed to carry out web searches: it discovers content on the World Wide Web using automated programs called crawlers or spiders, organises it in an index, and returns ranked results in response to user queries.

How search engines work

The process has three stages. Crawling: bots follow hyperlinks to fetch pages across the web. Indexing: fetched content is analysed and stored in a massive inverted index of words and their locations, along with signals such as link structure. Ranking/serving: for a query, the engine retrieves matching pages and ranks them by relevance algorithms — historically keyed on term matching and link analysis such as Google's PageRank — returning a results page with titles, snippets, and links.

History

Early tools included Archie (1990, for FTP files), Gopher indexes, and the first web search services such as WebCrawler, Lycos, and AltaVista (1994–95), followed by Yahoo!'s directory and Ask Jeeves. Google, founded in 1998, came to dominate through link-based ranking and a clean interface. Other major engines include Microsoft's Bing (2009), Baidu in China, Yandex in Russia, and privacy-focused services such as DuckDuckGo.

Market and issues

Search engines underpin the web economy, funded largely by search advertising. Issues include search engine optimisation (SEO) and manipulation, spam, privacy of query data, market concentration, and the shift toward AI-generated answer summaries.
