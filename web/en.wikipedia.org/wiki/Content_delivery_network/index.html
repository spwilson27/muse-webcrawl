Content delivery network

From Wikipedia, the free encyclopedia
[Image: World map diagram of a CDN: many edge server locations near clusters of users, fed by one origin]

A content delivery network (CDN) is a network of geographically distributed proxy servers and their data centres whose goal is to provide high availability and performance by distributing the service spatially relative to end users. When you load a popular website or stream a video, the bytes most likely come not from the publisher's own computers but from a CDN cache in your own city.

CDNs arose in the late 1990s as the web outgrew single-server sites: Akamai, founded in 1998 by MIT's Tom Leighton and Danny Lewin from work on consistent hashing, built the first large network and still serves a significant share of web traffic. A CDN caches static content at the 'edge', routes each user to a nearby healthy node (often using DNS and anycast), absorbs traffic spikes and denial-of-service attacks, and increasingly runs customers' code (edge computing) and security filtering at those same points.

Competitors such as Cloudflare, Fastly and the hyperscalers' own networks (Amazon CloudFront, Google Cloud CDN) made CDN delivery the default architecture of the popular web — with a side effect that an outage at one CDN can take down a visible slice of the Internet at once, as several memorable Fastly and Cloudflare incidents demonstrated.
