Nearest-neighbor interpolation (also known as proximal interpolation or, in some contexts, point sampling) is a simple method of multivariate interpolation in one or more dimensions. Interpolation is the problem of approximating the value of a function for a non-given point in some space when given the value of that function in points around (neighboring) that point. The nearest-neighbor algorithm selects the value of the nearest point and does not consider the values of neighboring points at all, yielding a piecewise-constant interpolant.

Definition

For a set of known data points, the nearest-neighbour interpolant assigns to any query point x the value of the data point closest to x under some metric, usually Euclidean distance. The regions of space assigned to each data point form a Voronoi diagram. In one dimension the method is equivalent to rounding the query position to the index of the nearest sample, and the interpolant is a step function whose jumps occur at midpoints between samples.

Applications

Image scaling

Nearest-neighbour resampling is widely used in digital image processing to resize images. When an image is enlarged, each output pixel takes the colour of the nearest input pixel, producing the characteristic blocky, "pixelated" appearance. The method is fast and preserves the exact original colour values and hard edges, making it the preferred choice for pixel art and for data where values are categorical — such as label maps or indexed images — where averaging neighbouring values (as in bilinear or bicubic interpolation) would create meaningless intermediate values.

Other uses

The same principle underlies nearest-neighbour classification in machine learning, nearest-neighbour resampling of geographic and scientific data, and the zero-order hold used to reconstruct signals in digital-to-analog conversion.

Advantages and disadvantages

Nearest-neighbour interpolation is the fastest and simplest interpolation method and never introduces new values outside the range of the data, which is essential for discrete data. Its disadvantages are the discontinuous, blocky output and poor approximation quality for smooth functions, where linear or higher-order methods are usually preferred.
