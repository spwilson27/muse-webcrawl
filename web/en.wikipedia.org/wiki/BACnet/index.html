BACnet

BACnet
Type: Building automation protocol
Standard: ANSI/ASHRAE 135, ISO 16484-5
Developed: ASHRAE SSPC 135
First published: 1995

BACnet is a communication protocol for Building Automation and Control networks. It is an ASHRAE, ANSI and ISO standard protocol designed to allow communication between building automation and control systems for applications such as heating, ventilating and air-conditioning (HVAC), lighting, access control and fire detection.

Overview

BACnet defines an object-oriented model: devices expose standard objects such as Analog Input, Analog Output, Binary Value and Device, each with named properties. Services such as ReadProperty, WriteProperty, Who-Is and I-Am allow controllers and workstations from different manufacturers to interoperate.

Transport

The protocol originally ran over RS-485 MS/TP, ARCNET, Ethernet and LonWorks point-to-point links. Modern deployments most commonly use BACnet/IP over UDP/IP, and increasingly BACnet/SC (Secure Connect) using TLS over WebSockets for encrypted communication.

Adoption

BACnet is maintained by ASHRAE Standing Standard Project Committee 135 and tested for interoperability by BACnet Testing Laboratories (BTL). It is one of the most widely used open protocols in commercial building automation alongside Modbus and KNX.
