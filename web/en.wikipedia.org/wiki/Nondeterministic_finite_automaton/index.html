Nondeterministic finite automaton

In automata theory, a nondeterministic finite automaton (NFA), also known as a nondeterministic finite-state machine, is a finite-state machine in which, for each state and input symbol, the transition function may lead to several possible next states — or none. The automaton accepts an input string if there exists at least one sequence of transitions that consumes the string and ends in an accept state.

Definition

An NFA is formally a five-tuple (Q, Σ, δ, q0, F) consisting of a finite set of states Q, an alphabet Σ, a transition function δ mapping a state and an input symbol (or the empty string ε) to a set of states, a start state q0, and a set of accept states F. Transitions on ε allow the machine to change state without consuming input.

Equivalence with DFAs

Despite their greater freedom, NFAs recognise exactly the same languages as deterministic finite automata (DFAs): the regular languages. The subset construction (powerset construction) converts any NFA into an equivalent DFA whose states are sets of NFA states, at the cost of a worst-case exponential increase in the number of states. NFAs are nevertheless widely used because they are often far more compact and easier to design — notably in the Thompson's construction that compiles regular expressions into NFAs, which underlies many text-search tools.

Applications

NFAs model regular-expression matching, lexical analysis in compilers, protocol states, and any system where several behaviours may be possible at a given step. Variants include NFAs with ε-transitions (ε-NFA), alternating automata, and the nondeterministic models used as stepping stones to pushdown automata and Turing machines in the Chomsky hierarchy.
