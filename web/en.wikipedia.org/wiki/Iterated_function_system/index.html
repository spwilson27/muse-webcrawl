Iterated function system

In mathematics, an iterated function system (IFS) is a method of constructing fractals. Formalised by John Hutchinson in 1981 and popularised by Michael Barnsley, an IFS consists of a finite set of contraction mappings on a complete metric space. Applying the associated Hutchinson operator repeatedly to any starting set converges to a unique compact set, the attractor of the system, which is typically self-similar and fractal.

Construction

Each mapping in the system is a contraction, usually an affine transformation combining scaling, rotation, reflection and translation. Classic examples include the Sierpiński triangle (three contractions with ratio 1/2), the Koch curve, and the Barnsley fern (four affine maps with assigned probabilities).

Algorithms

Two common rendering methods are the deterministic algorithm, which applies the Hutchinson operator to a discretised set, and the random iteration algorithm or "chaos game", which repeatedly applies a randomly chosen map to a point, choosing maps according to probability weights. The chaos game plots the attractor efficiently and underlies fractal image compression techniques developed by Barnsley and others.
