Pitch class

In music theory, a pitch class (p.c. or pc) is a set of all pitches that are a whole number of octaves apart; for example, the pitch class C consists of the Cs in all octaves. In other words, the pitch class of a note is the note irrespective of which octave it sounds in. The concept is fundamental to musical set theory and to the analysis of atonal and twelve-tone music.

The twelve pitch classes of the chromatic scale arranged as a clock face, a common representation in set theory.

Integer notation

In the standard integer notation used in set theory, the twelve pitch classes of the equal-tempered chromatic scale are labelled with the numbers 0 through 11, with 0 conventionally assigned to C. Pitch classes differing by 12 (mod 12) are identical, so pitch-class arithmetic is arithmetic modulo 12.

Pitch-class sets

A pitch-class set is an unordered collection of pitch classes, used to describe chords, scales and melodic motives abstracted from register, rhythm and order. Sets are commonly identified by their normal form and prime form, and catalogued using Forte numbers after the theorist Allen Forte, whose book The Structure of Atonal Music (1973) systematised the approach. Two sets belong to the same set class if one can be transformed into the other by transposition or inversion.

Use in twelve-tone theory

In twelve-tone technique, a row is an ordered arrangement of the twelve pitch classes; the pitch-class concept allows the composer and analyst to treat row forms (prime, inversion, retrograde, retrograde inversion) independently of octave placement. The concept was developed in the writings of Milton Babbitt and others in the mid-twentieth century.
