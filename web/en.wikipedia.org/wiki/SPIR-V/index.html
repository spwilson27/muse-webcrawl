SPIR-V

Standard Portable Intermediate Representation (SPIR) is an intermediate language for parallel computing and graphics by the Khronos Group, originally developed for use with OpenCL. SPIR-V, its current universal form announced in 2015, is the standard binary intermediate language for representing graphical shaders and compute kernels in the Vulkan API and in OpenCL 2.1 and later.

Instead of implementing a full high-level language compiler in every graphics driver, developers compile GLSL or HLSL shaders (for example with the glslang reference compiler) into portable SPIR-V modules ahead of time. Drivers then only need a simpler SPIR-V-to-native compiler, improving portability and reducing shader compile times and inconsistencies between vendors.

Design

SPIR-V is a binary format based on single static assignment (SSA) form, with explicit control flow and a rich decoration system that records information needed by graphics pipelines (such as descriptor bindings and built-in variables) that plain compute IRs lack. It supports both graphics shader stages (vertex, fragment, geometry, tessellation, mesh, ray tracing) and general-purpose compute kernels.

Ecosystem

The Khronos Group maintains SPIRV-Tools (assembler, disassembler, validator and optimizer) and SPIRV-Cross, which translates SPIR-V back into GLSL, HLSL, and Metal Shading Language. SPIR-V also serves as an interchange format in machine-learning and heterogeneous-computing frameworks, and projects such as LLVM-based compilers can target it.
