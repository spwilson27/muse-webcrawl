Apache License

Author: Apache Software Foundation
Latest version: 2.0 (January 2004)
Copyleft: No
Free software: Yes (FSF and OSI approved)

The Apache License is a permissive free software license written by the Apache Software Foundation (ASF). It allows users to use the software for any purpose, to distribute it, to modify it, and to distribute modified versions of the software under the terms of the license, without concern for royalties. The ASF and its projects release their software under the Apache License, and many non-ASF projects follow suit.

Terms

Like other free software licences, the Apache License allows the user of the software the freedom to use the software for any purpose, to distribute it, to modify it, and to distribute modified versions. Unlike copyleft licences, it does not require modified versions to be distributed under the same licence. The principal conditions are the preservation of copyright and licence notices, and the inclusion of a NOTICE file's attributions where present.

Version 2.0

Version 2.0, released in January 2004, added an explicit patent licence grant: each contributor grants users a licence under its patent claims that are necessarily infringed by the contribution, and the licence terminates for a party who brings patent litigation over the software. It also introduced a patent retaliation clause and clarified the definition of contributions. The Free Software Foundation considers the Apache License 2.0 compatible with version 3 of the GNU General Public License, though not with GPL version 2.

Adoption

The Apache License is among the most widely used open source licences, applied to projects such as Android, Apache Hadoop, Kubernetes, TensorFlow, and the Swift programming language.
