Hyper-threading

Hyper-threading (officially Hyper-Threading Technology, HTT) is Intel's proprietary implementation of simultaneous multithreading (SMT), used to improve parallelization of computations performed by x86 processors. Introduced with the Pentium 4 in 2002, it makes a single physical core appear to the operating system as two logical processors.

How it works

Each physical core duplicates its architectural state (registers and interrupt logic) so it can hold the context of two threads at once, while execution units, caches, and buses are shared. When one thread stalls — waiting for memory, for example — the core can execute instructions from the other thread, improving utilization of otherwise idle resources. Typical performance gains are on the order of 15–30% on suitably parallel workloads, at a die-area cost of only a few percent.

History and security

Hyper-threading debuted in Xeon and Pentium 4 processors, was dropped from early Core designs, and returned with the Nehalem microarchitecture in 2008, becoming standard across Core i3/i5/i7 lines. Because threads share caches and execution ports, SMT has been implicated in side-channel vulnerabilities such as TLBleed and the MDS attacks (ZombieLoad), leading some security-conscious environments to disable it. Intel has since omitted it from some recent efficiency-focused core designs.
