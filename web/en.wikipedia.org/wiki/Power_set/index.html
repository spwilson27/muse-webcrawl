Power set

The subsets of {x, y, z} ordered by inclusion; their collection is the power set.

In mathematics, the power set (or powerset) of a set S is the set of all subsets of S, including the empty set and S itself. It is commonly denoted 𝒫(S), P(S), or 2S. The notation 2S reflects the fact that if S has n elements, its power set has 2n elements, since each element of S may independently be in or out of a given subset.

Properties

In axiomatic set theory, the existence of the power set of any set is guaranteed by the axiom of power set. The power set of a finite set with n elements contains 2n subsets; the number of subsets with exactly k elements is the binomial coefficient C(n, k), and summing over all k yields 2n. The power set, ordered by inclusion, forms a complete Boolean algebra, and its elements correspond exactly to the characteristic functions (indicator functions) on S, which is the basis of the 2S notation.

Cantor's theorem

Cantor's theorem states that the power set of any set has a strictly greater cardinality than the set itself. Georg Cantor proved this with his diagonal argument: no function from S onto its power set can be surjective. Consequently there are infinitely many infinite cardinalities, and the power set of the natural numbers is uncountable. Whether there is a cardinality between that of the natural numbers and that of their power set is the subject of the continuum hypothesis, shown to be independent of the standard axioms of set theory.

Example

For S = {x, y, z}, the power set has 23 = 8 elements: ∅, {x}, {y}, {z}, {x, y}, {x, z}, {y, z} and {x, y, z}.
