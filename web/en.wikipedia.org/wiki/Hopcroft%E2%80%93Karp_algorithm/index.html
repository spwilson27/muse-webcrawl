Hopcroft–Karp algorithm

The Hopcroft–Karp algorithm is an algorithm for finding a maximum-cardinality matching in a bipartite graph. Published in 1973 by John Hopcroft and Richard Karp, it runs in O(E√V) time, making it faster than simpler augmenting-path methods for dense graphs.

Description

The algorithm works in phases. Each phase uses a breadth-first search to build a layered graph of the shortest augmenting paths from free vertices on one side, followed by depth-first searches to find a maximal set of vertex-disjoint shortest augmenting paths, along which the matching is augmented simultaneously. Because each phase lengthens the shortest augmenting path, only O(√V) phases are needed.

Applications

Maximum bipartite matching arises in assignment problems such as job scheduling, network flow and sparse matrix computations, and the Hopcroft–Karp algorithm is the standard practical method for large instances.
