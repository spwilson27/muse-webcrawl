0 (zero) is a number representing an empty quantity. Adding 0 to any number leaves that number unchanged. In mathematical terminology, 0 is the additive identity of the integers, rational numbers, real numbers, and complex numbers, as well as other algebraic structures. Multiplying any number by 0 has the result 0, and consequently, division by zero has no meaning in arithmetic.

As a numerical digit, 0 plays a crucial role in decimal notation: it indicates that the power associated with the preceding numeral is not naturally occurring in that position of the overall number. For example, in decimal notation, the integer 1000 has three zeroes, which indicate that the number represents one thousand and that the unit's place, the tens place, and the hundreds place are all empty. Zero also plays a role as a placeholder in other positional number systems, such as the binary system.

0 is an even number. The following are some basic rules for dealing with the number 0. These rules apply for any real or complex number x, unless otherwise stated: addition: x + 0 = 0 + x = x; subtraction: x − 0 = x and 0 − x = −x; multiplication: x · 0 = 0 · x = 0; division: 0/x = 0 for nonzero x, while x/0 is undefined.

History

Ancient Egyptian numerals were of base 10 type. Egyptians used hieroglyphs for the digits and were not positional. By 1770 BC, the Egyptians had a symbol for zero in accounting texts. The Babylonian placeholder zero, by contrast, was a true placeholder that represented an empty position in a positional numeral system. The concept of zero as a written digit in the decimal place value notation was developed in India. A symbol for zero, a large dot likely to be the precursor of the still-current hollow symbol, is seen in the Bakhshali manuscript, a practical manual on arithmetic for merchants. In 498 AD, Indian mathematician and astronomer Aryabhata stated that "sthānāt sthānaṁ daśaguṇaṁ syāt" — "from place to place each is ten times the preceding" — which is the origin of the modern decimal place value notation. The oldest undoubted example of zero with a symbol as used in India was found carved in stone at the Chaturbhuj Temple in Gwalior, dated 876 AD.

The Mesoamerican Long Count calendar developed in south-central Mexico required the use of zero as a placeholder within its vigesimal (base-20) positional numeral system. The Mayan civilization was among the first to use zero as a placeholder in a positional numeral system, centuries before it appeared in the Old World.

Etymology

The word zero came via French zéro from the Italian zero, itself a contraction of the Venetian zevero, which came from the Arabic صفر (ṣifr). It is also thought to be related to the Sanskrit word śūnya, meaning "empty" or "void".

Mathematics

Zero is the integer immediately preceding 1. Zero is an even number because it is divisible by 2 with no remainder. 0 is neither positive nor negative, or both positive and negative. Many definitions include 0 as a natural number, in which case it is the only natural number that is not positive. Zero is a number which quantifies a count or an amount of null size. In most cultures, 0 was identified before the idea of negative things (i.e., quantities less than zero) was accepted.

Zero is the value of false in many programming languages. In set theory, 0 is the cardinality of the empty set: if one does not have any apples, then one has 0 apples. In fact, in certain axiomatic developments of mathematics from set theory, 0 is defined to be the empty set. When this is done, the empty set is the Von Neumann cardinal assignment for a set with no elements, which is the empty set. The cardinality function, applied to the empty set, returns the empty set as a value, thus assigning it 0 elements.

Computing

In computing, 0 is used as a null value in many contexts. The most common representation of a positive integer in a computer is a string of bits, using the binary number encoding. Modern computers typically use the two's complement representation for integers. Array indexing in many programming languages (such as C) begins at 0, so that the first element of an array is at index 0.
