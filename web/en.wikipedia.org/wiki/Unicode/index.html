Unicode

Unicode, formally The Unicode Standard, is a text encoding standard maintained by the Unicode Consortium designed to support the use of text in all of the world's writing systems that can be digitised. Version 16.0 of the standard, published in September 2024, defines 154,998 characters covering 168 scripts and a wide array of symbols, including emoji. Unicode was developed to replace the fragmented landscape of incompatible character encodings such as ASCII and the ISO/IEC 8859 family.

Architecture

Unicode assigns each abstract character a unique number, its code point, written as U+ followed by hexadecimal digits — for example, U+0041 is "A" and U+1F600 is a grinning face emoji. The codespace is divided into 17 planes of 65,536 code points each. The standard itself does not define a byte representation; that is the role of the Unicode Transformation Formats, of which UTF-8 is dominant on the web, while UTF-16 is used internally by many operating systems and programming languages.

Design principles

Unicode encodes characters, not glyphs: the same character may be rendered differently depending on font and context. It handles complex scripts through combining characters, bidirectional text rules for scripts such as Arabic and Hebrew, and Han unification, which assigns shared code points to the CJK characters used in Chinese, Japanese and Korean. The standard also defines character properties, collation, case mapping and normalisation forms.

Adoption

Unicode underlies modern operating systems, the World Wide Web (where UTF-8 encodes the overwhelming majority of pages), XML, and most programming languages. Its emoji sets, expanded annually, have become a major part of global digital communication.
