Network congestion

Network congestion in data networking and queueing theory is the reduced quality of service that occurs when a network node or link carries more data than it can handle. Typical effects include queueing delay, packet loss, and the blocking of new connections. A network in a state of congestion collapse has little or no useful throughput.

Causes

Congestion occurs when offered load approaches or exceeds the capacity of links, routers, or end hosts, so that queues build up. Contributing factors include bursty traffic, insufficient buffer memory, slow processors, and retransmissions that add load precisely when the network is least able to carry it.

Congestion control

Modern networks use congestion control algorithms, notably those in TCP: senders probe for available bandwidth with slow start and adjust their sending rate using additive increase / multiplicative decrease (AIMD) in response to loss or delay signals, as in Reno, CUBIC, and BBR. Routers can assist with active queue management such as Random Early Detection (RED) and Explicit Congestion Notification (ECN). The Internet's congestion control mechanisms were largely designed following Van Jacobson's 1988 work after early congestion collapse events.

Related problems

Excessively large buffers can cause bufferbloat, in which queueing delay grows without packet loss. Fair queueing and traffic shaping are used to allocate bandwidth among competing flows.
