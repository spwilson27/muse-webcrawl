APNG (Animated Portable Network Graphics) is a file format that extends the Portable Network Graphics (PNG) specification to permit animated images comparable to GIF files, while remaining backward compatible with non-animated PNG viewers. Applications that do not support APNG simply display the first frame of the animation.

Design

The format, created in 2004, stores additional frames in ancillary chunks (acTL, fcTL, and fdAT) placed after the standard image data. Unlike the older MNG format, APNG was designed to be as simple as possible: it supports full 24-bit color and 8-bit alpha transparency, exceeding GIF's 256-color palette and binary transparency, and keeps files playable as static PNGs in older software.

Support and standardization

The PNG working group initially rejected APNG as an official extension in 2007, and Mozilla nevertheless shipped it in Firefox 3 in 2008; other browsers adopted it later, with Safari adding support in 2014 and Chromium-based browsers in 2017. In 2024–2025 the format was formally incorporated into the PNG specification's third edition, completing its long path from unofficial extension to standard.
