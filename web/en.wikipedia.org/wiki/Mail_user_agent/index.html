Mail user agent

A mail user agent (MUA), also called an email client, is a computer program or web application used to access and manage a user's email. The MUA is the component of the Internet mail architecture with which the end user interacts directly: it composes and sends messages through a mail submission agent, and retrieves received messages from a mailbox, typically using the POP3 or IMAP protocols or a proprietary API.


The interface of a desktop mail user agent showing folder list and message pane.

Functions

A mail user agent typically provides:

  • Reading — listing, displaying, and searching messages stored locally or on a server.
  • Composing — an editor for writing messages with attachments, formatted text (HTML), and multiple recipients.
  • Sending — submitting outgoing mail to a mail submission agent using SMTP, usually with authentication and encryption.
  • Organisation — folders, tags, filters/rules, flags, spam filtering, and address books.
  • Security — support for TLS connections and, in many clients, OpenPGP or S/MIME signing and encryption.

Types

Desktop and mobile clients

Installed applications such as Mozilla Thunderbird, Microsoft Outlook, and Apple Mail, and mobile apps bundled with smartphone operating systems, synchronise or download mail and offer offline access. Historically influential MUAs include Elm, Pine, Mutt, and Eudora.

Webmail

In webmail systems such as Gmail and Outlook.com, the MUA runs partly in the user's web browser, with the provider operating the interface logic on its servers. Webmail removed the need for local configuration and made access from any device routine, at the cost of dependence on the provider.

Protocols

The MUA sends mail using SMTP (with submission on port 587) and receives it using IMAP (keeping mail on the server and synchronising state) or POP3 (traditionally downloading and deleting from the server). Message format is defined by RFC 5322 and the MIME standards. The term "mail user agent" is defined in the Internet mail architecture (RFC 5598), which contrasts the MUA with the mail transfer agent (MTA) that routes messages between servers and the mail delivery agent (MDA) that files them into mailboxes.
