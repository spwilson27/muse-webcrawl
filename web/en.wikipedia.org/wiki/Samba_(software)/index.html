Samba is a free software re-implementation of the SMB networking protocol (also known as CIFS), originally developed by Andrew Tridgell. It allows Unix-like operating systems to interoperate with Microsoft Windows systems for file sharing, print services, authentication and directory services. Samba runs on most Unix and Unix-like systems, including Linux, and is a standard component of nearly all Linux distributions.

History

Tridgell began Samba in 1991–92 while at the Australian National University, reverse-engineering the SMB protocol with a packet sniffer because he wanted to connect his Unix workstation to a PC server. Originally called with various names, the project was renamed Samba after a trademark issue — the name was derived from "SMB". The project grew into the Samba Team, a distributed group of developers. Samba 4, released in December 2012 after a decade of development, added the ability to act as an Active Directory domain controller compatible with Microsoft's implementation, including its own LDAP server, Kerberos KDC and DNS services.

Features

  • File and printer sharing with Windows, macOS and Linux clients over SMB/CIFS and NetBIOS.
  • Membership in, or control of, Windows domains: Samba can be an NT4-style Primary Domain Controller or a full Active Directory DC.
  • Authentication services (winbind) integrating Unix logins with Windows domains.
  • Name resolution and browsing services (nmbd) and the main file-serving daemon smbd.

Security

Samba has a public security process with CVE advisories; notable vulnerabilities include the 2017 "SambaCry" remote-code-execution flaw (CVE-2017-7494) in the file-sharing code. Configuration is governed by the smb.conf file.
