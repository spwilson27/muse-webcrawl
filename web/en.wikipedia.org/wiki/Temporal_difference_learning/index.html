Temporal difference learning

Temporal difference (TD) learning is a class of model-free reinforcement learning methods that learn by bootstrapping from the current estimate of the value function. The name refers to the fact that updates are driven by the difference between temporally successive predictions. TD methods were developed principally by Richard Sutton in the 1980s and combine ideas from Monte Carlo methods and dynamic programming.

Method

In the simplest TD method, TD(0), the agent maintains an estimate V(s) of the value of each state. After each transition — observing reward r and moving to a new state s′ — the estimate is updated:

V(s) ← V(s) + α [ r + γ V(s′) − V(s) ]

where α is a learning rate and γ a discount factor. The bracketed quantity is called the TD error: the difference between the new one-step estimate and the previous prediction. Unlike Monte Carlo methods, which must wait until the end of an episode to learn the actual return, TD methods update after every step; unlike dynamic programming, they require no model of the environment's dynamics.

Algorithms

The most widely used TD control algorithms are SARSA, an on-policy method that updates action values using the action actually taken, and Q-learning, an off-policy method introduced by Chris Watkins that updates using the maximum action value of the next state. Extensions include TD(λ), which propagates credit over multiple steps using eligibility traces, and actor–critic methods, in which a TD critic evaluates the policy followed by an actor.

Applications and neuroscience

TD learning underlies famous systems such as Arthur Samuel's checkers player and Gerald Tesauro's TD-Gammon, which reached master-level backgammon play through self-play. In neuroscience, the TD error closely resembles the firing pattern of dopaminergic neurons in the midbrain, which signal reward prediction errors — a correspondence first highlighted in the 1990s that has strongly influenced computational theories of learning in the brain.
