Indexed color

From Wikipedia, the free encyclopedia

Indexed color is a technique in computer graphics for storing images in a compact form by mapping each pixel not to a full colour value, but to an index into a small table — the palette or colour look-up table (CLUT) — of the colours actually used in the image. With an 8-bit index, an image can display at most 256 distinct colours chosen from a much larger colour space, using one byte per pixel instead of the three bytes required by 24-bit RGB.

History and use

Indexed colour was a practical necessity in early personal computers and game consoles, whose video hardware offered limited memory and palette-based graphics modes. The GIF image format, introduced in 1987, is defined around palettes of up to 256 colours, and the PNG format also supports an indexed mode. To represent photographs in few colours, software uses colour quantization to choose an optimal palette, often combined with dithering to simulate intermediate shades.

Palette effects

Because rendering consults the table at display time, changing the palette changes the entire image at once — a trick exploited in early games and demos for effects such as flowing water, fades, and palette cycling animation. The technique survives today wherever memory is scarce or in retro-styled graphics, though direct-colour displays have made it unnecessary for most purposes.
