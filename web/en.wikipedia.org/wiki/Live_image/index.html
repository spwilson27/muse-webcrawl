Live image

A live image, live CD, live DVD, or live USB is a bootable computer storage medium — typically a complete operating system image — that can be run directly from the medium without installation onto a hard drive. Live images are widely used to try out operating systems, recover data from damaged systems, and perform installation or diagnostic tasks.

Characteristics

A live image loads the operating system into memory and runs from a read-only filesystem, often using an overlay so that changes made during the session are stored in RAM and lost on reboot (unless persistence is configured). Most Linux distributions offer live images that double as installers.

History

Early live systems appeared in the 1990s; Knoppix, released in 2000, popularized the live CD by providing automatic hardware detection and a full desktop environment. Live USB media later largely replaced optical discs because of greater capacity and speed.

Uses

  • Evaluating an operating system without modifying the installed system
  • System rescue, data recovery, and password or partition repair
  • Secure or ephemeral computing on untrusted hardware
  • Installing the operating system to permanent storage
