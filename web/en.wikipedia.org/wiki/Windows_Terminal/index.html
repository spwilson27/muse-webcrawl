Windows Terminal is a multi-tabbed terminal emulator developed by Microsoft for Windows 10 and later, replacing the legacy Windows Console as the default terminal application in Windows 11. It can run multiple command-line interfaces — including Command Prompt, PowerShell, Windows Subsystem for Linux shells, and Azure Cloud Shell — in separate tabs and panes within one window.

Features

Windows Terminal supports Unicode and UTF-8 character rendering, GPU-accelerated text rendering, Cascadia Code font, background images, custom color schemes, and extensive keyboard customization. Settings are stored in a JSON file, and the application is free and open-source, distributed through the Microsoft Store, GitHub, and as the in-box default terminal in Windows 11 (from version 22H2).

History

Microsoft announced Windows Terminal at its Build developer conference in May 2019; version 1.0 shipped in May 2020. It was developed to modernize the Windows command-line experience, whose underlying console infrastructure dated to the early 1990s.
