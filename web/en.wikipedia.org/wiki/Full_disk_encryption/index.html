Disk encryption

Full disk encryption (FDE) is a form of disk encryption in which every bit of data on a storage volume is encrypted, including the operating system partition. On-the-fly encryption and decryption are transparent to the user once the volume is unlocked, usually with a password, PIN or hardware token at boot time.


Pre-boot authentication

How it works

Software encrypts disk sectors using a symmetric cipher such as AES, commonly in XTS mode, which is designed for block storage. A master volume key encrypts the data; the volume key is itself protected by keys derived from the user's credentials, often with the help of a Trusted Platform Module (TPM) that also measures the boot process. Because encryption occurs below the file system, temporary files, swap space and deleted-but-recoverable data are protected as well.

Software

Common implementations include BitLocker on Windows, FileVault on macOS, LUKS/dm-crypt on Linux, and the cross-platform VeraCrypt, a successor of TrueCrypt. Many modern mobile devices encrypt all user data by default, tying keys to the device hardware.

Limitations

Full disk encryption protects data at rest only; it offers no defence once the machine is running and unlocked, and is vulnerable to attacks such as cold-boot attacks, evil-maid attacks on the boot process, and compelled disclosure of passwords.
