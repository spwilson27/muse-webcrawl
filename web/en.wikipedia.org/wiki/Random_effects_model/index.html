Random effects model

A random effects model (also called a variance components model) is a statistical model in which some parameters are treated as random variables drawn from a distribution, rather than as fixed unknown constants. It contrasts with a fixed effects model, where all parameters are fixed.

Panel data

In econometrics, for panel data the random effects specification assumes individual-specific intercepts are random draws uncorrelated with the regressors, which allows more efficient estimation (by generalised least squares) than fixed effects when the assumption holds. The Hausman test compares the two specifications to check that assumption.

Meta-analysis

In meta-analysis, a random-effects model (such as the DerSimonian–Laird method) assumes the true effect sizes vary across studies according to a distribution, incorporating between-study heterogeneity (τ²) into the weights. This produces wider confidence intervals than a fixed-effect meta-analysis when heterogeneity is present.
