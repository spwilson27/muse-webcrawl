Kernel smoother

A kernel smoother fitted to noisy data

A kernel smoother is a statistical technique to estimate a real valued function as the weighted average of neighboring observed data. The weight is defined by the kernel, such that closer points are given higher weights. The estimated function is smooth, and the level of smoothness is set by a single parameter called the bandwidth. Kernel smoothing is a type of local nonparametric regression.

Kernels

Common kernel functions include the uniform (boxcar), triangular, Epanechnikov, Gaussian, and biweight kernels. In practice, the choice of kernel has only a modest effect on accuracy; the bandwidth, which controls the bias–variance tradeoff, is more important. Very small bandwidths produce wiggly, overfitted curves, while very large bandwidths oversmooth and bias the estimate.

Types of kernel smoothers

  • Nadaraya–Watson estimator — a locally weighted average (locally constant fit) using a kernel as a weighting function.
  • Local linear and local polynomial regression — fits low-degree polynomials locally, reducing boundary bias.
  • Kernel density estimation — the related technique for estimating a probability density function.
