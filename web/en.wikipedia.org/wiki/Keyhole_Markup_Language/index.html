Keyhole Markup Language

Keyhole Markup Language (KML) is an XML notation for expressing geographic annotation and visualization within two-dimensional maps and three-dimensional Earth browsers. KML was developed for use with Google Earth, which was originally named Keyhole Earth Viewer. It was created by Keyhole, Inc, which was acquired by Google in 2004. KML became an international standard of the Open Geospatial Consortium (OGC) in 2008. The first Google Earth visualizations using KML files were published by amateur enthusiasts sharing annotations of places.

Structure

The KML file specifies a set of features (placemarks, images, polygons, 3D models, textual descriptions, etc.) that can be displayed on maps in geospatial software implementing the KML encoding. Each place always has a longitude and a latitude. Other data can make the view more specific, such as tilt, heading, or altitude, which together define a "camera view". KML shares some of the same structural grammar as Geography Markup Language (GML). KML files are very often distributed as KMZ files, which are zipped files with a .kmz extension containing a root KML document and any linked resources.

<Placemark>
  <name>Eiffel Tower</name>
  <Point>
    <coordinates>2.2945,48.8584,0</coordinates>
  </Point>
</Placemark>

Features

KML supports a range of geographic features:

  • Placemarks — points with icons, names and descriptions
  • Paths and polygons — lines and areas drawn on the ground
  • Ground and screen overlays — images draped over terrain or fixed to the display
  • 3D models — buildings and other objects positioned in the scene
  • Styles — colours, icons and labels applied to features
  • Network links — references to KML data hosted on remote servers, enabling dynamic updates
  • Tours — scripted flights through a scene

Standardisation

The OGC KML 2.2 standard was approved in April 2008, making KML the first "mass-market" geographic encoding to be adopted as an open standard. Google submitted KML to the OGC in 2007 while retaining compatibility with Google Earth. KML 2.2 supplements the Geography Markup Language and coexists with it; GML remains the more general standard for exchanging full geographic information system data.
