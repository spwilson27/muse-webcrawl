Lasso (statistics)

The diamond-shaped L1 constraint region encourages sparse solutions.
TypeRegularized regression
Introduced1996, Robert Tibshirani

In statistics and machine learning, the lasso (least absolute shrinkage and selection operator) is a regression analysis method that performs both variable selection and regularization in order to enhance prediction accuracy and interpretability. It was introduced by Robert Tibshirani in 1996.

minimize Σ(yᵢ − Σβⱼxᵢⱼ)² subject to Σ|βⱼ| ≤ t

Equivalently, the lasso adds an L1 penalty, λΣ|βⱼ|, to the least-squares objective. Because the L1 penalty has corners, the solution tends to set many coefficients exactly to zero, producing sparse models — a property not shared by ridge regression's L2 penalty.

Properties and extensions

The lasso is widely used in high-dimensional problems where the number of predictors exceeds the number of observations, and in compressed sensing. Variants include the elastic net (combining L1 and L2 penalties), the adaptive lasso, group lasso and fused lasso. Coefficients can be computed efficiently along the whole regularization path by algorithms such as least-angle regression (LARS) and coordinate descent.
