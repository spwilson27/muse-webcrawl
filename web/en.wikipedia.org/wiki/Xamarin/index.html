Xamarin

Xamarin is a Microsoft-owned software company and an associated set of developer tools that allow programmers to build cross-platform mobile applications for Android, iOS and other platforms using the C# programming language and the .NET framework. It was founded in May 2011 in San Francisco by engineers including Miguel de Icaza and Nat Friedman, who had previously created the Mono project.

History

Xamarin grew out of Mono, an open-source implementation of Microsoft's .NET framework created at Ximian and later Novell. After Attachmate laid off the Mono team in 2011, de Icaza and Friedman founded Xamarin to continue the technology commercially, focusing on mobile development. The company's products compiled C# code to native executables: Xamarin.iOS ahead-of-time compiled to ARM assembly for Apple's platform, while Xamarin.Android compiled to intermediate language run on a runtime alongside Android's. Microsoft announced its acquisition of Xamarin in February 2016 and subsequently made the tools free with Visual Studio and open-sourced the SDKs.

Products and succession

Xamarin.Forms, released in 2014, provided a shared user-interface toolkit in XAML or C# that rendered native controls on each platform. Microsoft evolved the technology into .NET MAUI (.NET Multi-platform App UI), and official support for Xamarin ended on 1 May 2024, with MAUI as its successor.
