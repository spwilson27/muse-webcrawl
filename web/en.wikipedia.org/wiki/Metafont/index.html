Metafont

Metafont (stylised as METAFONT) is a description language used to define raster fonts. It is also the name of the interpreter that executes Metafont code, generating bitmap fonts that can be embedded in documents, for example in PostScript files. Metafont was devised by Donald Knuth as a companion to his TeX typesetting system, starting in 1977 and substantially redesigned in 1984.

Parametric fonts

Unlike outline font formats, Metafont defines glyphs as mathematical equations and programs: each letterform is drawn by pens of specified shapes moving along paths, and a whole typeface family can be altered by changing parameters such as stem width, x-height or serif style. Knuth used the system to create the Computer Modern family, TeX's default typeface.

Output and legacy

Metafont outputs bitmap fonts at a specified resolution together with font metric (TFM) files. Although the rise of scalable outline fonts limited its mainstream adoption, Metafont remains influential as the archetype of parametric font design, and successors and relatives include MetaPost, which produces vector graphics from a similar language.
