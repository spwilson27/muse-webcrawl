Second-order cone programming

A second-order cone program (SOCP) is a convex optimisation problem that minimises a linear function subject to linear equality constraints and constraints requiring an affine combination of the variables to lie in a product of second-order (Lorentz) cones. SOCPs generalise linear and quadratic programs and include least-squares problems, robust linear programming, portfolio optimisation and many problems in control, signal processing and antenna design.

Formulation and solution

In standard form, an SOCP minimises cTx subject to Ax = b and, for each i, ||Aix + bi||2 ≤ ciTx + di, constraints that define convex sets because the Lorentz cone is convex. SOCPs can be solved efficiently in polynomial time by primal-dual interior point methods and are supported by modelling tools and solvers such as MOSEK, ECOS and SCS.
