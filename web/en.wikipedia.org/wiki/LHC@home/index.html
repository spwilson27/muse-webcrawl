LHC@home

LHC@home is a volunteer computing project run by CERN, the European Organization for Nuclear Research, which uses the idle processing power of volunteers' computers to simulate particle beam behaviour for the Large Hadron Collider (LHC) and to run computing jobs for LHC experiments. It runs on the Berkeley Open Infrastructure for Network Computing (BOINC) platform.

History

The project began in 2004 with the SixTrack application, created to test the long-term stability of proton orbits in the LHC: volunteers' computers each simulated tens of thousands of particle turns around the ring to verify that beams would remain stable over many hours of operation. The results contributed to the collider's design and commissioning. In 2011 the various CERN BOINC activities were consolidated under the single LHC@home banner.

Applications

  • SixTrack / SixTracktest — beam dynamics simulations for the LHC and its high-luminosity upgrade.
  • Theory (formerly Test4Theory) — Monte Carlo event generation for theoretical particle physics, an early showcase of virtualisation with the CERNVM virtual machine.
  • CMS, ATLAS and LHCb — production simulation jobs for the LHC experiments, distributed via virtual machines.
  • Beauty and other smaller subprojects have run at various times.

LHC@home was among the first large projects to distribute work through virtual machine images, letting complex scientific software run identically on volunteers' Windows, macOS and Linux machines.
