Root test

In mathematics, the root test is a criterion for the convergence of an infinite series. It is also known as the nth root test or Cauchy's root test, after Augustin-Louis Cauchy, who first published it. It depends on the behaviour of the nth root of the absolute value of the terms of the series.

Statement

Let Σ an be an infinite series of real or complex terms. Define

C = lim supn→∞ (|an|)1/n.

Then:

  • If C < 1, the series converges absolutely.
  • If C > 1, the series diverges.
  • If C = 1, the test is inconclusive — the series may converge or diverge.

Intuition

The test compares the series with a geometric series. If |an|1/n is eventually less than a number r < 1, then the terms are eventually bounded by rn, and the series converges by comparison with the geometric series Σ rn. If instead |an|1/n is greater than 1 along a subsequence, the terms do not even tend to zero, so the series diverges.

Relation to the ratio test

The root test is stronger than the ratio test: whenever the ratio test determines convergence or divergence, the root test does too, but the converse is not true. In fact, for any series,

lim inf |an+1/an| ≤ lim inf |an|1/n ≤ lim sup |an|1/n ≤ lim sup |an+1/an|,

so if the limit of the ratio exists, the limit of the nth root exists and equals it. The root test is especially convenient for series whose terms involve nth powers.

Example

For the series Σ (n/(2n+1))n, the nth root of the term is n/(2n+1), which tends to 1/2 < 1, so the series converges absolutely. By contrast, both the convergent series Σ 1/n2 and the divergent series Σ 1/n give C = 1, illustrating the inconclusive case.
