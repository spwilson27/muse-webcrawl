Affine hull

In mathematics, the affine hull of a set S in a Euclidean or affine space is the smallest affine subspace containing S. It consists of all affine combinations of points of S: all sums λ1x1 + … + λkxk where the coefficients λi sum to 1.

Examples

The affine hull of a single point is the point itself; of two distinct points, the line through them; of three non-collinear points, the plane containing them; and of four non-coplanar points in three-dimensional space, the whole space. The empty set has the empty set as its affine hull.

Properties

The dimension of a set is defined as the dimension of its affine hull. A set whose affine hull is the whole space is called affinely spanning. The affine hull is related to the linear span by translating the set so that it contains the origin, and it plays a central role in convex geometry, where the relative interior of a convex set is defined relative to its affine hull.
