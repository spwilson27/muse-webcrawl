WebGL (Web Graphics Library) is a JavaScript API for rendering interactive 2D and 3D graphics within any compatible web browser without the use of plug-ins. It is based on OpenGL ES and is managed by the Khronos Group as a non-profit consortium, and it is supported natively by all major modern browsers. WebGL allows web developers to use the graphics processing unit (GPU) to draw hardware-accelerated graphics directly into an HTML canvas element.

History

WebGL grew out of Mozilla's "Canvas 3D" experiments in 2006–2007. Vladimir Vukićević at Mozilla created the first prototype, and in 2009 the Khronos Group formed the WebGL working group. WebGL 1.0 was released in March 2011, based on OpenGL ES 2.0, with shaders written in GLSL ES. WebGL 2.0, based on OpenGL ES 3.0 and released in 2017, added features such as 3D textures, transform feedback, and instanced rendering.

Use and ecosystem

WebGL is used for browser games, data visualisation, scientific visualisation, CAD viewers, and product configurators. Popular libraries built on WebGL include Three.js, Babylon.js, and PixiJS, which abstract its low-level API. WebGL content runs on desktops, mobile devices, and virtual reality headsets via WebXR. Security concerns — a WebGL context exposes GPU capabilities — led to extensive work on validation and sandboxing, and all major browsers now ship WebGL enabled by default.

Successor

WebGPU, a newer API also standardised through the W3C, offers a lower-level, more modern GPU interface and is being adopted alongside WebGL for performance-critical applications; WebGL remains widely used for its broad compatibility and extensive library ecosystem.
