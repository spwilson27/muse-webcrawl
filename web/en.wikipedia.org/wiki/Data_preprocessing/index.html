Data preprocessing

Data preprocessing is a component of data preparation that transforms raw data into a format suitable for a specific data-mining or machine-learning task. It is an important step in the data science pipeline, as the quality of data and the information that can be extracted from it directly affect the ability of a model to learn; it is often said that most of a data scientist's effort is spent on preprocessing.

[ Hero image: Flowchart of a typical data preprocessing pipeline ]

Main tasks

  • Data cleaning — correcting errors, filling in or removing records with missing values, and handling outliers and duplicates.
  • Data transformation — normalisation and standardisation of numeric features, encoding of categorical variables (for example one-hot encoding), and discretisation.
  • Data reduction — dimensionality reduction, sampling, and feature selection to shrink volume while preserving information.
  • Data integration — combining data from multiple sources and resolving conflicts between them.

Issues

Missing values may be handled by deletion, mean or median imputation, or model-based estimation; each choice can bias results if the missingness is not random. Preprocessing must be fitted on training data only — applying statistics computed from the full data set, such as a global mean, leaks information about the test set and produces over-optimistic evaluations, a pitfall known as data leakage.
