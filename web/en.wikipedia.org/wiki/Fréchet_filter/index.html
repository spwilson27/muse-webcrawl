Fréchet filter

In mathematics, the Fréchet filter, also called the cofinite filter, on a set X is the collection of all subsets of X whose complement is finite. It is named after the French mathematician Maurice Fréchet.

Definition

A set B is a member of the Fréchet filter on X if and only if the complement X \ B is finite. The Fréchet filter is a genuine filter precisely when X is infinite; on a finite set the collection would contain the empty set and fail to be a proper filter. It is the smallest (coarsest) filter that contains all the finite sets' complements, and it is contained in every free ultrafilter on X.

Uses

The Fréchet filter underlies the standard notion of a "limit at infinity": a sequence converges in the Fréchet sense if the set of indices where it deviates from a limit by more than any given amount is finite. In topology, it defines the cofinite topology on a set, and in model theory it is the starting point for the construction of ultraproducts via free ultrafilters extending it.
