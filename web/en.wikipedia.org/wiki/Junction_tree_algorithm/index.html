Junction tree algorithm

TypeProbabilistic inference algorithm
Used forComputing marginal distributions in graphical models
RelatedBelief propagation, variable elimination, clique tree

The junction tree algorithm (also known as the clique tree algorithm) is a method for exact inference in probabilistic graphical models such as Bayesian networks and Markov random fields. It generalizes belief propagation from trees to arbitrary graphs by reorganizing the graph into a tree of clusters.

Description

The algorithm proceeds by moralizing and triangulating the graph, identifying its maximal cliques, and arranging those cliques into a junction tree that satisfies the running intersection property. Probability potentials are assigned to cliques, and evidence is incorporated before a two-phase message-passing procedure — a collect (inward) pass and a distribute (outward) pass — calibrates the tree so that each clique's beliefs are consistent with its neighbors.

Properties

After calibration, the marginal distribution of any variable can be read from a clique containing it. The computational cost is exponential in the size of the largest clique (related to the graph's treewidth), which limits the method to models of modest treewidth. The algorithm was developed from the work of Lauritzen and Spiegelhalter and of Jensen and colleagues in the late 1980s.
