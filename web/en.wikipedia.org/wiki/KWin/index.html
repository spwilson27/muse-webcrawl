KWin

KWin
Developer: KDE
Type: Window manager and compositor
Platforms: X11, Wayland
License: GPL

KWin is a window manager and compositing manager for the KDE Plasma desktop environment. It manages the placement and appearance of application windows and provides desktop effects, and it serves as KDE's compositor for both X11 and Wayland sessions.

History

KWin was first released in 2000 as the successor to KWM, the window manager of KDE 1. Over successive releases it gained compositing support, desktop effects such as wobbly windows and the desktop cube, and scripting in JavaScript and QML. With KDE Plasma 5 and 6, KWin became the standard Wayland compositor for the desktop.

Features

KWin supports tiling options, virtual desktops, activities, window rules, screen-edge actions and a wide range of accessibility and visual effects. Its behaviour is extensively configurable through KDE System Settings.
