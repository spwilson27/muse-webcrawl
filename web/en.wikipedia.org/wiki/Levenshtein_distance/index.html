Levenshtein distance

In information theory, linguistics, and computer science, the Levenshtein distance (also called the edit distance) is a string metric for measuring the difference between two sequences. Informally, the Levenshtein distance between two words is the minimum number of single-character edits (insertions, deletions or substitutions) required to change one word into the other.

It is named after the Soviet mathematician Vladimir Levenshtein, who considered this distance in 1965. For example, the Levenshtein distance between "kitten" and "sitting" is 3.

Definition and algorithm

The distance can be computed with a dynamic programming algorithm (the Wagner–Fischer algorithm) that fills a matrix whose entries give the distance between prefixes of the two strings. The algorithm runs in time proportional to the product of the lengths of the strings.

Applications

Applications include spell checking, approximate string matching, DNA sequence analysis, plagiarism detection and natural language processing. Variants include the Damerau–Levenshtein distance, which also counts transpositions, and the Hamming distance, which only allows substitutions.
