Prix fixe

Prix fixe (French for "fixed price") is a menu in which a meal of several courses is offered at a single set price. It contrasts with à la carte, in which each item is priced separately.

Usage

Prix fixe menus are common for tasting menus, pre-theatre dinners, and holiday services. They may offer choices within each course or present a fixed sequence chosen by the chef. The format can also appear in banquets and catering, where a set menu simplifies service.
