Reduced instruction set computer

A reduced instruction set computer (RISC) is a type of central processing unit architecture characterised by a small, highly optimised set of instructions, typically of fixed length, with a load–store design in which memory is accessed only by dedicated load and store instructions and all other operations act on registers.

Design philosophy

RISC designs aim to execute most instructions in a single clock cycle by using simple instructions, extensive pipelining and large register files, pushing complexity from hardware into the compiler. The approach emerged from research projects such as IBM's 801 project (begun 1975) and the Berkeley RISC and Stanford MIPS projects of the early 1980s, which showed that most processor time was spent on a small subset of instructions.

Examples and contrast

Prominent RISC architectures include ARM, MIPS, RISC-V, SPARC and PowerPC. RISC is conventionally contrasted with CISC (complex instruction set computer), exemplified by x86, though modern processors blur the distinction internally.
