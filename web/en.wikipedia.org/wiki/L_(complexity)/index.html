L (complexity)

In computational complexity theory, L (also known as LSPACE or DLOGSPACE) is the complexity class containing decision problems that can be solved by a deterministic Turing machine that uses a polynomial amount of time and only a logarithmic amount of writable memory space. Conceptually, L includes problems that can be solved while keeping track of only a constant number of pointers into the input and a logarithmic amount of other state.

Relations among logarithmic-space and polynomial classes

Properties

Analogous to the definition of L, the class NL is the set of problems solvable in logarithmic space by a nondeterministic machine. It is known that L ⊆ NL ⊆ P, and by Savitch's theorem NL ⊆ SPACE((log n)²). Whether L = NL was a long-standing open problem, settled in part for the important special case of graph reachability: Omer Reingold proved in 2005 that undirected graph connectivity is in L (SL = L), a result that earned wide recognition; directed reachability, however, is complete for NL.

Complete problems and function problems

Problems known to be complete for L under log-space reductions are relatively rare; examples include evaluating formulas over certain finite structures and problems concerning permutations and matrix powering over small dimensions. The associated function class FL captures functions computable in log space and is used to define log-space reductions between problems.
