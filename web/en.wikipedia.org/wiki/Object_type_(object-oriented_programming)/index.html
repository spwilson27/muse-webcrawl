In object-oriented programming, an object type is a data type whose values are objects: structured bundles of state (fields or attributes) and behaviour (methods) that are treated as a single unit. An object type defines the common structure and operations shared by all of its instances, and is typically specified by a class or by an interface declaration.

Definition

An object type consists of two parts: a set of instance variables that hold the object's state, and a set of methods that can be invoked on the object. When a program sends a message to an object, the method associated with the object's type is executed. The type of an object determines which messages it can respond to, which is the basis for polymorphism: code written against a general object type can operate on any object whose type conforms to it.

Object types and classes

In class-based languages such as Java, C++ and C#, a class serves both as the factory for objects and as their type. In prototype-based languages such as JavaScript, object types emerge from prototype chains rather than class declarations. Some languages, including Go, treat object types structurally: a value belongs to an interface type if it provides the required methods, regardless of any declared relationship.

Subtyping and polymorphism

Object types usually form hierarchies through inheritance. A subtype can be used wherever its supertype is expected (the Liskov substitution principle), so a variable declared with a general object type may at run time hold an object of any subtype. Dynamic dispatch then selects the most specific method implementation.

Object types in specific languages

  • Smalltalk — everything is an object; the root type is Object.
  • Java — every class ultimately derives from java.lang.Object.
  • Python — all values are objects of some class; type itself is an object.
  • Ruby — a fully object-oriented model in which classes are themselves objects.
