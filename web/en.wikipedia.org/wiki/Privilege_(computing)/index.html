Privilege (computing)

Privilege
Field: Computer security
Related concepts: Principle of least privilege, privilege escalation, protection ring

In computing, privilege is defined as the delegation of authority to perform security-relevant functions on a computer system. A privilege allows a user or process to perform an action that would otherwise be disallowed, such as modifying system files, loading kernel modules, or accessing other users' data.

Levels of privilege

Operating systems distinguish between privileged (administrator, root, or kernel) and unprivileged (ordinary user) execution. Hardware often implements this as protection rings, with the kernel running in the most privileged ring. Unix-like systems use the root account and mechanisms such as sudo and capabilities; Windows uses administrator accounts and access tokens.

Least privilege and escalation

The principle of least privilege holds that each user or process should have only the privileges needed for its task, limiting damage from errors or compromise. Privilege escalation — gaining privileges beyond those intended — is a common goal of attacks and a serious class of vulnerability.
