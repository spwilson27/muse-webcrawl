Pitch-class set

A pitch-class set is a collection of pitch classes used in musical set theory, a branch of music theory and analysis developed primarily in the United States in the mid-twentieth century. Because pitch classes are defined modulo octave equivalence, a pitch-class set groups together all pitches that share the same name in any octave: every C, for example, belongs to pitch class 0 (or pitch class C).

Notation

Analysts commonly notate pitch classes with integers 0 through 11, where 0 represents C, 1 represents C♯/D♭, and so on up to 11 for B. A pitch-class set is then written as an unordered collection of integers, such as {0, 1, 4} for the pitches C, C♯, and E. Two sets that are related by transposition or inversion are often considered members of the same set class.

Set classes and prime form

To compare sets systematically, theorists reduce each set to its normal order (the most compact ordering of its members) and then to its prime form, a canonical representative obtained by transposing the set so that its first member is 0 and choosing between the set and its inversion. Allen Forte's catalogue, published in The Structure of Atonal Music (1973), assigned each set class a "Forte number" (for example, 3-1 for the chromatic trichord {0,1,2}); John Rahn later proposed an alternative numbering. Sets are also characterised by their interval vector, which counts how many of each interval class the set contains.

Applications

Set theory was designed to analyse atonal and twelve-tone music by composers such as Arnold Schoenberg, Anton Webern, and Milton Babbitt, where traditional harmonic categories offer little guidance. It has since been applied to tonal music, folk traditions, and popular music, and concepts such as complementation (the relationship between a set and the pitches that complete the aggregate) and invariance underlay much of its analytical power. Critics have questioned whether set-theoretic groupings correspond to anything listeners actually hear, but the framework remains central to North American music theory.
