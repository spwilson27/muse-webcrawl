z/VM

Developer: IBM

Type: Hypervisor (Type 1)

Platform: IBM Z

z/VM is the current version in the VM family of IBM virtual machine operating systems. z/VM is built on the Control Program (CP) hypervisor, which allows a single IBM Z mainframe to run many independent virtual machines, each hosting its own guest operating system such as z/OS, z/VSE, or Linux on IBM Z.

History

The VM line descends from CP-40 and CP-67, developed at IBM's Cambridge Scientific Center in the 1960s, and from VM/370, released in 1972. Successive generations — VM/SP, VM/XA, and VM/ESA — led to z/VM, announced in 2000 alongside the 64-bit z/Architecture.

Features

z/VM provides the Conversational Monitor System (CMS) as a single-user guest environment, supports thousands of concurrently running Linux guests, and offers facilities such as single system image (SSI) clustering and live guest relocation between members of an SSI cluster.
