z/OS

z/OS is a 64-bit operating system for IBM Z mainframe computers, produced by IBM. It derives from and is the successor to OS/390, which in turn followed a line of MVS versions. Like OS/390, z/OS combines a number of formerly separate, related products, some of which remain optional.

History

IBM announced z/OS in October 2000 alongside the new zSeries 900 (later IBM Z) 64-bit mainframe hardware, and shipped the first release in March 2001. It was the first IBM mainframe operating system to support 64-bit addressing. z/OS succeeded OS/390, which had itself consolidated the MVS lineage that began with OS/360 in the 1960s.

Features

z/OS supports stable mainframe facilities such as CICS, IMS, DB2, RACF and SNA, in parallel with features of newer platforms such as Java, TCP/IP, and a UNIX environment (UNIX System Services). It includes Workload Manager (WLM), which dynamically manages system resources against business goals, and supports Parallel Sysplex clustering. The operating system is designed for very large-scale transaction processing and batch workloads with extremely high reliability, availability and security requirements, and is widely used by banks, insurers, airlines and governments.

Releases

IBM originally released new versions of z/OS roughly annually, later moving to a two-year cycle; since z/OS 3.1 the product has used a continuous-delivery model. The most recent major releases are z/OS 2.5 (2021) and z/OS 3.1 (2023).
