Continuation

In computer science, a continuation is an abstract representation of the control state of a computer program. A continuation implements the program state — essentially, "the rest of the computation" from a given point — as a data structure accessible to the program itself. Continuations are useful for encoding control mechanisms such as exceptions, backtracking, the generator pattern (yield), and coroutines, and they can be used to implement concurrency and web-server session handling.

First-class continuations

A first-class continuation is an entity that can be created, stored, composed and invoked like any other value in the language. The classic operator is call-with-current-continuation (abbreviated call/cc) in the Scheme programming language: it captures the current continuation as a procedure of one argument; invoking that procedure abandons the current computation and resumes the captured one with the supplied value. Because a captured continuation can be invoked multiple times, it can model backtracking search; because it can be invoked later, it can model threads and coroutines. Continuations are foundational in the semantics of programming languages: any program can be rewritten in continuation-passing style (CPS), in which functions never return but instead pass results to an explicit continuation, and denotational semantics uses continuations to give meaning to jumps and exceptions.

Delimited continuations

Full (undelimited) continuations capture the entire remaining computation, which can be difficult to compose. Delimited continuations capture only up to a specified boundary, marked in languages or libraries by operators such as shift and reset (introduced by Olivier Danvy and Andrzej Filinski). Delimited continuations underlie many implementations of algebraic effects and effect handlers, async/await-style concurrency, and probabilistic programming constructs.

Practical languages

Scheme, some ML dialects, and Ruby (callcc) expose first-class continuations directly. Other platforms provide restricted versions: C's setjmp/longjmp, Java's Project Loom virtual threads, and the promises and generators of Python and JavaScript can be understood as more limited continuation mechanisms. Stackless implementations of Python and certain web servers have used continuations to suspend and resume a computation across HTTP requests.
