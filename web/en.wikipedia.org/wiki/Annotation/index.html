Annotation

From Wikipedia, the free encyclopedia

An annotation is a note added to a text, image, or other work that provides explanation, commentary, or additional information. Annotations include footnotes, endnotes, marginalia, glosses, and editorial apparatus in scholarly editions, as well as structured metadata added to digital documents, images, genomic sequences, and computer code.

In texts and scholarship

Medieval manuscripts were routinely surrounded by glosses that explained difficult passages; in printed books this role passed to footnotes and commentary. An annotated edition of a literary or legal text supplements the original with notes on sources, variant readings, historical background, and interpretation. An annotated bibliography lists sources, each followed by a brief summary and evaluation of its content and usefulness. Readers' private annotations in margins — marginalia — can themselves become historically significant, as with the notes of Samuel Taylor Coleridge or Pierre de Fermat.

In computing and data

In software engineering, annotations attach metadata to code elements: in Java, annotations (introduced in 2004) influence compilation and runtime behaviour, and similar mechanisms exist in other languages. In linguistics and machine learning, annotation denotes labelling data — for example, tagging parts of speech in a corpus or drawing bounding boxes in images — to create training sets. Genome annotation identifies genes and functional elements within a DNA sequence. The W3C Web Annotation Data Model standardises annotations of web resources so that comments and tags can be shared across platforms.
