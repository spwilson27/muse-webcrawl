TypeQuery language for XML tree structures

XPath (XML Path Language) is an expression language designed to navigate and select nodes in an XML document. Defined by the W3C, it models a document as a tree of nodes (elements, attributes, text, namespaces, comments and processing instructions) and provides path expressions for addressing parts of that tree. XPath is a foundational component of XSLT, XPointer, XQuery and XML Schema identity constraints, and is also widely used from general-purpose programming languages to query XML and, by extension, HTML documents.

Syntax and axes

A location path is a sequence of steps separated by /; each step consists of an axis, a node test, and optional predicates in square brackets. Axes describe the direction of navigation relative to a context node: child (the default), parent, ancestor, descendant, following-sibling, attribute (abbreviated @), self and others. Abbreviated syntax is common in practice:

//book[@year > 2000]/title

selects the titles of all book elements anywhere in the document whose year attribute exceeds 2000. Predicates may also use the built-in function library — over 100 functions in XPath 1.0 for strings, numbers, booleans and node-sets, such as count(), contains() and position().

Versions

XPath 1.0 (1999) established the core model. XPath 2.0 (2007) introduced a richer type system aligned with XML Schema, sequences replacing node-sets, and regular expressions. XPath 3.0 added higher-order functions and dynamic function calls; XPath 3.1 (2017) added maps and arrays, chiefly to interoperate with JSON data. Implementations exist in virtually every XML toolchain and in web browsers, where XPath can be evaluated against the DOM alongside CSS selectors.
