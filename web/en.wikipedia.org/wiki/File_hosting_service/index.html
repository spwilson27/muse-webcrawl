File hosting service

A file hosting service, also known as a cloud storage service or online file storage provider, is an Internet hosting service designed to host user files. It allows users to upload files that can then be accessed over the Internet from a different computer, tablet, smart phone or other networked device, using a username and password or other authentication.

Types

Personal file hosting services store private files for backup and remote access, and include services such as Dropbox, Google Drive, iCloud, and OneDrive. One-click hosting services provide public download links for sharing large files. Image and video hosting services specialise in media. Synchronisation services, a related category, keep files consistent across multiple devices.

Business models and issues

Many services use a freemium model, offering limited free storage with paid tiers for more space and features. File hosting has raised legal questions around copyright infringement, since hosted content can include pirated material, leading services to adopt takedown procedures and content-scanning. Providers also face concerns about privacy, data security, and the longevity of stored data.
