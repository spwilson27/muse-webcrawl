Quantization (signal processing)

In signal processing, quantization is the process of mapping input values from a large set (often a continuous set) to output values in a smaller, countable set — most commonly, rounding values to a fixed number of discrete levels. It is a core step in converting an analogue signal into digital form, following sampling, and is performed by an analog-to-digital converter.

A continuous signal approximated by 3-bit (eight-level) quantization.

Basic types

A uniform quantizer divides the input range into levels of equal spacing; a quantizer with N bits produces 2^N output levels. Non-uniform quantizers, such as the μ-law and A-law companders used in telephony, use finer steps for small signals and coarser steps for large ones, matching the sensitivity of human hearing. Vector quantization quantises blocks of samples jointly and underlies many data-compression schemes.

Quantization error

Because quantization discards information, it introduces quantization error — the difference between input and output. Modelled as noise, this error yields the familiar rule of thumb that each additional bit improves the signal-to-noise ratio by about 6 dB. Dithering — adding a small amount of noise before quantization — decorrelates the error from the signal and can improve perceived quality, especially in digital audio and images. Overload (clipping) occurs when inputs exceed the quantizer's range.

Applications

Quantization appears in digital audio (e.g. 16-bit CD samples), digital images, speech and video codecs, digital communications, and the compression of neural network weights for efficient inference. Rate–distortion theory studies the fundamental trade-off between bit rate and the distortion quantization introduces.
