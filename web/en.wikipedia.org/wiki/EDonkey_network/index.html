eDonkey network

The eDonkey Network (also known as the eDonkey2000 network or eD2k) is a decentralized, mostly server-based, peer-to-peer file sharing network created in 2000 by US developers Jed McCaleb and Sam Yagan. It was designed for sharing large files among many users and for providing long-term availability of files, because files remain available from multiple sources even when the original uploader goes offline.

Features

Clients connect to servers that index available files and user locations. Files are identified by MD4-root hashes (in later versions, a combined MD4/SHA-1 "AICH" hash set) that allow a file to be assembled from chunks downloaded simultaneously from many sources, with corrupted chunks detected and re-downloaded. This swarming approach, similar in spirit to BitTorrent, made eD2k particularly effective for distributing large files such as CD images and videos.

Clients

The original client was eDonkey2000 by MetaMachine. After MetaMachine discontinued it in 2005 — following a cease-and-desist letter from the RIAA and a $30 million settlement in 2006 — the open-source client eMule became the most popular way to access the network, alongside aMule, MLDonkey, and Shareaza.

Legal issues

The network was heavily used for sharing copyrighted material, which brought sustained legal pressure. The Razorback2 servers, among the largest on the network, were seized by Belgian police in 2006. Usage declined through the late 2000s as BitTorrent grew dominant, though the network continues to operate on a small scale.
