Model checking

In computer science, model checking is a method for automatically verifying correctness properties of finite-state systems. Given a model of a system — for example a circuit design, a communication protocol, or a software program — and a formal specification expressed in temporal logic, a model checker exhaustively explores the model's state space to determine whether the specification holds; if not, it produces a counterexample trace.

Overview

The technique was developed independently in the early 1980s by Edmund M. Clarke and E. Allen Emerson, and by Jean-Pierre Queille and Joseph Sifakis. Its principal obstacle is the state explosion problem: the number of states grows exponentially with the number of system components. Advances that made model checking practical include symbolic representation with binary decision diagrams, bounded model checking using SAT solvers, abstraction, and partial-order reduction.

Applications and tools

Model checking is used in hardware verification, protocol analysis, and increasingly in software verification. Widely used tools include SPIN, developed for concurrent software systems; NuSMV; and UPPAAL for real-time systems. Clarke, Emerson, and Sifakis received the 2007 Turing Award for their work on the method.
