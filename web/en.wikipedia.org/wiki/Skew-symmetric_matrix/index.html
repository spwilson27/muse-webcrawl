Skew-symmetric matrix

In mathematics, particularly in linear algebra, a skew-symmetric matrix (also called an antisymmetric or antimetric matrix) is a square matrix whose transpose equals its negative; that is, it satisfies the equation

AT = −A.

Equivalently, a matrix A = (aij) is skew-symmetric if aij = −aji for all indices i and j. In particular, all entries on the main diagonal must be zero (provided the characteristic of the underlying field is not 2), since aii = −aii.

Examples

The matrix

[ 0  2  −1 ; −2  0  −4 ; 1  4  0 ]

is skew-symmetric, as is every 2 × 2 matrix of the form [ 0  a ; −a  0 ].

Properties

  • The set of all skew-symmetric n × n matrices forms a vector space of dimension n(n−1)/2.
  • The determinant of a skew-symmetric matrix of odd order is always zero; for even order it is the square of a polynomial in the entries called the Pfaffian.
  • Every real skew-symmetric matrix has purely imaginary (or zero) eigenvalues, and is diagonalisable by a unitary matrix.
  • The exponential of a real skew-symmetric matrix is a special orthogonal matrix; this relates skew-symmetric matrices to the Lie algebra of the rotation group, and to infinitesimal rotations in physics.
  • Any square matrix can be uniquely written as the sum of a symmetric and a skew-symmetric matrix.
  • In three dimensions, skew-symmetric matrices correspond to cross products: every 3 × 3 skew-symmetric matrix can be written in terms of a vector ω such that A v = ω × v.

Infinitesimal rotations

Skew-symmetric matrices over the reals form the Lie algebra so(n) of the special orthogonal group SO(n). In mechanics, the angular velocity of a rigid body is represented by a skew-symmetric matrix constructed from the angular velocity vector, an identification used throughout rigid body dynamics.
