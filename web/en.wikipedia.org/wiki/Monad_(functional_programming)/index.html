Monad (functional programming)

In functional programming, a monad is a structure that combines program fragments (functions) and wraps their return values in a type with additional computation. Programmers use monads to allow actions (functions that affect the program's environment) to be composed in a sequence, similar to using pipelines in Unix shells. This design pattern is especially prominent in the programming language Haskell, where monads are used extensively to handle input/output, state, exceptions, and other effects within a purely functional setting.

Definition

Formally, a monad is defined by a type constructor M together with two operations:

  • return (also called unit or pure): takes a value a and produces a computation of type M a.
  • bind (written >>=): takes a computation of type M a and a function from a to M b, and produces a computation of type M b.

These operations must satisfy the three monad laws:

  1. Left identity: return a >>= f is the same as f a.
  2. Right identity: m >>= return is the same as m.
  3. Associativity: (m >>= f) >>= g is the same as m >>= (\x -> f x >>= g).

Examples

Maybe monad

The Maybe monad represents computations that may fail. A value of type Maybe a is either Just a or Nothing. Binding a function over Nothing yields Nothing, short-circuiting the rest of the computation, which provides a clean alternative to explicit error checks or null references.

List monad

Lists form a monad in which bind corresponds to mapping a function over each element and concatenating the results, modelling non-deterministic computations that can return multiple results.

IO monad

In Haskell, the IO monad encapsulates computations that interact with the outside world, allowing a pure language to perform impure operations in a controlled, sequenced way.

History

The concept derives from the monads of category theory, introduced into computer science by Eugenio Moggi in 1991 as a framework for structuring denotational semantics. Philip Wadler popularised their use in functional programming in the early 1990s. Monads were incorporated into Haskell's standard approach to I/O in the mid-1990s and have since influenced languages such as Scala, F#, Rust, and Swift.
