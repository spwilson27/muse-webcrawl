Web service

A web service is a software system designed to support interoperable machine-to-machine interaction over a network. The W3C defines it as a system identified by a URI whose public interfaces are described using XML, so that other systems can interact with it in the manner prescribed by its description, typically conveyed using HTTP with XML or JSON serialisation.

Styles

Two broad styles dominate. SOAP-based services use formal contracts (WSDL), XML envelopes, and enterprise features such as WS-Security. RESTful services instead use the uniform interface of HTTP — resources addressed by URLs and manipulated with standard verbs — exchanging mostly JSON. REST has become the predominant style for public APIs.

Uses

Web services underpin service-oriented architectures and microservices, letting independently developed systems exchange data for payments, mapping, authentication, and countless other functions across the internet.
