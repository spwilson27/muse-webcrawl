Sidechain

A sidechain is a separate blockchain that is linked to a main blockchain (the "parent chain" or "mainchain") through a two-way peg, allowing digital assets to be transferred between the chains and used under the sidechain's own rules while remaining redeemable on the main chain. Sidechains let developers experiment with new features — faster transactions, different consensus mechanisms, privacy features, or smart-contract capabilities — without modifying the consensus rules of the base layer.

History

The term was popularised by the 2014 paper "Enabling Blockchain Innovations with Pegged Sidechains" by Adam Back and colleagues at Blockstream. To move coins to a sidechain, a user locks coins in a special output on the main chain; an equivalent amount is released on the sidechain once the lock is confirmed, typically using Simplified Payment Verification (SPV) proofs. Moving back reverses the process.

Security models

Sidechains differ in how the peg and block production are secured:

  • Federated pegs – a fixed set of functionaries (a federation) jointly controls the locked funds via multisignature, as in Blockstream's Liquid Network (launched 2018), a Bitcoin sidechain aimed at exchanges and traders with one-minute blocks and confidential transactions.
  • Drivechains – a proposed model in which miners themselves custody and release the pegged funds (BIP 300/301).
  • Merged mining – sidechain blocks are mined by the main chain's miners, as with RSK (Rootstock), a Bitcoin sidechain providing Ethereum-compatible smart contracts.

Because a sidechain has its own validators or miners, its security does not automatically equal that of the main chain: a failure or attack on the sidechain can strand pegged assets even if the main chain is unaffected. This distinguishes sidechains from layer-2 systems such as payment channel networks and rollups that inherit more of the base layer's security.

Examples

  • Liquid Network – federated Bitcoin sidechain for fast, confidential settlement between exchanges.
  • RSK / Rootstock – merge-mined Bitcoin sidechain with smart contracts; its token is "smart bitcoin" (RBTC).
  • Polygon PoS – often described as a "commit chain" for Ethereum, using its own validator set with checkpoints to Ethereum.
  • Plasma – an earlier framework for child chains reporting to Ethereum.
