Modbus

TypeIndustrial communications protocol
Introduced1979
DeveloperModicon (now Schneider Electric)
VariantsModbus RTU, Modbus ASCII, Modbus TCP/IP

Modbus is a client/server data communications protocol originally published by Modicon (now Schneider Electric) in 1979 for use with its programmable logic controllers (PLCs). It has become a de facto standard in industrial automation for connecting sensors, instruments, PLCs and SCADA systems.

Protocol

Modbus organises data into four tables: discrete inputs, coils (discrete outputs), input registers and holding registers, addressed by number. A client (formerly "master") issues function-coded requests — for example to read registers or write coils — and servers ("slaves") respond or return exception codes. The protocol itself is application-layer and media independent: common serial variants are Modbus RTU (binary, with CRC checking) and Modbus ASCII, while Modbus TCP/IP encapsulates messages on Ethernet, typically on port 502.

Criticism and use

Modbus has no built-in security — no authentication or encryption — which has made industrial networks using it a concern in cybersecurity, mitigated in modern deployments by network segmentation and secure wrappers. Its simplicity, openness and royalty-free specification have nonetheless kept it ubiquitous.
