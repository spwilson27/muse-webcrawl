Register renaming

Field: Computer architecture
Purpose: Eliminate false data dependencies
Used in: Out-of-order superscalar processors
Related: Tomasulo's algorithm, reorder buffer

Register renaming is a technique used in high-performance microprocessors to eliminate false data dependencies — write-after-read and write-after-write hazards — between instructions that use the same architectural register. The processor maps the small set of programmer-visible registers onto a larger pool of physical registers, giving each new write to a register a fresh physical register.

Problem addressed

In an out-of-order processor, instructions that merely reuse a register name create artificial ordering constraints. For example, if one instruction writes register R1 and a later, independent instruction also writes R1, the second write appears to depend on earlier reads of the first value. Such name dependencies limit instruction-level parallelism even though the instructions exchange no data.

Mechanism

At the decode stage, the processor consults a rename map table to translate each source register to the physical register holding its current value, allocates a new free physical register for each destination, and records the mapping so that the result can later be committed in program order, typically with the help of a reorder buffer. Superscalar designs such as the Intel P6 family and modern ARM and RISC-V processors all rely on renaming.
