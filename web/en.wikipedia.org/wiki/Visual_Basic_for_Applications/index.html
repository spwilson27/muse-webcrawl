Visual Basic for Applications (VBA) is an implementation of Microsoft's Visual Basic programming language built into most desktop Microsoft Office applications — including Word, Excel, Access, PowerPoint and Outlook — and also licensed for use in some third-party products such as AutoCAD and LibreOffice (in compatibility form). VBA allows users to automate tasks, build user-defined functions, create custom forms and dialogs, and control one Office application from another through the host's object model.

History

VBA was first released in 1993 with Microsoft Excel 5.0, replacing Excel's earlier XLM macro language, and was added to Word (replacing WordBasic), Access, and PowerPoint over the following releases. It reached its mature form with VBA version 6, shipped in Office 2000, and version 7 (2010) added 64-bit support. Although Microsoft has promoted newer extensibility technologies — VSTO add-ins and, later, JavaScript-based Office Add-ins — VBA remains deeply entrenched in business workflows and continues to ship with Microsoft 365 desktop applications.

Usage

Macros are recorded or written in the Visual Basic Editor (VBE) and stored within documents or templates. A simple Excel macro:

Sub HighlightTotal()
    Selection.Font.Bold = True
End Sub

Because macros can execute arbitrary code, macro viruses — beginning with the Concept virus in 1995 — became a major malware vector, leading Microsoft to disable macros by default and to block macros in files originating from the internet.
