Rabin–Karp algorithm

The Rabin–Karp algorithm or Karp–Rabin algorithm is a string-searching algorithm created by Richard Karp and Michael O. Rabin in 1987 that uses hashing to find an exact match of a pattern string in a text. It uses a rolling hash to quickly filter out positions of the text that cannot match the pattern, and then verifies any candidate positions by direct comparison.

Class: String searching algorithm
Worst-case performance: O(nm)
Average performance: O(n + m)
Creators: Richard Karp, Michael O. Rabin (1987)

Overview

Naive string matching compares the pattern against every possible substring of the text, character by character. The Rabin–Karp algorithm instead computes a hash value for the pattern and for each successive window of the text of the same length. If the hash values differ, the window cannot contain the pattern; if they are equal, the algorithm checks the characters directly to confirm the match (or detect a hash collision).

Rolling hash

The key idea is the use of a rolling hash function: the hash of each new window can be computed from the hash of the previous window in constant time by removing the contribution of the character that leaves the window and adding the contribution of the character that enters it. A common choice treats the string as a number in a base-d numeral system computed modulo a large prime q, which makes the sliding update a simple arithmetic operation.

Uses

Rabin–Karp is especially useful for multiple pattern searching, such as detecting plagiarism by searching a document for many source strings at once: a single pass with several pattern hashes can find candidate matches for all patterns simultaneously. Its worst case, O(nm), arises when many hash matches occur spuriously, but with a well-chosen modulus this is rare in practice.
