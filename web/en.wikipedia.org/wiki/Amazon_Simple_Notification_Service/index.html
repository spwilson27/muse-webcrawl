Amazon Simple Notification Service

Amazon SNS
Developer: Amazon Web Services
Initial release: 2010
Type: Managed publish/subscribe messaging service

Amazon Simple Notification Service (Amazon SNS) is a managed message service offered by Amazon Web Services for both application-to-application and application-to-person communication. It follows a publish/subscribe model: publishers send messages to a topic, and SNS delivers copies of the message to all endpoints subscribed to that topic.

Delivery endpoints

Subscriptions can deliver to HTTP/HTTPS endpoints, email addresses, Amazon SQS queues, AWS Lambda functions, and mobile push notification platforms (such as APNs and Firebase Cloud Messaging), as well as SMS text messages in many regions. SNS supports standard topics with at-least-once delivery and FIFO topics that preserve ordering and provide deduplication, commonly paired with SQS FIFO queues.

Use cases

Typical uses include event notifications from other AWS services, application alerts, user notifications, and fan-out architectures in which a single event must trigger multiple downstream processing paths in parallel.
