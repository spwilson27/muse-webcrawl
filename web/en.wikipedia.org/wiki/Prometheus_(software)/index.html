Prometheus (software)

Prometheus is a free software application for event monitoring and alerting. It records real-time metrics in a time series database, using an HTTP pull model in which the server periodically scrapes metrics endpoints exposed by targets, with flexible queries in its own query language, PromQL, and efficient storage. Written in Go, it is released under the Apache 2.0 license.

History

Prometheus was developed at SoundCloud starting in 2012, inspired by Google's internal Borgmon monitoring system, and was released publicly in 2015. In 2016 it became the second hosted project of the Cloud Native Computing Foundation (after Kubernetes), and it graduated from the CNCF in 2018. It is a standard component of cloud-native infrastructure and integrates closely with Kubernetes and with the Grafana visualization platform.

Architecture and features

Prometheus servers scrape and store time series locally; targets expose metrics via client libraries in many languages or through "exporters" that translate third-party metrics. Data can be queried with PromQL for dashboards and recording rules. Alertmanager handles alerts, deduplication, grouping, and routing to notification channels. Its data model labels every time series with key–value pairs, enabling multi-dimensional queries; long-term storage is typically provided by remote-write compatible systems.
