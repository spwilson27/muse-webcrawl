Linux Unified Key Setup

The Linux Unified Key Setup (LUKS) is a disk encryption specification created by Clemens Fruhwirth in 2004 and developed for Linux. It provides a standard on-disk format that is independent of any particular implementation, allowing compatibility between different tools and a secure management of multiple user passwords.

LUKS is the standard format used by cryptsetup together with the kernel's dm-crypt device-mapper target, and is the usual way to encrypt disks and partitions on Linux systems, including full-disk encryption during installation.

Design

A LUKS device begins with a header that stores the cipher specification and up to eight (LUKS1) or thirty-two (LUKS2) key slots. Each key slot holds the volume key encrypted with a user's passphrase, strengthened by a key derivation function (PBKDF2, or Argon2 in LUKS2) and anti-forensic splitting of key material. LUKS2, released with cryptsetup 2.0 in 2017, adds features such as integrity considerations, JSON metadata, and improved resilience.
