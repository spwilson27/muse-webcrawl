Multiple-image Network Graphics

Multiple-image Network Graphics (MNG) is a graphics file format for animated images, designed as an extension of the PNG image format. It was designed by members of the PNG development group as an alternative to the then-ubiquitous GIF format for animations, avoiding the patent issues associated with GIF at the time.

Features

MNG supports lossless and lossy (JPEG-based, called JNG) compression of image sequences, along with features such as nested loops, sprites, and delta encoding between frames. A simplified subset known as MNG-1.0 was intended for basic animations.

Support

Browser support for MNG was limited. Mozilla browsers supported it until 2003, when it was removed due to code size and low usage; animated PNG (APNG) later became the more widely adopted way to animate PNG images.
