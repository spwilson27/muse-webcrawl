Karmarkar's algorithm

Karmarkar's algorithm is an algorithm introduced by Narendra Karmarkar in 1984 for solving linear programming problems. It was the first reasonably efficient algorithm that solves these problems in polynomial time, and it launched the field of interior-point methods.

Overview

Where the simplex algorithm moves along the edges of the feasible polytope, Karmarkar's algorithm moves through its interior. At each step it applies a projective transformation that re-centres the current point, then takes a step in the direction of decreasing objective value within a ball inscribed in the transformed space.

Complexity and impact

The algorithm runs in polynomial time, with complexity O(n3.5L) operations for n variables and input size L. Its announcement made front-page news and led to a famous patent controversy at AT&T Bell Laboratories, where Karmarkar worked. Interior-point methods descended from it are now standard in optimisation software.

References: Karmarkar (1984), "A new polynomial-time algorithm for linear programming", Combinatorica 4.
