WSPR (pronounced "whisper") is an acronym for Weak Signal Propagation Reporter. It is a protocol, implemented in a computer program, used for weak-signal radio communication between amateur radio operators. The protocol was designed, and a program written initially, by Joe Taylor, K1JT. The software code is now open source and is developed by a small team.

The WSPR program is designed for sending and receiving low-power transmissions to test propagation paths on the MF and HF bands. Users with internet-connected stations can automatically upload reception reports to a central database, WSPRnet, which maintains a near-real-time map of propagation conditions worldwide.

Technical details

A WSPR transmission carries a station's callsign, Maidenhead grid locator, and transmitter power level in dBm, compressed into 50 bits and protected by a convolutional error-correcting code. The message is modulated as a continuous-phase 4-FSK signal with a symbol rate of about 1.46 baud, occupying a bandwidth of only about 6 Hz. A complete transmission lasts 110.6 seconds, beginning one second into an even-numbered minute (UTC).

Because of the narrow bandwidth and strong error correction, WSPR signals can be decoded at signal-to-noise ratios as low as about −28 dB in a 2500 Hz reference bandwidth — far below the threshold at which a human operator could copy Morse code or voice. Typical transmitter powers range from milliwatts to a few watts, yet intercontinental reception is common.

Applications

WSPR is used to study ionospheric propagation, compare antenna performance, and track high-altitude balloons: pico-balloon flights routinely carry WSPR transmitters, and their positions are reported as they circle the globe. The protocol forms part of the WSJT-X software suite alongside modes such as FT8 and JT65.
