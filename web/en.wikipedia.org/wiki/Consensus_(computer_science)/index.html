Consensus (computer science)

[Hero image placeholder: illustration of distributed nodes reaching agreement]

Consensus is a fundamental problem in distributed computing in which multiple processes, nodes, or agents must agree on a single data value. The value may be needed for agreement on which transaction to commit to a database, which block to append to a blockchain, or which process should act as leader. Consensus is considered one of the most important problems in fault-tolerant distributed systems, because many other problems — such as state machine replication — can be reduced to it.

Problem description

A consensus protocol typically must satisfy three properties:

  • Termination: every correct process eventually decides some value.
  • Agreement: all correct processes decide the same value.
  • Validity: the decided value must have been proposed by some process.

Consensus must be achieved even in the presence of faulty processes. In the classical Byzantine generals problem, processes may behave arbitrarily, including maliciously misreporting values.

The FLP impossibility result

In 1985, Fischer, Lynch and Paterson proved the FLP impossibility result: in a fully asynchronous system, no deterministic consensus protocol can guarantee termination if even a single process may crash. In practice, systems circumvent the result by using partial synchrony assumptions, randomization, or failure detectors.

Algorithms

Paxos

Paxos, described by Leslie Lamport, is a family of protocols for achieving consensus among unreliable processors. It is widely used in production systems, including Google's Chubby lock service and the Spanner database.

Raft

Raft was designed as a more understandable alternative to Paxos. It separates leader election, log replication, and safety into modular components.

Byzantine fault tolerant protocols

Practical Byzantine Fault Tolerance (PBFT), introduced by Castro and Liskov in 1999, tolerates up to f malicious replicas out of 3f+1 total. Modern blockchain systems such as those using proof of stake employ variants of BFT consensus.

Applications

Consensus algorithms underpin distributed databases, configuration management systems such as ZooKeeper and etcd, leader election, atomic broadcast, and cryptocurrency networks. Bitcoin's proof-of-work protocol achieves a probabilistic form of consensus known as Nakamoto consensus.
