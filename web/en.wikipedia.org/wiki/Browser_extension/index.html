Browser extension

TypeSoftware add-on
PurposeExtending web browser functionality
ExamplesAd blockers; password managers; tab managers
Major platformsChrome Web Store; Firefox Add-ons; Microsoft Edge Add-ons

A browser extension is a small software component that adds features or functionality to a web browser. Extensions can block advertisements, manage passwords, translate pages, capture screenshots, block trackers and modify the appearance or behaviour of websites.

Technology

Modern extensions are written mainly in HTML, CSS and JavaScript using APIs provided by the browser, such as the WebExtensions API, which allows a single extension to run in Firefox, Chrome, Edge and other Chromium-based browsers. Extensions are distributed through official stores — the Chrome Web Store, Firefox Add-ons and the Microsoft Edge Add-ons site — which review submissions for policy compliance.

Security and privacy

Because extensions can request permission to read and modify page content on many sites, malicious or compromised extensions are a recognised security risk. Browser vendors have progressively tightened extension platforms, notably with Chrome's Manifest V3, which restricts certain capabilities such as remote code execution and blocking web requests.
