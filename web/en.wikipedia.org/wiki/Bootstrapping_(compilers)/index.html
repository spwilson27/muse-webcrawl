Bootstrapping (compilers)

In computer science, bootstrapping is the process of writing a compiler (or assembler) in the programming language that it is intended to compile. Once a language exists in some initial form — perhaps via an interpreter or a compiler written in another language — the compiler can be rewritten in its own language and thereafter compiled by itself.

The process

A typical bootstrap proceeds in stages. Stage 0 is a compiler for a subset of the language written in some other language or machine code. That subset compiler compiles a fuller version of the compiler written in the subset, and the new compiler then compiles the complete compiler source. Languages commonly bootstrapped include C, Rust, Go and OCaml; GCC, for instance, builds itself in multiple stages and compares the outputs of the later stages as a correctness check.

Trust

Bootstrapping raises a security question famously explored in Ken Thompson's 1984 lecture "Reflections on Trusting Trust": a malicious modification could in principle be hidden in a self-hosting compiler's binary while being absent from its source. Reproducible builds and diverse double-compiling are proposed defences.
