List of widget toolkits

A widget toolkit (or GUI toolkit) is a library of graphical control elements ("widgets") — buttons, menus, text fields and windows — used to build graphical user interfaces. This article lists notable widget toolkits by platform and language.

Cross-platform toolkits

Platform-specific toolkits

Platform toolkits include Microsoft's Win32 controls, Windows Forms and WPF/WinUI on Windows; Cocoa/AppKit and SwiftUI on macOS; and the Android SDK views and Jetpack Compose on Android. Web-based "toolkits" include component libraries such as React component suites and Material UI.
