Core Video

Core Video
Developer: Apple Inc.
Operating system: macOS, iOS and other Apple platforms
Introduced: Mac OS X 10.4 Tiger (2005)

Core Video is the video processing model employed by macOS, iOS, and other Apple operating systems. It is a framework for processing and presenting digital video, providing a pipeline that links video decoding and playback (such as in QuickTime and AVFoundation) with compositing and rendering technologies such as Core Animation, Core Image and OpenGL/Metal.

Overview

Introduced with Mac OS X 10.4 "Tiger" in 2005 alongside Core Image, Core Video handles the display synchronisation and buffer management between decoded video frames and the graphics hardware. Its central abstraction is the display link (CVDisplayLink), which lets applications synchronise drawing with the display refresh rate. Because frames are passed around as pixel buffers that can live on the GPU, applications can apply Core Image filters or OpenGL rendering to video with minimal copying — enabling effects such as live video manipulation in applications like Photo Booth and Final Cut Pro.
