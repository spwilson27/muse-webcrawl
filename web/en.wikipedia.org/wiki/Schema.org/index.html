Schema.org

Schema.org provides a shared vocabulary for structured data on the web
Launched2 June 2011
FoundersGoogle, Microsoft (Bing), Yahoo!
TypeStructured data vocabulary / ontology
Websiteschema.org

Schema.org is a reference website that publishes documentation and guidelines for using structured data mark-up on web pages. It was launched on 2 June 2011 by Google, Microsoft, and Yahoo! (operators of the then-largest search engines), with Yandex joining later that year. Its main goal is to standardise structured data in order to create a Web of Data.

Overview

The schema.org vocabulary defines types (such as Person, Organization, Event, Product, and CreativeWork) and properties (such as name, author, datePublished) arranged in a hierarchy rooted at the type Thing. Webmasters embed the mark-up in pages so that search engines and other applications can extract and understand the content, enabling rich search results — reviews, recipes, events, FAQs — and knowledge panels.

Formats

Schema.org data can be encoded in three main formats:

  • JSON-LD — a script block of linked data; recommended by Google
  • Microdata — attributes added to HTML elements (itemscope, itemtype, itemprop)
  • RDFa — attribute-based mark-up from the RDF framework
{
  "@context": "https://schema.org",
  "@type": "Person",
  "name": "Ada Lovelace",
  "jobTitle": "Mathematician"
}

Governance and development

The vocabulary is developed in the open by the Schema.org Community Group at the W3C, with releases coordinated by a steering group drawn from the founding search engines. Much of the vocabulary draws on earlier formats such as microformats, FOAF, and GoodRelations. According to Web Data Commons studies, schema.org mark-up is used by tens of millions of domains, making it one of the most widely deployed semantic vocabularies on the web.

Uses

Beyond search, schema.org data underpins knowledge graphs, e-commerce product feeds, digital assistants, and data integration. Vertical extensions exist for domains such as health, autos, and finance, coordinated through community proposals.
