Message-oriented middleware

Message-oriented middleware (MOM) is software or hardware infrastructure supporting the sending and receiving of messages between distributed systems. MOM allows application modules to be distributed over heterogeneous platforms and reduces the complexity of developing applications that span multiple operating systems and network protocols.

How it works

In a MOM system, a sender application places a message on a queue or publishes it to a topic managed by a message broker, without needing the receiver to be available at the same moment. The receiver later retrieves or is delivered the message, enabling asynchronous, loosely coupled communication. Key patterns include point-to-point messaging through queues and publish–subscribe messaging through topics.

Examples and standards

Well-known message-oriented middleware products include Apache Kafka, RabbitMQ, Apache ActiveMQ, IBM MQ and Amazon SQS. Standard APIs and protocols include the Java Message Service (JMS), AMQP and MQTT. MOM is a core building block of enterprise application integration and event-driven architectures.
