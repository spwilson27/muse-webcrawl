Document-oriented database

A document-oriented database, or document store, is a type of NoSQL database designed for storing, retrieving and managing document-oriented information, also known as semi-structured data. Documents are typically encoded in formats such as JSON, BSON or XML, and unlike relational databases, documents in a collection may have differing structures.

Characteristics

Documents map closely to objects in application code, making development simpler for object-oriented programmers. Rather than splitting data across tables with joins, a document can contain nested structures and arrays. Document stores generally provide a query language or API for retrieving documents by content, and support indexing for performance.

Examples

Well-known document-oriented databases include MongoDB, CouchDB, Amazon DocumentDB, Couchbase and RethinkDB. Early systems such as Lotus Notes also embodied document-store ideas.
