Boyer–Moore string-search algorithm

Boyer–Moore algorithm
InventorsRobert S. Boyer and J Strother Moore (1977)
ClassString-searching algorithm
Best caseO(n/m) comparisons
Worst caseO(nm) (O(n) with Galil rule)

In computer science, the Boyer–Moore string-search algorithm is an efficient method for finding a substring (the "pattern" or "needle") within a larger string (the "text" or "haystack"). Published by Robert S. Boyer and J Strother Moore in 1977, it is the standard benchmark for practical string-search implementations.

How it works

Unlike naive search, Boyer–Moore compares the pattern against the text from right to left and precomputes two shift rules. The bad-character rule shifts the pattern so that a mismatched text character aligns with its last occurrence in the pattern (or past it if absent). The good-suffix rule aligns a matched suffix with another occurrence of the same suffix in the pattern. Taking the larger shift lets the algorithm skip over large sections of text, often examining only a fraction of the characters.

Performance

For long patterns and large alphabets, the algorithm achieves sublinear best-case behaviour of roughly n/m comparisons. Pathological inputs can degrade it, which the Galil rule fixes by guaranteeing linear worst-case time. Variants such as Boyer–Moore–Horspool simplify the rules while remaining fast in practice.

Applications

The algorithm and its variants underpin the "Find" functions of text editors and tools such as GNU grep, and it serves as the reference point against which other string-search algorithms are measured.
