Fabius function

In mathematics, the Fabius function is an example of a smooth function (infinitely differentiable) that is nowhere analytic. It was introduced by Jaap Fabius in 1966.

Definition

The function is defined on the unit interval [0,1] by an infinite series involving the cumulative distribution behaviour of sums of uniform random variables; equivalently it is the cumulative distribution function of the infinite sum Σ 2−n Un, where the Un are independent uniform(0,1) random variables. It satisfies the functional equation f(x) relates to a rescaled copy of itself: its derivative is proportional to a shifted version of the function, f′(x) = 2 f(2x) for 0 ≤ x ≤ 1/2, with f(0)=0 and f(1)=1, together with the symmetry f(1−x) = 1 − f(x).

Properties

The Fabius function is monotonically increasing, infinitely differentiable on the whole interval, yet at no point does its Taylor series converge to the function in any neighbourhood — it is nowhere analytic. All derivatives at dyadic rational endpoints behave in a way that makes the standard Taylor expansion useless. Its values are rational at dyadic rationals and have been conjectured irrational otherwise. The function is a classic counterexample in real analysis and is related to refinable (self-similar) functions in wavelet theory.
