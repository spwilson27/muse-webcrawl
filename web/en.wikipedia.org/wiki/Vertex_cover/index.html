Vertex cover

A minimum vertex cover (highlighted vertices) touching every edge of the graph.

In graph theory, a vertex cover (sometimes node cover) of a graph is a set of vertices that includes at least one endpoint of every edge of the graph. The problem of finding a minimum vertex cover — a vertex cover of smallest possible size — is a classical optimisation problem in computer science and a typical example of an NP-hard optimisation problem that has an approximation algorithm.

Definition

Formally, a vertex cover of an undirected graph G = (V, E) is a subset C of V such that if (u, v) is an edge of G, then either u is in C or v is in C (or both). The size of a vertex cover is the number of vertices in it. A minimum vertex cover is a vertex cover of smallest possible size; its size is denoted τ(G).

Computational complexity

The decision version of the problem — given a graph and an integer k, deciding whether a vertex cover of size at most k exists — is NP-complete; it was one of Karp's 21 NP-complete problems. A simple greedy algorithm that repeatedly picks both endpoints of an arbitrary uncovered edge achieves a 2-approximation. Under the Unique Games Conjecture, no (2 − ε)-approximation exists for any constant ε > 0.

Relations to other problems

A set of vertices is a vertex cover if and only if its complement is an independent set; hence the size of a minimum vertex cover plus the size of a maximum independent set equals the number of vertices. By Kőnig's theorem, in bipartite graphs the size of a minimum vertex cover equals the size of a maximum matching, so the problem is solvable in polynomial time for bipartite graphs. Minimum vertex cover is also closely related to the maximum matching problem in general graphs and to the dominating set problem.

Applications

Vertex cover models problems such as placing the minimum number of guards or cameras so that every corridor (edge) is watched, and appears in computational biology in the analysis of protein interaction networks.
