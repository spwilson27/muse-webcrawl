In mathematics, an analytic function is a function that is locally given by a convergent power series. A function is analytic on an open set if, at every point of the set, its Taylor series converges to the function in some neighbourhood of that point. Analytic functions are infinitely differentiable, but the converse is not true for real functions.

Real and complex cases

For functions of a complex variable, analyticity is equivalent to holomorphicity: every complex-differentiable function on an open set is automatically analytic, a remarkable theorem of complex analysis following from Cauchy's integral formula. For real functions the notions diverge: the function f(x) = e−1/x² for x ≠ 0, with f(0) = 0, is infinitely differentiable everywhere on the real line, yet its Taylor series at 0 is identically zero and so does not represent it — it is smooth but not analytic.

Properties

Sums, products, and compositions of analytic functions are analytic, as are quotients wherever the denominator is nonzero. An analytic function that is not identically zero has isolated zeros. By the identity theorem, two analytic functions on a connected open set that agree on any subset with a limit point agree everywhere; this underlies the principle of analytic continuation, by which a function may be extended beyond its original domain, as in the continuation of the Riemann zeta function.

Examples

All polynomials, the exponential function, sine and cosine, and rational functions away from their poles are analytic. The absolute value function is nowhere analytic, and the complex logarithm is analytic only after choosing a branch, since it is inherently multi-valued.
