Stable model semantics

From Wikipedia, the free encyclopedia

The stable model semantics is a framework for the declarative semantics of logic programs with negation, introduced by Michael Gelfond and Vladimir Lifschitz in 1988. It defines the meaning of a program as a collection of 'stable models' — sets of atoms that can be derived from the program by a self-consistent process — and forms the theoretical foundation of answer set programming.

Definition

Given a logic program and a candidate set of atoms S, the reduct of the program with respect to S is obtained by deleting rules whose negative premises conflict with S and dropping negation from the rest. S is a stable model if it is exactly the least model of its (positive) reduct.

Significance

Stable models capture non-monotonic reasoning and default negation ('not known to be true'), allowing combinatorial search and optimisation problems to be encoded declaratively. Efficient solvers such as clasp implement the semantics in the answer set programming paradigm.
