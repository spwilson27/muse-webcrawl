Modified nodal analysis

In electrical engineering, modified nodal analysis (MNA) is an extension of nodal analysis that not only determines the circuit's node voltages but also some branch currents. It is the standard formulation used by circuit simulators such as SPICE, because plain nodal analysis cannot directly handle voltage sources or other elements whose branch current is not expressible in terms of node voltages.

Method

In ordinary nodal analysis, Kirchhoff's current law is written at every non-reference node, with branch currents expressed through element conductances and node voltages. Voltage-defined elements — independent and dependent voltage sources, and (in most implementations) inductors — break this scheme, because their currents are unknown. MNA solves the problem by adding the currents through voltage-defined branches as extra unknowns, and adding the corresponding branch voltage equations as extra rows and columns of the linear system. The result is a sparse matrix equation of the form A x = z, where x contains the node voltages followed by the extra branch currents. Each element contributes a characteristic "stamp" of entries to the matrix, which makes the method easy to automate.

History and extensions

The method was formalised in the 1970s, notably by Chung-Wen Ho, Albert Ruehli and Paul Brennan of IBM in their 1975 paper "The modified nodal approach to network analysis," as SPICE-style simulators were being developed. Nonlinear devices are handled by linearising around an operating point within a Newton–Raphson iteration; dynamic elements in transient analysis are handled by companion models derived from numerical integration formulas such as trapezoidal or Gear methods. MNA's matrices are sparse and are solved with sparse LU factorisation and pivoting strategies that preserve sparsity.
