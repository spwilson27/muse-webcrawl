GUI widget toolkit

A widget toolkit, widget library, GUI toolkit or UX library is a library or a collection of libraries containing a set of graphical control elements (called widgets) used to construct the graphical user interface (GUI) of programs. Most widget toolkits additionally include their own rendering engine, which can be specific to an operating system or windowing system, or can draw on multiple back-ends to support cross-platform applications.

Widgets

Toolkits provide reusable controls such as buttons, menus, scrollbars, text fields, checkboxes, radio buttons, sliders, dialog boxes, tabbed panes, and tree and list views, together with layout managers that position these elements within windows. Toolkits also handle the event model — delivering mouse and keyboard input to the relevant widget — and painting and invalidation.

Native versus custom rendering

Some toolkits wrap the operating system's native controls (for example wxWidgets and Win32-based frameworks), giving applications a platform-native look and feel and accessibility behaviour. Others render their own controls (such as Qt and GTK), trading exact native appearance for consistent cross-platform behaviour and styling flexibility. Web browsers and HTML/CSS constitute another widely used GUI toolkit platform.

Examples

  • GTK — cross-platform, originating with the GNU Project
  • Qt — cross-platform C++ framework, basis of KDE
  • wxWidgets — wraps native controls on each platform
  • Swing and JavaFX — for the Java platform
  • Cocoa (macOS) and Windows Presentation Foundation (Windows) — platform toolkits
  • Flutter and React Native — mobile-focused frameworks
