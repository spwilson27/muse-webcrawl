Mumble is a free and open-source voice over IP (VoIP) application designed primarily for use by gamers, similar to programs such as TeamSpeak and Discord. It uses a client–server architecture allowing users to talk to each other via the same server, and is distinguished by its low-latency, high-quality audio and its use of the Opus audio codec.

Features

Mumble provides end-to-end encryption of voice and text traffic using TLS and OCB-AES128, positional audio in supported games (so voices sound as though they come from the player's in-game position), an in-game overlay, and a permissions system based on access control lists. Voice quality features include noise suppression, automatic gain control, and echo cancellation inherited from the Speex and RNNoise libraries.

Server

The Mumble server, historically called Murmur, is lightweight and can be hosted by users on their own hardware or rented from hosting providers. Servers support channels, virtual servers, and authentication via certificates. Third-party web interfaces and bots provide administration and music playback.

History

Mumble was created by Thorvald Natvig and first released in 2005. Version 1.2 (2009) introduced the CELT codec and certificate authentication; version 1.3 (2019) switched to Opus as the primary codec. The project is developed openly on GitHub under the BSD licence.
