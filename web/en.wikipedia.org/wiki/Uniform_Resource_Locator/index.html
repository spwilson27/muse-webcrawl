Uniform Resource Locator

From Wikipedia, the free encyclopedia
Uniform Resource Locator
AbbreviationURL
StandardRFC 3986 (URI); WHATWG URL Standard
[Image: Diagram of a URL broken into parts: scheme, host, port, path, query and fragment]

A Uniform Resource Locator (URL), colloquially known as a web address, is a reference to a web resource that specifies its location on a computer network and a mechanism for retrieving it. A URL is a specific type of Uniform Resource Identifier (URI), and is the fundamental addressing system of the World Wide Web.

A URL such as https://www.example.com:443/path/page?query=1#section consists of a scheme (https), a host (a domain name or IP address), an optional port, a path, an optional query string and an optional fragment identifying a part of the resource. The browser resolves the host through the DNS, connects — for HTTPS, negotiating encryption — and requests the path with HTTP.

URLs were defined by Tim Berners-Lee and standardised in the 1990s (RFC 1738, later subsumed into the URI standard RFC 3986; browsers today follow the WHATWG URL Standard). Berners-Lee later apologised for the double slash after the scheme, calling it a pointless wart. URLs appear everywhere from advertisements to QR codes, and their design — readable, hierarchical, hackable — shaped how the web grew.
