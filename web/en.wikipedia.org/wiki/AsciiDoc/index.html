AsciiDoc

Filename extensions: .adoc, .asciidoc, .txt

Initial release: 2002

Developed by: Stuart Rackham; Asciidoctor project

Type: Lightweight markup language

AsciiDoc is a human-readable document format, semantically equivalent to DocBook XML, but using plain-text mark-up conventions. AsciiDoc documents can be created using any text editor and read "as-is", and converted to HTML, PDF, EPUB, man pages and other formats. The format was created in 2002 by Stuart Rackham, who published tools ('asciidoc' and 'a2x') written in Python to convert plain-text 'AsciiDoc' files to commonly used formats.

Implementations

A Ruby implementation called Asciidoctor, released in 2013, is in use by GitHub and GitLab and became the reference implementation. Asciidoctor provides support for converting AsciiDoc into HTML, DocBook, PDF and other formats. Java and JavaScript ports (AsciidoctorJ and Asciidoctor.js) also exist. In 2021 a working group under the Eclipse Foundation began a standardisation effort for the language.

AsciiDoc is widely used for technical documentation, including the documentation of many open-source projects and O'Reilly Media books.
