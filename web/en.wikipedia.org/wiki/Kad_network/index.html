Kad network

The Kad network is a peer-to-peer (P2P) network which implements the Kademlia distributed hash table (DHT) protocol. The majority of users on the eDonkey network also connect to Kad in order to find sources for downloads even if the eDonkey servers are unavailable. The most widely used clients are eMule (Windows), aMule (cross-platform), and MLDonkey.

Overview

Unlike the server-based eDonkey network, Kad is fully decentralized: there are no central index servers. Each participating node has a 128-bit Kad ID and stores information about the files it shares in a virtual hash table distributed across the network. XOR distance between IDs determines which peers a node contacts, following Petar Maymounkov and David Mazières's Kademlia design (2002). Keyword searches are performed by hashing a word from the sought filename and contacting the nodes "closest" to that hash, which return matching file references supplied by publishing peers.

Bootstrap and use

To join the network a Kad client needs the address of at least one already-connected client, which can be obtained from peers met through an eDonkey server, from a contacts file (nodes.dat), or from prior sessions. eMule clients implement so-called "Kad-only" operation entirely without servers. Because Kad indexes keywords rather than whole filenames, searches combine term hashes, and sources exchange then proceeds using the standard eDonkey/eMule file transfer protocol.
