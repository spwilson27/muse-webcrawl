OpenTelemetry

OpenTelemetry is a vendor-neutral open-source observability framework for generating, collecting and exporting telemetry data — traces, metrics and logs — from software systems. It is a Cloud Native Computing Foundation (CNCF) project, formed in 2019 by merging Google's OpenCensus and Uber-originated OpenTracing.

Components

OpenTelemetry provides language-specific APIs and SDKs for instrumenting code, semantic conventions naming common operations and attributes, and the OpenTelemetry Protocol (OTLP) for transmitting data. The Collector, a separate agent or service, receives, processes and forwards telemetry to backends such as Jaeger, Prometheus, Grafana Tempo or commercial observability platforms, decoupling applications from vendor tooling.

Adoption

It has become the de facto standard instrumentation layer for cloud-native software, with automatic instrumentation agents for frameworks in languages including Java, .NET, Python, Go and JavaScript, and built-in support in many platforms.
