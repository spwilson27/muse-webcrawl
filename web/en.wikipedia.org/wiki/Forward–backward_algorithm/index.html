Forward–backward algorithm

The forward–backward algorithm is an inference algorithm for hidden Markov models (HMMs) that efficiently computes the posterior distribution of all hidden state variables given an observation sequence. It underlies smoothing in HMMs and supplies the expected counts used by the Baum–Welch algorithm for parameter estimation.

Description

The algorithm runs in two passes. In the forward pass, it computes for each time step t and state i the quantity αt(i) = P(o1:t, xt = i), the joint probability of the partial observation sequence and ending in state i. In the backward pass, it computes βt(i) = P(ot+1:T | xt = i), the probability of the remaining observations given state i at time t. Combining them gives the smoothed state posterior P(xt = i | o1:T) ∝ αt(i) βt(i).

Complexity

Dynamic programming reduces the running time to O(T·N²) for T time steps and N states, versus the exponential cost of enumerating all state sequences. Numerically, the probabilities are usually rescaled at each step to avoid floating-point underflow, or computed in log space.

Applications

The algorithm is used in speech recognition, bioinformatics sequence analysis, part-of-speech tagging, and activity recognition — anywhere hidden states must be inferred from noisy observations.
