WebRTC

Developed byGoogle (originated); standardised by W3C and IETF
First released2011 (open-sourced by Google)
StatusW3C Recommendation (January 2021)
TypeReal-time communication API and protocol suite
Key protocolsSRTP, DTLS, ICE, STUN, TURN, SCTP

WebRTC (Web Real-Time Communication) is a free and open-source project providing web browsers and mobile applications with real-time communication via application programming interfaces. It allows audio and video communication and arbitrary data transfer to work inside web pages by allowing direct peer-to-peer communication, eliminating the need to install plugins or native applications. Supported by all major browser vendors, WebRTC became a W3C Recommendation and IETF standard in January 2021.

History

Google acquired the voice and video technology companies Global IP Solutions and On2 in 2010 and open-sourced their technology as WebRTC in May 2011. The W3C and IETF then developed the standard APIs and protocols. Browser support rolled out through the 2010s — Chrome and Firefox first, then Edge and Safari — and usage surged with the growth of browser-based video conferencing during the COVID-19 pandemic. Google Meet, Discord, Facebook Messenger and many other services use WebRTC for their media paths.

Design

The JavaScript API comprises three main interfaces: getUserMedia, which obtains access to the camera and microphone; RTCPeerConnection, which manages the encrypted media session, codec negotiation and connectivity; and RTCDataChannel, a generic bidirectional channel for arbitrary data, carried over SCTP. Establishing a connection requires exchanging session descriptions (using the Session Description Protocol) through some external "signalling" channel — deliberately left unspecified by the standard. Connectivity through NATs and firewalls is handled by the ICE framework with STUN servers for address discovery and TURN servers as relays of last resort. Media is encrypted with DTLS-SRTP; encryption is mandatory.

Codecs and applications

Mandatory-to-implement audio codecs are Opus and G.711; for video, implementations must support VP8 or H.264, with VP9 and AV1 increasingly common. Applications include video conferencing, telehealth, live streaming, cloud gaming, remote desktop, and peer-to-peer file sharing.

Criticism and privacy

Because ICE gathers local network addresses, WebRTC has been criticised for potentially revealing a user's real IP address behind a VPN ("WebRTC leaks"); browsers have responded by masking local addresses with mDNS hostnames. The technology's mandatory encryption and peer-to-peer architecture are, conversely, cited as privacy and resilience advantages.
