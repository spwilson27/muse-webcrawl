EEPROM

EEPROM or E2PROM (electrically erasable programmable read-only memory) is a type of non-volatile memory used in computers, integrated in microcontrollers for smart cards and remote keyless systems, and other electronic devices to store relatively small amounts of data while allowing individual bytes to be erased and reprogrammed.

EEPROMs are organized as arrays of floating-gate transistors. Each cell usually consists of a small storage transistor with a floating gate, whose charge state — set or cleared by Fowler–Nordheim tunnelling or hot-carrier injection — determines the bit stored. Unlike EPROM, which must be removed from the circuit and exposed to ultraviolet light to erase the whole chip, EEPROM can be erased and rewritten in-circuit, byte by byte, using normal programming voltages; unlike flash memory (which evolved from EEPROM), it does not need to erase large blocks before rewriting.

History

The technology derives from work by Eliyahou Harari and others on floating-gate devices in the 1970s. Intel introduced the 2816 EEPROM in 1978, and early devices were produced by companies including Seeq Technology. EEPROM quickly displaced EPROM and mask ROM in applications such as storing configuration parameters, calibration constants, and BIOS settings.

Characteristics

Read operations are fast (tens of nanoseconds), but writes are slow — typically several milliseconds per byte — because on-chip charge pumps must generate the programming voltage and the cell must be erased before writing. Endurance is finite: classic devices tolerate roughly 100,000 to 1,000,000 write cycles per cell, with data retention of 10 to 40 years. Densities are modest (bits to a few megabits), so EEPROM is used for small data stores, in serial forms (I²C or SPI "serial EEPROM") as well as parallel parts.

Applications

EEPROM is used for storing firmware configuration (e.g. SPD chips on memory modules, EDID data in monitors), odometer and option settings in automobiles, remote controls, smart cards, and identification tags such as those embedded in printer cartridges, batteries, and game controllers.
