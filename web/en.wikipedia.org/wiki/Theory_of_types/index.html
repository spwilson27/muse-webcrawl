In mathematical logic, the theory of types is a family of formal systems in which every term belongs to a type, and operations are restricted to terms of specified types. Introduced by Bertrand Russell in 1908 and developed with Alfred North Whitehead in Principia Mathematica (1910–1913), it was designed to block the paradoxes of naive set theory — above all Russell's paradox.

Outline

Russell's paradox arises from considering the set of all sets that do not contain themselves, which both must and must not contain itself. Type theory prevents such self-reference by stratifying objects into a hierarchy: individuals (type 0), sets of individuals (type 1), sets of sets of individuals (type 2), and so on. A set may contain only objects of the next lower type, so no set can contain itself and the paradoxical formation is simply ill-formed. Russell's ramified theory further subdivided types by "orders" to handle semantic paradoxes, together with the vicious-circle principle and an axiom of reducibility.

Later developments

Alonzo Church simplified the system into the simple theory of types (1940), built on his lambda calculus, which became a foundation of modern type theory. Type theories now underpin proof assistants and programming languages — including Martin-Löf type theory and the calculi behind Coq and Lean — and, via the Curry–Howard correspondence, link logical propositions with computational types.
