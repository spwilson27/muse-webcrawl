Hamming code

In computer science and telecommunication, Hamming codes are a family of linear error-correcting codes that can detect up to two simultaneous bit errors and correct single-bit errors. They were introduced by Richard Hamming in 1950, in his landmark paper "Error detecting and error correcting codes", written while he was working at Bell Telephone Laboratories on early relay computers whose calculations were repeatedly ruined by undetected errors.

Construction

A Hamming code is specified by two integers r ≥ 2 (the number of parity bits) and is a block code of length n = 2r − 1 containing k = 2r − r − 1 data bits. Parity bits are placed at positions that are powers of two (1, 2, 4, 8, ...); each parity bit checks those positions whose binary index has a 1 in the corresponding place, enforcing even parity over its group. The minimum Hamming distance of the code is 3, so it corrects any single-bit error and detects two-bit errors. Adding one overall parity bit gives the extended Hamming code with distance 4, widely used in the SECDED (single-error-correcting, double-error-detecting) form in computer memory.

The (7,4) code

The best-known example encodes four data bits (d1d2d3d4) into seven bits by adding three parity bits. On receiving a word, the decoder computes the syndrome — the pattern of parity-check failures — which, read as a binary number, directly identifies the position of a single error (or is zero if no error occurred). Hamming's insight was that the parity bits could overlap so that the syndrome pinpoints the error rather than merely signalling its existence.

History and legacy

Hamming codes are perfect codes: they achieve the Hamming (sphere-packing) bound with equality, so no other code of the same length and minimum distance can have more codewords. Although modern systems favour more powerful families such as Reed–Solomon, turbo and LDPC codes for high-noise channels, Hamming codes and their extended SECDED versions remain in everyday use in ECC memory, and they are a standard teaching example in information theory. Hamming generalised his work to non-binary (q-ary) alphabets, and the Hamming distance, Hamming window and other concepts from the same period of his work bear his name.
