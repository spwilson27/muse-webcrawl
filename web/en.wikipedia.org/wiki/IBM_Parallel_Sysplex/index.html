IBM Parallel Sysplex

Parallel Sysplex is a cluster technology from IBM that connects up to 32 IBM mainframe computers into a single system image, allowing them to share data and workload as if they were one machine. Introduced in 1994 with the Sysplex concept extended by coupling facilities, Parallel Sysplex aims at near-continuous availability and linear scalability for the z/OS operating system and subsystems such as Db2, CICS and IMS.

Technology

The heart of a Parallel Sysplex is the Coupling Facility, a dedicated processor or partition that provides shared cache, lock and list structures accessed by all members over high-speed coupling links. A Sysplex Timer (or Server Time Protocol) keeps the clocks of all systems synchronized, allowing coordinated recovery and consistent timestamps across the cluster.

Benefits

Because workload can be balanced dynamically and any single system can fail or be taken out for maintenance without stopping service, Parallel Sysplex installations are used by banks, airlines and governments for transaction processing requiring extremely high availability, often quoted as approaching "five nines".
