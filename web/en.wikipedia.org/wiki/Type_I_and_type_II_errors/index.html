Type I and type II errors

In statistical hypothesis testing, a type I error is the mistaken rejection of a true null hypothesis (a "false positive"), while a type II error is the failure to reject a false null hypothesis (a "false negative"). Much of statistical theory revolves around minimizing one or both of these errors, though for any given test there is generally a trade-off between them.

Definitions

The probability of a type I error is denoted by α (alpha) and is called the significance level of the test. Conventionally α is set at 0.05 or 0.01. The probability of a type II error is denoted by β (beta); the quantity 1 − β is the statistical power of the test, i.e. the probability of correctly rejecting a false null hypothesis.

History

The terminology was introduced by Jerzy Neyman and Egon Pearson in the 1930s as part of their framework of hypothesis testing, which contrasted with Ronald Fisher's approach of significance testing. Neyman and Pearson emphasized that the two kinds of error usually carry different costs and should be weighed accordingly.

Applications

The framework is applied wherever binary decisions are made under uncertainty: medical screening (where a type I error means a false alarm and a type II error a missed diagnosis), quality control, spam filtering, and the legal system, where the two errors correspond roughly to convicting an innocent person versus acquitting a guilty one. Because decreasing α for a fixed sample size increases β, reducing both errors simultaneously generally requires more data.
