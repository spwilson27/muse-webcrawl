Password hashing

Password hashing is the practice of storing a cryptographic hash of a password, rather than the password itself, so that a system can verify a user's credentials without retaining the secret in recoverable form. When a user logs in, the submitted password is hashed and compared with the stored hash; if the database is later leaked, attackers obtain only hashes, which must be cracked one by one.

Salts and key stretching

Because users choose weak and reused passwords, plain fast hashes (such as MD5 or SHA-1) can be attacked with precomputed rainbow tables and rapid brute force. Modern practice therefore adds a unique random salt to each password before hashing, defeating precomputation, and uses deliberately slow, computationally expensive constructions. Key stretching algorithms designed for passwords include bcrypt, scrypt, PBKDF2, and Argon2, the winner of the Password Hashing Competition (2015), which can be tuned for computation time and memory hardness to resist GPU and ASIC attacks.

Practice

Security guidance, such as the OWASP Password Storage Cheat Sheet, recommends Argon2id, scrypt, or bcrypt with appropriate work factors, and discourages fast general-purpose hashes for password storage. An optional secret "pepper" stored separately from the database is sometimes added. Password hashing underlies authentication on virtually all modern operating systems, websites, and network services.
