For the desktop environment of Windows Vista and 7 generally, see Features of Windows Vista.

Windows Aero
Developer: Microsoft
Type: Desktop environment / user interface
Introduced: Windows Vista (2006)
Also in: Windows 7
Replaced by: Metro design language (Windows 8)

Windows Aero (a backronym for Authentic, Energetic, Reflective, and Open) is the graphical user interface and theme introduced with Windows Vista and continued in Windows 7. Its most recognizable feature is the "Aero Glass" effect: translucent, frosted window borders rendered with real-time blur and reflections by the Desktop Window Manager, which used the computer's graphics processing unit to composite the desktop.

Features

Aero introduced live taskbar thumbnails, Windows Flip and Flip 3D for switching between windows in a three-dimensional cascade, smooth window animations, and high-DPI scaling. In Windows 7 it gained Aero Snap (tiling windows by dragging them to the screen edges), Aero Shake (minimizing other windows by shaking one), and Aero Peek (previewing the desktop). The interface also refined icons, fonts (Segoe UI) and window controls throughout the system.

Requirements and reception

Aero Glass required a DirectX 9-capable graphics card with a WDDM driver and sufficient memory; systems that could not meet these requirements fell back to the opaque Windows Vista Basic or Windows Classic themes. At Vista's launch the requirements and the confusing "Windows Vista Capable" labelling drew criticism and litigation. Over time, however, the Aero look became strongly associated with Windows Vista and especially the well-regarded Windows 7.

Legacy

Windows 8 removed most Aero effects in favour of the flat Metro design language, though the Desktop Window Manager and compositing remained. Later Fluent Design elements in Windows 10 and 11, such as acrylic translucency and mica materials, are considered partial returns to the ideas Aero pioneered.
