Fingerprint (computing)

From Wikipedia, the free encyclopedia

A fingerprint maps a large data item to a much shorter bit string.

In computer science, a fingerprinting algorithm is a procedure that maps an arbitrarily large data item (such as a computer file) to a much shorter bit string, its fingerprint, that uniquely identifies the original data for all practical purposes just as human fingerprints uniquely identify people. Fingerprints are typically used to avoid the comparison and transmission of bulky data.

Properties

A good fingerprint function shares many properties with a cryptographic hash function: it should be fast to compute, produce outputs that appear random, and make it computationally infeasible to find two inputs with the same fingerprint (collision resistance). The probability of a collision depends on the length of the fingerprint; for example, a k-bit fingerprint from a well-designed function has a collision probability of roughly 2−k for a given pair of distinct inputs.

Algorithms

Rabin's fingerprinting scheme, introduced by Michael O. Rabin in 1981, uses polynomial arithmetic over a finite field and provides provable performance guarantees. Rolling hash functions such as those used in the Rabin–Karp string-search algorithm allow fingerprints of substrings to be updated in constant time.

Applications

Fingerprints are used in file deduplication, data integrity verification, plagiarism detection, and peer-to-peer file sharing. Related techniques include browser fingerprinting, in which a device's configuration attributes are combined to identify it, and acoustic fingerprinting, used to identify audio recordings.
