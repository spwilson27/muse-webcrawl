Isosurface

An isosurface is a three-dimensional analogue of an isoline (contour line). It is a surface that represents points of a constant value (e.g. pressure, temperature, density or scalar potential) within a volume of space; in other words, it is a level set of a continuous function whose domain is 3D space.

Isosurfaces are normally displayed using computer graphics and are used as data visualization methods in computational fluid dynamics, medical imaging, and other fields dealing with volumetric data. A particular isovalue defines the boundary between regions where the function is above and below that value.

Applications

Medical and scientific visualisation

In CT and MRI data, isosurfaces at chosen thresholds extract the surfaces of bones, organs or other structures. Meteorologists use isosurfaces of pressure and temperature; chemists display surfaces of constant electron density or molecular orbitals; engineers visualise pressure and vorticity in simulated flows.

Extraction algorithms

The best-known algorithm for polygonal isosurface extraction is marching cubes, published by Lorensen and Cline in 1987, which processes a scalar volume cell by cell and emits triangles where the surface crosses each cell. Related methods include marching tetrahedra and dual contouring. Efficient implementations use spatial data structures to skip empty regions, and modern GPUs can extract and render isosurfaces in real time.
