Topological map

A topological map is a map that has been simplified so that only the vital information remains and irrelevant detail — scale, exact distances, precise shapes — has been removed. Its geometry preserves topology: connectivity and relative order are retained while metric accuracy is abandoned, like a rubber-sheet drawing of a network.

Transit maps

The best-known examples are schematic public-transport diagrams, pioneered by Harry Beck's 1933 London Underground map. Beck recognised that passengers underground need to know station sequence and interchange connections, not surface geography, so lines were straightened to horizontal, vertical and 45-degree diagonal segments and the central area enlarged. The style has been adopted by metro systems worldwide and by bus, rail and utility network diagrams.

Other uses

In cartography more generally, topological maps include cartograms that distort area by a variable such as population. In robotics and cognitive science, a topological map is a graph-like representation of an environment whose nodes are places and whose edges are paths, used for navigation without exact coordinates.
