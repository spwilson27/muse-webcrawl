ICC profile

An ICC profile is a set of data that characterizes a color input or output device, or a color space, according to standards promulgated by the International Color Consortium (ICC). Profiles describe the color attributes of a particular device or viewing requirement by defining a mapping between the device source or target color space and a profile connection space (PCS)—either CIELAB or CIEXYZ.

Details

The ICC was founded in 1993 by eight industry vendors, including Adobe, Apple, Kodak, Microsoft, and Sun Microsystems. The profile format (current specification ICC.1, aligned with ISO 15076-1) stores a header followed by tagged data elements: curves, matrices, and lookup tables that a color management module uses to transform colors between devices. Rendering intents—perceptual, relative colorimetric, saturation, and absolute colorimetric—govern how out-of-gamut colors are handled.

Use

ICC profiles are embedded in image files (JPEG, TIFF, PNG) and are foundational to desktop publishing, digital photography, and prepress workflows. Common working-space profiles include sRGB IEC61966-2.1 and Adobe RGB (1998). Version 4 profiles introduced more rigorous definitions than the earlier version 2.
