Alpine Linux is a lightweight Linux distribution designed around security, simplicity, and small size. Built on the musl C library and BusyBox utilities rather than the more common glibc and GNU coreutils, its base system is only a few megabytes. These qualities made it the most popular base image for Docker containers, where minimal image size and attack surface are prized.

History

Alpine began around 2005, growing out of the LEAF (Linux Embedded Appliance Framework) project; its original purpose was a firewall/router distribution that could run from RAM and read-only media, managed through the Alpine Configuration Framework (ACF). For many years releases used hardened kernels (grsecurity/PaX patches) and compiled all packages as position-independent executables with stack-smashing protection. Although the patched-kernel edition was discontinued in 2017, the other hardening defaults remain.

Design

  • Size: a container base image of roughly 5–8 MB, and a full install under 200 MB excluding the kernel.
  • musl libc: a compact, standards-focused C library; some glibc-linked binaries need compatibility shims (gcompat).
  • BusyBox: a single compact binary providing most Unix utilities.
  • apk: Alpine's own package manager, noted for speed and for supporting atomic, scriptable system configuration; packages are indexed in the aports repository tree.
  • OpenRC init system by default, with run-from-RAM and diskless modes for appliances.

Use

Alpine is widely used in container images for web services, language runtimes, and microservices; as an embedded and router system; on virtual machines where small footprints matter; and as the basis of postmarketOS, a distribution for smartphones. Docker's official images for many popular projects publish Alpine variants alongside Debian-based ones.
