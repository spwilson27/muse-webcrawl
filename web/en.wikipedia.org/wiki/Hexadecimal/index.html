Hexadecimal

From Wikipedia, the free encyclopedia
[Image: A table converting decimal 0-15 to binary and hexadecimal digits]

In mathematics and computing, hexadecimal (also base 16, or simply hex) is a positional numeral system that represents numbers using a base of 16. It uses the symbols '0'–'9' for values zero to nine and 'A'–'F' (or 'a'–'f') for ten to fifteen.

Because each hexadecimal digit corresponds exactly to four binary digits (a nibble), hex is the standard human-friendly shorthand for binary data: memory addresses, machine code, colour codes in web design (#RRGGBB), MAC addresses, and cryptographic hashes are all written in hex.

Conversion

To convert binary to hex, group bits in fours from the right and translate each group (0000=0 ... 1111=F). Two hex digits make one byte (00–FF, 0–255 decimal). Programmers mark hex values with a 0x prefix (from C), while HTML colours use # and CSS inherits the convention.

Hexadecimal complements octal (base 8), used in early computing and still in Unix file permissions.
