In formal language theory, a context-free language (CFL) is a language generated by a context-free grammar (CFG). Context-free languages have many applications in programming languages; in particular, most arithmetic expressions are generated by context-free grammars. They form type 2 of the Chomsky hierarchy and are exactly the languages recognized by non-deterministic pushdown automata.

Properties

Every regular language is context-free, but not conversely: the language { anbn : n ≥ 1 } is context-free but not regular, as the pumping lemma for regular languages shows. CFLs are closed under union, concatenation, Kleene star, homomorphism and reversal, but not under intersection or complementation; the intersection of two CFLs need not be context-free (e.g. intersecting { anbncm } with { ambncn } yields the non-context-free { anbncn }).

Pumping lemma

The pumping lemma for context-free languages (Bar-Hillel lemma) states that for every CFL L there is a constant p such that every string s in L of length at least p can be written as s = uvwxy with |vwx| ≤ p, |vx| ≥ 1, and uviwxiy in L for all i ≥ 0. It is used to prove that certain languages, such as { anbncn }, are not context-free.

Decidability

Membership of a string in a CFL is decidable in polynomial time (e.g. by the CYK algorithm). Emptiness and finiteness of a CFL are decidable, but universality, equivalence and unambiguity are undecidable in general. The deterministic context-free languages (DCFLs), recognized by deterministic pushdown automata, form a proper subclass with better closure properties, including closure under complementation.

Applications

Context-free grammars and languages underlie the syntax of programming languages, document markup (balanced tags), and much of computational linguistics, where natural language syntax is often approximated with CFG-based formalisms.
