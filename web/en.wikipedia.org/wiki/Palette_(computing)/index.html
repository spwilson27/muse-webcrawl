Palette (computing)

In computer graphics, a palette is the set of available colors from which an image can be made. In some systems, the palette is a fixed set of colors specified by the hardware, known as a system palette or fixed palette. In other cases, the palette is an editable set stored in dedicated memory, often called a color lookup table (CLUT), which maps short index values to full color specifications.

Indexed color

In an indexed color image, each pixel stores not a color but an index into the palette. An 8-bit image, for example, can reference at most 256 palette entries, each of which may specify a full 24-bit RGB color. Changing a palette entry instantly changes every pixel that references it, a property exploited for palette cycling or color cycling animation effects in early video games and demos.

Hardware palettes

Early home computers and game consoles, such as the Commodore 64 and the Nintendo Entertainment System, offered small fixed palettes of a few dozen colors, from which a limited number could appear on screen simultaneously. Later systems such as the Amiga and VGA adapters provided programmable palettes, allowing software to choose any 256 colors from a master palette of 262,144 or more.

Web-safe palette

In the early World Wide Web, when many displays were limited to 256 colors, designers used the web-safe palette of 216 colors that the major operating systems reserved consistently, ensuring pages rendered without dithering across platforms. With the spread of truecolor displays the web-safe palette became largely obsolete.
