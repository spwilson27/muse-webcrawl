Quantum error correction

Quantum error correction (QEC) is used in quantum computing to protect quantum information from errors due to decoherence and other quantum noise. Quantum error correction is theorised as essential to achieve fault-tolerant quantum computation that can reduce the effects of noise on stored quantum information, faulty quantum gates, faulty quantum preparation, and faulty measurements.

Challenges

Classical error correction relies on redundancy: copying data and comparing copies. Quantum mechanics complicates this in several ways. The no-cloning theorem forbids copying an unknown quantum state; measurement of a qubit generally destroys its superposition; and errors are continuous rather than discrete, since a qubit can rotate by an arbitrary small angle. Nevertheless, by encoding one logical qubit into an entangled state of several physical qubits, and by measuring only error syndromes (which reveal information about errors, not about the encoded data), errors can be detected and corrected.

Early codes

Peter Shor proposed the first quantum error-correcting code in 1995, encoding one qubit into nine. Andrew Steane independently developed a seven-qubit code derived from the classical [7,4] Hamming code. These codes correct both bit-flip and phase-flip errors, and hence arbitrary single-qubit errors, because any error can be decomposed into a combination of those types.

Stabilizer codes and the surface code

Most modern codes are described by the stabilizer formalism, in which a set of commuting operators defines the code space and syndrome measurements identify errors. The surface code, based on a two-dimensional lattice of qubits with local checks, is currently the leading approach for large-scale machines because it requires only nearest-neighbour interactions and tolerates relatively high physical error rates, with thresholds around one percent per operation.

Fault tolerance

The threshold theorem states that if the physical error rate is below a certain constant threshold, arbitrarily long quantum computations can be performed reliably by encoding information at sufficiently many levels of error correction or, equivalently, by using a code with a large enough lattice. Quantum error correction is a central focus of current experimental quantum computing research.
