Computer cluster

From Wikipedia, the free encyclopedia

A computer cluster is a set of computers that work together so that they can be viewed as a single system. Unlike grid computers, computer clusters have each node set to perform the same task, controlled and scheduled by software. The components of a cluster are usually connected to each other through a fast local area network, with each node (computer used as a server) running its own instance of an operating system.

Computer clusters emerged as a result of the convergence of trends including the availability of low-cost microprocessors, high-speed networks, and software for high-performance computing. They are usually more cost-effective than single computers of comparable speed and are widely used for purposes ranging from web hosting to supercomputing.

Types of clusters

High-availability clusters

High-availability (HA) clusters are designed to ensure that services remain available if a node fails. Nodes monitor each other and take over workloads from failed members, a process called failover.

Load-balancing clusters

Load-balancing clusters distribute incoming requests — for example web traffic — across multiple back-end nodes to improve responsiveness and throughput. A load balancer typically sits in front of the cluster and routes requests.

High-performance computing clusters

HPC clusters are configured to perform computationally intensive tasks in parallel. Programs are written to split work across nodes, commonly using the Message Passing Interface (MPI). The early Beowulf clusters, built from commodity personal computers running Linux, demonstrated that supercomputer-class performance could be achieved cheaply; many machines on the TOP500 list are clusters of this kind.

Architecture and management

Cluster nodes are often identical or similar machines installed in racks, sharing storage systems and connected by dedicated interconnects such as InfiniBand or high-speed Ethernet. Job scheduling software (such as Slurm or PBS) queues users' jobs and allocates nodes. Container orchestration platforms, notably Kubernetes, provide a related model for managing clustered services in cloud computing.
