LabVIEW

LabVIEW
Developer: National Instruments (NI)
First released: 1986
Paradigm: Dataflow, visual

LabVIEW (short for Laboratory Virtual Instrument Engineering Workbench) is a graphical programming environment and systems engineering platform developed by National Instruments. It is widely used for data acquisition, instrument control, test automation, and industrial monitoring.

Dataflow programming

Programs, called virtual instruments (VIs), are drawn as block diagrams in the graphical language "G". Execution is determined by the flow of data between nodes: a node runs when all its inputs are available, which makes parallelism natural. Each VI has a front panel serving as its user interface.

History

LabVIEW was first released for the Apple Macintosh in 1986, led by Jeff Kodosky, and later ported to Windows, Unix, and Linux. It integrates with NI hardware such as CompactRIO and PXI systems, as well as third-party instruments via drivers.
