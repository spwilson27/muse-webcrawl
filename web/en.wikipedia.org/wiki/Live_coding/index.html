Live coding

From Wikipedia, the free encyclopedia
An algorave performance

Live coding is a performance practice and creative technique in which computer programs are written and modified in real time, in front of an audience, usually to generate improvised music or visuals. The performer's screen is typically projected so the audience can follow the code as it is written and changed while the program is running. Live coding is closely associated with the algorave scene, in which performers code generative techno and electronic dance music in clubs, and with the TOPLAP organisation ("Temporary Organisation for the Promotion of Live Algorithm Programming"), founded in 2004, whose manifesto demands that algorithms be shown to the audience — "obscurantism is dangerous" — rather than hidden like a DJ's secret technique.

Environments and practice

Popular live coding environments include SuperCollider, ChucK, TidalCycles (for pattern-based music in Haskell), Sonic Pi (created by Sam Aaron for education and performance), FoxDot, Extempore and the visual environments Hydra and PraxisLIVE. Performances emphasize liveness, improvisation and risk: because code is edited while it runs, errors are part of the aesthetic, and skilled performers treat the running program as an instrument. The practice extends beyond music to live-coded visuals, choreography, teaching demonstrations and "code jams". Academic conferences such as the International Conference on Live Coding (ICLC) study its aesthetics and pedagogy. Live coding differs from Live2D, an unrelated 2D animation technology.
