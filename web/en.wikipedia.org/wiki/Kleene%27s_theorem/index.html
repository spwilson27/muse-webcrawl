Kleene's theorem

Kleene's theorem, proved by Stephen Cole Kleene in 1951, is a fundamental result in automata theory: a language is regular if and only if it is recognised by a finite automaton — equivalently, the regular languages are exactly those that can be described by a regular expression.

Content

The theorem has two directions: any language accepted by a deterministic or nondeterministic finite automaton can be expressed by a regular expression (often proved via Kleene's algorithm or state elimination), and any regular expression can be compiled into a finite automaton (for example by Thompson's construction). It thus unifies the automaton-based and expression-based views of regularity that underpin lexical analysis in compilers.
