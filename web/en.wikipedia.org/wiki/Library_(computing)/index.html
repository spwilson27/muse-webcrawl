Library (computing)

In computer science, a library is a collection of read-only resources that is leveraged during software development to implement a computer program. Historically, a library consisted of subroutines (generally called functions today) that could be called by other programs. Modern uses of the term also include other types of executable code and non-executable data such as configuration files, documentation, help data, message templates, pre-written code and subroutines, classes, values, and type specifications.

History

The earliest computer libraries were collections of punched cards or tape containing commonly used routines, shared among programmers in the 1950s. Maurice Wilkes, David Wheeler, and Stanley Gill are credited with the invention of the subroutine library at Cambridge, described in their 1951 book on programming for the EDSAC. As operating systems developed, standard libraries became integral parts of programming languages, such as the C standard library.

Types

Static libraries

A static library is a set of object files that a linker copies into the target executable at build time, producing a self-contained program. On Unix-like systems these typically carry the .a suffix (archive); on Windows, .lib.

Shared libraries

A shared library or dynamic library is loaded and linked at run time, so that many programs can use the same code in memory. Unix systems use the .so (shared object) extension, macOS uses .dylib, and Windows uses DLLs (.dll). Dynamic loading allows a program to load a library only when needed, for example to implement plug-ins.

Linking and loading

Programs resolve calls to library routines through linking, performed either at compile time by a linker or at run time by a dynamic loader. Symbol tables record the names and addresses of routines so that references can be bound correctly.
