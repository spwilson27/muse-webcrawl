Process mining

Process mining extracts process models and insights from event logs recorded by information systems.

Process mining is a family of techniques in the field of process science that support the analysis of operational processes based on event logs recorded by information systems. It bridges the gap between traditional model-based process analysis (such as business process management) and data-centric analysis techniques such as data mining and machine learning.

Types

Three basic types of process mining are usually distinguished:

  • Process discovery — constructing a process model (for example a Petri net or BPMN model) from an event log, without prior knowledge of how the process is supposed to work.
  • Conformance checking — comparing an existing process model with an event log of the same process to detect deviations between modelled behaviour and observed behaviour.
  • Enhancement — extending or improving an existing process model using information extracted from event logs, for example by adding performance data such as bottlenecks and waiting times.

Event logs

Process mining starts from event data in which each event refers to an activity, a case (process instance) and a timestamp. Such logs are extracted from enterprise systems including ERP, CRM and workflow systems. The discipline was pioneered in the late 1990s and 2000s by Wil van der Aalst and colleagues at Eindhoven University of Technology, and has since developed into a commercial software category used for auditing, process improvement and automation projects.
