KVM

KVM most commonly refers to Kernel-based Virtual Machine, a virtualisation technology built into the Linux kernel that turns Linux into a Type-1 hypervisor. Using hardware virtualisation extensions such as Intel VT-x and AMD-V, KVM allows multiple virtual machines to run unmodified guest operating systems, each with virtual hardware.

KVM was developed by Qumranet and merged into the mainline Linux kernel in 2007. In practice it is usually combined with QEMU, which provides device emulation. It underpins many cloud and enterprise virtualisation platforms, including Red Hat Virtualization and numerous OpenStack deployments.

The abbreviation may also refer to a KVM switch, a hardware device that lets one keyboard, video monitor and mouse control several computers.
