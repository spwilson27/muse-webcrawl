Linear programming

From Wikipedia, the free encyclopedia

[Image: A shaded polygon feasible region on a graph with a dashed objective line touching a corner]

Linear programming is a method for optimising a linear objective function subject to linear equality and inequality constraints — getting the best outcome from limited resources when everything scales proportionally. The feasible solutions form a convex polygon (in general, a polytope), and the optimum, if it exists, is attained at a corner.

The field was created for logistics: Leonid Kantorovich formulated production-planning problems in 1939 (work that later shared a Nobel Prize in Economics), and George Dantzig invented the simplex algorithm in 1947 while planning for the US Air Force.

Practice

Linear programming schedules airlines, blends refinery feedstocks, sets diets at minimum cost and routes network traffic. The simplex method, though exponential in the worst case, is superb in practice; polynomial-time interior-point methods (Karmarkar, 1984) now rival it.

Duality — every linear program has a twin whose optimum equals its own — is both a computational tool and an economic theorem about shadow prices.
