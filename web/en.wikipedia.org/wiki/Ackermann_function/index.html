Ackermann function

In computability theory, the Ackermann function, named after Wilhelm Ackermann, is one of the simplest and earliest-discovered examples of a total computable function that is not primitive recursive. It grows extremely rapidly: even for small inputs its values are enormous. Ackermann published the (three-argument) function in 1928; the now-standard two-argument version is due to Rózsa Péter and Raphael Robinson.

Definition

A(m, n) = n + 1 if m = 0; A(m − 1, 1) if m > 0 and n = 0; A(m − 1, A(m, n − 1)) if m > 0 and n > 0

A(4, 2) is a tower of 2s 65,536 high minus 3 — a number with more than 19,000 decimal digits. The function can be understood in terms of hyperoperations: successive values of m correspond to addition, multiplication, exponentiation, tetration, and beyond (Knuth's up-arrow notation).

Significance

Ackermann showed that the function is computable — it terminates for every input — yet it eventually outgrows every primitive recursive function, disproving a conjecture in Hilbert's program that all computable functions might be primitive recursive. Its inverse, the inverse Ackermann function α(n), grows so slowly that it appears as an almost-constant factor in the analysis of algorithms such as the disjoint-set union data structure and in the Davenport–Schwartz theory of geometric algorithms.
