In computer science, an array is a data structure consisting of a collection of elements (values or variables), each identified by at least one array index or key. An array is stored so that the position of each element can be computed from its index tuple by a mathematical formula. The simplest type of data structure is a linear array, also called a one-dimensional array.

Properties

Arrays occupy contiguous memory and store elements of (usually) a single type, allowing constant-time random access: the address of element i is the base address plus i multiplied by the element size. The trade-off is that inserting or deleting elements in the middle requires shifting subsequent elements, an O(n) operation, and a fixed-size array cannot grow without reallocation — a limitation addressed by dynamic arrays such as C++'s std::vector and Python's list.

Indexing

Languages differ in their base index: C, Java and many successors use zero-based numbering, while Fortran, MATLAB and older languages use one-based numbering. Indices may also be arbitrary ranges, as in Pascal or Ada. Multi-dimensional arrays generalise the idea to grids indexed by several integers and are stored in either row-major or column-major order.

Applications

Arrays underlie many other structures and algorithms, including strings, heaps, hash tables with open addressing, and lookup tables. They are also the principal data type of numerical computing libraries and of languages designed for array programming, such as APL.
