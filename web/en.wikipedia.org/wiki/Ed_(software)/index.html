ed (software)

ed is a line editor for Unix and Unix-like operating systems. It was one of the very earliest parts of the Unix operating system developed, in August 1969, at Bell Labs by Ken Thompson, alongside the Unix kernel itself. It remains part of the POSIX and Open Group standards for Unix-based operating systems, alongside the more sophisticated full-screen editors ex and vi.

History and influence

Many features of ed came from the qed text editor developed by Thompson and Dennis Ritchie at Bell Labs in the 1960s. Thompson's version of QED on the CTSS system was the first editor to support regular expressions. Thompson re-implemented QED's regular expressions in ed as a distinct sub-language.

The editor is extremely terse: in its original form, its only feedback was a single question mark when an error occurred, and it required the user to type h to see the last error message. This terseness led to the famous joke that "ed is the standard text editor," and to the satirical Usenet post of 1991 that began "When I log into my Xenix system with my 110 baud teletype, both vi and Emacs are just too damn slow."

Features

Features of ed include:

  • being available on essentially every Unix system (and mandatory under the Single UNIX Specification);
  • support for editing very large files, line by line, with a small memory footprint;
  • a command language similar to a scripting language, with commands such as a (append), d (delete), s (substitute), g (global), and w (write).

ed influenced later editors: ex was an extended version of ed, vi added a full-screen visual mode to ex, and the stream editor sed generalized ed's non-interactive editing model. The regular-expression syntax pioneered in ed underlies grep (whose name derives from ed's g/re/p command — "global regular expression print"), awk, and much of the Unix tool tradition.
