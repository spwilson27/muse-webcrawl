Model in the loop

Model in the loop (MIL) is a stage in model-based design and testing, widely used in automotive and embedded systems engineering, in which a control algorithm model is simulated together with a mathematical model of the plant (the physical system being controlled) in a purely software simulation environment.

Position in the V-model

MIL is typically the earliest "in the loop" testing stage. As development proceeds, the model is progressively replaced by real artifacts:

  • Model in the loop (MIL) — both controller and plant are models running in simulation.
  • Software in the loop (SIL) — the generated or hand-written controller code runs against a plant model.
  • Processor in the loop (PIL) — the code runs on the target processor (or an evaluation board) against a simulated plant.
  • Hardware in the loop (HIL) — the real controller hardware interacts with a real-time simulation of the plant.

Purpose

MIL testing allows engineers to verify requirements, control performance, and edge cases early and cheaply, before any code generation or hardware exists. Discrepancies found at this stage can be fed back into the models, reducing the cost of defects discovered later in development.
