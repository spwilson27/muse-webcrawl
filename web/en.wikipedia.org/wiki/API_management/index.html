API management

API management is the process of creating and publishing web application programming interfaces (APIs), enforcing their usage policies, controlling access, collecting and analyzing usage statistics, and reporting on performance. It is typically delivered through a combination of an API gateway, a developer portal, and lifecycle management tooling.

Components

An API gateway sits between clients and back-end services, routing requests and applying policies such as authentication, rate limiting, quotas, and caching. A publisher portal lets API providers design, document, version and retire APIs, while a developer portal lets consumers discover APIs, register applications, and obtain credentials such as API keys and OAuth tokens.

Purpose

API management supports the "API economy", in which organizations expose data and services to partners, developers and internal teams in a controlled, measurable way. Analytics gathered by the platform inform capacity planning, monetization, and security auditing.
