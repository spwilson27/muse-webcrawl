Hinge loss

The hinge loss is a loss function used for training classifiers, most notably the support vector machine (SVM). For an intended output t = ±1 and a classifier score y, the hinge loss is defined as ℓ(y) = max(0, 1 − t·y).

Interpretation

The loss is zero when the sign of y matches t and the margin t·y is at least 1 — that is, the example is correctly classified with a comfortable margin. Otherwise the loss grows linearly with the violation. Minimizing hinge loss (with regularization) is exactly the optimization problem solved by a soft-margin SVM, which trades off margin maximization against classification errors. The function is convex but not differentiable at t·y = 1, so optimization typically uses subgradient methods.

Variants

Variants include the squared hinge loss, which is differentiable and penalizes violations quadratically, and multiclass extensions such as the Crammer–Singer loss. Compared with logistic loss, hinge loss yields sparse solutions in terms of support vectors and does not estimate probabilities.
