Codec

[Image placeholder: Diagram of audio/video encoding and decoding]

A codec is a device or computer program that encodes or decodes a data stream or signal. Codec is a portmanteau of coder/decoder. In electronic communications, an endec is a device that acts as both encoder and decoder on a signal or data stream.

Compression

Codecs often compress data to reduce file size or bandwidth. Lossy compression, used by formats such as MP3, AAC, H.264 and H.265, discards imperceptible information to achieve large reductions, while lossless codecs such as FLAC preserve the original data exactly.

Examples

  • Audio: MP3, AAC, Opus, FLAC, Vorbis
  • Video: H.264/AVC, H.265/HEVC, VP9, AV1, MPEG-2
  • Image: JPEG, PNG (strictly formats incorporating codecs)

Codecs and containers

A codec should not be confused with a container format (such as MP4, MKV or AVI), which packages encoded audio, video, subtitles and metadata into a single file.
