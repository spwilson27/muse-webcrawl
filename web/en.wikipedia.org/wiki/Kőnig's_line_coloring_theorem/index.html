Kőnig's line coloring theorem

In graph theory, Kőnig's line coloring theorem, proved by Dénes Kőnig (1916), describes an equivalence between the edge-coloring problem and the matching problem on bipartite graphs. It states that any bipartite graph can be edge-colored using a number of colors equal to the maximum degree Δ of the graph.

Statement

An edge coloring of a graph assigns a color to each edge so that no two edges sharing a vertex have the same color. The smallest number of colors needed is the chromatic index χ′(G). In any graph, at least Δ colors are necessary, because all the edges incident to a maximum-degree vertex must have different colors. Kőnig's theorem states that for bipartite graphs this lower bound is always achievable: χ′(G) = Δ for every bipartite graph G.

Example

Consider a schedule of meetings between teachers and classes: each requirement that a teacher meet a class is an edge in a bipartite graph. A coloring of the edges corresponds to an assignment of time slots to meetings in which no teacher or class is double-booked, and Kőnig's theorem guarantees a schedule whose length equals the largest number of meetings involving any single teacher or class — clearly the best possible.

Proof outline

The standard proof proceeds by induction on the number of edges. Given a bipartite graph with maximum degree Δ, one finds either a matching that covers all maximum-degree vertices — which can be colored with one color and removed, reducing to the case Δ − 1 — or, more directly, regularises the graph by adding dummy vertices and edges to make it Δ-regular, then repeatedly extracts perfect matchings (whose existence follows from Hall's marriage theorem) to serve as the color classes.

Relation to other results

The theorem is closely related to Kőnig's theorem on matchings and vertex covers in bipartite graphs (the Kőnig–Egerváry theorem), and indeed an edge coloring of a bipartite graph with Δ colors can be converted into a decomposition of the edge set into Δ matchings, each of which corresponds to a color class. For general (non-bipartite) graphs, the classification of graphs by chromatic index is governed instead by Vizing's theorem, which shows that Δ or Δ + 1 colors always suffice, and deciding which can be NP-complete.
