CircuitPython is an open-source programming language and runtime for microcontrollers, derived from MicroPython and maintained by Adafruit Industries together with a community of contributors. It implements a subset of the Python 3 language with hardware-specific modules, aiming to make embedded programming accessible to beginners, educators and hobbyists.

Features

A defining feature of CircuitPython is its ease of use: compatible boards appear on a host computer as a USB mass-storage drive, and editing the code.py file on that drive immediately saves and re-runs the program — no separate toolchain, flashing step or IDE is required. A serial REPL provides interactive access. Built-in modules expose hardware interfaces such as digital and analog I/O, I2C, SPI, UART, PWM, touch sensing, audio and NeoPixel LEDs, and a large ecosystem of community libraries supports sensors, displays and motors.

History

Adafruit forked MicroPython in 2016–2017 to prioritize a consistent, beginner-friendly hardware API across boards, releasing CircuitPython 1.0 in 2017. It powers Adafruit boards such as the Circuit Playground Express, Feather M0/M4, Metro, ItsyBitsy, CLUE, and third-party boards based on chips including the Microchip SAMD21/SAMD51, Nordic nRF52840, Espressif ESP32 family and Raspberry Pi RP2040.

Relationship to MicroPython

CircuitPython and MicroPython share the same core interpreter lineage but differ in goals: CircuitPython favours a uniform beginner-oriented API and the USB-drive workflow, while MicroPython targets a broader range of platforms and closer parity with CPython internals. Code is often portable between them with small changes, though the hardware APIs differ.
