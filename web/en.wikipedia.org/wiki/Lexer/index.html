Lexer

A lexer, short for lexical analyser (also called a scanner or tokenizer), is a program that performs lexical analysis: it converts a sequence of characters into a sequence of tokens (strings with an assigned meaning). A program that combines lexical analysis with parsing is commonly called a parser.

Function

The lexer reads input characters, groups them into lexemes according to the lexical grammar of the language, and outputs tokens such as identifiers, keywords, literals, operators and punctuation, discarding whitespace and comments. Lexers are usually implemented as finite-state machines based on regular expressions, and tools such as lex and flex can generate them automatically.

Relation to parsing

The token stream produced by the lexer is consumed by the parser, which builds a parse tree according to the syntactic grammar. Splitting compilation into lexical and syntactic phases simplifies both components, though some languages require feedback from the parser to the lexer.
