Fisher's exact test

FieldStatistics
Named afterRonald Fisher
Data typeCategorical (contingency tables)

Fisher's exact test is a statistical significance test used in the analysis of contingency tables. Although in practice it is employed when sample sizes are small, it is valid for all sample sizes. It is named after its inventor, Ronald Fisher, and is one of a class of exact tests, so called because the significance of the deviation from the null hypothesis can be calculated exactly using the hypergeometric distribution, rather than relying on an approximation that becomes exact only as the sample size grows.

Procedure

For a 2×2 contingency table, the test computes the probability of obtaining the observed table, or one more extreme, given fixed row and column margins. The classic illustration is Fisher's "lady tasting tea" experiment, designed to test Muriel Bristol's claim that she could tell whether milk or tea had been added first to a cup.

Comparison with chi-squared test

Unlike Pearson's chi-squared test, Fisher's exact test does not depend on large-sample approximations and is preferred when expected cell counts are small, though it can be computationally intensive for large tables.
