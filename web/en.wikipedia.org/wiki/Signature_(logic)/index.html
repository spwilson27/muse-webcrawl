Signature (logic)

In logic, especially mathematical logic, a signature lists and describes the non-logical symbols of a formal language. In universal algebra a signature is sometimes called a type or alphabet, and the notion overlaps with that of a first-order language: a language is determined by its signature together with the logical symbols (connectives, quantifiers, variables and equality).

Definition

A signature σ consists of a set of function symbols and a set of relation symbols (also called predicate symbols), each equipped with a natural-number arity. A function symbol of arity 0 is called a constant symbol. Formally, one may specify the signature as a triple σ = (Sfunc, Srel, ar), where ar assigns to every symbol its arity; alternatively it is presented as a set of symbols with arities annotated, e.g. σ = {+, ·, 0, 1} for the language of rings, with + and · binary function symbols and 0, 1 constants.

Structures and interpretations

A structure for a signature σ (a σ-structure, or model when it satisfies a given theory) consists of a non-empty set A (the universe or domain) together with an interpretation of each symbol: each n-ary function symbol is interpreted as a function An → A, each constant as an element of A, and each n-ary relation symbol as a subset of An. For example, the signature of arithmetic {0, S, +, ·, <} is interpreted in the standard model by the natural numbers with successor, addition, multiplication and the usual ordering.

Examples

  • Groups: σ = {·, −1, e} — one binary function, one unary function, one constant.
  • Ordered fields: σ = {+, ·, −, 0, 1, <} — the language of ordered fields used in real closed field theory.
  • Graphs: σ = {E} with E a single binary relation symbol.
  • Set theory: σ = {∈} — a single binary relation.

Homomorphisms

Between two σ-structures, a homomorphism is a map between universes commuting with the interpretations of function symbols and preserving the relation symbols; strong homomorphisms, embeddings and isomorphisms are defined by strengthening these requirements. The collection of σ-structures and their homomorphisms is a central object of model theory and universal algebra.
