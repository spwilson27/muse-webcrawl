Space complexity

Space is measured by the work tape cells an algorithm uses

In computational complexity theory, the space complexity of an algorithm or problem is the amount of memory space it requires to solve an instance of the computational problem as a function of characteristics of the input. It is the memory required by an algorithm until its execution is complete. Closely related is time complexity; together the two resources define the classic complexity classes studied in the field.

Definitions

Formally, for a Turing machine, DSPACE(f(n)) is the set of problems solvable using O(f(n)) cells of a work tape on inputs of size n; the input and output tapes are conventionally not counted, so that sublinear space bounds remain meaningful. NSPACE(f(n)) is the corresponding class for nondeterministic machines. Important classes include:

  • L — logarithmic space, DSPACE(O(log n))
  • NL — nondeterministic logarithmic space
  • PSPACE — polynomial space, the union of DSPACE(nk) for all k
  • EXPSPACE — exponential space

Key theorems

Savitch's theorem (1970) states that NSPACE(f(n)) ⊆ DSPACE(f(n)²) for f(n) ≥ log n; a famous corollary is that PSPACE = NPSPACE, and that NL ⊆ DSPACE(log² n). The space hierarchy theorem shows that strictly more space permits strictly more problems to be solved when the bound is space-constructible. The Immerman–Szelepcsényi theorem (1987–88) shows that nondeterministic space classes are closed under complement, so NL = coNL.

Space-bounded computation exhibits behaviour strikingly different from time: space can be reused, so polynomial space can simulate exponential time in some cases, and it remains unknown whether P = PSPACE — one of complexity theory's central open problems. Every problem in PSPACE can be solved in exponential time, so P ⊆ PSPACE ⊆ EXPTIME.

Auxiliary space

In practical algorithm analysis, "space complexity" often means auxiliary space — the extra memory beyond the input itself — and is reported in big-O notation: a mergesort uses O(n) auxiliary space, while an in-place heapsort uses O(1).
