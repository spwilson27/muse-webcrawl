Rank-width

Rank-width is a graph width parameter introduced by Sang-il Oum and Paul Seymour in their work on approximations of clique-width. It measures how closely a graph can be recursively partitioned into pieces that interact with each other through low-rank bipartite connections, where the rank is computed over the binary field GF(2).

Definitions

A rank decomposition of a graph G is a subcubic tree whose leaves are bijectively labelled by the vertices of G. Removing an edge of the tree splits the vertices into two sets A and B; the width of that cut is the rank over GF(2) of the bipartite adjacency matrix between A and B. The width of the decomposition is the maximum cut-rank over all its edges, and the rank-width of G is the minimum width over all rank decompositions.

Properties

Rank-width is functionally equivalent to clique-width: the two parameters bound each other by functions, so classes of graphs have bounded rank-width if and only if they have bounded clique-width. However, rank-width has some advantages: there is a cubic-time algorithm that either computes a rank decomposition of width at most k or determines that the rank-width exceeds k, for any fixed k, whereas the corresponding problem for clique-width is harder to approximate directly.

Graphs of rank-width one are exactly the distance-hereditary graphs. Rank-width is also related to the vertex-minor relation in the same way that treewidth relates to graph minors; Oum showed that graphs of bounded rank-width are well-quasi-ordered under vertex-minors.

Algorithms

Many graph problems that are NP-hard in general become fixed-parameter tractable when the input graph has bounded rank-width (or clique-width), including problems expressible in monadic second-order logic. Rank decompositions can be used to design dynamic programming algorithms over the decomposition tree.
