Suffix tree

In computer science, a suffix tree (also called a PAT tree) is a compressed trie that contains all the suffixes of a given text as keys, with their starting positions as values. It is a fundamental data structure for string algorithms, because many problems that appear to require scanning the whole text can be answered in time proportional only to the length of the pattern being searched.

Properties

For a text of length n, a suffix tree uses O(n) space and can be constructed in O(n) time. Once built, it supports substring search in O(m) time for a pattern of length m, finding the longest repeated substring, the longest common substring of two strings, and pattern matching with mismatches, among many other operations. Edges are labelled with substrings (stored as index ranges into the text), and internal nodes are connected by suffix links that shortcut between nodes representing suffixes of one another.

History and construction

Peter Weiner introduced the structure in 1973 — the first linear-time construction — followed by Edward McCreight's more space-economical algorithm in 1976. Esko Ukkonen's 1995 algorithm is the most widely taught: an online, left-to-right construction using suffix links and the "skip/count" trick, building the tree in a single pass. Farach's algorithm (1997) extended linear construction to integer alphabets.

Applications

Suffix trees are used in bioinformatics for genome analysis and sequence alignment, in data compression (the Lempel–Ziv family), in text editors' find functions, and as the conceptual basis for suffix arrays and the Burrows–Wheeler transform, which offer similar capabilities with smaller memory footprints and have largely supplanted suffix trees in practice.
