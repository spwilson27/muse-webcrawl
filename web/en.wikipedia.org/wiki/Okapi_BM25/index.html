Okapi BM25

In information retrieval, Okapi BM25 (BM stands for Best Matching) is a ranking function used by search engines to estimate the relevance of documents to a given search query. It is based on the probabilistic retrieval framework developed in the 1970s and 1980s by Stephen E. Robertson, Karen Spärck Jones, and others.

BM25 is a bag-of-words retrieval function that ranks a set of documents based on the query terms appearing in each document, regardless of their proximity within the document. It is not a single function, but a family of scoring functions with slightly different components and parameters. One common instantiation is described below.

Ranking function

Given a query Q containing keywords q1, ..., qn, the BM25 score of a document D is:

score(D, Q) = Σi IDF(qi) · [ f(qi, D) · (k1 + 1) ] / [ f(qi, D) + k1 · (1 − b + b · |D| / avgdl) ]

where f(qi, D) is the frequency of term qi in document D, |D| is the length of the document in words, avgdl is the average document length in the collection, and k1 and b are free parameters, usually chosen as k1 = 1.2 to 2.0 and b = 0.75.

History

The function was developed as part of the Okapi information retrieval system at City, University of London, which was used in the TREC (Text Retrieval Conference) evaluations in the 1990s. BM25 and its variants are widely used in practice, including in open-source search engines such as Lucene, Elasticsearch and Solr, where BM25 became the default similarity function.

Variants

Variants include BM25+, which addresses the issue that long documents can be unfairly penalised, and BM25F, which extends the model to documents composed of multiple fields such as title, body and anchor text.
