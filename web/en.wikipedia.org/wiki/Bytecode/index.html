Bytecode

Bytecode is a form of instruction set designed for efficient execution by a software interpreter. Unlike human-readable source code, it consists of compact numeric codes, constants and references (normally numeric addresses) that encode the result of compiler parsing and semantic analysis of things like type, scope and nesting depths of program objects.

Execution

Bytecode is typically executed by a virtual machine. Because it is a machine-independent intermediate representation, programs can run on any platform with a suitable interpreter — the principle behind Java's "write once, run anywhere". The Java Virtual Machine executes Java bytecode stored in .class files; the .NET Common Language Runtime executes CIL; Python compiles source to bytecode cached in .pyc files for its virtual machine.

Performance

Pure interpretation of bytecode is slower than native machine code, so many implementations use just-in-time (JIT) compilation to translate bytecode to native instructions at runtime. Bytecode is generally more compact than source code and easier for a machine to parse, speeding program loading and startup.
