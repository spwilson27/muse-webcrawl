Dataflow programming

Dataflow programming is a programming paradigm that models a program as a directed graph of operations connected by flows of data. Execution is driven by the availability of data: an operation runs when all its inputs are present. This contrasts with the control-flow von Neumann model, in which instructions execute in an order specified by a program counter.

Concepts

In a dataflow program, nodes represent operations and edges represent data passing between them as tokens. Because operations have no side effects on shared state and depend only on their inputs, dataflow programs expose inherent parallelism: independent operations can execute concurrently, in any order, or on separate processors. This made dataflow an active research area for parallel computer architecture in the 1970s and 1980s, with machines built at MIT and elsewhere.

Examples

Widely used dataflow systems include spreadsheets (where cells recompute when inputs change), the visual language LabVIEW, Unix pipelines, shader and node graphs in graphics software, stream-processing frameworks, and tools such as Apache NiFi and Node-RED. Dataflow concepts also appear in hardware description languages and in the execution graphs of machine-learning frameworks.
