Data-flow analysis

Data-flow analysis is a technique for gathering information about the possible set of values calculated at various points in a computer program. It is a form of static program analysis performed by compilers to enable optimisations and program verification. The analysis typically operates on the program's control-flow graph.

Principles

A data-flow analysis associates with each program point a data-flow value representing an abstraction of the set of possible program states. Analyses are classified as forward (information flows in the direction of execution, as in reaching definitions) or backward (as in live-variable analysis). Each basic block has a transfer function describing how it transforms input information, and information from multiple predecessors or successors is combined with a meet (or join) operator. The equations are solved iteratively until a fixed point is reached; termination is guaranteed when the values form a lattice of finite height and the transfer functions are monotone.

Common analyses

  • Reaching definitions — which definitions of a variable may reach a given point.
  • Live-variable analysis — which variables may be used before being redefined.
  • Available expressions — which expressions have already been computed and not invalidated.
  • Very busy expressions — which expressions will be evaluated along every path from a point.

Applications

Data-flow results underpin compiler optimisations such as constant propagation, common subexpression elimination, dead-code elimination and register allocation, as well as bug-finding tools that detect uninitialised variables or null-pointer dereferences.
