Completeness (logic)

In mathematical logic, completeness refers to several related properties of formal systems. A deductive system is semantically complete if every formula that is logically valid (true in every model) is provable in the system. A theory is negation-complete (or syntactically complete) if for every sentence, either the sentence or its negation is provable.

Semantic completeness

Kurt Gödel proved in his 1929 doctoral dissertation (published 1930) the completeness theorem for first-order logic: a sentence is provable from a set of axioms using first-order deduction if and only if it is true in every model of those axioms. Together with soundness, this means provability and logical consequence coincide for first-order logic.

Syntactic completeness and incompleteness

Gödel's first incompleteness theorem (1931) shows that any consistent, effectively axiomatised theory capable of expressing elementary arithmetic — such as Peano arithmetic — is negation-incomplete: there are true but unprovable sentences. Thus semantic completeness of the logic does not imply completeness of strong theories built in it.

Other notions

  • Expressive completeness — a language can express certain concepts (e.g., a set of connectives is functionally complete).
  • Completeness of propositional logic — Post's completeness results.
  • Lindström's theorem characterises first-order logic as the strongest logic with both completeness and compactness properties.
