m4 (computer language)

m4
Paradigm: Macro processing
Designed by: Brian Kernighan and Dennis Ritchie
First appeared: 1977
Implementations: GNU m4, BSD m4

m4 is a general-purpose macro processor created by Brian Kernighan and Dennis Ritchie for Unix systems. An m4 macro processor copies its input to its output, expanding macros as it goes. It is a standard component of Unix and POSIX systems and is best known as the language underlying GNU Autoconf and the sendmail configuration system.

Features

m4 provides built-in functions for defining macros (define), including files (include), arithmetic (eval), string manipulation (substr, index, translit), conditionals (ifelse), loops (forloop in GNU m4), and diverting output to temporary buffers (divert). By default the left and right quotes are the backtick and apostrophe, changeable with changequote.

History and influence

m4 descends from earlier macro processors such as GPM by Christopher Strachey. The original version was written for the first edition of Kernighan and Plauger's Software Tools (1976) as the Ratfor-era macro tool, then rewritten for Unix. Ozan Yigit's BSD m4 and the GNU m4 implementation (by René Seindal) are the common modern versions. Because Autoconf generates configure scripts using m4, the language is indirectly involved in building a large fraction of open-source software.

Example

define(`foo', `Hello, world')dnl
foo — expands to "Hello, world", with dnl deleting the following newline.
