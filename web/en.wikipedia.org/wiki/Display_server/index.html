Display server

A display server or window server is a program whose primary task is to coordinate the input and output of its clients to and from the rest of the operating system, the hardware, and each other. The display server communicates with its clients over the display server protocol, a communications protocol, which can be network-transparent or simply network-capable.

The display server is a key component in any graphical user interface, specifically, the windowing system. It manages the placement and appearance of windows within a display and handles input from devices such as the keyboard and mouse.

Implementations

The most historically significant display server implementation is the X Window System (X11), developed at MIT beginning in 1984 and long the standard on Unix and Unix-like systems; its reference implementation is the X.Org Server. In the X architecture, the display server and the window manager are separate processes, and a separate compositing manager may add effects such as transparency.

Wayland is a newer display server protocol for Unix-like systems in which the display server, window manager, and compositor are combined into a single process called a Wayland compositor; examples include Weston, Mutter (GNOME), KWin (KDE Plasma), and Sway. Mir, developed by Canonical, is another display server system that was later repositioned as a Wayland compositor framework.

On proprietary systems, Microsoft Windows uses the Desktop Window Manager and macOS uses the Quartz Compositor as their window servers, although these are integrated into the operating system rather than exposed as discrete servers in the Unix sense.
