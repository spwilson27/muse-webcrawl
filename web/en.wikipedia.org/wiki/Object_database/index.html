Object database

An object database (also called an object-oriented database management system, OODBMS) is a database management system in which information is represented in the form of objects as used in object-oriented programming. Object databases became a distinct field in the 1980s and 1990s as an alternative to the dominant relational model, and they are used when the data being stored closely matches an application's object model.

Overview

In a relational database, complex data structures must be decomposed into tables of rows and columns, and reassembled when read — a mismatch often called the object–relational impedance mismatch. An object database instead stores objects with their attributes and methods intact, supports inheritance and polymorphism in its data model, and identifies each object with a persistent object identifier. Objects are typically retrieved by navigating references from known objects, or by declarative queries in a language such as OQL (Object Query Language), standardized by the Object Data Management Group (ODMG).

History

Early commercial systems included GemStone (from Servio Logic, mid-1980s), Ontos, Objectivity/DB, ObjectStore, Versant, and the open-source db4o. Object databases found durable niches in telecommunications, engineering and CAD, financial trading, and scientific applications with deeply nested data. The ODMG published standards (final version ODMG 3.0 in 2000) but never achieved the cross-vendor uniformity of SQL. From the 2000s onward, many of the ideas were absorbed into object–relational mapping tools and object–relational databases, while modern document-oriented and NoSQL systems address some of the same use cases.

Comparison with relational databases

Object databases can outperform relational systems for workloads dominated by traversal of complex object graphs, and they avoid mapping code. Relational systems remain stronger for ad hoc querying, reporting, data independence, and tooling maturity. Many production architectures therefore combine both approaches.
