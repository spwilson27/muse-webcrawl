Numba is an open-source just-in-time (JIT) compiler that translates a subset of Python and NumPy code into fast machine code. It uses the LLVM compiler infrastructure to compile Python code, particularly numerical functions and loops, to optimized native code for CPUs and GPUs.

Numba is developed primarily by Anaconda, Inc., with support from various community contributors. It works by applying a decorator, such as @numba.jit, to Python functions, which are then compiled at runtime on first invocation. Numba supports automatic parallelization of code, generation of GPU-accelerated code for CUDA and ROCm, and works with NumPy arrays.

Example

A simple example compiles a loop-heavy function:

from numba import jit

@jit(nopython=True)
def sum2d(arr):
    total = 0.0
    for i in range(arr.shape[0]):
        for j in range(arr.shape[1]):
            total += arr[i, j]
    return total
