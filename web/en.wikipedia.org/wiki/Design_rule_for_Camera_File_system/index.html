Design rule for Camera File system (DCF) is a JEITA standard (number CP-3461) which specifies the file system for digital cameras, including the directory structure, file naming method, character set, file format, and metadata format. It is the de facto industry standard for digital still cameras. The file format of DCF is based on the Exif 2.2 specification.

File system structure

DCF requires a root directory named DCIM (Digital Camera IMages) on the removable media. Within DCIM, images are stored in subdirectories whose names consist of a three-digit directory number (100–999) followed by five alphanumeric characters chosen by the manufacturer — for example, 100CANON or 101MSDCF. File names consist of four alphanumeric characters (often DSC_, DSC0 or IMG_) followed by a four-digit file number, as in DSC_0001.JPG. The rules ensure that any DCF-compliant camera, printer or viewer can find and read images written by any other, enabling services such as direct printing via DPOF.

Objects and thumbnails

A "DCF object" is a file (or a group of related files, such as an image plus its audio annotation) sharing the same file number. The specification also defines thumbnail images and rules for directories and file numbers so that ordering is preserved when images are copied or displayed. Nearly all digital cameras — and smartphones when acting as cameras — write media in DCF form, which is why photo-import software expects the DCIM folder.
