Valgrind

Valgrind is a programming tool for memory debugging, memory leak detection, and profiling. Originally designed for Linux on x86, it has been ported to several platforms including Linux on ARM, FreeBSD, macOS, and Solaris. It is free software released under the GNU General Public License.

How it works

Valgrind runs programs on a synthetic virtual machine using dynamic binary translation: the program's machine code is translated into an intermediate representation, instrumented by a chosen tool, and executed without modifying or recompiling the original binary. Programs typically run 5 to 30 times slower under Valgrind.

Tools

The default and most used tool is Memcheck, which detects memory-management errors such as use of uninitialised memory, reading or writing freed memory, buffer overflows, and memory leaks. Other tools include Cachegrind and Callgrind (cache and call-graph profilers), Massif (a heap profiler), Helgrind and DRD (thread error detectors for race conditions and lock misuse), and DHAT (a dynamic heap analysis tool).

Valgrind was created primarily by Julian Seward and received a Google-O'Reilly Open Source Award in 2006.
