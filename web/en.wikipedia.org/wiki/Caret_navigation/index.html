Caret navigation

In computing, caret navigation (also called caret browsing) is a method of navigating a document or web page using a keyboard-accessible text cursor, known as a caret. Unlike tab navigation, which jumps between links and form controls, caret navigation moves through the text of a page in much the same way as a cursor in a word processor.

Usage

With caret navigation enabled, a blinking caret appears in the page. The arrow keys move it character by character and line by line, allowing users to select and copy text, or to read sequentially, without using a mouse. In several browsers the feature is toggled with the F7 key.

Accessibility

Caret navigation is an important accessibility feature. It benefits users who cannot use a pointing device and screen reader users who explore page content character by character. Most major browsers, including Firefox, Chrome, and Edge, support the feature natively or through settings.
