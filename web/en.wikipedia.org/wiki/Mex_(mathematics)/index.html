Mex (mathematics)

In combinatorial game theory, the mex, or minimum excluded value, of a set of ordinal numbers is the smallest ordinal that does not belong to the set. The name is a contraction of "minimum excluded".

The mex operation is central to the Sprague–Grundy theory of impartial games, where the Grundy value (or nimber) of a position is defined as the mex of the Grundy values of all positions reachable from it.

Examples

For finite sets of natural numbers, the mex is easy to compute:

mex({}) = 0
mex({0}) = 1
mex({1, 2}) = 0
mex({0, 1, 3}) = 2
mex({0, 1, 2, 3, ...}) = the first omitted value

In general, if a set S contains every natural number below n, and does not contain n, then mex(S) = n.

Use in impartial games

In the game of Nim and its variants, each impartial game position is equivalent to a nim-heap of some size, called its Grundy number. A position is a losing position for the player to move exactly when its Grundy number is 0, which occurs exactly when 0 is among the options' values — in other words, when the mex of the options excludes nothing smaller. Recursive application of the mex rule lets one compute the outcome class of complicated games from their simpler components.

Properties

The mex of a set of ordinals is always an ordinal not in the set, and it is the least such. For a set of natural numbers, mex(S) is at most the cardinality of S. The operation also appears in the theory of surreal numbers, where the simplest number not equal to any of a collection of earlier numbers is defined using a related "simplest value" idea.
