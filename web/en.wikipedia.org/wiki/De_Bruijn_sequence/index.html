De Bruijn sequence

A De Bruijn graph: an Eulerian cycle through it yields a De Bruijn sequence

In combinatorial mathematics, a De Bruijn sequence of order n on a size-k alphabet A is a cyclic sequence in which every possible length-n string on A occurs exactly once as a substring (that is, as a contiguous subsequence). Such a sequence is denoted B(k, n) and has length kn, which is also the number of distinct substrings of length n on a size-k alphabet; De Bruijn sequences are therefore optimally short. The sequence is named after the Dutch mathematician Nicolaas Govert de Bruijn, who studied the problem in 1946, though the binary case had been described earlier.

Example

For a binary alphabet (k = 2) and n = 3, one De Bruijn sequence is 00010111. Read cyclically, its eight substrings of length 3 are 000, 001, 010, 101, 011, 111, 110 and 100 — every possible 3-bit string exactly once.

Construction

De Bruijn sequences can be constructed by taking an Eulerian cycle of a De Bruijn graph: the directed graph whose vertices are the strings of length n − 1 and whose edges represent appending one symbol. Because the graph is Eulerian, a cycle using every edge exactly once always exists, and concatenating the symbols along such a cycle yields a De Bruijn sequence. The number of distinct B(k, n) sequences is (k!)kn−1 / kn. A simple constructive rule is the "prefer one" algorithm: starting with n zeros, repeatedly append a 1 if the resulting length-n string has not appeared before, otherwise append a 0. Related constructions include shift-register sequences and the lexicographically smallest De Bruijn sequence, produced by concatenating Lyndon words.

Applications

De Bruijn sequences have applications in many fields. They can encode the position of a rotating shaft or linear encoder with a minimal number of sensors: reading n consecutive symbols uniquely determines absolute position. In genomics, De Bruijn graphs (a related concept using substrings of reads) are the standard data structure for genome assembly. De Bruijn sequences also appear in card tricks, in testing of digital circuits, in the design of experiments, and in robotic localization.

De Bruijn torus

A two-dimensional generalisation, a De Bruijn torus, is an array in which every possible m-by-n submatrix over the alphabet occurs exactly once (wrapping around the edges). Such arrays can be used for two-dimensional position encoding.
