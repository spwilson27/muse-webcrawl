Minimum spanning tree

A minimum spanning tree (MST) or minimum weight spanning tree is a subset of the edges of a connected, edge-weighted undirected graph that connects all the vertices together, without any cycles, and with the minimum possible total edge weight. If the graph is not connected, the corresponding structure on each component is a minimum spanning forest.

Properties

A minimum spanning tree has V − 1 edges for a graph of V vertices. The cut property states that for any cut of the graph, the lightest edge crossing the cut belongs to some MST; the cycle property states that the heaviest edge in any cycle belongs to no MST (unless weights are tied). Minimum spanning trees need not be unique when edge weights repeat.

Algorithms

Classical greedy algorithms include Prim's algorithm, which grows the tree from a starting vertex, and Kruskal's algorithm, which adds edges in increasing order of weight while avoiding cycles, usually implemented with a disjoint-set data structure. The first known algorithm was published by Otakar Borůvka in 1926 in connection with efficient electrical network design in Moravia. Faster algorithms, such as the Chazelle algorithm, run in almost linear time, and a linear-time algorithm is conjectured to exist.

Applications

Minimum spanning trees model least-cost network design: laying cables, pipelines, or roads to connect sites. They are also used in cluster analysis, image segmentation, approximation algorithms for the travelling salesman problem, and network protocol design (the spanning tree protocol is named after the concept).
