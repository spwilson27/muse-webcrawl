Cycle (graph theory)


A cycle graph (placeholder image)

In graph theory, a cycle in a graph is a non-empty trail in which the first and last vertices are equal, and (in the common "simple cycle" sense) no other vertices are repeated. A graph containing at least one cycle is called cyclic; a graph with no cycles is acyclic — a forest if undirected, and a directed acyclic graph (DAG) if directed.

Definitions and related concepts

The length of the shortest cycle in a graph is its girth; the length of the longest is its circumference. A cycle with no chords is an induced cycle or "hole." Special cases include the cycle graph Cn, consisting of a single cycle of n vertices, and Hamiltonian cycles, which visit every vertex exactly once. Cycles underpin concepts such as the cycle space, cyclomatic number, and feedback arc sets, and detecting cycles is fundamental in algorithms, for example in topological sorting and deadlock detection.
