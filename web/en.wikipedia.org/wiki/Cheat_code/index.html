Cheat code

A cheat code is a method of modifying the behaviour of a video game beyond its normal rules, usually entered by the player through a sequence of button presses, a typed word or phrase, or a menu option, and typically implemented by the game's developers. Cheat codes can grant invincibility ("god mode"), extra lives, weapons, resources, level skips or access to hidden content.

History

Developers originally included cheat codes as testing tools, allowing them to skip levels and check game functions quickly, and many were left in the released games and discovered by players. The most famous cheat code is the Konami Code (↑↑↓↓←→←→BA), created by Kazuhisa Hashimoto for the NES version of Gradius (1986) and popularised by Contra (1988), where it granted thirty lives. Magazines and strategy guides of the 1980s and 1990s traded heavily in cheat codes, and devices such as the Game Genie and GameShark allowed players to modify game memory directly.

Modern usage

With the rise of online multiplayer games, where cheating gives an unfair advantage over others, built-in cheat codes have largely disappeared from competitive titles and are now more often found in single-player games, sandbox modes and developer consoles. Anti-cheat software is used to detect unauthorised modifications in online play. Some games keep the tradition alive with playful codes, unlockable modes and console commands.
