Kleene algebra

From Wikipedia, the free encyclopedia

In mathematics, a Kleene algebra (named after Stephen Cole Kleene) is an idempotent semiring endowed with a closure operator, the Kleene star. It generalises the operations known from regular expressions and provides the algebraic theory underlying regular languages, automata theory, and program semantics.

Definition

A Kleene algebra is a set K with two binary operations + : K × K → K and · : K × K → K, and two constants 0 and 1, such that (K, +, ·, 0, 1) forms an idempotent semiring (addition is idempotent: a + a = a), together with a unary operation * : K → K (star) satisfying:

  • 1 + a·a* ≤ a* and 1 + a*·a ≤ a*
  • a·x ≤ x implies a*·x ≤ x, and x·a ≤ x implies x·a* ≤ x

where ≤ is the natural order of the idempotent semiring, a ≤ b iff a + b = b. These axioms make * behave as reflexive transitive closure.

Examples

The standard model is the set of regular expressions over an alphabet, modulo the usual equivalences, with + as choice, · as concatenation, and * as repetition. Other models include the algebra of regular languages, the algebra of binary relations on a set with union, composition, and reflexive transitive closure, and the tropical semiring with its closure — in which the star computes shortest paths in a weighted graph, making Kleene algebra useful in routing algorithms and dynamic programming formulations.

History and applications

The axioms were distilled by Dexter Kozen in the early 1990s, building on work by Kleene (1956) on regular events and by John Horton Conway on regular algebra. Kozen proved that the equational theory of Kleene algebra is complete for regular-expression equivalence. Kleene algebras and their extension with tests (Kleene algebra with tests, KAT) are used in program analysis, compiler verification, and network programming languages such as NetKAT.
