MOD (file format)

MOD is a computer file format used primarily to represent music, and was the first module file format. MOD files use the ".MOD" file extension, except on the Amiga where the original trackers used a "mod." prefix convention, such as "mod.echoing". A MOD file contains a set of instruments in the form of samples, a number of patterns indicating how and when the samples are to be played, and a list of what patterns to play in what order.

History

The first version of the format was created by Karsten "Obi" Obarski for use in the Ultimate Soundtracker, a tracker program released for the Amiga computer in 1987. The format has since become supported by hundreds of playback programs for the Amiga as well as other platforms, and by modern tracker programs such as MilkyTracker, OpenMPT and Renoise.

Dozens of similar module formats were derived from the original MOD format, including Scream Tracker's .S3M, Fast Tracker's .XM and Impulse Tracker's .IT. These variants extended the original format with new effects, more channels, compressed samples and other features.

Characteristics

A pattern is represented in a graphical user interface as a table with one column per (physical) channel, into which the playback of notes and effects is inserted. A MOD file by default has four channels and 64 rows per pattern. Effects include volume changes, pitch slides (portamento), vibrato, arpeggio, sample offset, retriggering and pattern breaks.

Unlike rendered audio formats such as MP3, a MOD file stores the actual sample data together with the sequencing instructions, so files remain small while playback quality depends on the player's resampling.

Timing

In the original MOD format, the minimal time frame was one "tick", traditionally corresponding to 1/50 of a second (PAL) or 1/60 (NTSC); the speed of a tune is described by a tempo setting expressed either in ticks per row or, in later variants, in beats per minute.
