Code-division multiple access (CDMA) is a channel access method used by radio communication technologies in which several transmitters can send information simultaneously over a single communication channel. Each user is assigned a distinct code, and the signal is spread over a wide frequency band using that code; a receiver knowing the code can recover its intended signal while treating all others as noise. CDMA is an example of multiple access and of spread spectrum communication.

Principle

In direct-sequence CDMA, each data bit is multiplied by a high-rate sequence of "chips" unique to the user. Because the codes are designed to have low cross-correlation, correlating the received mixture with one user's code reinforces that user's signal and suppresses the rest — provided the powers of the arriving signals are comparable. This makes tight power control essential: a nearby transmitter would otherwise drown out distant ones, the so-called near–far problem.

History and applications

Spread-spectrum techniques originated in military communications, valued for resistance to jamming and interception. Qualcomm commercialised CDMA for cellular telephony in the IS-95 standard (marketed as cdmaOne) in the 1990s, followed by CDMA2000. A wideband form, W-CDMA, became the radio interface of the UMTS third-generation standard used by much of the world. CDMA is also fundamental to satellite navigation: GPS satellites all broadcast on the same frequencies, distinguished only by their codes.

Advantages and limits

CDMA allows every cell in a network to reuse the same frequencies, gives a "soft capacity" that degrades gracefully as users are added, and supports soft handover between base stations. Its disadvantages include complex power control and receiver design. Later cellular generations (LTE and 5G NR) moved to OFDMA-based schemes, but CDMA remains in service in navigation, military and legacy cellular systems.
