Template (word processing)

A template is a pre-formatted file created by a word processor or document processing program that serves as a starting point for a new document. When a template is opened in software such as Microsoft Word, LibreOffice Writer, or Google Docs, a copy of the file is created in which common elements — such as page layout, styles, fonts, boilerplate text, and placeholder content — are already present, so the user can simply fill in the variable parts.

Characteristics

Templates typically contain predefined paragraph and character styles, headers and footers, page numbers, tables, and placeholders marked with generic text (for example, "Click here to enter title"). They are used for letters, resumes, reports, invoices, newsletters, and academic papers, where a consistent format is required across many documents.

History

The concept derives from boilerplate text used in printing and law. Word processors popularised templates in the 1980s and 1990s; Microsoft Word's Normal.dot global template became the default basis for new documents, and most programs now ship libraries of downloadable templates covering common document types.
