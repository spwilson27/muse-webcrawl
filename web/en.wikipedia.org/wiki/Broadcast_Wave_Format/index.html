Broadcast Wave Format

Filename extension.wav, .bwf
Developed byEuropean Broadcasting Union (EBU)
Initial release1997
StandardEBU Tech 3285
TypeAudio file format (extension of Microsoft WAV/RIFF)

Broadcast Wave Format (BWF) is a file format for audio data used in professional broadcasting and audio production. It is an extension of Microsoft's WAV (RIFF) format, specified by the European Broadcasting Union in 1997 (EBU Tech 3285), and adds a "Broadcast Extension" chunk (<bext>) containing metadata such as a description, originator, reference code, date and time, and — most importantly — a time reference (timecode) giving the position of the first sample relative to midnight, so that recordings made on different devices can be synchronised in editing systems.

Features and versions

Subsequent versions of the specification added support for higher resolutions and sample rates, multichannel audio and loudness metadata. Version 2 (2011) incorporated the EBU R 128 loudness parameters and a unique material identifier (UMID). Because a BWF file is a valid WAV file, it can be played by ordinary WAV software, which ignores the extra chunks. BWF is widely supported by digital audio workstations, field recorders and playout systems, and is recommended as an archival format for audio by library and archive bodies.

Related formats

The RF64 extension (EBU Tech 3306) overcomes the 4 GB size limit of RIFF files for long multichannel recordings, while the AES31 and iXML standards provide related metadata schemes used in film and television sound production. In North America, BWF is standardised similarly by the AES. BWF files conventionally carry the ordinary .wav extension, though .bwf is also seen.
