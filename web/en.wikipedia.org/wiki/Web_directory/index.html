Web directory

A web directory or link directory is an online list or catalog of websites. That is, it is a directory on the World Wide Web of (all or part of) the World Wide Web. Historically, directories typically listed entries on topics in categories and subcategories. In the early days of the web, directories were a primary means of discovering content, before the rise of algorithmic search engines.

History

The first web directory was the World Wide Web Virtual Library, created by Tim Berners-Lee in 1991. Yahoo! Directory, launched in 1994 as "Jerry and David's Guide to the World Wide Web", became the most famous example, employing human editors to review and categorize submissions. The Open Directory Project (DMOZ), founded in 1998, used a large community of volunteer editors and supplied directory data to many search engines. As crawler-based search engines such as Google improved, the importance of directories declined; Yahoo! closed its directory in 2014 and DMOZ shut down in 2017.

Types

Web directories vary in scope and editorial policy. General directories accept sites on any topic, while niche directories focus on a single subject area or region. Some directories are edited by staff, others by volunteers, and some accept paid submissions with or without editorial review. Directories differ from search engines in that their listings are typically organized by category and selected by humans rather than indexed automatically by crawlers.
