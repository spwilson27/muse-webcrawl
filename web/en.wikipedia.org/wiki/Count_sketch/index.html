Count sketch

Count sketch is a type of dimensionality reduction used in the streaming algorithm model, introduced by Moses Charikar, Kevin Chen and Martin Farach-Colton in 2002. It estimates the frequency moments of a data stream using a small sketch and pairwise independent hash functions.

Method

Unlike the related count–min sketch, count sketch assigns each item a random sign of +1 or −1 as well as a bucket, so errors can cancel; the estimate for an item is the median over several rows of the signed counter values. This yields unbiased estimates and allows recovery of the most frequent ("heavy hitter") items.
