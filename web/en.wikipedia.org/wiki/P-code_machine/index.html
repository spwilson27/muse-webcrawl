P-code machine


Type: stack-based virtual machine / intermediate language.

In computer programming, a p-code machine (portable code machine) is a virtual machine designed to execute p-code, an assembly-like intermediate language generated by compilers. The best-known implementation is the p-code of the UCSD Pascal system of the late 1970s, which allowed the same compiled program to run on many different microcomputers.

Design

A p-code machine is typically a stack machine: instructions push operands onto an evaluation stack, pop them for arithmetic and logical operations, and transfer results to memory. The architecture also defines registers pointing to the stack, heap, and constant pool. Because the instruction set is compact and machine-independent, a compiler targets p-code once, and a small interpreter written for each host machine provides portability.

History

The concept grew out of work on portable Pascal compilers at ETH Zürich around Niklaus Wirth's group, where a hypothetical "P-machine" served as the target of the Pascal-P compiler. The University of California, San Diego (UCSD) p-System turned the idea into a complete, commercially distributed operating system and development environment, running on the Apple II, IBM PC, and many other platforms. The idea anticipates later portable bytecode systems such as the Java virtual machine.

Other uses

The term "p-code" has also been applied to other intermediate representations, including the compiled form of MATLAB scripts and the pseudocode produced by reverse-engineering tools.
