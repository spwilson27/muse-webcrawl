Algorithmic probability

Algorithmic probability is a mathematical method of assigning a prior probability to a given observation, based on the idea that simpler explanations should be more probable. It was developed in the 1960s by Ray Solomonoff, the founder of algorithmic information theory, and forms the theoretical basis of Solomonoff induction.

Principle

Given a fixed universal Turing machine U, the algorithmic probability of an output string x is defined as the sum, over all programs p that produce x when run on U, of 2−|p| — that is, each program of length L bits contributes a weight of 2−L. Shorter programs therefore contribute far more than longer ones, formalising Occam's razor: the probability of an observation is dominated by the shortest program that generates it.

Solomonoff induction

Solomonoff induction uses algorithmic probability as a universal prior for sequence prediction. It is provably optimal in a certain formal sense — its predictions converge to the true distribution for any computable sequence — but it is incomputable in general, because determining whether an arbitrary program halts is undecidable. Practical approximations, such as Levin search and compression-based predictors, are used instead.

Related concepts

Algorithmic probability is closely related to Kolmogorov complexity, the length of the shortest program producing a given string, and to the minimum description length principle in statistics.
