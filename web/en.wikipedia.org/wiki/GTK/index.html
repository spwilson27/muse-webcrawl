GTK

GTK (formerly GIMP ToolKit and GTK+) is a free and open-source cross-platform widget toolkit for creating graphical user interfaces (GUIs). It is licensed under the terms of the GNU Lesser General Public License, allowing both free and proprietary software to use it. GTK is a project of the GNOME Foundation and is the standard toolkit of the GNOME desktop environment.

GTK provides the widgets used by GNOME applications.

History

GTK was created for the GIMP image editor by Spencer Kimball, Peter Mattis, and Josh MacDonald, after dissatisfaction with the Motif toolkit. Released in 1997, it was adopted by the GNOME project as its foundation toolkit. GTK 2.0 (2002) added improved text rendering with Pango and Unicode support; GTK 3.0 (2011) introduced CSS-like theming and support for touch input; GTK 4.0 (2020) modernized rendering with Vulkan/OpenGL scene graphs and removed many deprecated APIs.

Design

GTK is written in C with an object system (GObject) provided by GLib. Language bindings exist for many languages, including Python (PyGObject), Rust, JavaScript (GJS), C++ (gtkmm), and Vala. Since GTK 4, rendering is done through GSK, which builds a scene graph rendered with Cairo, OpenGL, or Vulkan. The library includes widgets for windows, buttons, tree views, text editing, and since GTK 4, media playback and other modern controls.

Users

Beyond GNOME core applications, GTK is used by GIMP, Inkscape, and applications in the Xfce and LXDE desktop environments, among many others.
