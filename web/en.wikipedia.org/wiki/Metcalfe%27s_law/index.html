Metcalfe's law

Metcalfe's law states that the value of a telecommunications network is proportional to the square of the number of connected users of the system (n²). First proposed in 1980 by Robert Metcalfe in the context of Ethernet, the law reflects the fact that the number of possible connections in a network grows quadratically with the number of nodes.

Explanation

For a network of n nodes, the number of unique two-way connections is n(n − 1)/2, which is approximately n²/2 for large n. Metcalfe's reasoning was that the cost of a network grows linearly with its size while its value grows with the square — so networks become dramatically more valuable as they grow, explaining the power of network effects in technologies from telephones to social media.

Criticism and alternatives

Critics note that not all connections are equally valuable, and alternative formulations such as Reed's law (value proportional to 2ⁿ for group-forming networks) and more conservative n·log n models have been proposed. Metcalfe later used Facebook data to argue that the law fitted observed network valuations reasonably well.
