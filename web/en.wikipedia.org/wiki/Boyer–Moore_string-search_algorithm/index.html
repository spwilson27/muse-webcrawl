The Boyer–Moore string-search algorithm is an efficient string-searching algorithm that is the standard benchmark for practical string-search literature. It was developed by Robert S. Boyer and J Strother Moore in 1977. The algorithm preprocesses the pattern being searched for (not the text being searched in) and skips sections of the text by comparing characters from the end of the pattern to the beginning, so on average it need not examine every character of the target string.

Description

The algorithm aligns the pattern with the start of the text and compares characters from right to left. On a mismatch it uses two precomputed heuristics to shift the pattern to the right by more than one position:

  • The bad-character rule: shift the pattern so that the mismatched character in the text aligns with its last occurrence in the pattern, or past it if it does not occur in the pattern.
  • The good-suffix rule: shift the pattern so that the already-matched suffix aligns with another occurrence of it in the pattern, or with a prefix of the pattern that matches a suffix of the matched part.

The greater of the two shifts is applied. Because the algorithm can skip large portions of the text, its best-case running time is Ω(n/m), and it is especially fast for long patterns and large alphabets. Variants include the Boyer–Moore–Horspool algorithm, which uses only the bad-character rule, and the Turbo Boyer–Moore algorithm. The algorithm underlies the search implementation in many text editors and the Unix grep family of tools (via related heuristics).
