Address Resolution Protocol

The Address Resolution Protocol (ARP) is a communication protocol used for discovering the link layer address, such as a MAC address, associated with a given internet layer address, typically an IPv4 address.

Operation

A host needing to send a packet on the local network broadcasts an ARP request asking who owns the target IP address; the owner replies unicast with its MAC address. Results are stored in an ARP cache. ARP was defined in RFC 826 (1982).

Scope and security

ARP operates within a single link and is not routed. It has no authentication, enabling ARP spoofing attacks used for man-in-the-middle interception; mitigations include static entries and dynamic ARP inspection. IPv6 replaces ARP with the Neighbor Discovery Protocol using ICMPv6.
