Binary search

From Wikipedia, the free encyclopedia

[Image: A sorted row of numbers being repeatedly halved to find a target value]

In computer science, binary search is an algorithm that finds the position of a target value in a sorted array by repeatedly halving the search interval: compare the target with the middle element, then discard the half that cannot contain it. It runs in O(log n) time — finding an item among a billion takes about 30 comparisons.

The idea is simple but its correct implementation is famously tricky: Jon Bentley reported that most professional programmers, given the task, produced versions with bugs — typically in the midpoint and boundary handling. Integer overflow in computing the midpoint even infected standard library implementations for years.

Requirements and variants

Binary search needs random access to sorted data; on linked lists it degenerates. Variants find the first or last occurrence of a value, or the point where a value would be inserted, and the same halving principle searches continuous ranges (bisection for solving equations).

The algorithm is the prototype of divide and conquer, alongside mergesort and the fast Fourier transform.
