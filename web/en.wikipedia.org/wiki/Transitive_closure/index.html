Transitive closure

In mathematics, the transitive closure of a homogeneous binary relation R on a set is the smallest transitive relation on the set that contains R. If R relates x to y and y to z, the transitive closure also relates x to z. For example, the transitive closure of the relation "is a parent of" is "is an ancestor of".

Graph formulation

For a directed graph, the transitive closure is the reachability relation: it contains an edge (or pair) u → v whenever there is a directed path from u to v. The closure can be computed with Warshall's algorithm in O(n³) time, or by running a graph search (DFS/BFS) from every vertex. The reflexive transitive closure adds self-loops for every vertex.

Logic and computer science

Transitive closure appears in database query languages — SQL:1999 added recursive queries (WITH RECURSIVE) partly to compute closures over hierarchies — and in logic programming (Datalog computes closures naturally). In formal language theory, the Kleene star is the transitive-closure-like operation on strings and languages. Propositional and first-order logic cannot express transitive closure in general, which motivates logics with a transitive-closure operator, such as FO(TC) and PSPACE-related fixpoint logics.
