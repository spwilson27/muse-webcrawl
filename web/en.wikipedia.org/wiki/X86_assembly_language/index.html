x86 assembly language

x86 assembly language
Family: Assembly language
Platform: x86 (8086 through x86-64)
Syntax styles: Intel syntax, AT&T syntax
Assemblers: MASM, NASM, GAS, FASM

x86 assembly language is the family of assembly languages for the x86 family of processors, which originated with the Intel 8086 in 1978 and grew through the 80386, Pentium, and the 64-bit x86-64 extension. Assembly language is a human-readable mnemonic representation of the machine code executed by the processor; an assembler translates it into binary instructions.

Syntax

Two syntax traditions exist. Intel syntax, used by MASM and NASM, writes the destination operand first: mov eax, ebx. AT&T syntax, used by the GNU Assembler, reverses the order and decorates register names with % and immediates with $. A classic "Hello, world" in 32-bit Linux Intel syntax begins:

section .text
global _start
_start:
    mov edx, len   ; message length
    mov ecx, msg   ; message
    mov ebx, 1     ; stdout
    mov eax, 4     ; sys_write
    int 0x80

Registers and instruction set

The architecture provides general-purpose registers (EAX, EBX, ECX, EDX, ESI, EDI, EBP, ESP in 32-bit mode; extended to RAX–R15 in 64-bit mode), segment registers, the instruction pointer, and a flags register recording arithmetic outcomes used by conditional jumps. Common instructions include MOV, ADD, SUB, CMP, JMP and the conditional jumps, CALL/RET, PUSH/POP for the stack, and string and SIMD instructions added over successive generations (MMX, SSE, AVX).

Uses

Although most software is now written in high-level languages, x86 assembly remains essential in operating system kernels, boot code, device drivers, reverse engineering, exploit development, performance-critical routines, and understanding compiler output.
