TypeCAD drawing format

DWG (from drawing) is a proprietary binary file format used for storing two- and three-dimensional design data and metadata. It is the native format of AutoCAD, first released by Autodesk in 1982, and one of the most widely used CAD formats in architecture, engineering and construction.

History and versions

The format has evolved through many versions (identified by codes such as AC1009 for Release 11/12 and AC1032 for AutoCAD 2018). Third-party tools and the Open Design Alliance's libraries provide interoperability, while Autodesk's RealDWG toolkit licenses official support. Autodesk has defended the format's trademark status in litigation and trademark disputes.

Contents

A DWG file stores vector geometry, layers, blocks, dimensions, raster image references and, in modern versions, parametric and 3D solid data. It is commonly exchanged alongside the ASCII-based DXF format, also created by Autodesk.
