Procmail

Procmail
Original author: Stephen R. van den Berg
Initial release: 1990
Type: Mail delivery agent / email filter

Procmail is a mail processing utility for Unix-like systems, first released in 1990 by Stephen R. van den Berg. It acts as a mail delivery agent and a flexible filter, allowing incoming email to be sorted into folders, forwarded, piped through other programs, or discarded according to user-defined rules.

Recipes

Procmail is configured through a file of "recipes" in ~/.procmailrc. Each recipe consists of condition lines, usually regular expressions matched against headers or body, and an action, such as delivering to a particular mailbox. This made it a popular tool for early spam filtering and mailing-list sorting.

Status

Procmail was a standard component of many Unix and Linux installations and was long used as the default local delivery agent on some systems. Development ceased in the early 2000s, and the software is now considered unmaintained; administrators are generally advised to use alternatives such as maildrop or Sieve-based filtering.
