Logic programming

Logic programming is a programming paradigm which is based largely on formal logic. Any program written in a logic programming language is a set of sentences in logical form, expressing facts and rules about some problem domain. Major logic programming language families include Prolog, Answer Set Programming (ASP) and Datalog. In all of these languages, rules are written in the form of clauses:

H :- B1, ..., Bn.

and are read declaratively as logical implications:

H if B1 and ... and Bn.

H is called the head of the rule and B1, ..., Bn is called the body. Facts are rules that have no body, and are written in the simplified form:

H.

In the simplest case in which H, B1, ..., Bn are all atomic formulae, these clauses are called definite clauses or Horn clauses. However, there are many extensions of this simple case, the most important of which is the case in which the condition of a clause can also be the negation of atomic formulae, as in:

H :- B1, ..., Bn, not C1, ..., not Cm.

History

The use of mathematical logic to represent and execute computer programs is also a feature of the lambda calculus, developed by Alonzo Church in the 1930s. However, the first proposal that the clausal form of logic should be used to represent computer programs was by Cordell Green. The use of the Horn clausal form of logic as a proposed basis for a programming language was first proposed by Robert Kowalski in collaboration with Alain Colmerauer in Marseille. This led to the development of Prolog, first implemented in 1972.

Logic programming can be viewed as controlled deduction. An important concept in logic programming is the separation of programs into a logic component and a control component. With pure logic programming languages, the logic component alone determines the solutions produced. The control component can be varied to provide alternative ways of executing a logic program.

Concepts

Logic variables

Unlike other programming languages, in a logic language logical variables do not denote a location in memory but a logical relationship between data values.

Backtracking

Most logic programming systems provide a means of searching for solutions by backtracking: when a goal fails, the system returns to an earlier choice point and tries an alternative.

Languages and implementations

  • Prolog — the best-known logic programming language
  • Datalog — a declarative subset oriented toward databases
  • Answer set programming — for combinatorial search problems
  • Mercury — a strongly typed logic/functional language
