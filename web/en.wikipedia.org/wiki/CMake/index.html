CMake

CMake
Developer: Kitware
Initial release: 2000
Written in: C++
License: BSD-3-Clause

CMake is a free, cross-platform software tool for managing the build process of software using a compiler-independent method. Rather than building code directly, CMake generates native build files — such as Makefiles, Ninja files, or Visual Studio and Xcode projects — from script files called CMakeLists.txt.

History

CMake was created in 1999–2000 by Kitware for the Insight Segmentation and Registration Toolkit (ITK), funded by the US National Library of Medicine as part of the Visible Human Project. Lead developer Bill Hoffman designed it to be simpler than the Unix configure/make toolchain.

Features

CMake supports hierarchical directory builds, dependency analysis, in-source and out-of-source builds, caching of configuration, and companion tools CTest (testing) and CPack (packaging). It became the de facto standard build system generator for C and C++ projects, used by KDE, Blender, MySQL and many others.
