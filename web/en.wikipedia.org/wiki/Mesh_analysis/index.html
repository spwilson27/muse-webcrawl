Mesh analysis

From Wikipedia, the free encyclopedia

Mesh analysis (or the mesh current method) is a circuit analysis method for planar circuits. Mesh analysis is usually used when a circuit contains no current sources, or when current sources can be converted into voltage sources using source transformation. The method finds the mesh currents that flow around each mesh (window pane) of a planar circuit graph, after which all branch currents and voltages follow from Ohm's law and Kirchhoff's laws.

The technique is a specialization of the more general nodal analysis and is related to Kirchhoff's circuit laws. It is most effective when the circuit has more nodes than meshes, in which case fewer simultaneous equations are needed than with nodal analysis.

Basic concepts

A mesh is a loop in a planar circuit that contains no other loops inside it. Each mesh is assigned a fictitious mesh current, conventionally taken to circulate clockwise. A branch shared by two meshes carries a current equal to the algebraic sum (difference, if the mesh currents circulate in the same rotational sense) of the two mesh currents; a branch belonging to only one mesh carries that mesh current alone.

Applying Kirchhoff's voltage law (KVL) around each mesh yields one linear equation per mesh. For a circuit with m meshes the equations form an m × m system that can be written in matrix form as R i = v, where R is the mesh resistance matrix, i the vector of mesh currents, and v the vector of net voltage sources in each mesh.

Procedure

  1. Draw the circuit as a planar graph and identify each mesh.
  2. Assign a clockwise mesh current to each mesh.
  3. For each mesh, write KVL: the sum of resistance-times-current terms around the mesh equals the sum of voltage source rises in the direction of the mesh current. Self-resistance terms (the sum of all resistances in the mesh) multiply the mesh's own current; mutual-resistance terms (shared resistances, taken negative) multiply the neighbouring mesh currents.
  4. Solve the simultaneous equations, typically with Gaussian elimination or matrix inversion.
  5. Compute each branch current as the algebraic sum of the mesh currents passing through it, then find voltages with Ohm's law.

Supermesh

When a current source lies on the perimeter of a mesh or is shared between two meshes, the voltage across it is unknown, so ordinary KVL cannot be written directly. The meshes sharing the current source are then combined into a supermesh, and a constraint equation relating the two mesh currents to the current source is added. Alternatively, a current source on the outside of the circuit fixes one mesh current outright.

Planarity limitation

Mesh analysis in its elementary form applies only to planar circuits — circuits that can be drawn on a plane without crossing branches. Non-planar circuits are handled with the more general loop analysis (tree and link method) or with nodal analysis.
