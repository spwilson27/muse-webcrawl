Haswell (microarchitecture)

Haswell is the codename for the fourth-generation Intel Core processor microarchitecture, released in June 2013 as the successor to Ivy Bridge. Manufactured on a 22 nm process, Haswell formed the "architecture" step of Intel's tick–tock model and was sold as the 4th generation Core i3, i5 and i7 processors, as well as in Xeon, Pentium and Celeron lines. A refresh, Haswell Refresh, and the Broadwell shrink followed.

Features

Haswell widened the out-of-order core with additional execution ports, larger buffers and improved branch prediction. It introduced the AVX2 instruction set, expanding most 128-bit integer SIMD operations to 256 bits, along with FMA3 fused multiply–add and the BMI1/BMI2 bit-manipulation instructions. The integrated graphics were reworked into Iris and Iris Pro variants, the latter with up to 128 MB of embedded DRAM (eDRAM) on some models.

Power management

A major design goal was lower power for ultrabooks and tablets: Haswell introduced deeper package C-states (down to C10) and new active-idle S0ix states borrowed from the Atom line, greatly reducing idle power consumption. Desktop parts used the LGA 1150 socket, while high-end desktop and server parts (Haswell-E/EP) used LGA 2011-v3 with DDR4 memory support.

Transactional memory erratum

Haswell launched with hardware transactional memory (TSX), but in August 2014 Intel disclosed an erratum that could cause system hangs, and TSX was disabled on affected steppings via microcode updates; it returned in later products.
