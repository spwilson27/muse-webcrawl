Preorder

From Wikipedia, the free encyclopedia

In mathematics, especially in order theory, a preorder or quasiorder is a binary relation that is reflexive and transitive. The name preorder is meant to suggest that preorders are almost partial orders, but not quite, because they are not necessarily antisymmetric: elements a and b may satisfy a ≤ b and b ≤ a without being equal.

Definition

Let ≤ be a binary relation on a set P. Then ≤ is a preorder if it is reflexive (a ≤ a for all a) and transitive (if a ≤ b and b ≤ c then a ≤ c). A set equipped with a preorder is called a preordered set.

Examples and constructions

Every directed graph generates a preorder by reachability: there is an edge-path from a to b. Divisibility on the integers (ignoring sign) is a preorder that is not antisymmetric. From any preorder one obtains a partial order by identifying equivalent elements: define a ~ b when a ≤ b and b ≤ a; the quotient set then carries a partial order. Categories in which each hom-set has at most one morphism are exactly preorders, and topological spaces can be described via the specialisation preorder.

Related notions

A preorder that is antisymmetric is a partial order; a preorder in which every pair is comparable is a total preorder (such as a ranking with ties). The term also appears in computer science for preorder tree traversal, a different usage.
