The Message Passing Interface (MPI) is a standardised and portable message-passing standard designed to function on parallel computing architectures, especially distributed-memory systems such as clusters and supercomputers. The MPI standard defines the syntax and semantics of library routines useful to a wide range of users writing portable message-passing programs in C, C++ and Fortran.

Design

An MPI program consists of multiple processes, each identified by a rank within a communicator (by default MPI_COMM_WORLD). Processes communicate by explicitly sending and receiving messages: point-to-point routines such as MPI_Send and MPI_Recv, and collective operations such as MPI_Bcast (broadcast), MPI_Reduce, MPI_Allreduce, MPI_Gather and MPI_Barrier. Later versions of the standard added one-sided (remote memory access) communication, parallel I/O, dynamic process management and support for large counts and GPU-aware communication.

History

MPI grew out of a workshop process begun in 1992 by the parallel computing community, which needed to reconcile a proliferation of incompatible vendor message-passing libraries. The MPI Forum published MPI-1 in 1994, MPI-2 in 1997, MPI-3 in 2012 and MPI-4.0 in June 2021. Open-source implementations such as MPICH and Open MPI, together with vendor-tuned versions, made MPI the de facto standard for high-performance computing; virtually all of the world's fastest supercomputers run MPI programs, often combined with OpenMP for shared-memory parallelism within each node.
