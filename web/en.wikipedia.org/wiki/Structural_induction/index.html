Structural induction

Structural induction is a proof method in mathematics and computer science used to prove that all terms of a certain recursively defined structure satisfy some property. It is a generalisation of mathematical induction from the natural numbers to arbitrary inductively defined sets, such as lists, trees, formulas of a formal language, and abstract syntax trees.

Principle

To prove that every element of an inductively defined set has property P, one shows: (1) every base case (minimal element, given without reference to the set) has property P; and (2) for each constructor that builds new elements from existing ones, if the components have property P, then the constructed element also has property P. The induction hypothesis may then be used for the components. The method is valid because the underlying ordering — the subterm relation — is well-founded.

Example

For lists, one proves P for the empty list and shows that if P holds for a list xs, then it holds for x : xs (the list with head x). A classic result proved this way is that reversing a list twice returns the original list.

Relation to other principles

Structural induction is a special case of well-founded induction, and is the proof-theoretic counterpart of structural recursion, the pattern of defining functions by recursion on the structure of their arguments. It is foundational in programming-language semantics and in proof assistants such as Coq and Isabelle, where inductive types generate induction principles automatically.
