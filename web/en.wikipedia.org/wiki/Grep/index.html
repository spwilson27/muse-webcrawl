grep is a command-line utility for searching plain-text data sets for lines that match a regular expression. It was originally developed for the Unix operating system by Ken Thompson, building on the g/re/p command sequence of the ed text editor — "globally search for a regular expression and print matching lines" — from which its name derives. It first appeared publicly in Version 4 Unix (1973–74) and is now standard on Unix-like systems and widely available elsewhere.

Usage

In its basic form, grep pattern file prints every line of file containing a match for pattern; it is often used in pipelines to filter the output of other commands. Common options include -i (ignore case), -v (invert the match), -r (search directories recursively), -n (show line numbers) and -c (count matches). Variants include egrep (extended regular expressions, now grep -E) and fgrep (fixed strings, grep -F).

Influence

grep's name has entered general computing vocabulary as a verb ("to grep a file"), and its design inspired search features in countless tools and editors, as well as modern fast search programs such as ack, ag (the Silver Searcher) and ripgrep. The GNU implementation, GNU grep, is the default on Linux systems.
