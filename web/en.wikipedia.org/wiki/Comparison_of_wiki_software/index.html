Comparison of wiki software

This article compares notable wiki software applications — systems that allow collaborative creation and editing of interlinked web pages through a browser. The first wiki, WikiWikiWeb, was created by Ward Cunningham in 1995; the best-known engine is MediaWiki, which powers Wikipedia.

Features compared

Engines differ in their editing syntax (Wikitext, Markdown, WYSIWYG), storage backends (relational database vs. flat files), access control granularity, plugin ecosystems, and support for features such as full-text search, revision history, file attachments, and multilingual content. MediaWiki favours a custom markup and database storage; DokuWiki emphasises simplicity and file-based storage; commercial products such as Confluence integrate with corporate identity and project-management tools.
