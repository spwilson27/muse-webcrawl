PipeWire is a framework for handling audio, video streams, and hardware devices on Linux. It was created by Wim Taymans at Red Hat as a unified replacement for the separate audio and video servers then in use, providing compatibility layers for PulseAudio, JACK, and ALSA clients as well as capture for Wayland screen sharing.

History

Development began around 2015 under the name PulseVideo, intended to provide secure video capture for sandboxed (Flatpak) applications. Renamed PipeWire in 2017, the project expanded in scope to professional and consumer audio. Fedora 34 (2021) was the first major distribution to install PipeWire by default for audio; Ubuntu, Debian and Arch Linux followed, and by the mid-2020s PipeWire was the default audio/video server in most mainstream Linux distributions.

Design

PipeWire is built around a graph of nodes that process data streams with very low latency, in real time when needed. A session manager — the reference implementation is WirePlumber — sets policy for routing and device priorities. The compatibility layers let existing PulseAudio and JACK applications work unmodified, allowing professional low-latency audio and desktop audio to be handled by a single server.

Features

  • Low-latency audio and video routing suitable for pro audio
  • Drop-in replacement for PulseAudio and JACK servers
  • Secure screen capture and camera access for Wayland and flatpacked apps
  • Bluetooth audio support (A2DP, HFP, LE Audio)
  • Plugin architecture including effect chains (via the filter-chain module and tools such as EasyEffects)
