Weierstrass function

From Wikipedia, the free encyclopedia

In mathematics, the Weierstrass function is an example of a real-valued function that is continuous everywhere but differentiable nowhere. It is named after its discoverer Karl Weierstrass.

The Weierstrass function has historically served the role of a pathological function, being the first published example (1872) specifically concocted to challenge the notion that every continuous function is differentiable except on a set of isolated points. Weierstrass's demonstration that continuity did not imply almost-everywhere differentiability upended many assumptions about calculus that relied on geometric intuition and smoothness.

Construction

In Weierstrass's original paper, the function was defined as a Fourier series:

f(x) = Σn=0∞ an cos(bn πx),

where 0 < a < 1, b is a positive odd integer, and ab > 1 + 3π/2. The minimum value of b for which this is true is b = 7. This construction, along with the proof that the function is not differentiable at any point, was first presented by Weierstrass in a lecture to the Prussian Academy of Sciences on 18 July 1872.

Despite never being differentiable, the function is continuous: the series converges uniformly by the Weierstrass M-test, since each term an cos(bn πx) is bounded by an and Σan converges.

Behaviour and fractality

The function is an example of a fractal curve. Zooming in on any portion of the graph reveals further oscillations at every scale: the function is self-similar in structure, so no magnification ever smooths it out. Its graph has a Hausdorff dimension greater than 1, specifically 2 + logb a under the standard parameter conditions.

Density of nowhere-differentiable functions

It turns out that the Weierstrass function is far from being an isolated anomaly: although it might seem "pathological", it is in fact "typical" of continuous functions. In the space of all continuous functions on an interval equipped with the topology of uniform convergence, the set of functions differentiable at even a single point forms a meagre set, a result first proved by Stefan Banach in 1931. Thus nowhere-differentiable functions are, in the sense of Baire category, the norm rather than the exception.
