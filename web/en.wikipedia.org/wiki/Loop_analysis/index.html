Loop analysis, more commonly called mesh analysis (or the mesh-current method), is a technique used to solve planar electrical circuits for the currents (and indirectly the voltages) at any place in the circuit. It applies Kirchhoff's voltage law (KVL) — the principle that the sum of voltages around any closed loop is zero — systematically to each "mesh", a loop in the circuit graph that contains no other loops within it.

Method

The analyst assigns a mesh current to each mesh of the circuit, conventionally flowing clockwise. For each component, the voltage is expressed in terms of the mesh currents that pass through it; components shared between two meshes carry the difference of the two mesh currents. Writing KVL for every mesh produces a system of simultaneous linear equations, which can be solved for the mesh currents. Once these are known, the current and voltage for any element follow directly.

Special cases simplify the analysis: a current source on the perimeter of the circuit fixes its mesh current directly, while a current source shared between two meshes is handled by forming a "supermesh" combining both.

Comparison with nodal analysis

Mesh analysis is the dual of nodal analysis, which applies Kirchhoff's current law at the circuit's nodes. Mesh analysis is convenient when a circuit has fewer meshes than nodes and is limited to planar circuits — those that can be drawn without crossing branches — whereas nodal analysis applies to any topology.
