TLA+

TLA+ is a formal specification language developed by Leslie Lamport at Microsoft Research. It is used for designing, modelling, documenting, and verifying programs, especially concurrent systems and distributed systems. TLA+ is an acronym for the Temporal Logic of Actions, the logic on which the language is based; the "+" denotes the set theory and first-order logic added to it.

Overview

A TLA+ specification describes a system as a set of possible behaviours: sequences of states. Variables represent the system state; an Init formula characterises the initial states and a Next formula, written in terms of primed variables, describes each allowed step. Specifications are written largely as ordinary mathematics — set theory, functions, records and tuples — rather than as code, which allows them to describe a design at a high level of abstraction, above implementation detail.

Tools for TLA+ include the TLC model checker, which exhaustively explores the reachable states of a finite model to check invariants and temporal properties; TLAPS, a proof system for machine-checked deductive proofs; and the PlusCal algorithm language, which resembles pseudocode and translates into TLA+. Specifications are edited with the TLA+ Toolbox IDE or editor extensions.

Use

TLA+ has been used extensively at Amazon Web Services, where engineers have applied it to systems such as S3, DynamoDB and EC2, reporting that it found design bugs that testing had missed; it has also been used at Microsoft, Intel and other companies, and for specifying protocols including Paxos, which Lamport himself described in TLA+. Lamport's book Specifying Systems (2002) is the standard reference, and he advocates "thinking above the code" — writing a precise specification before implementation.
