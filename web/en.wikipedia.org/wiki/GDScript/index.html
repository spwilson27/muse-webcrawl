GDScript

GDScript is a high-level, dynamically typed programming language created for the Godot game engine. Its syntax is deliberately modelled on Python, with indentation-based blocks, while adding features tailored to game development such as built-in vector and matrix types, signals, and first-class integration with Godot's node and scene system. GDScript files use the .gd extension.

Design

GDScript was created after earlier experiments with embedding Lua and a custom language in the Godot engine showed the need for a scripting language tightly bound to the engine's types. Scripts attach to nodes in a scene tree and extend engine classes; the language exposes lifecycle callbacks such as _ready() and _process(delta) for per-frame logic. Since Godot 3, GDScript supports optional static typing with type inference, and Godot 4 (2023) substantially rewrote the language — adding lambdas, typed arrays and dictionaries improvements, first-class functions, and pattern matching refinements — while keeping its Python-like surface.

Features

The language includes coroutines via await, a signal system for decoupled communication between objects, properties with getters and setters, inner classes, and annotations (prefixed with @) that configure exported variables and tool behaviour in the editor. Because it compiles to bytecode executed by a dedicated virtual machine, GDScript trades raw performance for rapid iteration and hot-reloading inside the editor.

Usage

GDScript is the primary scripting language recommended for Godot projects and is used in commercial and hobbyist games shipped on all major platforms; Godot additionally supports C# and, through GDExtension, C++ and other languages for performance-critical code.
