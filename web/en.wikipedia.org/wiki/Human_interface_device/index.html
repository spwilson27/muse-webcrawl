Human interface device

A human interface device (HID) is a type of computer device usually used by humans that takes input from or provides output to humans. The term "HID" most commonly refers to the USB-HID specification, a standard that allows devices such as keyboards, mice, and game controllers to be connected to a computer without installing custom drivers.

USB HID standard

The HID class was defined by the USB Implementers Forum in the late 1990s. HID devices describe themselves to the host computer using report descriptors, so a single generic driver can handle many different devices. The protocol supports keyboards, pointing devices, gamepads, joysticks, barcode scanners, and control surfaces.

Bluetooth HID

The HID profile was later adapted for Bluetooth, enabling wireless keyboards, mice, and remote controls. Bluetooth Low Energy introduced the HID over GATT profile (HOGP), widely used by modern wireless peripherals.
