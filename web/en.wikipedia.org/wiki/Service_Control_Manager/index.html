Service Control Manager

Service Control Manager
File: services.exe
Operating system: Microsoft Windows
Type: System component

The Service Control Manager (SCM; services.exe) is a component of Microsoft Windows that manages Windows services — long-running background processes that start at boot or on demand. It maintains the database of installed services in the registry and handles starting, stopping, and querying them.

Functions

The SCM is started early in the boot process by wininit.exe. It launches services configured for automatic startup, processes service control requests from applications and administrators, and notifies services of system events such as shutdown. Users interact with it through the Services snap-in (services.msc), the sc.exe command-line tool, or the ServiceController API in .NET.

Service states

Services may be stopped, start pending, running, paused, or in other states; the SCM tracks these transitions and enforces the access rights of service accounts.
