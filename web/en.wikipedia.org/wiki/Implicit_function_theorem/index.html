Implicit function theorem

Implicit function theorem
FieldMultivariable calculus, analysis
RelatedInverse function theorem

In multivariable calculus, the implicit function theorem is a result that gives sufficient conditions for a relation of the form F(x, y) = 0 — an implicit function — to define a variable as a function of the others in a neighbourhood of a point. Specifically, if F is continuously differentiable and the partial derivative of F with respect to y is non-zero at a point (a, b) with F(a, b) = 0, then near that point there is a unique differentiable function y = g(x) whose graph passes through (a, b) and satisfies F(x, g(x)) = 0, with derivative g′(x) = −(∂F/∂x) / (∂F/∂y).

Example

The unit circle x² + y² − 1 = 0 cannot be expressed globally as a single function y(x), but the theorem guarantees that near any point with y ≠ 0 the circle is locally the graph of a function (the upper or lower semicircle). Near (1, 0), where ∂F/∂y = 0, no such function exists — instead x is locally a function of y.

General form and applications

The theorem extends to systems: if the Jacobian matrix of partial derivatives with respect to the dependent variables is invertible at a point, the equations can be solved for those variables as functions of the remaining ones. It is closely related to the inverse function theorem and underlies the local description of manifolds, level sets, and solution sets of differential and equilibrium equations in economics and physics. The result in modern form goes back to the 19th-century work of Cauchy and others, with a rigorous proof developed by Ulisse Dini.
