The Common Language Runtime (CLR) is the virtual machine component of Microsoft's .NET framework and the implementation of the Common Language Infrastructure (CLI) standard. Programs written for the CLR are compiled to Common Intermediate Language (CIL) bytecode, stored in assemblies, and are executed as managed code.

Languages compile to CIL; the CLR's just-in-time compiler translates CIL to native code at runtime.

Functions

The CLR provides memory management through automatic garbage collection, a common type system (CTS) enabling cross-language interoperability, exception handling, thread management, remoting and interoperation with unmanaged code, and security features such as (historically) code access security and verification of type safety. A just-in-time (JIT) compiler converts CIL to machine code as methods are first called; newer versions add tiered compilation and ahead-of-time options.

Implementations

The original CLR shipped with .NET Framework for Windows from 2002. The cross-platform, open-source successor is the runtime of modern .NET (formerly .NET Core), with alternative implementations such as Mono (used by Xamarin and Unity). The CLR is frequently compared with the Java virtual machine; a key design difference is the CLR's first-class support for multiple languages and value types.
