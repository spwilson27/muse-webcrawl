Erlang (programming language)

Erlang is a general-purpose, concurrent, functional programming language developed at Ericsson for fault-tolerant, distributed telecommunications systems.

Erlang is a general-purpose, concurrent, functional programming language and a garbage-collected runtime system. It was designed by Joe Armstrong, Robert Virding and Mike Williams at the Swedish telecommunications company Ericsson in the mid-1980s to build soft-real-time, highly available telephone switching systems. The name is both a reference to the Danish mathematician Agner Krarup Erlang and an abbreviation of "Ericsson Language".

Design

Erlang programs are built from very large numbers of lightweight processes that share no memory and communicate by asynchronous message passing, following the actor model. Processes are cheap to create — a system may run millions of them — and are supervised in trees: when a process fails, a supervisor restarts it, embodying the "let it crash" philosophy rather than defensive error handling. Other hallmarks include single-assignment variables, pattern matching, dynamic typing, and hot code swapping, allowing software to be upgraded without stopping the system — vital for telephone switches that could never be taken offline.

OTP and the BEAM

Erlang code runs on the BEAM virtual machine, and the language ships with OTP (Open Telecom Platform), a set of middleware libraries and design principles — supervisors, gen_server behaviours, release handling — that codify decades of practice in building reliable distributed systems. The language was released as open source in 1998 after an internal Ericsson ban on its use prompted its creators to spread it outside the company.

Applications

Erlang powered Ericsson's AXD301 ATM switch, reported to achieve "nine nines" reliability. It underlies the ejabberd messaging server, the CouchDB and Riak databases, RabbitMQ, and the back ends of large messaging systems; WhatsApp famously scaled to millions of concurrent connections per server with a small team using Erlang. The language Elixir, created by José Valim, compiles to the BEAM and shares Erlang's runtime and OTP ecosystem.
