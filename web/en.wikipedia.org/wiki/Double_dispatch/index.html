Double dispatch

Double dispatch is a mechanism that dispatches a function call to different concrete functions depending on the runtime types of two objects involved in the call. In most object-oriented systems, the concrete function that is called from a message send depends only on the type of the receiver (single dispatch); double dispatch extends this so the choice also depends on the type of one argument.

Motivation

Double dispatch is useful where the behaviour of an operation depends on the combination of two types — for example, computing the intersection of two geometric shapes, rendering different element types in a document model, or resolving collisions between different kinds of game objects. It is the classic implementation technique behind the visitor pattern.

Example

A typical implementation passes this back into a method on the argument, so the second dispatch resolves the argument's actual type:

abstract class SpaceObject {
    abstract void CollideWith(SpaceObject other);
    abstract void CollideWithAsteroid(Asteroid asteroid);
    abstract void CollideWithSpaceship(Spaceship ship);
}
class Asteroid : SpaceObject {
    override void CollideWith(SpaceObject other) {
        other.CollideWithAsteroid(this);  // second dispatch
    }
    ...
}

The first virtual call selects the receiver's method; that method calls back a type-specific method on the argument, achieving dispatch on both runtime types.

Language support

Languages with multiple dispatch, such as Common Lisp (CLOS), Julia and Dylan, provide the mechanism directly. In single-dispatch languages like Java, C# and C++, double dispatch is simulated with the visitor pattern or with method overloading combined with virtual calls.
