Confidential computing is a security and privacy-enhancing technology that encrypts data while it is in use, isolating it inside a hardware-protected environment called a trusted execution environment (TEE). Confidential computing is positioned alongside the two established data-protection approaches — encryption at rest and encryption in transit — completing protection across the full data lifecycle. It is particularly important for processing sensitive data such as health records, financial data, and personally identifiable information in cloud environments where the operator itself may be untrusted.

Technology

TEEs use CPU extensions to create isolated regions of memory ("enclaves") that even the hypervisor, operating system, and cloud administrator cannot inspect or tamper with. Remote attestation lets a client verify, before sending data, that the enclave is genuine hardware running the expected code. Major implementations include Intel SGX, AMD Secure Encrypted Virtualization (SEV), and Arm Confidential Compute Architecture; AMD SEV-SNP and Intel TDX extend protection to entire virtual machines.

Applications

Use cases include confidential virtual machines, secure multi-party computation, private machine learning inference on sensitive models and data, key management, and analytics on encrypted datasets. In 2019 the Linux Foundation launched the Confidential Computing Consortium, whose members include major cloud vendors and hardware makers, to develop open standards and tooling.

Limitations

Confidential computing is not a panacea: side-channel attacks against shared hardware can sometimes leak information from enclaves, and correct attestation and configuration remain the operator's responsibility. It protects data in use, but not against flaws in the application code running inside the enclave.
