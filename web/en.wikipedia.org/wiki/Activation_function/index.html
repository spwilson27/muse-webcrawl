DomainArtificial neural networks / machine learning
PurposeMaps a neuron's weighted input sum to its output; introduces nonlinearity
Common functionsReLU, sigmoid, tanh, softmax, GELU, Swish

In artificial neural networks, an activation function is a function applied to the weighted sum of a neuron's inputs (plus bias) that determines the neuron's output. Activation functions introduce nonlinearity into the network; without them, a multilayer network would collapse into an equivalent single linear transformation and could not learn complex patterns.

Plots of common activation functions: sigmoid, hyperbolic tangent, and the rectified linear unit (ReLU).

Common functions

The sigmoid (logistic) function squashes inputs to (0, 1) and was historically standard, but suffers from vanishing gradients. The hyperbolic tangent maps to (−1, 1). The rectified linear unit (ReLU), f(x) = max(0, x), became the default for deep networks because of its simplicity and gradient behaviour; variants include Leaky ReLU, ELU, GELU and Swish/SiLU. Softmax is used in output layers for multiclass classification, converting logits into a probability distribution.

Properties

Desirable properties include nonlinearity, differentiability (for gradient-based training via backpropagation), computational cheapness and, in some cases, being zero-centred or non-saturating. The choice of activation function materially affects trainability, especially in deep architectures.
