Implicit data structure

In computer science, an implicit data structure is a data structure that stores data with no (or very little) auxiliary information beyond the data elements themselves — conventionally, with only O(1) extra space beyond the storage for the elements. The structure is implicit in the arrangement of the elements, usually in an array: the relationships between elements (such as parent and child in a tree) are determined by their positions, computed by arithmetic on their indices rather than stored as pointers.

Examples

The best-known example is the binary heap, which represents a complete binary tree in an array: for a node at index i, its children are at indices 2i and 2i+1 and its parent at index floor(i/2), so no pointers are needed at all. Other examples include:

  • Sorted arrays supporting search with binary search;
  • The implicit representation of a permutation and of permutation graphs;
  • Beap (bi-parental heap) structures;
  • Circular buffers and array-based deques with fixed capacity.

Properties

Because they store no per-element overhead, implicit data structures are extremely space-efficient and have excellent cache locality, which often makes them fast in practice. The trade-off is rigidity: many implicit structures have a fixed capacity or support only a restricted set of operations efficiently — insertion and deletion in a sorted array, for example, take linear time. Implicit data structures are closely related to, and an extreme case of, succinct data structures, which aim to use space close to the information-theoretic minimum while still supporting efficient queries.
