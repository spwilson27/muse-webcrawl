Vulkan

Vulkan is a low-overhead, cross-platform application programming interface (API) for high-performance 3D graphics and general-purpose computing on GPUs. It was first announced by the Khronos Group at GDC 2015 and released in February 2016. Vulkan is intended to offer higher performance and more explicit control over the GPU than its predecessors OpenGL and Direct3D 11, distributing work across multiple CPU cores and reducing driver overhead.

Design

Unlike OpenGL's state-machine model, Vulkan is object-based and explicit: applications themselves manage memory allocation, synchronisation, command buffers and pipelines, and can record commands in parallel from many threads. Shaders are normally compiled offline to the portable SPIR-V intermediate representation. The API's verbosity shifts work from the driver to the application, rewarding expert developers with predictable performance at the cost of substantially more code for simple tasks.

History

Vulkan began as an evolution of AMD's Mantle API, which AMD donated to Khronos as the basis of a vendor-neutral standard. Version 1.1 (2018) added subgroup operations and formalised multi-GPU and cross-API features; 1.2 (2020) integrated many extensions into core; 1.3 (2022) added dynamic rendering and other widely requested features, with a "roadmap" profile system to raise baseline capabilities. Vulkan SC (Safety Critical), released in 2022, targets automotive and embedded systems.

Adoption

Vulkan is the native graphics API of Android for modern devices and is widely used on Linux gaming, including via Valve's Proton compatibility layer, where the DXVK and VKD3D-Proton translators implement Direct3D on top of Vulkan. Game engines such as id Tech (Doom 2016), Unity and Unreal Engine support it; emulators and the cross-platform library ecosystem (SDL, wgpu/WebGPU implementations) also build on it. On Apple platforms it is available through the MoltenVK translation layer to Metal.
