Web framework

A web framework (WF) or web application framework (WAF) is a software framework designed to support the development of web applications including web services, web resources, and web APIs. Web frameworks aim to alleviate the overhead associated with common activities performed in web development — such as database access, templating, session management, and URL routing — and to promote code reuse.

History

Early dynamic web content was generated with the Common Gateway Interface (CGI) in the 1990s. Frameworks such as Ruby on Rails (2004) and Django (2005) popularized convention over configuration and the model–view–controller (MVC) architecture, greatly influencing later frameworks.

Types

Server-side frameworks

Server-side frameworks run on the web server and typically handle request routing, data persistence through object–relational mapping, templating, security, and caching. Examples include Laravel (PHP), Django and Flask (Python), Rails (Ruby), Express (Node.js), and ASP.NET (C#).

Client-side frameworks

Client-side frameworks run in the browser and structure single-page applications, managing rendering, state, and routing in JavaScript or TypeScript. Examples include React, Angular, and Vue.js.

Features

Common features include support for libraries shared across applications, caching, access control and authentication, security protections against cross-site scripting and SQL injection, URL mapping, templating systems that separate logic from presentation, and Ajax support.
