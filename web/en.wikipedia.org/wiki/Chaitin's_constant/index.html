Chaitin's constant

Gregory Chaitin, after whom the constant is named

In the computer science subfield of algorithmic information theory, a Chaitin constant (Chaitin omega number) is a real number that, informally speaking, represents the probability that a randomly constructed program will halt. These numbers are formed from a construction due to Gregory Chaitin.

Although there are infinitely many halting probabilities, one for each model of computation, it is common to use the letter Ω to refer to them as if there were only one. Because Ω depends on the program encoding used, it is sometimes called Chaitin's construction instead of Chaitin's constant when not referring to any specific encoding.

Each halting probability is a normal and transcendental real number that is not computable, which means that there is no algorithm to compute its digits from one to the next. Solving the halting problem for the first N programs would allow the first N bits of Ω to be computed.

Definition

Let P be the domain of a prefix-free universal computable function F. The constant ΩF is defined as

ΩF = Σp ∈ P, F(p) halts 2−|p|

where |p| denotes the length of the bit string p. The sum runs over all programs p for which F halts; prefix-freeness ensures, by Kraft's inequality, that the sum converges to a number between 0 and 1, interpretable as the probability that a program generated by flipping a fair coin for each bit will halt.

Properties

  • Uncomputability: No algorithm can compute the digits of Ω. Knowing the first N bits of Ω would allow one to solve the halting problem for all programs up to length N, which is undecidable.
  • Algorithmic randomness: The binary expansion of Ω is algorithmically random (Martin-Löf random); its initial segments are incompressible.
  • Transcendence: Ω is a transcendental number.
  • Incompleteness: Chaitin used Ω to prove a version of Gödel's incompleteness theorem: a formal system with N bits of axioms can determine at most N + O(1) bits of Ω.

Computation of initial digits

For particular carefully chosen universal machines, the first few digits of Ω have been computed. In 2000, Cristian Calude and colleagues computed the first 64 bits of a halting probability for a specific register machine encoding; such values depend entirely on the chosen machine and encoding.
