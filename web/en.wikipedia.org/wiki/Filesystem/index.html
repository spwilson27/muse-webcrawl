File system

In computing, a file system (or filesystem) controls how data is stored and retrieved on a storage device. Without a file system, data placed on a storage medium would be one large body of information with no way to tell where one piece ended and the next began. By separating data into named files grouped in directories, a file system makes it possible to locate and manage information efficiently.

Architecture

A file system maintains metadata for each file — its name, size, location of its data blocks, timestamps, ownership, and access permissions — in structures such as file allocation tables, inodes, or B-trees. File systems may add journaling, which logs changes before committing them so the volume can recover after a crash, and features such as snapshots, compression, encryption, and copy-on-write.

Common file systems

Well-known file systems include FAT and its successor exFAT, NTFS and APFS used by Windows and macOS respectively, ext4, XFS, and Btrfs on Linux, and ZFS. Network file systems such as NFS and SMB allow files to be accessed over a network as if they were local, while special-purpose systems present virtual hierarchies — for example, the Linux /proc filesystem exposes kernel and process information as files.
