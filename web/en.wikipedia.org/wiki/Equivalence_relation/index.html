Equivalence relation

In mathematics, an equivalence relation is a binary relation that is reflexive, symmetric and transitive. The equipollence relation between line segments in geometry is a common example; another is congruence modulo n on the integers. The relation "is equal to" is the canonical example of an equivalence relation.

Definition

A binary relation ~ on a set X is an equivalence relation if, for all a, b, c in X: a ~ a (reflexivity); if a ~ b then b ~ a (symmetry); and if a ~ b and b ~ c then a ~ c (transitivity).

Equivalence classes and partitions

Every equivalence relation partitions its set into disjoint equivalence classes, whose union is the whole set; conversely, every partition defines an equivalence relation. The set of equivalence classes forms the quotient set, foundational to constructions such as quotient groups and quotient spaces.

Examples and non-examples

Congruence of geometric figures, equality of rational numbers defined by cross-multiplication, and having the same birthday are equivalence relations. Relations such as "is greater than" (not symmetric) or approximate equality (not transitive) are not.
