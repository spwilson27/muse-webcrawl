Euler's totient function

Euler's totient function
Notation: φ(n)
Field: Number theory
Named after: Leonhard Euler

In number theory, Euler's totient function φ(n) counts the positive integers up to n that are relatively prime to n — that is, the integers k in the range 1 ≤ k ≤ n for which gcd(n, k) = 1. Written using the Greek letter phi, φ(1) = 1 by convention, since the only integer in range coprime to 1 is 1 itself.

Formula and properties

If n factors into primes, Euler's product formula gives φ(n) = n Π (1 − 1/p) over the distinct primes p dividing n. The function is multiplicative: φ(mn) = φ(m)φ(n) whenever m and n are coprime. Euler's theorem states that a^φ(n) ≡ 1 (mod n) for a coprime to n, a generalisation of Fermat's little theorem.

Applications

The totient function is central to the RSA cryptosystem, where the difficulty of computing φ(n) for a product of two large primes underlies security.
