F1 score

In statistical analysis of binary classification and information retrieval, the F-score or F-measure is a measure of a test's accuracy. The most common form, the F1 score, is the harmonic mean of the precision and recall of the test. It is widely used to evaluate machine learning classifiers and search or recommendation systems, especially when class distributions are imbalanced.

Definition

Precision is the fraction of retrieved (predicted positive) instances that are actually positive; recall is the fraction of actual positives that were retrieved. The F1 score combines them:

F1 = 2 · (precision · recall) / (precision + recall)

Equivalently, in terms of true positives (TP), false positives (FP), and false negatives (FN):

F1 = 2TP / (2TP + FP + FN)

The harmonic mean, unlike the arithmetic mean, strongly penalizes extreme imbalance: a classifier with very high precision but very low recall (or vice versa) receives a low F1 score. The score ranges from 0 (worst) to 1 (best).

General F-beta score

The general Fβ score weights recall β times as much as precision. F2 emphasizes recall, while F0.5 emphasizes precision. The family traces to the effectiveness measure proposed by C. J. van Rijsbergen in information retrieval research in the 1970s.

Applications

F1 is a standard benchmark metric in natural language processing tasks such as named entity recognition, question answering (token-level F1), and machine translation evaluation variants, and in computer vision and medical diagnosis tasks. Variants include macro-F1 (averaged across classes, treating each class equally) and micro-F1 (aggregating counts across classes, which in single-label multiclass problems equals accuracy).

Criticism

F1 ignores true negatives, so it can be misleading when the negative class matters. It also does not correspond to performance at any particular decision threshold, and comparisons between F1 scores computed on different datasets or with different class prevalences are unreliable. Alternatives include the Matthews correlation coefficient, balanced accuracy, Cohen's kappa, and precision–recall curves summarized by average precision.
