Escape character

An escape character is a character that invokes an alternative interpretation of the characters that follow it in a sequence.

In computing and telecommunications, an escape character is a character that invokes an alternative interpretation on the following characters in a sequence of characters. An escape character is a metacharacter: it does not represent itself but changes the meaning of what comes next. Which character serves as the escape, and what the resulting combination means, depends on the context — a programming language, a terminal protocol, a markup format or a command shell.

The ASCII escape character

The original escape character is the dedicated ESC control character in ASCII (decimal 27, hexadecimal 0x1B), generated by the Esc key. Bob Bemer, who championed its inclusion, designed it to signal that subsequent characters form a control sequence rather than data. Such escape sequences — standardised by ANSI and embodied in terminals such as the VT100 — control cursor position, colour and other display functions, and survive today in every terminal emulator: the text ESC[31m, for example, renders following output in red.

The backslash

In many programming languages, beginning with BCPL and popularised by C, the backslash \ is the escape character within character and string literals. Escape sequences such as \n (newline), \t (tab), \\ (a literal backslash) and \" (a quotation mark that does not end the string) allow characters to be represented that cannot easily be typed or would clash with the syntax. Regular expressions likewise use the backslash both to escape metacharacters, making them literal, and to give ordinary letters special meanings such as \d for a digit.

Other conventions

HTML and XML use the ampersand to begin character references such as &amp;; URLs use the percent sign for percent-encoding; Unix shells use the backslash to quote the next character and single or double quotes to group text; SQL traditionally doubles a quote to escape it. In the TeX typesetting system the backslash introduces commands. The word escaping generally denotes the process of transforming data so it can be safely embedded in a context where some characters are special — a failure to escape user input correctly underlies injection vulnerabilities such as SQL injection and cross-site scripting.
