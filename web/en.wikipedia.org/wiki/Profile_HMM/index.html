Profile HMM

A profile hidden Markov model (profile HMM) is a type of hidden Markov model used in bioinformatics to represent a family of related biological sequences, such as a protein family or a set of aligned DNA or protein sequences. Profile HMMs are built from a multiple sequence alignment and can be used both to search sequence databases for new members of a family and to align sequences to the family.

Structure

A profile HMM has a series of columns corresponding to positions in the multiple sequence alignment. Each column contains three kinds of states: a match state, which emits a residue with probabilities derived from the column of the alignment; an insert state, which allows extra residues to be inserted between columns; and a delete state, which is silent and allows a column to be skipped. Transition probabilities between these states are estimated from the alignment, along with pseudocounts to avoid zero probabilities.

Applications

Profile HMMs underlie widely used tools and databases including HMMER and the Pfam database of protein families. Compared with simple consensus sequences or position-specific scoring matrices, profile HMMs give a probabilistic framework that scores both residue conservation and insertions and deletions in a consistent way.
