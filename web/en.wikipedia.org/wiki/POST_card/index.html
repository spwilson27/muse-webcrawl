POST card

From Wikipedia, the free encyclopedia

A POST card is a plug-in diagnostic tool that reports the progress of a computer's power-on self-test (POST) as hexadecimal codes on a small display. During boot, the BIOS or UEFI firmware writes checkpoint codes to a debug port (classically I/O port 0x80 on IBM PC compatibles); the card, inserted into an expansion slot such as ISA, PCI or PCI Express, decodes and displays them.

Use

When a computer fails to boot, beep codes and on-screen messages may be absent; the last code shown on the POST card indicates which initialisation step (CPU, memory, video, keyboard, storage, and so on) was running when the boot stalled. The technician consults the BIOS manufacturer's code table to identify the failing subsystem.

Modern equivalents

Many enthusiast and workstation motherboards now include an onboard two-digit "Q-code" LED display serving the same purpose, and servers expose boot progress through management controllers. USB and LPC-based diagnostic cards serve laptops and newer systems lacking legacy slots.
