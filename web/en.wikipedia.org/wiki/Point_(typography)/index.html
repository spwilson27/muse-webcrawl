Point (typography)

In typography, the point is the smallest unit of measure used to specify the size of type (font size), leading (line spacing), and other dimensions on a printed page. The size of a point has varied throughout printing history, but since the rise of desktop publishing the standard is the PostScript point, defined as exactly 1/72 of an inch (approximately 0.3528 mm). Twelve points make one pica, so a pica is 1/6 inch, and there are six picas to the inch.

Text set at increasing point sizes; font size is measured in points from baseline to baseline of the type body.

History

Before standardisation, printers named type sizes rather than numbering them (names such as brevier, bourgeois, and great primer survived into the metal type era). The first systematic point system was proposed by the French cleric and printer Pierre Simon Fournier in 1737, and refined by François-Ambroise Didot, whose Didot point (about 0.376 mm) became standard in continental Europe, with 12 Didot points forming a cicero. In Britain and the United States, type founders adopted a slightly smaller point of about 0.013837 inch (roughly 1/72.27 inch) in 1886; this "American point" remained standard until Adobe's PostScript rounded it to exactly 1/72 inch in 1984, a definition inherited by CSS and virtually all modern software.

Usage

Font sizes are conventionally quoted in points even though the visible height of letters varies between typefaces of the same nominal size, because the point measures the size of the type body (in digital fonts, the em square) rather than any particular letter. Body text in books is commonly set between 9 and 12 points; word processors default to 10–12 pt, and footnotes and captions are often 8 pt or smaller. TeX uses its own point of 1/72.27 inch, and CSS defines the pt unit as 1/72 inch, with 1 pt equal to 4/3 CSS pixels.
