Batch file

A batch file is a script file in DOS, OS/2 and Microsoft Windows containing a series of commands to be executed by the command-line interpreter, usually COMMAND.COM in DOS or cmd.exe in Windows. Batch files typically have the extension .bat, or .cmd.

Operation

When a batch file is run, the shell reads and executes its commands line by line. Batch files support simple programming constructs including variables (%VAR%), labels and GOTO, IF conditional tests, FOR loops over files, and subroutine calls with CALL. Echoing of commands can be suppressed with @ECHO OFF, and REM marks comments.

Uses

Batch files are used to automate routine tasks such as copying backups, launching programs with set options, and configuring the environment at logon. In DOS, AUTOEXEC.BAT ran automatically at boot to configure the system. Although Windows PowerShell and other scripting languages offer far greater power, batch files remain widely used for their simplicity and ubiquity.

Limitations and quirks

The batch language has well-known idiosyncrasies: delayed variable expansion requires SETLOCAL EnableDelayedExpansion, percent-sign escaping differs between interactive use and scripts, and error handling relies on the ERRORLEVEL variable checked after each command.
