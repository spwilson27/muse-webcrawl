Instruction cycle

The instruction cycle (also known as the fetch–decode–execute cycle, or simply the fetch–execute cycle) is the cycle that the central processing unit (CPU) follows from boot-up until the computer has shut down in order to process instructions. It is composed of three main stages: the fetch stage, the decode stage, and the execute stage.

Fetch

The program counter (PC) holds the address of the next instruction. At the start of the cycle, the instruction at that address is copied from memory into the instruction register (IR), and the PC is incremented to point to the following instruction.

Decode

The control unit interprets the opcode in the instruction register, identifies the operation and its operands, reads operand values from registers or memory, and configures the datapath accordingly. In microprogrammed processors, decoding selects an entry point in the microcode store; in hardwired designs it activates combinational control logic.

Execute

The CPU performs the specified operation: the ALU computes an arithmetic or logical result, memory is read or written, a branch changes the program counter, or input/output is transferred. At the end of execution, results are written back to registers or memory, and the cycle repeats with the next fetch. Between instructions the CPU may also check for interrupts and, if one is pending, save its state and transfer control to an interrupt handler.

Pipelining

Modern CPUs overlap the stages of many instructions in an instruction pipeline, and superscalar designs fetch and execute several instructions per cycle. The simple three-stage description remains the conceptual basis for these more complex organizations.
