Datapath

A datapath is a collection of functional units such as arithmetic logic units (ALUs) or multipliers that perform data processing operations, most central processing units consisting of a datapath and a control unit. The datapath contains the registers, buses, multiplexers, and functional units through which data actually flows and is transformed during instruction execution, while the control unit generates the signals that orchestrate those transfers.

Components

A typical processor datapath includes:

  • A register file holding operands and results close to the execution units;
  • One or more functional units (ALU, shifter, multiplier, load/store unit);
  • Buses and interconnect, often with multiplexers that select which source drives each destination in a given cycle;
  • Pipeline registers that separate stages in a pipelined design;
  • Interfaces to the instruction and data caches.

Design

Datapaths may be single-cycle, multi-cycle, or pipelined. In a classic five-stage pipeline (fetch, decode, execute, memory, write-back), the datapath is partitioned so different instructions occupy different stages simultaneously. Forwarding (bypassing) paths carry results directly between pipeline stages to reduce stalls caused by data hazards. The organization of the datapath largely determines a processor's clock rate and instructions-per-cycle capability.

Datapath synthesis

In digital design flows, datapath synthesis is the part of high-level synthesis that schedules operations and binds them to hardware resources, producing a register-transfer-level structure from a behavioral description. Specialized datapath elements are also found in digital signal processors, graphics units, and network processors, where wide parallel datapaths stream data with minimal control overhead.
