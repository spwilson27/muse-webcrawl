Central processing unit

A central processing unit (CPU), also called a central processor, main processor, or just processor, is the primary processor in a given computer. Its electronic circuitry executes instructions of a computer program, such as arithmetic, logic, controlling, and input/output (I/O) operations. This role contrasts with that of external components such as main memory and I/O circuitry, and specialized coprocessors such as graphics processing units (GPUs).

Operation

The fundamental operation of most CPUs is to execute a sequence of stored instructions — a program — through the fetch–decode–execute cycle. The control unit fetches an instruction from memory into the instruction register, decodes it, and directs the arithmetic logic unit (ALU), registers, and other components to carry it out. Performance is influenced by clock rate, instructions per cycle, cache size, and the number of cores; nearly all modern CPUs are multi-core, containing several independent processing units on one chip, and use pipelining, superscalar execution, out-of-order execution, and branch prediction.

History

Early computers such as ENIAC (1945) had CPUs built from vacuum tubes and occupying whole rooms. Transistors replaced tubes in the 1950s–60s, and integrated circuits then shrank the CPU dramatically. Intel introduced the first commercial single-chip microprocessor, the 4-bit 4004, in 1971; the 8-bit 8080 (1974) and the x86 family (from 1978) followed. From the 1970s to the early 2000s, transistor counts doubled roughly every two years (Moore's law) and clock rates rose steeply; since then, gains have come mainly from parallelism and efficiency as Dennard scaling ended.

Structure

Principal components of a CPU include the control unit, which directs operations; one or more ALUs; processor registers providing fast local storage; cache memory (typically split into L1, L2, and often a shared L3); and, in system-on-a-chip designs, integrated memory controllers and graphics. CPUs are implemented according to an instruction set architecture (ISA) such as x86-64, ARM, or RISC-V, which defines the instructions and state visible to software.
