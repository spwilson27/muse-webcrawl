Control unit

The control unit (CU) is a component of a computer's central processing unit (CPU) that directs the operation of the processor. It tells the computer's memory, arithmetic and logic unit, and input and output devices how to respond to the instructions of a program.

Function

The control unit fetches instructions from memory, decodes them, and issues the control signals that coordinate the datapath: opening and closing register transfers, selecting ALU operations, and managing reads and writes to memory and I/O. Together with the arithmetic logic unit, it forms the core of the CPU in the von Neumann architecture.

Designs

In a hardwired control unit, control signals are generated by combinational logic circuits, which is fast but difficult to modify. In a microprogrammed control unit, control signals are stored as microinstructions in a special control memory; this approach, proposed by Maurice Wilkes in 1951, simplifies the design of complex instruction sets at the cost of speed. Most modern processors combine both techniques.
