Glossary of graph theory

From Wikipedia, the free encyclopedia

Graph theory is the study of graphs, mathematical structures used to model pairwise relations between objects. This glossary collects the principal terms used in the field. A graph in this context is made up of vertices (also called nodes or points) which are connected by edges (also called links or lines).

Basic terms

Adjacent
Two vertices are adjacent if they are joined by an edge; an edge is adjacent to another edge if they share a vertex.
Arc
Another name for a directed edge.
Bipartite graph
A graph whose vertices can be divided into two disjoint sets such that every edge connects a vertex of one set to a vertex of the other.
Bridge
An edge whose removal increases the number of connected components of the graph.
Chromatic number
The smallest number of colours needed to colour the vertices of a graph so that no two adjacent vertices share the same colour.
Clique
A set of vertices every two of which are adjacent; a complete subgraph.
Complete graph
A graph in which every pair of distinct vertices is joined by an edge, denoted Kn for n vertices.
Connected component
A maximal connected subgraph.
Cycle
A closed walk with no repeated vertices (except the start/end).
Degree
The number of edges incident to a vertex; in a directed graph, split into in-degree and out-degree.
Diameter
The greatest distance between any pair of vertices.
Directed graph (digraph)
A graph whose edges have orientations, joining an ordered pair of vertices.
Eulerian trail
A trail that uses every edge of the graph exactly once.
Forest
An acyclic graph; a disjoint union of trees.
Hamiltonian path
A path that visits every vertex exactly once; a graph containing one is traceable, and a Hamiltonian cycle closes the path into a ring.
Independent set
A set of vertices no two of which are adjacent.
Matching
A set of edges no two of which share a vertex.
Path
A walk with no repeated vertices.
Planar graph
A graph that can be drawn in the plane with no edge crossings.
Regular graph
A graph in which every vertex has the same degree.
Spanning tree
A subgraph that is a tree containing all the vertices of the graph.
Subgraph
A graph whose vertex and edge sets are subsets of another graph's.
Tree
A connected acyclic graph.
Vertex cover
A set of vertices such that every edge has at least one endpoint in the set.
Walk
A sequence of vertices and edges in which consecutive edges share a vertex.
