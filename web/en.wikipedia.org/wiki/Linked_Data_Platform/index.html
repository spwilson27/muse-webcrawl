Linked Data Platform

The Linked Data Platform (LDP) is a W3C Recommendation for a set of rules and best practices for building RESTful web applications that read and write Linked Data resources. It became a W3C Recommendation in February 2015.

Model

An LDP server exposes resources identified by URIs. LDP distinguishes RDF sources (resources whose state can be represented in RDF) from non-RDF sources such as images or documents. Resources are organised into containers: basic containers list their members, while direct and indirect containers add membership properties and relations. Clients create resources by POSTing to containers, update them with PUT or PATCH, and delete them with DELETE, using standard HTTP semantics.

Implementations and use

LDP underpins projects such as the Fedora repository software for digital libraries and the Solid platform for decentralised personal data stores, which extends LDP for personal online datastores ("pods").
