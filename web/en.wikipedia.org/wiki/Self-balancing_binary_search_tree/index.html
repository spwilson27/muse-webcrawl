Self-balancing binary search tree

Balancing keeps tree height logarithmic in the number of nodes

In computer science, a self-balancing binary search tree (or height-balanced binary search tree) is any node-based binary search tree that automatically keeps its height small in the face of arbitrary insertions and deletions. An ordinary binary search tree can degenerate into a linked list when keys arrive in sorted order, making operations linear-time; a self-balancing tree restructures itself — usually through rotations — so that search, insertion and deletion all run in O(log n) time.

Common schemes

SchemeBalance condition / idea
AVL treeHeights of sibling subtrees differ by at most one
Red–black treeColouring rules bound the longest path to twice the shortest
Splay treeRecently accessed nodes are rotated toward the root
TreapRandom priorities maintain the heap property over keys
B-treeMultiway generalisation used in databases and filesystems
AA tree, scapegoat tree, weight-balanced treeSimplified or amortised balancing strategies

Applications

Self-balancing trees provide the ordered-map and ordered-set containers of standard libraries — for example the C++ std::map, Java's TreeMap and many language runtimes' symbol tables — as well as the index structures inside databases and operating-system kernels.
