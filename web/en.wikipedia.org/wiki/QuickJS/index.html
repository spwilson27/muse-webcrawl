QuickJS is a lightweight, embeddable JavaScript engine developed by Fabrice Bellard, notable as the creator of FFmpeg and QEMU. It was released publicly in 2019 and is distributed under the MIT License.

QuickJS supports the ECMAScript 2020 specification almost entirely, including modules, asynchronous generators, proxies, and BigInt. Despite its small size — the core interpreter is only a few hundred kilobytes — it offers a nearly complete modern JavaScript implementation.

Features

  • Small footprint: the entire engine consists of a few C source files and can be compiled with no external dependencies.
  • Fast start-up time and deterministic, reference-counting-based memory management combined with a cycle-collecting garbage collector.
  • A standalone executable qjs with an interactive REPL, and qjsc, a compiler that can produce standalone executables from JavaScript code.
  • Support for mathematical extensions, including arbitrary-precision integers (BigInt), arbitrary-precision decimals (BigFloat, BigDecimal), and operator overloading.

Design

Unlike engines such as V8 or SpiderMonkey, QuickJS does not use a just-in-time compiler. It compiles JavaScript to a compact bytecode and interprets it, trading peak execution speed for tiny size, fast startup, and predictable behaviour — properties that make it attractive for embedded systems, scripting in applications, and Internet-of-things devices.

The jsc.js / qjs design influenced later minimalist JavaScript runtimes; QuickJS has been embedded in tools such as txiki.js and used as a scripting layer in embedded products.

History

Bellard first announced QuickJS in July 2019. Its version numbers are dates. Subsequent releases added full ES2020 support, improved compatibility, and a small standard library. In 2023, development of a community fork called QuickJS-NG began to continue maintenance with broader contributor involvement.
