The BMP file format, also known as bitmap image file, device independent bitmap (DIB) file format and bitmap, is a raster graphics image file format used to store bitmap digital images, independently of the display device (such as a graphics adapter), especially on Microsoft Windows and OS/2 operating systems.

The BMP file format is capable of storing two-dimensional digital images both monochrome and colour, in various colour depths, and optionally with data compression, alpha channels, and colour profiles. The Windows Metafile (WMF) specification covers the BMP file format.

History

Microsoft has defined a particular representation of colour bitmaps of different colour depths, as an aid to exchanging bitmaps between devices and applications with a variety of internal representations. They called these device independent bitmaps or DIBs, and the file format for them is called DIB file format or BMP image file format.

The first version of the BMP file format appeared with Windows 2.0 in 1987. Subsequent versions added larger colour depths and additional header fields; the format grew through Windows 3.0, Windows 95 and Windows NT versions, with the BITMAPV5HEADER adding support for colour spaces and ICC profiles.

File structure

A bitmap image file consists of fixed-size structures (headers) as well as variable-sized structures appearing in a predetermined sequence. Many different versions of some of these structures can appear in the file, due to the long evolution of this file format.

BMP file header

The BMP file header is 14 bytes in size and starts every BMP file. Its first two bytes are the ASCII characters "B" then "M" (0x42, 0x4D), followed by the size of the file in bytes, two reserved fields, and the offset from the start of the file to the pixel array.

DIB header

The DIB header immediately follows the file header and tells the reader the dimensions and format of the image. The most common variant, BITMAPINFOHEADER (40 bytes), stores the width and height of the image, the colour planes (must be 1), the bits per pixel, the compression method, the size of the raw bitmap data, and the horizontal and vertical resolution.

Pixel storage

The bits representing the bitmap pixels are packed in rows. The size of each row is rounded up to a multiple of 4 bytes (a 32-bit DWORD) by padding. Pixels are usually stored "bottom-up", starting in the lower left corner of the image, going from left to right and then row by row from the bottom to the top. If the height is negative, the image is stored top-down instead.

For images with a colour depth of 8 bits per pixel or less, a colour table (palette) precedes the pixel array, mapping pixel values to RGB colour values.

Compression

BMP files may optionally be compressed using run-length encoding (RLE) for 4- and 8-bit images. In practice, most BMP files are stored uncompressed, which makes them considerably larger than comparable PNG or JPEG files; this is the main reason the format has declined for photographic images, although it remains common as a simple interchange and screenshot format in Windows applications.
