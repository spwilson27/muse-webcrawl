Algorithmic paradigm

FieldComputer science
ExamplesDivide and conquer; dynamic programming; greedy; backtracking; branch and bound
PurposeGeneral templates for designing algorithms

An algorithmic paradigm (or algorithm design paradigm) is a general approach or template that underlies a class of algorithms for solving computational problems. Paradigms provide reusable strategies that can be adapted to many specific problems.

Common paradigms

Divide and conquer splits a problem into smaller subproblems solved recursively, as in merge sort. Dynamic programming solves overlapping subproblems once and reuses their results, as in computing Fibonacci numbers or shortest paths. Greedy algorithms make locally optimal choices, as in Huffman coding. Backtracking incrementally builds candidates and abandons those that fail constraints, as in solving Sudoku. Other paradigms include brute force, reduction, branch and bound, and randomised algorithms.

Use in education

Algorithm design courses are typically organised around these paradigms, since recognising which paradigm fits a problem is a key step in devising an efficient solution.
