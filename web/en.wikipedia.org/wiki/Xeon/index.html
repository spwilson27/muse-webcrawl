Xeon

Xeon is a brand of x86 microprocessors designed, manufactured and marketed by Intel, targeting non-consumer workstations, servers and embedded markets. Introduced in June 1998 with the Pentium II Xeon, Xeon processors typically share architectures with Intel's desktop lines but add features such as support for error-correcting (ECC) memory, larger caches, more memory channels, more PCI Express lanes and multi-socket configurations.

History

The first Xeon chips were server versions of the Pentium II and Pentium III. The name was carried through the NetBurst era (Xeon based on Pentium 4), and Intel dropped the "Pentium" prefix. With the Core microarchitecture, Xeon 5100/5300 series chips powered workstations and servers including Apple's Mac Pro and Xserve. From 2017, Intel reorganised the data-centre range as Xeon Scalable Processors with Bronze, Silver, Gold and Platinum tiers, succeeding the E5 and E7 families. Successive generations (Skylake-SP, Cascade Lake, Cooper Lake, Ice Lake-SP, Sapphire Rapids, Emerald Rapids and Granite Rapids) increased core counts, eventually exceeding 100 cores per socket for cloud and high-performance computing variants, and added accelerators and support for DDR5 and PCIe 5.0. Xeon Phi — a many-core coprocessor line derived from the Larrabee project — was discontinued in 2018. Entry-level Xeon E and workstation Xeon W processors serve single-socket systems.

Features

Distinguishing Xeon features include RAS (reliability, availability and serviceability) capabilities, Intel's advanced vector extensions (AVX-512 on many models), support for terabytes of memory per socket, and certification for continuous operation in data centres.
