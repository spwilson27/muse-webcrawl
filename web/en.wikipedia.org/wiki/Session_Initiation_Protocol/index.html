Session Initiation Protocol

The Session Initiation Protocol (SIP) is a signaling protocol used for initiating, maintaining, and terminating real-time communication sessions that include voice, video and messaging applications. SIP is used in Internet telephony, in private IP telephone systems, and in mobile phone calling over LTE (VoLTE) and 5G.

Overview

SIP was designed by Henning Schulzrinne and Mark Handley in 1996 and standardised by the IETF, most comprehensively in RFC 3261 (2002). It is a text-based protocol modelled on HTTP and SMTP, using requests such as INVITE, ACK, BYE, REGISTER and OPTIONS, and numerical response codes. SIP works with the Session Description Protocol (SDP) to negotiate media parameters, while the actual media usually travels over the Real-time Transport Protocol (RTP).

Network elements

Endpoints are user agents; servers include proxies that route requests, registrars that bind addresses of record to locations, and redirect servers. Back-to-back user agents are used in session border controllers and PBX systems.

Adoption

SIP underlies most modern VoIP services, unified communications platforms, and the IMS architecture used by mobile operators for voice over LTE and 5G.
