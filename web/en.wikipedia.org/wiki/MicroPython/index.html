MicroPython is a software implementation of a programming language largely compatible with Python 3, written in C, that is optimized to run on a microcontroller. It includes a subset of the Python standard library and provides an interactive prompt (REPL) accessible over a serial connection, allowing developers to experiment with hardware directly.

History

MicroPython was created by Australian programmer Damien George. It was first released following a successful Kickstarter crowdfunding campaign in 2013–2014. The original hardware target was the "pyboard", a development board based on an STM32 microcontroller sold alongside the software.

Since then, MicroPython has been ported to many platforms, including the ESP8266 and ESP32, the BBC micro:bit (through the Micro:Maqueen ecosystem and its own official port), the Raspberry Pi Pico (RP2040), Arduino boards, and numerous other embedded systems. In 2016, a version of MicroPython was sent to the International Space Station as part of the European Space Agency's Astro Pi project.

Features

MicroPython implements the core Python language including generators, decorators, classes and list comprehensions, within the memory constraints of devices that may have as little as 16 KB of RAM. It provides modules for accessing low-level hardware (GPIO, I2C, SPI, UART, timers, ADC/DAC) through a machine module, along with a frozen-module system for embedding code in firmware.

The related project CircuitPython, maintained by Adafruit Industries, is a fork of MicroPython aimed at education and ease of use on Adafruit's hardware.

Relationship to Python

Unlike CPython, MicroPython is designed for microcontrollers rather than general-purpose computers. It trades some standard-library coverage and performance characteristics for a tiny footprint and immediate hardware access, making it popular in education, prototyping, and the Internet of Things.
