Crystal is a general-purpose, object-oriented programming language designed and developed by Ary Borenszweig, Juan Wajnerman, Brian Cardiff and over 500 contributors. Its syntax is heavily inspired by Ruby, but unlike Ruby it compiles to efficient native code via LLVM and uses static type checking with advanced global type inference, so explicit type annotations are usually unnecessary.

Design

Crystal aims to combine the elegance and productivity of Ruby with the speed and safety of a compiled language. It features a macro system, generics, method and operator overloading, and null-safety checks. Concurrency is provided by lightweight fibers and channels inspired by Go and CSP, while low-level primitives allow binding to existing C libraries.

Example

puts "Hello World!"

class Person
  def initialize(@name : String)
  end

  def greet
    puts "Hi, I'm #{@name}"
  end
end

john = Person.new("John")
john.greet

History

Work began in June 2011 at Manas Technology Solutions with the goal of a language with Ruby-like syntax but compiled performance. The first public compiler appeared in 2014, and the language reached version 1.0 in March 2021, guaranteeing backward compatibility.
