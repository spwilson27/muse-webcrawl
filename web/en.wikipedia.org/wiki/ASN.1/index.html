Abstract Syntax Notation One (ASN.1) is a standard interface description language mainly for defining data structures that can be serialized and deserialized in a cross-platform way. It is widely used in telecommunications and computer networking, and especially in cryptography.

Overview

ASN.1 defines the abstract syntax of information without restricting how it is encoded for transmission. Separate encoding rules — such as the Basic Encoding Rules (BER), Distinguished Encoding Rules (DER), Packed Encoding Rules (PER), and XML Encoding Rules (XER) — specify concrete representations. Protocol developers define data types and values in ASN.1 modules, which are typically sections of a broader standards document.

Applications

ASN.1 is a core notation in standards including X.509 digital certificates, Kerberos, Lightweight Directory Access Protocol (LDAP), SNMP, H.323, and cellular telephony signalling protocols such as those used in GSM, GPRS, UMTS, and LTE networks.

Example

A simple message type might be defined as a SEQUENCE containing named fields such as a string name and an integer quantity, allowing implementations in different languages to exchange identical structured data.
