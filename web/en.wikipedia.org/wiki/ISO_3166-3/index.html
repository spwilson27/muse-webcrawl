ISO 3166-3

ISO 3166-3 is part of the ISO 3166 standard published by the International Organization for Standardization (ISO), and defines codes for country names which have been deleted from ISO 3166-1 since its first publication in 1974. Each former country name is assigned a four-letter alphabetic code: the original alpha-2 code followed by a two-letter suffix.

Formation of codes

Where a country was simply renamed, the suffix is the former alpha-2 code (e.g. BYAA for the Byelorussian SSR, whose code BY later passed to Belarus). Where a country split, merged, or its code was reused, other suffixes apply: CSHH for Czechoslovakia (CS before 1993), YUCS for earlier Yugoslavia usages, SUHH for the USSR, and DDDE for the German Democratic Republic (East Germany), whose alpha-2 code DD was deleted in 1990 following reunification.

Purpose

Preserving deleted codes ensures that historical data coded under ISO 3166-1 remains interpretable, and the standard guarantees that withdrawn alpha-2 codes will not be reassigned for at least 50 years, preventing confusion in archives, statistics, and legacy systems.
