Info-ZIP

Info-ZIP is a set of free, open-source programs for working with ZIP archives, originally developed by a loose group of volunteer programmers in the early 1990s. Its best-known tools are Zip, which creates and updates ZIP archives, and UnZip, which extracts them. The code was written to be portable and was ported to a very wide range of operating systems, from Unix and MS-DOS to VMS, AmigaOS, and many others.

History

The ZIP format had been created by Phil Katz's PKZIP in 1989. Info-ZIP began as an effort to provide free implementations compatible with the published format specification. UnZip appeared around 1990 and Zip followed; later releases added support for large files, Zip64 extensions, bzip2 compression within archives, and Unicode file-name handling (in beta releases). The utilities were distributed under a permissive BSD-style licence.

Influence

Info-ZIP's portable code base was incorporated into many other products and systems. The related zlib library and Java's built-in ZIP support descend conceptually from this ecosystem of free ZIP tooling, and functions derived from UnZip appeared in early versions of some commercial archivers. Though development has slowed, Zip and UnZip remain standard tools on many Unix-like systems.
