Terminal emulator

From Wikipedia, the free encyclopedia

A terminal emulator, or terminal application, is a computer program that emulates a video terminal in some other display architecture. Though typically synonymous with a shell or text terminal, the term terminal in this context covers all remote terminals, including graphical interfaces. A terminal emulator inside a graphical user interface is often called a terminal window.

Function

A terminal window allows the user access to a console — a text terminal and its command-line interface (CLI) — running a shell or other text program, even when working in a graphical environment. The emulator interprets streams of characters and control sequences (such as ANSI escape codes) sent by the application, renders text in a grid of character cells, and sends keyboard input back to the application, usually through a pseudoterminal device on Unix-like systems.

History

Early computers were accessed through physical terminals: first teletypewriters, then glass terminals such as the DEC VT100 (1978), whose escape sequences became a de facto standard. As personal computers replaced dedicated terminals, software emulators took over the terminal's role, connecting over serial lines, dial-up modems, Telnet and later SSH. The xterm program (1984) for the X Window System set the pattern for Unix terminal emulators; its de facto extensions of the VT100/VT220 protocol remain the most widely emulated standard.

Examples

  • Unix-like: xterm, GNOME Terminal, Konsole, kitty, Alacritty, WezTerm, st
  • macOS: Terminal.app, iTerm2
  • Windows: Windows Terminal, ConHost, PuTTY
  • Web-based: xterm.js-based terminals in browser IDEs

Features

Modern emulators add tabs, split panes, scrollback buffers, Unicode and true-colour (24-bit) support, ligature rendering, hyperlinks, and GPU-accelerated drawing. Terminal multiplexers such as tmux and GNU Screen are a related but distinct layer, providing persistent sessions within a terminal.
