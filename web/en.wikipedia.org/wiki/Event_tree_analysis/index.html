Event tree analysis

Event tree analysis (ETA) is a forward, inductive safety analysis technique used in reliability engineering and probabilistic risk assessment. Starting from a defined initiating event — for example a pipe rupture or loss of electrical power — the analyst constructs a branching diagram in which each subsequent branch represents the success or failure of a safety function or barrier (detection, alarms, emergency cooling, containment, and so on). Every path through the tree represents a distinct accident sequence ending in an outcome of a given severity.

Method

An event tree is read from left to right. Branches are usually binary (success/failure) and are ordered chronologically by when each safety system must act. Where the probability of a branch is known, the probability of a complete sequence is obtained by multiplying the branch probabilities along its path, allowing outcomes to be ranked and the contribution of each barrier quantified. Event trees are commonly combined with fault tree analysis, which analyses each branch's failure probability in depth; together they form the cause–consequence and bow-tie models widely used in the nuclear, chemical process, offshore oil and gas, aerospace and rail industries.

History

The technique developed from decision-tree ideas in the 1960s and was brought to prominence by the 1975 Rasmussen report (WASH-1400), the first comprehensive probabilistic safety assessment of commercial nuclear power plants, which used event trees to model accident sequences at two US reactors. It remains a standard part of level 1 probabilistic safety assessment.
