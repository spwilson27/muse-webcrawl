Softmax function

The softmax function is a function that converts a vector of K real numbers into a probability distribution of K possible outcomes. It is a generalization of the logistic function to multiple dimensions, and used in multinomial logistic regression. The softmax function is often used as the last activation function of a neural network to normalize the output of a network to a probability distribution over predicted output classes.

Definition

The standard softmax function σ : ℝK → (0,1)K is defined by the formula

σ(z)i = ezi / Σj=1..K ezj

for i = 1, …, K and z = (z1, …, zK) ∈ ℝK. In other words, it applies the standard exponential function to each element zi of the input vector z and normalizes these values by dividing by the sum of all these exponentials. The output components are all positive and sum to 1, so they may be interpreted as probabilities.

Applications

  • Multinomial logistic regression and classification layers of neural networks.
  • Attention mechanisms: scaled dot-product attention in transformers applies softmax to compatibility scores to produce weights.
  • Reinforcement learning: Boltzmann (softmax) action selection, as used by Luce's choice axiom.
  • Statistical mechanics: the Boltzmann distribution is a softmax with temperature parameter.

Temperature and numerical stability

A temperature parameter T can sharpen (T < 1) or flatten (T > 1) the output distribution, used in knowledge distillation and sampling from language models. For numerical stability, implementations subtract the maximum input component before exponentiating, which leaves the result unchanged.
