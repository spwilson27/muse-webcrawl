Associative memory

Associative memory may refer to several related concepts in psychology, neuroscience, and computer science:

  • In psychology, the ability to learn and remember the relationship between unrelated items, such as the name of someone we have just met or the aroma of a particular perfume. This form of memory is sometimes called associative learning or associative recall.
  • In computer architecture, a content-addressable memory (CAM), also called an associative memory or associative storage, a type of computer memory used in certain very-high-speed searching applications.
  • In artificial intelligence, associative memory models such as the Hopfield network, which store patterns as attractors in a dynamical system and retrieve a complete pattern from a partial or corrupted input.

In psychology

Associative memory in humans is the capacity to encode and retrieve links between two or more pieces of information, for example between a face and a name, or between a stimulus and a response. It is a central component of episodic memory and underlies many forms of classical and operant conditioning. Associative memory tends to decline with normal ageing more steeply than memory for individual items, and it depends heavily on the hippocampus and surrounding medial temporal lobe structures.

Content-addressable memory

Unlike standard computer memory (random-access memory), in which the user supplies a memory address and the RAM returns the data word stored at that address, a CAM is designed so that the user supplies a data word and the CAM searches its entire memory to see if that data word is stored anywhere in it. If the data word is found, the CAM returns a list of one or more storage addresses where the word was found. CAMs are used in networking equipment such as routers, in processor cache controllers, and in database accelerators, although their cost per bit is much higher than that of ordinary RAM.

Neural network models

In computational neuroscience and machine learning, associative memories are models that map input patterns to output patterns, or that store patterns so they can be recalled from noisy cues. The Hopfield network, introduced in 1982, is the best-known example: a recurrent neural network whose stored states act as energy minima, so that the network converges to the stored pattern closest to its initial state. Later models, including sparse distributed memory and modern attention mechanisms, share the same basic principle of content-based retrieval.
