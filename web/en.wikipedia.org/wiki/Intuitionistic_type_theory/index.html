Intuitionistic type theory (also known as Martin-Löf type theory) is a theory of types designed by Per Martin-Löf, a Swedish mathematician and philosopher, as a constructive foundation for mathematics. First presented in 1972 and refined through the 1984 Bibliopolis volume Intuitionistic Type Theory, it is both a formal system for constructive mathematics and, via the Curry–Howard correspondence, a functional programming language: its types are simultaneously propositions and specifications, and its terms are simultaneously proofs and programs.

Features

The theory is built around judgements of the form "a is a term of type A". Its type formers include dependent function types (Π-types), dependent pair types (Σ-types), disjoint unions, the empty and unit types, natural numbers with an induction principle, W-types (well-founded trees), identity types — whose inhabitants represent proofs of equality and make the theory intensional — and a cumulative hierarchy of universes (Type₀ : Type₁ : …) that avoids Girard's paradox. Equality is split into definitional (judgemental) equality, checked automatically, and propositional equality carried by identity types; the 1972 impredicative version was shown inconsistent by Girard's paradox, prompting the predicative universe hierarchy.

Semantics and developments

Martin-Löf's meaning explanations justify the rules by the Brouwer–Heyting–Kolmogorov interpretation: a proof of a proposition is a construction witnessing it. The theory's computational interpretation — every closed term of natural-number type evaluates to a numeral — makes it a programming language as well as a logic. It directly underlies the proof assistant Agda and influenced Coq's calculus of inductive constructions and Lean. Its identity types, treated homotopically (equality as paths), grew into homotopy type theory (HoTT), with Voevodsky's univalence axiom, in the 2000s–2010s; cubical type theory restores computation for univalence. Extensional variants add equality reflection but lose decidable type checking.
