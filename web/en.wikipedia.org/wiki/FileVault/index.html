FileVault

FileVault is a disk encryption program in macOS. It first shipped with Mac OS X Panther (10.3) and provides full-disk encryption of the startup volume using XTS-AES-128 encryption with a 256-bit key.

History

The original FileVault (retroactively called FileVault 1 or Legacy FileVault) encrypted only the user's home directory, storing it as an encrypted disk image. FileVault 2, introduced with Mac OS X Lion (10.7) in 2011, encrypts the entire startup disk, using a key derived from the user's login password and protected by a recovery key that can optionally be stored with Apple or, on institutional deployments, an institutional recovery key.

Function

When FileVault is enabled, authorized users can unlock the volume at startup; the system volume remains encrypted at rest until a valid password or recovery key is provided. On Macs with Apple silicon or the T2 security chip, encryption is integrated with the hardware Secure Enclave.
