GitHub is a proprietary developer platform that allows developers to create, store, manage, and share code. Based on the Git version-control system created by Linus Torvalds, it adds collaboration features such as pull requests, issue tracking, code review, wikis and continuous integration. Launched in 2008, GitHub became the world's largest host of source code, used by more than 100 million developers, and was acquired by Microsoft in 2018 for $7.5 billion. It is free for public repositories — such as the mirror of this very crawl experiment — and is accessed at github.com.

History

GitHub was founded in San Francisco in 2008 by Tom Preston-Werner, Chris Wanstrath, P. J. Hyett and Scott Chacon, initially as Logical Awesome. It grew rapidly as the open-source community migrated from older hosting services, reaching one million users by 2010. The company raised venture funding at multi-billion-dollar valuations, expanded internationally, and kept a notably flat corporate culture for its early years. Microsoft announced its acquisition in June 2018 and completed it that October; GitHub continued to operate as a largely independent subsidiary.

Features

Core concepts include repositories, forking (copying another user's repository), pull requests (proposed changes reviewed and merged by maintainers), GitHub Actions for automation, GitHub Pages for static website hosting, and Gists for code snippets. Since 2021 GitHub has offered Copilot, an AI pair-programming assistant developed with OpenAI, which grew into a family of AI coding tools including chat and autonomous coding agents.

Criticism

GitHub has faced criticism and legal questions over training AI models on public code, over hosting controversial projects, and over compliance with sanctions and takedown demands in various countries, notably a 2021 decision to remove a tool used to circumvent censorship.
