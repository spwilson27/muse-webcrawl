sed ("stream editor") is a Unix utility that parses and transforms text, using a compact programming language developed by Lee E. McMahon of Bell Labs in 1973–1974, first appearing in Version 7 Unix. It reads input line by line, applies a series of editing commands — most commonly substitutions based on regular expressions — and writes the result to standard output, making it a core tool of Unix shell pipelines.

Usage

The best-known command is substitution: sed 's/old/new/g' replaces every occurrence of "old" with "new" on each line. Other commands delete (d), insert (i), append (a), print (p) and transliterate (y) text, and addresses select which lines commands apply to — line numbers or regex patterns. With the -n flag, sed suppresses automatic printing, a mode used for extraction tasks. GNU sed's -i option edits files in place.

Language and influence

Although usually used in one-liners, sed is Turing complete: it has two buffers (the pattern space and hold space), branching, and looping constructs, and enthusiasts have written interpreters and games in it. Its command syntax descends from the ed line editor, and it strongly influenced the later tools awk (1977) and Perl (1987), whose substitution syntax s/// is directly borrowed. POSIX standardises sed, and implementations ship with GNU/Linux, BSD and macOS systems.

Examples

sed -n '5,10p' file prints lines 5–10; sed '/^#/d' file removes comment lines; echo "hello world" | sed 's/world/sed/' outputs "hello sed".
