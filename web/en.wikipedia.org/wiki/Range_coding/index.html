Range coding

From Wikipedia, the free encyclopedia

Range coding is a form of entropy encoding used in lossless data compression. It is closely related to arithmetic coding and achieves essentially the same compression efficiency, but performs the computation with integer arithmetic on a "range" value rather than with the fractional interval arithmetic of the classical formulation.

Description

Like arithmetic coding, range coding represents an entire message as a sub-interval of [0, 1), narrowing the interval symbol by symbol according to each symbol's probability. In practice, implementations keep the current interval scaled to a fixed integer range (such as 32 bits). As the encoder processes symbols it repeatedly renormalises: when the top digits of the interval bounds agree, they can be output and the range rescaled, keeping numbers within machine word size. Range coding is often described as a byte-oriented reformulation, since renormalisation naturally emits whole bytes.

History and use

The method was described by G. Nigel N. Martin in 1979. Range coders are used in various compression schemes and libraries, sometimes as a patent-avoiding alternative to arithmetic coding, though both are now free of the historical patent concerns. Modern formats using range-coding-like entropy coders include the asymmetric numeral systems (ANS) family and the entropy coders in codecs such as VP9 and AV1, which are conceptually related.
