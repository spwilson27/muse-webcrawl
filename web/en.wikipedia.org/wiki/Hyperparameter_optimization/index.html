Hyperparameter optimization

Hyperparameter optimization or tuning is the problem of choosing a set of optimal hyperparameters for a learning algorithm. A hyperparameter is a parameter whose value is used to control the learning process, and its optimisation strongly affects the resulting model's performance.

Methods

Grid search exhaustively evaluates a manually specified set of values for each hyperparameter. Random search samples configurations at random and is often more efficient when only a few hyperparameters matter. Bayesian optimization builds a probabilistic surrogate model of performance and chooses the most promising configurations to evaluate next. Other approaches include gradient-based methods, evolutionary algorithms, and bandit-based methods such as Hyperband, which allocate resources adaptively and stop unpromising runs early.

Challenges

Each evaluation usually requires training a model, making optimisation expensive, especially for large neural networks. The search space can be high-dimensional and mixed (continuous, discrete and categorical variables), and care is needed to avoid overfitting the validation set through excessive tuning. Successive halving and multi-fidelity methods address the cost problem by first evaluating many configurations cheaply.

Software

Popular tools include Optuna, Ray Tune, Hyperopt, Keras Tuner and the hyperparameter search functions of scikit-learn (GridSearchCV and RandomizedSearchCV).
