Stockfish

Stockfish is a free and open-source chess engine, commonly considered the strongest in the world. It is available for various desktop and mobile platforms and can be used in chess software through the Universal Chess Interface (UCI). Stockfish has consistently ranked first or near first on most chess-engine rating lists and has won the Top Chess Engine Championship multiple times.

History

The program originated as a fork of another open-source engine, Glaurung, by Tord Romstad. Marco Costalba released the first version of Stockfish in November 2008; Romstad later joined the project. Development became a large community effort, coordinated through the Fishtest distributed testing framework, in which volunteers donate computing time to validate code changes with millions of test games. In 2020, Stockfish integrated an efficiently updatable neural network (NNUE) evaluation, a technique borrowed from shogi engines, which produced a large jump in playing strength. Later versions adopted larger networks trained on engine-generated data.

Features

Stockfish uses alpha–beta search with extensive pruning and extensions, bitboard board representation, and a hybrid evaluation combining handcrafted terms with the NNUE neural network. It supports multi-threaded parallel search, transposition tables, Syzygy tablebases, and the Chess960 (Fischer random chess) variant. Its strength on modern hardware exceeds that of any human player by a wide margin, and it is widely used for game analysis and opening preparation.

Software and derivatives

Stockfish is written in C++ and released under the GNU General Public License version 3. Derivatives and related projects have included Crystal, BrainFish, and numerous NNUE-based forks. The engine is bundled with many graphical interfaces, including those used for online play.
