Backend as a service

Backend as a service (BaaS), also known as mobile backend as a service (MBaaS), is a cloud computing service model in which developers outsource all the behind-the-scenes aspects of a web or mobile application so that they only have to write and maintain the frontend. The services provided include cloud storage, user authentication, database management, push notifications, remote updating and hosting, along with software development kits (SDKs) and API gateways that connect the application to them.

Overview

BaaS emerged in the early 2010s as mobile app development expanded and developers sought to avoid repeatedly building common server-side infrastructure. Providers such as Parse (acquired by Facebook in 2013 and later open-sourced), Firebase (acquired by Google in 2014), Supabase, AWS Amplify and Appwrite offer managed backends that scale automatically and are billed by usage.

Comparison with other models

BaaS differs from platform as a service (PaaS) in that it supplies application-specific backend functionality — databases, authentication and file storage exposed as APIs — rather than a general environment for deploying custom server code. It is closely related to serverless computing and function as a service (FaaS), which many BaaS offerings incorporate for custom logic.
