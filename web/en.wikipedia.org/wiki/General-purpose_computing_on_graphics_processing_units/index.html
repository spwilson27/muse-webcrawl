General-purpose computing on graphics processing units

General-purpose computing on graphics processing units (GPGPU, or less often GPGP) is the use of a graphics processing unit (GPU), which typically handles computation only for computer graphics, to perform computation in applications traditionally handled by the central processing unit (CPU). Because GPUs are massively parallel processors with thousands of arithmetic units optimized for throughput, they can accelerate data-parallel workloads — such as matrix operations, simulations, and machine learning — by orders of magnitude compared with general-purpose CPUs.

Modern GPUs contain thousands of cores suited to parallel computation

History

Researchers began exploiting programmable shaders for non-graphics computation in the early 2000s, expressing algorithms as texture operations despite awkward programming constraints. The field took off with NVIDIA's CUDA platform (2007), which exposed the GPU as a C-programmable parallel processor, followed by the vendor-independent OpenCL standard (2009) and APIs such as DirectCompute and Vulkan compute. Standard libraries and frameworks — cuBLAS, cuDNN, and later machine-learning libraries such as TensorFlow and PyTorch — made GPU acceleration mainstream in scientific computing and artificial intelligence.

Programming model

GPGPU programs typically consist of kernels: functions executed simultaneously by many threads organized into blocks and grids, each processing different data elements. Performance depends on keeping arithmetic units busy, coalescing memory accesses, and minimizing transfers between CPU (host) and GPU (device) memory. GPUs excel when the same operation is applied across large datasets (SIMT execution) but are less efficient for branchy, sequential code.

Applications

Applications include molecular dynamics, weather and fluid simulation, seismic processing, financial modeling, medical imaging, cryptography, video encoding, and the training of deep neural networks, where GPU (and later specialized tensor) acceleration underpins the modern deep-learning era in artificial intelligence.
