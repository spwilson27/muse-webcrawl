Synchronous dynamic random-access memory

Synchronous dynamic random-access memory (SDRAM) is a type of dynamic random-access memory (DRAM) whose operation is synchronized with an external clock signal supplied by the memory controller. Unlike asynchronous DRAM, SDRAM waits for clock edges before responding to control inputs, allowing pipelined operation and much higher effective bandwidth.

Operation

SDRAM organizes storage into multiple internal banks that can be activated and accessed in an interleaved fashion, hiding row-activation latency. Commands such as ACTIVE, READ, WRITE, PRECHARGE, and REFRESH are issued on clock edges, and burst transfers deliver consecutive locations after an initial CAS latency.

Generations

The original single data rate (SDR) SDRAM was standardized by JEDEC in the 1990s. DDR SDRAM (double data rate) doubled throughput by transferring on both clock edges, and successive generations — DDR2, DDR3, DDR4, and DDR5 — raised clock speeds and transfer rates while lowering voltage. SDRAM and its descendants became the standard main memory in computers and embedded systems.
