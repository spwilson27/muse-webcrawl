Bell numbers

In combinatorics, the Bell numbers count the number of partitions of a set — that is, the ways a set of n labelled elements can be divided into non-empty, unlabelled subsets. They are named after the mathematician Eric Temple Bell, who wrote about them in the 1930s.

Values

The Bell numbers, beginning with B0 = 1, run 1, 1, 2, 5, 15, 52, 203, 877, 4140, 21147, 115975, ... For example, a set of three elements has five partitions, so B3 = 5.

Recurrence

The Bell numbers satisfy the recurrence Bn+1 = Σk=0..n C(n, k) Bk: to count partitions of n+1 elements, choose which elements share a block with a fixed element, then partition the rest. They can also be computed with Bell's triangle (the Peirce triangle), in which each row begins with the last number of the previous row and each entry is the sum of the number to its left and the one above-left.

Generating functions and formulas

The exponential generating function of the Bell numbers is eex − 1. Dobinski's formula expresses Bn as (1/e) Σk≥0 kn/k!, connecting the sequence to moments of the Poisson distribution.

Applications

Bell numbers arise in counting set partitions, rhyming schemes, equivalence relations on finite sets, and in the combinatorics of moments and cumulants in probability theory.
