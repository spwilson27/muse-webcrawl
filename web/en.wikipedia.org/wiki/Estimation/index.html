Estimation

Estimation (or estimating) is the process of finding an estimate — an approximation reasonably close to an exact value that can be calculated or measured — or, in statistics, of using sample data to infer the value of an unknown population parameter. Estimation is fundamental to statistics, engineering, project management, and everyday reasoning.

Statistical estimation

In statistics, an estimator is a rule for calculating an estimate of a parameter (such as a population mean) from observed data; the numerical result for a particular sample is the estimate. In point estimation, a single value is produced, while interval estimation yields a range, such as a confidence interval, intended to contain the true parameter with a stated probability.

Desirable properties of estimators include unbiasedness (the expected value equals the true parameter), consistency (the estimate converges to the truth as sample size grows), and efficiency (low variance among unbiased estimators). Common methods include maximum likelihood estimation, the method of moments, and least squares. Bayesian estimation instead treats the parameter as a random variable and produces a posterior distribution, often summarised by a posterior mean or a credible interval.

Estimation theory

Estimation theory, applied extensively in signal processing and control engineering, deals with extracting parameter values from noisy measurements. Its classic tools include the Kalman filter for recursive estimation of the state of a dynamic system.

Everyday and project estimation

Outside statistics, estimation refers to approximate calculation — for example Fermi problems, in which an order-of-magnitude answer is derived from rough assumptions. In project management, estimation of cost, effort, and duration underlies scheduling and budgeting, and is subject to well-documented biases such as the planning fallacy, in which estimators systematically underestimate completion times.
