MapReduce

ParadigmDistributed computing, data-parallel processing
Designed byJeffrey Dean and Sanjay Ghemawat, Google
First described2004 (OSDI paper)
Notable implementationApache Hadoop

MapReduce is a programming model and an associated implementation for processing and generating big data sets with a parallel, distributed algorithm on a cluster. A MapReduce program is composed of a map procedure, which performs filtering and sorting (such as sorting students by first name into queues, one queue for each name), and a reduce method, which performs a summary operation (such as counting the number of students in each queue, yielding name frequencies).

Overview

The model is inspired by the map and reduce functions commonly used in functional programming. The framework takes care of partitioning the input data, scheduling the program's execution across a set of machines, handling machine failures, and managing the required inter-machine communication, allowing programmers without experience of parallel systems to use the resources of a large distributed system.

During the map phase, the input is split into chunks processed independently, each producing intermediate key–value pairs. The framework then shuffles and sorts these pairs, grouping values by key, and the reduce phase aggregates each group into output values. A classic example is counting word occurrences in a large corpus of documents.

History and implementations

Google's Jeffrey Dean and Sanjay Ghemawat described MapReduce in a 2004 paper, reporting its use in generating Google's search index. The open-source Apache Hadoop project reimplemented the model, with Hadoop MapReduce running on the Hadoop Distributed File System (HDFS), and became a standard tool in early big-data processing. Later systems such as Apache Spark improved on the model by supporting iterative and interactive workloads in memory, but MapReduce remains influential and widely used for batch jobs.
