Generic property

From Wikipedia, the free encyclopedia

In mathematics, a generic property is a property that holds for "almost all" or "typical" objects within a given class, where the precise meaning of "almost all" depends on the setting. The notion of genericity formalises the intuition that a property is normal or expected, and that objects failing to have it are exceptional or degenerate.

Definitions

Several distinct notions of genericity are used:

  • Topology (Baire category) — in a topological space, a property is generic if the set of objects having it contains a countable intersection of open dense sets (a dense Gδ set, called residual or comeagre). By the Baire category theorem, such a set is dense in any complete metric space, so a generic property holds for "topologically most" points.
  • Measure theory — a property holds generically if it holds almost everywhere, i.e. except on a set of measure zero. For example, almost all real numbers are irrational, and almost all are normal numbers (though this second fact is a theorem, not merely genericity).
  • Algebraic geometry — a property of points of an algebraic variety is generic if it holds on a nonempty Zariski open subset. For instance, a generic polynomial of degree n over the complex numbers has n distinct roots.

These notions can disagree: the rational numbers are dense (and in a naive sense "everywhere") but form a meagre set of measure zero, so irrationality is generic in both senses while rationality is generic in neither.

Examples

  • A generic smooth function has only nondegenerate critical points (Morse functions are dense among smooth functions).
  • A generic matrix over the real or complex numbers is invertible and has distinct eigenvalues.
  • A generic continuous function on [0, 1] is nowhere differentiable — the Banach–Mazurkiewicz theorem.
  • In dynamical systems, generic behaviour can be studied via typical orbits of a system.

Use in proofs

Genericity arguments establish existence results: to show that some object with a desired property exists, it suffices to prove the property is generic. The term is also used informally in physics and geometry — for example, "generic position" for configurations avoiding special coincidences, and in general relativity for conjectures about "generic" singularities and spacetimes.
