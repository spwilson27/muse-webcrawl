Online transaction processing

OLTP systems handle many short, concurrent transactions

Online transaction processing (OLTP) is a class of information systems that manage transaction-oriented applications, typically for data entry and retrieval in real time. OLTP systems power much of everyday commerce: airline reservations, bank ATM networks, point-of-sale systems, e-commerce checkouts, and order processing. They are characterised by large numbers of concurrent users issuing short, simple transactions that each read or modify a small amount of data and must complete in fractions of a second.

Characteristics

  • Short, atomic transactions — each transaction is an indivisible unit satisfying the ACID properties (atomicity, consistency, isolation, durability).
  • High concurrency — thousands of simultaneous users, coordinated by locking or multiversion concurrency control.
  • Current, detailed data — records reflect the present state of the business, updated continuously.
  • High availability — downtime directly halts commerce, so systems are engineered for reliability and fast recovery.

OLTP versus OLAP

OLTP is conventionally contrasted with online analytical processing (OLAP). OLTP databases are optimised for fast writes and point lookups on normalised schemas and hold current operational data; OLAP systems run long, complex queries over large volumes of historical, often denormalised data for reporting and analysis. Organisations typically replicate OLTP data into data warehouses or lakes for OLAP workloads so that analysis does not slow down operations.

Technology

Classic OLTP platforms include IBM's CICS and IMS on mainframes and relational databases such as Oracle, Microsoft SQL Server, PostgreSQL, and MySQL. Transaction monitors and, later, application servers coordinate distributed transactions using protocols such as two-phase commit. Modern systems may use in-memory databases and sharding to reach millions of transactions per second, benchmarked by the industry-standard TPC-C test administered by the Transaction Processing Performance Council.
