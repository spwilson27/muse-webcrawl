Tool-assisted speedrun

AbbreviationTAS
MethodEmulator savestates, frame advance, slow motion, input editing

A tool-assisted speedrun (or TAS) is a video game speedrun performed using an emulator's tools — savestates, slow motion, frame-by-frame advance and re-recording — to achieve a theoretically perfect playthrough beyond human reflexes. Rather than a competitive cheat, a TAS is generally understood as a demonstration of what is possible in a game under ideal execution; the input sequence, recorded as a file, can be replayed on the emulator (and in some cases on original hardware) to verify it.

Techniques

Authors build runs by advancing the emulation one frame at a time, trying inputs and rewinding with savestates whenever a better outcome is possible, sometimes analysing the game's code and random number generator ("luck manipulation") to force favourable events. Sub-frame and pixel-perfect techniques let TASes exploit glitches — sequence breaks, wrong warps, arbitrary code execution — that human runners later adopt or categorise separately.

Community

The community coalesced around sites such as TASVideos (founded as NESVideos in 2003), which judges submissions on entertainment as well as speed and publishes encoded movies for consoles from the NES to modern systems. Famous examples include an 11-minute completion of Super Mario Bros. 3 circulated in 2003 (revealed to be a TAS) and TASBot exhibitions at Games Done Quick charity marathons, where console-verified runs are replayed on original hardware. TASes of arcade games and of games such as Pokémon have achieved total control of the console to run arbitrary programs, including a chat-controlled Pong and Snake inside Pokémon Yellow.
