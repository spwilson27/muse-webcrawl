Second partial derivative test

A function of two variables may have a local maximum, a local minimum, or a saddle point at a critical point.

In mathematics, the second partial derivative test is a method in multivariable calculus used to determine whether a critical point of a function of several variables is a local minimum, a local maximum, or a saddle point.

The test for functions of two variables

Suppose f(x, y) is a differentiable real function of two variables whose second partial derivatives exist and are continuous in a neighbourhood of a critical point (x0, y0), where the first partial derivatives vanish. Define

D(x, y) = fxx(x, y) fyy(x, y) − ( fxy(x, y) )2

which is the determinant of the Hessian matrix of f. Then at the critical point:

  • If D > 0 and fxx > 0, the point is a local minimum.
  • If D > 0 and fxx < 0, the point is a local maximum.
  • If D < 0, the point is a saddle point (neither a maximum nor a minimum).
  • If D = 0, the test is inconclusive and higher-order analysis is needed.

Higher dimensions

For functions of n variables the test generalises through the Hessian matrix: at a critical point, if the Hessian is positive definite the point is a local minimum, if negative definite a local maximum, and if indefinite a saddle point. Definiteness can be checked by Sylvester's criterion using the signs of the leading principal minors. If the Hessian is only semidefinite, the test is inconclusive.

Relation to the single-variable test

The test is the multivariable analogue of the second derivative test for functions of one variable, in which the sign of f″(x) at a critical point distinguishes maxima from minima; in several variables curvature can differ in different directions, which is why a saddle — rising in one direction and falling in another — becomes possible.
