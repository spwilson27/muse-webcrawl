Separating hyperplane theorem


A hyperplane separating two disjoint convex sets (placeholder image)

In geometry, the separating hyperplane theorem is a result about disjoint convex sets in n-dimensional Euclidean space: if both sets are nonempty and disjoint, there exists a hyperplane that separates them, with each set lying in one of the closed half-spaces determined by the hyperplane. Under stronger hypotheses — for example, if one set is compact and the other closed — the separation can be strict.

Statement

Let A and B be two disjoint nonempty convex subsets of Rn. Then there exist a nonzero vector v and a real number c such that ⟨v, x⟩ ≥ c for all x in A and ⟨v, x⟩ ≤ c for all x in B. The theorem follows from, and is closely related to, the Hahn–Banach theorem in functional analysis, and versions hold in general topological vector spaces.

Applications

The theorem underlies Farkas's lemma and the duality theory of linear programming, provides the geometric intuition behind support vector machines in machine learning (where the separating hyperplane of maximum margin classifies data), and appears in mathematical economics in proofs connected with the fundamental theorems of welfare economics and separating equilibrium prices from production sets.
