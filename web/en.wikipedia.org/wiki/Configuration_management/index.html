Configuration management

Configuration management (CM) is the discipline of identifying, controlling, and verifying the configuration of a product or system throughout its life. Originating in United States defence procurement in the 1950s for complex weapons systems, it is now applied in systems engineering, software development, and IT infrastructure.

Elements

Classical configuration management comprises configuration identification (naming and versioning components and documents), change control (evaluating and approving modifications), configuration status accounting (recording the state of each item), and configuration audits (verifying that a delivered product matches its documentation). Authoritative baselines record an approved configuration at a point in time.

Software and IT

In software, configuration management overlaps with version control of source code and build artefacts. In IT operations, configuration-management tools such as Ansible, Puppet, Chef, and Terraform automate the provisioning and desired-state enforcement of servers and networks—sometimes called "infrastructure as code"—recording machines' settings in version-controlled repositories.

Standards

Key references include ANSI/EIA-649, ISO 10007, and the configuration-management processes within ITIL and ISO/IEC 20000 for IT service management.
