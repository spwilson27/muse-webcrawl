Lagrangian relaxation

Lagrangian relaxation
FieldMathematical optimization, operations research

Lagrangian relaxation is a relaxation method which approximates a difficult problem of constrained optimization by a simpler problem. A solution to the relaxed problem is an approximate solution to the original problem, and provides useful information.

The method penalizes violations of inequality constraints using a Lagrange multiplier, which imposes a cost on violations. These added costs are used instead of the strict inequality constraints in the optimization. In practice, this relaxed problem can often be solved more easily than the original problem.

Method

Given an integer programming problem of the form: maximize cTx subject to Ax ≤ b and Dx ≤ d, where the constraints Dx ≤ d are the "complicating" ones, Lagrangian relaxation removes those constraints from the feasible set and instead subtracts a penalty term λT(Dx − d) from the objective, for non-negative multipliers λ. The relaxed problem is easier — for example it may decompose into independent subproblems — and for any choice of multipliers its optimal value bounds the optimal value of the original problem.

The Lagrangian dual

Choosing the multipliers to make the bound as tight as possible is itself an optimization problem, called the Lagrangian dual. Because the bound is a concave but typically non-smooth function of the multipliers, subgradient methods are commonly used to solve the dual. The gap between the best dual bound and the optimum of the original problem is the Lagrangian duality gap; it is zero for convex problems satisfying constraint qualifications, but can be positive for integer programs.

Applications

Lagrangian relaxation is widely used in operations research: for the travelling salesman problem (the Held–Karp bound obtained from a minimum 1-tree relaxation), facility location, scheduling, vehicle routing, and network design. It is frequently embedded in branch-and-price and branch-and-bound algorithms, where it supplies strong bounds at each node.

History

The technique grew out of Lagrangian duality theory and was popularised for combinatorial optimization in the 1970s, notably by Held and Karp's work on the travelling salesman problem (1970–71) and Geoffrion's formalisation of Lagrangian relaxation for integer programming (1974).
