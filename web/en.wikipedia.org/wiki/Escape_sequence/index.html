Escape sequence

A terminal using ANSI escape sequences (image placeholder)

An escape sequence is a combination of characters which has a meaning other than the literal characters contained therein; it is marked by one or more preceding (or, rarely, trailing) characters that shift the interpretation, usually an escape character such as the ASCII escape (ESC, 0x1B) or, in many programming languages, the backslash.

In programming languages

In C and languages derived from it, escape sequences in string literals are introduced by a backslash: \n for newline, \t for tab, \\ for a literal backslash, \" for a double quote, and \xNN or \uNNNN for characters given by code point. These allow non-printing and otherwise hard-to-type characters to be embedded in source code.

In terminals

ANSI escape sequences, standardised in ANSI X3.64 and ECMA-48, allow control of cursor position, colour and text formatting on video terminals. They begin with ESC followed by a character such as [ (introducing a CSI sequence), e.g. ESC[31m sets red foreground text. Such sequences are widely used by Unix terminal emulators and command-line programs to produce coloured output and full-screen interfaces.

In data interchange

Escaping is also used so that data can contain characters that would otherwise act as delimiters: for example, in URLs, percent-encoding writes a character as %NN; in HTML, character references such as &amp; stand for the ampersand itself.
