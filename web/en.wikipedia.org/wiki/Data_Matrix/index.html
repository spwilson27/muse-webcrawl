Data Matrix

A Data Matrix is a two-dimensional barcode consisting of black and white cells arranged in a square or rectangular pattern, also known as a matrix code. Invented in 1994 by International Data Matrix, Inc., it has become one of the most common 2D symbologies for marking small items.

[ Hero image: A Data Matrix code encoding the text "Wikipedia" ]

Description

A Data Matrix symbol is identified by its L-shaped solid "finder pattern" along two adjacent borders and a "timing pattern" of alternating modules along the opposite borders, which together allow readers to locate and orient the symbol. Data is encoded in the remaining cells using the ECC 200 error-correction scheme based on Reed–Solomon codes, which can reconstruct the data even if up to about 30 per cent of the symbol is damaged.

Capacity and sizes

Symbols range from 10×10 to 144×144 modules. The largest symbol can store up to 2,335 alphanumeric characters, 3,116 numeric digits, or 1,555 bytes of binary data. Because of its high data density in a small footprint, Data Matrix is widely used for direct part marking in electronics, aerospace and medical-device manufacturing, where components are too small for conventional barcodes. It is also used on pharmaceutical packaging and, in several countries, on postage and parcel labels.

Standards

Data Matrix is standardised as ISO/IEC 16022. The GS1 variant, GS1 DataMatrix, encodes application identifiers used in supply-chain and healthcare product identification. The symbology is in the public domain and may be used free of licence fees.
