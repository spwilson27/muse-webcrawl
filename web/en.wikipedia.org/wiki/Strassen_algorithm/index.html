Strassen algorithm

In linear algebra, the Strassen algorithm, named after Volker Strassen, is an algorithm for matrix multiplication. It is faster than the standard matrix multiplication algorithm for large matrices, with a better asymptotic complexity, although the naive algorithm is often better for smaller matrices. The Strassen algorithm is slower in practice than the Coppersmith–Winograd-type "galactic algorithms" for the largest matrices, but it remains practical for matrices of moderate size.

Recursive block decomposition in Strassen's algorithm.

History

Volker Strassen published the algorithm in 1969, showing that the naive O(n3) algorithm was not optimal. The result surprised the mathematical community and began the research field of fast matrix multiplication. Subsequent work, beginning with the Coppersmith–Winograd algorithm (1987), reduced the exponent further, to below 2.38 by the 2020s.

Description

The algorithm divides each matrix into four blocks and computes the product using seven multiplications of blocks instead of the eight required by the naive block approach, at the cost of extra additions. Recursively applying this reduction gives a complexity of O(nlog2 7) ≈ O(n2.807). The seven products, conventionally denoted M1 through M7, are cleverly chosen linear combinations of the blocks of the two input matrices; the blocks of the result are then assembled from additions and subtractions of these products.

Complexity and practical use

Because of larger constant factors and numerical-stability considerations, Strassen's algorithm typically becomes faster than naive multiplication only for matrices above a certain size (often a few hundred rows). Implementations switch between Strassen recursion and the naive method at a crossover point tuned to the hardware.
