Windows NT

Windows NT is a family of operating systems developed by Microsoft, first released in 1993 as Windows NT 3.1. Designed as a portable, secure, multiprocessor-capable system independent of the DOS-based Windows line, NT became the foundation of all modern Microsoft operating systems: every consumer and server Windows release since Windows XP and Windows Server 2003 is built on the NT architecture.

Development

Microsoft hired Dave Cutler from DEC in 1988 to lead the project, originally conceived as "NT OS/2." After Windows 3.0's success, the project was redirected to a new Windows API, Win32. The initials "NT" were marketed as "New Technology," though Cutler later noted the name also referenced the N-Ten ("Northern Ten") emulator used in early development.

Architecture

NT uses a hybrid kernel with a hardware abstraction layer, supporting multiple processor architectures over its history, including x86, MIPS, Alpha, PowerPC, ARM, and x86-64. It introduced the NTFS file system, preemptive multitasking, a security model with access control lists, and support for multiple API personalities (Win32, POSIX, and OS/2 subsystems).

Versions

Major releases include NT 3.1 (1993), NT 3.5, NT 4.0 (1996), Windows 2000 (NT 5.0), Windows XP (NT 5.1), Windows Vista (NT 6.0), Windows 7, Windows 8, Windows 10 (NT 10.0), and Windows 11.
