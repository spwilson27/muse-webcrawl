Documentation

Documentation is any communicable material used to describe, explain, or instruct regarding some attributes of an object, system, or procedure. It ranges from paper manuals to digital help systems, API references, and internal records.

Types

Common forms include user documentation (manuals, tutorials, and online help aimed at end users), technical documentation (specifications, design documents, and test plans produced by engineers), and software documentation, which describes how a program works and how to use its interfaces — including API documentation generated from source code comments. Documentation science studies the organisation and retrieval of recorded information.

Producing documentation is the work of technical writers and is considered an integral part of product development, quality management, and regulatory compliance in fields from aviation to medicine.
