Wii Remote

Type: Motion controller / game controller

Manufacturer: Nintendo

Release date: November 19, 2006

The Wii Remote, also known colloquially as the Wiimote, is the primary game controller for Nintendo's Wii home video game console. An essential capability of the Wii Remote is its motion sensing capability, which allows a user to interact with and manipulate items on screen via motion, gesture recognition, and pointing, using an accelerometer and optical sensor technology. It is expandable by adding attachments.

The Wii Remote was announced at the Tokyo Game Show in September 2005. It received much attention due to its unique features, not supported by other gaming controllers. Nintendo's president Satoru Iwata described the controller as a way to expand the gaming audience, famously demonstrating how it could be used for games like tennis and fishing.

Design

The Wii Remote takes a one-handed remote control-based design instead of the traditional gamepad controllers of previous gaming consoles. This design was chosen so that motion sensing could be made more intuitive, as a remote design is meant to be more intuitive for pointing. Iwata has also stated that using the remote is intended to make it easier for a wider amount of people to play.

The controller measures 148 mm (5.8 in) long, 36.2 mm (1.43 in) wide, and 30.8 mm (1.21 in) thick. It communicates with the Wii console via Bluetooth and contains a 1 MB internal EEPROM memory chip, used to store up to 4000 characters of Mii data.

Motion sensing

The Wii Remote uses a constellation of infrared LEDs inside the Sensor Bar, placed above or below the television, together with an infrared camera in the tip of the controller to sense pointing position. An accelerometer inside the remote detects acceleration along three axes, allowing games to respond to tilting, shaking, and swinging motions. The combination enabled new styles of play across games such as Wii Sports.

Expansions

The Wii Remote features an expansion port at the bottom which allows additional controllers to be attached, such as the Nunchuk, which adds an analog stick and two trigger buttons, and the Classic Controller for more traditional games. The Wii MotionPlus accessory, released in 2009, added gyroscope sensors for more precise motion tracking and was later built into the Wii Remote Plus.

Reception and legacy

The Wii Remote was widely praised for broadening the appeal of video games to non-traditional audiences and is credited with popularizing motion-controlled gaming, influencing the PlayStation Move and the widespread use of gyroscopes in controllers and mobile devices.
