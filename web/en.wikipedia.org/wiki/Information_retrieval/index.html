Information retrieval

Information retrieval (IR) is the science and technology of obtaining information resources relevant to an information need from a collection of those resources. The classic IR task is document retrieval: given a user query, a system searches a collection and returns a ranked list of documents — the task performed by library catalogues, legal and news databases, and web search engines.

Models

Early systems used Boolean retrieval, returning documents that exactly match a logical query. Modern systems rank documents by estimated relevance using models such as the vector space model (documents and queries as weighted term vectors, commonly weighted by tf–idf), probabilistic models such as BM25, and language models. Large-scale web search added link analysis — most famously Google's PageRank — and learning-to-rank methods that combine many signals. More recently, dense vector ("neural") retrieval using text embeddings has complemented keyword matching.

Evaluation

Retrieval quality is measured with test collections (such as those from the TREC conferences) using metrics including precision (the fraction of retrieved documents that are relevant), recall (the fraction of relevant documents retrieved), and rank-sensitive measures such as mean average precision and nDCG. The field, founded in the 1950s by pioneers including Calvin Mooers (who coined the term), Hans Peter Luhn, and Gerard Salton, underlies today's search engines, recommender systems, and question-answering tools.

Related areas

Information retrieval overlaps with information science, database systems, natural language processing, and machine learning, and extends beyond text to image, audio, and multimedia retrieval.
