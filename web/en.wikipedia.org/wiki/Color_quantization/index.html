Color quantization or color image quantization is a process that reduces the number of distinct colors used in an image, usually with the intention that the new image should be as visually similar as possible to the original image. Computer algorithms to perform quantization on bitmaps have been studied since the 1970s. Color quantization is critical for displaying images with many colors on devices that can display only a limited number of colors, usually due to memory limitations, and enables efficient compression of certain types of images.

Background

Most computer graphic image formats support only a limited number of colors. For example, the GIF format supports at most 256 distinct colors per image (or per frame). Early computer displays similarly supported only indexed color modes with small palettes. When an image containing thousands or millions of true colors must be displayed or stored in such a format, a representative palette must be selected and each pixel mapped to the closest available palette entry.

Algorithms

Popularity algorithm

One of the earliest approaches, the popularity algorithm builds a fine histogram of the colors in the image and selects the most frequently occurring colors as the palette. It is fast but can produce poor results for images whose important colors are rare.

Median cut

The median cut algorithm, described by Paul Heckbert in 1982, recursively subdivides the color space. All pixels are placed in a single box in RGB space; the box is split along its longest axis at the median pixel value, and the process repeats until the desired number of boxes is reached. The average color of each box becomes a palette entry.

Octrees

Octree quantization (Gervautz and Purgathofer, 1988) builds a tree of depth up to eight, where each level corresponds to one bit of the red, green and blue components. Leaves accumulate pixel counts and average colors; when the number of leaves exceeds a limit, nodes are merged.

Clustering methods

Palette selection can also be treated as a clustering problem in color space, solved with k-means clustering or more sophisticated methods such as the approach of Orchard and Bouman, which uses binary splitting of color clusters based on their covariance.

Application to images

After a palette is chosen, each pixel is assigned the nearest palette color, typically measured by Euclidean distance in RGB or a perceptually uniform space. Because quantization introduces visible banding in smooth gradients, it is often combined with dithering, in which quantization error is diffused to neighboring pixels (Floyd–Steinberg dithering is the classic example), trading spatial resolution for smoother appearance.
