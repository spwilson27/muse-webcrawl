Personal information manager

A personal information manager (PIM) is a type of application software that functions as a personal organiser, helping users manage and synchronise personal data such as contacts, calendars, tasks, notes, and reminders.

History

The category emerged with early personal digital assistants (PDAs) in the 1980s and 1990s, such as the Psion Organiser and PalmPilot, whose core functions were address books and calendars synchronised with desktop software. Classic desktop PIMs include Lotus Organizer, Microsoft Outlook, and ACT!. The data handled by a PIM is sometimes called a personal information collection.

Functions and evolution

A modern PIM typically combines an address book, calendar with scheduling and alarms, a to-do list, notes, and often email (in which case the program overlaps with an email client). With smartphones and cloud services, these functions were absorbed into built-in apps and web services — Apple Contacts and Calendar, Google Calendar and Contacts — that synchronise continuously across devices using protocols such as CalDAV, CardDAV, and Exchange ActiveSync. PIM concepts also underpin personal knowledge management and "second brain" note-taking tools.
