cp (Unix)


Image placeholder: cp (Unix)

cp is a command in Unix and Unix-like operating systems used to copy files and directories. The name is short for "copy". It is specified by POSIX and is one of the core file-manipulation utilities alongside mv and rm.

Usage

The basic syntax is cp source destination to copy a file, or cp source... directory to copy one or more files into a directory. Common options include -r (or -R) for recursively copying directories, -i for interactive prompting before overwriting, -p to preserve timestamps and permissions, -a for archive mode, and -v for verbose output.

History

A copy command existed in early Unix from the first editions. The GNU version, part of coreutils, adds many extensions such as --parents and sparse-file handling.
