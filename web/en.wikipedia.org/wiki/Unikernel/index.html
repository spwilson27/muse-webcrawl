Unikernel

Unikernel
TypeLibrary operating system / single-address-space image
ExamplesMirageOS, Unikraft, IncludeOS, OSv

A unikernel is a type of specialised, single-address-space machine image constructed using library operating systems. In a unikernel, an application is compiled together with only the operating system components it requires, producing a small, sealed image that runs directly on a hypervisor or on bare hardware.

Because unused drivers, shells, and utilities are omitted, unikernels offer fast boot times, a small memory footprint, and a reduced attack surface compared with general-purpose operating systems.

History and examples

The unikernel approach grew out of research on library operating systems such as Exokernel and Nemesis in the 1990s, and was popularised in the 2010s by systems including MirageOS (written in OCaml), IncludeOS (C++), OSv, and Unikraft. Unikernels have been explored for cloud microservices, network functions, and edge computing, though debugging and observability remain challenges compared with conventional deployments.
