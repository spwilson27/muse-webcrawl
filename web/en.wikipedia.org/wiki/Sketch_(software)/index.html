Sketch (software)

Sketch
Developer: Sketch B.V.
Initial release: 7 September 2010
Platform: macOS
Type: Vector graphics editor / UI design

Sketch is a vector graphics editor for macOS developed by the Dutch company Sketch B.V. (formerly Bohemian Coding). Released in 2010, it is used primarily for designing user interfaces and user experiences for websites and mobile applications, and became one of the leading tools in digital product design during the 2010s.

Features

Sketch provides vector drawing tools, artboards sized to device screens, reusable symbols and styles, layout grids, and export of assets at multiple resolutions. Its workflow emphasised interface design rather than photo editing, in contrast to general-purpose tools such as Adobe Photoshop, which designers had previously adapted for UI work. A large ecosystem of plugins and integrations grew around the application. Sketch files use a proprietary format, though the format was later documented as JSON-based and opened for third-party tools.

History

Sketch won an Apple Design Award in 2012. As web-based collaborative competitors such as Figma grew in the late 2010s — offering Windows and browser support that the Mac-only Sketch lacked — Sketch added cloud collaboration features, a web app for sharing and commenting, and real-time co-editing. The company also moved from perpetual licences to a subscription model.
