QuickTime

Developer: Apple Inc.
Initial release: 2 December 1991
Platform: Mac OS / macOS; formerly Windows
Type: Multimedia framework
File format: QuickTime File Format (.mov)

QuickTime is a discontinued extensible multimedia architecture and framework created by Apple, capable of handling various formats of digital video, picture, sound, panoramic images, and interactivity. First released on 2 December 1991 as a Macintosh System 6 add-on, QuickTime pioneered desktop digital video and became the basis for the ISO MPEG-4 file format and for the MP4 container.

History

QuickTime 1.0 shipped in late 1991, playing tiny videos at 160×120 pixels on Macintosh computers. Successive versions added support for music and MIDI, text tracks, interactive "wired" sprites, streaming media (QuickTime Streaming Server, 1999), and the Sorenson Video codec that made movie trailers a popular early web attraction. QuickTime 6 (2002) added MPEG-4 support, and QuickTime 7 (2005) added H.264, accompanying the video iPod and iTunes Store video sales.

Components

The QuickTime ecosystem included the QuickTime Player application, the QuickTime browser plug-in, QuickTime Pro editing features, the QuickTime Streaming Server, and the Darwin Streaming Server open-source project. The QuickTime File Format (QTFF), with its atom-based structure, directly inspired the ISO base media file format used by MP4, 3GP, and HEIF files.

Decline and deprecation

With Mac OS X Snow Leopard (2009), Apple introduced QuickTime X, a new playback architecture, while QuickTime 7 persisted for legacy formats. Apple deprecated the QuickTime 7 APIs, ended Windows support in 2016 (after security vulnerabilities were disclosed and users were advised to uninstall QuickTime for Windows), and removed support for 32-bit codecs and the legacy framework in macOS Catalina (2019), completing the transition to AVFoundation.
