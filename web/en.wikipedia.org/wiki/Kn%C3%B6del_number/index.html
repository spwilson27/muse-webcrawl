Knödel number

In number theory, a Knödel number for a given positive integer n is a composite number m such that every i coprime to m satisfies am−n ≡ 1 (mod m) for all a coprime to m. In particular, for n = 1 the Knödel numbers are exactly the Carmichael numbers.

Definition

The concept is named after the Austrian mathematician Walter Knödel (1926–2018). For fixed n, the set of Knödel numbers generalizes familiar classes of pseudoprimes: the case n = 1 gives Carmichael numbers, n = 2 gives the so-called Dudeney numbers, and n = 3 the Sarrus numbers.

Examples

Knödel numbers for n = 1 begin 561, 1105, 1729, 2465, 2821, 6601, 8911, ... Those for n = 2 begin 6, 15, 21, 28, 42, 66, 78, 91, 105, ...
