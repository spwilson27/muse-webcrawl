ISO 9564 is an international standard for the management and security of personal identification numbers (PINs) in financial services. It specifies principles and techniques for protecting PINs during card-based transactions at ATMs and point-of-sale terminals, and for online PIN verification by card issuers.

Parts

  • ISO 9564-1 — Basic principles and requirements for PINs in card-based systems, including the approved PIN block formats.
  • ISO 9564-2 — Approved algorithms for PIN encipherment (historically centred on Triple DES, with migration to AES addressed in later work).
  • ISO 9564-3 — Requirements for offline PIN handling in ATMs and POS systems (chip-based offline PIN).
  • ISO 9564-4 — Requirements for PIN handling in eCommerce, including PINs entered on consumer devices.

PIN blocks

The standard defines formats for the PIN block, the encrypted representation of the PIN used in transaction messages. The widely used ISO Format 0 (equivalent to ANSI X9.8 format) XORs the PIN field with the card's Primary Account Number (PAN) field before Triple DES encryption. Format 3 adds random filler digits; Format 4, defined for AES encryption, uses two blocks and is the successor format for modern systems. Requirements cover PIN length (4 to 12 digits), encryption keys, key management and the rule that a PIN must never appear in clear text outside a tamper-resistant secure cryptoprocessor.
