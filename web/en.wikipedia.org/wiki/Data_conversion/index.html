Data conversion

Transforming data from one representation to another.

Data conversion is the conversion of computer data from one format to another. Throughout a computer environment, data is encoded in a variety of ways — in file formats, character encodings, database schemas and application-specific structures. Whenever data must be exchanged between systems or preserved over time, it may need to be converted, and such conversion can range from trivial (for example, converting a text file from one character encoding to another) to highly complex, involving intermediary formats and the loss or reinterpretation of information.

Lossless and lossy conversion

A conversion is lossless if all information in the source can be reconstructed from the result, as when a document is converted between two rich-text formats that support the same features. A conversion is lossy when the target format cannot express everything in the source: converting a 24-bit colour image to a 256-colour palette image discards colour information, and converting a formatted document to plain text discards all formatting.

Common examples

  • Character encoding conversion, e.g. from Latin-1 to UTF-8
  • Image, audio and video transcoding between formats and codecs
  • Unit conversion and number-format conversion (binary, decimal, hexadecimal)
  • Database migration between different database management systems
  • Serialization and deserialization in data interchange formats such as JSON and XML

Tools and accuracy

Because few formats map onto each other exactly, conversion software often makes simplifying assumptions, and validation is needed where accuracy matters, as in engineering or financial data. Specialist tools range from simple file converters to full extract–transform–load (ETL) pipelines used in data warehousing.
