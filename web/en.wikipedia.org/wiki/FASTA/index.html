FASTA format

In bioinformatics and biochemistry, the FASTA format is a text-based format for representing either nucleotide sequences or amino acid (protein) sequences, in which nucleotides or amino acids are represented using single-letter codes. The format allows for sequence names and comments to precede the sequences. It originated with the FASTA software package, a sequence-similarity searching program described by William R. Pearson and David J. Lipman in 1988, but has become a near-universal standard in the field.

Format

A sequence in FASTA format begins with a single-line description (header) starting with a ">" (greater-than) symbol, followed by one or more lines of sequence data. Sequence lines are typically wrapped at 60–80 characters.

>MCHU - Calmodulin - Human, rabbit, bovine, rat, and chicken
ADQLTEEQIAEFKEAFSLFDKDGDGTITTKELGTVMRSLGQNPTEAELQDMINEVDADGNGTID
FPEFLTMMARKMKDTDSEEEIREAFRVFDKDGNGYISAAELRHVMTNLGEKLTDEEVDEMIREA
DIDGDGQVNYEEFVQMMTAK*

Variants and use

Multi-FASTA files concatenate many records. Related conventions include FASTQ, which adds per-base quality scores and is the standard output of high-throughput sequencers. FASTA files are inputs for tools such as BLAST and for the original FASTA search programs (FASTA, SSEARCH, TFASTX and others), which use heuristics related to the Smith–Waterman algorithm to find similar sequences in databases.
