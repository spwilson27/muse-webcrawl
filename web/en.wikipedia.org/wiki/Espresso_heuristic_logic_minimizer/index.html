Espresso heuristic logic minimizer

The Espresso heuristic logic minimizer is a computer program for minimising Boolean functions in two-level sum-of-products form, used in the design of digital logic circuits. It was developed at the University of California, Berkeley, in the 1980s, succeeding the earlier MINI program and becoming a standard tool in electronic design automation.

Algorithm

Where the classic Quine–McCluskey algorithm finds an exact minimum but scales poorly, Espresso uses heuristic operations on a cover of the function — represented as a set of product terms (cubes). Its main loop repeatedly applies EXPAND (growing cubes to make them prime implicants), IRREDUNDANT (removing redundant cubes) and REDUCE (shrinking cubes to allow different expansions), iterating until the cover stops improving. The result is usually minimal or near-minimal but is produced far faster, for functions with many variables and outputs.

Use

Espresso became a component of widely used logic synthesis systems, including Berkeley's SIS, and its input/output format (a truth-table-like ".pla" format) remains in use. It handles multi-valued logic as well as plain Boolean functions, which made it useful for minimising state machines and programmable logic array (PLA) implementations.
