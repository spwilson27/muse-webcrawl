OBD-II PIDs

OBD-II PIDs (parameter IDs) are codes used to request specific data from a vehicle's on-board diagnostics system. Each PID identifies a measurement or status value — such as engine RPM, vehicle speed, or oxygen sensor voltage — that a scan tool can query from the engine control unit (ECU). The PIDs are defined in the SAE J1979 and ISO 15031 standards.

Modes

Requests are organised into diagnostic modes. Mode $01 returns current live data; Mode $02 returns freeze-frame data captured when a fault was stored; Mode $03 lists stored diagnostic trouble codes; Mode $04 clears codes and the malfunction indicator lamp; Mode $06 reports on-board monitoring test results; and Mode $09 returns vehicle information such as the VIN. Within Mode $01, early PIDs report supported functions: PID 00, for example, returns a bitmask of which of PIDs 01–20 the vehicle supports.

Examples

Common Mode $01 PIDs include 0C for engine speed (converted from two data bytes by dividing by four), 0D for vehicle speed in kilometres per hour, 05 for engine coolant temperature (byte value minus 40 °C), 0E for timing advance, 11 for absolute throttle position, and 2F for fuel tank level. Manufacturers may also implement proprietary PIDs beyond the standard set, accessible through enhanced diagnostics.
