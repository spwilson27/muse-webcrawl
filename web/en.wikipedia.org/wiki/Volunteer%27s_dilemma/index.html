Volunteer's dilemma

The volunteer's dilemma is a game in game theory that models a situation in which each player can either make a small sacrifice that benefits everybody, or wait in hope of benefiting from someone else's sacrifice. If nobody volunteers, everyone loses. The game was introduced by Andreas Diekmann in 1985.

The game

Each of N players chooses either to volunteer (cooperate) or to wait (defect). If at least one player volunteers, all players receive a benefit, but each volunteer pays a personal cost. If no one volunteers, nobody receives anything. Each individual therefore prefers that somebody else bear the cost.

Equilibria

The game has multiple asymmetric pure-strategy Nash equilibria, in which exactly one player volunteers, plus a symmetric mixed-strategy equilibrium in which each player volunteers with a probability that decreases as the group grows. This prediction formalises the bystander effect: the larger the group, the less likely any given individual is to act, and the chance that nobody acts can remain substantial.

Applications

The model has been applied to bystander intervention in emergencies, the provision of public goods, blood donation, and behaviour in organisations where a single volunteer can complete a task for a whole team.
