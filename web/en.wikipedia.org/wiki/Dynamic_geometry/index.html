Dynamic geometry

Dynamic geometry is the study and practice of geometry using interactive computer software — a dynamic geometry environment (DGE) — in which constructions can be dragged and manipulated while their geometric relationships are preserved. Points, lines and circles are defined by construction rules; when a free point is moved, all dependent objects update in real time.

Software

Pioneering programs include Cabri Geometry (1988) and The Geometer's Sketchpad (1991), which popularised dynamic geometry in schools. Later widely used environments include GeoGebra (which combines geometry with algebra and spreadsheets), Cinderella and the web-based Euclidea exercises. These tools let students test conjectures by dragging figures through many configurations, trace loci, and animate constructions.

Educational use

Dynamic geometry is extensively used in mathematics education because it shifts attention from static diagrams to invariants: properties that stay true under dragging are likely to be theorems, prompting learners to seek explanations and proofs. It also supports exploration of transformations, conic sections, and three-dimensional geometry in newer software.
