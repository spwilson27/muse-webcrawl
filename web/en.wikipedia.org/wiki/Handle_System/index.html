Handle System

The Handle System is a proprietary technical specification for assigning, managing, and resolving persistent identifiers for digital objects and other resources on the Internet. The protocols specified enable a distributed computer system to store identifiers (names, or handles) of resources and resolve those handles into the information necessary to locate, access, and otherwise make use of the resources.

Overview

The system was developed by Robert Kahn at the Corporation for National Research Initiatives (CNRI) as part of the Digital Object Architecture. A handle consists of a naming-authority prefix and a local suffix, separated by a slash — for example, 10.1000/182. The best-known application built on the Handle System is the Digital Object Identifier (DOI) system, whose handles all carry the "10" prefix.

Operation

Handles are resolved through a distributed global registry and local handle services; a public proxy (hdl.handle.net) allows resolution through ordinary web browsers. The system was designed so that identifiers remain stable even when the location or ownership of the identified object changes.
