Mach is a kernel developed at Carnegie Mellon University by Richard Rashid and Avadis Tevanian to support operating system research, primarily distributed and parallel computation. It is one of the earliest examples of a microkernel, and its design principles influenced a generation of operating systems, including the kernels underlying NeXTSTEP, macOS, iOS, and GNU Hurd.

The Mach microkernel provides a minimal set of core abstractions; most operating system services run in user space.

History

Development began in 1985 as a successor to the Accent kernel, also developed at Carnegie Mellon. The Mach project, funded in part by DARPA, sought to create a kernel that could run BSD Unix as an application while also supporting multiprocessor systems and distributed computing. Mach 3.0, released in the early 1990s, was the first version to separate the BSD compatibility code fully from the kernel itself, producing a true microkernel.

The project was later continued by the Open Software Foundation Research Institute and at the University of Utah as part of the Flux project. While research on Mach itself wound down, its commercial descendants proved enormously influential.

Design

Mach reduces the kernel to a small set of fundamental abstractions:

Tasks and threads. A task is an execution environment consisting of an address space and a set of port rights; a thread is a unit of execution within a task. This separation allows a single process to run many threads concurrently across multiple processors.

Ports and messages. All inter-process communication in Mach takes place by message passing through ports, which are protected message queues. A task holds rights to ports — receive, send, or send-once rights — and the kernel mediates every transfer, giving Mach a capability-like protection model.

Memory objects. Mach implements virtual memory in terms of memory objects, which can be backed by external pager tasks in user space. This made it possible to implement file systems, network buffering, and distributed shared memory outside the kernel.

Device and processor abstractions. Hardware is presented through device ports, and multiprocessor support is built into the basic scheduling model rather than bolted on.

Influence and derivatives

Avadis Tevanian carried Mach to NeXT, where it formed the core of NeXTSTEP together with BSD Unix code. When Apple acquired NeXT in 1997, that system became the basis of XNU, the hybrid kernel of macOS and iOS, which combines Mach with BSD components in a single kernel. GNU Hurd, the Free Software Foundation's kernel, is built on Mach (GNU Mach). The L4 microkernel family was designed partly in response to performance criticisms of Mach's message passing.

Criticism

Mach was criticized for the performance overhead of its IPC mechanism, especially on the hardware of its era, and for the complexity of implementing full Unix compatibility in user space. These critiques contributed to the debate between microkernel and monolithic kernel designs exemplified by the famous Tanenbaum–Torvalds exchange.
