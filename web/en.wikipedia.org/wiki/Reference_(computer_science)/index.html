Reference (computer science)

In computer science, a reference is a value that enables a program to indirectly access a particular datum, such as a variable's value or a record, in the computer's memory or in some other storage device. The reference is said to refer to the datum, and accessing the datum is called dereferencing the reference.

References and pointers

A reference is distinct from the datum itself and from a memory address: in many languages a pointer is a reference holding a raw address on which arithmetic may be performed, whereas a reference in languages such as C++ or Rust is an alias for an object with stronger guarantees — it is typically non-null, cannot be reseated, and is dereferenced implicitly. Java and C# references cannot be used for arithmetic and always refer to objects managed by a garbage collector.

Uses

References underlie data structures such as linked lists, trees and graphs, and mechanisms such as passing arguments by reference, symbolic links in file systems, and foreign keys in databases. They enable shared access and mutation of a single object from many places in a program.

Problems and safety

Faulty reference handling causes classic bugs: dangling references (pointing to deallocated memory), null dereferences, and memory leaks. Memory-safe languages address these with garbage collection, ownership and borrowing systems, or reference counting. A "weak reference" does not keep its referent alive, and is used in caches and observer patterns.
