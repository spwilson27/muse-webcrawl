Universal Coded Character Set

Standard
ISO/IEC 10646
Characters: over 149,000
Code space: 17 planes of 65,536

The Universal Coded Character Set (UCS), standardized as ISO/IEC 10646, is an international standard character set that aims to provide a unique numerical code for every character of every written language, past and present. Since 1991 its repertoire has been synchronized with the Unicode Standard.

Architecture

The UCS assigns each character a code point in the range U+0000 to U+10FFFF, divided into 17 planes of 65,536 code points each. The first plane, the Basic Multilingual Plane (BMP), contains most modern scripts; supplementary planes hold historic scripts and emoji. Characters are organized into blocks by script or function.

Encoding forms

Historically, UCS-2 encoded characters in two bytes (BMP only), while UCS-4 used four bytes for any character. These were largely superseded by the variable-length Unicode transformation formats UTF-8, UTF-16, and UTF-32, which ISO/IEC 10646 also describes.

Relation to Unicode

The Unicode Consortium and ISO/IEC JTC1/SC2/WG2 agreed in 1991 to maintain identical character repertoires and code points, so "the UCS" and "Unicode" code charts are effectively the same, though Unicode adds character properties and processing rules.
