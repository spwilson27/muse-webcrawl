Open Firmware

Developer: Mitch Bradley, Firmworks; Sun Microsystems

Standard: IEEE 1275-1994

Platforms: SPARC, PowerPC, ARM, x86

Type: Boot firmware

Open Firmware is a standard defining the interfaces of a computer firmware system, formerly known as OpenBoot, and is described by IEEE standard IEEE 1275-1994. It originated at Sun Microsystems, where it was known as OpenBoot, and has been used by vendors including Apple, IBM, ARM and Sun for boot firmware on SPARC, PowerPC and other machines.

Description

Open Firmware provides a processor-independent boot environment. It includes a Forth interpreter, allowing system administrators and developers to interact with hardware at the ok prompt, load and debug programs, and inspect a device tree that describes the system's hardware in a platform-neutral format.

Device drivers for Open Firmware can be written in FCode, a compiled form of Forth, stored on expansion cards; this allows a single driver to work on any Open Firmware platform regardless of CPU architecture. The firmware can load boot programs from disk, network, or other devices and passes the device tree to the operating system kernel.

History and use

The technology was developed by Mitch Bradley at Sun in the late 1980s. Apple used Open Firmware in its Power Macintosh line from the late 1990s until the transition to Intel processors in 2006, where its familiar Command-Option-O-F boot prompt allowed users to set boot variables such as boot-device stored in NVRAM. IBM used it on its Power Systems servers, and it powered the One Laptop per Child XO-1 laptop, in an open-source implementation called OpenFirmware written by Bradley.

Open Firmware has largely been supplanted by UEFI on modern personal computers, but remains in use on SPARC and Power platforms and in embedded systems. The coreboot project and various open implementations (such as OpenBIOS and SmartFirmware) carry on aspects of its design.
