Kernel principal component analysis

Kernel PCA can extract nonlinear structure from data

In the field of multivariate statistics, kernel principal component analysis (kernel PCA) is an extension of principal component analysis (PCA) using techniques of kernel methods. Using a kernel, the originally linear operations of PCA are performed in a reproducing kernel Hilbert space, allowing the method to extract nonlinear features from the data.

Background

PCA finds orthogonal directions of maximum variance in the data, but can only capture linear relationships. Kernel PCA, introduced by Schölkopf, Smola, and Müller in 1998, works by implicitly mapping data into a higher-dimensional feature space via a kernel function — the same "kernel trick" used in support vector machines — and then performing ordinary PCA there, using only inner products expressed through the kernel matrix.

Method

Given data points and a positive-definite kernel, one forms the centred Gram (kernel) matrix and computes its eigenvalues and eigenvectors. The principal components of a data point in feature space are obtained from the eigenvectors of the kernel matrix, without ever computing the feature map explicitly. Common kernel choices include the Gaussian (RBF) kernel and polynomial kernels; selecting the kernel and its parameters strongly affects the result.

Applications

Kernel PCA is used for nonlinear dimensionality reduction, feature extraction, denoising and novelty detection, and as a preprocessing step in machine learning pipelines.
