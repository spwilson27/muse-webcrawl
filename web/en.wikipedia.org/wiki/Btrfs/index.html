Btrfs (pronounced "b-tree F S", "butter F S", or "better F S") is a modern copy-on-write (CoW) file system for Linux. Announced by Chris Mason at Oracle in 2007 and merged into the Linux kernel in 2009, it was designed to add advanced features — pooling, snapshots, checksums and integrated multi-device spanning — while scaling to very large storage systems.

Features

Btrfs organises data in B-trees and supports online defragmentation and resizing, subvolumes, writable snapshots, data and metadata checksumming, transparent compression (zlib, LZO and Zstd), and built-in RAID 0, 1, 10 and (historically problematic) 5/6 modes. It has been the default file system of Fedora Workstation since Fedora 33 and is widely used in SUSE Linux Enterprise and openSUSE.

History

Red Hat deprecated Btrfs in RHEL in 2017 and later invested in alternatives, but development continued strongly at SUSE, Meta (Facebook) and elsewhere; Facebook deployed Btrfs widely in production. Ongoing work has included performance improvements and new features such as fs-verity support and encoded I/O.
