Bernoulli distribution

Bernoulli distribution
Parameters0 ≤ p ≤ 1 (success probability)
Supportk ∈ {0, 1}
PMFP(X = 1) = p; P(X = 0) = 1 − p
Meanp
Variancep(1 − p)
Named forJacob Bernoulli

In probability theory and statistics, the Bernoulli distribution, named after Swiss mathematician Jacob Bernoulli, is the discrete probability distribution of a random variable that takes the value 1 with probability p and the value 0 with probability 1 − p. It models a single experiment — a Bernoulli trial — that asks a yes–no question, such as a single coin flip.

Properties

Formally, P(X = k) = pk(1 − p)1−k for k ∈ {0, 1}. The expected value is E[X] = p and the variance is Var(X) = p(1 − p), which is maximised at p = 1/2, where it equals 1/4. The skewness is (1 − 2p) / √(p(1−p)).

Related distributions

The Bernoulli distribution is a special case of the binomial distribution with n = 1: the number of successes in n independent Bernoulli trials with the same p follows a binomial distribution. The sum of two independent Bernoulli variables with parameters p and q follows a Poisson binomial distribution. The Bernoulli distribution is also the two-point distribution rescaled, and forms an exponential family with natural parameter log(p/(1 − p)) — the logit — linking it to logistic regression. The number of trials needed to obtain the first success is given by the geometric distribution.
