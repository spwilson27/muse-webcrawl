Vim (a contraction of Vi IMproved) is a free and open-source, screen-based text editor program. It is an improved clone of Bill Joy's vi, released by Bram Moolenaar in 1991. Vim is designed for use both from a command-line interface and as a standalone application in a graphical user interface, and it is known for its modal editing model and extensive customizability.

History

Vim's predecessor, a program called Stevie, was written for the Atari ST in 1987. Bram Moolenaar began work on Vim for the Amiga in 1988, basing it on Stevie, and made the first public release (Vim 1.14) in 1991. The name originally stood for "Vi IMitation" but was changed to "Vi IMproved" with the 2.0 release in 1993 as Vim gained features beyond vi. Moolenaar maintained Vim until his death in 2023; the project continues under community maintainership. A modern fork, Neovim, began in 2014.

Interface

Like vi, Vim's interface is based not on menus or icons but on commands given in a text user interface. Vim is modal: in normal mode, typed characters are commands that move the cursor or manipulate text, while insert mode is used for entering text. Operator–motion combinations (such as d for delete combined with a movement command) allow efficient editing, and macros, registers, marks, and undo trees support powerful workflows. Vim's GUI mode, gVim, adds menus and toolbars.

Customization and features

Vim is highly configurable through a .vimrc file and the Vim script language; many plugins and colour schemes are available. Features include syntax highlighting for hundreds of languages, split windows and tabs, integrated spell checking, code folding, diff mode, and a built-in tutorial (vimtutor). Vim source code is charityware: users are encouraged to donate to ICCF Holland, a charity supporting projects in Uganda.
