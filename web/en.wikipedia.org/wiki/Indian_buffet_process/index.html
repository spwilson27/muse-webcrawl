Indian buffet process

From Wikipedia, the free encyclopedia

In the mathematical theory of probability, the Indian buffet process (IBP) is a stochastic process that generates a random binary matrix with a countable number of columns (features) and a finite number of rows (objects), in which the number of non-zero entries in each row is drawn from a Poisson distribution. It was introduced by Thomas Griffiths and Zoubin Ghahramani in 2005 as the prior distribution used in nonparametric Bayesian latent feature models.

Metaphor

The process is described by an analogy with an Indian buffet restaurant with infinitely many dishes arranged in a line. The first customer takes a Poisson(α) number of dishes. Each subsequent customer n takes each previously sampled dish k with probability mk/n, where mk is the number of previous customers who took that dish, and then takes a further Poisson(α/n) number of new dishes. The resulting binary matrix records which customers sampled which dishes.

Probability model

The IBP defines an exchangeable distribution over binary matrices: the probability of any particular matrix depends only on the number of rows, the number of non-empty columns, and the column sums, up to a factor accounting for the ordering of the columns. Formally, the probability of a binary matrix Z with N rows and K non-zero columns is proportional to αK exp(−α HN) ∑ (N − mk)! (mk − 1)! / N!, where HN is the N-th harmonic number and the sum runs over columns. Matrices that differ only by a permutation of columns that preserves the binary history are considered equivalent, giving rise to the notion of the "lof" (left-ordered form) of a matrix.

Relation to other processes

The Indian buffet process is the feature-allocation analogue of the Chinese restaurant process, which gives a distribution over partitions (clusters) rather than features. It can be constructed as the limit of a finite model in which each object belongs to each of K features independently with probability α/K, as K tends to infinity. It is closely connected with the beta process, a completely random measure on the unit interval: if feature weights are drawn from a beta process, the Bernoulli process draws that generate the binary matrix yield the IBP as its marginal distribution.

Applications

The IBP is used as a prior in Bayesian nonparametric models where the number of latent features is unknown and is to be inferred from data, including infinite latent feature models for images, link prediction in networks, collaborative filtering, and sparse factor analysis. Inference is commonly performed with Gibbs sampling or variational methods.
