Principal component regression

Placeholder image: regression on principal component scores

In statistics, principal component regression (PCR) is a regression analysis technique based on principal component analysis (PCA). The method regresses the response variable on a subset of the principal components of the predictor variables, typically those with the largest eigenvalues, which can mitigate the effects of multicollinearity.

Overview

PCR proceeds in three steps: first, PCA is performed on the (usually standardised) design matrix; second, ordinary least squares regression is fitted using only the first k principal components as predictors; third, the resulting coefficients are transformed back into the space of the original variables. Because the principal components are mutually orthogonal, the regression is numerically stable even when the original predictors are highly correlated.

Use in chemometrics

PCR has been widely used in chemometrics and spectroscopy, where predictors are absorbance readings at hundreds of wavelengths. It is closely related to partial least squares regression, which instead chooses components that also maximise covariance with the response.

Properties

Unlike ridge regression, which shrinks all directions smoothly, PCR performs a hard selection of directions: components in the retained set are unshrunk, and the rest are discarded entirely. The choice of k is often made by cross-validation. A known caveat is that the highest-variance components need not be the most predictive, so the response-blind step of PCA can sometimes discard useful low-variance directions.
