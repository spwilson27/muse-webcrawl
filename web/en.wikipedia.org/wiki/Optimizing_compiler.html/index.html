Optimizing compiler

Diagram of a compiler's optimisation pipeline.

An optimizing compiler is a compiler designed to generate efficient object code by applying program transformations that improve performance — execution speed, memory usage or power consumption — without changing the program's observable behaviour.

Optimisations

Common optimisations include constant folding and propagation, dead-code elimination, common subexpression elimination, loop-invariant code motion, loop unrolling, inlining, register allocation and instruction scheduling. Optimisations are usually divided among the compiler's front end, middle end (on an intermediate representation) and back end (target-specific).

Trade-offs

Aggressive optimisation increases compile time and can complicate debugging; compilers therefore expose optimisation levels (such as GCC's -O0 through -O3 and -Os) so programmers can balance speed, size and debuggability.
