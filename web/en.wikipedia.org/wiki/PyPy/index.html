PyPy

PyPy is an alternative implementation of the Python programming language, known for its speed. It is a drop-in replacement for the reference implementation, CPython, for most pure-Python code, and features a just-in-time (JIT) compiler that can make many programs run several times faster than CPython.

Design

PyPy originated in 2003, partly with European Union funding, as a Python interpreter written in a restricted subset of Python itself called RPython. The RPython toolchain translates the interpreter to lower-level code and can automatically generate a tracing JIT compiler — an approach the project calls "meta-tracing". Because the language implementation is written in a high-level language, experimenting with new language features and garbage collection strategies is comparatively easy.

Compatibility

PyPy officially supports Python 2.7 and Python 3 versions (with its releases sometimes lagging the newest CPython series). Most pure-Python libraries work unchanged; packages relying on CPython extension modules can use the slower emulation layer ("cpyext") or may not work at all, though the ecosystem's shift to stable binary interfaces and projects like HPy have improved matters. PyPy's historical GIL and memory usage profiles differ somewhat from CPython's.
