Program analysis

In computer science, program analysis is the process of automatically analyzing the behavior of computer programs regarding properties such as correctness, robustness, safety, and performance. The two main approaches are static program analysis, performed without executing the program, and dynamic program analysis, performed during execution.

Static analysis

Static analysis techniques include abstract interpretation, data-flow analysis, control-flow analysis, and model checking. Tools based on these methods can detect bugs such as null-pointer dereferences, buffer overflows, and uninitialized variables before a program is run. Because of fundamental limits related to the halting problem and Rice's theorem, analyses are necessarily approximations that trade precision against soundness and performance.

Dynamic analysis

Dynamic analysis observes a running program, for example through instrumentation, profiling, or testing with sanitizers, to find memory errors, race conditions, and performance bottlenecks. It can only report on executions actually observed, so coverage is a key concern.

Applications

Program analysis is used in compilers for optimization, in software verification, in security auditing, and in integrated development environments that flag likely errors as code is written.
