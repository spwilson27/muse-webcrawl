Pumping lemma for context-free languages

From Wikipedia, the free encyclopedia

The pumping lemma for context-free languages, also known as the Bar-Hillel lemma after Yehoshua Bar-Hillel, Micha Perles, and Eliahu Shamir, is a tool for proving that a language is not context-free. It states that every context-free language L has a pumping length p such that any string s in L of length at least p can be divided into five parts, s = uvxyz, satisfying:

  1. |vy| > 0 (the pumped part is non-empty),
  2. |vxy| ≤ p (the pumped part lies within a bounded window),
  3. uvnxynz ∈ L for all n ≥ 0 (the v and y parts can be "pumped" in tandem any number of times).

Intuition and proof

Intuitively, a parse tree for a sufficiently long string must repeat some nonterminal on a root-to-leaf path (by the pigeonhole principle applied to the finite set of nonterminals of a grammar in Chomsky normal form). The two occurrences of that repeated nonterminal delimit subtrees whose yields are v and y, which can be replicated any number of times.

Use in proofs

The lemma is used in contrapositive form: to show a language is not context-free, one exhibits a long string and argues that no decomposition satisfying the three conditions exists. A classic example is the language { anbncn | n ≥ 0 }, which cannot be generated by a context-free grammar. The pumping lemma is necessary but not sufficient: Ogden's lemma strengthens it, and there are languages satisfying the lemma that are nonetheless not context-free (e.g. some shown via Parikh's theorem).
