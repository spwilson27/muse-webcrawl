In coding theory, Kraft's inequality gives a necessary and sufficient condition for the existence of a prefix code with given codeword lengths. It was published by Leon Kraft in 1949.

Statement

For a binary prefix code with codeword lengths l1, ..., lm, the sum Σ 2−li must be less than or equal to 1. Conversely, any set of lengths satisfying the inequality corresponds to some prefix code.

Applications

The inequality underlies the theory of lossless data compression: it constrains how short codewords can be, and it is used in proofs of the optimality of Huffman coding and of Shannon's source coding theorem. McMillan's inequality extends the result to all uniquely decodable codes.
