Jakarta EE

From Wikipedia, the free encyclopedia

Jakarta EE platform logo

Jakarta EE, formerly Java Platform, Enterprise Edition (Java EE) and J2EE, is a set of specifications extending Java SE with enterprise features such as distributed computing and web services. It provides APIs and a runtime environment for developing and running large-scale, multi-tiered, scalable and secure network applications, implemented by application servers such as WildFly, Payara, Apache TomEE and WebSphere Liberty.

History

Sun Microsystems introduced the platform as J2EE in 1999; it was renamed Java EE with version 5 (2006) and developed by Oracle through Java EE 8 (2017). In 2017–2019 Oracle transferred the technology to the Eclipse Foundation, where it was renamed Jakarta EE; because of trademark restrictions on the "Java" name, Jakarta EE 9 (2020) changed the API package namespace from javax.* to jakarta.*.

Specifications

Core specifications include Jakarta Servlet, Jakarta Server Pages, Jakarta RESTful Web Services, Jakarta Persistence, Jakarta Transactions, Jakarta Messaging, Jakarta Contexts and Dependency Injection, and Jakarta Security. Releases are overseen by the Jakarta EE Working Group at the Eclipse Foundation.
