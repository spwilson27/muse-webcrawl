Derangement

In combinatorial mathematics, a derangement is a permutation of the elements of a set in which no element appears in its original position. Such permutations are also called subfactorials; the number of derangements of a set of size n is written !n.

Counting derangements

The number of derangements satisfies the recurrence !n = (n − 1)(!(n − 1) + !(n − 2)), with !0 = 1 and !1 = 0, giving the sequence 1, 0, 1, 2, 9, 44, 265, ... for n = 0, 1, 2, 3, 4, 5, 6, .... By inclusion–exclusion, !n equals the nearest integer to n!/e, where e is Euler's number. Consequently, the probability that a random permutation is a derangement approaches 1/e ≈ 36.8% as n grows.

History

The problem was first posed by Pierre Raymond de Montmort in 1708 in the context of the card game jeu du rencontre (matching game): what is the probability that, in a deck of 13 cards drawn against a fixed order, no card matches its predicted position? Nicolaus Bernoulli and later Leonhard Euler developed the enumeration.

Examples and applications

The classic illustration is the "hat check problem": the probability that none of a set of guests receives back his or her own hat. Derangements also model the Secret Santa gift exchange, in which no participant may draw their own name, and appear in the analysis of algorithms and in rook theory.
