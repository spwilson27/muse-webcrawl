Wiki software

Type: Collaborative software

First released: 1995 (WikiWikiWeb)

Wiki software (also known as a wiki engine or wiki application) is collaborative software that runs a wiki, which allows users to create and collaboratively edit web pages using a web browser. A wiki system is usually a web application that runs on one or more web servers. The content, including previous revisions, is usually stored in a file system or a database.

History

The first generally recognised wiki application, WikiWikiWeb, was created by American computer programmer Ward Cunningham in 1994 and launched on his website in 1995. Cunningham chose the name "wiki", the Hawaiian word for "quick", reflecting the speed with which pages could be created and updated. The concept grew rapidly: clones of the original software appeared in many programming languages, and by 2001 the largest wiki, the English Wikipedia, was running on UseModWiki before moving to the purpose-built software that became MediaWiki.

Features

Common features of wiki software include a simplified markup language or WYSIWYG editor, page history and revision control, internal hyperlinking by page title, search, and access control ranging from fully public wikis to private intranet deployments. Modern engines support file uploads, templates, categories, discussion pages, and extensibility through plug-ins.

Notable implementations

Well-known wiki engines include MediaWiki, which powers Wikipedia and many other sites; DokuWiki and TWiki, popular in corporate settings; MoinMoin; and hosted services such as Confluence and Notion, which incorporate wiki-like collaborative editing into broader knowledge-management platforms.
