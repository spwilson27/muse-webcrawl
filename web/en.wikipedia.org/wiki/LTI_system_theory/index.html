LTI system theory

Linear time-invariant (LTI) system theory is a branch of applied mathematics and engineering that investigates the response of linear and time-invariant systems to arbitrary input signals. It is a foundational tool in signal processing, control theory, and circuit analysis, because any such system is completely characterized by its impulse response.

Overview

A system is linear if it obeys the principle of superposition: the response to a sum of inputs equals the sum of the responses, and scaling the input scales the output by the same factor. A system is time-invariant if a time shift of the input produces the same time shift of the output. When both properties hold, the output for any input is the convolution of the input with the system's impulse response h(t), written y(t) = (x * h)(t).

Frequency-domain analysis

Applying the Laplace transform (for continuous-time systems) or the Z-transform (for discrete-time systems) converts convolution into multiplication, yielding the transfer function H(s) = Y(s)/X(s). The poles and zeros of the transfer function determine stability and frequency response; a causal LTI system is stable exactly when all its poles lie in the left half of the s-plane (or inside the unit circle in the z-plane).

Applications

LTI models underpin filter design, feedback control, communications channel modeling, and the analysis of electrical networks and mechanical vibrations, and serve as local linear approximations of nonlinear systems.
