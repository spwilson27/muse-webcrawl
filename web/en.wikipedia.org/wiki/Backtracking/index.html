Backtracking is a class of algorithms for finding solutions to computational problems, notably constraint satisfaction problems, that incrementally builds candidates to the solution and abandons a candidate ("backtracks") as soon as it determines that the candidate cannot possibly be completed to a valid solution. The method amounts to a systematic depth-first search of a tree of partial solutions, pruning whole subtrees when a partial assignment already violates a constraint.

Description

A backtracking algorithm enumerates a set of partial candidates that, in principle, can be extended in several ways. At each step it chooses one extension, tests whether the resulting partial candidate can still lead to a solution, and recurses; when no extension works, it undoes the last choice and tries the next alternative. The computation can be pictured as traversing a rooted tree whose nodes are partial candidates and whose leaves include the complete solutions. Techniques such as constraint propagation, forward checking, choosing the most constrained variable first, and memoisation can dramatically reduce the search space.

Examples

Classic applications include solving the eight queens puzzle, Sudoku and other logic puzzles, generating permutations and combinations, parsing in compilers, regular-expression matching, and the DPLL and CDCL algorithms used in SAT solvers, which are sophisticated backtracking procedures with clause learning. Logic programming languages such as Prolog are built directly on backtracking: a query is resolved by searching for a proof, retreating to alternative clauses whenever a goal fails.

History

The term "backtrack" was coined by the American mathematician D. H. Lehmer in the 1950s. Early applications included maze-solving and games; the method was systematised in the 1960s and 1970s in works on combinatorial algorithms, notably by Solomon Golomb and Martin Gardner's popularisations, and it remains one of the standard paradigms taught in algorithm design alongside divide and conquer, dynamic programming, and greedy algorithms.
