FASTQ format

FASTQ format is a text-based format for storing both a biological sequence (usually a nucleotide sequence) and its corresponding quality scores. Both the sequence letter and quality score are each encoded with a single ASCII character for brevity. It was originally developed at the Wellcome Trust Sanger Institute to bundle a FASTA sequence with its quality data, and has become the de facto standard for storing output from high-throughput sequencing instruments such as Illumina genome analysers.

Format

A FASTQ file normally uses four lines per sequence:

@SEQ_ID
GATTTGGGGTTCAAAGCAGTATCGATCAAATAGTAAATCCATTTGTTCAACTCACAGTTT
+
!''*((((***+))%%%++)(%%%%).1***-+*''))**55CCF>>>>>CCCCCCC65

Line 1 begins with '@' followed by a sequence identifier; line 2 is the raw sequence; line 3 begins with '+' and optionally repeats the identifier; line 4 encodes the quality values for the sequence in line 2.

Quality encoding

Quality scores are Phred scores encoded as ASCII characters. Several variants exist: the original Sanger format (Phred+33), the Solexa format, and Illumina versions using Phred+64 offsets. Modern pipelines have largely converged on the Sanger Phred+33 encoding.

Files and compression

FASTQ files from whole-genome sequencing runs can be tens to hundreds of gigabytes, and are routinely stored gzip-compressed with the extension .fastq.gz. Related formats include SAM/BAM for aligned reads and FASTA for sequences without quality scores.
