Phased array

In antenna theory, a phased array is an electronically scanned array of antennas in which the relative phases of the signals feeding each element are varied so that the effective radiation pattern of the whole array is reinforced in a desired direction and suppressed in others — allowing the beam to be steered electronically without moving the antennas. Phased arrays were originally developed for radar and are now used in military radars (such as the Aegis SPY-1), weather radar, satellite communications, 5G base stations and handsets (millimetre-wave beamforming), radio astronomy, and medical ultrasound imaging.

Principle

Each radiating element emits (or receives) a signal; by applying a progressive phase shift across the elements, the wavefronts add constructively along a chosen angle and destructively elsewhere. Changing the phase shifts steers the beam in microseconds. In a passive electronically scanned array (PESA) a single transmitter feeds all elements; in an active electronically scanned array (AESA) every element has its own transmit/receive module, giving greater power, flexibility, and graceful degradation. Element spacing near half a wavelength avoids grating lobes.[1]

Applications

Large fixed phased arrays such as the U.S. PAVE PAWS ballistic-missile warning radars watch thousands of kilometres of space; shipborne AESA radars track hundreds of targets simultaneously. In acoustics, the same principle steers sonar beams and focuses diagnostic ultrasound, where phased-array probes sweep a sector image from a small footprint. Massive MIMO antennas in 5G networks are phased arrays that beamform to individual users.
