An autoencoder is a type of artificial neural network used to learn efficient codings of unlabeled data in an unsupervised manner. The network consists of an encoder, which compresses the input into a lower-dimensional latent representation (the bottleneck or code), and a decoder, which reconstructs the original input from that representation. Training minimises a reconstruction loss, forcing the network to capture the most salient features of the data rather than simply copying input to output.

Architecture and training

In the simplest form, both encoder and decoder are fully connected feedforward networks with one or more hidden layers. If the bottleneck is smaller than the input and only linear activations are used, the autoencoder learns the same subspace as principal component analysis (PCA). Non-linear activations allow more powerful compressions. Because the target output is the input itself, autoencoders are an example of self-supervised learning and require no labelled data.

Variants

Denoising autoencoders are trained to reconstruct clean inputs from artificially corrupted versions, learning robust features. Sparse autoencoders penalise the number of active bottleneck units to encourage useful structure. Contractive autoencoders penalise sensitivity of the code to small input changes. Variational autoencoders (VAEs), introduced by Kingma and Welling in 2013, learn a probabilistic latent space from which new samples can be drawn, making them generative models used for image synthesis and interpolation. Convolutional, recurrent and transformer-based autoencoders adapt the idea to images, sequences and text.

Applications

Autoencoders are used for dimensionality reduction and visualisation, data compression, image denoising, anomaly and fraud detection (inputs unlike the training data reconstruct poorly), feature learning for downstream tasks, and — in their variational form — as components of generative systems.
