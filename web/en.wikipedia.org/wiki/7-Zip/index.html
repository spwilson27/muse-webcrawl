7-Zip is a free and open-source file archiver, developed by Igor Pavlov and first released in 1999. It uses the native 7z archive format with the LZMA and LZMA2 compression algorithms, which typically achieve higher compression ratios than competing formats such as ZIP and RAR. 7-Zip also supports packing and unpacking many other formats, including ZIP, gzip, bzip2, xz, tar, and (for extraction only) RAR, ISO images, and numerous others.

Features

The program includes a graphical file manager for Windows, a command-line version, and shell integration. Archives in 7z format can be protected with strong AES-256 encryption, including encryption of file names. 7-Zip supports multi-threading, archives up to very large sizes, self-extracting archives, and splitting archives into volumes. Its p7zip and official CLI ports extend support to Unix-like systems.

Reception

7-Zip has been widely praised for its compression efficiency and was voted SourceForge's "Best Project" and received community awards; it became a standard utility in IT support and software distribution. The 7z format's LZMA SDK has been used in installers and other software.
