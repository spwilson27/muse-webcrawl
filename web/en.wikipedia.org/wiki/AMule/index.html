aMule

Initial release2003
Written inC++ (wxWidgets)
Operating systemCross-platform
TypePeer-to-peer file sharing
LicenseGPL

aMule is a free and open-source peer-to-peer file sharing application that works with the eDonkey network and the Kad network. It was forked from the xMule project in 2003, itself derived from the Linux port of the Windows eMule client, and shares a substantial part of its codebase and features with eMule.

Features

aMule supports the core eMule feature set: searching and downloading files over both server-based eDonkey and serverless Kad (Kademlia-based) networks, a credit system rewarding uploaders, source exchange between clients, and detection of corrupted parts via AICH hashes. Because it is built on the wxWidgets toolkit, it runs on Linux, Windows, macOS, BSD variants, and other systems.

Architecture

The project offers a modular design: a core daemon, amuled, can run headless on a server or low-power device, while graphical, web-based (amuleweb), and command-line front ends connect to it remotely. This separation distinguishes aMule from the monolithic eMule client.
