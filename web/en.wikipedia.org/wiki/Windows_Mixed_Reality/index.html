Windows Mixed Reality (WMR), formerly named Windows Holographic, is a mixed reality platform developed by Microsoft, built into Windows 10 and Windows 11. Announced in January 2015 alongside the HoloLens augmented reality headset, the platform was renamed Windows Mixed Reality in March 2017. It provided the operating system, spatial mapping and input APIs for HoloLens and for a range of PC-tethered virtual reality headsets manufactured by partners including Acer, ASUS, Dell, HP, Lenovo and Samsung.

Immersive headsets

The partner "immersive" headsets launched in late 2017 used inside-out tracking: cameras on the headset tracked its position in the room without external base stations, and tracked a pair of motion controllers. A defining feature was ease of setup compared with competing PC VR systems. Headsets ran the Mixed Reality Portal application, which rendered a virtual home (the "Cliff House") as the platform's shell and supported 2D Windows apps, 360-degree video, and games, including many titles through SteamVR compatibility.

HoloLens

Microsoft's own HoloLens (2016) and HoloLens 2 (2019) are self-contained augmented reality head-mounted displays running the same platform, with hand tracking, eye tracking, and enterprise and military applications (including the US Army's IVAS programme, which encountered difficulties). HoloLens devices emphasize holographic applications placed in the real world rather than fully immersive VR.

Discontinuation

Windows Mixed Reality never achieved a large consumer market share against Meta's Quest line and other platforms. In December 2023 Microsoft announced the deprecation of Windows Mixed Reality, with removal planned from a future Windows release; the platform no longer functions on Windows 11 version 24H2 and later. Microsoft also ended HoloLens 2 production, though it continued supporting existing devices.
