Rete algorithm

The Rete algorithm (usually pronounced "REET-ee", from the Latin rete for net, or network) is a pattern matching algorithm for implementing rule-based systems. The algorithm was developed by Charles Forgy of Carnegie Mellon University, first published in a working paper in 1974, later elaborated in his 1979 Ph.D. thesis and a 1982 paper.

Overview

A naive implementation of an expert system might check each rule against the known facts in a knowledge base, executing the rule if applicable, then perhaps re-checking all rules against the updated facts. This forward-chaining process can be highly inefficient, because most rules are unaffected by small changes to the fact base. The Rete algorithm overcomes this inefficiency by caching the results of partial matches in a network of nodes: when a fact is added or removed, only a small part of the network needs to be re-evaluated.

Network structure

The Rete network is a directed acyclic graph divided into an alpha network, which tests individual facts against constant conditions, and a beta network, which joins partial matches and checks variable consistency across conditions. Tokens representing partial matches propagate through the network, and complete matches reach terminal nodes corresponding to rules whose left-hand sides are satisfied.

Use

Rete and its successors (Rete II, Rete III, ReteNT) underlie many production rule engines, including CLIPS, Jess, Drools, and commercial systems derived from the OPS5 tradition.
