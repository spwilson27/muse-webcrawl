Macro (computer science)

In computer science, a macro is a rule or pattern that specifies how a certain input should be mapped to a replacement output. Applying a macro to an input is known as macro expansion. The input and output may be a sequence of lexical tokens or characters, or a syntax tree. Character macros are supported in software applications to make it easier to invoke common command sequences. Token and tree macros are supported in some programming languages to enable code reuse or to extend the language, sometimes for domain-specific languages.

History

The concept dates to assembly language programming in the 1950s, where a macro instruction expanded into a sequence of machine instructions, sparing programmers repetitive coding. Macro processors such as the C preprocessor (cpp) perform text substitution: #define directives create object-like and function-like macros expanded before compilation.

Types

  • Text (character) macros — simple string substitution, as in the C preprocessor and in m4.
  • Keyboard and application macros — recorded sequences of commands replayed to automate tasks in editors and office applications; in Microsoft Office, macros written in VBA were historically a vector for "macro viruses".
  • Syntactic macros — in Lisp and its dialects, macros operate on syntax trees and can implement new control structures; Scheme's syntax-rules system provides hygienic macros that avoid accidental variable capture. Rust and other languages offer hybrid systems.

Comparison with functions

Unlike a function call, which is evaluated at run time, macro expansion typically happens at compile time, producing code that is then compiled. This allows syntactic extension but can also duplicate code and make debugging harder, since errors are reported in the expanded output.
