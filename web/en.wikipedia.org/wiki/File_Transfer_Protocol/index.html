File Transfer Protocol

From Wikipedia, the free encyclopedia
File Transfer Protocol
AbbreviationFTP
Ports21 (control), 20 (data)
Original RFCRFC 114 (1971)
PurposeTransferring computer files
[Image: Screenshot-style image of a classic FTP client with local files on one side and a remote directory on the other]

The File Transfer Protocol (FTP) is a standard communication protocol used for the transfer of computer files from a server to a client on a computer network. FTP is built on a client–server model architecture using separate control and data connections between the client and the server.

FTP is one of the oldest Internet protocols: the first specification was written by Abhay Bhushan in 1971 for the ARPANET, and the protocol took essentially its modern form in RFC 959 (1985). A user connects to port 21, logs in (often anonymously, giving an email address as a password, in the era of open software archives), and issues text commands — LIST, RETR, STOR — while files flow over a second connection. Public FTP archives were the software libraries of the early Internet, and tools like Archie arose to search them.

FTP's weakness is that it was designed for a more trusting age: usernames, passwords and data cross the network unencrypted. Encrypted successors and alternatives — FTPS (FTP over TLS), SFTP (a different protocol riding on SSH), and above all HTTP downloads and cloud storage — displaced it, and web browsers dropped FTP support entirely in 2021. It survives in niches such as uploading files to web servers and moving data between institutional systems.
