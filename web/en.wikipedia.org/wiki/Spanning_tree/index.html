Spanning tree

A spanning tree (bold) of a grid graph

In the mathematical field of graph theory, a spanning tree T of an undirected graph G is a subgraph that is a tree which includes all of the vertices of G. A graph may have many spanning trees; a complete graph with n vertices has nn−2 of them, by Cayley's formula. Spanning trees are a basic tool in the design of networks, where a tree layout connects all nodes with the fewest possible links and no redundant cycles.

Minimum spanning trees

If each edge has a weight, a minimum spanning tree (MST) is a spanning tree of minimum total weight. Classic polynomial-time algorithms include Kruskal's algorithm and Prim's algorithm, both greedy, and Borůvka's algorithm (1926), the oldest of all, devised for planning Moravia's electrical network. Minimum spanning trees are used in network design, clustering, image segmentation, and approximation algorithms for problems such as the travelling salesman problem.

Counting and structure

Kirchhoff's matrix tree theorem (1847) computes the number of spanning trees of any graph from the eigenvalues (or a cofactor) of its Laplacian matrix. A spanning forest is the analogous construction for a disconnected graph: one spanning tree per connected component. Algorithms for depth-first search and breadth-first search each implicitly construct a spanning tree of the graph they explore.

Applications in computing

The term also names the Spanning Tree Protocol (IEEE 802.1D), invented by Radia Perlman, which prevents loops in bridged Ethernet networks by disabling redundant links into a logical spanning tree — a usage distinct from, but directly inspired by, the graph-theoretic concept.
