Windows Forms (WinForms) is a free and open-source graphical class library included as part of the Microsoft .NET Framework and .NET, providing a platform to write client applications for desktop, laptop, and tablet PCs. It offers a managed wrapper around the native Windows user interface elements of the Win32 API.

Architecture

A Windows Forms application is built around Form objects — windows — populated with controls such as buttons, text boxes, labels, and data grids. Interaction is handled through an event-driven model in which controls raise events (clicks, key presses) that application code handles. Visual Studio provides a drag-and-drop designer for laying out forms, and data binding connects controls to data sources with minimal code.

History

Windows Forms shipped with .NET Framework 1.0 in 2002 as the primary desktop UI framework, succeeding approaches based on MFC and Visual Basic forms. In 2006 Microsoft introduced Windows Presentation Foundation (WPF) as a more flexible successor, but WinForms remained widely used for business applications. Microsoft open-sourced Windows Forms in 2018, and it continues to be supported on modern .NET for Windows.
