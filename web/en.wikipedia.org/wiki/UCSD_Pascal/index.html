UCSD Pascal

UCSD Pascal is a Pascal programming language system that ran on the UCSD p-System, a portable, machine-independent operating system developed at the University of California, San Diego in the late 1970s. It was widely used in education and on early personal computers, notably the Apple II, where it was sold as Apple Pascal.

History

The project was led by Kenneth Bowles, who saw Pascal — designed by Niklaus Wirth for teaching structured programming — as a remedy for the software problems of the day. Compilers produced portable "p-code" for an abstract machine, so the same programs could run on many different computers once a small interpreter was ported. The system was a commercial and educational success around 1979–1983, running on machines including the Apple II, the DEC PDP-11, and the IBM PC.

Language extensions

UCSD Pascal extended standard Pascal with units for separate compilation, string handling, direct file access, and other practical features that were later widely adopted by other dialects, including Borland's Turbo Pascal.

Legacy

The p-System was an early and influential example of a virtual-machine platform, a concept later popularized by the Java virtual machine. UCSD Pascal dominated Pascal teaching in universities in the late 1970s and early 1980s before being displaced by other systems.
