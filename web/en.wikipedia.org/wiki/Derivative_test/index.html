Derivative test

In calculus, a derivative test uses the derivatives of a function to locate its critical points and to determine whether each point is a local maximum, a local minimum, or a saddle point (inflection). Derivative tests may also give a sense of the concavity of a function. The two standard tests are the first derivative test and the second derivative test.

First derivative test

Let f be a real-valued function of a real variable defined on some interval containing the point x0, and suppose the first derivative f′ exists on either side of x0 (a critical point, where f′(x0) = 0 or is undefined). Then:

  • If f′ changes sign from positive to negative at x0, f has a local maximum there.
  • If f′ changes sign from negative to positive, f has a local minimum there.
  • If f′ has the same sign on both sides, x0 is neither a maximum nor a minimum.

Second derivative test

If f is twice differentiable near a critical point c with f′(c) = 0, then:

f''(c) > 0  ⇒  local minimum at c
f''(c) < 0  ⇒  local maximum at c
f''(c) = 0  ⇒  test is inconclusive

The test follows from the fact that the second derivative measures concavity: positive second derivative means the graph is concave up, so a stationary point must be a minimum.

Higher-order tests

When the second derivative also vanishes, one may examine higher derivatives. The first non-zero derivative at the point after the first determines the outcome: if it is of even order, the point is an extremum (minimum if positive, maximum if negative); if of odd order, it is an inflection point.
