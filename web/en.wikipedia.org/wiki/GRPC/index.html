gRPC

gRPC is a cross-platform, open-source, high-performance remote procedure call (RPC) framework developed by Google. It was initially created by Google as the next generation of its internal RPC system, Stubby, and was announced and open-sourced in 2015. In 2017 it became a project of the Cloud Native Computing Foundation.

A gRPC client calls methods on a server across languages and platforms.

Overview

gRPC uses HTTP/2 as its transport protocol and Protocol Buffers as its default interface description language and serialization format, though other formats such as JSON can be used. Services are defined in .proto files, from which client and server code is generated for many languages, including C++, Java, Go, Python, C#, and Ruby.

Features

  • Unary and streaming RPCs: server streaming, client streaming, and bidirectional streaming
  • Pluggable authentication, load balancing, and health checking
  • Strongly typed contracts and code generation
  • Efficient binary serialization suited to microservices communication

gRPC is widely used for communication between microservices, and for connecting mobile and browser clients to backend services (the latter through gRPC-Web).
