Computer program

From Wikipedia, the free encyclopedia


Source code for a simple program in the C programming language

A computer program is a sequence or set of instructions in a programming language for a computer to execute. It is one component of software, which also includes documentation and other intangible components.

A computer program in its human-readable form is called source code. Source code needs another computer program to execute because computers can only execute their native machine instructions. Therefore, source code may be translated to machine instructions using a compiler, or executed directly with the aid of an interpreter, or it may be embedded in hardware.

History

The earliest theoretical work on programs dates to Ada Lovelace's notes on Charles Babbage's Analytical Engine in the 1840s, which described an algorithm for computing Bernoulli numbers. The first programs for stored-program computers were written in the late 1940s; the Manchester Baby ran the first stored program on 21 June 1948.

Programming

Computer programming is the process of writing, testing, and maintaining source code. Programs are written in programming languages such as C, Python, Java, and JavaScript. A short example in Python:

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

Execution

When a program runs, the operating system loads it into memory and the central processing unit executes its instructions one by one. Programs may be compiled ahead of time into machine code, interpreted at run time, or compiled just-in-time. Application software, system software, and embedded firmware are all forms of computer programs.
