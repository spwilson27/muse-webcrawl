Level set

In mathematics, a level set of a real-valued function f of n real variables is a set where the function takes on a given constant value c — that is, the set of all points { (x1, …, xn) | f(x1, …, xn) = c }.

When the number of independent variables is two, a level set is generically a curve and is known as a level curve, contour line, or isoline. Thus a level curve is the set of all real-valued solutions of an equation in two variables x1 and x2. When n = 3, a level set is called a level surface (or isosurface), and for higher values of n the level set is a level hypersurface.

Alternative names

Level sets show up in many applications, often under different names. For example, an implicit curve is a level set, which is independent of its neighbours — highlighting that a curve is described by many equations rather than a single one. Likewise, a surface defined by an equation is an implicit surface or an isosurface.

Names used in specific fields include:

  • Contour lines and isobars / isotherms in cartography and meteorology.
  • Indifference curves in economics, for utility functions.
  • Equipotential surfaces in physics, for potential fields.
  • Isosurfaces in medical imaging and scientific visualization.

Level sets and gradients

A key theorem states that where the gradient of f is nonzero, it is perpendicular to the level set of f at that point. Consequently, level sets never cross the direction of steepest ascent, a fact exploited by optimization methods such as Lagrange multipliers: at a constrained optimum, the level set of the objective is tangent to the constraint set.

Level set method

The level set method, developed by Stanley Osher and James Sethian in 1988, is a numerical framework for tracking moving interfaces. A surface is represented implicitly as the zero level set of a higher-dimensional function, allowing topological changes such as merging and breaking to be handled naturally. It is widely used in fluid dynamics, image segmentation, and computer graphics.
