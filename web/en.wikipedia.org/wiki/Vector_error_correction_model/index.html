Vector error correction model

A vector error correction model (VECM) is a multivariate time series model used in econometrics when the variables are non-stationary but cointegrated — that is, some linear combination of them is stationary. The VECM is a restricted form of a vector autoregression (VAR) that builds the long-run equilibrium relationships between the variables directly into the dynamics of the system.

Cointegrated series move together in the long run despite wandering individually.

Background

If two series are each integrated of order one, I(1), regressing one on the other can yield spurious results unless they are cointegrated. The Granger representation theorem, developed by Clive Granger and Robert Engle, shows that cointegrated variables can always be represented by an error correction model, and vice versa. Sargan had earlier introduced error correction in a single-equation setting, and Hendry popularised it.

Specification

For a vector yt of n I(1) variables, the VECM takes the form Δyt = Π yt−1 + Σ Γi Δyt−i + εt. The matrix Π captures the long-run relationships and can be decomposed as Π = αβ′, where β contains the cointegrating vectors (the equilibrium relationships β′y that are stationary) and α contains the adjustment (loading) coefficients measuring how fast each variable responds to last period's disequilibrium. The rank r of Π is the number of independent cointegrating relationships, with 0 < r < n in the interesting case.

Estimation

The standard estimation procedure is that of Søren Johansen, which uses maximum likelihood based on canonical correlations to determine the cointegration rank (tested with trace and maximum-eigenvalue statistics) and to estimate α and β. A two-step alternative, the Engle–Granger method, estimates the long-run relation by static regression first; it is simpler but less efficient in systems with multiple cointegrating vectors.

Applications

VECMs are widely used in macroeconomics and finance to model systems such as money demand, purchasing power parity, the term structure of interest rates, and price discovery between linked markets — wherever theory predicts a long-run equilibrium but short-run dynamics are flexible.
