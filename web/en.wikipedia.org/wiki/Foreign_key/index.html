Foreign key

From Wikipedia, the free encyclopedia

A foreign key is a set of attributes in a relational database table that refers to the primary key of another table, or to a set of attributes that can be uniquely identified in another table. The foreign key links the two tables by establishing a parent-child relationship: rows in the referencing (child) table must match a row in the referenced (parent) table.

Foreign keys are the mechanism by which referential integrity is enforced in a relational database. The database management system prevents any operation that would create a foreign key value with no corresponding primary key value in the referenced table.

Definition

Formally, a foreign key is a set of columns in one table whose values are required to match the values of a candidate key — usually the primary key — in another (or occasionally the same) table. A table may have multiple foreign keys, and each foreign key may reference a different table.

Example

Consider a database with a Department table, whose primary key is DepartmentID, and an Employee table. Each employee row may include a DepartmentID column declared as a foreign key referencing the Department table. This guarantees that every employee is assigned to a department that actually exists.

Referential actions

When a referenced row is updated or deleted, the database can take several actions on the referencing rows, specified when the constraint is declared: RESTRICT or NO ACTION forbids the change; CASCADE propagates the change to the child rows; SET NULL and SET DEFAULT replace the foreign key values with null or a default value.
