Controllability

Controllability is an important property of a control system and plays a crucial role in many control problems, such as the stabilisation of unstable systems by feedback, or optimal control. Controllability and the dual concept of observability were introduced by Rudolf E. Kálmán in the 1960s as part of the state-space approach to control theory.

Definition

Roughly, a system is controllable if it is possible, by means of an admissible control input, to steer the state of the system from any initial state to any desired final state within a finite time interval. For a linear time-invariant system with state equation ẋ = Ax + Bu, complete controllability is equivalent to the controllability matrix [B, AB, A²B, …, An−1B] having full rank n (Kalman's rank condition), or to the controllability Gramian being positive definite over any positive time interval.

Related notions

  • Reachability: the ability to reach a target state from the origin; for discrete-time systems and some continuous systems the notions differ subtly from controllability (steering to the origin).
  • Stabilisability: a weaker property requiring only that the uncontrollable modes be stable, so that feedback can still stabilise the system.
  • Output controllability: steering the output rather than the full state.
  • Structural controllability: controllability for almost all parameter values of a given system structure, a concept applied in network science to identify "driver nodes" in complex networks.

Tests

Besides Kalman's rank condition, the Popov–Belevitch–Hautus (PBH) test checks that no left eigenvector of A is orthogonal to B. Numerically, the singular values of the controllability Gramian indicate how controllable a system is: weakly controllable directions require large control energy, which matters in practice for actuator placement and model reduction.
