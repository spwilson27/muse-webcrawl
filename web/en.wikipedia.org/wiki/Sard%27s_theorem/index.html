Sard's theorem

Sard's theorem, also known as the Morse–Sard theorem, is a result in differential topology and mathematical analysis. It states that the set of critical values of a sufficiently smooth function between Euclidean spaces (or manifolds) has Lebesgue measure zero.

Statement

Let f : Rn → Rm be a function of class Ck with k ≥ max(n − m + 1, 1). A point x in the domain is a critical point if the Jacobian of f at x does not have full rank m. The image of the set of critical points — the set of critical values — has Lebesgue measure zero in Rm. Equivalently, almost every value of f is a regular value.

History

Anthony Morse proved a special case in 1939, and Arthur Sard proved the general statement in 1942. The theorem is fundamental in differential topology, where it underlies transversality arguments and the proof that generic smooth maps have well-behaved fibres.

Applications

Sard's theorem is used in the proof of the Brouwer fixed point theorem via smooth approximation, in Morse theory, and in establishing that the set of regular values is dense. Infinite-dimensional generalisations, such as the Smale–Sard theorem for Fredholm maps, play a role in gauge theory and the study of moduli spaces.
