Liquid Haskell

Type: Program verifier / type system extension

Host language: Haskell

Developed at: University of California, San Diego

Technique: Refinement types + SMT solving

Liquid Haskell is an extension of the Haskell programming language that adds refinement types, allowing programmers to specify fine-grained properties of values directly in types and to have those properties verified automatically at compile time. The name "Liquid" stands for Logically Qualified Data Types. Specifications are written as annotations in comments and are checked using an SMT solver such as Z3.

Overview

In Liquid Haskell, a refinement type annotates a basic type with a logical predicate over its values. For example, the type of positive integers can be written as {v:Int | v > 0}. The system can verify properties such as the absence of division by zero, array bounds safety, and sortedness of data structures, with counterexamples reported when verification fails. Liquid Haskell is implemented as a plugin to the Glasgow Haskell Compiler (GHC).

Applications

Liquid Haskell has been used to verify correctness properties of real-world Haskell libraries and systems code, and it is a prominent example of practical refinement-type systems used in software verification research.
