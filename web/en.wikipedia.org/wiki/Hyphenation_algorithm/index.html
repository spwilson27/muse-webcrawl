Hyphenation algorithm

A hyphenation algorithm is a set of rules, especially one codified in computer software, that decides at which points a word can be broken over two lines with a hyphen. Hyphenation is most often required when text is justified, as block justification stretches or compresses spaces between words; hyphenating long words at line ends produces more even spacing. Hyphenation algorithms operate either by consulting a dictionary of pre-hyphenated words or by applying pattern rules to find permissible break points, often falling back on an exception list for words the rules get wrong.

Liang's algorithm

The most widely used approach is the pattern-based algorithm developed by Franklin Mark Liang in his 1983 Stanford Ph.D. dissertation, implemented for TeX. It uses a set of hyphenation patterns — short substrings interleaved with digits indicating break desirability at each position — stored in a packed trie. For a given word, all patterns matching as substrings are overlaid, and at each inter-letter position the maximum digit found determines whether a break is allowed (odd values allow, even values forbid). The TeX English pattern set contains a few thousand patterns and, combined with a small exception dictionary, correctly hyphenates the great majority of words while occupying little memory.

Other approaches and use

Simpler rule-based systems rely on syllabification and morphology, which works well for languages with regular phonetic spelling. Liang's patterns have been adapted for many languages and are used, in adapted form, in OpenOffice/LibreOffice, web browsers (via CSS hyphens: auto), and the Hunspell ecosystem. In soft­ware, discretionary ("soft") hyphens (U+00AD) let documents mark preferred break points explicitly.
