Barabási–Albert model

The Barabási–Albert (BA) model is an algorithm for generating random scale-free networks using a preferential attachment mechanism. Proposed by Albert-László Barabási and Réka Albert in 1999, it explains how networks such as the World Wide Web, citation networks, and some social networks develop a power-law degree distribution with a few highly connected hubs.

Proposed1999
AuthorsAlbert-László Barabási, Réka Albert
MechanismGrowth + preferential attachment
Degree distributionPower law, exponent 3

The algorithm

The network starts with a small set of connected nodes. New nodes are added one at a time, each forming a fixed number of links. The probability that a new node connects to an existing node is proportional to that node's current degree — the "rich get richer" rule. The resulting degree distribution follows a power law with exponent 3.

Significance

The model demonstrated that scale-free structure can emerge from simple growth rules, shifting network science away from the purely random graphs of the Erdős–Rényi model. Variants adjust the exponent, add node fitness, ageing, or nonlinear attachment.

Limitations

The basic model produces little clustering and no community structure, so many extensions have been developed for realistic applications.
