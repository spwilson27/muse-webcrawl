Formal grammar

A formal grammar is a set of production rules that describe all possible strings in a given formal language. It consists of a set of nonterminal symbols, a set of terminal symbols, a finite set of production rules of the form in which a string containing at least one nonterminal is rewritten, and a distinguished start symbol. Starting from the start symbol and repeatedly applying the rules generates exactly the strings of the language.

Chomsky hierarchy

Noam Chomsky introduced a classification of grammars by the form of their productions, known as the Chomsky hierarchy:

  • Type-0 (unrestricted) grammars generate the recursively enumerable languages, recognizable by a Turing machine.
  • Type-1 (context-sensitive) grammars generate languages recognized by a linear bounded automaton.
  • Type-2 (context-free) grammars have rules in which a single nonterminal is replaced by any string; their languages are recognized by a pushdown automaton and underlie most programming-language syntax, specified in Backus–Naur form.
  • Type-3 (regular) grammars generate the regular languages, recognized by a finite automaton.

Applications

Formal grammars are foundational in theoretical computer science, compiler design (parsing), and computational linguistics, where generative grammar models the syntactic structure of natural languages. Formal grammars in a mathematical sense should be distinguished from informal descriptions of the grammar of natural languages ("the grammar of English").
