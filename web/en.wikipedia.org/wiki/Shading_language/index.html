Shading language

A shading language is a programming language used to write shader programs — short programs that compute the appearance of surfaces, vertices, or pixels in computer graphics rendering. Shading languages are typically designed for parallel execution on graphics processing units (GPUs) and expose vector and matrix types suited to graphics mathematics.

Types of shaders

  • Vertex shaders process each vertex, computing transformed positions and per-vertex data.
  • Fragment (pixel) shaders compute the colour of each fragment, sampling textures and applying lighting models.
  • Geometry and tessellation shaders generate or subdivide geometry on the GPU.
  • Compute shaders run general-purpose parallel computation.

Notable languages

  • GLSL (OpenGL Shading Language) — the C-like language of OpenGL and WebGL.
  • HLSL (High-Level Shader Language) — Microsoft's language for Direct3D.
  • RenderMan Shading Language (RSL) — Pixar's pioneering language for offline film rendering.
  • Cg — NVIDIA's earlier cross-platform language, largely superseded.
  • OSL (Open Shading Language) — for physically based offline rendering.
  • WGSL — the shading language of WebGPU.
  • SPIR-V — though an intermediate representation rather than a source language, it is the common compilation target in the Vulkan ecosystem.

History

The concept originates with Robert Cook's shade trees and the RenderMan system in the 1980s, which made surface appearance programmable in film production. Programmable hardware shaders arrived in consumer graphics around 2001, and high-level shading languages quickly replaced assembly-level shader programming.
