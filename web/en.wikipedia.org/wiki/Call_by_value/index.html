Call by value

Call by value (also called pass by value) is the most common evaluation strategy in programming languages, in which the argument expression of a function call is evaluated and the resulting value is bound to the corresponding parameter variable in the function. If the value is a copy, changes made to the parameter inside the function do not affect the caller's argument.

Semantics

Under call by value, the argument is evaluated completely before the call, and the function receives a value in its own local variable. This contrasts with call by reference, where the parameter is an alias for the caller's variable, and with call by name, where the argument expression is re-evaluated at each use.

Language examples

C, Java and Python use call-by-value semantics (Java and Python passing references to objects by value — sometimes called "call by sharing"). A consequence is that swapping two variables inside a function cannot work in pure call by value unless the values themselves are mutable objects reachable through the copied reference.

Advantages and drawbacks

Call by value is simple to reason about and avoids surprising side effects, but copying large structures can be costly, which is why many languages pass references or pointers behind the scenes while preserving value-like semantics.
