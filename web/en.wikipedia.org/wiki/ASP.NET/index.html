ASP.NET is a server-side web-application framework designed for web development to produce dynamic web pages. It was developed by Microsoft to allow programmers to build dynamic web sites, applications and services. The name stands for Active Server Pages Network Enabled Technologies.

History

ASP.NET was first released in January 2002 with version 1.0 of the .NET Framework and is the successor to Microsoft's Active Server Pages (ASP) technology. It is built on the Common Language Runtime (CLR), allowing programmers to write ASP.NET code using any supported .NET language.

Programming models

ASP.NET supports several programming models for building web applications: Web Forms, an event-driven model with server controls; ASP.NET MVC, a model–view–controller framework; ASP.NET Web Pages (Razor); and ASP.NET Web API for building HTTP services. In 2016 Microsoft released ASP.NET Core, a redesigned, cross-platform successor that runs on Windows, Linux, and macOS.
