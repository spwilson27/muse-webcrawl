Set cover problem

The set cover problem is a classical question in combinatorics, computer science, operations research and complexity theory. Given a set of elements (the universe) and a collection of sets whose union equals the universe, the problem is to identify the smallest sub-collection of sets whose union also equals the whole universe.

Complexity

The decision version of set cover is one of Karp's 21 NP-complete problems, shown to be NP-complete in 1972. The optimisation version is NP-hard. The natural greedy algorithm — repeatedly selecting the set that covers the most still-uncovered elements — achieves an approximation ratio of Hn (the nth harmonic number), which grows like ln n + 1. Results by Feige (1998) and later Dinur and Steurer (2014) show that this logarithmic factor is essentially optimal: no polynomial-time algorithm can do substantially better unless P = NP.

Formulations

Set cover can be formulated as an integer linear program: minimise the number (or total cost) of chosen sets subject to the constraint that every element belongs to at least one chosen set. Related variants include the weighted set cover problem, the maximum coverage problem (cover as many elements as possible with a fixed number of sets) and hitting set, which is equivalent by duality.

Applications

Set cover models problems such as placing the fewest facilities to serve all customers, selecting features in machine learning, crew scheduling, and choosing tests to cover software code paths.
