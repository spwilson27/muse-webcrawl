The Geʻez script, also known as Ethiopic, is an abugida used to write several languages of Ethiopia and Eritrea. It originated as an abjad (consonant-only alphabet) in the 4th century AD, derived from the South Arabian script, and evolved into an abugida in which each symbol represents a consonant–vowel syllable, with systematic modifications of a base glyph for each of seven vowel orders.

Structure

The core script has 26 consonantal characters, each appearing in seven forms (orders) according to the vowel that follows. Additional characters exist for labialized consonants and, in Amharic usage, a set of letters for sounds not present in classical Geʻez. Word separation was originally marked by two dots; modern punctuation largely follows European norms.

Usage

Today the script is the official writing system for Amharic and Tigrinya and is used liturgically for Geʻez. It is encoded in Unicode as the Ethiopic blocks.
