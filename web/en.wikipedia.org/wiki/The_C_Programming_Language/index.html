The C Programming Language

Authors: Brian W. Kernighan, Dennis M. Ritchie
Publisher: Prentice Hall
First edition: 1978
Second edition: 1988

The C Programming Language is a computer programming book written by Brian Kernighan and Dennis Ritchie, the latter the original developer of the C programming language. First published in 1978, it is widely regarded as the definitive and most influential book on C and the model for technical writing about programming. It is colloquially known as "K&R."

Contents

The book presents C through a tutorial progression — beginning with the famous "hello, world" example — followed by chapters on types, operators, control flow, functions, pointers and arrays, structures, input and output, and the UNIX system interface, concluding with a reference manual. Its terse, example-driven style set a standard that later language books imitated.

Editions and influence

The first edition described the pre-standard version of C, which came to be called "K&R C." The second edition (1988) was revised to cover the ANSI C standard (C89) and remains in print. The "hello, world" convention introduced in the book — itself adapted from an earlier Kernighan tutorial for the B language — has become a near-universal tradition for introducing a programming language.
