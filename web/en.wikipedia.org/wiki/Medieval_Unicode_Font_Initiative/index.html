Medieval Unicode Font Initiative

Medieval abbreviation signs and letterforms covered by the MUFI recommendation

The Medieval Unicode Font Initiative (MUFI) is a project founded in 2001 by a group of scholars of medieval texts, coordinated at the University of Bergen, to standardise the encoding of special characters used in medieval European manuscripts that are not adequately covered by the Unicode standard. MUFI publishes a character recommendation specifying which characters should be used for transcribing medieval texts, combining existing Unicode code points with characters assigned to the Private Use Area.

Purpose

Medieval Latin and vernacular manuscripts use many letterforms, ligatures, superscript letters, punctuation marks, and abbreviation signs that have no direct equivalent in modern typography. Before MUFI, individual projects and fonts each used the Unicode Private Use Area differently, making texts incompatible between projects. MUFI provides a common recommendation so that digital editions of medieval texts can be exchanged and searched reliably.

Recommendations and fonts

The MUFI character recommendation, most recently issued in version 4.0, lists several hundred characters with recommended code points and glyphs. Where characters have since been added to Unicode itself, MUFI aligns its recommendation with the standard; remaining characters are placed in the Private Use Area in coordination with the Unicode roadmap. Several fonts implement the recommendation, including Junicode (developed by Peter S. Baker), Andron, and Cardo. Over the years a number of characters first used under MUFI conventions — particularly from Latin Extended-D and related blocks — have been formally encoded in Unicode.
