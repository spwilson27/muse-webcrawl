Architectural pattern

An architectural pattern is a general, reusable resolution of a commonly occurring problem in software architecture within a given context. Architectural patterns are similar to software design patterns but have a broader scope. In other words, an architectural pattern is a fundamental structural organisation schema for software systems. It provides a set of predefined subsystems, specifies their responsibilities, and includes rules and guidelines for organising the relationships between them.

Definition

Architectural patterns address various issues in software engineering, such as computer hardware performance limitations, high availability and minimisation of business risk. Some architectural patterns have been implemented within software frameworks. The use of architectural patterns is a systematic way of organising code; patterns reflect the overall structure of a system rather than the details of individual modules.

Examples

Layered pattern

The layered pattern organises a system into layers of functionality, each providing services to the layer above it. It is used for general desktop applications, e-commerce web applications, and other systems where separation of concerns and ease of maintenance matter.

Client–server pattern

The client–server pattern consists of two parties: a server and multiple clients. The server component provides services, and client components consume them, as in online applications such as email, document sharing and banking.

Model–view–controller

The model–view–controller (MVC) pattern separates an interactive application into the model (core functionality and data), the view (display of information) and the controller (input handling).

Other patterns

  • Master–slave pattern
  • Pipe–filter pattern
  • Broker pattern
  • Peer-to-peer pattern
  • Event-bus pattern

  • Microservices pattern

Comparison with design patterns

Architectural patterns are broader than design patterns: a design pattern addresses a recurring design problem within a subsystem or module, whereas an architectural pattern shapes the structure of the whole system. A single architecture may combine several architectural patterns, and each pattern may be realised with many design patterns.
