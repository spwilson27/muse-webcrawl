Active Directory (AD) is the directory service developed by Microsoft for Windows domain networks. It is included in most Windows Server operating systems as a set of processes and services. Active Directory stores information about objects on the network — users, groups, computers, printers, and shared resources — and provides authentication and authorisation through mechanisms such as Kerberos single sign-on and Group Policy.

Structure

Objects are organised into a hierarchical structure of domains, grouped into trees and forests; a forest is the top-level security and replication boundary. Within domains, objects can be arranged in organisational units (OUs). Every object is described by attributes defined in a schema, and the data are replicated between domain controllers using multi-master replication, so changes can be made on any controller.

Services

The umbrella has covered several related services over time: Active Directory Domain Services (AD DS), the core directory; Lightweight Directory Services (AD LDS); Certificate Services (AD CS), a public key infrastructure; Federation Services (AD FS), for claims-based single sign-on; and Rights Management Services (AD RMS). The cloud counterpart is Microsoft Entra ID (formerly Azure Active Directory).

Protocols and operation

Clients locate services through DNS SRV records, query the directory with LDAP, and authenticate with Kerberos v5 (falling back to NTLM). Group Policy Objects let administrators centrally configure user and computer settings, deploy software, and enforce security baselines. Because of its central role in enterprise networks, Active Directory is also a prime target of cyberattacks, and attacks abusing Kerberos features (such as "Kerberoasting" and golden tickets) are a major focus of network defence.
