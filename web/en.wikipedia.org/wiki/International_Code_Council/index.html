International Code Council

The ICC develops the model building codes used throughout the United States and in other countries.

The International Code Council (ICC) is an American nonprofit standards organization that develops model building codes and standards used in the design, construction, and compliance process of buildings. It was founded in 1994 and is headquartered in Washington, D.C.

History

The ICC was formed by the merger of three regional model code organizations: the Building Officials and Code Administrators International (BOCA), the International Conference of Building Officials (ICBO), and the Southern Building Code Congress International (SBCCI). Each had published its own regional codes — the National Building Code, the Uniform Building Code, and the Standard Building Code respectively. The first edition of the ICC's unified International Building Code was published in 2000, replacing the three legacy codes in most jurisdictions.

The I-Codes

The ICC publishes a family of model codes known as the I-Codes, updated on a three-year cycle through a governmental consensus process in which code officials and other stakeholders vote on proposed changes. The family includes:

  • International Building Code (IBC)
  • International Residential Code (IRC)
  • International Fire Code (IFC)
  • International Plumbing Code (IPC)
  • International Mechanical Code (IMC)
  • International Energy Conservation Code (IECC)
  • International Existing Building Code (IEBC)

I-Codes are adopted, often with local amendments, by states and municipalities across the United States and serve as references in a number of other countries. The ICC also provides certification of code officials and inspectors, product evaluation services, and training.
