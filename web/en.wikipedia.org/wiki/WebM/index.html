WebM is an open, royalty-free media file format designed for the web. It was introduced by Google at the Google I/O conference in May 2010, together with the release of the VP8 video codec as open source following Google's acquisition of On2 Technologies. WebM files consist of video streams compressed with VP8, VP9, or AV1, audio streams compressed with Vorbis or Opus, and a container based on a profile of the Matroska format.

History and adoption

WebM was created as part of the HTML5 video effort to give web developers a royalty-free alternative to H.264. YouTube began supporting WebM uploads in 2011, and the format is natively supported by Chrome, Firefox, Edge, Opera, and Safari (Safari added support for WebM in 2021). The format is widely used for short video clips, animations, and web video delivery, and its AV1-based profile is increasingly used for streaming because of its improved compression efficiency.

Technical details

WebM's container restricts the full Matroska feature set to a profile suited to web playback, simplifying implementation. Files carry the .webm extension and the MIME type video/webm (audio-only WebM uses audio/webm). The project is maintained by Google and the open-source community, with reference implementations in the libvpx and libaom codec libraries.
