Network layer

The network layer is the third layer of the seven-layer OSI model of computer networking, and the layer responsible for packet forwarding through intermediate routers. Whereas the data link layer delivers frames between nodes on the same link, the network layer moves packets across multiple networks from source to destination — a function called routing — and provides a logical addressing scheme that identifies endpoints independently of their physical location.

Functions

  • Logical addressing — assigning addresses (such as IP addresses) that identify hosts across an internetwork.
  • Routing and forwarding — selecting paths through the network and moving packets along them, hop by hop, according to forwarding tables built by routing protocols.
  • Fragmentation — splitting packets when an outgoing link's maximum transmission unit is smaller than the packet (in IPv4; in IPv6 fragmentation is performed only by the source).
  • Internetworking and diagnostics — interconnecting dissimilar networks and providing error reporting, as with ICMP.

Protocols

The dominant network-layer protocol is the Internet Protocol, in its versions IPv4 and IPv6. Supporting protocols include ICMP (and ICMPv6) for error messages and neighbour discovery, and routing protocols such as OSPF and BGP. In the Internet protocol suite, the equivalent is called the internet layer. Historically, other suites — IPX, AppleTalk, and X.25's packet layer — also implemented network-layer functions.

Relation to other layers

The network layer offers a connectionless, best-effort datagram service to the transport layer above it (layer 4, home of TCP and UDP), relying on end systems for reliability. Below it, the data link layer (layer 2) handles delivery across each individual link, resolving network-layer addresses to link-layer addresses (for example, ARP for IPv4).
