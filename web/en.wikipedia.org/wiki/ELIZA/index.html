ELIZA

ELIZA
Author: Joseph Weizenbaum
Released: 1966, MIT
Type: Early chatbot

ELIZA is an early natural language processing computer program created by Joseph Weizenbaum at MIT between 1964 and 1966. It simulated conversation using pattern matching and substitution, most famously in its DOCTOR script, which parodied a Rogerian psychotherapist.

How it worked

ELIZA scanned user input for keywords, ranked them, and transformed the input using decomposition and reassembly rules — for example turning "I am sad" into a question about being sad. It had no genuine understanding of language or context.

Impact

Weizenbaum was alarmed that users, including his own secretary, attributed human understanding and emotion to the program — a response now called the ELIZA effect. The program influenced early computer games and chatterbots, and Weizenbaum's later book Computer Power and Human Reason (1976) warned against treating computers as human judges.
