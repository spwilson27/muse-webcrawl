General Packet Radio Service (GPRS), also called 2.5G, is a packet oriented mobile data standard on the 2G cellular communication network's global system for mobile communications (GSM). GPRS was established by the European Telecommunications Standards Institute (ETSI) in response to the earlier CDPD and i-mode packet-switched cellular technologies. It is now maintained by the 3rd Generation Partnership Project (3GPP).

GPRS extends the GSM circuit-switched domain with a new packet-switched domain, allowing "always on" data connectivity and charging by volume of data transferred rather than connection time. It integrates mobility management and session management functions and offers data rates theoretically up to 171.2 kbit/s when all eight time slots of a GSM carrier are used, though typical real-world rates were far lower.

Technical overview

The GPRS core network has two main new elements: the Serving GPRS Support Node (SGSN) and the Gateway GPRS Support Node (GGSN). The SGSN tracks the location of mobile stations and handles security and access control, while the GGSN acts as the interface to external packet data networks such as the Internet. Data is carried through the network in tunnels established using the GPRS Tunnelling Protocol (GTP).

Services

GPRS enabled services such as multimedia messaging (MMS), wireless application protocol (WAP) browsing, email, and early mobile internet access. It provided the data bearer over which many early smartphone applications operated before the widespread deployment of 3G networks.

Evolution

The enhanced data rates for GSM evolution (EDGE) standard built on GPRS by introducing new modulation, roughly tripling data rates; GPRS enhanced with EDGE is sometimes called EGPRS or 2.75G. Later technologies such as UMTS, HSPA and LTE supplanted GPRS in most markets, though as of the early 2020s some operators continued to run GPRS for machine-to-machine applications.
