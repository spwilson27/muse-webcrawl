Cross compiler

FieldComputer science, software development
HostThe platform on which the compiler runs
TargetThe platform for which code is generated
Common usesEmbedded systems, operating system development, bootstrapping

A cross compiler is a compiler capable of creating executable code for a platform other than the one on which the compiler itself is running. The machine running the compiler is called the host, and the machine for which code is produced is the target. This contrasts with a native compiler, which generates code for the same platform it runs on.

Uses

Cross compilation is essential in embedded systems development, where the target device (a microcontroller or single-board computer) may lack the memory, storage, or processing power to run a compiler. It is also used to bootstrap new platforms: the first compiler for a new architecture must necessarily be a cross compiler built on an existing system. Operating system and kernel developers routinely cross-compile, and large software projects use cross compilation to produce binaries for multiple architectures from a single build server.

Toolchains

A cross-compilation environment, or toolchain, includes the compiler, assembler, linker, and libraries built for the target. Tools such as GCC can be configured for cross compilation, and projects like crosstool-NG and the GNU build system's "Canadian cross" terminology (build, host, and target machines) help manage the complexity. Challenges include correctly configuring the target's ABI, endianness, floating-point support, and C library (such as glibc, musl, or newlib).
