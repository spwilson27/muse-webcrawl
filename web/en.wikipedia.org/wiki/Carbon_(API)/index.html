Carbon (API)

From Wikipedia, the free encyclopedia

Carbon was one of Apple Inc.'s C-based application programming interfaces (APIs) for the Macintosh operating system. Introduced with Mac OS 8 and central to Mac OS X, Carbon provided a route for classic Mac OS applications to run natively on Mac OS X with relatively modest changes, in parallel with the Objective-C Cocoa API inherited from NeXTSTEP.

History

At the 1997 Worldwide Developers Conference, Apple cancelled its failing Copland operating system project and announced a strategy built on the NeXT acquisition. To reassure developers of classic Mac OS software, Apple created the "Carbon" specification: a cleaned-up subset of the classic Macintosh Toolbox that would be implemented as a native library on both Mac OS 8/9 (via CarbonLib) and Mac OS X. Developers could "carbonize" applications by removing obsolete calls and recompiling; Adobe Photoshop and Microsoft Office were among the major packages that reached Mac OS X by this route.

Architecture

Carbon combined low-level services (the Core Foundation layer, file and memory management) with the HIToolbox human-interface APIs for windows, menus and controls. Mac OS X's Carbon implementation sat alongside Cocoa and the kernel environment, allowing Carbon and Cocoa applications to share the Aqua interface and many system services.

Deprecation

Carbon was never extended to 64-bit: at WWDC 2007 Apple announced that the 64-bit Mac OS X roadmap would be Cocoa-only, effectively ending Carbon's development. The 32-bit-only Carbon APIs limited applications such as iTunes and the Adobe suite until they were rewritten in Cocoa. macOS 10.15 Catalina (2019) removed support for 32-bit applications entirely, retiring Carbon in practice, though some Carbon-derived services (such as parts of Core Foundation) persist beneath modern frameworks.
