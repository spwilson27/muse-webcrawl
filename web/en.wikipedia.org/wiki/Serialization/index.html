Serialization

In computing, serialization is the process of translating a data structure or object state into a format that can be stored (for example, in a file or database) or transmitted (for example, over a network) and reconstructed later — possibly in a different computer environment. The reverse process is called deserialization.

Purposes

Serialization underlies persistence, remote procedure calls and distributed computing: objects can be saved between runs of a program, sent between machines with different architectures, or passed between processes. To be reconstructed correctly, the byte stream must capture the object's data and type information, and handle references, so that shared and cyclic structures survive the round trip (a process sometimes called marshalling).

Formats

Human-readable text formats include JSON, XML and YAML, widely used for configuration files and web APIs. Binary formats such as Protocol Buffers, Apache Thrift, MessagePack and language-specific mechanisms (Java's java.io.Serializable, Python's pickle module) trade readability for compactness and speed. Choice of format affects interoperability, versioning and schema evolution.

Security

Deserializing untrusted data is a well-known vulnerability class: maliciously crafted streams have led to remote code execution in many libraries and frameworks, so security guidance recommends integrity checks and avoiding native deserialization of untrusted input.
