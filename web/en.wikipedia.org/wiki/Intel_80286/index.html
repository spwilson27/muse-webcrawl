Intel 80286

The Intel 80286 (also marketed as the iAPX 286 and often called simply the 286) is a 16-bit microprocessor introduced by Intel on February 1, 1982. It was the first 8086-based processor with separate, non-multiplexed address and data buses, and the first with an on-chip memory management unit.

Features

The 80286 could address up to 16 MB of physical memory and 1 GB of virtual memory using its protected mode, which added memory protection and segmentation features. Typical clock speeds ranged from 6 to 12.5 MHz, with later versions reaching 25 MHz. In real mode it remained compatible with the earlier 8086 software.

Use

The 80286 powered IBM's PC/AT and many clones, and was widely used in the mid-to-late 1980s. Its protected mode was underexploited by DOS software because returning to real mode required a reset, a limitation addressed by the Intel 80386.
