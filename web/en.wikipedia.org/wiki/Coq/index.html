Coq

Coq is an interactive theorem prover first released in 1984. It allows the expression of mathematical assertions, mechanically checks proofs of these assertions, helps find formal proofs, and extracts a certified program from the constructive proof of its formal specification. Coq is developed by the French institute Inria and a large open-source community, and is written primarily in OCaml.

Overview

Coq is based on the calculus of inductive constructions, a derivative of the calculus of constructions with dependent types. Users state theorems in the specification language Gallina and prove them interactively using tactics; the system then checks the resulting proof terms with a small trusted kernel. Coq won the ACM SIGPLAN Programming Languages Software Award in 2013.

Notable formalisations

Major results formalised in Coq include the four color theorem (completed by Georges Gonthier in 2005), the Feit–Thompson odd order theorem (2012), the CompCert verified C compiler, and the seL4-style verification of software systems. In 2024–2025 the project announced a rename to Rocq, honouring both Inria's home at Rocquencourt and Thierry Coquand.
