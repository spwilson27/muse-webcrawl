NVMe

NVM Express (NVMe) or Non-Volatile Memory Host Controller Interface Specification (NVMHCIS) is an open, logical-device interface specification for accessing a computer's non-volatile storage media, usually solid-state drives (SSDs), attached via the PCI Express bus. NVMe was designed from the ground up to exploit the low latency and internal parallelism of flash memory, in contrast to the older AHCI interface, which was built for spinning hard disks.

Background

As SSDs became faster, the SATA interface and AHCI protocol became bottlenecks: AHCI supports a single command queue of 32 commands, while flash devices can service many operations in parallel. A working group of more than 90 companies, led by Intel engineer Amber Huffman, developed the new specification; the first NVMe specification was released in March 2011, and the standard is now maintained by NVM Express, Inc.

Key features

NVMe supports up to 65,535 I/O queues, each holding up to 65,536 commands, mapped to multiple processor cores to avoid locking. It has a streamlined command set requiring far fewer CPU cycles per I/O than AHCI, supports MSI-X interrupts and interrupt steering, and provides features for enterprise use including end-to-end data protection, namespaces, reservations, and — in later versions — Zoned Namespaces (ZNS) and flexible data placement. NVMe over Fabrics (NVMe-oF), released in 2016, extends the protocol across network fabrics such as Fibre Channel, Ethernet with RDMA or TCP, allowing remote flash to be accessed with minimal added latency.

Form factors and adoption

NVMe drives are sold as M.2 cards, U.2 and U.3 drives, add-in PCI Express cards, and the newer EDSFF (E1/E3) "ruler" formats for servers. NVMe is now the default interface for consumer and enterprise SSDs; successive PCIe generations have pushed sequential throughput beyond 14 GB/s per device with PCIe 5.0 drives.
