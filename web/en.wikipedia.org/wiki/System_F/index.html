System F (also known as the polymorphic lambda calculus or second-order lambda calculus) is a typed lambda calculus that extends the simply typed lambda calculus with universal quantification over types. It was discovered independently by the logician Jean-Yves Girard (1972) and the computer scientist John C. Reynolds (1974).

Overview

Whereas the simply typed lambda calculus has abstractions over values (terms of a given type), System F additionally has abstractions over types themselves. A polymorphic identity function, for instance, can be written Λα. λ(x : α). x, with type ∀α. α → α. The type constructor ∀ binds a type variable, much as λ binds a term variable.

Logic and computation

Under the Curry–Howard correspondence, System F corresponds to second-order intuitionistic logic: types are propositions, and the universal type quantifier corresponds to second-order quantification over propositions. Church encodings in System F can represent natural numbers, booleans, pairs and lists, and every type in the system has a normal form, reflecting its strong normalization property.

Variants and influence

Variants include System Fω, which adds type constructors of higher kind, and System F<:, which adds bounded quantification and underlies much of the theory of object-oriented type systems. System F has profoundly influenced the design of typed functional languages: the Hindley–Milner type system of ML is a restricted fragment, and Haskell, Scala and other languages implement extensions of it.
