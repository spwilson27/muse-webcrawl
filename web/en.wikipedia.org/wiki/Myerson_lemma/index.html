Myerson lemma

The lemma ties truthful payments to the allocation rule.

The Myerson lemma is a fundamental result in auction theory and mechanism design, due to Roger Myerson (1981). It characterises incentive-compatible (truthful) mechanisms in single-parameter environments — such as single-item auctions — in which each agent's private information is a single number, her value. The lemma states that an allocation rule can be implemented truthfully if and only if it is monotone, and that the payment rule is then essentially unique, given by an integral formula.

Statement

Let x(v) be the probability that an agent reporting value v receives the item. The lemma says:

  • Monotonicity: The allocation rule is implementable in dominant strategies if and only if x is non-decreasing in v — a higher bid never lowers the chance of winning.
  • Payment identity: If the agent with value 0 pays 0, then the expected payment of an agent with value v is p(v) = v·x(v) − ∫₀ᵛ x(z) dz.

For a deterministic allocation in which the agent wins exactly when her bid exceeds a threshold t, the formula reduces to the familiar rule that the winner pays the threshold — the smallest bid at which she would still have won. This is why, in a second-price auction, the winner pays the second-highest bid. Combined with the revenue equivalence theorem, the lemma underlies Myerson's celebrated result on optimal auctions, including "virtual value" maximisation and reserve prices.
