Glibc

The GNU C Library, commonly known as glibc, is the GNU Project's implementation of the C standard library. It provides the system call wrappers and basic functions such as open, read, write, malloc, printf, getaddrinfo and pthread facilities used by nearly all programs on GNU/Linux systems.

History

Glibc was originally written in the 1980s by Roland McGrath. The Free Software Foundation designated it the official C library for GNU systems. Linux distributions adopted it in the 1990s; a fork called Linux libc was briefly used before distributions switched back to glibc 2.x. Development was long led by Ulrich Drepper; since 2012 the project has been overseen by a community steering committee.

Features

Glibc implements the ISO C, POSIX and BSD interfaces, supports internationalization, name service switching (NSS), and dynamic linking through its loader (ld.so). It is released under the GNU Lesser General Public License. Alternatives for embedded systems include musl and uClibc-ng, which are smaller but less fully featured.
