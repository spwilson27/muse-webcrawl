Objective function

In mathematical optimization, an objective function — also called a loss function or cost function in some contexts — is a real-valued function of one or more decision variables whose value is to be either minimized or maximized, subject to a set of constraints that define the feasible region. The goal of an optimization problem is to find the feasible values of the variables that give the best (smallest or largest) value of the objective function.

Types of problems

When the objective function and the constraints are all linear, the problem is a linear program. Other important classes include quadratic programming, convex optimization, nonlinear programming and multi-objective optimization, in which several objective functions are traded off against one another. In machine learning, training a model typically amounts to minimizing a loss function that measures the discrepancy between the model's predictions and observed data.
