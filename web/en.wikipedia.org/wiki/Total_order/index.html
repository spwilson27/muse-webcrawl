Total order

In mathematics, a total order or linear order is a partial order in which any two elements are comparable. That is, a total order is a binary relation ≤ on some set X, which satisfies the following for all a, b and c in X:

  1. a ≤ a (reflexive).
  2. If a ≤ b and b ≤ c, then a ≤ c (transitive).
  3. If a ≤ b and b ≤ a, then a = b (antisymmetric).
  4. a ≤ b or b ≤ a (strongly connected, formerly called total).

A set equipped with a total order is called a totally ordered set, a linearly ordered set, or a chain.

Examples

  • The real numbers ordered by the usual ≤ (or <) are totally ordered, as are its subsets such as the integers and rational numbers.
  • The letters of the alphabet ordered lexicographically (dictionary order) form a chain.
  • Any subset of a totally ordered set is totally ordered for the restriction of the order.

Strict total orders

A strict total order on a set X is a strict partial order in which any two distinct elements are comparable; equivalently, an irreflexive, transitive, trichotomous relation. Each total order corresponds to a strict total order and vice versa.

Related concepts

A linear extension of a partial order is a total order compatible with it; every partial order has a linear extension (the order-extension principle). Total preorders relax antisymmetry, allowing distinct elements to be equivalent. In computer science, sorting algorithms produce total orders of lists, and total orders on data types underlie ordered data structures such as balanced search trees.
