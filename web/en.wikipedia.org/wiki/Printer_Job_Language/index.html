Printer Job Language

Printer Job Language (PJL)
Developer: Hewlett-Packard
Type: Printer control language

Printer Job Language (PJL) is a method developed by Hewlett-Packard for switching printer languages at the job level and for status readback between a printer and a host computer. PJL commands sit "above" the page description language of a job — such as PCL or PostScript — and control the job itself.

Functions

PJL allows applications to set job attributes such as the number of copies, the input tray, and finishing options; to select the printer language used for each job; and to receive status messages from the printer about job completion, errors, and device state. Commands begin with the Universal Exit Language sequence and are written in plain text.

Use

Although created by HP, PJL was adopted by many other printer manufacturers and became a de facto standard in network and office printing, complementing page description languages that handle only the content of pages.
