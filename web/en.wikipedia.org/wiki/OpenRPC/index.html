OpenRPC

OpenRPC is a specification and ecosystem for describing JSON-RPC application programming interfaces in a machine-readable document, analogous to what OpenAPI does for RESTful HTTP APIs. An OpenRPC document describes an API's methods, parameters, results, errors and examples, typically using JSON Schema for data types.

Purpose and tooling

Because the description is standardised, tools can generate client libraries, server stubs, documentation, mock servers and interactive playgrounds automatically. OpenRPC emerged from the Ethereum ecosystem, where JSON-RPC is the standard interface to blockchain nodes, and is stewarded as an open-source community project.

Structure

A document declares its version, API metadata, servers, and a list of methods with parameter and result schemas, plus reusable components. Methods can include summaries, descriptions, deprecation notices and content descriptors specifying parameter ordering (by-name or by-position).
