Counter machine

An abstract model of computation using natural-number counters.

A counter machine is an abstract machine used in formal logic and theoretical computer science to model computation. It consists of a finite set of registers (counters), each holding a single arbitrarily large non-negative integer, together with a sequential list of instructions that increment a counter, decrement a counter, and test a counter for zero with a conditional jump. Counter machines are among the simplest models known to be Turing complete.

Definition

Formally, a counter machine is defined by a finite set of states (instruction labels), a finite set of counters, and instructions of three forms: INC(r) — increment register r and proceed to the next instruction; DEC(r, z) — if register r is positive, decrement it and proceed, otherwise jump to instruction z; and HALT. Computation proceeds deterministically from the first instruction.

Computational power

Marvin Minsky showed in the 1960s that a machine with only two counters suffices to simulate any Turing machine, by encoding the Turing machine's tape into a single number using prime factorisation (a Gödel numbering) and using the second counter as scratch space. Because decrementing and zero-testing such encoded numbers is extremely slow, two-counter machines are of theoretical rather than practical interest. One-counter machines are strictly weaker, while machines with three or more counters admit much more efficient simulations.

Variants

Related models include the register machine (or Minsky machine), the abacus machine of Lambek, and the pointer machine. Counter machines are used in proofs of undecidability, for example of the halting problem for restricted models and in the analysis of programs with integer variables.
