ISO image

An ISO image is a disk image of an optical disc. In other words, it is an archive file that contains everything that would be written to an optical disc, sector by sector, including the optical disc file system. ISO images are so named because they typically use the ISO 9660 file system used on CD-ROM media, and usually carry the file extension .iso.

Contents

An ISO image is an uncompressed, sector-by-sector copy of the data on an optical disc, stored in a single file. Because it preserves the disc's structure, including boot information (via the El Torito extension), ISO images are the standard way of distributing operating system installers and other bootable media online.

Use

ISO images can be "mounted" so that an operating system treats the file as if it were a physical disc in a drive; Windows, macOS, and Linux all include this capability. They can also be written ("burned") to a real disc or to a USB flash drive to create bootable media. Software distributors such as Linux distributions and Microsoft release downloads primarily as ISO images.

Related formats

Similar disc-image formats include Apple's DMG, the BIN/CUE pair, and NRG. For DVDs and Blu-ray, the underlying file system is usually UDF rather than ISO 9660, though the .iso extension is still used.
