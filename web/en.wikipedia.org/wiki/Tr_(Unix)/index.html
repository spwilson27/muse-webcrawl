tr is a command in Unix, Plan 9, Inferno, and Unix-like operating systems. It is an abbreviation of the word translate or transliterate, indicating its operation of replacing or removing specific characters in its input data set. The utility performs three main operations: translation of characters, deletion of characters, and squeezing of repeated characters into one.

Usage

The command reads standard input and writes to standard output. Its syntax is:

tr [options] "string1" ["string2"]

The first string specifies the characters to be replaced or deleted, and the second string, if present, specifies the characters they are replaced with, matched positionally. Character ranges such as a-z and character classes such as [:upper:] are supported.

Examples

Convert lowercase letters to uppercase:

$ echo 'hello' | tr 'a-z' 'A-Z'
HELLO

Delete a set of characters with the -d option:

$ echo 'hello123' | tr -d '0-9'
hello

Squeeze repeated characters into one with the -s option:

$ echo 'booook' | tr -s 'o'
bok

History

The tr utility first appeared in early versions of Unix developed at Bell Labs and was modeled on similar character-translation functions found in earlier systems. It is specified by POSIX and is included in the GNU coreutils package on Linux systems.
