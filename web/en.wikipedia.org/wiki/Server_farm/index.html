Server farm

Racks of servers in a large data centre.

A server farm or server cluster is a collection of computer servers, usually maintained by an organisation to supply server functionality far beyond the capability of a single machine. Server farms often consist of thousands of computers housed in a data center, and are used to provide services such as websites, cloud computing, scientific computation, and rendering.

Design

Servers in a farm are typically rack-mounted and connected by high-speed networks, with requests distributed among them by load balancers so that no single machine is overwhelmed and the failure of one server does not interrupt service. Large farms require substantial electrical power and cooling; energy efficiency is commonly measured by power usage effectiveness (PUE). Hyperscale operators such as Google, Microsoft, and Amazon operate server farms with hundreds of thousands of machines.

Applications

Server farms power search engines, social networks, video streaming, and cloud platforms. Specialised forms include render farms for computer-generated imagery and compute clusters for scientific research. The growth of artificial intelligence training has driven construction of very large GPU server farms in the 2020s.
