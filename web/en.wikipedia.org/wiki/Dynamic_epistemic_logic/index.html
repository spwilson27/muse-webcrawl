Dynamic epistemic logic

Dynamic epistemic logic (DEL) is a logical framework dealing with knowledge and information change. Typically, DEL focuses on situations involving multiple agents and studies how their knowledge changes when events occur. These events can change factual properties of the actual world (they are ontic events), but they can also change the knowledge agents have about the world while leaving the actual facts unchanged (they are epistemic events).

Historically, dynamic epistemic logic started in the 1980s with work on reasoning about knowledge in distributed systems and computer security, and it developed from earlier work in epistemic logic and dynamic logic. A key early treatment was the public announcement logic of Jan Plaza (1989). Later, the action model logic of Baltag, Moss and Solecki (1998) provided a general framework for information-changing actions. Independently, similar ideas were developed by Hans van Ditmarsch and others.

Epistemic logic background

Epistemic logic is a form of modal logic concerned with reasoning about knowledge. Its basic language extends propositional logic with a knowledge operator Ki for each agent i, where Kiφ reads "agent i knows that φ". Models are Kripke models: sets of possible worlds connected by accessibility relations representing each agent's uncertainty, together with a valuation of atomic propositions at each world.

Public announcement logic

Public announcement logic (PAL) adds to the epistemic language an operator [!φ]ψ, read "after the public announcement of φ, ψ holds". The semantics is given by model restriction: announcing φ removes all worlds where φ is false, and the updated model is evaluated at the remaining worlds. PAL over S5 models has the same expressive power as plain epistemic logic — every PAL formula is equivalent to one without announcements — but announcements can give exponential succinctness gains.

Action models

Action model logic (AML) generalises PAL by using action models (or event models): finite sets of events with preconditions and accessibility relations between events, modelling that agents may be uncertain about which event occurred, and may observe events to different degrees (private announcements, lies, and so on). The product update construction combines a model with an action model to produce an updated model. Action models can describe, among other things, private announcements to subgroups, public lies, and radical upgrades of beliefs.

Belief revision and other extensions

Extensions of DEL incorporate plausibility orderings on worlds, allowing belief revision as well as knowledge change; such frameworks connect DEL with AGM belief revision theory. Other developments include logics of communication and change with factual change (ontic actions), probabilistic dynamic epistemic logics, and connections with game theory, security protocols (e.g. analysing the Russian cards problem), and multi-agent planning.
