Windows Media Player (WMP) is a media player and media library application developed by Microsoft that is used for playing audio, video and viewing images on personal computers running the Microsoft Windows operating system, as well as on Pocket PC and Windows Mobile–based devices. Editions of Windows Media Player were also released for classic Mac OS, Mac OS X, and Solaris, but development of these has since been discontinued.

In addition to being a media player, Windows Media Player includes the ability to rip music from and copy music to compact discs, burn recordable discs in Audio CD format or as data discs with playlists, and synchronize content with digital audio players and mobile devices. It can also stream media over a home network using DLNA.

History

The first version of Windows Media Player appeared in 1991 as a component of Windows 3.0 with Multimedia Extensions, where it was simply called Media Player. It played media files using the Media Control Interface. Successive versions gained support for streaming media, playlists, skins, and visualizations. Windows Media Player 7, released in 2000, was a major redesign with a media library and CD burning support, and was bundled with Windows Me.

Windows Media Player 9 Series introduced streaming with the Windows Media codecs and Fast Stream technology. Versions 10 and 11 refined the library interface and added support for portable devices and online music stores. Windows Media Player 12, released with Windows 7 in 2009, added native support for H.264, AAC, and other formats, library sharing over home networks, and a simplified playback interface. It remained the final version of the "legacy" player for over a decade.

New Media Player for Windows 11

In 2021 Microsoft introduced a redesigned Media Player app for Windows 11, which eventually replaced both Windows Media Player Legacy and Groove Music. The new app includes full-featured music and video libraries, playlist management, and support for local files, while the legacy Windows Media Player remains available as an optional feature.

Features

  • Playback of Windows Media Audio and Video, MP3, and many other formats
  • Media library with metadata, album art, and ratings
  • CD ripping and burning
  • Synchronization with portable devices
  • Visualizations, skins, and plug-ins
  • Streaming and media sharing over a network

Criticism and competition

Windows Media Player was at the center of an antitrust case in the European Union, which resulted in Microsoft being required to offer editions of Windows without the player (the "N" editions) and a fine. The player also faced strong competition from iTunes, Winamp, VLC, and other media players, and criticism over its digital rights management features and format restrictions in early versions.
