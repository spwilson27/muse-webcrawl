Identity element

In mathematics, an identity element (or neutral element) of a binary operation on a set is an element of the set that leaves every element unchanged when combined with it. Formally, an element e is a two-sided identity for an operation · if, for every element a in the set, e · a = a and a · e = a. A set equipped with an operation that has an identity element is called a monoid when the operation is also associative.

Examples

  • For the integers, rational numbers, real numbers, and complex numbers under addition, the identity element is 0 (the additive identity).
  • For the same sets under multiplication, the identity element is 1 (the multiplicative identity).
  • For n-by-n matrices under multiplication, the identity is the identity matrix In.
  • For functions from a set to itself under composition, the identity is the identity function.
  • For strings under concatenation, the identity is the empty string; for sets under union, the empty set; under intersection, the universal set.
  • In a group, the identity element is conventionally denoted e and is the element to which every element times its inverse is equal.

One-sided identities and uniqueness

An operation may have a left identity (with e · a = a for all a) without having a right identity, and such one-sided identities need not be unique. However, if an operation has both a left identity and a right identity, they must coincide, so a two-sided identity, when it exists, is unique. Some operations have no identity at all: the positive integers under addition have none, since 0 is not positive, and even integers under multiplication have none.

Generalizations

The notion generalizes throughout abstract algebra: identity morphisms in category theory, unit elements of rings, and identity elements in semigroups, loops, and quasigroups all play the same structural role. In ring theory, the additive identity (zero) and multiplicative identity (one) are distinguished and are required to be different in any nontrivial ring.
