Meagre set

From Wikipedia, the free encyclopedia

In the mathematical fields of general topology and descriptive set theory, a meagre set (also called a meager set or a set of first category) is a set that, considered as a subset of a (usually larger) topological space, is in a precise sense small or negligible. A topological space is a Baire space if the countable intersection of every countable collection of dense open sets is dense; the Baire category theorem states that every complete metric space is a Baire space, i.e., is not meagre in itself.

Definitions

A subset of a topological space is nowhere dense if the interior of its closure is empty. A set is meagre (of the first category) if it can be written as a countable union of nowhere dense sets. A set that is not meagre is of the second category. The complement of a meagre set is called comeagre or residual.

Examples

The rational numbers are meagre in the real line, being a countable union of singletons, each nowhere dense; the irrationals are comeagre. The Cantor set is nowhere dense in ℝ, hence meagre, even though it is uncountable. Category and measure are independent notions of smallness: there exist sets of full measure that are meagre, and comeagre sets of measure zero.

Applications

Baire category arguments are a standard tool in functional analysis (underlying the uniform boundedness principle, open mapping theorem and closed graph theorem), in real analysis (a typical continuous function is nowhere differentiable), and in dynamical systems.
