Session Description Protocol

The Session Description Protocol (SDP) is a format for describing multimedia communication sessions for the purposes of announcement, invitation and other forms of session initiation. It is published by the IETF as RFC 8866 (which made obsolete RFC 4566 and the original RFC 2327) and is used in conjunction with protocols such as the Session Initiation Protocol (SIP), the Real-time Transport Protocol (RTP) and WebRTC.

Format

An SDP description is a text block of lines in the form type=value, divided into a session-level description and one or more media-level descriptions. Important fields include:

v=0 o=- 4611733050430603394 2 IN IP4 127.0.0.1 s=- c=IN IP4 203.0.113.2 t=0 0 m=audio 49170 RTP/AVP 0 a=rtpmap:0 PCMU/8000

Here v is the protocol version, o the originator, s the session name, c connection data, t timing, m a media description (type, port, transport protocol and formats) and a attribute lines that carry most of the detail, such as codec parameters, RTP mappings, encryption keys and WebRTC ICE candidates.

Offer/answer model

SDP itself does not transport media or negotiate; it describes a session. In the offer/answer model (RFC 3264), one endpoint sends an SDP offer listing the media and codecs it supports, and the other replies with an answer selecting a compatible subset. This exchange is the basis of call setup in SIP-based VoIP and of peer connection negotiation in WebRTC.
