Binary number

From Wikipedia, the free encyclopedia
[Image: A binary counter showing counting from 0 to 15 in binary]

A binary number is a number expressed in the base-2 numeral system, using only the digits 0 and 1. Each binary digit (bit) represents a power of two, so the binary numeral 1011 means 1×8 + 0×4 + 1×2 + 1×1 = 11 in decimal.

Binary is the foundation of virtually all modern computing: digital circuits naturally have two stable states, interpreted as 0 and 1, and every number, character, image, and instruction in a computer is ultimately encoded in binary. Leibniz published a formal account of binary arithmetic in 1703, marvelling at its simplicity (and seeing in it an image of creation from nothing).

Arithmetic and representation

Addition, subtraction (via two's complement), multiplication, and division have simple binary algorithms that map directly onto logic circuits — one reason George Boole's algebra and Shannon's circuit analysis converged on binary design.

Groups of bits form bytes (8 bits); hexadecimal (base 16) is a compact shorthand, each hex digit equalling exactly four bits. Fractions and very large numbers use binary floating-point formats (IEEE 754).

History

Binary-like systems predate Leibniz: the I Ching's hexagrams and Pingala's Sanskrit prosody patterns are sometimes cited. In computing, binary was adopted from the earliest electronic machines (Zuse, Atanasoff, ENIAC's rival designs) and became universal with the transistor era.
