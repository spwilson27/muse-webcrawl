Raspberry Pi OS is a Unix-like operating system based on the Debian Linux distribution, developed for the Raspberry Pi family of single-board computers. It is the officially supported operating system for the platform and is provided by the Raspberry Pi Foundation's trading arm. Until May 2020 it was known as Raspbian.

History

The system began as Raspbian, an unofficial port of Debian optimised for the original Raspberry Pi's ARMv6 processor, recompiled with hardware floating-point support (armhf) by Mike Thompson and Peter Green. The Foundation adopted it as its official image in 2012. In June 2019 a version based on Debian 10 "Buster" accompanied the Raspberry Pi 4; in November 2021 Debian 11 "Bullseye" followed, and Debian 12 "Bookworm" in October 2023, which switched the default display server to Wayland with the Wayfire compositor and later labwc. A 64-bit version, long in beta, was released in February 2022.

Features

Raspberry Pi OS ships in three variants: a full desktop edition with recommended software, a standard desktop edition, and a "Lite" edition without a graphical interface for server and embedded use. The desktop, originally called PIXEL (Pi Improved Xwindows Environment, Lightweight), is based on LXDE with a customised theme, the Chromium web browser, and education-oriented tools including Scratch, Thonny Python IDE, Wolfram Mathematica and a bundled copy of Minecraft Pi in earlier releases. Configuration is handled through the graphical Raspberry Pi Configuration tool or the terminal utility raspi-config. Images are distributed through the Raspberry Pi Imager application, which can pre-configure user accounts, Wi-Fi and SSH.

Reception and use

As the default operating system for tens of millions of boards, Raspberry Pi OS is widely used in education, home automation, retro gaming and hobbyist projects. Its close tracking of Debian, together with Pi-specific firmware and kernel support, distinguishes it from community distributions such as Ubuntu images for the Pi.
