Superscalar processor

A superscalar processor can dispatch multiple instructions to redundant execution units in each cycle.

A superscalar processor (or superscalar architecture) is a central processing unit that implements a form of parallelism called instruction-level parallelism, in which several instructions can be executed in a single clock cycle. This contrasts with a scalar processor, which can execute at most one instruction per cycle. A superscalar CPU contains multiple execution units — for example several integer ALUs, a floating-point unit, and load/store units — and dispatch logic that examines the incoming instruction stream and issues independent instructions to free units simultaneously.

History

The CDC 6600 (1964), designed by Seymour Cray, is often regarded as the first superscalar design, with multiple functional units fed from a central instruction scoreboard. The concept became mainstream in the 1990s with processors such as the Intel Pentium (1993), which had two integer pipelines, and the PowerPC 601. Modern high-performance CPUs — from Intel's and AMD's x86 families to Apple's Arm-based designs — are wide superscalar machines, commonly issuing four to eight instructions per cycle.

Design considerations

Exploiting superscalar execution requires the hardware (or, in VLIW designs, the compiler) to find instructions without data dependencies. Techniques include register renaming to remove false dependencies, out-of-order execution with reservation stations, branch prediction to keep the instruction fetch stream flowing, and speculative execution. The practical limits are set by the available parallelism in real programs, the cost of dependency-checking logic, and power consumption, which grows steeply with issue width.
