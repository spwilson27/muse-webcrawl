Intra-frame coding


Field: Video compression
Also known as: I-frame coding, spatial compression

Intra-frame coding is a technique used in video compression to exploit spatial redundancy within a single frame of video. Unlike inter-frame coding, which compresses a frame by reference to neighbouring frames, intra-frame coding uses only the information in the current frame itself, applying image-compression methods such as transform coding and entropy coding.

Applications

Frames coded this way in inter-frame formats are called I-frames (intra-coded frames) and serve as random-access points in standards such as MPEG-2, H.264/AVC, and HEVC. Some formats use intra-frame coding for every frame: these include DV, Apple ProRes, Avid DNxHD, and the Motion JPEG family. Such formats are favoured in video editing and professional production because each frame can be accessed and cut independently and is resilient to errors, at the cost of higher bitrates.

Techniques

Typical intra coding divides the frame into blocks, predicts each block from already-coded neighbouring samples (intra prediction), transforms and quantises the residual, and entropy-codes the result. Lossless intra formats such as FFV1 and HuffYUV are used for archiving.
