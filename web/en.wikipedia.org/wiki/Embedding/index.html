Embedding

In mathematics, an embedding (or imbedding) is one instance of some mathematical structure contained within another instance, such as a group that is a subgroup. When some object X is said to be embedded in another object Y, the embedding is given by an injective and structure-preserving map f : X → Y.

Topology

In general topology, an embedding is a homeomorphism onto its image: a topological space X is embedded in Y if it is homeomorphic to its image under an injective continuous map. In differential topology, an embedding is a smooth map whose differential is everywhere injective and which is a homeomorphism onto its image; immersions that are not injective are not embeddings.

Celebrated results include the Whitney embedding theorem, which states that any smooth n-dimensional manifold can be embedded in Euclidean space of dimension 2n, and the Nash embedding theorems for Riemannian manifolds.

Other fields

The term is used in algebra for structure-preserving injective homomorphisms, in order theory for order embeddings, and in category theory and geometry in various specialized senses. In machine learning, "embedding" also refers to dense vector representations of words or other data, a usage borrowed from the mathematical term.
