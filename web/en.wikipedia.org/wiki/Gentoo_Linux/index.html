Gentoo Linux

Gentoo Linux is a free and open-source Linux distribution built around the Portage package management system. Unlike binary distributions, Gentoo ordinarily compiles software from source code on the user's machine, allowing extensive customization through compile-time options known as USE flags.

Developer: Gentoo Foundation
Initial release: 31 March 2002
Package manager: Portage
Platforms: x86-64, x86, ARM, and others
License: Free software

History

Gentoo was created by Daniel Robbins, who had previously worked on Stampede Linux and FreeBSD; its design drew on FreeBSD's ports system. The first stable release, version 1.0, appeared on 31 March 2002. The distribution is named after the gentoo penguin, the fastest swimming species of penguin — reflecting its performance ambitions.

Portage

Portage installs packages described by ebuild scripts stored in the Gentoo ebuild repository. Users configure global and per-package USE flags, CFLAGS, and licensing preferences, and the emerge tool resolves dependencies and builds software accordingly. Gentoo follows a rolling release model with continuous updates rather than periodic versioned releases.

Use

Gentoo is aimed at experienced users who want fine-grained control; it serves as the basis for derivatives including Google's ChromeOS build environment and the security-focused Hardened Gentoo project.
