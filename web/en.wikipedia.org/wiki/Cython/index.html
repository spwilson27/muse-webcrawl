Cython

Cython
Type: Programming language / compiler
Developer: Cython developers
First released: 2007
Based on: Pyrex

Cython is a superset of the Python programming language that additionally supports calling C functions and declaring C types. It is designed to give C-like performance with code written mostly in Python, and compiles Python code into C extension modules.

How it works

Cython source files (.pyx) are compiled by the Cython compiler into C code, which is then compiled into a shared library importable from Python. Optional static type declarations let the compiler generate efficient native code, especially for numerical loops. The language descends from Pyrex, developed by Greg Ewing.

Use

Cython is widely used in scientific computing to accelerate libraries such as parts of SciPy and scikit-learn, and to wrap existing C libraries for use from Python. It is also popular for embedding Python in C applications.
