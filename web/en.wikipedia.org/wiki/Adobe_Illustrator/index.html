Adobe Illustrator

Adobe Illustrator is a vector graphics editor and design program developed and marketed by Adobe. Originally designed for the Apple Macintosh, development began in 1985. Along with Creative Cloud (Adobe's shift to a monthly or annual subscription service delivered over the Internet), Illustrator CC was released in 2013. Illustrator is widely regarded as an industry standard for vector illustration, used for logos, icons, typography, packaging and complex illustrations for print, web and video.

History

Adobe co-founder John Warnock conceived Illustrator to exploit the Bézier-curve capabilities of the PostScript page-description language; the first version shipped for the Macintosh in 1987 and helped establish desktop publishing. Successive versions added gradient meshes, live trace, perspective drawing and integration with Adobe's other applications. In 2013 Illustrator moved to the Creative Cloud subscription model, and a dedicated iPad version appeared in 2020. Later releases have added generative-AI features, including text-to-vector generation.

Features

Illustrator builds artwork from mathematically defined paths (anchor points and Bézier handles), which can be scaled without loss of quality. Core tools include the Pen and Shape tools, Pathfinder boolean operations, type tools, brushes, symbols, gradient and mesh fills, and image trace for converting raster images into vectors. Files are saved natively in the .ai format, which is based on PDF, and can be exported to EPS, SVG and other formats used across design workflows.
