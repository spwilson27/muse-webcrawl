Null character

The null character (also null terminator) is a control character with the value zero. It is present in many character sets, including ISO/IEC 646 (ASCII) and Unicode, where it occupies code point U+0000 and is abbreviated NUL. In ASCII it was originally used as padding — a character that could be transmitted to waste time or fill space on teleprinters and punched paper tape without printing anything.

Use as a string terminator

The null character is best known for its role in the C programming language, where strings are stored as arrays of characters ending with a null byte; such strings are called null-terminated strings (or C strings). Library functions such as strlen and strcpy determine the end of a string by finding the zero byte. Because the length is not stored explicitly, functions that write into buffers without checking bounds can overflow, and forgetting the terminator is a classic source of bugs and security vulnerabilities. A consequence of the convention is that a C string cannot contain an embedded null character.

Representation

In source code the null character is commonly written as the escape sequence \0, and in caret notation as ^@, since it can be typed with Ctrl+@ on many keyboards. In Unicode it is the first control character, sometimes displayed with the symbol ␀ in documentation. Filenames and text fields in most operating systems and file formats cannot contain an actual null byte, which historically enabled "null byte injection" attacks against software that mixed length-based and null-terminated string handling.
