Grails (framework)

Grails is an open-source web application framework that uses the Apache Groovy programming language and the convention-over-configuration paradigm. It is designed to be a high-productivity framework by following the "coding by convention" principle, providing a stand-alone development environment and hiding much of the configuration detail from the developer.

Overview

Grails is built on top of the Spring Framework and uses embedded servers such as Tomcat or Jetty for development. Its object-relational mapping layer, GORM, is implemented using Hibernate. Views are typically written with Groovy Server Pages (GSP). Scaffolding can generate controllers, views, and database schema from domain classes, allowing rapid prototyping.

History

The project began in 2005 under the name "Groovy on Rails", later changed to Grails to avoid trademark issues. Version 1.0 was released in February 2008. Grails 3, released in 2015, was rebuilt on Spring Boot and adopted Gradle as its build system. Later versions added support for the Micronaut framework's features and profiles for REST APIs, microservices, and reactive applications.
