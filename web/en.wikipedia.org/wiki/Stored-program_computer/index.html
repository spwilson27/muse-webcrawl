Stored-program computer

A stored-program computer is a computer that stores program instructions in electronically or optically accessible memory. This is in contrast to computers controlled by plugboards, punched paper tape mechanisms or fixed wiring, where changing the program meant physically rewiring the machine. The stored-program concept underlies almost all modern computers: because instructions are held in the same kind of memory as data, a program can be loaded, modified and even manipulated by other programs.

The Manchester Baby (1948), the first electronic stored-program computer to run a program.

Origins

The theoretical basis was laid by Alan Turing's universal machine (1936). The most influential articulation of the practical design is the 1945 First Draft of a Report on the EDVAC, circulated under John von Neumann's name and drawing on the ENIAC team's work; the resulting organisation is commonly called the von Neumann architecture. An earlier 1936 paper by Konrad Zuse had also described storing instructions in the same memory as data.

First implementations

The first electronic stored-program computer to actually run a program was the Manchester Baby (Small-Scale Experimental Machine), which ran its first program on 21 June 1948 at the University of Manchester. It was followed in 1949 by the full-scale Manchester Mark 1 and by EDSAC at Cambridge, the first practical stored-program computer in regular service. In the United States, machines derived from the EDVAC/ IAS designs proliferated in the early 1950s.

Characteristics

In a stored-program design a central processing unit fetches instructions from memory in sequence, decodes and executes them, with a program counter tracking progress and conditional branches altering the flow. Because program and data share memory, the design exhibits the "von Neumann bottleneck" — the limited throughput of the single connection between processor and memory — which modern caches and Harvard-architecture modifications mitigate.
