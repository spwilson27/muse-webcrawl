Actor model

The actor model in computer science is a mathematical model of concurrent computation that treats an actor as the basic building block of computation: everything is an actor. It was introduced by Carl Hewitt, Peter Bishop and Richard Steiger in 1973, and developed further by Gul Agha and others.

[Image: Actors exchanging messages]

Fundamental concepts

An actor is a computational entity that, in response to a message it receives, can concurrently: send a finite number of messages to other actors; create a finite number of new actors; and designate the behaviour to be used for the next message it receives. Actors communicate only by asynchronous message passing and share no state, so computation proceeds without locks; each actor processes messages sequentially from its own mailbox.

Influence and implementations

The actor model influenced the development of languages and frameworks for distributed and fault-tolerant systems, notably Erlang (and its OTP platform), Elixir, Scala's Akka toolkit, Microsoft's Orleans, and the Rust Actix framework. It is widely used in telecommunications, web services and real-time systems where concurrency and resilience are essential.
