Absorbing element

In mathematics, an absorbing element (also called an annihilating element or zero element for the operation in question) is a special element of a set with respect to a binary operation that, when combined with any other element, always yields itself. Formally, an element z of a magma (S, ·) is a (two-sided) absorbing element if z · s = s · z = z for every s in S.

Examples

  • In the integers, rationals, reals and complex numbers, 0 is absorbing under multiplication: 0 × a = 0 for all a, though it is the identity under addition, not absorbing.
  • In Boolean algebra, false (0) is absorbing for AND, and true (1) is absorbing for OR.
  • For sets, the empty set is absorbing under intersection, and the universal set is absorbing under union.
  • The zero matrix is absorbing under matrix multiplication relative to addition-distributing structures only in tandem with the zero scalar.
  • In a lattice, the bottom element ⊥ is absorbing for meet, and the top element ⊤ is absorbing for join.

Properties

An absorbing element, if it exists, is unique: if z and z′ are both absorbing, then z = z · z′ = z′. A structure can have a left-absorbing element without a right-absorbing one, although in commutative settings the distinction vanishes. An absorbing element should not be confused with an identity element, which leaves other elements unchanged rather than overwhelming them; in any nontrivial ring the two are distinct, and identifying them collapses the ring to a single element. Adding an absorbing element to a semigroup yields such constructions as the zero of a ring or the sink state of an automaton.
