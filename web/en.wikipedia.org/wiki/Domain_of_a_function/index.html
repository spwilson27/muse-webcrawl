A function from domain X to codomain Y

Domain of a function

In mathematics, the domain of a function is the set of inputs accepted by the function. It is sometimes denoted by dom(f), where f is the function. In layman's terms, the domain of a function can generally be thought of as "what x can be".

More precisely, given a function f : X → Y, the domain of f is X. In modern mathematical language, the domain is part of the definition of a function rather than a property of it. The set Y is the codomain, and the set of values actually attained is the range (image) of the function.

Natural domain

If a function is defined by a formula and no domain is explicitly stated, the natural domain is the largest set of inputs for which the formula gives a real value. For example, the natural domain of f(x) = 1/x is all real numbers except 0, and that of the square root function is the non-negative real numbers.

Other uses

Related notions include the domain of a partial function, where the function may be undefined for some inputs, and, in category theory and computer science, source objects and type signatures that generalise the concept.
