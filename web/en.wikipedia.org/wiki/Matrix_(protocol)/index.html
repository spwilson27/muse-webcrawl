Matrix (protocol)

Matrix
Type: Open standard for decentralised communication
Released: 2014
Steward: The Matrix.org Foundation

Matrix is an open standard and communication protocol for real-time communication. It aims to make messaging, voice, and video interoperable between providers through a federated network of servers, much as email works, with rooms replicated across participating homeservers.

Design

Matrix uses HTTP APIs with JSON, end-to-end encryption based on the Olm/Megolm protocols (derived from the Signal double ratchet), and bridges to other networks such as IRC and Slack. Element is the best-known client. The protocol was released in 2014 by the team at Amdocs that became New Vector and the Matrix.org Foundation.

Adoption

Matrix has been adopted by governments and organisations including the French government (Tchap), the German healthcare system, and open-source communities such as Mozilla.
