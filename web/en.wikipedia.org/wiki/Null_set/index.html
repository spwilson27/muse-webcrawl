Null set

In measure theory, a null set is a measurable set of measure zero. This can be characterized as a set that can be covered by a countable union of intervals (or, in higher dimensions, of more general sets) of arbitrarily small total measure. Every countable subset of the real line, and every subset of a null set in a complete measure space, is again a null set. Any countable union of null sets is a null set.

Definition

Let (X, Σ, μ) be a measure space. A set S ⊆ X is a null set if it is measurable and μ(S) = 0. In constructions of measures, it is common to define a null set more generally as any set that is a subset of a measurable set of measure zero; for the Lebesgue measure on the real line, the two definitions coincide because the measure is complete.

Examples

The empty set is a null set in every measure space. Every finite or countable set of points on the real line has Lebesgue measure zero: the set of rational numbers, though dense, is a null set, as is the Cantor set, even though the Cantor set is uncountable. In n-dimensional Euclidean space, every lower-dimensional subspace — a line in the plane, a plane in space — has n-dimensional Lebesgue measure zero.

Applications

Null sets underlie the notion of "almost everywhere": a property holds almost everywhere if the set on which it fails is a null set. In probability theory these are events of probability zero; in Lebesgue integration, functions differing only on a null set have the same integral and are identified in the Lp spaces.
