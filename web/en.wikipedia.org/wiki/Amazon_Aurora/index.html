Amazon Aurora

Amazon Aurora
Developer: Amazon Web Services
Initial release: 2014
Type: Relational database service (MySQL- and PostgreSQL-compatible)

Amazon Aurora is a proprietary relational database service offered by Amazon Web Services (AWS) since October 2014. Aurora is available as part of the Amazon Relational Database Service (RDS). It provides MySQL- and PostgreSQL-compatible editions while using a cloud-native storage architecture designed for high performance and availability.

Architecture

Aurora separates compute from storage: data is maintained in a distributed, replicated storage layer across three Availability Zones, with six copies of the data and continuous backup to Amazon S3. The design aims to deliver higher throughput than standard MySQL or PostgreSQL deployments, with replicas sharing the same underlying storage volume so that replica lag is typically very low. An Aurora cluster consists of a primary instance and up to 15 read replicas.

Variants

Aurora Serverless automatically scales compute capacity up and down based on application demand. Aurora Global Database enables replication across AWS regions, and features such as Aurora Machine Learning and integration with Amazon S3 export extend the service further.
