Smalltalk

Smalltalk is a purely object-oriented programming language and integrated development environment developed at Xerox PARC in the 1970s by Alan Kay, Dan Ingalls, Adele Goldberg, and others. It introduced or popularized many ideas now central to software development, including the graphical user interface with overlapping windows, the class–object model of object-oriented programming, the model–view–controller architecture, and just-in-time compilation.

History

Smalltalk grew out of Alan Kay's vision of the Dynabook and his work on the FLEX machine and Logo-like languages for children. Successive versions — Smalltalk-71, Smalltalk-72, and Smalltalk-76 — led to Smalltalk-80, released publicly in 1980 and described in the books Smalltalk-80: The Language and Its Implementation (the "Blue Book") by Adele Goldberg and David Robson. Smalltalk systems were commercialized by ParcPlace, Digitalk, and others, and influenced later languages including Objective-C, Java, Ruby, Python, and Scala.

Language design

In Smalltalk, everything is an object — including numbers, classes, code blocks, and control structures, which are implemented as message sends to objects. Programs are built by sending messages, written in a simple syntax with unary, binary, and keyword messages. Development takes place in a live image-based environment: programmers inspect and modify running objects, use class browsers and debuggers integrated with the system, and save the entire state as an image. The language emphasizes late binding, garbage collection, and reflective metaprogramming through its metaclass model.

Influence and modern use

Smalltalk introduced the first modern IDE, pioneered test-driven development practices (SUnit, the ancestor of xUnit frameworks), and inspired design patterns and agile methods such as extreme programming, which emerged from a Smalltalk project. Modern implementations include the open-source Pharo and Squeak environments, and commercial systems such as Cincom VisualWorks and GemStone/S. The web framework Seaside demonstrated Smalltalk's continuing influence on web development.
