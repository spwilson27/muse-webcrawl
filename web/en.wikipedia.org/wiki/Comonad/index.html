Comonad

A comonad provides extract and duplicate operations dual to a monad's return and join.

In category theory, a comonad is the dual notion of a monad. Where a monad describes computations that produce values with context, a comonad describes computations that consume values together with their context. In functional programming, comonads are used to model context-dependent computation, such as streams, cellular automata, and dataflow computations.

Definition

A comonad on a category consists of an endofunctor W together with two natural transformations: extract (or counit) extract :: W a → a, which obtains the value at the current focus, and duplicate (or comultiplication) duplicate :: W a → W (W a), which produces a structure of all possible focused contexts. These must satisfy coassociativity and counit laws, dual to the monad laws.

In Haskell

In Haskell, comonads are captured by the Comonad type class in the comonad package, generalising Functor with extract and either duplicate or extend. Examples include:

  • Store comonad — pairs a lookup function with an index; models a value embedded in an addressable space.
  • Env (Reader-like) comonad — a value paired with an environment.
  • Stream and zipper comonads — infinite streams and list zippers, whose extract returns the focused element and duplicate yields all possible refocusings.
  • Traced comonad — accumulates a monoidal trace.

Applications

Comonads are used in image processing (each output pixel computed from a neighbourhood of inputs), cellular automata such as Conway's Game of Life, signal processing, and user-interface frameworks where widgets are context-dependent values.
