Code page 437 (CCSID 437) is the character set of the original IBM PC, introduced in 1981. It is also known as CP437, OEM-US, or PC-8. The character set consists of 256 characters: the lower 128 reproduce printable ASCII, while the upper 128 provide accented letters, Greek letters, mathematical symbols, and a celebrated set of box-drawing and block characters.

Character set

Positions 0x00–0x1F, control codes in ASCII, were assigned printable glyphs on the IBM PC — smileys (☺ ☻), card suits (♥ ♦ ♣ ♠), bullets, and musical notes — because the PC's display hardware rendered them directly. Code points 0xB0–0xDF supply shading blocks (░ ▒ ▓) and single- and double-line box-drawing characters that became the foundation of text-mode user interfaces on DOS. The upper range also includes accented Latin letters for Western European languages, Greek letters (α β π Σ σ µ τ Φ θ Ω), and symbols such as ∞, ∩, ≡, ±, ≥, ≤, ÷, and ≈.

Use

Code page 437 was the default character set of the IBM PC BIOS and of MS-DOS in the United States. Files and screen output in the DOS era — including ANSI art and BBS graphics — were almost universally encoded in CP437 or a close relative. Other regional code pages (such as 850 for Western Europe and 866 for Cyrillic) rearranged the upper half while retaining the box-drawing block.

Legacy

Although superseded by Windows code pages and then Unicode, code page 437 remains in use: Windows consoles in the United States still default to it as the "OEM" code page, its block and box characters survive in Unicode's corresponding blocks, and it is the standard encoding assumed when displaying legacy DOS text and ANSI artwork.
