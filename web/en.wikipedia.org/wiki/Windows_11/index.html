Windows 11 is a major release of the Windows NT operating system developed by Microsoft. It was announced on June 24, 2021, and released on October 5, 2021, as a free upgrade to eligible Windows 10 devices. Windows 11 features a redesigned user interface influenced by the cancelled Windows 10X, with a centered Start menu and taskbar, rounded corners, and new widgets and window-management features.

Features

Key interface changes include a centered Start button and taskbar icons, a simplified Start menu without live tiles, Snap Layouts and Snap Groups for window arrangement, virtual desktop improvements, a Widgets panel, integration of Microsoft Teams chat (later removed), and redesigned built-in apps including File Explorer with tabs, Notepad, Paint and the Microsoft Store. Later updates added the Copilot AI assistant and expanded AI features for "Copilot+ PCs."

Gaming and platform

Windows 11 inherited DirectStorage and Auto HDR from the Xbox Series X/S, and initially promised an Amazon Appstore-powered Android app subsystem, which Microsoft later discontinued in 2025.

System requirements and controversy

The release drew criticism for its strict minimum requirements — notably a TPM 2.0 security chip, Secure Boot, and a limited list of supported CPUs (roughly Intel 8th generation / AMD Ryzen 2000 and newer) — which rendered many otherwise capable Windows 10 machines ineligible for the official upgrade path.

Reception and adoption

Reviews praised the visual refresh and window management while criticizing taskbar functionality regressions and the hardware requirements. Adoption grew steadily, and Windows 11 eventually overtook Windows 10 in global desktop share around the time support for Windows 10 ended in October 2025.
