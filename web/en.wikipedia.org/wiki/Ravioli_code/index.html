Ravioli code

Ravioli code is a term used in computer programming to describe code consisting of many small, loosely coupled objects or modules — analogous to a plate of ravioli, in which each pocket of pasta is separate and self-contained. The phrase is often (though not always) used pejoratively, for code in which the overall structure is hard to grasp because behaviour is spread across a multitude of tiny components.

Context

The term belongs to a family of food metaphors for code structure: spaghetti code is tangled and unstructured; lasagna code has rigid, heavy layers; ravioli code is the opposite extreme of spaghetti — highly modular, but potentially over-fragmented. It is most often levelled at object-oriented programs with excessive numbers of small classes and indirection, where understanding any single behaviour requires hopping among many files.

Discussion

Advocates of modular design reply that small, cohesive units are easier to test and reuse; critics counter that ravioli code can obscure control flow and that the right level of modularity depends on the problem, team and tooling. The term dates to discussion on software engineering forums and mailing lists in the 1990s.
