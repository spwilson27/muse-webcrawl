Relocation (computing)

Relocation is the process of assigning load addresses for position-dependent code and data of a program and adjusting the code and data to reflect the assigned addresses. Prior to the advent of virtual memory, it was common for programs to be assembled or compiled for a fixed load address; relocation allows the same code to run at different addresses.

Overview

Relocation is typically performed by a linker or loader. Object files contain relocation entries (or "fixups") that identify locations in the code or data whose values depend on the final placement of program segments. The linker resolves symbolic references between modules, and where a module is placed at an address different from the one assumed at assembly time, it adds the displacement (the difference between the linked address and the assumed address) to the values at the relocation sites.

Types

Static relocation is performed once, at link or load time, and the program cannot subsequently be moved. Dynamic relocation is performed by hardware, typically the memory management unit (MMU), which translates the logical addresses generated by the program into physical addresses on every memory access, making the process transparent. Position-independent code (PIC) avoids most relocation by using relative addressing, which is important for shared libraries and address space layout randomization (ASLR).

Relocation in executable formats

Formats such as ELF and PE store relocation tables describing the type of each relocation (for example, absolute 32-bit, PC-relative, or GOT-relative). Self-relocating programs, common in early microcomputer software and boot loaders, carry out the fixups on themselves at start-up.
