Constraint programming

Constraint programming is a programming paradigm in which the user declaratively states constraints on the feasible solutions for a set of decision variables, rather than specifying the steps the computer must take. The solver then searches for assignments that satisfy all the constraints, typically by combining constraint propagation — which prunes variable domains — with systematic search and backtracking.

Constraint satisfaction problems

A constraint satisfaction problem (CSP) consists of variables, each with a domain of possible values, and constraints restricting which combinations of values are allowed. Constraint propagation algorithms such as arc consistency repeatedly remove values that cannot participate in any solution. Classic examples include map colouring, the n-queens problem and Sudoku.

Languages and solvers

Constraint programming grew out of logic programming in the 1980s, and constraints can be embedded in languages such as Prolog (via CLP libraries) or used through dedicated modelling systems and solvers such as MiniZinc, Choco, Gecode and OR-Tools. It is widely applied to scheduling, planning, vehicle routing, configuration and resource allocation problems.
