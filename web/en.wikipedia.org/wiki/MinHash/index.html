MinHash

MinHash (or the min-wise independent permutations locality sensitive hashing scheme) is a technique for quickly estimating how similar two sets are. The scheme was invented by Andrei Broder in 1997 and initially used in the AltaVista search engine to detect duplicate web pages and eliminate them from search results. It has also been applied in large-scale data mining and clustering problems.

Method

Given two sets A and B, their similarity is measured by the Jaccard index, the size of their intersection divided by the size of their union. MinHash estimates this quantity by applying a random permutation (in practice, one or more hash functions) to the elements and recording, for each set, the minimum hash value attained. A key property is that the probability that the minima of the two sets coincide equals their Jaccard similarity, so by comparing many such minimum values one obtains an accurate estimate from compact "sketches" of the sets.

Applications

MinHash is used for near-duplicate detection in documents, web pages and source code; for clustering of large document collections; and in computational biology, where variants such as Mash use MinHash sketches to compare DNA sequences and estimate mutation distances between genomes. Combined with locality-sensitive hashing, the sketches allow similar items to be retrieved efficiently from very large databases.

Variants

Numerous variants improve on the basic scheme, including b-bit minwise hashing, which stores only the lowest bits of each minimum, and one-permutation hashing, which derives many estimates from a single permutation by partitioning the hashed values into bins.
