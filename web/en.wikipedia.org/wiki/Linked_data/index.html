Linked data

In computing, linked data is a set of design principles for sharing machine-readable, interlinked data on the Web. The term was coined by Tim Berners-Lee in a 2006 note on the Semantic Web project. When data is published following the principles, it becomes part of a single global database — the "Web of data" — in which entities are identified by URLs and described with standard metadata formats, so that links between datasets are as navigable as links between web pages. Datasets published as linked open data include DBpedia, Wikidata, and numerous government, library, scientific and cultural-heritage collections; their interconnections are visualised in the "Linked Open Data cloud" diagram, first drawn in 2007 and updated periodically.

The four principles

Berners-Lee set out four rules for publishing linked data:

  1. Use URIs as names for things.
  2. Use HTTP URIs so that people can look up those names.
  3. When someone looks up a URI, provide useful information, using the standards (RDF, SPARQL).
  4. Include links to other URIs, so that they can discover more things.

His later five-star scheme grades open data deployments from simple web publication under an open licence (one star) through machine-readable structured formats (two), non-proprietary formats (three), RDF with URIs (four), to fully linked data (five stars).

Technologies

The Resource Description Framework (RDF) models data as subject–predicate–object triples, serialised in formats such as Turtle, RDF/XML and JSON-LD. Vocabularies and ontologies (declared with RDFS and OWL) give shared meanings to the terms used; schema.org provides a widely used lightweight vocabulary. SPARQL is the standard query language for RDF stores ("triplestores"), and content negotiation lets the same URI return a human-readable HTML page to a browser and machine-readable RDF to software. Linked data principles influenced later developments including knowledge graphs at major web companies and the FAIR data principles in research data management.

Linked open data

The Linking Open Data community project, begun in 2007, persuaded owners of large datasets to publish them as linked data under open licences. Early contributors included DBpedia (structured data extracted from Wikipedia), GeoNames, the BBC, Thomson Reuters' OpenCalais and the US and UK governments' data portals. The cloud grew from 12 datasets in 2007 to well over a thousand by the late 2010s, spanning life sciences, publications, media, geography and social networking; Wikidata (launched 2012) became a central hub identifier for entities across the web.
