XML Schema, published as a W3C recommendation, is a schema language for XML documents: it describes the structure and data types of elements and attributes that may appear in a document, enabling processors to validate documents against a formal definition. Files containing XML Schema definitions conventionally have the extension .xsd (XML Schema Definition) and are themselves written in XML. XML Schema was designed to overcome the limitations of DTDs, the earlier schema mechanism inherited from SGML.

Features

Compared with DTDs, XML Schema offers:

  • XML syntax: schemas are XML documents, so no separate notation must be learned or parsed.
  • Namespace support: elements from multiple vocabularies can be validated together.
  • Rich data types: built-in types such as xs:string, xs:decimal, xs:date and xs:boolean, plus the ability to derive new types by restriction (patterns, ranges, enumerations) and extension.
  • Type derivation and substitution: complex types can be extended or restricted, supporting a degree of schema reuse and object-oriented-style design.
<xs:element name="note">
  <xs:complexType>
    <xs:sequence>
      <xs:element name="to" type="xs:string"/>
      <xs:element name="body" type="xs:string"/>
    </xs:sequence>
  </xs:complexType>
</xs:element>

History

XML Schema 1.0 became a W3C Recommendation in May 2001, drawing on proposals such as Microsoft's XML-Data and the DCD submission. Its complexity drew criticism, and simpler alternatives — notably RELAX NG and Schematron — gained followings, though XML Schema remained dominant in enterprise and web-service contexts (for example, in WSDL descriptions). Version 1.1, published in April 2012, added assertions (xs:assert), conditional type assignment, and other refinements.
