Executable and Linkable Format

Structure of an ELF file: header, program header table, sections, and section header table.

In computing, the Executable and Linkable Format (ELF, formerly named Extensible Linking Format) is a common standard file format for executable files, object code, shared libraries, and core dumps. First published in the specification for the Application Binary Interface (ABI) of the Unix operating system version System V Release 4 (SVR4), it was quickly accepted among different vendors of Unix systems. In 1999, it was chosen by the 86open project as the standard binary file format for Unix and Unix-like systems on x86 processors.

Structure

An ELF file has two views: the program header shows the segments used at run time, whereas the section header lists the set of sections of the binary. Each ELF file begins with a header containing a magic number (0x7F followed by "ELF"), the class (32- or 64-bit), the data encoding (endianness), the type of file, the target instruction set architecture, and the locations of the program and section header tables.

Adoption

ELF has replaced older formats such as a.out and COFF on most Unix-like systems. It is the standard executable format on Linux, Solaris, and most BSD systems, and is also used by many embedded systems and game consoles, including the PlayStation series. Its flexibility supports cross-compilation and the loading of position-independent executables and shared libraries.

Tools

Standard utilities for inspecting ELF files include readelf, objdump, nm, size, and ldd, all of which report on the headers, sections, symbols, and dynamic dependencies of a binary.
