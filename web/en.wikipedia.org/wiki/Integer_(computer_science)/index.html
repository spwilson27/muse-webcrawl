Integer (computer science)

Integers are stored in memory as binary values of fixed width.

In computer science, an integer is the computer representation of the mathematical concept of an integer: a datum of integral data type, a data type representing a finite subset of the mathematical integers. Integral data types may be of different sizes and may or may not be allowed to contain negative values.

Integers are commonly represented in a computer as a group of binary digits (bits). The size of the group varies, so the set of integer sizes available varies between different types of computers and programming languages. Computer hardware nearly always provides a way to represent a processor register or memory address as an integer.

Value and representation

The value of an item with an integral type is the mathematical integer that it corresponds to. Integral types may be unsigned (capable of representing only non-negative integers) or signed (capable of representing negative integers as well). Signed integers are most often represented in two's complement form.

Overflow

Arithmetic on fixed-width integers can produce results outside the representable range, a condition called integer overflow. Depending on the language, overflow may wrap around modulo 2n, raise an error, or invoke undefined behaviour.

Arbitrary precision

Some languages, such as Python and Lisp, provide arbitrary-precision integers ("bignums") whose size is limited only by available memory, at the cost of speed.
