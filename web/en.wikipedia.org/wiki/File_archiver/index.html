File archiver

A graphical file archiver
TypeUtility software
FunctionsArchiving; compression; spanning; encryption
Examples7-Zip, WinRAR, WinZip, tar

A file archiver is a computer program that combines a number of files together into one archive file, or a series of archive files, for easier transportation or storage. File archivers may employ lossless data compression in order to reduce the size of the archive.

Features

Beyond simply concatenating files, archivers store file metadata such as names, directory structure, timestamps, and permissions, and typically include error detection codes (checksums) to verify integrity. Common features include:

  • Compression — reducing total size using algorithms such as DEFLATE or LZMA.
  • Encryption — protecting the archive contents with a password.
  • Spanning/splitting — dividing an archive into multiple volumes of a given size.
  • Solid archiving — compressing files together as a single data block for better ratios.

Formats and programs

Well-known archive formats include ZIP, RAR, 7z, and tar (often combined with gzip or xz compression). Prominent archiver programs include 7-Zip, WinRAR, WinZip, PeaZip, and the tar utility on Unix-like systems. The earliest archivers, such as ARC in the 1980s, popularised the practice of distributing software and file collections as single compressed archives.
