Preimage attack


Diagram of a hash function

In cryptography, a preimage attack on a cryptographic hash function attempts to find a message that produces a given hash value. A hash function is preimage resistant if such an attack is computationally infeasible; for an ideal n-bit hash, brute force requires on the order of 2n operations.

Types

In a first preimage attack, the attacker is given only a hash and must find any message hashing to it. In a second preimage attack, the attacker is given a specific message and must find a different message with the same hash — a weaker requirement than a collision attack, in which any two colliding messages suffice.

Status of common hashes

Practical preimage attacks remain out of reach for widely used functions such as SHA-256; theoretical attacks slightly better than brute force have been published against reduced-round variants of several designs and against MD5, which is nevertheless broken primarily through collision attacks.
