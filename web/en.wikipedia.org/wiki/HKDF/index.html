HKDF

From Wikipedia, the free encyclopedia

Image placeholder: HKDF

HKDF is a simple key derivation function (KDF) based on an HMAC construction. It was designed by Hugo Krawczyk and is standardised in RFC 5869. HKDF follows an "extract-then-expand" paradigm: first it extracts a fixed-length pseudorandom key from possibly weak input keying material using a salt, and then it expands that key into one or more strong keys of the desired length, using an optional context string to bind the output to a particular application or protocol.

Construction

In the extract step, HKDF computes PRK = HMAC-Hash(salt, IKM), where IKM is the input keying material. In the expand step, blocks T(1), T(2), ... are computed as HMAC iterations keyed with PRK over the info string and a counter, and concatenated and truncated to produce the output keying material (OKM).

Uses

HKDF is widely deployed in modern cryptographic protocols. It is the key derivation mechanism in TLS 1.3, in the Signal protocol's ratcheting design, in the Noise protocol framework, in WireGuard-related constructions, and in many implementations of the Web Cryptography ecosystem via libraries. Its security has been analysed in the random oracle model, showing that HMAC-based extraction and expansion yield a strong KDF under standard assumptions.
