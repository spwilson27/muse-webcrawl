Quantization (image processing)

An image at decreasing numbers of intensity levels.

Quantization, involved in image processing, is a lossy compression technique achieved by compressing a range of values to a single quantum value. When the number of discrete symbols in a given stream is reduced, the stream becomes more compressible. For example, reducing the number of colours required to represent a digital image makes it possible to greatly reduce its file size. Specific applications include discrete cosine transform (DCT) data quantization in JPEG and discrete wavelet transform (DWT) data quantization in JPEG 2000.

Colour quantization

Colour quantization reduces the number of colours used in an image while aiming to keep the result visually similar. This is essential for displaying images on devices supporting limited colours and for formats such as GIF, which permits at most 256 colours per image. Algorithms choose a palette — by popularity, median-cut, or octree methods — and map each original colour to the nearest palette colour. Dithering can then distribute the quantization error among neighbouring pixels, producing gradients that appear smoother at the cost of added noise.

Frequency-domain quantization

In JPEG compression, each 8×8 block's DCT coefficients are divided by entries of a quantization matrix and rounded; high-frequency coefficients, to which human vision is less sensitive, are quantised more coarsely and often become zero, enabling efficient entropy coding. The quality setting of a JPEG encoder essentially scales this matrix.

Quantization error

The difference between the original and quantised value is the quantization error. Too coarse a step size produces visible artefacts: banding (false contours) in smooth gradients, posterization, and blockiness. Grayscale quantization from 256 levels down to a handful makes individual levels plainly visible as flat bands.
