Column space

In linear algebra, the column space (also called the range or image) of a matrix A is the span of its column vectors. It is the set of all possible linear combinations of the columns of A, and equivalently the set of all vectors Ax as x ranges over all vectors.

Definition

If A is an m × n matrix with columns a1, …, an, then the column space of A is

C(A) = { x1a1 + ⋯ + xnan }.

It is a subspace of Rm. The dimension of the column space is called the rank of the matrix.

Relation to linear systems

A linear system Ax = b has a solution if and only if b lies in the column space of A — intuitively, b must be expressible as a combination of the columns. Elementary row operations do not change the row space but do change the column space; however, the columns of the original matrix corresponding to pivot columns of the row-reduced form a basis for the column space.

Four fundamental subspaces

The column space is one of the four fundamental subspaces associated with a matrix, alongside the null space, the row space and the left null space. The column space is orthogonal to the left null space, and the rank–nullity theorem relates the dimensions of these subspaces.
