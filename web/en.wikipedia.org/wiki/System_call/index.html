System call

A system call is the controlled gateway between user programs and the kernel.

In computing, a system call (syscall) is the programmatic way in which a computer program requests a service from the operating system on which it is executed. This may include hardware-related services (for example, accessing a hard disk drive or accessing the device's camera), creation and execution of new processes, and communication with integral kernel services such as process scheduling.

System calls provide an essential interface between a process and the operating system. In most systems, system calls can only be made from userspace processes, while in some systems, OS/360 and successors, privileged system code also issues system calls.

Mechanism

System calls are usually invoked through a software interrupt or special trap instruction (such as syscall on x86-64) that switches the CPU from user mode to kernel mode. The application specifies a system call number and arguments; the kernel validates the request, performs the service, and returns a result. Typical examples on Unix-like systems include read, write, open, fork, and exec.

Library wrappers

Programs rarely invoke system calls directly. Instead, they call functions in the standard library (such as the C library), which wrap the low-level trap mechanism and handle details like setting up registers and reporting errors via errno.

Categories

System calls are commonly grouped into process control, file management, device management, information maintenance, communications, and protection.
