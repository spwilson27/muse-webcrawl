In computational complexity theory, the language TQBF (true quantified Boolean formulas) is a formal language consisting of the quantified Boolean formulas that evaluate to true. A quantified Boolean formula (QBF) is a formula in propositional logic where variables may be quantified by either existential (∃) or universal (∀) quantifiers, for example ∀x ∃y (x ∨ y) ∧ (¬x ∨ ¬y). Deciding whether such a formula is true is the canonical PSPACE-complete problem.

Definition

A fully quantified Boolean formula is one in which every variable is bound by a quantifier, so the formula has no free variables and is simply true or false. It can be evaluated recursively: ∃x φ(x) is true if φ is true for x = true or x = false; ∀x φ(x) is true if φ is true for both assignments. TQBF is the set of all such formulas that are true.

PSPACE-completeness

TQBF can be solved in polynomial space by a straightforward recursive evaluation that reuses space for each level of quantification, placing it in PSPACE. It is also PSPACE-hard: any problem solvable by a polynomial-space Turing machine can be reduced to it, a result central to the proof given in standard treatments following Savitch's theorem. Consequently TQBF is PSPACE-complete. Because PSPACE contains both NP and coNP, quantified formulas are believed to be substantially harder than ordinary satisfiability (SAT): alternation of quantifiers corresponds to the moves of two players, a generalisation that also makes QBF the natural formalism for two-player games.

Applications

Quantified Boolean formulas model problems involving adversarial choices and planning under uncertainty: game solving, formal verification, synthesis, and certain problems in knowledge representation and artificial intelligence. Practical QBF solvers exist and are used in hardware verification, despite the worst-case complexity.
