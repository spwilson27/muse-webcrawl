List of animated feature films

This is a list of notable animated feature films, organised by era, from the earliest works of the 1910s–1930s to the computer-animated era. The first animated feature is generally considered to be the Argentine film El Apóstol (1917), now lost; the oldest surviving animated feature is Lotte Reiniger's silhouette film The Adventures of Prince Achmed (1926).
