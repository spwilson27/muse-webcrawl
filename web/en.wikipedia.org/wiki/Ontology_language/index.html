Ontology language

Ontologies model a domain as classes, properties and individuals.

In computer science and information science, an ontology language is a formal language used to construct ontologies — explicit, machine-processable specifications of the concepts in a domain and the relationships among them. Ontology languages allow users to write conceptualisations that machines can reason over, enabling knowledge sharing, data integration and automated inference.

Characteristics

Most modern ontology languages are based on description logic or first-order logic, and are usually serialised in XML- or RDF-based syntaxes so they can be exchanged on the Web. They typically distinguish classes (sets of individuals), properties (binary relations), and individuals themselves, and support axioms such as subclass relations, domain and range restrictions, and cardinality constraints.

Examples

  • OWL (Web Ontology Language) — the W3C standard family (OWL Lite, OWL DL, OWL Full, and the OWL 2 profiles EL, QL and RL).
  • RDF Schema (RDFS) — a lightweight vocabulary for describing classes and properties in RDF data.
  • Knowledge Interchange Format (KIF) and Common Logic — first-order logic-based interchange formats.
  • CycL — the language of the Cyc knowledge base.
  • Frames and OKBC — frame-based knowledge representation languages.
  • Topic Maps — an ISO standard for representing knowledge structures.

Reasoning

Because many ontology languages rest on decidable fragments of logic, automated reasoners (such as HermiT, Pellet and FaCT++) can check the consistency of an ontology, compute the implied class hierarchy, and classify individuals — services that are central to the Semantic Web vision.
