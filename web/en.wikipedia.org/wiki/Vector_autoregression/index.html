Vector autoregression

Vector autoregression (VAR)
FieldEconometrics, time series analysis
Introduced byChristopher Sims (1980)
GeneralizesAutoregressive (AR) model

Vector autoregression (VAR) is a statistical model used to capture the relationship between multiple quantities as they change over time. It is a type of stochastic process model, generalizing the univariate autoregressive model to multivariate time series: each variable is modelled as a linear function of its own past values and the past values of all the other variables.

Specification

A VAR of order p for a vector of k variables yt is written:

yt = c + A1yt−1 + A2yt−2 + … + Apyt−p + et

where c is a vector of constants, the Ai are coefficient matrices, and et is a vector of error terms. Because each equation contains the same regressors, equation-by-equation ordinary least squares is efficient.

History and applications

The approach was popularized by Christopher Sims in his 1980 paper "Macroeconomics and Reality", which criticized the exclusion restrictions of earlier structural macroeconometric models and proposed treating all variables as endogenous. VARs are widely used in macroeconomics and finance for forecasting, impulse-response analysis of shocks, and forecast-error variance decomposition. Structural VARs (SVARs) add identifying assumptions to interpret the shocks causally, and vector error correction models extend the framework to cointegrated non-stationary series.
