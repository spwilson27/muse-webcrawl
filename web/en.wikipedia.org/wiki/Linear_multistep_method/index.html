Linear multistep method

Linear multistep methods are numerical methods for solving ordinary differential equations. Unlike one-step methods such as Runge–Kutta methods, multistep methods use information from several previous steps to compute the next value of the solution, achieving high accuracy with fewer evaluations of the derivative function per step.

Form

For the initial value problem y′ = f(t, y), a linear multistep method takes the form of a linear combination of past solution values yn, yn−1, … and past and present derivative values fn, fn−1, … equalling zero. If the coefficient of fn+1 is zero the method is explicit; otherwise it is implicit and requires solving an equation at each step, usually by predictor–corrector iteration.

Families

The best-known families are the Adams–Bashforth methods (explicit), Adams–Moulton methods (implicit), and the backward differentiation formulas (BDF), which are widely used for stiff equations in software such as the VODE and CVODE solvers.

Stability and convergence

A multistep method is convergent if it is consistent and zero-stable. The Dahlquist barriers limit the order of zero-stable and A-stable methods: no A-stable linear multistep method can exceed order two, which motivates BDF methods with weaker (A(α)) stability for stiff problems.
