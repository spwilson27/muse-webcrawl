Additive category

In mathematics, specifically category theory, an additive category is a preadditive category in which all finite biproducts exist. A preadditive category is one enriched over abelian groups — each hom-set is an abelian group and composition is bilinear — and a biproduct is an object that is simultaneously a product and a coproduct of a family of objects.

Properties and examples

Every additive category has a zero object, and matrices of morphisms can be used to describe maps between biproducts, closely paralleling linear algebra. The standard example is the category of abelian groups; categories of modules over a ring are also additive. An additive category in which every morphism has a kernel and cokernel, and every monomorphism is a kernel and every epimorphism a cokernel, is an abelian category.
