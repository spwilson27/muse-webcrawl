DDR5 SDRAM

DDR5 SDRAM
Type: Synchronous dynamic random-access memory
Released: 2020 (JEDEC standard, July 2020)
Predecessor: DDR4 SDRAM
Data rates: 4,800–8,400 MT/s and beyond

DDR5 SDRAM (double data rate 5 synchronous dynamic random-access memory) is a type of computer memory and the successor to DDR4. The JEDEC standard was published in July 2020, with modules reaching consumers alongside Intel's 12th-generation Core processors in late 2021.

Improvements

DDR5 doubles the burst length to 16, splits each DIMM into two independent 32-bit subchannels, moves voltage regulation onto the module itself, and adds on-die error correction. Base speeds start at DDR5-4800, well above DDR4-3200, with higher capacities per module.

Adoption

AMD adopted DDR5 exclusively with its Ryzen 7000 (AM5) platform in 2022. Server and data-centre systems followed, and by the mid-2020s DDR5 had become the standard memory for new PCs.
