FidelityFX Super Resolution

FSR upscales a lower-resolution rendered frame
DeveloperAMD
Initial release22 June 2021
TypeUpscaling technology
LicenceMIT (open source)

FidelityFX Super Resolution (FSR) is a set of upscaling technologies developed by AMD as part of its FidelityFX GPUOpen toolkit. It renders a game at a lower internal resolution and reconstructs a higher-resolution image, improving performance with a modest cost in image quality. FSR is open source and runs on a wide range of GPUs, including those of AMD's competitors, as well as on game consoles.

Versions

FSR 1 (2021) is a spatial upscaler: it processes each frame independently using an edge-adaptive scaling algorithm followed by a contrast-adaptive sharpening pass. FSR 2 (2022) is a temporal upscaler that accumulates data from previous frames, using motion vectors and depth information to produce substantially better image quality, requiring deeper integration by game developers. FSR 3 (2023) added frame generation, interpolating an additional frame between rendered ones to increase displayed frame rates, together with latency-reduction features. Later versions have incorporated machine-learning-based upscaling on newer AMD hardware.

Quality modes

FSR offers quality presets such as Ultra Quality, Quality, Balanced, and Performance, which scale the internal render resolution by different factors (from about 1.3× to 2× per dimension), trading image quality against performance.
