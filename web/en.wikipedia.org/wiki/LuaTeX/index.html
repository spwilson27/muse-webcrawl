LuaTeX is a typesetting system derived from TeX that embeds the Lua scripting language as an integral part of the engine. It is the designated successor of pdfTeX and is the default engine for the ConTeXt format; it can also be used with LaTeX through the LuaLaTeX format. Development began in 2006, and version 1.0 was released in 2016.

Features

Unlike traditional TeX engines, LuaTeX gives Lua code access to the internals of the typesetting process—node lists, fonts, callbacks and the paragraph builder—so document behaviours that once required engine modifications can be scripted. LuaTeX natively supports Unicode input, OpenType fonts (via embedded font-handling libraries), and system fonts, and it can embed the MetaPost graphics language (as the MPlib library) for programmatic drawing. It produces PDF output directly and retains much of pdfTeX's micro-typographic extension set.

LuaLaTeX

When run with the LaTeX format, the engine is commonly called LuaLaTeX. Packages such as fontspec allow LuaLaTeX documents to select system OpenType fonts with full feature control, and luaotfload provides the OpenType font loader. LuaLaTeX is one of the engines recommended for new LaTeX documents requiring Unicode and modern fonts.

Development

LuaTeX is developed by a small team including Hans Hagen, Taco Hoekwater and Hartmut Henkel, with roots in the earlier Aleph and Omega projects that had extended TeX for multilingual typesetting. Since version 1.0 the engine has been considered feature-stable, with ongoing maintenance releases.
