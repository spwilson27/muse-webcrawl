A cue sheet, or cue file, is a metadata text file describing how the tracks of a CD or DVD are laid out. Cue sheets are stored as plain text files, usually with a .cue extension, and accompany a single data file containing the disc audio or data (the "BIN/CUE" pair). The format originated with the CDRWIN CD-recording program.

Format

A cue sheet lists, for each file, its tracks in order, each track's type (audio, data mode) and its index points — including INDEX 01, the track start, and an optional INDEX 00 pregap. Times are expressed in minutes:seconds:frames (75 frames per second). CD-Text information such as performer and title can be embedded with REM and string commands.

FILE "album.wav" WAVE
  TRACK 01 AUDIO
    TITLE "First Song"
    INDEX 01 00:00:00
  TRACK 02 AUDIO
    INDEX 00 03:41:12
    INDEX 01 03:43:12

Uses

Beyond burning discs, cue sheets let media players treat one long audio file (e.g. a ripped CD as a single FLAC or WAV) as separate tracks. They are widely used in lossless audio archiving, DJ mixes, and emulation of CD-based game consoles.
