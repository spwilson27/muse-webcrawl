UEFI

The Unified Extensible Firmware Interface (UEFI) is a specification, maintained by the UEFI Forum, that defines the architecture of the platform firmware used for booting computers and its interface for interaction with the operating system. UEFI firmware provides several technical advantages over the traditional BIOS, including the ability to boot from drives larger than 2 tebibytes, support for the GUID Partition Table (GPT), a modular driver model, and a pre-boot environment that can include networking and a graphical interface.

History

UEFI originated as Intel's Extensible Firmware Interface (EFI), developed in the late 1990s for the Itanium architecture; the first specification, EFI 1.02, was released in 2000. In 2005 Intel transferred the specification to the newly formed UEFI Forum, whose members include AMD, Apple, Dell, HP, IBM, Lenovo, and Microsoft. Macintosh computers adopted EFI beginning in 2006, and UEFI became standard on Windows PCs following the launch of Windows 8 and Microsoft's Secure Boot requirement for certification in 2012.

Features

UEFI defines boot services and runtime services available to loaders and operating systems. A UEFI system boots by loading EFI application images — typically a boot loader stored as a .efi file in the EFI System Partition, a FAT32 partition on the boot disk. Firmware can include a Compatibility Support Module (CSM) that emulates legacy BIOS booting, though many vendors have removed it. Secure Boot uses digital signatures to ensure that only trusted boot software runs, a feature intended to block bootkits and rootkits but also criticized for complicating the installation of alternative operating systems.

Implementation

Most UEFI firmware is built on the TianoCore EDK II open-source codebase. The firmware executes in phases — security, pre-EFI initialization, driver execution, boot device selection, and runtime — and exposes variables stored in NVRAM for boot configuration shared between firmware and operating system.
