Stationary point

In mathematics, particularly calculus, a stationary point of a differentiable function of one variable is a point on the graph of the function where the derivative is zero — that is, where the function neither increases nor decreases locally, and the tangent line is horizontal. Stationary points are important because local maxima and minima of a differentiable function can occur only at stationary points or at endpoints of the domain.

Classification

Stationary points are classified using the first or second derivative tests. With the first derivative test, if the derivative changes sign from positive to negative, the point is a local maximum; from negative to positive, a local minimum; if it does not change sign, the point is a point of inflection (for example, x = 0 for f(x) = x³). With the second derivative test, if f″(x) > 0 the point is a local minimum, and if f″(x) < 0 a local maximum; if f″(x) = 0 the test is inconclusive. Stationary points that are neither a local maximum nor a local minimum, such as horizontal inflections, are sometimes called saddle points in one dimension.

Higher dimensions

For functions of several variables, stationary points (critical points) are those where the gradient vanishes. They are classified by the Hessian matrix: positive definite indicates a local minimum, negative definite a local maximum, and indefinite a saddle point. Critical points are central to optimization, differential topology (Morse theory), and physics, where equilibrium configurations of a system correspond to stationary points of its energy or action.
