In the theory of computation, a branch of theoretical computer science, a pushdown automaton (PDA) is a type of automaton that employs a stack. Pushdown automata are used in theories about what can be computed by machines. They are more capable than finite-state machines but less capable than Turing machines. The term "pushdown" refers to the fact that the stack can be regarded as being "pushed down" like a tray dispenser at a cafeteria, since the operations never work on elements other than the top of the stack.

A pushdown automaton manipulates an input tape together with a stack.

A finite-state machine only needs to track its current state to know everything about its past computations, which is a finite amount of information. A pushdown automaton has the additional ability to store an unbounded amount of information on its stack, although it can only access that information in a last-in, first-out manner. The class of languages recognized by pushdown automata is exactly the class of context-free languages, which include languages such as the set of all correctly matched parentheses and the language of palindromes (in the nondeterministic case).

Informal description

A pushdown automaton differs from a finite-state machine in two ways:

  1. It can use the top of the stack to decide which transition to take.
  2. It can manipulate the stack as part of performing a transition, pushing a symbol onto it or popping the top symbol off.

A pushdown automaton can also read input symbols, as a finite automaton does, and it may additionally make transitions that consume no input symbol (ε-transitions) and transitions that push or pop without reading input. Acceptance is usually defined in one of two equivalent ways: by final state, in which the automaton accepts if it reaches a designated accepting state after consuming the whole input, or by empty stack, in which it accepts if it empties its stack after consuming the whole input.

Formal definition

A pushdown automaton is formally defined as a 7-tuple:

M = (Q, Σ, Γ, δ, q0, Z0, F)

  • Q is a finite set of states;
  • Σ is a finite set called the input alphabet;
  • Γ is a finite set called the stack alphabet;
  • δ is the transition function, mapping Q × Σε × Γε into finite subsets of Q × Γ*;
  • q0 ∈ Q is the start state;
  • Z0 ∈ Γ is the initial stack symbol;
  • F ⊆ Q is the set of accepting (final) states.

A configuration of the automaton is a triple (q, w, α) giving the current state, the input remaining to be read, and the contents of the stack. A deterministic pushdown automaton (DPDA) is one in which the transition function never offers a choice of moves and never mixes input-consuming and ε-moves from the same configuration. Unlike the nondeterministic case, deterministic PDAs are strictly weaker: they recognize exactly the deterministic context-free languages, a proper subset of the context-free languages. For example, a DPDA can recognize { anbn } but no DPDA can recognize all even-length palindromes, because the machine cannot guess where the middle of the string lies.

Example

The language L = { anbn : n ≥ 0 } is not regular — no finite-state machine can recognize it, because doing so requires counting an unbounded number of a's. A pushdown automaton recognizes it easily: it pushes a marker onto the stack for every a read, and once b's begin to appear it pops one marker per b. If the stack empties exactly as the input ends, the string is accepted.

On a: push A
On first b: switch state; on each b: pop A
Accept if input exhausted and stack empty

Equivalence with context-free grammars

Every context-free grammar can be transformed into an equivalent pushdown automaton that accepts the same language, and vice versa. The automaton can simulate a leftmost derivation of the grammar on its stack: it repeatedly expands the variable on top of the stack using a production of the grammar, or matches a terminal on top of the stack against the next input symbol. This equivalence makes PDAs a central tool in the design of parsers for programming languages, whose syntax is conventionally specified by context-free grammars.

Generalizations and restrictions

Equipping a pushdown automaton with two stacks yields a machine equivalent in power to a Turing machine, because the two stacks can simulate the two halves of a Turing tape. Conversely, if the stack alphabet has only one symbol, the automaton degenerates to a counter automaton, which is weaker than a general PDA. A PDA whose stack depth is bounded is equivalent to a finite-state machine, since only finitely many configurations remain possible.
