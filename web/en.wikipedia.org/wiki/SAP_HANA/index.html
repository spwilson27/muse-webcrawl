SAP HANA (High Performance Analytic Appliance) is an in-memory, column-oriented, relational database management system and application platform developed by SAP SE. First announced in 2010 and generally available in 2011, HANA stores data primarily in main memory rather than on disk, enabling very fast transactional and analytical processing on the same data — a combination known as HTAP.

Architecture

HANA combines row and column stores in memory, with data compression, parallel query execution across many CPU cores, and persistence to storage for recovery. It incorporates application services, integration and data-quality tools, spatial and text analytics, predictive libraries, and support for multiple engines (relational, graph, document, time series). Deployment options include on-premises appliances, certified hardware configurations, and cloud editions (SAP HANA Cloud).

History and ecosystem

HANA grew out of SAP research including the TREX search engine, the P*TIME in-memory transaction system acquired with Transact in Memory, and the MaxDB lineage, championed by SAP co-founder Hasso Plattner and executive Vishal Sikka. It became the foundation of SAP's product strategy: the SAP Business Suite was adapted as S/4HANA (launched 2015), SAP's flagship ERP, which runs exclusively on HANA. The database is also offered to third-party applications and is supported by hardware partners including IBM, Dell, HPE, Lenovo, and Fujitsu, as well as hyperscale cloud providers.

Editions and licensing

HANA is sold in platform and enterprise editions with optional components; a free developer/express edition (SAP HANA, express edition) is available for smaller memory footprints. Licensing is typically based on memory size (per gigabyte) for the database.
