Stackless Python, or Stackless, is a significant fork of the Python programming language interpreter. It avoids the C call stack for much of the interpreter's own operation, enabling features such as microthreads (tasklets), channels and coroutines for highly concurrent programming.

Features

Tasklets are lightweight units of execution that can be scheduled cooperatively and communicate through channels. This makes Stackless well suited to simulation and game servers; it became famous as the engine behind the massively multiplayer game EVE Online.

Influence

Although its changes were never merged into mainstream CPython, Stackless influenced the design of greenlet, gevent and other concurrency libraries for Python.
