π-calculus

ParadigmProcess calculus, concurrency
Designed byRobin Milner, Joachim Parrow, David Walker
First appeared1992

In theoretical computer science, the π-calculus (or pi-calculus) is a process calculus developed by Robin Milner, Joachim Parrow, and David Walker in the early 1990s as a continuation of work on the calculus of communicating systems (CCS). It is designed to describe concurrent systems whose configuration or topology changes during computation.

Overview

The defining feature of the π-calculus is name mobility: processes interact by sending and receiving names of communication channels along channels themselves. Because a process can receive a channel name it did not previously know, the set of connections between processes is dynamic — a property that lets the calculus model mobile telephony, internet protocols, and software with changing structure.

Syntax

Processes are built from a small grammar: the null process 0; input x(y).P, which receives a name on channel x and continues as P; output x̄⟨z⟩.P, which sends name z along x; parallel composition P | Q; restriction (νx)P, which creates a fresh private name; replication !P; and choice P + Q.

Semantics and variants

The calculus is given meaning by structural congruence, reduction rules for communication, and labelled transition semantics with notions of bisimulation used to prove processes equivalent. Variants include the polyadic π-calculus, higher-order π-calculus, asynchronous π-calculus, and the spi calculus, which adds cryptographic primitives. The π-calculus is Turing complete, and fragments of it underpin the session-type theory of communication protocols.
