Chaos game

In mathematics, the term chaos game originally referred to a method of creating a fractal, using a polygon and an initial point selected at random inside it. The fractal is created by iteratively generating a sequence of points: starting from a random point in the polygon, each successive point is a given fraction of the distance between the previous point and a randomly chosen vertex. Repeating this process many times produces a deterministic fractal pattern from random choices.

ProducesAttractors of iterated function systems, e.g. Sierpinski triangle

Description

With a triangle and a contraction factor of one half, the chaos game produces the Sierpinski triangle: although each vertex is chosen at random, the plotted points never fall in the central inverted triangle or other "holes" of the fractal. With a square and no restrictions, the points simply fill the square uniformly; adding restrictions — such as forbidding the same vertex twice in a row — yields intricate fractal patterns instead.

Relation to iterated function systems

The chaos game is a Monte Carlo method for rendering the attractor of an iterated function system (IFS). The random iteration visits points of the attractor with a frequency related to the probabilities assigned to the maps, giving a picture of the invariant measure of the system.

Applications

A modified form, chaos game representation (CGR), maps DNA sequences to points in a square by letting each of the four nucleotides occupy a corner. CGR is used in bioinformatics for alignment-free sequence comparison and visualisation of genomic patterns.
