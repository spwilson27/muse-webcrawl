Dynamic Host Configuration Protocol

From Wikipedia, the free encyclopedia
Dynamic Host Configuration Protocol
AbbreviationDHCP
PortsUDP 67 (server), 68 (client)
StandardRFC 2131 (1997)
[Image: Diagram of the DHCP four-step exchange: Discover, Offer, Request, Acknowledge (DORA)]

The Dynamic Host Configuration Protocol (DHCP) is a network management protocol used on Internet Protocol networks for automatically assigning IP addresses and other communication parameters to devices. It is the reason a laptop joining a coffee-shop Wi-Fi network 'just works': no one typed an address.

When a device connects, it broadcasts a DHCP Discover message; a DHCP server (often built into the home router) answers with an Offer of an address; the device Requests it, and the server Acknowledges, granting the address as a time-limited lease, together with the subnet mask, default gateway and DNS server addresses. The exchange is remembered by its initials: DORA. Leases let a network recycle addresses among far more devices than could hold them permanently, and centralise configuration so administrators change settings in one place.

DHCP (1993) succeeded the earlier BOOTP and is defined in RFC 2131; its IPv6 counterpart, DHCPv6, complements IPv6's stateless autoconfiguration.
