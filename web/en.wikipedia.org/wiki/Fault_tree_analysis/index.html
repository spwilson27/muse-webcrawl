Fault tree analysis

Fault tree analysis (FTA) is a top-down, deductive failure analysis in which an undesired state of a system (the "top event") is analysed using Boolean logic to combine lower-level events that could cause it. The result is a graphical fault tree: a diagram of the pathways by which component failures, human errors, and external events can combine to produce the system failure. FTA is widely used in safety engineering and reliability engineering in aerospace, nuclear power, chemical processing, and other high-hazard industries.

Method

Analysis begins by defining the top event — a specific failure such as "reactor core overheats". The analyst then asks what immediate combinations of events could cause it, connecting them through logic gates: an OR gate means any input alone suffices; an AND gate means all inputs must co-occur (for example, a failure plus failure of its backup). Decomposition continues until events are reached that need no further development — basic events such as component failures, whose probabilities can be estimated from data. Standard symbols include circles for basic events, rectangles for intermediate events, diamonds for undeveloped events, and house shapes for expected (normal) events.

Qualitatively, the tree is reduced to its minimal cut sets: the smallest combinations of basic events whose occurrence guarantees the top event. Quantitatively, basic-event probabilities are propagated through the logic to compute the probability of the top event, and importance measures identify which components contribute most to system risk, guiding design changes.

History

Fault tree analysis was developed in 1961–62 by H. A. Watson and colleagues at Bell Telephone Laboratories under a US Air Force contract to evaluate the Minuteman I intercontinental ballistic missile launch control system. Boeing adopted and extended the method, and it was taken up by the nuclear industry, notably in the 1975 Reactor Safety Study (WASH-1400). It is now standardised in documents such as the NRC Fault Tree Handbook and is a complement to bottom-up methods such as failure mode and effects analysis (FMEA).
