GridFTP is an extension of the File Transfer Protocol (FTP) designed for high-performance, secure and reliable transfer of very large datasets in grid computing environments. Developed within the Globus project and standardised through the Open Grid Forum, it became the standard data-moving protocol of large scientific collaborations, notably the Worldwide LHC Computing Grid, which used it to distribute petabytes of particle-physics data.

Features

GridFTP adds to FTP a set of capabilities aimed at wide-area, high-bandwidth networks:

  • Parallel data streams — multiple simultaneous TCP connections between the same hosts to fill high bandwidth-delay product links.
  • Striped transfers — data distributed across several servers at each end, aggregating their bandwidth and storage throughput.
  • Partial and restartable transfers — support for transferring file ranges and resuming interrupted transfers, essential for multi-gigabyte files.
  • Security — authentication, integrity protection and optional confidentiality using GSI (Grid Security Infrastructure, based on X.509 certificates).
  • Third-party transfers — one host can orchestrate a direct transfer between two others.
  • Automatic TCP tuning — negotiation of buffer and window sizes for optimal throughput.

Implementations and successors

The reference implementation ships with the Globus Toolkit (the globus-url-copy client and GridFTP server), and the protocol was supported by storage systems at CERN, Fermilab and other laboratories. GridFTP underpinned the Globus transfer service used by thousands of research institutions. More recently, HTTP-based transfer (WebDAV/HTTPS with third-party copy) has been adopted as the LHC grid's successor protocol, though GridFTP remains in production use.
