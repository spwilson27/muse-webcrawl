Classification (machine learning)

In machine learning and statistics, classification is the problem of identifying which of a set of categories (sub-populations) an observation (or observations) belongs to. Examples include assigning an email to the "spam" or "non-spam" class, and assigning a diagnosis to a given patient based on observed characteristics.

Overview

Classification is an instance of supervised learning, where a training set of correctly identified observations is available. An algorithm that implements classification, especially in a concrete implementation, is known as a classifier. The corresponding unsupervised procedure is known as clustering.

Algorithms

Common classification algorithms include logistic regression, decision trees, random forests, support vector machines, k-nearest neighbors, naive Bayes, and artificial neural networks.

Evaluation

Classifier performance is commonly evaluated using a confusion matrix, from which metrics such as accuracy, precision, recall, and the F1 score are derived. Techniques such as cross-validation are used to estimate performance on unseen data.
