Unified Process

The Unified Process (UP) is an iterative and incremental software development process framework. The best-known refinement is the Rational Unified Process (RUP), developed by Rational Software (later IBM) and described by Ivar Jacobson, Grady Booch, and James Rumbaugh—the "Three Amigos" behind the Unified Modeling Language (UML), which the process uses as its primary notation.

Phases

UP divides a project into four phases, each ending in a milestone: Inception (scope, business case, and feasibility), Elaboration (requirements and a proven executable architecture), Construction (building the remaining features in iterations), and Transition (deployment, beta testing, and user training). Within each phase, work proceeds in time-boxed iterations, each producing a tested increment of the system.

Characteristics

The process is use-case driven, architecture-centric, and risk-focused: iterations are planned to address the highest risks first. Workflows (disciplines) such as requirements, analysis and design, implementation, and test run across all phases with varying intensity. UP influenced later agile and scaled frameworks; lighter variants include the Unified Process's open-source OpenUP and the Agile Unified Process.
