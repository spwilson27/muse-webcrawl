Automatic repeat request

Automatic repeat request (ARQ), also known as automatic repeat query, is an error-control method for data transmission that uses acknowledgements (messages sent by the receiver indicating that it has correctly received a packet) and timeouts (specified periods of time allowed to elapse before an acknowledgment is to be received) to achieve reliable data transmission over an unreliable communication channel. If the sender does not receive an acknowledgment before the timeout, it retransmits the packet until the sender receives an acknowledgment or exceeds a predefined number of retransmissions.

Variants

Stop-and-wait ARQ

In the simplest scheme, the sender transmits one frame and waits for an acknowledgement before sending the next. It is reliable but inefficient on links with a high bandwidth-delay product, because the channel sits idle during each round trip.

Go-Back-N ARQ

Go-Back-N allows the sender to have several frames outstanding within a sliding window. If a frame is lost or received in error, the receiver discards it and all subsequent frames, so the sender retransmits from the lost frame onward.

Selective Repeat ARQ

Selective Repeat avoids retransmitting correctly received frames: the receiver buffers out-of-order frames and requests only the missing ones. It is the most efficient of the three but requires more complex buffering and bookkeeping at both ends.

Hybrid ARQ

Hybrid ARQ (HARQ) combines ARQ with forward error correction: instead of discarding an erroneous packet, the receiver stores it and combines it with retransmissions, which may carry additional redundancy (incremental redundancy). HARQ is used in HSPA, LTE and 5G NR radio interfaces, where it operates at the physical layer with very short turnaround times.
