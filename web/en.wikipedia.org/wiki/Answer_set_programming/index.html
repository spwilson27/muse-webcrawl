Answer set programming

Answer set programming (ASP) is a form of declarative programming oriented towards difficult, primarily NP-hard, search problems. It is based on the stable model (answer set) semantics of logic programming, in which a problem is encoded as a logic program whose answer sets correspond to solutions of the problem.

Overview

In the ASP approach, search problems are reduced to computing stable models of a program, and answer set solvers — systems such as Clingo, DLV and smodels — are used to find them. A typical ASP program consists of rules of the form a0 :- a1, ..., am, not am+1, ..., not an. where not denotes negation as failure. Unlike Prolog, ASP programs are evaluated without a query-driven execution order, and the semantics is defined model-theoretically.

Applications

ASP has been applied to problems in knowledge representation and reasoning, planning, configuration, bioinformatics, and natural language processing. Its combination of a expressive modelling language with efficient solvers makes it a prominent paradigm within artificial intelligence research.
