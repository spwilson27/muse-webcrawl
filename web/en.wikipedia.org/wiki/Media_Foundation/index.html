The Media Foundation pipeline: sources, transforms, and sinks

Media Foundation (MF) is a COM-based multimedia framework and application programming interface developed by Microsoft for digital media on Windows Vista and later versions of Windows. It is the successor to DirectShow and is intended to provide a unified platform for audio and video playback, capture, transcoding, and content protection.

Architecture

Media Foundation processes media through a pipeline of components. Media sources generate data (from files, networks, or capture devices), Media Foundation Transforms (MFTs) decode, encode, or otherwise process it, and media sinks render or store the result. Pipelines can be constructed as full topologies managed by the Media Session, or applications can use lower-level primitives such as the Source Reader and Sink Writer for simpler scenarios like transcoding and capture.

The framework was designed with digital rights management support through the Protected Media Path, high-definition content, and hardware-accelerated video processing in mind. It supports the DXVA 2.0 video acceleration model and integrates with Direct3D.

Applications

Windows Media Player versions from Windows 7 onward use Media Foundation for playback of many formats, as do the Windows media apps, Microsoft Edge media playback, and many third-party applications and games. Built-in transforms include decoders and encoders for formats such as H.264, AAC, MP3, and MPEG-4, with later Windows versions adding support for formats such as HEVC, VP9, and AV1 through extensions.

Criticism

Developers have criticised Media Foundation for its complexity, its asynchronous programming model, and historically restricted access to raw camera data through standard APIs, which limited some augmented-reality and computer-vision applications until later Windows updates added additional access paths.
