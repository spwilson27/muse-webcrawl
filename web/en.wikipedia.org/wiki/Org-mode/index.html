Org-mode

Org Mode (also: Org-mode; stylised Org) is a mode for document editing, formatting and organizing within the free software text editor Emacs. It is a plain-text markup language and outliner designed for keeping notes, authoring documents, computational notebooks, maintaining to-do lists, and project planning.

History

Org Mode was created by German astrophysicist Carsten Dominik in 2003 to organize his own work and life in Emacs; it was included as part of Emacs from version 22.1 (2007). It is maintained by a community of contributors, long led by Bastien Guerry, and developed as a GNU project.

Features

  • Outlining: documents are hierarchies of headlines marked with asterisks, which can be folded, moved and reorganised.
  • Task management: TODO keywords, priorities, tags, deadlines and scheduled dates, with an "agenda" view collecting items from many files.
  • Markup and export: lightweight markup for emphasis, lists, tables and links; one keystroke exports to HTML, LaTeX/PDF, ODT, Markdown and other formats.
  • Literate programming: Org Babel embeds executable source-code blocks in dozens of languages, with results woven into the document, making Org popular for reproducible research.
  • Spreadsheets and capture: tables with formulas, and "capture" templates for quickly filing notes from anywhere in Emacs.

File format

Org files are plain text, usually with the .org extension, and are therefore amenable to version control and readable without Emacs. The format's simplicity has inspired implementations and mobile apps outside Emacs, such as Orgzly (Android) and beorg (iOS).
