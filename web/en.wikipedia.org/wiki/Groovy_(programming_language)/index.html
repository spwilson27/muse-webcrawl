Groovy (programming language)

First appeared2003
Designed byJames Strachan
PlatformJava Virtual Machine
TypingDynamic, static, strong, optional

Apache Groovy is a programming language for the Java platform with both dynamic and static typing features, designed to enhance developer productivity with a concise, familiar syntax. It integrates smoothly with any Java program and delivers features including closures, builders, runtime and compile-time metaprogramming, and DSL support.

History

Groovy was developed by James Strachan beginning in 2003, growing out of ideas for an enhanced, scriptable dialect of Java. It was standardized through the Java Community Process as JSR 241 and released as Groovy 1.0 in 2007. The project later came under Pivotal Software and in 2015 moved to the Apache Software Foundation, becoming Apache Groovy.

Features

Groovy's syntax is largely compatible with Java while adding list and map literals, string interpolation (GStrings), closures, operator overloading, safe-navigation operators and builders for XML, JSON and UI construction. Code can be compiled to JVM bytecode ahead of time or run as scripts. It underlies the Grails web framework, the Gradle build tool (which uses a Groovy-based DSL), the Spock testing framework and Jenkins pipeline scripts.
