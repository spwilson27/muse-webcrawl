Text-based user interface

A text-based user interface (TUI), also called a text user interface or terminal user interface, is a user interface that operates within the constraints of text displays and character cells, as opposed to a graphical user interface (GUI) using windows, icons, and a pointing device. TUIs can display menus, forms, windows, and colours using characters and terminal escape sequences.

History

Text interfaces were the norm on computer terminals before GUIs became widespread in the 1980s. Unlike simple command-line interfaces, full-screen TUIs — such as those built with the Unix curses library — manage the whole screen, support mouse input and drop-down menus, and were used in popular applications like the Norton Commander file manager, Lotus 1-2-3, and DOS-based word processors.

Modern use

TUIs remain common in system administration, embedded systems, network equipment, and developer tools, where they run efficiently over remote connections such as SSH. Modern libraries and frameworks (for example ncurses, Textual, and Bubble Tea) continue the tradition, and many BIOS/UEFI setup utilities and installer programs use text-mode interfaces.
