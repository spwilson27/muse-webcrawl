Real-time simulation

Real-time simulation refers to a computer simulation that runs at the same rate as actual time — that is, the simulated system's state is computed in step with a wall clock, so that one second of simulated time takes one second of real time. If the computation for a time step takes longer than the step itself, the simulation cannot keep up and ceases to be "real-time."

Applications

Real-time simulation is essential wherever a simulated system must interact with real hardware or human operators. In hardware-in-the-loop (HIL) testing, a physical controller — such as an engine control unit or a protective relay — is connected to a simulator that emulates the plant it will control, allowing safe, repeatable testing of faults that would be dangerous or expensive on real equipment. Flight simulators and driving simulators likewise run in real time to train operators.

Power systems and control

Digital real-time simulators built by companies such as RTDS Technologies and OPAL-RT simulate electrical power grids with time steps of tens of microseconds, enabling engineers to test protection and control equipment against detailed electromagnetic-transient models. In control engineering, real-time simulation supports rapid control prototyping and model-based design workflows in tools such as Simulink.
