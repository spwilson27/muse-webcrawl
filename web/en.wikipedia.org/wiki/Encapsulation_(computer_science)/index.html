Encapsulation (computer science)

In programming languages and software design, encapsulation refers to the bundling of data with the methods that operate on it, and the restriction of direct access to some of an object's components. It is one of the fundamental concepts of object-oriented programming, alongside inheritance, polymorphism, and abstraction.

Information hiding

Encapsulation implements information hiding: a module exposes a public interface while keeping its internal representation private. In languages such as Java and C++, access modifiers (public, protected, private) enforce this at compile time. Users of a class interact with it through methods such as getters and setters, so the internal representation can change without breaking client code, provided the interface is preserved.

Benefits and criticism

Advocates argue that encapsulation reduces coupling, protects invariants, and makes code easier to maintain and test. Critics note that indiscriminate use of accessors can amount to little more than procedural access to the data, and that overly rigid boundaries can impede refactoring.

Networking usage

The term is also used in networking for the wrapping of data in protocol headers as it passes down the protocol stack — for example, a TCP segment encapsulated in an IP packet, itself encapsulated in an Ethernet frame.
