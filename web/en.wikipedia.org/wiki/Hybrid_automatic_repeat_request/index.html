Hybrid automatic repeat request

Hybrid automatic repeat request (hybrid ARQ or HARQ) is a method of error control for data transmission that combines forward error correction (FEC) with the retransmission mechanism of automatic repeat request (ARQ). The receiver attempts to decode each block using the FEC code; if decoding fails, it requests a retransmission but keeps the received data, combining the old and new transmissions to improve the chance of successful decoding.

Types

In Chase combining, each retransmission repeats the same coded block, and the receiver combines the copies by maximal-ratio combining, gaining signal energy. In incremental redundancy (IR), each retransmission sends different parity bits, so that the combined codeword has a lower code rate and stronger error-correcting capability. HARQ with incremental redundancy can approach the performance of a well-designed code while adapting the effective code rate to channel conditions.

Applications

HARQ is a central part of modern mobile radio standards, including UMTS/HSPA, LTE and 5G NR, where multiple parallel HARQ processes allow continuous transmission while waiting for acknowledgements. It is also used in standards such as IEEE 802.16 (WiMAX).
