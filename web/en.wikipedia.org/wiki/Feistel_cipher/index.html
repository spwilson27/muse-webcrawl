Feistel cipher

A Feistel cipher (or Feistel network) is a symmetric structure used in the construction of block ciphers, named after the German-American cryptographer Horst Feistel, who pioneered the design at IBM in the early 1970s. It underlies the Data Encryption Standard (DES) and many other ciphers.

Structure

A Feistel network splits the block into two halves, conventionally L and R. In each round, a round function F — which takes a subkey derived from the main key — is applied to one half, and the result is combined with the other half using XOR; the halves are then swapped. Schematically, from (Li, Ri) the next round computes Li+1 = Ri and Ri+1 = Li ⊕ F(Ri, Ki).

Properties

The structure's celebrated advantage is that encryption and decryption are nearly identical: the round function need not be invertible, because the XOR-and-swap arrangement reverses itself simply by running the subkeys in reverse order. This simplifies hardware and software implementation. The security of a Feistel cipher depends on the round count and the strength of F; theoretical work by Luby and Rackoff showed that a Feistel network with enough rounds of a good pseudorandom function is itself a strong pseudorandom permutation.

Examples

Notable Feistel ciphers include DES, its variant Triple DES, Blowfish, Twofish (in part), Camellia, CAST-128 and the GOST cipher. The Advanced Encryption Standard (AES) is not a Feistel cipher but uses a substitution–permutation network instead.
