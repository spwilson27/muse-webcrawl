Worley noise

Worley noise is a noise function introduced by Steven Worley in 1996 for use in procedural texture generation in computer graphics. It is a type of cellular noise: the function is based on the distances from a sample point to a set of randomly distributed feature points, producing patterns that resemble cells, pebbles, scales or cracked surfaces.

Algorithm

The algorithm proceeds as follows:

  • Feature points are distributed randomly throughout the space, typically with one point in each cell of a regular grid.
  • For any point being evaluated, the distances to the nearest feature points are computed and ordered: F1 is the distance to the closest point, F2 to the second closest, and so on.
  • The returned value is some combination of these distances, such as F1, F2 − F1, or a weighted combination.

Using F1 alone yields a pattern of rounded cells similar to a Voronoi diagram, while F2 − F1 produces thin borders along cell boundaries, useful for simulating cracks, veins or giraffe-like markings.

Applications

Worley noise is widely used in 3D rendering and game development to synthesise textures such as stone, water surfaces, clouds, lizard skin, marble and biological cell structures. It is implemented in many graphics packages, shader languages and procedural generation tools, often alongside gradient noise functions such as Perlin noise and simplex noise. Because feature points can be animated over time, the noise can also generate effects such as caustics in shallow water.
