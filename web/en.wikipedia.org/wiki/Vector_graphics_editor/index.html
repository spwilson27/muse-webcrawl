Vector graphics editor

A vector graphics editor is a computer program that allows users to compose and edit vector graphics images interactively on a computer, and save them in one of many popular vector graphics formats, such as EPS, PDF, WMF, SVG, or VML. Rather than storing an image as a grid of pixels, a vector editor stores it as a collection of geometric objects — points, lines, Bézier curves, polygons and text — each with attributes such as position, stroke and fill colour, which can be scaled to any size without loss of quality.

Features

The defining tool of a vector editor is the pen tool, which creates paths from anchor points and direction handles using cubic Bézier curves. Shapes can be combined with Boolean operations (union, intersection, difference), arranged in layers and groups, transformed (translated, rotated, scaled, sheared), and filled with solid colours, gradients or patterns. Editors typically include typography tools with text-on-a-path, clipping paths and masks, blend modes, and import/export filters. Because vector images are resolution-independent, they are the standard choice for logos, icons, technical illustration, typography and artwork destined for print.

Comparison with raster editors

Vector editors differ from raster (bitmap) graphics editors such as photo editors, which manipulate pixels and are better suited to photographs and painterly effects. The two approaches are complementary: designers often prepare artwork in a vector editor and rasterise it at the target resolution for output. Most modern editors blur the boundary, offering some raster effects inside a vector workflow.

Notable editors

Well-known vector graphics editors include Adobe Illustrator, CorelDRAW, Affinity Designer, Figma, Sketch, and the free and open-source Inkscape. Xfig and MacDraw were among the early examples. The native format of the web is SVG, an open XML-based standard supported by editors and browsers alike.
