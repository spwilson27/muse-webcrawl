Likelihood function

In statistical inference, the likelihood function measures how well a statistical model explains observed data as a function of the model's parameters. Formally, for observed data x from a distribution with parameter θ, the likelihood is L(θ | x) = f(x | θ): the probability (or probability density) of the data, viewed as a function of the parameter with the data fixed.

Maximum likelihood estimation

The value of the parameter that maximises the likelihood function is the maximum likelihood estimate. Because products of probabilities are unwieldy, inference usually works with the log-likelihood, which turns products into sums and has the same maximum. Likelihood theory, developed largely by R. A. Fisher in the 1920s, underlies much of modern statistics.

Likelihood principle and ratios

The likelihood principle states that all information about a parameter contained in an experiment is in the likelihood function. Ratios of likelihoods for two parameter values quantify the relative support the data give to those values, and likelihood-ratio tests are a standard method of hypothesis testing.
