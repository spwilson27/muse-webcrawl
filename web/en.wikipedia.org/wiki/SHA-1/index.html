SHA-1

Designers: National Security Agency
First published: 1993 (as SHA-0); 1995 (SHA-1)
Series: SHA-0, SHA-1, SHA-2, SHA-3
Digest size: 160 bits
Block size: 512 bits
Structure: Merkle–Damgård construction
Rounds: 80

In cryptography, SHA-1 (Secure Hash Algorithm 1) is a hash function which takes an input and produces a 160-bit (20-byte) hash value known as a message digest – typically rendered as 40 hexadecimal digits. It was designed by the United States National Security Agency, and is a U.S. Federal Information Processing Standard. The algorithm has been cryptographically broken but was previously widely used.

SHA-1 produces a message digest based on principles similar to those used by Ronald L. Rivest of MIT in the design of the MD2, MD4 and MD5 message digest algorithms, but generates a larger hash value (160 bits vs. 128 bits).

Development

SHA-1 was developed as part of the U.S. Government's Capstone project. The original specification of the algorithm was published in 1993 under the title Secure Hash Standard, FIPS PUB 180, by the U.S. government standards agency NIST (National Institute of Standards and Technology). This version is now often named SHA-0. It was withdrawn by the NSA shortly after publication and was superseded by the revised version, published in 1995 in FIPS PUB 180-1, generally designated SHA-1.

Cryptanalysis and validation

The algorithm's security has been gradually undermined since 2005, when researchers found collision attacks more efficient than the birthday attack. In 2017, researchers at Google and CWI Amsterdam produced the first demonstrated SHA-1 collision, known as the "SHAttered" attack, generating two distinct PDF files with the same SHA-1 digest. In 2020, a practical chosen-prefix collision attack was demonstrated. Major browsers and certificate authorities deprecated SHA-1 support, and NIST formally deprecated the algorithm, recommending migration to the SHA-2 and SHA-3 families.

Applications

SHA-1 formed part of several widely used security applications and protocols, including TLS and SSL, PGP, SSH, and the Git version control system, which uses SHA-1 hashes to identify objects (Git has been transitioning to SHA-256).
