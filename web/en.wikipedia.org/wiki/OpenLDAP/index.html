OpenLDAP is a free, open-source implementation of the Lightweight Directory Access Protocol (LDAP) developed by the OpenLDAP Project. It is released under its own BSD-style license called the OpenLDAP Public License. LDAP is a platform-independent protocol.

Several common Linux distributions include OpenLDAP Software for LDAP support. The software also runs on BSD-variants, as well as AIX, HP-UX, macOS, Solaris, Microsoft Windows (NT and derivatives), and z/OS.

History

The project was started in 1998 by Kurt Zeilenga. The project started by cloning the LDAP reference source from the University of Michigan where a long-running project had supported development and evolution of the LDAP protocol until that project's end in 1996.

As of August 2019, the OpenLDAP project has four team members: Gavin Henry (Scotland), Howard Chu (US), Pierangelo Masarati (Italy), and Michael Ströder (Germany), plus a large contingent of contributors.

Components

The OpenLDAP project has four main components:

  • slapd – stand-alone LDAP daemon
  • slurpd – stand-alone LDAP update replication daemon (deprecated and removed)
  • routines supporting LDAP – library of LDAP programming routines
  • utilities, tools, and sample clients

Also, the OpenLDAP project provides several subprojects: JLDAP (a Java LDAP class library), JDBC-LDAP (a Java JDBC – LDAP bridge driver), ldapc++ (an LDAP C++ class library), and Fortress (a role-based access control system).

Backends

The overall modular design of OpenLDAP allows for a variety of storage and access backends. The backends are of a variety of kinds: BDB and HDB (Berkeley DB-based backends), MDB (a Memory-Mapped Database based on LMDB), SQL (a proxy backend to SQL databases), Monitor, Config, and several others.
