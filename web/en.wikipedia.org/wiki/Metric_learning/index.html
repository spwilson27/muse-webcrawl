Metric learning

Metric learning is the task in machine learning of learning a distance function over objects that captures task-specific notions of similarity. A learned metric is typically used to make similar objects lie close together and dissimilar objects far apart, improving the performance of tasks such as classification with k-nearest neighbours, clustering, and information retrieval.

Approaches

Classical approaches learn a Mahalanobis distance, d(x, y) = √((x−y)T M (x−y)), where the positive semi-definite matrix M is optimised subject to constraints derived from labelled pairs (must-link / cannot-link) or relative comparisons ("x is closer to y than to z"). Representative algorithms include Large Margin Nearest Neighbor (LMNN), Neighbourhood Components Analysis (NCA), and Information-Theoretic Metric Learning (ITML).

Deep metric learning

With deep learning, a neural network learns an embedding space in which distance directly reflects semantic similarity, trained with losses such as the contrastive loss (Siamese networks), triplet loss (notably in face recognition, e.g. FaceNet), and their many extensions. Applications include face and person re-identification, image and product retrieval, few-shot learning, and recommendation.
