Public key

In cryptography, a public key is one half of a pair of keys used in public-key (asymmetric) cryptography. The public key may be shared openly and is used to encrypt messages or verify digital signatures, while the corresponding private key is kept secret and is used to decrypt messages or create signatures.

How it works

Key pairs are generated by mathematical algorithms based on one-way functions, such as integer factorisation in RSA or discrete logarithms in Diffie–Hellman and elliptic-curve cryptography. Anyone can encrypt a message with a recipient's public key, but only the holder of the private key can decrypt it. Conversely, data signed with a private key can be verified by anyone with the public key.

Distribution

Public keys are distributed via digital certificates issued by certificate authorities, forming public key infrastructure (PKI), or through webs of trust, key servers and direct exchange. Authentic distribution is essential to prevent man-in-the-middle attacks.
