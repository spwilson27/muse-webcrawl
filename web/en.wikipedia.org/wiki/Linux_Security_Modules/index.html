Linux Security Modules

Linux Security Modules (LSM) is a framework in the Linux kernel that allows a variety of computer security models to be implemented as loadable kernel modules. The framework provides security hooks at key points inside the kernel — for example when files are opened, processes are created, or network packets are processed — so that a security module can permit or deny an operation according to its policy.

History

The LSM framework was developed in the early 2000s, in part in response to the NSA's SELinux work, to avoid tying the kernel to any single security model. It was merged into the Linux kernel in version 2.6.

Security modules

Well-known modules built on LSM include SELinux, AppArmor, Smack, TOMOYO Linux, and Yama. Since kernel 5.1, multiple major LSMs can be stacked and enabled simultaneously.
