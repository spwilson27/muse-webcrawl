Quadratic field

In algebraic number theory, a quadratic field is an algebraic number field of degree two over the rational numbers ℚ. Every quadratic field has the form ℚ(√d) for a unique square-free integer d ≠ 0, 1. If d > 0 the field is called a real quadratic field; if d < 0, an imaginary quadratic field.

Ring of integers and class number

The ring of integers of ℚ(√d) consists of elements (a + b√d)/2 with a, b ∈ ℤ of the same parity when d ≡ 1 (mod 4), and of a + b√d otherwise. Quadratic fields are the simplest test case for many questions in number theory, including the class number problem: Gauss conjectured that infinitely many real quadratic fields have class number one, while exactly nine imaginary quadratic fields (the Heegner numbers) have class number one.

Units

The unit group of a real quadratic field is infinite, generated (modulo ±1) by a fundamental unit connected with solutions of Pell's equation; the units of an imaginary quadratic field are finite, consisting only of roots of unity.
