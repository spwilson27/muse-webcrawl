YAML

YAML
Filename extension: .yaml, .yml
First released: 2001
Type: Data serialization language
Designed by: Clark Evans, Ingy döt Net, Oren Ben-Kiki

YAML (a recursive acronym for "YAML Ain't Markup Language") is a human-readable data serialization language commonly used for configuration files and in applications where data is stored or transmitted. It is designed for readability, using indentation to indicate structure, and is a superset of JSON: any valid JSON document is also a valid YAML document.

Syntax

YAML represents data with mappings (key–value pairs), sequences (lists), and scalars. Structure is expressed by indentation with spaces rather than braces or brackets, though a flow style similar to JSON is also supported:

person:
  name: Ada Lovelace
  roles:
    - programmer
    - writer
active: true

Features include comments beginning with #, multi-line ("block") scalars, anchors and aliases for repeated content, and explicit type tags. The specification's rich implicit typing has also caused pitfalls — famously, unquoted values such as no, on, or country code NO being parsed as booleans (the "Norway problem").

Uses

YAML is ubiquitous in DevOps and software configuration: Kubernetes manifests, Ansible playbooks, Docker Compose files, GitHub Actions workflows, GitLab CI, OpenAPI descriptions, and the configuration of countless applications and static site generators.
