Video for Windows

DeveloperMicrosoft
ReleasedNovember 1992
TypeMultimedia framework

Video for Windows (VfW) is a multimedia framework developed by Microsoft, first released in November 1992 as an add-on for Windows 3.1. It allowed Windows applications to play back digital video, and introduced the Audio Video Interleave (AVI) file format.

Video for Windows playing back an early AVI clip on Windows 3.1.

Features

Video for Windows consisted of a runtime for video playback, the Media Player application, and a set of tools for capturing and editing video, including VidCap and VidEdit. It supported software codecs such as Microsoft Video 1, Cinepak, and Intel Indeo, which made it possible to play small, low-frame-rate videos (typically 160×120 or 320×240 pixels at 15 frames per second) on the personal computers of the era.

The framework provided programming interfaces (the VCM/VfW APIs) that allowed hardware vendors to support video capture cards and codecs. Video for Windows was Microsoft's response to Apple's QuickTime, which had appeared a year earlier for the Macintosh.

Legacy

The technology became part of the core Windows operating system with Windows 95. Video for Windows was later supplanted by DirectShow in the late 1990s, but the AVI format it created remained in widespread use for many years, and the VfW interfaces are still supported for compatibility in modern versions of Windows.
