In computational number theory, the Lucas test is a primality test for a natural number n. It can be used to prove that n is prime if the complete factorization of n − 1 is known.

Statement

Let n > 1 be an odd integer. If there exists an integer a with 1 < a < n such that an−1 ≡ 1 (mod n), and for every prime factor q of n − 1, a(n−1)/q is not congruent to 1 (mod n), then n is prime. Such an a is a primitive root modulo n, and its existence with the stated order certifies that the multiplicative group modulo n has an element of order n − 1, which is possible only when n is prime.

Background

The test descends from work of Édouard Lucas in the 19th century. It is the conceptual basis of the Lucas–Lehmer test for Mersenne numbers and of Pocklington's criterion, which relaxes the need for a full factorization of n − 1. A related probabilistic method, the Lucas probable prime test based on Lucas sequences, is combined with the Miller–Rabin test in the Baillie–PSW primality test, for which no counterexamples are known.

Applications

Because the test produces a verifiable certificate of primality (the witness a together with the factorization), it and its refinements are used in primality proving, for example for numbers of special form and in cryptographic key generation where proven primes are required.
