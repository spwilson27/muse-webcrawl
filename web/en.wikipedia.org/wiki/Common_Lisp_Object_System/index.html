Common Lisp Object System

CLOS combines classes, multiple inheritance and generic functions with multiple dispatch.

The Common Lisp Object System (CLOS) is the facility for object-oriented programming in ANSI Common Lisp. CLOS is a dynamic object system which differs radically from the OOP facilities found in more static languages such as C++ or Java. CLOS was inspired by earlier Lisp object systems such as MIT Flavors and Xerox CommonLoops, although it differs from both.

Features

  • Multiple inheritance — a class can inherit from several superclasses, with a class precedence list resolving conflicts.
  • Generic functions and multiple dispatch — methods are not attached to a single class but to generic functions, which dispatch on the classes of all required arguments.
  • Method combination — methods can be qualified as :before, :after or :around the primary method, or combined using custom combination types.
  • Dynamic redefinition — classes can be redefined at run time, and existing instances are updated accordingly.
  • Metaobject protocol — the implementation of CLOS itself is exposed as objects that can be customised, allowing users to change the semantics of the object system.

Example

Classes are defined with defclass, generic functions with defgeneric, and methods with defmethod. Slots may have accessor, reader, writer and initialisation options, and instances are created with make-instance.

Influence

CLOS ideas influenced later systems including Dylan, Julia's multiple dispatch, and generic-function libraries in other languages. Its metaobject protocol, documented in The Art of the Metaobject Protocol (1991), is a landmark in the design of reflective programming systems.
