Server Message Block

Server Message Block (SMB)
PurposeNetwork file sharing, printer sharing, inter-process communication
DeveloperBarry Feigenbaum (IBM); later Microsoft
Introduced1983
PortsTCP 445 (direct); 137–139 (over NetBIOS)

Server Message Block (SMB) is a communication protocol used to provide shared access to files and printers across nodes on a network. It also provides an authenticated mechanism for inter-process communication. SMB originated at IBM in the 1980s and was extensively developed by Microsoft, becoming the basis of Windows file and print sharing. In the mid-1990s Microsoft renamed an extended version Common Internet File System (CIFS), though the SMB name has since prevailed again.

Versions

SMB 1.0, the original version, is a "chatty" request–response protocol now considered obsolete and insecure; vulnerabilities in it were exploited by the WannaCry ransomware outbreak of 2017. SMB 2.0, introduced with Windows Vista, sharply reduced the number of commands, added support for symbolic links and larger buffers, and improved performance over wide-area networks. SMB 3.0, shipped with Windows 8 and Windows Server 2012, added end-to-end encryption, multichannel connections, and transparent failover for clustered file servers.

Implementations

Beyond Windows, the most widely used implementation is Samba, the free software suite that lets Unix and Linux servers interoperate with Windows clients. SMB is also supported by macOS and most network-attached storage systems.
