Quasiconcave function

In mathematics, a quasiconcave function is a function whose domain and range are subsets of a real vector space, and which satisfies the inequality

f(θx + (1−θ)y) ≥ min{f(x), f(y)}

for all x, y in the domain and θ ∈ [0, 1]. Equivalently, a function is quasiconcave if its upper level sets are convex sets. A function that is both quasiconcave and quasiconvex is called quaslinear.

A quasiconcave function: its upper level sets are convex

Properties

Every concave function is quasiconcave, but the converse is not true: quasiconcavity is a strictly weaker property. Unlike concavity, quasiconcavity is preserved under any monotonic (nondecreasing) transformation of the function values, because it depends only on the ordering of values, not their magnitudes.

A quasiconcave function on an interval is first non-decreasing and then non-increasing, so it has a single peak (or a plateau of maximal points). This single-peakedness makes quasiconcave functions useful in optimization, where local maxima of a quasiconcave function on a convex set behave well.

Applications

Quasiconcave functions appear prominently in mathematical economics: utility functions are typically assumed quasiconcave, which is precisely the statement that consumers prefer balanced bundles — the upper contour sets (indifference sets) are convex. Quasiconcavity also arises in game theory, in the theory of production functions, and in statistics.
