IEEE 802.11i

IEEE 802.11i-2004, or 802.11i for short, is an amendment to the IEEE 802.11 standard specifying security mechanisms for wireless networks. Ratified on 24 June 2004, it replaced the broken Wired Equivalent Privacy (WEP) with a Robust Security Network (RSN) framework based on strong encryption and authentication. The Wi-Fi Alliance's WPA2 certification is based on the full IEEE 802.11i standard. The amendment was later incorporated into IEEE 802.11-2007.

Background

WEP, the original security protocol of 802.11, was shown in 2001 to be fundamentally flawed: its use of the RC4 stream cipher with short 24-bit initialisation vectors allowed key recovery from passively collected traffic. As an interim fix, the Wi-Fi Alliance created WPA in 2003, based on a draft of 802.11i, introducing TKIP (Temporal Key Integrity Protocol) as a firmware-upgradable patch for existing hardware. IEEE 802.11i completed the work with a full redesign around the Advanced Encryption Standard (AES).

Architecture

802.11i defines a Robust Security Network with three entities: the station (supplicant), the access point (authenticator), and an authentication server, typically RADIUS. Authentication can use IEEE 802.1X with an EAP method (Enterprise mode) or a pre-shared key (PSK, Personal mode). A Pairwise Master Key is established, from which session keys are derived. The standard mandates CCMP — Counter Mode with CBC-MAC Protocol — based on AES, providing confidentiality, authentication, and replay protection; TKIP is retained as an optional transitional protocol.

The four-way handshake

To derive fresh session keys, the supplicant and authenticator perform a four-way handshake using nonces exchanged in EAPOL-Key frames. From the Pairwise Master Key and the two nonces both sides compute a Pairwise Transient Key, split into keys for confirming the handshake, encrypting keys, and encrypting data. A separate group key handshake distributes the broadcast/multicast Group Temporal Key.

Encryption protocols

  • TKIP — wraps RC4 with per-packet key mixing, a 48-bit sequence counter, and the Michael message integrity check; designed for legacy hardware and now deprecated.
  • CCMP — AES in counter mode with CBC-MAC; the mandatory-to-implement cipher of 802.11i and default of WPA2.
  • WRAP — an earlier AES-based proposal (offset codebook mode) dropped in favour of CCMP.

Security issues

In 2017 the KRACK (Key Reinstallation Attacks) disclosed by Mathy Vanhoef showed that the four-way handshake could be manipulated into reinstalling an already-used key, weakening encryption on most implementations; the flaw was addressed by software patches and later by WPA3 (2018), which replaced the PSK handshake with SAE (Simultaneous Authentication of Equals).
