Graph traversal

In computer science, graph traversal (also known as graph search) refers to the process of visiting (checking and/or updating) each vertex in a graph. Such traversals are classified by the order in which the vertices are visited. Tree traversal is a special case of graph traversal.

Redundancy

Unlike tree traversal, a general graph may contain cycles, so a vertex might be reached more than once. Graph traversal algorithms therefore keep track of which vertices have already been visited — for example with a boolean visited array or a hash set — to avoid processing a vertex twice and to guarantee termination on cyclic graphs.

Classification

Graph traversal algorithms are generally classified by the order in which vertices are first visited:

  • Breadth-first search (BFS) — explores all vertices at the present depth before moving to vertices at the next depth level; implemented with a queue. BFS finds shortest paths (in edges) in unweighted graphs.
  • Depth-first search (DFS) — explores as far as possible along each branch before backtracking; implemented with a stack or recursion. DFS is used in topological sorting, cycle detection, and maze solving.

Applications

Graph traversal underlies algorithms for connectivity, shortest paths, spanning trees, web crawling, garbage collection (mark-and-sweep), and the analysis of social and transportation networks.
