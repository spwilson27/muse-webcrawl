Egress filtering

In computer networking, egress filtering is the practice of monitoring and restricting the flow of information from one network to another — typically, packets leaving a private network toward the Internet. It is the counterpart of ingress filtering, which restricts incoming traffic. Egress filtering is performed by firewalls and routers using rules based on source and destination addresses, ports and protocols.

Egress filtering controls what may leave a network.

Purposes

A primary purpose is anti-spoofing: a network should never emit packets whose source address does not belong to that network, a practice recommended in IETF BCP 38 (for ingress) and RFC 2827. Egress rules can also block malware "phone home" connections to command-and-control servers, prevent data exfiltration, stop compromised machines from sending spam or participating in distributed denial-of-service attacks, and enforce organisational policy on which internal systems may reach the Internet at all.

Implementation

Administrators commonly permit outbound traffic only on required ports (for example DNS, HTTP/HTTPS through a proxy, and mail submission), route all web traffic through an explicit proxy, and log denied connections for analysis. Overly permissive egress is regarded as a common weakness, since many attacks succeed only if the attacker can establish an outbound channel.
