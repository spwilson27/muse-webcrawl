Bus (computing)

TypeCommunication system
ExamplesPCI Express, USB, SATA, I²C

Expansion slots on a motherboard connected by bus traces.

In computer architecture, a bus is a communication system that transfers data between components inside a computer, or between computers. Early computer buses were parallel electrical wires with multiple hardware connections, but the term now covers any physical or logical system sharing the same function, including serial links that carry data one bit at a time.

Structure

A classical bus consists of three functional groups of lines: the data bus, which carries the payload; the address bus, which specifies the source or destination of the data; and the control bus, which carries commands and timing signals. Devices attached to a shared bus must arbitrate for access, because only one device can transmit at a time on a simple shared medium.

Evolution

As processors grew faster, parallel buses faced problems of clock skew and signal interference, and shared buses became bottlenecks. Modern architectures therefore favour high-speed point-to-point serial interconnects — such as PCI Express and USB — which are still commonly called buses although they are switched networks of dedicated links. Within chips, bus standards such as AMBA connect processor cores to memory and peripherals.
