Hölder condition

In mathematics, a real or complex-valued function f on d-dimensional Euclidean space satisfies a Hölder condition, or is Hölder continuous, when there are nonnegative real constants C and an exponent α with 0 < α ≤ 1, such that |f(x) − f(y)| ≤ C‖x − y‖α for all x and y in the domain of f. The condition is named after Otto Hölder.

For α = 1 the condition is the Lipschitz condition, while for α = 0 it says merely that the function is bounded. The Hölder condition is a quantitative strengthening of uniform continuity: every Hölder continuous function is uniformly continuous, but not conversely (the function 1/log|x| near 0 is a standard counterexample).

Hölder spaces

The collection of functions satisfying a Hölder condition, equipped with a norm combining the supremum norm and the smallest admissible constant C, forms a Banach space called a Hölder space, denoted C0,α. Generalised versions in which derivatives up to some order are themselves Hölder continuous play a central role in the theory of partial differential equations, beginning with the Schauder estimates for elliptic equations. Hölder continuity also appears in the definition of paths of Brownian motion, which are almost surely Hölder continuous for every exponent α < 1/2 but not for α = 1/2.
