Direct-sequence spread spectrum

In telecommunications, direct-sequence spread spectrum (DSSS) is a spread-spectrum modulation technique primarily used to reduce overall signal interference, whereby the signal to be transmitted is spread over a frequency band much wider than the minimum bandwidth required. Each data bit is represented by multiple "chips" — a fast pseudonoise code sequence — so the signal becomes resistant to narrowband interference and to detection, and multiple users can share the same channel with different codes.

Principle

The transmitter multiplies the data stream by a high-rate chipping sequence known to both transmitter and receiver; the receiver correlates the incoming signal with the same sequence to recover the data, a process called despreading, which restores the desired signal while spreading any narrowband interferer. The ratio of chip rate to data rate is the processing gain.

Uses

DSSS underlies code-division multiple access (CDMA) mobile telephony standards such as IS-95 and CDMA2000, the original IEEE 802.11 and 802.11b Wi-Fi standards, and the civilian signals of the Global Positioning System, whose C/A code spreads each satellite's navigation data.
