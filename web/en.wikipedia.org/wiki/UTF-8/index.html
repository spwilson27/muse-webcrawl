UTF-8

UTF-8 is a variable-length character encoding standard for Unicode, defined by the Unicode Standard and by RFC 3629. It uses one to four 1-byte units (8-bit code units) to encode all 1,112,064 valid Unicode code points. UTF-8 is backward compatible with ASCII: the first 128 Unicode characters are encoded identically to their ASCII counterparts in a single byte. It is by far the dominant encoding on the World Wide Web, used by the overwhelming majority of web pages, and is the default or recommended encoding for most modern software.

History

UTF-8 was designed at Bell Labs by Ken Thompson and Rob Pike in September 1992 for the Plan 9 operating system; Thompson famously sketched the design on a placemat. It was presented publicly in 1993 and later standardised by the Unicode Consortium and the IETF. Its self-synchronising design—a decoder can find the start of a character from any byte—made it robust and simple to adopt.

Encoding scheme

The leading bits of the first byte indicate the sequence length: 0xxxxxxx (1 byte, ASCII), 110xxxxx (2 bytes), 1110xxxx (3 bytes), 11110xxx (4 bytes); continuation bytes all begin with 10. Characters in most European scripts take two bytes; most Chinese, Japanese and Korean characters take three; emoji and rare historic scripts take four.

Adoption

UTF-8 became the most common encoding for web pages in the late 2000s and now accounts for nearly all web content. It is the required default in standards such as JSON (in practice), HTML5, and XML recommendations, and the standard character set for most programming languages' source files and for Unix-like systems generally.
