Cap height

In typography, cap height is the height of a capital letter above the baseline in a particular typeface. Specifically, it is the height of capital letters that are flat, such as H or I, as opposed to round letters such as O, or pointed letters such as A, both of which may display overshoot.

Relation to other measurements

Cap height is one of several vertical measurements defining a typeface's proportions, alongside the x-height (height of lowercase letters such as x), the ascender height, and the descender depth. The ratio between cap height and x-height influences the apparent size and readability of type: faces with a large x-height relative to cap height appear bigger at the same point size and are often preferred for body text and signage. Cap height is measured from the baseline to the top of the flat capital; in metal type it was a fraction of the point size, and in digital fonts it is specified in the font's metric tables (for example, the sCapHeight value in OpenType OS/2 metrics).

Use

Type designers use cap height when aligning text with graphic elements, setting all-capitals text, and designing complementary typefaces. CSS provides the cap unit, equal to the cap height of the current font, allowing layouts to align precisely with capital letters.
