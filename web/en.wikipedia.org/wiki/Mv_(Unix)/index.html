mv (Unix)

mv is a Unix command that moves one or more files or directories from one place to another. If both file system locations are on the same file system, this results in simply renaming the file; otherwise the file content is copied to the new location and the old file is removed.

Usage

The basic syntax is mv source target. Common options include -i (prompt before overwriting), -f (force overwrite without prompting), -n (never overwrite an existing file), -v (verbose), and -u (move only when the source is newer). The command is part of GNU coreutils on Linux and was standardised in POSIX; it dates back to early editions of Unix from Bell Labs in the 1970s.
