Unary operation

In mathematics, a unary operation is an operation with only one operand, i.e. a single input. Formally, it is a function f : A → B where A and B are sets; when the operation maps a set to itself it is a function f : A → A. The term contrasts with binary operations (two operands) and ternary operations (three operands); collectively these are described by their arity.

Examples

Common unary operations include:

  • Negation and the additive inverse: −x
  • Absolute value: |x|
  • Factorial: n!, written with a postfix symbol
  • Square root and other functions such as the trigonometric functions sin, cos and tan
  • Logical NOT in Boolean algebra
  • Transpose of a matrix and the successor function on natural numbers

In computer science

Programming languages provide many unary operators. In C-like languages these include increment (++) and decrement (--), unary plus and minus, logical negation (!), bitwise complement (~), address-of (&) and dereference (*), and the sizeof operator. Unary operators may be written in prefix notation (before the operand), postfix notation (after it, as with factorial), or in function-call style. In the lambda calculus and functional programming, unary functions are the norm, since multi-argument functions can be simulated by currying.

Unary numeral system

The simplest numeral system, unary, represents a natural number by repeating a single symbol that many times — as in tally marks. It is the basis of counting in some contexts and appears in theoretical computer science, for instance in the encoding of Turing machine inputs.
