Spanner is a distributed SQL database management and storage service developed by Google. It provides features such as global transactions, strongly consistent reads, and automatic multi-shard replication and failover. Spanner is used internally for services including Google Ads and Google Play, and is offered publicly as Cloud Spanner on Google Cloud Platform. It is the database that underpins the claim that a system can be both globally distributed and strongly consistent — a landmark counterexample to loose readings of the CAP theorem.

TrueTime and external consistency

Spanner's defining idea is the TrueTime API, which exposes clock uncertainty explicitly. Google equips its data centers with GPS receivers and atomic clocks so that servers know the time with a bounded error interval (typically a few milliseconds). By waiting out the uncertainty interval before committing ("commit wait"), Spanner assigns timestamps that guarantee external consistency: if transaction T1 commits before T2 starts in real time, T1 receives the smaller timestamp. This makes Spanner the first system to offer globally consistent, lock-free snapshot reads at scale.

Architecture

Data is stored in tables sharded into "splits", each replicated across zones with the Paxos consensus algorithm; two-phase commit across Paxos groups provides global ACID transactions. Spanner was described in a 2012 OSDI paper and an expanded 2017 SIGMOD paper, "Spanner: Becoming a SQL System", which added a full SQL interface. Its design strongly influenced open-source successors such as CockroachDB and TiDB.
