Five-qubit error correcting code

The five-qubit error correcting code is the smallest quantum error correcting code that can protect a single logical qubit against arbitrary single-qubit errors. It encodes one logical qubit in five physical qubits and is a perfect code: it saturates the quantum Hamming bound, meeting the theoretical minimum number of physical qubits needed to correct all single-qubit errors. The code was introduced independently in 1996 by Raymond Laflamme and collaborators, and by Charles Bennett and collaborators.

Properties

The code has parameters [[5,1,3]]: five physical qubits (n = 5), one logical qubit (k = 1), and code distance d = 3, allowing it to correct any single-qubit error — a bit flip (X), a phase flip (Z), or a combined bit-and-phase flip (Y) — on any one of the five qubits. There are 15 possible nontrivial single-qubit errors (three Pauli errors on each of five qubits) plus the identity, and the code's 24 = 16 syndromes exactly distinguish all of them, which is why it is called perfect.

Stabilizer description

The code is a stabilizer code whose stabilizer group is generated by four cyclically related operators: XZZXI, IXZZX, XIXZZ, and ZXIXZ, where X, Z, and I denote the Pauli X, Pauli Z, and identity operators on successive qubits. Logical operators may be taken as XXXXX (logical X̄) and ZZZZZ (logical Z̄). Unlike the seven-qubit Steane code, the five-qubit code is not a CSS code, since its stabilizer generators mix X and Z operators.

Significance

Because it uses the fewest possible qubits for single-error correction, the five-qubit code is a benchmark in quantum computing experiments, and encoding and error-correction circuits for it have been demonstrated on several hardware platforms, including trapped ions and superconducting qubits. Its relatively complicated encoding circuit and non-transversal gates, however, make larger codes such as the surface code more practical for fault-tolerant architectures.
