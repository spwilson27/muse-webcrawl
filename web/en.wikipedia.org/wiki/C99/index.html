C99

C99
Standard: ISO/IEC 9899:1999
Language: C
Predecessor: C90 (ANSI C)
Successor: C11

C99 is a past version of the ISO C standard, formally ISO/IEC 9899:1999, which revised the C programming language after the C90 standard. It was adopted in 1999 and introduced a number of features that had originated in C++ and in compiler extensions.

Features

New features included inline functions, declarations anywhere in a block, variable-length arrays, flexible array members, the long long int type, complex numbers, designated initializers, compound literals, the restrict keyword, single-line // comments, and new library headers such as stdint.h and stdbool.h.

Adoption

Adoption was gradual: GCC supported most of C99 early, while Microsoft's Visual C++ lagged for years. C99 was superseded by C11 in 2011, which made some C99 features optional, but C99 remains a widely used baseline dialect.
