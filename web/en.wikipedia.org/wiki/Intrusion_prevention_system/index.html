Intrusion prevention system


Type: Network security appliance
Related: Intrusion detection system (IDS)

An intrusion prevention system (IPS), also known as an intrusion detection and prevention system (IDPS), is a network security appliance that monitors network or system activities for malicious activity and can react in real time to block or prevent it. Unlike a purely passive intrusion detection system (IDS), an IPS sits inline in the traffic path and can drop malicious packets, reset connections, and block traffic from offending addresses.

Detection methods

IPS products use signature-based detection against known attack patterns, protocol and statistical anomaly detection, and stateful protocol analysis. Modern next-generation firewalls commonly integrate IPS functions, and host-based variants protect individual servers and endpoints.

Responses

When an event is detected, an IPS may drop the offending packets, terminate the session, block the source address, or alert administrators. Because it acts inline, false positives can disrupt legitimate traffic, so tuning and careful placement are essential; a fail-open design ensures connectivity if the appliance itself fails.

History

The concept grew out of IDS technology in the late 1990s, with early dedicated products from companies such as OneSecure and IntruVert (later acquired by NetScreen and McAfee respectively), and open-source systems such as Snort gaining inline prevention modes.
