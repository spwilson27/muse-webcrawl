Cross-site request forgery

In a CSRF attack, a malicious site causes the victim's browser to send an unwanted request to a trusted site.

Cross-site request forgery, also known as one-click attack or session riding and abbreviated as CSRF (sometimes pronounced "sea-surf") or XSRF, is a type of malicious exploit of a website or web application where unauthorised commands are submitted from a user that the web application trusts. In a CSRF attack, an innocent end user is tricked by an attacker into submitting a web request that they did not intend — for example by visiting a page that automatically submits a form to a site where the user is logged in, changing settings or making a transaction.

Characteristics

Unlike cross-site scripting (XSS), which exploits the trust a user has for a particular site, CSRF exploits the trust that a site has in a user's browser: the forged request carries the victim's cookies, so the target site cannot distinguish it from a legitimate request. The attacker does not need to see the response, only to cause a state-changing action.

Prevention

Standard defences include synchroniser tokens — unpredictable secret values embedded in forms and checked by the server — SameSite cookies, which restrict when cookies are sent with cross-site requests, and checking Origin or Referer headers. Requiring re-authentication or confirmation for sensitive actions provides additional protection.
