Tiling window manager

A tiling window manager is a window manager with an organisation of the screen into mutually non-overlapping frames, as opposed to the more popular stacking approach in which windows may overlap like sheets of paper. Tiling managers arrange windows to use all available screen space and encourage keyboard-driven control.

Approaches

Manual tiling managers (such as i3) let the user specify how containers split; dynamic managers (such as dwm, awesome, and xmonad) apply predefined layouts — for example a large main area with a stack beside it — that adjust automatically as windows open and close. Many offer workspaces, floating exceptions for dialogues, and configuration through text files or scripting.

History

Tiling interfaces date to early systems such as Xerox's Cedar environment and Microsoft Windows 1.0, which tiled rather than overlapped windows. Modern tiling managers became popular with Unix and Linux users from the 2000s; similar snapping features have since been adopted by mainstream desktop systems.
