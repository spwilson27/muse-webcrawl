Fixed point (mathematics)

In mathematics, a fixed point (sometimes shortened to fixpoint) of a function is an element of the function's domain that is mapped to itself by the function. That is to say, c is a fixed point of the function f if f(c) = c. This means f(f(...f(c)...)) = fn(c) = c, which is a repeating sequence called an orbit.

A set of fixed points is sometimes called a fixed set. For example, if f is defined on the real numbers by f(x) = x2 − 3x + 4, then 2 is a fixed point of f, because f(2) = 2.

Not all functions have fixed points: for example, f(x) = x + 1 has no fixed points, since x + 1 is never equal to x for any real number. In graphical terms, a fixed point x means the point (x, f(x)) is on the line y = x, or in other words the graph of f has a point in common with that line.

Attractive fixed points

An attractive fixed point of a function f is a fixed point x0 of f such that for any value of x in the domain that is close enough to x0, the iterated function sequence x, f(x), f(f(x)), f(f(f(x))), ... converges to x0. A commonly used tool is the Banach fixed-point theorem, which gives conditions under which a contraction mapping on a complete metric space has a unique fixed point.

Fixed-point theorems

A number of famous results guarantee the existence of fixed points under suitable conditions. The Brouwer fixed-point theorem states that every continuous function from a closed ball to itself has a fixed point. The Knaster–Tarski theorem gives fixed points for monotone functions on complete lattices, and the Kleene fixed-point theorem underlies denotational semantics and recursive definitions in computer science.

Applications

Fixed points are central to many areas: solving equations by iteration, equilibrium points in game theory (a Nash equilibrium is a fixed point of the best-response correspondence), compilers and the lambda calculus (the Y combinator constructs fixed points), and the analysis of dynamic systems.
