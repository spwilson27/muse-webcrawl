2D computer graphics

2D computer graphics is the computer-based generation of digital images — mostly from two-dimensional models such as geometric shapes, text and digital images — and by techniques specific to them. The word may stand for the branch of computer science that comprises such techniques or for the models themselves.

2D graphics are used extensively in user interfaces, electronic documents, video games, digital publishing and image processing. They are divided chiefly into two families: raster graphics, which store an image as a rectangular grid of pixels, and vector graphics, which describe an image as mathematical paths, lines and curves that can be scaled without loss of quality.

Raster graphics

In raster (or bitmap) graphics, each pixel of a rectangular array carries a colour value. Raster formats such as PNG, JPEG and GIF are used for photographs and scanned images. Operations on raster images include scaling, rotation, filtering and compositing; because pixels are discrete, enlarging a raster image produces visible pixelation.

Vector graphics

Vector graphics represent images by geometric primitives — points, lines, Bézier curves, circles and polygons — together with attributes such as fill colour and stroke width. They are the standard for logos, typefaces, technical illustration and formats such as SVG. Vector images are resolution-independent and are rasterised (converted to pixels) at display time.

Rendering and APIs

Rendering 2D graphics involves drawing primitives in a painter's-algorithm order, applying transformations (translation, scaling, rotation) expressed as affine matrices, and compositing with alpha blending. Widely used 2D graphics libraries and APIs include Cairo, Skia, Java 2D, the HTML canvas element and the drawing layers of operating-system windowing toolkits.

Applications

Two-dimensional graphics underpin desktop publishing, cartography, technical drawing, sprite-based video games, animation, and the graphical user interfaces of nearly all personal computers and mobile devices.
