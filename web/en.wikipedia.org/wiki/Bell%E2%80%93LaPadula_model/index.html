Bell–LaPadula model

TypeComputer security model
Developed1973, David Bell and Leonard LaPadula
FocusConfidentiality, mandatory access control

The Bell–LaPadula model (BLP) is a state machine model used for enforcing access control in government and military applications, developed by David Elliott Bell and Leonard J. LaPadula in the 1970s at MITRE for the US Air Force. It formalises mandatory access control to protect data confidentiality using security labels and clearances.

Rules

The model is built on two mandatory properties. The simple security property ("no read up") states that a subject at a given security level may not read an object at a higher level. The *-property or star property ("no write down") states that a subject may not write to an object at a lower level, preventing classified information from leaking downward. A discretionary security property adds access matrices, and the tranquillity principle restricts changes to security labels during operation.

Influence and limitations

Bell–LaPadula influenced the design of secure operating systems and the US Department of Defense "Orange Book" evaluation criteria (TCSEC). The model addresses confidentiality only — not integrity, which is the concern of the Biba model — and it does not by itself solve covert channel problems, which its authors addressed in later work.
