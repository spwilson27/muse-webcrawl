Haskell (/ˈhæskəl/) is a general-purpose, statically-typed, purely functional programming language with type inference and lazy evaluation. Designed for teaching, research and industrial application, Haskell has pioneered a number of programming language features such as type classes, which enable type-safe operator overloading, and monadic input/output (IO). It is named after the logician Haskell Curry. Haskell's main implementation is the Glasgow Haskell Compiler (GHC).

History

After the release of Miranda in 1985, interest in lazy functional languages grew, but proliferation hampered adoption; at a 1987 conference in Portland, Oregon (FPCA '87), a committee was formed to consolidate the existing languages into a common standard. Successive reports defined Haskell 1.0 (1990) through Haskell 98 and the Haskell 2010 revision. The language has served as a testbed for research ideas — software transactional memory, type families, generalised algebraic data types — many of which later entered mainstream languages.

Features

Haskell is purely functional: functions have no side effects, with effects such as IO isolated in monads. Evaluation is non-strict (lazy) by default. Its static type system, based on Hindley–Milner inference extended with type classes, allows most type errors to be caught at compile time while requiring few annotations. Notable libraries and applications include the Pandoc document converter, the xmonad window manager, ShellCheck, and GHC itself; content- and finance-industry users include Meta (spam filtering with Haxl) and several banks.

Example

quicksort [] = []
quicksort (p:xs) = quicksort [x | x <- xs, x < p] ++ [p] ++ quicksort [x | x <- xs, x >= p]
