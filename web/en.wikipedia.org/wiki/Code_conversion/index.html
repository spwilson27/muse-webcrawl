Code conversion

Code conversion refers to the translation of data or programs from one encoding, format or instruction set into another. The term is used in fields including data communications, software porting and building regulation.

In computing

In computing, code conversion includes character-encoding conversion, such as between ASCII, EBCDIC and Unicode formats; transcoding of media files; and the conversion of source code between programming languages or of legacy code, for example COBOL systems, to modern environments. In telecommunications it may refer to converting between line codes or signalling formats.

In construction

In the building industry, code conversion describes adapting a structure from the requirements of one occupancy or regulatory category to another, such as converting a warehouse to residential use under a different section of the building code.
