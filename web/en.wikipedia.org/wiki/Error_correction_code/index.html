Error correction code

In computing, telecommunication, information theory and coding theory, an error correction code, sometimes an error-correcting code (ECC), is a scheme for controlling errors in data transmitted or stored over unreliable or noisy communication channels. The sender encodes the message in a redundant way, most often by adding check bits computed from the data, so that the receiver can detect and correct a limited number of errors without needing retransmission. This technique is called forward error correction (FEC).

Principles

The idea dates to Claude Shannon's 1948 work on information theory, which proved that reliable communication is possible over a noisy channel at rates below the channel capacity. A code's ability is measured by its rate (the fraction of transmitted bits carrying information) and its error-correcting capability, related to the Hamming distance between valid codewords.

Major families

  • Block codes, such as Hamming codes, Reed–Solomon codes and BCH codes, encode fixed-size blocks of data.
  • Convolutional codes encode a continuous stream and are decoded with the Viterbi algorithm.
  • Modern capacity-approaching codes, including turbo codes, LDPC codes and polar codes, are used in deep-space links, mobile networks and 5G.

Applications

Error correction is ubiquitous: CDs, DVDs and QR codes use Reed–Solomon codes; ECC memory protects servers against bit flips; deep-space probes, satellite links, DSL, Wi-Fi and cellular systems all rely on FEC to operate at low signal-to-noise ratios. Interleaving is often combined with ECC to spread burst errors across many codewords.
