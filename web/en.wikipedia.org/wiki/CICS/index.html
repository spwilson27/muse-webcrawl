CICS

CICS
Full name: Customer Information Control System
Developer: IBM
Released: 1969
Platform: IBM Z mainframes (z/OS)

CICS (Customer Information Control System) is a family of mixed-language application servers from IBM that provides online transaction management and connectivity for applications on IBM mainframe systems under z/OS. Developed in the late 1960s, it became one of the most successful software products in history.

Overview

CICS handles very high-volume online transaction processing — historically for banks, insurers and airlines — managing concurrency, security, data integrity and recovery for thousands of simultaneous users. Applications are typically written in COBOL, but also PL/I, C, Java and assembler.

Architecture

A CICS region manages tasks (transactions), files, queues, terminals and inter-system communication. Modern releases (CICS Transaction Server) support web services, REST APIs, JSON and cloud-style deployment while retaining compatibility with decades-old programs.
