Kernel (linear algebra)

In mathematics, the kernel of a linear map, also known as the null space or nullspace, is the vector space of all vectors that the map sends to the zero vector. For a linear map L : V → W between two vector spaces, the kernel is the set of all elements v of V such that L(v) = 0, where 0 denotes the zero vector in W.

Definition

Given vector spaces V and W over a field F and a linear map L : V → W, the kernel is defined by ker L = { v ∈ V : L(v) = 0 }. The kernel is always a linear subspace of V. When L is represented by a matrix A, the kernel is the solution set of the homogeneous system Ax = 0.

Properties

  • The kernel is trivial (containing only the zero vector) if and only if the map is injective.
  • The rank–nullity theorem states that the dimension of the kernel (the nullity) plus the dimension of the image (the rank) equals the dimension of the domain.
  • The kernel is the preimage of the zero subspace and is itself a subspace, so the quotient space V / ker L is isomorphic to the image of L (the first isomorphism theorem).

Computation

For a matrix, the kernel is found by Gaussian elimination: the matrix is reduced to row echelon form and the free variables parametrise the solution space. Numerical algorithms such as the singular value decomposition are preferred for floating-point data because they are more stable.

Applications

The null space is fundamental in solving systems of linear equations, in least-squares problems, in differential equations (where the kernel of a differential operator gives the general solution of the homogeneous equation), and in machine learning, where null-space methods appear in feature extraction and constraint satisfaction.
