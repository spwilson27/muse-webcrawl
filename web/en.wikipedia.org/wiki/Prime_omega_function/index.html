Prime omega function

The functions ω(n) and Ω(n) count prime factors of n

In number theory, the prime omega functions ω(n) and Ω(n) count the number of prime factors of a natural number n. The function ω(n) counts the number of distinct prime factors, while Ω(n) counts the number of prime factors with multiplicity.

Definitions

If n = ∏ piai is the prime factorization of n, then:

  • ω(n) = the number of distinct primes pi;
  • Ω(n) = Σ ai, the total number of prime factors counted with multiplicity.

For example, 12 = 2² · 3, so ω(12) = 2 and Ω(12) = 3. Also ω(1) = Ω(1) = 0. The function ω is strongly additive and Ω is completely additive: Ω(mn) = Ω(m) + Ω(n) for all m, n.

Properties

Both functions have average order log log n: a classical result of Hardy and Ramanujan states that the normal order of ω(n) (and of Ω(n)) is log log n, meaning that most numbers near n have about log log n distinct prime factors. The Erdős–Kac theorem refines this into a central limit theorem: (ω(n) − log log n) / √(log log n) is asymptotically normally distributed. The function Ω is also related to the Liouville function λ(n) = (−1)Ω(n), and ω appears in the error terms of many estimates in analytic number theory and in bounds on the divisor function.
