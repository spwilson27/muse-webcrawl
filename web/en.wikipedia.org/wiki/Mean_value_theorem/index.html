Mean value theorem

Mean value theorem
For some point c, the tangent is parallel to the secant through the endpoints
FieldMathematical analysis (calculus)
First stated byAugustin-Louis Cauchy (1823), building on Rolle's theorem (1691)

In mathematics, the mean value theorem (or Lagrange's mean value theorem) states, roughly, that for a smooth curve there is a point at which the instantaneous rate of change (the derivative) equals the average rate of change over an interval. More precisely:

If a function f is continuous on the closed interval [a, b] and differentiable on the open interval (a, b), then there exists a point c in (a, b) such that the tangent at c is parallel to the secant line through the endpoints (a, f(a)) and (b, f(b)).

f′(c) = [ f(b) − f(a) ] / ( b − a )

History

A special case, in which f(a) = f(b) so that the required tangent is horizontal, was stated by Michel Rolle in 1691 for polynomials — this is Rolle's theorem. The general theorem was formulated by Joseph-Louis Lagrange and given its modern rigorous proof by Augustin-Louis Cauchy in 1823; an even earlier statement appears in the work of the Indian mathematician Parameshvara (c. 1370–1460) of the Kerala school.

Proof

The standard proof reduces the theorem to Rolle's theorem: define an auxiliary function that subtracts from f the linear function running along the secant line. This auxiliary function takes equal values at a and b, so by Rolle's theorem its derivative vanishes at some interior point c, which is equivalent to the conclusion.

Consequences

  • A function with derivative zero everywhere on an interval is constant there.
  • If |f′| ≤ M on an interval, then |f(b) − f(a)| ≤ M|b − a| (the mean value inequality), the basis of error bounds in numerical analysis.
  • The theorem is a key step in proofs of the fundamental theorem of calculus, Taylor's theorem, and L'Hôpital's rule (via Cauchy's generalised mean value theorem).
  • A familiar paraphrase: a car whose average speed over a journey is 60 km/h must, at some instant, have travelled at exactly 60 km/h.

Generalisations

Cauchy's mean value theorem extends the result to two functions; further generalisations include mean value theorems for divided differences, for functions of several variables (via reduction to one variable along a segment), and versions in complex analysis, where the straightforward analogue fails and inequalities take its place.
