Absolute value

In mathematics, the absolute value or modulus of a real number x, denoted |x|, is the non-negative value of x regardless of its sign: |x| = x if x ≥ 0, and |x| = −x if x < 0. Geometrically it is the distance of the number from zero on the real line. The concept generalises to complex numbers (where it gives the distance from the origin in the complex plane), vectors (the norm), and abstract algebraic structures.

Definition and properties

The absolute value function is piecewise linear and continuous everywhere but not differentiable at zero. Fundamental properties include: |x| ≥ 0 with equality only at x = 0; |xy| = |x|·|y|; |x + y| ≤ |x| + |y| (the triangle inequality); and the reverse triangle inequality ||x| − |y|| ≤ |x − y|. The distance between two real numbers is |x − y|, making the real line a metric space.

Complex numbers

For a complex number z = a + bi, the absolute value (modulus) is |z| = √(a² + b²), the distance from the origin in the Argand diagram. It satisfies |z|² = z·z̄ (where z̄ is the complex conjugate) and the multiplicative property |zw| = |z||w|. In polar form, z = |z|(cos θ + i sin θ).

Generalisations

The idea extends to norms on vector spaces, absolute values on fields (including the p-adic absolute value on the rationals, which gives a non-Archimedean geometry where the triangle inequality strengthens to an ultrametric inequality), and ordered rings. By Ostrowski's theorem, every non-trivial absolute value on the rational numbers is equivalent to either the usual one or a p-adic one.
