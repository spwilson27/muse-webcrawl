Isolation forest

Isolation forest is an algorithm for anomaly detection originally proposed by Fei Tony Liu, Kai Ming Ting and Zhi-Hua Zhou in 2008. Instead of profiling normal data points, the method explicitly isolates anomalies by randomly partitioning the feature space. Because anomalies are few and different, they tend to be isolated in fewer splits than normal points, so the average path length from the root of an isolation tree to a leaf is shorter for anomalies than for inliers.

Algorithm

An isolation forest is an ensemble of isolation trees (iTrees). Each tree is built by recursively selecting a random feature and a random split value between that feature's minimum and maximum until every point is isolated or a height limit is reached. The anomaly score of a point is derived from the expected path length across all trees, normalised by the expected path length of an unsuccessful search in a binary search tree. Scores close to 1 indicate anomalies, scores near 0.5 indicate no distinct anomaly, and scores well below 0.5 indicate normal points.

Properties

The algorithm has low memory requirements, a linear time complexity in the number of samples, and works well on high-dimensional data because it uses subsampling: only a small sample of the data (often 256 points) is needed to build each tree. It does not rely on distance or density measures, which makes it fast but can cause it to struggle with local anomalies and irrelevant features.

Applications

Isolation forests are used for fraud detection, intrusion detection, fault monitoring in industrial systems and outlier screening in data preprocessing. The method is implemented in libraries such as scikit-learn.
