Kolmogorov–Smirnov test

In statistics, the Kolmogorov–Smirnov test (K–S test or KS test) is a nonparametric test of the equality of continuous (or discontinuous) one-dimensional probability distributions. It can be used to test whether a sample came from a reference probability distribution (one-sample K–S test), or whether two samples came from the same distribution (two-sample K–S test).

Statistic

The test statistic is based on the maximum vertical distance between empirical distribution functions, or between an empirical distribution function and the cumulative distribution function of the reference distribution. For a sample of size n drawn from a hypothesized distribution F, the statistic is Dn = supx |Fn(x) − F(x)|, where Fn is the empirical distribution function and sup denotes the supremum of the set of distances.

Kolmogorov distribution

Under the null hypothesis that the sample comes from the reference distribution, √n Dn converges to the Kolmogorov distribution, whose cumulative distribution function is an infinite series involving exponentials. Andrey Kolmogorov derived this limiting distribution in 1933, and Nikolai Smirnov extended the results to the two-sample case and tabulated the distribution in 1939. The test is distribution-free when the reference distribution is fully specified and continuous, though adjustments such as the Lilliefors test are needed when parameters are estimated from the data.

Applications

The K–S test is used in many fields as a goodness-of-fit test and to compare data sets, for example in astrophysics to compare distributions of astronomical objects, and in finance. It is sensitive to differences in both location and shape of the distributions, though it is generally less powerful than tests designed specifically for particular alternatives, such as the Anderson–Darling test for normality.
