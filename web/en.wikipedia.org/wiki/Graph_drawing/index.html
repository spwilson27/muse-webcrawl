Graph drawing

Graph drawing is an area of mathematics and computer science combining methods from geometric graph theory and information visualization to derive two-dimensional depictions of graphs arising from applications such as social network analysis, cartography, linguistics, and bioinformatics.

A drawing of a graph or network diagram is a pictorial representation of the vertices and edges of a graph. This drawing should not be confused with the graph itself: very different layouts can correspond to the same graph.

Quality measures

Many different quality measures have been defined for graph drawings, including:

  • Crossing number: the number of edge crossings, which should be minimised for readability.
  • Symmetry: layouts that display the graph's symmetries are often preferred.
  • Angular resolution: the smallest angle between edges incident to a vertex.
  • Aspect ratio and area: compact drawings that use space efficiently.

Layout methods

Common methods include force-directed layouts, which model edges as springs and use physical simulation to position vertices; layered (Sugiyama-style) layouts for directed acyclic graphs; orthogonal layouts; and spectral layouts based on eigenvectors of the graph Laplacian. Software such as Graphviz implements many of these algorithms. The field's main venue is the International Symposium on Graph Drawing. See also network theory and information visualization.
