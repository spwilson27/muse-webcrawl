Binary operation
FieldMathematics (algebra)
Arity2
NotationUsually infix: a ∘ b, a + b, a · b
ExamplesAddition, multiplication, exponentiation, vector cross product

In mathematics, a binary operation or dyadic operation is a rule for combining two elements of a set (the operands) to produce another element. More formally, a binary operation on a set S is a function that maps elements of the Cartesian product S × S to S:

f : S × S → S.

Familiar examples of binary operations on numbers are addition, subtraction, multiplication and division; on vectors, the dot product and cross product; on sets, union and intersection; and in logic, conjunction (AND) and disjunction (OR).

Properties

  • Commutativity: a ∘ b = b ∘ a for all a, b.
  • Associativity: (a ∘ b) ∘ c = a ∘ (b ∘ c).
  • Identity element: an element e with e ∘ a = a ∘ e = a.
  • Distributivity: one operation distributes over another, as multiplication over addition.

Not all pairs of elements need yield an element of the same set in a partial binary operation such as division (undefined for division by zero). A set equipped with a binary operation is called a magma; with associativity it becomes a semigroup, with an identity a monoid, and with inverses a group.
