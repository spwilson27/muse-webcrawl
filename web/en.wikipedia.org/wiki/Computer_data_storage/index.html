Computer data storage

Computer data storage is a technology consisting of computer components and recording media used to retain digital data. It is a core function and fundamental component of computers.

Hierarchy of storage

Storage is organized in a hierarchy by speed and cost: registers and cache, primary storage (main memory/RAM), secondary storage (hard disk drives and solid-state drives), tertiary storage (removable media and tape libraries), and offline storage.

Characteristics

Key characteristics include volatility, mutability, accessibility (random vs. sequential), addressability, capacity, and performance (latency and throughput).

Media

Recording technologies include semiconductor (flash memory), magnetic (hard disks, tape), optical (CD, DVD, Blu-ray), and historical media such as punched cards and magnetic core memory.
