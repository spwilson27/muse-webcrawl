The Apache Software Foundation (ASF) is an American non-profit corporation that supports a large community of open-source software projects, providing legal, financial and organisational infrastructure. It was founded in 1999 by the Apache Group, the developers of the Apache HTTP Server, then the world's most popular web server.

Projects

The ASF hosts several hundred projects, including the HTTP Server, Tomcat, Maven, Ant, Kafka, Hadoop, Spark, Cassandra, OpenOffice and Groovy. Projects enter through the Apache Incubator and graduate to top-level status when their communities demonstrate self-governance under the foundation's meritocratic model, known as "the Apache Way".

Licensing

All ASF software is released under the Apache License, a permissive free-software licence (version 2.0, published 2004, includes an express patent grant). The foundation is funded by donations and sponsorships and is run largely by volunteers; membership is earned through sustained contribution.
