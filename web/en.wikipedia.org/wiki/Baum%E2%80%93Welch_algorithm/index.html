Baum–Welch algorithm

Baum–Welch algorithm
Type: Expectation-maximisation algorithm
Used for: Training hidden Markov models
Named after: Leonard E. Baum, Lloyd R. Welch

The Baum–Welch algorithm is a statistical algorithm used to find the unknown parameters of a hidden Markov model (HMM). It is a special case of the expectation-maximisation algorithm, developed from work by Leonard E. Baum and colleagues in the late 1960s.

Overview

Given a sequence of observations, the algorithm iteratively estimates the transition and emission probabilities that maximise the likelihood of the observations.

Method

It uses the forward-backward procedure to compute expected state occupancies and transitions, then re-estimates parameters, repeating until convergence to a local maximum.

Applications

The algorithm underpins HMM training in speech recognition, bioinformatics sequence analysis and cryptanalysis.
