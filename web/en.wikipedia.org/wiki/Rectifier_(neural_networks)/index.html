Rectifier (neural networks)

In the context of artificial neural networks, the rectifier or ReLU (Rectified Linear Unit) activation function is an activation function defined as the non-negative part of its argument: f(x) = x⁺ = max(0, x), where x is the input to a neuron. It is analogous to half-wave rectification in electrical engineering.

Advantages

ReLU became the default activation function for many types of neural networks because it mitigates the vanishing gradient problem that afflicted the older sigmoid and hyperbolic tangent functions, allows models to train faster, and induces sparsity in activations. Its simplicity — a threshold at zero — makes it computationally cheap. ReLU was popularized for deep learning in work around 2010–2011 and was a key component of AlexNet (2012), which won the ImageNet competition.

Potential problems

A drawback is the "dying ReLU" problem: neurons whose inputs are always negative output zero and stop learning, because the gradient there is zero. Variants address this by allowing a small negative slope.

Variants

  • Leaky ReLU — uses a small fixed slope (e.g. 0.01) for negative inputs.
  • Parametric ReLU (PReLU) — learns the negative slope during training.
  • Exponential linear unit (ELU) and GELU — smooth relatives used in many later architectures.
