MATE (Spanish pronunciation: "mah-teh") is a free and open-source desktop environment for Linux and other Unix-like operating systems. It is a fork of GNOME 2, created after the release of GNOME 3 in 2011 introduced a redesigned interface that many users disliked. MATE's stated goal is to preserve and continue the traditional desktop metaphor of GNOME 2 while still adopting newer technologies.

History

The project began in 2011 when an Arch Linux user known as Perberos forked GNOME 2 components and made them available in response to dissatisfaction with the new GNOME Shell interface. It was named after the yerba mate plant and the South American infusion prepared from it, following the Spanish-themed naming. The desktop was subsequently adopted by Linux Mint and became an official flavour or default option in a number of distributions.

Components

MATE renamed the forked GNOME 2 applications to avoid conflicts with their GNOME 3 successors: the Caja file manager (from Nautilus), Pluma text editor (from gedit), Eye of MATE image viewer (from Eye of GNOME), Atril document viewer (from Evince), Engrampa archive manager, and the Marco window manager (from Metacity). The traditional layout consists of two panels with an applications menu, window list and system indicators.

Development

Over successive releases the codebase was migrated from GTK 2 to GTK 3, deprecated libraries such as CORBA-based components were dropped, and support for Wayland compositing has been developed. MATE is the default desktop of Ubuntu MATE and is available in the repositories of most major Linux distributions and BSD systems.
