False memory

A false memory is a phenomenon in which someone recalls something that did not happen, or recalls it differently from the way it actually occurred. Suggestibility, activation of associated information, incorporation of misinformation, and source misattribution have all been proposed as mechanisms. False memories can range from small distortions to rich recollections of entirely fictitious events.

Research

Psychologist Elizabeth Loftus has been a central figure in false memory research. Her "lost in the mall" studies showed that about a quarter of participants could come to remember a suggested childhood event that never happened. The misinformation effect — distortion of memory by misleading post-event information — and the Deese–Roediger–McDermott (DRM) paradigm, in which people confidently "recall" unpresented lure words, are standard demonstrations. The so-called Mandela effect describes widely shared false memories of public facts.

Controversy

False memory research gained prominence during the debates over recovered-memory therapy in the 1980s and 1990s, when some patients recovered apparently repressed memories of abuse, some later shown to be false. The work has implications for eyewitness testimony and clinical practice, and has been criticized by some clinicians who dispute how readily rich false memories can be implanted and the ethics of the experiments.
