Adobe InDesign is a desktop publishing and page-layout application produced by Adobe Inc. It is used to design posters, flyers, brochures, magazines, newspapers, books and presentations, and supports export for print, PDF and interactive digital formats including EPUB. InDesign is the industry-standard successor to Adobe PageMaker and the principal rival — and eventual displacer — of QuarkXPress in professional publishing.

History

InDesign grew out of code Adobe acquired with Aldus Corporation in 1994; Adobe had been developing a new layout program (under the code name "K2" / "Shuksan") while Aldus's PageMaker fell behind QuarkXPress. Released in 1999, InDesign was the first major desktop publishing application to ship natively for Mac OS X, and offered advanced typography (including optical kerning and sophisticated hyphenation and justification), transparency, long-document features and deep integration with Photoshop and Illustrator. Versions CS3 onward bundled it in Creative Suite; since 2013 it has been distributed by subscription through Adobe Creative Cloud. InDesign Server powers automated, template-driven publishing.

Features

Key features include master pages (now "parent pages"), paragraph and character styles, threaded text frames, tables, data merge for catalogue production, GREP styles and find/change, preflight checking, and packaging of fonts and linked graphics. Its native format is INDD, with IDML as an XML interchange format. Through Adobe Fonts and InCopy integration, InDesign anchors collaborative editorial workflows.
