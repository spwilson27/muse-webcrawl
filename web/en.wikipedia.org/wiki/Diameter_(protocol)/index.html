Diameter (protocol)

Diameter is an authentication, authorisation and accounting (AAA) protocol for computer networks, standardised by the IETF in RFC 6733. It evolved from the earlier RADIUS protocol, whose name inspired "Diameter" — a diameter is twice a radius — as a pun on its predecessor.

Overview

Diameter operates over TCP or SCTP and supports reliable transport, failover, and extensible attribute–value pairs (AVPs). It is widely used in mobile network cores, including LTE and 5G architectures, for subscriber authentication, policy control (PCRF) and online charging.

Applications

Defined applications include the Diameter base protocol, network access (NASREQ), mobile IPv4, credit control, and the many 3GPP interfaces (S6a, Gx, Gy, Rx) used between core network elements such as the MME, HSS and PCRF.
