Hard link

In computing, a hard link is a directory entry that associates a name with a file. Every regular file is a hard link to its data; creating an additional hard link creates another name for the same underlying file content (inode), so that the file can be accessed by more than one path.

A file's data is deleted only when its last hard link is removed. Hard links cannot normally span filesystems, and most systems do not allow hard links to directories. They contrast with symbolic links, which are separate files containing a path reference that can point across filesystems or to nonexistent targets.

Usage

On Unix-like systems the ln command creates hard links, and the link count is shown by utilities such as ls -l. Hard links are used by backup tools to store unchanged files efficiently, by snapshot systems, and by programs installed under multiple names that behave according to the name used to invoke them.

Limitations

Because all hard links are indistinguishable names for the same data, editing through one name changes the file seen through every other name. Hard links also do not record which name was the "original".
