List of software palettes

This is a list of notable colour palettes defined in software rather than by graphics hardware — including fixed palettes of graphics programs, drawing tools, pixel-art-oriented editors and retro-styled games, as opposed to the hardware palettes of systems such as the CGA, ZX Spectrum or Game Boy.

Software palettes became a creative constraint in modern pixel art: artists deliberately choose a limited, harmonious set of colours to imitate the look of older hardware or to develop a consistent style. Websites such as Lospec host thousands of user-contributed palettes with downloadable formats for common editors.
