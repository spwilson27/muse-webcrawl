Scalar processor

Scalar processors are a class of computer processors that process only one data item at a time. Typical data items include integers and floating point numbers. A scalar processor is classified as a SISD (single instruction, single data) processor in Flynn's taxonomy.

In contrast, a vector processor processes a single instruction on multiple data items at the same time (SIMD). The difference is analogous to the difference between scalar and vector arithmetic in mathematics.

Superscalar processors

A superscalar processor is a mixture of a scalar processor and a vector processor: it can issue and retire multiple instructions per clock cycle, executing them in parallel on multiple execution units, while each instruction still operates on scalar data. Most general-purpose CPUs in desktop and server computers since the 1990s are superscalar scalar processors.

Scalar processing in GPUs

Modern graphics processing units combine scalar and vector processing elements; a scalar processor may also appear as a component within a larger vector or SIMD machine, handling control flow and scalar operands.
