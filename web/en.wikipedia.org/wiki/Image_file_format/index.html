Image file format

From Wikipedia, the free encyclopedia

[Image placeholder: image format comparison chart]

An image file format is a standard way to organize and store digital images. Image files are composed of digital data in one of these formats so that the data can be displayed on a digital (computer) display or printed. During the process of rasterization, an image file is converted into a sequence of pixels; vector formats instead store geometric descriptions that are rasterized at display size.

Raster formats

Raster (bitmap) formats store a grid of pixels, usually compressed. Lossless compression preserves every pixel exactly, while lossy compression discards information for smaller files.

Vector formats

Vector formats — such as SVG, EPS, PDF and the native formats of illustration software — store lines, curves and shapes mathematically, so images scale without loss of quality. SVG, an XML-based format, is the standard vector format of the web.

Compound and raw formats

Camera raw formats (e.g. DNG, CR2, NEF) store minimally processed sensor data. Container formats such as HEIF store image sequences and derived images. Most formats also carry metadata, notably Exif and IPTC fields embedded by cameras and editors.
