Midpoint circle algorithm

The midpoint circle algorithm is an algorithm used in computer graphics to determine the points needed for rasterizing a circle. It is a generalization of Bresenham's line algorithm. The algorithm can be further generalized to conic sections.

History

The algorithm was conceived by Pitteway and popularized by van Aken and Novak, in two publications from the mid-1970s and early 1980s. Like Bresenham's line algorithm, it works entirely with integer arithmetic in its most common form, making it well suited to implementation in hardware and in low-level graphics code.

Algorithm summary

A circle of radius r centered at the origin is defined implicitly by the equation x2 + y2 − r2 = 0. Because of the eightfold symmetry of the circle, it is sufficient to compute the points in a single octant — conventionally the second octant from x = 0 to x = y — and then reflect them into the other seven octants.

At each step, starting from the point (0, r), the algorithm must choose between the pixel directly to the right and the pixel diagonally down and to the right. It does so by evaluating the circle function at the midpoint between the two candidate pixels. If the midpoint lies inside the circle, the right-hand pixel is chosen; if it lies outside, the diagonal pixel is chosen. An incremental decision variable tracks this evaluation using only integer additions and subtractions.

Integer-based algorithm

One common integer formulation maintains a decision parameter d, initialized to 1 − r. While x < y, the eight symmetric points are plotted. If d < 0, then d is increased by 2x + 3 and only x advances; otherwise d is increased by 2(x − y) + 5, x advances, and y decreases by one.

x = 0
y = r
d = 3 - 2*r
while y >= x:
    draw_points(x, y)
    x = x + 1
    if d > 0:
        y = y - 1
        d = d + 4*(x - y) + 10
    else:
        d = d + 4*x + 6

Variants

The same midpoint strategy can be applied to ellipses, giving the midpoint ellipse algorithm, and more generally to other conic sections. The algorithm is closely related to the midpoint line drawing methods and remains a standard topic in introductory computer graphics courses.
