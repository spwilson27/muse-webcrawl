DOSBox

DOSBox is a free and open-source emulator designed to run software written for MS-DOS and compatible operating systems. It emulates an Intel x86 PC running DOS, including its hardware: a Sound Blaster-compatible sound card, graphics modes such as CGA, EGA, VGA and VESA, and input devices including keyboard, mouse and joystick.

DOSBox was first released in 2002 by Dutch programmers Peter Veenstra and Sjoerd van der Berg. It was motivated mainly by the fact that Windows NT-based operating systems such as Windows XP could no longer run many classic DOS games and applications. Unlike virtualization tools, DOSBox emulates the complete hardware environment, so DOS itself does not need to be installed separately; a simple built-in DOS-like shell is provided.

Features

DOSBox can emulate a range of CPU types from the 8086/8088 through the Pentium, with adjustable emulation speed measured in "cycles". It supports disk images, mounting host folders as drives, and networking over IPX for multiplayer games. Special builds such as DOSBox-X and DOSBox Staging have extended the original with additional features.

Usage

The emulator is widely used to play classic video games from the 1980s and 1990s. Commercial re-releases of old games on distribution platforms such as GOG.com and Steam frequently bundle DOSBox so the games run on modern systems.
