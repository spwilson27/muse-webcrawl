Microsoft Visual Studio

Microsoft Visual Studio is an integrated development environment (IDE) developed by Microsoft. It is used to develop computer programs including websites, web applications, services, and mobile apps. Visual Studio supports 36 different programming languages and includes a code editor with IntelliSense (intelligent code completion), an integrated debugger, a graphical user interface designer, and tools for version control, testing, and deployment. It must not be confused with Visual Studio Code, a separate, lightweight cross-platform editor released in 2015.

History

Visual Studio 97 (1997) first bundled Microsoft's separate language tools — Visual Basic, Visual C++, Visual J++, and others — into a single environment. Visual Studio .NET (2002) accompanied the launch of the .NET Framework and the C# language, shifting development toward managed code. Subsequent releases added support for web development with ASP.NET, team collaboration through what became Azure DevOps, and the .NET cross-platform workloads. Visual Studio 2022 was the first fully 64-bit version of the IDE, easing memory limits for very large solutions.

Features and editions

The IDE provides a code editor, debugger that works at both source and machine level, designers for Windows Forms and WPF interfaces, a profiler, unit-testing frameworks, and IntelliCode AI-assisted completion; GitHub Copilot integration has been added in recent versions. Visual Studio is sold in editions: the free Community edition for individual developers, students, and open source; Professional; and Enterprise, which adds advanced testing and architecture tools. A large marketplace of extensions supports additional languages and workflows.

Supported development

Built-in languages include C, C++, C++/CLI, Visual Basic, C#, F#, and TypeScript/JavaScript, with support for Python, Ruby, and many others via extensions. Visual Studio is the principal tool for building Windows desktop applications, games with engines such as Unity, Xamarin/.NET MAUI mobile apps, and Azure cloud services.
