Federated search

Federated search is an information retrieval technology that allows the simultaneous search of multiple searchable resources through a single query and user interface, returning a merged set of results.

How it works

A federated search system broadcasts the user's query to participating databases or search engines, collects the results, de-duplicates and ranks them, and presents a unified list. Unlike a web crawler-based index, federated search queries the sources in real time, which makes it suited to the "deep web" of subscription databases.

Applications

Federated searching is widely used in libraries (to search catalogues and journal databases together), enterprise search, and travel or price-comparison metasearch engines. Challenges include differing query syntaxes, result merging, and slower response times than a single index.
