HTTP

Hypertext Transfer Protocol (HTTP)
Developer: Tim Berners-Lee / IETF
Ports: 80 (HTTP), 443 (HTTPS)
Versions: HTTP/1.1, HTTP/2, HTTP/3

The Hypertext Transfer Protocol (HTTP) is an application-layer protocol for transmitting hypermedia documents such as HTML; it is the foundation of data exchange on the World Wide Web.

Operation

Clients (browsers) send requests with methods such as GET, POST, PUT and DELETE; servers reply with status codes (200 OK, 404 Not Found, 500) and headers. HTTP is stateless; cookies add sessions. HTTPS encrypts HTTP with TLS.

Versions

Berners-Lee's HTTP/0.9 (1991) was followed by HTTP/1.0 and persistent-connection HTTP/1.1 (1997, standardised in RFC 9112). HTTP/2 (2015) added multiplexing and header compression over a binary framing layer; HTTP/3 (2022, RFC 9114) runs over QUIC/UDP.
