Internet protocol suite

Internet protocol suite (TCP/IP)
Layers: Link, Internet, Transport, Application
Key protocols: IP, TCP, UDP, HTTP, DNS
Origins: ARPANET, 1970s; Cerf & Kahn

The Internet protocol suite, commonly known as TCP/IP, is the set of communications protocols used on the Internet and similar networks, conceptualised in layers that provide end-to-end data communication.

Layers

The link layer handles local transmission (Ethernet, Wi-Fi); the internet layer provides addressing and routing via IP; the transport layer provides host-to-host channels via TCP (reliable, ordered) and UDP (lightweight); the application layer includes HTTP, DNS, SMTP, FTP and SSH.

History

Vint Cerf and Bob Kahn designed the core protocols in 1973–74 for ARPANET, drawing on CYCLADES ideas. TCP/IP became the ARPANET standard on 1 January 1983 ("flag day") and was bundled with Berkeley Unix, driving adoption over the rival OSI model.
