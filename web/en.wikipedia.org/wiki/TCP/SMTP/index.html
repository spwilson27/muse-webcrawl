Simple Mail Transfer Protocol

SMTP
Full name: Simple Mail Transfer Protocol
Port: 25 (also 587 submission, 465)
Standard: RFC 5321
Layer: Application

The Simple Mail Transfer Protocol (SMTP) is an Internet standard communication protocol for electronic mail transmission. Mail servers and other message transfer agents use SMTP to send and receive mail messages.

History

SMTP was first defined in 1982 by RFC 821 and updated in 2008 by RFC 5321, which remains in use. It grew from earlier mail protocols on ARPANET in the 1970s. Jon Postel was a central figure in its development.

Operation

A client connects, typically on TCP port 25, greets the server with EHLO or HELO, then issues MAIL FROM, RCPT TO, and DATA commands. Messages are relayed store-and-forward between servers until delivery. Retrieval by end users uses separate protocols such as POP3 or IMAP. SMTP itself is a text-based, request-response protocol; extensions (ESMTP) add authentication, TLS encryption via STARTTLS, and 8-bit data support.

Security and spam

Original SMTP had no authentication, enabling spam and spoofing. Modern defences include SPF, DKIM, DMARC, and submission-port authentication.
