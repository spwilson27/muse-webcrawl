TCP/IP model

From Wikipedia, the free encyclopedia
[Image: Comparison diagram of the four-layer TCP/IP model beside the seven-layer OSI model]

The TCP/IP model is a descriptive framework for the protocols of the Internet protocol suite, named after its two most important protocols, the Transmission Control Protocol (TCP) and the Internet Protocol (IP). It organises networking functions into four layers of abstraction.

The layers, from bottom to top, are: the link layer (network access), which handles communication on the local link via technologies such as Ethernet; the internet layer, where IP addressing and routing between networks occur; the transport layer, where TCP provides reliable streams and UDP provides datagrams; and the application layer, home to HTTP, DNS, SMTP and most other user-facing protocols.

Comparison with the OSI model

The older OSI model divides the same functions into seven layers, splitting TCP/IP's application layer into application, presentation and session layers, and its link layer into physical and data link layers. In practice the OSI model is used mainly as a teaching and reference tool, while the protocols that actually run the Internet follow the TCP/IP architecture. Critics note that the four-layer model's boundaries are loose — some descriptions add a fifth 'physical' layer — but its closeness to the real protocol stack keeps it dominant in textbooks and practice.
