Domain Name System

Domain Name System (DNS)
Port: 53 (UDP/TCP)
Introduced: 1983 (Paul Mockapetris)
Function: Name-to-address translation

The Domain Name System (DNS) is a hierarchical, distributed naming system for computers and services on the Internet, translating human-readable domain names (e.g. example.com) into IP addresses.

How it works

Resolvers query root servers, then top-level domain (TLD) servers, then authoritative name servers, caching results according to TTL. Record types include A/AAAA (addresses), MX (mail), CNAME (alias), NS and TXT. DNS was designed by Paul Mockapetris in 1983 (RFCs 882/883, later 1034/1035).

Security

DNSSEC adds authentication; DNS over HTTPS (DoH) and DNS over TLS (DoT) add encryption. Threats include spoofing/cache poisoning, amplification attacks and censorship via DNS blocking.
