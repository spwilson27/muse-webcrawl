Transmission Control Protocol

TCP
Layer: Transport
Standard: RFC 9293 (2022)
Connection: Yes, stateful
Delivery: Reliable, ordered byte stream

The Transmission Control Protocol (TCP) is one of the main protocols of the Internet protocol suite. It originated in the initial network implementation in which it complemented the Internet Protocol (IP); the entire suite is commonly called TCP/IP.

Operation

TCP provides reliable, ordered, and error-checked delivery of a stream of octets between applications. Before exchanging data, endpoints establish a connection with a three-way handshake. Sequence numbers, acknowledgements, retransmission of lost segments, flow control through a sliding window, and congestion control algorithms protect the network from overload.

History

Vint Cerf and Bob Kahn described TCP in 1974. It was standardised in RFC 793 in 1981 and consolidated in RFC 9293 in 2022. Key congestion-control milestones include the 1988 addition of slow start after congestion collapses on early Internet links.

Applications

The World Wide Web (HTTP/HTTPS), email (SMTP), file transfer, and remote login run over TCP. Its contrast protocol, UDP, trades reliability for lower latency.

Header

A TCP segment header contains source and destination ports, sequence and acknowledgement numbers, flags (SYN, ACK, FIN, RST, PSH, URG), window size, checksum, and options.
