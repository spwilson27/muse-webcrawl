User Datagram Protocol

UDP
Layer: Transport
Standard: RFC 768 (1980)
Connection: None
Header: 8 bytes

In computer networking, the User Datagram Protocol (UDP) is one of the core communication protocols of the Internet protocol suite, used to send messages — datagrams — to other hosts on an IP network.

Features

UDP uses a simple connectionless communication model with a minimum of protocol mechanisms. It provides checksums for data integrity and port numbers for addressing different applications, but no handshaking, ordering, retransmission, or congestion control. Error handling and reliability, if needed, are left to the application.

Applications

UDP suits time-sensitive transmissions where dropping packets is preferable to waiting for retransmissions: DNS lookups, DHCP, streaming media, voice over IP, online games, and the QUIC transport protocol, which builds reliability on top of UDP.

Comparison with TCP

Unlike the Transmission Control Protocol, UDP has lower overhead — an 8-byte header versus TCP's minimum 20 bytes — and supports broadcast and multicast delivery.
