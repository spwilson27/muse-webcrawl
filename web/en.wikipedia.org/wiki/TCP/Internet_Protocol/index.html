Internet Protocol

Internet Protocol (IP)
Layer: Network (Layer 3)
Versions: IPv4 (1981), IPv6 (1998)
Designers: Vint Cerf, Bob Kahn (suite)

The Internet Protocol (IP) is the network-layer communications protocol in the Internet protocol suite for relaying datagrams across network boundaries — the function that makes internetworking, and thus the Internet, possible.

Function

IP provides best-effort delivery of packets from a source host to a destination host based solely on IP addresses in packet headers. It defines addressing, fragmentation and reassembly, and a Time to Live field; reliability, ordering and flow control are left to higher layers such as TCP.

Versions

IPv4 (RFC 791, 1981) is the first major version and remains widely used. IPv6 (RFC 8200, 2017, first specified 1998) expands addresses to 128 bits and simplifies headers. Routers forward packets hop by hop using routing tables.
