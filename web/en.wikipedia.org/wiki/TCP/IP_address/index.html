IP address

IP address
IPv4: 32-bit, dotted decimal
IPv6: 128-bit, hexadecimal
Allocated by: IANA / regional registries

An Internet Protocol address (IP address) is a numerical label assigned to each device on a network using the Internet Protocol, serving to identify the host and locate it for routing.

Versions

IPv4 uses 32-bit addresses written as four decimal octets (e.g. 192.0.2.1), giving about 4.3 billion addresses — now exhausted at registry level, mitigated by NAT and private ranges (RFC 1918). IPv6 uses 128-bit addresses written in hexadecimal groups (e.g. 2001:db8::1), providing a vastly larger space.

Allocation

Addresses are allocated hierarchically by IANA to regional Internet registries and ISPs, assigned statically or dynamically via DHCP, and divided into subnets using CIDR notation (e.g. /24).
