OSI model
Full name: Open Systems Interconnection model
By: ISO, from 1978; ISO/IEC 7498-1
Layers: 7

The Open Systems Interconnection model (OSI model) is a conceptual model from the International Organization for Standardization that partitions a telecommunication system into seven abstraction layers.

The seven layers

  1. Physical — bits on media
  2. Data link — frames, MAC addressing (Ethernet)
  3. Network — packets, routing (IP)
  4. Transport — segments, end-to-end (TCP/UDP)
  5. Session — dialogues
  6. Presentation — encoding, encryption, formatting
  7. Application — user services (HTTP, SMTP)

A common mnemonic is "Please Do Not Throw Sausage Pizza Away." Although the Internet protocol suite (TCP/IP) with fewer layers won in practice, the OSI vocabulary remains standard for describing network functions and troubleshooting.
