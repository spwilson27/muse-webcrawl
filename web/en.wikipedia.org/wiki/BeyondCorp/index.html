BeyondCorp is a zero trust security framework pioneered by Google. It shifts access controls from the network perimeter to individual users and devices, allowing employees to work securely from any location without the need for a traditional VPN.

History

BeyondCorp was developed at Google in the aftermath of Operation Aurora, a series of cyber attacks in 2009 that targeted Google and other companies. Google began rethinking its security model, concluding that network location should not determine trust. The initiative was publicly described in a series of papers published in ;login: magazine beginning in 2014.

Design

The model is built on several principles: access to services must not be determined by the network from which a user connects; access is granted based on information about the user and the device; and all access to services must be authenticated, authorized, and encrypted. Key components include an inventory database of devices, a trust inference system that dynamically assigns trust tiers, and an access proxy that brokers requests to applications.

Influence

BeyondCorp is widely credited with popularizing the zero trust security model. In 2021 Google Cloud launched BeyondCorp Enterprise, a commercial product based on the internal system. Similar approaches have been adopted across the technology industry, and the model informed later frameworks such as the U.S. federal zero trust strategy.
