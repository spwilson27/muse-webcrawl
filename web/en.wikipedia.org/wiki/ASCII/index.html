ASCII (American Standard Code for Information Interchange) is a character encoding standard for electronic communication. ASCII codes represent text in computers, telecommunications equipment, and other devices. It defines 128 characters — 95 printable (letters, digits, punctuation and a space) and 33 non-printing control characters — encoded in seven bits.

History

ASCII was developed by a committee of the American Standards Association (ASA) chaired with key contributions from Bob Bemer of IBM, drawing on earlier telegraph codes. The first edition was published in 1963; a major revision in 1967 (USASI X3.4-1967) fixed the code layout recognisable today, including lowercase letters and the relocation of some controls. It became an official U.S. federal standard in 1968 and was later standardised internationally as ISO/IEC 646, whose invariant subset matches ASCII.

The design made arithmetic easy on the hardware of the day: digits differ from their binary values only in the high bits, and upper- and lowercase letters differ by a single bit (32), simplifying case-insensitive comparison and sorting (though punctuation interleaved between the letter ranges produces the well-known lexicographic quirks).

Legacy and variants

Numerous 8-bit "extended ASCII" code pages (such as ISO 8859-1 and Windows-1252) added accented letters and symbols in positions 128–255. ASCII forms the first 128 code points of Unicode, and UTF-8 encodes ASCII text byte-for-byte identically, making ASCII a permanent subset of modern text encoding. The term also survives in "ASCII art", text files ("ASCII files"), and protocol design, where many internet protocols (SMTP, HTTP headers) remain ASCII-based.
