Shannon–Fano coding

In the field of data compression, Shannon–Fano coding is a technique for constructing a prefix code based on a set of symbols and their probabilities (estimated or measured). It is named after Claude Shannon and Robert Fano, who described versions of the method in 1948 and 1949 respectively.

Method

The symbols are first arranged in order of decreasing probability. The list is then divided into two parts whose total probabilities are as nearly equal as possible; the symbols in one part are assigned the binary digit 0 as the first symbol of their codewords, and those in the other part the digit 1. Each part is subdivided recursively in the same way until every group contains a single symbol. The accumulated digits form a prefix-free code in which no codeword is a prefix of another.

Comparison with Huffman coding

Shannon–Fano coding is a top-down construction, whereas Huffman coding works bottom-up by repeatedly merging the two least probable symbols. Shannon–Fano coding does not always produce an optimal prefix code; it can yield average codeword lengths slightly longer than the source entropy and longer than Huffman's optimum. Nevertheless it was historically important as one of the first practical entropy-coding methods and remains a clear illustration of the principle that more frequent symbols should receive shorter codewords.

A related but distinct technique, Shannon–Fano–Elias coding, is used in arithmetic coding and produces codewords directly from cumulative probabilities.
