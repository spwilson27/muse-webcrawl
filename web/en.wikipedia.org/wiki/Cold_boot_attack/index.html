Cold boot attack

In computer security, a cold boot attack (or, less exactly, a cold-booting attack, cold boot attack, or platform reset attack) is a type of side channel attack in which an attacker with physical access to a computer performs a memory dump of the computer's random-access memory (RAM) by performing a hard reset of the target machine. Typically, cold boot attacks are used for retrieving encryption keys from a running operating system for malicious or criminal investigative reasons.

Background

The attack relies on the data remanence property of DRAM and SRAM: memory contents are not erased instantly when power is removed, but decay over seconds to minutes, and decay far more slowly at low temperatures. In February 2008, researchers led by J. Alex Halderman at Princeton University published "Lest We Remember: Cold Boot Attacks on Encryption Keys", demonstrating that the contents of RAM could be recovered after a machine was powered off and rebooted into a lightweight operating system, and that disk encryption keys for systems such as BitLocker, FileVault, dm-crypt and TrueCrypt could be reconstructed from the recovered memory images despite errors introduced by decay.

Technique

An attacker typically interrupts the target machine's power or resets it, then boots it from removable media running a small program that copies the contents of RAM to external storage before they decay. Cooling the memory chips — for example with inverted cans of compressed air, reaching temperatures around −50 °C — slows bit decay and extends the window for recovery. The recovered image is then analysed: encryption keys can be located and reconstructed using algorithms that exploit the redundancy in the key schedule, tolerating a substantial fraction of flipped bits. In some variants the memory modules are physically transplanted into a machine controlled by the attacker.

Mitigation

Because the attack assumes physical access, defences include keeping machines physically secure, shutting them down fully (rather than sleeping) when unattended, and configuring systems to overwrite memory on boot. Full memory encryption — in which RAM contents are encrypted with keys held in the CPU, as in AMD's Secure Memory Encryption or Intel's Total Memory Encryption — defeats the attack by making recovered memory images unintelligible. Some systems also employ the Trusted Computing Group's "memory overwrite request" (MOR) bit, which instructs the firmware to wipe memory on the next boot after an unexpected shutdown; this was bypassed in later research on certain implementations. Scrubbing keys from memory when a system locks, and keeping keys in CPU registers or caches instead of RAM, are additional countermeasures used by some tools.
