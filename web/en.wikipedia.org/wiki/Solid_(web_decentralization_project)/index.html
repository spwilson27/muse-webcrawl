Solid (web decentralization project)

Solid (derived from "social linked data") is a web decentralization project led by Tim Berners-Lee, the inventor of the World Wide Web, and developed collaboratively at the Massachusetts Institute of Technology and through an open-source community. The project aims to radically change the way web applications work today, resulting in true data ownership as well as improved privacy by developing a platform for linked-data applications that are completely decentralized and fully under users' control.

Design

Solid's central idea is the pod (personal online data store): each user stores all of their data — documents, photos, contacts, messages — in a pod hosted wherever they choose. Applications authenticate with the user's WebID and request permission to access specific data in the pod, rather than holding copies on their own servers. Data are represented using linked data standards such as RDF, so different applications can interoperate over the same data. Access is governed by Web Access Control rules.

History

Berners-Lee publicly launched Solid in 2016 and in 2018 co-founded the company Inrupt to commercialise the ecosystem and build enterprise-grade Solid servers. Governments and organisations, including the government of Flanders, have piloted Solid-based data services.

Criticism and reception

Solid has been praised as an attempt to rebalance power on the web toward users, and criticised for the difficulty of achieving developer adoption, the complexity of linked-data tooling, and the challenge of competing with the convenience of centralised platforms.
