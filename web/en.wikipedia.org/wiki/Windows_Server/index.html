Windows Server is a brand name for a group of server operating systems developed by Microsoft since 2003. Built on the Windows NT codebase shared with the client versions of Windows, Windows Server editions add features for networking, hosting, virtualization, and enterprise administration.

Roles and features

Windows Server provides server roles such as Active Directory Domain Services for identity and authentication, DNS and DHCP servers, file and storage services, Internet Information Services (IIS) for web hosting, and the Hyper-V hypervisor for virtualization. Management is performed through Server Manager, Windows Admin Center, and PowerShell. Licensing is typically by processor cores, with editions such as Standard and Datacenter differing mainly in virtualization rights.

Versions

Major releases include Windows Server 2003, 2008 (with its R2 update), 2012, 2016, 2019, 2022, and 2025. Since 2017 Microsoft has also offered the Semi-Annual Channel (later Azure Stack HCI-aligned releases) for container and software-defined datacenter workloads, alongside the Long-Term Servicing Channel.
