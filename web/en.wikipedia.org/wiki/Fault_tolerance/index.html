Fault tolerance

Fault tolerance is the property that enables a system to continue operating properly in the event of the failure of (or one or more faults within) some of its components. If the system's operating quality decreases at all, the decrease is proportional to the severity of the failure — a property sometimes called graceful degradation — as opposed to a naively designed system in which even a small failure can cause total breakdown. Fault tolerance is essential in systems whose failure would be catastrophic or costly, such as flight control, nuclear plants, medical devices, and financial infrastructure.

Approaches

The most common technique is redundancy: duplicating critical components so that a backup can take over. Hardware redundancy ranges from duplicated power supplies and RAID disk arrays to lockstep processors that execute the same instructions and cross-check results, and to triple modular redundancy, in which three units vote on an output so that a single faulty unit is outvoted. Software approaches include error detection with retry, checkpointing and rollback, replication of services across machines, and N-version programming. Information redundancy — error-detecting and error-correcting codes such as parity, checksums, and Hamming codes — protects data in storage and transmission.

Designers distinguish fault detection, diagnosis, containment (preventing a fault from propagating), masking, and recovery. A system is described as fail-safe if it enters a safe state on failure, fail-operational if it must keep functioning, and single point of failure analysis is used to hunt down components whose loss would defeat the redundancy scheme. Byzantine fault tolerance addresses the harder problem of components that behave arbitrarily or maliciously, and underlies consensus protocols in distributed systems and blockchains.

History

Formal fault-tolerant computing began with John von Neumann's work in the 1950s on building reliable organisms from unreliable components, and was driven by aerospace and defence projects such as the Apollo guidance system and long-life unmanned spacecraft. The Tandem Computers NonStop systems of the 1970s brought hardware fault tolerance to commercial transaction processing. Modern cloud computing has shifted emphasis toward software-level resilience across commodity machines, formalised in concepts such as recovery-oriented computing and chaos engineering.
