Boolean function

In mathematics, a Boolean function is a function whose arguments and result assume values from a two-element set (usually {true, false}, {0,1}, or {−1,1}). Alternative names include switching function, used especially in older computer science literature, and truth function (or logical function), used in logic. Boolean functions are the subject of Boolean algebra and switching theory.

Representation

A Boolean function of n variables can be represented by a truth table with 2n rows, by algebraic formulas built from the connectives AND, OR, and NOT, by decision diagrams such as binary decision diagrams, or by circuits of logic gates. There are 22n distinct Boolean functions of n variables.

Applications

Boolean functions are fundamental to digital circuit design, where they describe the behavior of combinational logic, and to complexity theory, cryptography (where properties such as nonlinearity and balancedness are crucial for S-boxes), and coding theory.
