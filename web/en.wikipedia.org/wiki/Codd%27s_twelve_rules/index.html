Codd's twelve rules

Codd's twelve rules are a set of thirteen criteria (numbered zero to twelve) published by Edgar F. Codd in 1985 to define what counts as a truly relational database management system (RDBMS).

The rules

Rule 0 requires the system to qualify as relational as a database and a management system. The remaining rules cover, among other things: representing all information as values in tables; guaranteed access to every datum by table name, primary key and column name; systematic treatment of null values; an online catalogue based on the relational model; a comprehensive data sublanguage; view updating; high-level insert, update and delete; physical and logical data independence; integrity independence; distribution independence; and the non-subversion rule, preventing low-level access from bypassing integrity constraints.

Reception

Few commercial products satisfy all the rules, which were intended partly as a benchmark against products marketed as "relational" that were not.
