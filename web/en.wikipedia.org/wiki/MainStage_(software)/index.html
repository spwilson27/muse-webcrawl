MainStage (software)

MainStage is a music application developed by Apple for use in live performance. Released originally alongside Logic Studio in 2007, it turns a Mac into a multi-instrument and effects processor that can be controlled with a MIDI controller, using the same plug-ins, software instruments and effects found in Logic Pro.

Features

The program is organised around concerts, which contain sets of songs, each holding patches — combinations of channel strips, instruments and effects. A visual Layout mode lets performers design a screen of customisable controls (keyboards, knobs, faders, pedals) mapped to hardware, while the Edit mode assigns sounds and plug-ins. A full-screen Perform mode presents the controls for use on stage. MainStage supports features such as patch switching without cutting off sustained notes, playback of backing tracks, loop recording with the Loopback plug-in, and the Playback plug-in for multi-track accompaniment.

Release

MainStage was bundled with Logic Studio and later sold separately through the Mac App Store at a low price, with MainStage 3 released in 2013 alongside Logic Pro X. It is widely used by touring keyboardists, musical theatre productions, worship bands and guitarists as a software-based live rig.
