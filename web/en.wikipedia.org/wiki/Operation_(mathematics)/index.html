Operation (mathematics)

From Wikipedia, the free encyclopedia

In mathematics, an operation is a function that takes zero or more input values (called operands) to a well-defined output value. The number of operands is the arity of the operation. The most commonly studied operations are binary operations (arity two), such as addition and multiplication, and unary operations (arity one), such as additive inverse and trigonometric functions. An operation of arity zero, or a nullary operation, is simply a constant. An operation can be thought of as a special case of a function: an n-ary operation on a set S is a function from Sn to S.

Types

There are two common types of operations: unary and binary. Unary operations involve only one operand, such as negation and the trigonometric functions. Binary operations take two operands and include addition, subtraction, multiplication, division, and exponentiation. Operations can involve mathematical objects other than numbers: logical values true and false can be combined using logical operations such as AND, OR, and NOT; vectors can be added and subtracted; rotations can be combined; sets can be combined using union and intersection; and functions can be composed.

Definition and properties

An operation need not have as its domain or codomain a single set: in general, the types of the operands and the result may differ (as in scalar multiplication of vectors, or the dot product, which maps two vectors to a scalar). Properties commonly studied for binary operations include commutativity (whether the order of operands matters), associativity (whether grouping matters), and the existence of identity elements and inverse elements. These properties form the basis of algebraic structures studied in abstract algebra, such as groups, rings, and fields.

Notations

Operations are commonly denoted by infix symbols (a + b), function notation (f(a, b)), prefix notation (as in Polish notation), or postfix notation (as in reverse Polish notation). The order of operations is a collection of rules that reflect conventions about which procedures to perform first in a given mathematical expression.
