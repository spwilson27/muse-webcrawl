Mail transfer agent

A mail transfer agent (MTA), also called a mail relay or mail exchanger, is software that transfers electronic mail messages from one computer to another using the Simple Mail Transfer Protocol (SMTP). MTAs receive mail from mail user agents (MUAs) or from other MTAs, decide where the message should go next — using DNS MX records for the recipient's domain — and forward it onward until it reaches the destination mail server, which delivers it to the recipient's mailbox via a mail delivery agent.

Operation

When a message arrives, the MTA may accept it for local delivery, relay it to another server, or reject it. To combat spam, modern MTAs generally refuse to act as "open relays" for third parties, authenticate submitting users, and apply checks such as SPF, DKIM and DMARC verification, greylisting and reputation-based filtering. Messages that cannot be delivered immediately are queued and retried; after repeated failures the MTA generates a bounce message to the sender.

Common MTAs

Historically dominant MTAs include Sendmail, one of the earliest and most widely deployed. Postfix, Exim and qmail became popular alternatives noted for simpler configuration or stronger security design, while Microsoft Exchange provides MTA functions within its mail platform. Together these programs form the backbone of the global email system.
