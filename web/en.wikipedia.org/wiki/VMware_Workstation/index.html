VMware Workstation

VMware Workstation
Developer: VMware (Broadcom)
Initial release: 1999
Platform: Windows, Linux (x86-64)
Type: Type-2 hypervisor
Variants: Workstation Pro, Workstation Player

VMware Workstation is a hosted (type-2) hypervisor developed by VMware that runs on Microsoft Windows and Linux hosts, allowing users to create and run multiple x86-64 virtual machines simultaneously on a single physical computer. Each virtual machine can run its own guest operating system — including other versions of Windows, Linux distributions, BSD and legacy systems — sharing the host's hardware resources.

History

VMware was founded in 1998, and Workstation was its first product, released in 1999; it brought virtualization technology previously associated with mainframes to commodity PCs and helped launch the modern virtualization industry. Versions for both professional and free use developed over time: the full-featured Workstation Pro and the simpler Workstation Player (originally VMware Player, 2005). Following Broadcom's acquisition of VMware, the company announced in 2024 that Workstation Pro would become free for personal and then for all use, with the Player discontinued as a separate product.

Features

Workstation supports snapshots (saving and reverting a VM's complete state), linked and full clones, virtual networking (bridged, NAT and host-only modes, with a virtual network editor), shared folders and drag-and-drop with the host, USB device passthrough, and 3D graphics acceleration including DirectX and OpenGL support in guests. VMs can be encrypted, restricted, and connected to vSphere/ESXi servers and clouds. Its ability to run complete isolated lab environments on a laptop made it a standard tool for software development, testing, training and malware analysis.

Related products

VMware Fusion provides equivalent functionality on macOS hosts, while the company's server products — ESXi and the vSphere suite — use a bare-metal (type-1) hypervisor derived from the same lineage.
