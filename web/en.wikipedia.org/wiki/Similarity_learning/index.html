Similarity learning

Similarity learning is an area of supervised machine learning concerned with learning a similarity function that measures how similar or related two objects are. It is closely related to metric learning, in which the goal is to learn a distance function over objects. Rather than predicting a class label directly, a similarity or distance model supports tasks such as ranking, retrieval, clustering, verification and nearest-neighbour classification.

Problem setting

Training data typically consist of pairs or triplets of examples annotated with relational information: pairs labelled as similar or dissimilar, or triplets (anchor, positive, negative) indicating that the anchor is more similar to the positive than to the negative example. The learning algorithm then fits a function — often a Mahalanobis distance defined by a positive semidefinite matrix, or the distance between learned embeddings produced by a neural network — that respects these constraints.

Approaches

Classical approaches learn a Mahalanobis metric by convex optimisation, as in large-margin nearest neighbour (LMNN) and neighbourhood components analysis (NCA). Deep metric learning instead trains neural networks — for example Siamese networks on pairs, or triplet networks minimising a triplet loss — to map inputs into an embedding space where Euclidean or cosine distance reflects semantic similarity. Contrastive learning methods extend these ideas to largely unlabelled data using augmented views of the same input as positive pairs.

Applications

Similarity learning is used in face verification and person re-identification, image and product retrieval, recommender systems, information retrieval and document ranking, speaker verification, and few-shot learning, where new classes must be recognised from a handful of examples by comparing them to stored prototypes.
