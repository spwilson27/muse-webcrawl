Taihō Code

The Taihō Code (大宝律令, Taihō-ritsuryō) was an administrative reorganisation enacted in imperial Japan in 701–702, at the end of the Asuka period. It established the ritsuryō system of government modelled on Tang dynasty China.

Contents and structure

Compiled under Prince Osakabe and Fujiwara no Fuhito, the code comprised criminal law (ritsu) and administrative statutes (ryō). It organised the imperial government into the Council of State (Daijō-kan) and eight ministries, and the country into provinces, districts and villages, with a census, land-allotment and taxation system.

Significance

The Taihō Code consolidated centralised imperial rule under the emperor. Although the original text is lost, its content is largely recoverable from the later Yōrō Code and commentaries. Parts of the system remained nominally in force until the Meiji Restoration.
