The High Efficiency Image File Format (HEIF) is a container format for storing individual images and image sequences, standardised by the Moving Picture Experts Group (MPEG) as ISO/IEC 23008-12. Files typically store images encoded with HEVC (High Efficiency Video Coding), giving roughly half the file size of equivalent-quality JPEG, along with support for 16-bit colour, transparency, thumbnails, auxiliary images such as depth maps, and non-destructive edits stored as metadata.

Variants and adoption

The variant using HEVC intra-frame coding is commonly known by its extension .heic (High Efficiency Image Container). Apple adopted HEIC as the default photo format on iOS 11 (2017), which drove widespread — though still incomplete — support across platforms, cameras and browsers. HEIF can also carry AV1-encoded images (AVIF is a separate but related container derived from it).

Features

  • Image sequences and bursts in a single file
  • Derived images and edits (crop, rotate, overlays) stored without altering the original data
  • Multiple codec support; thumbnails and metadata (EXIF, XMP) embedded
