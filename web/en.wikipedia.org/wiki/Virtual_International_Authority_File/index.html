Virtual International Authority File

The Virtual International Authority File (VIAF) is an international authority file. It is a joint project of several national libraries and is operated by OCLC. The project was initiated by the US Library of Congress (LC), the Deutsche Nationalbibliothek (DNB), and the Bibliothèque nationale de France (BnF) to link the national authority files of names, so that the same person or organisation recorded differently in different countries' catalogues could be identified as a single entity.

Purpose and structure

Authority control solves a basic problem of library cataloguing: the same author may appear under variant name forms — different transliterations, pseudonyms, married names, or spellings — in different catalogues. Each participating national library maintains its own authority record, with its own identifier. VIAF's matching algorithms cluster these records together when they appear to describe the same entity, and assign the cluster a single VIAF identifier (VIAF ID). Each cluster links out to the original records in the source files, such as the Library of Congress Name Authority File (LCNAF), the German Integrated Authority File (GND), and the authority files of dozens of other national libraries and cultural agencies.

Participating institutions

Contributors grew from the three founding libraries to include national libraries from countries across Europe, Asia, the Americas, Africa, and Oceania, together with other contributors such as the Getty's Union List of Artist Names and Wikidata. VIAF data is available as linked open data, and VIAF identifiers are widely used in library metadata, in Wikipedia and Wikidata infoboxes, and in scholarly identification systems to connect a person across catalogues.
