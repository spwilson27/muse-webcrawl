RISC-V (pronounced "risk-five") is an open standard instruction set architecture (ISA) based on established reduced instruction set computer (RISC) principles. Unlike most other ISA designs, RISC-V is provided under royalty-free open licenses, so anyone may design, manufacture and sell RISC-V chips and software without paying licence fees, while proprietary implementations need not be disclosed.

The project began in 2010 at the University of California, Berkeley, led by Krste Asanović and David Patterson, as the fifth generation of Berkeley RISC designs. The RISC-V Foundation, now RISC-V International, was established in 2015 to maintain the standard; in 2019 the foundation moved its headquarters to Switzerland.

Design

RISC-V is structured as a small base integer instruction set (such as RV32I or RV64I) plus optional standard extensions, allowing implementations to be tailored from tiny embedded controllers to supercomputers. Standard extensions include M (integer multiplication and division), A (atomics), F and D (single- and double-precision floating point), C (compressed 16-bit instructions), and V (vector operations). The base and most extensions were frozen and ratified, guaranteeing that software written for them will run on future implementations.

The architecture provides separate user-level and privileged specifications, a variable-length instruction encoding, and a large uniform register file of 31 general-purpose registers plus a zero register in the base design.

Adoption

RISC-V has been adopted for embedded controllers, storage devices, AI accelerators, and increasingly for application processors and data-centre chips. Western Digital committed to shipping RISC-V cores in its storage products; NVIDIA uses RISC-V cores as controllers in its GPUs; and vendors including SiFive, Alibaba (T-Head), Andes and Espressif market RISC-V silicon. Open-source cores such as Rocket Chip and BOOM, and support in Linux, GCC and LLVM, underpin a growing software ecosystem.
