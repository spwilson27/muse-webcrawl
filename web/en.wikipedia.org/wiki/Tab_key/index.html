Tab key

The tab key (short for tabulator key or tabular key) is a key on many computer keyboards, found right above the Caps Lock key and to the left of the Q key on QWERTY layouts. It is used to insert a tab character, to move the cursor to the next tab stop, and in graphical user interfaces to move keyboard focus between controls.

History

The tabulator mechanism originated on typewriters, where it allowed the carriage to jump quickly to preset positions ("tab stops") for filling in tables, invoices, and forms. Early computer terminals inherited the concept, and the tab character (ASCII code 9, horizontal tabulation) became a standard whitespace character in text files.

Uses

In text editing, pressing Tab inserts a tab character or an equivalent run of spaces used for indentation. In word processors it advances to the next tab stop. In forms and dialog boxes, Tab moves focus forward through fields, while Shift+Tab moves it backward. Many shells and code editors use Tab for autocompletion of commands and file names. In programming source code, tabs are widely used for indentation, a subject of long-running debate with advocates of spaces.
