DTrace

DTrace is a comprehensive dynamic tracing framework originally developed by Sun Microsystems and released in Solaris 10 in 2005. It allows administrators and developers to observe the behaviour of both user programs and the operating system kernel in production, with negligible overhead when probes are not enabled.

Design

Users write scripts in the D language, attaching actions to probes provided by providers such as syscall, fbt (function boundary tracing) and profile. Probes fire as events occur; aggregations summarise data in the kernel, reducing output volume.

Ports

DTrace was ported to FreeBSD, macOS (where a restricted form ships as part of the system tools), NetBSD, and later to Linux and Windows under the OpenDTrace effort and by Oracle and Microsoft.
