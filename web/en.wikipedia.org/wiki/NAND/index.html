NAND

NAND may refer to: the logical NAND operation ("not AND"), a binary operation that is false only when both inputs are true; the NAND gate in digital electronics; and NAND flash memory, a type of non-volatile storage.

Logic

The NAND operation is functionally complete: any Boolean function can be implemented using only NAND gates, a property exploited in computer design. Its truth table gives output 0 only for inputs 1,1.

Flash memory

NAND flash, named for the NAND-like series connection of its memory cells, underlies USB drives, memory cards and solid-state drives, offering high density at low cost.
