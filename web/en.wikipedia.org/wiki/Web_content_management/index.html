Web content management

Web content management (WCM) is the process of creating, managing and publishing content on websites. A web content management system (WCMS, or CMS) is a software system that provides website authoring, collaboration and administration tools designed to allow users with little knowledge of web programming languages or markup languages to create and manage website content with relative ease.

A robust WCMS provides the foundation for collaboration, offering capabilities that enable multiple users to create, edit and publish content. Most systems store content in a database and assemble pages from templates when they are requested, or generate the site statically in advance.

Features

Core features typically include a WYSIWYG editor, content versioning and workflow, user roles and permissions, media management, search and categorisation, multi-site and multilingual support, and personalisation. Plugins or modules extend functionality to areas such as e-commerce, forms, analytics and search engine optimisation.

Types

Well-known systems include WordPress, Drupal and Joomla among open-source platforms, and commercial products such as Adobe Experience Manager, Sitecore and Contentful. "Headless" CMS products separate content storage and delivery APIs from presentation, allowing content to be reused in mobile apps and other channels.
