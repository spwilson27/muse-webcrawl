Universal Disk Format

Universal Disk Format (UDF) is an open, vendor-neutral file system format for computer data storage, originally developed by the Optical Storage Technology Association (OSTA). It is the standard file system for DVD and Blu-ray Disc media and can also be used on other storage media.

History

UDF was designed to replace ISO 9660, overcoming its limits on file size and naming. The first version was released in 1995; UDF 1.50 added support for packet writing on CD-R and CD-RW, and UDF 2.50/2.60 are used on Blu-ray media. DVD-Video discs use a constrained subset called UDF Bridge, combining UDF 1.02 with ISO 9660 for compatibility.

Features

UDF supports files up to 16 exbibytes, long Unicode file names, extended attributes, and metadata partitioning. Its "VAT" (virtual allocation table) and later "sparing" structures allow rewritable and write-once media to be used somewhat like a hard disk, enabling drag-and-drop file copying to optical discs in operating systems such as Windows (Live File System) and macOS.
