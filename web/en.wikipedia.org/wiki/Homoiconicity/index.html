Homoiconicity

In computer programming, homoiconicity (from Greek homo, "same", and icon, "representation") is a property of some programming languages in which the program structure is similar to its syntax, and therefore the program's internal representation can be inferred from reading its text. In a homoiconic language, the primary representation of programs is also a data structure in a primitive type of the language itself.

Lisp

The classic example is Lisp, whose code is written as S-expressions — nested lists that are also Lisp's fundamental data structure. A Lisp program can therefore manipulate its own code as data using ordinary list operations, which underlies Lisp's powerful macro system. For example, the expression (+ 1 2) is simultaneously a function call and a three-element list.

Other languages

Other languages with homoiconic features include Prolog (to a degree), Rebol, Julia, Tcl, Io and various concatenative languages. Alan Kay is sometimes credited with popularising discussion of the concept, and the term echoes Douglas McIlroy's observation about Lisp in early AI research.

Advantages

Because code and data share a representation, metaprogramming becomes straightforward: programs can generate, transform and analyse other programs without needing a separate parser or abstract syntax tree representation.
