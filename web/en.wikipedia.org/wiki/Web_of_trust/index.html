Web of trust

In cryptography, a web of trust is a concept used in PGP, GnuPG, and other OpenPGP-compatible systems to establish the authenticity of the binding between a public key and its owner. It is a decentralized alternative to the centralized trust model of a public key infrastructure (PKI), which relies exclusively on a certificate authority (or hierarchies of such authorities).

Operation

In a web of trust, users generate their own key pairs and certify the keys of others by digitally signing them, typically after verifying the owner's identity in person, for example at a key signing party. When a user receives a new key, they can decide whether to trust it based on the signatures it carries: a key signed by a fully trusted introducer, or by a sufficient number of marginally trusted introducers, may be considered valid. Trust in this model is thus quantified and propagated through the network of signatures rather than conferred by a single authority.

Comparison with PKI

The web of trust contrasts with the hierarchical model used by TLS certificate authorities, in which trust flows from a small set of root authorities. The decentralized model avoids a single point of failure but places more burden on users to manage trust decisions and has proved difficult to scale for non-technical users.
