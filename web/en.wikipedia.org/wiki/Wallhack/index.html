Wallhack

A wallhack is a form of cheating in multiplayer video games, particularly first-person shooters, that allows a player to see opponents and other objects through walls and other solid surfaces. Because game clients must receive information about nearby entities in order to render them when they become visible, cheat software can exploit this data to render hidden players as outlines or highlighted models regardless of occlusion.

Methods

Wallhacks are typically implemented by modifying the game's rendering: disabling depth testing for player models, intercepting graphics API calls (such as DirectX or OpenGL) to draw characters with distinct colours through geometry, or reading entity positions from memory and drawing markers via an external overlay (ESP, or "extrasensory perception", cheats). Related cheats include "chams" (character models rendered in bright colours) and radar hacks.

Countermeasures

Game developers combat wallhacks with server-side occlusion — withholding information about players a client cannot legitimately see — and with anti-cheat systems such as Valve Anti-Cheat (VAC), Easy Anti-Cheat, BattlEye, and kernel-level systems like Riot Vanguard, which attempt to detect cheat software. Use of wallhacks in competitions can lead to account bans and disqualification from esports events.
