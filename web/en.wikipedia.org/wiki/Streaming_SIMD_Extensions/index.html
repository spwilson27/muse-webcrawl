Streaming SIMD Extensions

SSE registers hold four single-precision floats operated on in parallel

Streaming SIMD Extensions (SSE) is a single instruction, multiple data (SIMD) instruction set extension to the x86 architecture, introduced by Intel with the Pentium III processor in 1999. SSE added eight new 128-bit registers (XMM0–XMM7) and 70 instructions, principally for single-precision floating-point operations performed on four 32-bit values at once, together with cache prefetching and streaming-store instructions designed to reduce cache pollution when processing large media data.

Successive versions

SSE2 (Pentium 4, 2000) extended SIMD to double-precision floating point and to integer operations in the XMM registers; it is part of the baseline of the x86-64 architecture. SSE3 (2004) added horizontal arithmetic and a few DSP-oriented instructions; SSSE3 (2006) added byte-shuffle and absolute-value operations; SSE4 (2007–2008, in two sub-versions, SSE4.1 and SSE4.2) added string processing, dot products and a population-count instruction. The line was later superseded by Advanced Vector Extensions (AVX), which widened registers to 256 bits (and 512 bits with AVX-512), but SSE instructions remain ubiquitous in compiled software.

Use

SSE is heavily used in multimedia codecs, games, scientific computing and signal processing, where the same operation on arrays of floats is common. Compilers generate SSE2 code by default for 64-bit x86 targets, and programmers can access the instructions through intrinsic functions such as those in the <xmmintrin.h> family of headers.
