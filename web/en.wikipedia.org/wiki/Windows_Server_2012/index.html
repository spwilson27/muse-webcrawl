Windows Server 2012, codenamed "Windows Server 8", is the fifth major release of the Windows Server operating system by Microsoft, released alongside Windows 8. It was the first Windows Server version with no support for Itanium-based computers and the first to emphasize cloud computing and large-scale virtualization.

Features

Notable additions included Hyper-V 3.0 with support for up to 320 logical processors and 4 TB of memory per host, the ReFS resilient file system, Storage Spaces for storage virtualization, an IP address management (IPAM) role, and version 3 of Server Message Block (SMB). The operating system adopted the Metro-style interface of Windows 8, while the Server Core installation option became the recommended default and administrators could switch between Server Core and full GUI modes.

Editions

Microsoft simplified the lineup to four editions: Foundation (OEM-only), Essentials, Standard, and Datacenter, with Standard and Datacenter differing chiefly in virtualization rights. Extended support, including paid Extended Security Updates, ended in October 2026 for eligible customers.
