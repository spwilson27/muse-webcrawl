Edwards curve geometry underlying Ed25519

Ed25519 is an EdDSA digital signature scheme using SHA-512 (SHA-2) and the twisted Edwards curve −x² + y² = 1 + dx²y² with d = −121665/121666, related by a birational equivalence to Curve25519. It was introduced in 2011 by Daniel J. Bernstein and co-authors in the paper "High-speed high-security signatures". Ed25519 is designed to provide fast signing and verification, small keys and signatures, and — critically — deterministic signature generation that avoids the catastrophic failures that occur when a conventional random number generator fails during signing.

Design and properties

In Ed25519, the private key is a 32-byte seed, hashed with SHA-512 to derive a secret scalar and a nonce prefix. The signature nonce is computed deterministically as a hash of the nonce prefix and the message, so signing the same message always yields the same signature and no randomness is needed at signing time. A signature consists of 64 bytes: a curve point R and a scalar S. Verification checks the group equation [S]B = R + [H(R, A, M)]A, where A is the public key and H is SHA-512 reduced mod the group order.

Key features include:

  • Speed — over 100,000 signatures per second were reported on contemporary hardware in the original paper, with fast batch verification.
  • Safety by design — the curve parameters were chosen transparently from explicit security criteria; the implementation avoids secret-dependent branches and array indices, resisting timing side channels.
  • Collision resilience — security is not undermined by hash collisions in the way Schnorr-style schemes analysed generically are.
  • Small sizes — 32-byte public keys and 64-byte signatures.

Adoption

Ed25519 is supported in OpenSSH (as a default key type since version 6.5), GnuPG, NaCl/libsodium, OpenSSL, Bouncy Castle and many other libraries. It was standardised with Ed448 in RFC 8032 (2017) and included in TLS 1.3, FIPS 186-5 (2023), and the protocols of Signal, Tor (next-generation onion services), and many blockchain systems. Its deterministic signing and resistance to implementation pitfalls have made it the default recommendation for new signature applications.

Variants

Ed25519ph signs a pre-hashed message for contexts where the message cannot be processed in one pass; Ed25519ctx adds a context string for domain separation. Related schemes include Ed448 (using the larger Goldilocks curve) and the XEdDSA variant used by Signal, which allows the same key material to be used for both X25519 key agreement and signatures.
