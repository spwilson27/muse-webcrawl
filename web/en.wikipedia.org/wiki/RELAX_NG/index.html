RELAX NG

RELAX NG (REgular LAnguage for XML, Next Generation) is a schema language for XML — a set of rules that defines the structure and content of XML documents. It was designed by James Clark and Murakami Makoto, merging Clark's TREX (Tree Regular Expressions for XML) and Murakami's RELAX (Regular Language description for XML).

RELAX NG was standardised by OASIS in 2001 and as part of ISO/IEC 19757 (the Document Schema Definition Languages, DSDL) in 2003. A RELAX NG schema can be written in two syntaxes: an XML-based syntax and a compact, non-XML syntax designed to be easier to read and write.

Features

Unlike XML Schema (XSD), RELAX NG is based on a mathematical theory of tree automata and treats elements and attributes uniformly. It supports unordered content, mixed content, namespaces, and pluggable datatype libraries. It deliberately omits features such as identity constraints and schema-aware type assignment, keeping validation simple and composable.

Users

RELAX NG is the schema language of the OASIS OpenDocument format and of DocBook 5, and is used for TEI and numerous other vocabularies. Tools such as Jing validate documents against RELAX NG schemas.
