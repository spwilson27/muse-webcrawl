Deterministic pushdown automaton

A pushdown automaton reads input while manipulating a stack.

In automata theory, a deterministic pushdown automaton (DPDA or DPA) is a variation of the pushdown automaton. The class of deterministic pushdown automata accepts the deterministic context-free languages, a subset of context-free languages. Unlike a nondeterministic pushdown automaton, a DPDA's next action is uniquely determined by its current state, the top of the stack, and the next input symbol (or the option of an ε-move, which must be exclusive).

Formal definition

A DPDA is a 7-tuple (Q, Σ, Γ, δ, q0, Z, F) consisting of a finite set of states, an input alphabet, a stack alphabet, a transition function, a start state, an initial stack symbol, and a set of accepting states. Determinism requires that for every state, input symbol, and stack symbol, there is at most one possible transition, and that ε-transitions cannot compete with input-consuming transitions from the same configuration.

Power

DPDAs are strictly less powerful than nondeterministic pushdown automata: for example, no DPDA can accept the language of even-length palindromes, because the machine cannot guess the middle of the input. They are strictly more powerful than finite automata, since they can accept languages such as {anbn : n ≥ 0}. Every regular language is a deterministic context-free language.

Properties and decidability

The class of languages accepted by DPDAs is closed under complement, which makes problems such as equivalence decidable — a famous result proved by Sénizergues in 1997. Emptiness is decidable as well. These properties distinguish deterministic machines sharply from their nondeterministic counterparts.
