Syntax (programming languages)

In computer science, the syntax of a programming language is the set of rules that defines the combinations of symbols that are considered to be correctly structured statements or expressions in that language. This applies both to programming languages, where the document represents source code, and to markup languages, where the document represents data.

The syntax of a language defines its surface form. Text-based programming languages are based on sequences of characters, while visual programming languages are based on the spatial layout and connections between symbols. A language's syntax is usually defined by a combination of regular expressions (for lexical structure) and Backus–Naur form (for grammatical structure). Programs that fail to conform to the syntax are rejected by the compiler or interpreter with a syntax error, before any question of meaning arises.

Levels of syntax

  • Lexical syntax — the rules, often expressed as regular expressions, that group characters into tokens such as identifiers, literals, operators, and keywords.
  • Concrete syntax — the grammar of token sequences, usually described by a context-free grammar in Backus–Naur form, which determines how expressions, statements, and declarations can be composed. Parsing builds a parse tree from source text.
  • Abstract syntax — the essential structure of a program, represented as an abstract syntax tree, discarding punctuation and other purely notational details.

Syntax versus semantics

Syntax concerns what programs look like; semantics concerns what they mean. A syntactically valid program may still be meaningless or wrong — for example, adding a string to an integer may be grammatically well-formed in some languages but rejected by type rules, a distinction captured in Chomsky's famous natural-language example "Colorless green ideas sleep furiously", which is grammatical but nonsensical. Language design decisions — such as Python's significant indentation, Lisp's uniform parenthesized S-expressions, or C's braces and semicolons — shape the character of a language while expressing equivalent underlying structures.
