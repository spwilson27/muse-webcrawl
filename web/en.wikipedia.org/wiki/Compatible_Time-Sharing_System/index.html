Compatible Time-Sharing System

The Compatible Time-Sharing System (CTSS) was one of the first time-sharing operating systems. It was developed at the MIT Computation Center, led by Fernando J. Corbató, and first demonstrated in 1961 on an IBM 709, later running on modified IBM 7090/7094 machines.

Features

CTSS let multiple users at terminals interact with programs simultaneously, sharing the processor. It introduced or popularised many now-familiar concepts: one of the first computer password systems, inter-user messaging that anticipated email, text editing and formatting tools (RUNOFF), and the ability to share files. Its name reflected compatibility with the standard batch-processing system (IBSYS) running in the background.

Influence

CTSS directly inspired Multics, and through it many ideas in Unix. A notable incident was an early password-file mishap in which a software bug printed user passwords — an early lesson in computer security. It ran at MIT until 1973.
