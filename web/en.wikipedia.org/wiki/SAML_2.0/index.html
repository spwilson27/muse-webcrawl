SAML 2.0

SAML 2.0
Full name: Security Assertion Markup Language 2.0
Year: 2005
Body: OASIS Security Services Technical Committee

Security Assertion Markup Language 2.0 (SAML 2.0) is a version of the SAML standard for exchanging authentication and authorisation data between security domains. SAML 2.0 is an XML-based protocol that uses security tokens containing assertions to pass information about a principal (usually an end user) between an identity provider (IdP) and a service provider (SP).

History

SAML 2.0 was ratified as an OASIS standard in March 2005, superseding SAML 1.1. It merged features of the Liberty Alliance's Identity Federation Framework, which was donated to OASIS, and remained the dominant standard for enterprise web single sign-on for well over a decade.

How it works

In the most common flow, the Web Browser SSO Profile, the user attempts to access a service provider, which redirects the browser to the identity provider with an authentication request. The IdP authenticates the user and returns a digitally signed XML assertion, delivered through the browser, attesting to the user's identity and attributes. The service provider validates the signature and creates a local session. SAML 2.0 also defines single logout and metadata profiles used to establish trust between parties.
