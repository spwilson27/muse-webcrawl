WPA2 (Wi-Fi Protected Access 2) is a security certification program and network security protocol developed by the Wi-Fi Alliance to secure wireless computer networks. It implements the IEEE 802.11i standard and replaced the interim WPA in 2004. WPA2 became mandatory for all new devices bearing the Wi-Fi trademark from 2006 and for many years was the most widely used wireless security protocol in the world.

Operation

WPA2 encrypts traffic using AES in CCMP mode (Counter Mode with Cipher Block Chaining Message Authentication Code Protocol), providing both confidentiality and integrity. Two modes of authentication are defined: WPA2-Personal, using a pre-shared key (PSK) derived from a passphrase via PBKDF2, and WPA2-Enterprise, using IEEE 802.1X and an authentication server (typically RADIUS) with EAP methods. A four-way handshake between client and access point derives fresh session keys and confirms both parties know the credentials.

Security issues

WPA2-Personal is vulnerable to offline dictionary attacks against captured handshakes if a weak passphrase is chosen. In October 2017, Mathy Vanhoef disclosed the KRACK (Key Reinstallation Attack) vulnerabilities, which forced nonce reuse in the handshake and allowed decryption of traffic; patches were issued for virtually all platforms. Other flaws, including the WPS PIN weakness (affecting WPA/WPA2 routers with Wi-Fi Protected Setup enabled), have also been documented.

Successor

The Wi-Fi Alliance announced WPA3 in January 2018. WPA3-Personal uses the SAE (Simultaneous Authentication of Equals) handshake, which resists offline dictionary attacks and provides forward secrecy. WPA2 remains widely deployed, often in mixed transition modes alongside WPA3.
