Document type definition

Document type definition
AbbreviationDTD
Used withSGML, XML
DeclarationsELEMENT, ATTLIST, ENTITY, NOTATION

A document type definition (DTD) is a set of markup declarations that define a document type for an SGML-family markup language such as XML or HTML. A DTD specifies the legal building blocks of a document: which elements and attributes may appear, their nesting and content models, and the entities and notations available.

Declarations

DTDs consist of element type declarations (<!ELEMENT>), attribute-list declarations (<!ATTLIST>), entity declarations (<!ENTITY>) and notation declarations (<!NOTATION>). A DTD may be internal, embedded in the document's DOCTYPE declaration, or external, referenced by a system or public identifier.

Validation

An XML processor can validate a document against its DTD, checking that the structure conforms. DTDs were the original schema language for XML, but their non-XML syntax, limited datatyping and lack of namespace support led to alternatives such as XML Schema (XSD) and RELAX NG. The HTML 4 DTDs were central to early web standards; HTML5 replaced them with a simple <!DOCTYPE html> trigger for standards mode.
