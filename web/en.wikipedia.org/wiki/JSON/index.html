JSON

JSON (JavaScript Object Notation)

Filename extension: .json

Internet media type: application/json

Developed by: Douglas Crockford and the JSON.org community

Standard: RFC 8259; ECMA-404; ISO/IEC 21778

Type: Data interchange format

JSON (JavaScript Object Notation, pronounced "Jason") is an open standard file and data interchange format that uses human-readable text to store and transmit data objects consisting of name–value pairs and arrays. It is the most common data format used for asynchronous browser–server communication, having largely replaced XML in web APIs, and is also widely used for configuration files and in NoSQL databases.

History

JSON grew out of a subset of the JavaScript scripting language — specifically the syntax for object literals — in the early 2000s. Douglas Crockford popularized the format and registered the json.org website in 2001; the first JSON message was sent in 2001 from a computer in a garage in San Francisco. The format was formalized as RFC 4627 in 2006, then as ECMA-404 in 2013, and the current internet standard is RFC 8259 (2017), published in lockstep with the second edition of ECMA-404.

Data types and syntax

JSON supports a small set of data types: strings (in double quotes, with backslash escapes), numbers, the literals true, false, and null, objects (unordered collections of name–value pairs in braces), and arrays (ordered lists in brackets). Comments are not permitted. An example:

{
  "name": "Ada Lovelace",
  "born": 1815,
  "programmer": true,
  "languages": ["Analytical Engine notes"],
  "spouse": null
}

Use

Because nearly every programming language ships with JSON parsers, JSON became the default for REST APIs, webhooks, and configuration (for example in package.json for Node.js). Document databases such as MongoDB and CouchDB store JSON-like documents, and formats including GeoJSON and JSON-LD extend the base syntax for geographic data and linked data respectively. Critics note limitations such as the absence of dates, the single number type, and the inability to represent comments; variants like JSON5 and JSONC address some of these for configuration use.
