Maildir

Maildir is a widely used format for storing electronic mail messages, in which each message is kept in a separate file with a unique name. It was designed by Daniel J. Bernstein for the qmail mail transfer agent as an alternative to the older mbox format, which stores all messages of a folder in a single file.

Structure

A Maildir directory (often ~/Maildir) contains three subdirectories: tmp, new and cur. A delivering program writes a new message to a uniquely named file in tmp, then moves it to new once writing is complete, ensuring that readers never see a partial message. When a mail reader accesses the folder, messages are moved to cur and information about their state — such as whether they have been seen, replied to or flagged — is encoded by suffixes appended to the filename after a colon.

Advantages

Because every message is a separate file and delivery is done by atomic renames, Maildir requires no file locking, making it robust on network filesystems and safe against corruption when processes access the mailbox concurrently — a chronic weakness of mbox. Individual messages can also be backed up, searched and deleted as ordinary files. Its main drawbacks are poorer performance on very large folders on some filesystems and less efficient storage than single-file formats.

Use

Maildir is supported by mail servers and delivery agents including qmail, Postfix, Dovecot, Courier and procmail, and by many mail user agents; the related Maildir++ variant adds support for subfolders and quotas.
