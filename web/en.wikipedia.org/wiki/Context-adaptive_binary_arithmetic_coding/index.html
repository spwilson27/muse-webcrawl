Context-adaptive binary arithmetic coding

Context-adaptive binary arithmetic coding (CABAC) is a form of entropy encoding used in modern video compression standards, principally the H.264/MPEG-4 AVC and H.265/HEVC standards, and retained in later codecs in evolved forms. CABAC compresses data by arithmetic coding of a binary symbol stream, while adapting the probability model used for each symbol to its surrounding context — the values of neighbouring and previously coded symbols.

Algorithm

The encoder works in three stages. First, binarisation: each non-binary syntax element (such as a quantised transform coefficient level or a motion-vector component) is converted into a string of binary decisions ("bins") using schemes such as unary, truncated unary or Exp-Golomb codes. Second, context modelling: for each bin, a context model is selected based on previously coded data, and the model maintains an adaptive probability estimate for the bin being 0 or 1, updated as coding proceeds. Third, the binary arithmetic coding engine encodes the bin using its estimated probability, subdividing the current coding interval. Certain bins of less statistical significance may be coded in a "bypass" mode assuming equal probability, which simplifies and speeds up processing.

Performance and usage

CABAC typically provides substantially better compression than the simpler variable-length (CAVLC) alternative in H.264 — commonly on the order of 10–15% bit-rate savings for equivalent quality — at the cost of greater computational complexity and harder parallelisation, since probability adaptation is serial. For this reason early mobile implementations often preferred CAVLC. CABAC is mandatory in the higher profiles of H.264 and is the sole entropy coding method in HEVC, whose larger context set and improved initialisation yield further gains. The technique builds on earlier context-based arithmetic coders developed in research at companies including IBM.
