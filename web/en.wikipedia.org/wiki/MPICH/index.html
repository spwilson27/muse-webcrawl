MPICH

MPICH, formerly known as MPICH2, is a freely available, portable implementation of MPI, a standard for message-passing for distributed-memory applications used in parallel computing. It is developed primarily by Argonne National Laboratory in the United States, and is distributed as free and open-source software under a BSD-style licence.

History

The original MPICH implementation was developed during the 1990s alongside the MPI-1 standard, with the goal of providing a high-quality, portable reference implementation of the standard. MPICH2 was a complete redesign implementing the MPI-2 standard, including parallel I/O and dynamic process management; with the release of version 3.0 in 2012, which implemented MPI-3, the project returned to the name MPICH. Later releases have added support for the MPI-4 standard.

Architecture

MPICH is organised in layers: an upper layer implementing the MPI interface, an abstract device interface (ADI, in modern versions the "CH" device layer, e.g. ch3 and ch4), and low-level communication backends ("netmods") targeting networks such as TCP sockets, InfiniBand (via UCX or OFI/libfabric) and shared memory. Many vendor and derivative implementations, including Intel MPI, Microsoft MPI and Cray MPI, have been based on MPICH code.
