Address bus

An address bus is a computer bus architecture used to transfer data between devices that are identified by the hardware address of the physical memory (the physical address), which is stored in the form of binary numbers to enable the data bus to access memory storage. The address bus carries the address of the location the processor intends to read from or write to, while the data bus carries the actual data and the control bus carries signals such as read/write and timing.

Width and capacity

The width of the address bus — the number of its parallel lines — determines the maximum amount of addressable memory: an n-bit address bus can address 2n locations. The 8086's 20-bit address bus could address 1 MB; 32-bit buses allow 4 GB; modern processors use 64-bit virtual addressing with somewhat narrower physical address buses. Unlike the data bus, the address bus is typically unidirectional, driven by the CPU or a DMA controller.
