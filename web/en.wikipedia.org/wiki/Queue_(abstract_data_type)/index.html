Queue (abstract data type)

From Wikipedia, the free encyclopedia

In computer science, a queue is a collection of entities that are maintained in a sequence and can be modified by the addition of entities at one end of the sequence (the rear) and the removal of entities from the other end (the front). This makes the queue a first-in-first-out (FIFO) data structure: the first element added is the first to be removed, like a line of people waiting for service.

Operations

  • enqueue — add an element to the rear of the queue.
  • dequeue — remove and return the element at the front.
  • peek / front — return the front element without removing it.
  • isEmpty — test whether the queue has no elements.

Implementations

Queues are commonly implemented with a linked list or with a fixed array used as a circular buffer, in which head and tail indices wrap around so that both enqueue and dequeue run in constant time. Variants include the double-ended queue (deque), which allows insertion and removal at both ends, and the priority queue, in which elements are removed in order of priority rather than arrival.

Uses

Queues model buffers, print spoolers, task schedulers, message queues between processes, and breadth-first search in graphs.
