Inverse distance weighting

Inverse distance weighting (IDW) is a type of deterministic method for multivariate interpolation with a known scattered set of points. The assigned values to unknown points are calculated with a weighted average of the values available at the known points. This method can also be used to create spatial weights matrices in spatial autocorrelation analyses.

The name given to this type of method was motivated by the weighted average applied, as it resorts to the inverse of the distance to each known point ("amount of proximity") when assigning weights.

Definition

Given a set of sample points, the IDW method assigns to an unknown point u a value that is a weighted average of the sample values, where each weight decreases as the distance from the unknown point increases. A common form of the weight is:

wi = 1 / d(x, xi)p

where d is the distance between the unknown point and the i-th sample point, and p is a positive real number called the power parameter. The estimated value is then the weighted mean of all sample values.

Properties

As the power parameter increases, the influence of more distant points diminishes and the interpolant approaches a nearest-neighbour surface. IDW is an exact interpolator: it passes through the sample points themselves. However, it can produce characteristic "bull's-eye" artefacts around isolated sample points, and it cannot predict values outside the range of the sampled data.

Applications

IDW is widely used in geographic information systems (GIS) to interpolate surfaces from point measurements, such as rainfall, temperature, elevation samples, and mineral grades in mining. Its simplicity and speed make it a common baseline against which more sophisticated methods such as kriging are compared.
