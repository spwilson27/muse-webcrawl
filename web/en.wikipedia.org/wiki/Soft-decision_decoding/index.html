Soft-decision decoding

In information theory, soft-decision decoding is a method of error-correction decoding in which the decoder uses not only the received symbols but also information about their reliability — the probability that each symbol is correct — rather than a single hard 0/1 judgement per bit.

Comparison with hard-decision decoding

A hard-decision decoder first quantises each received value to a definite bit, discarding reliability information. A soft-decision decoder retains graded values (often as log-likelihood ratios), which typically yields a coding gain of roughly 2–3 dB over hard-decision decoding at the cost of greater complexity.

Applications

Soft-decision methods are central to algorithms such as the Viterbi algorithm applied to convolutional codes, turbo decoding, and belief-propagation decoding of LDPC codes, all used widely in modern communications.
