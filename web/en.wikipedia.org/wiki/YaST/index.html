YaST

YaST (Yet another Setup Tool) is an installation and configuration tool for the openSUSE and SUSE Linux Enterprise operating systems. It provides a unified interface — available in graphical (Qt), text-based (ncurses), and web-based forms — for tasks such as installing the system, managing software packages, configuring hardware, setting up networks, and administering users.

History

YaST began as the installer for SuSE Linux in the mid-1990s. It was long written in a proprietary scripting language called YCP (YaST Control Programming). In 2004, Novell released YaST under the GNU General Public License. The codebase was later converted from YCP to Ruby, a project completed around 2013, making it more accessible to outside contributors.

Features

YaST includes modules for partitioning disks, managing the GRUB bootloader, configuring printers and scanners, administering the firewall, and managing software repositories through the libzypp package backend. AutoYaST allows fully automated, unattended installation of large numbers of machines using XML profiles. YaST's comprehensive system administration capabilities are frequently cited as one of the distinguishing features of the SUSE family of distributions.
