Literate programming

Literate programming is a programming paradigm introduced by Donald Knuth in 1984. It treats a program as literature addressed to human readers: the source document interleaves a natural-language explanation with code snippets, written in the order best for exposition rather than the order demanded by the compiler.

WEB and the tangle/weave model

Knuth's WEB system processed a single source file with two tools: WEAVE, which produced a typeset document (via TeX) with cross-references and an index, and TANGLE, which extracted the code fragments and rearranged them into a compilable Pascal (later C, in CWEB) program. Macros in WEB resemble section names — for instance, "〈 Scan the input 23 〉" — letting the programmer define code where it is discussed rather than where it must appear.

Applications and influence

Knuth wrote TeX itself as a literate program, published in book form as TeX: The Program. The concept influenced later tools such as noweb, FunnelWeb, and org-mode/Babel workflows, and survives in spirit in computational notebooks like Jupyter, which likewise interleave prose, code and output — though notebooks typically keep the compiler's order rather than the essay's.

"Let us change our traditional attitude to the construction of programs: Instead of imagining that our main task is to instruct a computer what to do, let us concentrate rather on explaining to human beings what we want a computer to do." — Donald Knuth
