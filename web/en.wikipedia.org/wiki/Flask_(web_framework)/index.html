Flask (web framework)

Flask is a micro web framework written in Python. It is classified as a microframework because it does not require particular tools or libraries and has no database abstraction layer, form validation, or other components where pre-existing third-party libraries provide common functions. Flask was created by Armin Ronacher of the Pallets project and first released in 2010.

Features

Flask is based on the Werkzeug WSGI toolkit and the Jinja templating engine. It supports extensions for ORM, form validation, authentication, and other features, and includes a built-in development server and debugger. Applications are commonly structured around routes declared with decorators.

Popularity

Flask is one of the most popular Python web frameworks, widely used for APIs, prototypes, and production sites; it has been used by companies including Pinterest and LinkedIn for parts of their services. It is released under a BSD licence.
