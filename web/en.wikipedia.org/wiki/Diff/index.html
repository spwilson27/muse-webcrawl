diff

diff is a file comparison utility for Unix and Unix-like operating systems that outputs the differences between the contents of two computer files. It compares files line by line and is typically used to show the changes between two versions of the same file, making it a foundational tool for software developers. The output of diff is called a "diff", or a "patch", since the output can be applied with the Unix program patch.

History

The diff utility was developed in the early 1970s on the Unix operating system, which was emerging from Bell Labs. The final version, first shipped with the 5th Edition of Unix in 1974, was written entirely by Douglas McIlroy. The algorithm at its heart derives from the work on the longest common subsequence problem, refined in the Hunt–Szymanski algorithm and later by Eugene Myers's widely used O(ND) algorithm.

Usage

Invoked from the command line, diff takes two file names as arguments:

$ diff original_file new_file

Common options include -u for unified format, -c for context format, -r for recursive directory comparison, and -i to ignore case differences.

Output formats

Normal format

The default output uses commands such as a (add), d (delete), and c (change) with line ranges, for example 2,4c2,3.

Context format

Developed at the University of California, Berkeley, the context format shows changed lines surrounded by unchanged "context" lines, marked with !, while additions and deletions use + and -.

Unified format

The unified format, created by Wayne Davison in 1990 for GNU diff, combines context into a single hunk headed by @@ -l,s +l,s @@ and is the format most commonly seen in patches and in version control systems such as Git.
