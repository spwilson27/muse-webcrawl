Dynamic array

In computer science, a dynamic array, growable array, resizable array, dynamic table, mutable array, or array list is a random access, variable-size list data structure that allows elements to be added or removed. It overcomes the fixed-size limitation of static arrays by maintaining spare capacity in an underlying fixed array.

Implementation

A dynamic array stores its elements in a contiguous block of memory of a certain capacity, together with a count of the elements actually in use (its size). Appending an element normally just writes into the next free slot. When the array is full, a new, larger block is allocated — commonly twice the size — the elements are copied across, and the old block is freed. Geometric expansion ensures that although a single append occasionally costs linear time, the amortised cost of appending remains constant.

Shrinking is handled symmetrically: to avoid rapid alternation between growing and shrinking ("thrashing"), implementations typically shrink the underlying array only when the load factor falls well below the growth threshold.

Language support

Dynamic arrays are provided as std::vector in C++, ArrayList in Java, List<T> in C#, the built-in list type in Python, and arrays in languages such as JavaScript and Ruby. Bounds checking, iterators and generic element types are usually built in.

Performance

Random access and appends are O(1) (amortised for appends), insertion or deletion in the middle costs O(n) because elements must be shifted, and searching an unsorted dynamic array costs O(n). Dynamic arrays have good cache locality but may waste up to half their allocated capacity.
