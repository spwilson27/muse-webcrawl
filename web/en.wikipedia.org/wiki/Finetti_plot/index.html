Finetti plot

A Finetti plot is a graphical representation of the genetic structure of a population in terms of genotype frequencies, used in population genetics. It is named after the Italian statistician Bruno de Finetti.

Description

The plot uses values such as the fixation index (FST) and heterozygosity plotted against allele frequencies, with points positioned inside a bounded region whose edges correspond to extreme cases of allele fixation. Populations in Hardy–Weinberg equilibrium fall along a parabolic curve across the plot.

Use

Finetti plots are used to visualise departures from Hardy–Weinberg equilibrium, helping researchers detect inbreeding, selection, or population stratification in genetic data.
