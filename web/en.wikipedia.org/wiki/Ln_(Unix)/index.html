ln (Unix)

The ln command is a standard Unix command used to create links to files. It can create both hard links, which are additional directory entries pointing to the same inode, and symbolic links (symlinks or soft links), which are special files containing a pathname reference to another file. ln is part of the GNU Core Utilities on Linux and is specified by POSIX.

Usage

ln [OPTION]... [-T] TARGET LINK_NAME
ln [OPTION]... TARGET
ln [OPTION]... TARGET... DIRECTORY
ln [OPTION]... -t DIRECTORY TARGET...

By default, ln creates hard links. The most common option is:

  • -s, --symbolic — create symbolic links instead of hard links.
  • -f, --force — remove existing destination files.
  • -i, --interactive — prompt whether to remove destinations.
  • -n, --no-dereference — treat a symlink to a directory as if it were a file.
  • -v, --verbose — print the name of each linked file.
  • -r, --relative — create symbolic links relative to the link location (GNU extension).

Hard vs. symbolic links

A hard link shares the target's inode: the data remains available as long as at least one link exists, and hard links generally cannot cross filesystems or refer to directories. A symbolic link is a separate file storing a path; it can cross filesystems and point to directories, but becomes "dangling" if its target is removed.

Examples

$ ln -s /usr/share/doc/example.txt ~/example-link
$ ln file1 file2        # hard link: file2 is another name for file1

History

ln appeared in early versions of Unix (present by Version 1 AT&T Unix, 1971). Symbolic links were introduced with 4.2BSD in 1983. The behavior of ln is standardized in the POSIX specification.
