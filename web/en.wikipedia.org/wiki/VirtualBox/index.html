Oracle VirtualBox (formerly Sun VirtualBox, Sun xVM VirtualBox and Innotek VirtualBox) is a hosted hypervisor for x86 and ARM virtualization developed by Oracle Corporation. VirtualBox was originally created by Innotek GmbH, which was acquired by Sun Microsystems in 2008, which was in turn acquired by Oracle in 2010. It is installed on an existing host operating system as an application; within this application, additional operating systems, each known as a Guest OS, can be loaded and run, each with its own virtual environment.

Features

VirtualBox supports the creation and management of guest virtual machines running Windows, Linux, BSD, OS/2, Solaris, Haiku, macOS, and others. It emulates or virtualizes a standard PC environment, including a virtual hard disk (VDI and other formats), network adapters, sound card, and USB controllers. Features include snapshots, cloned VMs, seamless windows mode, shared folders and clipboard with Guest Additions installed, remote display via RDP, and a command-line interface (VBoxManage) and APIs for automation. On hosts with hardware virtualization support (Intel VT-x and AMD-V), VirtualBox runs guest code natively for near-native performance; VirtualBox 6.1 and later require a 64-bit host CPU with hardware virtualization.

Licensing

The core VirtualBox package is free and open-source software released under the GNU General Public License (version 3 since VirtualBox 7). The separate Extension Pack, containing features such as USB 2.0/3.0 device support, RDP server, disk encryption, and NVMe support, is distributed under the proprietary VirtualBox Personal Use and Evaluation License (PUEL), free for personal use but requiring a commercial license in business settings.

History

Innotek, a German software company, released VirtualBox in early 2007, offering both a proprietary and an open-source edition. Sun Microsystems acquired Innotek in February 2008; after Oracle's acquisition of Sun in 2010, the product became Oracle VM VirtualBox. Subsequent releases added features such as support for macOS hosts on Apple silicon (in developer preview from version 7.x), improved graphics, and cloud integration with Oracle Cloud Infrastructure.
