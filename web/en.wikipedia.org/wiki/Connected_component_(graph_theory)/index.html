Field: Graph theory

Connected component (graph theory)

In graph theory, a connected component of an undirected graph is a maximal subgraph in which any two vertices are connected to each other by paths, and which is connected to no additional vertices in the rest of the graph. A graph that has exactly one connected component is called a connected graph.

Algorithms

The connected components of a graph can be found in linear time using depth-first search or breadth-first search: vertices are repeatedly explored from unvisited starting points, and each completed search yields one component. The same decomposition underlies union–find data structures used in image processing and network analysis.

Directed graphs

For directed graphs the analogous notions are strongly connected components — maximal subgraphs in which every vertex reaches every other — and weakly connected components, obtained by ignoring edge directions. Strong components can be found with Kosaraju's or Tarjan's algorithms, both linear-time.

Applications

Component analysis is used to segment images, identify communities in networks, and verify connectivity of circuits and road systems, wherever structure separates into independent parts.
