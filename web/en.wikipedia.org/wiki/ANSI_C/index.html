Successor: C99

ANSI C, ISO C and Standard C are successive standards for the C programming language published by ANSI, ISO and IEC. Historically, the names referred specifically to the original and best-supported version of the standard, published in 1989 and known as C89.

History

The first standard for C was published by ANSI in 1989, document ANSI X3.159-1989, Programming Language C. This was adopted by ISO in 1990 as ISO/IEC 9899:1990, known as C90. The terms ANSI C and C89 usually refer to this standard.

Features

ANSI C standardized function prototypes, void pointers, international character sets, and a standard library. It formalized the language as described in Kernighan and Ritchie's The C Programming Language, second edition.
