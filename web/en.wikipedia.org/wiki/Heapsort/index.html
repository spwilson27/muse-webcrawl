Heapsort

Heapsort is a comparison-based sorting algorithm that uses a binary heap data structure. It was invented by J. W. J. Williams in 1964, the same year he published the heap structure; Robert W. Floyd published an improved in-place version the same year.

Algorithm

Heapsort can be divided into two phases. In the first phase, the input array is rearranged in place into a max heap ("heapified"), which takes linear time. In the second phase, the largest element — at the root of the heap — is repeatedly swapped to the end of the unsorted region and the heap property is restored on the shrinking remainder, until the whole array is sorted.

Complexity

Heapsort runs in O(n log n) time in the best, average and worst cases, and requires only O(1) additional space because it operates in place. It is, however, not a stable sort, and in practice it is often slower than a well-implemented quicksort because of poorer cache locality, despite quicksort's worse worst-case bound. A hybrid algorithm, introsort, begins with quicksort and switches to heapsort when recursion depth exceeds a threshold, combining the speed of quicksort with heapsort's guaranteed worst-case performance.

Variants

Variants include Floyd's bottom-up heap construction improvement, the smoothsort algorithm of Edsger Dijkstra (which adapts to nearly-sorted input), and weak heapsort. Ternary and d-ary heaps can also be used to reduce the number of comparisons.
