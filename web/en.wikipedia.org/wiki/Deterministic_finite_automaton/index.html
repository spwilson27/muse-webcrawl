In the theory of computation, a branch of theoretical computer science, a deterministic finite automaton (DFA) — also known as deterministic finite acceptor (DFA), deterministic finite-state machine (DFSM), or deterministic finite-state automaton (DFSA) — is a finite-state machine that accepts or rejects a given string of symbols by running through a state sequence uniquely determined by the string.

Deterministic refers to the uniqueness of the computation: in each state, each possible input symbol has exactly one transition. DFAs recognize exactly the regular languages, and every nondeterministic finite automaton can be converted into an equivalent DFA by the powerset construction, at the cost of a possible exponential increase in states.

Formal definition

A DFA is a 5-tuple (Q, Σ, δ, q0, F) consisting of a finite set of states Q; a finite set of input symbols Σ (the alphabet); a transition function δ : Q × Σ → Q; a start state q0 ∈ Q; and a set of accepting states F ⊆ Q. The machine reads the input string symbol by symbol, following δ, and accepts exactly when it ends in a state of F. The language of the machine is the set of strings it accepts.

Example

A two-state DFA over the alphabet {0, 1} can accept the binary strings with an even number of 0s: the states record parity, each 0 flips the state, each 1 leaves it unchanged, and the start state (representing "even so far") is accepting.

Closure properties

The regular languages are closed under union, intersection, complement, concatenation, and Kleene star; each operation has a corresponding construction on DFAs (for complement, simply swapping accepting and non-accepting states). Emptiness and equivalence of DFAs are decidable, and equivalence is tested by minimizing both machines and comparing them.

Minimization

Every DFA has a unique minimal-state equivalent DFA (up to isomorphism), whose states correspond to the equivalence classes of the Myhill–Nerode relation. Hopcroft's algorithm computes it in O(n log n) time; Brzozowski's algorithm achieves minimization by reversing and determinizing twice.

Applications

DFAs underlie lexical analysis in compilers, regular-expression matching, protocol and circuit verification, text search, and the control logic of simple devices such as vending machines and traffic lights.
