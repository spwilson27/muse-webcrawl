Metasploit

The Metasploit Project is a computer security project that provides information about security vulnerabilities and aids in penetration testing and IDS signature development. It is owned by the Boston, Massachusetts–based security company Rapid7.

Its best-known sub-project is the open-source Metasploit Framework, a tool for developing and executing exploit code against a remote target machine. Other important sub-projects include the Opcode Database, shellcode archive, and related research.

History

Metasploit was created by H. D. Moore in 2003 as a portable network tool using the Perl language. It was subsequently rewritten in Ruby. On October 21, 2009, the Metasploit Project announced that it had been acquired by Rapid7, a security company that provides unified vulnerability management solutions.

The Framework

The Metasploit Framework is a modular platform written in Ruby, organized around exploits, payloads, encoders, auxiliary modules, and post-exploitation modules. Its console interface, msfconsole, allows a tester to scan targets, select and configure an exploit, choose a payload (such as the Meterpreter advanced payload, which provides an in-memory command shell and post-exploitation features), and execute an attack. Commercial editions developed by Rapid7 include Metasploit Pro, with additional features for penetration-testing teams. The framework ships as a standard component of Kali Linux.

Editions

  • Metasploit Framework — the free, open-source edition (BSD license).
  • Metasploit Pro — the commercial edition for penetration testers, adding campaign management, reporting, and automation features.
  • Former editions included Metasploit Express and Metasploit Community.
