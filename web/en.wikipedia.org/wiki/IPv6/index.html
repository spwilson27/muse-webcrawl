IPv6

From Wikipedia, the free encyclopedia
IPv6
Address size128 bits
StandardRFC 2460 (1998); RFC 8200 (2017)
NotationHexadecimal groups, e.g. 2001:db8::1
Developed byIETF
[Image: Diagram of the IPv6 packet header, showing version, traffic class, flow label, payload length, next header, hop limit and the 128-bit source and destination addresses]

Internet Protocol version 6 (IPv6) is the most recent version of the Internet Protocol, the communications protocol that provides identification and location for computers on networks and routes traffic across the Internet. It was developed by the Internet Engineering Task Force to succeed IPv4 and deal with the long-anticipated problem of IPv4 address exhaustion.

IPv6 addresses are 128 bits long, giving roughly 3.4 × 10^38 possible addresses — enough, in the usual phrase, for every atom on Earth to have many addresses each. They are written as eight groups of four hexadecimal digits separated by colons; leading zeros can be dropped and one run of zero groups can be compressed to '::', so the documentation example 2001:0db8:0000:0000:0000:ff00:0042:8329 becomes 2001:db8::ff00:42:8329.

Design changes

Beyond the address space, IPv6 simplifies the packet header, drops the header checksum so routers work faster, replaces broadcast with multicast, and makes autoconfiguration a standard feature: a device can generate its own address (SLAAC) without a DHCP server. Extension headers carry optional information, and the flow label supports quality-of-service handling. Network address translation is generally unnecessary, restoring the original end-to-end model of the Internet.

Deployment

World IPv6 Day in 2011 and the World IPv6 Launch in 2012 marked the start of permanent deployment by large providers. Adoption has climbed steadily since: mobile networks in several countries are majority-IPv6, and global usage measured by large content providers passed roughly a third of users in the early 2020s and continues to grow, though IPv4 remains widespread through dual-stack operation.
