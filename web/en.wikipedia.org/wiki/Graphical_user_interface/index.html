Graphical user interface

A typical desktop GUI, showing windows, icons, menus and a pointing device (the WIMP paradigm).

A graphical user interface (GUI) is a form of user interface that allows users to interact with electronic devices through graphical icons and visual indicators such as secondary notation, instead of text-based user interfaces, typed command labels or text navigation. In a GUI, information and actions are usually presented through graphical elements including windows, icons, menus and pointers — collectively known as the WIMP paradigm.

GUIs were introduced in reaction to the perceived steep learning curve of command-line interfaces (CLIs), which require commands to be typed on a computer keyboard. They are now the dominant interface style for personal computers, smartphones and most consumer electronics.

History

Precursors

Ivan Sutherland's Sketchpad (1963) demonstrated interactive computer graphics. At SRI International, Douglas Engelbart and colleagues developed the oN-Line System (NLS), featuring the mouse, hypertext and multiple windows, famously demonstrated in the 1968 "Mother of All Demos".

Xerox PARC

At Xerox PARC in the 1970s, researchers led by Alan Kay built the Alto, a personal computer with a bitmapped display, overlapping windows, icons, menus and a mouse, programmed in Smalltalk. The Alto's interface drew on the desktop metaphor and Kay's Dynabook concept of a computer for learning and creativity. In 1981 Xerox commercialised these ideas in the Xerox Star (8010), the first commercial system to integrate the now-standard GUI features.

Popularisation

Steve Jobs's visits to PARC in 1979 inspired Apple's Lisa (1983) and, more successfully, the Macintosh (1984), which brought the GUI to a mass market with its menu bar, trash can, drag-and-drop and consistent application design. Microsoft responded with Windows (1985), which became dominant with Windows 3.0 (1990) and Windows 95. The X Window System (1984) provided GUIs for Unix workstations, and desktop environments such as GNOME and KDE later brought them to Linux.

Mobile and beyond

The iPhone (2007) popularised multi-touch GUIs, replacing the pointer with direct finger manipulation, pinching and swiping. Subsequent interface styles — voice interfaces, augmented and virtual reality, and so-called post-WIMP interfaces — extend the GUI beyond the desktop metaphor.

Elements

  • Windows — rectangular regions presenting an application's content.
  • Icons — small pictograms representing files, applications or actions.
  • Menus — lists of commands, including menu bars, context menus and pie menus.
  • Widgets — buttons, check boxes, sliders, scroll bars, tabs and text fields.
  • Pointer — a cursor moved by a mouse, trackpad or other pointing device.
  • Desktop — the background workspace on which windows appear.

Design and usability

GUI design draws on human–computer interaction research. Principles include visibility of system status, consistency, feedback, affordances, error prevention and recognition rather than recall. Pioneering usability guidelines were published by Apple and Microsoft, and researchers such as Jakob Nielsen developed heuristic evaluation methods. Critics have argued that GUIs can be less efficient than command lines for expert users and repetitive tasks, which is why many systems retain both.
