ARM big.LITTLE

ARM big.LITTLE
TypeHeterogeneous computing architecture
DeveloperARM Holdings
AnnouncedOctober 2011
SuccessorDynamIQ

ARM big.LITTLE is a heterogeneous computing architecture developed by ARM Holdings, coupling relatively battery-saving and slower processor cores (LITTLE) with relatively more powerful and power-hungry ones (big). Typically, only one "side" or the other will be active at once, but all cores have access to the same memory regions, so workloads can be swapped between big and LITTLE cores on the fly.

Design

The intention is to create a multi-core processor that can adjust better to dynamic computing needs and use less power than clock scaling alone. ARM's marketing material promised up to a 75% savings in power usage for some activities. The design allows cores of different performance and power characteristics to be combined in a single system on a chip, with the operating system scheduler assigning tasks to the most appropriate core.

Run-state migration

There are three ways for the different processor cores to be arranged in a big.LITTLE design, depending on the scheduling algorithms implemented in the kernel: cluster migration, in-kernel switcher (CPU migration), and global task scheduling. Global task scheduling is the most flexible model, allowing the scheduler to use all cores simultaneously.

Successor

In May 2017, ARM announced DynamIQ as the successor to big.LITTLE, offering greater flexibility in core configurations within a cluster.
