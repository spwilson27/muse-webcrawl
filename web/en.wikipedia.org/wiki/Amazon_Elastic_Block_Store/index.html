Amazon Elastic Block Store

Amazon EBS
Developer: Amazon Web Services
Type: Block storage service

Amazon Elastic Block Store (Amazon EBS) is a high-performance block storage service offered by Amazon Web Services, designed for use with Amazon Elastic Compute Cloud (EC2) instances. EBS volumes behave like raw, unformatted block devices that can be attached to instances, formatted with a file system, and used for persistent storage that survives independent of the lifetime of an instance.

Volume types

EBS offers solid-state-drive-backed volumes (general purpose gp2/gp3 and provisioned IOPS io1/io2) for transactional workloads, and hard-disk-drive-backed volumes (Throughput Optimized HDD and Cold HDD) for large, sequential workloads. Volumes are automatically replicated within their Availability Zone to protect against component failure.

Snapshots

Users can create point-in-time snapshots of volumes, which are stored incrementally in Amazon S3 and can be used to create new volumes or copy data across regions. EBS also supports encryption at rest using AWS Key Management Service keys.
