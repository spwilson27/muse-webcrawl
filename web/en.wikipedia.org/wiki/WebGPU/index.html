WebGPU

DeveloperW3C GPU for the Web Community Group
Initial releaseApril 2023 (Chrome 113)
TypeGraphics and compute API
Shading languageWGSL

WebGPU is a JavaScript API provided by a web browser that enables webpage scripts to efficiently use a device's graphics processing unit (GPU). It is developed by the W3C GPU for the Web Community Group, with engineers from Apple, Google, Microsoft, Mozilla, and Intel participating. WebGPU is designed as the successor to WebGL, offering access to modern GPU capabilities modeled on native APIs such as Vulkan, Metal, and Direct3D 12.

Features

Unlike WebGL, which exposes an OpenGL-like state machine, WebGPU uses explicit render pipelines, command encoders, and bind groups, reducing driver overhead and allowing work to be prepared on multiple threads. It also provides first-class support for general-purpose GPU computing (GPGPU) through compute shaders, making it suitable for machine learning inference and physics simulation in the browser. Shaders are written in WGSL (WebGPU Shading Language), a language designed for safety and for translation to platform shader languages.

Availability

Google shipped WebGPU by default in Chrome 113 in April 2023 on Windows, macOS, and ChromeOS, with other platforms following. Implementations in Firefox and Safari proceeded through the mid-2020s, with Safari shipping support in 2025. Libraries such as Three.js and Babylon.js added WebGPU renderers, and frameworks use it to accelerate in-browser AI workloads via runtimes like ONNX Runtime Web and WebLLM.
