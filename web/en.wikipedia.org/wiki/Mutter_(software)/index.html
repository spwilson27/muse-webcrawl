Mutter is a window manager and Wayland compositor originally created for the GNOME desktop environment. Its name is a portmanteau of "Metacity" and "Clutter," the toolkit on which it was originally based.

Role in GNOME

Mutter manages window placement, compositing, and input for GNOME Shell, which runs as a Mutter plugin. On Wayland sessions it acts as the display server and compositor; on X11 it functions as a compositing window manager.

Features

Mutter supports fractional scaling, multi-monitor configurations, and — since version 40 and later releases — improved touchpad gestures and variable refresh rate support. It is written primarily in C.
