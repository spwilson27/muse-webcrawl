Virtual ground

In electronics, a virtual ground (or virtual earth) is a node in a circuit that is maintained at a steady reference potential, without being directly connected to the reference potential. The concept is central to the analysis of operational amplifier circuits with negative feedback.

Principle

In an ideal op-amp with negative feedback, the output adjusts so that the voltage difference between the two inputs is driven to (nearly) zero. If the non-inverting input is grounded, the inverting input therefore also sits at approximately ground potential, even though no current flows into the op-amp input and the node is not galvanically connected to ground. Because input current is negligible, all current from an input source flows through the feedback element — the basis of inverting amplifiers, transimpedance amplifiers, and integrators.

Applications and limits

Virtual grounds are exploited in current-to-voltage converters (such as photodiode amplifiers), inverting summing amplifiers, and active filters. In practice the approximation degrades with finite open-loop gain, limited bandwidth, and output saturation, so precision circuits must account for small residual errors.
