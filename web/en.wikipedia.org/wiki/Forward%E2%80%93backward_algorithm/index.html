Forward–backward algorithm

ClassDynamic programming algorithm
Used forInference in hidden Markov models
RelatedBaum–Welch algorithm, Viterbi algorithm

The forward–backward algorithm is an inference algorithm for hidden Markov models which computes the posterior marginals of all hidden state variables given a sequence of observations. The algorithm makes use of the principle of dynamic programming and has two passes: a forward pass, which computes a set of "forward probabilities" summarizing the probability of the observations up to each point in time, and a backward pass, which computes "backward probabilities" for the observations following each point.

Overview

By multiplying the forward and backward probabilities for each state at each time step and normalizing, one obtains the smoothed probability of being in that state given the entire observation sequence. This smoothing problem is one of the three canonical problems of hidden Markov models, alongside filtering and most-likely-sequence decoding.

Applications

The forward–backward algorithm is a core part of the Baum–Welch algorithm for training hidden Markov models, and it has been applied in speech recognition, bioinformatics (including gene prediction and sequence alignment), and computational linguistics.

Complexity

For a model with N states and a sequence of length T, the algorithm runs in O(N²T) time, a dramatic improvement over the exponential cost of enumerating all state sequences.
