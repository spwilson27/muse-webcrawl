Correlated equilibrium

[Image placeholder: traffic light as correlating device]

In game theory, a correlated equilibrium is a solution concept that is more general than the well-known Nash equilibrium. It was first introduced by the mathematician Robert Aumann in 1974. The idea is that each player chooses their action according to a private signal they receive from a common randomising device — a correlation device — which recommends actions to the players. If no player would gain by disobeying their recommendation, assuming the others obey theirs, the resulting distribution over action profiles is a correlated equilibrium.

A simple example is the game of chicken, in which two drivers head towards each other. A traffic light that shows green to one driver and red to the other, choosing at random which, coordinates behaviour: following the signal is optimal for both, and the average payoff exceeds that of the symmetric mixed-strategy Nash equilibrium, because the dangerous outcome in which both drive on is avoided.

Formal definition

Formally, a probability distribution over the set of action profiles is a correlated equilibrium if, for every player and for every pair of actions that the player might be recommended and might deviate to, the expected payoff from following the recommendation (conditioned on receiving it) is at least as great as the expected payoff from deviating. Every Nash equilibrium is a correlated equilibrium, but the set of correlated equilibria is a convex polytope that is generally strictly larger, and it can be computed efficiently by linear programming — a notable contrast with the computational difficulty of finding Nash equilibria.

Learning

Correlated equilibria arise naturally from simple learning dynamics: if players repeatedly play a game and each uses a no-regret strategy (such as multiplicative weights), the empirical distribution of play converges to the set of (coarse) correlated equilibria.
