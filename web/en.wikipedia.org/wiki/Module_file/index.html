Module file

TypeMusic file format family
ContentsInstrument samples plus note patterns (sequence data)
Common extensions.mod, .xm, .it, .s3m
Associated softwareMusic trackers (ProTracker, FastTracker II, Impulse Tracker, OpenMPT)

A module file is a family of computer music file formats originating on the Commodore Amiga in the late 1980s. A module stores both the digital audio samples used as instruments and a compact description of how those samples are to be played — notes, effects and their arrangement into patterns and an order list — so that playback software, called a tracker, can reconstruct the song in real time. Because the music is described rather than recorded, module files are extremely small compared with recorded audio of the same length, typically a few hundred kilobytes for several minutes of music.

Structure

The original format, introduced by Karsten Obarski's Ultimate Soundtracker (1987) and standardised by ProTracker, is the MOD format: up to 31 samples and four channels of pattern data, each pattern having 64 rows. Successors extended the idea: Scream Tracker 3 produced S3M files with more channels and instruments; FastTracker II's XM format added 16-bit samples, instrument envelopes and up to 64 channels; Impulse Tracker's IT format added filters, new-note actions and compressed samples. Later formats such as MPTM (OpenMPT) continued the line. Patterns are arranged in a playlist (the "order list"), and playback sweeps through them row by row at a set tempo, applying effects such as vibrato, portamento, arpeggio and sample offset.

History and culture

Modules became the standard music format of the Amiga and PC demoscene, where musicians exchanged files through BBSes, diskmags and scene archives. Trackers were both composition tools and a subculture: composers crafted elaborate music within tight memory limits, and the format's openness — samples and patterns are visible and editable — made remixing and learning from others' files easy. Module music scored countless demos, intros and early shareware games; the game Unreal and Deus Ex famously used tracker music (UMX). Large public archives such as The Mod Archive preserve hundreds of thousands of modules, and modern trackers like OpenMPT, Renoise (which imports modules) and MilkyTracker keep the format in use.

Playback

Playing a module requires resampling each triggered sample to the note's pitch and mixing channels; accuracy varies between players, historically making the composing tracker the reference. Libraries such as libopenmpt and players like XMPlay provide high-quality playback across platforms.
