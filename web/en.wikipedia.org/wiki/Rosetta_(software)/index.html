Rosetta (software)

DeveloperApple Inc.
Initial release2006 (Rosetta); 2020 (Rosetta 2)
Operating systemmacOS
TypeBinary translation / emulator layer

Rosetta is a dynamic binary translator developed by Apple Inc. for macOS, designed to allow applications built for one processor architecture to run on Macintosh computers using a different architecture. It has been released twice: the original Rosetta in 2006 supported the transition from PowerPC processors to Intel x86 processors, and Rosetta 2 in 2020 supported the transition from Intel processors to Apple silicon (ARM64).

Original Rosetta (2006)

When Apple announced at the Worldwide Developers Conference in June 2005 that the Macintosh would move from PowerPC to Intel processors, it introduced Rosetta as the translation layer that would let most existing PowerPC applications run, unmodified, on the new Intel-based Macs. Rosetta shipped with Mac OS X 10.4.4 "Tiger" in January 2006 alongside the first Intel iMac and MacBook Pro.

The technology was based on the QuickTransit software of Transitive Corporation. Unlike the earlier 68k emulator used during the 1990s transition, Rosetta translated PowerPC code to x86 code at runtime, caching the translated blocks. It supported most applications written for Mac OS X on PowerPC, but not Classic (Mac OS 9) applications, code requiring a PowerPC G5, or kernel extensions. Performance was generally adequate for productivity software but noticeably slower than native code, and Apple presented Rosetta as a stopgap while developers shipped Universal binaries.

Rosetta became an optional install in Mac OS X 10.6 "Snow Leopard" (2009) and was removed entirely in Mac OS X 10.7 "Lion" (2011), ending support for PowerPC applications.

Rosetta 2 (2020)

At WWDC in June 2020 Apple announced a second transition, from Intel x86-64 to its own ARM-based Apple silicon, beginning with the M1 chip. Rosetta 2 translates x86-64 application binaries so they can run on Apple silicon Macs. In addition to just-in-time translation at runtime, Rosetta 2 can translate an application ahead of time, at installation, producing an optimized ARM64 version of much of the code.

Translated applications often perform surprisingly well because of the speed of Apple silicon, though software that relies on newer x86 vector instructions (such as AVX-512) or just-in-time compilers of its own may not work. Rosetta 2 does not translate kernel extensions or virtual-machine software that virtualizes x86-64 platforms. It is installed automatically the first time a user launches an Intel-only application on an Apple silicon Mac.

With Rosetta 2 and the Universal 2 binary format, Apple repeated the pattern of its earlier transitions: emulation first, native binaries as developers recompiled their software.
