In mathematics, a generating function is a representation of an infinite sequence of numbers as the coefficients of a formal power series. Since different techniques are useful for different types of sequences, the term covers several kinds, of which the most common is the ordinary generating function. Generating functions were first introduced by Abraham de Moivre in 1730 to solve recurrence problems.

Ordinary generating functions

The ordinary generating function of a sequence a0, a1, a2, ... is G(x) = a0 + a1x + a2x2 + ... . For example, the Fibonacci numbers have the rational generating function x / (1 − x − x2), from which Binet's closed formula can be derived by partial fractions. Operations on sequences — shifting, convolution, partial sums — correspond to simple algebraic operations on their generating functions.

Other types

The exponential generating function divides the n-th coefficient by n! and is adapted to labelled combinatorial structures. Dirichlet generating functions use terms an/ns and connect to number theory; in probability, the probability generating function and moment-generating function play analogous roles.

Applications

Generating functions are a central tool of combinatorics and analytic combinatorics, used to count partitions (Euler), solve linear recurrences, analyse algorithms, and study random variables.
