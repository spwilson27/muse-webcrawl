Screen recorder

A screen recorder is a software program or built-in operating-system feature that captures the contents of a computer or mobile device display — and often accompanying audio — as a video file. Screen recorders are widely used to produce screencasts, tutorial and training videos, software demonstrations, technical-support evidence, lecture captures, and recordings of video game play and video calls.

Operation

Screen recording software intercepts the framebuffer or uses operating-system capture APIs (such as the Windows Graphics Capture API, macOS ScreenCaptureKit, or pipewire-based capture on Linux) to sample screen images many times per second, compressing them with codecs such as H.264, H.265 or AV1. Typical options include recording the full display, a single window, or a selected region; capturing system audio and microphone input; showing or hiding the mouse cursor and highlighting clicks; webcam picture-in-picture overlay; and annotation tools for drawing on screen while recording.

Common tools

Well-known screen recorders include OBS Studio (free, open-source, and also used for streaming), Camtasia, ShareX, Bandicam, Snagit, and Loom for web-based recording and sharing. Modern operating systems include built-in options: the Xbox Game Bar on Windows, the Screenshot/QuickTime tooling on macOS, and native screen recording on iOS (since iOS 11) and Android devices. Browser-based recorders use the WebRTC getDisplayMedia API to capture a tab, window or screen without installed software.

Considerations

Screen recording can be performance-intensive, particularly at high resolutions and frame rates; hardware-accelerated encoding (NVENC, Quick Sync, VideoToolbox) greatly reduces CPU load. Recorded files can be large, so resolution, frame rate and bit rate are commonly traded off against file size. Legal and ethical issues arise when recording copyrighted streams — many streaming services employ DRM and HDCP that blank the video in recordings — or when recording other people in calls, which in some jurisdictions requires consent.
