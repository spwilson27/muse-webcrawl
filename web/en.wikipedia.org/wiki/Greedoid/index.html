Greedoid

In combinatorics, a greedoid is a set system that generalizes the concept of a matroid by relaxing the requirement that feasible sets be closed under taking subsets. Greedoids model situations in which a greedy algorithm can be used to search feasibly through a set of objects built up one element at a time. They were introduced by Bernhard Korte and László Lovász in the early 1980s.

Definition

A greedoid is a pair (E, F) where E is a finite ground set and F is a nonempty family of subsets of E, called feasible sets, satisfying the augmentation property: if X, Y are feasible and |X| > |Y|, then there exists an element x in X \ Y such that Y ∪ {x} is feasible. Every matroid's independent sets form a greedoid.

Language formulation

Equivalently, a greedoid can be described by a set of feasible words (orderings) closed under taking prefixes and satisfying an exchange property. This formulation captures examples where order matters, such as feasible search orderings: vertex search orderings of graphs (breadth-first and depth-first search give graph search greedoids), elimination orderings, and the feasible sequences for posets.

Greedy algorithms

The name reflects the theory of greedy algorithms: on a greedoid, a greedy procedure that builds a feasible set step by step, always adding the best available element, optimizes any objective function that is compatible with the greedoid structure (roughly, functions whose local optima along feasible continuations behave consistently). This extends the classical result that greedy algorithms optimize linear functions over matroids. Examples include antimatroids (which model precedence-constrained scheduling), interval greedoids, and Gaussian greedoids.
