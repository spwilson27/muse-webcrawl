Gittins index

The Gittins index is a measure associated with each state of a stochastic process, used to solve the multi-armed bandit problem. Introduced by John C. Gittins in the 1970s, the index provides an optimal policy for choosing which of several uncertain projects ("bandit arms") to work on at each step so as to maximize discounted expected reward.

Definition and theorem

In the classical bandit problem, a decision-maker faces several independent Markov processes, each in a known state. At each time step exactly one process is advanced, yielding a reward that depends on its state and on chance; the others remain frozen. All future rewards are discounted. The Gittins index theorem states that an optimal policy is an index policy: compute for each process, based only on its own current state, a real number — its Gittins index — and always advance the process with the largest index.

The index for a state can be characterized as the "fair charge" or retirement value that makes a decision-maker indifferent between continuing the process and stopping to receive that value with certainty. It balances the expected immediate reward of an arm against the information and future rewards that further trials may bring, elegantly resolving the exploration–exploitation trade-off.

Applications

Gittins index policies are used in clinical trial design, research and development project selection, job scheduling on machines, sensor management, and adaptive routing. For problems where the index cannot be computed exactly, approximation schemes such as the Whittle index for restless bandits extend the idea to settings where unplayed processes also evolve.
