Box Drawing

Box Drawing is a Unicode block containing line and double-line characters used for drawing boxes, tables, and simple diagrams in text. It spans the code points U+2500 to U+257F and includes horizontal and vertical lines in light, heavy, double, dashed, and arc forms, along with corners, tees, and crosses.

Use

Box-drawing characters originated in early text-mode displays and code pages, where they allowed program interfaces, menus, and charts to be drawn on character-cell terminals. They remain common in console applications, ASCII art, terminal user interfaces, and plain-text tables compiled in README files and source code comments. Together with the related Block Elements block, they permit simple graphics robust to monospaced fonts.

Characters

Examples include the light horizontal ─ (U+2500), light vertical │ (U+2502), corners such as ┌ ┐ └ ┘, junctions ┼ ├ ┤, and double-line forms ═ ║ ╔ ╗ used for emphasis frames. Mixing weights in one diagram is common in command-line interfaces.
