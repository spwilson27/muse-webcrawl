Open 3D Engine (O3DE) is a free and open-source 3D game engine developed by the Open 3D Foundation, a subsidiary of the Linux Foundation. It was initially developed by Amazon as a successor to Amazon Lumberyard, itself a fork of CryEngine.

History

On July 6, 2021, the Linux Foundation announced the formation of the Open 3D Foundation and the release of Open 3D Engine as an open-source project under the Apache 2.0 license. Amazon contributed the engine, derived from its Lumberyard engine, as the founding project. Other founding members included Adobe, Huawei, Intel, Niantic, and Red Hat.

The first stable release, version 21.11, was released in December 2021. Subsequent releases have added improved rendering, networking, and editor features.

Features

O3DE provides a modular "Gem" system allowing developers to enable or disable features as needed, a physically based renderer (Atom), a visual scripting system (Script Canvas), Lua and Python scripting support, and a multiplayer framework. It supports development for Windows, Linux, macOS, Android, and iOS platforms.
