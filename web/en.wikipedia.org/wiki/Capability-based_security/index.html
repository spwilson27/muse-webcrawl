Capability-based security

Capability-based security is a concept in computer security in which a capability is an unforgeable token that both designates a resource (such as a file, object or service) and carries the rights to access it. Possession of the capability is sufficient to exercise those rights, following the principle of least authority.

Capabilities vs ACLs

This contrasts with access control lists (ACLs), where a resource checks the identity of the requester against a list. Capability systems avoid "ambient authority" — privileges a program has merely because of who is running it — and thereby resist confused-deputy attacks, because a program can only use the specific capabilities it is given and can delegate subsets of them explicitly.

Implementations

Historical capability machines and operating systems include the Cambridge CAP computer, KeyKOS, EROS and its successor Coyotos, and the seL4 microkernel with capability-based access control. Object-capability languages such as E, and modern designs including FreeBSD's Capsicum sandboxing and CHERI capability hardware, draw on the same ideas. Unguessable web URLs (bearer tokens) are an informal analogue.
