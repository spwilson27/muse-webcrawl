Clingo

Clingo is an answer set solver for logic programming. It combines the grounder gringo with the solver clasp and was developed at the University of Potsdam as part of the Potassco project (the Potsdam Answer Set Solving Collection).

Description

Clingo takes a logic program written in the language of answer set programming (ASP), grounds it — replacing variables with all relevant ground instances — and computes its answer sets (stable models) using conflict-driven constraint learning techniques adapted from satisfiability solving. It supports features such as disjunction, aggregates, optimisation statements, theory atoms and multi-shot (incremental) solving, and provides APIs for Python, Lua and C.

Uses

Clingo is used in research and applications of knowledge representation and reasoning, including configuration, scheduling, bioinformatics and robotics.
