DX encoding

DX encoding (Digital indeX) is an ANSI and ISO standard (ISO 1007) for marking 135 and APS film cartridges, introduced by Kodak in 1983. It lets a camera automatically read the film's speed, length and exposure tolerance.

Components

The system has three parts:

  • CAS (Camera Auto Sensing) code — a pattern of conductive and insulated patches on the metal cassette shell, read by electrical contacts in the camera, encoding film speed (ISO 12–5000), number of exposures, and exposure latitude.
  • DX barcode — printed on the cassette and on the film edge, identifying the manufacturer, film type and frame number, mainly for photofinishing laboratories.
  • DX iX data exchange — on APS film, additional information recorded by the camera.

Use

Most 35mm cameras from the mid-1980s onward read the CAS code to set film speed automatically, usually allowing manual override. Non-DX-coded bulk-loaded film may require the user to set the speed manually or use foil to modify the code.
