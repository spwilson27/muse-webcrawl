Involution (mathematics)

From Wikipedia, the free encyclopedia


An involution is its own inverse: applying it twice restores each element

In mathematics, an involution, involutory function, or self-inverse function is a function f that is its own inverse:

f(f(x)) = x for all x in the domain of f.

Equivalently, applying f twice produces the original value. Any involution is a bijection. The identity function is a trivial example; more generally, a function that swaps pairs of elements while possibly leaving fixed points unchanged is an involution.

Examples

  • Negation: x ↦ −x on the real numbers, and logical negation.
  • Reciprocation: x ↦ 1/x.
  • Reflection in geometry, e.g. reflection across a line or point reflection (half-turn).
  • Complex conjugation and matrix transposition; an involutory matrix satisfies A² = I, as does the Householder reflection.
  • Complement of a set within a universal set; XOR with a fixed value in Boolean algebra and cryptography (e.g. the Atbash cipher and ROT13 applied to digits and letters jointly).
  • In group theory, an element of order 2; conjugation by such an element is itself an involution on the group.

Properties

The composition of two involutions is an involution only if they commute. The number of involutions on a finite set of n elements (involution numbers, or telephone numbers) counts permutations consisting solely of fixed points and transpositions, and satisfies a simple recurrence. Involutions play roles across algebra, geometry and combinatorics; in Euclidean geometry, the basic symmetries — reflections and half-turns — are involutions, and more general isometries are products of them. The term also extends to algebra involutions, such as the *-operation on a *-algebra, an anti-automorphism of order two.
