Shell script

A shell script is a computer program designed to be run by a Unix shell, a command-line interpreter. The various dialects of shell scripts are considered to be scripting languages. Typical operations performed by shell scripts include file manipulation, program execution, and printing text. A script which sets up the environment, runs the program, and does any necessary cleanup or logging is called a wrapper.

A short shell script displayed in a terminal.

Overview

Shell scripts are text files containing a sequence of commands for the shell, beginning typically with a shebang line such as #!/bin/sh or #!/bin/bash that names the interpreter. Scripts support variables, parameter expansion, control structures (if, for, while, case), functions, and input/output redirection and pipelines, allowing users to automate repetitive administration and build up compound commands from simple tools.

#!/bin/sh
# Count the lines in every text file in the current directory
for f in *.txt; do
  echo "$f: $(wc -l < "$f")"
done

Shells and dialects

The original Bourne shell (sh) defined the core syntax, standardised later by POSIX. Extended dialects include the KornShell (ksh), the Bourne-Again shell (Bash), and the Z shell (zsh), all broadly compatible supersets. The C shell (csh) and its descendant tcsh use a different, C-like syntax, generally discouraged for scripting. On Windows, analogous facilities are provided by batch files and PowerShell scripts.

Uses and limitations

Shell scripts are used for system initialisation and administration, build automation, file processing pipelines, cron jobs, and application wrappers. Drawbacks include relatively slow execution, historically weak facilities for complex data structures and error handling, and portability pitfalls between dialects; for larger tasks, general-purpose scripting languages such as Perl or Python are often preferred. Shell scripts are also a security-sensitive surface: a bug in a shell script executed with elevated privileges became famous in 2014 as Shellshock, a vulnerability in Bash's function-import mechanism.
