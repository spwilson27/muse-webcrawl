Key stretching

In cryptography, key stretching techniques are used to make a possibly weak key, typically a password or passphrase, more secure against brute-force attack by increasing the resources it takes to test each possible key. Typically the technique involves applying a cryptographic hash function many times — often thousands or millions of iterations — sometimes combined with deliberate memory hardness.

Key stretching
PurposeStrengthen weak keys against brute force
ExamplesPBKDF2, bcrypt, scrypt, Argon2

Techniques

Key derivation functions such as PBKDF2 repeatedly apply a pseudorandom function; bcrypt adds an expensive key schedule; scrypt and Argon2 are designed to require large amounts of memory, limiting attackers' ability to use massively parallel custom hardware.

Use with salts

Key stretching is normally combined with salting: a unique random salt stored alongside the hash prevents precomputed rainbow-table attacks and means identical passwords yield different stored values.
