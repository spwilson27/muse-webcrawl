Merkle tree

In cryptography and computer science, a hash tree or Merkle tree is a tree in which every "leaf" node is labelled with the cryptographic hash of a data block, and every node that is not a leaf (called a branch, inner node, or inode) is labelled with the cryptographic hash of the labels of its child nodes. A hash tree allows efficient and secure verification of the contents of a large data structure. Hash trees are a generalization of hash lists and hash chains.

History

The concept was patented by Ralph Merkle in 1979 as part of his work on digital signatures. The Merkle signature scheme uses a hash tree whose root signs many one-time key pairs at once.

How it works

To prove that a particular data block belongs to a tree, one provides the block and the hash values along the path from its leaf to the root (a Merkle proof, or audit path). A verifier recomputes the hashes up the path and checks the result against a trusted root hash. This requires only a logarithmic number of hashes relative to the size of the data set, making verification efficient.

Uses

Hash trees are used in peer-to-peer file sharing protocols, the Git version control system (which structure is Merkle-tree-like), distributed databases such as Cassandra and DynamoDB, certificate transparency logs, and blockchains: Bitcoin organises the transactions in each block into a Merkle tree whose root is stored in the block header, enabling simplified payment verification (SPV) by light clients.
