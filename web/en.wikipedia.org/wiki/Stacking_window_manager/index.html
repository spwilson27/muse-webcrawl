Stacking window manager

A stacking window manager (also called a floating window manager) is a type of window manager that draws windows on the desktop in a stack, allowing them to overlap one another like sheets of paper on a desk. It contrasts with tiling window managers, which arrange windows without overlap, and compositing window managers, which buffer each window separately.

Characteristics

Stacking window managers, such as those traditionally used in Microsoft Windows and macOS, let users freely move, resize and layer windows. Early X Window System managers like twm and Openbox are classic examples.

Compositing

Modern stacking managers usually incorporate compositing, enabling shadows, translucency and animations while retaining the familiar overlapping-window model.
