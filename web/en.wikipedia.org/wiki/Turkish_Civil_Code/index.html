Turkish Civil Code

The Turkish Civil Code (Turkish: Türk Medeni Kanunu) is the main civil law code of the Republic of Turkey. The original code, adopted on 17 February 1926, was closely modelled on the Swiss Civil Code as part of Mustafa Kemal Atatürk's sweeping secular reforms.

The 1926 code

Replacing the Ottoman Mecelle and sharia-based family law, the 1926 code introduced civil marriage, abolished polygamy, and granted women formal legal equality in matters such as divorce and inheritance — revolutionary changes for the time, though the husband remained designated head of the family.

The 2001 code

A new Civil Code (Law No. 4721) was adopted in 2001 and entered into force on 1 January 2002. It removed the "head of family" concept, equalised spouses' rights over marital property with a default regime of participation in acquired property, and raised the minimum marriage age to 18 for both sexes.
