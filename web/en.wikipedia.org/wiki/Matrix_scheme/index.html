Matrix scheme (Matrix protocol)

Matrix is an open standard and communication protocol for real-time, decentralised and federated messaging and voice-over-IP. Sometimes described in terms of its addressing scheme — user IDs, room IDs and event IDs arranged in a federated "matrix" of servers — the protocol allows users on different servers to communicate as if on a single network, much as email works across providers.

Design

Matrix organises communication into rooms, whose conversation history is replicated across all participating homeservers rather than stored on one central machine. Every event in a room — a message, a membership change, a reaction — is signed and linked to earlier events in a directed acyclic graph, so servers can synchronise state and resolve conflicts. User identifiers take the form @user:server.name and room identifiers the form !id:server.name.

Encryption

The protocol supports end-to-end encryption based on the Double Ratchet Algorithm, through its Olm and Megolm implementations, so that server operators cannot read message content.

History and adoption

Matrix was created by Matthew Hodgson and Amandine Le Pape, initially developed within Amdocs and released in 2014. Development is stewarded by the Matrix.org Foundation, and the reference client is Element. The protocol has been adopted by several governments and public-sector bodies, including in France and Germany, for sovereign messaging infrastructure, and bridges exist to networks such as IRC, Slack and Discord.
