Universally unique identifier

AbbreviationUUID
Size128 bits
StandardRFC 9562
Example123e4567-e89b-12d3-a456-426614174000

A universally unique identifier (UUID) is a 128-bit identifier used to label information in computer systems so that it can be generated independently by different parties with a negligible probability of duplication. UUIDs are standardized by RFC 9562 and are typically displayed as 32 hexadecimal digits in five groups separated by hyphens.

Versions

Several UUID versions exist: version 1 combines a timestamp with a node identifier (often a MAC address); version 4 is generated from random numbers; version 5 derives the identifier by hashing a namespace and name with SHA-1; and newer versions 6, 7, and 8 provide time-ordered layouts suited to database keys.

Applications

UUIDs are widely used as database primary keys, session identifiers, transaction IDs, and component identifiers (as GUIDs in Microsoft systems). Because they require no central registry, they are especially useful in distributed systems.
