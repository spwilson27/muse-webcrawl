Computability

Computability is the ability to solve a problem in an effective manner. It is a topic of computability theory and a key concept in numerous fields, including computer science, mathematics, logic, and philosophy. A problem is regarded as computable if a definite procedure — an algorithm — exists that always produces the correct answer in a finite number of steps.

Models of computation

In the 1930s several independent formalisms captured the intuitive notion of effective calculation: Alan Turing's Turing machine, Alonzo Church's lambda calculus, and Stephen Kleene's general recursive functions. The Church–Turing thesis asserts that these and all other reasonable models define exactly the same class of functions. A function is computable if some Turing machine computes it; problems such as the halting problem are provably undecidable — no algorithm can solve them in general.

Degrees of unsolvability

Computability theory orders uncomputable problems into Turing degrees according to relative computability, forming a rich structure studied in recursion theory. Beyond the classical theory, fields such as computational complexity refine computability by asking not only whether a problem can be solved, but how efficiently.
