Open MPI is a Message Passing Interface (MPI) library, developed and maintained by a consortium of academic, research and industry partners. It implements the MPI standard for distributed-memory parallel programming and is widely used on high-performance computing clusters and supercomputers. (Despite the similar name, it is a different project from OpenMP, which addresses shared-memory threading.)

History

Open MPI was formed by merging the experience and codebases of several earlier MPI implementations — FT-MPI, LA-MPI, LAM/MPI and PACX-MPI — and its first release appeared in 2005. Its design centres on a component architecture (the Modular Component Architecture, MCA) in which frameworks for point-to-point messaging, collective operations, process launching and network transports are assembled from selectable plug-in components at run time.

Features

  • Full MPI standard support (including MPI-3 and MPI-4 features such as nonblocking collectives and improved one-sided communication)
  • Multiple network transports: TCP/IP, shared memory, InfiniBand and other RDMA fabrics
  • Automatic selection of transports and tuning parameters via MCA parameters
  • Support for heterogeneous clusters and process binding/pinning for NUMA locality
  • Job launching integrated with resource managers such as Slurm and Torque, as well as its own mpirun (OpenRTE / PRRTE)

Use

Open MPI competes with MPICH and its derivatives (Intel MPI, MVAPICH) as one of the main open-source MPI stacks, and has powered applications on many TOP500 systems.
