Gettier problem

Gettier problem
FieldEpistemology
PublishedEdmund Gettier, 'Is Justified True Belief Knowledge?', Analysis (1963)
[Image: The three-page 1963 issue of the journal Analysis containing Gettier's paper]

The Gettier problem is a challenge to the classical analysis of knowledge as justified true belief, posed by Edmund Gettier in a three-page paper in 1963. Gettier described cases in which a person has a belief that is both true and justified, yet intuitively is not knowledge because its truth is a matter of luck — for instance, inferring a true conclusion from a justified but false premise.

Aftermath

The paper overturned consensus in epistemology overnight. Proposed repairs added a fourth condition (no false lemmas, defeasibility, causal connection), while others abandoned the analysis project (relying on reliabilism or knowledge-first approaches). The problem's fame vastly exceeds its length, and it remains a standard test for any theory of knowledge.
