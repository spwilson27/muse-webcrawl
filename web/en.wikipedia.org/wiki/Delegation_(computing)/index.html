Delegation (computing)

Delegation: an object hands a request to a delegate object, which performs the operation

In computing, delegation refers to one object passing a request, responsibility or authority to another object. The term is used in several related senses in object-oriented programming, language design, and computer security.

Object-oriented programming

In object-oriented programming, delegation is a design pattern in which an object, instead of performing one of its stated tasks, delegates that task to an associated object called a delegate. It is a fundamental technique for code reuse and is often presented as a flexible alternative to inheritance. In prototype-based languages such as Self and JavaScript, delegation is the mechanism by which objects inherit behavior: when a message is not understood by an object, it forwards the request to its parent (prototype) object.

Security and access control

In security, delegation means the transfer of authority from one principal to another — for example, when a user grants a service limited rights to act on their behalf. This is central to capability-based security and to authorization protocols such as OAuth, where access tokens represent delegated authority.
