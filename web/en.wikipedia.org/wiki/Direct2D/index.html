Direct2D

Direct2D is a 2D vector graphics application programming interface (API) designed by Microsoft and implemented as part of DirectX 11 and later versions. It was first introduced with Windows 7 and Windows Vista with Service Pack 2 (SP2) via the Platform Update, replacing GDI and GDI+ as the recommended way to render two-dimensional graphics on Windows.

Direct2D provides hardware-accelerated rendering of aliased and anti-aliased 2D geometry, bitmaps, and text. It is built on top of Direct3D, which allows it to use the graphics processing unit (GPU) while still interoperating with GDI, GDI+, and Direct3D content.

Overview

Direct2D is a native-code API based on the Component Object Model (COM). Applications create a factory object, from which they obtain render targets and drawing resources such as brushes and geometries. Drawing is performed with an immediate-mode-style API, although under the hood commands are batched and sent to Direct3D for execution.

The API is designed to be fast and to produce visually consistent results. It supports:

  • Vector geometry rendering with per-primitive antialiasing
  • Bitmap drawing, scaling, and effects
  • Text rendering through integration with DirectWrite
  • Printing support through the same drawing model
  • Interoperability with Direct3D surfaces and GDI device contexts

Architecture

Direct2D render targets abstract the destination of drawing operations: a window (HwndRenderTarget), a Direct3D texture, a WIC bitmap, or a GDI device context. Resources created from one render target are generally specific to it, reflecting the underlying device-dependent nature of GPU resources.

Direct3D supplies the device and the rasterization pipeline, while DirectWrite supplies font enumeration, text layout, and glyph rendering that Direct2D draws. In Windows 8, Direct2D 1.1 added an effects API, device contexts, and improved geometry realization; later versions continued to add features such as ink and SVG support.

Performance

Because most rendering work is offloaded to the GPU, Direct2D can outperform GDI significantly for complex scenes with many primitives, gradients, and transformed bitmaps, while using comparable or less CPU time. Where hardware acceleration is unavailable, Direct2D falls back to a highly optimized software rasterizer based on the WARP (Windows Advanced Rasterization Platform) Direct3D device.
