Illumos (stylized as illumos) is a partly free and open-source Unix operating system. It is based on OpenSolaris, which was created from Solaris by Sun Microsystems. Illumos comprises a kernel, device drivers, system libraries and application software, collectively known as the core operating system. Development began in 2010 as a fork of the OpenSolaris OS/Net consolidation after Oracle Corporation discontinued open development of Solaris following its acquisition of Sun.

History

Illumos was announced on 3 August 2010 at an event in New York City, presented by Garrett D'Amore and other former Sun engineers, as a community-driven continuation of the open-source Solaris codebase. Because Oracle owned the "OpenSolaris" trademark and declined to participate, the project adopted a new name — derived from Latin illuminare ("to illuminate") combined with "OS". The project aimed to replace the closed-source components of OpenSolaris with open equivalents and to continue development of technologies such as ZFS, DTrace, and Zones.

Features and technologies

Illumos inherits many advanced features from Solaris, including:

  • ZFS — a combined file system and logical volume manager with data integrity verification and protection against data corruption.
  • DTrace — a dynamic tracing framework for troubleshooting kernel and application problems on production systems.
  • Zones — an operating system-level virtualization technology for partitioning resources.
  • SMF (Service Management Facility) — a replacement for init.d scripts and inetd.
  • Crossbow — network virtualization and resource control.
  • KVM and later bhyve — hardware virtualization hypervisors ported to the platform.

Distributions

Illumos itself is a core system rather than a complete end-user distribution. Distributions built on it include SmartOS (a hypervisor platform developed by MNX Solutions, formerly Joyent), OpenIndiana (a general-purpose workstation and server distribution), OmniOS, Tribblix, DilOS, and XStreamOS. These distributions package the illumos kernel and userland with their own installers and package management.

Governance

The project is overseen by a developer council and is stewarded by the Illumos Foundation. Development takes place around the illumos-gate repository, with changes subject to code review and advocacy before integration.
