Non-volatile memory

Non-volatile memory (NVM) or non-volatile storage is a type of computer memory that can retain stored information even after power is removed. In contrast, volatile memory (such as DRAM and SRAM) requires constant power to maintain its data.

Types

Historically, non-volatile storage was dominated by magnetic and optical media — hard disk drives, magnetic tape, floppy disks, and CDs/DVDs — as well as read-only memory technologies such as mask ROM, PROM, EPROM, and EEPROM. The dominant electrically addressable non-volatile memory today is flash memory, in NAND and NOR forms, used in USB drives, memory cards, and solid-state drives. Emerging technologies include ferroelectric RAM (FeRAM), magnetoresistive RAM (MRAM), phase-change memory, and resistive RAM (ReRAM), which aim to combine the speed of volatile memory with persistence.

Non-volatile random-access memory

NVRAM refers to non-volatile memory that can be accessed in a random-access, byte-addressable fashion, including battery-backed SRAM once used for configuration storage, and modern persistent-memory products. Such memory blurs the traditional boundary between memory and storage and enables new programming models in which data structures survive process termination or power loss.
