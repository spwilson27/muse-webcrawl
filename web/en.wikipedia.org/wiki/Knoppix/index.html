Knoppix

Knoppix

Developer: Klaus Knopper

Family: Linux (Unix-like)

Initial release: 2000

Based on: Debian

Knoppix, stylized KNOPPIX, is an operating system based on Debian designed to be run directly from a CD or DVD (Live CD) or a USB flash drive (Live USB). It was one of the first live Linux distributions.

History

Knoppix was developed by the German Linux consultant Klaus Knopper and first released in 2000. It pioneered automatic hardware detection and configuration for live media, and could be used as a Linux demo, educational disc, rescue system, or platform for commercial software product demos.

Features

The distribution includes thousands of software packages, including the LXDE or KDE desktop environments, office suites, and system-recovery tools. When booted, Knoppix can optionally save user changes to a persistent overlay on the boot medium.
