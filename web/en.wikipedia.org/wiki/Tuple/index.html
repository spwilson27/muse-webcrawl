Tuple

In mathematics, a tuple is a finite ordered list of elements. An n-tuple is a sequence of n elements, written (a1, a2, …, an). Special cases have familiar names: a 2-tuple is an ordered pair, a 3-tuple a triple, and so on.

Properties

Unlike a set, a tuple can contain the same element more than once, and the order of elements matters: (1, 2) differs from (2, 1). Tuples may be defined set-theoretically — for example, an ordered pair can be constructed as a Kuratowski set {{a}, {a, b}} — and n-tuples can be built recursively as pairs. The set of all n-tuples drawn from given sets is their Cartesian product.

In computing

Tuples are a basic data type in many programming languages, including Python, where they are immutable sequences, and in relational databases, where a row of a table is often formally described as a tuple. In type theory and functional programming, tuple types generalise the notion of a product type.
