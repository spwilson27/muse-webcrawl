Emulator

Emulator

Type: Software and/or hardware system

Purpose: Imitate another computer system ("guest") on a host system

Examples: QEMU, DOSBox, video game console emulators

Related concepts: Simulation, virtualization, compatibility layer

In computing, an emulator is hardware or software (or both) that enables one computer system (called the host) to behave like another computer system (called the guest), so that the host can run software and use peripherals designed for the guest. Emulation differs from simulation, which models the behaviour of a system abstractly: an emulator aims to reproduce the guest accurately enough to execute its actual software.

Techniques

Software emulators typically reproduce the guest's CPU and other hardware in code. Interpretation executes guest instructions one at a time and is simple but slow; dynamic recompilation (just-in-time compilation) translates blocks of guest machine code into host code for much better performance. "Low-level emulation" (LLE) reproduces the behaviour of individual hardware components, potentially cycle-by-cycle, while "high-level emulation" (HLE) intercepts calls to the guest's operating system or libraries and substitutes host equivalents, sacrificing accuracy for speed.

Uses

  • Preservation and retro gaming: console and home-computer emulators (for systems from the Atari 2600 to the PlayStation) allow classic games to run on modern hardware; projects such as MAME preserve arcade history.
  • Development: mobile and embedded developers test software on emulated devices, e.g. the Android Emulator.
  • Compatibility: running legacy applications, terminal emulation, and printer emulation.
  • Full-system emulation: platforms such as QEMU can emulate entire machines and instruction sets.

History and legal issues

The concept dates to IBM's work in the 1960s on running programs for older machines on the System/360. Modern emulation is generally legal in itself — US courts upheld reverse engineering for interoperability in cases such as Sega v. Accolade — but distributing copyrighted firmware (BIOS images) or game ROMs is usually infringement, which shapes how emulators are distributed.
