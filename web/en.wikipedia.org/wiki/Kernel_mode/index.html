Kernel mode

Placeholder image: CPU privilege levels, kernel mode innermost.

Kernel mode, also known as supervisor mode or privileged mode, is a state of operation of a computer's central processing unit in which executing code has unrestricted access to all hardware and system resources. It contrasts with user mode, in which application code runs with limited privileges.

Privilege separation

Modern CPUs implement privilege levels — for example, rings 0 through 3 in the x86 architecture — with ring 0 reserved for the operating system kernel. In kernel mode, code can execute any instruction, access any memory address, and manipulate page tables, interrupt handling, and device registers directly.

Entering kernel mode

User programs enter kernel mode only through controlled interfaces: system calls, hardware interrupts, and exceptions (traps). This mechanism lets the kernel validate requests and protect processes from one another; a fault in kernel-mode code, however, can crash or compromise the entire system, which is why device drivers and kernel extensions are a common source of instability.

Design approaches

Monolithic kernels run most operating-system services in kernel mode, whereas microkernels minimise kernel-mode code, running services in user mode for reliability at some cost in overhead.
