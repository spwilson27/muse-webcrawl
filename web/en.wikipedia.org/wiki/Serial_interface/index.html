Serial interface

A serial interface is an interface (communication channel) over which data is transmitted sequentially, one bit at a time, in contrast to a parallel interface, which conveys multiple bits simultaneously over multiple wires. Serial communication is used for most computer networking, long-distance links, and modern computer buses because it requires fewer wires, avoids the skew problems of parallel buses at high speed, and supports high clock rates through techniques such as differential signalling.

Examples

  • RS-232 — the classic asynchronous serial standard once used for modems and terminals.
  • RS-422 / RS-485 — differential signalling standards for longer distances and multi-drop networks.
  • USB (Universal Serial Bus), SATA, PCI Express, HDMI, and Ethernet — high-speed serial links that replaced older parallel interfaces.
  • SPI, I²C, and UART interfaces — short-range serial protocols used between integrated circuits and peripherals such as microcontrollers.
  • CAN bus — a serial protocol used in vehicles and industrial control.

Serial versus parallel

Historically, parallel interfaces were faster because they moved many bits per clock cycle. However, at high frequencies the bits on parallel lines arrive at slightly different times (skew), and crosstalk worsens. Modern serial links run at many gigahertz with embedded clocking, encoding schemes (such as 8b/10b), and equalization, so a single serial lane can outperform a wide parallel bus; multiple lanes can be bonded for still more bandwidth.

Asynchronous and synchronous serial

Asynchronous serial communication frames each byte with start and stop bits (as in a UART), avoiding a separate clock line but adding overhead. Synchronous interfaces (such as SPI and I²C) share a clock between sender and receiver.
