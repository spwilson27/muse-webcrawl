Sweep line algorithm

In computational geometry, a sweep line algorithm or plane sweep algorithm is an algorithmic paradigm that uses a conceptual sweep line, or sweep surface, to solve various problems in Euclidean space. It is one of the key techniques in computational geometry.

The idea behind algorithms of this type is to imagine that a line (often a vertical line) is swept or moved across the plane, stopping at various points. Geometric operations are restricted to geometric objects that either intersect or are in the immediate vicinity of the sweep line whenever it stops, and the complete solution is formulated once the line has passed over all objects.

Applications

The sweep line technique underlies several classic results, including Fortune's algorithm for computing Voronoi diagrams in O(n log n) time, Bentley–Ottmann segment-intersection reporting, algorithms for finding the closest pair of points, and computation of the area of a union of rectangles. An application of this approach led to a breakthrough in the history of computer graphics, since algorithms for hidden-surface removal can be implemented using sweep techniques.

Implementation

A sweep algorithm typically maintains two data structures: an event queue, usually a priority queue of future points at which the sweep line will stop, and a status structure, usually a balanced binary search tree holding the objects currently intersected by the sweep line in sorted order. Processing events in order lets the algorithm answer questions about pairs of neighbouring objects only, which is what gives the method its efficiency.
