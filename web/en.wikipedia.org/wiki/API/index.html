API

An application programming interface (API) is a connection between computers or between computer programs. It is a type of software interface, offering a service to other pieces of software. A document or standard that describes how to build or use such a connection is called an API specification. By abstracting underlying implementation details, APIs let programs interact through defined operations without needing to know how those operations are carried out.

Types

APIs exist at many levels: operating system APIs (such as Win32 and POSIX), library and framework APIs, hardware APIs, and remote or web APIs. Modern web APIs commonly use HTTP and exchange data in JSON, following architectural styles such as REST or query languages such as GraphQL. Older remote styles include SOAP and XML-RPC.

Design and use

Good API design emphasizes stability, clear versioning, and least surprise, since published APIs accumulate dependents — a principle sometimes summarized by Hyrum's Law. APIs underpin platform ecosystems: mapping, payment, and social-media APIs allow third-party developers to build on a provider's services, and API documentation and rate limits govern that access.
