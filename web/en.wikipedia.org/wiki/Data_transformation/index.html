Data transformation

In computing, data transformation is the process of converting data from one format or structure into another format or structure. It is a fundamental aspect of most data integration and data management tasks, such as data wrangling, data warehousing, and application integration.

In ETL processes

Data transformation is the middle stage of the extract, transform, load (ETL) process used to populate data warehouses. After data is extracted from source systems, it is cleaned, validated, deduplicated, aggregated, enriched, and reshaped to conform to the target schema before loading. The alternative ELT pattern loads raw data first and transforms it within the target platform.

Types of transformation

  • Basic transformations — data type conversions, formatting changes, renaming fields, and splitting or combining columns.
  • Cleansing — correcting errors, standardizing values, and handling missing data.
  • Integration — joining data from multiple sources and resolving conflicting representations of the same entities.
  • Aggregation and derivation — summarizing data and computing new fields from existing ones.

Statistical data transformation

In statistics, data transformation refers to applying a mathematical function (such as a logarithm, square root, or reciprocal) to a set of values to make them better satisfy the assumptions of a statistical procedure, for example by making a distribution more nearly normal or stabilizing variance.
