Objective-C is a general-purpose, object-oriented programming language that adds Smalltalk-style messaging to the C programming language. Originally developed in the early 1980s by Brad Cox and Tom Love at Stepstone, it was later selected by NeXT for its NeXTSTEP operating system, and became the primary language for developing software for Apple's macOS and iOS until the introduction of Swift in 2014.

History

Cox began work on an object-oriented layer on top of C in the early 1980s, inspired by Smalltalk-80. The language was licensed by NeXT in 1988 and shipped with NeXTSTEP, whose application frameworks were written in Objective-C. When Apple acquired NeXT in 1997, those frameworks became the basis of Mac OS X's Cocoa API. Objective-C was the main language of the original iPhone software development kit in 2008, driving a resurgence of interest.

Syntax

Objective-C is a strict superset of C: any valid C program is a valid Objective-C program. Object-oriented extensions use a syntax derived from Smalltalk messaging, with method calls written in square brackets:

[receiver messageWithArgument:arg anotherArgument:other];

Class interfaces are declared with @interface and implementations with @implementation. The later Objective-C 2.0 release added properties, fast enumeration, blocks and automatic reference counting (ARC).

Messaging

Unlike C++-style function calls, Objective-C method invocations are messages resolved at runtime. The runtime looks up the method implementation for the receiver's class when the message is sent, enabling dynamic behaviour such as message forwarding, swizzling and categories (adding methods to existing classes).

The runtime

The Objective-C runtime is a small library that supports the language's dynamic features: class creation at runtime, introspection, and dynamic typing through the generic object pointer type id. Apple's modern runtime is open source and also underpins much of Swift's interoperability with Apple frameworks.

Use at Apple

For three decades Objective-C was the principal language of Apple's platforms. Although Swift is now preferred for new development, large parts of macOS and iOS, and frameworks such as UIKit and AppKit, remain written in or exposed through Objective-C, and interoperability between the two languages is maintained.
