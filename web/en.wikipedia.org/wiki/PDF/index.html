Portable Document Format (PDF), standardized as ISO 32000, is a file format developed by Adobe in 1992 to present documents — including text formatting and images — in a manner independent of application software, hardware, and operating systems. Each PDF file encapsulates a complete description of a fixed-layout flat document, including the text, fonts, vector graphics, raster images and other information needed to display it.

History

PDF grew out of Adobe co-founder John Warnock's 1991 "Camelot" project, which aimed to let anyone capture documents from any application and view them anywhere. Adobe released PDF 1.0 with Acrobat in June 1993. The formerly proprietary format became an open ISO standard in 2008 (ISO 32000-1), and ISO 32000-2 (PDF 2.0) followed in 2017.

Technical structure

PDF builds on a simplified subset of PostScript: a file contains a body of indirect objects (page content streams, fonts, images), a cross-reference table, and a trailer pointing to the root catalogue. Text is drawn with content-stream operators using embedded or standard fonts and explicit glyph positioning, which makes PDFs reliable for display and printing but harder to re-flow or edit than markup formats. Optional features include forms (AcroForms and the XML-based XFA), annotations, layers, multimedia, encryption and digital signatures, and JavaScript actions.

Variants and use

Standardized subsets include PDF/A for long-term archiving, PDF/X for print production, PDF/E for engineering and PDF/UA for accessible documents. PDF is the de facto standard for final-form documents: government forms, scholarly articles, manuals, e-books distributed outside storefronts and prepress workflows. Viewers range from Adobe Acrobat to browser-integrated renderers such as PDFium and PDF.js.
