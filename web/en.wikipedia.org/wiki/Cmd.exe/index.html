cmd.exe

cmd.exe, commonly known as Command Prompt, is the default command-line interpreter for the Microsoft Windows operating system family. It provides a text-based interface in which users type commands to perform file operations, run programs, and automate tasks with batch files.

History

cmd.exe was introduced with Windows NT as the successor to COMMAND.COM used by MS-DOS and Windows 9x. It supports many internal commands such as dir, copy, del and cd, environment variables, redirection and piping, and the execution of batch files with the .bat and .cmd extensions.

Successors

From 2006 Microsoft promoted PowerShell, and later Windows Terminal, as more capable environments, but cmd.exe remains included in Windows for compatibility.
