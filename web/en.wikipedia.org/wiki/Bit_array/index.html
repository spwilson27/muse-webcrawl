Bit array

A bit array (also known as a bitmap, bit set, bit string, or bit vector) is an array data structure that compactly stores bits. It can be used to implement a simple set data structure. A bit array is effective at exploiting bit-level parallelism in hardware to perform operations quickly. A typical bit array stores kw bits, where w is the number of bits in the unit of storage, such as a byte or word, and k is some nonnegative integer. If w does not divide the number of bits to be stored, some space is wasted due to internal fragmentation.

Definition

A bit array is a mapping from positive integers to bits. It is a data structure that compactly stores individual bits (boolean values). It implements a finite set: a bit array of length n can represent a subset of a universe of n elements, where the i-th bit is 1 if and only if element i is in the set.

Basic operations

Although most machines cannot directly address individual bits, they typically have instructions for performing bitwise logical operations on words. These operations make it possible to test, set, clear, and toggle individual bits, as well as to compute set operations such as union, intersection, and difference across whole words at a time. Bit arrays are therefore the basis for more advanced structures such as the Bloom filter, which uses a bit array together with several hash functions to test set membership probabilistically.

Compression

Sparse bit arrays can be compressed using techniques such as run-length encoding. Compressed bitmap indexes are used in databases to answer queries efficiently, with schemes such as the Word-Aligned Hybrid (WAH) representation compressing runs of identical words while keeping the data in a form that supports fast bitwise operations without full decompression.

Applications

Bit arrays are used to represent priority queues in operating system kernels, to track free blocks on disks, in bitmap graphics and fonts, in sieve algorithms such as the sieve of Eratosthenes for finding prime numbers, and in network protocols for flags and options fields.
