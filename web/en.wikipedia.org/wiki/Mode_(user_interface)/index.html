Mode (user interface)

In user interface design, a mode is a distinct setting within a computer program or any physical machine interface, in which the same user input will produce perceived results different from those that it would in other settings. Modal interface components include the Caps Lock and Insert keys on the standard computer keyboard, both of which typically put the user's typing into a different mode after being pressed, then return it to the regular mode after being re-pressed.

An interface that uses no modes is known as a modeless interface. Modeless interfaces avoid mode errors, in which the user performs an action appropriate to one mode while the system is in another mode, by making it impossible for the user to commit them.

Examples

Many programs have multiple modes of operation. The vi text editor has a number of modes, including insert mode, in which typed text is inserted into the document, and command mode, in which keystrokes are interpreted as commands. Video games often switch between modes of play. In photography, cameras offer automatic, aperture priority, shutter priority and manual modes, in which the same controls adjust different parameters.

Mode errors

Mode errors occur when a user performs an action that has one effect in the mode the user believes is active but a different effect in the mode that is actually active. The classic example is typing text while a text editor is in command mode. Don Norman and other human-computer interaction researchers have argued that modes are a frequent source of user error, and systems should be designed so that modes are visible, or avoided entirely.

Quasimodes

Jef Raskin proposed quasimodes, modes that remain active only while the user physically sustains an action, such as holding down the Shift key or a mouse button. Because the mode is maintained by continuous physical effort, the user is constantly aware of it, which greatly reduces mode errors.
