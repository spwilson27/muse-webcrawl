Linear Tape File System

The Linear Tape File System (LTFS) is a file system specification that allows files stored on magnetic tape media, in particular LTO (Linear Tape-Open) cartridges, to be accessed in a manner similar to files on disk or removable flash drives. It was developed by IBM and released in 2010 with the LTFS Single Drive Edition software.

How it works

LTFS divides a tape into two partitions: a small index partition holding metadata in XML format, and a data partition holding the file contents. Because the index is stored on the tape itself, an LTFS tape is self-describing: any system with LTFS software can mount the cartridge and see directories and files. When files change, updated index copies are appended, preserving earlier versions in some workflows.

Standardisation

The specification was standardised by the Storage Networking Industry Association (SNIA) and published as ISO/IEC 20919:2016. LTFS requires LTO-5 or later drives, which support hardware partitioning. It is widely used for archiving video production assets and broadcast content.

Limitations

Tape remains a sequential medium: random access is slow, and small-file workloads perform poorly compared with disk. LTFS does not itself provide versioning or error correction beyond that of the tape format.
