Metric tree

A metric tree is a type of spatial data structure used to index objects in a metric space — a set equipped with a distance function satisfying the triangle inequality — in order to answer similarity queries such as nearest-neighbour and range searches efficiently. Unlike structures for vector spaces, metric trees rely only on distances between objects, so they apply to strings, shapes, and other non-numerical data.

Principle

Metric trees recursively partition the data into regions, commonly metric balls centred on chosen "pivot" objects with a covering radius. During a search, the triangle inequality provides lower bounds on the distance from the query to every object in a region; if that bound exceeds the best distance found so far, the whole region can be pruned without examining its members.

Examples

  • Ball tree — partitions data into nested hyperspheres.
  • VP-tree (vantage-point tree) — splits data by distance to a chosen vantage point.
  • M-tree — a balanced, dynamic tree designed for secondary storage and large databases.
  • BK-tree — designed for discrete metric spaces such as edit distance between strings.
  • Cover tree — offers strong theoretical guarantees for nearest-neighbour search in spaces of low intrinsic dimension.

Applications

Metric trees are used in content-based image and music retrieval, spell checking, biological sequence searching, and duplicate detection — any domain where similarity is defined by a distance function. Their effectiveness diminishes in very high-dimensional spaces, a manifestation of the curse of dimensionality.
