AVKit

DeveloperApple Inc.
Operating systemiOS, macOS, tvOS, visionOS
TypeSoftware framework
First released2013 (iOS 7 / OS X 10.9 era components)

AVKit is a software framework from Apple that provides ready-made user-interface components for playing video and audio content in applications on iOS, macOS, tvOS, and visionOS. Built on top of AVFoundation, AVKit supplies standard playback controls and behaviors so that developers can present media without implementing a custom player interface.

Components

On iOS and tvOS the central class is AVPlayerViewController, a view controller that manages full-screen and embedded playback, transport controls, chapter navigation, subtitles and closed captions, playback-speed selection, and picture-in-picture. On macOS, AVPlayerView provides an analogous view with configurable controls and fullscreen support. AVKit integrates with system features including AirPlay routing, Now Playing metadata, and accessibility technologies such as VoiceOver.

Relationship to AVFoundation

AVFoundation handles the underlying media pipeline — loading assets, managing AVPlayer and AVPlayerItem objects, and decoding — while AVKit handles presentation. Developers who need custom controls typically use AVFoundation directly and observe player state themselves; AVKit is the recommended path for a standard playback experience with minimal code. Since iOS 9, AVKit has also provided successors to the older MediaPlayer framework's movie player classes.
