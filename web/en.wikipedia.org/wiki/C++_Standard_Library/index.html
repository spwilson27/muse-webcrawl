C++ Standard Library

The standard library provides containers, algorithms, strings, streams, and numerics, defined by the ISO C++ standard.

In the C++ programming language, the C++ Standard Library is a collection of classes and functions, which are written in the core language and part of the C++ ISO Standard itself. It provides several generic containers, functions to manipulate these containers, function objects, generic strings and streams (including interactive and file I/O), some features for functional programming, support for certain language features, and functions for common tasks such as finding the square root of a number. The C++ Standard Library also incorporates most headers of the ISO C standard library, which they replaced by incorporating them into the std namespace.

Components

The library is conventionally divided into several parts. The Standard Template Library (STL) portion supplies containers (vector, list, map, set, unordered_map, and others), iterators, generic algorithms (sort, find, transform, and about a hundred more), and function objects. The strings library provides std::string, string views, and regular expressions. The streams library implements input/output through iostreams and file streams. The numerics library includes complex numbers, random-number facilities, valarray, and mathematical functions and constants. Later standards added a concurrency library (threads, mutexes, atomics, futures), a filesystem library, a date and time library (chrono and calendars in C++20), and ranges.

History

The core of the modern library originated with the Standard Template Library developed by Alexander Stepanov and Meng Lee at Hewlett-Packard, which the C++ standards committee adopted in 1994 — an extraordinary late addition to the draft standard. The first ISO standard, C++98, merged the STL, strings, streams, and the C library into a single specification. Subsequent standards expanded it substantially: C++11 brought smart pointers, move semantics support, threading, and regular expressions; C++17 added optional, variant, any, and parallel algorithms; C++20 added concepts, ranges, coroutines support, and formatting.

Implementations

Major implementations include GCC's libstdc++, LLVM's libc++, and Microsoft's STL, shipped with their respective compilers, and implementations must conform to the standard's requirements including exception-safety guarantees and complexity bounds for containers and algorithms. Unlike libraries in managed languages, much of the C++ Standard Library is implemented as header-only templates instantiated at compile time, giving it its characteristic zero-overhead genericity — and its notoriously long compile times and error messages.
