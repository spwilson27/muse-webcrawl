Parallel computing

Parallel computing is a form of computation in which many calculations or processes are carried out simultaneously, operating on the principle that large problems can often be divided into smaller ones that are solved concurrently. It underlies modern supercomputing, multi-core processors, graphics processing units (GPUs), and distributed systems.

Principles

The achievable speedup from parallelisation is bounded by Amdahl's law: if a fraction of a program is inherently serial, that fraction limits the maximum speedup no matter how many processors are added. Gustafson's law offers a more optimistic view for problems that scale in size with the machine. Parallel workloads are classified by granularity, and by Flynn's taxonomy of instruction and data streams (SISD, SIMD, MISD, MIMD).

Forms of parallelism

  • Bit-level and instruction-level parallelism — wider data paths, pipelining, and superscalar execution within a single core.
  • Data parallelism — the same operation applied simultaneously to many data elements, as in SIMD units and GPUs.
  • Task parallelism — different tasks or threads running concurrently on multiple cores or machines.
  • Distributed computing — computation spread over networked computers, coordinated by message passing (e.g. MPI).

Hardware and programming

Parallel hardware ranges from multi-core CPUs and GPU clusters to warehouse-scale systems. Shared-memory programming models include OpenMP and POSIX threads; distributed-memory programming commonly uses MPI; GPU programming uses CUDA or OpenCL. Key challenges include race conditions, deadlocks, load balancing, communication overhead, and ensuring deterministic, correct results.

History

Early parallel machines include the ILLIAC IV (1970s) and the vector supercomputers of Seymour Cray. The 2000s saw clock-speed scaling stall ("the free lunch is over"), making multi-core parallelism the mainstream path to performance, and exascale supercomputers such as Frontier (2022) rely on millions of parallel processing elements.
