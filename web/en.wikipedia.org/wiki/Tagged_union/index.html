Tagged union

In computer science, a tagged union, also called a variant, variant record, choice type, discriminated union, disjoint union, sum type, or coproduct, is a data structure used to hold a value that could take on several different, but fixed, types. Only one of the types can be in use at any one time, and a tag field explicitly indicates which one is in use.

Concept

A tagged union can be thought of as a type that has several "cases", each of which should be handled separately when the value is inspected — analogous to an enumerated type where each enumerator carries its own payload data. Unlike the unions of C, which are untagged and permit unsafe reinterpretation of the stored bits, a tagged union records the active case, so the language or runtime can enforce that a value is only read as the type it was written as.

Language support

Algebraic data types in functional languages such as ML and Haskell are intrinsically tagged unions; Haskell's data declarations define sum types whose constructors serve as tags. Rust provides tagged unions via enum, with each variant optionally carrying data, and guarantees exhaustive handling through pattern matching. Swift, Kotlin (sealed classes), and TypeScript (discriminated unions of object types) offer similar constructs. In C, programmers emulate tagged unions by pairing an enum tag with a union of payloads, and C++17 added the library type std::variant.

-- Haskell: a shape as a sum type
data Shape = Circle Double
           | Rectangle Double Double
           | Triangle Double Double

area :: Shape -> Double
area (Circle r)       = pi * r * r
area (Rectangle w h)  = w * h
area (Triangle b h)   = b * h / 2

Advantages

Compared with encoding alternatives with inheritance or nullable pointers, tagged unions make the set of possible cases explicit and closed, let compilers check that pattern matches are exhaustive, and store values compactly without indirection.
