Representation learning

In machine learning, feature learning or representation learning is a set of techniques that allows a system to automatically discover the representations needed for feature detection or classification from raw data. This replaces manual feature engineering and allows a machine to both learn the features and use them to perform a specific task.

Motivation

Classical machine learning pipelines depended heavily on hand-crafted features designed by domain experts. Representation learning instead optimises internal features jointly with the end task, so that the representation exposes the underlying explanatory factors of variation in the data — ideally in a form where simple models, such as linear classifiers, succeed.

Approaches

Supervised methods learn representations as by-products of predicting labels; the hidden layers of a neural network trained for classification are a representation of the input. Unsupervised methods include autoencoders, restricted Boltzmann machines and generative adversarial networks. Self-supervised methods construct surrogate tasks from unlabelled data — for example, predicting masked words, as in BERT, or maximising agreement between augmented views of an image, as in contrastive learning. Word embeddings such as Word2vec are a widely used form of learned representation for language.

Deep learning

Representation learning is the conceptual core of deep learning: deep networks stack learned transformations so that successive layers capture increasingly abstract features, from edges to object parts in vision, or from characters to semantics in language. A widely cited 2013 review by Yoshua Bengio, Aaron Courville and Pascal Vincent systematised the field, and the annual ICLR conference was founded with representation learning as its theme.
