Advanced Programmable Interrupt Controller

APIC
Type: Interrupt controller architecture
Introduced: Intel P54C (Pentium), 1994
Components: Local APIC, I/O APIC
Successor: x2APIC, MSI-based interrupt delivery

The Advanced Programmable Interrupt Controller (APIC) is an interrupt controller architecture used in x86 computer systems to distribute hardware interrupts among processors and to support multiprocessor interrupt handling.

Components

The system consists of a Local APIC integrated into each processor core, which handles local interrupts and inter-processor interrupts (IPIs), and one or more I/O APICs that collect interrupts from external devices and route them to the local APICs. The APIC succeeded the simpler 8259 PIC by offering prioritised, flexible routing and support for symmetric multiprocessing.

Later developments

The x2APIC extension enlarged processor addressing, and message-signalled interrupts (MSI/MSI-X) over PCIe have largely superseded pin-based delivery in modern systems.
