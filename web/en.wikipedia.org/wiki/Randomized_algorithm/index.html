Randomized algorithm

A randomized algorithm is an algorithm that employs a degree of randomness as part of its logic, typically using uniformly random bits as auxiliary input to guide its behaviour. By making random choices, such algorithms often achieve better expected performance, greater simplicity, or both, compared with the best known deterministic methods — for example by avoiding worst-case inputs that an adversary could otherwise construct.

Types

Randomized algorithms are classified by the kind of error they tolerate. Las Vegas algorithms always produce a correct answer, but their running time is a random variable (randomized quicksort, which picks a random pivot, is of this kind). Monte Carlo algorithms have a bounded running time but may produce a wrong answer with a small probability, which can usually be reduced by repetition; probabilistic primality tests are the classical example. The complexity classes RP, co-RP, BPP, and ZPP formalize these notions.

Applications

Randomness is central to hashing, random sampling, load balancing, simulated annealing, cryptography, and distributed protocols such as contention resolution on shared channels. The technique of derandomization studies when random choices can be replaced by deterministic ones without loss, and results such as the Miller–Rabin to AKS progression in primality testing show how randomized methods can point the way to deterministic ones.
