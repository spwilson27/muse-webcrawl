Birkhoff–von Neumann theorem

Every doubly stochastic matrix is a convex combination of permutation matrices.

The Birkhoff–von Neumann theorem states that the set of doubly stochastic matrices — square matrices of non-negative real numbers whose rows and columns each sum to 1 — forms a convex polytope whose extreme points are exactly the permutation matrices. Equivalently, every doubly stochastic matrix can be written as a convex combination of permutation matrices. The convex set of doubly stochastic matrices is therefore known as the Birkhoff polytope.

History and proof

The result was published by Garrett Birkhoff in 1946 and independently anticipated by John von Neumann in work from 1953. One common proof uses Hall's marriage theorem: every doubly stochastic matrix has a permutation "diagonal" of positive entries; subtracting a suitable multiple of that permutation matrix reduces the number of non-zero entries, and induction completes the decomposition.

Applications

The theorem implies that the assignment problem in linear programming, when relaxed to allow fractional assignments, always has an optimal solution that is a true permutation — so the relaxation is exact. It is also used in the theory of fair division, in scheduling inputs to outputs in network switches via randomized algorithms, and in quantum information and majorization theory, where doubly stochastic maps characterize transformations that cannot decrease mixedness.
