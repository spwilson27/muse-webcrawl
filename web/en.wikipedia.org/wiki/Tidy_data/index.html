Tidy data

Tidy data is a standard way of mapping the meaning of a dataset to its structure, formalised by statistician Hadley Wickham in a 2014 paper in the Journal of Statistical Software. A dataset is tidy when it follows a set of principles that make it easy to manipulate, model and visualise.

Principles

Wickham defined tidy data by three interrelated rules:

  1. Each variable must have its own column.
  2. Each observation must have its own row.
  3. Each value must have its own cell.

Equivalently, each tidy dataset is a rectangular table in which columns are variables and rows are observations. The idea is closely related to Codd's third normal form in relational databases, recast for statistical data analysis.

Messy data and tidying

Common departures from tidiness include column headers that are values rather than variable names (requiring "pivoting" or melting the data longer), variables stored in both rows and columns, multiple types of observational unit stored in the same table, and multiple variables stored in a single column. Tools such as the tidyr package in R (part of the tidyverse) provide verbs for reshaping data into tidy form; similar approaches exist in Python's pandas and other ecosystems. Wickham argued that perhaps 80 percent of data analysis is spent cleaning and preparing data, and that a standard tidy structure lets analysts spend their effort on analysis rather than on repeatedly re-encoding the same datasets for different tools.
