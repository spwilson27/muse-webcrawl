Lucas-Lehmer primality test

The Lucas–Lehmer iteration
TypeDeterministic primality test
Applies toMersenne numbers

In mathematics, the Lucas-Lehmer test (LLT) is a primality test for Mersenne numbers. The test was originally developed by Édouard Lucas in 1876 and subsequently improved by Derrick Henry Lehmer in the 1930s. It has been used to find most of the largest known prime numbers.

The test

Let Mp = 2p − 1 be the Mersenne number to test, with p an odd prime. Define a sequence by s0 = 4 and si = si−12 − 2 for i ≥ 1, computed modulo Mp. Then Mp is prime if and only if sp−2 ≡ 0 (mod Mp).

Lucas–Lehmer(p):
  s := 4
  M := 2^p − 1
  repeat p − 2 times:
    s := (s*s − 2) mod M
  if s == 0 return PRIME else return COMPOSITE

Significance

Because the test is efficient and conclusive, it powers the Great Internet Mersenne Prime Search (GIMPS), a distributed computing project that has discovered the largest known prime numbers, all of them Mersenne primes verified with the Lucas-Lehmer test.
