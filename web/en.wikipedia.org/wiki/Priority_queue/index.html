Priority queue

In computer science, a priority queue is an abstract data type similar to a regular queue or stack, but where each element additionally has a priority associated with it. An element with high priority is served before an element with low priority. In a priority queue, an element with high priority is dequeued before an element with low priority; if two elements have the same priority, they are generally served according to their order in the queue.

Operations

The basic operations are insert (add an element with a given priority), extract-max (or extract-min: remove and return the element of highest priority), and peek. A common additional operation is decrease-key, which lowers an element's key and is essential for the efficiency of Dijkstra's shortest path algorithm.

Implementations

Priority queues are usually implemented with heaps. A binary heap offers O(log n) insertion and extraction and O(1) peek. Other structures include Fibonacci heaps, which give amortised O(1) decrease-key and are used in theoretical analyses of graph algorithms, pairing heaps, and, for integer keys, van Emde Boas–style structures. Simple implementations using sorted or unsorted arrays are adequate for small inputs.

Applications

Priority queues underlie Dijkstra's and A* search algorithms, discrete-event simulation, Huffman coding, operating-system scheduling, and bandwidth management, as well as the event queues of many algorithms in computational geometry (such as Bentley–Ottmann).
