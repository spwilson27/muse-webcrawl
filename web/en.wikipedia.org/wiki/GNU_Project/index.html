The GNU Project is a free software, mass collaboration project announced by Richard Stallman on September 27, 1983. Its goal is to give computer users freedom and control in their use of their computers and computing devices by collaboratively developing and publishing software that gives everyone the rights to freely run the software, copy and distribute it, study it, and modify it. GNU software grants these rights in its license.

In order to ensure that the entire software of a computer grants its users all freedom rights (use, share, study, modify), even the most fundamental and important part, the operating system (including all its numerous utility programs), needed to be written. According to its manifesto, the founding goal of the project was to build a wholly free Unix-compatible operating system. The name "GNU" is a recursive acronym for "GNU's Not Unix!", chosen because GNU's design is Unix-like, but differs from Unix by being free software and containing no Unix code.

History

Stallman announced the project in 1983 while working at the MIT Artificial Intelligence Laboratory, and began writing GNU software in January 1984, leaving MIT so the institute could not interfere with distribution. Early components included the GNU Emacs text editor (1985), the GNU Compiler Collection (1987), the GNU Debugger, and the Bash shell. The Free Software Foundation was founded in 1985 to raise funds and hold copyrights for the project.

By the early 1990s, GNU provided nearly all of a complete operating system except the kernel. When Linus Torvalds released the Linux kernel under the GNU GPL in 1992, the combination became the widely used GNU/Linux system. The GNU project's own kernel, GNU Hurd, remains under development.

Software

Well-known GNU packages include GCC, the GNU C Library (glibc), the GNU Core Utilities, Bash, Emacs, the GNOME desktop environment, the GIMP image editor, and the GNU General Public License itself — the most widely used free software license, first published in 1989. Copyleft, the licensing mechanism pioneered by the GPL, uses copyright law to guarantee that the freedoms of free software are preserved in derivative works.

Philosophy

The GNU Manifesto (1985) set out the project's ethical case: software should be free not merely in price but in the sense of liberty. Stallman summarises this as "free as in free speech, not free beer." The project distinguishes itself from the later "open source" movement by emphasising these ethical and social goals over practical development methodology.
