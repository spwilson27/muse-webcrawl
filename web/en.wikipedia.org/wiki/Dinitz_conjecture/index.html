Dinitz conjecture

The Dinitz conjecture is a theorem in combinatorics concerning the completion of partial Latin squares, proposed by Jeff Dinitz in 1979 and proved by Fred Galvin in 1995. It states that, given an n × n array of cells in which each cell is assigned a set of n colours, one can choose a colour from each cell's set so that no colour is repeated in any row or column — that is, the resulting coloured array forms a Latin square using the chosen colours.

In the language of graph colouring, the conjecture asserts that the line graph of the complete bipartite graph Kn,n is n-edge-choosable: its list chromatic index equals its ordinary chromatic index. Galvin's proof, celebrated for its elegance, used the kernel method for list colouring developed from the work of Galvin and others on list colouring of bipartite graphs.

The result is a special case of the broader list edge-colouring conjecture, which remains open in general. The Dinitz problem arose from a question about scheduling and Latin squares and is often presented as the statement that an n × n array of n-element colour sets always admits a "Latin transversal" selection, one colour per cell, distinct in each row and column.
