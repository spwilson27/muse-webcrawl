OpenCL

Original author: Apple Inc.

Developer: Khronos Group

Initial release: 2009 (OpenCL 1.0)

Latest major version: OpenCL 3.0 (2020)

Written in: C and C++ bindings

Type: Heterogeneous computing framework

OpenCL (Open Computing Language) is a framework for writing programs that execute across heterogeneous platforms consisting of central processing units (CPUs), graphics processing units (GPUs), digital signal processors (DSPs), field-programmable gate arrays (FPGAs) and other processors or hardware accelerators. OpenCL specifies a programming language (based on C99 and C++11) for programming these devices and application programming interfaces (APIs) to control the platform and execute programs on the compute devices.

History

OpenCL was initially developed by Apple Inc., which submitted the proposal to the Khronos Group. Apple held trademark rights to the name and licensed it to Khronos for royalty-free use. The OpenCL 1.0 specification was released in 2008 and ratified by Khronos members including AMD, IBM, Intel, and Nvidia; conforming implementations shipped in 2009, including in Apple's Mac OS X Snow Leopard.

Subsequent revisions added significant features: OpenCL 1.1 (2010), OpenCL 1.2 (2011), and OpenCL 2.0 (2013), which introduced shared virtual memory, dynamic parallelism, and generic address spaces. OpenCL 3.0, released in 2020, refocused the specification, making many 2.x features optional in order to broaden deployment, and aligned with deployment through layers over other APIs such as Vulkan.

Programming model

OpenCL programs consist of host code, written in C or C++, and kernels — functions executed on OpenCL devices in a data-parallel fashion. Work is organized into work-items (threads) grouped into work-groups, mapped onto an N-dimensional range (NDRange). The memory model distinguishes global, constant, local, and private memory spaces.

The platform model abstracts a host connected to one or more compute devices, each containing compute units subdivided into processing elements. A runtime API manages contexts, command queues, buffers, and program objects, while kernels are compiled at runtime for the target device, enabling portability across vendors.

Industry adoption

OpenCL has been implemented by AMD, Intel, Nvidia, Qualcomm, ARM, and others, and is used in applications including scientific computing, image processing, machine learning frameworks, and cryptocurrency mining. Competing and related technologies include NVIDIA's proprietary CUDA platform, Microsoft's DirectCompute, and the SYCL programming model, which builds on OpenCL. Apple deprecated OpenCL in macOS in 2018 in favor of its Metal API, though implementations remain available.
