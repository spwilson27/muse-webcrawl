Private branch exchange (PBX)
Type: Telephone switching system
Users: Businesses and organisations

A private branch exchange (PBX) is a private telephone network used within a company or organisation. Users of the PBX can communicate internally via extension numbers and share a pool of outside lines for external calls, reducing the number of lines that must be rented from the public telephone network.

History

Early PBXs were manual switchboards operated by attendants with cord boards. Electromechanical and then electronic systems automated switching (the automated system is sometimes called a PABX), and modern systems are software-based.

IP PBX

An IP PBX routes calls over data networks using Voice over IP, integrating voicemail, conferencing, call recording, and unified communications. Hosted or cloud PBX services deliver the same functions from a provider's data centre rather than on-premises hardware.

Features

Typical PBX features include call transfer, call forwarding, voicemail, auto-attendants (interactive voice response), call queues, and direct inward dialling numbers for individual extensions.
