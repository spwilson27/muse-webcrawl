The Common Language Infrastructure (CLI) is an open specification and technical standard originally developed by Microsoft and standardised by Ecma International (ECMA-335) and ISO/IEC (ISO/IEC 23271). It describes an executable code format and a runtime environment that allow multiple high-level languages to be used on different computer platforms without being rewritten for each.

Overview

The CLI defines four main parts:

  • The Common Type System (CTS), a rich set of type and operation definitions shared by all CLI languages.
  • Metadata, describing the types, members, and references in compiled code, making assemblies self-describing.
  • The Common Language Specification (CLS), a subset of the CTS that guarantees interoperability between languages.
  • The Virtual Execution System (VES), which loads and executes CLI-compatible programs, typically by just-in-time compiling the Common Intermediate Language (CIL) instruction set.

Implementations

Microsoft's Common Language Runtime (CLR), shipped with the .NET Framework and its successor .NET, is the best-known implementation. The open-source Mono project provides a cross-platform implementation. Languages targeting the CLI include C#, F#, Visual Basic .NET, C++/CLI, and IronPython.

Distinction from CIL

The CLI is the overall infrastructure specification; the Common Intermediate Language is the bytecode instruction set that CLI implementations execute. The two terms are frequently conflated but refer to different layers of the design.
