Matching function

In economics, a matching function is a mathematical relationship that describes the formation of new relationships (matches) between unemployed resources and vacant jobs or positions over time. It is a central component of search and matching theory, which models frictions in the labor market.

Formulation

The matching function is commonly written as M = m(U, V), where U is the number of unemployed workers, V is the number of job vacancies, and M is the number of new matches (hires) formed in a period. The function is usually assumed to be increasing in both arguments, concave, and homogeneous of degree one (constant returns to scale), so that doubling both unemployment and vacancies doubles the number of matches.

A widely used specification is the Cobb–Douglas form, M = A·U^α·V^(1−α), where A measures matching efficiency and α is the elasticity of matches with respect to unemployment. From the matching function one derives the job-finding rate for workers and the vacancy-filling rate for firms, which together determine the Beveridge curve relationship between unemployment and vacancies.

Empirical evidence

Empirical studies generally support the Cobb–Douglas specification with roughly constant returns to scale, though estimates of the elasticity with respect to unemployment vary, often around 0.3–0.5. Surveys of the literature, such as that by Petrongolo and Pissarides (2001), conclude that the matching function is a useful and empirically robust reduced-form description of the hiring process.

Applications

Matching functions are used in the Diamond–Mortensen–Pissarides (DMP) model of the labor market, for which the three economists received the 2010 Nobel Memorial Prize in Economic Sciences. Analogous functions are used to model matches in marriage markets, housing markets, and money search models.
