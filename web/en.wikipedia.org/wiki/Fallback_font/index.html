Fallback font

A fallback font is a reserve typeface containing symbols for as many Unicode characters as possible. When a display system encounters a character that is not part of the range of the primary font, the character is rendered using a font from the fallback list instead.

Mechanism

In web browsers and operating systems, text is typically specified with a list of fonts in priority order, often ending with a generic family such as serif, sans-serif or monospace. If the first font lacks a glyph for a character, the renderer searches the next fonts in the list. In CSS this is declared through the font-family property; systems such as fontconfig on Linux maintain configurable fallback chains per language and character set.

Unicode fonts

Some fonts attempt near-complete Unicode coverage, such as GNU Unifont and the Noto font family developed by Google, whose name derives from "no tofu" — referring to the hollow rectangles (tofu) displayed when no glyph is available. Despite such efforts, virtually no single font contains every Unicode character, so fallback chains remain essential, particularly for rare scripts, historic characters and emoji.

Issues

Fallback rendering can produce inconsistent typography, as glyphs from different fonts may differ in weight, x-height and style. When no font in the chain contains a character, the system displays a placeholder such as an empty box or question mark, known as the last resort glyph.
