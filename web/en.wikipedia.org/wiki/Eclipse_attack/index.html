Eclipse attack

Eclipse attack is a type of attack on a peer-to-peer network in which an attacker controls a large number of IP addresses or distributed nodes and uses them to surround a target node, obscuring the victim's view of the rest of the network.

Eclipse attack
Type: Peer-to-peer network attack
Related: Sybil attack, routing attack

Overview

In a peer-to-peer system, nodes depend on connections to other peers for transactions, blocks, and routing information. If an attacker can monopolize all of a victim's incoming and outgoing connections, the attacker can filter, delay, or fabricate the information the victim sees — effectively "eclipsing" it from the honest network.

Mechanism

The attacker creates many identities (Sybil attack), exploits peer selection and address manager behavior, and may use denial-of-service or restart tricks to force the victim to reconnect only to attacker-controlled peers. In Bitcoin and Ethereum research, eclipse attacks have been demonstrated using botnets, BGP hijacking, and manipulation of tried/new address tables.

Consequences

Eclipsed victims can be tricked into accepting invalid chains, wasting mining power, double-spending, or leaking private transaction information. Merchants and miners are particularly sensitive targets.

Countermeasures

Defenses include diversifying peer connections, anchoring connections across restarts, detecting anomalous address distributions, limiting connections per IP range or autonomous system, and adding test-before-evict logic. Bitcoin Core has adopted several mitigations since research in 2015-2016 by Ethan Heilman and collaborators.
