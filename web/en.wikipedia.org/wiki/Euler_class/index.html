Euler class

In mathematics, specifically in algebraic topology, the Euler class is a characteristic class of oriented, real vector bundles. Like other characteristic classes, it is an obstruction to finding a nowhere-vanishing section of the bundle.

Definition

For an oriented real vector bundle E of rank r over a space X, the Euler class e(E) is a cohomology class in H^r(X; Z). Pulling back the Thom class of the bundle via the zero section yields the Euler class.

Properties

When the base is a compact oriented manifold and the bundle is its tangent bundle, the evaluation of the Euler class on the fundamental class equals the Euler characteristic of the manifold — a restatement of the Poincaré–Hopf theorem. The Euler class squares to the top Pontryagin class.

Relations

For a complex vector bundle viewed as a real bundle, the Euler class equals the top Chern class. The Euler class is multiplicative under Whitney sums of bundles of even rank in suitable settings.
