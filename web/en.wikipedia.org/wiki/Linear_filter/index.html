Linear filter

In signal processing, linear filters are a fundamental class of filters that obey the superposition principle: the output of a linear filter in response to a sum of inputs is the sum of the outputs in response to each input separately, and scaling an input scales the output by the same factor.

Linear filters are widely used in fields such as electronics, digital signal processing, control theory, audio engineering, and image processing. Common types include low-pass, high-pass, band-pass, and band-stop filters.

Linear time-invariant systems

A linear filter that is also time-invariant (an LTI system) is completely characterised by its impulse response. The output is the convolution of the input signal with the impulse response. In the frequency domain, the system is described by its transfer function or frequency response, which indicates how each frequency component of the input is scaled and phase-shifted.

Design methods

Digital linear filters are commonly designed as finite impulse response (FIR) filters or infinite impulse response (IIR) filters. FIR filters are always stable and can have exactly linear phase; IIR filters can achieve a given magnitude response with fewer coefficients but are not guaranteed to be stable and cannot have exactly linear phase.
