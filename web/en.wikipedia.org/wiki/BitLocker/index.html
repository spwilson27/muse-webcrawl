BitLocker

BitLocker Drive Encryption management in Windows.
DeveloperMicrosoft
Initial releaseJanuary 30, 2007 (with Windows Vista)
TypeDisk encryption software
Operating systemMicrosoft Windows

BitLocker is a full volume encryption feature included with Microsoft Windows versions starting with Windows Vista. It is designed to protect data by providing encryption for entire volumes. By default, it uses the Advanced Encryption Standard (AES) algorithm in cipher block chaining (CBC) or XTS mode with a 128-bit or 256-bit key.

History

BitLocker originated as part of Microsoft's Next-Generation Secure Computing Base initiative and was originally called "Secure Startup". It debuted in Windows Vista Ultimate and Enterprise editions (2007) and was extended with "BitLocker To Go" for removable drives in Windows 7. Later Windows versions broadened availability and management; from Windows 11, a simplified variant called Device Encryption is automatically enabled on many new PCs.

Operation

BitLocker encrypts an entire volume at the sector level. In its most secure configuration it stores the volume encryption key sealed in a Trusted Platform Module (TPM), which releases the key only if the early boot components have not been tampered with; additional authentication factors such as a PIN or a USB startup key can be required. A 48-digit numerical recovery password (recovery key) can unlock a volume if the TPM validation fails, and in managed environments keys can be escrowed in Active Directory or Azure Active Directory. Disk encryption protects against offline attacks — data theft from a lost or stolen machine whose drive is examined directly — but offers less protection against attacks on a running, unlocked system.
