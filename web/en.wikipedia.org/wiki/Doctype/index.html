Document type declaration

A document type declaration, or DOCTYPE, is an instruction that associates a particular SGML or XML document (for example, a webpage) with a document type definition (DTD). In the serialized form of the document, it manifests as a short string of markup that conforms to a particular syntax.

HTML

In HTML, the doctype is a required preamble. The HTML5 specification defines the doctype as simply <!DOCTYPE html>. Earlier versions of HTML used longer declarations referencing public or system identifiers of formal DTDs, such as the HTML 4.01 Transitional doctype.

Rendering modes

Web browsers use the doctype to determine the document's rendering mode: documents with a complete, modern doctype are rendered in standards mode, while absent or outdated doctypes trigger quirks mode, in which the browser emulates bugs of older browsers. An intermediate "almost standards" mode exists in some browsers.
