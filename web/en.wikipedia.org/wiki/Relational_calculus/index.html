Relational calculus

Relational calculus is a non-procedural query language for relational databases, forming, together with relational algebra, the theoretical foundation of query languages such as SQL. Where relational algebra describes how to obtain a result as a sequence of operations, relational calculus describes what result is wanted, using predicates from first-order logic.

Variants

There are two main forms. In tuple relational calculus, variables range over tuples, and a query has the form { t | P(t) } for a formula P. In domain relational calculus, variables range over individual attribute values (domains). Edgar F. Codd showed that the relational algebra and the (domain-independent) relational calculus have the same expressive power, a result known as Codd's theorem. The tuple calculus influenced the QUEL language, while SQL's WHERE clause resembles the calculus in style.
