Interface description language

An interface description language (IDL), or interface definition language, is a specification language used to describe a software component's application programming interface (API) in a language-independent way. IDLs enable communication between components written in different programming languages or running on different machines, as in remote procedure calls and distributed object systems.

Purpose

An IDL defines data types, operations, and parameters abstractly. Compilers then generate "stub" and "skeleton" code that marshals arguments into a wire format, transmits them, and dispatches calls on the receiving side, letting programmers work with local-looking interfaces.

Examples

  • CORBA IDL – the OMG's language for the Common Object Request Broker Architecture
  • Microsoft IDL (MIDL) – used with COM and DCOM
  • Protocol Buffers (.proto) and gRPC – Google's schema and RPC framework
  • Apache Thrift and Apache Avro – schema-based serialization/RPC systems
  • WSDL – XML-based description of SOAP web services
  • Web IDL – used to specify browser APIs

Data types

IDLs typically define primitive types (integers, floating point, strings, booleans), compound types (structures, enumerations, sequences/arrays), and sometimes exceptions, inheritance of interfaces, and versioning mechanisms for schema evolution.
