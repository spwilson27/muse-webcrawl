Operator norm

In mathematics, the operator norm measures the "size" of a bounded linear operator between normed vector spaces. For an operator T from a normed space X to a normed space Y, the operator norm is defined as the smallest constant c such that ||Tx|| ≤ c||x|| for all x in X; equivalently it is the supremum of ||Tx|| over the unit sphere of X.

An operator has finite operator norm exactly when it is bounded, which for linear operators is equivalent to continuity. With the operator norm, the space of bounded linear operators becomes a normed space, and a Banach space when the codomain is complete.

For matrices, the operator norm induced by the Euclidean vector norm equals the largest singular value. Other induced norms include the maximum absolute column sum (for the 1-norm) and the maximum absolute row sum (for the infinity norm).
