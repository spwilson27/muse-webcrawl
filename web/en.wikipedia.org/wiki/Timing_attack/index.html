Timing attack

Timing attack
Type: Side-channel attack
Field: Cryptography, computer security

In cryptography, a timing attack is a side-channel attack in which an adversary attempts to compromise a cryptosystem by analysing the time taken to execute cryptographic algorithms. Because many operations take measurably different amounts of time depending on their inputs, response times can leak information about secret keys and other confidential data.

How it works

Every logical operation in a computer takes some time to execute, and this time can differ based on the input. By precisely measuring the time taken for operations such as modular exponentiation or password comparison, and applying statistical analysis over many samples, an attacker can progressively deduce secret values, sometimes reducing the search space for a key dramatically.

Notable examples

Timing attacks were demonstrated against RSA implementations in the mid-1990s by Paul Kocher. Remote timing attacks over networks have also been shown to be practical, and cache-timing variants exploit shared CPU caches on modern processors.

Countermeasures

Defences include constant-time implementations that avoid input-dependent branches and memory accesses, blinding techniques that randomise inputs before secret operations, and adding deliberate noise or delays, though noise alone is generally considered weak protection.
