BCP 47

BCP 47 is a standard for language tags used for identifying human languages, published by the Internet Engineering Task Force (IETF) as part of its Best Current Practice series. It is the standard referenced by many technologies for indicating the language of content, including HTML, XML and numerous Internet protocols.

Structure

A BCP 47 language tag is composed of hyphen-separated subtags. A typical tag consists of a primary language subtag (such as en for English or de for German), optionally followed by a script subtag (such as Hant for Traditional Chinese characters), a region subtag (such as GB for the United Kingdom), variant subtags, and extension or private-use subtags. For example, zh-Hant-TW denotes Chinese written in traditional characters as used in Taiwan, and de-CH denotes German as used in Switzerland.

Specification

The current specification is defined by RFC 5646, "Tags for Identifying Languages", published in 2009, together with RFC 4647 on matching of language tags. The valid subtags are maintained in the IANA Language Subtag Registry, which draws language codes from ISO 639, script codes from ISO 15924, and region codes from ISO 3166-1 and UN M.49.

Usage

BCP 47 tags are used in the lang attribute of HTML and XML documents, in HTTP's Accept-Language header, in operating-system locale identifiers, and in software internationalisation frameworks such as ICU and the Unicode Common Locale Data Repository (CLDR).
