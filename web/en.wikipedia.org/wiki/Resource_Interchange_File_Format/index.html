Resource Interchange File Format

The Resource Interchange File Format (RIFF) is a generic file container format for storing data in tagged chunks, introduced by Microsoft and IBM in 1991. It is based on the Interchange File Format (IFF) from Electronic Arts, differing principally in byte order (little-endian on x86 systems).

Structure

A RIFF file consists of chunks, each with a four-character code (FourCC), a 32-bit size, and the data. The top-level chunk has the ID "RIFF" followed by a form type such as "WAVE" (audio) or "AVI " (video). Chunks can be nested as LIST chunks, and data is padded to even byte boundaries.

Uses

Well-known RIFF-based formats include WAV, AVI, and the WebP image format (whose files begin with "RIFF" and form type "WEBP"). Files larger than 4 GB are handled by the RF64 extension, which uses a special "ds64" chunk.
