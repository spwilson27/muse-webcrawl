Loadable kernel module

In computing, a loadable kernel module (LKM) is an object file that contains code to extend the running kernel, or so-called base kernel, of an operating system. LKMs are typically used to add support for new hardware (as device drivers) and/or filesystems, or for adding system calls. When the functionality provided by an LKM is no longer required, it can be unloaded in order to free memory and other resources.

Modular extensions to a running kernel

Advantages and drawbacks

Without loadable modules, an operating system would have to include all functionality anticipated in the base kernel, wasting memory on features rarely used, and requiring a reboot whenever new hardware or functionality was added. Most modern monolithic and hybrid kernels — Linux, the BSDs, macOS (kernel extensions), Solaris, and Windows (dynamically loadable drivers) — support modules. The drawbacks include the risk that a buggy module compromises the whole kernel, version-matching requirements between module and kernel, and security concerns: the ability to load a module is equivalent to full control of the system, which is why module loading is restricted to privileged users and, in secure-boot configurations, to cryptographically signed modules.

Linux

Linux kernel modules are files with the .ko (kernel object) extension, managed with tools such as insmod, rmmod, modprobe, and lsmod; modprobe resolves dependencies between modules. A module loaded under a licence incompatible with the kernel's GPL "taints" the kernel, which is reported in logs and bug reports. Out-of-tree modules are commonly built with the DKMS framework so they are rebuilt automatically for new kernels. Since kernel 4.x–5.x, signed modules and lockdown mode under UEFI Secure Boot limit unsigned code in kernel space.

Licensing and other systems

Because modules link intimately with the kernel, their licensing status has been debated, particularly for proprietary graphics drivers on Linux. FreeBSD and other BSD systems provide a similar module system (kldload), and macOS historically used kernel extensions (kexts), now largely replaced by system extensions in user space for security.
