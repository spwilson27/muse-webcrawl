Loop optimization

Loop optimization is a set of compiler techniques that transform loops in program source code to improve execution speed, reduce code size, or better exploit the memory hierarchy and parallel hardware. Because programs typically spend most of their running time in a small number of loops, these transformations are among the most valuable a compiler performs.

Common transformations

Well-known loop optimizations include loop-invariant code motion, which moves computations whose operands do not change out of the loop; induction variable simplification and strength reduction; loop unrolling, which replicates the loop body to reduce overhead; loop fusion and loop fission (distribution), which merge or split loops; loop interchange, which swaps nested loops to improve data locality; and loop tiling (blocking), which partitions iteration spaces to fit caches.

Dependence analysis

Most transformations are legal only when they preserve the program's data dependences. Compilers use dependence analysis and representations such as the polyhedral model to prove that reordering iterations cannot change the result. The same analysis underpins automatic vectorization and automatic parallelization, in which iterations are distributed across SIMD units or multiple cores.
