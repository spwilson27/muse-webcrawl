Fuzzing

Fuzzing or fuzz testing is an automated software testing technique that involves providing invalid, unexpected, or random data as inputs to a computer program. The program is then monitored for exceptions such as crashes, failing built-in code assertions, or potential memory leaks. Typically, fuzzers are used to test programs that take structured inputs.

The technique originated with Barton Miller at the University of Wisconsin–Madison in 1988. Modern coverage-guided fuzzers such as American fuzzy lop and libFuzzer use instrumentation feedback to evolve inputs, and fuzzing is now a standard part of secure development at organizations including Google, whose OSS-Fuzz project continuously fuzzes open-source software.
