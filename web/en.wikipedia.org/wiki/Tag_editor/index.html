Tag editor

A tag editor (also called a tagger) is a piece of software that supports editing the metadata of multimedia files, rather than the content of the files themselves. The term is most commonly used for editors of audio-file tags such as ID3 tags in MP3 files, Vorbis comments in FLAC and Ogg files, and metadata in AAC and other formats.

Functions

Tag editors allow users to view and change fields such as title, artist, album, year, track number, genre, composer, and embedded cover art and lyrics. Most provide batch editing, so that shared fields — for example the album name and artist for a whole album — can be applied to many files at once. Common additional features include renaming files from their tags (or generating tags from filenames), automatic identification of recordings using acoustic fingerprinting services such as MusicBrainz, freedb/CDDB lookups for ripped CDs, and export of playlists or reports.

Examples

Well-known tag editors include Mp3tag and foobar2000 on Windows; MusicBrainz Picard, EasyTAG, Kid3 and puddletag on desktop platforms generally; and the tagging functions built into media players and library managers such as iTunes/Apple Music and MediaMonkey. Command-line tools such as eyeD3 and mid3v2 serve the same purpose in scripts.

Relation to metadata standards

Because each audio format stores metadata differently, tag editors typically translate between schemes: ID3v1 and ID3v2 for MP3, Vorbis comments for FLAC and Ogg Vorbis, and atoms in MP4 containers. Inconsistent handling of these standards — for instance, the interpretation of ID3v2.4 frames — is a frequent source of compatibility problems between players and editors.
