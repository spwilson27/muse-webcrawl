Feature space

FieldMachine learning, pattern recognition
ElementsFeature vectors in an n-dimensional space

In machine learning and pattern recognition, a feature space is the abstract vector space in which data points are represented by their measured attributes, or features. If an object is described by n features, it corresponds to a point — its feature vector — in an n-dimensional space, and classification becomes the geometric problem of separating regions of that space.

Construction

Building a useful feature space is the task of feature engineering: raw data such as images, text, or audio must be converted into numbers. Typical features include pixel statistics, word counts, frequencies, and derived quantities. Feature selection seeks the subset of features most informative for the task, while dimensionality reduction techniques such as principal component analysis project the space into fewer dimensions to fight the curse of dimensionality — the phenomenon that data becomes vanishingly sparse as dimensions multiply.

Kernel methods

Methods such as support vector machines implicitly map data into a much higher-dimensional feature space, where classes that were not linearly separable in the original space may become separable; the kernel trick computes inner products in that space without ever constructing it explicitly.
