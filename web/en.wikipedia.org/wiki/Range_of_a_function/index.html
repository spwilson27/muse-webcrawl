Range of a function

In mathematics, the range of a function may refer either to its codomain or to its image — the set of values the function actually takes. In modern usage the image is usually meant: for a function f: X → Y, the range is f(X) = { f(x) : x ∈ X }, a subset of the codomain Y.

Terminology

The ambiguity is historical: "range" was used for the codomain before "image" became standard, and many textbooks still use range to mean the image — the set of output values actually attained. A function is surjective (onto) when its image equals its codomain. For example, the function f(x) = x² from the real numbers to the real numbers has image (range) the non-negative real numbers, though its codomain is all of ℝ.
