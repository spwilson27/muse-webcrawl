Pure function

In computer programming, a pure function is a function that, given the same input, always returns the same output, and produces no side effects — it does not modify external state, perform I/O, or depend on mutable data outside itself.

Properties

Pure functions are referentially transparent: a call can be replaced by its result without changing program behaviour. This makes them easy to test, reason about, memoise, parallelise and optimise. Mathematical functions and most string and arithmetic operations are pure; functions that read the clock, generate random numbers or write to disk are impure.

Functional programming

Purity is a central principle of functional programming languages such as Haskell, which enforce it by default, while other languages encourage pure functions as a design discipline.
