Inverter (logic gate)

In digital logic, an inverter or NOT gate is a logic gate that implements logical negation. It produces an output which is the inverse, or complement, of its input: a high input yields a low output and vice versa.

Implementation

An inverter can be built with a single transistor. In CMOS technology, a complementary pair of p-type and n-type MOSFETs forms the standard static inverter, which draws almost no current in either steady state. Classic TTL implementations include the 7404 hex inverter chip, containing six independent inverters.

Performance

Digital inverter quality is often measured using the voltage transfer characteristic (VTC), which plots output voltage against input voltage. Key parameters include propagation delay, noise margins, and power dissipation — the inverter is the core building block from which more complex gates and circuits are composed.
