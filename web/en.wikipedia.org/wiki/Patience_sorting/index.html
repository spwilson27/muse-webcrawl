Patience sorting

Patience sorting is a sorting algorithm inspired by, and named after, a card game patience (solitaire). It takes its name from a simplified version of the patience game Klondike: cards are dealt one at a time into piles, and the algorithm efficiently both sorts the cards and finds the length of the longest increasing subsequence of the original sequence.

Algorithm

Given an input sequence, the algorithm deals each element, in order, onto the leftmost pile whose top element is greater than or equal to it; if no such pile exists, a new pile is started to the right. Each pile thereby holds a decreasing sequence. Because the pile tops are in increasing order, binary search can locate the correct pile, giving an efficient dealing phase.

To produce sorted output, the smallest top card is repeatedly removed from among the piles — efficiently done with a priority queue. The total running time is O(n log n) in the worst case.

Longest increasing subsequence

A notable property is that the number of piles at the end of the dealing phase equals the length of the longest increasing subsequence (LIS) of the input. By recording, for each card placed, a pointer to the top card of the pile to its left, an actual longest increasing subsequence can be recovered by backtracking. This application was described by C. L. Mallows and was analysed in the context of the "patience sorting" literature of the 1990s, including work connected to the Ulam problem on longest increasing subsequences of random permutations.

History

The algorithm was named by C. L. Mallows in the early 1960s and later popularised in discussions by Donald Knuth and others. It is closely related to Dilworth's decomposition and the Robinson–Schensted correspondence.
