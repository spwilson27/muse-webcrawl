Grafana

Grafana is a multi-platform open source analytics and interactive visualization web application. It provides charts, graphs, and alerts when connected to supported data sources, and is commonly used for monitoring infrastructure, applications, and business metrics in real time.

Grafana was first released in 2014 by Torkel Ödegaard, originating as a fork of Kibana focused on time-series data sources such as Graphite and InfluxDB. It has since grown to support many data sources through plugins, including Prometheus, Elasticsearch, MySQL, PostgreSQL, and cloud monitoring services.

The software is developed by Grafana Labs, which also offers Grafana Cloud, a hosted version, and related open-source tools such as the log aggregation system Loki and the tracing backend Tempo. Grafana is written primarily in Go and TypeScript and is released under the AGPLv3 licence.
