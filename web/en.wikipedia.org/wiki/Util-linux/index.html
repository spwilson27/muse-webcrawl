Util-linux is a standard package of essential system utilities for Linux operating systems, maintained as a community project hosted on kernel.org. It supplies many of the low-level commands administrators use to manage disks, filesystems, processes, terminals, and system logs, and is included by default in virtually every Linux distribution.

Contents

Notable utilities in the package include:

  • mount / umount — mounting and unmounting filesystems
  • fdisk, sfdisk, cfdisk — partition table manipulation
  • lsblk, blkid, findmnt — block device and mount information
  • dmesg — kernel ring buffer display
  • hwclock — hardware clock management
  • logger — system log entries
  • losetup — loop device setup
  • more, script, su, login, agetty — terminal and session utilities
  • kill, renice, setsid, nsenter, unshare — process and namespace tools
  • lsblk, fstrim, swaplabel and other storage tools

History

The package descends from utilities assembled in the early 1990s by Rik Faith and others for the first Linux distributions; a fork circulated as "util-linux-ng" (next generation) between 2006 and 2010 before resuming the original name. Since 2011 the project has been maintained by Karel Zak of Red Hat. The shared library libblkid and libmount, developed within util-linux, are used by other system components including systemd and udisks.
