Short-circuit evaluation

Short-circuit evaluation, also called minimal evaluation or McCarthy evaluation, is a semantics for Boolean operators in programming languages in which the second argument is executed or evaluated only if the first argument does not suffice to determine the value of the expression.

Behaviour

For AND, if the first operand is false, the result is false without evaluating the second. For OR, if the first operand is true, the result is true immediately. Languages such as C, Java, Python, and JavaScript provide short-circuiting && and || operators.

Uses

Short-circuiting enables safe guard patterns — for example checking a pointer is non-null before dereferencing it — and can improve performance by skipping unnecessary computation. It can also cause subtle bugs when the skipped operand was expected to have side effects.
