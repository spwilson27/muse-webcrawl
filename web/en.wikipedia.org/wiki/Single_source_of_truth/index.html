Single source of truth

In information systems and information technology, single source of truth (SSOT) is the practice of structuring information models and associated data schemas such that every data element is mastered (authoritatively stored and edited) in only one place. Any other copies are derived views or synchronised replicas that link back to the master rather than being maintained independently.

Rationale

When the same fact is stored in several systems and edited in more than one of them, the copies inevitably diverge, producing inconsistency, duplicated effort and disputes about which value is correct. Designating a single authoritative source for each data element removes the ambiguity: users and downstream systems always consult or synchronise from the master.

Implementation

SSOT architectures commonly rely on a central database or master data management platform, unique identifiers for entities, and clearly defined ownership of each data domain. Where a fully centralised store is impractical, federated approaches assign each type of record a "system of record" and enforce that other systems reference rather than duplicate it.

Related concepts

The idea is closely related to database normalisation and the DRY ("don't repeat yourself") principle in software development. A related but distinct notion, "single version of the truth," describes an agreed single reporting view used for organisational decision-making.
