API gravity

The American Petroleum Institute gravity, or API gravity, is a measure of how heavy or light a petroleum liquid is compared to water: if its API gravity is greater than 10, it is lighter and floats on water; if less than 10, it is heavier and sinks. API gravity is thus an inverse measure of a petroleum liquid's density relative to that of water (also known as specific gravity). It is used to compare the densities of petroleum liquids.

Formula

The formula for API gravity is:

API gravity = (141.5 / SG at 60 °F) − 131.5

where SG is the specific gravity of the petroleum liquid at 60 °F (15.6 °C). There is no theoretical or fundamental reason for this scale; it was devised in the early 20th century as an improvement on the older Baumé scale to correct systematic errors in hydrometers.

Classification of crude oil

In the petroleum industry, crude oil is commonly characterised as:

  • Light crude oil — API gravity higher than 31.1°
  • Medium crude oil — API gravity between 22.3° and 31.1°
  • Heavy crude oil — API gravity below 22.3°
  • Extra heavy crude oil — API gravity below 10°, also called bitumen when it occurs in oil sands

Benchmark crudes such as West Texas Intermediate (around 39.6° API) and Brent (around 38° API) are light, sweet crudes, while many Canadian and Venezuelan crudes are heavy.

Measurement

API gravity is measured with a hydrometer floating in the liquid at the reference temperature, or calculated from density measurements such as those from an oscillating U-tube density meter.
