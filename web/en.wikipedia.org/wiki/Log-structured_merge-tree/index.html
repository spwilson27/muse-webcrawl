Log-structured merge-tree
Type: Data structure
Used in: NoSQL databases, storage engines

A log-structured merge-tree (LSM tree) is a data structure designed for write-intensive workloads, used in storage engines such as LevelDB, RocksDB, Cassandra and HBase. It buffers writes in memory and flushes them as sorted runs to disk.

('Structure', 'Writes go to an in-memory memtable backed by a write-ahead log. When full, the memtable is flushed as an immutable sorted file; background compaction merges files across levels, trading read and space amplification for high write throughput.')

('Trade-offs', 'LSM trees excel at sequential writes and range scans but require compaction management and may suffer read amplification, mitigated by Bloom filters and tiered or levelled compaction strategies.')
