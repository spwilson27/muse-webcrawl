Binary heap

A binary heap is a heap data structure that takes the form of a complete binary tree. It is a common way of implementing a priority queue. In a max-heap, each parent node's key is greater than or equal to the keys of its children; in a min-heap, each parent's key is less than or equal to its children's keys — the "heap property".

Representation

Because the tree is complete, a binary heap is usually stored in an array with no gaps. For a node at index i (in 1-based indexing), its children are at indices 2i and 2i+1, and its parent is at index ⌊i/2⌋. No pointers are needed, making the structure compact and cache-friendly.

Operations

Insertion appends the new element at the end of the array and restores the heap property by "bubbling up" (sift up). Extracting the maximum (or minimum) removes the root, moves the last element to the root, and restores the property by "bubbling down" (sift down). Both operations take O(log n) time; building a heap from n elements can be done in O(n) by heapifying from the bottom up.

Applications

Binary heaps underlie the heapsort sorting algorithm, and are used in graph algorithms such as Dijkstra's shortest path and Prim's minimum spanning tree, in schedulers, and in event-driven simulation. The binary heap was introduced by J. W. J. Williams in 1964 as part of heapsort.
