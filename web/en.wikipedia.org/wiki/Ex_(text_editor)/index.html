ex (text editor)

ex, short for extended, is a line editor for Unix systems originally written by Bill Joy in 1976, beginning with an earlier editor written by Charles Haley. It is the direct ancestor of the visual editor vi.

Original authorBill Joy, Charles Haley
Initial release1976 / 1978 (with BSD)
Operating systemUnix, Unix-like
TypeLine editor

Description

ex extends the earlier ed editor with a more powerful command set, addressing lines by number or pattern, substitution with regular expressions, and multiple-file handling. Invoking vi's command line with a colon uses ex commands; ex can be started directly, and POSIX standardises ex as part of the Unix specification. Many modern vi clones such as Vim retain full ex-mode functionality.
