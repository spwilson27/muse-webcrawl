Stabilizer code

A stabilizer code is a class of quantum error-correcting code that encodes logical qubits into a subspace of the Hilbert space of several physical qubits, where the codespace is defined as the simultaneous +1 eigenspace of a commuting set of Pauli operators called the stabilizer group. The formalism was introduced by Daniel Gottesman in 1997 and independently developed from earlier work by Calderbank, Shor, Steane, and others. It provides the dominant framework for quantum error correction and fault-tolerant quantum computation.

Formalism

On n qubits, the Pauli group consists of tensor products of the Pauli operators I, X, Y, and Z (with phases). A stabilizer code is specified by an Abelian subgroup S of the Pauli group not containing −I. The codespace is the set of states |ψ⟩ such that S|ψ⟩ = |ψ⟩ for every element S of the subgroup. If S has n − k independent generators, the codespace has dimension 2k, encoding k logical qubits in n physical ones. Errors that anticommute with some stabilizer generator change the measured eigenvalue of that generator from +1 to −1; measuring all the generators yields an error syndrome that identifies (for correctable errors) which error occurred without disturbing the encoded information.

Examples

Early examples include Shor's nine-qubit code and Steane's seven-qubit code, the latter being an example of a CSS code built from two classical codes. The five-qubit code is the smallest code capable of correcting an arbitrary single-qubit error. Surface codes, based on Kitaev's toric code, arrange qubits on a two-dimensional lattice with local stabilizer checks (plaquette and star operators) and exhibit a high error threshold near 1 percent, making them a leading candidate for practical fault-tolerant quantum computers. Color codes are another widely studied family.

Fault tolerance

Within the stabilizer formalism, the operations that map stabilizer states to stabilizer states are the Clifford group operations; by the Gottesman–Knill theorem these can be simulated efficiently on a classical computer, so a universal fault-tolerant computer must supplement them with non-Clifford resources such as magic states. The stabilizer framework underlies threshold theorems showing that, below a critical physical error rate, arbitrarily long quantum computations are possible with polylogarithmic overhead.
