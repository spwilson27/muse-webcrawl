Small-step semantics

In programming language theory, small-step semantics, also known as structural operational semantics or reduction semantics, is a style of operational semantics that describes how the individual steps of a computation are performed. Rather than mapping a program directly to its final result, a small-step semantics defines a one-step reduction relation between program configurations, typically written e → e′, and a full execution is a sequence of such steps ending in a value (or diverging).

Contrast with big-step semantics

Small-step semantics contrasts with big-step semantics (natural semantics), which relates a program directly to the value it evaluates to, written e ⇓ v. Because big-step judgements only describe terminating computations that produce values, they cannot readily distinguish between a program that loops forever and one that gets stuck on an error. Small-step semantics makes intermediate states explicit, so it can model divergence, stuck states, interleaving of concurrent threads, and interactive or reactive behaviour step by step.

Form and rules

A small-step semantics is usually presented as a set of inference rules over configurations, which may pair an expression with a state, store, environment, or continuation. Congruence rules specify which subterm is reduced next, thereby fixing an evaluation strategy such as call-by-value or call-by-name. The approach originates in Gordon Plotkin's 1981 lecture notes on structural operational semantics (SOS), which provided a uniform framework for defining the behaviour of programming constructs.

Applications

Structural operational semantics is a standard tool in the formal study of programming languages. It is used to prove type soundness (through progress and preservation lemmas), to define abstract machines, to reason about program equivalence, and to give precise specifications of real languages — most famously the Definition of Standard ML, which uses a related style. Small-step relations also support reasoning about non-termination and are the natural setting for labelled transition systems and bisimulation in process calculi.
