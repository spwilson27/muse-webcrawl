Matching (graph theory)

In the mathematical discipline of graph theory, a matching or independent edge set in an undirected graph is a set of edges without common vertices. In other words, a subset of the edges is a matching if each vertex is incident with at most one edge of the matching. A vertex incident to an edge of a matching is said to be matched or covered; otherwise it is unmatched or exposed.

Definitions

A maximal matching is a matching that cannot be extended by adding another edge. A maximum matching is a matching that contains the largest possible number of edges. A perfect matching is a matching in which every vertex of the graph is incident to exactly one edge of the matching; it can only exist when the number of vertices is even. A near-perfect matching leaves exactly one vertex unmatched.

Algorithms

A maximum matching can be found in polynomial time. For bipartite graphs, the Hopcroft–Karp algorithm finds a maximum cardinality matching in O(E√V) time. For general graphs, Edmonds's blossom algorithm (1965) finds a maximum matching in polynomial time; Edmonds's paper "Paths, Trees, and Flowers" is considered a landmark in combinatorial optimization.

Theory

Hall's marriage theorem characterizes when a bipartite graph has a matching that covers one side of the bipartition. Kőnig's theorem states that in a bipartite graph the size of a minimum vertex cover equals the size of a maximum matching. In a graph with no isolated vertices, the size of a maximum matching plus the size of a minimum edge cover equals the number of vertices.

Applications

Matchings arise in assignment problems, scheduling, chemistry (Kekulé structures of aromatic molecules), network design, and kidney exchange programs, where weighted matching algorithms are used.
