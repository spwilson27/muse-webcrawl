Boyer–Moore string-search algorithm

The Boyer–Moore string-search algorithm is an efficient string-searching algorithm that is the standard benchmark for practical string-search literature. It was developed by Robert S. Boyer and J Strother Moore in 1977. The algorithm preprocesses the string being searched for (the pattern), but not the string being searched in (the text). It is thus well suited for applications in which the pattern is much shorter than the text or persists across multiple searches.

Description

Unlike naive search, Boyer–Moore compares the pattern with the text from right to left. When a mismatch occurs, two precomputed heuristics determine how far the pattern can be shifted forward: the bad-character rule aligns the mismatched text character with its last occurrence in the pattern, and the good-suffix rule aligns the already-matched suffix with another occurrence of it in the pattern. The algorithm takes the larger of the two shifts.

Performance

Because it can skip over stretches of text without examining every character, Boyer–Moore often runs in sublinear time on natural-language text — roughly n/m comparisons for a text of length n and pattern of length m in favourable cases. Its worst case is quadratic for periodic patterns unless the good-suffix rule is implemented with the Galil rule refinement, which guarantees linear time.

Variants and use

Variants include the Boyer–Moore–Horspool algorithm, which uses only the bad-character rule with a simplified shift table, and Turbo Boyer–Moore. The algorithm family underlies the search functions of text editors, the Unix grep implementations, and many programming-language libraries.
