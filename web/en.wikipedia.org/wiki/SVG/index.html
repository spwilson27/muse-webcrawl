Scalable Vector Graphics (SVG) is an XML-based vector image format for defining two-dimensional graphics, having support for interactivity and animation. The SVG specification is an open standard developed by the World Wide Web Consortium (W3C) since 1999.

SVG images are defined in a vector graphics format and stored in XML text files. SVG images can thus be scaled in size without loss of quality, and SVG files can be searched, indexed, scripted, and compressed. The XML text files can be created and edited with text editors or vector graphics editors, and are rendered by the most popular web browsers.

History

SVG was developed by the W3C SVG Working Group starting in 1998, after competing proposals such as Adobe's Precision Graphics Markup Language (PGML) and Microsoft's Vector Markup Language (VML) were submitted to the consortium. SVG 1.0 became a W3C Recommendation on 4 September 2001, and SVG 1.1 followed in January 2003. The SVG Tiny and SVG Basic profiles addressed mobile devices with limited capabilities.

Work on SVG 2 began in the following decade, incorporating features inspired by HTML5 and CSS, though the specification long remained a candidate recommendation. Meanwhile, browser support for inline SVG in HTML documents became universal, making SVG the standard choice for icons, diagrams, charts, and logos on the web.

Overview

An SVG file describes graphics using geometric shapes — paths, lines, rectangles, circles, ellipses, and polygons — together with text, gradients, patterns, and transformations. Because the image is described mathematically rather than as a grid of pixels, it can be rendered crisply at any size. SVG supports scripting through the Document Object Model (DOM), styling through CSS, and declarative animation through SMIL, as well as interactivity such as hyperlinks and event handling.

<svg xmlns="http://www.w3.org/2000/svg" width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="red" />
</svg>

Compression

SVG files can be compressed with gzip, producing files conventionally given the .svgz extension. Compressed SVG is supported by web browsers and is often substantially smaller than the uncompressed XML text.

Applications

SVG is widely used for icons and user-interface elements, maps, scientific diagrams, charts generated by data-visualization libraries, and logos. Wikimedia projects, including Wikipedia, prefer SVG for diagrams and flags because the format scales cleanly and can be edited as text.
