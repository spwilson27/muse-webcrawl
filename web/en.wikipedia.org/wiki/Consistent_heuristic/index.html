Consistent heuristic

A consistent heuristic obeys the triangle inequality along every edge.

In the study of path-finding problems in artificial intelligence, a heuristic function is said to be consistent, or to satisfy monotonicity, if its estimate is always less than or equal to the estimated distance from any neighbouring vertex to the goal, plus the step cost of reaching that neighbour. Formally, for every node N and each successor P of N generated by an action a:

h(N) ≤ c(N, a, P) + h(P)

where h is the heuristic, c is the step cost, and h(goal) = 0. The condition is analogous to the triangle inequality.

Consequences

Every consistent heuristic is also admissible (it never overestimates the true cost), but the converse is not true. When the A* search algorithm uses a consistent heuristic, the first time it expands a node it has found the optimal path to that node, so no node needs to be re-expanded, and the f-values of expanded nodes increase monotonically. Most heuristics used in practice, such as straight-line distance in route finding, are consistent.
