Bash, short for Bourne Again SHell, is a Unix shell and command language written by Brian Fox for the GNU Project as a free replacement for the Bourne shell. Released in 1989, it incorporates features from the Korn shell and C shell, and is the default login shell on most Linux distributions and was the default on macOS until Catalina (2019).

Features

Bash supports command-line editing and history, job control, shell functions, arrays, brace expansion, and the [[ ]] conditional and arithmetic constructs of POSIX-mode scripting. Scripts beginning #!/bin/bash are ubiquitous in system administration and DevOps. In 2014 the Shellshock vulnerability (CVE-2014-6271), a flaw in Bash's function-export parsing present for some 25 years, prompted urgent patching across the internet.
