Master boot record

From Wikipedia, the free encyclopedia

The master boot record (MBR) is the first sector of a partitioned mass-storage device, such as a hard disk drive, containing the initial code executed when the system boots and the table describing the disk's partitions. It occupies the very first 512 bytes of the device (logical block address 0) and is used by the BIOS firmware of IBM PC compatible computers to start the boot process.

Structure

The classic MBR layout divides its 512 bytes as follows:

OffsetSizeContents
0x000446 bytesBootstrap code
0x1B84 bytesDisk signature (Windows NT family)
0x1BE64 bytesPartition table — four 16-byte entries
0x1FE2 bytesBoot signature 0x55AA

Each partition table entry describes a primary partition with its status (bootable flag), starting and ending CHS addresses, partition type identifier, first LBA sector and total number of sectors. Because the table holds only four entries, at most four primary partitions can be described; one entry may instead point to an extended partition containing a chain of logical drives.

Boot process

On power-up, the BIOS loads the MBR into memory at address 0x7C00, checks the trailing 0x55AA signature, and transfers control to the bootstrap code. That code locates the partition marked active (bootable), loads its first sector — the volume boot record — and jumps to it, which in turn loads the operating system kernel or a fuller boot loader such as GRUB or the Windows Boot Manager.

Limitations and successors

The MBR scheme uses 32-bit sector addresses, limiting addressable disk size to 2 TiB with 512-byte sectors, and imposes the four-primary-partition limit. It has been largely superseded on modern systems by the GUID Partition Table (GPT) used with UEFI firmware, which supports far larger disks, more partitions and redundant copies of the partition table, although MBR partitioning remains widespread on removable media and older systems. MBR code has also been a target of malware known as bootkits, which infect the bootstrap area to load before the operating system.
