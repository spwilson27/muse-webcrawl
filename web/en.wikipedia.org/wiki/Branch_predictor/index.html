Branch predictor

In computer architecture, a branch predictor is a digital circuit that tries to guess which way a branch (e.g., an if–then–else structure) will go before it is known definitively. The purpose of the branch predictor is to improve the flow in the instruction pipeline. Branch predictors play a critical role in achieving high effective performance in many modern pipelined microprocessor architectures.

Implementation

Techniques range from static prediction (always predicting not taken, or using backward-taken forward-not-taken heuristics) to dynamic schemes using branch history tables with saturating counters, two-level adaptive predictors, and perceptron-based predictors. Modern high-performance processors achieve prediction accuracies well above 95% on typical workloads.

Interaction with security

Speculative execution driven by branch prediction was implicated in the Spectre vulnerabilities disclosed in 2018, in which mistraining a predictor can cause a processor to leak data from speculative paths.
