Darwin Information Typing Architecture

The Darwin Information Typing Architecture (DITA) is an XML architecture for authoring, producing and delivering technical information. It is an open standard maintained by the Organization for the Advancement of Structured Information Standards (OASIS) DITA Technical Committee. The name derives from Charles Darwin (for its use of specialization and inheritance), "information typing" (the identification of topics by type) and "architecture".

DITA organizes content into typed topics assembled by maps.

Overview

DITA is built around the topic: a self-contained unit of information with a title and content, typically short enough to be read at a glance. Topics are typed by their purpose. The three core topic types are concept (explanatory material), task (step-by-step procedures) and reference (lookup material such as specifications and command syntax). A generalized topic type underlies all three.

Topics are assembled into deliverables using maps, which are XML documents that collect and organize topics, define navigation structures such as tables of contents, and support cross-references and linking. Separating content from its assembly allows the same topics to be reused across many publications and output formats, including HTML, PDF and help systems.

Key features

  • Content reuse through maps, key references and content references (conrefs) that transclude shared fragments.
  • Specialization, a mechanism by which new element and topic types are derived from existing ones while remaining processable by general tools.
  • Conditional processing using attributes such as audience, platform and product, filtered at build time by DITAVAL files.
  • Metadata at topic and element level to support retrieval, indexing and personalization.

History

DITA originated within IBM, where it was developed in the late 1990s and early 2000s by a team including Michael Priestley, who coined the name. IBM donated the architecture to OASIS in 2004, and DITA 1.0 was approved as an OASIS standard in 2005. Version 1.2 followed in 2010, and version 1.3 in 2015. The freely available DITA Open Toolkit (DITA-OT) is the reference implementation for publishing DITA content.
