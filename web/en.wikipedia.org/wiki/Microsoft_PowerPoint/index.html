Microsoft PowerPoint

Microsoft PowerPoint is a presentation program developed by Microsoft. It was originally created by Robert Gaskins and Dennis Austin at Forethought, Inc., released in 1987 for the Apple Macintosh, and acquired by Microsoft later that year.

Features

PowerPoint uses slides containing text, images, charts, animations and multimedia, organised into presentations saved in .ppt and later XML-based .pptx formats. It is part of Microsoft Office / Microsoft 365 and is available on Windows, macOS, web and mobile platforms.

Usage and criticism

The program became the dominant presentation tool in business and education. Critics, notably Edward Tufte, have argued that default bullet-heavy styles can oversimplify information, a debate often summarised as criticism of "PowerPoint culture".
