Template (C++)

Templates are a feature of the C++ programming language that allow functions and classes to operate with generic types. This allows a function or class declaration to reference a set of values directly defined by parameters, enabling type-safe generic programming without duplication of code. Templates are a major component of the C++ Standard Library, which includes the Standard Template Library (STL) containers and algorithms.

Kinds of templates

  • Function templates — e.g. template <typename T> T max(T a, T b), instantiated for each argument type used.
  • Class templates — e.g. std::vector<T>; support full and partial specialisation.
  • Variable templates (C++14) and alias templates (C++11).
  • Variadic templates (C++11) accepting arbitrary numbers of type arguments.

How templates work

C++ templates are instantiated at compile time: the compiler generates a concrete function or class for each set of template arguments. This "monomorphisation" yields fast code at the cost of larger binaries and longer compile times. Template metaprogramming exploits the fact that the instantiation mechanism is Turing-complete, and modern C++ constrains templates with concepts (C++20) to improve error messages and expressiveness.

Example

template <typename T>
T const& max(T const& a, T const& b) {
    return a < b ? b : a;
}
