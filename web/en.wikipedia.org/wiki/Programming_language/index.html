Programming language

From Wikipedia, the free encyclopedia
[Image: A screen of colourful syntax-highlighted source code]

A programming language is a formal language comprising a set of instructions that produce various kinds of output, used in computer programming to implement algorithms. Thousands exist, from low-level machine-oriented languages to high-level languages designed for human readability.

Languages are described by their syntax (form) and semantics (meaning), and are usually implemented by a compiler or interpreter. They are classified by paradigm (imperative, functional, object-oriented, logic), typing discipline (static/dynamic, strong/weak), and abstraction level.

History

Ada Lovelace's notes on Babbage's Analytical Engine (1840s) contained the first algorithm intended for a machine. Practical languages began in the 1950s: Fortran (1957, John Backus's team at IBM) for science, Lisp (1958, John McCarthy) for AI and symbolic computing, COBOL (1959) for business, and BASIC (1964) for teaching.

C (1972, Dennis Ritchie) became the systems lingua franca; its descendants include C++, Java (1995), C#, and influences on JavaScript (1995) and Python (1991, Guido van Rossum), the latter now among the most widely used languages, especially in data science and education.

Concepts

Core ideas include variables and data types, control flow (loops, conditionals), functions and modularity, data structures, and abstraction. The theory of programming languages draws on formal language theory (Chomsky hierarchy), type theory, and semantics research.

Language popularity is tracked by indices such as TIOBE; ecosystems of libraries and tooling often matter as much as language design.
