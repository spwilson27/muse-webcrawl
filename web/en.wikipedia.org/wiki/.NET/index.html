.NET (pronounced as "dot net") is a free and open-source, managed computer software framework for Windows, Linux, and macOS operating systems. It is a cross-platform successor to the .NET Framework. The project is mainly developed by Microsoft employees by way of the .NET Foundation, and released under an MIT License.

.NET was first announced in 2000 and the original .NET Framework 1.0 was released on 13 February 2002. The modern, unified platform began with .NET Core in 2016 and was renamed simply ".NET" starting with .NET 5 in November 2020, which merged the .NET Framework, .NET Core, and Xamarin/Mono lineages into a single product.

Architecture

Programs written for .NET execute in a software environment known as the Common Language Runtime (CLR), an application virtual machine that provides services such as security, memory management, and exception handling. Source code written in languages such as C#, F#, and Visual Basic is compiled into Common Intermediate Language (CIL), which is then just-in-time compiled to native machine code by the runtime.

The platform includes a large class library known as the Base Class Library (BCL), which provides features including user interface, data access, database connectivity, cryptography, web application development, numeric algorithms, and network communications. ASP.NET Core is the framework's web development stack, while MAUI (Multi-platform App UI) supports cross-platform desktop and mobile applications.

Release history

Since .NET 5, Microsoft has released a new major version every November. Even-numbered releases (.NET 6, .NET 8, .NET 10) are long-term support (LTS) releases supported for three years, while odd-numbered releases are standard-term support (STS) releases supported for 18 months. .NET 8 was released in November 2023 and .NET 9 in November 2024.
