List of LDAP software

The Lightweight Directory Access Protocol (LDAP) is an open, vendor-neutral application protocol for accessing and maintaining distributed directory information services over an Internet Protocol network. This article lists notable software implementations of LDAP, divided into server software, client software, and libraries.

Libraries

Programming libraries implementing LDAP client functionality include python-ldap (Python), Novell.Directory.Ldap (.NET), UnboundID LDAP SDK (Java), and ldapjs (Node.js). Most operating systems also ship native LDAP client libraries.
