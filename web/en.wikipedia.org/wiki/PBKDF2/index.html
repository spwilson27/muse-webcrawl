PBKDF2

PBKDF2 (Password-Based Key Derivation Function 2) is a key derivation function with a sliding computational cost, used to reduce vulnerability to brute-force attacks. It is part of RSA Laboratories' Public-Key Cryptography Standards (PKCS) series, published in RFC 8018 (PKCS #5 v2.1), and was earlier defined in RFC 2898.

Algorithm

PBKDF2 applies a pseudorandom function, such as a cryptographic hash, cipher, or HMAC, to the input password or passphrase together with a salt value, and repeats the process many times to produce the derived key. The added computational work raises the cost of brute-force attacks, while the salt makes rainbow-table attacks infeasible and prevents identical passwords from producing identical keys.

Use

PBKDF2 is widely used for password storage and disk encryption, including WPA/WPA2 pre-shared keys, Apple iOS key protection, and numerous password managers and libraries. Its iteration count can be tuned as hardware improves. Newer alternatives such as bcrypt, scrypt, and Argon2 add memory hardness, but PBKDF2 remains widely deployed and standardised.
