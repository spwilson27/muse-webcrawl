Metric (mathematics)

In mathematics, a metric or distance function is a function that defines a concept of distance between elements of a set, generalising the familiar notion of distance in Euclidean space. A set equipped with a metric is called a metric space. Metrics allow notions such as convergence, continuity, and the open and closed sets of topology to be developed in great generality.

Definition

A metric on a set X is a function d : X × X → ℝ such that for all x, y, z in X:

  • Non-negativity and identity: d(x, y) ≥ 0, and d(x, y) = 0 if and only if x = y.
  • Symmetry: d(x, y) = d(y, x).
  • Triangle inequality: d(x, z) ≤ d(x, y) + d(y, z).

Examples

  • The Euclidean metric on ℝn, from the Pythagorean theorem.
  • The taxicab (Manhattan) metric, the sum of absolute coordinate differences.
  • The discrete metric, where distinct points are all at distance 1.
  • The British Rail metric and other ultrametrics, in which a stronger triangle inequality holds.
  • Metrics on function spaces, such as the supremum (uniform) metric.

History and variants

The concept was introduced by Maurice Fréchet in his 1906 doctoral thesis on functional analysis. Relaxations of the axioms give pseudometrics (allowing zero distance between distinct points), quasimetrics (dropping symmetry), and semimetrics (dropping the triangle inequality). Every metric induces a topology, though not every topological space arises from a metric — metrizability theorems, such as the Urysohn metrization theorem, characterise when it does.
