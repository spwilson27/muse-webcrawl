World file

TypeSidecar plain-text georeferencing file
Introduced byEsri (ArcView GIS)
File extensions.tfw, .jgw, .pgw, .gfw, .wld
ContainsSix affine transformation parameters

A world file is a six-line plain-text sidecar file used in geographic information systems (GIS) to georeference a raster image such as a scanned map or aerial photograph. It specifies the location, scale, and rotation of the image's pixels in real-world coordinates, allowing software to position the image correctly on a map without embedding georeferencing data in the image itself.

Format

The six lines define an affine transformation from pixel coordinates to map coordinates:

32.0
0.0
0.0
-32.0
447520.0
3734640.0

The values are, in order: the pixel width in map units (x-scale), a rotation term, a second rotation term, the negative pixel height in map units (y-scale), and the map coordinates of the center of the upper-left pixel. With these six parameters, any pixel's position in the image can be converted to a real-world coordinate.

Naming

The world file takes its name from the image it accompanies, using an extension derived from the image format: .tfw for TIFF images, .jgw for JPEG, and .pgw for PNG. A generic extension, .wld, is also recognized. The convention was introduced by Esri for ArcView GIS and is supported by nearly all raster GIS software.

Limitations

A world file does not record the coordinate reference system (that is usually stored separately, for example in a .prj file), and it can only express an affine transformation, so it cannot describe warped or non-uniformly distorted imagery.
