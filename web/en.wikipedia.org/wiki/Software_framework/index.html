Software framework

In computer programming, a software framework is an abstraction in which software providing generic functionality can be selectively changed by additional user-written code, thus providing application-specific software. Frameworks provide a standard way to build and deploy applications.

Characteristics

A defining feature is inversion of control: rather than the developer's code calling library functions, the framework calls the developer's code at defined extension points. Frameworks typically include support programs, libraries, and a scripting or configuration environment.

Examples

Well-known frameworks include Ruby on Rails and Django for web applications, .NET, Angular and React ecosystems for user interfaces, and Spring for enterprise Java. Frameworks trade flexibility for productivity, imposing conventions that speed development of typical applications.
