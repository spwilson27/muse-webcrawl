gzip is a file format and a software application used for file compression and decompression. The program was created by Jean-loup Gailly and Mark Adler as a free software replacement for the compress program used in early Unix systems, and was intended for use by the GNU Project, from which its name ("GNU zip") derives.

File format

The gzip format, specified in RFC 1952, wraps a DEFLATE compressed data stream (RFC 1951) with a header containing metadata such as the original filename and timestamp, and a trailer containing a CRC-32 checksum and the uncompressed data size modulo 232. The DEFLATE algorithm combines LZ77 and Huffman coding. Unlike the related ZIP format, gzip normally compresses a single file or stream; multiple files are conventionally first combined with tar, producing ".tar.gz" or ".tgz" archives.

Usage

gzip is ubiquitous on Unix-like systems and is a standard component of GNU/Linux distributions. Web servers commonly serve gzip-compressed content encoding for HTTP responses, negotiated via the Accept-Encoding header, substantially reducing page transfer sizes. The zlib library implements the same DEFLATE stream and is used by many other formats, including PNG.

History

Version 0.1 was first publicly released on 31 October 1992, and version 1.0 followed in February 1993. The format was documented as an Internet standard-track RFC in May 1996.
