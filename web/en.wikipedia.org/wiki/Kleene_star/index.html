Kleene star

In mathematical logic and computer science, the Kleene star (or Kleene operator, or Kleene closure) is a unary operation, either on sets of strings or on sets of symbols or characters. The application of the Kleene star to a set V is written as V*. It is widely used for regular expressions, a context in which it was introduced by Stephen Kleene to characterise certain automata.

Definition

If V is a set of strings, then V* is defined as the smallest superset of V that contains the empty string ε and is closed under the string concatenation operation. Equivalently:

V* = ⋃i ≥ 0 Vi = {ε} ∪ V ∪ V2 ∪ V3 ∪ ⋯

If V is a set of characters, then V* is the set of all strings over characters in V, including the empty string.

Examples

The application of the Kleene star to the set {"a", "b"} gives {"", "a", "b", "aa", "ab", "ba", "bb", "aaa", ...} — every finite string of a's and b's. Applied to the set of all strings over an alphabet Σ, the operation is idempotent: (Σ*)* = Σ*. In regular expression syntax, the pattern ab* matches "a" followed by zero or more "b"s.

Kleene plus

The related Kleene plus, written V+, denotes one or more repetitions: V+ = V V*, excluding the empty string unless it was already in V.

Generalisation

The operation generalises to any monoid: the Kleene star of an element a of a complete semiring (a "Kleene algebra") is the infinite sum 1 + a + a² + ⋯. The concept also appears in formal language theory, where the star height problem asks how deeply nested stars must be in regular expressions for a given regular language.
