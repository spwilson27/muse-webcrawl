Go, also known as Golang, is a statically typed, compiled programming language designed at Google by Robert Griesemer, Rob Pike and Ken Thompson. It is syntactically similar to C but includes memory safety, garbage collection, structural typing and CSP-style concurrency built around lightweight processes called goroutines.

History

Go was announced in November 2009 and reached version 1.0 in March 2012. The designers aimed to combine the efficiency and safety of a statically typed compiled language with the ease of programming in a dynamic interpreted language, targeting modern multicore, networked machines and large codebases. Go 1.18, released in 2022, added generics — the language's most requested feature.

Design

Go emphasizes simplicity and readability: it omits features such as classes, inheritance, exceptions and macros. Concurrency is provided by goroutines (which multiplex onto OS threads) and channels for communication, following Tony Hoare's communicating sequential processes. The standard library includes a production-grade HTTP server, and the toolchain ships with formatting (gofmt), testing, documentation and module support built in.

Adoption

Go is widely used for cloud and network infrastructure; well-known projects written in Go include Docker, Kubernetes, Hugo, Terraform and Prometheus. Its fast compilation, single static binaries and strong networking support have made it a default choice for many microservices and command-line tools.
