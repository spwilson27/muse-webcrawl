Key exchange

Key exchange
FieldCryptography
PurposeEstablish a shared secret key over an insecure channel
Key examplesDiffie–Hellman key exchange, ECDH

Key exchange (also called key establishment) is a method in cryptography by which cryptographic keys are exchanged between two parties, allowing use of a cryptographic algorithm such as symmetric encryption for the rest of their communication. The central problem is that the parties may have only an insecure channel — monitored by an eavesdropper — over which to agree a secret.

Diffie–Hellman key exchange

The breakthrough came in 1976 with the Diffie–Hellman key exchange, published by Whitfield Diffie and Martin Hellman (with the underlying concept developed by Ralph Merkle, and an equivalent system devised earlier in secret at GCHQ by James Ellis, Clifford Cocks and Malcolm Williamson). Each party generates a private exponent and sends the other a public value computed by exponentiation in a finite group; both then compute the same shared secret, while an observer who sees only the public values cannot feasibly derive it — a security property resting on the difficulty of the discrete logarithm problem. Variants using elliptic curves (ECDH) provide the same security with smaller keys and are used pervasively in protocols such as TLS, SSH and Signal.

Limitations and authentication

Unauthenticated key exchange is vulnerable to man-in-the-middle attacks, in which an attacker runs separate exchanges with each party. Practical systems therefore authenticate the exchange using digital signatures and certificates (as in TLS) or pre-shared information. Exchanging ephemeral keys each session provides forward secrecy, ensuring that compromise of long-term keys does not expose past communications. Post-quantum key encapsulation mechanisms, such as ML-KEM standardised by NIST in 2024, address the threat that quantum computers pose to discrete-logarithm-based schemes.
