Minimax

Minimax (sometimes MinMax or MM) is a decision rule used in artificial intelligence, decision theory, game theory, statistics, and philosophy for minimising the possible loss for a worst case (maximum loss) scenario. When dealing with gains, it is referred to as "maximin" — to maximise the minimum gain. Originally formulated for several-player zero-sum game theory, covering both the cases where players take alternate moves and where they make simultaneous moves, it has also been extended to more complex games and to general decision-making in the presence of uncertainty.

Game theory

In zero-sum games, the minimax solution is the same as the Nash equilibrium. The minimax theorem, proved by John von Neumann in 1928, states that for every finite two-player zero-sum game with perfect information or with mixed strategies allowed, there exists a value V and a mixed strategy for each player such that (a) given player 2's strategy, the best payoff possible for player 1 is V, and (b) given player 1's strategy, the best payoff possible for player 2 is −V.

Combinatorial game theory and computer play

For sequential games that can be represented as a game tree, the minimax algorithm recursively evaluates positions: at the maximising player's nodes it takes the maximum of the child values, and at the minimising player's nodes it takes the minimum. A heuristic evaluation function supplies values for positions at the search depth limit. Improvements include alpha–beta pruning, which discards branches that cannot affect the result, and the negamax formulation.

function minimax(node, depth, maximizingPlayer): if depth == 0 or node is terminal: return heuristic value of node if maximizingPlayer: value := -infinity for each child of node: value := max(value, minimax(child, depth-1, FALSE)) return value else: value := +infinity for each child of node: value := min(value, minimax(child, depth-1, TRUE)) return value

Applications

Minimax search underpins classic game-playing programs for chess, checkers, tic-tac-toe, and other two-player perfect-information games, and variants such as expectiminimax handle chance events. In statistics, minimax estimators minimise the maximum risk over a parameter space.
