Column generation

Column generation
Field: Operations research, linear programming
Related: Dantzig–Wolfe decomposition, branch and price, cutting stock problem

Column generation is a solution technique for large linear programming problems in which the number of variables (columns) is so large that they cannot all be enumerated in advance. Instead, the algorithm works with a small restricted master problem and generates new columns only as they are needed to improve the solution.

Method

The restricted master problem is solved to optimality, and its dual values are passed to a pricing subproblem, which searches for a variable with negative reduced cost (for a minimisation problem). If such a column exists, it is added to the master problem and the process repeats; if none exists, the current solution is optimal for the full problem. The method is closely tied to Dantzig–Wolfe decomposition.

Applications

Column generation was first demonstrated on the cutting stock problem by Gilmore and Gomory in the early 1960s. It is now standard for vehicle routing, airline crew scheduling and pairing, bin packing, and other problems whose natural formulations contain exponentially many variables, such as possible routes or schedules.

Branch and price

When the underlying problem requires integer solutions, column generation is embedded within branch and bound in a framework called branch and price, where branching rules must be chosen so that the pricing subproblem remains tractable.
