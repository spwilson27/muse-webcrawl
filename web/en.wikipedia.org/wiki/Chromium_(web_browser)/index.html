Chromium (web browser)

From Wikipedia, the free encyclopedia
[Image: The Chromium logo: a blue-grey circle surrounded by three muted blue segments]

Chromium is a free and open-source web browser project, primarily developed and maintained by Google. It is the codebase from which Google Chrome is built, differing mainly in branding and in some proprietary additions (licensed media codecs, crash reporting and Google integration).

Released alongside Chrome in 2008, Chromium's code — including the Blink rendering engine (forked from WebKit in 2013) and the V8 JavaScript engine — became the foundation of the modern browser ecosystem. Microsoft Edge, Opera, Brave, Vivaldi and many other browsers are Chromium-based, so a large majority of all web browsing runs on this single open-source codebase.

That success is double-edged: Chromium's openness lets anyone build a competitive browser, yet Google's stewardship of the project gives it outsized influence over web standards — a tension at the heart of debates about the web's future governance.
