Amazon Simple Queue Service (Amazon SQS) is a distributed message queuing service introduced by Amazon.com in late 2004. It supports programmatic sending of messages via web service applications as a way to communicate over the Internet. SQS is intended to provide a highly scalable hosted message queue that resolves issues arising from the common producer-consumer problem or connectivity between producer and consumer. It is generally considered to be the first service launched by Amazon Web Services.

Features

Amazon SQS offers two types of message queues. Standard queues offer maximum throughput, best-effort ordering, and at-least-once delivery. FIFO queues are designed to guarantee that messages are processed exactly once, in the order that they are sent. Messages can be up to 256 KB in size, and are retained for up to 14 days. SQS uses a visibility timeout to prevent messages from being received and processed more than once while in flight, and supports dead-letter queues for messages that fail processing repeatedly.

Usage

SQS is commonly used to decouple components of distributed applications, buffer workloads in microservices architectures, and integrate with other AWS services such as Lambda, EC2, and SNS. Pricing is based primarily on the number of API requests.
