Zero divisor

In abstract algebra, an element a of a ring is called a left zero divisor if there exists a nonzero element x such that ax = 0, and a right zero divisor if there exists a nonzero y such that ya = 0. An element that is both is simply called a zero divisor. The zero element itself is usually excluded from the definition by the requirement that the other factor be nonzero (with 0 sometimes described separately as a trivial case).

Examples

The ring of integers has no zero divisors: if ab = 0 then a = 0 or b = 0. By contrast, in the ring of integers modulo 6, the element 2 is a zero divisor because 2 × 3 = 6 ≡ 0, and neither 2 nor 3 is zero. More generally, in Z/nZ the zero divisors are exactly the elements not coprime to n.

In a ring of matrices over a field, the zero divisors are precisely the nonzero singular (non-invertible) matrices. In the ring of continuous real functions, any function that vanishes on an interval can be a zero divisor.

Properties

A ring with no zero divisors (other than 0 itself) is called a domain; a commutative domain is an integral domain. Zero divisors can never be units: if a had an inverse, then ax = 0 would imply x = 0. In a commutative ring, an element that is not a zero divisor is called regular, and regular elements are exactly those for which multiplication by them is injective — the basis for cancellation laws and for the construction of total quotient rings.
