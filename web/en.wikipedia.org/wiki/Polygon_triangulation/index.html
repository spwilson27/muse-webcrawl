Polygon triangulation

In computational geometry, polygon triangulation is the decomposition of a polygon into a set of triangles using non-crossing diagonals. Every simple polygon with n vertices has a triangulation with exactly n − 2 triangles and n − 3 diagonals.

Algorithms

The ear-clipping method removes successive "ear" vertices in O(n²) time. More sophisticated approaches decompose the polygon into monotone pieces, achieving O(n log n), and Bernard Chazelle gave a linear-time algorithm in 1991, though it is too complex for practical use.

Applications

Triangulation underlies the art gallery problem, polygon area computation, and rendering of polygonal regions in computer graphics.
