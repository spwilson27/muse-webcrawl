Multiple dispatch

From Wikipedia, the free encyclopedia

Multiple dispatch selects a method based on the runtime types of several arguments at once.

Multiple dispatch, also called multimethods, is a feature of some programming languages in which a function or method can be dynamically dispatched based on the run-time types of more than one of its arguments. It generalizes the familiar single dispatch of object-oriented languages, in which a method call is selected only by the class of the object on which it is invoked (the "receiver"), as with virtual methods in C++, Java, or Python.

Motivation

Single dispatch handles operations on two objects awkwardly: a binary operation such as collide(asteroid, spaceship) may need different code for every combination of argument types, forcing patterns like double dispatch or long conditional chains in one class. With multiple dispatch, the programmer simply defines one method per type combination, and the language selects the most specific applicable method for the actual argument types at run time. This keeps code open for extension in both dimensions — new types and new operations — mitigating the expression problem.

Languages

Multiple dispatch is a central feature of the Common Lisp Object System (CLOS, where the functions are called generic functions), Dylan, and Julia, in which essentially all functions are generic and method selection on all arguments drives the language's design and performance model. Multimethods are also available in Clojure, in R (S4 classes), in Groovy, and in libraries for languages without native support (e.g. Python's multipledispatch package; Python itself offers only single dispatch via functools.singledispatch). Method resolution rules, and the handling of ambiguous combinations, differ between languages.
