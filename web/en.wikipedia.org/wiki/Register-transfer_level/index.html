Register-transfer level

FieldDigital circuit design
AbstractionBetween behavioural and gate level
LanguagesVerilog, VHDL, SystemVerilog
Key toolsLogic synthesis, simulation

The register-transfer level (RTL) is a design abstraction used in hardware description languages (HDLs) to model a synchronous digital circuit in terms of the flow of digital signals (data) between hardware registers, and the logical operations performed on those signals. RTL is the level at which most modern integrated circuits are designed, using languages such as Verilog, VHDL and SystemVerilog, and it forms the principal input to logic synthesis tools that convert the description into a gate-level netlist.

Concepts

An RTL description models a circuit as a set of registers (flip-flops) clocked by one or more clocks, together with combinational logic that computes the next values of the registers and the circuit outputs from the current register values and inputs. On each clock edge, all registers update simultaneously — a "register transfer". Anything not explicitly stored in a register is combinational: its value is a pure function of its inputs and settles within the clock cycle.

Design flow

RTL sits between high-level behavioural or algorithmic descriptions and the physical gates of the chip. Designers write RTL to describe datapaths, control state machines, pipelines and interfaces. The code is verified by simulation and formal methods, then passed to a logic synthesis tool, which maps the description onto the standard cells of a target technology library, optimising for area, speed and power. The resulting gate-level netlist proceeds to place-and-route for physical layout.

Synthesisable subset

Not every construct of an HDL is synthesisable. Hardware description languages can also express testbench behaviour — delays, file I/O, waveform printing — that has no hardware meaning. Designers therefore write RTL within the synthesisable subset: clocked processes or always blocks with edge-sensitive lists describe registers, while continuous assignments and level-sensitive blocks describe combinational logic. Accidentally inferring latches, by leaving a combinational output unassigned on some path, is a classic RTL pitfall.

Cycle accuracy

Because values change only at clock edges, an RTL model is cycle-accurate: it reproduces exactly which values appear on every signal in every clock cycle, while abstracting away the analogue details of signal transitions within a cycle. This makes RTL simulation much faster than gate- or transistor-level simulation while preserving the timing behaviour that matters for verifying pipelines and protocols.
