KDE Plasma

KDE Plasma is a graphical desktop environment developed by the KDE community for Linux and other Unix-like operating systems. It is built on the Qt framework and is known for its extensive customizability, allowing users to modify nearly every aspect of the desktop's appearance and behavior. Plasma is the default desktop environment on several Linux distributions and is also the environment used on Valve's Steam Deck in desktop mode.

History

KDE's desktop was originally known simply as the K Desktop Environment. The Plasma name was introduced with KDE 4 in 2008, unifying the desktop shell, panels, and widgets under a single framework built around "plasmoids" (widgets). Plasma 5, released in July 2014, brought a flatter visual style (the Breeze theme), a migration to Qt 5 and KDE Frameworks 5, and improved support for high-DPI displays. Plasma 6, released on 28 February 2024, moved to Qt 6, made Wayland the default display server session, and adopted a floating panel and revised default settings.

Features

Plasma provides panels, application launchers, a system tray, and desktop widgets that can be added, removed, and rearranged freely. Its window manager, KWin, supports both X11 and Wayland compositing, virtual desktops, and window effects. KDE Activities allow users to maintain separate sets of windows and widgets for different tasks. The Discover software center provides graphical package management, and KDE Connect integrates the desktop with smartphones for notifications, file transfer, and remote input.

Releases

Plasma follows a regular release cycle with feature releases several times a year and long-term support (LTS) releases maintained with bug fixes for extended periods. Major versions include Plasma 5 (2014), its final release Plasma 5.27 LTS (2023), and Plasma 6 (2024), followed by Plasma 6.1, 6.2, and subsequent updates.
