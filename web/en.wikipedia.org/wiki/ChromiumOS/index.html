ChromiumOS

The ChromiumOS desktop environment

ChromiumOS (formerly styled as Chromium OS) is an open-source operating system designed by Google for running web applications and browsing the World Wide Web. It is the open-source version of ChromeOS, a Linux distribution made by Google.

ChromiumOS is based on the Linux kernel, and like ChromeOS it uses the Google Chrome web browser as its principal user interface. Google announced the project in July 2009. The source code was released in November 2009 under the BSD license as the ChromiumOS project.

Architecture

ChromiumOS is built upon a three-tier architecture: the firmware, the system-level software and services, and the window manager and browser. It is based on Gentoo Linux and uses Google's build system. The operating system emphasises security, speed, and simplicity, employing sandboxing and verified boot to reduce malware risks.

Relationship to ChromeOS

ChromeOS is built upon ChromiumOS but adds a number of proprietary features, including support for certain media codecs, Google Play and Android applications, automatic updates delivered by Google, and integration with Google services. Developers can compile ChromiumOS from source and install it on compatible hardware, though it lacks official support.
