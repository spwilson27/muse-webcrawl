Hindley–Milner type system

A Hindley–Milner (HM) type system is a classical type system for the lambda calculus with parametric polymorphism. It was first described by J. Roger Hindley and later rediscovered by Robin Milner. A key property of HM is that it is complete, so types can be inferred without any type annotations using Algorithm W, Milner's type inference algorithm.

Properties

In HM, types are built from type variables, primitive types, and function types; type schemes allow a variable to be used at several different types (let-polymorphism). Type inference proceeds by unification, producing the most general (principal) type of any well-typed expression.

Use

HM forms the basis of the type systems of the ML family of programming languages, including OCaml and Standard ML, and strongly influenced Haskell. Extensions such as type classes, row polymorphism, and higher-rank types go beyond the basic system.
