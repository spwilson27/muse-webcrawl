macOS Big Sur

macOS Big Sur (version 11) is the seventeenth major release of macOS, Apple's desktop operating system for Macintosh computers. It was announced at Apple's Worldwide Developers Conference (WWDC) on 22 June 2020, and was released to the public on 12 November 2020. Big Sur is the successor to macOS Catalina (version 10.15) and was succeeded by macOS Monterey (version 12) on 25 October 2021.

The release is named after the coastal region of Big Sur in California. It is the first version of macOS since the original Mac OS X in 2001 to increment the major version number from 10 to 11, and the first version to run on Apple silicon Macs powered by the Apple M1 chip, while also supporting Intel-based Macs.

Changes

Big Sur introduced the most significant redesign of the macOS user interface since Mac OS X: a translucent menu bar, full-height sidebars, redesigned rounded app icons, a customisable Control Center modelled on iOS, and a reworked Notification Center with widgets. Safari gained a customisable start page, improved performance, built-in translation and a Privacy Report feature. Messages, Maps and the App Store also received substantial updates, and the system volume became cryptographically signed (the "Signed System Volume" feature).

System requirements and reception

Big Sur supports iMacs from 2014, MacBooks from 2015 and comparable machines or later; it dropped support for several models supported by Catalina. The release was praised for its visual refresh and for the smooth transition to Apple silicon through the Rosetta 2 translation layer, though some critics noted bugs in early versions.
