Regression dilution

Regression dilution, also known as regression attenuation, is a bias in statistical estimation that arises when an explanatory (independent) variable is measured with error. In ordinary least squares regression, random measurement error in the independent variable biases the estimated regression coefficient toward zero, understating the true strength of the association — the "dilution" of the slope.

Cause and correction

If the observed variable is the sum of the true value and independent measurement error, the slope is attenuated by a factor equal to the proportion of the observed variance attributable to the true variable (the reliability ratio). Corrections include using repeated measurements to estimate the error variance, instrumental-variable methods, and errors-in-variables models. Regression dilution is a major concern in epidemiology, for example in estimating the effect of blood pressure or cholesterol levels on disease risk, where a single baseline measurement poorly represents long-term "usual" levels; statistical corrections for it substantially strengthen estimated associations.
