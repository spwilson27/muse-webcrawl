Make (software)

Make is a build automation tool that automatically builds executable programs and libraries from source code by reading files called makefiles, which specify how to derive the target program. Though integrated development environments and language-specific compiler features can also be used to manage a build process, Make remains widely used, especially in Unix and Unix-like operating systems.

Origin

Make was created by Stuart Feldman in April 1976 at Bell Labs as part of the Unix environment. Feldman was inspired by the experience of a colleague who spent a night debugging a broken build caused by a file that had not been recompiled. The utility received the 2003 ACM Software System Award. Make decides which pieces of a large program need to be recompiled by comparing file modification times against the dependencies declared in the makefile, executing only the necessary commands.

Variants and derivatives

Several variants exist, most notably GNU Make, which is the standard implementation on Linux systems, and the BSD family of makes. Make's dependency-graph model has influenced many later build tools, including Ant, Maven, CMake generators and Ninja. The POSIX standard specifies a version of make with a core feature set to ensure portability of makefiles.

Makefiles

A makefile consists of rules of the form target: prerequisites followed by tab-indented commands (recipes). Variables, pattern rules and automatic variables allow makefiles to generalize over many files. A frequently criticised but defining feature is that recipe lines must begin with a literal tab character.
