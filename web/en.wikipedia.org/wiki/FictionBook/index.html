FictionBook is an open XML-based e-book format that originated in Russia and gained popularity there and in several other countries. FictionBook files have the .fb2 extension and are usually distributed uncompressed or within ZIP archives (fb2.zip).

Format

Unlike formats that describe a document's presentation, FictionBook describes its logical structure: sections, paragraphs, epigraphs, verses, citations, and annotations are marked semantically. Metadata about the book (title, authors, genre, language, and publication information) is embedded in a description block, and images are stored inside the file encoded in Base64. Because the structure is semantic, reading software can reflow the text and restyle it for different screen sizes and user preferences.

Support

The format is supported by many e-readers and reading applications, including FBReader, Cool Reader, AlReader, and Calibre (which can convert to and from FB2). A number of online libraries, particularly Russian-language collections, distribute their catalogues primarily in FictionBook format.
