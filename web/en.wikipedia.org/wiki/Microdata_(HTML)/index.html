Microdata (HTML)

Microdata embeds machine-readable metadata within HTML content

Microdata is a WHATWG HTML specification used to nest metadata within existing content on web pages. Search engines, web crawlers, and browsers can extract and process Microdata from a web page and use it to provide a richer browsing experience for users. Microdata uses a supporting vocabulary to describe an item and name-value pairs to assign values to its properties.

Usage

Microdata is defined by a small set of attributes: itemscope marks an element as an item, itemtype gives the item's type as a URL (commonly a schema.org vocabulary term), itemprop names a property of the item, itemid supplies a unique identifier, and itemref associates properties that are not descendants of the item element. For example, a block describing a person might use itemscope itemtype="http://schema.org/Person" with properties such as name and jobTitle.

Schema.org and search engines

In 2011, Google, Microsoft and Yahoo! launched the schema.org initiative, a shared vocabulary for structured data on web pages, with Microdata as one of its principal syntaxes (alongside RDFa and JSON-LD). Search engines use such markup to generate rich results, such as event listings, recipes and product prices, in search results pages.

Support

The HTML specification also defines a Microdata DOM API and JSON conversion for accessing item properties from scripts. While JSON-LD has become the format Google most often recommends, Microdata remains widely deployed on the web.
