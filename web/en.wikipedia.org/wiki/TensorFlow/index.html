TensorFlow is a free and open-source software library for machine learning and artificial intelligence. Developed by the Google Brain team and released under the Apache License 2.0 in 2015, it can be used across a range of tasks but has a particular focus on training and inference of deep neural networks. Its name derives from the operations that neural networks perform on multidimensional data arrays, called tensors.

TensorFlow logo

History

TensorFlow was developed from DistBelief, a proprietary machine learning system built by Google in 2011 for internal use in products such as Google Search, Gmail, Photos and speech recognition. Google released TensorFlow as open source on 9 November 2015. TensorFlow 2.0, released in 2019, made eager execution the default and integrated the Keras API as its principal high-level interface, simplifying model building.

Features

TensorFlow provides a Python API (and bindings for other languages) for defining and training models, which can then be deployed on CPUs, GPUs and Google's Tensor Processing Units (TPUs). Its ecosystem includes TensorFlow Lite for mobile and embedded devices, TensorFlow.js for browser-based models, TensorBoard for visualisation, and TensorFlow Extended (TFX) for production pipelines. Models are represented as dataflow graphs in which tensors flow through operations; automatic differentiation supports gradient-based optimisation.

Applications

TensorFlow has been used in image and speech recognition, natural language processing, recommendation systems, drug discovery and many other fields, and it became one of the most widely adopted deep learning frameworks in research and industry, competing with PyTorch.
