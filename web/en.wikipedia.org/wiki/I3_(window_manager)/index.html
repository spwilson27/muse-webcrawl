i3 (window manager)

i3 is a tiling window manager designed for X11, written in C and inspired by wmii. It arranges application windows automatically in non-overlapping frames ("tiles") according to a tree data structure, and is designed primarily for power users and developers. i3 is free and open-source software released under the BSD license; its first version appeared in 2009.

Design

Windows are organised as leaves of a tree of containers, each of which may use a split, stacked or tabbed layout. Floating windows, such as dialog boxes, are supported on top of the tiled arrangement. Configuration is done through a plain-text file, and users are expected to drive the environment from the keyboard using a configurable modifier key. i3 supports multiple monitors with independent workspaces per display.

Forks and ecosystem

Popular community projects include i3-gaps, a fork adding gaps between windows (later merged into i3), i3status and i3blocks status bars, and Sway, a Wayland compositor designed to be a drop-in replacement for i3 on Wayland.
