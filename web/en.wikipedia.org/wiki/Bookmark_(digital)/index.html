Bookmark (digital)

In the context of the World Wide Web, a bookmark is a Uniform Resource Identifier (URI) that is stored for later retrieval in any of various storage formats. All modern web browsers include bookmark features, in which bookmarks are usually accessed through a bookmarks menu or toolbar. In some browsers they are called favorites (notably in Internet Explorer) or shortcuts.

History

Bookmarks were incorporated into the Mosaic browser in 1993 as "hotlists", and the feature was carried into Netscape Navigator and other early browsers. As the web grew, bookmark managers gained folders, tags, search, and synchronisation across devices through browser accounts.

Storage

Browsers store bookmarks in proprietary databases or in the widely supported Netscape bookmarks file format, an HTML-based export format that allows bookmarks to be moved between browsers. Bookmark files record the title, URL, and optionally the date added and keyword metadata for each entry.

Social bookmarking

Social bookmarking services, beginning with sites such as Delicious in 2003 and later Pinterest and Pocket, allowed users to save bookmarks online, tag them, and share them publicly, turning personal bookmark collections into a means of discovering and categorising web content.

Other uses

E-book readers and document viewers use "bookmarks" to mark a position within a document, and some applications support bookmarklets — small JavaScript programs stored as bookmark URLs that run in the context of the current page.
