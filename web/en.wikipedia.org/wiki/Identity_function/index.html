Identity function

In mathematics, an identity function, also called an identity relation, identity map or identity transformation, is a function that always returns the value that was used as its argument, unchanged. That is, when f is the identity function, the equality f(x) = x holds for all x.

Definition

Formally, if X is a set, the identity function f : X → X is defined such that for all elements x in X, f(x) = x. It is commonly denoted idX or 1X.

Algebraic properties

The identity function is the identity element of the monoid of all functions from a set to itself. It is bijective, is its own inverse, and acts as a neutral element under function composition: for any function g, g ∘ id = id ∘ g = g.
