Martin-Löf randomness

In algorithmic information theory, a sequence of bits is called Martin-Löf random if it passes all effectively testable statistical tests for randomness. The notion was introduced by the Swedish mathematician Per Martin-Löf in 1966 and gives a rigorous definition of a random infinite sequence using computability theory.

Definition

A Martin-Löf test is a uniformly computably enumerable sequence of open sets in Cantor space whose measures shrink geometrically to zero. An infinite binary sequence passes the test if it is not contained in the intersection of all the sets. A sequence is Martin-Löf random if it passes every Martin-Löf test. There exists a universal Martin-Löf test, so the class of random sequences is characterised by a single test.

Equivalent characterisations

Martin-Löf randomness coincides with several other notions: a sequence is Martin-Löf random if and only if it is incompressible in the sense of prefix-free Kolmogorov complexity (the Schnorr–Levin theorem), and if and only if no computable martingale succeeds on it (Schnorr's theorem). The set of Martin-Löf random sequences has Lebesgue measure one.

Examples and applications

Chaitin's constant Ω is a famous example of a Martin-Löf random real number. The theory of Martin-Löf randomness founded the field of algorithmic randomness, in which weaker notions such as Schnorr randomness and computable randomness, and stronger ones such as 2-randomness, are also studied.
