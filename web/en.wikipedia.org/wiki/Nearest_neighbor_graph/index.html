Nearest neighbor graph

The nearest neighbor graph (NNG) is a directed graph defined for a set of points in a metric space: each point is connected by an edge to its nearest neighbor, the closest other point under the given distance measure. It is a basic structure in computational geometry and is closely related to the k-nearest neighbors algorithm used in machine learning and data mining.

Properties

Every vertex of the nearest neighbor graph has out-degree exactly one, so the graph consists of components each containing a single cycle of length two (a pair of mutually nearest points) with trees directed toward it, in general Euclidean settings. The NNG is a subgraph of the Delaunay triangulation and of the relative neighborhood graph, and its edges are contained in the Euclidean minimum spanning tree for the nearest-neighbor pairs. In one dimension, the NNG of sorted points is simply a path-like structure connecting adjacent values.

Variants and applications

The k-nearest neighbor graph generalizes the construction by connecting each point to its k closest points. Such graphs underlie clustering, manifold learning, similarity search, and approximate nearest-neighbor indices (for example navigable small-world graphs). The NNG also appears in the analysis of the nearest neighbour algorithm for the travelling salesman problem and in studies of percolation and spatial networks.
