Filename extension

A filename extension, file name extension or file extension is a suffix to the name of a computer file (for example, .txt, .docx, .md). The extension indicates a characteristic of the file contents or its intended use. A filename extension is typically delimited from the rest of the filename with a full stop (period), but in some systems it is separated with spaces or underscores.

Usage

Some file systems implement filename extensions as a feature of the file system itself, while others, such as Unix-like systems, treat the extension as simply a part of the file name with no special significance. Operating systems such as Windows and macOS use extensions to associate files with applications and to infer content type.

History

Early systems such as CP/M and MS-DOS limited extensions to three characters in the 8.3 filename format; modern systems allow much longer and multiple extensions, such as .tar.gz for gzipped tar archives.
