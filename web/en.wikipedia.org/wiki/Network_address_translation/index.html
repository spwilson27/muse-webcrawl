Network address translation

Network address translation (NAT) is a method of mapping an IP address space into another by modifying network address information in the IP header of packets while they are in transit across a traffic routing device. The technique was originally used to bypass the need to assign a new address to every host when a network was moved or when the upstream Internet service provider was replaced, but it became a popular tool in dealing with IPv4 address exhaustion.

Basic NAT

The simplest type of NAT provides a one-to-one translation of IP addresses. Basic NAT can be used to interconnect two IP networks that have incompatible addressing. In contrast, the most common form, often simply called NAT or IP masquerading, is port address translation (PAT), which maps many private addresses to a single public address by also translating port numbers, allowing an entire household or office to share one public IPv4 address.

Operation

When a packet from an internal host crosses the NAT device, its source address (and, in PAT, source port) is rewritten to the device's public address, and the mapping is recorded in a translation table. Reply packets arriving at the public address are matched against the table and forwarded to the correct internal host. Stateful mappings expire after a period of inactivity.

Applications and limitations

NAT is ubiquitous in home routers and mobile carrier networks (carrier-grade NAT). It complicates protocols that embed addresses in their payloads, and makes unsolicited inbound connections impossible without port forwarding, which is why techniques such as STUN, TURN, ICE, UPnP, and NAT-PMP were developed for peer-to-peer applications and voice over IP. NAT breaks the original end-to-end principle of the Internet, a point emphasised by its critics, although it also provides a degree of incidental inbound filtering.

IPv6

The enormous address space of IPv6 was designed to remove the need for NAT, restoring end-to-end connectivity; nevertheless, various IPv6 translation mechanisms (such as NAT64) exist for transition and special cases.
