ZIP (file format)

From Wikipedia, the free encyclopedia

ZIP
Filename extension: .zip
Internet media type: application/zip
Developed by: Phil Katz, PKWARE, Inc.
Initial release: 1989
Type of format: Data compression, archive

ZIP is an archive file format that supports lossless data compression. A ZIP file may contain one or more files or directories that may have been compressed. The ZIP file format permits a number of compression algorithms, though DEFLATE is the most common. This format was originally created in 1989 and was first implemented in PKWARE, Inc.'s PKZIP utility, as a replacement for the previous ARC compression format created by Thom Henderson.

History and design

Designer Phil Katz publicly released the format's technical documentation, and PKWARE maintained the specification in the freely available APPNOTE file. The format stores each file individually with a local file header, followed at the end of the archive by a central directory that records all entries, enabling random access and easy addition or deletion of files. The original format had a 4 GiB size limit, later extended by the ZIP64 extension.

The ZIP format is the basis for many other formats, including Java JAR archives, Office Open XML documents (.docx, .xlsx), OpenDocument files, and Android APK packages. Virtually all operating systems now include built-in ZIP support.
