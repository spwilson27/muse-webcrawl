Supervised learning

In supervised learning, a model is trained on labelled examples.

Supervised learning (SL) is a paradigm in machine learning where input objects (typically vectors of features) and a desired output value (also known as a human-labelled signal) are used to train a model. The training data is processed, building a function that maps new data to expected output values. An optimal scenario will allow for the algorithm to correctly determine output values for unseen instances.

Task types

The two canonical supervised tasks are classification, in which the output is a discrete category (such as "spam" or "not spam"), and regression, in which the output is a continuous value (such as a house price). Other task types include ranking, structured prediction, and sequence labelling.

Algorithms

Widely used supervised algorithms include linear and logistic regression, decision trees and random forests, support vector machines, k-nearest neighbours, naive Bayes classifiers, gradient boosting, and artificial neural networks. Each algorithm makes different assumptions about the structure of the mapping from inputs to outputs.

Generalization

The goal of training is not memorization but generalization: performing well on data not seen during training. Practitioners split data into training, validation, and test sets (or use cross-validation) to estimate generalization error, and they combat overfitting with regularization, early stopping, and limits on model complexity. The bias–variance tradeoff summarizes the tension between underfitting and overfitting.

Applications

Supervised learning powers spam filters, image and speech recognition, medical diagnosis aids, credit scoring, machine translation, and many other deployed systems.
