Singular value

In mathematics, the singular values of a matrix are the non-negative square roots of the eigenvalues of the matrix A*A (or equivalently AA*), where A* is the conjugate transpose. They are conventionally ordered from largest to smallest.

Singular value decomposition

Every real or complex matrix admits a singular value decomposition A = UΣV*, where U and V are unitary, and Σ is diagonal with the singular values on its diagonal. The number of non-zero singular values equals the rank of the matrix.

SVD underlies the pseudoinverse, low-rank approximation (Eckart–Young theorem), principal component analysis, and many algorithms in signal processing and statistics.
