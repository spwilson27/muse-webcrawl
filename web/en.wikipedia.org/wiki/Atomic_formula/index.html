Atomic formula

In mathematical logic, an atomic formula (or atom) is a formula with no deeper propositional structure — that is, a formula that contains no logical connectives or quantifiers operating on subformulas. Atomic formulas are the building blocks from which all formulas of a formal language are constructed.

Definition

In first-order logic, an atomic formula is either an equality between terms, t1 = t2, or an application of a predicate symbol to terms, R(t1, …, tn). In propositional logic, the atoms are simply the propositional variables (or truth constants). Compound formulas are formed from atoms using connectives such as ¬, ∧, ∨, → and quantifiers ∀ and ∃.

Use

Atomic formulas are significant in proof theory and model theory; for example, an atomic sentence is an atomic formula with no free variables, and the set of true atomic sentences about a structure is its atomic diagram.
