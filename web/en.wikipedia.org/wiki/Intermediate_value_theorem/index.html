Intermediate value theorem


A continuous function takes every value between f(a) and f(b)

In mathematical analysis, the intermediate value theorem states that if f is a continuous function whose domain contains the interval [a, b], then it takes on any given value between f(a) and f(b) at some point within the interval. Intuitively, a continuous function on an interval cannot "jump" over a value: its graph can be drawn without lifting the pen, so it must pass through every intermediate height.

Statement

Let I = [a, b] be a closed interval, and let f : I → ℝ be a continuous function. Let u be a number between f(a) and f(b). Then there exists a point c in [a, b] such that f(c) = u.

An equivalent form, sometimes called Bolzano's theorem, states that if f(a) and f(b) have opposite signs, then there is a point c between them with f(c) = 0 — that is, the function has a root in the interval.

History

Bernard Bolzano gave a proof in 1817, aiming to free the theorem from geometric intuition; Augustin-Louis Cauchy provided a proof in his Cours d'Analyse of 1821. Both proofs relied on the completeness of the real numbers, and the theorem is in fact equivalent to forms of that completeness property.

Proof

A standard proof takes c to be the supremum of the set of points x in [a, b] with f(x) ≤ u (assuming f(a) < u < f(b)). By continuity, f(c) can be neither less than nor greater than u, hence equals u. The bisection method, which repeatedly halves an interval on which a function changes sign, provides a constructive route to locating the root and is the basis of a practical numerical algorithm.

Applications and generalisations

The theorem guarantees solutions to equations such as x5 + x − 1 = 0 in a given interval, explains why a wobbly table can be steadied by rotating it, and motivates the bisection method in numerical analysis. The converse is false: functions with the intermediate value property (Darboux functions) need not be continuous. In topology, the theorem generalises to the statement that the continuous image of a connected space is connected.
