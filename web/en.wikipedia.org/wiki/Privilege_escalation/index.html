Privilege escalation

Privilege escalation exploits flaws to gain elevated access to protected resources.

Privilege escalation is the act of exploiting a bug, design flaw or configuration oversight in an operating system or application to gain elevated access to resources that are normally protected from an application or user. Attackers use the increased privileges to perform unauthorized actions, such as running arbitrary code, accessing sensitive data or taking full control of a system.

Types

Vertical privilege escalation, also known as privilege elevation, occurs when a lower-privileged user or application gains access to functions or content reserved for higher-privileged users — for example, when an ordinary user obtains administrator or root access. Horizontal privilege escalation occurs when a user accesses functions or content reserved for users of the same privilege level, such as one bank customer viewing another customer's account.

Techniques

Common techniques include exploiting buffer overflow vulnerabilities in privileged programs, manipulating access tokens and credentials, abusing misconfigured services and file permissions, and leveraging unpatched kernel vulnerabilities. On Unix-like systems, setuid programs and sudo misconfigurations are frequent targets; on Windows, token impersonation and insecure service permissions are common paths.

Prevention

Defences include the principle of least privilege, prompt patching, code review and secure development practices, proper configuration management, and monitoring for suspicious privilege changes. Operating systems also provide mitigations such as address space layout randomization and mandatory access control frameworks.
