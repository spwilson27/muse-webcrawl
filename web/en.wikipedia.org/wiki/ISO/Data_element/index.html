Data element

In metadata, a data element is a unit of data that, in a certain context, is considered indivisible. The concept is standardised in ISO/IEC 11179, the international standard for metadata registries, which specifies how data elements are named, defined, and registered so that data can be shared and understood consistently across systems and organisations.

The ISO/IEC 11179 model

Under ISO/IEC 11179, a data element is the combination of a data element concept (an object class plus a property—for example, "person" + "birth date") with a representation (the form of the value, such as a date format, a code list, or a unit of measure). Separating the concept from its representation lets the same underlying concept be recorded in different systems using different formats while remaining semantically equivalent. Value domains enumerate permissible values, and classification schemes organise elements within a registry.

Usage

Data element definitions underpin data dictionaries, interchange standards in health care, finance, and government, and semantic interoperability initiatives. Precise, context-independent definitions—avoiding circular or system-specific wording—are the standard's central discipline.
