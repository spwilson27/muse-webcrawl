ISO/IEC 11179

ISO/IEC 11179, Information technology — Metadata registries (MDR), is an international standard for representing metadata in a metadata registry. It provides a framework for defining data elements precisely, naming them systematically, and classifying them so that data can be understood, shared, and reused consistently across systems and organisations. The standard is published jointly by the International Organization for Standardization (ISO) and the International Electrotechnical Commission (IEC) and is maintained by ISO/IEC JTC 1/SC 32.

Overview

The standard addresses a common problem: the same concept is often given different names and definitions in different databases, while the same name may mean different things. A metadata registry maintained according to ISO/IEC 11179 records data elements with unambiguous definitions, permissible values, and classification, enabling semantic interoperability between information systems — for example across government agencies, health systems, and statistics offices.

Parts of the standard

  • Part 1: Framework — overall scope and concepts.
  • Part 2: Classification — classifying administered items using taxonomies and ontologies.
  • Part 3: Registry metamodel and basic attributes — the core model of the registry.
  • Part 4: Formulation of data definitions — rules for writing precise definitions (a definition should state what a concept is, be unambiguous, and avoid circularity or embedded definitions of other concepts).
  • Part 5: Naming and identification principles — how names are constructed.
  • Part 6: Registration — procedures and roles (such as registration authorities) for registering administered items.

The data element model

Central to the metamodel is the distinction between a data element concept — the idea, independent of any representation, formed by an object class (e.g. "person") and a property (e.g. "birth date") — and a data element, which combines the concept with a representation (the value domain, data type, and format). This separation lets one concept be realised in multiple systems with different encodings while retaining a single definition.

Naming conventions

Part 5 builds data element names from components: an object class term, a property term, a representation term (such as "date", "code", or "name"), and optional qualifiers. For example, "Person Birth Date" is composed of object class Person, property Birth, and representation term Date.

Adoption

ISO/IEC 11179 underpins metadata registries in sectors including health (such as the US National Cancer Institute's caDSR), government statistics, defence, and finance; related standards and registries such as ISO/IEC 19763 and various national data dictionaries draw on its metamodel.
