Metadata

Metadata is "data that provides information about other data", but not the content of the data itself. Within the framework of International Organization for Standardization (ISO) standards, metadata is formalised above all by ISO/IEC 11179, which governs metadata registries, and by standards such as ISO 19115 for geographic information metadata.

Types

Metadata is commonly classified as descriptive (title, author, keywords—used for discovery), structural (how components of an object are organised), and administrative (provenance, rights, preservation and technical details). The Dublin Core Metadata Element Set (ISO 15836) defines fifteen core elements for resource description across domains.

ISO standardisation

ISO/IEC 11179 defines the structure of metadata registries in which administered items—data elements, value domains, conceptual domains—are registered with identifiers, names, and definitions. ISO 19115-1 specifies schemas for describing geographic datasets and services, including identification, extent, quality, and distribution information, and is widely used for spatial data infrastructures.
