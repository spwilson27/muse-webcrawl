Windows-1252

TypeCharacter encoding
DeveloperMicrosoft
AliasCP1252
Based onISO/IEC 8859-1 (with extensions)

Windows-1252 or CP-1252 (code page 1252) is a single-byte character encoding of the Latin alphabet used by default in the legacy components of Microsoft Windows for many Western European languages. It was the most popular character encoding on the World Wide Web for many years.

Differences from ISO 8859-1

Windows-1252 is a superset of ISO/IEC 8859-1: it assigns printable characters — including the euro sign, curly quotation marks, ellipsis, dagger, and trademark sign — to the byte range 0x80–0x9F, which ISO 8859-1 reserves for control codes. Because documents labelled ISO-8859-1 frequently contained Windows-1252 bytes, the HTML5 standard formally redefined the ISO-8859-1 label to mean Windows-1252.

Decline

Since the early 2010s, UTF-8 has surpassed Windows-1252 as the dominant encoding of the web.
