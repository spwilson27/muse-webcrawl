Page (computer memory)

A page is a fixed-length contiguous block of virtual memory, described by a single entry in the page table, with the size determined by the processor architecture. Pages are the smallest unit of data for memory management in a virtual memory operating system, and the unit in which memory is allocated, protected, and transferred (paged) between main memory and secondary storage such as a hard disk or solid-state drive.

Page size

The typical page size on modern architectures, including x86-64, is 4 kilobytes (4,096 bytes). Many architectures also support larger pages—often called huge pages—of 2 megabytes or 1 gigabyte, which reduce page-table size and translation lookaside buffer (TLB) pressure for applications with large memory footprints. Historically, page sizes have ranged from 512 bytes to several megabytes depending on the system.

Paging

In a paged system, virtual address spaces are divided into pages and physical memory into page frames of the same size. The operating system's page tables map virtual pages to frames; a page fault occurs when a program accesses a page that is not currently mapped into physical memory, prompting the operating system to load it from backing store. Algorithms such as least recently used (LRU) approximation govern which pages are evicted when memory is full, a process known as swapping or paging out.

Multiple page sizes

Several modern processors allow page tables to mix base pages with large pages at different levels of the hierarchy. Operating systems such as Linux (transparent huge pages) and Windows (large pages) expose these facilities to reduce address-translation overhead.
