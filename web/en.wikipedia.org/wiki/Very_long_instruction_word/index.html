Very long instruction word

Very long instruction word (VLIW) is a computer architecture concept in which a single instruction encodes several independent operations, which the processor issues simultaneously to separate functional units. Unlike superscalar designs, in which hardware discovers parallelism at run time, in a VLIW machine the compiler schedules the parallel operations in advance.

History and examples

The concept was developed by Josh Fisher at Yale and at Multiflow Computer in the early 1980s. Examples include the Multiflow TRACE machines, the Texas Instruments TMS320 C6000 digital signal processors, the Transmeta Crusoe (which translated x86 code into VLIW internally), and, in a related explicitly parallel form (EPIC), Intel's Itanium. VLIW suits predictable workloads such as DSP, where compilers can schedule efficiently; for general-purpose code, stalls and code-size growth, and binary incompatibility between generations, limited its adoption.
