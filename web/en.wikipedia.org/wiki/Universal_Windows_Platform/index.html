Universal Windows Platform

Universal Windows Platform (UWP) is a computing platform created by Microsoft and introduced with Windows 10. Its goal is to allow developers to build applications once and run them across the range of devices running Windows 10 and Windows 11, including personal computers, tablets, smartphones, Xbox consoles, HoloLens, Surface Hub, and Internet of Things devices. UWP apps are typically distributed through the Microsoft Store and run within a sandbox with restricted access to system resources.

Design

UWP builds on the Windows Runtime (WinRT) APIs introduced with Windows 8, together with a core set of APIs common to all device families, supplemented by device-specific extension SDKs. A single app package can adapt its interface to different screen sizes and input methods using adaptive controls and layouts. UWP apps can be written in C#, Visual Basic, C++/CX or C++/WinRT, and JavaScript with HTML, and XAML is the usual language for defining user interfaces.

History

Microsoft announced the "universal app" concept at its 2014 Build conference, evolving the Windows 8 and Windows Phone app models into a single platform. With Windows 10, the company promoted the idea that developers could target hundreds of millions of devices with one binary. Microsoft later introduced bridges to bring desktop (Win32), iOS, Android, and web applications into the UWP ecosystem, including the Desktop Bridge (Project Centennial), which allows traditional desktop applications to be packaged for the Microsoft Store. In later years Microsoft increasingly promoted the Windows App SDK as the successor path for Windows application development, while UWP remained supported.
