Fast Healthcare Interoperability Resources

Developed by: HL7 (Health Level Seven International)
Initial release: 2014 (DSTU1)
Type: Health informatics interoperability standard
Formats: JSON, XML, RDF

Fast Healthcare Interoperability Resources (FHIR, pronounced "fire") is a standard developed by the health informatics organisation HL7 that describes data formats and elements (known as "resources") and an application programming interface (API) for exchanging electronic health records (EHRs). The standard was created to make health information exchange easier to implement than with the earlier HL7 version 3, by adopting modern web technologies.

Design

FHIR organises clinical and administrative data into modular resources — such as Patient, Observation, Condition, MedicationRequest, and Encounter — each defined by a standard structure of common data elements. Roughly the most common 20% of data elements are included in the base resource, while extensions allow local requirements to be represented. Implementations expose resources through RESTful APIs using JSON or XML, with defined operations for searching, reading, creating, and updating data. Implementation guides, such as the US Core profiles, constrain the standard for particular jurisdictions and use cases, and the SMART on FHIR framework adds an authorisation and app-launch model based on OAuth 2.0 and OpenID Connect, enabling third-party applications to run inside EHR systems.

Adoption

FHIR was first published as a Draft Standard for Trial Use in 2014; the fourth release, FHIR R4 (2019), was the first to contain normative content. The standard gained major regulatory backing in the United States, where rules under the 21st Century Cures Act required certified health IT to provide FHIR-based APIs for patient access, and it is supported by major EHR vendors and technology companies. Earlier versions of the Argonaut Project, an industry consortium, accelerated implementation in practice. FHIR is also used for bulk data export, clinical research, and mobile health applications.
