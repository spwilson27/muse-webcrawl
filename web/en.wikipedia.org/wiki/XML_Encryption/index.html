XML Encryption

XML Encryption, also known as XML-Enc, is a specification governed by a World Wide Web Consortium (W3C) Recommendation that defines how to encrypt the content of an XML element and represent the result in XML. It became a W3C Recommendation on 10 December 2002.

Overview

Unlike transport-level encryption such as TLS, XML Encryption allows only parts of a document to be encrypted, so that different recipients can read different portions, and encrypted content can persist while stored. When an element is encrypted, it is replaced in the document by an EncryptedData element containing a CipherData element with the ciphertext (usually base64-encoded) and an EncryptionMethod element naming the algorithm. Content keys are typically carried in an EncryptedKey element, itself encrypted with the recipient's public key, and the key information structures are shared with XML Signature (XML-DSig).

Algorithms

The specification supports block ciphers including Triple DES and AES with various key lengths, and key transport using RSA. Later maintenance work addressed weaknesses in the common CBC mode of operation; in 2011 researchers demonstrated a practical padding oracle attack against XML Encryption in CBC mode as deployed in several web-service frameworks, prompting recommendations to prefer authenticated modes and updated algorithm profiles in XML Encryption 1.1.

Applications

XML Encryption is used in WS-Security for SOAP messages and in SAML assertions, where portions of an assertion can be encrypted for a specific relying party. It is closely related to XML Signature, with which it was developed as part of the W3C's XML security work.
