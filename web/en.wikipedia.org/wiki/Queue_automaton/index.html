Queue automaton

From Wikipedia, the free encyclopedia

A queue automaton is a finite-state machine equipped with a single infinite queue, a first-in-first-out (FIFO) storage structure from which symbols may be removed only at the head and to which symbols may be appended only at the tail. Queue automata are a model of computation equivalent in power to Turing machines: any computation that can be performed by a Turing machine can be simulated by a queue automaton, and vice versa, even though the queue automaton has only one queue and a finite control.

Formal definition

A queue automaton is formally defined as a tuple consisting of a finite set of states, an input alphabet, a queue alphabet (possibly larger than the input alphabet and containing a special bottom-of-queue marker), an initial state, a set of accepting states, and a transition function. On each step, the machine reads the symbol at the head of the queue, removes it, and, depending on its current state, appends zero or more symbols to the tail of the queue and moves to a new state. Some formulations also allow the machine to read an input string initially loaded into the queue.

Computational power

Despite the restriction that data can only be accessed in FIFO order, a queue automaton is Turing complete. The key idea of the simulation is that the contents of a Turing machine tape can be represented as the contents of the queue: by repeatedly cycling symbols from the head of the queue to the tail, the machine can bring any desired cell to the head, modify it, and restore the cyclic order. This rotation technique compensates for the lack of random access, at the cost of extra steps.

Because queue automata are Turing equivalent, the halting problem for them is undecidable, and they compute exactly the recursively enumerable languages when equipped with suitable acceptance conditions.

Variants

Several restricted variants have been studied. A queue automaton with a bounded number of queue reversals or with a finite number of visits to each symbol has strictly less power. Machines combining a stack and a queue, and multi-queue automata, have also been defined; two queues already suffice for Turing completeness by direct simulation of a two-stack machine or a Turing machine tape split into two halves.
