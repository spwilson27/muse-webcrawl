Probabilistic method

Placeholder image: a random graph, a classic tool of the method

The probabilistic method is a nonconstructive method, primarily used in combinatorics and theoretical computer science, pioneered by Paul Erdős, for proving the existence of a mathematical object with specified properties. One works in a probability space of objects and shows that the probability that a random object has the desired property is positive — therefore such an object must exist, even if no explicit example is given.

Techniques

  • First moment / counting: show the expected number of "bad" events is less than the total, or use the union bound: if the probabilities of all bad events sum to less than 1, a good outcome occurs with positive probability.
  • Expectation arguments: a random variable taking values both above and below its mean guarantees extremal objects.
  • Second moment method: control the variance to show an event occurs with positive probability.
  • Alteration (deletion): take a random object and repair its few defects.
  • Lovász local lemma: if each bad event depends on only a few others and is sufficiently unlikely, all can be avoided simultaneously.

Classic example

Erdős proved lower bounds on Ramsey numbers by colouring the edges of a complete graph at random: for suitable sizes, the probability that no monochromatic clique of the target size appears is positive, so R(k, k) > 2k/2 — a bound that, despite decades of effort, has barely been improved by constructive methods.
