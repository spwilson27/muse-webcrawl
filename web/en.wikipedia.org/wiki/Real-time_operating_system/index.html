Real-time operating system

A real-time operating system (RTOS) is an operating system intended to serve real-time applications that process data as it comes in, typically without buffer delays. The key characteristic of an RTOS is not raw speed but determinism: it guarantees that high-priority tasks will execute within a bounded, predictable time.

Design principles

RTOS kernels are usually small and built around a preemptive, priority-based scheduler. Interrupt latency and context-switch times are kept minimal and bounded. Common scheduling algorithms include rate-monotonic scheduling and earliest-deadline-first scheduling. To avoid unbounded priority inversion, kernels provide mechanisms such as priority inheritance and priority ceiling protocols on mutexes.

Hard and soft real-time

In a hard real-time system, missing a deadline is a system failure — examples include flight control and anti-lock braking. In a soft real-time system, deadlines are important but occasional misses merely degrade quality, as in audio and video streaming.

Examples

Well-known real-time operating systems include FreeRTOS, VxWorks, QNX, RTEMS (used in space missions), Zephyr, and ThreadX. Real-time extensions and configurations exist for general-purpose systems, such as the Linux kernel's PREEMPT_RT patch set.
