Istio

Istio is an open-source service mesh platform that provides a uniform way to connect, secure, control, and observe microservices. It is most commonly deployed on Kubernetes, where it manages traffic between services using sidecar proxies based on the Envoy proxy.

History

Istio was announced in May 2017, developed by Google and IBM in collaboration with the Envoy team from Lyft. Version 1.0 was released in July 2018. In 2022 Google transferred the project to the Cloud Native Computing Foundation (CNCF); Istio graduated from the CNCF in July 2023. Newer releases introduced an "ambient mesh" mode that can operate without per-pod sidecars.

Architecture

Istio divides into a data plane and a control plane:

  • The data plane consists of Envoy proxies deployed alongside services (as sidecars) or, in ambient mode, as per-node proxies, intercepting all network traffic between microservices.
  • The control plane, centred on the istiod daemon, configures the proxies, distributes security certificates, and aggregates telemetry (metrics, logs, and traces).

Features

Istio provides traffic management (retries, timeouts, load balancing, traffic shifting for canary releases), security (mutual TLS authentication, authorisation policies), and observability, without requiring changes to application code.
