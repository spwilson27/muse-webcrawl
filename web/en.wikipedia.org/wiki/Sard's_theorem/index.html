Sard's theorem

Sard's theorem, also known as the Sard–Morse theorem, is a fundamental result in differential topology proved by Arthur Sard in 1942, building on work of Anthony Morse. It states that for a sufficiently smooth map between manifolds, the set of critical values has Lebesgue measure zero — in other words, almost every value is a regular value.

Statement

Let f : M → N be a Ck map between smooth manifolds of dimensions m and n, with k sufficiently large (k > max{m − n, 0}). A point x is a critical point if the differential dfx is not surjective; its image f(x) is a critical value. Sard's theorem asserts that the set of critical values of f has measure zero in N.

Applications

The theorem underlies many genericity arguments in geometry and analysis: it guarantees that regular values are dense, which is used in transversality theory, in proofs that generic smooth functions are Morse functions, in the Brouwer fixed-point theory via smooth approximations, and in the study of the structure of solutions to partial differential equations.
