Pretty Good Privacy

Original author: Phil Zimmermann
Initial release: 1991
Type: Encryption software
Standard: OpenPGP (RFC 4880)

Pretty Good Privacy (PGP) is an encryption program that provides cryptographic privacy and authentication for data communication. It is widely used for signing, encrypting and decrypting texts, e-mails, files, directories and whole disk partitions.

History

PGP was created by Phil Zimmermann in 1991 and distributed freely, spreading worldwide. Because it used strong cryptography, its export from the United States led to a criminal investigation of Zimmermann under U.S. munitions export law; the case was dropped in 1996. The source code was famously published in book form by MIT Press to exploit First Amendment protections.

How it works

PGP uses a hybrid cryptosystem: data is compressed, encrypted with a one-time symmetric session key, and the session key is encrypted with the recipient's public key. Digital signatures use a hash of the message signed with the sender's private key. Users exchange keys within a decentralised "web of trust". The OpenPGP standard underlies implementations such as GnuPG (GPG).
