Knuth–Morris–Pratt algorithm

The Knuth–Morris–Pratt algorithm (KMP algorithm) is a string-searching algorithm that searches for occurrences of a "word" W within a main "text string" S. It exploits the observation that when a mismatch occurs, the word itself embodies sufficient information to determine where the next match could begin, thus bypassing re-examination of previously matched characters. The algorithm was conceived in 1970 by Donald Knuth and Vaughan Pratt, and independently by James H. Morris; the three published it jointly in 1977.

How it works

A naive search backs up in the text whenever a partial match fails, giving worst-case quadratic behaviour. KMP instead precomputes a partial match table (also called the failure function or prefix function) for the pattern. The table records, for each position in the pattern, the length of the longest proper prefix of the pattern that is also a suffix of the substring ending at that position. On a mismatch, the algorithm shifts the pattern forward by the amount indicated in the table without ever moving backwards in the text.

Complexity

Building the table takes O(m) time and space, where m is the length of the pattern, and the search itself takes O(n) time for a text of length n — linear overall, regardless of the input. This makes KMP one of the classic efficient substring-search algorithms, alongside the Boyer–Moore algorithm, which is often faster in practice for long alphabets but has a worse worst case.

Example

For the pattern "ABABCABAB", the prefix function values are 0, 0, 1, 2, 0, 1, 2, 3, 4. When a mismatch occurs after the partial match "ABAB", the algorithm knows the first two characters "AB" are already re-matched and resumes comparison from pattern position 2 instead of starting over.
