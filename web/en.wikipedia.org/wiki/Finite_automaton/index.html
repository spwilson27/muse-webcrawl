A finite automaton (plural: automata), or finite-state machine, is a mathematical model of computation used to design computer programs and sequential logic circuits. It consists of a finite number of states, transitions between those states, and actions; the machine is in exactly one state at any time, and changes state in response to input symbols.

Definition

A deterministic finite automaton (DFA) is a 5-tuple (Q, Σ, δ, q0, F) consisting of a finite set of states Q, a finite input alphabet Σ, a transition function δ : Q × Σ → Q, a start state q0, and a set of accepting states F. A string is accepted if processing it symbol by symbol ends in an accepting state. Nondeterministic finite automata (NFAs) allow multiple or ε-transitions; a theorem of Rabin and Scott (1959) shows NFAs accept exactly the same class of languages as DFAs.

Regular languages

The languages recognised by finite automata are exactly the regular languages (Kleene's theorem), which are also those described by regular expressions and generated by regular grammars. DFAs can be minimised uniquely (up to isomorphism) by algorithms based on the Myhill–Nerode theorem. The pumping lemma provides a tool for proving that certain languages are not regular.

Applications

Finite automata underpin lexical analysis in compilers, regular-expression search, text processing, protocol and circuit design, and control systems.
