In information theory, the cross-entropy between two probability distributions p and q, over the same underlying set of events, measures the average number of bits needed to identify an event drawn from the set, if a coding scheme used for the set is optimized for an "unnatural" probability distribution q, rather than the "true" distribution p.

The cross-entropy for the distributions p and q over a given set is defined as follows:

H(p, q) = − Σx p(x) log q(x)

where the sum is over all possible events x. Cross-entropy is closely related to entropy and to the Kullback–Leibler divergence: H(p, q) = H(p) + DKL(p ‖ q). Because H(p) is fixed for a given dataset, minimizing cross-entropy with respect to a model q is equivalent to minimizing the KL divergence between the data distribution and the model.

Motivation

Suppose events occur with true probabilities p, and we design an optimal code for a distribution q that we believe (or our model predicts). Shannon's source-coding theorem says the expected code length is minimized when q = p, giving the entropy H(p). Using the wrong code costs extra bits on average; that expected length is the cross-entropy. By Gibbs' inequality, H(p, q) ≥ H(p), with equality only when the two distributions are identical almost everywhere.

Estimation

In practice the true distribution p is unknown, and cross-entropy is estimated from samples: the average negative log-probability that a model assigns to observed data. For language models this is often reported in exponentiated form as perplexity, which can be interpreted as the effective branching factor of the prediction problem.

Relation to maximum likelihood

Maximizing the likelihood of training data under a probabilistic model is mathematically equivalent to minimizing the cross-entropy between the empirical distribution of the data and the model distribution. This is why cross-entropy minimization underlies logistic regression, multinomial classification, and the training of modern neural networks.

Cross-entropy loss in machine learning

In machine learning, cross-entropy loss (also called log loss) is the standard loss function for classification. For a single example with a one-hot target vector and predicted probabilities from a softmax output layer, the loss reduces to the negative logarithm of the predicted probability of the correct class. It penalizes confident wrong predictions extremely heavily, and its gradient has a convenient form: for softmax outputs, the derivative of the loss with respect to the logits is simply (prediction − target).

Variants include binary cross-entropy for two-class problems, categorical cross-entropy for multi-class problems, sparse categorical cross-entropy when labels are integers, and label-smoothed or focal losses used to address overconfidence and class imbalance.
