Kruskal's tree theorem

Kruskal's tree theorem
FieldMathematical logic, combinatorics
Proved byJoseph Kruskal (1960)
ConsequenceTREE(3) is finite but enormous

Kruskal's tree theorem states that the set of finite trees over a well-quasi-ordered set of labels is itself well-quasi-ordered under homeomorphic embedding. It was proved by Joseph Kruskal in 1960.

Significance

The theorem is not provable in weak systems of second-order arithmetic (it exceeds ATR0), making it a notable example of a natural combinatorial statement requiring strong axioms. Harvey Friedman derived from it the finite TREE function, whose value TREE(3) is finite but so large it dwarfs a googolplex.

Related theorems

Kruskal's theorem generalises Higman's lemma and is closely related to the Robertson–Seymour graph minor theorem. Nash-Williams gave a proof using the minimal bad sequence method.
