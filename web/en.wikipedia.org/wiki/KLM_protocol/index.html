KLM protocol

The KLM protocol (or KLM scheme) is an implementation of linear optical quantum computing (LOQC), proposed in 2001 by Emanuel Knill, Raymond Laflamme, and Gerard J. Milburn. It proved that scalable quantum computation is possible using only linear optical elements — beam splitters, phase shifters, and mirrors — together with single-photon sources, photodetectors, and feed-forward, even though photons do not interact directly with one another.

Overview

In the KLM scheme, qubits are encoded in the presence or absence (occupation) of photons in optical modes. Single-qubit operations are straightforward with linear optics, but a two-qubit entangling gate such as a controlled-NOT cannot be implemented deterministically with passive linear elements alone. KLM showed that by adding ancilla photons, photon counting, and fast feed-forward — choosing later operations based on detector outcomes — a nonlinear sign-shift gate can be implemented with a success probability of 1/4, and such probabilistic gates can be boosted to near-deterministic operation using quantum teleportation with specially prepared entangled ancilla states.

Elements

The protocol's components include single-photon sources and high-efficiency photon-number-resolving detectors; the NS (nonlinear sign) gate, which applies a π phase shift only to the two-photon component of a mode; teleportation-based gate error correction; and cluster-state techniques that can reduce resource requirements. Although the original resource overhead per gate was large, later work — notably measurement-based linear optical schemes of Browne and Rudolph — reduced it dramatically, and the KLM result remains foundational because it established that linear optics plus measurement is universal for quantum computation.
