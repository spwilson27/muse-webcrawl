LaTeX

LaTeX is a document preparation system and markup language for typesetting documents, widely used in academia for the communication and publication of scientific documents, especially those containing mathematical formulas. It is built on top of the TeX typesetting system created by Donald Knuth, and was originally written in the early 1980s by Leslie Lamport at SRI International.

Overview

Unlike word processors, where formatting is applied directly, a LaTeX author writes plain text marked up with commands describing the document's logical structure — chapters, sections, figures, citations — and the system handles layout, numbering, cross-referencing and bibliography automatically. This separation of content and presentation produces consistently high-quality typography, particularly for mathematics.

Usage

LaTeX is the standard for journals and conferences in mathematics, computer science, physics, and engineering. Documents are typically compiled from .tex source files into PDF using engines such as pdfTeX, XeTeX, or LuaTeX. The Comprehensive TeX Archive Network (CTAN) hosts thousands of extension packages; BibTeX and its successors manage references.

Example

\documentclass{article}
\begin{document}
Hello, world! $E = mc^2$
\end{document}
