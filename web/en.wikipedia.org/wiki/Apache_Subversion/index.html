Apache Subversion

Apache Subversion, often abbreviated SVN, is a software versioning and revision control system distributed as open source under the Apache License. It was created by CollabNet in 2000 as a successor to CVS and became an Apache Software Foundation project in 2010.

Model

Subversion uses a centralised repository that records changes to files and directories in numbered revisions. Users check out a working copy, modify it and commit changes back to the repository. Commits are atomic, and the repository versions directory trees as well as file contents, preserving renames and metadata more faithfully than CVS had done.

Features

Subversion introduced cheap branching and tagging implemented as directory copies, versioned properties, and network access through custom protocols or WebDAV/HTTP. Its centralised model contrasts with distributed systems such as Git, in which every clone contains the full history.

Use

SVN was widely adopted by open-source projects and enterprises in the 2000s. Although Git later became dominant, Subversion remains in use, particularly where centralised control, fine-grained path-based permissions or large binary assets are priorities.
