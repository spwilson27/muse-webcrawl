Sampling error

In statistics, sampling error is the error caused by observing a sample instead of the whole population. It is the difference between a sample statistic used to estimate a population parameter and the actual but unknown value of the parameter. Sampling error occurs even in properly designed random samples, simply because a sample is only a subset of the population; it decreases as the sample size increases.

Concept

The sampling error can be estimated from the variability of the statistic across repeated samples. For a mean, the standard error — the standard deviation of the sampling distribution — provides a measure of the likely size of the sampling error. Confidence intervals and margins of error reported for surveys are built from this concept: for example, a poll reporting a margin of error of ±3 percentage points is expressing the range within which the true population value is expected to lie with a stated level of confidence.

Sampling versus non-sampling error

Sampling error is distinct from non-sampling error, which includes all other sources of inaccuracy in a study: measurement error, response error, processing mistakes, coverage problems, and sampling bias. A larger sample reduces sampling error but does nothing to reduce non-sampling error; indeed, very large samples can create a false sense of precision if non-sampling errors are significant.

Reduction

Sampling error is reduced by increasing the sample size, by using efficient sampling designs such as stratified sampling, and by reducing the variability of the quantity being measured. Because the standard error shrinks with the square root of the sample size, quadrupling the sample only halves the expected error, producing diminishing returns.
