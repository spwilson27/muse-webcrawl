Memory protection

Memory protection is a way to control memory access rights on a computer. The principal purpose of memory protection is to prevent a process from accessing memory that has not been allocated to it, so that a bug or malicious code in one process cannot corrupt the memory of another process, or of the operating system itself. It is a core feature of virtually all modern operating systems.

Mechanisms

Memory protection is usually implemented in hardware by a memory management unit (MMU), which translates virtual addresses to physical addresses and enforces per-page access permissions (read, write, execute). A process attempting an illegal access triggers a fault — on Unix-like systems, a segmentation fault — and is typically terminated. Related techniques include protection keys, capability-based addressing, address space layout randomisation (ASLR), and the execute-disable (NX/XD) bit that prevents execution of data pages, mitigating buffer-overflow attacks.

History

Early forms appeared on systems such as the Burroughs B5000 and the IBM System/360 (with storage keys), and protection rings and segmentation were elaborated on Multics. Paging-based protection became standard with virtual memory systems from the 1970s onward.
