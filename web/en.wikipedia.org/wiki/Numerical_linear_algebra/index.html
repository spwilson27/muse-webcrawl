Numerical linear algebra

Numerical linear algebra, sometimes called applied linear algebra, is the study of how matrix operations can be used to create computer algorithms which efficiently and accurately provide approximate answers to questions in continuous mathematics. It is a subfield of numerical analysis, and a type of linear algebra. Because computers use floating-point arithmetic, algorithms must be designed for stability — small errors in input or rounding should not be catastrophically amplified — a discipline shaped by pioneers such as John von Neumann, Herman Goldstine, and James H. Wilkinson.

Core problems

The field centres on a few fundamental problems: solving systems of linear equations Ax = b, by direct methods such as Gaussian elimination with pivoting, LU, Cholesky, and QR factorisations, or by iterative methods such as conjugate gradients and GMRES for large sparse systems; computing eigenvalues and eigenvectors, classically via the QR algorithm; and computing decompositions such as the singular value decomposition (SVD), used in least squares, data compression, and principal component analysis.

Software

Standard problems are solved by mature software libraries, notably BLAS (Basic Linear Algebra Subprograms) and LAPACK, which underlie most scientific computing environments including MATLAB, NumPy, and R. Randomised numerical linear algebra, which uses random sampling to obtain fast approximate decompositions of very large matrices, has become important in machine learning and data science.
