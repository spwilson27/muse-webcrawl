Fuzzy set

In mathematics, fuzzy sets are sets whose elements have degrees of membership. They were introduced by Lotfi A. Zadeh in 1965 as an extension of the classical notion of a set, in order to represent vague concepts such as "tall", "warm", or "expensive", where membership is a matter of degree rather than a sharp yes-or-no boundary.

Membership functions

A fuzzy set A in a universe X is characterized by a membership function μA : X → [0, 1], assigning each element a value between 0 (not a member at all) and 1 (full member). Common shapes for membership functions include triangular, trapezoidal, and Gaussian curves. Ordinary ("crisp") sets correspond to the special case where the membership function takes only the values 0 and 1.

Operations

Zadeh defined fuzzy versions of the standard set operations: the membership of an element in the union of two fuzzy sets is the maximum of its two memberships, in the intersection the minimum, and in the complement one minus the membership. Other choices of t-norms and t-conorms generalize the intersection and union operations.

Applications

Fuzzy sets underpin fuzzy logic and fuzzy control systems, and are used in decision-making, pattern recognition, information retrieval, and the modelling of expert knowledge and natural language.
