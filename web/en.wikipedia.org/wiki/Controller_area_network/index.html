Controller area network

A controller area network (CAN bus) is a vehicle bus standard designed to allow microcontrollers and devices — electronic control units (ECUs) — to communicate with each other's applications without a host computer. It was developed by Robert Bosch GmbH and released in 1986; the first production car using CAN, the Mercedes-Benz W140, followed in 1991.

Design

CAN is a message-based, multi-master serial protocol. Nodes broadcast frames identified by an identifier that also sets priority: when two nodes transmit simultaneously, bit-wise arbitration on the identifier ensures the higher-priority frame continues undamaged. The physical layer traditionally uses a twisted pair with differential signalling, giving good noise immunity. Classical CAN supports bit rates up to 1 Mbit/s and payloads of up to 8 bytes; CAN FD (flexible data-rate) extends payloads to 64 bytes with faster data-phase rates.

Applications

CAN is the backbone network of virtually every modern automobile, and is also used in trucks, agricultural and industrial machinery, medical devices, elevators, and embedded control systems. Higher-layer protocols such as CANopen, DeviceNet, J1939 and OBD-II diagnostics are built on it.
