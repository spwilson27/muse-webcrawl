GNU Emacs is a free software text editor and the most popular of the Emacs family of editors. It was created by Richard Stallman in 1985 as part of the GNU Project, evolving from the Emacs editor he had developed at the MIT AI Lab in the 1970s. GNU Emacs is famous for its extensibility: most of its functionality is implemented in its own dialect of Lisp, Emacs Lisp, and users can customise or extend nearly every aspect of the editor.

Features

Beyond ordinary text editing, Emacs offers syntax highlighting and specialised modes for dozens of programming languages, a macro recorder, multiple windows and buffers, a built-in file manager (dired), a mail and news reader (Gnus), an organiser (Org mode), a debugger interface, and access to a shell. Its proponents describe it, only half in jest, as "a great operating system, lacking only a decent editor" — a joke that also yielded the tongue-in-cheek "Church of Emacs".

Architecture

The core is a small C interpreter for Emacs Lisp plus display and editing primitives; everything else — the user interface, editing commands and packages — is written in Lisp and can be redefined at runtime without restarting the editor. This self-documenting, live-modifiable design made Emacs as much a programming environment as an editor and contributed to its longevity.

History

GNU Emacs was the first program released by the GNU Project. A long-running fork, XEmacs, split off in the early 1990s and was eventually discontinued, leaving GNU Emacs as the main line. Major releases continue to appear regularly, adding features such as native compilation of Lisp code (Emacs 28) and built-in language-server support via Eglot (Emacs 29).
