Redfish (specification)

Redfish is a standard designed to deliver simple and secure management for converged, hybrid IT and the Software Defined Data Center. Released by the DMTF in 2015, it provides a RESTful interface using JSON and OData for managing servers, storage, networking and other data centre hardware, and is intended as a modern successor to IPMI.

Redfish is implemented in the baseboard management controllers of servers from major vendors and is used by data centre automation tools. Its schema-based model covers systems, chassis, managers, power, cooling, firmware update and eventing.
