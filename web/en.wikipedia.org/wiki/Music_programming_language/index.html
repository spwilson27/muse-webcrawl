Music programming language

A music programming language is a programming language designed for creating music—whether by representing scores symbolically, synthesizing and processing audio, or enabling live performance. The field began with Max Mathews's MUSIC I program at Bell Labs in 1957, the first widely used computer music system, which spawned the MUSIC-N family of languages.

Score languages

Score-oriented languages describe notes and structures for later rendering. Examples include the input languages for LilyPond and MuseScore-like notation tools, Guido Music Notation, and the **kern representation used in Humdrum. Csound, descended from MUSIC IV, combines an orchestra language (instruments) with a score language and remains widely used.

Real-time synthesis and DSP languages

  • SuperCollider (James McCartney, 1996) — language plus audio server, popular for algorithmic composition and live coding.
  • ChucK (Ge Wang) — strongly timed, concurrent audio programming, used in live performance.
  • Pure Data (Miller Puckette) and its commercial sibling Max/MSP — visual patching environments for interactive music.
  • FAUST — a functional language compiling signal-processing descriptions to efficient code.
  • Extempore, TidalCycles (Haskell-based, for pattern-based live coding), and Sonic Pi (created by Sam Aaron for education and performance).

Live coding

Music programming languages are central to the practice of live coding, in which performers write and modify code on stage, often at algoraves. Environments such as TidalCycles, Sonic Pi, and FoxDot are designed so code changes map transparently to musical change.
