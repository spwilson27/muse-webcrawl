False negative

A false negative is an error in binary classification or medical testing in which a test result incorrectly indicates the absence of a condition when the condition is actually present. For example, a disease test that returns negative in an infected person has produced a false negative. It is the counterpart of a false positive, in which a test incorrectly indicates presence.

In hypothesis testing

In statistical hypothesis testing, a false negative corresponds to a type II error: failing to reject a null hypothesis that is in fact false. The probability of a type II error is denoted β, and the statistical power of the test (1 − β) measures its ability to avoid false negatives. The proportion of actual positives that a test misses is its false negative rate, closely related to the test's sensitivity: sensitivity equals 1 minus the false negative rate.

Consequences

The relative costs of false negatives and false positives depend on context. In disease screening, a false negative can delay treatment and allow spread, so tests are often designed for high sensitivity and positive results confirmed by further testing. In security screening or spam filtering, the costs may be weighted differently. Test thresholds (for example, the level of a biomarker counted as positive) trade one error type off against the other.
