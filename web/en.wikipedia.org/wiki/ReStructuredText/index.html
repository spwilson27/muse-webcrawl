reStructuredText

reStructuredText (abbreviated RST, ReST, or reST) is a file format and lightweight markup language for plaintext documentation, principally used in the Python programming community for technical documentation. It is part of the Docutils project and is the default markup used by the Sphinx documentation generator.

History

reStructuredText evolved from an earlier system called StructuredText, developed at Zope, and from Setext, an early 1990s lightweight markup language. David Goodger began developing reStructuredText and the Docutils framework in 2001, aiming for a markup that was readable in plain text yet powerful enough for structured technical documents. The file extension most commonly used is .rst.

Syntax

Section titles are marked by underlining (or overlining and underlining) a line of text with punctuation characters such as =, -, or ~. Inline markup handles emphasis (*italic*), strong emphasis (**bold**), inline literals, hyperlinks, and interpreted text roles. Directives — explicit markup blocks introduced by .. — provide images, tables of contents, code blocks, admonitions, and other constructs.

Section Title
=============

This is a paragraph with *emphasis* and **strong emphasis**.

.. note:: This is an admonition directive.

Applications

reStructuredText is used for the official Python documentation, the Linux kernel documentation (via Sphinx), and Read the Docs hosting. Tools such as Pandoc can convert it to and from formats including HTML, LaTeX, PDF, and man pages.
