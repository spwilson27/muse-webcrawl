Contour integration

Contour integration is the method in complex analysis of evaluating a definite integral along a path (contour) in the complex plane. It is the main tool for computing certain real and complex integrals that are difficult by other means.

The value of a contour integral is governed by the residues inside.

Contour integrals

∫C f(z) dz = ∫ f(γ(t)) γ′(t) dt

for a piecewise-smooth parametrised contour γ. By the Cauchy integral theorem, the integral of a holomorphic function over a closed contour is zero if no singularities are enclosed.

Methods

  • Cauchy integral formula: evaluates integrals via function values inside the contour.
  • Residue theorem: the integral equals 2πi times the sum of residues inside.
  • Jordan's lemma: justifies closing contours at infinity for oscillatory integrands.

Applications

Improper real integrals (such as ∫ sin x / x dx), Fourier transforms, inverse Laplace transforms, and counting zeros of functions via the argument principle all use contour integration.

Examples

Keyhole contours for integrals with branch cuts, semicircular contours for rational functions, and indented contours for poles on the real axis are standard techniques.
