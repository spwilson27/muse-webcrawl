Color management

Color management is the process of controlling the representation of colours across a variety of devices, such as digital cameras, computer displays, printers and offset presses, so that colours remain as consistent as possible from capture through editing to final output. It is implemented by a color management system, which transforms colour data between device-dependent colour spaces using standardised device profiles.

How it works

Each device is characterised by an ICC profile, created by calibration and profiling, which describes how its colours correspond to a device-independent reference space — the profile connection space, usually CIEXYZ or CIELAB. A colour management module (CMM) uses the source and destination profiles to translate colours, applying a rendering intent that handles out-of-gamut colours by clipping or compression. Common rendering intents are perceptual, relative colorimetric, absolute colorimetric and saturation.

Workflow

A colour-managed workflow typically involves calibrating the monitor, working in a standard space such as sRGB or Adobe RGB, soft-proofing the output, and printing with the correct media profile. The International Color Consortium, founded in 1993 by eight industry vendors, maintains the ICC profile specification, which is also an ISO standard.

Applications

Colour management is essential in professional photography, graphic design, prepress and digital cinema, and is increasingly built into operating systems (for example Windows Color System and macOS ColorSync) and consumer software.
