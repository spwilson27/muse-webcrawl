Redheffer matrix

In mathematics, a Redheffer matrix, studied by Raymond Redheffer, is a square (0,1) matrix whose entries are defined by divisibility: the entry aij is 1 if i divides j or if j = 1; otherwise it is 0.

Determinant and the Riemann hypothesis

The determinant of the n × n Redheffer matrix is equal to the value of the Mertens function M(n), the summatory function of the Möbius function. Because the Mertens function also appears in the eigenvalues of the matrix — n − 1 of whose eigenvalues can be computed exactly — the Riemann hypothesis is equivalent to a bound on the determinant: the hypothesis holds if and only if det(An) = O(n1/2+ε) for every ε > 0.

This connection makes Redheffer matrices a notable bridge between linear algebra and analytic number theory, giving a purely matrix-theoretic formulation of the Riemann hypothesis.
