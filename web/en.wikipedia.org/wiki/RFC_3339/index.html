RFC 3339

RFC 3339, titled Date and Time on the Internet: Timestamps, is a Request for Comments published by the Internet Engineering Task Force in July 2002, authored by Graham Klyne and Chris Newman. It defines a profile of the ISO 8601 standard for representing dates and times in Internet protocols, aiming to resolve ambiguities in ISO 8601 by fixing specific choices for interoperability.

Format

An RFC 3339 timestamp consists of a full date in the form YYYY-MM-DD, the letter T as a separator, a time of day in 24-hour notation HH:MM:SS with optional fractional seconds, and a mandatory time offset — either Z for UTC or a numeric offset such as +05:30. An example is 1996-12-19T16:39:57-08:00. Unlike full ISO 8601, RFC 3339 does not permit week dates, ordinal dates, or omitted components. The grammar is expressed in ABNF in the document.

Usage

RFC 3339 timestamps are used extensively in Internet standards and APIs, including Atom feeds, the JSON-based protocols of many web services, logging formats, and as the date-time format in JSON Schema and OpenAPI. Many programming languages expose RFC 3339 parsing and formatting directly, and the format is a de facto standard for machine-readable timestamps because it is unambiguous, sortable when normalized, and always carries explicit offset information.

Relation to ISO 8601

RFC 3339 is a strict subset of ISO 8601 with a few additional constraints; every conforming RFC 3339 timestamp is a valid ISO 8601 timestamp, but not vice versa. It also discusses handling of leap seconds and the special offset -00:00, which indicates an unknown local offset.
