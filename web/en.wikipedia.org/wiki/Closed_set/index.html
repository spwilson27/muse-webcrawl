Closed set

Closed set
FieldTopology
DefinitionA set whose complement is open; equivalently, a set containing all its limit points
RelatedOpen set, closure, boundary, clopen set

In geometry, topology, and related branches of mathematics, a closed set is a set whose complement is an open set. Equivalently, a set is closed if it contains all of its limit points, or if it is equal to its closure — itself together with its boundary. The notion only makes sense relative to a specified topological space in which open sets have been defined.

Properties

In any topological space, the empty set and the whole space are closed (and also open). Finite unions of closed sets are closed, and arbitrary intersections of closed sets are closed. In the real line with the usual topology, closed intervals such as [0, 1] are closed, the half-open interval [0, 1) is neither open nor closed, and a finite set of points is closed. Sets that are both open and closed are called clopen; in a connected space only the empty set and the whole space are clopen.

Uses

Closed sets are fundamental throughout analysis: a function between topological spaces is continuous if and only if the preimage of every closed set is closed; in metric spaces, sequences in a closed set whose limits exist converge to points of the set; and compactness in Hausdorff spaces is tied to closedness (compact subsets of Hausdorff spaces are closed). In algebraic geometry, closed sets in the Zariski topology are the zero sets of polynomials.
