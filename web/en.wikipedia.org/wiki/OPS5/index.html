OPS5 is a rule-based programming language for building production systems and expert systems, developed at Carnegie Mellon University in the late 1970s. Its name stands for "Official Production System". An OPS5 program consists of if–then rules ("productions") that pattern-match against a working memory of symbolic elements; at each cycle the interpreter selects a matching rule instantiation — using a conflict-resolution strategy — and fires it, modifying working memory.

History and significance

OPS5 is notable as the implementation language of the R1/XCON expert system, developed with Digital Equipment Corporation from 1978 onward to configure VAX computer systems automatically — one of the first commercially successful expert systems. Charles Forgy developed the Rete algorithm for OPS5's pattern matcher, drastically speeding up rule matching by caching partial matches; the Rete algorithm became a standard technique in rule engines. Forgy's later OPS83 extended the ideas.

Legacy

OPS5 strongly influenced later production-system languages and tools, including NASA's CLIPS and the Java-based Jess, and it helped establish the architecture — working memory, rule base, inference engine — characteristic of the expert-system boom of the 1980s.
