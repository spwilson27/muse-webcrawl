Portable Executable


Filename extensions: .exe, .dll, .sys, .ocx, .cpl. Developed by: Microsoft. Based on: COFF.

The Portable Executable (PE) format is a file format for executables, object code, and DLLs used in 32-bit and 64-bit versions of Microsoft Windows. The 64-bit extension is called PE32+. The format is a data structure that encapsulates the information the Windows loader needs to manage executable code, and derives from the Unix COFF (Common Object File Format) tradition.

Structure

A PE file begins with a legacy MS-DOS header and stub (starting with the "MZ" signature), followed by the PE signature ("PE\0\0"), a COFF file header, and an "optional header" that is in practice required for images and contains the entry-point address, image base, and data directories. These directories point to tables for imports, exports, resources, relocations, debug data, and the certificate table used for Authenticode signatures. The body is divided into named sections such as .text (code), .data, .rdata, and .rsrc (resources).

Use

PE is the native executable format of Windows NT and all its successors, and is also used by Windows CE, the UEFI firmware environment (which loads PE images), and the .NET framework, whose assemblies are PE files containing CIL bytecode and metadata. Toolchains such as MinGW produce PE files on non-Windows hosts, and projects like Wine parse the format to run Windows binaries elsewhere.
