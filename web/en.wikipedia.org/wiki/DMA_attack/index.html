DMA attack

A DMA attack is a type of side-channel attack in computer security, in which an attacker who has physical access to a computer can read from and write to its main memory by exploiting direct memory access (DMA) capabilities of peripheral buses. DMA allows hardware devices to access system memory without involvement of the CPU, so a malicious device can bypass operating-system protections that would otherwise guard memory contents.

Method

DMA attacks have been demonstrated over interfaces including FireWire (IEEE 1394), Thunderbolt, ExpressCard, and PCI Express, using devices ranging from purpose-built hardware such as PCILeech to modified peripherals. Because the attack reads raw memory, it can be used to extract encryption keys and passwords, disable screen locks, inject code, or install rootkits — often in seconds and without leaving traces on the target's disk. The vulnerability was publicized as early as 2004, when researcher Maximillian Dornseif demonstrated reading memory over FireWire.

Countermeasures

Defences include disabling unused external DMA-capable ports, physical security, and, most importantly, an input–output memory management unit (IOMMU) — such as Intel VT-d or AMD-Vi — configured by the operating system to restrict which memory regions a device may access. Modern systems implement protections such as Kernel DMA Protection on Windows and Thunderbolt security levels to mitigate these attacks.
