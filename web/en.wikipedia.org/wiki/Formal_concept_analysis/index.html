Formal concept analysis (FCA) is a principled method of deriving a concept hierarchy — a concept lattice — from a collection of objects and their properties. Introduced by Rudolf Wille in 1982 and developed by Wille, Bernhard Ganter and others at Darmstadt, it applies lattice theory and order theory to data analysis, knowledge representation and information retrieval.

Formal contexts and concepts

The starting point is a formal context: a set of objects, a set of attributes, and an incidence relation stating which objects have which attributes, often presented as a cross table. A formal concept is a pair consisting of a set of objects (its extent) and the set of attributes shared by exactly those objects (its intent), closed under the natural derivation operators. The set of all formal concepts of a context, ordered by inclusion of extents, always forms a complete lattice, the concept lattice, which can be visualised as a labelled line (Hasse) diagram.

Applications

FCA has been applied to software engineering (class hierarchy restructuring), ontology engineering, data mining, text retrieval, biology and social-network analysis. Attribute implications — dependencies of the form "every object with attributes A also has attributes B" — extracted from a context support rule discovery, and algorithms such as Ganter's Next Closure enumerate concepts and implication bases efficiently.
