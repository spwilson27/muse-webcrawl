MorphOS is a proprietary, partly open-source computer operating system produced for the Pegasos and Efika computer systems, as well as certain PowerPC-based models of Apple Macintosh computers. The core, based on the Quark microkernel, is proprietary, although several libraries and other components are open source, such as the Ambient desktop environment. It is an AmigaOS-like operating system, API-compatible with AmigaOS 3.x, and able to run many Amiga applications through its integrated 68k emulation and Trance JIT compiler.

History

Development began in 1999, when the German company bPlan and the Phase5 hardware designers sought an operating system for their planned PowerPC Amiga successor. The first release appeared in August 2000, initially supporting Phase5's BlizzardPPC and CyberStormPPC accelerator boards for classic Amiga computers. MorphOS subsequently became the native operating system of the Pegasos platform, produced by Genesi. Version 2.0, released in 2008, added support for the Efika 5200B and introduced the NetStack TCP/IP stack; version 2.4 brought support for Apple's Mac Mini G4, and later releases added eMac, Power Mac G4/G5, iBook and PowerBook models.

Components

MorphOS is built on the Quark microkernel, which provides memory protection between the kernel tasks themselves but runs the Amiga-compatible "ABox" environment in a single address space for speed and compatibility. Its native graphics system is based on TinyGL and the Rave3D-compatible Reggae multimedia framework handles audio and video codecs as modular classes. The desktop, Ambient, is a MUI-based file manager and desktop environment modelled on Workbench but considerably extended, supporting multiple views, previews, and advanced file handling.

Applications

MorphOS ships with a suite of applications including the Wayfarer web browser (based on WebKit), the IRIS email client, the Jukebox audio player, and the Sketch paint program. A bundled software development kit targets both MorphOS-native and Amiga-compatible APIs.

Reception

Within the post-Commodore Amiga community, MorphOS was one of the principal PowerPC successors to the classic system, competing and coexisting with AmigaOS 4 and the open-source AROS. It has been praised for its efficiency on low-power hardware and its high degree of application compatibility with legacy Amiga software.
