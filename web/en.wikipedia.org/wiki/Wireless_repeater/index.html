Wireless repeater

A wireless repeater (also called a wireless range extender or range expander) is a device that takes an existing signal from a wireless router or wireless access point and rebroadcasts it to create a second network. When two or more hosts have to be connected with one another over the IEEE 802.11 protocol and the distance is too long for a direct connection to be established, a wireless repeater is used to bridge the gap.

A consumer wireless range extender

Operation

The repeater listens for frames from the primary access point and retransmits them on the same or a different channel, and likewise forwards client traffic back to the access point. Because a single-radio repeater must receive and then retransmit each frame on the same channel, the maximum throughput available to clients behind the repeater is typically reduced by about half. Dual-band extenders can mitigate this by using one band for the backhaul link and the other for serving clients.

Applications

Wireless repeaters are used in homes and businesses to extend coverage into areas where the original signal is weak or obstructed, such as upper floors, basements, and large buildings. They require no wired connection to the main network, which makes installation simple, but correct placement is important: the repeater must itself be located where it can receive a good signal from the base station. In modern installations, wired access points and mesh networking systems often provide better performance for the same coverage goal.
