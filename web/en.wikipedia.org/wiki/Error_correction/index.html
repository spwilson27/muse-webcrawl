Error correction

In information theory and telecommunications, error correction is the process of detecting errors in transmitted or stored data and reconstructing the original, error-free data. It is commonly combined with error detection under the heading error detection and correction, and is essential wherever data passes over an unreliable channel or is stored on a fallible medium, from deep-space communications to CDs, DVDs, QR codes and computer memory.

Forward error correction

In forward error correction (FEC), the sender encodes the message in a redundant way using an error-correcting code, adding check data that allows the receiver to detect and correct a limited number of errors without retransmission. Classic codes include Hamming codes, Reed–Solomon codes, convolutional codes decoded with the Viterbi algorithm, and modern capacity-approaching codes such as turbo codes and LDPC codes. FEC is one-way and is used where retransmission is impossible or expensive, such as satellite links and broadcast.

Automatic repeat request

An alternative strategy, automatic repeat request (ARQ), detects errors and asks the sender to retransmit corrupted frames. ARQ is used in protocols such as TCP/IP networks' link layers and is often combined with FEC in hybrid schemes.

Applications

Error correction underpins reliable digital communication and storage: ECC memory corrects single-bit errors in RAM, Reed–Solomon coding protects optical discs and barcodes, and deep-space missions rely on powerful codes to recover signals received at extremely low power.
