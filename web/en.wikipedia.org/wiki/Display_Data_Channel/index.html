Display Data Channel

The Display Data Channel (DDC) is a collection of protocols for digital communication between a computer display and a graphics adapter that enables the display to communicate its supported display modes to the adapter and that enables the computer host to adjust monitor parameters, such as brightness and contrast.

Protocol versions

DDC1, introduced in 1994, transmitted the display's Extended Display Identification Data (EDID) continuously over a single data pin. DDC2 switched to the I2C bus, allowing the host to query the display on demand; later revisions unified under E-DDC with segment addressing for larger data structures.

DDC/CI

The DDC/CI (Command Interface) extension allows a computer to send commands to adjust monitor settings such as brightness, contrast, and input selection, and to read status information such as the monitor's model and operating hours. It is based on the Monitor Control Command Set (MCCS) standard.

Usage

DDC signals are carried on dedicated pins of VGA, DVI, HDMI, and DisplayPort connectors. Operating systems use the retrieved EDID to automatically select a suitable resolution and refresh rate when a display is connected.
