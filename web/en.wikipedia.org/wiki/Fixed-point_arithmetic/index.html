Fixed-point arithmetic

In computing, fixed-point is a real data type for a number that has a fixed number of digits (or bits) after — and sometimes before — the radix point. A fixed-point representation is essentially an integer scaled by a fixed factor: for example, the value 12.34 might be stored as the integer 1234 with an implicit scaling of two decimal places. The position of the point is fixed by convention for all numbers of the type, in contrast to floating-point representation, in which the point can move and an exponent is stored.

Notation

Fixed-point formats are commonly described in Q notation: Qm.n denotes a signed number with m integer bits and n fractional bits. Thus Q1.15 — one sign/integer bit and fifteen fractional bits — is the classic format for signal-processing values between −1 and just under +1, and Q16.16 gives a 32-bit number with a range of about ±32,768 and a resolution of about 1/65,536.

Operations

Addition and subtraction of fixed-point numbers use ordinary integer arithmetic. Multiplication produces a result with twice the fractional bits, which must be shifted and rounded or truncated back to the working format; division is correspondingly more involved. Because the representable range is small, overflow is a constant hazard, and programmers must track the range of every quantity — the payoff is speed and simplicity on hardware without a floating-point unit, exact representation of decimal fractions such as tenths, and perfectly reproducible results across platforms.

Applications

Fixed-point arithmetic was the norm in early computers and remains standard in embedded systems, digital signal processors, financial software (where exact decimal representation of currency is required), and many game engines and graphics pipelines of the 1990s — the original PlayStation's geometry hardware, for instance, worked in fixed point. Languages such as COBOL and PL/I, and SQL's DECIMAL type, provide native fixed-point decimal types, while in C and C++ fixed-point work is usually done with integer types and explicit scaling, or with libraries.
