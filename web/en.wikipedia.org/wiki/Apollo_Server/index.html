Apollo Server is an open-source, spec-compliant GraphQL server library for JavaScript and TypeScript, developed by the company Apollo GraphQL (formerly Meteor Development Group). It lets developers build a GraphQL API by defining a schema and resolver functions, and can run standalone or integrated with frameworks such as Express, Fastify, Koa and serverless platforms.

Features

Apollo Server supports queries, mutations and real-time subscriptions, schema federation (combining multiple services' schemas into one graph), persisted queries, caching, and request tracing and metrics through Apollo Studio. Version 4, released in 2022, was a major rewrite with a modular plugin and integration API following the project's earlier versions built around Express middleware.

Ecosystem

It is the server counterpart to Apollo Client, the widely used GraphQL client for React and other front-end frameworks, and is used in production by many large web services. The project is maintained on GitHub under the MIT License.
