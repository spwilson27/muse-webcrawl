Syntax highlighting

Syntax highlighting is a feature of text editors, integrated development environments, and other software that displays source code or structured text in different colours and fonts according to the category of each term. Keywords, comments, strings, and numbers are typically distinguished, making code easier to read, navigate, and debug.

Function

Highlighting is usually generated by a lexical analyser or parser that classifies tokens in real time as the user types. By emphasising structure, it helps programmers spot errors such as unmatched delimiters or misused keywords. Early examples appeared in editors of the 1980s; a notable early system was LEXX for mainframe systems, and live syntax colouring became standard in editors such as Emacs and Vim and in modern IDEs.

Design considerations

Colour schemes vary widely and can be customised; designers must account for readability, colour-vision deficiency, and contrast. On the web, libraries such as Pygments and highlight.js render highlighted code in documentation and code-hosting sites.
