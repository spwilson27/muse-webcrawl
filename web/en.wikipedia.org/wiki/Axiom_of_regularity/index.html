Axiom of Regularity

The axiom of regularity, also called the axiom of foundation, is one of the axioms of Zermelo–Fraenkel set theory. It was introduced by Dmitry Mirimanoff in 1917 and in its modern form by John von Neumann in 1925. It states that every non-empty set A contains an element that is disjoint from A:

∀x (x ≠ ∅ → ∃y (y ∈ x ∧ y ∩ x = ∅))

Consequences

The axiom rules out pathological sets such as a set that contains itself (x ∈ x) and infinite descending membership chains ··· ∈ x3 ∈ x2 ∈ x1. Together with the other axioms it implies that every set belongs to some level of the von Neumann cumulative hierarchy, in which sets are built up in stages starting from the empty set; each set can then be assigned an ordinal rank. This justifies proof techniques such as ε-induction (set induction).

Status

No contradiction arises if the axiom is omitted; relatively consistent non-well-founded set theories, such as Aczel's theory with the anti-foundation axiom, permit sets like the unique set Ω with Ω = {Ω}. Regularity is rarely needed for ordinary mathematics outside set theory, but it greatly simplifies the structure theory of the set-theoretic universe and is standard in ZF and ZFC.
