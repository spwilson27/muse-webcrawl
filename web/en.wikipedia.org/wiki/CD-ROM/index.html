CD-ROM

Media type: Optical disc
Capacity: ~650–700 MB
Standard: Yellow Book (1985)
Developed by: Philips, Sony

A CD-ROM (compact disc read-only memory) is a type of read-only memory consisting of a pre-pressed optical compact disc containing data. CD-ROMs became a standard distribution medium for software, games and multimedia from the late 1980s through the 1990s.

Format

The format, defined in the 1985 "Yellow Book", builds on the audio CD (Red Book) with additional error correction, holding around 650 to 700 MB. The ISO 9660 file system was standardised for cross-platform use. Discs are read by a laser in a CD-ROM drive at multiples of the original 150 KB/s "1×" speed.

History

CD-ROMs enabled encyclopaedias, games with full-motion video, and large software distributions before writable CDs (CD-R, CD-RW), DVDs and downloads displaced them in the 2000s.
