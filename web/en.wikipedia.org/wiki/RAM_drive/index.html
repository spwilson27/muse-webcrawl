RAM drive

RAM drive
TypeSoftware / hardware storage device
MediumVolatile random-access memory
Also calledRAM disk

A RAM drive (also called a RAM disk) is a block of a computer's random-access memory that the operating system treats as if it were a disk drive. Because RAM is far faster than magnetic or even solid-state storage, a RAM drive offers extremely high read and write speeds, at the cost of capacity and of volatility: the contents are normally lost when power is removed or the system restarts.

Implementations

Software RAM disks have existed since the early personal computer era — for example RAMDRIVE.SYS in MS-DOS and the tmpfs and ramfs filesystems in Linux — and are still used for temporary files, caches, browser profiles and build directories where speed matters more than persistence. Dedicated hardware RAM drives with battery backup and flash shadow copies were sold as accelerators before fast SSDs became common.

Advantages and drawbacks

Besides speed, RAM drives produce no mechanical wear and operate silently. Their capacity is limited to a portion of installed memory, however, and data placed on them must be copied elsewhere if it is to survive shutdown.
