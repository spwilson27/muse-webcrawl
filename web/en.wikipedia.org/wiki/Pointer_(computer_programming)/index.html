Pointer (computer programming)

In computer science, a pointer is an object in many programming languages that stores a memory address, usually the location of another value in computer memory. A pointer references a location in memory, and obtaining the value stored there — dereferencing the pointer — is a fundamental operation in low-level programming. Pointers are a central feature of the C and C++ languages, where they support dynamic memory allocation, arrays, strings, data structures such as linked lists and trees, and efficient passing of large data to functions.

A pointer variable holds the memory address of the value it points to.

ConceptMemory address stored as a value
Key operationsAddress-of (&), dereference (*)
Typical languagesC, C++, Pascal, Go, assembly
Null valueNULL / nullptr / nil

Basic use in C

int x = 42;
int *p = &x;   /* p holds the address of x */
printf("%d", *p); /* dereferencing p prints 42 */
*p = 7;           /* writes through the pointer: x is now 7 */

Pointer arithmetic — adding or subtracting integers scaled by the size of the pointed-to type — underlies array handling in C, where arrays and pointers are closely related. Function pointers store the address of executable code and are used for callbacks, dispatch tables, and implementing polymorphism in C.

Special kinds of pointers

  • Null pointer: a pointer value (NULL, nullptr) that points to nothing; dereferencing it is an error, called "the billion-dollar mistake" by its inventor, Tony Hoare.
  • Dangling pointer: a pointer to memory that has been freed or has gone out of scope; using it causes undefined behaviour.
  • Void pointer: a generic pointer (void *) to an object of unspecified type.
  • Smart pointers: in C++, objects such as std::unique_ptr and std::shared_ptr that manage the lifetime of the pointed-to object automatically.
  • References: safer, restricted pointer-like aliases in languages such as C++, Java, and Rust, which generally cannot be null or reassigned.

Safety and security

Because pointers allow unrestricted access to memory, pointer errors — buffer overflows, use-after-free, double-free, and uninitialised pointers — are a leading source of crashes and of exploitable security vulnerabilities. Many high-level languages therefore hide pointers entirely behind references and garbage collection, while newer systems languages such as Rust retain explicit pointers within a compile-time-checked ownership system.

History

Indirect addressing existed in machine architecture from the earliest stored-program computers; pointers as a language construct appeared in the 1950s–60s (for example in PL/I) and were made central by C (1972), whose design reflected the memory model of the PDP-11. The concept contrasts with the GUI "pointer" (see Pointer (user interface)) and with the typographic unit discussed under Point (typography).
