Computer font

From Wikipedia, the free encyclopedia

A digital font file contains glyphs, metrics, and kerning for a typeface

A computer font is implemented as a digital data file containing a set of graphically related glyphs. A computer font is designed and created using a font editor. A computer font specifically designed for the computer screen, and not for printing, is a screen font. In the terminology of movable metal type, a font is a set of pieces of type that implement a particular typeface at a particular size and weight, whereas in digital typography a single font file typically implements one style (such as regular, bold, or italic) of a typeface family and can be scaled to any size.

Types of fonts

  • Bitmap fonts — each glyph is stored as a raster image (pixel pattern) for a specific size and resolution. They render quickly and were standard on early systems, but scale poorly; they survive in embedded devices and terminal emulators.
  • Outline (vector) fonts — glyph shapes are defined by mathematical curves (Bézier curves), so one file serves at every size. The major formats are TrueType (quadratic curves, developed by Apple and Microsoft), PostScript Type 1 (cubic curves, from Adobe), and OpenType, which unifies the two and adds advanced typographic features such as ligatures and alternate glyphs.
  • Stroke fonts — glyphs defined by skeletal lines of uniform or varying width, used mainly in engraving, CAD, and some East Asian typography.

Font files and features

Beyond glyph outlines, font files contain metrics (advance widths, bearings, ascenders and descenders), kerning pairs, hinting instructions that align outlines to the pixel grid at small sizes, and — in OpenType fonts — substitution and positioning tables for complex scripts and fine typography. Modern developments include variable fonts, which pack a continuous range of weights and widths into one file, and colour fonts, whose glyphs carry colour information. Web fonts are delivered in compressed formats such as WOFF and WOFF2 via the CSS @font-face rule.

History

Digital fonts emerged in the 1970s with bitmap faces for displays and early typesetters. The field was transformed in the 1980s by PostScript and the Apple LaserWriter (1985), which brought outline fonts to desktop publishing, and by TrueType (1991), which standardized scalable fonts in consumer operating systems. OpenType followed in the late 1990s. Because font software is copyrighted (and, in the United States, designs themselves receive only limited protection), licensing and piracy of fonts remain active commercial and legal topics.
