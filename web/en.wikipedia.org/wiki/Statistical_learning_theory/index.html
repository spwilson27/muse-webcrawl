Statistical learning theory

Statistical learning theory is a framework for machine learning drawing from the fields of statistics and functional analysis. It deals with the problem of finding a predictive function based on data, and provides the theoretical foundations for understanding when and how learning from examples is possible.

Framework

The theory was pioneered by Vladimir Vapnik and Alexey Chervonenkis in the 1960s and 1970s. A learner observes training examples drawn independently from an unknown distribution and selects a function from a hypothesis class that minimises empirical risk — the average loss on the training data. The central question is how well the empirical risk approximates the true expected risk, so that the chosen function generalises to new data.

Key concepts

The VC dimension measures the capacity of a hypothesis class: the size of the largest set of points it can shatter. Generalisation bounds relate the gap between training and test error to the VC dimension and the number of training examples. Related complexity measures include Rademacher complexity and PAC learning, a parallel framework introduced by Leslie Valiant. The theory underlies algorithms such as support vector machines, which maximise the margin to control capacity.
