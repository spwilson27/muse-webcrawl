Edge coloring

In graph theory, an edge coloring of a graph is an assignment of "colors" to the edges of the graph so that no two incident edges share the same color. An edge coloring is proper if adjacent edges always receive different colors. The smallest number of colors needed for a proper edge coloring is called the chromatic index, denoted χ′(G). Each color class in a proper edge coloring forms a matching.

Vizing's theorem

By a theorem of Vadim Vizing (1964), the chromatic index of any simple graph with maximum degree Δ is either Δ or Δ + 1. Graphs needing only Δ colors are called class 1; those needing Δ + 1 are class 2. Deciding which class a graph belongs to is NP-complete in general, even for cubic graphs, although many families are known to be class 1: bipartite graphs (by König's line coloring theorem, χ′ = Δ for all bipartite graphs), most complete graphs, and planar graphs of sufficiently large degree.

Examples and special cases

  • The complete graph Kn has chromatic index n − 1 when n is even and n when n is odd.
  • The Petersen graph is class 2 — it needs four colors although its maximum degree is three.
  • "Snarks" are bridgeless cubic class-2 graphs with additional properties; the Petersen graph is the smallest snark.
  • For multigraphs, Shannon's theorem gives the bound χ′ ≤ 3Δ/2.

Applications

Edge coloring models scheduling problems in which pairwise interactions must be assigned time slots — for example, scheduling sports fixtures, timetabling examinations, and assigning wavelengths or registers in networks and compilers. A round-robin tournament schedule for an even number of teams is exactly an edge coloring of a complete graph.
