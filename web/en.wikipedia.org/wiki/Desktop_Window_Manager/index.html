Desktop Window Manager

Desktop Window Manager (DWM, previously Desktop Compositing Engine or DCE) is the compositing window manager in Microsoft Windows since Windows Vista that enables the use of hardware acceleration to render the graphical user interface. It is implemented as the Windows service Desktop Window Manager Session Manager and runs as the process dwm.exe.

Architecture

Under DWM, applications draw into off-screen buffers (redirection surfaces) rather than directly to the display. The DWM composites these buffers into the final desktop image using the graphics processing unit via DirectX, applying effects such as transparency and window animations. Because every window's content is retained in a buffer, the system can display live thumbnail previews in the taskbar and Alt-Tab switcher, and features such as Windows Flip 3D, without asking applications to repaint.

Features and requirements

DWM underlies the Windows Aero interface introduced with Vista, providing glass transparency, fluent window animations and high-DPI scaling support. It requires a graphics card with a suitable driver (originally WDDM) and pixel shader support. In Windows Vista and Windows 7 the composition could be disabled, reverting to a basic theme; from Windows 8 onwards, desktop composition is always on and is also used in the pre-login environment and on the Start screen. DWM also manages multi-monitor rendering, colour calibration passthrough for professional applications, and the presentation of protected video content.
