Ray transfer matrix analysis


A ray traced through a lens using ABCD matrices.

Ray transfer matrix analysis (also known as ABCD matrix analysis) is a mathematical method in geometrical optics for tracing a light ray through an optical system. The state of a paraxial ray at a plane is described by its height from the optical axis and its angle with the axis; each optical element is then represented by a 2×2 matrix acting on this vector.

The ABCD matrix

For an element, the output ray (height x₂, angle θ₂) is related to the input ray by a matrix with elements A, B, C, D. Free-space propagation over distance d has matrix [1, d; 0, 1]; refraction at a spherical surface and reflection have matrices involving the surface power; a thin lens of focal length f has matrix [1, 0; −1/f, 1]. The matrix of a complete system is the product of the element matrices in reverse order of traversal.

Applications

The method determines system focal lengths, cardinal points, magnification, and imaging conditions (imaging occurs when B = 0). It is widely used in the design of cameras, telescopes, microscopes, and laser resonators, where the related round-trip ABCD matrix governs beam stability and Gaussian beam propagation via the complex beam parameter.
