64b/66b encoding

In data networking and transmission, 64b/66b encoding is a line code that transforms 64-bit data into a 66-bit line code in order to provide clock recovery and alignment of the data stream. Unlike the older 8b/10b encoding, which carries a 25% overhead, 64b/66b has an overhead of only about 3%, making it well suited to high-speed links.

Operation

Each 66-bit block consists of a 2-bit synchronization header followed by a 64-bit payload. A sync header of "01" indicates a pure data block, while "10" indicates a block containing eight control characters (or a mixture of control and data, identified by a block-type field). The payload is scrambled with a self-synchronous scrambler polynomial (x58 + x39 + 1) to ensure adequate transition density for clock recovery; the sync header itself is not scrambled, which guarantees that block boundaries can be found regardless of the payload content.

Applications

64b/66b was introduced with 10 Gigabit Ethernet (IEEE 802.3ae) and has since been adopted by many other standards, including later Ethernet variants, Fibre Channel, InfiniBand, Thunderbolt, Serial RapidIO, and many Aurora and inter-chip links. A variant, 128b/130b encoding, is used by PCI Express 3.0 and later, and 128b/132b is used by USB 3.1.
