Line code

In telecommunication, a line code is a code chosen for use within a communications system for transmitting a digital signal down a transmission line. Line coding converts a sequence of bits into a physical waveform—typically a pattern of voltage, current, or light levels—suitable for the channel, and the process is usually carried out before modulation or other channel coding.

Desired properties

A good line code provides frequent signal transitions so that the receiver can recover the clock, avoids a DC component where the channel cannot pass DC, limits occupied bandwidth, and helps detect (or resist) transmission errors. Common trade-offs involve overhead: block codes such as 8b/10b add extra bits to guarantee balance and transitions, while scrambling achieves similar effects without fixed overhead.
