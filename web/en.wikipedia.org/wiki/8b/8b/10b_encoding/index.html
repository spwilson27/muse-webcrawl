8b/10b encoding

In telecommunications, 8b/10b is a line code that maps 8-bit words to 10-bit symbols to achieve DC balance and bounded running disparity, while providing enough state changes to allow reasonable clock recovery. It was invented by Al Widmer and Peter Franaszek of IBM in 1983, and IBM holds a patent on one implementation of it.

How it works

The encoder splits each byte into a 5-bit and a 3-bit part, which are encoded as 6-bit and 4-bit symbols (5b/6b and 3b/4b encoding). The encoder tracks the running disparity — the difference between the number of ones and zeros sent — and selects symbol encodings to keep the transmitted signal DC-balanced, which prevents baseline wander in AC-coupled links and guarantees frequent transitions for clock recovery.

Control symbols

Some 10-bit symbols are reserved as control characters (the K codes, such as K28.5) that cannot result from encoding any data byte. These are used for framing, alignment, and special functions such as the comma character used for symbol synchronization.

Applications

8b/10b encoding has been widely used in Fibre Channel, Gigabit Ethernet (1000BASE-X), InfiniBand, Serial ATA, PCI Express (generations 1 and 2), USB 3.0, and DisplayPort. Later high-speed standards largely moved to more efficient schemes such as 64b/66b and 128b/132b encoding, which carry much lower overhead than 8b/10b's 25%.
