In coding theory, the BCH codes or Bose–Chaudhuri–Hocquenghem codes form a class of cyclic error-correcting codes constructed using polynomials over a finite field (Galois field). BCH codes were invented in 1959 by French mathematician Alexis Hocquenghem, and independently in 1960 by Raj Chandra Bose and Dwijendra Kumar Ray-Chaudhuri. The acronym BCH comprises the initials of these inventors' surnames.

Construction

One of the key features of BCH codes is that during code design, there is precise control over the number of symbol errors correctable by the code. In particular, it is possible to design binary BCH codes that can correct multiple bit errors. Another advantage is the ease with which they can be decoded via an algebraic method known as syndrome decoding, which allows simple, low-power electronic decoder hardware — one reason BCH codes are used in flash memory, solid-state drives, QR codes, CDs and DVDs, satellite communications and deep-space links. The Reed–Solomon codes used on optical discs are a non-binary special case of BCH codes.

Decoding

Decoders compute a syndrome from the received word; if the syndrome is zero, no errors are detected. Otherwise, algorithms such as Peterson's algorithm, the Berlekamp–Massey algorithm, or the extended Euclidean algorithm find an error-locator polynomial, whose roots identify the erroneous positions, after which error values can be corrected (for non-binary codes, via Forney's algorithm). BCH decoding fails gracefully: if errors exceed the designed correction capability, the decoder either detects the failure or, with some probability, miscorrects.
