Point process

In probability and statistics, a point process is a mathematical model for a random collection of points scattered in some mathematical space, typically Euclidean space, time, or a combination such as space-time. Point processes are used to model phenomena whose occurrences are localised — for example, the times of earthquakes, the locations of trees in a forest, or the arrivals of customers at a service point.

Definitions and examples

Formally, a point process can be defined as a random counting measure: for each region of the space, it returns the random number of points falling in that region. The simplest and most fundamental example is the Poisson point process, in which points in disjoint regions are independent and the counts follow Poisson distributions. Other important families include renewal processes (on the real line), Cox processes, in which the intensity is itself random, Gibbs point processes, which model interaction between points, and determinantal point processes, which exhibit repulsion.

Applications

Point process theory underpins spatial statistics, queueing theory, telecommunications (modelling network nodes and call arrivals), neuroscience (spike trains), astronomy (galaxy distributions), and epidemiology (case locations).
