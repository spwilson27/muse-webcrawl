Bfloat16 floating-point format

The bfloat16 (brain floating point) floating-point format is a computer number format occupying 16 bits in computer memory; it represents a wide dynamic range of numeric values by using a floating radix point. This format is a truncated (16-bit) version of the 32-bit IEEE 754 single-precision floating-point format (binary32) with the intent of accelerating machine learning and near-sensor computing.

Definition

The bfloat16 format keeps the full 8-bit exponent of binary32, giving it roughly the same dynamic range as single precision, while reducing the explicit significand (mantissa) from 23 bits to 7 bits. Conversion between bfloat16 and binary32 is therefore simple: a bfloat16 value is just the high 16 bits of the corresponding binary32 value, rounded or truncated.

Usage

Because deep learning workloads are relatively insensitive to reduced mantissa precision but benefit greatly from reduced memory bandwidth and increased arithmetic throughput, bfloat16 became a standard format for training neural networks. It is supported natively by Google's Tensor Processing Units (TPUs), Intel processors and accelerators, NVIDIA GPUs (Ampere generation and later), AMD accelerators, and ARM architectures. It is widely used in frameworks such as TensorFlow and PyTorch.

Comparison with fp16

Compared to the IEEE half-precision format (fp16), which has a 5-bit exponent, bfloat16 offers a much larger range at the cost of precision, making it suitable for gradient values during training without loss scaling.
