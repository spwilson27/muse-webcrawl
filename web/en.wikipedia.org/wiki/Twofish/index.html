Twofish is a symmetric key block cipher with a block size of 128 bits and key sizes up to 256 bits. It was one of the five finalists of the Advanced Encryption Standard contest, but was not selected for standardisation, losing to Rijndael (AES). Twofish was designed by Bruce Schneier, John Kelsey, Doug Whiting, David Wagner, Chris Hall and Niels Ferguson; it is a successor to Schneier's earlier Blowfish cipher.

Design

Twofish is a 16-round Feistel network with a bijective F function made of four key-dependent 8-by-8-bit S-boxes, a maximum distance separable (MDS) matrix multiplication, a pseudo-Hadamard transform and key addition. Distinctive features include precomputed key-dependent S-boxes and a carefully scheduled key expansion. The cipher was designed to be efficient across platforms, from large processors to smart cards and hardware.

The designers placed Twofish in the public domain, and reference implementations are freely available. It has been incorporated into open-source cryptography libraries such as GnuPG, and into disk-encryption software.

Security

As of recent cryptanalysis, the best published attacks on full Twofish are related-key attacks that do not threaten practical use; reduced-round versions have been attacked more deeply. Twofish has never been broken in a practical sense, and its security margin — a deliberate part of the design philosophy — remains respected, though the cipher sees less use than AES because it lacks hardware acceleration on modern processors.
