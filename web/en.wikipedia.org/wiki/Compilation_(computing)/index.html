Compilation (computing)

In computer programming, a compilation is the process of transforming source code written in a programming language into another computer language, usually machine code that can be executed directly by a computer's central processing unit. The program that performs this translation is called a compiler.

The compilation process

A compiler typically performs several phases:

  • Lexical analysis – the source text is converted into a stream of tokens by a lexer, which discards whitespace and comments and classifies characters into identifiers, keywords, literals, and operators.
  • Syntax analysis (parsing) – the token stream is organized, according to the grammar of the language, into a parse tree or abstract syntax tree (AST) by a parser.
  • Semantic analysis – the compiler checks the tree for semantic consistency, performing operations such as type checking and building symbol tables.
  • Intermediate representations – the program is lowered through one or more intermediate representations (IR), on which machine-independent optimizations such as constant folding, dead-code elimination, and loop optimization are performed.
  • Code generation – optimized IR is translated into target machine code or assembly, including instruction selection, register allocation, and instruction scheduling.
  • Linking – a linker combines object files and libraries into a final executable, resolving references between compilation units.

Types of compilation

Ahead-of-time (AOT) compilation translates a program before it is run, as is traditional for languages such as C, C++, and Rust. Just-in-time (JIT) compilation translates code during program execution, a technique used by the Java virtual machine, the .NET Common Language Runtime, and JavaScript engines such as V8. A cross compiler runs on one platform (the host) but generates code for a different platform (the target). Languages that translate to another high-level language are said to use a source-to-source compiler or transpiler.

Compilation versus interpretation

Compiled languages contrast with interpreted languages, in which an interpreter executes the program directly without producing a separate machine-code executable. Many modern implementations blur the distinction: bytecode compilation followed by JIT execution, as in Java and CPython (which compiles source to bytecode), combines elements of both approaches.
