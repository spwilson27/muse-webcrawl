In logic and computability theory, a problem, theory, or set is decidable if there exists an effective procedure (algorithm) that always terminates and correctly answers, for every input, whether it belongs to the set or whether a statement is true or provable. A problem for which no such procedure exists is undecidable.

Decidable and undecidable theories

Propositional logic is decidable, for example by truth tables. Several important first-order theories are also decidable, including Presburger arithmetic (arithmetic with addition only), the theory of real closed fields (shown decidable by Alfred Tarski, encompassing elementary geometry), and the theories of algebraically closed fields of fixed characteristic. By contrast, full first-order logic is undecidable: by the negative solution to the Entscheidungsproblem (Church and Turing, 1936), there is no algorithm that decides whether an arbitrary first-order sentence is valid. Peano arithmetic is undecidable, and by Gödel's incompleteness theorems no consistent, effectively axiomatized theory strong enough to contain arithmetic is both complete and decidable.

Semi-decidability

A set or problem is semi-decidable (recursively enumerable) if an algorithm exists that confirms membership whenever it holds, though it may run forever on non-members. The set of theorems of first-order logic is semi-decidable: proofs can be enumerated, so every valid sentence will eventually be certified, but invalidity may never be established.

Significance

Decidability results delimit what can be automated in mathematics and computer science. They underlie the theory of computation (Turing machines, the halting problem), automated theorem proving and satisfiability solving—where decidable fragments are industrially important—and they connect to complexity theory, which asks not merely whether a decision procedure exists but how efficient it can be.
