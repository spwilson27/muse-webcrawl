Cumulative distribution function

[Image: Graph of the cumulative distribution function of a normal distribution, an S-shaped curve rising from 0 to 1]

In probability theory and statistics, the cumulative distribution function (CDF) of a real-valued random variable X is the probability that X will take a value less than or equal to x:

FX(x) = P(X ≤ x)

Every probability distribution on the real numbers is completely characterised by its CDF. For a continuous distribution, the CDF is the integral of the probability density function.

Properties

Every CDF satisfies the following properties: it is monotonically non-decreasing; it is right-continuous; it tends to 0 as x → −∞ and to 1 as x → +∞. Conversely, any function with these properties is the CDF of some random variable. The probability that X falls in a semi-open interval (a, b] is F(b) − F(a).

Examples

The uniform distribution on [0, 1] has CDF F(x) = x on that interval. The exponential distribution with rate λ has CDF F(x) = 1 − e−λx for x ≥ 0. For the standard normal distribution the CDF is commonly written Φ(x) and is related to the error function; it has no closed form in elementary functions and is evaluated numerically or from tables.

Inverse

The generalised inverse of the CDF is the quantile function; for continuous strictly increasing CDFs the inverse gives the value below which a given proportion of the distribution lies, so that the median is F−1(0.5). Sampling from the inverse CDF is a standard method of generating random variates on a computer.

Empirical CDF

The empirical distribution function estimates the true CDF from a sample; by the Glivenko–Cantelli theorem it converges uniformly to the true CDF as the sample size grows.
