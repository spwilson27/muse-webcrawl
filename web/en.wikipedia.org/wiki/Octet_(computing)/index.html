Octet (computing)

An octet in computing is a unit of digital information consisting of exactly eight bits. The term is used in contexts where the size of a byte is ambiguous or must be specified precisely, since historically some computer architectures used bytes of other sizes.

Terminology

On virtually all modern platforms a byte is eight bits, making "byte" and "octet" interchangeable in practice. Nevertheless, standards documents — especially in telecommunications and networking — prefer "octet" for precision. French and several other languages use octet as the ordinary word for the unit, and file sizes in French software are expressed in octets (Mo for megabytes, and so on).

Networking usage

Internet Protocol addresses are described in octets: an IPv4 address consists of four octets, conventionally written in decimal as in 192.0.2.1. The Internet standards (RFCs) use "octet" throughout, and the term also appears in the ASN.1 data type OCTET STRING.

Values

An octet can represent 256 distinct values, from 0 to 255 as an unsigned integer, or −128 to 127 in two's complement signed form.
