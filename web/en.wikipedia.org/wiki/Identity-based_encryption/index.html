Identity-based encryption

Identity-based encryption (IBE), also called identity-based cryptography, is a type of public-key cryptography in which a publicly known string representing an individual or organization is used as a public key. The public string could include an email address, domain name, or a physical IP address.

History

The concept was proposed by Adi Shamir in 1984, but he was able only to give an instantiation of identity-based signatures; identity-based encryption remained an open problem for nearly twenty years. The first practical solutions were given in 2001 by Dan Boneh and Matthew Franklin, using bilinear pairings on elliptic curves, and independently by Clifford Cocks, whose scheme relied on quadratic residues.

Usage

IBE uses a trusted private key generator (PKG), which holds a master secret and issues each user a private key derived from their identity string. A sender can encrypt a message to "bob@example.com" before Bob has even obtained his private key, eliminating the need for certificate directories required by conventional public key infrastructure. The central drawback is that the PKG can decrypt all messages (key escrow), so IBE is most suitable within organizations that already trust a central authority.
