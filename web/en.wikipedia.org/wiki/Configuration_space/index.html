Configuration space

From Wikipedia, the free encyclopedia


The configuration space of a two-jointed planar arm is a torus

In classical mechanics, a configuration space is the space of possible positions that a physical system may attain, possibly subject to external constraints. The configuration space of a typical system has the structure of a manifold; a single point in it specifies the positions of all particles or components of the system at an instant.

Examples

For a single particle moving in three-dimensional space, the configuration space is ℝ³. For N free particles it is ℝ3N. A rigid body has configuration space ℝ³ × SO(3) (position plus orientation). A double pendulum has configuration space a torus, since each joint angle is periodic. The dimension of the configuration space equals the number of degrees of freedom of the system.

Uses

Configuration space is the setting for Lagrangian mechanics: a system's motion is a curve in its configuration space, and adding velocities yields the tangent bundle, while Hamiltonian mechanics takes place on phase space, the cotangent bundle. In robotics, configuration space (often called C-space) generalizes to the set of all poses of a robot; motion planning becomes the problem of finding a path through C-space that avoids regions corresponding to collisions with obstacles. The topology of configuration spaces of points (for example, related to braid groups) is also an active area of pure mathematics.
