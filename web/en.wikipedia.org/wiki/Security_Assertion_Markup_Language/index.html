Security Assertion Markup Language

AbbreviationSAML
TypeXML-based authentication and authorisation standard
DeveloperOASIS Security Services Technical Committee
VersionsSAML 1.0 (2002), 1.1 (2003), 2.0 (2005)

Security Assertion Markup Language (SAML, pronounced "sam-el") is an open standard for exchanging authentication and authorisation data between parties — in particular between an identity provider (IdP), which verifies a user's identity, and a service provider (SP), which delivers an application. It is the basis of most enterprise web single sign-on (SSO) systems.

How it works

In the most common flow (the Web Browser SSO profile), a user who requests a protected application is redirected by the service provider to their identity provider with a SAML authentication request. After the user logs in — typically once, with corporate credentials and possibly multifactor authentication — the IdP returns a digitally signed XML assertion stating who the user is and what attributes (such as group memberships or email) they have. The service provider validates the signature and grants access without ever seeing the user's password.

Versions and use

SAML 1.0 was approved as an OASIS standard in 2002; SAML 2.0, released in 2005, merged earlier work including the Liberty Alliance's Identity Federation Framework and remains the current version. SAML is widely used for federated identity in government, higher education (for example the InCommon and eduGAIN federations), and corporate SaaS access. Newer systems often prefer OpenID Connect, built on OAuth 2.0 and JSON, but SAML remains deeply embedded in enterprise environments.
