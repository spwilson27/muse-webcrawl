Y combinator

In lambda calculus, the Y combinator is a fixed-point combinator: a higher-order function that, given a function, returns a fixed point of that function. It allows anonymous functions to refer to themselves, thereby enabling recursion in languages (or calculi) without named function definitions. It was discovered by Haskell Curry and is commonly written:

Y = λf. (λx. f (x x)) (λx. f (x x))

How it works

Applying Y to a function g yields Y g, which satisfies the fixed-point equation Y g = g (Y g). The "generator" g describes one step of a recursive definition in terms of a not-yet-recursive argument; Y ties the knot, supplying g's own output as that argument. Under call-by-value evaluation, direct application of Y loops forever, so practical strict languages use the variant known as the Z combinator, which inserts an extra lambda to delay evaluation.

Significance

The Y combinator demonstrates that recursion can be derived from pure function abstraction and application alone, a foundational result for computability theory and programming language semantics. Fixed-point combinators exist in many forms (Curry's Y, Turing's Θ combinator) and the concept generalizes to recursive types. The startup accelerator Y Combinator, founded by Paul Graham, took its name from this construct.
