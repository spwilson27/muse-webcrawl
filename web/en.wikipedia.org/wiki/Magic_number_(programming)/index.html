Magic number (programming)

In computer programming, a magic number is a numeric value that appears directly in source code without explanation of its meaning, making the code harder to read, understand, and maintain. The term also has other technical senses, including constants used to identify file formats (such as the ELF header bytes) and unique values used as error or sentinel markers.

As an anti-pattern

Using unexplained literals is widely considered an anti-pattern. If the same value appears in several places, changing it requires finding and updating every occurrence, with a risk of missing one. Style guidance therefore recommends replacing magic numbers with named constants whose names explain the value's purpose — for example, writing MAX_STUDENTS = 30 rather than the bare number 30.

Other senses

In file formats, a magic number is a constant embedded at a fixed position in a file to identify its type; examples include the bytes 0x7F 'E' 'L' 'F' for ELF executables and the eight-byte signature of PNG images. Programmers also use the term for arbitrary "magic" values chosen to be distinctive in memory, such as 0xDEADBEEF, to help debugging.
