Channel I/O

Channel I/O offloads data transfer work from the CPU

Channel I/O is a generic term for a high-performance input/output (I/O) architecture used on mainframe computers, most famously in IBM's System/360 and its successors. Instead of requiring the central processing unit to manage every transfer, channel I/O delegates I/O operations to specialized processors called channels (or channel subsystems).

Operation

The CPU issues a single Start I/O instruction pointing to a program of channel command words (CCWs) stored in memory. The channel then executes this program autonomously—transferring data between memory and peripheral devices, chaining commands, and handling device-specific details—and interrupts the CPU only when the whole operation completes or an error occurs.

Advantages

By freeing the CPU from byte-by-byte supervision of slow peripheral devices, channel I/O lets the processor spend its time on computation while many transfers proceed concurrently. The design strongly influenced later bus-mastering and direct memory access schemes.
