Channels on IBM Z

IBM Z mainframes retain the channel I/O architecture introduced with the System/360: all input and output is performed by a channel subsystem made up of subchannels and channel paths, which execute channel programs concurrently with the central processors. Modern IBM Z systems support several hundred channel paths and tens of thousands of subchannels (devices) per machine.

Channel subsystem

The channel subsystem is implemented by dedicated system-assist processors and I/O firmware. Each device is represented by a subchannel that stores its status and pending I/O state; the operating system (z/OS, z/VM, or Linux on IBM Z) starts work with START SUBCHANNEL and receives completion through I/O interruptions or the transport-mode protocols used by zHPF. I/O configuration is defined with the Hardware Configuration Definition (HCD) and loaded as the I/O configuration data set (IOCDS) at power-on reset.
