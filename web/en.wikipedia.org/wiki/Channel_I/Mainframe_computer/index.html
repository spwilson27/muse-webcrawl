Mainframe computer

Mainframe computer
TypeLarge-scale computer system
First prominent systemsIBM System/360 (1964)
Typical usesBanking, insurance, government, bulk transaction processing
Key traitsHigh I/O throughput, reliability, backward compatibility

A mainframe computer, informally called a mainframe or big iron, is a large computer system designed primarily for bulk data processing, enterprise resource planning, and large-scale transaction processing by governments and corporations. Mainframes are distinguished by high reliability, security, and massive input/output capacity rather than raw floating-point speed.

Channel I/O

A defining feature of classic mainframe architecture, pioneered by IBM's System/360 and System/370, is channel I/O: dedicated channel processors (channel subsystems) execute channel programs made of channel command words to transfer data between memory and peripheral devices independently of the central processors. This offloads I/O work from the CPU and allows the machine to sustain very high transaction rates.

Modern mainframes

Modern systems such as IBM Z continue the architecture with virtualization, hardware cryptography and support for running thousands of Linux instances alongside traditional operating systems such as z/OS. Despite predictions of decline, mainframes still process a large share of the world's banking and credit-card transactions.
