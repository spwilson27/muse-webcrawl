FICON

FICON (Fibre Connection) is the name IBM gives to its implementation of the ANSI FC-SB-3 single-byte command code sets mapping protocol for Fibre Channel, used to connect IBM mainframe computers to storage and other peripheral devices. Introduced in 1998 as the successor to the copper-based ESCON channel, FICON maps the traditional mainframe channel architecture and its command-word protocols onto a Fibre Channel fabric, giving much higher data rates and longer distances than ESCON while preserving compatibility with the existing channel programming model.

FICON channels connect a mainframe to storage over a Fibre Channel fabric

Characteristics

FICON channels attach through a switched fabric or point-to-point links and can be extended over metropolitan distances with dense wavelength-division multiplexing. Because the protocol preserves the architecture of parallel and ESCON channels, existing channel programs run unchanged, while the underlying transport uses standard Fibre Channel frames and switches.

zHPF

High Performance FICON (zHPF) is a revised transport protocol that reduces the number of sequences exchanged per I/O operation, substantially increasing small-block I/O rates on flash storage. FICON also supports cascaded directors, channel-to-channel connections for coupling and data sharing, and FICON tape and printer attachments.
