Direct memory access

DMA lets devices move data without the CPU copying each byte

Direct memory access (DMA) is a feature of computer systems that allows certain hardware subsystems to access main system memory independently of the central processing unit (CPU). Without DMA, the CPU would have to copy each piece of data between a device and memory itself, keeping it busy during slow I/O operations.

Operation

A DMA controller is programmed by the CPU with a source, a destination, and a byte count. The controller then performs the transfer directly, arbitrating for the memory bus as needed, and typically signals completion with an interrupt. Modern systems use bus-mastering devices that perform DMA without a separate central controller.

Relation to channel I/O

DMA is the microcomputer-era counterpart of the channel I/O architecture pioneered on IBM mainframes, in which dedicated channel processors executed entire I/O programs. DMA is simpler: it transfers blocks of data, while channel processors interpret command chains and manage devices more autonomously.

Uses

DMA is used by disk and network controllers, graphics hardware, and sound devices—essentially any subsystem that moves large amounts of data at high speed.
