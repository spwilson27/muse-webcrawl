Channel I/O

Channel I/O is a high-performance input/output architecture used by IBM and compatible mainframe computers. In a channel system, input and output operations are handled by specialized processors, called channels, which execute their own small programs (channel programs) stored in main memory. This frees the central processing unit (CPU) from the details of data transfer: the CPU merely initiates an I/O operation and is interrupted when it completes. Channel I/O was introduced with the IBM 709 in 1958, generalized by the System/360 in 1964, and is still used, in modernized form, by IBM Z systems.

Organization of a channel-based I/O system

Concepts

  • Channel – an independent processor that executes channel programs and transfers data between devices and main storage (see direct memory access).
  • Channel program – a sequence of channel command words (CCWs) specifying operations such as read, write, control, and sense, with command chaining and data chaining.
  • Subchannel – the channel subsystem's representation of a single device, holding its status and I/O state.
  • Control unit – logic that manages one or more physical devices and presents them to the channel through a standard interface.

Operation

To start I/O, the operating system builds a channel program in memory and issues a start instruction (START I/O on early systems, START SUBCHANNEL on later ones). The channel subsystem fetches and executes the CCWs, arbitrating for storage cycles, and the device transfers data concurrently with CPU execution. Completion, errors, and device events are reported through I/O interruptions and status words, allowing deep overlap of computation and I/O across hundreds of devices.

Implementations

Early channels were separate cabinets; later they were integrated into the processor as a channel subsystem. Physical channel technologies progressed from the parallel (bus-and-tag) interface through ESCON to FICON over Fibre Channel. Similar channel concepts appeared on computers from CDC, UNIVAC, and other mainframe manufacturers, but the term is most closely associated with the IBM mainframe line.
