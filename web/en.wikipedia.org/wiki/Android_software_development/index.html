Android software development is the process by which applications are created for devices running the Android operating system. Apps are principally written in Kotlin — Google's preferred language since 2019 — or Java, using the Android software development kit (SDK). Code, resources and data are packaged into an APK file or, for distribution through Google Play, an Android App Bundle.

Development tools

The official integrated development environment is Android Studio, based on IntelliJ IDEA and released by Google in 2014 as the successor to Eclipse-based tooling. It provides a layout editor, an emulator, profiling tools and the Gradle-based build system. The Android SDK supplies platform libraries, the ADB debugging bridge and command-line tools. The Native Development Kit (NDK) allows portions of an app, such as game engines, to be written in C or C++.

Application architecture

Android apps are built from components: activities (single screens with a user interface), services (background operations), broadcast receivers (responses to system-wide announcements) and content providers (structured data sharing). Components communicate through intents. Every app declares its components and required permissions in an AndroidManifest.xml file, and runs in its own Linux process and security sandbox under a unique user ID.

Since 2017 Google has promoted a recommended app architecture built on the Jetpack libraries — including LiveData, ViewModel and Room — and since 2021 the declarative Jetpack Compose toolkit for building user interfaces. Kotlin coroutines and Flow are the standard approach to asynchronous work.

Distribution

Most apps are distributed through Google Play, which requires a developer account and, since 2021, App Bundle publishing for new apps. Alternative stores and direct ("sideloaded") APK installation are also supported, subject to device settings and regional regulation. Oracle's long-running lawsuit against Google over the use of Java APIs in Android ended in 2021, when the U.S. Supreme Court held in Google v. Oracle that the copying constituted fair use.
