PostScript (PS) is a page description language and dynamically typed, stack-based programming language developed by Adobe Systems. It is used primarily in desktop publishing and electronic printing: a PostScript program describes the text, vector graphics and images of a page in a device-independent way, and a raster image processor (RIP) in the printer or imagesetter renders it at the device's resolution.

PostScript describes pages as programs; the same file can be rendered at proof or press resolution.

History

PostScript grew out of work by John Warnock and Charles Geschke at Xerox PARC on the Interpress language. After founding Adobe in 1982 they created a simpler, commercially practical design, released in 1984. Apple's LaserWriter (1985), the first printer with a PostScript interpreter, together with the Aldus PageMaker application and the Macintosh, ignited the desktop publishing revolution. Adobe published the specification (the "Red Book"), making PostScript an industry standard; its font technology, Type 1, was initially proprietary.

The language

PostScript uses reverse Polish (postfix) notation: operands are pushed onto a stack and operators consume them, e.g. 100 200 moveto 300 200 lineto stroke. The language is Turing-complete, with dictionaries, procedures and dynamic typing. Successive versions — Level 2 (1991) and PostScript 3 (1997) — added colour management, compression and improved halftoning. Encapsulated PostScript (EPS) packages a single page or graphic for inclusion in other documents.

Legacy

The Portable Document Format (PDF) was designed as a successor that keeps PostScript's imaging model but replaces the programming language with a static, structured file format. PostScript remains in use in professional printing and influenced later display systems such as NeXT's Display PostScript.
