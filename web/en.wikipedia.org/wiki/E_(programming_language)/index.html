E is an object-oriented programming language for secure distributed computing, created by Mark S. Miller and others at Electric Communities in 1997. E combines message-based computation with a capability-based security model: the only way to interact with an object is through references held as unforgeable capabilities, so authority is conveyed only by connectivity.

Design

E was originally developed for Electric Communities' "E" secure desktop and virtual-world platform (EC Habitats), drawing on the Joule language and on an earlier language called Original-E used internally. After Electric Communities released the language as open source, E continued to evolve as a research vehicle for secure distributed programming.

The language's most distinctive feature is its treatment of concurrency and distribution through vats — event-loop containers that process messages one at a time, avoiding locks and race conditions. References to objects in other vats are "eventual references": sending a message to one returns a promise immediately, and the message is delivered when the remote vat runs its event loop. This model, often called the "eventual-send" or promise pipelining model, influenced later designs including the Waterken Web Calculus and actor-model languages such as Pony.

Security model

Because E integrates object-capability security into the language itself — no ambient authority, no global mutable state accessible by default, and references that act as both designation and authorization — programs written in E are intended to be analyzable for security properties following the principle of least authority (POLA).
