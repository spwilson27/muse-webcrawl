Knuth–Morris–Pratt algorithm

In computer science, the Knuth–Morris–Pratt algorithm (or KMP algorithm) is a string-searching algorithm that searches for occurrences of a "word" W within a main "text string" S. It exploits the observation that when a mismatch occurs, the word itself embodies sufficient information to determine where the next match could begin, thus bypassing re-examination of previously matched characters.

Description

The algorithm preprocesses the pattern to build a partial match table (the "failure function") recording, for each position, the length of the longest proper prefix of the pattern that is also a suffix of the substring ending there. Scanning then runs in time linear in the combined lengths of text and pattern, O(n + m).

History

The algorithm was conceived in 1970 by Donald Knuth and Vaughan Pratt, and independently by James H. Morris; the three published it jointly in 1977.
