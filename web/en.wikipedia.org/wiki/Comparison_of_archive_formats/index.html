Comparison of archive formats

[Image: Archive format icons]

An archive file format is a file format that combines multiple files into one, often with compression, to facilitate storage and transfer. This article compares the principal archive formats by their features, including compression methods, support for encryption, recovery records, splitting into volumes, preservation of file-system metadata and licensing.

Features vary in practice by implementation: for example, solid compression (treating all files as one data stream) improves ratios in 7z, RAR and tar-compressor combinations but slows random access. Disk image formats such as ISO 9660 and features like Unicode filename support, sparse-file handling and archive comments are also compared in the full treatment.
