Metric-compatible typeface

Metric-compatible typefaces are fonts designed to have exactly the same advance widths (and often the same heights and line spacing) as another typeface, so that a document laid out in one font can be rendered in the other without text reflow. Such fonts are usually created as free-software substitutes for widely used proprietary fonts, whose designs are protected but whose metrics are not always practically avoidable.

Examples

  • Liberation fonts — metric-compatible with Microsoft's Arial, Times New Roman, and Courier New; developed for Red Hat and now maintained by Google as the Croscore fonts (Arimo, Tinos, Cousine).
  • Carlito and Caladea — Google's metric-compatible substitutes for Calibri and Cambria.
  • Gelasio — metric-compatible with Georgia.
  • Liberation Serif/Sans are frequently bundled with LibreOffice to replace Times New Roman and Arial in documents.

Purpose

Metric compatibility ensures that documents created on systems with proprietary fonts (typically Microsoft Office) display and print identically on systems using free fonts (such as Linux with LibreOffice), preserving page counts, line breaks, and table layouts. Because only the metrics are matched, the substitute font's appearance may differ in detail while occupying exactly the same space.
