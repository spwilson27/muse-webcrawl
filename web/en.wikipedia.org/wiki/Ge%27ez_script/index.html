Ge'ez script

TypeAbugida
LanguagesGe'ez, Amharic, Tigrinya, Tigre, Oromo (historically)

The Ge'ez script (ግእዝ, Gəʽəz) is an abugida originally developed to write the Ge'ez language, the classical liturgical language of Ethiopia and Eritrea. It is now used principally for Amharic and Tigrinya, and remains in liturgical use in the Ethiopian Orthodox Tewahedo Church and the Eritrean Orthodox Tewahedo Church.

History

The script derives from the South Arabian alphabet, which reached the Horn of Africa in the first millennium BC. Early inscriptions in the Kingdom of Aksum were written in an unvocalised consonantal form; by the 4th century AD, during the reign of Ezana, the script had developed its characteristic vocalised syllabic characters (fidäl).

Structure

Each consonant has a basic form that can be modified in seven vocalic orders to indicate the following vowel. The core syllabary contains 26 consonantal characters, giving over 180 basic syllabograms, supplemented by labialised variants. Numerals in the traditional Ethiopic system are written with separate characters.
