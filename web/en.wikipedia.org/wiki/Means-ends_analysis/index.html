Means-ends analysis

Means-ends analysis (MEA) is a problem-solving technique used in artificial intelligence and cognitive psychology for limiting search in artificial intelligence programs. It works by detecting the difference between the current state and the goal state, then selecting an operator (action) known to reduce that difference. It was a central component of the General Problem Solver (GPS), the influential 1959 program by Allen Newell, J. C. Shaw, and Herbert A. Simon.

How it works

The solver maintains a "difference table" linking differences to operators that reduce them. The process proceeds recursively:

  1. Compare the current state with the goal state and identify the most important difference.
  2. Select an operator relevant to reducing that difference.
  3. If the operator's preconditions are not met in the current state, set a new subgoal of satisfying them, and solve that subgoal (again by means-ends analysis).
  4. Apply the operator and repeat until the goal state is reached.

This recursive goal stacking allows problems to be decomposed: when an obstacle blocks progress toward the main goal, the solver works on the obstacle as a subgoal, then returns to the main task.

History and influence

GPS demonstrated that a single, domain-general heuristic could solve puzzles such as the Tower of Hanoi, logic proofs, and mission-and-cannibals problems. Newell and Simon argued in Human Problem Solving (1972) that human protocol data showed people using the same strategy, making MEA an early bridge between AI and cognitive psychology. Means-ends analysis underlies later systems including STRIPS planners, Soar, and many hierarchical task network planners, and the idea of working backward from goal differences appears in domains from route planning to instructional design ("backward design").

Limitations

Interacting subgoals can defeat simple means-ends analysis: an operator may reduce one difference while increasing another (the classic example being the Sussman anomaly in block stacking). Pure MEA also relies on having an adequate difference–operator table, which may be difficult to construct for real-world domains.
