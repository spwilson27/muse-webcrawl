In computing, plain text is a loose term for data (e.g. file contents) that represent only characters of readable material but not its graphical representation nor other objects (floating-point numbers, images, etc.). It may also include a limited number of "whitespace" characters that affect simple arrangement of text, such as spaces, line breaks, or tabulation characters.

Plain text is different from formatted text, where style information is included in "rich text", from structured text, where some parts of a document are interpreted as having definite structure (such as headings in HTML), and from binary files, in which some portions must be interpreted as binary objects (encoded integers, real numbers, images, etc.).

Encoding

Historically, plain text files in English used the ASCII character set, which has only 128 characters; the encoding of text for other languages and for typographic characters was long handled by a patchwork of code pages. The near-universal modern encoding is UTF-8, which is backward-compatible with ASCII. The term "plain text" is sometimes loosely used for any file readable without specialised software, in contrast to binary formats.

Uses

Plain text is the format of source code, configuration files, log files, and markup documents such as HTML, which are stored as plain text with embedded structure. In cryptography, "plaintext" has a distinct technical meaning: the unencrypted input to a cipher, as opposed to ciphertext.
