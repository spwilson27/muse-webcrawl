Address space

In computing, an address space defines a range of discrete addresses, each of which may correspond to a single memory location, a network host, a peripheral device, a disk sector, or other logical or physical entity. A process or device is assigned an address space of its own, distinct from the address spaces of others, so that each can operate independently.

Types

A physical address space corresponds to actual hardware memory, while a virtual address space is the set of virtual addresses a process can use, translated to physical addresses by the memory management unit through page tables. Flat address spaces provide a single continuous range, whereas segmented architectures divide addresses into segments with offsets.

Address space size

The size of an address space is determined by the number of address bits: a 32-bit architecture provides 4 GiB of addressable space, while 64-bit architectures provide a vastly larger space, of which current implementations use only a portion (typically 48 bits of virtual addressing).
