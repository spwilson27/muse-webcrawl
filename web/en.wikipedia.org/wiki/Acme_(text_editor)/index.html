Acme is a text editor and graphical shell for the Plan 9 from Bell Labs operating system, designed and implemented by Rob Pike. It is notable for its radical integration of mouse-driven interaction — including mouse chording — and for treating all text on screen as potentially executable commands or meaningful addresses.

Acme's tiled windows, each with a tag line of executable commands.

Design

Acme windows are tiled automatically, and each window has a "tag" line containing text commands. The three mouse buttons have distinct roles: button 1 selects, button 2 executes the clicked text as a command, and button 3 "plumbs" the clicked text — opening a file, jumping to an address, or searching. Chords of buttons perform cut, paste and other editing operations. There is no conventional menu bar, and almost any visible text can serve as a command, filename or address argument.

Acme exposes a file-system interface (via Plan 9's 9P protocol) through which external programs can create windows, insert text and respond to events, making it a programmable environment for building mail readers, debuggers, wiki clients and other tools. Its plumbing subsystem routes messages between applications based on pattern-matching rules.

Influence and ports

Acme shipped with Plan 9 and was later ported to Unix-like systems as part of Plan 9 from User Space (plan9port). Its ideas influenced later experimental editors and interfaces that treat text as an interface in itself.
