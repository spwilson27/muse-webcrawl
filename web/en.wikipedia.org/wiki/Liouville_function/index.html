Liouville function

The Liouville function, denoted by λ(n) and named after Joseph Liouville, is an important function in number theory. If n is a positive integer with prime factorisation n = Π piai, then λ(n) = (−1)a1 + a2 + ... + ak: that is, λ(n) is +1 if the total number of prime factors of n, counted with multiplicity, is even, and −1 if it is odd. By convention λ(1) = 1.

Properties

The Liouville function is completely multiplicative, and it is related to the Möbius function. Its summatory function L(n) = Σk≤n λ(k) is connected with the Riemann hypothesis through identities involving series over the integers; the conjecture that L(n) ≤ 0 for all n ≥ 2 (Pólya's conjecture) was famously disproved, with the smallest counterexample found to exceed 9 × 108.

Dirichlet series

The Dirichlet series for λ(n) is ζ(2s) / ζ(s), where ζ is the Riemann zeta function.
