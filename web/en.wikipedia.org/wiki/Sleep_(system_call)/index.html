Sleep (system call)

Sleep is a system call and library function that causes the calling process or thread to suspend execution for a specified interval of time. While asleep, the process consumes essentially no CPU time; the operating system schedules other work until the timer expires or an event interrupts the sleep.

Implementations

On Unix and POSIX systems, sleep(seconds) suspends the process for a whole number of seconds and is defined in the C library, traditionally implemented via the alarm mechanism or nanosleep. Higher-resolution variants include usleep (microseconds, now deprecated) and nanosleep, which takes a timespec and can report the unslept remainder if interrupted by a signal. The underlying Linux system calls are nanosleep and clock_nanosleep.

On Windows, the equivalent is the Sleep(milliseconds) function in kernel32.dll. Most programming languages expose sleep facilities, such as time.sleep() in Python, Thread.sleep() in Java, and std::this_thread::sleep_for in C++.

Behaviour and caveats

A sleep may return early if the process receives a signal, and the actual delay may exceed the requested interval depending on system load and timer granularity. Historically, thread sleep functions such as early Unix sleep interacted badly with SIGALRM and multiple threads, leading to thread-safe, higher-resolution interfaces. Sleep is not a synchronization primitive: programs use it for polling delays, pacing, and backoff, but condition variables and event loops are preferred for waiting on work.
