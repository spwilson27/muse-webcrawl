Discriminant function analysis

Discriminant function analysis (DFA), also known as discriminant analysis, is a statistical technique used to classify observations into predefined groups based on a set of predictor variables. It was introduced in a series of papers by Ronald Fisher in the 1930s.

Overview

The method constructs one or more discriminant functions — linear combinations of the predictors — that maximise the separation between groups relative to the variation within groups. New observations are assigned to the group for which their discriminant score (or posterior probability) is most favourable.

Linear discriminant analysis

Linear discriminant analysis (LDA) assumes that the predictor variables are multivariate normally distributed within each group with a common covariance matrix, yielding linear decision boundaries. Quadratic discriminant analysis (QDA) allows each group its own covariance matrix, producing quadratic boundaries.

Applications

DFA is used in pattern recognition, marketing research, medical diagnosis, finance (such as bankruptcy prediction via Altman's Z-score), and the biological sciences. It is closely related to principal component analysis, logistic regression, and multivariate analysis of variance (MANOVA).
