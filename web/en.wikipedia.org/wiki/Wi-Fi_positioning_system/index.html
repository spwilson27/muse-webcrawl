Wi-Fi positioning system

A Wi-Fi positioning system (WPS) is a geolocation system that uses the characteristics of nearby Wi-Fi hotspots and other wireless access points to discover where a device is located. It is commonly used alongside, or as an alternative to, satellite navigation systems such as GPS, particularly indoors and in dense urban areas where satellite signals are weak or blocked.

Methods

The most common technique is based on measuring the received signal strength (RSSI) from multiple access points and comparing it against a database that records the geographic locations of access points (identified by BSSID/MAC address). Approaches include trilateration from estimated distances, and fingerprinting, in which the pattern of signal strengths at a location is matched against a previously surveyed radio map. More recent standards exploit round-trip time measurements (Wi-Fi RTT, IEEE 802.11mc) for metre-level accuracy.

Databases

Large-scale WPS databases are built by companies such as Google, Apple, Microsoft, Skyhook, and Mozilla, using wardriving, crowd-sourced data from smartphones, and user-submitted access-point locations. A device queries the service with the list of visible access points and receives an estimated position and accuracy radius.

Privacy

Because MAC addresses are broadcast publicly, WPS databases raised privacy concerns; access-point owners can opt out, for example by appending "_nomap" to the network name (SSID) in Google's system. Modern mobile operating systems randomise MAC addresses when scanning to limit tracking.
