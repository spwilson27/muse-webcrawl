Eager evaluation

Eager evaluation
Also called: Strict evaluation
Contrast: Lazy evaluation

In computer programming, eager evaluation, also known as strict evaluation, is the evaluation strategy in which an expression is evaluated as soon as it is bound to a variable, and function arguments are fully evaluated before the function is applied.

Characteristics

Most mainstream programming languages — including C, Java, Python and most dialects of Lisp — evaluate eagerly by default. Eager evaluation makes the order and timing of side effects predictable and can simplify reasoning about performance, but it may compute values that are never used.

Comparison with lazy evaluation

Under lazy evaluation, evaluation is delayed until a value is needed, permitting infinite data structures and avoiding wasted work, at the cost of less predictable space and time behaviour. Some lazy languages provide strictness annotations, and some eager languages offer lazy constructs such as generators and short-circuit operators.
