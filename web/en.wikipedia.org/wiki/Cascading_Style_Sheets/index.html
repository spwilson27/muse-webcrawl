Cascading Style Sheets

CSS separates the presentation of a document from its structure.

Cascading Style Sheets (CSS) is a style sheet language used to describe the presentation of documents written in markup languages such as HTML. Together with HTML and JavaScript, it is a cornerstone technology of the World Wide Web. CSS separates content from layout, colour, typography, and responsive behaviour, so the same document can be rendered differently on screens, in print, or on other media.

Syntax and the cascade

A CSS rule combines a selector with declarations such as color: red;. Multiple rules may apply to one element; the “cascade” resolves conflicts using origin, importance, specificity, and source order, and properties may be inherited from parent elements. Selectors can target element types, classes, identifiers, attributes, and structural relationships.

History

CSS was proposed by Håkon Wium Lie in 1994 and developed with Bert Bos; the World Wide Web Consortium published CSS Level 1 in 1996 and CSS Level 2 in 1998. Rather than a single monolithic CSS3 specification, modern CSS is developed as a set of modules covering features such as flexbox, grid layout, transforms, animations, custom properties, and media queries.

Use

Browsers apply CSS to render web pages, and the language is also used in other contexts such as user-interface styling. Preprocessors and frameworks extend its authoring workflow, but the delivered styles are ultimately CSS.
