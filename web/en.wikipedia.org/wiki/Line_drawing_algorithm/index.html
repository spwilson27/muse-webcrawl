Line drawing algorithm

A line drawing algorithm is a graphical algorithm for approximating a line segment on a discrete graphical medium, such as pixel-based displays and printers. On such media, line drawing requires such an approximation (in non-trivial cases). Basic algorithms rasterise lines of one pixel in thickness; special algorithms may simulate anti-aliasing by shading pixels according to their distance from the ideal line.

The naive algorithm

The simplest approach evaluates the line equation y = mx + b for successive x values and plots the nearest pixel. This requires floating-point multiplication and addition per step, leaves gaps for steep lines (where |m| > 1, unless the roles of x and y are swapped), and historically was too slow for interactive graphics.

Differential analysers and incremental methods

The digital differential analyser (DDA) algorithm generalises the evaluation by stepping along the longer axis and accumulating the fractional increment along the shorter one, replacing multiplication with a single addition per pixel. It still uses floating-point arithmetic and rounding.

Bresenham's line algorithm

Bresenham's line algorithm, developed by Jack Elton Bresenham in 1962 at IBM, is the classic rasterisation method. Using only integer addition, subtraction, and bit shifting, it maintains an error term representing the deviation between the pixel centre and the true line, choosing at each step the pixel that keeps the error smallest. Its speed and simplicity made it a standard in graphics hardware, plotters, and libraries for decades, and it generalises to circles and other conic sections (the midpoint algorithms).

Anti-aliased lines

Simple rasterisation produces visible "jaggies". Xiaolin Wu's line algorithm (1991) draws each endpoint precisely and shades pairs of pixels straddling the line in proportion to coverage, producing smooth anti-aliased lines at modest cost. The Gupta–Sproull algorithm achieves anti-aliasing by computing each pixel's exact distance to the ideal line. Modern GPUs rasterise lines and triangles in hardware using related edge-function methods.
