Extensible Application Markup Language (XAML, pronounced "zammel") is a declarative XML-based language developed by Microsoft for initialising structured values and objects. It was introduced with Windows Presentation Foundation (WPF) in .NET Framework 3.0 in 2006.

Overview

In XAML, user interfaces are declared in markup while behaviour is written in a code-behind file in C# or another .NET language. Each XML element maps to a class instance and attributes map to properties or events. XAML supports data binding, styles, templates, animations, and resource dictionaries, supporting a separation between design and development workflows in tools such as Visual Studio and Blend.

Uses

Beyond WPF, XAML dialects are used in Silverlight (historically), Windows Store and UWP apps, WinUI, Xamarin.Forms and its successor .NET MAUI, and third-party frameworks such as Avalonia and Uno Platform.

Example

A simple window might declare a Button with a Click handler: <Button Content="OK" Click="OnOk"/>. The markup can be compiled (BAML) or parsed at runtime.
