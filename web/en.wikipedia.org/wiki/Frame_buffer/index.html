Frame buffer

A frame buffer (also framebuffer) is a portion of random-access memory containing a bitmap that drives a video display. It is a memory buffer containing data representing all the pixels in a complete video frame.

History

Early frame buffers emerged in the 1960s–70s at research centres such as Xerox PARC, where the Alto's bitmapped display set the pattern for personal computing. As memory prices fell, frame buffers became standard in workstations and home computers during the 1980s.

Organisation

The buffer stores colour information for each pixel, in formats from 1-bit monochrome to 24-bit (or higher) true colour, sometimes with an alpha channel. Modern graphics processing units integrate large frame buffers with additional structures for double buffering — drawing to a back buffer while a front buffer is displayed, then swapping to avoid tearing — and for depth (z-buffering) and stencil operations.

Software access

Operating systems expose frame buffers through graphics APIs; on Linux, the fbdev interface and its successor DRM/KMS let user programs map the buffer directly, while most applications draw through compositors and GPU-accelerated pipelines.
