Quartz (graphics layer)

DeveloperApple Inc.
Operating systemmacOS
TypeGraphics layer
ComponentsQuartz 2D, Quartz Compositor

Quartz is the graphics layer of Apple's macOS operating system. It consists of two core components: Quartz 2D, a two-dimensional drawing library based on the PDF imaging model, and the Quartz Compositor, the window server that composites window buffers to the screen.

Quartz 2D

Quartz 2D provides a vector-based drawing environment for rendering text, images, and shapes with anti-aliasing, transparency, and resolution independence. Applications draw into graphics contexts that can target the screen, printers, or PDF files identically. The API is part of the Core Graphics framework.

Quartz Compositor

The Quartz Compositor manages each window as an off-screen buffer and composes the final display, enabling effects such as drop shadows, transparency, Exposé, and smooth window animation. It is accessed indirectly through system services rather than by applications directly. Historically it leveraged OpenGL acceleration ("Quartz Extreme"); more recent macOS versions render through Metal.

Quartz in other contexts

The same Core Graphics technologies underlie iOS drawing, where UIKit builds on Quartz 2D. Related technologies include Quartz Composer, a visual programming environment for graphics processing (deprecated), and Core Image and Core Animation, which sit above the basic layer.
