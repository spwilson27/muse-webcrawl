Linear programming relaxation

In mathematical optimisation, the linear programming relaxation (LP relaxation) of an integer linear program is the problem obtained by dropping the requirement that the variables take integer values, allowing them instead to vary continuously. The relaxation can be solved efficiently with standard linear programming algorithms.

Bounds

Because the relaxation enlarges the feasible region, its optimal value bounds the optimum of the original problem: for a minimisation problem the LP value is a lower bound, and for a maximisation problem it is an upper bound. If the relaxed solution happens to be integral, it is optimal for the original problem as well. The difference between the two optima is called the integrality gap.

Uses

LP relaxations are central to branch and bound algorithms for integer programming, where they supply the bounds used to prune the search tree, and to approximation algorithms, where a fractional solution is rounded to an integer solution with a provable performance guarantee.
