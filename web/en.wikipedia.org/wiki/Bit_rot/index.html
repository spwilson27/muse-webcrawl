Bit rot

Bit rot is a colloquial term used in computing in two related senses. In the first, it is the gradual decay of storage media or the data stored on them, so that stored bits are silently corrupted or become unreadable over time. In the second, it is a humorous description of software that appears to degrade over time even though its code has not changed — usually because its environment, dependencies, or the hardware and formats around it have changed.

Data decay

Physical media degrade in different ways: magnetic tapes and disks lose magnetisation, optical discs suffer oxidation of the reflective layer ("disc rot"), and flash memory cells leak charge. Hardware faults, cosmic rays, and firmware bugs can also flip bits. Because such corruption is often silent, archives defend against it with checksums, redundant copies, periodic scrubbing, and error-correcting storage systems such as RAID and filesystems with built-in integrity verification.

Software rot

In its software sense, bit rot is closely related to software rot (software entropy): a program that is not maintained gradually becomes less useful as operating systems, libraries, network protocols, and file formats evolve around it. The term is often used ironically, since the bits of the program itself are unchanged; what has "rotted" is its fit with its surroundings.
