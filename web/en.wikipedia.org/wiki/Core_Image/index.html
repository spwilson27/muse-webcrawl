Core Image

Core Image is a pixel-accurate, near-realtime image processing framework in Apple's macOS, iOS, tvOS and watchOS operating systems. Introduced with Mac OS X 10.4 "Tiger" in 2005, it provides image filters, warps, transitions and analysis tools, accelerated on the graphics processing unit (GPU) where possible.

Overview

Core Image works non-destructively: filters are chained together into a graph, and the framework renders only the region of the image actually needed, evaluating the chain lazily. Its central classes include CIImage (a recipe for producing an image rather than bitmap data itself), CIFilter (an effect with input parameters), CIContext (the rendering destination) and CIColor.

Filters

The framework ships with several hundred built-in filters across categories such as blur, color adjustment, distortion, compositing, halftone effects, tile effects and generators. Developers can write custom filters using the Core Image Kernel Language, a subset of the Metal Shading Language (formerly GLSL-based), allowing per-pixel GPU programs to be embedded in applications.

Use

Core Image underlies effects in applications such as Photos and Photo Booth, and is used directly by developers in Objective-C and Swift. On iOS it also provides face detection and other image analysis features.
