Product activation

Product activation is a license validation procedure required by some proprietary software programs. Product activation prevents unlimited free use of copied or replicated software. Unactivated software usually reminds the user to activate the product, via the Internet or a telephone, before it can be fully used, and some products cease to function or run in a reduced-functionality mode if activation is not completed within a set period.

How it works

During installation or first run, the software generates an installation ID derived from a product key supplied with the software and a hash of the computer's hardware configuration. This ID is sent to the vendor's activation servers, which return an activation code or record the license as used. The hardware binding is intended to detect when the same license is installed on substantially different machines.

History

Product activation in mass-market software became prominent with products such as Windows XP (2001), which introduced Windows Product Activation (WPA), and with Adobe and Macromedia applications of the same era. Earlier forms of copy protection included key disks, dongles, and serial numbers without online checking. Activation has since become standard for operating systems, office suites, creative applications, and many video games, often implemented through platforms such as Steam or vendor account sign-in.

Criticism

Activation has been criticized for inconveniencing legitimate users, for privacy concerns arising from the transmission of hardware data, and for the risk that software becomes unusable if a vendor's activation servers are shut down. Changes of hardware components may require reactivation. Proponents argue activation, unlike more intrusive digital rights management, permits reasonable use such as reinstalling on the same machine while reducing casual copying.
