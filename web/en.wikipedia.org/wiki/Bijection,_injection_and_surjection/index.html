Bijection, injection and surjection

In mathematics, injections, surjections, and bijections are classes of functions distinguished by how elements of the domain relate to elements of the codomain. The terminology was introduced by the Bourbaki group.

Injection

A function is injective (one-to-one) if distinct inputs always give distinct outputs: no two elements of the domain map to the same element of the codomain. An injective function has a left inverse, and can be recognised by the horizontal line test on its graph.

Surjection

A function is surjective (onto) if every element of the codomain is the image of at least one element of the domain — that is, the function's range equals its codomain. A surjective function has a right inverse (assuming the axiom of choice).

Bijection

A function is bijective if it is both injective and surjective, establishing a one-to-one correspondence between domain and codomain. Bijective functions have full inverses. Two sets have the same cardinality if and only if there exists a bijection between them — the foundation for comparing sizes of infinite sets.
