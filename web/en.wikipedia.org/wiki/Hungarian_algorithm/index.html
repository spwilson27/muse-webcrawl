The Hungarian algorithm, also called the Kuhn–Munkres algorithm, is a combinatorial optimisation algorithm that solves the assignment problem in polynomial time. Given a square matrix of costs for assigning each of n workers to n tasks, it finds the one-to-one assignment with the minimum (or maximum) total cost.

History

The algorithm was published by Harold Kuhn in 1955 in the journal Naval Research Logistics Quarterly. Kuhn named it the "Hungarian method" because it was based on the earlier work of two Hungarian mathematicians, Dénes Kőnig and Jenő Egerváry, whose theorems on bipartite graphs underpin the method. James Munkres reviewed the algorithm in 1957 and showed it runs in polynomial time; hence the double name Kuhn–Munkres algorithm. The original implementation ran in O(n⁴); later refinements, including the Jonker–Volgenant variant (1987), achieve O(n³) and are widely used in practice.

Problem statement

Suppose there are n workers and n tasks, and a cost c(i, j) for assigning worker i to task j. The goal is to assign each worker to exactly one task and each task to exactly one worker so that the total cost is minimised. In graph terms this is a minimum-weight perfect matching in a complete bipartite graph. Rectangular problems (more workers than tasks, or vice versa) are handled by padding the matrix with dummy entries.

Method

The classical matrix form of the algorithm proceeds as follows:

  1. Subtract the smallest entry in each row from every entry in that row, then subtract the smallest entry in each column from every entry in that column. This produces zeros without changing which assignments are optimal.
  2. Try to assign workers to distinct tasks using only zero entries. Cover all zeros with the minimum number of horizontal and vertical lines; by Kőnig's theorem, if the number of lines equals n, an optimal assignment exists among the zeros.
  3. If fewer than n lines suffice, find the smallest uncovered entry, subtract it from all uncovered entries, and add it to entries covered twice. This creates new zeros while preserving optimality; return to step 2.

Modern implementations usually work with dual potentials and augmenting paths on graphs rather than explicit matrix manipulation, treating the problem as a sequence of shortest-path computations.

Applications

The Hungarian algorithm is used wherever one-to-one matching must be optimised: assigning workers to jobs, vehicles to delivery routes, gates to aircraft, and — prominently — data association in multi-object tracking, where detections in successive frames must be matched to existing tracks. It is a standard component of tracking libraries and of the scipy function linear_sum_assignment.
