Bootkit

A bootkit is a type of malware that infects the boot process of a computer system, such as the master boot record (MBR), volume boot record, or firmware, in order to load before the operating system and its security software start. As a persistent form of rootkit, a bootkit can intercept the loading of the kernel, patch code in memory, and hide other malicious components, making detection and removal difficult.

History and examples

Boot-sector viruses date to the floppy-disk era, but modern bootkits emerged in the 2000s with examples such as Mebroot (Sinowal) and the TDL/TDSS family, which combined boot-record infection with rootkit functionality for botnets and fraud. Later threats, including the LoJax UEFI rootkit (2018) and BlackLotus (2022–2023), attacked firmware and Secure Boot mechanisms themselves.

Countermeasures

Defenses include UEFI Secure Boot, measured boot with a TPM, boot integrity monitoring, and full-disk encryption. Removing a bootkit may require rewriting the boot code or reflashing firmware from trusted media.
