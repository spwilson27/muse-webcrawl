Code talker

Navajo code talkers with the U.S. Marine Corps in the Pacific War.

A code talker was a person employed by the military during wartime to transmit secret messages using a little-known language as a form of code. The term is most strongly associated with the Navajo speakers recruited by the United States Marine Corps during World War II, who communicated tactical messages in the Navajo language over radio and telephone in the Pacific theatre. Other Native American peoples — including the Choctaw, Cherokee, Comanche, Meskwaki, Hopi, and Lakota — also served as code talkers in both world wars.

The Navajo code

The Navajo programme began in 1942 when the first twenty-nine Navajo recruits devised a code at Camp Pendleton: Navajo words stood for letters of the alphabet (for example, wol-la-chee, "ant", for A), and several hundred common military terms were given Navajo equivalents, such as "iron fish" for submarine and "hummingbird" for fighter plane. Because Navajo was an unwritten language with complex grammar known to very few non-Navajos, the code was never broken by the Japanese. Roughly 400 Navajo code talkers eventually served, taking part in every major Marine assault in the Pacific from Guadalcanal to Okinawa; Major Howard Connor credited them with a decisive role at Iwo Jima, where six code talkers transmitted more than 800 messages without error in the first two days.

Recognition

The programme remained classified until 1968, which delayed public recognition. In 2001 the original twenty-nine Navajo code talkers received the Congressional Gold Medal, and surviving code talkers of other tribes were similarly honoured under the Code Talkers Recognition Act of 2008. Code talkers of the First World War — notably the Choctaw telephone squad of 1918 — have also received increasing recognition.
