Audio Video Interleave

AVI
Filename extension: .avi
Developed by: Microsoft
Initial release: November 1992
Type of format: Container format
Container for: Audio, video

Audio Video Interleave (also Audio Video Interleaved), known by its initials AVI, is a multimedia container format introduced by Microsoft in November 1992 as part of its Video for Windows software. AVI files can contain both audio and video data in a file container that allows synchronous audio-with-video playback.

Structure

AVI is a derivative of the Resource Interchange File Format (RIFF), which divides a file's data into blocks, or "chunks". Each chunk is identified by a FourCC tag. An AVI file takes the form of a single RIFF chunk containing a header describing the streams, followed by the interleaved audio and video data chunks themselves.

Limitations and successors

The original AVI specification did not anticipate later compression techniques such as B-frames used in MPEG-4, and files are limited in practice by addressing issues beyond 2 GB in early implementations; the OpenDML extension ("AVI 2.0") relaxed these limits. AVI has largely been superseded by formats such as MP4, MKV and WMV, though it remains widely readable.
