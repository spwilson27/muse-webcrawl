Crime analysis

Crime analysis is a law enforcement function that involves the systematic analysis of identified patterns, trends and problems in crime and disorder, using statistical, spatial and qualitative methods to support patrol, investigations and crime prevention strategy.

Types

Analysts distinguish tactical analysis (immediate patterns and series), strategic analysis (long-term trends and resource planning), administrative analysis (reporting to decision-makers and the public) and criminal intelligence analysis (networks and organised crime).

Methods

Common techniques include crime mapping with geographic information systems, hot-spot analysis, repeat-victimisation studies, time-series forecasting and social network analysis. Crime analysis underpins problem-oriented policing and intelligence-led policing models such as CompStat.
