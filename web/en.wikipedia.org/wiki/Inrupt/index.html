Inrupt

Inrupt, Inc.
Founded: 2017
Founders: Tim Berners-Lee, John Bruce
Product: Enterprise Solid Server
Focus: Solid protocol, personal data stores

Inrupt is a technology company co-founded in 2017 by World Wide Web inventor Tim Berners-Lee and entrepreneur John Bruce to commercialise the Solid project. Solid is an open specification, developed by Berners-Lee at MIT, that aims to give people control over their own data by storing it in personal online data stores called "Pods", which applications access only with the owner's permission — separating data from the applications that use it.

Products and deployments

Inrupt develops the Enterprise Solid Server and developer tools (such as client libraries and the PodSpaces service) for organisations adopting Solid. Governments and companies have run pilots using the technology, notably the Government of Flanders in Belgium, which built citizen data "vaults" on Solid principles, and media and financial organisations experimenting with user-controlled data sharing.

Vision

Berners-Lee has described Solid as an attempt to restore the web's original decentralised ethos by shifting power from large platforms back to individuals, who could grant and revoke access to their data across services. Inrupt is headquartered in Boston, Massachusetts.
