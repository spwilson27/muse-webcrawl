Data structure alignment

Data structure alignment is the way data is arranged and accessed in computer memory. It consists of two related issues: data alignment, the requirement that a datum's memory address be a multiple of its size (a datum is then said to be naturally aligned), and data structure padding, the insertion of unused bytes between members of a structure so that each member satisfies its alignment requirement.

Motivation

Computer memory is accessed in machine words; reading a value that straddles word boundaries may require two memory accesses instead of one, and on some architectures (such as older ARM and SPARC) an unaligned access raises a hardware fault. Modern x86 processors tolerate unaligned access but with a performance penalty, especially when a datum crosses a cache line. Compilers therefore pad structures — for example, in C a struct { char c; int i; } typically occupies 8 bytes with three padding bytes after the char — and programmers can reorder members to minimise wasted space.

Rules and control

Typical alignment requirements equal the size of the type: 2-byte types on 2-byte boundaries, 4-byte types on 4-byte boundaries, and so on, up to the machine's maximum alignment. Languages and compilers expose control through directives such as #pragma pack, C11's _Alignas, and attributes requesting packed structures for matching external file or network formats at the cost of slower access.
