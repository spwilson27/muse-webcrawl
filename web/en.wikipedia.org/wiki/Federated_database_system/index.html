Federated database system

A federated database system (FDBS) is a type of meta-database management system that transparently maps multiple autonomous database systems into a single federated database, allowing them to be queried as if they were one system while component databases remain independent.

Architecture

Federated systems use schema integration: local schemas are translated into export schemas and integrated into a global (federated) schema. Systems may be loosely coupled (integration done by users/applications) or tightly coupled (managed by the federation). A classic reference architecture is the five-level schema architecture of Sheth and Larson (1990).

Characteristics

Key issues include distribution, heterogeneity (data model, query language, semantics) and autonomy of the component databases. Federated approaches contrast with data warehouses, where data is physically copied into a single repository.
