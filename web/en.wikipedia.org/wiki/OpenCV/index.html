OpenCV (Open Source Computer Vision Library) is a free and open-source software library for computer vision and machine learning. Originally developed at Intel beginning in 1999, it contains more than 2,500 optimised algorithms for tasks such as face detection and recognition, object tracking, image stitching, camera calibration, feature detection (SIFT, SURF, ORB), and — in its dnn module — running deep neural networks from frameworks such as TensorFlow, PyTorch, and Caffe.

History

OpenCV was initiated by Gary Bradski at Intel to encourage computer vision research and provide common infrastructure for applications, partly to help drive demand for faster processors. The first alpha was released in 2000; version 1.0 followed in 2006. The project later received support from Willow Garage and Itseez (acquired by Intel in 2016). Governance eventually passed to the non-profit OpenCV.org foundation. Major releases include OpenCV 2 (2009, introducing the C++ interface), OpenCV 3 (2015), and OpenCV 4 (2018), which moved to C++11 and Apache 2 licensing. OpenCV 5 development has continued the library's expansion into deep learning and 3D vision.

Features and bindings

The library is written natively in C++ and provides official interfaces for Python (the widely used opencv-python package), Java, and MATLAB, with community bindings for many other languages. It supports CPU optimisation (SIMD, Intel IPP/TBB) and GPU acceleration via CUDA and OpenCL. Its modular structure includes core data structures, image processing, video analysis, GUI and media I/O, and the community-contributed opencv_contrib modules.

Applications

OpenCV is used in research, robotics, surveillance, augmented reality, industrial inspection, medical imaging, and interactive art. It played a role in systems from Google and other companies' early vision products, and its built-in Haar cascade face detector — trained with the method of Viola and Jones — was for years the default starting point for real-time face detection projects.
