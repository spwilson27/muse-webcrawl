Programming paradigm

A programming paradigm is a relatively high-level way to conceptualize and structure the implementation of a computer program. A language can be classified as supporting one or many paradigms.

Common paradigms

  • Imperative: programs state sequences of commands that change state; includes procedural and object-oriented programming
  • Declarative: programs describe what should be computed rather than how; includes functional and logic programming
  • Object-oriented: code is organized around objects combining data and behavior
  • Functional: computation is the evaluation of mathematical functions, avoiding mutable state
  • Concurrent and event-driven paradigms structure programs around interacting processes and events

Multi-paradigm languages

Many modern languages, such as Python, Scala, and C++, support several paradigms, letting programmers choose the style best suited to each part of a problem. The concept of paradigms was popularized in part by Robert W. Floyd's 1978 Turing Award lecture, "The Paradigms of Programming".
