X.500

X.500
Type: ITU-T recommendation series
Subject: Directory services standards
First published: 1988

X.500 is a series of computer networking standards covering electronic directory services. The X.500 series was developed by the ITU-T (formerly CCITT) in cooperation with ISO and was first published in 1988. The standards define a distributed directory — the Directory — holding information about objects such as people, organizations, and devices, organized in a hierarchical Directory Information Tree.

Standards in the series

The principal recommendations include X.500 (overview of concepts, models and services), X.501 (information models), X.509 (public-key and attribute certificate frameworks and authentication), X.511 (abstract service definition), X.518 (procedures for distributed operation), X.519 (protocol specifications, including the Directory Access Protocol, DAP), X.520 (selected attribute types), and X.521 (selected object classes).

Influence

Of the series, X.509 has had by far the greatest lasting impact: X.509 certificates underpin the public key infrastructure used in TLS and much of Internet security. The heavyweight DAP protocol saw limited deployment, but its data model inspired the much lighter LDAP (Lightweight Directory Access Protocol), which retains the X.500 directory model and naming scheme and is widely used in enterprise directories such as Active Directory and OpenLDAP.

Concepts

Entries in the Directory are identified by distinguished names built from relative distinguished names following a hierarchical structure, for example a country, organization, organizational unit, and common name. Directory System Agents (DSAs) hold portions of the tree and cooperate through chaining and referrals to answer queries from Directory User Agents (DUAs).
