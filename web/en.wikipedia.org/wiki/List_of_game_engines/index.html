List of game engines

A game engine is a software framework used to build video games, providing rendering, physics, audio, scripting, and asset tools. This list collects notable engines, both commercial and open-source.

Notable engines

EngineDeveloperFirst releasedNotes
Unreal EngineEpic Games1998Powered Unreal, Fortnite; version 5 released 2022
UnityUnity Technologies2005Widely used for mobile and indie games
GodotCommunity (open source)2014Free, MIT-licensed
id Techid Software1993 (Doom engine)Lineage from Doom to Doom Eternal
SourceValve2004Half-Life 2; Source 2 followed
CryEngineCrytek2002Far Cry, Crysis
FrostbiteDICE / EA2008Battlefield series
GameMakerYoYo Games19992D-focused; Undertale
RPG MakerEnterbrain/Kadokawa1992Tool for role-playing games
RE EngineCapcom2017Resident Evil remakes

Open-source engines

Besides Godot, notable free engines include OGRE (graphics), Bullet and ODE (physics middleware), Ren'Py (visual novels), and OpenMW (a reimplementation of the Morrowind engine).
