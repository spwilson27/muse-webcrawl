Core rope memory

Core rope memory is a form of read-only memory (ROM) that was used in the 1960s, notably in the Apollo Guidance Computer (AGC) of NASA's Apollo program and in the DEC PDP-8. It is a form of transformer read-only memory: the data is physically encoded by weaving wires ("ropes") through or around small ferrite cores, so a wire passing through a core represents a binary 1 and one bypassing it represents a 0.

Construction

Because the software was literally woven into the hardware, the Apollo core ropes were manufactured by hand — largely by women at the Raytheon plant in Waltham, Massachusetts, nicknamed "Little Old Ladies" or "rope mothers", who threaded wires through thousands of tiny cores with needles under magnification. Changes to the flight software late in a mission's preparation were costly and time-consuming because new ropes had to be woven.

Characteristics

Core rope memory offered much higher storage density than the erasable magnetic-core RAM of the time: the AGC's ropes held 36,864 words of 15 bits. It was rugged, non-volatile, and immune to the kinds of electrical upsets that could erase core RAM, though it was strictly read-only. The technique is a development of the core memory systems used in early computers and is closely related to transformer ROM in the UNIVAC and other machines.
