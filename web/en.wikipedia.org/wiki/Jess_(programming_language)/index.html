Jess (programming language)

Developer: Ernest Friedman-Hill (Sandia National Laboratories)
First appeared: 1995
Platform: Java
Paradigm: Rule-based, declarative
License: Proprietary (free for academic use historically)

Jess (the Java Expert System Shell) is a rule engine and scripting environment written in the Java programming language. Developed by Ernest Friedman-Hill at Sandia National Laboratories beginning in 1995, Jess allows developers to build expert systems that apply declarative rules to data, using a syntax derived from the CLIPS expert-system language.

Features

Jess uses an enhanced version of the Rete algorithm to match rule patterns efficiently against a working memory of facts. Rules are written in a Lisp-like syntax with constructs such as deftemplate, deffacts, and defrule. Because it runs on the Java virtual machine, Jess integrates tightly with Java code: it can manipulate Java objects directly, call Java methods, and be embedded in servlets, applets, and enterprise applications. Its engine supports both forward chaining (data-driven inference) and, through a scripting facility, procedural programming.

History and licensing

Jess grew out of Friedman-Hill's interest in porting CLIPS-style inference to Java. It became widely used in research, education, and commercial applications, including web-based recommendation and diagnostic systems. Version 7, released in the mid-2000s, added the "Charlemagne" query language improvements and an Eclipse-based development environment, the JessDE. Jess is distributed under a proprietary license by Sandia, free for academic users.
