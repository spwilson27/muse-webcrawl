Beta software

The typical software release life cycle, with beta following alpha

Beta software is a pre-release version of a computer program given to a selected group of users — beta testers — for testing under real-world conditions before general release. The beta phase follows the alpha phase in the software release life cycle and is generally the first time the software is available outside the organisation that developed it.

History and usage

The terms alpha and beta, borrowed from early hardware testing terminology at IBM, came into widespread use for software in the 1960s and 1970s. Traditionally, beta software is feature-complete but may contain numerous known and unknown bugs; the purpose of the beta phase is to find defects, assess performance and usability, and gather feedback before the "release candidate" and final release stages.

A closed beta is restricted to invited testers, whereas an open beta (or public beta) is available to anyone interested. Since the rise of web applications and continuous deployment, some products — famously including Google's Gmail, which carried a beta label for over five years — have remained in a state of "perpetual beta", receiving continuous updates rather than a single final release. In modern agile practice the term is often associated with staged rollouts, early-access programmes, and feature flags.
