Windows 7 is a major release of Microsoft's Windows NT operating system, released to manufacturing on 22 July 2009 and made generally available on 22 October 2009. It is the successor to Windows Vista and was itself succeeded by Windows 8 in 2012. Windows 7 was developed primarily as an incremental upgrade to Vista, addressing that release's widely criticized performance and compatibility problems while refining the Aero visual style.

Features

Windows 7 introduced a redesigned taskbar with application pinning and jump lists, window management gestures such as Aero Snap and Aero Shake, an improved Windows Search, Libraries in Windows Explorer, HomeGroup networking, and support for multitouch input. Performance was improved with faster boot times and lower resource usage, and the intrusive prompts of User Account Control were reduced. The operating system shipped in editions including Starter, Home Basic, Home Premium, Professional, Enterprise and Ultimate.

Reception

Windows 7 was a major success for Microsoft, receiving widespread critical acclaim in contrast to the poor reception of Vista. Reviewers praised its speed, stability, compatibility and polished interface. It sold over 100 million copies within six months and more than 630 million licences by mid-2012, overtaking Windows XP as the most used desktop operating system in the world. Many users and businesses considered it a high point of the Windows line and were reluctant to leave it.

End of support

Mainstream support ended on 13 January 2015 and extended support on 14 January 2020, after which only paid Extended Security Updates remained available, concluding in January 2023. Despite this, Windows 7 retained a small but persistent user base for years afterward, particularly on older hardware and embedded systems.
