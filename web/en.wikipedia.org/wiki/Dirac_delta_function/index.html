Dirac delta function

In mathematical analysis, the Dirac delta function (or δ distribution), also known as the unit impulse, is a generalised function whose value is zero everywhere except at zero, and whose integral over the entire real line is equal to one. It was introduced by the physicist Paul Dirac in the 1920s for use in quantum mechanics. The delta function is not a function in the ordinary sense, since no ordinary function has these properties; it is rigorously defined as a distribution or a measure.

Definition and properties

The delta function is characterised heuristically by two conditions: δ(x) = 0 for all x ≠ 0, and the integral of δ over any interval containing the origin equals one. Its most important property is the sifting or sampling property: integrating the product of δ(x) with any well-behaved function f(x) picks out the value of f at zero, ∫ f(x)δ(x) dx = f(0). The delta function can be pictured as the limit of a sequence of ever narrower, ever taller pulses of unit area, such as Gaussians or rectangles shrinking to zero width.

Useful identities include the scaling property δ(ax) = δ(x)/|a|, the fact that δ is an even distribution, and its relation to the Heaviside step function, of which it is the derivative. The Fourier transform of the delta function is the constant function 1, making it central to Fourier analysis and signal processing.

Applications

The delta function models idealised point sources and instantaneous impulses: a point mass or point charge in physics, a sudden hammer blow in mechanics, or an impulse input used to characterise a linear system by its impulse response. In probability it represents the distribution of a constant random variable. Solutions of differential equations driven by such impulses are found using Green's functions, which are built from delta-function responses.

History and rigour

Dirac introduced δ in his 1930 text The Principles of Quantum Mechanics, acknowledging that it was an "improper function" justified by its results. Laurent Schwartz's theory of distributions in the 1940s later supplied the rigorous framework in which the delta function is a continuous linear functional on a space of test functions.
