Password manager

A password manager is a program or service that stores and manages passwords in an encrypted vault, unlocked by a single master password or by biometrics. Password managers generate strong, unique passwords for each account, autofill credentials, and can store related data such as payment cards and secure notes.

Types

Managers may be cloud-based services (such as Bitwarden, 1Password and Dashlane), locally stored databases (such as KeePass), or built into browsers and operating systems (such as Apple Passwords and Google Password Manager). Cloud services synchronise the vault across devices; local managers leave sync to the user but avoid trusting a third party.

Security

Vaults are encrypted client-side, typically with AES-256, the key derived from the master password using a key-derivation function. Because the vault concentrates credentials, the master password is a single point of failure, and managers are high-value targets — several services have suffered breaches of encrypted vault data. Security guidance nonetheless generally recommends password managers because unique passwords prevent credential stuffing. Managers increasingly also support passkeys.
