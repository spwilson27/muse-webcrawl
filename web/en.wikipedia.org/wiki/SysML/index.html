Systems Modeling Language

The Systems Modeling Language (SysML) is a general-purpose modelling language for systems engineering applications. It supports the specification, analysis, design, verification and validation of a broad range of systems and systems-of-systems. SysML was developed as an open-source adaptation and extension of a subset of the Unified Modeling Language (UML), tailored to the needs of systems engineers, and was adopted by the Object Management Group (OMG) as a standard; OMG SysML 1.0 was released in 2007.

Diagrams

SysML defines nine diagram types, organised around four pillars: structure, behaviour, requirements and parametric relationships.

  • Structure: block definition diagram, internal block diagram, package diagram.
  • Behaviour: activity diagram, sequence diagram, state machine diagram, use case diagram.
  • Requirements: requirement diagram, capturing textual requirements and their traceability (satisfy, verify, derive, refine) to model elements.
  • Parametrics: parametric diagram, expressing mathematical constraints among system properties, enabling engineering analysis.

Compared with UML, SysML replaces class diagrams with block diagrams, generalises objects to parts and flows, and adds the requirement and parametric diagrams that UML lacks. It uses "blocks" as the fundamental unit of structure — representing hardware, software, people, facilities or any system component.

SysML v2

Work on a major revision, SysML v2, began in the late 2010s. It provides a formal semantic foundation (based on the KerML metamodel), a textual syntax alongside the graphical one, and a standard API for interoperability between tools. The OMG adopted the SysML v2 specifications in 2025.

Applications

SysML is widely used in model-based systems engineering (MBSE) in aerospace, defence, automotive and other complex engineering domains, where it is used to build integrated system models that replace or complement document-based specifications.
