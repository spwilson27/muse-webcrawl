Shader

In computer graphics, a shader is a computer program that calculates the appropriate levels of light, darkness, and color during the rendering of a 3D scene — a process known as shading. Shaders have evolved to perform a variety of specialized functions in special effects and video post-processing, and have also been adapted for general-purpose computing on graphics processing units (GPGPU).

Most shaders are written for, and run on, a GPU, which executes the same program in parallel across many elements — every vertex of a mesh or every pixel of an image — making them extremely fast for rendering. Modern graphics APIs such as OpenGL, Vulkan, Direct3D, and Metal all structure their rendering pipelines around shaders.

History

The term "shader" was introduced to the public by Pixar's RenderMan system in the 1988 RenderMan Interface Specification, where shaders were software routines executed per surface point on the CPU. As graphics hardware became programmable in the early 2000s — notably with NVIDIA's GeForce 3 (2001) — the term came to denote the small programs running on dedicated GPU stages. High-level shading languages such as GLSL (OpenGL), HLSL (Direct3D), and Cg made shaders accessible to application developers; more recently SPIR-V serves as a portable intermediate representation.

Types of shaders

Vertex shaders

A vertex shader runs once for each vertex of a mesh. It typically transforms vertex positions from object space to screen space using the model-view-projection matrix, and passes data such as normals, colors, and texture coordinates down the pipeline to be interpolated.

Fragment (pixel) shaders

A fragment shader runs once for each fragment (roughly, each pixel covered by a primitive). It computes the final color of the pixel, sampling textures and applying lighting models — from simple Lambertian diffuse to physically based rendering — as well as effects such as fog, reflections, and transparency.

Geometry, tessellation, and mesh shaders

Geometry shaders can generate or discard primitives; tessellation shaders subdivide surfaces for finer detail; mesh shaders (introduced in Vulkan extensions and Direct3D 12) combine vertex and primitive processing into a more flexible model.

Compute shaders

Compute shaders run outside the graphics pipeline proper and are used for general computations such as physics simulation, image processing, and machine learning kernels.
