Complexity class

From Wikipedia, the free encyclopedia

In computational complexity theory, a complexity class is a set of computational problems "of related resource-based complexity". The two most commonly analyzed resources are time and memory. In general, a complexity class is defined in terms of a type of computational problem, a model of computation, and a bounding resource, and the class is the set of problems that can be solved by an algorithm using a certain amount of the resource.

Many complex questions can be framed in terms of the inclusions and relationships between various complexity classes. For example, P versus NP, one of the Millennium Prize Problems, asks whether the complexity classes P and NP are equal; the related but stronger question of whether P and PSPACE are equal is also unresolved.

Defining complexity classes

A complexity class is specified by three components: a model of computation (most commonly a Turing machine), a mode of computation (deterministic, nondeterministic, probabilistic, alternating, or quantum), and a resource bound (such as a function of the input size limiting time or space). Under this scheme there are four common measures: DTIME, NTIME, DSPACE, and NSPACE.

By the time hierarchy theorems, allowing an algorithm more time genuinely enlarges the class of solvable problems, so the deterministic time classes form a strict hierarchy. The space hierarchy theorems give analogous results for space. In contrast, nondeterministic space classes satisfy Savitch's theorem, which shows NSPACE(s(n)) ⊆ DSPACE(s(n)2), and the Immerman–Szelepcsényi theorem, which shows nondeterministic space classes are closed under complement.

Important complexity classes

Some of the most studied complexity classes include:

  • P — problems solvable in polynomial time by a deterministic Turing machine.
  • NP — problems whose "yes" answers can be verified in polynomial time, or equivalently solved in polynomial time by a nondeterministic machine.
  • coNP — problems whose "no" answers can be verified in polynomial time.
  • PSPACE — problems solvable using polynomial space.
  • EXP (or EXPTIME) — problems solvable in exponential time.
  • BQP — problems solvable in polynomial time by a quantum computer with bounded error.
  • L and NL — problems solvable in logarithmic space, deterministically and nondeterministically.
  • PH — the polynomial hierarchy, a union of generalizations of P, NP, and coNP.

Known inclusions include L ⊆ NL ⊆ P ⊆ NP ⊆ PSPACE ⊆ EXP. At least one of these inclusions must be strict, because the time and space hierarchy theorems imply P ⊊ EXP and L ⊊ PSPACE, but it is not known which.

Complete problems

A central tool for comparing classes is the notion of a complete problem: a problem in a class that is among the "hardest" in the class, in the sense that every other problem in the class can be reduced to it. The Cook–Levin theorem established that the Boolean satisfiability problem (SAT) is NP-complete. Thousands of problems across combinatorics, graph theory, and logic have since been shown NP-complete.
