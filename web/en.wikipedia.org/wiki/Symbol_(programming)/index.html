Symbol (programming)

In some programming languages, a symbol is a primitive data type whose instances have a unique, human-readable name and are guaranteed to be unique (interned): two symbols with the same name are always the identical object. Symbols are used as identifiers whose meaning is their identity rather than their content, in contrast to strings, which are compared by their characters.

Usage

Symbols are central in the Lisp family, where code itself is built from symbols and lists; a symbol is a first-class object that can name variables and functions. Ruby adopted symbols (written :name) widely, especially as hash keys, where they are more memory-efficient than strings. JavaScript introduced a Symbol primitive type in ECMAScript 2015, whose values are unique and immutable and are used for non-string property keys, such as Symbol.iterator. Symbols also appear in Erlang and Elixir (as atoms), Scala, and Smalltalk (#name).

Advantages

Because symbols are interned, comparing them is a fast identity check rather than a character-by-character string comparison, and their immutability makes them safe as keys in hash tables. In some languages symbols are garbage-collected; in older implementations symbol tables could grow unboundedly, motivating care when creating symbols dynamically from user input.
