ID3 is a metadata container format most often used with the MP3 audio file format. It allows information such as the title, artist, album, track number, year and genre to be stored inside the audio file itself, so that media players can display and organise tracks. The name derives from "IDentify an MP3".

ID3v1

The original format, created by programmer Eric Kemp in 1996, is a fixed 128-byte block appended to the end of the file: a 3-byte "TAG" identifier, followed by fixed fields for title, artist and album (30 bytes each), year, comment and a one-byte genre code drawn from a standard list (later expanded by Winamp). An extension (ID3v1.1) reuses two comment bytes to store the track number.

ID3v2

ID3v2, developed from 1998, places a flexible tag at the beginning of the file. It consists of frames, each identified by a short code (TIT2 for title, TPE1 for artist, TALB for album, APIC for attached picture, USLT for lyrics), supporting Unicode text, embedded album artwork, and hundreds of defined frame types. Versions 2.2, 2.3 (the most widely supported) and 2.4 differ in details such as text encoding and frame size encoding; ID3v2.4 was published in 2000 but adoption by players remained slower than 2.3.

Related formats

Other audio formats carry their own metadata systems — Vorbis comments in FLAC and Ogg, APE tags, and iTunes-style atoms in MP4 files — but ID3 remains the de facto tag standard for MP3, and tagging software such as MusicBrainz Picard and Mp3tag reads and writes it across formats.
