Additive identity

FieldAbstract algebra
DefinitionElement e such that a + e = a
Examples0 (numbers), zero vector, zero matrix

In mathematics, the additive identity of a set equipped with an addition operation is an element which, when added to any element x in the set, yields x. The most familiar additive identity is the number 0, from elementary arithmetic, but additive identities occur in many algebraic structures where addition is defined, such as in groups and rings.

The additive identity familiar from elementary arithmetic is zero, denoted 0. For any real number a, a + 0 = a, 0 + a = a, and a + (−a) = 0. The concept is generalized to structures with two binary operations, such as rings and fields.

Examples

In the set of integers, rational numbers, real numbers and complex numbers, the additive identity is 0. In vector spaces, the zero vector plays this role: adding it to any vector leaves the vector unchanged. For matrices of a fixed size, the zero matrix, all of whose entries are 0, is the additive identity. In the set of even functions, the zero function is the identity.

Properties

In a ring R, the additive identity is denoted 0. It satisfies a + 0 = 0 + a = a for all a in R. The additive identity is unique: if e and e′ are both additive identities, then e = e + e′ = e′. The additive inverse of an element a, written −a, is the unique element such that a + (−a) = 0.
