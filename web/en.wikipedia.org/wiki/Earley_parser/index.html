Earley parser

The Earley parser is an algorithm for parsing strings that belong to a given context-free grammar. It was invented by Jay Earley in his 1968 PhD thesis and 1970 paper. The algorithm uses dynamic programming and is notable because it can parse all context-free grammars, including ambiguous ones, in a top-down manner driven by the input.

Algorithm

The parser processes the input left to right, building a sequence of "item sets" (state sets), one per input position. Each item is a production rule with a dot marking how much of the right-hand side has been matched, together with an origin position. Three operations manipulate the items: prediction adds items for nonterminals that could start at the current position, scanning consumes an input token matching the next terminal, and completion advances items whose awaited nonterminal has been finished. A successful parse is recorded by a completed item for the start symbol spanning the whole input.

Complexity

Earley parsing runs in O(n³) time in the worst case for general context-free grammars, O(n²) for unambiguous grammars, and O(n) for a large class of deterministic grammars (including LR(k) grammars). This combination of generality and efficiency makes it attractive for natural-language processing and for domain-specific languages with highly ambiguous grammars, though practical implementations must handle its potentially large memory use and the extraction of parse forests carefully.
