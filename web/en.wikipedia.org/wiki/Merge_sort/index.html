Merge sort

Merge sort is an efficient, general-purpose, comparison-based sorting algorithm. Most implementations produce a stable sort, meaning the order of equal elements is preserved. Merge sort is a divide-and-conquer algorithm invented by John von Neumann in 1945.

Algorithm

Conceptually, a merge sort works as follows:

  1. Divide the unsorted list into n sublists, each containing one element (a list of one element is considered sorted).
  2. Repeatedly merge sublists to produce new sorted sublists until only one sorted list remains.

In a top-down implementation, the list is recursively split in half until sublists of size one are reached, then merged on the way back up.

Analysis

Merge sort has guaranteed worst-case, average-case and best-case time complexity of O(n log n). A straightforward implementation requires O(n) auxiliary space for arrays; variants for linked lists need only O(1) extra space beyond recursion. Because it accesses data mostly sequentially, merge sort is well suited to sorting data stored on external media and is commonly used in hybrid algorithms such as Timsort's building blocks and in many standard library sort routines for linked structures.

Variants

Variants include bottom-up merge sort, in-place merging techniques, natural merge sort (which exploits existing runs), and parallel merge sort for multiprocessor machines.
