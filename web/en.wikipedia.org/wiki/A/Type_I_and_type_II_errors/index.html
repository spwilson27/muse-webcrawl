Type I and type II errors

From Wikipedia, the free encyclopedia

[Image placeholder: Confusion matrix diagram contrasting false positives and false negatives]

In statistical hypothesis testing, a Type I error is the mistaken rejection of a null hypothesis that is actually true — a "false positive". A Type II error is the failure to reject a null hypothesis that is actually false — a "false negative". The terminology was introduced by Jerzy Neyman and Egon Pearson in 1933 as part of their framework for hypothesis testing, which, unlike pure significance testing, treats the two mistakes as distinct quantities to be balanced.

Type I error

The probability of a Type I error is denoted α (alpha) and corresponds to the significance level of the test: a test at the conventional α = 0.05 level will, over many repetitions, wrongly reject a true null hypothesis 5% of the time. In everyday terms, a Type I error is like a fire alarm sounding when there is no fire, or a medical test indicating disease in a healthy person. Practices that inflate the effective α — such as testing many outcomes and reporting only the significant ones — are a recognised contributor to the replication crisis.

Type II error

The probability of a Type II error is denoted β (beta). Its complement, 1 − β, is the statistical power of the test: the probability of detecting an effect that genuinely exists. Type II errors become more likely when sample sizes are small, effects are weak, or measurements are noisy. In medicine, a Type II error is a test that misses a disease the patient actually has.

Trade-off

For a fixed sample size, decreasing the risk of one type of error generally increases the risk of the other: making a test stricter (smaller α) reduces false positives but also reduces power. The relative seriousness of the two errors depends on context. Criminal trials, for example, treat the Type I error of convicting an innocent person as far worse than acquitting a guilty one, while screening programmes for dangerous diseases may accept more false positives to avoid missing true cases.
