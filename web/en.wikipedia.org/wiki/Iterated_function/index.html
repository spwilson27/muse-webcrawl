Iterated function

In mathematics, an iterated function is a function obtained by composing a function with itself repeatedly. Starting from a function f : X → X, the iterates are f, f ∘ f, f ∘ f ∘ f, …, written f n. The sequence of values obtained by applying the iterates to a starting point is its orbit.

Study

Iteration is central to dynamical systems theory: fixed points, periodic cycles and chaotic behaviour all arise from iterating simple maps, such as the logistic map. The Abel equation and Schröder's equation relate an iterated function to a simpler one by conjugation. Fractional iterates extend the notion to non-integer numbers of applications.

Examples

The Collatz function, Newton's method for solving equations, and the repeated application of a hash or cellular automaton rule can all be viewed through iteration. Computer science uses the same idea in loops and recursion.
