Static random-access memory (static RAM or SRAM) is a type of random-access memory (RAM) that uses latching circuitry (flip-flops) to store each bit. SRAM is volatile in the conventional sense that data is lost when the memory is not powered, but it is called static because, unlike dynamic RAM (DRAM), it does not need to be periodically refreshed while power is applied.

Design

A typical SRAM cell consists of six MOSFETs: four transistors form two cross-coupled inverters that store the bit in one of two stable states, and two additional access transistors connect the cell to bit lines under control of a word line during read and write operations. Because each cell uses several transistors, SRAM is less dense and more expensive per bit than DRAM, whose cell is a single transistor and capacitor.

Characteristics

SRAM is significantly faster than DRAM, with access times of a few nanoseconds, making it the technology used for CPU cache memory (L1, L2 and usually L3 caches), register files, and small buffers in networking and storage devices. It also consumes little standby power in its idle state when no access is occurring, which suits battery-backed and embedded applications, though large arrays do draw leakage current. Common variants include asynchronous and synchronous SRAM, dual-port SRAM, and non-volatile nvSRAM, which pairs SRAM cells with a non-volatile backup store.
