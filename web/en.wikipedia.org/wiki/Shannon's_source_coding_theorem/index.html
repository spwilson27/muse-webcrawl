Shannon's source coding theorem

In information theory, Shannon's source coding theorem (or the noiseless coding theorem), established by Claude Shannon in 1948, states the fundamental limits of lossless data compression. Informally, it says that independent and identically distributed random variables can be compressed, with negligible loss of information, down to — but not below — their common entropy rate.

Statement

For a discrete source with entropy H(X), no uniquely decodable code can have an expected code length of fewer than H(X) symbols per source symbol; and there exist prefix codes with expected length less than H(X) + 1. For long blocks of n symbols coded jointly, the average length per symbol can be brought arbitrarily close to the entropy rate as n grows. Compressing below the entropy is impossible without loss: any attempt forces a nonzero probability of decoding error, and the probability that a "typical" sequence cannot be represented in fewer bits tends toward certainty.

Significance

The theorem founded the theory of data compression. Practical coders — Huffman coding, arithmetic coding, and dictionary methods such as LZ77 and LZ78 — are all measured against the entropy bound it defines. Its companion result, the source coding theorem for symbol codes, underlies the converse: the strong converse shows the error probability rises sharply to 1 if one attempts compression below the entropy rate.
