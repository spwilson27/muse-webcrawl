Microkernel

In computer science, a microkernel (often abbreviated as μ-kernel) is the near-minimum amount of software that can provide the mechanisms needed to implement an operating system (OS). These mechanisms include low-level address space management, thread management, and inter-process communication (IPC). Services that a monolithic kernel would provide internally — such as device drivers, file systems, and network stacks — run instead as separate user-mode processes (servers) that communicate via IPC.

Design

The microkernel approach aims to improve reliability and security: because most OS services run in unprivileged mode, a crash or compromise in a driver or file system need not bring down the whole system, and faulty components can often be restarted. The main disadvantage historically was performance, since operations that are simple function calls in a monolithic kernel require message passing and context switches in a microkernel design. Second-generation microkernels such as L4 greatly reduced IPC overhead through careful design.

History and examples

Early microkernel systems included Carnegie Mellon's Mach (used as the basis of NeXTSTEP and, in hybrid form, Apple's macOS and iOS kernels), the University of Amsterdam's Amoeba, and Chorus. The MINIX operating system, written by Andrew S. Tanenbaum for teaching, is a well-known microkernel design; the debate between Tanenbaum and Linus Torvalds in 1992 over microkernel versus monolithic design became famous. Production microkernels include QNX (widely used in embedded and automotive systems), the L4 family (including seL4, which has been formally verified), and the kernel of the GNU Hurd. Zircon, the kernel of Google's Fuchsia OS, is also microkernel-based.

Hybrid kernels

Some operating systems combine elements of both designs and are described as hybrid kernels: the XNU kernel of macOS integrates Mach with a BSD layer in the same address space, and the Windows NT kernel runs many services in user mode while keeping core executive services in kernel mode.
