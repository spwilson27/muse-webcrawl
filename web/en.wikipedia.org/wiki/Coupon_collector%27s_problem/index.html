Coupon collector's problem

In probability theory, the coupon collector's problem asks how many random trials are needed, on average, to collect a complete set of n distinct coupons when each trial yields one coupon chosen uniformly at random.

Solution

If T is the number of trials to collect all n coupons, then the expected value is E[T] = n(1 + 1/2 + … + 1/n) = n·Hn, approximately n ln n + γn, where Hn is the nth harmonic number and γ is the Euler–Mascheroni constant. The problem arises in the analysis of algorithms, hashing, and in estimating how long it takes to observe every outcome of a random process.
