ISO 15924

ISO 15924, Codes for the representation of names of scripts, is an international standard that assigns four-letter codes (and numeric codes) to writing systems. It was first published in 2004; the Registration Authority is the Unicode Consortium.

Codes

Each script receives a capitalised four-letter code, such as Latn (Latin), Cyrl (Cyrillic), Arab (Arabic), Hans (Han, simplified) and Hant (Han, traditional), Deva (Devanagari), Hebr (Hebrew) and Grek (Greek). Special codes include Zyyy (undetermined/common) and Zzzz (uncoded script). The standard defines well over 200 codes, which are also used in Unicode script property values, BCP 47 language tags (e.g. sr-Latn for Serbian in Latin script) and font and localisation technologies.
