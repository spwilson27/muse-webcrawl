Rank (linear algebra)

In linear algebra, the rank of a matrix A is the dimension of the vector space generated (or spanned) by its columns. This corresponds to the maximal number of linearly independent columns of A. Equivalently, it equals the dimension of the image of the linear map represented by A, and it also equals the maximal number of linearly independent rows.

The rank measures the dimension spanned by a matrix's columns.

Definitions and equivalence

Several definitions coincide: the column rank (dimension of the column space), the row rank (dimension of the row space) and the determinantal rank (largest size of a non-vanishing minor) are all equal. A fundamental theorem states that row rank equals column rank, so "the rank" is unambiguous. A matrix is said to have full rank if its rank equals the smaller of its numbers of rows and columns.

Properties

  • Rank is unchanged by elementary row or column operations, so it can be computed from a row echelon form by counting pivots.
  • rank(A) ≤ min(m, n) for an m × n matrix.
  • Sylvester's rank inequality: rank(AB) ≥ rank(A) + rank(B) − n.
  • rank(AB) ≤ min(rank A, rank B).
  • The rank–nullity theorem: rank(A) + nullity(A) = number of columns of A.

Applications

Rank determines whether systems of linear equations have solutions and whether they are unique: a system Ax = b is consistent exactly when rank(A) = rank of the augmented matrix [A | b]. Rank also appears in control theory (controllability and observability), statistics, computer vision (the rank-2 fundamental matrix), and data science, where low-rank approximation via the singular value decomposition underlies principal component analysis and recommender systems.
