Kademlia

Kademlia is a distributed hash table (DHT) for decentralized peer-to-peer computer networks designed by Petar Maymounkov and David Mazières in 2002. It specifies the structure of the network and the exchange of information through node lookups. Kademlia nodes communicate among themselves using UDP.

Design

A Kademlia network is formed by nodes, each identified by a unique node ID, typically a 160-bit number. Distances between nodes are computed with the exclusive or (XOR) operation on their IDs, interpreted as integers. This XOR metric gives Kademlia a key property: the distance is symmetric, satisfies the triangle inequality, and allows nodes to learn useful routing information from every message they receive.

Each node maintains a routing table of k-buckets: lists of contact information for nodes at progressively greater XOR distances. Lookups proceed iteratively, querying the α closest known nodes (commonly α = 3) in parallel and refining the set of candidates until the closest nodes to the target key are found. Values are stored at the k nodes closest to the key, giving redundancy against churn.

Protocol messages

The protocol defines four remote procedure calls: PING (probe a node to see if it is online), STORE (instruct a node to store a key–value pair), FIND_NODE (return the k nodes closest to a target ID) and FIND_VALUE (like FIND_NODE but returns the stored value if the recipient holds it).

Uses

Kademlia underpins several large peer-to-peer systems, including the BitTorrent Mainline DHT used for trackerless torrents, the Kad network of eMule, and node discovery in Ethereum. Its popularity stems from its provable efficiency — lookups require O(log n) messages — and its resistance to certain denial-of-service attacks through its preference for long-lived nodes in routing tables.
