Carrier-sense multiple access with collision avoidance

Carrier-sense multiple access with collision avoidance (CSMA/CA) is a network multiple access method in which a node verifies the absence of other traffic before transmitting on a shared medium. It is used where collision detection is impractical, most notably in IEEE 802.11 wireless LANs.

Operation

A station wishing to transmit listens to the channel. If the channel is idle for a distributed inter-frame space (DIFS), it may transmit; otherwise it defers and waits a random backoff interval, chosen from a contention window, before trying again. Because collisions cannot be reliably detected on a radio link, receivers acknowledge successful frames, and optional RTS/CTS handshaking can reserve the medium and mitigate the hidden node problem.
