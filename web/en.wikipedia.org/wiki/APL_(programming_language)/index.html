APL (programming language)

APL

Paradigm: Array, functional, structured, modular

Designed by: Kenneth E. Iverson

First appeared: 1966 (as an interactive system; notation from 1962)

Major implementations: Dyalog APL, APL2, GNU APL, NARS2000

Influenced: J, K, Q, MATLAB concepts, array features in many languages

APL (named after Iverson's book A Programming Language) is an interactive array-oriented programming language developed in the 1960s by Kenneth E. Iverson. Its central datatype is the multidimensional array, and it uses a large range of special graphic symbols to represent most functions and operators, making programs extremely concise — powerful operations on whole arrays can often be written in a single line.

Characteristics

APL's distinctive symbols (such as ⍳ iota, ⍴ rho, ⌈ ceiling, and ∘. outer product) originally required special typewriter typeballs and later custom keyboards and character sets; Unicode now includes the APL symbols. Expressions are evaluated strictly right-to-left with no operator precedence among functions. Famous one-liners include Conway's Game of Life in a single line and prime-number sieves in a handful of characters. Iverson received the 1979 Turing Award in part for this work, delivering the lecture "Notation as a Tool of Thought."

History and use

The notation was first published in Iverson's 1962 book and implemented at IBM in 1966 as APL\360, an influential early timesharing system. APL found a devoted following in finance, insurance, actuarial work, and scientific computing, and it survives today principally through Dyalog APL. Its descendants include J (using ASCII digraphs) and the K/Q languages used in finance.
