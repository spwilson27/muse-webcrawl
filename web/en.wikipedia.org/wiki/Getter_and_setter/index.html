Getter and setter

Accessor methods mediate access to an object's fields

In object-oriented programming, a getter and a setter (together called accessor and mutator methods) are methods used to read and write the value of a private field of an object. They support encapsulation: the internal representation of data is hidden, and all access passes through a controlled interface, allowing validation, lazy computation or change notification whenever a value is set.

Usage

By convention in languages such as Java, accessors are named getX() and setX() for a field x. Some languages, including C#, Python and Kotlin, provide property syntax so that field-like access invokes getter and setter logic behind the scenes.

// Java example
public class Person {
    private String name;
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}

Criticism

Automatically generated getters and setters for every field are sometimes criticised as violating the spirit of encapsulation — exposing object state rather than behaviour — and as adding boilerplate. Advocates argue they preserve flexibility: the internal storage can change without breaking client code, and invariants can be enforced centrally.
