Whitespace character

A whitespace character is a character that represents empty space when text is rendered — typically an invisible or blank gap that separates words, lines, or other elements rather than a visible glyph. Whitespace characters are essential to formatting, parsing, and typography in computing and in writing systems generally.

In computing

Regular expressions denote whitespace with the class \s, and most programming languages treat runs of whitespace as token separators; a few, notably Python, make indentation semantically significant, and the esoteric language Whitespace uses only spaces, tabs, and newlines as its entire syntax. Unicode assigns the property White_Space to 25 characters. Typographers distinguish visible spacing characters from formatting characters such as the zero-width joiner, which are not whitespace.
