Hierarchical database model

The hierarchical database model organises data into a tree structure of parent–child records: each child has exactly one parent, while a parent may have many children. It was the first widely used database model.

History

IBM's Information Management System (IMS), developed in the 1960s for the Apollo programme's bill of materials, is the canonical implementation and remains in use in banking and telecoms. Navigation is by traversing paths from the root segment, which is fast for predictable access patterns but rigid when relationships are many-to-many.

Comparison

It was largely superseded by the network model and then the relational model, though hierarchical storage survives in XML, LDAP directories and file systems.

References: IBM IMS documentation; Codd (1970) relational model paper.
