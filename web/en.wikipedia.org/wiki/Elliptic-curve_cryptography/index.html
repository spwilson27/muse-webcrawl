Elliptic-curve cryptography

Elliptic-curve cryptography (ECC) is an approach to public-key cryptography based on the algebraic structure of elliptic curves over finite fields. ECC allows smaller keys to provide equivalent security compared to non-EC cryptography (larger keys) based on Galois fields.

Elliptic curves are applicable for key agreement, digital signatures, pseudo-random generators and other tasks. The primary benefit promised by elliptic curve cryptography is a smaller key size, reducing storage and transmission requirements, while providing the same level of security.

Introduction

Public-key cryptography is based on the intractability of certain mathematical problems. Early public-key systems based on integer factorization, such as RSA, remain secure for large key sizes. For elliptic curves, the presumed difficulty of computing the discrete logarithm of a random elliptic curve element with respect to a publicly known base point has resisted analysis for decades; no efficient algorithm has been published that computes it in the general case.

Mathematical theory

For current cryptographic purposes, an elliptic curve is a plane curve over a finite field consisting of the points satisfying the equation y² = x³ + ax + b, together with a distinguished point at infinity. The set of points forms an abelian group in which the point at infinity serves as the identity element. Scalar multiplication — adding a point to itself n times — is the fundamental operation, and its one-way nature (easy to compute, hard to invert) underlies ECC security.

Domain parameters and key sizes

Because the most secure pairs of finite fields and elliptic curves cannot be subjected to a dedicated attack, standardised domain parameters are used, such as NIST P-256 and Curve25519. A 256-bit elliptic curve public key provides comparable security to a 3072-bit RSA public key.

Schemes

Well-known ECC schemes include the Elliptic Curve Diffie–Hellman (ECDH) key agreement protocol, the Elliptic Curve Digital Signature Algorithm (ECDSA), used in Bitcoin and in TLS, and the Edwards-curve Digital Signature Algorithm (EdDSA). ECC is widely deployed in Transport Layer Security (TLS) certificates and secure messaging.

Implementation challenges

The NSA's announcement in 2015 of plans to transition to quantum-resistant algorithms reflected the vulnerability of ECC to a sufficiently large quantum computer running Shor's algorithm, which could solve the ECDLP efficiently. Post-quantum cryptography standards have since been developed to succeed it.
