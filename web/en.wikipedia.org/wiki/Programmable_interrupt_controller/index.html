Programmable interrupt controller

In computing, a programmable interrupt controller (PIC) is an integrated circuit that helps a microprocessor (or CPU) handle interrupt requests (IRQs) coming from multiple different sources which may occur simultaneously. It helps prioritize IRQs so that the CPU switches execution to the most appropriate interrupt handler after the PIC assesses the IRQs' relative priorities.

Common types

The best known PIC, the Intel 8259, was included in the IBM Personal Computer and x86 PCs. In modern systems the 8259 has been largely superseded by the Advanced Programmable Interrupt Controller (APIC), which supports multiple processors and many more interrupt inputs.

Function

The PIC maintains registers for masking individual interrupt lines, recording pending and in-service requests, and assigning priorities. When an unmasked interrupt is pending and of sufficient priority, the PIC signals the CPU and supplies an interrupt vector identifying the source.
