Non-breaking hyphen

The non-breaking hyphen (U+2011) is a Unicode character that looks like a hyphen but does not allow a line wrap after it, analogous to the non-breaking space. It is used in typesetting and word processing to keep hyphenated words or numbers together on one line, such as in a part number or a compound name that must not be split.

Usage and support

Unlike the ordinary hyphen-minus (U+002D), which creates a break opportunity, the non-breaking hyphen suppresses it. Support varies: not all fonts contain the U+2011 glyph, and some rendering engines have historically substituted a regular hyphen or failed to display it. In HTML it may be written as the character itself or as a numeric character reference; word processors such as Microsoft Word insert it with a special keystroke (Ctrl+Shift+Hyphen).

Related characters

Other line-break control characters include the soft hyphen (U+00AD), which marks an optional break point and is visible only if used, and the word joiner (U+2060), which suppresses breaks around a character without adding a visible mark.
