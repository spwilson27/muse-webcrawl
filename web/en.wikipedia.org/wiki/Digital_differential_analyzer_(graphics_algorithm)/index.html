A digital differential analyzer (DDA) is a line-drawing algorithm used in computer graphics to rasterise a line segment between two endpoints. It works by sampling the line at uniform intervals along its dominant axis and rounding the computed coordinate on the other axis to the nearest pixel. The name is borrowed from the digital differential analyzer, a class of early computing machine that solved problems incrementally.

Algorithm

Given endpoints (x0, y0) and (x1, y1), the algorithm computes dx and dy, takes steps = max(|dx|, |dy|), and increments x by dx/steps and y by dy/steps at each of the steps, plotting the rounded coordinates. Because each step depends only on fixed increments added to running values, the method is simple and was well suited to early graphics hardware and software, though it relies on floating-point arithmetic and division.

Variants and successors

The same incremental principle extends to circles and other curves, and to texture-mapping and ray casting (for example grid traversal in tile-based games). For line drawing it was largely superseded by Bresenham's line algorithm (1962–65), which achieves the same result using only integer addition and subtraction, making it faster on early hardware.
