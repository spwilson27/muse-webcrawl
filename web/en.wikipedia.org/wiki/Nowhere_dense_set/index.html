Nowhere dense set

In mathematics, specifically general topology and descriptive set theory, a subset A of a topological space X is said to be nowhere dense or rare if its closure has empty interior. Equivalently, a set is nowhere dense if and only if in every non-empty open set U one can find a non-empty open set V contained in U and disjoint from A.

Definition

A subset A of a topological space X is nowhere dense if the interior of its closure is empty: int(cl(A)) = ∅. Characterisations include: the complement of the closure is dense in X; and every non-empty open subset of X contains a non-empty open subset disjoint from A.

Examples

  • The integers Z form a nowhere dense subset of the real line R.
  • Any finite subset of R is nowhere dense.
  • The Cantor set is nowhere dense in R, despite being uncountable and closed.
  • A "fat Cantor set" is closed and nowhere dense but has positive Lebesgue measure, showing that nowhere denseness does not imply measure zero.
  • The rationals Q are not nowhere dense in R, because their closure is all of R, whose interior is non-empty; they are instead dense.

Meagre sets and Baire category

A set that is a countable union of nowhere dense sets is called meagre or of the first category; all other sets are of the second category. The Baire category theorem states that a complete metric space is of the second category in itself, so a meagre subset cannot be the whole space. This underlies many existence proofs in functional analysis, such as the uniform boundedness principle.
