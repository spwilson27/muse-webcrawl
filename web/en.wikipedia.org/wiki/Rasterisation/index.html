Rasterisation

Rasterisation (also rasterization) is the process of taking an image described in a vector graphics format (shapes) and converting it into a raster image (a series of pixels, dots or lines, which, when displayed together, create the image which was represented via shapes). This conversion happens either in software or in dedicated graphics hardware, and it is the core technique by which real-time 3D graphics — games, CAD and visualisation — are rendered on essentially all modern GPUs.

Process

In a 3D rendering pipeline, objects are modelled as meshes of triangles. Vertices are transformed into screen space (clip space, then normalised device coordinates, then window coordinates), triangles are clipped against the view frustum, and the rasteriser determines which pixels (fragments) each triangle covers. For each fragment, attributes such as colour, depth, texture coordinates and normals are interpolated across the triangle — typically using barycentric coordinates with perspective correction — and passed to a fragment (pixel) shader that computes the final colour. A depth (z) buffer resolves visibility between overlapping fragments.

Line and polygon rasterisation

Classic algorithms include Bresenham's line algorithm and the midpoint algorithm for drawing lines, and scanline conversion for filling polygons. Because sampling a shape at discrete pixel positions produces aliasing — jagged edges or "jaggies" — graphics systems use antialiasing techniques such as supersampling (SSAA) and multisample antialiasing (MSAA), or post-process methods, to smooth the result.

Rasterisation versus ray tracing

Rasterisation projects geometry onto the image plane and therefore handles direct visibility very efficiently, but global effects such as reflections, refractions, soft shadows and indirect illumination must be approximated with tricks (shadow maps, environment maps, screen-space techniques). Ray tracing, which simulates the path of light rays through the scene, handles these effects naturally but has historically been far more expensive; modern GPUs increasingly combine the two, rasterising primary visibility and ray-tracing selected effects.

Other uses

The term is also used for the conversion of vector data to raster in printing (raster image processing, RIP), font rendering, mapping and GIS, and for converting vector artwork into bitmaps for display or print production.
