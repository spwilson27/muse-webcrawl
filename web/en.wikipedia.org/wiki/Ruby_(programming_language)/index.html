Ruby is a dynamic, reflective, object-oriented general-purpose programming language designed by Yukihiro Matsumoto in Japan and released in 1995. Matsumoto combined ideas from Perl, Smalltalk, Eiffel, Ada and Lisp, aiming for a language "optimised for programmer happiness" in which everything is an object and syntax reads naturally.

Features

Ruby has dynamic typing with duck typing, garbage collection, blocks and closures, metaprogramming, mixins via modules, and a rich standard library. Its philosophy follows the principle of least astonishment. Packages are distributed as "gems" through RubyGems, and dependencies are managed with Bundler. The reference implementation is MRI (Matz's Ruby Interpreter, now CRuby); Ruby 3.0 (2020) brought major performance work and RBS type signatures, and 3.2 added WebAssembly support and the YJIT just-in-time compiler.

Ruby on Rails and popularity

Ruby's popularity surged in the mid-2000s with David Heinemeier Hansson's Ruby on Rails web framework, whose conventions powered early versions of Twitter, GitHub, Shopify, Airbnb and many other services. Although its mainstream ranking has since cooled relative to JavaScript and Python, Ruby remains widely used in web development, DevOps tooling (Chef, Vagrant, Homebrew), and prototyping.
