RANSAC

Random sample consensus (RANSAC) is an iterative method to estimate parameters of a mathematical model from a set of observed data that contains outliers, when outliers are to be accorded no influence on the values of the estimates. Therefore, it is also a non-deterministic algorithm in the sense that it produces a reasonable result only with a certain probability, and this probability increases as more iterations are allowed. The algorithm was first published by Fischler and Bolles at SRI International in 1981.

Overview

RANSAC repeatedly selects a random minimal subset of the data, fits a model to that subset, and counts how many other data points agree with the model within a tolerance (the inliers, or consensus set). The model with the largest consensus set is kept, and may be refitted using all of its inliers. The number of iterations required can be computed from the desired success probability, the estimated outlier fraction, and the size of the minimal sample.

Applications

RANSAC is widely used in computer vision, for example in estimating the fundamental matrix and homographies in stereo matching and image stitching, in fitting geometric primitives (lines, circles, planes) to noisy data, and in robotics and structure-from-motion pipelines. Variants such as MSAC, MLESAC, and PROSAC improve scoring or sampling strategies.

Advantages and limitations

RANSAC is robust to a large fraction of outliers — it can succeed when more than half the data is contaminated — but it can fail when the inlier structure is weak or the threshold is poorly chosen, and its runtime grows as the outlier ratio rises.
