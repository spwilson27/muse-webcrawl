MMX (instruction set)

MMX is a single instruction, multiple data (SIMD) instruction set architecture designed by Intel, introduced on 8 January 1997 with its Pentium P5 (microarchitecture)-based line of microprocessors, named "Pentium with MMX Technology". It was developed from a similar unit introduced on the Intel i860 and earlier Intel i750 video pixel processor.

MMX
Designer: Intel
Introduced: 1997
Registers: MM0–MM7 (aliased to x87 stack)
Data types: Packed 8/16/32-bit integers
Successor: SSE

Technical details

MMX added 57 new instructions operating on eight 64-bit registers holding packed integer data, enabling parallel arithmetic useful for multimedia, graphics and communications workloads. The MMX registers aliased the existing x87 floating-point registers, which complicated simultaneous use of floating point and MMX code.

Legacy

MMX was succeeded by SSE and its successors, which introduced dedicated registers and floating-point SIMD. The MMX name — officially not an acronym, though often read as "MultiMedia eXtensions" — is a trademark of Intel.
