Algebra (universal algebra)

In universal algebra, an algebra (or algebraic structure) is a set A together with a collection of operations on A. The set A is called the carrier set (or underlying set), and the operations are typically finitary — each takes a finite number of inputs (its arity) and returns a single element of A. Nullary operations correspond to distinguished constant elements of the carrier.

Definition and examples

The list of arities of the operations is called the signature (or type) of the algebra. Familiar algebraic structures are all instances of this notion: a group is an algebra with one binary operation, one unary operation (inverse) and one constant (identity); a ring has two binary operations and two constants; a lattice has two binary operations. Structures studied in universal algebra are required to be defined by equations (identities) alone — a class of algebras satisfying a set of identities is called a variety.

Basic concepts

Key notions include subalgebras, homomorphisms between algebras of the same signature, congruences and quotient algebras, and product algebras. Birkhoff's HSP theorem characterises varieties as exactly those classes of algebras closed under homomorphic images, subalgebras and products.
