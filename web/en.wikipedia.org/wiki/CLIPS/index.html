CLIPS

CLIPS (C Language Integrated Production System) is a public-domain software tool for building expert systems. Originally developed at NASA's Johnson Space Center beginning in 1985 as an alternative to the Lisp-based ART system, CLIPS is written in C for portability and speed, and its syntax and name were inspired by Charles Forgy's OPS5 production system language.

Description

A CLIPS program consists of rules, facts, and objects. Facts are stored in a working memory (fact list), and rules — written with defrule — specify patterns of facts that, when matched, cause actions to execute. Pattern matching is performed efficiently by the Rete algorithm. CLIPS provides three programming paradigms:

  • Rule-based programming using forward-chaining rules over facts;
  • Object-oriented programming through COOL, the CLIPS Object-Oriented Language;
  • Procedural programming with functions written in a Lisp-like syntax.

Because the engine is written in C, CLIPS can be embedded in other applications, and it has been extended through interfaces such as CLIPSJNI (Java), CLIPSPy (Python), and various GUI environments.

History and use

NASA released CLIPS freely, and it became one of the most widely used expert system shells in universities and industry, used for teaching artificial intelligence and for deployed diagnostic, monitoring, and decision-support systems. Development stewardship passed from NASA to the open-source community; modern versions (6.3x and 6.4x) are maintained on public repositories and continue to add features such as Unicode support.
