Azure Kubernetes Service (AKS) is a managed container orchestration service provided by Microsoft Azure, based on the open-source Kubernetes system. Azure manages the Kubernetes control plane at no charge, while users pay for the virtual machines that run workloads.

Features

AKS offers automated upgrades, cluster autoscaling, integration with Azure Active Directory (Microsoft Entra ID), Azure Monitor, and Azure networking, along with features such as confidential computing node pools and workload identity.

History

The service evolved from the Azure Container Service; after Microsoft joined the Cloud Native Computing Foundation in 2017, the Kubernetes-focused offering was rebranded as AKS and became generally available in June 2018.
