Multithreading (computer architecture)

In computer architecture, multithreading is the ability of a central processing unit (CPU) — or a single core in a multi-core processor — to provide multiple threads of execution concurrently, supported by the processor hardware. It should not be confused with software multithreading managed by an operating system scheduler.

Approaches

Temporal multithreading allows a single core to switch between threads, keeping only one thread's instructions in the pipeline at a time. In coarse-grained multithreading, the core switches threads on a long-latency event such as a cache miss; in fine-grained (interleaved) multithreading, the core switches threads every cycle, as in the CDC 6600's peripheral processors and many RISC designs.

Simultaneous multithreading (SMT) allows instructions from multiple threads to be issued and executed in the same cycle, exploiting instruction-level parallelism within a superscalar pipeline. Intel markets its implementation as Hyper-Threading, which debuted in the Pentium 4 in 2002. AMD's Zen processors and IBM's POWER series also implement SMT with two or more threads per core.

Benefits and costs

Hardware multithreading improves utilisation of execution resources that would otherwise idle during memory stalls, raising throughput especially in server workloads. The costs include duplicated architectural state (register files, program counters) and shared-resource contention, and SMT has been implicated in side-channel attacks such as TLBleed and MDS vulnerabilities.
