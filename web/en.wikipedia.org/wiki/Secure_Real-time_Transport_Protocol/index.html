Secure Real-time Transport Protocol

The Secure Real-time Transport Protocol (SRTP) is a profile for the Real-time Transport Protocol (RTP) intended to provide encryption, message authentication and integrity, and replay attack protection to the RTP data in both unicast and multicast applications. It was developed by a small team of Internet Protocol and cryptographic experts from Cisco and Ericsson, and was first published by the IETF in March 2004 as RFC 3711.

Features

SRTP provides confidentiality by encrypting the RTP payload, by default with the Advanced Encryption Standard (AES) in counter mode or segment integer counter mode, which allows parallel processing and low latency suitable for real-time media. Message authentication and integrity are provided using HMAC-SHA1, producing an authentication tag appended to each packet. A sliding window mechanism provides protection against replay attacks.

The protocol defines a corresponding secure control protocol, SRTCP, for the Real-time Transport Control Protocol (RTCP). SRTP adds minimal overhead: the default authentication tag is 80 bits for SRTP and 32 bits for SRTCP, and the packet header is transmitted in the clear so that header compression and quality-of-service features continue to work.

Key management

SRTP itself does not provide key exchange; session keys are established by external protocols such as ZRTP, DTLS-SRTP (RFC 5764), MIKEY (RFC 3830), or SDES (RFC 4568), in which key material is exchanged in the Session Description Protocol during call setup.

Applications

SRTP is widely used in Voice over IP, videoconferencing, and WebRTC, in which DTLS-SRTP is mandatory for media transport.
