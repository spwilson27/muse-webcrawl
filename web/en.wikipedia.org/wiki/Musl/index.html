musl

musl is a C standard library intended for operating systems based on the Linux kernel, released under the MIT License. It was developed by Rich Felker and others with the aim of providing a small, fast, simple and correct implementation of the standard functions defined in the C and POSIX standards, in contrast to the larger and more feature-rich glibc. musl is designed for static linking and efficient embedded and system use, and is the standard C library of Alpine Linux and Void Linux's musl edition, and is widely used in container images because it produces small binaries.

Design

musl emphasises standards conformance, robustness against resource exhaustion, and a small code size. Its dynamic linker and library are implemented as a single file, and it supports static linking without the licensing and runtime complications associated with glibc. musl implements the functions normally found in the libc, libm, libpthread, librt and related libraries of a typical Linux system.

Compatibility

Because musl omits some glibc-specific extensions and handles certain locales and name-service lookups differently (for example, it historically lacked NSS-based user database lookups and implements its own DNS resolver), software written against glibc occasionally requires adjustment to run on musl-based systems. Distributions such as Alpine Linux patch packages accordingly.
