Flow-based programming

Flow-based programming (FBP) is a programming paradigm that defines applications as networks of 'black box' processes exchanging data across predefined connections by message passing, with connections specified externally to the processes.

History

FBP was invented by Canadian engineer J. Paul Morrison at IBM in the early 1970s, influenced by dataflow concepts.

In FBP, processes run asynchronously, data travels in packets along connections with bounded buffers, and the network definition is often expressed as a diagram or textual graph.

Applications

The paradigm anticipates modern dataflow and stream-processing systems and has implementations in languages including Java, C#, and JavaScript (such as NoFlo).
