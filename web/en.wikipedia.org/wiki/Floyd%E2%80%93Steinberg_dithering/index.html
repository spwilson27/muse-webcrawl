Floyd–Steinberg dithering

Floyd–Steinberg dithering is an image dithering algorithm first published in 1976 by Robert W. Floyd and Louis Steinberg, widely used by image manipulation software to approximate colours unavailable in a limited palette by diffusing quantisation error to neighbouring pixels.

Algorithm

The algorithm processes pixels left to right, top to bottom, quantising each to the nearest available colour and distributing the error to neighbours with weights 7/16 to the right, 3/16 below-left, 5/16 below, and 1/16 below-right.

Applications

It is a classic error-diffusion method used when converting images to indexed colour formats such as GIF, and in printing and display rendering.
