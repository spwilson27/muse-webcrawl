Model–view–controller

Model–view–controller (MVC) is a software design pattern commonly used for developing user interfaces that divides the related program logic into three interconnected elements: the model (data and business logic), the view (presentation), and the controller (input handling).

History

MVC was described in 1979 by Trygve Reenskaug, then working on the Smalltalk language at Xerox PARC. It later became the foundation of many web application frameworks, including Ruby on Rails, Django, and ASP.NET MVC.

Components

The model manages data and rules, the view renders output to the user, and the controller converts user input into commands for the model or view.
