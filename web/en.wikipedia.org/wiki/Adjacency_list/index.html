Adjacency list

In graph theory and computer science, an adjacency list is a collection of unordered lists used to represent a finite graph. Each list describes the set of neighbors of a vertex in the graph. This is one of several commonly used representations of graphs for use in computer programs, alongside the adjacency matrix and the incidence matrix.

Implementation details

An adjacency list representation for a graph associates each vertex in the graph with the collection of its neighboring vertices or edges. There are many variations of this idea, differing in details of how they implement the association between vertices and collections, in how they implement the collections, in whether they include both directions of an edge or only one, and in what kinds of objects may be used as vertices and edge objects. In many implementations, the collection for each vertex is a linked list or a dynamic array; in languages such as Python, adjacency lists are often dictionaries mapping each vertex to a list or set of neighbors.

Operations

The main operation performed by an adjacency list is to report a list of the neighbors of a given vertex; this takes time proportional to the number of neighbors reported (the degree of the vertex). With adjacency lists, testing whether an edge exists between two given vertices can be done by scanning the shorter of their two neighbor lists, and can be accelerated with hash sets or sorted lists. Traversals such as breadth-first search and depth-first search run in time O(|V| + |E|) with this representation.

Tradeoffs

Adjacency lists require space proportional to the number of edges plus vertices, O(|V| + |E|), making them far more space-efficient than adjacency matrices, which need Θ(|V|²) space, for the sparse graphs that arise in most applications. Conversely, adjacency matrices answer edge-existence queries in constant time and better suit dense graphs and matrix-based algorithms. For weighted graphs, adjacency lists store the weight alongside each neighbor entry.
