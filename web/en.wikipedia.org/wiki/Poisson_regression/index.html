Poisson regression

In statistics, Poisson regression is a generalized linear model used to model count data and contingency tables. It assumes the response variable Y follows a Poisson distribution, and models the logarithm of its expected value as a linear combination of explanatory variables.

Model

Given predictor variables x, the model specifies

log(E(Y | x)) = α + β′x,

so that the expected count is E(Y | x) = exp(α + β′x). The logarithmic link function ensures that predicted counts are always positive. Coefficients are interpreted multiplicatively: a one-unit increase in a predictor multiplies the expected count by eβ, an incidence rate ratio.

Estimation

Parameters are estimated by maximum likelihood, typically using iteratively reweighted least squares. The Poisson distribution has the restrictive property that its mean equals its variance. When real count data exhibit variance greater than the mean — overdispersion — standard errors from ordinary Poisson regression will be too small. Common remedies include quasi-Poisson models, robust (sandwich) standard errors, and negative binomial regression.

Exposure and offset

If counts arise over different periods of time, population sizes, or areas, an offset term — the logarithm of the exposure — is included so that the model describes rates rather than raw counts. For example, disease counts in different cities can be modelled with log(population) as an offset.

Applications

Poisson regression is widely used in epidemiology (disease incidence), insurance (claim counts), criminology, ecology, and traffic safety analysis — any setting where the outcome is a non-negative integer count of events.
