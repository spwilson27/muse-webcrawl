Data migration

Data migration is the process of selecting, preparing, extracting, and transforming data and permanently transferring it from one computer storage system to another. Additionally, the validation of migrated data for completeness and the decommissioning of legacy data storage are considered part of the entire data migration process. Data migration is a key consideration for any system implementation, upgrade, or consolidation, and it is typically performed in such a way as to be as automated as possible, freeing up human resources from tedious tasks.

Data migration occurs for a variety of reasons, including server or storage equipment replacements, maintenance or upgrades, application migration, website consolidation, disaster recovery, and data center relocation.

Categories

Data may be migrated between many different locations and formats. Examples include migration between databases, migration of application data when a company replaces its enterprise resource planning system, and migration from local storage to cloud storage. The major categories of migration include storage migration, database migration, application migration, and business process migration.

Process

A typical migration project involves analysis of the source data, design of the mapping to the target system, extraction, transformation and loading (ETL), testing, validation, and cleansing of data that does not meet quality requirements. Poorly planned migrations can result in data loss or corrupted records, so verification against the source is an essential final step.
