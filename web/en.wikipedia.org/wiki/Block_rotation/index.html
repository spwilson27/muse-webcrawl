Block rotation

Block rotation is an in-place algorithm for rotating an array — that is, exchanging two adjacent blocks of elements of possibly different lengths — using only a constant amount of additional storage. Rotating an array is a fundamental operation used in algorithms such as in-place merging during merge sort, and block rotation is the key primitive behind several in-place stable sorting methods.

Problem

Given an array containing two contiguous blocks A and B, the rotation replaces the sequence A B with B A while preserving the internal order of each block. A naive implementation copies one block to a temporary buffer, but a true block rotation uses only O(1) extra space.

Algorithms

Reversal algorithm

The best-known method uses three reversals: reverse A, reverse B, then reverse the whole array. Reversing each element range is a simple in-place operation, so the total running time is linear and the extra space is constant.

Juggling algorithm

The juggling (or dolphin) algorithm moves elements one at a time along cycles determined by the greatest common divisor of the array length and the rotation distance. It touches each element exactly once but accesses memory in a less cache-friendly pattern.

Gries–Mills algorithm

The Gries–Mills algorithm repeatedly swaps the smaller block with an equal-sized portion of the larger block, reducing the problem until both blocks are equal in size and can be exchanged directly. It performs more swaps than the reversal method but is the basis of some in-place merge procedures.

Applications

Block rotation is used in in-place stable merge sort, in implementations of the C++ standard library std::rotate, and in buffer management where contiguous regions must be exchanged without auxiliary storage.
