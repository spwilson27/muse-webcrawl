sbt (software)

sbt
Developer: Lightbend and community
Written in: Scala
Type: Build automation tool
License: Apache 2.0

sbt (Scala Build Tool) is an open-source build automation tool mainly used for Scala and Java projects. It is the standard build tool in the Scala ecosystem and is known for its interactive shell, incremental compilation, and a build definition written in Scala itself.

Features

sbt provides continuous compilation and testing triggered by source changes, incremental compilation using the Zinc compiler, support for mixed Scala/Java projects, and dependency management via Apache Ivy or Coursier using Maven-format repositories. Its interactive mode allows commands to be run repeatedly without restarting the JVM, speeding up the development cycle.

Build definitions

Builds are defined in a build.sbt file using a domain-specific language based on Scala. Tasks, settings, and dependencies form a dependency graph that sbt evaluates in parallel. Projects can be composed into multi-module builds, and functionality can be extended through a rich ecosystem of plugins, such as those for packaging, code formatting, and deployment.

History

sbt was originally developed by Mark Harrah. Version 1.0, released in 2017, stabilized much of its internals while keeping compatibility with the 0.13 series of build definitions. It is maintained by Lightbend (formerly Typesafe) together with the Scala community.
