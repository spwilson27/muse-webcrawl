Replication (computing)

Replication in computing involves sharing information so as to ensure consistency between redundant resources, such as software or hardware components, to improve reliability, fault-tolerance, or accessibility. Replication is widely used in databases, file systems and distributed systems, where copies of data are maintained on multiple machines.

Types

In active replication (state machine replication), every replica processes every request, so replicas stay identical if they start from the same state and process requests in the same order. In passive replication, a primary replica processes requests and sends state updates to backup replicas. Multi-primary (multi-master) schemes allow updates at several replicas and require conflict resolution; leader-based schemes funnel writes through one node and propagate them to followers.

Consistency models

Replication forces trade-offs captured by results such as the CAP theorem. Synchronous replication can offer strong consistency, in which all replicas appear as a single up-to-date copy, at the cost of latency and availability. Asynchronous replication improves performance but may lose recent updates on failure or serve stale reads, giving eventual consistency. Consensus algorithms such as Paxos and Raft keep replicated logs consistent in the presence of failures.

Database replication

Database systems support replication through transaction logs: a primary ships log records to replicas that replay them. Implementations include primary–replica replication in MySQL and PostgreSQL, multi-master systems such as Galera, and globally distributed services using quorum protocols.
