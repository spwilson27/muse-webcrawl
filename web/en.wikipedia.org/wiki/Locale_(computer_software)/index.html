Locale (computer software)

From Wikipedia, the free encyclopedia
Language and region settings define the locale

In computing, a locale is a set of parameters that defines a user's language, region and cultural conventions, used to localise the behaviour of software: how dates and times are written, which decimal separator and thousands separator numbers use, how currency is formatted, in what order text is sorted (collation), which character encoding and paper size apply, and in which language messages are displayed.

Identification and implementation

Locales are identified by language tags: on POSIX systems by names such as en_US.UTF-8 (language, territory, encoding), set through environment variables like LANG and the LC_* family (LC_TIME, LC_MONETARY, LC_COLLATE and so on); on the web and in modern frameworks by BCP 47 tags such as en-GB or zh-Hans-CN. The Unicode Consortium's CLDR (Common Locale Data Repository) supplies the standard data — date patterns, number formats, exemplar characters and translations of region and language names — consumed by the ICU library and by the internationalisation facilities of Java, JavaScript (Intl) and other platforms. Classic pitfalls of locale-insensitive code include the "Turkish I problem" (in Turkish locales, the lowercase of I is the dotless ı, which has broken case-insensitive comparisons in software), ambiguity between day-first and month-first dates, and sorting orders that differ by language — Swedish, for example, sorts å, ä and ö after z. Locale belongs to the broader discipline of internationalisation and localisation (i18n/L10n), of which localization in the neurological sense is an unrelated namesake.
