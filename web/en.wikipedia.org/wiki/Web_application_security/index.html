Web application security

Web application security is the branch of information security concerned with protecting websites and web applications from attacks that exploit application-level vulnerabilities. Because web applications are publicly reachable and handle sensitive data, they are among the most frequently attacked systems on the internet.

Common vulnerabilities

The OWASP Top 10, published by the Open Web Application Security Project, periodically ranks the most critical risks. Long-standing entries include injection attacks (such as SQL injection), broken access control, cross-site scripting (XSS), insecure design, security misconfiguration, vulnerable components, authentication failures and server-side request forgery. The CWE database catalogues the underlying weakness types.

Countermeasures

Defences include input validation and parameterised queries, output encoding, strong authentication and session management, least-privilege design, security headers and TLS encryption, regular patching, and testing techniques such as static and dynamic analysis and penetration testing. Web application firewalls can filter malicious requests, though they do not replace secure development practices. Standards such as the OWASP Application Security Verification Standard define requirements for building and testing secure applications.
