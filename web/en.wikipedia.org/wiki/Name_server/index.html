Name server

From Wikipedia, the free encyclopedia
[Image: Diagram of a DNS query travelling from a resolver to root, TLD and authoritative name servers]

A name server is a computer application or server that implements a network service for providing responses to queries against a directory service — in practice, almost always the Domain Name System (DNS), which translates human-readable domain names into IP addresses.

Two roles are commonly distinguished. Authoritative name servers hold the original records for a zone (a domain and its subdomains): the TLD registries run them for endings like .com, and every registered domain delegates to its own authoritative servers, which answer with final authority about addresses, mail servers (MX records) and other data. Recursive resolvers, usually run by ISPs or public services such as Google Public DNS and Cloudflare's 1.1.1.1, do the legwork for users: starting from the 13 logical root server addresses, they chase referrals down the hierarchy and cache answers according to each record's time-to-live.

The root name servers at the top of this system are operated by twelve organisations under IANA coordination, replicated worldwide by anycast so that the same address is answered from hundreds of physical sites — a key part of the Internet's resilience.
