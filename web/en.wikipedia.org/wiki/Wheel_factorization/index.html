Wheel factorization

Wheel factorization is a method for generating integers that are not divisible by a given set of small primes, used to speed up trial division and prime sieving. It is a generalisation of the simple observation that, after 2, every prime is odd, so when searching for primes one need only test odd numbers.

How it works

Given the first few primes, say 2, 3 and 5, every integer coprime to 30 must be congruent to one of 1, 7, 11, 13, 17, 19, 23 or 29 modulo 30. These residues repeat with period 30, forming a "wheel" of spokes: one turns the wheel by adding the successive gaps (6, 4, 2, 4, 2, 4, 6, 2) to generate candidates. All primes greater than 5 appear among these candidates, though many composites do too — the wheel merely eliminates multiples of 2, 3 and 5 without any division.

A wheel based on the first k primes has φ(p1…pk) spokes, where φ is Euler's totient function. Larger wheels eliminate more composites but need more memory for the gap pattern: the wheel for 2, 3, 5, 7 has 48 spokes with period 210, and the wheel for 2, 3, 5, 7, 11 has 480 spokes with period 2310.

Uses

Wheel factorization is used inside segmented sieves and in the initial trial-division stage of primality tests and integer factorisation routines. It is a simple, division-free pre-filter that removes a large fraction of composite candidates before more expensive tests are applied.
