Set theory

From Wikipedia, the free encyclopedia

Set theory is the branch of mathematical logic that studies sets — collections of objects. Developed largely by Georg Cantor from the 1870s, set theory provides the standard foundational framework for mathematics: numbers, functions and geometric objects can all be defined as sets, and most of mathematics can be derived from its axioms, standardly the Zermelo–Fraenkel axioms with the axiom of choice (ZFC).

Basic concepts

Sets are written with braces, {1, 2, 3}, and related by membership (∈), subsets, unions, intersections and complements, visualised with Venn diagrams. Cantor showed that some infinities are larger than others: the real numbers are 'uncountable' — a proof using his famous diagonal argument.

Foundations and paradoxes

Naive set theory led to paradoxes such as Russell's paradox (the set of all sets that do not contain themselves), motivating axiomatic systems. The continuum hypothesis, about whether an infinity exists between the integers and the reals, was shown to be independent of ZFC by Gödel and Cohen.
