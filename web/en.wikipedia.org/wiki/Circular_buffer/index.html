Circular buffer

A circular buffer with read and write positions.

A circular buffer, circular queue, or ring buffer is a data structure that uses a single, fixed-size buffer as if it were connected end-to-end, forming a ring. It is a common implementation of a queue for streaming data: elements are written at a "tail" position and read from a "head" position, and both indices advance modulo the buffer size, wrapping around to the beginning when they reach the end. When the writer laps the reader, the oldest unread data is overwritten, so the structure naturally keeps the most recent items — the standard behaviour of a first-in, first-out buffer of bounded size.

Implementation

A circular buffer is typically implemented as an array together with read and write index variables. The buffer is empty when the indices are equal (or when a count is zero) and full when the write index is about to overtake the read index; implementations either keep an explicit element count, reserve one empty slot to distinguish full from empty, or use monotonically increasing sequence numbers. All operations are constant-time and require no memory allocation or data movement, which makes the structure attractive in embedded systems.

Uses

Circular buffers are used wherever producers and consumers of data run at different rates: audio and video streaming, keyboard and serial-port input buffers in operating systems, network packet queues, sensor logging, digital signal processing delay lines, and audio delay and reverb effects. Lock-free single-producer/single-consumer ring buffers are a standard mechanism for low-latency communication between threads and in high-frequency trading systems.
