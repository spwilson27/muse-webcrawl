Blink (browser engine)

Developer: Google and contributors
Initial release: 2013
Written in: C++
Type: Browser engine
License: BSD and LGPL

Blink is a browser engine developed as part of the Chromium project by Google and other contributors. It is a fork of the WebCore component of the WebKit engine, announced in April 2013.

Usage

Blink powers Google Chrome, Microsoft Edge (since 2020), Opera, Brave, Vivaldi and many other Chromium-based browsers, giving it the largest share of any browser engine. The name was chosen as a tongue-in-cheek reference to the non-standard <blink> HTML tag.

Architecture

Blink handles parsing of HTML and CSS, layout, painting and compositing, working alongside the V8 JavaScript engine. Its development emphasises a multi-process architecture inherited from Chromium.
