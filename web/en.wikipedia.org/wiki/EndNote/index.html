EndNote

DeveloperClarivate
TypeReference management software
PlatformsWindows, macOS, web

EndNote is a commercial reference management software package used to manage bibliographies and references when writing essays, reports, and academic articles. It is produced by Clarivate.

Features

EndNote allows users to build a personal library of references imported from online databases, organise them into groups, attach full-text PDFs, and insert citations into word-processing documents in thousands of journal styles, automatically generating bibliographies. Its "Cite While You Write" plug-in integrates with Microsoft Word and other editors. EndNote also supports sharing libraries with collaborators and syncing through EndNote Online.

History

EndNote was first released in the late 1980s by Niles Software. It passed through Thomson Reuters' research software division before becoming part of Clarivate. Version numbering reached EndNote 20 in 2020, followed by later annual releases with redesigned interfaces and improved PDF handling.

File formats

EndNote's native library files use the .enl extension with an accompanying data folder. It can import and export common bibliographic formats such as BibTeX and RIS.
