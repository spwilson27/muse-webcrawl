Program refinement

Program refinement (also called stepwise refinement) is an approach to software development in which a program is derived from a formal specification through a sequence of correctness-preserving transformations, each replacing an abstract construct by a more concrete one until executable code is reached. It is a central technique of formal methods.

History

The idea grew from Niklaus Wirth's stepwise refinement in structured programming and was given a rigorous basis in the work of Edsger Dijkstra, C. A. R. Hoare, and Ralph Back, and in the refinement calculus of Carroll Morgan. Languages and notations supporting refinement include the B-Method, Z notation, and Event-B.

Refinement laws

Refinement calculi provide laws for introducing sequence, selection and iteration, for replacing a specification statement with code that satisfies it, for introducing local variables and procedures, and for transforming data representations (data refinement). Because every step preserves correctness with respect to the specification, the final program is correct by construction.
