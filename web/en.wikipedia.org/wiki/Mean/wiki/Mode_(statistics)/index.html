Mode (statistics)

The mode is the value that appears most often in a set of data values. If X is a discrete random variable, the mode is the value x at which the probability mass function takes its maximum value. In other words, it is the value that is most likely to be sampled. Like the statistical mean and median, the mode is a way of expressing, in a (usually) single number, important information about a random variable or a population.

Properties

  • The mode is the only measure of central tendency applicable to nominal (categorical) data, such as the most popular flavour of ice cream.
  • A data set may have one mode (unimodal), two modes (bimodal), several modes (multimodal), or no mode if all values occur equally often.
  • For a continuous distribution, the mode is the point at which the probability density function attains its maximum.
  • Unlike the mean, the mode always coincides with an observed value (for discrete data), but it can be unstable for small samples.

Comparison with mean and median

In a symmetric unimodal distribution, the mode, median, and mean all coincide. In a skewed distribution they differ; Karl Pearson proposed an empirical relation, mean − mode ≈ 3(mean − median), for moderately skewed distributions. The mode is used in fields such as manufacturing (most common shoe size stocked), polling, and signal processing.

History

The term "mode" originates with Karl Pearson in 1894, borrowed from the French la mode (fashion), since the most frequent value is in a sense the "most fashionable" value.
