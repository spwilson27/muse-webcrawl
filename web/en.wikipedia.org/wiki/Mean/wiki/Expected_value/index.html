Expected value

In probability theory, the expected value (also called expectation, mathematical expectation, mean, average, or first moment) is a generalization of the weighted average. Informally, the expected value is the arithmetic mean of a large number of independently selected outcomes of a random variable.

The expected value of a random variable with a finite number of outcomes is a weighted average of all possible outcomes. In the case of a continuum of possible outcomes, the expectation is defined by integration. In the axiomatic foundation for probability provided by measure theory, the expectation is given by the Lebesgue integral.

Definition

For a discrete random variable X with values x1, x2, ... and probabilities p1, p2, ..., the expected value is

E[X] = Σ xi pi

For a continuous random variable with probability density function f(x), the expected value is

E[X] = ∫ x f(x) dx

Properties

  • Linearity: E[aX + bY] = aE[X] + bE[Y] for constants a and b.
  • Constants: E[c] = c for any constant c.
  • Law of the unconscious statistician: for a function g, E[g(X)] can be computed from the distribution of X alone.
  • Inequalities: Jensen's inequality relates E[g(X)] to g(E[X]) for convex functions.

History

The idea of the expected value originated in the middle of the 17th century from the study of the problem of points, which seeks to divide the stakes of an unfinished game of chance fairly between two players who must end the game before it is finished. The problem was famously discussed in correspondence between Blaise Pascal and Pierre de Fermat in 1654, and Christiaan Huygens published a treatment in 1657.

Applications

Expected value is used throughout probability, statistics, economics, finance (as expected return), gambling, and decision theory, where choices are ranked by their expected outcomes. The expected value of a fair game is zero net gain, and games of chance offered by casinos are generally set slightly in the house's favour.
