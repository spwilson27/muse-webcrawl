List edge coloring

In mathematics, list edge coloring is a type of graph coloring that combines list coloring with edge coloring. An instance of a list edge coloring problem consists of a graph together with a list of allowed colors for each edge. A list edge coloring is a choice of a color for each edge, from its list, such that no two adjacent edges receive the same color; it is proper if it satisfies this condition. A graph is k-edge-choosable if every instance with lists of size k has a proper list edge coloring. The smallest such k is the list chromatic index of the graph.

List coloring conjecture

The list coloring conjecture (also called the list edge coloring conjecture) states that the list chromatic index of every graph equals its ordinary chromatic index — that is, list edge coloring is no harder than ordinary edge coloring. By Vizing's theorem, the chromatic index of a graph with maximum degree Δ is either Δ or Δ + 1, so the conjecture asserts that the list chromatic index is likewise Δ or Δ + 1, whichever applies.

The conjecture has been attributed to several authors in the 1970s and 1980s, including Vizing, Erdős, Rubin, and Taylor. It remains unproven in general, but has been verified for many classes of graphs, including bipartite graphs (proved by Galvin in 1995 using the kernel method), graphs with small maximum degree, and planar graphs under certain conditions.

Related results

Galvin's theorem states that the list chromatic index of a bipartite graph equals its chromatic index. This result settled the list coloring conjecture for the important special case of bipartite multigraphs, and by König's line coloring theorem the common value equals the maximum degree of the graph.

List edge coloring arises naturally in connection with the Dinitz conjecture on Latin squares, which was proved using related methods before Galvin's more general theorem.
