Quotient set

In mathematics, a quotient set is a set derived from another set by an equivalence relation. Given a set A and an equivalence relation ~ on A, the quotient set A/~ is the set of all equivalence classes of A under ~:

A/~ = { [x] : x ∈ A }, where [x] = { y ∈ A : y ~ x }.

Partitioning a set into equivalence classes

Examples

A standard example is modular arithmetic: the integers modulo n are the quotient of Z by the relation "a ~ b if n divides a − b", giving the set Z/nZ of n residue classes. The rational numbers can likewise be constructed as a quotient of pairs of integers, and in group theory the cosets of a normal subgroup partition a group, forming a quotient group.

Canonical projection

Every quotient set comes with a natural surjection, called the canonical projection (or quotient map), π: A → A/~, sending each element to its own equivalence class. Functions defined on a quotient set must be checked for well-definedness: a definition made using a representative of a class must not depend on which representative was chosen. Quotients are the standard way to "identify" points of a space or set, and quotient constructions pervade algebra and topology (quotient spaces).
