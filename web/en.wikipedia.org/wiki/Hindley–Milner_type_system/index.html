Hindley–Milner type system

Hindley–Milner
Designed byJ. Roger Hindley (1969); Robin Milner (1978)
Key propertyComplete type inference; principal types
Used inML, Haskell, OCaml, F#, Rust (in part)

A Hindley–Milner (HM) type system is a classical type system for the lambda calculus with parametric polymorphism. It was described by J. Roger Hindley in 1969 and rediscovered and extended by Robin Milner in 1978 in connection with the ML programming language. Its most remarkable property is that a complete, sound type inference algorithm exists — Algorithm W — which always infers the most general (principal) type of an expression without any type annotations.

Features

HM combines simply typed lambda calculus with let-polymorphism: a value bound by a let expression may be used at several different types, because its type is generalised into a type scheme (a universally quantified type) before use. For example, the identity function can be given the scheme ∀a. a → a, allowing it to be applied both to integers and to strings within the same program.

Type inference proceeds by generating equality constraints between type expressions and solving them with unification, generalising free type variables at let-bindings. Luis Damas and Milner proved the soundness and completeness of Algorithm W in 1982.

Influence and limitations

HM-style inference is the foundation of the type systems of the ML family (Standard ML, OCaml), Haskell, Clean, F# and many other languages, and has influenced languages such as Rust and Swift. Its principal limitations include the lack of subtyping, difficulty with higher-rank polymorphism, mutable references (addressed in ML by the value restriction), and the fact that error messages from global unification can be hard to localise.
