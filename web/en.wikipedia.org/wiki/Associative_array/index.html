Associative array

An associative array stores pairs of unique keys and their values.

An associative array, also called a map, dictionary or symbol table, is an abstract data type that stores a collection of (key, value) pairs, such that each possible key appears at most once. It supports operations to add a pair, remove a pair, modify the value of an existing key, and look up the value associated with a key. Unlike an ordinary array, whose indices are consecutive integers, associative arrays allow keys of arbitrary types, most commonly strings.

Operations

The core operations are insert (add or replace a key–value pair), lookup (retrieve the value for a key) and delete. Efficient implementations aim to make these operations run in constant or logarithmic time on average.

Implementations

The most common implementation is the hash table, which uses a hash function to distribute keys into buckets and offers average-case O(1) operations. Ordered maps are usually implemented with balanced search trees such as red–black trees, giving O(log n) operations and iteration in sorted key order. For small collections a simple list of pairs may suffice.

Language support

Many languages provide associative arrays as a built-in type: Python's dict, JavaScript's objects and Map, Lua's tables, Perl and Ruby hashes, PHP's arrays, and Java's Map interface and C++'s std::map / std::unordered_map in their standard libraries. A Python example:

capitals = {"France": "Paris", "Japan": "Tokyo"}
capitals["Italy"] = "Rome"     # insert
print(capitals["Japan"])        # lookup -> Tokyo
