Approximate string matching

In computer science, approximate string matching (often colloquially referred to as fuzzy string searching) is the technique of finding strings that match a pattern approximately rather than exactly. It is used when the text or the pattern may contain errors, as in spell checking, optical character recognition output, and searching of DNA sequences.

Problem formulation

The closeness of a match is usually measured in terms of an edit distance — the number of primitive operations (insertions, deletions, substitutions, and sometimes transpositions) needed to convert one string into another. Common distance metrics include the Levenshtein distance, the Hamming distance (for equal-length strings), and the Jaro–Winkler distance. A typical problem is: given a pattern, a text, and a maximum allowed distance k, find all substrings of the text within distance k of the pattern.

Algorithms

Dynamic programming algorithms related to the Wagner–Fischer method compute edit distances and can be adapted to search. Bit-parallel algorithms, such as Myers' algorithm and the approach used in the agrep tool, achieve large speedups by packing the computation into machine words. Indexing methods, including n-gram filtering and suffix structures, are used for dictionary and database searches where many queries are run against a fixed text collection.

Applications

Applications include spell checkers and "did you mean" suggestions in search engines; record linkage and deduplication in databases; plagiarism detection; bioinformatics, where approximate matching aligns sequence reads subject to mutations and sequencing errors; and information security, such as detecting variants of known malicious strings.
