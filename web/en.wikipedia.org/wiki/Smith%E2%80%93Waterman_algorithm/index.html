Smith–Waterman algorithm


Published: 1981, by Temple F. Smith and Michael S. Waterman
Type: Dynamic programming algorithm
Purpose: Local sequence alignment

The Smith–Waterman algorithm performs local sequence alignment: given two strings, typically DNA, RNA or protein sequences, it finds the most similar subsequences between them. It is a dynamic programming algorithm guaranteed to find the optimal local alignment for a given scoring system.

Algorithm

The algorithm fills a scoring matrix where each cell takes the maximum of zero (starting a new alignment), a diagonal match or mismatch score, and gap penalties from above or left. The highest-scoring cell marks the end of the best local alignment, which is recovered by traceback until a zero cell is reached.

Applications

Smith–Waterman is widely used in bioinformatics for finding conserved regions between sequences. Because its time and memory grow with the product of the sequence lengths, faster heuristic methods such as BLAST are often used for database searches, with Smith–Waterman reserved for accurate pairwise alignment.
