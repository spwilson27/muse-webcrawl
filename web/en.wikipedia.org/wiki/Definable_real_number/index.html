Definable real number

A definable real number is a real number that can be uniquely specified by a logical formula in a given formal language, such as the language of set theory or arithmetic.

Examples

All rational numbers, algebraic numbers and computable numbers such as pi and e are definable, though definitions depend on language.

Cardinality

In a countable language there are only countably many definitions, so almost all real numbers are undefinable.

Related notions

Computable numbers form a narrower class requiring an algorithm that produces digits to any precision.
