Multivibrator

A multivibrator is an electronic circuit used to implement two-state devices such as oscillators, timers, and flip-flops. It is a regenerative circuit with cross-coupled active devices whose behaviour falls into three classes.

Types

  • Astable — no stable state; the circuit oscillates continuously between its two states, producing a square wave. It serves as a simple clock or tone generator.
  • Monostable — one stable state; an external trigger drives it to the other state for a fixed interval set by an RC time constant, then it returns. Used for pulse generation and timing (the classic example is the 555 timer in monostable mode).
  • Bistable — both states stable; the circuit is a flip-flop, the basic one-bit memory element of digital electronics.

History

The first multivibrator circuit, the astable oscillator, was invented in 1918 by William Eccles and F. W. Jordan using vacuum tubes; the name reflects the richness of harmonics in its output. Transistor and integrated-circuit versions — including the ubiquitous 555 timer — made multivibrators among the most widely used building blocks in electronics.
