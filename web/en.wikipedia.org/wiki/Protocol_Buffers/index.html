Protocol Buffers

Protocol Buffers, abbreviated as protobuf, is a free and open-source cross-platform data format used to serialize structured data. It is developed by Google and is language-neutral, platform-neutral, and extensible. Protobuf is similar to XML, JSON or Thrift, but smaller, faster, and simpler; users define how data should be structured once, and code generators then produce source code in a variety of languages to read and write the structured data.

Design

Data structures are described in .proto files as messages, each a logical record of name–value pairs called fields. Every field has a unique number used to identify it in the binary encoding, along with a name and a type (integers, floating-point numbers, strings, bytes, booleans, enumerations, or other messages).

message Person {
  string name = 1;
  int32 id = 2;
  string email = 3;
}

The field numbers, not the names, appear in the encoded data, so schemas can evolve: new fields can be added without breaking readers of the old schema, and removed field numbers are reserved to prevent reuse. The binary wire format uses variable-length integer encoding and a key–value structure in which each key combines the field number and a wire type.

History

Protocol Buffers were developed internally at Google beginning in 2001 for use in indexing and communication protocols, and were released to the public as open source in 2008 under the name Protocol Buffers version 2 (proto2). A simplified syntax, proto3, followed in 2016, dropping required fields and field-presence tracking for scalars in favour of simpler semantics across languages. The format underpins gRPC, Google's widely used remote procedure call framework, and is used extensively in microservices, storage systems and mobile applications.

Language support

The official compiler, protoc, generates code for C++, Java, Python, Go, C#, Ruby, PHP, Objective-C and JavaScript, among others, and third-party implementations cover many additional languages. Compared with JSON or XML, protobuf messages are typically several times smaller and an order of magnitude faster to parse, at the cost of not being human-readable. Alternatives include Apache Thrift, Avro, Cap'n Proto, and CBOR. See also serialization and JSON.
