Windowing system

A windowing system (or window system) is a software component of a graphical user interface (GUI) that supports the implementation of window managers and provides basic graphics hardware support, including handling of the pointing device and keyboard. It divides the screen into rectangular regions — windows — in which different processes can display their output independently, and it routes user input to the correct window.

Components

A windowing system typically provides low-level facilities for drawing primitive shapes and text, managing off-screen buffers and compositing window contents onto the display. The window manager, a separate component, is responsible for the placement, decoration and behaviour of windows. In compositing systems, each window renders to its own buffer and a compositor assembles the final screen image, enabling effects such as transparency, shadows and live thumbnails.

Examples

Major windowing systems include the X Window System (X11) and its successor Wayland on Unix-like systems; Quartz and the Aqua interface on macOS; the Desktop Window Manager underlying Microsoft Windows; and the SurfaceFlinger compositor on Android. Historically, research systems at Xerox PARC pioneered the overlapping-window paradigm later popularised by the Apple Macintosh in 1984.

Client–server models

The X Window System popularised a network-transparent client–server design, in which the display server owns the screen and input devices and applications (clients) connect to it — even over a network. Wayland simplifies this by making the compositor the display server and having clients render into shared buffers, aiming for lower latency and smoother graphics.
