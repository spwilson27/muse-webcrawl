Modified Huffman coding

Modified Huffman coding (MH) is a data compression algorithm used for lossless compression of images. It was standardized as part of the CCITT (now ITU-T) Group 3 fax standard, Recommendation T.4, and is sometimes called the T.4 or one-dimensional coding scheme.

Modified Huffman coding is a variant of run-length encoding combined with Huffman coding. Each scan line of a bi-level (black-and-white) image is encoded as a sequence of alternating runs of white and black pixels. Run lengths from 0 to 63 are encoded with specific terminating codes, while longer runs are expressed as a makeup code (representing a multiple of 64) followed by a terminating code. Separate code tables are used for white and black runs, reflecting their different statistical distributions in typical documents.

Use in fax

Because most document scan lines begin with a white run, each line starts with a white run-length code, which may be zero. An end-of-line (EOL) marker synchronizes the decoder at each line. Modified Huffman coding was later extended by Modified READ (MR, two-dimensional) and Modified Modified READ (MMR) coding, which exploit correlation between adjacent scan lines to achieve higher compression, and which are used in Group 3 and Group 4 fax respectively.

Characteristics

MH achieves typical compression ratios of roughly 5:1 to 10:1 on typed business documents. It is simple to implement in hardware, which made it well suited to early facsimile machines.
