Tree (data structure)

In computer science, a tree is a widely used abstract data type that represents a hierarchical structure with a set of connected nodes. Each node in the tree can be connected to many children, but must be connected to exactly one parent, except for the root node, which has no parent.

Terminology

A node with no children is called a leaf; nodes on the path from the root to a node are its ancestors, and nodes below it are its descendants. The height of a tree is the length of the longest downward path to a leaf, and the depth of a node is the length of the path from the root to that node.

Common types

  • Binary tree – each node has at most two children.
  • Binary search tree – a binary tree ordered so that left descendants are smaller and right descendants larger than their ancestor.
  • Heap – a tree satisfying the heap property, used in priority queues.
  • B-tree – a self-balancing tree used in databases and filesystems.
  • Trie – a tree for storing strings, keyed by characters.

Traversal

Trees are commonly traversed in depth-first order (pre-order, in-order, post-order) or breadth-first (level) order. See graph theory and binary tree.
