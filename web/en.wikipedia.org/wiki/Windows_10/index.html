Windows 10 is a major release of Microsoft's Windows NT operating system. It was released to manufacturing on July 15, 2015, and went on general sale on July 29, 2015. Windows 10 was offered as a free upgrade for most users of Windows 7 and Windows 8.1 during its first year and introduced a "Windows as a service" model in which the system receives continual feature updates rather than discrete successor versions.

Development and release

Windows 10 was unveiled in September 2014 under the codename "Threshold." Microsoft skipped the name "Windows 9," saying the new system represented too large a leap. The Windows Insider Program gave millions of testers preview builds before launch.

Features

Windows 10 restored the Start menu (combining the Windows 7 layout with live tiles), introduced the Cortana voice assistant, the Microsoft Edge web browser, virtual desktops (Task View), the Windows Hello biometric sign-in, DirectX 12, and Continuum for switching between desktop and tablet modes. It also unified Microsoft's platform across PCs, tablets, Xbox One and embedded devices under the Universal Windows Platform.

Version history

Major feature updates included the Anniversary Update (1607), Creators Update (1703), Fall Creators Update (1709) and twice-yearly releases thereafter, later shifting to annual updates named by year and half (e.g., 21H2, 22H2). Version 22H2 was the final feature update.

Reception and market share

Windows 10 was generally praised for restoring desktop usability after Windows 8, though it drew criticism over forced updates, advertising and telemetry/privacy practices. It passed 400 million devices within its first year-plus and remained one of the world's most-used desktop operating systems even after Windows 11 launched; mainstream support ended on October 14, 2025, with a paid Extended Security Updates program available.
