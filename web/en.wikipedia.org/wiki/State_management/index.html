State management

State management refers to how state (data) is managed and updated in computer software, particularly in user interface development and web applications. An application's state includes the data displayed to the user, user input, and the current condition of interactive components. As applications grow in complexity, predictable approaches to storing, updating and propagating state become essential.

Approaches

Common approaches include local component state, in which each component manages the data it needs; lifted or shared state, where state is held in a common ancestor; and external state management libraries or stores that centralise state in a single source of truth. In the React ecosystem, tools such as Redux, MobX, Zustand and React's built-in Context API are widely used; other frameworks offer similar facilities, such as Vuex/Pinia for Vue and services or signals for Angular.

Concepts

Key concepts include immutability, in which state is replaced rather than mutated to simplify change detection; unidirectional data flow, in which actions dispatch updates and the view re-renders from state; and derived state, computed from base state rather than stored. Server state and caching form a related concern handled by data-fetching libraries.
