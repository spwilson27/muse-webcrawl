Distribution (mathematics)

In mathematics, a distribution is a generalised function: an object that extends the concept of a function so that operations like differentiation apply even to quantities that are not ordinary functions, such as the Dirac delta, which models a point mass or impulse. Distributions — also called generalised functions — were given rigorous form by Laurent Schwartz in the 1940s, work for which he received the Fields Medal in 1950.

Definition

A distribution is defined not by its values at points but by how it acts on well-behaved "test functions". Formally, a distribution on an open set is a continuous linear functional on a space of smooth, compactly supported test functions. Every locally integrable function defines a distribution by integration against a test function, and more singular objects are included: the Dirac delta δ assigns to each test function φ its value φ(0).

Operations

Operations on functions transfer to distributions by duality: the derivative of a distribution is defined by moving the derivative onto the test function with a sign change (integration by parts), so every distribution is infinitely differentiable in this generalised sense — the delta is the derivative of the Heaviside step function. Distributions can be multiplied by smooth functions, convolved with test functions, and Fourier-transformed (in the class of tempered distributions), and they provide the natural setting for fundamental solutions of partial differential equations: a fundamental solution is a distributional solution with delta-function forcing.

Applications

Distributions are indispensable in the theory of partial differential equations, Green's functions in physics, signal processing (impulse responses), and probability, where densities of discrete random variables can be written using delta functions. Earlier heuristic use by Paul Dirac and Oliver Heaviside was made rigorous by the Schwartz theory.
