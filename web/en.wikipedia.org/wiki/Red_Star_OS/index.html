Red Star OS

Red Star OS (Korean: 붉은별; RR: Bulg-eunbyeol) is a North Korean Linux distribution, developed by the Korea Computer Center. Development began in 1998, and the first version was released in 2008. The operating system is designed to reflect North Korean ideology and to provide a state-approved computing environment, with access limited to the national intranet, Kwangmyong.

Design

Version 3.0, released around 2013, redesigned the desktop to resemble Apple's macOS, a change from earlier versions that imitated Windows XP. The system includes a modified Mozilla Firefox browser named Naenara ("My Country"), used for the Kwangmyong intranet, as well as office applications, an email client, and media players. North Korean terminology and spellings are used throughout, and the calendar can display the Juche year.

Control features

Analysis of leaked copies by foreign researchers has revealed extensive state-control mechanisms: the system watermarks files opened from removable media with the hard drive's serial number, allowing content to be traced, and it automatically deletes or encrypts files that do not pass integrity checks. System files are protected against modification, and the OS reboots or displays an error if tampering is detected.

Reception

Red Star OS attracted international press attention after copies leaked abroad, notably following a visit by journalists and a presentation by German researchers at the Chaos Communication Congress in 2015, who described it as a tool of surveillance and control.
