Causal loop diagram

A causal loop diagram (CLD) is a diagram used in system dynamics that helps visualize how different variables in a system are causally interrelated. The diagram consists of a set of nodes representing the variables, connected by arrows showing the causal relationships between them, each marked with a polarity.

Link polarity

Each causal link is assigned a polarity. A positive link (+) means that if the cause increases, the effect increases above what it would otherwise have been, and if the cause decreases, the effect decreases. A negative link (−) means the effect moves in the opposite direction: an increase in the cause decreases the effect.

Loop types

Closed chains of cause and effect form feedback loops. A reinforcing loop (labelled R) contains an even number of negative links and amplifies change in one direction, producing exponential growth or collapse — for example, the compounding of interest on a bank balance. A balancing loop (labelled B) contains an odd number of negative links and counteracts change, driving the system toward a goal or equilibrium, as in a thermostat regulating room temperature.

Use

Causal loop diagrams are used in management, public policy, environmental modelling and systems thinking education to communicate hypotheses about the structure of a problem before constructing a quantitative stock-and-flow simulation. Their limitations include the inability to distinguish stocks from flows and the absence of information about the magnitudes and timing of effects.
