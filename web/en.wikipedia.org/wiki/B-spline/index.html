B-spline

[ Image placeholder: Cubic B-spline basis functions ]

In mathematics, a B-spline (basis spline) is a spline function that has minimal support with respect to a given degree, smoothness and knot partition. B-splines were introduced by Isaac Schoenberg (1946) and form a basis for the vector space of all splines of a given degree over a given knot sequence: any spline function can be written uniquely as a linear combination of B-splines of that degree. They are the standard curve- and surface-representation tool in computer-aided geometric design, generalising Bézier curves.

Definition

Given a non-decreasing knot vector t = (t0, …, tm), the B-spline basis functions Bi,k of degree k are defined by the Cox–de Boor recursion: Bi,0(t) = 1 if ti ≤ t < ti+1, else 0; higher degrees are convex combinations of two lower-degree basis functions. Each Bi,k is non-zero only over k+2 consecutive knots (local support), is a piecewise polynomial of degree k, and the functions form a partition of unity.

Curve representation

A B-spline curve is C(t) = Σi Pi Bi,k(t), where Pi are control points. Repeated knots reduce continuity in a controlled way; Bézier curves are the special case with knots only at the ends. Rational B-splines, weighted by wi, give NURBS, which can represent conic sections exactly and are ubiquitous in CAD kernels, font outlines (in quadratic form), animation and isogeometric analysis.

Properties

  • Local control — moving one control point affects only k+1 spans of the curve.
  • Convex hull and variation-diminishing properties.
  • Efficient, numerically stable evaluation via the de Boor algorithm.
  • Knot insertion and degree elevation allow refinement without changing the shape.
