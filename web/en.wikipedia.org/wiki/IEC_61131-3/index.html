IEC 61131-3

IEC 61131-3 is the third part of the IEC 61131 international standard for programmable logic controllers (PLCs), published by the International Electrotechnical Commission. It defines the syntax and semantics of a unified suite of programming languages for industrial controllers, and is the dominant global standard for PLC software. The first edition appeared in 1993, with second and third editions in 2003 and 2013 adding features including object-oriented extensions.

Programming languages

The standard defines five languages:

  • Ladder Diagram (LD) — graphical language resembling relay logic circuits.
  • Function Block Diagram (FBD) — graphical language wiring together reusable function blocks.
  • Structured Text (ST) — high-level textual language similar in style to Pascal.
  • Instruction List (IL) — low-level assembler-like textual language (deprecated in the third edition).
  • Sequential Function Chart (SFC) — graphical language for structuring sequential control as steps and transitions.

Programming model

Software is organized into program organization units (POUs): programs, function blocks, and functions. Configurations, resources, and tasks govern how programs execute on the controller, with tasks running cyclically or on events. The standard defines a common data type system (such as BOOL, INT, REAL, TIME, and STRING), variables at local and global scope, and direct representation of I/O addresses. Major development environments implementing the standard include CODESYS and vendor tools from Siemens, Rockwell Automation, Schneider Electric, Mitsubishi Electric, and others. The organization PLCopen promotes conformity and extensions of the standard.
