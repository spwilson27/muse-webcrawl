Incidence matrix

In mathematics, an incidence matrix is a matrix that shows the relationship between two classes of objects. For a graph, the incidence matrix has one row for each vertex and one column for each edge; the entry is nonzero (commonly 1, or ±1 for oriented edges in a directed graph) when the vertex is an endpoint of the edge, and zero otherwise.

Properties

For an undirected graph without loops, each column contains exactly two 1s. The incidence matrix of a bipartite incidence structure or a finite incidence geometry (such as points and blocks in a block design) has entries recording whether a point lies in a block. Multiplying the incidence matrix by its transpose yields information about shared edges or blocks, and the rank of the incidence matrix is an important invariant in design theory and coding theory.

Related matrices

The incidence matrix is distinct from the adjacency matrix, which records vertex–vertex connections. Incidence matrices are used in network analysis, electrical circuit theory (relating branch currents to nodes) and the analysis of hypergraphs.
