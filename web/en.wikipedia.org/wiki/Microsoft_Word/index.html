Microsoft Word is a word processing program developed by Microsoft. It was first released on October 25, 1983, under the name Multi-Tool Word for Xenix systems. Subsequent versions were written for DOS, the Apple Macintosh, SCO Unix, OS/2 and Microsoft Windows, and it became the dominant word processor in the world during the 1990s. Word is a component of the Microsoft Office (now Microsoft 365) suite and is also available as a web application and for mobile platforms.

History

Word was developed under Charles Simonyi, whom Microsoft hired from Xerox PARC, where he had worked on Bravo, the first WYSIWYG word processor. Word for Windows, released in 1989, brought the graphical interface to the PC and rapidly overtook WordPerfect. Major interface changes came with the introduction of the Ribbon in Office 2007 and the switch from the proprietary .doc format to the XML-based .docx format, standardised as part of Office Open XML.

Features

Word provides spell checking, grammar checking, text and font formatting, styles and templates, mail merge, tables, image embedding, tracked changes and comments for collaborative review, and extensive page layout controls. It dominates document exchange in business, education and publishing, though it faces competition from Google Docs and LibreOffice Writer.
