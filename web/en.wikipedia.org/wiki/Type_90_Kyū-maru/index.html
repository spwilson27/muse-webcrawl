Type 90 Kyū-maru

The Type 90 Kyū-maru (90式戦車, Kyū-maru-shiki sensha) is a main battle tank of the Japan Ground Self-Defense Force (JGSDF), built by Mitsubishi Heavy Industries and introduced in 1990 to replace the Type 74.

Design

The Type 90 is armed with a Rheinmetall 120 mm smoothbore cannon fed by an automatic loader, which allows a crew of three. It uses composite armour, hydropneumatic suspension that can "kneel", and a 1,500 hp Mitsubishi diesel engine. Around 341 were produced. Because of its weight (about 50 tonnes), the tank is deployed mainly in Hokkaido, where Japanese planning expected a possible Soviet landing; it is being succeeded in part by the lighter Type 10 tank.
