Phoenix (web framework)

Phoenix is a web development framework written in the functional programming language Elixir, which runs on the Erlang virtual machine (BEAM). It implements the server-side model–view–controller pattern and is known for its support for real-time features through Channels and for LiveView, which enables rich interactive pages rendered on the server.

Created by Chris McCord, Phoenix was first released in 2014. Its design leverages Erlang's concurrency and fault-tolerance to handle large numbers of simultaneous connections, making it popular for chat, presence and collaborative applications.
