Branch misprediction

A branch misprediction occurs when a central processing unit (CPU) mispredicts the direction or target of a branch instruction, so that the speculatively executed instructions fetched down the wrong path must be discarded and the pipeline refilled from the correct path. In modern pipelined processors this penalty is typically on the order of ten to twenty clock cycles, depending on pipeline depth.

Branch prediction

Because instructions are fetched before earlier branches are resolved, CPUs use branch predictors — hardware structures such as pattern history tables, branch target buffers and, in recent designs, perceptron- or TAGE-based predictors — to guess the outcome of conditional branches and the targets of indirect branches. High-end processors achieve prediction accuracies above 95% on typical code, but data-dependent branches with unpredictable outcomes (such as branches on random or hash values) remain a major source of performance loss.

Mitigation

Software techniques include restructuring code to make branches predictable, replacing branches with conditional-move or arithmetic (branchless) code, profile-guided optimisation, and arranging hot paths to fall through. Mispredicted speculative execution was central to the Spectre security vulnerabilities disclosed in 2018, since instructions executed down a mispredicted path can leave observable traces in the cache.
