Entire function

In complex analysis, an entire function is a complex-valued function that is holomorphic everywhere on the whole complex plane. Because such a function has a Taylor series that converges everywhere, entire functions are exactly those given by power series with infinite radius of convergence. Typical examples are the polynomials, the exponential function, and the sine and cosine functions. By contrast, the function 1/z is not entire, since it is not defined at z = 0.

Properties

Liouville's theorem states that every bounded entire function must be constant — a result that yields an elegant proof of the fundamental theorem of algebra. Stronger results govern how an entire function behaves at infinity: by the Casorati–Weierstrass theorem and the Picard theorems, a non-constant entire function comes arbitrarily close to every complex value, and in fact takes every value infinitely often with the possible exception of one value (the exponential function, which never takes the value 0, shows the exception is real).

Growth and order

Entire functions are classified by their rate of growth, measured by the order and type of the function. Polynomials have order 0; the exponential has order 1; functions such as exp(z2) have order 2. Growth is intimately connected with the distribution of zeros: the Weierstrass factorisation theorem represents an entire function as a product over its zeros, in the same spirit as factorising a polynomial, while the Hadamard factorisation theorem relates a function's order to the genus of that product. An entire function with no zeros at all must be the exponential of another entire function.

Examples

  • All polynomials
  • The exponential function ez and the trigonometric functions sin z, cos z
  • The error function and the Fresnel integrals
  • The reciprocal gamma function 1/Γ(z)
  • Non-examples: rational functions with poles, log z, and any function with an essential singularity or branch point at a finite location
