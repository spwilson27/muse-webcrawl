Eight-point algorithm

The eight-point algorithm is an algorithm used in computer vision to estimate the essential matrix or the fundamental matrix related to a pair of cameras from a set of corresponding image points. It was introduced by Christopher Longuet-Higgins in 1981 for the case of the essential matrix. In principle the algorithm can be used for the fundamental matrix as well, as generalised by Richard Hartley.

Principle

Each pair of corresponding points in two images satisfies the epipolar constraint, which can be written as a linear equation in the entries of the fundamental (or essential) matrix. With eight or more point correspondences, the resulting homogeneous system of linear equations can be solved, typically by singular value decomposition, to obtain the matrix up to scale. Because a fundamental matrix must be singular (of rank 2), an additional step enforces this constraint by projecting the estimated matrix onto the set of rank-2 matrices.

Normalised eight-point algorithm

The basic algorithm performs poorly with raw pixel coordinates because the equations are badly conditioned. Hartley showed in 1997 that a simple normalisation — translating and scaling the points in each image so that their centroid is at the origin and their mean distance from the origin is √2 — dramatically improves accuracy. The normalised eight-point algorithm consists of normalising the points, estimating the matrix, enforcing the rank constraint, and then denormalising. It remains a standard method, often used as the inner step of robust estimation procedures such as RANSAC.
