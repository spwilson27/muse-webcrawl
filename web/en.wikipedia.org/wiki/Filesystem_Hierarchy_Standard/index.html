Filesystem Hierarchy Standard

The Filesystem Hierarchy Standard (FHS) is a reference describing the conventions used for the layout of file system hierarchy in Unix and Unix-like operating systems, maintained by the Linux Foundation since 2015. Its development began in 1994 with a version for Linux, and the current version is 3.0, released on June 3, 2015.

The FHS defines the directory structure and directory contents in Linux distributions. In the FHS, all files and directories appear under the root directory /, even if they are stored on different physical or virtual devices. Some of these directories only exist if a certain subsystem, such as the X Window System, is installed.

History

The process of developing a standard file system hierarchy began with the release of the FSSTND (Filesystem Standard), a filesystem standard specific to the Linux operating system, on February 14, 1994. Subsequent revisions were released on October 9, 1994 and March 28, 1995. In early 1996, the goal of developing a more comprehensive version of FSSTND to address not only Linux, but other Unix-like systems, was adopted with the help of members of the BSD development community. As a result, a concerted effort was made to focus on issues that were general to Unix-like systems. In recognition of this widening of scope, the name of the standard was changed to Filesystem Hierarchy Standard or FHS for short.

Criticism

The FHS has been criticized for not going far enough in rationalizing the filesystem layout, and modern distributions have diverged from it in various ways, such as the merging of /bin, /lib, and /sbin into their /usr counterparts on many systems. Alternative layouts, such as the one used by GoboLinux, reject the traditional hierarchy altogether.
