Code Club is a network of free volunteer-led after-school coding clubs for children, founded in the United Kingdom in 2012 by Clare Sutcliffe and Linda Sandvik. The clubs teach children aged roughly 9–13 to program through project-based activities in languages and tools such as Scratch, HTML/CSS, and Python.

History

Code Club launched in April 2012 with the aim of giving every child in the UK the chance to learn to code. It grew rapidly through schools and libraries, recruiting volunteers from the technology industry to run weekly sessions using its library of step-by-step projects. In 2015 Code Club joined the Raspberry Pi Foundation, and its international partner network, Code Club World, expanded the model to many countries. The network has encompassed tens of thousands of clubs worldwide, reaching hundreds of thousands of children.

Model

Clubs are free for children and are hosted by schools, libraries, and community venues. Volunteers use ready-made projects—games, animations, and websites arranged in progressive pathways—so that neither teachers nor volunteers need deep programming expertise. The ethos emphasizes creativity, collaboration, and learning by making.
