Page cache

In computing, a page cache, sometimes also called a disk cache, is a transparent cache for the pages originating from a secondary storage device such as a hard disk drive (HDD) or solid-state drive (SSD). The operating system keeps a page cache in otherwise unused portions of the main memory (RAM), resulting in much quicker access to the contents of cached pages.

Overview

When a process reads data from a file, the kernel first checks the page cache; if the page is present, the data is copied directly from memory without a disk access. When data is written, it is typically placed in the page cache and marked "dirty"; a background writeback mechanism later flushes dirty pages to the storage device. This deferred writing greatly improves performance but means recently written data can be lost on a power failure unless the application calls fsync or a related system call.

Linux

In Linux, the page cache is unified with the virtual memory system: file pages and anonymous pages are managed together, and free memory is used opportunistically for caching. Tools such as free report cached memory separately from memory used by applications, and administrators may drop caches through /proc/sys/vm/drop_caches for benchmarking. The kernel reclaims cached pages under memory pressure, preferring to evict clean pages that can be re-read from disk.
