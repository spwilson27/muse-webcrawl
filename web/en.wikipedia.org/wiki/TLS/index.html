Transport Layer Security

International standardRFC 5246 (TLS 1.2), RFC 8446 (TLS 1.3)
Developed byNetscape (SSL); IETF (TLS)
Introduced1999 (TLS 1.0)

Transport Layer Security (TLS), formerly known as Secure Sockets Layer (SSL), is a cryptographic protocol designed to provide communications security over a computer network. The protocol is widely used in applications such as email, instant messaging, and voice over IP, but its most visible use is in securing HTTPS web traffic. Websites can use TLS to secure all communications between their servers and web browsers.

How it works

TLS runs above a reliable transport protocol such as TCP. A session begins with a handshake in which the client and server agree on a protocol version and cipher suite, the server presents an X.509 certificate authenticating its identity (and the client optionally does the same), and the parties use asymmetric cryptography — typically an ephemeral Diffie–Hellman key exchange — to establish shared session keys. Thereafter, application data is protected with symmetric authenticated encryption, providing confidentiality, integrity and forward secrecy.

Versions

SSL was developed by Netscape in the mid-1990s; SSL 3.0 (1996) was the last version before the IETF renamed and standardised the protocol as TLS 1.0 (1999). TLS 1.1 (2006) and TLS 1.2 (2008) followed. Older versions were progressively deprecated after attacks such as POODLE, BEAST and Heartbleed (the latter an implementation bug in OpenSSL). TLS 1.3, published as RFC 8446 in 2018, removed obsolete and insecure features, mandated forward secrecy, encrypted more of the handshake, and reduced the handshake to a single round trip, with an optional zero-round-trip resumption mode.

Applications and deployment

Beyond HTTPS, TLS secures email submission and retrieval (SMTPS, IMAPS, POP3S), VPNs, Wi-Fi authentication (EAP-TLS) and many APIs. Its datagram counterpart, DTLS, adapts the protocol to UDP. Certificates are issued by certificate authorities under the Web PKI; the free automated CA Let's Encrypt, launched in 2015, greatly increased adoption, and the large majority of web page loads now use HTTPS.
