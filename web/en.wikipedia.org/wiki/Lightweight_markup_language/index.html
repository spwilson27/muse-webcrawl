Lightweight markup language

A lightweight markup language (LML) is a markup language with simple, unobtrusive syntax, designed to be easy for humans to read and write in its raw form as well as to be converted by software into formats such as HTML, PDF or rich text. Unlike heavyweight languages like HTML or XML, whose tags clutter the text, lightweight languages use punctuation-like conventions borrowed from plain-text email and Usenet practice.

Characteristics

  • Source text remains legible and meaningful without rendering
  • A small set of rules covering headings, lists, emphasis, links and code
  • Conversion to HTML is the most common use, for wikis, blogs, documentation and static sites

Examples

  • Markdown (2004) — created by John Gruber with Aaron Swartz; the most widely used LML, standard for documentation, README files and many content platforms; extended by variants such as CommonMark and GitHub Flavored Markdown
  • reStructuredText — used in Python documentation and the Sphinx system
  • AsciiDoc — a richer language suited to books and technical manuals
  • Textile — an early web-oriented LML
  • Wiki markup — e.g., MediaWiki's wikitext, and its ancestor Creole, an attempt at a common wiki syntax
  • BBCode — used in internet forums
  • org-mode markup — from the Emacs Org-mode outliner

History

Simple text conventions — *asterisks* for emphasis, indented lists, angle-bracket addresses — arose naturally in early networked text. Ward Cunningham's WikiWikiWeb (1995) formalised simple formatting rules for editable web pages, and the 2000s saw a proliferation of languages culminating in Markdown's dominance in software development culture.
