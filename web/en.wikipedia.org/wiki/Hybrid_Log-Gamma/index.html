Hybrid log-gamma

Hybrid log-gamma (HLG) is a high dynamic range (HDR) television technology and transfer function developed jointly by the BBC and NHK. It was standardised as ARIB STD-B67 and included in ITU-R BT.2100.

Overview

HLG is designed for broadcast: its signal is backward compatible with standard dynamic range (SDR) displays, rendering an acceptable SDR picture while HDR-capable displays show extended brightness and colour. Unlike PQ-based formats, HLG uses relative scene-referred values and requires no metadata.

Transfer function

The HLG opto-electronic transfer function combines a conventional gamma curve for the lower half of the signal range with a logarithmic curve for the upper half, hence "hybrid log-gamma". System gamma adjusts overall brightness according to ambient viewing conditions.
