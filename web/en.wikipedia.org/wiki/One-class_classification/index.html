One-class classification

In machine learning, one-class classification (OCC), also known as unary classification or concept learning, is the problem of identifying objects of a specific class among all objects when the training set contains examples of only that one class. It differs from ordinary multi-class classification, which requires counterexamples of other classes; OCC instead characterizes the target class and treats anything sufficiently dissimilar as an outlier.

Approaches

Density-based methods estimate the probability distribution of the training data and threshold it. Boundary methods, such as the one-class support vector machine (Schölkopf et al.) and support vector data description, learn a decision boundary enclosing most of the data — for example a hyperplane separating the data from the origin in feature space, or a minimal hypersphere. Reconstruction methods, including autoencoders, flag examples with high reconstruction error. Typical applications are novelty and anomaly detection: machine fault monitoring, medical screening, and fraud detection, where abnormal examples are rare, costly, or impossible to enumerate in advance.
