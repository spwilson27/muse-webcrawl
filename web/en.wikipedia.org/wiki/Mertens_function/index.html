Mertens function

In number theory, the Mertens function is defined for all positive integers n as

M(n) = Σk=1..n μ(k)

where μ is the Möbius function. Since μ(k) takes only the values −1, 0, and +1, the Mertens function changes slowly, moving by at most 1 at each step. It counts the difference between the number of square-free integers up to n with an even number of prime factors and those with an odd number.

The Mertens function for arguments up to 10,000

History and the Mertens conjecture

The function is named after the German mathematician Franz Mertens (1840–1927), who computed its values for n up to 10,000. Thomas Joannes Stieltjes had claimed in an 1885 letter to Charles Hermite that |M(n)| < √n, and Mertens, on the basis of his computations, put forward the stronger Mertens conjecture that |M(n)| < √n for all n > 1.

The conjecture would have implied the Riemann hypothesis (indeed, the bound M(n) = O(n1/2+ε) for every ε > 0 is equivalent to the Riemann hypothesis), but in 1985 Andrew Odlyzko and Herman te Riele disproved it, showing that lim sup |M(n)|/√n > 1.06 and lim inf < −1.009, using the zeros of the Riemann zeta function and lattice reduction. Their proof was non-constructive: it showed a counterexample exists without exhibiting one explicitly, though a counterexample is known to be below about e3.21×1064 and above 1016.

Computation

Values of M(n) have been computed for increasingly large n using sieve-like algorithms related to the Meissel–Lehmer prime-counting method, exploiting the identity Σk=1..n M(⌊n/k⌋) = 1. Deleglise and Rivat gave an algorithm running in roughly O(n2/3) time, and values are now known beyond 1016. No sign pattern or simple growth law is known; the best unconditional bound, due to work of Walfisz and later refinements, is only slightly better than M(n) = o(n).
