WAV

Waveform Audio File Format (WAVE, or WAV owing to its filename extension) is an audio file format standard for storing an audio bitstream on personal computers. Developed by Microsoft and IBM and released in August 1991, it is the principal format used on Microsoft Windows systems for uncompressed audio, and it remains widely used for professional recording, editing and archiving where lossy compression is unacceptable.

Format details

WAV files are an application of the Resource Interchange File Format (RIFF) bitstream format, which stores data in chunks. A typical WAV file begins with a RIFF header containing the ASCII identifier "WAVE", followed by a fmt subchunk describing the audio format — the encoding, number of channels, sample rate, byte rate and bits per sample — and a data subchunk containing the audio samples themselves. A minimal uncompressed WAV file has a 44-byte header.

Audio is most commonly stored using linear pulse-code modulation (LPCM), in which case the file is essentially a raw recording of the samples: CD-quality audio uses a sample rate of 44,100 Hz with 16 bits per sample per channel, giving a bitrate of 1,411.2 kbit/s. Although WAV files are usually uncompressed, the format's header can also declare compressed encodings such as ADPCM or even MP3, in which case the data is interpreted according to an Audio Compression Manager codec.

Limitations

Because RIFF uses 32-bit fields for chunk sizes, a WAV file cannot exceed 4 gigabytes, which at CD quality corresponds to roughly 6.8 hours of audio. The RF64 extension, standardised by the European Broadcasting Union, overcomes this limit by substituting a 64-bit size field and is used in professional broadcast and recording software. WAV files also have limited native support for metadata compared with formats such as FLAC or MP3, although LIST and BEXT (Broadcast Wave Format) chunks can carry descriptive information.

Comparison with other formats

WAV's uncompressed nature makes files large — about 10 megabytes per minute of stereo CD-quality audio — so lossy formats such as MP3 and AAC became preferred for distribution, while lossless compressed formats such as FLAC and Apple Lossless are often used for archiving. WAV remains a default interchange format in digital audio workstations, video editing and telephony because decoding it is trivial and it introduces no generational quality loss in editing.
