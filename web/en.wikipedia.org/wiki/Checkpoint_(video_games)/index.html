Checkpoint (video games)

A checkpoint is a point in a video game level at which the player's progress is recorded, so that if the player character dies or fails, the game can be restarted from that point rather than from the beginning of the level. Checkpoints are a fundamental element of game design in platform games, action-adventure games, first-person shooters, and many other genres.

History

Early arcade and home computer games typically forced the player to restart an entire level — or the whole game — after losing all lives. As games grew longer during the 16-bit era, designers introduced mid-level checkpoints, often shown as flags, signposts, or glowing markers that changed appearance once activated. Racing games popularised a related mechanic in which passing a checkpoint added time to a countdown timer.

Design considerations

Checkpoint placement strongly affects a game's perceived difficulty and fairness. Checkpoints placed immediately before difficult sections reduce frustration but can also reduce tension; sparse checkpoints increase the stakes of each attempt. Some games combine checkpoints with a save system, while others, such as roguelikes, deliberately omit them to enforce permadeath.

Modern titles frequently use invisible, automatically triggered checkpoints, sometimes called "autosaves," which record progress at scripted moments without any on-screen marker.
