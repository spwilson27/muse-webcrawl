Load balancing (computing)

In computing, load balancing is the process of distributing a set of tasks over a set of resources (computing units), with the aim of making overall processing more efficient. Load balancing can optimise response time and avoid unevenly overloading some computing nodes while other nodes are left idle.

Overview

Load balancing is a key component of high-availability infrastructures commonly used to improve the reliability and performance of web sites, applications, databases and other services by distributing the workload across multiple servers. A load balancer sits between clients and a server farm, accepting requests and forwarding each to a server capable of fulfilling it.

Algorithms

AlgorithmDescription
Round-robinRequests are distributed sequentially in rotation across the server pool
Weighted round-robinServers with greater capacity receive a proportionally larger share
Least connectionsEach new request goes to the server with the fewest active connections
Least response timeDirects traffic to the server responding fastest with the fewest connections
IP hash / consistent hashingThe client's identity determines the server, preserving session affinity
RandomRequests are assigned to servers at random

Hardware and software balancers

Load balancing may be implemented in dedicated hardware appliances (often combined with SSL offloading and application delivery features, e.g. F5 BIG-IP), in software (e.g. HAProxy, NGINX, Envoy), or by DNS (round-robin DNS). Cloud providers offer managed load balancers operating at layer 4 (transport) or layer 7 (application) of the OSI model.

Health checking and failover

Load balancers typically probe back-end servers ("health checks") and remove failed instances from rotation automatically, enabling redundancy and fault tolerance. Related techniques include session persistence ("sticky sessions"), geographic load balancing, and anycast routing.
