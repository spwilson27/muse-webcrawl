Extensible Markup Language (XML) is a markup language and file format for storing, transmitting, and reconstructing arbitrary data. It defines a set of rules for encoding documents in a format that is both human-readable and machine-readable. The World Wide Web Consortium's XML 1.0 Specification of 1998 and several other related specifications define XML.

Design goals

XML's design goals emphasize simplicity, generality, and usability across the Internet. It is a textual data format with strong support via Unicode for different human languages. Although XML's design focuses on documents, the language is widely used for representing arbitrary data structures, such as those used in web services. XML is a simplified subset of SGML, designed so that documents could be processed by software that is much simpler than a full SGML processor.

<note>
  <to>Tove</to>
  <from>Jani</from>
  <heading>Reminder</heading>
  <body>Don't forget me this weekend!</body>
</note>

Related technologies

A large family of specifications grew around XML: XML Schema and DTDs for validation, XPath and XQuery for addressing and querying, XSLT for transformation, and namespaces for mixing vocabularies. Several application formats are XML-based, including XHTML, SVG, RSS, Atom, SOAP, and the Office Open XML formats used by Microsoft Office and the OpenDocument format.

Criticism and alternatives

XML has been criticised for verbosity and complexity; lighter formats such as JSON and YAML have displaced it in many web APIs, though XML remains deeply embedded in publishing, documents, configuration, and enterprise data interchange.
