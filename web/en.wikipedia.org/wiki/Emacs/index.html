Emacs is a family of text editors characterised by extensibility. The most widely used variant, GNU Emacs, was created by Richard Stallman as part of the GNU Project. Its core is an interpreter for Emacs Lisp, a dialect of Lisp specialised for editing, in which most of the editor's functionality — and thousands of user extensions — are implemented. The name originally stood for "Editor MACroS", from the TECO macros written at MIT in 1976 by Stallman and Guy Steele.

Features

Emacs is less a single editor than a platform for text-based applications: within it users can edit code with syntax highlighting and project tools, read email and news (Gnus), browse files (Dired), run shells, keep notes and agendas (Org mode), play games, and even consult a mock psychotherapist (Doctor). Its manual describes it as "the extensible, customizable, self-documenting, real-time display editor". Editing is modal only in effect: commands are invoked by key chords, prominently the Control and Meta keys, and every command can be called by name with M-x.

History

The original EMACS (1976) unified a sprawling collection of TECO editor macros at the MIT AI Lab. James Gosling wrote Gosling Emacs for Unix in 1981; Stallman began GNU Emacs in 1984 as the first program of the GNU Project, releasing it in 1985. A schism in the early 1990s produced XEmacs, which was eventually discontinued. GNU Emacs development continues, with native compilation and modern display features added in recent versions.

Culture

Emacs is one party to the long-running, tongue-in-cheek "editor war" with vi/Vim users. Jokes cast Emacs as "a great operating system, lacking only a decent editor", and devotees formed the parody "Church of Emacs", with Stallman as "Saint IGNUcius". Its kitchen-sink extensibility and steep learning curve remain its defining reputation.
