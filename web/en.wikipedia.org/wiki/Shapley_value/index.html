Shapley value

FieldCooperative game theory
Named forLloyd Shapley
Introduced1953

In cooperative game theory, the Shapley value is a solution concept that assigns to each player a payoff equal to their average marginal contribution across all possible coalitions. It was introduced by Lloyd Shapley in 1953.

Definition

For a game with player set N and characteristic function v, the Shapley value of player i averages the player's marginal contribution v(S ∪ {i}) − v(S) over all subsets S not containing i, weighted by the number of orderings in which that coalition forms. It is the unique allocation satisfying efficiency, symmetry, the dummy-player property and additivity.

Applications

The Shapley value is used in cost allocation, voting-power analysis and, more recently, machine learning, where SHAP (SHapley Additive exPlanations) uses it to attribute a model's prediction to individual input features.
