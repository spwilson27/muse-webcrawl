Larrabee (microarchitecture)

Larrabee was a code name for a many-core graphics processing unit (GPU) project developed by Intel. Announced in the late 2000s, Larrabee was intended to compete with the discrete graphics cards of Nvidia and AMD using an array of many small x86-compatible cores, each augmented with a wide vector processing unit. Intel publicly demonstrated Larrabee in 2009 but cancelled the product as a consumer graphics card in 2010 because its performance and power consumption were not competitive and its development had fallen behind schedule.

Architecture

Unlike conventional GPUs built from specialised fixed-function and shader hardware, Larrabee consisted of dozens of in-order cores derived from the Pentium (P54C) design, each with a 512-bit vector unit capable of processing 16 single-precision floats at once, connected by a wide bidirectional ring bus to shared L2 cache and memory controllers. Because the cores ran a variant of the x86 instruction set (extended with Larrabee New Instructions), the chip could run a flexible, largely software-based rendering pipeline — including rasterisation in software — as well as general-purpose computation.

Cancellation and legacy

In December 2009 Intel announced that the first Larrabee chip would serve only as a software development platform, and in May 2010 the project was formally cancelled as a GPU product. The architecture's ideas survived in Intel's Many Integrated Core (MIC) line: the Knights Ferry development platform and the Knights Corner Xeon Phi coprocessors used for high-performance computing, which retained the concept of many simple x86 cores with wide vector units. Intel eventually returned to discrete graphics more than a decade later with the Arc series, based on a different architecture.
