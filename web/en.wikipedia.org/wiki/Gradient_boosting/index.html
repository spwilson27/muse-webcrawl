Gradient boosting

[Image placeholder: Sequential fitting of weak learners in gradient boosting]

Gradient boosting is a machine learning technique for regression, classification and other tasks, which produces a prediction model in the form of an ensemble of weak prediction models, typically decision trees. When a decision tree is the weak learner, the resulting algorithm is called a gradient-boosted tree or gradient-boosting decision tree (GBDT); such models usually outperform random forest ensembles and have won many data-science competitions.

History

The idea of boosting originated in the observation that a collection of weak learners can be combined into a strong learner. Leo Breiman's work in the 1990s framed boosting as an optimisation problem, and Jerome H. Friedman formalised gradient boosting in 1999–2001, generalising boosting to arbitrary differentiable loss functions by fitting each new tree to the negative gradient of the loss — an approach analogous to gradient descent in function space.

Method

Gradient boosting builds the model in a stage-wise fashion. Starting from an initial constant prediction, the algorithm repeatedly computes the residuals (pseudo-residuals) implied by the loss function, fits a weak learner to those residuals, and adds it to the model scaled by a learning rate (shrinkage parameter). Regularisation is achieved through shrinkage, subsampling of rows and columns, tree-depth limits, and early stopping.

Implementations

Widely used implementations include XGBoost, LightGBM and CatBoost, which add efficient handling of sparse data, histogram-based split finding and categorical features. Gradient-boosted trees are a standard choice for tabular data problems.
