The Spring Framework is an application framework and inversion of control container for the Java platform. First released in 2003 by Rod Johnson as a lightweight alternative to the heavyweight Enterprise JavaBeans model, Spring became one of the most widely used frameworks for building enterprise Java applications.

Core features

At the heart of Spring is its inversion of control (IoC) container, which manages the creation and wiring of objects ("beans") through dependency injection, configured by annotations, Java code, or XML. Around this core sit modules for aspect-oriented programming, data access with JDBC and object-relational mapping, transaction management, web applications through Spring MVC and the reactive WebFlux, messaging, testing, and integration with other technologies.

Spring Boot

Spring Boot, released in 2014, builds on the framework to simplify the creation of stand-alone, production-grade applications, favouring convention over configuration with auto-configuration, embedded web servers and starter dependencies. Much of the surrounding ecosystem — Spring Data, Spring Security, Spring Cloud and others — is organised as portfolio projects under the Spring umbrella.

History

Johnson described the framework's design in his 2002 book Expert One-on-One J2EE Design and Development. The project was open-sourced in 2003 and reached version 1.0 in 2004. Development later passed to SpringSource, then Pivotal Software, and subsequently VMware and Broadcom, while remaining open source under the Apache License.
