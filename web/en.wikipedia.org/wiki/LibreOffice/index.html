LibreOffice

Developer: The Document Foundation

Initial release: 25 January 2011

Written in: C++, Java, Python

Operating system: Linux, macOS, Windows, and others

License: MPL-2.0

LibreOffice is a free and open-source office productivity software suite, developed by The Document Foundation. It was created in 2010 as a fork of OpenOffice.org, after members of the OpenOffice.org community became concerned about the project's future under Oracle Corporation. The name is a hybrid of the French word libre ("free") and office.

Components

The suite includes a word processor (Writer), a spreadsheet (Calc), a presentation program (Impress), a vector-graphics and flowchart application (Draw), a database manager (Base), and a formula editor (Math). LibreOffice uses the OpenDocument Format (ODF) as its native file format and also supports Microsoft Office formats and many others.

History

The Document Foundation was announced in September 2010, and LibreOffice 3.3 was released in January 2011. The project attracted most of the OpenOffice.org developer community and many corporate and government deployments. It has since become the default office suite in most Linux distributions. Major milestones include an online version (LibreOffice Online / Collabora Online) and continuing work on interoperability, accessibility, and performance. The project is funded by donations and by an ecosystem of commercial contributors.

Features

LibreOffice runs on Windows, macOS, and Linux, is translated into more than 100 languages, and supports extensions written in several languages. It can generate PDF files directly from any component and includes tools for digital signatures and document redaction.
