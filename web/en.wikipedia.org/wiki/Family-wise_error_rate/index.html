Family-wise error rate

In statistics, family-wise error rate (FWER) is the probability of making one or more false discoveries, or type I errors, when performing multiple hypothesis tests. It is defined as FWER = Pr(V ≥ 1), where V is the number of true null hypotheses that are incorrectly rejected.

Background

When a single hypothesis is tested at significance level α = 0.05, the chance of a false positive is 5%. However, when many hypotheses are tested in a "family" — for example, comparing several treatment groups — the chance that at least one test yields a false positive grows rapidly, approaching 1 − (1 − α)m for m independent tests. Controlling the FWER at a chosen level ensures that the probability of any false rejection across the entire family stays below that level.

Controlling procedures

The simplest and most conservative method is the Bonferroni correction, which tests each hypothesis at level α/m. Other procedures include Tukey's range test for pairwise comparisons, Dunnett's test for comparisons against a control, the Šidák correction, and stepwise methods such as the Holm–Bonferroni procedure, which is uniformly more powerful than Bonferroni while still controlling the FWER.

Weak and strong control

A procedure controls the FWER in the weak sense if control holds only when all null hypotheses are true (the complete null), and in the strong sense if control holds for any configuration of true and false nulls. Critics note that strict FWER control can be overly conservative for large numbers of tests, motivating alternative criteria such as the false discovery rate.
