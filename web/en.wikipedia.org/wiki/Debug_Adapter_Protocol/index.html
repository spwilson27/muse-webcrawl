Debug Adapter Protocol

The Debug Adapter Protocol (DAP) is an abstract protocol developed by Microsoft that standardizes the communication between a development tool (such as an integrated development environment or text editor) and a debugger or runtime environment. It is the debugging analogue of the Language Server Protocol (LSP), which standardized editor support for programming languages.

Before DAP, each development tool had to implement custom support for every debugger it wished to use, and each debugger had to be adapted to every tool. By introducing an intermediate component — the debug adapter — the protocol allows a single tool to work with many debuggers, and a single debugger implementation to serve many tools.

Architecture

In the DAP model, the development tool communicates with a debug adapter using JSON messages over a channel such as standard streams or a socket. The debug adapter is a separate process that translates the protocol's generic requests into the native commands of the actual debugger, for example GDB, LLDB, or a language runtime's built-in debugging facilities.

The protocol distinguishes between requests (sent by the tool), responses (returned by the adapter), and events (asynchronous notifications, such as a breakpoint being hit or a thread stopping). Messages are framed with HTTP-like headers, including a Content-Length header, similar to the base protocol of LSP.

Capabilities

Typical operations covered by the protocol include:

  • Launching and attaching to a debug session
  • Setting and removing breakpoints, including conditional and function breakpoints
  • Stepping execution (step in, step over, step out, continue, pause)
  • Inspecting threads, stack traces, scopes, and variables
  • Evaluating expressions in the context of a stopped frame
  • Reading and writing memory, and disassembly views

Because debug adapters declare their capabilities during initialization, tools can adapt their user interface to the features a particular debugger supports, such as data breakpoints or restart-frame requests.

Adoption

DAP was created for Visual Studio Code, whose debugging user interface is built entirely on the protocol. Debug adapters exist for many languages and platforms, including Python, Go (via Delve), Java, C and C++, and JavaScript. Other editors and IDEs, including Neovim and Emacs, also support DAP through plugins.
