Fletcher's checksum

Fletcher's checksum
TypeError-detection algorithm
InventorJohn G. Fletcher
VariantsFletcher-16, Fletcher-32, Fletcher-64

Fletcher's checksum is an error-detection algorithm developed by John G. Fletcher at Lawrence Livermore Labs in the late 1970s. It computes a position-dependent checksum from two running sums of the data blocks: the first is a simple sum of the blocks, and the second is a sum of the values of the first sum at each step, all computed modulo 255 (or 65535 in the 32-bit variant).

Properties

Because the second sum depends on the order of the data, Fletcher's checksum can detect errors that a simple additive checksum cannot, such as reordered blocks and inserted zero words. Its error-detection capability is comparable to a cyclic redundancy check of the same size, while being computable with only additions. Weaknesses include insensitivity to certain patterns of 0x00 and 0xFF blocks.

Applications

The algorithm is specified in ISO/IEC TR 13233 and has been used in protocols and systems including the ZFS file system, which uses Fletcher checksums for data integrity, and in various networking standards. Variants are named by their output size: Fletcher-16, Fletcher-32 and Fletcher-64.
