Virtual machine

A virtual machine (VM) is a virtualization of a computer system: an emulation of a computer, its hardware, and its environment, implemented in software. Virtual machines are based on computer architectures and provide the functionality of a physical computer, allowing multiple "guest" systems to run in isolation on a single physical "host."

Types

System virtual machines provide a complete platform that can run an entire operating system. They are managed by a hypervisor — either bare-metal (Type 1, e.g. VMware ESXi, Microsoft Hyper-V, Xen) or hosted (Type 2, e.g. VirtualBox) — which multiplexes CPU, memory, and I/O. Modern processors support hardware-assisted virtualization (Intel VT-x, AMD-V) that reduces overhead. Process virtual machines, by contrast, execute a single application atop a runtime, such as the Java Virtual Machine or the .NET Common Language Runtime.

History and uses

The concept dates to IBM's CP/CMS systems of the 1960s and the VM/370 mainframe line. Virtualization was revived on x86 in the late 1990s by VMware and underlies today's cloud computing: providers such as Amazon EC2 and Microsoft Azure rent virtual machines as their basic unit of compute. VMs enable server consolidation, sandboxing, legacy-system support, software testing across operating systems, and rapid provisioning and migration (including live migration between hosts).
