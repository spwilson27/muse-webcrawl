Iterative closest point

Iterative closest point (ICP) is an algorithm employed to minimize the difference between two clouds of points. ICP is often used to reconstruct 2D or 3D surfaces from different scans, to localize robots and achieve optimal path planning (especially when wheel odometry is unreliable due to slippery terrain), to co-register bone models, amongst others.

Overview

The iterative closest point algorithm contrasts with the Kabsch algorithm and other solutions to the orthogonal Procrustes problem in that it iteratively revises the transformation (combination of translation and rotation) needed to minimize an error metric, usually a distance from a source point cloud to a reference point cloud. ICP was introduced independently by several groups in the early 1990s, notably in work by Besl and McKay and by Chen and Medioni.

Algorithm

Inputs: reference and source point clouds, initial estimate of the transformation, and criteria for stopping the iteration. The algorithm repeatedly: (1) associates points in the source cloud with their closest points in the reference cloud; (2) estimates the transformation using a mean squared error cost function; (3) transforms the source points using the estimated transformation; and (4) iterates until convergence.

Variants and applications

Many variants modify the selection, matching, weighting, or error-minimization steps, including point-to-plane ICP and generalized ICP. The algorithm is widely used in computer vision, robotics, medical imaging, and geographic information systems for scan matching and registration.
