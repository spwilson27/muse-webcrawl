Substring

In formal language theory and computer science, a substring is a contiguous sequence of characters within a string. For instance, the word "rib" is a substring of "ribosome", and "strings" is a substring of "substring". Substrings are also called factors in some literature, particularly in combinatorics on words.

Definitions

Given a string s of length n, a substring is any string s[i..j] consisting of the characters from index i to index j inclusive, where 0 ≤ i ≤ j < n. The empty string is conventionally counted as a substring of every string. A proper substring is a substring that is not equal to the whole string. A string has exactly n(n+1)/2 non-empty substrings (counted with multiplicity of position), though the number of distinct substrings may be smaller.

A prefix is a substring beginning at the first character, and a suffix is a substring ending at the last character. Substrings should not be confused with subsequences, which are formed by deleting characters without requiring contiguity — every substring is a subsequence, but not conversely.

Algorithms and applications

Substring problems are fundamental in string algorithms. The substring-search problem (finding whether and where a pattern occurs in a text) is solved efficiently by algorithms such as Knuth–Morris–Pratt and Boyer–Moore. Data structures including suffix arrays, suffix trees, and suffix automata compactly represent all substrings of a string and support queries such as counting distinct substrings and finding the longest repeated or longest common substring. Applications include text editors, bioinformatics (searching DNA sequences), plagiarism detection, and data compression.
