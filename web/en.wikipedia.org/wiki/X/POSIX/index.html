POSIX

The Portable Operating System Interface (POSIX; also styled IEEE Std 1003) is a family of standards specified by the IEEE Computer Society for maintaining compatibility between operating systems. POSIX defines the application programming interface (API), along with command-line shells and utility interfaces, for software compatibility with variants of Unix and other operating systems. The name was suggested by Richard Stallman as a pronounceable rendering of "portable operating system interface".

Contents

The modern POSIX standard, IEEE Std 1003.1, is developed jointly by the Austin Group (the IEEE, The Open Group and ISO/IEC JTC 1/SC 22/WG 15) and is technically identical to the base specifications of the Single UNIX Specification. It covers system interfaces (functions such as fork, exec and pthread threading), the shell command language, and hundreds of utilities such as awk, grep, sed and vi.

Compliance

Most Unix-like systems are largely POSIX-compliant. Fully certified examples include macOS (since 10.5 Leopard on Intel) and several commercial Unix systems. Linux distributions are generally not formally certified but follow POSIX closely; the Windows NT kernel family historically provided limited POSIX subsystems (Interix/SFU), later replaced by the Windows Subsystem for Linux.
