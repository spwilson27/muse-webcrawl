ArchiMate

ArchiMate is an open and independent enterprise architecture modelling language maintained by The Open Group. It provides a standard notation for describing, analysing and visualising the relationships among business, application and technology domains of an organisation's architecture.

History

ArchiMate was developed in the Netherlands in the early 2000s by a consortium led by the Telematica Instituut, with partners from government, industry and academia. In 2008 stewardship passed to The Open Group, which published ArchiMate 1.0 in 2009. Version 2.0 followed in 2012, 3.0 in 2016 and 3.2 in 2022.

Framework

The language organises elements into layers — strategy, business, application, technology, physical and implementation & migration — crossed by aspects: passive structure (information and objects), behaviour (processes and services), and active structure (actors, components and devices). A core concept is service orientation: elements in one layer provide services consumed by the layer above. ArchiMate is designed to align closely with the TOGAF standard, whose architecture development method it commonly supports.

Tools and exchange

Models can be exchanged between tools using the ArchiMate Model Exchange File Format (XML). Popular modelling tools include the open-source Archi tool, as well as commercial enterprise-architecture platforms.
