Tru64 UNIX

Developer: DEC, Compaq, HP
Platform: DEC Alpha
Kernel: Mach-based hybrid
First released: 1992 (as DEC OSF/1)
Final release: 5.1B (2010s support era)

Tru64 UNIX is a discontinued 64-bit Unix operating system for the DEC Alpha instruction-set architecture, developed successively by Digital Equipment Corporation (DEC), Compaq and Hewlett-Packard. It originated as DEC OSF/1, the first commercial operating system based on the Open Software Foundation's OSF/1 code.

History

DEC released OSF/1 in 1992 for its Alpha workstations and servers. The system used a Mach-derived kernel with BSD and System V compatibility, and was notable for being built from the start as a fully 64-bit system — operating system, file system and applications alike. It was renamed Digital UNIX in 1995 and then Tru64 UNIX in 1998, after Compaq acquired DEC, to emphasise its 64-bit design.

Features

Tru64 was praised for its TruCluster clustering software, the AdvFS advanced file system, and strong symmetric multiprocessing scalability on AlphaServer systems. After HP acquired Compaq in 2002, HP initially planned to migrate Tru64 features into HP-UX but cancelled the project; sales of new licences ended in the early 2010s and extended support wound down thereafter, ending with the Alpha platform itself.
