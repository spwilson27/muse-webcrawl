Mach (kernel)

Mach is a microkernel (and, in early versions, monolithic kernel) developed at Carnegie Mellon University by Richard Rashid and Avie Tevanian to support operating-system research, emphasising multiprocessing and portability. It began in 1984 as a successor to the Accent kernel.

Design

Mach reduces the kernel to a small set of abstractions: tasks and threads, address spaces with virtual-memory management, message-based inter-process communication via ports, and memory objects that allow pagers to live outside the kernel. Most operating-system services — file systems, device drivers, protocol stacks — run as user-level servers communicating by messages.

History and influence

Mach 2.5 underlay early releases of NeXTSTEP and the OSF/1 operating system of the Open Software Foundation. Mach 3.0 was a true microkernel version. Although pure microkernels suffered performance criticism, Mach's design proved influential: Apple's XNU kernel, used in macOS and iOS, combines Mach with BSD components in a hybrid design; the GNU Hurd was built on Mach; and research systems such as L4 trace conceptual lineage to lessons learned from Mach.
