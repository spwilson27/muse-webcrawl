The LLDB Debugger (LLDB) is a software debugger developed as part of the LLVM project. It is built as a set of reusable components that leverage existing libraries from LLVM, such as the Clang expression parser and the LLVM disassembler. LLDB is the default debugger in Xcode on macOS and supports debugging programs written in C, Objective-C, C++, and Swift.

Features

LLDB features a powerful expression evaluator, a Python-based scripting interface, and support for multiple target architectures including x86-64, ARM and AArch64. It supports debugging on the host machine as well as remote debugging via a debug server. Its command language is extensible, and many commands are designed to be familiar to users of the GNU Debugger (GDB), including a GDB compatibility driver, lldb-gdb, and a command-mapping layer.

History

Development of LLDB began at Apple around 2010, motivated by the limitations of GDB in indexing and parsing modern C++ and Objective-C code. Apple funded its development as an open-source project under the LLVM umbrella. It shipped as the default debugger in Xcode 5 in 2013. Ports to Linux, FreeBSD, NetBSD, and Windows followed, and LLDB is used by development environments including Android Studio and the Swift toolchain on multiple platforms.

Architecture

LLDB is organised as libraries (liblldb) with a command-line driver, allowing IDEs and editors to integrate it directly. It uses LLVM's JIT for evaluating expressions in the debuggee's context and supports formatted output through data formatters and type summaries, including synthetic children providers for container types.
