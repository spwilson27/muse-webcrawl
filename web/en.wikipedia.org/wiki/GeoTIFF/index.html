GeoTIFF is a public domain metadata standard that allows georeferencing information to be embedded within a TIFF raster image file. The potential additional information includes map projection, coordinate systems, ellipsoids, datums, and everything else necessary to establish the exact spatial reference of the image.

How it works

GeoTIFF defines a set of reserved TIFF tags ("GeoKeys") that store, among other things, the model type (projected, geographic or geocentric), the pixel scale, tiepoints linking raster coordinates to model coordinates, and identifiers from the EPSG registry for coordinate reference systems and units. Because the metadata travels inside the file itself, a GeoTIFF remains self-describing without external sidecar files.

History and adoption

The format was created in the early 1990s, principally by Niles Ritter of NASA's Jet Propulsion Laboratory and Mike Ruth, drawing on earlier efforts such as the SPOT and USGS formats; Revision 1.0 was published in 1995. Handling was popularised by Frank Warmerdam's libgeotiff library and the GDAL raster library, making GeoTIFF the default interchange format for satellite imagery, digital elevation models and scanned maps. In 2019 the Open Geospatial Consortium adopted GeoTIFF 1.1 as a formal standard, and the Cloud Optimized GeoTIFF (COG) profile — using internal tiling and overviews for HTTP range-request streaming — became the common way to serve such data from cloud storage.
