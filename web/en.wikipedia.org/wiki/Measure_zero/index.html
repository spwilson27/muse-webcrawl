Measure zero

In mathematical analysis, a set has measure zero (or is a null set) if it can be covered by a countable union of intervals (or, in higher dimensions, boxes) of arbitrarily small total length (volume). Formally, a subset S of the real line has Lebesgue measure zero if, for every ε > 0, there is a countable covering of S by intervals whose total length is less than ε.

Examples

Any single point has measure zero, as does any finite set. Because a countable union of null sets is again null, every countable set — including the rational numbers ℚ — has measure zero, even though the rationals are dense in the real line. Uncountable sets can also have measure zero: the classic example is the Cantor set, which has the cardinality of the continuum yet is constructed so that its total length is zero. By contrast, any set of positive measure must be uncountable, and the "fat Cantor sets" show that a nowhere dense closed set can nonetheless have positive measure.

Uses

Measure zero is the technical backbone of the phrase "almost everywhere": a property holds almost everywhere if the set where it fails has measure zero. Lebesgue's criterion states that a bounded function on an interval is Riemann integrable if and only if its set of discontinuities has measure zero — explaining why, for instance, the Dirichlet function (discontinuous everywhere) is not Riemann integrable, while Thomae's function (discontinuous only on the rationals) is. In probability, events of measure zero are "almost surely" excluded; in differential geometry and integration on manifolds, null sets allow coordinate changes and integrals to disregard negligible exceptional sets.
