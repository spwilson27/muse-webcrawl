Berlekamp–Massey algorithm

The Berlekamp–Massey algorithm is an algorithm for finding the shortest linear feedback shift register (LFSR) that generates a given binary output sequence.

Method

Developed from Elwyn Berlekamp's work on decoding BCH codes and James Massey's formulation, the algorithm iteratively updates a connection polynomial whenever the register fails to predict the next symbol.

Uses

It is used in error-correcting codes, stream-cipher cryptanalysis—since a short LFSR reproducing a keystream breaks the cipher—and in coding theory more broadly.
