Web Monetization

Web Monetization is a proposed web standard and JavaScript API that allows websites to receive small payments, often called micropayments or "streaming payments", from visitors who wish to support the site without advertising or subscriptions. The proposal originated with the company Coil, founded by former Ripple chief technology officer Stefan Thomas, and was developed through the W3C Web Monetization community process together with the Interledger protocol community.

How it works

A website includes a link tag pointing to a payment pointer — an address for receiving Interledger payments. A visitor with a Web Monetization provider (originally a Coil subscription, later wallet providers such as GateHub and Uphold) streams small amounts of money to the site for as long as the page remains open, at a rate set by the provider. A JavaScript API exposes monetization events so the page can react, for example by removing advertisements or unlocking extra content.

Development and adoption

Web Monetization was supported by Grant for the Web, a fund launched in 2019 by Coil, Mozilla and Creative Commons to support creators and open-source work on the standard. Mozilla, Puma Browser and others experimented with native support. The specification continues as a community-driven effort in the W3C Web Monetization Community Group, using the Rafiki open-source implementation of Interledger.
