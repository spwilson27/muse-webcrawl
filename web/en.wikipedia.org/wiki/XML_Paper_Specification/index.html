The XML Paper Specification (XPS) is a page description language and fixed-document format developed by Microsoft. Like PDF, it describes documents in a device- and resolution-independent way so that a document appears and prints identically everywhere. XPS files use the .xps extension; the standardised OpenXPS variant uses .oxps.

Technology

An XPS document is a ZIP archive following the Open Packaging Conventions, containing XML markup that describes each page's text, vector graphics and images, together with embedded fonts and colour profiles. The format is based on the Windows Presentation Foundation (WPF) printing and display architecture and uses a subset of XAML to define page layout.

XPS was introduced with Windows Vista in 2006, which included an XPS viewer and a virtual printer ("Microsoft XPS Document Writer") for creating XPS files from any application. Support was also added to Windows XP via the .NET Framework.

Standardisation

In 2009 the specification was standardised by Ecma International as ECMA-388, the Open XML Paper Specification (OpenXPS), which differs slightly from Microsoft's original XPS, notably in its handling of some markup features.

Comparison with PDF

XPS was widely seen as Microsoft's answer to Adobe's PDF. Although XPS is integrated into Windows and supports features such as digital signatures and rights management, it never achieved PDF's cross-platform ubiquity, and Microsoft later de-emphasised the format, removing the XPS Viewer as a default component in later Windows 10 releases (while retaining the newer OpenXPS viewer).
