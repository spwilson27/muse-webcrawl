Internet protocol suite

The Internet protocol suite, commonly known as TCP/IP, is a framework for computer networking protocols used in the Internet and similar networks. The suite is the conceptual model and set of communications protocols developed in the 1970s by DARPA for the ARPANET, and it defines how data should be packetized, addressed, transmitted, routed and received.

Layers

The suite is organized into four abstraction layers:

LayerExamples
Application layerHTTP, SMTP, FTP, DNS, SSH
Transport layerTCP, UDP, QUIC
Internet layerIP (IPv4, IPv6), ICMP
Link layerEthernet, Wi-Fi, ARP

History

The foundational specifications were written by Vint Cerf and Bob Kahn in 1974, building on work in packet switching by researchers in the United States, Britain and France. The standards are published as Requests for Comments (RFCs) overseen by the Internet Engineering Task Force (IETF). The defining documents are RFC 1122 and RFC 1123, with the core protocols specified in documents such as RFC 791 (IP) and RFC 793 (TCP, later updated by RFC 9293).

Comparison with OSI

The Internet protocol suite predates the seven-layer OSI model and uses a simpler four-layer structure; the models correspond approximately, with the Internet application layer encompassing the OSI application, presentation and session layers.
