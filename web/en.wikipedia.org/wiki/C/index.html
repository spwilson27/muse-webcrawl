C (programming language)

C is a general-purpose programming language created by Dennis Ritchie at Bell Labs between 1972 and 1973 to construct utilities for the Unix operating system. It has become one of the most widely used programming languages of all time, providing low-level access to memory and language constructs that map efficiently to machine instructions, and forming the basis of the syntax of many later languages such as C++, Java and C#.

History

C evolved from Ken Thompson's B language, itself derived from BCPL. Ritchie developed C on the PDP-11 to rewrite the Unix kernel, and the language was first described for a wider audience in the 1978 book The C Programming Language by Brian Kernighan and Ritchie ("K&R"). The ANSI standard of 1989 (ANSI C) and subsequent ISO standards (C99, C11, C17, C23) formalized the language.

Characteristics

C features a small core language, structured control flow, pointers and direct memory manipulation, a simple standard library, and a static type system. A classic first program is:

#include <stdio.h>

int main(void) {
    printf("hello, world\n");
    return 0;
}

Uses

C remains dominant in operating systems, embedded systems, compilers and high-performance software where close control of hardware is required. The Linux kernel, much of Windows and most Unix systems are written largely in C.

Criticism

The language's manual memory management and permissive pointer arithmetic are frequent sources of buffer overflows and security vulnerabilities, motivating safer systems languages that nonetheless borrow C's syntax and ABI.
