A data dictionary, in computing and data management, is a centralised repository of information — metadata — about data: its meaning, origin, format, allowed values, relationships to other data, and who is responsible for it. By giving an organisation a single authoritative description of its data elements, a data dictionary helps analysts, developers and users interpret data consistently and prevents the same term from being silently used in different senses by different departments.

Contents

For each data element a dictionary typically records the element's name and any aliases, a precise definition, its data type and length, permitted values or ranges, whether it may be null, default values, the system or table in which it is stored, and its owner or steward. In a database management system, the built-in system catalogue is an active data dictionary maintained automatically by the software itself, storing schemas, constraints, indexes and access privileges; "passive" dictionaries are maintained separately and must be updated by hand whenever the underlying systems change.

Uses

Data dictionaries support database design, application development, impact analysis (which programs would break if a field changed), data governance and regulatory compliance. In research and statistics, the term also refers to the codebook accompanying a dataset, defining each variable — an essential companion document for surveys and clinical trials.
