Material Exchange Format

Material Exchange Format (MXF)
Filename extension: .mxf
Developed by: SMPTE
Type: Container format for professional video

The Material Exchange Format (MXF) is a container format for professional digital video and audio media defined by a set of SMPTE standards (notably ST 377). It is designed for the exchange of programme material between servers, tape decks, and editing systems in broadcast production.

Features

MXF wraps essence (video, audio, data) with rich metadata in a key-length-value (KLV) encoded structure, supporting timecode, descriptive metadata, and partial restore. Operational patterns (OP1a, OP-Atom, etc.) constrain the format for different workflows.

Usage

MXF is widely used in television broadcasting, digital cinema distribution variants, and camera recording formats such as Panasonic P2 and Sony XDCAM.

References
