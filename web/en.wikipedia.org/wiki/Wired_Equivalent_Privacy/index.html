Wired Equivalent Privacy

Wired Equivalent Privacy (WEP) is a deprecated security algorithm for IEEE 802.11 wireless networks. Introduced as part of the original 802.11 standard in 1997, it was intended to provide data confidentiality comparable to that of a traditional wired network. WEP was found to have serious design flaws, and in 2004 the IEEE formally deprecated it in favour of Wi-Fi Protected Access (WPA and WPA2).

How it works

WEP encrypts each frame with the RC4 stream cipher using a concatenation of a shared secret key and a 24-bit initialisation vector (IV), and appends a CRC-32 checksum as an integrity check value. Two key lengths were common: "64-bit WEP" (40-bit key) and "128-bit WEP" (104-bit key), the shorter length resulting from US export restrictions of the era.

Flaws

The 24-bit IV is so short that it repeats after only a few thousand packets, and RC4 key scheduling weaknesses — exposed by Fluhrer, Mantin and Shamir in 2001 — let attackers recover the key passively after collecting enough traffic. The linear CRC-32 is not a cryptographic integrity check, so packets can be modified undetected. Tools such as Aircrack-ng can crack a WEP key in minutes, and WEP should never be used where any alternative exists.
