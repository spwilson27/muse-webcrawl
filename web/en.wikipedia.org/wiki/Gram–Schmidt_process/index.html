Gram–Schmidt process

Each new orthogonal vector is obtained by subtracting from a given vector its projections onto the previous ones.

In mathematics, particularly linear algebra and numerical analysis, the Gram–Schmidt process (or Gram–Schmidt orthogonalisation) is a method for orthonormalising a set of vectors in an inner product space, most commonly the Euclidean space Rn equipped with the standard inner product. It is named after the Danish mathematician Jørgen Pedersen Gram and the German mathematician Erhard Schmidt, though the method appeared earlier in the work of Laplace and Cauchy.

Definition

Given linearly independent vectors v1, …, vk, the projection operator is defined by

proju(v) = ( ⟨u, v⟩ / ⟨u, u⟩ ) u

The Gram–Schmidt process then constructs orthogonal vectors u1, …, uk by

u1 = v1,   uj = vj − Σi<j projui(vj)

Normalising each uj to unit length, ej = uj / ‖uj‖, yields an orthonormal set that spans the same subspace as the original vectors. If an input vector is linearly dependent on the previous ones, the procedure produces the zero vector, signalling that dependence.

Applications

The process underlies several standard constructions:

  • QR decomposition — factoring a matrix A = QR, where Q has orthonormal columns produced by applying Gram–Schmidt to the columns of A and R is upper triangular.
  • Constructing orthonormal bases of polynomials (Legendre, Chebyshev and other orthogonal polynomials arise from applying Gram–Schmidt to monomials under suitable inner products).
  • Orthogonalising wavefunctions and basis sets in quantum mechanics and computational chemistry.
  • Algorithms in lattice reduction and in the theory of determinant calculations (the Gram determinant tests linear independence).

Numerical stability

The classical algorithm as written above is numerically unstable: rounding errors can cause the computed vectors to lose orthogonality badly when the input vectors are nearly parallel. The modified Gram–Schmidt process, which subtracts the projections one at a time and immediately uses each updated vector, is mathematically equivalent in exact arithmetic but far more stable in floating point, and is the version implemented in serious numerical software. Even more stable alternatives, such as Householder reflections and Givens rotations, are generally preferred for computing QR decompositions.
