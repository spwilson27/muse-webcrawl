Slackware is a Linux distribution created by Patrick Volkerding in 1993. Originally based on Softlanding Linux System (SLS), Slackware has been the basis for many other Linux distributions, most notably the first versions of SUSE Linux distributions, and is the oldest distribution that is still maintained.

Philosophy

Slackware aims for design stability and simplicity and to be the most "Unix-like" Linux distribution. It makes as few modifications as possible to software packages from upstream and tries not to anticipate use cases or preclude user decisions. In contrast to most modern distributions, Slackware provides no graphical installation procedure and no automatic dependency resolution of software packages. It uses plain text files and only a small set of shell scripts for configuration and administration. Without further modification it boots into a command-line interface environment.

History

The first Slackware release, 1.00, was announced on 17 July 1993. The name "Slackware" came from Volkerding's wish not to be taken too seriously at first; it references "slack" as promoted by the Church of the SubGenius. The distribution long used "Bob" Dobbs imagery associated with that parody religion.

Because of its conservative and simple design, Slackware is often considered suitable for advanced and technically inclined Linux users. Release 15.0, the first stable release in nearly six years, arrived in February 2022 with the Plasma 5 desktop and Linux kernel 5.15.

Package management

Slackware packages are tarballs compressed with xz (historically gzip), installed and removed with the pkgtool family of tools. The official slackpkg tool can update the system, but dependency resolution is left to the administrator — a deliberate design choice.
