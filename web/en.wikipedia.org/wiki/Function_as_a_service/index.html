Function as a service

Function as a service (FaaS) is a category of cloud computing services that provides a platform allowing customers to develop, run, and manage application functionalities without the complexity of building and maintaining the infrastructure typically associated with developing and launching an app. It is a core component of the serverless computing model.


Event-driven function execution

Characteristics

In a FaaS offering, developers deploy individual functions — small units of code — which the provider executes in response to events such as HTTP requests, database changes or messages arriving on a queue. The provider manages provisioning, scaling and patching, starts containers on demand, and bills by execution time and resources consumed, often in increments of milliseconds. Instances are ephemeral and stateless; persistent state must live in external storage or databases.

Examples

AWS Lambda, launched in 2014, popularised the model; other major offerings include Microsoft Azure Functions, Google Cloud Functions (Cloud Run functions) and Cloudflare Workers. Open-source frameworks such as Knative and Apache OpenWhisk allow FaaS-style deployment on private infrastructure.

Drawbacks

Cold-start latency, execution time limits, difficulty in local testing and debugging, and vendor lock-in are commonly cited disadvantages.
