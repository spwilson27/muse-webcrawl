Identity (mathematics)

In mathematics, an identity is an equality relating one mathematical expression A to another mathematical expression B, such that A and B (which might contain some variables) produce the same value for all values of the variables within a certain range of validity. In other words, A = B is an identity if A and B define the same functions.

Examples

Familiar examples include the trigonometric identity sin²θ + cos²θ = 1, which holds for all real values of θ, and Euler's identity eiπ + 1 = 0, linking five fundamental constants. The binomial theorem is also an identity valid for all values of its variables.

Identities and equations

An identity differs from an ordinary equation: an equation may be true only for particular values of its variables (its solutions), whereas an identity holds universally. The symbol ≡ is sometimes used to emphasise that an equality is an identity.

Identity functions and elements

Related uses of the term include the identity function, which maps every element to itself, and the identity element of an algebraic structure, such as 0 for addition or 1 for multiplication, which leaves other elements unchanged under the operation.
