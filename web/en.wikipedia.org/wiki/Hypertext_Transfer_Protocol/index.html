HTTP

Full name: Hypertext Transfer Protocol
Designer: Tim Berners-Lee and the CERN team
First version: 1991 (HTTP/0.9)
Standardised by: IETF (RFC 9110 and related)

The Hypertext Transfer Protocol (HTTP) is an application layer protocol in the Internet protocol suite model for distributed, collaborative, hypermedia information systems. HTTP is the foundation of data communication for the World Wide Web, where hypertext documents include hyperlinks to other resources that the user can easily access.

Development of HTTP was initiated by Tim Berners-Lee at CERN in 1989 and summarised in a simple document describing the behaviour of a client and a server using the first HTTP version, named 0.9. The protocol was standardised by the Internet Engineering Task Force; HTTP/1.1 (1997, refined in RFC 2616 and later the RFC 723x series and RFC 9110) long dominated. HTTP/2 (2015) introduced binary framing, multiplexing, and header compression over a single connection, and HTTP/3 (2022) runs over QUIC instead of TCP.

Overview

HTTP functions as a request–response protocol in the client–server model. A web browser, for example, acts as the client and submits a request message to a server; the server returns a response message containing completion information (a status code) and the requested content. HTTP is stateless: each request is independent, with state managed by mechanisms such as cookies. HTTP resources are identified by Uniform Resource Locators (URLs).

Request methods

HTTP defines a set of request methods indicating the desired action: GET retrieves a resource; POST submits data for processing; PUT replaces the target resource; DELETE removes it; HEAD, OPTIONS, PATCH, and others serve specialised purposes. Responses carry status codes grouped in classes: informational (1xx), success (2xx), redirection (3xx), client error (4xx), and server error (5xx).

Security

HTTP messages are transmitted in plaintext in the original protocol. HTTPS wraps HTTP in TLS encryption, providing confidentiality, integrity, and server authentication, and is now used by the large majority of web traffic.
