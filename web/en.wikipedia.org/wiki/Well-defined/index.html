Well-defined


A definition is well-defined when it gives the same result for every representative of an object.

In mathematics, a definition is well-defined if its value does not depend on the particular way the object being defined is represented. The concern arises most often when a function or operation is defined on equivalence classes: one picks a representative of the class, applies some rule, and must check that any other representative would have given the same answer. If the check fails, the "definition" is ambiguous and therefore not a valid definition of a function at all.

Examples

A classic example is arithmetic on fractions. Addition of rational numbers, defined by (a/b) + (c/d) = (ad + bc)/(bd), is well-defined because replacing a/b by an equivalent fraction such as (2a)/(2b) yields a result equivalent to the original answer. By contrast, the purported function from rational numbers to integers that sends a/b to a + b is not well-defined, since 1/2 and 2/4 represent the same rational number but would be sent to 3 and 6 respectively.

Similar checks are required for operations on cosets in group theory, functions defined by cases, and operations in quotient structures generally: one must verify that the operation respects the equivalence relation before it descends to a genuine operation on the quotient set.

Related usage

The term is also used more loosely for questions that are precisely posed — a "well-defined problem" is one whose statement is unambiguous and admits a determinate answer — and in set theory, where a well-defined collection must satisfy criteria for set membership.
