Red-black tree

Image placeholder: an example red-black tree.

A red-black tree is a self-balancing binary search tree data structure in which each node carries an extra bit of information, its colour, red or black. By constraining the colours on any path from the root to a leaf, the tree ensures that no such path is more than twice as long as any other, so the tree remains approximately balanced and search, insertion and deletion take O(log n) time in the worst case.

Properties

A red-black tree satisfies the following properties: every node is either red or black; the root is black; every leaf (NIL node) is black; if a node is red, both its children are black; and for each node, all simple paths from that node to descendant leaves contain the same number of black nodes.

History

The data structure was invented in 1972 by Rudolf Bayer, who called it the symmetric binary B-tree, and was popularised by Leonidas Guibas and Robert Sedgewick, who gave it the red-black name in 1978. Red-black trees are used in many standard libraries, including the associative containers of C++ and Java, and in the Linux kernel's scheduling and memory-management structures.

Operations

Insertion and deletion proceed as in an ordinary binary search tree and then restore the red-black properties using recolouring and rotations. At most a constant number of rotations is needed, so updates remain efficient.
