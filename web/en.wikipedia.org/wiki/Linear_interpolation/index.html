Linear interpolation

In mathematics, linear interpolation is a method of curve fitting using linear polynomials to construct new data points within the range of a discrete set of known data points. Given two points (x0, y0) and (x1, y1), the interpolated value at x is:

y = y0 + (x − x0) · (y1 − y0) / (x1 − x0)

Applications

Linear interpolation has been used since antiquity for filling gaps in tables, for example in astronomy. Today it is ubiquitous: in computer graphics (where it is often called "lerp"), texture mapping and colour blending use linear and bilinear interpolation; in numerical analysis it underlies the trapezoidal rule and piecewise-linear finite elements; and in signal processing it is the simplest form of resampling.

Accuracy and extensions

The error of linear interpolation is proportional to the square of the spacing between points and to the second derivative of the function. Extensions include bilinear and trilinear interpolation in higher dimensions, and polynomial or spline interpolation when smoother results are needed.
