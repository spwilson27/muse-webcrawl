Classic Mac OS is the series of operating systems developed for the Macintosh family of personal computers by Apple from 1984 to 2001, retroactively named to distinguish it from Mac OS X. It was one of the first commercially successful systems to popularize the graphical user interface with windows, icons, and menus.

History

The original System 1 shipped with the Macintosh 128K in January 1984, introducing the Finder and the menu bar. System 7 (1991) added cooperative multitasking and color; Mac OS 8 (1997) and Mac OS 9 (1999) modernized the interface with the Platinum appearance and Sherlock search.

Architecturally the system remained a single-user, cooperatively-multitasked OS with no memory protection — a source of frequent crashes. Apple replaced it with the Unix-based Mac OS X, shipping Classic compatibility for the transition.

Legacy

Concepts pioneered by classic Mac OS — the desktop metaphor, drag and drop, the trash, the menu bar — became standard across the industry. Enthusiasts maintain emulators such as SheepShaver and Basilisk II.
