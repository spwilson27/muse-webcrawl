Iterator

In computer programming, an iterator is an object that progressively provides access to each item of a collection, in turn. A collection may provide multiple iterators via its interface that provide items in different orders, such as forwards and backwards.

An iterator is often implemented in terms of the structures underlying a collection implementation. It provides an abstraction that decouples algorithms from the details of how a collection stores its elements.

Design pattern

The iterator design pattern, one of the Gang of Four patterns, provides a way to access the elements of an aggregate object sequentially without exposing its underlying representation. A separate iterator object encapsulates the traversal state.

In programming languages

Many languages provide iterators: C++ has iterators as a central part of its standard library containers; Python iterators implement __iter__ and __next__ methods; Java provides the Iterator and Iterable interfaces; Rust, C#, and many other languages have similar facilities, often integrated with for-each loops.

Internal and external iterators

An external iterator leaves control of the iteration with the client, which explicitly advances it. An internal iterator, by contrast, is given a function to apply to each element, and controls the traversal itself.
