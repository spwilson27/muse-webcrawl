Misère Nim

Misère Nim is the misère-play version of the impartial combinatorial game Nim. The rules are identical to normal Nim — players alternately remove any positive number of objects from a single heap — except that the player who removes the last object loses instead of winning.

Strategy

The winning strategy for misère Nim is the same as the normal-play strategy — always leave a position whose nim-sum (bitwise XOR of the heap sizes) is zero — until the move that would leave only heaps of size one. From that point the strategy is adjusted: leave an odd number of heaps of size one, rather than an even number as normal play would require. Thus, if all remaining heaps have size one, the position is losing exactly when the number of heaps is odd, whereas in normal Nim the first player loses only when there are no objects at all.

Theory

Misère Nim is notable because its misère quotient is unusually simple compared with most impartial games: the Sprague–Grundy theory adapts with only the endgame modification described above. This makes it a standard example in combinatorial game theory teaching, contrasting with games whose misère versions are far more complex than their normal-play forms.
