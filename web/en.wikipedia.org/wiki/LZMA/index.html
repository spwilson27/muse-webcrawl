LZMA

The Lempel–Ziv–Markov chain algorithm (LZMA) is an algorithm used to perform lossless data compression. It has been under development since either 1996 or 1998 by Igor Pavlov and was first used in the 7z format of the 7-Zip archiver. This algorithm uses a dictionary compression scheme somewhat similar to the LZ77 algorithm published by Abraham Lempel and Jacob Ziv in 1977 and features a high compression ratio (generally higher than bzip2) and a variable compression-dictionary size (up to 4 GB).

7-Zip, the archiver in which LZMA debuted

Overview

LZMA uses an LZ77-type dictionary coder whose output is encoded with a range encoder guided by a complex model of context and bit-level probability prediction based on Markov chains. The compressed output format specifies a dictionary size, literal context bits, and position slot encoding; decompression is comparatively fast and can be streamed.

LZMA2 and uses

LZMA2 is a simple container format wrapping LZMA chunks, introduced in the .xz file format and the Utils of the same name; it permits multi-threaded compression and decompression and stores incompressible data without wasteful recompression. LZMA and LZMA2 are used in the .7z and .xz formats, in many software installers and firmware images, in the Linux kernel's compressed image formats, and in numerous package distribution systems.

The reference implementation, the LZMA SDK, was released by Pavlov into the public domain. Ports and reimplementations exist in C, Java, Go, Python (in the standard library as lzma), and other languages.
