Note value

In music notation, a note value indicates the relative duration of a note, using the texture of the notehead, its presence or absence of a stem, and the presence or absence of beams or flags. Note values are not absolutely defined durations but are proportional to all other note values in the piece: in a given tempo, a half note lasts exactly half as long as a whole note, and so on.

List of note values

The principal note values, in order from longest to shortest, are: the whole note (semibreve), half note (minim), quarter note (crotchet), eighth note (quaver), sixteenth note (semiquaver), thirty-second note (demisemiquaver), and sixty-fourth note (hemidemisemiquaver). Longer values include the double whole note (breve) and the archaic longa and maxima. Each value is half the duration of the one above it.

Modification

A dot placed after a note (a dotted note) increases its duration by half its original value. Tuplets — most commonly triplets — divide a beat into equal parts other than the prevailing binary division. Ties join two notes of the same pitch into a single sustained sound. Rests use a parallel system of symbols expressing silence of equivalent durations.

Historical development

Modern note values evolved from the mensural notation of the late medieval and Renaissance periods, systematized around 1600 into the barred, metrical notation used today.
