Django (web framework)

Django is a free and open-source, Python-based web framework that runs on a web server. It follows the model–template–views (MTV) architectural pattern and is maintained by the Django Software Foundation. Django's primary goal is to ease the creation of complex, database-driven websites.

History

Django was developed at the Lawrence Journal-World newspaper in 2003–2005 and released publicly in July 2005. It is named after the jazz guitarist Django Reinhardt. Version 1.0 was released in September 2008; long-term support (LTS) releases appear roughly every two years.

Features

Django includes an object-relational mapper (ORM), a templating system, URL routing, an automatically generated administration interface, authentication, caching, and protection against common web attacks. Its "batteries included" philosophy and the reusable "apps" model support rapid development; well-known sites built with it include Instagram, Pinterest (in its early years), and Mozilla support sites.
