Convex hull

In geometry, the convex hull or convex envelope of a set of points is the smallest convex set that contains them. Intuitively, for a set of points in the plane, the convex hull is the shape formed by a rubber band stretched around the outermost points.

Definition and properties

The convex hull can be defined as the intersection of all convex sets containing the given set, or equivalently as the set of all convex combinations of its points. For a finite set of points in the plane, the hull is a convex polygon whose vertices are a subset of the points; in three dimensions it is a convex polyhedron.

Algorithms

Computing convex hulls is a fundamental problem in computational geometry. Well-known algorithms include Graham's scan and the Jarvis march ("gift wrapping"), which run in O(n log n) and O(nh) time respectively, as well as QuickHull and Chan's algorithm. In fixed low dimensions efficient algorithms exist, while the complexity grows in higher dimensions.

Applications

Convex hulls are used in pattern recognition, image processing, geographic information systems, collision detection, statistics (for example in data depth), and as preprocessing steps for problems such as the traveling salesman problem and nearest-neighbor searches.
