Convex set

A convex set is a subset of an affine or vector space such that the line segment between any two of its points is itself contained in the set. A set S is convex when, for all x and y in S and all t in the interval [0, 1], the convex combination tx + (1−t)y is also an element of S.

Examples

Convex sets include intervals, lines, half-planes, disks, balls, ellipsoids, polytopes and any intersection of convex sets. Standard non-examples include annuli, crescents and the union of two disjoint disks. Every affine subspace is convex, and every convex set in Euclidean space is contractible.

Hulls and separation

The convex hull of an arbitrary set is the intersection of all convex sets containing it — equivalently, the set of all convex combinations of its points. The Hahn–Banach separation theorem says that disjoint convex sets can be separated by a hyperplane under mild hypotheses; this underlies much of functional analysis and convex optimization.

Extreme points

A point of a convex set that cannot be written as a proper convex combination of two other points of the set is an extreme point. The Krein–Milman theorem states that a compact convex set is the closed convex hull of its extreme points.
