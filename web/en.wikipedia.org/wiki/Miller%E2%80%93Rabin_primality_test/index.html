Miller–Rabin primality test

The Miller–Rabin primality test is a probabilistic primality test: an algorithm that determines whether a given number is likely to be prime. It was developed from Gary Miller's deterministic test (1976) by Michael O. Rabin (1980), who turned it into an efficient randomised algorithm. The test is widely used in computer algebra systems and cryptographic software, for instance to generate large prime numbers for RSA.

Principle

To test an odd integer n > 2, write n − 1 = 2s·d with d odd, and pick a random base a. If ad ≡ 1 (mod n) or a2rd ≡ −1 (mod n) for some 0 ≤ r < s, then n is a probable prime to base a; otherwise a is a witness that n is composite. A composite that passes is called a strong pseudoprime to base a.

Accuracy

For a composite odd n, at most one quarter of the bases are "liars" that fail to detect compositeness, so k independent rounds give an error probability of at most 4−k. For fixed input sizes, small deterministic sets of bases are known that make the test exact — for example, testing the first few prime bases suffices for all 64-bit integers.

History

Miller's original test was deterministic but relied on the unproven generalised Riemann hypothesis. Rabin's probabilistic version removed that assumption and is the form used in practice.
