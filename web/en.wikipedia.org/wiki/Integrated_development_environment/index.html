An integrated development environment (IDE) is a software application that provides comprehensive facilities for software development. An IDE normally consists of at least a source-code editor, build automation tools, and a debugger. Some IDEs, such as NetBeans and Eclipse, contain the necessary compiler, interpreter, or both; others, such as SharpDevelop and Lazarus, do not.

The boundary between an IDE and other parts of the broader software development environment is not well-defined; sometimes a version control system or various tools to simplify the construction of a graphical user interface (GUI) are integrated.

History

IDEs evolved from simpler development environments. Maestro I, released in 1975, is considered one of the first IDEs. Turbo Pascal (1983) popularised the integrated edit-compile-run cycle on personal computers, and Microsoft's Visual Basic (1991) brought visual GUI design into the mainstream. Modern IDEs add refactoring, code completion (IntelliSense), integrated terminals, and extension marketplaces.

Features

Common features include syntax highlighting, code completion, static analysis, integrated version control, visual designers, and support for multiple programming languages through plug-ins. Web-based IDEs run in a browser and store projects in the cloud.
