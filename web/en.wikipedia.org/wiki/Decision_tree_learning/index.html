Decision tree learning

Decision tree learning is a supervised learning approach used in statistics, data mining, and machine learning. In this formalism, a classification or regression decision tree is used as a predictive model to draw conclusions about a set of observations. The model takes the form of a tree structure: internal nodes represent tests on attributes, branches represent the outcomes of those tests, and leaf nodes represent class labels or continuous values.

Overview

The goal is to create a model that predicts the value of a target variable based on several input variables. An example is the survival of passengers on the Titanic: attributes such as sex, age, and passenger class can be combined in a small tree that separates survivors from non-survivors with reasonable accuracy. Decision trees are prized for their interpretability — the resulting model can be read as a set of if–then rules — and they require little data preparation, handling both numerical and categorical data.

Algorithms

Well-known decision tree algorithms include:

  • ID3 (Iterative Dichotomiser 3), developed by Ross Quinlan, which selects attributes by information gain based on entropy.
  • C4.5, Quinlan's successor to ID3, using gain ratio, handling continuous attributes and missing values, and supporting pruning.
  • CART (Classification and Regression Trees), introduced by Breiman and colleagues, which builds binary trees using the Gini impurity and supports regression as well as classification.
  • CHAID, which uses chi-squared tests for splitting multi-way categorical trees.

Most algorithms grow the tree greedily, top-down, choosing at each node the split that maximises a purity measure such as information gain or minimises impurity such as the Gini index. Growth stops when subsets are pure or a stopping criterion is met.

Overfitting and pruning

Deep trees can overfit training data, memorising noise rather than learning general patterns. Pruning simplifies a tree by removing sections that provide little predictive power, trading a small increase in training error for better generalisation. Cost-complexity pruning, reduced-error pruning, and limits on depth or leaf size are common strategies.

Ensembles

Decision trees are frequently combined into ensembles. Random forests average many trees trained on bootstrap samples with random feature subsets, greatly improving accuracy at some cost to interpretability. Gradient-boosted trees, implemented in systems such as XGBoost and LightGBM, sequentially fit trees to the errors of their predecessors and have won many machine learning competitions.
