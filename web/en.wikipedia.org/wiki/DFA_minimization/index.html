DFA minimization

In automata theory (a branch of theoretical computer science), DFA minimization is the task of transforming a given deterministic finite automaton (DFA) into a DFA that accepts the same regular language and has a minimum number of states. For every regular language there is a unique (up to isomorphism) minimal DFA, a consequence of the Myhill–Nerode theorem.

Approach

Minimization typically proceeds in two steps. First, states that are unreachable from the start state are removed, since they can never participate in accepting a string. Second, states that are indistinguishable — meaning that no input string can lead from one to an accepting state and from the other to a non-accepting state — are merged into equivalence classes, and each class becomes a single state of the minimal machine.

Algorithms

Several algorithms solve the problem. The table-filling algorithm marks pairs of states as distinguishable in rounds until no further pairs can be marked. Moore's algorithm repeatedly refines a partition of the states. Hopcroft's algorithm, which maintains a partition while processing the "smallest half" of each splitting set, is the most efficient classical method, running in O(n log n) time for a DFA with n states. Brzozowski's algorithm obtains the minimal DFA by reversing the transitions, determinising via the subset construction, and repeating the process a second time.
