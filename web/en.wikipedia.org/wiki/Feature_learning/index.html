Feature learning

Feature learning in machine learning is the automatic discovery of useful representations of data, replacing the manual process of feature engineering in which domain experts hand-craft the inputs given to a learning algorithm. Learned features are typically hierarchical: simple low-level patterns are combined into progressively more abstract representations, enabling algorithms to perform well on tasks such as classification, detection, and generation with less human intervention.

Motivation

Traditional machine learning pipelines depend heavily on features designed by experts — edges and corners for images, phonemes for speech, word counts for text. Such pipelines are brittle and labor-intensive. Representation learning seeks algorithms that automatically discover the explanatory factors underlying observed data, disentangling them into features that make downstream tasks easier.

Methods

Unsupervised feature learning includes techniques such as principal component analysis (PCA), independent component analysis, dictionary learning and sparse coding, clustering methods like k-means, and autoencoders, which learn compressed encodings by reconstructing their inputs. Restricted Boltzmann machines and their stacked form, deep belief networks, were historically important in reviving interest in deep architectures.

Supervised feature learning arises naturally in deep neural networks: each layer of a network trained on labelled data transforms the representation of the input, and the final layers' activations serve as learned features. Convolutional neural networks learn spatial hierarchies in images, while recurrent networks and transformers learn contextual features in sequences; word embeddings such as word2vec are a prominent shallow example from natural language processing.

Relationship to deep learning

Feature learning is a defining characteristic of deep learning: instead of engineering features by hand, deep models learn successive levels of abstraction directly from data. The representation-learning perspective, articulated in influential reviews such as Bengio, Courville and Vincent (2013), frames much of modern machine learning research.
