List of PDF software

This is a list of notable software for working with the Portable Document Format (PDF), including viewers, editors, converters and libraries for creating PDF files.

Creators and converters

  • Ghostscript – interpreter for PostScript and PDF, widely used for conversion.
  • Microsoft Print to PDF – built-in virtual printer in Windows.
  • CUPS-PDF and PDFCreator – virtual printers for producing PDFs.
  • Pandoc – document converter that can output PDF via LaTeX.
  • WeasyPrint and Prince – HTML/CSS to PDF renderers.

Libraries

  • iText (Java/.NET), PDFBox (Java), ReportLab and PyPDF (Python), PDFKit (JavaScript), Poppler (C++ rendering library).
