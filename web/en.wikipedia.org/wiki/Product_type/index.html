Product type

In programming languages and type theory, a product type is a compound data type formed by combining other types. A value of a product type is a tuple (or record) containing one value of each component type; the set of possible values is the Cartesian product of the sets of values of the components, which gives the construction its name.


A product type combines component values into a single tuple.

Examples

Pairs, tuples, structs in C, records in Pascal and ML, and classes used as plain data containers are all product types. For example, a point in the plane can be represented by the product type Real × Real, and a record {name: String, age: Int} is a product of a string and an integer. Product types are dual to sum types, which represent a choice between alternatives; the two together form algebraic data types.

Properties

Values of product types are constructed by supplying all components and accessed by projection (or pattern matching). The unit type, with exactly one value, acts as the identity for products. In category theory, product types correspond to categorical products, and their algebraic properties — for instance, that A × (B + C) is isomorphic to (A × B) + (A × C) — mirror the arithmetic of natural numbers, hence the name "algebraic data types".
