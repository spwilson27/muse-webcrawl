Model-driven engineering

Model-driven engineering (MDE) is a software development methodology that focuses on creating and exploiting domain models, which are conceptual models of all the topics related to a specific problem. Hence, it highlights and aims at abstract representations of the knowledge and activities that govern a particular application domain, rather than the computing (i.e. algorithmic) concepts.

MDE is a subfield of model-driven development (MDD), which is often applied together with domain-specific languages (DSLs). The best known MDE initiative is the Object Management Group's Model Driven Architecture (MDA), which defines standards such as UML, MOF, XMI and QVT for model representation and transformation.

Overview

The MDE approach is meant to increase productivity by maximizing compatibility between systems (via reuse of standardized models), simplifying the process of design (via models of recurring design patterns in the application domain), and promoting communication between individuals and teams (via standardization of the terminology and best practices used in the application domain).

Key concepts

Central concepts in MDE include metamodels, which define the structure of modelling languages; model transformations, which convert models between abstraction levels or languages; and code generation, which produces executable artifacts from platform-specific models. Models are typically structured according to a four-layer metamodeling architecture, from instance data up to the meta-metamodel.

Tools and applications

MDE tooling includes the Eclipse Modeling Framework (EMF), MetaEdit+, and various UML-based CASE tools. Applications range from embedded systems and enterprise software to the automatic generation of simulation code and configuration artifacts.
