Gradient descent

Gradient descent is a first-order iterative optimisation algorithm for finding a local minimum of a differentiable function. The idea is to take repeated steps in the opposite direction of the gradient of the function at the current point, because this is the direction of steepest descent. Conversely, gradient ascent follows the gradient toward a local maximum. First proposed by Augustin-Louis Cauchy in 1847, gradient descent is now the workhorse of machine learning, where it is used — usually in its stochastic form and with gradients computed by backpropagation — to train models from linear regression to deep neural networks.

Algorithm

Starting from an initial guess x0, the iteration is:

x(n+1) = x(n) − η ∇f(x(n))

The step size, or learning rate η, is crucial: too small and convergence is slow; too large and the iterates may overshoot, oscillate or diverge. For convex functions with suitable step sizes, gradient descent converges to the global minimum; for non-convex functions it can settle in local minima or saddle points.

Variants

  • Batch gradient descent computes the gradient over the entire training set for each update — accurate but slow for large data.
  • Stochastic gradient descent (SGD) updates using a single randomly chosen example, adding noise that speeds computation and can help escape shallow minima.
  • Mini-batch gradient descent, the usual compromise, updates using small random subsets of the data.

Extensions

Many refinements adapt the step size or direction: momentum accumulates a velocity term; Nesterov accelerated gradient looks ahead before stepping; and adaptive methods such as Adagrad, RMSProp and Adam scale the learning rate per parameter using running averages of gradients and squared gradients. These variants underpin most modern large-scale learning systems.
