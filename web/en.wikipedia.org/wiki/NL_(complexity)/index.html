NL (complexity)


NL
Field: Computational complexity theory
Machine model: Nondeterministic Turing machine
Resource: O(log n) space

In computational complexity theory, NL (Nondeterministic Logarithmic-space) is the complexity class containing the decision problems that can be solved by a nondeterministic Turing machine using a logarithmic amount of memory space.

Definition and properties

NL is a generalization of L, the class of problems solvable in logarithmic space by a deterministic machine. Because a nondeterministic machine can be simulated deterministically with only a quadratic increase in space, Savitch's theorem implies NL ⊆ SPACE(log2 n). The Immerman–Szelepcsényi theorem (1987–88) shows that NL is closed under complement, i.e. NL = co-NL.

Complete problems

The canonical NL-complete problem is ST-connectivity (reachability): given a directed graph and two vertices s and t, determine whether a path exists from s to t. Other NL-complete problems include 2-SAT and reachability in restricted graph classes. NL can also be characterized in descriptive complexity as the set of properties expressible in first-order logic with transitive closure.

Relations to other classes

It is known that L ⊆ NL ⊆ P, and that NL is contained in larger classes such as NC2 and AC1. Whether L = NL remains an open problem in computer science.
