GNOME (pronounced "guh-nome") is a free and open-source desktop environment for Linux and other Unix-like operating systems. It is the default desktop of several major Linux distributions, including Fedora, Ubuntu and Debian. The project was founded in 1997 by Miguel de Icaza and Federico Mena, partly in response to licensing concerns about the toolkit then used by the rival KDE environment.

Design

GNOME's user interface, GNOME Shell, emphasises simplicity and minimal distraction: a top bar, an Activities overview for launching applications and switching workspaces, and few visible controls. GNOME is built on the GTK toolkit and a stack of core libraries including GLib and GObject. Its human interface guidelines encourage applications with clean header bars and adaptive layouts.

History

GNOME 1.0 was released in 1999, followed by the widely used GNOME 2 series in 2002. The release of GNOME 3 in 2011 replaced the traditional panel-and-menus desktop with the Shell design, a controversial change that led to the creation of the MATE and Cinnamon desktops as continuations of the older paradigm. GNOME 40 (2021) adopted a new versioning scheme and refreshed the overview design; subsequent six-monthly releases have added features such as dark style support and a quick settings menu.

Applications and community

The project maintains a suite of core applications — a file manager (Files/Nautilus), web browser (Web/Epiphany), terminal, text editor, image viewer and others — developed by the GNOME Foundation's community of volunteers and company contributors. The GNOME Foundation, a non-profit organisation, supports the project's infrastructure, conferences such as GUADEC, and outreach programmes.
