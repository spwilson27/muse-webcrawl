Apache Cassandra

Apache Cassandra is a free and open-source distributed NoSQL database management system designed to handle large amounts of data across many commodity servers with no single point of failure. Originally developed at Facebook for inbox search, it was released as an open-source project in 2008 and became an Apache Software Foundation top-level project in 2010.

Architecture

Cassandra uses a peer-to-peer ring architecture in which all nodes are equal. Data is partitioned by a hash of the partition key and replicated to multiple nodes according to a replication strategy. Its design draws on Amazon's Dynamo for distribution and Google's Bigtable for the data model. Tunable consistency lets applications trade consistency against availability and latency on a per-query basis.

Data model and CQL

Data is organised into keyspaces and tables with rows identified by primary keys; wide rows support many columns for time-series and similar workloads. Cassandra Query Language (CQL) provides an SQL-like syntax for creating tables and querying data, though joins and many relational features are intentionally absent.

Uses

Cassandra is used for high-write, geographically distributed workloads by companies and projects needing continuous availability. Managed services and distributions based on Cassandra are offered by several vendors.
