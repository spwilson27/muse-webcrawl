Inkscape

Inkscape is a free and open-source vector graphics editor used to create vector images, primarily in the Scalable Vector Graphics (SVG) format. It runs on Windows, macOS, and Linux, and is used for creating illustrations, icons, logos, diagrams, maps, and web graphics. Inkscape is released under the GNU General Public License and is a widely used free alternative to proprietary editors such as Adobe Illustrator.

History

Inkscape began in 2003 as a fork of the Sodipodi editor, after disagreements over development direction. The new project adopted the C++ language with the gtkmm toolkit and set full SVG standards compliance as a goal. After a long series of 0.x releases, version 1.0 was released in May 2020, bringing improved performance, HiDPI support, and a modernized interface.

Features

Inkscape provides drawing tools (pen, pencil, calligraphy, shapes, text), object manipulation (transformations, layers, grouping, cloning), fill and stroke controls with gradients and patterns, path operations and simplification, bitmap tracing (potrace), and a large collection of extensions and filters. Because its native format is standard SVG, files can be edited by other tools and rendered directly by web browsers. Inkscape can import and export many formats, including PDF, EPS, PNG, and DXF.

Uses

The editor is popular with hobbyists, open-source projects, and technical illustrators. Among other uses, a large share of the free clip art in the Openclipart library and many diagrams on Wikimedia Commons were produced with it.
