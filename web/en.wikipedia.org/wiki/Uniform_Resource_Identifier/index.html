Uniform Resource Identifier

A Uniform Resource Identifier (URI) is a unique sequence of characters that identifies an abstract or physical resource, such as a web page, file, email address, phone number, or book. The most common form of URI is the Uniform Resource Locator (URL), which identifies a web address; Uniform Resource Names (URNs), such as ISBNs for books, identify resources by name in a particular namespace.

Syntax

URIs are specified by Internet Standard STD 66 (RFC 3986). The generic syntax consists of a scheme followed by a colon, then an optional authority, a path, an optional query, and an optional fragment:

scheme://authority/path?query#fragment

For example, in https://www.example.com:80/path/to/page?key=value#section, the scheme is https, the authority includes the host www.example.com and port 80, the query begins after ?, and the fragment after # identifies a secondary resource such as a section of a document. Characters outside a permitted set are written using percent-encoding.

History and relationship to URLs

The concepts were developed by Tim Berners-Lee and the Internet Engineering Task Force in the early 1990s as part of the World Wide Web's addressing system. The umbrella term URI was introduced to reconcile the URL and URN families: every URL and every URN is a URI, distinguished by whether it gives a location or a persistent name. The WHATWG URL Standard used by web browsers defines a slightly different, more forgiving model, and the term Internationalized Resource Identifier (IRI) extends URIs to permit Unicode characters directly.
