Quadratic programming

Quadratic programming (QP) is the process of solving certain mathematical optimization problems involving quadratic functions. Specifically, one seeks to optimize (minimize or maximize) a multivariate quadratic function subject to linear constraints on the variables. Quadratic programming is a type of nonlinear programming and a generalization of linear programming.

Problem formulation

The quadratic programming problem with n variables and m constraints can be formulated as follows. Given:

  • a real-valued, n-dimensional vector c,
  • an n × n-dimensional real symmetric matrix Q,
  • an m × n-dimensional real matrix A,
  • a real-valued, m-dimensional vector b,

the objective is to minimize (1/2)xTQx + cTx subject to Ax ≤ b, where xT denotes the vector transpose of x.

Solution methods

If the matrix Q is positive semidefinite, the problem is convex, and it can be solved efficiently by methods such as the ellipsoid method or interior-point methods, which run in polynomial time. If Q is positive definite, the objective is strictly convex and there is a unique global minimum. Active-set methods, which work well for small and medium problems, generalize the simplex method. If Q has even one negative eigenvalue, the problem is non-convex and in general NP-hard.

Applications

Quadratic programming arises in portfolio optimization (the Markowitz model of mean-variance analysis), in least-squares problems with constraints, in support vector machines in machine learning, in sequential quadratic programming for general nonlinear optimization, and in control engineering, including model predictive control.
