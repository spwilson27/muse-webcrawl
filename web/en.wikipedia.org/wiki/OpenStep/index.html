OpenStep

The OPENSTEP desktop, heir to NeXTSTEP.
DevelopersNeXT and Sun Microsystems
Announced1993; specification published 1994
TypeObject-oriented application programming interface / specification

OpenStep is an object-oriented application programming interface (API) specification for an object-oriented operating system, with conforming implementations developed by NeXT and Sun Microsystems. It grew out of NeXT's NeXTSTEP environment and was intended to make its frameworks — Foundation and AppKit, written in Objective-C — available across multiple operating systems.

History

Sun and NeXT announced their partnership in 1993, and the OpenStep specification was published in September 1994. NeXT implemented it as part of OPENSTEP (versions 4.x of its operating system, for NeXT hardware, Intel PCs, SPARC and PA-RISC), while Sun planned an implementation for Solaris that was never fully delivered. The best-known deployment ran on Windows NT as part of Apple's "Yellow Box" after Apple acquired NeXT in late 1996.

Legacy

OpenStep is the direct ancestor of Apple's Cocoa API: macOS (and later iOS) frameworks retain the "NS" class prefix inherited from NeXTSTEP/OpenStep, and core ideas — Interface Builder, nib files, target–action and delegation — descend from it. The free-software GNUstep project reimplements the OpenStep specification and Cocoa-compatible APIs for Unix-like systems.

Architecture

The specification comprises the Foundation Kit (basic classes: strings, collections, run loops, distributed objects) and the Application Kit (user-interface objects and event handling), together with Display PostScript for drawing. Unlike NeXTSTEP the operating system, OpenStep the specification abstracted over the underlying OS, so applications could be hosted on third-party platforms.
