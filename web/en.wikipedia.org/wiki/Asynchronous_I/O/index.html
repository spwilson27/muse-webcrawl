Asynchronous I/O

Asynchronous I/O (or non-blocking I/O) is a form of input/output processing that permits other processing to continue before a transmission or read/write operation has finished. A process initiates an operation and is later notified of its completion, rather than waiting (blocking) for it.

Forms

Common models include readiness-based notification, as in the Unix select, poll, epoll and kqueue mechanisms; completion-based interfaces such as POSIX AIO, Windows overlapped I/O and Linux io_uring; and signal-driven I/O. Programming models built on these primitives include event loops, callbacks, futures and promises, and coroutines.

Uses

Asynchronous I/O underpins high-concurrency network servers, graphical user interfaces, and modern runtimes such as Node.js, allowing a single thread to manage many simultaneous connections.
