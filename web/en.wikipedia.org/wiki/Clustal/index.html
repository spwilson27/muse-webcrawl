Clustal

Clustal
Developers: Desmond Higgins and colleagues
Initial release: 1988 (Clustal); 1994 (ClustalW); 1997 (ClustalX); 2011 (Clustal Omega)
Type: Bioinformatics software
License: Free for academic use

Clustal is a series of widely used computer programs in bioinformatics for multiple sequence alignment of protein and nucleotide sequences. It was developed chiefly by Desmond Higgins and collaborators.

Versions

Successive versions include the original Clustal, ClustalV, ClustalW (a command-line version described in a 1994 paper by Thompson, Higgins, and Gibson that became one of the most cited papers in biology), ClustalX (a graphical interface), and Clustal Omega, released in 2011, which uses seeded guide trees and hidden Markov model profile–profile alignment to align very large numbers of sequences quickly.

Method

Clustal uses progressive alignment: all pairs of sequences are aligned to compute a distance matrix, from which a guide tree is built; sequences are then aligned progressively following the tree, starting with the most similar pair. Position-specific gap penalties and substitution matrices such as BLOSUM are applied.
