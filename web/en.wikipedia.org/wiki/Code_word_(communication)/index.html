Code word (communication)

In communication, a code word is a word or phrase designed to convey a predetermined meaning to a receptive audience, while remaining inconspicuous or unintelligible to those who do not know the convention. Code words are used in espionage, military operations, emergency services, commerce and everyday social interaction wherever a speaker wishes to communicate discreetly in the presence of others.

Uses

Code words allow information to be transmitted in plain hearing without alerting bystanders. A classic example is the use of prearranged phrases in radio communications: during the Second World War, the BBC broadcast messages personnels to occupied France, among them the lines of Verlaine's poem "Chanson d'automne", which signalled to the French Resistance that the Normandy landings were imminent.

In retail and hospitality, staff may use code words over a public-address system to alert colleagues to a situation — for example a shoplifter, a medical emergency or a lost child — without alarming customers. Hospitals and airports similarly employ colour codes and numbered codes announced over loudspeakers.

In espionage and the military

Intelligence services use code words (also called cryptonyms) to refer to operations, agents and projects in documents and conversation. Military operations are routinely assigned code names, a practice formalised during the Second World War with names such as Operation Overlord. Unlike a cipher, which transforms a whole message, a code word substitutes only selected sensitive terms, leaving the surrounding speech natural.
