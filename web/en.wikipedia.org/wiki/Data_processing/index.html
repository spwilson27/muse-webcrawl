Data processing

Data processing is the collection and manipulation of data to produce meaningful information. In a general sense it covers any conversion of raw data into a more useful form — calculation, sorting, summarization, transformation and reporting — whether performed by hand, by mechanical devices or by computers. In modern usage the term usually implies processing by computer systems, often in large volumes and as a core business function.

Data processing transforms input data through a series of operations into useful output.

Stages

  • Collection — gathering raw data from sources such as transactions, sensors or surveys.
  • Preparation — cleaning, validating and formatting data for processing.
  • Input — loading data into the processing system.
  • Processing — performing calculations, sorting, classification and aggregation.
  • Output — presenting results as reports, files, visualizations or updated records.
  • Storage — retaining data and results for future use.

Modes of processing

Batch processing accumulates transactions and processes them together at intervals, as in payroll systems. Real-time and online transaction processing handle each item immediately. Historically, the term was associated with punched-card tabulating equipment and the data processing departments that ran them; Herman Hollerith's machines, used for the 1890 United States census, are an early landmark. Today data processing underpins database management, data warehousing and large-scale analytics on distributed systems.
