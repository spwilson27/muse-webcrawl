Drop C tuning

Drop C tuning is an alternative guitar tuning where at least one string is lowered to C, but most commonly the whole guitar is tuned down one whole step with the lowest string dropped further. The most common arrangement, from lowest to highest string, is C–G–C–F–A–D. It is derived from drop D tuning by lowering all strings a whole step.

Usage

Drop C gives a heavier, lower sound and allows power chords to be played with a single finger (barre) on the three lowest strings. It is widely used in heavy metal, metalcore, and hard rock by bands seeking a darker tonality while retaining the fingering convenience of drop tunings. Because of the reduced string tension, heavier string gauges are often used.
