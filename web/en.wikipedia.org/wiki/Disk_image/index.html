Disk image

From Wikipedia, the free encyclopedia

A disk image is a computer file that contains the complete contents and structure of a storage medium, such as a hard disk drive, floppy disk, optical disc, or USB flash drive. A disk image is produced by making a sector-by-sector copy of the source medium, replicating the structure and contents of the storage device independently of the file system. Depending on the disk image format, a disk image may span one or more computer files.

The format usually contains all of the data on the disk, including partition tables, boot sectors, file system structures, and unused space. Because of this completeness, disk images are widely used for backup, system deployment, software distribution, digital forensics, and emulation of older hardware.

History

Disk imaging originated in the era of floppy disks, when utilities allowed an entire floppy to be copied to a single file for transmission over bulletin board systems and early networks. As optical media became common, the ISO image format, based on the ISO 9660 file system, became the standard way to distribute CD and DVD contents. Modern imaging tools handle hard drives, solid-state drives, and complex partition schemes such as GPT.

Uses

  • Backup and recovery: restoring a system to a known state after failure or malware infection.
  • System deployment: installing identical operating system configurations on many machines, sometimes called cloning.
  • Software distribution: distributing operating systems and large applications as downloadable images.
  • Forensics: creating bit-for-bit copies of evidence media so the original is preserved.
  • Emulation and virtualization: virtual machines use disk image formats such as VHD, VMDK, and QCOW2 as their virtual hard drives.

Formats

Common formats include raw images (often with the .img extension), ISO images for optical media, Apple's DMG, Microsoft's VHD and VHDX, VMware's VMDK, and the QEMU QCOW2 format. Some formats support compression, encryption, split files, and incremental or differential backups. Creating an image is often called imaging a disk, and the resulting file may be mounted by an operating system so that it appears as a physical drive.
