Smart pointer

In computer science, a smart pointer is an abstract data type that simulates a pointer while providing added features, such as automatic memory management or bounds checking. Such features are intended to reduce bugs caused by the misuse of pointers, while retaining efficiency. Smart pointers typically keep track of the memory they point to, and may also be used to manage other resources, such as network connections and file handles. Smart pointers were first popularized in the programming language C++ during the first half of the 1990s as a rebuttal to criticisms of C++'s lack of garbage collection.

Ownership semantics

Smart pointers are usually implemented as class templates whose instances have the semantics of pointers, but also manage the lifetime of the pointed-to object through the RAII (resource acquisition is initialization) idiom. The C++ standard library defines several types in the <memory> header:

  • std::unique_ptr — sole, exclusive ownership; the object is destroyed when the unique pointer goes out of scope. Introduced in C++11.
  • std::shared_ptr — shared ownership via reference counting; the object is destroyed when the last shared pointer is destroyed or reset.
  • std::weak_ptr — a non-owning observer of a shared_ptr-managed object, used to break reference cycles; must be converted to a shared_ptr to access the object.
  • std::auto_ptr — an early design with transfer-of-ownership copy semantics, deprecated in C++11 and removed in C++17.
std::unique_ptr<Widget> p = std::make_unique<Widget>();
std::shared_ptr<Widget> q = std::make_shared<Widget>();
std::weak_ptr<Widget>   w = q;   // does not extend lifetime

In other languages

Rust's ownership system is built around smart-pointer types in its standard library, notably Box<T> (unique ownership on the heap), Rc<T> (single-threaded reference counting) and Arc<T> (thread-safe reference counting). Managed languages such as C# and Java incorporate some smart-pointer-like behaviour (such as weak references) on top of tracing garbage collection.
