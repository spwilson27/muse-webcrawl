Inter frame

An inter frame is a frame in a video compression stream that is expressed in terms of one or more neighboring frames, rather than containing a complete image. Inter frames are used in standards such as MPEG-2, H.264/AVC, and H.265/HEVC to exploit temporal redundancy between successive pictures.

Types

P-frames are predicted from a preceding frame using motion compensation, storing only motion vectors and the prediction error. B-frames are predicted bidirectionally from preceding and following frames, often achieving the highest compression. Inter frames depend on other frames, so decoding must start from a self-contained intra frame (keyframe).

Trade-offs

Because consecutive images in natural video usually differ only slightly, inter frames can be far smaller than independently coded frames. The cost is greater encoding complexity, latency, and error propagation: damage to a reference frame affects all frames predicted from it until the next keyframe.
