The Classic Environment, usually referred to as Classic, is a hardware and software abstraction layer in early versions of Mac OS X that allows applications compatible with Mac OS 9 to run on the newer operating system. It was a key transition technology for users and developers moving from the classic Mac OS to Mac OS X, codenamed "Blue Box" during development (in reference to the blue border shown around the classic desktop when booting).

Operation

Classic loads a Mac OS 9 System Folder into memory and runs it as a process within Mac OS X, sharing the screen with native applications. Mac OS 9 applications appear in their own windows alongside Cocoa and Carbon applications, although the classic desktop uses the older Platinum appearance and its own menu bar conventions. Because Classic runs a complete copy of Mac OS 9, it requires a valid Mac OS 9.1 or later installation, shipped with most PowerPC Macs of the era as "Mac OS 9 Classic Support" discs.

Limitations

Applications running in Classic cannot take advantage of Mac OS X features such as protected memory and preemptive multitasking; if a Classic application crashes, it can bring down the entire Classic environment. Software that accesses hardware directly, including some games and utilities, does not work. Performance is generally good for productivity software but graphics-intensive applications suffer.

Discontinuation

Classic was never supported on Intel-based Macs, which used Rosetta instead to translate PowerPC native applications. Apple removed support in Mac OS X 10.5 Leopard (2007), making 10.4 Tiger the last version able to run Classic on PowerPC hardware. The transition away from Classic marked the end of software compatibility with the pre-2001 Mac OS lineage.
