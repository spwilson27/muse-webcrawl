Interpreter (computing)


An interpreter executes source code instruction by instruction.

In computer science, an interpreter is a computer program that directly executes instructions written in a programming or scripting language, without requiring them to have been compiled into machine language beforehand. Interpreters generally translate and run a program statement by statement, or compile it internally to an intermediate representation such as bytecode that is then executed by a virtual machine.

History

Interpreters date to the earliest days of high-level languages: LISP, developed from 1958, was among the first languages to be primarily interpreted, and BASIC interpreters were ubiquitous on early microcomputers in the 1970s and 1980s, often stored in ROM. In modern practice the line between interpreters and compilers is blurred, with languages such as Python and Java using a mixture of compilation to bytecode and just-in-time compilation at run time.

Advantages and disadvantages

Interpreted programs can start running immediately and are easy to modify and debug interactively, and the same source can run unchanged on different platforms. The trade-off is typically slower execution and the need for the interpreter itself to be present at run time.

Types

Interpreters range from simple recursive-descent evaluators and tree-walking interpreters to threaded-code interpreters and bytecode virtual machines. A read–eval–print loop (REPL) gives users an interactive way to evaluate expressions one at a time.
