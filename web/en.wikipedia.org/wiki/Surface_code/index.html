Surface code

The surface code is a family of quantum error-correcting codes in which qubits are arranged on a two-dimensional lattice and information is stored in the global, topological properties of the array rather than in any single physical qubit. It is the leading candidate architecture for fault-tolerant quantum computation and descends from Alexei Kitaev's toric code.

Structure

Physical "data" qubits sit on the vertices or edges of a square grid, interspersed with "measure" (ancilla) qubits. Repeated rounds of measurements of local parity checks — plaquette (Z-type) and vertex/star (X-type) stabilizers — reveal the locations of errors as "defects" at the boundaries of error chains, without disturbing the encoded information. A decoder, commonly a minimum-weight perfect matching algorithm, infers the most likely error chains so that corrections can be tracked in software.

Logical qubits are defined by holes (defects) cut into the lattice or by the lattice's boundaries; increasing the code distance — the size of the patch — exponentially suppresses the logical error rate, provided physical error rates stay below a threshold close to 1 percent, unusually high among error-correcting codes.

Computation

Logical operations are performed by braiding holes around one another or, in the modern formulation, by lattice surgery — merging and splitting patches of the code. Universal computation additionally requires magic state distillation to implement non-Clifford gates.

Experiments

Superconducting-qubit processors have demonstrated the key scaling behaviour: Google's experiments with its Sycamore and later Willow processors showed that enlarging surface-code patches reduced logical error rates, a landmark result reported in 2024 in which a distance-7 code outperformed its physical qubits. Ion-trap and neutral-atom platforms have also implemented surface-code elements.
