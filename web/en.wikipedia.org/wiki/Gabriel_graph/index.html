Gabriel graph

Named afterK. R. Gabriel
FieldComputational geometry
Introduced1969 (Gabriel & Sokal)

In computational geometry, a Gabriel graph of a set of points in the Euclidean plane is a graph formed from the points as vertices, in which two points are joined by an edge exactly when the closed disc having the segment between them as its diameter contains no other point of the set.

Properties

The Gabriel graph is a subgraph of the Delaunay triangulation and contains the Euclidean minimum spanning tree and the relative neighborhood graph's supergraph relationships in the hierarchy of proximity graphs. It can be computed in linear time from the Delaunay triangulation.

Applications

Gabriel graphs are used in geographic information systems, wireless network routing (where they help define planar, locally computable network topologies), and in the statistical analysis of spatial point patterns, the context in which K. Ruben Gabriel and Robert Sokal introduced the concept in 1969.
