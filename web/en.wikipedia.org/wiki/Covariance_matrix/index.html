Covariance matrix

In probability theory and statistics, a covariance matrix (also called an auto-covariance matrix, dispersion matrix, variance matrix, or variance–covariance matrix) is a square matrix giving the covariance between each pair of elements of a given random vector. Its diagonal entries are the variances of the components, and its off-diagonal entries are the pairwise covariances.

Definition

For a random vector X = (X₁, …, Xₙ)ᵀ with mean vector μ, the covariance matrix is defined as Σ = E[(X − μ)(X − μ)ᵀ], so that the (i, j) entry is Σᵢⱼ = cov(Xᵢ, Xⱼ) = E[(Xᵢ − μᵢ)(Xⱼ − μⱼ)]. When the components are uncorrelated, the matrix is diagonal.

Properties

A covariance matrix is always symmetric and positive semi-definite: for any vector a, aᵀΣa = Var(aᵀX) ≥ 0. Under a linear transformation Y = AX + b, the covariance transforms as ΣY = A ΣX Aᵀ. The determinant of the covariance matrix is sometimes called the generalised variance.

Estimation

Given a sample of observations, the sample covariance matrix is computed by averaging the outer products of the centred observations, with Bessel's correction (dividing by n − 1) giving an unbiased estimator. Covariance matrices are central to principal component analysis, multivariate normal distributions, portfolio theory and Kalman filtering.
