E.164 is an international standard (ITU-T Recommendation) that defines a numbering plan for the worldwide public switched telephone network and some other data networks. E.164 numbers are the globally unique numbers used for international phone calls, SMS routing and many internet identity services.

Format

An E.164 number has a maximum of 15 digits and is usually written with a leading "+" sign followed by the country code (one to three digits) and the national significant number. For example, numbers in the North American Numbering Plan begin with country code 1, followed by a three-digit area code and a seven-digit subscriber number. The "+" represents the international call prefix of the originating country (such as 011 or 00).

Number categories

The plan distinguishes geographic numbers, global services (such as international freephone under country code 800), and numbers for networks and groups of countries. Companion recommendations include E.123 (notation for national and international numbers) and E.212 (mobile country codes for mobile networks).

Use on the internet

E.164 formatting is the default for phone-number fields in messaging applications and two-factor authentication, and the ENUM protocol (E.164 Number Mapping) maps E.164 numbers into DNS names under e164.arpa.
