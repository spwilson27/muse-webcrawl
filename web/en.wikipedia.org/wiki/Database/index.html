Database

From Wikipedia, the free encyclopedia
[Image: A table of rows and columns representing relational data]

A database is an organised collection of data stored and accessed electronically, managed by a database management system (DBMS). Databases range from small embedded stores to global distributed systems holding petabytes.

The relational model, proposed by Edgar F. Codd in 1970, organises data into tables (relations) of rows and columns, queried with SQL; it has dominated for decades (Oracle, MySQL, PostgreSQL, SQL Server). From around 2009, NoSQL systems — document stores, key-value stores, wide-column and graph databases — traded some consistency for scale and flexibility.

Concepts

Key ideas include schemas, keys and normalisation (reducing redundancy), transactions with ACID properties (atomicity, consistency, isolation, durability), indexing (B-trees), and concurrency control. Distributed databases face the CAP theorem's trade-off between consistency and availability under network partitions.

Data warehouses and lakes support analytics rather than transactions; newer systems blend both.

Applications

Databases underpin banking, reservations, e-commerce, social networks, and scientific archives; database administration and design are major professional specialisations.
