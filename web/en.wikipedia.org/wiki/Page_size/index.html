Page size

Page size refers to the dimensions of a page, most commonly of paper used for printing and writing. Standardised paper sizes are used internationally, principally the ISO 216 A series (A4, A5 and so on), while North America continues to use sizes such as Letter and Legal. In computing, "page size" can also refer to the size of a memory page.

ISO 216

The A series is based on a sheet of one square metre (A0) with an aspect ratio of 1:√2, so that halving a sheet along its long side produces the next size down with the same proportions. ISO 216 also defines the B series, and ISO 269 defines the C series for envelopes.

Memory pages

In virtual memory systems, memory is divided into fixed-size pages, commonly 4 KiB on x86 systems, with larger "huge pages" (2 MiB or 1 GiB) available for workloads that benefit from fewer translation lookaside buffer misses.
