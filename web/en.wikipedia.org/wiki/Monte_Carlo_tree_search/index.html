Monte Carlo tree search

Monte Carlo tree search (MCTS) is a heuristic search algorithm for decision-making processes, most notably in game-playing software. It builds a search tree incrementally and asymmetrically using random simulations (playouts) of the game from candidate positions.

The algorithm proceeds in four steps, repeated many times per move: selection, descending the tree by choosing promising nodes, typically with the UCT formula, which balances exploitation of high-scoring moves against exploration of less-visited ones; expansion, adding a new child node; simulation, playing out the game from that node with random or lightly guided moves to a terminal result; and backpropagation, updating the win statistics of all nodes on the path. Unlike minimax search, MCTS does not require a handcrafted evaluation function.

MCTS was introduced around 2006 and revolutionized computer Go, a game long resistant to brute-force search; combined with deep neural networks and reinforcement learning, it was the core of AlphaGo, which defeated world-class human players in 2016. It is now used widely in game AI, planning, and scheduling problems.
