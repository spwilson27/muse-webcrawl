Cantor set

In mathematics, the Cantor set is a set of points lying on a single line segment that has a number of unintuitive properties. It was discovered in 1874 by Henry John Stephen Smith and introduced by German mathematician Georg Cantor in 1883. Through consideration of this set, Cantor and others helped lay the foundations of modern point-set topology. The most common modern construction is the Cantor ternary set, built by removing the middle third of a line segment repeatedly.

Construction

The Cantor ternary set is created by repeatedly deleting the open middle third of a set of line segments. One starts by deleting the open middle third (1/3, 2/3) from the interval [0, 1], leaving two line segments: [0, 1/3] and [2/3, 1]. Next, the open middle third of each of these remaining segments is deleted, leaving four segments. This process is continued indefinitely.

C0 = [0, 1];   Cn+1 = (Cn / 3) ∪ (2/3 + Cn / 3);   C = ∩n Cn

The total length removed is 1/3 + 2/9 + 4/27 + … = 1, so the remaining set has Lebesgue measure zero — yet it is far from empty.

Properties

  • Uncountability: The Cantor set is uncountable; it has the same cardinality as the whole interval [0, 1]. Points in the set are exactly those whose base-3 (ternary) expansion uses only the digits 0 and 2.
  • Self-similarity: The set is the union of two copies of itself scaled by a factor of 1/3; it is a classic example of a fractal.
  • Fractal dimension: Its Hausdorff dimension is log(2)/log(3) ≈ 0.631.
  • Closed and perfect: It is closed, contains no isolated points, and is nowhere dense in [0, 1].
  • Compact and totally disconnected: It contains no interval of positive length.

Endpoints and other points

The endpoints of the removed intervals (such as 0, 1/3, 2/3, 1, 1/9, 2/9, ...) belong to the Cantor set and form a countable dense subset of it. But the set also contains points that are not endpoints of any removed interval — for example, 1/4, whose ternary expansion is 0.020202…3. Every point of the Cantor set is a limit point of endpoints and also a limit point of points that are not endpoints.

Historical notes

Although the set is named after Cantor, similar constructions appeared earlier in the work of Smith (1874) and Volterra. Cantor used the set in developing the theory of transfinite numbers and point sets; the result that a measure-zero set could be uncountable was striking to contemporaries.
