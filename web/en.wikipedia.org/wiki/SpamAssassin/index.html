Apache SpamAssassin is a free, open-source computer program for e-mail spam filtering. It uses a wide variety of techniques — header and text analysis, Bayesian filtering, DNS blocklists, and collaborative filtering databases — to identify spam, and is a project of the Apache Software Foundation.

Operation

SpamAssassin applies a large rule set of tests to each message, each contributing a positive or negative score; a message whose total score reaches a threshold (5.0 by default) is classified as spam. Tests are implemented as Perl regular expressions and modules, and users can add local rules and adjust scores. Optional Bayesian learning (sa-learn) can be trained on a user's own spam and ham, and network tests consult services such as the Spamhaus blocklists and Razor and DCC collaborative checksums.

Deployment

The software can run as a daemon (spamd) with a lightweight client (spamc), be integrated into mail servers such as Postfix and Exim, or be used by mail user agents. It has been a standard component of Unix mail infrastructure since the early 2000s, processing mail for many ISPs and hosting providers.

History

SpamAssassin was created by Justin Mason, building on an earlier filter by Mark Jeftovic, and first released in 2001. It moved to the Apache Incubator in 2003 and became a top-level Apache project in 2004.
