Plug-in (computing)

In computing, a plug-in (or plugin, add-in, add-on, or extension) is a software component that adds a specific feature to an existing computer program. When a program supports plug-ins, it enables customization.

The host application provides services which the plug-in can use, including a way to register itself and a protocol for exchanging data. Plug-ins depend on services provided by the host and do not usually work by themselves; conversely, the host operates independently of the plug-ins, making it possible for end users to add and update plug-ins dynamically.

Examples

Examples include browser extensions, audio plug-ins such as VST effects in digital audio workstations, graphics software plug-ins for image formats, and extensions in integrated development environments such as Visual Studio Code and Eclipse.

History

Plug-in architectures appeared in the 1970s in text editors and were popularized by applications such as HyperCard, Photoshop, and Netscape Navigator, whose NPAPI interface enabled third-party media players such as Flash.
