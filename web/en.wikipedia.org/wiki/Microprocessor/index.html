Microprocessor

Microprocessor
Invented1971 (Intel 4004)
TypeIntegrated circuit (CPU)
Key firmsIntel, AMD, ARM, Apple, Qualcomm

A microprocessor is a computer processor in which the data processing logic and control is included on a single integrated circuit (IC), or a small number of ICs. The microprocessor contains the arithmetic, logic, and control circuitry required to perform the functions of a computer's central processing unit (CPU).

History

The first commercial microprocessor was the Intel 4004, released in 1971 for a calculator project; its designers included Federico Faggin, Marcian "Ted" Hoff, and Stanley Mazor. It was a 4-bit processor with 2,300 transistors. The 8-bit Intel 8080 (1974) powered early personal computers such as the Altair 8800, and the 16-bit Intel 8086 (1978) founded the x86 architecture that still dominates desktop computing. Successive generations — 386, Pentium, Core — alongside ARM-based designs for mobile devices, increased transistor counts into the tens of billions, consistent with Moore's law.

Architecture

A microprocessor fetches instructions from memory, decodes them, and executes them using an arithmetic logic unit (ALU), registers, and a control unit. Modern designs add pipelining, superscalar execution, out-of-order completion, branch prediction, multiple cores, and hierarchical caches. A microcontroller differs by integrating memory and peripherals on the same chip for embedded applications.

Applications

Microprocessors are used in personal computers, servers, smartphones (as systems-on-a-chip), game consoles, automobiles, industrial control, and countless embedded systems.
