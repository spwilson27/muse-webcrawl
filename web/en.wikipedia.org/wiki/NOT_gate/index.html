NOT gate


NOT gate (inverter)
Truth table: input 0 → output 1; input 1 → output 0
Type: Logic gate

The NOT gate, also known as an inverter, is a digital logic gate that implements logical negation. It produces an output that is the opposite logic level of its single input: a high input yields a low output and vice versa. In Boolean algebra the NOT operation on a variable A is written ¬A, Ā, or !A.

Symbols and truth table

The traditional ANSI symbol is a triangle pointing right with a small circle (bubble) at the output, which denotes inversion. The truth table has two rows: input 0 gives output 1; input 1 gives output 0.

Implementation

In CMOS technology an inverter consists of one PMOS and one NMOS transistor with a common gate input and common drain output; it is the simplest and most ubiquitous digital building block. Inverters are also used in analog contexts as simple amplifiers, in ring oscillators, and in Schmitt trigger configurations. In TTL families, hex inverter chips such as the 7404 package six independent NOT gates.

Use

NOT gates are fundamental to digital circuits: combined with NAND or NOR gates they enable any Boolean function, and they serve in signal buffering, level shifting, clock distribution, and memory cells such as SRAM latches.
