Jacobi symbol

The Jacobi symbol is a generalization of the Legendre symbol in number theory. Introduced by Jacobi in 1837, it is written (a/n), where a is an integer and n is any positive odd integer. It is defined as the product of the Legendre symbols corresponding to the prime factors of n, with multiplicity: if n = p1α1p2α2···pkαk, then (a/n) = (a/p1)α1···(a/pk)αk.

Properties

The Jacobi symbol takes values in {−1, 0, 1}; it is 0 exactly when gcd(a, n) ≠ 1. It is completely multiplicative in both arguments and satisfies a law of quadratic reciprocity analogous to that for the Legendre symbol, together with supplementary laws for (−1/n) and (2/n). These rules make it possible to compute the symbol efficiently, in a manner similar to the Euclidean algorithm, without factoring n.

Interpretation

Unlike the Legendre symbol, the Jacobi symbol (a/n) = 1 does not imply that a is a quadratic residue modulo the composite number n; it means only that a has Legendre symbol 1 for an even number of the prime factors of n (counted with multiplicity). The symbol is used in primality tests such as the Solovay–Strassen test and in the Goldwasser–Micali cryptosystem.
