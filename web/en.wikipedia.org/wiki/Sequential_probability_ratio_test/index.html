Sequential probability ratio test

From Wikipedia, the free encyclopedia

The sequential probability ratio test (SPRT) is a specific sequential hypothesis test, developed by Abraham Wald, later proven optimal by Wald and Jacob Wolfowitz: among all tests (sequential or not) with the same error probabilities, the SPRT minimises the expected sample size under both hypotheses. It was first published in 1945 in connection with wartime quality-control work.

Procedure

Instead of fixing the sample size in advance, the SPRT evaluates data one observation at a time. After each observation xi, the cumulative log likelihood ratio is updated:

Λn = Σ log [ f1(xi) / f0(xi) ]

Sampling continues while log(β/(1−α)) < Λn < log((1−β)/α), where α and β are the desired probabilities of type I and type II error. If Λn crosses the upper boundary the null hypothesis is rejected; if it crosses the lower boundary the alternative is rejected (the null is accepted).

Applications

The SPRT is used in industrial acceptance sampling, clinical trials with interim analyses, detection problems in engineering, and computerised adaptive testing. In online experimentation, its "always-valid" descendants (such as mixture SPRTs) are used to monitor A/B tests continuously without inflating false-positive rates.
