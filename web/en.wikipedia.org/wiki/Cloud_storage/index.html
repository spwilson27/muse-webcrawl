Cloud storage

TypeInternet hosting service model
ExamplesObject, file and block storage services

Cloud storage is a model of computer data storage in which digital data is stored on remote servers accessed over the internet ("the cloud"), maintained and operated by a cloud storage provider rather than on local devices.

Models

Services are commonly offered as object storage (data stored as discrete objects, e.g. Amazon S3), file storage (hierarchical filesystems) and block storage. Consumer services emphasise file synchronisation and sharing, while business services emphasise backup, archiving and disaster recovery.

Characteristics

Customers typically pay for capacity used, gain redundancy through replication across sites, and access data from anywhere. Concerns include security, privacy, vendor lock-in and dependence on network availability.
