Booting

In computing, booting is the process of starting a computer as initiated via hardware such as a button or by a software command. After it is switched on, a computer's central processing unit (CPU) has no main operating system software in its main memory, so some process must load software into memory before it can be executed. This may be done by hardware or firmware in the CPU, or by a separate processor in the computer system. The term derives from "bootstrap," as in the idiom "pull oneself up by one's bootstraps."

Process

On personal computers, powering on typically runs firmware (BIOS or UEFI) stored in ROM, which performs a power-on self-test (POST), locates a boot device, and loads a bootloader such as GRUB or Windows Boot Manager. The bootloader then loads the operating system kernel into memory and transfers control to it, after which the system initializes drivers and user services. Restarting a computer is called rebooting, which can be "hard" (power cycled physically) or "soft" (initiated by software without removing power).
