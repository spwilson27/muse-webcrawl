Free-software license

A free-software license is a notice that grants the recipient of a piece of software extensive rights to modify and redistribute that software. These actions are usually prohibited by copyright law, but the rights-holder (usually the author) of a piece of software can remove these restrictions by accompanying the software with a software license which grants those rights.

According to the Free Software Foundation's Free Software Definition, a license qualifies as free when it preserves the "four essential freedoms": the freedom to run the program for any purpose, to study and change it, to redistribute copies, and to distribute modified versions.

Types

Copyleft licenses, such as the GNU General Public License (GPL), require that derivative works be distributed under the same license terms, ensuring the software and its derivatives remain free. Permissive licenses, such as the MIT License, the BSD licenses and the Apache License, impose minimal requirements, typically only attribution and a disclaimer of warranty, and allow use in proprietary software.

Compatibility and approval

Licenses differ in their compatibility: code under one license cannot always be legally combined with code under another. The Free Software Foundation maintains a list of licenses it considers free, and the Open Source Initiative approves licenses that conform to the Open Source Definition; most free-software licenses are also open-source licenses, though the two movements emphasise different values.

Well-known free-software licenses include the GNU GPL (versions 2 and 3), the GNU Lesser General Public License (LGPL), the Apache License 2.0, the MIT License, and the BSD 2- and 3-clause licenses.
