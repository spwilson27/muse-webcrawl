Process (computing)

In computing, a process is the instance of a computer program that is being executed by one or many threads. There are many different process models, some of which are light-weight, but almost all processes (even entire virtual machines) are rooted in an operating system (OS) process which comprises the program code, assigned system resources, physical and logical access permissions, and data structures to initiate, control, and coordinate execution activity.


Processes move between ready, running, and blocked states.

Representation

The operating system represents each process with a process control block (PCB) holding its identifier (PID), state, program counter, register values, memory-management information, and open files. A process's memory typically includes the program code (text), initialised and uninitialised data, a heap, and a stack.

States and scheduling

As a program executes, its process changes state: it may be created, ready to run, running on a CPU, waiting (blocked) for an event such as input/output, and finally terminated. The scheduler decides which ready process runs next; switching between processes is called a context switch. Processes communicate through inter-process communication mechanisms such as pipes, sockets, and shared memory.

Processes and threads

A process provides an isolated address space; threads within a process share that address space while having their own stacks and registers. Modern operating systems schedule threads, and a process may contain one or many threads.
