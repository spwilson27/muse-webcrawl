Trusted Platform Module
Abbreviation:TPM
Standard:ISO/IEC 11889
Developer:Trusted Computing Group
Versions:TPM 1.2; TPM 2.0 (2014)

A Trusted Platform Module (TPM) is a secure cryptoprocessor — a dedicated microcontroller designed to secure hardware through integrated cryptographic keys. The international standard for a TPM is ISO/IEC 11889, published by the Trusted Computing Group (TCG). A TPM provides functions for generating cryptographic keys, limiting their use, storing measurements of the boot process, and reporting the state of the platform to a remote party (remote attestation).

Functions

Key functions include protected storage sealed to platform configuration register (PCR) values, which record hashes of firmware and software measured at boot; cryptographic key generation for signing, encryption and device identity (via endorsement keys burned in at manufacture); and a hardware random number generator and hash functions. These capabilities underpin features such as Windows BitLocker full-disk encryption, measured/secure boot, and credential protection.

Versions and adoption

TPM 1.2 shipped in most business PCs from the mid-2000s. TPM 2.0, released in 2014, is not backward compatible with 1.2; it supports algorithm agility (including elliptic-curve cryptography and, later, post-quantum-ready designs) and enhanced authorisation policies. TPMs may be discrete chips, firmware-based (such as Intel PTT or AMD fTPM), or virtualised. Microsoft made a TPM 2.0 a minimum hardware requirement for Windows 11, greatly increasing deployment. TPM-like functionality also exists in Apple's Secure Enclave and Google's Titan chips.

Criticism

Critics, including free-software advocates, have raised concerns that trusted computing could be used for vendor lock-in and to restrict user control of devices. Physical attacks on discrete TPM bus communication (TPM sniffing) have also been demonstrated against certain disk-encryption setups.
