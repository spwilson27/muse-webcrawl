Single-source publishing

Single-source publishing, also known as single-sourcing, is a content management method that allows the same source content to be used to publish documents in multiple formats, such as print, HTML, PDF, EPUB and online help, without duplicating or manually reformatting the material.

Method

In a single-source workflow, content is authored once in a structured, format-neutral markup language such as XML (for example DocBook or DITA), SGML, or Markdown. Stylesheets and transformation pipelines (for example XSLT) then render the content into each required output. Conditional processing allows variants of a document — for different audiences, products or languages — to be generated from the same source by including or excluding tagged sections.

Advantages

  • Consistency: corrections made once propagate to every output.
  • Reduced maintenance cost compared with maintaining parallel documents.
  • Faster publication across channels and easier localisation.
  • Content can be repurposed in new formats without re-authoring.

Disadvantages

Single-sourcing requires up-front investment in structured authoring tools and training, enforces a degree of writing discipline (topics must be self-contained and context-independent), and can make finely tuned print typography harder because output is generated generically.

Applications

The method is widely used in technical documentation, where software manuals must appear as printed books, web help and in-application assistance, and by publishers producing simultaneous print and electronic editions.
