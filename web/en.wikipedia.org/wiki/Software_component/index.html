Software component

A software component is a modular, reusable unit of software that encapsulates a set of related functions and communicates with other components through well-defined interfaces. Component-based software engineering aims to build systems by composing such pre-built parts.

Definition

A widely cited definition (Szyperski) describes a software component as a unit of composition with contractually specified interfaces and explicit context dependencies only, which can be deployed independently and composed by third parties. Examples of component models include COM, CORBA components, JavaBeans, and modern web components.

Benefits and challenges

Components promise reuse, faster development, and easier maintenance, but introduce challenges in versioning, interface compatibility, and discovering suitable components.
