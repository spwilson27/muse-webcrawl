Square matrix

In mathematics, a square matrix is a matrix with the same number of rows and columns. An n-by-n matrix is known as a square matrix of order n. Any two square matrices of the same order can be added and multiplied.

Square matrices are central to linear algebra: they represent linear transformations of a vector space into itself, and only for square matrices are the determinant, trace, eigenvalues and eigenvectors defined.

Main diagonal

The main diagonal (or principal diagonal) of a square matrix A consists of the entries a11, a22, …, ann, running from the upper left to the lower right corner. The trace is the sum of these entries. A matrix whose entries outside the main diagonal are all zero is a diagonal matrix; the simplest example is the identity matrix.

Special kinds

  • Symmetric matrix: equal to its transpose, A = AT.
  • Skew-symmetric matrix: A = −AT, with zeros on the diagonal.
  • Orthogonal matrix: its transpose equals its inverse.
  • Upper and lower triangular matrices: entries below (or above) the diagonal are zero.
  • Invertible matrix: has a non-zero determinant and possesses a matrix inverse.

Determinant and eigenvalues

The determinant det(A) is a scalar that encodes whether the matrix is invertible and how the associated transformation scales volumes. The eigenvalues λ satisfy det(A − λI) = 0, the characteristic equation, and underlie much of the theory of linear systems, differential equations, and dynamics.
