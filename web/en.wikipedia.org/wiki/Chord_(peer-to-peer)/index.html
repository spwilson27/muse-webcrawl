Chord (peer-to-peer)

From Wikipedia, the free encyclopedia

Chord is a protocol and algorithm for a peer-to-peer distributed hash table (DHT). A distributed hash table stores key-value pairs by assigning keys to different computers (known as "nodes"); a node will store the values for all the keys for which it is responsible. Chord specifies how keys are assigned to nodes and how a node can discover the value for a given key by first locating the node responsible for that key.

Overview

Chord was introduced in 2001 by Ion Stoica, Robert Morris, David Karger, Frans Kaashoek and Hari Balakrishnan at MIT. Nodes and keys are assigned an m-bit identifier using consistent hashing (typically SHA-1). Identifiers are arranged on a circle modulo 2m, and a key is stored at its "successor" — the first node whose identifier equals or follows the key's identifier.

Finger tables

Each node maintains a routing table, called a finger table, with up to m entries pointing to nodes at exponentially increasing distances around the circle. This allows lookups to be resolved in O(log N) messages for a network of N nodes, and nodes can join and leave the network with minimal disruption. Periodic "stabilisation" operations keep finger tables and successor pointers correct as the network changes.
