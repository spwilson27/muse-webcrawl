Orbital elements

Orbital elements are the parameters required to uniquely identify a specific orbit. In celestial mechanics these elements are generally considered in two-body systems, where an orbit follows Kepler's laws. Six parameters are sufficient to describe the size, shape and orientation of the orbit and the position of the body along it at a given epoch.

The Keplerian elements

  • Semi-major axis (a) — half the longest diameter of the elliptical orbit; sets the orbit's size and period.
  • Eccentricity (e) — the shape of the ellipse, from 0 (circular) to just below 1 (highly elongated).
  • Inclination (i) — the tilt of the orbital plane relative to a reference plane.
  • Longitude of the ascending node (Ω) — the angle locating where the orbit crosses the reference plane going north.
  • Argument of periapsis (ω) — the angle from the ascending node to the orbit's closest approach point.
  • True anomaly (ν) — the angle locating the body on its orbit at the epoch.

Two-line elements

For Earth satellites, orbital elements are distributed as two-line element sets (TLEs), a standard format produced by NORAD and used with the SGP4 propagation model to predict satellite positions.

Perturbations

Real orbits are perturbed by third bodies, atmospheric drag and the non-spherical shape of the central body, so elements change slowly over time; a set is valid for the epoch at which it was measured. Osculating elements are the Keplerian elements an orbit would have if perturbations ceased at that instant.
