Generic programming is a style of computer programming in which algorithms are written in terms of data types to be specified later, which are then instantiated as needed for specific types provided as parameters. The approach, pioneered in the 1970s in languages such as CLU and Ada and developed by David Musser and Alexander Stepanov, lifts algorithms from concrete examples to reusable abstractions by expressing the exact requirements a type must satisfy — in C++ called concepts — rather than demanding a particular representation.

The STL model

The most influential realisation is the C++ Standard Template Library (STL), designed by Stepanov and Meng Lee at Hewlett-Packard and adopted into standard C++ in 1994. The STL organises generic components into containers, iterators that glue them to algorithms, function objects, and adaptors. Because C++ templates are resolved at compile time, generic algorithms can achieve performance equal to hand-written type-specific code, with no run-time abstraction penalty.

Generics in other languages

Java (from version 5, 2004) and C# provide generics implemented largely by type erasure or reification respectively; Haskell and ML offer parametric polymorphism with type classes; Rust provides generics with trait bounds, resolved by monomorphisation. Dynamic languages achieve similar effects through duck typing, sacrificing static guarantees.

Advantages and limitations

Generic programming promotes code reuse and type-safe abstraction, but template-heavy code can suffer from long compile times, cryptic error messages, and code bloat when many instantiations are generated — issues addressed by explicit concepts in C++20.
