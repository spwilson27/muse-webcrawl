Template metaprogramming

Template metaprogramming (TMP) is a metaprogramming technique in which templates are used by a compiler to generate temporary source code, which is merged with the rest of the source code and then compiled. In C++, template instantiation is Turing-complete, allowing computations—such as factorials or type transformations—to be performed at compile time.

History

The power of C++ templates was noticed in the early 1990s; Erwin Unruh famously produced a program whose error messages computed prime numbers, and Todd Veldhuizen popularised TMP for high-performance numerical libraries such as Blitz++. Libraries like Boost.MPL formalised compile-time lists and algorithms.

Uses and trade-offs

TMP is used for compile-time assertions, type traits, expression templates and policy-based design, moving work from run time to compile time. Its drawbacks include long compile times, cryptic diagnostics and code that is hard to read; modern C++ features such as constexpr and concepts have absorbed many of its use cases.
