Text mode

From Wikipedia, the free encyclopedia

Text mode is a computer display mode in which content is rendered internally in terms of characters rather than individual pixels. The screen is divided into a rectangular grid of cells, each displaying a single character from a character set, typically with attributes such as foreground and background color, bold, blink, and underline.

History

Text mode dominated early computer displays because it required little video memory: a classic 80×25 screen (used by the IBM PC's MDA, CGA, and VGA adapters) needs only 4,000 bytes — two per cell, one for the character code and one for attributes. Text user interfaces built file managers, word processors, and BBS software on this foundation. Text modes survive today in firmware setup screens, boot loaders, operating-system consoles, and terminal emulators, which faithfully reproduce the grid model.

Characteristics

Because characters come from fixed fonts stored in hardware (code pages such as CP437 on the PC), text mode graphics were limited to block and box-drawing characters, giving rise to ANSI art and text-mode games. Modern Unicode-capable consoles extend the model with thousands of glyphs, but the cell-based rendering remains.
