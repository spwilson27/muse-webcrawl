Wayland (protocol)

Wayland is a computer protocol that specifies communication between a display server (called a Wayland compositor) and its clients, as well as a C library implementing it. It was designed to replace the ageing X Window System with a simpler, more secure architecture.

Design

In Wayland, the compositor is the display server: clients render into their own buffers and ask the compositor to display them, eliminating the separate X server and compositing manager round-trips of the X11 model. Input and rendering events pass directly between client and compositor, which reduces latency and removes X11's network-transparent but insecure core protocol.

Adoption

Wayland was created by Kristian Høgsberg at Red Hat in 2008. Major desktop environments — GNOME and KDE Plasma — now support Wayland sessions, and many Linux distributions ship it as the default. X11 applications run on Wayland through the XWayland compatibility layer.
