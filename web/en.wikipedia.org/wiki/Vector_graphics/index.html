Vector graphics

Vector graphics are computer images created from sequences of points connected by lines, curves and polygons, rather than from a fixed grid of pixels. Because the image is stored as mathematical descriptions of geometric shapes, it can be scaled to any size without loss of quality — the renderer simply redraws the shapes at the new resolution. Vector graphics are the standard medium for logos, icons, typography, technical illustration and computer-aided design.

Principles

A vector image consists of objects, each defined by coordinates and attributes such as stroke colour and width, fill colour, and transparency. Curved shapes are usually specified with Bézier curves, defined by anchor points and off-curve control handles — the same model used in digital typefaces. Objects are layered in a drawing order, and groups can be transformed (scaled, rotated, skewed) by transforming their coordinates.

Comparison with raster graphics

Raster (bitmap) images store a value for every pixel and are natural for photographs and complex shading; enlarging them reveals blocky pixelation. Vector files are typically far smaller for line art and flat-colour illustration, and their objects remain individually editable. Their weakness is photographic realism: rendering a photo-like image as vectors requires huge numbers of shapes. In practice, documents often mix both — a PDF page, for example, may contain vector text and embedded raster photographs.

Formats and software

The dominant open web format is SVG (Scalable Vector Graphics), an XML-based standard supported by all major browsers. Print workflows rely on EPS and PDF; proprietary working formats include Adobe Illustrator's AI. Widely used editors include Adobe Illustrator, Inkscape (free and open source), Affinity Designer, CorelDRAW and Figma. Vector displays were used in early computer graphics and oscilloscope-based games such as Asteroids before raster displays became universal.

Applications

Beyond illustration, vector data underlies geographic information systems (maps), CAD and engineering drawing, laser cutting and CNC toolpaths, plotters, and scalable icon fonts and UI assets in software design.
