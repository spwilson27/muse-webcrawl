Boundary value problem

In mathematics, in the field of differential equations, a boundary value problem is a differential equation together with a set of additional constraints, called the boundary conditions. A solution to a boundary value problem is a solution to the differential equation which also satisfies the boundary conditions.

Boundary value problem
Field: Differential equations
Contrasted with: Initial value problem
Examples: Laplace's equation, heat equation

Types of boundary conditions

A boundary condition specifying the value of the function itself is a Dirichlet condition; one specifying the value of its derivative normal to the boundary is a Neumann condition; a mixture of the two is a Robin condition. Conditions specified on only part of a boundary, or on different parts at different times, produce mixed problems.

Examples

Finding the temperature distribution in a metal rod whose ends are held at fixed temperatures is a boundary value problem for the heat equation. Laplace's equation with Dirichlet conditions models electrostatic potentials inside a region, and its solutions are harmonic functions. The vibration modes of a string fixed at both ends form a Sturm–Liouville problem, whose eigenvalues give the string's harmonics.

Applications

Boundary value problems arise throughout physics and engineering: elasticity, fluid flow, electromagnetism, and quantum mechanics (where the Schrödinger equation is solved in a box or potential well). Numerical methods include finite differences, finite elements, and the shooting method, which converts the problem into an initial value problem.
