List of HTTP header fields

HTTP header fields are a list of strings sent and received by both the client program and server on every HTTP request and response. These headers are usually invisible to the end-user and are only processed or logged by the server and client applications. This article lists the standard and common non-standard HTTP request and response header fields, with their purposes.

Request fields (selected)

HeaderPurpose
AcceptMedia types acceptable for the response
Accept-EncodingCompression algorithms the client supports (e.g., gzip, br)
Accept-LanguagePreferred natural languages for the response
AuthorizationCredentials for authenticating the user agent
CookieHTTP cookies previously sent by the server
HostDomain name and port of the requested server
If-Modified-SinceConditional request based on modification time
RefererAddress of the previous web page
User-AgentString identifying the client software

Response fields (selected)

HeaderPurpose
Cache-ControlDirectives for caching in requests and responses
Content-EncodingEncoding applied to the response body
Content-LanguageNatural language of the content
Content-LengthSize of the response body in bytes
Content-TypeMedia type of the resource
DateDate and time the message originated
ETagIdentifier for a specific version of a resource
LocationURL for redirection
ServerName of the server software
Set-CookieSends cookies from server to client
