Feature detection (computer vision)

In computer vision and image processing, feature detection includes methods for computing abstractions of image information and making local decisions about whether there is an image feature of a given type at each image point.

Types of features

Common feature types include edges, corners (interest points), blobs (regions of interest), and ridges. Detectors are often paired with descriptors that encode the local appearance for matching across images.

Algorithms

Well-known detectors and descriptors include the Harris corner detector, Shi–Tomasi, FAST, SIFT, SURF, ORB, and blob detectors based on the Laplacian of Gaussian. Feature detection underpins applications such as image stitching, object recognition, structure from motion, and visual SLAM.
