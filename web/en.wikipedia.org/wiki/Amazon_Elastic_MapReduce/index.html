Amazon EMR

Amazon EMR (formerly Amazon Elastic MapReduce)
Developer: Amazon Web Services
Type: Big data processing platform

Amazon EMR (previously called Amazon Elastic MapReduce) is a managed cluster platform offered by Amazon Web Services that simplifies running big data frameworks such as Apache Hadoop and Apache Spark to process and analyse vast amounts of data.

Features

EMR provisions clusters of Amazon EC2 instances (or serverless and Kubernetes-based deployments) with pre-installed open-source applications including Hadoop, Spark, Hive, Presto/Trino, HBase, and Flink. Data is typically read from and written to Amazon S3 using EMRFS, which decouples storage from compute so clusters can be resized or terminated when jobs finish.

Use cases

Common workloads include log analysis, data warehousing ETL, machine learning data preparation, financial analysis, and genomics. Pricing is charged per second for the EMR service in addition to underlying EC2 or other infrastructure costs.
