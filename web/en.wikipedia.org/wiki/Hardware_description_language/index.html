Hardware description language

A hardware description language (HDL) is a specialized computer language used to describe the structure and behaviour of electronic circuits, most commonly digital logic circuits. HDLs allow designers to model concurrency — many signals changing simultaneously — which distinguishes them from conventional programming languages.

Major languages

The two most widely used HDLs are VHDL and Verilog, both standardized by the IEEE. SystemVerilog extends Verilog with advanced verification features. Newer languages such as Chisel (embedded in Scala) and Bluespec aim to raise the level of abstraction.

Synthesis and simulation

An HDL description can be simulated to verify behaviour, and a synthesizable subset can be automatically translated by logic synthesis tools into a netlist of gates for implementation in an ASIC or FPGA. Timing, clocks and register behaviour are central concepts in HDL design.
