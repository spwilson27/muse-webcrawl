Baillie–PSW primality test

From Wikipedia, the free encyclopedia

[Image: Flowchart of the combined Miller–Rabin and Lucas probable-prime tests]

The Baillie–PSW primality test is a probabilistic primality test that combines a base-2 Miller–Rabin probable-prime test with a strong Lucas probable-prime test. It is named after Robert Baillie and Samuel S. Wagstaff Jr.; "PSW" refers to Carl Pomerance, John Selfridge and Wagstaff.

Description

Given an odd integer n, the test first checks small factors and perfect squares, then applies a strong Miller–Rabin test with base 2. If n passes, it then performs a strong Lucas test with parameters chosen by Selfridge's method. A composite passing both is called a Baillie–PSW pseudoprime.

Accuracy

No composite number is known to pass the full test: exhaustive computation has shown there are no Baillie–PSW pseudoprimes below 264, and Pomerance conjectured infinitely many exist, with a $620 prize once offered for an example. Because the two component tests err on essentially independent sets, the combined test is used in computer algebra systems such as Mathematica and Maple as a fast, effectively reliable primality check, though it is not a proof like the AKS test.
