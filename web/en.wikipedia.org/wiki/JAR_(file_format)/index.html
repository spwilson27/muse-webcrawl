JAR (file format)

A JAR (Java Archive) file is a package file format typically used to aggregate many Java class files and associated metadata and resources into one file for distribution of application software or libraries on the Java platform.

Format

JAR files are built on the ZIP file format and have the .jar file extension. A JAR file may contain a manifest file, META-INF/MANIFEST.MF, which specifies the main class and other metadata. Executable JARs can be run with java -jar.

Related formats

WAR and EAR files are specialised JAR formats for web applications and enterprise applications respectively; APK files for Android are also derived from JAR.
