Coreboot

coreboot
Developer: coreboot community
Initial release: 1999 (as LinuxBIOS)
License: GNU GPL v2
Platforms: x86, ARM, RISC-V, POWER

coreboot, formerly known as LinuxBIOS, is a software project aimed at replacing proprietary firmware (BIOS or UEFI) found in most computers with a lightweight firmware designed to perform only the minimum tasks necessary to load and run a modern 32-bit or 64-bit operating system. It is free and open-source software distributed under the GNU General Public License.

Design

coreboot performs hardware initialisation — configuring the CPU, memory controller and chipset — and then hands control to a "payload", which can be a bootloader such as SeaBIOS (which provides a legacy BIOS interface), TianoCore (UEFI), GRUB, or a Linux kernel stored directly in flash. Because coreboot itself does minimal work, systems can boot very quickly.

Adoption

The project began in 1999 at Los Alamos National Laboratory for Linux clusters. coreboot ships on all Google Chromebooks, and is offered by vendors of privacy- and security-focused laptops. It is also used in some servers and embedded systems. Porting coreboot to modern Intel platforms is complicated by the need for proprietary binary blobs such as the Firmware Support Package (FSP) and the Management Engine firmware.
