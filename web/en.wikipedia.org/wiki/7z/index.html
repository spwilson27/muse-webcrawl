7z is a compressed archive file format that supports several different data compression, encryption, and pre-processing algorithms. The 7z format initially appeared as implemented by the 7-Zip archiver developed by Igor Pavlov. It supports Unicode file names, very large files and archives, solid compression, and optional AES-256 encryption.

Features

The format's default compression method is LZMA (Lempel–Ziv–Markov chain algorithm) and its successor LZMA2, which generally give higher compression ratios than the DEFLATE algorithm used by ZIP. The format also supports bzip2, PPMd, and delta and BCJ filters for executable files. Header compression and header encryption mean that even the archive's directory listing can be concealed. Because the specification is available in the public LZMA SDK, many third-party tools can create and extract 7z archives.

Limitations

The 7z format does not store Unix file permissions directly (they are preserved by implementations via attributes or tar-like wrapping) and, lacking per-file recovery records, can complicate partial extraction from damaged places; its high compression also tends to be slower than simpler formats. Nevertheless it is widely used in software distribution, backups, and game modding.
