Layer 2

Layer 2 or L2 may refer to several related concepts in computer networking and telecommunications, most commonly the data link layer of the OSI model. The term is also used in blockchain technology for secondary frameworks built on top of a main chain.

Data link layer

In the seven-layer OSI model of computer networking, the data link layer is layer 2. It provides node-to-node data transfer—a link between two directly connected nodes—and handles error correction from the physical layer. It is divided into the media access control (MAC) sublayer and the logical link control (LLC) sublayer. Ethernet switches operate at layer 2, forwarding frames based on MAC addresses.

Layer 2 in blockchain

In cryptocurrency networks such as Ethereum, "layer 2" refers to scaling solutions—such as rollups, state channels, and sidechains—that process transactions off the main chain (layer 1) while inheriting its security, in order to increase throughput and reduce fees.

Other uses

The term also appears in atmospheric science, neuroscience, and geology for the second layer of various stratified systems, and in caching hierarchies (L2 cache) in computer architecture, where it denotes the second-level memory cache.
