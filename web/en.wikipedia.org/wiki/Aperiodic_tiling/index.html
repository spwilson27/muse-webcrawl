Aperiodic tiling

An aperiodic tiling is a non-periodic tiling with the additional property that it does not contain arbitrarily large periodic patches. A set of tiles is aperiodic if copies of them can form only non-periodic tilings.

An aperiodic tiling is a tiling of the plane that lacks translational symmetry: no shift maps the tiling onto itself. More strongly, a set of prototiles is called aperiodic if the tiles can cover the plane only in non-periodic ways. Aperiodic tilings first arose in the 1960s in connection with mathematical logic and the decision problem for tilings.

History

Hao Wang conjectured in 1961 that any set of tiles that tiles the plane can do so periodically. His student Robert Berger refuted this in 1964 by constructing an aperiodic set of 20,426 tiles, a number quickly reduced. In the 1970s Roger Penrose discovered elegant aperiodic sets of only two tiles, the famous Penrose tilings, which have local fivefold symmetry. In 2023 a single tile — the "hat" — was shown to tile the plane only aperiodically, solving the long-standing einstein problem.

Relation to quasicrystals

The mathematics of aperiodic tilings acquired physical significance with the discovery of quasicrystals in 1982: their atomic structure can be modelled by three-dimensional analogues of Penrose tilings, ordered but not periodic.
