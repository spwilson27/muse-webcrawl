Extract, transform, load

In computing, extract, transform, load (ETL) is a three-phase process used to prepare and move data from one or more sources into a destination system, commonly a data warehouse. It became a standard approach to data integration in the 1970s and remains central to analytics engineering.

Phases

Extract: data is read from source systems such as databases, applications, files, and streams, often copied into a staging area without disturbing operational systems. Transform: the data is cleaned, validated, deduplicated, joined, reformatted, and subjected to business rules so it conforms to the target schema and quality standards. Load: the transformed data is written into the target, as full reloads or incremental updates.

ELT and modern practice

Cloud data warehouses popularised the reverse order, extract, load, transform (ELT), in which raw data is loaded first and transformed in place with SQL-based tools. Commercial ETL tools include Informatica, Talend, and Microsoft SQL Server Integration Services; open-source and cloud services such as Airbyte, Fivetran, and Apache Airflow are widely used.

Challenges

ETL design must handle data quality, schema changes, performance at scale, error handling, and the lineage and governance of data as it moves between systems.
