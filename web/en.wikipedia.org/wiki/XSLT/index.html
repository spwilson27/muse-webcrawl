XSLT

XSLT (Extensible Stylesheet Language Transformations) is a language originally developed for transforming XML documents into other XML documents, or into other formats such as HTML for web pages, plain text or XSL Formatting Objects. It is part of the W3C's XSL family and uses XPath to navigate and select parts of the input document.

Mechanism

An XSLT stylesheet is itself an XML document containing template rules. An XSLT processor matches nodes of the source tree against patterns, instantiating templates to construct a result tree. Built-in templates recurse through the document by default. XSLT is a declarative, functional programming language and is Turing complete.

Versions

XSLT 1.0 became a W3C Recommendation in November 1999 and was widely implemented in web browsers and server frameworks. XSLT 2.0 (2007) added strong typing, grouping, multiple output documents and a much larger function library; XSLT 3.0 (2017) added streaming of large documents, packages, and maps and arrays. The principal implementations include Saxon (by Michael Kay, the editor of the 2.0 specification) and the libxslt-based processors.
