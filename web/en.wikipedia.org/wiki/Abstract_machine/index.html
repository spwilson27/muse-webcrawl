Abstract machine

An abstract machine is a theoretical model of a computer or computation device that specifies states, inputs, and transition rules without committing to a physical implementation. Abstract machines allow computer scientists to reason about computability, complexity, and program semantics. The best-known example is the Turing machine.

Formal models

Classic abstract machines include finite-state machines, pushdown automata, and Turing machines, which form the levels of the Chomsky hierarchy of formal languages. Register machines and the random-access machine model underpin the analysis of algorithms, while the lambda calculus serves as an abstract machine for functional computation, realised operationally by devices such as the SECD machine and the Krivine machine.

In programming language implementation

In compiler and interpreter design, an abstract (or virtual) machine defines the execution model for a language: the Java Virtual Machine, the Common Language Runtime, and the register-based Lua VM are engineered abstract machines specified in terms of instructions, stacks, and memory model rather than hardware. Defining semantics against an abstract machine makes programs portable and their behaviour predictable across platforms.

Philosophical use

The term is also used in philosophy — notably by Gilles Deleuze and Félix Guattari — for a diagram of functions and relations abstracted from any particular apparatus, a looser usage distinct from the technical one.
