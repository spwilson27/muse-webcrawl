Logistic regression

FieldMachine learning, statistics
TypeSupervised learning, classification

Logistic regression is a statistical method for analysing a dataset in which there are one or more independent variables that determine a binary outcome. The outcome is measured with a dichotomous variable (in which there are only two possible outcomes). In logistic regression, the dependent variable is predicted by estimating the probability that a given input point belongs to a particular category, using the logistic function (sigmoid) to map a linear combination of the input features onto the range between 0 and 1.

Introduction

The logistic model was developed and popularised by statistician David Cox in 1958. It is widely used in the social sciences, medicine, and machine learning, for example in predicting whether a patient has a disease from observed characteristics, or whether a loan applicant will default.

The model

The log-odds (logit) of the outcome is modelled as a linear combination of the predictor variables:

ln(p / (1 − p)) = β0 + β1x1 + … + βkxk

Equivalently, the probability of the outcome is:

p = 1 / (1 + e−(β0 + β1x1 + …))

Estimation

The parameters are typically estimated by maximum likelihood estimation. Unlike linear regression, there is no closed-form solution; iterative algorithms such as Newton–Raphson (iteratively reweighted least squares) are used instead.

Extensions

Multinomial logistic regression generalises the method to outcomes with more than two categories, while ordered logit models handle ordinal outcomes. Regularised versions (LASSO, ridge) add penalty terms to prevent overfitting.
