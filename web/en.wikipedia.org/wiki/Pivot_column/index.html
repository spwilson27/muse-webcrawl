Pivot column

From Wikipedia, the free encyclopedia

FieldLinear algebra
Related conceptsRow echelon form, Gaussian elimination, rank, leading entry

In linear algebra, a pivot column is a column of a matrix that, after the matrix has been reduced to row echelon form (or reduced row echelon form), contains a pivot — the first non-zero entry (the leading entry) in a non-zero row.

Definition and properties

When a matrix is transformed by Gaussian elimination, each non-zero row of the resulting echelon form has a leading entry. The columns in which those leading entries sit are the pivot columns; all other columns are free columns. The number of pivot columns equals the rank of the matrix, and the pivot columns of the original matrix form a basis for its column space.

Use in solving linear systems

For a system of linear equations written as an augmented matrix, the variables corresponding to pivot columns are called basic variables (or leading variables), while variables corresponding to free columns are free variables, which may be assigned arbitrary values as parameters. A system is consistent if and only if the augmented column is not a pivot column; if it is a pivot column, the echelon form contains a row expressing 0 = (non-zero constant), and the system has no solution. If the system is consistent, it has a unique solution exactly when every variable column is a pivot column.

Pivoting in numerical algorithms

The word "pivot" also appears in numerical linear algebra, where pivoting refers to interchanging rows (partial pivoting) or rows and columns (complete pivoting) during elimination to select a larger-magnitude entry as the pivot, improving numerical stability. In the simplex method of linear programming, the pivot column is the column chosen to enter the basis at each iteration.
