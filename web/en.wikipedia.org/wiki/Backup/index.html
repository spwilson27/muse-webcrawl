Backup

In information technology, a backup, or data backup, is a copy of computer data taken and stored elsewhere so that it may be used to restore the original after a data loss event. The verb form, referring to the process of doing so, is "back up", whereas the noun and adjective form is "backup". Backups can be used to recover data after its loss from data deletion or corruption, or to recover data from an earlier time.

Storage and media

Backup data may be stored on magnetic tape, hard disk drives, solid-state drives, optical discs, or remote cloud storage. The 3-2-1 rule is a widely cited guideline: keep at least three copies of data, on two different storage media, with one copy off-site. Rotating media schemes such as grandfather-father-son balance retention depth against media cost.

Backup types

A full backup copies all selected data. An incremental backup copies only data changed since the last backup of any type, minimizing storage and time but lengthening restore chains. A differential backup copies data changed since the last full backup. Synthetic full backups consolidate incrementals into a new full image without re-reading the source.

Backup window and live systems

Backing up a running system raises consistency issues: files may change mid-copy. Snapshot technology, database dump tools and application-aware agents address this by capturing a point-in-time view. The period during which a backup may be performed is called the backup window.

Recovery

The purpose of a backup is recovery. Key metrics include recovery point objective (RPO), the maximum tolerable data loss measured in time, and recovery time objective (RTO), the maximum tolerable downtime. Restores must be tested regularly, as an untested backup may itself be corrupt or incomplete.
