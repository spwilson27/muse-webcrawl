Hopcroft–Karp algorithm

From Wikipedia, the free encyclopedia

Phases of shortest augmenting paths in the algorithm

The Hopcroft–Karp algorithm is an algorithm in computational graph theory for finding a maximum-cardinality matching in a bipartite graph. It was published in 1973 by John Hopcroft and Richard Karp, and independently discovered by other researchers. The algorithm runs in time O(E √V) in the worst case, improving on the O(VE) bound of simpler augmenting-path methods.

Description

Like the Hungarian search algorithm for bipartite matching, Hopcroft–Karp repeatedly increases the size of a partial matching by finding augmenting paths — paths that alternate between edges outside and inside the matching, beginning and ending at free (unmatched) vertices. Its key idea is to find, in each phase, a maximal set of vertex-disjoint augmenting paths of the shortest length simultaneously. A breadth-first search builds a layered graph of edges that can appear in a shortest augmenting path, and depth-first searches then extract a maximal set of such paths. Because the shortest augmenting path length strictly increases after each phase, and there can be at most √V phases before the remaining paths are long and few, the total running time is O(E √V).

Analysis

The analysis divides the phases into two groups: after √V phases the matching is within √V augmentations of optimal, and each subsequent phase increases the matching size by at least one, so at most 2√V phases occur overall. Each phase takes linear time in the number of edges. The algorithm is closely related to Dinic's algorithm for maximum flow, and bipartite matching can also be solved by reduction to flow, but Hopcroft–Karp's specialised analysis gives the tighter bound for this problem.
