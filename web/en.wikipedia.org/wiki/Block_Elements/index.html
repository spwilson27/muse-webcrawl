Block Elements

From Wikipedia, the free encyclopedia

Block Elements is a Unicode block containing characters for use in text-based graphics, consisting of squares filled to varying fractions, half blocks, and shaded rectangles. The block spans the code point range U+2580 to U+259F and contains 32 characters.

Contents

The block includes the full block character █ (U+2588), upper and lower half blocks, left and right half blocks, blocks filled to one eighth through seven eighths vertically and horizontally, quadrant blocks, and light, medium and dark shade characters (░ ▒ ▓). These glyphs descend from the text semigraphics of early personal computers such as the Commodore PET, the IBM PC code page 437 and teletext systems.

Usage

Block elements are widely used in terminal applications for progress bars, sparklines, box-drawing interfaces and ASCII-art-style logos. Together with the neighbouring Box Drawing block they allow detailed monochrome artwork in plain text.
