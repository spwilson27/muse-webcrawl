Wine (originally an acronym for "Wine Is Not an Emulator") is a free and open-source compatibility layer that aims to allow application software and computer games developed for Microsoft Windows to run on Unix-like operating systems. Wine translates Windows API calls into POSIX calls on the fly, eliminating the performance and memory penalties of emulation.

Development

Bob Amstadt and Eric Youngdale began the project in 1993; Alexandre Julliard has led development since 1994. Wine 1.0 was released in June 2008 after 15 years of development, and annual stable releases followed, with Wine 9.0 appearing in 2024. The project maintains the AppDB database of application compatibility.

Derivatives and impact

Wine is the basis for Valve's Proton, which enables thousands of Windows games to run on Linux and the Steam Deck, as well as for the commercial CrossOver product from CodeWeavers, Wine's principal corporate sponsor. ReactOS also reuses Wine components for its Windows compatibility.
