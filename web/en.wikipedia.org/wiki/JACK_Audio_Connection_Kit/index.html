JACK Audio Connection Kit

JACK Audio Connection Kit (often shortened to JACK; recursive acronym for "JACK Audio Connection Kit") is a professional sound server daemon and API providing low-latency, real-time interconnection between audio and MIDI applications.

Overview

JACK was designed for professional audio work on Linux and other Unix-like systems, allowing many applications to connect to an audio device and share audio with each other in a patchbay-like model. It supports scheduling priorities for real-time performance.

Implementations

The original implementation is JACK1; JACK2 is a multithreaded C++ rewrite. PipeWire can act as a JACK server for compatible applications.
