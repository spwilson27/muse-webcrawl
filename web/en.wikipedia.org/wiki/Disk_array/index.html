Disk array

A disk array is a disk storage system which contains multiple disk drives. It is differentiated from a disk enclosure, in that an array has cache memory and advanced functionality, like RAID, deduplication, encryption and virtualization.

Components of a typical disk array include:

  • Disk array controllers, which manage the drives and present them to host computers as logical units;
  • Array cache, usually DRAM, which buffers reads and writes;
  • Disk enclosures holding the physical drives;
  • Redundant power supplies and cooling.

History

Disk arrays emerged in the late 1980s and 1990s as enterprises sought higher capacity, performance, and reliability than single large disks could provide. The concept of RAID (redundant array of independent disks), described in a 1988 paper by David Patterson, Garth Gibson, and Randy Katz at the University of California, Berkeley, became a defining feature. Vendors such as EMC (with its Symmetrix line), IBM, Hewlett-Packard, Hitachi, and NetApp built large businesses around enterprise disk arrays, which became the standard storage platform in data centers.

Modern arrays

Contemporary arrays increasingly use solid-state drives (SSDs) instead of, or alongside, spinning hard disk drives; arrays built entirely from flash memory are marketed as all-flash arrays. Modern systems provide features such as thin provisioning, snapshots, replication, automated tiering, compression, and inline deduplication, and they connect to hosts over Fibre Channel, iSCSI, or NVMe-oF protocols in storage area networks (SANs) or as network-attached storage (NAS).
