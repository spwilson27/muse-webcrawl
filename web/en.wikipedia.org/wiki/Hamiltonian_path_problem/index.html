Hamiltonian path problem

The Hamiltonian path problem is a topic in the fields of graph theory and theoretical computer science. It consists of determining whether a Hamiltonian path (a path in an undirected or directed graph that visits each vertex exactly once) or a Hamiltonian cycle exists in a given graph.

Both problems are NP-complete. The Hamiltonian cycle problem is a special case of the travelling salesman problem, obtained by setting the distance between two cities to one if they are adjacent and two otherwise, and verifying that the total distance travelled is equal to n.

NP-completeness

The problems of finding a Hamiltonian path and a Hamiltonian cycle in a graph are both among Karp's 21 NP-complete problems. They remain NP-complete even for planar, bipartite, or cubic graphs, though they can be solved in polynomial time for certain restricted graph classes.

Algorithms

There are n! different sequences of vertices that might be Hamiltonian paths in an n-vertex graph, so a brute force search algorithm that tests all possible sequences would be very slow. Dynamic programming approaches, such as the Held–Karp algorithm, solve the problem in O(n2 2n) time.
