Barabási–Albert model

The Barabási–Albert (BA) model is an algorithm for generating random scale-free networks using a preferential attachment mechanism. A scale-free network is a network whose degree distribution follows a power law, at least asymptotically. The BA model, proposed by Albert-László Barabási and Réka Albert in 1999, was one of the first models to explain how such distributions arise naturally in real networks such as the World Wide Web, citation networks and some social networks.

The algorithm

The network begins with a small initial set of m0 connected nodes. At each time step a new node is added with m edges (m ≤ m0) linking it to existing nodes. The probability that a new edge connects to an existing node i is proportional to that node's current degree ki — "the rich get richer". Formally, Π(ki) = ki / Σj kj.

Properties

The resulting network has a degree distribution P(k) ~ k−3, independent of m; its average path length grows slowly, roughly as ln N / ln ln N; and its clustering coefficient decays with network size, a known mismatch with many real networks that motivated later models such as the Holme–Kim model with triad formation. The BA model lacks degree correlations in the large-network limit.

History

Preferential attachment had been anticipated by Yule (1925), Simon (1955) and Price (1965/1976, for citation networks). Barabási and Albert's contribution was to connect the mechanism with the power-law degree distributions measured in real-world networks and to emphasise network growth as an essential ingredient.
