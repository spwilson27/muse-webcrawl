Oklab color space

The Oklab color space is a color space for representing colors, designed by Björn Ottosson in 2020. It is intended to be perceptually uniform, meaning that a change of the same amount in a color value should produce a change of about the same visual importance. Oklab has been included in web standards: CSS Color Level 4 defines the oklab() and oklch() notations, the latter being the cylindrical (polar) form of Oklab using chroma and hue in place of the Cartesian a and b components.

Coordinates

Oklab has three components: L (perceptual lightness), a (roughly green–red) and b (roughly blue–yellow). The a and b axes are unbounded, but in practice are usually in the range of about −0.4 to +0.4. The cylindrical form, Oklch, uses L, chroma C and hue angle h.

Conversion

Conversion from CIE XYZ to Oklab proceeds via an intermediate LMS cone-response space: XYZ values are transformed with a matrix to LMS, a cube root is applied to each component, and a second matrix produces the L, a, b values. Colors converted from sRGB first require linearisation of the sRGB values. Compared with CIELAB, Oklab offers improved hue linearity, so that, for example, blue colors do not shift toward purple when their lightness is changed.

Adoption

Oklab and Oklch are supported by all major web browsers and are increasingly used in design tools and color-gradient generation because interpolating colors in Oklab avoids the muddy midpoints that can occur when interpolating in sRGB.
