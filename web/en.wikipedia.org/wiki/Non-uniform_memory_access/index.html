Non-uniform memory access

Non-uniform memory access (NUMA) is a computer memory design used in multiprocessing systems, where the memory access time depends on the memory location relative to the processor. Under NUMA, a processor can access its own local memory faster than non-local memory shared with other processors.

Architecture

A NUMA machine is divided into nodes, each with processors and local memory, connected by a high-speed interconnect (historically systems such as SGI Origin; today AMD EPYC and Intel Xeon servers expose multiple NUMA nodes per socket or chiplet). Cache-coherent NUMA (ccNUMA) keeps memory coherent across nodes.

Software implications

Operating systems and applications achieve best performance by keeping threads and their data on the same node ("NUMA locality"). Tools such as numactl and NUMA-aware schedulers and databases implement first-touch memory placement and node binding; ignoring NUMA can cost a significant share of memory bandwidth and latency performance.
