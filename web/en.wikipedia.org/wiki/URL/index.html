URL

A Uniform Resource Locator (URL), colloquially known as a web address, is a reference to a web resource that specifies its location on a computer network and a mechanism for retrieving it. A URL is a type of Uniform Resource Identifier (URI), although the two terms are often used interchangeably. URLs occur most commonly to reference web pages (HTTP/HTTPS), but are also used for file transfer (FTP), email (mailto), database access (JDBC), and many other applications.

History

The URL was defined by Tim Berners-Lee at CERN in 1994 in RFC 1738, building on the addressing scheme he had created for the World Wide Web in 1991. The generic URI syntax was later standardised in RFC 3986 (2005), and the web-platform definition maintained by the WHATWG URL Standard governs how browsers parse URLs.

Syntax

A URL consists of several components: a scheme (e.g., https), an optional authority containing user information, a host (domain name or IP address) and port, a path, an optional query string of key–value parameters introduced by ?, and an optional fragment identifier introduced by # that locates a section within the resource. For example, in https://www.example.com:443/path/page?name=value#section, the scheme is https, the host is www.example.com, and the fragment is section. Characters outside a permitted set are percent-encoded, such as %20 for a space.

Related concepts

Every URL is a URI, but not every URI is a URL: a URN, for example, names a resource (e.g., an ISBN) without indicating how to locate it. Standardisation of URLs underpins hyperlinks, bookmarks, QR codes and the entire navigable structure of the Web.
