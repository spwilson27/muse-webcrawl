Path (computing)

Placeholder image

A path (or filepath, file path, pathname, or similar) is a string of characters used to uniquely identify a location in a directory structure. It is composed by following the directory tree hierarchy, in which components are separated by a delimiting character, and represents a file or directory.

Absolute and relative paths

An absolute path begins at the root of the file system, for example /home/user/documents on Unix-like systems or C:\Users\user\Documents on Windows. A relative path is interpreted from the current working directory. The special components . and .. refer to the current directory and its parent.

Conventions

Unix-like systems use the forward slash / as separator; classic Mac OS used the colon, and Microsoft Windows accepts the backslash \ (and also generally the forward slash). Related concepts include the URL, which adapts path syntax for the web, and the PATH environment variable used to locate executables. See also filename and directory.
