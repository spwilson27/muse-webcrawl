Superposition theorem

The superposition theorem is a method of analysing linear electrical circuits containing multiple independent sources. It states that the voltage across, or current through, any element in a linear network is the algebraic sum of the voltages or currents produced by each independent source acting alone, with all other independent sources turned off.

Procedure

To apply the theorem:

  1. Consider one independent source at a time. Replace every other independent voltage source with a short circuit and every other independent current source with an open circuit.
  2. Dependent sources, if present, are left intact in every sub-circuit.
  3. Calculate the contribution of the active source to the quantity of interest using ordinary circuit techniques such as Ohm's law, Kirchhoff's laws, and series–parallel reduction.
  4. Repeat for each independent source and sum the contributions algebraically, taking account of sign and reference direction.

Limitations

The theorem applies only to linear circuits, in which elements obey proportional relationships, and only to voltages and currents. It cannot be applied directly to power, because power is a quadratic (non-linear) function of voltage and current: the power delivered with all sources active is generally not the sum of the powers computed for each source individually.

Relation to other methods

Superposition is one of several standard analysis tools alongside nodal analysis, mesh analysis, and the Thévenin and Norton equivalent circuits. It is particularly instructive because it demonstrates the practical meaning of linearity, and it underlies frequency-domain techniques in which a signal is decomposed into sinusoidal components that are analysed separately and recombined.
