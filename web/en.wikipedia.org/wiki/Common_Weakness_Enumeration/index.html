Common Weakness Enumeration

CWE provides a common language for describing software and hardware security weaknesses.

The Common Weakness Enumeration (CWE) is a category system for hardware and software weaknesses and vulnerabilities. It is maintained by the MITRE Corporation and supported by the US Department of Homeland Security's Cybersecurity and Infrastructure Security Agency. The goal of CWE is to create specific guidance for defining each weakness in an understandable manner for use by the community.

Structure

Each weakness is assigned an identifier, such as CWE-79 for cross-site scripting (XSS) and CWE-89 for SQL injection. Weaknesses are organised in a hierarchy of pillars, classes, base weaknesses and variants, and are related to the Common Vulnerabilities and Exposures (CVE) system: a CVE entry describes a specific instance of a vulnerability in a product, while a CWE describes the type of flaw that made it possible.

CWE Top 25

The CWE Top 25 Most Dangerous Software Weaknesses list ranks weaknesses by prevalence and severity in observed CVE data, using the Common Vulnerability Scoring System (CVSS). It is published periodically to guide developers and security teams towards the most consequential classes of defects.

Uses

CWE is used by static analysis tools, security assessment standards, and secure development guidance, providing a shared vocabulary for identifying, mitigating and preventing weakness types throughout the software development life cycle.
