Standard ML

Standard ML (SML) is a general-purpose, modular, functional programming language with compile-time type checking and type inference. It is known for its rigorous formal definition and for innovations including a powerful module system, parametric polymorphism, pattern matching and a formal treatment of exceptions. Standard ML grew out of the ML language designed by Robin Milner and colleagues in the 1970s as the meta-language of the LCF theorem prover at the University of Edinburgh.

Features

Standard ML combines a functional core language — with first-class functions, immutable data, algebraic datatypes and exhaustive pattern matching — with references and exceptions for imperative programming. Every expression has a type inferred by the compiler using the Hindley–Milner algorithm, extended with equality types; well-typed programs enjoy the guarantee that they cannot produce run-time type errors ("well-typed programs cannot go wrong").

The modules language — structures, signatures and functors — supports large-scale programming in a way unique among mainstream languages: a functor is effectively a function from structures to structures, parameterised at compile time. The language was formally defined in The Definition of Standard ML (Milner, Tofte, Harper, 1990; revised edition with MacQueen, 1997), one of the most complete formal definitions ever produced for a practical language, together with a commentary volume explaining it.

Implementations

Major implementations include Standard ML of New Jersey (SML/NJ), MLton (a whole-programme optimising compiler), Moscow ML, Poly/ML (noted for its use in the Isabelle proof assistant), and MLKit. A community effort known as Successor ML (MLton and SML/NJ) experiments with compatible extensions. Standard ML has been widely used in programming-language research, compiler construction, automated theorem proving and university teaching, and it strongly influenced the design of OCaml and F#, which descend from its dialect Caml.

Example

The factorial function with pattern matching:

fun fact 0 = 1 | fact n = n * fact (n - 1)
