React (also known as React.js or ReactJS) is a free and open-source front-end JavaScript library for building user interfaces based on components. It is maintained by Meta and a community of individual developers and companies. React is used to build single-page applications and mobile applications (via React Native).

History

React was created by Jordan Walke, a software engineer at Facebook, and was first deployed on Facebook's News Feed in 2011 and on Instagram in 2012. It was open-sourced at JSConf US in May 2013. React Native, enabling native Android and iOS development with React, followed in 2015.

Features

React uses a declarative programming style: developers describe the UI for each state, and React updates and renders the right components when data changes. Key features include the virtual DOM for efficient rendering, JSX (a syntax extension combining JavaScript and HTML-like markup), one-way data flow, and Hooks (introduced in React 16.8) for using state in function components. More recent versions added concurrent rendering and server components.

Adoption

React is one of the most widely used front-end libraries in the world, employed by many large websites and applications, and it consistently ranks among the most popular technologies in developer surveys.
