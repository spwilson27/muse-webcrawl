Bloom filter

Type: Probabilistic data structure
Invented by: Burton Howard Bloom (1970)
Time complexity: O(k) insertion and query

A Bloom filter is a space-efficient probabilistic data structure, conceived by Burton Howard Bloom in 1970, that is used to test whether an element is a member of a set. False positives are possible, but false negatives are not.

Algorithm

An empty Bloom filter is a bit array of m bits, all set to 0, together with k independent hash functions mapping each element to k bit positions. Inserting an element sets all its k bits to 1; querying checks whether all of an element's bits are 1—if any is 0, the element is definitely absent.

Applications

Bloom filters are used to avoid expensive lookups, for example in database systems checking whether a key exists on disk, in web browsers detecting malicious URLs, and in spell checkers. Their chief limitation is that elements ordinarily cannot be deleted without a counting variant.
