Taxon

[Image: Taxa are nested groups within a classification hierarchy]

In biology, a taxon (plural taxa) is a group of one or more populations of organisms that taxonomists judge to form a unit. A taxon is usually assigned a scientific name and a rank within a hierarchical classification — for example, the species Homo sapiens, the genus Homo, the family Hominidae and the order Primates are all taxa.

Definition and use

The term was proposed in the 1920s–40s (from Greek taxis, "arrangement") and formalised in the international codes of nomenclature. A taxon need not correspond exactly to a clade, but modern phylogenetic taxonomy holds that named taxa should be monophyletic — consisting of an ancestor and all of its descendants. Groups once recognised but now considered polyphyletic or paraphyletic, such as the old "Pachydermata", have been abandoned or redefined.

Naming

Taxa are circumscribed and named under rules such as the International Code of Zoological Nomenclature and the International Code of Nomenclature for algae, fungi, and plants. Each name is anchored to a type — a type specimen for a species, a type species for a genus — which fixes the application of the name regardless of how the group's boundaries are redrawn. Estimates of the total number of taxa ever formally described run into the millions.
