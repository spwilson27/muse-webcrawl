Generalized extreme value distribution

In probability theory and statistics, the generalized extreme value (GEV) distribution is a family of continuous probability distributions developed within extreme value theory to combine the Gumbel, Fréchet, and Weibull families otherwise known as type I, II and III extreme value distributions. By the extreme value theorem, the GEV distribution is the only possible limit distribution of properly normalized maxima of a sequence of independent and identically distributed random variables.

Specification

The GEV distribution has three parameters: a location parameter μ, a scale parameter σ > 0, and a shape parameter ξ, which governs the tail behaviour. Its cumulative distribution function is

F(x; μ, σ, ξ) = exp{ −[1 + ξ(x − μ)/σ]−1/ξ }

for values of x where 1 + ξ(x − μ)/σ > 0. The case ξ > 0 corresponds to the Fréchet (type II) family with a heavy upper tail; ξ < 0 corresponds to the Weibull (type III) family with a bounded upper tail; and the limit ξ → 0 gives the Gumbel (type I) family.

Applications

The GEV distribution is widely used in hydrology and climatology to model extreme events such as annual maximum rainfall, river discharge, and wind speeds, and in finance and insurance to model extreme losses. It underlies the "block maxima" approach to extreme value analysis, in which data are divided into blocks (such as years) and the maximum in each block is modelled.
