Computer keyboard

From Wikipedia, the free encyclopedia


A typical full-size computer keyboard with QWERTY layout

A computer keyboard is a peripheral input device modeled after the typewriter keyboard which uses an arrangement of buttons or keys to act as mechanical levers or electronic switches. Following the decline of punch cards and paper tape, interaction via teleprinter-style keyboards became the main input method for computers.

Keyboard keys (buttons) typically have a set of characters engraved or printed on them, and each press of a key typically corresponds to a single written symbol. However, producing some symbols may require pressing and holding several keys simultaneously or in sequence. While most keys produce characters (letters, numbers or symbols), other keys (such as the escape key) can prompt the computer to execute system commands.

History

The keyboard descends from typewriter and teleprinter technology. In the 1970s and early 1980s, keyboards were built into the computer housing itself, as in the Commodore 64 and Apple II. The IBM PC and its successors popularized the detachable keyboard, and the IBM Model M of 1985 became a landmark design noted for its buckling-spring key switches.

Types

Keyboards vary by layout (such as QWERTY, AZERTY, and Dvorak), by switch technology (membrane, scissor-switch, and mechanical), and by connection (PS/2, USB, and Bluetooth wireless). Ergonomic keyboards are shaped to reduce strain, while compact and laptop keyboards omit the numeric keypad found on full-size models.

Key layout

A standard keyboard includes alphanumeric keys, punctuation keys, function keys (F1–F12), a numeric keypad, cursor (arrow) keys, and modifier keys such as Shift, Control, Alt, and the Windows or Command key. Keyboards typically contain 84 to 110 keys depending on the model and regional layout.
