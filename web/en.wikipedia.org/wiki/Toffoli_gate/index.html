Toffoli gate

In logic circuits, the Toffoli gate (also called the CCNOT gate) is a universal reversible logic gate invented by Tommaso Toffoli. It has three input and three output bits: the first two bits pass through unchanged, and the third bit is flipped if and only if both of the first two bits are 1.

Definition

The gate maps (a, b, c) to (a, b, c XOR (a AND b)). Because it is its own inverse, applying it twice restores the original state, making the computation reversible. Its truth table swaps only the final two rows, exchanging 110 and 111.

Universality

The Toffoli gate is universal for reversible classical computation: any reversible function can be built from Toffoli gates alone. With the third input fixed at 0 it acts as an AND gate on its output; with inputs fixed appropriately it can act as NAND, NOT, and fanout, so it can simulate any Boolean circuit with ancilla bits.

Quantum computing

In quantum computing the Toffoli gate is a controlled-controlled-NOT acting on three qubits. Together with the Hadamard gate it forms a universal set for quantum computation. Implementing a fault-tolerant Toffoli is a significant resource cost in quantum algorithms, and much research concerns reducing its "T-count" and T-depth.
