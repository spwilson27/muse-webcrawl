Topological space

In mathematics, a topological space is a set endowed with a structure, called a topology, which allows defining continuous deformation of subspaces, and, more generally, all kinds of continuity.

Definition

A topology on a set X is a collection τ of subsets of X, called open sets, such that: the empty set and X itself belong to τ; any union of members of τ belongs to τ; and the intersection of any finite number of members of τ belongs to τ. The pair (X, τ) is a topological space.

Examples

The real line with intervals as open sets forms the standard topology underlying calculus. Every metric space induces a topology via open balls. The discrete topology makes every subset open, while the trivial topology has only the empty set and the whole space.

Concepts

Within this framework mathematicians define continuity, convergence, compactness, connectedness, and separation axioms such as Hausdorffness (T2), which generalize intuitions from Euclidean geometry to far more abstract settings.
