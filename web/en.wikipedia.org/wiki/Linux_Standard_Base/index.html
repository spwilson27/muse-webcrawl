Linux Standard Base

Linux Standard Base
Developer: Linux Foundation
Type: Software standard
Latest release: LSB 5.0 (2015)

The Linux Standard Base (LSB) was a standardization initiative based on the POSIX specification and other open standards, extending them to the GNU/Linux operating system. The goal of the LSB was to develop and promote a set of open standards that would increase compatibility among Linux distributions and enable software applications to run on any compliant system, even in binary form. In addition, the LSB helped coordinate efforts to recruit software vendors to port and write products for Linux.

History

The LSB project was announced in 1998 and the first specification, LSB 1.0, was released in 2001 under the Free Standards Group, which later merged into the Linux Foundation. Successive versions added support for additional architectures (including IA-32, IA-64, PowerPC and z/Architecture), desktop libraries such as GTK+ and Qt, and printing and trial-directory standards.

Contents

The specification defined the binary interface of system libraries, the layout defined by the Filesystem Hierarchy Standard (FHS), the RPM package format for installable application packages, and a set of required commands and utilities. LSB compliance could be certified, and distributions such as Debian, Red Hat Enterprise Linux, SUSE Linux Enterprise and Ubuntu held certifications at various times.

Criticism and decline

The LSB was criticized for mandating the RPM format, which Debian-based distributions did not natively use, and for lagging behind actual distribution practice. After LSB 5.0 in 2015, development stalled; the emphasis in the Linux ecosystem shifted toward containers and distribution-specific packaging, and the LSB working group was eventually wound down.
