ChromeOS (formerly styled Chrome OS) is a Linux-based operating system developed by Google, designed around the Chrome web browser as its principal user interface. Announced in July 2009 and first shipped on retail Chromebooks in June 2011, ChromeOS was conceived primarily for working with web applications, with most user data stored in the cloud.

Design

ChromeOS emphasises speed, simplicity, and security. It uses verified boot, sandboxing, and automatic updates; user data is encrypted and largely synchronised to a Google account, so a lost device loses little data. The interface centres on a browser window with a taskbar-like "shelf" and an app launcher. Early versions supported only web apps, but the system later gained the ability to run Android applications from the Google Play Store (from 2016) and Linux applications in a virtual machine container ("Crostini", from 2018), broadening its capabilities considerably.

Hardware and market

ChromeOS runs on Chromebooks (laptops), Chromeboxes (desktops), and Chromebase all-in-ones, made by manufacturers including Acer, ASUS, HP, Lenovo, and Samsung. Low prices, long battery life, and easy central management made Chromebooks especially popular in education, where they came to dominate US K–12 device purchases, and during periods of remote learning demand surged.

Open source basis

ChromeOS is built on the open-source ChromiumOS project. Google maintains the commercial build with proprietary components such as the Chrome browser branding, media codecs, and Google service integration.
