Metal (API)

Metal is a low-level, low-overhead hardware-accelerated 3D graphic and compute shader API developed by Apple. Debuting in iOS 8 (2014), Metal combines functions similar to OpenGL and OpenCL into a single interface optimised for Apple's own GPUs across iOS, macOS, tvOS, and visionOS.

Features

Metal gives applications near-direct access to the GPU, reducing CPU overhead associated with traditional driver models. It supports compute shaders for general-purpose GPU computing, which underpins Apple's machine-learning and image-processing frameworks. Shaders are written in the Metal Shading Language, based on C++14.

Subsequent releases added features such as Metal 2 (2017) with support for virtual reality and machine learning, and Metal 3 (2022) with hardware-accelerated ray tracing, mesh shaders, and MetalFX upscaling. With the introduction of Apple silicon Macs, Metal became the sole graphics API for the platform, OpenGL and OpenCL having been deprecated.

Adoption

Metal is required for modern games and professional applications on Apple platforms, and cross-platform engines such as Unity and Unreal Engine target it. The API has influenced and parallels other low-overhead APIs such as Vulkan and DirectX 12.
