In computing, NaN (/næn/), standing for Not a Number, is a particular value of a numeric data type (often a floating-point number) used to represent an undefined or unrepresentable value, especially in floating-point arithmetic. Systematic use of NaNs was introduced by the IEEE 754 floating-point standard in 1985, along with the representation of other non-finite quantities such as infinities.

Floating point

NaNs are produced when an arithmetic operation yields a result that has no meaningful numeric value. In the IEEE 754 standard, a NaN is encoded with the exponent field filled with ones (like infinity) and a non-zero significand (unlike infinity). Two separate kinds are distinguished: quiet NaNs (qNaN), which propagate through most operations without raising an exception, and signaling NaNs (sNaN), which may raise an invalid-operation exception when consumed.

Types of NaN

A quiet NaN propagates through arithmetic, allowing a computation to continue and produce a NaN result, which is useful for deferred error handling. A signaling NaN is intended to trap when it participates in an operation, making it useful for detecting use of uninitialised memory or for filling variables with recognisable filler values. In practice, signaling NaNs are rarely used because many systems convert them to quiet NaNs during operations.

Operations producing NaN

Common operations that yield NaN include:

  • Division of zero by zero (0/0) and other indeterminate forms such as ∞ − ∞ and 0 × ∞
  • The square root of a negative number
  • Logarithm of a negative number
  • Operations in which a NaN is an operand (most return NaN)
  • Real operations delivering complex results, such as arcsine of a value greater than 1

Comparisons and testing

A peculiar property of NaN, specified by IEEE 754, is that it is unordered with respect to every value, including itself: all comparisons x < NaN, x > NaN, x == NaN, and even NaN == NaN evaluate to false. Consequently, the standard way to test whether a value is NaN is to check whether x != x, or to use a library function such as isnan() in C or Number.isNaN() in JavaScript. This behaviour is frequently a source of bugs, since NaNs can silently propagate through sorting, search, and data pipelines.

Encoding

In IEEE 754 binary formats, NaNs have all-ones exponents and a non-zero fraction field; the most significant fraction bit distinguishes quiet (1) from signaling (0) NaNs. The remaining fraction bits may carry a "payload" that diagnostic software can use to identify the origin of the NaN. A decimal NaN representation also exists in the 2008 revision of the standard.
