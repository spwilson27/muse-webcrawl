Covering set

Image: Venn-style diagram of a covering of a set by subsets (placeholder)

In mathematics, a covering set (or simply a cover) of a set X is a family of sets whose union includes X as a subset. More precisely, if C = {Uα : α ∈ A} is an indexed family of sets, then C is a covering of X if

X ⊆ ⋃α∈A Uα.

The members of the covering need not be subsets of X themselves, although in most applications — in particular in topology — they usually are. A subfamily of a cover that is itself a cover is called a subcover. If every member of a cover is an open set, the cover is an open cover.

Covering in topology

Covers are a fundamental tool in topology. A topological space X is said to be compact if every open cover of X has a finite subcover — that is, a finite subcollection that still covers X. Related properties include the Lindelöf property (every open cover has a countable subcover) and paracompactness, which concerns refinements of open covers by locally finite open covers. A refinement of a cover is another cover each of whose members is contained in some member of the original cover.

Other uses

The notion appears throughout mathematics: in set theory, in the theory of uniform spaces (where coverings are used to define uniformities), and in combinatorics, where covering problems ask for the smallest family of sets with covering properties — related to set cover and covering designs. In the theory of covering spaces, a different (though historically related) use of the word "covering" applies to continuous maps with local homeomorphism properties.
