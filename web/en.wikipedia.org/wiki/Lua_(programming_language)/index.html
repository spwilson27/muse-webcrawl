Lua is a lightweight, high-level, multi-paradigm programming language designed primarily for embedded use in applications. It is cross-platform, since the interpreter is written in ANSI C, and it has a relatively simple C API. The name lua means "moon" in Portuguese.

History

Lua was created in 1993 by Roberto Ierusalimschy, Luiz Henrique de Figueiredo, and Waldemar Celes, members of the Computer Graphics Technology Group (Tecgraf) at the Pontifical Catholic University of Rio de Janeiro, in Brazil. Import restrictions on computer technology in Brazil at the time motivated the team to build the tools they needed locally.

Features

Lua combines simple procedural syntax with powerful data description constructs based on associative arrays (tables) and extensible semantics. Tables are the sole compound data structure and can be used to implement arrays, records, sets, and objects. Lua supports metatables and metamethods, first-class functions, closures, coroutines for cooperative multitasking, and automatic memory management with incremental garbage collection.

-- Hello world in Lua
print("Hello, World!")

-- Factorial using recursion
function factorial(n)
  if n == 0 then
    return 1
  else
    return n * factorial(n - 1)
  end
end

Applications

Lua is widely used as a scripting language in video games, including World of Warcraft addons and the Roblox platform (which uses a dialect called Luau). It is also used in Adobe Lightroom, the Wikipedia software (for template scripting via Scribunto), Redis, nginx (via OpenResty), and many embedded systems.
