Run-time type information

Run-time type information or run-time type identification (RTTI) is a feature of some programming languages (such as C++, Object Pascal, and Ada) that exposes information about an object's data type at runtime. While available in many languages via reflection or similar mechanisms, the term RTTI is commonly used for the C++ implementation.

In C++

In C++, RTTI is provided through the typeid operator, which returns an object of type std::type_info, and the dynamic_cast operator, which safely converts pointers and references between classes in an inheritance hierarchy. RTTI is only available for polymorphic classes — those with at least one virtual function — because instances of such classes carry a pointer to a virtual function table that also points to type information.

Costs and alternatives

RTTI can add overhead in code size and, in some implementations, run time, so many projects disable it (for example with the GNU compiler option -fno-rtti). Critics argue that heavy use of RTTI may indicate a design that should instead use polymorphism, the visitor pattern, or pattern matching. Nevertheless, it remains useful for debugging, serialization fallback, and interoperability code.
