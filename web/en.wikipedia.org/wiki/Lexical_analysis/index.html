Lexical analysis

From Wikipedia, the free encyclopedia

Lexical analysis, also called scanning or tokenization, is the process of converting a sequence of characters into a sequence of tokens — strings with an identified meaning — for subsequent processing. It is the first phase of a compiler or interpreter. The program that performs lexical analysis is called a lexer, tokenizer or scanner.

Tokens

A token is a structured string: a token name (an abstract symbol) together with an optional concrete value, the lexeme, which is the actual character sequence matched in the input. Typical token classes in a programming language include identifiers, keywords, operators, numeric and string literals, separators and whitespace. For example, the source text if (x == 42) might be tokenised as IF, LPAREN, IDENTIFIER("x"), EQUALS, NUMBER(42), RPAREN.

Implementation

Token patterns are conventionally specified with regular expressions, and a lexer is equivalent in power to a finite automaton. Lexers are therefore often generated automatically from such specifications by tools such as Lex and Flex, or written by hand in recursive-descent style. The lexer typically discards whitespace and comments, tracks line numbers for error reporting, and interacts with the symbol table. The resulting token stream is passed to the parser, which builds a parse tree according to the language's grammar.

Lexical analysis in linguistics

In linguistics and natural language processing, tokenization similarly refers to segmenting text into words, punctuation and other meaningful units — a preparatory step for lexical and syntactic analysis of natural language.
