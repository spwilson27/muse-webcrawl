Probability density function

From Wikipedia, the free encyclopedia

In probability theory, a probability density function (PDF) is a function whose integral over any interval gives the probability that a continuous random variable falls in that interval. Unlike a probability mass function, the value of a PDF at a single point is not itself a probability and may exceed 1; only areas under the curve represent probabilities.

Definition

A random variable X has density f if f is non-negative and

P(a ≤ X ≤ b) = ∫ab f(x) dx,

with total area ∫ f(x) dx = 1 over the whole real line. The cumulative distribution function is F(x) = P(X ≤ x) = ∫−∞x f(t) dt, and where F is differentiable, f = F′.

Examples

The standard normal density is f(x) = (1/√(2π)) e−x2/2. The uniform density on [a, b] is constant 1/(b−a). The exponential density with rate λ is f(x) = λe−λx for x ≥ 0.

Properties and uses

Expected values are computed as E[g(X)] = ∫ g(x) f(x) dx. Densities transform under smooth changes of variable with a Jacobian correction. Joint densities describe several variables together, marginal densities are obtained by integrating out the others, and conditional densities are ratios of joint to marginal densities. Kernel density estimation uses sample data to construct an estimated PDF.
