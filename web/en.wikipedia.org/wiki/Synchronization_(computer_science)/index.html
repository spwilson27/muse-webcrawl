Synchronization (computer science)

In computer science, synchronization refers to coordinating the execution of multiple threads or processes so that shared resources are accessed safely and operations happen in a correct order. Without synchronization, concurrent accesses to shared data can produce race conditions, inconsistent states, and corrupted results.

Mechanisms

Common synchronization primitives include mutexes (mutual exclusion locks), which allow only one thread to hold the lock at a time; semaphores, counting constructs introduced by Edsger W. Dijkstra; monitors, which combine locks with condition variables; and barriers, at which threads wait until all have arrived. Atomic operations and memory barriers provide lower-level tools, while message passing avoids shared memory altogether.

Problems

Synchronization must balance correctness against performance: coarse locking wastes parallelism, while fine-grained locking risks deadlock (threads each waiting forever for the other), livelock, and starvation. Priority inversion, in which a high-priority thread waits on a low-priority one, motivated priority inheritance protocols.

Process synchronization

At the operating-system level, synchronization coordinates separate processes, for example ensuring events occur in a fixed sequence or that producers and consumers of a shared buffer stay coordinated — the classic producer–consumer problem.
