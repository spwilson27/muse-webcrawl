Dependent type

In computer science and logic, a dependent type is a type whose definition depends on a value. For example, the type "list of n integers" depends on the number n. Dependently typed programming allows extremely precise types to be written — a function that returns a list with exactly as many elements as its input can be typed as taking a value of type Vect n a to Vect n a — so that many errors are caught by the type checker, and programs can encode mathematical proofs.

History and theory

Dependent types arise in intuitionistic type theory, developed by Per Martin-Löf in the 1970s, and are related to the Curry–Howard correspondence between proofs and programs: a dependent function type (a Π-type) generalises both the ordinary function type and the universal quantifier of logic.

Languages and proof assistants

Languages with full dependent types include the proof assistants Coq, Agda and Lean, and the programming languages Idris and F*. Mainstream languages such as Haskell and Scala support increasingly expressive approximations. Deciding type equality in dependently typed systems may require evaluating terms, and type checking can become undecidable in sufficiently permissive systems.
