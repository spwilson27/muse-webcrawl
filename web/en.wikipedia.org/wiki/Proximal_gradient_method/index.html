Proximal gradient method

Type: First-order convex optimization algorithm
Key operator: Proximal (prox) operator
Variants: ISTA, FISTA (accelerated)
Applications: Lasso, compressed sensing, image processing

Proximal gradient methods are a family of iterative algorithms for solving optimization problems of the form minimize f(x) + g(x), where f is smooth and convex and g is convex but possibly nonsmooth. Each iteration takes a gradient step on f followed by application of the proximal operator of g, which acts as a generalized projection.

Algorithms

The basic method is also called iterative shrinkage-thresholding (ISTA) when g is the ℓ1 norm, in which case the proximal step is soft-thresholding — the core of sparse regression methods like the Lasso. The accelerated variant FISTA, which adds a momentum term in the style of Nesterov, improves the convergence rate from O(1/k) to O(1/k²).

Applications

Proximal gradient methods underpin much of modern large-scale machine learning and signal processing: compressed sensing, total-variation denoising, matrix completion, and sparse logistic regression. Related schemes include Douglas–Rachford splitting and ADMM.
