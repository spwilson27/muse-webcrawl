Central processing unit

From Wikipedia, the free encyclopedia
[Image: A modern CPU package with its pin grid and printed markings]

A central processing unit (CPU), also called a main processor or just processor, is the electronic circuitry that executes the instructions of a computer program: performing arithmetic, logic, control, and input/output operations specified by the instructions in the program.

A CPU consists of an arithmetic logic unit (ALU) performing operations, a control unit directing execution (fetch–decode–execute), registers for working data, and cache memory. Modern CPUs integrate billions of transistors on a single chip, with multiple cores executing in parallel.

History

Early computers (ENIAC, 1945) had fixed or plugboard-programmed processors; the stored-program concept (von Neumann architecture, 1945) made the CPU a general-purpose instruction engine. The first commercial microprocessor, Intel's 4004 (1971), put a CPU on one chip with 2,300 transistors; today's devices integrate tens of billions, following the scaling trend summarised by Moore's law.

Architectures are defined by instruction sets: x86 dominates desktops and servers, ARM dominates mobile and is growing in laptops and data centres, and open RISC-V is emerging. Techniques — pipelining, superscalar execution, branch prediction, out-of-order execution, speculative execution — squeeze performance from each clock cycle, at the cost of side-channel vulnerabilities like Spectre (2018).

Performance

Clock speed, instructions per cycle, core count, and cache size jointly determine real performance; process-node shrinks have slowed, shifting emphasis to specialised accelerators (GPUs, NPUs) alongside the general-purpose CPU.
