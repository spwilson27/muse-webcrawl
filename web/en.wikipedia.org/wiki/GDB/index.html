The GNU Debugger (GDB) is a portable debugger that runs on many Unix-like systems and works for many programming languages, including C, C++, Fortran, Ada, Go and Rust. Originally written by Richard Stallman in 1986 as part of the GNU system, GDB is free software released under the GNU General Public License.

Features

GDB offers the facilities typical of a symbolic debugger: starting a program under controlled conditions, stopping execution on specified conditions such as breakpoints, examining variables and memory when the program stops, stepping through code line by line, and inspecting the call stack with a backtrace. It also supports watchpoints, conditional breakpoints, reverse debugging on some targets, and debugging of programs running on remote or embedded systems via the GDB remote serial protocol.

Usage

GDB is normally driven from a text command-line interface. A typical session loads an executable compiled with debugging symbols (for example with the -g flag of GCC), sets breakpoints, and runs the program:

(gdb) break main
(gdb) run
(gdb) backtrace
(gdb) print variable
(gdb) continue

Graphical front ends and integrated development environments frequently use GDB as their debugging back end through its machine-oriented MI interface.

History

Stallman modelled GDB partly on the DBX debugger distributed with BSD Unix. The program was rewritten and extended by many contributors over the following decades, with support for dozens of processor architectures and for languages beyond C. It remains an actively maintained component of the GNU toolchain alongside GCC and the GNU Binutils.
