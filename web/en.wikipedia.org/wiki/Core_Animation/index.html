Core Animation

Developer: Apple Inc.

Initial release: 2007 (Mac OS X Leopard)

Operating system: macOS, iOS, iPadOS, watchOS, tvOS

Type: Graphics animation framework

Framework: QuartzCore

Core Animation is a graphics compositing framework used by macOS, iOS, and their derived operating systems. It was first shown publicly by Steve Jobs during Macworld 2007 as a feature of Mac OS X 10.5 Leopard, though its origins lie in Layer Kit software developed at Apple. Core Animation allows developers to create animated user interfaces while producing much of the code needed to do so automatically, delegating compositing and animation to the GPU-accelerated render server.

Overview

In Core Animation, most of what appears on screen is backed by a layer (an instance of CALayer), which manages bitmap content and geometry much like a sprite. Layers are arranged in a tree, and the system composites them in a separate process, so an application can change layer properties — position, bounds, opacity, transform, shadow — and have them animate smoothly without redrawing. Many property changes are implicitly animated: altering an animatable property automatically interpolates from its old to its new value over a default duration. Developers can also attach explicit animation objects (CAAnimation and subclasses such as CABasicAnimation and CAKeyframeAnimation) to control timing, keyframes, and timing functions (easing curves).

Use in Apple software

Core Animation underpins many signature effects of Apple's interfaces, including the iPhone's springy scrolling and transitions, macOS features such as Mission Control, Spaces, Time Machine, and the Dock, and the layered interfaces of the Apple TV and Apple Watch. On iOS, every UIView is backed by a CALayer, so UIKit animations are built on top of it. Because compositing happens out of process and on the GPU, interfaces can maintain 60 (or 120) frames per second while the main thread remains free for application logic.

Related technologies

Core Animation sits within the Quartz technologies alongside Core Graphics (Quartz 2D) and Core Image. In the rendering stack it communicates with the render server (in the WindowServer process) over an interprocess pipeline, and layer contents are ultimately drawn by Metal or OpenGL in earlier systems. SceneKit and SpriteKit are higher-level Apple frameworks whose presentation likewise relies on layers.
