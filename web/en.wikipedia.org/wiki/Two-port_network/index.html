Two-port network

A two-port network is an electrical network or circuit element with two pairs of terminals, an input port and an output port, used to model components such as amplifiers, filters, transmission lines and transformers as black boxes characterised entirely by their terminal voltages and currents.

Parameter sets

The behaviour of a linear two-port can be described by several equivalent sets of four parameters relating the port voltages V1, V2 and currents I1, I2:

  • Impedance (z) parameters — express voltages in terms of currents; measured under open-circuit conditions.
  • Admittance (y) parameters — express currents in terms of voltages; measured under short-circuit conditions.
  • Hybrid (h) parameters — widely used for transistor models, mixing an input impedance and output admittance.
  • Transmission (ABCD) parameters — relate input quantities to output quantities, convenient for cascaded networks, whose ABCD matrices multiply.
  • Scattering (s) parameters — based on travelling waves, standard in radio-frequency and microwave engineering.

Properties

A network is reciprocal if it contains no independent sources or non-reciprocal devices, imposing symmetry conditions such as z12 = z21. Networks may be interconnected in series, parallel, cascade or hybrid combinations, and parameter conversion tables allow translation between representations.

Applications

Two-port analysis underpins the design of amplifiers, attenuators, matching networks and filters, and the modelling of power system components such as transformers and lines.
