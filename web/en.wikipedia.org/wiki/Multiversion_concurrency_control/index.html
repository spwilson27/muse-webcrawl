Multiversion concurrency control

Multiversion concurrency control (MVCC) is a method commonly used by database management systems to provide concurrent access to data. Instead of overwriting a data item when it changes, the system creates a new version, so that readers can access a consistent snapshot of the database without being blocked by writers.

Implementation

Each transaction is associated with a timestamp or transaction identifier. When a transaction reads an item, it sees the most recent version committed before it started. Writes create new versions rather than modifying data in place, and old versions are removed by a garbage-collection or "vacuum" process once no active transaction can see them.

Use

MVCC is used by many widely used databases, including PostgreSQL, Oracle, MySQL's InnoDB engine and CouchDB. A key advantage is that readers and writers rarely block each other; a drawback is the storage overhead of keeping multiple versions and the need to clean them up.
