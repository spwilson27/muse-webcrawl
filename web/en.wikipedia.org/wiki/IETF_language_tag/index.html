IETF language tag

Structure of a language tag: language, script, region and variant subtags

An IETF language tag is an abbreviated language code used to identify human languages in computer systems. The tags are standardised by the Internet Engineering Task Force in the Best Current Practice document BCP 47, currently defined by RFC 5646 (which replaced RFC 4646) together with RFC 4647 on matching language ranges. IETF language tags are used in many protocols and formats, including HTTP, HTML, XML, and PNG, to specify the language of content and to drive language negotiation.

Structure

A language tag is composed of one or more subtags separated by hyphens, each taken from registries maintained by IANA. The core subtags are: a primary language subtag (from ISO 639, e.g. en for English, de for German, zh for Chinese); an optional script subtag (from ISO 15924, e.g. Cyrl for Cyrillic, Latn for Latin); an optional region subtag (from ISO 3166-1 or UN M.49, e.g. GB, US, 419 for Latin America); and optional variant, extension and private use subtags. Examples include en-GB (British English), zh-Hans-CN (Chinese as written in mainland China using simplified characters), sr-Latn (Serbian in Latin script) and de-CH-1901 (German as used in Switzerland with the 1901 orthography variant).

Registry and maintenance

Valid subtags are listed in the IANA Language Subtag Registry, which incorporates ISO codes and registers additional variants. Changes are overseen by a Language Subtag Reviewer appointed by the IESG, with discussion on a public mailing list. RFC 5646 also introduced extended language subtags and grandfathered tags inherited from earlier practice under RFC 1766 and RFC 3066.

Use

Language tags underpin content negotiation (for example the HTTP Accept-Language header), the HTML lang attribute, locale selection in operating systems and libraries such as ICU, and internationalisation frameworks across the web platform.
