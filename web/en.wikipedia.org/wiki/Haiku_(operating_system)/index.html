Haiku is a free and open-source operating system that is binary-compatible with BeOS, the multimedia-oriented system developed by Be Inc. in the 1990s. Development began in 2001 as OpenBeOS, after Palm acquired Be's assets and discontinued BeOS; the project was renamed Haiku in 2004, in reference to the haiku error messages displayed by BeOS applications such as NetPositive. Haiku aims specifically at personal computing, combining a clean, responsive desktop with the pervasive multithreading and object-oriented API of its inspiration.

Design

Haiku is written mainly in C++ and provides an API modelled directly on the BeOS API (libbe). Its hybrid kernel, derived from the NewOS kernel by former Be engineer Travis Geiselbrecht, supports symmetric multiprocessing and is modular. Distinctive features include the Deskbar taskbar, yellow tabbed windows that can be stacked and tiled, live queries of the BFS filesystem's extended attributes, and replicants — live application components embedded in the desktop or other programs. The interface kit, storage kit, media kit and other "kits" mirror the BeOS architecture so that legacy BeOS binaries can run unmodified on 32-bit x86 builds.

History and releases

After a long development period the project issued alpha releases beginning in 2009 (R1/Alpha 1) and moved to beta with R1/Beta 1 in September 2018, the first release to include a full package management system, the WebPositive browser (based on WebKit) and substantial modern hardware support. Subsequent betas added NVMe, USB 3 and improved HiDPI support, a port of the Qt framework and other applications such as LibreOffice, and work toward the 64-bit (x86_64) build and eventual R1 release. The non-profit Haiku, Inc. holds the project's trademarks and funds development, supplemented by community donations and Google Summer of Code participation.
