Device independent file format

The device independent file format (DVI) is the output file format of the TeX typesetting program, designed by David R. Fuchs and implemented by Donald Knuth in 1982. Unlike the TeX markup files used to generate them, DVI files are not intended to be human-readable; they consist of binary data describing the visual layout of a document in a manner not reliant on any specific image format, display hardware, or printer.

A DVI file records the position of each character or rule on every page, together with font definitions. Driver programs then convert DVI output into the format required by a particular device, such as PostScript or PDF, or display it on screen with previewers such as xdvi. The format's device independence was central to TeX's portability across the varied computing hardware of the early 1980s.

Later variants include the extended XDV format used by XeTeX.
