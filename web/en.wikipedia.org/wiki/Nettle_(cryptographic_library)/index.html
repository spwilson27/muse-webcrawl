Nettle (cryptographic library)

Nettle is a cryptographic library designed to provide a low-level, toolkit-independent set of cryptographic routines for other applications. It is part of the GNU Project and is best known as the cryptographic backend of GnuTLS. Nettle emphasises a simple C interface in which each algorithm is exposed through small, object-oriented structures.

Design

Unlike large cryptographic frameworks, Nettle deliberately implements only primitives: hash functions, block and stream ciphers, message authentication codes, public-key algorithms, and random number generation. It makes no decisions about protocols, key storage, or certificates, leaving those to the application. This separation allows programs to combine Nettle's routines freely and helped it serve as a foundation for GnuTLS from version 3 onwards.

Algorithms

Supported algorithms include AES, Camellia, ChaCha, and the legacy DES and RC4; hash functions MD5, RIPEMD-160, SHA-1, the SHA-2 family, SHA-3, and GOST; public-key algorithms RSA, DSA, ECDSA, EdDSA (including Ed25519), and GOST DSA; and modes of operation such as CBC, CTR, GCM, and CCM. Performance-critical routines are hand-optimised in assembly for common architectures including x86-64, ARM, and PowerPC.

History

Nettle was started by Swedish programmer Niels Möller, originally in connection with the LSH implementation of the Secure Shell protocol. It was adopted as a GNU package and gradually accumulated algorithms, with major releases adding elliptic-curve cryptography (2.7/3.0), ChaCha-Poly1305, and SHA-3. The related "hogweed" library contains the public-key routines that depend on the GMP multiple-precision arithmetic library.

Usage

Beyond GnuTLS, Nettle is used by a variety of free-software projects requiring lightweight cryptography, and it is distributed with all major Linux distributions.
