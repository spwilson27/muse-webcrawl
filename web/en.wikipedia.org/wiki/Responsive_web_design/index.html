Responsive web design

FieldWeb design
Coined byEthan Marcotte (2010)
TechniquesFluid grids, flexible images, media queries

One design, many screen sizes

Responsive web design (RWD) is an approach to web design that makes web pages render well on a variety of devices and screen sizes, from desktop monitors to mobile phones. The term was coined by Ethan Marcotte in a 2010 article for A List Apart.

Core techniques

Responsive design combines three ingredients: fluid grids, in which page elements are sized in relative units such as percentages rather than fixed pixels; flexible images, which scale within their containers; and CSS media queries, which apply different styles depending on the characteristics of the device, most commonly its viewport width.

Adoption

As mobile browsing overtook desktop use in the 2010s, responsive design largely replaced separate "mobile sites". Search engines such as Google adopted mobile-friendliness as a ranking signal, further accelerating its uptake.
