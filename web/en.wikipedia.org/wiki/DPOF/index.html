DPOF

DPOF (Digital Print Order Format) is a format for storing information on the memory card of a digital camera that specifies which images are to be printed, and in what quantities and formats. The format was created in 1998 by a group of companies including Canon, Kodak, Fujifilm and Matsushita (Panasonic).

Operation

When a user marks images for printing on a camera, the camera writes a small text-based "order file" (AUTPRINT.MRK, in a MISC folder on the card) rather than modifying the image files themselves. The order file records the print quantity for each selected image and options such as whether to imprint the date, image rotation, and index prints. Photo printing kiosks, home photo printers, online photo finishers and directly connected PictBridge printers can read the file and produce the requested prints automatically. DPOF version 1.10 (2000) added functions such as specifying paper size, prints with text and slide-show settings.

Status

With the decline of consumer photo printing and the rise of smartphones, DPOF support has become less common, but the format remains embedded in many cameras and printers as a legacy standard.
