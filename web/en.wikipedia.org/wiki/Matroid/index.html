In combinatorics, a matroid is a structure that abstracts and generalizes the notion of linear independence in vector spaces. A matroid consists of a finite set together with a collection of subsets called independent sets, required to satisfy three axioms: the empty set is independent; every subset of an independent set is independent; and if one independent set is larger than another, an element of the larger set can be added to the smaller one while preserving independence (the augmentation property).

Definitions

There are many equivalent ways to define a matroid — via independent sets, bases (maximal independent sets), circuits (minimal dependent sets), rank functions, closure operators, or hyperplanes. All bases of a matroid have the same size, called the rank. The rank function assigns to each subset the size of its largest independent subset and is submodular.

Examples

  • Vectorial (linear) matroids: independent sets are linearly independent sets of vectors in a vector space.
  • Graphic matroids: independent sets are the forests (acyclic edge sets) of a graph; circuits are cycles.
  • Uniform matroids: every subset of size at most k is independent.
  • Partition matroids: the ground set is partitioned and independence limits how many elements may be taken from each part.
  • Transversal matroids: independent sets are partial transversals of a family of sets.

History

Matroids were introduced by Hassler Whitney in 1935 in his paper "On the abstract properties of linear dependence", which sought a common framework for linear algebra and graph theory. The subject grew through the work of Garrett Birkhoff, Saunders Mac Lane, and later William Tutte, who developed deep connections with graph theory. Matroid theory now underpins results in combinatorial optimization — notably that the greedy algorithm optimally solves linear optimization over a matroid, and that systems optimized by greedy algorithms are exactly matroids.

Applications

Matroids appear in network flows, matching theory, coding theory, and algorithm design. Related structures such as greedoids and matroid intersections support algorithms for scheduling, spanning trees, and transversal problems.
