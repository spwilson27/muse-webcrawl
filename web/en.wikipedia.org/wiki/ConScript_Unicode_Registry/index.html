ConScript Unicode Registry

The ConScript Unicode Registry (CSUR) is a volunteer project founded in 1997 by John Cowan and Michael Everson to coordinate the assignment of code points in the Private Use Areas of Unicode for constructed scripts (conscripts) and other scripts not eligible for official encoding.

Purpose

Unicode reserves Private Use Areas for private agreements, which normally creates a risk that different users will assign the same code points to different characters. The CSUR provides a common, public registry so that fonts and software supporting fictional and constructed writing systems can interoperate. Registered scripts are assigned blocks within the Private Use Areas, accompanied by code charts and character names modelled on official Unicode practice.

Registered scripts

Scripts registered under the CSUR include Tengwar and Cirth (from the works of J. R. R. Tolkien), Klingon pIqaD, and various other constructed and minor scripts. When a script registered in the CSUR is later officially encoded in Unicode — as happened with some proposals — the registry notes the change.

Under-ConScript Unicode Registry

A related effort, the Under-ConScript Unicode Registry (UCSUR), continued and extended the work for additional scripts and proposals.
