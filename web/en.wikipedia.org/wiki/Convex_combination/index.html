Convex combination

In convex geometry, a convex combination is a linear combination of points (which can be vectors, scalars, or more generally points in an affine space) where all coefficients are non-negative and sum to 1. Explicitly, given finitely many points x1, …, xn, a convex combination is a point of the form α1x1 + … + αnxn where the real numbers αi satisfy αi ≥ 0 and α1 + … + αn = 1.

Properties

A set is convex if and only if it contains all convex combinations of its points. The convex hull of a set is the set of all convex combinations of points in the set. By Carathéodory's theorem, any point in the convex hull of a set in n-dimensional space can be expressed as a convex combination of at most n + 1 points of the set.

Examples

With two points, a convex combination traces out the line segment between them. The expected value of a random variable is a continuous analogue of a convex combination, and probability distributions themselves form a convex set under mixing.
