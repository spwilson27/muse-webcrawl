Tietze extension theorem

In topology, the Tietze extension theorem (also known as the Tietze–Urysohn–Brouwer extension theorem) states that continuous functions on a closed subset of a normal topological space can be extended to the whole space. It is named for Heinrich Tietze, who proved it for metric spaces, and Pavel Urysohn, who extended it to normal spaces.

Statement

If X is a normal topological space and A is a closed subset of X, then any continuous function from A to the real numbers (with the standard topology) can be extended to a continuous function defined on all of X. Moreover, if the original function is bounded, the extension can be chosen to have the same bound. The theorem likewise holds for functions valued in an interval, a disk, or more generally the same proof works for extensions into spaces such as Hilbert space in finite or separable cases, though for arbitrary Banach-space-valued functions additional results (such as Dugundji's extension theorem) are used.

Significance

Along with Urysohn's lemma, the Tietze extension theorem characterises normal spaces: a space is normal if and only if every continuous real-valued function on a closed subset extends continuously to the whole space. The theorem is a fundamental tool in algebraic topology — for instance in proving that certain embedding and extension problems have solutions — and extensions of scalar functions underpin results about absolute retracts and the theory of dimension.
