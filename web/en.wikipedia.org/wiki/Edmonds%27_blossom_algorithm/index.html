Edmonds' blossom algorithm

Edmonds' blossom algorithm, developed by Jack Edmonds in 1965, is an algorithm in graph theory for constructing maximum matchings on graphs. Unlike bipartite matching, the problem is more difficult for general graphs because of odd-length cycles, which Edmonds showed how to handle by contracting them into single vertices.

Description

The algorithm works by searching for augmenting paths. When it encounters an odd cycle (a "blossom"), it contracts the cycle into a single vertex and continues the search; any matching found in the contracted graph can be lifted back to the original graph. The running time of the original algorithm is polynomial, O(|V|²|E|).

Significance

The paper describing the algorithm, "Paths, Trees, and Flowers", was a landmark in combinatorial optimisation and helped establish the theory of polynomial-time computation, with Edmonds proposing efficient computation as equivalent to polynomial running time.
