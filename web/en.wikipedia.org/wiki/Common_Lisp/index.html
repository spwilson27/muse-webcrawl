Common Lisp (CL) is a dialect of the Lisp programming language, published in the ANSI standard document ANSI INCITS 226-1994. Developed to standardise the divergent Lisp dialects of the 1970s and early 1980s, Common Lisp is a general-purpose, multi-paradigm programming language supporting an incremental, interactive development style.

Features

Common Lisp is notable for its powerful macro system, which lets programmers extend the language's syntax by manipulating code as data (homoiconicity); the Common Lisp Object System (CLOS), an object-oriented extension supporting multiple inheritance, multiple dispatch, and a metaobject protocol; a condition system with restarts for interactive error recovery; first-class functions and closures; arbitrary-precision arithmetic, ratios, and complex numbers; and a read–eval–print loop (REPL) supporting image-based development. Unlike many Lisp dialects, Common Lisp is a Lisp-2: functions and variables occupy separate namespaces.

(defun factorial (n)
  (if (zerop n)
      1
      (* n (factorial (1- n)))))

History

Work began in 1981 as an effort, initially led by DARPA and the Lisp community, to unify Maclisp, Interlisp, NIL, Lisp Machine Lisp, Spice Lisp, and other dialects. The first edition of Guy L. Steele Jr.'s book Common Lisp the Language (1984) served as the de facto specification; the ANSI X3J13 committee produced the formal standard in 1994, making Common Lisp the first object-oriented language with an ANSI standard (via CLOS). The language played a central role in artificial intelligence research and was used commercially in systems such as ITA Software's airline reservation system.

Influence and use

Common Lisp influenced later Lisps such as Emacs Lisp (which borrowed features) and languages including Racket, Julia (dispatch design), and Dylan. Active implementations include the native-code compiler SBCL, and the language retains a dedicated community with the Quicklisp library manager providing access to thousands of libraries.
