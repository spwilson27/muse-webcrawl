CLU is a programming language created at the Massachusetts Institute of Technology (MIT) by Barbara Liskov and her students between 1974 and 1975. While it did not achieve widespread use, it introduced many features that are now widely used in mainstream languages, and it is regarded as a major step in the development of object-oriented programming.

CLU programs are organized around clusters — abstract data types with their operations.

Key features

The name CLU derives from cluster, the language's central construct: a cluster bundles a data representation together with the operations that manipulate it, providing data abstraction with strong encapsulation. CLU also pioneered or popularized several other ideas:

  • Exception handling with explicit signalling in procedure interfaces, which influenced later languages.
  • Iterators — procedures that yield values one at a time to a calling loop, an idea later seen in Sather, Python generators, and C#.
  • Parameterized types (generics), with explicit "where" clauses constraining type parameters.
  • Multiple return values and multiple assignment.

Design and influence

CLU was notable for its disciplined approach: it had no goto statement, assignment was by sharing (references to heap objects), and it included automatic garbage collection. Although CLU itself remained mainly a research language, its ideas flowed into Ada, Java, Python, Ruby, and Lua — Lua's designers have cited CLU's multiple assignment and multiple return values as influences.

Barbara Liskov received the 2008 Turing Award in part for the work on data abstraction embodied in CLU.
