Smoothness

In mathematical analysis, the smoothness of a function is a property measured by the number of continuous derivatives it has over some domain. A function is said to be of class Ck if it has derivatives up to order k and those derivatives are continuous. A function with derivatives of all orders is called smooth, or of class C∞.

Classes of differentiability

  • C0: the function is continuous, but not necessarily differentiable (for example, the absolute value function at 0).
  • C1: the function is differentiable and its first derivative is continuous.
  • Ck: derivatives up to order k exist and are continuous.
  • C∞: derivatives of all orders exist; such functions are called smooth.
  • Cω: the function is analytic — smooth and equal to its Taylor series near every point. Every analytic function is smooth, but not every smooth function is analytic.

Examples

The function f(x) = x2 is smooth, because derivatives of all orders exist and are continuous everywhere. By contrast, f(x) = |x| is continuous but not differentiable at x = 0, so it is C0 but not C1. A classic non-analytic smooth function is f(x) = e−1/x for x > 0 and f(x) = 0 for x ≤ 0: all of its derivatives at 0 are zero, so its Taylor series there is identically zero and does not equal the function. Functions built from it are used to construct bump functions and partitions of unity.

Smooth manifolds and maps

The notion extends to maps between smooth manifolds: a map is smooth (C∞) if, when expressed in local coordinates (charts), it is a smooth function between open subsets of Euclidean space. Smoothness classes Ck similarly define Ck manifolds and maps, which are central to differential topology and differential geometry.

Other uses

"Smoothness" is also used informally for curves and surfaces without sharp corners, in approximation theory (smoothness of a function controls how well it can be approximated), and in the study of partial differential equations, where solutions gain smoothness under elliptic and parabolic equations (regularity theory). In algebraic geometry, smoothness has a separate technical meaning for morphisms of schemes, generalising the notion of a non-singular variety.
