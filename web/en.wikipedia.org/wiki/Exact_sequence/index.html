Exact sequence

From Wikipedia, the free encyclopedia

An exact sequence is a sequence of mathematical objects, usually groups, rings, modules or vector spaces, connected by morphisms (maps), such that the image of one morphism equals the kernel of the next. Exact sequences are a fundamental organising tool of homological algebra, because they compress information about injectivity, surjectivity and quotients into a single diagram.

Definition

Given objects A1, A2, …, An and maps fi : Ai → Ai+1, the sequence A1 → A2 → … → An is exact at Ai if the image of fi−1 equals the kernel of fi. The sequence is exact if it is exact at every interior object. A necessary consequence is that consecutive maps compose to zero.

Short exact sequences

The most important case is the short exact sequence

0 → A —f→ B —g→ C → 0

Exactness here says that f is injective, g is surjective, and the image of f is the kernel of g, so that C is isomorphic to the quotient B / f(A). One says that B is an extension of C by A. Such a sequence splits if there is a map back from C to B making B isomorphic to the direct sum A ⊕ C. A classic example is 0 → ℤ —×2→ ℤ → ℤ/2ℤ → 0, which does not split, in contrast to sequences of vector spaces, which always do.

Long exact sequences

Constructions in homology and cohomology naturally produce long exact sequences: the long exact sequence of a fibration in homotopy groups, the Mayer–Vietoris sequence in homology, and the sequences arising from the snake lemma and derived functors. Chain complexes that fail to be exact have their failure measured by homology groups, turning exactness into a quantitative tool.
