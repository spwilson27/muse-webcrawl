Algorithmic information theory

From Wikipedia, the free encyclopedia

Algorithmic information theory (AIT) is a branch of theoretical computer science that mainly concerns itself with the relationship between computation and information of computably generated objects, such as strings or data structures. Developed principally by Ray Solomonoff, Andrey Kolmogorov and Gregory Chaitin in the 1960s, its central concept is Kolmogorov complexity: the length of the shortest computer program that outputs a given object.

Main ideas

An object is considered "random" in this framework if it is incompressible — its shortest description is about as long as the object itself. Because the halting problem is undecidable, Kolmogorov complexity is not a computable function, yet it yields deep results, including a formal definition of randomness for finite strings and infinite sequences, and incompleteness theorems related to Gödel's: Chaitin showed that there is a constant beyond which a formal system cannot prove that any specific string has higher complexity.

Related notions

AIT also includes algorithmic probability (Solomonoff's universal prior, foundational to theories of machine learning and induction), the study of prefix-free complexity and self-delimiting programs, and applications of incompressibility arguments in combinatorics and computational complexity theory.
