Lossless compression

Lossless compression is a class of data compression algorithms that allows the original data to be perfectly reconstructed from the compressed data. It contrasts with lossy compression, which permits reconstruction only of an approximation. Lossless methods are essential where any loss is unacceptable — text, executables, financial and medical records — and are used in formats such as ZIP, gzip, PNG and FLAC.

Principles

Lossless compression exploits statistical redundancy. Entropy-encoding methods such as Huffman coding and arithmetic coding assign shorter codes to more frequent symbols, approaching the Shannon entropy limit. Dictionary methods of the LZ77 and LZ78 families (Lempel–Ziv) replace repeated sequences with references to earlier occurrences; DEFLATE, used in gzip and PNG, combines LZ77 with Huffman coding. Other techniques include run-length encoding, the Burrows–Wheeler transform (used in bzip2), prediction by partial matching, and context mixing (PAQ family). By the counting argument, no lossless algorithm can shrink every possible file; compression works because real data is not random.

Applications

General-purpose archivers include ZIP, 7z, and zstd. Lossless formats serve specialised media: PNG and GIF for images (GIF uses LZW), FLAC and ALAC for audio, and lossless modes in TIFF and JPEG 2000. File systems and network protocols also apply transparent lossless compression, and Unix tools such as gzip and xz are staples of system administration.

Benchmarks and limits

Compression ratio and speed trade off against each other; benchmarks such as the Canterbury Corpus and the Hutter Prize (which rewards compression of a 1 GB text corpus as a proxy for prediction) measure progress. Modern neural-network-based compressors have pushed ratios further at high computational cost.
