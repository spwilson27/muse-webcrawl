Texture atlas

From Wikipedia, the free encyclopedia

[Image: A texture atlas packing many sprites and surfaces into a single image]

In realtime computer graphics, a texture atlas (also called a sprite sheet in 2D contexts) is an image containing a collection of smaller images, usually packed together to reduce overall size and allow faster rendering. Atlases reduce the number of texture-binding operations a GPU must perform, since many objects can share a single texture with different UV coordinates.

Usage

Texture atlases are widely used in video games for character sprites, user-interface elements, terrain tiles, and the block and item textures of voxel games such as Minecraft. Game engines and tools such as TexturePacker automatically pack images and emit metadata (often JSON or XML) describing each sub-image's position and size.

Considerations

Packing textures can cause bleeding between adjacent images when mipmapping shrinks the atlas, so padding or extruded borders are commonly added. Very large atlases can also waste memory when only a fraction of the images is needed, which has led to alternatives such as texture arrays and bindless textures.
