Imitation learning

Imitation learning is a branch of machine learning in which an agent learns to perform a task by observing demonstrations from an expert, rather than by trial-and-error reward signals as in reinforcement learning. It is also known as learning from demonstration, apprenticeship learning and programming by demonstration.

Approaches

In behavioural cloning, the agent is trained by supervised learning to map observed states to the expert's actions. Its main weakness is distribution shift: small errors carry the agent into states the expert never visited. Interactive methods such as DAgger ask the expert to label states visited by the learner. Inverse reinforcement learning instead infers the reward function the expert appears to optimise, and adversarial methods such as GAIL train the policy against a discriminator that distinguishes learner from expert behaviour.

Applications

Applications include robot manipulation and locomotion, autonomous driving, game playing and natural-language tasks.
