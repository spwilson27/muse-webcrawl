Linear function

The term linear function refers to two distinct but related notions. In calculus and analytic geometry, a linear function is a function whose graph is a straight line, that is, a polynomial function of degree zero or one: f(x) = mx + b, where m is the slope and b the y-intercept. In linear algebra and functional analysis, a linear function (or linear map) is a function that preserves addition and scalar multiplication, and necessarily passes through the origin.

Slope and intercept

For the affine form f(x) = mx + b, the slope m measures the rate of change of the output per unit change in the input, and b is the value of the function when x = 0. Linear functions are the simplest non-constant functions and are widely used to model proportional and near-proportional relationships in science, economics, and statistics, where linear regression fits such a function to observed data.
