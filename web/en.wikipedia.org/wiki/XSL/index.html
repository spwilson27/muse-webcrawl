XSL

In computing, the term Extensible Stylesheet Language (XSL) is used to refer to a family of languages used to transform and render XML documents. Historically, the W3C XSL Working Group produced a draft specification under the name "XSL", which eventually split into three parts:

  1. XSLT (XSL Transformations): an XML language for transforming XML documents.
  2. XPath (XML Path Language): a non-XML language used by XSLT and other technologies to identify particular parts of an XML document.
  3. XSL-FO (XSL Formatting Objects): an XML language for specifying the visual formatting of an XML document.

History

Work on XSL began in the late 1990s at the World Wide Web Consortium (W3C), drawing on earlier stylesheet proposals for SGML such as DSSSL. The intention was to bring the powerful transformation and formatting capabilities of those systems to XML on the web. As the work progressed, it became clear that the transformation component had uses far beyond styling, and XSLT was separated into its own recommendation, reaching W3C Recommendation status in November 1999 alongside XPath 1.0.

XSL-FO

XSL Formatting Objects describes page layout in detail — page masters, blocks, tables, lists, and inline formatting — and is typically used to produce PDF output from XML sources via a formatter such as Apache FOP. XSL-FO became a W3C Recommendation in October 2001.

Relationship to CSS

XSL and Cascading Style Sheets (CSS) are complementary: CSS is generally simpler and aimed at styling documents for screen display, while XSLT can restructure documents entirely, and XSL-FO targets precise paginated output.
