DOS

From Wikipedia, the free encyclopedia

DOS (Disk Operating System) is a family of disk-based operating systems for x86-based personal computers. The DOS family of operating systems primarily consists of Microsoft's MS-DOS and a rebranded version under the name IBM PC DOS, which were introduced in 1981 and 1981 respectively, along with other systems later that followed a similar architecture. DOS systems generally ran on IBM PC compatible machines and were characterised by a command-line interface with commands such as DIR, COPY and DEL, a single-tasking architecture, and direct access to the underlying hardware.

History

The lineage began with 86-DOS (originally "Quick and Dirty Operating System", QDOS), written by Tim Paterson at Seattle Computer Products in 1980 for the Intel 8086 processor. Microsoft licensed and then purchased 86-DOS, adapting it as MS-DOS for the IBM Personal Computer, released in August 1981 as PC DOS 1.0. Successive versions added subdirectories, hard disk support, and networking; MS-DOS 6.22 (1994) was the last standalone retail version, although DOS technology underpinned Windows 95, 98 and Me. Competing compatible systems included DR-DOS from Digital Research and, later, the open-source FreeDOS project, which continues to be used for embedded systems, firmware updates and retrocomputing.

Architecture and interface

A classic DOS system consists of a kernel (IO.SYS and MSDOS.SYS on MS-DOS), a command interpreter (COMMAND.COM), and a set of external utility programs. It uses the FAT file system, 8.3 filenames, drive letters, and the conventional memory model of the 8086 with a 640 KB user memory limit — constraints that third-party memory managers and DOS extenders later worked around. Programmers accessed services through software interrupt INT 21h and could also program the hardware directly, which made DOS popular for games.

Legacy

DOS was the dominant personal-computer operating system from the early 1980s until the mid-1990s, when graphical Windows versions took over. Its conventions — drive letters, backslash path separators, and many command names — persist in modern Windows. Emulators such as DOSBox keep its enormous software library runnable today.
