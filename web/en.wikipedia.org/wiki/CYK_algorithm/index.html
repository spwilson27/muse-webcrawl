CYK algorithm

The Cocke–Younger–Kasami algorithm (alternatively called CYK, or CKY) is a parsing algorithm for context-free grammars published by Itiroo Sakai in 1961. The algorithm is named after some of its rediscoverers: John Cocke, Daniel Younger, Tadao Kasami, and Jacob T. Schwartz. It employs bottom-up parsing and dynamic programming.

Description

The standard version of CYK operates on context-free grammars given in Chomsky normal form (CNF), in which every production has the form A → BC or A → a. For an input string of length n, the algorithm fills a triangular table P[i, j] recording the set of nonterminals that can derive the substring spanning positions i through j. The base cells are filled from terminal productions; longer spans are computed by trying every split point k and every pair of nonterminals B ∈ P[i, k], C ∈ P[k+1, j], adding A whenever A → BC is a production. The string is in the language if the start symbol appears in the cell covering the whole string.

Complexity

The running time is O(n3 · |G|) for grammar size |G|, and memory usage is O(n2 · |V|). This made CYK, for decades, the asymptotically fastest general context-free parsing algorithm known; Valiant (1975) showed parsing can be reduced to Boolean matrix multiplication, enabling sub-cubic algorithms in theory.

Extensions

Probabilistic variants of CYK (the "inside algorithm") compute the most likely parse or the total probability of a string under a probabilistic context-free grammar, and are used in computational linguistics for parsing natural language and in bioinformatics for RNA secondary structure analysis. Converting a grammar to CNF is harmless for recognition purposes, though it may require care when the parse structure itself matters.
