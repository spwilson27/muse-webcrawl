System of linear equations

In mathematics, a system of linear equations (or linear system) is a collection of one or more linear equations involving the same variables. For example,

3x + 2y − z = 1
2x − 2y + 4z = −2
−x + (1/2)y − z = 0

is a system of three equations in the three variables x, y, z. A solution to a linear system is an assignment of values to the variables such that all the equations are simultaneously satisfied. The solution above is x = 1, y = −2, z = −2.

Linear systems are a fundamental part of linear algebra, historically the first part of the subject to be developed, and arise throughout science and engineering — in circuit analysis, structural mechanics, economics (input–output models), and as linearizations of nonlinear problems.

Matrix form

A general system of m equations in n unknowns can be written as Ax = b, where A is an m × n matrix of coefficients, x the vector of unknowns, and b the vector of constants. The system has a solution if and only if b lies in the column space of A; the Rouché–Capelli theorem compares the ranks of A and the augmented matrix [A | b]. A homogeneous system (b = 0) always has the trivial solution and has nontrivial solutions exactly when A is rank-deficient.

Solution methods

  • Gaussian elimination — row-reducing the augmented matrix to echelon form, then back-substituting.
  • Matrix inversion and Cramer's rule — practical for small systems; Cramer's rule is mostly of theoretical interest.
  • LU and QR factorizations — the workhorses of numerical computation.
  • Iterative methods (Jacobi, Gauss–Seidel, conjugate gradient) — used for very large, sparse systems.

Geometrically, each equation in two variables defines a line, and in three variables a plane: a system may have no solution (parallel or inconsistent planes), exactly one solution, or infinitely many (a line or plane of intersection).
