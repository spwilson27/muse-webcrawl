Network Access Control

Network Access Control (NAC) is an approach to computer security that attempts to unify endpoint security technology (such as antivirus, host intrusion prevention, and vulnerability assessment), user or system authentication, and network security enforcement. It is a networking solution that uses a set of protocols to define and implement a policy that describes how to secure access to network nodes by devices when they initially attempt to access the network.

A device is authenticated and its security posture checked before network access is granted.

How it works

When a device connects to a network, it is not immediately granted full access. Instead, the NAC system identifies the device and user, evaluates the device's compliance with security policy (for example, operating system patch level and antivirus status), and then grants full access, restricted access, or quarantine to a remediation network if the device is non-compliant or unauthorized. Unknown or guest devices may be placed on a limited segment.

Standards and implementations

NAC is commonly implemented using the IEEE 802.1X port-based authentication standard together with a RADIUS server. Historically, major frameworks included Cisco's Network Admission Control and Microsoft's Network Access Protection (NAP), the latter deprecated with Windows Server 2016. Commercial NAC products are offered by vendors such as Cisco (Identity Services Engine), Aruba (ClearPass), and Forescout.

Goals

  • Mitigate zero-day attacks by enforcing policy at connection time
  • Allow only authorized and compliant devices on the network
  • Provide visibility of all devices, including unmanaged and IoT devices
  • Automate remediation or quarantine of non-compliant endpoints
