Runtime library

A runtime library is a library of routines that implement functions of a programming language that are too complex or too dependent on the target environment to be compiled directly into a program's object code. Typical services include input and output, memory management, mathematical functions and conversions between types.

Role in program execution

When a compiler translates a program, calls to built-in language features — such as division for languages without hardware support, string handling, or exception handling — are emitted as calls into the runtime library. The library is either linked statically into the executable or loaded dynamically at run time, as with the C runtime libraries provided by operating systems.

Examples

Examples include the C standard library implementations such as glibc and the Microsoft Visual C++ Runtime, as well as the runtime systems for languages such as Ada, Fortran and Go, which provide facilities like garbage collection, tasking or goroutine scheduling alongside ordinary library functions.
