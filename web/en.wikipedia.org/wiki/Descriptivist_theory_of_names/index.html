The descriptivist theory of names is a view in the philosophy of language about how proper names function. According to descriptivism, a proper name — such as "Aristotle" — has as its meaning a definite description, or a cluster of descriptions, which the bearer uniquely satisfies. The name refers to whatever object fits the description (or most of the cluster), and understanding the name consists in associating the description with it.

Classical descriptivism

The view develops from Gottlob Frege's distinction between sense and reference, and from Bertrand Russell's theory of descriptions: "Aristotle" might abbreviate "the pupil of Plato and teacher of Alexander the Great". John Searle later proposed a looser "cluster" version: a name refers to the object satisfying a sufficient but unspecified number of the descriptions speakers associate with it.

Kripke's criticisms

In Naming and Necessity (1972), Saul Kripke raised famous objections: the modal argument (a name is a rigid designator, picking out the same object in every possible world, whereas descriptions need not); the semantic argument (speakers may associate false descriptions — e.g. if Jonah never existed as described); and the epistemic argument (descriptions can be contingent and a posteriori while identity statements with names can be necessary and a priori). Kripke's rival causal-historical picture, and similar arguments by Keith Donnellan and Hilary Putnam, made descriptivism a minority view, though neo-descriptivist and two-dimensionalist replies remain influential.
