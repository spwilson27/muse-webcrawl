Page layout

Page layout is the part of graphic design that deals in the arrangement of visual elements on a page. It generally involves organisational principles of composition to achieve specific communication objectives.

Elements

A page layout combines text (body copy, headlines, captions), images, and white space within a grid. Common considerations include margins, columns, the hierarchy of headings, and the balance between content and empty space. In print design the layout is fixed for a given page size; in web design, layouts must adapt to different screen sizes, a practice known as responsive web design.

Grids

Designers often begin with a grid: a framework of intersecting lines that aligns elements and creates visual order. Modular and columnar grids are standard in newspapers and magazines, while manuscript grids are used for long-form text such as books.

Tools

Layout was historically done by paste-up on boards; modern work uses desktop publishing software such as Adobe InDesign, QuarkXPress and Scribus, and, for the web, CSS layout systems including flexbox and grid.
