Fat binary

A fat binary (or multiarchitecture binary) is a computer executable program or library which has been expanded (or "fattened") with code native to multiple instruction set architectures (ISAs), which can consequently be run on multiple processor types. In the Apple ecosystem such files are called Universal binaries.

History

The technique originated with NeXTSTEP, which supported Motorola 68k, Intel x86, SPARC, and HP PA-RISC architectures in a single "Multi-Architecture Binary," enabling software distribution on one medium during an architecture transition. Apple adopted the concept when moving Macintosh from 68k to PowerPC in 1994, again for the PowerPC-to-Intel transition in 2006 (Universal binary), and again for the Intel-to-Apple silicon transition in 2020 (Universal 2, combining x86-64 and ARM64).

Implementation

A fat binary contains a header identifying separate embedded executable images — one per architecture — and the operating system's loader selects the image matching the host processor. The trade-off is larger file size, since machine code is duplicated for each supported ISA. Tools such as Apple's lipo can inspect, merge, and split fat binaries.

Similar techniques include Android application packages containing native libraries for several ABIs, and "fat JAR" files in Java distribution.
