DR-DOS (written as DR DOS until version 6.0) is an operating system of the DOS family, written originally by Digital Research and derived from Concurrent PC DOS 6.0 and DOS Plus. It was a compatible alternative to Microsoft's MS-DOS and IBM's PC DOS for IBM PC compatible computers.

History

Digital Research, the company behind CP/M, had earlier produced Concurrent DOS and DOS Plus. DR DOS 3.31, released in 1988, was the first version sold under the DR-DOS name; it was compatible with Compaq MS-DOS 3.31 and offered features such as larger hard-disk partitions than rival products. Subsequent versions added a graphical file manager (ViewMAX), disk compression, memory management tools and multitasking support through the TaskMAX task switcher.

DR DOS 5.0 (1990) was noted for loading most of the operating system into high memory on 286 and 386 machines, freeing conventional memory for applications. DR DOS 6.0 (1991) added the SuperStor disk compression technology. Novell acquired Digital Research in 1991 and released Novell DOS 7 in 1993, which integrated NetWare technology including peer-to-peer networking. Caldera later acquired the product line, releasing DR-DOS 7.02 and 7.03, and famously sued Microsoft over alleged incompatibility tricks involving the AARD code in pre-release versions of Windows. The suit was settled in 2000 for a sum reported at about $280 million.

Later development

The source base was also used to create the open-source OpenDOS project. DeviceLogics acquired DR-DOS in 2002 and released DR-DOS 8.0 in 2004; version 8.1 followed before being withdrawn over licensing concerns regarding embedded FreeDOS code. DR-DOS remains of interest to retrocomputing enthusiasts and embedded systems.
