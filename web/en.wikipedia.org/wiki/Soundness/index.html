Soundness

In logic and deductive reasoning, an argument has soundness if it is both valid in form and its premises are true. A sound argument is therefore guaranteed to have a true conclusion.

FieldLogic, philosophy, mathematics
RequiresValidity + true premises

In logic

A deductive argument is sound if (1) all its premises are true, and (2) the conclusion follows logically — that is, it is impossible for the premises to be true and the conclusion false. Validity concerns form alone; soundness adds truth. Example: 'All men are mortal; Socrates is a man; therefore Socrates is mortal' is sound.

Soundness of logical systems

A formal system is sound if every theorem provable in it is true in every model (semantically valid). Soundness is paired with completeness: Gödel's completeness theorem shows first-order logic is both sound and complete, while his incompleteness theorems limit what sufficiently strong systems can prove about themselves.

In computer science

In type theory and program analysis, a system is sound if it does not accept programs that exhibit forbidden behaviour — e.g. a sound type system prevents certain runtime errors.
