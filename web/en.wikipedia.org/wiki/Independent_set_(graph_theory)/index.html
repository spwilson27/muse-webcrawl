Independent set (graph theory)

In graph theory, an independent set, stable set, coclique or anticlique is a set of vertices in a graph, no two of which are adjacent. That is, it is a set S of vertices such that for every two vertices in S, there is no edge connecting the two. Equivalently, each edge in the graph has at most one endpoint in S. The size of an independent set is the number of vertices it contains.

Maximum independent sets

An independent set that is not a proper subset of any other independent set is called maximal. Such sets are dominating sets. A maximum independent set is an independent set of largest possible size for a given graph G. This size is called the independence number of G and is usually denoted by α(G). Every maximum independent set is maximal, but the converse does not hold.

Computational complexity

The maximum independent set problem is NP-hard, and the decision version — determining whether a graph has an independent set of a given size — is one of Karp's 21 NP-complete problems. Even approximating the maximum independent set is hard: it cannot be approximated within a factor of n1−ε for any ε > 0 unless P = NP. Nevertheless, the problem is fixed-parameter tractable, and exact exponential-time algorithms exist; for restricted graph classes such as claw-free graphs and perfect graphs it can be solved in polynomial time.

Relations to other problems

A set of vertices is independent if and only if its complement is a vertex cover, and if and only if it is a clique in the complement graph. Consequently, the sum of the independence number and the vertex cover number equals the number of vertices. The classic result of Moon and Moser (1965) bounds the number of maximal independent sets in an n-vertex graph by 3n/3. Independent sets arise in coding theory, scheduling, and the study of statistical physics models such as the hard-core gas model.
