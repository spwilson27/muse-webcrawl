Production system

A production system (or production rule system) is a computer program typically used to provide some form of artificial intelligence, which consists primarily of a set of rules about behavior, but also the mechanism necessary to follow those rules as the system responds to states of the world. These rules, termed productions, are a basic representation found useful in automated planning, expert systems and action selection.

Components

A production system consists of:

  • a rule base (long-term memory) of productions, each in the form condition → action ("if–then" rules);
  • a working memory (short-term memory) holding the facts or assertions describing the current state;
  • an inference engine (rule interpreter) that repeatedly matches rule conditions against working memory, selects among the rules that fire (the "conflict set") using a conflict-resolution strategy, and executes the chosen rule's actions, which typically add, delete or modify working-memory elements.

This match–select–act cycle continues until no rules match or a goal state is reached. Rule ordering strategies include specificity, recency and refraction (a rule may not fire twice on the same data).

History

The theoretical roots lie in Emil Post's rewriting systems of the 1920s–40s. Allen Newell and Herbert A. Simon adopted production systems in the 1970s as a model of human cognition, notably in their work on human problem solving and later in the Soar architecture developed by John Laird. Production systems became a central technology of 1980s expert systems; Charles Forgy's Rete algorithm (1979) greatly accelerated pattern matching for large rule bases and underlies many modern rule engines.

Applications

Production systems are used in expert systems (such as XCON for configuring computer systems), business rule management systems, cognitive architectures (Soar, ACT-R), automated planning, and tutorial systems.
