DeviceNet

DeviceNet is a network protocol used in the automation industry to interconnect control devices for data exchange. It utilizes the Common Industrial Protocol (CIP), which is also used by EtherNet/IP and ControlNet. DeviceNet was originally developed by Allen-Bradley (now part of Rockwell Automation) and is maintained by ODVA.

Technical overview

DeviceNet is based on the Controller Area Network (CAN) technology originally developed for automotive applications. It supports data rates of 125, 250 and 500 kbit/s over distances depending on cable type and speed. A single network can support up to 64 nodes.

Features

The network carries both signal and power on the same cable, simplifying installation of sensors, actuators, motor starters and other field devices. It supports master/slave, peer-to-peer and producer/consumer communication models, along with features such as automatic device replacement and network-based configuration.

Applications

DeviceNet is widely used in factory automation, including automotive plants, packaging machinery and material handling systems, particularly in North America.
