Constrained optimization

In mathematical optimization, constrained optimization (also called constraint optimization) is the process of optimizing an objective function with respect to some variables in the presence of constraints on those variables. The constraints may be equalities or inequalities that the solution is required to satisfy.

Formulation

A constrained optimization problem can be written as minimizing (or maximizing) a function f(x) subject to equality constraints gi(x) = 0 and inequality constraints hj(x) ≤ 0. The set of points satisfying all constraints is called the feasible set or feasible region.

Methods

Classical techniques include Lagrange multipliers, which convert equality-constrained problems into unconstrained stationarity conditions, and the Karush–Kuhn–Tucker conditions, which generalize them to inequality constraints. Numerical algorithms for constrained problems include penalty and barrier methods, sequential quadratic programming, and interior-point methods. Hard constrained problems in which the feasible set is complicated may be attacked by first solving an easier relaxed problem, as in branch and bound.

Applications

Constrained optimization is used throughout economics, engineering design, control theory, portfolio selection and machine learning — for instance, support vector machines are trained by solving a constrained quadratic program.
