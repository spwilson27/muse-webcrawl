Möbius function

The Möbius function, denoted μ(n), is a multiplicative function in number theory introduced by the German mathematician August Ferdinand Möbius in 1832. It is used in the Möbius inversion formula and in the study of summatory functions in analytic number theory.

Definition

For a positive integer n, μ(n) is defined as follows:

  • μ(n) = 1 if n is a square-free positive integer with an even number of prime factors;
  • μ(n) = −1 if n is square-free with an odd number of prime factors;
  • μ(n) = 0 if n has a squared prime factor.

Thus μ(1) = 1, μ(2) = μ(3) = μ(5) = −1, μ(4) = 0, and μ(6) = 1.

Properties

The Möbius function satisfies the identity Σd|n μ(d) = 1 if n = 1 and 0 otherwise. This property underlies the Möbius inversion formula, which recovers a function from its divisor sums. The summatory Möbius function M(x) = Σn≤x μ(n) is closely related to the Riemann hypothesis: the hypothesis is equivalent to the statement that M(x) grows no faster than about x1/2+ε for every ε > 0.

Applications

The Möbius function appears in combinatorics (counting aperiodic necklaces and binary Lyndon words), in the inclusion–exclusion principle, and in physics, where it occurs in models of the free Riemann gas.
