ZFS

ZFS (previously Zettabyte File System) is a file system with volume management capabilities. It began as part of the Sun Microsystems Solaris operating system in 2001. Large parts of Solaris — including ZFS — were published under an open source license as OpenSolaris for around five years from 2005 before being placed under a closed-source license when Oracle Corporation acquired Sun in 2009–2010. During 2005 to 2010, the open source version of ZFS was ported to Linux, Mac OS X (continued as MacZFS) and FreeBSD.

In 2013, OpenZFS was founded to coordinate the development of the open source version of ZFS. OpenZFS maintains and releases code under the CDDL license.

Features

ZFS combines a file system and a logical volume manager in a single design built around storage pools. Its notable features include:

  • End-to-end checksumming and self-healing: data blocks are checksummed, and corruption detected against redundant copies is repaired automatically ("scrubbing").
  • Copy-on-write transactional semantics, so the on-disk state is always consistent and no fsck is needed.
  • Snapshots and clones, which are nearly free in space and time.
  • Built-in RAID levels (mirroring, RAID-Z, RAID-Z2, RAID-Z3) similar to RAID-5/6/7.
  • Compression, deduplication, and encryption.
  • Very large limits: ZFS is a 128-bit file system, designed to scale to zettabyte storage pools.

History

ZFS was developed at Sun Microsystems by a team led by Jeff Bonwick and Matthew Ahrens, and announced in 2004. It shipped with Solaris 10 in 2006. It became the default file system of FreeBSD in many installations and is widely used through OpenZFS on Linux, despite a long-running debate about the compatibility of the CDDL license with the GPL.
