Compactness theorem

In mathematical logic, the compactness theorem states that a set of first-order sentences has a model if and only if every finite subset of it has a model. That is, if no finite subset is inconsistent, then the whole set is consistent and can be satisfied simultaneously. The theorem is one of the central results of model theory, alongside the completeness theorem and the Löwenheim–Skolem theorems.

History

The compactness theorem follows from Kurt Gödel's completeness theorem of 1930: a set of sentences is inconsistent exactly when a contradiction can be derived from finitely many of them, so if every finite subset has a model, the set cannot be inconsistent. An independent, purely semantic proof was given by Anatoly Maltsev in 1936, and the theorem can also be proved using ultraproducts or deduced from the compactness of propositional logic via the Boolean prime ideal theorem.

Applications

The classic application is the construction of non-standard models: by adding a constant c and infinitely many sentences saying that c exceeds 1, 2, 3, …, compactness shows that the natural numbers (and the real numbers) have models containing infinitely large elements — the basis of non-standard analysis. Compactness is also used to show that certain properties are not expressible in first-order logic: for example, finiteness and connectedness of graphs cannot be captured by a first-order theory, since a theory requiring arbitrarily large finite approximations would, by compactness, also have infinite models. It implies that first-order logic cannot distinguish infinite cardinalities beyond the Löwenheim–Skolem bounds, and it underlies transfer principles between finite and infinite structures.

Generalisations and limits

Compactness fails for second-order logic and for infinitary logics that allow infinite conjunctions, which is one measure of first-order logic's balance between expressiveness and good behaviour. Lindström's theorem states that first-order logic is the strongest logic satisfying both the compactness theorem and the downward Löwenheim–Skolem property.
