Function (computer programming)

In computer programming, a function is a named section of a computer program that performs a specific task. It is a type of procedure or routine: some programming languages distinguish between functions, which return a value, and procedures, which perform an operation without returning one, though in practice the terms are often used interchangeably, along with related terms such as subroutine, subprogram, and method.

Concepts

A function is typically defined with a list of parameters and a body of statements; it is executed when it is called (invoked) from elsewhere in the program, with actual arguments passed to its parameters. Functions support abstraction, code reuse, and modular decomposition of large programs. Recursive functions call themselves, directly or indirectly. A function that has no side effects and whose result depends only on its inputs is called a pure function, a concept central to functional programming.

History

The idea of subroutines dates to the 1940s, in work by Konrad Zuse, and by David Wheeler, Maurice Wilkes, and Stanley Gill at Cambridge, who developed the subroutine library for the EDSAC. Modern languages add first-class functions, anonymous functions (lambdas), closures, and higher-order functions that take other functions as arguments.
