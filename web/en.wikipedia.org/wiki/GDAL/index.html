GDAL

The Geospatial Data Abstraction Library (GDAL) is a computer software library for reading and writing raster and vector geospatial data formats, and is released under the permissive X/MIT style free software license by the Open Source Geospatial Foundation. As a library, it presents a single abstract data model to the calling application for all supported formats.

GDAL was originally developed by Frank Warmerdam, with the first release in 2000. It may also be built with a variety of useful command line interface utilities for data translation and processing — such as gdal_translate, gdalwarp, ogr2ogr, and gdalinfo.

Formats and usage

GDAL supports over 100 raster formats including GeoTIFF, JPEG 2000, ECW, and HDF, and — through its companion OGR library — dozens of vector formats including ESRI Shapefile, GeoJSON, PostGIS, and KML. It is used extensively by GIS software, including QGIS, ArcGIS, and Google Earth, and by remote sensing pipelines for satellite imagery.

Bindings exist for Python, Java, C#, R, and other languages, making GDAL one of the most widely used pieces of open-source geospatial software.
