Icon (computing)

Typical desktop icons: folders, documents, applications and the trash.

In computing, an icon is a pictogram or ideogram displayed on a computer screen in order to help the user navigate a computer system. The icon itself is a quickly comprehensible symbol of a software tool, function, or data file, accessible on the system, and is more like a traffic sign than a detailed illustration of the entity it represents. It can serve as an electronic hyperlink or file shortcut to access the program or data. The user can activate an icon using a mouse, pointer, finger, or voice commands.

History

Icons originated with the pioneering work at Xerox PARC in the 1970s, where David Canfield Smith coined the term in his 1975 PhD thesis and the Xerox Star (1981) presented documents, folders and a desktop metaphor to users. The Apple Lisa (1983) and Macintosh (1984) popularised icons for a mass market, and Microsoft Windows and other graphical user interfaces followed. Susan Kare's bitmap icons for the original Macintosh — including the Happy Mac and the trash can — became classics of the genre.

Design

Effective icons rely on simple, recognisable metaphors: an envelope for mail, a floppy disk for saving, a magnifying glass for search. Because displays differ in size and resolution, icon sets are supplied at multiple sizes and, increasingly, as resolution-independent vector graphics. File formats include ICO on Windows, ICNS on macOS, and PNG or SVG on the web; website icons appear in browsers as favicons.
