Creative coding

Generative visual art produced by code

Creative coding is a type of computer programming in which the goal is to create something expressive or artistic, rather than something purely functional. It is used to produce visual art, interactive installations, generative music, data-driven design, and live performance, and is closely associated with the demoscene, digital art, and computational design communities.

Overview

Creative coding treats the computer program itself as a creative medium. Practitioners write code to explore emergent behaviour, randomness, and systems, often producing output that could not be predicted in detail in advance. The practice emphasises iteration, improvisation, and play over engineering rigour: code is frequently written quickly, modified live, and discarded.

History

The roots of creative coding lie in early computer art of the 1960s, when artists such as Vera Molnár, Frieder Nake, and Georg Nees used mainframe computers and plotters to generate drawings from algorithms. The demoscene of the 1980s and 1990s pushed real-time graphics on home computers. The release of Processing in 2001 by Casey Reas and Ben Fry made programming far more accessible to visual artists, and its JavaScript successor p5.js, created by Lauren McCarthy, brought the approach to the web browser.

Tools and frameworks

Popular environments include Processing and p5.js for 2D graphics and interaction; openFrameworks and Cinder for high-performance C++ work; TouchDesigner for node-based real-time visuals; Max/MSP and Pure Data for audio-visual patching; and shader languages such as GLSL for GPU-driven imagery. Libraries for machine learning, computer vision, and physics are frequently combined with these frameworks.

Practices

Creative coding encompasses generative art, live coding performances (including algoraves, where music is improvised by coding in front of an audience), creative coding in education ("coding for artists" courses), and commercial applications in advertising, architecture, and interactive exhibits. Communities organise around events such as festivals, hack days, and online galleries where sketches and source code are shared openly.
