Segmentation fault

A shell reporting "Segmentation fault (core dumped)" on a Unix-like system.

A segmentation fault (often shortened to segfault) is a specific kind of error caused by accessing memory that "does not belong" to the running program. When a program attempts to read from or write to an illegal memory location — for example dereferencing a null pointer or an uninitialised or freed pointer, or overrunning a buffer — the operating system's memory protection hardware detects the fault and terminates the program. On Unix-like systems the process receives the signal SIGSEGV, and a shell may report "Segmentation fault (core dumped)"; on Windows the equivalent event is an access violation (exception code 0xC0000005).

Causes

Common causes in languages with manual memory management, such as C and C++, include:

  • Dereferencing a null, wild or dangling pointer
  • Buffer overflows and out-of-bounds array indexing
  • Use of a pointer after its memory has been freed (use-after-free)
  • Stack overflow, usually from unbounded recursion
  • Attempting to write to read-only memory, such as a string literal
  • Passing incorrectly formatted arguments to library functions, for example a non-pointer where printf expects an address

Languages with automatic memory management and bounds checking (such as Java, Python and Rust in safe code) are designed to prevent segfaults in ordinary code, converting such errors into catchable exceptions instead.

Handling and debugging

By default the operating system terminates a faulting process, optionally writing a core dump that records its memory state for post-mortem analysis. Debuggers such as GDB can run a program and stop at the exact instruction that faulted, showing the offending address and backtrace; tools such as Valgrind and the compiler sanitizers (AddressSanitizer and related tools) detect invalid accesses earlier and with better diagnostics. Because memory corruption can also be a security vulnerability, a segfault may indicate an exploitable bug, not merely a crash.
