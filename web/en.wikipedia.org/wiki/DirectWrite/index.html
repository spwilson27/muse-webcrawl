DirectWrite

DirectWrite is a text layout and glyph rendering API from Microsoft, introduced with Windows 7 and Windows Vista SP2 as part of the DirectX family. It was designed to succeed GDI and GDI+ for high-quality, hardware-accelerated text, and it powers text rendering in modern Windows browsers and applications.

DirectWrite provides full support for Unicode, complex-script shaping and bidirectional text layout, advanced OpenType typography (ligatures, stylistic alternates, contextual forms), and sub-pixel positioning with ClearType rendering, including improved y-direction anti-aliasing. It works hand-in-hand with Direct2D for drawing and with Windows Imaging Component for colour fonts.

The API separates layout (measuring, line-breaking, hit-testing) from rendering, allowing applications to render text via Direct2D, GDI, or custom renderers. Successive Windows versions extended DirectWrite with variable fonts, colour glyph layers for emoji, and distance-field rendering techniques.
