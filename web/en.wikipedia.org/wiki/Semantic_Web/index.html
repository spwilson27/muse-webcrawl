The Semantic Web, sometimes known as Web 3.0 (not to be confused with Web3), is an extension of the World Wide Web through standards set by the World Wide Web Consortium (W3C). The goal of the Semantic Web is to make Internet data machine-readable.

To enable the encoding of semantics with the data, technologies such as the Resource Description Framework (RDF) and the Web Ontology Language (OWL) are used. These technologies are used to formally represent metadata. For example, ontology can describe concepts, relationships between entities, and categories of things. These embedded semantics offer significant advantages such as reasoning over data and operating with heterogeneous data sources.

Overview

The term was coined by Tim Berners-Lee for a web of data that can be processed by machines. In his original 1999 book Weaving the Web, Berners-Lee envisioned a web in which software agents could carry out sophisticated tasks for users by understanding the meaning of web content, rather than merely its presentation.

A key element is the use of Uniform Resource Identifiers (URIs) to name every resource, and the representation of facts as subject–predicate–object triples in RDF, forming vast interlinked graphs of data that can be queried with the SPARQL query language.

Components

The Semantic Web stack includes Unicode and URI layers at its base, followed by XML, RDF, RDFS, OWL, SPARQL, RIF, and layers for logic, proof, and trust. Linked Data principles, published by Berners-Lee in 2006, set out best practices for exposing and connecting data on the Web using these standards.

Applications and criticism

Semantic Web technologies underpin knowledge graphs such as DBpedia and Wikidata, enterprise data integration, and structured markup like schema.org used by search engines. Critics have questioned the feasibility of the full vision, noting the difficulty of getting content providers to supply reliable metadata, problems of trust and provenance, and the complexity of ontology alignment. Nevertheless, many of its core technologies have been widely adopted in data integration and knowledge representation.
