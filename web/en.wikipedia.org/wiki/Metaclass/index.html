Metaclass

In object-oriented programming, a metaclass is a class whose instances are themselves classes. Just as an ordinary class defines the behaviour of its instances (objects), a metaclass defines the behaviour of classes and their instances. Metaclasses are supported in languages such as Python, Ruby, Smalltalk, and Objective-C, and underlie much of their metaprogramming capability.

Instance–class–metaclass relationships

Concepts

In class-based languages every object is an instance of some class; in languages where classes are themselves objects, a class must in turn be an instance of something — its metaclass. Smalltalk pioneered this uniform treatment, in which every class is an instance of Metaclass. In Python, the default metaclass is type, which creates classes; programmers can define custom metaclasses (usually subclassing type) to intercept class creation, register classes automatically, enforce interfaces, or add methods and attributes — techniques used by frameworks such as Django's ORM and SQLAlchemy's declarative base. In Ruby, each class has a singleton ("eigenclass") mechanism serving a similar role.

Uses

Typical uses include automatic registration of subclasses in plugin architectures, validation of class attributes at definition time, generation of boilerplate methods, implementing abstract base class checks, and object–relational mapping. Because metaclasses act implicitly whenever a class is defined, they are powerful but can obscure code behaviour, leading to the common Python maxim (attributed to Tim Peters) that metaclasses are "deeper magic than 99% of users should ever worry about".
