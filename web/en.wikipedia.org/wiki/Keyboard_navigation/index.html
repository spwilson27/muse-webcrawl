Keyboard navigation

Keyboard navigation
FieldHuman–computer interaction, accessibility

Keyboard navigation refers to using a computer keyboard to move through the elements of a graphical user interface or web page — such as links, form fields, buttons, and menus — rather than using a mouse or other pointing device. It is an essential part of accessible design, since many users with motor disabilities, as well as screen reader users and power users, rely on the keyboard as their primary means of interaction.

Focus and tab order

The element that currently receives keyboard input is said to have the focus. Pressing the Tab key moves focus forward through the focusable elements on a page, while Shift+Tab moves focus backwards. The sequence in which elements receive focus is the tab order, which by default follows the source order of the document. A visible focus indicator — an outline or highlight around the focused element — is necessary for sighted keyboard users to know where they are.

Common conventions

  • Tab / Shift+Tab — move between controls
  • Enter or Space — activate a button or link
  • Arrow keys — move within lists, menus, sliders, and radio groups
  • Escape — close dialogs and menus
  • Access keys and keyboard shortcuts — direct activation of commands

Accessibility requirements

The Web Content Accessibility Guidelines (WCAG) require that all functionality be operable through a keyboard interface (criterion 2.1.1), that keyboard use never trap the user's focus (2.1.2), and that the focus indicator be visible (2.4.7). Skip links, which let keyboard users bypass long navigation menus, are a common technique for satisfying these requirements.
