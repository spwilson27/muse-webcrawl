NeXTSTEP is a discontinued object-oriented, multitasking operating system based on the Mach kernel and BSD Unix. It was developed by NeXT Computer, founded by Steve Jobs, and first released in 1989 for NeXT's own workstations such as the NeXTcube. It later ran on other architectures including Intel x86, Sun SPARC and HP PA-RISC.

Features

NeXTSTEP was notable for its elegant graphical user interface built on Display PostScript, its powerful object-oriented development environment based on Objective-C and the AppKit framework, and tools such as Interface Builder, which pioneered graphical interface design by drag and drop. The system provided preemptive multitasking, memory protection, and rich multimedia support ahead of most contemporaries.

Legacy

Tim Berners-Lee wrote the first web browser and server on a NeXT computer at CERN in 1990 using NeXTSTEP's tools. After Apple acquired NeXT in 1997, NeXTSTEP's successor OPENSTEP became the basis of Mac OS X, and its frameworks live on in macOS, iOS and related systems through Cocoa and Objective-C/Swift development.
