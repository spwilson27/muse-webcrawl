Eulerian path

In graph theory, an Eulerian path (or Eulerian trail) is a trail in a finite graph that visits every edge exactly once. An Eulerian circuit (or Eulerian cycle) is an Eulerian trail that starts and ends on the same vertex. The concept was introduced by Leonhard Euler in his solution to the Seven Bridges of Königsberg problem in 1736, which is regarded as the first paper in graph theory.

Existence

An undirected graph has an Eulerian circuit if and only if it is connected (ignoring isolated vertices) and every vertex has even degree. It has an Eulerian path that is not a circuit if and only if exactly zero or two vertices have odd degree. Analogous conditions exist for directed graphs using in-degrees and out-degrees.

Counting and algorithms

Hierholzer's algorithm constructs an Eulerian circuit in linear time. The BEST theorem counts the number of Eulerian circuits in a directed graph, and the number in undirected graphs can be computed in polynomial time.

Applications

Eulerian paths are used in route planning (such as snow ploughing and postal delivery), in DNA fragment assembly, and in generating de Bruijn sequences.
