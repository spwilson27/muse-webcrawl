Libhandy is a free and open-source GTK library that provides adaptive widgets for building applications that adjust their interfaces between desktop and mobile form factors. It was originally developed by Purism for use on the Librem 5 Linux smartphone, and was subsequently adopted by the GNOME project for applications that needed to run both on conventional computers and on phones.

Features

The library supplies widgets not found in GTK 3, including adaptive containers that collapse multi-pane layouts into a single column on narrow screens (such as the leaflet and deck widgets), swipeable carousels, avatar widgets, view switchers that relocate to the bottom of the window on phones, and preferences windows designed for convergent use. These components allow a single application binary to present a desktop interface in a wide window and a touch-friendly mobile interface in a narrow one.

History and succession

Libhandy 1.0 was released in 2020 and was used by numerous GNOME applications. With the move to GTK 4, the library's role was taken over by libadwaita, which incorporated libhandy's adaptive widgets as part of the official GNOME platform libraries and superseded it for new development.
