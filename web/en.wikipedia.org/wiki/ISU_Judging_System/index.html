ISU Judging System

The ISU Judging System (or the International Judging System (IJS)), occasionally referred to as the Code of Points, is the scoring system that has been used since 2004 to judge the figure skating disciplines of men's and ladies' singles, pair skating, ice dance, and synchronized skating. It was designed and implemented by the International Skating Union (ISU), the ruling body of the sport, after the 2002 Winter Olympics figure skating scandal, which badly damaged the credibility of the older 6.0 system.

Components

Under the IJS, each programme receives a Total Element Score (TES) and a Program Component Score (PCS). A technical panel identifies each element performed (jumps, spins, step sequences, lifts) and assigns it a level of difficulty; each element has a base value in the Scale of Values. Judges award a grade of execution (GOE) ranging from −5 to +5 for each element. Program components cover skating skills, transitions, performance, composition and interpretation of the music. Deductions are applied for falls and rule violations.

History

The system was introduced for the 2003–04 season in some events and fully adopted after the 2002 scandal in which a French judge admitted to being pressured to vote for the Russian pair in the pairs event. It replaced ordinal placements with cumulative points, and judges' marks were initially made anonymous, a feature later modified.

Criticism

Critics argue the system rewards technical difficulty at the expense of artistry, is difficult for audiences to follow, and its detailed protocols make competitions excessively long. Supporters credit it with greater objectivity and transparency through published protocols listing every element and mark.
