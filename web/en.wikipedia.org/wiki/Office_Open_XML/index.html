Office Open XML

Office Open XML (also informally known as OOXML) is a zipped, XML-based file format developed by Microsoft for representing spreadsheets, charts, presentations and word processing documents. Ecma International standardized the initial version as ECMA-376 in 2006. A second version was standardized as ISO/IEC 29500 in 2008.

The format is used by Microsoft Office since Office 2007, with filename extensions such as .docx, .xlsx, and .pptx, where the final "x" denotes the XML format. It replaced the earlier binary formats as the default.
