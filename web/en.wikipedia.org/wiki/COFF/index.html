COFF

Full name: Common Object File Format
Filename extension: .obj, .o, .lib (implementation-dependent)
Introduced: With UNIX System V (1983)
Successors: ELF (Unix-like systems); PE/COFF (Windows)

The Common Object File Format (COFF) is a format for executable, object code and shared library computer files used on Unix systems. Introduced in UNIX System V Release 1 (1983) as the successor to the earlier a.out format, it was influential in the design of later object file formats.

Design

COFF improved on a.out by dividing the file into named sections (such as .text for code and .data for initialised data), each with its own relocation information, file header, and optional section headers, allowing linkers and loaders greater flexibility. It also included support for symbolic debugging information associated with source lines, which helped the development of source-level debuggers.

Derivatives and legacy

Several variants extended the format, including IBM's XCOFF for AIX and Microsoft's extended implementations. COFF's most widespread descendants are the Portable Executable (PE) format used by Microsoft Windows — often called PE/COFF — and the format still used by Microsoft's compilers for object files. On most Unix-like systems, COFF itself was eventually superseded by the Executable and Linkable Format (ELF).
