Rencontres numbers

In combinatorics, the rencontres numbers are a triangular array of integers that enumerate permutations of a set {1, …, n} with specified numbers of fixed points, or rencontres (coincidences). The name derives from the French card game jeu des rencontres studied by Pierre Raymond de Montmort in 1708.

Definition

The rencontres number Dn,k counts the number of permutations of n elements with exactly k fixed points. The diagonal Dn,0 gives the derangements (subfactorials), denoted !n.

Formulas

The numbers satisfy Dn,k = C(n,k) · Dn−k,0, and the recurrence Dn,k = (n−1)(Dn−2,k−1 + Dn−1,k). Summing over k recovers n!, since every permutation has some number of fixed points. The first rows of the triangle begin: n=1: 0, 1; n=2: 1, 0, 1; n=3: 2, 3, 0, 1; n=4: 9, 8, 6, 0, 1.

Applications

Rencontres numbers appear in the classical matching problem (problème des rencontres), in the analysis of card games such as Frustration Solitaire, and in probability, where the number of fixed points of a random permutation is asymptotically Poisson distributed with mean 1.
