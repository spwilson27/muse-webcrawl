The Revision Control System (RCS) is an early implementation of a version control system, developed by Walter F. Tichy at Purdue University and released in 1982. It automates the storing, retrieval, logging, identification, and merging of revisions of text files, and is still maintained as part of the GNU Project.

Design

RCS operates on single files rather than whole projects. For each file foo it keeps an archive file foo,v storing revisions as reverse deltas — the latest version in full plus differences back to earlier versions. Check-in and check-out are done with the ci and co commands, and locking prevents simultaneous edits.

Influence

RCS's concepts — revision numbers, check-in logs, keyword expansion such as $Id$ — strongly influenced its successor CVS, which added multi-file, networked operation, and later systems such as Subversion and Git.
