OpenGL Shading Language

Paradigm: Imperative, procedural

Developer: Khronos Group (OpenGL ARB)

First appeared: 2004 (OpenGL 2.0)

Typing: Static, strong

File extensions: .vert, .frag, .geom, .comp, .glsl

OpenGL Shading Language (GLSL) is a high-level shading language with a syntax based on the C programming language. It was created by the OpenGL Architecture Review Board (ARB) to give developers more direct control of the graphics pipeline without having to use ARB assembly language or hardware-specific languages. GLSL shaders are compiled and linked at runtime by the OpenGL driver and executed on the graphics processing unit (GPU).

History

Before GLSL, developers could use the fixed-function pipeline or assembly-level interfaces such as ARB_vertex_program and ARB_fragment_program. Following 3Dlabs' proposal of a C-like language integrated into OpenGL, GLSL 1.10 was made a core part of OpenGL 2.0 in 2004. Version 1.20 and 1.30 accompanied OpenGL 2.1 and 3.0; GLSL 1.40 and 1.50 arrived with OpenGL 3.1 and 3.2, adding geometry shaders. Subsequent versions are numbered to match OpenGL releases: GLSL 4.00 (OpenGL 4.0) added tessellation shaders, and GLSL 4.30 added compute shaders.

Language features

GLSL resembles C in control flow, functions, and preprocessor, but is designed around vector and matrix types central to graphics: vec2, vec3, vec4, and mat3/mat4, with component swizzling such as color.rgb. It provides built-in variables such as gl_Position and built-in functions for trigonometry, interpolation, and texture sampling.

Programs are organized as shader stages: vertex, tessellation control and evaluation, geometry, fragment, and compute shaders. Data flows between stages via in/out variables, while uniforms supply constant parameters from the host application and attributes (in modern core-profile GLSL, in variables in the vertex shader) supply per-vertex data.

Variants

GLSL ES is the shading language for OpenGL ES and WebGL, adapted for embedded and mobile devices with reduced precision qualifiers (lowp, mediump, highp). A related language, ESSL, is used in WebGL 1.0 and 2.0. Shaders written for Vulkan can use GLSL compiled to SPIR-V intermediate representation through tools such as glslangValidator.
