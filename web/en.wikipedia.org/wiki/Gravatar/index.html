Gravatar

A Gravatar is an image that follows a user from site to site.

Gravatar (a portmanteau of globally recognized avatar) is a service for providing globally unique avatars which was created by Tom Preston-Werner. Since 2007 it has been owned by Automattic, the company behind WordPress.com, which integrated it into that blogging platform.

How it works

On Gravatar, users create a profile based on their email address and upload an avatar image to associate with that address. When a user posts a comment or article on a website that supports Gravatar, that website hashes the user's email address (traditionally with MD5, later SHA-256) and requests the corresponding image from Gravatar's servers. The avatar is then displayed next to the user's name, allowing commenters to maintain a consistent identity across many independent websites without each site storing its own avatar images.

Features

Avatars may be requested in sizes from 1 to 2048 pixels and are rated similarly to film ratings; site owners can specify a maximum rating and a default image to show when a user has no Gravatar. Default options include a blank image, the Gravatar logo, and generated patterns such as "Identicon", "MonsterID", "Wavatar" and "Retro" faces derived from the hash. Gravatar profiles can also include verified links to other social networks, contact information and cryptocurrency wallet addresses.

Privacy considerations

Because the avatar lookup is based on a hash of the email address, researchers have noted that the hashes of known addresses can be computed in advance, making it possible to check whether a given address has a Gravatar profile and, in some cases, to harvest profile data at scale. The service has responded with options to hide profiles and the use of truncated hashes in newer API versions.
