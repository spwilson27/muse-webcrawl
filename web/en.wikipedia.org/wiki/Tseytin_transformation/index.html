Tseytin transformation

The Tseytin transformation, also called the Tseitin encoding, is a method in mathematical logic and computer science for converting an arbitrary Boolean formula or circuit into an equisatisfiable formula in conjunctive normal form (CNF). It is named after Grigori Tseitin, who described it in 1968.

Motivation

Naive conversion to CNF can cause an exponential blow-up in formula size. The Tseytin transformation avoids this by introducing fresh auxiliary variables for each subformula or gate, producing a CNF formula whose size is linear in the size of the original circuit. The result is not logically equivalent, but it is equisatisfiable: the original formula is satisfiable if and only if the transformed formula is.

Method

For each gate or subformula, a new variable is introduced together with clauses that encode the equivalence between that variable and the subformula it represents. For example, a variable x representing an AND gate with inputs a and b is constrained by clauses equivalent to x ↔ (a ∧ b). A final unit clause asserts the output variable.

Applications

The encoding is fundamental to modern SAT solvers and to reductions in computational complexity theory. It is widely used in electronic design automation, formal verification and automated theorem proving, where circuits and formulas must be presented to solvers in CNF.
