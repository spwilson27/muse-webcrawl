Morse code

Morse code is a telecommunications method which encodes text characters as standardised sequences of two different signal durations, called dots and dashes (or dits and dahs). Morse code is named after Samuel Morse, one of the early developers of the system adopted for electrical telegraphy, together with his assistant Alfred Vail.

History

Morse and Vail developed their code for the electric telegraph in the 1830s–1840s; the first message, "WHAT HATH GOD WROUGHT", was sent from Washington, D.C. to Baltimore in 1844. The original American Morse code was largely replaced by the International Morse code standardised in 1865 by the International Telegraph Union, which remains in use today. Morse became the universal language of telegraphy and early radio; the distress signal SOS (···–––···), adopted in 1906, is its most famous signal. Commercial maritime use ended in 1999 with the Global Maritime Distress and Safety System, but Morse remains popular with amateur radio operators and is still used in aviation aids and accessibility devices.

The code

International Morse assigns shorter codes to more frequent letters in English. Timing is standardised: a dash equals three dots; the gap between symbols within a character is one dot; between characters, three dots; between words, seven dots.

Use today

Morse proficiency was dropped as a requirement for amateur radio licences in most countries in the 2000s, but the mode (continuous wave, CW) remains efficient for weak-signal communication. Morse is also used in assistive technology, allowing people with severe motor disabilities to communicate by blinking or switch presses.
