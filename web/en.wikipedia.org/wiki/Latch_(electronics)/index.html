In electronics, a latch is a circuit that has two stable states and can be used to store state information — a bistable multivibrator. The circuit can be made to change state by signals applied to one or more control inputs and will have one or two outputs. It is the basic storage element in sequential logic. Latches are level-sensitive, in contrast to flip-flops, which are edge-triggered: a latch's output can change as long as its enable signal is asserted, whereas a flip-flop captures its input only at a clock edge.

SR latch

The most fundamental latch is the SR (set–reset) latch, built from a pair of cross-coupled NOR or NAND gates. Setting the S input drives the output Q high; setting R drives Q low; with both inputs inactive the circuit retains its previous state. Applying both inputs simultaneously produces a forbidden or invalid condition in which both outputs take the same value and the final state is unpredictable when the inputs are released.

Gated latches and the D latch

Adding gating logic produces the gated SR latch, whose inputs are effective only while an enable signal is active. The D latch (data or delay latch) eliminates the forbidden state by deriving the reset input from the complement of the data input: while the enable is high the output transparently follows the input D, and when the enable falls the last value is held. A pair of D latches in a master–slave arrangement, or a purpose-designed circuit, forms the edge-triggered D flip-flop used throughout synchronous digital design.

Applications

Latches appear in address demultiplexing (for example in early microprocessor systems, where a latch captures the multiplexed address bus), in I/O ports that hold output values, in fast cache memories built from SRAM cells — each cell being essentially a pair of cross-coupled inverters forming a latch — and in asynchronous and clock-domain-crossing circuits.
