Version space

FieldMachine learning
Introduced byTom M. Mitchell (1977–1982)
Related algorithmCandidate elimination

A version space, in the sense introduced by Tom M. Mitchell, is the set of all hypotheses in a hypothesis space that are consistent with a given set of training examples in a concept learning task. Mitchell's version space framework represents this set compactly by its boundary sets: the most general hypotheses consistent with the data (the G set) and the most specific consistent hypotheses (the S set).

Candidate elimination

Mitchell's candidate elimination algorithm incrementally refines the S and G boundary sets as each training example is observed. Positive examples cause the S set to be generalised minimally and overly general members of G to be removed; negative examples cause the G set to be specialised minimally and overly specific members of S to be removed. When the S and G sets converge to a single hypothesis, the concept has been uniquely learned; if they become empty, no hypothesis in the space is consistent with the data.

Significance

Version spaces were an influential early formalisation of inductive learning from examples, illustrating the role of inductive bias: the restriction of the hypothesis space is what makes generalisation from finite data possible.
