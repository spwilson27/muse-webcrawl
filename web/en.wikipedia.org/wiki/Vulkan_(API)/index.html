Vulkan

Vulkan is a low-level, cross-platform API and open standard for 3D graphics and computing. It was intended to address the shortcomings of OpenGL, providing a higher-performance alternative. Like OpenGL, Vulkan targets high-performance real-time 3D graphics applications, such as video games and interactive media, and highly parallelized computing.

Vulkan is maintained by the not-for-profit technology consortium Khronos Group. It was announced at GDC 2015 by the Khronos Group, and the first version was released in February 2016. Vulkan was initially referred to as the "next generation OpenGL initiative" or glNext.

Design

In contrast to OpenGL, Vulkan was designed from the ground up with consideration for multithreading and modern GPUs. Rendering state is encapsulated in pre-built pipeline objects, work is recorded into command buffers that can be generated in parallel across multiple CPU threads, and memory management and synchronization are handled explicitly by the application. This shifts much of the driver complexity into application code and engine middleware, reducing CPU overhead and making performance more predictable.

Vulkan supports compute shaders as well as graphics, and uses the SPIR-V intermediate representation for shaders. Extensions have added support for ray tracing, mesh shading, and video encoding and decoding.

Adoption

Vulkan is supported on Windows, Linux, Android, and (via the MoltenVK translation layer) Apple platforms. It is used by game engines such as Unreal Engine and Unity, and underlies the Proton compatibility layer that runs Windows games on Linux.
