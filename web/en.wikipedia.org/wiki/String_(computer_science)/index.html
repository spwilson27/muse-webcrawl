String (computer science)

A string is a finite sequence of symbols — usually characters — from an alphabet.

In computer programming, a string is traditionally a sequence of characters, either as a literal constant or as some kind of variable. The latter may allow its elements to be mutated and the length changed, or it may be fixed (after creation). A string is generally considered a data type and is often implemented as an array data structure of bytes (or words) that stores a sequence of elements — typically characters — using some character encoding. In formal language theory, a string is defined as a finite sequence of symbols chosen from a set called an alphabet.

String datatypes

Most programming languages provide a string datatype, whether built in (C#, Java, Python, JavaScript, Rust) or via a standard library (C++'s std::string, C strings as char arrays). Common operations include concatenation, substring extraction, searching (index-of), comparison, splitting, joining, case conversion, and formatting/interpolation. Regular expressions provide a powerful pattern-matching language over strings.

Representations

  • Null-terminated strings (C-style): characters followed by a zero byte; length must be computed by scanning.
  • Length-prefixed strings (Pascal-style): an integer stores the length before the character data.
  • Ropes: a binary tree of small string pieces, making concatenation and insertion into huge strings efficient.
  • Interned strings: identical literal strings share one copy in memory.

Character encodings range from ASCII and Latin-1 to Unicode encodings UTF-8, UTF-16, and UTF-32. Whether a "character" is a byte, a code unit, a code point, or a grapheme cluster is a frequent source of bugs.

String algorithms

Classical algorithms on strings include substring search (Knuth–Morris–Pratt, Boyer–Moore, Rabin–Karp), edit distance (Levenshtein), suffix arrays and suffix trees, and longest common subsequence. Stringology — the study of string algorithms — underpins text editors, search engines, bioinformatics sequence analysis, and data compression.

Security

Improper handling of strings underlies major vulnerability classes: buffer overflows in fixed buffers, format-string attacks, and injection attacks (SQL injection, cross-site scripting) where untrusted string data is treated as code.
