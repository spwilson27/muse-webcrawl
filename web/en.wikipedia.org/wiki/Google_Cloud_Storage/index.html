Google Cloud Storage is a RESTful online file storage web service for storing and accessing data on Google Cloud Platform infrastructure. The service combines the performance and scalability of Google's cloud with advanced security and sharing capabilities. It is an Infrastructure as a Service (IaaS), comparable to Amazon S3.

Features

Cloud Storage stores objects inside containers called buckets. Each object is identified by a unique key and is accessible via a REST API, the JSON API, an XML API, and client libraries for many programming languages. Data is encrypted at rest and in transit, and access is controlled through Identity and Access Management (IAM) roles and access control lists.

Storage classes

Cloud Storage offers several storage classes optimised for different access patterns: Standard Storage for frequently accessed data, Nearline Storage and Coldline Storage for infrequently accessed backups and archives, and Archive Storage for long-term retention. Object Lifecycle Management rules can automatically transition objects between classes or delete them based on age and other conditions.

Design

Google Cloud Storage stores data redundantly across multiple locations, offering durability of 99.999999999% (eleven nines) annually. It supports strongly consistent reads and writes, versioning of objects, and interoperability with Amazon S3 APIs.
