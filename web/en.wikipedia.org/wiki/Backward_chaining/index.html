Backward chaining

Backward chaining (or backward reasoning) is an inference method used in automated reasoning, theorem provers, proof assistants, rule engines and expert systems. It is a goal-driven strategy: starting from a goal (a statement to be proved or a question to be answered), the system works backwards through rules whose conclusions match the goal, replacing it with the rules' premises as new sub-goals, until it reaches facts known to be true.

Implementation

Backward chaining is the reasoning strategy of the logic programming language Prolog, and of classic expert system shells such as EMYCIN, which derived it from the medical consultation system MYCIN. Because it only explores rules relevant to the goal, it is often more efficient than the alternative, forward chaining, which starts from known facts and derives everything that follows. The trade-off is that backward chaining must manage goal stacks and can revisit sub-goals unless memoisation is used.

Related fields

The same name is used in applied behaviour analysis for teaching a multi-step task by first training the final step, and in supply-chain management with a different meaning. In artificial intelligence, backward chaining remains a foundational concept for knowledge-based systems and automated planning.
