Cantor's theorem

In set theory, Cantor's theorem states that for any set, the set of all its subsets (its power set) has a strictly greater cardinality than the set itself. It was proved by Georg Cantor in 1891 using a diagonal argument.

Field: Set theory
Author: Georg Cantor

Proof idea

For any function from a set A to its power set, one can form the set of elements not belonging to their own image; this set cannot be in the image, so no such function is surjective.

Consequences

The theorem implies an infinite hierarchy of infinite cardinalities, with no largest cardinal number.
