Traceroute

From Wikipedia, the free encyclopedia
[Image: Screenshot-style image of traceroute command output listing numbered hops with hostnames and round-trip times]

Traceroute is a computer network diagnostic command for displaying possible routes (paths) and measuring transit delays of packets across an Internet Protocol network. On Windows it is known as tracert; on Unix-like systems, traceroute.

The tool works by exploiting the time-to-live (TTL) field of IP packets. It first sends a packet with TTL 1, which expires at the first router, prompting that router to return an ICMP 'time exceeded' error that reveals its address and the round-trip time. Traceroute then repeats with TTL 2, 3, and so on, mapping each hop until the packet reaches its destination. The original implementation was written by Van Jacobson in 1987, from a suggestion by Steve Deering.

Traceroute is a first resort for diagnosing slow or broken connections: it shows where packets travel and where delays or losses begin — though modern firewalls, load balancers and MPLS tunnels can make its picture incomplete, hiding hops or showing paths that differ from the traffic a user actually sends.
