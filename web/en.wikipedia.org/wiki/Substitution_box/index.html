Substitution box

In cryptography, an S-box (substitution-box) is a basic component of symmetric key algorithms that performs substitution: it takes a fixed number of input bits and transforms them into a (possibly different) number of output bits according to a lookup table. S-boxes are the main source of nonlinearity in block ciphers such as DES and AES.

Design

A good S-box has the property that changing one input bit changes about half of the output bits (the avalanche effect) and that each output bit depends on all input bits. In DES, eight 6×4-bit S-boxes were central to the design; in AES, a single 8×8 S-box based on the multiplicative inverse in the finite field GF(28) is used, chosen for its low differential and linear probabilities.

Analysis

The security of S-boxes is studied through differential and linear cryptanalysis: designers seek tables whose difference distribution table and linear approximation table have low maximum values. Key-dependent and dynamically generated S-boxes are used in some ciphers, such as Blowfish.
