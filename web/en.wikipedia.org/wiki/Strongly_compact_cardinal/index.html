Strongly compact cardinal

In set theory, a strongly compact cardinal is a type of large cardinal. An uncountable cardinal κ is called strongly compact if every κ-complete filter on any set can be extended to a κ-complete ultrafilter. Equivalently, κ is strongly compact if and only if an infinitary logic allowing conjunctions and disjunctions of fewer than κ formulas satisfies a compactness property for theories of arbitrary size: every theory in the logic Lκ,κ all of whose subtheories of size less than some bound are satisfiable is itself satisfiable.

Properties

Every measurable cardinal is strongly compact, and every strongly compact cardinal is a weakly compact cardinal and indeed a Mahlo cardinal; the converses fail. Strong compactness can also be characterised by elementary embeddings: κ is strongly compact if and only if for every set x there is an elementary embedding of the universe into a transitive class with critical point κ that is κ-closed in a suitable sense and covers x.

History

The notion was isolated by Robert Solovay and others in the 1960s, motivated by infinitary logic. The least strongly compact cardinal, if one exists, need not be measurable: it is consistent that the least strongly compact cardinal is the least measurable one, and also consistent (under suitable assumptions) that it is strictly smaller than the least measurable cardinal. A cardinal that is both strongly compact and supercompact-related strengthenings lead to the notion of supercompact cardinal introduced by Solovay and Reinhardt.
