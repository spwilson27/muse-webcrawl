typedef

typedef is a reserved keyword in the programming languages C, C++, and Objective-C. It is used to create an additional name (alias) for another data type; it does not create a new type. As such, it is often used to simplify the syntax of declaring complex data structures consisting of struct and union types, although it is also commonly used to provide specific descriptive type names for integer data types of varying sizes.

Usage in C

The syntax of a typedef declaration follows the syntax of an ordinary variable declaration, preceded by the keyword typedef; the identifier that would name the variable instead names the new type alias. For example:

typedef int Length;
Length l = 42;

A common use is to remove the need for the struct keyword in C when declaring variables of a structure type:

typedef struct {
    int x;
    int y;
} Point;

Point p = {10, 20};

typedef is also frequently used for function pointer types, which can otherwise have confusing syntax, and in portable code to define fixed-width integer aliases such as those standardized in the <stdint.h> header.

In C++

In C++, typedef remains available, but the using alias declaration introduced in C++11 is often preferred, especially because it supports alias templates:

using Length = int;
