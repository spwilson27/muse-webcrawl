Duplicate code

From Wikipedia, the free encyclopedia

Duplicate code (also called code duplication) is a sequence of source code that occurs more than once, either within the same program or in different programs owned or maintained by the same entity. Duplicate code is generally considered undesirable for reasons similar to those that motivate the don't repeat yourself (DRY) principle.

Causes

Duplication commonly arises from copy-and-paste programming, in which a developer copies a working block of code and modifies it rather than creating a reusable abstraction. It can also appear when the same logic is independently implemented by different programmers, when a language lacks convenient abstraction mechanisms, or when performance or readability concerns lead developers to unroll or special-case code deliberately.

Problems

The main difficulty with duplicated code is maintenance: a bug fixed in one copy must be fixed in every copy, and developers may not know all the places a fragment occurs. Duplication also increases code size, makes programs harder to understand, and can produce inconsistent behaviour when copies diverge over time.

Detection and removal

Automated clone-detection tools analyse source code — at the level of raw text, tokens, abstract syntax trees or program dependence graphs — to find exact or near-miss copies. The standard remedy is refactoring: extracting the common behaviour into a function, class, library or other shared abstraction, a practice related to the rule of three. In some cases, however, small amounts of duplication are accepted as preferable to a premature or overly complex abstraction.
