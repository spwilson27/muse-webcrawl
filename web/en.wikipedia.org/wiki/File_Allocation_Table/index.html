File Allocation Table

File Allocation Table (FAT) is a file system developed for personal computers and was the default filesystem for MS-DOS and Windows 9x operating systems. Originally developed in 1977 for use on floppy disks, it was adapted for use on hard disks and other devices.

Design

The FAT file system uses a table that the operating system maintains on the volume, mapping each cluster to an entry that indicates whether the cluster is free, in use, the next cluster in a file's chain, or the end of the chain. The directory entries store file names, sizes, and starting cluster numbers.

Variants

The major variants are FAT12, FAT16, and FAT32, named for the number of bits in each table entry. Microsoft later developed exFAT to overcome FAT32's 4 GiB file-size limit while retaining simplicity for flash media. FAT remains widely used on removable media such as USB drives and SD cards for compatibility.
