Magnetic-core memory

Magnetic-core memory was the predominant form of random-access computer memory between about 1955 and 1975. It stored information in the magnetization of tiny ferrite rings — cores — threaded on wires in a grid. Each core stored one bit, magnetized clockwise or counterclockwise to represent 1 or 0.

Operation

Cores were arranged in planes, with X and Y drive wires passing through each core. To write or read a selected core, current pulses were sent simultaneously along one X and one Y wire; only the core at the intersection received the full field needed to flip its magnetic state (the coincident-current technique). Reading was destructive — sensing whether a core flipped also reset it — so a restore cycle followed each read. A third (or fourth) wire, the sense/inhibit line, detected the induced pulse when a core changed state.

History

The technology was developed in the late 1940s and early 1950s, with key work by Jay Forrester at MIT for the Whirlwind computer, Frederick Viehe, and An Wang. Core memory was non-volatile: it retained data without power, a property few succeeding technologies share. It was used in systems from the IBM System/360 to the Apollo Guidance Computer, whose core rope memory variant carried the flight software.

Decline

Core planes were assembled largely by hand, making the technology expensive — about a dollar per bit in early forms, falling to roughly a cent per bit. Semiconductor memory, especially Intel's 1103 DRAM chip of 1970, offered higher density and lower cost, and by the mid-1970s core memory was largely obsolete. The term "core dump" for a memory image survives as a legacy of the era.
