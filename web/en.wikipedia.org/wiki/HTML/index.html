HTML

From Wikipedia, the free encyclopedia
[Image: A text editor showing HTML markup with tags highlighted]

The HyperText Markup Language (HTML) is the standard markup language for documents designed to be displayed in a web browser. It structures content with elements such as headings, paragraphs, links, and images; browsers render the result, styled by CSS and made interactive by JavaScript.

HTML was invented by Tim Berners-Lee at CERN in 1989–91 as part of the World Wide Web, adapting ideas from SGML. HTML 2.0 (1995) was the first standard; HTML5 (standardised 2014 by the W3C, now maintained as a 'living standard' by WHATWG) added native video, canvas graphics, and semantic elements.

Structure

An HTML document consists of nested elements denoted by tags in angle brackets (e.g. <p> for paragraph, <a href=...> for a hyperlink), forming a tree — the Document Object Model (DOM) — that scripts can manipulate. Attributes modify elements; the <head> holds metadata and the <body> the visible content.

HTML is not a programming language but a markup language: it describes structure and meaning, leaving presentation to CSS and behaviour to JavaScript ('separation of concerns').

Development

The web's growth produced browser wars and competing dialects in the 1990s; the WHATWG, formed by browser vendors in 2004, eventually took over the standard with its continuously updated HTML Living Standard. Accessibility (semantic markup, ARIA) is a central modern concern.
