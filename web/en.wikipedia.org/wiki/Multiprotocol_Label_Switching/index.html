Multiprotocol Label Switching

Multiprotocol Label Switching (MPLS) is a routing technique in telecommunications networks that directs data from one node to the next based on labels rather than network addresses. It operates between the data link layer and the network layer of the OSI model and is sometimes described as a "layer 2.5" protocol. MPLS can encapsulate packets of various network protocols, hence its name.

Operation

In an MPLS network, ingress routers — called label edge routers (LERs) — attach a short, fixed-length label to each packet, assigning it to a forwarding equivalence class (FEC). Interior routers, called label switch routers (LSRs), forward packets by swapping labels according to pre-established label-switched paths (LSPs), without examining the packet's network-layer header. Labels are distributed between routers using protocols such as the Label Distribution Protocol (LDP) or RSVP-TE.

History

MPLS grew out of mid-1990s efforts to improve IP routing speed, including Cisco's Tag Switching and Ipsilon's IP Switching. The IETF MPLS working group standardised the technology in RFC 3031 (2001), "Multiprotocol Label Switching Architecture". Because forwarding decisions use a simple label lookup, MPLS originally offered a performance advantage over longest-prefix-match IP lookups; modern routers perform IP lookups in hardware, so MPLS is now valued mainly for traffic engineering and VPN services.

Uses

MPLS is widely used by service providers to build virtual private networks (MPLS VPNs), to perform traffic engineering by steering traffic along explicit paths, and to offer quality-of-service guarantees. Generalised MPLS (GMPLS) extends label switching to optical and time-division networks.
