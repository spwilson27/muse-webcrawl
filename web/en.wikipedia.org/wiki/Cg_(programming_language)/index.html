Cg (programming language)

From Wikipedia, the free encyclopedia

Cg (short for C for graphics) is a high-level shading language developed by Nvidia in collaboration with Microsoft for programming vertex and pixel shaders. It is based on the C programming language and shares many of its features with Microsoft's HLSL, with which it was developed concurrently.

Design

Cg programs define vertex, geometry and fragment (pixel) shaders executed on the GPU. The language adds vector and matrix types, swizzling, and built-in functions suited to graphics computation. A profile system lets a single Cg program be compiled to the instruction sets of different graphics APIs, including OpenGL and DirectX, and to platform-specific targets such as the PlayStation 3.

History

Cg was introduced in 2002 alongside Nvidia's GeForce FX series of graphics cards. It was widely used in game development and professional graphics before being deprecated: Nvidia released the final version of the Cg Toolkit (3.1) in 2012 and has since recommended GLSL and HLSL directly. Legacy engines and emulators still contain substantial Cg shader code.
