Stack (abstract data type)

In computer science, a stack is an abstract data type that serves as a collection of elements governed by the last in, first out (LIFO) principle: the most recently added element is the first to be removed. The name is an analogy with a stack of physical objects such as plates.

Push adds an element to the top; pop removes the top element

Operations

  • Push: add an element to the top of the stack.
  • Pop: remove and return the top element.
  • Peek (or top): return the top element without removing it.
  • isEmpty: test whether the stack contains no elements.

Implementation and uses

Stacks are implemented with arrays or linked lists. They underpin call stacks in program execution, expression evaluation (including reverse Polish notation and the shunting-yard algorithm), syntax parsing, backtracking algorithms and depth-first search, and undo mechanisms in editors.
