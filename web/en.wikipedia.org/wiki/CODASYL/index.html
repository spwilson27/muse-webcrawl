CODASYL, the Conference on Data Systems Languages (later the Committee on Data Systems Languages), was a consortium formed in 1959 by the United States Department of Defense together with computer manufacturers and users. It is best known for developing the COBOL programming language and for standardizing the network model for database management systems.

The CODASYL network model represented records connected by named set types.

History

CODASYL's short-range committee produced the initial COBOL specification in 1960, and the language went on to dominate business data processing for decades. CODASYL standing committees continued to maintain COBOL standards for years afterwards.

The database work

In the late 1960s CODASYL's Data Base Task Group (DBTG) issued reports (1969 and 1971) defining a standard database model based on Charles Bachman's network model: records organized into record types, linked by set types forming a network or plex structure, with a data definition language for schemas and a data manipulation language embedded in a host language (typically COBOL). Commercial systems such as Cullinet's IDMS and DEC's DBMS implemented the CODASYL proposals.

The network model was one of the two dominant database paradigms of the 1970s, competing with the hierarchical model of IBM's IMS, before both were largely displaced by the relational model championed by Edgar F. Codd.
