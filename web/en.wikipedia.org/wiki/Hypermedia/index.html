Hypermedia

Hypermedia is an extension of hypertext in which graphics, audio, video, plain text and hyperlinks intertwine to create a generally non-linear medium of information. The term was coined by Ted Nelson in 1965.

Concept

Where hypertext links pieces of text, hypermedia links multiple media types, so a user can navigate between text, images, sound and video in any order. The World Wide Web is the canonical example: a web page may combine all of these media connected by links. Hypermedia contrasts with the related term multimedia, which describes linear presentations combining media without navigational structure.

Hypermedia in APIs

In software architecture, hypermedia is used as a constraint of REST-style web services: responses include links describing the actions available to the client, an idea known as HATEOAS ("hypermedia as the engine of application state"). This allows clients to discover transitions dynamically rather than relying on out-of-band documentation.

History

Early hypermedia systems included the Aspen Movie Map (1978), which let users take a virtual tour through photographs of a city, and Apple's HyperCard (1987), which popularised linked "cards" combining text, graphics and buttons before the Web became widespread.
