Feature (machine learning)

In machine learning, features are the measurable properties used as model inputs.

In machine learning and pattern recognition, a feature is an individual measurable property or characteristic of a data instance being observed. Choosing informative, discriminating and independent features is a crucial element of effective algorithms in pattern recognition, classification and regression. Features are usually numeric or categorical, and a set of features for one example is organised into a feature vector, with the space of all possible vectors forming the feature space.

Definition and terminology

A feature is essentially an input variable used by a learning algorithm to make predictions. Examples include the words of a document in text classification, pixel intensities in image recognition, or a patient's age and blood pressure in a medical model. The concept overlaps with the explanatory variables of statistics, though features need not correspond to naturally meaningful quantities — they can be engineered combinations of raw measurements.

Feature engineering

Feature engineering is the process of selecting, transforming, and creating features from raw data to improve model performance. Techniques include normalisation and scaling, encoding categorical variables (e.g. one-hot encoding), binning, polynomial expansions, and aggregations. Automated feature engineering and deep learning's representation learning reduce the need for manual design, since neural networks can learn useful features directly from data.

Feature selection

Feature selection aims to keep only the most relevant features, reducing overfitting, training time, and storage. Methods are commonly grouped into filter methods (based on statistical tests), wrapper methods (searching subsets by model performance), and embedded methods (selection during training, such as L1 regularisation).

Dimensionality

Large feature spaces can make learning difficult — a phenomenon known as the curse of dimensionality. Dimensionality reduction techniques such as principal component analysis (PCA) and t-SNE project features into lower-dimensional spaces while preserving much of their information.
