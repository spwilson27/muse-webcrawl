Line score

In baseball, the line score is a compact summary of a game that lists, for each team, the runs scored in each inning together with the totals for runs, hits, and errors (abbreviated R, H, and E). It traditionally appears at the top of the fuller box score.

Format

Each column of the line score represents one inning; innings in which a team does not score are shown as 0, and an "x" is placed in the final inning column for the home team if it does not need to bat because it already leads. Games longer than nine innings extend the row with additional columns. Pitchers' decisions — the winning pitcher, losing pitcher, and any save — are usually printed beneath the line score.

Use

The line score allows a reader to see at a glance the flow of a game: when scoring occurred, whether a team rallied late, and how cleanly each side played in the field. Newspapers have printed line scores since the 19th century, and the format is still displayed by broadcasters and scoreboards.
