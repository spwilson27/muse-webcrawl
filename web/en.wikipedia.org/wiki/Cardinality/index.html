Cardinality

From Wikipedia, the free encyclopedia

In mathematics, the cardinality of a set is a measure of the number of elements of the set. For a finite set, the cardinality is simply a natural number: the set {a, b, c} has cardinality 3. The concept extends to infinite sets through the theory of cardinal numbers, developed by Georg Cantor in the 1870s, which shows that some infinities are larger than others.

Comparing sets

Two sets A and B have the same cardinality, written |A| = |B|, if there exists a bijection (a one-to-one correspondence) between them. A set is countably infinite if it has the same cardinality as the natural numbers; its cardinal is denoted ℵ0 (aleph-null). Cantor's diagonal argument (1891) shows that the real numbers cannot be put in bijection with the naturals, so ℝ has a strictly greater cardinality, often written 𝔠 (the cardinality of the continuum). Cantor's theorem generalises this: for any set, its power set has strictly greater cardinality still, generating an endless hierarchy of infinite cardinals.

The continuum hypothesis

Cantor's continuum hypothesis asks whether any set has cardinality strictly between that of the integers and that of the reals; equivalently, whether 2ℵ0 = ℵ1. Work by Kurt Gödel (1940) and Paul Cohen (1963) proved it independent of the standard axioms of set theory (ZFC): it can neither be proved nor disproved from them.

Other uses

In database design, cardinality describes the numerical relationship between rows of two tables (one-to-one, one-to-many, many-to-many); in data modelling and SQL query optimisation it also refers to the number of distinct values in a column.
