Root-finding algorithm

In numerical analysis, a root-finding algorithm is a method for finding roots of continuous functions — values x for which f(x) = 0. Such problems arise throughout science and engineering, and because most equations cannot be solved in closed form, iterative approximations are used.

Bracketing methods

Bracketing methods start from an interval where the function changes sign and shrink it while keeping the root inside. The bisection method halves the interval each step — slow but guaranteed. The false position (regula falsi) method uses linear interpolation of the endpoints and usually converges faster; Brent's method combines bisection, secant and inverse quadratic interpolation and is a standard robust choice.

Open methods

Newton's method (Newton–Raphson) uses the derivative to extrapolate from a single starting guess and converges quadratically near a simple root, but can diverge for poor starting points. The secant method replaces the derivative with a finite difference. Fixed-point iteration recasts the equation as x = g(x). For polynomials, specialized algorithms such as the Durand–Kerner method find all roots simultaneously.
