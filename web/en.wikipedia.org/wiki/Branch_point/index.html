Branch point

In the mathematical field of complex analysis, a branch point of a multi-valued function is a point such that the function is discontinuous when going around a small closed curve (loop) around the branch point. More precisely, on traversing the closed curve completely, the function approaches different values.

Categories

Branch points fall into three broad categories: algebraic branch points, transcendental branch points, and logarithmic branch points. The archetypal example is the complex logarithm: looping once around the origin increases the logarithm by 2πi, and the origin is a logarithmic branch point of infinite order. The square root function has an algebraic branch point of order two at the origin.

Branch cuts

A branch cut is a curve in the complex plane across which a multi-valued function is defined to be discontinuous, chosen so that a single-valued branch can be defined on the remaining domain. Riemann surfaces provide a geometric way of avoiding branch cuts by treating the function as single-valued on a layered surface.
