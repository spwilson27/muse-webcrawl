Smooth function

Smooth function
NotationC∞
FieldMathematical analysis, differential geometry

In mathematical analysis, the smoothness of a function is a property measured by the number of continuous derivatives it has over some domain, called differentiability class. A function of class C∞ — one that has derivatives of all orders — is called a smooth function, or infinitely differentiable function.

Differentiability classes

A function is of class C0 if it is continuous, C1 if its first derivative exists and is continuous, and Ck if its first k derivatives exist and the k-th is continuous. Every analytic function is smooth, but not every smooth function is analytic: the classic example is f(x) = e−1/x for x > 0 and f(x) = 0 otherwise, which is smooth everywhere but has a Taylor series at 0 that does not reproduce it.

A bump function: smooth, nonzero only on a bounded interval

Applications

Smooth functions are the basic objects of differential geometry: a smooth manifold is built from charts with smooth transition maps, and smooth maps between manifolds allow calculus on them. Smooth bump functions and partitions of unity—families of smooth functions that patch local constructions into global ones—are indispensable tools. Mollifiers, smooth approximations of the identity, are used to approximate rough functions by smooth ones in the theory of partial differential equations.
