JMRI (Java Model Railroad Interface) is an open-source software suite for computer control of model railroads. It provides tools for programming Digital Command Control (DCC) decoders, operating trains, controlling layout accessories such as turnouts and signals, and automating layout operation. JMRI runs on Windows, macOS, and Linux using the Java platform.

Components

The suite includes several main applications. DecoderPro simplifies programming the configuration variables of locomotive decoders through graphical interfaces that mask the underlying register details. PanelPro supports the creation of graphical control panels for layout operation, including signalling logic and dispatching. Additional tools handle operations (train scheduling and car forwarding), roster management, and throttles, including apps for smartphones that act as Wi-Fi throttles.

History and legal case

The JMRI project began in the early 2000s, led by developer Bob Jacobsen. JMRI became the subject of a landmark copyright case, Jacobsen v. Katzer, after a commercial developer incorporated JMRI code into a proprietary product without complying with its open-source Artistic License. In 2008 the United States Court of Appeals for the Federal Circuit held that the terms of an open-source licence are enforceable as conditions of a copyright licence, a ruling widely regarded as a foundational precedent for open-source licensing in the United States. The case was settled in 2010.

Community

JMRI is maintained by a large volunteer community and supports hardware from most DCC manufacturers, including Digitrax, NCE, Lenz, and ESU, as well as DIY systems. Its decoder definitions database covers thousands of decoder models.
