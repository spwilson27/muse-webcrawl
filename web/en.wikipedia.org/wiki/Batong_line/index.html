Batong line

Tool geometry relative to the batong line

The batong line is a reference line used in the geometry of single-point cutting tools, particularly in woodturning and metal lathe work in Chinese machining practice, from which the tool's working angles are measured. The term derives from the Chinese name for the reference edge used when grinding and setting a turning tool against the workpiece.

Definition

In tool geometry, the angles of rake, clearance, and inclination that determine how a tool cuts are all measured from defined reference planes and lines. The batong line serves as the datum — the line against which the operator aligns the tool when setting its height relative to the axis of rotation. Correct alignment on the line ensures the tool's presented rake and clearance angles match those ground into it.

Application

Setting a lathe tool above or below the workpiece centerline effectively changes its rake and clearance, which can cause rubbing, poor surface finish, or tool digging-in on small-diameter work. Machinists use the batong line concept alongside center-height gauges to position tool bits consistently, especially in toolroom and instructional contexts.
