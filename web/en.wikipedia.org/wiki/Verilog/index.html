Verilog

Verilog, standardized as IEEE 1364, is a hardware description language (HDL) used to model electronic systems. It is most commonly used in the design and verification of digital circuits at the register-transfer level (RTL) of abstraction. It is also used in the verification of analog circuits and mixed-signal circuits, as well as in the design of genetic circuits.

History

Verilog was created by Phil Moorby and Prabhu Goel during the winter of 1983/1984 at Gateway Design Automation. Cadence Design Systems acquired Gateway in 1989 and placed Verilog in the public domain in 1990 under the Open Verilog International organization. It was standardized by the IEEE as Standard 1364-1995, with revisions in 2001 and 2005. SystemVerilog (IEEE 1800), a major extension adding verification and object-oriented features, later merged with the base language.

Overview

A Verilog design consists of modules with defined input and output ports. Inside a module, the designer describes hardware using continuous assignments (assign), procedural blocks (always and initial), and instantiations of other modules. A classic example is a D flip-flop:

module dff (input clk, input d, output reg q);
  always @(posedge clk)
    q <= d;
endmodule

Verilog models hardware concurrency: statements in separate always blocks execute in parallel, unlike conventional software. Values typically use a four-state system (0, 1, X for unknown, and Z for high impedance).
