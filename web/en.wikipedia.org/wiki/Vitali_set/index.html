Vitali set

In mathematics, a Vitali set is an elementary example of a set of real numbers that is not Lebesgue measurable. The Vitali theorem is the existence theorem that there are such sets, proved by Giuseppe Vitali in 1905. Every Vitali set is uncountable, and its construction depends on the axiom of choice.

Construction

Consider the unit interval [0, 1]. Define an equivalence relation on it by declaring x ~ y whenever x − y is a rational number. The equivalence classes partition [0, 1], and each class is a countable, dense subset of the interval. By the axiom of choice, one may select exactly one representative from each class; the set V of all selected representatives is a Vitali set.

Non-measurability

Suppose V were Lebesgue measurable. Translating V by every rational number q in [−1, 1] produces a countable family of disjoint sets whose union covers [0, 1] and is contained in [−1, 2]. All these translates have the same measure as V. If the measure of V were zero, the union would have measure zero, contradicting that it covers [0, 1]; if it were positive, the union would have infinite measure, contradicting that it lies in [−1, 2]. Hence V cannot be measurable.

Related ideas

The same construction underlies the Hausdorff and Banach–Tarski paradoxes, in which the axiom of choice is used to decompose a ball into non-measurable pieces that reassemble into two balls. Robert Solovay showed in 1970 that, if an inaccessible cardinal exists, there is a model of ZF set theory in which every set of reals is Lebesgue measurable — so some form of choice is genuinely necessary for the Vitali construction.
