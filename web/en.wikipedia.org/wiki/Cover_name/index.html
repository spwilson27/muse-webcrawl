Cover name

A cover name or pen name equivalent in intelligence work is a pseudonym or code name adopted by a person, organisation, operation or project to conceal its true identity. In espionage, an intelligence officer or agent operating under a false identity is said to work under cover, and the cover name is the name by which they are known in that role.

Types of cover

Official cover means the officer works openly in a declared position, usually at an embassy or consulate, while secretly performing intelligence duties; the cover name may simply be their real name in a false job. Non-official cover (NOC) is far riskier: the officer poses as a private citizen — a businessperson, journalist or aid worker — with no link to their government, which will deny all knowledge if they are caught. A complete false biography supporting the cover name is called a legend.

Operation and project code names

Cover names are also given to operations so that they can be discussed without revealing their purpose: examples include Operation Overlord for the Normandy landings and the Manhattan Project for the Second World War atomic bomb programme. Modern militaries generate code names randomly to avoid giving clues, a practice adopted after Winston Churchill complained that evocative names could reveal intentions or trivialise operations in which men might die.

In organised crime and policing, informants and undercover officers likewise operate under cover names, and journalists protect sources with pseudonyms in the same spirit.
