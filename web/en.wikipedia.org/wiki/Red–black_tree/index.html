Red–black tree

Image placeholder: an example red–black tree.

A red–black tree is a kind of self-balancing binary search tree in computer science. Each node stores an extra bit representing its colour, either red or black. By enforcing constraints on the colours along paths from the root to the leaves, the tree guarantees that its height stays within a logarithmic bound, so that search, insertion and deletion all run in O(log n) worst-case time.

Properties

Every red–black tree satisfies these properties: each node is red or black; the root is black; all leaves (sentinel NIL nodes) are black; the children of a red node are black; and every path from a given node to its descendant leaves passes through the same number of black nodes.

Background

Rudolf Bayer described the symmetric binary B-tree in 1972, and Leonidas J. Guibas and Robert Sedgewick derived the red–black formulation in 1978. The structure underlies the map and set containers in many programming libraries, including those of C++ and Java, and is used in kernels and databases where predictable performance is required.
