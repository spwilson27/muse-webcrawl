K-nearest neighbors algorithm

In statistics, the k-nearest neighbors algorithm (k-NN) is a non-parametric supervised learning method first developed by Evelyn Fix and Joseph Hodges in 1951, and later expanded by Thomas Cover. It is used for classification and regression: in both cases the input consists of the k closest training examples in a data set, with the output depending on the task.

Classification

In k-NN classification, the output is a class membership. An object is classified by a plurality vote of its neighbours, being assigned to the class most common among its k nearest neighbours (with k a small positive integer, often odd to avoid ties). If k = 1, the object is simply assigned the class of its single nearest neighbour.

Regression

In k-NN regression, the output is a continuous value — the average (possibly distance-weighted) of the values of the k nearest neighbours.

Features and limitations

Because the algorithm only stores the training data and defers computation until prediction, it is an example of instance-based or "lazy" learning. Neighbours are usually found with a distance metric such as Euclidean distance, and features are typically normalised. The value of k controls the bias–variance trade-off and is usually chosen by cross-validation. The method suffers from the curse of dimensionality and can be slow on large data sets; data structures such as k-d trees and ball trees, and approximate nearest-neighbour methods, mitigate the cost. Cover and Hart showed in 1967 that the error rate of the 1-NN rule is at most twice the Bayes error rate.

Applications

k-NN is used in pattern recognition, recommender systems, image classification, missing-data imputation and anomaly detection.
