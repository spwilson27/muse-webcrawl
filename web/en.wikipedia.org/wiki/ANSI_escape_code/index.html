ANSI escape code

From Wikipedia, the free encyclopedia

[Image placeholder: A terminal window displaying coloured text produced by ANSI SGR sequences]

ANSI escape sequences are a standard for in-band signalling to control cursor location, colour, font styling, and other options on video text terminals and terminal emulators. Certain sequences of bytes, most starting with the ASCII escape character (ESC, hexadecimal 0x1B) and a bracket character [, are embedded into text and interpreted by the terminal rather than displayed.

History

The sequences descend from the standards of the 1970s: the ECMA-48 standard and the American ANSI X3.64 standard, popularised by DEC's VT100 terminal (1978), whose control set became the de facto norm. The DOS device driver ANSI.SYS brought the sequences to IBM PC compatibles, and they remain universally supported by Unix and Linux terminal emulators and, since Windows 10, by the Windows console.

Control sequence introducer (CSI)

Most functions begin with the Control Sequence Introducer, ESC [, followed by numeric parameters separated by semicolons and a final letter indicating the function. Examples:

SequenceEffect
ESC[31mSet foreground colour to red (SGR)
ESC[1mBold text (SGR)
ESC[0mReset all attributes
ESC[2JClear entire screen
ESC[<row>;<col>HMove cursor to row and column
ESC[KErase from cursor to end of line

The SGR (Select Graphic Rendition) function, ending in m, controls text attributes including bold, italic, underline, and colours — originally 8 colours, extended to 256-colour palettes (ESC[38;5;<n>m) and 24-bit "true colour" in modern emulators.
