The Globus Toolkit was an open-source software toolkit for building grid computing systems and applications, developed by the Globus Alliance, a collaboration led by Ian Foster and Carl Kesselman of Argonne National Laboratory and the University of Chicago. It provided the foundational middleware used by many of the world's scientific computing grids, including those supporting the Large Hadron Collider and the Earth System Grid.

Components

The toolkit implemented core services for distributed computing: the Grid Resource Allocation and Management (GRAM) protocol for job submission, GridFTP for high-performance data transfer, the Grid Security Infrastructure (GSI) for authentication based on public-key cryptography and X.509 proxy certificates, and information services (MDS) for resource discovery and monitoring.

Versions

Globus Toolkit 2 (2001) established the toolkit's early architecture. GT3 (2003) introduced an implementation of the Open Grid Services Architecture based on web services, and GT4 (2005), aligned with the Web Services Resource Framework, became the most widely deployed version. Later releases (GT5 and GT6) streamlined the components. Development of the toolkit wound down in the late 2010s as the community's focus shifted to the Globus cloud service for research data management, and support for the toolkit formally ended in 2018–2023.

Legacy

The Globus Toolkit shaped the practice of grid and distributed high-throughput computing for two decades. Its successor, the Globus platform operated by the University of Chicago, provides hosted services for data transfer, sharing and automation used by national laboratories and universities worldwide.
