Finite impulse response

In signal processing, a finite impulse response (FIR) filter is a filter whose impulse response (or response to any finite length input) is of finite duration, because it settles to zero in finite time. This is in contrast to infinite impulse response (IIR) filters, which may have internal feedback and may continue to respond indefinitely.

Properties

FIR filters are inherently stable and can be designed to have exactly linear phase, which is often desirable in audio and data communications. They are typically implemented as a weighted moving average of delayed input samples, using structures such as the transversal (tapped delay line) form.

Design methods

Common design techniques include the window method, frequency sampling, and the Parks–McClellan (Remez) algorithm for equiripple designs.
