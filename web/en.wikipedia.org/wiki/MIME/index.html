MIME

Multipurpose Internet Mail Extensions (MIME) is a standard that extends the format of email messages to support text in character sets other than ASCII, as well as attachments of audio, video, images and application files. Message bodies may consist of multiple parts, and header information may be encoded in character sets other than ASCII. MIME was first defined in 1992 in RFC 1341 and 1342 and updated by RFCs 2045–2049. Virtually all human-written Internet email and a substantial proportion of automated email is transmitted in MIME format over SMTP.

Overview

The basic Internet email format defined by RFC 822 allowed only 7-bit ASCII text, which made it impossible to send binary data or text in many languages directly. MIME added header fields such as Content-Type, which declares the media type of the message body (for example text/html or image/jpeg), and Content-Transfer-Encoding, which describes an encoding such as Base64 or quoted-printable used to represent 8-bit or binary data using 7-bit characters.

Multipart messages

Using a multipart content type with a unique boundary string, a single message can carry several body parts — for instance a plain-text and an HTML version of the same message (multipart/alternative), or a cover note together with file attachments (multipart/mixed). MIME types are also used far beyond email: web servers and browsers use them to identify the content of files and HTTP responses, and they are maintained as a registry by the Internet Assigned Numbers Authority (IANA).
