In graph theory, a Hamiltonian path is a path in an undirected or directed graph that visits each vertex exactly once. A Hamiltonian cycle (or circuit) is a Hamiltonian path that returns to its starting vertex, forming a cycle. A graph containing such a path is called traceable; one containing a Hamiltonian cycle is called Hamiltonian.

History

The concepts are named after the Irish mathematician William Rowan Hamilton, whose "icosian game" (1857) challenged players to find a cycle visiting all twenty vertices of a dodecahedron. Earlier, a knight's tour in chess posed a related puzzle, and Thomas Kirkman studied such cycles in polyhedra independently.

Complexity

Determining whether a graph contains a Hamiltonian path or cycle is NP-complete, one of Karp's 21 NP-complete problems, which makes the problem central to computational complexity theory. Despite this, special cases — such as tournaments, which always possess a Hamiltonian path — and sufficient conditions like Dirac's theorem (every vertex has degree at least n/2) and Ore's theorem guarantee Hamiltonicity in dense graphs. Practical algorithms use backtracking, dynamic programming (the Held–Karp style O(2nn2) method), and meet-in-the-middle techniques.

Applications

Hamiltonian paths appear in scheduling, genome assembly, and puzzle design; the travelling salesman problem generalises the Hamiltonian cycle problem by weighting edges and asking for a minimum-weight tour.
