Document Style Semantics and Specification Language

The Document Style Semantics and Specification Language (DSSSL) is an international standard (ISO/IEC 10179:1996) for specifying the formatting and transformation of SGML documents. It provides a language for writing stylesheets that describe how the elements of a structured document should be presented — for example in print or on screen — and for transforming one SGML document structure into another.

Overview

DSSSL is based on a subset of the Scheme programming language. A DSSSL stylesheet contains transformation specifications (mapping a source document tree to a result tree) and style specifications (associating document elements with "flow objects" such as paragraphs, characters, pages and tables, whose formatting characteristics are defined in the standard). A piece of software that applies such specifications, such as James Clark's Jade processor and the later OpenJade, is called a DSSSL engine.

History and influence

Development of DSSSL began in the early 1990s within ISO, in parallel with SGML itself. Although powerful, DSSSL was widely perceived as complex, and it saw only limited adoption; its most notable uses were in the documentation toolchains of projects such as the Linux Documentation Project (via DocBook stylesheets) and the FreeBSD documentation.

DSSSL nevertheless strongly influenced later web technologies: XSLT adopted its tree-transformation model for XML, while CSS took over the simpler styling role for web documents. The word-processing and page-layout vocabularies of XSL Formatting Objects (XSL-FO) also descend in part from DSSSL's flow objects.
