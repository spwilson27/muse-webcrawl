Long-term memory

Long-term memory (LTM) is the stage of the Atkinson–Shiffrin memory model in which informative knowledge is held indefinitely. It contrasts with short-term and working memory, which hold limited information for seconds to minutes. Long-term memory has a vast capacity and can retain information for years or a lifetime.

Types

Following Endel Tulving and Larry Squire, long-term memory is divided into explicit (declarative) memory — conscious recollection of facts (semantic memory) and personal events (episodic memory) — and implicit (nondeclarative) memory, including procedural skills, classical conditioning, and priming. The famous case of patient H.M., who after bilateral medial temporal lobe surgery could not form new explicit memories while retaining procedural learning, demonstrated that these systems are dissociable.

Encoding and consolidation

Information enters long-term memory through encoding, aided by elaboration, organisation, and sleep. Consolidation stabilises memory traces: synaptic consolidation occurs within hours, while systems consolidation — in which memories initially dependent on the hippocampus gradually become supported by the neocortex — may take years. Retrieval can render a memory labile again, a process called reconsolidation.

Forgetting

Long-term forgetting is attributed to decay, interference from other memories, retrieval failure, and motivated forgetting. Despite its durability, long-term memory is reconstructive and prone to distortion, as shown by research on eyewitness testimony and false memories.
