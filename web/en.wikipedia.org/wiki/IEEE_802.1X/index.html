IEEE 802.1X

StandardIEEE 802.1X (first published 2001)
PurposePort-based network access control
FrameworkExtensible Authentication Protocol (EAP)
Typical serverRADIUS

IEEE 802.1X is an IEEE standard for port-based network access control (PNAC). It is part of the IEEE 802.1 group of networking protocols and provides an authentication mechanism to devices wishing to attach to a LAN or WLAN. The standard defines the encapsulation of the Extensible Authentication Protocol (EAP) over IEEE 802, known as EAPOL ("EAP over LAN").

Architecture

802.1X involves three parties: a supplicant (the client device requesting access), an authenticator (the switch or wireless access point controlling the port), and an authentication server (typically a RADIUS server). Before authentication, the authenticator keeps the port in an unauthorized state that passes only EAPOL traffic. The supplicant and server authenticate each other using an EAP method — such as EAP-TLS with certificates, or tunneled methods such as PEAP and EAP-TTLS carrying inner credentials — after which the authenticator opens the port and may assign the client to a VLAN or apply access policies.

Use in networks

The standard is the basis of WPA-Enterprise and WPA2/WPA3-Enterprise wireless security, and of network access control on wired campus networks, where it prevents unauthorised devices from using wall ports. Large federated deployments such as eduroam, the worldwide academic roaming service, use 802.1X with RADIUS proxying so users authenticate against their home institution.

Security considerations

Deployments must choose EAP methods carefully: methods without mutual certificate validation have exposed users to rogue access points and credential theft. Wired 802.1X can also be weakened by devices attached behind an authenticated port, mitigated by modes that authenticate each MAC address separately. 802.1X controls admission to the network but does not itself encrypt traffic; on wireless networks it is combined with link-layer encryption keyed during the EAP exchange.
