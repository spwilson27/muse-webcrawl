M3U

M3U (MP3 URL or Moving Picture Experts Group Audio Layer 3 Uniform Resource Locator in full) is a computer file format for a multimedia playlist. A file with the .m3u extension is a plain-text list of the locations of media files, one per line — originally the file names or paths of MP3 audio files, and later also URLs for streaming media. The format was originally developed for the Winamp media player and has since been supported by most media players.

Format

In its simplest form, an M3U file contains one path or URL per line. Lines may be absolute or relative to the location of the playlist file itself. The extended M3U format adds directives beginning with #. A file begins with the header #EXTM3U, and each entry may be preceded by an #EXTINF directive giving the track duration in seconds and a display title:

#EXTM3U
#EXTINF:245,Artist Name - Track Title
music/track01.mp3
#EXTINF:-1,Live Radio Stream
http://example.com/stream

M3U8 and streaming

The variant with the .m3u8 extension is identical in structure but encoded in UTF-8. M3U8 became particularly important because Apple adopted it as the playlist format for HTTP Live Streaming (HLS), in which playlists reference short media segments and, at the top level, alternative renditions at different bitrates. M3U playlists are also widely used to distribute IPTV channel lists and by internet radio directories.

Support

Support for M3U is nearly universal among media players, including VLC, Windows Media Player (legacy), iTunes/Apple Music, foobar2000 and numerous hardware and mobile players. Unlike proprietary binary playlist formats, M3U files are human-readable and can be created or edited with any text editor.
