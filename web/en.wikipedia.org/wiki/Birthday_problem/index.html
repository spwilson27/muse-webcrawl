Birthday problem

The probability of a shared birthday exceeds 50 percent with only 23 people.

In probability theory, the birthday problem asks for the probability that, in a set of n randomly chosen people, at least two will share the same birthday. Counter-intuitively, the answer exceeds 50 percent for a group of only 23 people, and reaches about 99.9 percent for 70 people — even though there are 365 possible birthdays. It is therefore often called the birthday paradox, though it is not a true paradox, merely a result that conflicts with intuition.

Calculation

The easiest route is to compute the probability that all birthdays are different. With birthdays assumed uniformly distributed over 365 days and independent, the probability that n people all differ is 365/365 × 364/365 × … × (365 − n + 1)/365. The probability of at least one match is one minus this quantity. The intuition-defying result arises because the number of pairs grows quadratically: 23 people make 253 pairs, each a chance for a match. A useful approximation for the group size needed for a 50 percent chance of a collision among d equally likely outcomes is √(2d ln 2) ≈ 1.177√d.

Applications

The same mathematics underlies the birthday attack in cryptography, which exploits collisions in hash functions: a hash with an m-bit output can expect a collision after about 2m/2 evaluations rather than 2m, which is why hash outputs must be twice as long as naive analysis would suggest. Variants of the problem consider near-matches, matches with a specified date, and multiple collisions.
