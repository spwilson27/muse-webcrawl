Cross-entropy

In information theory, the cross-entropy between two probability distributions p and q over the same underlying set of events measures the average number of bits needed to identify an event drawn from the set, if a coding scheme used for the set is optimised for an estimated probability distribution q, rather than the true distribution p.

Definition

The cross-entropy of the distribution q relative to a distribution p over a given set is defined as:

H(p, q) = −Σx p(x) log q(x)

where the sum is over the possible events, and the logarithm is usually base 2 (giving units of bits) or base e (nats). Cross-entropy is related to the entropy H(p) and the Kullback–Leibler divergence DKL(p ‖ q) by:

H(p, q) = H(p) + DKL(p ‖ q)

Since the KL divergence is non-negative, cross-entropy is minimised when q equals p, in which case it equals the entropy of p.

Use in machine learning

Cross-entropy loss (log loss) is the standard loss function for classification problems in machine learning. A neural network trained with cross-entropy against one-hot target labels is, in effect, performing maximum-likelihood estimation of the class probabilities. For binary classification it reduces to the binary cross-entropy; combined with a softmax output layer it yields simple gradients that speed learning, and it underlies the training of large language models, where minimising cross-entropy over next-token predictions is equivalent to minimising perplexity.
