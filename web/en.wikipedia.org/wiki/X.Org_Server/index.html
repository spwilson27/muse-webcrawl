The X.Org Server is the free and open-source implementation of the X Window System display server stewarded by the X.Org Foundation. Released in April 2004 as a fork of XFree86 4.4, it became the dominant X server on Linux and other Unix-like systems, providing the low-level framework for drawing and moving windows on screen and handling keyboard and mouse input.

Architecture

The server implements the X11 protocol and uses a modular driver architecture (DDX) with drivers for graphics hardware, including the generic modesetting driver. Extensions such as RandR (resize and rotate), Composite, XInput and DRI (Direct Rendering Infrastructure) support modern compositing desktops and hardware-accelerated rendering.

History and successors

Development slowed in the 2010s as distributions began migrating to Wayland compositors, which replace X11's network-transparent client-server model with a more direct architecture. The server continues to be maintained for compatibility, and Xwayland allows X11 applications to run within Wayland sessions. Long-lived releases such as X.Org Server 1.20 served for years as the standard version on many distributions.
