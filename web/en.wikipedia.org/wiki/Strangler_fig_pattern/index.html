Strangler fig pattern

The strangler fig pattern (also called the strangler application pattern) is a software design pattern for gradually migrating a legacy system to a new system. It is named after the strangler fig plant, which grows around a host tree and eventually replaces it.

Description

The pattern was described by Martin Fowler, who observed strangler figs in Queensland rainforests. Instead of rewriting a legacy system in a risky "big bang" replacement, developers incrementally build new functionality alongside the old system. Requests are intercepted — often by a facade or proxy — and progressively redirected to the new implementation, while the legacy system handles a shrinking share of the work. When the new system covers everything, the legacy system can be retired.

Use in practice

The pattern is widely used in modernizing monolithic applications into microservices, and in migrating systems between platforms or databases. Its advantages are reduced risk, continuous delivery of value during the migration, and the ability to validate the new system against production traffic before full cutover.
