Minimum-weight triangulation

In computational geometry, a minimum-weight triangulation (MWT) of a set of points or a polygon is a triangulation that minimises the total length of all edges. For point sets, minimising weight tends to avoid very long, skinny triangles, though the related Delaunay triangulation is only an approximation to the true minimum.

Complexity

For a simple polygon, the minimum-weight triangulation can be found in cubic time by dynamic programming. For arbitrary point sets the problem was long of unknown status until Mulzer and Rote proved in 2006 that it is NP-hard, settling a decades-old question.

Applications

Minimum-weight triangulations are used in mesh generation, terrain modelling and graphics, where edge length correlates with interpolation quality and resource costs.
