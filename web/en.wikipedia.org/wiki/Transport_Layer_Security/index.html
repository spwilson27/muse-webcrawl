Transport Layer Security (TLS) is a cryptographic protocol designed to provide communications security over a computer network, such as the Internet. It aims primarily to provide confidentiality and data integrity between two communicating applications, and underlies secure web browsing (HTTPS), email, instant messaging, and voice over IP.

How it works

A TLS connection begins with a handshake in which client and server agree on cipher suites, exchange random values, and authenticate — typically the server (and optionally the client) by means of X.509 certificates issued by a certificate authority. Key exchange (in modern versions, ephemeral Diffie–Hellman) establishes a shared secret with forward secrecy, from which symmetric session keys are derived; the subsequent record layer encrypts and integrity-protects application data, commonly with AEAD ciphers such as AES-GCM or ChaCha20-Poly1305.

Versions

TLS descends from Netscape's Secure Sockets Layer (SSL 2.0, 1995; SSL 3.0, 1996). The IETF standardised TLS 1.0 in 1999, followed by 1.1 (2006), 1.2 (2008), and TLS 1.3 (2018), which removed legacy algorithms, mandated forward secrecy, and reduced the handshake to a single round trip. SSL and TLS versions below 1.2 are deprecated because of attacks such as POODLE and BEAST. A datagram variant, DTLS, serves UDP-based traffic, and the QUIC transport protocol integrates TLS 1.3.
