Polar code (coding theory)

From Wikipedia, the free encyclopedia

In information theory, a polar code is a linear block error-correcting code. The code construction is based on a multiple recursive concatenation of a short kernel code which transforms the physical channel into virtual outer channels. When the number of recursions becomes large, the virtual channels tend to either have high reliability or low reliability (in other words, they polarize or become sparse), and the data bits are allocated to the most reliable channels. Polar codes were proposed by Erdal Arıkan in 2008 and were the first class of codes with an explicit construction able to provably achieve the symmetric capacity of binary-input discrete memoryless channels, with encoding and decoding complexity of O(N log N) for block length N.

Channel polarisation

The central idea is to apply a linear transform recursively so that a set of identical copies of a channel split into subchannels whose capacities polarise: as the block length grows, the fraction of subchannels whose capacity approaches 1 or 0 tends toward the original channel's capacity and its complement respectively. Information bits are sent over the "good" subchannels while the positions of the "bad" subchannels are filled with frozen bits known to both encoder and decoder.

Decoding

The natural decoder for polar codes is the successive-cancellation (SC) decoder, which decodes bits one at a time using likelihood information propagated through the polarisation graph. Later refinements — successive-cancellation list (SCL) decoding with a CRC check — substantially improved finite-length performance and made polar codes competitive with LDPC and turbo codes at short and moderate block lengths.

Applications

In 2016, polar codes were adopted as the channel coding scheme for the control channels of the 5G NR (New Radio) standard by 3GPP, while LDPC codes were chosen for the data channels. Polar codes are also used in certain deep-space and storage applications where short block lengths and provable performance are valuable.
