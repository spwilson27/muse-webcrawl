Porting

In software engineering, porting is the process of adapting software for the purpose of achieving some form of execution in a computing environment that is different from the one that a given implementation of the program was originally designed for — for example, a different CPU, operating system, or third-party library.

The term is also used when hardware or software is changed to make it usable in different environments. Software is said to be portable if the cost of adapting it to a new platform is significantly less than the cost of writing it from scratch; the lower the cost of porting relative to implementation, the more portable it is said to be.

History

The number of significantly different CPUs and operating systems used in the desktop today is much smaller than in the past, so the need for porting has lessened. Portability became a major design goal of languages such as C and of the Unix operating system, whose port from the PDP-11 to other architectures in the 1970s was a landmark. In video games, a "port" is a version of a game converted from one platform to another, sometimes by a different studio.

Porting process

Porting typically involves isolating platform-dependent code behind abstraction layers, replacing operating-system calls and libraries, handling differences in byte order, word size, and file formats, and re-testing on the target platform.
