Longest common subsequence

The longest common subsequence (LCS) problem is the problem of finding the longest subsequence common to all sequences in a set of sequences (often just two sequences). A subsequence is obtained by deleting some or no elements of a sequence without changing the order of the remaining elements; unlike substrings, subsequences need not occupy consecutive positions. For example, the longest common subsequence of "ABCBDAB" and "BDCABA" is "BCBA", of length 4.

Dynamic programming solution

For two sequences of lengths m and n the classic dynamic programming solution fills an (m+1) × (n+1) table using the recurrence: if the current characters match, LCS(i,j) = LCS(i−1, j−1) + 1; otherwise LCS(i,j) = max(LCS(i−1, j), LCS(i, j−1)). This runs in O(mn) time, and the subsequence itself is recovered by backtracking through the table. Memory can be reduced to O(min(m, n)) if only the length is needed. Hunt–Szymanski and Hirschberg's algorithm give improvements for special cases and for reconstructing the answer in linear space.

Applications

The LCS problem underlies the diff utility for comparing files, revision control systems, and DNA sequence comparison in bioinformatics, where it is related to sequence alignment and edit distance. The problem becomes NP-hard for an arbitrary number of sequences over a general alphabet.
