x86

x86 (also known as 80x86 or the 8086 family) is a family of complex instruction set computer (CISC) instruction set architectures initially developed by Intel based on the Intel 8086 microprocessor and its 8088 variant. The name derives from the succession of Intel processors whose model numbers ended in "86", including the 80186, 80286, 80386 and 80486. The architecture has been implemented by Intel, AMD and other manufacturers and has dominated personal computing since the 1980s.

History

The 8086 was introduced in 1978 as a 16-bit processor. The IBM Personal Computer of 1981 used the cost-reduced 8088, cementing the architecture's position in the desktop market. The 80386 (1985) extended the architecture to 32 bits with protected-mode multitasking and paging; this 32-bit variant is often called IA-32. In the early 2000s AMD introduced the 64-bit extension x86-64 (also marketed as AMD64), which became the standard for desktop and server processors, while Intel's rival 64-bit Itanium architecture failed to displace it.

Features

Characteristic features of x86 include variable-length instructions (1 to 15 bytes), a historically small register set that has been progressively extended, two-operand instructions in which one operand may be a memory location, and extensive backward compatibility: modern x86-64 processors can still run software written for the original 8086, passing through real mode, protected mode and long mode.

Extensions

Over time the instruction set has accumulated extensions including x87 floating point, MMX, SSE and its successors up to AVX-512 for vector processing, and hardware virtualisation support (Intel VT-x and AMD-V).

Market position

x86 processors power the majority of desktop and laptop personal computers and most servers, though ARM-based processors have become dominant in mobile devices and have gained ground in laptops and data centres.
