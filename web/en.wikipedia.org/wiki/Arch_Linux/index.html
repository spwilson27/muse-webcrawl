Arch Linux is an independently developed, x86-64 general-purpose Linux distribution that strives to provide the latest stable versions of most software by following a rolling-release model. The default installation is a minimal base system, configured by the user to only add what is purposely required. Arch is known for its pacman package manager, its extensive documentation in the ArchWiki, and its user-centric philosophy summarized by the KISS principle ("keep it simple, stupid").

History

Arch Linux was founded by Canadian programmer Judd Vinet, who was inspired by the simplicity of Slackware and the BSD ports system, and by the Polish distribution PLD Linux. The first release, version 0.1 (codenamed "Homer"), appeared in March 2002. Vinet led the project until 2007, when he stepped down and Aaron Griffin took over. Leadership later passed to Levente Polyak in 2020.

Design principles

Arch follows five core principles: simplicity, modernity, pragmatism, user centrality, and versatility. The distribution targets competent Linux users — in its own words, it is "user-centric, not user-friendly". The base system is deliberately minimal; users build their environment from the command line up, choosing their own desktop environment or window manager. Configuration is centralized in plain-text files, and Arch-specific tools favor simplicity over abstraction.

Package management

Packages are managed with pacman, which installs, upgrades, and removes binary packages from official repositories (core, extra, and multilib) while tracking dependencies and protecting against broken upgrades. Source-based packages are described by PKGBUILD scripts and built with makepkg. The Arch Build System and the community-maintained Arch User Repository (AUR) extend the official repositories with tens of thousands of user-submitted build scripts. Because Arch is a rolling release, a single installation can be kept current indefinitely with regular full-system upgrades.

Derivatives and reception

Numerous distributions are based on Arch, including Manjaro, EndeavourOS, and the SteamOS 3.0 release used on Valve's Steam Deck. Arch is frequently praised by experienced users for its up-to-date software, the AUR, and the quality of the ArchWiki, which serves as a reference for Linux users of all distributions, while its manual installation process is considered a barrier to newcomers.
