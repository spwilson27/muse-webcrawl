Control flow

In computer science, control flow (or flow of control) is the order in which individual statements, instructions or function calls of an imperative program are executed or evaluated. The emphasis on explicit control flow distinguishes an imperative programming language from a declarative programming language.

Control structures

Within an imperative programming language, a control-flow statement is a statement that results in a choice being made as to which of two or more paths to follow. The basic building blocks are sequence, selection and iteration. Selection statements include if–then–else conditionals and multi-way switches; iteration is provided by loops such as while, do–while and for, which repeat a block until a condition changes. Procedure and function calls transfer control temporarily to a subroutine, returning afterwards, while unrestricted jumps (goto) can transfer control arbitrarily.

The structured program theorem (Böhm and Jacopini, 1966) showed that sequence, selection and iteration suffice to express any computable function, forming the theoretical basis of structured programming, which discouraged the use of goto. More advanced control mechanisms include coroutines, generators, continuations and exception handling, which transfers control to a handler when an error or exceptional condition occurs.

Analysis

Compilers and static analysis tools model control flow explicitly using the control-flow graph, whose basic blocks and branch edges capture all paths a program might take. Reasoning about control flow underlies type checking, optimization and formal verification of programs.
