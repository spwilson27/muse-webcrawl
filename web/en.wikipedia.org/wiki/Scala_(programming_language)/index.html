Scala (/ˈskɑːlə/) is a strong statically typed high-level general-purpose programming language that supports both object-oriented and functional programming. Designed by Martin Odersky at EPFL, it was released in 2004 and runs primarily on the Java Virtual Machine, interoperating seamlessly with Java libraries. The name is a portmanteau of "scalable" and "language".

Features

Scala unifies object-oriented and functional idioms: every value is an object, functions are first-class values, and the language provides pattern matching, algebraic data types (in Scala 3, enums), higher-kinded types, implicit parameters and conversions, and a powerful type inference system. Its actor-based and future-based concurrency libraries, and frameworks such as Apache Spark (written in Scala), Akka and Play, made it a popular choice for distributed data processing and backend services. Companies such as Twitter, LinkedIn and Netflix have used Scala extensively.

Scala 3

Scala 3, released in 2021, was a major redesign based on the DOT calculus, introducing a new syntax with optional braces, extension methods, opaque types, union and intersection types, and a metaprogramming system based on inline definitions and quotes. The compiler is codenamed Dotty.
