Port (computer networking)

In computer networking, a port is a communication endpoint identified by a 16-bit number that allows a single host, addressed by its IP address, to multiplex many simultaneous communications and direct them to the correct application process.

Port numbers

Port numbers range from 0 to 65,535. The Internet Assigned Numbers Authority (IANA) divides them into well-known ports (0–1023), assigned to standard services such as HTTP (80), HTTPS (443), SMTP (25) and DNS (53); registered ports (1024–49,151); and dynamic or ephemeral ports (49,152–65,535), chosen temporarily by client software.

Operation

Transport protocols such as TCP and UDP place a source and destination port number in every segment header. A connection is uniquely identified by the combination of source and destination IP addresses and ports — a socket pair. Servers listen on known ports; clients connect from ephemeral ones. Network address translation (NAT) rewrites ports to let many private hosts share one public address.

Security

Firewalls filter traffic by port, and port scanning — probing many ports on a host — is a basic network reconnaissance technique.
