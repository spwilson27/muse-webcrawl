XGBoost (eXtreme Gradient Boosting) is an open-source software library providing a scalable, distributed gradient-boosting framework for machine learning. Originally developed by Tianqi Chen as part of the Distributed (Deep) Machine Learning Community (DMLC), it implements gradient-boosted decision trees with an emphasis on speed, regularisation and handling of sparse data.

Features

XGBoost optimises a regularised objective combining a loss function with penalties on tree complexity. Key techniques include a sparsity-aware split-finding algorithm, weighted quantile sketches for approximate tree learning, parallel and distributed computation, cache optimisation and out-of-core computing for datasets larger than memory. It provides interfaces for C++, Python, R, Java, Scala and Julia, and integrates with frameworks such as scikit-learn and Spark.

Impact

XGBoost gained prominence through its dominance in machine learning competitions, including numerous winning solutions on Kaggle, where its accuracy and speed on structured tabular data made it a default choice. It remains widely used in production systems alongside alternatives such as LightGBM and CatBoost.
