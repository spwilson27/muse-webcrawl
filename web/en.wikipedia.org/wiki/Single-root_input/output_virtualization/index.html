Single-root input/output virtualization

StandardPCI-SIG
Applies toPCI Express devices
PurposeHardware I/O sharing among VMs

Single-root input/output virtualization (SR-IOV) is a specification by the PCI-SIG that allows a single physical PCI Express device, such as a network adapter, to present itself to a hypervisor as multiple separate virtual devices. Each virtual function can be assigned directly to a virtual machine, giving near-native I/O performance.

Architecture

An SR-IOV device has one physical function (PF), used for configuration and management, and up to hundreds of lightweight virtual functions (VFs), each with its own configuration space, queues and DMA channels. The hypervisor assigns VFs to guests, whose drivers then communicate with the hardware almost directly.

Benefits

By bypassing the hypervisor's virtual switch or emulated device for the data path, SR-IOV reduces latency and CPU overhead in virtualised servers. It is widely used in cloud data centres, high-performance computing and network function virtualisation.

Limitations

Direct device assignment can complicate live migration, since the guest depends on specific hardware state, though techniques such as bonding with a virtual device are used to mitigate this.
