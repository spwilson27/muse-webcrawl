WebAssembly

From Wikipedia, the free encyclopedia
[Image: The WebAssembly logo: the letters WASM in white on a purple square with a cut corner]

WebAssembly (Wasm) is a binary instruction format for a stack-based virtual machine, designed as a portable compilation target for programming languages. It enables deployment of client and server applications on the web at near-native speed — the fourth native language of the browser, alongside HTML, CSS and JavaScript.

WebAssembly grew out of Mozilla's asm.js experiments (2013), which showed JavaScript engines could run compiled C code surprisingly fast. Announced in 2015 as a joint project of all major browser vendors and standardised by the World Wide Web Consortium (first MVP in browsers in 2017, a W3C Recommendation in 2019), it lets developers compile C, C++, Rust, Go and other languages to a compact binary that browsers execute in the same sandbox as JavaScript.

Its showcase uses are heavy computation in the browser — photo and video editors, CAD, games (Unity and Unreal engines), Google Earth — and, increasingly, outside it: server-side and edge computing platforms adopted Wasm as a fast, safe, portable runtime, fulfilling part of the old 'write once, run anywhere' dream that Java applets and Flash once chased on the same turf.
