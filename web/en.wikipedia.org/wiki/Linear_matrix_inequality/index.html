Linear matrix inequality

In convex optimisation, a linear matrix inequality (LMI) is an expression of the form F0 + x1F1 + … + xnFn ⪰ 0, where the Fi are given symmetric matrices, the xi are decision variables, and the inequality means that the resulting matrix is positive semidefinite.

Properties

The set of points satisfying an LMI is a convex set (a spectrahedron), so minimising a linear objective subject to LMI constraints is a semidefinite program solvable in polynomial time by interior-point methods. Many constraints — on eigenvalues, norms, and quadratic forms — can be expressed as LMIs; for example, a constraint that a symmetric matrix be positive definite is itself an LMI.

Applications

LMIs are widely used in control theory, where problems such as stability analysis, H-infinity control, and state-feedback synthesis can be reduced to feasibility of matrix inequalities, a connection popularised by the work of Boyd, El Ghaoui, Feron, and Balakrishnan in the 1990s. They also appear in structural design, signal processing, and system identification.
