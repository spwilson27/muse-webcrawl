Low-density parity-check code

In information theory, a low-density parity-check (LDPC) code is a linear error-correcting code, a method of transmitting a message over a noisy transmission channel. An LDPC code is constructed using a sparse Tanner graph (a subgraph of a bipartite graph). LDPC codes are capacity-approaching codes, which means that practical constructions exist that allow the noise threshold to be set very close to the theoretical maximum (the Shannon limit) for a symmetric memoryless channel.

History

LDPC codes were first developed by Robert G. Gallager in his doctoral dissertation at MIT in 1960. Because the computational demands of implementing the encoders and decoders were far beyond the hardware of the time, they were largely forgotten for three decades. They were rediscovered in the mid-1990s, in the wake of the excitement over turbo codes, notably through the work of David MacKay and Radford Neal, who showed that Gallager's codes performed as well as or better than turbo codes. LDPC codes have since been adopted in a wide range of communications standards.

Construction and decoding

An LDPC code is defined by a parity-check matrix H containing mostly zeros and relatively few ones — hence "low-density." A codeword is a vector c satisfying HcT = 0. The structure of H is conveniently drawn as a bipartite (Tanner) graph connecting variable nodes to check nodes. Codes whose parity-check matrix has a constant number of ones per row and column are called regular; carefully optimised varying degrees give irregular LDPC codes with still better performance.

Decoding is performed iteratively by message passing — belief propagation, or the sum-product algorithm — on the Tanner graph: variable and check nodes exchange estimates of the transmitted bits until a valid codeword is found or a maximum number of iterations is reached. Simplified variants such as min-sum decoding are used in hardware.

Applications

LDPC codes are used in the DVB-S2 satellite television standard, Wi-Fi standards from 802.11n onward, 10GBASE-T Ethernet, WiMAX, DOCSIS 3.1 cable, and the data channel of the 5G NR mobile standard. They are also widely studied for data storage in flash memory and hard drives.
