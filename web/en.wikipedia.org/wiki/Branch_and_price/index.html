Branch and price

In applied mathematics, branch and price is a method of combinatorial optimization for solving integer linear programming (ILP) and mixed integer linear programming (MILP) problems with many variables. The method is a hybrid of branch and bound and column generation methods.

Method

In problems where the formulation has an enormous number of variables (columns), it is impractical to generate them all explicitly. Instead, branch and price solves the linear programming relaxation using column generation: a restricted master problem containing only a subset of columns is solved, and a pricing subproblem generates new columns with negative reduced cost until optimality of the relaxation is reached. If the relaxation's solution is fractional, branching is performed, with care taken that branching decisions remain compatible with the pricing problem.

Applications

Branch and price has been used successfully for vehicle routing, crew scheduling, and cutting stock problems.
