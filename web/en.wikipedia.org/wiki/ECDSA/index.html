ECDSA

The Elliptic Curve Digital Signature Algorithm (ECDSA) offers a variant of the Digital Signature Algorithm (DSA) which uses elliptic-curve cryptography, providing smaller keys for equivalent security.

ECDSA
Type: Digital signature
Standardised: ANSI X9.62, FIPS 186
Used in: TLS, Bitcoin

Algorithm

Key generation selects a private key d and public point Q = dG on a curve such as NIST P-256 or secp256k1. Signing uses a per-message secret k to produce (r, s); reuse of k reveals the private key, as in the PlayStation 3 compromise.

Usage

ECDSA is widely used in TLS certificates, SSH and Bitcoin. Deterministic ECDSA (RFC 6979) derives k from message and key. Quantum computing via Shor's algorithm threatens it.
