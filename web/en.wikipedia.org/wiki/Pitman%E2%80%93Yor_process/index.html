Pitman–Yor process

In probability theory, the Pitman–Yor process (also known as the two-parameter Poisson–Dirichlet process) is a stochastic process whose sample paths are probability distributions. It generalizes the Dirichlet process through the addition of a second parameter.

Definition

The process is denoted PY(d, θ, H), where H is a base probability distribution, θ > −d is a concentration parameter, and 0 ≤ d < 1 is a discount parameter. It can be constructed by a stick-breaking procedure in which the stick proportions follow Beta(1 − d, θ + kd) distributions for k = 0, 1, 2, …

Properties

When d = 0 the process reduces to the Dirichlet process. For d > 0 the number of distinct clusters in a sample of size n grows as a power law, nd, rather than logarithmically. This heavy-tailed behaviour makes the Pitman–Yor process a better model than the Dirichlet process for data such as natural language word frequencies, which follow power-law distributions.

History and applications

The underlying two-parameter Poisson–Dirichlet distribution was introduced by Jim Pitman and Marc Yor in 1997. The process is widely used in Bayesian nonparametric statistics and machine learning, including language modelling, topic modelling, and species-sampling problems.
