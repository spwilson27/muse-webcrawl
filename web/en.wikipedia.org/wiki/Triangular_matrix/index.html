Triangular matrix

In linear algebra, a triangular matrix is a special kind of square matrix. A square matrix is called lower triangular if all entries above the main diagonal are zero, and upper triangular if all entries below the main diagonal are zero. A matrix that is both is a diagonal matrix.

Upper triangular: ▍ a b c ▍ Lower triangular: ▍ a 0 0 ▍ ▍ 0 d e ▍ ▍ b d 0 ▍ ▍ 0 0 f ▍ ▍ c e f ▍

Properties

The determinant of a triangular matrix is simply the product of its diagonal entries, which are also its eigenvalues. The sum, difference and product of two upper triangular matrices are upper triangular, as is the inverse of an invertible upper triangular matrix. The set of upper triangular matrices forms a subalgebra of the algebra of square matrices.

Solving triangular systems

Systems of linear equations with a triangular coefficient matrix are solved directly by substitution: forward substitution for lower triangular systems and back substitution for upper triangular ones. This efficiency is why Gaussian elimination reduces a general system to triangular form (the LU decomposition), and why the Schur decomposition, which triangularises a matrix by a unitary similarity, is central to numerical eigenvalue algorithms.
