Rootkit

A rootkit is a collection of computer software, typically malicious, designed to enable access to a computer or an area of its software that is otherwise not allowed (for example, to an unauthorised user) while concealing its own existence or the existence of other software. The term combines "root" — the privileged administrator account on Unix-like systems — with "kit", the set of tools that makes up the software. Rootkits are a type of malware whose defining purpose is stealth.

Types

  • User-mode rootkits modify applications or libraries (for example, by replacing system utilities such as ls or ps, or by API hooking) so that processes, files and network connections belonging to the attacker are hidden.
  • Kernel-mode rootkits run with operating-system privileges, modifying the kernel itself or loading malicious drivers; they can hide objects from every application at once and are correspondingly harder to detect.
  • Bootkits infect the master boot record or bootloader and load before the operating system, while firmware rootkits persist in device firmware, surviving reinstallation of the OS.
  • Hypervisor-level rootkits (research examples include SubVirt and "Blue Pill") place the victim operating system inside a virtual machine controlled by the attacker.

Detection and removal

Because a rootkit subverts the very mechanisms used to observe the system, detection often relies on behavioural analysis, integrity checking against known-good signatures, or examining the system from a trusted external environment (for example, booting from clean media). Well-known incidents include the 2005 Sony BMG copy-protection scandal, in which copy-protection software on music CDs installed a rootkit on customers' Windows PCs, and the LoJax UEFI rootkit attributed to state-sponsored attackers in 2018. Prevention emphasises patching, least-privilege operation, secure boot and firmware integrity measurement.
