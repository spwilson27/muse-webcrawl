Earned run
Sport: Baseball
Related statistic: Earned run average (ERA)

In baseball statistics, an earned run is a run scored for which the pitcher is held responsible — that is, a run that scores without the benefit of an error or a passed ball by the fielding team.

Scoring

The official scorer determines earned runs by reconstructing the inning as it would have unfolded without errors and passed balls. Runs scored by batters who reached base because of an error, or after an inning should have ended on an error, are unearned. Relief pitchers are charged with earned runs for runners they allow to score, while inherited runners who score are charged to the pitcher who put them on base.

Use

Earned runs are the basis of earned run average (ERA), the mean of earned runs given up per nine innings pitched, one of the most widely used measures of pitching performance since it became an official statistic in the early 20th century.
