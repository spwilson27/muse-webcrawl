RDFa

RDFa (Resource Description Framework in Attributes) is a W3C Recommendation that adds a set of attribute-level extensions to HTML, XHTML and various XML-based document types for embedding rich metadata within Web documents. The Resource Description Framework (RDF) data-model mapping is used by RDFa, allowing publishers to embed RDF subject-predicate-object expressions (triples) directly in markup.

RDFa was first proposed by Mark Birbeck and developed within the W3C's Semantic Web Deployment Working Group. The RDFa Primer and RDFa Core specifications were published as W3C Recommendations in 2008, with RDFa 1.1 following in 2012 and RDFa Lite 1.1 — a minimal subset aimed at web authors — published alongside it.

Overview

RDFa uses a small set of attributes, principally about, rel, rev, property, resource, content, datatype, typeof and vocab, prefix and property in RDFa Lite. Vocabularies such as schema.org, Dublin Core, FOAF and the Open Graph protocol can be expressed. Search engines including Google and Bing have used RDFa markup to enhance search result displays.

Versions

RDFa 1.0 was designed primarily for XHTML. RDFa 1.1 broadened support to HTML5 and introduced the vocab attribute for declaring a default vocabulary and initial contexts defining commonly used prefixes. RDFa Lite omits most advanced features, requiring only vocab, typeof, property, resource and prefix.
