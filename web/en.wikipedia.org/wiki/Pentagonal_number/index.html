Pentagonal number

Pentagonal number
First terms1, 5, 12, 22, 35, 51, 70
Formulan(3n−1)/2
TypeFigurate number

A pentagonal number is a figurate number that extends the concept of triangular and square numbers to a pentagon: it counts the dots in nested pentagons sharing a corner. The nth pentagonal number is given by pn = n(3n − 1)/2, yielding 1, 5, 12, 22, 35, 51, ...

Properties

Generalised pentagonal numbers, obtained by allowing n = 0, ±1, ±2, ..., are central to Euler's pentagonal number theorem, which gives a recurrence for the partition function counting the ways an integer can be written as a sum of positive integers. Pentagonal numbers were studied in antiquity as part of Greek figurate arithmetic; every pentagonal number is also a third of a triangular number.

Tests

A positive integer x is pentagonal if and only if (sqrt(24x + 1) + 1)/6 is a natural number.
