SD card

Secure Digital, officially abbreviated as SD, is a proprietary non-volatile flash memory card format developed by the SD Association (SDA) for use in portable devices. Introduced in 1999 by SanDisk, Panasonic (Matsushita), and Toshiba, the format became the dominant removable storage standard for digital cameras, mobile phones, game consoles, single-board computers, and many other devices.

The three SD form factors: SD, miniSD (largely discontinued), and microSD.

Adapters allow smaller cards to be used in full-size slots. Full-size cards include a sliding write-protect tab, although whether it is honored is up to the host device.

Capacity standards

The original SD standard (SDSC) supports up to 2 GB. SDHC (High Capacity) extends this to 32 GB and uses FAT32; SDXC (eXtended Capacity) reaches 2 TB and uses exFAT; SDUC (Ultra Capacity) raises the theoretical maximum to 128 TB. Host devices must support the corresponding standard to use higher-capacity cards.

Speed classes

Cards are marked with speed ratings guaranteeing minimum sequential write speeds: the original Speed Class (Class 2–10), UHS Speed Class (U1, U3), Video Speed Class (V6–V90), and the Application Performance Class (A1, A2) for random access. The UHS bus interfaces (UHS-I, UHS-II, UHS-III) and SD Express, which uses PCIe and NVMe, progressively increased maximum transfer rates, with SD Express reaching several gigabytes per second.

Use

SD and especially microSD cards are used in smartphones, cameras, drones, the Nintendo Switch, Raspberry Pi computers, dashcams, and industrial equipment. The format's small size, low cost, and broad host support made it the most successful flash card standard.
