Analytic class number formula

From Wikipedia, the free encyclopedia

The analytic class number formula links the Dedekind zeta function to arithmetic invariants.

In algebraic number theory, the analytic class number formula relates the residue of the Dedekind zeta function of a number field at s = 1 to the field's fundamental arithmetic invariants: its class number, regulator, discriminant, and numbers of real and complex embeddings. It was proved by Dirichlet in the nineteenth century and is a cornerstone of the subject.

Statement

For a number field K with class number hK, regulator RK, discriminant DK, number of roots of unity wK, and r1 real and r2 pairs of complex embeddings, the Dedekind zeta function has a simple pole at s = 1 with residue

Ress=1 ζK(s) = (2r1 (2π)r2 hK RK) / (wK √|DK|)

Consequences

Because the residue is positive, the formula shows the class number is finite and nonzero. For quadratic fields it specializes to Dirichlet's class number formula expressing h in terms of a value of a Dirichlet L-function at s = 1, connecting class numbers to character sums. The formula also underlies the Brauer–Siegel theorem on the growth of class numbers and generalizes, in the Birch and Swinnerton-Dyer and Lichtenbaum conjectures, to deep statements relating L-function values to arithmetic geometry.
