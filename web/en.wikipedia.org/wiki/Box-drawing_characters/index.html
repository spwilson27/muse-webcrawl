Box-drawing characters

Box-drawing characters, also known as line-drawing characters, are a set of characters used in text-mode interfaces to draw simple diagrams, boxes and borders. In Unicode they occupy the Box Drawing block (U+2500–U+257F), which contains 128 characters including horizontal and vertical lines in light, heavy, dashed and double styles, corners, T-junctions and crossings.

History

Line drawing was a feature of early video terminals such as the DEC VT100, whose special graphics character set enabled crude forms and menus. On the IBM PC, code page 437 included a rich set of box-drawing glyphs widely used by DOS applications and bulletin board systems for menus, windows and ANSI art. Similar sets appeared in PETSCII, ATASCII and the ZX Spectrum's block graphics. These legacy sets were the source of most of the Unicode block, supplemented by the related Block Elements (U+2580–U+259F) used for shading and mock-pixel graphics.

Use

Box-drawing characters remain in daily use in terminal user interfaces, console file managers, command-line tools that print tables and trees, source-code comments, and plain-text documentation. Because each character occupies a full cell in monospace fonts, diagrams drawn with them align correctly only in fixed-width contexts.
