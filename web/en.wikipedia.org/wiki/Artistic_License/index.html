Artistic License

The Artistic License is an open-source software license used for the Perl programming language distribution and a number of other projects hosted on CPAN. Drafted by Larry Wall, it permits redistribution and modification of the software provided certain conditions are met — notably that modified versions not be represented as the standard version and that changes be clearly indicated — while disclaiming warranty.

Versions

The original license, now called Artistic License 1.0, was criticised for vagueness; the Free Software Foundation regards the original wording as ambiguous, though it treats a clarified interpretation as free. Artistic License 2.0, released in 2006 after a revision process led by the Perl Foundation, rewrote the terms in precise legal language to address intellectual-property concerns; it is approved by both the FSF (as a free license compatible with the GPL) and the Open Source Initiative. Perl 5 is dual-licensed under the Artistic License and the GNU General Public License.
