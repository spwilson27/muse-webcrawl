Packet error ratio

The packet error ratio (PER) is the number of incorrectly received data packets divided by the total number of received packets at a receiver in a digital communication system. A packet is declared incorrect if at least one bit is erroneous. The expectation value of the PER is denoted the packet error probability pp, which for a data packet length of N bits can be expressed as:

pp = 1 − (1 − pe)N

where pe is the bit error probability (bit error rate), assuming bit errors are independent of each other. For small bit error probabilities and large packet lengths this approximation holds:

pp ≈ N · pe

Measurement

Such measurements are frequently carried out during the development and certification of radio systems. The packet error ratio is a key figure of merit for wireless links because a single bit error causes the entire packet to be discarded or retransmitted, linking physical-layer quality directly to throughput at higher layers. PER is typically measured as a function of signal-to-noise ratio, often plotted against the energy per bit to noise power spectral density ratio (Eb/N0), and compared between modulation and coding schemes.

Applications

PER targets are specified in standards for technologies such as Bluetooth, Wi-Fi (IEEE 802.11), and cellular systems. Because packet loss triggers retransmission in protocols such as TCP and automatic repeat request (ARQ) schemes, minimizing the packet error ratio is a central goal of link adaptation, forward error correction, and diversity techniques.
