Robert Cecil Martin (born 5 December 1952), colloquially known as "Uncle Bob", is an American software engineer, instructor, and author. He is a co-author of the Agile Manifesto (2001) and a leading figure in the software craftsmanship movement. Martin has worked in the software industry since the early 1970s and founded the consulting company Object Mentor and later 8th Light.

Contributions

Martin popularised a set of object-oriented design principles that Michael Feathers later arranged under the acronym SOLID: Single responsibility, Open–closed, Liskov substitution, Interface segregation, and Dependency inversion. He also promoted package design principles, test-driven development, and the idea of software craftsmanship as an ethical, professional discipline for programmers, founding the Software Craftsmanship movement with the 2008 manifesto effort that followed.

Books

  • Designing Object-Oriented C++ Applications Using the Booch Method (1995)
  • Agile Software Development, Principles, Patterns, and Practices (2002) — winner of the Jolt Award
  • UML for Java Programmers (2003)
  • Clean Code: A Handbook of Agile Software Craftsmanship (2008)
  • The Clean Coder: A Code of Conduct for Professional Programmers (2011)
  • Clean Architecture: A Craftsman's Guide to Software Structure and Design (2017)
  • Clean Agile: Back to Basics (2019)

His "Clean Code" talks and blog posts are widely read, and his talks on the history and future of programming are popular conference material. Martin has also been an outspoken — and sometimes controversial — commentator on programming languages, agile practices and professional ethics.
