RPM Package Manager

RPM Package Manager (RPM) (originally Red Hat Package Manager, now a recursive acronym) is a free and open-source package management system. The name RPM refers to the .rpm file format and the package manager program itself.

RPM was created by Erik Troan and Marc Ewing at Red Hat and first released in 1997. It is the package format used by the Linux Standard Base and by distributions including Red Hat Enterprise Linux, Fedora, CentOS and Rocky Linux (via DNF), SUSE Linux Enterprise and openSUSE (via Zypper), and Mandriva-derived systems.

The format

An .rpm package is an archive (historically cpio-based) containing a lead, signature and header structures with metadata — name, version, release, architecture, dependencies, file list and scripts — followed by the compressed payload of files. Source packages use the .src.rpm extension and contain the spec file, sources and patches needed to build binary packages.

Features

RPM maintains a database of installed packages and can verify file integrity against package signatures, query metadata, and install, upgrade and remove packages while checking dependencies. Higher-level resolvers such as DNF and Zypper handle repository-based dependency resolution on top of RPM.
