Key size

In cryptography, key size or key length refers to the number of bits in a key used by a cryptographic algorithm, such as a cipher. An algorithm's key length is distinct from its cryptographic security, although the two are related: the key size determines an upper bound on the work needed for a brute-force attack, which must try on average half of all possible keys.

Significance

Keys with too small a size can be attacked by exhaustive search. The Data Encryption Standard (DES) used a 56-bit key, which by the late 1990s could be broken by purpose-built hardware such as the EFF's "Deep Crack" machine. Modern symmetric ciphers such as AES use keys of 128, 192 or 256 bits, which place brute-force search far beyond any feasible computing power.

Asymmetric algorithms

For public-key algorithms, the relationship between key size and security is weaker: RSA keys of 2,048 bits are commonly compared in strength to roughly 112 bits of symmetric security, because factoring algorithms are much faster than brute force. Elliptic-curve cryptography achieves comparable security with shorter keys, around 256 bits for a 128-bit security level.

Quantum considerations

Grover's algorithm would let a quantum computer search an n-bit key space in about 2n/2 operations, which is why doubling symmetric key sizes is recommended for the post-quantum era, while Shor's algorithm threatens RSA and elliptic-curve systems outright.
