Wavelet tree

The wavelet tree is a succinct data structure to store strings in compressed space. It generalizes the access, rank, and select operations defined on binary vectors to alphabets of arbitrary size. Originally introduced to represent compressed suffix arrays, it has found application in many contexts. The tree is a balanced binary tree with as many leaves as there are symbols in the alphabet; at each node, a bitvector stores the symbols of its string that are represented by the left and right children.

Properties

The wavelet tree can be used to answer queries about the original string without decompressing it. Given a string S of length n over an alphabet of size σ, the wavelet tree uses n log σ + o(n log σ) bits of space, which is asymptotically optimal in the information-theoretic sense. The fundamental operations supported are access (returning the symbol at a given position), rank (counting the occurrences of a symbol up to a given position), and select (finding the position of the k-th occurrence of a symbol), each in O(log σ) time.

Construction

Construction proceeds recursively. The root of the tree holds the whole string, together with a bitvector indicating for each character whether it belongs to the first or second half of the alphabet. The characters are then stably partitioned according to this split, and the two resulting subsequences are processed recursively by the left and right children until each leaf represents a single symbol of the alphabet.

Extensions

Variants include the wavelet matrix, which rearranges the bitvectors to improve query times in practice while using the same space, and multiary wavelet trees, which use larger branching factors to reduce the height of the tree. Wavelet trees also form the basis of range-quantile and two-dimensional orthogonal range counting queries.
