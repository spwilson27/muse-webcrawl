PowerShell is a task automation and configuration management program from Microsoft, consisting of a command-line shell, an associated scripting language, and a framework for processing cmdlets. Originally released in 2006 as Windows PowerShell and built on the .NET Framework, it was redeveloped on .NET Core as the cross-platform, open-source PowerShell Core (version 6, 2016) and now runs on Windows, macOS, and Linux.

Design

Unlike traditional shells that pass plain text between commands, PowerShell pipelines pass structured .NET objects, allowing commands to manipulate properties and methods directly. Small specialised commands called cmdlets (pronounced "command-lets") follow a consistent Verb-Noun naming convention — Get-Process, Stop-Service, Set-Date — and share common parameters and formatting, remoting, and help systems. The shell supports aliases, tab completion, transcripts, background jobs, and remote management of servers over WS-Management and SSH, and administrators can extend it with modules published through the PowerShell Gallery.

Uses

PowerShell became the principal automation tool for Windows administration, underpinning the management of Active Directory, Exchange, Azure, and Windows Server roles, and its Desired State Configuration system allows declarative definition of machine state. Because of its power and ubiquity on Windows systems it is also frequently abused in cyberattacks through "living off the land" techniques, which has prompted extensive logging, constrained language modes, and application control in secured environments.
