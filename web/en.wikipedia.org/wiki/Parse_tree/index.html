Parse tree

Parse tree
Also called: Derivation tree, concrete syntax tree
Fields: Computer science, linguistics
Root: Start symbol of the grammar
Leaves: Terminal symbols (the input sentence)
Related: Abstract syntax tree, parsing

A parse tree or parsing tree, also known as a derivation tree or concrete syntax tree, is an ordered, rooted tree that represents the syntactic structure of a string according to a context-free grammar. The interior nodes of the tree are labelled by non-terminal symbols of the grammar, and the leaf nodes by terminal symbols (or by the empty string ε). Reading the leaves from left to right yields the original string — the "yield" of the tree.

Derivations

A parse tree encodes a derivation of the string from the grammar's start symbol: each expansion of a non-terminal corresponds to one step of the derivation. A grammar is ambiguous if some string has more than one distinct parse tree. Different parsing strategies (top-down or bottom-up) correspond to different orders of constructing the same tree.

Applications

In compiler design, parsers (such as recursive-descent, LL, and LR parsers) construct parse trees or, more commonly, abstract syntax trees, which omit the purely grammatical detail of the concrete tree and serve as the basis for semantic analysis and code generation. In natural language processing, parse trees represent the constituent structure of sentences, and treebanks such as the Penn Treebank provide large corpora of hand-annotated parse trees used to train statistical parsers. Linguists use them to model phrase structure in theories of syntax.

Parse trees versus abstract syntax trees

Unlike an abstract syntax tree, a concrete parse tree contains a node for every rule application in the derivation, including punctuation and keywords that carry no semantic weight. As a result, parse trees are larger but preserve complete information about the surface form of the input.
