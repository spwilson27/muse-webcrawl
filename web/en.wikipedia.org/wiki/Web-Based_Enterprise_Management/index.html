Web-Based Enterprise Management

Web-Based Enterprise Management (WBEM) is a set of systems-management standards developed by the Distributed Management Task Force (DMTF) to unify the management of distributed computing environments. WBEM is based on Internet standards and DMTF open standards, most notably the Common Information Model (CIM) schema, the CIM-XML protocol, and WS-Management.

Components

The WBEM architecture includes a CIM server (or CIM object manager) that stores management data in a repository organized by the object-oriented CIM schema; providers that gather data from managed devices and applications; and clients that access the data over HTTP/HTTPS using CIM operations encoded in XML. A key feature is a common data model intended to let management applications from different vendors interoperate.

Implementations

Notable implementations include OpenPegasus (an open-source CIM server used on Unix-like systems), Microsoft's Windows Management Instrumentation (WMI, and its successor MI), Small Footprint CIM Broker (SFCB), and the WBEM Solutions SDKs. In practice, WS-Management (implemented by WinRM on Windows) and Redfish have superseded CIM-XML in many deployments, though CIM modeling remains foundational to DMTF standards.
