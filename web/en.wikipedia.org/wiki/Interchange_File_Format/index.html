Interchange File Format

Interchange File Format (IFF) is a generic container file format introduced by Electronic Arts in 1985 (in cooperation with Commodore) to facilitate the transfer of data between software applications on the Amiga platform. It has influenced many later formats, including RIFF and AIFF.

Structure

An IFF file consists of chunks, each with a four-character type identifier (FourCC), a 32-bit length, and data. Chunks can be grouped into FORM, LIST and CAT containers, allowing complex structured data such as images (ILBM), music (SMUS) and animations (ANIM) to share a common framework.

Legacy

Although the Amiga declined, IFF's chunked design proved durable: Microsoft's RIFF (the basis of WAV and AVI) and Apple's AIFF both derive directly from it, and the TIFF image format follows similar principles.
