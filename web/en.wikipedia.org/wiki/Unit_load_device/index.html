A unit load device (ULD) is a container or pallet used to load luggage, freight, and mail onto wide-body aircraft and specific narrow-body aircraft. It enables large quantities of cargo to be bundled into a single unit, speeding loading and unloading, protecting contents, and allowing the aircraft's cargo restraint system to secure loads without individual tie-downs. ULDs are also integral to the aircraft structure during flight because they interface directly with the cargo loading system.

Types

ULDs come in two main forms: containers (often called cans or pods), which are closed boxes with a contoured profile matching the aircraft fuselage, and pallets, flat aluminium sheets onto which cargo is stacked and secured with nets. Common container types include the LD3 (AKE), the standard lower-deck container for wide-body aircraft; the LD6 and LD11; and the A330/A340 and 747-specific shapes. A common main-deck pallet size is 96 × 125 inches. Lower-deck containers have a base of 60.4 × 61.5 inches (half-width) or full-width configurations.

Identification

Every ULD carries a unique identification code assigned under IATA rules. The code combines a three-letter type prefix (for example AKE for a certified lower-deck container), a five-digit serial number, and a two-character owner code indicating the airline. This allows the global fleet of roughly one million ULDs to be tracked and interchanged between airlines.

Handling and regulation

Because a damaged or improperly restrained ULD can compromise flight safety, ULD operations are governed by the IATA ULD Regulations and airworthiness standards such as NAS 3610. Special types exist for specific cargo: refrigerated containers with active cooling, insulated containers, horse stalls, car racks, and secure containers for valuables. Fire-resistant and fire-containment covers have become increasingly widespread for shipments containing lithium batteries.
