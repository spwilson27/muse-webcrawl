Cinnamon (desktop environment)

From Wikipedia, the free encyclopedia

Cinnamon is a free and open-source desktop environment for Linux and other Unix-like operating systems. It was developed by the Linux Mint team as a fork of GNOME Shell, first released in 2011, and is the default desktop of Linux Mint's flagship edition.

Design

Cinnamon aims to provide a traditional desktop metaphor — a bottom panel with a menu, taskbar and system tray — in reaction to the more radical interface changes of GNOME 3. Its components include the Muffin window manager (a fork of Mutter) and the Nemo file manager (a fork of Nautilus). Users can customise the desktop with themes, applets, desklets and extensions distributed through the Cinnamon Spices website.

History and adoption

The project began as a set of extensions for GNOME Shell (the Mint GNOME Shell Extensions) before becoming a full fork in 2012 with version 1.4. Beyond Linux Mint, Cinnamon is packaged for many distributions, including Debian, Ubuntu (as the Ubuntu Cinnamon flavour), Fedora and Arch Linux.
