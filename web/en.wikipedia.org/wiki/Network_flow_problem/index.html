Network flow problem

In graph theory, a network flow problem concerns the movement of a commodity through a directed graph called a flow network, where each edge has a capacity and receives a flow that cannot exceed that capacity. Flow enters at a source node and leaves at a sink node, and at every other node the inflow equals the outflow (flow conservation).

Maximum flow

The best-known problem is the maximum flow problem: finding the greatest feasible flow from source to sink. The max-flow min-cut theorem states that the value of a maximum flow equals the capacity of a minimum cut separating source from sink. Classic algorithms include the Ford–Fulkerson method, the Edmonds–Karp algorithm and the push–relabel algorithm.

Applications

Network flow models are used in transportation, telecommunications, logistics, bipartite matching, project scheduling and image segmentation. Variants include the minimum-cost flow problem and multi-commodity flow problems.
