Destructor (computer programming)

In object-oriented programming, a destructor is a method which is invoked mechanically just before the memory of an object is released. It can be used to clean up resources — such as closing file handles, releasing locks, or freeing heap memory — that were allocated during the object's lifetime.

Syntax and semantics

In C++, a destructor is declared with the name of the class preceded by a tilde, e.g. ~Widget(). It takes no arguments, returns nothing, and cannot be overloaded. Destructors are invoked automatically when a stack-allocated object goes out of scope, when delete is applied to a heap object, and for member objects in reverse order of construction. A class with virtual functions that is used polymorphically should declare a virtual destructor so that the derived class's destructor runs correctly.

RAII

Destructors are the cornerstone of the RAII (Resource Acquisition Is Initialization) idiom, in which resource lifetime is bound to object lifetime, guaranteeing cleanup even when exceptions are thrown. In languages with garbage collection, such as C# and Java, analogous finalizers exist but run non-deterministically, so deterministic disposal patterns (e.g. IDisposable, try-with-resources) are preferred.
