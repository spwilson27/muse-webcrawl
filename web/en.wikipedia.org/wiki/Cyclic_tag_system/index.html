A cyclic tag system is a modification of the tag system originally developed by Emil Leon Post, introduced by Matthew Cook and used in his proof that the cellular automaton Rule 110 is Turing-complete. It is a minimal computational model operating on a binary string.

Definition

A cyclic tag system consists of a finite cyclic list of productions (finite binary strings, possibly empty) and an initial data string of 0s and 1s. At each step, the first symbol of the data string is read and deleted. If it was a 1, the current production is appended to the end of the data string; if it was a 0, nothing is appended. The system then advances to the next production in the list, wrapping around to the first after the last. Computation halts if the data string becomes empty.

Universality

Cyclic tag systems can simulate ordinary tag systems, and Cook showed how Rule 110 can emulate a cyclic tag system using gliders and background patterns — completing the proof that Rule 110, a one-dimensional cellular automaton, is capable of universal computation. Stephen Wolfram popularised this result in A New Kind of Science (2002).
