Functional programming

Functional programming is a programming paradigm in which programs are constructed by applying and composing functions. It is a declarative paradigm based on the lambda calculus, treating computation as the evaluation of mathematical functions and avoiding changing state and mutable data.

History

The paradigm's theoretical foundation is Alonzo Church's lambda calculus of the 1930s. Lisp, created by John McCarthy in 1958, was the first functional language; later milestones include ML, Haskell, Erlang, and the incorporation of functional features into mainstream languages such as JavaScript, Python, and Java.

Concepts

Key concepts include pure functions, immutability, first-class and higher-order functions, recursion in place of loops, lazy evaluation, and pattern matching. Popular operations such as map, filter, and reduce derive from functional practice.

Advantages and criticism

Functional code is often easier to reason about, test, and parallelize, because pure functions have no side effects. Critics note performance costs of immutability and a steep learning curve, though modern compilers mitigate many costs.
