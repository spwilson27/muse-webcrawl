Parameter (computer programming)

Arguments supplied at a call site are bound to the parameters declared in the function definition.

In computer programming, a parameter or a formal argument is a special kind of variable used in a subroutine to refer to one of the pieces of data provided as input to the subroutine. These pieces of data are the values of the arguments (often called actual arguments or actual parameters) with which the subroutine is going to be called or invoked.

Terminology

The distinction is commonly summarised as "parameters are declared, arguments are passed". In the function definition:

def add(x, y):
    return x + y

x and y are parameters. In the call add(3, 4), the values 3 and 4 are the arguments.

Parameter passing

Programming languages differ in how arguments are associated with parameters. Common evaluation strategies include call by value, in which the argument's value is copied, and call by reference, in which the parameter becomes an alias of the argument variable. Many languages also support default parameters, which supply a value when no argument is given, and variadic parameters, which accept a variable number of arguments.

Output parameters

Some languages allow parameters to be used to return results from a subroutine (output or in-out parameters), in addition to or instead of a return value. In C, for example, passing a pointer to a variable lets a function modify the caller's variable.
