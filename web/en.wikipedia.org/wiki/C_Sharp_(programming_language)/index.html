C# (pronounced "C sharp") is a general-purpose, high-level programming language developed by Microsoft. It was created by Anders Hejlsberg and his team as part of the .NET initiative and first released in 2000. The language is standardised by Ecma (ECMA-334) and ISO, and is widely used for Windows applications, web services, enterprise software, and game development with the Unity engine.

History

Development began in 1999 under the codename "Cool". The language was announced as C# in July 2000 alongside the .NET Framework. Hejlsberg, who had earlier designed Turbo Pascal and Delphi, was the lead architect. Successive versions added generics (C# 2.0), LINQ and lambda expressions (3.0), asynchronous programming with async/await (5.0), pattern matching (7.0 onwards), records and nullable reference types (8.0–9.0), and further features in annual releases aligned with modern .NET.

Features

C# is a statically typed, object-oriented language with a syntax derived from C and C++ and similarities to Java. Programs compile to Common Intermediate Language (CIL) and run on the Common Language Runtime (CLR), which provides garbage collection, type safety and just-in-time compilation. Notable features include properties, events and delegates, LINQ for querying data, and strong support for component-oriented programming.

Example

using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }
}

Name

The name "C sharp" is inspired by the musical notation in which a sharp raises a note by a semitone; it suggests C# is an increment over C++. Because the ♯ symbol is not available on standard keyboards, the number sign # is used.
