Whonix

Whonix
Type: Operating system (security-focused)
Based on: Debian, Kicksecure
Routing: Tor network

Whonix is a free and open-source desktop operating system designed for advanced security and privacy, based on Debian and the Tor anonymity network. Its defining feature is an isolated two-virtual-machine architecture that forces all network traffic through Tor.

Architecture

Whonix consists of two virtual machines: the Whonix-Gateway, which runs Tor and acts as the sole network gateway, and the Whonix-Workstation, where user applications run and which can only reach the internet through the gateway. Because the workstation has no direct network access, even malware with administrative privileges cannot easily discover the user's real IP address or bypass Tor. Whonix can run in hypervisors such as VirtualBox, KVM, or under Qubes OS.

History

The project began in 2012 as "TorBOX" and was later renamed Whonix. It has since integrated the Kicksecure hardening platform as its base.
