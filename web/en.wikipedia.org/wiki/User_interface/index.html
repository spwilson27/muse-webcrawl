User interface

In the industrial design field of human–computer interaction, a user interface (UI) is the space where interactions between humans and machines occur. The goal of this interaction is to allow effective operation and control of the machine from the human end, while the machine simultaneously feeds back information that aids the operator's decision-making process.

Types

User interfaces include command-line interfaces, which accept typed textual commands; graphical user interfaces (GUIs), which present windows, icons, menus, and pointers; touch user interfaces; voice user interfaces; and natural user interfaces that respond to gestures and movement. Physical interfaces, such as knobs, switches, and steering wheels, are also user interfaces.

History

Early computers were operated through batch processing and punched cards. The development of interactive terminals, the command line, and later the graphical interfaces pioneered at Xerox PARC and popularised by the Apple Macintosh and Microsoft Windows transformed computing into a direct-manipulation activity accessible to non-specialists.

Design principles

Good interface design emphasises clarity, consistency, feedback, and error tolerance, matching the user's mental model of the system. The design of user interfaces is a central concern of human–computer interaction research and practice.
