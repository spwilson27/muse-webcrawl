Q-learning

TypeReinforcement learning algorithm
Introduced1989 (Chris Watkins)
ClassModel-free, value-based, off-policy

Q-learning is a model-free reinforcement learning algorithm for learning the value of an action in a particular state. It seeks an action-value function Q(s, a) — the expected cumulative reward of taking action a in state s and following an optimal policy thereafter. Because it learns the value of the optimal action independently of the policy being followed, Q-learning is an off-policy method. It was introduced by Chris Watkins in his 1989 doctoral thesis and became one of the foundational algorithms of reinforcement learning.

Algorithm

The algorithm maintains a table (or function approximator) of Q-values, initialised arbitrarily, and updates it after each observed transition using the Bellman optimality equation:

Q(s, a) ← Q(s, a) + α [ r + γ · maxa′ Q(s′, a′) − Q(s, a) ]

where α is the learning rate, r the observed reward, γ the discount factor, and s′ the resulting state. Watkins and Dayan proved in 1992 that Q-learning converges to the optimal action-value function provided every state–action pair is visited infinitely often and the learning rate satisfies standard stochastic-approximation conditions. Exploration is commonly handled with an ε-greedy strategy.

Variants and applications

For state spaces too large for a table, Q-values can be approximated with neural networks. This idea underlies deep Q-networks (DQN), used by DeepMind in 2015 to learn Atari 2600 games from raw pixels. Other variants include Double Q-learning (which reduces maximisation bias), SARSA (the on-policy counterpart) and various dueling and distributional architectures.
