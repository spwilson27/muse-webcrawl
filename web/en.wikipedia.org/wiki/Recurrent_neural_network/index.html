Recurrent neural network

Recurrent neural network
Type: Artificial neural network
Applications: Sequence modelling, speech recognition, machine translation, time-series prediction

A recurrent neural network (RNN) is a class of artificial neural networks designed for processing sequential data. Unlike feedforward networks, an RNN maintains a hidden state that carries information from earlier elements of a sequence to later ones, giving the network a form of memory.

Architecture

At each time step t, the network receives an input xt and updates its hidden state ht = f(Whht−1 + Wxxt + b). The same weights are shared across all time steps. Outputs may be produced at every step, as in language modelling, or only after the whole sequence has been consumed, as in sentiment classification.

Training

RNNs are trained by backpropagation through time, in which the network is unrolled into a deep feedforward network and gradients are propagated across time steps. Plain RNNs suffer from vanishing and exploding gradients, which make learning long-range dependencies difficult.

Variants

Long short-term memory

The long short-term memory (LSTM) architecture, proposed by Sepp Hochreiter and Jürgen Schmidhuber in 1997, uses gated memory cells with input, forget, and output gates that regulate information flow and largely solve the vanishing gradient problem.

Gated recurrent unit

The GRU, introduced in 2014, simplifies the LSTM with fewer gates and parameters while retaining comparable performance.

Other variants

Elman and Jordan networks, echo state networks, bidirectional RNNs, and neural Turing machines are other members of the family. The Hopfield network is an early recurrent model.

Applications

RNNs were the dominant architecture for speech recognition, handwriting recognition, machine translation, and text generation before being largely superseded by the Transformer architecture after 2017; they remain useful for streaming and low-latency sequence tasks.
