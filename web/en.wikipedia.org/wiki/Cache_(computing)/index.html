Cache (computing)

In computing, a cache is a hardware or software component that stores data so that future requests for that data can be served faster; the data stored in a cache might be the result of an earlier computation or a copy of data stored elsewhere. A cache hit occurs when the requested data can be found in a cache, while a cache miss occurs when it cannot. Caches exploit locality of reference — the tendency of programs to access the same data repeatedly or data near previously accessed locations.

Overview

Caches are typically small, fast stores placed between a consumer of data and a larger, slower backing store. Because faster storage is more expensive, caches trade capacity for speed: keeping the most likely-to-be-reused data close at hand greatly improves average access time. When the cache is full, a replacement policy decides which entry to evict; common policies include least recently used (LRU), least frequently used (LFU), and random replacement.

Hardware caches

Modern CPUs include multiple levels of cache (L1, L2, and often L3) between the processor cores and main memory. The L1 cache is smallest and fastest, located on the processor die itself; higher levels are progressively larger and slower. Disk drives and storage devices also employ caches, buffering data in RAM to reduce the cost of mechanical or flash access.

Software caches

Software caching appears at many layers: web browsers cache pages and images; operating systems maintain a page cache of file data in unused RAM; web servers and content delivery networks cache responses; databases cache query results and index pages. Application-level caches such as Memcached and Redis store key-value pairs in memory for rapid retrieval.

Cache coherence and writing policies

In multiprocessor systems, multiple caches may hold copies of the same data, requiring coherence protocols to keep them consistent. Write policies determine when changes propagate to the backing store: write-through caches update both cache and store immediately, while write-back caches defer updates until the entry is evicted.
