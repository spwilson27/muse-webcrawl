Cloud migration

Cloud migration is the process of moving digital business operations into the cloud. Cloud migration is the movement of data, applications or other business elements from on-premises hardware and software to the cloud, or from one cloud environment to another — sometimes called cloud-to-cloud migration.

Strategies

Industry frameworks describe migration strategies often summarised as the "6 Rs":

  • Rehost ("lift and shift") — deploy applications as-is on cloud infrastructure.
  • Replatform ("lift and reshape") — make limited optimisations during migration.
  • Repurchase — replace the application with a different, usually SaaS, product.
  • Refactor / re-architect — rebuild the application using cloud-native features.
  • Retire — decommission applications that are no longer needed.
  • Retain — keep the application in its existing environment.

Considerations

Organisations migrate seeking scalability, flexibility, cost optimisation, and access to managed services. Challenges include data gravity and transfer costs, application dependencies, security and regulatory compliance, downtime risk during cutover, and the possibility of vendor lock-in. Migrations are commonly preceded by an assessment phase that inventories the application portfolio and maps dependencies, followed by migration in waves with testing at each stage.
