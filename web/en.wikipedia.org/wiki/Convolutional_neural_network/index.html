A convolutional neural network (CNN) is a type of neural network in which at least one layer uses convolution instead of general matrix multiplication. CNNs are the dominant architecture for computer vision tasks such as image classification and object detection.

Architecture

Convolutional layers apply small learnable filters across the input, exploiting local connectivity and weight sharing; pooling layers (e.g. max pooling) down-sample feature maps; stacks of these extract hierarchies of features — edges, then textures, then parts and objects — ending in fully connected classification layers. Nonlinearities such as ReLU follow each convolution.

History

Kunihiko Fukushima's Neocognitron (1980) introduced the convolutional-pooling pattern; Yann LeCun's LeNet (1989–1998) learned digit recognition by backpropagation. In 2012, AlexNet decisively won the ImageNet challenge, launching the deep-learning era. Later landmarks include VGG, GoogLeNet, and ResNet (2015, residual connections).

Applications

Image and video recognition, medical image analysis, face recognition, autonomous vehicles, and — via 1-D convolutions — speech and time-series analysis.

Variants

Fully convolutional networks for segmentation (U-Net), region-based detectors (R-CNN family), and single-shot detectors (YOLO, SSD) adapt the basic design.
