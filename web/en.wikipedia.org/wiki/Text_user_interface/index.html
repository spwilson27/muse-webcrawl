Text user interface

A text user interface (TUI), also called a textual user interface or terminal user interface, is a user interface that runs in a text terminal or terminal emulator and uses the character grid of the display — with box-drawing characters, colours, and mouse support where available — to present menus, windows, forms, and dialogues. TUIs sit between pure command-line interfaces, where interaction is a scrolling stream of text, and graphical user interfaces built from pixels.

Characteristics

TUIs exploit the text mode of terminals such as the VT100 and the ANSI escape sequences for cursor positioning and colour. Libraries such as curses (and its successor ncurses) on Unix, and Turbo Vision on DOS, standardised full-screen text applications: file managers (Midnight Commander, Norton Commander), text editors (Emacs, Vim in terminal form), installers, and system monitors. Classic examples include the MS-DOS Editor, Lotus 1-2-3's menu interface, and the BIOS setup screens of PCs. On modern systems, TUIs remain popular for server and developer tools — htop, tmux, git interfaces such as tig — because they work over SSH, consume few resources, and are scriptable and accessible.

Comparison

Unlike a CLI, a TUI maintains a persistent two-dimensional layout and responds to single keystrokes rather than whole commands; unlike a GUI, it renders with a fixed monospace character set, limiting graphics but guaranteeing consistent appearance on almost any terminal.
