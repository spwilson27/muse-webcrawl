6LoWPAN

6LoWPAN
IPv6 over Low-Power Wireless Personal Area Networks
Standardised chiefly in IETF RFC 4944 and related documents.

6LoWPAN is a networking technology that adapts Internet Protocol version 6 (IPv6) to low-power wireless personal area networks, especially networks based on IEEE 802.15.4. Its name is an acronym for “IPv6 over Low-Power Wireless Personal Area Networks.” The design lets very small, battery-powered devices—sensors, switches, meters and embedded controllers—participate in IP networks without requiring a wholly separate protocol stack.

Motivation

IEEE 802.15.4 frames are small, with a maximum physical-layer packet of 127 bytes, while an IPv6 header alone is 40 bytes and IPv6 requires links to support a much larger minimum transmission unit. Directly placing ordinary IPv6 and transport headers into such frames would leave little room for data and would waste energy. 6LoWPAN therefore supplies an adaptation layer between the link layer and IPv6 that compresses headers, fragments larger datagrams when necessary and supports mesh forwarding.

Mechanisms

Header compression exploits the fact that many fields in a local wireless network are predictable or can be inferred from link-layer addresses. Later work, including RFC 6282, refined the compression format and supported compression of UDP headers and some extension headers. Fragmentation and reassembly allow IPv6 packets to cross links whose frames are far smaller than the packet. Mesh addressing permits frames to be forwarded from node to node before IP routing begins, although routed topologies are also common.

Applications

6LoWPAN became an important building block for the Internet of things. It is associated with home automation, industrial sensing, smart metering, environmental monitoring and early work that fed into Thread and other low-power IP networking systems. Its central idea—that constrained devices should use interoperable IP protocols rather than isolated gateways for every function—helped move embedded networking toward end-to-end Internet architecture.
