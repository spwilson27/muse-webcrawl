Stack machine

In computer science, a stack machine is a computer processor — or a virtual machine — whose primary interaction is with a push-down stack rather than with named registers. Most instructions are "zero-address" instructions: they implicitly take their operands from the top of the stack and push their results back onto it.

Evaluation of (3 + 4) × 5 on a stack machine: push 3, push 4, add, push 5, multiply

Characteristics

Because operands are implicit, stack-machine instructions are short, giving high code density and simple compilers; expressions compile naturally from postfix (reverse Polish) form. The trade-off is that stack manipulation can create a bottleneck at the top of the stack in hardware designs.

Examples

Historical stack machines include the Burroughs large systems (B5000 onward), the HP 3000, and many Forth processors. Virtual stack machines are even more common: the Java virtual machine, .NET's Common Language Runtime, WebAssembly's validation model, and the Bitcoin script engine all use stack-based bytecode.
