Record (computer science)

From Wikipedia, the free encyclopedia

In computer science, a record (also called a structure, struct, or compound data) is a basic data structure. Records are among the simplest data structures. A record is a value that contains other values, typically in a fixed number and sequence and typically indexed by names. The elements of records are usually called fields or members.

In the context of databases, a row in a table can be considered a record.

Description

A record type is a data type that describes such values and variables. Most modern computer languages allow the programmer to define new record types. The definition includes specifying the data type of each field and an identifier (name or label) by which it can be accessed. In type theory, product types (with no special name) are generally preferred due to their simplicity, but most languages provide records for convenience.

Records are distinguished from arrays by the fact that their number of fields is typically fixed, each field has a name, and the fields may have different types. In contrast, the elements of an array are accessed by numeric index and are usually of a single type.

Examples

A record in Pascal:

type Person = record
  Name: string;
  Age: Integer;
end;

A struct in C:

struct Person {
    char name[50];
    int age;
};

Modern languages such as C# and Java provide dedicated record constructs (record classes in C# 9 and Java 14 and later) that automatically generate equality members, hash codes and string representations based on the record's fields, supporting immutable data modelling.

History

The concept of a record originates with punched-card accounting machines and the file-processing tradition in business computing. COBOL was among the first widely used languages with explicit record definitions, reflecting its orientation toward business data processing. Record types were a central feature of Pascal, designed by Niklaus Wirth, and of its successors.

Records in databases

In relational databases, a record is often used interchangeably with a row: a single, implicitly structured data item in a table. A record is a collection of fields, possibly of different data types, typically in a fixed number and sequence. The columns of the table correspond to the fields of the record type.
