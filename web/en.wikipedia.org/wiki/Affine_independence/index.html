Affine independence

FieldMathematics (affine geometry, linear algebra)
DefinitionA set of points whose only affine combination equal to zero with coefficients summing to zero is the trivial one
Maximum sizen + 1 points in n-dimensional space
Related conceptsLinear independence, affine hull, simplex, barycentric coordinates
Three non-collinear points are affinely independent and span a triangle (a 2-simplex)

In affine geometry, a set of points is said to be affinely independent if no point in the set lies in the affine hull of the others — equivalently, if the vectors formed by subtracting one of the points from all the rest are linearly independent.

Definition

Formally, points x0, x1, …, xk in an affine space are affinely independent if the only scalars λ0, …, λk satisfying both λ0 + … + λk = 0 and λ0x0 + … + λkxk = 0 are λ0 = … = λk = 0. Equivalently, the difference vectors x1 − x0, …, xk − x0 are linearly independent; the choice of base point does not affect the result.

Examples and consequences

Two distinct points are always affinely independent; three points are affinely independent exactly when they are not collinear; four points exactly when they are not coplanar. In n-dimensional space at most n + 1 points can be affinely independent, and a maximal such set forms the vertices of an n-simplex — a segment, triangle, tetrahedron, and so on — and serves as an affine basis: every point of the space can then be written uniquely as an affine combination of the basis points, the coefficients being its barycentric coordinates.

Relation to linear independence

If the points are embedded in a vector space, affine independence of x0, …, xk corresponds to linear independence of the vectors (x0, 1), …, (xk, 1) in one dimension higher — the standard device by which affine geometry is reduced to linear algebra.
