Working memory

Working memory
FieldCognitive psychology, neuroscience
FunctionTemporary storage and manipulation of information
Key modelBaddeley & Hitch (1974) multicomponent model
CapacityAbout 4 ± 1 chunks (Cowan); classically 7 ± 2 (Miller)
Key brain regionPrefrontal cortex

Working memory is a cognitive system with limited capacity that temporarily holds information available for processing, enabling reasoning, comprehension, problem-solving and mental arithmetic. It differs from short-term memory in emphasising the active manipulation, not merely the storage, of information, and it is strongly associated with activity in the prefrontal cortex.

The multicomponent model of working memory

The multicomponent model

Alan Baddeley and Graham Hitch proposed in 1974 that working memory comprises a central executive that directs attention, a phonological loop that rehearses speech-based information, and a visuospatial sketchpad that handles visual and spatial material. In 2000 Baddeley added an episodic buffer, a multimodal store that integrates information across the subsystems and with long-term memory. The model was supported by dual-task experiments showing that verbal and visual tasks interfere selectively with their corresponding subsystems.

Capacity

George A. Miller's famous 1956 paper placed short-term memory capacity at "the magical number seven, plus or minus two" items; later research by Nelson Cowan and others argues that the core capacity, when rehearsal and chunking are controlled, is closer to four chunks. Capacity varies between individuals, predicts performance in reading comprehension and reasoning tests, and declines with age and in conditions such as ADHD and schizophrenia.
