Common Intermediate Language

From Wikipedia, the free encyclopedia

Common Intermediate Language (CIL), formerly called Microsoft Intermediate Language (MSIL) or Intermediate Language (IL), is the intermediate language instruction set defined by the Common Language Infrastructure (CLI) specification. CIL instructions are executed by a CLI environment such as the Common Language Runtime. Languages that target the CLI compile into CIL, which is assembled into an object code format known as a portable executable (PE) assembly.

Design

CIL is a CPU- and platform-independent, stack-based bytecode, object-oriented in design: it has instructions for loading, storing, initializing, and calling methods on objects, as well as for arithmetic and logical operations, control flow, and exception handling. Unlike register-based virtual machines, operands are pushed onto and popped from an evaluation stack. CIL code is fully type-described through metadata carried in the assembly, enabling verification of type safety before execution.

Compilation and execution

At run time, a just-in-time (JIT) compiler translates CIL into native machine code. Ahead-of-time compilation is also possible, for example with .NET Native or NativeAOT, or via Microsoft's NGen tool. The disassembler ILDASM and assembler ILASM are distributed with the .NET SDK.

Example

.method public static void Main() cil managed
{
  .entrypoint
  ldstr "Hello, world!"
  call void [System.Console]System.Console::WriteLine(string)
  ret
}

Relationship to the CLI

CIL should not be confused with the Common Language Infrastructure itself: the CLI is the overall specification (standardised as ECMA-335 and ISO/IEC 23271) for the runtime, type system, and libraries, of which CIL is the instruction-set component.
