Bounded operator

FieldFunctional analysis
DefinitionA linear operator mapping bounded sets to bounded sets
EquivalentlyA continuous linear operator between normed spaces

A bounded linear operator sends the unit ball of the domain into a bounded set.

In functional analysis, a bounded operator is a linear operator T : X → Y between normed vector spaces that maps bounded sets in X to bounded sets in Y. Equivalently, there is a constant C ≥ 0 such that ‖Tx‖ ≤ C‖x‖ for every x in X. For linear operators, boundedness is the same as continuity — a fact that is false for nonlinear maps.

Operator norm

The smallest such constant C is the operator norm of T, written ‖T‖. It can be computed as the supremum of ‖Tx‖ over all unit vectors x. With the operator norm, the space B(X, Y) of all bounded linear operators becomes a normed space; when Y is complete (for example, a Banach space acting on itself), B(X, Y) is itself a Banach space. Every operator on a finite-dimensional space is bounded, and the matrix norm of a matrix gives an example.

Examples and counterexamples

Multiplication operators by bounded functions, integral operators with well-behaved kernels (such as Hilbert–Schmidt operators), and the unilateral shift on ℓ² are bounded. By contrast, differentiation is an unbounded operator on spaces of functions: on L², the operator Df = f′ can increase norms without limit. Many operators of quantum mechanics, including position and momentum, are unbounded and must be studied with careful attention to their domains.

The bounded inverse theorem

A cornerstone result, the bounded inverse theorem (a corollary of the open mapping theorem), says that a bijective bounded linear operator between Banach spaces has a bounded inverse. Banach also proved that a linear operator defined everywhere on a Banach space with a closed graph is automatically bounded (the closed graph theorem), and the Hellinger–Toeplitz theorem shows that an everywhere-defined symmetric operator on a Hilbert space is bounded.
