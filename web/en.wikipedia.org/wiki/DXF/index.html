AutoCAD DXF

Drawing Interchange Format, or Drawing Exchange Format (DXF), is a CAD data file format developed by Autodesk for enabling data interoperability between AutoCAD and other programs. It was introduced with AutoCAD 1.0 in 1982.

DXF files are either ASCII text or binary. Data is organised as groups of a group code and a value, describing entities such as lines, circles, text, layers and blocks in sections named HEADER, TABLES, BLOCKS, ENTITIES and OBJECTS. ASCII DXF files can be parsed and generated by many drawing, CAM and CNC programs, making DXF a de facto exchange standard, especially for 2D profiles used in laser and plasma cutting.
