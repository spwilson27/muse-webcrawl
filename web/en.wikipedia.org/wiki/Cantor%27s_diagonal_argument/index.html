Cantor's diagonal argument

Cantor's diagonal argument is a proof by Georg Cantor, published in 1891, that there are infinite sets which cannot be put into one-to-one correspondence with the natural numbers — in particular, the real numbers are uncountable.

Field: Set theory
Author: Georg Cantor
Published: 1891

The argument

Given any supposed list of real numbers between 0 and 1, a new number can be constructed by changing the nth digit of the nth number in the list, producing a real number absent from the list — contradicting the assumption that all reals were listed.

Influence

Diagonalisation became a central technique in logic and computer science, used in proofs relating to the halting problem and Gödel's incompleteness theorems.
