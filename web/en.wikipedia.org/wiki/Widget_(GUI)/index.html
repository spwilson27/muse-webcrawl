Widget (GUI)

In a graphical user interface (GUI), a widget (also called a control or element) is a standardized component of interaction that the user manipulates directly: a button, checkbox, slider, scroll bar, text field, menu, or list box. Widgets are the building blocks from which windows and dialogs are assembled.

History

The concept was developed at Xerox PARC in the 1970s as part of the WIMP (windows, icons, menus, pointer) paradigm. The term "widget" — a generic manufactured gadget — was adopted in the X Window System's Athena and Motif toolkits in the 1980s and 1990s and became standard vocabulary in GUI programming.

Widget toolkits

Widget toolkits and frameworks such as GTK, Qt, Tk, and the browser's HTML form controls provide libraries of prebuilt widgets with consistent look, feel, and behavior, letting application developers compose interfaces without drawing each control manually.
