Extended Kalman filter

The predict–update loop of the extended Kalman filter.

In estimation theory, the extended Kalman filter (EKF) is the nonlinear version of the Kalman filter which linearises about the current mean and covariance estimate. The EKF has been the de facto standard in navigation systems, GPS, and process control since the 1960s, when it was developed for the Apollo guidance system.

Method

For a nonlinear system xk = f(xk−1, uk) + wk with measurements zk = h(xk) + vk, the EKF propagates the state estimate through the nonlinear function f, but propagates the covariance using the Jacobians of f and h evaluated at the current estimate. Each cycle has a predict step (time update) and a correct step (measurement update) that computes a Kalman gain exactly as in the linear filter, but with the linearised system matrices.

Limitations and variants

Because linearisation discards higher-order terms, the EKF can perform poorly — and even diverge — when nonlinearities are severe or initial errors are large. It is also not an optimal estimator in the nonlinear case. These shortcomings motivated alternatives such as the unscented Kalman filter (UKF), which propagates carefully chosen sigma points through the true nonlinearity, and particle filters, which represent the distribution non-parametrically. Despite this, the EKF remains widely used because of its simplicity, speed, and good behaviour in mildly nonlinear problems.

Applications

  • Spacecraft and aircraft navigation and attitude estimation.
  • Simultaneous localisation and mapping (SLAM) in robotics.
  • Battery state-of-charge estimation and biomedical signal tracking.
