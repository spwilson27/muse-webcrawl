Device driver

In computing, a device driver is a computer program that operates or controls a particular type of device attached to a computer or automaton. A driver provides a software interface to hardware devices, enabling operating systems and other programs to access hardware functions without needing to know precise details about the hardware being used.

Drivers typically communicate with the device through the computer bus or communications subsystem, translating generic commands from the operating system into device-specific operations and handling interrupts and data transfers. Many drivers run in kernel mode, so a faulty driver can destabilise the whole system; user-mode driver frameworks exist to mitigate this risk.

Modern operating systems ship with large libraries of generic and vendor-supplied drivers supporting printers, graphics processors, storage controllers, network adapters, and countless other peripherals, abstracted through models such as the Windows Driver Model or the Linux driver architecture.
