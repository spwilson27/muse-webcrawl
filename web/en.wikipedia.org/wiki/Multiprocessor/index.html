Multiprocessor

A multiprocessor system is a computer system with two or more central processing units (CPUs) that share access to a common main memory and peripherals, allowing tasks to be executed in parallel.

Types

In symmetric multiprocessing (SMP), all processors are peers running a single operating system image and sharing memory through a bus or interconnect; maintaining cache coherence among processors is a central design problem. In asymmetric multiprocessing, specific tasks are assigned to specific processors. NUMA (non-uniform memory access) systems give each processor local memory with faster access, scaling to larger processor counts.

History and modern form

Multiprocessor mainframes and minicomputers appeared from the 1960s onward. Today the concept is embodied in multicore processors, in which several CPU cores sit on one chip, and in large servers and supercomputers containing many sockets.

Advantages and challenges

Multiprocessors increase throughput and reliability, but gains depend on how much of the workload can be parallelised — a limit described by Amdahl's law — and on software support for concurrent execution.
