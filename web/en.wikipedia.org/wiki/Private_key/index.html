Private key

From Wikipedia, the free encyclopedia

A private key is a variable in cryptography that is used with an algorithm to encrypt and decrypt data. In asymmetric (public-key) cryptography, a private key is one half of a key pair: it is kept secret by its owner and is mathematically related to a corresponding public key that may be shared freely. Data encrypted with the public key can only be decrypted with the private key, while a digital signature created with the private key can be verified by anyone holding the public key.

Properties

The security of a private key rests on the computational infeasibility of deriving it from the public key — a problem typically based on integer factorisation (as in RSA), the discrete logarithm problem (Diffie–Hellman, DSA), or elliptic-curve analogues (ECDSA, EdDSA). Private keys must be generated with a cryptographically secure random number generator and stored securely, commonly in encrypted key files, hardware security modules, smart cards, or dedicated cryptocurrency wallets. Compromise of a private key destroys the security of the system it protects, since an attacker can decrypt messages, forge signatures, or impersonate the owner.

Uses

  • TLS/HTTPS: web servers hold private keys corresponding to their certificates.
  • SSH: users authenticate to servers with private keys instead of passwords.
  • Digital signatures: signing documents, software, and email (e.g., PGP).
  • Cryptocurrency: control of coins is effectively control of the private keys for an address.
