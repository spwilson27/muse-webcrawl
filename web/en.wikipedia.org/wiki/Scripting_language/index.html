Scripting language

A short script written in a high-level scripting language.

A scripting language or script language is a programming language that is used to control or automate the operations of a software system, often by interpreting programs — called scripts — at runtime rather than compiling them ahead of time. Scripting languages are typically high-level, dynamically typed, and designed for rapid development and gluing together existing components.

Paradigm: Often multi-paradigm, dynamic

Execution: Usually interpreted or JIT-compiled

Examples: JavaScript, Python, Perl, Ruby, Lua, Bash, PowerShell, Tcl

Typical uses: Automation, web development, system administration, embedding

Characteristics

Scripting languages generally offer automatic memory management, rich built-in data types such as lists and associative arrays, and concise syntax that favours programmer productivity over raw execution speed. Many began as job-control or command languages for operating systems — such as the Unix shells and IBM's JCL — and evolved into general-purpose languages.

Uses

Scripts automate repetitive tasks, configure systems, process text and files, drive web browsers and servers, and extend applications through embedded interpreters: Lua is widely embedded in games, JavaScript runs in every web browser, and Python is used for data analysis, machine learning and system administration as well as application scripting.

Scripting versus programming

The boundary between scripting languages and other programming languages is blurred. The distinction traditionally rested on interpretation versus compilation and on use for small, task-specific programs, but modern scripting languages support large applications, optional static typing, and just-in-time compilation, while traditional systems languages are sometimes interpreted.
