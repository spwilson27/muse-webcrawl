Written in: Ruby
Type: Web application framework

Ruby on Rails (often simply Rails) is a server-side web application framework written in Ruby. It follows the model–view–controller (MVC) architectural pattern and is known for its emphasis on convention over configuration and the DRY ("Don't Repeat Yourself") principle.

History

Rails was created by Danish programmer David Heinemeier Hansson, who extracted it from the project management tool Basecamp at the company 37signals. It was released as open source in 2004, with version 1.0 following in December 2005. Rails dramatically lowered the barrier to building database-backed web applications and influenced a generation of later frameworks in other languages. Companies that built major products on Rails include GitHub, Shopify, Airbnb, Twitter (in its early years), Kickstarter and GitLab.

Philosophy and features

Rails provides defaults for the entire application stack: Active Record as an object-relational mapping layer, Action View and Action Controller for request handling, migrations for database schema evolution, and built-in support for routing, testing, caching, internationalisation and asset management. Its scaffolding tools and generators allow developers to produce working prototypes quickly. Later releases added features such as the asset pipeline, Action Cable for WebSockets, Hotwire (Turbo and Stimulus) for building reactive interfaces with minimal JavaScript, and Active Storage for file uploads.

Rails is distributed as a Ruby gem via RubyGems and is typically deployed with application servers such as Puma.
