Advanced Message Queuing Protocol

AMQP
Type: Message-oriented middleware protocol
Standard: ISO/IEC 19464; OASIS AMQP 1.0 (2012)

The Advanced Message Queuing Protocol (AMQP) is an open standard application-layer protocol for message-oriented middleware. Its defining features are message orientation, queuing, routing (including point-to-point and publish-and-subscribe), reliability and security.

History and versions

AMQP originated at JPMorgan Chase in 2003. The widely implemented 0-9-1 version underlies the RabbitMQ broker. AMQP 1.0, standardised by OASIS in 2012 and as ISO/IEC 19464 in 2014, is a substantially redesigned wire protocol used by Azure Service Bus, Apache Qpid and Apache ActiveMQ.

Model

In the 0-9-1 model publishers send messages to exchanges, which route them according to bindings to queues, from which consumers receive them with acknowledgements. See also Message queue and RabbitMQ.
