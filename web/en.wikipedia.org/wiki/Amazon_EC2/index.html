Amazon Elastic Compute Cloud

Amazon EC2
Developer: Amazon Web Services
Initial release: 2006
Type: Virtual private servers / infrastructure as a service

Amazon Elastic Compute Cloud (Amazon EC2) is a part of Amazon's cloud-computing platform, Amazon Web Services (AWS), that allows users to rent virtual computers on which to run their own computer applications. EC2 encourages scalable deployment of applications by providing a web service through which a user can boot an Amazon Machine Image (AMI) to configure a virtual machine, called an "instance".

History

EC2 was announced in public beta in August 2006 and is widely regarded as one of the foundational services of modern cloud computing. It initially offered a single instance type and has since expanded to hundreds of instance types optimised for compute, memory, storage, and accelerated computing, including instances based on AWS's own Graviton ARM processors.

Pricing models

Instances can be purchased as On-Demand (by the hour or second), Reserved Instances with a term commitment, Savings Plans, or as Spot Instances that bid for spare capacity at discounted rates. Storage is provided by instance stores and Amazon Elastic Block Store volumes, and networking features include Elastic IP addresses and Virtual Private Cloud integration.
