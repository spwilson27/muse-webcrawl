FM-index

In computer science, an FM-index is a compressed full-text substring index based on the Burrows–Wheeler transform (BWT), with some similarities to the suffix array. It was created by Paolo Ferragina and Giovanni Manzini in 2000, from whom the "FM" in the name derives. The FM-index can count the occurrences of a pattern in the compressed text and locate the position of each occurrence, all within space roughly proportional to the compressed size of the text itself.

Structure

The index stores the BWT of the text — a permutation of its characters obtained by sorting all rotations of the text — together with auxiliary rank data structures. Two arrays or functions suffice for searching: C[c], the number of characters in the text lexicographically smaller than character c, and Occ(c, k), the number of occurrences of c in the first k characters of the transformed string. Combining these gives the LF-mapping, which maps a position in the transformed string to the position of the preceding character in the original text, allowing one to step through the text backwards.

Search

To count occurrences of a pattern, the index processes the pattern from its last character to its first, repeatedly narrowing an interval of the suffix array that corresponds to suffixes beginning with the already-processed suffix of the pattern. This backward search takes time linear in the length of the pattern (with fast rank queries). Locating each occurrence then requires sampling: the index stores the text positions of a subset of rows and recovers other positions by iterating the LF-mapping until a sampled row is reached, trading space for time.

Applications

Because the FM-index compresses while it indexes, it became fundamental in bioinformatics, where texts are genomes of billions of characters. The popular sequence aligners Bowtie and BWA use FM-index-based algorithms (the Burrows–Wheeler Aligner) to map short DNA sequencing reads to a reference genome quickly in modest memory. Variants such as the compressed suffix array, the r-index (which scales with the number of runs in the BWT and excels on collections of similar genomes), and bidirectional FM-indexes extend the basic scheme to support richer queries and pangenome data structures.
