TypeScript is a free and open-source high-level programming language developed by Microsoft that adds static typing with optional type annotations to JavaScript. It is designed for the development of large applications and transpiles to JavaScript. Because TypeScript is a superset of JavaScript, any valid JavaScript program is also a valid TypeScript program.

History

TypeScript was first made public in October 2012, after two years of internal development at Microsoft, led by Anders Hejlsberg, the creator of C# and Turbo Pascal. It was motivated by the difficulty of scaling large JavaScript codebases: static types enable editors to offer reliable refactoring, navigation and error detection before code runs. The language gained rapid adoption, notably after Google adopted it for Angular 2 in 2016, and it has consistently ranked among the most used and most loved languages in developer surveys.

Features

TypeScript's type system is structural: types are compatible when their members are compatible, regardless of declared names. It supports type inference, interfaces, classes, generics, union and intersection types, literal types, enums and namespaces, and it compiles newer ECMAScript features down to older JavaScript targets. Type annotations are erased at compile time, so they impose no runtime cost.

interface User { name: string; id: number; }
const user: User = { name: "Ada", id: 1 };

Existing JavaScript libraries can be used through declaration files (.d.ts), many of which are maintained in the community DefinitelyTyped repository. In 2025 Microsoft announced a native port of the compiler (written in Go) promising roughly tenfold speedups on large projects.
