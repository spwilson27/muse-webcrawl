In number theory, the Carmichael function λ(n) of a positive integer n is the smallest positive integer m such that

am ≡ 1 (mod n)

for every integer a coprime to n. In other words, λ(n) is the exponent of the multiplicative group of integers modulo n — the least common multiple of the orders of all elements of that group. The function was introduced by the American mathematician Robert Carmichael in 1910. It refines Euler's theorem, which states the same congruence holds with m equal to Euler's totient function φ(n); the Carmichael function often gives a smaller, and always the optimal, exponent.

Definition by prime factorisation

Carmichael's theorem gives λ(n) via the prime factorisation of n: for prime powers, λ(pk) = φ(pk) = pk − pk−1 for odd primes p, while for powers of two, λ(1) = 1, λ(2) = 1, λ(4) = 2, and λ(2k) = 2k−2 for k ≥ 3. For general n, λ(n) is the least common multiple of the values at its prime power factors. In particular λ(n) divides φ(n).

Examples

  • λ(8) = 2, since every odd number squared is ≡ 1 (mod 8).
  • λ(15) = lcm(λ(3), λ(5)) = lcm(2, 4) = 4.
  • λ(561) = lcm(λ(3), λ(11), λ(17)) = lcm(2, 10, 16) = 80, which divides 560 = 561 − 1 — an instance of the property underlying Carmichael numbers, composite numbers n for which λ(n) divides n − 1, so that they pass the Fermat primality test for every base coprime to n.

Applications

The Carmichael function appears in cryptography, notably in the RSA cryptosystem, where decryption works because exponents may be reduced modulo λ(n) of the modulus n = pq; using λ instead of φ can give smaller private exponents. Carmichael's conjecture (still open) concerns not λ but φ: it asserts that no value of Euler's totient is taken exactly once. Erdős proved in 1956 that the values of λ(n) grow roughly like n / (log n)log log log n for most n, far below φ(n) in typical size.
