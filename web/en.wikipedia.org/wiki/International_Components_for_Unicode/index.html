International Components for Unicode

From Wikipedia, the free encyclopedia


ICU provides Unicode and locale support for software.

International Components for Unicode (ICU) is an open-source project of mature C/C++ and Java libraries providing Unicode and globalisation support for software applications. ICU is maintained by the Unicode Consortium and is widely portable, giving applications the same results on all platforms and between C and Java software. It implements Unicode text handling, collation, formatting, transliteration, and regular expressions with data drawn from the Unicode Common Locale Data Repository (CLDR).

Features

ICU provides: conversion between legacy character encodings and Unicode; locale-sensitive collation (sorting) following the Unicode Collation Algorithm; formatting and parsing of dates, times, numbers, currencies, and messages with plural rules; transliteration between scripts; Unicode regular expressions; text boundary analysis for words, sentences, and lines; bidirectional text layout support; and code-page and script detection utilities. Its data files encode the conventions of several hundred locales.

History

ICU grew out of work at Taligent and IBM in the 1990s; the Java classes were contributed to Sun's JDK 1.1, and the C++ library (ICU4C) followed. It became a Unicode Consortium project in 2016. ICU underpins internationalisation in major platforms: it is used by many operating systems, browsers (through components in Chromium and Firefox), programming runtimes, and database systems, so that locale behaviour stays consistent across applications.

ICU4J and ICU4C

The library ships in two main forms: ICU4C for C and C++, and ICU4J for Java (which also underlies parts of Android's internationalisation). A later effort, ICU4X, reimplements the components in Rust for memory safety and small code size, targeting constrained environments.
