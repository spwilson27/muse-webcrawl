AArch64

AArch64 is the 64-bit execution state of the ARM architecture family, introduced with the ARMv8-A profile in 2011. It defines a new instruction set, A64, alongside the legacy 32-bit state AArch32 (which executes A32 and T32, the successors of ARM and Thumb). Code named ARM64 in the ecosystems of Apple and Microsoft refers to the same architecture. AArch64 underpins nearly all modern smartphones, Apple silicon Macs, and a growing share of servers and cloud instances.

Features

A64 uses fixed-length 32-bit instructions, like its predecessors, but with a cleaned-up encoding. The register file provides 31 general-purpose registers, X0–X30, each 64 bits wide; the lower 32 bits of each are accessible as W registers. Register X30 serves as the link register, while the stack pointer and program counter are dedicated registers outside the general file and cannot be freely used as operands. Predication of most instructions, a hallmark of the 32-bit ARM set, was removed in favour of conditional select and branch instructions, simplifying out-of-order pipeline design.

The architecture mandates support for the Advanced SIMD (NEON) unit with 32 registers of 128 bits, double-precision floating point, and cryptographic extensions for AES and SHA. Virtualisation (EL2) and the TrustZone security state are integral to the design, with four exception levels from EL0 (user) to EL3 (firmware).

History and adoption

Arm announced ARMv8-A in October 2011, and the first consumer devices — Apple's iPhone 5s with the A7 chip — shipped in 2013. Android followed with 64-bit support in Android 5.0 "Lollipop". Microsoft's Windows on ARM and Apple's transition of the Mac to Apple silicon (announced 2020) made AArch64 a mainstream desktop architecture. In servers, implementations such as Amazon's Graviton processors and the Ampere Altra family brought ARM64 into cloud data centres, while Linux distributions treat arm64 as a first-class architecture.

Extensions

Subsequent architecture versions added features including large system extensions, RAS (reliability, availability and serviceability), the Scalable Vector Extension (SVE and SVE2), and the Scalable Matrix Extension (SME). Armv9-A, announced in 2021, retains the A64 instruction set while adding security features such as Confidential Compute Architecture and memory tagging in later revisions.
