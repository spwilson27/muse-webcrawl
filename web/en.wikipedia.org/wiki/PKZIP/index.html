PKZIP

PKZIP is a file archiving computer program, notable for introducing the ZIP file format. It was written by Phil Katz and first released in 1989 by his company PKWARE, Inc.

History

Katz had previously written PKARC, an archiver compatible with System Enhancement Associates' ARC format. After a lawsuit from SEA over copyright and trademark, Katz withdrew PKARC and wrote PKZIP, which used a new and faster compression format and was distributed as shareware. PKZIP quickly became the standard archiver on MS-DOS and bulletin board systems.

The ZIP format

PKZIP defined the .ZIP file format and its "deflate" compression method. PKWARE later published the format specification in an application note, allowing many other tools to implement ZIP, and the format became the most widely used archive format on personal computers. Version 2.0 (1993) offered improved compression and multi-disk spanning.

Legacy

Phil Katz died in 2000. PKWARE continues to sell archiving and data security products, while the ZIP format Katz created remains built into every major operating system.
