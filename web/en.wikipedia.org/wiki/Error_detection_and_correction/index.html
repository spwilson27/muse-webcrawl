Error detection and correction

From Wikipedia, the free encyclopedia

Error detection and correction (EDAC) is a set of techniques that enable reliable delivery of digital data over unreliable communication channels. Many communication channels are subject to channel noise, and thus errors may be introduced during transmission from the source to a receiver. Error detection techniques allow detecting such errors, while error correction enables reconstruction of the original data in many cases.

Definitions

Error detection is the detection of errors caused by noise or other impairments during transmission from the transmitter to the receiver. Error correction is the detection of errors and reconstruction of the original, error-free data. The general definitions of error detection and correction are as follows:

  • Error detection: the process by which a receiver determines whether received data contains errors.
  • Error correction: the process by which a receiver, after detecting errors, reconstructs the original error-free information.

History

The modern development of error detection and correction codes is credited to Richard Hamming. Hamming errors in punch-card teleprinter codes motivated his work. In 1950 he published the Hamming(7,4) code, a linear error-correcting code that adds three parity bits to four data bits. Around the same period, Claude Shannon's 1948 paper A Mathematical Theory of Communication established the theoretical limits of reliable communication over noisy channels.

Error detection schemes

Repetition codes

A repetition code sends each data bit multiple times. If the channel flips some bits, the receiver takes a majority vote. Repetition codes are extremely inefficient and are mainly of theoretical interest, though they illustrate the basic principle of redundancy.

Parity bits

A parity bit is a bit appended to a string of binary code. It ensures that the total number of 1-bits in the string is even or odd. A single parity bit can detect any single-bit error but cannot correct it.

Checksums

A checksum is a modular arithmetic sum of message code words of a fixed word length, often transmitted along with the message. Checksums are used widely, for example in TCP/IP headers and file verification.

Cyclic redundancy checks

The cyclic redundancy check (CRC) treats data as a polynomial over a finite field and appends the remainder of a division by a generator polynomial. CRCs detect all burst errors up to the length of the remainder and are standard in Ethernet, storage devices, and many other systems.

Cryptographic hash functions

A cryptographic hash function produces a fixed-length digest of a message. Because it is computationally infeasible to find two messages with the same digest, hashes provide strong error (and tamper) detection, though they do not themselves correct errors.

Error correction

Error correction may generally be realized in two different ways:

  • Automatic repeat request (ARQ): the receiver detects errors and requests retransmission of the corrupted data. Their combination is often called hybrid ARQ.
  • Forward error correction (FEC): the sender encodes the data with an error-correcting code (ECC) that adds enough redundancy for the receiver to correct a limited number of errors without retransmission.

Error-correcting codes

Important families of error-correcting codes include:

  • Hamming codes — perfect single-error-correcting linear codes introduced by Richard Hamming in 1950.
  • Reed–Solomon codes — non-binary cyclic codes widely used in CDs, DVDs, QR codes, and deep-space communication.
  • Convolutional codes — codes whose parity bits depend on a sliding window of message bits, decoded with the Viterbi algorithm.
  • Turbo codes and LDPC codes — modern capacity-approaching codes used in mobile networks, Wi-Fi, and satellite links.
  • BCH codes — a class of cyclic codes generalising Hamming codes to multiple-error correction.

Applications

Error detection and correction are essential wherever data is stored or transmitted: computer memory (ECC RAM), hard disks and SSDs, optical discs, QR codes, deep-space probes, mobile telephony, and packet-switched networks. Without them, even a tiny bit-error rate would make modern digital systems unusable.
