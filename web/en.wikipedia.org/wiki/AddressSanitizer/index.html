AddressSanitizer (or ASan) is an open source programming tool by Google that detects memory corruption bugs such as buffer overflows and use-after-free errors. It is a compile-time instrumentation tool built into Clang, GCC, Xcode, and MSVC; programs are rebuilt with the -fsanitize=address flag and linked against a runtime library that tracks shadow memory to determine whether each memory access is valid.

Features

AddressSanitizer detects out-of-bounds accesses to heap, stack, and global objects, use-after-free and use-after-return errors, double frees, and memory leaks (via the bundled LeakSanitizer). Its typical performance overhead is roughly a factor of two in runtime and increased memory usage, making it suitable for testing and continuous integration.

History

AddressSanitizer was announced by Google in 2011 and contributed to LLVM and GCC. It has been used to find thousands of bugs in projects including Chromium, Firefox, and the Linux kernel ecosystem, and spawned related sanitizers for threads (ThreadSanitizer), memory initialization (MemorySanitizer), and undefined behavior (UndefinedBehaviorSanitizer).
