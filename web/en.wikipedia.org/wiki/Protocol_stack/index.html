Protocol stack

A protocol stack, or network stack, is a set of communications protocols organized in layers, in which each layer provides services to the layer above it and uses the services of the layer below. The term is especially associated with the implementation of suites such as the Internet protocol suite (TCP/IP) and the OSI model.

Layering

In a stack, each layer communicates with the corresponding peer layer on another host according to its protocol, while interacting vertically with adjacent layers through defined interfaces. Data passing down the stack is encapsulated — each layer adds its own header (and sometimes a trailer) to the payload it receives — and the process is reversed on receipt. Layering makes protocol design modular: a layer can be replaced (for example, Ethernet by Wi-Fi at the link layer) without redesigning the layers above.

Examples

The Internet protocol suite is commonly described in four layers: link, internet, transport, and application, with protocols such as Ethernet, IP, TCP/UDP, and HTTP at successive levels. The OSI reference model defines seven layers, from physical to application. Other stacks include Bluetooth, Zigbee, and the CAN bus protocols used in vehicles.

Implementation

Protocol stacks are implemented in operating-system kernels, in user-space libraries, and in dedicated hardware. Performance-critical stacks may be offloaded to network interface controllers or implemented with kernel-bypass techniques in high-performance computing and trading systems.
