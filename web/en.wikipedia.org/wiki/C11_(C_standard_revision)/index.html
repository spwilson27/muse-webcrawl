C11 (formerly C1X) is an informal name for ISO/IEC 9899:2011, a past standard for the C programming language. It replaced C99 (standard ISO/IEC 9899:1999) and was superseded by C17 (ISO/IEC 9899:2018). The standard was published in December 2011 after approval by ISO on 8 December 2011.

Changes from C99

C11 standardised the multithreading support that had been a common implementation need, adding a memory model, atomic operations (header <stdatomic.h>) and a threads library (<threads.h>). Other additions include generic selections via the _Generic keyword, anonymous structures and unions, static assertions (_Static_assert), exclusive file access modes, the quick_exit function, UTF-16/UTF-32 character types (char16_t, char32_t) with conversion functions, and alignment support (_Alignof, _Alignas, aligned_alloc). Support for some features, including threads and atomics, was made optional through feature-test macros, and the controversial Annex K bounds-checking interfaces remained optional.

Compiler support

Support was implemented progressively: GCC and Clang added most C11 features in releases from 2012 onward, while Microsoft's Visual C++ long lagged behind, substantially improving C11 conformance only with Visual Studio 2019 and later.
