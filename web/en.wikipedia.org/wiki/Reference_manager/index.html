Reference manager

A reference manager (also called citation management software or bibliographic software) is software used by scholars and authors to store, organise and retrieve bibliographic references, and to generate citations and bibliographies in documents according to thousands of citation styles.

Features

  • Building a personal database of references, imported from library catalogues, publisher sites and databases via DOI lookup, ISBN, BibTeX, RIS or direct capture.
  • Storing and annotating full-text PDFs, with automatic extraction of metadata.
  • Word-processor plugins (for Microsoft Word, LibreOffice and Google Docs) that insert citations while writing and format bibliographies dynamically using styles defined in the Citation Style Language (CSL).
  • Synchronisation across devices and facilities for sharing libraries among research groups.

Examples

SoftwareNotes
ZoteroFree and open-source; developed at George Mason University / Corporation for Digital Scholarship.

BibTeX / BibLaTeXReference system for LaTeX documents, with managers such as JabRef.
Citavi, Paperpile, ReadCubeOther commercial or freemium tools.

History

Bibliographic software emerged in the 1980s on personal computers; EndNote (1988) and ProCite were early leaders, while Reference Manager (from which the generic name derives) was an early product later absorbed into the Thomson Reuters/Clarivate catalogue and eventually discontinued. The release of the open-source Zotero in 2006, first as a Firefox extension, significantly widened adoption.
