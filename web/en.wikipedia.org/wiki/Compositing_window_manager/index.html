Compositing window manager

From Wikipedia, the free encyclopedia

Compositing enables per-window translucency, shadows, and smooth animation

A compositing window manager, or compositor, is a window manager that provides applications with an off-screen buffer for each window. The window manager composites the window buffers together to create the image of the desktop and writes the result into the display memory. This differs from a traditional "stacking" window manager, in which applications draw directly into the shared framebuffer.

Effects made possible

Because the compositor holds each window as a separate image (texture), it can manipulate windows freely before presenting them:

  • Drop shadows and window borders rendered independently of applications
  • True translucency and alpha blending between overlapping windows
  • Smooth scaling, fading, and animation of windows, including live previews and thumbnails (as in task switchers and Exposé/Mission Control)
  • Desktop effects such as virtual-desktop transitions, zooming accessibility aids, and 3D effects like the Compiz cube
  • Elimination of tearing and flicker, since partially drawn windows are never displayed

History and implementations

Compositing was popularized on the desktop by Apple's Quartz Compositor in Mac OS X (2001). On Linux and Unix, compositing for the X Window System became practical with the X Composite extension (2004) and managers such as Compiz (2006), KWin, and Mutter; the Wayland display protocol builds compositing into its core design, with the compositor also acting as the display server. Microsoft's Desktop Window Manager, introduced with Windows Vista (2007), made compositing standard on Windows. A drawback of compositing is some added latency and GPU memory use, which matters for full-screen games; many systems therefore "unredirect" or bypass composition for full-screen windows.

Compositing and tiling

Compositing is independent of the window-management model: compositors may stack windows in the familiar overlapping style or tile them without overlap, as in tiling compositors such as Sway under Wayland.
