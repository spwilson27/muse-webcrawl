Personal identification number

A personal identification number (PIN) is a numeric or alphanumeric passcode used in the process of authenticating a user accessing a system. PINs are most familiar as the codes used with payment cards at ATMs and point-of-sale terminals, and to unlock mobile phones and SIM cards.

History

The PIN is credited to the Scottish inventor James Goodfellow, who patented the concept of an encrypted personal number used with a machine-readable card in 1966 in connection with the first ATM systems. Four digits became the common length partly because of the memory limits of users — ATM pioneer John Shepherd-Barron's wife reportedly found four digits the most she could comfortably remember — though the relevant standard, ISO 9564, permits PINs of four to twelve digits.

Security

A PIN is a knowledge factor in multi-factor authentication, combined with a possession factor such as a card or phone. Systems typically allow only a few attempts before locking, limiting the chance of guessing a four-digit PIN (10,000 possibilities) by trial. PINs are transmitted and stored in encrypted form, often as "PIN blocks", and verified inside hardware security modules. Analyses of leaked PIN datasets show that users favour predictable choices such as 1234, 1111, and birth years, weakening real-world security.

Uses

Beyond banking, PINs protect chip-and-PIN debit and credit transactions, mobile SIMs (with a longer PUK code for recovery), telephone banking, door locks, and parental controls. Related codes include the card security code (CVV), which is not a PIN and is never supposed to be entered into the same channels.
