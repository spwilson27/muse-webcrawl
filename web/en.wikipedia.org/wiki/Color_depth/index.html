Color depth

Color depth or colour depth (see spelling differences in the article "Color"), also known as bit depth, is either the number of bits used to indicate the color of a single pixel, or the number of bits used for each color component of a single pixel. When referring to a pixel, the concept can be defined as bits per pixel (bpp). When referring to a color component, the concept can be defined as bits per component, bits per channel, bits per color, and so on.

Indexed color

At low bit depths, pixel values index into a palette (color lookup table) of up to 256 colors selected from a larger space. Formats such as GIF use 8-bit indexed color. Careful palette selection and dithering can make indexed images appear much richer than the palette size suggests.

True color and deep color

24-bit color allocates 8 bits each to red, green, and blue, yielding about 16.7 million combinations — roughly matching the discrimination of the human visual system. "Deep color" formats with 10 or more bits per channel reduce banding in gradients and are used in HDR video (e.g. HDR10, Dolby Vision) and professional imaging, where RAW photographs often store 12–14 bits per channel.

Alpha channel

An additional 8 bits per pixel is often used for an alpha channel (transparency), giving 32-bit RGBA images in which color depth is still conventionally described as 24-bit.
