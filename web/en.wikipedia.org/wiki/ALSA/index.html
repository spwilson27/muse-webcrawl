Advanced Linux Sound Architecture (ALSA) is a software framework and part of the Linux kernel that provides an application programming interface (API) for sound card device drivers. It was designed to replace the older Open Sound System (OSS) in the Linux kernel, adding support for features such as automatic configuration of sound-card hardware, software mixing of multiple audio streams, and full-duplex playback and capture.

History

The ALSA project was started in 1998 by Jaroslav Kysela, originally to write a Linux driver for the Gravis Ultrasound sound card. It was developed separately from the kernel for some time before being merged into the mainline kernel during the 2.5 development series, and it became the default sound architecture in Linux 2.6, displacing OSS (which was deprecated, though an emulation layer was retained).

Architecture

ALSA consists of kernel-space drivers for a wide range of audio hardware and a user-space library, alsa-lib, which presents a higher-level API to applications. Its design supports features including a modular driver structure, SMP and thread-safe operation, and a plugin system allowing resampling, channel conversion, and software mixing (via the dmix plugin). A sequencer interface supports MIDI hardware and software synthesizers.

Because ALSA operates at a low level, most desktop Linux systems layer an audio server such as PulseAudio or PipeWire on top of it to provide per-application volume control, network transparency, and convenient device routing, while ALSA continues to handle the actual hardware.

Tools

The alsa-utils package provides command-line utilities including alsamixer, a terminal mixer program; aplay and arecord, for playback and capture of raw and WAV audio; and alsactl, which stores and restores mixer settings.
