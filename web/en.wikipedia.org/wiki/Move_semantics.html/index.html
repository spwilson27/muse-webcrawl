Move semantics

Move semantics is a programming language feature that allows the resources of an object (such as dynamically allocated memory) to be transferred to another object instead of being copied, leaving the source object in a valid but unspecified state. It is a central feature of C++11, which introduced rvalue references, move constructors, and move assignment operators.

Purpose

Move semantics avoid expensive deep copies when a source object is a temporary or will no longer be used — for example, returning a large container from a function, inserting elements into a vector, or transferring ownership of a resource managed by std::unique_ptr. The standard library function std::move casts an expression to an rvalue so that move operations can be selected even for named objects the programmer no longer needs.

Other languages

Rust builds ownership transfer (moves) into its core semantics, invalidating moved-from variables at compile time. Other languages with move support include D and certain dialects of other systems languages.
