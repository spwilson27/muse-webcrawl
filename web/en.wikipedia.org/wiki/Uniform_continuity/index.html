Uniform continuity

Uniform continuity
For a uniformly continuous function, one δ works at every point
FieldMathematical analysis
Related resultsHeine–Cantor theorem; Lipschitz continuity

In mathematics, a real function f of real numbers is said to be uniformly continuous if there is a positive real number δ such that function values over any function domain interval of length δ are as close to each other as desired. In other words, for every ε > 0 there exists δ > 0 such that |f(x) − f(y)| < ε whenever |x − y| < δ — crucially, δ depends only on ε, not on where in the domain x and y lie.

Comparison with continuity

Ordinary (pointwise) continuity allows the δ that works to vary from point to point. Uniform continuity is therefore a strictly stronger property on unbounded or open domains: f(x) = 1/x is continuous but not uniformly continuous on (0, 1), and f(x) = x² is not uniformly continuous on the whole real line. On a closed and bounded interval, however, the Heine–Cantor theorem states that every continuous function is uniformly continuous.

Properties

Uniformly continuous functions map Cauchy sequences to Cauchy sequences and map totally bounded sets to totally bounded sets. Lipschitz continuous functions (such as those with bounded derivative) are uniformly continuous, and absolutely continuous functions are as well. The uniform limit of uniformly continuous functions is uniformly continuous.
