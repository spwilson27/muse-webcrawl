Opposite category

From Wikipedia, the free encyclopedia

In category theory, a branch of mathematics, the opposite category or dual category Cop of a given category C is formed by reversing the morphisms, i.e. interchanging the source and target of each morphism. Doing the reversal twice yields the original category, so the opposite of an opposite category is the original category itself. In symbols, (Cop)op = C.

Construction

The opposite category Cop has the same objects as C. For every morphism f : X → Y in C, there is a corresponding morphism fop : Y → X in Cop. Composition in Cop is defined by reversing the order: fop ∘ gop = (g ∘ f)op. Identities and the associativity axioms carry over directly, so Cop satisfies all the axioms of a category.

Duality

The construction underlies the duality principle of category theory: for every categorical statement there is a dual statement obtained by reversing all arrows, and the statement is true if and only if its dual is true. Concepts come in dual pairs — monomorphisms and epimorphisms, products and coproducts, limits and colimits, initial and terminal objects. A contravariant functor from C to D can equivalently be viewed as an ordinary (covariant) functor from Cop to D; the classic example is the dual vector space functor, and presheaves on a category C are defined as functors from Cop to the category of sets.

Examples

The opposite of the category of sets and partial functions relates to the category of pointed sets; the opposite of the category of groups has concrete descriptions via the same underlying objects with reversed operations. In order theory, the opposite of a partially ordered set is the same set with the order relation inverted, turning meets into joins — the source of order-theoretic duality.
