Non-volatile random-access memory

Non-volatile random-access memory (NVRAM) is random-access memory that retains its information when power is turned off, unlike volatile SRAM and DRAM. The term covers both traditional battery-backed or EEPROM-based devices used for storing configuration data, and newer byte-addressable technologies intended to combine the speed of RAM with the persistence of storage.

Types

  • Battery-backed SRAM / nvSRAM — ordinary RAM paired with a battery or an automatic store to EEPROM or flash on power loss, long used for settings and caches.
  • FeRAM — ferroelectric RAM, low power and fast writes, used in meters and embedded systems.
  • MRAM — magnetoresistive RAM storing data in magnetic elements.
  • ReRAM — resistive RAM based on changes in material resistance.
  • Phase-change memory (PCM) — exploited commercially in Intel's Optane persistent memory (discontinued in 2022).

Applications

NVRAM is used for BIOS/UEFI settings, RAID controller caches, industrial logging and, in persistent-memory form, in-memory databases that must survive power failure without reloading from disk.
