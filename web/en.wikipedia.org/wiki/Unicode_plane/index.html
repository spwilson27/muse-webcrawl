Plane (Unicode)

From Wikipedia, the free encyclopedia

In the Unicode standard, a plane is a continuous group of 65,536 (216) code points. The Unicode codespace of 1,114,112 code points is divided into 17 planes, numbered 0 through 16. Each code point can be written as U+HHHHHH, where the higher-order digits identify the plane; within a plane, code points are organised into blocks by script or function.

The principal planes

Plane 0, the Basic Multilingual Plane (BMP), contains nearly all characters of modern languages, common symbols, and the surrogate code points used by UTF-16. Plane 1, the Supplementary Multilingual Plane (SMP), holds historic scripts such as Egyptian hieroglyphs and cuneiform, musical notation, and most emoji. Plane 2, the Supplementary Ideographic Plane (SIP), contains rarer and historic CJK ideographs; Plane 14, the Supplementary Special-purpose Plane (SSP), holds tag characters and variation selectors. Planes 15 and 16 are private use planes, whose code points are not assigned by the standard and may be used for any characters by private agreement. The remaining planes — 3 through 13 — are currently unassigned. Characters outside the BMP require four bytes in UTF-8 and a surrogate pair in UTF-16, a distinction that has visible consequences in software that assumes one character per 16-bit unit.
