Identity matrix

In linear algebra, the identity matrix of size n is the n × n square matrix with ones on the main diagonal and zeros elsewhere. It is commonly denoted In, or simply I if the size is immaterial or can be trivially determined by the context.

The identity matrix is the multiplicative identity for matrix multiplication: for any m × n matrix A, Im A = A In = A. In particular, the identity matrix serves as the identity element of the general linear group of invertible matrices under matrix multiplication.

Properties

  • The identity matrix is a diagonal matrix and a special case of an orthogonal matrix; its transpose is itself.
  • Its determinant is 1 and its trace is n.
  • All its eigenvalues are equal to 1.
  • The columns of the identity matrix are the standard basis vectors of Euclidean space, often written ei.
  • When multiplied by a vector, the identity matrix leaves the vector unchanged, representing the identity function as a linear map.

Notation

Using the Kronecker delta, the entries of the identity matrix can be written (In)ij = δij, which is 1 when i = j and 0 otherwise.
