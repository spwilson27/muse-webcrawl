Monotone class theorem

Monotone class theorem
FieldMeasure theory
Relatedπ–λ theorem, Dynkin system, algebra of sets

In measure theory, the monotone class theorem is a result that allows one to prove that a property holding for all sets in a small collection (an algebra of sets) holds for all sets in the σ-algebra generated by that collection, provided the property is preserved under monotone unions and intersections. It states that the smallest monotone class containing an algebra A equals the σ-algebra generated by A.

Statement and proof idea

A monotone class is a collection of sets closed under increasing unions and decreasing intersections. The intersection of all monotone classes containing A is itself a monotone class; the theorem is proved by showing that this minimal monotone class is also closed under complements and finite unions, hence is a σ-algebra, and must therefore equal σ(A).

A standard application is proving that two probability measures agreeing on an algebra agree on the generated σ-algebra, and proving that a function property established for indicator functions of an algebra extends to all bounded measurable functions (the functional form of the theorem).

Relation to the π–λ theorem

The monotone class theorem serves much the same purpose as Dynkin's π–λ theorem, which works with π-systems and λ-systems (Dynkin systems) instead. Different texts prefer one or the other; together they are the standard tools for extending results from simple generating classes to full σ-algebras.
