WS-Management

WS-Management (Web Services Management) is a DMTF standard protocol for managing servers, devices, applications and web services. Built on SOAP and other WS-* specifications, it provides a common way for management systems to identify, access and control resources across heterogeneous IT infrastructure.

Developed byDMTF (with AMD, Dell, Intel, Microsoft, Sun and others)
TypeSystems management protocol
Based onSOAP, WS-Addressing, WS-Enumeration, WS-Eventing, WS-Transfer

Overview

The specification, developed from 2004 and standardised by the Distributed Management Task Force, defines operations to GET, PUT, CREATE and DELETE managed resources, enumerate collections, and subscribe to events, using a resource model based on the Common Information Model (CIM). It was designed as a small-footprint protocol suitable for devices as well as large data centres.

Implementations

The best-known implementations are Windows Remote Management (WinRM) in Microsoft Windows — the transport used by PowerShell remoting — and OpenWSMAN, an open-source implementation; Intel's AMT out-of-band management also uses WS-Management.
