Graphviz (short for Graph Visualization Software) is a package of open-source tools for drawing graphs specified in DOT language scripts. The package was initiated by AT&T Labs Research and provides several main layout programs along with web and interactive graphical interfaces, auxiliary tools, libraries, and language bindings.

Architecture

Graphviz consists of a graph description language (DOT) and a set of tools that generate output in a variety of formats such as (PostScript, PDF, SVG, PNG, or plain text):

  • dot — a layered layout for directed graphs.
  • neato — "spring model" layouts, for undirected graphs.
  • fdp — a force-directed layout suitable for larger undirected graphs.
  • twopi — radial layouts.
  • circo — circular layouts.
  • sfdp — a scalable force-directed layout for very large graphs.

Applications

Graphviz is widely used in software engineering (call graphs, class diagrams), bioinformatics (phylogenetic and pathway diagrams), database documentation, and machine learning (decision trees). Many other tools, including Doxygen and various wiki engines, embed Graphviz to render diagrams.
