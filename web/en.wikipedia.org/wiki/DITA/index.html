Darwin Information Typing Architecture

The Darwin Information Typing Architecture (DITA) is a free and open XML standard for authoring, producing, and delivering technical information, maintained by the OASIS standards consortium. DITA was originally developed by IBM, which donated the specification to OASIS in 2004; version 1.0 became an OASIS standard in 2005.

Principles

DITA is built around small, self-contained content units called topics, each covering a single subject, which are assembled for publication using maps. Its name reflects its key mechanisms: "Darwin" for specialization and inheritance of element types, "Information Typing" for its semantic categories of content, and "Architecture" for its extensible design. The base topic types follow research on information design, distinguishing concept, task, and reference topics.

Reuse and publishing

DITA supports single-source publishing: content can be written once and published to HTML, PDF, help systems, and other formats, using tools such as the open-source DITA Open Toolkit. Content reuse is supported through content references (conrefs), key references, conditional processing (ditaval), and relationship tables, and elements can be specialized to define new information types while remaining compatible with generic processing. A lighter profile, Lightweight DITA (LwDITA), allows authoring in simplified XML, HTML5, or Markdown forms.

Adoption

DITA is widely used in the technical communication industry, particularly for software, semiconductor, and equipment documentation, and by vendors including Adobe, Microsoft, and PTC in their documentation toolchains.
