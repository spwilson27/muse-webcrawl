Partial application

In computer science, partial application (or partial function application) refers to the process of fixing a number of arguments of a function, producing another function of smaller arity. Given a function f : (X × Y × Z) → N, partial application binds the first argument to a value, producing a new function partial(f, x) : (Y × Z) → N. The resulting function can then be invoked with the remaining arguments as usual.

Motivation

Partial application supports the reuse of general functions in specialised contexts: a generic two-argument add function can be turned into an increment function by fixing the first argument to 1. It appears naturally in languages with first-class functions and is a common idiom in functional programming, callback configuration and dependency injection.

Relation to currying

Partial application is related to, but distinct from, currying. A curried function is transformed into a chain of unary functions once and for all, whereas partial application fixes arguments at a particular call site. Any curried function applied to one argument is effectively partially applied, but partial application can fix several arguments at once, in any pattern supported by the language or library — as in the bind method of JavaScript functions or the functools.partial helper in Python.
