Logical consequence

Logical consequence (also entailment) is a fundamental concept in logic, the most important notion in the analysis of arguments. A sentence (or proposition) is a logical consequence of a set of sentences if it is impossible for all the premises to be true while the conclusion is false. Equivalently, the conclusion is true in every model in which all the premises are true. The relation is written Γ ⊨ φ: φ follows semantically from the premise set Γ.

The model-theoretic account

Alfred Tarski's 1936 account made logical consequence precise via models: φ is a consequence of Γ if and only if every model of Γ is also a model of φ. This semantic notion is distinguished from the syntactic notion of derivability (Γ ⊢ φ, "φ can be proved from Γ in a formal system"), though for first-order logic Gödel's completeness theorem guarantees that the two coincide.

Properties

  • Reflexivity: every sentence is a consequence of itself.
  • Monotonicity: adding premises cannot destroy a consequence (in classical logic).
  • Transitivity (cut): consequences of consequences are consequences of the original premises.
  • Necessity and formality: the relation holds in virtue of logical form, regardless of subject matter, and is necessary rather than contingent.

Philosophical debates

Philosophers debate whether logical consequence is fundamentally modal (truth-preservation in all possible circumstances) or model-theoretic, whether it is normative for reasoning, and how it extends to non-classical logics. Relevance logicians reject some classical entailments (such as a contradiction implying anything) as failing to capture a genuine consequence relation; non-monotonic logics relax monotonicity to model defeasible reasoning.
