Knuth–Morris–Pratt algorithm

The Knuth–Morris–Pratt (KMP) algorithm is a string-searching algorithm that searches for occurrences of a "word" (pattern) within a main "text string" in linear time. It was developed by Donald Knuth, Vaughan Pratt and, independently, by James H. Morris, and published jointly in 1977.

How it works

KMP exploits information from partial matches: when a mismatch occurs, the pattern itself contains enough information to determine where the next match could begin, avoiding re-examination of previously matched characters. A preprocessing step builds a partial match table (failure function) giving, for each position, the length of the longest proper prefix of the pattern that is also a suffix.

Complexity

Preprocessing takes O(m) time for a pattern of length m, and searching takes O(n) for a text of length n, giving overall linear O(n + m) time, a major improvement over naive search in the worst case.
