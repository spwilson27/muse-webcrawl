The Web Ontology Language (OWL) is a family of knowledge representation languages for authoring ontologies, standardised by the World Wide Web Consortium (W3C). OWL ontologies define classes, properties, individuals, and data values, and are intended to be used together with the Resource Description Framework (RDF) on the Semantic Web, enabling machines to reason about the structure of knowledge published on the web.

History and versions

OWL grew out of DAML+OIL, a language developed by DARPA and European researchers around 2000, and became a W3C Recommendation in 2004. The original language had three species: OWL Lite, OWL DL, and OWL Full, differing in expressiveness; OWL DL is so named for its basis in description logic, a decidable fragment of first-order logic. OWL 2 (2009) added profiles — EL, QL, and RL — tuned for different reasoning tasks and scalability requirements.

Concepts and reasoning

An OWL ontology states facts such as "every person is an agent," "a mother is a female parent," and class relationships, restrictions on properties, and property characteristics (such as transitivity and symmetry). Reasoners such as Pellet, HermiT, and FaCT++ can automatically check the consistency of an ontology and infer new class memberships. OWL operates under the open-world assumption: a fact not stated is not assumed false.

Applications

OWL is used in biomedical informatics (for example, the Gene Ontology's formal layers and SNOMED CT's logic profile), data integration, and knowledge graphs. Editor tools include Protégé, developed at Stanford.
