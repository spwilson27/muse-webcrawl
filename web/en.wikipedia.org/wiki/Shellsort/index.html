Shellsort

Shellsort, also known as Shell sort or Shell's method, is an in-place comparison sort. It is a generalization of insertion sort that allows the exchange of items that are far apart. The method starts by sorting pairs of elements far apart from each other, then progressively reducing the gap between elements to be compared.

History and operation

The algorithm was published by Donald Shell in 1959. Starting with a large gap, the algorithm performs insertion sort on subarrays consisting of elements separated by the gap, then repeats with smaller gaps until the gap is 1, at which point it is an ordinary insertion sort on an almost-sorted array, which runs efficiently.

Gap sequences and complexity

Performance depends heavily on the gap sequence. Shell's original sequence halves the gap each pass; later sequences by Hibbard, Sedgewick, Tokuda and Ciura give better results. The worst-case complexity is O(n2) for poor sequences, while good sequences approach O(n log n) behaviour in practice, though the exact complexity remains an open problem for many sequences.
