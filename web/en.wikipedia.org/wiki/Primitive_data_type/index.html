Primitive data type

ClassificationBasic data types provided by a programming language

In computer programming, primitive data types are a set of basic data types from which all other data types are constructed. Specifically it often refers to the limited set of data representations in use by a particular processor, which all compiled programs must use. Most processors support a similar set of primitive data types, although the specific representations vary. More generally, "primitive data types" may refer to the standard data types built into a programming language (built-in types). Data types that are not primitive are referred to as derived or composite.

Primitive types are almost always value types, but composite types may also be value types.

Overview

The actual range of primitive data types that is available is dependent upon the specific programming language that is being used. For example, in C, string types are not primitive types but are composite types (arrays of characters) instead, whereas in most modern languages string types are built-in primitive types supported by the syntax and semantics of the language implementation. Complicating the matter, some languages implement strings as an immutable reference type, but display them in a manner indistinguishable from primitives, thereby imparting in-built string manipulation syntax into the language.

Most languages support, in principle, the following types:

  • Character types, which can hold a single character or a fixed-length string of characters;
  • Integer types, with a variety of precisions;
  • Floating-point numbers, which reflect, within limits, real number values;
  • Boolean type, representing values true and false.

Numeric types

Integers

An integer data type represents some range of mathematical integers. Integers may be either signed (allowing negative values) or unsigned (non-negative integers only). Common ranges are 8-bit (byte), 16-bit (short), 32-bit (int) and 64-bit (long) values.

Floating-point numbers

A floating-point number represents a limited-precision rational number that may have a fractional part. These numbers are stored internally in a format typically resembling scientific notation, with a dedicated exponent and mantissa. Common types are single precision (32-bit) and double precision (64-bit), following the IEEE 754 standard.

Boolean type

A Boolean type, typically denoted "bool" or "boolean", is typically a one-bit type representing either "true" or "false". In practice many languages store a Boolean in a full byte or word for efficiency.
