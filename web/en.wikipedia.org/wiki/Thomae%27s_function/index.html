Thomae's function

Thomae's function
Also called: Popcorn function, raindrop function
Named after: Carl Johannes Thomae
Continuous at: every irrational number; discontinuous at every rational number

Thomae's function is a real-valued function of a real variable named after Carl Johannes Thomae (1840–1921). It is defined as f(x) = 1/q if x is a rational number p/q in lowest terms (with q > 0), and f(x) = 0 if x is irrational. It is also known as the popcorn function or raindrop function, because its graph resembles popped corn or raindrops.

Properties

Thomae's function is continuous at every irrational point and discontinuous at every rational point — the reverse behaviour of the Dirichlet function, which is discontinuous everywhere. It is bounded between 0 and 1, has period 1, and attains local maxima at every rational number.

Integrability

Despite being discontinuous on the dense set of rationals, Thomae's function is Riemann integrable on [0, 1], with integral 0, because its set of discontinuities (the rationals) has Lebesgue measure zero. It is not differentiable anywhere.

History

The function was introduced by Thomae in 1875 and became a standard example in real analysis of the subtleties of continuity and integrability.
