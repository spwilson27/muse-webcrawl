Almost periodic function

From Wikipedia, the free encyclopedia

An almost periodic function is a function of a real variable that generalises the notion of a periodic function: roughly, every sufficiently long interval contains segments on which the function repeats itself to within any prescribed tolerance. The concept was introduced and developed by the Danish mathematician Harald Bohr in the 1920s.

Definition

In Bohr's definition, a continuous function f is almost periodic if for every ε > 0 there exists a length L such that every interval of length L contains a number τ (an "ε-almost-period") with |f(x + τ) − f(x)| < ε for all real x. An equivalent formulation, due to Bochner, requires the set of translates of f to be relatively compact in the uniform norm.

Properties and generalisations

Sums of periodic functions with incommensurable periods, such as sin x + sin(√2 x), are almost periodic but not periodic. Every almost periodic function is bounded and uniformly continuous, has a mean value, and admits an analogue of a Fourier series, whose development led to the theory of the Bohr compactification of the real line. Variants defined by Besicovitch, Weyl and Stepanoff relax the definition in various ways, and the idea extends to functions on general locally compact abelian groups, where it connects with harmonic analysis and the study of quasiperiodic motion.
