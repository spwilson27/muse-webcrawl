Deming regression

In statistics, Deming regression, named after W. Edwards Deming, is an errors-in-variables model that finds the line of best fit for a two-dimensional dataset when both variables are measured with error. Unlike ordinary least squares, which assumes the independent variable is error-free, Deming regression accounts for measurement error in both x and y.

Method

The method requires the ratio of the error variances of the two variables. When that ratio is one, Deming regression reduces to orthogonal regression (total least squares), which minimizes perpendicular distances to the line. It is widely used in clinical chemistry and method-comparison studies.
