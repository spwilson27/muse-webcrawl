Basic Linear Algebra Subprograms

Basic Linear Algebra Subprograms (BLAS) is a specification that prescribes a set of low-level routines for performing common linear algebra operations such as vector addition, scalar multiplication, dot products, linear combinations, and matrix multiplication. They are the de facto standard low-level routines used by numerical libraries such as LAPACK.

Levels

The routines are grouped into three levels of increasing computational intensity. Level 1 (1973–77) covers vector–vector operations such as the dot product (DDOT) and AXPY. Level 2 (1984–86) adds matrix–vector operations, including the general matrix–vector product (GEMV) and rank-1 updates. Level 3 (1988–90) adds matrix–matrix operations, above all the general matrix multiply GEMM, which performs O(n³) arithmetic on O(n²) data and can therefore be optimised heavily for cache hierarchies and modern processors.

Implementations

A portable reference implementation in Fortran is maintained at Netlib. Hardware vendors and open-source projects supply tuned implementations — including Intel MKL, OpenBLAS, ATLAS and Apple's Accelerate — which often determine the practical speed of scientific computing, machine learning and engineering software.
