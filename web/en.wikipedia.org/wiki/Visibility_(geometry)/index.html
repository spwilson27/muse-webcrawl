Visibility (geometry)


The visibility polygon of a point inside a polygon

In geometry, visibility is a mathematical abstraction of the real-life notion of visibility. Two points in a set are said to be visible to each other if the straight line segment joining them does not intersect any obstacle in the set. Visibility problems arise in computational geometry, computer graphics, robotics and computer vision.

Visibility polygon

The visibility polygon of a point in a polygonal environment is the set of all points visible from it. Computing visibility polygons is a classical problem with applications in motion planning, art gallery problems and architectural analysis.

The art gallery problem

The art gallery problem asks for the minimum number of stationary guards, each able to see in all directions, needed so that every point in a polygonal gallery is visible to at least one guard. Chvátal's theorem establishes that ⌊n/3⌋ guards are always sufficient and sometimes necessary for a polygon with n vertices.

Applications

Visibility algorithms underpin hidden-surface removal in rendering, shadow computation, sensor placement and the analysis of line-of-sight in terrain models.
