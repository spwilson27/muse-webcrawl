Linear extension

In order theory, a linear extension of a partial order is a total order (or linear order) that is compatible with the partial order: whenever x ≤ y in the partial order, then also x ≤ y in the total order. Every finite partial order has at least one linear extension, which can be found by topological sorting of the corresponding directed acyclic graph.

Existence

The order-extension principle states that every partial order may be extended to a total order; for finite sets this is elementary, and for infinite sets it follows from a weak form of the axiom of choice. A partial order is the intersection of all of its linear extensions, a fact connected with the concept of order dimension.

Counting linear extensions

Counting the number of linear extensions of a finite poset is a classic problem in enumerative combinatorics. The problem is #P-complete in general (Brightwell and Winkler, 1991), although closed forms exist for special families such as Young diagrams, where the hook-length formula applies.
