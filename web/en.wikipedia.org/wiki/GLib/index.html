GLib

GLib is a bundle of low-level system libraries written in C and developed by the GNOME project. It provides data structures (linked lists, hash tables, balanced trees), string utilities, file and I/O abstractions, threading primitives, and the main event loop used by graphical applications. GLib is released under the GNU Lesser General Public License and is cross-platform, running on Linux, Windows, and macOS.

GLib includes the GObject object system and the GIO library for file, network, and D-Bus functionality. It underlies GTK and most GNOME applications, and is used by many other projects as a general-purpose portability and utility library.
