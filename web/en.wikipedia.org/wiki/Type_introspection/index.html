Type introspection

In computer programming, type introspection is the ability of a program to examine the type or properties of an object at runtime. It is closely related to reflection, which additionally allows a program to manipulate the values and metadata it discovers.

Examples

Languages with strong introspection support include Ruby, Python (with functions such as type(), isinstance() and dir()), Smalltalk and Objective-C. In C++, the run-time type information (RTTI) mechanism provides typeid and dynamic_cast. Introspection underpins frameworks for object-relational mapping, serialization and dependency injection.
