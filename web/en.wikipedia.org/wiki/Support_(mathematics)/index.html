Support (mathematics)

The support of a function is the set of points where it is not zero (or the closure of that set).

In mathematics, the support of a real-valued function f is the subset of its domain containing those elements which are not mapped to zero. If the domain of f is a topological space, then the support is instead defined as the smallest closed set containing all points not mapped to zero. This concept is used very widely in mathematical analysis.

Formulation

Suppose f : X → ℝ is a function whose domain X is an arbitrary set. The set-theoretic support of f, written supp(f), is the set of points in X where f is non-zero: supp(f) = {x ∈ X : f(x) ≠ 0}. When X is a topological space, the support is usually taken to be the closure of this set, which makes the support a closed set.

Compact support

A function has compact support if its support is compact. Real-valued functions with compact support on Euclidean space are central to distribution theory and the theory of partial differential equations: smooth compactly supported functions ("bump functions") serve as test functions and as mollifiers for approximating less regular functions.

Other uses

The term "support" is used analogously throughout mathematics: the support of a measure is the smallest closed set of full measure; the support of a probability distribution is the smallest closed set whose probability is 1; and in algebra, the support of a module element or of a permutation records where it is nontrivial.
