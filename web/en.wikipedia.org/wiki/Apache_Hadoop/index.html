Apache Hadoop

Apache Hadoop is a collection of open-source software utilities for distributed storage and processing of very large data sets across clusters of computers. It was inspired by Google's MapReduce and Google File System papers and was created by Doug Cutting and Mike Cafarella, initially as part of the Nutch search engine project.

Components

The core of Hadoop consists of the Hadoop Distributed File System (HDFS), which stores data in large blocks replicated across machines, and a resource-management and processing layer. Earlier versions centred on MapReduce; later versions added YARN (Yet Another Resource Negotiator) to schedule jobs and share cluster resources among multiple engines.

Design principles

Hadoop assumes hardware failures are common and should be handled automatically by the framework. It is designed for batch processing of huge files with high aggregate bandwidth rather than low-latency interactive queries. An ecosystem of related projects — including Hive, Pig, HBase, Spark integrations and Sqoop — grew around the core.

Influence

Hadoop became a defining technology of the “big data” era in the late 2000s and 2010s. Although many workloads later shifted toward cloud object storage and engines such as Apache Spark, Hadoop remains historically important and is still used in large on-premises clusters.
