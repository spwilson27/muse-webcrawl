Linear combination

From Wikipedia, the free encyclopedia

In mathematics, a linear combination is an expression constructed from a set of terms by multiplying each term by a constant and adding the results. For vectors v1, …, vn and scalars (coefficients) a1, …, an, the linear combination is a1v1 + a2v2 + … + anvn.

Definition and examples

Let V be a vector space over a field K. A vector v in V is a linear combination of vectors v1, …, vn if there exist scalars a1, …, an in K such that v = a1v1 + … + anvn. For example, in the plane R², the vector (5, 7) is a linear combination of the standard basis vectors e1 = (1, 0) and e2 = (0, 1), since (5, 7) = 5e1 + 7e2. By contrast, polynomials such as 3x² − x + 4 are linear combinations of the monomials 1, x, x².

Related concepts

The set of all linear combinations of a set of vectors is their span, the smallest subspace containing them. A linear combination is called affine if its coefficients sum to 1, and convex if in addition all coefficients are non-negative. A set of vectors is linearly independent if none of them can be written as a linear combination of the others — equivalently, if the only linear combination equalling the zero vector is the trivial one with all coefficients zero.
