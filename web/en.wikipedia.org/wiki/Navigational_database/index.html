Navigational database

A navigational database is a type of database model in which records are stored in a structure of linked sets, and applications access data by "navigating" from record to record by following pointers, rather than by declarative queries. It was one of the earliest database models and dominated mainframe data processing in the 1960s and 1970s.

In a navigational database, programs follow pointer chains between records.

History

The model grew out of the Integrated Data Store (IDS) developed by Charles Bachman at General Electric in the early 1960s, and was standardised by the CODASYL Data Base Task Group in 1969, producing the "network model". IBM's hierarchical IMS database, released in 1968 for the Apollo program, is a related navigational system. Bachman received the Turing Award in 1973 for his pioneering work.

Characteristics

Data is organised into record types connected by set types (one-to-many relationships implemented as pointer chains). Programs issue procedural commands — FIND, GET, STORE, CONNECT — moving a "currency" pointer through the database. This gave excellent performance for predictable access paths but made applications brittle: changing the data structure meant rewriting programs, and ad-hoc queries were difficult.

Decline and legacy

Navigational databases were largely displaced by the relational model proposed by E. F. Codd in 1970 and commercialised in the 1980s. Nevertheless they persist in legacy systems, and their ideas reappear in hierarchical stores and modern graph databases, which again emphasise traversing links between records.
