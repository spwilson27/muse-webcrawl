Core fonts for the Web

Core fonts for the Web was a project started by Microsoft in 1996 to create a standard pack of fonts for the World Wide Web. The fonts were released under a proprietary license that allowed free redistribution as long as they remained unmodified, and they were made available for Windows and Macintosh platforms. Microsoft terminated the project in 2002, but the fonts remain widely installed and their license still permits their use.

The fonts

The pack originally included Arial, Arial Black, Times New Roman, Courier New, Verdana, Georgia, Trebuchet MS, Comic Sans MS, Impact, Andale Mono and Webdings. The fonts were designed for on-screen readability: Verdana and Georgia, designed by Matthew Carter, were notable for their large x-heights and hinted rendering optimised for the low-resolution displays of the era.

Impact

Because the fonts shipped with Windows and Internet Explorer and were freely available for the Mac, web designers could rely on them being present on most systems, and the fonts became near-universal default choices in web design through the late 1990s and 2000s. The msttcorefonts package remains commonly installed on Linux systems for compatibility. Later successors such as the ClearType Font Collection (Calibri, Cambria, etc.) did not carry the same free-redistribution terms.
