Joint Electronics Type Designation System

The Joint Electronics Type Designation System (JETDS), formerly the Army–Navy Nomenclature System (AN System), is the method by which the United States Department of Defense assigns designations to military electronics equipment. This page is filed under the AN/ path (AN/Joint Electronics Type Designation System).

Format

Designations have the form AN/XXX-nn, where "AN" historically indicated Army–Navy, the three letters code the installation, equipment type and purpose, and the number identifies the model. For example, AN/APG-68 is an airborne radar, and AN/PRC-77 a portable radio. The system also underlies related designations such as AIM (air-launched missiles) in wider usage.

History

The system was adopted during the Second World War to replace incompatible service-specific naming schemes and is governed today by MIL-STD-196. See also MIL-STD-196.
