Postfix is a free and open-source mail transfer agent (MTA) that routes and delivers electronic mail. It was created by Wietse Venema while at IBM's Thomas J. Watson Research Center and first released in December 1998 under the name VMailer, later IBM Secure Mailer. Intended as a faster, easier-to-administer and more secure alternative to the then-ubiquitous Sendmail program, Postfix became one of the most widely used MTAs on the Internet and the default MTA of many Linux distributions and of macOS Server.

Architecture

Where Sendmail is a single large monolithic program, Postfix consists of a cooperating set of small daemon programs, each performing a specific task and each running with the least privileges necessary: the master daemon supervises the system; smtpd receives mail by SMTP; cleanup and trivial-rewrite process headers and addresses; the queue manager qmgr schedules deliveries through agents such as smtp, local, lmtp and pipe. Mail is staged through several on-disk queues (incoming, active, deferred, hold, corrupt). This compartmentalized design was a principal reason for Postfix's strong security record.

Features

Postfix supports SMTP and LMTP, TLS encryption, SASL authentication, IPv6, virtual domains and mailboxes, address rewriting and canonicalization, content filtering via before- and after-queue filters and the milter protocol (shared with Sendmail), and policy delegation that underlies greylisting and SPF/DKIM checks. Configuration is through human-readable files such as main.cf and lookup tables in formats including hash, regexp, PCRE, LDAP, MySQL and PostgreSQL. Postfix is designed to be Sendmail-compatible at the command level (including a sendmail replacement binary and support for /etc/aliases), easing migration.
