Software license

A software license is a legal instrument (usually by way of contract law, with or without printed material) governing the use or redistribution of software. Under United States copyright law, all software is copyright protected, in both source code and object code forms, unless the software was developed by the U.S. Government, in which case it cannot be copyrighted. Authors of copyrighted software can donate their software to the public domain, in which case the software is not covered by copyright and, as a result, cannot be licensed.

Proprietary licenses

The hallmark of proprietary software licenses is that the software publisher grants the use of one or more copies of software under the end-user license agreement (EULA), but ownership of those copies remains with the software publisher. This feature means that all rights to the software are reserved by the publisher, and only a limited set of use rights is granted to the end-user.

Free and open-source licenses

Copyleft

Copyleft licenses, most prominently the GNU General Public License (GPL), require derivative works distributed to others to be licensed under the same terms, ensuring the software remains free. Variants include the LGPL, which permits linking from proprietary code, and the AGPL, which extends the distribution trigger to network interaction.

Permissive

Permissive licenses such as MIT, BSD and Apache 2.0 impose minimal conditions — typically preservation of copyright notices — and allow reuse in proprietary products. The Apache License additionally includes an express patent grant.

Compatibility and enforcement

Mixed codebases must respect licence compatibility: for example, Apache-2.0 code may be combined into GPLv3 projects but not GPLv2-only ones. Licence conditions are enforced through copyright law; notable enforcement actions have involved embedded Linux distributions and GPL compliance.
