Dolby Vision is an HDR imaging technology

Dolby Vision

Dolby Vision is a set of technologies developed by Dolby Laboratories for high dynamic range (HDR) video. It covers content creation, distribution, and playback, and includes dynamic metadata that define the colour grading of each frame. Dolby Vision content is produced in a mastering process that uses per-shot or per-frame metadata to optimise the picture for each display.

Technology

Dolby Vision supports up to 12-bit colour depth, a peak brightness of up to 10,000 nits in its specification, and the wide Rec. 2020 colour gamut. Unlike the competing HDR10 format, which uses static metadata for an entire programme, Dolby Vision's dynamic metadata allows tone mapping to be adjusted scene by scene or frame by frame to match the capabilities of the target display. A licensed, royalty-bearing format, it is supported by television manufacturers, streaming services including Netflix, Disney+ and Apple TV+, and by Ultra HD Blu-ray.

Dolby Vision IQ and gaming

Dolby Vision IQ, introduced in 2020, uses a television's ambient light sensor to adapt the picture to room lighting. Dolby Vision gaming extends the format to video game consoles, enabling HDR gaming with dynamic metadata at up to 120 Hz on supported displays.
