Statechart

A statechart is a formalism and visual language for describing the behaviour of complex reactive systems. It was invented by David Harel in the 1980s and presented in his influential 1987 paper "Statecharts: A Visual Formalism for Complex Systems". Statecharts extend conventional finite-state machines with hierarchy, concurrency and communication, addressing the "state explosion" problem that makes flat state diagrams impractical for large systems.

Features

Hierarchy

States may contain substates, allowing behaviour to be described at multiple levels of abstraction. A transition from a high-level state applies to all of its substates, so common behaviour does not have to be repeated for every nested state.

Orthogonality (concurrency)

A state may be decomposed into orthogonal regions separated by dashed lines, each region being an independent state machine running in parallel. This models concurrent components without multiplying out all combinations of states.

Broadcast communication

Events generated in one part of the diagram can trigger transitions elsewhere, providing a mechanism for communication between orthogonal regions.

History

A history pseudo-state allows a composite state to "remember" which substate was active when it was last exited, so that re-entering the state resumes where it left off. Shallow history remembers only the immediate substate; deep history remembers nested configurations.

Semantics and variants

Because Harel's original paper left some semantic choices open, many variants exist. The state-machine notation of the Unified Modeling Language (UML) — called state machine diagrams — is based on statecharts but has its own semantics, notably run-to-completion event processing. The W3C's SCXML (State Chart XML) standard defines an executable statechart language used in voice applications and elsewhere. Tools implementing Harel-style semantics include Statemate (the original commercial tool), Rhapsody, Yakindu Statechart Tools, and the JavaScript library XState.

Applications

Statecharts are used in embedded and safety-critical systems — avionics, automotive control, medical devices — as well as in user-interface logic, game development and workflow modelling, anywhere a system's behaviour depends on its history of events.
