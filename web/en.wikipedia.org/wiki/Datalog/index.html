Datalog

Datalog is a declarative logic programming language that is a subset of Prolog. It is particularly suited for expressing queries over relational databases: a Datalog program consists of facts and rules (Horn clauses without function symbols), and evaluation computes all facts derivable from the program, guaranteeing termination because the set of possible conclusions is finite.

Syntax and semantics

A rule such as ancestor(X,Y) :- parent(X,Z), ancestor(Z,Y) states that X is an ancestor of Y if X is a parent of some Z who is an ancestor of Y. Semantics are given by the least fixed point (least Herbrand model) of the program, which can be computed bottom-up by repeatedly applying rules until no new facts appear, or top-down with memoisation. Stratified negation allows not in rule bodies provided dependencies are not cyclic.

History and use

Datalog emerged from research on deductive databases in the late 1970s and 1980s. Interest revived in the 2000s with systems such as Soufflé and LogicBlox applying it to program analysis, points-to analysis for compilers, security policies, networking, and as the query language of graph and RDF databases. Its combination of recursion and declarative queries exceeds the expressiveness of basic relational algebra while remaining decidable and efficiently evaluable.
