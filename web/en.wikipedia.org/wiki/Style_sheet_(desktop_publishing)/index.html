Style sheet (desktop publishing)

Style sheets in a page-layout application, listing paragraph and character styles

In desktop publishing, a style sheet is a collection of named sets of formatting instructions — styles — that can be applied to text and objects in a document and updated centrally. The term was popularised by QuarkXPress in the late 1980s and is used in varying forms by Adobe InDesign, Microsoft Word, and other layout and word-processing software.

Types of styles

Paragraph styles define the font, size, leading, alignment, spacing, indents and other attributes of whole paragraphs. Character styles override selected attributes — for example, italic or small caps — for a highlighted range within a paragraph. Page-layout applications add object, table and cell styles. Styles can be based on other styles, so changing a "base" style cascades through its children; applying a style name rather than manual formatting ensures consistent typography across a long document and allows instant global redesign by editing the style definitions alone.

Relation to other meanings

The concept parallels, and partly inspired, style sheets for the web — Cascading Style Sheets (CSS) — though the two are not interchangeable. The term should also be distinguished from editorial style guides (such as a publisher's house style), which prescribe usage and spelling rather than document formatting.
