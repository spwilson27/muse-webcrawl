In computer science, the analysis of algorithms is the process of finding the computational complexity of algorithms — the amount of time, storage, or other resources needed to execute them. Usually, this involves determining a function that relates the size of an algorithm's input to the number of steps it takes (its time complexity) or the number of storage locations it uses (its space complexity).

Asymptotic analysis

Because running time depends on hardware and implementation details, analysis is normally expressed in terms of asymptotic behaviour as input size n grows, using big O notation: for example, binary search runs in O(log n), while a naive sorting algorithm may run in O(n²). Analysts distinguish worst-case, average-case and best-case complexity, and use techniques such as solving recurrence relations (summarised by the master theorem) for divide-and-conquer algorithms, and amortized analysis for data structures whose expensive operations are offset by many cheap ones.

History

The systematic study of algorithmic efficiency developed alongside computing itself; Donald Knuth's multi-volume The Art of Computer Programming (from 1968) established rigorous step-counting analysis as a central discipline of computer science. The theory connects closely to computational complexity theory, which classifies problems by the resources their best possible algorithms require.
