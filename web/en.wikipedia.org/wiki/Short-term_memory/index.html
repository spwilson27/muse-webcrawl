Short-term memory

Short-term memory
CapacityAbout 7 ± 2 items (Miller); ~4 chunks (Cowan)
DurationRoughly 15–30 seconds without rehearsal
Related modelAtkinson–Shiffrin model; working memory (Baddeley)

Short-term memory (or "primary" or "active memory") is the capacity for holding a small amount of information in an active, readily available state for a short period of time. For example, short-term memory holds a telephone number that has just been recited. Its duration, when rehearsal is prevented, is believed to be on the order of 15 to 30 seconds.

Capacity

In his famous 1956 paper "The Magical Number Seven, Plus or Minus Two", George A. Miller proposed that short-term memory can hold about seven items, give or take two. Later research, notably by Nelson Cowan, suggests the true capacity for unrehearsed material is closer to four chunks. Capacity can be expanded by "chunking" — grouping items into meaningful units, as in remembering a phone number in segments.

Relation to working memory

Short-term memory is often distinguished from working memory, which additionally involves the manipulation of stored information. Alan Baddeley's model of working memory (1974, with Graham Hitch) decomposes the system into a phonological loop, a visuospatial sketchpad, an episodic buffer, and a central executive. The phonological similarity effect and the word-length effect are classic evidence for a speech-based rehearsal store.

Forgetting

Information in short-term memory is lost through decay over time and through displacement by new material; interference from similar items is a major cause of forgetting. The Brown–Peterson task, in which participants count backwards to prevent rehearsal, shows rapid loss within about 18 seconds.

Neural basis and impairment

Short-term retention depends on persistent activity in prefrontal and parietal networks and, for verbal material, left-hemisphere perisylvian regions. Notably, damage to the medial temporal lobe, as in patient H.M., devastates the formation of new long-term memories while leaving short-term memory largely intact — key evidence that the two systems are distinct.
