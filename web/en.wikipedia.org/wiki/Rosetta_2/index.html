Rosetta 2 is a dynamic binary translator developed by Apple Inc. that enables software compiled for Intel x86-64 processors to run on Macs with Apple silicon (ARM64) processors. It was announced at WWDC in June 2020 and shipped with macOS Big Sur in November 2020, as part of Apple's two-year transition of the Mac product line from Intel to its own silicon.

Operation

Unlike the original Rosetta, which translated PowerPC code instruction-by-instruction for the 2006 Intel transition, Rosetta 2 translates most x86-64 code ahead of time at install time, falling back to just-in-time translation for code such as JavaScript JIT output. Translated applications often run faster than on comparable Intel hardware, though some instruction sets (such as AVX-512 and certain virtualization features) are not supported, and kernel extensions and x86 virtual machines cannot be translated.

Reception and phase-out

Reviewers praised Rosetta 2's performance and transparency; most users could run legacy Intel applications without noticing the translation layer. As developers shipped universal and native ARM builds, reliance on Rosetta 2 declined. Apple has indicated that Rosetta 2 will eventually be phased out, remaining available for a transitional period to support older games and software that depend on Intel-specific frameworks.
