An abstract syntax tree (AST), or just syntax tree, is a tree representation of the abstract syntactic structure of text (often source code) written in a formal language. Each node of the tree denotes a construct occurring in the text. The syntax is "abstract" in the sense that it does not represent every detail appearing in the real syntax, but rather just the structural or content-related details.

Use in compilers

ASTs are produced by the parsing phase of a compiler or interpreter. Subsequent phases — semantic analysis, optimisation and code generation — operate on the AST, which serves as a central intermediate representation. Because the AST omits punctuation and delimiters, it is a more compact and manipulable representation of a program than a concrete syntax tree (parse tree).

Other applications

ASTs are used in program analysis and transformation systems, transpilers, linters and automatic code-formatting tools. Language Server Protocol implementations build ASTs to provide navigation and refactoring. Comparing ASTs, rather than raw text, allows structural diffs of programs.
