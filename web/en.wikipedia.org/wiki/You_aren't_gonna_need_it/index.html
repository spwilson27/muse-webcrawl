You aren't gonna need it

"You aren't gonna need it" (often abbreviated YAGNI) is a principle in software engineering, associated with extreme programming (XP), which states that a programmer should not add functionality until it is deemed necessary. The principle is intended to avoid wasted effort on features that are speculative and may never be used.

The phrase is commonly attributed to Ron Jeffries, a co-founder of extreme programming, who summarised the practice as: "Always implement things when you actually need them, never when you just foresee that you need them."

Rationale

Software developers frequently predict future requirements and build general, flexible solutions in anticipation. YAGNI argues that such predictions are unreliable and costly: speculative features add code that must be written, tested, documented, and maintained, and they increase complexity, which in turn makes the genuinely needed changes harder. Postponing a feature until it is actually required usually results in a better-informed design informed by real use.

Relationship to other principles

YAGNI is closely related to the XP practice of "do the simplest thing that could possibly work" and complements principles such as KISS ("keep it simple, stupid") and, in some tension, DRY ("don't repeat yourself"). While DRY encourages abstraction to remove duplication that already exists, YAGNI discourages abstraction created in anticipation of duplication that has not yet occurred. The principle is a core element of the "simple design" values promoted by Kent Beck and others in the agile software development movement.

Criticism

Critics note that some architectural decisions are expensive to retrofit — for example, concerns such as security, internationalisation, or scalability may be far cheaper to design in from the start. Practitioners generally answer that YAGNI applies to features and speculative generality, not to good design, refactoring, or automated tests, which XP treats as continuous activities that keep the cost of later change low.
