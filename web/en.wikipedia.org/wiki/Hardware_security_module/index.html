Hardware security module

From Wikipedia, the free encyclopedia

A hardware security module (HSM) is a physical computing device that safeguards and manages secrets—usually cryptographic keys—and performs encryption, decryption, digital signing and strong authentication on behalf of other systems. HSMs are designed to be tamper-evident and tamper-resistant, so that keys can be used but not extracted in plaintext.

Design

HSMs come as plug-in cards for servers, standalone network appliances, or portable USB devices. They typically include a secure cryptoprocessor, protected key storage, a hardware random number generator and mechanisms that erase secrets if the enclosure is breached. Applications communicate with the HSM through standard APIs such as PKCS#11, Microsoft CryptoAPI/CNG or Java Cryptography Architecture, sending data to be signed or decrypted without the key ever leaving the device.

Certification

HSMs are commonly certified to the FIPS 140-2/140-3 standard, at Levels 3 or 4, or evaluated under Common Criteria. Such certification is often a requirement in regulated industries.

Uses

Banks rely on HSMs to generate and verify card PINs and to protect ATM and payment networks. Certificate authorities protect their root signing keys in HSMs, and HSMs secure TLS private keys, code-signing keys, blockchain and cryptocurrency custody, and national identity systems. Cloud providers offer HSM-backed key management services, including dedicated "cloud HSM" appliances, allowing customers to keep control of keys while using cloud infrastructure.
