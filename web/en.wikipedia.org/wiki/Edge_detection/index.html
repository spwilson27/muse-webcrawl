Edge detection

Edge detection includes a variety of mathematical methods that aim at identifying edges — curves in a digital image at which the image brightness changes sharply, or, more formally, has discontinuities. Such changes typically correspond to important events and structure in a scene, such as object boundaries, surface markings, changes in surface orientation, and variations in material properties. Edge detection is a fundamental tool in image processing, machine vision, and computer vision, particularly for feature detection and feature extraction.

Approaches

Many edge detection operators approximate the first derivative of image intensity: the Sobel, Prewitt, and Roberts operators use small convolution kernels to estimate gradients, after which thresholding isolates strong responses. Second-derivative methods, such as the Laplacian of Gaussian (Marr–Hildreth) operator, locate edges at zero crossings. The Canny edge detector (1986) remains widely used: it smooths the image with a Gaussian filter, computes gradient magnitude and direction, thins responses by non-maximum suppression, and links edges using hysteresis thresholding, yielding good detection, good localisation, and single responses.

Applications

Edges serve as input to segmentation, object recognition, image registration, and document analysis. Because edge pixels carry much of an image's semantic information, edge maps are far more compact than the original image and are a standard early stage in vision pipelines.
