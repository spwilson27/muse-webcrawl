Memory address

Memory address
Related conceptsPointer, virtual memory, address space
Typical sizes32-bit, 64-bit addresses

In computing, a memory address is a reference to a specific memory location used at various levels by software and hardware to access data and instructions stored in memory. The memory address is typically represented as an unsigned integer in binary form, though displayed for convenience in hexadecimal. Programs manipulate data by loading it from, and storing it to, addressed locations; the CPU's memory management unit translates addresses used by a program into physical addresses in RAM.

Types of addresses

  • Physical address: the actual location in main memory, placed on the address bus.
  • Logical/virtual address: the address used by a running program within its own virtual address space, translated by the MMU using page tables.
  • Effective address: the result of an instruction's addressing-mode computation (base + index + displacement, and so on).

Address space and word size

The number of distinct addresses a machine can reference is determined by the width of its addresses: a 32-bit architecture can address at most 232 bytes (4 GiB) of byte-addressable memory, while 64-bit architectures raise the theoretical limit to 264 bytes. In byte-addressable machines each address refers to one byte; in word-addressable machines, historically common, each address refers to a machine word.

Addressing modes and pointers

Assembly instructions reach operands through addressing modes such as immediate, direct, indirect, register-indirect, and indexed addressing. In high-level languages such as C, a pointer is a variable that stores a memory address, enabling dynamic data structures and manual memory management.
