Live CD

Live CD
TypeBootable optical disc / operating system distribution
RelatedLive USB, Live image
ExamplesKnoppix, Ubuntu live media, SystemRescue

A live CD (also live DVD or live disc) is a complete bootable computer operating system installation that runs directly from a CD-ROM or similar storage medium into a computer's memory, rather than loading from a hard disk drive. A live CD allows users to run an operating system for any purpose without installing it or making any changes to the computer's configuration. Live CDs can run on a computer without secondary storage, such as a hard disk drive, or with a corrupted hard disk drive or file system, allowing data recovery.

As CD and DVD drives have been steadily phased out, live CDs have become less popular, being replaced by live USBs, which are equivalent systems written to USB flash drives. The functionality of a live CD can also be provided by a "live image", a bootable disk image stored on a hard drive or network server.

History

The first Linux-based "live CD" was Yggdrasil Linux, released in 1993, although its live functionality was hampered by the low throughput of contemporary CD-ROM drives. DemoLinux, released in 1998, was a live CD distribution of the Linux operating system developed in France that could run entirely from CD. The concept gained wide popularity with the release of Knoppix in 2003, a Debian-based distribution by Klaus Knopper featuring automatic hardware detection and configuration. Knoppix became a widely used tool for system troubleshooting and demonstrations, and many distributions subsequently offered live CD versions of their installers, including Ubuntu, Fedora, and Linux Mint.

Uses

  • Evaluating or demonstrating an operating system without installing it
  • System rescue and repair, including removing malware and recovering files from a damaged installation
  • Data recovery from disks whose installed operating system no longer boots
  • Forensic analysis and secure computing, since the running system leaves the host disk untouched
  • Kiosk and classroom use, where every session begins from an identical known state

Technology

A live CD typically combines a read-only compressed file system, such as SquashFS, with a writable overlay held in RAM (often via tmpfs and a union mount such as OverlayFS or AUFS). Boot loaders such as isolinux load the kernel and an initial ramdisk, which then locate the compressed image on the disc. Because the medium is read-only and changes are kept in memory, rebooting discards all modifications unless a persistence mechanism on a separate partition or file is used.
