Inflection point

In differential calculus and differential geometry, an inflection point, point of inflection, flex, or inflexion is a point on a smooth plane curve at which the curvature changes sign. The curve changes from being concave upwards (positive curvature) to concave downwards (negative curvature), or vice versa.

Definition

If a function f is twice differentiable, an inflection point typically occurs where the second derivative f′′ equals zero and changes sign. A zero of f′′ that does not change sign is not an inflection point. The classic example is f(x) = x³, whose inflection point is at the origin: the curve is concave downward for x < 0 and concave upward for x > 0.

Classification

An inflection point at which the tangent is horizontal is a stationary point of inflection (as with x³ at the origin); one at which the tangent has a non-zero gradient is a non-stationary point of inflection. Inflection points mark where a function changes the direction of its bending and are of interest in curve sketching, economics (for example, the point of diminishing returns on a production curve) and physics.
