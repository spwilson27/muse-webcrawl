Opcode

In computing, an opcode (abbreviated from operation code) is the portion of a machine language instruction that specifies the operation to be performed. Besides the opcode itself, most instructions also specify the data, known as operands, on which the operation is to act.

Structure

Depending on the architecture, operands may be register values, stack values, memory addresses given by an addressing mode, or constants encoded in the instruction itself. Instruction sets differ widely: RISC architectures such as ARM and RISC-V use fixed-length instructions with regular opcode fields, while CISC architectures such as x86 use variable-length encodings with prefix bytes and escape sequences that extend the opcode space.

Opcodes beyond CPUs

The term is also used for bytecode formats — for example, Java bytecode and the Ethereum Virtual Machine each define their own opcode tables — and in networking and hardware protocols, where an opcode field in a packet or transaction identifies the requested operation.
