FluidSynth

FluidSynth, formerly named iiwusynth, is a free software synthesizer which converts MIDI note data into an audio signal using SoundFont technology without need for a SoundFont-compatible sound card. It can also play MIDI files and act as a virtual MIDI input device. As a software library, FluidSynth is embedded in many applications, including media players, game engines, and scorewriters such as MuseScore.

Features

FluidSynth reads SoundFont instrument banks in the SF2 and SF3 formats and renders MIDI in real time, supporting multiple MIDI channels, effects such as reverb and chorus, and several audio and MIDI drivers on Linux, macOS, and Windows. Its design as a reusable library lets other programs use it as their synthesis engine, while the standalone program provides a shell for interactive control. The related Qsynth application provides a graphical user interface for FluidSynth.
