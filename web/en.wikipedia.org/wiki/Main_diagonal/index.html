Main diagonal

In linear algebra, the main diagonal (sometimes called the principal diagonal, primary diagonal, or leading diagonal) of a matrix A consists of the entries ai,j where the row and column indices are equal (i = j). For a square matrix, the main diagonal runs from the top-left corner to the bottom-right corner.

Uses

The sum of the entries on the main diagonal of a square matrix is called its trace. A diagonal matrix is a matrix whose entries outside the main diagonal are all zero; an identity matrix is a diagonal matrix whose main diagonal consists entirely of ones. In matrix expressions, the main diagonal plays a key role in determinants, eigenvalues, and many algorithms.

For rectangular matrices, the term main diagonal is still used for the entries ai,i as far as they extend. The entries on the diagonal running from the top-right to the bottom-left form the anti-diagonal.
