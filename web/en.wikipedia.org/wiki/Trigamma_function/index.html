Trigamma function

In mathematics, the trigamma function, denoted ψ1(z), is the second of the polygamma functions and is defined as the derivative of the digamma function:

ψ1(z) = d2/dz2 ln Γ(z) = Σn=0∞ 1/(z+n)2

It follows from the series that ψ1(1) = π2/6, the value of the Basel problem sum, and ψ1(1/2) = π2/2.

Properties

The trigamma function satisfies a recurrence, ψ1(z+1) = ψ1(z) − 1/z2, and a reflection formula relating ψ1(1−z) and ψ1(z) to π2/sin2(πz). It has a simple pole of order two at each non-positive integer. For large |z| it admits the asymptotic expansion ψ1(z) ~ 1/z + 1/(2z2) + 1/(6z3) − 1/(30z5) + …, involving Bernoulli numbers. The trigamma function also equals the sum of the Hurwitz zeta function ζ(2, z).

Applications

Trigamma values appear in the exact evaluation of definite integrals and infinite series, in statistics (the variance of the log of a gamma-distributed variable), and in analytic number theory.
