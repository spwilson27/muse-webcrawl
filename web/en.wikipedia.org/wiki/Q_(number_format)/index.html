Q (number format)

The Q notation is a way to specify the parameters of a fixed-point numeric representation used in digital signal processing and embedded systems. A number written as Qm.n — or Qn when m = 0 — consists of m bits for the integer part (including the sign bit in signed representations) and n bits for the fractional part, stored in a fixed-width word.

Notation

For example, Q1.15 is the standard 16-bit signed fixed-point format: one sign/integer bit and fifteen fractional bits, representing values from −1.0 to just under +1.0 in steps of 2−15. The total word length is m + n bits, and the number of fractional bits determines the resolution of the representation. Texas Instruments popularised the notation with its DSP documentation and IQmath libraries.

Use

Fixed-point arithmetic with Q formats allows fractional computation on processors without a floating-point unit, trading dynamic range for speed and determinism. Conversions between Q formats involve shifting and scaling, and arithmetic in Q format underlies many filtering, control, and audio algorithms.
