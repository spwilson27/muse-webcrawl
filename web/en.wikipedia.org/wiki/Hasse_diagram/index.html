Hasse diagram

In order theory, a Hasse diagram is a type of mathematical diagram used to represent a finite partially ordered set, in the form of a drawing of its transitive reduction. Such a diagram is named after the German mathematician Helmut Hasse (1898–1979), who popularised their use.

Definition

For a partially ordered set (S, ≤), one represents each element of S as a vertex in the plane and draws a line segment (or curve) upward from x to y whenever x < y and there is no z with x < z < y — that is, whenever x is covered by y. Arrowheads and loops are omitted: the vertical direction encodes the order, and transitivity supplies all the remaining comparisons implicitly. A classic example is the set of divisors of 12 ordered by divisibility, drawn with 1 at the bottom and 12 at the top.

Reading a Hasse diagram

An element a is less than an element b exactly when there is an ascending path from a to b in the diagram. Elements on the same horizontal "rank" need not be comparable; two elements with no ascending path between them are incomparable. The power set of a set, ordered by inclusion, produces a Hasse diagram in the shape of a hypercube.

Layout

Although Hasse diagrams were originally drawn by hand, algorithms for drawing them automatically are an active topic in graph drawing: good layouts minimise edge crossings and keep edges at uniform slopes. Upward planarity of the underlying cover graph is the corresponding theoretical notion.

Examples

  • The Boolean lattice of subsets of a three-element set forms a cube.
  • The partition lattice of a set, ordered by refinement.
  • The positive integers under divisibility form an infinite Hasse diagram.
