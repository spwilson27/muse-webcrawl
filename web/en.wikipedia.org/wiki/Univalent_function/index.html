Univalent function

In complex analysis, a univalent function is an analytic function that is injective on its domain. The study of univalent functions on the unit disk is a central topic of geometric function theory.

Class S

The class S consists of functions analytic and univalent in the unit disk, normalized by f(0)=0 and f'(0)=1, with expansions f(z)=z+a2z2+…

Major results

The Koebe quarter theorem states the image of a function in S contains a disk of radius 1/4. The Bieberbach conjecture, proved by Louis de Branges in 1984, states |an| ≤ n, with equality for the Koebe function k(z)=z/(1-z)2.

Subclasses

Important subclasses include starlike, convex, close-to-convex and typically real functions, as well as the theory of Loewner chains and Schramm-Loewner evolution.
