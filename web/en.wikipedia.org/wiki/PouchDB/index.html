PouchDB

PouchDB is an open-source JavaScript database inspired by Apache CouchDB, designed to run in the browser and on Node.js. It stores data locally and synchronises with CouchDB-compatible servers when online.

Features

PouchDB implements the CouchDB replication protocol, uses a revision-tree model with eventual consistency, and supports map-reduce queries. In browsers it uses IndexedDB (or WebSQL/LevelDB backends in other environments). It is maintained under the Apache License 2.0.

Use

PouchDB is commonly used for offline-first web applications, allowing apps to work without a network connection and sync changes later.
