Five-point algorithm

The five-point algorithm is a method in computer vision for estimating the relative position and orientation (pose) of a calibrated camera between two views, given correspondences between five pairs of points. It solves for the essential matrix E, a 3×3 matrix encoding the epipolar geometry of the two views, which satisfies the epipolar constraint x′ᵀ E x = 0 for each corresponding pair of normalised image points.

Background

Five points is the minimum number needed to determine the essential matrix up to scale, because the essential matrix has five degrees of freedom (three for rotation and two for the direction of translation). Earlier approaches, such as the eight-point algorithm, used more correspondences and solved a linear system, but could produce matrices that do not satisfy the internal constraints of a true essential matrix (two equal non-zero singular values and one zero singular value).

The algorithm

The algorithm was presented by David Nistér in 2004. From five point correspondences, the epipolar equations yield a 5×9 coefficient matrix whose four-dimensional null space gives a basis for the essential matrix. Imposing the cubic constraints on E — the determinant condition det(E) = 0 and the trace constraint 2EEᵀE − tr(EEᵀ)E = 0 — produces ten cubic equations in four unknowns. These are solved by computing the action matrix from a Gröbner basis (via Gauss–Jordan elimination on an expanded polynomial system), giving up to ten real solutions for E. Each candidate is then tested against additional correspondences.

Applications

Because it uses the minimal sample, the five-point algorithm is the standard minimal solver inside RANSAC procedures for robust relative pose estimation, visual odometry, structure from motion and SLAM, where its small sample size greatly reduces the number of iterations needed to reject outlier correspondences.
