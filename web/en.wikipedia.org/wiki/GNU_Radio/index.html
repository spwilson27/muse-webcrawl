GNU Radio is a free software development toolkit that provides signal processing blocks to implement software-defined radios and signal-processing systems. It can be used with external radio frequency hardware to create software-defined radios, or without hardware in a simulation-like environment. It is widely used in hobbyist, academic and commercial environments to support both wireless communications research and real-world radio systems.

Overview

GNU Radio applications are constructed as flow graphs in which signal-processing blocks — sources, filters, modulators, demodulators, decoders and sinks — are connected together and stream samples between them. The performance-critical blocks are written in C++ (with SIMD acceleration provided by the VOLK library), while the flow graph structure is usually described in Python, or graphically with the GNU Radio Companion (GRC) tool.

The project began in 2001, growing out of work at MIT and the Pspectra project; Eric Blossom became its principal maintainer. In 2004 a complete rewrite produced the architecture still in use today. GNU Radio is part of the GNU Project.

Applications

GNU Radio has been used to build GSM, LTE and ADS-B receivers, passive radar systems, radio-astronomy instruments, satellite ground stations and amateur-radio transceivers. Notable users have included NASA, universities, and signals-intelligence hobbyists; the gr-osmosdr and UHD drivers connect it to hardware such as the USRP, HackRF, RTL-SDR and Airspy.

Governance

Since 2011 the project has been fiscally sponsored and led by a project leadership team, holding an annual conference, GRCon, and participating in Google Summer of Code. The codebase is licensed under the GNU General Public License version 3.
