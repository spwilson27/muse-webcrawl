Combinatorial optimization

The travelling salesman problem, a classic combinatorial optimization problem

Combinatorial optimization is a subfield of mathematical optimization in which the set of feasible solutions is discrete or can be reduced to a discrete set. Typical problems involve finding the best element of a finite (but usually enormous) set — for example, the shortest route visiting a set of cities, the best packing of items into bins, or the optimal assignment of tasks to machines.

Examples

  • Travelling salesman problem
  • Knapsack problem
  • Bin packing problem
  • Minimum spanning tree
  • Maximum flow problem
  • Assignment problem
  • Graph coloring
  • Vehicle routing problem

Methods

Many combinatorial problems, such as shortest paths and minimum spanning trees, can be solved exactly in polynomial time. Others are NP-hard, so exact solutions rely on techniques such as branch and bound, branch and cut, dynamic programming, and integer programming formulations solved by commercial solvers. In practice, large instances are handled with approximation algorithms and heuristics and metaheuristics such as simulated annealing, tabu search, genetic algorithms, and local search.

Applications

Combinatorial optimization underlies logistics and supply-chain planning, airline crew scheduling, telecommunications network design, VLSI chip layout, protein structure prediction, and timetabling.
