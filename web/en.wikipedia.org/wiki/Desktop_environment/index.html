Desktop environment

In computing, a desktop environment (DE) is an implementation of the desktop metaphor — a bundle of programs running on top of an operating system that shares a common graphical user interface (GUI), sometimes described as a graphical shell. Desktop environments typically include a window manager, file manager, panels, settings tools, and a suite of default applications.

The desktop metaphor was pioneered at Xerox PARC in the 1970s and popularised by the Apple Macintosh and Microsoft Windows. On Unix-like systems, the best-known desktop environments include GNOME, KDE Plasma, Xfce, Cinnamon, and MATE. These run on display servers such as the X Window System or Wayland.

Desktop environments differ from stand-alone window managers, which provide only the framework for windows and rely on separately chosen programs for the rest of the interface.
