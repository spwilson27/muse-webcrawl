Hilbert's tenth problem

Hilbert's tenth problem asks for an algorithm that decides, given any Diophantine equation with integer coefficients, whether it has a solution in integers. It was one of Hilbert's 23 problems of 1900.

Solution

In 1970, Yuri Matiyasevich completed work by Martin Davis, Hilary Putnam, and Julia Robinson proving that no such algorithm exists: the problem is undecidable. The result, known as the MRDP theorem, established that every recursively enumerable set is Diophantine.

Consequences

The theorem links number theory with computability theory and implies, among other things, that there is a polynomial equation whose positive values are exactly the prime numbers.
