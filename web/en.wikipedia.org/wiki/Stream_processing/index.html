Stream processing

Stream processing is a programming paradigm and a model of computation in which data is treated as a continuous, potentially unbounded sequence of records (a stream) that is processed incrementally as it arrives, rather than being stored and processed in batches. Stream processing systems can filter, aggregate, join, and transform data in real time, with low latency.

Characteristics

In a stream processing system, computations are typically defined as dataflow graphs of operators applied to streams. Key concerns include handling out-of-order and late-arriving events (using event time and watermarks), maintaining stateful computations over windows of data, and guaranteeing processing semantics such as exactly-once delivery. Common applications include fraud detection, monitoring and alerting, real-time analytics, and processing of sensor and clickstream data.

Systems

Widely used stream processing frameworks include Apache Kafka Streams, Apache Flink, Apache Spark Structured Streaming, and Apache Storm. Modern systems combine streaming with batch processing under unified APIs, an approach sometimes called the "Kappa architecture", in contrast to the earlier Lambda architecture.
