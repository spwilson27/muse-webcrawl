Statistical classification

In statistics, classification is the problem of identifying which of a set of categories (sub-populations) an observation (or observations) belongs to. Examples include assigning an e-mail to a "spam" or "non-spam" class, or assigning a diagnosis to a patient based on observed characteristics. In the machine learning literature the term is used for supervised learning algorithms that learn a classifier from labelled training data; in the statistics literature the same task is often called discriminant analysis or supervised classification.

Formulation

Formally, an observation is represented by a feature vector x and the aim is to predict a class label y taking values in a finite set of categories. Classification differs from regression, where the predicted output is a continuous quantity, and from clustering, where the categories are not known in advance (unsupervised learning). When there are only two classes the problem is binary classification; with more than two it is multiclass classification.

Algorithms

  • Linear classifiers — logistic regression, linear discriminant analysis (LDA), perceptron, linear support vector machines
  • Naive Bayes classifiers — based on Bayes' theorem with conditional-independence assumptions
  • Decision trees and ensembles such as random forests and gradient boosting
  • Support vector machines with kernel functions
  • k-nearest neighbours
  • Neural networks, including deep learning models
  • Quadratic discriminant analysis (QDA)

The earliest formal approach was Fisher's linear discriminant (1936), developed by R. A. Fisher for classifying iris flowers and taxonomic specimens.

Evaluation

Classifier performance is commonly summarised with a confusion matrix, from which accuracy, precision, recall (sensitivity), specificity and the F1 score are derived. For binary problems the ROC curve and its area under the curve (AUC) measure performance across decision thresholds. Because a classifier tuned and tested on the same data gives an optimistic estimate, techniques such as cross-validation and held-out test sets are used for honest evaluation.

Applications

Classification is used in document and e-mail categorisation, spam filtering, medical diagnosis, credit scoring, fraud detection, face and speech recognition, bioinformatics (for example protein classification), and many other domains.
