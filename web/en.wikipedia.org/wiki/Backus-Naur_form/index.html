Backus–Naur form

In computer science, Backus–Naur form (BNF; Backus normal form or Backus form) is a notation used to describe the syntax of languages used in computing, such as computer programming languages, document formats, instruction sets and communication protocols. It is a formal metalanguage used to express context-free grammars that define those languages.

BNF was introduced in the late 1950s by John Backus and Peter Naur for describing the syntax of the ALGOL 60 programming language. Variants of the notation are widely used as the basis for parser generators and for specifying languages in standards documents such as Internet RFCs.

Description

A BNF specification is a set of derivation rules, written as

<symbol> ::= __expression__

where <symbol> is a nonterminal, and the expression consists of one or more sequences of symbols separated by the vertical bar, |, indicating a choice. Symbols that never appear on the left side are terminals. The symbol ::= means "is defined as". A production with multiple alternatives can be written on several lines for readability.

Example

A possible BNF description of a simple postal address might be:

<postal-address> ::= <name-part> <street-address> <zip-part>
<name-part>      ::= <personal-part> <last-name> | <personal-part> <name-part>
<street-address> ::= <house-num> <street-name> <opt-apt-num>
<zip-part>       ::= <zip-code>

Variants

Several variants extend or simplify the original notation. Extended Backus–Naur form (EBNF), standardized as ISO/IEC 14977, adds regular-expression-like operators for repetition, optionality, and grouping. Augmented Backus–Naur form (ABNF), defined in RFC 5234, is used to specify Internet protocols such as HTTP and email and uses character-string terminals and case-insensitive literals.

History

John Backus presented a notation based on Emil Post's production systems at a 1959 UNESCO conference on ALGOL. Peter Naur, editor of the ALGOL 60 report, simplified the notation and is credited with calling it Backus normal form; Donald Knuth later suggested that the name "Backus–Naur form" was more appropriate because the notation is not a normal form in the technical sense.
