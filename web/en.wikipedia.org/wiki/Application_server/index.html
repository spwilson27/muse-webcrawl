Application server

An application server is a server that hosts applications or software that delivers a business application through a communication protocol, typically supporting the construction of dynamic web pages and web services. The term originally referred to servers in three-tier architectures that ran application logic between user interfaces and databases, and came to prominence with Java EE (Jakarta EE) platforms and Microsoft's .NET framework.

Functions

Application servers provide services such as transaction management, security, clustering, load balancing, connection pooling and messaging, so that developers can concentrate on business logic rather than infrastructure. Examples include WildFly, WebLogic, WebSphere, GlassFish (now Eclipse GlassFish), Apache Tomcat (a servlet container sometimes classed with application servers), and application servers for other languages such as PHP, Ruby and Python environments.

Relation to web servers

A web server primarily serves static content and forwards dynamic requests, whereas an application server executes application code and generates dynamic content itself. In modern deployments the distinction has blurred, with web servers, application servers and frameworks often combined behind reverse proxies and in cloud platforms.
