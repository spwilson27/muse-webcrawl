Watchman route problem

The watchman route problem asks for the shortest route from which a watchman can see an entire polygon.

Field: Computational geometry

The watchman route problem is a problem in computational geometry concerning visibility. Given a simple polygon — modelling, for example, the floor plan of a building or art gallery — the problem asks for the shortest closed route (or path) inside the polygon such that every point of the polygon is visible from at least one point of the route. The name evokes a night watchman patrolling a building who must be able to see every room.

Relation to the art gallery problem

The watchman route problem is closely related to the art gallery problem, which asks for the minimum number of stationary guards needed to see the whole polygon. A single mobile guard following an optimal watchman route can replace many stationary guards. Variants include routes for polygons with holes, multiple watchmen, and watchmen with limited visibility range or field of view, as well as applications in robot motion planning, where a robot with sensors must inspect an entire environment.

Complexity

The problem can be solved in polynomial time for simple polygons without holes, using the notion of an "essential" set of visibility cuts that any valid route must cross. For polygons with holes, and for several natural variants, the problem is NP-hard, and approximation algorithms are studied instead.
