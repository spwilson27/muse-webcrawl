Cairo (graphics)

Cairo
Type: Graphics library
Written in: C
License: LGPL / MPL
First release: 2003

Cairo (stylized as cairo) is an open-source graphics library that provides a vector graphics-based device-independent API for software developers. It provides software routines for drawing vector graphics, text and images onto various output back ends.

Design

Cairo uses a drawing model closely following that of PDF and PostScript: paths are constructed from lines and Bézier curves, then stroked, filled, clipped or used as masks, with colour applied from solid, gradient or pattern sources. Because output is resolution-independent, the same code can render to a screen window, an image buffer, a PDF document or a printer.

Back ends and users

Back ends include X11/XCB, Win32, Quartz, image buffers, PDF, PostScript and SVG. Cairo underlies much of the GNOME desktop and the GTK toolkit, and is used by Mozilla software, Inkscape, GIMP and many other projects. Language bindings exist for C++, Python, Rust, Java and others.

History

The project began within XFree86-related work by Keith Packard and Carl Worth, evolving out of the Xr library; it was renamed Cairo in 2003. Version 1.0 was released in 2005, and the library continues to be maintained by the freedesktop.org community.
