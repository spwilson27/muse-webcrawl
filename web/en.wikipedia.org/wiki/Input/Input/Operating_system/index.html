Operating system

From Wikipedia, the free encyclopedia


Position of an operating system in a computer system.

An operating system (OS) is system software that manages computer hardware and software resources, and provides common services for computer programs. Time-sharing operating systems schedule tasks for efficient use of the system and may also include accounting software for cost allocation of processor time, mass storage, peripherals, and other resources. The operating system acts as an intermediary between users and the computer hardware, creating an environment in which applications can run conveniently and efficiently while being isolated from one another.

Components

The core of an operating system is the kernel, which controls the CPU, memory, and devices. Around it sit system services: a file system, networking stack, security and authentication, and the system libraries and utilities that applications use. Most desktop systems bundle a user interface — a graphical shell or a command-line interpreter — as part of the operating system distribution.

Functions

Key functions include process and thread management with CPU scheduling; memory management, including virtual memory that gives each process its own address space; file and directory management on storage media; device control through drivers; user authentication and access control; and error detection and handling. Modern systems add power management, virtualization support, and sandboxing of applications.

Types

Operating systems are often classified as batch, time-sharing, distributed, real-time, or embedded. Real-time operating systems guarantee response within strict deadlines for industrial and embedded control. Mobile operating systems combine a general-purpose OS with touch interfaces and application stores. Server and mainframe systems emphasise throughput, reliability, and virtualization.

Examples

Dominant families include Microsoft Windows on desktop PCs; macOS and Linux on desktops and servers; Android (Linux-based) and iOS on mobile devices; and Unix and Unix-like systems throughout servers, supercomputers, and embedded devices. By device count, Linux-derived systems power the majority of the world's computers when phones, servers, and embedded devices are included.

History

The first operating systems of the 1950s, such as GM-NAA I/O and the SHARE Operating System, automated batch job loading. IBM's OS/360 (1964) introduced a family-wide OS; time-sharing systems like CTSS and Multics pioneered interactive use and influenced Unix (1969), whose portability and tools philosophy shaped everything after it. The personal-computer era brought CP/M, MS-DOS, the Macintosh System Software, and Windows; the 1990s added free systems — Linux (1991) and the BSDs — that now dominate servers and infrastructure.
