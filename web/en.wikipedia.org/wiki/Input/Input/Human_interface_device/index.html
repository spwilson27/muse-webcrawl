Human interface device

From Wikipedia, the free encyclopedia


Keyboards, mice, and game controllers are common HIDs.

A human interface device or HID is a type of computer device usually used by humans that takes input from or provides output to humans. The term "HID" most commonly refers to the USB-HID specification, a generic device class defined by the USB Implementers Forum for devices such as keyboards, mice, and game controllers, which allows them to work with a single standard driver rather than a vendor-specific one.

USB HID class

The USB HID class describes devices through report descriptors — data structures that tell the host exactly what data the device sends and receives: which buttons, axes, keys, and indicator LEDs it has, and the format of each report. This self-describing design, formalised in the Device Class Definition for Human Interface Devices (firmware 1.11), let a single operating-system driver handle thousands of products. HID devices communicate over the USB interrupt transfer pipe with low latency, and the class was later carried over Bluetooth (HID over GATT, "HOGP") and I2C.

Examples

Typical HIDs include keyboards, pointing devices (mouse, trackball, touchpad, pointing stick), game controllers (joysticks, gamepads, steering wheels), front-panel controls such as knobs and switches, barcode scanners in keyboard-emulation mode, and assistive devices for users with disabilities. Telephony devices, uninterruptible power supplies, and some sensors also expose HID interfaces.

Advantages and limitations

Because operating systems ship with HID class drivers, devices are plug-and-play and portable across platforms. The trade-offs are the modest bandwidth of the interrupt pipe and the fixed, descriptor-driven report format. The very generality of the class has also been exploited for attacks: a malicious device can present itself as a keyboard and inject keystrokes (the "BadUSB" class of attacks), a risk addressed by endpoint-security policies that restrict unauthorised HID devices.

Related concepts

The broader discipline of human–computer interaction studies input and output devices generally, including displays, printers, and haptic devices that are not part of the USB HID class. In video games, HID support determines which controllers an operating system or console recognises natively.
