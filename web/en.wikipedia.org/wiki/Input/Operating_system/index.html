Operating system
System software managing hardware and providing services to applications.

An operating system (OS) is system software that manages computer hardware and software resources, and provides common services for computer programs. Time-sharing operating systems schedule tasks for efficient use of the system and may also include accounting software for cost allocation of processor time, mass storage, peripherals, and other resources.

Functions

The operating system acts as an intermediary between users and hardware. Its kernel manages processes and threads, allocates memory, controls devices through drivers, and handles input from devices via mechanisms including interrupts. Higher layers provide file systems, networking stacks, security and access control, and user interfaces — command-line shells or graphical desktops. Applications interact with the OS through system calls and APIs.

Types

Operating systems are categorized by purpose: general-purpose desktop systems (Windows, macOS, Linux distributions), mobile systems (Android, iOS), server systems, embedded systems, and real-time operating systems (RTOS) that guarantee response deadlines. Multi-user, multitasking systems descend from the time-sharing mainframes of the 1960s.

History

Early computers had no operating system; programs controlled hardware directly. Batch monitors of the 1950s (GM-NAA I/O, 1956) automated job loading, and systems such as IBM's OS/360 (1964) and Multics pioneered multiprogramming and time-sharing. Unix (1969) influenced nearly all later designs. Personal computing brought CP/M and MS-DOS, then graphical systems from Xerox PARC, Apple, and Microsoft. Linux (1991) and the BSD family carried Unix ideas into the open-source era, and mobile platforms of the 2000s extended OS services to sensors, radios, and app sandboxes.

Input handling

Input is a core OS responsibility: keyboard, pointer, touch, and network events are received by drivers, queued and timestamped, and dispatched to the focused application. Subsystems such as USB HID stacks and event loops in windowing systems are described in articles including human interface device and interrupt handler.
