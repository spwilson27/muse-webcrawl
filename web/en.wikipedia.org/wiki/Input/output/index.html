Input/output

In computing, input/output (I/O, or input and output) is the communication between an information processing system, such as a computer, and the outside world, such as another computer system, peripherals, or a human operator. Inputs are the signals or data received by the system and outputs are the signals or data sent from it. The term can also refer to an action: "performing I/O" means to perform an input or output operation.

Devices

I/O devices are the hardware used by a human (or other systems) to communicate with a computer. Devices that provide input only are called input devices (for example keyboards and mice); devices that provide output only are output devices (monitors and printers); and devices that do both, such as disks, network interfaces, and touchscreens, are input/output devices. I/O devices are typically grouped as block devices, which store and transfer data in fixed-size blocks, and character devices, which transfer data one character at a time.

Techniques

Because processors are typically much faster than I/O devices, several techniques coordinate data transfer. In programmed I/O, the CPU polls the device to check whether it is ready. With interrupt-driven I/O, the device signals the CPU when ready, allowing the processor to do other work meanwhile. Direct memory access (DMA) lets a device transfer data directly to or from memory without CPU involvement in each word. In memory-mapped I/O, devices are controlled through the same address space as memory, while port-mapped I/O uses a separate address space and special instructions.

Software handling

Operating systems manage I/O through device drivers and system calls, presenting applications with abstractions such as files and streams. Mechanisms such as buffering, caching, and spooling smooth over speed differences; asynchronous and non-blocking I/O APIs (for example, epoll, kqueue, and IOCP) let programs manage many simultaneous I/O operations efficiently. In programming languages, the standard library typically exposes standard input, standard output, and standard error streams, a model popularized by Unix.
