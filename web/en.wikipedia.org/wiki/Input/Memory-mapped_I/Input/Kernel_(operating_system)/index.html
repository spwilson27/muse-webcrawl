Kernel (operating system)

A kernel is a computer program at the core of a computer's operating system that always has complete control of everything in the system. It is the portion of the operating system code that is always resident in memory and facilitates interactions between hardware and software components. The kernel is responsible for low-level tasks such as process and memory management, disk and task scheduling, and handling of interrupts and system calls.

System calls and modes

Applications run in user mode and request services from the kernel through system calls, which trigger a controlled switch into privileged kernel mode, where the code has unrestricted access to the hardware. The kernel checks the validity of requests, performs the operation — for example, reading from a device or allocating memory — and returns the result. Device drivers, which may run as part of the kernel or as loadable modules, mediate access to specific hardware.

Designs

Kernels are commonly classified as monolithic, in which all operating-system services run in kernel space (Linux is the best-known example); microkernels, which keep only the most fundamental functions — inter-process communication, basic scheduling and memory management — in kernel space and run other services in user space (as in Mach and MINIX); and hybrid kernels, combining elements of both (as in Windows NT and macOS's XNU). The merits of each design were the subject of the famous Tanenbaum–Torvalds debate of 1992.
