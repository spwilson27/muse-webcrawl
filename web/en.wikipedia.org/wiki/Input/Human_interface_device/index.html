Human interface device
Input devices that take input directly from humans.

A human interface device (HID) is a type of computer device that interacts directly with, and most often takes input from, humans. The term was popularized by the USB Implementers Forum's HID class specification, which standardized how such devices communicate over USB, and the concept was later extended to Bluetooth (HID over GATT) and other transports.

Examples

Common human interface devices include keyboards, mice, pointing devices such as trackballs and touchpads, game controllers and joysticks, graphics tablets, touchscreens, barcode scanners, and biometric readers such as fingerprint scanners. Some HID-class devices also provide output to the user, for example force-feedback game controllers, braille displays, and the indicator LEDs on a keyboard.

The USB HID class

The USB HID class defines a protocol in which a device describes its data formats to the host using a report descriptor. Because the description is generic, operating systems can support a wide range of devices with a single built-in class driver, without vendor-specific drivers. Data is exchanged in structured reports over interrupt endpoints, giving low latency suitable for interactive input. The HID Usage Tables document maintained by the USB-IF assigns standardized codes to keys, buttons, axes, and controls.

Extensions and related concepts

Bluetooth Low Energy devices implement HID over the GATT profile (HOGP). The broader term human–computer interaction covers the design of such devices, while in industrial control an HMI (human–machine interface) usually refers to a panel or terminal used to monitor and control machinery.
