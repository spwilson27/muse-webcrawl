Device driver

In computing, a device driver is a computer program that operates or controls a particular type of device that is attached to a computer or automaton. A device driver provides a software interface to hardware devices, enabling operating systems and other computer programs to access hardware functions without needing to know precise details about the hardware being used.

Operation

A device driver simplifies programming by acting as a translator between a hardware device and the applications or operating systems that use it. Instead of dealing with the device's registers, protocols and timing directly, programmers use a standardised high-level application programming interface (API). When a calling program invokes a routine in the driver, the driver issues commands to the device; when the device sends data back, the driver invokes routines in the calling program.

Drivers may run in kernel space, where they have direct access to hardware but where a fault can crash the whole system, or in user space, as in microkernel designs, where they are isolated but incur communication overhead. Modern operating systems such as Linux, Windows and macOS ship with generic drivers for common device classes (for example USB mass storage and HID devices), supplemented by vendor-specific drivers for graphics cards, printers and network adapters.

Development

Writing a device driver requires an in-depth understanding of how the hardware and the operating system work. Because drivers interact closely with low-level hardware events — interrupts, DMA transfers and memory-mapped I/O — bugs in drivers are a common source of system instability. Hardware manufacturers publish programming manuals and reference drivers, and frameworks such as the Windows Driver Model and the Linux device model standardise driver structure.

Virtual device drivers

A virtual device driver presents a software abstraction of hardware that may not exist physically, or virtualises a real device for use by virtual machines. Hypervisors use paravirtualised drivers to give guest systems efficient access to storage and networking.
