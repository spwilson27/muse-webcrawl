Kernel (operating system)

From Wikipedia, the free encyclopedia

Kernel
The core component of an operating system, mediating between applications and hardware.

A kernel is a computer program at the core of a computer's operating system that always has complete control of everything in the system. It is the portion of the operating system code that is always resident in memory and facilitates interactions between hardware and software components. The kernel performs tasks such as running processes, managing hardware devices (through device drivers), handling interrupts, and managing memory and I/O.

Functions

Typically, the kernel is responsible for process management (scheduling and inter-process communication), memory management (virtual memory, paging, and protection), device management, and system call handling. User programs request services from the kernel through system calls, crossing from the unprivileged user mode into privileged kernel mode. This separation protects the system: application programs cannot directly access hardware or another process's memory.

Design approaches

In a monolithic kernel, such as the Linux kernel, most operating-system services run in kernel space within a single address space, favoring performance and simplicity of interaction between subsystems. A microkernel, as in MINIX 3 or the Mach-derived designs, keeps only the most basic services — scheduling, IPC, and basic memory management — in kernel space and runs drivers and file systems as user-space servers, favoring fault isolation and security at some cost in message-passing overhead. Hybrid kernels, such as the Windows NT kernel and Apple's XNU, combine elements of both. An exokernel exposes hardware resources almost directly to applications.

History

Early operating systems of the 1960s, including OS/360 and Multics, established the resident supervisor or monitor concept. Unix (1969) popularized a relatively small, portable kernel written in C. The 1990s saw debate over microkernel versus monolithic design, including the well-known Tanenbaum–Torvalds debate of 1992, as Linux grew rapidly while microkernel research systems such as Mach evolved.
