DirectShow

DirectShow (sometimes abbreviated DS or DShow), formerly known as ActiveMovie, is a multimedia framework and API produced by Microsoft for software developers to perform operations with media files and streams. Released in 1996 and long bundled with the DirectX SDK, it was the standard Windows architecture for audio and video playback and capture for many years.

DirectShow is built on a filter graph model: media flows from source filters (files, capture devices, network streams) through transform filters (decoders, splitters, effects) to renderer filters (speakers, screens). Applications assemble filters into a graph, which the Filter Graph Manager builds automatically by matching media types and registered filter "merit". Filters are COM objects, and third parties could extend the system with their own codecs and processing filters.

Although powerful and widely used by media players and video-editing tools, DirectShow's complexity and security exposure led Microsoft to develop Media Foundation as its intended successor from Windows Vista onward. DirectShow remains present in Windows for backward compatibility and is still relied on by many capture devices and applications.
