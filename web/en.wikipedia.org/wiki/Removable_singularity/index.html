Removable singularity

Removable singularity
FieldComplex analysis
Classification of singularitiesRemovable, pole, essential
Key resultRiemann's theorem on removable singularities

In complex analysis, a removable singularity of a holomorphic function is a point at which the function is undefined, but it is possible to redefine the function at that point in such a way that the resulting function is continuous and indeed holomorphic in a neighbourhood of the point. Intuitively, a removable singularity is one that can be "filled in" without disturbing the function elsewhere.

Formal definition

Let D be an open subset of the complex plane, a a point of D, and f a holomorphic function on D \ {a}. The point a is called a removable singularity for f if there exists a holomorphic function g defined on all of D that agrees with f on D \ {a}. In that case the value g(a) must equal the limit of f(z) as z approaches a.

Riemann's theorem

Riemann's theorem on removable singularities gives a simple criterion: if f is bounded in a neighbourhood of a, then a is a removable singularity. More generally, it suffices that f(z) = o(1/|z − a|) as z → a, or that the limit of (z − a) f(z) as z → a equals zero.

Example

The function f(z) = sin(z)/z is undefined at z = 0, but its limit there is 1. Defining f(0) = 1 yields the entire sinc function, so 0 is a removable singularity. By contrast, g(z) = 1/z also blows up at 0 and has a pole, while h(z) = exp(1/z) has an essential singularity at 0 and behaves wildly nearby, as described by the Casorati–Weierstrass theorem and Picard's great theorem.

Classification of singularities

Isolated singularities of holomorphic functions fall into exactly three classes: removable singularities, where the limit exists and is finite; poles, where the function tends to infinity and some power of (z − a) times f extends holomorphically with a nonzero value at a; and essential singularities, which are neither.
