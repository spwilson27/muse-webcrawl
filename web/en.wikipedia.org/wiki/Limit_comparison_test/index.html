Limit comparison test

In mathematics, the limit comparison test (LCT) (in contrast with the related direct comparison test) is a method of testing for the convergence of an infinite series.

Statement

Suppose we have two series Σn an and Σn bn, with an ≥ 0 and bn > 0 for all n. Then if

limn→∞ an/bn = c, with 0 < c < ∞,

then either both series converge or both series diverge. When c = 0, convergence of Σbn implies convergence of Σan; when c = ∞, divergence of Σbn implies divergence of Σan.

Proof idea

Because the ratio tends to c, for large n the terms an are between (c/2)bn and (3c/2)bn, so the direct comparison test applied to these bounds forces the two series to share the same fate.

Example

To test Σ 1/(n2 + 2n), compare with the convergent p-series Σ 1/n2: the ratio of terms tends to 1, a finite positive number, so the given series converges.
