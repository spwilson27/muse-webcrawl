Object storage

Object storage (also called object-based storage) is a computer data storage architecture that manages data as discrete units called objects, each bundling the data itself, descriptive metadata, and a globally unique identifier. Unlike file storage, which organises data in hierarchical directories, or block storage, which divides data into fixed blocks, object storage keeps objects in a flat namespace — typically grouped into containers or "buckets" — and accesses them through an HTTP-based API rather than a filesystem interface.

Characteristics

Because objects are self-describing and addressed by key, object storage systems scale to billions of objects and petabytes or exabytes of data, distributing replicas or erasure-coded fragments across many servers and sites for durability. Metadata can be extensive and customisable, enabling search and lifecycle policies. The trade-offs are that objects are generally written whole rather than modified in place, and latency is higher than with block storage, making object storage best suited to backups, archives, media libraries, data lakes, and web content.

Services and standards

Amazon S3, launched in 2006, popularised object storage, and its API became a de facto standard implemented by many vendors. Comparable services include Microsoft Azure Blob Storage and Google Cloud Storage, while on-premises systems such as Ceph and MinIO provide S3-compatible object storage in private data centres.
