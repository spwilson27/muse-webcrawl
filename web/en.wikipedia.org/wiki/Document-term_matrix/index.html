Document-term matrix

A document-term matrix is a mathematical matrix that describes the frequency of terms that occur in a collection of documents. In a document-term matrix, rows correspond to documents in the collection and columns correspond to terms. It is a fundamental representation in information retrieval, text mining, and natural language processing.

Example

catdogbird
Doc 1201
Doc 2031

Weighting schemes

The entries of the matrix may be raw counts, binary values, or weighted scores. A common weighting scheme is tf–idf (term frequency–inverse document frequency), which down-weights terms that appear in many documents. Because vocabularies are large and documents use few terms, such matrices are typically very sparse.

Applications

Document-term matrices underlie the vector space model of information retrieval, latent semantic analysis, document clustering, and topic models such as latent Dirichlet allocation.
