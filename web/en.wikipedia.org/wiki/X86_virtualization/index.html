x86 virtualization

x86 virtualization is the use of hardware-assisted virtualization capabilities of x86 processors to run multiple guest operating systems concurrently on a single physical machine, each within its own virtual machine managed by a hypervisor. The principal technologies are Intel VT-x and AMD-V.

Background

The classic x86 architecture was not designed for virtualization: certain privileged instructions behaved differently depending on privilege level without trapping to the hypervisor, violating the Popek and Goldberg virtualization requirements. Early x86 hypervisors such as VMware's products worked around this with binary translation of guest kernel code, while open-source systems such as Xen initially relied on paravirtualization, in which the guest operating system is modified to cooperate with the hypervisor.

Hardware assistance

Intel introduced VT-x (codenamed Vanderpool) in 2005, and AMD introduced AMD-V (codenamed Pacifica) in 2006. These add a new, more privileged mode of operation — often informally called "ring −1" — in which the hypervisor runs in VMX root mode while guests run in non-root mode. Sensitive instructions and events cause VM exits to the hypervisor, which emulates or mediates them, allowing unmodified guests to run.

Second-generation features reduced the cost of virtualization further: Extended Page Tables (EPT) from Intel and Nested Page Tables (NPT) from AMD let the processor translate guest virtual addresses to physical addresses in hardware, avoiding shadow page tables. VT-d and AMD-Vi (IOMMU) permit safe direct assignment of PCI devices to guests.

Software

Hypervisors using these extensions include KVM, Xen, VMware ESXi, Microsoft Hyper-V, VirtualBox and QEMU. Hardware-assisted x86 virtualization underpins modern cloud computing, server consolidation, desktop virtualization and sandboxing.
