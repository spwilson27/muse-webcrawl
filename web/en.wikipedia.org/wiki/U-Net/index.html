U-Net

U-Net is a convolutional neural network architecture developed for biomedical image segmentation at the University of Freiburg. It was introduced by Olaf Ronneberger, Philipp Fischer, and Thomas Brox in 2015. The architecture consists of a contracting path to capture context and a symmetric expanding path that enables precise localization, forming a characteristic U shape.

Architecture

The contracting (encoder) path repeatedly applies convolutions followed by max-pooling, doubling the number of feature channels at each downsampling step. The expansive (decoder) path upsamples the feature map and concatenates it with the correspondingly cropped feature map from the contracting path — the distinctive "skip connections" of U-Net — which allows high-resolution features to be combined with upsampled output. A final 1×1 convolution maps the feature vector to the desired number of classes.

Applications

U-Net achieved state-of-the-art results on several biomedical segmentation challenges while training on very few annotated images, aided by aggressive data augmentation with elastic deformations. Variants have since been applied far beyond medicine, including satellite imagery, industrial inspection, and as the denoising network in diffusion models for image generation.
