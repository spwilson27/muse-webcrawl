Audio Units (AU) are a system-level plug-in architecture provided by the Core Audio framework in Apple's macOS and iOS operating systems. Audio Units allow applications — typically digital audio workstations such as Logic Pro, GarageBand and third-party hosts — to load software instruments and audio effects written by Apple or third parties. The format is a direct competitor to Steinberg's VST and Avid's AAX formats.

An Audio Unit plug-in hosted in a DAW.

Architecture

Audio Units are built on Apple's Component Manager and later component plug-in APIs. Each unit declares a type — effect, instrument (music device), generator, mixer, panner, output and others — and communicates with the host through a C API describing properties, parameters and audio streams in the AudioStreamBasicDescription format. AU plug-ins historically shipped as bundles with the .component extension installed in /Library/Audio/Plug-Ins/Components.

AU version 3 and app extensions

With OS X El Capitan and iOS 9 (2015), Apple introduced Audio Unit version 3 (AUv3), implemented as app extensions. AUv3 plug-ins can run out of process, can be distributed through the App Store inside a containing app, and can run on both macOS and iOS, enabling desktop-class instruments and effects on iPad and iPhone hosts such as GarageBand for iOS and AUM.

Built-in units

macOS ships with a large set of Apple Audio Units, including AUDelay, AUDynamicsProcessor, AUBandpass, AUReverb2, the AUMatrixReverb, samplers (AUSampler), and the DLS synth. Apple's AU Lab and the command-line tool auval are used by developers to host and validate plug-ins.
