Platform independence

Platform independence is the property of software — or of a file format, protocol, or specification — of not depending on the characteristics of any single computing platform, so that it can be used on many different hardware and operating-system combinations without modification.

Ways of achieving it

Platform independence is commonly achieved by defining an abstract layer over the hardware: a virtual machine (as with Java's "write once, run anywhere" model), an interpreter, standardized languages and APIs (such as POSIX), or open data formats like HTML and PDF. Operating-system abstraction libraries hide platform differences from application code.

Degrees and limits

Independence is a matter of degree: a program may run unchanged on every platform with a Java virtual machine but still differ in performance or behaviour; "platform-agnostic" file formats can still render differently between implementations. The term is also used outside computing, for example for vendor-neutral specifications and standards.
