NPAPI

NPAPI (Netscape Plugin Application Programming Interface) is a cross-platform plugin architecture used by web browsers to support plugins such as Adobe Flash Player, Java applets, and media players. It was developed by Netscape in the 1990s for its Navigator browser.

History

Introduced with Netscape Navigator 2.0 in 1995, NPAPI was adopted by most major browsers, including Internet Explorer (via compatibility layers), Firefox, Safari, Opera and early versions of Chrome.

Deprecation

Because plugins were a frequent source of security vulnerabilities, instability and poor performance, browser vendors phased NPAPI out during the 2010s. Google Chrome removed support in 2015 and Mozilla Firefox in 2017; Adobe ended Flash Player at the end of 2020.
