Euler's totient function

Values of φ(n) for n = 1 to 1000.

In number theory, Euler's totient function counts the positive integers up to a given integer n that are relatively prime to n. It is written φ(n) (phi function) and defined as the number of integers k in the range 1 ≤ k ≤ n for which gcd(n, k) = 1. Thus φ(1) = 1, φ(2) = 1, φ(6) = 2 (namely 1 and 5), and φ(9) = 6.

Formula

Using the prime factorisation n = Π piki, Euler's product formula gives:

φ(n) = n Πp | n (1 − 1/p)

Hence φ is multiplicative: φ(mn) = φ(m)φ(n) whenever m and n are coprime; and for a prime p, φ(p) = p − 1, φ(pk) = pk − pk−1.

Properties and applications

The sum of φ(d) over the divisors d of n equals n (Gauss). The totient function is central to Euler's theorem, aφ(n) ≡ 1 (mod n) for a coprime to n, and thus to the RSA cryptosystem, where φ of a product of two secret primes must remain hidden. It also counts the generators of the cyclic group Z/nZ and the elements of the multiplicative group of units modulo n.

Unsolved problems

Carmichael's totient function conjecture—that no value of φ is taken exactly once—remains unproven, as does Lehmer's problem asking whether φ(n) dividing n − 1 implies n is prime. Values never taken by φ are called nontotients.
