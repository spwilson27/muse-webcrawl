The Wolfram Language is a general multi-paradigm programming language developed by Wolfram Research. It emphasizes symbolic computation, functional programming, and rule-based programming, and can employ arbitrary structures representing data, including formulas and images. It is the programming language of the mathematical symbolic computation program Mathematica.

The language was first released in 1988 as the language embedded in Mathematica, but it was only given its own name, the Wolfram Language, in 2013, as Wolfram Research moved to position it as a general-purpose system for technical computing, data science, and deployment across desktop, cloud, and embedded platforms such as the Raspberry Pi.

Design

In the Wolfram Language everything is represented as a symbolic expression, built from atoms and function applications in a uniform tree structure. The language contains several thousand built-in functions covering mathematics, statistics, machine learning, image processing, natural-language understanding, and curated real-world data through entities and the Wolfram Knowledgebase. Evaluation proceeds by applying transformation rules until expressions no longer change, combining symbolic rewriting with conventional procedural and functional constructs.

Implementations and deployment

The principal implementation is the Wolfram Engine, delivered with Mathematica and the Wolfram Cloud. A free Wolfram Engine for developers was released in 2019, and the language has been bundled on the Raspberry Pi since 2013. The related Wolfram|Alpha service uses the language and its curated knowledge to answer factual queries computationally.
