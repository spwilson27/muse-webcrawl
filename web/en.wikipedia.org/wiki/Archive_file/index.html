Archive file

An archive file is a computer file composed of one or more files along with metadata. Archive files are used to collect multiple data files together into a single file for easier portability and storage, or simply to compress files to use less storage space. Archives may also preserve directory structure, file attributes, permissions, and error-detection information such as checksums.

Purposes

Archives serve several purposes: bundling many files for convenient transfer (for example, software source-code distributions and email attachments), backup, and long-term preservation. Some formats combine archiving with data compression, so that the archive is smaller than the sum of its contents. Others, such as Unix tar, only aggregate files, leaving compression to an external tool like gzip or xz — the origin of the compound ".tar.gz" naming convention.

Common formats

The ZIP format, created by Phil Katz in 1989, is the most widely supported archive format, readable by all major operating systems. Other common formats include RAR, 7z, and ARJ; Unix and Linux environments favour tar variants and cpio, while disk-image formats such as ISO 9660 archive whole filesystems. Many application file formats — JAR, WAR, DOCX, and APK among them — are ZIP archives in disguise. Archive files typically store metadata including file names, timestamps, ownership, and a table of contents that allows individual members to be listed and extracted selectively.

Error handling and features

Robust formats add checksums (such as CRC-32) to detect corruption, and some add redundant recovery records so damaged archives can be partially repaired. Encryption, digital signatures, multi-volume spanning, and "solid" compression — in which files are compressed as a single stream for a better ratio at the cost of slower random access — are offered by several modern archivers.
