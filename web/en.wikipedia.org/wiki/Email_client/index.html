Email client

An email client, email reader or, more formally, message user agent (MUA) is a computer program used to access and manage a user's email. The term also covers web-based interfaces — webmail such as Gmail or Outlook.com — which perform the same role in a web browser.

TypeApplication software
FunctionComposing, sending, receiving, reading and organising email
Retrieval protocolsIMAP, POP3
Sending protocolSMTP
ExamplesMicrosoft Outlook, Mozilla Thunderbird, Apple Mail, Mutt, Gmail (webmail)

Operation

An email client connects to a mail server to retrieve messages, typically using the Internet Message Access Protocol (IMAP), which keeps messages on the server and synchronises them across devices, or the older Post Office Protocol (POP3), which downloads them to a single machine. Outgoing mail is submitted to a server using the Simple Mail Transfer Protocol (SMTP). Messages are formatted according to the Internet Message Format (RFC 5322 and its predecessors), with MIME extensions for attachments and non-text content.

Features

Modern clients typically provide address books, folders and rules for filing, full-text search, conversation threading, spam filtering (often in cooperation with server-side tools), support for multiple accounts, calendar and task integration, and encryption and signing through standards such as S/MIME and OpenPGP. Many also support push notifications and offline access.

History

Email predates the internet, originating on time-sharing systems in the 1960s; programs such as SNDMSG on TENEX allowed users of the same machine to exchange messages. With the ARPANET and later the internet, dedicated clients proliferated: Eudora (1988) popularised graphical email on personal computers; Microsoft Outlook (1997) became dominant in corporate environments; Mozilla Thunderbird (2004) provided a free, open-source alternative. The rise of webmail — Hotmail (1996), Yahoo! Mail and Gmail (2004) — moved the client into the browser, and the smartphone era made mobile mail apps such as Apple Mail ubiquitous.
