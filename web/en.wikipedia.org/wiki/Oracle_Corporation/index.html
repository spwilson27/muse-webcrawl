Oracle Corporation is an American multinational computer technology company headquartered in Austin, Texas. Founded in 1977 by Larry Ellison, Bob Miner and Ed Oates as Software Development Laboratories, it commercialised the relational database based on Edgar Codd's model and became the dominant database vendor for enterprises. Oracle later expanded by acquisition into business applications and, with Oracle Cloud Infrastructure, competes in cloud computing with Amazon Web Services and Microsoft Azure; co-founder Larry Ellison is among the world's wealthiest people.

History

Oracle's founders took inspiration from a CIA project codenamed "Oracle" and from IBM's System R research, releasing Oracle Version 2 in 1979, among the first commercial SQL relational database systems. A long series of acquisitions built the modern company: PeopleSoft (2005), Siebel (2006), BEA Systems (2008), Sun Microsystems (2010) — which brought the Java programming language and MySQL — NetSuite (2016) and the health-records company Cerner (2022), its largest deal at about $28 billion. Oracle moved its headquarters from Redwood Shores, California, to Austin in 2020.

Oracle was the plaintiff in Google LLC v. Oracle America, Inc., a long-running copyright dispute over the use of Java APIs in Android, decided for Google by the US Supreme Court in 2021 on fair-use grounds.

Products

Oracle Database remains the flagship product, alongside the Java platform, Oracle Fusion Cloud enterprise applications (ERP, human capital management, supply chain), NetSuite for mid-size companies, and Oracle Cloud Infrastructure, which in the mid-2020s won very large contracts to provide AI computing capacity.
