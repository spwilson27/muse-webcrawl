Harvard architecture

The Harvard architecture is a computer architecture with separate storage and signal pathways for instructions and data. It is named after the Harvard Mark I relay-based computer, which stored instructions on punched tape and data in electromechanical counters. The term contrasts with the von Neumann architecture, in which program instructions and data share the same memory and pathways.

Characteristics

Because instruction and data memories are physically separate, the processor can fetch an instruction and access data at the same time, and the two memories may have different word sizes, capacities and technologies. These properties make the design common in digital signal processors and microcontrollers, where predictable throughput matters more than a unified address space.

Modified Harvard architecture

Most modern general-purpose processors use a modified Harvard architecture: memory is unified at the main-memory level, but the CPU cache is split into separate instruction and data caches (the "split cache"), combining the speed advantages of separation with the flexibility of a single address space. Programs running on such machines generally cannot treat instructions as data at the cache level, though the underlying memory remains shared.

Comparison with von Neumann architecture

In a von Neumann machine, a single bus shared by instructions and data can become a bottleneck (the "von Neumann bottleneck"). The Harvard design removes that particular contention but complicates programming models that rely on self-modifying code or loading programs as data, which must be handled by special instructions in pure Harvard designs.
