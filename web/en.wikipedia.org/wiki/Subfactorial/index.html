Subfactorial

In mathematics, the subfactorial of a number n, written !n, is the number of derangements of a set of n elements — that is, the number of permutations in which no element appears in its original position. The first values are 0, 1, 2, 9, 44, 265 for n = 1, 2, 3, 4, 5, 6.

Definition

The subfactorial can be computed by the recurrence !n = (n − 1)(!(n − 1) + !(n − 2)), with !0 = 1 and !1 = 0, or by the inclusion–exclusion formula !n = n! · Σ (−1)k/k! for k = 0 to n. It is also the nearest integer to n!/e, where e is Euler's number.

Applications

The term "subfactorial" was coined by W. A. Whitworth. Derangements arise in the classic "hat-check problem": the probability that a random permutation of n hats returns none to its owner approaches 1/e as n grows.
