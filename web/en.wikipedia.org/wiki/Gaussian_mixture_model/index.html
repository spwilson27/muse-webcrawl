Gaussian mixture model

A Gaussian mixture model (GMM) is a probabilistic model that assumes all the data points are generated from a mixture of a finite number of Gaussian distributions with unknown parameters. One can think of mixture models as generalizing k-means clustering to incorporate information about the covariance structure of the data as well as the centers of the latent Gaussians.

Definition

A Gaussian mixture model is a weighted sum of K component Gaussian densities:

p(x) = Σₖ πₖ N(x | μₖ, Σₖ), with Σₖ πₖ = 1, πₖ ≥ 0

where μₖ is the mean and Σₖ the covariance matrix of component k, and πₖ is its mixing weight. The model is a standard approach for density estimation and for clustering in pattern recognition and machine learning.

Parameter estimation

Parameters are usually estimated by maximum likelihood using the expectation–maximization (EM) algorithm. In the expectation step, the algorithm computes the posterior probabilities ("responsibilities") of each component for each data point; in the maximization step, it updates the weights, means, and covariances using those responsibilities. The procedure is iterated until convergence, though it may reach only a local optimum.

Applications

  • Clustering and unsupervised learning
  • Speaker recognition and voice activity detection in speech processing
  • Image segmentation and background subtraction in computer vision
  • Anomaly detection and density estimation
  • Modelling of astronomical and biological data distributions

Relation to k-means

K-means clustering can be viewed as a limiting case of a Gaussian mixture model with equal, spherical covariances whose variance tends to zero; the GMM's "soft" assignments generalize k-means' hard assignments.

Model selection

The number of components K is usually chosen by criteria such as the Bayesian information criterion (BIC) or cross-validation. Bayesian nonparametric extensions, such as Dirichlet process mixture models, allow the number of components to be inferred from data.
