Interpolation

In the mathematical field of numerical analysis, interpolation is a type of estimation: a method of constructing new data points based on the range of a discrete set of known data points. It is often required in engineering and science to estimate the value of a function for an intermediate value of an independent variable, given a table of measured values.

Example

If a table gives the temperature at noon on successive days, interpolation estimates the temperature at, say, 2 p.m. from the surrounding values. By contrast, extrapolation estimates values outside the range of the known data and is generally more uncertain.

Methods

The simplest method is linear interpolation, which connects consecutive points with straight line segments; it was used in astronomical tables in antiquity but produces a curve whose derivative is discontinuous. Polynomial interpolation fits a single polynomial through all points, generalising the linear case; however, high-degree polynomials can oscillate wildly (Runge's phenomenon). Spline interpolation avoids this by using low-degree polynomials piecewise, yielding smooth curves. Other approaches include trigonometric interpolation and multivariate interpolation for data on grids or scattered points.

Applications

Interpolation is used in image scaling, digital signal processing, computer graphics, geographic information systems, and in filling gaps in experimental data.
