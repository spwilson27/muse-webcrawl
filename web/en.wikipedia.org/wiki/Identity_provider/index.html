Identity provider

An identity provider (IdP or IDP) is a system entity that creates, maintains, and manages identity information for principals and provides authentication services to relying applications (service providers) within a federation or distributed network.

Identity providers offer user authentication as a service — for example, a user may use a single set of credentials to sign in to many unrelated websites (single sign-on). The IdP checks the user's credentials and issues an assertion or token (such as a SAML assertion, an OpenID Connect ID token, or an OAuth access token) that the service provider trusts.

Relationship to service providers

In federated identity models, the identity provider is distinguished from the service provider (or relying party), which hosts the application the user wishes to access. Trust between the two is established by exchanging metadata and certificates in advance. Examples of identity providers include corporate directories accessed via LDAP, commercial services such as Microsoft Entra ID and Okta, and consumer login services offered by large platform companies.
