Magma (algebra)

TypeAlgebraic structure
DefinitionA set with a single closed binary operation
Also calledGroupoid (older usage)

In abstract algebra, a magma is the most basic kind of algebraic structure: a set equipped with a single binary operation that is closed, meaning that combining any two elements of the set always produces another element of the same set. No further axioms — such as associativity, commutativity, or the existence of an identity element — are required. The term was introduced by Nicolas Bourbaki; the older name "groupoid" is now mainly reserved for a different concept in category theory.

Special types

Magmas with additional properties form the base of the hierarchy of algebraic structures:

  • A quasigroup is a magma in which division is always possible (equations a·x = b and y·a = b have unique solutions).
  • A loop is a quasigroup with an identity element.
  • A semigroup is an associative magma.
  • A monoid is a semigroup with an identity element.
  • A group is a monoid in which every element has an inverse — equivalently, an associative loop.

Examples and morphisms

Everyday examples include the natural numbers under subtraction (a magma but not a semigroup, since subtraction is not associative), the set of rock–paper–scissors throws under the "beats" operation, and vector cross products. A morphism between magmas is a function preserving the operation, f(x·y) = f(x)·f(y); a bijective morphism is an isomorphism. The study of arbitrary magmas is closely tied to combinatorics: the number of distinct magma structures on small sets grows extremely rapidly, and universal algebra treats magmas as the archetypal "type (2)" algebra.
