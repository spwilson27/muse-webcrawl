The High-Level Shading Language (HLSL) is a proprietary shading language developed by Microsoft for use with the Direct3D API. It is analogous to the GLSL language used by OpenGL and Vulkan, but specific to the Microsoft platform. HLSL programs come in several forms: vertex shaders, pixel (fragment) shaders, geometry shaders, compute shaders, and, with DirectX Raytracing, ray tracing shaders.

History

HLSL was introduced with DirectX 9 in 2002, replacing hand-written assembly shaders. Microsoft developed it in collaboration with Nvidia, whose parallel Cg language shared much of its syntax. Later versions of the language added support for Shader Model 4.0 (DirectX 10), tessellation shaders (Shader Model 5.0, DirectX 11) and compute, and the open-source DirectX Shader Compiler (DXC), based on LLVM/Clang, which compiles HLSL to DXIL and, through SPIR-V output, enables use with Vulkan.

Language features

HLSL is syntactically similar to C, with built-in vector and matrix types (such as float4 and float4x4), swizzling and masking operators, intrinsic functions for common graphics operations, and semantics (such as SV_Position) that bind shader inputs and outputs to pipeline stages. Programs are compiled offline or at runtime into an intermediate bytecode.

float4 main(float4 pos : SV_POSITION) : SV_TARGET
{
    return float4(1.0f, 0.0f, 0.0f, 1.0f);
}
