David R. Fuchs

David R. Fuchs is an American computer scientist associated with the development of the Java programming language and platform at Sun Microsystems. He contributed to the early engineering of Java during the period in which it grew from an embedded-systems project into a mainstream software platform in the mid-1990s.

Fuchs worked on Java in its formative years at Sun Microsystems.

Work at Sun Microsystems

Fuchs was part of the engineering community at Sun that built and maintained the Java platform, working on core aspects of the language implementation and virtual machine technology as Java was applied first to interactive devices and then, from 1995, to web browsers and enterprise servers. The platform's "write once, run anywhere" model, garbage-collected runtime and bytecode-based virtual machine were central products of this effort.
