Call by reference

This article is about the parameter-passing strategy. For the evaluation strategy in functional programming, see Evaluation strategy.

Call by reference (or pass by reference) is an evaluation strategy in computer programming in which a function receives an implicit reference to a variable used as an argument, rather than a copy of its value. This means that modifications the function makes to the parameter are visible in the caller's variable, because the parameter and the argument are aliases for the same memory location. Call by reference is contrasted with call by value, in which the argument is an independent copy.

Semantics

Under call by reference, the address of the argument is passed implicitly. Assignments through the formal parameter write directly to the caller's storage:

procedure swap(ref x, ref y):
    temp := x
    x := y
    y := temp

a := 3; b := 4
swap(a, b)
// now a = 4, b = 3

Because the parameter aliases the argument, call by reference also allows a function to “return” several results by writing to multiple reference parameters, a pattern common in older procedural languages. A consequence is that programmers must be careful: it is not visible at the call site whether an argument may be modified, and aliasing can create subtle bugs.

Language support

Fortran passes arguments by reference by default. C achieves reference-like behaviour explicitly with pointers (passing the address by value), while C++ provides true reference types denoted with &. Pascal uses the var keyword, C# uses ref and out, and Visual Basic historically defaulted to ByRef. Languages such as Java and Python are sometimes loosely described as “pass by reference” for objects, but strictly they use call by sharing: references (object identities) are passed by value, so rebinding the parameter does not affect the caller, although mutating the shared object does.
