Telnet

From Wikipedia, the free encyclopedia
Telnet
PortTCP 23
First RFCRFC 97 (1971); standard RFC 854 (1983)
PurposeRemote terminal access (text-based)
[Image: Screenshot-style image of a terminal window showing a Telnet session login to a remote Unix system]

Telnet is a client/server application protocol that provides access to virtual terminals of remote systems on local area networks or the Internet. It was one of the first protocols of the ARPANET, developed from 1969 and standardised as RFC 854 in 1983, and for two decades it was the way to use a remote computer: a user at one machine logged into another across the network and worked in its command line as if sitting at its terminal.

Telnet's fatal flaw is that everything — including passwords — is transmitted in plaintext. On the trusting research network that was acceptable; on the commercial Internet it became untenable, and from the mid-1990s Telnet was displaced for remote administration by SSH, which encrypts the session. Telnet survives in niches: configuring legacy network equipment, testing whether a TCP port answers (the classic 'telnet host 25' mail-server check), and charming anachronisms such as BBSes and ASCII-art Star Wars screenings served over port 23.
