z/OS is a 64-bit operating system for IBM Z mainframe computers, produced by IBM. It derives from and is the successor to OS/390, which in turn followed a line of MVS releases dating back to OS/360 in the 1960s. z/OS is designed for large-scale enterprise computing, offering high throughput, reliability, availability and security for batch processing, transaction processing and mixed workloads.

Features

z/OS supports both traditional mainframe workloads — batch jobs written in JCL, transaction systems such as CICS and IMS, and databases such as Db2 — and modern environments including UNIX System Services, Java, and Linux-like containers through z/OS Container Extensions. Workload Manager (WLM) dynamically allocates system resources to meet performance goals. Parallel Sysplex clustering allows multiple systems to share data and present a single image with continuous availability.

History

IBM announced z/OS with the z900 systems in 2000, bringing 64-bit addressing to the mainframe operating system line. Successive releases (versioned as V1, then V2 from 2013, and V3 from 2023) added support for larger memory, improved analytics and AI integration, enhanced security and encryption, and cloud-style provisioning. Despite its age and proprietary nature, z/OS remains in wide use in banking, insurance, government and other sectors running mission-critical transaction systems.
