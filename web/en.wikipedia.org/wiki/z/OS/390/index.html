OS/390

From Wikipedia, the free encyclopedia

OS/390 is an IBM operating system for the System/390 (S/390) and IBM Z mainframe computers. It was introduced in 1995 as a bundled successor to MVS/ESA: instead of a bare operating system kernel with separately ordered components, OS/390 packaged MVS together with a large set of middleware — including UNIX System Services, TCP/IP, LAN server functions, and security and systems-management elements — tested and delivered as one product.

OS/390 retained full compatibility with MVS applications and data while adding an integrated POSIX/UNIX environment that let the mainframe host internet and open-systems workloads. Release 10, the last, supported the first 64-bit z/Architecture machines; in 2001 OS/390 was succeeded by z/OS, which continues the line today.
