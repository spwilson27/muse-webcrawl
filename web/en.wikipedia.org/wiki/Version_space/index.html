Version space

FieldMachine learning
Introduced byTom M. Mitchell (1977–1982)
BoundariesS (most specific), G (most general)

A version space is a concept in machine learning, introduced by Tom M. Mitchell, denoting the set of all hypotheses in a hypothesis space that are consistent with a given set of training examples — that is, every hypothesis that correctly classifies all the examples seen so far.

Boundary representation

Rather than enumerating the version space, Mitchell showed it can be represented compactly by two boundary sets: S, the set of maximally specific consistent hypotheses, and G, the set of maximally general consistent hypotheses, within a partial ordering of hypotheses from more specific to more general. Every hypothesis between the boundaries is in the version space.

Candidate elimination algorithm

The candidate-elimination algorithm maintains the S and G boundaries as examples arrive. A positive example causes over-specific hypotheses in S to be minimally generalised; a negative example causes over-general hypotheses in G to be minimally specialised. Learning has converged when the version space collapses to a single hypothesis, and the algorithm has failed (the version space "collapses") if the boundaries cross, meaning no hypothesis in the space is consistent with the data — for instance because of noise or an inadequate hypothesis language.
