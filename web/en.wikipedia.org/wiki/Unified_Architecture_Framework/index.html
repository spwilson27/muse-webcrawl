Unified Architecture Framework

From Wikipedia, the free encyclopedia

The Unified Architecture Framework (UAF) is an enterprise architecture framework published by the Object Management Group (OMG) for describing the architecture of enterprises, systems, and systems of systems, with roots in military architecture frameworks. It supersedes and generalises the earlier UPDM (Unified Profile for DoDAF and MODAF), bringing the U.S. Department of Defense Architecture Framework (DoDAF) and the British Ministry of Defence Architecture Framework (MODAF) — and concepts from NATO's Architecture Framework — into a single, commercially maintained metamodel not tied to any one nation's defence establishment.

Structure

UAF organises architecture descriptions into a grid: rows represent viewpoints or domains (such as strategic, operational, services, resources, personnel, security, projects, standards, and actual resources), while columns represent aspects of concern (taxonomy, structure, connectivity, processes, states, interaction, constraints, roadmap, traceability, and others). Cells of the grid define model kinds ("view specifications") that an architecture description may populate. The framework is implemented as a UML/SysML profile, so models can be exchanged between tools, and it defines a domain metamodel from which consistent views — capability maps, operational activity models, service specifications, resource structures, deployment schedules — are derived. UAF was adopted by the OMG in 2015–2017 (version 1.0) and continues to evolve; it is used by defence ministries but also by civilian enterprises for business and systems architecture.
