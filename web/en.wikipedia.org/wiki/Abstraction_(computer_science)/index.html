Abstraction (computer science)

In computer science, abstraction is the process of removing or generalizing physical, spatial, or temporal details or attributes in the study of objects or systems in order to focus attention on details of greater importance. It is similar in nature to the process of generalization; the creation of abstract concepts is related to abstraction in philosophy.

Abstraction is a fundamental concept in computer science, underpinning object-oriented programming, data types, and the layered architecture of modern computing systems, in which each layer hides the complexity of the layer below it.

Levels of abstraction

A computer system can be described at many levels. At the lowest level are transistors and logic gates; above these sit the instruction set architecture, then assembly language, then high-level programming languages, and finally applications. Each level provides an abstraction barrier: programmers at one level need not know the details of the levels below.

Data abstraction

Data abstraction refers to providing only essential information about data to the outside world, hiding background details. An abstract data type (ADT) such as a stack or a queue is defined by the operations it supports rather than by its implementation, so clients can use it without depending on how the data is stored.

Control abstraction

Control abstraction simplifies the expression of program flow. Structured programming constructs such as loops and conditionals abstract away machine-level jumps, while procedures and functions let a complex computation be named and reused as a single unit.
