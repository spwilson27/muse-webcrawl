Locality-sensitive hashing

Locality-sensitive hashing (LSH) is an algorithmic technique that hashes input items so that similar items map to the same "buckets" with high probability. Unlike cryptographic hashes, which aim to make outputs for slightly different inputs unrelated, LSH deliberately maximises collisions for similar inputs. It was introduced by Piotr Indyk and Rajeev Motwani in 1998 to give sub-linear-time approximate solutions to the nearest neighbour problem in high dimensions.

Definition

A family of hash functions is called (r, cr, p₁, p₂)-sensitive if points within distance r collide with probability at least p₁, while points farther than cr apart collide with probability at most p₂. By concatenating several functions and using several hash tables, the gap between p₁ and p₂ is amplified so that a query point retrieves mostly true near neighbours, which can then be checked exactly.

Hash families

  • Random projections (SimHash) for cosine similarity — the sign of the dot product with a random hyperplane.
  • MinHash for Jaccard similarity of sets.
  • Stable-distribution projections for Euclidean (Lp) distances.
  • Bit sampling for Hamming distance.

Applications

LSH is used in near-duplicate detection for web pages and documents, plagiarism detection, image and audio fingerprinting, genome sequence matching, and large-scale recommendation and search systems.
