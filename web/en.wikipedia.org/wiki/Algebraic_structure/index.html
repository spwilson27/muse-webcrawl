Algebraic structure

In universal algebra and abstract algebra, an algebraic structure is a set equipped with one or more finitary operations (and possibly distinguished constants) satisfying a specified list of axioms. Familiar examples include groups, rings, fields, vector spaces, and lattices.

Definition

Formally, an algebraic structure consists of a nonempty carrier set A, a collection of operations on A of finite arity, and a finite set of identities (equations) that those operations must satisfy. Structures with partial operations or underlying relational structure, such as ordered fields, go beyond the purely algebraic setting.

Examples by number of operations

  • One operation: magma, semigroup, monoid, group, abelian group.
  • Two operations: ring, field, lattice, Boolean algebra.
  • Operations plus scalar action: vector space, module, algebra over a field.

Classification

Algebraic structures form hierarchies: every field is a ring, every ring is an abelian group under addition, and so on. Universal algebra studies classes of structures (varieties) defined by identities, characterised by Birkhoff's HSP theorem, while category theory studies the structure-preserving maps (homomorphisms) between them.
