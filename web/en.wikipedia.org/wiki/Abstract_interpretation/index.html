Abstract interpretation

Abstract interpretation is a theory of sound approximation of the semantics of computer programs, developed by Patrick and Radhia Cousot in the late 1970s. Abstract interpretation is a partial execution of a computer program that gathers information about its semantics (such as control-flow and data-flow) without performing all the calculations.

Overview

The semantics of a program is expressed in a concrete domain, which typically involves sets of possible execution states that are too large or infinite to compute exactly. Abstract interpretation replaces this domain with an abstract domain that over-approximates it while remaining computable. The connection between the two domains is formalised by a Galois connection, which guarantees the soundness of the analysis: properties proved in the abstract domain hold in the concrete execution.

Applications

Abstract interpretation underlies many static program analyses used in compilers and verification tools, including interval analysis (determining possible ranges of variables), sign analysis, and detection of runtime errors such as buffer overflows and divisions by zero. The Astrée static analyser, built on abstract interpretation, has been used to prove the absence of runtime errors in safety-critical avionics software.
