Branch cut

In the mathematical field of complex analysis, a branch point of a multi-valued function is a point such that if the function is n-valued (or multi-valued) at that point, all of its values come together there in a cyclic manner, and the function is discontinuous when going around a small loop around it. Closely associated is the notion of a branch cut: a curve (usually) in the complex plane across which a chosen single-valued branch of the function is discontinuous.

Branch cuts

To define a single-valued branch of a multi-valued function such as √z or log z, one removes from the plane a curve — the branch cut — that connects branch points (or runs from a branch point to infinity). For the principal branch of the logarithm, the standard branch cut is the negative real axis, with the argument taken in (−π, π]. The choice of cut is a matter of convention; different cuts produce different branches agreeing on the overlap of their domains.

Examples

The origin is a branch point of the square-root function: circling 0 once interchanges the two values of √z. The functions log z, za for non-integer a, arcsin and arccos all require branch cuts. Riemann surfaces provide the natural setting in which multi-valued functions become single-valued: the branch cut corresponds to a choice of "gluing" sheets of the surface.
