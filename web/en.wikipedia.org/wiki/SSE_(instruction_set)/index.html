Streaming SIMD Extensions

In computing, Streaming SIMD Extensions (SSE) is a single instruction, multiple data (SIMD) instruction set extension to the x86 architecture, designed by Intel and introduced in 1999 in its Pentium III series of central processing units (CPUs) shortly after the appearance of Advanced Micro Devices (AMD's) 3DNow!. SSE contains 70 new instructions, most of which work on single precision floating-point data. SIMD instructions can greatly increase performance when exactly the same operations are to be performed on multiple data objects. Typical applications are digital signal processing and graphics processing.

SSE introduced eight new 128-bit registers (XMM0–XMM7) and a new MXCSR control and status register. SSE instructions operate on packed single-precision floating-point values, and also added integer instructions extending the MMX set. It was followed by SSE2 (2000), SSE3 (2004), SSSE3 (2006), SSE4 (2006), and the related Advanced Vector Extensions (AVX).

History

Intel introduced SSE in the Pentium III ("Katmai") in February 1999 in response to AMD's 3DNow!, which had shipped with the K6-2 in 1998. AMD adopted SSE support beginning with the Athlon XP processors. SSE2, introduced with the Pentium 4, extended the set to double-precision floating point and became a baseline requirement for x86-64 software.

Registers

SSE adds eight 128-bit XMM registers in 32-bit mode; in 64-bit mode, eight additional registers (XMM8–XMM15) are available. Each register holds four 32-bit single-precision floating-point values, two 64-bit double-precision values, or various packed integer quantities.
