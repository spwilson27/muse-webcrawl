Drools

Drools is a business rule management system (BRMS) with a forward and backward chaining inference-based rules engine, more correctly known as a production rule system, using an enhanced implementation of the Rete algorithm. It is open-source software released under the Apache License 2.0, written in Java, and managed as part of the KIE (Knowledge Is Everything) group sponsored by Red Hat.

Features

Drools allows business rules to be separated from application code and expressed in its own Drools Rule Language (DRL), in decision tables, or via graphical tooling. Components include Drools Workbench, Drools Expert (the rule engine), Drools Fusion for complex event processing, and OptaPlanner for planning optimisation, now continued as Timefold.

History

The project began in 2001 and joined the JBoss community in 2005. Modern versions align with the Decision Model and Notation (DMN) standard for decision modelling.
