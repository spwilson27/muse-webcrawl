Windows Presentation Foundation (WPF) is a free and open-source user interface framework for Microsoft Windows-based desktop applications. WPF, previously known as "Avalon", was initially released as part of .NET Framework 3.0 in 2006. WPF uses the Extensible Application Markup Language (XAML) to define and link various UI elements.

WPF employs DirectX and uses a vector-based rendering engine, allowing for resolution-independent graphics. It includes a comprehensive set of application-development features, including controls, data binding, layout, 2D and 3D graphics, animation, styles, templates, documents, media, text, and typography.

The architecture of Windows Presentation Foundation

Architecture

WPF's rendering capability is based on DirectX, specifically Direct3D, which allows the framework to take advantage of hardware acceleration on the graphics processing unit. The framework consists of two major components: the Engine and the Programming Framework. WPF applications are built from a combination of XAML markup, which describes the user interface declaratively, and code-behind written in a .NET language such as C# or Visual Basic.

Features

WPF provides a consistent programming model for building applications and provides a clear separation between the user interface and the business logic. It introduced data binding with the Model–View–ViewModel (MVVM) design pattern, in which the view model acts as an intermediary between the view and the model. Other features include templates for customizing the appearance of controls, a retained-mode graphics system, animation support, and rich text and document support based on the XML Paper Specification.

History

WPF was codenamed "Avalon" during development and was first shown at the Professional Developers Conference in 2003. It shipped with Windows Vista and .NET Framework 3.0 in November 2006. In 2018, Microsoft announced at its Build conference that WPF, along with Windows Forms and WinUI, would be open-sourced under the MIT License, and it became part of the .NET Core 3.0 release in 2019.
