Centered tetrahedral number

A centered tetrahedral number is a centered figurate number that represents a tetrahedron with a point in the center and all other points surrounding it in tetrahedral layers. The centered tetrahedral number for a specific number of layers n is given by the formula:

(2n + 1)(n² + n + 3) / 3

Sequence and properties

The first such numbers are 1, 5, 15, 35, 69, 121, 195, 295, 425, and 589. Each centered tetrahedral number is the sum of two consecutive (non-centered) tetrahedral numbers: for example, 15 = 10 + 5, and 35 = 20 + 15. This reflects a geometric construction in which the centered figure can be split into two ordinary tetrahedral stacks.

Interpretation

The number also counts the points in a three-dimensional lattice arrangement built around a central point, with the number of points growing roughly as (2/3)n³ for large n. Centered tetrahedral numbers appear in problems of sphere packing and crystal coordination, where a central atom is surrounded by successive shells.
