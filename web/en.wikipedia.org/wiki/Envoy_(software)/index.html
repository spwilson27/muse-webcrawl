Envoy (software)

From Wikipedia, the free encyclopedia

Envoy is a free and open-source edge and service proxy, designed for cloud-native applications. Originally built at Lyft, Envoy is a high-performance C++ distributed proxy designed for single services and applications, as well as a communication bus and "universal data plane" designed for large microservice "service mesh" architectures.

Features

Envoy runs alongside every application and abstracts the network by providing common features such as dynamic service discovery, load balancing, TLS termination, HTTP/2 and gRPC proxying, circuit breaking, health checks, staged rollouts, fault injection, and rich metrics. It supports the xDS APIs for dynamic configuration, allowing a control plane to manage large fleets of proxies.

History and governance

Created by Matt Klein and the engineering team at Lyft — where it powered more than 100 services — Envoy was open-sourced in September 2016 and donated to the Cloud Native Computing Foundation (CNCF) in 2017, graduating in 2018. It is the data-plane component of the Istio service mesh and is used by many organizations as an API gateway and ingress proxy.
