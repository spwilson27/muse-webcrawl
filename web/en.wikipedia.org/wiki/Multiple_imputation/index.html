Multiple imputation

Multiple imputation is a statistical method for handling missing data. Instead of filling in a single value for each missing observation, it creates several plausible complete datasets, analyses each one separately, and then combines the results so that the uncertainty about the missing values is properly reflected in the final estimates.

Method

The procedure, developed largely by Donald Rubin, generally proceeds in three phases: imputation, in which missing values are drawn multiple times (commonly five or more datasets) from a model for the data; analysis, in which each completed dataset is analysed using the method intended for complete data; and pooling, in which the estimates are combined using Rubin's rules, which average the estimates and adjust the total variance for both within-imputation and between-imputation variation.

Applications

Multiple imputation is widely used in survey research, clinical trials and the social sciences, and is implemented in software packages such as mice in R. It generally assumes data are missing at random.
