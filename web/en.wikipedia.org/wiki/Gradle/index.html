Gradle

Gradle is a build automation and multilingual software development tool. It manages tasks such as compilation, packaging, testing, deployment, and publishing. Gradle builds on the concepts of Apache Ant and Apache Maven and introduces a Groovy- and Kotlin-based domain-specific language (DSL) instead of the XML-based project configuration used by Maven.

Overview

Gradle uses a directed acyclic graph to decide the order in which tasks can be run, based on the dependencies between them. It runs on the Java Virtual Machine and is the official build tool for Android, through the Android Gradle Plugin maintained by Google. Gradle supports incremental builds, build caching, and parallel execution, and its plugin ecosystem extends it to languages including Java, Kotlin, Scala, Groovy, C++, and Swift.

History

The first versions of Gradle appeared in 2008, with Gradle 1.0 released in June 2012. Gradle Inc., founded by Hans Dockter and others, provides the Gradle Build Tool as open-source software under the Apache License 2.0, alongside commercial services such as Develocity (formerly Gradle Enterprise), a build analytics and acceleration platform.

Build scripts

Build scripts are written in Groovy or Kotlin DSL and declare projects, tasks, configurations, and dependencies, which Gradle resolves from repositories such as Maven Central. The Gradle Wrapper allows a project to pin a specific Gradle version so builds run consistently across machines.
