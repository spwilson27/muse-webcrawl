Exposed point

Image placeholder: A supporting hyperplane isolating an exposed point

In mathematics, an exposed point of a convex set is a point on the boundary at which a strictly supporting hyperplane touches the set only at that point. More precisely, let C be a convex subset of a vector space. A point x ∈ C is called an exposed point if there exists a continuous linear functional f such that f(x) > f(y) for every other point y ∈ C; that is, f attains its maximum over C uniquely at x.

Relation to extreme points

Every exposed point is an extreme point, but the converse does not hold in general: in three or more dimensions there exist convex sets having extreme points that are not exposed. In finite-dimensional spaces, the theorem of Straszewicz (1935) states that for a compact convex set, the exposed points are dense in the set of extreme points, so any extreme point can be approximated arbitrarily well by exposed points.

Exposed faces

The concept generalises to exposed faces: a face of a convex set that is the intersection of the set with a supporting hyperplane. Exposed points are precisely the zero-dimensional exposed faces.
