Selection sort

Selection sort is a simple in-place comparison sorting algorithm. It divides the input list into a sorted part at the front and an unsorted part at the back. Repeatedly, it finds the smallest (or largest) element in the unsorted part and swaps it into position at the end of the sorted part, until nothing remains unsorted.

Selection sort grows a sorted prefix by repeatedly selecting the minimum remaining element.

Algorithm

for i = 0 to n-2:
    minIndex = i
    for j = i+1 to n-1:
        if a[j] < a[minIndex]: minIndex = j
    swap a[i] and a[minIndex]

Analysis

Best caseO(n²)
Average caseO(n²)
Worst caseO(n²)
Extra spaceO(1)
StableNot in the standard form

Selection sort performs exactly n(n−1)/2 comparisons, but at most n−1 swaps — the minimum possible number of exchanges — which makes it useful where writing data is expensive but reading is cheap, such as flash memory with limited write cycles. Its quadratic time makes it impractical for large inputs; it is mainly of pedagogical interest and for tiny arrays. A variant using a heap data structure to find the minimum efficiently becomes heapsort. Another variant, double selection sort, selects both minimum and maximum on each pass.
