Platform (computing)

A computing platform, or digital platform, is the environment in which a piece of software is executed. It may be the hardware or the operating system, a web browser, an application programming interface (API), or other underlying software on which application programs run.

Components

A platform typically combines a hardware architecture (instruction set), an operating system, runtime libraries, and frameworks that define how programs are written, compiled, and executed. Examples of platforms at different levels include the x86 and ARM hardware architectures, operating systems such as Windows, Linux, Android, and iOS, the Java platform with its virtual machine, and web browsers as platforms for web applications.

Cross-platform software

Software described as cross-platform (or multi-platform) is implemented so that it runs on more than one platform, either by being written in a portable language and runtime, or by being compiled separately for each target. Platform providers also act as intermediaries between developers and users, as in app stores and cloud platforms.
