Kebab case

Kebab case is a naming convention in computer programming and web design in which words in a phrase are written in lowercase and separated by hyphens, like words threaded on a skewer — hence the humorous name, which likens the hyphens to a kebab skewer. Examples include kebab-case, my-file-name and background-color.

Usage

Kebab case is widely used in:

  • CSS — property names such as font-size and margin-top, and class naming conventions.
  • URLs and file names — web addresses and slugs, where lowercase hyphenated words are recommended for readability and search engines.
  • Lisp programming languages — identifiers such as define-function are conventionally written in kebab case.
  • Command-line flags — options such as --long-option.
  • HTML — attribute names and data attributes, e.g. data-user-id.

Variants of kebab case include "train case", in which each word is capitalised, and "screaming kebab case", which is all capitals. Some style guides discourage kebab case for program identifiers because the hyphen is parsed as a minus operator in most languages, which is why it is rare in variables in C-family languages but common in Lisp, CSS and URLs.
