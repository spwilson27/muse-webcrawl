Industrial control system (ICS)

Components: SCADA, DCS, PLCs, RTUs, HMIs

Used in: Power grids, water treatment, manufacturing, oil and gas

An industrial control system (ICS) is an electronic control system used to monitor and control industrial processes, including supervisory control and data acquisition (SCADA) systems, distributed control systems (DCS), and programmable logic controllers (PLCs).

Components

Typical architectures combine field devices and sensors, remote terminal units (RTUs) and PLCs that execute control logic, human–machine interfaces (HMIs) for operators, and supervisory software that gathers data across a plant or network.

Security

ICS security has become a major concern as control networks connect to corporate IT and the internet; the 2010 Stuxnet worm, which damaged Iranian centrifuges, demonstrated that malware could cause physical destruction through control systems.
