Just-in-time compilation

In computing, just-in-time (JIT) compilation is compilation done during execution of a program — at run time — rather than before execution. A JIT compiler translates bytecode or an intermediate representation into native machine code for frequently executed code, combining the portability of interpretation with speeds approaching ahead-of-time compilation.

Design

Modern JITs, as in the Java HotSpot virtual machine, .NET's RyuJIT, and JavaScript engines such as V8, use profiling to identify "hot" methods, apply optimisations such as inlining and escape analysis, and may deoptimise back to an interpreter when assumptions fail. Tracing JITs instead compile hot execution paths through loops. Drawbacks include startup latency and memory use.
