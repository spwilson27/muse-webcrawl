OpenGL (Open Graphics Library) is a cross-language, cross-platform application programming interface (API) for rendering 2D and 3D vector graphics. The API is typically used to interact with a graphics processing unit (GPU) to achieve hardware-accelerated rendering. It was developed by Silicon Graphics, Inc. (SGI), released in 1992, and is now managed by the non-profit Khronos Group.

Design

OpenGL is specified as an abstract state machine: applications set state (such as the current shader program, textures and buffers) and issue drawing commands whose output is written to a framebuffer. Since OpenGL 2.0, programmable shaders written in GLSL (the OpenGL Shading Language) control vertex transformation and fragment colouring; the older fixed-function pipeline was deprecated in version 3.0 and removed from the core profile in 3.2, the same release that added geometry shaders. Version 4.x added tessellation and compute-adjacent features.

Variants

OpenGL ES is a subset designed for embedded systems and mobile devices, and underlies graphics in most smartphones. WebGL exposes OpenGL ES to web browsers through JavaScript. Mesa 3D is a widely used open-source software implementation, and Apple's platforms deprecated OpenGL in favour of Metal. Khronos's newer Vulkan API provides lower-level, more explicit GPU control and is considered OpenGL's successor for high-performance applications, though OpenGL remains broadly supported, especially in CAD, scientific visualization and long-lived games.

History

OpenGL evolved from SGI's proprietary IRIS GL. The OpenGL Architecture Review Board oversaw the specification from 1992 until 2006, when control passed to Khronos. The release of version 3.0 in 2008, following the abandoned "Longs Peak" redesign, disappointed some developers, but 3.2's core/compatibility profiles stabilized the API. The final version, 4.6, was released in 2017.
