TrueType

TrueType glyphs are described by quadratic Bézier outlines

TrueType is an outline font standard developed by Apple in the late 1980s as a competitor to Adobe's Type 1 fonts used in PostScript. It became the most common format for fonts on the classic Mac OS, macOS and Microsoft Windows operating systems, and is still widely used, with files typically carrying the .ttf extension.

Technology

In TrueType, the outline of each glyph is described using quadratic Bézier curves (conic splines) defined by on-curve and off-curve control points, which require less computation to render than the cubic curves of Type 1 fonts. A distinguishing feature is its hinting system: fonts can embed bytecode instructions executed by a virtual machine inside the rasteriser, allowing precise control of pixel rendering at small sizes. TrueType Collection files (.ttc) package several fonts in one file.

History

Apple introduced TrueType with Macintosh System 7 in 1991 and licensed the technology to Microsoft, which built it into Windows 3.1. Apple and Microsoft later collaborated with Adobe on OpenType, a successor format that can contain either TrueType or PostScript-style (CFF) outlines and adds advanced typographic features.
