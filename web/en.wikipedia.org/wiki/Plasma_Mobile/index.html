Plasma Mobile

Developer: KDE community

Operating system: Linux

Plasma Mobile is a free and open-source mobile user interface developed by the KDE community, based on the KDE Plasma desktop technology stack and the Kirigami UI framework. It is designed for smartphones and tablets running Linux.

Features

Plasma Mobile provides a touch-oriented shell with a swipeable app drawer, quick settings, and an application ecosystem built largely with Kirigami and Qt. Its phone functions rely on components such as ModemManager and oFono for telephony. It ships as the default interface on several community Linux mobile distributions and devices, including postmarketOS images and the PinePhone, and it supports convergence, adapting its layout when connected to an external display.

History

The project was announced in 2015 as a fully open, community-developed alternative to the dominant proprietary mobile platforms. Development since has proceeded through the KDE Plasma Mobile Gear application releases and integration with the Plasma 6 generation of the desktop.
