Event Viewer is a component of Microsoft's Windows NT line of operating systems that lets administrators and users view the event logs on a local or remote machine. It provides access to logs maintained by the Windows Event Log service, which records application, security, setup, and system events.

Overview

Applications and operating-system components use event logging to record significant occurrences, such as errors, warnings, and informational events. In Windows Vista and later, the event log was redesigned around XML, and Event Viewer gained a redesigned interface with channels, tasks, subscriptions, and the ability to forward events between computers.

Log categories

The principal Windows logs are Application, Security, Setup, System, and Forwarded Events. The Security log records logon attempts and resource access when auditing is enabled. Administrative events combine critical, error, and warning events from across logs for troubleshooting.

Usage

Event Viewer can be launched via the Microsoft Management Console snap-in eventvwr.msc. Events carry an ID, level, source, and timestamp, and administrators can attach tasks to specific events, filter views, and export logs in EVTX format.
