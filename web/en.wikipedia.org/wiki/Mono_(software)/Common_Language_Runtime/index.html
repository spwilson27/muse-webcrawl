Common Language Runtime

The Common Language Runtime (CLR) is the virtual machine component of Microsoft's .NET Framework and .NET platforms, and is responsible for managing the execution of .NET programs. Programs written for the CLR are compiled to Common Intermediate Language (CIL) bytecode, which the runtime's just-in-time (JIT) compiler translates into native machine code at execution time.

Services

The CLR provides core services including memory management through automatic garbage collection, type safety verification, exception handling, thread management, and security enforcement. Because all .NET languages compile to the same intermediate language and share the Common Type System, components written in C#, F#, Visual Basic, and other languages can interoperate seamlessly. The runtime also supports metadata-driven features such as reflection and attributes.

Implementations

The original CLR shipped with the .NET Framework on Windows. The open-source CoreCLR is the runtime of modern .NET, running on Windows, Linux, and macOS. The Mono project developed an independent compatible runtime used historically for cross-platform, mobile (via Xamarin), and embedded scenarios, including a full ahead-of-time compilation mode and a compacting garbage collector.
