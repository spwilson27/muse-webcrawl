C Sharp (programming language)

ParadigmMulti-paradigm: object-oriented, functional, generic
Designed byMicrosoft; Anders Hejlsberg
First appeared2000
Typing disciplineStatic, strong, safe

C# (pronounced "C sharp") is a general-purpose, high-level, multi-paradigm programming language developed by Microsoft as part of its .NET initiative and first released in 2000. Designed by a team led by Anders Hejlsberg, C# combines the computing power of C++ with the programming ease of Visual Basic, and draws on features of Java, Delphi, and other languages. The name derives from the musical sharp symbol, denoting a note a semitone higher.

Features

C# is a statically typed, object-oriented language in which all types derive from a common root. Programs are compiled to Common Intermediate Language (CIL) and run on the Common Language Runtime (CLR), which provides garbage collection, type safety, and exception handling. Over successive versions the language has gained generics, lambda expressions and LINQ, dynamic typing, async/await for asynchronous programming, pattern matching, records, and nullable reference types, among many other features.

Uses

C# is widely used for enterprise applications, web services with ASP.NET, desktop applications, and game development with the Unity engine, where it is the principal scripting language. The open-source Roslyn compiler platform exposes the compiler as an API, enabling analysis and code-generation tools.
