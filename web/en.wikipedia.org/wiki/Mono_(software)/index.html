Mono is a free and open-source software framework that aims to allow developers to create cross-platform applications by implementing Microsoft's .NET Framework based on the ECMA standards for C# and the Common Language Runtime. Sponsored originally by Ximian and later Novell and Xamarin, the project provides a Common Language Infrastructure (CLI) runtime, compilers for C# and other .NET languages, and class libraries compatible with .NET.

History

The project was announced by Miguel de Icaza in 2001 and first released in 2004. Mono enabled .NET applications to run on Linux, macOS and other Unix-like systems. Xamarin built commercial products on Mono for iOS and Android development (Xamarin.iOS and Xamarin.Android); Microsoft acquired Xamarin in 2016 and relicensed Mono under permissive terms. With the advent of the unified, cross-platform .NET (formerly .NET Core), Mono's role shifted largely to mobile, WebAssembly and embedded scenarios; in 2024 Microsoft transferred stewardship of Mono to WineHQ.

Components

  • Runtime: a just-in-time and ahead-of-time compiling virtual machine executing Common Intermediate Language code, with a garbage collector.
  • Compilers: the C# compiler (mcs) and tools for other CLI languages.
  • Class libraries: implementations of the Base Class Library and APIs such as Windows Forms, ASP.NET and ADO.NET subsets, plus Mono-specific libraries like Gtk# for the GNOME toolkit.

Uses

Mono underpins the Unity game engine's scripting runtime, many cross-platform desktop applications, and embedded .NET deployments.
