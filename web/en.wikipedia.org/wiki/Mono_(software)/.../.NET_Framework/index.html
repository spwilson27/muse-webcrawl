.NET Framework (Mono)

The .NET Framework is a software framework developed by Microsoft that runs primarily on Microsoft Windows. The Mono project provides an open-source, cross-platform implementation of the .NET Framework's core components — most importantly the Common Language Runtime (CLR) and the Base Class Library — so that applications written for .NET can run on Linux, macOS, and other operating systems.

Overview

The .NET Framework consists of the Common Language Runtime, which executes programs compiled to Common Intermediate Language (CIL), and a large class library providing user interface, data access, database connectivity, cryptography, and network communications. Programs written in languages such as C#, F#, and Visual Basic .NET compile to CIL assemblies (PE files with the .exe or .dll extension) that any compliant runtime can execute.

Mono's implementation

Mono, sponsored by Novell and later Xamarin and Microsoft, re-implements the CLR (the mono runtime, itself written in C) together with class libraries compatible with the .NET Framework up to roughly version 4.7. It includes a just-in-time compiler, ahead-of-time compilation support, a garbage collector (SGen), and bindings for platform APIs. Mono powers Xamarin's mobile tools, the Unity game engine's scripting layer, and numerous Linux desktop applications such as Banshee and F-Spot.

Relationship to .NET Core and modern .NET

In 2016 Microsoft released .NET Core, a modular cross-platform successor to the .NET Framework. With the release of .NET 5 in 2020, the "Core" branding was dropped and the unified ".NET" platform became the mainline. Mono continues to be maintained as a runtime for platforms the mainline .NET does not reach (such as certain game consoles and WebAssembly targets) and remains the basis of Xamarin workloads, which were folded into .NET MAUI.
