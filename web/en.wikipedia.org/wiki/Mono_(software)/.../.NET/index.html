Mono is a free and open-source implementation of Microsoft's .NET framework, based on the ECMA standards for C# and the Common Language Infrastructure (CLI). Within the Mono project, ".NET" refers to the platform Mono implements: the Common Language Runtime virtual machine, the C# compiler, and the class libraries compatible with Microsoft's .NET Framework, allowing .NET applications and assemblies to run on Linux, macOS, and other operating systems besides Windows.

Mono reimplements the .NET runtime and libraries for cross-platform use.

Relationship between Mono and .NET

When Microsoft released .NET in 2002, its runtime and tools were essentially Windows-only. Miguel de Icaza and the Ximian company launched Mono in 2001 to bring .NET development to Linux, attracted by the productivity of the C# language, the CLI's language interoperability, and the ECMA standardisation of the core technologies. Mono implements:

  • The Common Language Runtime, executing Common Intermediate Language (CIL) bytecode with just-in-time and ahead-of-time compilation and a generational garbage collector.
  • The Base Class Library and large parts of the .NET Framework API — including ADO.NET, ASP.NET (Web Forms and MVC variants), Windows Forms, LINQ, and XML libraries — plus C# and Visual Basic compilers.
  • Mono-specific APIs, such as Gtk# for native Linux desktop applications, POSIX bindings (Mono.Unix), and bindings to macOS (Xamarin.Mac) and mobile platforms.

History and adoption

Mono 1.0 was released on 30 June 2004. Sponsored by Ximian, then Novell, Attachmate, and from 2011 by Xamarin (founded by de Icaza after the Attachmate layoffs), the runtime became the basis of Xamarin's tools for building iOS and Android applications in C#. Microsoft acquired Xamarin in 2016, relicensed Mono under the MIT License, and progressively converged Mono with its own open-source .NET (formerly .NET Core): the modern .NET runtime incorporates Mono's runtime for mobile and WebAssembly workloads, and since 2024 the Mono project's stewardship has been transferred to the Wine community. Applications built with Mono include the Unity game engine's scripting environment, the GNOME applications Banshee and F-Spot, and many cross-platform games and embedded systems.

Patent concerns

Because .NET originated with Microsoft, Mono's legality was debated for years: only the ECMA-standardised portions (C# and the CLI) were covered by Microsoft's Community Promise, while parts of the broader .NET Framework stack, such as ASP.NET and Windows Forms, were originally not. These concerns diminished after Microsoft released .NET Core as open source in 2014 and adopted more permissive patent pledges.
