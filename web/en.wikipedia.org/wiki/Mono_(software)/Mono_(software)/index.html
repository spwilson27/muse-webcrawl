Mono (software)

Mono
Developer: .NET Foundation and contributors
Initial release: June 30, 2004
Written in: C, C#, XML
Operating system: Cross-platform
Type: Software framework
License: MIT and others

Mono is a free and open-source software framework that aims to run software written for the .NET Framework on Unix-like operating systems and other platforms. Sponsored originally by Ximian and later by Novell and Xamarin, Mono is an implementation of Microsoft's Common Language Infrastructure (CLI) and Common Language Specifications, based on the ECMA standards for C# and the Common Language Runtime.

The Mono project provides an open-source implementation of the .NET framework

History

The Mono project was announced by Miguel de Icaza of Ximian in 2001, motivated by a desire to bring the productivity benefits of modern programming languages and component software to Linux developers. The first version, Mono 1.0, was released on June 30, 2004. After Novell acquired Ximian, development continued under Novell; following Novell's acquisition by Attachmate and subsequent layoffs, de Icaza founded Xamarin in 2011 to continue Mono and related mobile tooling. Microsoft acquired Xamarin in 2016, relicensed Mono under the MIT License, and transferred stewardship to the .NET Foundation.

Components

Mono consists of a C# compiler, a runtime implementing the ECMA Common Language Infrastructure including a just-in-time compiler and garbage collector, and a set of class libraries compatible with those of the .NET Framework. It also includes development tools and bindings to popular Unix libraries. Mono supports languages such as C# and F#, and can run applications written in other CLI languages.

Uses

Mono has been used to build cross-platform desktop applications for Linux and macOS, server software, and, notably, video games: the Unity game engine historically used Mono to run C# scripts across platforms. Xamarin's products built on Mono allowed developers to write native Android and iOS applications in C#. With the advent of the cross-platform .NET (formerly .NET Core), Mono's role shifted toward mobile and embedded scenarios, and its runtime has been incorporated into modern .NET workloads.

Licensing and patents

Early in its history, Mono attracted debate over Microsoft's software patents on .NET technologies. Mono's components were dual-licensed and its core was available under free software licenses; Microsoft later made patent promises covering the ECMA-standardized specifications, and its acquisition of Xamarin removed much of the uncertainty.
