.NET Core

.NET Core is a free and open-source, managed computer software framework for Windows, Linux, and macOS operating systems. It is a cross-platform successor to the .NET Framework, developed by Microsoft and the .NET community on GitHub. First released in June 2016, .NET Core introduced a modular, high-performance implementation of the .NET standard libraries and runtime that could be deployed alongside applications.

History and unification

Microsoft announced .NET Core in November 2014 as part of a shift toward open-source development. Successive versions added APIs and performance improvements; with version 5.0 in November 2020, the "Core" branding was dropped and the product was renamed simply ".NET", unifying the .NET Framework and .NET Core lines into a single platform. Annual releases have followed, alternating between standard-term and long-term support versions.

Features

The platform supports C#, F#, and Visual Basic, and comprises the CoreCLR runtime, the CoreFX libraries, the ASP.NET Core web framework, and the Entity Framework Core data-access library. Applications can be built for console, web, cloud, and, through related workloads, desktop and mobile targets. The runtime's just-in-time compiler (RyuJIT) and optional ahead-of-time compilation are central to its performance focus.

Relation to Mono

The Mono project, an independent open-source implementation of .NET, historically ran where the official framework could not; parts of Mono's runtime have been incorporated into the modern .NET platform, particularly for mobile and WebAssembly workloads.
