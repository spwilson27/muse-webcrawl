Middleware

Middleware
Type: Software layer
Role: Connects applications and services
Examples: Message brokers, API gateways, ORBs

Middleware is computer software that provides services to software applications beyond those available from the operating system, acting as a bridge between applications, databases and networks. It is often described as "software glue".

Types

Major categories include message-oriented middleware (such as message brokers like RabbitMQ and Apache Kafka), remote procedure call frameworks, object request brokers (CORBA), database middleware, transaction monitors, and web middleware layers in frameworks such as Express or Django that process requests between the server and application code. Application servers and enterprise service buses combine several of these roles.

Purpose

Middleware lets developers build distributed systems without handling low-level details of networking, data formats, security and transactions for every component, promoting interoperability between heterogeneous systems.
