Microsoft Windows

From Wikipedia, the free encyclopedia
[Image: A Windows desktop with its blue wallpaper and Start menu open]

Microsoft Windows is a proprietary graphical operating system developed and marketed by Microsoft. Since its first release in 1985 as a shell for MS-DOS, Windows has been the dominant desktop operating system worldwide, with a market share around 70% in recent years.

Major versions include Windows 95 (which introduced the Start menu and taskbar), Windows XP (2001), Windows 7 (2009), Windows 10 (2015), and Windows 11 (2021). The modern line descends from Windows NT (1993), a from-scratch kernel design led by Dave Cutler.

History

Windows 3.0 (1990) achieved mass success; Windows 95 unified the consumer line and drove home PC adoption, bundling Internet Explorer — central to the US antitrust case against Microsoft (1998–2001). Windows XP merged consumer and NT lines and became one of the longest-lived releases.

Windows 8 (2012), optimised for touch, was poorly received on desktops; Windows 10 moved to a regularly updated 'Windows as a service' model, and Windows 11 tightened hardware requirements (TPM 2.0).

Role

Windows dominates business desktops and PC gaming and is a major platform for enterprise software; server variants (Windows Server) and the Azure cloud extend Microsoft's ecosystem. Criticisms historically targeted security vulnerabilities, though the platform's openness to hardware variety is also its strength.
