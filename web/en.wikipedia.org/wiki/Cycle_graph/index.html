Cycle graph

Cycle graphs on 3 to 8 vertices.

In graph theory, a cycle graph or circular graph is a graph that consists of a single cycle, or in other words, some number of vertices (at least 3, if the graph is simple) connected in a closed chain. The cycle graph with n vertices is denoted Cn. Every vertex in a cycle graph has degree 2, and the graph has n edges.

Properties

Cycle graphs are connected, 2-regular, and Eulerian and Hamiltonian. A cycle graph is bipartite if and only if n is even, and its chromatic number is 2 for even cycles and 3 for odd cycles. Cycle graphs are a standard example in extremal and structural graph theory, and they form the polynomial ring structures known in chemistry as cycloalkanes.

Directed cycle graph

A directed cycle graph is the directed version of a cycle graph in which all edges are oriented consistently around the ring; every vertex has indegree and outdegree 1. Directed cycle graphs appear in the study of state machines, Markov chains, and feedback systems.
