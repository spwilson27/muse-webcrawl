OpenDocument

Developed by: OASIS

Initial release: 2005

Type of format: Document file format

Container for: XML files in a ZIP archive

Standard: ISO/IEC 26300

The Open Document Format for Office Applications (ODF), also known as OpenDocument, is an open file format for word processing documents, spreadsheets, presentations and graphics, using ZIP-compressed XML files. It was developed with the aim of providing an open, XML-based file format specification for office applications.

The standard is developed and maintained by the OASIS industry consortium. It was based on the Sun Microsystems specification for OpenOffice.org XML, the default format for OpenOffice.org and LibreOffice. It was originally developed for StarOffice "to provide an open standard for office documents."

File types

The most common filename extensions used for OpenDocument documents are:

  • .odt — word processing (text) documents
  • .ods — spreadsheets
  • .odp — presentations
  • .odg — graphics and drawings
  • .odf — formulae and mathematical equations
  • .odb — databases

An OpenDocument file is a ZIP archive containing XML files for content, styles, metadata, and application settings, together with embedded media. The META-INF/manifest.xml file lists the archive's contents.

Standardization

OASIS approved OpenDocument as an OASIS Standard on 1 May 2005. It was subsequently submitted to ISO and published as ISO/IEC 26300 in 2006, making it the first office document format to become an ISO standard developed by an independent consortium. Version 1.2 was approved by OASIS in 2011 and published as an ISO standard in 2015; version 1.3 followed in 2020.

Adoption

OpenDocument is the native format of LibreOffice, Apache OpenOffice, Collabora Online, Calligra Suite, and many other applications. Microsoft Office has supported ODF since Office 2007 SP2. Numerous national governments, including several in Europe, have adopted ODF as a standard for document exchange, and the United Kingdom selected ODF in 2014 as the standard for editable documents in government.

The format's standardization proceeded in parallel with that of Microsoft's Office Open XML (ISO/IEC 29500), leading to longstanding debate over competing document-format standards.
