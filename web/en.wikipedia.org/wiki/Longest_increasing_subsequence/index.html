Longest increasing subsequence

Longest increasing subsequence
FieldCombinatorics, computer science
Classic algorithmPatience sorting, O(n log n)
Key resultErdős–Szekeres theorem

In computer science and combinatorics, the longest increasing subsequence problem is to find a subsequence of a given sequence in which the elements are in sorted order, lowest to highest, and the subsequence is as long as possible. This subsequence is not necessarily contiguous or unique.

Algorithms

The problem can be solved by dynamic programming in O(n2) time, where each subproblem computes the length of the longest increasing subsequence ending at a given element. A more efficient O(n log n) algorithm uses the method of patience sorting: elements are dealt onto piles, and the number of piles equals the length of the longest increasing subsequence, with binary search used to place each card.

Related results

The Erdős–Szekeres theorem guarantees that any sequence of (r−1)(s−1)+1 distinct numbers contains an increasing subsequence of length r or a decreasing subsequence of length s. By Dilworth's decomposition and Mirsky's theorem, the length of the longest increasing subsequence relates to partitions of the sequence into decreasing subsequences. The expected length of the longest increasing subsequence of a random permutation of n elements grows like 2√n (the Ulam–Hammersley problem), a result central to work on random matrices and the Tracy–Widom distribution.
