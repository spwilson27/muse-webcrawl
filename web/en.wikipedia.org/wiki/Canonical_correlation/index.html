Canonical correlation

Image placeholder — two sets of variables related through canonical variates

Canonical correlation analysis (CCA), also called canonical variates analysis, is a way of inferring information from cross-covariance matrices. Given two sets of variables, CCA finds linear combinations of the variables in each set — canonical variates — that have maximum correlation with each other. It was introduced by Harold Hotelling in 1936.

Definition

Given two column vectors of random variables with finite second moments, CCA seeks weight vectors a and b maximising the correlation between the linear combinations a′X and b′Y:

ρ = maxa,b corr(a′X, b′Y)

Successive pairs of canonical variates are found subject to being uncorrelated with the previous pairs. The solution reduces to eigenvalue problems involving the within-set and between-set covariance matrices.

Relation to other methods

CCA generalises several classical techniques: when one set contains a single variable it corresponds to multiple regression, and it is related to principal component analysis, factor analysis and linear discriminant analysis. Regularised and kernel variants are used in machine learning, for example for multi-view learning and for relating neural recordings to stimuli in neuroscience.
