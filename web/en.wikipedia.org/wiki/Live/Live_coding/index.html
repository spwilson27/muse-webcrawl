Live coding

Live coding, sometimes referred to as on-the-fly programming, just in time programming and conversational programming, makes programming an integral part of the running program. It is most prominent as a performing arts form and a creativity technique centred upon the writing of source code and the use of interactive programming in an improvised way, usually to create sound or image, but also in other fields such as interactive installations and education.

A live coder performing with projected source code

History

Live coding emerged in the early 2000s from practices in electronic music and software art. The TOPLAP collective (Temporary Organisation for the Promotion of Live Algorithm Programming), founded in 2004, promoted the slogan "show us your screens" — performers project their code so the audience can see the programming as it happens. Environments such as SuperCollider, ChucK, Max, Pure Data, and later Sonic Pi, TidalCycles, FoxDot, and Hydra (for visuals) made real-time code evaluation practical on stage.

Techniques

A live-coding environment evaluates code while the program runs, allowing performers to add, remove, and transform musical patterns, synthesis processes, or visual shaders without stopping. Pattern languages such as TidalCycles represent musical structure as cyclic patterns that can be layered and transformed with combinators, making the code itself a musical score that is edited in performance.

Algorave

Live coding is closely associated with the algorave movement — events at which music and visuals generated from algorithms, often written live, are performed for dancing audiences. Algoraves have spread from the UK to a worldwide network of events, festivals, and streamed performances.

Education and research

Systems such as Sonic Pi were designed for teaching programming through music in schools. In research, live coding informs studies of human–computer interaction, liveness in programming languages, and improvisation; the annual International Conference on Live Coding (ICLC), first held in 2015, is the field's main academic venue.
