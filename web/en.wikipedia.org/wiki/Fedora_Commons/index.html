Fedora Commons

Fedora (or Fedora Commons; backronym for Flexible Extensible Digital Object Repository Architecture) is a digital asset management system and repository software used by libraries, archives, museums and research institutions to store, manage and provide access to digital content. It provides a robust, flexible core repository platform — content modelling, relationships between objects, and versioning — upon which applications such as Islandora, Samvera and the former Hydra stack are built.

History

Fedora originated in research at Cornell University in the late 1990s by Sandra Payette and Carl Lagoze, with later development in collaboration with the University of Virginia. The Fedora Commons non-profit organisation was formed in 2007 to support the growing user community; it merged with the DSpace Foundation in 2009 to form DuraSpace, which in turn merged into LYRASIS in 2019. The modern Fedora 6, released in 2021, is built around the Oxford Common File Layout (OCFL) for long-term preservation of content on disk.

Architecture

Fedora exposes a REST-based API in which digital objects are organised hierarchically and described with properties and relationships; since version 4 it has implemented the Linked Data Platform recommendations. Institutions use it to manage millions of objects, from journal articles and theses to images, audio and research datasets.
