Qubes OS

DeveloperQubes team (Invisible Things Lab)
Initial release2012
Platformx86-64
LicenseGPL and others (free software)
VirtualizationXen hypervisor

Qubes OS is a security-focused desktop operating system that aims to provide security through isolation, a principle its developers call "security by compartmentalization". It uses the Xen hypervisor to run multiple virtual machines ("qubes"), each dedicated to a separate security domain — for example, work, personal, banking, and untrusted browsing — so that a compromise of one domain does not endanger the others.

Design

Each qube runs its own guest operating system based on templates (such as Fedora or Debian, and optionally Whonix for Tor integration). Window borders are color-coded by domain trust level. Networking and USB devices are handled by dedicated service VMs, and an administrative domain (dom0) has no direct network access. Features include disposable VMs, split GPG and split Bitcoin setups, and secure copy-and-paste between domains under user control.

History

Qubes OS was created by Joanna Rutkowska and the Invisible Things Lab team, with the first release in 2012. It is recommended by privacy advocates and has been praised by Edward Snowden. Development is supported by the open-source community and commercial backers.
