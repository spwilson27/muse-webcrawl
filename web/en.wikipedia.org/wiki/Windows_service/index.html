Windows service

In Microsoft Windows operating systems, a Windows service is a computer program that operates in the background. It is similar in concept to a Unix daemon. A Windows service must conform to the interface rules and protocols of the Service Control Manager, the component responsible for managing Windows services. It is the Services and Controller app, services.exe, that launches all the services and manages their actions, such as start, end, etc.

Windows services can be configured to start when the operating system is started and run in the background as long as Windows is running. Alternatively, they can be started manually or by an event. Windows services usually run under the system account, a specially-configured user account, or the user's own account.

The Services management console in Windows

Administration

Administrators can manage services through the Services snap-in of the Microsoft Management Console, the sc.exe command-line tool, Windows PowerShell cmdlets such as Start-Service and Stop-Service, or the Task Manager in newer versions of Windows. Installation and management of services can also be performed programmatically through the Windows API.

Development

A service is created by developing a program in a language such as C, C++, or a .NET language that implements the service control handler functions and registers them with the Service Control Manager. In the .NET Framework, the ServiceBase class provides the base implementation. Services typically have no user interface and cannot be run directly by double-clicking their executable; they must be installed and started by the Service Control Manager.
