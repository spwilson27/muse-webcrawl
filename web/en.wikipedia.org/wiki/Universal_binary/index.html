Universal binary

A universal binary is, in Apple parlance, an executable file or application bundle that runs natively on more than one hardware architecture of Macintosh computer. The concept entered wide use with Apple's transition from PowerPC to Intel processors, announced in 2005: a universal binary contains both PowerPC and x86 machine code in a single "fat" file, and the operating system launches the appropriate version automatically.

Background

The underlying mechanism is the Mach-O "fat binary" format, which dates to NeXTSTEP and was also used during Apple's earlier transition from 68k to PowerPC processors in the 1990s. The alternative to universal binaries was emulation: Apple's Rosetta layer translated PowerPC code to run on Intel Macs, at a performance cost.

Universal 2

With the transition to Apple silicon announced in 2020, Apple introduced Universal 2, a variant containing x86-64 and ARM64 code in one binary, so applications could run natively on both Intel Macs and Macs with M-series chips, with Rosetta 2 providing translation for Intel-only apps.
