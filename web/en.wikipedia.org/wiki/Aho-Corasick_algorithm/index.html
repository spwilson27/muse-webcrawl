Aho–Corasick algorithm

In computer science, the Aho–Corasick algorithm is a string-searching algorithm invented by Alfred V. Aho and Margaret J. Corasick of Bell Labs in 1975. It is a kind of dictionary-matching algorithm that locates elements of a finite set of strings (the "dictionary") within an input text. It matches all strings of the set simultaneously, generalising the single-pattern Knuth–Morris–Pratt algorithm to many patterns.

Description

The algorithm first constructs a finite-state machine resembling a trie of the dictionary patterns, augmented with failure links: for each state, a pointer to the state representing the longest proper suffix of the current string that is also a prefix of some pattern. Output links record which patterns end at each state (or are reachable via suffix links). The text is then processed in a single left-to-right pass; on each character the machine follows transitions or failure links, and every time an output state is reached, a match of the corresponding pattern is reported.

Complexity

Building the automaton takes time proportional to the total length of the patterns, and scanning takes time linear in the length of the text plus the number of matches found — formally O(n + m + z), where n is the text length, m the total pattern length, and z the number of matches. This contrasts with running a single-pattern search once per dictionary word and makes Aho–Corasick the standard approach for matching large keyword sets.

Applications

The algorithm is used in intrusion detection systems (the Snort network IDS originally used it for signature matching), antivirus and malware scanning, text filtering, bibliographic search (its original application was a bibliographic search system), bioinformatics motif search, and spell-checking and full-text search libraries.
