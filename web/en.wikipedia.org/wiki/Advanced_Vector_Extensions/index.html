Advanced Vector Extensions

Image placeholder: AVX register layout

Advanced Vector Extensions (AVX) are a set of SIMD extensions to the x86 instruction set architecture first proposed by Intel in March 2008 and first supported in processors in 2011 — Intel's Sandy Bridge and AMD's Bulldozer families. AVX widened the vector registers from 128 bits (XMM) to 256 bits (YMM) and introduced a new three-operand instruction encoding, the VEX prefix.

Introduced: 2011 (Sandy Bridge / Bulldozer)
Register width: 256 bits (YMM)
Successors: AVX2, AVX-512, AVX10

Features

AVX instructions operate on 256-bit vectors of floating-point numbers, doubling the peak throughput of earlier SSE instructions, and most 128-bit SSE operations were extended to non-destructive three-operand VEX-encoded forms. AVX also added support for unaligned memory access and more flexible operand combinations.

Later versions

AVX2, introduced with Intel Haswell in 2013, extended most integer operations to 256 bits and added gather instructions and fused multiply-add (FMA3). AVX-512, announced in 2013 and shipped in Xeon Phi and later server processors, widened registers to 512 bits (ZMM), added 32 registers, opmask registers and many specialised instruction subsets, though its fragmented feature sets drew criticism. AMD first supported AVX-512 with its Zen 4 processors in 2022. Intel and AMD have since moved toward the converged AVX10 specification.

Software support

Operating systems must explicitly enable the extended register state via the XCR0 register before AVX can be used; Linux, Windows and macOS all support it. Compilers such as GCC, Clang and MSVC can auto-vectorise code to AVX or emit it through intrinsics, and libraries for media encoding, cryptography and machine learning rely heavily on AVX and AVX2.
