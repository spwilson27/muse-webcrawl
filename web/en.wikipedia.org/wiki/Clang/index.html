Clang

Clang is a compiler front end for the programming languages C, C++, Objective-C and Objective-C++. It uses the LLVM compiler infrastructure as its back end and has been part of the LLVM release cycle since LLVM 2.6. Clang is designed to offer a replacement to the GNU Compiler Collection (GCC) and is free and open-source software.

History and design

Clang development began at Apple Inc., which needed a modern compiler front end for its development tools and sponsored the project under Chris Lattner, the creator of LLVM. Unlike GCC's monolithic design, Clang is built as a set of reusable libraries with a modular architecture, making it suitable for integration into IDEs and tools providing code completion, refactoring, static analysis, and expressive error diagnostics. Its clear, detailed warning and error messages are often cited as an advantage.

Adoption

Clang is the default compiler for macOS and iOS development through Xcode, is widely used on Linux and BSD systems, and underpins tooling such as the Clang Static Analyzer and clang-format. Major projects compiled with Clang include the Chrome browser and parts of the Linux kernel.
