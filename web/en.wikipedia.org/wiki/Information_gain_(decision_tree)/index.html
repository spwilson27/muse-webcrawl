Information gain (decision tree)

In decision tree learning, information gain is a measure of how much an attribute reduces uncertainty about a target variable, used to choose which attribute to split on at each node. It is based on the concept of entropy from information theory: the information gain of an attribute is the expected reduction in entropy of the target class caused by partitioning the examples according to that attribute.

Definition

Let H(S) be the entropy of a set S of examples with respect to the class label. The information gain of attribute A is Gain(S, A) = H(S) − ∑v (|Sv|/|S|) H(Sv), where Sv is the subset of examples for which A takes value v. Algorithms such as ID3 select, at each step, the attribute with the highest information gain.

Limitations and variants

Information gain is biased toward attributes with many distinct values, since fine-grained splits can reduce entropy trivially (an extreme case is a unique identifier attribute). The C4.5 algorithm addresses this by using the gain ratio, which normalises information gain by the intrinsic entropy of the split. Related impurity measures include the Gini impurity used in CART trees.
