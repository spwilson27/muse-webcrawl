G-code

G-code is the most widely used computer numerical control (CNC) and 3D printing programming language. It is used mainly in computer-aided manufacturing to control automated machine tools, as well as for 3D printers via slicers. G-code instructions tell a machine where to move, how fast to move, and what path to follow; commands beginning with G are preparatory (geometric) functions, while M-codes control miscellaneous machine functions.

The language was developed in the 1950s at MIT and standardized in variants such as RS-274. In fused-filament 3D printing, G-code files generated by slicers control extrusion, temperatures, and movements, with dialects for firmware such as Marlin and RepRap.
