D (programming language)

From Wikipedia, the free encyclopedia

D, also known as Dlang, is a multi-paradigm system programming language created by Walter Bright at Digital Mars and released in 2001. Andrei Alexandrescu joined the design team in 2007 and co-authored The D Programming Language (2010). D was designed as a pragmatic re-engineering of C++, retaining its performance and low-level control while adding modern conveniences and removing features its designers considered error-prone.

Features

  • Compilation model: Statically typed and compiled to native machine code, with fast compilation times.
  • Memory management: Garbage collection by default, with tools for manual memory management and deterministic resource handling where required.
  • Metaprogramming: Compile-time function execution (CTFE), templates, mixins and conditional compilation.
  • Design by contract: Built-in support for class invariants, preconditions and postconditions, inherited from Bright's experience with Eiffel.
  • Interoperability: Direct linking with C object code and easy use of C libraries; limited compatibility with C++.
  • Concurrency: An immutability-aware type system and message-passing primitives intended to make concurrent programs safer.

History

The first version of D (D1) reached a stable specification in 2007. Development then shifted to D2, a backwards-incompatible revision that added const/immutable correctness and other features; D1 support ended in 2012. The reference compiler, DMD, was joined by the GCC-based GDC and the LLVM-based LDC compilers. The language's standard library is Phobos, and its package manager and build tool is called Dub.

Example

import std.stdio;

void main() {
    writeln("Hello, world!");
}

Reception

D has been used in production by companies including Facebook (which used it for some high-performance infrastructure components), Netflix, eBay and Weka. It is often praised for combining C++-level performance with productivity closer to that of C# or Go, though it has remained a niche language compared with its competitors.
