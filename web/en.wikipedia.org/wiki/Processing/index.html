Processing is a free graphical library and integrated development environment (IDE) built for the electronic arts, new media art, and visual design communities with the purpose of teaching non-programmers the fundamentals of computer programming in a visual context. Processing uses the Java language, with additional simplifications such as an added setup() and draw() structure and integrated drawing functions, and comes with its own simplified syntax layer intended to make programming graphics, animation and interaction accessible to artists and designers.

History

The project was initiated in 2001 by Casey Reas and Ben Fry, who were then at the MIT Media Lab Aesthetics and Computation Group, drawing on John Maeda's earlier Design By Numbers project. It grew into one of the most widely used tools in creative coding education, supported since 2012 by the Processing Foundation. The core team also produced related projects: p5.js, a JavaScript library reinterpreting Processing for the web; Processing for Android; and Processing.py, a Python mode. Its simplified environment also directly inspired the Arduino IDE, whose interface was modelled on Processing's.

Features

A Processing program is called a sketch. Programs are written in the PDE (Processing Development Environment) and can be exported as standalone applications. By default sketches render with a 2D renderer; 3D graphics are available through OpenGL-based renderers, and an extensive ecosystem of community libraries adds sound, computer vision, physics and hardware interaction. Iconic works and textbooks — including Reas and Fry's Processing: A Programming Handbook for Visual Designers and Artists and Daniel Shiffman's The Nature of Code — have made it a standard introduction to generative art.
