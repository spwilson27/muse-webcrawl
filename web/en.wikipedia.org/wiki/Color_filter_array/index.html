Color filter array

A color filter array (CFA), or color filter mosaic (CFM), is a mosaic of tiny color filters placed over the pixels of an image sensor to capture color information. The most common pattern is the Bayer filter, patented by Bryce Bayer of Kodak in 1976.

Bayer pattern

The Bayer array uses twice as many green filters as red or blue, matching the human eye's greater sensitivity to green luminance. Because each pixel records only one colour, the full-colour image is reconstructed by an interpolation process called demosaicing.

Alternatives

Other designs include Fujifilm's X-Trans pattern, which uses a less regular 6×6 arrangement to reduce moiré, RGBW arrays that add a white (clear) pixel for sensitivity, and the Foveon X3 sensor, which stacks photodetectors instead of using a mosaic.
