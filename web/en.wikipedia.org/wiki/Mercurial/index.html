Mercurial

Mercurial is a free and open-source distributed version control system designed to handle projects of any size with speed and efficiency. It is primarily implemented in Python, with latency-critical parts written in C and Rust. Mercurial's command-line interface is invoked as hg — the chemical symbol for mercury, from which the software takes its name.

History

Mercurial was created by Olivia Mackall (then known as Matt Mackall) in April 2005, during the controversy over the withdrawal of the free licence for BitKeeper, then used for Linux kernel development. Mackall released the first version, 0.1, on 19 April 2005 — the same month that Linus Torvalds began developing Git, which was ultimately chosen for the kernel. Mercurial nonetheless became one of the most widely used distributed version control systems, at various times adopted by projects and companies including Python, Mozilla (Firefox), Facebook, and Google, some of which later migrated to Git or to internal systems.

Design and features

Like Git, Mercurial gives every developer a complete copy of the repository history, supports branching and merging, and identifies revisions by SHA-1 hashes. It emphasises a consistent, simple command set, robust backwards compatibility, and an extension system written in Python. Large deployments inspired features such as narrow clones, sparse checkouts, and the EdenFS filesystem, developed at Facebook for its enormous monorepo.

Usage

Typical commands include hg init, hg clone, hg add, hg commit, hg push, hg pull, hg update, and hg log. Mercurial is cross-platform, running on Unix-like systems, Windows, and macOS, and is released under the GNU General Public License v2+.
