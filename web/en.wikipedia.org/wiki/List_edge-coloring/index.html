List edge-coloring

In mathematics, list edge-coloring is a problem in graph coloring that combines edge coloring with list coloring: each edge of a graph is assigned a list of allowed colors, and the task is to choose, for every edge, a color from its list so that no two adjacent edges receive the same color. The list chromatic index of a graph is the smallest number k such that a valid coloring exists whenever every edge is given a list of at least k colors.

A list edge-coloring of a graph; each edge must receive a color from its own list.

List coloring conjecture

The central open problem in the area is the list coloring conjecture (also called the list edge-coloring conjecture), which states that for any multigraph, the list chromatic index equals the ordinary chromatic index. By Vizing's theorem the chromatic index is either Δ or Δ + 1, where Δ is the maximum degree, so the conjecture asserts that the same values suffice for list coloring. The conjecture was posed independently by several authors in the 1970s–1990s, including Vizing, Gupta, Albertson and Collins, and Dinitz.

Partial results

The conjecture has been proved for several important classes of graphs. Galvin proved it in 1995 for bipartite multigraphs, a celebrated application of the kernel method that also implies Dinitz's theorem on Latin squares. Kahn later showed that the list chromatic index is asymptotically equal to Δ for large graphs. Progress continues with the development of the "polynomial method" and nibble techniques, but the general conjecture remains open.
