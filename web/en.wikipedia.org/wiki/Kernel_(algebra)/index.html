Kernel (algebra)

Kernel (algebra)
FieldAbstract algebra
DefinitionThe set of elements mapped to the identity (zero) element under a homomorphism
ExamplesKernel of a group homomorphism; null space of a matrix

In algebra, the kernel of a homomorphism is generally the inverse image of the identity element (or zero element) of the codomain — that is, the set of all elements of the domain that the homomorphism sends to the identity. The kernel measures the extent to which the homomorphism fails to be injective: a homomorphism is injective if and only if its kernel is trivial. Kernels are fundamental because the structures that can appear as kernels (normal subgroups, ideals, subspaces) are exactly the structures by which one can form quotients.

Groups

If f : G → H is a group homomorphism, its kernel is ker f = { g ∈ G : f(g) = eH }. The kernel is always a normal subgroup of G, and every normal subgroup arises as the kernel of the natural projection onto the quotient group. The first isomorphism theorem states that the image of f is isomorphic to the quotient G / ker f.

Linear algebra and modules

For a linear map T : V → W between vector spaces, the kernel — also called the null space — is the subspace of V consisting of vectors sent to the zero vector. The rank–nullity theorem relates its dimension to the dimension of the image. For a matrix A, the kernel is the solution space of the homogeneous equation Ax = 0. The same construction applies to homomorphisms of rings (where kernels are ideals) and of modules.
