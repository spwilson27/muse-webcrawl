Separation logic

From Wikipedia, the free encyclopedia

Separation logic is an extension of Hoare logic devised by John C. Reynolds, Peter O'Hearn, Samin Ishtiaq and Hongseok Yang for reasoning about programs that manipulate pointer data structures and mutable heap memory. It is a substructural logic whose central connective, the separating conjunction (written P * Q), asserts that two claims hold of disjoint portions of the heap.

Key ideas

The basic assertion x ↦ v says that the heap consists of a single cell at address x holding value v. The frame rule allows a specification proved about a small piece of heap to be extended with any additional, untouched portion of the heap described by a frame assertion. This supports local reasoning: a procedure can be verified by examining only the memory it actually accesses, which makes proofs scale and has made separation logic a foundation for automated program verifiers.

Concurrent separation logic

O'Hearn's concurrent separation logic extends the discipline to shared-memory concurrency by enforcing that threads own disjoint resources, with ownership transferred at synchronisation points. For this work and for separation logic generally, Reynolds, O'Hearn and Yang shared key honours; O'Hearn later co-founded the Infer static analyser project at Facebook (Meta), which uses separation-logic-based techniques (bi-abduction) to find bugs in production code.
