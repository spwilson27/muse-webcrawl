Carry-save adder

A carry-save adder is a type of digital adder used in computer microarchitecture to compute the sum of three or more binary numbers quickly. Unlike an ordinary adder, it does not propagate carries along the word; instead it produces two outputs — a partial sum and a vector of carries — in a single gate delay per stage.

Operation

Each bit position contains a full adder that takes three input bits and produces a sum bit and a carry bit, but the carry bit is passed to the next stage of a subsequent addition rather than rippling through the current word. Carry-save adders are widely used inside binary multipliers, where many partial products must be reduced efficiently (for example in Wallace trees and Dadda trees), with a final conventional carry-propagate adder producing the result.
