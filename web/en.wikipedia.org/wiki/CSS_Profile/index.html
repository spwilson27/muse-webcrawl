CSS Profile

The CSS Profile, short for the College Scholarship Service Profile, is an online financial aid application administered by the College Board. It is used by roughly 200 colleges, universities, and scholarship programs in the United States — mostly private institutions — to award non-federal institutional aid.

Comparison with the FAFSA

Unlike the FAFSA, which determines eligibility for federal aid using a standard federal methodology, the CSS Profile collects more detailed information, including home equity, the income and assets of a noncustodial parent, and the value of small businesses. Each participating institution applies its own institutional methodology to the data, so the same family may be assessed differently by different schools. The Profile also charges a submission fee (with fee waivers for eligible low-income applicants), whereas the FAFSA is free.

Process

Students typically complete the CSS Profile in the autumn of the year before enrollment, often by early November for early decision applicants. The College Board transmits the data to the colleges and programs the student designates, and some institutions request supporting documents through the College Board's IDOC service.
