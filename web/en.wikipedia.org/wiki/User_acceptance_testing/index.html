User acceptance testing

UAT is typically performed by end users or clients

User acceptance testing (UAT) is the final phase of the software testing process, during which actual end users or clients test a software system to verify that it can handle required tasks in real-world scenarios according to their specifications, and to determine whether it is acceptable for delivery.

Process

Unlike system testing, which is carried out by developers or QA teams against technical specifications, UAT is performed by representatives of the business users against business requirements and acceptance criteria, often using test scenarios derived from real workflows. Successful UAT concludes with user sign-off, after which the system is released to production. Forms of UAT include alpha and beta testing, contract acceptance testing, and operational acceptance testing.
