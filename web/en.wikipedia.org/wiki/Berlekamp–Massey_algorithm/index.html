Berlekamp–Massey algorithm

The Berlekamp–Massey algorithm is an algorithm for finding the shortest linear-feedback shift register (LFSR) that generates a given binary output sequence. Equivalently, over any field it finds the minimal polynomial of a linearly recurrent sequence given some of its terms. It is a cornerstone of algebraic decoding of error-correcting codes such as Reed–Solomon and BCH codes.

History

Elwyn Berlekamp devised the algorithm in 1968 for decoding BCH codes, presenting it in his book Algebraic Coding Theory. James Massey, in 1969, recognised its application to synthesising the shortest LFSR for a given sequence and gave the algorithm its common form and name. The procedure is closely related to the extended Euclidean algorithm applied to polynomials and to Padé approximation.

Description

The algorithm processes the sequence term by term, maintaining a candidate connection polynomial C(x). For each new term it computes a discrepancy — the difference between the actual term and the value predicted by the current register. If the discrepancy is zero the register is unchanged; otherwise the polynomial is corrected using the last polynomial that caused a change, scaled and shifted to cancel the discrepancy. When a correction increases the register length, bookkeeping variables are updated. The result after processing the whole sequence is the minimal polynomial of the linear recurrence that generates it.

Applications

In Reed–Solomon and BCH decoders, Berlekamp–Massey finds the error-locator polynomial from syndrome values. It also appears in stream-cipher cryptanalysis — the linear complexity of a keystream can be computed with it — and in computer algebra for finding minimal polynomials and rational generating functions.
