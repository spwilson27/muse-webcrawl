Bang–bang control

In control theory, a bang–bang controller (also called an on–off controller) is a feedback controller that switches abruptly between two states, typically fully on and fully off. Such controllers are common in household thermostats, which turn a heater fully on when the temperature falls below a set point and fully off when it rises above it.

TypeFeedback controller
Output statesTwo (on/off)
ExampleThermostat

Optimality

Bang–bang solutions also arise in optimal control theory: for certain problems, such as minimum-time control of linear systems, the optimal control input switches between its maximum and minimum allowed values. This is a consequence of Pontryagin's maximum principle.

Hysteresis

Practical on–off controllers incorporate hysteresis — a small dead band around the set point — to prevent rapid, wear-inducing switching (chattering) when the measured variable hovers near the threshold.

Applications

Beyond heating systems, bang–bang control is used in water-level regulation, refrigeration, simple robotics, and spacecraft attitude control with thrusters that can only fire or not fire.
