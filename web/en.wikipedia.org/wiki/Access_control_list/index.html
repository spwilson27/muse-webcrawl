Access control list

An access control list (ACL) is a list of permissions associated with a system resource (an object), specifying which users or system processes are granted access and what operations they may perform. Each entry in an ACL identifies a subject and an operation — for example, that a named user may read a particular file.

Filesystem ACLs

Traditional Unix permissions assign read, write and execute rights to an owner, a group and others. Filesystem ACLs, standardised in the withdrawn POSIX.1e draft and implemented in Linux, FreeBSD and other systems, generalise this by allowing permissions to be granted to arbitrary named users and groups. NTFS in Windows uses a rich ACL model with allow and deny entries, inheritance from parent directories, and auditing entries (SACLs).

Network ACLs

In networking, ACLs are rule sets applied on routers and firewalls to filter packets by source and destination address, protocol and port. They form a basic stateless packet-filtering mechanism and are also used to select traffic for NAT, quality of service and route filtering.

Models

ACLs implement discretionary access control and correspond to columns of an access control matrix. The alternative capability-based model instead associates unforgeable tokens of authority with subjects. Role-based access control (RBAC) is often layered on top of ACL mechanisms for administration at scale.
