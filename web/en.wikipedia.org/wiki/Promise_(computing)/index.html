Promise (computing)

In computing, a promise (also called a future, delay or deferred) is an object used for deferred synchronisation: it represents a value that may not yet be available because the computation producing it has not finished. Promises are a core tool of asynchronous programming, used to handle operations such as file access, network requests and timers without blocking execution.

Behaviour

A promise is in one of three states: pending, fulfilled (with a value), or rejected (with a reason). Consumers attach callbacks to be run on settlement. In JavaScript, standardised in ECMAScript 2015, promises are created with the Promise constructor, chained with then and catch, and combined with Promise.all and Promise.race. The async/await syntax is built on top of promises.

History

The concept appeared in the 1970s in the work of Daniel Friedman and David Wise and in the language MultiLisp, and spread through futures in Java and C#, tasks in .NET, and deferred objects in libraries such as jQuery before becoming a language standard.
