Web font

A web font is a font delivered over the web and downloaded by a browser so that a web page can be rendered in a typeface that is not installed on the user's device. Web fonts are made possible by the CSS @font-face rule, which lets designers specify font files to be fetched from a server and used for specified elements of a page.

History

The @font-face rule was first proposed for CSS2 in 1998 and implemented with proprietary formats — Microsoft's Embedded OpenType (EOT) in Internet Explorer and Netscape's TrueDoc — but failed to gain traction. Around 2009–2010, wider browser support for directly linkable TrueType and OpenType fonts, combined with commercial hosting services, made web fonts mainstream.

Formats

  • WOFF (Web Open Font Format) – a compressed wrapper for TrueType/OpenType, standardized by the W3C.
  • WOFF2 – an improved version using Brotli compression, offering roughly 30% better compression than WOFF.
  • EOT, SVG fonts, and raw TTF/OTF – legacy or fallback formats.

Services and licensing

Services such as Google Fonts, Adobe Fonts, and Fontstand host and serve web fonts; Google Fonts distributes open-source typefaces free of charge. Because font files are copyrighted software, web-font use is governed by licenses, and subsetting and compression reduce file size for delivery. Variable fonts, supported in modern browsers, package a range of weights and styles in a single file.
