Instruction register

In computing, the instruction register (IR) is the part of a CPU's control unit that holds the instruction currently being executed or decoded. In simple processors, each instruction to be executed is loaded into the instruction register, which holds it while it is decoded, prepared and ultimately executed — a process that may take several steps.

Operation

During the fetch stage of the instruction cycle, the instruction at the address held by the program counter is read from memory, often via a memory data register, into the instruction register. The control unit decodes the opcode field of the IR and generates signals to execute the operation on the operands it specifies. In pipelined processors, analogous structures hold instructions at each pipeline stage.
