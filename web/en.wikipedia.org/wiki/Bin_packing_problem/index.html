Bin packing problem

Packing items of varying sizes into the fewest possible fixed-size bins.

The bin packing problem is a combinatorial optimization problem in which items of different sizes must be packed into a finite number of bins, each of a fixed capacity, in a way that minimizes the number of bins used. It is a classic NP-hard problem in computational complexity theory and has many practical applications.

Formal definition

Given a set of items with sizes between 0 and 1, and bins of capacity 1, the goal is to assign each item to a bin such that the sum of sizes in any bin does not exceed 1, using as few bins as possible. The decision version — whether items can be packed into a given number of bins — is NP-complete, reducible from the partition problem.

Approximation algorithms

Because exact solutions are computationally expensive for large instances, simple heuristics are widely used. First Fit places each item in the first bin with enough remaining space; Best Fit places it in the bin with the least remaining space that can still hold it. First Fit Decreasing, which sorts items from largest to smallest before applying First Fit, guarantees using at most 11/9 of the optimal number of bins plus a small constant. More sophisticated asymptotic approximation schemes achieve ratios arbitrarily close to 1.

Variants and applications

Variants include the online version, in which items arrive one at a time and must be packed without knowledge of future items, and multi-dimensional versions such as packing rectangles or boxes. Applications include loading trucks and containers, allocating jobs to servers, cutting stock in manufacturing, memory allocation, and scheduling television advertisements into time slots.
