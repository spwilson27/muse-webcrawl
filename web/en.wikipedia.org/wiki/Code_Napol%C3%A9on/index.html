Code Napoléon

The Code Napoléon, officially the French Civil Code (Code civil des Français), is the national civil code of France, established under Napoleon Bonaparte and promulgated on 21 March 1804. It replaced the patchwork of customary and Roman-influenced laws that had varied across France before the Revolution.

Content and influence

The code abolished privilege based on birth, guaranteed freedom of religion and property rights, and organised law into books on persons, property and the acquisition of property. Spread by Napoleonic conquest and later imitation, it became the model for civil codes across continental Europe, Latin America, Louisiana and Quebec, and remains, heavily amended, the civil code of France today.
