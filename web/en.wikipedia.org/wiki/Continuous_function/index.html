Continuous function

In mathematics, a continuous function is a function such that a continuous change of the argument induces a continuous change of the value of the function. More precisely, a function is continuous if arbitrarily small changes in its value can be assured by restricting to sufficiently small changes of its argument. A function that is not continuous is called discontinuous.

Definition

A function f : R → R is continuous at a point c in its domain if the limit of f(x) as x approaches c equals f(c). The precise epsilon–delta definition, formalised by Cauchy and Weierstrass in the 19th century, states: for every ε > 0 there exists δ > 0 such that whenever |x − c| < δ, then |f(x) − f(c)| < ε.

A function is continuous on its domain if it is continuous at every point of the domain. In topology, continuity is generalised: a function between topological spaces is continuous if the preimage of every open set is open.

Examples

All polynomials, exponential functions, sine and cosine, and rational functions (on their domains) are continuous. The Heaviside step function, which jumps from 0 to 1 at the origin, is discontinuous. The Dirichlet function — 1 on the rationals, 0 on the irrationals — is discontinuous everywhere. The Weierstrass function is continuous everywhere but differentiable nowhere.

Properties

Sums, products, quotients (where defined) and compositions of continuous functions are continuous. Continuous functions on a closed bounded interval attain their maximum and minimum (extreme value theorem) and take every intermediate value (intermediate value theorem). Uniform continuity, a stronger condition, holds automatically for continuous functions on compact domains.

History

An intuitive notion of continuity was used by Euler and others in the 18th century. Bernard Bolzano gave a precise definition in 1817, and Augustin-Louis Cauchy developed the concept in his Cours d'Analyse (1821); Karl Weierstrass later gave the rigorous epsilon–delta formulation that became standard.
