Windows App SDK

DeveloperMicrosoft
Initial releaseNovember 2021 (version 1.0)
PlatformWindows 10 (1809+) and Windows 11
TypeSoftware development kit
LicenseMIT (open source components)

The Windows App SDK is a software development kit from Microsoft that provides a unified set of APIs and components for building desktop applications on Windows 10 and Windows 11. It originated as "Project Reunion," announced at Build 2020, with the goal of untangling the split between the Win32 and Universal Windows Platform (UWP) app models.

Overview

The SDK is delivered as a set of NuGet packages that developers reference from existing Win32, WPF, Windows Forms or UWP apps, allowing them to use modern Windows features without migrating their entire application or waiting for a new Windows release. Components are versioned and shipped independently of the operating system.

Components

  • WinUI 3 — the modern native UI framework (Windows UI Library), shipped as part of the SDK rather than with the OS.
  • App lifecycle APIs — activation, single-instancing and power notifications.
  • Windowing APIs — AppWindow classes for managing windows beyond the UWP model.
  • Notifications — push notifications and app notifications for unpackaged apps.
  • Deployment and bootstrap APIs — the framework package loader that lets packaged and unpackaged apps use the SDK runtime, alongside MSIX packaging support.
  • Other features — text rendering (DWriteCore), MRT Core resource management, dynamic dependency handling, and environment-variable and package-management APIs.

History

Project Reunion preview releases appeared through 2020–2021; version 1.0 of the renamed Windows App SDK shipped in November 2021 alongside Visual Studio 2022. Subsequent releases (1.1 through 1.6 and beyond) added widgets providers, improved deployment tooling, background tasks, and additional WinUI controls.
