Chekhov's gun

From Wikipedia, the free encyclopedia

FieldDramaturgy, narrative theory
Named forAnton Chekhov (1860-1904)
RelatedForeshadowing, red herring, setup and payoff

Chekhov's gun is a narrative principle: every element introduced in a story should be necessary, and seemingly irrelevant elements should be removed.

Statement

Anton Chekhov expressed the idea in letters and reported remarks in several forms, most famously that if a rifle hangs on the wall in the first act, it must be fired in a later act - otherwise it should not be there.

Use and interpretation

The principle covers props, plot points and details: introduced elements create expectations that the narrative should satisfy. It is the inverse of the red herring, which deliberately misleads, and underlies the maxim of economy in plotting.

Criticism

Some writers argue atmosphere, texture and deliberately unresolved details also have value, so the rule is best read as guidance against gratuitous digression.
