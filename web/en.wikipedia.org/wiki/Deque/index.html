Double-ended queue

From Wikipedia, the free encyclopedia

In computer science, a double-ended queue (abbreviated to deque, pronounced "deck") is an abstract data type that generalises a queue, for which elements can be added to or removed from either the front (head) or back (tail). It is also often called a head-tail linked list, though properly this refers to a specific data structure implementation of a deque.

Operations

The basic operations on a deque are:

  • push_front / push_back — insert an element at the front or back
  • pop_front / pop_back — remove and return the front or back element
  • peek_front / peek_back — inspect the end elements without removing them

All of these are typically O(1). A deque can be used as a stack (inserting and removing at the same end) or as a queue (inserting at one end, removing at the other).

Implementations

Deques are commonly implemented with a doubly linked list or with a dynamic array of blocks ("chunked" arrays). The C++ Standard Library provides std::deque, typically implemented as a sequence of fixed-size arrays; Java's java.util.ArrayDeque, Python's collections.deque and Rust's VecDeque are widely used implementations.

Applications

Deques appear in the monotonic-queue algorithm for sliding-window minima, work-stealing schedulers (such as the one in Java's fork/join framework and Cilk), undo histories, and breadth-first-search variants such as 0-1 BFS.
