State-space representation

In control engineering and dynamical systems theory, a state-space representation is a mathematical model of a physical system as a set of input, output and state variables related by first-order differential equations (in continuous time) or difference equations (in discrete time). The state of the system is the smallest set of variables that, together with the input, fully determines the system's future behaviour. State-space methods, developed in the 1960s in the work of Rudolf Kálmán and others, form the basis of "modern" control theory, in contrast to the "classical" frequency-domain methods based on transfer functions.

The linear state-space model

A continuous-time linear time-invariant system is written as:

ẋ(t) = A x(t) + B u(t)
y(t) = C x(t) + D u(t)

Here x is the state vector, u the input vector and y the output vector; the matrix A describes the internal dynamics, B how inputs affect the state, C how the state maps to the outputs, and D the direct feedthrough of input to output (often zero). The discrete-time form replaces the derivative with the next-step state, x(k+1) = A x(k) + B u(k).

Key concepts

Controllability asks whether the state can be driven anywhere by suitable inputs — for linear systems it is equivalent to the controllability matrix [B, AB, A²B, …] having full rank. Observability asks whether the state can be reconstructed from output measurements, with an analogous rank test on the observability matrix. These dual concepts govern the design of state feedback controllers, pole placement, and state estimators such as the Luenberger observer and the Kalman filter, which is the optimal estimator for linear systems with Gaussian noise.

Relation to transfer functions and applications

A state-space model can be converted to a transfer function G(s) = C(sI − A)⁻¹B + D, but the state-space form handles multiple-input multiple-output (MIMO) systems, initial conditions and time-varying or (by linearisation) nonlinear systems more naturally. State-space models are used across aerospace, robotics, process control, econometrics (e.g. dynamic factor models) and signal processing, and similar state-space formulations underlie hidden Markov models and modern sequence-learning architectures in machine learning.
