x86-64 (also known as AMD64, Intel 64, and generically x64) is the 64-bit extension of the x86 instruction set architecture. It was designed by Advanced Micro Devices (AMD), which published the specification in 2000 and shipped the first processors implementing it — the Opteron and Athlon 64 — in 2003. The architecture retains full backward compatibility with 32-bit and 16-bit x86 code while doubling the number of general-purpose registers, widening them to 64 bits, and expanding the virtual address space far beyond the 4 GiB limit of 32-bit systems.

History

At the end of the 1990s Intel was pursuing a clean-slate 64-bit architecture, Itanium (IA-64), which lacked native x86 compatibility. AMD instead extended x86 itself. The commercial success of AMD64 forced Intel to adopt a compatible implementation, first marketed as EM64T and later Intel 64, beginning with the Pentium 4 "Prescott" generation in 2004. Microsoft, whose Windows operating systems required a single 64-bit x86 standard, was a decisive external pressure in Intel's decision. Itanium was eventually discontinued, and x86-64 became the dominant architecture for personal computers and servers.

Features

Beyond 64-bit addressing, x86-64 added eight additional general-purpose registers (R8–R15), a larger SSE register file, an instruction-pointer-relative addressing mode that improves position-independent code, and the NX (no-execute) bit for memory protection — a key security feature. Operating modes include long mode (64-bit and compatibility sub-modes) and legacy mode for running unmodified older operating systems.

Present status

Under the leadership of CEO Lisa Su, AMD's Zen-family processors revitalised competition in x86-64 from 2017 onward. The architecture now faces growing competition in laptops and data centres from ARM-based designs, though it remains the standard for Windows PCs and much of the world's server installed base.
