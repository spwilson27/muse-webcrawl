LLVM is a set of compiler and toolchain technologies that can be used to develop a front end for any programming language and a back end for any instruction set architecture. It is designed around a language-independent intermediate representation (IR) that serves as a portable, high-level assembly language that can be optimised with a variety of transformations over multiple passes, supporting both static and just-in-time compilation.

History

The project began in 2000 at the University of Illinois at Urbana–Champaign, under Vikram Adve and Chris Lattner, as a research infrastructure for dynamic compilation techniques. The name originally stood for "Low Level Virtual Machine", but the project outgrew that meaning and the acronym was officially dropped. Apple hired Lattner in 2005 and became a major sponsor; LLVM became central to Apple's developer tools.

Components

  • Clang – a front end for C, C++, Objective-C and related languages.
  • LLD – a linker designed as a drop-in replacement for GNU and MSVC linkers.
  • LLDB – a debugger built on LLVM libraries.
  • libc++ – an implementation of the C++ standard library.
  • MLIR – a multi-level intermediate representation for machine learning and other compilers.
  • compiler-rt – runtime support libraries, including sanitisers.

Users

LLVM is used by the Swift, Rust and Julia languages, by graphics drivers for just-in-time shader compilation, and by many commercial and open-source compilers. The LLVM Foundation, a nonprofit, oversees the project and its community.
