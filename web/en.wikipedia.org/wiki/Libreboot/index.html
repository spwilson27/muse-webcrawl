Libreboot
Initial releaseDecember 2013
TypeBoot firmware
LicenseGNU General Public License

Libreboot is a free software project that provides a boot firmware distribution based on coreboot, intended to replace the proprietary BIOS or UEFI firmware found in many computers. It configures the hardware and hands control to a payload, commonly the GRUB bootloader, from which an operating system can be started.

The project was started in December 2013 by Leah Rowe. Its stated goal is to make coreboot easier to install and use by providing pre-built ROM images for supported hardware and extensive documentation, and by excluding proprietary binary blobs where possible. In September 2016 Libreboot briefly became a GNU project, but it left the GNU project in early 2017 after a public dispute.

Approach

Earlier versions of Libreboot aimed to be completely blob-free, which restricted it to older hardware (such as certain ThinkPad models) whose initialization could be performed without proprietary code. Later releases adopted a pragmatic policy permitting some vendor-supplied binaries where these were judged necessary, in order to support newer machines. The project provides automated build systems that compile coreboot and payloads from source, and it supports features such as full-disk encryption with /boot encrypted, GRUB configurations stored in ROM, and SeaBIOS as an alternative payload.

Reception

Libreboot is recommended by the Free Software Foundation as part of its Respects Your Freedom certification criteria for hardware, and pre-installed Libreboot systems are sold by a small number of vendors. The project has also been the subject of disputes within the free software community over its governance and its blob policy.
