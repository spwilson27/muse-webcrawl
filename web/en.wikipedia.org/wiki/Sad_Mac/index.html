Sad Mac

Platform: Classic Macintosh (1984–2002 era)
Meaning: Fatal startup hardware error
Counterpart: Happy Mac (successful startup)

The Sad Mac is a symbol in the classic Mac OS used to indicate a severe hardware or software problem at startup that prevented a Macintosh computer from successfully booting. It depicts a small Macintosh with a sad face and X-shaped eyes, modelled on the "Happy Mac" icon shown when a bootable system is found.

Behaviour

When a fatal error was detected during the power-on self-test, older Macintosh models displayed the Sad Mac together with a hexadecimal error code identifying the failed test, often accompanied by a distinctive "Chimes of Death" arpeggio on later models. The codes allowed technicians to diagnose faults such as bad RAM or logic-board failures.

Legacy

The Sad Mac disappeared from Macs with Mac OS X, replaced first by a flashing question-mark folder for a missing system and later by prohibitory symbols and, on modern machines, a globe for Internet Recovery. It remains a nostalgic icon of early personal computing.
