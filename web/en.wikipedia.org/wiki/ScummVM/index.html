ScummVM

ScummVM is a free and open-source software project that provides a collection of game engine recreations, allowing many classic graphic adventure games to be played on modern hardware and operating systems. The "VM" in its name stands for virtual machine.

History

The project began in 2001 with Ludvig Strigeus, who reverse-engineered LucasArts' SCUMM scripting language so that games such as Monkey Island could run on Linux. Vincent Hamm joined shortly afterwards. ScummVM is not an emulator: it replaces the original game executables with reimplemented engines, while the user supplies the original game data files.

Supported games

Support has expanded far beyond SCUMM to hundreds of games and many engines, including Sierra's AGI and SCI games, Broken Sword, Beneath a Steel Sky (whose developers provided the source code), Flight of the Amazon Queen, Humongous Entertainment titles, and—following the merger with the ResidualVM project—3D adventures such as Grim Fandango and Myst III: Exile.

Ports

ScummVM has been ported to a wide range of platforms, including Windows, macOS, Linux, Android, iOS, and numerous games consoles and handheld devices.
