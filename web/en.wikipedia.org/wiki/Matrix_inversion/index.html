Matrix inversion

Matrix inversion is the process of finding, for a given square matrix A, another matrix A−1 — the inverse of A — such that their product in either order is the identity matrix. A matrix possessing an inverse is called invertible (or non-singular); one without an inverse is singular. Over the real or complex numbers, a square matrix is invertible if and only if its determinant is nonzero, equivalently if its rows and columns are linearly independent and its rank is full.

Methods

The oldest method is the adjugate formula: the inverse is the transpose of the cofactor matrix divided by the determinant. For a 2 × 2 matrix this gives a simple closed form, but for large matrices the method is impractical. In practice, Gauss–Jordan elimination — augmenting the matrix with the identity and performing row operations — or an LU decomposition is used. Cramer's rule expresses the inverse through determinants and shares the same inefficiency. Special structures admit faster approaches: the inverse of a block matrix can be computed through the Schur complement, and the Woodbury identity updates inverses after low-rank modifications.

Computational complexity

Classical elimination inverts an n × n matrix in O(n³) arithmetic operations. Strassen-type fast matrix multiplication reduces the exponent, and matrix inversion is known to have the same asymptotic complexity as matrix multiplication. Numerical analysts generally advise against forming an explicit inverse when the real goal is solving a linear system Ax = b, since solving directly is faster and more stable; the condition number of the matrix governs the accuracy of either approach.

Generalizations

Rectangular and singular matrices possess generalized inverses, most famously the Moore–Penrose pseudoinverse, which gives least-squares solutions of overdetermined systems.
