RGBA color model

Image placeholder: the red, green, blue and alpha channels of an image shown over a checkerboard.

RGBA stands for red green blue alpha. While it is sometimes described as a color space, it is actually a three-channel RGB color model supplemented with a fourth channel — an alpha channel that specifies the opacity of each pixel. An alpha value of 1 means fully opaque, 0 means fully transparent, and intermediate values allow partial transparency used in compositing.

Representation

In computing, RGBA pixels are commonly stored in 32 bits: 8 bits each for red, green, blue and alpha, often written in hexadecimal notation such as #RRGGBBAA. In CSS, the rgba() function specifies colors with a decimal or percentage alpha component. The byte order of the channels varies between systems and file formats; some environments store premultiplied alpha, in which the colour components are already scaled by the alpha value, which simplifies compositing arithmetic.

History

The concept of an alpha channel was developed in the late 1970s at the New York Institute of Technology's Computer Graphics Lab by Alvy Ray Smith and Ed Catmull, and was described in detail in the 1984 paper "Compositing Digital Images" by Thomas Porter and Tom Duff, which defined the "over" compositing operator.

Applications

RGBA data underlies modern image formats such as PNG, window-system compositing, game graphics, and user-interface rendering, where layered elements with soft shadows and translucency are routine. It should not be confused with RGBA as used in some printing contexts, nor with the palette-based colour models of early home computers.
