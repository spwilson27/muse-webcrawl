The AVFoundation class architecture

AVFoundation is a multimedia framework developed by Apple Inc. for working with time-based audiovisual media on iOS, macOS and related platforms. It provides a set of Objective-C and Swift interfaces for playing, creating, editing, and capturing audio and video, and it forms the foundation on which higher-level frameworks such as AVKit and Photos are built.

History

AVFoundation was introduced for iOS with iOS 4 in 2010, initially oriented toward playback and recording. On the Mac it arrived with Mac OS X Lion (10.7) in 2011 as Apple's designated successor to the ageing QuickTime framework (QTKit), which was deprecated with OS X Mavericks and later removed. Over successive releases the framework absorbed capabilities for media composition, video processing, metadata handling, speech synthesis (via AVSpeechSynthesizer), and camera capture, and it expanded to tvOS, watchOS, and visionOS.

Architecture

The framework is organized around a small number of central abstractions:

  • AVAsset — represents a media resource such as a movie file or a stream, exposing its tracks, duration, and metadata.
  • AVPlayer and AVPlayerItem — manage playback of assets, including HTTP Live Streaming content.
  • AVMutableComposition — allows tracks from multiple assets to be combined for non-linear editing.
  • AVAssetExportSession — exports composed or trimmed media to files in various formats.
  • AVCaptureSession — coordinates inputs from cameras and microphones and outputs such as photos, movies, and metadata (including QR code detection).
  • AVAssetReader and AVAssetWriter — provide low-level access to decoded samples and encoding pipelines.

Time within AVFoundation is represented with the Core Media type CMTime, a rational number structure that allows frame-accurate editing without floating-point drift.

Use

Most Apple-platform media applications use AVFoundation directly or indirectly; the higher-level AVKit framework supplies ready-made player user interfaces on top of it. With the introduction of Swift concurrency and the Swift programming language, Apple has progressively added asynchronous APIs to the framework.
