LAPACK ("Linear Algebra Package") is a standard software library for numerical linear algebra. It provides routines for solving systems of linear equations, linear least squares problems, eigenvalue problems, and singular value decompositions, as well as associated matrix factorizations such as LU, QR, Cholesky and Schur decompositions. It is one of the most widely used libraries in scientific and engineering computing.

History and design

LAPACK was first released in 1992 as the successor to the 1970s packages LINPACK and EISPACK. Where its predecessors were designed for the vector machines of their era, LAPACK reorganised the algorithms to be blocked — operating on submatrices so as to maximise use of fast cache memory and the level-3 BLAS (matrix–matrix operations). It was originally written in Fortran 77, and modern releases use Fortran 90. Routine names follow a systematic scheme (e.g. DGESV for a double-precision general linear solver; xYYZZZ pattern encoding precision, matrix type and operation).

Implementations and ecosystem

The reference implementation is freely available from Netlib under a permissive BSD-style license. Vendors and open-source projects provide highly optimised versions, including Intel MKL, AMD AOCL, OpenBLAS, Apple Accelerate and the GPU-oriented cuSOLVER/MAGMA libraries. LAPACK underlies higher-level environments such as MATLAB, NumPy/SciPy, Julia, R and Octave. Associated projects include ScaLAPACK (distributed-memory parallel LAPACK), PLASMA and MAGMA for multicore and accelerator architectures.
