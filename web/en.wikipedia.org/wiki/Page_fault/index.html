Page fault

A page fault is a type of exception raised by computer hardware when a running program accesses a memory page that is not currently mapped into the process's virtual address space. The operating system's page fault handler then makes the access valid — for example by loading the page from disk — or terminates the program if the access is invalid.

Types

A minor (soft) fault occurs when the page is in memory but not marked present in the accessing process's page table; it is resolved without disk I/O. A major (hard) fault requires reading the page from secondary storage, such as a swap file or memory-mapped file, and is far more expensive. An invalid fault results from an illegal address and typically produces a segmentation fault.

Role in virtual memory

Page faults are the mechanism that makes demand paging possible: pages are loaded only when first touched, allowing programs to use more virtual memory than physically exists and enabling features such as memory-mapped files and copy-on-write.
