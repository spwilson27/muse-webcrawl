Stochastic process

From Wikipedia, the free encyclopedia
[Image: Several jagged random-walk paths spreading out from a common starting point]

A stochastic process (or random process) is a mathematical object defined as a collection of random variables indexed by a mathematical set — typically, random variables evolving in time. It is the probabilistic model for phenomena that change randomly: stock prices, particle motion, queue lengths, epidemics.

Canonical examples include the random walk (steps of random direction), the Poisson process (random events at a constant average rate), Markov chains (memoryless state transitions), and Brownian motion/Wiener process (continuous paths, nowhere differentiable), formalised by Norbert Wiener in 1923.

Theory and use

Stochastic calculus (Itô, 1940s) extends calculus to Brownian paths and prices financial derivatives (Black–Scholes–Merton, 1973). Martingales — fair-game processes — unify many limit theorems; stochastic differential equations model diffusion in physics and biology.

Simulation of stochastic processes (Monte Carlo methods) is how most applied questions get answered in practice.
