State observer

In control theory, a state observer or state estimator is a system that provides an estimate of the internal state of a given real system, from measurements of its inputs and outputs. Knowing the state is necessary to solve many control problems — for example, stabilising a system using state feedback — yet in practice not all internal states are directly measurable, sensors may be expensive or noisy, and some quantities (such as internal temperatures or concentrations) cannot be instrumented at all. An observer reconstructs the full state so that output-feedback control can approximate the performance of state feedback.

Luenberger observer

For a linear system with dynamics ẋ = Ax + Bu and measured output y = Cx, the Luenberger observer (introduced by David Luenberger in the 1960s) is a copy of the plant model corrected by the output error:

x̂̇ = A x̂ + B u + L (y − C x̂)

The estimation error e = x − x̂ then obeys ė = (A − LC) e, so by choosing the gain matrix L the designer can place the observer's error poles — typically several times faster than the controller poles — and drive the error to zero. The observer can be designed if and only if the system is observable. The separation principle guarantees that a stabilising state-feedback controller and a convergent observer can be designed independently and combined without destroying stability.

Other estimators

The Kalman filter is the optimal observer for linear systems subject to Gaussian process and measurement noise, choosing the gain to minimise the error covariance; its nonlinear generalisations include the extended and unscented Kalman filters. Other approaches include sliding-mode observers, high-gain observers for nonlinear systems, and unknown-input observers that decouple disturbances. Observers are used ubiquitously in aerospace flight control, motor drives, chemical process control, robotics and battery management systems (estimating state of charge), where they also serve fault-detection and sensor-fusion functions.
