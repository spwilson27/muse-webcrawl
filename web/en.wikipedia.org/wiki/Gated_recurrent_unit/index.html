Gated recurrent unit

Gated recurrent units (GRUs) are a gating mechanism in recurrent neural networks, introduced in 2014 by Kyunghyun Cho and colleagues in the context of neural machine translation. The GRU is similar to the long short-term memory (LSTM) unit but uses fewer parameters, having only two gates — an update gate and a reset gate — and no separate output gate or cell state.

Architecture

At each time step, the update gate determines how much of the previous hidden state is carried forward versus replaced by a candidate activation; the reset gate determines how much of the previous state contributes to the candidate. This gating helps mitigate the vanishing gradient problem and allows the network to retain information over long sequences.

Comparison with LSTM

Empirical studies on tasks such as machine translation, speech recognition, and music modeling found GRUs perform comparably to LSTMs while training faster and requiring less data in some settings; no consistent winner across all tasks has been established. Both architectures were largely superseded for large-scale language modeling by the transformer after 2017, though GRUs remain in use for smaller sequence models and on-device applications. Variants include the minimal gated unit and the light GRU used in speech processing.
