Symmetric multiprocessing

Symmetric multiprocessing or shared-memory multiprocessing (SMP) involves a multiprocessor computer hardware and software architecture where two or more identical processors are connected to a single, shared main memory, have full access to all input and output devices, and are controlled by a single operating system instance that treats all processors equally, reserving none for special purposes. Most multiprocessor systems today use an SMP architecture.

Description

In the case of multi-core processors, the SMP architecture applies to the cores, treating them as separate processors. Because all processors share access to the same memory, SMP systems must solve problems of cache coherence: when one processor updates a location in memory, other processors with cached copies must see the update. Protocols such as MESI maintain coherence between processor caches.

Advantages and limitations

SMP simplifies programming because a single model of execution and memory applies, and workloads can be balanced dynamically among processors. However, scaling is limited by contention for the shared memory bus and by coherence traffic; practical SMP machines historically topped out at a few dozen processors. Larger systems often use NUMA, in which each processor has fast access to local memory and slower access to remote memory.

Alternatives

Alternatives to SMP include asymmetric multiprocessing, in which processors have specialized roles, and massively parallel processing (MPP), in which processors have private memories and communicate by message passing.
