Text-based game

A text-based game or text game is a video game that uses a text-based user interface — typically character output on a terminal or display — rather than graphics. Players read descriptions and enter typed commands (or menu choices), and the game responds in text. Text games were among the earliest video games, flourishing on mainframes and early home computers where graphics were limited, and the genre survives today through interactive fiction, MUDs, and roguelikes using ASCII graphics.

History

Early examples circulated on 1960s–70s mainframes: The Oregon Trail (1971), Hunt the Wumpus (1973), and the landmark Colossal Cave Adventure (1976), whose natural-language parser inspired the commercial interactive fiction of Infocom — Zork (1980), The Hitchhiker's Guide to the Galaxy (1984) — sold in elaborate "feelie" packaging. Multi-user dungeons (MUDs), beginning with MUD (1978) at Essex University, added persistent multi-player worlds and became ancestors of modern MMORPGs. Roguelikes such as Rogue (1980) and NetHack (1987) rendered dungeons in ASCII characters and pioneered procedural generation and permadeath.

Forms

Parser-based interactive fiction accepts free-form commands ("take lamp"); choice-based works (including gamebooks' descendants and Twine stories) present clickable options; and modern tools like Inform 7 and Ink support a thriving amateur and indie scene coordinated through communities and competitions such as IFComp. Because the interface is pure text, these games are also notable for accessibility to screen readers.
