Bump function

In mathematics, a bump function (also called a test function) is a function f : ℝⁿ → ℝ on Euclidean space which is both smooth (having continuous derivatives of all orders) and compactly supported — that is, it vanishes outside some bounded region, its support. The space of all bump functions with domain in ℝⁿ is denoted Cc∞(ℝⁿ). Bump functions exist in abundance and are fundamental tools in analysis, despite the fact that no bump function can be analytic: a smooth function that vanishes on an open set need not vanish everywhere unless it is analytic, and bump functions show how far smooth functions are from analytic ones.

Example

The standard construction starts from the function h(x) = e−1/x for x > 0 and h(x) = 0 for x ≤ 0, which is smooth on the whole line because all its derivatives tend to zero as x approaches 0 from the right. Combining two such pieces gives a bump function on ℝ, for example Ψ(x) = exp(−1/(1−x²)) for |x| < 1 and 0 for |x| ≥ 1, supported on the interval [−1, 1]. Rescaling, translating, and multiplying such functions produces bumps supported on any desired region, and products give examples in higher dimensions.

Uses

Bump functions are used to construct mollifiers — smooth approximate identities used to approximate rough functions by smooth ones — and partitions of unity, which allow local constructions on manifolds to be patched into global ones. In distribution theory, test functions are the objects against which distributions (generalised functions) are defined, and the space of bump functions is the standard test-function space. They also underlie cutoff arguments throughout partial differential equations and differential geometry.
