Windows Driver Model


Developer Microsoft
Introduced Windows 98 / Windows 2000
Successor Windows Driver Frameworks (KMDF/UMDF)

The Windows Driver Model (WDM) is a framework for device drivers introduced by Microsoft with Windows 98 and Windows 2000, designed so that a single driver source (and, in some cases, binary) could work across the consumer Windows 9x line and the Windows NT line.

Architecture

WDM organises drivers into layered stacks of device objects: bus drivers enumerate hardware and create physical device objects (PDOs), function drivers implement device functionality (FDOs), and optional filter drivers modify behaviour above or below the function driver. Communication between layers uses I/O request packets (IRPs). WDM standardised support for Plug and Play and power management, which had previously been handled inconsistently between Windows versions. Driver categories defined under WDM include audio, network (NDIS-based miniports), and the Kernel Streaming architecture for multimedia devices.

History and successors

WDM replaced the older VxD model of Windows 9x and the disparate NT driver model. Although powerful, raw WDM programming was complex and error-prone, so Microsoft introduced the Windows Driver Foundation — later Windows Driver Frameworks — offering the Kernel-Mode Driver Framework (KMDF) and User-Mode Driver Framework (UMDF) to simplify driver development while building on the WDM architecture beneath.
