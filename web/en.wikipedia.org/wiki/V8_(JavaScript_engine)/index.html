V8 (JavaScript engine)

V8 is a free and open-source JavaScript engine developed by the Chromium Project for Google Chrome and Chromium web browsers. The project's creator is Lars Bak. Released in 2008 alongside Chrome, V8 compiles JavaScript directly to native machine code before executing it, dramatically improving performance compared with earlier interpreters.

Design

V8 implements ECMAScript as specified in ECMA-262. It uses just-in-time compilation, hidden classes, and inline caching to optimise dynamic JavaScript, and a precise garbage collector for memory management. Successive optimising compilers, including Crankshaft and later TurboFan, along with the Ignition interpreter, form its modern pipeline.

Uses

Beyond Chrome, V8 powers the Node.js runtime, the Deno runtime, and applications built with frameworks such as Electron. It is written in C++ and can be embedded in other programs, making it one of the most widely used JavaScript engines in the world.
