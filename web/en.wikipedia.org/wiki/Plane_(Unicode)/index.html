Plane (Unicode)

In the Unicode standard, a plane is a continuous group of 65,536 (216) code points. There are 17 planes, identified by the number 0 to 16, which corresponds with the possible values 00–1016 of the first two positions in six position hexadecimal format (U+hhhhhh). Plane 0 is the Basic Multilingual Plane (BMP), which contains most commonly used characters. The higher planes 1 through 16 are called "supplementary planes". The last code point in Unicode is the last code point in plane 16, U+10FFFF. As of Unicode version 16.0, five of the planes have assigned code points (characters), and seven are named.

Basic Multilingual Plane

The BMP contains characters for almost all modern languages and a large number of symbols. Most of the allocated code points are for characters of the Chinese, Japanese, and Korean (CJK) languages. Within the BMP, the high-surrogate and low-surrogate blocks (U+D800–U+DFFF) are reserved for use in the UTF-16 encoding as surrogate pairs for supplementary-plane characters, and are not themselves characters.

Supplementary planes

Characters in the supplementary planes are accessed in UTF-16 through surrogate pairs and in UTF-8 through four-byte sequences. The Supplementary Multilingual Plane holds historic scripts such as Linear B and Egyptian hieroglyphs, musical notation, mathematical alphanumeric symbols, playing cards, dominoes, and most emoji. The Supplementary Ideographic Plane holds CJK Unified Ideographs Ext. B through I, and the Tertiary Ideographic Plane holds further rare and historic ideographs, including the Tangut script characters assigned there.
