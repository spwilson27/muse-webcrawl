Directed graph

In mathematics, and more specifically in graph theory, a directed graph (or digraph) is a graph that is made up of a set of vertices connected by directed edges, often called arcs. It differs from an ordinary undirected graph in that its edges have orientations: each edge connects an ordered pair of vertices rather than an unordered pair.

Definition

Formally, a directed graph is an ordered pair G = (V, A) comprising a set V of vertices (or nodes) and a set A of arcs, each arc being an ordered pair of distinct vertices. For an arc (x, y), x is the tail and y is the head; y is a direct successor of x and x is a direct predecessor of y.

Types

Directed acyclic graphs (DAGs) contain no directed cycles and are used to model precedence relations, citation networks, and scheduling problems. In a strongly connected digraph, every vertex is reachable from every other; weakly connected digraphs are connected only when direction is ignored.

Basic concepts

The indegree of a vertex counts incoming arcs and the outdegree counts outgoing arcs. Degrees feature in flow problems, ranking algorithms such as PageRank, and reachability analysis.

Applications

Digraphs model one-way streets in road networks, hyperlinks between web pages, dependencies in software builds, and state transitions in automata.
