Control bus

In computer architecture, a control bus is part of the system bus, used by CPUs for communicating with other devices within the computer. While the address bus carries information between the CPU and memory about the device with which the CPU is communicating, the control bus carries signals that control and coordinate the activities of the system.

Control bus
Part ofSystem bus
SignalsRead, write, interrupt, clock
DirectionBidirectional

Function

The control bus carries command and timing signals between the central processing unit and other components. Typical signals include memory read and memory write lines, I/O read and write lines, interrupt requests and acknowledgments, bus request and bus grant lines, and the system clock.

Operation

When the CPU wishes to read data from memory, it places the address on the address bus, asserts the memory read line on the control bus, and the memory responds by placing data on the data bus. Control signals ensure that only one device drives the shared buses at a time, preventing contention.

Modern systems

In modern computers, the classical parallel bus structure has largely been replaced by point-to-point serial links such as PCI Express, but the conceptual distinction between address, data, and control functions remains useful in describing how processors coordinate transfers.
