Data mining

Data mining is the process of extracting and finding patterns in massive data sets involving methods at the intersection of machine learning, statistics, and database systems. It is the analysis step of the "knowledge discovery in databases" (KDD) process.

[ Hero image: The stages of the knowledge discovery in databases (KDD) process ]

Tasks

  • Classification — assigning items to predefined categories, such as flagging transactions as fraudulent or legitimate.
  • Clustering — grouping similar items without predefined labels, for example customer segmentation.
  • Association rule learning — discovering relations between variables, classically market-basket analysis ("customers who buy X also buy Y").
  • Regression — predicting a continuous value from input variables.
  • Anomaly detection — identifying records that deviate markedly from expected patterns.
  • Summary and visualisation — producing compact descriptions of data subsets.

Process

Standard process models such as CRISP-DM organise data mining into phases: business understanding, data understanding, data preparation, modelling, evaluation, and deployment. Data preparation — cleaning, transformation, and feature selection — typically consumes the majority of project effort. Because large data sets contain spurious correlations by chance, results require validation on held-out data to avoid overfitting.

Applications and concerns

Data mining is used in retail recommendation, credit scoring, network intrusion detection, bioinformatics, and scientific research. Its large-scale application to personal data raises privacy concerns and has attracted regulatory attention, since patterns extracted from anonymised data sets can sometimes be de-anonymised by linkage with other sources.
