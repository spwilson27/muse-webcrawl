Weisner theorem

In combinatorics, Weisner's theorem is a result about the Möbius function of a finite lattice, proved by Louis Weisner in 1935. It states that in a finite lattice with a smallest element 0̂ and a largest element 1̂, for any element x that is not 0̂, summing the values of the Möbius function μ(a, 1̂) over all elements a that join with x to give 1̂ (a ∨ x = 1̂) yields zero.

Significance

The theorem is a powerful tool for computing Möbius functions and proving identities in lattice theory and enumerative combinatorics. It is closely related to Philip Hall's theorem and to the combinatorial theory of incidence algebras developed by Gian-Carlo Rota; Weisner's result is often described as a precursor of Rota's crosscut theorem.
