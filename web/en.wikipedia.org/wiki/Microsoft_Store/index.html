Microsoft Store

Microsoft Store
Developer: Microsoft
Launched: 2012 (as Windows Store)
Platform: Windows, Xbox

The Microsoft Store is a digital distribution platform operated by Microsoft. It started as an app store for Windows 8 and Windows Server 2012, called the Windows Store, and grew to distribute apps, games, movies, TV shows and (formerly) music and e-books.

History

The store launched alongside Windows 8 in October 2012, initially for the new "Metro-style" Universal Windows Platform apps. With Windows 10 it merged the separate Windows Phone Store and Xbox stores into a single storefront, renamed Microsoft Store in 2017. Windows 11 brought a redesigned store that also accepts traditional Win32 desktop applications and third-party storefronts.

Policies

Apps are certified for security and content before listing. Microsoft historically took a 30% commission, later reducing it — to 15% for apps and 12% for PC games — and in 2021 allowed developers using their own commerce systems in apps to keep all revenue.
