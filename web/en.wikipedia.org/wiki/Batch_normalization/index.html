Batch normalization

Batch normalization is a technique for training deep neural networks that standardizes the inputs to each layer for each mini-batch. Introduced by Sergey Ioffe and Christian Szegedy in 2015, it stabilises the distribution of layer inputs during training, allowing higher learning rates, faster convergence, and reduced sensitivity to weight initialisation, and it also has a mild regularising effect.

FieldDeep learning

PurposeStabilise and accelerate network training
ParametersLearnable scale (γ) and shift (β) per feature

Method

For each feature in a mini-batch, batch normalization computes the batch mean and variance, normalises the activations to zero mean and unit variance, then applies a learned affine transformation with scale γ and shift β so the layer can recover the original representation if optimal. During training the statistics come from the current mini-batch while running averages are accumulated; at inference time the running averages are used instead, making the transformation deterministic for single examples.

Effects and debate

The original paper attributed the benefit to reducing "internal covariate shift". Later research argued the main effect is a smoother loss landscape, making gradients more predictive and optimisation easier. Batch normalization can interact poorly with very small batch sizes, motivating alternatives such as layer normalization, instance normalization, and group normalization, which normalise within each example rather than across the batch.
