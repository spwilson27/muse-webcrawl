Method (computer programming)

A method in object-oriented programming (OOP) is a procedure associated with an object, consisting of code that operates on the object's data. A method defines the behaviour of the objects that are instances of a class, and is one of the basic building blocks of an object-oriented program.

Concepts

Calling code invokes a method on an object (often described as sending the object a message), passing arguments and receiving any return value. Methods typically have access to the object's internal state through a special reference such as this or self. Instance methods act on individual objects, while static (class) methods belong to the class itself.

Variation across languages

Methods may be overridden in subclasses to enable polymorphism, declared abstract to require implementation, or made constructors and destructors to manage object creation and cleanup. Access modifiers such as public, private and protected control which code may call a method, supporting encapsulation. In languages like Java and C# all executable code resides in methods; in others, methods contrast with standalone functions and procedures.
