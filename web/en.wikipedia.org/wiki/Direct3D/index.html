Direct3D

Direct3D is a graphics application programming interface (API) for Microsoft Windows. Part of DirectX, Direct3D is used to render three-dimensional graphics in applications where performance is important, most notably computer games. Direct3D uses hardware acceleration if it is available on the graphics card, allowing the hardware acceleration of the entire 3D rendering pipeline or even only partial acceleration.

History

Direct3D 1.0 through 3.0 shipped as part of early DirectX releases in 1996, offering immediate mode and retained mode APIs. Direct3D 7 (1999) introduced hardware transform and lighting (T&L) and cube environment mapping. Direct3D 8 (2000) unified the vertex and pixel programming models into the first widely used shader model. Direct3D 9 (2002) added longer shader programs and floating-point formats, and was the version bundled with Windows XP; its extended support life came through the widely deployed Direct3D 9Ex variant on Windows Vista.

Direct3D 10, released with Windows Vista in 2006, was a ground-up redesign that required Shader Model 4.0 hardware and dropped fixed-function legacy support. Direct3D 11 (2009) introduced tessellation, multithreaded rendering, and compute shaders. Direct3D 12, released with Windows 10 in 2015, is a lower-level API that gives developers explicit control over command queues, resource states, and memory, in the spirit of APIs such as Vulkan and Apple's Metal.

Architecture

Applications issue drawing commands into command lists that are submitted to the GPU through a device context. The rendering pipeline processes vertex data through vertex shaders, primitive assembly, rasterization, and pixel (fragment) shaders before blending results into render targets. Direct3D 11 and later expose the pipeline through a state-object design intended to reduce driver overhead.

Direct3D 12

Direct3D 12 reduces CPU overhead by letting applications record command lists on multiple threads and manage synchronization explicitly via fences. Resources are described through descriptor heaps, and pipelines are bound as immutable pipeline state objects combined with mutable root signatures. While more verbose than its predecessors, the API allows engines to scale across many CPU cores and approach console-style efficiency on PC hardware.
