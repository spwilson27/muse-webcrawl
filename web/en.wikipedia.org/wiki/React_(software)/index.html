React (software)


Disambiguation page for software named React.

React may refer to several software projects:

Computing

React (JavaScript library) — a free and open-source front-end JavaScript library, maintained by Meta, for building user interfaces from components. Closely related are React Native, for native mobile applications, and ReactOS, an open-source operating system aiming at binary compatibility with Windows applications and drivers.

Other uses

The name is also used by various unrelated tools and frameworks, including reactive programming libraries, event-driven runtimes, and the biochemical pathway database REACTOME (sometimes rendered "Reactome"), which catalogues molecular reactions and pathways in human biology.
