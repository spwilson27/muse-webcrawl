Constraint satisfaction problem

Map colouring is a classic constraint satisfaction problem.

Constraint satisfaction problems (CSPs) are mathematical questions defined as a set of objects whose state must satisfy a number of constraints or limitations. A CSP is formally defined as a triple (X, D, C), where X is a set of variables, D is a set of domains of values for those variables, and C is a set of constraints specifying allowable combinations of values. A solution is an assignment of a value from its domain to every variable such that all constraints are satisfied.

Classic examples include map colouring, the eight queens puzzle, Sudoku, Boolean satisfiability (SAT), scheduling and timetabling, and configuration problems. CSPs are studied in artificial intelligence, operations research and complexity theory; in general they are NP-complete, but many subclasses are tractable.

Solving techniques

Standard solution methods combine backtracking search with constraint propagation techniques such as arc consistency (e.g. the AC-3 algorithm), variable- and value-ordering heuristics (such as minimum remaining values), and local search methods like min-conflicts for large problems. Constraint programming languages and solvers implement these techniques for industrial applications.
