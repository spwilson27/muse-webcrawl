BLS digital signature

The BLS digital signature scheme is a cryptographic signature scheme described by Dan Boneh, Ben Lynn, and Hovav Shacham that allows a user to verify that a signer is authentic. The scheme uses a bilinear pairing, in particular the Weil pairing on elliptic curves, and supports efficient signature aggregation: many signatures generated under many different public keys for many different messages can be aggregated into a single short signature.

Properties

BLS signatures are short: a signature consists of a single element of an elliptic curve group, roughly 160–256 bits depending on the security parameter. They are deterministic, requiring no randomness at signing time, which removes a common failure mode of schemes such as ECDSA. Because the verification equation is multiplicative, signatures can be aggregated: given signatures σ1, …, σn, anyone can compute the product σ = σ1···σn, which verifies against all the corresponding public keys and messages at once with only two pairing computations.

Scheme

Let e : G1 × G2 → GT be a bilinear pairing and g a generator of G2. A private key is a random scalar x; the public key is v = gx. To sign a message m, the signer hashes it to a point H(m) in G1 and outputs σ = H(m)x. Verification checks that e(σ, g) = e(H(m), v).

Applications

BLS signatures are used in blockchain systems, most notably the Ethereum consensus layer, where thousands of validator attestations are aggregated into a single signature each block. They also underpin threshold signature schemes used in distributed randomness beacons such as drand, because partial signatures from many parties combine into one valid signature.
