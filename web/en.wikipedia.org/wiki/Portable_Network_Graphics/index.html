Portable Network Graphics (PNG, officially pronounced /pɪŋ/, sometimes "pee-en-gee") is a raster-graphics file format that supports lossless data compression. PNG was developed as an improved, non-patented replacement for Graphics Interchange Format (GIF) and is the most frequently used lossless image compression format on the Internet.

PNG supports palette-based images (with palettes of 24-bit RGB or 32-bit RGBA colors), grayscale images (with or without an alpha channel for transparency) and full-color non-palette-based RGB or RGBA images. The PNG working group designed the format for transferring images on the Internet, not for professional-quality print graphics, and therefore does not support non-RGB color spaces such as CMYK.

History and development

The motivation for creating PNG arose in early 1995, after Unisys announced it would enforce its software patent on the Lempel–Ziv–Welch (LZW) data compression algorithm used in GIF. An informal group of developers on Usenet designed a patent-free successor, settling on DEFLATE compression. The specification was released in 1996 as RFC 2083, became a W3C Recommendation on 1 October 1996, and was adopted as ISO/IEC 15948 in 2004. The file signature and chunked structure allow decoders to detect errors and to extend the format with new chunks while remaining backward compatible.

File format

A PNG file begins with an eight-byte signature followed by a series of chunks, each with a four-letter type code, a length and a cyclic redundancy check. Critical chunks include IHDR (image header), PLTE (palette), IDAT (image data, compressed with DEFLATE) and IEND. Ancillary chunks store gamma (gAMA), ICC profiles (iCCP), textual metadata (tEXt, iTXt, zTXt), background color, physical pixel dimensions and timestamps.

Pixels are filtered before compression: each row is transformed by one of five filters (None, Sub, Up, Average, Paeth) chosen to improve DEFLATE efficiency. PNG supports bit depths from 1 to 16 bits per channel and interlacing using the Adam7 algorithm, which allows a progressively refining display as data arrives.

Comparison with other formats

Compared with GIF, PNG offers better compression for most images, true alpha transparency instead of a single transparent color, 24-bit color, and gamma correction, but no animation in the core standard (the unofficial APNG extension adds animation and is widely supported by browsers). Compared with JPEG, PNG compression is lossless but produces much larger files for photographs. For line art, screenshots and images with sharp edges and text, PNG remains the standard choice on the web.
