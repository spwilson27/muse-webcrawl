Booth's multiplication algorithm

Booth's multiplication algorithm is a multiplication algorithm that multiplies two signed binary numbers in two's complement notation. The algorithm was invented by Andrew Donald Booth in 1950 while doing research on crystallography at Birkbeck College in London. It is of interest mainly because it reduces the number of additions required when the multiplier contains long strings of consecutive 1s, by encoding runs of 1s using subtraction.

Principle

The algorithm examines pairs of bits of the multiplier, including an appended 0 at the least significant end. A transition from 0 to 1 marks the beginning of a run (subtract the multiplicand); a transition from 1 to 0 marks the end of a run (add the multiplicand); when the bits are equal, no operation is performed. After each step the partial product is arithmetically shifted right. Because it handles signed numbers directly, Booth's algorithm is widely taught in computer architecture and used as a basis for fast hardware multipliers, including radix-4 (modified Booth) encoding.
