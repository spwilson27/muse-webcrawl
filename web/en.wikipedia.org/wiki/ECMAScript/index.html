ECMAScript

ECMAScript (ES) is a standard for scripting languages, including JavaScript, JScript, and ActionScript. It is best known as a JavaScript standard intended to ensure the interoperability of web pages across different web browsers. It is standardized by Ecma International in the ECMA-262 specification.

History

The language was created by Brendan Eich at Netscape in 1995 and submitted to Ecma International for standardization in 1996. The first edition of ECMA-262 was adopted in June 1997. ECMAScript 3, published in 1999, became the widely implemented baseline for many years. The planned fourth edition was abandoned due to disagreements over language complexity; many of its ideas were later incorporated into ECMAScript 5 (2009) and ECMAScript 2015.

Editions

EditionYearNotable features
ES52009Strict mode, JSON support, getter/setter syntax
ES2015 (ES6)2015Classes, modules, arrow functions, let/const, promises, generators
ES20162016Exponentiation operator, Array.prototype.includes
ES20172017Async functions, shared memory and atomics
ES20202020Optional chaining, nullish coalescing, BigInt, globalThis
ES20222022Top-level await, class fields, Error cause

Since ECMAScript 2016, new editions are released annually, with the specification developed openly on GitHub by the TC39 committee through a staged proposal process.

Conformance

Implementations such as V8 (Chrome, Node.js), SpiderMonkey (Firefox), and JavaScriptCore (Safari) are tested against the Test262 conformance suite maintained by TC39.
