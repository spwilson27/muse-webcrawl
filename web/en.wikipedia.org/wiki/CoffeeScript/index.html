CoffeeScript

CoffeeScript is a programming language that compiles to JavaScript. Created by Jeremy Ashkenas and first released in 2009, it offers a terser, more readable syntax inspired by Ruby, Python and Haskell, with significant whitespace and minimal punctuation.

Features and influence

CoffeeScript added features such as list comprehensions, destructuring assignment, string interpolation and a class syntax that were later adopted into ECMAScript 2015, after which the language's popularity declined. CoffeeScript 2, released in 2017, compiles to modern JavaScript syntax.
