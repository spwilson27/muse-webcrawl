Extract, transform, load

Extract, transform, load (ETL) is a three-phase computing process where data is extracted from an input source, transformed (including cleaning), and loaded into an output destination, most commonly a data warehouse. Data finally loaded is typically used for business intelligence, reporting, and analysis.

The three phases

Extract: data is read from one or more source systems — operational databases, files, APIs, or streaming feeds — and copied into a staging area.

Transform: the data is cleaned, validated, deduplicated, joined, aggregated, and converted into a consistent format and schema suitable for the target system. This stage enforces data-quality and business rules.

Load: the transformed data is written into the destination, historically a data warehouse, replacing or appending to existing data.

ETL versus ELT

With the rise of powerful cloud data warehouses and data lakes, the ELT pattern — extract, load, then transform in place — has become popular, because raw data can be stored cheaply and transformed on demand using the warehouse's compute. ETL tools include Informatica, Talend, Apache NiFi, SSIS, and cloud services such as AWS Glue and Azure Data Factory.

Challenges

ETL processes must handle schema drift, data quality problems, incremental loading, idempotency, and error recovery. Orchestration tools such as Apache Airflow schedule and monitor complex pipelines.
