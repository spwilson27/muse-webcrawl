Bootloader

A bootloader (also spelled boot loader) is a computer program that is responsible for booting a computer: it completes hardware initialisation handed over by the firmware and loads the operating system kernel into memory so that the system can start. Bootloaders range from a few hundred bytes of code in the master boot record of a disk to full-featured programs offering menus of operating systems, recovery tools, and configuration options.

Boot process

On a traditional PC, the BIOS firmware runs power-on self tests and then loads the first sector of the boot disk — the master boot record (MBR) — into memory. Because 512 bytes is too small for a full loader, the MBR code typically loads a larger second stage, which reads a configuration, presents a boot menu if configured, loads the kernel and initial ramdisk, and transfers control to the kernel. Under UEFI, the firmware can itself load bootloader applications (such as GRUB's EFI image or the Windows Boot Manager) stored as files on the EFI system partition. Many bootloaders are "chain-loaded" in sequence, and multiboot setups use a single loader such as GNU GRUB to offer a choice among several installed operating systems.

Security

Because a bootloader runs with full control before the operating system starts, it is a critical point for security. UEFI Secure Boot requires bootloaders to be cryptographically signed, protecting against bootkits and other malware that persist below the operating system. Conversely, locked bootloaders on phones and game consoles are a focus of debate over owners' ability to install alternative software; unlocking a phone's bootloader is often the first step in installing a custom Android ROM.
