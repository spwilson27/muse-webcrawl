Length of a module

In algebra, the length of a module over a ring is a measure of the module's "size". It generalises both the dimension of a vector space and the order (number of elements) of a finite abelian group. A module has finite length if and only if it is both Artinian and Noetherian.

Definition

The length of a module M is defined as the length of the longest chain of submodules 0 = M0 ⊊ M1 ⊊ … ⊊ Mn = M, or infinity if no maximum exists. If the length is finite, a maximal such chain is called a composition series; by the Jordan–Hölder theorem, all composition series of a module of finite length have the same length and the same factors up to order, so the definition is unambiguous. Equivalently, the length counts the number of simple modules occurring as composition factors.

Examples

A vector space over a field has length equal to its dimension. As a module over the integers, a finite abelian group of order n has length equal to the total number of prime factors of n counted with multiplicity; for example, Z/6Z has length 2. The ring Z itself has infinite length as a module over itself.

Properties

Length is additive on short exact sequences: if 0 → L → M → N → 0 is exact, then ℓ(M) = ℓ(L) + ℓ(N). For a Noetherian local ring, the length of an Artinian quotient such as R/mk is a polynomial in k for large k, giving rise to the Hilbert–Samuel function and the notion of multiplicity.
