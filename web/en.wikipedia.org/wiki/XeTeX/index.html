XeTeX (pronounced "zee-tech") is a TeX typesetting engine that uses Unicode natively and supports modern font technologies such as OpenType, Graphite and Apple Advanced Typography (AAT). It was originally developed by Jonathan Kew (working at SIL International) and released in 2004, initially for Mac OS X.

Features

Unlike the original TeX and pdfTeX engines, which work with 8-bit input and require fonts to be specially prepared for TeX, XeTeX accepts UTF-8 input directly and can use any font installed on the operating system, selectable by name through packages such as fontspec in LaTeX. This makes it straightforward to typeset documents in scripts such as Arabic, Chinese, Devanagari and Hebrew, with correct handling of complex-script shaping via libraries including HarfBuzz and ICU.

XeTeX produces an intermediate extended DVI file (XDV) that is converted to PDF by a driver (xdvipdfmx). It supports colour, graphics inclusion and bidirectional text.

Usage

XeTeX is included in the major TeX distributions (TeX Live, MiKTeX, MacTeX) and is invoked with the commands xelatex or xetex. It has been particularly popular in the humanities, linguistics and multilingual publishing, where its font and script support is valuable. Its perceived drawbacks compared with pdfTeX include a lack of the micro-typographic extensions available in pdfTeX and LuaTeX.
