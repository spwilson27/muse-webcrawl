Directory (computing)

In computing, a directory is a file system cataloguing structure which contains references to other computer files, and possibly other directories. On many computers, directories are known as folders, a metaphor drawn from office filing. A directory contained within another is its subdirectory (child); the containing one is the parent directory. Together the directories form a hierarchy, or tree, whose topmost element is the root directory.

Overview

Early systems such as CP/M and early MS-DOS had a single flat directory per disk volume, limiting the number of files. Hierarchical file systems, pioneered in Multics and popularised by Unix, let users create directories within directories without practical structural limits. Each process typically has a working (current) directory, and files may be specified by absolute pathnames from the root or relative pathnames from the working directory. The special entries "." and ".." in Unix-like systems refer to the current and parent directories.

Folder metaphor

Graphical user interfaces present directories as folder icons that can be opened to display their contents, an analogy introduced in early systems such as the Xerox Star and adopted by Macintosh and Windows.
