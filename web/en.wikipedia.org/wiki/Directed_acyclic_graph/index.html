Directed acyclic graph

FieldGraph theory, computer science
StructureDirected graph with no directed cycles
Key propertyAdmits a topological ordering

In mathematics and computer science, a directed acyclic graph (DAG) is a directed graph with no directed cycles — that is, no path can start and end at the same vertex by following the direction of the edges. Every DAG has at least one topological ordering, an arrangement of its vertices such that every edge goes from earlier to later in the order.

Properties

A finite directed graph is acyclic if and only if it has a topological ordering. Unlike general directed graphs, DAGs support efficient algorithms for shortest and longest paths, and many problems that are hard on general graphs become tractable on DAGs through dynamic programming over a topological order.

Applications

DAGs model dependencies and precedence constraints: build systems and spreadsheets use them to order computations; compilers use them to represent expressions; version control systems such as Git store history as a DAG of commits; Bayesian networks are DAGs encoding conditional dependencies between random variables; and several distributed ledgers use DAG structures in place of a single blockchain.
