Nowhere continuous function

In mathematics, a nowhere continuous function, also called an everywhere discontinuous function, is a function that is not continuous at any point of its domain. Although continuous functions are fundamental in analysis, nowhere continuous functions show that discontinuity can be as extreme as possible.

Dirichlet function

The classic example is the Dirichlet function, usually denoted 1ℚ, defined as 1 for rational inputs and 0 for irrational inputs. Because every neighbourhood of any real number contains both rationals and irrationals, the function oscillates between 0 and 1 arbitrarily close to every point and is continuous nowhere. Modifications, such as Thomae's function, are continuous at the irrationals but discontinuous at the rationals, showing intermediate behaviour.

Properties

Modifying the Dirichlet function by an irrational scaling produces functions discontinuous everywhere with other values. By a theorem of Darboux, derivatives always have the intermediate value property, so no nowhere continuous function can be the derivative of any function. Sums and products of such functions with continuous ones can exhibit varied behaviour studied in real analysis courses as counterexamples.
