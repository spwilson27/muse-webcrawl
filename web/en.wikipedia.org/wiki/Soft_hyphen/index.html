Soft hyphen

In computing and typesetting, the soft hyphen (also called the discretionary hyphen or syllable hyphen) is a code point reserved in some character sets for breaking words across lines by inserting a visible hyphen. It differs from the ordinary "hard" hyphen, which is always visible and is part of the word, such as in "well-known".

If a line is not broken at a soft hyphen, the character remains invisible. In Unicode, the soft hyphen is encoded at U+00AD, and in HTML it can be written as the character entity &shy;. Its behaviour has historically been inconsistent across browsers and character encodings, notably in ISO 8859-1, where the character was variously treated as always visible or as a formatting character.

Usage

Authors insert a soft hyphen at a preferred syllable break inside a long word. Text-layout software may then break the word at that point if needed for justification, rendering a hyphen glyph at the line end, or keep the word intact and invisible otherwise. This allows finer control than automatic hyphenation dictionaries, especially for unusual words, names, and URLs.

Encoding history

The soft hyphen existed in ISO 8859-1 as character 0xAD. Unicode adopted it with the intent that it only appear when a line break occurs, but early implementations displayed it as an ordinary hyphen regardless of position, causing confusion. Modern HTML and CSS rendering follows the conditional-display model.
