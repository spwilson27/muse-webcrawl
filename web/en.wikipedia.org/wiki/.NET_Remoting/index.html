.NET Remoting

.NET Remoting
DeveloperMicrosoft
Platform.NET Framework
TypeRemote procedure call API
StatusLegacy; succeeded by WCF

.NET Remoting is a Microsoft application programming interface for inter-process communication, released with the .NET Framework in 2002. It allowed objects in different application domains or processes — including across a network — to communicate as if they were in the same process.

Architecture

Remoting distinguishes between marshal-by-reference objects, accessed through transparent proxies over channels (TCP or HTTP), and marshal-by-value objects, serialised and copied to the client. Formatters such as the binary and SOAP formatters encode messages, and channels, sinks and lease-based lifetime services manage activation and garbage collection of remote objects.

Successors

Microsoft superseded Remoting with Windows Communication Foundation (WCF) in .NET Framework 3.0 (2006). Remoting was not carried into modern .NET (formerly .NET Core), and Microsoft advises against it for new development, citing security concerns with its binary serialisation.
