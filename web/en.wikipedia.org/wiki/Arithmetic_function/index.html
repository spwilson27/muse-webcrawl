Arithmetic function

From Wikipedia, the free encyclopedia

Arithmetic functions describe number-theoretic properties of integers.

In number theory, an arithmetic function, or number-theoretic function, is generally any function f(n) whose domain is the positive integers and whose range is a subset of the complex numbers. In other words, an arithmetic function is a sequence of complex numbers. Hardy and Wright offer the following generalisation: "The phrase arithmetic function is used loosely, to mean a real or complex valued function defined on the set of positive integers."

Examples

Many functions of elementary number theory are arithmetic functions, including:

  • The divisor function σ(n), the sum of the divisors of n, and d(n), the number of divisors.
  • Euler's totient function φ(n), counting integers up to n coprime to n.
  • The Möbius function μ(n), central to Möbius inversion.
  • The von Mangoldt function Λ(n), used in the study of prime distribution.
  • The prime-counting function π(x) and summatory functions formed from the above.
  • The partition function p(n), counting representations of n as a sum of positive integers.

Multiplicative and additive functions

An arithmetic function is multiplicative if f(mn) = f(m)f(n) whenever gcd(m, n) = 1, and completely multiplicative if this holds for all m, n. It is additive if f(mn) = f(m) + f(n) for coprime m, n. A multiplicative function is determined by its values at prime powers. The set of arithmetic functions forms a ring under pointwise addition and Dirichlet convolution, (f * g)(n) = Σd|n f(d) g(n/d), whose identity element is the function ε with ε(1) = 1 and ε(n) = 0 otherwise.

Average order

Analytic number theory studies arithmetic functions through their average behaviour: the summatory function Σn≤x f(n) often has a smooth asymptotic "average order" even when f itself fluctuates wildly—as with Dirichlet's divisor problem and the Prime Number Theorem.
