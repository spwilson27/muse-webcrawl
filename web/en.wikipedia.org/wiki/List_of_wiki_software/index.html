List of wiki software

Wiki software is the software that runs a wiki website, allowing users to create and edit pages collaboratively in a web browser. The first wiki software, written by Ward Cunningham in 1994–95 for the WikiWikiWeb, inspired all later systems. The best-known today is MediaWiki, the software behind Wikipedia. The table below lists notable packages, most of them free and open-source.

Hosted services

Beyond self-hosted software, hosted wiki platforms include Fandom (running MediaWiki, for fan communities), Miraheze and wiki.gg (MediaWiki farms), Wikidot, and general tools such as Notion and SharePoint that incorporate wiki-like pages.
