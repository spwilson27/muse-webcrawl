Bus admittance matrix

In power engineering, a bus admittance matrix (also called a Y matrix or Ybus matrix) is an N × N matrix describing a power system with N buses. It represents the nodal admittances of the various buses in the network, with the relationship between bus voltages and injected currents given by I = Ybus V.

Construction

Each diagonal element Yii is the sum of all admittances connected to bus i, and each off-diagonal element Yij is the negative of the admittance directly connecting buses i and j; elements are zero where no direct connection exists, making the matrix highly sparse for real networks. It can be built directly by inspection from the network's branch data.

Applications

The bus admittance matrix is the foundation of power-flow (load-flow) studies, in which it is used with methods such as Newton–Raphson and fast decoupled load flow to compute bus voltages across a power system. It is also used in short-circuit analysis and stability studies.
