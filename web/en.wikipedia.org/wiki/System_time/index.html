System time

In computing, system time represents a computer system's notion of the passing of time. It is typically measured as the number of seconds (or smaller units) elapsed since a defined starting point called the epoch. For Unix and POSIX systems the epoch is 00:00:00 UTC on 1 January 1970, and Unix time counts seconds from that moment, disregarding leap seconds.

Clocks and synchronisation

Computers maintain system time using a hardware real-time clock backed by a battery, updated by the operating system at boot. Because hardware clocks drift, systems commonly synchronise with network time servers using the Network Time Protocol (NTP). Operating systems also distinguish wall-clock time from a monotonic clock used for measuring intervals, which is immune to manual changes and leap adjustments.

Limitations

Representations can overflow: 32-bit signed Unix timestamps wrap in the year 2038 problem, while other systems use different epochs, such as 1 January 1601 (Windows FILETIME) or 1 January 2001 (Apple's reference date). Timestamps are central to file systems, logging, scheduling, and security protocols.
