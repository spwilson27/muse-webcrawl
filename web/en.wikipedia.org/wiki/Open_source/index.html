Open source

From Wikipedia, the free encyclopedia

Open source is a source code that is made freely available for possible modification and redistribution. Products include permission to use and view the source code, design documents, or content of the product. The open-source model is a decentralised software development model that encourages open collaboration.

A main principle of open-source software development is peer production, with products such as source code, blueprints, and documentation freely available to the public. The open-source movement in software began as a response to the limitations of proprietary code, and the term was formalised in 1998 with the founding of the Open Source Initiative (OSI), which maintains the Open Source Definition — a set of criteria that a licence must satisfy for software to be considered open source.

Open Source Definition

The OSI's definition, derived from the Debian Free Software Guidelines, requires free redistribution; availability of source code; permission for derived works; no discrimination against persons, groups, or fields of endeavour; and that the licence be technology-neutral, among other criteria. Approved licences include the MIT License, the Apache License 2.0, the GNU General Public License family, and the BSD licences.

Relationship to free software

Open source overlaps almost entirely in practice with free software, championed by Richard Stallman and the Free Software Foundation since the 1980s. The two movements differ philosophically: the free-software movement frames the issue as an ethical matter of user freedom, while the open-source movement emphasises pragmatic benefits — quality, reliability, and collaboration — and engages more readily with business.

Beyond software

The open-source approach has been extended to hardware, data, content, science, and culture — giving rise to open-source hardware, open data, open access publishing, open educational resources, and open design. These movements share principles of transparency, decentralised participation, and reuse under permissive or copyleft terms.

Impact

Open source underpins much of the modern internet and technology industry: the Linux kernel, the Apache and Nginx web servers, the Firefox and Chromium browsers, and the Android operating system are prominent examples, and collaborative development platforms such as GitHub host hundreds of millions of open-source projects.
