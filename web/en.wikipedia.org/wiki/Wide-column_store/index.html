Wide-column store

A wide-column store (also called a column-family database) is a type of NoSQL database that stores data in tables with rows and dynamic columns. Unlike a relational database, the names and formats of columns can vary from row to row in the same table, and each cell can hold multiple timestamped versions of a value. Wide-column stores are designed to scale horizontally across many commodity servers and to handle very large volumes of sparse data.

Data model

Data is organised into column families — groups of related columns that are stored together and usually accessed together. A row is identified by a row key, and the full address of a value is given by row key, column family, column qualifier, and timestamp. Because columns are created dynamically, different rows can have entirely different sets of columns, making the model well suited to event data, time series, and user profiles with heterogeneous attributes.

Examples

The model was popularised by Google's Bigtable (described in a 2006 paper), which inspired the open-source Apache HBase. Other widely used wide-column stores include Apache Cassandra (originally developed at Facebook) and ScyllaDB. These systems are used for write-heavy workloads such as messaging inboxes, recommendation data, sensor readings, and activity logs.

Comparison

Wide-column stores differ from relational column-oriented databases (columnar OLAP systems), which have fixed schemas and are optimised for analytical scans; wide-column stores instead prioritise flexible schemas, fast key-based lookups, and massive write throughput on distributed clusters.
