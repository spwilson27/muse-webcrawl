Software portability

Software portability is the ease with which a computer program or system can be transferred from one environment — such as a hardware platform, operating system, or processor architecture — to another. Porting is the process of adapting software so that it runs in a different environment.

Approaches

Portability is improved by using standardised programming languages, portable libraries, and abstraction layers, and by avoiding platform-specific features. Standards such as POSIX allow Unix-like programs to be recompiled for different systems with minimal changes. Virtual machines and interpreted languages, such as Java's "write once, run anywhere" model, move portability into the runtime.

Costs

Achieving high portability can involve trade-offs in performance or access to platform-specific features, and ongoing costs of testing on each target environment.
