Font substitution

Font substitution is the process of using one typeface in place of another when the intended typeface either is not available or does not contain glyphs for the required characters. Font substitution is critical to the correct viewing of documents, especially on systems with different installed font sets, and in web browsing, where a page may specify fonts the visitor does not have.

How substitution works

Operating systems and applications maintain substitution tables or matching rules that select a replacement font with a similar appearance and, ideally, compatible metrics, so that page layout and line breaks are preserved. On the web, CSS font stacks list a sequence of preferred families ending in a generic family (such as serif or sans-serif), and the browser uses the first available match. If a font exists but lacks a particular character, a process called font fallback draws that character from another font instead.

Problems

Poor substitution can alter a document's appearance, change text length and pagination, or produce inconsistent typography within a single line. Metric-compatible open-source fonts such as Liberation Sans and Croscore fonts were developed specifically to substitute transparently for common proprietary fonts like Arial and Times New Roman.
