Timsort

Timsort is a hybrid, stable sorting algorithm derived from merge sort and insertion sort, designed to perform well on many kinds of real-world data. It was implemented by Tim Peters in 2002 for use in the Python programming language, and has been Python's standard sort since version 2.3. It is also used to sort arrays of non-primitive types in Java SE 7, the Android platform, GNU Octave, V8, Swift and Rust.

Operation

Timsort finds subsequences of the data that are already ordered — runs — and uses them to sort the remainder more efficiently. A run that is too short is extended using insertion sort to a minimum length (minrun, typically 32–64). Runs are then merged pairwise, in an order chosen to keep the stack of pending runs balanced, using a modified merge step that can "gallop" through one run when many consecutive elements come from it.

Complexity

In the worst case Timsort performs O(n log n) comparisons and takes O(n) space; on already-sorted or nearly sorted data it degrades gracefully to O(n). It is an adaptive, stable sort.

History and analysis

In 2015, researchers formally verifying the Java implementation found that the invariants chosen for the merge stack were insufficient, allowing an array-bound violation for very large inputs; the issue led to adjusted invariants in both the Java and Python implementations. A 2018–2019 line of work further characterised the algorithm as an instance of "stacksort"-style merging and refined its analysis.
