Hexagonal number

A hexagonal number is a figurate number. The nth hexagonal number hn is the number of distinct dots in a pattern of dots consisting of the outlines of regular hexagons with sides up to n dots, when the hexagons are overlaid so that they share one vertex. The formula for the nth hexagonal number is hn = 2n2 − n = n(2n − 1).

Sequence

The first few hexagonal numbers are 1, 6, 15, 28, 45, 66, 91, 120, 153, 190, 231, ... Every hexagonal number is a triangular number — specifically the (2n − 1)th triangular number — but only every other triangular number (the odd-positioned ones) is hexagonal.

Properties

Every even perfect number is hexagonal, given by 2p−1(2p − 1) where 2p − 1 is a Mersenne prime. Hexagonal numbers should not be confused with centered hexagonal numbers, which model hexagonal packings of dots around a central dot.
