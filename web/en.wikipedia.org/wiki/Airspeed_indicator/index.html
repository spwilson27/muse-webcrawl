Airspeed indicator

The airspeed indicator (ASI) or airspeed gauge is a flight instrument indicating the airspeed of an aircraft in kilometres per hour (km/h), knots (kn), miles per hour (mph), or metres per second (m/s). It is one of the six basic instruments in the standard cockpit layout and works by measuring the difference between pitot pressure and static pressure supplied by the pitot-static system.

Operation

Inside the sealed instrument case, a thin diaphragm expands or contracts as pitot (ram air) pressure changes relative to the static pressure surrounding the case. Linkage converts this movement into needle deflection. Because the instrument responds to dynamic pressure, it reads indicated airspeed, which is accurate only at standard sea-level density; true airspeed increases with altitude for the same indication.

Colour markings

Standard colour coding includes a white arc for the flap operating range, a green arc for the normal operating range, a yellow arc for the caution range (smooth air only), and a red line marking VNE, the never-exceed speed. Multi-engine aircraft add a blue line for the best single-engine rate-of-climb speed (VYSE). Blockage of the pitot tube — for example by icing — is a classic cause of erroneous readings and features in several accident investigations.
