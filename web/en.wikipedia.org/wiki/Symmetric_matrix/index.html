Symmetric matrix

In linear algebra, a symmetric matrix is a square matrix that is equal to its transpose. Formally,

A is symmetric ⟺ A = AT

Because equal matrices have equal entries, this is equivalent to

aij = aji for all indices i and j,

so the entries of a symmetric matrix are symmetric with respect to the main diagonal. If the entries are taken from a field whose characteristic is not 2, then a symmetric matrix is determined by its entries on and above the diagonal.

Examples

The following 3 × 3 matrix is symmetric:

A = ⎡ 1  7  3 ⎤
⎢ 7  4  5 ⎥
⎣ 3  5  0 ⎦

Every square diagonal matrix is symmetric, since all off-diagonal elements are zero. Similarly, in characteristic different from 2, each diagonal element of a skew-symmetric matrix must be zero, since each is its own negative.

Properties

Basic properties

  • The sum and difference of two symmetric matrices is again symmetric.
  • This is not always true for the product: given symmetric matrices A and B, then AB is symmetric if and only if A and B commute.
  • For any integer n, An is symmetric if A is symmetric.
  • If A−1 exists, it is symmetric if and only if A is symmetric.

Decomposition into symmetric and skew-symmetric

Any square matrix can uniquely be written as the sum of a symmetric matrix and a skew-symmetric matrix: X = (X + XT)/2 + (X − XT)/2. This decomposition is known as the Toeplitz decomposition.

Symmetric matrices and quadratic forms

A quadratic form in real variables corresponds uniquely to a symmetric matrix whose entries are the coefficients of the form. An important property is the spectral theorem: every symmetric matrix with real entries is orthogonally diagonalizable, and all of its eigenvalues are real. This is a cornerstone of the theory of quadratic forms and of applications such as principal component analysis.

Complex symmetric matrices

A complex symmetric matrix can be diagonalized by a unitary matrix: this is the Autonne–Takagi factorization. In contrast to real symmetric matrices, complex symmetric matrices need not be diagonalizable by similarity, and their eigenvalues need not be real.
