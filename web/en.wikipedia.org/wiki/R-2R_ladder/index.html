R-2R ladder

An R-2R ladder is a resistor network used in digital-to-analog converters. It uses only two resistor values, R and 2R, arranged in a repeating ladder structure so that each digital bit contributes a binary-weighted current or voltage to the output.

Operation

Each bit controls a switch that connects a ladder node either to a reference voltage or to ground. Because the equivalent resistance looking into successive sections remains constant, the contribution of each bit halves as it moves away from the output. This produces an analog value proportional to the binary input word.

Advantages and limits

The design is attractive in integrated circuits because matched resistors with a simple ratio are easier to fabricate than many precisely graded values. Accuracy still depends on resistor matching, switch resistance and settling time. R-2R ladders are used in multiplying DACs, audio converters and embedded control systems.

The network is a practical application of binary weighting and Thevenin equivalent circuits.
