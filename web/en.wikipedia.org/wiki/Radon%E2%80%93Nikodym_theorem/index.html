Radon–Nikodym theorem

Radon–Nikodym theorem
FieldMeasure theory
Named afterJohann Radon; Otto M. Nikodym
Proved1913 (Radon); 1930 (Nikodym)

In mathematics, the Radon–Nikodym theorem is a fundamental result in measure theory. If a measure ν is absolutely continuous with respect to a σ-finite measure μ on the same measurable space, then there exists a measurable function f — the Radon–Nikodym derivative dν/dμ — such that ν of any measurable set equals the integral of f over that set with respect to μ.

Applications

The theorem generalises the idea of a probability density function: if a probability measure is absolutely continuous with respect to another, its density is the Radon–Nikodym derivative. Conditional expectation in probability theory is defined through the theorem, and it is central to mathematical finance, where changes of measure (for example under Girsanov's theorem) use it.

History

Johann Radon proved a special case for Euclidean space in 1913; Otto Nikodym gave the general measure-theoretic proof in 1930.
