Code point

From Wikipedia, the free encyclopedia

A code point is a numerical position in a coded character set.

A code point (or code position) is a particular position in a table of characters within a coded character set. More precisely, in character encoding terminology, a code point is the numerical value assigned to a specific character (or to a reserved or non-character slot) in a codespace—the range of integers available to a character set.

In Unicode

In Unicode, code points are written in hexadecimal and prefixed with "U+", for example U+0041 for the letter "A" and U+1F600 for a grinning face emoji. The Unicode codespace spans U+0000 to U+10FFFF, divided into 17 planes of 65,536 code points each. The first, the Basic Multilingual Plane (BMP), contains nearly all commonly used characters; higher planes hold historic scripts, rare characters, and emoji.

Not every code point is assigned to a character: some are reserved for future use, some are permanently non-characters, and the range U+D800–U+DFFF is reserved for surrogate halves used by the UTF-16 encoding. A code point is an abstraction distinct from its encoded form: UTF-8 represents a code point as one to four bytes, UTF-16 as one or two 16-bit code units, and UTF-32 as a single 32-bit unit.

In other encodings

The concept predates Unicode. In ASCII, "A" occupies code point 65 (0x41) of a 128-point codespace; in ISO 8859 and Windows code pages, code points run from 0 to 255. Confusion between code points, code units, bytes, and user-perceived characters (grapheme clusters) is a common source of software bugs, since a single visible character may consist of several code points (for example, a base letter plus combining accents).
