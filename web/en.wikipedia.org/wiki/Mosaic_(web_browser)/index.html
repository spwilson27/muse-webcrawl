Mosaic (web browser)

From Wikipedia, the free encyclopedia
[Image: An early-1990s computer screen showing the Mosaic browser with inline images on a grey page]

Mosaic is one of the first popular graphical web browsers, credited with popularising the World Wide Web. It was developed at the National Center for Supercomputing Applications (NCSA) at the University of Illinois Urbana-Champaign, led by Marc Andreessen and Eric Bina, and released in 1993 (version 1.0 in November 1993).

Mosaic's innovations — displaying images inline with text rather than in separate windows, a point-and-click interface on ordinary computers (Unix, then Windows and Mac), and easy installation — made the web accessible beyond researchers; web traffic and the number of websites exploded in 1993–94 ('Year of the Web').

Legacy

Andreessen co-founded Netscape in 1994, whose Navigator browser was built by much of the Mosaic team and commercialised the web; Microsoft licensed Mosaic code (via Spyglass) as the basis of Internet Explorer. NCSA Mosaic itself was discontinued in 1997, eclipsed by its descendants.

The browser's style — grey pages, blue underlined links, inline images — set the template of the early web, and its release is a standard marker for the web's transition from academic tool to mass medium.
