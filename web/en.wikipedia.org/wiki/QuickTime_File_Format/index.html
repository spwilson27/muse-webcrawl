QuickTime File Format

QuickTime File Format
Filename extension: .mov, .qt
Developed by: Apple Inc.
Initial release: 1991
Type of format: Container format

The QuickTime File Format (QTFF) is a computer file format used natively by Apple's QuickTime framework. Files in the format usually carry the extension .mov and store digital video, audio, and other media in a hierarchical structure of data blocks called atoms.

Design

A QuickTime file is organised as a tree of atoms, each beginning with a header giving its size and a four-character type code. Top-level atoms include ftyp (file type), mdat (the media data itself), and moov (the "movie" atom), which holds the metadata — tracks, durations, edit lists, and references to where each sample of media lives in the file. Because the metadata is separate from the media data, movies can be edited non-destructively and can reference media stored in other files.

Relationship to MP4

The QuickTime format served as the basis for the MPEG-4 Part 14 (MP4) container, standardised by MPEG in 2001–2003. The two formats are closely related: MP4 adopted the atom-based structure with modifications, and many files are largely interchangeable with a change of declared brand in the ftyp atom.

Use

The .mov format remains a standard working and delivery format in professional video production, where it commonly wraps codecs such as ProRes and DNxHD as well as H.264 and uncompressed video. Many digital cameras also record video as .mov files.
