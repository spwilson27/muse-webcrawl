ISO 11783

TitleTractors and machinery for agriculture and forestry — Serial control and communications data network
Known asISOBUS
Based onCAN bus (SAE J1939)

ISO 11783, known in the agricultural industry as ISOBUS, is an international standard that specifies a serial control and communications data network for tractors and agricultural and forestry machinery. It allows implements, tractors and terminals from different manufacturers to interoperate over a common CAN-based network.

Overview

The standard is published in multiple parts covering the physical layer, data link and network layers, diagnostic services, and the virtual terminal — a standardized display through which any implement can present its user interface on a single in-cab screen. It also defines task controllers for precision farming functions such as section control and variable rate application.

Adoption

Conformance testing and certification are coordinated by the Agricultural Industry Electronics Foundation (AEF), whose ISOBUS database lists certified products and their supported functionalities.
