Root cause analysis

Root cause analysis (RCA) is a method of problem solving used for identifying the root causes of faults or problems. A factor is considered a root cause if removal thereof prevents the final undesirable outcome from recurring, whereas a causal factor affects an event's outcome but is not a root cause.

Approach

RCA is typically performed after an incident in fields such as manufacturing, healthcare, aviation, and software engineering. The aim is not merely to treat the symptoms of a failure but to correct or eliminate the underlying causes so the problem does not happen again. Common techniques include the "Five Whys", Ishikawa (fishbone) diagrams, fault tree analysis, Pareto analysis, and barrier analysis.

Process

A typical RCA involves defining the problem, collecting data and a timeline of events, identifying possible causal factors, determining which of them are root causes, and recommending corrective actions, followed by verification that those actions are effective. In patient safety, formal RCA frameworks are mandated in many health systems after serious adverse events.
