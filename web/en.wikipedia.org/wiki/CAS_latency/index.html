CAS latency

Column address strobe latency, or CL, is the delay in clock cycles between the READ command and the moment data is available on a dynamic random-access memory (DRAM) module. In asynchronous DRAM, the interval is specified in nanoseconds; in synchronous DRAM (SDRAM), it is specified in clock cycles.

Timing

When a memory controller requests data, it activates a row, then issues a read command asserting the column address strobe. The data appears after the CAS latency elapses. Memory modules are marketed with timings such as "CL16" or sequences like 16-18-18-38, of which CL is the first number. Because clock periods shrink as memory speeds rise, a DDR4-3200 CL22 module and a DDR3-1600 CL11 module have similar absolute latencies of about 13.75 nanoseconds.

Effect on performance

Real latency depends on both CAS latency and clock frequency: latency (ns) = CL × 2000 / (data rate in MT/s). CAS latency is one of several timings (alongside tRCD, tRP and tRAS) that influence memory performance, though bandwidth often matters more in practice.
