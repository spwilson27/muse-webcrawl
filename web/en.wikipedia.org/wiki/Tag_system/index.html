Tag system

A tag system is a deterministic computational model introduced by Emil Leon Post in 1943 as a simple model of computation, related to his earlier Post canonical systems. Tag systems operate on strings of symbols and are of interest in computability theory because sufficiently general tag systems are Turing complete.

Definition

An m-tag system is defined by an alphabet of symbols, a deletion number m (a positive integer), and a set of production rules, one for each symbol. Computation proceeds on a string as follows: read the first symbol of the string, append the production associated with that symbol to the end of the string, then delete the first m symbols. The process repeats until the string becomes shorter than m, the string becomes empty, or a special halting symbol is read.

History and significance

Post hoped tag systems would yield an approach to the decision problem, but in 1943 he could prove neither undecidability nor decidability for the general class. In 1961 Marvin Minsky showed that tag systems with deletion number 2 are universal — capable of simulating any Turing machine — resolving the question: the halting problem for 2-tag systems is undecidable. Simpler variants, such as cyclic tag systems (a restriction in which productions are used in a fixed rotation), were later shown by Matthew Cook to support universal computation and were used in the proof that the elementary cellular automaton Rule 110 is universal.

Example

Consider a 3-tag system with alphabet {a, b, c} and productions a → bc, b → a, c → aaa. Starting from the string baa: read b, append a, delete three symbols, giving a, which is shorter than 3, so the computation halts.
