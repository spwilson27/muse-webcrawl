TACACS

Terminal Access Controller Access-Control System (TACACS) is a family of related protocols handling remote authentication and related services for network access control through a centralised server. The original TACACS protocol, created in 1984, was used for communicating with an authentication server, common in older UNIX networks.

History and versions

TACACS was developed for the ARPANET-era MILNET and later adopted by Cisco for its network equipment. An extended version, XTACACS (1990), added accounting and auditing features. Cisco then developed TACACS+, a largely new protocol described in RFC 8907, which separates authentication, authorisation and accounting (AAA) into independent functions and encrypts the entire packet body, unlike the original protocol, which used UDP and left most traffic unencrypted.

Comparison with RADIUS

TACACS+ is often compared with RADIUS. TACACS+ uses TCP (port 49), encrypts the whole payload, and separates the AAA functions, making it popular for controlling administrative access to routers and switches; RADIUS, which uses UDP and encrypts only the password, is more common for end-user network access such as VPNs and Wi-Fi.
