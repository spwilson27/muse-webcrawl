Pascal is an imperative and procedural programming language, designed by Niklaus Wirth in 1968–69 and published in 1970, as a small, efficient language intended to encourage good programming practices using structured programming and data structuring. It is named after the French mathematician, philosopher and physicist Blaise Pascal — the same namesake as the physical principle of Pascal's law and the arithmetical array Pascal's triangle, which are separate topics.

History

Pascal grew out of Wirth's work on ALGOL W and Euler. It became the dominant teaching language in universities through the 1970s and 1980s, spread on microcomputers by UCSD Pascal and Borland's Turbo Pascal (1983), and was standardised as ISO 7185. Much of the early Macintosh system software and applications such as TeX's development environment used Pascal implementations.

Language and descendants

Pascal features strong static typing, records, sets, enumerations, pointers and nested procedures, all within a readable block structure of begin … end. Its successor line ran through Modula-2 and Oberon, while object-oriented dialects — Object Pascal, embodied in Borland Delphi and the open-source Free Pascal/Lazarus ecosystem — kept the language in commercial use for decades.
