Three-tier architecture

Three-tier architecture is a software architecture pattern in which an application is organised into three logical and physical computing tiers: the presentation tier, the application (logic) tier, and the data tier. It is a widely used form of multitier architecture for client–server applications, particularly web applications.

Tiers

The presentation tier is the user interface and communication layer, presenting information to the user and accepting input. The application tier (business logic tier) processes information according to the application's rules, coordinating with both other tiers. The data tier stores and manages information, typically using a database management system, and keeps data independent of the application logic.

Benefits

Separating tiers allows each to be developed, scaled, and maintained independently, improves security by preventing direct client access to the database, and lets developers use different technologies for each tier.
