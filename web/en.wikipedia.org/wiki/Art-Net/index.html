Art-Net

From Wikipedia, the free encyclopedia


Stage lighting controlled via Art-Net over Ethernet

Art-Net is a royalty-free communications protocol for transmitting the DMX512-A lighting control protocol and Remote Device Management (RDM) protocol over the User Datagram Protocol (UDP) of the Internet Protocol suite. It is typically used to send lighting control data between a controller and fixtures or dimmers across standard Ethernet networks.

History

Art-Net was developed by Wayne Howell of Artistic Licence Holdings Ltd as an extension of DMX over Ethernet. Art-Net I, released in 1998, used broadcast addressing and was limited to 255 universes. Subsequent versions added unicast transmission, vastly increased the number of addressable universes (Art-Net 3 permits 32,768 universes, and Art-Net 4 reorganized addressing into a hierarchical scheme), and added support for RDM and for the sACN-style synchronization.

Protocol details

Art-Net packets use UDP port 6454. The primary data packet, ArtDmx, carries a single DMX universe of up to 512 channels. Discovery of nodes on the network is performed using ArtPoll and ArtPollReply packets. Art-Net 4 allows nodes to be managed and configured through a web interface, and allows the mixing of multiple protocols such as sACN and Art-Net on the same network.
