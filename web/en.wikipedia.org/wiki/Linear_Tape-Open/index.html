Linear Tape-Open

Linear Tape-Open (LTO), also known as Ultrium, is a magnetic tape data storage technology developed in the late 1990s as an open-standards alternative to the proprietary tape formats then available. It was developed and initiated by the LTO Consortium, originally formed by Hewlett Packard Enterprise (then Hewlett-Packard), IBM, and Quantum; the format licences the technology to other manufacturers.

History and generations

LTO Ultrium cartridges were first released in 2000 with a native capacity of 100 GB. Successive generations have roughly doubled capacity each time; LTO-9 (2021) stores 18 TB native (45 TB compressed), and the consortium published a roadmap extending to LTO-14. Drives typically read two generations back and write one generation back. Data is written in linear serpentine tracks along the tape using multiple head elements, and cartridges contain a small amount of contactless "LTO-CM" memory storing usage and format information.

Features

From LTO-3 onward the format supports WORM (write once, read many) cartridges for regulatory compliance; LTO-4 added hardware encryption (AES-256); and LTO-5 introduced the Linear Tape File System (LTFS), which lets a tape volume appear as a file system with drag-and-drop access. LTO remains widely used for backup and archival storage because of its low cost per terabyte, high streaming throughput, and long media life.
