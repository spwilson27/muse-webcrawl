Apache Tomcat is a free and open-source implementation of the Jakarta Servlet, Jakarta Pages, Jakarta Expression Language and WebSocket technologies, developed by the Apache Software Foundation. Originally created at Sun Microsystems by James Duncan Davidson and donated to Apache in 1999, Tomcat is one of the most widely used Java web servers and servlet containers.

Components

Tomcat comprises Catalina (the servlet container), Coyote (the HTTP connector) and Jasper (the JSP engine). It powers large-scale, mission-critical web applications across many industries and is frequently embedded in frameworks such as Spring Boot. Major modern releases include Tomcat 9 (Servlet 4.0) and Tomcat 10/10.1, which implement the Jakarta EE 9/10 specifications with the javax-to-jakarta package renaming, and Tomcat 11 for Jakarta EE 11.
