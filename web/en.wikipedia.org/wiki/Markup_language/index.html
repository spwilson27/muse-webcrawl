Markup language

A markup language is a system for annotating a document in a way that is syntactically distinguishable from the text, so that the annotations can be processed to control the presentation or structure of the content. The term derives from the practice of "marking up" manuscripts with editorial instructions.

Types

Markup is commonly divided into presentational markup (specifying appearance, as in word processors), procedural markup (instructions to processing software, as in troff or TeX), and descriptive or semantic markup, which labels parts of a document by their meaning — the approach of SGML and HTML.

Examples

Well-known markup languages include HTML for web pages, XML for general structured data, Markdown for lightweight formatting, LaTeX for typesetting, and TEI for scholarly texts.
