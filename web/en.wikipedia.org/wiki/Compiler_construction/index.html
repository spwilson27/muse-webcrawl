Compiler construction

From Wikipedia, the free encyclopedia

The classic phases of compilation: analysis, intermediate representation, and code generation

Compiler construction is the area of computer science concerned with the theory and practice of designing and implementing compilers — programs that translate source code written in one programming language into another language, usually machine code or a lower-level language. The field draws on formal language theory, algorithms, and computer architecture, and it is a standard subject in undergraduate computer science curricula.

Structure of a compiler

A compiler is conventionally divided into a front end, which analyses the source program, and a back end, which synthesizes the target program, often with an intermediate representation (IR) between them.

Front end

  • Lexical analysis — a scanner or lexer groups characters into tokens such as identifiers, keywords, and operators.
  • Syntax analysis — a parser checks the token stream against the grammar of the language and builds a parse tree or abstract syntax tree (AST), using techniques such as LL and LR parsing.
  • Semantic analysis — type checking and other context-sensitive checks are performed, with information stored in a symbol table.

Middle end and back end

  • Intermediate code generation — the AST is translated into an IR such as three-address code or static single assignment (SSA) form.
  • Optimization — machine-independent transformations (constant folding, dead-code elimination, loop optimizations) improve the IR.
  • Code generation — target machine instructions are selected, registers allocated, and instructions scheduled.

Tools and theory

Compiler writers use generator tools — historically Lex and Yacc, and their modern successors such as Flex and Bison, or frameworks like ANTLR and LLVM — to build scanners and parsers from formal grammars. The theory behind these tools rests on automata theory and the Chomsky hierarchy: regular expressions describe tokens, and context-free grammars describe syntax.

History

The first compilers were written in the 1950s, notably Grace Hopper's A-0 system and the FORTRAN compiler led by John Backus at IBM in 1957, which demonstrated that compiled code could rival hand-written assembly. The 1960s and 1970s brought formal parsing theory and influential systems such as ALGOL. Aho, Sethi, and Ullman's textbook Compilers: Principles, Techniques, and Tools (1986), the "Dragon Book", became the field's best-known reference. Modern construction emphasizes retargetable back ends, just-in-time compilation, and verified compilers such as CompCert.
