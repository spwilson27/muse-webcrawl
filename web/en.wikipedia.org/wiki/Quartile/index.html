Quartile

In statistics, quartiles are the values that divide a data set into quarters. When the data are arranged in order, the three quartiles are:

  • The first quartile (Q1), also called the lower quartile, below which 25% of the data fall.
  • The second quartile (Q2), which is the median, below which 50% of the data fall.
  • The third quartile (Q3), also called the upper quartile, below which 75% of the data fall.

A box plot summarises a data set using its quartiles.

Interquartile range

The difference between the third and first quartiles, Q3 − Q1, is called the interquartile range (IQR). It is a robust measure of statistical dispersion, used to identify outliers: observations lying more than 1.5 IQRs below Q1 or above Q3 are commonly flagged as outliers.

Methods of calculation

Several methods exist for computing quartiles from finite samples, differing in how they interpolate between data points; they were catalogued in a widely cited paper by Hyndman and Fan (1996) and are implemented with different defaults in statistical software packages. For large data sets the methods agree closely.
