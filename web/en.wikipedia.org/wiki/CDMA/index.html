Code-division multiple access

Code-division multiple access (CDMA) is a channel access method used by various radio communication technologies. It allows several transmitters to send information simultaneously over a single communication channel by assigning each user a unique spreading code.

Principle

CDMA is a form of spread-spectrum signalling: each user's data is multiplied by a fast pseudo-random code sequence, spreading the signal over a wide bandwidth. The receiver, knowing the code, correlates the received signal to recover the data while other users' signals appear as noise. Tight power control is essential to overcome the near–far problem.

Uses

CDMA underpinned the IS-95 (cdmaOne) and CDMA2000 mobile phone standards, the UMTS/W-CDMA 3G system, and GPS satellite navigation signals.
