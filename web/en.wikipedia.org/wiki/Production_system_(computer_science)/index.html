Production system (computer science)

A production system (or production rule system) is a computer programme model consisting of a set of condition–action rules ("productions"), a working memory of facts, and an inference engine that repeatedly matches rule conditions against working memory and executes the actions of selected rules. Production systems are a foundational formalism in artificial intelligence, especially for expert systems.

Architecture

The engine runs a recognise–act cycle: it computes the conflict set of rules whose conditions are satisfied, selects one or more by a conflict-resolution strategy, and fires them, modifying working memory, which may enable further rules. Data-driven systems work forward from facts to conclusions (forward chaining), while goal-driven systems reason backward from a goal (backward chaining), as in logic programming.

History

The model derives from Emil Post's production systems of the 1940s, which are Turing-complete. Allen Newell and Herbert Simon used production systems for cognitive modelling; the OPS5 language and the Rete matching algorithm (Charles Forgy, 1979) made rule systems efficient enough for large expert systems such as XCON/R1, which configured VAX computers at DEC. Modern descendants include business rule engines (e.g., Drools, CLIPS) and cognitive architectures such as Soar and ACT-R.
