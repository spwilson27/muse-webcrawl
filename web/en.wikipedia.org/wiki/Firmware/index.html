Firmware

Firmware is permanent software programmed into a device's read-only or flash memory.

Firmware is software that provides low-level control of a device's hardware. It is stored in non-volatile memory — historically ROM, PROM and EPROM, today usually flash memory — and supplies the instructions a device needs to start up, communicate with other hardware, and perform its basic functions. Familiar examples include the BIOS or UEFI firmware of a personal computer, the embedded software in routers, printers, washing machines, digital cameras, and the controller firmware inside solid-state drives.

Characteristics

Firmware sits between hardware and higher-level software: it abstracts the hardware for operating systems and applications, initialises components at power-on, and often implements standard interfaces. The term was coined by Ascher Opler in 1967 for microcode stored in writable control store, "firm" because it was harder to change than software but easier than hardware. Microcode in modern processors remains a form of firmware and can be updated to fix errata or security flaws.

Firmware updates

Because most firmware now resides in rewritable flash, manufacturers issue updates to fix bugs, patch vulnerabilities, add features or improve compatibility. Updating ("flashing") carries a small risk: an interrupted update can render a device inoperable ("bricked"), so many devices implement recovery modes or dual-bank (A/B) update schemes. In consumer usage, "firmware" is sometimes applied loosely to the whole operating system image of phones and embedded devices.

Security

Firmware operates with high privilege and below the visibility of most security tools, making it an attractive target: malware such as LoJax and MoonBounce has persisted in UEFI firmware across operating-system reinstalls. Defences include secure boot with signed firmware images, measured boot with TPM attestation, and vendor update mechanisms such as the Linux Vendor Firmware Service (fwupd).

Open firmware

Projects such as coreboot and Libreboot provide free-software replacements for proprietary PC firmware, and open-source firmware exists for routers (OpenWrt), keyboards, and many embedded devices, giving users control over code that would otherwise be opaque.
