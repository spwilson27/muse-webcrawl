Microsoft Solitaire
Developer: Wes Cherry / Microsoft
First release: 1990 (Windows 3.0)
Genre: Card game (Klondike)
The classic Windows Klondike solitaire layout

Microsoft Solitaire is a computer game included with Microsoft Windows, based on the Klondike patience card game. It was first included in Windows 3.0 in 1990. The game was developed by Microsoft intern Wes Cherry, and its card faces were designed by Susan Kare. Microsoft intended Solitaire to "soothe people intimidated by the operating system" and to teach users how to use a mouse — dragging and dropping cards mimics basic file manipulation.

History

Solitaire shipped with every version of Windows from 3.0 through Windows 7. It was removed as a built-in component in Windows 8 but returned as part of the Microsoft Solitaire Collection in Windows 10, adding FreeCell, Spider, TriPeaks and Pyramid variants with daily challenges and optional advertising. Microsoft has celebrated the game as one of the most played video games of all time, claiming over 500 million players in the preceding decade in 2020. In 2019 it was inducted into the World Video Game Hall of Fame.

Gameplay

The player builds four foundation piles from ace to king, moving cards in the tableau in descending order with alternating colours. The familiar cascading card animation when a game is won became an iconic feature of early personal computing. The Vegas scoring mode keeps a cumulative score across games, simulating wagering.
