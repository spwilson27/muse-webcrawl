Autoregressive model

In statistics, econometrics, and signal processing, an autoregressive (AR) model is a representation of a type of random process; as such, it is used to describe certain time-varying processes in nature, economics, behavior, etc. The autoregressive model specifies that the output variable depends linearly on its own previous values and on a stochastic term (an imperfectly predictable term); thus the model is in the form of a stochastic difference equation.

Definition

The notation AR(p) indicates an autoregressive model of order p. The AR(p) model is defined as

Xt = c + φ1Xt−1 + φ2Xt−2 + ⋯ + φpXt−p + εt

where φ1, …, φp are the model parameters, c is a constant, and εt is white noise. Using lag operator notation, the model can be written as φ(L)Xt = c + εt.

Stationarity

An AR(p) process is (weakly) stationary if the roots of the characteristic polynomial φ(z) = 0 lie outside the unit circle. For an AR(1) model this reduces to the condition |φ1| < 1. When φ1 = 1 the process is a random walk, which is non-stationary.

Estimation and applications

Parameters may be estimated by least squares, maximum likelihood, or the Yule–Walker equations, which exploit the autocorrelation structure of the process. Together with the moving-average (MA) model, the AR model forms the basis of the ARMA and ARIMA families used for forecasting economic series, speech processing (linear predictive coding), and control engineering.
