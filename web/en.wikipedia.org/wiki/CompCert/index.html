CompCert

CompCert compiles a large subset of C with a machine-checked correctness proof.

CompCert is a formally verified optimizing compiler for a large subset of the C programming language (intended to be compatible with the C99 and C11 standards) that targets PowerPC, ARM, RISC-V and x86 architectures. The compiler is developed by Xavier Leroy and colleagues at Inria, and is written and proved correct in the Coq proof assistant.

Verification

The central theorem of CompCert states that the generated assembly code behaves exactly as prescribed by the semantics of the source C program: for any program that does not go wrong, the observable behaviour of the compiled code is one of the behaviours allowed by the source semantics. This eliminates whole classes of compiler-introduced bugs, in contrast to conventional compilers, in which testing campaigns using tools such as Csmith have found hundreds of defects.

Use

CompCert is aimed at safety- and mission-critical embedded software, such as avionics and nuclear plant control systems, where it can support certification regimes including DO-178C. It is distributed under a proprietary licence for commercial use by AbsInt, with source available for research and evaluation. Its performance is competitive with GCC at moderate optimisation levels.

History

The project began in the early 2000s as part of research on formal methods for critical software. CompCert's development team received the ACM Software System Award in 2021 and the ACM SIGPLAN Programming Languages Software Award, recognising formally verified compilation as a practical technology.
