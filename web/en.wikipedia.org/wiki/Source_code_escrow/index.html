Source code escrow

Source code escrow is the deposit of the source code of software into an account held by a third party escrow agent. Escrow is typically requested by a party licensing software (the licensee), to ensure maintenance of the software instead of abandonment or orphaning that could happen in the event of the software developer going bankrupt or failing to maintain and update the software as promised in the software license agreement.

Purpose

Businesses that depend on critical proprietary software face a risk: if the vendor ceases trading, is acquired, or discontinues the product, the licensee may be left with executable code it cannot maintain or modify. An escrow agreement mitigates this by specifying release conditions — such as the vendor's insolvency, breach of maintenance obligations, or discontinuation of support — under which the deposited materials are released to the licensee so it can continue to maintain the software for its own use.

Deposited materials

A useful deposit goes beyond raw source code. Agreements typically require build instructions, documentation, lists of compilers and libraries and their versions, encryption keys, database schemas, and sometimes third-party components and development tools. Escrow agents may offer verification services ranging from simple inventory checks to full verification, in which the agent actually builds the software from the deposit to confirm it produces a working copy of the product.

Parties and agreements

The arrangement commonly involves three parties: the software developer (depositor), the licensee (beneficiary), and the escrow agent. Agreements may be negotiated for a single beneficiary or as multi-beneficiary arrangements covering many licensees of the same product. Open-source software largely removes the need for escrow, since the source code is already available to users.
