Web mapping

From Wikipedia, the free encyclopedia

A typical interactive web map interface.

Web mapping or online mapping is the process of using, creating, and distributing maps on the World Wide Web, usually through a web browser. A web map is both served and consumed via the web, allowing users to pan, zoom, and toggle layers interactively. Web mapping is built on geographic information systems (GIS) technology but delivered with the usability patterns of consumer web applications.

History

Early web maps were static images generated on demand; the Xerox PARC Map Viewer (1993) is often cited as the first interactive web mapping application. The launch of Google Maps and Google Earth in 2005 popularised the "slippy map" interface based on pre-rendered map tiles and AJAX techniques, and Google's release of a public API triggered an explosion of map mashups. OpenStreetMap (founded 2004) provided freely editable map data, and libraries such as Leaflet and OpenLayers made custom web maps easy to embed.

Technology

Web maps are served as raster tiles (PNG/JPEG images) or, increasingly, vector tiles that are styled client-side for sharper rendering and flexible design. Standards from the Open Geospatial Consortium — WMS (Web Map Service), WFS (Web Feature Service), and WMTS — define how servers deliver map images and geographic features. Client libraries fetch tiles as the user navigates, cache them, and overlay data from APIs in formats such as GeoJSON.

Applications

Web mapping underpins navigation and ride-hailing apps, real-estate and tourism sites, logistics dashboards, journalism and election reporting, environmental monitoring, and government open-data portals. Participatory mapping, in which volunteers contribute local knowledge, is used in disaster response (for example, the Humanitarian OpenStreetMap Team) and urban planning.
