Coupon collector's problem

In probability theory, the coupon collector's problem asks: if each box of a product contains a coupon chosen uniformly at random from n different types, how many boxes must be bought, on average, before a complete set of all n coupons has been collected? The problem is a classical illustration of the geometric distribution and of the analysis of waiting times.

Solution

Let T be the number of trials needed to collect all n coupons. Split the process into stages: once k distinct coupons have been collected, the probability that the next coupon is a new one is (n − k)/n, so the expected waiting time for the next new coupon is n/(n − k). Summing over all stages gives the expected total:

E[T] = n · (1 + 1/2 + 1/3 + … + 1/n) = n · Hn,

where Hn is the n-th harmonic number. Since Hn grows asymptotically like ln n + γ (where γ ≈ 0.5772 is the Euler–Mascheroni constant), the expected number of trials is approximately n ln n + γn + 1/2. For example, with n = 50 coupons the expected number of purchases is about 225.

Variance

The variance of T is the sum of the variances of the independent geometric waiting times for each stage, and is asymptotically (π²/6)n². The distribution of the normalised variable (T − n ln n)/n converges to the Gumbel distribution, so large deviations above the mean are considerably more likely than symmetric intuition might suggest.

Generalisations

Variants of the problem consider coupons drawn with unequal probabilities, collectors who need several copies of each coupon, and groups of collectors pooling their finds. The problem also appears in computer science in the analysis of randomised algorithms, in occupancy problems, and in ecology, where it is related to estimating the number of species in a habitat from samples.
