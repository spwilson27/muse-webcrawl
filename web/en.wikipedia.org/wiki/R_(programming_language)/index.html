R (programming language)

Designed by: Ross Ihaka and Robert Gentleman
First appeared: 1993
Paradigm: Multi-paradigm: functional, object-oriented, imperative
License: GNU GPL
Typing: Dynamic, strong

R is a programming language for statistical computing and data visualization. It has been adopted in data mining, bioinformatics, and data analysis environments. The core R language is augmented by a large number of extension packages, containing reusable code, documentation, and sample data.

R was created by statisticians Ross Ihaka and Robert Gentleman at the University of Auckland, New Zealand, as an implementation of the S programming language developed at Bell Laboratories. It is named partly after its creators' first names and partly as a play on "S". R source code was first released in 1993; version 1.0.0 followed in 2000. Development is now overseen by the R Core Team, and the language is supported by the R Foundation.

Features

R provides a wide variety of statistical techniques (linear and nonlinear modelling, classical statistical tests, time-series analysis, classification, clustering) and graphical techniques. It is highly extensible through packages hosted on the Comprehensive R Archive Network (CRAN), which hosts well over 20,000 packages. Popular ecosystems include the tidyverse (with ggplot2 and dplyr), data.table, and Shiny for interactive web applications. RStudio is a widely used integrated development environment.
