The Common Criteria for Information Technology Security Evaluation (abbreviated as Common Criteria or CC) is an international standard (ISO/IEC 15408) for computer security certification. It provides a framework in which users can specify security requirements, developers can implement and claim security attributes for products, and accredited laboratories can evaluate whether products meet those claims.

Framework

An evaluation is conducted against a Protection Profile or a Security Target document. Confidence in the evaluation is expressed as an Evaluation Assurance Level (EAL) from EAL1, functionally tested, to EAL7, formally verified design and tested; higher EALs demand progressively more rigorous evidence.

Recognition

Under the Common Criteria Recognition Arrangement, participating countries mutually recognise certificates, allowing vendors to have a product evaluated once and accepted in many markets, particularly for government procurement.
