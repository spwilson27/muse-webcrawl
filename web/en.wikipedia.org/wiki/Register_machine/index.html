Register machine

In mathematical logic and theoretical computer science, a register machine is a generic class of abstract machines used in a manner similar to a Turing machine. A register machine consists of a finite number of registers, each capable of holding a non-negative integer of unbounded size, together with a program of instructions that increment a register, decrement a register and test whether it is zero, and control the flow of execution.

Computational power

Despite its simplicity, a register machine with at least two registers is Turing complete: it can simulate any Turing machine, though possibly with exponential slowdown. Register machines were used by Marvin Minsky in his work on the unsolvability of the halting problem and related questions, and are closely related to counter machines and to the later random-access machine model.

Variants

Related models include the counter machine, the pointer machine, and the random-access stored-program (RASP) machine. The Shepherdson–Sturgis register machine formulation is a standard version in textbooks.
