R-U-Dead-Yet

R-U-Dead-Yet, or RUDY, is a denial-of-service attack tool that aims to overwhelm a targeted server using long-form HTTP POST transmissions. The attack was first described in 2010 and works by opening connections to a web server and slowly submitting form data in very small chunks, keeping the connections open for long periods.

Mechanism

RUDY attacks exploit the way web servers handle POST requests. The tool discovers forms on a target website, then sends a POST request with an abnormally large declared Content-Length header. The actual data is transmitted extremely slowly — as little as one byte every several seconds — so the server holds resources waiting for the request body to complete. By opening many such connections, an attacker can exhaust the server's connection pool, preventing it from serving legitimate users. RUDY belongs to the class of "low and slow" application-layer (Layer 7) attacks, alongside tools such as Slowloris.

Mitigation

Defenses include setting timeouts on incomplete requests, limiting the number of connections per client IP address, configuring minimum data-rate thresholds, and deploying web application firewalls or reverse proxies that buffer requests before passing them to origin servers. Web servers such as Apache can be hardened with modules that drop connections whose bodies arrive too slowly.
