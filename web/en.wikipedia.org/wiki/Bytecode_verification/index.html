Bytecode verification

Bytecode verification is the process by which a virtual machine, most notably the Java Virtual Machine (JVM), checks that compiled bytecode is structurally valid and type-safe before it is executed. Verification is a key part of the Java security model, allowing untrusted code to be run safely.

Process

The verifier performs data-flow analysis over each method, checking that operands are of the correct types, that stack operations do not overflow or underflow, that jumps target valid instructions, and that access restrictions are respected. Since Java 6, the StackMapTable attribute allows a simpler, faster type-checking verification.

Purpose

Because bytecode may come from untrusted sources, verification ensures that malformed or malicious code cannot violate the integrity of the runtime, forge pointers, or bypass access controls.
