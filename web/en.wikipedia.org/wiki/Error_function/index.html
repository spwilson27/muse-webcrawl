Error function

In mathematics, the error function (also called the Gauss error function), often denoted by erf, is a special function defined by the integral erf(x) = (2/√π) ∫0x e−t² dt. It is an entire function of the complex variable and cannot be expressed in terms of elementary functions.

Properties

The error function is an odd function, erf(−x) = −erf(x), with erf(0) = 0 and erf(x) → 1 as x → ∞. Its derivative is (2/√π) e−x². The complementary error function is erfc(x) = 1 − erf(x), and the imaginary error function erfi is obtained by rotating the argument into the complex plane.

Applications

The error function arises naturally in probability, statistics and partial differential equations. It is directly related to the cumulative distribution function of the normal distribution, so it appears in the theory of measurement errors; it also gives solutions of the heat equation with step-function initial conditions, and hence occurs in diffusion problems throughout physics and engineering. Numerical values are computed using series expansions, continued fractions and rational approximations tabulated since the nineteenth century.
