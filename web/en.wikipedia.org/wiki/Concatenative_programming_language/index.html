Concatenative programming language

A concatenative programming language is a point-free computer programming language in which all expressions denote functions, and the juxtaposition of expressions denotes function composition. Concatenative programming replaces function application, which is common in other languages, with function composition as the default way to build subroutines. Most concatenative languages are stack-based.

Characteristics

In a concatenative language, programs are sequences of words that transform an implicit stack. For example, in many such languages the program 5 4 + pushes 5 and 4 onto the stack and then applies the word +, leaving 9. Because composition is associative and expressions do not name variables, refactoring and algebraic reasoning about programs are unusually straightforward.

Examples

Well-known concatenative languages include Forth, PostScript, Joy, Factor, and Cat. Forth and PostScript are widely used in embedded systems and document rendering respectively.

Properties

Concatenative languages support a distinctive style in which new words are defined by composing existing ones, and combinators manipulate whole program fragments. Critics note that stack-based code can become difficult to read when data flow is complex; advocates point to its uniformity, interactivity, and ease of implementation.
