IP address spoofing

In computer networking, IP address spoofing or IP spoofing is the creation of Internet Protocol (IP) packets with a false source IP address, for the purpose of impersonating another computing system. IP spoofing can also be used legitimately, for example in testing and in some load-balancing and redundancy configurations.

Background

The basic protocol for sending data over the Internet and most other computer networks is the Internet Protocol. The header of each IP packet contains, among other things, the source address of the packet, which is normally the address of the computer from which the packet was sent. Nothing in the protocol itself guarantees this address is genuine, so a sender can craft packets with an arbitrary source address.

Applications and attacks

Spoofing is a building block of several attacks. In denial-of-service and distributed denial-of-service attacks, spoofed source addresses hide the attacker and defeat traceback. In reflection and amplification attacks, requests are sent to third-party servers with the victim's address spoofed as the source, so the responses flood the victim. Spoofing has also been used to bypass IP-address-based authentication, a weakness famously exploited in the 1994 attack attributed to Kevin Mitnick against Tsutomu Shimomura's machines.

Defense

The main defense is ingress and egress filtering at network borders — routers drop packets arriving from outside with source addresses that belong inside, and vice versa, as recommended in BCP 38. Packet filtering, cryptographic authentication at higher layers (such as IPsec and TLS), and abandoning address-based trust also mitigate the problem.
