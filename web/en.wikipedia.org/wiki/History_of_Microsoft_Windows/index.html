History of Microsoft Windows

History of Microsoft Windows
First release: Windows 1.0, 20 November 1985
Developer: Microsoft
Milestones: Windows 95; Windows XP; Windows 7; Windows 10; Windows 11

The history of Microsoft Windows begins in 1985, when Microsoft released Windows 1.0, a graphical operating environment for MS-DOS. Early versions were modest successes, but Windows 3.0 (1990) and 3.1 (1992) sold in the millions and established the platform.

Consumer and NT lines

Windows NT 3.1 (1993) introduced a separate, fully 32-bit kernel line aimed at workstations and servers. Windows 95 (1995) merged the consumer line with a new interface — Start menu, taskbar and Explorer — and was a major commercial event. Windows 98 and Me followed, while Windows 2000 advanced the NT line.

Unification and later versions

Windows XP (2001) unified consumer and business lines on the NT kernel and became one of the most widely used operating systems ever. Windows Vista (2007) was criticised for performance and compatibility; Windows 7 (2009) restored confidence. Windows 8 (2012) pursued touch devices with a controversial redesign; Windows 10 (2015) returned the Start menu and moved to a service model, and Windows 11 followed in 2021 with a refreshed interface and stricter hardware requirements.
