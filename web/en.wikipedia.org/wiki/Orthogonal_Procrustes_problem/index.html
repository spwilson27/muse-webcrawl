Orthogonal Procrustes problem

The orthogonal Procrustes problem is a matrix approximation problem in linear algebra. In its classical form, one is given two matrices A and B and seeks an orthogonal matrix Ω which most closely maps A to B. Specifically, the problem is to find the orthogonal matrix Ω that minimizes the Frobenius norm of the difference ΩA − B, that is, minimize ‖ΩA − B‖F subject to ΩTΩ = I.

Solution

The solution to this problem was given by Peter Schönemann in 1966. It makes use of the singular value decomposition (SVD). If M = BAT has the SVD M = UΣVT, then the optimal solution is Ω = UVT. This result is closely related to the Kabsch algorithm used in structural biology and computer graphics to align point sets.

Name and applications

The name derives from Procrustes, a bandit from Greek mythology who stretched or amputated his victims to fit an iron bed. Procrustes analysis is used in statistics and shape analysis to compare shapes, and the orthogonal Procrustes problem appears in factor analysis, signal processing, and the alignment of molecular structures.
