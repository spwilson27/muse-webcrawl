Characterization test

Characterization tests pin down existing behaviour

In computer programming, a characterization test (also known as a golden master test) is a means to describe the actual behaviour of an existing piece of software and to protect it against unintended changes when the code is refactored. The term was popularized by Michael Feathers in his book Working Effectively with Legacy Code.

Approach

Rather than asserting what the software should do, the developer feeds inputs to the system, records its actual outputs—including quirks and bugs—and turns those recordings into automated tests. Subsequent refactoring must keep the tests passing, so behaviour is preserved even where it is imperfect.

Use with legacy code

Characterization tests are especially valuable for legacy systems that lack specifications and unit tests: they create a safety net before changes are made, and they document behaviour discovered in the code as it runs. The technique overlaps with regression testing and approval testing.
