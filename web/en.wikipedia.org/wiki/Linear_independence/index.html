Linear independence

In the theory of vector spaces, a set of vectors is said to be linearly independent if there exists no nontrivial linear combination of the vectors that equals the zero vector. If such a linear combination exists, then the vectors are said to be linearly dependent. These concepts are central to the definition of dimension.

Vectors in a plane: a set spanning the plane is independent if no vector in it lies in the span of the others.

Definition

A finite set of vectors {v1, v2, …, vk} in a vector space V is said to be linearly independent if the only scalars a1, a2, …, ak such that

a1v1 + a2v2 + ⋯ + akvk = 0

are a1 = a2 = ⋯ = ak = 0. If any other scalars work, the set is linearly dependent; equivalently, one of the vectors can be written as a linear combination of the others.

Examples

In the three-dimensional Euclidean space R3, the standard basis vectors (1,0,0), (0,1,0) and (0,0,1) are linearly independent. In contrast, the vectors (1,2,3), (2,4,6) and (0,1,1) are dependent, since the second is twice the first. In R4, the four vectors (1,0,0,0), (0,1,1,0), (0,1,0,0) and (1,1,0,0) are dependent because the fourth equals the sum of the second and third minus adjustments—indeed any set of more vectors than the dimension of the space is automatically dependent.

Relation to bases and dimension

A linearly independent set that spans the whole space is a basis. All bases of a given vector space have the same number of elements, and this number is the dimension of the space. Any set of vectors can be reduced to a linearly independent set spanning the same subspace by discarding vectors that are combinations of earlier ones.

Determining linear independence

For vectors given as columns of a matrix, the vectors are linearly independent if and only if the matrix has full column rank, which can be checked by Gaussian elimination. For square matrices this is equivalent to a nonzero determinant. The Wronskian plays an analogous role for functions.
