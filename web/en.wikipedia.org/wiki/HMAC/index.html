HMAC

In cryptography, an HMAC (sometimes expanded as hash-based message authentication code or keyed-hash message authentication code) is a specific type of message authentication code involving a cryptographic hash function and a secret cryptographic key. It is used to verify both the data integrity and the authenticity of a message.

Construction

HMAC is defined in RFC 2104 and FIPS 198-1. Given a hash function H, a secret key K and a message m, the HMAC is computed by hashing twice with the key padded and XORed with two distinct constants, the inner pad (ipad, 0x36 repeated) and the outer pad (opad, 0x5c repeated): HMAC = H( (K ⊕ opad) ‖ H( (K ⊕ ipad) ‖ m ) ). This nested construction protects against length-extension attacks to which a naive prefix key–message hash would be vulnerable, and its security can be formally reduced to the security of the underlying hash function.

HMAC may be used with any iterated hash function, most commonly in modern practice HMAC-SHA-256. Applications include IPsec, TLS, JSON Web Tokens, challenge–response authentication and verifying downloaded files.
