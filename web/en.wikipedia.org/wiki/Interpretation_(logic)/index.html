Interpretation (logic)

In mathematical logic, an interpretation is an assignment of meaning to the symbols of a formal language. Many formal languages used in mathematics, logic and theoretical computer science are defined purely syntactically and have no meaning until they are given an interpretation. The standard interpretation of a formal system is studied in model theory, while the general notion also plays a role in proof theory and semantics.

Formal languages and interpretations

A formal language for a logic such as first-order logic consists of constant symbols, function symbols and relation (predicate) symbols, together with variables and logical connectives. An interpretation of such a language consists of:

— a non-empty set called the domain of discourse (or universe); — for each constant symbol, an element of the domain; — for each n-ary function symbol, a function from n-tuples of the domain to the domain; and — for each n-ary relation symbol, a set of n-tuples of the domain (its extension).

An interpretation together with an assignment of values to the free variables determines a truth value for every sentence of the language. If a sentence is true in an interpretation, that interpretation is called a model of the sentence; a theory (a set of sentences) has a model if there is an interpretation making all of its sentences true.

Examples

The language of arithmetic contains a constant 0, a successor function symbol S, and function symbols for addition and multiplication. Its intended or standard interpretation takes the domain to be the natural numbers, 0 to denote zero, and S, + and × to denote the usual arithmetical operations. By the Löwenheim–Skolem theorem, however, first-order arithmetic also admits non-standard models.

In propositional logic, an interpretation is simply a truth-value assignment: each propositional variable is assigned true or false, and the truth values of compound formulas are computed from the connectives' truth tables.

Intended and unintended interpretations

Formal semantics distinguishes the interpretation a system is designed to capture from other mathematically possible interpretations. Foundational results such as Gödel's incompleteness theorems turn in part on the existence of unintended models of arithmetic.
