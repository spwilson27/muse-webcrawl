TENEX is a discontinued operating system developed in 1969 by Bolt Beranek and Newman (now BBN Technologies) for the Digital Equipment Corporation PDP-10 mainframe computer. The name is a syllabic abbreviation of "TEN-EX", reflecting its extension of DEC's earlier TOPS-10 ("the TEN"). TENEX became one of the most influential early timesharing systems and was widely used on the ARPANET.

Design

The project was led by Daniel Bobrow, with contributions from Ray Tomlinson and others. Because the standard PDP-10 lacked paging hardware, BBN designed a custom pager that gave TENEX a full demand-paged virtual memory system — a notable advance at the time. Each user process received a private virtual address space, and the system provided a rich set of system calls (JSYS) supporting hierarchical file naming, inter-process communication and sophisticated terminal handling.

TENEX's command interpreter was particularly admired: it supported command completion, recognition of unambiguous abbreviations, and "?" help at any point in a command line — features that influenced later interactive systems. Ray Tomlinson implemented network mail on TENEX machines in 1971, choosing the "@" sign to separate user and host names, and the system's large ARPANET user community made it a de facto standard platform for network software development.

Legacy

DEC acquired the rights to TENEX and reworked it with full demand paging on the newer KL10 processor to produce TOPS-20 (internally "TWENEX"), released in 1976, which retained TENEX's user interface and much of its design. TENEX itself continued to run at BBN and elsewhere into the 1980s.
