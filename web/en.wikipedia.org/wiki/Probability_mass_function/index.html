Probability mass function

Placeholder image: the PMF of a discrete distribution as a bar chart

In probability and statistics, a probability mass function (PMF) is a function that gives the probability that a discrete random variable takes exactly a given value. It is the discrete analogue of the probability density function used for continuous variables.

Probability mass function
NotationpX(x) = P(X = x)
Applies toDiscrete random variables
Propertiesp(x) ≥ 0 for all x; Σ p(x) = 1

Definition

For a discrete random variable X, the probability mass function is pX(x) = P(X = x). The PMF is zero for values outside the support of X, non-negative everywhere, and sums to 1 over all possible values. Probabilities of events are computed by summing the PMF over the relevant values, and the cumulative distribution function is the running sum of the PMF.

Examples

  • Fair coin: p(heads) = p(tails) = 1/2.
  • Fair die: p(x) = 1/6 for x = 1, …, 6.
  • Binomial distribution: p(k) = C(n, k) pk (1 − p)n−k.
  • Poisson distribution: p(k) = λk e−λ / k!.

Moments

The expected value of a function g(X) is E[g(X)] = Σ g(x) p(x), from which the mean, variance, and other moments of the distribution follow.
