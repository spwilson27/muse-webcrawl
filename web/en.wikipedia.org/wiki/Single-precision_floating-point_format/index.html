Single-precision floating-point format

The single-precision floating-point format (sometimes called FP32 or float32) is a computer number format, usually occupying 32 bits in computer memory, that represents a wide dynamic range of numeric values by using a floating radix point. It is specified by the IEEE 754 standard as binary32.

A binary32 value is laid out as 1 sign bit, 8 exponent bits, and 23 fraction (significand) bits. The exponent is stored with a bias of 127. The format can represent numbers with an absolute value from about 1.18 × 10−38 (smallest positive normal) up to about 3.40 × 1038, with roughly 6 to 9 significant decimal digits of precision (24 bits of significand, including the implicit leading bit).

Encoding

For a normal number, the value is given by (−1)sign × 1.fraction × 2exponent − 127, where the leading 1 is implicit. When the exponent field is all zeros, the value is either zero or a subnormal number, in which the implicit leading bit is 0, allowing gradual underflow. An exponent field of all ones encodes infinity (fraction zero) or NaN (fraction nonzero).

Uses

Single precision is the default float type in languages such as C and Java, and is used extensively in computer graphics, where GPUs historically performed most arithmetic in FP32, and in machine learning, where it remains a common training and inference format. It offers twice the throughput and half the memory footprint of double precision at the cost of reduced range and precision.

Example

The decimal number 0.15625 is encoded as sign 0, exponent field 124 (2−3 after removing the bias), and a fraction of 0.25 in binary terms, giving the hexadecimal representation 0x3E200000. The value π is approximated as 0x40490FDB, equal to 3.14159274101257324219…
