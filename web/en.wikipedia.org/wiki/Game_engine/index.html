Game engine

From Wikipedia, the free encyclopedia

A game engine is a software framework primarily designed for video game development, which may include specialized integrated development environment (IDE), runtime libraries, and other tools for building games. Developers use game engines to construct games for video game consoles and desktop, mobile and web platforms. The core functionality typically provided by a game engine includes a rendering engine ("renderer") for 2D or 3D graphics, a physics engine or collision detection (and collision response), sound, scripting, animation, artificial intelligence, networking, streaming, memory management, threading, localization support, scene graph, and video support for cinematics.

History

Before game engines, games were typically written as singular entities; reusable codebases emerged with 1980s construction kits and with id Software's Doom engine (1993), which separated core software components from game-specific assets and rules. The term "game engine" arose in the mid-1990s. Epic Games' Unreal Engine (1998) and id Tech popularized licensing engines to third parties. In the 2000s and 2010s, Unity and Unreal Engine came to dominate independent and AAA development respectively, while open-source engines such as Godot grew rapidly.

Components

Modern engines bundle a scene editor, asset pipeline, scripting languages (C#, C++, GDScript, visual scripting), a physics solver such as PhysX or Havok, audio mixing, animation state machines, and exporters targeting many platforms from a single project. Engines increasingly serve film production, architecture and simulation, a practice known as real-time filmmaking or virtual production.
