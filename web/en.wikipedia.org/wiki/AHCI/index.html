Advanced Host Controller Interface

AHCI

Full name: Advanced Host Controller Interface

Developer: Intel

Version: 1.3.1

Applies to: Serial ATA (SATA) host controllers

Successor context: NVMe for PCIe solid-state drives

The Advanced Host Controller Interface (AHCI) is a technical standard defined by Intel that specifies the hardware mechanism by which Serial ATA (SATA) host controllers communicate with storage devices and the operating system. It provides a single, standard register-level interface, allowing operating systems to ship one driver that works with any AHCI-compliant SATA controller rather than needing vendor-specific drivers.

Features

AHCI exposes the advanced capabilities of SATA that are unavailable in legacy IDE emulation mode, including Native Command Queuing (NCQ), which lets a drive internally optimise the order of read and write commands; hot swapping of drives; staggered spin-up of multiple disks; and support for up to 32 commands in a queue. It supports the SATA link speeds through 6 Gbit/s.

Operating system support

Windows Vista and later, modern versions of macOS, Linux (via the libata subsystem), and the BSD family all include native AHCI support. Because enabling AHCI after an operating system was installed in IDE mode can make the boot drive inaccessible, firmware and installation guides commonly warn users to select AHCI mode in the BIOS/UEFI before installing the OS. For solid-state drives attached over PCI Express, AHCI has largely been superseded by the NVMe protocol, which was designed from the ground up for flash storage and much deeper command queues.
