Idris (programming language)

Idris is a purely functional programming language with dependent types, developed by Edwin Brady at the University of St Andrews. Unlike most languages, where types and values live in separate worlds, Idris allows types to be computed from ordinary values, so that a type can state precise properties of a program — for example, that a list has a particular length, or that an index is within bounds — and the compiler checks those properties automatically.

Features

Idris supports full dependent types, type-driven development with interactive "holes" that the editor can refine step by step, totality checking, and a foreign function interface. A canonical example is Vect n a, a list of exactly n elements of type a: appending a Vect n a and a Vect m a yields a Vect (n + m) a, and out-of-range indexing becomes a compile-time error rather than a runtime failure.

Idris 2

Idris 2, released in 2020 and implemented in Idris itself, is based on Quantitative Type Theory (QTT). Quantities on binders (0, 1, or unrestricted) let programmers state how many times a value is used, enabling both erased compile-time-only data and efficient resource handling such as linear types. Backends generate Scheme (Chez Scheme by default), Racket, JavaScript and C code.

Name

The language is named after Idris, the singing dragon from the Welsh children's television series Ivor the Engine.
