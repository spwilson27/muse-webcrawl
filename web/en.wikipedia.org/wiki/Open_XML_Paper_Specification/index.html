The Open XML Paper Specification (OpenXPS) is a specification for a page description language and fixed-document format, originally developed by Microsoft as the XML Paper Specification (XPS) and standardised by Ecma International as ECMA-388 in 2009. It is a competitor to PDF for documents that must render identically everywhere.

Format

An XPS document is a ZIP archive following the Open Packaging Conventions, containing XML markup that describes each page as a fixed arrangement of glyphs, vector shapes, and images, along with resources, document structure, and optional digital signatures and rights metadata. The file extension is .xps (or .oxps for the standardised OpenXPS variant).

Adoption

XPS was built into Windows Vista and later versions, with a viewer and a virtual printer driver (Microsoft XPS Document Writer). Adoption outside Windows remained limited compared with PDF, and Microsoft eventually de-emphasised the format, making its viewer an optional component in Windows 10.
