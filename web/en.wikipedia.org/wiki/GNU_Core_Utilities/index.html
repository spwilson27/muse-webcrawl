The GNU Core Utilities, or coreutils, are a package of GNU software containing implementations of many of the basic tools of a Unix operating system, such as cat, ls and rm. The package, released in its combined form in 2002–2003, merged the earlier GNU fileutils, textutils, shellutils and related packages into a single collection.

Contents

The utilities cover three main areas: file operations (cp, mv, ln, mkdir, rm, chmod, chown, dd, df, du), text operations (cat, head, tail, sort, uniq, wc, cut, tr, join) and shell and system operations (echo, printf, env, uname, whoami, date, sleep, kill). GNU versions generally extend the behaviour specified by POSIX with additional options, such as long options in the form --verbose.

Use

Coreutils is installed by default on virtually every Linux distribution and forms the command-line foundation on which shell scripts and system administration rely. Ports exist for other Unix-like systems, and the utilities are also available on macOS (often installed via package managers, sometimes with a "g" prefix to distinguish them from the BSD versions).

History

The component packages were among the earliest produced by the GNU Project in the late 1980s and early 1990s, written as free replacements for the proprietary Unix utilities. Their merger into coreutils simplified maintenance and distribution; the package continues to receive regular releases adding performance improvements and occasional new tools.
