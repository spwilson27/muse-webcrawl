Shunting-yard algorithm

The shunting-yard algorithm is a method for parsing mathematical expressions specified in infix notation. It can produce either a postfix notation string, also known as reverse Polish notation (RPN), or an abstract syntax tree. The algorithm was invented by Edsger Dijkstra and named the "shunting yard" algorithm because its operation resembles that of a railroad shunting yard.

Description

The algorithm maintains an output queue and an operator stack. Operands are sent directly to the output; operators are pushed onto the stack, first popping any operators of greater precedence (or equal precedence, for left-associative operators) to the output. Parentheses control grouping: a left parenthesis is pushed, and a right parenthesis causes operators to be popped until the matching left parenthesis is reached.

Applications

Shunting-yard parsing is widely used in calculators, expression evaluators, and simple compilers, and it can be extended to handle functions and differing operator associativities.
