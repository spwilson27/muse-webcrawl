Structured prediction

From Wikipedia, the free encyclopedia

Structured prediction or structured (output) learning is an umbrella term for supervised machine learning techniques that involve predicting structured objects, rather than scalar discrete or real values. Structured objects might be sequences, trees, graphs, or other combinatorial objects whose components are interrelated.

Motivation

Similar to commonly used supervised learning techniques, structured prediction models are trained on observed data in which the true values are used to adjust model parameters. However, because outputs have internal structure, the model must account for dependencies among output variables. For example, in part-of-speech tagging, the correct tag for a word depends on neighbouring tags; classifying each word independently can produce tag sequences that are grammatically impossible.

Techniques

Conditional random fields (CRFs), introduced by Lafferty, McCallum, and Pereira in 2001, are probabilistic models that define a conditional distribution over structured outputs given an input, and are widely used for sequence labelling in natural language processing.

Structured support vector machines (structured SVMs), developed by Tsochantaridis and collaborators, generalise the max-margin principle to structured outputs, using loss functions such as Hamming loss over the components of the output.

Structured perceptron algorithms extend the classic perceptron update to structured outputs, performing prediction with an inference subroutine and updating parameters whenever the predicted structure differs from the correct one. Learning typically requires solving an inference problem — finding the highest-scoring output structure — which for sequences can be done with the Viterbi algorithm and for other structures with dynamic programming or approximate inference.

Applications

Structured prediction is used in natural language processing (parsing, named-entity recognition, machine translation), bioinformatics (protein secondary structure prediction, gene finding), and computer vision (image segmentation, object detection).
