Variance reduction

Variance reduction is a collection of procedures in experimental design and simulation, especially Monte Carlo methods, designed to increase the precision of estimates obtainable for a given number of iterations or observations. Output from simulations is analysed using statistical techniques so that the same computational budget yields tighter confidence intervals.

Common techniques

Antithetic variates pair each random draw with a negatively correlated counterpart (for example, using both U and 1−U), so errors tend to cancel. Control variates exploit a correlated quantity whose exact expectation is known, adjusting the estimate by the difference between the simulated and true values of the control. Importance sampling draws from an alternative distribution that oversamples the important region of the integrand, correcting with likelihood ratios. Stratified sampling divides the sample space into strata — Latin hypercube sampling is a related scheme — ensuring even coverage. Rao–Blackwellization replaces random variables by their conditional expectations where feasible.

Applications

These techniques are widely used in computational finance (option pricing), reliability analysis, queueing simulation, and particle transport, where crude Monte Carlo converges slowly at rate proportional to the inverse square root of the number of samples.
