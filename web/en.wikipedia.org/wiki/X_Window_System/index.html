X Window System

The X Window System (X11, or simply X) is a windowing system for bitmap displays, common on Unix-like operating systems. It provides the basic framework for a graphical user interface: drawing and moving windows on the display device and interacting with a mouse and keyboard. X originated at the Massachusetts Institute of Technology (MIT) in 1984, and the current protocol version, X11, was released in September 1987.

Design

X uses a client–server model: the X server runs on the machine with the display and keyboard, accepting requests from client programs — which may run on remote machines — to draw windows, and sending back input events. This network transparency was a defining feature, allowing graphical applications to run across a network. Unusually, X does not mandate a user interface style; window management, title bars and icons are handled by a separate window manager program, and complete desktop environments such as GNOME and KDE were built on top of it.

History

X was created as part of MIT's Project Athena. Version 11 spread widely through the MIT X Consortium and later the X Consortium and Open Group. The free implementation XFree86 became standard on Linux and BSD systems; a 2004 licensing dispute led most of the community to the forked X.Org Server, which remains the reference implementation. X.Org releases added extensions for compositing, direct rendering and input devices. In the 2010s and 2020s, many Linux distributions began moving to Wayland as a simpler successor, with X applications supported through the XWayland compatibility layer, though X11 remains in wide use.

Principles

The system's design tenets, as summarised by its developers, included "mechanism, not policy" and the maxim that "the only thing worse than generalizing from one example is generalizing from no examples at all". These led to a highly extensible protocol whose longevity — and accumulated complexity — shaped decades of Unix graphics.
