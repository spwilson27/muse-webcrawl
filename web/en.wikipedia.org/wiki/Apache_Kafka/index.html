Apache Kafka

Apache Kafka is an open-source distributed event streaming platform developed by the Apache Software Foundation. It was originally created at LinkedIn and open-sourced in 2011. Kafka is used for building real-time data pipelines, streaming applications, log aggregation and event-driven architectures.

Architecture

Kafka stores streams of records in categories called topics. Producers publish records to topics, consumers subscribe and read them, and brokers store the data durably in partitioned, replicated logs. Partitions allow parallelism and ordering within a partition, while consumer groups coordinate load balancing and offsets.

Kafka Connect provides integration with external systems, and Kafka Streams is a client library for building stream-processing applications. Later versions replaced ZooKeeper-based metadata management with an internal Raft-based mode known as KRaft.

Characteristics

Kafka is designed for high throughput, horizontal scalability, fault tolerance and low-latency delivery. Because records are retained for a configurable period rather than deleted on consumption, consumers can replay streams and new applications can process historical events.
