Self (programming language)

Self
ParadigmObject-oriented, prototype-based
Designed byDavid Ungar, Randall Smith
First appeared1987
InfluencedJavaScript, NewtonScript, Io, Lua

Self is an object-oriented programming language based on the concept of prototypes. It was developed at Xerox PARC and later at Stanford University and Sun Microsystems during the 1980s and 1990s. Self dispenses with classes entirely: new objects are created by cloning existing prototype objects, and behaviour is shared through delegation rather than class-based inheritance.

Design

In Self, everything is an object and all computation is performed by sending messages. Objects consist of named slots, which may hold data or methods, and slots can be added, removed, or changed at run time. Because there are no classes, the distinction between instances and templates disappears; a programmer modifies a prototype directly and clones it to obtain working objects.

Self also pioneered an experimental graphical programming environment, later called the Morphic user interface framework, in which objects are manipulated directly on screen. Morphic went on to influence the Squeak implementation of Smalltalk.

Implementation and influence

Although Self itself never achieved mainstream adoption, its implementation research was highly influential. The adaptive optimization and just-in-time compilation techniques developed for Self — including polymorphic inline caches and adaptive compilation pioneered by Urs Hölzle — led directly to the HotSpot Java virtual machine. Self's prototype model also helped inspire JavaScript's object system.
