Common Object Request Broker Architecture

CORBA
Full name: Common Object Request Broker Architecture
Maintained by: Object Management Group
First released: 1991

The Common Object Request Broker Architecture (CORBA) is a standard defined by the Object Management Group (OMG) designed to facilitate the communication of systems deployed on diverse platforms. It enables software components written in multiple computer languages and running on multiple computers to interoperate.

Overview

CORBA uses an interface definition language (IDL) to specify the interfaces that objects present to other components. An object request broker (ORB) mediates remote method invocations, marshalling arguments and returning results across the network using the IIOP protocol.

History and decline

First released in 1991, CORBA became a major enterprise middleware technology in the 1990s. It was widely criticised for complexity and for standardisation-by-committee, and from the 2000s was largely displaced by simpler approaches such as SOAP and REST web services, though it persists in telecommunications, defence and finance systems.
