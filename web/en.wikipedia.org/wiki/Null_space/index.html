Null space

In mathematics, the null space or kernel of a linear map L : V → W between vector spaces is the set of all vectors v in V such that L(v) = 0. It is a subspace of V. For a matrix A, the null space consists of all solutions x of the homogeneous equation Ax = 0.

Properties

  • The null space is always a linear subspace, since it contains the zero vector and is closed under addition and scalar multiplication.
  • A linear map is injective (one-to-one) if and only if its null space is trivial, containing only the zero vector.
  • The dimension of the null space is called the nullity of the map or matrix.
  • The rank–nullity theorem states that for a linear map on a finite-dimensional space, rank + nullity = dimension of the domain.

Computation

For a matrix, the null space is found by Gaussian elimination to reduced row echelon form and solving for the free variables, which yields a basis. Numerically, the singular value decomposition is preferred because it is stable: the null space is spanned by right singular vectors corresponding to zero (or near-zero) singular values. Null spaces are used in solving linear systems, least squares, and in physics for constraint and gauge spaces.

Generalisation

The same word, "kernel", applies to linear operators on infinite-dimensional spaces in functional analysis, and by analogy to group homomorphisms and other morphisms in algebra; see nullity (mathematics) for the dimension of the kernel as distinct from unrelated uses in law.
