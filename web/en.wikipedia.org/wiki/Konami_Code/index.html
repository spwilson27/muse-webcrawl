Konami Code

The Konami Code (Japanese: コナミコマンド, "Konami command") is a cheat code that appears in many video games published by Konami and, by homage, in games and websites by other developers. The code is entered on the controller as:

↑ ↑ ↓ ↓ ← → ← → B A (sometimes followed by Start or Select)

History

The code was created by Konami programmer Kazuhisa Hashimoto while porting the arcade shoot-'em-up Gradius to the Nintendo Entertainment System in 1986. Finding the game too difficult to play through while testing, Hashimoto added a hidden sequence that granted the player's ship a full set of power-ups. He intended to remove it before release but forgot; it shipped with the game and was soon discovered by players.

The code became famous worldwide through the NES version of Contra (1988), where it awarded the player 30 lives instead of the standard three — almost essential in the punishingly difficult run-and-gun game. There it is sometimes remembered as the "30 lives code".

Legacy

The sequence has since become a general pop-culture reference and an Easter egg convention: websites (including news and entertainment sites) have hidden jokes triggered by typing the sequence on a keyboard, and it appears in films, music, and merchandise. Variations of the code work in dozens of Konami titles — from Castlevania and Teenage Mutant Ninja Turtles to Metal Gear — and in games by completely unrelated studios as a tribute.
