Extreme value theory

Extreme value theory or extreme value analysis (EVA) is an outgrowth of statistics and a branch of probability theory dealing with the extreme deviations from the median of probability distributions. It seeks to assess, from a given ordered sample of a random variable, the probability of events that are more extreme than any previously observed.

Theory

The Fisher–Tippett–Gnedenko theorem states that the limiting distribution of suitably normalized maxima of independent, identically distributed random variables must be one of three types: the Gumbel, Fréchet, or Weibull distribution. These are unified in the generalized extreme value distribution (GEV), parameterized by a shape parameter called the extreme value index. A complementary approach, the peaks-over-threshold method, uses the generalized Pareto distribution for exceedances over a high threshold.

Applications

Extreme value analysis is widely used in hydrology (estimating flood return levels such as the 100-year flood), structural engineering, finance and insurance (modelling large losses), climatology (heatwaves and record rainfall), and ocean engineering (design wave heights). It is, for example, used to design flood defences such as the Dutch Delta Works, which are built to withstand events with very long return periods.
