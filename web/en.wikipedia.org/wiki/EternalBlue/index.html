EternalBlue

EternalBlue is a computer exploit developed by the U.S. National Security Agency (NSA). It was leaked by the hacker group The Shadow Brokers on 14 April 2017 and exploits a vulnerability in Microsoft's implementation of the Server Message Block (SMB) protocol, designated CVE-2017-0144.

DeveloperNational Security Agency (attributed)
Released byThe Shadow Brokers, April 2017
TargetMicrosoft Windows SMBv1
CVECVE-2017-0144
PatchMS17-010 (March 2017)

Use in attacks

Microsoft had issued patch MS17-010 on 14 March 2017, a month before the leak, but many systems remained unpatched. EternalBlue was used to spread the WannaCry ransomware in May 2017, which affected hundreds of thousands of computers including Britain's National Health Service, and the NotPetya attack in June 2017, which caused billions of dollars of damage worldwide.

Response

Microsoft took the unusual step of releasing patches for unsupported versions including Windows XP and Windows Server 2003. The episode fuelled debate about governments stockpiling vulnerabilities — the so-called equities process — rather than disclosing them for patching.
