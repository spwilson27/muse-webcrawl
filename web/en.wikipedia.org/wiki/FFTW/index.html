FFTW

FFTW, the Fastest Fourier Transform in the West, is a widely used software library for computing discrete Fourier transforms (DFTs), developed by Matteo Frigo and Steven G. Johnson at the Massachusetts Institute of Technology. First released in 1997, it became the benchmark FFT implementation, used by systems such as MATLAB, GNU Octave and many scientific programs.

Design

Instead of a single fixed algorithm, FFTW divides the transform into small precomputed blocks called codelets, generated by an OCaml program, and at run time a planner searches for the fastest combination for the user's specific problem size and hardware — measuring timings empirically. It computes transforms of arbitrary size, multidimensional and real-data DFTs, and discrete cosine and sine transforms, in single or double precision, with support for shared-memory threads and MPI.

Recognition

In 1999 Frigo and Johnson received the J. H. Wilkinson Prize for Numerical Software for FFTW. The name playfully echoes earlier libraries such as the Fast Fourier Transform in the West Coast tradition and the FFTPACK package.
