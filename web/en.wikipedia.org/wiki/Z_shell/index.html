The Z shell (zsh) is a Unix shell that can be used as an interactive login shell and as a command interpreter for shell scripting. Zsh is an extended Bourne shell with many improvements, including some features of Bash, ksh, and tcsh.

History and features

Paul Falstad wrote Zsh in 1990 while a student at Princeton University; the name derives from Yale professor Zhong Shao, whose login ID was "zsh". Zsh is known for powerful programmable command-line completion, spelling correction, themeable prompts, extended globbing, floating-point arithmetic, arrays with flexible indexing, and loadable modules. Its startup files are .zshrc and .zprofile.

Community frameworks such as Oh My Zsh (created in 2009) popularized plugin and theme customization. Zsh is the default login shell on Kali Linux and, since macOS Catalina (2019), on Apple's macOS. It is largely compatible with Bash scripts while offering more advanced interactive features.
