Font rasterization

Font rasterization is the process of converting text from a vector description (as found in scalable fonts such as TrueType) to a raster or bitmap description. This often involves some anti-aliasing on screen text to make it smoother and easier to read. It may also involve hinting — information embedded in the font data that optimises rendering at small sizes.

Types of rasterization

In modern operating systems, rasterisation is typically provided by a shared component such as Microsoft's DirectWrite, Apple's Core Text, or the open-source FreeType library. Techniques include:

  • Black-and-white rendering — each pixel is simply on or off; now largely obsolete because it produces jagged edges at small sizes.
  • Grayscale anti-aliasing — pixels at edges are shaded according to coverage, smoothing the appearance of glyphs.
  • Subpixel rendering — exploits the red, green, and blue sub-elements of LCD pixels (as in Microsoft's ClearType) to increase effective horizontal resolution.

Hinting

Hinting adjusts the rasterised outline of a glyph so that it conforms more closely to the pixel grid, improving legibility at small point sizes. TrueType fonts may contain explicit bytecode instructions executed by an interpreter in the rasteriser, while PostScript Type 1 fonts use a more declarative hinting model.
