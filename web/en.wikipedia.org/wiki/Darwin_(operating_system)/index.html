Darwin is the core Unix-like operating system released by Apple Inc. that forms the foundation of macOS, iOS and Apple's other operating systems. It consists of code developed by Apple together with code derived from NeXTSTEP, FreeBSD and other free-software projects. Darwin is itself released as free and open-source software under the Apple Public Source License, though complete bootable distributions are largely a community effort.

Architecture

At Darwin's heart is the XNU kernel, a hybrid combining the Mach microkernel (developed at Carnegie Mellon and refined at NeXT) with components of the BSD implementation of Unix, including the POSIX API, networking stack and process model. Above the kernel sit core services such as IOKit for device drivers and the familiar BSD command-line environment.

History

Darwin's lineage runs from NeXTSTEP (1989), which Apple acquired with its purchase of NeXT in 1997. Apple released the Darwin core as an open-source project in 2000, inviting outside developers to contribute; the community OpenDarwin project operated from 2002 to 2006, and PureDarwin later carried on the work of making Darwin usable on its own. The platypus-themed mascot Hexley was proposed by the community. Each macOS release corresponds to a Darwin version — for example, macOS Ventura is based on Darwin 22.

Relationship to macOS

Darwin provides the kernel and Unix userland of Apple's systems, but excludes the proprietary graphical layers — Aqua, Quartz, Cocoa and the Finder — that distinguish macOS as a commercial product. Because Darwin is POSIX-compliant, much open-source Unix software can be built and run on it.
