Search algorithm

Searching a binary search tree

In computer science, a search algorithm is an algorithm designed to solve a search problem: to retrieve information stored within a particular data structure, or calculated in the search space of a problem domain, either with discrete or continuous values. Search algorithms are fundamental to computing, underpinning everything from looking up a name in a sorted list to finding routes in maps and moves in games.

Classes of search algorithms

Searching lists and arrays

The simplest search procedure is linear search (or sequential search), which examines each element of a list in order until a match is found or the list ends. It runs in O(n) time and requires no preconditions on the data.

For sorted arrays, binary search is far more efficient: it repeatedly halves the interval under consideration, comparing the target with the middle element, and achieves O(log n) time. Variants include interpolation search, which estimates the target's position from the values at the interval ends, and exponential search, which first finds a bounding range.

Searching trees and graphs

Tree and graph searches systematically explore vertices and edges. Breadth-first search (BFS) explores neighbours level by level and finds shortest paths in unweighted graphs. Depth-first search (DFS) follows each branch as deeply as possible before backtracking. Informed algorithms such as A* use heuristic estimates to guide the search toward the goal, and Dijkstra's algorithm finds shortest paths in weighted graphs with non-negative edge weights.

Search in problem solving and AI

Artificial intelligence treats many problems — planning, scheduling, game playing — as searches through a space of possible states. Uninformed strategies (breadth-first, depth-first, iterative deepening, uniform-cost) rely only on the structure of the space, while informed strategies use heuristics. Adversarial search, used in games, applies the minimax principle with alpha–beta pruning. Local search methods such as hill climbing and simulated annealing are used for optimisation problems where the path to the goal is irrelevant.

String searching

String-searching algorithms find occurrences of a pattern within a text. The naive algorithm checks every alignment; more efficient methods such as Knuth–Morris–Pratt and Boyer–Moore preprocess the pattern to skip characters, achieving linear or sublinear average performance.

Complexity and evaluation

Search algorithms are evaluated by their time complexity, space complexity, completeness (whether they are guaranteed to find a solution if one exists), and optimality (whether the solution found is the best possible). The choice of algorithm depends on the structure of the data, whether it is sorted, the frequency of insertions and deletions, and the size of the search space.

Applications

Search algorithms are used in databases (index lookups), web search engines, route planning and navigation, compilers, bioinformatics (sequence alignment), constraint satisfaction, and combinatorial optimisation.
