Forward error correction

FEC adds redundancy so the receiver can correct errors without retransmission.

Forward error correction (FEC) or channel coding is a technique used for controlling errors in data transmission over unreliable or noisy communication channels. The central idea is that the sender encodes the message with redundant information (an error-correcting code) that allows the receiver to detect and correct a limited number of errors without requesting retransmission.

How it works

An FEC encoder adds redundancy to the transmitted data, producing codewords of a channel code. The ratio of data bits to total bits is the code rate. Because errors can be corrected at the receiver, FEC is essential where retransmission is impossible or costly — for example in simplex links, deep-space communication, broadcast media, and storage devices.

Types of codes

  • Block codes — work on fixed-size blocks, e.g. Hamming codes, Reed–Solomon codes and BCH codes.
  • Convolutional codes — process streams bit by bit, decoded with the Viterbi algorithm.
  • Turbo codes and LDPC codes — modern capacity-approaching codes used in mobile networks, satellite links and Wi-Fi.
  • Polar codes — adopted for control channels in 5G.

Applications

FEC is used in CDs and DVDs (Reed–Solomon), QR codes, DSL and cable modems, satellite television, cellular networks (3G, 4G, 5G), deep-space probes, data storage systems and one-way data links such as telemetry. Hybrid ARQ combines FEC with retransmission requests for further reliability.
