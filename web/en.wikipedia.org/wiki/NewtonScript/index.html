NewtonScript

NewtonScript is a prototype-based programming language created by Walter Smith at Apple Computer for the Newton platform, which powered the MessagePad personal digital assistants released in the 1990s. The language was derived from the Self programming language but modified to be more practical for resource-constrained handheld devices and for programmers accustomed to procedural languages.

Design

NewtonScript uses prototype-based inheritance: objects, called frames, are slot-based structures that inherit from other frames through a _proto slot. Functions are first-class values, and the language integrates tightly with the Newton view system and its persistent object store known as "soups". Garbage collection and a compact bytecode virtual machine allowed programs to run within the MessagePad's limited memory.

Example

helloWorld := { _proto: protoTextButton,
               text: "Hello World",
               buttonClickScript: func()
                 begin
                   :Notify(kNotifyAlert, "NewtonScript", "Hello World!");
                 end };

Legacy

Although the Newton line was discontinued in 1998, NewtonScript influenced later prototype-based languages and remains of interest to retrocomputing enthusiasts, with emulators and community toolchains keeping the platform accessible.
