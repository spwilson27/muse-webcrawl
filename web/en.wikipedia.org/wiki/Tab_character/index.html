Tab character

The tab character is a control character (ASCII code 9) that causes printing or display devices to move the cursor to the next tab stop. It derives from the tabulator keys and stops used on typewriters to align columns of text and numbers.

In computing

In source code and text files, tabs are used for indentation and alignment. The width a tab displays as varies — commonly eight spaces, or four in many programming conventions — which has long fueled debates between using tabs and spaces for indentation.
