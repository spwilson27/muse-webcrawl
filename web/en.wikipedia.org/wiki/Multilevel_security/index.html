Multilevel security

Multilevel security or multiple levels of security (MLS) is the application of a computer system to process information with incompatible classifications (i.e., at different security levels), permit access by users with different security clearances and needs-to-know, and prevent users from obtaining access to information for which they lack authorization.

Concepts

MLS systems enforce a security policy based on a lattice of security labels combining hierarchical sensitivity levels (such as Unclassified, Confidential, Secret, Top Secret) with non-hierarchical categories or compartments. The classical formal models are the Bell–LaPadula model, which protects confidentiality with the "no read up, no write down" rules, and the Biba model, which protects integrity with the dual rules.

A system that handles information at multiple levels within a single accredited system is said to operate in multilevel mode, in contrast to period-based processing ("system high" mode), where a system must be cleared of information before being used at a different level.

Implementation

Genuinely trusted MLS operating systems have historically been rare and specialized, evaluated under criteria such as the Trusted Computer System Evaluation Criteria (the "Orange Book") and later the Common Criteria. Examples included systems built for military and intelligence use. Modern approaches include separation kernels, labelled security in mainstream systems such as SELinux and Trusted Solaris, and cross-domain solutions (guards) that mediate transfers between networks at different classification levels.

Challenges

The principal difficulties of MLS are covert channels — indirect paths by which information can leak from a high level to a low one — the problem of polyinstantiation (maintaining parallel versions of data at different levels), and the high cost of evaluation and accreditation. Economic pressure toward commercial off-the-shelf products has shifted practice toward multiple separate systems (MILS, "multiple independent levels of security") connected by controlled guards, rather than a single MLS platform.
