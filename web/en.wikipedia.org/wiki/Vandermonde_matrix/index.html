Vandermonde matrix

In linear algebra, a Vandermonde matrix, named after Alexandre-Théophile Vandermonde, is a matrix whose rows (or columns) form geometric progressions. An m × n Vandermonde matrix built from values α1, …, αm has entries Vij = αij−1:

V = [ 1  α1  α12  …  α1n−1; 1  α2  α22  …  α2n−1; ⋮ ; 1  αm  …  αmn−1 ]

Determinant

For a square Vandermonde matrix, the determinant is the product of all pairwise differences of the α values:

det(V) = ∏1 ≤ i < j ≤ n (αj − αi)

It follows that the matrix is invertible if and only if all the αi are distinct.

Applications

Vandermonde matrices arise naturally in polynomial interpolation: solving Va = y gives the coefficients of the unique polynomial of degree less than n passing through given points. They also appear in the discrete Fourier transform (whose matrix is a special Vandermonde matrix with roots of unity), in Reed–Solomon error-correcting codes, and in control theory.
