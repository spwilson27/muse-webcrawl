Ideal class group

From Wikipedia, the free encyclopedia

In number theory, the ideal class group (or simply class group) of an algebraic number field K is the quotient group JK / PK, where JK is the group of fractional ideals of the ring of integers of K, and PK is its subgroup of principal ideals. The class group measures the extent to which unique factorisation fails in the ring of integers: it is trivial if and only if every ideal is principal, in which case the ring is a unique factorisation domain.

History

The theory grew out of Ernst Kummer's work on Fermat's Last Theorem in the 1840s. Kummer introduced "ideal numbers" to restore unique factorisation in cyclotomic fields; Richard Dedekind later recast the idea in terms of ideals. The order of the class group is called the class number, denoted hK. Kummer showed that if the class number of a cyclotomic field is not divisible by the prime p (a "regular prime"), then Fermat's Last Theorem holds for that exponent.

Properties

A fundamental theorem, proved using Minkowski's geometry of numbers, states that the class group is always finite. The class number can be computed by the analytic class number formula, which relates it to the residue of the Dedekind zeta function at s = 1, the regulator, the number of roots of unity and the discriminant of the field. For quadratic fields, the class group is closely related to the theory of binary quadratic forms developed by Gauss.

Examples

The fields ℚ(√−5) has class number 2: the ideal (2, 1 + √−5) is not principal, reflecting the famous failure 6 = 2·3 = (1 + √−5)(1 − √−5). Heegner numbers correspond to imaginary quadratic fields with class number 1. Which real quadratic fields have class number 1 remains an open problem in general.
