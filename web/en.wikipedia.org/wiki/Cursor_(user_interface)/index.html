In human–computer interaction, a cursor is an indicator used to show the current position for user interaction on a computer monitor or other display device that will respond to input. The term derives from the Latin cursor, "runner", and from the sliding marker used on slide rules. Two forms predominate: the mouse pointer, controlled by a pointing device, and the text cursor, which marks where typed characters will appear.

Mouse pointer

The pointer is usually rendered as an angled arrow, a design introduced at Xerox PARC and popularized by the Apple Macintosh and Microsoft Windows. Its "hot spot" — the pixel that actually selects — is at the arrow's tip. The pointer's shape changes with context: an I-beam over text, a pointing hand over hyperlinks, a crosshair for precision drawing, an hourglass or spinning wheel when the system is busy, and resize arrows at window edges. Douglas Engelbart's group developed early pointer control with the invention of the computer mouse, publicly demonstrated in 1968.

Text cursor

The text cursor, often called the caret when it is a thin vertical bar, indicates the insertion point in editable text. On early terminals it appeared as a blinking block or underline generated by character-cell hardware; teletype and teleprinter systems had earlier used a physical carriage position as the insertion point. Blinking — typically at around 1 Hz — helps users locate the cursor without distracting them; most systems stop the blinking while the user is typing. Keyboard keys such as the arrow keys and the Insert key (which toggles between insert and overtype modes) control its behaviour.

Implementation

Early systems drew cursors in dedicated hardware sprites so the pointer could move without redrawing the screen beneath it. Modern compositing window systems generally render the pointer as a separate hardware plane or overlay, minimizing latency between physical movement and visual feedback — a factor that materially affects pointing performance, described by Fitts's law. On touchscreens, a persistent cursor is usually absent; instead, temporary handles appear during text selection.
