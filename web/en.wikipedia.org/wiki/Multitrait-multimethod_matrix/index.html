Multitrait-multimethod matrix

The multitrait-multimethod (MTMM) matrix is an approach to examining construct validity developed by Donald T. Campbell and Donald W. Fiske in 1959. It organizes the correlations among a set of measures in which each of several traits is measured by each of several methods, allowing researchers to evaluate both convergent validity and discriminant validity.

Structure

The matrix contains correlations of several kinds. Reliability coefficients reflect agreement between repeated measurements of the same trait by the same method. Validity coefficients join measures of the same trait by different methods; high values support convergent validity. Correlations between different traits measured by the same method reveal method effects, while correlations between different traits measured by different methods should be the lowest in the matrix if the traits are truly distinct.

Criteria

Campbell and Fiske proposed that validity coefficients should be significantly different from zero and large enough to encourage further examination; that a measure should correlate more highly with an independent measure of the same trait than with measures of different traits using the same method; and that the pattern of trait intercorrelations should be similar across methods.

Modern approaches

Contemporary analyses often replace visual inspection of the matrix with confirmatory factor analysis, in which trait factors and method factors are modeled simultaneously to partition variance among trait, method, and error components.
