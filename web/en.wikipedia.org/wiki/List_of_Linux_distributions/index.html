List of Linux distributions

This page provides general information about notable Linux distributions in the form of a categorized list. Distribution families are grouped by their package management system and lineage. A Linux distribution is an operating system built on the Linux kernel, typically with the GNU userland and a package manager, together with a selection of applications and a desktop environment.

Debian-based

  • Debian — one of the oldest distributions (1993), developed by a volunteer community; uses dpkg/APT and .deb packages.
  • Ubuntu — derived from Debian by Canonical (2004); the basis of many further derivatives including Linux Mint, Pop!_OS, elementary OS, and Zorin OS.
  • Raspberry Pi OS (formerly Raspbian) — optimised for the Raspberry Pi.
  • Kali Linux — focused on penetration testing and security auditing.
  • MX Linux, Devuan, Deepin, SteamOS (3.0, based on Arch; earlier versions on Debian).

Red Hat / Fedora-based (RPM)

  • Fedora Linux — community distribution sponsored by Red Hat.
  • Red Hat Enterprise Linux (RHEL) — commercial enterprise distribution; derivatives and rebuilds include CentOS (until 2020), CentOS Stream, Rocky Linux, and AlmaLinux.
  • Mageia and OpenMandriva — descended from the former Mandriva Linux.

SUSE-based

  • openSUSE (Leap and Tumbleweed) and SUSE Linux Enterprise — using RPM packages with YaST and Zypper.

Arch-based

  • Arch Linux — rolling-release, do-it-yourself distribution using pacman.
  • Manjaro, EndeavourOS, Garuda Linux, and SteamOS 3.

Independent and other families

  • Gentoo — source-based distribution with the Portage package manager.
  • Slackware — among the oldest surviving distributions (1993).
  • Alpine Linux — small, security-oriented, musl-based; popular in containers.
  • Void Linux, NixOS (declarative package management), Solus, Clear Linux.
  • Android and ChromeOS — Linux-kernel-based systems outside the traditional GNU/Linux family tree.

Lightweight, live, and embedded distributions, as well as discontinued distributions of historical interest, are covered in separate sections and related lists.
