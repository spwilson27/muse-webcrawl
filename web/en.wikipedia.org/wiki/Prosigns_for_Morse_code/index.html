Prosigns for Morse code

Prosigns (procedural signals) are a set of standardised abbreviations used in Morse code radiotelegraphy to convey common procedural messages compactly. A prosign is written as two (sometimes more) letters with a line over them — for example AR — and is sent as a single character: the component letters are run together without the normal gap between letters, so the group is heard as one continuous signal.

Usage

Prosigns form part of the operating procedure that frames a radiotelegraph contact: a transmission may open with CT (attention), identify the parties with DE, close the message with AR, and close the contact with SK. Together with Q codes and amateur radio abbreviations, they allowed operators of different native languages to exchange service messages reliably. The most famous prosign, SOS, was adopted internationally in 1906–1908 as the maritime distress signal and is sent as a single unbroken string of three dits, three dahs and three dits.
