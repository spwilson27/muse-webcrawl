Injective function

In mathematics, an injective function (also known as an injection or one-to-one function) is a function f that maps distinct elements of its domain to distinct elements of its codomain. In other words, if f(a) = f(b) then necessarily a = b; equivalently, no two different inputs share the same output.

Properties

An injective function need not map onto every element of the codomain — that stronger property is surjectivity; a function that is both injective and surjective is bijective and has an inverse function. Every injective function has a left inverse, and a function has a (two-sided) inverse if and only if it is bijective. On the real numbers, a continuous function is injective if and only if it is strictly monotonic; the horizontal line test checks injectivity graphically.

Examples

The function f(x) = 2x on the reals is injective, whereas f(x) = x² is not, since f(2) = f(−2) = 4; restricting the squaring function to non-negative inputs makes it injective. The exponential function is injective, with the natural logarithm as its inverse. In set theory, the existence of an injection from set A to set B is written |A| ≤ |B| and is central to the theory of cardinal numbers; the Cantor–Bernstein theorem states that injections in both directions imply a bijection.
