Fuzzball router

Fuzzball routers were the first modern routers on the Internet. Invented by David L. Mills of the University of Delaware, they were built around DEC PDP-11 minicomputers running the Fuzzball operating system and software written by Mills.

History

The name "Fuzzball" began as Mills's term for the routing and network measurement software. In 1986 the National Science Foundation selected Fuzzball routers, running on LSI-11 hardware, to operate the original NSFNET backbone at 56 kbit/s — the first production network to run TCP/IP protocols in this role.

Technical features

Fuzzballs implemented early versions of the Exterior Gateway Protocol (EGP), the Hello routing protocol, network time synchronisation that led to NTP, and extensive network measurement and debugging tools. Mills used them as testbeds for congestion control and clock synchronisation research.

Legacy

Although soon outpaced by dedicated commercial routers, Fuzzballs played a foundational role in the development of Internet routing and of the Network Time Protocol.
