Control system

A control system manages, commands, directs, or regulates the behavior of other devices or systems using control loops. It can range from a single home heating controller to large industrial process control systems used for controlling production machinery and plants.

Open- and closed-loop control

In an open-loop system, the controller acts without measuring the result — for example, a simple timer-based sprinkler. In a closed-loop (feedback) system, sensors measure the output and the controller adjusts its action based on the error between the desired setpoint and the measured value. The humble thermostat is a classic feedback controller, as is the centrifugal governor fitted to early steam engines.

Control theory

The mathematical study of control systems is control theory. Common controller designs include on–off (bang–bang) control, the widely used PID controller (proportional–integral–derivative), and model-based modern controllers developed using state-space methods. Key design concerns include stability, responsiveness, robustness to disturbances, and steady-state accuracy.

Implementation

Control loops may be implemented with mechanical, pneumatic, electrical, or digital devices. Modern industrial systems typically use programmable logic controllers (PLCs), distributed control systems (DCS), and SCADA software, while embedded controllers govern everything from washing machines to aircraft autopilots.
