Indicator function

In mathematics, an indicator function or characteristic function of a subset A of a set X is a function 1A : X → {0, 1} defined by 1A(x) = 1 if x ∈ A, and 0 if x ∉ A. It "indicates" membership of the subset: the function is 1 exactly on A and 0 outside it.

Notation and properties

Common notations include 1A, IA and χA (the term characteristic function has a different, conflicting meaning in probability theory, where it denotes the Fourier transform of a distribution). Indicator functions convert set operations into arithmetic: the indicator of an intersection is the product of the indicators, and that of a union can be written 1A∪B = 1A + 1B − 1A1B.

Applications

In measure theory, simple functions are linear combinations of indicator functions of measurable sets, and the Lebesgue integral is built up from them. In probability, the expected value of the indicator of an event equals the probability of the event, a fact used throughout statistics. Indicator (0–1) variables are likewise ubiquitous in combinatorics, optimisation and machine learning.
