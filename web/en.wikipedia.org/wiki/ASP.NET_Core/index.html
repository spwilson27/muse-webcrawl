ASP.NET Core

ASP.NET Core
Developer: Microsoft
Initial release: June 27, 2016
Written in: C#
Platform: Cross-platform, .NET

ASP.NET Core is a free, open-source, cross-platform web framework developed by Microsoft as the successor to ASP.NET. It runs on Windows, macOS and Linux on .NET, supports building web apps, APIs and microservices, and unifies MVC and Web API patterns.

Features

Features include a modular middleware pipeline, built-in dependency injection, Razor Pages, Blazor for client-side C#, gRPC support, and high performance in benchmarks. From .NET 5 onward the "Core" branding continued in versions while the runtime unified.
