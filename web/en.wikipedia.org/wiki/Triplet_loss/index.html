Triplet loss

Triplet loss is a loss function for machine learning algorithms where a baseline (anchor) input is compared to a positive input and a negative input. The distance from the baseline (anchor) input to the positive input is minimized, and the distance from the baseline (anchor) input to the negative input is maximized. An early formulation of the idea was introduced in metric learning for face recognition by researchers at Google, and the method was popularized by the FaceNet system described by Schroff, Kalenichenko and Philbin in 2015.

Definition

Let f(x) be an embedding function mapping an input into a d-dimensional Euclidean space. For a triplet consisting of an anchor a, a positive example p (same class as the anchor) and a negative example n (different class), the triplet loss is:

L = max( d(a, p) − d(a, n) + α, 0 )

where d is typically the squared Euclidean distance and α is a margin enforced between positive and negative pairs. The goal of training is that, after optimization, the anchor is closer to the positive than to the negative by at least the margin α.

Triplet selection

The effectiveness of triplet loss depends heavily on how triplets are sampled. Random triplets often produce near-zero loss early in training, so practitioners use mining strategies:

  • Hard negatives: negatives closer to the anchor than the positive, giving the largest loss but sometimes causing instability or collapse.
  • Semi-hard negatives: negatives that are farther than the positive but still within the margin; these were used in FaceNet and tend to train more stably.
  • Easy negatives: negatives already farther than the positive by more than the margin, contributing zero loss.

Online mining, in which triplets are formed within each mini-batch, is common in modern implementations.

Applications

Triplet loss has been applied to face recognition and verification, person re-identification, image retrieval, signature verification, speaker recognition, and learning embeddings for recommendation systems. Variants and related contrastive objectives include the contrastive loss of Chopra, Hadsell and LeCun, the N-pair loss, lifted structured loss, and quadruplet loss, which adds a second negative constraint.
