Perl is a high-level, general-purpose, interpreted, dynamic programming language. Though Perl is not officially an acronym, there are various backronyms in use, including "Practical Extraction and Reporting Language". Perl was developed by Larry Wall in 1987 as a general-purpose Unix scripting language to make report processing easier. Since then, it has undergone many changes and revisions.

Perl borrows features from other programming languages including C, sh, AWK, and sed. The language provides powerful text processing facilities without the arbitrary data-length limits of many contemporary Unix command-line tools. Perl is a highly expressive programming language: source code for a given algorithm can be short and highly compressible.

History

Larry Wall began work on Perl in 1987, while working as a programmer at Unisys; version 1.0 was released to the Usenet newsgroup comp.sources.misc on 18 December 1987. The language expanded rapidly over the next few years. Perl 2, released in 1988, featured a better regular expression engine. Perl 3, released in 1989, added support for binary data streams. Perl 4 followed in 1991, and Perl 5 appeared in October 1994, introducing references, modules, and a much-improved interpreter.

The design principle of Perl, summed up in its motto "There's more than one way to do it" (TMTOWTDI), together with the slogan "Perl: the Swiss Army chainsaw of scripting languages", reflects its philosophy of giving the programmer freedom and providing multiple ways to express solutions.

Features

Perl's rich set of built-in functions and operators — particularly its native regular expression engine, associative arrays (hashes), and list-processing functions such as map and grep — made it a favourite for text manipulation, system administration, and early web development through CGI scripts.

#!/usr/bin/perl
use strict;
use warnings;
my %count;
while (<>) {
    $count{$_}++ for split;
}
print "$count{$_} $_\n" for sort keys %count;

Community and culture

The Comprehensive Perl Archive Network (CPAN), founded in 1995, hosts tens of thousands of freely available modules. The Perl community also developed a playful culture of obfuscated code, Perl golf, poetry written in Perl, and the annual Yet Another Perl Conference (YAPC) gatherings. In 2019, the language long known as Perl 6 was renamed Raku, and Perl 5 continued as Perl, with version numbering continuing from 5.32 onward.
