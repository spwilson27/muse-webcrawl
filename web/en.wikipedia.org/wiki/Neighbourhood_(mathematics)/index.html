Neighbourhood (mathematics)

In topology and related areas of mathematics, a neighbourhood (or neighborhood) of a point is one of the basic concepts. Intuitively, a neighbourhood of a point is a set of points containing that point where one can move some amount in any direction away from the point without leaving the set.

Definition

If X is a topological space and p is a point in X, then a neighbourhood of p is a subset V of X that includes an open set U containing p: p ∈ U ⊆ V. The point p need not itself be open. Equivalently, a neighbourhood of p is a set whose interior contains p. A neighbourhood of a set S is a set that is a neighbourhood of every point in S.

In a metric space

In a metric space M = (X, d), a set V is a neighbourhood of a point p if there exists an open ball centred at p with radius r > 0 contained in V. Such balls, and in particular the ε-neighbourhoods of a point, provide the standard examples: the set of all points within distance ε of p.

Neighbourhood systems

The collection of all neighbourhoods of a point is called the neighbourhood system at that point. Neighbourhood systems satisfy axioms (non-emptiness, superset closure, finite intersection, and an openness condition) that allow a topology to be reconstructed from them, making neighbourhoods an alternative foundation for topology alongside open sets, closed sets, and closure operators.
