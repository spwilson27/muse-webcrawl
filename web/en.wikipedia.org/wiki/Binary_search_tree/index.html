In computer science, a binary search tree (BST), also called an ordered or sorted binary tree, is a rooted binary tree data structure whose internal nodes each store a key, and in which every node's key is greater than all keys in its left subtree and less than all keys in its right subtree. This binary search tree property allows algorithms akin to binary search to locate, insert, and delete elements efficiently.

A binary search tree of size 9 and depth 3.

Operations

Searching begins at the root: if the target key equals the node's key, the search succeeds; if it is smaller, the search continues in the left subtree; if larger, in the right subtree. Insertion follows the same descent and attaches the new key as a leaf where the search falls off the tree. Deletion has three cases: a leaf is simply removed; a node with one child is replaced by that child; a node with two children is replaced by its in-order successor (or predecessor), which is then deleted. An in-order traversal of a BST visits the keys in sorted order — a standard way to implement sorting.

Performance

The cost of BST operations is proportional to the tree's height. For randomly built trees the expected height is O(log n), giving logarithmic average-case performance. However, inserting keys in sorted order degenerates the tree into a linked list with O(n) operations. This weakness motivates self-balancing binary search trees — such as AVL trees, red–black trees, and splay trees — which restructure themselves during updates to guarantee a logarithmic height.

Uses

Binary search trees underlie implementations of associative arrays (maps and sets) in many programming libraries, are used in database indexing (in generalized form, as B-trees), and appear in graphics, networking, and operating systems wherever ordered dynamic sets are needed.
