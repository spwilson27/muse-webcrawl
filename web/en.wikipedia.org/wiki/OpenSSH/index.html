OpenSSH

Developer: The OpenBSD Project

Initial release: 1 December 1999

Written in: C

Operating system: Cross-platform

License: BSD

Type: Secure shell software suite

OpenSSH (also known as OpenBSD Secure Shell) is a suite of secure networking utilities based on the Secure Shell (SSH) protocol, which provides a secure channel over an unsecured network in a client–server architecture. It is the most widely used implementation of SSH and is developed by the OpenBSD project.

OpenSSH started as a fork of the free SSH program developed by Tatu Ylönen. It was created as an alternative to the original SSH software, which had become proprietary. The first release, OpenSSH 1.2.2, appeared in December 1999 as part of OpenBSD 2.6.

Components

The suite includes:

  • sshd — the SSH server daemon
  • ssh — the client program for remote login
  • scp — secure copy (legacy protocol)
  • sftp — secure file transfer program, with sftp-server
  • ssh-keygen, ssh-keyscan, ssh-add, and ssh-agent — key management utilities

Features

OpenSSH supports strong encryption, public-key and password authentication, X11 forwarding, port forwarding (tunnelling), and agent forwarding. Development is led by the OpenBSD team under the direction of Theo de Raadt, with a focus on security: the codebase uses privilege separation, in which the daemon splits work between a privileged monitor process and unprivileged child processes, minimizing the impact of vulnerabilities. Portable releases adapt the code to Linux, macOS, the other BSDs, and other platforms; Microsoft ships OpenSSH as a component of Windows 10 and later and Windows Server.

Security record and development

The project is funded by donations and the OpenBSD Foundation. Its developers emphasize proactive auditing and the rapid removal of obsolete or insecure code — for example, dropping support for the SSH 1 protocol in 2017 and progressively disabling weak algorithms such as DSA and SHA-1-based signatures. In 2024, the "regreSSHion" vulnerability (CVE-2024-6387), a signal-handler race condition in sshd, was disclosed by Qualys and patched by the project.
