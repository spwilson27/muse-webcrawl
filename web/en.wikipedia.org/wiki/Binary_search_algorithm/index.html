Binary search algorithm

Binary search halves the search interval at each step.

In computer science, binary search, also known as half-interval search, is a search algorithm that finds the position of a target value within a sorted array. It compares the target with the middle element of the array; if they are unequal, the half in which the target cannot lie is eliminated, and the search continues on the remaining half until the target is found or the interval is empty.

Procedure

The algorithm maintains the invariant that the target, if present, lies within the current search interval. Each step computes the middle element and narrows the interval to either the lower or upper half. Because the interval shrinks by a factor of two at every iteration, the algorithm runs in logarithmic time.

function binary_search(A, n, T):
    L := 0
    R := n − 1
    while L ≤ R:
        m := floor((L + R) / 2)
        if A[m] < T: L := m + 1
        else if A[m] > T: R := m − 1
        else: return m
    return unsuccessful

Complexity

Binary search runs in O(log n) time and, in its iterative form, O(1) extra space. It is dramatically faster than linear search for large data sets: searching a billion elements requires at most about 30 comparisons. The data must be sorted, and the array must support random access; for linked lists binary search is impractical.

History and pitfalls

Although the idea is old, the first published binary search algorithm that works for all array sizes appeared in 1960, in a paper by Derrick Henry Lehmer. The algorithm is famously easy to describe but hard to implement correctly: Jon Bentley reported that most professional programmers given the task produced code containing overflow or off-by-one bugs, notably when computing the midpoint of very large arrays.
