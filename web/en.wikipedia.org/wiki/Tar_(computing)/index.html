tar (computing)

In computing, tar (derived from tape archive) is a computer software utility for collecting many files into one archive file, often referred to as a tarball, for distribution or backup purposes. The archive normally retains the file structure, ownership and timestamps of the original files. The tar format itself does not compress data; archives are commonly compressed with programs such as gzip, bzip2 or xz, producing files with extensions such as .tar.gz or .tgz.

History

The tar command first appeared in Version 7 Unix in 1979, designed to write archives onto sequential magnetic tape. Successive standardised formats — ustar (POSIX.1-1988) and the extended pax format (POSIX.1-2001) — added support for longer file names, larger files and additional metadata. GNU tar, BSD tar (libarchive) and other implementations remain standard tools on Unix-like systems.

Format

A tar archive is a sequence of 512-byte blocks. Each file is preceded by a header block recording its name, size, modification time, permissions and ownership, followed by the file's contents padded to a whole number of blocks. Two blocks of zeros mark the end of the archive.

Usage

Common invocations include tar -cf archive.tar files to create an archive, tar -xf archive.tar to extract one, and tar -czf archive.tar.gz files to create a gzip-compressed archive. Because source code for Unix software is traditionally distributed as tarballs, tar remains a ubiquitous part of software packaging and backup workflows.
