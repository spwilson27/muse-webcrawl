False positive rate

From Wikipedia, the free encyclopedia

The false positive rate (FPR) is the proportion of all negatives that still yield positive test outcomes; that is, the conditional probability of a positive test result given an event that was not present. It is defined as:

FPR = FP / (FP + TN)

where FP is the number of false positives and TN is the number of true negatives. The false positive rate is closely related to the specificity (true negative rate) of a test: specificity = 1 − FPR.

In hypothesis testing

In statistical hypothesis testing, the false positive rate corresponds to the Type I error rate, conventionally denoted α. A test conducted at significance level α = 0.05 will, in the long run, falsely reject a true null hypothesis about 5% of the time. When many hypotheses are tested simultaneously, the probability of at least one false positive grows, which motivates multiple-comparison corrections such as the Bonferroni correction and procedures controlling the false discovery rate.

In classification

In binary classification and machine learning, the false positive rate is one axis of the receiver operating characteristic (ROC) curve; the other axis is the true positive rate (sensitivity). Lowering the classification threshold generally increases both true and false positive rates, and model design involves trading one off against the other.

Medical testing example

In screening for a rare condition, even a test with a low false positive rate can produce more false positives than true positives, because the number of healthy people tested vastly exceeds the number of cases — a consequence of the base rate of the condition in the population.
