Minimalist program

The minimalist program is a framework within generative linguistics, developed principally by Noam Chomsky beginning in the early 1990s, which seeks to explain the faculty of language with the simplest possible machinery consistent with the facts.

Core ideas

Minimalism treats language as an optimal solution to interface conditions imposed by the conceptual-intentional and sensory-motor systems. Its central operation is Merge, which combines two syntactic objects into one; later versions add Agree and feature-checking, phases, and the Strong Minimalist Thesis that the language faculty is an optimal realisation of such conditions. Key texts include The Minimalist Program (1995) and Derivation by Phase (2001).
