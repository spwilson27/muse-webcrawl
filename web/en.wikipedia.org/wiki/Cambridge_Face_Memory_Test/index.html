Cambridge Face Memory Test

Cambridge Face Memory Test
Authors: Brad Duchaine, Ken Nakayama (2006)
Measures: face recognition ability
Format: 72 forced-choice trials, 6 target faces

The Cambridge Face Memory Test (CFMT) is a widely used psychological test of face recognition ability, introduced by Brad Duchaine and Ken Nakayama in 2006 to assess individuals with prosopagnosia (face blindness) and to measure variation in face memory in the general population.

Design

Test-takers first study six target male faces, then complete 72 three-alternative forced-choice trials in three stages: recognition of the studied images, recognition of novel views and lighting of the same identities, and recognition with Gaussian noise added. The images are cropped to remove hair and other external cues, so performance depends on processing the face itself.

Use

The CFMT became a benchmark in face-perception research, used to identify developmental prosopagnosia and exceptionally strong "super-recogniser" performers. Because the original test became widely circulated, variants such as the CFMT+ (with extra, harder trials) and versions using other-race faces were developed.
