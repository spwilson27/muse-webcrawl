Conjugacy class

Elements in the same conjugacy class are related by conjugation, gag−1.

In mathematics, especially group theory, two elements a and b of a group G are conjugate if there exists an element g in G such that gag−1 = b. This is an equivalence relation whose equivalence classes are called conjugacy classes. Members of the same conjugacy class cannot be distinguished from each other using group structure alone, and share many properties. The study of conjugacy classes of non-abelian finite groups is central to the study of their structure.

Definition

The conjugacy class of an element a in a group G is the set

Cl(a) = { gag−1 : g ∈ G }.

Conjugacy is an equivalence relation: it is reflexive, symmetric and transitive, so the group is partitioned into disjoint conjugacy classes. In an abelian group, conjugation is trivial and every conjugacy class is a singleton. The identity element is always alone in its class, and more generally the centre Z(G) consists exactly of those elements whose conjugacy class has size one.

Class equation

The size of the conjugacy class of a equals the index of its centraliser, |G : CG(a)|, and therefore divides the order of the group. Summing over one representative from each class gives the class equation:

|G| = |Z(G)| + Σ [G : CG(ai)],

where the sum runs over representatives of the non-central classes. The class equation is a basic tool in proving results such as the non-triviality of the centre of a finite p-group, and hence that groups of order p2 are abelian.

Examples

In the symmetric group Sn, two permutations are conjugate if and only if they have the same cycle type; thus conjugacy classes correspond to partitions of n. In the rotation group of a cube, classes correspond to rotation types (by axis and angle). Conjugate matrices in the general linear group are those representing the same linear map in different bases — they share the same rational and Jordan canonical forms.

Applications

The number of conjugacy classes of a finite group equals the number of its irreducible complex representations, and class sums form a basis of the centre of the group algebra, facts that underpin character theory. Conjugacy also arises in the classification of group elements in crystallography and in the study of symmetry in physics.
