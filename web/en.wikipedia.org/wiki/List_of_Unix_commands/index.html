List of Unix commands

This is a list of Unix commands — programs and utilities found in Unix and Unix-like operating systems. Many are standardized by POSIX and the Single UNIX Specification; others are specific to particular systems such as GNU/Linux or the BSD family. Commands are grouped here by function.

File and directory management

CommandDescription
lsList directory contents
cdChange the working directory
cpCopy files and directories
mvMove or rename files
rmRemove files or directories
mkdir / rmdirCreate / remove directories
touchChange file timestamps or create empty files
lnMake hard or symbolic links
findSearch for files in a directory hierarchy
chmod / chownChange file permissions / ownership

Text processing

CommandDescription
catConcatenate and print files
grepPrint lines matching a pattern
sedStream editor for filtering and transforming text
awkPattern scanning and text processing language
sort / uniqSort lines / report or omit repeated lines
head / tailOutput the first / last part of files
wcCount lines, words, and bytes
cutRemove sections from each line of files
diffCompare files line by line
vi / emacsText editors

System and process management

CommandDescription
psReport a snapshot of current processes
killSend a signal to a process
topDisplay and update sorted process information
df / duReport file system disk space usage / estimate file space usage
mount / umountMount / unmount file systems
sudoExecute a command as another user (typically root)
manDisplay the manual pages
env / exportShow or set environment variables

Networking

CommandDescription
pingSend ICMP echo requests to network hosts
sshOpenSSH remote login client
scp / sftpSecure file copy / secure file transfer
curl / wgetTransfer data from or to a server
netstat / ssPrint network connections and socket statistics
