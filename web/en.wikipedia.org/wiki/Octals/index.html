Octal

The octal numeral system is the base-8 positional number system, using the digits 0 through 7. Because eight is a power of two (23), each octal digit corresponds exactly to three binary digits, which made octal a convenient shorthand for binary in early computing.

Use in computing

Octal was widely used on machines whose word lengths were divisible by three, such as the PDP-8 and other Digital Equipment Corporation systems, and in the instruction sets of early mainframes. In Unix and Unix-like systems, file permissions are conventionally expressed as three octal digits (for example, 755) representing read, write and execute rights for owner, group and others, as set by the chmod command. In many programming languages descended from C, an integer literal beginning with a leading zero denotes an octal number, a convention that occasionally causes confusion; newer notations such as 0o have been introduced in some languages to make the base explicit.

Conversion

To convert binary to octal, the binary digits are grouped in threes from the right and each group replaced by its octal digit. The decimal number 65, for example, is 1000001 in binary, grouped as 1 000 001, giving 101 in octal.

Other uses

Octal counting has been reported in some indigenous languages of Mexico and California, where speakers counted using the spaces between the fingers rather than the fingers themselves. In aviation, transponder codes are assigned as four-digit octal numbers (0000–7777).
