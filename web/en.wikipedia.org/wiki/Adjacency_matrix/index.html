Adjacency matrix

In graph theory and computer science, an adjacency matrix is a square matrix used to represent a finite graph: its entries indicate whether pairs of vertices are adjacent (joined by an edge).

Definition

For a graph with n vertices, the matrix is n × n. The entry aij equals 1 (or the edge weight) if vertices i and j are joined, and 0 otherwise. Undirected graphs give symmetric matrices; the diagonal counts loops twice in standard convention.

Properties and uses

Powers of the adjacency matrix count walks of a given length between vertices; its eigenvalues form the graph's spectrum, used in spectral graph theory, network analysis, and Markov chain representations. Space cost is O(n²), favouring adjacency lists for sparse graphs.
