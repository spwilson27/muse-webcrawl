SPARQL

From Wikipedia, the free encyclopedia

SPARQL (pronounced "sparkle", an acronym for SPARQL Protocol and RDF Query Language) is an RDF query language—that is, a semantic query language for databases—able to retrieve and manipulate data stored in Resource Description Framework (RDF) format. It was made a standard by the RDF Data Access Working Group (DAWG) of the World Wide Web Consortium, and became a W3C Recommendation on 15 January 2008. SPARQL 1.1, which added update and entailment features, became a Recommendation in March 2013.

Overview

SPARQL allows users to write queries against data that can be loosely called "key-value" data, more specifically data conforming to the RDF specification of the W3C. A whole database is thus a set of subject–predicate–object triples. SPARQL queries consist of triple patterns matched against the RDF graph, combined with filters, optional patterns, unions, and other graph-pattern operators.

Query forms

SPARQL defines four query forms:

  • SELECT — extracts raw values in tabular form.
  • CONSTRUCT — extracts data transformed into a valid RDF graph.
  • ASK — returns a boolean indicating whether a pattern matches.
  • DESCRIBE — extracts an RDF graph describing a resource.
SELECT ?name ?email
WHERE {
  ?person a foaf:Person .
  ?person foaf:name ?name .
  OPTIONAL { ?person foaf:mbox ?email }
}

Protocol and endpoints

The SPARQL protocol defines how queries are sent to a SPARQL processor over HTTP. Public SPARQL endpoints include the DBpedia and Wikidata query services, which allow arbitrary queries over large knowledge bases derived from Wikipedia.
