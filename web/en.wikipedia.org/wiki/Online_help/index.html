Online help

Online help is documentation and assistance provided to users of software as part of the application itself, in formats that can be displayed on screen, searched, and navigated by hyperlinks. It replaced printed manuals as the primary form of user assistance for most software products.

Characteristics

Online help systems are typically organized as collections of topics, each covering a task, concept, or interface element. Users navigate through tables of contents, alphabetical indexes, and full-text search. Unlike linear manuals, help topics are written to be read in whatever order the user's problem dictates.

Common forms include context-sensitive help, which opens the topic relevant to the current dialog or screen; tooltips and embedded cues within the interface; and procedural "how-to" topics that walk the user through tasks step by step.

Formats and technologies

Early systems included the help facilities of mainframe and Unix systems, such as man pages. In desktop software, notable formats have included WinHelp and its successor Microsoft Compiled HTML Help (CHM), Apple Help, JavaHelp, and Oracle Help for the Web. Modern help is commonly delivered as web-based documentation hosted on vendor sites, allowing publishers to update content after the software ships and to gather usage analytics.

Authoring

Help content is produced by technical writers using help authoring tools. Single-source publishing workflows let the same source content be output as online help, PDF manuals, and web pages. Structured authoring standards such as DITA (Darwin Information Typing Architecture) support topic-based help development.
