Simple Mail Transfer Protocol

SMTP
Ports: 25 (relay), 587 (submission), 465 (implicit TLS)
Standard: RFC 5321 (2008)
Layer: Application

The Simple Mail Transfer Protocol (SMTP) is the standard Internet protocol for sending electronic mail. Mail servers and other message transfer agents use SMTP to send and relay messages, while mail clients typically retrieve mail with IMAP or POP3. SMTP was first defined in 1982 (RFC 821) by Jon Postel and is currently specified by RFC 5321.

Operation

SMTP is a text-based, connection-oriented protocol over TCP. A sending host opens a connection, greets the server with HELO or EHLO, and issues commands such as MAIL FROM, RCPT TO, and DATA, followed by the message headers and body, terminated by a line containing a single dot. Servers reply with three-digit status codes. Messages are typically relayed through several servers, each adding a Received header.

Extensions and security

Extended SMTP (ESMTP) allows servers to advertise optional features negotiated at EHLO, including STARTTLS encryption, authentication (SMTP AUTH), pipelining, and size limits. Port 587 is designated for authenticated message submission by clients, and port 465 for submission over implicit TLS. Because SMTP originally lacked sender authentication, adjunct standards — SPF, DKIM, and DMARC — were developed to combat spoofing and spam.

History

SMTP replaced earlier mail transfer methods on the ARPANET and became the backbone of Internet email in the 1980s. Despite predictions of its decline, it remains the universal mechanism for mail transport between organisations.
