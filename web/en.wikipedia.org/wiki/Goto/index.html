Goto

This article is about the programming statement. For other uses, see Goto (disambiguation).

Goto is a statement found in many computer programming languages. It performs a one-way transfer of control to another line of code; in contrast, a function call normally returns control. The jumped-to locations are usually identified using labels, though some languages use line numbers. At the machine code level, a goto is a form of branch or jump statement. GOTO is the keyword in many languages, notably BASIC, Fortran and C (as goto).

Usage

A goto statement transfers execution unconditionally to a labelled statement elsewhere in the program (usually within the same function). Common uses include breaking out of deeply nested loops, jumping to shared error-handling code at the end of a function (a common idiom in C), implementing state machines, and generated code. In early languages such as Fortran, Cobol and BASIC, goto was the principal — sometimes the only — means of controlling program flow, and programs written with indiscriminate gotos became known as "spaghetti code" for their tangled control paths.

Criticism and structured programming

The dangers of goto were famously articulated by Edsger W. Dijkstra in his 1968 letter to the Communications of the ACM, published under the editor-supplied title "Go To Statement Considered Harmful". Dijkstra argued that unconditional jumps make the static text of a program a poor guide to its dynamic behaviour, hindering reasoning and verification. The letter helped ignite the structured programming movement, which favoured control structures such as loops, conditionals and subroutines with single entry and exit points. Donald Knuth's 1974 paper "Structured Programming with go to Statements" offered a more measured view, defending limited, disciplined uses. Standard results such as the Böhm–Jacopini theorem show goto is never strictly necessary, since any flowchart program can be re-expressed with sequence, selection and iteration.

In modern languages

Many languages still include a restricted goto: C, C++, C#, PHP and Perl among them; Java reserves the word but does not implement it, providing labelled break and continue instead, and Python omits it entirely. Modern practice generally discourages goto, although the error-cleanup pattern in C, jumping forward to a single exit block, is widely accepted, including in the Linux kernel.
