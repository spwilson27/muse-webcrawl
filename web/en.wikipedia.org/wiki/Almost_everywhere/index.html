Almost everywhere

From Wikipedia, the free encyclopedia

In measure theory, a property P is said to hold almost everywhere (abbreviated a.e.) on a measure space if the set of points at which P fails has measure zero. Equivalently, P holds at every point of some subset whose complement is null. The notion generalises the idea of "almost surely" in probability theory, where probability replaces measure.

Examples

A bounded function on a closed interval is Riemann integrable if and only if it is continuous almost everywhere (the Lebesgue criterion). Two functions that agree almost everywhere define the same element of the spaces Lp, which is why those spaces are properly spaces of equivalence classes of functions rather than of functions themselves. A real number chosen at random is irrational almost surely — the rationals have Lebesgue measure zero — and is in fact a normal number almost surely.

Related notions

"Almost everywhere" must not be confused with "everywhere except a countable set" (a stricter condition) or with "for all but finitely many" points. In analysis it is common to modify functions on null sets freely: the value of a Lebesgue integral, for instance, is unchanged if the integrand is altered on a set of measure zero. Convergence of a sequence of functions "almost everywhere" is pointwise convergence outside a null set, a concept central to theorems such as Egorov's theorem and the dominated convergence theorem.
