COMMAND.COM

From Wikipedia, the free encyclopedia

COMMAND.COM is the default command-line interpreter for MS-DOS, Windows 95, Windows 98 and Windows Me. In OS/2 and Windows NT, the default command interpreter is cmd.exe, although COMMAND.COM is also provided in 32-bit versions of those systems for backward compatibility. COMMAND.COM is the successor of COMMAND.EXE in CP/M-derived traditions and is loaded at startup as the user shell.

As a shell, COMMAND.COM provides internal commands such as DIR, COPY, DEL, TYPE, REN, CD, MD, RD, CLS, DATE, TIME, VER, and VOL, and it runs batch files with the .BAT extension. It reads the file AUTOEXEC.BAT at boot to configure the environment and drivers. External commands are provided by separate utility programs in the DOS directory.

Technical details

COMMAND.COM has two parts: a resident portion, loaded in low memory, and a transient portion in high conventional memory that could be overwritten by large application programs; when an application exited, a checksum verified whether the transient part needed to be reloaded from disk. It also installs the critical-error handler responsible for the famous "Abort, Retry, Fail?" prompt.

History

The interpreter shipped with every version of MS-DOS from 1.0 (1981) through PC DOS 2000 and was included in Windows up to Windows Me. Derivatives and work-alikes include DR-DOS's COMMAND.COM and FreeDOS's FreeCom. In modern Windows, PowerShell and cmd.exe have entirely supplanted it.
