Tails (operating system)

Tails, or "The Amnesic Incognito Live System", is a security-focused Debian-based Linux distribution aimed at preserving privacy and anonymity. It is designed to be booted as a live system from a USB stick or DVD, routes all network traffic through the Tor network, and leaves no trace on the host machine unless explicitly configured otherwise.

Features

Tails comes preconfigured with applications for secure communication and document handling, including the Tor Browser, Thunderbird with encryption support, KeePassXC, and LibreOffice. An encrypted persistent volume can optionally be created on the USB device to retain files and settings between sessions; without it, the system is "amnesic", forgetting everything on shutdown.

History

The project was first released in June 2009 under the name Amnesia. It gained wide public attention in 2013–2014 after it was revealed that whistleblower Edward Snowden and journalists working with his documents used Tails for secure communication. It is developed by the Tails project with support from the Tor Project and other sponsors.
