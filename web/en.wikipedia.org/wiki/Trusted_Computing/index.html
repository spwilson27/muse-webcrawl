Trusted Computing (TC) is a technology developed and promoted by the Trusted Computing Group. The term is taken from the field of trusted systems and has a specialized meaning that is distinct from the concept of a trusted system in information security. With Trusted Computing, a computer system consistently behaves in expected ways; those behaviours are enforced by the computer's hardware and software, using cryptographic keys and a hardware component called the Trusted Platform Module (TPM).

Key concepts

Trusted Computing encompasses several key ideas: endorsement of the hardware by a unique cryptographic key burned into the TPM at manufacture; secure input and output; memory curtaining, which isolates sensitive data in protected memory; sealed storage, which encrypts data so it can only be decrypted in a specific software state; and remote attestation, which allows a remote party to verify that a system is running expected software.

Criticism

Critics such as Richard Stallman and Ross Anderson have argued that Trusted Computing could be used to restrict what users can do with their own computers — for example by enforcing digital rights management, locking users into particular applications, or allowing vendors to censor software — and dubbed it "treacherous computing". Supporters respond that the technology protects against malware, theft and tampering, and that features such as attestation can be switched off or placed under owner control.
