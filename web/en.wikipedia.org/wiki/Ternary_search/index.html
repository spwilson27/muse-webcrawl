Ternary search

A ternary search is a divide-and-conquer algorithm for finding the minimum or maximum of a unimodal function — a function that strictly increases and then strictly decreases (or vice versa). The technique is similar to binary search but divides the interval into three parts at each step, discarding the third that cannot contain the extremum.

Ternary search on a unimodal function

Algorithm

Given a unimodal function f on the interval [l, r], two interior points are evaluated:

m1 = l + (r - l) / 3
m2 = r - (r - l) / 3

If f(m1) < f(m2) (when seeking a maximum), the maximum cannot lie in [l, m1], so the search continues on [m1, r]; otherwise it continues on [l, m2]. The interval shrinks by a factor of 2/3 per iteration, so the algorithm requires O(log2/3(ε)) evaluations to reach precision ε. For discrete unimodal arrays the procedure terminates when the interval becomes sufficiently small, after which the few remaining points are checked directly.

Uses

Ternary search is used in optimisation problems where the objective function is known to be unimodal but has no easily computed derivative — for example, maximising a likelihood, tuning a physical quantity, or finding the best response in game-theoretic and geometry problems such as locating the point minimising the sum of distances along a line. When the function is evaluated many times, the golden-section search is a related alternative that reuses one function evaluation per iteration.
