Greedy randomized adaptive search procedure

The greedy randomized adaptive search procedure (GRASP) is a metaheuristic for combinatorial optimization problems, originally proposed by Thomas A. Feo and Mauricio G. C. Resende in the late 1980s. It is an iterative multi-start method in which each iteration constructs a solution greedily but with randomization, then improves it by local search.

Algorithm

In the construction phase, a solution is built element by element. At each step, candidate elements are ranked by a greedy function, and instead of always taking the best, the algorithm forms a restricted candidate list (RCL) of the best few candidates and selects one at random from it. The quality threshold for the RCL is often controlled by a parameter α between 0 (purely greedy) and 1 (purely random). The greedy values are "adaptive" because they are recomputed as the partial solution grows. The constructed solution is then passed to a local search phase, which moves to a locally optimal solution. The best solution found over all iterations is returned.

Variants and applications

Important extensions include reactive GRASP, which adjusts α adaptively based on the quality of solutions previously obtained, and path relinking, which intensifies the search by exploring trajectories between elite solutions. GRASP has been applied to vehicle routing, scheduling, facility location, set covering, graph problems, and many other NP-hard optimization tasks.
