Windows Vista

Windows Vista is an operating system developed by Microsoft for use on personal computers, released to manufacturing on November 8, 2006, and generally available on January 30, 2007. It succeeded Windows XP after one of the longest development periods in Microsoft's history (codenamed "Longhorn") and was succeeded by Windows 7 in 2009.

Features

Vista introduced the Windows Aero visual style with translucent "glass" window frames, the Windows Sidebar and gadgets, instant search, Windows Defender, BitLocker drive encryption, and a redesigned networking and audio stack. It also debuted User Account Control (UAC), intended to limit software running with administrator privileges, and a greatly expanded set of parental controls and security features.

Reception

Vista received mixed to negative reviews. Criticisms focused on its high system requirements, intrusive UAC prompts, restrictive digital rights management, poor performance on hardware sold as "Vista Capable," and incompatibilities with existing devices and software. Two service packs improved performance and compatibility. Despite Vista's reputation, many of its underlying security and platform improvements were retained and refined in the more popular Windows 7.

Editions

Vista was sold in six editions, including Starter, Home Basic, Home Premium, Business, Enterprise, and Ultimate — a proliferation itself criticized as confusing.
