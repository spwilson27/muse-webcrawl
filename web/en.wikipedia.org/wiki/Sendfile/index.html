Sendfile

sendfile is a system call in Unix-like operating systems that transfers data between two file descriptors within the kernel, avoiding the overhead of copying data between kernel space and user space. It is widely used by web servers and file servers to serve static content efficiently.

Motivation

In the traditional approach, a server reads a file into a user-space buffer with read() and then writes it to a socket with write(), causing multiple context switches and redundant copies of the same data. With sendfile(), the kernel transfers the data directly—often using DMA from disk into the page cache and then gathering it to the network interface—so the data never passes through user space. This "zero-copy" technique substantially improves throughput for static file serving.

Implementations

The call originated in the form of sendfile() in Linux 2.2 and similar facilities in FreeBSD (developed for the Apache and thttpd servers), HP-UX and Solaris. Web servers such as nginx and Apache httpd expose sendfile support as a configuration option; it is typically disabled when serving from network filesystems or when TLS encryption must be performed in user space (kernel TLS can preserve the benefit).
