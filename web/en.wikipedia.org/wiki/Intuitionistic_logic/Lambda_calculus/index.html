Lambda calculus

From Wikipedia, the free encyclopedia

Lambda calculus (also written as λ-calculus) is a formal system in mathematical logic for expressing computation based on function abstraction and application using variable binding and substitution. It was introduced by the mathematician Alonzo Church in the 1930s as part of his research into the foundations of mathematics, and it has had a lasting influence on computer science, forming the theoretical basis of functional programming.

Syntax and reduction

Lambda expressions are built from variables, abstraction (λx. M, a function with parameter x and body M), and application (M N). Computation proceeds by beta reduction: applying (λx. M) N yields M with N substituted for x. Other rules include alpha conversion (renaming bound variables) and eta conversion. Despite its tiny syntax, the untyped lambda calculus is Turing complete: any computable function can be expressed in it, a result related to the Church–Turing thesis. The Church–Rosser theorem guarantees that the order of reductions does not affect the final result, when a normal form exists.

Typed lambda calculus

The simply typed lambda calculus assigns types to terms and corresponds, by the Curry–Howard correspondence, to intuitionistic propositional logic: types are propositions and terms are proofs. Typed variants always terminate under beta reduction, trading Turing completeness for strong logical properties. Richer type systems — System F, the calculus of constructions — underpin the design of functional languages and proof assistants.

Influence on programming

Lambda calculus inspired Lisp, the first functional programming language, and through it ML, Haskell, and features such as closures and anonymous functions ("lambdas") in mainstream languages. Its treatment of functions as first-class values is now standard across programming paradigms.
