The Arch User Repository (AUR) is a community-driven repository of package build scripts for users of the Arch Linux distribution. Unlike the official Arch repositories, which contain pre-built binary packages, the AUR hosts PKGBUILD scripts — shell scripts describing how to fetch, build and package software — which users download and compile with the makepkg tool.

How it works

Any registered user may submit a PKGBUILD for software not available in the official repositories. Other users can comment, vote and flag packages as out of date. Packages are maintained by their submitters; unmaintained packages may be adopted by new maintainers. Utilities known as "AUR helpers" automate searching the AUR and building packages, although the Arch project officially expects users to understand the manual build process.

Relationship to official repositories

Popular AUR packages may be adopted into the official repositories by Arch's Trusted Users and package maintainers. Because AUR content is user-submitted and not formally reviewed, users are advised to inspect PKGBUILD scripts before building them, and the AUR itself is not officially supported by Arch Linux — a distinction that forms a standard part of Arch installation guidance.

History

The AUR grew out of the earlier Arch User-contributed Repository and Trusted User Repository arrangements in the mid-2000s, centralising community packaging in a single web interface. It has since grown to contain tens of thousands of packages and is frequently cited as one of the largest community software collections of any Linux distribution.
