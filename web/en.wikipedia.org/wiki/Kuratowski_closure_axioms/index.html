Kuratowski closure axioms

In topology and related branches of mathematics, the Kuratowski closure axioms are a set of axioms that can be used to define a topological structure on a set. They are equivalent to the more commonly used open-set definition. They were first introduced by Kazimierz Kuratowski in 1922.

The axioms

A closure operator on a set X is a function cl: P(X) → P(X) from the power set of X to itself satisfying, for all subsets A, B of X:

  1. cl(∅) = ∅ (preservation of null unions)
  2. A ⊆ cl(A) (extensivity)
  3. cl(A ∪ B) = cl(A) ∪ cl(B) (preservation of binary unions)
  4. cl(cl(A)) = cl(A) (idempotence)

Given such an operator, a set is closed if it equals its own closure, and the family of closed sets defines a topology on X: arbitrary intersections of closed sets are closed, and finite unions of closed sets are closed.

Equivalence with topologies

Every topology on X determines a closure operator by assigning to each set its topological closure, and every closure operator satisfying the axioms arises this way, giving a one-to-one correspondence between topologies and Kuratowski closure operators. Analogous axiom systems exist for interior operators, which replace extensivity with intensivity, and for complement-dual approaches. Variants that drop idempotence give rise to Čech closure operators, used in pretopology and mathematical morphology.
