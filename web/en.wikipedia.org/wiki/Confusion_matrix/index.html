Confusion matrix

From Wikipedia, the free encyclopedia

In the field of machine learning and specifically the problem of statistical classification, a confusion matrix, also known as an error matrix, is a specific table layout that allows visualization of the performance of an algorithm, typically a supervised learning one. Each row of the matrix represents the instances in an actual class while each column represents the instances in a predicted class, or vice versa.

Binary classification

For a binary classifier, the matrix has four entries:

Predicted positivePredicted negative
Actually positiveTrue positive (TP)False negative (FN)
Actually negativeFalse positive (FP)True negative (TN)

The terminology comes from diagnostic testing and signal detection: a false positive is a "false alarm" (type I error), and a false negative is a "miss" (type II error).

Derived measures

Many standard evaluation metrics are computed from the four counts:

  • Accuracy = (TP + TN) / (TP + TN + FP + FN)
  • Precision (positive predictive value) = TP / (TP + FP)
  • Recall (sensitivity, true positive rate) = TP / (TP + FN)
  • Specificity (true negative rate) = TN / (TN + FP)
  • F1 score = harmonic mean of precision and recall
  • Matthews correlation coefficient — a balanced measure using all four cells.

Accuracy alone can be misleading on imbalanced datasets — a classifier that always predicts the majority class may score highly while being useless — so the full matrix and per-class measures are preferred.

Multiclass case

For problems with more than two classes, the confusion matrix is an n × n table whose diagonal entries are correct predictions and whose off-diagonal entries show which classes are confused with one another, guiding feature engineering and error analysis.
