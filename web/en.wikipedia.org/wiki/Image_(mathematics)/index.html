Image (mathematics)

In mathematics, the image of a function is the set of all output values it may produce. More generally, evaluating a given function at each element of a subset of its domain produces a set, called the "image of the subset under the function". The inverse image (or preimage) of a subset of the codomain is the set of all elements of the domain that map to its members.

A function f from X to Y; the image of the subset A is f(A), shown within the codomain.

Definition

Let f : X → Y be a function from set X (the domain) to set Y (the codomain). The image of an element x ∈ X is the single value f(x) ∈ Y. The image of a subset A ⊆ X is the set f(A) = { f(x) : x ∈ A }. The image of the whole domain, f(X), is also called simply the image of f, written im(f); it is always a subset of the codomain, and coincides with it exactly when the function is surjective.

Inverse image

The inverse image of a subset B ⊆ Y under f is the set f−1(B) = { x ∈ X : f(x) ∈ B }. Despite the notation, the inverse image is defined whether or not f has an inverse function. Images and preimages interact cleanly with unions and intersections: preimages preserve both unions and intersections, while images preserve unions but in general only inclusions for intersections — a distinction that underlies many constructions in topology, where a function is continuous precisely when preimages of open sets are open.

Examples

For f(x) = x² on the real numbers, the image of ℝ is the set of all nonnegative reals, [0, ∞), while the preimage of {4} is {−2, 2}. For the sine function, the image of ℝ is the interval [−1, 1].
