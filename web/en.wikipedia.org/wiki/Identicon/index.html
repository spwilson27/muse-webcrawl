Identicon

From Wikipedia, the free encyclopedia

An identicon is a visual representation of a hash value, usually of an IP address or a user identifier, that serves to identify a user of a computer system as a form of avatar while protecting the user's privacy. The original identicon was a 9-block graphic, proposed by Don Park in 2007 as a way to visually distinguish information units in blogs and online forums.

How it works

An identicon is generated deterministically from a hash of the input data. Bits of the hash select a colour and determine which blocks of a symmetric grid are filled. Because the pattern is mirrored, a small number of hash bits generates a large number of visually distinct patterns that are easy for humans to compare at a glance.

Uses

Identicons are best known as the default avatars once generated by GitHub for accounts without a profile picture: a 5×5 pixel-art pattern derived from the user ID. Gravatar offers identicons (and related generated styles such as "monsterid" and "wavatar") as fallbacks for email addresses without a registered image. Comment systems including WordPress plugins and various wikis have used them to give anonymous commenters persistent, recognisable identities without tracking.

Security considerations

Identicons help users spot impersonation or changes of identity, but they are not a security mechanism by themselves: collisions are possible, and an attacker who can choose identifiers can search for one whose identicon resembles a target's.
