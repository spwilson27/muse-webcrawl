Red Hat OpenShift is a family of containerisation software products developed by Red Hat. Its flagship product, the OpenShift Container Platform, is a commercial Kubernetes platform — a hybrid-cloud platform as a service built around Linux containers orchestrated and managed by Kubernetes on a foundation of Red Hat Enterprise Linux CoreOS.

History

OpenShift began in 2011 as a public platform-as-a-service (OpenShift Online) supporting applications in its own container format ("gears" and "cartridges"). Version 3 (2015) was rebuilt on Docker containers and Kubernetes; OpenShift 4 (2019) added operator-based lifecycle management, immutable CoreOS nodes and over-the-air updates. The open-source upstream project is called OKD.

Features

Beyond upstream Kubernetes, OpenShift adds integrated image registries, source-to-image (S2I) builds that turn application source code into container images, Routes for exposing services externally, an opinionated security model (containers run as non-root by default under Security Context Constraints), a web console for developers and administrators, and support through the OperatorHub ecosystem for databases and middleware.

Offerings

  • OpenShift Container Platform — self-managed enterprise distribution
  • Red Hat OpenShift Service on AWS (ROSA) and Azure Red Hat OpenShift (ARO) — jointly managed cloud services
  • OpenShift Dedicated — managed clusters on public cloud
  • OpenShift Online / Developer Sandbox — hosted offerings for individual developers
