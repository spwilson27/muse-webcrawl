Message transfer agent

A message transfer agent (MTA), also called a mail transfer agent or mail relay, is software that transfers electronic mail messages from one computer to another using the Simple Mail Transfer Protocol (SMTP). MTAs route mail across networks, looking up the recipient domain's MX records in the Domain Name System to find the next hop.

Operation

An MTA accepts mail from a mail user agent (MUA) or another MTA, stores it in a queue, and forwards it toward its destination. Mail for local recipients is handed to a mail delivery agent (MDA) for storage in a mailbox; mail for remote recipients is relayed to the destination domain's MTA. If delivery fails temporarily, the MTA retries; after repeated failures it generates a bounce message.

Common MTAs

  • Sendmail — one of the earliest and long the most widely used MTA on Unix systems.
  • Postfix — designed by Wietse Venema with an emphasis on security and ease of configuration.
  • Exim — developed at the University of Cambridge, common on Debian systems.
  • qmail — written by Daniel J. Bernstein with a modular, security-focused design.
  • Microsoft Exchange Server — provides MTA functionality in Windows environments.
