Graph (discrete mathematics)

From Wikipedia, the free encyclopedia

In discrete mathematics, and more specifically in graph theory, a graph is a structure amounting to a set of objects in which some pairs of the objects are "related". The objects are called vertices (also nodes or points) and the links between them are called edges (also links or lines). Formally, a graph is a pair G = (V, E), where V is a set of vertices and E is a set of pairs of vertices.

Types

In an undirected graph, edges have no orientation; in a directed graph (digraph), each edge runs from one vertex to another. Graphs may be simple (no loops or multiple edges), allow multiple edges (multigraphs), carry weights on edges (weighted graphs), or be infinite. Special families include complete graphs, trees, bipartite graphs, and planar graphs.

Basic concepts

The degree of a vertex is the number of edges incident to it. A path is a sequence of distinct vertices joined by edges; a cycle is a closed path. A graph is connected if every pair of vertices is joined by a path. Concepts such as adjacency, subgraphs, isomorphism, and coloring underlie algorithmic problems from shortest paths to network design.

Applications

Graphs model networks of communication, transport, social relations, molecules, and dependencies in computation. They are a standard data structure in computer science, where algorithms such as Dijkstra's and Kruskal's solve optimization problems over graphs.
