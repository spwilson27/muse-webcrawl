Variadic function

In mathematics and computer programming, a variadic function is a function of indefinite arity — that is, one which accepts a variable number of arguments. Support for variadic functions differs widely among programming languages. The term variadic is a neologism, dating to the 1970s, formed from variable and -adic as in monadic and dyadic.

A variadic function can be called with any number of arguments.

Examples and implementation

The classic example is C's printf, declared with an ellipsis (int printf(const char *format, ...)); the function retrieves arguments with the va_list, va_start, va_arg and va_end macros from <stdarg.h>, relying on the format string to know their number and types — a source of format-string vulnerabilities when input is unchecked. C++ adds type-safe variadic templates (parameter packs), while languages such as Python (*args), JavaScript (rest parameters and the arguments object), Java (Type...) and Go (...Type) collect extra arguments into a tuple, array or slice, enabling functions like summing an arbitrary list of numbers or composing logging wrappers.

Related concepts

Variadic functions should be distinguished from functions taking a single list argument and from function overloading, where several fixed-arity definitions share a name. In functional languages, the same effect is often achieved with lists, folds, or — in languages with variadic polymorphism, such as Typed Racket — dedicated type machinery.
