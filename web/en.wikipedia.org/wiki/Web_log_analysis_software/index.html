Web log analysis software

Web log analysis software (also called a log analyser) is software that parses a web server's log files, in which the server automatically records all requests it processes, and produces reports on website traffic: numbers of visitors and visits, pages viewed, hits, referrers, search keywords, bandwidth used, and visitor geography and browsers.

Log formats

Web servers such as Apache and nginx typically record the Common Log Format or the extended Combined Log Format, including the client IP address, timestamp, request line, HTTP status code, bytes transferred, referrer, and user agent. Analyser software reads these records and aggregates them into sessions and statistics, typically resolving IP addresses to countries and filtering out known web crawlers.

Notable software

Long-lived open-source analysers include Analog (1995, once the most popular), AWStats, Webalizer, and W3Perl; GoAccess provides real-time terminal and HTML reporting. Commercial and hosted tools such as Urchin — acquired by Google in 2005 and developed into Google Analytics — shifted the industry toward page-tagging (JavaScript-based) measurement, which complements log analysis with client-side data but cannot record downloads, errors, and bot traffic in the same way.

Use

Log analysis remains valuable because it is based on server-side records the site owner fully controls, requires no client scripting, works for all content types, and can be reprocessed historically when logs are retained.
