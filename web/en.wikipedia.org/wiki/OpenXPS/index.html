OpenXPS

The Open XML Paper Specification (OpenXPS) is a specification for a page description language and a fixed-document format. It was developed by Microsoft as the XML Paper Specification (XPS), first shipped with Windows Vista in 2006, and was standardised by Ecma International as ECMA-388 in 2009.

Format

An OpenXPS document is a ZIP container (Open Packaging Conventions) holding XML markup describing each page with a subset of the Windows Presentation Foundation layout language, together with embedded fonts, images and optional features such as digital signatures, rights management and print tickets. Files use the .oxps extension, distinguishing them from the earlier non-standardised .xps variant introduced with Vista; Windows 8 and later default to .oxps.

Support

Windows includes an XPS viewer and print path; support elsewhere has been limited, with viewers available on other platforms and converters to PDF. OpenXPS has seen far less adoption than PDF, its principal competitor.
