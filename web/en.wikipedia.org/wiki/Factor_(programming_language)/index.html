Factor (programming language)

Factor is a stack-oriented programming language created by Slava Pestov. Factor is a dynamically typed, concatenative programming language in the tradition of Forth; its code is organised into small procedures called words that manipulate a data stack.

Factor ships with an interactive graphical development environment.

Design

Factor programs are built by composing words; evaluation pushes and pops values on a stack rather than naming arguments. The language supports generic words with multiple dispatch, an object system based on tuples, higher-order programming with quotations (anonymous functions), and a rich library of collections. Its implementation combines an optimizing compiler with just-in-time compilation and garbage collection.

History

Pestov began Factor in 2003 as a scripting language for a game, initially implemented in Java, before rewriting it in C and Factor itself. The environment emphasises interactive, image-based development similar to Smalltalk and Lisp systems.
