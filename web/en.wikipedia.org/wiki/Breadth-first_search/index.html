Breadth-first search

Breadth-first search (BFS)
Class: Search algorithm
Data structure: Queue
Time complexity: O(V + E)
Complete: Yes
BFS visits nodes level by level

Breadth-first search (BFS) is an algorithm for searching a tree or graph data structure. Starting from a chosen root node, it explores all neighbours at the current depth before moving on to nodes at the next depth level, using a queue to keep track of discovered but unexplored vertices. It was first described in the context of maze solving by Edward F. Moore in 1959 and independently by C. Y. Lee for circuit routing.

Properties and applications

For a graph with V vertices and E edges, BFS runs in O(V + E) time but may require substantial memory to hold a whole level of the graph. Because it expands outward uniformly, BFS finds the shortest path (in edges) between the start node and any other node in an unweighted graph. Applications include finding connected components, testing bipartiteness, computing shortest paths in unweighted networks, web crawling, and solving puzzles such as the fewest-move solutions modelled as state graphs. Its counterpart, depth-first search, explores as deeply as possible along each branch before backtracking.
