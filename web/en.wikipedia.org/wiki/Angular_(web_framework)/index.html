Angular is a TypeScript-based, free and open-source web application framework led by the Angular Team at Google. It is used for building single-page applications with a component-based architecture.

History

Angular is a complete rewrite of AngularJS (2010). It was announced in 2014 and released as Angular 2 in September 2016; the "JS" suffix was dropped and version numbering jumped to 4 in 2017 to align the framework's packages. Since then it has followed a regular six-month major release cycle.

Features

Angular provides a command-line interface (Angular CLI), dependency injection, a component router, forms handling, and server-side rendering through Angular Universal. Applications are written in TypeScript and structured around components, services, and modules; later versions introduced standalone components and signals for fine-grained reactivity.

Adoption

Angular is widely used in enterprise applications and in Google's own products, and is one of the most popular front-end frameworks alongside React and Vue.js.
