watchOS is the operating system of the Apple Watch, developed by Apple Inc. It is based on iOS and has many similar features. It was released on April 24, 2015, along with the Apple Watch, the only device that runs watchOS. watchOS exposes an API called WatchKit for developer use.

The operating system emphasises health and fitness tracking, communication via glances and notifications, and tight integration with the paired iPhone. Major annual releases have added features such as third-party complications, an App Store on the watch itself, sleep tracking, handwashing detection and double-tap gestures.

Overview

The watchOS home screen consists of circular icons arranged in a honeycomb pattern, navigable with the Digital Crown. Watch faces can be customised with complications that surface information from apps. The system supports Siri, Apple Pay, activity rings for movement tracking, and ECG and blood-oxygen measurements on supported hardware.

History

watchOS 1 shipped with the original Apple Watch in 2015. watchOS 2 allowed native apps to run on the watch. Subsequent versions steadily shifted computation from the iPhone to the watch, improved workout metrics, and in watchOS 10 (2023) introduced a redesigned interface built around widgets in a Smart Stack.
