Intrusion detection system


An IDS monitors traffic and host activity for signs of attack.

An intrusion detection system (IDS) is a device or software application that monitors a network or systems for malicious activity or policy violations. Detected events are typically reported to an administrator or collected centrally using a security information and event management (SIEM) system.

Types

Network intrusion detection systems (NIDS) analyse traffic at strategic points in a network, while host-based systems (HIDS) monitor files, logs and system calls on individual machines. An intrusion prevention system (IPS) goes further by actively blocking detected threats. Well-known open-source examples include Snort and Suricata.

Detection methods

Signature-based detection matches observed activity against a database of known attack patterns, making it effective for known threats but blind to novel ones. Anomaly-based detection builds a model of normal behaviour and flags deviations, which can catch new attacks at the cost of higher false-positive rates. Stateful protocol analysis compares traffic against accepted protocol behaviour.

Limitations

ID systems can be evaded by fragmentation, encryption and low-and-slow attacks, and generate large alert volumes that need triage. Encrypted traffic increasingly requires inspection at endpoints or proxies for detection to remain effective.
