Java class file

Image placeholder: Java class file

A Java class file is a file (with the .class filename extension) containing Java bytecode that can be executed on the Java Virtual Machine (JVM). A Java class file is usually produced by a Java compiler from Java programming language source files (.java files) containing Java classes (alternatively, other JVM languages can also be used to create class files). If a source file has more than one class, each class is compiled into a separate class file.

Structure

The class file format is specified by the Java Virtual Machine Specification. It begins with a four-byte magic number, 0xCAFEBABE, followed by the minor and major versions of the class file format. Major version numbers correspond to Java releases: for example, version 52 corresponds to Java 8, version 61 to Java 17, and version 65 to Java 21.

Following the version come the constant pool — a table of strings, class and interface names, field and method references, and other constants — access flags indicating whether the file defines a class or interface and its modifiers, references to this class and its superclass, and tables describing interfaces, fields, methods, and attributes, including the Code attribute that holds the bytecode instructions for each method.

Execution

The JVM loads class files through a class loader, verifies their bytecode for safety and type correctness, and then interprets or just-in-time compiles the bytecode for execution. The platform independence of the class file format is the basis of Java's "write once, run anywhere" capability.
