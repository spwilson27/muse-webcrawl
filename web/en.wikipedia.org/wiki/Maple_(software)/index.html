Maple is a symbolic and numeric computing environment as well as a multi-paradigm programming language. It covers several areas of technical computing, such as symbolic mathematics, numerical analysis, data processing, visualization, and others. A toolbox, MapleSim, adds functionality for multidomain physical modeling and code generation.

History

Maple was first developed in 1980 by the Symbolic Computation Group at the University of Waterloo in Ontario, Canada, with the first limited release in 1982. The software was commercialized by Waterloo Maple Inc., now known as Maplesoft. The name "Maple" is a tribute to Canada's national emblem, the maple leaf.

Features

Maple supports symbolic and numeric computation to arbitrary precision, polynomial and differential equation solving, matrix operations, calculus, statistics, graph theory, and two- and three-dimensional plotting. Users interact with it through a document-style worksheet interface or through the Maple programming language, an imperative language with functional elements. Code generated from Maple models can be exported to languages such as C, Fortran, Java, MATLAB and Visual Basic, and Maple worksheets can interface with external programs and hardware.
