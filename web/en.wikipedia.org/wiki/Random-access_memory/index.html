Random-access memory (RAM) is a form of electronic computer memory that can be read and changed in any order, typically with access times that do not depend on the physical location of the data. It contrasts with sequential-access storage such as magnetic tape, where the time required to access a given item varies with its position. RAM is used by computers to hold the code and data currently being processed, and it is normally volatile: its contents are lost when power is removed.

Types

The two main forms of modern RAM are static RAM (SRAM), which stores each bit in a flip-flop circuit of several transistors and is fast but expensive, and dynamic RAM (DRAM), which stores each bit as charge on a tiny capacitor that must be refreshed thousands of times per second. DRAM, in synchronous form (SDRAM and its DDR successors), provides the main memory of most computers, while SRAM is used for processor caches. Early random-access technologies included magnetic-core memory, dominant from the 1950s to the 1970s.

Use

Because of its speed, RAM acts as the working space of a computer system: programs and files are loaded from slower secondary storage (such as an SSD or hard disk) into RAM for execution. The amount of installed RAM strongly affects a machine's ability to run multiple programs and handle large datasets simultaneously. Memory is supplied in standard modules such as DIMMs for desktops and servers and SO-DIMMs for laptops.
