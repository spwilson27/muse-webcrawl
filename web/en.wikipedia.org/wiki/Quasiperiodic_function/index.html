Quasiperiodic function

In mathematics, a quasiperiodic function is a function that has a certain similarity to a periodic function without being exactly periodic. A common definition is that a function f is quasiperiodic with quasiperiods ω1, …, ωn if there exists a function F on a torus such that f is obtained by restricting F to a line with irrational slope; equivalently, f is a sum of periodic functions whose periods are incommensurable (their ratios are irrational).

Example

The function

f(x) = sin(x) + sin(√2 x)

is quasiperiodic but not periodic, because √2 is irrational: the two components never realign exactly, although the function comes arbitrarily close to repeating. Such functions arise in the study of quasiperiodic motion on tori, Kronecker's theorem, and almost periodic functions.

Related notions

In the theory of elliptic and theta functions, "quasiperiodic" also denotes functions satisfying a functional equation of the form f(z + ω) = eaz+b f(z) for a period ω — that is, the function reproduces itself up to an exponential factor. Quasiperiodic motion in dynamical systems and physics underlies the study of quasicrystals and KAM theory.
