PuTTY

PuTTY is a free and open-source terminal emulator, serial console, and network file transfer application. It supports several network protocols, including SCP, SSH, Telnet, rlogin, and raw socket connections. The name "PuTTY" has no official meaning. It was originally written for Microsoft Windows, and has since been ported to Unix-like systems.

History

PuTTY was developed by Simon Tatham, a British programmer, beginning in the late 1990s; the first public release was in 1999. It is released under the MIT License. Tatham has remained the lead developer, and the project is notable for its long maintenance history and careful security practices.

Features

The suite includes the main terminal client, PSCP and PSFTP for file transfer, Plink for command-line connection, Pageant, an SSH authentication agent, and PuTTYgen, a key generator for RSA, DSA, ECDSA, and Ed25519 keys. PuTTY emulates xterm and VT102 terminals, supports IPv6, port forwarding, and tunneling, and stores session configurations in the Windows registry in its Windows build.

Usage

PuTTY became one of the most widely used SSH clients on Windows, particularly before Windows 10 included a native OpenSSH client. It remains popular for administering servers, routers, and embedded devices via serial connections.
