Resource Description Framework

The Resource Description Framework (RDF) is a World Wide Web Consortium (W3C) standard originally designed as a data model for metadata. It has come to be used as a general method for description and exchange of graph data, and forms a foundation of the Semantic Web. RDF data is made up of statements in the form of subject–predicate–object expressions known as triples.

Data model

The subject of a triple denotes the resource being described, the predicate denotes a trait or aspect of the resource, and the object is a value or another resource. Resources are identified by Internationalized Resource Identifiers (IRIs), and literal values such as strings and numbers may appear as objects. A set of triples forms a directed graph. Vocabularies defined using RDF Schema (RDFS) and the Web Ontology Language (OWL) provide classes, properties and richer semantics on top of the basic model.

Serializations

RDF graphs can be serialised in several formats, including Turtle, N-Triples, RDF/XML and JSON-LD. An example in Turtle:

<http://example.org/book1> dc:title "The Great Gatsby" ;
    dc:creator <http://example.org/author1> .

Querying and storage

RDF data is commonly stored in specialised databases called triplestores and queried with SPARQL, the W3C's query language for RDF. RDF underlies linked data publishing, knowledge graphs such as Wikidata and DBpedia, and many metadata applications.
