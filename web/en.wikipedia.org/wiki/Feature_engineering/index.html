Feature engineering

Feature engineering is the process in machine learning of selecting, creating and transforming variables ("features") from raw data so that they better represent the underlying problem to a predictive model. Good features can improve model accuracy more than the choice of algorithm, but the process is often laborious and requires domain knowledge.

Techniques

  • Encoding — converting categorical variables into numeric form, e.g. one-hot encoding or target encoding.
  • Scaling and normalisation — standardising ranges so features are comparable.
  • Aggregation and binning — summarising groups of records or discretising continuous values.
  • Interaction and polynomial features — combining variables to capture non-linear relationships.
  • Text and time features — extracting word counts, embeddings, or calendar components from timestamps.
  • Imputation — handling missing values.

Feature selection

Related to engineering is feature selection: choosing a subset of relevant features to reduce overfitting, training time and the curse of dimensionality, via filter, wrapper or embedded methods.

Automation and deep learning

Automated feature engineering tools search large spaces of transformations. Deep learning reduces the need for manual feature design by learning representations directly from raw data (representation learning), though engineered features remain standard in tabular-data problems, where gradient-boosted trees fed with well-crafted features are often state of the art.
