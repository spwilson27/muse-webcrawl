Type Allocation Code

The Type Allocation Code (TAC) is the initial eight-digit portion of the fifteen-digit IMEI and sixteen-digit IMEISV codes used to uniquely identify wireless devices on GSM, UMTS, LTE and 5G networks. The TAC identifies the manufacturer and model of the device.

Structure

The first two digits of the TAC form the Reporting Body Identifier, indicating which organisation allocated the code; the remaining six digits identify the device model. TACs are administered by the GSMA, which maintains the official database used by network operators to recognise device types, block stolen handsets, and gather analytics. Before 2003 the structure differed, with the code incorporating a type approval code and a final assembly code under the older IMEI format.
