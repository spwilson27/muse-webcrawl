The Open Packaging Conventions (OPC) is a container-file technology initially created by Microsoft to store a combination of XML and non-XML files that together form a single entity such as an Open XML paper specification (OpenXPS) document. OPC-based file formats combine the advantages of leaving the independent file entities embedded in the document intact and resulting in much smaller files compared to normal use of XML and its normally larger overhead.

Specifications

The OPC is specified in Part II of the Office Open XML standards ISO/IEC 29500:2021 and ECMA-376. The ISO/IEC 29500-2:2021 specification defines a "Package model" and "Physical package" and is independent of the main specification parts.

The OPC specification defines the core properties and the relationships for package parts. It also describes the storage of package parts inside a physical container file such as a ZIP file.

Usage

Both the XML paper specification (XPS) and Office Open XML (OOXML) formats use the OPC, a ZIP-based container file format, to embed content and resources. OPC is also used by other formats, including the NuGet package format (.nupkg), Virtual Hard Disk and application packages for Windows (AppX), and 3MF files for 3D printing.

Parts and relationships

A package consists of a collection of parts, each identified by a URI-like part name, and relationships that describe how the parts are connected. A special part named [Content_Types].xml at the package root declares the content types of all parts. Relationship parts have the extension .rels.
