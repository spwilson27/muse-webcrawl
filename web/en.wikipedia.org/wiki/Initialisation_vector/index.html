Initialization vector

In cryptography, an initialization vector (IV) or starting variable (SV) is a fixed-size input to a cryptographic primitive that is typically required to be random or pseudorandom. It is used to ensure that encrypting the same plaintext under the same key produces different ciphertext each time, preventing patterns that would leak information.

Use in block cipher modes

Modes of operation such as cipher block chaining (CBC) XOR the IV with the first plaintext block before encryption; other modes, such as counter mode, derive their starting counter value from a related nonce. The IV generally need not be secret, and it is commonly transmitted alongside the ciphertext, but it must satisfy mode-specific requirements — for example, uniqueness, and unpredictability for CBC. Reusing an IV with the same key, or using a predictable IV, has led to practical attacks, including the BEAST attack on TLS.

Related concepts

Stream ciphers similarly combine a key with an IV or nonce to initialise their internal state. In password hashing and key derivation, a salt plays a related role in defeating precomputation.
