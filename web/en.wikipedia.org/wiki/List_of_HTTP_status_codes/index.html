List of HTTP status codes

From Wikipedia, the free encyclopedia

This is a list of Hypertext Transfer Protocol (HTTP) response status codes. Status codes are issued by a server in response to a client's request. The first digit of the code specifies one of five standard classes: 1xx informational, 2xx successful, 3xx redirection, 4xx client error, and 5xx server error. The codes are defined principally in RFC 9110 (HTTP Semantics) and registered with IANA.

In addition to the standard codes, individual servers and frameworks define unofficial codes, such as Cloudflare's 520–527 series and nginx's 499 (Client Closed Request).
