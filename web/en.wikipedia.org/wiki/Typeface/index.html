Typeface

A typeface (or font family) is a design of letters, numbers and other symbols whose appearance is unified by a common design theme. Each typeface consists of one or more fonts — in metal type, a set of sorts in a specific size and style; in digital type, a file — sharing the same overall look while varying in weight, slope or width. Familiar typefaces include Times New Roman, Helvetica, Arial and Garamond.

Terminology

Strictly, the typeface is the design and the font is its implementation — historically, one size and style of metal type, today a digital file. In everyday usage the words are often interchanged. A typeface's characters share features such as stroke contrast, x-height, the shape of terminals, and whether serifs (small finishing strokes) are present.

Classification

Typefaces are commonly grouped into serif (old-style, transitional, modern/Didone, slab), sans-serif (grotesque, neo-grotesque, humanist, geometric), script and calligraphic designs, blackletter, monospace and display faces. Systems such as the Vox-ATypI classification formalise these groupings. Type design balances legibility for body text against character for headlines, and modern variable fonts let a single file interpolate across weight and width axes.
