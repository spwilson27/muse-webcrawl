Shannon's source coding theorem

In information theory, Shannon's source coding theorem (or the noiseless coding theorem) establishes the statistical limits of lossless data compression. Published by Claude Shannon in 1948, it states that the average codeword length of an optimal code cannot be less than the entropy of the source.

Statement

For an i.i.d. source with entropy H(X), it is impossible to compress losslessly to an average rate below H(X) bits per symbol, but rates arbitrarily close to H(X) can be achieved by coding long blocks of symbols together.

Converse and achievability

The converse part shows any code with rate below entropy must incur errors, while the direct part follows from the asymptotic equipartition property: long sequences almost surely fall into a "typical set" of about 2^(nH) sequences, which can be indexed compactly.

Legacy

The theorem founded the theory of data compression, underlying practical schemes such as Huffman coding, arithmetic coding and Lempel–Ziv algorithms.
