In programming language theory, parametricity is an abstract property enjoyed by parametrically polymorphic functions: such a function behaves uniformly at all types, without depending on the concrete representation of the values it manipulates. The property was isolated by John C. Reynolds in his 1983 paper "Types, Abstraction and Parametric Polymorphism", which introduced the technique of logical relations to prove representation-independence results. Philip Wadler's celebrated 1989 paper "Theorems for Free!" showed how the type of a polymorphic function alone determines equational theorems the function must satisfy.

Idea

Consider a function of type ∀α. list α → list α in System F, such as a list-reversing function. Because the function cannot inspect the elements (it has no operations available on an abstract α), it can only rearrange, duplicate or discard them. Parametricity strengthens such intuitions into a theorem: for any two types and any relation between them, the function preserves the lifting of that relation to lists. From this, one can prove, for example, that any function of that type commutes with mapping an arbitrary function over the list: f (map g xs) = map g (f xs) — a theorem obtained "for free", from the type alone.

The abstraction theorem

Reynolds' abstraction theorem states that every well-typed term in a parametrically polymorphic language is related to itself by the logical relation built from its type, provided the language's primitives respect the relations. Consequences include data abstraction guarantees: two implementations of an abstract data type that are relationally equivalent cannot be distinguished by any client program. Languages that permit type-case inspection or certain effects (such as unrestricted reflection) can break parametricity, which is why full parametricity holds in pure calculi like System F but only approximately in industrial languages with features like Java's instanceof or Haskell's Typeable.

Applications

Parametricity underlies proofs of program equivalence, compiler optimisation justification, information-flow security, and the theory of generic programming; in dependently typed languages and proof assistants it appears as internal parametricity axioms and "parametricity translations" used to derive free theorems automatically.
