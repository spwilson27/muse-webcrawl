The Miller–Rabin test repeatedly checks whether random bases "witness" that a number is composite.

The Miller–Rabin primality test is a probabilistic algorithm for determining whether a given number is a probable prime. It is the most widely used primality test in practice, particularly in cryptographic applications such as generating the large prime numbers needed for RSA. The test is a refinement of the Fermat primality test and is based on properties of strong pseudoprimes.

Background

Gary L. Miller first proposed the test in 1976 as a deterministic polynomial-time algorithm whose correctness depends on the truth of the generalised Riemann hypothesis. Michael O. Rabin modified Miller's idea in 1980 into an unconditional probabilistic test: for any odd composite n, at least three quarters of the possible bases a reveal n to be composite, so repeating the test with k independent random bases makes the probability of a false "prime" verdict at most 4−k.

Algorithm

Given an odd integer n > 2, write n − 1 = 2s·d with d odd. For a randomly chosen base a in the range [2, n − 2], compute x = ad mod n. If x is 1 or n − 1, the test passes for this base. Otherwise, square x repeatedly (up to s − 1 times); if it never equals n − 1, then a is a witness that n is definitely composite. If no witness is found after k rounds, n is declared a probable prime.

Deterministic variants

For numbers below known bounds, testing a small fixed set of bases is provably sufficient, making the test deterministic in those ranges. For example, testing the first twelve prime bases suffices for all 64-bit integers. Such deterministic variants are used in computer algebra systems and programming libraries.
