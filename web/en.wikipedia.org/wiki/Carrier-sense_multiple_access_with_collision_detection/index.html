Carrier-sense multiple access with collision detection

Carrier-sense multiple access with collision detection (CSMA/CD) is a medium access control method used most notably in early Ethernet technology for local area networks. It is a refinement of carrier-sense multiple access that detects when two stations transmit simultaneously.

Operation

A station listens before transmitting and continues to monitor the medium while sending. If it detects a collision, it transmits a jam signal to ensure all stations notice, stops, and waits a random backoff period — governed by the truncated binary exponential backoff algorithm — before retrying. CSMA/CD is effective only in half-duplex, shared-medium networks; modern switched, full-duplex Ethernet does not use it.
