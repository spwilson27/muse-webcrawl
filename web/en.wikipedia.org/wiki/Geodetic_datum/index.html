Geodetic datum

A geodetic datum is a coordinate system and reference framework used to measure locations on Earth. It consists of a reference ellipsoid model of the Earth's shape, together with a set of reference points and an origin that tie the ellipsoid to the actual Earth.

Types

Horizontal datums (such as NAD27, NAD83 in North America and the global WGS 84 used by GPS) define latitude and longitude; vertical datums define elevations relative to a reference surface such as mean sea level (the geoid). Because datums differ, the same physical point can have coordinates differing by hundreds of metres between older regional datums and modern global ones, making datum transformations essential in mapping and navigation.
