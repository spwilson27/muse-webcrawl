SPARC

SPARC (Scalable Processor Architecture) is a reduced instruction set computer (RISC) instruction set architecture originally developed by Sun Microsystems. Its design was strongly influenced by the experimental Berkeley RISC system. First developed in 1986 and published in 1987, SPARC was most recently implemented by Fujitsu and Oracle (after Oracle's acquisition of Sun in 2010).

A characteristic feature of SPARC implementations is a large register file organised into overlapping register windows, designed to speed procedure calls. The architecture is freely licensable, with several implementations available as open-source hardware descriptions (such as the LEON core used in space applications and the OpenSPARC designs).

History

The first SPARC implementation shipped in Sun's Sun-4 workstations in 1987. Successive generations — SuperSPARC, UltraSPARC, and later the SPARC T series with chip multithreading — powered Sun's Solaris servers through the 1990s and 2000s. The SPARC Version 9 architecture (1994) extended the architecture to 64 bits. Oracle announced the SPARC M8 processor in 2017; Fujitsu used SPARC64 chips in Japanese supercomputers, including the K computer, before moving to ARM with Fugaku.

Architecture

SPARC is a load–store architecture with a fixed-length 32-bit instruction encoding. Processors implement register windows: typically 2 to 32 sets of registers, of which 8 global registers and one window of 24 registers are visible at a time. Delayed branches and an optional floating-point unit defined by the architecture are other notable features.

Operating systems

Solaris is the native operating system most associated with SPARC; Linux, the BSD variants, and real-time operating systems also support the architecture.
