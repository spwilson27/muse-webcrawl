BPP (complexity)

In computational complexity theory, BPP (bounded-error probabilistic polynomial time) is the class of decision problems solvable by a probabilistic Turing machine in polynomial time with an error probability of at most 1/3 on all instances. BPP is one of the most important classes of practical, efficiently solvable problems, because the error can be driven down exponentially by repeating the algorithm and taking a majority vote (a consequence of the Chernoff bound).

Definition

A language L is in BPP if there is a probabilistic polynomial-time Turing machine M such that for every input x: if x ∈ L, M accepts with probability at least 2/3; if x ∉ L, M accepts with probability at most 1/3. The constants 2/3 and 1/3 are arbitrary: any constant gap from 1/2 gives the same class, by amplification.

Relationships to other classes

BPP contains the deterministic class P and is contained in PSPACE. By the Sipser–Gács–Lautemann theorem, BPP ⊆ Σ2 ∩ Π2 in the polynomial hierarchy. It is widely conjectured that BPP = P — that randomness does not add power for decision problems — because sufficiently strong pseudorandom generators would allow all BPP algorithms to be derandomised. The quantum analogue of BPP is BQP.
