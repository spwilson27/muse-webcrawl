Home server

A home server is a computer located in a private residence that provides services to other devices inside or outside the household over a home network or the Internet. It is typically an ordinary desktop, a repurposed machine, a small low-power computer, or a network-attached storage (NAS) device configured for server duties.

Services

Common uses include file storage and sharing, media streaming (for example with Plex or Jellyfin), automated backups, print serving, home automation hubs, personal cloud services, game servers, and hosting personal websites or email. Enthusiasts often run virtualisation platforms or container systems to host many services on one machine.

Software

Home servers commonly run Linux distributions, TrueNAS, Unraid, Proxmox VE, or Windows Server/Home Server successors. Energy efficiency, low noise and reliability are usually prioritised over raw performance.
