User space and kernel space

A simplified view of a system's virtual address space

User space and kernel space are the two regions into which an operating system divides a computer's virtual memory. Kernel space is reserved for the running kernel, kernel extensions, and most device drivers, and is strictly protected. User space is the memory area where all user-mode application software and some drivers execute, isolated into separate address spaces per process.

Interaction

User-space processes can only access their own memory and must communicate with the kernel via system calls to perform privileged actions such as file I/O, networking, or spawning processes. This division is enforced by the CPU's privilege levels and the memory management unit, providing stability and security: a faulty user process can be terminated without bringing down the system, whereas a fault in kernel space typically causes a system crash (kernel panic).

Usage

The term "userland" conversely refers collectively to all application software that runs in user space, in distinction to the kernel itself.
