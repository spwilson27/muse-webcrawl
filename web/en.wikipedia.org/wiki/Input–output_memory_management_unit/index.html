Input–output memory management unit

An input–output memory management unit (IOMMU) is a memory management unit (MMU) connecting a direct-memory-access–capable (DMA-capable) I/O bus to the main memory. Like a traditional MMU, which translates CPU-visible virtual addresses to physical addresses, the IOMMU maps device-visible virtual addresses (called device addresses or I/O addresses in this context) to physical addresses.

Purposes

The IOMMU serves several purposes. It allows a device that can only address a limited range of memory (for example, a legacy 32-bit DMA device) to access buffers anywhere in a larger physical address space, by remapping. It enables scatter-gather DMA without requiring physically contiguous buffers. Most importantly, it provides protection: a malfunctioning or malicious device can be restricted to only the memory regions granted to it, preventing rogue DMA from corrupting the rest of the system. This protection is what makes safe direct device assignment to virtual machines possible in hardware virtualisation (Intel VT-d and AMD-Vi are the best-known implementations).

Implementations

Examples include the graphics address remapping table (GART) on AGP systems, Intel's VT-d, AMD's AMD-Vi (formerly simply IOMMU), and ARM's System Memory Management Unit (SMMU). Operating systems use IOMMU translation both for virtualisation passthrough and, increasingly, as a security boundary for Thunderbolt- and USB4-attached peripherals.
