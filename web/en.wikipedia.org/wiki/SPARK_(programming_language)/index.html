SPARK (programming language)

Paradigm: Multi-paradigm; structured, imperative, object-oriented
Family: Ada
First appeared: 1988
Stable release series: SPARK 2014
Typing discipline: Static, strong, safe

SPARK is a formally defined computer programming language based on the Ada programming language, intended for the development of high-integrity software used in systems where predictable and highly reliable operation is essential. It facilitates the development of applications that demand safety, security, or business integrity.

Originally, there were three versions of the SPARK language (SPARK83, SPARK95, SPARK2005) based on Ada 83, Ada 95 and Ada 2005 respectively. A fourth version, SPARK 2014, based on Ada 2012, was released on April 30, 2014. SPARK 2014 is a complete re-design of the language and supporting verification tools.

Overview

SPARK aims to exploit the strengths of Ada while eliminating its potential for ambiguity and unsafe constructs. The language restricts features that are difficult to verify and supplements programs with contracts — preconditions, postconditions, and data-flow annotations — that can be checked both statically by the GNATprove tool and at run time.

The SPARK toolset uses formal proof to establish properties such as the absence of run-time errors, freedom from information-flow violations, and functional correctness with respect to contracts. It is used in avionics, air traffic control, railway signalling, and cryptographic applications, including the Tokeneer ID Station, a high-assurance security system developed as a demonstration of the approach.
