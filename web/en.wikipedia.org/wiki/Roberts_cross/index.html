Roberts cross

The Roberts cross operator is used in image processing and computer vision for edge detection. It was one of the first edge detectors, proposed by Lawrence Roberts in 1963, and is a differential operator that computes an approximation of the gradient of an image by discrete differentiation achieved by summing the squares of the differences between diagonally adjacent pixels.

Motivation

According to Roberts, an ideal edge detector should mark edge points clearly, produce as little noise as possible, and place the response close to the true edge location. Because the operator uses only a 2×2 neighbourhood, it is computationally very fast, though it is correspondingly sensitive to noise and produces weaker responses to edges than larger operators such as Sobel or Prewitt.

Formulation

The operator uses two 2×2 convolution kernels, rotated 45° versions of one another:

Gx = [ +1  0 ]      Gy = [ 0 +1 ]
     [  0 -1 ]           [ -1  0 ]

The approximate gradient magnitude is then computed from the two filtered images, commonly as |Gx| + |Gy| or as the square root of Gx² + Gy².
