StyleGAN

StyleGAN is a type of generative adversarial network (GAN) introduced by researchers at Nvidia in December 2018. It became widely known for generating photorealistic images of human faces that do not correspond to any real person, popularized by the website This Person Does Not Exist.

Architecture

Unlike a traditional GAN generator, which feeds the latent code directly into the first layer, StyleGAN uses a two-part design. A mapping network transforms the input latent code into an intermediate latent space, whose vectors control the generator through adaptive instance normalization (AdaIN) at each resolution layer. This separation allows different layers to govern different visual features: coarse layers control pose, face shape, and hairstyle, while finer layers control details such as skin texture, freckles, and eye color.

The generator also injects per-layer random noise, enabling stochastic variation in fine details without affecting the overall layout. Techniques such as style mixing — using different latent codes at different layers — demonstrated the disentanglement of the learned representation.

Versions

  • StyleGAN (2018/2019): introduced the style-based generator architecture.
  • StyleGAN2 (2019/2020): removed characteristic artifacts such as droplet-like blobs, improved image quality, and redesigned the normalization.
  • StyleGAN3 (2021): addressed aliasing and texture sticking, producing generators equivariant to translation and rotation.

Applications and concerns

StyleGAN has been used for art, game assets, fashion, and data augmentation, and adapted to generate animals, cars, landscapes, and medical images. Its realism has also raised concerns about synthetic media and disinformation, and researchers have studied detectors for GAN-generated faces based on artifacts and frequency-domain signatures.
