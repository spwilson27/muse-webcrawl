dm-crypt

dm-crypt is a transparent block device encryption subsystem in the Linux kernel. It is implemented as a device mapper target and provides encryption of whole disks, partitions, and logical volumes using symmetric ciphers from the kernel's crypto API.

dm-crypt
TypeDisk encryption subsystem
PlatformLinux kernel (device mapper)
Front-endcryptsetup / LUKS

Function

dm-crypt maps a virtual block device onto a physical device so that data written to the virtual device is encrypted before reaching the disk, and decrypted transparently on read. It supports modes such as XTS with AES and other ciphers, with sector-level tweakable encryption.

LUKS

Most users configure dm-crypt through the cryptsetup utility with the LUKS (Linux Unified Key Setup) on-disk format, which stores encryption metadata, supports multiple passphrase slots, and enables features such as key derivation with Argon2 in LUKS2.

Related features

The related dm-integrity target can be combined with dm-crypt to provide authenticated encryption-like integrity protection, and dm-verity provides read-only integrity checking used by Android and ChromeOS.
