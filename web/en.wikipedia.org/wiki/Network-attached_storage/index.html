Network-attached storage

Network-attached storage (NAS) is a file-level computer data storage server connected to a computer network providing data access to a heterogeneous group of clients. NAS systems are specialised computers or appliances containing one or more storage drives, often arranged in RAID arrays, that serve files using protocols such as NFS, SMB/CIFS and AFP.

Characteristics

Unlike a storage area network (SAN), which provides block-level storage, NAS operates at the file level and manages its own file system. NAS devices are typically managed through a web-based interface and require no keyboard or display. They are popular in homes and small businesses for centralised backup, media streaming and file sharing.

History

File-server concepts that led to NAS emerged in the 1980s with Novell's NetWare and the development of the NFS protocol by Sun Microsystems. Dedicated NAS appliances became widespread in the 2000s as hard drive capacities grew and home networks became common.
