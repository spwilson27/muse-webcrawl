Wireless router

A wireless router is a networking device that forwards data packets between computer networks and provides wireless access to that network, most commonly the Internet. In home and small-office settings, a wireless router typically combines a network router, a wireless access point, an Ethernet switch, a DHCP server, and a firewall in a single unit, connecting to a modem or directly to the Internet service provider's line.

Function

The router assigns local IP addresses to connected devices through DHCP and uses network address translation (NAT) so that many devices can share one public IP address. Its wireless access point broadcasts a network name (SSID) and encrypts traffic using WPA2 or WPA3. Most units operate in the 2.4 GHz and 5 GHz bands, with newer Wi-Fi 6E and Wi-Fi 7 models adding the 6 GHz band.

Features

Common features include guest networks, parental controls, quality of service (QoS) prioritization, USB ports for shared storage or printers, and support for mesh networking, in which multiple nodes cooperate to cover a large home with one network. Administration is usually through a web interface or mobile app.

Security

Default administrator passwords, outdated firmware, and features such as WPS have historically made home routers a common target for botnets; experts recommend changing default credentials, enabling automatic updates, and disabling remote administration.
