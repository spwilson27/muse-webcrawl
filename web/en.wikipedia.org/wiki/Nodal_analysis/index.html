Nodal analysis


Labelled placeholder: example circuit

In electric circuits analysis, nodal analysis, node-voltage analysis, or the branch current method is a method of determining the voltage (potential difference) between "nodes" (points where elements or branches connect) in an electrical circuit in terms of the branch currents.

Nodal analysis is essentially an application of Kirchhoff's current law (KCL). Nodal analysis is possible when all the circuit elements' branch constitutive relations have an admittance representation. Nodal analysis produces a compact set of equations for the network, which can be solved by hand if small, or can be quickly solved using linear algebra by computer. Because of the compact system of equations, many circuit simulation programs (e.g., SPICE) use nodal analysis as a basis. When elements do not have admittance representations, a more general extension of nodal analysis, modified nodal analysis, must be used.

Although simple examples with a DC (resistive) focus on linear elements, nodal analysis equations can be reformulated for more general complex frequency-dependent linear elements, as long as their branch constitutive relations also allow an admittance representation.

Method

  1. Note all connected wire segments in the circuit. These are the nodes of nodal analysis.
  2. Select one node as the ground reference. The choice does not affect the element voltages (only their reference) but does affect the solution complexity. Choose the node with the most connections to simplify.
  3. For each node except the reference, assign a variable designating the voltage at the node with respect to the reference. These voltages are the unknowns to be solved.
  4. For each unknown voltage, form an equation based on Kirchhoff's current law (i.e., add together all currents leaving the node and mark the sum equal to zero). The current through an element is the element's admittance times the voltage difference across the element.
  5. If there are voltage sources between two unknown voltages, form a supernode. A supernode is formed by enclosing the voltage source and any elements connected in parallel with it, so that all elements in that supernode are considered in a single KCL equation.
  6. Solve the system of simultaneous equations for each unknown voltage.

Example

Consider a basic circuit with two nodes, one of which is the reference (ground). With resistor R1 connected to a current source Is at node V1, and resistor R2 from V1 to ground, KCL at node 1 gives:

(V1 − Vs)/R1 + V1/R2 − Is = 0

This single equation can be solved directly for V1.

Supernodes

In a supernode, the KCL equation is written for the region enclosed by the boundaries around both nodes connected by a voltage source. A constraint equation equating the difference between the two node voltages to the source voltage is added, reducing the number of unknowns by one for each voltage source.
