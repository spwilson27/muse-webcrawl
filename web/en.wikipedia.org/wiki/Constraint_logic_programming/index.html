Constraint logic programming

Constraint logic programming is a form of constraint programming in which constraint solving is integrated into a logic programming language, most commonly Prolog. In constraint logic programming, the unification mechanism of logic programming is replaced or augmented by a constraint solver over a particular domain, such as real numbers, rational numbers, finite domains, or Boolean values. The paradigm originated in the 1980s with systems such as CLP(R) and CHIP.

ParadigmLogic, constraint programming, declarative
First appeared1980s
Notable systemsCLP(R), CHIP, ECLiPSe, SICStus Prolog, SWI-Prolog (CLP(FD))

Overview

A constraint logic program consists of clauses in which goals may include constraints. Execution maintains a constraint store; each new constraint is checked for consistency by the solver, and computation fails if the store becomes unsatisfiable. Depending on the domain, solvers use techniques such as Gaussian elimination for linear equations, the simplex method, or arc-consistency algorithms for finite domains.

Variants

CLP schemes are usually parameterised by their constraint domain: CLP(R) works over real numbers, CLP(FD) over finite domains (integers with bounded ranges), CLP(B) over Booleans, and CLP(Q) over rationals. Finite-domain CLP is widely used for scheduling, timetabling, and combinatorial puzzles. Concurrent constraint logic programming extends the paradigm with processes that communicate through the constraint store.

Applications

Applications include industrial scheduling, resource allocation, circuit verification, natural-language processing grammars, bioinformatics, and financial decision support. The declarative style lets programmers state relationships among variables and delegate search to the solver.
