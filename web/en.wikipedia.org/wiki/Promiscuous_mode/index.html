Promiscuous mode

In computer networking, promiscuous mode is a mode for a network interface controller in which the controller passes all traffic it receives to the central processing unit, rather than only frames addressed to it. Normally an interface discards frames not matching its hardware (MAC) address, broadcast address, or subscribed multicast addresses.

Uses

Promiscuous mode is used by packet analyzer software such as Wireshark and tcpdump to monitor and diagnose network activity. On shared media such as hubs, it allows capturing all traffic on the segment; on modern switched networks, a host in promiscuous mode generally sees only its own traffic unless port mirroring or related techniques are used.

Security considerations

Because it enables eavesdropping on network traffic, promiscuous mode can be abused in sniffing attacks; detecting interfaces operating in promiscuous mode is a known network security concern. Virtualization platforms also use the mode so virtual machines can receive traffic for multiple MAC addresses.
