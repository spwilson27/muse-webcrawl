Boolean data type

In computer science, the Boolean data type is a data type that has one of two possible values, usually denoted true and false, intended to represent the two truth values of logic and Boolean algebra. It is named after George Boole, who first defined an algebraic system of logic in the mid-19th century.


Truth values and basic operations

Operations

Boolean values support the operations of Boolean algebra, principally:

OperationMeaningCommon symbols
ANDBoth operands true&&, AND, ∧
ORAt least one operand true||, OR, ∨
NOTNegation!, NOT, ¬
XORExactly one operand true^, XOR, ⊕

Booleans are the result type of comparison operators (equal to, greater than, etc.) and drive conditional statements (if), loops (while), and other control flow in nearly every programming language.

In programming languages

Most modern languages provide an explicit Boolean type: bool in C++ (and C99's _Bool/stdbool.h), boolean in Java, bool in Python (where True and False are a subtype of integer), and boolean in JavaScript. Some older languages, notably C before C99 and shell scripting, lack a dedicated type and instead treat zero as false and any non-zero value as true — a convention also found in languages such as Perl and Lua (where nil is also false). Although a Boolean logically needs only one bit, implementations usually store it in a full byte or word for alignment and addressing convenience; languages like C++ allow packed bit-fields and specialisations such as std::vector<bool>.

History

The earliest computers operated on Boolean logic at the hardware level, and George Boole's algebra was connected to digital circuits by Claude Shannon in 1937. ALGOL introduced a formal Boolean type in the late 1950s, and it has been standard in programming-language design ever since.
