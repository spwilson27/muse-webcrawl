Randomness tests

A randomness test, in data evaluation, is a test used to analyse the distribution of a set of data to determine whether it follows a random pattern. Statistical tests of randomness are used to evaluate random number generators and to detect structure in observed data.

Common tests include the chi-squared test, runs test, spectral test, and batteries of tests such as the Diehard tests and the NIST Statistical Test Suite, which check properties such as frequency, serial correlation and the distribution of subsequences. Passing such tests cannot prove true randomness, but failing them reveals patterns inconsistent with randomness.
