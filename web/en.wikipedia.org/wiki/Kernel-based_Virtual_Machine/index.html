Architecture of KVM

Kernel-based Virtual Machine (KVM) is a free and open-source virtualization module in the Linux kernel that allows the kernel to function as a hypervisor. It was merged into the mainline Linux kernel in version 2.6.20, released in February 2007. KVM requires a processor with hardware virtualization extensions, such as Intel VT-x or AMD-V.

Using KVM, one can run multiple virtual machines running unmodified Linux or Windows images. Each virtual machine has private virtualized hardware: a network card, disk, graphics adapter, and so on. KVM itself provides only the virtualization of the CPU and memory via the /dev/kvm interface; in practice it is almost always combined with QEMU, which emulates or paravirtualizes the remaining devices, and managed through tools such as libvirt and oVirt.

History

KVM was developed by Qumranet, which was acquired by Red Hat in 2008. It has since become the standard virtualization technology of the Linux ecosystem and underpins many cloud platforms.

Features

KVM supports live migration, memory overcommit, CPU and memory hotplug, paravirtualized drivers through VirtIO, and nested virtualization. Because virtual machines are ordinary Linux processes, they benefit from the kernel's scheduler, memory management, and security features.
