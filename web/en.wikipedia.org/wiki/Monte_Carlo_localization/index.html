Monte Carlo localization

Monte Carlo localization (MCL), known also as particle filter localization, is an algorithm for robots to localize using a particle filter. Given a map of the robot's environment, the algorithm estimates the position and orientation of a robot as it moves and senses the environment. The robot's belief about its pose is represented by a set of randomly drawn samples ("particles"), each weighted by how well the robot's sensor readings match the map.

Operation

MCL maintains a distribution over possible poses. When the robot moves, each particle is updated according to the motion model (with added noise). When the robot observes the environment, each particle is re-weighted by the likelihood of the observation given the particle's pose, and a new set of particles is drawn with replacement according to these weights (resampling). Over time the particles concentrate around the true pose.

Because the particle set can represent multi-modal distributions, MCL solves the global localization problem — a robot placed somewhere unknown can recover its position from scratch — as well as the position-tracking problem. Variants such as KLD-sampling adapt the number of particles to the uncertainty of the estimate, and augmented MCL injects random particles to recover from localization failures such as the "kidnapped robot" scenario.

History and use

The method was developed in the late 1990s by researchers including Dieter Fox, Wolfram Burgard, Frank Dellaert, and Sebastian Thrun, building on earlier condensation/particle-filtering work in computer vision. It was famously used in museum tour-guide robots. An adaptive version (AMCL) is widely used in the Robot Operating System (ROS) navigation stack for mobile robots equipped with laser rangefinders.
