Data link layer

The data link layer is layer 2 of the OSI model.

The data link layer, or layer 2, is the second layer of the seven-layer OSI model of computer networking. This layer is the protocol layer that transfers data between nodes on a network segment across the physical layer. The data link layer provides the functional and procedural means to transfer data between network entities and may also provide the means to detect and possibly correct errors that can occur in the physical layer.

Functions

The data link layer is concerned with local delivery of frames between nodes on the same level of the network. Its services include:

  • Framing — encapsulating network-layer packets into frames with headers and trailers
  • Physical addressing — adding the hardware (MAC) addresses of sender and receiver
  • Error control — detecting corrupted frames using checksums such as the frame check sequence, and sometimes correcting or retransmitting them
  • Flow control — preventing a fast sender from overwhelming a slow receiver
  • Medium access control — regulating which device may transmit on a shared medium

Sublayers

The IEEE 802 standards divide the layer into two sublayers: the media access control (MAC) sublayer, which controls access to the physical medium, and the logical link control (LLC) sublayer, which provides multiplexing and flow control. Familiar layer-2 technologies include Ethernet, Wi-Fi (IEEE 802.11), PPP, and VLAN tagging (IEEE 802.1Q).
