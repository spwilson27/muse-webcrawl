Key derivation function

In cryptography, a key derivation function (KDF) is a cryptographic algorithm that derives one or more secret keys from a secret value such as a master key, a password, or a passphrase using a pseudorandom function (which typically uses a cryptographic hash function or block cipher).

Uses

Key derivation functions can be used to expand keys into longer keys or to obtain keys of a required format, such as converting a group element from a Diffie–Hellman key exchange into a symmetric key for use with AES. Keyed cryptographic hash functions are popular examples of pseudorandom functions used for key derivation.

Password-based key derivation

KDFs were originally used for obtaining keys from passwords, but modern password-based KDFs — including PBKDF2, bcrypt, scrypt, and Argon2 — are deliberately computationally expensive and incorporate a unique salt for each password. This "key stretching" slows brute-force and dictionary attacks, since every guess requires the full derivation cost, and the salt defeats precomputed rainbow tables. Password-based KDFs are the standard mechanism for password hashing in secure systems.

Standard constructions

Well-known KDFs include HKDF (an HMAC-based extract-and-expand construction used in TLS 1.3 and the Signal protocol), the NIST-specified counter- and feedback-mode KDFs based on HMAC or CMAC, and the key derivation built into protocols such as TLS and IKE.
