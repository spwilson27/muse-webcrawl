Initial release2004
File extensions.md, .markdown
TypeLightweight markup language

Markdown is a lightweight markup language for creating formatted text using a plain-text editor. John Gruber created Markdown in 2004, in collaboration with Aaron Swartz, as a markup language intended to be easy to read and write in its source form. A Markdown processor converts the plain text to HTML (or another output format), and the language is widely used for documentation files, readme files, note-taking, forums and content management systems.

Design

Markdown's syntax is designed so that a document reads naturally as plain text: headings are marked with #, emphasis with asterisks or underscores, lists with dashes or numbers, and links with a [text](url) pattern derived from email conventions. Unlike heavyweight markup such as HTML itself, source documents remain legible without rendering.

Variants and standardisation

Because the original specification left many edge cases ambiguous, numerous dialects emerged, including GitHub Flavored Markdown (GFM), which added tables, task lists and strikethrough, and Markdown Extra. In 2014 a group of developers produced the CommonMark specification, a strict, unambiguous formalisation of the language, together with a reference implementation and test suite.

Usage

Markdown is the standard format for README files on software hosting platforms, for static site generators, and for much technical writing. Its simplicity has made it a default choice for documentation in software projects and for text stored in version control.
