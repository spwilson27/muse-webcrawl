cron

The cron daemon runs scheduled commands at fixed times and intervals.

The cron daemon is a time-based job scheduler in Unix-like computer operating systems. Users who set up and maintain software environments use cron to schedule jobs (commands or shell scripts), also known as cron jobs, to run periodically at fixed times, dates, or intervals. It typically automates system maintenance or administration — though its general-purpose nature makes it useful for things like downloading files from the Internet and downloading email at regular intervals.

Overview

cron is driven by a crontab (cron table) file, a configuration file that specifies shell commands to run periodically on a given schedule. The crontab files are stored in operating system-specific locations and can be edited with the crontab command. Each line of a crontab entry has five time-and-date fields, followed by a command:

# ┌───────────── minute (0–59)
# │ ┌───────────── hour (0–23)
# │ │ ┌───────────── day of the month (1–31)
# │ │ │ ┌───────────── month (1–12)
# │ │ │ │ ┌───────────── day of the week (0–6, Sunday to Saturday)
# │ │ │ │ │
# * * * * * <command to execute>

For example, 0 3 * * 1 /usr/bin/backup runs the backup program at 03:00 every Monday. Special strings such as @daily and @reboot are supported by many implementations.

History

A simple form of cron appeared in early versions of Unix in the 1970s. The widely used Vixie cron, written by Paul Vixie and released in 1987, added features such as per-user crontabs and environment settings, and its descendants remain standard on Linux and BSD systems. Modern alternatives and complements include anacron, systemd timers, and launchd on macOS.
