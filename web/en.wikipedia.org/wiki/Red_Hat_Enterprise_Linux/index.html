Red Hat Enterprise Linux

Red Hat Enterprise Linux (RHEL) is a commercial open-source Linux distribution developed by Red Hat for the commercial market. It is released in server versions for multiple architectures including x86-64, ARM, IBM Power and IBM Z, as well as a workstation version.

History

The first version of Red Hat Enterprise Linux, initially marketed as Red Hat Linux Advanced Server, was released in 2002, succeeding Red Hat Linux as the company's enterprise offering. Each major release is supported for about ten years, with a predictable release cadence and an emphasis on stability and long-term API/ABI compatibility.

Development model

RHEL development draws on the community Fedora project, which serves as its upstream testbed, and on CentOS Stream, which since 2021 sits between Fedora and RHEL in the development pipeline. Historically, community rebuilds such as CentOS Linux replicated RHEL; after CentOS Linux was discontinued, alternatives including AlmaLinux and Rocky Linux took its place. RHEL is sold by subscription, which includes support and access to software updates through the Red Hat Customer Portal.
