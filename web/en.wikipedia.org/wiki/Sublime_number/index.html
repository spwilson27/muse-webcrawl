In number theory, a sublime number is a positive integer which has a perfect number of positive divisors (factors), and whose positive divisors add up to a perfect number. Equivalently, if σ denotes the sum-of-divisors function and τ (or d) denotes the number-of-divisors function, then n is sublime when both τ(n) and σ(n) are perfect numbers.

Examples

The number 12, for example, is a sublime number. It has a perfect number of positive divisors (6): 1, 2, 3, 4, 6, and 12; and the sum of these is again a perfect number: 1 + 2 + 3 + 4 + 6 + 12 = 28.

There are only two known sublime numbers: 12 and a 76-digit number discovered by Kevin Brown:

608655567023837898967037173424316962265783077852631550595983708296127164760

which factorises as 242 · 37 · 52 · 72 · 11 · 13 · 17 · 19 · 23 · 29 · 37 · 41. It has τ = 2126 divisors (a perfect number), and the sum of its divisors is also perfect.

Open problems

It is not known whether any odd sublime numbers exist, nor whether there are infinitely many sublime numbers. The question is entangled with the famous unsolved problem of whether odd perfect numbers exist: since σ(n) for an odd sublime number n would have to be an odd perfect number (or an even perfect number—actually σ(n) must be perfect and n odd forces σ(n) to be constrained), progress on one problem would inform the other.
