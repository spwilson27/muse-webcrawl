IP address

From Wikipedia, the free encyclopedia
[Image: Diagram showing an IPv4 address in dotted-decimal notation and an IPv6 address in hexadecimal notation]

An Internet Protocol address (IP address) is a numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication. An IP address serves two main functions: it identifies the host, or more specifically its network interface, and it provides the location of the host in the network, enabling packets to be routed to it.

Two versions of the Internet Protocol are in use. IPv4 addresses are 32-bit numbers, usually written in dotted-decimal notation as four numbers from 0 to 255 separated by dots, such as 192.0.2.1. IPv6 addresses are 128 bits long, written as groups of hexadecimal digits separated by colons, and were introduced to overcome the exhaustion of the IPv4 address space.

Allocation and types

Addresses are allocated hierarchically: ICANN, through the Internet Assigned Numbers Authority, assigns blocks to five regional Internet registries, which in turn allocate them to Internet service providers and organisations. Addresses may be static (fixed) or dynamic (assigned temporarily, typically via DHCP). Special ranges are reserved for private networks — for example 10.0.0.0/8 and 192.168.0.0/16 — whose addresses are not routable on the public Internet and are shared through network address translation (NAT).

A human-readable domain name is translated into an IP address by the Domain Name System, so users rarely need to type addresses directly.
