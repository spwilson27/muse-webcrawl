List of web browsers

The following is a list of web browsers — software applications for accessing the World Wide Web. The first widely used browser was Mosaic (1993), followed by Netscape Navigator; the field is now dominated by browsers based on the Chromium (Blink) engine, alongside Mozilla's Gecko and Apple's WebKit.

Historical browsers

Historically important browsers include WorldWideWeb (1990), Mosaic (1993), Netscape Navigator (1994), Internet Explorer (1995–2022), Opera's Presto-based versions, and text browsers such as Lynx (1992), which is still maintained.
