Hoare logic

Hoare logic (also known as Floyd–Hoare logic) is a formal system for reasoning rigorously about the correctness of computer programs. It was proposed by the British computer scientist Tony Hoare in a 1969 paper, building on earlier work by Robert Floyd, who had introduced a related method for flowcharts in 1967.

Hoare triples

The central feature of the system is the Hoare triple, written {P} C {Q}, where P (the precondition) and Q (the postcondition) are assertions about program state, and C is a command. The triple expresses partial correctness: if P holds before executing C, and C terminates, then Q holds afterwards.

Rules

Hoare logic provides an axiom and inference rules for each construct of a simple imperative language, including:

  • Assignment axiom: {P[x/E]} x := E {P} — substitution of the assigned expression into the postcondition.
  • Composition rule: from {P} C1 {R} and {R} C2 {Q}, infer {P} C1;C2 {Q}.
  • Conditional and loop rules: the while rule uses a loop invariant that must hold before and after each iteration.
  • Consequence rule: preconditions may be strengthened and postconditions weakened using logical implication.

Influence

Hoare logic underlies program verification tools and influenced Dijkstra's weakest-precondition calculus, design by contract, and modern separation logic, which extends the framework to reason about heap-manipulating and concurrent programs.
