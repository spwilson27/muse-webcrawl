Penalty method

Penalty methods are a certain class of algorithms for solving constrained optimization problems in mathematical optimization. A penalty method replaces a constrained optimization problem by a series of unconstrained problems whose solutions ideally converge to the solution of the original constrained problem.

Formulation

The unconstrained problems are formed by adding a term, called a penalty function, to the objective function; the penalty function consists of a penalty parameter multiplied by a measure of violation of the constraints. When the penalty parameter grows to infinity, the solution of the unconstrained problem converges to the solution of the original problem, though in practice finite penalty parameters create numerical ill-conditioning, so algorithms increase the parameter gradually.

Types

For equality constraints h(x) = 0, a common penalty is (μ/2)·||h(x)||²; for inequality constraints g(x) ≤ 0, the quadratic penalty uses (μ/2)·||max(0, g(x))||². Exterior penalty methods approach the feasible region from outside, whereas barrier methods keep iterates strictly feasible and penalise approach to the boundary; the two ideas are combined in augmented Lagrangian methods, which add multiplier estimates to quadratic penalties and can achieve exact solutions with finite penalty parameters.

Applications

Penalty methods appear in nonlinear programming solvers, in finite element analysis for enforcing contact and incompressibility constraints, and in machine learning, where regularisation terms such as ridge (L2) and lasso (L1) penalties are closely related constructions.
