List of archive formats

An archive format is a file format for storing multiple files, often with compression, in a single container file. Archive formats are used for software distribution, backup, and data transfer. This list divides formats into archiving-only, compression-only, and combined archiving-and-compression formats.

Archiving only

FormatExtensionNotes
tar.tarTape archive; standard on Unix since 1979
ar.aUnix archiver; used for static libraries and .deb packages
cpio.cpioCopy-in/copy-out archive used in initramfs images
ISO image.isoDisc image format for optical media (ISO 9660 / UDF)
WARC.warcWeb archive format used by the Internet Archive

FormatExtensionAlgorithm

bzip2.bz2Burrows–Wheeler transform + Huffman coding
xz.xzLZMA2
Zstandard.zstZstd
LZ4.lz4LZ4 (very fast, moderate ratio)
compress.ZLZW
