Newton fractal

The Newton fractal is a fractal generated by applying Newton's method for finding roots of a complex polynomial. Each starting point in the complex plane is coloured according to which root the iteration converges to, and by how quickly; the boundaries between these basins of attraction form intricate fractal patterns.

Construction

For a polynomial p(z), Newton's iteration z → z − p(z)/p′(z) is applied from each initial point. For a polynomial of degree n there are generally n roots and n basins. Near basin boundaries, tiny changes in the starting point can send the iteration to a different root — a manifestation of sensitive dependence. Famous examples use p(z) = z³ − 1, whose threefold-symmetric fractal illustrates the Wada property in places.

Generalisations

Variants include shaded renderings by iteration count, Nova fractals, and damped or generalised Newton methods for other equations. The Newton fractal is a staple of computer graphics and complex dynamics, closely related to Julia sets.
