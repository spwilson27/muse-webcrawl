Cantor function

The Cantor function is a classic example in mathematical analysis of a function that is continuous everywhere but not absolutely continuous. It is sometimes called the Devil's staircase, and is closely related to the Cantor set. It was first described by Georg Cantor in 1884.

Definition

Write x in [0,1] in base 3 (ternary). If the expansion contains a 1, truncate at the first 1; replace every 2 by 1 and reinterpret the result as a binary number; numbers in the Cantor set map in a related way. Equivalently, the function is constant on each interval removed in the construction of the Cantor set, and the values on those intervals enumerate the dyadic rationals in increasing order.

Properties

The Cantor function rises continuously from 0 to 1, yet its derivative is zero almost everywhere — it climbs only on the Cantor set, which has Lebesgue measure zero. It is monotonic and singular. It maps the Cantor set (measure zero) onto the whole interval [0,1] (measure one), a striking example used in teaching real analysis and measure theory.

Generalizations

Variants can be constructed from fat Cantor sets and other fractals, producing staircases with similar singular behaviour.
