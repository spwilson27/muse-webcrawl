Minkowski bound

In algebraic number theory, the Minkowski bound is an upper bound on the absolute value of the discriminant of a number field that can be used to show that the class number of the field is finite, and to determine a set of prime ideals whose classes must generate the ideal class group.

Definition

Let K be a number field of degree n over the rationals, with r1 real embeddings and r2 pairs of complex embeddings, so n = r1 + 2r2. Let dK be the discriminant of K. The Minkowski bound MK is

MK = (n! / nn) (4/π)r2 √|dK|.

Use

Minkowski's theorem on linear forms, from the geometry of numbers, implies that every ideal class of K contains an integral ideal whose norm is at most MK. Consequently only finitely many ideals need be examined to compute the class group, and any prime ideal with norm below the bound must be considered.

The bound is a special case of Minkowski's convex body theorem applied to the lattice obtained by embedding the ring of integers into Euclidean space.
