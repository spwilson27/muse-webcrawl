Microsoft Outlook

Microsoft Outlook
Developer: Microsoft
First released: 1997
Type: Personal information manager
Part of: Microsoft Office / Microsoft 365

Microsoft Outlook is a personal information manager software system from Microsoft, available as part of the Microsoft Office and Microsoft 365 suites. Though primarily an email client, Outlook also includes calendaring, task management, contact management, note-taking and journal features. It is used by hundreds of millions of people, especially in corporate environments connected to Microsoft Exchange Server.

History

Outlook 97 was released in January 1997 as a component of Office 97, unifying Microsoft's mail and scheduling clients. Successive versions added Internet mail support, improved rules and search, the ribbon interface (2007), and deep cloud integration with Microsoft 365. A new web-based "One Outlook" client began replacing the separate Windows Mail and classic desktop app in the 2020s.

Related services

The name Outlook is also used for Microsoft's free webmail service, Outlook.com (the successor to Hotmail, rebranded in 2012–2013), and for mobile apps on iOS and Android derived from the acquired Acompli app. Outlook supports the .pst and .ost data file formats for local mail storage.
