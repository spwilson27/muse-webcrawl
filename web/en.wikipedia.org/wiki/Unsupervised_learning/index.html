Unsupervised learning

From Wikipedia, the free encyclopedia

Clustering: finding structure in unlabelled data

Unsupervised learning is a framework in machine learning in which algorithms learn patterns from data that has not been labelled, classified or categorised by humans. Instead of being told the correct answer for each example, the algorithm must discover structure in the data itself.

Principal tasks

The best-known unsupervised task is clustering — grouping similar examples together — using methods such as k-means, hierarchical clustering and DBSCAN. Dimensionality reduction compresses data into fewer variables while preserving structure, with techniques including principal component analysis (PCA), t-SNE, UMAP and autoencoders; the results aid visualisation and downstream learning. Other tasks include association rule learning (finding items that co-occur, e.g. with the Apriori algorithm), anomaly detection for spotting outliers and fraud, and density estimation.

Approaches and applications

Generative models — from Gaussian mixture models to generative adversarial networks and diffusion models — learn the distribution of the data and can produce new samples. Self-supervised learning, in which labels are generated automatically from parts of the input (for example, predicting masked words), blurs the boundary with supervised learning and underlies modern large language models' pre-training.

Applications include customer segmentation, recommendation, document organisation, gene-expression analysis, image compression, and pre-processing for supervised systems where labelled data is scarce or expensive.
