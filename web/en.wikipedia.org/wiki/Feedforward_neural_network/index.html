Feedforward neural network

An artificial neural network is called a feedforward neural network if the connections between the nodes do not form a cycle. In such a network, information moves in only one direction—forward—from input nodes, through hidden layers (if any), to the output nodes.

Structure

Each neuron computes a weighted sum of its inputs plus a bias, passed through a nonlinear activation function such as the sigmoid, tanh or ReLU. The simplest feedforward network is the single-layer perceptron; networks with one or more hidden layers (multilayer perceptrons) can approximate arbitrary continuous functions, per the universal approximation theorem.

Training

Feedforward networks are usually trained by backpropagation, in which the gradient of a loss function is computed via the chain rule and weights are updated by gradient descent. They contrast with recurrent neural networks, which contain cycles and internal state.
