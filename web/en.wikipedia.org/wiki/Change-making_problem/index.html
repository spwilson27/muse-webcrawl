Change-making problem

Making change with the fewest coins

The change-making problem addresses the question of finding the minimum number of coins (of certain denominations) that add up to a given amount of money. It is a special case of the integer knapsack problem and has applications beyond money, wherever items come in fixed sizes.

Methods of solution

For canonical coin systems such as those used in the United States and the euro area, a greedy algorithm—repeatedly taking the largest denomination not exceeding the remaining amount—always yields an optimal solution. For arbitrary coin systems, greedy can fail, and the problem is generally solved with dynamic programming in pseudo-polynomial time.

A coin system for which the greedy algorithm is always optimal is called canonical. It can be tested efficiently whether a given coin system is canonical, and counterexamples, when they exist, can be found within certain bounds.

Related problems

The variant asking how many ways change can be made is a counting problem also solvable by dynamic programming. The change-making problem is closely related to the coin problem (Frobenius coin problem), which asks for the largest amount that cannot be formed from given denominations.
