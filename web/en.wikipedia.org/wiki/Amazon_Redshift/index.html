Amazon Redshift

Amazon Redshift
Developer: Amazon Web Services
Initial release: 2012 (preview); 2013 (general availability)
Type: Cloud data warehouse

Amazon Redshift is a fully managed, petabyte-scale data warehouse service in the cloud, offered by Amazon Web Services. It is built for online analytical processing (OLAP) and business intelligence workloads, allowing customers to run complex analytic queries against structured and semi-structured data using standard SQL.

Architecture

Redshift is based on a massively parallel processing (MPP) architecture derived from PostgreSQL 8.0.2, with columnar storage, data compression, and query optimisation for analytics. A cluster consists of a leader node that coordinates query execution and compute nodes that store data and run queries in parallel. Redshift Serverless, introduced later, removes the need to provision cluster capacity manually.

Integration

Data can be loaded from Amazon S3, DynamoDB, and other sources, and Redshift Spectrum allows querying data directly in S3 data lakes. The service integrates with AWS analytics and machine learning tools and is named after the astronomical phenomenon of redshift, in a playful nod to "Oracle" — corporate shorthand being "shifting away" from traditional database vendors.
