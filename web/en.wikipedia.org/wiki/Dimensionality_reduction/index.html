Dimensionality reduction

Dimensionality reduction, or dimension reduction, is the transformation of data from a high-dimensional space into a low-dimensional space so that the low-dimensional representation retains some meaningful properties of the original data, ideally close to its intrinsic dimension.

Motivation

High-dimensional data suffer from the curse of dimensionality: distances become uninformative, models overfit, and computation grows costly. Reducing dimensions aids visualisation (to 2D or 3D), speeds learning, removes redundant features and noise, and compresses storage.

Methods

Linear methods include principal component analysis (PCA), linear discriminant analysis and factor analysis. Nonlinear manifold methods include t-SNE, UMAP, Isomap and autoencoders. Feature selection — choosing a subset of original features — is a related approach that keeps interpretability.

Applications

Uses include visualising single-cell gene expression, face recognition (eigenfaces), information retrieval via latent semantic analysis, and preprocessing for machine-learning pipelines.
