Huffman coding

A Huffman tree: frequent symbols sit near the root and receive short codes.

In computer science and information theory, Huffman coding is a widely used algorithm for lossless data compression. It assigns variable-length binary codes to input symbols such that more frequent symbols receive shorter codes, and no code is a prefix of any other (a prefix-free code), allowing unambiguous decoding. The algorithm was developed by David A. Huffman and published in his 1952 paper "A Method for the Construction of Minimum-Redundancy Codes", written while he was a graduate student at MIT in Robert Fano's information theory class.

Algorithm

Given symbols and their frequencies, the algorithm repeatedly combines the two least frequent nodes into a new internal node whose weight is the sum of the two, building a binary tree from the bottom up. When one node remains, the path from the root to each symbol's leaf — left and right branches read as 0 and 1 — spells out that symbol's code. The greedy construction provably yields an optimal prefix-free code, minimising the average code length for the given frequencies; its expected length lies within one bit per symbol of the source's entropy.

Variants and uses

Canonical Huffman codes allow the code to be transmitted compactly by specifying only code lengths. Adaptive Huffman coding updates the tree as data is processed, and length-limited variants cap the maximum code length for practical decoders. Huffman coding is a component of many compression formats, including DEFLATE (ZIP, gzip, PNG), JPEG and MP3, where it encodes quantised coefficients after other transforms have concentrated the data.
