The perceptual quantizer (PQ) is a transfer function developed by Dolby Laboratories for high dynamic range (HDR) video that allows for the display of luminance values up to 10,000 cd/m2 (nits) and down to 0.0001 nits. It was standardized as SMPTE ST 2084 in 2014 and is the electro-optical transfer function (EOTF) at the foundation of the HDR10, Dolby Vision, and HDR10+ formats. PQ is also specified in ITU-R Recommendation BT.2100 alongside the hybrid log–gamma (HLG) function.

Technical details

Unlike the gamma curves used in standard dynamic range video, which are based on the characteristics of cathode-ray tube displays, PQ is based on the contrast sensitivity of the human visual system — specifically on the Barten contrast sensitivity model — so that successive code values correspond to just-noticeable differences in brightness across the whole range. With a 12-bit signal, quantization steps remain below the threshold of visibility even at the full 10,000-nit range, avoiding visible banding; with 10 bits, small amounts of dithering or mild banding may occur in the darkest tones.

The PQ EOTF maps a non-linear signal value to a display luminance in cd/m2, defined by a formula involving constants m1 = 2610/16384, m2 = 2523/4096 × 128, and c1, c2, c3 values derived from those constants. The inverse function (the OETF used in mastering) converts linear scene light into PQ code values. Because PQ is an absolute, display-referred system, the code values have a fixed relationship to physical luminance, in contrast to HLG's relative, scene-referred approach.

Use in HDR formats

HDR10 uses PQ with 10-bit colour depth, static metadata (ST 2086) and the Rec. 2020 colour space. Dolby Vision uses PQ with up to 12-bit depth and dynamic, scene-by-scene metadata. HDR10+ also builds on PQ with dynamic metadata. The wide adoption of PQ in streaming services, Ultra HD Blu-ray, and broadcast standards has made it the dominant transfer function for consumer HDR.
