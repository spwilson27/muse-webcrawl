Standard library

A standard library in computer programming is the library made available across implementations of a programming language. These libraries are conventionally described in programming language specifications; however, contents of a language's associated library may also be determined (in part or whole) by more informal practices of a language's community.

Contents

A standard library typically includes definitions for commonly used algorithms, data structures, and mechanisms for input and output. Typical contents include string handling, mathematical functions, file and network input/output, data structures such as lists and maps, and facilities for memory management, concurrency, and error handling.

Philosophies

Languages differ greatly in how much functionality they place in the standard library. Python follows a "batteries included" philosophy, shipping a very large library covering everything from XML parsing to a built-in web server. In contrast, languages such as C provide a relatively small standard library, while Rust and Go include moderately large, carefully curated libraries. Java's class library and the .NET Framework's Base Class Library are extensive and central to their platforms.
