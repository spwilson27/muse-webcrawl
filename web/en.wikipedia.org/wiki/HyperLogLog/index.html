HyperLogLog

HyperLogLog is a probabilistic data structure and algorithm for the count-distinct problem: estimating the cardinality (number of distinct elements) of a multiset using small, fixed memory. It was described by Philippe Flajolet and co-authors in 2007, building on the LogLog algorithm.

How it works

Elements are hashed uniformly; the hash bits select one of m registers, and each register stores the maximum number of leading zeros (plus one) seen in the remaining bits — the maximum rank. A harmonic-mean estimator over the registers, with bias corrections for small and large ranges, yields the cardinality estimate with a standard error of about 1.04/√m.

Use

With only about 1.5 kilobytes for m = 211 registers, HyperLogLog can estimate counts in the billions with roughly 2% error. It is implemented in systems such as Redis (PFCOUNT), PostgreSQL extensions, Google BigQuery, and Presto/Trino for approximate distinct counting.

References: Flajolet et al., "HyperLogLog: the analysis of a near-optimal cardinality estimation algorithm" (2007).
