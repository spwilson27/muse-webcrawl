Zero matrix

In mathematics, particularly linear algebra, a zero matrix or null matrix is a matrix all of whose entries are zero. It serves as the additive identity of the additive group of matrices of the same size, and is denoted by the symbol 0 (without any subscript, or with a subscript indicating its size when needed).

Examples

Some examples of zero matrices are:

01×1 = [0],  02×2 = a 2×2 array of zeros,  02×3 = a 2×3 array of zeros.

Properties

The set of m × n matrices with entries in a ring forms a ring, and the zero matrix is its additive identity: for any matrix A of the same size, A + 0 = A = 0 + A. There is exactly one zero matrix of any given size. Multiplying any matrix by a zero matrix of compatible size yields a zero matrix: 0 · A = 0 and A · 0 = 0. The zero matrix has rank 0 (unless it has no rows or columns at all), determinant 0 in the square case, and is the only matrix that is both symmetric and skew-symmetric. Unlike the zero vector space over the empty set, products involving empty matrices also lead to the zero matrix being the identity of certain degenerate cases.
