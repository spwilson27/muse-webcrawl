Noetherian module

In abstract algebra, a Noetherian module is a module that satisfies the ascending chain condition on its submodules: every increasing sequence of submodules M1 ⊆ M2 ⊆ … eventually stabilises. Equivalently, every submodule is finitely generated, and every non-empty set of submodules has a maximal element. The concept is named after Emmy Noether.

Properties

Submodules and quotient modules of a Noetherian module are Noetherian, and a module is Noetherian if and only if it can be built from Noetherian pieces in a short exact sequence. A ring is called a Noetherian ring if it is Noetherian as a module over itself. Hilbert's basis theorem implies that polynomial rings over Noetherian rings are Noetherian, and that finitely generated modules over Noetherian rings are Noetherian.

Examples

The integers as a module over themselves (an abelian group under the usual correspondence) are Noetherian since every subgroup is finitely generated, while the ring of polynomials in infinitely many variables is not Noetherian. The Prüfer group is an example of a non-Noetherian abelian group.
