eMule is a free peer-to-peer file sharing application for Microsoft Windows. Started in May 2002 by Hendrik Breitkreuz ("Merkur"), who was dissatisfied with the original eDonkey2000 client, it connects to both the eDonkey network and the serverless Kad network (based on the Kademlia algorithm). Distributed as open-source software under the GNU General Public License, it became one of the most-downloaded projects on SourceForge.

Features

eMule introduced features that distinguished it from eDonkey2000, including a credit system rewarding users who upload, intelligent corruption control that re-downloads only damaged parts of files, preview of partially downloaded media, built-in chat, and extensive source exchange so clients can find peers without a server. Files are identified by MD4 hashes and shared via "ed2k" links, which can be published on link sites. Because the code is open source, numerous modified versions ("mods") such as eMule Xtreme appeared, as did the cross-platform clone aMule.

History and use

At its mid-2000s peak, the eDonkey network was among the most-used file-sharing networks in the world, particularly in Europe. Use declined with the rise of BitTorrent and later streaming services, but eMule maintained a niche reputation for finding rare and older files. As with other peer-to-peer systems, much shared content was copyrighted material distributed without authorisation, and the network attracted legal and scholarly attention for that reason.
