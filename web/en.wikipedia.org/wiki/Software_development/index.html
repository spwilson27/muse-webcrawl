Software development

Software development is the process of designing, creating, testing, and maintaining software applications, frameworks, and systems. It encompasses the full software development life cycle (SDLC): requirements analysis, design, implementation (programming), verification and validation, deployment, and maintenance. Software development is carried out by programmers, software engineers, and multidisciplinary teams, and is central to the modern software industry.

Process

Development methodologies organize work in different ways. The traditional waterfall model proceeds through sequential phases, each completed before the next begins. Agile approaches, popularized by the 2001 Agile Manifesto, instead iterate in short cycles ("sprints" in Scrum), delivering working software incrementally and adapting to changing requirements. Related practices include DevOps, which integrates development with IT operations and emphasizes continuous integration and continuous delivery (CI/CD), and test-driven development (TDD), in which automated tests are written before the code they check.

Activities

  • Requirements engineering — eliciting, analyzing, and documenting what the software must do, often recorded in a software requirements specification.
  • Design — software architecture, data structures, interfaces, and user experience.
  • Construction — writing and reviewing source code, typically managed with version control systems such as Git.
  • Testing — unit, integration, system, and acceptance testing to find defects.
  • Deployment and maintenance — releasing the software and fixing bugs, adding features, and adapting to new environments over its lifetime; maintenance commonly consumes the majority of total cost.

History

Software development emerged as a discipline in the 1950s and 1960s alongside commercial computing. The 1968 NATO conference on "software engineering" coined that term amid a perceived "software crisis" of projects delivered late, over budget, and full of errors. Structured programming, object-oriented programming, integrated development environments, open-source collaboration, and cloud platforms successively transformed practice. In the 2020s, AI-assisted coding tools began reshaping how code is written and reviewed.
