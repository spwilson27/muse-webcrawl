CUDA (originally Compute Unified Device Architecture) is a proprietary parallel computing platform and application programming interface (API) that allows software to use certain types of graphics processing units (GPUs) for accelerated general-purpose processing, a technique known as GPGPU. CUDA is a software layer that gives direct access to the GPU's virtual instruction set and parallel computational elements for the execution of compute kernels.

Programming model

CUDA is designed to work with programming languages such as C, C++, and Fortran. A CUDA program invokes parallel kernels: functions that run on the GPU executed by many threads in parallel. Threads are organised into blocks, and blocks into a grid; threads within a block can cooperate through shared memory and synchronisation. This hierarchy maps onto the GPU hardware of streaming multiprocessors, allowing programs to scale transparently across devices with different numbers of cores.

History

Nvidia introduced CUDA in November 2006 alongside the GeForce 8800 GTX, the first GPU built on the unified Tesla architecture with dedicated CUDA cores. The CUDA Toolkit version 1.0 followed in February 2007. Initially aimed at scientific computing, CUDA became central to high-performance computing and, in the 2010s, to deep learning: frameworks such as TensorFlow and PyTorch rely on CUDA libraries (cuBLAS, cuDNN) for training neural networks, which made Nvidia GPUs the dominant hardware of the AI boom.

Capabilities and limitations

CUDA exposes features tuned to Nvidia hardware, including fine-grained memory hierarchies, tensor cores for matrix arithmetic in later architectures, cooperative groups, and unified memory. Because it is proprietary and runs only on Nvidia hardware, alternatives such as OpenCL, SYCL, Vulkan compute and AMD's ROCm/HIP (which can translate much CUDA code) compete with it. GPU programmers use CUDA for applications from molecular dynamics and weather simulation to cryptography and real-time rendering.
