Source-to-source compiler

A source-to-source translator, source-to-source compiler (S2S compiler), transcompiler, or transpiler is a type of translator that takes the source code of a program written in a programming language as its input and produces an equivalent source code in the same or a different programming language. A source-to-source translator converts between programming languages that operate at approximately the same level of abstraction, while a traditional compiler translates from a higher level programming language to a lower level programming language.

History

One of the earliest transcompilers was Ratfor (1970s), which translated a structured version of Fortran into standard Fortran. The original implementation of C++ (Cfront, developed by Bjarne Stroustrup in the early 1980s) translated C++ into C, allowing C++ to run anywhere a C compiler existed. Similarly, early implementations of many languages, and the Eiffel compiler, used C as a portable intermediate target.

Examples

  • Babel translates modern JavaScript (ES6 and later) into older versions compatible with more browsers.
  • TypeScript compiles to plain JavaScript, adding static type checking.
  • Emscripten compiles C and C++ to WebAssembly or JavaScript.
  • Haxe can output many target languages from a single source language.
  • CoffeeScript, Dart (in its early years), and numerous other languages compile to JavaScript.
  • f2c translates Fortran 77 into C.
  • 2to3 and similar tools translate between versions of the same language, such as Python 2 to Python 3.

Uses

Source-to-source translation is used to port legacy code to modern platforms, to run code written for one ecosystem in another (for example, on the web), to apply mechanical refactorings and program transformations, and to implement new languages quickly by targeting an existing language with mature tooling. Automatic parallelising compilers and some program optimisation tools also work in a source-to-source fashion.
