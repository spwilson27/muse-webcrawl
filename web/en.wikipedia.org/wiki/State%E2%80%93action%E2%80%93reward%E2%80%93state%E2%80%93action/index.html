State–action–reward–state–action

State–action–reward–state–action (SARSA) is an algorithm for learning a Markov decision process policy, used in the reinforcement learning area of machine learning. It was proposed by Rummery and Niranjan in a technical note with the name "Modified Connectionist Q-Learning" (MCQ-L). The alternative name SARSA, proposed by Richard Sutton, mentions the quintuple of states, actions and rewards that influence the update: (st, at, rt, st+1, at+1).

Algorithm

SARSA is an on-policy temporal-difference control algorithm. Its update rule for the action-value function Q is:

Q(st, at) ← Q(st, at) + α [ rt + γ Q(st+1, at+1) − Q(st, at) ],

where α is the learning rate and γ is the discount factor. Because the update uses the action actually taken in the next state under the current policy, SARSA is classified as on-policy, in contrast to the off-policy Q-learning algorithm, which uses the maximum over next actions.

Properties

With appropriate exploration policies (such as ε-greedy with decaying ε) and learning-rate schedules, SARSA converges to the optimal action-value function. Because it accounts for the exploratory actions the agent actually takes, SARSA can learn safer policies than Q-learning in environments where exploration carries penalties, such as the classic "cliff walking" example.
