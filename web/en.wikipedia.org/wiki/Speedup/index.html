Speedup

In computer architecture, speedup is a number that measures the relative performance of two systems processing the same problem. More formally, the speedup obtained by improving a system with some enhancement is the ratio of the execution time without the enhancement to the execution time with it; in parallel computing it is the ratio of the execution time on one processor to the execution time on p processors solving the same problem.

Amdahl's and Gustafson's laws

Amdahl's law states that the theoretical speedup of a program using multiple processors is limited by the fraction of the program that must remain sequential. If a fraction s of the work is inherently serial, then even with infinitely many processors the speedup cannot exceed 1/s. For example, a program that is 95% parallelizable has a maximum speedup of 20.

Gustafson's law offers a complementary view: as more processors are added, the problem size is typically scaled up as well, so the serial fraction's share shrinks and near-linear scaled speedup is achievable.

Efficiency and anomalies

Speedup divided by the number of processors gives efficiency; an ideal parallel program has linear speedup (efficiency 1). In practice, overheads in communication, synchronization, and load imbalance yield sublinear speedup. Occasionally, superlinear speedup is observed, usually because the aggregate cache or memory of the parallel system holds working sets that do not fit on a single processor, reducing memory stalls.
