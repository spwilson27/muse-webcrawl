Similarity search

Similarity search is the problem of finding, within a large collection of objects, those most similar to a given query object according to some similarity or distance measure. It generalises the nearest neighbour search problem and is a fundamental operation in databases, information retrieval, data mining and machine learning.

Problem formulation

Given a set of objects, typically represented as vectors in a metric space or a high-dimensional feature space, and a query object, a similarity search returns either the k nearest neighbours of the query (k-NN search) or all objects within a given distance threshold (range search). Similarity may be defined by Euclidean distance, cosine similarity, Jaccard similarity over sets, edit distance over strings, or a domain-specific measure.

Challenges

Exact search by linear scan becomes prohibitively slow for large collections, while classical indexing structures such as kd-trees and R-trees degrade badly in high dimensions — an instance of the curse of dimensionality, under which distances concentrate and pruning becomes ineffective. As a result, most practical systems accept approximate nearest neighbour (ANN) search, trading a small loss of recall for large gains in speed.

Techniques

Important families of methods include:

  • Locality-sensitive hashing (LSH), which hashes similar items into the same buckets with high probability;
  • Space-partitioning and tree methods, effective in low to moderate dimensions;
  • Graph-based methods, such as hierarchical navigable small world (HNSW) graphs, which navigate a proximity graph greedily from entry points toward the query;
  • Quantisation methods, such as product quantisation, which compress vectors into short codes so that billions of items can be searched in memory.

Applications

Similarity search underlies content-based image retrieval, recommender systems, near-duplicate detection, plagiarism detection, genomic sequence matching, and retrieval-augmented generation, in which the passages most similar to a query are fetched from a vector database to supply context to a language model. Widely used libraries and systems include FAISS, Annoy, ScaNN and dedicated vector databases.
