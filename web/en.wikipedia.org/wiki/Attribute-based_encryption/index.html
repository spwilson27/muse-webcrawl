Attribute-based encryption

Attribute-based encryption (ABE) is a type of public-key encryption in which the secret key of a user and the ciphertext are dependent upon attributes (e.g. the country in which the user lives, or the kind of subscription they have). In such a system, the decryption of a ciphertext is possible only if the set of attributes of the user's secret key matches the attributes of the ciphertext, or satisfies the access policy embedded in it.

History and types

The concept grew out of identity-based encryption and was introduced by Amit Sahai and Brent Waters in 2005 as "fuzzy identity-based encryption". Two main variants were subsequently developed:

  • Key-policy ABE (KP-ABE): ciphertexts are labelled with sets of attributes, and a user's private key embeds an access structure; the key can decrypt a ciphertext if its attribute set satisfies the structure.
  • Ciphertext-policy ABE (CP-ABE) (Bethencourt, Sahai and Waters, 2007): the encryptor specifies an access policy over attributes, and users' keys are associated with attribute sets; this variant more closely matches access control scenarios.

Security and properties

ABE schemes are typically built from bilinear pairings on elliptic curves, and are designed to be collusion resistant: combining keys from multiple users should not allow decryption beyond what each key permits individually. A central authority issues keys corresponding to users' attributes. Challenges include key revocation, efficient implementation, attribute management, and resistance to authority compromise, for which multi-authority schemes have been proposed.

Applications

ABE enables fine-grained, cryptographic access control over encrypted data, and is proposed for secure cloud storage, targeted broadcast encryption, electronic health records, and content distribution where data must be shared only with users satisfying a policy.
