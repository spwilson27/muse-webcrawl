List of game engine recreations

The List of game engine recreations documents open-source re-implementations of video game engines, sometimes called source ports. Such projects rewrite an engine from scratch — often by reverse engineering or after an official source release — so that classic games can run on modern and alternative platforms, typically requiring the original game's data files.

Motivation

Engine recreations preserve games whose original binaries no longer run on current hardware, fix bugs, enable widescreen and high-refresh support, and open the door to modding. Because they generally ship without copyrighted assets, players must supply data from a legally owned copy of the game.
