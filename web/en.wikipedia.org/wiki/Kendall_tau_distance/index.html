Kendall tau distance

The Kendall tau distance is a metric that counts the number of pairwise disagreements between two ranking lists. The value is equal to the number of pairs of items whose relative order differs between the two rankings, and it is also known as the bubble-sort distance because it equals the number of swaps bubble sort must perform to transform one ranking into the other.

Kendall tau distance
Named afterMaurice Kendall
Also known asBubble-sort distance

Definition

Given two lists of the same n items, the Kendall tau distance counts the pairs (i, j) such that i precedes j in one list but follows j in the other. The distance ranges from 0 (identical orderings) to n(n−1)/2 (complete reversal).

Properties and computation

The distance is a true metric on permutations and is related to the number of inversions in a permutation, so it can be computed in O(n log n) time with a modified merge sort. A normalised version, dividing by the maximum possible distance, is closely related to Kendall's tau rank correlation coefficient.

Applications

The Kendall tau distance is used in rank aggregation, information retrieval, voting theory, and the comparison of search engine results and recommender system outputs.
