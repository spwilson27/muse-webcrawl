In machine learning, the perceptron is an algorithm for supervised learning of binary classifiers. A binary classifier is a function which can decide whether or not an input, represented by a vector of numbers, belongs to some specific class. It is a type of linear classifier, i.e. a classification algorithm that makes its predictions based on a linear predictor function combining a set of weights with the feature vector.

History

The perceptron was invented in 1957 at the Cornell Aeronautical Laboratory by Frank Rosenblatt, funded by the United States Office of Naval Research. The perceptron was intended to be a machine, rather than a program, and while its first implementation was in software for the IBM 704, it was subsequently implemented in custom-built hardware as the "Mark 1 perceptron". This machine was designed for image recognition: it had an array of 400 photocells, randomly connected to the "neurons". Weights were encoded in potentiometers, and weight updates during learning were performed by electric motors.

In 1969, Marvin Minsky and Seymour Papert published the book Perceptrons, which showed that single-layer perceptrons could not learn the XOR function — a result often (though somewhat unfairly) blamed for a decline in funding and interest in connectionist research during the so-called "AI winter". Interest revived with the popularisation of the multilayer perceptron and backpropagation in the 1980s.

Definition

A perceptron computes f(x) = 1 if w·x + b > 0 and 0 otherwise, where w is a vector of real-valued weights, w·x is the dot product, and b is the bias, a constant term that does not depend on any input value. The perceptron learning rule updates the weights whenever an example is misclassified: w ← w + y·x for the true label y ∈ {−1, +1}. If the training data are linearly separable, the perceptron convergence theorem guarantees that the algorithm will find a separating hyperplane in finitely many steps.

Variants

  • Multilayer perceptron — networks of perceptron-like units trained by backpropagation
  • Averaged perceptron — keeps an average of weight vectors for better generalisation
  • Voted perceptron — uses multiple weight vectors weighted by their survival time
  • Kernel perceptron — applies the kernel trick for non-linear boundaries
