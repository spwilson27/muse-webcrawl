IOMMU

In computing, an input–output memory management unit (IOMMU) is a memory management unit (MMU) connecting a direct-memory-access–capable (DMA-capable) I/O bus to the main memory. Like a traditional MMU, which translates CPU-visible virtual addresses to physical addresses, the IOMMU maps device-visible virtual addresses (also called device addresses or I/O addresses) to physical addresses. Some units also provide memory protection from faulty or malicious devices.

Advantages

An IOMMU allows devices to address memory using the same virtual addresses as the rest of the system, enables devices with limited address ranges to access all of main memory, provides scatter-gather DMA by mapping scattered physical pages into a contiguous device-visible range, and protects memory from erroneous or malicious DMA. These features are essential for device passthrough in virtualization, where a guest virtual machine is given direct control of a physical device while being prevented from accessing memory outside its own.

Implementations

Intel markets its IOMMU technology as VT-d (Virtualization Technology for Directed I/O). AMD's implementation is called AMD-Vi. ARM specifies the System Memory Management Unit (SMMU) architecture. Older and simpler forms include the Graphics Address Remapping Table (GART) used by AGP and early x86 systems.

Use in virtualization

With IOMMU support, hypervisors such as Xen, KVM and Hyper-V can assign PCI devices directly to guest virtual machines (PCI passthrough, and with SR-IOV, individual virtual functions), achieving near-native I/O performance while the IOMMU enforces isolation between guests.
