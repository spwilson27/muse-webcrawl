QNX

QNX (pronounced "Q-N-X") is a commercial Unix-like real-time operating system, aimed primarily at the embedded systems market. It is based on a microkernel architecture in which nearly all functionality, including device drivers, file systems and networking, runs as separate user-space processes communicating by message passing. QNX is developed by QNX Software Systems, a subsidiary of BlackBerry Limited, and is widely used in automobiles, medical devices, industrial control and railway systems.

History

QNX was created in 1980 by Gordon Bell and Dan Dodge, students at the University of Waterloo, who founded Quantum Software Systems to market it. An early demonstration version famously fit a kernel, editor and BASIC interpreter onto a single floppy disk. In the 1990s the system was renamed QNX and gained the Photon microGUI. Harman International acquired the company in 2004, and Research In Motion (now BlackBerry) purchased it in 2010, briefly using a QNX-derived system in the BlackBerry PlayBook and BlackBerry 10 phones. The source code was made available to registered developers between 2007 and 2010 before returning to a fully proprietary licence.

Architecture

The QNX Neutrino kernel itself provides only CPU scheduling, interprocess communication, interrupt redirection and low-level network services. Everything else — including process creation — is handled by cooperating processes, so a crashed driver can be restarted without rebooting. The kernel implements priority inheritance to avoid priority inversion, a key property for hard real-time deadlines, and supports symmetric multiprocessing. Because of its POSIX compliance, software written for Unix-like systems can usually be ported to QNX with little effort.

Uses

QNX is best known today for automotive software: its operating system and hypervisor run in digital instrument clusters and infotainment systems in tens of millions of vehicles, and it has been certified to ISO 26262 ASIL D for functional safety. It also powers medical devices, industrial automation controllers, the Canadarm-era space systems' successors, and networking equipment.
