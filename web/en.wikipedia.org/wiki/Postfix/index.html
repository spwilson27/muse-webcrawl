Postfix

Postfix is a free and open-source mail transfer agent (MTA) that routes and delivers electronic mail. It was written by Wietse Venema at the IBM Thomas J. Watson Research Center and first released in 1998 under the name VMailer, later IBM Secure Mailer, before being renamed Postfix. It was designed as a faster, easier to administer, and more secure alternative to the then-dominant Sendmail program, and it has become one of the most widely deployed mail servers on the internet, running on a large share of surveyed mail servers together with Exim.

Architecture

Unlike monolithic mail programs, Postfix is built from many small cooperating daemon processes, each performing a specific task with the least privilege necessary: the smtpd daemon receives mail over SMTP, the queue manager (qmgr) schedules deliveries, smtp sends mail to other servers, and local delivers to local mailboxes. The master daemon starts and supervises these processes. This design limits the damage from any single compromised component and makes the system notably robust under load.

Features

  • Compatibility with Sendmail-style configuration, aliases, and mailbox formats, easing migration
  • Extensive anti-spam controls, address rewriting, and support for external content filters ("milters")
  • Support for SMTPUTF8, TLS encryption, DANE, and multiple databases for lookup tables (LDAP, MySQL, PostgreSQL, SQLite)
  • Virtual domain hosting and per-domain transport routing

Postfix runs on most Unix-like operating systems and is the default mail transfer agent on several Linux distributions and on macOS Server. It is often paired with the Dovecot IMAP/POP3 server to provide a complete mail system.
