Wireless mesh network

TypeNetwork topology
Node typesMesh routers, mesh clients, gateways
Key standardsIEEE 802.11s, IEEE 802.15.4, Thread, Zigbee
RoutingProactive, reactive (AODV), hybrid (HWMP)

A wireless mesh network (WMN) is a communications network made up of radio nodes organized in a mesh topology, in which each node also acts as a relay for other nodes. Mesh networks can relay messages using either a routing technique, in which packets travel along a computed path, or a flooding technique, in which data is broadcast and forwarded throughout the network.

Architecture

A wireless mesh network typically consists of mesh clients (end-user devices), mesh routers that forward traffic, and gateways that connect the mesh to other networks such as the Internet. Because nodes cooperate to forward data, the network can cover a large area and is self-healing: if one node fails, traffic is rerouted around it.

Protocols

Routing in mesh networks uses ad hoc protocols such as OLSR (proactive, link-state), AODV and DSR (reactive, on-demand), and hybrid schemes. The IEEE 802.11s amendment defines mesh networking for Wi-Fi with its Hybrid Wireless Mesh Protocol (HWMP). Open-source implementations such as B.A.T.MAN. are popular in community networks. For low-power devices, protocols including Zigbee, Thread and Bluetooth Mesh provide mesh connectivity for home automation and the Internet of things.

Applications

Mesh networks are used in home Wi-Fi systems (multi-node consumer "mesh Wi-Fi" kits), community broadband networks, municipal and public-safety networks, military tactical communications, disaster recovery, smart metering, and industrial sensor networks. Their main limitations are reduced throughput over multiple hops on a single radio channel, interference, and the complexity of routing and security management.
