DCE/RPC

DCE/RPC
Full name: Distributed Computing Environment / Remote Procedure Calls
Developed by: Open Software Foundation
Descendant: Microsoft RPC (MSRPC)

DCE/RPC is a remote procedure call system developed for the Distributed Computing Environment (DCE) by the Open Software Foundation in the early 1990s. It lets a program execute procedures on another computer as if they were local calls.

Design

Interfaces are defined in an Interface Definition Language (IDL) and compiled into client and server stubs. The runtime handles marshalling of arguments using the Network Data Representation (NDR), locating servers through the DCE directory service, and security through authentication services. It was derived from work at Apollo Computer on its Network Computing System.

Influence

Microsoft's RPC implementation (MSRPC) is based on DCE/RPC and underpins Windows networking services, DCOM and many internal protocols, so DCE/RPC concepts remain widely encountered in Windows environments.
