Computer security model

A computer security model is a formal specification of a security policy: a set of rules and states describing how a system manages, protects, and distributes sensitive information. Security models provide the theoretical foundation for access control mechanisms and are used in the design and evaluation of trusted systems.

Well-known models

The Bell–LaPadula model (1973) enforces confidentiality using security levels, with the rules "no read up" and "no write down". The Biba model is its dual, enforcing integrity with "no read down" and "no write up". The Clark–Wilson model addresses integrity in commercial systems through well-formed transactions and separation of duties. The Brewer–Nash (Chinese Wall) model prevents conflicts of interest by dynamically restricting access to competitor data. Other models include Harrison–Ruzzo–Ullman, the take-grant model, lattice models, and non-interference.

Purpose

A model abstracts a policy so that it can be analysed mathematically; some models have been proven secure under stated assumptions. Security evaluation criteria such as the Trusted Computer System Evaluation Criteria (Orange Book) and the Common Criteria historically required systems to be built according to formal models at higher assurance levels.
