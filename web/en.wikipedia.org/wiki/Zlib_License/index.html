The zlib license is a permissive free software license which defines the terms under which the zlib software library can be distributed, together with other software that uses it. It is also used by many other free software packages. The license is approved by the Free Software Foundation (FSF) as a free software license and by the Open Source Initiative (OSI) as an open source license. It is compatible with the GNU General Public License.

Terms

The license is notably short and imposes only a few conditions:

  • Copyright notices and the permission notice must be retained in the source code; acknowledgement in binary distributions is appreciated but not required in the product documentation unless the original authors request it.
  • The origin of the software must not be misrepresented; the authors may not be claimed as the creators of altered versions by others.
  • Altered source versions must be plainly marked as such and must not be misrepresented as the original software.
  • The software is provided "as is" without warranty, and the authors are not liable for damages arising from its use.

Usage

Beyond zlib itself, the license (often called "zlib/libpng license") is used by the libpng reference library and by numerous libraries and game engines, including parts of the Allegro library and many components in the open-source gaming and embedded software ecosystems. Its brevity and lack of advertising or documentation requirements have made it a popular alternative to the BSD and MIT licenses.
