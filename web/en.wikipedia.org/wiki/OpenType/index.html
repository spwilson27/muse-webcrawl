OpenType

OpenType fonts support ligatures, alternates and rich script shaping.
DevelopersMicrosoft and Adobe
Released1996
TypeComputer font file format
StandardISO/IEC 14496-22 (OFF)

OpenType is a format for scalable computer fonts, developed jointly by Microsoft and Adobe as the successor to TrueType and PostScript Type 1 fonts. An OpenType font is a single file containing outline data in either TrueType (glyf) or PostScript CFF form, plus extensive typographic layout tables, and it is cross-platform: the same file works on Windows, macOS and other systems.

Features

  • Unicode encoding — fonts can contain tens of thousands of glyphs covering many scripts.
  • Advanced typography — the GSUB and GPOS tables provide ligatures, small caps, swashes, old-style figures, contextual alternates and correct positioning for complex scripts such as Arabic and Indic scripts.
  • Font variations — OpenType Font Variations (2016, "variable fonts") let one file interpolate weight, width and other axes, developed jointly with Apple and Google.
  • Colour fonts — layered and bitmap/SVG colour glyph tables.
  • WOFF/WOFF2 — compressed containers of OpenType fonts for web use.

History

Microsoft began work on the format in the mid-1990s; Adobe joined in 1996, contributing its CFF/PostScript outline technology and multiple-master experience. The specification was later standardised as the Open Font Format, ISO/IEC 14496-22. Adobe converted its entire type library to OpenType in the early 2000s, and the format is now the near-universal standard for professional fonts.
