Vector display

A vector display, also called a vector graphics display, calligraphic display or (historically) a stroker display, is a display device that draws images by directing an electron beam to trace lines directly between coordinates, rather than scanning the whole screen in a fixed raster pattern as in television.

Vector monitors draw crisp, flicker-prone line images with a deflected electron beam.

How it works

In a vector CRT, analogue voltages applied to the deflection coils steer the electron beam freely over the phosphor screen. A display list of line segments (vectors) is repeatedly executed — typically 30 to 60 times per second — to maintain the image. Because the beam paints only where lines are needed, resolution is limited mainly by the deflection electronics, giving exceptionally smooth lines and text. The trade-off is flicker: as the display list grows, each frame takes longer to draw and the refresh rate falls below the threshold of perception.

History

Vector displays were standard in early computer graphics: the Whirlwind and TX-2 computers, Ivan Sutherland's Sketchpad system (1963), and the DEC GT40 and Tektronix storage-tube terminals all used them. The Tektronix direct-view storage tube avoided flicker by using a phosphor that retained the image without refreshing, though it could not easily erase parts of the picture.

Arcade games and the Vectrex

The technology is best remembered from arcade games: Atari's Lunar Lander (1979), Asteroids (1979), Battlezone (1980), Tempest (1981) and Star Wars (1983) all used vector monitors, some in colour (Quadrascan). Cinematronics built its early catalogue around vector hardware. The only home console with a built-in vector display was the Vectrex (1982). As raster hardware gained cheap memory and sprite capability in the mid-1980s, vector displays disappeared from gaming.

Modern analogues

Laser projectors used in laser shows are the direct descendants of vector displays, steering a beam with galvanometer mirrors along vector paths. The glowing-line aesthetic of vector games is widely emulated in retro-styled software.
