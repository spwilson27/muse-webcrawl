Web browser

From Wikipedia, the free encyclopedia
[Image: A browser window showing tabs, an address bar, and a web page]

A web browser is an application for accessing websites. It retrieves content from web servers (using HTTP/HTTPS), renders HTML, CSS and JavaScript, and presents web pages and apps to the user through text, graphics, and interactive elements such as links and forms.

The first browser was Tim Berners-Lee's WorldWideWeb (later Nexus) in 1990. Mosaic (1993, Marc Andreessen's team at NCSA) popularised the graphical web; Netscape Navigator (1994) commercialised it; Microsoft's Internet Explorer bundled with Windows won the first browser war (and an antitrust case), was itself displaced by Mozilla Firefox (2004) and then Google Chrome (2008), whose Chromium engine now powers most browsers, including Microsoft Edge.

How browsers work

Main components: a user interface (tabs, address/search bar), a rendering engine (Blink, Gecko, WebKit) that parses HTML/CSS into the DOM and paints pixels, a JavaScript engine (V8, SpiderMonkey, JavaScriptCore) with just-in-time compilation, networking, and storage (cookies, local storage, caches). Modern browsers are effectively operating systems for web applications, with sandboxed processes per site for security.

Extensions and developer tools are standard; browsers also enforce the web's security model (same-origin policy, TLS warnings, tracking protections).

Market

Chrome holds roughly two-thirds of global browser share in most measurements; Safari second (default on Apple devices), with Edge and Firefox following. Engine consolidation around Chromium/WebKit is an ongoing competition-policy debate.
