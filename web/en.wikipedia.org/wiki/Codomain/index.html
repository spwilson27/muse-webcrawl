Codomain

In mathematics, the codomain of a function is the set into which all of the output of the function is constrained to fall. It is normally specified as part of the definition of the function. If f is a function from a set X to a set Y, written

f : X → Y,

then X is the domain of f and Y is its codomain. The set of values that the function actually takes, called the image or range of f, is always a subset of the codomain.

Codomain and range

The distinction between codomain and range is subtle but important. For example, the function f(x) = x² considered as a function from the real numbers to the real numbers has codomain ℝ, but its range is only the set of non-negative real numbers, [0, ∞). The same formula with codomain [0, ∞) defines a different function — one that is surjective, whereas the first is not.

A function is called surjective (or onto) if its range equals its codomain. Whether a function is surjective therefore depends on the codomain chosen; whether it is injective (one-to-one) does not.

Terminology

Some older authors use "range" to mean the codomain, which can be a source of confusion; in modern usage "range" most often means the image. The term "codomain" gained currency through the work of Nicolas Bourbaki in the mid-twentieth century. In category theory, a morphism is specified by a source object and a target object, the target playing the role of the codomain.

Examples

  • The function f : ℤ → ℤ given by f(n) = 2n has codomain ℤ and range the even integers.
  • The matrix of a linear transformation may be viewed as a function between finite-dimensional vector spaces, whose codomain is the target space.
