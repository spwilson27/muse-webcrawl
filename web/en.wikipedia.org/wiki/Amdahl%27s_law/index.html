Amdahl's law (or Amdahl's argument) is a formula which gives the theoretical speedup in latency of the execution of a task at fixed workload that can be expected of a system whose resources are improved. It is named after computer scientist Gene Amdahl, who presented it in 1967.

Definition

If a fraction p of a program can be parallelised and the remaining fraction (1 − p) must run serially, then the maximum speedup using N processors is:

S = 1 / ((1 − p) + p/N)

As N grows large, the speedup is bounded by 1 / (1 − p). Thus, if 95% of a task is parallelisable, the theoretical maximum speedup is 20×, no matter how many processors are added.

Implications

Amdahl's law is frequently used in parallel computing to predict the theoretical speedup when using multiple processors, and to argue that effort should focus on reducing the serial portion of a program. The law assumes the problem size stays fixed — an assumption relaxed by Gustafson's law, which observes that larger problems typically allow the parallel fraction to grow.
