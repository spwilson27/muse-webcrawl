Focus (computing)

In computing, focus indicates the component of a graphical user interface that is currently selected to receive input. Text entered at the keyboard or pasted from the clipboard is delivered to the component that has the focus, and focus is usually indicated visually by a highlight, a blinking text cursor (caret) or a dotted outline.

Focus operates at several levels. A window may be the active window of the desktop while, within it, a particular text field, button or control holds keyboard focus. Clicking a component with the mouse usually moves focus to it, and pressing the Tab key cycles focus through focusable elements in a defined order.

Focus models

Window managers historically implemented different focus policies. In click to focus, the default on most modern systems, a window must be clicked before it receives keyboard input. In focus follows mouse (also called point-to-focus), the window under the pointer has focus without being raised. The sloppy focus variant keeps focus on the last window when the pointer moves over the desktop background. X Window System window managers commonly offered all three; Microsoft Windows and macOS primarily use click-to-focus.

Focus events

GUI toolkits deliver focus events to components when they gain or lose focus, commonly named focus/blur in web browsers and focusin/focusout in the Document Object Model. Developers use these events for validation, showing helper text and updating dependent controls. In web development the :focus CSS pseudo-class styles the focused element, and accessibility guidance recommends that this indicator never be removed without a visible alternative, since keyboard and assistive-technology users depend on knowing where focus is.

Focus stealing

Focus stealing occurs when a background program or pop-up dialog abruptly takes focus, potentially causing keystrokes intended for one application to be received by another. Modern operating systems restrict this behaviour, flashing a taskbar icon instead of raising the window.
