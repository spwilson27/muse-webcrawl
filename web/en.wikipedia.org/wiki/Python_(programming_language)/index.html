Python (programming language)

From Wikipedia, the free encyclopedia
[Image: The Python logo, two interlocking snake-like shapes in blue and yellow]

Python is a high-level, general-purpose programming language. Its design philosophy emphasises code readability with significant indentation. Created by Guido van Rossum and first released in 1991, Python is dynamically typed, garbage-collected, and supports multiple paradigms including procedural, object-oriented, and functional programming.

Python consistently ranks among the most popular programming languages. It is the leading language in data science, machine learning, and education, and is widely used for web development, automation, scientific computing, and scripting.

History

Van Rossum began work on Python in 1989 at CWI in the Netherlands, naming it after Monty Python's Flying Circus. Python 2.0 arrived in 2000; Python 3.0 (2008), a deliberately backwards-incompatible revision, eventually superseded it (Python 2 support ended in 2020). The Python Software Foundation oversees development; after van Rossum stepped down as 'BDFL' in 2018, an elected steering council governs the project.

The reference implementation is CPython, written in C; libraries such as NumPy, pandas, TensorFlow and PyTorch anchor its scientific ecosystem.

Features

Python's syntax favours clarity ('There should be one — and preferably only one — obvious way to do it', per the Zen of Python). It has a large standard library ('batteries included'), dynamic typing with strong typing semantics, list comprehensions, generators, and first-class functions.

Criticisms include execution speed relative to compiled languages and the global interpreter lock (GIL) limiting thread parallelism in CPython — recent versions are progressively removing it.
