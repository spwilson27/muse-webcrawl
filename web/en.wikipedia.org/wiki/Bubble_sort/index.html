Bubble sort

Bubble sort, sometimes called sinking sort, is a simple comparison-based sorting algorithm that repeatedly steps through a list, compares adjacent elements, and swaps them if they are in the wrong order. Larger elements gradually "bubble" to the end of the list. The passes repeat until a complete pass makes no swaps, meaning the list is sorted.

Analysis

Bubble sort has worst-case and average time complexity of O(n²), making it impractical for large lists, though its best case on an already sorted list is O(n) when the no-swap optimization is used. It requires only O(1) extra memory, is stable, and is easy to implement, which is why it is widely taught as an introductory algorithm.

Pseudocode

repeat: swapped ← false; for each adjacent pair (a, b): if a > b, swap them and set swapped ← true; until swapped is false.

Variants and reputation

Variations include cocktail shaker sort, which passes in both directions. Despite its pedagogical value, bubble sort is often used as an example of an inefficient algorithm, and computer scientists have long criticized teaching it in place of better simple sorts such as insertion sort.
