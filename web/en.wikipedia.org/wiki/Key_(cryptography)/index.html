Key (cryptography)

In cryptography, a key is a piece of information, usually a string of numbers or letters stored in a file, which when processed through a cryptographic algorithm can encode or decode cryptographic data. Based on the algorithm used, the key may vary in size, but modern practice uses keys of 128, 192, or 256 bits for symmetric ciphers and thousands of bits for public-key systems.

Key types

In symmetric-key cryptography, the same key is used for encryption and decryption. In public-key (asymmetric) cryptography, each user has a pair of keys: a public key that anyone may use to encrypt messages or verify signatures, and a private key that is kept secret for decryption or signing.

Key management

Secure generation, exchange, storage, and destruction of keys — collectively called key management — is essential to the security of a cryptosystem; by Kerckhoffs's principle, a system should be secure even if everything about it except the key is public knowledge. Keys are typically generated using random number generators or derived from passwords with key derivation functions.
