Wikipedia:File Upload Wizard

From Wikipedia, the free encyclopedia
[Image: A step-by-step upload form with progress steps across the top and a file drop area]

The File Upload Wizard (Special:UploadWizard / 'Upload file' on Wikipedia) is the tool that guides editors through uploading images and other media files to Wikipedia and Wikimedia Commons, step by step.

The wizard walks the uploader through choosing the file, providing source and author information, selecting a licence, and adding a description — because freely licenced media is central to Wikipedia's model and non-free content is tightly restricted.

Steps

As remembered, the wizard's stages are: learn (a short guide to what can be uploaded), upload (select files), release rights (state who created the work and its licence), describe (titles, captions, categories), and use (get the wikitext to place the file in an article).

Where files go

Most uploads actually go to Wikimedia Commons so all Wikimedia projects can use them; Wikipedia-local uploads are mainly for certain non-free uses such as fair-use logos under strict criteria.
