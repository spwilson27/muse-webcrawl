Cryptographic nonce

In cryptography, a nonce is an arbitrary number that can be used just once in a cryptographic communication. The word is commonly explained as "number used once". Nonces are often random or pseudo-random values issued by a server in authentication protocols to prevent replay attacks, ensuring that old communications cannot be reused.

Uses

Nonces appear in HTTP Digest access authentication, where the server issues a nonce that the client incorporates into its hashed response; in transport-layer and challenge–response protocols; as initialisation vectors for stream ciphers and block cipher modes (where uniqueness under a given key is essential); and in proof-of-work systems such as Bitcoin mining, where miners vary a nonce field in the block header searching for a hash below a target.

Requirements

A nonce need not be secret, but it must never repeat within the context where it is used. Reuse of a nonce with the same key in some stream-cipher constructions catastrophically exposes plaintext, and repeated nonces in ECDSA signatures have historically leaked private keys.
