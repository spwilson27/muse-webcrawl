Union (computer science)

In computer science, a union is a value that may have any of several representations or formats within the same area of memory; that is, a data structure that can hold data of one of several types, but only one at a time. A program can treat the value as any of the types, although it is responsible for knowing which type it currently holds. Unions are supported in many programming languages, including C, C++, Pascal, and Rust, and contrast with records (structs), in which values of all members are stored simultaneously.

In C and C++

In C, a union is declared with the union keyword. All members share the same memory location, so the size of a union is the size of its largest member. Writing to one member and reading another reinterprets the stored bytes, a practice known as type punning:

union Value {
    int i;
    float f;
    char str[20];
};

Because only one member is valid at a time and the language does not track which one, programmers often combine a union with an enumerated "tag" in a surrounding struct, forming a tagged union (also called a variant or sum type). Since C11, C also supports anonymous unions. In C++, unions have additional rules: members with non-trivial constructors or destructors were historically prohibited, though restrictions were relaxed in C++11.

Uses

Unions are used to save memory when a value takes one of several mutually exclusive forms, to implement low-level views of the same data (for example, examining the bytes of a floating-point number), and in systems programming for hardware registers and protocol messages. Many modern languages provide safer sum types instead — such as Rust's enum or Haskell's algebraic data types — which check the active variant at compile or run time.
