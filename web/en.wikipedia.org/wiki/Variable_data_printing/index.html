Variable data printing

Variable data printing (VDP) is a form of digital printing, including on-demand printing, in which elements such as text, graphics and images may be changed from one printed piece to the next without stopping or slowing the press, using information from a database or external file. For example, a set of direct-mail letters can be printed with the same layout but a different name, address, offer or photograph on each copy. VDP is a core technology of one-to-one marketing and mass customisation of printed material.

Each piece in a VDP run can carry unique content.

How it works

A VDP job combines a static template with variable fields driven by records in a database, composed by software using standards and languages such as PPML, VPS, PDF/VT and (for transactional documents) AFP. The raster image processor (RIP) merges reusable elements — cached once — with per-record data at press speed. Applications range from simple mail merge and numbered tickets or invoices with unique barcodes, to fully personalised brochures in which text, images, prices and offers are selected by rules for each recipient.

Impact

Because personalised pieces generally achieve higher response rates than static mail, VDP became a major growth area for digital press manufacturers and print service providers, and a bridge between print and data-driven marketing workflows such as customer relationship management.
