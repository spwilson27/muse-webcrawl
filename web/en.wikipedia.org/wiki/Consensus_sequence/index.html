Consensus sequence

A sequence logo visualises the information content of a consensus sequence.

In molecular biology and bioinformatics, the consensus sequence (or canonical sequence) is the calculated sequence of the most frequent residues, either nucleotide or amino acid, found at each position in a sequence alignment. It represents the results of multiple sequence alignments in which related sequences are compared to each other and similar sequence motifs are calculated.

Consensus sequences are used to describe conserved functional elements such as promoters, binding sites and restriction enzyme recognition sites. Well-known examples include the TATA box of eukaryotic promoters, the Kozak consensus sequence governing translation initiation in vertebrates, and the Shine–Dalgarno sequence in bacterial mRNA. Nucleotide ambiguity codes (such as R for A/G or N for any base) are used when a position is variable.

Analysis

Software such as sequence logo generators summarises an alignment as a stack of letters whose heights reflect residue frequency and information content, providing a richer picture than a single consensus string. Position weight matrices generalise the consensus concept by scoring every possible residue at each position.
