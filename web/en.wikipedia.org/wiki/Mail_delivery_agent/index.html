Mail delivery agent

Mail delivery agent
Other namesLocal delivery agent (LDA)
TypeEmail software
Examplesprocmail, maildrop, Dovecot LMTP/LDA

A mail delivery agent (MDA), also called a local delivery agent (LDA), is a computer software component that is responsible for the delivery of e-mail messages to a local recipient's mailbox. Within the Internet mail architecture, local message delivery is achieved through a process of handling messages from the message transfer agent (MTA), and storing them into the recipient's environment, typically a mailbox.

Implementation

Many mail handling software products bundle multiple MDAs with the message transfer agent, while others provide a separate MDA program. MDAs may classify or filter messages before delivery, a process known as filtering. Well-known filtering MDAs include procmail and maildrop, which support rule-based sorting of incoming mail into folders, spam filtering hooks and automatic replies. Modern mail servers such as Dovecot combine delivery with the Local Mail Transfer Protocol (LMTP), in which the MTA hands messages to the delivery service over a socket or TCP connection rather than invoking a program.

Mailbox formats

The MDA writes messages into the user's mailbox, historically in the mbox format, in which all messages are appended to a single file, or the Maildir format, in which each message is a separate file in a directory structure. The choice of format affects locking, reliability and concurrent access by mail user agents (MUAs).
