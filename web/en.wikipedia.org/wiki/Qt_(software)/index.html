Qt (software)

Qt (pronounced "cute") is a free and open-source cross-platform software development framework for creating graphical user interfaces and applications that run on various software and hardware platforms. It is written in C++ and provides bindings for other languages, notably Python (PyQt and PySide). Qt is developed by the Qt Group and the Qt Project community, and is dual-licensed under commercial and open-source (GPL and LGPL) terms.

History

Qt was begun in 1991 by Haavard Nord and Eirik Chambe-Eng of the Norwegian company Trolltech. The first version was released in 1995; the KDE desktop environment adopted Qt as its toolkit, which prompted the creation of the rival GNOME project because of Qt's then-proprietary licence. Nokia acquired Trolltech in 2008 and later sold the commercial licensing business to Digia, which spun out the Qt Company (now the Qt Group). Major releases include Qt 4 (2005), Qt 5 (2012), and Qt 6 (2020), the latter modernising the graphics stack and build tooling around CMake.

Features

  • Signals and slots — a type-safe mechanism for communication between objects, implemented by a meta-object compiler (moc).
  • Qt Widgets — a mature set of traditional desktop user-interface controls.
  • Qt Quick and QML — a declarative language and runtime for fluid, touch-friendly interfaces, with JavaScript for logic.
  • Cross-platform abstraction — a single codebase targeting Windows, macOS, Linux, Android, iOS and embedded systems.
  • Extensive libraries — modules for networking, SQL databases, XML, multimedia, 3D graphics, Bluetooth and positioning.

Applications

Well-known software built with Qt includes the KDE Plasma desktop, VLC media player, VirtualBox, the Autodesk and Adobe toolsets, and many automotive and industrial interfaces. Qt Creator is the framework's official integrated development environment. See also GUI widget toolkit and KDE.
