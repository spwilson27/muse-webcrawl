Remote direct memory access

Remote direct memory access (RDMA) is a direct memory access from the memory of one computer into that of another without involving either one's operating system. This permits high-throughput, low-latency networking, especially useful in massively parallel computer clusters and data centres, because the transfer bypasses the CPU, caches and context switching of the traditional network stack.

How it works

RDMA-capable network adapters (RNICs) perform zero-copy transfers: data moves directly between application memory buffers on two machines, with the adapter handling protocol processing in hardware. Applications register memory regions, exchange keys, and then post one-sided read and write operations or two-sided send/receive operations to hardware queues.

Implementations

The principal implementations are InfiniBand, designed with native RDMA support; RoCE (RDMA over Converged Ethernet), which runs the InfiniBand transport over Ethernet; and iWARP, which implements RDMA over TCP/IP. RDMA underpins high-performance computing interconnects, distributed storage, and the training networks of large AI clusters.
