Semidefinite programming

Semidefinite programming (SDP) is a subfield of convex optimization concerned with optimizing a linear objective function over the cone of positive semidefinite matrices, subject to linear equality constraints. It generalizes linear programming — whose feasible sets are polyhedra — to spectrahedra, and many problems in control theory, combinatorial optimization, and quantum information are formulated most naturally as SDPs.

The feasible set of an SDP is a spectrahedron.

Formulation

A standard-form SDP optimizes over a symmetric matrix variable X:

minimize ⟨C, X⟩ subject to ⟨Aᵢ, X⟩ = bᵢ (i = 1…m), X ⪰ 0,

where X ⪰ 0 means X is positive semidefinite. Equivalently, variables may appear as a vector x whose linear matrix inequality F₀ + x₁F₁ + … + xₙFₙ ⪰ 0 must hold. SDP has a well-developed duality theory similar to that of linear programming, with a zero duality gap under constraint qualifications such as Slater's condition.

Algorithms

SDPs can be solved in polynomial time to arbitrary precision by interior-point methods, which dominated the field from the 1990s work of Nesterov and Nemirovski and of Alizadeh. Practical solvers include SeDuMi, SDPT3, MOSEK, and SCS; for very large or low-rank problems, first-order and specialized algorithms are used. Determining whether an SDP is feasible to high accuracy has subtle complexity status — it lies between P and PSPACE-related classes, related to the existential theory of the reals.

Applications

  • Control theory: linear matrix inequalities for stability and H∞ control (the original motivation).
  • Combinatorial optimization: the celebrated Goemans–Williamson SDP relaxation gives a 0.878-approximation for Max-Cut, and SDP hierarchies (Lasserre/sum-of-squares) approximate polynomial optimization problems.
  • Quantum information: entanglement detection, quantum channel capacities, and Bell inequality bounds (the NPA hierarchy).
  • Statistics and geometry: matrix completion, phase retrieval, sensor network localization, and structural design.
