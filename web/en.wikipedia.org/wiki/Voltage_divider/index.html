Voltage divider
TypePassive linear circuit
ComponentsTwo (or more) impedances in series

A voltage divider (also known as a potential divider) is a passive linear circuit that produces an output voltage that is a fraction of its input voltage. Voltage division results from distributing the input voltage among components connected in series, most commonly two resistors.

Resistive divider

For two resistors R1 and R2 in series across an input voltage Vin, with the output taken across R2:

Vout = Vin · R2 / (R1 + R2)

This follows from Ohm's law: the same current flows through both resistors, so the voltage across each is proportional to its resistance.

Loading and applications

The simple formula assumes the output draws negligible current. If a load is connected, its resistance appears in parallel with R2 and lowers the output ("loading effect"), so divider impedances are chosen much lower than the load where accuracy matters. Voltage dividers are used to scale signals for analogue-to-digital converters, set bias points in transistor circuits, adapt logic levels, and read resistive sensors such as thermistors and photoresistors. A potentiometer is a three-terminal adjustable divider; capacitive and inductive dividers perform the same function for AC signals.
