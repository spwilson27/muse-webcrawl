Walk-off home run

In baseball, a walk-off home run is a home run hit by the home team in the bottom of the ninth inning, or in the bottom of an extra inning, that gives the home team the lead and thereby ends the game. The term derives from the fact that the visiting team must "walk off" the field after the winning run crosses the plate.

Because the game ends as soon as the winning run scores, a walk-off home run is usually scored such that the batter is credited with only as many runs batted in as are needed to win, unless the ball leaves the park — in which case all runs, including the batter's, count. The phrase "walk-off" was popularised in the 1990s and attributed to reliever Dennis Eckersley's description of a pitch he had to watch end a game.

Famous examples

Among the most celebrated walk-off home runs in Major League Baseball history are Bobby Thomson's "Shot Heard 'Round the World", which won the 1951 National League pennant for the New York Giants; Bill Mazeroski's home run in Game 7 of the 1960 World Series, still the only walk-off homer in a World Series Game 7; Kirk Gibson's pinch-hit home run in Game 1 of the 1988 World Series; and Joe Carter's home run that ended the 1993 World Series for the Toronto Blue Jays.
