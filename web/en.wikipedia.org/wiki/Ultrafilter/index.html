Ultrafilter

In the mathematical field of order theory, an ultrafilter on a partially ordered set (or "poset") P is a maximal filter on P; that is, a filter on P that cannot be enlarged to a strictly larger filter. When P is the power set of a set, ordered by inclusion, ultrafilters have a particularly rich theory and widespread applications in set theory, model theory, topology, and measure theory.

Ultrafilters on a set X can be viewed as finitely additive (0,1)-valued measures defined on all subsets of X, or equivalently as homomorphisms from the Boolean algebra of subsets of X to the two-element Boolean algebra. The existence of non-principal ultrafilters on infinite sets is a consequence of the Boolean prime ideal theorem, a weak form of the axiom of choice.

Definition

A filter on a set X is a non-empty family F of subsets of X such that:

  • the empty set is not in F;
  • F is closed under finite intersections: if A, B ∈ F then A ∩ B ∈ F;
  • F is upward closed: if A ∈ F and A ⊆ B, then B ∈ F.

An ultrafilter is a filter U on X that is maximal with respect to inclusion among filters. Equivalently, U is an ultrafilter if and only if for every subset A ⊆ X, either A ∈ U or its complement X \ A ∈ U (and not both). This dichotomy property is the source of most applications: an ultrafilter "decides" every subset of X.

Types of ultrafilter

Principal ultrafilters

For any point x ∈ X, the collection of all subsets of X containing x is an ultrafilter, called the principal ultrafilter at x. Principal ultrafilters behave like the point itself and are generally regarded as trivial. On a finite set, every ultrafilter is principal.

Free (non-principal) ultrafilters

An ultrafilter is free or non-principal if it is not principal, equivalently if it contains the Fréchet filter of cofinite sets, equivalently if it contains no finite set. Free ultrafilters exist on every infinite set, but — unlike principal ultrafilters — no free ultrafilter on the natural numbers can be exhibited explicitly; their existence proof requires a choice principle. The set of all ultrafilters on X is denoted βX in topology, where it forms the Stone–Čech compactification of a discrete space.

Ultrafilter lemma

The ultrafilter lemma states that every filter on a set can be extended to an ultrafilter. It follows from Zorn's lemma and is equivalent to the Boolean prime ideal theorem, which is strictly weaker than the full axiom of choice but cannot be proved in Zermelo–Fraenkel set theory alone.

Applications

Logic and model theory

The ultraproduct construction, built using an ultrafilter, underlies Łoś's theorem in model theory and provides a rigorous construction of the hyperreal numbers used in nonstandard analysis: one takes the ultrapower of the real numbers modulo a free ultrafilter on the natural numbers.

Topology

Ultrafilters give an elegant characterisation of compactness: a topological space is compact if and only if every ultrafilter on it converges to at least one point, and it is Hausdorff if and only if every ultrafilter converges to at most one point. The set of ultrafilters on a Boolean algebra, with a suitable topology, is its Stone space, central to Stone duality.

Measure theory and combinatorics

A free ultrafilter on the natural numbers yields a finitely additive probability measure on all subsets of the naturals that vanishes on finite sets. In combinatorics, ultrafilters appear in proofs of results such as Hindman's theorem, via the algebraic structure of βℕ as a compact right-topological semigroup, and in the theory of social choice, where ultrafilters characterise possible "decisive" coalition structures.
