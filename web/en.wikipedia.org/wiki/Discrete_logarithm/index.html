Discrete logarithm

From Wikipedia, the free encyclopedia

In mathematics, for given real numbers a and b, the logarithm logb a is a number x such that bx = a. Analogously, in any group G, powers bk can be defined for all integers k, and the discrete logarithm logb a is an integer k such that bk = a. In number theory, the more commonly used term is index. The problem of computing discrete logarithms in carefully chosen groups is believed to be computationally hard, and this hardness underpins several public-key cryptosystems.

Definition and example

Let G be a finite cyclic group of order n with generator b. For any element a of G there is a unique integer k in {0, …, n−1} with:

bk ≡ a

and k is the discrete logarithm of a to the base b. For example, in the multiplicative group modulo 17, 3 is a generator: 35 = 243 ≡ 5 (mod 17), so log3 5 = 5 in this group.

Algorithms

No efficient classical algorithm is known for the general discrete logarithm problem. Known methods include trial multiplication, the baby-step giant-step algorithm (a time–memory trade-off running in O(√n)), Pollard's rho algorithm, the Pohlig–Hellman algorithm (effective when the group order is smooth), and the index calculus family, including the number field sieve, which achieves subexponential time for finite fields. Shor's algorithm solves the problem in polynomial time on a quantum computer.

Cryptography

The assumed difficulty of the discrete logarithm problem is the basis of the Diffie–Hellman key exchange, the ElGamal encryption system, the Digital Signature Algorithm (DSA), and elliptic-curve cryptography, where the analogous problem is posed in groups of points on elliptic curves.
