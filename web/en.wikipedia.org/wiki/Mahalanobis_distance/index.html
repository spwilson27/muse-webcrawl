Mahalanobis distance

Introduced byPrasanta Chandra Mahalanobis
Year1936
FieldStatistics, multivariate analysis

The Mahalanobis distance is a measure of the distance between a point and a distribution, introduced by the Indian statistician Prasanta Chandra Mahalanobis in 1936. Unlike the Euclidean distance, it accounts for the correlations between variables and is scale-invariant, because it measures distance in units of standard deviation along each principal axis of the distribution.

Definition

For a point x and a distribution with mean μ and covariance matrix S, the Mahalanobis distance is d(x) = √((x − μ)ᵀ S⁻¹ (x − μ)). The distance between two points uses the same covariance matrix. If the covariance matrix is the identity matrix, the measure reduces to the standard Euclidean distance; if it is diagonal but not identity, the result is the normalised Euclidean distance.

Applications

The Mahalanobis distance is widely used in cluster analysis and classification, including linear discriminant analysis, and for detecting outliers in multivariate data: points with unusually large distances from a cluster centre are flagged as anomalous. Squared Mahalanobis distances for normally distributed data follow a chi-square distribution, which provides a statistical test for outliers. In computer vision, the measure has been used for face recognition and texture analysis.
