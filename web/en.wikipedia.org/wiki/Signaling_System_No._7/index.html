Signaling System No. 7

Signaling System No. 7 (SS7) is a set of telephony signalling protocols developed by the ITU-T from 1975 onwards and standardised in the Q.700 series of recommendations. It provides out-of-band signalling for the public switched telephone network (PSTN) and mobile networks: setting up and tearing down calls, routing, number translation, billing, and supporting services such as caller ID, call forwarding, roaming and SMS. In North America the closely related variant is often called CCS7 (Common Channel Signaling 7). SS7 remains the backbone signalling system of the world's telephone networks, though it is gradually being displaced in mobile cores by Diameter (4G) and HTTP/2-based signalling (5G).

Architecture

SS7 separates the signalling path from the voice path. Telephone switches acting as Service Switching Points (SSPs) originate and terminate signalling messages; Signal Transfer Points (STPs) route messages through the network in redundant pairs; and Service Control Points (SCPs) are databases queried for services such as freephone (800-number) translation, calling-card validation and local number portability. Links between nodes traditionally run at 56 or 64 kbit/s; the SIGTRAN protocols carry SS7 over IP networks.

Protocol stack

The lower layers are the Message Transfer Part (MTP levels 1–3), which ensures reliable message delivery, and the Signaling Connection Control Part (SCCP), which adds global-title addressing and connectionless/connection-oriented services. Above these, TCAP supports database transactions, and application parts include ISUP (ISDN User Part) for call control, MAP (Mobile Application Part) for GSM/UMTS mobility management, roaming and SMS, and INAP/CAP for intelligent-network services such as prepaid charging.

Security issues

SS7 was designed for a small club of trusted national carriers and incorporates essentially no authentication: any node able to inject messages is trusted by the rest. As access widened through leased global titles and IP interconnection, researchers publicly demonstrated from 2008 onwards — and dramatically in 2014 — attacks enabling interception of calls and texts, location tracking of subscribers, and fraud. Criminal exploitation has been documented, including the redirection of SMS-based banking codes. Mitigations include SS7 firewalls and message screening at network borders, and migration to newer protocols, but the system's openness remains a widely discussed vulnerability so long as 2G/3G interconnection persists.
