Reed–Muller code

Reed–Muller codes are error-correcting codes used in wireless communications and deep-space transmission. They are among the oldest and simplest families of codes, named after David E. Reed and Irving S. Reed, and David E. Muller, who proposed the code in 1954; Reed proposed the majority-logic decoding algorithm the same year.

Construction

The Reed–Muller code RM(r, m) is defined by two parameters: an order r and a number of variables m. Codewords correspond to Boolean functions in m variables of degree at most r, evaluated at all 2m points of the Boolean cube. The code has length n = 2m, dimension equal to the sum of binomial coefficients C(m,0) + C(m,1) + ... + C(m,r), and minimum distance 2m−r. Thus RM(0, m) is a repetition code, RM(1, m) gives first-order codes related to Hadamard codes, and RM(m−2, m) gives extended Hamming codes.

Decoding

Reed's majority logic decoder recovers each coefficient of the encoding polynomial by taking majority votes over carefully chosen sets of received bits, allowing correction of up to half the minimum distance of errors. Recursive (Plotkin) decompositions of Reed–Muller codes underlie modern decoding techniques, and polar codes are constructed from the same recursive structure.

Applications

Reed–Muller codes were famously used by NASA's Mariner spacecraft: Mariner 9 (1971) used a first-order RM(1, 5) code — a (32, 6) biorthogonal code — to transmit photographs of Mars. The family remains central to coding theory and has attracted renewed interest with results showing that Reed–Muller codes achieve capacity on binary erasure and, later, general binary memoryless symmetric channels.
