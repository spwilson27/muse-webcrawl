Compiz

Compiz is a compositing window manager for the X Window System, created in 2006 by David Reveman at Novell and released as free and open-source software. It uses 3D graphics hardware to produce fast compositing desktop effects, such as a rotating cube workspace switcher, wobbling windows and live window previews, and was one of the earliest compositing window managers for X.

History

Compiz debuted alongside Novell's Xgl display server in early 2006 and quickly attracted attention for bringing hardware-accelerated desktop effects to Linux. Later that year a community fork, Beryl, split off over development disagreements; the projects re-merged in 2007, with the effects package becoming Compiz Fusion. Ubuntu adopted Compiz by default in 2007 and later built its Unity desktop environment as a Compiz plugin, shipping it from 2011 until Unity was discontinued in 2017. Development continues in the community-maintained Compiz 0.9 series ("Compiz Reloaded" maintains the 0.8 branch).

Features

Compiz is built around a plugin architecture: features such as the Desktop Cube, Expo workspace overview, window animations, window decoration, switchers, zoom and accessibility tools are individual plugins configured through the CompizConfig Settings Manager (CCSM). Compositing also enables features such as live thumbnails in task switchers and true window translucency. While influential, Compiz-era X11 compositing has largely been superseded on Linux by Wayland compositors, which integrate compositing directly into the display server.
