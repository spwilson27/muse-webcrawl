OPML

OPML (Outline Processor Markup Language) is an XML format for outlines, defined as "an outline with hierarchically nested elements each having an arbitrary set of attributes". It was developed by Dave Winer and Radio UserLand, growing out of the outliner software tradition, with the OPML 1.0 specification released in 2000 and version 2.0 in 2007.

Structure

An OPML document has an <opml> root element containing a <head> with metadata (such as title and dates) and a <body> containing nested <outline> elements. Each outline element typically has a text attribute and may carry arbitrary additional attributes, which applications use for their own purposes.

<outline text="News" type="folder">
  <outline text="Example Blog" type="rss"
    xmlUrl="https://example.com/feed.xml"/>
</outline>

Uses

Although designed as a general-purpose format for outliners and list exchange, OPML became best known for exchanging lists of RSS and Atom feed subscriptions between feed readers: exporting an OPML file lets users move their entire subscription list from one reader to another, and blogrolls were often published as OPML. It has also been used for podcast directories, presentation outlines and other hierarchical lists.
