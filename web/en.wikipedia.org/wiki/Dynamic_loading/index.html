Dynamic loading

Dynamic loading is a mechanism by which a computer program can, at run time, load a library (or other binary) into memory, retrieve the addresses of functions and variables contained in the library, execute those functions or access those variables, and unload the library from memory. It is one of the four mechanisms for using a library, alongside static linking, dynamic linking, and late binding.

Mechanism

Unlike dynamic linking, where libraries are loaded automatically when the program starts, dynamic loading lets the program decide if and when to load a library, making it the basis of plug-in architectures. Failure to load the library can be handled by the program itself.

Interfaces

On Unix-like systems, the dlopen, dlsym, dladdr, dlvsym, and dlclose functions in <dlfcn.h> provide the API. On Windows, the corresponding functions are LoadLibrary, GetProcAddress, and FreeLibrary. Java uses class loaders and Class.forName, and .NET provides reflection-based assembly loading.
