Percent-encoding

Percent-encoding, also known as URL encoding, is a mechanism for encoding information in a Uniform Resource Identifier (URI) under certain circumstances. Although it is known as URL encoding, it also applies more generally to the full URI character set, including both Uniform Resource Locators (URLs) and Uniform Resource Names (URNs).

Characters outside an allowable set are encoded using a triplet of the form %XY, where X and Y are two hexadecimal digits representing the eight bits of the character's value. For example, a space character may be encoded as %20, and the character / may be encoded as %2F.

The URI character set

The characters allowed in a URI are either reserved or unreserved, or a percent sign as part of a percent-encoding. Reserved characters are those that may have special significance within a URI. Unreserved characters, by contrast, have no special meaning and should not be encoded.

Encoding of specific characters

When a character from the reserved set has special meaning in a particular context, and a URI scheme says it must be used for some other purpose, the character must be percent-encoded. For instance, if a URL path segment contains data in which a slash has no path-delimiting role, it is written as %2F.

Arbitrary binary data may also be encoded this way; for example, UTF-8 text is commonly percent-encoded byte by byte, so the character "é" becomes %C3%A9.

Application/x-www-form-urlencoded

When data that has been entered into HTML forms is submitted, the form field names and values are encoded and sent to the server in an HTTP request message using the URL encoding scheme, with a plus sign (+) permitted as a substitute for a space. This content type is called application/x-www-form-urlencoded.
