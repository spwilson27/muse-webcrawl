Numerical analysis

From Wikipedia, the free encyclopedia
[Image: A graph showing a function approximated by a numerical method]

Numerical analysis is the study of algorithms that use numerical approximation for the problems of mathematical analysis — as distinguished from discrete mathematics. It asks how to compute solutions to continuous problems accurately, efficiently, and stably on a (finite-precision) computer.

Core topics include solving equations (Newton's method, bisection), interpolation and approximation, numerical integration and differentiation, solving linear systems and eigenvalue problems, and numerical methods for differential equations.

Error and stability

Numerical errors arise from rounding (floating-point arithmetic), truncation, and discretisation. An algorithm is stable if small perturbations do not blow up; the condition number of a problem measures its intrinsic sensitivity. Backward-error analysis, associated with James Wilkinson, is a standard framework for judging algorithms.

Much of pre-computer mathematics was numerical — Babylonian approximations of square roots, Newton's and Gauss's methods — but the field crystallised with electronic computers after the Second World War.

Applications

Numerical methods underlie weather forecasting, structural engineering (finite element method), fluid dynamics simulations, optimisation, and machine learning. Standard software includes LAPACK and the libraries behind MATLAB, NumPy and similar tools.
