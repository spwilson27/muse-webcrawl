Sonic Pi is a live coding environment based on the Ruby programming language, originally designed to support both computing and music lessons within schools. It was developed by Sam Aaron at the University of Cambridge Computer Laboratory, initially in collaboration with the Raspberry Pi Foundation.

History

Sonic Pi began in 2012 as a project to teach programming concepts through music on the inexpensive Raspberry Pi computer. Because of its low hardware requirements it spread widely in education, and it later developed into a performance tool used by live coders and algorave musicians around the world. The project is free and open-source software, funded in part through community patronage.

Features

Users write Ruby code that triggers samples and synthesised sounds in real time. Core features include:

• live_loop constructs that run musical patterns in synchronised threads
• A large library of built-in samples and software synthesisers
• Effects such as reverb, echo, and filters applied with with_fx blocks
• Precise timing control and support for MIDI and OSC messages
• Built-in tutorials aimed at beginners with no musical or programming background

live_loop :beat do
  sample :bd_haus
  sleep 0.5
end

Use in education and performance

Sonic Pi is used in classrooms to introduce computational thinking, and it is a prominent instrument in the algorave and live coding scenes, where performers write and modify code on stage to generate music in front of an audience.
