Comparison of file archivers

From Wikipedia, the free encyclopedia

A file archiver is a program that combines files into an archive, usually with data compression, for storage or transfer. This article compares notable archivers by platform, licence, and the archive formats they can create and extract.

Archive formats

The most widespread format is ZIP, supported natively by major operating systems. The 7z format generally achieves higher compression ratios using LZMA/LZMA2, while RAR offers strong compression and recovery records. On Unix systems, uncompressed tar archives combined with a compression program (producing .tar.gz, .tar.xz, .tar.zst and similar) remain the convention. Archivers differ in features such as encryption (AES-256 in ZIP extensions, 7z and RAR), solid compression, multi-volume splitting, recovery data, and preservation of file-system metadata such as permissions, timestamps and extended attributes.

Comparison criteria

Comparisons typically consider: formats readable and writable; compression ratio and speed on standard corpora; encryption and integrity checking; Unicode filename handling; and licensing for redistribution. No single tool leads on all criteria, which is why several formats coexist.
