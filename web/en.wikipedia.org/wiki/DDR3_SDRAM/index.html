DDR3 SDRAM

A 240-pin DDR3 DIMM for desktop computers.

Double Data Rate 3 Synchronous Dynamic Random-Access Memory (DDR3 SDRAM) is a type of synchronous dynamic random-access memory (SDRAM) with a high-bandwidth ("double data rate") interface, and has been in use since 2007. It is the third generation of DDR memory, succeeding DDR2 SDRAM and preceding DDR4 SDRAM, which replaced it from 2014 onwards.

Overview

DDR3 achieves higher transfer rates than DDR2 chiefly by using an 8n-prefetch architecture — an internal data bus eight times the width of the external bus — allowing the interface clock to run faster without the memory core itself speeding up proportionally. Standard DDR3 modules operate at a supply voltage of 1.5 V (with low-voltage DDR3L variants at 1.35 V), compared with 1.8 V for DDR2, reducing power consumption. Specified data rates run from DDR3-800 to DDR3-2133, i.e. 800 to 2133 million transfers per second.

Modules

DDR3 memory for desktops is supplied on 240-pin DIMMs; laptop memory uses 204-pin SO-DIMMs. Although the pin count matches DDR2 DIMMs, the keying notch is in a different position, so the generations are not interchangeable. DDR3 modules may carry an SPD EEPROM describing their timings, and registered (buffered) variants are used in servers.

History

The JEDEC standard for DDR3 was published in 2007, and Intel's P35 chipset and AMD's Socket AM2+ platforms were among the first to support it. DDR3 became the mainstream PC memory technology around 2009–2010 and was succeeded in the mainstream by DDR4 after its 2014 launch, though it remained in production for older and embedded systems.
