Mathematica is a software system with built-in libraries for many areas of technical computing, developed by Wolfram Research. It was conceived by Stephen Wolfram and first released in 1988. The software allows mathematical computation, symbolic manipulation, numerical calculation, visualisation, and programming, all integrated within an interactive notebook interface.

Features

Mathematica's core is the Wolfram Language, a symbolic programming language in which everything — numbers, formulas, graphics, documents, and code — is represented as symbolic expressions. The system includes thousands of built-in functions covering calculus, linear algebra, statistics, differential equations, graph theory, image processing, machine learning, and access to curated real-world data through Wolfram Knowledgebase. The notebook interface combines input, formatted output, graphics, and text in a single document.

Development and use

Mathematica is widely used in science, engineering, mathematics, finance, and education. Stephen Wolfram's 2002 book A New Kind of Science was written using Mathematica explorations of cellular automata. The technology also underlies the computational knowledge engine WolframAlpha, launched in 2009. Mathematica is proprietary commercial software, though a free Wolfram Engine for developers and limited free access through Wolfram Cloud are available.
