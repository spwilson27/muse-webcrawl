Cantor's diagonal argument

Cantor's diagonal argument is a mathematical proof published by Georg Cantor in 1891 demonstrating that there are infinite sets which are not in one-to-one correspondence with the set of natural numbers — in particular, that the real numbers are uncountable.

The argument

Suppose, for contradiction, that the real numbers between 0 and 1 could be listed in a sequence r1, r2, r3, …, each written as an infinite decimal expansion. Construct a new number whose n-th decimal digit differs from the n-th digit of rn — for instance, change it to a different digit, avoiding 0 and 9 to sidestep dual decimal representations. This new number lies between 0 and 1 but differs from every number in the list in at least one decimal place, so it is not in the list: contradiction. Hence no such listing exists.

Consequences

The argument shows the cardinality of the real numbers is strictly greater than that of the natural numbers, and generalises to Cantor's theorem: the power set of any set has strictly greater cardinality than the set itself. Diagonalisation has been adapted widely, including in proofs of the undecidability of the halting problem and Gödel's incompleteness theorems.
