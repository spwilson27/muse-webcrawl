Nginx

From Wikipedia, the free encyclopedia
Nginx
Released4 October 2004
AuthorIgor Sysoev
TypeWeb server, reverse proxy, load balancer
[Image: The Nginx wordmark in green capital letters]

Nginx (pronounced 'engine x') is a web server that can also be used as a reverse proxy, load balancer, mail proxy and HTTP cache. The software was created by Russian developer Igor Sysoev and publicly released in 2004.

Sysoev designed Nginx to solve the C10K problem — serving ten thousand simultaneous connections — which the process-per-connection model of the Apache HTTP Server handled poorly. Nginx's event-driven, asynchronous architecture uses a small, fixed number of worker processes and handles each connection cheaply, giving it a reputation for speed and low memory use under heavy load. It became the server of choice for many of the world's busiest sites and, by common surveys, overtook Apache in the 2020s as the most widely used web server.

Beyond serving static files, Nginx is typically deployed in front of application servers as a reverse proxy and load balancer, terminating TLS and distributing requests — a role that made it core infrastructure of the cloud era. The company behind it, NGINX Inc., was acquired by F5 Networks in 2019 for a reported $670 million.
