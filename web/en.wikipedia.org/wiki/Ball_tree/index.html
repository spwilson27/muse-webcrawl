Ball tree

A ball tree is a binary tree data structure used in computer science to organise points in a multi-dimensional space. Each internal node defines a hypersphere (an n-ball) containing a subset of the points; the root sphere contains all points, and children partition their parent's points into two smaller spheres. Ball trees are a type of metric tree.

Construction

A common construction picks the point farthest from the node's centroid, then the point farthest from that, and assigns each point to the nearer of these two pivots, recursively splitting until leaves hold a small number of points. Other heuristics split along the dimension of greatest spread. Construction costs roughly O(n log n) comparisons for typical data.

Applications

Ball trees accelerate nearest-neighbour search: a query can prune whole subtrees whose bounding spheres cannot contain a closer point than the best found so far, using the triangle inequality. They are used in machine learning libraries such as scikit-learn for k-nearest neighbours classification, kernel density estimation, and clustering, and are often preferred over k-d trees for high-dimensional or non-Euclidean metric data, though performance degrades with the curse of dimensionality.

History

The structure was described in a 1989 technical report by Stephen Omohundro as part of work on learning algorithms. Variants include the vantage-point tree and M-tree.
