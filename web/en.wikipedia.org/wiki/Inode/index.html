Inode

An inode (index node) is a data structure in a Unix-style file system that describes a file-system object such as a file or a directory. Each inode stores the attributes and disk block location(s) of the object's data. Every object is identified by an inode number within its file system.

Details

An inode typically contains metadata including file type and permissions, owner and group identifiers, size, timestamps (access, modification, and inode change times), a link count, and pointers to the data blocks. In classic designs, inodes hold direct block pointers plus single, double, and triple indirect pointers for large files; modern file systems such as ext4 may use extents instead.

Names and directories

File names are not stored in the inode itself but in directory entries that map names to inode numbers. This separation allows multiple directory entries—hard links—to refer to the same inode. The inode number of a file can be displayed with the ls -i command and with stat.

Implications

Because the number of inodes is fixed when a traditional file system is created, a volume can run out of inodes—preventing new file creation—even when disk space remains free. File systems such as XFS and Btrfs allocate inodes dynamically.
