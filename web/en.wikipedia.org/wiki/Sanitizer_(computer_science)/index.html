Sanitizer (computer science)

In computer science, a sanitizer is a programming tool that detects bugs in program code, typically at run time, by instrumenting the program and checking its behaviour against correctness criteria. Sanitizers are widely used in testing and fuzzing workflows, especially for languages such as C and C++ that lack memory safety.

An AddressSanitizer report identifying a heap buffer overflow

Types

Well-known sanitizers, largely developed at Google and integrated into LLVM/Clang and GCC, include:

AddressSanitizer (ASan) detects memory errors such as buffer overflows and use-after-free by surrounding allocations with poisoned "redzone" memory and shadowing checks. MemorySanitizer (MSan) detects reads of uninitialized memory. ThreadSanitizer (TSan) detects data races between threads. UndefinedBehaviorSanitizer (UBSan) detects signed integer overflow, invalid shifts, misaligned accesses, and other undefined behaviour. LeakSanitizer (LSan) detects memory leaks.

Usage

Sanitizers are enabled with compiler flags (for example, -fsanitize=address) and trade execution speed and memory usage for detailed diagnostic reports. They are standard components of continuous-fuzzing infrastructure such as OSS-Fuzz, and have been credited with finding tens of thousands of bugs — many of them security vulnerabilities — in major open-source projects.
