Silicon photomultiplier

A silicon photomultiplier, often abbreviated SiPM, is a solid-state single-photon-sensitive device built from an array of single-photon avalanche diode (SPAD) pixels on a common silicon substrate. Each pixel is operated in Geiger mode, above its breakdown voltage, so that a single absorbed photon triggers a self-sustaining avalanche discharge producing a standardised output pulse. The sum of the pulses from all fired pixels is proportional to the number of photons detected, giving the device photomultiplier-like gain (typically 105–106) in a compact, rugged, low-voltage package.

Operation

Each SPAD pixel is connected to the common output through its own quenching resistor, which limits the avalanche current and resets the pixel after a dead time of tens of nanoseconds. SiPMs typically operate at bias voltages of roughly 25–70 V, far below the kilovolt supplies required by vacuum photomultiplier tubes. They are insensitive to magnetic fields and can be manufactured with CMOS-compatible processes.

Characteristics

Key parameters include photon detection efficiency (which can exceed 50% at peak wavelengths), dark count rate (thermally generated pulses that increase with temperature), optical crosstalk between neighbouring pixels, afterpulsing, gain uniformity, and timing resolution, which can reach below 100 picoseconds for single photons.

Applications

SiPMs are widely used in positron emission tomography (PET) and other medical imaging, high-energy and nuclear physics experiments, LiDAR, fluorescence measurement, and automotive and consumer sensing.
