Linker (computing)

In computing, a linker or link editor is a computer system program that takes one or more object files (generated by a compiler or an assembler) and combines them into a single executable file, library file, or another "object" file. A simpler version that writes its output directly to memory is called the loader, though loading is typically considered a separate process.

The linker combines object files and libraries into one executable.

Overview

Computer programs typically comprise several parts or modules; all of these parts need not be contained within a single object file, and in such case, they refer to each other by means of symbols. Typically, an object file can contain three kinds of symbols: defined ("exported") symbols, undefined ("imported") symbols that call for definitions in other modules, and local symbols used internally. When a program comprises multiple object files, the linker combines these files into a unified executable program, resolving the symbolic references along the way—a process called relocation, which involves assigning final addresses to code and data segments.

Static and dynamic linking

In static linking, all library routines used in the program are copied into the final executable at link time, producing a self-contained but larger file. In dynamic linking, references to shared libraries are resolved at load time or run time by a dynamic linker, producing smaller executables and allowing library updates to benefit all programs that use them, at the cost of a dependency on the library being present.

Notable linkers

Examples include the GNU linker ld and its faster successors GNU gold and LLD from the LLVM project, the Microsoft link editor link.exe, and ld64 on Apple platforms.
