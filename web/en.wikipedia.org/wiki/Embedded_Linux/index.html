Embedded Linux

Embedded Linux is the use of the Linux kernel and various open-source components in embedded systems, such as consumer electronics, industrial controllers, networking equipment, and medical devices. Advantages of Linux for embedded systems include the absence of royalty fees, a mature and stable kernel, support for many processor architectures, and access to a large pool of device drivers and software.

Characteristics

Embedded Linux systems are often tailored to run on resource-constrained hardware, using lightweight C libraries such as musl or uClibc, small user-space toolkits like BusyBox, and customized kernels built with build systems such as the Yocto Project or Buildroot.

Applications

Linux powers most home routers, smart televisions, and many automotive infotainment systems. Android, which uses the Linux kernel, dominates the smartphone market. Linux also runs in industrial control systems, point-of-sale terminals, and network-attached storage devices.
