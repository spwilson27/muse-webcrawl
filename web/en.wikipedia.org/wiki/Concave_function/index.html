Concave function

In mathematics, a concave function is the negative of a convex function. A function f is concave over an interval if, for every pair of points x and y in the interval and every t in [0, 1], f(tx + (1−t)y) ≥ t f(x) + (1−t) f(y). Intuitively, the line segment between any two points of the graph lies on or below the graph itself.

Properties

A twice-differentiable function is concave if and only if its second derivative is non-positive on its domain. Concave functions have decreasing marginal returns, a property exploited in economics for utility and production functions. A function that is both concave and convex must be affine. Local maxima of concave functions are also global maxima. Jensen's inequality takes a corresponding reversed form for concave functions.

Examples

Examples include the logarithm log x, the square root √x, and power functions xα for 0 < α < 1 on the positive reals, as well as sin x on [0, π].
