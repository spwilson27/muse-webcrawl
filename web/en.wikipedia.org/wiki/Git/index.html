Git

Original author: Linus Torvalds

Initial release: April 7, 2005

Written in: C, shell script, Perl, Tcl

Type: Distributed version control system

License: GNU GPL v2

Git is a distributed version control system that tracks versions of files, generally used for coordinating work among programmers who are collaboratively developing source code during software development. Its goals include speed, data integrity, and support for distributed, non-linear workflows. Git is the most widely used version control system in the world, underlying hosting services such as GitHub, GitLab, and Bitbucket.

History

Development of Git began in April 2005, after the Linux kernel community's licence to use the proprietary BitKeeper system was revoked. Linus Torvalds, the creator of Linux, wrote the initial version in about ten days, modelling it on his experience maintaining the kernel. Torvalds named it "git" (British slang for an unpleasant person), joking that he named projects after himself. Junio Hamano became the project's principal maintainer in July 2005 and has overseen releases ever since.

Design

Git is a distributed system: every working copy of a repository contains the full history, so most operations are local and fast. Rather than storing file differences, Git conceptually stores snapshots of a miniature filesystem; files that have not changed are stored only once. Objects (blobs, trees, commits, and tags) are identified by SHA-1 (and increasingly SHA-256) hashes, which guarantee integrity — corruption or tampering changes the object's identifier. Branching and merging are lightweight and central to the Git workflow, in contrast to earlier centralised systems such as CVS and Subversion.

Characteristics

Git's data model makes operations like committing, branching, and history rewriting extremely fast even for very large projects — the Linux kernel repository contains millions of commits. Its staging area (index) lets users assemble commits from selected changes. Critics note a steep learning curve and terminology that can confuse beginners, though a large ecosystem of graphical clients and documentation mitigates this.

Adoption

Git surpassed Subversion in use by the early 2010s and is used by the overwhelming majority of professional developers. Microsoft migrated Windows development to Git in 2017, creating one of the largest repositories in existence. Hosting platforms built around Git have become central infrastructure for open-source and commercial software development.
