The Prewitt operator is used in image processing, particularly within edge detection algorithms. Technically, it is a discrete differentiation operator that computes an approximation of the gradient of the image intensity function. It was proposed by Judith M. S. Prewitt in 1966 for detecting boundaries in medical (cell) images. At each point in the image, the result of the Prewitt operator is either the corresponding gradient vector or the norm of this vector.

Description

The operator uses two 3×3 convolution kernels. One estimates the horizontal derivative:

Gx = [−1 0 +1; −1 0 +1; −1 0 +1] * A

and the other the vertical derivative:

Gy = [−1 −1 −1; 0 0 0; +1 +1 +1] * A

where A is the source image. The gradient magnitude is commonly computed as |G| = √(Gx² + Gy²), or approximated by |Gx| + |Gy|, and the direction as θ = atan2(Gy, Gx). Because the kernels give equal weight to all three rows (or columns), the Prewitt operator averages uniformly, whereas the closely related Sobel operator weights the central row or column more heavily (by a factor of 2), giving slightly better noise suppression and rotational symmetry. Premultiplying the smoothing and derivative parts shows the Prewitt kernel factors as a box blur along one axis and a central difference along the other.

Applications

Prewitt filtering is a cheap first step in many edge-detection pipelines, feature extraction, and introductory computer-vision teaching. It is implemented in major libraries (for example the Prewitt method in MATLAB's image processing toolbox and various OpenCV examples) and is often compared with the Sobel, Roberts cross, Laplacian of Gaussian, and Canny operators.
