Simply typed lambda calculus

Simply typed lambda calculus (λ→)
Introduced byAlonzo Church (1940)
Based onLambda calculus, simple theory of types

The simply typed lambda calculus (λ→) is a typed interpretation of the lambda calculus with only one type constructor: the function type →. It was introduced by Alonzo Church in 1940 as part of his simple theory of types. It is the simplest example of a typed lambda calculus and a foundational system in type theory and programming-language semantics.

Syntax and typing

Types are built from base types using →. Terms are variables, abstractions λx:τ. t, and applications. A typing judgement Γ ⊢ t : τ assigns types to terms in a context Γ. The key typing rules give a variable its declared type, give an abstraction a function type, and allow application when the argument matches the function's domain type.

Properties

Unlike the untyped calculus, every well-typed term in the simply typed lambda calculus is strongly normalising: evaluation always terminates. Consequently the system cannot express general recursion directly (though it can encode substantial computation, and fixed-point combinators can be added as constants at the cost of normalisation). Type checking is decidable.

Curry–Howard correspondence

Under the Curry–Howard correspondence, the simply typed lambda calculus corresponds to intuitionistic implicational propositional logic: types are propositions and terms are proofs. It is also the internal language of Cartesian closed categories, and it underlies the type systems of functional languages such as ML and Haskell, which extend it with polymorphism (System F) and other features.
