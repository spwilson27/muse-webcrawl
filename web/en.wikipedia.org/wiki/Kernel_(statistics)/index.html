Kernel (statistics)

In statistics, a kernel is a non-negative real-valued integrable function used as a weighting function in non-parametric estimation techniques, most prominently in kernel density estimation and kernel regression.

Definition

A kernel K is typically required to satisfy K(x) ≥ 0 and ∫K(x)dx = 1, and is often symmetric about zero. The kernel is scaled by a bandwidth parameter h, written Kh(x) = (1/h)K(x/h), which controls the amount of smoothing.

Common kernels

Standard choices include the uniform (rectangular), triangular, Epanechnikov (parabolic), quartic (biweight), triweight, Gaussian, cosine and logistic kernels. The Epanechnikov kernel is optimal in a mean-squared-error sense, though in practice the choice of kernel matters far less than the choice of bandwidth.

Uses

Kernels underpin kernel density estimators, the Nadaraya–Watson regression estimator, and — in a different sense — the kernel trick in machine learning.

References

Texts on nonparametric statistics, e.g. Silverman (1986).
