Gradient noise

Gradient noise is a type of procedural noise used in computer graphics, in which pseudo-random gradients are assigned to points on a lattice and smoothly interpolated between them, producing a continuous, natural-looking random function. The best-known examples are Perlin noise, introduced by Ken Perlin in 1983, and its successor simplex noise (2001).

Method

For an input point, the algorithm finds the surrounding lattice cell, computes the dot product of the displacement vector from each corner with a pseudo-random gradient vector chosen (usually by hashing the corner coordinates), and interpolates these values with a smooth fade function, such as the quintic curve 6t⁵ − 15t⁴ + 10t³. Unlike value noise, which interpolates random values directly, gradient noise tends to produce fewer grid-aligned artefacts.

Applications

Summing several octaves of gradient noise at increasing frequency and decreasing amplitude (fractal Brownian motion) creates textures resembling clouds, fire, marble and terrain. Gradient noise underlies procedural terrain generation in games, texture synthesis in film — Perlin's work on Tron (1982) won an Academy Award for Technical Achievement in 1997 — and many shader effects.
