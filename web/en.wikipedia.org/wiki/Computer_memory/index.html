Computer memory

From Wikipedia, the free encyclopedia
[Image: A RAM module (memory stick) with black memory chips on a green circuit board]

Computer memory (also called main memory or RAM — random-access memory) is the hardware that stores data and machine instructions for quick access by a computer's processor. In the memory hierarchy, fast, small registers and caches sit closest to the CPU, followed by RAM, then slower but larger solid-state and magnetic storage.

Modern RAM is DRAM: each bit stored as charge in a tiny capacitor, refreshed thousands of times per second, and lost when power is removed (volatile). Typical desktop capacities grew from kilobytes in the 1970s to tens of gigabytes today.

Types and hierarchy

SRAM (fast, expensive, no refresh) implements CPU caches; DRAM implements main memory in generations — DDR3, DDR4, DDR5 — each faster and more efficient. Non-volatile memories include ROM, flash (SSDs, USB drives), and historically magnetic core memory (the 1950s–70s standard, woven by hand) and delay-line or drum stores.

Virtual memory lets the operating system use disk as an extension of RAM, paging data in and out, trading speed for capacity and isolation between processes.

Performance

Memory latency and bandwidth are central performance limits ('the memory wall'): caches and prefetching exist to hide them. Memory errors from cosmic rays are countered with ECC memory in servers.
