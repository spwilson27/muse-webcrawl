Positive and negative predictive values

Predictive values

PPV = TP / (TP + FP)
NPV = TN / (TN + FN)
Depend on: Prevalence, sensitivity, specificity

The positive predictive value (PPV) and negative predictive value (NPV) are measures of the performance of a diagnostic test or other binary classification. The PPV is the proportion of positive test results that are true positives — that is, the probability that a subject with a positive test actually has the condition. The NPV is the proportion of negative results that are true negatives.

Definitions

Condition presentCondition absent
Test positiveTrue positive (TP)False positive (FP)
Test negativeFalse negative (FN)True negative (TN)

PPV = TP / (TP + FP), and NPV = TN / (TN + FN).

Relation to prevalence

Unlike sensitivity and specificity, which are properties of the test itself, predictive values depend strongly on the prevalence of the condition in the population tested. Even a highly accurate test yields mostly false positives when used to screen for a very rare condition, because the small false-positive rate applied to the large number of healthy people outweighs the true positives. By Bayes' theorem, PPV can be computed from sensitivity, specificity and prevalence.

Applications

Predictive values are central to medical screening (for example in mammography and infectious-disease testing) and, under the names precision and related measures, to information retrieval and machine learning evaluation.
