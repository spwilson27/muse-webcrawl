RubyGems

RubyGems
Initial release: 2004
Written for: Ruby programming language
Repository: rubygems.org
Type: Package manager

RubyGems is a package manager for the Ruby programming language that provides a standard format for distributing Ruby programs and libraries, in the form of self-contained packages called "gems". RubyGems is bundled with Ruby itself since Ruby 1.9 and is operated in conjunction with Ruby Together and later the Ruby Central organisation.

Overview

A gem contains the code of a library or application, a gemspec file describing the package (name, version, dependencies, authors), and documentation. The command-line tool gem allows users to install, update and remove packages, for example gem install rails. The central public repository, RubyGems.org (originally Gemcutter), hosts hundreds of thousands of gems that have been downloaded billions of times.

The tool Bundler, itself distributed as a gem, works alongside RubyGems to manage exact dependency versions for an application, recording them in a Gemfile and Gemfile.lock, resolving the notorious "dependency hell" problems of early Ruby development.

History

RubyGems was developed by Chad Fowler, Jim Weirich and others and was first presented in 2003–2004. It became Ruby's standard distribution mechanism, though not without debate — some distributors objected to its divergence from native operating-system packaging. It remains the default source of Ruby libraries, including major frameworks such as Ruby on Rails.
