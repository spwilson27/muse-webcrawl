Pull request

A pull request (PR), called a merge request on some platforms, is a method of submitting contributions to a software project managed with version control. A contributor asks the maintainers to review and pull in changes made on a branch or fork, typically through a hosting platform such as GitHub, GitLab or Bitbucket.

Workflow

The author creates a branch, commits changes and opens a pull request describing them. Automated checks and continuous integration run, reviewers comment on individual lines, request changes or approve, and the change is merged (often by merge commit, squash or rebase) into the target branch. Pull requests structure code review, discussion and audit trails in collaborative and open-source development.
