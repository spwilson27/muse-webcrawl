Assembly language

Paradigm: Imperative, low-level
First appeared: 1947
Translation tool: Assembler

Assembly code for the x86 architecture.

An assembly language (or assembler language, often abbreviated asm) is any low-level programming language that has a very strong correspondence between its instructions and the architecture's machine code instructions. Each assembly language is specific to a particular computer architecture — x86, ARM, MIPS and RISC-V each have their own — in contrast to high-level languages, which are generally portable across architectures.

Structure

Assembly statements typically consist of an instruction mnemonic followed by operands: registers, memory addresses, constants or labels. For example, in x86 assembly using Intel syntax:

MOV AX, 5      ; load the value 5 into register AX
ADD AX, 3      ; add 3 to AX

A program called an assembler translates assembly source code into machine code, resolving symbolic labels and addresses. Assemblers also support directives (pseudo-instructions) and macros that generate repetitive code.

History

The earliest assembly languages appeared in the late 1940s; Kathleen Booth is credited with designing one of the first for the ARC computer in 1947. Assembly was the dominant programming medium through the 1950s and 1960s, and remained common for home computers and game programming into the 1980s and 1990s.

Modern use

Today assembly is used where direct hardware control or maximum performance is critical: device drivers, embedded systems, bootloaders, operating system kernels, real-time systems, reverse engineering, and compiler back-ends. Compilers for high-level languages often translate code through an assembly stage, and programmers still read disassembled output when debugging or analysing malware.
