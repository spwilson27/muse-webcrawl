Bisection method

In numerical analysis, the bisection method is a root-finding method that applies to any continuous function for which one knows two values with opposite signs. The method repeatedly bisects an interval and then selects the subinterval in which the function changes sign, and therefore must contain a root. It is a simple and robust method, but relatively slow, and is the prototype of the bracketing methods.

Method

Given a continuous function f and an interval [a, b] with f(a) and f(b) of opposite signs, the intermediate value theorem guarantees a root inside the interval. One computes the midpoint c = (a + b)/2 and evaluates f(c). If f(c) has the same sign as f(a), the root lies in [c, b]; otherwise it lies in [a, c]. The interval thus halves with each iteration.

Convergence

After n iterations the error is at most (b − a)/2n, so the method converges linearly, gaining roughly one binary digit per step — about three iterations per decimal digit. Unlike Newton's method or the secant method, the bisection method cannot fail to converge once a valid bracket is found, provided continuity holds; however, it cannot detect roots where the function touches zero without changing sign (even-multiplicity roots), and it requires only function evaluations of sign, not derivatives. Faster bracketing methods such as Brent's method build on its reliability.
