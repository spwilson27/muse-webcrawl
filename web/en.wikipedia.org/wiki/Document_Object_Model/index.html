Document Object Model

The Document Object Model (DOM) is a cross-platform and language-independent interface that treats an HTML or XML document as a tree structure, in which each node is an object representing a part of the document. The DOM represents the document as nodes and objects so that programming languages — most commonly JavaScript — can interact with the page: changing its structure, style, and content dynamically.

History and standardisation

The DOM originated in the "browser wars" of the 1990s, when Netscape Navigator and Internet Explorer implemented incompatible dynamic HTML models. The World Wide Web Consortium (W3C) standardised DOM Level 1 in 1998, followed by Level 2 and Level 3; the standard is now maintained by the WHATWG as the DOM Living Standard.

Applications of the DOM include form validation, dynamic menus, web applications, and client-side frameworks that manipulate the tree to update pages without reloading.
