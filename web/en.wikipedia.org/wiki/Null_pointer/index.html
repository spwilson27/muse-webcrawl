Null pointer

In computing, a null pointer (sometimes null reference) is a pointer value reserved to indicate that the pointer does not refer to a valid object. Programs routinely use null pointers to represent absent or optional values, the end of a list, or the failure of an operation such as a memory allocation or a search.

Representation

In C and C++ the null pointer constant is written NULL or (since C++11) nullptr; in Java, Python (None), and many other languages the analogous value is a null reference rather than a raw address. A null pointer constant need not correspond to the machine address zero in a program's source representation, though in practice it almost always does.

Dereferencing

Attempting to dereference a null pointer — reading or writing the object it purports to point to — is a classic programming error. In C and C++ it is undefined behaviour and typically causes a segmentation fault; in Java it throws a NullPointerException. Tony Hoare, who introduced the null reference in the ALGOL W language in 1965, famously apologized in 2009, calling it his "billion-dollar mistake" because of the countless errors, vulnerabilities, and system crashes it has enabled.

Mitigations

Modern languages reduce null-pointer errors with option types (such as Option in Rust or Optional in Java), nullable-type annotations and null-safety in languages like Kotlin and Swift, smart pointers, and static analysis tools that detect potential null dereferences at compile time.
