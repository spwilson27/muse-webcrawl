Equality (mathematics)

In mathematics, equality is a relationship between two quantities or, more generally, between two expressions, asserting that the quantities have the same value, or that the expressions represent the same mathematical object. The equality between expressions A and B is written A = B, using the equals sign, and pronounced "A equals B."

A = B

Properties

Equality, treated as a relation, is reflexive (every object equals itself), symmetric (if A = B then B = A), and transitive (if A = B and B = C then A = C); a relation with these properties is an equivalence relation. Equality also satisfies substitution: if A = B, then B may be substituted for A in any expression without changing its truth value — a principle formalised by Leibniz as the identity of indiscernibles.

Equations and identities

An equality asserting that two expressions are equal for some (or all) values of their variables is an equation, whose solutions are the values that make it true. An identity, such as (a + b)² = a² + 2ab + b², holds for all values. In set theory, two sets are equal when they have exactly the same elements (extensionality). In logic, equality is usually taken as a primitive notion governed by axioms, and in type theory and computer science several distinct notions of equality (propositional, definitional, extensional) are distinguished.

Notation

The equals sign "=" was introduced by the Welsh mathematician Robert Recorde in 1557, who chose two parallel lines because "no two things can be more equal." Related symbols include ≠ (not equal), ≈ (approximately equal), ≡ (identically equal or congruent), and := (defined as).
