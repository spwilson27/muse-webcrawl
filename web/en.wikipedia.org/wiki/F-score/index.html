In statistical analysis of binary classification and information retrieval, the F-score or F-measure is a measure of a test's accuracy. It is calculated from the precision and the recall of the test, where the precision is the number of true positive results divided by the number of all positive results, including those not identified correctly, and the recall is the number of true positive results divided by the number of all samples that should have been identified as positive.

Definition

The traditional F-measure, F1, is the harmonic mean of precision (P) and recall (R):

F1 = 2 · (P · R) / (P + R) = TP / (TP + ½(FP + FN))

where TP, FP and FN are the numbers of true positives, false positives and false negatives. The harmonic mean is used, rather than the arithmetic mean, because it penalises extreme imbalance: a system with very high precision but negligible recall scores poorly.

The Fβ score

The general Fβ score weights recall β times as much as precision:

Fβ = (1 + β²) · (P · R) / (β²P + R)

Common choices are F2, which emphasises recall, and F0.5, which emphasises precision. The measure derives from C. J. van Rijsbergen's effectiveness measure E, with the "F" conventionally taken from the complement of that measure.

Applications and criticism

The F-score is ubiquitous in information retrieval, named-entity recognition, machine translation evaluation and imbalanced classification, where plain accuracy is misleading. Criticisms note that F1 ignores true negatives, weights false positives and false negatives equally regardless of context, and can favour biased classifiers on skewed datasets; alternatives include the Matthews correlation coefficient and precision–recall curves summarised by average precision.
