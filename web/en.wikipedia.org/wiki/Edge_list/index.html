Edge list

An edge list is a representation of a graph in graph theory and computer science, in which the graph is stored simply as a list of its edges. Each edge is recorded as a pair of the vertices it connects; for a weighted graph, each pair is accompanied by the edge's weight. An edge list with m edges requires O(m) space.

Properties

The edge list is the most compact of the common graph representations and is simple to construct and store, which makes it popular for exchanging graph data in text files: each line of a file typically holds one edge. However, it is inefficient for operations such as testing whether a given edge exists, finding all edges incident to a vertex, or listing a vertex's neighbours, since these require scanning the whole list in O(m) time. By contrast, an adjacency list supports neighbour queries efficiently, and an adjacency matrix answers edge-existence queries in constant time at the cost of more space.

Uses

Edge lists are well suited to algorithms that process every edge in turn, such as Kruskal's algorithm for minimum spanning trees and the Bellman–Ford algorithm for shortest paths, both of which repeatedly iterate over all edges. Variants include the incidence list, which groups edges by vertex, and sorted edge lists used in external-memory and streaming graph processing.
