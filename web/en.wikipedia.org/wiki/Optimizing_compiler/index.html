Optimizing compiler

An optimizing compiler is a compiler that applies transformations to a program to improve its performance — such as execution speed, memory usage or energy consumption — while preserving its meaning. Optimisations are usually selected by compiler flags and applied at various stages of compilation.

Common optimisations include constant folding and propagation, dead-code elimination, common subexpression elimination, loop optimisation (such as unrolling, fusion and invariant code motion), inlining, register allocation and instruction scheduling. Analysis techniques such as data-flow analysis underpin many of them.

Optimisation involves trade-offs: aggressive optimisation can increase compile time and make debugging harder, since the executed code may no longer correspond closely to the source. Widely used optimising compilers include GCC, LLVM/Clang and the compilers in commercial toolchains.
