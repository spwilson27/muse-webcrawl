Orthogonal polygon

An orthogonal polygon is a polygon whose edges are aligned with the coordinate axes — that is, all edges are either horizontal or vertical, so every interior angle is either 90° or 270°. Orthogonal polygons are also called rectilinear polygons. They arise naturally in applications such as VLSI circuit layout, floor planning, and computational geometry.

Properties

An orthogonal polygon with n vertices has exactly n edges, with n even. For a simple orthogonal polygon, the numbers of convex (90°) and reflex (270°) corners are related: the count of convex corners exceeds the count of reflex corners by four. Every orthogonal polygon can be partitioned into rectangles, and a polygon with h holes requires a correspondingly larger number of rectangles in any rectangular partition.

Algorithms

Many classic problems become simpler when restricted to orthogonal polygons: area computation by sweeps, rectangular partitioning, guard placement (the art gallery problem), and decomposition into rectangles for chip layout. The minimum number of rectangles needed to partition an orthogonal polygon without holes can be found in polynomial time using matching techniques on reflex vertices.

Generalizations

In three dimensions, the analogous objects are orthogonal polyhedra, whose faces are parallel to the coordinate planes. Orthogonal polygons with edges at 45° increments are sometimes called octilinear polygons.
