Ordinal number

From Wikipedia, the free encyclopedia

[Image: A queue of numbered positions stretching to infinity then starting a new row labelled omega]

In set theory, an ordinal number extends the idea of position — first, second, third — to infinite sequences. Finite ordinals are the natural numbers; the first infinite ordinal, ω (omega), comes after all of them, and is followed by ω+1, ω+2, …, ω·2, …, ω², and far beyond.

Ordinals measure order type: two well-ordered sets have the same ordinal when they are order-isomorphic. They differ from cardinals, which measure size: ω and ω+1 are different ordinals (the orderings differ) but the same cardinal (the sets correspond one-to-one).

Construction and use

In the von Neumann construction each ordinal is the set of all smaller ordinals, making the ordering simply set membership. Ordinals index transfinite induction and recursion, the stages of the set-theoretic universe, and the lengths of proofs in proof theory.

The collection of all ordinals is itself too large to be a set — the Burali-Forti paradox (1897), a cousin of Russell's paradox.
