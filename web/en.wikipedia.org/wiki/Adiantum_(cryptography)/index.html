Adiantum (cryptography)

DesignerPaul Crowley and Eric Biggers (Google)
Published2018
PurposeDisk encryption mode
ComponentsChaCha, AES, Poly1305 / NH hashing

Adiantum is a disk encryption mode designed by Paul Crowley and Eric Biggers at Google, announced in 2018 and formally presented at the IACR Transactions on Symmetric Cryptology in 2019. It is intended for low-end devices — such as entry-level Android phones, smartwatches, and Internet-of-things hardware — whose processors lack the dedicated AES acceleration instructions used by conventional disk encryption.

Design

Adiantum is a wide-block cipher construction built within the HBSH framework (hash, block cipher, stream cipher, hash). It combines the ChaCha stream cipher (in its XChaCha variant), a single AES round function used as a mixing step, and fast hashing based on Poly1305 and the NH universal hash family. Because most of the work is done by ChaCha and the hashes, Adiantum encrypts data several times faster than AES-XTS on processors without AES instructions, while still providing strong, length-preserving, tweakable encryption suitable for sector-based storage.

Deployment

Google announced Adiantum for Android devices that cannot use hardware-accelerated AES; support was merged into the Linux kernel (version 5.0) in the dm-crypt and fscrypt subsystems. The name comes from Adiantum, a genus of maidenhair ferns, following a naming theme of plants symbolizing sincerity.

Security

Adiantum is designed to be at least as secure as the standard AES-XTS mode under its stated assumptions, with a security proof based on the underlying primitives. It provides no integrity protection, which is the same limitation as other common disk encryption modes.
