Statistical model

A statistical model is a mathematical model that embodies a set of statistical assumptions concerning the generation of sample data (and similar data from a larger population). It represents, often in considerably idealised form, the data-generating process.

Definition

Formally, a statistical model is a set of probability distributions on a sample space. When the set is indexed by a finite-dimensional parameter θ, the model is parametric; when the parameter is infinite-dimensional, it is nonparametric; intermediate cases are called semiparametric. A model is identifiable if distinct parameter values give distinct distributions.

Model selection and checking

Statisticians choose among candidate models using goodness-of-fit tests, information criteria such as AIC and BIC, and cross-validation. Because all models simplify reality, residual diagnostics are used to check whether assumptions such as independence, constant variance and normality are plausible.

Examples

Common models include the normal distribution for measurements, the Poisson distribution for counts, linear regression, logistic regression and generalised linear models.
