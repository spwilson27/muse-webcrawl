Branch and bound

Branch and bound explores a search tree, pruning branches whose bounds cannot beat the incumbent solution

Branch and bound (BB, B&B, or BnB) is a general algorithm design paradigm for solving discrete and combinatorial optimisation problems, as well as mathematical optimisation problems more generally. A branch-and-bound algorithm consists of a systematic enumeration of candidate solutions by means of state-space search: the set of candidate solutions is thought of as forming a rooted tree, and the algorithm explores branches of this tree, estimating upper and lower bounds on the optimal solution reachable from each branch and discarding branches that cannot improve on the best solution found so far.

History

The method was first proposed by Ailsa Land and Alison Doig in 1960 for discrete programming, and has become the most commonly used tool for solving NP-hard optimisation problems. The name "branch and bound" first appeared in the work of Little and colleagues on the travelling salesman problem.

Description

The algorithm recursively splits ("branches") the problem into smaller subproblems, typically by fixing the value of a decision variable. For each subproblem it computes a bound on the best achievable objective value, often by solving a relaxation such as the linear programming relaxation of an integer program. If the bound for a subproblem is no better than the incumbent (the best feasible solution found so far), the whole subtree is pruned and never explored. If the relaxation yields a feasible solution, the incumbent is updated.

Applications

Branch and bound underlies most commercial and open-source mixed-integer programming solvers and is used for scheduling, vehicle routing, facility location, cutting stock, and many other combinatorial problems. Variants include branch and cut, which strengthens relaxations with cutting planes, and branch and price, which combines branching with column generation.
