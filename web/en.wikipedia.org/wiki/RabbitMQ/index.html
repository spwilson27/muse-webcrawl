RabbitMQ is an open-source message-broker software that implements the Advanced Message Queuing Protocol (AMQP). Written in Erlang and built on the Open Telecom Platform framework for clustering and failover, it accepts and forwards messages between distributed applications, allowing producers and consumers to communicate asynchronously through exchanges and queues.

Features

RabbitMQ supports multiple messaging protocols including AMQP 0-9-1 and 1.0, MQTT and STOMP, offers routing, acknowledgements, publisher confirms, clustering and high-availability queues, and provides client libraries for many languages. Management is through a web-based console, HTTP API and command-line tools. It is widely deployed for task queues, event distribution and microservice communication.

History

RabbitMQ was originally developed by Rabbit Technologies, a joint venture of LShift and CohesiveFT, and released in 2007. The company was acquired by SpringSource (a division of VMware) in 2010; the project is now maintained under Broadcom's VMware Tanzu umbrella with a commercial offering alongside the open-source server.
