List of Java bytecode instructions

Java bytecode is the instruction set of the Java virtual machine (JVM). Each instruction is represented by a one-byte opcode (hence "bytecode"), possibly followed by operand bytes stored in the method's Code attribute in the class file. There are 256 possible opcodes, of which around 200 are in use.

Notes

Instruction families follow systematic patterns: loads, stores and arithmetic exist in variants for int (i), long (l), float (f), double (d) and references (a). Opcodes fe and ff (impdep1, impdep2) are reserved for implementation-specific purposes.
