README

Image placeholder: a typical README file displayed in a text editor.

A README file contains information about the other files in a repository or software archive. It is a form of documentation, usually in a simple plain text file called README, Read Me, READ.ME, README.txt, or, in the case of a Markdown file, README.md. The format is an informal standard in software development, typically containing a description of the project, installation and usage instructions, licensing information, and how to obtain support or contribute.

History

Text files with names in all capitals date from early operating systems in which file names were case-insensitive or conventionally uppercase; on such systems a file named README would sort near the top of a directory listing and catch the user's attention. The convention was widespread by the time of early Unix distributions and the GNU Project, and was later adopted by distributed revision-control systems.

On hosting platforms

Code-hosting services such as GitHub, GitLab and Bitbucket automatically render the contents of a repository's README file on its landing page, which has made the README the de facto front page and summary document of open-source projects. READMEs frequently include badges, screenshots, usage examples and links to fuller documentation.

Contents

A well-written README typically answers: what the project does, why it is useful, how to install and run it, where to get help, and who maintains and contributes to it. In many projects it coexists with files such as CHANGELOG, LICENSE and CONTRIBUTING.
