Convex function

A function f is convex if the line segment between any two points on its graph lies above or on the graph.

In mathematics, a real-valued convex function is a function defined on an interval (or, more generally, on a convex subset of some vector space) such that the line segment between any two distinct points on the graph of the function lies above or on the graph between the two points. Equivalently, a function is convex if its epigraph — the set of points on or above the graph — is a convex set. In simple terms, a convex function curves upward.

A single-variable convex function on an interval satisfies Jensen's inequality: for any two points x and y in its domain and any number t in [0, 1],

f(tx + (1−t)y) ≤ t f(x) + (1−t) f(y).

If a function has a second derivative at all points, then it is convex on its domain if and only if its second derivative is nonnegative throughout its domain; this is a useful test for convexity. Well-known examples of convex functions of a single variable include the quadratic function f(x) = x² and the exponential function f(x) = ex.

Definition

Let X be a convex subset of a real vector space and let f : X → ℝ be a function. The function f is called convex if, for any two points x and y in X and any t with 0 ≤ t ≤ 1, one has f(tx + (1−t)y) ≤ tf(x) + (1−t)f(y). The function f is called strictly convex if the inequality is strict for x ≠ y and 0 < t < 1. A function f is concave if −f is convex.

Properties

Every convex function on a closed bounded interval is bounded above and attains its maximum at one of the endpoints. A convex function on an open interval is continuous; indeed, a convex function on an open interval of the real line is locally Lipschitz continuous and therefore almost everywhere differentiable. Every local minimum of a convex function is also a global minimum, a fact of central importance in convex optimization.

Operations that preserve convexity

  • A nonnegative weighted sum of convex functions is convex.
  • The pointwise maximum of any collection of convex functions is convex.
  • The composition of a convex nondecreasing function with a convex function is convex.

Applications

Convex functions play a key role in optimization theory, economics, game theory, and probability. Convex optimization problems are generally easier to solve than general nonconvex problems because local optimality implies global optimality and efficient algorithms such as gradient descent are guaranteed to converge under mild assumptions.
