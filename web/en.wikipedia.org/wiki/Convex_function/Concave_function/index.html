Concave function

In mathematics, a concave function is the negative of a convex function. A function f defined on an interval is concave if, for any two points x and y in the interval and any t in [0, 1],

f(tx + (1−t)y) ≥ t f(x) + (1−t) f(y).

Equivalently, a concave function is one whose graph lies above any of its secant lines: the line segment between any two points of the graph lies below the graph. A function is strictly concave if the inequality is strict whenever x ≠ y and t is strictly between 0 and 1.

Properties

A twice-differentiable function of one variable is concave if and only if its second derivative is everywhere non-positive. A concave function on a closed interval attains its minimum at one of the endpoints, and any local maximum is a global maximum. The pointwise infimum of concave functions is concave, and the sum of concave functions is concave.

Examples

The logarithm and square root functions are concave on their domains, as is −x2 and any affine function (which is both concave and convex). In economics, concave utility functions model risk aversion, and concave production functions model diminishing returns.

Applications

Concavity underlies Jensen's inequality for concave functions (with the inequality reversed relative to the convex case) and appears throughout optimization, information theory and economics.
