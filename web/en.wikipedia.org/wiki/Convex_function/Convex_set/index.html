Convex set

In geometry and analysis, a convex set is a subset of a vector space such that, for every pair of points within the set, the line segment connecting them lies entirely within the set. Formally, a set S is convex if for all x, y in S and all t in [0, 1], the point (1−t)x + ty also belongs to S.

Examples

Intervals of the real line, disks and balls, triangles, cubes, half-spaces and affine subspaces are convex. The intersection of any family of convex sets is convex, but the union of convex sets need not be. A set that is not convex is sometimes called non-convex or concave; a star-shaped set such as a five-pointed star outline is a typical non-example.

Properties

Every convex set is connected and simply connected in finite dimensions. The convex hull of a set is the smallest convex set containing it. The Krein–Milman theorem states that a compact convex set in a locally convex topological vector space is the closed convex hull of its extreme points. The hyperplane separation theorem guarantees that two disjoint nonempty convex sets, one of them open, can be separated by a hyperplane.

Convex functions

A function is convex if its epigraph is a convex set; this connects the geometry of convex sets to convex optimization, where minimizing a convex function over a convex set has the property that every local minimum is global.
