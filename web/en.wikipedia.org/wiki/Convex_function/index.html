Convex function

In mathematics, a real-valued function defined on an interval (or on a convex set) is called convex if the line segment between any two points on its graph lies above or on the graph. Equivalently, for all x, y in the domain and all t in [0, 1]:

f(tx + (1−t)y) ≤ t f(x) + (1−t) f(y).

Properties

A convex function has an epigraph that is a convex set. If twice differentiable, a function is convex exactly when its second derivative is everywhere non-negative. Every local minimum of a convex function is a global minimum, a property that makes convex functions central to convex optimization. Jensen's inequality states that for a convex function, the function of an average is at most the average of the function values.

Examples

Examples include x², the exponential function eˣ, |x|, and x log x on the positive reals. A function is concave if its negative is convex; the logarithm and square root are concave on their domains. A function that is both convex and concave is affine.
