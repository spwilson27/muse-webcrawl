Berkeley Software Distribution

The Berkeley Software Distribution (BSD) is a family of Unix operating system distributions derived from source code developed at the University of California, Berkeley, beginning in the late 1970s. BSD code — including its TCP/IP networking implementation and the sockets API — became foundational to modern operating systems, and its permissive BSD licences allowed wide reuse in both open-source and proprietary products.

History

Berkeley received Unix from Bell Labs in the 1970s, and students and researchers — notably Bill Joy — began adding utilities: the ex/vi editors, the C shell and the Pascal compiler appeared in the early 1BSD and 2BSD tapes distributed from 1978. With DARPA funding, the Computer Systems Research Group (CSRG) developed 4BSD for the VAX, and the 4.2BSD release of 1983 delivered the first widely used implementation of TCP/IP along with the Berkeley sockets interface and the Fast File System.

The networking releases Networking Release 1 (1989) and Release 2 (1991) provided BSD code free of AT&T licence restrictions, prompting the commercial startup BSDi and the volunteer 386BSD project, from which FreeBSD and NetBSD descend. A lawsuit by AT&T's Unix System Laboratories against BSDi and the university (1992–1994) slowed adoption while Linux surged, but the settlement cleared most of the code as freely distributable. The CSRG disbanded in 1995 after 4.4BSD-Lite Release 2.

Legacy

BSD code lives on in FreeBSD, NetBSD, OpenBSD and DragonFly BSD, in the networking stacks of many commercial systems, and in Apple's macOS and iOS, whose userland derives substantially from FreeBSD. Key Berkeley contributions — sockets, virtual memory, the vi editor and sendmail — remain ubiquitous.
