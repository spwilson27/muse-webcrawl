Schematron

Schematron validates XML by testing assertions about its structure
Original authorRick Jelliffe
Initial release1999
StandardISO/IEC 19757-3
TypeXML schema language

Schematron is a rule-based validation language for making assertions about the presence or absence of patterns in XML documents. It was created by Rick Jelliffe in 1999 and standardised as ISO/IEC 19757-3 within the Document Schema Definition Languages (DSDL) family.

Approach

Where grammar-based schema languages such as XML Schema (XSD) and RELAX NG define permissible structures, Schematron expresses constraints as assertions written in XPath, organised into rules and patterns. Each rule selects nodes by context and then states assertions (which should hold) and reports (conditions that should be flagged when true). Failed assertions produce human-readable diagnostic messages written by the schema author, making Schematron particularly valued for business-rule validation and user-friendly error reporting.

<rule context="invoice">
  <assert test="total = sum(item/price)">
    The invoice total must equal the sum of item prices.
  </assert>
</rule>

Features

  • Phases — different subsets of patterns can be activated for different validation scenarios
  • Abstract patterns — reusable rule templates parameterised for different contexts
  • Query language binding — XPath 1.0, XPath 2.0, or XSLT bindings, allowing progressively richer tests
  • Diagnostics and properties — detailed, localisable messages and machine-readable metadata attached to failures

Implementation

Schematron schemas are often "compiled" into XSLT stylesheets in a multi-step pipeline: the schema is expanded, abstract patterns resolved, and XPath expressions embedded into a validator stylesheet, which outputs results in SVRL (Schematron Validation Report Language). Schematron is widely used in publishing, government, and finance — for example in the validation of UBL invoices and European e-procurement documents — frequently as a complement to grammar-based schemas.
