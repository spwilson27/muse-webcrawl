ActivityPub is an open, decentralised social networking protocol standardised by the World Wide Web Consortium (W3C) in January 2018. It provides a client-to-server API for creating and modifying content and a federated server-to-server protocol for delivering notifications and posts between independent servers, allowing users on different services to follow and interact with one another.

Design

ActivityPub is built on the ActivityStreams 2.0 vocabulary, expressed in JSON-LD. Every user is an "actor" with an inbox and an outbox hosted on their server. Posts, likes, boosts and follows are "activities" that servers exchange by POSTing them to recipients' inboxes, usually with HTTP signatures for authentication. Because there is no central authority, any implementation can interoperate with any other, an arrangement comparable to email.

Implementations

The best-known implementation is Mastodon, whose network of interconnected servers is nicknamed the Fediverse. Other ActivityPub software includes PeerTube (video), Pixelfed (photos), Lemmy (link aggregation), Misskey, Pleroma and WordPress via a plugin. In 2023–2024 Meta began federating its Threads service with ActivityPub, greatly expanding the protocol's reach.

History

ActivityPub grew out of the pump.io protocol and the work of the W3C Social Web Working Group, with Evan Prodromou and Christine Lemmer-Webber among its principal editors.
