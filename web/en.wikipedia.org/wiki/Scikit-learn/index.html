Scikit-learn

Original author: David Cournapeau

Initial release: 2007

Written in: Python, Cython, C, C++

License: BSD (3-clause)

Scikit-learn (formerly scikits.learn) is a free and open-source machine learning library for the Python programming language. It began in 2007 as a Google Summer of Code project by David Cournapeau and has since been developed by a large community, with institutional support from Inria and others.

Features

The library implements a wide range of supervised and unsupervised learning algorithms through a uniform interface built around the estimator API of fit and predict methods. It provides classification, regression and clustering algorithms including support vector machines, random forests, gradient boosting, k-means and DBSCAN, together with tools for model selection and evaluation, cross-validation, hyperparameter search, dimensionality reduction, feature extraction and data preprocessing pipelines. It is built on NumPy, SciPy and matplotlib, and is designed to interoperate with the wider Python scientific ecosystem rather than to handle very large-scale or GPU-based deep learning, for which frameworks such as TensorFlow or PyTorch are typically used.

Usage

Scikit-learn is one of the most popular machine learning libraries in industry and academia and is frequently used for teaching because of its consistent API and thorough documentation.
