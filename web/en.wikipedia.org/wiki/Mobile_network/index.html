Cellular network

TypeTelecommunications network
Generations1G, 2G (GSM), 3G (UMTS), 4G (LTE), 5G (NR)
Key componentsBase stations, core network, mobile devices

A cellular network or mobile network is a telecommunications network in which the coverage area is divided into small geographic areas called cells, each served by its own base station transceiver. Mobile devices connect to the nearest cell, and calls or data sessions are handed over from cell to cell as the user moves.

Principles

The cellular concept, developed at Bell Labs in the 1940s–1970s, allows the same radio frequencies to be reused in non-adjacent cells, greatly increasing capacity compared with a single high-power transmitter. Each cell uses low-power transmitters, and a core network routes traffic between cells and to other networks such as the public switched telephone network and the Internet.

Generations

Successive generations have increased data rates and efficiency: analogue 1G systems of the 1980s; digital 2G (notably GSM) with text messaging; 3G (UMTS/CDMA2000) with mobile data; 4G LTE with all-IP service; and 5G NR, offering higher speeds, lower latency and support for massive numbers of connected devices.
