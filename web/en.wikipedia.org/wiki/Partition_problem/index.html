Partition problem

In number theory and computer science, the partition problem is the task of deciding whether a given multiset of positive integers can be partitioned into two subsets whose sums are equal. It is one of the classical NP-complete problems, though it is "weakly" NP-complete because it admits a pseudo-polynomial-time algorithm based on dynamic programming.

Algorithms

Dynamic programming over achievable subset sums solves the problem in time proportional to the number of elements times the total sum. Approximation algorithms, including the Karmarkar–Karp differencing heuristic, find near-optimal partitions quickly, and a fully polynomial-time approximation scheme exists.

Variants

Related problems include the multiway number partitioning problem (dividing numbers into k subsets with near-equal sums), the subset sum problem, and the 3-partition problem, which is strongly NP-complete.
