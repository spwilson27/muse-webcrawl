Type safety

Type safety is the extent to which a programming language discourages or prevents type errors — errors caused by applying an operation to a value of a type for which that operation is not defined, such as treating a string as a number or jumping to an arbitrary memory address. A language is described as type-safe if well-typed programs cannot "go wrong" in this sense at runtime; Robin Milner's slogan for the ML language summarised the ideal: "Well-typed programs cannot go wrong."

A type-safe language guarantees that operations are only applied to values of appropriate types.

Definitions

In programming language theory, type safety is typically proved through two properties of the type system: preservation (if an expression has a type and evaluates one step, the result has the same type) and progress (a well-typed expression is either a value or can take an evaluation step). Together they imply that well-typed programs never get "stuck" on account of a type mismatch.

In practice the term is graded and somewhat contentious. A language may be statically type-safe (violations caught at compile time) or dynamically type-safe (violations caught at runtime before an invalid operation occurs, as in Lisp, Smalltalk, or Python). Memory safety is closely related: languages such as C and C++ permit type errors through unchecked casts, unions, and pointer arithmetic that can corrupt memory, whereas languages like Java, Rust, ML, and C# rule most such errors out by construction (subject to escape hatches such as Java's native methods or Rust's unsafe blocks).

Type safety versus expressiveness

Strong guarantees come at a cost. Features such as unrestricted reflection, dynamic loading, or low-level systems programming can conflict with a purely static discipline, and type systems differ in the class of errors they can express and prevent. Designers trade off: gradual typing systems, as in TypeScript or Typed Racket, allow typed and untyped code to interoperate, retaining safety within the typed portion at some cost in soundness guarantees.
