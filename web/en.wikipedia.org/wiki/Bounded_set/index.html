Bounded set

In mathematical analysis and related areas, a set is called bounded if it is, in a certain sense, of finite measure. A set that is not bounded is called unbounded. The notion appears in several settings: bounded subsets of the real line, bounded subsets of metric spaces, and bounded sets in topological vector spaces, where the definition generalises to absorption by neighbourhoods of zero.

In the real numbers

A subset of the real line is bounded if it has both an upper bound and a lower bound; equivalently, if it is contained in some finite interval. A function is bounded if its range is a bounded set. Bounded sequences of real numbers have convergent subsequences by the Bolzano–Weierstrass theorem, and continuous functions on closed bounded intervals attain their maxima and minima.

In metric spaces

In a metric space, a set is bounded if it is contained in a ball of finite radius — that is, if the distances between its points have a finite supremum (its diameter). Total boundedness, a strengthening in which the set can be covered by finitely many arbitrarily small balls, is a key ingredient, together with completeness, in characterising compactness.
