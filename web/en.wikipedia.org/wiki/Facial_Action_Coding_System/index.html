Facial Action Coding System

The Facial Action Coding System (FACS) is a system to taxonomize human facial movements by their appearance on the face, based on a system originally developed by Carl-Herman Hjortsjö. It was later developed by psychologists Paul Ekman and Wallace V. Friesen, and published in 1978, with a significant update in 2002 by Ekman, Friesen, and Joseph C. Hager.

FACS divides facial movement into individual action units based on muscle contractions.

Action units

Using FACS, human coders can manually code nearly any anatomically possible facial expression, deconstructing it into the specific action units (AUs) that produced it. Examples include AU1 (inner brow raiser), AU2 (outer brow raiser), AU4 (brow lowerer), AU12 (lip corner puller, as in a smile), and AU15 (lip corner depressor). Emotions are commonly described as combinations of action units; the Duchenne smile, for example, combines AU6 and AU12.

Uses

FACS is widely used in psychology, behavioural science, animation, and computer vision. Automated FACS coding has become a tool in affective computing, and the system has been adapted for studying facial movement in infants and non-human primates.
