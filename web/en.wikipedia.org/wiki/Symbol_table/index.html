Symbol table

[Image placeholder: symbol table]

In computer science, a symbol table is a data structure used by a language translator — such as a compiler or interpreter — to store information about the source program's symbols, including variable names, function names, classes, and objects. Each entry typically records the symbol's name, type, scope, and, where relevant, its memory address or offset.

Role in compilation

The symbol table is built up during lexical and syntactic analysis as declarations are encountered, and it is consulted during semantic analysis (for example, to check that a variable is declared before use and that types are compatible) and during code generation (to assign storage locations). Operations on the table are primarily insert, lookup, and scope management — entering and leaving scopes as blocks are entered and exited.

Implementation

Symbol tables are commonly implemented with hash tables for fast lookup, often with chained lists of symbols per scope or a stack of scopes. Object files and executables also contain symbol tables, used by linkers and debuggers; these can be stripped to reduce file size, which removes debugging information.

Examples

Utilities such as nm on Unix-like systems display the symbol table of an object file, listing symbols such as functions in the text section and variables in the data and BSS sections.
