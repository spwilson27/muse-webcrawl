List coloring

In graph theory, list coloring is a type of graph coloring in which each vertex is assigned a list of allowed colors, and a proper coloring must be chosen so that every vertex receives a color from its own list. List coloring was first studied in the 1970s in independent works by Vadim G. Vizing and by Paul Erdős, Arthur L. Rubin and Herbert Taylor.

Definition

Given a graph G and, for each vertex v, a list L(v) of colors, a list coloring (or choosable coloring) is a proper coloring f such that f(v) ∈ L(v) for all v. A graph G is k-choosable (or k-list-colorable) if every assignment of lists of size k admits a list coloring. The smallest k for which G is k-choosable is the list chromatic number or choice number, written ch(G).

Properties

Every proper coloring is a list coloring in which all lists are identical, so the ordinary chromatic number satisfies χ(G) ≤ ch(G). However, the two parameters can differ substantially: there exist bipartite graphs (with χ = 2) whose choice number is arbitrarily large. For planar graphs, the famous theorem of Carsten Thomassen (1994) states that every planar graph is 5-choosable, while examples show that 4-choosability fails in general. Voigt gave a planar graph that is not 4-choosable.

Conjectures

The list coloring conjecture (edge version) asserts that for every loopless multigraph, the list chromatic index equals the ordinary chromatic index: ch′(G) = χ′(G). This conjecture, proposed in the 1970s, remains open in general, although it has been proved for bipartite graphs by Fred Galvin (1995) using the kernel method.

Applications

List coloring models channel-assignment problems in wireless networks, where each transmitter has a restricted set of available frequencies, as well as scheduling and register-allocation problems in which resources are not uniformly available.
