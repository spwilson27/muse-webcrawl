Elliptic Curve Digital Signature Algorithm

From Wikipedia, the free encyclopedia

The Elliptic Curve Digital Signature Algorithm (ECDSA) is a variant of the Digital Signature Algorithm (DSA) which uses elliptic-curve cryptography. It was standardised in ANSI X9.62 in 1998 and in FIPS 186, and is one of the most widely deployed public-key signature schemes.

Algorithm

A signer's private key is a random integer d; the public key is the curve point Q = dG. To sign a message, the signer hashes the message, picks a secret random nonce k, computes the point kG, and derives the signature pair (r, s) from that point's x-coordinate and the hash. A verifier with the public key can check the signature using only public information.

Nonce security

The nonce k must be unique and unpredictable for every signature. Reusing a nonce for two different messages allows an attacker to solve for the private key — a failure famously exploited against the PlayStation 3, which used a constant nonce. Deterministic nonce generation, specified in RFC 6979, derives k from the message and private key and removes the dependence on a random number generator.

Applications

ECDSA is used in TLS certificates, secure messaging, and cryptocurrencies: Bitcoin uses ECDSA with the secp256k1 curve to authorise transactions, as did Ethereum before its later protocol changes. Common standard curves include NIST P-256 and P-384.

Comparison with EdDSA

Newer protocols often prefer EdDSA (such as Ed25519), which is deterministic by design, faster, and less vulnerable to implementation mistakes, though ECDSA remains entrenched in existing standards and hardware.
