Bigtable

Bigtable is a distributed storage system developed by Google for managing structured data at very large scale — petabytes of data across thousands of commodity servers. Described in a 2006 research paper, it underpinned many Google services including web indexing, Google Maps, Gmail, and YouTube.

DeveloperGoogle
Released2005 (described 2006)
TypeWide-column store / NoSQL database
Successor serviceGoogle Cloud Bigtable (2015)

Design

Bigtable is a sparse, distributed, persistent multidimensional sorted map indexed by row key, column key, and timestamp. Data is stored in tablets — contiguous row ranges — served by tablet servers, with files kept in the Google File System and coordination handled by the Chubby lock service. Rows are sorted lexicographically, giving applications control over data locality.

Influence

Bigtable's design inspired open-source systems such as Apache HBase and inspired the wide-column data model used by Apache Cassandra. In 2015 Google offered the system to the public as the managed service Cloud Bigtable.
