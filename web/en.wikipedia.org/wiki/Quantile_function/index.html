Quantile function

The quantile function of the normal distribution (the probit function).

In probability and statistics, the quantile function (also called the inverse cumulative distribution function or percent point function) of a probability distribution describes the value x such that the probability of the random variable being less than or equal to x equals a given probability p. It is written Q(p) = F−1(p), where F is the cumulative distribution function (CDF). If the CDF is strictly increasing, then Q is simply its inverse.

Definition

For distributions with flat stretches or jumps, the quantile function is defined using the generalised inverse: Q(p) = inf { x : F(x) ≥ p } for 0 < p < 1. Familiar special cases are the 0.25 quantile (first quartile), the 0.5 quantile (the median), and the 0.75 quantile (third quartile).

Properties and applications

  • Random variate generation: If U is uniform on (0,1), then Q(U) has the distribution F — the basis of inverse transform sampling in simulation.
  • Probit: The quantile function of the standard normal is called the probit function, central to probit analysis and Q–Q plots.
  • Value at risk: In finance, a loss distribution's 0.99 quantile is the widely used Value at Risk.
  • Quantile regression: Modelling conditional quantiles rather than the conditional mean.

Unlike the CDF, the quantile function of a distribution with a density f satisfies Q′(p) = 1 / f(Q(p)), showing that where the density is low, quantiles spread out.
