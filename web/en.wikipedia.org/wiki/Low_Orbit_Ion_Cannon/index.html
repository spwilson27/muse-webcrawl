Low Orbit Ion Cannon

Low Orbit Ion Cannon

Abbreviation: LOIC

Type: Network stress-testing / DoS application

Written in: C#

Known for: Use by Anonymous in hacktivist campaigns

The Low Orbit Ion Cannon (LOIC) is an open-source network stress testing and denial-of-service attack application, written in C#. LOIC was initially developed by Praetox Technologies, however it was later released into the public domain and is currently available on several open-source platforms.

Use

LOIC floods a target server with TCP, UDP or HTTP requests, with the intention of disrupting the service of a particular host. A single user running LOIC cannot generate enough traffic to overwhelm a target, so it is effective only when thousands of users coordinate their attacks — the "voluntary botnet" model. A "Hive Mind" mode lets the tool be controlled remotely via IRC, allowing operators to coordinate mass attacks.

Operation Payback

LOIC became famous in December 2010 when the hacktivist collective Anonymous used it in Operation Payback against the websites of Visa, MasterCard, PayPal and others that had cut services to WikiLeaks. Because LOIC does not hide the attacker's IP address, many participants were identified and arrested in several countries, a fact that security researchers had warned about.

Name

The name is a reference to the ion cannon superweapon of the Command & Conquer video game series. A successor tool, the High Orbit Ion Cannon (HOIC), was later developed to be more powerful.
