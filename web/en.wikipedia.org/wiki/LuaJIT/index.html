LuaJIT is a just-in-time (JIT) compiler for the Lua programming language. It is designed to be embedded into other programs and is notable for achieving performance close to compiled C code while retaining Lua's flexibility and small footprint. LuaJIT is largely compatible with Lua 5.1, with many features from later versions backported as extensions.

Architecture

LuaJIT combines a fast interpreter, written in hand-tuned assembly for each supported architecture, with a trace-based JIT compiler. Hot loops are recorded as traces, optimized—using techniques such as allocation sinking, store sinking and constant folding—and compiled into machine code. If a guard in a trace fails, execution falls back to the interpreter. LuaJIT also includes an FFI (foreign function interface) library that lets Lua code call C functions and use C data types directly, without writing binding glue code.

History

The project was started by Mike Pall in 2005. LuaJIT 1.x provided a tracing compiler for x86; LuaJIT 2.0, released in 2012, rewrote the VM and extended support to many architectures. The project is used in production by companies and projects including Cloudflare, OpenResty (nginx with Lua), Neovim-facing plugin systems, game engines and networking equipment. After many years as principal developer, Mike Pall stepped down as project leader in 2025, with the project continuing under community maintainership at the LuaJIT GitHub organization.

Performance

LuaJIT is frequently cited among the fastest dynamic-language implementations; on micro-benchmarks its compiled traces often run within a small factor of optimized C, and its interpreter alone is typically several times faster than the reference Lua interpreter.
