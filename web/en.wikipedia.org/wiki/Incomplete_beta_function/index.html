Incomplete beta function


The regularized incomplete beta function

In mathematics, the incomplete beta function is a generalization of the beta function obtained by replacing the definite integral of the beta function with an indefinite integral over a variable upper limit. For x between 0 and 1 and parameters a, b > 0, the incomplete beta function B(x; a, b) is the integral from 0 to x of ta−1(1−t)b−1 dt.

Regularized incomplete beta function

Dividing the incomplete beta function by the complete beta function B(a, b) gives the regularized incomplete beta function Ix(a, b), which equals the cumulative distribution function of the beta distribution. It is therefore central to probability and statistics: the cumulative distribution functions of the binomial distribution and of Student's t-distribution and the F-distribution can all be expressed through it. For example, the probability of at most k successes in n Bernoulli trials with success probability p is related to I1−p(n−k, k+1).

Properties and computation

The regularized function satisfies I0(a, b) = 0, I1(a, b) = 1, and the symmetry Ix(a, b) = 1 − I1−x(b, a). It can be evaluated numerically by a continued-fraction expansion, the method used in standard numerical libraries, with series expansionspreferred in complementary parameter ranges.
