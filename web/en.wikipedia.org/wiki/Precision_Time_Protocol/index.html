Precision Time Protocol

The Precision Time Protocol (PTP) is a protocol used to synchronise clocks throughout a computer network. On a local area network it achieves clock accuracy in the sub-microsecond range, making it suitable for measurement and control systems. PTP was originally defined in the IEEE 1588-2002 standard ("IEEE Standard for a Precision Clock Synchronization Protocol for Networked Measurement and Control Systems"); the second version, IEEE 1588-2008, is known as PTPv2.

Operation

PTP uses a hierarchical master–slave architecture: the best master clock algorithm elects a grandmaster, which distributes time to other clocks. Synchronisation uses timestamped messages exchanged between master and slave; by measuring the round trip and assuming symmetric path delay, a slave computes its offset from the master. Switches and routers may act as boundary clocks or transparent clocks, correcting timestamps for their own residence time to improve accuracy.

Applications

PTP is widely used in telecommunications (mobile network phase synchronisation), power substations (IEC 61850), professional audio and video (AES67 and SMPTE ST 2059), industrial automation and financial trading systems, where regulations require precise, traceable timestamps. It complements the simpler Network Time Protocol (NTP), which typically provides millisecond accuracy over wide-area networks.
