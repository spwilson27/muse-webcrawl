Fabrice Bellard

Fabrice Bellard, French computer scientist

Fabrice Bellard (born 1972) is a French computer scientist and programmer known for creating several widely used pieces of software, including the FFmpeg multimedia framework and the QEMU emulator, as well as setting records for computing digits of pi.

Career and projects

Bellard studied at Télécom Paris. While still a student he wrote the LZEXE executable compressor. Among his best-known creations:

  • FFmpeg (2000) — the ubiquitous open-source multimedia library and toolset for recording, converting and streaming audio and video.
  • QEMU (2003) — a generic machine emulator and virtualiser using dynamic binary translation, now a foundation of much cloud and development infrastructure.
  • Tiny C Compiler (TCC) — a small, fast C compiler; a bootable variant won the International Obfuscated C Code Contest.
  • QuickJS (2019) — a small, embeddable JavaScript engine supporting recent ECMAScript standards.
  • JSLinux — a PC emulator written in JavaScript capable of booting Linux in a web browser.
  • BPG (Better Portable Graphics) — an image format based on HEVC intra-frame coding.
  • TSAC and other neural-network-based compression experiments in the 2020s.

Records

Bellard has twice set world records for computing digits of pi: in 2009 he computed nearly 2.7 trillion digits on a single desktop computer, and he later calculated the first 2^62 binary digits using the BBP-type formula that bears his name in part — Bellard's formula, published in 1997, improved on the Bailey–Borwein–Plouffe formula for extracting hexadecimal digits of pi.

He is also a co-founder of the Amarisoft company, which develops 4G/5G cellular network software.
