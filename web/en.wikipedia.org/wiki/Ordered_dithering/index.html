Ordered dithering

Ordered dithering is an image dithering algorithm used to display a continuous image on a display of smaller color depth. It converts an image by applying a threshold map — a fixed pattern of thresholds, commonly a Bayer matrix — tiled across the image. For each pixel, its value is compared with the corresponding threshold in the map; the pattern of output pixels creates the illusion of intermediate shades.

The Bayer matrix

The classic threshold matrices, described by Bryce Bayer in 1973, are constructed recursively for sizes 2×2, 4×4, 8×8 and so on. The 4×4 matrix spreads thresholds in a dispersed pattern so that, at each gray level, the "on" pixels are distributed as evenly as possible, avoiding visible clumps.

Algorithm

For an input pixel value v (normalized to [0,1)) and a threshold t taken from the matrix position corresponding to the pixel's coordinates, the output is 1 if v > t, otherwise 0. The operation is purely local and pointwise — unlike error-diffusion methods such as Floyd–Steinberg dithering — which makes ordered dithering fast, parallelizable and stable for animation, at the cost of a visible crosshatch or checkerboard texture.

Applications

Ordered dithering was widely used in early computer graphics, printers, and GIF/Web images with limited palettes, and remains common in shaders and retro-style games for its characteristic patterned look and low computational cost.
