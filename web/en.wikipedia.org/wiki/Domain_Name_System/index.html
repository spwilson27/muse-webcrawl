Domain Name System

From Wikipedia, the free encyclopedia
[Image: A hierarchical tree diagram of domain names: root, top-level domains, and subdomains]

The Domain Name System (DNS) is a hierarchical and distributed naming system for computers and services connected to the Internet or a private network. It associates domain names (such as en.wikipedia.org) with numerical IP addresses and other records, acting as the internet's phone book.

DNS was designed in 1983 by Paul Mockapetris (RFCs 882/883, replaced by 1034/1035 in 1987), replacing a single centrally maintained hosts file that could not scale. It is administered hierarchically: ICANN oversees the root; registries run top-level domains (.com, .org, country codes); registrars sell names to the public.

How resolution works

A recursive resolver (often run by an ISP or public provider) answers queries by walking the hierarchy — root servers, TLD servers, authoritative servers — and caching results for the record's TTL. Record types include A/AAAA (addresses), MX (mail), CNAME (aliases), TXT (text, used for verification).

DNS is largely plaintext UDP, enabling spoofing and surveillance; DNSSEC adds signatures for authenticity, and DNS over HTTPS/TLS encrypts queries. The system is also a censorship and filtering battleground, and outages at major providers have repeatedly shown its criticality.
