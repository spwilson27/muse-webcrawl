BibTeX is reference management software for formatting lists of references. The BibTeX tool is typically used together with the LaTeX document preparation system. Within the typesetting system, its name is styled as BIBTEX.

History

BibTeX was created by Oren Patashnik and Leslie Lamport in 1985. It was designed to separate bibliographic information from its presentation, so that a single database of references can be reformatted to suit many different citation styles.

Bibliographic database files

References are stored in a plain-text .bib file as entries such as @article, @book, @inproceedings, and @misc, each with a citation key and fields such as author, title, journal, year, and pages. A bibliography style file (.bst), written in a stack-based language, controls how entries are sorted and formatted in the output. Running LaTeX and BibTeX in sequence produces a formatted bibliography containing only the works cited in the document.

Variants

BibTeX has been largely succeeded in new workflows by BibLaTeX with the Biber backend, which supports Unicode and richer entry types, while the original BibTeX remains widely used. Reference managers such as Zotero, Mendeley, and JabRef can import and export the BibTeX format.
