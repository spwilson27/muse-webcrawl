ZIP is an archive file format that supports lossless data compression. A ZIP file may contain one or more files or directories that may have been compressed. The ZIP file format permits a number of compression algorithms, though DEFLATE is the most common. This format was originally created in 1989 and was first implemented in PKWARE, Inc.'s PKZIP utility, as a replacement for the previous ARC compression format. The ZIP format is supported by many software utilities and is built into Microsoft Windows and macOS; it also underlies formats such as JAR, Office Open XML (.docx, .xlsx) and EPUB.

History

The format was designed by Phil Katz of PKWARE in 1989, following a legal dispute with System Enhancement Associates over the ARC format. Katz released the ZIP specification into the public domain via the APPNOTE.TXT document, encouraging interoperability. The format's name was chosen to imply speed — "zip" meaning move quickly.

Design

ZIP files are archives that store multiple entries. Each entry is preceded by a local file header with metadata, followed by the (optionally compressed) file data. A central directory at the end of the archive lists all entries and their offsets, allowing programs to read the archive's contents without scanning the whole file. The format supports file attributes, comments, digital signatures, and encryption — traditionally the weak ZipCrypto and, in later extensions, strong AES encryption.

Compression methods

The most commonly used method is DEFLATE, the same algorithm used by gzip. Other supported methods include BZIP2, LZMA, WavPack and PPMd in various implementations. Files can also be stored without compression.

ZIP64 and limits

The original format limited files and archives to 4 GiB. The ZIP64 extension, introduced in 2001, extended these limits to 16 EiB, enabling modern large archives.

Related formats

Many file formats are ZIP archives with a specific internal structure, including Java JAR files, Android APK packages, Microsoft Office Open XML documents, OpenDocument (which uses a closely related structure), and EPUB e-books.
