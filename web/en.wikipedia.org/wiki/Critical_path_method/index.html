Critical path method

The critical path method (CPM), or critical path analysis (CPA), is an algorithm for scheduling a set of project activities and is commonly used in project management. It identifies the longest sequence of dependent activities — the critical path — which determines the shortest possible duration of the whole project. Any delay to an activity on the critical path delays the project itself.

Method

The method requires a list of all activities, the duration of each, and the dependencies between them. A forward pass computes each activity's earliest start and finish; a backward pass computes the latest start and finish that do not delay the project. The difference between latest and earliest times is the float (or slack); activities with zero total float lie on the critical path. Crashing shortens the schedule by adding resources to critical activities, while fast-tracking overlaps activities normally done in sequence.

History

CPM was developed in 1957 by Morgan R. Walker of DuPont and James E. Kelley Jr. of Remington Rand for scheduling chemical-plant construction and maintenance shutdowns. In parallel, the U.S. Navy developed the related probabilistic PERT technique (1958) for the Polaris missile programme. The two methods have since converged in practice and are built into standard project-management software.

Criticism and extensions

CPM assumes activity durations are known and resources unlimited; extensions such as the critical chain method add resource constraints and buffers. Stochastic approaches (PERT, Monte Carlo simulation) model duration uncertainty. Despite these refinements, the critical path remains the core scheduling concept in construction, engineering, software and event planning.
