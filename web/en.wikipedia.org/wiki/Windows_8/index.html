Windows 8 is a major release of the Windows NT operating system developed by Microsoft. It was released to manufacturing on August 1, 2012, and made generally available on October 26, 2012. Windows 8 introduced major changes to the platform, emphasizing touchscreen input through a new tile-based Start screen and the "Metro" design language.

Features

Windows 8 replaced the traditional Start menu with a full-screen Start screen of live tiles, introduced the Windows Store for distributing "Windows Store apps" that ran in a sandboxed environment, and added support for the ARM architecture through Windows RT. Other additions included native USB 3.0 support, a new File Explorer ribbon interface, integrated antivirus (Windows Defender), and faster startup via hybrid boot.

Reception

The removal of the Start button and the emphasis on touch interfaces on traditional desktop PCs drew substantial criticism, although performance improvements and the updated file operations were praised. Microsoft responded with Windows 8.1 in 2013, which restored a Start button and allowed booting directly to the desktop. Mainstream support for Windows 8 ended in 2016, with users directed to upgrade to 8.1 or later.
