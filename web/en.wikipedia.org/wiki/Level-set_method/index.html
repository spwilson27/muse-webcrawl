Level-set method

The level-set method is a conceptual framework for using level sets as a tool for numerical analysis of surfaces and shapes. Developed by Stanley Osher and James Sethian in 1988, it represents an evolving curve or surface implicitly as the zero level set of a higher-dimensional function, allowing topological changes such as merging and splitting to be handled naturally.

Overview

Rather than tracking marker points on a moving front, the method embeds the front in a function φ(x, t), usually a signed distance function. The front is the set where φ = 0. Its motion is governed by a Hamilton–Jacobi-type partial differential equation, φt + F|∇φ| = 0, where F is the speed of the front in its normal direction, which may depend on curvature, external forces, or image data.

Advantages and implementation

Because the front is implicit, cusps, corners, and changes in topology require no special bookkeeping, and geometric quantities such as normals and curvature are computed directly from φ. Numerical schemes use upwind finite differences and fast time-stepping methods; narrow-band techniques restrict computation to a tube around the front, and the fast marching method solves related static problems. Periodic reinitialisation keeps φ close to a signed distance function.

Applications

Level-set methods are used in image segmentation (including active contours), fluid dynamics (tracking interfaces between phases), computer graphics (water, fire, and smoke simulation), materials science (crystal growth, etching), and shape optimisation in engineering design.
