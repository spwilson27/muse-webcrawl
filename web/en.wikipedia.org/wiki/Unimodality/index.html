Unimodality

In statistics, a unimodal probability distribution is a probability distribution with a single mode — loosely, a distribution with a single peak. The term "mode" here can refer to the most likely value of a discrete distribution or the point of maximum density of a continuous distribution.

Unimodal functions

A function f(x) is called unimodal if, for some value m (the mode), it is monotonically increasing for x ≤ m and monotonically decreasing for x ≥ m. Many common distributions are unimodal, including the normal, exponential, Poisson, binomial (in typical parameter ranges) and uniform distributions (weakly). Distributions with two or more modes are called bimodal or multimodal.

Properties and applications

Unimodality is useful in inequalities such as the Gauss inequality and the Vysochanskij–Petunin inequality, which bound deviations from the mode for unimodal distributions. In optimisation, unimodality of an objective function on an interval guarantees that local search methods such as ternary search can find the global maximum or minimum.
