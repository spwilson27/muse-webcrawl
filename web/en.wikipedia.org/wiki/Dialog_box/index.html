Dialog box

A dialog box (also spelled dialogue box) is a graphical control element in the form of a small window that communicates information from an application to the user and prompts them for a response. Dialog boxes present options through controls such as buttons, checkboxes, radio buttons, and text fields.

Modal and modeless

A modal dialog blocks interaction with the rest of the application until it is dismissed — used for alerts, confirmations ("Do you want to save changes?"), and critical choices. A modeless dialog remains open while the user continues working in the main window, as in find-and-replace or formatting palettes. Application-modal and system-modal variants differ in scope of the block.

Common dialog boxes

Standard dialogs provided by operating systems include file open/save pickers, print dialogs, color and font choosers, and message boxes. Design guidelines discourage overuse of modal alerts because they interrupt workflow; modern interfaces often prefer inline messages, undo facilities, or non-modal notifications for non-critical information.
