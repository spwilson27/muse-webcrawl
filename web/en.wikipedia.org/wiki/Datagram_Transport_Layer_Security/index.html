Datagram Transport Layer Security

Datagram Transport Layer Security (DTLS) is a communications protocol providing security for datagram-based applications by allowing them to communicate in a way designed to prevent eavesdropping, tampering, or message forgery. The DTLS protocol is based on the stream-oriented Transport Layer Security (TLS) protocol and provides similar guarantees, while tolerating the packet loss and reordering of underlying transports such as UDP.

Versions

DTLS 1.0 (RFC 4347, 2006) was based on TLS 1.1; DTLS 1.2 (RFC 6347, 2012) corresponds to TLS 1.2; and DTLS 1.3 (RFC 9147, 2022) aligns with TLS 1.3, reducing handshake latency and removing obsolete cryptography. Unlike TLS, DTLS uses explicit sequence numbers and retransmission timers to survive packet loss, and datagrams must fit within a single packet to avoid IP fragmentation issues.

Uses

DTLS is widely used in WebRTC for securing media (as DTLS-SRTP) and data channels, in VPN clients, in secure VoIP, and in the CoAP protocol for constrained Internet-of-things devices.
