Docker is a set of platform as a service products that use operating-system-level virtualisation to deliver software in packages called containers. Containers are isolated from one another and bundle their own software, libraries and configuration files, communicating through well-defined channels. Because containers share the host operating system's kernel, they are lighter than virtual machines.

History

Docker was released as open source in March 2013 by dotCloud, a platform-as-a-service company founded by Solomon Hykes, which renamed itself Docker, Inc. It built on Linux kernel features such as cgroups and namespaces, and initially on LXC before adopting its own library, libcontainer. Docker popularised the modern container format and image-based workflow, profoundly influencing cloud-native development and microservices architecture.

Components

The Docker daemon (dockerd) manages images, containers, networks and volumes; the Docker client communicates with it via a REST API. Images are built from instructions in a Dockerfile and distributed through registries such as Docker Hub. Docker Compose defines multi-container applications, and Docker Swarm provides built-in orchestration, though Kubernetes became the dominant orchestrator.

Licensing

In 2021 Docker changed the terms of Docker Desktop for larger organisations to require paid subscriptions, prompting some users to alternatives such as Podman and containerd.
