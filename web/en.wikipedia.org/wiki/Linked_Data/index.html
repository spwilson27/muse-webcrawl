Linked data

In computing, linked data is structured data that is interlinked with other data so it becomes more useful through semantic queries. It builds upon standard Web technologies such as HTTP, RDF and URIs, but rather than using them to serve web pages only for human readers, it extends them to share information in a way that can be read automatically by computers. This enables data from different sources to be connected and queried, forming part of the vision of the Semantic Web.

The Linking Open Data cloud diagram, showing datasets published in linked data format.

Principles

In 2006, Tim Berners-Lee set out four principles of linked data:

  1. Use URIs as names for things.
  2. Use HTTP URIs so that people can look up those names.
  3. When someone looks up a URI, provide useful information, using the standards (RDF, SPARQL).
  4. Include links to other URIs, so that they can discover more things.

Berners-Lee later proposed a five-star rating scheme encouraging publishers to make data openly licensed, structured, in non-proprietary formats, identified by URIs, and linked to other datasets.

Linked open data

Linked open data is linked data released under an open licence. Major public datasets include DBpedia, extracted from Wikipedia; Wikidata, the Wikimedia Foundation's knowledge base; and GeoNames for geographical data. Governments and libraries increasingly publish catalogues and statistics as linked open data.
