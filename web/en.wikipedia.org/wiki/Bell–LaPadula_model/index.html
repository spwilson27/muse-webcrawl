Bell–LaPadula model

The Bell–LaPadula model (BLP) is a state machine model used for enforcing access control in government and military applications, developed by David Elliott Bell and Leonard J. LaPadula at MITRE Corporation in the 1970s for the United States Department of Defense. It focuses on data confidentiality and access to classified information, in contrast to the Biba model, which emphasises integrity.

Principles

The model assigns each subject (user or process) a security clearance and each object (file or resource) a security classification, forming a lattice of levels. It is defined by two mandatory access control properties:

  • Simple security property — "no read up": a subject can read an object only if the subject's clearance dominates the object's classification.
  • Star (*) property — "no write down": a subject can write to an object only if the object's classification dominates the subject's clearance, preventing information from flowing from high to low levels.

A third, discretionary security property governs access via an access matrix. The Basic Security Theorem states that a system is secure if its initial state is secure and every state transition preserves these properties.

Limitations

The model does not address covert channels, integrity, or changes of classification (it assumes tranquillity — that labels do not change). Practical systems such as multilevel secure operating systems and the security modes of SELinux have nonetheless been strongly influenced by BLP.
