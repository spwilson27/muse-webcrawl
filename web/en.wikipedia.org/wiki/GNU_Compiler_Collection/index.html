The GNU Compiler Collection (GCC) is a collection of compilers from the GNU Project that support various programming languages, hardware architectures and operating systems. The Free Software Foundation (FSF) distributes GCC as free software under the GNU General Public License (GNU GPL). GCC is a key component of the GNU toolchain which is used for most projects related to GNU and the Linux kernel. With roughly 15 million lines of code in 2019, GCC is one of the largest free programs in existence.

GCC was originally called the GNU C Compiler and, as its name suggests, it handled only the C programming language. GCC 1.0 was released in 1987 and was extended to compile C++ in December of that year. Front ends were later developed for Objective-C, Objective-C++, Fortran, Ada, D, Go, Rust and Modula-2, among others. The OpenMP and OpenACC specifications are also supported in the C and C++ compilers.

History

In 1983, Richard Stallman announced the GNU Project and began work on the tools needed to build a free Unix-like operating system. After an earlier attempt at a compiler based on his Pastel compiler stalled, Stallman wrote GCC almost from scratch; the first release, GCC 1.0, appeared on 22 March 1987 and was immediately notable for its high-quality code generation and portability.

In 1997, frustration with the slow pace of official development led a group of developers to create a fork called EGCS (Experimental/Enhanced GNU Compiler System). The EGCS project proved so successful that in April 1999 the FSF made it the official version of GCC, and development has since proceeded under a steering committee with annual major releases.

Design

GCC follows a modular design in which a language-specific front end parses source code into a generic tree representation (GENERIC), which is then lowered into the GIMPLE intermediate representation for high-level optimisations. A middle end performs architecture-independent optimisations, after which the code is translated into RTL (Register Transfer Language) for low-level, target-specific optimisation and final machine-code generation by a back end.

GCC can act as a cross-compiler for a wide range of processors including ARM, x86, PowerPC, RISC-V, SPARC and MIPS, and it is the standard compiler for most Linux distributions and many embedded systems.

Languages

As of recent releases, GCC includes front ends for C (gcc), C++ (g++), Objective-C, Objective-C++, Fortran (gfortran), Ada (GNAT), Go (gccgo), D (gdc), Modula-2 (gm2) and Rust (gccrs, under development). Many more languages were supported historically or are available through third-party front ends.
