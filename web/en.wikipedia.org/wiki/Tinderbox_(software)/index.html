Tinderbox (software)


Tinderbox's map view for visual note organization

Tinderbox is a personal content management and note-taking application for macOS developed by Eastgate Systems. Designed by Mark Bernstein, it stores notes as small text items that can be linked, organized spatially on maps, and annotated with attributes, prototypes, and rules. It is widely used by writers, researchers, and analysts for organizing complex bodies of information.

Features

Tinderbox represents information as notes arranged in hierarchies and visual maps, allowing users to see relationships emerge spatially. Notes carry user-defined attributes, and "agents" continuously search and collect notes matching queries, while rules and stamps can transform notes automatically. Content can be exported to HTML, XML, plain text, and other formats, making the program a flexible tool for building websites, timelines, and research archives. The software has a long history in the hypertext community and is a prominent example of a tool for thought.
