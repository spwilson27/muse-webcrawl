In computer science, string-searching algorithms, sometimes called string-matching algorithms, are an important class of string algorithms that try to find a place where one or several strings (also called patterns) are found within a larger string or text. Formally, given a text of length n and a pattern of length m, the task is to report all starting positions at which the pattern occurs in the text.

Naive search

The simplest approach aligns the pattern at every position of the text and compares characters one by one. It requires no preprocessing and constant extra space, but its worst-case running time is O(n·m), which occurs, for example, when searching for many repetitions of a character followed by a mismatch.

Classic algorithms

Knuth–Morris–Pratt (1977)

The Knuth–Morris–Pratt (KMP) algorithm preprocesses the pattern into a "failure function" recording, for each prefix, the longest proper border. This lets the search skip ahead on a mismatch without re-examining text characters, guaranteeing O(n + m) time.

Boyer–Moore (1977)

The Boyer–Moore algorithm compares the pattern from right to left and uses "bad character" and "good suffix" heuristics to skip large portions of the text, often achieving sublinear performance in practice. Its simplified variant, Boyer–Moore–Horspool, is widely used in library implementations of memmem-style searches.

Rabin–Karp (1987)

Rabin–Karp uses rolling hash functions to compare the pattern's hash with hashes of text windows, verifying candidate matches character by character. It is especially useful for multiple-pattern search, where many patterns of the same length can be sought simultaneously.

Finite-automaton and multiple-pattern methods

The Aho–Corasick algorithm (1975) builds a trie with failure links to find all occurrences of a dictionary of patterns in a single pass, and underpins intrusion-detection and antivirus scanning tools. Algorithms based on suffix arrays, suffix trees and the Burrows–Wheeler transform (as in FM-indexes) support fast repeated queries over static texts.

Applications

String searching is fundamental to text editors, search engines, plagiarism detection, bioinformatics (searching DNA and protein sequences), network security, and spell checking.
