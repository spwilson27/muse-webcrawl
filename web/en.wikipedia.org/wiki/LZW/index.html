Lempel–Ziv–Welch

Lempel–Ziv–Welch (LZW) is a universal lossless data compression algorithm created by Abraham Lempel, Jacob Ziv and Terry Welch. It was published by Welch in 1984 as an improved implementation of the LZ78 algorithm published by Lempel and Ziv in 1978. The algorithm is simple to implement and can achieve high throughput in hardware implementations.

How it works

LZW builds a dictionary (string table) of sequences it has encountered. The encoder initialises the dictionary with all single characters, then repeatedly finds the longest string in the dictionary that matches the upcoming input, outputs that string's code, and adds the string plus the next character as a new dictionary entry. The decoder can reconstruct the identical dictionary from the codes alone, so no table needs to be transmitted. Codes are typically emitted in increasing widths, up to a maximum (often 12 bits), after which the table may be frozen or reset.

Uses and patents

LZW became extremely widely used: it is the compression method of the GIF image format, was used in the TIFF format, and in the Unix compress utility and early modems (V.42bis). Welch's patent, held by Unisys, became controversial when Unisys began asserting licensing fees against GIF-using software in the 1990s — a dispute that helped spur creation of the patent-free PNG format. The LZW patents expired in 2003–2004, leaving the algorithm free for all uses.
