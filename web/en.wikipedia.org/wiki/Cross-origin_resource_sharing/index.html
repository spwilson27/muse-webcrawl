Cross-origin resource sharing

Cross-origin resource sharing (CORS) is a mechanism that allows restricted resources on a web page to be requested from another domain outside the domain from which the first resource was served. It defines a way for a browser and server to interact to determine whether it is safe to allow a cross-origin request, relaxing the same-origin policy in a controlled manner.

How it works

Servers signal permission with HTTP response headers such as Access-Control-Allow-Origin. For requests that may have side effects, the browser first sends a "preflight" OPTIONS request to check the server's CORS policy before sending the actual request. Simple requests — for example GET requests with only safelisted headers — skip preflight.

History and standardisation

CORS grew out of work begun by the Voice Browser working group and was standardised by the W3C; it is now maintained as part of the WHATWG Fetch standard and is implemented by all major browsers.
