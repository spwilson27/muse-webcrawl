Buffer (computer science)

Data flowing through a buffer between producer and consumer

In computer science, a buffer is a region of memory used to temporarily store data while it is being moved from one place to another. Buffers are used when there is a difference in the rate at which data is received and the rate at which it can be processed, or when data must be adapted between devices or processes with different timing or block sizes.

Uses

Buffers are ubiquitous. Operating systems buffer disk I/O so that programs can read and write in convenient block sizes while the disk works at its own speed; network stacks buffer packets to smooth out bursty traffic; video players buffer several seconds of media so playback continues through brief network stalls; and graphics pipelines use frame buffers to hold the image being displayed.

Types

Common buffer organisations include the ring buffer (circular buffer), in which a fixed-size array is treated as a loop with separate read and write pointers, widely used in streaming and embedded systems; the double buffer, used in graphics to avoid tearing by drawing into a back buffer while the front buffer is displayed; and the queue used between producer and consumer threads, often with blocking or lock-free synchronisation.

Buffer overflow

Writing more data into a buffer than it can hold is a buffer overflow, a classic software bug and a major class of security vulnerability, since overflowing data can overwrite adjacent memory, including return addresses on the stack. Modern defences include bounds checking, canaries, non-executable stacks and address-space layout randomisation.
