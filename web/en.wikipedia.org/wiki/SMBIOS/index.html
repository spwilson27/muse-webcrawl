SMBIOS

Name: System Management BIOS
Maintainer: DMTF (Distributed Management Task Force)
Purpose: Hardware inventory data format for firmware

The System Management BIOS (SMBIOS) specification defines data structures (and access methods) that allow a user or application to store and retrieve information about a computer's hardware, such as the manufacturer, model, serial numbers, and installed memory devices.

Overview

SMBIOS is produced by the system firmware (BIOS/UEFI) and consumed by the operating system and management software. It supersedes the earlier Desktop Management Interface (DMI) specification, and is maintained by the DMTF. On Linux, tools such as dmidecode read the SMBIOS tables; on Windows, the data is exposed through WMI.

Structures

The tables are organised as typed structures, including Type 0 (BIOS information), Type 1 (system information), Type 2 (baseboard), Type 3 (chassis), Type 4 (processor), and Type 17 (memory device). Version 3.x extended addressing and added support for newer hardware.
