MP4 (formally MPEG-4 Part 14) is a digital multimedia container format most commonly used to store video and audio, but which can also store subtitles and still images. It is one of the most widely used formats for streaming and distributing video over the Internet, supported by virtually all modern devices and media players.

MP4 is based on the ISO base media file format and is closely related to Apple's QuickTime file format, from which it was derived. Like its predecessor, it organizes data into a hierarchy of boxes (historically called "atoms"), including a movie box (moov) containing metadata and media data boxes (mdat) containing the actual samples.

History

The first version of the specification was published in 2001 as part of MPEG-4 (ISO/IEC 14496-1:2001); a revised version followed in 2003 as MPEG-4 Part 14. MP4 files typically carry video encoded with H.264/AVC or H.265/HEVC and audio encoded with AAC, though the container can hold many other codecs. Variants include .m4a (audio-only), .m4v (Apple video), .m4p (FairPlay DRM-protected audio), and .3gp, a simplified mobile profile derived from the same base format.

Technical details

An MP4 file consists of a file type box (ftyp) followed by structured boxes. Tracks describe individual video, audio, hint (streaming), subtitle, or metadata streams, each with timing, sample tables, and references into the media data. Because metadata can be placed at the start of the file ("fast start"), MP4 supports progressive download and streaming over HTTP. MP4 also underlies newer streaming technologies: fragmented MP4 (fMP4) is the container used by MPEG-DASH and Apple's HLS for adaptive streaming.
