Product key

From Wikipedia, the free encyclopedia

A product key, also called a licence key, activation key or CD key, is a specific software-based key used to certify that a copy of a program is original. It is typically a sequence of letters and digits, grouped for readability, such as XXXXX-XXXXX-XXXXX-XXXXX-XXXXX, which the user enters during installation or activation; the program verifies it algorithmically or against an online server before enabling full use.

History

Product keys spread with commercial PC software in the 1990s, notably Microsoft Windows and Office, whose keys were printed on certificates of authenticity and CD jewel cases. Verification evolved from simple checksum algorithms in the key itself, to online product activation (introduced with Windows XP in 2001), which binds the key to a hardware fingerprint, and to digital licences stored in firmware or tied to user accounts.

Verification

Offline keys often embed check digits so that random strings almost always fail. Online activation sends the key (and a hardware identifier) to the vendor, which can limit the number of installations and detect widely leaked keys. Key generators ("keygens") that reverse-engineer the algorithm have long been a target of vendors' anti-piracy efforts, as have leaked volume-licence keys sold by unauthorised "grey market" resellers.

Modern practice

Subscription licensing and app stores have reduced reliance on typed keys, but product keys remain common for games (redeemed on platforms such as Steam), enterprise software and OEM Windows installations.
