Constructor (object-oriented programming)

In class-based object-oriented programming, a constructor (abbreviation: ctor) is a special type of function called to create an object. It prepares the new object for use, often accepting arguments that the constructor uses to set required member variables. A constructor resembles an instance method, but it differs in that it has no explicit return type, is not implicitly inherited, and usually has different rules for scope modifiers.

KindSpecial member function
PurposeObject initialization
CounterpartDestructor

Types

Common varieties include the default constructor, which takes no arguments; the parameterized constructor, which accepts arguments to initialise fields; the copy constructor, which creates an object from another object of the same class; and, in C++11 and later, the move constructor. Languages differ: Java and C# constructors share the name of the class, Python uses the __init__ method after the __new__ allocator, and JavaScript historically used constructor functions with the new operator before class syntax was added.

Example

public class Point {
    private final int x;
    private final int y;

    // Constructor
    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }
}

Constructor chaining and inheritance

In many languages a constructor can invoke another constructor of the same class or of the superclass, a practice called constructor chaining. Because constructors are not inherited, a subclass must explicitly call an appropriate superclass constructor to initialise inherited state.
