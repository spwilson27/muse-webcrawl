Game Genie

Game Genie
Type: Cheat cartridge / game enhancer
Developer: Codemasters
Distributor: Galoob (North America)
Released: 1990 (NES version)
Platforms: NES, SNES, Game Boy, Genesis, Game Gear

The Game Genie is a series of cheat systems designed by Codemasters and sold by Galoob (and in Canada by Camerica) for several video game consoles. By entering codes, players could modify game data — for example gaining extra lives, invincibility, or skipping levels. The first device, for the Nintendo Entertainment System, was released in 1990.


The Game Genie for the NES

Design and function

The Game Genie is a pass-through cartridge that sits between the game cartridge and the console. It intercepts data read from the game's ROM and substitutes modified values according to codes entered by the user, which encode a memory address and a replacement value. Versions followed for the Super NES, Game Boy, Sega Genesis and Game Gear.

Legal history

Nintendo attempted to stop the device, but in Lewis Galoob Toys, Inc. v. Nintendo of America, Inc. (1992) the US Court of Appeals for the Ninth Circuit held that using the Game Genie did not create an infringing derivative work. Nintendo later designed some NES revisions to resist the device.

Legacy

The Game Genie was succeeded by later cheat devices such as the GameShark and Action Replay. The brand was revived in the 2010s for save-editing products for modern consoles.
