Release engineering

Release engineering, frequently abbreviated RelEng, is a sub-discipline of software engineering concerned with the compilation, assembly and delivery of source code into finished, deployable products. The release engineer builds and maintains the infrastructure — build systems, continuous integration pipelines, packaging, signing and distribution — that turns developers' code into releases.

Role

Tasks include managing version control branching and code freezes, automating builds and tests, producing release candidates, and ensuring that builds are reproducible. Modern practice overlaps with DevOps and site reliability engineering, emphasising automation, continuous delivery and rapid, low-risk releases. The field has a professional literature and conferences; the term is sometimes credited to practitioners at Bell Labs in the 1980s. Release management, a related IT service-management discipline, covers the planning and scheduling of releases more broadly.
