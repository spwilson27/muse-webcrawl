SteamOS is a Linux distribution developed by Valve Corporation and designed primarily for video gaming. It was announced in September 2013 as the operating system for Valve's Steam Machines initiative — pre-built living-room PCs from third-party manufacturers — and released in beta that December alongside prototype hardware. The original versions were based on Debian Linux and ran the Steam client in its television-oriented Big Picture mode.

History

Steam Machines failed to gain significant market share, and by 2018 Valve had quietly wound the program down; SteamOS development went largely dormant in public. However, Valve kept investing in Linux gaming compatibility through the Proton compatibility layer (released 2018), which allows Windows games to run on Linux — an effort that made a revived SteamOS viable.

SteamOS 3.0, rebuilt on Arch Linux with a KDE Plasma desktop mode and an immutable, image-based update system, shipped with the Steam Deck handheld PC in February 2022. It defaults to a console-like "Game Mode" built around the Steam library, while a full desktop is one menu away. Updates are delivered as atomic system images with rollback support. Valve has stated its intent to release SteamOS 3.0 for general installation beyond the Steam Deck, and versions have shipped on third-party handhelds such as the Lenovo Legion Go S.

Features

SteamOS integrates the Steam store, library, and community features; supports the Gamescope Wayland compositor and session for consistent frame pacing; and includes Proton, DXVK, and VKD3D for running Windows titles. Because the system is read-only by default, it is resistant to corruption, though users can enable developer mode for full system modification.
