C++ Standard Library

From Wikipedia, the free encyclopedia

The C++ Standard Library is the collection of classes, functions, and templates specified by the ISO C++ standard, available to every conforming C++ program. It incorporates the Standard Template Library (STL) — containers, iterators, algorithms, and function objects — along with input/output streams, strings, numerics, localisation, threading support, and much of the C standard library.

Contents

Major components include sequence containers such as std::vector, std::list, and std::deque; associative containers such as std::map and std::set; generic algorithms for searching, sorting, and transformation; smart pointers and utilities; regular expressions; and, in later standards, concurrency facilities, ranges, and modules support.

History

The library was defined with the first ISO C++ standard in 1998, drawing heavily on Alexander Stepanov's STL from Hewlett-Packard. Subsequent standards (C++11, C++14, C++17, C++20, C++23) greatly expanded it. Well-known implementations include those shipped with GCC (libstdc++), Clang (libc++), and Microsoft Visual C++.
