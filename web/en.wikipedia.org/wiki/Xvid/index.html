Xvid

Xvid (formerly "XviD") is a video codec library following the MPEG-4 video coding standard, specifically MPEG-4 Part 2 Advanced Simple Profile (ASP). It is free software distributed under the GNU General Public License. Xvid became one of the most widely used codecs for compressing video files shared over the internet in the 2000s, typically inside AVI containers.

History

Xvid originated in 2001 from the OpenDivX project of DivXNetworks. When DivXNetworks took its codec proprietary as DivX 5, the last open version of the OpenDivX encoder was forked by independent developers into Xvid — the name is "DivX" spelled backwards. A later controversy arose when Sigma Designs was found to have used Xvid code in its REALmagic MPEG-4 codec without credit; Sigma subsequently released the code under the GPL. Xvid development produced successive releases improving compression features such as B-frames, quarter-pixel motion estimation, global motion compensation and custom quantisation matrices. The "DivX Certified" hardware players of the era generally also played Xvid files.

Patent issues

Like other MPEG-4 implementations, Xvid implements techniques covered by patents in some jurisdictions, so while the source code is freely available, distributors of compiled binaries may need patent licences — a common caveat with free codec projects. Its popularity declined in the 2010s as H.264 and later codecs became standard.
