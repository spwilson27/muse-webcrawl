Live USB

A bootable USB flash drive containing a live operating system

A live USB is a portable USB storage device — typically a USB flash drive or external hard drive — that contains a complete bootable operating system (a "live" system). When connected to a computer, the machine can be booted from the USB device, running the operating system without installing anything on the internal disk or altering the installed system.

Characteristics

Live USBs are the successor to live CDs and DVDs, offering much higher read and write speeds, greater capacity, and the ability to store data persistently. By default many live systems load into RAM and discard changes on shutdown, but most distributions support a persistence feature — a writable overlay (often a file or partition, e.g. casper-rw on Ubuntu-based images) that preserves files, settings, and installed packages between boots.

Uses

  • Trying out a Linux distribution before installing it.
  • Installing operating systems, including on machines without optical drives.
  • System rescue and repair: recovering files from a machine that will not boot, resetting passwords, partitioning disks, and removing malware.
  • Privacy and forensics: amnesic distributions such as Tails run entirely from USB and leave no trace on the host machine.
  • Portable work environments carried between computers.

Creation

Live USBs are created by writing a distribution's hybrid ISO image to a USB device with tools such as Rufus, balenaEtcher, Ventoy, UNetbootin, or the Unix dd command. Ventoy and similar multi-boot loaders allow several images to coexist on one drive. Booting requires the target machine's firmware (BIOS or UEFI) to be set to boot from USB, and Secure Boot may require signed bootloaders.

Comparison with live CDs

USB media offer faster boot times and random-access performance, silent operation, persistence, and capacities far beyond optical discs; modern desktops and laptops since the late 2000s can almost universally boot from USB. Drawbacks include slower write endurance of cheap flash memory and the risk of the device being altered or infected when used on untrusted machines.
