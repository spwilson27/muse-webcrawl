Kernel (operating system)

Kernel
TypeCore component of an operating system
ArchitecturesMonolithic, microkernel, hybrid, exokernel
ExamplesLinux kernel, Windows NT kernel, XNU (macOS), Mach

The kernel is a computer program at the core of a computer's operating system and generally has complete control over everything in the system. It is the portion of the operating system code that is always resident in memory, and it facilitates interactions between hardware and software components.

Functions

The kernel manages the system's resources: it schedules processes and threads on the CPU, manages memory (including virtual memory and paging), handles interrupts and device drivers, and provides system calls through which user programs request services such as file access, networking and process creation. It enforces the separation between privileged kernel space and user space, protecting stability and security.

Designs

  • Monolithic kernels run all operating system services in kernel space (e.g. Linux, traditional Unix), offering performance at the cost of a large trusted codebase.
  • Microkernels (e.g. Minix, Mach, L4) run only basic functions—scheduling, memory management and inter-process communication—in the kernel, with drivers and services in user space, improving modularity and fault isolation.
  • Hybrid kernels (e.g. Windows NT, XNU in macOS) combine aspects of both.
  • Exokernels expose hardware resources almost directly to applications.

Criticality

Because the kernel runs with full privileges, a bug can crash the whole system (a "kernel panic" on Unix-like systems, or the "Blue Screen of Death" historically on Windows). Modern development focuses on modular loadable components, verified microkernels such as seL4, and moving drivers out of the privileged core.
