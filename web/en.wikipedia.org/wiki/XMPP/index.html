XMPP

XMPP
Full name: Extensible Messaging and Presence Protocol
Type: Communication protocol
Standardized: IETF RFC 6120, RFC 6121 (2011)
Port: 5222 (client), 5269 (server)

XMPP (Extensible Messaging and Presence Protocol) is an open communication protocol designed for instant messaging (IM), presence information, and contact list maintenance. Based on XML, it enables the near-real-time exchange of structured data between two or more network entities. Originally named Jabber, the protocol was developed by the open-source community starting in 1998 and formalized by the IETF.

Architecture

XMPP uses a decentralized client–server architecture similar to email: users connect to their home server, and servers federate with one another, so anyone can run a server and interoperate with the public network. Addresses, called Jabber IDs (JIDs), look like email addresses, e.g. user@example.org. Core XML building blocks are the stanzas <message/>, <presence/>, and <iq/> (info/query).

Extensions

The base protocol is extended by XMPP Extension Protocols (XEPs) maintained by the XMPP Standards Foundation, adding features such as multi-user chat (MUC), publish–subscribe, file transfer, voice and video signaling (Jingle), and end-to-end encryption via OMEMO. XMPP has powered or underpinned major services historically including Google Talk, Facebook Chat's former interface, and WhatsApp's modified internal variant, and it remains used in IoT, gaming, and enterprise messaging.
