Kotlin is a cross-platform, statically typed, general-purpose programming language with type inference, developed by JetBrains. It is fully interoperable with Java and the Java Virtual Machine ecosystem while offering a more concise and safer syntax. Since 2019 it has been Google's preferred language for Android app development.

History

JetBrains, whose development teams are largely based in St. Petersburg, began Kotlin in 2010 seeking a modern alternative to Java for its own codebase; the language was unveiled in 2011 and named after Kotlin Island in the Gulf of Finland. Version 1.0 was released in February 2016. At Google I/O 2017 Kotlin received first-class support for Android, and in 2019 Google declared Android development "Kotlin-first"; the great majority of professional Android applications now use it. Kotlin development was transferred to the non-profit Kotlin Foundation, founded by JetBrains and Google.

Features

Kotlin's design emphasises safety and concision: null safety is built into the type system (distinguishing nullable from non-nullable types), which largely eliminates the NullPointerException errors common in Java. It supports data classes, extension functions, lambdas and higher-order functions, smart casts, coroutines for asynchronous programming, and full bidirectional interoperability with Java code. Kotlin Multiplatform allows sharing code between JVM, Android, iOS, JavaScript, and native targets.

fun main() {
    val names = listOf("Ada", "Bjarne", "Edsger")
    names.filter { it.length > 3 }
         .forEach { println("Hello, $it!") }
}
