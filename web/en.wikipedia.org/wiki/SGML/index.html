The Standard Generalized Markup Language (SGML; ISO 8879:1986) is a standard for defining generalised markup languages for documents. Rather than being a markup language itself, SGML is a metalanguage: it specifies how to define a document type — its elements, attributes, and structure — through a document type definition (DTD), and how documents of that type are marked up with descriptive tags.

History

SGML descends from IBM's Generalized Markup Language (GML), developed in the 1960s and 1970s by Charles Goldfarb, Edward Mosher, and Raymond Lorie (their initials giving GML its name). Goldfarb led the work that produced the ISO standard, published in 1986. SGML was adopted for large-scale documentation by the U.S. Department of Defense (CALS initiative), the publishing industry, and technical-documentation communities.

Features and influence

SGML emphasises descriptive rather than procedural markup: tags identify what a part of a document is (a title, a warning, a part number) rather than how it should be formatted, so the same source can be rendered in many ways and processed by software. The language permits features such as tag omission and complex content models that made full SGML parsers difficult to write.

HTML was originally defined as an application of SGML, and XML (1998) was created as a simplified profile of SGML that could be implemented far more easily, deliberately dropping most optional features. Many concepts central to modern document technology — DTDs and schemas, validation, structured content reuse — trace directly to SGML.
