Gibbs' phase rule

Gibbs' phase rule (also called simply the phase rule), derived by Josiah Willard Gibbs in his landmark 1875–78 work On the Equilibrium of Heterogeneous Substances, relates the number of degrees of freedom of a thermodynamic system at equilibrium to the number of its components and phases:

F = C − P + 2

where F is the number of degrees of freedom (independently variable intensive properties such as temperature and pressure), C is the number of chemically independent components, and P is the number of phases in equilibrium.

Interpretation

For a pure substance (C = 1) present as liquid and vapour (P = 2), F = 1: pressure alone fixes the boiling temperature. Where three phases of a pure substance coexist — the triple point — F = 0, an invariant point. For a two-component system (such as a salt–water mixture) with one phase present, F = 3.

Applications

The phase rule underlies phase diagrams in materials science, metallurgy, geology and chemical engineering, governing alloy cooling, mineral assemblages in metamorphic rocks, and separation processes. Variants of the rule handle systems at fixed pressure (F = C − P + 1) or with chemical reactions.
