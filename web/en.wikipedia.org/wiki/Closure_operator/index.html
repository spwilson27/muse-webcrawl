Closure operator

FieldMathematics (set theory, algebra, logic)
PropertiesExtensive, monotone, idempotent

In mathematics, a closure operator on a set S is a function from the power set of S to itself that is extensive (A ⊆ cl(A)), monotone (A ⊆ B implies cl(A) ⊆ cl(B)), and idempotent (cl(cl(A)) = cl(A)).

Examples

Familiar examples include the topological closure of a set, the linear span of a set of vectors, the subgroup generated by a set in group theory, the convex hull of a set of points, and the set of logical consequences of a set of propositions.

Closed sets and algebras

Sets satisfying cl(A) = A are called closed under the operator; they form a complete lattice, and the study of such systems connects closure operators with Galois connections and abstract algebraic logic.
