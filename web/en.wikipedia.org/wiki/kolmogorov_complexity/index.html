Kolmogorov complexity

In algorithmic information theory, the Kolmogorov complexity of an object such as a piece of text is the length of the shortest computer program (in a given programming language) that produces the object as output. It is named after Andrey Kolmogorov, who first published on the subject around 1963, and was independently developed by Ray Solomonoff and Gregory Chaitin.

Definition and properties

Fixing a universal Turing machine U, the complexity K(x) of a string x is the length of the shortest program p such that U(p) = x. By the invariance theorem, different universal machines change K only by an additive constant. A string whose shortest program is nearly as long as itself is called algorithmically random, or incompressible.

Uncomputability

Kolmogorov complexity is not a computable function: no program can output the exact K(x) for arbitrary x, a fact related to the Berry paradox and the halting problem. Chaitin's incompleteness theorem limits how much complexity any formal system can certify.

Applications

The theory underlies Solomonoff induction and minimum description length inference, gives elegant proofs in computability and combinatorics, and informs data compression, where compressed size approximates complexity.
