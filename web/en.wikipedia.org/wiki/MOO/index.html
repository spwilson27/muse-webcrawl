MOO

A text-based MOO session

A MOO (MUD, object-oriented) is a text-based online virtual reality system to which multiple users (players) are connected at the same time. MOOs descend from MUDs (multi-user dungeons) but are distinguished by being built around an object-oriented internal database and programming language that lets users create and program their own rooms, objects and commands.

History

The first MOO software was written by Stephen White in 1990, inspired by the programming capabilities of TinyMUD-style systems. Pavel Curtis at Xerox PARC developed the influential LambdaMOO server and launched the LambdaMOO virtual community, which became a famous early experiment in online society — famously chronicled in Julian Dibbell's 1993 essay "A Rape in Cyberspace". Other notable MOOs included MediaMOO, designed for media researchers, and educational worlds such as Diversity University.

Technology and use

Users connect via Telnet or dedicated clients and interact by typing commands in a shared textual world. Objects are defined in a persistent database and programmed in a language such as MOOcode; administrators ("wizards") manage permissions. MOOs were widely used in the 1990s for education, academic conferencing and social interaction, and although largely superseded by graphical worlds and the web, some communities remain active.
