Network analysis (electrical circuits)

From Wikipedia, the free encyclopedia

In electrical engineering, network analysis is the process of finding the voltages across, and the currents through, all of the components in an electrical network. There are many techniques for calculating these values; however, for the most part, the techniques assume linear components. Except where stated, the methods described in this article are applicable only to linear network analysis.

Basic concepts

A network consists of branches (components such as resistors, capacitors, inductors and sources) joined at nodes. The governing laws are Kirchhoff's circuit laws: the current law (KCL), that the algebraic sum of currents entering a node is zero, and the voltage law (KVL), that the algebraic sum of voltages around any closed loop is zero. A fundamental result is that a network with b branches and n nodes has b − n + 1 independent loop equations and n − 1 independent node equations.

Equivalent circuits

  • Series and parallel combinations of resistors, capacitors and inductors.
  • Y-Δ (star–delta) transformation, converting between three-terminal configurations.
  • Thévenin's theorem — any linear network can be replaced, at a pair of terminals, by a single voltage source in series with a resistance.
  • Norton's theorem — the dual equivalent: a current source in parallel with a resistance.
  • Source transformation between Thévenin and Norton forms.

Systematic methods

Nodal analysis

Nodal analysis assigns unknown voltages to the essential nodes (relative to a reference node) and applies KCL at each, yielding a system of simultaneous equations. It is the basis of most circuit-simulation programs such as SPICE.

Mesh analysis

Mesh analysis assigns unknown currents to the meshes (windows) of a planar network and applies KVL around each mesh. The related loop analysis uses a set of fundamental loops defined by a spanning tree of the network graph.

Superposition

The superposition theorem states that the response in a linear network with several independent sources equals the sum of the responses to each source acting alone, with the others turned off (voltage sources shorted, current sources opened).

Frequency-domain analysis

For sinusoidal steady state, components are represented by their impedance and voltages and currents by phasors, converting differential equations into algebra. For arbitrary signals, the Laplace transform gives transfer functions, poles and zeros, from which stability and transient response are read. Two-port network parameters (z, y, h and ABCD parameters) describe networks as black boxes characterised at their terminals.
