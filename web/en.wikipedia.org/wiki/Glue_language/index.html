Glue language

From Wikipedia, the free encyclopedia

Glue language
PurposeConnecting software components
Typical examplesShell scripts, Perl, Python, Tcl, Lua, AppleScript

A glue language is a programming language (usually a scripting language) used to connect software components together, writing the "glue code" that coordinates libraries, programs or subsystems typically written in other languages. Instead of implementing complex algorithms itself, a glue language excels at invoking external programs, manipulating files and text, and wiring together pre-existing components into a working system.

Characteristics

Glue languages are generally interpreted, dynamically typed, and rich in facilities for string processing, process control and inter-process communication. Unix shell languages were the original glue languages, used to combine command-line utilities with pipes and redirection. Perl grew to prominence in the 1990s as a glue language for system administration and early web (CGI) programming. Tcl was explicitly designed to be embedded in applications as a command and extension language, and Lua plays the same role today in games and embedded systems. Python, JavaScript and AppleScript are widely used to script applications and automate workflows across component boundaries, such as COM, Apple events or web APIs.

Glue code

The term "glue code" can carry a negative connotation for code that does not contribute functionality directly but is necessary to reconcile incompatible interfaces, data formats or object models — for example adapter layers between libraries. Well-chosen glue languages minimise this burden by providing foreign function interfaces, bindings and data-interchange formats such as JSON.
