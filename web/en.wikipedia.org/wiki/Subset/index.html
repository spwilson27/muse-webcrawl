Subset

In mathematics, set A is a subset of a set B if all elements of A are also elements of B; B is then a superset of A. The relationship is called inclusion or containment and is written A ⊆ B. If A is a subset of B but A is not equal to B, then A is called a proper subset of B, written A ⊊ B.

Definitions and notation

Formally, A ⊆ B if and only if for every x, if x ∈ A then x ∈ B. Every set is a subset of itself, and the empty set ∅ is a subset of every set. The set of all subsets of a given set S is called the power set of S, denoted P(S); a set with n elements has exactly 2n subsets.

Examples

The set {1, 3} is a proper subset of {1, 2, 3}; the set of even integers is a proper subset of the integers; and the integers are in turn a subset of the rational numbers, which are a subset of the real numbers. Inclusion is a partial order on sets: it is reflexive, antisymmetric, and transitive.
