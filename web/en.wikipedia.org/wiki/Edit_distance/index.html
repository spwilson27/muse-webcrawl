Edit distance

In computational linguistics and computer science, an edit distance is a string metric: a way of quantifying how dissimilar two strings are to one another by counting the minimum number of operations required to transform one string into the other. Edit distances find applications in natural language processing, where automatic spelling correction can determine candidate corrections for a misspelled word by selecting words from a dictionary that have a low distance to the word in question. In bioinformatics, it can be used to quantify the similarity of DNA sequences, which can be viewed as strings of the letters A, C, G and T.

Types of edit distance

Different types of edit distance allow different sets of string operations. The Levenshtein distance allows deletion, insertion and substitution of characters. The Damerau–Levenshtein distance additionally allows transposition of adjacent characters. The Hamming distance only allows substitutions, and therefore only applies to strings of equal length. The Jaro distance and Jaro–Winkler distance are related measures often used for record linkage.

Properties

Formally, an edit distance between two strings is a metric in the mathematical sense if it satisfies non-negativity, identity of indiscernibles, symmetry and the triangle inequality. Edit distances are commonly computed with dynamic programming algorithms, such as the Wagner–Fischer algorithm, which fills a matrix whose entries give the distances between prefixes of the two strings.

Applications

Edit distance is used in spell checkers, correction systems for optical character recognition, fuzzy string searching, plagiarism detection, and in algorithms that quantify the similarity between DNA and protein sequences. Weighted edit distances assign different costs to different operations, for example charging more for a substitution than for an insertion.
