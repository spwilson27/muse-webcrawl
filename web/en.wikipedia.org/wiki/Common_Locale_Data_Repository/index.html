Common Locale Data Repository

CLDR provides locale data for hundreds of languages and regions.

The Common Locale Data Repository (CLDR) is a project of the Unicode Consortium to provide locale data in XML format for use in computer applications. CLDR contains locale-specific information that an operating system will typically provide to applications, including number and date formats, names of languages, countries, currencies and time zones, collation orders, and translations of common strings.

Data and process

The data is expressed in Locale Data Markup Language (LDML). It is gathered and vetted through the CLDR Survey Tool, in which translators and language experts propose and vote on entries for their locales. Releases are published roughly twice a year and cover several hundred locales derived from more than 250 languages.

Users

CLDR data is used by major software libraries and platforms, including International Components for Unicode (ICU), Apple's macOS and iOS, Google's Android and ChromeOS, Microsoft Windows, and many programming language runtimes. It underpins locale-sensitive operations such as formatting dates, times and numbers, sorting text, and selecting plural rules.
