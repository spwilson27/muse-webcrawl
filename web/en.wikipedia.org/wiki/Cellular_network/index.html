Cellular network

From Wikipedia, the free encyclopedia

A cellular network or mobile network is a telecommunications network where the link to and from end nodes is wireless and the network is distributed over land areas called cells, each served by at least one fixed-location transceiver (such as a base station). These base stations provide the cell with the network coverage which can be used for transmission of voice, data, and other types of content over radio waves.

The concept of a cellular network was developed at Bell Labs in the 1940s and 1950s, principally by Douglas H. Ring and W. Rae Young, who proposed dividing a service area into small cells with low-power transmitters and reusing frequencies in non-adjacent cells. The first commercial cellular network, the Nippon Telegraph and Telephone (NTT) system in Tokyo, launched in 1979. The Nordic Mobile Telephone (NMT) system followed in 1981, and the Advanced Mobile Phone System (AMPS) in the United States in 1983.

Concept

In a cellular radio system, a land area to be supplied with radio service is divided into regular shaped cells, which can be hexagonal, square, circular or some other shapes. Each of these cells is assigned multiple frequencies (f1 – fk) which correspond to the channels of a particular base station. The group of frequencies can be reused in other cells, provided that the same frequencies are not reused in adjacent cells, which would cause co-channel interference.

The increased capacity in a cellular network, compared with a network with a single transmitter, comes from the mobile communication switching system developed by Amos Joel of Bell Labs, which permitted multiple callers in the same area to use the same frequency by switching calls made using one tower to the next as the caller traveled, a process known as handover or handoff.

Generations

Cellular technology is commonly described in generations: first-generation (1G) analog systems such as AMPS and NMT; second-generation (2G) digital systems such as GSM and IS-95 (cdmaOne), which introduced text messaging and packet data via GPRS and EDGE; third-generation (3G) systems such as UMTS and CDMA2000, designed for higher data rates; fourth-generation (4G) all-IP systems based on LTE; and fifth-generation (5G) networks using new radio interfaces and, in many deployments, millimetre-wave spectrum.

Cell types

Cells vary in size according to the expected traffic density. Macrocells cover several kilometres and serve general coverage; microcells cover a few hundred metres in dense urban areas; picocells serve indoor venues such as shopping centres; and femtocells are small, low-power cells intended for homes and offices, backhauled over a customer's broadband connection. Umbrella cells may overlay smaller cells to handle fast-moving users and reduce the number of handovers.
