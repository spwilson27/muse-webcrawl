Singular function

From Wikipedia, the free encyclopedia

In mathematics, a real-valued function f on the interval [a, b] is said to be singular if it has the following properties:

  • f is continuous on [a, b];
  • there exists a set N of Lebesgue measure 0 such that for all x outside N, the derivative f′(x) exists and equals 0 — that is, the derivative vanishes almost everywhere;
  • f is non-constant on [a, b].

Thus a singular function increases (or decreases) from f(a) to f(b) even though its derivative is zero at almost every point. All of its "growth" is concentrated on a set of measure zero. A standard example is the Cantor function (the "Devil's staircase"), which is constant on each interval removed in the construction of the Cantor set, climbs only on the Cantor set itself, and rises continuously from 0 to 1 while having derivative 0 almost everywhere.

Properties and related notions

Singular functions arise naturally in the Lebesgue decomposition theorem: every function of bounded variation can be written as the sum of an absolutely continuous part, a jump part, and a singular continuous part. A function that is both continuous and singular in the above sense is called singular continuous. Probability distributions whose cumulative distribution functions are singular continuous — such as the distribution supported on the Cantor set — are neither discrete nor absolutely continuous with respect to Lebesgue measure.

Another classical example is Minkowski's question-mark function, which maps quadratic irrationals to dyadic rationals and has derivative zero almost everywhere. Salem numbers and certain Fourier series provide further examples, and singular functions play a role in the theory of multifractals and in the spectral theory of Schrödinger operators, where singular continuous spectra occur.

Terminology

When discussing functions of a real variable, "singular" has this specific meaning. It should not be confused with the notion of a singularity of a function of a complex variable — a point at which the function is not analytic — nor with singular distributions in physics and engineering.
