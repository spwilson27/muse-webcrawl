Mir (software)

Mir is a computer display server and Wayland compositor library developed by Canonical for Linux. It was announced in 2013 as a replacement for the X Window System in Ubuntu, with the aim of supporting converged desktop, tablet and phone interfaces.

History

Mir was central to Ubuntu's Unity 8 interface and Ubuntu Touch. After Canonical ended Unity 8 development in 2017, Mir was repositioned as a library for building Wayland compositors, providing the protocol handling, input and window management plumbing so that smaller shells can be written with less code.

Use

Mir underlies Canonical's Ubuntu Frame for embedded and kiosk displays, and has been used by desktop shells such as the Lomiri environment. It is free software, licensed mainly under the GPL and LGPL.
