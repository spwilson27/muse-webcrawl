Trusted Computer System Evaluation Criteria

The TCSEC is nicknamed the "Orange Book" for its cover

The Trusted Computer System Evaluation Criteria (TCSEC), commonly known as the Orange Book, is a United States Department of Defense standard (DoD 5200.28-STD) published in 1985 that set requirements for evaluating the security effectiveness of computer systems, particularly for handling classified information. It was the centrepiece of the "Rainbow Series" of computer security publications.

Evaluation classes

The TCSEC divides systems into four divisions of increasing security assurance:

  • Division D – Minimal protection: systems that failed to meet any higher class.
  • Division C – Discretionary protection: classes C1 (discretionary security) and C2 (controlled access protection).
  • Division B – Mandatory protection: classes B1 (labelled security), B2 (structured protection) and B3 (security domains), introducing mandatory access control and increasingly rigorous design verification.
  • Division A – Verified protection: class A1, requiring formal verification of the system's design.

Legacy

The Orange Book strongly influenced the development of operating system security, encouraging features such as auditing, access control lists and trusted computing bases. It was eventually superseded internationally by the Common Criteria (ISO/IEC 15408), which combined TCSEC with European and Canadian criteria.
