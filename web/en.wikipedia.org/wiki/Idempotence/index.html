Idempotence

Idempotence is the property of certain operations in mathematics and computer science whereby they can be applied multiple times without changing the result beyond the initial application. The concept originates in abstract algebra, where an element x of a structure is idempotent under an operation if x · x = x.

Examples

In mathematics, the absolute value function is idempotent (applying it twice changes nothing), as are the floor and ceiling functions and set union/intersection with a set itself; in linear algebra, a projection matrix P satisfies P² = P. In computing, an idempotent HTTP method (such as GET, PUT or DELETE in REST design) can be safely retried without unintended side effects — a property exploited in distributed systems, deduplication and exactly-once processing designs.
