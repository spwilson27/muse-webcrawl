Hardware acceleration

Hardware acceleration is the use of computer hardware designed to perform specific functions more efficiently than is possible in software running on a general-purpose central processing unit (CPU). By offloading specialised tasks to dedicated devices, systems can achieve higher throughput, lower latency, and reduced power consumption.

Types of accelerators

Common examples include graphics processing units (GPUs) for rendering and parallel computation, digital signal processors (DSPs), field-programmable gate arrays (FPGAs), application-specific integrated circuits (ASICs) such as cryptocurrency mining hardware, and neural processing units (NPUs) for machine learning inference. Cryptographic accelerators speed up encryption operations such as AES.

Advantages and disadvantages

Hardware acceleration exploits parallelism, fixed-function pipelines and locality of data to outperform software, but the hardware is less flexible: an accelerator designed for one task usually cannot be repurposed, and development costs are higher than for software. Modern system design often balances general-purpose cores with several specialised accelerators.
