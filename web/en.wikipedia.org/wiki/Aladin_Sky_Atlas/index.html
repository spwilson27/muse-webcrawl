Aladin Sky Atlas
Developer: Centre de données astronomiques de Strasbourg (CDS)
Type: Interactive sky atlas / astronomy software
First released: 1999
Platform: Java (desktop), web (Aladin Lite)

Aladin is an interactive sky atlas software package, developed and maintained by the Centre de données astronomiques de Strasbourg (CDS) in France. It allows users to visualize digitized astronomical images of any part of the sky, superimpose entries from astronomical catalogues and databases such as SIMBAD and VizieR, and interactively access related data and information from archives.

Features

Aladin is a key tool of the Virtual Observatory. It supports multi-wavelength views, allowing the same region of sky to be compared across radio, infrared, optical and X-ray surveys; it can display images in FITS format, overlay catalogue sources with cross-identification links, and draw contours, filters and proper motions. A lightweight web version, Aladin Lite, written in JavaScript/WebGL, is used by many data centres — including the ESA Sky portal — to embed sky views in web pages.

Use

Released in 1999, Aladin is widely used by professional astronomers for data exploration and outreach, and by the CDS as the reference visualisation client for its services. It is distributed free of charge.
