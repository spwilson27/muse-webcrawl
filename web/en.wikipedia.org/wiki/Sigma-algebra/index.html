Sigma-algebra

In mathematical analysis and in probability theory, a σ-algebra (also σ-field, pronounced sigma-algebra) on a set X is a nonempty collection Σ of subsets of X closed under complements and countable unions and countable intersections. The pair (X, Σ) is called a measurable space.

Definition

A collection Σ of subsets of X is a σ-algebra if: (1) X ∈ Σ; (2) if A ∈ Σ then its complement X \ A ∈ Σ; (3) if A1, A2, … ∈ Σ then their union ⋃i Ai ∈ Σ.

It follows that Σ also contains the empty set and is closed under countable intersections. A function between measurable spaces is called measurable if the preimage of every set in the codomain's σ-algebra lies in the domain's σ-algebra; this definition underpins the theory of integration and of random variables, which are measurable functions from a probability space to the real line with its Borel σ-algebra.

Examples

The smallest σ-algebra on X is {∅, X}; the largest is the power set of X. On the real line, the Borel σ-algebra, generated by the open intervals, contains all intervals, open sets, and closed sets, and is the standard setting for Lebesgue measure. The Lebesgue σ-algebra extends it by all subsets of null sets.

Generated σ-algebras

For any collection of subsets of X there is a smallest σ-algebra containing it, called the σ-algebra generated by the collection; generating σ-algebras from simple families such as half-open intervals is fundamental to constructing measures via the Carathéodory extension theorem.
