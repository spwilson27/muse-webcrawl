User mode

User mode is the least privileged protection ring

User mode is a restricted operating mode for application programs in a computer system. When the CPU runs in user mode, code is prevented from directly accessing hardware and reference memory outside its allocated address space; attempts to execute privileged operations or access protected memory fault and are handled by the operating system. Applications request services from the kernel through system calls, which transition the processor into the privileged kernel mode.

Purpose

The separation between user mode and kernel mode is a fundamental protection mechanism: a crash or bug in a user-mode program cannot corrupt the kernel or other processes, and malicious code in user mode cannot seize control of the machine. Modern processors provide multiple privilege levels (rings), of which most operating systems use principally two — ring 0 for the kernel and ring 3 for user applications.
