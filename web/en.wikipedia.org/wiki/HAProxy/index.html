HAProxy is a free and open-source software that provides a high-availability load balancer and reverse proxy for TCP- and HTTP-based applications, spreading requests across multiple servers. Written in C by Willy Tarreau, it is known for its speed, efficiency and reliability, and is used by many high-traffic websites and by major cloud platforms and Linux distributions as part of their infrastructure. The name derives from "High Availability Proxy".

History

Tarreau wrote the first version of HAProxy in 2000–2001 to meet load-balancing needs that existing hardware and software solutions handled poorly, releasing version 1.0 in 2001. Development has continued steadily ever since, with the single-process, event-driven architecture progressively gaining features such as SSL/TLS termination, HTTP/2 and HTTP/3 support, a runtime API, dynamic configuration through the Data Plane API, and extensive observability. The company HAProxy Technologies, founded around the project, sells an enterprise edition (HAProxy Enterprise) and a hardware/virtual appliance (ALOHA), while the community edition remains open source under the GNU General Public License version 2.

Features

HAProxy operates at layer 4 (TCP) or layer 7 (HTTP). Its main capabilities include:

  • Load-balancing algorithms — round-robin, least-connections, source-IP hash, URI hash, and weighted variants.
  • Health checking — active TCP and HTTP checks that automatically remove failed servers from rotation.
  • Session persistence — stickiness based on cookies, which HAProxy can insert, rewrite or learn.
  • TLS termination and pass-through, with SNI-based routing.
  • Access control lists (ACLs) and a rich configuration language for content switching and request/response rewriting.
  • Statistics and monitoring via a built-in stats page, socket API and Prometheus exporter.
  • Rate limiting, queuing and connection management for protecting backends.

Architecture and performance

HAProxy uses an event-driven, non-blocking design historically built around a single process (with optional multi-threading added in later versions), which minimises context switching and memory use. It can typically handle tens of thousands of concurrent connections and saturate multi-gigabit network links on commodity hardware, which has made it a common component in front of large web applications and inside platforms such as OpenStack and Kubernetes ingress setups.

Users

Well-known users of HAProxy have included GitHub, Twitter (X), Reddit, Stack Overflow, Tumblr and Amazon Web Services, whose classic Elastic Load Balancer was reported to be based on HAProxy. It is packaged in essentially all major Linux distributions.
