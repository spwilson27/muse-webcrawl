Type 10

The Type 10 (Japanese: 10式戦車, Hitomaru-shiki sensha) is a fourth-generation main battle tank produced by Mitsubishi Heavy Industries for the Japan Ground Self-Defense Force. It entered service in 2012 as a lighter, more deployable successor to the Type 74 and Type 90 tanks.

Design

The Type 10 weighs about 44 tonnes so that it can cross more of Japan's bridges than the heavier Type 90. It features modular composite armour, an autoloaded 120 mm smoothbore gun developed by Japan Steel Works, a continuously variable transmission, and an advanced C4I system allowing tanks to share targeting data in a network.
