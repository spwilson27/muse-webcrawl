Desktop metaphor

In computing, the desktop metaphor is an interface metaphor which is a set of unifying concepts used by nearly all modern graphical user interfaces (GUIs) to help users interact more easily with the computer. The monitor of a computer represents the user's desktop, upon which documents and folders of documents can be placed. A document can be opened into a window, which represents a paper copy of the document placed on the desktop.

The desktop metaphor: files as documents, directories as folders, deletion as a trash can.

History

The metaphor was developed at Xerox PARC in the 1970s, under researchers including Alan Kay, and was realised in the Xerox Alto and the commercial Xerox Star (1981). It was popularised by the Apple Lisa (1983) and Macintosh (1984), and subsequently adopted by Microsoft Windows, making it the dominant model of personal computing for decades.

Elements

  • Desktop: the background surface holding icons and open windows.
  • Files and folders: documents and the containers that organise them.
  • Windows: movable, resizable frames presenting applications and documents.
  • Trash can / Recycle Bin: deleting by dragging items "into the bin".
  • Clipboard: cut, copy and paste as moving paper between documents.

Criticism and evolution

Critics have noted that the metaphor strains as documents become streams, searches and cloud objects rather than discrete papers, and that mobile interfaces (iOS, Android) largely abandoned the desktop for full-screen apps and icon grids. Nevertheless, desktop/laptop operating systems retain the metaphor in evolved form, and concepts such as folders and the trash remain deeply embedded in users' mental models.
