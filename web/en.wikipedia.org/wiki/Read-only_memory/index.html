Read-only memory

Read-only memory (ROM) is a type of non-volatile memory used in computers and other electronic devices. Data stored in ROM cannot be electronically modified after the manufacture of the memory device, or can be modified only slowly or with difficulty. ROM is therefore mainly used to store firmware — software closely tied to specific hardware that rarely needs updating.

History

The simplest type of ROM, mask ROM, has its contents set during manufacture by the pattern of the photolithographic mask. Early computers used ROM built from diode matrices and, later, semiconductor integrated circuits. Because mask ROM requires a new mask for any change, programmable variants soon appeared.

Types

PROM (programmable ROM) can be written once using a PROM programmer that blows microscopic fuses. EPROM can be erased by strong ultraviolet light and rewritten. EEPROM can be erased and rewritten electrically, byte by byte, and its descendant flash memory erases in large blocks and dominates modern non-volatile storage.

Uses

ROM has stored the bootstrap firmware (BIOS or UEFI) of personal computers, the built-in programs of embedded systems, video game cartridges, and character fonts in early terminals and printers. Although modern systems usually load firmware from rewritable flash, the term "ROM" is still widely used for the fixed system image in devices such as smartphones.
