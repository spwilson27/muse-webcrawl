Mac OS X

Mac OS X was the name of Apple's desktop operating system line for Macintosh computers from 2001 to 2016, when it was renamed to macOS. (The name was shortened to "OS X" in 2012.) "X" is the Roman numeral 10 and was pronounced "ten". Mac OS X succeeded the classic Mac OS and was based on technology developed at NeXT, the company Steve Jobs founded after leaving Apple and which Apple acquired in 1997.

History

After Apple's attempts to develop a successor to the classic Mac OS (Taligent, Copland and Gershwin) failed, Apple bought NeXT in 1996 and based its new system on NeXTSTEP, an operating system built on the Mach kernel and BSD Unix. The resulting Darwin core is open-source. Mac OS X Public Beta shipped in 2000, and Mac OS X 10.0 "Cheetah" was released on 24 March 2001 with the colourful new Aqua user interface.

Versions

From 10.0 to 10.8, versions were named after big cats: Cheetah, Puma, Jaguar, Panther, Tiger, Leopard, Snow Leopard, Lion and Mountain Lion. From 2013 (10.9 Mavericks) Apple switched to California place names, continuing with Yosemite, El Capitan and Sierra. Early releases targeted PowerPC processors; following the transition to Intel processors in 2006, 10.6 Snow Leopard was Intel-only. Each release bundled technologies such as Time Machine, Spotlight search, the Dock, Quick Look and Launchpad.

Architecture

Mac OS X combined a Unix foundation (Darwin, with the XNU hybrid kernel) with Apple's graphical frameworks (Cocoa, Carbon, Quartz and Aqua) and was certified as a UNIX 03 operating system from version 10.5 on Intel. Its Unix base made it popular with developers, while its interface targeted consumers.
