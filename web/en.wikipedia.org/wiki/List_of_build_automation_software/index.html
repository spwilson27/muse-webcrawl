List of build automation software

Build automation software automates compiling source code, running tests, packaging binaries, and related tasks in software development. This list summarises notable tools by primary language or ecosystem.

General and multi-language

ToolNotes
MakeClassic Unix build tool driven by Makefiles (1976)
CMakeCross-platform generator for native build files
NinjaLow-level, speed-focused build system
BazelGoogle's tool for large monorepos
SConsPython-based build tool
MesonModern cross-platform build system

By ecosystem

Java/JVM: Maven, Gradle, Ant. JavaScript: npm scripts, webpack, esbuild, Vite, Gulp, Grunt. .NET: MSBuild, Cake. Go: the built-in go build toolchain and Mage. Rust: Cargo. Python: setuptools, Hatch, PDM, Poetry build backends. Ruby: Rake. Erlang/Elixir: Rebar3 and Mix.

Continuous integration

Build automation overlaps with continuous integration servers and services such as Jenkins, GitHub Actions, GitLab CI, CircleCI, Travis CI, TeamCity, and Azure DevOps Pipelines, which run automated builds on code changes.
