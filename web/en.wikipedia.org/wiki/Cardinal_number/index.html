Cardinal number

From Wikipedia, the free encyclopedia

[Image: Countably many dots in a row labelled aleph-null beside an uncountable continuum bar]

A cardinal number measures the size of a set: two sets have the same cardinality when they can be put in one-to-one correspondence. For finite sets the cardinals are simply 0, 1, 2, …; Georg Cantor showed that infinite sets require new, transfinite cardinals.

The smallest infinite cardinal, ℵ₀ (aleph-null), is the cardinality of the natural numbers and of any countably infinite set, including the rationals. Cantor's diagonal argument proves the real numbers have a strictly larger cardinality, the cardinality of the continuum.

The cardinal hierarchy

Cantor's theorem guarantees an endless ladder: the power set of any set always has larger cardinality, so there are infinitely many different infinities.

Whether any cardinal lies between ℵ₀ and the continuum is the continuum hypothesis, shown to be undecidable within standard set theory.
