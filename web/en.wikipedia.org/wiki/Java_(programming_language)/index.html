Java (programming language)

From Wikipedia, the free encyclopedia
[Image: The Java logo, a steaming cup of coffee]

Java is a high-level, class-based, object-oriented programming language designed to have as few implementation dependencies as possible: code is compiled to bytecode that runs on any device with a Java Virtual Machine (JVM) — 'write once, run anywhere'.

Developed by James Gosling and colleagues at Sun Microsystems and released in 1995 (version 1.0 in 1996), Java became a dominant language for enterprise software, Android apps (via a JVM-like runtime), and large back-end systems. Oracle acquired Sun in 2010 and stewards the language; OpenJDK is the open-source reference implementation.

Characteristics

Java is statically typed, garbage-collected, and emphasises portability, security (the sandbox model of its applet era), and a vast standard library and ecosystem (Spring, Jakarta EE, build tools Maven/Gradle). Applets in browsers died with the plugin era; Java's centre of gravity is servers and Android.

The language evolves on a six-month release cadence since 2018, gaining records, pattern matching, virtual threads (2023) and other modern features while preserving backwards compatibility.

Criticism

Java has been criticised for verbosity, slow startup, memory footprint, and Oracle's licensing changes for its builds (2019 onwards) pushing users toward OpenJDK distributions. It remains, by most indices, one of the top few languages by usage and job demand.
