Babel (transcompiler)

Babel
Initial release2014 (as 6to5)
Written inJavaScript
TypeSource-to-source compiler
LicenseMIT

Babel is a free and open-source JavaScript transcompiler used to convert ECMAScript 2015+ (ES6+) code into backwards-compatible versions of JavaScript that can run in older browsers and environments. It is a core tool in modern web development toolchains.

Features

Babel works through plugins that transform individual syntax features, and presets — notably preset-env — that select transforms based on target environments and browserslist data. It can also apply polyfills (via core-js) for missing built-in features, and is used to compile JSX in React projects and to strip types from TypeScript code.

History

The project began in 2014 as "6to5", created by Sebastian McKenzie, and was renamed Babel in 2015. It is downloaded tens of millions of times per month from npm and is maintained by a small open-source team funded through donations and sponsorships.
