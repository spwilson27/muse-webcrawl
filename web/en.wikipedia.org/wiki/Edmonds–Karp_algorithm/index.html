Edmonds–Karp algorithm

The Edmonds–Karp algorithm is an implementation of the Ford–Fulkerson method for computing the maximum flow in a flow network. It was first published by Yefim Dinitz in 1970 and independently by Jack Edmonds and Richard Karp in 1972.

Description

The algorithm differs from the generic Ford–Fulkerson method in that the search order for augmenting paths is defined: the augmenting path found must be a shortest path (in terms of number of edges) in the residual graph, which is achieved using breadth-first search.

Complexity

This choice guarantees the algorithm terminates in O(VE²) time, because each augmentation can increase the distance of the found path only a bounded number of times, and each edge can become critical O(V) times.
