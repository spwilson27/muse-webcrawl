Fuzzy mathematics

Fuzzy mathematics is the branch of mathematics that deals with fuzzy sets and related concepts, extending classical set theory and logic to handle reasoning that is approximate rather than exact. It originated with Lotfi A. Zadeh's 1965 paper introducing fuzzy sets, in which elements have degrees of membership between 0 and 1 rather than a strict in-or-out classification.

Branches

The field includes fuzzy set theory, fuzzy logic, fuzzy measure theory, fuzzy topology, fuzzy algebra (including fuzzy groups and rings), fuzzy arithmetic, fuzzy graph theory, and fuzzy analysis. It provides tools for modeling uncertainty arising from vagueness, as distinct from randomness treated by probability theory.

Applications

Fuzzy mathematics underlies fuzzy control systems, which have been applied to products from rice cookers and washing machines to subway train control and anti-lock braking, as well as fuzzy clustering and decision-making methods.
