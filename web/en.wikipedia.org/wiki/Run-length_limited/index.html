Run-length limited

Run-length limited or RLL coding is a line coding technique used in telecommunications and data storage that constrains the lengths of runs of consecutive identical symbols. An RLL code is described by parameters (d, k), where d is the minimum and k the maximum number of zeros between consecutive ones in the encoded stream.

Purpose

In magnetic and optical recording, long runs without transitions make clock recovery difficult and risk losing track of position, while transitions too close together can exceed the resolution of the read channel. RLL codes therefore guarantee enough transitions for timing recovery while spacing them far enough apart to be resolved.

Variants

Well-known examples include FM and MFM encoding used on early floppy disks, the (2,7) RLL code, EFM used on compact discs, and EFMPlus used on DVDs. Group coded recording on hard disk drives used RLL schemes before modern drives moved to partial-response maximum-likelihood (PRML) channels.
