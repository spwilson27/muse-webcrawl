Wayland

Wayland is a communication protocol that specifies the communication between a display server and its clients, as well as a C library implementation of that protocol. A display server using the Wayland protocol is called a Wayland compositor, as it additionally performs the task of a compositing window manager.

Wayland was developed by a group of developers from Intel and Red Hat, led by Danish developer Kristian Høgsberg, with the goal of simplifying the graphics stack of Linux and other Unix-like operating systems by replacing the ageing X Window System (X11). The project was started in 2008 and reached its first stable release of the protocol and reference compositor in 2012.

Overview

Unlike X11, in which a central server draws windows and forwards input events, the Wayland protocol lets clients render their own surfaces and communicate directly with the compositor, which handles input, output and composition. Each client receives its own buffer, and the compositor combines the buffers for display. Communication between clients and the compositor uses Unix domain sockets and shared memory, giving Wayland lower latency and enabling perfect frames without tearing.

Architecture

The core protocol is intentionally small and covers buffer management, input events and surface roles. Extensions defined in the wayland-protocols repository add features such as screenshotting, tablet support and idle inhibition. The wlroots-based compositors (such as Sway), KDE's KWin and GNOME's Mutter all implement Wayland. X11 applications can run under Wayland through the XWayland compatibility server.

Adoption

Most major Linux distributions now use Wayland by default for their GNOME and KDE Plasma sessions, although adoption is gradual because of differences in application support for screen recording, remote desktop and global hotkeys.
