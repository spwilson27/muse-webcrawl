Artinian module

An Artinian module satisfies the descending chain condition on submodules

In abstract algebra, an Artinian module is a module that satisfies the descending chain condition on its partially ordered set of submodules: every descending chain of submodules eventually stabilises. Artinian modules are named after Emil Artin, who first developed their theory in the 1920s.

Properties

The class of Artinian modules over a ring is closed under quotients, submodules, finite direct sums and extensions. A module over a Noetherian ring is Artinian if and only if it is finitely generated in a suitable dual sense; more precisely, over a Noetherian ring a module is Artinian if and only if it has finite length as a module over its support. Every Artinian module is Noetherian — the Akizuki–Hopkins theorem states that over a Noetherian ring, an Artinian module is Noetherian and of finite length.

Examples

Finite-dimensional vector spaces are Artinian over their field. The Prüfer p-group Z(p∞) is an Artinian Z-module that is not Noetherian over a general ring context, and any finite abelian group is Artinian as a Z-module. A ring is an Artinian ring if it is Artinian as a module over itself.
