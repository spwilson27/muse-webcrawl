Graphical shell

A graphical shell is a graphical user interface for access to the functions of an operating system's kernel or services. The term refers to the software layer that presents windows, icons, menus and a pointer (the WIMP paradigm) to the user, in contrast to a text-based command-line shell such as Bash.

Examples

On Microsoft Windows, the graphical shell is Windows Explorer (now File Explorer), which provides the desktop, taskbar, Start menu, and file management windows. On macOS, the Finder and the Aqua interface serve this role. On Unix-like systems, desktop environments such as GNOME, KDE Plasma, and Xfce provide graphical shells, typically running atop a display server such as X11 or a Wayland compositor.

History

The graphical shell descends from the pioneering work at Xerox PARC in the 1970s, commercialised in the Xerox Star (1981), Apple Lisa (1983), and Macintosh (1984). Microsoft followed with Windows, which evolved from a graphical environment for MS-DOS into the full shell of Windows 95.

A graphical shell may be replaced independently of the underlying operating system on some platforms, and alternative shells exist for Windows and Linux. See also shell (computing), desktop environment, and windowing system.
