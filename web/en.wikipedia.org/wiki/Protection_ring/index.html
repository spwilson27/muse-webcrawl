Protection ring

In computer science, hierarchical protection domains, often called protection rings, are mechanisms to protect data and functionality from faults (by improving fault tolerance) and malicious behaviour (by providing computer security). This approach is diametrically opposite to that of capability-based security.

Overview

Computer operating systems provide different levels of access to resources. A protection ring is one of two or more hierarchical levels or layers of privilege within the architecture of a computer system. This is generally hardware-enforced by some architectures that provide multiple CPU modes at the hardware or microcode level. Rings are arranged in a hierarchy from the most privileged (lowest numbered, ring 0) to the least privileged (highest numbered).

Implementation

The x86 architecture provides four rings, but most operating systems use only two: ring 0 for the kernel and ring 3 for user applications. The Multics operating system was influential in developing a hierarchical ring model with up to eight levels. Supervisor mode, hypervisor mode and virtualisation extensions add further privilege distinctions; a hypervisor is sometimes informally described as running at "ring −1".

Use

Code running in a higher-privilege ring can access memory and instructions denied to lower rings. Transitions between rings occur through controlled gates such as system calls, which validate parameters before executing privileged operations.
