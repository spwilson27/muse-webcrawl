Document classification

Document classification or document categorization (often called text classification in natural language processing) is a problem in library science, information science and computer science. The task is to assign a document to one or more classes or categories. This may be done "manually" (or "intellectually") or by automated computational (algorithmic) means.

Approaches

Manual classification, as performed by librarians using controlled vocabularies such as the Dewey Decimal Classification, relies on human judgement. Automated approaches include:

  • Rule-based systems — using hand-crafted rules or expert systems
  • Machine learning — training a classifier on labelled examples, using algorithms such as naive Bayes, support vector machines, k-nearest neighbours, decision trees and neural networks
  • Deep learning — using word embeddings and architectures such as recurrent and transformer networks, including fine-tuned language models

Documents are typically represented as bags of words, often weighted by tf–idf, before classification. The task may be binary (e.g. spam vs. not spam), multi-class (one of several topics), or multi-label (any number of labels).

Applications and evaluation

Applications include spam filtering, sentiment analysis, news categorisation, language identification, legal e-discovery and medical coding. Classifiers are evaluated using measures such as precision, recall, F-measure and accuracy on held-out test sets. Widely used benchmark collections include the Reuters-21578 and 20 Newsgroups corpora.
