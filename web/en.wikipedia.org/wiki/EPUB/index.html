EPUB

From Wikipedia, the free encyclopedia

Filename extension: .epub

Developed by: International Digital Publishing Forum (IDPF); now W3C

Initial release: 2007 (EPUB 2.0)

Type of format: E-book file format

EPUB is an e-book file format that uses the ".epub" file extension. The term is short for electronic publication. EPUB is supported by many e-readers and by reading software on computers, tablets and phones, and is the most widely supported vendor-independent e-book format.

Format

An EPUB file is a ZIP archive containing XHTML or HTML content documents, CSS styling, images, fonts and an XML package document describing the book's metadata, manifest and reading order. Text in the default "reflowable" layout adapts to screen size and reader font settings; a fixed-layout variant preserves page design for children's books, comics and textbooks. EPUB 3, released in 2011 and maintained since by the World Wide Web Consortium after the IDPF merged into it, added HTML5 features, MathML, synchronised audio narration ("media overlays") and improved accessibility metadata.

History

EPUB succeeded the Open eBook Publication Structure developed in 1999. EPUB 2.0 was standardised in 2007 and EPUB 3.0 in 2011, with minor revisions since. Bookshops and libraries distribute EPUBs widely; Amazon's Kindle ecosystem long used its own formats (MOBI/KF8/AZW) but added EPUB ingestion for Send to Kindle in 2022. Many files are sold with digital rights management (DRM) from vendors such as Adobe, though DRM-free EPUB is standard for public-domain and many independent titles.

Software

Reading systems include Apple Books, Google Play Books, Kobo and numerous open-source tools; the editor Sigil and the library manager Calibre are commonly used to create and convert EPUB files.
