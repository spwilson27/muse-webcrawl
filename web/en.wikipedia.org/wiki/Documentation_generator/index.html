Documentation generator

A documentation generator is a programming tool that generates software documentation from specially formatted comments in source code, or from specially formatted markup files. The output is typically a set of HTML pages describing the classes, methods, and functions of an API.

Examples

Well-known documentation generators include Javadoc for Java, Doxygen for C, C++, and many other languages, Sphinx and pdoc for Python, rustdoc for Rust, JSDoc for JavaScript, and RDoc for Ruby. By embedding documentation in special comment blocks (doc comments) adjacent to the code they describe, these tools keep reference documentation synchronised with the implementation and can extract cross-references, inheritance diagrams, and indexes automatically.
