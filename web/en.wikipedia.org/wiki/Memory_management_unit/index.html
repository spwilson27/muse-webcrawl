Memory management unit

The MMU translates virtual addresses to physical addresses

A memory management unit (MMU), sometimes called a paged memory management unit (PMMU), is a computer hardware unit that examines all memory references on the memory bus, translating these requests, known as virtual memory addresses, into physical addresses in main memory.

Functions

In modern systems an MMU performs three basic functions: address translation (virtual to physical), memory protection (checking that a process may access a region with the requested permissions), and cache control. By translating addresses, the MMU allows each process to run in its own virtual address space, isolated from other processes, and enables paging, in which pages of memory can be moved between RAM and disk storage on demand. If an access violates protection rules or references an unmapped page, the MMU raises a page fault or protection fault for the operating system to handle.

Translation lookaside buffer

Because consulting page tables in memory on every access would be slow, MMUs include a translation lookaside buffer (TLB), a cache of recent virtual-to-physical translations. A TLB hit supplies the physical address immediately; on a miss, the MMU (or software, on some architectures) walks the page tables to find the mapping and fill the TLB.

History

Early systems such as the Atlas computer pioneered paging hardware in the 1960s. As microprocessors developed, MMUs moved from separate chips — such as the Motorola 68851 used with the 68020 — to being integrated on the processor die, as in the Intel 80386 and all subsequent mainstream CPUs. Small microcontrollers and embedded processors may include a simpler memory protection unit (MPU) that provides protection without full virtual memory translation.
