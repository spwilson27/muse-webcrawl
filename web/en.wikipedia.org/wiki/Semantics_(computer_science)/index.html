Semantics (computer science)

In programming language theory, semantics is the rigorous mathematical study of the meaning of programming languages. It assigns computational meaning to syntactically valid strings, complementing syntax, which concerns form. Semantics provides the basis for program verification, compiler correctness and language design.

Approaches

Operational semantics defines meaning by the operation of an abstract machine executing the program, either in small steps (structural operational semantics, after Gordon Plotkin) or big-step transitions to final values. Denotational semantics, developed by Christopher Strachey and Dana Scott, maps each phrase to a mathematical object (denotation), typically using domain theory for recursion and iteration. Axiomatic semantics, exemplified by Hoare logic, defines meaning through assertions about program states before and after execution.

Applications

Formal semantics underpins static analysis, type systems, verified compilation (such as the CompCert C compiler), and specification languages. Informal counterparts, such as reference manuals describing language behaviour in prose, are also called semantics, but lack mathematical precision.

History

The field grew out of 1960s work on Algol and the Vienna Definition Language. Robert Floyd's 1967 paper on assigning meanings to programs and Tony Hoare's axiomatic basis (1969) founded program verification, while Scott and Strachey's work in the early 1970s established denotational semantics.
