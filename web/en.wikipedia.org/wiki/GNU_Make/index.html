GNU Make (often shortened to gmake) is a build automation tool from the GNU Project that automatically builds executable programs and libraries from source code by reading files called makefiles, which specify how to derive target files from source files based on dependency relationships and timestamps.

Features

Make decides which pieces of a program need recompiling and issues the commands to rebuild them. GNU Make extends the original Unix Make with pattern rules, automatic variables, functions for transforming text, conditional directives, and parallel job execution with the -j option.

Makefiles

A makefile contains rules of the form target: prerequisites followed by tab-indented recipe commands. When invoked, Make builds the default target or a named target, recursively rebuilding prerequisites that are newer than the files that depend on them.
