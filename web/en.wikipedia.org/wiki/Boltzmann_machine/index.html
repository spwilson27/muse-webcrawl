Boltzmann machine

A Boltzmann machine is a type of stochastic recurrent neural network. It was invented by Geoffrey Hinton and Terry Sejnowski in 1985. Boltzmann machines can be seen as stochastic, generative counterparts of Hopfield networks, and they were among the first neural networks capable of learning internal representations — of learning interesting features — in a purely unsupervised way.

Structure

A Boltzmann machine consists of binary units divided into visible units, which represent data, and hidden units, which capture dependencies between the visible units. Units are connected by symmetric weighted connections, and each configuration of the network has an associated "energy". The probability of a global state follows the Boltzmann distribution familiar from statistical mechanics: low-energy states are exponentially more likely. Learning adjusts the weights so that the distribution over visible states matches the distribution of the training data, typically by gradient ascent on the log-likelihood using samples drawn from the model.

Restricted Boltzmann machines

Fully connected Boltzmann machines are slow to train. The restricted Boltzmann machine (RBM), introduced by Paul Smolensky in 1986 as the "harmonium" and popularised by Hinton in the 2000s, removes connections within each layer, making the hidden units conditionally independent given the visible ones (and vice versa). With the contrastive divergence training algorithm proposed by Hinton in 2002, RBMs became practical. In 2006, stacks of RBMs ("deep belief networks") trained layer by layer helped ignite the modern deep-learning revival. RBMs have been applied to collaborative filtering, dimensionality reduction and feature learning.

Variants

Deep Boltzmann machines extend the idea with multiple fully connected hidden layers, trained with more elaborate approximate inference. Gaussian–Bernoulli RBMs adapt the visible layer to real-valued data such as image pixels or audio.
