SQL

From Wikipedia, the free encyclopedia
[Image: A SELECT query typed on screen above a results table]

Structured Query Language (SQL) is a declarative programming language for managing data held in a relational database management system: querying, updating, defining schemas, and controlling access. It is written 'sequel' or 'S-Q-L' depending on speaker tradition.

SQL descends from SEQUEL, developed by Donald Chamberlin and Raymond Boyce at IBM in 1974, following Edgar Codd's relational model (1970). It was standardised by ANSI in 1986 and ISO in 1987 and has been extended repeatedly (SQL:1999, 2003, 2011, 2016, 2023), including window functions, JSON support, and property-graph queries.

The language

Core statements: SELECT (queries with filtering, joins, grouping, aggregation), INSERT, UPDATE, DELETE, and DDL commands CREATE/ALTER/DROP. Declarative style tells the system what to retrieve; the query optimiser decides how — one of computing's most successful abstractions.

Every major database speaks SQL or a close dialect (Oracle, PostgreSQL, MySQL, SQL Server, SQLite — the world's most deployed database, embedded in phones and browsers), and even many NoSQL and big-data systems (Spark SQL, BigQuery) adopted SQL interfaces.

Criticism

SQL is faulted for awkward composition, vendor dialects, and impedance mismatch with application languages (hence ORM libraries) — yet after five decades it remains the lingua franca of data, outliving most predicted replacements.
