Topological sorting

FieldGraph theory, computer science
InputDirected acyclic graph (DAG)
ComplexityO(V + E)

In computer science, a topological sort or topological ordering of a directed graph is a linear ordering of its vertices such that for every directed edge u → v, vertex u comes before v in the ordering. A topological ordering exists if and only if the graph is a directed acyclic graph (DAG).

Algorithms

Two classic linear-time algorithms are Kahn's algorithm (1962), which repeatedly removes vertices of in-degree zero, and a depth-first-search-based method that outputs vertices in reverse order of their finishing times. Kahn's algorithm also detects cycles: if the output contains fewer vertices than the graph, the graph has a cycle.

Applications

Topological sorting is used whenever tasks have dependencies: scheduling jobs, ordering build steps in build systems such as make, resolving package dependencies, ordering spreadsheet recalculation, and sequencing courses with prerequisites. A graph may have many valid topological orderings.
