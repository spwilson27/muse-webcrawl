Axiom of empty set

In axiomatic set theory, the axiom of empty set is a statement that asserts the existence of a set with no elements. It is an axiom of Zermelo–Fraenkel set theory (ZF) and of related systems.

Formal statement

In the formal language of set theory, the axiom reads: ∃ x ∀ y ¬(y ∈ x) — there exists a set x such that no set y is a member of x.

Interpretation

By the axiom of extensionality there is exactly one such set, the empty set, denoted ∅ or {}. The axiom is often considered redundant because the existence of an empty set can be derived from other axioms: from the axiom of infinity one can obtain some set, and then apply separation with a contradictory condition (e.g. x ≠ x) to carve out an empty subset. Nevertheless it is traditionally listed among the axioms of ZF.

From the empty set, using pairing, union and power set, one can build the finite von Neumann ordinals: 0 = ∅, 1 = {∅}, 2 = {∅, {∅}}, and so on.
