Fortran

Fortran (originally FORTRAN, from "Formula Translation") is a general-purpose, compiled, imperative programming language especially suited to numeric computation and scientific computing. Developed at IBM in the 1950s by a team led by John Backus, it was the first widely used high-level programming language, and its optimising compiler set the standard for what compilers could achieve. Fortran has been continuously used for more than six decades in weather prediction, physics, engineering, and high-performance computing; modern standards retain the name with the spelling "Fortran".

History

Backus proposed automatic programming for the IBM 704 in 1953; the FORTRAN compiler was delivered in 1957. FORTRAN II (1958) added subroutines; FORTRAN IV became a de facto standard and was formalised as FORTRAN 66, the first ANSI-standardised language. Fortran 77 added structured programming features and character handling and dominated for a decade. Fortran 90 was a major modernisation — free-form source, modules, array operations, pointers, and user-defined types — followed by Fortran 95, 2003 (object orientation), 2008 (coarrays for parallel computing), 2018, and 2023.

Features

Fortran is designed for efficient array and floating-point computation: multidimensional arrays are first-class, whole-array expressions are allowed, and compilers exploit the language's aliasing rules to optimise aggressively. Native support for parallel programming (coarrays, do concurrent), interoperability with C (ISO_C_BINDING), and an enormous legacy of numerical libraries (BLAS, LAPACK, and the Netlib collections) keep the language in production use in supercomputing centres.

Influence

Fortran established core concepts later languages inherited: compiled high-level code, expressions with operator precedence, the DO loop, formatted input/output, and separate compilation. Its long history also made it a cautionary example of standardisation challenges, such as the three-way jump (arithmetic IF) removed in later standards.
