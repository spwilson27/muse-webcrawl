FreeBSD is a free and open-source Unix-like operating system descended from the Berkeley Software Distribution (BSD), which was based on Research Unix. The first version was released in 1993 from code derived from 386BSD and 4.4BSD-Lite. Unlike Linux, which is a kernel combined with userland components from many projects, FreeBSD is developed as a complete operating system with kernel, device drivers, userland utilities, and documentation maintained in a single source tree.

Features

FreeBSD is known for its advanced networking, security features, and performance, and it has historically powered some of the busiest services on the Internet. Notable technologies include the Ports collection of third-party software, the GEOM storage framework, the OpenZFS file system, the pf and ipfw firewalls, jails (an early form of OS-level virtualisation), Capsicum sandboxing, and the bhyve hypervisor.

History

The project was founded by Jordan Hubbard, Nate Williams, and Rodney Grimes. Following the settlement of the USL v. BSDi lawsuit, FreeBSD 2.0 (1995) was re-based on 4.4BSD-Lite with AT&T code removed. FreeBSD code has been incorporated into many commercial products: it forms the basis of the core of Apple's macOS and iOS (via Darwin), Sony's PlayStation 3 and 4 system software, Netflix's content-delivery appliances, and network equipment from vendors such as Juniper.

Derivatives

Well-known derivatives include TrueNAS (network-attached storage), pfSense and OPNsense (firewalls), GhostBSD (desktop), and the hardened distribution HardenedBSD.

License

FreeBSD is released under the permissive two-clause BSD license, allowing proprietary reuse of the code with attribution.
