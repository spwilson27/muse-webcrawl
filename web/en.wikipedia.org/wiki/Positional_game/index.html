Positional game

A positional game is a kind of a combinatorial game for two players. It is described by a finite set of elements, a family of subsets of this set (called the winning sets), and a winning criterion. The players alternately claim previously unclaimed elements until all elements are claimed or a winner is determined. Positional games were systematically studied by Paul Erdős and John Selfridge and later developed by mathematicians including József Beck.

Maker–Breaker and Maker–Maker games

In a Maker–Breaker game, the two players are called Maker and Breaker. Maker wins by claiming all elements of some winning set, while Breaker wins by preventing this, i.e. by claiming at least one element in every winning set. Tic-tac-toe is a classic example, where the winning sets are the rows, columns, and diagonals of the board. In a Maker–Maker game, both players aim to claim a winning set first; the strong positional game variant requires the first player to complete a winning set to win outright, with draws possible if the board fills first.

Avoider–Enforcer games

In an Avoider–Enforcer game, Avoider aims not to claim all elements of any losing set, while Enforcer tries to force Avoider to do so. Misère-type play, as in Treblecross, is an example of this family.

Theory

Key questions in the theory include determining the threshold bias at which the outcome changes in biased games (where one player claims multiple elements per move), and criteria such as the Erdős–Selfridge criterion, which gives conditions under which Breaker has a winning strategy. Positional games connect to the probabilistic method, Ramsey theory, and the study of hypergraph games.
