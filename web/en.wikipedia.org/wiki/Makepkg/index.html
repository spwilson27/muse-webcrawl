Part ofpacman (package manager)
Written inBash
Operating systemArch Linux and derivatives
TypePackage build tool

makepkg is a script that automates the building of packages for the pacman package manager used by Arch Linux and its derivatives. Given a PKGBUILD file — a Bash script describing the package's source, dependencies and build instructions — makepkg downloads the source code, verifies its integrity with checksums, compiles it in a clean fakeroot environment, and produces an installable .pkg.tar.zst package archive (earlier versions used xz compression).

Functionality

makepkg reads its configuration from makepkg.conf, which controls compiler flags, build options and compression. It can automatically resolve and install missing build dependencies with the -s flag (invoking pacman), install the finished package with -i, and clean build artifacts afterwards. Because PKGBUILDs are simple shell scripts, the same mechanism powers the Arch User Repository (AUR), where community-contributed build scripts are built locally by users with makepkg rather than distributed as binaries.
