Picard theorem

In complex analysis, Picard's theorem — named after the French mathematician Charles Émile Picard, who proved it in 1879 — refers to two related results about the range of an analytic function near an essential singularity:

Little Picard theorem

The little Picard theorem states that if a function f is entire and non-constant, then the set of values that f attains is either the whole complex plane or the plane minus a single point. In other words, an entire non-constant function can omit at most one complex value.

This is a considerable strengthening of Liouville's theorem, which says only that a bounded entire function must be constant, and of the Casorati–Weierstrass theorem. The exponential function ez shows that the single omitted value really can occur: it omits 0.

Great Picard theorem

The great Picard theorem states that if an analytic function f has an essential singularity at a point w, then on any punctured neighborhood of w, f attains every complex value infinitely often, with the possible exception of one value.

For example, the function e1/z has an essential singularity at 0 and takes every non-zero value infinitely often in every neighborhood of 0, omitting only the value 0.

Proofs and generalizations

Picard's original proof relied on the properties of the modular lambda function. Modern proofs of the little theorem often use Montel's theorem on normal families; the great theorem can be proved using the Schottky theorem or via the theory of the universal covering of the twice-punctured plane. The theorems are also closely related to Bloch's principle and to Nevanlinna theory, and they generalize to statements about meromorphic functions and holomorphic curves.

A useful corollary: a polynomial of degree at least one takes every complex value (the fundamental theorem of algebra aside, Picard's theorem extends this flavor of statement far beyond polynomials, though the exceptional-value phenomenon is new).
