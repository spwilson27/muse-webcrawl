Convolutional code

In telecommunication, a convolutional code is a type of error-correcting code that generates parity symbols via the sliding application of a boolean polynomial function to a data stream. The sliding application represents the "convolution" of the encoder over the data, which gives rise to the term "convolutional coding".

Encoding

A convolutional encoder is typically implemented as a shift register whose contents are combined through modulo-2 adders selected by generator polynomials. The code rate k/n means that for every k input bits, the encoder produces n output bits. Unlike block codes, the output depends not only on the current input but also on previous inputs stored in the register, giving the code memory.

Decoding

The Viterbi algorithm, described by Andrew Viterbi in 1967, performs maximum-likelihood decoding by finding the most likely path through the code's trellis diagram. Soft-decision decoding uses reliability information from the demodulator to improve performance.

Applications

Convolutional codes have been widely used in deep-space communications, satellite links, and mobile telephony standards. Puncturing — selectively deleting parity bits — allows higher-rate codes to be derived from a low-rate mother code. Concatenated with block codes or replaced by turbo and LDPC codes in newer systems, convolutional codes remain foundational in coding theory.
