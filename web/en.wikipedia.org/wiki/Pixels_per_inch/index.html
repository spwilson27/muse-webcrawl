Pixels per inch

Pixels per inch (PPI)
QuantitySpatial pixel density
Unit ofPixels per linear inch
Related unitsDots per inch (DPI), pixels per centimetre

Pixels per inch (PPI) is a measurement of the pixel density (resolution) of an electronic image device, such as a computer monitor or television display, or of an image digitising device such as a scanner. It counts how many pixels fit into one linear inch: the higher the PPI, the finer the detail a display can render.

Calculation

For a rectangular display, PPI is calculated from the diagonal resolution in pixels divided by the diagonal size in inches, or separately along width and height. For example, a 1920 × 1080 display of 24 inches diagonal has a pixel density of about 92 PPI. Smartphone displays commonly exceed 300 PPI — marketed by Apple as "Retina" density because at typical viewing distances individual pixels become hard to distinguish.

PPI versus DPI

PPI is often confused with dots per inch (DPI), which properly refers to the resolution of printers — the density of ink dots a printer can lay down. Operating systems have historically used conventional values such as 72 or 96 PPI for display scaling, independent of a monitor's true density, which affects how large interface elements appear.

Image files

Digital image files carry PPI metadata that instructs output devices how large to print or display the image; the metadata does not change the pixel data itself. Doubling an image's PPI at print halves its printed dimensions.
