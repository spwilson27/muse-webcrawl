Password (video games)

In video gaming, a password is a string of characters shown to the player at a certain point in a game — typically upon completing a level or reaching a checkpoint — which, when entered later, returns the player to that point with an approximation of their previous state. Password systems were widely used on cartridge-based consoles and home computers of the 1980s and early 1990s that lacked battery-backed memory or other built-in save capability.

A password entry screen from a cartridge-era game.

How passwords work

A password typically encodes the game state — current level, score, lives, inventory, and abilities — in compressed form. Because more state requires longer passwords, some games used very long strings: River City Ransom and The Guardian Legend are noted for lengthy codes, while others, such as Metroid (1986), used 24-character passwords. Entering specific passwords could also function as a cheat or Easter egg; the famous "JUSTIN BAILEY" code in Metroid and the Konami-published Mega Man series' dot-matrix passwords are well-known examples. The Mega Man games used a grid of coloured dots rather than text.

Advantages and disadvantages

Passwords allowed publishers to avoid the cost of battery-backed SRAM in cartridges and made progress portable between consoles — the same code works on any copy of the game. However, they were cumbersome to copy down, prone to transcription errors, often could not reproduce the player's exact state, and allowed players to share codes freely. Password generators and brute-force analyses by fans later revealed the encoding schemes of many games.

Decline

As battery saves, memory cards, and eventually hard drives and cloud saves became standard from the mid-1990s onward, password systems largely disappeared from mainstream games. They survive in retro-style games as a nostalgic feature.
