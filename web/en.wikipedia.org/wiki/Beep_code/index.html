Beep code

Beep code
PurposeDiagnose hardware errors during POST
Output deviceInternal PC speaker

A beep code is an audible diagnostic signal emitted by a computer during the power-on self-test (POST), produced through the internal speaker before the video display is initialised. Because serious hardware faults may prevent anything from appearing on screen, patterns of short and long beeps are used to indicate the type of error detected, such as memory failure, video card failure, or CPU problems.

Interpretation

Beep codes are defined by the BIOS or firmware vendor — historically IBM, AMI, Award, and Phoenix each published their own tables — so the same pattern can mean different things on different machines. A single short beep usually indicates a successful POST. Modern systems increasingly replace beep codes with on-board LED indicators, two-digit debug displays, or on-screen UEFI diagnostics, and many laptops and compact desktops omit the speaker entirely.
