Immunological memory

Immunological memory is the ability of the immune system to respond more rapidly and effectively to a pathogen that has been encountered previously. It is a defining feature of the adaptive immune system and is the basis of vaccination. The specific components of memory are memory B cells, memory T cells, and long-lived plasma cells that continue to secrete antibody.

Development

During a primary immune response, antigen-activated B and T cells proliferate and differentiate into effector cells; most die after the pathogen is cleared, but a small population persists as memory cells. B cells that have passed through germinal centres carry somatically hypermutated, high-affinity receptors and can rapidly produce large amounts of high-affinity antibody on re-exposure. Memory T cells are subdivided into central memory cells, which circulate through lymphoid organs, and effector memory cells, which patrol peripheral tissues; tissue-resident memory T cells remain in non-lymphoid tissues indefinitely.

Secondary response

On re-encounter with the same antigen, the secondary response is faster (days rather than a week or more), larger, and dominated by IgG rather than IgM, often preventing symptoms entirely. This is why most childhood infections are suffered only once, and why booster vaccinations are used to maintain protection where memory wanes.

Duration and complications

Memory to some pathogens, such as measles, can last a lifetime, while memory to others fades within years. Phenomena such as original antigenic sin — where memory of a related earlier strain shapes (and can bias) the response to a new strain — and antibody-dependent enhancement illustrate that memory is not always beneficial.
