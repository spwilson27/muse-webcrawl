Balinese script

The Balinese script, natively known as Aksara Bali and historically as Hanacaraka, is an abugida used in the island of Bali, Indonesia, traditionally for writing the Austronesian Balinese language, Old Javanese, and Sanskrit. It is a descendant of the Kawi script, itself derived from the Pallava and Brahmi scripts of India.

Characteristics

Like other Brahmic abugidas, each consonant letter carries an inherent vowel /a/, which is modified or suppressed by diacritics. The script has 47 letters in its full traditional form, though the modern script used for everyday Balinese employs a reduced set of 33 characters: 18 consonants, vowel signs, and numerals.

Usage

Balinese script is traditionally inscribed on lontar palm leaves for religious texts, literature, calendars, and magical inscriptions. Today it appears on public signage across Bali alongside the Latin alphabet, and it is taught in Balinese schools as part of local cultural education.

Unicode

The script was added to the Unicode Standard in 2006, in the Balinese block (U+1B00–U+1B7F).
