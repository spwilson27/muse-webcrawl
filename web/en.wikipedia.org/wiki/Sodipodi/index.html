Sodipodi

Sodipodi
Developer: Lauris Kaplinski and contributors
Initial release: 1999
Written in: C
Operating system: Linux, Windows, macOS
Type: Vector graphics editor
License: GNU GPL

Sodipodi is a free and open-source vector graphics editor, primarily developed by Lauris Kaplinski. Its name derives from the Estonian words sodi ("jumble" or "mess") and podi ("pot" or "mix"), roughly "mixed pot". Sodipodi was one of the earliest free SVG editors and served as the codebase from which Inkscape was forked in 2003.

History

Kaplinski began Sodipodi in 1999 as a successor to his earlier drawing program, Gill (GNOME Illustration Application). Gill was based on the rendering technology of GNOME Canvas and was among the first free programs to attempt an SVG-based illustration tool. Sodipodi adopted the Scalable Vector Graphics (SVG) format as its native file format at a time when SVG was a new W3C standard.

In 2003, a group of Sodipodi developers who wanted a stronger focus on full SVG compliance, a reorganized codebase, and a more community-driven development model forked the project to create Inkscape. Inkscape went on to become the dominant free vector graphics editor, while Sodipodi development slowed considerably, with sporadic releases into the 2000s.

Features

Sodipodi provides tools for creating and editing vector shapes, Bézier paths, text, gradients, and clones. It uses the SVG format natively and can import and export a variety of formats. Its user interface is based on the GTK+ toolkit. Unusually for its time, the interface emphasized a streamlined canvas with floating tool windows.
