Man page

A man page (short for manual page) is a form of software documentation found on Unix and Unix-like operating systems. Each man page is a self-contained document describing a command, library function, system call, file format or other topic, and is traditionally viewed with the man command.

Usage

To read the manual for a topic, a user types man topic at the command line. The system displays the page through a pager program such as less. Man pages are organised into numbered sections; for example, section 1 covers user commands, section 2 system calls, section 3 library functions, section 5 file formats and section 8 administrative commands. A topic with entries in several sections can be specified as man 2 open.

Layout

Man pages follow a conventional structure: a NAME section with a one-line summary, SYNOPSIS, DESCRIPTION, OPTIONS, EXAMPLES, and sections such as SEE ALSO, AUTHORS and BUGS. They are traditionally written in the roff typesetting language using the man macro package, and are rendered as formatted text on terminals.

History

The first man pages were written for the original Unix system at Bell Labs in 1971, beginning with the Unix Programmer's Manual prepared by Dennis Ritchie and Ken Thompson. The man page format has remained in continuous use for over fifty years and remains the standard reference documentation on Linux, the BSD systems and macOS, complemented today by info pages, built-in help and online documentation.
