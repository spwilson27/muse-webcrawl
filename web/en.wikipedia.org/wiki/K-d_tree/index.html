K-d tree

In computer science, a k-d tree (short for k-dimensional tree) is a space-partitioning data structure for organizing points in a k-dimensional space. It is a binary tree in which every leaf node is a k-dimensional point, and every non-leaf node defines a splitting hyperplane that divides the space into two parts, known as half-spaces. K-d trees were introduced by Jon Bentley in 1975.

Construction

Construction of a balanced k-d tree from a set of points proceeds recursively: at each level, choose a splitting dimension — often by cycling through the dimensions or by selecting the one with greatest spread — and pick the median point along that dimension as the node. Points with smaller coordinates in the splitting dimension go to the left subtree, and the rest to the right subtree. Using a linear-time median selection, the whole structure can be built in O(n log n) time. The result is a binary search tree generalised to multiple dimensions, in which every node implicitly represents an axis-aligned region (cell) of space.

Operations

The most important operation is nearest neighbour search: given a query point, traverse the tree to find the leaf region containing it, keep the best candidate point found, and then backtrack, pruning any subtree whose region cannot contain a closer point. In low dimensions this runs in roughly logarithmic time on average, which makes k-d trees a popular choice for nearest-neighbour classification and clustering. Range searches, orthogonal range reporting, and approximate nearest-neighbour queries are also supported.

Limitations

K-d trees suffer from the curse of dimensionality: as the number of dimensions grows (roughly beyond 20–30), nearest-neighbour search may have to visit nearly all points, and alternative methods such as ball trees, locality-sensitive hashing, or graph-based approximate search become preferable. Insertions and deletions can also unbalance the tree, so implementations often rebuild it periodically or use relaxed variants.

Applications

K-d trees are used in computer graphics (ray tracing acceleration with photon mapping), robotics and motion planning, geographic information systems, machine learning (for example the scikit-learn implementations of nearest-neighbour algorithms), computer vision for feature matching, and databases for multidimensional indexing.
