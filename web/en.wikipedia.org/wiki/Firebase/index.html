Firebase

Firebase may refer to:

  • Firebase (also called a fire support base), a temporary military encampment used to provide artillery fire support, most notably during the Vietnam War — see Fire support base.
  • Firebase, a set of back-end cloud computing services and application development platforms provided by Google, including hosting, real-time databases, authentication and analytics for mobile and web applications.

Firebase (platform)

The software platform began as Envolve, a startup founded in 2011 by James Tamplin and Andrew Lee that provided developers with a real-time chat API. The founders noticed the system was being used to pass application data more than chat messages, and spun out the database technology as Firebase. Google acquired the company in October 2014 and integrated it into its cloud offerings, announcing a major expansion at Google I/O 2016.

Firebase provides developers with services intended to replace a self-managed back end: the Realtime Database and its successor Cloud Firestore synchronise JSON-like data across clients; Firebase Authentication handles user sign-in; Cloud Functions runs serverless back-end code; Firebase Hosting serves web content; and tools such as Cloud Messaging, Remote Config, Crashlytics and Analytics support engagement and quality monitoring. The platform is widely used for rapid development of Android, iOS and web applications.
