Count–min sketch

The count–min sketch is a probabilistic data structure, introduced by Graham Cormode and S. Muthu Muthukrishnan in 2003, that serves as a frequency table of events in a stream of data. It uses hash functions to map events to frequencies and occupies sub-linear space.

Operation

The structure is a two-dimensional array of counters of width w and depth d. Each arriving item is hashed once per row and the corresponding counters are incremented; the estimated count of an item is the minimum of its counters across rows, which can overestimate but never underestimate the true count.

Applications

Count–min sketches are used in databases, network traffic measurement and natural language processing to track frequent items in massive data streams.
