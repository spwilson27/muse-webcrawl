Smith–Volterra–Cantor set

In mathematics, the Smith–Volterra–Cantor set (SVC), also known as the fat Cantor set, is an example of a set of points on the real line ℝ that is nowhere dense (in particular it contains no intervals), yet has positive Lebesgue measure. It is named after the mathematicians Henry Smith, Vito Volterra and Georg Cantor. In an 1875 paper, Smith became the first to discuss a nowhere-dense set of positive measure.

Construction

Similar to the construction of the Cantor set, the Smith–Volterra–Cantor set is constructed by removing certain intervals from the unit interval [0, 1]. The process starts by removing the open middle interval of length 1/4 from the middle of [0, 1], leaving [0, 3/8] ∪ [5/8, 1]. At the next step, an interval of length 1/16 is removed from the middle of each remaining interval, and in general at step n an interval of length 1/22n is removed from the centre of each of the 2n−1 remaining intervals.

The total length removed is 1/4 + 1/8 + 1/16 + … = 1/2, so the set remaining has measure 1 − 1/2 = 1/2. By choosing the removed lengths appropriately, one can obtain a fat Cantor set of any measure strictly between 0 and 1.

Properties

  • The SVC is compact, nowhere dense, and totally disconnected, like the standard Cantor set.
  • Unlike the standard Cantor set, it has positive Lebesgue measure (1/2 in the construction above).
  • It contains no intervals, yet it has the same cardinality as [0, 1].
  • The boundary of the set equals the set itself.

Uses

The Smith–Volterra–Cantor set is used in the construction of Volterra's function, a differentiable function whose derivative is bounded but not Riemann integrable — a classic counterexample showing that the fundamental theorem of calculus cannot be extended to all bounded derivatives within Riemann integration. Analogous constructions in the plane yield sets such as Osgood curves, Jordan curves of positive area.
