Computer architecture

In computer science and computer engineering, computer architecture is a description of the structure of a computer system made from component parts. It can sometimes be a high-level description that ignores details of the implementation. At a more detailed level, the description may include the instruction set architecture design, microarchitecture design, logic design, and implementation.

A common definition distinguishes three levels:

  • Instruction set architecture (ISA) — the abstract model of the machine visible to programmers and compilers: the instruction set, registers, addressing modes, data types, memory model, and exception behaviour. Examples include x86-64, ARM AArch64, and RISC-V.
  • Microarchitecture (computer organisation) — a particular implementation of an ISA: pipelines, caches, branch predictors, superscalar execution units, and interconnects. Many different microarchitectures can implement the same ISA.
  • System design — the organisation of the whole system: memory hierarchy, buses, I/O, multiprocessors, and accelerators.

History

The stored-program concept described in John von Neumann's 1945 First Draft of a Report on the EDVAC gave the canonical "von Neumann architecture": a processing unit, control unit, memory holding both instructions and data, and input/output. The Harvard architecture (from the Harvard Mark I) separates instruction and data storage; most modern machines use a modified Harvard design with unified main memory but separate instruction and data caches. Fred Brooks popularised "architecture" for the conceptual structure of the IBM System/360 family (1964), which introduced the idea of a compatible family of machines sharing one ISA.

Design goals and techniques

Architects balance performance, energy efficiency, cost, and reliability. Key techniques include pipelining, superscalar and out-of-order execution, speculative execution and branch prediction, SIMD/vector instructions, cache hierarchies, virtual memory, multicore and many-core parallelism, and heterogeneous accelerators such as GPUs. The slowdown of Moore's law and the end of Dennard scaling since the mid-2000s pushed the field toward parallelism and domain-specific architectures. Quantitative evaluation (benchmarks, simulation, Amdahl's law) is a hallmark of the discipline, codified in Hennessy and Patterson's Computer Architecture: A Quantitative Approach.
