Sphinx (documentation generator)

Original authorGeorg Brandl
Initial releaseMarch 2008
Written inPython
LicenseBSD license
Websitesphinx-doc.org

Sphinx is a documentation generator written in Python that converts files written in lightweight markup languages — principally reStructuredText, and Markdown via the MyST parser — into HTML, PDF (via LaTeX), ePub, man pages, and other formats. It was created by Georg Brandl and first released in 2008 to produce the documentation for the Python programming language itself, and has since become the standard documentation tool for the Python ecosystem and many other projects.

Features

  • Cross-referencing: semantic markup roles and directives let authors link between documents, sections, glossary terms, functions, classes, and modules, with automatic index generation.
  • API documentation: the autodoc extension extracts documentation from Python docstrings, building reference pages automatically from source code; companion tools such as Napoleon support Google-style and NumPy-style docstrings.
  • Multiple outputs and themes: a single source produces websites with selectable themes, printable PDFs through LaTeX, and other formats.
  • Extensibility: a large ecosystem of extensions adds support for testing code examples (doctest), diagrams, Jupyter notebooks, versioned documentation, and internationalisation (i18n) with gettext catalogues.
  • Intersphinx: inventories allow cross-references to resolve to the documentation of other projects hosted elsewhere.

Usage

Sphinx powers the official documentation of Python, the Linux kernel, Django, NumPy, SciPy, and hundreds of other projects, and it is the backend most commonly used with the Read the Docs hosting service. A project is configured through a conf.py file and a master document with a table of contents tree (toctree); sources are built with the sphinx-build command or the generated Makefile.
