GNU GRUB

GNU GRUB (short for GNU GRand Unified Bootloader) is a multiboot bootloader package from the GNU Project. It allows a user to have multiple operating systems on a computer and choose which one to run when the machine starts, and it can load kernels conforming to the Multiboot specification as well as chain-load others, including Windows.

GRUB was originally written by Erich Boleyn in 1995; GRUB 2, a complete rewrite, became the default bootloader of most Linux distributions, including Ubuntu and Fedora. It supports many filesystems, graphical menus, scripting, and both BIOS and UEFI firmware. Configuration is typically generated from /etc/default/grub and scripts in /etc/grub.d into grub.cfg.
