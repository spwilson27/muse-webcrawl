Darwin Core (often abbreviated DwC) is a standard vocabulary of terms for sharing information about biological diversity — above all, records of where and when organisms have been observed or collected. It is maintained by Biodiversity Information Standards (TDWG) and is the principal data standard behind global aggregators such as the Global Biodiversity Information Facility (GBIF), which indexes billions of species occurrence records published in Darwin Core format.

Structure

The standard defines a glossary of terms organised into classes such as Occurrence (an organism at a place and time), Event (a sampling or observation event), Location, GeologicalContext, Identification, Taxon and MeasurementOrFact. Familiar terms include scientificName, decimalLatitude, decimalLongitude, eventDate, basisOfRecord and occurrenceID. Terms have stable identifiers so that datasets from museums, herbaria and citizen-science projects can be combined reliably.

Darwin Core Archive

For exchange, data are usually packaged as a Darwin Core Archive (DwC-A): a compressed bundle of one or more UTF-8 text files of tabular data together with an XML descriptor (meta.xml) mapping columns to Darwin Core terms and an Ecological Metadata Language (EML) file describing the dataset. Publishers typically expose archives through the Integrated Publishing Toolkit (IPT).

History

Darwin Core grew out of efforts in the late 1990s and 2000s to network natural history collection databases, drawing on earlier species-analyst and Dublin Core traditions — the name echoes the Dublin Core metadata standard as much as Charles Darwin. It was ratified as a TDWG standard in 2009 and has been extended since, for example to support extended specimen data and DNA-derived occurrences.
