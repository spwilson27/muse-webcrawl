Non-measurable set


Labelled placeholder: Vitali construction

In mathematics, a non-measurable set is a set which cannot be assigned a meaningful "volume" in the standard way. The mathematical existence of such sets is construed to reveal the notions of length, area and volume in formal set theory to be ill-defined. The notion of a non-measurable set has been a source of great controversy since its introduction by Giuseppe Vitali in 1905.

The Vitali set is the first example of such a set. The Banach–Tarski paradox goes further: it states that a solid ball can be decomposed and reassembled into two balls each identical to the original.

Historical constructions

In 1905, Vitali was the first to show that the real numbers contain a subset that is not Lebesgue measurable. The Vitali set is constructed using the axiom of choice: consider the equivalence relation on the real numbers in which two numbers are equivalent if they differ by a rational number; selecting one representative from each equivalence class within [0,1] yields a set that cannot be Lebesgue measurable, because countably many disjoint translates of it would have to fill an interval while sharing the same measure.

In 1970, Robert M. Solovay constructed the Solovay model, which shows that it is consistent with standard set theory without the axiom of choice that all subsets of the real numbers are Lebesgue measurable. However, this result depends on the existence of an inaccessible cardinal, which cannot be proven within the usual ZFC system.

Considerations

If A is a subset of R with positive outer measure, then A contains a non-measurable subset. The existence of non-measurable sets depends essentially on the axiom of choice; in its absence (as in the Solovay model), every subset of R can be measurable.
