Tabu search

Tabu search (TS) is a metaheuristic search method employing local search methods used for mathematical optimization. It was created by Fred W. Glover in 1986 and formalized in 1989. Local (neighbourhood) searches take a potential solution to a problem and check its immediate neighbours in the hope of finding an improved solution, but they tend to become stuck in suboptimal regions. Tabu search enhances local search by relaxing its basic rule: worsening moves can be accepted if no improving move is available, and prohibitions (the "tabu" lists) discourage the search from returning to previously visited solutions.

Mechanism

The method keeps a short-term memory of recently visited solutions or recently applied moves, which are declared tabu (forbidden) for a certain number of iterations (the tabu tenure). An aspiration criterion — most commonly, finding a solution better than the best known so far — can override a move's tabu status. Long-term memory structures such as frequency counts support diversification into unexplored regions and intensification around promising ones.

Applications

Tabu search has been applied to scheduling, vehicle routing, the travelling salesman problem, telecommunications network design, quadratic assignment, graph colouring and many other combinatorial optimization problems, often with results competitive with the best known methods.
