Executable

In computing, an executable is a file that causes a computer "to perform indicated tasks according to encoded instructions", as opposed to a data file that must be interpreted by a program to be meaningful. These instructions are traditionally machine code instructions for a physical CPU; however, in a broader sense a file containing instructions for a software interpreter — a script — is also considered executable. The term is often used as a noun ("an executable") for the file itself, which commonly carries the filename extension .exe on DOS and Windows systems.

Executable file formats

An executable file typically contains, in addition to machine code, data, resources (such as icons and text), and metadata describing how the operating system's loader should prepare the program in memory — for example which shared libraries to load and where to begin execution. Major formats include:

  • PE (Portable Executable) — used by Windows for .exe and .dll files.
  • ELF (Executable and Linkable Format) — standard on Linux and most Unix-like systems.
  • Mach-O — used by macOS and iOS.
  • COM and MZ formats — historical DOS executables.
  • Bytecode formats — such as Java class files and .NET assemblies, executed by a virtual machine.

Creation and execution

Executables are usually produced from source code by a compiler and linker, which translate high-level language statements into machine code and resolve references between object files and libraries. When a user runs an executable, the operating system creates a process, maps the file into virtual memory, performs dynamic linking and relocation, and transfers control to the entry point. On Unix-like systems, any file — including a text script starting with a "shebang" line — can be made executable by setting the execute permission bit.

Security

Because executables contain arbitrary instructions, they are a principal vehicle for malware; operating systems and browsers therefore warn before running executables from untrusted sources, and modern platforms employ code signing, sandboxing and address-space layout randomisation to mitigate abuse.
