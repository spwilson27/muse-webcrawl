Boundedness

Boundedness is a mathematical concept describing sets, functions, or sequences that are confined within some finite limit. The term appears in several branches of mathematics with related but distinct meanings.

Field: Mathematics
Related: Bounded set, bounded function, bounded operator

Bounded set

In a metric space, a set is bounded if its diameter — the supremum of distances between its points — is finite; equivalently, if it fits inside a ball of finite radius. In the real numbers, a set is bounded if it has both an upper and a lower bound. The Heine–Borel theorem relates boundedness, combined with closedness, to compactness in Euclidean space.

Bounded function

A real-valued function is bounded if its range is a bounded set, that is, if there is a number M such that |f(x)| ≤ M for all x in its domain. The sine and cosine functions are bounded; the function 1/x on (0, 1) is not. Bounded functions on an interval form the space underlying much of analysis, and every continuous function on a compact set is bounded.

Other uses

A linear operator between normed spaces is called bounded if it maps bounded sets to bounded sets, which for linear operators is equivalent to continuity. In order theory, a subset of a partially ordered set is bounded if it has upper and lower bounds within the order. "Boundedness" also names a principle in the theory of dynamical systems and in Karl Weierstrass's and Bernhard Bolzano's theorem that every bounded sequence of real numbers has a convergent subsequence.
