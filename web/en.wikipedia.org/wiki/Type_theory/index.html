Type theory

Type theory
FieldMathematical logic, computer science
Key figuresBertrand Russell, Alonzo Church, Per Martin-Löf

In mathematics, logic and computer science, a type theory is the formal presentation of a specific type system, a collection of rules assigning a property called a type to terms — for example, classifying expressions as numbers, strings or functions. Type theories serve both as foundations of mathematics and as the basis of typed programming languages and proof assistants.

History

Type theory originated with Bertrand Russell's response to the paradoxes of naive set theory: his ramified theory of types, presented in Principia Mathematica (1910–13, with Alfred North Whitehead), stratified entities into a hierarchy to block self-reference. Alonzo Church's simply typed lambda calculus (1940) gave an influential simplified system. In the 1970s Per Martin-Löf developed intuitionistic (dependent) type theory, in which types may depend on values, unifying logic and computation through the Curry–Howard correspondence between propositions and types and between proofs and programs.

Main ideas

A type theory is specified by judgements — principally the typing judgement that a term t has type T in a context Γ — together with formation, introduction, elimination and computation rules. Dependent types allow rich specifications; inductive types encode data such as natural numbers and lists. Modern systems, including the calculus of constructions underlying the Coq and Lean proof assistants, extend these ideas, and homotopy type theory adds a homotopical interpretation of identity types.
