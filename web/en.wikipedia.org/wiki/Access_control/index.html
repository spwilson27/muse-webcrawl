Access control

Access control
FieldSecurity, computer security
ModelsDAC, MAC, RBAC, ABAC
ComponentsAuthentication, authorisation, audit

Access control is the selective restriction of access to a place, resource or data. In physical security it includes locks, guards, fences and electronic systems such as card readers and biometric scanners. In computer security, access control is the process by which a system determines whether a subject (user or process) may perform an operation on an object, following authentication of the subject's identity.

Models

  • Discretionary access control (DAC) — the owner of a resource decides who may access it, as in Unix file permissions.
  • Mandatory access control (MAC) — a central policy, based on security labels and clearances, governs access; used in high-security systems.
  • Role-based access control (RBAC) — permissions are assigned to roles, and users acquire permissions through role membership.
  • Attribute-based access control (ABAC) — decisions are computed from attributes of the user, resource and environment.

Implementation

Operating systems enforce access control with access control lists (ACLs) or capability lists; web applications commonly use session tokens and authorisation frameworks such as OAuth 2.0. Effective access control follows the principle of least privilege, granting only the access necessary for a task.
