Base32

Base32 is the base-32 transfer encoding using the twenty-six upper-case letters A–Z and the digits 2–7. It is designed to represent binary data in an ASCII string format by translating the data into a radix-32 representation. Base32 is defined in RFC 4648, along with the related Base16 and Base64 encodings.

Encoding

Base32 encodes five bytes (40 bits) of input into eight characters, each character carrying five bits. The resulting output is about 60% longer than the original data. Input that is not a multiple of five bytes is padded with "=" characters to a multiple of eight output characters.

Alphabets

The standard alphabet uses A–Z followed by 2–7; the digit 0 is avoided to prevent confusion with the letter O, and 1 with I or L. Variants include the "base32hex" alphabet, which preserves lexicographic ordering, and Douglas Crockford's Base32, which excludes I, L, O and U to avoid ambiguity and accidental profanity. z-base-32 is another variant used in some peer-to-peer systems.

Applications

Base32 is widely used for encoding TOTP and HOTP shared secrets in two-factor authentication, onion service addresses in earlier Tor versions, and human-readable identifiers such as file hashes in the NSEC3 and DNSSEC protocols.
