WinZip is a file archiver and compressor for Windows and other platforms, first released in 1991 by Nico Mak Computing. Originally a graphical front-end for the PKZIP archiver, it became one of the most widely used utilities of the early personal-computing era for creating and extracting ZIP archives.

History

WinZip spread rapidly in the 1990s as shareware distributed on bulletin boards and the early web, at a time when compressing files was essential for floppy disks and slow dial-up connections. WinZip Computing was acquired by Corel in 2006.

Features

Modern versions support ZIP and Zipx (with advanced compression methods), open RAR, 7z, TAR and other formats, apply AES encryption, and integrate with cloud storage and file-sharing services. Versions are available for Windows, macOS, iOS and Android.
