Template (C++)

Templates are a feature of the C++ programming language that allows functions and classes to operate with generic types, so a single definition can work with many different data types. Function templates and class templates are compiled into concrete instances for each type used, a process called instantiation. Templates underpin the Standard Template Library and much of generic programming in C++.

Function and class templates

A function template such as template<typename T> T max(T a, T b) generates an ordinary function for each argument type. Class templates such as std::vector<T> generate container classes parameterised by element type. Templates may also take non-type parameters, such as integer sizes.

Advanced features

Template specialisation allows a custom implementation for a particular type. Variadic templates (C++11) accept any number of parameters, and concepts (C++20) constrain template arguments with named requirements. Heavy compile-time computation is possible through template metaprogramming, though it can lengthen compile times and produce difficult error messages.
