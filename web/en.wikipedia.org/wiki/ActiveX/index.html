ActiveX is a deprecated software framework created by Microsoft in 1996 that adapts its earlier Component Object Model (COM) and Object Linking and Embedding (OLE) technologies for content downloaded from a network, particularly from the World Wide Web. ActiveX controls are small program building blocks that can be embedded in applications and web pages, most famously in Internet Explorer.

History

Microsoft introduced ActiveX in March 1996, rebranding its OLE controls (OCX) for the internet era. Controls could be written in C++, Visual Basic, Delphi, and other languages, digitally signed with Authenticode, and automatically downloaded and installed when a user visited a page that referenced them. The technology powered rich intranet applications, online banking in some countries (notably South Korea, where it was long mandated for secure transactions), media players, and document viewers.

Security concerns

Unlike sandboxed Java applets, ActiveX controls run with the full privileges of the user once installed, and its security model relied largely on trusting the publisher's signature. This made malicious or buggy controls a major vector for malware in the 2000s, and browsers responded with information bars, "kill bits" for vulnerable controls, and default blocking. Competing browsers never adopted ActiveX, tying the technology to Internet Explorer on Windows.

Decline

With the rise of HTML5, plugin-free web standards, and Microsoft's retirement of Internet Explorer, ActiveX was deprecated: Microsoft Edge does not support it (an IE mode preserves it for legacy enterprise sites), and Windows 11 removed Internet Explorer entirely. ActiveX remains in maintenance in some legacy enterprise and government systems.
