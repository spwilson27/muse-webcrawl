Hibernation (computing)

Hibernation (also known as suspend to disk, or Safe Sleep on Macintosh computers) in computing is powering down a computer while retaining its state. When hibernation begins, the computer saves the contents of its random access memory (RAM) to a hard disk or other non-volatile storage. When the computer is turned back on, the saved state is restored and the user can resume work exactly where they left off.

Comparison with sleep mode

Hibernation corresponds to ACPI state S4. Unlike sleep mode (suspend to RAM, S3), which keeps the memory powered and therefore draws a small amount of electricity, hibernation consumes no power at all and the machine can be unplugged or have its battery removed. The trade-off is speed: resuming from hibernation requires reading the memory image back from storage and is slower than waking from sleep, though fast solid-state drives have narrowed the gap.

Implementation

On Microsoft Windows the memory image is written to the file hiberfil.sys in the root of the system drive. Linux supports hibernation through kernel mechanisms such as swsusp and uswsusp, writing the image to a swap partition or file. Apple's macOS "Safe Sleep" writes the memory image to disk automatically when a laptop sleeps, so that the session survives a complete battery drain.

Hybrid sleep

Some systems combine the two approaches in hybrid sleep: the machine enters sleep mode but also writes a hibernation image, so it wakes instantly if power is retained but can still resume from disk if power is lost.
