Manchester code

In telecommunications and data storage, Manchester code (also known as phase encoding, or PE) is a line code in which each data bit is represented by a transition in the middle of the bit period. It was developed at the University of Manchester, from which it takes its name.

Encoding

In the convention used by the IEEE 802.3 (Ethernet) standard, a binary 1 is represented by a low-to-high transition in the middle of the bit period, and a binary 0 by a high-to-low transition. (An alternative convention, used by G. E. Thomas, reverses these transitions.) Because every bit contains a transition, the receiver can recover the clock signal from the data itself, making the code self-clocking.

Properties

Manchester code has no DC component, since over each bit period the signal spends equal time high and low, which makes it suitable for transmission over AC-coupled links such as transformers and optical channels. The guaranteed mid-bit transitions simplify clock recovery but come at a cost: the code requires roughly twice the bandwidth of simple non-return-to-zero encoding, since the signalling rate is doubled relative to the data rate.

Applications

Manchester code was used in the physical layer of the original 10BASE5 and 10BASE2 Ethernet standards and in the IEC 60958 digital audio interface (AES3/S/PDIF) in a variant called biphase mark code. It is also found in RFID systems, infrared remote control protocols and some magnetic recording schemes. Differential Manchester encoding, a variant, is used in token ring networks.
