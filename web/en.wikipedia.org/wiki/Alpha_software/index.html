Alpha software

Alpha software is software in the alpha phase of the software release life cycle — the first phase of active testing, following pre-alpha development and preceding beta. Alpha versions are typically unstable, may lack some planned features, and are tested primarily by the developers and internal quality-assurance teams ("white-box" testing).

Characteristics

An alpha release is generally feature-incomplete or early in feature completion, and is not intended for general users, although some projects release public alphas. Bugs, crashes, and data loss are expected. The term "alpha" comes from the first letter of the Greek alphabet, matching its position as the first testing stage.

Release cycle

The typical sequence runs: pre-alpha → alpha → beta → release candidate → general availability (stable). Alpha testing focuses on finding defects early, when they are cheapest to fix, and on validating core functionality before external beta testers become involved.
