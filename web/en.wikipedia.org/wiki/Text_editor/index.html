Text editor

A text editor is a type of computer program that edits plain text. An example of such program is "notepad" software (e.g. Windows Notepad). Text editors are provided with operating systems and software development packages, and can be used to change files such as configuration files, documentation files and programming language source code. Unlike word processors, text editors do not add formatting information to the text itself, though they may display it with syntax highlighting, line numbers, and folding.

Types

Early text editors worked line by line: line editors such as ed on Unix and TECO operated on one line at a time because terminal displays were limited. Full-screen editors, exemplified by vi (1976, Bill Joy) and Emacs (1976, Richard Stallman and others), display a screenful of text that can be edited directly, and became the dominant form. Editors are often classified by their editing model—modal editors such as Vim switch between command and insert modes, while modeless editors such as most graphical editors and Visual Studio Code use modifier keys and menus. Programmable editors (Emacs with Lisp, Vim with Vimscript) can be extensively extended and are often compared in the long-running "editor war" culture of computing.

Features

Common features include search and replace (often with regular expressions), cut/copy/paste, undo and redo, text folding, multiple open files in tabs or buffers, macros, spell checking, and integration with compilers and version control through integrated development environments (IDEs), which build on text editor cores with debugging and project management tools.
