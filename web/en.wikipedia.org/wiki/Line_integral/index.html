Line integral

Line integral
Field: Vector calculus
Types: Scalar field, vector field
Related: Surface integral, Green's theorem, Stokes' theorem

In mathematics, a line integral is an integral where the function to be integrated is evaluated along a curve. The terms path integral, curve integral and curvilinear integral are also used; contour integral is used as well, although that is typically reserved for line integrals in the complex plane.

Definition

The functions to be integrated may be scalar fields or vector fields. For a scalar field f along a smooth curve C parametrised by r(t), the line integral is ∫C f ds = ∫ f(r(t)) |r′(t)| dt, which can be interpreted as the area of a "curtain" beneath the curve. For a vector field F, the line integral ∫C F · dr measures the work done by the field along the path and depends on the direction of traversal.

Applications and results

Line integrals are fundamental in physics, for example in computing the work done on an object moving in a force field, and in electromagnetism. Fundamental results include the fundamental theorem for line integrals (for conservative fields the integral is path-independent and depends only on the endpoints), Green's theorem, Stokes' theorem and the divergence theorem. In complex analysis, line (contour) integrals underlie Cauchy's integral theorem and the residue theorem.
