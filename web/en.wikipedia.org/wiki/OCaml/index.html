OCaml (formerly Objective Caml) is a general-purpose, multi-paradigm programming language that extends the Caml dialect of ML with object-oriented features. Developed since 1996 mainly by the French research institute Inria, OCaml is known for combining the expressiveness and safety of a statically typed functional language — with full type inference, pattern matching, algebraic data types, and parametric polymorphism — with a fast native-code compiler and pragmatic support for imperative and modular programming.

Features

OCaml's hallmark features include a powerful module system with functors (modules parametrised by other modules), first-class functions and currying, immutable data by default with optional mutable records and arrays, exceptions, and garbage collection. Its type inference means programmers rarely write type annotations yet all code is statically checked. Foreign-function interfaces to C, an interactive toplevel, and tools such as the dune build system and the opam package manager support large projects. OCaml 5 (2022) added native multicore parallelism with domains and algebraic effect handlers.

Applications

OCaml is used where correctness and performance both matter. Notable users and projects include the Coq proof assistant, the MirageOS unikernel library, the Hack typechecker and Flow at Meta, the Tezos blockchain, and trading systems at Jane Street, which is one of the language's largest industrial users. Facebook's ReasonML/Reason language and the ReScript compiler target OCaml-family syntax. Derivative and sibling languages include F#, which adopted much of the OCaml design for the .NET platform.

History

OCaml descends from Robin Milner's ML, created in the 1970s for the LCF theorem prover. The Caml implementation was developed at Inria in the 1980s; Xavier Leroy's Caml Light followed, and in 1996 the object system and native compiler of Objective Caml appeared, renamed OCaml in 2011. Development is now coordinated through the OCaml Software Foundation.
