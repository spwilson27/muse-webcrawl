Linear classifier

From Wikipedia, the free encyclopedia

In the field of machine learning, a linear classifier is a classification model that makes its decision based on a linear combination of the input features. Such classifiers work well for many practical problems, especially when the number of features is large compared to the number of training samples, as in text classification.

Definition

If the input feature vector is x, the output class y, and the learned weight vector is w, then a binary linear classifier predicts y = 1 if w·x + b exceeds a threshold (usually zero) and y = 0 otherwise. Because the decision boundary is the hyperplane w·x + b = 0, the two classes are separated by a flat surface. For multiclass problems, a common approach is to learn one weight vector per class and predict the class with the highest score wk·x.

Generative and discriminative models

Linear classifiers fall into generative models, which model the joint distribution of features and classes — such as linear discriminant analysis and naive Bayes — and discriminative models, which model the decision boundary or posterior directly. Logistic regression and the perceptron and linear support vector machines are leading discriminative examples, differing in their loss functions: log loss for logistic regression, hinge loss for the SVM, and the perceptron criterion for Rosenblatt's perceptron.
