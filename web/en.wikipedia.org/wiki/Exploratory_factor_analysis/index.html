Exploratory factor analysis

Observed variables and their loadings on underlying latent factors.

In multivariate statistics, exploratory factor analysis (EFA) is a statistical method used to uncover the underlying structure of a relatively large set of variables. EFA is a technique within factor analysis whose overarching goal is to identify the underlying relationships between measured variables. It is commonly used by researchers when developing a scale and serves as a technique to identify the latent constructs underlying a battery of measured variables.

EFA is used when the researcher does not know how many factors are needed to explain the relationships among a set of indicators, or which variables belong to which factor. This contrasts with confirmatory factor analysis (CFA), in which the structure is specified in advance and tested.

Procedure

  1. Extracting factors. Common methods include principal axis factoring and maximum likelihood estimation. (Principal component analysis is a related but distinct data-reduction technique.)
  2. Deciding the number of factors. Researchers use the Kaiser criterion (eigenvalues greater than 1), scree plots, and parallel analysis.
  3. Rotation. The initial solution is rotated to a simpler, more interpretable structure. Orthogonal rotations (such as varimax) keep factors uncorrelated; oblique rotations (such as promax or oblimin) allow factors to correlate.
  4. Interpretation. Variables with high loadings on a factor are used to infer what the latent factor represents.

Applications

EFA is widely used in psychology (notably in the development of personality inventories such as the Big Five), marketing research, education, and the social sciences generally, wherever a large questionnaire or test battery is hypothesised to measure a smaller number of underlying traits.
