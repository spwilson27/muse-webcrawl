DFT matrix

In applied mathematics, a DFT matrix is a square matrix expression of a discrete Fourier transform (DFT) as a transformation matrix, which can be applied to a signal through matrix multiplication. It is a special case of a Vandermonde matrix whose entries are powers of a primitive root of unity.

Definition

An N-point DFT is expressed as the multiplication X = Wx, where x is the input signal vector, W is the N-by-N DFT matrix, and X is the DFT of the signal. The entries of W are Wjk = ωjk, where ω = e−2πi/N is the N-th primitive root of unity and the indices j and k run from 0 to N−1. The DFT matrix is symmetric under this convention, and its inverse is its complex conjugate scaled by 1/N.

Properties

The DFT matrix is a Vandermonde matrix built on the roots of unity on the unit circle, and it is unitary up to the normalisation factor √N. Its eigenvalues take only four possible values. Multiplying by the DFT matrix directly costs O(N2) arithmetic operations, so practical implementations of the DFT use fast Fourier transform algorithms such as the Cooley–Tukey algorithm instead of explicit matrix multiplication.
