Structure (mathematical logic)

In universal algebra and in model theory, a structure consists of a set along with a collection of finitary operations and relations that are defined on it. In model theory, a structure is the mathematical object that a formal sentence of a formal language is interpreted in: given a signature σ consisting of constant symbols, function symbols, and relation symbols (each with an arity), a σ-structure is a set (the domain or universe) together with an interpretation of each symbol of the signature as a constant element, function, or relation on that set.

Definition

Formally, a structure for a signature σ = (C, F, R) consists of a non-empty set A called the domain, and an interpretation function that assigns: to each constant symbol c in C an element cA of A; to each n-ary function symbol f in F a function fA : An → A; and to each n-ary relation symbol R in R a relation RA ⊆ An. The cardinality of A is called the cardinality of the structure.

Examples

The standard model of arithmetic is the structure whose domain is the set of natural numbers, with the constant 0, the successor function, addition, multiplication, and the usual ordering interpreting the corresponding symbols. In algebra, groups, rings, and fields can all be regarded as structures for suitable signatures; a graph is a structure for a signature with a single binary relation symbol.

Models and satisfaction

Given a σ-structure A and a sentence φ of the first-order language over σ, A is called a model of φ if φ is true in A under the interpretation, written A ⊨ φ. Satisfaction is defined inductively on the construction of formulas, extending the interpretation to terms and assignments of variables (Tarski's definition of truth).

Substructures and embeddings

A substructure is a structure whose domain is a subset closed under the interpretations of the function symbols and constants, with relations restricted to that subset. An embedding is an injective map preserving the interpretations of all symbols; elementary embeddings additionally preserve all first-order truths. These notions underlie fundamental results such as the Löwenheim–Skolem theorem and compactness arguments in model theory.
