Linked list

In computer science, a linked list is a linear collection of data elements whose order is not given by their physical placement in memory. Instead, each element (node) points to the next one. It is a data structure consisting of a collection of nodes which together represent a sequence.

Trade-offs

Linked lists allow efficient insertion and removal of elements at known positions in constant time, and can grow dynamically without reallocation. However, they offer no random access — reaching the k-th element requires traversing k nodes — and the extra pointer storage and poor cache locality make them slower than arrays for many workloads.

Variants

In a singly linked list each node points to the next; a doubly linked list also points to the previous node, enabling bidirectional traversal; in a circular linked list the last node points back to the first. Linked lists were developed in 1955–56 by Allen Newell, Cliff Shaw, and Herbert A. Simon at RAND for the Information Processing Language.
