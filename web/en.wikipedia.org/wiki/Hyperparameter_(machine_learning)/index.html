Hyperparameter (machine learning)

In machine learning, a hyperparameter is a parameter whose value is used to control the learning process, in contrast to ordinary model parameters whose values are derived from training data. Hyperparameters must be set before training begins (or tuned by an outer optimisation loop).

Examples

Examples include the learning rate of a neural network, the number of hidden layers and units, batch size, the number of epochs, the regularisation strength, the number k of neighbours in k-nearest neighbours, the maximum depth of a decision tree, and the kernel and penalty parameter C of a support vector machine.

Tuning

Selecting good hyperparameters — hyperparameter optimisation — is usually done by evaluating candidate configurations on validation data, using methods such as grid search, random search or Bayesian optimisation. Because hyperparameters are not learned directly from the training set, tuning on the test set would leak information and overfit; nested cross-validation or a separate validation set is used to avoid this.

Distinguishing features

Hyperparameters may be continuous, integer or categorical, and they often strongly influence model behaviour: a learning rate that is too large can cause divergence, while one that is too small slows convergence. Automated machine learning (AutoML) systems attempt to reduce the manual effort of choosing them.
