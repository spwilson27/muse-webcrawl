Cluster analysis or clustering is the task of grouping a set of objects in such a way that objects in the same group (called a cluster) are more similar to each other than to those in other groups. It is a main task of exploratory data analysis and a common technique for statistical data analysis, used in fields including pattern recognition, image analysis, information retrieval, bioinformatics and data compression.

Approaches

Connectivity-based clustering (hierarchical clustering) builds nested clusters by merging or splitting them successively, represented by a dendrogram. Centroid-based clustering, typified by the k-means algorithm, represents each cluster by a mean vector. Distribution-based clustering models clusters as statistical distributions. Density-based methods such as DBSCAN and OPTICS define clusters as connected dense regions and can find arbitrarily shaped clusters while marking sparse points as noise.

Evaluation

Because clustering is unsupervised, evaluating results is difficult. Internal measures such as the silhouette coefficient assess cohesion and separation using the data alone; external measures compare a clustering against known ground-truth labels. Choosing the number of clusters and the similarity measure strongly affects outcomes.
