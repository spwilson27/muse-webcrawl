Geolocation

Geolocation is the identification or estimation of the real-world geographic location of an object, such as a radar source, mobile phone, or Internet-connected computer terminal. In its broadest sense, geolocation involves estimating the position of a device or user, usually expressed as latitude and longitude, and is used in applications ranging from navigation and mapping to location-based services, advertising, and law enforcement.

Methods

Position can be determined by satellite navigation systems such as the Global Positioning System (GPS), which uses signals from satellites to calculate precise coordinates. Where GPS is unavailable, devices use cell tower triangulation, Wi-Fi positioning based on known access points, or IP address geolocation, which maps an Internet address to an approximate location using databases maintained by geolocation providers. Modern smartphones combine these sources in "fused" location services for improved accuracy.

Applications

Geolocation underlies turn-by-turn navigation, ride-hailing, asset and fleet tracking, geotagging of photographs and social media posts, proximity-based recommendations, and location-targeted advertising. Web browsers expose a Geolocation API, subject to user permission, allowing websites to request a device's position.

Privacy

Precise location data is considered sensitive personal information, and its collection has raised privacy concerns. Regulations such as the European Union's General Data Protection Regulation impose conditions on collecting and retaining location data, and operating systems increasingly limit background location access and report approximate rather than precise positions.
