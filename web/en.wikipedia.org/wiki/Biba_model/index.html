The Biba model (also called the Biba Integrity Model) is a formal state transition system of computer security policy describing a set of access control rules designed to ensure data integrity. It was developed by Kenneth J. Biba in 1977 and is the integrity counterpart of the confidentiality-focused Bell–LaPadula model.

Rules

Subjects and objects are assigned integrity labels (levels). The model's core policies are the strict integrity policy: the simple integrity property ("no read down") — a subject may not read data at a lower integrity level, which would contaminate it with less trustworthy information; and the integrity *-property ("no write up") — a subject may not write to a higher integrity level, which would corrupt more trusted data. Variants include the low-water-mark policy and ring policy.

Applications

Biba-style integrity controls underlie features such as Windows Mandatory Integrity Control, which assigns integrity levels to processes and files to prevent less-trusted code (e.g., a web browser) from modifying system data. The model is often combined with Bell–LaPadula in systems needing both confidentiality and integrity, though the two models' rules can conflict.
