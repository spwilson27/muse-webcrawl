Metadata registry

From Wikipedia, the free encyclopedia

A metadata registry is a central location in an organisation where metadata definitions are stored and maintained in a controlled method. A metadata repository is the database where metadata is stored; the registry also adds relationships among data elements, documentation of their meanings, permissible values and stewardship, so that the meaning of data is understood and shared consistently across systems.

Purpose

Metadata registries exist because large organisations accumulate overlapping, inconsistently defined data — different departments may define "customer" or "revenue" differently. A registry provides a single, authoritative source of data element definitions, promoting data quality, interoperability and reuse, recording each element's definition, representation, version history and the organisation responsible for it. Registries are typically published so that both human users and other systems can discover and reference standardised data elements rather than reinventing them.

Standards

The principal international standard is ISO/IEC 11179, Information technology — Metadata registries (MDR), which specifies a metamodel for describing data elements using data element concepts, conceptual domains and value domains, and procedures for registration. In the semantic web world, registries of vocabularies and ontologies (such as Dublin Core's registry and vocabulary services built on SKOS and RDF) play an analogous role. Government-wide examples include data standards catalogues maintained by statistical agencies and the data dictionaries behind health-data exchanges.
