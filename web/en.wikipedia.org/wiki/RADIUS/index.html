RADIUS

Remote Authentication Dial-In User Service (RADIUS) is a networking protocol that provides centralized authentication, authorization, and accounting (AAA) management for users who connect and use a network service. It operates in the application layer and can use either TCP or UDP as transport. Network access servers, the gateways that control access to a network, usually contain a RADIUS client component that communicates with the RADIUS server.

History

RADIUS was developed in 1991 by Livingston Enterprises as an access server authentication and accounting protocol, and was later brought into the IETF standards process. The protocol was standardised in RFC 2865 (authentication and authorization) and RFC 2866 (accounting) in 2000. Its successor, Diameter, was designed to overcome RADIUS's limitations in mobile and roaming networks, but RADIUS remains by far the most widely deployed AAA protocol.

Operation

When a user connects, the network access server (NAS) forwards the credentials to the RADIUS server in an Access-Request packet. The server checks the credentials against a database — which may be a local file, an LDAP directory, or Active Directory — and replies with Access-Accept, Access-Reject, or Access-Challenge (for example requesting a second factor). Once authorised, accounting packets record session start and stop times and usage data. Passwords in RADIUS packets are obfuscated using a shared secret and MD5, and the protocol traditionally runs over UDP ports 1812 (authentication) and 1813 (accounting); encrypted transports such as RADIUS over TLS ("RadSec") address the weaknesses of the original MD5-based scheme.

Features

  • Attribute–value pairs — requests and replies carry extensible attributes, including vendor-specific attributes
  • Proxying and roaming — servers can forward requests based on realm, enabling federated networks such as eduroam
  • 802.1X support — RADIUS underpins enterprise Wi-Fi security (WPA2/WPA3-Enterprise) and port-based network access control
  • Accounting — interim updates and stop records support billing and auditing

Deployments

RADIUS servers such as FreeRADIUS, Microsoft Network Policy Server, and Cisco ISE authenticate users for ISPs, VPNs, wireless LANs and university networks worldwide. See also Diameter, TACACS and IEEE 802.1X.
