Data element

In metadata, the term data element is an atomic unit of data that has precise meaning or precise semantics. A data element has a clear definition, an identification (name), permissible values or a representation, and optionally a set of synonyms or aliases in different metadata registries.

Properties

A data element can be thought of in two parts: a data element concept, which expresses an idea independently of any representation (for example, "the name of a person"), and a representation, which specifies the value domain, data type and form in which the concept is recorded (such as a character string of a given length). Two data elements that share a concept but differ in representation are distinct elements with the same underlying meaning.

Standards and registries

The international standard ISO/IEC 11179 provides a framework for the specification and standardisation of data elements in metadata registries, defining attributes such as definition, identifier, version, permissible values, and stewardship. The United States National Institutes of Health promotes common data elements (CDEs) — standardised, precisely defined questions paired with allowable responses — to enable consistent data collection and comparison across clinical research studies.

Use in data modelling

Data elements are the building blocks of data dictionaries, database schemas, and message formats used in electronic data interchange. In database design, a data element typically corresponds to a column or attribute of a table; governing elements through a registry helps organisations avoid duplicate, inconsistently named, or ambiguously defined fields.
