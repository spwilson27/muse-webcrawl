DocBook

DocBook is a semantic markup language for technical documentation. It was originally intended for writing technical documents related to computer hardware and software but it can be used for any other sort of documentation.

DocBook
Filename extension: .dbk, .xml
Internet media type: application/docbook+xml
Initial release: 1991
Type of format: Markup language

As a semantic language, DocBook enables its users to create document content in a presentation-neutral form that captures the logical structure of the content; that content can then be published in a variety of formats, including HTML, XHTML, EPUB, PDF, man pages, WebHelp and HTML Help, without requiring users to make any changes to the content. In other words, when a document is written in DocBook format it becomes easily portable into other formats, rather than needing to be rewritten.

Design

DocBook is an XML language. In its current version (5.x), DocBook's language is formally defined by a RELAX NG schema with integrated Schematron rules. There is also a W3C XML Schema (WXS) schema available, as well as a Document Type Definition (DTD).

DocBook started in 1991 as a joint project of HAL Computer Systems and O'Reilly & Associates, and eventually spawned a dedicated organisation, the Davenport Group, whose charter was the continued maintenance and development of the standard. It later became an OASIS Standard and is now maintained by the DocBook Technical Committee at OASIS.
