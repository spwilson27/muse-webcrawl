TOPS-10 is a discontinued operating system from Digital Equipment Corporation (DEC) for the PDP-10 (and the DECsystem-10/DECSYSTEM-20) family of mainframe computers. The name stands for "Timesharing / Total Operating System–10". Launched in 1970, it developed from the monitor software written for the PDP-6 in 1964 and became one of the best-known interactive timesharing systems of the 1970s and early 1980s.

Overview

TOPS-10 supported timesharing, batch processing and real-time operation simultaneously. Users interacted through a command language with a characteristic dot prompt, issuing commands such as DIRECTORY, COPY, COMPILE and RUN. The system offered a hierarchical (for its time, two-level) file system with named devices, file protection codes, job scheduling with swapping to disk or drum, and spooling for printers and card equipment. Programming languages included FORTRAN, COBOL, BASIC-PLUS-style BASIC, ALGOL, APL and MACRO-10 assembly language.

The system was famously customisable: sites patched the monitor and utilities extensively, and the source code was distributed with the system, fostering a culture of local modification. The hacker community chronicled in Steven Levy's Hackers was centred on machines of this family, and many conventions of early computing culture — including the Jargon File — trace to TOPS-10 installations at universities and laboratories.

History and legacy

DEC positioned TOPS-10 against the TENEX-derived TOPS-20, which offered demand paging and a more modern design; many sites migrated, though TOPS-10 loyalists defended its efficiency and maturity. The final release, version 7.04, shipped in 1988 for the last PDP-10 systems. Enthusiasts still run TOPS-10 today on emulators such as SIMH and KLH10, and its command style influenced generations of system design.
