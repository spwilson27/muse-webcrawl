Insertion sort

Insertion sort is a simple sorting algorithm that builds the final sorted array one item at a time. It works much like sorting a hand of playing cards: each new card is compared with those already sorted and inserted into its correct position.

Algorithm

The array is conceptually split into a sorted prefix and an unsorted suffix. At each step the first unsorted element is taken and shifted left past larger elements until it reaches its proper place. The algorithm runs in O(n²) worst-case and average time, but O(n) on nearly sorted input; it requires only O(1) additional space.

Properties

Insertion sort is stable, adaptive, and online — it can sort a list as it is received. These qualities make it efficient for small arrays, and production sorting routines such as Timsort and introsort use insertion sort for small partitions. Binary search can reduce the number of comparisons to find the insertion point, though shifting elements still dominates the running time for arrays.

Variants

Shellsort generalizes insertion sort by comparing elements separated by a gap, greatly improving performance on larger inputs.
