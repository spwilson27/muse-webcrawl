Stochastic matrix

In mathematics, a stochastic matrix is a square matrix used to describe the transitions of a Markov chain. Each of its entries is a non-negative real number representing a probability. It is also called a probability matrix, transition matrix, substitution matrix, or Markov matrix.

In a right stochastic matrix, each row sums to 1, with each entry giving the probability of moving from one state to another in one step. A left stochastic matrix has columns summing to 1, and a doubly stochastic matrix has both rows and columns summing to 1.

Stochastic matrices were developed by Andrey Markov in the early 20th century. Repeated multiplication of a stochastic matrix by a probability vector describes the evolution of the Markov chain, and for an irreducible, aperiodic chain the powers converge to a matrix whose rows equal the stationary distribution. Stochastic matrices are used throughout science, economics and engineering, including in population models, queueing theory and the PageRank algorithm, where a (modified) stochastic matrix ranks web pages.
