Limbo is a programming language for writing distributed systems and the language used to write applications for the Inferno operating system. It was designed at Bell Labs by Sean Dorward, Phil Winterbottom, and Rob Pike. The Limbo compiler generates architecture-independent object code which is then interpreted by the Dis virtual machine or compiled just before runtime to improve performance. Limbo has many features that are significant for concurrent programming and distributed systems, most notably channels as a form of inter-process communication modelled on Tony Hoare's CSP.

Design

Limbo's syntax derives from C, but it has a powerful type system, garbage collection, and built-in support for concurrency. Concurrency is achieved through lightweight processes ("threads") that communicate over typed channels, following the communicating sequential processes model also seen in the earlier Newsqueak and Alef languages. Abstract data types, tuples, and first-class modules (loaded dynamically) are built into the language. Unlike many contemporaries, Limbo has no pointers accessible to the programmer in the usual sense; references are managed and memory is reference-counted with a garbage collector for cyclic data.

Influence

Limbo's channel-based concurrency and its virtual-machine design influenced the Go programming language, created by Pike and others, and the Inferno system itself remains available from Vita Nuova Holdings.
