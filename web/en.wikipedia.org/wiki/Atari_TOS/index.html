Atari TOS

TOS (The Operating System) is the operating system of the Atari ST range of computers. It was developed by Atari Corporation and first released in 1985 with the Atari 520ST. TOS combined Digital Research's GEM graphical user interface with the GEMDOS disk operating system, and was typically stored in ROM chips inside the machine, allowing near-instant boot times.

Components

TOS consists of several layers: the BIOS (basic input/output system), XBIOS (extended BIOS), GEMDOS (file and process management, modelled partly on MS-DOS), the VDI (Virtual Device Interface) graphics library, and the AES (Application Environment Services) which managed windows, menus and dialogues. The desktop itself, GEM Desktop, presented a file manager similar to the Macintosh Finder.

Versions

Versions progressed from TOS 1.0 ("ROM TOS") through 1.04 ("Rainbow TOS", 1989), 1.06/1.62 for the STe, 2.x for the Mega STe, and 3.x for the TT030, culminating in TOS 4.x for the Falcon030 in 1992. MultiTOS, a preemptive multitasking extension based on MiNT, was released later.

Legacy

Because TOS resided in ROM, it influenced a generation of musicians and desktop publishers who used the ST's built-in MIDI ports and software such as Cubase and Calamus.
