Scalable Vector Graphics (SVG) is an XML-based vector image format for defining two-dimensional graphics, with support for interactivity and animation. The SVG specification is an open standard developed by the World Wide Web Consortium since 1999. Unlike raster image formats such as PNG or JPEG, SVG images are defined mathematically by lines, curves, and shapes, so they can be scaled to any size without losing quality.

History

SVG grew out of several submissions to the W3C in 1998, including PGML (from Adobe) and VML (from Microsoft). The first version, SVG 1.0, became a W3C Recommendation in September 2001, followed by SVG 1.1 in 2003 — the version most widely implemented — and the mobile profiles SVG Tiny and SVG Basic. Work on SVG 2, aligning the format more closely with HTML and CSS, proceeded through the 2010s. Browser support, initially dependent on plug-ins, became native in all major browsers during the 2000s and early 2010s.

Features

SVG documents describe graphics with elements such as <path>, <rect>, <circle>, <ellipse>, <line>, <polygon>, and <text>, styled with attributes or CSS. Features include gradients, patterns, clipping paths, masks, filters, transformations, and Bézier curves. Text in SVG remains text, making images searchable, indexable, and accessible. Because SVG is XML, files can be created and edited with a text editor as well as with drawing programs such as Adobe Illustrator and the free editor Inkscape, and can be embedded directly in HTML pages, scripted with JavaScript, and animated with CSS or SMIL.

<svg xmlns="http://www.w3.org/2000/svg" width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="steelblue"/>
</svg>

Applications

SVG is widely used for icons, logos, diagrams, maps, charts, and user-interface elements on the web, and by Wikipedia and Wikimedia Commons for flags, diagrams, and other graphics that benefit from scaling. Compressed SVG files using gzip have the extension .svgz.
