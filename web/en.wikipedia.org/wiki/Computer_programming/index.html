Computer programming

[Image: a monitor filled with colour-highlighted source code in a dark editor, a keyboard in front of it]

Computer programming is the process of writing and maintaining the source code of computer programs — instructions that tell a computer how to perform tasks. Programmers (also called developers or software engineers) work in programming languages such as Python, JavaScript, C, Java, Rust and Go, using tools including editors, compilers, interpreters, debuggers and version-control systems.

Programming ranges from small scripts automating personal tasks to the enormous systems behind operating systems, the web, banking, aviation and science; its products — software — mediate much of modern life.

History

Ada Lovelace's notes on Charles Babbage's Analytical Engine (1840s) include an algorithm often called the first computer program. Electronic programming began with rewiring and punched cards; the stored-program computers of the late 1940s and high-level languages — Fortran (1957), COBOL (1959), BASIC (1964) — made programming progressively more accessible and abstract.

Structured programming, object-oriented programming and the open-source movement reshaped practice; the internet added web and mobile development, and in the 2020s AI coding assistants began generating and completing code, changing but not eliminating the programmer's role.

Practice

Professional programming involves analysing requirements, designing, writing, testing, debugging, documenting and maintaining code, usually in teams using methods such as version control (Git), code review and agile development. Correctness, security, performance and readability are constant trade-offs.

Programming is taught from primary school in some countries and through universities, bootcamps and self-study; it underpins the discipline of Computer science while remaining a broader craft practised by millions who are not computer scientists.
