Wireless ad hoc network

A wireless ad hoc network (WANET) is a decentralized type of wireless network in which each node participates in routing by forwarding data for other nodes, so the network forms spontaneously without relying on a pre-existing infrastructure of access points or routers. The determination of which nodes forward data is made dynamically based on network connectivity.

Types

Well-known subclasses include mobile ad hoc networks (MANETs), in which nodes move freely; vehicular ad hoc networks (VANETs) for communication between vehicles; and wireless mesh and sensor networks. Military packet-radio research by DARPA in the 1970s laid the foundations, and the IETF MANET working group standardized several routing approaches in the 1990s and 2000s.

Routing and challenges

Protocols divide into proactive (table-driven, e.g., OLSR), reactive (on-demand, e.g., AODV and DSR), and hybrid schemes. Ad hoc networks face distinctive difficulties: rapidly changing topologies, limited battery power, variable link quality, and security threats arising from the absence of centralized administration. Applications range from disaster recovery and military operations to community mesh networks and device-to-device communication.
