Software craftsmanship

Software craftsmanship is an approach to software development that emphasises the coding skills, professionalism, and pride of the developers themselves, treating programming as a craft practised with care rather than an industrial process. It arose partly in response to perceived shortcomings of heavyweight engineering methodologies and as a complement to agile software development.

Manifesto

In 2009 practitioners published the Manifesto for Software Craftsmanship, valuing well-crafted software, steadily adding value, a community of professionals, and productive partnerships. Influential books include Robert C. Martin's Clean Code and Sandro Mancuso's The Software Craftsman.

Practices

Associated practices include test-driven development, code katas, deliberate practice, mentoring, and apprenticeships within developer communities and "craftsmanship" conferences and meetups.
