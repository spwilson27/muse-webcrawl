Unicode block
DefinitionA contiguous range of code points in the Unicode standard
Total blocksMore than 300
Planes17 (planes 0-16)

A Unicode block is a contiguous range of code points in the Unicode character encoding standard. Each block is assigned a unique name and a range of code points, which are used to organize the characters of a particular script, symbol set, or functional group. Blocks are the primary organizational unit by which Unicode charts group characters for reference.

Blocks vary widely in size, from as few as 16 code points to several thousand. The first 128 code points form the Basic Latin block, which corresponds to ASCII. Many code points within a block may be unassigned or reserved for future use.

Organization

Unicode's code space of 1,114,112 code points (U+0000 to U+10FFFF) is divided into 17 planes of 65,536 code points each. Blocks never overlap, and each block begins at a code point that is a multiple of 16. Block names are unique and are intended to be descriptive of the characters they contain, such as "Greek and Coptic" or "Mathematical Operators."

Examples

Well-known blocks include Basic Latin, Latin-1 Supplement, Cyrillic, Arabic, Devanagari, CJK Unified Ideographs, Emoticons, and Miscellaneous Symbols and Pictographs. Large collections of related blocks, such as those covering the Chinese, Japanese, and Korean scripts, occupy much of the Supplementary Ideographic Plane.
