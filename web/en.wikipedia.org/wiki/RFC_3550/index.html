RFC 3550

RFC 3550, titled "RTP: A Transport Protocol for Real-Time Applications", is an Internet Engineering Task Force (IETF) Request for Comments document published in July 2003 that specifies the Real-time Transport Protocol (RTP) and its companion control protocol, RTCP. Written by Henning Schulzrinne, Stephen Casner, Ron Frederick and Van Jacobson, it obsoleted RFC 1889 and is designated Internet Standard STD 64.

Contents

The document defines the RTP fixed header (version, padding, extension, CSRC count, marker bit, payload type, sequence number, timestamp and SSRC identifier), the rules for timing, sequence numbering and source identification, and the RTP Control Protocol (RTCP), which periodically sends sender reports, receiver reports and source description packets to provide quality-of-service feedback and minimal session control.

RTP itself does not guarantee delivery or quality of service; it provides the mechanisms — sequencing, timestamps, payload identification and reception-quality reporting — that applications use to reconstruct timing and detect loss. The protocol is widely used for voice over IP, videoconferencing and streaming media, typically over UDP, and forms the media transport basis of WebRTC.

Related documents

RFC 3551 defines the profile for audio and video conferences with minimal control, assigning default payload type numbers for common codecs.
