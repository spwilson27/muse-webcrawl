Apollo Client is a comprehensive state management library for JavaScript applications that enables developers to manage both local and remote data with GraphQL. Developed by Apollo GraphQL (formerly the Meteor Development Group), it is one of the most widely used GraphQL client libraries, providing declarative data fetching, caching, and integration with front-end frameworks such as React, Angular, and Vue.

Apollo Client manages GraphQL data fetching and caching in web applications

Features

Apollo Client lets components declare the data they need with GraphQL queries and automatically handles requesting, loading, and error states. Its normalized in-memory cache stores objects by identifier, so data returned by different queries stays consistent, and updates—whether from mutations, subscriptions over WebSockets, or refetches—propagate to all components using the affected objects. Additional features include pagination helpers, optimistic user-interface updates, local state management through reactive variables and local fields, and developer tools in the browser for inspecting the cache and queries.

Architecture

Requests pass through a chain of "links" that can modify operations (for example, adding authentication headers) and terminate in an HTTP or WebSocket connection to a GraphQL server. In React applications, hooks such as useQuery and useMutation bind components to GraphQL operations. Apollo Client is part of the broader Apollo platform, which also includes Apollo Server, the Apollo Federation specification for composing multiple GraphQL services into a unified graph, and Apollo Studio for schema management and analytics.

History

The Apollo project began in 2016, growing out of the Meteor team's work on data loading, and Apollo Client reached version 3 in 2020 with integrated local state and a re-architected cache. In 2024, Apollo GraphQL changed the licensing of some of its surrounding tooling, prompting community discussion, while Apollo Client itself remained open source under the MIT License.
