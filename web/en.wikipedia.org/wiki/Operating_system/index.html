Operating system

From Wikipedia, the free encyclopedia
[Image: A desktop screen showing windows, icons and a taskbar]

An operating system (OS) is system software that manages computer hardware and software resources and provides common services for computer programs. It acts as intermediary between users, applications, and the hardware: scheduling processes on the CPU, allocating memory, managing files, and handling input and output.

The dominant desktop systems are Microsoft Windows, macOS, and Linux distributions; on mobile, Android and iOS; servers and supercomputers are dominated by Linux. All of the world's top 500 supercomputers have run Linux since 2017.

Functions

The kernel is the core component with complete control over the system. Around it the OS provides process management and multitasking, virtual memory, file systems, device drivers, networking, security and user accounts, and a user interface (command-line or graphical).

Modern systems descend conceptually from 1960s mainframe systems such as IBM's OS/360 and the influential Multics project, whose ideas fed into Unix (1969).

History

Unix (Ken Thompson and Dennis Ritchie, Bell Labs) introduced portable, composable design in C. Its descendants include BSD, macOS/iOS (via Darwin), and Linux (1991, Linus Torvalds), written independently as a free Unix-like kernel. Microsoft's line ran DOS (1981) → Windows (1985) → Windows NT (1993) and its successors.

Mobile operating systems adapted the same ideas to touch devices: iOS (2007) and Android (2008, Linux-based, Google).
