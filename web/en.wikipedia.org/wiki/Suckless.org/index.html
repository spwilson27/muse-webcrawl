Suckless.org

Suckless.org is a community of free and open-source software developers known for minimalist Unix software and for the philosophy that software should be simple, small, and free of "bloat". The project was founded in 2006 by Anselm R. Garbe, who had previously created the dwm window manager. Its name expresses the aim of producing software that "sucks less".

Software

Well-known suckless projects include dwm, a dynamic tiling window manager; st, a simple terminal emulator; dmenu, a dynamic menu for X; surf, a minimalist web browser; slock, a screen locker; the sbase and ubase core utilities; and ii, a filesystem-based IRC client. Configuration is typically done by editing a C header file and recompiling, and features are often distributed as patches rather than built in.

Philosophy

The suckless philosophy prizes code clarity, frugality of lines of code, adherence to the Unix philosophy, and static linking, and is explicitly critical of large frameworks, complex build systems, and what it calls "the bloated mainstream". The community holds an annual conference, slcon, and develops through mailing lists and git repositories hosted at suckless.org.
