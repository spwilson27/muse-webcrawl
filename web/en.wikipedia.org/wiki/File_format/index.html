File format

A file format is a standard way that information is encoded for storage in a computer file. It specifies how bits are used to encode information in a digital storage medium. File formats may be either proprietary or free, and may be either unpublished or open. Some file formats are designed for particular types of data: PNG, for example, encodes raster images; HTML encodes documents for web browsers; and MP3 encodes audio.

Identification

Formats are commonly identified by filename extensions (such as .txt, .jpg or .pdf), by internal metadata like magic numbers — characteristic byte sequences at the start of a file, e.g. "%PDF" or the PNG signature — and, on the internet, by MIME media types. Operating systems differ in how strongly they bind files to applications: classic Mac OS used type and creator codes, while Unix-like systems often rely on content sniffing via the file command.

Structure

Many complex formats are container formats, built from chunks or boxes (such as RIFF, ZIP-derived formats like DOCX and EPUB, and ISO base media files) that bundle data, metadata, and embedded resources. Text formats encode data as legible character sequences, often structured with markup or serialization languages like XML and JSON; binary formats encode numbers and structures directly, favouring compactness and speed of parsing.

Specifications and issues

For interoperability, formats should be documented: open formats are published by standards bodies (ISO, IETF, W3C) while proprietary formats may be reverse-engineered or licensed. Long-term digital preservation concerns — obsolescence, patent encumbrance, and loss of specifications — make format choice an archival issue, addressed by format registries such as PRONOM and by migration to open formats.
