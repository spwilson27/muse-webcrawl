Myhill–Nerode theorem

In the theory of formal languages, the Myhill–Nerode theorem provides a necessary and sufficient condition for a language to be regular. It is named after John Myhill and Anil Nerode, who proved it at the University of Chicago in 1958. Whereas the pumping lemma gives only a necessary condition (and so can only show languages non-regular), the Myhill–Nerode theorem characterizes regularity exactly and also yields the unique minimal deterministic finite automaton for a regular language.

Definitions

Given a language L over an alphabet Σ, two strings x and y are called indistinguishable by L (written x ≡L y) if for every string z, the concatenation xz belongs to L if and only if yz belongs to L. Indistinguishability is an equivalence relation on strings, and it refines the split between membership and non-membership in L. The number of equivalence classes is called the index of the relation.

Statement

The following three statements are equivalent for any language L:

  1. L is a regular language (accepted by some deterministic finite automaton).
  2. L is the union of some of the equivalence classes of a right congruence of finite index on Σ*.
  3. The indistinguishability relation ≡L has finite index.

Moreover, the number of equivalence classes of ≡L equals the number of states in the minimal DFA for L, and that minimal automaton is unique up to isomorphism: its states are exactly the equivalence classes, its start state is the class of the empty string, and its transitions append one symbol at a time.

Applications

To prove a language is not regular, it suffices to exhibit infinitely many pairwise distinguishable strings. The classic example is L = {anbn : n ≥ 0}: for each n, the string an is distinguished from every am (m ≠ n) by the suffix bn, so ≡L has infinitely many classes and L is not regular. The theorem also underpins DFA minimization algorithms and learning algorithms for regular languages.
