Ge'ez script

The fidäl, the character set of the Ge'ez script.

The Ge'ez script (ግእዝ), also known as Ethiopic, is an abugida (alphasyllabary) used to write several languages of Ethiopia and Eritrea. It originated as an abjad (consonant-only alphabet) to write the Ge'ez language around the 1st century CE and developed into an abugida in the 4th century, when vowel marks were added to each base consonant sign.

History

The script derives from the ancient South Arabian (Musnad) script that reached the Horn of Africa together with South Arabian settlers. Early inscriptions from the kingdom of Aksum were first written in the South Arabian script and in Greek; by the reign of Ezana in the 4th century CE the script had acquired its distinctive vocalized form and was written left-to-right, unlike its consonantal ancestor.

Structure

Each consonant has an unmarked "inherent" form representing the consonant plus the vowel ä, and six derived orders modifying the base glyph to indicate the other vowels — seven orders in total, traditionally called fidäl. The base inventory of 26 consonants gives 182 core characters, expanded further by labialized variants used in modern languages. Languages written with the script include:

Unicode

The script is encoded in Unicode in the Ethiopic block (U+1200–U+137F), with supplements for additional characters. Punctuation includes the word separator ፡ and the sentence-final ።, and the script possesses its own numeral system (፩ ፪ ፫ …) derived from Greek letters, used alongside Arabic numerals.
