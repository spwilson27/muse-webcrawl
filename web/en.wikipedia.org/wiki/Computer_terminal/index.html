A computer terminal is an electronic or electromechanical hardware device that can be used for entering data into, and transcribing data from, a computer or a computing system. Most early computers were accessed through terminals, typically connected by a serial line, which provided the only user interface.

Early terminals

The first computer terminals were electromechanical teleprinters such as the Teletype Model 33, which printed typed input and output on paper. "Glass teletypes" replaced paper with cathode-ray-tube displays in the late 1960s and 1970s. Terminals ranged from "dumb" devices that merely sent keystrokes and displayed characters, to "smart" or "intelligent" terminals capable of local editing and, in models such as the IBM 3270, block-mode transmission.

The VT100 and standardisation

Digital Equipment Corporation's VT100 (1978) became one of the most influential terminals: it supported ANSI escape sequences for cursor positioning and character attributes, a control protocol that shaped later standards and is still emulated today. Escape sequences, control characters, and character sets used by terminals remain embedded in modern computing.

Terminal emulators

As personal computers displaced centralised mainframes, dedicated terminals were largely replaced by terminal emulator software — programs such as xterm, PuTTY, and the terminal applications of modern operating systems — which reproduce the behaviour of hardware terminals so that users can interact with shell sessions and remote systems. The concept persists in command-line interfaces and in web-based consoles.
