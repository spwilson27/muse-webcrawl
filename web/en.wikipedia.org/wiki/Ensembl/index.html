Ensembl

Ensembl is a scientific project to provide a central resource for geneticists, molecular biologists and other researchers studying the genomes of humans and other species. It is a joint project between the European Bioinformatics Institute (EMBL-EBI) and the Wellcome Sanger Institute, launched in 1999 in response to the imminent completion of the Human Genome Project.

Background

Ensembl's aim is to automatically annotate genomes, integrate the annotation with other available biological data, and make all of this publicly available via the web. All data and software produced by the project are freely available. Most Ensembl software is based around the Perl programming language, with a public API and downloadable MySQL databases from each numbered release.

Genome browser

The central feature is a genome browser that displays genes, transcripts, regulatory features, comparative genomics alignments and variation data along a reference genome assembly. Sister projects include Ensembl Genomes, covering bacteria, fungi, plants and invertebrate metazoa, and resources such as the Ensembl Variant Effect Predictor (VEP) and BioMart data-mining tool.
