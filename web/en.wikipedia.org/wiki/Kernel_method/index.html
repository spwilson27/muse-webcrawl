Kernel method

In machine learning, kernel methods are a class of algorithms for pattern analysis, whose best-known member is the support vector machine (SVM). Kernel methods map input data into a higher-dimensional feature space via a (usually nonlinear) function, where linear algorithms can then find patterns such as decision boundaries, while computations are carried out efficiently in the original space through a kernel function that evaluates inner products in the feature space. This device is known as the kernel trick.

The kernel trick

Many learning algorithms require only inner products between pairs of input points. If the data are mapped by some function φ(x) into a feature space, the algorithm needs ⟨φ(x), φ(x′)⟩. A kernel function k(x, x′) = ⟨φ(x), φ(x′)⟩ computes this inner product directly, without evaluating or even specifying φ explicitly. The feature space may be extremely high-dimensional — for some kernels, infinite-dimensional — yet the computation remains cheap.

Valid kernels

By Mercer's theorem, a symmetric function k corresponds to an inner product in some reproducing kernel Hilbert space if and only if it is positive semi-definite: every finite Gram matrix formed from it is positive semi-definite.

Common kernels

  • Linear: k(x, x′) = ⟨x, x′⟩
  • Polynomial: k(x, x′) = (γ⟨x, x′⟩ + r)d
  • Gaussian / radial basis function (RBF): k(x, x′) = exp(−γ‖x − x′‖²), corresponding to an infinite-dimensional feature space
  • Laplacian, sigmoid, and string/graph kernels for structured data

Applications

Kernel methods underlie support vector machines for classification and regression, kernel principal component analysis, kernel ridge regression, Gaussian processes, kernel Fisher discriminant analysis, and spectral clustering. Their popularity peaked in the 1990s and 2000s before deep learning became dominant, but they remain important for small and medium data sets, structured inputs (text, graphs, sequences), and theory, including connections to neural networks through the neural tangent kernel.
