Cubic function

From Wikipedia, the free encyclopedia

A cubic function with three real roots; the graph crosses the x-axis at each root.

In mathematics, a cubic function is a function of the form f(x) = ax3 + bx2 + cx + d, where a ≠ 0. The coefficients a, b, c, and d are usually real numbers. The graph of a cubic function is a cubic curve; it always has at least one real root, and it has exactly one inflection point, about which the graph has 180-degree rotational symmetry.

Roots

Setting f(x) = 0 gives a cubic equation. Depending on the coefficients, a cubic function has either three real roots (counting multiplicity) or one real root and a pair of complex conjugate roots. The nature of the roots is determined by the discriminant, Δ = 18abcd − 4b3d + b2c2 − 4ac3 − 27a2d2: if Δ > 0 there are three distinct real roots; if Δ = 0 a multiple root occurs; if Δ < 0 there is one real and two non-real complex roots. An explicit formula for the roots — Cardano's formula — was published by Gerolamo Cardano in 1545, building on work by Scipione del Ferro and Niccolò Tartaglia.

Critical points and inflection

The derivative of a cubic function is a quadratic, so a cubic has either two critical points (a local maximum and a local minimum) or none, depending on whether b2 − 3ac is positive. The inflection point occurs at x = −b/(3a), where the concavity changes; if the cubic is translated so that its inflection point lies at the origin, it takes the depressed form y = x3 + px, an odd function.

Applications

Cubic functions arise naturally as volume formulas, in the physics of equations of state such as the van der Waals equation, and in interpolation: cubic splines and Bézier curves, built from cubic polynomial segments, are standard tools in computer graphics, animation, and engineering design because they give smooth curves with continuous slope and curvature.
