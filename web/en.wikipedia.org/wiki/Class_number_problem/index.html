Class number problem

In mathematics, the class number problem (also called the Gauss class number problem) is the problem of determining, for a given positive integer n, all imaginary quadratic fields whose ring of integers has class number n. Carl Friedrich Gauss posed aspects of the problem in his Disquisitiones Arithmeticae of 1801.

Class number one problem

The most famous case is n = 1. Gauss conjectured that there are exactly nine imaginary quadratic fields with class number one, corresponding to discriminants −3, −4, −7, −8, −11, −19, −43, −67, and −163. This was proved independently by Kurt Heegner, Harold Stark, and Alan Baker in the mid-20th century; the result is known as the Stark–Heegner theorem. The largest of these, 163, is connected with the near-integer value of eπ√163 observed by Ramanujan.

General problem

For general n, work by Heilbronn and Linfoot showed the number of such fields is finite for each fixed n, but effective determination proved difficult. The class number two problem was resolved in the 1970s by Baker and Stark, and further cases have been completed using methods building on the class number formula and transcendence theory.
