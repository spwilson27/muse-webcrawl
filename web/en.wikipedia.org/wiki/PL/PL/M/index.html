PL/M

PL/M (Programming Language for Microcomputers), filed under the nested path PL/PL/M as a dialect of the PL/I family, is a high-level programming language developed by Gary Kildall in 1972 for Intel microprocessors. It was the first high-level language for microcomputers and was modelled on subsets of PL/I and XPL. PL/M was used to write the CP/M operating system, the first widely used operating system for microcomputers.

History

While consulting for Intel, Kildall created PL/M for the 8008 microprocessor and later the 8080, writing its first compiler in Fortran for execution on mainframes. Intel's ISIS development system tools were written in PL/M, and the language was sold as part of Intel's microprocessor development systems. When Kildall founded Digital Research, he wrote CP/M largely in PL/M.

Language features

PL/M deliberately omitted the more complex parts of PL/I. It had no floating-point arithmetic in the 8008 version, no string manipulation built in, and no separate compilation in its earliest form, but it provided:

  • BYTE and ADDRESS (16-bit) data types, plus structures built from them;
  • Structured control flow: DO loops, DO WHILE, IF/THEN/ELSE;
  • Procedures with parameters, declared REENTRANT, INTERRUPT, or neither;
  • Direct access to I/O ports and absolute memory locations, essential for systems work;
  • Inline assembly language in later versions.

Versions and legacy

Versions were produced for the Intel 8008, 8080/8085, 8086 (PL/M-86), 80196, and 80386 (PL/M-386) processor families. Digital Research also implemented PL/I-80 and PL/I-86, full PL/I subsets, for CP/M systems. Although largely superseded by C in the 1980s, PL/M remained in use for embedded Intel development for many years, and firmware projects such as parts of early PC BIOS code were written in it.
