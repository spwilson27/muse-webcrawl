The Lucas–Lehmer test is a primality test for Mersenne numbers. It was originally developed by Édouard Lucas in 1878 and subsequently improved by Derrick Henry Lehmer in the 1930s. Because of its speed for this special class of numbers, it is the test used in the Great Internet Mersenne Prime Search (GIMPS), which has found the largest known prime numbers.

The test

Let Mp = 2p − 1 be the Mersenne number with prime exponent p. Define the sequence s0 = 4, si = (si−12 − 2) mod Mp. Then Mp is prime if and only if sp−2 ≡ 0 (mod Mp). All arithmetic operations are performed modulo Mp, which is efficient because reduction modulo a Mersenne number can be done with additions and shifts.

Example

For p = 5, M5 = 31: s = 4 → 14 → 8 → 0 after p − 2 = 3 iterations, so 31 is prime. For M11 = 2047 = 23 × 89 the sequence ends at a nonzero residue, proving compositeness.

History and use

Lucas used his method to verify that 2127 − 1 is prime — the largest prime known before computers. Lehmer formalised the test in modern form, and it remains the standard deterministic proof for Mersenne primes; variant Lucas–Lehmer–Riesel tests handle related forms.
