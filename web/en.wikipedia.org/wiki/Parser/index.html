Parser

A parser is a software component that takes input data (frequently text) and builds a data structure — often some kind of parse tree, abstract syntax tree, or other hierarchical structure — that gives a structural representation of the input while checking it for correct syntax. Parsing is a central stage of compilers and interpreters, but parsers are also used for data interchange formats, query languages, configuration files, and natural language processing.

Role in a compiler

In a typical compiler front end, a lexical analyser (lexer or scanner) first breaks the source text into tokens. The parser then consumes the token stream and determines whether it conforms to the grammar of the language, organising it into a tree that later phases — semantic analysis, optimisation, and code generation — can traverse. Parsers commonly report syntax errors and attempt to recover so that further errors can be found in a single pass.

Types of parser

Common parsing approaches
Top-downRecursive descent, LL parsers, PEG/packrat
Bottom-upLR, SLR, LALR, GLR (shift–reduce)
Generatorsyacc, GNU Bison, ANTLR

Top-down parsers start from the grammar's start symbol and try to expand it into the input, effectively building the parse tree from the root down. Recursive descent parsers implement each grammar rule as a procedure and are often hand-written. Bottom-up parsers start from the input tokens and repeatedly reduce them toward the start symbol; the LR family, usually generated from grammar tables by tools such as yacc or Bison, powers many production compilers. Chart parsers and the Earley parser are used where grammars are ambiguous, as in natural language.

Parser generators

A parser generator takes a formal grammar as input and produces parser source code. Classic tools include yacc (Yet Another Compiler-Compiler) and its successor GNU Bison for LALR grammars, and ANTLR for LL(*) grammars. Parsing expression grammars (PEGs) and combinators offer alternative approaches in which the grammar is written directly in a host programming language.

Applications beyond compilers

Parsers validate and structure JSON, XML, HTML, and other data formats; interpret query languages such as SQL; read configuration files; and, in computational linguistics, analyse the grammatical structure of sentences in human languages.
