System on a chip

System on a chip (SoC)
TypeIntegrated circuit
ComponentsCPU, GPU, memory controllers, I/O interfaces, signal processors
ApplicationsSmartphones, tablets, embedded systems, IoT devices, single-board computers
ExamplesApple silicon, Qualcomm Snapdragon, MediaTek Dimensity, Samsung Exynos

A system on a chip (SoC) is an integrated circuit that integrates most or all components of a computer or other electronic system onto a single die. These components almost always include a central processing unit (CPU), memory interfaces, input/output controllers, and often a graphics processing unit (GPU), digital signal processors, modems and other specialised accelerators.

Design

SoCs are designed by combining pre-verified intellectual property (IP) blocks—processor cores, interconnect fabrics, memory controllers and peripheral controllers—connected by on-chip buses or networks-on-chip (NoC). Designs are typically described in hardware description languages and verified extensively before fabrication. Most modern SoCs use Arm or RISC-V processor cores, although x86-based SoCs also exist.

Advantages and trade-offs

Integrating functions on one die reduces power consumption, physical size, cost and interconnect latency compared with multi-chip designs, which is why SoCs dominate mobile and embedded computing. The trade-offs include high design and mask costs, difficulty of mixing analogue and digital process technologies, and limited upgradeability: a defective or outdated block cannot be replaced independently.

Applications

SoCs power virtually all smartphones and tablets (e.g. Apple's A-series and M-series, Qualcomm's Snapdragon line), smart TVs, wearable devices, automotive driver-assistance systems, and single-board computers such as the Raspberry Pi. Related concepts include the microcontroller (MCU), which integrates a CPU with flash memory and peripherals for simpler control tasks, and the package-on-package (PoP) arrangement used to stack memory above the SoC.
