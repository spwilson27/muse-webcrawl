In group theory, a character table is a two-dimensional table whose rows correspond to irreducible group representations and whose columns correspond to conjugacy classes of group elements. The entries consist of characters, the traces of the matrices representing group elements in the corresponding representation. Character tables are compact summaries of key information about a group and are widely used in chemistry and crystallography, where tables for point groups are used in spectroscopy and molecular orbital theory.

Properties

The character table of a finite group has several important properties. The number of irreducible representations equals the number of conjugacy classes, so the table is square. The first row is always the trivial representation (all entries 1), and the first column gives the dimensions of the representations. The rows and columns satisfy orthogonality relations, and the sum of the squares of the dimensions of the irreducible representations equals the order of the group. Entries are algebraic integers, typically sums of roots of unity.

Chemical applications

For molecular point groups, character tables additionally list how basis functions such as coordinates, rotations, and quadratic functions transform under each representation, and often give the Mulliken symbols for the representations. These allow chemists to determine selection rules for infrared and Raman spectra and to construct symmetry-adapted molecular orbitals.
