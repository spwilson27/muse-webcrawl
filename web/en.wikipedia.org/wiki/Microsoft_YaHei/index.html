Microsoft YaHei

Microsoft YaHei (微软雅黑)
Classification: Sans-serif (gothic)
Foundry: Founder Type / Microsoft
Released: 2007 with Windows Vista
Microsoft YaHei is designed for Simplified Chinese UI text

Microsoft YaHei (Chinese: 微软雅黑; pinyin: Wēiruǎn Yǎhēi) is a Simplified Chinese gothic (sans-serif) typeface developed for Microsoft by the Beijing company Founder Type, with hinting by Monotype Imaging. It was introduced as the default user interface font for Simplified Chinese editions of Windows beginning with Windows Vista, and it remains a default font in later versions of Windows.

Design

YaHei was designed for legibility on screen at small sizes, optimised for Microsoft's ClearType subpixel rendering. Its letterforms follow the modern Chinese national standard (GB) shapes and pair with Segoe UI metrics so that mixed Chinese and Latin interface text align harmoniously. The family originally shipped in regular and bold weights; a Light weight was added with Windows 8.1/10 as "Microsoft YaHei Light" and "Microsoft YaHei UI" variants adapted for interface use.

Licensing and criticism

The font is proprietary and licensed for use within Microsoft products. Its development cost was reported to be unusually high per glyph because of the size of the Chinese character set. Some reviewers criticised the rendering of certain characters and its heavy appearance at small sizes, but it was widely welcomed as a major improvement over the bitmap-oriented SimSun previously used for Chinese Windows interfaces.
