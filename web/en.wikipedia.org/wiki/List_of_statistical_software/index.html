List of statistical software

The following is a list of statistical software — computer programs used for statistical analysis of data. Statistical packages range from general-purpose commercial suites to free, open-source environments widely used in academia and data science.

Major packages

SoftwareTypeNotes
RFree / open sourceProgramming language and environment; huge ecosystem of packages via CRAN
SASCommercialLong-established suite used in industry, government and clinical trials
SPSS (IBM SPSS Statistics)CommercialPopular in social sciences; menu-driven interface
StataCommercialWidely used in economics, epidemiology and political science
MinitabCommercialQuality improvement and industrial statistics, Six Sigma
MATLABCommercialNumerical computing with Statistics and Machine Learning Toolbox
Python (pandas, NumPy, SciPy, statsmodels)Free / open sourceGeneral-purpose language with extensive statistical libraries
JMPCommercialInteractive exploratory analysis from SAS Institute
EViewsCommercialEconometrics and time-series forecasting
gretlFree / open sourceEconometrics package

JuliaFree / open sourceLanguage for technical computing with growing statistics ecosystem
Microsoft ExcelCommercialSpreadsheet with basic statistical functions and the Analysis ToolPak

Specialised software

Specialised tools include WinBUGS and Stan for Bayesian inference, NVivo for qualitative data, and environment-specific packages for survey analysis, survival analysis and structural equation modelling (such as Mplus and LISREL).
