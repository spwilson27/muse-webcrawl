DWG

From Wikipedia, the free encyclopedia

DWG (from drawing) is a proprietary binary file format used for storing two- and three-dimensional design data and metadata. It is the native format for several CAD packages including AutoCAD, and was developed by Autodesk, which launched it with the first release of AutoCAD in 1982. DWG files conventionally use the file extension .dwg.

Description

DWG contains all the information a user enters in a CAD drawing: geometric data (points, lines, arcs, surfaces and solids), design metadata, and references to raster images and other external files. The format is versioned, and each major generation of AutoCAD has introduced a new DWG version identified by an internal code such as AC1032 (AutoCAD 2018 format). Drawings saved by newer releases cannot generally be opened by older ones without conversion.

History and control

Autodesk has maintained tight control over the DWG specification, which has never been fully published. Competing CAD vendors have relied on reverse-engineered libraries, notably those of the Open Design Alliance, to read and write DWG files. Autodesk's attempts to trademark "DWG" and related marks were contested by rivals and opposed in part by the United States Patent and Trademark Office.

Because of the dominance of AutoCAD in architecture, engineering and construction, DWG became a de facto interchange standard for CAD data despite its proprietary status. Autodesk also publishes the ASCII-based DXF format as an open exchange alternative, and provides the free DWG TrueView viewer for inspecting DWG files.
