DEFLATE (stylised Deflate) is a lossless data compression file format and algorithm that uses a combination of LZ77 and Huffman coding. It was originally defined by Phil Katz for version 2 of his PKZIP archiving tool, and the format was later specified in RFC 1951 (1996). DEFLATE is the compression algorithm at the heart of the ZIP archive format, gzip, the PNG image format and the zlib library, and is also used in HTTP compression.

Algorithm

A DEFLATE stream consists of a series of blocks. Each block is compressed in two stages: first, the LZ77 algorithm replaces repeated substrings with references (a length and a backward distance into a 32 KB sliding window); second, the resulting literals and length/distance symbols are encoded with Huffman coding, either using fixed built-in code tables or dynamic tables transmitted in the block header. Data may also be stored uncompressed in a "stored" block. Because Huffman codes are packed starting with the least-significant bit, DEFLATE differs in bit order from many other formats.

Encoders

The best-known implementation is Jean-loup Gailly and Mark Adler's zlib library and the gzip tool; its compression levels (1 fastest to 9 best) trade speed for ratio by varying the match search. Other encoders include 7-Zip's more exhaustive optimiser and Google's Zopfli, which produces smaller (but fully compatible) output at much greater CPU cost. The format is in the public domain in the sense that it may be implemented freely; earlier patent concerns around LZ77 variants were a factor in the creation of the rival LZW-based GIF format's history and PNG's choice of DEFLATE.
