Plot device

A plot device or plot mechanism is any narrative technique used to move a story forward. Plot devices include the MacGuffin, deus ex machina, red herring, cliffhanger, flashback and plot twist.

Plot device

Examples

A MacGuffin is an object that motivates characters but whose nature is unimportant. Deus ex machina resolves a plot through an unexpected intervention. A red herring misleads the audience.

Criticism

Overused or contrived devices — e.g. contrived coincidences, idiot plots depending on characters acting foolishly — are often criticised as lazy writing.
