Golden-section search

From Wikipedia, the free encyclopedia

The golden-section search is a technique for finding an extremum (minimum or maximum) of a strictly unimodal function by successively narrowing the range of values inside which the extremum is known to exist. The method owes its name to the fact that the algorithm maintains the function values for triples of points whose distances form a golden ratio. The technique derives from the Fibonacci search technique of Kiefer (1953), and it is closely related to the ternary search.

Description

Let f be a unimodal function on an interval [a, b]. Two interior points are chosen so that the interval is divided in the golden ratio φ = (1 + √5)/2 ≈ 1.618. Depending on which interior point gives the better function value, one end of the interval is discarded, and the surviving interior point is reused — so each iteration after the first costs only one new function evaluation. The interval shrinks by a constant factor of about 0.618 per iteration, giving linear convergence.

Algorithm

With φ satisfying 1/φ = φ − 1 ≈ 0.618, the interior points are placed at c = b − (b − a)/φ and d = a + (b − a)/φ. To find a minimum, if f(c) < f(d) the new interval is [a, d], otherwise it is [c, b]. The iteration continues until the interval is smaller than a prescribed tolerance.

Related methods

The golden-section search is essentially the limit of the Fibonacci search as the number of iterations grows, and it shares its worst-case efficiency. For smooth functions, methods using derivative information, such as parabolic interpolation and Brent's method, generally converge faster.
