Arial

Arial (also called Arial MT) is a sans-serif typeface and set of computer fonts in the neo-grotesque style. Fonts from the Arial family are packaged with all versions of Microsoft Windows from Windows 3.1 onwards, some other Microsoft software applications, Apple Mac OS X, and many PostScript 3 computer printers. The typeface was designed in 1982 by a ten-person team led by Robin Nicholas and Patricia Saunders for Monotype Typography.

History

Arial was designed in 1982 for IBM's new laser printers as a metrically compatible alternative to Linotype's Helvetica, allowing documents formatted for Helvetica to be printed without licensing that typeface. Monotype's team, led by Robin Nicholas and Patricia Saunders, drew letterforms that were similar in proportion and weight to Helvetica but with subtly different details, such as the curved tail of the capital R and the diagonal terminal of the lowercase t.

Distribution

Microsoft first supplied Arial with Windows 3.1 in 1992 and made it a core font for the web in 1996, distributing it freely as part of the Core fonts for the Web initiative. Because of this ubiquity, Arial became one of the most widely used typefaces in the world, appearing in office documents, signage, and web pages. TrueType versions of Arial are also shipped with macOS.

Design characteristics

Arial shares Helvetica's basic proportions but is somewhat softer in appearance: terminals are cut diagonally, strokes are less uniform, and the design has a slightly more humanist feel. Distinguishing features include the tail of the R, the shape of the lowercase a, and the slash through the zero in some related fonts such as Arial Monospaced.

Variants

The Arial family includes Arial Black, Arial Narrow, Arial Rounded, Arial Light, Arial Medium, and Arial Monospaced, among others. Arial Unicode MS was a version with extensive Unicode coverage shipped with Microsoft Office.
