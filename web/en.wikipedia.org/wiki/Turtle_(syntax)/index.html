Turtle (syntax)

Turtle (Terse RDF Triple Language) is a syntax and file format for expressing data in the Resource Description Framework (RDF) data model. It provides a compact, human-readable way of writing RDF triples, and is a subset of the Notation3 (N3) syntax. Turtle was standardised by the World Wide Web Consortium (W3C) as a Recommendation in February 2014.

Syntax

A Turtle document consists of statements made up of subject–predicate–object triples. Prefixes allow namespace IRIs to be abbreviated, semicolons group multiple predicates for the same subject, and commas group multiple objects for the same subject and predicate.

@prefix ex: <http://example.org/> .
ex:Alice ex:knows ex:Bob , ex:Carol ;
    ex:age 30 .

Literals may be written as quoted strings, numbers or booleans, and blank nodes and collections are supported with a concise bracket syntax.

Usage

Turtle files commonly use the .ttl extension and the media type text/turtle. The format is widely used for publishing linked data, authoring ontologies, and writing SPARQL queries, whose triple-pattern syntax closely follows Turtle. Related formats include TriG, which extends Turtle for RDF datasets, and N-Quads.

History

Turtle was developed by Dave Beckett, drawing on Notation3 as designed by Tim Berners-Lee and Dan Connolly. It gained popularity through its use in Semantic Web tools such as Redland and Jena before formal standardisation by the W3C RDF Working Group in the RDF 1.1 family of specifications.
