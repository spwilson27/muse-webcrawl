Location independence

Location independence is a concept in computing and information systems meaning that the physical location of data or resources is irrelevant to, or hidden from, the user or application that accesses them. A user can retrieve information without knowing where it is stored, and changes to the physical storage location do not require changes to the applications that use the data.

Location independence hides physical placement behind logical names.

In databases

In distributed database management systems, location independence (also called location transparency) is one of the classical goals alongside fragmentation and replication transparency: users query data as if it were all at their local site, while the system resolves where fragments physically reside. Dates's rules for distributed databases list location independence among the fundamental objectives.

In identifiers and networking

The concept also appears in persistent identifier schemes for digital objects, where a resolvable name (such as a DOI or Handle) remains stable while the underlying object moves between servers. In internet architecture, debates about the identifier/locator split — separating what a node is from where it is attached to the network — are fundamentally about location independence: protocols such as HIP and LISP attempt to make endpoint identities independent of their network locations, enabling mobility and multihoming.
