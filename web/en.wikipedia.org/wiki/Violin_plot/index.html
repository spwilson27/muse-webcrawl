Violin plot

Violin plots combine a box plot with a kernel density estimate

A violin plot is a method of plotting numeric data that combines features of the box plot with a kernel density plot. It was introduced by Jerry L. Hintze and Ray D. Nelson in a 1998 paper in The American Statistician as a richer alternative for displaying distributions, particularly when comparing several groups.

Description

Each "violin" is formed by mirroring a one-dimensional kernel density estimate about the axis of the variable, so that the width of the violin at any value is proportional to the estimated density of observations there. Wider sections indicate values that occur more frequently; narrow sections indicate rarer values. Inside the violin, a miniature box plot is usually drawn, showing the median, the interquartile range, and sometimes the mean, so that the familiar summary statistics of a box plot remain visible alongside the shape of the distribution.

Advantages and limitations

Unlike a plain box plot, a violin plot reveals multimodal structure: a bimodal distribution appears as two bulges joined by a pinch, something a box plot cannot show. This makes violins useful for comparing distributions across categories in exploratory data analysis. Their main limitation is that viewers unfamiliar with density plots may misread them, and the apparent smoothness depends on the bandwidth chosen for the kernel density estimate, which can create spurious bumps or hide genuine detail if poorly chosen. For very small sample sizes the density estimate may be misleading and a strip plot or box plot is preferable.

Software

Violin plots are available in many statistical packages, including R (via ggplot2's geom_violin and the vioplot package), Python (matplotlib and seaborn), and Stata.
