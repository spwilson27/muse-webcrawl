Page table

A page table is the data structure used by a virtual memory system in a computer operating system to store the mapping between virtual addresses and physical addresses. When a program accesses memory, the memory management unit (MMU) walks the page table to translate the virtual page number into a physical frame number.

Structure

Each entry in the table records the frame in which a page resides along with metadata bits indicating whether the page is present, writable, accessed, or dirty. Because a flat table for a modern address space would be enormous, systems use multi-level (hierarchical) page tables, hashed page tables, or inverted page tables. A translation lookaside buffer (TLB) caches recent translations to avoid repeated walks.

Operation

If a translation shows the page is not present, the hardware raises a page fault and the operating system loads the page into a free frame, updates the table, and restarts the instruction.
