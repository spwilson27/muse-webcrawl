Trusting trust

"Reflections on Trusting Trust" is a 1984 lecture by Ken Thompson, co-creator of Unix, delivered on receiving the Turing Award and published in Communications of the ACM. In it Thompson describes a self-reproducing backdoor attack on a C compiler: a modified compiler inserts a Trojan horse into the login program it compiles, and — crucially — also inserts the backdoor code into any future compiler it compiles, even though the compiler's source code appears clean.

AuthorKen Thompson
Published1984 (Turing Award lecture)
TopicCompiler backdoors, software trust

Argument

Thompson's conclusion, summarised as "you can't trust code that you did not totally create yourself", is that source-code inspection alone cannot guarantee the security of a system, because the tools used to build and inspect the software must themselves be trusted. The lecture remains a foundational reference in discussions of supply-chain security and reproducible builds.

Countermeasures

David A. Wheeler's "diverse double-compiling" technique proposes defeating the attack by recompiling the suspect compiler with an independent trusted compiler and comparing the resulting binaries. Bootstrappable-builds initiatives in projects such as GNU Guix aim to reduce the trusted seed needed to build a system from source.
