Surjective function

In mathematics, a function f : X → Y is surjective (also called onto, or a surjection) if every element y of the codomain Y is the image of at least one element x of the domain X — that is, if for every y in Y there exists an x in X with f(x) = y. Equivalently, the image of the function equals its codomain.

A surjective function: every element of the codomain is hit

Properties

A function is bijective if and only if it is both surjective and injective. Every function can be decomposed into a surjection followed by an injection, by restricting the codomain to the image. A function f has a right inverse if and only if it is surjective (a fact equivalent to the axiom of choice), and the composition of surjective functions is surjective.

Examples

The function f(x) = 2x from the real numbers to the real numbers is surjective (indeed bijective), while the squaring function f(x) = x² from ℝ to ℝ is not surjective, since negative numbers have no preimage; however, the same formula defines a surjection from ℝ onto the non-negative reals. For finite sets, a function between two sets of the same size is surjective if and only if it is injective.

History

The terminology of surjection, injection and bijection was introduced by the Bourbaki group in the mid-twentieth century; "onto" remains common in older texts.
