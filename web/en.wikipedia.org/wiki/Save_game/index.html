Saved game

A saved game (also called a savegame, save file or save state) is a piece of stored information about the progress of a player in a video game. Saving allows a player to stop playing and resume later from the same point, preserving character statistics, inventory, completed objectives and the state of the game world. Nearly all modern games provide saving, automatically (autosave), at checkpoints, or at the player's command.

History

Early arcade games kept no progress beyond high-score initials. Home computer games of the late 1970s and early 1980s — such as text adventures like Zork — pioneered saving to tape or disk, while console games initially used password systems that encoded progress in strings of characters. The Legend of Zelda (1986) was among the first console games with battery-backed saved games on the cartridge. Memory cards for the PlayStation era, hard drives, and later cloud saves tied to user accounts successively standardised the practice.

Design

Save systems shape game design: free manual saving ("save anywhere") lets players retry challenges but can enable "save scumming" — repeatedly reloading for favourable outcomes — while checkpoint systems control pacing and difficulty. Emulators add save states, snapshots of the entire machine memory that can be restored instantly, a feature some modern games and retro re-releases have adopted as "rewind." Save files may also be shared, edited or exploited (for example, to duplicate items), and corrupted saves are a perennial technical-support issue.
