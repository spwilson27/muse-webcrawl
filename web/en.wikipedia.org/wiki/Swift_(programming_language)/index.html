Swift is a high-level general-purpose, multi-paradigm, compiled programming language created by Chris Lattner in 2010 for Apple Inc. and maintained by the open-source community. Swift compiles to machine code (as opposed to Objective-C's dynamic dispatch) and is intended to replace Objective-C as the primary language for Apple's platforms, including iOS, macOS, watchOS and tvOS. It was first released in 2014 and made open source under the Apache License 2.0 in December 2015.

Features

Swift is designed to be safe by default: variables must be initialized before use, arrays and integers are checked for overflow, optionals make the absence of a value explicit, and memory is managed automatically through Automatic Reference Counting (ARC). It supports type inference, generics, protocols and protocol extensions (the basis of what Apple calls "protocol-oriented programming"), closures, tuples, and powerful pattern matching in switch statements.

let names = ["Anna", "Alex", "Brian", "Jack"]
let sortedNames = names.sorted { $0 > $1 }
print(sortedNames) // ["Jack", "Brian", "Anna", "Alex"]

History

Development of Swift was begun in 2010 by Chris Lattner, and it was unveiled at Apple's Worldwide Developers Conference (WWDC) on June 2, 2014. Version 1.0 was released that September. Swift 2.0, announced in 2015, added error handling with try/catch and was open-sourced later that year along with a port to Linux. Swift 3.0 (2016) made sweeping API changes; Swift 4.0 (2017) and 5.0 (2019) stabilised the ABI on Apple platforms. Swift 6.0 (2024) introduced opt-in strict data-race safety checking for concurrent code.

Platforms

Swift is supported on Apple platforms, Linux, and Windows. Tooling centred on Xcode includes Swift Playgrounds, an interactive environment for learning and prototyping. The Swift Package Manager provides dependency management, and server-side frameworks such as Vapor have made Swift a language for backend development as well.
