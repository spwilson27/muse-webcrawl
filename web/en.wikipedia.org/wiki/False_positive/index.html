False positive

A false positive is an error in binary classification or testing in which a result incorrectly indicates the presence of a condition when it is not actually present. In statistical hypothesis testing, a false positive corresponds to a Type I error: rejecting a true null hypothesis. The complementary error, failing to detect a condition that is present, is a false negative (Type II error).

In medical testing

In medicine, a false positive result means that a test indicates a person has a disease or condition when they do not. False positives can cause anxiety, unnecessary follow-up procedures, and costs. The probability that a positive result is a true positive depends on the test's sensitivity and specificity and on the prevalence of the condition in the tested population: when a condition is rare, even a highly accurate test can produce many false positives relative to true positives, a consequence of Bayes' theorem.

In other fields

The concept is widely used in other domains. In spam filtering and antivirus software, a false positive is a legitimate message or file incorrectly flagged as malicious. In machine learning, the false positive rate is a standard performance metric summarised in confusion matrices and ROC curves. In security screening and quality control, false positives trigger needless inspections and alarms.

False positive rate

The false positive rate is the proportion of negative cases that are incorrectly classified as positive: FP / (FP + TN). It is equal to 1 − specificity. Test designers trade off false positives against false negatives by adjusting decision thresholds, depending on the relative costs of each kind of error.
