.NET Framework

The .NET Framework (pronounced as "dot net") is a proprietary software framework developed by Microsoft that runs primarily on Microsoft Windows. It was the predominant implementation of the Common Language Infrastructure (CLI) until being superseded by the cross-platform .NET project. It includes a large class library called the Framework Class Library (FCL) and provides language interoperability across several programming languages.

History

Microsoft began developing .NET Framework in the late 1990s under the name Next Generation Windows Services (NGWS). Version 1.0 was released on February 13, 2002, alongside Visual Studio .NET. Subsequent major releases included version 2.0 (2005), which introduced generics; version 3.0 (2006), which added Windows Presentation Foundation (WPF), Windows Communication Foundation (WCF), Windows Workflow Foundation (WF) and Windows CardSpace; version 3.5 (2007), which added Language Integrated Query (LINQ); and version 4.0 (2010). The final version, 4.8.1, was released in August 2022.

Architecture

Programs written for .NET Framework execute in a software environment known as the Common Language Runtime (CLR), an application virtual machine that provides services such as security, memory management and exception handling. Source code written in languages such as C#, Visual Basic and F# is compiled into Common Intermediate Language (CIL), which the CLR compiles to native machine code at runtime using just-in-time (JIT) compilation. The Framework Class Library provides a large reusable library of types covering user interfaces, data access, database connectivity, cryptography, web application development and numeric algorithms.

Successor

With the release of .NET Core in 2016, Microsoft moved toward a cross-platform, open-source implementation. The .NET Framework remains supported as a Windows component, but new development has shifted to the unified .NET platform (version 5 and later). Microsoft has stated that .NET Framework 4.8.1 is the final version, though it continues to receive support as part of Windows.
