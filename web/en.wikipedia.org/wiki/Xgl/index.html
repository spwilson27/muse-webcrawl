DeveloperDavid Reveman (Novell)

TypeX server / compositing architecture

Xgl was an X server architecture, developed by David Reveman at Novell and released in 2006, that implemented the X Window System on top of OpenGL, enabling hardware-accelerated compositing effects on the Linux desktop. Used together with the Compiz window manager, Xgl demonstrated effects such as wobbly windows, desktop cubes and live window previews that attracted wide attention.

How it worked

Xgl ran as an X server whose rendering was performed through OpenGL (using the GLX_EXT_texture_from_pixmap extension), typically nested on top of a conventional X server or directly on the framebuffer. It complemented the Composite extension by redirecting window contents into textures that a compositing manager could manipulate.

Successors

Xgl was soon superseded by AIGLX, developed by the Fedora/Red Hat community, which achieved similar acceleration within the standard X.Org server without a separate nested server. Xgl development was discontinued around 2008, but it played a key transitional role in bringing composited desktops to Linux.
