Negative binomial regression

In statistics, negative binomial regression is a popular generalization of Poisson regression because it loosens the highly restrictive assumption that the variance is equal to the mean, made by the Poisson model. The traditional negative binomial regression model is based on the Poisson-gamma mixture distribution.

Negative binomial regression is commonly used when analysts have over-dispersed count data, that is, when the conditional variance exceeds the conditional mean. Under such circumstances, the Poisson model can fail to fit the data adequately, producing underestimated standard errors and overly optimistic test statistics.

Specification

In the standard formulation, the expected count for observation i is modelled as a log-linear function of explanatory variables: log(μi) = xi′β. The count itself follows a negative binomial distribution whose variance is Var(yi) = μi + αμi2, where α ≥ 0 is a dispersion (or heterogeneity) parameter. As α → 0 the model reduces to Poisson regression.

Estimation is typically by maximum likelihood, using the full probability mass function of the negative binomial, which involves the gamma function of the reciprocal dispersion parameter.

Applications

The model is widely used in epidemiology (counts of disease cases), criminology (counts of offences), health-services research (numbers of hospital visits), marketing, and political science (counts of protest events or cabinet formations). Related models include zero-inflated negative binomial regression, which handles data with an excess of zero counts, and truncated variants for counts that cannot take the value zero.
