Streaming algorithm

Streaming algorithms are algorithms for processing data streams in which the input is presented as a sequence of items that can be examined in only a few passes (typically one) and with limited working memory. Because the data may be far too large to store, streaming algorithms produce approximate answers using small sketches or summaries of the input.

Model and measures

In the standard data-stream model, algorithms are evaluated by the number of passes over the data, the memory (space) used, and the processing time per item. Classic problems include estimating the number of distinct elements (solved approximately by Flajolet–Martin and HyperLogLog), finding frequent items (heavy hitters, solved by Count-Min sketch and Misra–Gries), and estimating frequency moments.

Applications

Streaming algorithms underlie network traffic monitoring, database query processing, sensor networks and large-scale machine learning on data that cannot be stored or rescanned.
