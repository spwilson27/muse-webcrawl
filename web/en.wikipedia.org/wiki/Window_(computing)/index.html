Window (computing)

In computing, a window is a graphical control element consisting of a visual area, usually rectangular, that contains some of the graphical user interface of the program it belongs to and is framed by a window decoration. Windows are a central metaphor of the desktop environment, allowing multiple applications or documents to be displayed and manipulated on a single screen.

Properties

A typical window includes a title bar identifying its contents, window controls for closing, minimizing, and maximizing, and borders that can often be dragged to resize it. Windows may overlap (as in overlapping window managers) or tile without overlapping. A window that requires user interaction before the underlying application can continue is called a modal window; one that does not is modeless.

History

The window concept emerged from research at SRI International and Xerox PARC in the 1960s and 1970s, notably in Douglas Engelbart's NLS and the Xerox Alto. It was popularized commercially by the Apple Macintosh in 1984 and Microsoft Windows from 1985 onward, becoming the dominant paradigm of personal computing interfaces.

Window managers

The software responsible for placing and managing windows is the window manager, which on Unix-like systems using the X Window System or Wayland is a separate component from the applications themselves. Window managers implement policies for focus, stacking order, and virtual desktops.
