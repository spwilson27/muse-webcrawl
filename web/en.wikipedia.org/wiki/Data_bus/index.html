Data bus

A data bus carries information between components of a computer system.

In computer architecture, a data bus is a subsystem that transfers data between components inside a computer, or between computers. It is one of the three parts of the classic system bus, alongside the address bus, which carries the addresses in memory that the CPU is reading from or writing to, and the control bus, which carries timing and control signals.

Characteristics

The width of a data bus — the number of parallel lines, or bits transferred simultaneously — is a key measure of a processor's architecture: early microprocessors had 8-bit data buses, while modern CPUs use 64-bit (or wider) external data paths. The bus bandwidth depends on both its width and its clock frequency. Because all devices share the bus, an arbitration protocol determines which device may transmit at a given time.

Serial and parallel buses

Traditional buses such as ISA and PCI transfer data in parallel over many wires. At high clock rates, skew between parallel lines becomes a problem, so modern interconnects — USB, SATA, PCI Express — instead use high-speed serial links, often with multiple lanes, despite nominally transferring one bit at a time per lane.
