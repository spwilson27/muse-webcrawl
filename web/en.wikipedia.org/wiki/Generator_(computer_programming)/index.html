Generator (computer programming)

In computer programming, a generator is a routine that can be used to control the iteration behaviour of a loop. All generators are also iterators. A generator is very similar to a function that returns an array, in that a generator has parameters, can be called, and generates a sequence of values. However, instead of building an array containing all the values and returning them all at once, a generator yields the values one at a time, which requires less memory and allows the caller to get started processing the first values immediately.

Characteristics

Generators were first introduced in the programming language CLU in the 1970s and are now available in many languages, including Python, C#, JavaScript, PHP, Ruby, and Rust. In Python, a function containing the yield keyword becomes a generator function; each call to next() resumes execution where it last suspended, preserving local state between yields. This allows the representation of infinite sequences, such as the sequence of Fibonacci numbers, and supports lazy evaluation of data pipelines.

Comparison with iterators and coroutines

Generators are a special case of coroutines: a generator can suspend and resume its execution, but control always returns to the routine that resumed it, whereas full coroutines can transfer control to one another. Generators simplify the implementation of custom iterators, because the compiler automatically manages the state machine underlying the iteration protocol.

Examples

In Python:

def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

In JavaScript, generator functions are declared with function* and use the yield expression; the ECMAScript standard introduced them in ES2015.
