Private Use Areas

In Unicode, a Private Use Area (PUA) is a range of code points that, by definition, will not be assigned characters by the Unicode Consortium. The private use areas are reserved for private use, and are intended for use by software that requires code points for characters not (yet) in Unicode, such as characters for constructed scripts, logos, or specialised symbols.


The three private use areas of Unicode.

Ranges

Three private use areas are defined:

  • the Private Use Area in the Basic Multilingual Plane: U+E000 to U+F8FF (6,400 code points);
  • Supplementary Private Use Area-A: U+F0000 to U+FFFFD (65,534 code points);
  • Supplementary Private Use Area-B: U+100000 to U+10FFFD (65,534 code points).

Because the characters assigned to these code points are not standardised, text using them can only be interpreted correctly if sender and receiver share the same private agreement about their meanings. The same code point may represent entirely different characters in different fonts or systems.

Usage

Private use code points are used by icon fonts such as Font Awesome, by fonts for constructed languages (for example, Klingon in some fonts), and by operating systems for vendor-specific glyphs. The Medieval Unicode Font Initiative and other scholarly projects publish recommended mappings for characters not yet encoded in Unicode.
