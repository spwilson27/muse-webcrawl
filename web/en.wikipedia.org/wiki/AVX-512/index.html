AVX-512

DesignerIntel
Introduced2016 (Knights Landing)
Architecturex86-64 instruction set extension
Register width512 bits (ZMM)

AVX-512 is a family of extensions to the x86 instruction set architecture for microprocessors from Intel. It expands most AVX and AVX2 instructions to operate on 512-bit-wide ZMM vector registers, doubles the number of vector registers to 32 in 64-bit mode, and adds eight dedicated opmask registers enabling per-element predication. AVX-512 debuted in the Xeon Phi "Knights Landing" accelerator in 2016 and in Xeon server processors with Skylake-SP in 2017.

Subsets

Unlike its predecessors, AVX-512 is not a single monolithic extension but a collection of subsets — such as AVX-512F (foundation), CD, ER, PF, BW, DQ, VL, VBMI, and VNNI — which different processors implement in varying combinations. This fragmentation complicated software dispatch: a program might need separate code paths for server, workstation, and consumer silicon. The VL subset maps the new features onto 128- and 256-bit vectors.

Reception and consumer availability

AVX-512 significantly improves throughput for scientific computing, cryptography, and machine-learning inference, and Xeon implementations include two fused multiply-add ports on high-end parts. On consumer processors the feature had a checkered history: it appeared in Cannon Lake, Ice Lake, Tiger Lake, and Rocket Lake, but Intel disabled it on Alder Lake because its efficiency cores lacked support, and removed it from later consumer lines, while AMD introduced broad AVX-512 support with its Zen 4 architecture in 2022 and expanded it in Zen 5.
