Sundanese script

Sundanese script (Sundanese: ᮃᮊ᮪ᮞᮛ ᮞᮥᮔ᮪ᮓ, Aksara Sunda) is a Brahmic abugida used to write the Sundanese language of western Java, Indonesia. Derived from the Old Sundanese script used in inscriptions and palm-leaf manuscripts from roughly the 14th to 18th centuries, a standardised form (Aksara Sunda Baku) was revived by the government of West Java in 1997 and is now taught in schools and used on street signs and public buildings alongside the Latin alphabet.

Type: Abugida
Languages: Sundanese
Unicode range: U+1B80–U+1BBF

Structure

Like other Brahmic scripts, Sundanese is an abugida: each consonant letter carries an inherent vowel /a/ that can be modified by diacritics (rarangkén) or suppressed by a virama-like mark (pamaéh). The standard script has 18 consonant letters (aksara ngalagena), 7 independent vowel letters (aksara swara), supplementary letters for foreign sounds such as /f/, /v/ and /z/, and digits. Words are written without spaces in the traditional style.

History and revival

Old Sundanese was written in manuscripts such as the Carita Parahyangan and Sanghyang Siksa Kandang Karesian. Use declined under Dutch colonial rule as Sundanese came to be written in Javanese script, Arabic-derived Pegon, and eventually Latin. The 1997 standardisation, based largely on the Old Sundanese letterforms, was followed by inclusion in the Unicode Standard in 2008 (version 5.1) and by regional regulations requiring the script on signage in West Java and Banten.
