zlib is a software library used for data compression. zlib was written by Jean-loup Gailly and Mark Adler and is an abstraction of the DEFLATE compression algorithm used in their gzip file compression program. zlib is also a crucial component of many software platforms, including Linux, macOS, and iOS. It has also been used in gaming consoles such as the PlayStation and Xbox lines.

Format

The zlib format, specified in RFC 1950, wraps a raw DEFLATE stream (RFC 1951) with a two-byte header and a four-byte Adler-32 checksum of the uncompressed data. The header indicates the compression method and level and includes a check value. zlib should not be confused with the gzip format (RFC 1952), which wraps the same DEFLATE stream with different headers and a CRC-32 checksum; both wrappers are produced and consumed by the library.

Capabilities

The library provides functions for compressing and decompressing data in memory, streaming compression and decompression with adjustable levels (0 for stored data through 9 for best compression), dictionary-based compression, and the gz* family of functions for reading and writing gzip-format files. It is designed to be portable, free, and virtually memory-independent in operation.

Adoption

Because of its permissive zlib License and ubiquity, zlib is embedded in an enormous range of software: the PNG image format depends on it, as do the HTTP compression features of many web servers and clients, the OpenSSH and OpenSSL ecosystems, package formats, and countless programming-language standard libraries. Forks and optimised descendants include zlib-ng and Intel's IPP-based variants.
