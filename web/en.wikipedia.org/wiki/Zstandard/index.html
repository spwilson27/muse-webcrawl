Zstandard

Zstandard, commonly known by its command-line program name zstd, is a lossless data compression algorithm developed by Yann Collet at Facebook (now Meta) and first released in 2016. It aims to offer compression ratios comparable to DEFLATE (as used by gzip and zlib) with much faster compression and decompression speeds.

Features

Zstandard supports a range of compression levels, from fast low-ratio settings to very high ratios at slower speeds, including a special mode with long-range matching for redundancy over large distances. It also supports dictionary compression, in which a small dictionary trained on representative samples can dramatically improve ratios for small files. Decompression speed is high across all levels, typically several hundred megabytes per second per core.

The reference implementation is written in C and released under a dual BSD/GPL license. The format was standardised as RFC 8878 in 2021.

Adoption

Zstandard is used in the Linux kernel (for compressed filesystems such as Btrfs and for module compression), in package formats and distributions, in HTTP content encoding, and by many databases and backup tools.
