Game editor

A game editor is a software tool used to create or modify the content of a video game. The term most often refers to a level editor (also called a map or scenario editor), which lets designers — professional developers or players themselves — lay out levels, place objects and enemies, script events and test gameplay without editing raw code. Game editors range from internal development tools to polished end-user products that form a selling point of the game.

History

Player-facing editors appeared early: Lode Runner (1983) and Pinball Construction Set (1983) shipped with construction tools that anticipated the "construction set" genre. The modding culture around Doom (1993) and id Software's openly shared tools popularised user-made levels. Landmark shipped editors include StarCraft's StarEdit, whose scripting enabled the custom maps from which the MOBA genre emerged, Warcraft III's World Editor, Valve's Hammer editor, and Bethesda's Creation Kit. Full game-creation environments such as RPG Maker and GameMaker blur the line between editor and engine.

Features

Typical editors provide 2D or 3D viewport editing, asset browsers, terrain sculpting, trigger and scripting systems (visual or text-based), navmesh and lighting tools, and play-testing within the editor. Tile-based editors dominate 2D games, while modern 3D editors support real-time rendering identical to the shipped game. Many integrate with the game's engine pipeline so that edited content can be shared as mods.

Community role

Editors extend a game's lifespan by enabling user-generated content: entire genres (tower defence, MOBAs, battle royale via mods) began as editor creations. Platforms such as Steam Workshop institutionalise distribution of editor-made content, and some publishers monetise or formally support creator programmes built around their editors.
