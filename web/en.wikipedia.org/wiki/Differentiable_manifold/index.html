In mathematics, a differentiable manifold (also differential manifold) is a type of manifold that is locally similar enough to a vector space to allow one to apply calculus. Any manifold can be described by a collection of charts. One may then apply ideas from calculus while working within the individual charts, since each chart lies within a vector space to which the usual rules of calculus apply. If the charts are suitably compatible (namely, the transition between two overlapping charts is differentiable), then computations done in one chart are valid in any other differentiable chart.

Definition

A differentiable manifold is a topological manifold equipped with an equivalence class of atlases. Each atlas consists of charts (U, φ) where U is an open subset of the manifold and φ maps U homeomorphically onto an open subset of Rn. The atlas is smooth (of class C∞) if every transition map between overlapping charts is infinitely differentiable. Two atlases define the same differentiable structure if their union is also a smooth atlas.

Tangent spaces and smooth maps

At each point of an n-dimensional differentiable manifold one can define a tangent space, a vector space of dimension n consisting of the tangent vectors of curves passing through the point. A function between manifolds is smooth if its expression in charts is smooth. The derivative of a smooth map is a linear map between tangent spaces, called the differential or pushforward. These constructions underpin the whole machinery of differential geometry: tensors, differential forms, integration on manifolds, and Stokes' theorem.

Examples and applications

Spheres, tori, projective spaces and Lie groups are standard examples of differentiable manifolds. Differentiable manifolds are the natural setting for classical mechanics (configuration and phase spaces), general relativity (spacetime is modelled as a four-dimensional Lorentzian manifold), and much of modern mathematical physics and geometry.
