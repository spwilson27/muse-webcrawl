Standard Portable Intermediate Representation

The Standard Portable Intermediate Representation (SPIR) is an intermediate language for parallel compute and graphics by Khronos Group, originally developed for use with OpenCL. SPIR was influenced by and is based on the LLVM intermediate representation. SPIR-V is the version adopted as the native format for Vulkan.

History

The first version of SPIR was announced in 2011 as a temporary representation for OpenCL kernels. SPIR 1.2 was released in 2013, followed by SPIR 2.0 in 2014, which aligned with LLVM 3.2. In 2015, Khronos released SPIR-V, a ground-up redesign that became a unified intermediate representation for both graphics shaders and compute kernels, replacing the LLVM-based format with a binary format defined by a specification rather than tied to LLVM releases.

SPIR-V

SPIR-V is used by the Vulkan API, OpenCL 2.1 and later, and other Khronos standards. Shaders and kernels written in high-level languages such as GLSL and HLSL are compiled to SPIR-V by tools such as glslang, which drivers then translate into native hardware instructions. This allows application developers to ship portable intermediate code instead of hardware-specific binaries.
