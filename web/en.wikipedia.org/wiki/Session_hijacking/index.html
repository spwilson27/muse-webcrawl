Session hijacking

Session hijacking is a computer security attack in which an attacker steals or predicts a valid session token — commonly a session cookie — and uses it to impersonate a legitimate user in an ongoing session with a web application or network service.

Methods

Attackers may obtain session identifiers through cross-site scripting (XSS), session fixation, network sniffing of unencrypted traffic, brute-force prediction of weak session IDs, or malware. A related attack at the network layer, TCP session hijacking, involves injecting packets into an established TCP connection.

Countermeasures

Defences include using long, randomly generated session IDs, transmitting cookies only over HTTPS with Secure and HttpOnly attributes, regenerating session tokens after login, binding sessions to client characteristics, and expiring idle sessions.
