Boolean algebra (structure)

[Image placeholder: Boolean algebra (structure)]

In abstract algebra, a Boolean algebra is a complemented distributive lattice: an algebraic structure ⟨A, ∧, ∨, ¬, 0, 1⟩ satisfying identities that capture the behaviour of set intersection, union and complement, and equally of logical AND, OR and NOT.

Definition

A Boolean algebra is a set A with two binary operations ∧ (meet) and ∨ (join), a unary operation ¬ (complement), and distinguished elements 0 and 1, such that the operations are commutative and associative, distribute over each other, satisfy identity and absorption laws, and every element x has a complement ¬x with x ∧ ¬x = 0 and x ∨ ¬x = 1.

Examples and applications

Examples include the two-element algebra {0, 1} of logic circuits, the power set of any set under union/intersection/complement, and Lindenbaum algebras of propositional theories. Boolean algebras are dual to Boolean rings and connect algebra, logic and topology through Stone's representation theorem; they underpin digital circuit design and database query languages.
