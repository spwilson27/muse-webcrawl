iSCSI

Internet Small Computer Systems Interface or iSCSI is an Internet Protocol-based storage networking standard for linking data storage facilities. iSCSI is a transport layer protocol that works on top of the Transport Control Protocol (TCP). It enables block-level SCSI data transport between the iSCSI initiator and the storage target over TCP/IP networks.

Overview

iSCSI allows two hosts to negotiate and then exchange SCSI commands using Internet Protocol networks. By doing this, iSCSI takes a popular high-performance local storage bus and emulates it over a wide range of networks, creating a storage area network (SAN). Unlike some SAN protocols, iSCSI requires no dedicated cabling; it can be run over existing switching and IP infrastructure.

Concepts

An iSCSI initiator sends SCSI commands to a target, which typically resides on a storage device. Targets expose logical units (LUNs) which appear to the initiator's operating system as local disks. The protocol was standardized by the IETF in RFC 3720 and updated by RFC 7143.
