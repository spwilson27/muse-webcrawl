Functional completeness

From Wikipedia, the free encyclopedia

A single NAND gate is functionally complete: all Boolean functions can be built from NAND alone.

In logic, a functionally complete set of logical connectives or Boolean operators is one which can be used to express all possible truth tables by combining members of the set into a Boolean expression. A well-known complete set is {AND, NOT}, since binary operators reduced to AND alone are not enough: with NOT also available, any other operator (OR, IMPLIES, XOR, etc.) can be defined.

Definition

A set F of Boolean functions is functionally complete if the closure of F under composition — that is, all functions obtainable by composing functions of F with each other and with projections — covers all Boolean functions of every arity. The canonical singletons are NAND and NOR: each alone is functionally complete, a fact first proved by Henry M. Sheffer (1913) for the "Sheffer stroke" (NAND) and related to Charles Sanders Peirce's earlier unpublished work on the "ampheck" (NOR and NAND).

Post's completeness criterion

Emil Post (1920–1941) gave a necessary and sufficient condition: a set of Boolean functions is functionally complete if and only if it is not contained in any of the five closed classes:

  • T0 — truth-preserving functions (mapping all-false to false)
  • T1 — falsity-preserving functions (mapping all-true to true)
  • M — monotone functions
  • S — self-dual functions
  • L — affine (linear) functions

This leads to the structure known as Post's lattice, classifying all clones on a two-element set.

Examples

  • {AND, OR, NOT} — the standard textbook-complete set
  • {AND, NOT}, {OR, NOT}, {NAND}, {NOR}
  • {IMPLIES, FALSE} and {IMPLIES, NOT}
  • {AND, XOR, TRUE} — the basis of algebraic normal form (Reed–Muller expansion)

In digital electronics, sets such as NAND-gate-only or NOR-gate-only logic are used because a single gate type simplifies fabrication. In intuitionistic logic and other non-classical settings, functional completeness behaves differently, since classical definability of connectives can fail.
