Data serialization

In computing, serialization (or serialisation) is the process of translating a data structure or object state into a format that can be stored (for example, in a file or memory buffer) or transmitted (for example, over a network) and reconstructed later, possibly in a different environment. The reverse process is called deserialization.

Uses

Serialization is used for persisting objects to disk, sending data between processes or machines in distributed systems and remote procedure calls, and caching. Human-readable text formats include XML, JSON and YAML; compact binary formats include Protocol Buffers, Apache Thrift, MessagePack and BSON. Many programming languages provide built-in object serialization, such as Java's Serializable mechanism and Python's pickle module.

Considerations

Designs must handle versioning so older data can still be read after schemas change, character encoding, and ordering of bytes (endianness) in binary formats. Deserializing untrusted data is a well-known security risk, since malicious input can trigger unexpected behaviour in reconstruction code, and it is a recurring source of vulnerabilities.
