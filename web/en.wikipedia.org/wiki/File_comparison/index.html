File comparison

File comparison, in computing, is the automatic comparison of files on a computer system, most often text files, to identify their similarities and differences. The best-known tool is the Unix utility diff, whose output — itself called a "diff" — lists added, removed, and changed lines between two versions of a file.

Algorithms

Most comparison tools are built on the problem of finding the longest common subsequence of two files' lines, classically solved with dynamic programming. The widely used Myers algorithm finds a shortest edit script efficiently and underlies the diff implementations in the GNU diffutils package and in the Git version control system.

Uses

File comparison is fundamental to software development: version control systems use it to store changes compactly and to merge work, the patch utility applies diffs to update source code, and code review tools present changes side by side. Graphical comparison tools highlight differences in colour and support three-way merges between a common ancestor and two edited versions. Beyond text, specialized comparators exist for binary files, directory trees, disk images, and documents, often using checksums or byte-by-byte comparison.
