Web typography

Web typography is the use of fonts on the World Wide Web. When HTML was first created, font faces and styles were controlled exclusively by the settings of each web browser. There was no mechanism for individual web pages to control font display until Netscape introduced the font element in 1995, which was later standardised in the HTML 3.2 specification; however, the font specified by the tag had to be installed locally on the user's computer.

CSS and web fonts

The Cascading Style Sheets language improved typographic control through font-family lists and rules for size, weight, line height and letter spacing. The CSS2 specification included @font-face, which lets a page download a font file, but differing formats (Embedded OpenType, TrueType, SVG) and licensing concerns slowed adoption until the WOFF and WOFF2 formats and services such as Google Fonts and Typekit made downloadable fonts practical in the 2010s.

Considerations

Web typography must cope with varied screen sizes, pixel densities and reading conditions. Responsive typography scales type with viewport units and fluid type scales; performance concerns favour subsetted variable fonts; and accessibility requires adequate contrast, resizable text and line lengths suited to reading. Generic font families — serif, sans-serif, monospace, cursive and fantasy — provide fallbacks when preferred fonts are unavailable.
