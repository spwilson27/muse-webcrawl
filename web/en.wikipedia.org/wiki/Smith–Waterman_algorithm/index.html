Smith–Waterman algorithm

The Smith–Waterman algorithm performs local sequence alignment; that is, for determining similar regions between two strings of nucleic acid sequences or protein sequences. Instead of looking at the entire sequence, the Smith–Waterman algorithm compares segments of all possible lengths and optimises the similarity measure. The algorithm was first proposed by Temple F. Smith and Michael S. Waterman in 1981. Like the Needleman–Wunsch algorithm, of which it is a variation, Smith–Waterman is a dynamic programming algorithm and works by guaranteeing to find the optimal local alignment with respect to the scoring system being used.

Explanation

A matrix H is built with rows and columns corresponding to the two sequences. Each cell receives the maximum of four quantities: zero (the key difference from the global-alignment algorithm — no negative scores are allowed, so an alignment may start anew at any cell), the diagonal score plus a match or mismatch score, and the top or left scores minus gap penalties. With gap costs the general recurrence is:

H(i,j) = max { 0,
                 H(i-1,j-1) + s(a_i, b_j),
                 H(i-1,j) - d,
                 H(i,j-1) - d }

The highest-scoring cell gives the score of the best local alignment; traceback proceeds from that cell until a cell with score zero is reached.

Motivation and use

Local alignment is more useful than global alignment when comparing sequences that share only a conserved domain or motif, or sequences of very different lengths. Smith–Waterman is therefore fundamental in bioinformatics for database searching, though because it runs in quadratic time and memory it is usually approximated in practice by heuristic programs such as FASTA and BLAST, and by accelerated implementations for database search.

Complexity

For sequences of lengths m and n, the basic algorithm takes O(mn) time and can be reduced to O(n) space if only the score is required. Variants by Osamu Gotoh (1982) handle affine gap penalties efficiently, and many hardware and SIMD-accelerated implementations exist.
