Memoization

Memoization stores results of function calls in a table

In computing, memoization or memoisation is an optimization technique used primarily to speed up computer programs by storing the results of expensive function calls to pure functions and returning the cached result when the same inputs occur again. Memoization has also been used in other contexts, such as in simple mutually recursive descent parsing.

Etymology

The term "memoization" was coined by Donald Michie in 1968 and is derived from the Latin word memorandum ("to be remembered"). Although "memoization" might be confused with "memorization" (because of their similar spellings), "memoization" has a distinct meaning in computing. It is a specific form of caching that involves a function call.

How it works

A memoized function "remembers" the results corresponding to some set of specific inputs. Subsequent calls with remembered inputs return the remembered result rather than recalculating it, eliminating the primary cost of a call with given parameters from all but the first such call. The technique trades memory for speed, and it is a classic example of a space–time tradeoff.

function factorial(n)
    if n is in lookup table then
        return lookup table value for n
    else
        let x = factorial(n - 1) * n
        store x in lookup table for n
        return x

Applications

Memoization is fundamental to dynamic programming: problems with overlapping subproblems, such as computing Fibonacci numbers or finding optimal sequence alignments, can be solved efficiently by caching subproblem results. It is also used in parsers (packrat parsing), in automatic differentiation, and in functional programming languages, where language features or libraries — for example Python's functools.lru_cache — make it easy to apply to pure functions.
