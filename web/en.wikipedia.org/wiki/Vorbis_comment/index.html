Vorbis comment

A Vorbis comment is a metadata container used in the Vorbis, FLAC, Theora, Speex and Opus file formats, and in the Ogg container generally. It allows the inclusion of information about the file, such as the track title, artist, album, track number and other tags, in a flexible, human-readable form.

Structure

A Vorbis comment consists of a vendor string followed by a list of fields, each of the form FIELDNAME=value. Field names are case-insensitive ASCII and values are stored as UTF-8 text, so any language can be used. Tags are not limited to a fixed set: standard field names include TITLE, ARTIST, ALBUM, TRACKNUMBER, DATE, GENRE, DESCRIPTION and COMPOSER, and multiple fields with the same name are allowed — for example, several ARTIST fields for collaborations.

Comparison with other formats

Unlike ID3 tags in MP3 files, which use numeric frame identifiers and (in early versions) fields of fixed length, Vorbis comments are simple UTF-8 key–value pairs with no size limits and no binary structures. The specification deliberately keeps the system minimal — a "comment", not a full metadata framework — and discourages storing large binary data in the comment header.

Usage

The comment header appears in the codec setup headers: as the second header packet in Vorbis and Opus streams, and in FLAC files usually within a VORBIS_COMMENT metadata block. Most audio players and tag editors (such as MusicBrainz Picard and foobar2000) read and write Vorbis comments transparently.
