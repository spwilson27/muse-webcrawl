In computing, virtualization (sometimes abbreviated v12n, a numeronym) is a series of technologies that allow dividing of physical computing resources into a series of virtual machines, operating systems, processes or containers. Virtualization began in the 1960s on IBM mainframes as a method of logically dividing system resources between different applications, and it became mainstream on commodity x86 servers in the 2000s, forming the technical foundation of cloud computing.

Hardware virtualization

Hardware virtualization creates virtual machines (VMs) that act like physical computers with their own operating systems. The software that creates and runs VMs is called a hypervisor. Type 1 ("bare-metal") hypervisors—such as VMware ESXi, Microsoft Hyper-V (in its server role), and the open-source Xen and KVM—run directly on hardware and dominate data centers. Type 2 ("hosted") hypervisors—such as VirtualBox and VMware Workstation—run as applications on a host OS. Techniques include full virtualization (with binary translation or, nowadays, hardware assists such as Intel VT-x and AMD-V), paravirtualization (guests modified to cooperate with the hypervisor), and hardware-assisted virtualization, which with nested paging provides near-native performance.

OS-level virtualization

Operating-system-level virtualization, popularized by FreeBSD jails, Solaris Zones, and Linux containers (LXC, Docker), runs multiple isolated user-space instances ("containers") on a single kernel. Containers share the host kernel, so they start quickly and are lightweight, but they cannot run a different operating system kernel and their isolation is generally weaker than that of VMs. Containers became the standard packaging unit for microservices and are orchestrated by platforms such as Kubernetes.

Other forms

Desktop virtualization separates a user's desktop environment from the physical machine (VDI). Application virtualization packages software to run in an isolated layer without full installation. Network virtualization abstracts networking into virtual networks, VLANs, and software-defined networking, while storage virtualization pools physical storage into logical volumes. Memory and data virtualization apply the same abstraction principle in their domains.

Benefits and drawbacks

Virtualization improves hardware utilization, enables server consolidation and energy savings, provides isolation and security boundaries, simplifies backup, snapshotting, migration (including live migration of running VMs), testing, and disaster recovery, and allows legacy systems to run on modern hardware. Drawbacks include performance overhead (small with hardware assists), licensing complexity, VM sprawl, and the concentration of risk when many VMs share one host or hypervisor ("hyperjacking" attacks and side channels). Together with automation and self-service provisioning, virtualization underlies infrastructure as a service (IaaS) in cloud computing.

History

IBM's CP-40 and CP-67/CMS systems (1966–1967) and the IBM System/370 with VM/370 (1972) established time-sharing virtual machines on mainframes. On x86, VMware (founded 1998) overcame the architecture's virtualization obstacles, and Intel and AMD added hardware support in 2005–2006. Amazon Web Services' EC2 (2006) built its public cloud on Xen (later the Nitro hypervisor), cementing virtualization as the default computing substrate of the internet era.
