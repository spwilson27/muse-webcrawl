The Baudot code is an early character encoding for telegraphy invented by the French engineer Émile Baudot in the 1870s. It encodes each character in five bits, allowing 32 distinct code points, and was transmitted by an operator using a five-key piano-style keyboard, several operators sharing a single line by time-division multiplexing. The unit of telegraph speed, the baud, is named after Baudot.

Operation

Because 32 combinations cannot cover letters, digits and punctuation, the Baudot code uses two "shift" characters — Letters shift and Figures shift — which switch the interpretation of all following codes until the other shift is sent. Baudot's original assignment of codes was arranged for his keyboard and printing mechanism. Around 1901 Donald Murray rearranged the code to minimise wear on the machinery, assigning the most frequent letters the fewest punched holes; this version, standardised internationally as International Telegraph Alphabet No. 2 (ITA2), became the basis of teleprinter operation worldwide.

Use

Five-unit codes drove teleprinters and Telex networks through most of the twentieth century, and ITA2-derived encodings persisted in radio-teletype (RTTY) amateur and press services and in telecommunications devices for the deaf (TDDs). A missed shift character in the original system produced the famous garbling known to operators, and in the ASCII era the same code family influenced conventions such as the all-capitals style of telegrams. The Baudot code was eventually superseded by 7-bit ASCII and later encodings, but survives in niche radio use.
