Pumping lemma for regular languages

In the theory of formal languages, the pumping lemma for regular languages states a necessary condition that every regular language must satisfy. It is most often used, via its contrapositive, to prove that a given language is not regular: if a language violates the condition, no finite automaton can recognise it. The lemma was proved by Yehoshua Bar-Hillel, Micha Perles and Eli Shamir in 1961, in work on simplification of context-free grammars.

Statement

If a language L is regular, then there exists an integer p ≥ 1 (the pumping length) such that every string s in L with |s| ≥ p can be written as s = xyz satisfying:
  1. |y| ≥ 1 (the middle part is non-empty);
  2. |xy| ≤ p (the first two parts together are no longer than p);
  3. for every integer i ≥ 0, the string xyiz is in L.

Intuitively: a finite automaton with p states reading a long input must revisit some state, completing a loop; the loop segment y can then be traversed any number of times ("pumped" up or down) without leaving the language.

Proof idea

Let p be the number of states of a deterministic finite automaton accepting L. For a string s of length at least p, the run of the automaton visits p + 1 states, so by the pigeonhole principle some state repeats within the first p symbols. The substring read between the two visits forms y; deleting it or repeating it keeps the run on a valid path from the start state to an accept state.

Use: proving non-regularity

The standard application is a proof by contradiction, framed as a game: the adversary chooses p; the prover exhibits a string s ∈ L with |s| ≥ p; the adversary splits s = xyz subject to the constraints; the prover finds an i with xyiz ∉ L.

Classic example: let L = { anbn : n ≥ 0 }. Choose s = apbp. Since |xy| ≤ p, the part y consists only of a's; pumping up to xy2z gives more a's than b's, which is not in L. Hence L is not regular.

Limitations

The condition is necessary but not sufficient: some non-regular languages satisfy it, so the lemma cannot prove a language regular. Finer tools for non-regularity include the Myhill–Nerode theorem, which gives an exact characterisation, and closure arguments.

Generalisations

Analogous pumping lemmas exist for context-free languages (the Bar-Hillel lemma) and for other families in the Chomsky hierarchy, and there are stronger forms (e.g. Ogden's lemma) for finer distinctions.
