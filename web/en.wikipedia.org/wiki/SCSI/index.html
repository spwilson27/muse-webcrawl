SCSI

SCSI (pronounced "scuzzy"), originally the Small Computer System Interface, is a set of standards for physically connecting and transferring data between computers and peripheral devices, most commonly hard disk drives, tape drives, optical drives and scanners. The SCSI standards define commands, protocols, and the electrical, optical and logical interfaces. SCSI is most commonly used for hard disk drives and tape drives, but it can connect a wide range of other devices.

History

SCSI descends from the Shugart Associates System Interface (SASI), developed in 1979–1981. Shugart and NCR proposed it to ANSI, which published the SCSI-1 standard in 1986. SCSI-2 (1994) added Fast and Wide variants and command queuing; SCSI-3 split the standard into a family of documents, including the parallel Ultra, Ultra2, Ultra-160 and Ultra-320 generations. The parallel interface was eventually displaced by serial transports that reuse the SCSI command set: Serial Attached SCSI (SAS), Fibre Channel, and iSCSI over TCP/IP networks.

Architecture

A SCSI subsystem consists of an initiator (usually a host bus adapter in the computer) and one or more targets (peripherals), each target possibly exposing several logical units (LUNs). Classic parallel SCSI uses a shared multi-drop bus with unique device IDs and termination at both ends; data transfers reached 320 MB/s with Ultra-320 (80 MHz, 16-bit "wide" transfers). Commands are organised in command descriptor blocks covering operations such as READ, WRITE, INQUIRY and TEST UNIT READY, with a rich set of device-class command sets for disks (SBC), tapes (SSC) and media changers.

Interfaces and connectors

Parallel SCSI connectors evolved from 50-pin Centronics-style and D-sub connectors to high-density 68-pin and VHDCI types. Single-ended, low-voltage differential (LVD) and high-voltage differential (HVD) signalling schemes were used, with careful termination required to prevent signal reflections. The serial successors use small point-to-point connectors and support much longer cable runs, hot-swapping and far higher speeds—modern SAS links reach 24 Gbit/s per lane.

Legacy

Although parallel SCSI has disappeared from mainstream personal computers (where USB, SATA and NVMe prevailed), the SCSI command architecture lives on: SAS, iSCSI, Fibre Channel, USB mass-storage class and even ATAPI all carry SCSI-derived command sets, and operating systems still model storage devices in SCSI terms.
