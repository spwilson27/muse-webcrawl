Shell (computing)

Shell
TypeUser interface software
ExamplesBash, Zsh, PowerShell, Windows shell

In computing, a shell is a computer program that exposes an operating system's services to a human user or another program, acting as an outer layer around the kernel. Shells may take the form of a command-line interface (CLI), in which users type commands that the shell interprets and executes, or a graphical user interface (GUI) presenting windows, icons and menus.

Command-line shells

The command-line shell both interprets single commands interactively and runs scripts. The Unix tradition began with the Thompson shell (1971), followed by the Bourne shell (sh, 1979) and C shell (csh). Modern successors include the Bourne Again Shell (bash), the Z shell (zsh), and fish, offering features such as command history, job control, pipelines, redirection, wildcards (globbing) and programmable completion. On Windows, command-line shells include cmd.exe and PowerShell, the latter built around objects rather than text streams.

Graphical shells

Graphical shells provide the desktop environment's most visible layer: managing windows, launching applications and handling files through metaphors such as the desktop and taskbar. Examples include the Windows shell (Windows Explorer), macOS Finder, and Linux desktop environments such as GNOME Shell, KDE Plasma and Xfce.

Features

Shells commonly provide environment variables, command substitution, input/output redirection, conditional execution and functions. Because the shell is the user's primary interface to the system, its scripting language is also a general automation tool, widely used in system administration and software build processes.
