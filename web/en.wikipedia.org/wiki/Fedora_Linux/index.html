Fedora Linux

Fedora Linux is a Linux distribution developed by the community-supported Fedora Project and sponsored primarily by Red Hat, a subsidiary of IBM. Fedora contains only free and open-source software and is known for adopting new technologies early; it serves as the upstream source for Red Hat Enterprise Linux, and Linus Torvalds has used it for many years.

History

Fedora was created in 2003 when Red Hat split its distribution into the community Fedora Core and the enterprise-oriented Red Hat Enterprise Linux. The "Core" and "Extras" repositories merged in 2007, and the name was shortened to Fedora. In 2020 the project adopted the name Fedora Linux for the distribution as a whole. New releases appear roughly every six months, each supported for about thirteen months.

Editions and features

Official editions include Workstation (for desktops, with the GNOME desktop), Server, IoT and Cloud images, alongside "spins" with other desktop environments such as KDE Plasma, Xfce and i3, and "labs" for specialised fields including astronomy and security. Fedora pioneered features now standard in Linux distributions, including SELinux enabled by default, systemd, Wayland as the default display protocol, and the Flatpak packaging ecosystem.
