Font

FieldTypography
DefinitionA particular size, weight and style of a typeface
Common formatsTrueType, OpenType, WOFF

In metal typesetting, a font was a particular size, weight and style of a typeface. Each font was purchased as a set of metal sorts. The use of the term has since extended to digital files: today a "font" usually means a computer file containing glyphs in a given typeface design, often with multiple weights and styles — though strictly, a typeface is the design and a font is one implementation of it.

Terminology

The word derives from French fonte, "something that has been melted", referring to type cast in a type foundry. Traditional distinctions include weight (light, regular, bold), style (italic, condensed), and size measured in points. A set of related fonts forms a typeface family.

Digital fonts

Early computer fonts were bitmaps; scalable outline formats followed — PostScript Type 1, TrueType (developed by Apple and Microsoft), and OpenType, which unified them and added advanced typographic features such as ligatures and alternate glyphs. Web fonts are delivered in formats such as WOFF and WOFF2 via the CSS @font-face rule. Variable fonts encode a continuous range of weights and widths in a single file.
