Computer language

A computer language is a formal language used to communicate instructions to a computer. The term is broader than programming language: it covers any language designed for machine processing, including markup languages, data description languages, query languages, and hardware description languages, as well as the programming languages used to write software.

Categories

  • Programming languages — specify computations and algorithms, e.g. Python, C, Java, Haskell. They are usually Turing complete.
  • Markup languages — annotate text and documents so that structure or presentation is machine-readable, e.g. HTML, XML, Markdown. They are generally not Turing complete.
  • Data and query languages — describe, store, and retrieve structured data, e.g. SQL for relational databases and JSON or YAML as data formats.
  • Modelling and specification languages — describe systems, protocols, or formats, e.g. UML, regular expressions, and grammar notations such as BNF.
  • Hardware description languages — describe electronic circuits, e.g. Verilog and VHDL.
  • Command and configuration languages — direct shells, build tools, and system configuration.

Formal properties

Computer languages are defined by syntax (form) and semantics (meaning), often specified with formal grammars. In the Chomsky hierarchy, most practical languages combine context-free syntax with context-sensitive semantic rules. Unlike natural languages, they are designed to be unambiguous and mechanically processable by compilers, interpreters, parsers, and other tools. The study of computer languages overlaps formal language theory, linguistics, and software engineering.
