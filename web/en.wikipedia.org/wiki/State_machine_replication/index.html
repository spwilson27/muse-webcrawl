State machine replication

State machine replication (SMR) is a general method for implementing a fault-tolerant service by replicating servers and coordinating client interactions with the replicas. Each replica executes the same deterministic sequence of commands, so all replicas pass through the same sequence of states.

Approach

The key requirement is that replicas agree on the order of incoming requests — a problem solved by consensus protocols such as Paxos and Raft — and that the service behaves deterministically given the same inputs. Clients send commands to the replicas, which agree an ordering, execute in that order, and return matching replies.

Applications

SMR underlies distributed coordination services and replicated databases such as ZooKeeper, etcd, and Chubby, and Byzantine-fault-tolerant variants are used in some blockchain systems.
