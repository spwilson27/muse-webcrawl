Similar matrix

In linear algebra, two n-by-n matrices A and B are called similar if there exists an invertible n-by-n matrix P such that

B = P−1 A P.

Similar matrices represent the same linear transformation under two different bases, with P being the change-of-basis matrix. The transformation of a matrix into a similar one is called a similarity transformation.

Properties

Similarity is an equivalence relation on square matrices. Two similar matrices share many properties, including:

  • the same rank;
  • the same determinant;
  • the same trace;
  • the same eigenvalues (including algebraic multiplicities);
  • the same characteristic polynomial and minimal polynomial;
  • the same Jordan normal form, up to permutation of the Jordan blocks.

These quantities are therefore invariants of the underlying linear map, independent of the choice of basis. The converse is not true in general: matrices with the same characteristic polynomial need not be similar, though matrices with the same Jordan form are similar.

Motivation and applications

Because similar matrices describe one linear operator in different coordinate systems, one seeks bases in which the matrix takes an especially simple form. Diagonalisation is the special case in which a matrix is similar to a diagonal matrix; more generally, the Jordan normal form gives the simplest representative of a similarity class over an algebraically closed field. Similarity also underlies the notion of conjugacy in group theory: in the general linear group, similarity classes are exactly the conjugacy classes.

Notes

Two matrices that are similar over a larger field are also similar over the ground field, since the rational canonical form depends only on the field of definition. Similarity should not be confused with matrix equivalence, which allows independent changes of basis in the domain and codomain, or with congruence, which arises for bilinear forms.
