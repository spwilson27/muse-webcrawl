Petrov classification

The Petrov classification (also called the Petrov–Penrose classification) is a scheme in differential geometry and general relativity for classifying spacetimes according to the algebraic structure of the Weyl tensor at each point. Introduced by the Soviet physicist Aleksey Petrov in 1954, it groups the possible symmetries of the Weyl tensor into a set of types based on the multiplicities and alignments of its principal null directions.

Types

A spacetime point is characterised by up to four principal null directions of the Weyl tensor. The Petrov types are:

  • Type I — four distinct principal null directions (the generic, algebraically general case).
  • Type II — one direction repeated twice, the other two distinct.
  • Type D — two pairs of repeated directions; the type of the Schwarzschild and Kerr black hole solutions.
  • Type III — one direction of multiplicity three.
  • Type N — all four directions coincident; the type of pure gravitational radiation such as plane waves.
  • Type O — the Weyl tensor vanishes; the spacetime is conformally flat.

Significance

The classification organises the exact solutions of Einstein's field equations: most physically important solutions are algebraically special (types II, D, N, or O). Type D includes the Kerr metric of a rotating black hole, while type N describes gravitational waves. The scheme can be described elegantly using spinors in the Newman–Penrose formalism, where the types correspond to factorisation patterns of the Weyl spinor polynomial.
