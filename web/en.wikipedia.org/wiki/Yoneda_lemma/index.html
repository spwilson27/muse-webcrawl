Yoneda lemma

Yoneda lemma
The Yoneda lemma relates an object to the system of maps into it
FieldCategory theory (mathematics)
Named afterNobuo Yoneda
StatementNat(Hom(A, –), F) ≅ F(A) for a locally small category and a set-valued functor F

In mathematics, specifically category theory, the Yoneda lemma is an abstract result on functors of the type morphisms-into-an-object. Loosely speaking, it says that an object of a category is determined up to isomorphism by the network of morphisms relating it to every other object — by "what maps into it" (or out of it, in the dual version). It is named after the Japanese mathematician Nobuo Yoneda, who communicated it to Saunders Mac Lane in the 1950s.

Formal statement

Let C be a locally small category and F : C → Set a functor. For any object A of C, the natural transformations from the representable functor HomC(A, –) to F are in natural bijection with the elements of the set F(A):

Nat(Hom(A, –), F) ≅ F(A)

The bijection sends a natural transformation α to the element αA(idA) of F(A) — the image of the identity morphism. Moreover, this bijection is natural in both A and F.

Consequences

Applying the lemma with F itself representable shows that the Yoneda embedding — the functor sending each object A to Hom(–, A) — is full and faithful. Hence a category embeds into its category of set-valued presheaves, and properties of objects can be studied through their associated presheaves. Many familiar constructions — Cayley's theorem for groups, the Dedekind embedding of rings, and the fact that a topological space is determined by maps into it — are special cases or analogues of the lemma. A common slogan summarising the philosophy is that "an object is determined by how it is seen from every other object."

Proof sketch

Given α, define the corresponding element as above. Conversely, given x in F(A), define a transformation whose component at an object B sends a morphism f : A → B to F(f)(x). Naturality forces these two constructions to be mutually inverse; the key steps are forced by what must happen to the identity morphism idA.
