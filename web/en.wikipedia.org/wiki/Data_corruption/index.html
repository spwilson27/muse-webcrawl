Data corruption

Data corruption refers to errors in computer data that occur during writing, reading, storage, transmission or processing, introducing unintended changes to the original data. Corruption may be detected and corrected, detected but uncorrectable, or — in the most damaging cases — go entirely unnoticed ("silent corruption").

Visible corruption in an image file caused by bit errors in the stored data.

Causes

  • Hardware faults, including failing storage media, bit rot, and cosmic-ray-induced bit flips in memory.
  • Power loss or system crashes during write operations.
  • Software bugs in drivers, file systems, firmware or applications.
  • Transmission errors on networks and buses.
  • Malicious modification by malware.

Detection and correction

Common defenses include parity bits, checksums and cryptographic hash functions for detection, and error-correcting codes (ECC), redundant storage such as RAID, journaling file systems and backups for correction and recovery. File systems such as ZFS and Btrfs checksum data blocks so that silent corruption can be identified and repaired from redundant copies. Memory systems in servers commonly use ECC RAM to correct single-bit errors.

Silent data corruption

Large-scale studies of disk drives and data centers have shown that silent corruption — data returned incorrectly with no error reported — occurs at rates higher than traditional models assumed, motivating end-to-end checksumming throughout storage stacks.
