Code name

A code name, codename, or cryptonym is a code word or name used, sometimes clandestinely, to refer to another name, word, project, or person. Code names are commonly adopted by military organisations, intelligence agencies, governments, and corporations to protect operational security and confidentiality, and to give internal projects a convenient shorthand distinct from their eventual public names.

Military use

Modern military code naming expanded during the Second World War, when major operations received names such as Overlord (the Allied invasion of Normandy), Barbarossa (the German invasion of the Soviet Union), and Torch (the invasion of North Africa). Winston Churchill laid down rules for choosing names: they should not imply the nature of the operation, boast, or be frivolous, since a widow might one day read the name of the operation in which her husband died. The United States later adopted a computerised system (NICKA) that generates two-word exercise and operation names from approved word blocks, producing names such as Desert Storm and Enduring Freedom that also serve a public-affairs purpose, blurring the line between code name and brand.

Intelligence and government

Intelligence services assign cryptonyms to agents, sources, and operations; the CIA traditionally used two-letter digraph prefixes indicating the country or programme concerned. Protective services use code names for the people they guard — United States presidents and their families receive Secret Service code names (for example, "Eagle" and "Renegade") that persist as convenient radio call signs even though they are publicly known.

Commercial and technological use

Companies use code names for products under development to prevent leaks and to defer trademark decisions. Well-known examples include Apple's Mac OS X releases named after big cats, Google's Android versions named after desserts (Cupcake, Donut, KitKat), Microsoft's "Chicago" (Windows 95) and "Longhorn" (Windows Vista), and Intel processor families named after rivers and geographic features. In software development, code names often survive in documentation and configuration long after launch.
