AppArmor

AppArmor (“Application Armour”) is a Linux kernel security module that implements mandatory access control by confining programs to a limited set of resources. It supplements traditional Unix discretionary permissions and is included in the mainline Linux kernel.

Profiles

AppArmor policies are expressed as per-program profiles written in a text format. A profile specifies which files a program may read, write or execute, which capabilities it may use and what network access it may have. Profiles can run in complain mode, logging violations without blocking them, or enforce mode, denying actions outside the policy. Tools can generate profiles semi-automatically by observing a program's behaviour.

History and use

AppArmor originated in Immunix's work in the late 1990s, was developed by Novell after it acquired Immunix, and later by Canonical. It is enabled by default in Ubuntu and used in SUSE and Debian systems. AppArmor is often compared with SELinux: AppArmor is path-based and generally considered simpler to configure, while SELinux uses labels and offers finer-grained type enforcement.
