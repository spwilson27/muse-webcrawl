Chromatic polynomial

The chromatic polynomial is a graph polynomial studied in algebraic graph theory. For a graph G and a positive integer k, the value P(G, k) counts the number of proper vertex colourings of G using at most k colours — colourings in which no two adjacent vertices share a colour. It was introduced by George David Birkhoff in 1912 in connection with the four colour problem, in the hope that its properties might illuminate the conjecture for planar graphs.

Definition and computation

For a graph with no edges, P(G, k) = kn, where n is the number of vertices, since every vertex can be coloured independently. The polynomial is computed using the deletion–contraction recurrence: for an edge e, P(G, k) = P(G − e, k) − P(G/e, k), where G − e deletes the edge and G/e contracts it. For example, a tree on n vertices has chromatic polynomial k(k − 1)n−1, and the complete graph Kn has the falling factorial k(k−1)⋯(k−n+1).

Properties

The degree of the polynomial equals the number of vertices, its leading coefficient is 1, and the smallest positive integer at which it is nonzero is the chromatic number of the graph. The coefficients alternate in sign and satisfy log-concavity. Evaluating the chromatic polynomial is #P-hard in general, except at a few special points.

Relations

The chromatic polynomial is a special case of the Tutte polynomial: P(G, k) = (−1)|V|−c kc TG(1 − k, 0), where c is the number of connected components. It is also connected to the Potts model of statistical mechanics, where it appears as a special case of the partition function.
