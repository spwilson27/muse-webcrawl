Augmented Backus–Naur form

From Wikipedia, the free encyclopedia

In computer science, Augmented Backus–Naur form (ABNF) is a metalanguage based on Backus–Naur form (BNF) that is used to describe a formal system of a language, most often the syntax of Internet protocols. ABNF was standardised by the Internet Engineering Task Force in RFC 5234 (2008), superseding RFC 4234 and the original RFC 2234, with case-sensitive string support added by RFC 7405.

ABNF rules defining a simple date syntax.

Description

An ABNF specification is a set of derivation rules of the form:

rulename = elements

Rule names are case-insensitive. Elements may be terminals written as quoted strings (case-insensitive by default), numeric values given in decimal, hexadecimal or binary (e.g. %x41 for "A"), or references to other rules. Operators include concatenation (juxtaposition), alternation (/), grouping with parentheses, optional elements in square brackets, and repetition prefixes such as 1*4 (one to four occurrences) or * (zero or more). Comments follow a semicolon.

Example

The postal address example from RFC 5234 illustrates typical usage:

postal-address   = name-part street zip-part
name-part        = *(personal-part SP) last-name [SP suffix]
                     CRLF
street           = [apt SP] house-num SP street-name CRLF
zip-part         = town-name "," SP state 1*2SP zip-code CRLF

Usage

ABNF is the standard grammar notation of IETF specifications: it defines parts of HTTP, SMTP, IMAP, SIP, URI syntax and many other protocols. RFC 5234 itself defines a "core" set of rules (ALPHA, DIGIT, CRLF, SP, etc.) in its appendix that other specifications import.
