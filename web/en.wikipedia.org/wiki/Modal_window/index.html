Modal window

TypeGraphical user interface element
RelatedDialog box, pop-up, lightbox

In user interface design, a modal window is a graphical control element subordinate to an application's main window that creates a mode in which the main window is disabled until the user interacts with the modal window. Modal windows are commonly used for dialog boxes requiring a response — such as confirmations, alerts, or data entry — before work can continue.

Usage

Design guidelines generally reserve modality for critical information, confirmations of destructive actions, or short, focused subtasks, because modal windows interrupt the user's flow. On the web, modal overlays in the "lightbox" style dim the underlying page and present content such as forms, images or sign-in prompts. Accessible implementation requires keyboard focus management, trapping focus within the dialog and returning focus on close.

Modeless alternatives

Modeless dialogs and non-blocking notifications (such as "toast" messages and undo patterns) allow users to continue working and are often preferred where an immediate response is not essential.
