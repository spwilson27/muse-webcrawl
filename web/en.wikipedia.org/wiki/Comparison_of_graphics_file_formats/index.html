Comparison of graphics file formats

This is a comparison of image file formats, covering raster (bitmap) and vector formats used for still images. Formats differ in compression (lossless or lossy), color depth, support for transparency and animation, metadata, and licensing.

Choosing a format

Photographs favour lossy formats (JPEG, WebP, AVIF); graphics with sharp edges or text favour lossless PNG or vector SVG; animation is served by GIF, WebP, AVIF, or video formats; archival and print work favours TIFF and camera RAW formats such as DNG. Newer formats generally improve compression efficiency but depend on browser and platform support.
