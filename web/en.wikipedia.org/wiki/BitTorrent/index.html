BitTorrent, also referred to simply as torrent, is a communication protocol for peer-to-peer file sharing (P2P), which enables users to distribute data and electronic files over the Internet in a decentralized manner. The protocol was designed in April 2001 by programmer Bram Cohen and was first implemented that summer.

How it works

To share a file or group of files, a user first creates a small torrent descriptor file (.torrent) containing metadata about the files and about a tracker — a server that coordinates the action of peers. The file is divided into equal-sized pieces; peers downloading the file (the "swarm") exchange pieces with one another, so each downloader simultaneously uploads pieces it already has to others. This tit-for-tat design means a popular file becomes easier, not harder, to download as demand grows — inverting the bottleneck of client–server distribution.

Terminology

Peers that possess the complete file are called seeders; those still downloading are leechers. Later developments added trackerless operation using distributed hash tables (DHT), magnet links that identify content by cryptographic hash rather than by a hosted .torrent file, and protocol encryption.

Use and impact

BitTorrent is used for many legitimate purposes, including distributing Linux installation images, game updates, scientific datasets and content delivery by companies such as Blizzard Entertainment and Facebook internally. It has also been widely used for unauthorised copying of films, music and software, prompting sustained legal and technical countermeasures by copyright holders. At its peak, BitTorrent traffic accounted for a substantial fraction of all Internet traffic.
