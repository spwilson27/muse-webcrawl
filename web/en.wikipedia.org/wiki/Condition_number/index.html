Condition number

From Wikipedia, the free encyclopedia


Small input changes can produce large output changes in ill-conditioned problems

In the field of numerical analysis, the condition number of a function measures how much the output value of the function can change for a small change in the input argument. This is used to measure how sensitive a function is to changes or errors in the input, and how much error in the output results from an error in the input.

Matrices

For a square matrix A, the condition number with respect to a matrix norm is defined as κ(A) = ‖A‖ ‖A−1‖. In solving the linear system Ax = b, the condition number bounds the amplification of relative errors: a perturbation in b or in A can change the solution x by a factor roughly κ(A) times larger in relative terms.

In the 2-norm, κ(A) equals the ratio of the largest to the smallest singular value of A. A matrix with a large condition number is said to be ill-conditioned; one with κ near 1 is well-conditioned. A singular matrix has an infinite condition number. As a rule of thumb, if κ(A) ≈ 10k, then up to k digits of accuracy may be lost in solving the system on a computer.

General definition

For a general problem f(x), the (relative) condition number is the limit, as the perturbation tends to zero, of the ratio of the relative change in the output to the relative change in the input. Problems with small condition numbers are well-conditioned; large condition numbers indicate ill-conditioning, a property of the problem itself, distinct from the stability of any particular algorithm.
