Struct (C programming language)

Memory layout of a struct with padding

In the C programming language, a struct (short for "structure") is a composite data type that groups together variables of potentially different types under a single name. The members of a struct are stored in memory in the order declared, possibly with implementation-defined padding inserted to satisfy alignment requirements, so the size of a struct is at least the sum of its members' sizes.

Declaration and use

struct point {
    int x;
    int y;
};

struct point p = { .x = 3, .y = 4 };
p.x += 1;

Members are accessed with the dot operator (.) on a struct value or the arrow operator (->) through a pointer. A typedef is commonly used to avoid repeating the struct keyword. Structs can contain pointers to their own type, enabling linked lists, trees and other recursive data structures, and can be nested, returned from functions, and assigned wholesale—unlike arrays.

Bit fields and unions

A member may be declared with a width in bits (a bit field), allowing compact packing of flags and small integers; the packing order is implementation-defined. A union is a related construct in which all members share the same storage. An anonymous struct or union member (standardised in C11) contributes its members to the enclosing type.

Implementation details

Alignment requirements mean reordering members can change a struct's size; tools such as offsetof reveal member offsets. Because struct layouts are part of binary interfaces, operating-system headers define them carefully, and flexible array members (C99) support variable-length trailing data in allocated structs.
