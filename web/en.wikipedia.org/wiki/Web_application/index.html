Web application

A web application (or web app) is application software that is accessed through a web browser and typically runs on a remote web server, in contrast to software installed locally on a device. Web applications range from webmail and online banking to collaborative document editors and social networks.

Architecture

A typical web application follows a client–server model: the browser (client) renders the user interface, while application logic and data storage reside on servers. Modern applications often use a three-tier design — presentation, application logic and data tiers — and may expose APIs to which a JavaScript front end sends asynchronous requests. Frameworks and libraries such as React, Angular, Django and Ruby on Rails structure much of this development.

History

Early websites were static documents; interactivity arrived with CGI scripts in the 1990s, followed by server-side scripting languages and Ajax techniques in the mid-2000s that allowed pages to update without full reloads — a shift memorably demonstrated by Gmail and Google Maps. Single-page applications and progressive web apps further blurred the line between web and native software, adding offline operation and installability.

Advantages and challenges

Web applications need no installation, update centrally and run across platforms, but depend on connectivity and browser capabilities, and must address security threats such as cross-site scripting and session hijacking.
