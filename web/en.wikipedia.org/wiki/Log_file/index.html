Log file
Type: Computer file
Use: Record of events

In computing, a log file is a file that records events, messages and transactions generated by an operating system, application, server or device. Logs are used for debugging, monitoring, security auditing and performance analysis.

('Types and formats', 'Common logs include system logs, application logs, access logs and error logs, often in plain text with timestamps. Standards and tools such as syslog, log rotation, and centralised log management and analysis platforms help manage large volumes.')

('Practice', 'Good logging balances detail with performance and privacy, avoids storing sensitive data, and uses structured formats such as JSON for machine parsing.')
