Matrix multiplication

From Wikipedia, the free encyclopedia
Each entry of the product is the dot product of a row of the first matrix with a column of the second.

In mathematics, specifically in linear algebra, matrix multiplication is a binary operation that produces a matrix from two matrices. For matrix multiplication to be defined, the number of columns in the first matrix must equal the number of rows in the second matrix. The resulting matrix, known as the matrix product, has the number of rows of the first matrix and the number of columns of the second.

Definition

If A is an m × n matrix and B is an n × p matrix, their product C = AB is the m × p matrix whose entries are given by:

cij = Σk=1..n aik bkj

That is, the entry in row i and column j is the dot product of the i-th row of A with the j-th column of B.

Properties

Matrix multiplication is associative, (AB)C = A(BC), and distributive over addition, but it is in general not commutative: AB ≠ BA. The product corresponds to the composition of the linear maps represented by the matrices. The identity matrix acts as a multiplicative neutral element. Square matrices of a given size form a ring under addition and multiplication, and the invertible ones form the general linear group.

Computational complexity

The schoolbook algorithm for multiplying two n × n matrices takes Θ(n3) arithmetic operations. In 1969 Volker Strassen published the first asymptotically faster algorithm, running in roughly O(n2.807) time. Subsequent work, culminating in the Coppersmith–Winograd algorithm and its refinements, reduced the exponent ω to about 2.37. Determining the true value of ω is a major open problem in computer science. Matrix multiplication underlies many other algorithms in linear algebra, computer graphics, machine learning and scientific computing.

Applications

Matrix products model linear transformations such as rotations and scalings in computer graphics, transitions in Markov chains, input–output relations in economics, and the weight layers of artificial neural networks, where large matrix multiplications dominate modern machine-learning computation.
