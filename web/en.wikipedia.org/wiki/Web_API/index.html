Web API

A web API is an application programming interface (API) for either a web server or a web browser. As a web development concept, it can be related to a web application's client side (including any web frameworks being used). A server-side web API consists of one or more publicly exposed endpoints to a defined request–response message system, typically expressed in JSON or XML and accessed over HTTP.

Server side

A server-side web API exposes endpoints through which programs can retrieve data or trigger operations. Styles include REST, which uses standard HTTP methods and resource URLs; older SOAP-based services; and newer approaches such as GraphQL, which lets clients specify the shape of the data they need, and gRPC. Mashups are web applications which combine the use of multiple server-side web APIs.

Client side

A client-side web API is a programmatic interface to extend functionality within a web browser or other HTTP client. Browsers expose numerous built-in APIs, such as the DOM API, the Fetch API, Geolocation, Canvas, and Web Storage, specified largely by the W3C and WHATWG.

Design considerations

Web APIs must address authentication and authorization (e.g., API keys and OAuth), versioning, rate limiting, error formats, and documentation. Public specifications are often described with the OpenAPI Specification. Well-designed APIs contributed to the "API economy," in which services are composed from each other's interfaces.
