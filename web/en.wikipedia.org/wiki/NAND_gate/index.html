NAND gate

In digital electronics, a NAND gate (NOT-AND) is a logic gate which produces an output which is false only if all its inputs are true; thus its output is complementary to that of an AND gate. A LOW (0) output results only if all the inputs to the gate are HIGH (1); if any input is LOW (0), the output is HIGH (1).

The ANSI/MIL symbol for a NAND gate: an AND shape with an inversion bubble at the output.

Functional completeness

The NAND gate is of particular importance because of its functional completeness: any Boolean function can be implemented using only NAND gates (as can be done with NOR gates alone). Consequently, entire processors have been built from NAND gates, and in modern CMOS integrated circuits NAND structures are among the most economical to fabricate — a two-input CMOS NAND gate requires only four transistors.

Implementation

NAND gates are available in standard integrated-circuit packages, most famously the 7400 series quad two-input NAND (and its CMOS counterpart, the 4011). In TTL logic the gate is typically implemented with a multiple-emitter transistor input stage; in CMOS it uses two PMOS transistors in parallel in the pull-up network and two NMOS transistors in series in the pull-down network.

Symbols

Three symbols are in common use: the distinctive-shape (ANSI/MIL) symbol, the rectangular IEC symbol, and the older DIN symbol. By De Morgan's laws, a NAND gate is equivalently drawn as an OR gate with inverted inputs.
