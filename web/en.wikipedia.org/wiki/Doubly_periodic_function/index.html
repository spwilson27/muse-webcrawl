Doubly periodic function

In mathematics, a doubly periodic function is a function defined on the complex plane and having two distinct periods — two complex numbers whose ratio is not real — such that the function takes the same value when its argument is shifted by either period. Formally, a function f is doubly periodic with periods ω1 and ω2 if f(z + ω1) = f(z + ω2) = f(z) for all complex z, where ω1/ω2 is not a real number.

Properties

The set of all period combinations forms a lattice in the complex plane, and the function's behaviour is determined by its values on a fundamental parallelogram. A non-constant doubly periodic function that is holomorphic everywhere must be constant, by Liouville's theorem, so the interesting doubly periodic functions are meromorphic — the elliptic functions, such as the Weierstrass ℘-function and the Jacobi elliptic functions.
