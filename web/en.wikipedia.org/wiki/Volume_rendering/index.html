Volume rendering

In scientific visualization and computer graphics, volume rendering is a set of techniques used to display a 2D projection of a 3D discretely sampled data set, typically a 3D scalar field. A typical 3D data set is a group of 2D slice images acquired by a CT, MRI or micro-CT scanner.

Approach

Unlike surface rendering, which extracts polygonal surfaces from the data, direct volume rendering treats the whole volume as a semi-transparent medium. A transfer function maps each data value (voxel) to a colour and an opacity, letting different materials — bone, soft tissue, air — be distinguished visually. Rendering then simulates how light is emitted, absorbed and scattered as it passes through the volume.

Techniques

Common algorithms include ray casting, in which a ray is cast through the volume from each pixel and samples are composited front-to-back or back-to-front; splatting, which projects voxels onto the image plane; texture-based methods using 2D or 3D textures; and maximum intensity projection (MIP), widely used in angiography. Modern implementations run on GPUs and support real-time interactive exploration.

Applications

Volume rendering is central to medical imaging, where it helps surgeons plan operations from CT and MRI data, and is used in geology, computational fluid dynamics, materials science, and for visual effects and volumetric clouds in film and games.
