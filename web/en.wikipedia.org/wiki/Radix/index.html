Radix

In a positional numeral system, the radix (plural radices) or base is the number of unique digits, including zero, used to represent numbers. For the decimal system the radix is ten, because it uses digits 0 through 9. The radix is usually a positive integer greater than 1.

Examples

Common radices include binary (base 2), octal (base 8), decimal (base 10), hexadecimal (base 16) and sexagesimal (base 60, used historically in Babylonian mathematics and still for time and angles). In base b, a string of digits dn...d0 represents the number dn·bn + ... + d0.

Radix point and fractions

The radix point (decimal point in base 10) separates the integer part from fractional digits, which represent negative powers of the base. Some fractions terminate in one base but recur in another; for example 1/3 terminates in base 12 but not in base 10.

Economy

Radix economy measures the cost of representing numbers, balancing digit size against string length; it is minimised near base e, which motivates occasional interest in ternary computing.
