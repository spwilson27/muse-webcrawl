Myhill–Nerode theorem

FieldFormal language theory, automata theory
Named afterJohn Myhill and Anil Nerode
StatementA language is regular iff its syntactic equivalence relation has finitely many classes

In the theory of formal languages, the Myhill–Nerode theorem provides a necessary and sufficient condition for a language to be regular. Named after John Myhill and Anil Nerode, who presented it in 1958, the theorem characterises regular languages in terms of an equivalence relation on strings: a language is regular if and only if this relation has finitely many equivalence classes, and the number of classes equals the number of states in the minimal deterministic finite automaton for the language.

Statement

Given a language L over an alphabet, define an equivalence relation: two strings x and y are equivalent with respect to L if, for every string z, xz belongs to L exactly when yz belongs to L. The theorem states that L is recognised by some deterministic finite automaton if and only if this relation partitions all strings into finitely many classes.

The automaton built from the classes has one state per class, which proves minimality: no automaton for L can have fewer states.

Applications

The theorem is a standard tool for proving that a language is not regular, complementing the pumping lemma: showing that infinitely many strings are pairwise distinguishable with respect to L establishes that L cannot be regular. Unlike the pumping lemma, the Myhill–Nerode condition is exact, giving an if-and-only-if characterisation.

The construction also underlies DFA minimisation, since the equivalence classes correspond directly to the states of the unique minimal automaton for the language, closely related to the syntactic monoid in algebraic language theory.
