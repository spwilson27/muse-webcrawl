Metadata (or metainformation) is "data that provides information about other data", but not the content of the data itself, such as the text of a message or an image itself. The concept dates to classical library cataloguing, in which catalogue cards described books by author, title and subject. In the digital era, metadata is created and used for files, databases, web pages, photographs, audio and video recordings, scientific datasets and many other kinds of information.

Types

Metadata is commonly divided into three types:

  • Descriptive metadata describes a resource for discovery and identification — for example title, author, abstract and keywords. The Dublin Core standard is a widely used descriptive scheme.
  • Structural metadata describes how parts of a resource relate to one another, such as the order of pages in a digitised book or chapters in an audiobook.
  • Administrative metadata supports management of a resource, including rights and preservation information, file type, creation date and how it may be accessed.

Examples

Digital photographs commonly carry EXIF metadata recording the camera model, exposure settings, date, time and often GPS location. MP3 files use ID3 tags to store title, artist and album. Web pages embed metadata in elements such as <meta> tags and structured data (Schema.org) used by search engines. Telephone call records — numbers, times and durations, but not content — are a prominent example in law and public policy debates.

Standards and schemes

Metadata is usually recorded according to standardised schemas so that systems can exchange and interpret it. Examples include MARC for library catalogues, Dublin Core for general resources, MODS and METS for digital libraries, IPTC and XMP for media, ISO 19115 for geographic information, and thousands of discipline-specific schemes. A metadata registry documents the elements and vocabularies of such schemes.

Privacy and controversy

The collection of communications metadata by governments became a major public controversy following the 2013 disclosures by Edward Snowden about mass surveillance programmes. Defenders of such collection argued that metadata is less sensitive than content, while critics and researchers showed that metadata alone can reveal detailed patterns of a person's associations, movements and habits.

Creation and storage

Metadata may be created manually by cataloguers, generated automatically by software at the time a file is created, or produced by automated analysis such as speech recognition and image tagging. It can be stored within the file itself (embedded metadata, as with EXIF) or externally in a database or sidecar file linked to the resource.
