Input–output memory management unit

An input–output memory management unit (IOMMU) is a hardware component that connects DMA-capable input/output devices to main memory and translates the addresses they use, much as a CPU's memory management unit (MMU) translates virtual addresses for programs. By mapping device-visible addresses to physical memory through page tables, an IOMMU lets devices work with simplified or virtualised address spaces.

Functions

An IOMMU provides several benefits. It allows a device with limited addressing capability (for example, a 32-bit DMA engine) to access memory anywhere in the machine by remapping a contiguous device-side region onto scattered physical pages ("scatter–gather" without driver workarounds such as bounce buffers). It improves security and reliability by restricting each device to the memory regions it has been granted, so a malfunctioning or malicious device cannot read or corrupt arbitrary memory. It is also a key enabling technology for device passthrough in virtualisation, letting a virtual machine use a physical device directly and safely: Intel markets the technology as VT-d and AMD as AMD-Vi, while ARM designs include the SMMU.

History

Address-translation hardware for I/O appeared in early systems such as the IBM System/360 Model 67 and in later workstations and servers (for example, the IOMMUs of Sun SPARC systems and the GART of AMD Athlon 64 chipsets) before becoming standard in mainstream x86 platforms in the 2000s.
