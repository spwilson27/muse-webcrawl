Imputation (statistics)

In statistics, imputation is the process of replacing missing data with substituted values. When substituting for a data point, the process is called unit imputation; when substituting for a component of a data point, item imputation.

Methods

Simple methods include mean or median substitution, hot-deck imputation (borrowing values from similar observed cases) and regression imputation, which predicts missing values from other variables. These single-imputation approaches tend to understate uncertainty.

Multiple imputation

Multiple imputation, developed by Donald Rubin from the 1970s, creates several plausible complete datasets by drawing missing values from a predictive distribution, analyses each, and pools the results so that standard errors reflect imputation uncertainty. It is valid under the assumption that data are missing at random given the observed data.

References: Rubin, D. B. Multiple Imputation for Nonresponse in Surveys (1987); Little & Rubin, Statistical Analysis with Missing Data.
