Path graph

In graph theory, a path graph (or linear graph) is a graph whose vertices can be listed in an order such that the edges are exactly the pairs of consecutive vertices in the list. The path graph on n vertices is denoted Pn; it has n vertices and n − 1 edges.

Properties

Path graphs are trees, bipartite graphs, and caterpillar graphs. Their two end vertices have degree 1 (unless n = 1 or 2) and all internal vertices have degree 2. A graph is a path graph if and only if it is a connected graph in which at most two vertices have odd degree in a specific configuration — more simply, it has maximum degree at most 2 and is connected and acyclic.

Occurrence

Paths appear throughout graph theory: a path in a general graph is a trail whose vertices map to a path graph, and Hamiltonian path problems ask for a spanning path graph.
