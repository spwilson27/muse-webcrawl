Network function virtualization

Network functions virtualization (NFV) is a network architecture concept that uses virtualization technologies to implement network node functions, traditionally performed by dedicated proprietary hardware appliances, as software running on generic, high-volume servers, switches and storage. The resulting software instances are called virtual network functions (VNFs) and can be chained, scaled and moved to build communication services flexibly.

History

The concept was introduced in a white paper presented in November 2012 at the "SDN and OpenFlow World Congress" in Darmstadt, authored by a group of major telecommunications service providers that subsequently founded the NFV Industry Specification Group within the European Telecommunications Standards Institute (ETSI). The initiative aimed to reduce operators' dependence on purpose-built middleboxes such as firewalls, load balancers, NAT gateways, deep packet inspection systems, and evolved packet core elements, and to shorten the time needed to launch new services.

Architecture

The ETSI NFV framework comprises three main components:

  • Virtual network functions (VNFs) — software implementations of network functions, running in virtual machines or containers.
  • NFV infrastructure (NFVI) — the hardware and virtualization layer (compute, storage, networking, hypervisor or container platform) on which VNFs run.
  • Management and orchestration (MANO) — the systems that manage the lifecycle of VNFs and end-to-end services, including the NFV orchestrator, VNF managers and virtualized infrastructure managers.

Relationship with SDN and cloud native

NFV is complementary to software-defined networking (SDN): SDN separates the network control and data planes, while NFV virtualizes the functions themselves. More recently, operators have adopted cloud-native network functions (CNFs) packaged as containers and orchestrated with systems such as Kubernetes, particularly in 5G core networks where functions like the access and mobility management function (AMF) and user plane function (UPF) are deployed as software.
