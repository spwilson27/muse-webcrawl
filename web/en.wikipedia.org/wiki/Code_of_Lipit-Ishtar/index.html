The Code of Lipit-Ishtar is a law code promulgated by Lipit-Ishtar (reigned c. 1870–1860 BC), the fifth king of the First Dynasty of Isin in ancient Mesopotamia. Written in Sumerian in cuneiform script, it predates the famous Code of Hammurabi by roughly a century and a half.

Content

The surviving text consists of a prologue and epilogue framing approximately 43 laws (of an original set of about 60). The laws concern inheritance, marriage, slavery, hired labour, ox rental, boat hire, false testimony and property disputes. Penalties are usually monetary fines rather than the physical punishments common in Hammurabi's code.

Discovery

Fragments of the code were excavated at Nippur in the late 19th and early 20th centuries and are held principally at the University of Pennsylvania Museum and the Oriental Institute in Chicago. The text was first published in full by Francis Rudolph Steele in 1948.
