Window system


Type System software; graphical user interface component

A window system (or windowing system) is the software component of a graphical user interface that manages the placement and appearance of windows on a display, handling input from devices such as the keyboard and mouse and coordinating drawing between applications.

Components

A typical window system includes a display server or window manager that creates and positions windows, assigns input focus, and clips or composites each application's drawing surface. Core protocols define how clients request windows, receive events, and render content. In modern compositing systems, each window is rendered to its own buffer and combined by a compositor, enabling transparency and visual effects.

History

Windowing was pioneered at Xerox PARC in the 1970s on the Alto and Star systems, and popularised by the Apple Macintosh (1984) and Microsoft Windows (1985). On Unix-like systems, the X Window System (X11), developed at MIT from 1984, long served as the standard, network-transparent window system; its modern successor is the Wayland protocol. Other examples include Microsoft's Desktop Window Manager, Apple's Quartz Compositor, and Android's SurfaceFlinger.

Concepts

Key concepts include windows, icons, menus, and pointers (the WIMP paradigm); event loops and message queues; window decorations provided by the window manager; and virtual desktops. A window system is distinct from a full desktop environment, which adds panels, file managers, and settings tools on top of it.
