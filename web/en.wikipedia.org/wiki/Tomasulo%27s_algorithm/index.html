Tomasulo's algorithm

Tomasulo's algorithm
InventorRobert Tomasulo (IBM)
First usedIBM System/360 Model 91 (1967)
PurposeDynamic scheduling for out-of-order execution

Tomasulo's algorithm is a computer architecture technique for dynamic scheduling of instructions that allows out-of-order execution and enables more efficient use of multiple execution units. It was developed by Robert Tomasulo at IBM and first implemented in the IBM System/360 Model 91's floating-point unit in 1967.

Concepts

The algorithm distributes control of instruction execution to reservation stations attached to each functional unit. Instructions are issued in order but execute as soon as their operands are available. Operands are tracked by tags rather than register numbers, so register renaming is implicit: when an instruction issues, it either captures the current value of its source registers or records the tag of the instruction that will produce the value. Results are broadcast to all waiting reservation stations over a common data bus (CDB). By removing name dependencies (write-after-read and write-after-write hazards) and stalling only on true data dependencies, the algorithm extracts instruction-level parallelism that a static scoreboard cannot.

Influence

Tomasulo's algorithm underlies the design of virtually all modern high-performance superscalar processors, usually combined with a reorder buffer to support precise exceptions and speculative execution.
