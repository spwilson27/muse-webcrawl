Directed set

In mathematics, a directed set (or a directed preorder or a filtered set) is a nonempty set A together with a reflexive and transitive binary relation ≤ (that is, a preorder), with the additional property that every pair of elements has an upper bound. In other words, for any a and b in A, there exists some c in A with a ≤ c and b ≤ c.

Directed sets are a generalization of nonempty totally ordered sets. That is, all totally ordered sets are directed sets (contrast partially ordered sets, which need not be directed). Join-semilattices (which are partially ordered sets) are directed sets as well, but not conversely. Likewise, lattices are directed sets.

Applications

Directed sets are used in domain theory and in the study of nets, a generalization of sequences that allows indexing by directed sets rather than by the natural numbers. In topology, nets indexed by directed sets are used to characterize closure, continuity, and compactness in spaces that are not first-countable. Directed sets also underlie the construction of the Riemann integral generalized to line integrals and appear in the definition of inductive limits in category theory: a directed set serves as an index category for a diagram whose colimit is taken.

Examples

The set of natural numbers N with the ordinary ordering ≤ is a directed set (as is every totally ordered set). Another important example is the set of neighbourhoods of a point in a topological space, ordered by reverse inclusion: neighbourhoods directed downward by intersection. The set of finite subsets of a given set, ordered by inclusion, is directed, since the union of two finite subsets is a finite upper bound. If x is a real number, the set of open intervals containing x ordered by reverse inclusion is directed.

Directed subsets

A subset D of a partially ordered set P is called a directed subset if it is nonempty and every pair of elements in D has an upper bound in D. Directed subsets are used in domain theory, where directed-complete partial orders (dcpos) and Scott continuity are defined in terms of suprema of directed subsets.
