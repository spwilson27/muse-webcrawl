Write once, run anywhere

Bytecode allows one program to run on many platforms.
Coined bySun Microsystems
Year1995
Related toJava (programming language)

"Write once, run anywhere" (WORA), sometimes rendered "write once, run everywhere", is a slogan coined by Sun Microsystems in 1995 to promote the cross-platform benefits of the Java programming language. Ideally, a Java program compiled into bytecode could run on any device equipped with a Java Virtual Machine (JVM), regardless of the underlying computer architecture or operating system, without needing to be recompiled or adapted for each platform.

Origins

The phrase echoed an older ideal — Sun had earlier used the similar idea of "write once, compile anywhere" for its Network File System products — and was popularised alongside Java's launch in May 1995. Java's designers, led by James Gosling, had designed the language for embedded systems and consumer electronics, where hardware diversity made portability especially valuable, before repositioning it for the World Wide Web and applets.

Reception and criticism

WORA became one of the best-known slogans in software, but developers often found reality fell short: differences between JVM implementations, graphical user interface libraries and platform conventions led to the satirical variant "write once, debug everywhere". Nevertheless, the principle influenced later cross-platform technologies, including the .NET Common Language Runtime, web applications delivered through the browser, and modern cross-platform frameworks, while the JVM itself became a long-lived host for other languages such as Kotlin and Scala.
