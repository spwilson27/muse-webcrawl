Typed lambda calculus

From Wikipedia, the free encyclopedia

A typed lambda calculus is a typed formalism that uses the lambda symbol (λ) to denote anonymous function abstraction. In this context, types are usually objects of a syntactic nature that are assigned to lambda terms; the exact nature of a type depends on the calculus considered. From a certain point of view, typed lambda calculi can be seen as refinements of the untyped lambda calculus, but from another point of view, they can also be considered the more fundamental theory and untyped lambda calculus a special case with only one type.

Typed lambda calculi are foundational programming languages and are the base of typed functional programming languages such as ML and Haskell, as well as typed proof assistants such as Coq and Agda. Through the Curry–Howard correspondence, types correspond to logical propositions and programs to proofs, making typed lambda calculi central to mathematical logic as well as computer science.

Simply typed lambda calculus

The simply typed lambda calculus (λ→), introduced by Alonzo Church in 1940, extends the untyped calculus with base types and function types σ → τ. Every term has a type, and operations are restricted to function application only when the argument's type matches the function's domain. Unlike the untyped calculus, the simply typed calculus is strongly normalising: every well-typed term reduces to a normal form, and consequently it is not Turing complete — a trade-off that makes it suitable as a logic, since self-application and general recursion are excluded unless added explicitly through constructs such as fixed-point combinators.

Extensions

Many systems extend the simply typed calculus:

  • System F (polymorphic lambda calculus), which adds universal quantification over types, permitting generic functions;
  • System Fω and the lambda cube, which systematise combinations of polymorphism, type operators and dependent types;
  • Dependent type systems, such as the calculus of constructions, in which types may depend on values, forming the basis of modern proof assistants;
  • Linear type systems, which track resource usage.

Applications

Typed lambda calculi provide a rigorous model of computation with functions, the semantics of programming languages, and — through the proofs-as-programs interpretation — a foundation for interactive theorem proving.
