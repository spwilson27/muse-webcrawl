Fermat primality test

The Fermat primality test is a probabilistic test to determine whether a number is a probable prime. It is based on Fermat's little theorem, which states that if p is prime and a is not divisible by p, then ap−1 ≡ 1 (mod p).

Algorithm

Given an integer n > 1 to test, choose a random base a in the range 2 ≤ a ≤ n − 2 and compute an−1 mod n. If the result is not 1, then n is definitely composite. If it is 1, n is a "probable prime to base a." Repeating the test with several independent bases reduces the probability of error—but not to zero, because some composite numbers pass for particular bases.

function isProbablePrime(n, k):
    repeat k times:
        pick a at random in [2, n-2]
        if a^(n-1) mod n != 1: return composite
    return probably prime

Fermat liars and Carmichael numbers

A base a for which a composite n satisfies an−1 ≡ 1 (mod n) is called a Fermat liar, and n is a pseudoprime to base a. If n passes for every base a coprime to n, it is a Carmichael number; infinitely many exist (e.g., 561 = 3 × 11 × 17). Carmichael numbers make the Fermat test unreliable in the worst case, though they are rare among random numbers in practice.

Applications

The Fermat test is fast and simple and forms the conceptual basis of more powerful tests. In practice it has largely been superseded by the Miller–Rabin primality test, which detects all Carmichael numbers, and by the deterministic Baillie–PSW test used in computer algebra systems. Fermat-style tests are still used in cryptographic key generation as a quick screen for candidate primes in some implementations.
