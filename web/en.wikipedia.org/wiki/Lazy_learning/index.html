Lazy learning

From Wikipedia, the free encyclopedia

In machine learning, lazy learning (or instance-based learning) is a learning method in which generalisation of the training data is delayed until a query is made to the system, in contrast to eager learning, in which the system builds a general model of the target function during training. Because lazy methods defer processing, they incur little training cost but can be expensive at prediction time and require storing the entire training set.

Examples

  • k-nearest neighbours — classifies a query point by majority vote among the k most similar stored examples under a distance metric.
  • Case-based reasoning — solves new problems by retrieving and adapting stored cases.
  • Locally weighted learning — fits a local model around each query point using nearby examples.
  • Kernel regression — predicts a weighted average of stored target values.

Advantages and disadvantages

Lazy learners adapt naturally to changes in the target function, can model complex, locally varying decision boundaries without a fixed global structure, and update simply by adding examples. Their disadvantages include high query-time computation, sensitivity to irrelevant features and to the choice of distance metric, memory demands, and vulnerability to the curse of dimensionality. Techniques such as kd-trees and approximate nearest-neighbour search are used to speed up queries.
