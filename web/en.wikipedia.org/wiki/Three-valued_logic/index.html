Three-valued logic

In logic, a three-valued logic (also trinary logic, trivalent, ternary or trilean) is one of several many-valued logic systems in which there are three truth values indicating true, false and some indeterminate third value. This contrasts with conventional bivalent logics (such as classical Boolean logic), which provide only two values, true and false.

History

The first systematic three-valued logics were developed independently around 1920 by Jan Łukasiewicz and Emil Post. Łukasiewicz introduced a third value, "possible", partly motivated by Aristotle's problem of future contingents — statements about the future that seem neither true nor false in advance. Stephen Cole Kleene later defined another system, with the third value read as "unknown", suited to partial functions in computability.

Systems

In Kleene logic the truth tables extend the classical ones monotonically: unknown combined with true under OR yields true, and so on. The logic of paradox (LP) uses the same tables but designates both "true" and the third value, allowing some contradictions without triviality. Bochvar's logic treats the third value as "meaningless" and infectious: any compound containing it takes the third value.

Applications

Three-valued reasoning is embedded in SQL, where comparisons with NULL yield UNKNOWN, and in digital hardware description, where signals may be in an unknown or high-impedance state.
