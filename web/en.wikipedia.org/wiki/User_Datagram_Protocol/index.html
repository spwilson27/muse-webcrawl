User Datagram Protocol

From Wikipedia, the free encyclopedia
User Datagram Protocol
LayerTransport
StandardRFC 768 (1980)
Designed byDavid P. Reed
Port range0–65535
[Image: Diagram of a UDP header showing source port, destination port, length and checksum fields]

The User Datagram Protocol (UDP) is one of the core communication protocols of the Internet protocol suite. It provides a simple, connectionless transport service: applications send messages, called datagrams, to other hosts on an IP network without first establishing a connection.

Unlike TCP, UDP guarantees neither delivery, ordering, nor duplicate protection; packets may arrive out of order, be duplicated, or be lost silently, and the sender is not notified. In exchange, UDP adds almost no overhead — its header is just eight bytes, carrying source and destination ports, a length field and an optional checksum (mandatory with IPv6). There is no handshaking, retransmission or congestion control built in.

Applications

UDP suits applications where timeliness matters more than completeness. It carries DNS lookups, the DHCP configuration protocol, streaming audio and video, voice over IP, online games, and the QUIC transport protocol that underlies HTTP/3. When reliability is needed over UDP, it must be implemented by the application itself, as QUIC does.

The protocol was designed by David P. Reed in 1980 and is formally defined in RFC 768.
