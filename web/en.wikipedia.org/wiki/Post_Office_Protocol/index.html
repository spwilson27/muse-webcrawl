Post Office Protocol

POP3 is used by email clients to retrieve messages from a mail server.

The Post Office Protocol (POP) is an application-layer Internet standard protocol used by e-mail clients to retrieve e-mail from a mail server. The current and most widely used version, POP3, is defined in RFC 1939. Together with IMAP, it is one of the two standard protocols for mail retrieval, complementing the Simple Mail Transfer Protocol (SMTP) used to send mail.

Operation

POP3 operates over a TCP connection, conventionally on port 110, or port 995 for connections secured with TLS (POP3S). A session proceeds through three states: authorisation, in which the client supplies a username and password; transaction, in which the client lists, retrieves and marks messages for deletion; and update, in which the server deletes the marked messages and closes the session when the client issues the QUIT command. Typical commands include USER, PASS, STAT, LIST, RETR, DELE, NOOP, RSET and QUIT; server responses begin with +OK or -ERR.

History

The first version of the protocol was published in 1984 as RFC 918 by Joyce Reynolds, with POP2 following in 1985. POP3 first appeared in 1988 in RFC 1081, written by Marshall Rose, and was revised several times before the current specification in 1996. Extensions, described in RFC 2449, allow servers to advertise optional capabilities such as pipelining and improved authentication mechanisms.

Comparison with IMAP

POP3 was designed for an era in which users accessed mail from a single computer: messages are downloaded to the client and, historically, deleted from the server. IMAP, by contrast, keeps messages on the server and synchronises folders, flags and state across multiple devices. POP3 remains in use for simple retrieval, archiving and offline access, but IMAP and webmail have largely displaced it for multi-device use. Because base POP3 transmits credentials in clear text, the APOP command and TLS are used to protect authentication.
