Cantor's theorem

In mathematical set theory, Cantor's theorem states that for any set A, the set of all subsets of A — its power set, denoted 𝒫(A) — has a strictly greater cardinality than A itself. The theorem was proved by Georg Cantor and published in 1891 as part of the paper in which he introduced his celebrated diagonal argument.

Proof

Suppose, for contradiction, that there were a bijection (in fact, merely a surjection) f from A onto 𝒫(A). Consider the diagonal set B = { x ∈ A : x ∉ f(x) }. Since f is assumed surjective, B = f(b) for some b ∈ A. But then b ∈ B if and only if b ∉ f(b) = B, a contradiction. Hence no surjection from A onto its power set exists, while the inclusion map shows 𝒫(A) is at least as large, so it is strictly larger.

Consequences

For a finite set with n elements the power set has 2n elements, so the theorem generalises the obvious fact that 2n > n. Applied repeatedly, it yields an endless hierarchy of ever-larger infinities. Applied to the natural numbers, it shows that the set of all sets of natural numbers is uncountable; combined with Cantor's diagonal argument for the real numbers, it founded the modern theory of transfinite cardinal numbers. The theorem is also the engine behind Russell's paradox and related results in logic, where self-referential diagonal constructions recur.
