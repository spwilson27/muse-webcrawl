Probability integral transform

Applying a random variable's own CDF to it produces a uniform distribution on [0, 1].

In probability theory, the probability integral transform (also known as the universality of the uniform distribution) relates the cumulative distribution function of a continuous random variable to the uniform distribution. Specifically, if X is a continuous random variable with cumulative distribution function FX, then the random variable Y = FX(X) has a standard uniform distribution on the interval [0, 1].

Proof sketch

For 0 ≤ y ≤ 1, P(Y ≤ y) = P(FX(X) ≤ y) = P(X ≤ FX−1(y)) = FX(FX−1(y)) = y, which is exactly the cumulative distribution function of a uniform random variable on [0, 1].

Applications

The converse of the transform — inverse transform sampling — is a standard method for generating random samples from arbitrary distributions: drawing U uniformly from [0, 1] and returning F−1(U) yields a sample from the distribution with CDF F. The transform is also used in goodness-of-fit testing, such as the Kolmogorov–Smirnov test, and in the construction of copulas, where the transformed variables (the copula's marginals) are uniform by construction.

For discrete or mixed random variables the result does not hold directly, but generalized (randomized) versions of the transform exist that restore uniformity by distributing probability mass within jumps of the CDF.
