Dirichlet function

In mathematics, the Dirichlet function is the indicator function of the set of rational numbers, 1ℚ, defined as 1ℚ(x) = 1 if x is rational and 1ℚ(x) = 0 if x is irrational. It is named after the mathematician Peter Gustav Lejeune Dirichlet and is a classic example of a pathological function.

Properties

The Dirichlet function is continuous nowhere: every point is a point of discontinuity, because any interval around any real number contains both rational and irrational numbers. It is periodic with any rational number as a period. It is not Riemann integrable on any interval, since its upper and lower integrals differ, but it is Lebesgue integrable, with integral zero over any interval. A modified version, Thomae's function, is continuous at the irrationals and Riemann integrable.

Significance

The function appeared in the 19th-century debates over the proper definition of a function and motivated the development of rigorous analysis, including the Riemann and Lebesgue theories of integration.
