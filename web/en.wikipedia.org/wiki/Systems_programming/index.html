Systems programming

Systems programming, or system programming, is the activity of programming computer system software. It is distinguished from application programming by its focus on the underlying platform: systems programmers write operating systems, compilers, assemblers, linkers, loaders, device drivers, and utility software that other programs depend upon.

Characteristics

Systems software typically requires detailed knowledge of computer hardware, efficient use of resources, and operation in resource-constrained or performance-critical environments. Historically, systems programming was done in assembly language; the development of languages such as C at Bell Labs in the 1970s made it practical to write portable systems software, exemplified by the Unix operating system. More recent systems languages include C++, Rust, and Go.

Examples

Examples of system software include the Linux kernel, the GNU Compiler Collection (GCC), database management systems' storage engines, hypervisors, and network protocol stacks.
