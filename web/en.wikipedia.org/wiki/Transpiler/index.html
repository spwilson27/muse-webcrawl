Transpiler

A transpiler, or source-to-source compiler, is a type of translator that takes the source code of a program written in a programming language as its input and produces an equivalent source code in the same or a different programming language. A source-to-source translator converts between programming languages that operate at approximately the same level of abstraction, while a traditional compiler translates from a higher-level programming language to a lower-level programming language.

History

One of the earliest examples was the ratfor preprocessor, and the original C++ implementation, Cfront (1983), which translated C++ into C. The Eiffel language also compiles via C. In the web era, CoffeeScript (2009) popularized transpilation to JavaScript, followed by TypeScript (2012), which adds static typing, and Babel, which converts newer ECMAScript (ES6+) code into widely supported ES5 code — a pattern sometimes called "transpiling down".

Examples

  • Babel — JavaScript to JavaScript (newer syntax to older syntax).
  • TypeScript compiler (tsc) — TypeScript to JavaScript.
  • CoffeeScript compiler — CoffeeScript to JavaScript.
  • Haxe — Haxe to many target languages.
  • Emscripten — C/C++ (via LLVM) to JavaScript/WebAssembly (borderline between compiler and transpiler).
  • 2to3 — Python 2 to Python 3 source converter.

Purpose

Transpilers are used to bring new language features to established platforms without new runtime support, to port legacy code bases to modern languages, and to target platforms (such as browsers) that support only one language.
