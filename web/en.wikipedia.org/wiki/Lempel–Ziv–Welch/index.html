Lempel–Ziv–Welch (LZW) is a universal lossless data compression algorithm created by Abraham Lempel, Jacob Ziv and Terry Welch. It was published by Welch in 1984 as an improved implementation of the LZ78 algorithm published by Lempel and Ziv in 1978.

Algorithm

LZW builds a dictionary (string table) of sequences encountered in the input. The encoder starts with a table containing all single characters, then repeatedly finds the longest sequence already in the table that matches the current input, outputs its code, and adds that sequence plus the next character as a new table entry. Codes are typically emitted at increasing widths, commonly up to 12 bits, allowing a table of 4,096 entries. The decoder reconstructs the identical table on the fly from the code stream, so no dictionary needs to be stored or transmitted.

Applications and patents

LZW became extremely widely used: it is the compression behind the GIF image format, an option in TIFF and PDF, and the algorithm of the Unix compress utility and the V.42bis modem standard. Unisys held a patent on LZW (US 4,558,302); the controversy over enforcing it against GIF software in the 1990s spurred the creation of the patent-free PNG format. The LZW patents expired in 2003–2004.
