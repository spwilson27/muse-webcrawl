Antenna array

Antenna array
Type: Multi-element antenna system
Key property: Directional radiation pattern
Applications: Radar, radio astronomy, 5G

An antenna array is a set of multiple connected antennas working together as a single antenna to transmit or receive radio waves. The individual elements' signals combine so that the radiation pattern reinforces in desired directions and cancels in others, giving higher gain and directivity than a single element of similar size.

Principles

The overall pattern of an array is the product of the individual element pattern and the array factor, which depends on the elements' positions, spacing, and the relative amplitudes and phases of their feeds. Elements are often spaced about half a wavelength apart to avoid grating lobes — unwanted secondary main beams.

Types

Common geometries include linear, planar, and circular arrays. In a phased array, electronic phase shifters steer the beam without physically moving the antenna, enabling rapid scanning in radar systems. Other types include the Yagi–Uda array, log-periodic arrays, and large radio-astronomy installations such as aperture-synthesis arrays, which combine signals computationally to emulate a much larger dish.

Applications

Antenna arrays are used in radar, satellite communications, cellular base stations (including massive MIMO in 5G networks), radio telescopes, and navigation systems. Multiple-input multiple-output (MIMO) systems exploit arrays at both ends of a link to increase data throughput.
