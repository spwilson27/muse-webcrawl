Multiprocessor system on a chip

A multiprocessor system on a chip (MPSoC) is a system on a chip (SoC) that contains multiple processors, typically several programmable processing elements, interconnected memories, and specialized accelerators on a single integrated circuit. MPSoCs are widely used in embedded systems, mobile devices, automotive electronics, and high-performance computing.

Architecture

An MPSoC integrates multiple processor cores — which may be homogeneous (identical cores) or heterogeneous (different core types, such as general-purpose CPUs combined with digital signal processors or graphics processing units) — together with memory hierarchies, direct memory access controllers, and communication infrastructure such as buses or networks on chip (NoC).

Key design challenges include managing communication between cores, maintaining cache coherence, partitioning tasks among processors, and meeting real-time, power, and thermal constraints.

Applications

  • Smartphones and tablets, where application processors combine CPU and GPU cores.
  • Automotive driver-assistance and infotainment systems.
  • Networking equipment and telecommunications baseband processing.
  • Multimedia devices such as set-top boxes and game consoles.

Design methodology

Because of their complexity, MPSoCs are commonly designed using platform-based design and electronic system-level tools, with hardware/software co-design, high-level synthesis, and simulation used to explore the architecture space before fabrication.
