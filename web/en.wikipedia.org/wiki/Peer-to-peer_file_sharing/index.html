Peer-to-peer file sharing

Peer-to-peer file sharing is the distribution and sharing of digital media using peer-to-peer (P2P) networking technology, in which files are stored on and served from the computers of individual users rather than a central server. Each participant both downloads and uploads pieces of files to others.

History

P2P file sharing entered mass awareness with Napster in 1999, which used a central index of music files held by users. After Napster was shut down by litigation, decentralized networks such as Gnutella, eDonkey, Kazaa, and especially BitTorrent became dominant. BitTorrent's swarming design — splitting files into pieces verified by hashes from a .torrent file or magnet link — made large-file distribution efficient and remains widely used for legitimate distribution as well, including software updates and Linux images.

Legal issues

Because the technology makes unauthorized copying of music, films, and software easy, file sharing has been the subject of extensive copyright litigation and legislation, including cases against services and individual users. Courts in many jurisdictions have distinguished between the technology itself and infringing uses of it.
