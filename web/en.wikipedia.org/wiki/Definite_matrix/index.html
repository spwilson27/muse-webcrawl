Definite matrix

In mathematics, a symmetric matrix M (or, more generally, a Hermitian matrix) is called a definite matrix according to the sign of the quadratic form xTMx for nonzero real (or complex) vectors x.

Definitions

  • Positive-definite: xTMx > 0 for all nonzero x.
  • Positive semi-definite: xTMx ≥ 0 for all x.
  • Negative-definite: xTMx < 0 for all nonzero x.
  • Negative semi-definite: xTMx ≤ 0 for all x.
  • Indefinite: the quadratic form takes both positive and negative values.

Characterisations

A symmetric matrix is positive-definite if and only if all its eigenvalues are positive; positive semi-definite if and only if all eigenvalues are nonnegative, and so on. Sylvester's criterion states that a Hermitian matrix is positive-definite exactly when all its leading principal minors are positive. A positive-definite matrix is always invertible and admits a Cholesky decomposition M = LL*.

Applications

Positive-definite matrices arise as covariance matrices in statistics, as Hessians at local minima in optimisation (the second derivative test), as mass and stiffness matrices in mechanics, and in the definition of inner products and Mahalanobis distance. Covariance matrices are always positive semi-definite.
