Mach-O

Mach-O, short for Mach object file format, is a file format for executables, object code, shared libraries, dynamically loaded code and core dumps. It was developed by the Mach Project at Carnegie Mellon University for the Mach kernel and was later adopted by NeXTSTEP and by Apple for macOS and iOS, where it replaced the a.out and PEF formats.

Structure

A Mach-O file begins with a header containing a magic number, the target CPU type and subtype, the file type and a count of load commands. The load commands describe the layout of the file's segments, the dynamic linker information, symbol tables and other metadata. Segments, conventionally named with a __ prefix such as __TEXT and __DATA, are divided into sections.

Multi-architecture support

Mach-O supports "fat" binaries, in which a wrapper header points to several Mach-O files for different processor architectures bundled into a single file. This mechanism allowed Apple to ship universal binaries during its transitions from PowerPC to Intel and from Intel to Apple silicon.

Use

Mach-O is the native executable format for macOS, iOS, iPadOS, tvOS and watchOS. Tools such as otool and nm inspect Mach-O files, and the format is produced by the LLVM/Clang toolchain.
