Rijndael S-box

The Rijndael S-box is a substitution box (lookup table) used in the Rijndael cipher, which was selected as the Advanced Encryption Standard (AES). It provides the cipher's only nonlinear operation: each byte of the state is replaced by another byte according to a fixed, carefully designed table.

Construction

The S-box is built from algebra in the finite field GF(28) with the irreducible polynomial x8 + x4 + x3 + x + 1. Each byte is replaced by its multiplicative inverse in the field (with zero mapped to itself), and the result is passed through a fixed affine transformation over GF(2). This combination yields strong resistance to linear and differential cryptanalysis while remaining easy to compute in hardware and software.

Inverse S-box

Decryption uses the inverse S-box, which applies the inverse affine transform and then the multiplicative inverse, restoring the original byte.
