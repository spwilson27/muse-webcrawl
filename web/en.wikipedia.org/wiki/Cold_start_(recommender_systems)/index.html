Cold start (recommender systems)

Cold start is a potential problem in recommender systems, concerning users, items, or entire systems about which the system has gathered insufficient information to make reliable recommendations. Because collaborative filtering depends on historical ratings and interactions, it struggles precisely where data are absent — a situation every new user and every newly launched service faces.

Types of cold start

  • New user problem — a user has just registered and has rated nothing, so the system cannot personalise recommendations. Common mitigations include asking the user to rate a starter set of items, using demographic or registration data, and defaulting to popular or critically acclaimed items.
  • New item problem — a new item (film, product, article) has no interactions, so it is rarely recommended, creating a rich-get-richer bias toward established items. Content-based features (genre, text, attributes) let the system reason about unseen items.
  • New system problem — a service launched from scratch has neither users nor ratings, and must bootstrap with content-based methods, editorial curation, or imported data.

Approaches

Hybrid recommenders combine collaborative and content-based signals so that one can cover the other's cold spots. Active learning strategies deliberately elicit informative ratings from new users. Bandit algorithms, such as multi-armed bandits with exploration–exploitation trade-offs, treat the cold start as exploration: showing a new user diverse items to learn quickly what they like. Social-network information, cross-domain transfer learning, and meta-learning (learning to initialise models that adapt from few examples) are active research areas.

Related difficulties

Cold start is related to the sparsity problem (most user–item pairs are unobserved), the long-tail problem (most items attract few interactions), and concept drift, where an existing user's tastes change faster than the model updates. In practice, systems usually pass through a cold-start phase in which recommendations are generic, then sharpen as data accumulate.
