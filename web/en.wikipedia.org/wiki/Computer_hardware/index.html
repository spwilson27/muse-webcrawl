Computer hardware

Computer hardware includes the physical parts of a computer, such as the case, central processing unit (CPU), random access memory (RAM), monitor, mouse, keyboard, data storage, graphics card, sound card, speakers, and motherboard.

Components

Core components of a personal computer include the motherboard, CPU, memory, storage devices, power supply, and expansion cards, together with input peripherals (keyboard, mouse, scanner) and output peripherals (display, printer, speakers).

History

Hardware evolved from mechanical and electromechanical machines through vacuum-tube and transistor systems to integrated circuits and microprocessors, dramatically reducing size and cost over successive generations.

Architecture

Most computers follow the von Neumann architecture, in which program instructions and data share the same memory, communicating over buses under the control of the CPU.
