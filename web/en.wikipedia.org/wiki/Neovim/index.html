Neovim is a free and open-source text editor forked from Vim that strives to improve the extensibility and maintainability of Vim. Neovim takes the good parts of Vim and adds features such as an embedded Lua interpreter, support for the Language Server Protocol (LSP), asynchronous I/O via libuv, and a remote API allowing the editor to be embedded in other programs and user interfaces.

History

The project began in 2014 when developer Thiago de Arruda Padilha started refactoring Vim's codebase after contributing a patch implementing multi-threading that was not accepted upstream. A crowdfunding campaign on Bountysource raised over $34,000, enabling full-time work. The first release, version 0.1, appeared in November 2015. Subsequent releases added a built-in terminal emulator, native LSP support, Tree-sitter integration for syntax-aware highlighting, and an increasingly complete Lua API that allows the whole editor to be configured in Lua instead of Vim script.

Features

Neovim preserves Vim's modal editing model and compatibility with most Vim script plugins, while providing a stable msgpack-RPC API for external processes. Graphical front-ends can render through the API without a terminal. The editor ships with sensible defaults differing from Vim, an XDG-compliant configuration directory, and a built-in package manager convention for plugins. Its community maintains a large ecosystem of Lua plugins.
