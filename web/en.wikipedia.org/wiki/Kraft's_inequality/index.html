Kraft's inequality

In coding theory, Kraft's inequality gives a necessary and sufficient condition for the existence of a prefix code with a given set of codeword lengths. It is named after Leon G. Kraft, who stated it in his 1949 master's thesis at MIT.

Statement

If a prefix-free code over an alphabet of size r has codeword lengths l1, l2, …, ln, then

Σi=1..n r−li ≤ 1

Conversely, if positive integers l1, …, ln satisfy this inequality, then there exists a prefix code over an r-letter alphabet with exactly those codeword lengths.

Proof idea

Represent the code as a complete r-ary tree of depth max(li). A codeword of length li at depth li excludes rL−li leaves at full depth L from use by any other codeword. Counting excluded leaves against the total rL leaves and dividing through by rL gives the inequality. For the converse, one constructs the code greedily, assigning the shortest codewords first; the inequality guarantees a free node is always available.

Applications

Kraft's inequality underlies the theory of lossless data compression: it bounds the achievable codeword lengths in prefix codes such as Huffman codes and Shannon–Fano codes, and it is a stepping stone to Shannon's source coding theorem. McMillan's inequality extends the same bound to all uniquely decodable codes, showing that restricting attention to prefix codes costs nothing in achievable lengths.
