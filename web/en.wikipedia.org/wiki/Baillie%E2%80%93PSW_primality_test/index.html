Baillie–PSW primality test

The Baillie–PSW primality test is a probabilistic primality testing algorithm that determines whether a number is composite or is a probable prime. It combines a base-2 (or some specified base) strong Miller–Rabin test (Fermat test) with a strong Lucas probable prime test.

How it works

To test whether n is prime, the algorithm first performs trial division by small primes and a perfect square check. It then applies a Miller–Rabin test (typically to base 2), followed by a Lucas test with parameters selected by the Selfridge method (Method A). A number that passes both tests is very likely prime.

Reliability

No composite number is known that passes the combined test, and extensive computer searches have found no counterexample below very large bounds (at least up to 2^64). This makes the test practically deterministic for 64-bit integers and it is used in computer algebra systems such as Mathematica and Maple.

The test is named after Robert Baillie, Carl Pomerance, John Selfridge, and Samuel Wagstaff; Pomerance, Selfridge, and Wagstaff offered a cash prize in 1980 for a counterexample, which remains unclaimed.
