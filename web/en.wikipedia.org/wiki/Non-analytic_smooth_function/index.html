Non-analytic smooth function

In mathematics, smooth functions (also called infinitely differentiable functions) and analytic functions are two very important types of functions. One can easily prove that any analytic function of a real argument is smooth. The converse is not true, as demonstrated with this counterexample.

One of the most important applications of smooth functions with compact support is the construction of so-called mollifiers, which are important in theories of generalised functions, like e.g. Laurent Schwartz's distribution theory. The existence of smooth but non-analytic functions represents the main difference between differential geometry and analytic geometry. In terms of sheaf theory, this difference can be stated as follows: the sheaf of differentiable functions on a differentiable manifold is fine, in contrast with the analytic case.

The functions below are generally used to build up partitions of unity on manifolds.

A smooth function which is nowhere real analytic

A more pathological example, of an infinitely differentiable function which is not analytic at any point can be constructed by means of a Fourier series. Let A ⊂ R denote the set of all real numbers, and define the function:

f(x) = Σn∈N e−√n cos(nx²) ... (series construction)

The example function

Consider the function defined on the real line by

f(x) = e−1/x if x > 0, and f(x) = 0 if x ≤ 0.

This function is infinitely differentiable at every point of the real line, including x = 0, where all derivatives vanish. However, its Taylor series around 0 is identically zero, which does not equal f(x) for x > 0; hence f is not analytic at 0.

Smooth transition functions

By rescaling and combining such functions one obtains smooth transition functions that rise from 0 to 1 across an interval, and from these, bump functions with compact support — the key ingredients of partitions of unity and mollifiers.
