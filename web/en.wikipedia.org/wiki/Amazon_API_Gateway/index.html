Amazon API Gateway is a fully managed service from Amazon Web Services (AWS) that enables developers to create, publish, maintain, monitor and secure application programming interfaces (APIs) at scale. It acts as a front door for applications, routing client requests to back-end services such as AWS Lambda functions, EC2 instances, or publicly addressable HTTP endpoints, and is a core building block of serverless architectures on AWS.


API Gateway forwarding client requests to back-end services

Features

  • API types: REST APIs (with full resource/method modelling), lower-cost HTTP APIs, and WebSocket APIs for two-way real-time communication.
  • Traffic management: throttling, quotas and usage plans with per-client API keys, protecting back ends from overload.
  • Security: authorization via AWS IAM, Amazon Cognito user pools, Lambda authorizers and JWT authorizers; TLS and mutual TLS; AWS WAF integration.
  • Transformations and validation: request/response mapping templates (Velocity Template Language), model-based request validation, and response caching.
  • Operations: staged deployments (e.g. dev/test/prod), canary releases, CloudWatch metrics and logging, and API import/export using OpenAPI definitions.

History and pricing

API Gateway was announced at AWS re:Invent and launched in July 2015, alongside the rapid growth of Lambda-based serverless applications. WebSocket support was added in late 2018, and the streamlined, cheaper HTTP APIs reached general availability in 2020. Pricing for REST APIs is pay-per-use — a per-million-requests charge plus data transfer — with HTTP APIs priced lower; there are no upfront commitments, which suits intermittent serverless workloads.

Use with serverless architectures

In the canonical AWS serverless pattern, API Gateway receives an HTTP request, invokes a Lambda function, and returns its response, allowing an entire web API to run without provisioned servers. API Gateway also fronts microservices behind Application Load Balancers and integrates with AWS's VPC Link for private back ends.
