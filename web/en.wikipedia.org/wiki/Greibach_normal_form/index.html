Greibach normal form

In formal language theory, a context-free grammar is in Greibach normal form (GNF) if every production rule has the form A → a α, where A is a nonterminal, a is a terminal symbol, and α is a (possibly empty) string of nonterminals. Equivalently, each derivation step produces exactly one terminal symbol at the leftmost position of the sentential form.

Properties

The normal form is named after Sheila Greibach, who proved in 1965 that every context-free grammar not generating the empty string can be transformed into an equivalent grammar in Greibach normal form. Because each step of a derivation emits one terminal, a string of length n has a derivation of exactly n steps, which makes the form useful in proofs about pushdown automata: a grammar in GNF corresponds directly to a pushdown automaton that reads one input symbol at each move and never performs an ε-transition. The conversion can cause a large blow-up in grammar size — the transformed grammar may be exponentially larger, and in the worst case doubly exponential — which limits its practical use in parsing, where Chomsky normal form is more common.
