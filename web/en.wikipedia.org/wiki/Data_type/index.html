Data type

In computer science, a data type (or simply type) is a collection of data values characterised by a set of allowed operations. Types classify values such as integers, booleans, and strings, and constrain how programs manipulate them.


Field: Computer science, type theory

Classification

Primitive types include integers, floating-point numbers, characters, and booleans. Composite types — arrays, records/structs, tuples, and strings — combine simpler types. Abstract data types define behaviour without specifying implementation. Most languages also provide pointers/references and function types.

Type systems

Type systems may be static or dynamic, strong or weak, and nominal or structural. Type checking prevents errors such as adding a number to a string, while type inference (as in ML and Haskell) deduces types automatically. Type theory formalises these ideas and connects to logic via the Curry–Howard correspondence.
