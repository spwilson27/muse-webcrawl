vi (pronounced "vee-eye") is a screen-oriented text editor originally created for the Unix operating system by Bill Joy in 1976 at the University of California, Berkeley. It was the visual mode of the line editor ex, developed for BSD Unix when terminal screens made full-screen editing practical. vi became part of standard Unix, is specified by POSIX, and is guaranteed to be present on virtually every Unix-like system — one reason it remains a core skill for system administrators nearly five decades later.

Modal editing

vi's defining feature is modal editing. In normal mode, keystrokes are commands: single letters move the cursor (h, j, k, l), delete, copy ("yank"), paste, search and repeat edits, and can be combined with counts and text objects into a small compositional language — for example d2w deletes two words. In insert mode, reached by commands such as i or a, keys type text normally; Escape returns to normal mode. Colon commands in command-line mode handle saving (:w), quitting (:q), substitution and other ex operations. The design minimized keystrokes and network traffic on slow terminals, and devotees prize its efficiency; newcomers, famously, often struggle even to exit the program.

Legacy

Numerous clones and extensions appeared, most prominently Vim ("Vi IMproved," 1991), which added multiple windows, syntax highlighting, an extension language and a vast ecosystem, and more recently Neovim. The contrast between vi's modal philosophy and the modeless design of Emacs fuelled the playful "editor war" of Unix culture. Vim keybindings are now emulated in countless editors, IDEs, shells and web applications.
