Endianness

Endianness is the order in which the bytes of a multi-byte data element — such as a word or integer — are stored in computer memory or transmitted over a medium. In big-endian order the most significant byte is stored first (at the lowest address); in little-endian order the least significant byte is stored first.

Terminology

The whimsical terms derive from Jonathan Swift's Gulliver's Travels (1726), in which the Lilliputians argue over whether to crack a boiled egg at the big end or the little end. Danny Cohen's 1980 paper "On Holy Wars and a Plea for Peace" carried the terms into computing.

Examples

For the 32-bit value 0x0A0B0C0D stored at address 100:

Order100101102103
Big-endian0A0B0C0D
Little-endian0D0C0B0A

Architectures

Intel x86 and most ARM implementations are little-endian; Motorola 68000 and many network protocols are big-endian. Internet protocols specify big-endian as the standard "network byte order". Some architectures, including ARM, PowerPC and RISC-V implementations, are bi-endian and can operate in either order. Endianness also applies, less commonly, to bit order within bytes and to the ordering of digits in written numerals.

File formats and data exchange

File formats specify an endianness explicitly — for example, TIFF supports both, flagged in its header — while formats such as PNG and JPEG are big-endian. Programming languages provide byte-swapping functions (such as htons/ntohs in C networking APIs) to convert between host and network order.
