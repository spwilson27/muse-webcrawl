Copy constructor

In the C++ programming language, a copy constructor is a special constructor for creating a new object as a copy of an existing object. Copy constructors are the standard way of copying objects in C++, as opposed to assignment, and are used in various contexts, including passing objects by value and returning them from functions.

class Example {
public:
    Example(const Example& other); // copy constructor
};

The first argument of such a constructor is a reference to an object of the same type as the class (typically a const reference), and the constructor may take additional arguments if they have default values. If a copy constructor is not defined by the programmer, the compiler generates an implicitly declared copy constructor that performs memberwise copying — a shallow copy. Classes that manage resources such as dynamically allocated memory often need a user-defined copy constructor to perform a deep copy, alongside a destructor and copy assignment operator, a principle known as the rule of three.

Uses

Copy constructors are invoked when an object is initialized from another of the same type, when an object is passed by value to a function, and when an object is returned by value. Copy elision optimizations, standardized in C++17 for some cases, can eliminate unnecessary copies. Since C++11, move constructors provide an alternative for transferring resources from temporary objects.

Bitwise copy

Some objects can be safely copied bit-for-bit; types satisfying the trivially copyable requirements can be copied with functions like memcpy. Types with pointers to owned resources generally cannot.
