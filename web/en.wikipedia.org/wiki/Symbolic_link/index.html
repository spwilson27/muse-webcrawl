Symbolic link

A symbolic link (also symlink or soft link) is a term for any file that contains a reference to another file or directory in the form of an absolute or relative path and that affects pathname resolution. Symbolic links were already present by 1978 in minicomputer operating systems from DEC and Data General's RDOS. Today they are supported by the POSIX operating-system standard, most Unix and Unix-like operating systems such as FreeBSD and Linux, and Microsoft Windows (with some limitations).

Overview

A symbolic link contains a text string that is automatically interpreted and followed by the operating system as a path to another file or directory. This other file or directory is called the "target". The symbolic link is a second file that exists independently of its target. If a symbolic link is deleted, its target remains unaffected. If a symbolic link points to a target, and sometime later that target is moved, renamed or deleted, the symbolic link is not automatically updated or deleted, but becomes a "dangling" link that points to a nonexistent target.

Symbolic links are different from hard links, which directly reference the underlying data of a file. Hard links may not normally refer to directories and cannot refer to files on different filesystems or volumes. Symbolic links can be created with the ln -s command in Unix-like systems, and with mklink on Windows.

POSIX and Unix

POSIX-compliant operating systems provide the symlink() system call to create symbolic links. The readlink() call returns the contents of the link itself rather than following it. Shell commands such as ls -l display the target of a link after an arrow, for example link_name -> target_path.

Microsoft Windows

Windows Vista and later versions support true symbolic links through the CreateSymbolicLink API and the mklink command, for both files and directories. Earlier versions of Windows used "shortcuts", which are plain files interpreted only by the shell, and junction points, which work only for directories on local volumes.
