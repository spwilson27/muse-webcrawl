Aimbot

An aimbot (sometimes called auto-aim) is a type of cheat software used in first-person shooter video games that automatically aims the player's weapon at opponents, giving an unfair advantage. Aimbots typically work by reading game memory to obtain enemy positions, hooking into the game's rendering or input, or analyzing screen images, and then moving the crosshair onto a target — often the head — faster and more precisely than a human player could.

Types

Internal aimbots run inside the game process and have direct access to entity data. External aimbots run as separate processes that read memory or use computer-vision techniques on captured frames; newer variants use machine-learning object detection, which can operate even on separate hardware and is harder to detect. Related cheats include triggerbots, which fire automatically when the crosshair passes over an enemy, and wallhacks, which reveal opponents through walls.

Countermeasures

Game developers combat aimbots with anti-cheat systems such as Valve Anti-Cheat (VAC), Easy Anti-Cheat, BattlEye, and Riot Vanguard, using signature scanning, behavioral analysis, and machine learning. Statistical detection looks for superhuman accuracy, unnatural snap angles, and reaction times below human limits. Use of aimbots commonly results in account bans, and tournaments have disqualified and banned professional players caught using them.

Legitimate analogues

By contrast, aim assist built into many console shooters is a sanctioned feature that subtly slows or nudges the crosshair near targets to compensate for the imprecision of gamepad sticks.
