Rectifiable set

In mathematics, a rectifiable set is a set in a Euclidean space that is, in a measure-theoretic sense, well approximated by smooth or Lipschitz surfaces. Roughly speaking, an m-rectifiable set can be covered, up to a set of m-dimensional Hausdorff measure zero, by countably many Lipschitz images of bounded subsets of ℝm. A set that is m-rectifiable and has finite m-dimensional Hausdorff measure is said to have finite measure, and an m-rectifiable set further requires that almost every point have an approximate tangent space.

Rectifiable curves

The one-dimensional case generalises the classical notion of a rectifiable curve: a curve of finite length. A connected set in ℝn with finite one-dimensional Hausdorff measure is a rectifiable curve if and only if it can be traversed by a Lipschitz path.

Properties

Rectifiable sets are central in geometric measure theory. They possess approximate tangent planes almost everywhere, which permits a theory of integration of differential forms and the application of tools such as the area and coarea formulas. The concept was developed by Herbert Federer, building on work by Besicovitch on one-dimensional sets.
