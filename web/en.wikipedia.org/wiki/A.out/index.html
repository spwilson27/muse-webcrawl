a.out is a file format used in older versions of Unix-like computer operating systems for executables, object code, and, in later systems, shared libraries. The name derives from "assembler output," the default filename given by the assembler and linker when no output name was specified—a convention that survives today in the default a.out produced by C compilers such as GCC when the -o option is omitted.

History and variants

The format appeared in the earliest editions of Unix on the PDP-7 and PDP-11 and evolved through several variants, including OMAGIC, NMAGIC, ZMAGIC (demand-paged), and QMAGIC, distinguished by magic numbers in the file header. An a.out file contains a header, text (code) and data segments, relocation information, and a symbol table with optional string table and debugging information in stab format.

Replacement and legacy

Because a.out handled shared libraries awkwardly, Unix systems migrated first to COFF and then, with System V Release 4, to ELF, which Linux adopted in the mid-1990s. Linux kernels dropped support for the a.out format by version 6.0, but the term lives on in compiler defaults and in GCC's historic website domain naming conventions.
