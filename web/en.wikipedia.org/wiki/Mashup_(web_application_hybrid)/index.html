Mashup (web application hybrid)

A mashup in web development is a web page or web application that uses content from more than one source to create a single new service displayed in a single graphical interface. Mashups were a hallmark of the Web 2.0 era, enabled by public APIs, RSS/Atom feeds, and AJAX techniques.

Types and examples

Mapping mashups plotted data such as real-estate listings or crime reports onto services like Google Maps — an early famous example being HousingMaps, which combined Craigslist listings with Google Maps. Other genres included photo and video mashups (drawing from Flickr or YouTube), search and shopping aggregators, and news mashups assembled from many feeds. Consumer tools such as Yahoo! Pipes and Microsoft Popfly let non-programmers build mashups visually.

Architecture

A mashup typically combines data providers, which expose content through APIs or feeds; a mashup server or client-side script that aggregates and transforms the data; and a presentation layer, often built with JavaScript. Enterprise variants, sometimes called enterprise mashups, combine internal and external data behind the firewall for dashboards and situational applications.

Decline

As platforms restricted APIs, mobile apps displaced open web composition, and social networks consolidated distribution in the 2010s, the classic mashup culture waned, though its patterns survive in modern API-driven integration and low-code tools.
