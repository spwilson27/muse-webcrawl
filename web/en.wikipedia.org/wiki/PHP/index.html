PHP

From Wikipedia, the free encyclopedia
PHP
Designed byRasmus Lerdorf (1995)
ParadigmMulti-paradigm, scripting
TypingDynamic, weak
Used byWordPress, Facebook (originally), Wikipedia
[Image: The PHP logo: the letters php in white inside a blue-violet oval]

PHP is a general-purpose scripting language geared toward web development. It was originally created by Danish-Canadian programmer Rasmus Lerdorf in 1993 and released in 1995 as 'Personal Home Page' tools; the reference implementation is now produced by The PHP Group, and the name is a recursive backronym: 'PHP: Hypertext Preprocessor'.

PHP code is executed on the server by an interpreter, typically embedded in the Apache HTTP Server or fronted by Nginx, and generates HTML (or other output) sent to the client's browser. Its low barrier to entry — a beginner can mix code into a page in minutes and simply upload it to shared hosting — made it the engine of the dynamic web: WordPress, Drupal and Joomla run on it, as did early Facebook and Wikipedia (MediaWiki). Surveys consistently find PHP on the server side of roughly three-quarters of websites whose technology is known.

Long criticised for inconsistencies and security pitfalls, the language modernised substantially with PHP 7 (2015, much faster) and PHP 8 (2020, just-in-time compilation and a tidier type system). Whatever fashion says, the sheer mass of running PHP — most of the web's content management — guarantees its long future.
