Berge's lemma

Berge's lemma is a result in graph theory, named after Claude Berge, stating that a matching in a graph is maximum if and only if there is no augmenting path with respect to that matching.

Statement

An augmenting path is a path that starts and ends at free (unmatched) vertices and alternates between edges outside and inside the matching. Augmenting along such a path increases the matching size by one.

Significance

The lemma underlies algorithms for maximum matching, including methods for bipartite matching, by giving a simple optimality criterion.
