Google Cloud Platform

Google Cloud Platform (GCP), offered by Google, is a suite of cloud computing services that provides a series of modular cloud services including computing, data storage, data analytics, and machine learning, alongside a set of management tools. It runs on the same infrastructure that Google uses internally for its end-user products, such as Google Search, Gmail and Google Docs.

Services

Major products include Compute Engine (virtual machines), App Engine (platform as a service, launched in 2008 as Google's first cloud offering), the Google Kubernetes Engine for container orchestration, Cloud Storage, BigQuery for serverless data warehousing, Cloud SQL and Spanner databases, and Vertex AI for machine learning. Google Cloud is typically ranked the third-largest cloud provider worldwide, behind Amazon Web Services and Microsoft Azure.

History

App Engine was released in preview in April 2008. The platform expanded through the 2010s, was rebranded under the "Google Cloud" umbrella in 2016, and grew rapidly under CEO Thomas Kurian from 2019, with emphasis on enterprise customers, data analytics and artificial intelligence services built on Google's Tensor Processing Units (TPUs).
