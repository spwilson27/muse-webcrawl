Simulink

DeveloperMathWorks
Initial release1990
PlatformMATLAB
TypeSimulation software

Simulink is a graphical programming environment for modelling, simulating and analysing multidomain dynamical systems, developed by MathWorks. It provides a block diagram editor, customizable block libraries and solvers for continuous, discrete and hybrid systems, and is tightly integrated with MATLAB.

Overview

Users assemble models by dragging blocks representing transfer functions, integrators, gains, signal sources and scopes into a diagram and connecting them with signal lines. Simulink supports model-based design, in which the same model is used for simulation, automatic code generation and testing of embedded controllers.

Applications

Simulink is used extensively in control systems engineering, automotive and aerospace development, signal processing and communications. Add-ons such as Simscape extend it to physical modelling of electrical, mechanical and hydraulic systems; Stateflow adds state machines and flow charts.

History

Simulink was first released in 1990 as SimuLAB and renamed shortly after. It became a standard tool in industry and academia for prototyping control algorithms before deployment to embedded hardware.
