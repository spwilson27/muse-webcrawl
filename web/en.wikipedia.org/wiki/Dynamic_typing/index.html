Dynamic typing

Dynamic typing
Field: programming language theory
Examples: Python, JavaScript, Ruby, Lisp
Contrast: static typing

In computer programming, a programming language is said to use dynamic typing when type checking is performed at run time rather than at compile time. In dynamically typed languages, variables are bound to values but not declared with fixed types; a variable may hold an integer in one statement and a string later, and type errors surface only when the offending operation executes.

Characteristics

Dynamic typing supports flexible idioms such as duck typing — where an object's suitability is determined by the methods it provides rather than its class — and easy metaprogramming and reflection. The trade-offs are that certain errors are caught only in testing, and compilers have less type information for optimisation, though modern just-in-time techniques narrow the gap.

Popular dynamically typed languages include Python, JavaScript, Ruby, PHP, Perl, and Lisp dialects. Gradual typing systems, as in TypeScript for JavaScript or type hints in Python, let programmers add optional static annotations to dynamically typed code bases. See type system.
