Binary-to-text encoding

Binary-to-text encoding
PurposeRepresent binary data using printable text characters
Common schemesBase64, Base32, hexadecimal, uuencode

A binary-to-text encoding is a process that translates binary data into a restricted set of printable characters, so that the data can pass safely through systems designed to handle only text — for example, email protocols, URLs, and legacy file formats.

Common schemes

Base64 is the most widely used scheme, encoding data in groups of three bytes into four characters drawn from a 64-character alphabet, expanding the data by about 33 percent. Base32 uses a smaller alphabet suited to case-insensitive systems. Hexadecimal encoding represents each byte as two hex digits, doubling the size but remaining simple and human-readable. Historical schemes include uuencode and BinHex, used for transferring files over early networks.

Applications

Binary-to-text encodings are used to embed images and attachments in email (MIME), to carry binary data in URLs and data URIs, to store cryptographic keys and certificates in PEM format, and to represent hashes and tokens in configuration files and web APIs.
