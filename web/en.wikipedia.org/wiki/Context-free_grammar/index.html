In formal language theory, a context-free grammar (CFG) is a formal grammar whose production rules can be applied to a nonterminal symbol regardless of its context. Formally, a CFG is a 4-tuple (V, Σ, R, S) where V is a finite set of nonterminal symbols, Σ is a finite set of terminal symbols disjoint from V, R is a finite set of production rules each of the form A → w (with A a nonterminal and w a string of terminals and nonterminals), and S is the start symbol. A grammar is context-free when every production has exactly one nonterminal on its left-hand side.

Background

Context-free grammars were developed in the mid-1950s by Noam Chomsky to describe the syntax of natural languages, forming type 2 of the Chomsky hierarchy. Independently, a nearly identical notation (Backus–Naur form) was devised by John Backus and Peter Naur to specify the syntax of the ALGOL 60 programming language, and CFGs have since been central to the design and parsing of programming languages.

Derivations and parse trees

A grammar derives strings by repeatedly replacing a nonterminal with the right-hand side of one of its productions, beginning from the start symbol. A derivation can be represented as a parse tree whose root is the start symbol and whose leaves, read left to right, form the derived string. A grammar is ambiguous if some string has two distinct parse trees; certain context-free languages are inherently ambiguous, i.e. every grammar generating them is ambiguous.

Normal forms and algorithms

Every CFG can be converted to Chomsky normal form (productions of the forms A → BC or A → a), which underlies the CYK algorithm for membership testing in cubic time, and to Greibach normal form. Membership in any context-free language is decidable in polynomial time, while equivalence of two CFGs is undecidable. Parsing algorithms such as Earley's algorithm, LR parsing, and LL parsing are used extensively in compilers.
