ReFS

ReFS (Resilient File System), codenamed "Protogon", is a proprietary file system developed by Microsoft, introduced with Windows Server 2012. It was designed to succeed NTFS for large-scale, data-intensive workloads, emphasizing data integrity, scalability, and resilience against corruption.

Features

ReFS uses B+ tree structures for metadata and files, checksums for metadata (and optionally for file data via integrity streams), copy-on-write ("allocate-on-write") semantics that avoid in-place metadata updates, and integration with Storage Spaces so that corrupted data can be detected and repaired from a mirror copy. It also supports very large files and volumes, block cloning for fast virtual-machine operations, and sparse VDL.

Limitations and deployment

ReFS cannot be used as a boot volume in most configurations and historically lacked some NTFS features such as file compression, encryption (EFS), disk quotas, and named streams in early versions. Microsoft positions ReFS for servers, backup targets, and virtualization; from Windows 10 Fall Creators Update, the ability to create new ReFS volumes was restricted to Pro for Workstations and Enterprise editions.
