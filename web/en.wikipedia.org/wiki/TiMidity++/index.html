TiMidity++ is a free and open-source software synthesizer that can play MIDI files without a hardware synthesizer. It converts MIDI data into digital audio using Gravis Ultrasound-compatible patch files (GUS patches) or SoundFonts, rendering the instrument samples in software. It is the successor to TiMidity, written by Tuukka Toivonen in the mid-1990s.

Features

TiMidity++ can read MIDI files, KAR files, and module formats in some builds, and output to WAV, MP3, Ogg Vorbis, FLAC and other audio formats as well as playing in real time through system audio. It can act as an ALSA sequencer client on Linux, providing a virtual MIDI port to other applications. Supported effects include reverb and chorus, and it supports the GS, XG and GM2 extensions to the MIDI standard to varying degrees.

Interfaces

The program offers several interfaces, from a plain command-line and ncurses text interface to graphical front ends using GTK+ and other toolkits, plus a Windows interface known as TWSYNTH in common distributions. Because it runs entirely in software, TiMidity++ was historically a popular way to obtain MIDI playback on systems lacking wavetable hardware, and it remains used for batch conversion of MIDI files to audio.
