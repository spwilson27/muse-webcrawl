Lanczos approximation

The Lanczos approximation is a method for computing the numerical value of the gamma function, published by Cornelius Lanczos in 1964. It is a practical alternative to the more famous Stirling's approximation for calculating the gamma function with fixed precision.

The gamma function Γ(z) is defined, for complex numbers with a positive real part, by the integral

Γ(z) = ∫0∞ tz−1 e−t dt.

Lanczos developed an approximation of the form

Γ(z+1) = √(2π) (z + g + 1/2)z+1/2 e−(z+g+1/2) Ag(z),

where g is a real parameter that can be chosen to trade off accuracy and simplicity, and Ag(z) is a partial sum of a series whose coefficients p0, p1, … depend on g.

Coefficients

For the commonly used choice g = 7, a set of nine coefficients gives an approximation accurate to about 15 significant digits for arguments in the right half-plane. The first coefficient is p0 = 0.99999999999980993, followed by p1 = 676.5203681218851, p2 = −1259.1392167224028, and further alternating terms. These values are hard-coded in many numerical libraries.

Use in software

The approximation is widely used in practice, for example in the GNU Scientific Library, Boost, and other numerical packages, because it is fast, accurate, and valid over a large part of the complex plane. Combined with the reflection formula, it can be extended to arguments with negative real parts.
