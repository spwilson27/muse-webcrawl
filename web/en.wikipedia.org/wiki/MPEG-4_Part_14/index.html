MPEG-4 Part 14

MPEG-4 Part 14 or MP4 is a digital multimedia container format most commonly used to store video and audio, but it can also be used to store other data such as subtitles and still images. Like most modern container formats, it allows streaming over the Internet. The only filename extension for MPEG-4 Part 14 files as defined by the specification is .mp4.

MPEG-4 Part 14 (formally ISO/IEC 14496-14:2003) is a standard specified as a part of MPEG-4. It is based on the ISO base media file format, which was itself derived from Apple's QuickTime file format (.mov). Related extensions include .m4a (audio only), .m4v and .3gp, used by mobile phones.

History

The first version of the specification was published in 2001 as part of MPEG-4 Part 1; Part 14 was split off and published in 2003, aligning the format with the second edition of the ISO base media file format. A "fast start" arrangement places the metadata (the moov atom) at the beginning of the file so that playback can begin before the whole file has downloaded.

Data streams

MP4 files organise data into a hierarchy of objects called atoms or boxes. Virtually any kind of codec can be stored, but in practice most MP4 files contain video encoded with MPEG-4 Part 2, H.264/MPEG-4 AVC or H.265/HEVC, and audio encoded with AAC. Metadata such as title, album art and chapters is stored in dedicated structures, and the format supports DRM through schemes such as FairPlay.
