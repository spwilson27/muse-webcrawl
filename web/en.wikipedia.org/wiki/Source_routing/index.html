Source routing

In computer networking, source routing, also called path addressing, allows a sender of a data packet to partially or completely specify the route the packet takes through the network. In contrast, in conventional routing, routers in the network determine the path incrementally based on the packet's destination.

Types

In strict source routing, the sender specifies every hop on the path, and each router must forward the packet to the next specified address or return an error. In loose source routing, the sender specifies a list of intermediate points that the packet must visit, but the network may choose the paths between them. IPv4 provides loose and strict source routing through its LSRR and SSRR options; because of security concerns — source routing lets an attacker bypass some route-based filtering and can be used in address-spoofing attacks — most routers disable or drop source-routed packets by default, and IPv6's original Routing Type 0 extension header was deprecated for similar reasons.

Uses

Source routing can be used to test particular paths, work around routing failures, balance load between links, and measure network performance. Its principles reappear in modern techniques such as Multiprotocol Label Switching (MPLS) traffic engineering and segment routing, in which a path is encoded as a sequence of segment identifiers and imposed at the ingress, combining path control with the scalability of hop-by-hop forwarding.
