B+ tree

A B+ tree is an n-ary tree data structure used for storing sorted data in a way that supports efficient insertion, retrieval and deletion, typically in databases and file systems. It is a variant of the B-tree in which all actual data records are stored only in the leaf nodes, and internal nodes hold only keys that guide the search.

Properties

In a B+ tree, leaf nodes are linked together in a linked list, making range scans and sequential access efficient. Internal nodes act as an index of separators, giving a high fan-out and a shallow tree that minimises disk accesses.

Uses

B+ trees underlie the indexes of most relational database systems (such as the InnoDB storage engine) and the metadata structures of file systems including NTFS, ext4 (via HTree for directories) and XFS.
