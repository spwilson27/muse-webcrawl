Media type

A media type (formerly known as a MIME type) is a two-part identifier for file formats and format contents transmitted on the Internet. The Internet Assigned Numbers Authority (IANA) is the official authority for the standardisation and publication of these classifications. Media types were originally defined in Request for Comments RFC 2045 (November 1996) as part of the MIME (Multipurpose Internet Mail Extensions) specification, for denoting type of email message content and attachments; hence the name MIME type.

Structure

A media type consists of a type and a subtype, separated by a slash, optionally with parameters: for example text/html; charset=UTF-8. Top-level types include:

  • text — readable text, e.g. text/plain, text/html, text/css
  • image — e.g. image/png, image/jpeg, image/svg+xml
  • audio and video — e.g. audio/mpeg, video/mp4
  • application — miscellaneous binary or program-specific data, e.g. application/json, application/pdf, application/octet-stream
  • multipart and message — composite body types
  • font, model, example, and others added later

Registration trees

Subtypes are registered in trees: the standards tree (IANA-reviewed), the vendor tree (prefix vnd.), the personal/vanity tree (prs.), and the unregistered x- prefix (discouraged but widely seen). The +suffix convention (e.g. +xml, +json) indicates the underlying generic format.

Use

Media types appear in HTTP Content-Type headers, email headers, file magic identification, and content negotiation, allowing software to handle content appropriately without relying on file extensions.
