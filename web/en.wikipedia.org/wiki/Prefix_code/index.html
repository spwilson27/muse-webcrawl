Prefix code

A prefix code is a type of code system (typically a variable-length code) distinguished by its possession of the "prefix property": no valid code word is a prefix of any other valid code word. This property allows encoded symbols to be decoded instantaneously, without delimiters or lookahead, making prefix codes fundamental to data compression.

Examples and theory

Huffman coding produces an optimal prefix code for a given set of symbol frequencies. Morse code is not a strict prefix code because it relies on pauses to separate letters. The set of code word lengths of a binary prefix code must satisfy the Kraft inequality, and conversely any lengths satisfying the inequality can be realised as a prefix code — equivalently, code words correspond to leaves of a binary tree.

Uses

Besides Huffman coding, prefix codes appear in the DEFLATE compression format, in country calling codes and telephone numbering plans, in brain-teaser "twenty questions" bounds, and in the design of uniquely decodable instruction sets and file formats where self-synchronising, instantaneous decoding is valuable.
