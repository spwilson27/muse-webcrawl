Element (software)

Element (previously known as Riot and Vector) is a free and open-source software instant messaging client implementing the Matrix protocol. It supports end-to-end encrypted 1:1 and group chat, voice and video calls, file sharing, and bridging to other communication networks. Element is developed by the company Element (formerly New Vector) and a community of contributors.

History

The client was first released in beta in 2016 under the name Vector, then relaunched as Riot, and rebranded to Element in July 2020 to avoid confusion with other products and to unify the brand. The flagship application is built with the Matrix React SDK and is available as a web application and as native apps for Windows, macOS, Linux, Android, and iOS; the mobile apps were progressively rewritten as Element X using the Matrix Rust SDK.

Features and adoption

Element provides rooms (including public rooms and private spaces), threads, reactions, polls, location sharing, and a built-in Jitsi-based or native (Element Call) voice and video conferencing option. Because it is based on the open Matrix standard, users can self-host or choose any provider and still interoperate. The client has been adopted by organisations including the French government (as part of its Tchap deployment), the German armed forces (BwMessenger), and various open-source communities.
