Cubic Hermite spline

A cubic Hermite spline (or cubic Hermite interpolator) is a spline in which each piece is a third-degree polynomial specified by its values and first derivatives at the endpoints of the interval. Named after Charles Hermite, it is widely used in numerical analysis and computer graphics for interpolating data smoothly while controlling tangents.

Formulation

On the unit interval, the interpolant is built from four basis functions that weight the endpoint values p0, p1 and the endpoint tangents m0, m1. Chaining such segments yields a curve that is C1 continuous. Common choices of tangents produce the cardinal splines, Catmull–Rom splines, and Kochanek–Bartels splines used in animation.

Applications

Hermite interpolation underlies keyframe animation curves, font outline design, trajectory planning and monotone interpolation schemes such as the Fritsch–Carlson method, which adjusts tangents to preserve the monotonicity of data.
