Formal semantics (logic)

In logic, formal semantics is the study of the meaning of formal languages, typically by specifying interpretations of their symbols in mathematical structures. Whereas syntax defines which strings of symbols are well-formed formulas, semantics determines under what conditions those formulas are true. The model-theoretic semantics for first-order logic, developed in the work of Alfred Tarski in the 1930s, defines truth in a structure: a model consisting of a domain of discourse and an interpretation function assigning denotations to constants, predicates and function symbols, together with recursive satisfaction clauses for connectives and quantifiers.

Semantics stands in contrast to proof theory, which studies what can be mechanically derived from axioms; the central theorems of logic relate the two — soundness (everything provable is true in all models) and completeness (everything true in all models is provable), proved for first-order logic by Kurt Gödel.

Model-theoretic semantics

A model for a first-order language consists of a non-empty set (the universe or domain) and interpretations of the language's non-logical symbols: each constant denotes an element of the domain, each n-ary predicate denotes a set of n-tuples, and each function symbol denotes a function on the domain. An assignment of values to variables then allows every formula to be evaluated as true or false in the model. Tarski's definition of truth gives clauses such as: a conjunction is satisfied when both conjuncts are; an existential formula is satisfied when some element of the domain witnesses it.

Semantics for other systems

  • Propositional logic: models are truth-value assignments (valuations) to atomic propositions.
  • Modal logic: Kripke semantics evaluates formulas at possible worlds connected by accessibility relations.
  • Intuitionistic logic: Kripke or Heyting-algebra semantics reflect its constructive character.
  • Programming languages: operational, denotational and axiomatic semantics specify the meaning of programs — territory shared with formal verification.

Contrast with linguistics

The same model-theoretic apparatus was adapted by Richard Montague and others to natural language, giving rise to formal semantics in linguistics. The logic usage, however, concerns artificial formal languages rather than the grammar of human languages.
