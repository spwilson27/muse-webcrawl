Standard Template Library

The Standard Template Library (STL) is a software library originally designed by Alexander Stepanov and Meng Lee at Hewlett-Packard, which profoundly influenced the C++ Standard Library. It provides generic implementations of common data structures and algorithms organised around four components: containers, iterators, algorithms and function objects (functors). The STL is the flagship realisation of generic programming: algorithms are written once, in terms of iterator interfaces, and work with any container whose iterators satisfy the required concepts.

Components

  • Containers store collections of objects: sequence containers such as vector, list and deque; associative containers such as set and map; and, from C++11, unordered (hash-based) containers.
  • Iterators generalise pointers, providing a uniform way to traverse containers; they are classified in a hierarchy from input and output iterators through forward and bidirectional iterators to random-access iterators.
  • Algorithms — around a hundred in the standard — perform operations such as sorting, searching, counting, transforming and partitioning on iterator ranges.
  • Function objects are objects that can be called as functions, used to customise algorithms with user-defined operations, comparisons and predicates.

History

Stepanov had been developing the ideas of generic programming since the late 1970s, in work with David Musser at General Electric and in the Ada and Scheme communities, believing that fundamental algorithms should be lifted from particular implementations to abstract, mathematically specified concepts. The STL was presented to the C++ standards committee in 1993–94 and adopted, with modifications, into the draft standard; C++98 incorporated most of the library. Its inclusion transformed C++ practice and the design of the standard library, and its concepts were formally recognised in C++20, which added language-supported concepts and ranges.

Implementations of the STL have included the original HP/SGI version, STLPort, and the versions shipped with major compilers (libstdc++, libc++, and Microsoft's). Stepanov's related writings, including Elements of Programming (2009, with Paul McJones), set out the mathematical foundations of the approach.
