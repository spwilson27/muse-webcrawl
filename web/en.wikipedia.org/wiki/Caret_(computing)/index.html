Caret (computing)

In computing, the term caret is used for several related concepts involving the circumflex character ^ (U+005E) and the text insertion point. The caret is the blinking cursor — typically a vertical bar, underscore, or block — that indicates where typed text will be inserted in a document or text field. In graphical user interfaces this text cursor is formally distinguished from the mouse pointer.

Text caret

The word "caret" for the text cursor comes from Latin caret, "it lacks", referring to the proofreading mark (‸) used to show where something should be inserted in a text. The on-screen insertion point may appear as a thin vertical line, a block, or an underline, and frequently blinks to distinguish it from static text.

Circumflex usages

The circumflex character itself is widely used in computing: in caret notation control characters are written as ^A, ^C and so on; in many languages ^ denotes the bitwise XOR operator or exponentiation; in regular expressions it anchors a match to the start of a line; and in command-line interfaces it has been used as an escape character.
