Maximum common subgraph
FieldGraph theory, algorithm design
Problem typeOptimisation / isomorphism problem
ComplexityNP-hard

In graph theory and theoretical computer science, the maximum common subgraph problem asks, given two graphs G and H, for the largest graph that is (isomorphic to) a subgraph of both — that is, the largest structure shared by the two graphs. Variants distinguish between maximum common induced subgraphs and maximum common edge subgraphs, and between exact and approximate solutions.

Complexity

The problem is NP-hard: it generalises both the clique problem (the maximum common subgraph of a graph with a complete graph) and the subgraph isomorphism problem. Unless P = NP, exact solutions can therefore require exponential time in the worst case, although branch-and-bound algorithms using constraint propagation and strong upper bounds solve many practical instances efficiently.

Algorithms

A common approach transforms the problem into finding a maximum clique in a derived "modular product" (association) graph built from pairs of compatible vertices. Modern solvers instead use direct backtracking search over vertex mappings with forward checking, as in the McCreesh–Prosser algorithm, which has substantially improved performance on benchmark instances. Approximate and heuristic methods, including local search and continuous relaxations, are used for very large graphs.

Applications

Maximum common subgraph computation is a core tool in cheminformatics for comparing molecular structures, in pattern recognition and computer vision for object matching, in bioinformatics for comparing protein structures and networks, and in code analysis for detecting cloned or plagiarised software fragments.
