Loop invariant

In computer science, a loop invariant is a property of a program loop that is true before (and after) each iteration. It is a logical assertion, sometimes checked within the code by means of an assertion call. Knowing its invariant(s) is essential in understanding the effect of a loop.

In formal program verification, particularly the Floyd–Hoare approach, loop invariants are used to reason about the correctness of loops: if a property (1) holds before the loop starts (initiation), (2) is preserved by every iteration assuming the loop condition (maintenance), and (3) together with the negation of the loop condition implies the desired postcondition (termination step, along with a variant showing progress), then the loop is partially correct and achieves its goal when it exits.

Example

For a simple loop that computes the maximum of an array a[0..n-1] by scanning indices i and keeping a running maximum m, a suitable invariant is: "m equals the maximum of a[0..i-1]". It holds initially (empty range, with m initialised to the first element), is preserved by each step, and at exit gives m as the maximum of the whole array.

Language support

The Eiffel programming language includes explicit invariant clauses for loops as part of its design-by-contract features. Loop invariants also appear in specification languages such as JML for Java and ACSL for C, and in deductive verification tools (e.g. Dafny, Frama-C).
