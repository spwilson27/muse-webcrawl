libvirt

libvirt is an open-source API, daemon and management tool for managing platform virtualization. Written mainly in C and released under the GNU Lesser General Public License, it provides a single, hypervisor-agnostic interface for creating, configuring and controlling virtual machines, networks and storage.

Overview

Libvirt abstracts differences between hypervisors including KVM/QEMU, Xen, VMware ESX, Hyper-V, LXC containers and VirtualBox. Virtual machines ("domains") are described in a standard XML format. The libvirtd daemon runs on the host and exposes the API locally and over the network; client tools such as virsh (command line) and virt-manager (graphical) communicate with it. Bindings exist for many programming languages, including Python, Java, OCaml and Ruby.

History

The project was started by Red Hat in 2005, initially to manage Xen, and grew to cover most major virtualization technologies on Linux and other operating systems. Libvirt became a foundational component of private-cloud and hosting infrastructure and of the oVirt and OpenStack ecosystems.
