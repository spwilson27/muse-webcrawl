Hybrid kernel

A hybrid kernel is an operating system kernel architecture that attempts to combine the performance of a monolithic kernel with the modularity and reliability benefits of a microkernel. In a hybrid design, most operating-system services run in kernel space as in a monolithic kernel, but the structure is organised along microkernel lines, with subsystems communicating through message passing.

Examples

The best-known examples are the Windows NT kernel, which runs subsystems such as the executive services in kernel mode while exposing personality subsystems (historically partly in user mode), and Apple's XNU kernel, which combines the Mach microkernel with a BSD layer and an I/O Kit driver framework in a single kernel address space. The term is sometimes considered a marketing category rather than a sharply defined architecture, since any microkernel that colocates services for performance tends toward the same design point.

Criticism

Critics, including Linus Torvalds in the context of the Tanenbaum–Torvalds debate, have argued that "hybrid kernel" is simply a name for a monolithic kernel with modular structure. Supporters respond that the internal message-passing design and subsystem separation meaningfully distinguish hybrids from purely monolithic designs such as traditional Unix kernels.
