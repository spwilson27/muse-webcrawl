Asymmetric numeral systems

ANS encodes symbols as natural numbers whose density matches symbol probabilities.

Asymmetric numeral systems (ANS) is a family of entropy encoding methods introduced by Polish computer scientist Jarek Duda in the late 2000s. ANS combines the near-optimal compression ratio of arithmetic coding with processing speed comparable to Huffman coding, and has been widely adopted in modern compressors. Its key idea is to encode information in a single natural number whose distribution over ranges reflects the probabilities of the symbols being coded.

Variants

Three main variants are used in practice:

  • uABS — the uniform binary variant, for coding binary alphabets with unequal probabilities.
  • rANS — the range variant, suited to larger alphabets and popular in high-performance codecs.
  • tANS — the tabled variant, which precomputes a finite-state automaton, giving very fast decoding; it underlies the FSE (Finite State Entropy) library.

Adoption

ANS-based schemes appear in Facebook's Zstandard compressor (via FSE), Apple's LZFSE, JPEG XL image coding, CRAM DNA-sequence archives, and many game and middleware compression libraries. Because the inventor placed the core techniques in the public domain, ANS spread rapidly despite early patent disputes concerning some applications.

Principle

In ANS, the encoder maintains a state number x. Symbols are distributed over the natural numbers with a density roughly equal to their probability: common symbols occupy most of the number line, so adding them increases the state only slightly, while rare symbols expand it by many bits. Decoding reverses the process, so the coder works as a stack (LIFO), unlike the queue-like behaviour of arithmetic coders.
