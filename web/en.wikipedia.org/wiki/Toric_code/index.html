Toric code

FieldQuantum information, condensed matter physics
Introduced byAlexei Kitaev (1997/2003)
TypeTopological quantum error-correcting code (stabilizer code)
RelatedSurface code, topological order, anyons

The toric code is a topological quantum error-correcting code, and an example of a stabilizer code, defined on a two-dimensional spin lattice. It was introduced by Alexei Kitaev and is the simplest model exhibiting topological order: its quantum information is stored non-locally, in degrees of freedom that are robust against local perturbations and errors.

Definition

Qubits are placed on the edges of a square lattice wrapped on a torus. The code's stabilizer generators are of two kinds: "star" operators, the product of Pauli X operators on the edges meeting at a vertex, and "plaquette" operators, the product of Pauli Z operators around a face. The ground space of the code Hamiltonian—the sum of these commuting operators—has dimension four on a torus, encoding two logical qubits. The code distance grows with the lattice size, so arbitrarily good protection (up to lattice size) can be achieved.

Error correction and anyons

Errors create pairs of excited syndromes, interpreted as quasiparticles: electric charges (e) at violated vertices and magnetic fluxes (m) at violated plaquettes. Because the syndromes reveal only the endpoints of error strings, correction is a decoding problem analogous to matching pairs of anyons, solvable for example with minimum-weight perfect matching. The excitations are Abelian anyons: exchanging e and m particles yields mutual semionic statistics, and their bound state is a fermion. This structure links the toric code to lattice gauge theory (a Z2 gauge theory).

Significance

The toric code is a foundational model of fault-tolerant quantum computation and topological phases of matter. Its planar variant, the surface code, dispenses with the torus topology by adding boundaries and is the leading architecture pursued in experimental superconducting quantum computing, because it requires only nearest-neighbor interactions and has a high error threshold (around 1%).
