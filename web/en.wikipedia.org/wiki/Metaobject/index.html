In computer science, a metaobject is an object that manipulates, creates, describes, or implements other objects, including itself. The architecture in which metaobjects describe a language or system is called a metaobject protocol (MOP): a set of functions and objects that implement the semantics of an object system and can be customized by programmers.

Concepts

Metaobjects arise in systems supporting reflection — the ability of a program to examine and modify its own structure at runtime. In Smalltalk, classes are themselves objects, instances of metaclasses. In Python, classes are instances of type, and custom metaclasses let programmers intercept class creation. In the Common Lisp Object System (CLOS), the metaobject protocol — documented in The Art of the Metaobject Protocol (1991) by Gregor Kiczales, Jim des Rivières, and Daniel Bobrow — exposes classes, generic functions, and slot definitions as metaobjects whose behavior can be extended.

Uses

Metaobject protocols enable aspect-oriented programming, object-relational mapping, transparent persistence, distributed objects, and domain-specific language extensions, all without modifying the underlying language implementation. The trade-off is complexity and potential performance cost.
