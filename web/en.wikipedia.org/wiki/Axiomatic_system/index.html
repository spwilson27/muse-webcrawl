In mathematics and logic, an axiomatic system is a set of axioms from which some or all of the axioms can be used, in conjunction with rules of inference, to logically derive theorems. A theory is a consistent, relatively self-contained axiomatic system; the mathematical structure that satisfies the axioms is called a model of the system. An axiomatic system that is fully formalised is a formal system.

Components

An axiomatic system typically consists of: a set of primitive (undefined) terms whose meaning is fixed implicitly by the axioms; a set of axioms, statements taken as true without proof; rules of inference, such as modus ponens, by which new statements (theorems) are derived; and definitions introducing new terms as abbreviations. Examples range from Euclidean geometry and Peano arithmetic to the Zermelo–Fraenkel axioms of set theory and Hilbert's axioms for geometry.

Properties

Several properties of axiomatic systems are of central interest. A system is consistent if it cannot prove both a statement and its negation; independent if no axiom can be proved from the others; and complete if for every statement in its language, either the statement or its negation is provable. Kurt Gödel's incompleteness theorems (1931) showed that any consistent axiomatic system strong enough to express elementary arithmetic is incomplete and cannot prove its own consistency.

History

The axiomatic method originates with Euclid's Elements (c. 300 BCE), which derived the theorems of geometry from five postulates. Attempts to prove Euclid's parallel postulate from the others led, in the nineteenth century, to the discovery of consistent non-Euclidean geometries, transforming understanding of what axioms are: not self-evident truths, but stipulations. David Hilbert's Foundations of Geometry (1899) exemplified the modern, formal conception, and the axiomatic approach spread throughout mathematics — to algebra (groups, rings, fields), probability (Kolmogorov's axioms, 1933), and beyond.

Models

A model of an axiomatic system is an assignment of meanings to its primitive terms under which all the axioms become true. The existence of a model shows the system is consistent (relative to the theory in which the model is built), while the existence of models with different properties shows axioms are independent — as when the Beltrami–Klein model demonstrated the independence of the parallel postulate.
