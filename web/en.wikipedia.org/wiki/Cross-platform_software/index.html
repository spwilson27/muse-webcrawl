Cross-platform software

Cross-platform software runs on more than one computing platform.

In computing, cross-platform software (also called multi-platform software, platform-agnostic software, or platform-independent software) is computer software that is designed to work in several computing platforms. Some cross-platform software requires a separate build for each platform, while others can be directly installed on any platform without special preparation, being written in an interpreted language or pre-compiled portable bytecode for which the interpreters or run-time packages are available for all supported platforms.

Approaches

Common strategies include writing source code that compiles for multiple targets (as with much C and C++ software using cross-platform libraries such as Qt), running on a virtual machine (as with Java and .NET), web applications delivered through a browser, and cross-platform frameworks for mobile development such as React Native and Flutter. Emulation and compatibility layers, such as Wine, allow software written for one platform to run on another.

Advantages and disadvantages

Cross-platform development reduces the cost of reaching users on different operating systems and keeps features consistent across them. Its drawbacks can include lower performance than native applications, increased size, and user interfaces that do not fully follow each platform's conventions — the "lowest common denominator" problem.
