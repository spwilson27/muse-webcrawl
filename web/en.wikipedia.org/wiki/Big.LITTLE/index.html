ARM big.LITTLE

ARM big.LITTLE is a heterogeneous computing architecture developed by ARM Holdings, announced in October 2011, that combines relatively slow, power-efficient processor cores ("LITTLE") with larger, high-performance but power-hungry cores ("big") on a single system on a chip (SoC). Because most computing workloads are bursty, the operating system can run background and light tasks on the efficient cores and migrate demanding work to the powerful cores, improving energy efficiency.

Heterogeneous clusters: performance cores beside efficiency cores.

Operation

Early implementations paired Cortex-A15 (big) with Cortex-A7 (LITTLE) cores, which are instruction-set compatible so threads can migrate between them. Software models progressed from cluster migration (only one cluster active) through CPU migration to global task scheduling, in which all cores can be active simultaneously and the scheduler assigns each thread to a suitable core.

Implementations

Samsung's Exynos 5 Octa, launched in 2013 in the Galaxy S4, was the first widely shipped big.LITTLE chip. MediaTek, HiSilicon and others followed. In 2017 ARM introduced DynamIQ, which generalises the idea by allowing varied core configurations within a single cluster. The big.LITTLE philosophy later influenced heterogeneous designs across the industry, including hybrid desktop and laptop processors.
