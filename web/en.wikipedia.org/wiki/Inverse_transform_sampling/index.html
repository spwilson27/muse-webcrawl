Inverse transform sampling

Inverse transform sampling generates random numbers from a distribution using its inverse CDF.

Inverse transform sampling (also known as inversion sampling, the inverse probability integral transform, the inverse transformation method, or the Smirnov transform) is a basic method for pseudo-random number sampling, i.e., for generating sample numbers at random from any probability distribution given its cumulative distribution function (CDF).

Method

The method works as follows. Let X be a random variable with CDF F. Generate a uniform random number U on the interval (0, 1). Then X = F−1(U) has distribution F. Intuitively, one samples a point uniformly along the vertical axis of the CDF graph and reads off the corresponding horizontal value.

Proof

Because U is uniform, P(F−1(U) ≤ x) = P(U ≤ F(x)) = F(x), which is exactly the statement that F−1(U) has CDF F.

Applications and alternatives

Inverse transform sampling is conceptually simple and efficient when the inverse CDF is available in closed form, as for the exponential and Cauchy distributions. When the inverse is not tractable, alternatives such as rejection sampling, the Box–Muller transform, or the ziggurat algorithm are used.
