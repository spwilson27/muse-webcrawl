Disk partitioning

Disk partitioning or disk slicing is the creation of one or more regions on secondary storage, called partitions, so that they can be managed separately. Each partition appears to the operating system as a distinct logical disk with its own file system. A disk's layout is recorded in a partition table; the two dominant schemes are the Master Boot Record (MBR) scheme, introduced with IBM PC DOS 2.0 in 1983, and the GUID Partition Table (GPT), part of the UEFI standard, which supports disks larger than 2 TiB and many more partitions.

Partition schemes

Under MBR, a disk may hold up to four primary partitions, one of which may be an extended partition containing any number of logical partitions. GPT replaces this hierarchy with up to 128 partitions by default in Windows, identified by type GUIDs, with CRC32 checksums and a protective MBR for backward compatibility. Other historical schemes include the Apple Partition Map and BSD disklabels. Modern operating systems also provide logical volume managers that supersede fixed partitions with resizable volumes.

Purposes

Partitioning allows multiple operating systems to coexist on one disk (multi-booting), separates system files from user data to simplify backup and reinstallation, isolates swap space, logs, or caches, and limits the damage of file-system corruption or runaway disk usage to a single region. Typical tools include fdisk, GNU Parted, GParted, and Windows Disk Management. Resizing partitions after creation is possible with suitable tools but historically risky, though modern file systems and LVM have made it routine.
