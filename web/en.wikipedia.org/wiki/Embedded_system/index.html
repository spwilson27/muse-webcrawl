Embedded system

From Wikipedia, the free encyclopedia

An embedded system is a microprocessor-based computer system with a dedicated function, designed as part of a larger mechanical or electronic device, often subject to real-time computing constraints. Unlike a general-purpose computer, which runs many varied applications chosen by the user, an embedded system performs one or a few predefined tasks — controlling a washing machine, a car's engine, a medical infusion pump, or an industrial robot — and is typically optimised for cost, size, power consumption, and reliability.

Characteristics

Embedded systems are built around microcontrollers or digital signal processors integrated with memory and input/output peripherals, frequently on a single chip. Their software, often called firmware, may run on a real-time operating system or directly on the hardware in a control loop that must respond to events within strict deadlines. Many operate unattended for years, use minimal user interfaces of buttons and indicator lights, and must fail safely if they fail at all.

History

One of the earliest embedded systems was the Apollo Guidance Computer (1960s), which guided the Apollo spacecraft using core rope memory and a real-time operating system. The development of the microprocessor in the 1970s — notably the Intel 4004 and later the 8051 microcontroller — made embedded control cheap enough for mass-produced consumer goods. By the early twenty-first century, embedded processors vastly outnumbered general-purpose ones, appearing in automobiles (modern cars contain dozens), phones, appliances, industrial control systems, and network equipment.

Design considerations

Engineers trade off performance against unit cost, power, and time-to-market, programming mainly in C and C++ with hardware-specific debugging tools. Connected embedded devices form much of the Internet of Things, which has raised new concerns about security updates and longevity as billions of unattended devices join networks.
