CP/M

CP/M (Control Program for Microcomputers, initially "Control Program/Monitor") is a mass-market operating system created in 1974 for Intel 8080/85-based microcomputers by Gary Kildall of Digital Research. It was the dominant operating system for microcomputers in the late 1970s and early 1980s, and standardized the market so that application software could run across machines from many manufacturers.

Architecture

CP/M divided the system into three parts so that only one small piece needed to be rewritten for each new machine: the BIOS (Basic Input/Output System), machine-specific hardware routines; the BDOS (Basic Disk Operating System), providing file and console services; and the CCP (Console Command Processor), which presented the famous A> prompt and built-in commands such as DIR, ERA, REN, TYPE, and PIP (for copying files). Programs loaded at address 0100h in the Transient Program Area, giving rise to the .COM file format.

Software ecosystem

CP/M hosted the first generation of mass-market microcomputer software: the WordStar word processor, dBASE II database, SuperCalc spreadsheet, MBASIC, and implementations of languages from Pascal to C. Business machines such as the Osborne 1, Kaypro, and IMSAI shipped with CP/M, and the 8-inch floppy format became a de facto interchange standard.

Decline

Digital Research produced CP/M-86 for the Intel 8086, but when IBM launched the IBM PC in 1981 it primarily offered Microsoft's PC DOS — whose API was modeled on CP/M's — at a much lower price. CP/M rapidly lost the desktop to DOS, though derivatives (Concurrent DOS, DR-DOS, MP/M multi-user variants) survived in niches, and CP/M remained common in embedded systems for many years. In 2014 the original CP/M source code was released for non-commercial study by the Computer History Museum.
