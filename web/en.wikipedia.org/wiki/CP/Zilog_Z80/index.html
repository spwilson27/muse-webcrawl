Zilog Z80 in CP/M Systems

The Zilog Z80, launched in July 1976, became the most widely used processor for CP/M computers. Designed by Federico Faggin and Masatoshi Shima, the Z80 was binary-compatible with the Intel 8080 — so all CP/M software written for the 8080 ran unchanged — while adding an enhanced instruction set, single +5 V supply, built-in DRAM refresh, and an alternate register set.

CP/M dominance

Because CP/M required only an 8080-compatible CPU, computer makers overwhelmingly chose the cheaper, easier-to-integrate Z80. Classic Z80 CP/M machines include the Osborne 1, the Kaypro II, the Amstrad PCW series, and the TRS-80 Model 4 (in CP/M mode). The Amstrad PCW alone kept CP/M commercially relevant into the early 1990s as a dedicated word-processing system running LocoScript and CP/M Plus.

Technical features

The Z80 added index registers IX and IY, block move and search instructions, bit manipulation instructions, and a second bank of general-purpose registers. Later variants, such as the Z80H, reached clock speeds of 8 MHz and beyond. Its interrupt modes and relative jump instructions made it attractive for embedded control as well.

Longevity

Long after CP/M faded, the Z80 persisted in embedded systems, the Game Boy, the TI-83 series of calculators, and countless industrial controllers. Zilog announced the end of orders for the standalone Z80 in 2024, closing a production run of nearly 48 years.
