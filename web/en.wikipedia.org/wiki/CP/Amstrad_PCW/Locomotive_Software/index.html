Locomotive Software

From Wikipedia, the free encyclopedia

Locomotive Software was a British software company founded in 1983, best known for the software it developed for Amstrad home computers. The company wrote the LocoScript word processor supplied with the Amstrad PCW series, as well as versions of the CP/M operating system (CP/M Plus) supplied with Amstrad's CPC 6128 and PCW ranges, and Mallard BASIC for the PCW.

Work for Amstrad

Locomotive's relationship with Amstrad began with the Amstrad CPC range, for which it provided ports of CP/M and the Mallard BASIC interpreter. For the PCW 8256 and 8512 word-processor computers launched in 1985, Locomotive wrote LocoScript, a dedicated word-processing program that ran on a custom CP/M-derived environment; the PCW machines shipped with CP/M Plus, whose implementation on the machine was also Locomotive's work. Later products included LocoScript 2, LocoFile, LocoSpell, and LocoMail for the PCW, plus software for Amstrad's later PcW16 machine.

Later work

As the market moved to PCs, Locomotive produced software such as Turnpike, an Internet access suite for Windows developed with Demon Internet. The company was based in Dorking, Surrey.
