MS-DOS (Microsoft Disk Operating System) was the dominant operating system for IBM PC compatibles during the 1980s and early 1990s. It originated as 86-DOS, written by Tim Paterson at Seattle Computer Products as a 16-bit system modelled on CP/M, which Microsoft bought in 1981 and adapted for the IBM Personal Computer, where IBM sold it as PC DOS.

The MS-DOS command-line interface, driven by COMMAND.COM.

Overview

MS-DOS is a single-user, single-tasking system with a command-line interface. Its kernel (IO.SYS and MSDOS.SYS) provides file and device services through software interrupts (notably INT 21h), uses the FAT file system, and runs one program at a time in real mode within the 640 KB "conventional memory" limit. Successive versions added hierarchical directories (2.0, 1983), networking support, hard-disk and memory-management utilities, disk compression, and the graphical shell DOS Shell.

Legacy

Microsoft Windows ran on top of MS-DOS through Windows 3.x and the Windows 9x line, which gradually subsumed it; consumer DOS releases ended with Windows Me in 2000. MS-DOS's licensing to clone makers — rather than selling hardware — established Microsoft's business model and the PC-compatible ecosystem. In 2018 Microsoft released the MS-DOS 1.25 and 2.0 source code under the MIT License.
