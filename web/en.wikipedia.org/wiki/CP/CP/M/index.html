CP/M

DeveloperDigital Research; Gary Kildall
Initial release1974
PlatformsIntel 8080, 8085, Zilog Z80
SuccessorMP/M, DOS Plus, DR-DOS

CP/M, originally standing for Control Program/Monitor and later Control Program for Microcomputers, is a mass-market operating system created in 1974 for Intel 8080/85-based microcomputers by Gary Kildall of Digital Research, Inc. It was the dominant operating system for microcomputers in the late 1970s and early 1980s, and for a time the most widely used operating system across different makes of computer.

The CP/M command line on an 8-bit microcomputer

History

Kildall, a computer science instructor at the Naval Postgraduate School in Monterey, California, wrote CP/M in his PL/M language in 1974, initially as a program to control a floppy disk drive for testing Intel's Intellec-8 development system. He and his wife Dorothy founded Intergalactic Digital Research, later simply Digital Research, to sell the system. CP/M was first licensed to IMS Associates for the IMSAI 8080 computer in 1975.

The system separated machine-specific input/output code into a BIOS (Basic Input/Output System), allowing the same operating system to run on many different machines. This hardware independence made CP/M attractive to manufacturers such as Kaypro, Osborne Computer Corporation, and Amstrad, whose CPC and PCW machines shipped with CP/M.

Components

CP/M consisted of three main components: the BIOS, the BDOS (Basic Disk Operating System), and the CCP (Console Command Processor), which provided commands such as DIR, ERA, TYPE, REN, and PIP for copying files. The file system used 8.3 filenames and allocated disk space in blocks, with a maximum file size of 16 MB in later versions via extents.

Software

A large library of software was written for CP/M, including the WordStar word processor, the dBASE II database, the SuperCalc spreadsheet, and languages such as MBASIC, Turbo Pascal, and CBASIC. Business software accounted for much of CP/M's success in professional settings.

Decline and influence

In 1980, IBM approached Digital Research about licensing CP/M for its forthcoming personal computer, but negotiations faltered; IBM instead adopted PC DOS from Microsoft, which was closely modeled on 86-DOS, itself inspired by CP/M's API. CP/M rapidly lost market share to the IBM PC platform. Later Digital Research products, including MP/M, Concurrent DOS, and DR-DOS, carried its lineage forward. The CP/M source code was released for non-commercial redistribution by the Computer History Museum in 2014.
