OpenSSH

OpenSSH (Open Secure Shell) is a suite of secure networking utilities based on the Secure Shell (SSH) protocol. It provides encrypted communication sessions over unsecured networks and is the most widely used implementation of SSH, developed by the OpenBSD project and released under the BSD license.

History

OpenSSH began in 1999, when OpenBSD developers, led by Theo de Raadt, forked the last free version of Tatu Ylönen's original SSH implementation after later versions became proprietary. It shipped first with OpenBSD 2.6 in December 1999 and quickly became the standard SSH implementation on Unix-like systems; a portable version runs on Linux, macOS, the BSDs and other platforms, and Microsoft has shipped OpenSSH components with Windows since 2018.

Components

The suite includes:

  • ssh — the client program for logging into remote machines.
  • sshd — the server daemon that accepts connections.
  • scp and sftp — file transfer clients; sftp-server on the server side.
  • ssh-keygen, ssh-agent and ssh-add — key generation and authentication-agent tools.
  • ssh-keyscan and related utilities.

OpenSSH supports public-key and password authentication, port forwarding and tunnelling, X11 forwarding, and agent forwarding. Its configuration is controlled principally by ssh_config and sshd_config files.

Security

Developed with the OpenBSD emphasis on code auditing, OpenSSH pioneered techniques such as privilege separation, in which most of the daemon runs in an unprivileged, sandboxed process. Its cryptographic support comes from LibreSSL or OpenSSL depending on the build.
