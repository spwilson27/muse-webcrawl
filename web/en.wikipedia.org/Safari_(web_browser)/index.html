Safari (web browser)

Safari
Developer: Apple Inc.
Initial release: 7 January 2003
Engine: WebKit, JavaScriptCore
Platforms: macOS, iOS, iPadOS, visionOS

Safari is the default web browser on Apple platforms.

Safari is a web browser developed by Apple Inc. It is built on the open-source WebKit rendering engine and is the default browser on macOS, iOS, iPadOS, and visionOS. Steve Jobs introduced Safari on 7 January 2003 at Macworld; it replaced Internet Explorer for Mac as the default Macintosh browser later that year.

History and development

Safari's rendering engine, WebKit, derives from the KHTML and KJS libraries of the KDE project, which Apple forked and open-sourced. Its JavaScript engine, JavaScriptCore (marketed in fast versions as Nitro and SquirrelFish), has been repeatedly benchmarked among the fastest. A version for Microsoft Windows was offered from 2007 to 2012. Notable features over the years include tabbed browsing refinements, a Reading List, iCloud Keychain password sync, tab groups, and privacy measures such as Intelligent Tracking Prevention, which restricts cross-site tracking cookies. Since 2023, Safari has supported web apps added to the Dock on macOS and multiple user profiles.

Usage

Safari is consistently the second most used browser worldwide, behind Google Chrome, owing largely to its position as the only default browser on the iPhone. Apple's requirement that all iOS browsers use WebKit was relaxed in the European Union under the Digital Markets Act in 2024. Safari's version numbering aligned with Apple's operating systems when Safari 26 shipped alongside the "26" generation of Apple platforms in 2025.
