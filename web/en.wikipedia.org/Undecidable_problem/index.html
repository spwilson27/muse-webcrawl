Undecidable problem

From Wikipedia, the free encyclopedia

In computability theory and computational complexity theory, an undecidable problem is a decision problem for which it is proved to be impossible to construct an algorithm that always leads to a correct yes-or-no answer. The concept derives from work by Kurt Gödel, Alan Turing, and Alonzo Church in the 1930s, which showed that even in arithmetic there are true statements that cannot be proved (Gödel's incompleteness theorems) and decision problems that no computer can solve.

Examples

The most famous undecidable problem is the halting problem: determining, from a description of an arbitrary computer program and an input, whether the program will finish running or continue to run forever. Turing proved in 1936 that no general algorithm for solving the halting problem for all possible program–input pairs can exist. Other undecidable problems include:

  • The Entscheidungsproblem — whether a statement of first-order logic is universally valid
  • Determining whether a Diophantine equation has an integer solution (Hilbert's tenth problem)
  • The Post correspondence problem
  • Determining whether a given context-free grammar is ambiguous, and many questions about program behaviour covered by Rice's theorem

Relationship to decidability

A decision problem is decidable if there is an algorithm (equivalently, a Turing machine) that answers it for every input in finite time. Undecidable problems vary in difficulty: the halting problem is recognisable — a machine can confirm "yes" instances by running the program — but not decidable, whereas other problems are not even recognisable. Undecidability does not mean that specific instances cannot be settled; it means no single algorithm settles all instances.

Logical undecidability

The term is also used for statements in a formal system that can neither be proved nor disproved within that system, such as the continuum hypothesis in ZFC set theory. Gödel's first incompleteness theorem shows that any consistent, effectively axiomatised system capable of basic arithmetic contains such undecidable statements.
