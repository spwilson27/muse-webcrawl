uBlock Origin (pronounced "you-block", styled uBlock Origin and often abbreviated uBO) is a free and open-source browser extension for content filtering, including ad blocking. It is available for several browsers, including Mozilla Firefox, Google Chrome, Microsoft Edge, Opera and Safari (in earlier forms), and is widely regarded as one of the most efficient blockers in terms of memory and CPU usage.

History

uBlock was first released in 2014 by developer Raymond Hill, known online as gorhill. It grew out of Hill's earlier work on the HTTP Switchboard extension. In 2015 the project was forked: the original repository was transferred and renamed, while Hill continued development of his version under the name uBlock Origin to distinguish it from the separately maintained ublock.org version.

The extension gained a large user base through word of mouth and favourable independent benchmarks comparing its resource consumption with other blockers such as Adblock Plus. Hill has maintained the project as a volunteer effort, declining donations and insisting the software remain free.

Features

uBlock Origin blocks requests using filter lists in the Adblock Plus filter syntax, shipping by default with lists including EasyList, EasyPrivacy, Peter Lowe's ad server list, and its own uBlock filters. In addition to network request blocking, it performs cosmetic filtering to hide page elements, and can block JavaScript, pop-ups, large media elements and remote fonts on a per-site basis.

Advanced features include:

  • An element picker/zapper for creating custom cosmetic filters.
  • Dynamic filtering, which lets advanced users set per-site rules for classes of requests.
  • A logger showing network requests and the filters that matched them.
  • Support for blocking CSP reports, prefetching and hyperlink auditing.

Manifest V3 and uBlock Origin Lite

Google's transition of Chrome extensions to the Manifest V3 platform limited the capabilities of the original blocking API, which uBlock Origin relies on. In response, Hill developed uBlock Origin Lite (uBOL), a redesigned, permission-less version built on the declarativeNetRequest API. The full uBlock Origin remains available and fully featured on Firefox, whose extension platform continues to support the blocking webRequest API.

Reception

uBlock Origin has been praised by technology publications and by Mozilla, which has featured it as a recommended extension. Independent tests have repeatedly found it lighter on memory and CPU than competing content blockers.
