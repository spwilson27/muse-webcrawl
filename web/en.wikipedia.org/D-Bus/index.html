D-Bus

D-Bus (short for "Desktop Bus") is a free and open-source inter-process communication (IPC) and remote procedure call (RPC) mechanism used primarily on Linux and other Unix-like systems. It allows multiple programs running concurrently to exchange information through a message bus.

Overview

D-Bus was developed as part of the freedesktop.org project, drawing on the design of KDE's DCOP and GNOME's Bonobo systems. Its reference implementation provides two kinds of bus: a system bus, of which there is one per machine, used for system events and services; and a session bus, of which there is one per user login session, used by desktop applications.

Architecture

Applications connect to a bus daemon and send messages addressed to services identified by well-known names such as org.freedesktop.NetworkManager. A service exposes objects at object paths, which in turn implement interfaces of methods, signals and properties. D-Bus supports one-to-one connections as well as publish-and-subscribe style signal broadcasts, and a match-rule system lets clients subscribe only to messages of interest.

Usage

D-Bus is a core part of modern Linux desktops and of systemd-based systems, where it carries service management, device events (via udisks and UPower), notifications, and countless desktop functions. The busctl and gdbus command-line tools allow inspecting and calling services from scripts.
