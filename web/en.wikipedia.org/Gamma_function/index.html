Gamma function

In mathematics, the gamma function (represented by Γ, the capital letter gamma) is one commonly used extension of the factorial function to complex numbers. For positive integers it satisfies Γ(n) = (n − 1)!, and it is defined for all complex numbers except the non-positive integers.

Definition

Γ(z) = ∫₀^∞ t^(z−1) e^(−t) dt, for Re(z) > 0.

The function extends to a meromorphic function on the whole complex plane with simple poles at 0, −1, −2, … It satisfies the functional equation Γ(z + 1) = z Γ(z), the reflection formula Γ(z)Γ(1 − z) = π / sin(πz), and takes the value Γ(1/2) = √π, a result connected with the Gaussian integral.

History

The gamma function was introduced by Leonhard Euler in correspondence of 1729–1730 as an interpolation of the factorials; the notation Γ is due to Adrien-Marie Legendre. Karl Weierstrass later gave a product representation, and the Bohr–Mollerup theorem characterises Γ as the unique log-convex function with Γ(1) = 1 satisfying the functional equation.

Properties and applications

Derivatives lead to the digamma function; the incomplete gamma functions generalise the integral with a finite limit. The gamma function appears throughout analysis, probability (the gamma distribution), combinatorics, and physics, for instance in computing volumes of n-spheres and in dimensional regularisation.
