Web ARChive

The Web ARChive (WARC) archive format specifies a method for combining multiple digital resources into an aggregate archive file together with related information. The WARC format is a revision of the Internet Archive's ARC format, which has been used since 1996 to store web crawl data. WARC was standardized as ISO 28500 in 2009 and revised in 2017.

Format

Filename extension: .warc, .warc.gz
Developed by: Internet Archive / IIPC
Standard: ISO 28500
Type: Web archive container

A WARC file is a concatenation of records, each with a header containing a record type, a unique record ID, a date, and a content length, followed by the content block and a separator. Record types include warcinfo (describing the file itself), response and request (captured HTTP traffic), metadata, revisit (for unchanged content), resource, conversion, and continuation. Files are usually compressed with gzip, one record per gzip member, so individual records can be retrieved by byte offset.

Use

WARC is the standard format of the International Internet Preservation Consortium (IIPC) members, including national libraries running legal-deposit web archives. Open-source tools such as the Heritrix crawler write WARC natively; replay systems such as OpenWayback, pywb, and webrecorder.io read it; and the Common Crawl dataset distributes its crawls as WARC files.
