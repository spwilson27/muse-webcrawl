Courier New is a monospaced slab serif typeface. It is a version of Courier, the typewriter typeface designed by Howard "Bud" Kettler in 1955 for IBM typewriters, adapted for digital use and distributed with Microsoft Windows and Apple's macOS. Because IBM did not trademark the original design, Courier and its variants became widely used.

Characteristics

Like all Courier designs, Courier New gives every character the same width — 12 characters per inch at 12 point — imitating typewritten output. Courier New has thinner strokes than the original Courier, which some readers find less legible in print, and adjusted line spacing. It became the default monospace font in many early text editors and email clients.

Usage

The Courier family remains the standard for screenplays (normally 12-point Courier, giving roughly one page per minute of screen time) and is commonly specified for manuscripts, legal documents, and displaying computer code and terminal output.
