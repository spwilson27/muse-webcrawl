The Ge'ez script (ግዕዝ), also known as Ethiopic, is an abugida (alphasyllabary) used to write several languages of Ethiopia and Eritrea. It originated as an abjad (consonant-only alphabet) developed from the South Arabian script in the Horn of Africa, and was vocalised — converted into an abugida in which each consonant sign is modified to indicate the following vowel — around the 4th century CE, during the Kingdom of Aksum.

Structure

The script, called fidäl, consists of basic characters for each consonant, each of which appears in seven "orders" corresponding to the vowels that follow it. The basic set for Ge'ez comprises 26 consonants, giving 182 core syllabic signs, with additional labialised and supplementary characters for languages such as Amharic and Tigrinya. Unlike most Semitic scripts, it is written left to right.

Use

The script was created for the Ge'ez language, which survives as the liturgical language of the Ethiopian and Eritrean Orthodox churches. Today it is the everyday writing system for Amharic (the working language of Ethiopia's federal government), Tigrinya, Tigre, and several other languages, and is encoded in Unicode in the Ethiopic blocks.
