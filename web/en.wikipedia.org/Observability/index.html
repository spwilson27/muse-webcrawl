Observability

Observability is a measure of how well the internal states of a system can be inferred from knowledge of its external outputs. It is conceptually dual to controllability. A system is said to be observable if, for every possible sequence of state and control vectors, the current state can be determined in finite time using only the outputs; otherwise it is unobservable. The concept was introduced by Rudolf Kálmán for linear dynamic systems.

Linear systems

For a linear time-invariant system with state matrix A and output matrix C, observability can be tested by forming the observability matrix from C, CA, CA², … ; the system is observable if and only if this matrix has full rank. This is Kálmán's rank condition.

Applications

Observability underlies state estimation: state observers and the Kalman filter reconstruct internal states from measurements, a prerequisite for effective feedback control. The term is also used in software engineering and systems monitoring for the ability to infer internal system behavior from logs, metrics, and traces.
