Device context

A device context (DC) is a structure in the Microsoft Windows Graphics Device Interface (GDI) that defines a set of graphic objects and their associated attributes, plus the graphic modes that affect output. It provides a layer of abstraction that allows an application to draw on a screen, printer, or other output device using the same drawing calls, regardless of the underlying hardware.

Concepts

A device context holds the currently selected pen, brush, font, bitmap, palette, and region, along with drawing attributes such as colours, mapping mode, and clipping. Applications obtain a device context — represented by a handle of type HDC — before painting and release it afterwards; functions such as BeginPaint or GetDC return one for a window's client area, while the CreateDC and CreateCompatibleDC functions create display or memory device contexts for offscreen drawing.

Usage

Because the device context stores state, typical GDI programming consists of selecting objects into the DC, issuing drawing primitives (lines, rectangles, text), and restoring the previous state. Modern Windows graphics frameworks such as Direct2D, WPF, and WinUI supersede GDI device contexts with device-independent rendering models, but the DC remains foundational to Win32 programming and is still used by much legacy and systems software.
