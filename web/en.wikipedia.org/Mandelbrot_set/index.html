Mandelbrot set

The Mandelbrot set is a two-dimensional set with a relatively simple definition that exhibits great complexity, especially when magnified. It is popular for its aesthetic appeal and fractal structures. The set is defined in the complex plane as the set of complex numbers c for which the function

fc(z) = z² + c

does not diverge to infinity when iterated starting from z = 0; that is, for which the sequence fc(0), fc(fc(0)), … remains bounded in absolute value.

The Mandelbrot set, the most famous example of a fractal.

History

The set was first drawn by Robert W. Brooks and J. Peter Matelski in 1978 as part of a study of Kleinian groups. Benoit Mandelbrot, working at IBM, obtained the first high-quality visualisations in 1980 and popularised the set, connecting it with the earlier work of Gaston Julia and Pierre Fatou on iterated rational maps.

Properties

The Mandelbrot set is connected (proved by Douady and Hubbard), compact, and its boundary has Hausdorff dimension 2 (proved by Shishikura). Points c inside the set correspond to connected Julia sets; outside, to totally disconnected "dust". The main cardioid and the period bulbs encode the dynamics of the quadratic family, and miniature near-copies of the set ("baby Mandelbrots") recur at all scales. Colouring points outside the set by their "escape time" produces the familiar intricate images; whether the set is locally connected (the MLC conjecture) remains an open problem.

Generalizations

Related fractals include the Multibrot sets for powers zd + c, the three-dimensional Mandelbulb, and the Burning Ship fractal.
