Container (virtualization)

OS-level virtualization, commonly known as containerization, is an operating-system virtualization method in which the kernel allows the existence of multiple isolated user-space instances, called containers, partitions, or jails. Containers share the host kernel rather than running a separate guest operating system, making them more lightweight than virtual machines.

History

The concept evolved from chroot (1979) through FreeBSD jails (2000) and Solaris Containers (2004) to Linux mechanisms — cgroups (2007) and namespaces — combined in LXC. Docker (2013) popularized containers with a standard image format and tooling, and Kubernetes (2014) became the dominant orchestration system. The Open Container Initiative standardized image and runtime specifications.

Characteristics

Containers start in seconds, package an application with its dependencies for portability across environments, and use fewer resources than hypervisor-based virtualization. Because they share a kernel, their isolation is weaker than that of virtual machines, and containers are typically limited to the host operating system's kernel family.
