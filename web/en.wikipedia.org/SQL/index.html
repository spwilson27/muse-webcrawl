SQL

SQL (Structured Query Language) is a domain-specific programming language used to manage data stored in relational database management systems (RDBMS) and for stream processing in relational data stream systems. It is used to define database schemas, insert, query, update and delete data, and control access and transactions. SQL is the standard language of relational databases such as PostgreSQL, MySQL, Oracle, Microsoft SQL Server, and SQLite.

History

SQL grew out of Edgar F. Codd's relational model (1970). At IBM's San Jose Research Laboratory, Donald Chamberlin and Raymond Boyce developed the language SEQUEL for the experimental System R database in the mid-1970s; the name was shortened to SQL for trademark reasons. Oracle released the first commercial SQL product in 1979. ANSI standardised SQL in 1986 and ISO in 1987, with major revisions adding object-relational features (SQL:1999), XML support (SQL:2003), JSON (SQL:2016), and property graph queries (SQL:2023).

Language elements

SQL statements are commonly grouped into Data Query Language (SELECT), Data Manipulation Language (INSERT, UPDATE, DELETE, MERGE), Data Definition Language (CREATE, ALTER, DROP), Data Control Language (GRANT, REVOKE), and Transaction Control Language (COMMIT, ROLLBACK). The SELECT query — with clauses such as FROM, WHERE, GROUP BY, HAVING, JOIN and ORDER BY — is the heart of the language and is declarative: the user specifies what data is wanted, and the system's query optimiser decides how to retrieve it efficiently, using indexes and join strategies.

Usage and variants

Nearly every substantial application uses SQL databases directly or indirectly, and SQL consistently ranks among the most-used programming languages. Vendors extend standard SQL with procedural dialects (PL/SQL, T-SQL, PL/pgSQL), and dialect differences remain a perennial portability concern. The rise of NoSQL systems in the 2010s did not displace SQL; many such systems later added SQL-like interfaces.
