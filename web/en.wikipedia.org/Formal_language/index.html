Formal language

In logic, mathematics, computer science, and linguistics, a formal language consists of words whose letters are taken from an alphabet and are well-formed according to a specific set of rules called a formal grammar. The alphabet of a formal language is a finite, non-empty set of symbols, and a word is a finite sequence of symbols from that alphabet.

Definition

A formal language is a (possibly infinite) set of finite-length strings over a finite alphabet. Unlike natural languages, formal languages are defined precisely, with no ambiguity about which strings belong to them. Examples include the set of all valid programs in a programming language and the set of all correct mathematical formulas.

Language hierarchy

Formal languages are classified by the power of the grammar or automaton needed to describe them, following the Chomsky hierarchy: regular languages (recognized by finite automata), context-free languages (pushdown automata), context-sensitive languages (linear bounded automata), and recursively enumerable languages (Turing machines).

Operations and applications

Languages support operations such as union, intersection, concatenation, and Kleene star. Formal language theory is fundamental to compiler design, where lexical analysis and parsing determine whether a program text belongs to the language, and to the theory of computation itself.
