Shellcode


Shellcode is a small piece of machine code used as the payload of an exploit.

In hacking, a shellcode is a small piece of code used as the payload in the exploitation of a software vulnerability. It is called "shellcode" because it typically starts a command shell from which the attacker can control the compromised machine, but any piece of code that performs a similar task can be called shellcode. Shellcode is commonly written in machine code and delivered as part of an exploit for a buffer overflow or similar memory-corruption flaw.

Types

Local and remote

Local shellcode is used by an attacker who already has limited access to a machine and wishes to escalate privileges, for example by exploiting a setuid binary to obtain a root shell. Remote shellcode is delivered across a network and typically either spawns a listening shell on a TCP port (bind shell) or connects back to the attacker's machine (reverse shell), the latter being useful for bypassing firewalls and NAT.

Staged

When the space available for injected code is small, the payload is split into stages: a first, tiny stage ("stager") downloads and executes a larger second stage with full functionality. Frameworks such as Metasploit provide libraries of staged and stageless payloads.

Encoding and constraints

Shellcode often must avoid certain byte values — most commonly the null byte, line feed, or carriage return — because these terminate strings or input processing in the vulnerable program. Encoders transform the payload so it contains only permitted bytes (for example, printable ASCII), with a small decoder stub that reconstructs the original code in memory. Techniques such as position-independent code, egg hunters, and alphanumeric shellcode are used to satisfy these constraints and evade detection.

Countermeasures

Defences against shellcode delivery and execution include non-executable memory (DEP), address space layout randomisation (ASLR), stack canaries, and intrusion detection systems that scan network traffic for characteristic shellcode patterns.
