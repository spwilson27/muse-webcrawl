Feature integration theory

Feature integration theory is a theory of visual attention and perception proposed by Anne Treisman and Garry Gelade in 1980. The theory explains how the visual system combines the separate features of an object — such as its color, shape, orientation, and motion — into a unified percept, and it assigns focused attention a central role in that binding process.

The theory

According to feature integration theory, the early stages of visual processing register features automatically and in parallel across the visual field. Each feature dimension is represented in its own "feature map": one map for color, another for orientation, another for size, and so on. At this preattentive stage the features exist as "free-floating" values not yet attached to particular objects.

To bind features into coherent objects, the theory proposes a second, serial stage in which focused attention selects a location in a "master map of locations." Attention acts like a glue: whichever features are currently active at the attended location are combined into a temporary object representation, sometimes called an object file. Only through this attentive process, Treisman argued, do features become correctly conjoined.

Evidence

Several lines of evidence support the theory:

  • Illusory conjunctions: When displays are shown briefly and attention is diverted, observers sometimes report objects combining features of two different items — for example, reporting a red circle after seeing a red square and a green circle — suggesting that unbound features can recombine incorrectly.
  • Visual search: Searching for a target defined by a single feature (such as a red item among green ones) is fast and parallel, producing "pop-out," whereas searching for a conjunction of features (a red circle among red squares and green circles) is slower and appears to require serial attention.
  • Patients with brain damage: Patients with parietal lobe damage, such as those with Balint's syndrome, make frequent illusory conjunctions even with unlimited viewing time, consistent with a deficit in the attentional binding mechanism.

Later developments

Treisman later revised the theory, and it became a foundation for subsequent research on the binding problem in neuroscience. Related proposals include Wolfe's guided search model, which combines bottom-up and top-down guidance of attention. Feature integration theory remains one of the most influential accounts of how attention contributes to perception.
