Google Fonts

Owner: Google

Launched: 2010

Type: Font embedding service

Google Fonts (formerly Google Web Fonts) is a computer font and web font service owned by Google. This includes free and open source font families, an interactive web directory for browsing the library, and APIs for using the fonts via CSS and Android. In June 2023, there were more than 1,550 font families in the library.

History

Google Fonts was launched in 2010 and revamped in 2011, 2016, and 2020. Popular fonts in the library include Roboto, Open Sans, Lato, Oswald, Montserrat, and Raleway. All fonts in the library are released under either the SIL Open Font License or the Apache License, both of which are free software licenses.

Usage

To embed a font, Google Fonts generates CSS that a website includes by linking to the Google Fonts API; the font files are then served from Google's servers. The fonts can also be downloaded for self-hosting or offline use under their open licenses. Google Fonts are used extensively on the web; the service reported trillions of total font views.

Privacy

Because fonts are loaded from Google's servers, the service can log the IP addresses of site visitors, which has raised privacy concerns and led some website operators to self-host fonts instead. In 2022, a German court ruled that embedding Google Fonts in a way that transferred visitor IP addresses to Google violated the GDPR in that case.
