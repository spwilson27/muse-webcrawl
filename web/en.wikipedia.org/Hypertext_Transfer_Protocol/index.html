The Hypertext Transfer Protocol (HTTP) is an application-layer protocol in the Internet protocol suite model for distributed, collaborative, hypermedia information systems. HTTP is the foundation of data communication for the World Wide Web, where hypertext documents include hyperlinks to resources that users can access.

History

HTTP was developed by Tim Berners-Lee at CERN beginning in 1989. The simple first version, HTTP/0.9, was followed by HTTP/1.0 (1996) and HTTP/1.1 (standardized in 1997 and updated in 2014 and 2022). HTTP/2 (2015) added multiplexing and header compression over a binary framing layer; HTTP/3, published in 2022, runs over QUIC instead of TCP.

How it works

HTTP follows a client–server model: a client (usually a web browser) sends a request with a method such as GET, POST, PUT, or DELETE, a URL, and headers; the server replies with a status code (such as 200 OK or 404 Not Found), headers, and usually a body containing the requested resource. HTTP is stateless, so state is maintained with mechanisms such as cookies. The secure variant, HTTPS, encrypts HTTP with TLS.
