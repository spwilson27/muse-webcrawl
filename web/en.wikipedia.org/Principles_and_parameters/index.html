Principles and parameters

Principles and parameters is a framework within generative linguistics in which the syntax of a natural language is described in accordance with general principles (abstract rules or grammars) and specific parameters (markers or switches) particular to individual languages. The framework was central to Noam Chomsky's government and binding theory, set out in the 1981 Lectures on Government and Binding.

Core idea

Universal Grammar is conceived as a system of invariant principles with a finite set of binary parameters. A child acquiring language need only set the parameters from experience — the classic metaphor is a switchbox — which explains the speed and uniformity of acquisition despite limited input (the poverty of the stimulus argument).

Examples of parameters

Well-known proposed parameters include the head-directionality parameter (head-initial languages such as English versus head-final languages such as Japanese), the null-subject (pro-drop) parameter, and wh-movement parameters. Principles and parameters was later largely superseded by the minimalist program, though parametric comparison remains influential.
