Fuzzy set

In mathematics, fuzzy sets are sets whose elements have degrees of membership. Fuzzy sets were introduced independently by Lotfi A. Zadeh and Dieter Klaua in 1965 as an extension of the classical notion of set. In classical set theory, the membership of elements in a set is assessed in binary terms according to a bivalent condition — an element either belongs or does not belong to the set. By contrast, fuzzy set theory permits the gradual assessment of the membership of elements in a set; this is described with the aid of a membership function valued in the real unit interval [0, 1].

Fuzzy sets generalize classical sets, since the indicator functions (also called characteristic functions) of classical sets are special cases of the membership functions of fuzzy sets, if the latter only take values 0 or 1.

Definition

If X is a collection of objects denoted generically by x, then a fuzzy set A in X is defined as a set of ordered pairs: A = {(x, μA(x)) | x ∈ X}, where μA(x) is called the membership function (or MF) of x in A. The MF maps each element of X to a membership value between 0 and 1.

History

Fuzzy set theory was proposed by Lotfi Zadeh of the University of California, Berkeley, in a paper published in 1965 in the journal Information and Control. He elaborated on his ideas in a 1973 paper that introduced the concept of a linguistic variable, which in this setting equates to a variable defined as a fuzzy set. Other research followed, with the first industrial applications of fuzzy logic developed in Japan and Europe after 1975.

Basic operations

For fuzzy sets A and B on the universe X, the standard operations are defined pointwise: the membership of the union is the maximum of the two memberships, the membership of the intersection is the minimum, and the complement is given by one minus the membership. These reduce to the ordinary set operations when the membership functions are crisp. More general operations use t-norms and t-conorms.

Applications

Fuzzy sets underlie fuzzy logic, fuzzy control systems, approximate reasoning, and pattern recognition. They are used in consumer products such as washing machines and air conditioners, in decision analysis, and in data mining, where graded membership can model vague concepts such as "tall", "warm", or "expensive" more naturally than sharp thresholds.
