Programmable logic controller

A programmable logic controller (PLC) is an industrial computerised control system that continuously monitors the state of input devices and makes decisions based upon a custom program to control the state of output devices. PLCs are ruggedised for factory environments and are used to automate assembly lines, machinery, robotics, and process control.

History

The first PLC, the Modicon 084, was developed in 1968 by Bedford Associates under Dick Morley for General Motors, which wanted to replace hard-wired relay panels with a reprogrammable electronic system. Early PLCs were programmed in ladder logic, a graphical language mimicking relay schematics familiar to electricians.

Operation and programming

A PLC operates in a repeating scan cycle: read inputs, execute the program, update outputs. Programming languages are standardised by IEC 61131-3 and include ladder diagram, function block diagram, structured text, instruction list, and sequential function charts. Modern PLCs integrate networking (EtherNet/IP, PROFINET, Modbus) and are key components of SCADA and industrial automation systems.
