Primality test

A primality test is an algorithm for determining whether an input number is prime. Unlike integer factorization, primality tests do not generally give prime factors, only stating whether the input number is prime or not. Factorization is thought to be a computationally difficult problem, whereas primality testing is comparatively easy (its running time is polynomial in the size of the input).

Introduction

Primality tests come in two varieties: deterministic tests, which determine exactly whether a number is prime, and probabilistic tests, which can only establish compositeness with certainty (a number passing is "probably prime"). Some of the tests can be made deterministic by checking a fixed set of bases for numbers below a proven bound.

Simple methods

The simplest primality test is trial division: given an input number n, check whether it is divisible by any prime number between 2 and √n. If n is divisible by any of these numbers, it is composite; otherwise it is prime. This method is fast for small numbers but impractical for large ones.

Probabilistic tests

Probabilistic tests rely on witnesses: for a composite n, most bases a will "witness" compositeness. The Miller–Rabin primality test is based on properties of modular arithmetic derived from Fermat's little theorem and the fact that the only square roots of 1 modulo a prime are ±1. Repeating the test with k random bases reduces the error probability to at most 4−k.

Deterministic tests

In 2002, Manindra Agrawal, Neeraj Kayal, and Nitin Saxena announced the AKS primality test, the first published general, fast, unconditional, and deterministic primality test. It runs in polynomial time in the number of digits of n. In practice, the elliptic curve primality proving (ECPP) method and the Baillie–PSW test are widely used.

Applications

Fast primality tests are essential to public-key cryptography: systems such as RSA require generating large prime numbers, which is done by randomly selecting candidate numbers and subjecting them to probabilistic tests such as Miller–Rabin.
