Virtual memory

Virtual memory, or virtual storage, is a memory management technique that provides an "idealized abstraction" of the storage resources that are actually available on a given machine, creating the illusion to users of a very large (main) memory. The computer's operating system, using a combination of hardware and software, maps memory addresses used by a program, called virtual addresses, into physical addresses in computer memory.

Mechanism

Main storage, as seen by a process, appears as a contiguous address space. The address space is usually divided into fixed-size pages; the memory management unit (MMU) translates virtual page numbers to physical frame numbers using page tables. Pages not resident in RAM may be held in a page file or swap area on disk; accessing one triggers a page fault, after which the operating system loads the page, possibly evicting another. This permits programs larger than physical memory to run and allows each process to operate in its own protected address space.

History

The concept was first developed for the Atlas computer at the University of Manchester, completed in 1962, where it was called the "one-level store". IBM's OS/360 MVT and later MVS, DEC's VMS, and the Unix family all adopted virtual memory; it is now universal in general-purpose operating systems. Excessive disk swapping can cause thrashing, in which the system spends most of its time moving pages rather than executing instructions.

Uses

Beyond enlarging effective memory, virtual memory enables memory protection between processes, memory-mapped files, shared libraries loaded once for many processes, and copy-on-write optimisation.
