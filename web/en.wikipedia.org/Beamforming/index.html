Beamforming

FieldSignal processing
Used inRadar, sonar, wireless communications, acoustics
Key elementPhased array of sensors or antennas

Beamforming or spatial filtering is a signal processing technique used in sensor arrays for directional signal transmission or reception. By combining signals from multiple elements of an array with controlled phase and amplitude, the array's sensitivity is concentrated in a chosen direction while interference from other directions is suppressed.

Techniques

In a conventional delay-and-sum beamformer, each sensor's signal is delayed so that waves arriving from the target direction add coherently, then summed. Adaptive beamformers, such as the minimum variance distortionless response (MVDR or Capon) beamformer, adjust weights in response to the measured environment to null interferers. Beamforming is distinguished from MIMO techniques, which use multiple propagation paths to send separate data streams, though hybrid approaches combine the two.

Applications

Beamforming originated in radar and sonar and is now central to wireless standards including IEEE 802.11ac/ax Wi-Fi and 5G NR, where base stations steer beams toward individual users. Other applications include medical ultrasound imaging, hearing aids, microphone arrays for speech enhancement, radio astronomy, and seismology. Digital beamforming performs the combining in software after analogue-to-digital conversion, allowing many simultaneous beams; analogue beamforming combines signals in RF hardware and is cheaper but less flexible.
