Block design
Field: Combinatorics
Key parameters: v, b, r, k, λ
Example: Finite projective planes

In combinatorial mathematics, a block design is an incidence structure consisting of a set of points together with a family of subsets called blocks, chosen so that specified balance conditions hold. Balanced incomplete block designs (BIBDs) are central to the statistical design of experiments.

Parameters

A BIBD is described by parameters (v, b, r, k, λ): v points arranged in b blocks, each block containing k points, each point in r blocks, and each pair of points together in exactly λ blocks.

Applications

Block designs originated in experimental design, where blocking controls variation, and connect to finite geometry, coding theory and graph theory.
