Community-led development of open-source software for the public good — home to the Apache HTTP Server and more than 300 projects, from big data to AI.

Distributed event streaming used by thousands of companies for real-time data pipelines.

Apache Hadoop

The framework that launched the big-data era, for distributed storage and processing.

The widely deployed Java servlet container behind countless web applications.

Apache Airflow

Programmatic workflow authoring, scheduling and monitoring for data pipelines.

"The Apache Way"

Meritocracy, community over code, open development and consensus-based decision making — the governance model behind every Apache project, stewarded by a volunteer foundation founded in 1999.
