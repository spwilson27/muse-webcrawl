About this paper

The public consortium's draft of the human genome: some 3 billion bases, a surprisingly small gene count of roughly 30,000–35,000 as then estimated, vast repeat landscapes, and segmental duplications mapped for the first time. Published in a landmark Nature issue alongside Celera's rival draft, it is the reference point from which modern genomics descends. The sequence itself was released freely — the anti-paywall ethos Sci-Hub cites most often.
