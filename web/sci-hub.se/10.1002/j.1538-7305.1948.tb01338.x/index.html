TitleA Mathematical Theory of Communication
Author(s)Claude E. Shannon
JournalBell System Technical Journal 27: 379–423, 623–656
Year1948

About this paper

Shannon's two-part 1948 paper that created information theory: it defines the bit, entropy as a measure of information, channel capacity, and proves the noisy-channel coding theorem — showing error-free communication is possible below capacity. It underlies all modern digital communication and compression.
