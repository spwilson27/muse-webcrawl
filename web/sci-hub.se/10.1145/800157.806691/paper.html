The Complexity of Theorem-Proving Procedures

Stephen A. Cook

Department of Computer Science, University of Toronto

Proceedings of the Third Annual ACM Symposium on Theory of Computing (STOC '71), Shaker Heights, Ohio, 1971, pp. 151–158. DOI: 10.1145/800157.806691

ABSTRACT

It is shown that any recognition problem solved by a polynomial-time nondeterministic Turing machine can be "reduced" to the problem of determining whether a given propositional formula is a tautology, the reduction being computable in polynomial time. Hence the satisfiability problem (equivalently, the tautology problem) is at least as hard as every problem in the class now called NP: if tautologies could be recognised in polynomial time, then so could all problems solvable in nondeterministic polynomial time, including many natural problems for which no good algorithm is known — the travelling salesman problem, subgraph isomorphism, and the scheduling problems. The paper thereby founds the theory of NP-completeness. [Reconstruction from memory; argument paraphrased.]

1. Introduction

Theoretical computer science has measured procedures chiefly in terms of computability; but for problems that arise in practice — in theorem proving, in combinatorics, in operations research — the operative question is not whether a procedure exists but whether one exists whose running time grows only polynomially in the size of the input. Consider the problem of deciding whether a propositional formula in disjunctive normal form is a tautology. The obvious procedure tests all assignments; nothing substantially better is known. This paper shows the poverty of our algorithms is not accidental: the tautology problem stands at the head of a large class of seemingly unrelated problems, all equivalent under efficient reductions. Either all of them admit polynomial procedures, or none does.

2. Definitions

A query machine is a Turing machine equipped with a query tape and distinguished states; on entering a query state it asks whether the string then on the query tape belongs to a fixed set (the "oracle"), and continues according to the answer, the whole question costing one step. A set S is P-reducible to a set T if a query machine with oracle T decides S in a number of steps bounded by a polynomial in the length of its input. A set S belongs to the class 𝒫 if it is decided by an ordinary machine in polynomial time, and to the class 𝒩𝒫 if it is decided by a nondeterministic machine — one allowed to branch, accepting if some branch accepts — in polynomial time. Clearly 𝒫 ⊆ 𝒩𝒫; whether equality holds is the great open question the paper leaves on the table.

3. The main theorem

Theorem 1. If a set S of strings is accepted by some nondeterministic Turing machine within polynomial time, then S is P-reducible to the set of satisfiable (equivalently, of tautologous in disjunctive normal form) propositional formulas.

The proof constructs, for a given machine M, input w of length n, and time bound p(n), a propositional formula A(w) whose variables describe the entire computation tableau of M on w: variable Q[i,t] says the machine is in state i at time t; H[i,t] locates the tape head; S[j,i,t] says square i holds symbol j at time t. Clauses then enforce, purely propositionally, that the first row of the tableau is the initial configuration on w, that each successive row follows from its predecessor by M's transition table, that the head is in exactly one place at each time, and that the final row contains an accepting state. The formula has polynomially many variables and clauses — O(p(n)²), in effect a square tableau — and it is a tautology (in the satisfiable-sign variant) exactly when M accepts w. Theorem proving is thereby shown to be the universal nondeterministic problem.

w accepted in time p(n)  ⟹  A(w) satisfiable,   |A(w)| = O(p(n)² log p(n))

4. Corollaries and companion problems

Because P-reducibility composes, Theorem 1 propagates hardness through any chain of efficient reductions. The paper lists natural companions of the tautology problem: whether a formula in conjunctive normal form is satisfiable (with three literals per clause already as hard as the general case); whether two graphs contain isomorphic subgraphs of a given size, or one graph contains a clique or an independent set of size k; whether a graph has a Hamiltonian path; set covering and exact cover; and the integer-programming feasibility problem. Each is in 𝒩𝒫 by inspection — guess the witness and check it — and each inherits, via short reductions from satisfiability, the property of being complete for 𝒩𝒫. The class of problems for which only exponential procedures are known is thus a single web, not a scattered collection of puzzles.

5. Concluding remarks

The theorem does not prove that no polynomial procedure exists for the tautology problem; it proves that finding one would settle, in the affirmative and all at once, hundreds of problems that have resisted attack — among them most of the open optimisation problems of combinatorics. The presumption of the field thereafter: 𝒫 ≠ 𝒩𝒫, and the problems catalogued here are intrinsically exponential. That presumption, still unproved half a century on, is the P versus NP problem; the paper's eight pages are its birthplace, and Karp's 1972 catalogue of 21 complete problems its first expansion.
