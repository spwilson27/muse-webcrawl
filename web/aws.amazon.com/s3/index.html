Amazon Simple Storage Service (Amazon S3)

Object storage built to store and retrieve any amount of data from anywhere — the storage foundation for websites, data lakes, backups and archives across the internet.

Get Started with Amazon S3
[Image: Green S3 bucket icon surrounded by files, photos and backups flowing in]
99.999999999% — "eleven nines" of durability, with data replicated across at least three Availability Zones. S3 stores hundreds of trillions of objects for millions of applications (figures as marketed by AWS, from memory).

Storage classes for every use case

S3 Standard

Frequent access, low latency — the default for websites, content distribution and analytics.

S3 Intelligent-Tiering

Automatically moves data between tiers as access patterns change; the most popular class for unknown patterns.

S3 Standard-IA & One Zone-IA

Cheaper storage for infrequently accessed but rapidly available data and backups.

S3 Glacier Instant Retrieval

Archive storage with millisecond retrieval, at a fraction of Standard cost.

S3 Glacier Flexible / Deep Archive

The lowest-cost tiers for long-term retention, compliance archives and digital preservation.

S3 Express One Zone

The fastest S3 class — single-digit millisecond latency for the most demanding applications.

Security & management

Block Public Access by default for new buckets, bucket policies and IAM integration, default encryption, Versioning, Object Lock for ransomware protection, Replication across Regions, and lifecycle rules that age data into cheaper classes automatically.
