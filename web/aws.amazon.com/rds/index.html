Amazon Relational Database Service (Amazon RDS)

Set up, operate and scale a relational database in the cloud with just a few clicks — AWS handles provisioning, patching, backup, recovery and failure detection.

Your engine, managed

Amazon Aurora

AWS's own MySQL- and PostgreSQL-compatible engine — up to 5× MySQL throughput, serverless and provisioned options, and Aurora DSQL for distributed SQL.

PostgreSQL

The community favourite, with extensions like PostGIS, on managed instances with automated minor upgrades.

MySQL & MariaDB

The web's workhorse databases, fully managed — including read replicas for read-heavy applications.

Oracle & SQL Server

Commercial engines on RDS, license-included or bring-your-own-license depending on edition.

Db2

IBM Db2 as a managed RDS engine for mainframe-adjacent enterprise workloads.

RDS Custom

For applications that need OS and database customisation managed hosting normally forbids.

Built-in reliability

Multi-AZ deployments keep a synchronous standby for automatic failover, automated backups and point-in-time restore cover up to 35 days, and cross-Region backups and Global Databases span continents. RDS Blue/Green Deployments make engine upgrades nearly risk-free.
