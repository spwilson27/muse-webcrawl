How images work here: this repo is pushed through a text-only channel, so every image lives in the repo as a base64 text file (…/images/foo.png.b64) while the pages reference the plain image path. A small service worker registered by this page intercepts image requests, decodes the base64 in your browser, and serves the real picture. Tip: land on this page once per visit so the worker activates; if a page ever shows blank images, come back here and then hard-refresh (Ctrl/Cmd+Shift+R).
